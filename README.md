# 民法大全：来源归档与中文整理

《民法大全》（Corpus Iuris Civilis）四部分的网页来源归档、可编辑译稿、术语和译校记录，以及可导航 EPUB。当前快照版本为 **v2026.10.11**。

本项目汇集现有整理成果。《法学阶梯》目前只有拉丁原文版；《学说汇纂》提供五十卷中文全译本；《查士丁尼法典》和《新律》提供中文及中拉对照阅读版本。中文译文为机器辅助整理成果，尚未由独立罗马法学者全面审定。请结合原文、底本版本与译校记录使用。

## 收录范围与版本

- **法学阶梯（Institutiones）**：序文、第一至第四卷、标题索引。网页署名据 Paulus Krueger 文本，由 Philippe Paschel 校对；本整理未对该印本逐页校勘。
- **学说汇纂（Digesta）**：三篇敕令、标题索引、第一至第五十卷。保留拉丁原文与中文稿中的编号、原文锚点、希腊文片段、编辑标记和疑难记录。第30卷底本空段等例外保留于翻译进度记录。
- **查士丁尼法典（Codex）**：三篇前置文本、第一至第十二卷。台账列有4,683个翻译单元；`ai_second_pass`是项目审校状态，不能替代独立学术审定。拉丁单语版对网页英文缺文提示的处理、网页来源版与中文单语版的区别，见作品说明。
- **新律（Novellae）**：按来源目录保存165个新律链接篇目、10个敕令链接页、9个附录篇目和两页尤利安摘要。新律136、137、163及敕令7、9、13未见目录链接；敕令I、V、VI标作“Unknown text.”；尤利安摘要kp.531缺载。缺失内容保留记录，中拉对照版只包含成对段落。

## 来源与文件

主要来源为格勒诺布尔—阿尔卑斯大学的 [The Roman Law Library](https://droitromain.univ-grenoble-alpes.fr/)。各作品说明、来源清单与原始 HTML 保留具体底本、网页录入者、编码、来源 URL、下载时间和 SHA-256。

- [`works/institutiones`](works/institutiones)：法学阶梯的原始网页、离线网页、编排源和 EPUB。
- [`works/digesta`](works/digesta)：学说汇纂的原始网页、拉丁 EPUB、中文稿、术语表、疑难表及进度记录。
- [`works/codex`](works/codex)：法典的来源文件、逐条译稿、台账、术语、校验工具和四个 EPUB。
- [`works/novellae`](works/novellae)：新律的来源文件、对读稿、中文稿、构建工具和三个 EPUB。
- [`reports`](reports)：本次发布的结构、来源、重建与导航修订记录。作品目录内2026年9月的验收文件作为历史记录保留；以本次发布报告中的文件哈希为准。

原始来源文件按字节保留。来源署名、既有权利声明和研究整理说明照录；本仓库暂未设置覆盖全部文本与代码的统一开放许可证。公开上传本身不替代各来源的既有说明。

## 离线构建与核验

使用 Python **3.10或更高版本**，核心构建与校验仅依赖标准库。命令在仓库根目录执行：

```sh
python3 scripts/verify.py
python3 scripts/build.py --work all --output-dir build
```

也可用 `--work institutiones`、`--work digesta`、`--work codex` 或 `--work novellae` 单独重建。工具在独立临时目录中构建，输出到 `build/`；缺少来源、来源哈希变化、断链、导航缺口或重建正文不一致都会导致失败。默认使用已有归档，构建不重新请求网站。

《法学阶梯》的 `edition/` 是从已有阅读版本导出的可编辑 XHTML、目录、CSS和包元数据；其构建入口重建 EPUB 封装。原始网站字节另存在 `source_original/`。其余三部分使用原有网页解析及译稿构建器。这些入口均不代表新增校勘或重新翻译。

重建核对正文、标题、锚点、链接、导航及阅读顺序。生成时间、包标识或ZIP时间可能改变，故不要求重建文件与发布快照具有同一字节哈希。

本次校验包括来源 SHA-256及字节数、ZIP CRC、首项未压缩 `mimetype`、XML、OPF资源、内部链接与片段、目录及译稿覆盖。EPUBCheck未安装，未声称通过其官方校验；10册均通过Calibre 7.22.0转换解析；机器校验不替代专业译校和阅读器人工校样。
