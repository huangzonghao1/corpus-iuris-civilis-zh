| *natalibus redditus* / *natalibus restituere* | 恢复自由出生者身份 | 皇帝授予自由释奴、使其法律地位恢复为自由出生者的特权；原则上使释奴保护人的继承等权利消灭，与仅取得金戒指权而仍保有释奴身份区分。 | D.38.2.3.1; D.40.11.1–5 |
| *in servitutem petere* | 请求将某人置于奴隶身份 | 自自由身份主张某人应为奴隶的身份诉讼；应与对已经处于奴隶占有状态者提出自由请求而作出的抗辩区分。 | D.38.2.14–16 |
| *bonorum possessio unde liberi* | 子女顺位遗产占有 | 依裁判官告示以子女身份请求的无遗嘱遗产占有；与依遗嘱书板或违遗嘱方式取得的遗产占有区分。 | D.38.6 |
| *bonorum possessio unde legitimi* | 法定继承人顺位遗产占有 | 依裁判官告示向法定继承人开放的无遗嘱遗产占有；须与市民法上的继承权本身区分。 | D.38.7 |
| *consanguinei* / *consanguinitas* | 同父血亲 / 同父血亲关系 | 罗马继承语境中的特定亲属类别，通常指同父兄弟姊妹；依具体文本处理，不泛指一切血亲。 | D.38.7.2.1, 5.1, 6 |
| *adgnati* / *cognati* | 宗亲 / 血亲 | 宗亲必然属于血亲，但血亲不必然是宗亲；依《十二表法》继承顺位和具体亲等区分。 | D.38.7.2, 5 |
| *unde cognati* / *bonorum possessio unde cognati* | 按血亲亲属顺位取得遗产占有 | 裁判官依据自然血缘关系，准许市民法上不能继承者取得的遗产占有；范围不限于现代狭义“旁系血亲”。 | D.38.8 |
| *successorium edictum* | 继承顺位告示 | 规定遗产占有人接受或放弃遗产占有的期间，并使下一顺位者依次承接；与各特定顺位的遗产占有告示区分。 | D.38.9.1.pr. |
| *proximus cognatus* / *proximi cognati* | 最近亲属 | 依裁判官告示按亲等顺序取得遗产占有者；最近亲属依遗产占有被授予之时确定。 | D.38.8.1.5–7 |
| *vulgo quaesiti liberi* | 非婚生子女 | 指并非婚姻关系中所生的子女；在本卷文本中，母子之间及同母兄弟姐妹之间仍可成立血亲关系。 | D.38.8.2 |
| *tempus utile* / *dies utilis* | 有效期间／有效日 | 仅在当事人知道且能够行使请求权的日期内计算；不得将其等同于连续日历期间。 | D.38.15.2.pr.–5 |
| *bona castrensia*（军人遗产） | 军营特有产 | 军人依军旅身份取得并按特别规则继承的财产；与一般遗产以及军营特有财产的所有权来源区分。 | D.38.12.2 |
| *gradus cognationis* | 亲属亲等 | 按亲属世代或旁系共同祖先逐级计算的距离；保留原文对直系与旁系的计算说明。 | D.38.10.10.9–11 |
| *consobrinus* / *consobrina* | 表亲（广义；必要时保留原词） | 保罗指出其时代不少人以此概称不同支系的兄弟姐妹之子女；不宜机械对应单一现代亲属称谓。 | D.38.10.10.15–17 |
| *patruus* / *amita* / *avunculus* / *matertera* | 伯叔父／姑母／舅父／姨母 | 依父系、母系区分父母的兄弟姐妹；本题以这些专名为基础推演远代亲属称谓。 | D.38.10.10.14–17 |
| *patruus magnus* / *amita magna* / *avunculus magnus* / *matertera magna* | 伯叔祖父／姑祖母／舅祖父／姨祖母 | 对应祖父母的兄弟姐妹；后续 *maior*、*maximus* 继续表示更远一代，但代际译名仅作便读，首次保留拉丁称谓。 | D.38.10.10.15–17 |
| *proavus* / *abavus* / *atavus* / *tritavus* | 曾祖父／高祖父／五世祖父／六世祖父 | 本题逐代列出上行尊亲属专名；汉语代际名称依该段层级处理，遇计算链条时保留拉丁词以便核对。 | D.38.10.10.14–17 |
| *levir* / *glos* / *ianitrices* | 丈夫之兄／丈夫之姐妹／兄弟之妻（彼此） | 罗马姻亲称谓；*levir* 等词按本题语境译，希腊转写及引文保留原形。 | D.38.10.4.6 |
| *privignus* / *privigna* / *vitricus* / *noverca* | 继子／继女／继父／继母 | 因父母再婚形成的姻亲称谓；依说话主体与性别确定具体关系。 | D.38.10.4.6 |
| *socer* / *socrus* / *gener* / *nurus* | 岳父或公公／岳母或婆婆／女婿／儿媳 | 姻亲称谓，具体汉语译名随关系方向而定；订婚亦可产生相应称谓。 | D.38.10.4.6; D.38.10.6.1 |
| *senatus consultum Tertullianum* | 《特尔图良元老院决议》 | 规定母亲在特定条件下可继承无遗嘱子女遗产的决议；须与《奥尔菲提安元老院决议》所规定子女继承母亲遗产的规则区分。 | D.38.17.2, 5 |
| *senatus consultum Orphitianum* | 《奥尔菲提安元老院决议》 | 规定子女可继承无遗嘱母亲遗产的决议；涉及自然、收养及非婚生子女时应依具体条文判断。 | D.38.17.1, 6–10 |
| *vulgo quaesitus* / *vulgo quaesiti* | 非婚生子女 | 非婚姻关系所生子女；本卷确认其在特定条件下可依元老院决议取得父母遗产，不径直套用现代婚生/非婚生法律效果。 | D.38.17.1.2–3; 2.1 |

| *remissio nuntiationis* | 新工程告示的解除 | 裁判官程序中使告示的停止施工效力终止；与告示被视为已经解除的担保情形相联系。 | D.39.1.5.17; D.39.1.8.4; D.39.1.20 |
| *suggrunda* / *proiectio* | 屋檐／突出建筑部分 | D.39.2 题名列举的建筑构造；*proiectio* 指从建筑物突出或伸出的部分，依语境保留原词以便回查。 | D.39.2.0 |
| *superficies* / *superficiarius* | 地上建筑权／地上权人 | 指他人在土地上享有建筑或地上物权利的关系及其权利人；与土地所有权及用益权区分。 | D.39.2.9.4–5 |
| *missio in possessionem* / *in possessionem mittere* / *in possessionem mitti* | 准入占有／准许进入占有 | 裁判官准许请求人进入特定财产占有或保全财产的程序救济；依场合可构成实际占有，也可能仅授予保管、看守资格，不当然等同取得所有权。 | D.39.2.4.1, 5.1; D.42.4.1–15, 12 |
| *interdictum quod vi aut clam* | 关于暴力或秘密行为的禁令 | 针对以暴力或秘密方式实施行为的裁判官禁令；本题将其与工程损害担保并列。 | D.39.2.13.10 |
| *rudera* / *ruina* | 瓦砾／倒塌 | 指建筑物倒塌及其残瓦碎石；按是否清除、遗弃及损害已发生区分相应救济。 | D.39.2.6–9 |

| *commissum* | 没收；没收物 | 因违反税赋申报或其他规定而发生的财物没收；依上下文译作“没收处罚”或“判归没收”。 | D.39.4.7.1; D.39.4.11.2 |
| *publicani familia* | 公税承包人帮役队伍 | 服务于公税承包人税赋承包事务的奴隶及其他帮役人员；本题中不限于公税承包人所有的奴隶。 | D.39.4.1.5; D.39.4.12.2 |
| *vectigal locare / conducere* | 出租 / 承包税赋 | 公共机关将税赋征收或相关收入经营权交由承包人经营，承包人支付约定租金或承包款。 | D.39.4.9.1–5 |
| *in commissum cadere* | 落入没收事由 | 因未申报、违法运入或其他税赋违规而使物品受没收。 | D.39.4.16.1–12 |
| *noxalis actio* | 诺克萨诉权；家父替代责任诉权 | 奴隶或受家父权支配者实施行为时，对家父或主人提起的特别诉权；责任结构及交付行为人的抗辩效果依具体条文判断。 | D.39.2.17.pr. |
| *actio communi dividundo* | 共有物分割之诉 | 共有人请求分割共有物并结算必要费用或共同关系的诉讼。 | D.39.2.15.19 |
| *longi temporis dominium capere* | 通过长期占有取得所有权 | 本题指经裁判官第二道裁令确立取得占有后，方开始计算长期占有取得所有权。 | D.39.2.15.16–18 |
| *bona fide absentes* | 善意离开者 | 善意离开相关财产或所在地、因此未能及时请求担保者；返回后仍可请求衡平救济。 | D.39.2.19.pr. |
| *manumissio testamento* / *libertas testamentaria* | 遗嘱释奴／遗嘱所给自由 | 依有效遗嘱给予奴隶的自由；通常须遗嘱有效且继承人接受遗产，并依直接释奴或遗嘱信托释奴的方式区分。 | D.40.4 |
| *libertas directa* | 直接释奴 | 遗嘱直接给予的自由；与通过遗嘱信托要求继承人释放奴隶的 *libertas fideicommissaria* 区分。 | D.40.4.43 |
| *heres necessarius* | 必然继承人 | 依罗马法特定规则，在继承开始时依法当然承受遗产、通常不能自由拒绝的继承人；与 *heres suus et necessarius* 等复合分类按语境区分。 | D.40.4.27, 32 |
| *operae*（释奴语境） | 释奴劳务／劳役 | 获释后释奴可能对释奴保护人承担的劳务；奴隶在释奴前的誓言本身不当然产生该义务。 | D.40.4.36; D.40.12.44 |
| *nomenclator* | 报姓名者 | 为他人提示、报出姓名的随侍或奴隶；D.40.12.44.2 将其作为未适婚人也能提供劳务的例子。 | D.40.12.44.2 |


| *donatio* | 赠与 | 出于慷慨而使受领人取得财物或利益；依条文区分立即、附条件及附解除条件的赠与，不将所有无偿或因某种原因给付一概归入同一类型。 | D.39.5.1.pr.–1; D.39.5.3 |
| *donatio mortis causa* | 因死亡赠与 | 以赠与人的死亡危险、预期或其他死亡事件为背景的赠与；依罗马法规则可附返还或生效条件，与绝对生前赠与区分。 | D.39.5.1.pr.; D.39.5.7.4–6; D.39.5.18.2; D.39.6.1.pr.–2; D.39.6.35 |
| *causa donationis* / *condicio* | 赠与原因／条件 | 本题以二者区分给付的动机与决定给付或返还的条件：仅为原因的事件不当然产生返还请求，真正条件未成就或解除时可能请求返还。 | D.39.5.1.pr.; D.39.5.2.7; D.39.5.3 |
| *in quantum facere potest* / *quantum facere potest* | 仅在履行能力范围内 | 限制因赠与而承担债务者的责任；依上下文扣除债权债务或适用于诉讼执行，不泛化为所有债务责任规则。 | D.39.5.12; D.39.5.24; D.39.5.33.pr., 3 |
| *actio constitutae pecuniae* | 约定款项之诉（暂译） | 对经约定应支付的款项提起的裁判官法诉讼；D.39.5.33.pr.依赠与原因将责任限于被告履行能力。 | D.39.5.33.pr. |
| *servitus haustus* / *haustus* | 取水役权／取水权 | 允许从水源取水的役权；与经他人土地引水的 *aquae ductus* 及为到达水源而设的通行役权区分。 | D.39.3.17.2–4 |
| *arbiter aquae pluviae arcendae* | 阻止雨水侵入之诉裁判人 | 在该诉程序中负责判断未来水害并命令填沟、恢复工程或判令责任的裁判人；依上下文与普通审判法官区分。 | D.39.3.24 |
| *agger* | 堤坝；堤堰 | 可能是天然形成或人为修筑的土堤；其是否属人工、年代是否可考，会影响恢复义务及本诉适用。 | D.39.3.2.5; D.39.3.23.2 |
| *specus* / *cuniculus* | 地下水道／隧洞 | D.39.3.11.pr. 区分河道下方引水的地下水道与隧洞；保留拉丁词以核对水流受损的具体构造。 | D.39.3.11.pr. |
| *fistula* / *fistulae* | 水管；管道 | 引水役权通常可采用的管道方式；设定役权时未逐项写明，并不当然排除使用，但不得损害土地所有人。 | D.39.3.17.1 |
| *servitus aquae nocturnae* / *servitus aquae diurnae* | 夜间用水役权／白天用水役权 | 分别指在夜间或白天引水的土地役权；若作为不同原因设立且规定期间内只行使其中一项，另一项可能消灭。 | D.39.3.17.pr. |

| *mortis causa capere* | 因死亡而取得 | 因他人死亡而取得财物或利益的概念，范围不止于赠与，也涉及遗赠条件给付等；依文本与继承、遗赠、遗嘱信托等专门取得方式区分。 | D.39.6.8.pr.; D.39.6.31.pr. |
| *condictio* ex *donatione mortis causa* | 因死亡赠与返还之诉 | 赠与人康复、撤回意思或约定条件未成就时，请求受赠人返还财物或价额的返还诉讼；依具体条文与对物之诉区分。 | D.39.6.13.pr.; D.39.6.30; D.39.6.37.1 |
| *donatio inter vivos* | 生前赠与 | 与因死亡赠与相对，指不以赠与人死亡或死亡危险作为返还/取得条件的赠与；依条文可能包括不得撤销的绝对赠与。 | D.39.6.27 |

| *manumissio vindicta* | 以仪式杖施行的正式释奴仪式 | 在有管辖权的官员面前以节杖象征性触及奴隶、宣布其自由的正式释奴方式；正文标题简称“以仪式杖释奴”；皇帝可依特别规则以其意思直接使奴隶自由。 | D.40.1.14.1, 15; D.40.2 |
| *redimi suis nummis*（奴隶释奴） | 以奴隶自己的钱赎买以获释 | 皇帝敕令承认的释奴路径；严格说奴隶不拥有自己的钱，故包括由第三人代付、但买主未动用自己财产的情形。 | D.40.1.4.pr.–14; D.40.1.5.pr. |
| *causa manumissionis* / *iusta causa* | 释奴的正当原因 | 未满二十岁者在特定释奴情形中须证明的正当原因；包括亲属关系、婚姻及奴隶既往贡献等情形；依是否属遗嘱信托释奴及其他法定途径分别处理。 | D.40.1.20.pr.–1; D.40.2.9–16 |
| *consilium*（释奴程序） | 顾问团 | 未满二十岁者释奴时参与审查释奴原因的顾问团；与一般法律咨询或裁判官提供的意见相区别。 | D.40.2.4.2, 6, 15.1, 19, 24 |
| *Lex Aelia Sentia* | 《埃利亚·森提亚法》 | 规定释奴的年龄、正当原因、债权人保护及身份效果等限制；具体适用须结合条文与相关帝国敕令。 | D.40.1.4, 8, 20; D.40.9.5–32 |
| *Lex Fabia* / *plagium* | 《法比亚法》／拐掠自由人罪 | 《法比亚法》规制将自由人非法拐掠、置于奴隶身份的行为；D.40.1.12 涉及主人为此受罚后，相关奴隶在一定期间内不得被解放。 | D.40.1.12 |
| *Lex Iunia Petronia* | 《尤尼亚·佩特罗尼亚法》 | 规定自由身份诉讼中法官意见相等而相异时作有利于自由的裁判；证人数量相等的处理亦依敕令确定。 | D.40.1.24.pr.–1 |

| *servus civitatis* | 市镇共同体奴隶 | 属于市镇共同体的奴隶；依市镇法令获释后，对其未被收回的特有产仍可保有。 | D.40.3.3 |


| *ademptio libertatis* | 自由的剥夺 | 指法律使已授予或拟授予的自由失去效力；本题将依法剥夺自由的效果比照视为未曾授予，或视同遗嘱人撤销自由。 | D.40.6.1 |


| *sine manumissione ad libertatem pervenire* | 无须正式释奴而取得自由 | 指依法律、交易条件或其他法定事由直接取得自由，无须另行完成通常的释奴行为。 | D.40.8 |
| *pro derelicto habere*（奴隶） | 视为遗弃物 | 主人因奴隶重病等原因放弃其所有权；本题引神圣克劳狄乌斯告示，相关奴隶可因此取得自由。 | D.40.8.2 |


| *in fraudem creditorum manumittere* | 为诈害债权人而释奴 | 债务人于无清偿能力时或因释奴而陷入无清偿能力，意图损害债权人而授予自由；《埃利亚·森提亚法》依债务到期、条件及债权人类型分别规制。 | D.40.9.5–11, 16, 18, 23–29 |
| *accusatio liberti ingrati* | 控告释奴忘恩负义 | 释奴保护人对被释奴提起的身份性控告；谁有权控告，取决于实际释奴、父权同意、军役特有产及释奴保护人顺位。 | D.40.9.30 |

## 本轮术语校订说明

- *litis contestatio* 统一译作“争讼程序”，涉及时间节点时译作“争讼程序确定前／后／时”。中文罗马法研究对该术语存在不同译法；本译本采用能标示程式诉讼中当事人确定法律争议并进入审判阶段的“争讼程序”，不等同现代法院受理。参见《罗马法上的“诉”——构造、意义与演变》，《中外法学》2013年第3期。
- *actio iniuriarum* 统一译作“侵辱之诉”；正文中的 *iniuria* 仍依一般违法、侮辱或损害等上下文分别翻译。参见 Peter Birks, “Iniuria (Contempt),” in *The Roman Law of Obligations* (2014).
- *servitus* 按上下文区分奴隶身份与役权；役权作为上位译名，土地役权在明确语境中译作“地役权”。D.50.17.209 仍保留疑难标记。
- *acceptilatio* 统一译作“要式免债行为”，强调其为使债务消灭的形式行为，并非实际收款。
