# D.32.1 论遗赠与遗嘱信托（*De legatis et fideicommissis*，第一段）

<!-- 依随附原始网页 HTML 补回篇题；题名锚点 1 在整理后的 EPUB 中未保留。 -->
<a id="1"></a>**32.0**　论遗赠与遗嘱信托（*De legatis et fideicommissis*）。

<!-- source-p 001 -->
<a id="32.1"></a>**32.1**

<!-- source-p 002 -->
**乌尔比安：《遗嘱信托论》第一卷。**

<!-- source-p 003 -->
<a id="32.1.pr."></a>**序言。**如果某人的身份尚不确定，不知他是被俘，还是被强盗围困，他就不能订立遗嘱。即使他是自权人，却不知道这一点，误以为自己因被强盗抓获、仿佛被敌人俘虏而沦为奴隶，也不能设立遗嘱信托；同样，如果某位使节（*legatus*）认为自己与俘虏无异，也不能设立遗嘱信托。〔*legatus* 此处暂译“使节”；该词亦有其他含义。〕对此可以确定，因为连能否订立遗嘱都尚有疑问的人，也不能订立遗嘱。

<!-- source-p 004 -->
<a id="32.1.1"></a>**1.**但如果家子或奴隶留下遗嘱信托，该信托无效；然而，如果他们获释后死亡，我们仍应坚持认为遗嘱信托视同在死亡时新近设立，只要获释后其意思一直持续。当然，若遗嘱本身无效，我们不会承认其中的遗嘱信托有效，因为遗嘱无效时，遗嘱中的任何内容均无效；但若某人是以其他方式留下遗嘱信托，则可另作处理。

<!-- source-p 005 -->
<a id="32.1.2"></a>**2.**被剥夺水火之权的人，以及被流放者，均不能设立遗嘱信托，因为他们不享有订立遗嘱的权利，已成为无国籍者。

<!-- source-p 006 -->
<a id="32.1.3"></a>**3.**我们所说的被流放者，是指皇帝指定其流放之岛屿，或下令将其流放的人。但在总督的决定获皇帝确认前，应认为当事人尚未丧失公民身份。因此，如果他在确认前死亡，就应视为以公民身份死亡；他在承受判决前所留下的遗嘱信托有效。即使是在判决后、皇帝确认前留下的遗嘱信托，也有效，因为在此之前他的身份仍然确定。

<!-- source-p 007 -->
<a id="32.1.4"></a>**4.**但由禁卫军长官，或受皇帝授权代行其职权者，以及城市长官下令流放的人——神圣塞维鲁皇帝和我们的皇帝曾以书信授予城市长官流放权——会立即丧失公民身份；因此，可以确定，他们既无订立遗嘱的权利，也无设立遗嘱信托的权利。

<!-- source-p 008 -->
<a id="32.1.5"></a>**5.**如果某人被流放至岛屿后在那里订立遗嘱附录，后经皇帝特赦而恢复身份，并在该遗嘱附录的意思仍然持续时死亡，可以主张遗嘱信托有效，但以其意思始终未变为限。

<!-- source-p 009 -->
<a id="32.1.6"></a>**6.**应当知道，可以将遗嘱信托托付给这样的人：立遗嘱人死亡时，某物将归其取得，无论是通过给予该物，还是通过不将该物从其处取走。

<!-- source-p 010 -->
<a id="32.1.7"></a>**7.**我们不仅可以将遗嘱信托托付给顺位最近的遗产占有人，也可以托付给较低顺位的遗产占有人。

<!-- source-p 011 -->
<a id="32.1.8"></a>**8.**也可以将遗嘱信托托付给尚未出生的人，但以其出生后将成为我们的继承人为限。

<!-- source-p 012 -->
<a id="32.1.9"></a>**9.**有一项毫无疑问的规则：某人无遗嘱死亡，将遗嘱信托托付给第一顺位可能继承其遗产的人；如果此人拒绝继承，继承顺位遂转至下一顺位，那么后一顺位继承人无须履行该遗嘱信托。我们的皇帝也曾以敕答作此规定。

<!-- source-p 013 -->
<a id="32.1.10"></a>**10.**如果遗嘱信托是由庇护人留下的，而其死亡后，庇护人的一名子女获准取得遗产占有，也应作同样判断。

<!-- source-p 014 -->
<a id="32.2"></a>**32.2**

<!-- source-p 015 -->
**盖尤斯：《遗嘱信托论》第一卷。**

<!-- source-p 016 -->
如果有儿子被遗嘱遗漏，即使该儿子属于自权继承人，也不能对其留下遗嘱信托。〔原文短句关系不明，暂按“以被遗漏之子为信托负担人”理解。〕

<!-- source-p 017 -->
<a id="32.3"></a>**32.3**

<!-- source-p 018 -->
**乌尔比安：《遗嘱信托论》第一卷。**

<!-- source-p 019 -->
<a id="32.3.pr."></a>**序言。**如果妻子曾以要式口约请求返还嫁资，后来又免除了丈夫的债务，以便由丈夫设立遗嘱信托，那么应当说遗嘱信托应予履行；因为丈夫显然从妻子处获得了某种利益。以上适用于妻子为死亡原因赠与丈夫而免除债务的情形。如果妻子为死亡原因增加给丈夫的嫁资，或者为死亡原因将嫁资重新纳入婚姻关系，也可以说丈夫应履行遗嘱信托。

<!-- source-p 020 -->
<a id="32.3.1"></a>**1.**尤利安写道：如果奴隶遗赠给我，并要求我将其解放，我不能再设立遗嘱信托；但这是指该要求并无条件而言。如果解放奴隶的要求附有条件或期限，由于我可以取得中间期间的利益，尤利安也不会怀疑我因此负有义务。

<!-- source-p 021 -->
<a id="32.3.2"></a>**2.**如果某人依据要式口约对某物负有给付义务，而该物又遗赠给此人，他就不能将该物托付给遗嘱信托；尽管受遗赠人似乎从遗赠中获得利益，因为他立即取得所有权，无须等待依要式口约提起诉讼。或许有人会说，他因此节省了若依要式口约诉讼所需承担的费用。但绝不能据此说可以将该物托付给遗嘱信托。

<!-- source-p 022 -->
<a id="32.3.3"></a>**3.**但如果我为死亡原因将用益权让与已经拥有所有权的你，可以说我能够设立遗嘱信托。不要因为用益权通常因死亡而消灭，就对此产生疑虑；我们应当考虑的是赠与人尚在人世的中间期间所产生的利益。

<!-- source-p 023 -->
<a id="32.3.4"></a>**4.**但如果我为死亡原因解除债务人的质押，并将该利益托付给遗嘱信托，那么遗嘱信托不能成立。

<!-- source-p 024 -->
<a id="32.4"></a>**32.4**

<!-- source-p 025 -->
**保罗：《判例集》第四卷。**

<!-- source-p 026 -->
父亲或主人留下遗嘱信托，而遗产未归其取得时，被解放出家父权的儿子或获释的奴隶，可以通过有益诉权请求履行；因为遗产一经取得，其利益即归他们所有。

<!-- source-p 027 -->
<a id="32.5"></a>**32.5**

<!-- source-p 028 -->
**乌尔比安：《遗嘱信托论》第一卷。**

<!-- source-p 029 -->
<a id="32.5.pr."></a>**序言。**如果遗赠给市镇团体，可以由负责公共事务的人履行遗嘱信托。

<!-- source-p 030 -->
<a id="32.5.1"></a>**1.**如果某人将遗嘱信托托付给的不是继承人或受遗赠人本人，而是该继承人或受遗赠人的继承人，宽厚地说，该遗嘱信托有效。

<!-- source-p 031 -->
<a id="32.6"></a>**32.6**

<!-- source-p 032 -->
**保罗：《遗嘱信托论》第一卷。**

<!-- source-p 033 -->
<a id="32.6.pr."></a>**序言。**如果我如此将遗嘱信托托付给自己的继承人：“卢基乌斯·提图斯，我请求你要求你的继承人向梅维乌斯给付十枚金币”（*te rogo, Luci Titi, ut ab herede tuo petas dari Maevio decem aureos*），该遗嘱信托有效；也就是说，提图斯死亡后，可以向其继承人请求给付。尤利安也作出了同样的答复。

<!-- source-p 034 -->
<a id="32.6.1"></a>**1.**遗嘱信托不得如此设立：“如果斯提库斯依塞伊乌斯的命令成为其所有，并接受遗产，我请求他给付”（*si Stichus Seii factus iussu eius hereditatem adierit, rogo det*）。因为以偶然而非立遗嘱人意思取得遗产或遗赠的人，不应因此承担负担；也不应允许某人对自己并未给予任何财产的人，仅以请求的方式施加义务。

<!-- source-p 035 -->
<a id="32.7"></a>**32.7**

<!-- source-p 036 -->
**乌尔比安：《遗嘱信托论》第一卷。**

<!-- source-p 037 -->
<a id="32.7.pr."></a>**序言。**如果遗嘱信托写给被流放者的奴隶，应当说该遗嘱信托归国库所有；但如果被流放者在立遗嘱人生前已转让该奴隶，或者被恢复身份，则遗嘱信托应归其本人所有。

<!-- source-p 038 -->
<a id="32.7.1"></a>**1.**如果军人将遗嘱信托留给被流放者，更妥当的看法是——马尔凯鲁斯也赞同此见——被流放者可以取得该遗嘱信托。

<!-- source-p 039 -->
<a id="32.7.2"></a>**2.**如果某人将自己所欠债务遗赠给债权人，不能将该利益托付给该债权人的诚信履行；除非债权人从遗赠中取得某种利益，例如因担心抗辩而获益，或者债务尚未到期，或附有条件。

<!-- source-p 040 -->
<a id="32.8"></a>**32.8**

<!-- source-p 041 -->
**保罗：《遗嘱信托论》第一卷。**

<!-- source-p 042 -->
<a id="32.8.pr."></a>**序言。**如果受遗赠人负有履行遗嘱信托的义务，却向继承人请求遗赠，那么他只须将其经由法官判决实际取得的部分交给遗嘱信托受益人；若尚未请求给付，则应将诉权让与受益人。若诉讼并非因受遗赠人的过失而败诉，却让其承担诉讼风险，是不公平的。

<!-- source-p 043 -->
<a id="32.8.1"></a>**1.**不得有效地将遗嘱信托托付给继承人的奴隶，除非委托该奴隶的诚信，使其解放奴隶。

<!-- source-p 044 -->
<a id="32.8.2"></a>**2.**立遗嘱人请求：凡其财产中归父亲取得的部分，均应由父亲返还给女儿，使女儿所得超过她原本可从父亲财产中取得的份额。神圣庇护皇帝以敕答规定，显然立遗嘱人所指的是父亲死亡之后的情形。

<!-- source-p 045 -->
<a id="32.9"></a>**32.9**

<!-- source-p 046 -->
**麦基安努斯：《遗嘱信托论》第一卷。**

<!-- source-p 047 -->
如果遗嘱信托如此留下：“给任何依据我的遗嘱或无遗嘱继承而取得遗产的人”（*ad quemcumque ex testamento meo vel ab intestato*），或者“给任何以任何法律途径取得我财产的人”（*ad quemcumque quoquo iure bona mea perveniant*），那么这些措辞也包括此后出生或进入家族的人，以及此后才成为亲属的人；也包括尚未结婚、但后来在丈夫无遗嘱死亡时依告示通常取得其财产的妻子。

<!-- source-p 048 -->
<a id="32.10"></a>**32.10**

<!-- source-p 049 -->
**瓦伦斯：《遗嘱信托论》第二卷。**

<!-- source-p 050 -->
如果我将一百枚金币遗赠给你，并将该遗赠也给予我三个儿子中参加我葬礼的那一人，那么即使无人参加葬礼，你所得的遗赠也不减少。

<!-- source-p 051 -->
<a id="32.11"></a>**32.11**

<!-- source-p 052 -->
**乌尔比安：《遗嘱信托论》第二卷。**

<!-- source-p 053 -->
<a id="32.11.pr."></a>**序言。**遗嘱信托可以用任何语言设立，不仅可以用拉丁语或希腊语，也可以用布匿语、加利亚语或其他任何民族的语言。

<!-- source-p 054 -->
<a id="32.11.1"></a>**1.**如果某人准备了一份遗嘱草案，却在正式订立遗嘱前死亡，草案中所写的内容不会像遗嘱附录那样有效，即使文书中包含设立遗嘱信托的措辞。麦基安努斯写道，神圣庇护皇帝曾作出同样裁决。

<!-- source-p 055 -->
<a id="32.11.2"></a>**2.**如果某人写道：“我将此人托付给你”（*Illum tibi commendo*），神圣庇护皇帝以敕答规定，不负有遗嘱信托义务；因为托付某人，与将遗嘱信托人的意思告知继承人，是两回事。

<!-- source-p 056 -->
<a id="32.11.3"></a>**3.**某人被请求在收取确定数额后返还遗产份额，有答复认为，他可以直接向继承人请求遗嘱信托。但他是否愿意接受该确定数额而返还份额，还是即使不愿也必须在收取该数额后被迫返还份额，则属于其自行决定的事项。确实，如果某人被请求在收取确定数额后返还一份遗产，就有两项遗嘱信托：一项是使其可以请求该数额，并准备交出该份额；另一项是即使其不请求该数额，只要受益人准备给付该数额，他仍必须被迫返还份额。

<!-- source-p 057 -->
<a id="32.11.4"></a>**4.**如果某人写道：“葡萄园或土地对你已经足够”（*sufficiunt tibi vineae vel fundus*），这构成遗嘱信托；因为我们也认为，下列表述构成遗嘱信托：“你就满足于那件物品吧”（*contentus esto illa re*）。

<!-- source-p 058 -->
<a id="32.11.5"></a>**5.**如果遗嘱信托如此留下：“除非我的继承人不愿意，否则我希望将十枚金币给他”（*nisi heres meus noluerit, illi decem dari volo*），这是一项附条件的遗嘱信托，要求首先确定继承人的意思；因此，继承人一旦表明最初的意思，就不能再称自己不愿意。

<!-- source-p 059 -->
<a id="32.11.6"></a>**6.**“在他愿意时”（*cum voluerit*）这一表述，效力持续至留下遗嘱信托的人死亡为止。但如果该人尚未给付便死亡，应由其继承人履行。反之，如果遗嘱信托受益人在继承人作出选择之前死亡，似乎没有任何权利移转给其继承人。因为毫无疑问，这是一项附条件的遗赠；遗赠条件尚未成就时，受益人即已死亡。

<!-- source-p 060 -->
<a id="32.11.7"></a>**7.**虽然如此留下的遗嘱信托——“如果你愿意”（*si volueris*）——并不负有给付义务，但如果附加了“如果你认为合适”（*si fueris arbitratus*）、“如果你判断”（*si putaveris*）、“如果你评估”（*si aestimaveris*）、“如果你认为有用”或“如果看起来有用”（*si utile tibi fuerit visum / videbitur*）等措辞，则应当给付；因为这并未将完全的意思裁量权交给继承人，而是仿佛将事项托付给善良之人判断。

<!-- source-p 061 -->
<a id="32.11.8"></a>**8.**因此，如果遗嘱信托如此留下：“给他，但以他值得你给付为条件”（*illi, si te meruerit*），只要受益人可以像善良之人那样判断其是否值得，就应当给付。如果写的是“只要他没有冒犯你”（*si te non offenderit*），也同样应当给付；即使继承人能够主张此人不值得，但其他善良且不怀敌意的人会认定其值得，继承人也不能据此抗辩。

<!-- source-p 062 -->
<a id="32.11.9"></a>**9.**“儿子，我请求你凭着自己的勤勉，珍爱归你所有的地产并照料它们，使其能够传给你的儿子”（*te, fili, rogo, ut praedia, quae ad te pervenerint, pro tua diligentia diligas et curam eorum agas, ut possint ad filios tuos pervenire*）。这些话虽然没有充分表达遗嘱信托，更像是建议而非留下强制义务，但在儿子的父亲死亡后，这些地产仍似乎包含了以遗嘱信托方式传给孙辈的效力。

<!-- source-p 063 -->
<a id="32.11.10"></a>**10.**如果父亲指定儿子为继承人，并留下遗嘱信托，即使没有明确写作“父亲死亡时”（*cum pater moreretur*），但可以从“使其传给儿子”（*ut relinquat filio*）、“我希望他取得”（*volo eum habere*）或“我希望归他所有”（*volo ad eum pertinere*）等措辞中推知这一点，也应解释为在儿子成为自权人时履行遗嘱信托。

<!-- source-p 064 -->
<a id="32.11.11"></a>**11.**如果遗嘱信托如此留下：“如果他在父亲死亡时成为自权人”（*si morte patris sui iuris fuerit effectus*），儿子后来通过解放而成为自权人，也不应认为条件未成就；父亲死亡时，应视为条件已经成就，并准许其请求遗嘱信托。

<!-- source-p 065 -->
<a id="32.11.12"></a>**12.**如果立遗嘱人将自己的物遗赠，后来因迫不得已而将其让与他人，仍可请求遗嘱信托，除非能够证明立遗嘱人意在撤回遗赠。继承人应对立遗嘱人改变意思承担举证责任。

<!-- source-p 066 -->
<a id="32.11.13"></a>**13.**因此，如果某人收取了以遗嘱信托方式留下的债权，且其意思并非要消灭遗嘱信托，也可以说该信托仍应履行；除非有人认为二者有所不同：在前一种情形中，债务关系本身消灭；在后一种情形中，物虽已让与他人，仍然存在。但如果某人收取了债务人的债权，并将所得钱款作为寄托保管，我认为仍可请求遗嘱信托，尤其因为并非他主动收取，而是债务人主动提出付款；既然债务人主动给付，他便不能不予接受。因此，我们将逐步承认：即使他用这笔钱购买了某物，只要收取钱款并非为了剥夺受益人的遗嘱信托，仍可继续请求履行该遗嘱信托。

<!-- source-p 067 -->
<a id="32.11.14"></a>**14.**如果某人违法建造了建筑物，也就是建造了依皇帝敕令必须拆除的建筑物，问题是他能否就该建筑物设立遗嘱信托。我认为可以；既然该建筑物必须拆除，元老院决议就显然不会构成障碍。

<!-- source-p 068 -->
<a id="32.11.15"></a>**15.**如果继承人被请求以确定利率贷出确定数额的钱款，该遗嘱信托有效。但麦基安努斯认为，除非向继承人提供充分担保，否则不得强迫其放贷；我则更倾向于认为，不应要求提供担保。

<!-- source-p 069 -->
<a id="32.11.16"></a>**16.**如果他人所有的奴隶被遗赠以从军，问题是该遗赠是否归奴隶的主人取得。如果立遗嘱人知道他是奴隶，我认为应给付其估价；如果立遗嘱人不知道，就应拒绝受益人提起遗嘱信托之诉，因为如果立遗嘱人知道他是奴隶，就不会作出该遗赠。

<!-- source-p 070 -->
<a id="32.11.17"></a>**17.**由此可见，以遗嘱信托留下某物时，原则上应当给付所留下的该物；但如果不能给付该物，则应给付其估价。

<!-- source-p 071 -->
<a id="32.11.18"></a>**18.**如果某人以遗嘱信托留给某人十枚金币，并规定在遗嘱留下的钱款灭失时再次补给该人，就会产生疑问：后一个遗嘱信托是否有效；继承人是否应要求受益人提供担保，保证十枚金币仍会留存，从而避免被迫给付；如果受益人数次丢失钱款，是否也应数次补给。神圣庇护皇帝以敕答规定，不得要求担保；遗嘱信托只须在钱款丢失后再给付一次。继承人不应承担无限负担，以致受益人每次丢失钱款都必须再次给付同额；后一个遗嘱信托只是使遗赠的数额加倍。此后，若受益人在收到后一个遗嘱信托的给付后又将钱款花掉，继承人不再承担风险。

<!-- source-p 072 -->
<a id="32.11.19"></a>**19.**同样，如果某人留给他人确定数额，并补充说这笔钱可较容易地用于抵销遗产债务，而遗嘱信托受益人因盖乌斯·塞伊乌斯的遗产而成为债务人，且此人不愿接受盖乌斯·塞伊乌斯的遗产、却请求遗嘱信托，我主皇帝以敕答规定，即使这违背立遗嘱人的意思，他仍可请求遗嘱信托；因为在遗嘱信托中，尤其应当考察并遵守立遗嘱人的意思。〔原文此处 *contra voluntatem* 与下文所述应遵守立遗嘱人意思的关系不明，暂依文字直译。〕

<!-- source-p 073 -->
<a id="32.11.20"></a>**20.**常有这种情形：所留下之物关系到许多人的利益，但立遗嘱人却只想优待其中一人。马尔凯鲁斯的这一见解极为正确。

<!-- source-p 074 -->
<a id="32.11.21"></a>**21.**因此，有时立遗嘱人想优待数人，也确实考虑到数人的利益；尽管只设立了一项遗赠，仍准许数人请求履行。例如，十人对同一物享有要式口约债权，而继承人或遗嘱信托受益人被请求向他们给付：如果他们全都具有利害关系，且立遗嘱人考虑到了每一个人，那么他们都可以请求遗嘱信托。但他们应按份额还是可以请求全部，我们还须考察。我认为，他们应按各自的利害关系取得给付。因此，先行起诉的一人可以取得全部，但须提供担保，保证向其给付的人将免受其他遗嘱信托受益人的追索，无论他们是否属于共同债权人。

<!-- source-p 075 -->
<a id="32.11.22"></a>**22.**有时遗嘱中写明一人的姓名，但遗嘱信托请求权或遗赠请求权属于另一人。例如，继承人受托代提图斯缴纳公税；此时，公税承包人虽在遗嘱中被写明，却无权请求该遗嘱信托或遗赠；能够请求的是立遗嘱人意在使其受益的人。我认为，关键在于立遗嘱人希望为谁提供利益、是着眼于谁的利益而作出安排。通常应当理解为立遗嘱人是为了私人利益作此安排，即使公税承包人也会因此受益。

<!-- source-p 076 -->
<a id="32.11.23"></a>**23.**如果遗留某物用于建造城市公共工程，神圣马尔库斯皇帝和卢基乌斯·维鲁斯皇帝以敕答规定，每名继承人均对全部给付负有义务。但他们给予共同继承人一段期限，要求其在期限内将应有份额交付用于工程；期限届满后，普罗库拉可以就其共同继承人应承担的份额向其追偿。

<!-- source-p 077 -->
<a id="32.11.24"></a>**24.**神圣马尔库斯皇帝以敕答规定，雕像、地役权及其他不能分割之物，也适用同一规则。

<!-- source-p 078 -->
<a id="32.11.25"></a>**25.**如果某人被命令完成一项工程，却愿意给公共团体钱款让其自行施工，而立遗嘱人的意思是让他亲自完成工程，则不得允许这种做法。神圣马尔库斯皇帝曾以敕答作此规定。
