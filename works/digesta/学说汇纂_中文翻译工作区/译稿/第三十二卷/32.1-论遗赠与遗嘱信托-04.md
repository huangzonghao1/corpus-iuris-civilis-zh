<a id="32.78"></a>
### 32.78

<!-- source-p 405 -->
保罗《评维特利乌斯论》第二卷

<!-- source-p 406 -->
<a id="32.78.pr."></a>
**序言**　有人询问：斯提库斯奴隶在立遗嘱人死亡前一年被从某庄园带走并送去学习，此后未返回该庄园，是否仍应交付？答复是：若送他去是为了学习，而非意在将他从庄园转移到别处，则仍应交付。

<!-- source-p 407 -->
<a id="32.78.1"></a>
**1**　有人如此写信给儿子梅维乌斯：“儿子，因为我已将大部分财产给了你，你应当满足于塞姆普罗尼乌斯庄园，以及居住于其上的人，即家内奴隶和其他现存之物。”有人询问这是否包括债务人的债权凭证和钱币。死者又曾寄出如下信件：“我将所有银器和家具，以及我所拥有的一切，都赠与你；我在塞姆普罗尼乌斯庄园拥有的任何财物，也一并给你。”若家具在其他庄园或房屋中，是否属于梅维乌斯？立遗嘱人又将该庄园的奴隶遗赠给他人，这些奴隶是否也属其遗赠？答复是：除非能够明确证明死者也有意遗赠这些债权和钱币，否则不应认为它们包括在内。将同一庄园中的奴隶另行遗赠给他人，会减少儿子所得的遗赠。至于在别处的银器和家具，应由审理者判断；若受遗赠人能够证明立遗嘱人意在使其取得这些物品，就应判其取得。

<!-- source-p 408 -->
<a id="32.78.2"></a>
**2**　某人遗赠庄园时附加如下文字：“如同由我占有时那样，以及我死亡时其中的一切。”有人询问，在这些庄园中因农务或其他职务而居留的奴隶，以及死亡当日仍在那里的其他物品，是否属于受遗赠人。答复说，问题中提到的这些物品均视为已被遗赠。

<!-- source-p 409 -->
<a id="32.78.3"></a>
**3**　有人写道：“我请求将我的坎帕尼亚庄园按其现状登记给我的养女革涅西亚，价值二百奥里。”有人询问，庄园是否连同佃户所欠的款项，以及死亡时在庄园中的奴隶一并给付。答复是：佃户所欠款项并未遗赠；其他物品则视为包含在“按其现状”（ita uti est）一语之中。

<!-- source-p 410 -->
<a id="32.78.4"></a>
**4**　或有人会问：为何遗赠“银”也包括已经制成的银器，而若遗赠大理石，似乎只能指未加工的原料？对此流传着如下解释：某些物质的性质使其能够一再还原为原始形态；它们一旦受物质本性之力支配，就无法摆脱这种力量。

<!-- source-p 411 -->
<a id="32.78.5"></a>
**5**　无人怀疑，以专名称为“胭脂红”（coccum）的物品也包含在各种有色物品之中。那么，黑色颜料（coracinum）、红紫色颜料（hysginum）或蜜黄色颜料（melinum），难道不也像胭脂红或紫色染料一样，能够以自己的专名加以指称吗？〔色料名称的具体对应译法尚待术语审校。〕

<!-- source-p 412 -->
<a id="32.78.6"></a>
**6**　某男子遗赠时写道：“凡为我妻子而备置的物品，我都给付并遗赠给她。”我曾向遗嘱信托裁判官请求将已估价、且其价款已作为嫁资交付的物品也判归妻子，却未获支持，理由是立遗嘱人似乎未考虑这些物品。然而，若这些物品已交由妻子使用，则其究竟是妻子本人还是他人购得，并无区别。后来我在阿布尔尼乌斯·瓦伦斯的著作中见到类似案件：妻子将已估价的物品作为嫁资交付，丈夫随后以如下文字将其遗赠给她：“凡为她而购置或备置的物品。”他认为，“购置或备置”一语不包括作为嫁资交付的物品，除非丈夫在这些物品归其所有后，又将其转用于妻子的用途。

<!-- source-p 413 -->
<a id="32.78.7"></a>
**7**　遗赠庄园内的物品时，若某些物品通常属于该庄园，即使它们当时不在庄园内，也包括在遗赠中；但偶然在那里出现的物品，不视为已被遗赠。

### 32.79

<!-- source-p 415 -->
塞尔苏斯《学说汇纂》第九卷

<!-- source-p 416 -->
<a id="32.79.pr."></a>
**序言**　遗赠一个合唱团或一组家内奴隶，应视为遗赠了其中每一个人。

<!-- source-p 417 -->
<a id="32.79.1"></a>
**1**　若遗赠写道：“我在该处的动产，均给付并遗赠”，普罗库鲁斯说，存放在那里准备借出的金钱不属于遗赠；但若有些钱如内战期间有人所为那样，作为储备而存放，则属于遗赠。据说他曾听乡村老人这样说：没有备用金的钱财是脆弱的；他们把为防备之用而存放的钱称作备用金（peculium）。

<!-- source-p 418 -->
<a id="32.79.2"></a>
**2**　若遗赠一块空地，该地一度在中间建有建筑，后来又恢复为空地，尽管在建筑尚存时无法请求交付，如今仍应交付。

<!-- source-p 419 -->
<a id="32.79.3"></a>
**3**　遗赠的奴隶若在此期间被释放，后来又重新成为奴隶，也可以请求交付。

<a id="32.85"></a>
### 32.85

<!-- source-p 442 -->
庞波尼《评昆图斯·穆基乌斯论》第二卷

<!-- source-p 443 -->
**序言**　元首曾规定，即使遗嘱人没有加上“我的”（meum）一词，只要他遗赠某一特定物，并且意思显然是仅在该物属于自己时才给付，遗赠仍然有效；应以遗嘱人的意思为准，而非拘泥于“我的”一词。因此，恰当的区分是：遗赠特定物时，“我的”一词即使指向当前状态，也不构成条件；若遗赠的是不特定物，例如“我的酒”（vina mea）或“我的衣服”（vestem meam），“我的”一词似乎就构成条件，只有属于立遗嘱人的物品才视为被遗赠。我认为这一说法不易有力地成立；更妥当的看法是，属于立遗嘱人财产范围的衣服或酒也属于遗赠。正如曾有答复所说，即使葡萄酒已经变酸，只要立遗嘱人仍将其列在酒类中，也包括在遗赠内。当然，我认为，若遗嘱写作“我死亡时属于我的衣服”（vestem, quae mea erit），其中明确指向死亡时的文字，应当作为条件理解；我也认为“届时属于我的斯提库斯”（Stichum qui meus erit）属于条件，不论写作“届时属于我的”（qui meus erit）还是“如果属于我的”（si meus erit），两种写法中的这一部分都是条件。不过，拉贝奥写道，即便“届时属于我的”指向未来，也应理解为对标的物的说明；但我们采用不同的规则。

<!-- source-p 444 -->

<a id="32.89"></a>
### 32.89

<!-- source-p 457 -->
保罗《评尤利亚法与帕皮亚法》第六卷

<!-- source-p 458 -->
若同一物分别遗赠给二人，则是标的物本身共同遗赠，而非遗嘱措辞上的共同遗赠。反之，若写道“我将庄园平分给提图斯和塞尤斯”，则只是措辞上共同遗赠，而非标的物本身共同遗赠，因为受遗赠人始终各有份额。因此，兼具标的物与措辞共同性的受遗赠人，无论如何都优先于其他人；若只在标的物上共同，则不享有优先权；若只在措辞上共同，是否享有优先权尚有疑问，较妥当的看法是该受遗赠人也应优先。

### 32.91

<!-- source-p 463 -->
帕比尼安《答复集》第七卷

<!-- source-p 464 -->
<a id="32.91.pr."></a>
**序言**　若庄园通过先行取得的方式给付给女儿，连同管理人和佃户的账目余额一并交付，则凡仍与庄园收益相关的余额，均视为已遗赠。否则，很容易认定：从佃户处收取并在同一地区账簿中作为借款记载的钱款，不属于佃户或管理人的余额，即使立遗嘱人明确希望管理人归女儿所有也是如此。

<!-- source-p 465 -->
<a id="32.91.1"></a>
**1**　遗嘱写道：“我将这些庄园连同宅邸一并给卢基乌斯·提图斯，如同我在死亡之日占有它们时那样。”通常应认为，庄园农具以及一切使庄园主人能够充分经营庄园的物品都应给付；佃户所欠的余额则不包括在内。

<!-- source-p 466 -->
<a id="32.91.2"></a>
**2**　父亲将一家紫色染料铺遗赠给儿子，连同店内奴隶、店员，以及父亲死亡时仍在店里的紫色染料。但已封存的紫色染料价款、欠款和账目余额，不属于遗赠。

<!-- source-p 467 -->
<a id="32.91.3"></a>
**3**　遗嘱写道：“我将塞尤斯庄园按购置时的状态给付并遗赠。”另有一处加比尼乌斯庄园也与之同时以一个价款购得。我答复说，仅凭共同购买这一事实不足以证明两处庄园都包含在内；还应查明账簿和记录是否将加比尼乌斯庄园也列入“塞尤斯庄园”之名下，以及两处庄园的收益是否混合记账，并一并记入塞尤斯庄园的收入。〔底本句末有疑似拼接文字 “accepto lati essententiarum”。〕

<!-- source-p 468 -->
<a id="32.91.4"></a>
**4**　通常可以确定，浴场属于遗赠房屋的一部分。但若浴场向公众开放，只有在其也能从房屋内部进入、家父或其妻有时使用、其收入与房屋其他收益一同记账，且浴场与房屋以一个价款共同购置或配置时，才可认为浴场属于该房屋。〔底本句末有疑似拼接文字 “fuissententiarum”。〕

<!-- source-p 469 -->
<a id="32.91.5"></a>
**5**　某房屋的占有人买下紧邻房屋的花园，随后遗赠房屋。若他为房屋之用而购买花园，使房屋更宜人、更健康；并且能够从房屋进入花园，花园因此成为房屋的附属部分，则该花园包括在房屋遗赠之中。

<!-- source-p 470 -->
<a id="32.91.6"></a>
**6**　若公寓楼与房屋以一个价款一并购得，且二者的租金同样记在一处账目中，则“房屋”一词也应视为包括与其相连的公寓楼。

### 32.93

<!-- source-p 477 -->
<a id="32.93.pr."></a>
**序言**　卢基乌斯·提图斯在遗嘱中规定，不得以任何方式出售其郊区别墅或房屋。他指定女儿为继承人；女儿又指定自己的女儿为继承人。孙女长期占有这些财产，临终时却指定家族外之人为继承人。有人询问，这些庄园是否应归属于尤利娅——她视立遗嘱人卢基乌斯·提图斯为其族叔祖父。答复说，没有事实显示发生了违反死者意思的情形，因此这些财产应归继承人所有，因为上述内容只是一个空洞的命令。

<!-- source-p 478 -->
<a id="32.93.1"></a>
**1**　遗嘱如此写道：“我命令我的继承人向我的妻子塞姆普罗尼娅返还一百奥里，这是我向她借的。”有人询问，若塞姆普罗尼娅以债务为由请求该款而败诉，是否仍可基于遗嘱信托请求给付。答复说，依所述情形，可以基于遗嘱信托请求；因为已经表明该款并非因其他原因而成为债务。

<!-- source-p 479 -->
<a id="32.93.2"></a>
**2**　某人将庄园遗赠给被释自由人，并附加如下文字：“如同我占有时那样，以及我死亡时其中的一切。”有人询问，因农务或其他职务而居留在这些庄园中的奴隶，以及当时在庄园内的其他物品，是否属于受遗赠人。答复说，属于。

<!-- source-p 480 -->
<a id="32.93.3"></a>
**3**　有人询问，继承人受托向兄弟返还的财产是否也应归姐妹。答复说，应当归姐妹，除非能够证明立遗嘱人另有意思。

<!-- source-p 481 -->
<a id="32.93.4"></a>
**4**　某人将一处庄园连同通常附属于该庄园的树林，按其最佳、最大状态遗赠给工匠公会。有人询问，立遗嘱人死亡时在那里的一切——即干草、饲料、秸秆、机器、酒器（即固定在酒窖中的大桶和酒瓮）以及粮仓——是否也属于遗赠。答复说，对未曾遗赠之物提出请求，并无正当理由。〔底本在“是否已被遗赠”一语处有拼接疑误，原文作 “legata essententiarum”。〕

<!-- source-p 482 -->
<a id="32.93.5"></a>
**5**　一名取得遗产二分之一份额的继承人通过先行取得的方式获遗赠一处庄园，立遗嘱人并请求他：“我请求你，愿意接纳你的共同继承人克洛狄乌斯——我真正的孙子、你的亲属——加入我那处尤利乌斯庄园；我还命令你另外接纳他。”有人询问，是否应基于遗嘱信托向孙子给付庄园的一部分。答复说，应当给付。

<!-- source-p 483 -->
<a id="32.94"></a>
### 32.94

<!-- source-p 484 -->
瓦伦斯《遗嘱信托论》第二卷

<!-- source-p 485 -->
某人留下数名被释自由人，将一处庄园遗赠给其中三人，并请求他们确保该庄园不脱离其家名或家族名下。〔原文 ne de nomine suo exiret 的指向有歧义。〕有人询问，三人中首先死亡者是否应将自己的份额留给与其共同受遗赠的另一人或二人，还是可以留给其他共同被释自由人。尽管这取决于立遗嘱人的意思，通说认为，即使他将份额留给其他共同被释自由人，也算履行了义务。若他没有留给任何人，则不清楚应由先占者取得，还是所有共同被释自由人，抑或仅原先共同受遗赠之人请求遗嘱信托。尤利安正确地认为，所有人均有权请求。

<!-- source-p 486 -->
<a id="32.95"></a>
### 32.95

<!-- source-p 487 -->
梅基安《遗嘱信托论》第二卷

<!-- source-p 488 -->
**序言**　遗嘱写道：“凡成为我继承人的，应给付并受托其信义：给付我已指示或交付的所有款项。”阿里斯托认为，这也包括有体物，例如庄园、奴隶、衣物和银器。由嫁资返还以及买卖遗产的要式口约可见，“所有款项”（quantas summas）一语并非仅指现钱；“数额”（summae）一词也应作同样理解，所举的这些依据足以证明这一点。此外，遗嘱信托尤其应尊重死者的意思，这一原则也支持此说：若立遗嘱人只想给付现钱，就不会在上述引言之后再增列有体物。

<!-- source-p 489 -->
<a id="32.96"></a>
### 32.96

<!-- source-p 490 -->
盖尤斯《遗嘱信托论》第二卷

<!-- source-p 491 -->
若提图斯作为部分继承人受托向梅维乌斯返还遗产，而提图斯的共同继承人又受托向提图斯返还自己的份额或其一部分，那么提图斯是否也应将其从共同继承人处基于遗嘱信托取得的这一部分返还给梅维乌斯？神圣的安敦尼皇帝受询后以敕答答复说，无须返还，因为“遗产”一词不包括遗赠或遗嘱信托。

<!-- source-p 492 -->
<a id="32.97"></a>
### 32.97

<!-- source-p 493 -->
保罗《裁决集》第二卷

<!-- source-p 494 -->
有人名为霍西狄乌斯，指定女儿瓦莱里娅娜为继承人，释放了自己的管事奴隶安提奥库斯，并将特定庄园、特有产及各项账目余额遗赠给他；这些余额既包括霍西狄乌斯自己的，也包括佃户的。受遗赠人出示了家父亲笔记录的账目，记载着属于他本人及佃户的余额；同一份文书还写道：“以及他应当交账的一切”，即家父存放在仓库中的谷物、葡萄酒和其他物品。获释奴隶也请求这些物品，并主张它们属于账目余额；他在行省总督面前胜诉。相反一方主张，既然佃户的余额并非向安提奥库斯请求，且也不是他自己的财物，那么存放在仓库中的物品就应区别处理。皇帝询问受遗赠人一方：“姑且假设仓库中有一百奥里，通常供日常支用；你会说仓库里留下的全部钱都应给付吗？”法庭认可其主张有理。受遗赠人一方又指出，有些款项是在家父死亡后才从佃户处收取的。答复说，死亡后收取的款项应返还给受遗赠人。

<!-- source-p 495 -->
<a id="32.98"></a>
### 32.98

<!-- source-p 496 -->
保罗《遗嘱形式论》单卷

<!-- source-p 497 -->
若继承人有多个顺位，遗嘱写道“我的继承人应给付”，该措辞适用于所有顺位，正如“凡成为我的继承人者”一语一样。因此，若立遗嘱人不愿所有继承人都负担遗赠给付义务，而只想让其中一些人承担，就必须指名指定他们。

<!-- source-p 498 -->
<a id="32.99"></a>
### 32.99

<!-- source-p 499 -->
保罗《文书含义论》单卷

<!-- source-p 500 -->
<a id="32.99.pr."></a>
**序言**　若遗赠城市奴隶，有人按其工作而非所在地来区分城市奴隶：即使奴隶住在乡村庄园，只要不从事农务，也被视为城市奴隶。但应当认为，家父平时列入城市奴隶名册的人才属于城市奴隶；这尤其可以从家内奴隶名册以及口粮记录中查明。

<!-- source-p 501 -->
<a id="32.99.1"></a>
**1**　猎人和捕鸟人究竟应归入城市奴隶还是乡村奴隶，可能有疑问；但应认为，他们属于家父居住并供养他们之处的奴隶。

<!-- source-p 502 -->
<a id="32.99.2"></a>
**2**　车夫属于城市事务奴隶，除非立遗嘱人指定他们从事乡村劳作。

<!-- source-p 503 -->
<a id="32.99.3"></a>
**3**　某奴隶出生于城市女奴，后被送到别墅抚养。有人认为，在此期间他既不属于城市奴隶，也不属于乡村奴隶；但应当考察他是否仍应视为城市奴隶，这种看法更为可取。

<!-- source-p 504 -->
<a id="32.99.4"></a>
**4**　若遗赠的是抬轿奴隶，而其中一人同时也是厨师，该厨师也包括在遗赠之中。

<!-- source-p 505 -->
<a id="32.99.5"></a>
**5**　若一部分遗赠给家生奴隶，另一部分遗赠给信使奴隶，而有人同时属于家生奴隶和信使奴隶，则其归于信使奴隶一类；因为具体类别优先于一般类别。若某奴隶在两项遗赠中均按同一类别被指明——均属具体类别或均属一般类别——通常由相关受遗赠人共同取得。

<!-- source-p 506 -->
<a id="32.100"></a>
### 32.100

<!-- source-p 507 -->
雅沃雷努斯《拉贝奥遗著》第二卷

<!-- source-p 508 -->
<a id="32.100.pr."></a>
**序言**　遗嘱写道：“我的继承人必须将我的奴隶斯提库斯交还给卢基乌斯·提图斯”（Heres meus damnas esto Lucio Titio Stichum servum meum reddere），或写道：“将那名奴隶交还给他”（Illum servum meum illi reddito）。卡斯切利乌斯说，继承人应当交付；拉贝奥也不反对，因为受命“交还”也意味着受命“给付”。

<!-- source-p 509 -->
<a id="32.100.1"></a>
**1**　某人指名将两尊大理石雕像遗赠给一人，此外又概括遗赠了所有大理石。卡斯切利乌斯认为，除那两尊外，不应再给付其他大理石雕像；奥菲利乌斯和特雷巴提乌斯则持相反意见。拉贝奥赞同卡斯切利乌斯的见解；我认为此说正确，因为立遗嘱人具体遗赠两尊雕像，可能说明他并不认为自己的“大理石”遗赠还包括雕像。

<!-- source-p 510 -->
<a id="32.100.2"></a>
**2**　遗嘱写道：“我将妻子的衣物、全部女性用品、饰品、金银，以及所有为她制作或备置之物，给付并遗赠给她。”特雷巴提乌斯认为，“为她制作或备置之物”仅指金银；普罗库鲁斯认为该语适用于全部物品，此说正确。

<!-- source-p 511 -->
<a id="32.100.3"></a>
**3**　特雷巴提乌斯答复说，若有人遗赠科林斯式器皿，也应给付为安放这些器皿而备置的底座（en baseis）。但若立遗嘱人将这些底座计入器皿数量，拉贝奥不赞同此说。普罗库鲁斯则正确指出，若底座是青铜制而非科林斯式的，就不应给付。

<!-- source-p 512 -->
<a id="32.100.4"></a>
**4**　拉贝奥和特雷巴提乌斯答复说，若遗赠龟甲制品，也应给付龟甲镶面、足部镀银的床；此说正确。

<!-- source-p 513 -->
<a id="32.101"></a>
### 32.101

<!-- source-p 514 -->
斯凯沃拉《学说汇纂》第十六卷

<!-- source-p 515 -->
<a id="32.101.pr."></a>
**序言**　某人在自己出生的行省拥有自有庄园，此外还因债务取得其他土地作为质押；他在附录遗嘱中写道：

> Ty glukutaty mou patridi boulomai eis ta mery autys dovynai aforizw auty xwria panta, hosa en suria kektymai, sun pasin tois enousin boskymasin doulois karpois apovetois kataskeuais pasais
>
> [Patriae meae mihi carissimae volo pro eius parte dari eique destino quaecumque possideo in Syria cum omnibus quae in iis sunt gregibus servis fructibus apothecis instrumentis]

意为：“我最亲爱的祖国，我愿将我在叙利亚拥有的所有土地划归你，并指定归你所有，连同其中的一切，即畜群、奴隶、孳息、仓储处及全部设备。”有人询问，立遗嘱人是否也将其作为质押持有的土地遗赠给祖国。答复说，依所述情形，不应认为这些土地也被遗赠，除非它们已转入立遗嘱人的自有财产——这通常发生于债务人不履行债务时。

<!-- source-p 516 -->
<a id="32.101.1"></a>
**1**　有人写道：“我请求将我的庄园按其现状交给我的养女。”有人询问，庄园是否连同佃户所欠的余额，以及立遗嘱人死亡时仍在庄园里的奴隶一并给付。答复说，佃户所欠余额不属于遗赠；其他物品则视为包括在“按其现状”（ita uti est）一语之中。

<!-- source-p 517 -->
<a id="32.102"></a>
### 32.102

<!-- source-p 518 -->
斯凯沃拉《学说汇纂》第十七卷

<!-- source-p 519 -->
<a id="32.102.pr."></a>
**序言**　遗嘱以如下文字遗赠给妻子：“我的旅行侧箱，以及其中所存放的一切，凡载于我亲笔书写的小纸片上的物品，只要我死亡时尚未收回，即使已记入我的账簿，且我已将债务凭证交给管事，也一并遗赠。”此人准备进城时，将债务人的借据和钱币放进侧箱；在收回借据并花掉钱款后，他返回家乡。两年后，他又将后来购置的庄园的其他借据和钱币放入侧箱。有人询问，这是否意味着他仅遗赠返乡后放入同一侧箱的债权。答复说，依所述情形，死亡时仍在侧箱中且记载于其亲笔纸片上的财物，应予给付。又有人询问，庄园买卖文书既存放在同一侧箱中，庄园是否也包括在遗赠内。答复说，立遗嘱人对庄园的意思并不十分明确；但若他将买卖文书放在那里，是为了在将文书给受遗赠人时一并使其取得庄园所有权，则可以主张庄园也应给付。

<!-- source-p 520 -->
<a id="32.102.1"></a>
**1**　一位家父如此遗赠：“我希望给付两只轻便的盘子，正是我在西吉拉里亚节（sigillaria）期间买的那两只。”他在西吉拉里亚节期间并未买过轻便盘子，但确实买过盘子；并且他在死前三日口授遗嘱。有人询问，他买下并持有的那两只节庆盘子是否属于遗赠，因为他没有买过其他节庆用品，也没有遗赠其他物品。答复说，依所述情形，应当给付他在节庆期间买下的那两只盘子。

<!-- source-p 521 -->
<a id="32.102.2"></a>
**2**　立遗嘱人以如下措辞将军职或军役遗赠给其养子：“给我的养子塞姆普罗尼乌斯某物某物；并且待其年龄许可时，我希望为他购得该军职及其入职资格；一切条件均应完整。”有人询问，若塞姆普罗尼乌斯自行购得该军职，能否基于遗嘱信托向继承人请求其价款，以及通常为取得入职资格所支付的费用。答复说，依所述情形，可以请求。

<!-- source-p 522 -->
<a id="32.102.3"></a>
**3**　同一立遗嘱人以如下措辞将军职遗赠给其被释自由人：“我将某军职给付并遗赠给我的被释自由人塞尤斯。”立遗嘱人自己也曾任该军职。有人询问，继承人是否须给付取得军职的一切费用及入职费。答复说，应当给付。

<!-- source-p 523 -->
<a id="32.103"></a>
### 32.103

<!-- source-p 524 -->
斯凯沃拉《公开讨论疑问集》单卷

<!-- source-p 525 -->
<a id="32.103.pr."></a>
**序言**　若父亲排除儿子的继承资格，并为其指定一名家族外的替补继承人；该家族外之人后来又指定这名儿子为自己的继承人，而儿子成为继承人后在未适婚时死亡，我认为替补继承人完全无须向该儿子给付遗赠，因为父亲的遗产并非直接、而是通过继承关系才到达儿子手中。

<!-- source-p 526 -->
<a id="32.103.1"></a>
**1**　兄弟的情形更能说明这一点：某人先成为父亲的继承人，随后又指定被排除继承的兄弟为自己的继承人。我认为，该兄弟的替补继承人无须给付遗赠；即使该兄弟无遗嘱死亡，亦无须给付，因为其兄弟的财产并非直接、而是通过继承关系才归于该人。

<!-- source-p 527 -->
<a id="32.103.2"></a>
**2**　若儿子被指定为十二分之一份额的继承人，并由其作出遗赠，且他也有替补继承人；后来另一名儿子援引裁判官告示，使其取得遗产二分之一的遗产占有（bonorum possessio），那么他的替补继承人应按十二分之一还是二分之一给付遗赠？较正确的看法是按二分之一给付；但对其他子女及尊亲属，则仍按十二分之一给付。〔“ex uncia omnibus ex reliquis liberis et parentibus”的分配对象与句法关系不甚明确，暂从字面处理。〕

<!-- source-p 528 -->
<a id="32.103.3"></a>
**3**　反之，若儿子原被指定为十二分之九份额的继承人，却在援引裁判官告示后仅取得遗产二分之一的遗产占有，则其替补继承人只须按二分之一给付遗赠。正如取得更多遗产占有时，遗赠负担随之增加；取得较少时，负担也相应扣减。
