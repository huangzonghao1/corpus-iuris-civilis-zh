# D.32.1 论遗赠与遗嘱信托（*De legatis et fideicommissis*）——第三段

<!-- source-p 265 -->
<a id="32.50.2"></a>**2.**若遗赠给予精神失常者、挥霍者，或裁判官因某种原因指定监护人的人，我认为，对他们作出这样的遗赠，也可能是指他们解除监护或保佐之时。

<!-- source-p 266 -->
<a id="32.50.3"></a>**3.**由这些及类似事例可见，萨宾解释了立遗嘱人意思的问题。若遗赠如此给予已适婚者，尤其是年满二十五岁者，他无疑会认为立遗嘱人所指的是该人脱离他权、获得自主。

<!-- source-p 267 -->
<a id="32.50.4"></a>**4.**这种写法的含义各异，必须探求立遗嘱人意思。例如，有人写道“待其成为自权人时”，也同样须作意思解释；因为该语有时指脱离家父权，有时指达到适婚年龄或年满二十五岁。

<!-- source-p 268 -->
<a id="32.50.5"></a>**5.**我认为，即使遗赠给已经适婚但未满二十五岁之人，并写道“待其达到适婚年龄时”，立遗嘱人所指也应是年龄；达到该年龄后，此人便不再享有回复原状救济。

<!-- source-p 269 -->
<a id="32.50.6"></a>**6.**若立遗嘱人写道“待其达到自己的年龄时”，究竟指适婚年龄还是二十五岁，仍可探求其意思；写作“待其达到适当年龄”“待其达到成熟年龄”或“待其成年”时，也同样如此。

<a id="32.52"></a>**32.52**

<!-- source-p 274 -->
**乌尔比安：《萨宾评注》第二十四卷。**

<!-- source-p 275 -->
<a id="32.52.pr."></a>**序言。**“书籍”一词包括所有卷册，无论写在纸草纸、羊皮纸还是其他任何材料上；即使写在树皮、椴树内层（有人用这些材料制成书写物）或其他皮革上，也应作相同处理。但若文字写在羊皮纸、纸草纸、象牙或其他材料制成的册页上，或写在涂蜡书板上，是否属于书籍遗赠，仍须考察。盖乌斯·卡西乌斯写道，遗赠书籍也包括写有文字的羊皮纸；据此，其他材料也应包括在内，除非立遗嘱人意思相反。

<!-- source-p 276 -->
<a id="32.52.1"></a>**1.**若遗赠一百本书，应交付一百卷，而非按一人抄写一卷所需的内容量来计算。例如，若荷马全集写在一卷中，就不能把它算作四十八本；应将一卷荷马作品算作一本书。

<!-- source-p 277 -->
<a id="32.52.2"></a>**2.**若遗赠荷马全集，但全集并不完整，则现存多少篇章，都应交付多少。

<!-- source-p 278 -->
<a id="32.52.3"></a>**3.**萨宾写道，遗赠书籍不包括图书馆；卡西乌斯也持同一意见。他说，遗赠书籍包括写有文字的羊皮纸；他接着指出，书柜、书箱以及其他存放书籍之物均不包括在内。

<!-- source-p 279 -->
<a id="32.52.4"></a>**4.**但卡西乌斯关于未写文字的羊皮纸的意见是正确的：遗赠书籍不包括空白纸草纸，遗赠纸草纸也不包括书籍；除非立遗嘱人意思促使我们作不同解释。例如，某人如此遗赠“我全部的纸草纸”，而其除书籍外别无他物；他本人爱书，又留给同样爱书之人。无人会怀疑，这里指的是书籍，因为许多人也习惯把书称作纸草纸。那么，若有人遗赠的是未书写的纸草纸呢？这既不包括空白羊皮纸，也不包括其他书写材料，更不包括已经开始书写但尚未完成的书籍。

<!-- source-p 280 -->
<a id="32.52.5"></a>**5.**因此，有人恰当地询问：若遗赠书籍，尚未写完的书是否包括在内。我认为不包括，正如“衣物”不包括尚未织成的布匹。但已经写完、尚未装订或装饰的书籍，应包括在内；同样，尚未粘合或校订的书籍也包括在内；尚未缝合的羊皮纸页亦同。

<!-- source-p 281 -->
<a id="32.52.6"></a>**6.**若遗赠纸草纸，不包括尚未制成纸草纸的纸莎草，也不包括尚未完成的纸草纸。

<!-- source-p 282 -->
<a id="32.52.7"></a>**7.**若遗赠图书馆，究竟仅包括书柜，还是也包括书籍，存在疑问。涅尔瓦精当地说，应取决于立遗嘱人的意思：“图书馆”有时指存放书籍的地方，有时指书柜，正如人们会说“他买了一座象牙图书馆”；有时则指书籍本身，正如人们会说“他买了一批书”。

<!-- source-p 283 -->
<a id="32.52.7a"></a>**7a.**萨宾所说书籍不随图书馆遗赠，并非在所有情形下都正确；因为有时书柜也应交付，许多人把书柜称为图书馆。但若你所说的书柜与建筑物相连或固定在建筑物上，则无疑不应交付，因为它们属于建筑物的一部分。

<!-- source-p 284 -->
<a id="32.52.8"></a>**8.**庞波尼乌斯在《萨宾评注》第六卷讨论了遗赠宝石戒指盒时的同一问题。他说，戒指也应包括在内，而不只是专为放置戒指而制的盒子。他据此推断，因为有人如此遗赠：“我的宝石戒指盒，以及我另外拥有的所有戒指。”他又说，拉贝奥也持同一意见。

<!-- source-p 285 -->
<a id="32.52.9"></a>**9.**不过，有些物品无论如何都会随遗赠物一并交付，例如遗赠床铺时包括床垫；柜子或抽屉的锁和钥匙也随其一并交付。

<a id="32.54"></a>**32.54**

<!-- source-p 291 -->
**庞波尼乌斯：《萨宾评注》第七卷。**

<!-- source-p 292 -->
若我无条件遗赠给你某物，之后又写道：“此外，若船从亚洲抵达，我的继承人应把地产交给他”，则更妥当的理解是，“此外”一语也使前面的遗赠内容重新适用。正如我们说：“卢基乌斯·提提乌斯给平民每人五千；此外，塞尤斯还给了肉食分配款”，应理解塞尤斯也给了每人五千；又如“提提乌斯取得五枚，塞尤斯此外取得地产”，应理解塞尤斯也取得了五枚。

<!-- source-p 293 -->
<a id="32.55"></a>**32.55**

<!-- source-p 294 -->
**乌尔比安：《萨宾评注》第二十五卷。**

<!-- source-p 295 -->
<a id="32.55.pr."></a>**序言。**“木材”是一般用语，但应区分为建筑木料和木柴。建筑木料是建造或支撑房屋所必需之物；木柴则是为燃烧而备的任何木料。问题是，只有劈成木柴的才算，还是尚未劈开的也算？昆图斯·穆基乌斯在《民法》第二卷记载：若有人遗赠地产中的木柴，作为建筑木料砍下的树木不应交付；他没有补充说，若砍树并非为了燃烧，木材就归受遗赠人；但由此应作这种理解。

<!-- source-p 296 -->
<a id="32.55.1"></a>**1.**奥菲利乌斯在《法律分类》第五卷也如此写道：凡遗赠木柴，所有不以其他名称称呼、且除燃烧外没有其他用途的木料都属于受遗赠人，例如枝条、木炭、橄榄核；果核也应包括在内。

<!-- source-p 297 -->
<a id="32.55.2"></a>**2.**奥菲利乌斯在《法律分类》第二卷认为，尚未劈开的树木不属于木柴遗赠，除非该木料已经被劈成小块。我则认为，尚未劈成小块的木料，只要已准备劈作木柴，也包括在“木柴”之内。因此，若立遗嘱人留有专供此用的林地，林地本身不随遗赠，但已砍倒的树木属于木柴；除非立遗嘱人意思相反。

<!-- source-p 298 -->
<a id="32.55.3"></a>**3.**木柴遗赠包括一切备作燃料之物，无论原本用于浴室取暖、加热起居室，还是用于烧制石灰或其他物品。

<!-- source-p 299 -->
<a id="32.55.4"></a>**4.**奥菲利乌斯在《法律分类》第五卷写道，树枝不包括在“木柴”一词之内；但若立遗嘱人意思不相反，则细枝、枯枝、藤枝、剩余木料，以及葡萄藤的茎和根也都包括在内。

<!-- source-p 300 -->
<a id="32.55.5"></a>**5.**在某些地区，例如埃及，人们以芦苇代替木材作燃料；因此，芦苇、纸莎草以及某些草、小刺或荆棘也包括在“木柴”之内。这有什么奇怪？人们把这种木料称为 *culon*，也把从沼泽中拖运这些木料的船称作 *culygas*（底本附希腊语转写：*apo twn helwn deducunt*）。

<!-- source-p 301 -->
<a id="32.55.6"></a>**6.**在某些行省，人们也以牛粪作此用途。

<!-- source-p 302 -->
<a id="32.55.7"></a>**7.**若木料已备作烧制木炭之用，奥菲利乌斯在《法律分类》第五卷说，这类材料不包括在“木炭”遗赠中。问题是，它是否包括在“木柴”遗赠中？有人或许会说也不包括，因为立遗嘱人持有这些木料，并非为了将其作为木柴。但树脂木和其他经烧制、不产生烟的木料，又应归入木柴、木炭，还是单独一类？较可取的意见是，应将其视为单独一类。

<!-- source-p 303 -->
<a id="32.55.8"></a>**8.**涂有硫磺的木料，也应依同一界定处理。

<!-- source-p 304 -->
<a id="32.55.9"></a>**9.**为制火把而备的木料不包括在“木柴”之内，除非立遗嘱人有此意思。

<!-- source-p 305 -->
<a id="32.55.10"></a>**10.**松树上完整的球果包括在“木柴”一词之内。

<!-- source-p 316 -->
**尤利安：《学说汇纂》第三十四卷。**

<!-- source-p 317 -->
遗赠债权文书之人，所考虑的不只是文书本身，也包括文书所证明的诉权。显然，我们有时用“债权文书”一词指债权本身；例如，出售债权文书时，我们知道被出售的是债权。甚至有人遗赠债权，也应理解为遗赠其诉权所代表的权利。

<a id="32.60"></a>**32.60**

<!-- source-p 319 -->
**阿尔费努斯：《保罗节编》第二卷。**

<!-- source-p 320 -->
<a id="32.60.pr."></a>**序言。**有人询问，遗赠“羔羊”应包括多大年龄的羊。有人说只包括六个月大的羔羊；但更妥当的意见是，遗赠的是尚未满一岁的羊。

<!-- source-p 321 -->
<a id="32.60.1"></a>**1.**我答复：遗赠城市奴隶和女奴，不包括马夫或骡夫；因为只有家父为满足自身生活需要而留在身边的人，才属于城市奴隶。

<!-- source-p 322 -->
<a id="32.60.2"></a>**2.**遗赠给妻子羊毛、亚麻和紫色织物，且这些物品原是为她备置；立遗嘱人留有大量羊毛和各种其他物品。有人询问是否应将全部羊毛交给妻子。答复：若立遗嘱人未将其中任何部分指定供妻子使用，而所有羊毛混在一起，则应像遗赠食品储藏物的情形一样审查；立遗嘱人留下许多食品储藏物，其中有些通常会出售。若酒已被分装储存，立遗嘱人及其继承人均可使用，我们仍认为所有酒都属于食品储藏物。但若能证明立遗嘱人通常出售部分储藏物，则确立了如下规则：继承人应把一年所需之量交给受遗赠人。我认为，羊毛也应如此处理，妻子可以取用足够一年使用的羊毛；这并非先扣除丈夫所需后，将剩余羊毛遗赠给妻子，而是只遗赠原为妻子备置之物。

<!-- source-p 323 -->
<a id="32.60.3"></a>**3.**遗赠地产及为耕作地产而购买、备置之物，不包括园丁或林地看守人；园丁是为装饰地产而备置，林地看守人则主要负责守护和照料，而非耕作。机械用驴似乎包括在内；为给土地施肥而备置的羊也包括在内；若牧羊人负责照看这类羊，牧羊人亦包括在内。

<a id="32.64"></a>**32.64**

<!-- source-p 334 -->
**阿非利卡努斯：《疑问集》第六卷。**

<!-- source-p 335 -->
某人指定儿子和孙子为继承人，并以遗嘱信托将特定地产及死者死亡时属于自己的财物留给孙子，但排除债权簿。死者死亡时，在存放债权文书和债务担保的箱子中发现了现金。多数人认为，立遗嘱人不大可能把现金也包括在债权簿遗赠中。我则认为值得审查：某人若希望把债权簿交给他人，究竟应理解为只交付债务人名册，还是也交付已向债务人收回、但仍用于同一债权簿的款项？我更倾向于认为，正如已收回后再次出借的钱款，即使债权人名册变更，也不会使遗嘱信托消灭或减少；同样，若收回的现金仍用于债权簿，也应归入同一遗嘱信托。甚至可以主张，不仅向债务人收回的钱款，凡因任何原因收回、但仍归入同一账目之款，也都应属于该遗嘱信托。

<!-- source-p 336 -->
<a id="32.65"></a>**32.65**

<!-- source-p 337 -->
**马尔基安：《法学阶梯》第七卷。**

<!-- source-p 338 -->
<a id="32.65.pr."></a>**序言。**遗赠奴隶时排除经商者，拉贝奥写道：这里排除的是被派去经营业务之人，例如负责采购、出租或承租业务的人；但贴身侍从、采买食物的人，或负责渔业的人，不包括在“经商”一词之内。我认为拉贝奥的意见正确。

<!-- source-p 339 -->
<a id="32.65.1"></a>**1.**若奴隶从职务转为技艺，有人正确地认为遗赠失效，因为原有职务已变为技艺。反过来则不然，例如轿夫后来改作厨师。

<!-- source-p 340 -->
<a id="32.65.2"></a>**2.**若同一奴隶会多种技艺，而遗赠分别给予厨师、织工或轿夫，则应将奴隶交给其实际主要从事之技艺所对应的受遗赠人。

<!-- source-p 341 -->
<a id="32.65.3"></a>**3.**遗赠女发饰师时，塞尔苏斯写道：仅在师傅处学习两个月的人不包括在内。另有意见认为，此人也应包括在内；否则可能无人符合条件，因为所有人仍可继续学习，任何技艺都可以进步。后一意见应当采纳，因为它符合人性。

<!-- source-p 342 -->
<a id="32.65.4"></a>**4.**卡西乌斯写道，牲畜包括成群放牧的四足动物。猪也包括在牲畜之中，因为猪亦成群放牧。荷马在《奥德赛》中也这样说：“*dyeis ton ge suessi parymenon: ahi de nemontai par korakos petry epi te kryny arevousy*”〔底本附拉丁释文：*invenies cum adsidentem suibus, quae pascuntur ad Coracis rupem prope fontem Arethusam*〕（意为：“你会发现他坐在猪群旁；猪在科拉克斯岩、阿瑞托萨泉旁吃草。”）

<!-- source-p 343 -->
<a id="32.65.5"></a>**5.**遗赠役畜不包括牛；反之，遗赠牛也不包括在役畜之内。

<!-- source-p 344 -->
<a id="32.65.6"></a>**6.**遗赠马匹也包括母马。

<!-- source-p 345 -->
<a id="32.65.7"></a>**7.**遗赠绵羊不包括羊羔。羊羔何时不再被视为羊羔，应依当地习惯判断；有些地方以羊开始剪毛之时，认定其已属于绵羊。

<!-- source-p 353 -->
**乌尔比安：《答复集》第一卷。**

<!-- source-p 354 -->
<a id="32.68.pr."></a>**序言。**尤尼安努斯提出咨询。立遗嘱人写道：“全部塞伊乌斯地产。”这一表述也将上述地产中仿佛属于立遗嘱人的部分，以遗嘱信托留给受益人；该部分是他依据质权取得的，但债务人的权利仍应保留。

<!-- source-p 355 -->
<a id="32.68.1"></a>**1.**仅凭以下措辞：“请照料田地，这样我的儿子就会把你们的子女赠与你们”，不能请求履行遗嘱信托。

<!-- source-p 356 -->
<a id="32.68.2"></a>**2.**塞娅以“若我死时属于我”为条件遗赠共有奴隶；除非立遗嘱人意思是，只有奴隶完全属于她时才应交付，否则不应认定遗赠义务成立。〔底本此处有连写疑误〕

<!-- source-p 357 -->
<a id="32.68.3"></a>**3.**若地产连同其上财产一并遗赠，遗嘱订立时位于该地产上的奴隶也应随地产交付；后来增加的奴隶亦同，但以立遗嘱人明确表达此意为限。

<a id="32.69"></a>**32.69**

<!-- source-p 359 -->
**马尔凯卢斯：《答复集》单卷。**

<!-- source-p 360 -->
<a id="32.69.pr."></a>**序言。**只有在立遗嘱人显然另有所指时，才应偏离措辞的通常含义。

<!-- source-p 361 -->
<a id="32.69.1"></a>**1.**提提乌斯在遗嘱附录中规定：“我希望将我雇用的所有年轻人给予普布利乌斯·梅维乌斯。”我询问“年轻人”应从何种年龄开始，又到何种年龄为止。马尔凯卢斯答复：立遗嘱人欲以这些措辞指明何人，属于审理此事之人的判断范围。在遗嘱案件中，不应总是追求严格定义，因为人们通常会不精确地使用词语，并非始终采用准确名称。除此之外，可以认为“年轻人”指已过少年年龄、但尚未开始被列入年长者之列的人。〔底本此处有缺词〕

<a id="32.70"></a>**32.70**

<!-- source-p 363 -->
**乌尔比安：《萨宾评注》第二十二卷。**

<!-- source-p 364 -->
<a id="32.70.pr."></a>**序言。**遗赠羊毛时，看来指未染色、保持天然色泽的羊毛。

<!-- source-p 365 -->
<a id="32.70.1"></a>**1.**无论羊毛已经制成织物还是尚未加工，都包括在“羊毛”一词之内。

<!-- source-p 366 -->
<a id="32.70.2"></a>**2.**有人询问，“羊毛”是否仅包括尚未纺成纱线的羊毛，还是也包括已纺成的羊毛，例如经线和纬线。萨宾认为已纺成的也包括在内；我们遵从其意见。

<!-- source-p 367 -->
<a id="32.70.3"></a>**3.**意见认为，“羊毛”一词的范围延伸至织成布匹为止。

<!-- source-p 368 -->
<a id="32.70.4"></a>**4.**应知，未经清洗的羊毛以及已洗净的羊毛也包括在内，只要尚未染色。

<!-- source-p 369 -->
<a id="32.70.5"></a>**5.**“羊毛”一词不包括填充物。

<!-- source-p 370 -->
<a id="32.70.6"></a>**6.**某人为了治病或享乐，已用羊毛制成类似衣物之物，也不包括在羊毛遗赠内。

<!-- source-p 371 -->
<a id="32.70.7"></a>**7.**为热敷或医疗而备置的羊毛，也不包括在“羊毛”一词内。

<!-- source-p 372 -->
<a id="32.70.8"></a>**8.**带毛的兽皮是否也包括在羊毛中？显然，这类兽皮也随羊毛遗赠交付。

<!-- source-p 373 -->
<a id="32.70.9"></a>**9.**我认为，遗赠羊毛时，也包括兔毛、鹅绒、山羊毛，以及一种以木材制成、称为 *eriocylon* 的材料。

<!-- source-p 374 -->
<a id="32.70.10"></a>**10.**遗赠羊毛不包括亚麻。

<!-- source-p 375 -->
<a id="32.70.11"></a>**11.**遗赠亚麻时，已加工和未加工的亚麻都包括在内；已经纺成纱线以及织入尚未织完的布匹中的亚麻也包括在内。因此，亚麻与羊毛的处理不同。亚麻若已染色，我认为仍包括在亚麻遗赠之中。

<!-- source-p 376 -->
<a id="32.70.12"></a>**12.**对于“彩色织物”一词，应当审查其范围。古人一致认为，“羊毛”一词不包括彩色织物；但凡已经染色、并已纺成纱线而尚未织成或编成织物者，均应视为已遗赠。问题是，紫色是否属于彩色织物。我认为，未染色之物不计入彩色织物；因此，白色、天然黑色或其他天然颜色都不包括在内。但紫色和胭脂红不属于天然色，故应包括在内，除非立遗嘱人另有所指。

<!-- source-p 377 -->
<a id="32.70.13"></a>**13.**我认为，“紫色”一词包括各种紫色；但不包括胭脂红，而包括福基斯紫和风信子紫。“紫色”一词无疑也包括已经织成的纬线；但专门留作染成紫色之用的羊毛不包括在内。

<!-- source-p 385 -->
**乌尔比安：《萨宾评注》第二十卷。**

<!-- source-p 386 -->
<a id="32.73.pr."></a>**序言。**我们将“自己的奴隶或女奴”理解为完全归立遗嘱人所有之人；享有用益权的人不包括在内。

<!-- source-p 387 -->
<a id="32.73.1"></a>**1.**但若奴隶基于善意为立遗嘱人服役，较妥当的意见是也将其包括在“自己的奴隶”之中，前提是立遗嘱人以“自己的”称谓指其所计入自己名下之人。

<!-- source-p 388 -->
<a id="32.73.2"></a>**2.**债务人把奴隶出质或设定抵押时，显然应认为债务人把该奴隶作为自己的奴隶遗赠；债权人则绝非如此。

<!-- source-p 389 -->
<a id="32.73.3"></a>**3.**若某人拥有自己的奴隶，但将其服务出租，例如安排其从事烘焙、表演或其他类似工作，是否也视为依“奴隶”一词将他们遗赠？除非立遗嘱人意思相反，应推定包括在内。

<!-- source-p 390 -->
<a id="32.73.4"></a>**4.**我认为，经营奴隶买卖之人通常不希望将其奴隶财物计入“自己的奴隶”，除非其意思明确表明也包括这些人；因为某人购买奴隶后立即转售，应认为他把奴隶视为货物，而非自己的人。

<!-- source-p 391 -->
<a id="32.73.5"></a>**5.**庞波尼乌斯在《萨宾评注》第五卷写道，某人自己的奴隶所拥有的从属奴隶，不包括在“自己的奴隶”之中。
