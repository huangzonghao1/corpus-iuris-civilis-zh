# D.32.1 论遗赠与遗嘱信托（第二段：P133–P264）

<!-- source-p 133 -->
**保罗：《裁决集》第二卷。**

<!-- source-p 134 -->
<a id="32.27.pr."></a>**序言。**保拉指定卡利尼库斯为其女儿尤文提娅的部分继承人，并在遗嘱中给他留下十枚金币；此后她又作成遗嘱补编，将一百枚金币留给同一卡利尼库斯，却没有加上“此外”一语。裁决认为，两笔金额均应给付；尤其是因为遗嘱补编中没有给卡利尼库斯的女儿留下任何遗赠。

<!-- source-p 135 -->
<a id="32.27.1"></a>**1.**庞培乌斯·赫尔米普斯指定儿子赫尔米普斯继承四分之三，女儿提提娅继承四分之一，并分别将特定土地先取遗赠给二人；此外，他规定，若赫尔米普斯无子女而死，另一处地产应给女儿。立遗嘱后，他又以遗嘱补编将若干土地给女儿，并要求她以这些土地满足其全部继承份额及遗嘱中留给她的一切。赫尔米普斯的财产后来归入国库，妹妹提提娅请求履行遗嘱信托。争议在于，父亲是否意在让她以遗嘱补编所留土地替代继承份额，并同时替代兄长死后无子女时应返还给她的财产。我原认为，这已背离立遗嘱人的全部意思。最终采纳了较为宽厚的解释：被撤回的仅是她在兄长生前即可取得的财物；若兄长无子女而死，父亲留给她的死后财物并未被撤回。裁决亦如此作出。

<!-- source-p 136 -->
<a id="32.27.2"></a>**2.**尤利乌斯·塞维鲁斯死亡时指定若干继承人，并遗赠五十枚金币给其受养人；他要求由其佃户尤利乌斯·马乌鲁斯从拖欠的土地租金中给付该款，也向马乌鲁斯留下了若干遗赠。国库对遗产提出权利主张后，马乌鲁斯奉财务官命令向国库交付了该款；后来，遗嘱指定的继承人胜诉，国库败诉。受养人死亡后，其继承人向马乌鲁斯的继承人请求履行遗嘱信托。皇帝认为，这并非将遗嘱信托义务托付马乌鲁斯，而只是指出受益人可以从何处取得款项。因此，塞维鲁斯的继承人应当给付。

<a id="32.29"></a>**32.29**

<!-- source-p 141 -->
**拉贝奥：《后编》第二卷（由雅沃勒努斯摘编）。**

<!-- source-p 142 -->
<a id="32.29.pr."></a>**序言。**某人有一名姘居伴侣，并把前一名姘居伴侣的衣物交给她使用；此后他遗赠：“为她的需要所购置、备办的衣物。”卡斯凯利乌斯和特雷巴提乌斯认为，该遗赠不包括为前一名姘居伴侣备办的衣物，因为妻子与姘居伴侣的法律地位不同。拉贝奥不赞同此说：此类遗赠不应遵循婚姻法上的规则，而应解释其文字；对于女儿或任何其他人，法律也应相同。拉贝奥的意见正确。

<!-- source-p 143 -->
<a id="32.29.1"></a>**1.**如果遗嘱规定：“我的妻子提提娅取得与任一继承人相同的份额”，而各继承人的份额并不相等，昆图斯·穆基乌斯和加卢斯认为遗赠的是最大份额，因为较大份额也包含较小份额；塞尔维乌斯和奥菲利乌斯则认为遗赠的是最小份额，因为既然继承人负有给付义务，给付哪一份额便取决于其选择。拉贝奥赞同后说，此说正确。

<!-- source-p 144 -->
<a id="32.29.2"></a>**2.**如果遗嘱如此规定：*“Quanta pecunia ex hereditate Titii ad me pervenit, tantam pecuniam heres meus Seiae dato”*（“提提乌斯遗产中有多少金钱归我取得，我的继承人就应向塞娅给付同额金钱”），拉贝奥认为，遗赠的金额应为立遗嘱人已将从该遗产取得的款项记入自己账簿的数额；除此之外，若继承人后来因该遗产而负有任何给付义务，受遗赠人无须就此向继承人提供担保。我持相反意见，因为继承人将代表该遗产给付的金额，不能视为已经归其取得。阿尔费努斯·瓦鲁斯记载，塞尔维乌斯也持此说；此说正确。

<!-- source-p 145 -->
<a id="32.29.3"></a>**3.**如果你作为继承人，将一名未具体指明的奴隶遗赠给我，却交付了斯提库斯，而斯提库斯后来被第三人依法追回，拉贝奥写道，我可以依据遗嘱起诉，因为继承人交付之物既然无法由我保有，就不应视为已完成给付。我认为此说正确。但他还指出，在诉讼系属之前，你必须通知继承人；否则，你提起遗嘱诉讼时，继承人可以对你提出诈欺抗辩。

<!-- source-p 146 -->
<a id="32.29.4"></a>**4.**遗嘱写道：*“如果我死亡时斯提库斯和达马仍处于我的权力之下，那么斯提库斯和达马即为自由人，并取得那块土地。”*如果立遗嘱后主人将二人中的一人转让或释放，拉贝奥认为二人均不能取得自由；图贝罗则认为，仍处于权力之下的那一人应获得自由并取得遗赠。我认为，图贝罗的意见更符合死者的意思。

<a id="32.30"></a>**32.30**

<!-- source-p 148 -->
**拉贝奥：《后编》第二卷（由雅沃勒努斯摘编）。**

<!-- source-p 149 -->
<a id="32.30.pr."></a>**序言。**某人有四只橄榄木杯，并遗赠：“两对橄榄木杯。”我答复说，只遗赠了一对，因为他没有写“两对杯子”，也没有写“杯子的两对”；特雷巴提乌斯也持此说。

<!-- source-p 150 -->
<a id="32.30.1"></a>**1.**某人向国家承租了公共花园，并将这些花园在承租期内（至租约届满之年）的孳息遗赠给奥菲狄乌斯；他还命令继承人将花园租约交给奥菲狄乌斯，并允许其使用、收益。我答复说，继承人有义务允许其使用、收益；此外，继承人还应向国家支付花园租金。

<!-- source-p 151 -->
<a id="32.30.2"></a>**2.**遗嘱写道：*“我的继承人应给我的奴隶斯提库斯五枚金币；如果斯提库斯为我的继承人服务两年，他即为自由人。”*我认为，两年后遗赠才应给付，因为自由和遗赠均应推迟至该期限；特雷巴提乌斯也如此答复。

<!-- source-p 152 -->
<a id="32.30.3"></a>**3.**如果你负有以确定价格将土地卖给我的义务，就无权在该项买卖中另行扣留土地的任何孳息，因为该价格涵盖了土地的全部利益。

<!-- source-p 153 -->
<a id="32.30.4"></a>**4.**某人按照我的委任，以合伙方式为我和自己买下一块土地，随后划分了土地边界；在尚未将土地交付给我之前，他遗嘱写道：“我将我的土地给你。”我否认我还可请求土地的其他份额，因为很难认为家父会如此立遗嘱，以致其继承人因委任关系而承担给付义务。

<!-- source-p 154 -->
<a id="32.30.5"></a>**5.**遗嘱写道：*“在我的妻子与我儿子同住卡普阿期间，我的继承人应给她二百枚金币。”*后来儿子离开了母亲。特雷巴提乌斯认为，如果二人都住在卡普阿，即使没有同住，该遗赠仍应给母亲；但如果二人迁往另一市镇，则只应给付他们曾共同居住那一年的遗赠，无论共同居住的时间多短。我们应当考察，“在她与儿子同住卡普阿期间”这些文字是否并非表示条件，而应视为多余文字；我不赞同这种解释。如果未能与儿子同住并非由该女子造成，则遗赠应向她给付。

<!-- source-p 155 -->
<a id="32.30.6"></a>**6.**如果你被判令交付他人所有的房屋，而无论基于何种条件你都无法买下该房屋，阿泰乌斯写道，法官应评定该房屋的价值；继承人支付价款后即可免责。即使你本可买下房屋却没有买下，法律也相同。

塞克斯提娅继承四分之一，其余份额由塞尤斯和马尔基乌斯（死者姐妹之子）继承；立遗嘱人指定塞克斯提娅为马尔基乌斯的替补继承人，也指定马尔基乌斯为塞克斯提娅的替补继承人，并将若干特定物品以先取遗赠方式留给马尔基乌斯。马尔基乌斯放弃了遗嘱指定给他的遗产份额，随后无遗嘱死亡，其财产依法归其兄弟塞尤斯所有。有人问：塞克斯提娅能否依据替补继承的权利，向死者的法定继承人请求取得原先先取遗赠给马尔基乌斯的物品？答复说，根据所陈述的事实，塞克斯提娅并未被指定为马尔基乌斯所受遗赠的替补受益人。

<a id="32.33"></a>**32.33**

<!-- source-p 163 -->
**斯凯沃拉：《学说汇纂》第十五卷。**

<!-- source-p 164 -->
<a id="32.33.pr."></a>**序言。**某人将下列事项遗赠给妻子：“此外，还有我们惯常居住的那部分房屋。”有人问：立遗嘱时及死亡时，他都在整幢房屋内居住，也未将其中任何部分出租；这是否意味着他仅遗赠了惯常睡觉的卧室？答复说，应是他与家人惯常居住的整个部分。

<!-- source-p 165 -->
<a id="32.33.1"></a>**1.**某人将下列事项遗赠给妻子：“我希望将我生前给予、赠与或为她使用而购置的一切，交由我的妻子保有。”我问，立遗嘱后赠与妻子的物品，是否也在允许保有之列？答复说，所引文字并未表达任何关于未来时间的意思。

<!-- source-p 166 -->
<a id="32.33.2"></a>**2.**塞尤斯替妻子向债权人清偿了一百枚金币，并赎回作为质物的首饰；后来他立遗嘱，将自己对妻子享有的相关权利一并让与她，并额外遗赠每年二十枚金币。有人问：丈夫的继承人能否向妻子或其继承人追回这百枚金币？答复说，如果塞尤斯是出于赠与目的向债权人付款，继承人依据遗嘱信托负有义务；即使他们起诉请求返还，也应以抗辩排除其请求。除非继承人证明相反事实，否则应推定该付款是出于赠与。〔底本此处 *inve stipulatum eius concessit* 语句疑有讹脱，暂据上下文作概括处理。〕

<a id="32.34"></a>**32.34**

<!-- source-p 168 -->
**斯凯沃拉：《学说汇纂》第十六卷。**

<!-- source-p 169 -->
<a id="32.34.pr."></a>**序言。**遗嘱以如下文字遗赠债务人的债权：“此外，我希望向提提乌斯给付十枚金币，即盖乌斯·塞尤斯的继承人所欠我的款项；我希望将针对他们的诉权委托给他，并将相应质物交付给他。”我问，继承人仅须给付十枚金币，还是应委托提提乌斯追收全部债务，包括利息？答复说，应认为遗赠了该债权所包含的全部债务。又问：若家母不知情，受委托的代理人在行省将利息计入本金后又约定利息，提提乌斯是否也能依据上述遗嘱信托取得新增的债务？答复说，可以取得。

<!-- source-p 170 -->
<a id="32.34.1"></a>**1.**立遗嘱人将儿子指定为部分继承人，并在先取遗赠中写道：“我的儿子提提乌斯应从账簿所载债务人中任选二十人，取得对他们的债权，且不得有故意欺诈。”他生前将全部财产管理权交给儿子。立遗嘱后、父亲死亡前，儿子为父亲管理事务长达十年；他违反父亲经营账簿债务的惯常方式，新增了数额巨大的债务人，并将更大金额的债权计入父亲原先拥有的小额债权之中，结果几乎将账簿的全部财产价值集中于二十名债务人名下。有人问，是否应允许儿子先取其本人新增的这些债权。答复说，他只能选择立遗嘱时已记入立遗嘱人账簿的债权。

<!-- source-p 171 -->
<a id="32.34.2"></a>**2.**某人将其亡夫阿雷托努斯遗产中剩余的财物先取遗赠给一名继承人，并托付其诚信，要求在曾孙年满十六岁时将同一财物交还给他；她还写道：“我另请求你以这些财产的收益，向所有债权人清偿、返还并提供充分担保，以清偿阿雷托努斯遗产所欠的剩余债务。”有人问：若继承人证明遗产收益不足以清偿全部债务，他是否仍须承认并承担该项债务负担？答复说，文字明确要求他仅从该等财产的收益中清偿债务，并未要求他以自己的财产清偿。

<!-- source-p 172 -->
<a id="32.34.3"></a>**3.**某父亲指定儿子和女儿为继承人，并分别将特定土地和债权账簿先取遗赠给他们；他规定：“我亲爱的儿子，我请求你履行我所留下的一切遗赠；如果出现任何债务，包括我曾以借贷方式借入且尚欠的款项，我希望由你清偿，从而使我留给你妹妹的财物完整归她所有。”有人问，父亲因任何原因所欠的债务是否都应由儿子清偿。答复说，女儿可以依据遗嘱信托请求减轻债务负担，使立遗嘱人留给她的财物能够完整归她取得。

<a id="32.35"></a>**32.35**

<!-- source-p 174 -->
**斯凯沃拉：《学说汇纂》第十七卷。**

<!-- source-p 175 -->
<a id="32.35.pr."></a>**序言。**一名被释奴的主人曾立即为他购买部族身份；但主人继承人长期拖延。该被释奴死亡时留下继承人，一名显贵男子。有人问，部族身份的估价是否应给付给他的继承人。答复说，应予给付。又问：如果该被释奴当时依主人的意思取得部族身份，他原本会享有的利益及皇帝所赐恩惠，或该估价金额的利息，是否也应给其继承人？答复说，他本人原可取得的一切，均应转归其继承人。

<!-- source-p 176 -->
<a id="32.35.1"></a>**1.**某人如此遗赠给塞姆普罗尼乌斯：“塞姆普罗尼乌斯应取得我位于加拉太边界、直至名为加阿斯的地产范围内的所有土地；这些土地均在第一管事的管理之下，并按现状连同全部附属物取得。”有人问：在该等地产的相邻区域，有一处土地并不位于加拉太而位于卡帕多基亚，但仍由同一管事管理，该土地是否也应随其他土地归塞姆普罗尼乌斯？答复说，该土地也应给付。

<!-- source-p 177 -->
<a id="32.35.2"></a>**2.**立遗嘱人如此向其列名的被释奴遗赠：“我希望将位于阿特拉塔地区的特雷巴提乌斯土地，以及位于尼法纳地区的萨特里乌斯土地连同店铺一并给付。”有人问：所列土地中确有一处名为萨特里乌斯的土地，但不在尼法纳地区，是否应基于遗嘱信托向被释奴给付？答复说，如果尼法纳地区没有名为萨特里乌斯的土地，而可以确定立遗嘱人意指一处位于其他地点的同名土地，那么尽管其指定地区有误，仍应给付该土地。

<!-- source-p 178 -->
<a id="32.35.3"></a>**3.**经确认的遗嘱补编如此规定：“我最亲爱的提布尔市民们，我希望尤利安浴场与我的房屋相连，并由我的继承人以公费及其管理，每年十个月免费向公众开放。”有人问，继承人是否还应承担维修所需费用。答复说，根据所述情况，应认为立遗嘱人不仅要求承担供暖和开放费用，也要求承担日常维护所需的费用，包括配置浴场设施以及在通常暂停开放期间进行准备、清洁和修整，使浴场能够供人沐浴。

<a id="32.36"></a>**32.36**

<!-- source-p 180 -->
**克劳狄乌斯在斯凯沃拉《学说汇纂》第十八卷处作注。**

<!-- source-p 181 -->
若某人的遗嘱被认定为不合义务遗嘱，则其以无遗嘱继承为基础所作的遗嘱信托也不应由继承人履行；因为应认为此人近乎精神失常，不能立遗嘱，因此其他涉及其最后意思表示的处分也均无效。〔底本作 *ab intestato data*；此处“以无遗嘱继承为基础所作”暂依上下文处理。〕

<!-- source-p 182 -->
<a id="32.37"></a>**32.37**

<!-- source-p 183 -->
**斯凯沃拉：《学说汇纂》第十八卷。**

<!-- source-p 184 -->
<a id="32.37.pr."></a>**序言。**某人临终时将一块属于其母亲的土地遗赠给母亲，并请求母亲在自己死后将该土地返还给其妻弗拉维娅·阿尔比娜。立遗嘱人死亡后，母亲向官员声明，她准备遵从儿子的意思，将土地交给弗拉维娅·阿尔比娜，但要求每年向自己支付两份收益；然而她既未交付占有，也未收取这两份年收益。有人问，她能否依法将土地出售给他人。答复说，如果争议涉及遗赠及遗嘱信托的效力，根据所述事实，遗赠母亲自己的土地并未生效，遗嘱信托的负担也未发生；前提是母亲没有另外取得任何利益。

<!-- source-p 185 -->
<a id="32.37.1"></a>**1.**某人在遗嘱中指定继承人，并遗赠二百枚金币给梅维乌斯，托付其诚信，要求他给格劳刻一百枚，给提刻·埃尔庇斯五十枚。后来，应立遗嘱人的请求，梅维乌斯写信给她们，表示将按照立遗嘱人的意思返还财物。此后，立遗嘱人又作成遗嘱补编，规定除该补编外，若另有任何文件出现，均不生效。有人问：既然立遗嘱人改变了对该信件的意思，取得二百枚金币（或以该金额为价款取得土地）的梅维乌斯，是否会被这些女子依据遗嘱信托起诉？答复说，根据所述情况，无论梅维乌斯取得的是二百枚金币还是以此换得的土地，这些女子起诉梅维乌斯均无理由。

<!-- source-p 186 -->
<a id="32.37.2"></a>**2.**某人指定自己的被释奴塞娅和梅维乌斯各继承一半，并为自己的受监护人塞姆普罗尼乌斯指定梅维乌斯的替补继承人。随后，他以遗嘱补编确认遗嘱信托，写道：“卢基乌斯·提提乌斯向其继承人塞娅问候。我指定你继承二分之一；我禁止我的被释奴梅维乌斯（我在遗嘱中指定其继承二分之一）取得该份遗产；我希望由我的主人、未成年人普布利乌斯·塞姆普罗尼乌斯继承该份额或取代该份额。”他又遗赠给不愿使其取得遗产份额的梅维乌斯遗嘱信托，写道：“我希望给我的被释奴梅维乌斯一百五十 *lagynoi*（量）的陈年葡萄酒；他对我并无任何功劳。”有人问：既然立遗嘱人的意思是无论如何都要使遗产份额归未成年人塞姆普罗尼乌斯，以上文字是否设立了有效遗嘱信托；又因遗嘱补编是写给特定人的，塞姆普罗尼乌斯可以向谁请求？答复说，可以向梅维乌斯请求履行遗嘱信托。

<!-- source-p 187 -->
<a id="32.37.3"></a>**3.**某父亲以非因死亡而赠与的方式，将其全部财产（两名奴隶除外）赠给已解放的儿子，并要求儿子作如下允诺：“我已因赠与而将奴隶及土地交付、移转给你；你、或者该财物将来归属之人，不得故意欺诈，致使这些奴隶、由他们所生的奴隶以及这些土地连同附属物，在我要求时或我死亡时，无法交还给我或我指定的人；但须以这些财物届时仍存在且未因你的故意、欺诈或行为（或将来取得该财物者的故意、欺诈或行为）而灭失或脱离控制为限。”父亲卢基乌斯·提提乌斯为允诺人，儿子卢基乌斯·提提乌斯为承诺人。父亲死亡时又给儿子写了一封遗嘱信托书，内容为：“卢基乌斯·提提乌斯致其子，问候。我确信你的孝心，托付你的诚信，请你向某人等给付并提供特定数额的金钱；我还希望我的奴隶卢克里奥获得自由。”有人问：儿子既未接受父亲遗产的占有，也未成为父亲的继承人，是否仍应依该信件履行遗嘱信托并给予自由？答复说，即使他既未接受遗产，也未请求遗产占有，且未占有遗产中的任何财物，他仍可被父亲的继承人依据允诺诉权起诉；对遗嘱信托有利害关系的人也可将他视为债务人起诉，尤其是在神圣的庇护皇帝作出该项规定之后。

<!-- source-p 188 -->
<a id="32.37.4"></a>**4.**一名女子即将再婚；她命令自己与前夫所生的两个儿子约定，她作为嫁资给付的二十枚金币，在婚姻解除的任何情形下均须返还，以便全部嫁资可给其中一人。婚姻存续期间，两个儿子中的一人死亡；女子写信给在世的儿子，请求他日后只追索一半嫁资，并满足于此，允许另一半留在她丈夫处。此后，女子仍在婚姻关系中死亡。有人问：若儿子向丈夫请求全部嫁资，丈夫能否以诈欺抗辩自保；他能否主动依据遗嘱信托请求免除一半债务？又问：就剩余一半嫁资而言，女子的继承人能否对其儿子提起有用的委任诉讼？答复说，诈欺抗辩有效；丈夫也可主动依据遗嘱信托提出请求。就另一半而言，根据所述事实，尤其是已有写给儿子的信件，委任诉讼并无实益。克劳狄乌斯补充说：因为她在信中明确表示，儿子只须满足于一半嫁资；通说认为，这些文字已足以向儿子设立遗嘱信托。

<!-- source-p 189 -->
<a id="32.37.5"></a>**5.**遗嘱补编写道：

> *Boulomai panta ta hupotetagmena kuria einai. Macimw tw kuriw mou dynaria muria pentakisxilia, hatina elabon parakatavykyn para tou veiou autou Iouliou Macimou, hina autw andrwventi apodwsw, ha ginontai sun tokw tris muria, apodovynai autw boulomai: houtw gar tw veiw autou wmosa.*

〔底本所附拉丁释文为：*Quaecumque infra scripta sunt rata esse volo. Maximo domino meo denariorum quindecim milia, quae a patruo eius Iulio Maximo deposita sunt apud me, ut ei restituerem puberi facto, quae fiunt cum usuris denariorum triginta milia, restitui volo: nam ea re patruo eius iusiurandi dedi.* 大意为：“我希望以下所写均有效。我的主人马克西穆斯在成年时，应取得一万五千第纳里；该款由其叔父尤利乌斯·马克西穆斯寄存于我，约定在他成年时返还；计入利息后为三万第纳里，我希望返还给他，因为我曾就此向其叔父宣誓。”〕

有人问：若除遗嘱补编文字外没有其他证据，这些文字是否足以请求返还寄存款？我答复说，根据所述情况，尤其是立遗嘱人已确认自己就此宣过誓，应当相信该书面记载。

<!-- source-p 190 -->
<a id="32.37.6"></a>**6.**提提娅是一位声名卓著的女子，事务一向由卡利马科斯代为办理；卡利马科斯依法不能从遗嘱取得财产。她作成遗嘱后亲笔写道：

> *Titia dievemyn kai boulomai dovynai kallimaxw misvou xarin dynaria muria.*

〔底本所附拉丁释文为：*Ego Titia testamentum feci et volo dari Callimacho pro mercede denariorum milia decem*（“我提提娅作成遗嘱，并希望给卡利马科斯一万第纳里作为报酬”）。〕

我问，提提娅的继承人是否必须以报酬为由给付这笔金钱。我答复说，不能仅因为写有这些文字，就允许他人请求给付；该项处分显然是为规避法律而作。

<!-- source-p 191 -->
<a id="32.37.7"></a>**7.**遗嘱写道：“我希望将在这些遗嘱文书或任何其他文书中已经或将要释放的所有男女被释奴的子女，一并交付给他们。”有人问，是否也应将立遗嘱人生前已经释放之人的子女给付给被释奴。答复说，即使是立遗嘱订立前已释放的男女被释奴，其子女也应依据遗嘱信托交付。

<a id="32.38"></a>**32.38**

<!-- source-p 193 -->
**斯凯沃拉：《学说汇纂》第十九卷。**

<!-- source-p 194 -->
<a id="32.38.pr."></a>**序言。**父亲禁止儿子出售或质押土地，但以遗嘱信托嘱托儿子将其保留给合法婚姻所生的子女及其他亲属。儿子将父亲留下且已设质的土地用于清偿遗产债权人，以自己的金钱清偿原债权人，并将质押权转移给后手债权人。有人问，质押是否有效。答复说，根据所述事实，质押有效。又问：若儿子出售遗产土地以清偿遗产债权人，而买受人不知道遗嘱信托，买卖是否有效？答复说，根据所述情况，买卖有效，但前提是遗产中没有其他财产可用于清偿债务。

<!-- source-p 195 -->
<a id="32.38.1"></a>**1.**某人指定其两名被释奴斯提库斯和埃罗斯为继承人，并规定：“我禁止科尔内利乌斯土地脱离我家族之名。”其中一名继承人斯提库斯在遗嘱中命令女奴阿瑞斯库莎获得自由，并将自己在该土地上的份额遗赠给她。我问，埃罗斯和斯提库斯的其他共同被释奴能否依据遗嘱信托，向斯提库斯的继承人请求该土地份额。答复说，遗嘱信托不包括该份额。

<!-- source-p 196 -->
<a id="32.38.2"></a>**2.**某人指定女儿为继承人，并规定：“我禁止建筑物脱离我的家族之名；我希望其归属于我在本遗嘱中列名的家生奴隶。”有人问：继承人及列名的家生奴隶均死亡后，遗嘱信托的全部利益是否归于唯一在世的一名被释奴？答复说，根据所述情况，遗嘱信托中相当于一人份额的部分应归于在世的那名家生奴隶。

<!-- source-p 197 -->
<a id="32.38.3"></a>**3.**某人禁止其儿子在有生之年出售、赠与或质押土地，并补充道：“若他违背我的意思行事，提提安努斯土地应归国库；这样，提提安努斯土地就永远不会脱离你们家族之名。”儿子在世时遵从父亲的意思保有该土地。有人问，儿子死亡后，该土地应归儿子遗嘱指定的继承人，还是归属于家族成员。答复说，可以从死者意思中看出，儿子在世时不得出售或质押土地；但他仍可就该土地订立遗嘱，也可将遗嘱继承人指定为家族外的人。

<!-- source-p 198 -->
<a id="32.38.4"></a>**4.**首席百人队长尤利乌斯·阿格里帕在遗嘱中规定，继承人不得以任何方式质押或转让其遗骸、郊外地产或主要住宅。他的女儿被指定为继承人；女儿又指定自己的女儿，即首席百人队长的外孙女为继承人。外孙女长期占有这些财产后死亡，并指定外人继承。有人问，这些地产应归外人继承人，还是应归曾有尤利乌斯·阿格里帕这位叔祖的尤莉娅·多姆娜。答复说，既然这只是一个没有进一步制裁的命令，就没有事实表明其违反死者意思，因此这些财产归继承人。

<!-- source-p 199 -->
<a id="32.38.5"></a>**5.**某人将一小块土地连同店铺遗赠给其所列名的十五名被释奴，并补充道：“我希望他们依下列条件共同保有、占有该物：任何人均不得将自己的份额出售、赠与或以其他方式处分给他人；若有人违反上述规定，则这些份额、土地或店铺应归图斯库卢姆公有。”其中若干被释奴将自己的份额出售给同一奴隶群体中的两名共同被释奴；买受人死亡后指定外人盖乌斯·塞尤斯为继承人。有人问，已售出的份额应归盖乌斯·塞尤斯，还是归未出售份额的其他在世共同被释奴。答复说，根据所述情况，应归盖乌斯·塞尤斯。又问，已售份额是否应归图斯库卢姆公有。我答复说，不应归公有。克劳狄乌斯补充说：应考虑买受人的身份，而非现已成为外人的持有人身份；这些买受人属于立遗嘱人允许出售给的人，因此并未发生将遗产信托给图斯库卢姆公有的条件。

<!-- source-p 200 -->
<a id="32.38.6"></a>**6.**某人将二千枚金币遗赠给某人，并托付其诚信，写道：“佩特罗尼乌斯，我请求你将这二千枚金币交给某寺庙的团体。”有人问，该团体后来解散后，遗赠应归佩特罗尼乌斯，还是应留在继承人手中。答复说，佩特罗尼乌斯有权请求该款，尤其是在未能遵行死者意思并非由他造成的情况下。

<!-- source-p 201 -->
<a id="32.38.7"></a>**7.**某母亲指定儿子为继承人，并补充道：“我希望他们不得以任何理由转让从我的遗产取得的土地，而应将其保留给自己的继承人；他们还应就此相互提供担保。”有人问，是否可依据这些文字认为设立了遗嘱信托。答复说，所述事实并未表明设立遗嘱信托。

<!-- source-p 202 -->
<a id="32.38.8"></a>**8.**某人指定一人为二分之一继承人，并将一块土地以先取遗赠方式留给他，随后请求他：“我请求你允许你的共同继承人、我的真孙子克洛狄乌斯，与你共同取得我尤利乌斯土地中的份额；该土地是我另行命令你先取的。”有人问，孙子是否可基于遗嘱信托取得土地的一部分。答复说，应当给付。

<a id="32.39"></a>**32.39**

<!-- source-p 204 -->
**斯凯沃拉：《学说汇纂》第二十卷。**

<!-- source-p 205 -->
<a id="32.39.pr."></a>**序言。**遗嘱写道：*“此外，我希望给我的被释奴潘菲鲁斯一百枚金币，数额超过我在遗嘱补编中留给他的部分。我深知，我留给你的所有财物，潘菲鲁斯，最终都会归我儿子们取得，因为我十分了解你对他们的感情。”*我问：根据上述文字，潘菲鲁斯是否受遗嘱信托约束，须在立遗嘱人死亡后向其儿子返还一百枚金币？答复说，根据所述事实，就立遗嘱人文字本身而言，不能认为潘菲鲁斯受托返还一百枚金币；但被释奴若欺骗死者的意思，显然十分不人道，因此留给他的这一百枚金币应返还给立遗嘱人的儿子；在类似情形下，我们的皇帝、神圣的马可也曾作出此项规定。

<!-- source-p 206 -->
<a id="32.39.1"></a>**1.**有人提出如下事实：一名没有子女或亲属的人病重垂危，召来朋友，对其同居伴侣盖乌斯·塞尤斯说，自己希望将所指明的土地留给他；所说事项由盖乌斯·塞尤斯记录为证，并当面询问立遗嘱人是否确曾如此说；立遗嘱人回答“*malista*”（确实如此），该答复也记入文书。有人问，指定土地是否应基于遗嘱信托归盖乌斯·塞尤斯。答复说，对此毫无疑问，遗嘱信托有效。

<!-- source-p 207 -->
<a id="32.39.2"></a>**2.**某人指定两名女儿各继承一半，将一块土地先取遗赠给其中一人，并请求她给妹妹二十枚金币；他还请求该女儿将土地的一半返还给妹妹。有人问，二十枚金币是否仍须给付。我答复说，无须给付。

<a id="32.40.pr."></a>**序言。**一名女子被解除父权后，由其叔父作为法定继承人接纳；她请求叔父将一部分遗产及两块土地给她的舅父。她的继承权又通过遗产占有归属于叔父和舅父二人，因为他们均为最近的亲属。有人问：遗产份额并未设立遗嘱信托，舅父本来可以依据自己的权利通过遗产占有取得该份额，那么他是否仍可取得土地的一半，从而使提提乌斯能够请求两份土地份额：一份是他依据遗产占有自行取得的，另一份是基于遗嘱信托取得的？答复说，他可以请求。又问，若她还向同一叔父为他人设立遗嘱信托，叔父应全部履行还是按份额履行？答复说，应全部履行。

**斯凯沃拉：《学说汇纂》第二十二卷。**

<!-- source-p 214 -->
<a id="32.41.pr."></a>**序言。**某人指定妻子和共同的儿子为继承人，并托付妻子的诚信，写道：“女主人、我的妻子，我请求你不要主张提提安努斯土地中有你的一份；你知道，整块土地是我出资购买的，只是出于我对你的爱与情义，我才将用自己的钱买下的土地与你分享。”有人问，他是否意在使该土地全部归儿子所有。答复说，立遗嘱人意在将该土地视同全部属于遗产；因此，妻子和儿子各应按二分之一份额，将该土地作为遗产取得。

<!-- source-p 215 -->
<a id="32.41.1"></a>**1.**遗嘱一处写道：“我希望将我的房屋连同相连的花园交给我的被释奴。”另一处又写道：“我希望我的继承人将我的房屋中我居住的那间居室（*diaeta*），以及与之相连的储藏室，交给我的被释奴福图尼乌斯；该房屋已遗赠给我的被释奴。”有人问，尽管整幢房屋已先取遗赠给被释奴，立遗嘱人的继承人是否仍须履行对福图尼乌斯的遗赠。答复说，继承人不负有该项负担。

<!-- source-p 216 -->
<a id="32.41.2"></a>**2.**立遗嘱人以遗嘱补编确认并规定：“我将男女伴侣及其子女遗赠给我所有的被释奴，包括我生前已释放、在本遗嘱补编中释放或此后将释放的被释奴；但遗嘱中我已表示应归我妻子所有，或已明确遗赠给她的伴侣及子女除外。”此后，他又请求继承人以遗嘱信托将翁布里亚、图西亚和皮凯努姆地区的财产返还给其妻，连同当地一切财物、乡村及城市奴隶和管理人，但已释放的奴隶除外。有人问：奴隶埃罗斯和斯提库斯在立遗嘱人死亡前一直在翁布里亚和皮凯努姆管理事务，而他们是达马的亲生子女；达马是立遗嘱人生前释放的奴隶。这些子女应依据遗嘱补编交给其亲生父亲达马，还是应依据书信中的文字归妻子塞娅？答复说，根据遗嘱补编，出于自然亲情的考虑，他们应归其亲生父亲。

<!-- source-p 217 -->
<a id="32.41.3"></a>**3.**立遗嘱人将加尔吉利乌斯土地连同房屋遗赠给自己已释放的费利基西穆斯和费利基西玛；另将四分之一遗产指定给其子提提乌斯，并先取遗赠给他，文字如下：“儿子提提乌斯，此外，你还应从共有财产中先取我父亲在世时以及你父亲的兄弟科埃利乌斯·尤斯图斯留给我的遗赠。”有人问：加尔吉利乌斯土地是由立遗嘱人的丈夫——亦即提提乌斯之父——遗赠给她的；现依据遗嘱信托，该土地应给谁：仅给儿子提提乌斯，还是给费利基西穆斯和费利基西玛，抑或三人均得？答复说，不能认为立遗嘱人原本只给费利基西穆斯和费利基西玛留下她明确遗赠的物品，却又以概括措辞将该遗赠转给儿子；她还给儿子留下了自己遗产的一部分。

<!-- source-p 218 -->
<a id="32.41.4"></a>**4.**某人在遗嘱中如此遗赠奴隶：“我希望我的继承人将我自己的五名奴隶交给我的小主人普布利乌斯·梅维乌斯；这些奴隶应是在七岁以下的。”立遗嘱数年后，他死亡。有人问，应给梅维乌斯哪一年龄段的奴隶：立遗嘱时未满七岁的，还是死亡时未满七岁的？答复说，应按遗赠人留下奴隶时的年龄确定。

<!-- source-p 219 -->
<a id="32.41.5"></a>**5.**立遗嘱人以如下文字将土地遗赠给姘居伴侣：“我希望将阿庇亚大道旁的土地连同其管事、管事的伴侣及子女一并给付。”有人问，立遗嘱人是否也意在将管事及其伴侣的孙辈一并给姘居伴侣。答复说，没有理由认为这些孙辈不应给付。

<!-- source-p 220 -->
<a id="32.41.6"></a>**6.**遗嘱人通过遗嘱信托如此遗赠给梅维乌斯家族的人：“此外，将我在故乡加迪斯所拥有的一切给他们。”有人问，如果他还拥有邻近的郊外地产，该地产是否也应依据遗嘱信托给付给梅维乌斯家族的人。答复说，这一文字可以扩及该地产。又问：如果死者在故乡或其境内经营债权账簿，而账簿凭证留在他故乡的住宅中，这些账簿是否也依据上述文字属于遗嘱信托？答复说，不属于。又问，在加迪斯住宅的箱中发现的金钱，或从不同债务人处收回并存放于该处的金钱，是否应依据遗嘱信托给付？答复说，适用前述答复。

<!-- source-p 221 -->
<a id="32.41.7"></a>**7.**某人在遗嘱中指定儿子和妻子为继承人，并通过遗嘱信托给女儿遗赠一百枚金币，条件是她嫁入家族；他补充规定：“女儿，我托付你的诚信：每当你嫁入家族时，你都应允许你的兄弟和母亲塞娅分别就你所给付嫁资的一半作出要约；如果你在婚姻存续期间，或离婚后、嫁资尚未返还或就此提供清偿前死亡，且未留下与该丈夫所生的子女，那么你兄弟和母亲塞娅各自应取得其中一半。”父亲将未婚的女儿嫁出并为她给付嫁资；离婚后，他取回嫁资，又使她带着嫁资改嫁，并约定该嫁资返还给自己或女儿。女儿在第二次婚姻存续期间，父亲死亡，仍留下同一遗嘱；其儿子和妻子成为继承人。后来第二任丈夫死亡，女儿成为家母（*mater familias*）并取回嫁资，随后在兄弟和母亲在场并同意的情况下再嫁他人；母亲还增加了女儿的嫁资，但兄弟和母亲都未要求对方作出返还嫁资的要约。不久，母亲死亡，儿女继承其遗产；后来女儿在婚姻存续期间死亡，其丈夫为继承人。有人问：女儿并非以遗赠名义从父亲的继承人取得嫁资，而是在第二任丈夫死亡后成为家母并取回嫁资；她的继承人是否应基于遗嘱信托向她已故兄弟的继承人给付一笔款项，即假如她曾要求对方作出嫁资返还要约时本可取得的金额？答复说，根据所述事实，不负有给付义务。

<!-- source-p 222 -->
<a id="32.41.8"></a>**8.**某人的继承人或受遗赠人受嘱托收养某人，并附加以下文字：“若不如此办理，即丧失继承资格”或“即丧失遗赠”。有人问：若其未收养，被收养人能否依据遗嘱信托提起某种诉讼？答复说，要求某人收养他人的遗嘱信托无效。

<!-- source-p 223 -->
<a id="32.41.9"></a>**9.**遗嘱写道：“我希望将位于该地区的一块土地转让给梅维乌斯、普布利乌斯和盖乌斯；价款应由公正之人评定并计入遗产；其他继承人应承诺双倍返还瑕疵担保，并以一百枚金币为罚金，保证该土地或其任何部分不会以任何方式归于塞尤斯或其后代。”有人问：普布利乌斯愿意购买而盖乌斯不愿意时，该遗赠是否有效？答复说，愿意请求履行遗嘱信托的人，即使另一人不愿请求，也可以请求该遗赠土地的一半。又问，依照立遗嘱人的意思，应由各继承人按何种份额提供应作的担保？答复说，应按遗嘱信托实际履行的份额提供。

<!-- source-p 224 -->
<a id="32.41.10"></a>**10.**某人将遗嘱中列名的奴隶遗赠给其姐妹，并托付其诚信，要求她死亡时将同一批奴隶返还给自己的儿子。有人问，遗赠后新生的奴隶子女是否也应在受遗赠人死亡后返还给死者的儿子，还是应由受遗赠人的继承人保有。答复说，之后出生的奴隶不在遗嘱信托文字所包含的范围内。

<!-- source-p 225 -->
<a id="32.41.11"></a>**11.**某女子的生父依据其丈夫的遗嘱，负有对她履行遗嘱信托的义务。女子另嫁他人时，生父未经她委托，向其丈夫给付嫁资，并约定若女儿无子女而死，丈夫须将嫁资返还给自己。女子后来生下一名女儿。有人问，她能否向父亲请求履行遗嘱信托。答复说，如果她未认可所给付的嫁资，仍可请求履行遗嘱信托。又问，若父亲希望依据该要约免除债务，是否应拒绝女子行使遗嘱信托请求权。答复仍如上述；如果该父亲给付嫁资时是为了让女儿认可，便可以提起返还之诉。

<!-- source-p 226 -->
<a id="32.41.12"></a>**12.**某人指定丈夫塞尤斯为继承人，并指定其受养女阿庇娅为替补继承人；她托付继承人的诚信，要求塞尤斯死亡后将遗产返还给阿庇娅；如果阿庇娅先发生死亡等情形，则将同一遗产返还给其兄弟之子瓦莱里安努斯。有人问：若塞尤斯在世时已将从遗产中取得的一切返还给阿庇娅，是否符合死者意思，尤其是阿庇娅也被指定为替补继承人？答复说，如果阿庇娅先于塞尤斯死亡，塞尤斯仍未因此免除对瓦莱里安努斯所负的遗嘱信托义务。

<a id="32.41.13"></a>**13.**斯凯沃拉答复说：若遗嘱指定的继承人受嘱托在其愿意时将遗产返还给他人，在此期间不得强迫其履行遗嘱信托。克劳狄乌斯补充说：因为可以认为，遗产是留待继承人死亡后才给付。

<!-- source-p 228 -->
<a id="32.41.14"></a>**14.**某人托付其指定继承人的诚信，要求其将全部遗产返还给妻子塞娅；他又托付妻子的诚信，写道：“塞娅，我请求你将从我的遗产中取得的一切（除我以上遗赠给你的任何物品外）全部交付并返还给最亲爱的幼女梅维娅。我禁止向她要求担保，因为我知道她只会使财产增益，不会造成损害。”有人问，梅维娅能否立即向塞娅请求履行遗嘱信托。答复说，没有理由认为她不能请求。

<a id="32.47.pr."></a>**序言。**如果某人在迎娶妻子之前购置了某些物品，后来将其交给妻子使用，就如同婚后为她备办的一样。妻子根据该项遗赠取得那些为她购买、购置并保留下来的物品；其中也包括原属于前妻、女儿、孙女或儿媳的物品。

<!-- source-p 247 -->
<a id="32.47.1"></a>**1.**有人问，“购买”与“备办”有何区别。答复说，购买之物必然属于备办之物，但备办之物不一定是购买所得。例如，某人将原为前妻购买的物品交给后妻，这些物品可以说是为后妻备办的，却不是为后妻购买的。因此，即使丈夫没有为后妻购买任何物品，他将自己此前已有的物品交给后妻，也视为为她备办。即使未特别指定给她，这些物品也属于遗赠；但原为前妻备办的物品，只有指定给后妻时才应给她，因为购买这些物品时并未考虑后妻。

<!-- source-p 249 -->

<a id="32.49"></a>**32.49**

<!-- source-p 252 -->
**乌尔比安：《萨比努斯评注》第二十二卷。**

<!-- source-p 253 -->
<a id="32.49.pr."></a>**序言。**此项遗赠还包括奴隶，例如只负责抬举女主人的轿夫；也包括牲畜、轿子、坐椅及驮骡；还包括其他奴隶，例如妇女用来装扮自己的梳妆女仆。

<!-- source-p 254 -->
<a id="32.49.1"></a>**1.**如果某人赠给她若干男用物品，这些物品也可以说是为她备办。

<!-- source-p 255 -->
<a id="32.49.2"></a>**2.**同样，如果某些物品本属共同使用，而丈夫惯常向她借用、由她使用，也应认为这些物品是为她备办的。

<!-- source-p 256 -->
<a id="32.49.3"></a>**3.**此外，遗赠给她的是为她备办的物品，还是为她购买的物品，也有区别。前者包括所有指定供她使用的物品；后者则仅包括丈夫因她而购买的物品。因此，如果遗赠仅限于购买之物，家父因其他原因购置、后来指定供她使用的物品不在其中；但无论何种遗赠，都包括丈夫曾委托他人购买，或已自行购买却尚未交给她、若仍在世便会交给她的物品。

<!-- source-p 257 -->
<a id="32.49.4"></a>**4.**无论遗赠给妻子还是姘居伴侣，为其需要而购买、备办的物品均适用此规则；除二者身份地位不同外，法律上确无其他区别。

<!-- source-p 258 -->
<a id="32.49.5"></a>**5.**如果为妻子备办的黄金遗赠给她，后来黄金被熔化，但其材料仍然存在，则该物仍应给她。

<!-- source-p 259 -->
<a id="32.49.6"></a>**6.**普罗库鲁斯写道，为使该遗赠有效，受遗赠人在立遗嘱人死亡时必须仍是其妻；此说正确，因为分居会使遗赠失效。

<!-- source-p 260 -->
<a id="32.49.7"></a>**7.**“为其需要而备办的物品”这一遗赠可以留给儿子、女儿、男奴或女奴；遗赠范围包括分配给他们或指定供他们使用的物品。

<a id="32.50"></a>**32.50**

<!-- source-p 262 -->
**乌尔比安：《萨比努斯评注》第二十三卷。**

<!-- source-p 263 -->
<a id="32.50.pr."></a>**序言。**如果遗赠给家子，并规定“在他达到自主管理之时”（*cum is in tutelam suam pervenerit*），所指的是达到青春期。确实，如果遗赠给未达青春期的家子，通常应依萨比努斯之说理解为，他须达到成年，而非成为家父。另一方面，如果一名母亲怀疑已与其离婚的丈夫会危害生命，即使儿子尚未达到青春期，她仍将遗赠留给儿子，则不应认为她只指儿子达到青春期之时，而应认为她指儿子既达到青春期、又成为家父之时；因为即使儿子已经成年，也更应如此解释，如同她写道：“达到自主管理并取得自己的权力。”

<!-- source-p 264 -->
<a id="32.50.1"></a>**1.**如果遗赠给一名尚未成年、但已是家父并处于自主管理之下的人，则遗嘱人指的是其达到青春期；若遗嘱人的意思表明如此，有时也可能指二十五岁。因为如果遗赠给已达到青春期但未满二十五岁的人，毫无疑问，所定期限就是二十五岁。
