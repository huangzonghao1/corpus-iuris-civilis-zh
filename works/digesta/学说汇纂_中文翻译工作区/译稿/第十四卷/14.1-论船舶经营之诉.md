## 14.1.0　论船舶经营之诉（*De exercitoria actione*）

### <a id="14.1.1"></a>14.1.1　乌尔比安《评告示》第二十八卷

<a id="14.1.1.pr."></a>

**序言（pr.）** 无人不知本告示的实用价值。有时，为航行之需，我们会与船长订立契约，却不知道其身份状况或为人如何；因此，由任命船长上船的人承担责任，是公平的，正如任命店铺或企业经理的人须承担责任一样。与店铺经理相比，与船长订约的必要性更大。毕竟，人们尚可查明店铺经理的身份，再决定是否与其订约；对于船长则并非如此，因为地点、时间等情形有时不允许人们从容周详地考虑。

<a id="14.1.1.1"></a>

**1.** 我们所说的船长，是指受托负责管理整艘船舶的人。

<a id="14.1.1.2"></a>

**2.** 但是，如果交易是与任何一名船员订立的，就不授予针对船舶经营人的诉权；不过，对于船上任何一名为航行而服务之人的不法行为，仍可针对船舶经营人提起诉讼。因为订约的原因与实施不法行为的原因不同：任命船长的人允许他人同船长订约；雇用船员的人并未允许他人同船员订约，但应确保船员没有过失或故意欺诈。

<a id="14.1.1.3"></a>

**3.** 任命船长，是为了出租船舶以承运货物，或者招揽乘客乘船，或购买船具；即使其受任购买或出售货物，就此所订立的契约也会使船舶经营人承担责任。

<a id="14.1.1.4"></a>

**4.** 船长的身份状况无关紧要：无论其为自由人还是奴隶，无论属于船舶经营人还是他人，均不影响；其年龄也无关紧要，因为任命他的人应自行承担由此产生的后果。

<a id="14.1.1.5"></a>

**5.** 我们所说的船长，不仅包括船舶经营人任命的人，也包括由另一名船长任命的人。尤利安经询问后，就船舶经营人不知情的情形作出了这一答复。不过，如果船舶经营人知情，并容许此人在船上担任船长，则视为船舶经营人亲自任命了他。我认为这一意见合理：既然由我任命此人担任船长，我就应对他的一切行为负责；否则，交易相对人会受欺骗。为航行利益起见，这一规则较之店铺经理的情形更应予以承认。但如果船舶经营人任命船长时规定不得另行任命他人，是否仍应采纳尤利安的意见，尚须考察。例如，他明确禁止使用提提乌斯担任船长。不过，仍应将航行者的利益保护扩展到何种程度，也须判断。

<a id="14.1.1.6"></a>

**6.** 我们所说的船舶，包括海船、河船、在湖泊中航行的船，甚至筏。

<a id="14.1.1.7"></a>

**7.** 裁判官并非基于一切原因都向船舶经营人授予诉权，而仅就船长受任处理的事项授予；例如，船舶受托承运货物，或船长购买航行所需物品，或为修理船舶而订立契约、支出费用，或船员请求支付劳务报酬。

<a id="14.1.1.8"></a>

**8.** 如果船长借入金钱，是否也属于其受任处理的事项？佩加苏斯认为，如果借款是用于其受任事务，就应授予诉权。我认为这一意见正确：例如，船长借款用于装备、整修船舶，或供给船员，难道不属于受任事务吗？

<a id="14.1.1.9"></a>

**9.** 因此，奥菲利乌斯提出这样的问题：船长借款称用于修理船舶，却将钱用于自己事务，是否可对船舶经营人提起诉讼？他说，如果船长受领借款时约定将其用于船舶，后来才改变主意，船舶经营人就应承担责任，因为他应自行承担任命此人的后果。但如果船长从一开始就打算欺骗债权人，而且没有特别说明借款是为了船舶事务，则应作相反处理。佩迪乌斯赞同这一划分。

<a id="14.1.1.10"></a>

**10.** 如果船长在购买物品的价格上欺骗了他人，损失应由船舶经营人承担，而非债权人承担。

<a id="14.1.1.11"></a>

**11.** 如果船长向他人借款，用以偿还曾为修理船舶而提供贷款的人，我认为，也应准许该债权人提起诉讼，视同其为船舶事务提供了贷款。

<a id="14.1.1.12"></a>

**12.** 因此，任命船长时所作的授权，为交易相对人设定了明确范围。如果船舶经营人任命船长仅为收取运费，而非出租船舶——例如船舶经营人本人已将船舶出租——那么船长擅自出租时，船舶经营人不承担责任。反之，如果仅授权出租而未授权收取运费，结论相同。又如，船长只获授权招揽乘客而不得出租船舶承运货物，或反之，超越权限就不使船舶经营人承担责任。若船长只获授权以承运特定货物为条件出租船舶，例如豆类或大麻，却将船舶出租用于运输大理石或其他材料，也应认定船舶经营人不承担责任。有些船是货船，有些船则（人们如此称呼）是客船（*epibatygoi*）。我知道许多人会指示船长不得接载乘客，或者只准在特定地区、特定海域经营。例如，有些船在布伦迪西乌姆与卡西俄佩或狄拉基翁之间运送乘客，却不适于载货；另有一些船只能在河流中航行，不能驶入海中。

<a id="14.1.1.13"></a>

**13.** 如果有多名船长而未划分职责，他们中任何一人与他人所作的交易都会使船舶经营人承担责任；如果职责已经划分，例如一人负责出租，另一人负责收取运费，则船舶经营人依各自职责承担责任。

<a id="14.1.1.14"></a>

**14.** 但是，如果船舶经营人作出如下任命——多数情形下他们如此行事〔底本异文：*plerumque*〕——规定一人不得脱离另一人单独处理任何事务，那么与其中一人订约的人应自行承担后果。

<a id="14.1.1.15"></a>

**15.** 我们所说的船舶经营人，是指所有收益和收入均归其取得的人；无论其是船舶所有人，还是从所有人处以整体方式租得船舶，或按一定期限、永久租得船舶，均属此列。

<a id="14.1.1.16"></a>

**16.** 船舶经营人是男性还是女性，是家父、家子还是奴隶，都无关紧要；但如果受监护的未成年人经营船舶，则须有监护人的认可。

<a id="14.1.1.17"></a>

**17.** 我们可以选择对船舶经营人或船长提起诉讼。

<a id="14.1.1.18"></a>

**18.** 反过来说，对于经营船舶之人向与船长订约的人提起的诉讼，告示并未予以承诺，因为他并不需要同样的救济。他可以基于出租关系对船长提起诉讼——如果船长有偿为其提供劳务；如果是无偿提供，则可以提起委任之诉。显然，粮食供应事务的主管官员，以及行省总督，有时会因船长订立的契约，在特别程序中给予他们救济。

<a id="14.1.1.19"></a>

**19.** 如果经营船舶之人受他人权力支配，并经该权力主体同意而经营船舶，那么就其与船长所作的交易，应授予针对该权力主体的诉讼。

<a id="14.1.1.20"></a>

**20.** 虽然可以针对支配经营船舶之人的权力主体提起诉讼，但仅限于经营船舶确经其同意的情形。支配经营者的人之所以因其同意而承担全部责任，是因为船舶经营关乎公共利益。店铺经理的情形则不同：与在主人知情下以特有产经营的人订约者，仅得参与特有产的分配。但如果与船长订约时，主人仅知情而未同意，我们究竟应如同其已同意那样授予全部责任之诉，还是应依分配之诉的例子处理？在疑难情形下，较妥当的是遵循告示的文字：不得仅因家父或主人单纯知情，便使其对船舶经营承担责任；也不得将特有产营业中要求同意的规则扩展为全部责任。庞波尼似乎也表达了这一意思：如果经营者受他人权力支配，经权力主体同意而经营的，权力主体承担全部责任；否则，仅以特有产为限承担责任。〔底本 *perinet*，疑为 *pertinet*。〕

<a id="14.1.1.21"></a>

**21.** 这里所说的受权力支配，包括男女家子、家女以及男奴、女奴。

<a id="14.1.1.22"></a>

**22.** 但是，如果属于特有产的奴隶，经其特有产归属的家子的同意而经营船舶，或者由该奴隶的代管奴隶经营船舶，那么未表示同意的家父或主人仅在特有产范围内承担责任，而家子本人承担全部责任。显然，如果船舶经营经主人或家父同意，则他们承担全部责任；此外，如果家子本人也表示同意，他也承担全部责任。

<a id="14.1.1.23"></a>

**23.** 虽然裁判官承诺的诉权仅适用于与船长订约的情形，但正如尤利安所写，即使是与船舶经营人本人订约，家父或主人也承担全部责任。

<a id="14.1.1.24"></a>

**24.** 本诉是基于船长这一主体而针对船舶经营人提起的。因此，若已对其中一人提起诉讼，就不得再对另一人提起。但如果已经履行给付，若由船长履行，债务依法即予减少；若由船舶经营人履行，无论其以自己名义——即基于其名誉法上的责任——还是以船长名义履行，债务也会减少，因为他人代我履行也能使我免责。〔底本此处 *datur [datur]* 有重复。〕

<a id="14.1.1.25"></a>

**25.** 如果有多名船舶经营人，可以对其中任何一人请求其承担全部责任，

### <a id="14.1.2"></a>14.1.2　盖尤斯《评行省告示》第九卷

与一人订约的人，不应因此被迫向多个对方分别追索。

### <a id="14.1.3"></a>14.1.3　保罗《评告示》第二十九卷

各人对船舶享有多少份额，并不影响上述规则；先行承担责任的人，可以通过合伙之诉向其他人追偿。

### <a id="14.1.4"></a>14.1.4　乌尔比安《评告示》第二十九卷

<a id="14.1.4.pr."></a>

**序言（pr.）** 但是，如果数人各自经营船舶，他们应按各自经营份额被起诉；因为他们彼此并不被视为对方的船长。〔底本作 *videbuntur*，另见 *videntur*。〕

<a id="14.1.4.1"></a>

**1.** 如果数人共同经营船舶，却从中任命一人担任船长，则可以因该船长的行为而请求他们承担全部责任。

<a id="14.1.4.2"></a>

**2.** 如果数人共有的奴隶经他们同意而经营船舶，应适用多名船舶经营人的规则。显然，如果该奴隶仅经其中一人同意而经营船舶，则该人承担全部责任；因此，我认为，在前一种情形下，所有人也都应承担全部责任。

<a id="14.1.4.3"></a>

**3.** 如果奴隶经主人同意经营船舶，后来被转让，转让奴隶的人仍须承担责任。同样，即使奴隶死亡，其仍须承担责任；正如船长死亡后，责任仍然存在。

<a id="14.1.4.4"></a>

**4.** 这些诉讼不受期间限制，并可对继承人提起，也可由继承人提起。因此，即使经主人同意经营船舶的奴隶已经死亡，经过一年后仍可提起本诉，尽管特有产之诉超过一年后即不得提起。

### <a id="14.1.5"></a>14.1.5　保罗《评告示》第二十九卷

<a id="14.1.5.pr."></a>

**序言（pr.）** 如果你任命处于我权力之下的人担任船长，那么我也可以就我与其订立的契约对你提起诉讼；如果该奴隶为我与你共有，结论也相同。不过，由于你租用了我奴隶的劳务，你可以对我提起劳务租赁之诉；因为即使他与他人订约，你也可以对我主张：我应向你提供我因此取得的诉权。这与雇用自由人的情形相同。如果你有偿雇用其劳务，可以提起相应诉讼；如果劳务无偿提供，则可以提起委任之诉。

<a id="14.1.5.1"></a>

**1.** 同样，如果我的奴隶经营船舶，而我与该船的船长订约，并不妨碍我依据市民法或裁判官法赋予我的诉权对船长起诉。任何其他人也可以提起此类诉讼；本告示并未移转原有诉权，而是在其上增加一项诉权。

<a id="14.1.5.2"></a>

**2.** 如果数名船舶经营人中的一人与船长订立契约，他可以对其他船舶经营人提起诉讼，

### <a id="14.1.6"></a>14.1.6　保罗《简要论集》第六卷

<a id="14.1.6.pr."></a>

**序言（pr.）** 如果奴隶未经主人同意而经营船舶，但主人知情，应给予类似分配之诉的救济；如果主人不知情，则应给予特有产之诉。

<a id="14.1.6.1"></a>

**1.** 如果共有奴隶经各共有人同意而经营船舶，应分别对每名共有人授予全部责任之诉。

### <a id="14.1.7"></a>14.1.7　阿非利卡努斯《疑问集》第八卷

<a id="14.1.7.pr."></a>

**序言（pr.）** 卢基乌斯·提提乌斯任命斯提库斯担任船长。斯提库斯借入金钱，并以要式口约承诺该款用于修理船舶。问题是：是否只有债权人证明借款确实用于修船，才能依据船舶经营之诉追究提提乌斯的责任？答复是，如果出借款项时船舶处于应予修理的状态，债权人即可以有效提起诉讼。因为不应要求债权人亲自承担修船事务、代替主人处理事务——若必须证明借款确已用于修理，就会导致这种结果。另一方面，必须要求债权人知道其所贷之款，是借给受任处理相关事务的船长；而这只有在债权人也知道船舶确有修理必要时才可能。因此，即使船舶确有修理必要，但所贷金额远超修理所需，也不应准许债权人对船舶所有人请求承担全部责任。

<a id="14.1.7.1"></a>

**1.** 有时还应考察借款是否发生在可以购买所需物品的地点。比如，有人为了购买船帆而在根本买不到船帆的岛上借款，情形会如何？总之，债权人对此应尽一定注意。

<a id="14.1.7.2"></a>

**2.** 他说，如果讨论的是店铺经理诉权，也大致应作相同处理：债权人应知道购买货物确有必要，而奴隶正是受任负责购买货物的人。只要债权人是为此目的提供借款，就已足够；不应再要求债权人亲自查明该项支出是否确有必要。
