## 14.5.0　论与受他人权力支配者订立交易之诉（*Quod cum eo, qui in aliena potestate est, negotium gestum esse dicetur*）

### <a id="14.5.1"></a>14.5.1　盖尤斯《评行省告示》第九卷

总督采取一切措施，使与受他人权力支配者订立交易的人，即使不能适用前述诉权——也就是船舶经营之诉、店铺经理之诉或分配之诉——仍能在公平合理所允许的范围内取得救济。如果交易是经支配该人的权力主体命令而订立的，总督就此承诺一项要求其承担全部责任的诉讼；如果并非依命令订立，但所得利益转入该权力主体的财产，则仅在该利益转入的范围内引入诉权；如果两种情形均不存在，则设立特有产之诉。

### <a id="14.5.2"></a>14.5.2　乌尔比安《评告示》第二十九卷

<a id="14.5.2.pr."></a>

**序言（pr.）** 裁判官说：“对于已被解放出家父权或被剥夺继承权的人，以及在某人死亡时原受该人权力支配、后来放弃该人遗产的人，就其仍受权力支配时与他订立的交易，无论他是自行决定订约，还是经支配他之人的命令订约；无论交易所得被转入其特有产，还是被转入支配他之人的财产，经审查案件后，我都将授予诉讼，但以其力所能及的范围为限。”

<a id="14.5.2.1"></a>

**1.** 即使某人并未经过解放程序便取得自权人身份，或被收养进入他人家族，随后其生父死亡；又或者他仅被指定继承极小份额，也极为公平，应经审查案件后对其授予诉讼，但以其力所能及的范围为限。

### <a id="14.5.3"></a>14.5.3　乌尔比安《论辩集》第三卷

还可以讨论，是否应从其可承担的数额中扣除其对其他人的债务。如果有些债权人是在他仍受他人权力支配时与他订约的，较妥当的意见是，先行主张者处于较优地位；除非出现享有优先权的债权人，因为优先权人的请求理应先予考虑。相反，如果有些债权人是在他取得自权人身份后才与他订约，我认为应当考虑这些债权人的请求。

### <a id="14.5.4"></a>14.5.4　乌尔比安《评告示》第二十九卷

<a id="14.5.4.pr."></a>

**序言（pr.）** 如果儿子被指定为遗产的非微小份额继承人，债权人可以自行选择：按照其继承份额对他起诉，或者要求他承担全部责任。不过，法官也应进行估量，判断是否应仅在他力所能及的范围内判令其承担责任。

<a id="14.5.4.1"></a>

**1.** 有时，即使儿子已被剥夺继承权或解放出家父权，也应准许对其提起要求全部责任的诉讼。例如，他在订约时谎称自己是家父。马尔凯鲁斯在《学说汇纂》第二卷中写道，即使他无力履行，也应因其欺诈而对其起诉。

<a id="14.5.4.2"></a>

**2.** 虽然基于契约对他提起的诉讼仅以其力所能及的范围为限，但因不法行为对其起诉，则可要求他承担全部责任。

<a id="14.5.4.3"></a>

**3.** 仅对儿子本人给予救济，不及于其继承人；然而，帕皮尼安在《疑问集》第九卷中也写道，应准许对儿子的继承人提起要求全部责任的诉讼。

<a id="14.5.4.4"></a>

**4.** 是否也应考虑时间因素？如果在儿子取得自权人身份后立即对他起诉，应准许诉讼仅及于其力所能及的范围；但如果许多年后才起诉，是否不应再给予宽宥？我认为应当考虑时间，因为案件审查正取决于此。

<a id="14.5.4.5"></a>

**5.** 某人本可提起基于命令的诉讼，却选择提起特有产之诉，此后便不得再提起基于命令的诉讼；普罗库鲁斯持此意见。但如果他是受骗而提起特有产之诉，凯尔苏斯认为应予救济；这一见解有其道理。

### <a id="14.5.5"></a>14.5.5　保罗《评告示》第三十卷

<a id="14.5.5.pr."></a>

**序言（pr.）** 如果家子在其父尚在世时被起诉并被判决承担责任，那么在其后来被解放出家父权或被剥夺继承权后，应准许对其提起判决之诉，但以其力所能及的范围为限。

<a id="14.5.5.1"></a>

**1.** 如果依据《特雷贝利安元老院决议》，被剥夺继承权的儿子受领了父亲的遗产返还，就不应仅在其力所能及的范围内判令其承担责任，而应判令其承担全部责任，因为他在事实上已成为继承人。

<a id="14.5.5.2"></a>

**2.** 但是，如果他是在受迫情况下介入并受领遗产返还，则应如同其放弃继承一样处理。

### <a id="14.5.6"></a>14.5.6　乌尔比安《论辩集》第二卷

马尔凯鲁斯写道，某人假冒家父身份，并应他人委托作出要式允诺，即使无力履行，也应依委任关系承担责任。此说确属正确，因为他实施了欺诈。所有诚信诉讼中也应适用这一规则。

### <a id="14.5.7"></a>14.5.7　斯凯沃拉《答复集》第一卷

父亲允许儿子借入金钱，并写信给债权人，委托其向儿子放款。儿子仅作为父亲遗产的极小份额继承人。我答复说，债权人可以选择：要求其所放款的儿子承担全部责任，或者按照各继承人的继承份额向他们起诉；但对儿子本人只能在其力所能及的范围内判决承担责任。

### <a id="14.5.8"></a>14.5.8　保罗《裁决集》第一卷

提提阿努斯·普里穆斯起初任命一名奴隶负责借贷和收取质物。该奴隶还经常代替购买者承接大麦商人的债务并予以清偿。奴隶逃走后，一名受托支付大麦价款的人以店铺经理之诉为由起诉主人；主人辩称，自己不应因此被诉，因为该奴隶并未受任处理此类事务。然而，证据表明，该奴隶还处理过其他事务、租赁过仓库并向许多人付款，于是粮食供应长官作出对主人不利的判决。我们的意见是：奴隶替他人清偿债务时，看起来相当于作了保证；但他为他人承接债务时，不应据此认定主人也承担责任。通常不得基于这种原因对主人授予诉权，而且看来主人也没有授权该奴隶如此行事。但是，由于该奴隶似乎在所有事务中都以主人的名义行事，皇帝维持了该判决。
