# D.14.2　论罗得海法抛货

<a id="2"></a><a id="14.2"></a>

## 14.2.0　论罗得海法的抛货规则（*De lege Rodia [Rhodia] de iactu*）

### <a id="14.2.1"></a>14.2.1

*保罗《格言集》第二卷*

**正文：** 罗得海法（*lex Rhodia*）规定：为减轻船舶而抛弃货物的，应由全体分担为众人利益而付出的损失（*iactus*）。

### <a id="14.2.2"></a>14.2.2

*保罗《评告示》第三十四卷*

<a id="14.2.2.pr."></a>**序言（pr.）**：若船舶遇险时发生抛货，丢失货物的所有人如曾委托承运其货物，应对船舶经营人提起租赁之诉（*actio ex locato*）；船舶经营人随后可以对其他货物获救的人提起雇用之诉（*actio ex conducto*），要求其按比例分担损失。塞尔维乌斯曾答复说，货物丢失的所有人应对船舶经营人提起租赁之诉，使其扣留其他乘客的货物，直到他们支付各自应分担的损失份额。实际上，即使船舶经营人“没有”扣留货物，他也可以主动对乘客提起租赁之诉：毕竟，乘客中也可能有人没有任何行李。显然，如果乘客有货物，扣留货物更为妥当。但如果委托承运的并非整艘船，则船舶经营人应提起雇用之诉，正如只租用了船上舱位的乘客一样。因为凡因他人财物丢失而得以保全自己货物的人，共同分担损失最为公平。

<a id="14.2.2.1"></a>**1.** 若货物获救而船舶本身受损，或者船上的装备被拆除，就不应进行分摊，因为为船舶本身准备的物品，与某人收取报酬承运的物品，性质不同。比如，工匠折断了砧或锤，不应将此归责于雇用其工作的委托人。但是，如果损害是应乘客的要求，或因某种危险而造成的，则应补偿该损失。

<a id="14.2.2.2"></a>**2.** 若数名商人把不同种类的货物装在同一艘船上，另有许多自由人和奴隶乘船，遇到猛烈风暴而不得不抛货，随后便产生以下问题：是否所有人都必须分担损失？如果有人装载了不会使船舶超载的货物，例如宝石、珍珠，也须分担吗？各自应承担多少份额？是否也应就自由人的人身承担给付？应通过何种诉讼解决？法学家认为，凡有利害关系者都应分担，因为其货物获救应负担这项费用；因此，船主也应按份承担。抛弃货物的总额，应按各项财物的价值分配。自由人的人身不得估价。丢失货物的所有人应对船员，也就是船舶经营人，提起雇用之诉。人们还讨论，是否应估价各人的衣物和戒指；结论是都应计入，除非某些货物是供消耗之用，例如食物。尤其是航行途中食物耗尽时，每个人都应把自己所有的食物拿出来共同使用。

<a id="14.2.2.3"></a>**3.** 若船舶被海盗赎回，塞尔维乌斯、奥菲利乌斯和拉贝奥认为，全体应共同分担赎金；但海盗掠走的财物，由其所有人自行承担损失；即使有人赎回了自己的货物，也不得要求他人分担该项损失。

<a id="14.2.2.4"></a>**4.** 通常应根据获救财物和丢失财物的估价，按比例承担相应份额。丢失的财物即使可能卖得更高的价钱，也不影响此规则，因为所补偿的是损失，而非利润。但就应参与分摊的财物而言，估价应依其可售价格，而非购买价格。

<a id="14.2.2.5"></a>**5.** 在海中丧生的奴隶也不应估价；这与在船上患病死亡或自行投海的人一样。

<a id="14.2.2.6"></a>**6.** 若某名乘客无力偿付，该损失不由船舶经营人承担；船员没有义务查明每个人的财产状况。

<a id="14.2.2.7"></a>**7.** 若被抛弃的财物后来找到，就免除分摊义务；若已经完成分摊，已付款者可以对船舶经营人提起租赁之诉，使船舶经营人通过雇用之诉追偿，并返还其所收取的款项。

<a id="14.2.2.8"></a>**8.** 被抛弃的财物仍归原所有人所有，不因他人拾得而转归拾得者，因为该财物并不被视为已抛弃。

### <a id="14.2.3"></a>14.2.3

*帕比尼安《答复集》第十九卷*

**正文：** 为排除共同危险而移除树木或其他船舶设备的，应当进行分摊。

### <a id="14.2.4"></a>14.2.4

*卡利斯特拉图《疑义集》第二卷*

<a id="14.2.4.pr."></a>**序言（pr.）**：满载货物的船舶因载荷过重而无法驶入河流或港口，于是将部分货物转移到小艇上，以免船舶在河外或河口、港口处遇险；但小艇沉没了。对于留在大船上、货物获救的人与货物在小艇上丢失的人，应当进行分摊，犹如发生了抛货；萨宾在《答复集》第二卷中也认可这一点。反之，如果小艇连同部分货物获救而大船沉没，则大船上货物丢失的人之间不应进行分摊，因为只有船舶获救时，抛货损失才计入共同分摊。

<a id="14.2.4.1"></a>**1.** 若一艘船在风暴中因抛弃一名商人的货物而减轻载荷，却在另一地点沉没，之后潜水员收取报酬，打捞出部分商人的货物，萨宾也答复说：后来由潜水员救回自己货物的人，应向航行途中为减轻船舶而被抛弃货物的所有人分担损失。但由潜水员救回货物的人彼此之间，不应与那位在航行中抛货的人相互结算；因为船舶已经沉没，其上的货物不可能被视为为了保全船舶而抛弃。

<a id="14.2.4.2"></a>**2.** 若船上发生抛货，而留在船上的某人的财物因此劣化，应考察是否必须由其参与分摊，因为他不应同时承受分摊损失及财物劣化的双重负担。应当主张，他须按财物现值参与分摊：例如两人的货物原各值二十，其中一人的货物因受水浸而只值十，货物完好者按二十计付，该人的货物则按十计付。然而，也可以采取另一种观点，区分货物劣化的原因：究竟是抛货使货物暴露于损害之中，还是因其他原因，例如货物放在某个角落而海水渗入。后一情形中，他就应参与分摊；但若属于前一种原因，他是否不应承担分摊，因为抛货也损害了他？又或者，若财物因抛货而受水浸劣化，是否也应如此？应当作更细致的区分，比较损害与分摊哪一方更重：例如财物原值二十，分摊额为十，而损害为二，那么扣除其遭受的损害后，他应支付其余部分。那么，如果损害超过分摊额呢？例如财物因劣化而损失十，而分摊额为二。显然，他不应承受双重负担；但此时还要考察他是否仍应参与分摊。因为，我的财物被抛弃而灭失，与我的财物留在船上却因暴露而劣化，两者有何区别？正如应帮助财物丢失的人，也应帮助因抛货而使财物劣化的人。帕皮里乌斯·弗龙托就此作了这样的答复。

### <a id="14.2.5"></a>14.2.5

*赫尔莫革尼安《法律撮要》第二卷*

<a id="14.2.5.pr."></a>**序言（pr.）**：船舶沉没所造成的损失，不应由那些在海难中保全了自己货物的人通过共同分摊予以补偿；因为只有在抛货补救共同危险、船舶因此获救时，才承认这种公平原则。

<a id="14.2.5.1"></a>**1.** 若砍伐树木是为了使船舶连同货物脱险，则适用公平分摊原则。

### <a id="14.2.6"></a>14.2.6

*尤利安《学说汇纂》第八十六卷*

**正文：** 一艘船在风暴中遭遇险情，桅杆、帆具和横桁被雷击焚毁，随后漂抵希波；船上临时拼凑了替代的帆具，继续驶往奥斯提亚，所载货物全部安全运抵。有人询问：货物所有人是否应向船员分担损失。答复是不应，因为这笔支出主要是为了修复船舶，而非为了保全货物。

### <a id="14.2.7"></a>14.2.7

*保罗《阿尔芬努〈学说汇纂〉撮要》第三卷*

**正文：** 船舶沉没或倾覆时，某人从船上救出的物品应归其自己所有，如同从火灾中救出的物品一样。

### <a id="14.2.8"></a>14.2.8

*尤利安《摘自米尼基乌斯》第二卷*

**正文：** 为减轻船舶而抛出物品的人，并无将其作为无主弃物抛弃的意思；因为如果他们找到这些物品，就会带走；如果猜到物品被抛到何处，也会去寻找。其情形犹如某人因负载过重而把物品丢在路上，打算很快带其他人回来取走同一物品。

### <a id="14.2.9"></a>14.2.9

*梅基安努《罗得海法》*

**正文（希腊文原文及底本所附拉丁释文）：**

**希腊文原文（底本以拉丁字母转写）：**

> Aciwsis Eudaimonos Nikomydews pros Antwninon basilea. Kurie basileu Antwnine, naufragion poiysantes en ty Italia diyrpagymen hupo twn dymosiwn twn tas Kukladas nysous oikountwn. Antwninos eipen Eudaimoni. Egw men tou kosmou kurios, ho de nomos tys valassys. Tw nomw twn Hrodiwn krinesvw tw nautikw, en ohis mytis twn hymeterwn autw nomos enantioutai. Touto de auto kai ho veiotatos Augoustos ekrinen.

**译文：** 尼科米底亚人欧戴蒙致皇帝安东尼努斯的请愿书：“陛下，皇帝安东尼努斯，我们在意大利 [更正：应作伊卡里亚] 遭遇海难后，被居住在基克拉泽斯群岛的公职人员 [更正：应作税吏] 掠夺。”安东尼努斯答欧戴蒙：“我固然是天下之主，但海洋自有其法。凡属航海事务，应依罗得海法裁断，只要该法不与我国任何法律相抵触。神圣的奥古斯都也曾作出同样裁决。”

**底本所附拉丁释文：**

> Id est: Petitio Eudaemonis Nicomedensis ad imperatorem Antoninum. Domine imperator Antonine, cum naufragium fecissemus in Italia [ immo in Icaria], direpti sumus a publicis [ immo a publicanis], qui in Cycladibus insulis habitant. Antoninus dicit Eudaemoni. Ego orbis terrarum dominus sum, lex autem maris, lege Rhodia de re nautica res iudicetur, quatenus nulla lex ex nostris ei contraria est. Idem etiam divus Augustus iudicavit.

即：尼科米底亚人欧戴蒙向皇帝安东尼努斯提出请愿：“陛下，皇帝安东尼努斯，我们在意大利 [应作伊卡里亚] 遭遇海难，被居住于基克拉泽斯群岛的公职人员 [应作税吏] 掠夺。”安东尼努斯对欧戴蒙说：“我是天下之主，但海洋遵循其自身法律。航海事务应依罗得海法裁判，只要我国没有与之相抵触的法律。神圣的奥古斯都也曾作出同样裁决。”

### <a id="14.2.10"></a>14.2.10

*拉贝奥《Pithanon》第一卷（保罗节编）*

<a id="14.2.10.pr."></a>**序言（pr.）**：若你租用船舶承运奴隶，对于在船上死亡的奴隶，不应向你收取运费。保罗补充说：应查明双方约定的究竟是按装上船的奴隶人数，还是按运抵的奴隶人数计费；若无法查明，只要船员证明该奴隶曾被装上船，便已足够。

<a id="14.2.10.1"></a>**1.** 若你以承运自己的货物为条件租用船舶，而船员并非出于不得已，且明知你不愿意，仍把货物转装到一艘状况较差的船上；你的货物随后随最后承运它们的那艘船一同灭失，那么你可以基于租赁关系对先前的船员提起诉讼（底本措辞为 *ex conducto locato*）。保罗补充说：相反，若在该航程中两艘船都沉没，且此事并非因船员的欺诈或过失所致，则结论不同。若先前的船员遭公共权力扣留，因而被禁止载着你的货物航行，法律处理也相同。若你与他约定：除非他在指定日期前将货物运至约定地点，否则须向你支付确定的罚金；但未能免除该罚金并非出于他的原因，法律处理也相同。若证明确因船员患病而无法航行，也适用同一规则；若其船舶发生故障，且并非因其欺诈或过失所致，亦同。〔译者按：本段 *nec per eum staret, quo minus remissa sibi ea poena spectaret* 的确切法律效果有待结合语境复核；此处暂按罚金未获免除并非船员所致译出。〕

<a id="14.2.10.2"></a>**2.** 若你租用了一艘可装载两千只双耳陶罐的船，并在船上装运陶罐，就应支付相当于两千只陶罐的运费。保罗补充说：若整艘船按包船方式租用，就应支付两千只陶罐的运费；若运费是按实际装船的陶罐数量约定的，则相反：装运多少只，就应支付多少只的运费。
