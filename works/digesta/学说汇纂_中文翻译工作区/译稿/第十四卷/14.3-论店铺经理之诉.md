## 14.3.0　论经理人之诉（*De institoria actione*）

### <a id="14.3.1"></a>14.3.1　乌尔比安《评告示》第二十八卷

裁判官认为，既然我们可以从经理人（*institor*）的经营活动中获得利益，那么也应因他们所订立的契约而承担责任，并可被起诉。不过，裁判官并未同样允许任命经理人的人提起相应诉讼。如果任命的是自己的奴隶作经理人，任命人可以安心，因为他能够取得相应的诉权；如果任命的是他人的奴隶，甚至是自由人，则任命人可能没有相应诉权。不过，他可以对经理人本人或其主人提起委任之诉或无因管理之诉。马尔凯卢斯则说，应当向任命经理人者提供诉权，使其可以起诉与经理人订约的人。

### <a id="14.3.2"></a>14.3.2　盖尤斯《评行省告示》第九卷

只有在请求人无法以其他方式保全自己的权利时，才可以就经理人所订立的那项交易提起本诉。

### <a id="14.3.3"></a>14.3.3　乌尔比安《评告示》第二十八卷

经理人（*institor*）这一称呼源自他积极经营事务；他是受任管理店铺，还是受任管理其他任何业务，区别并不大，

### <a id="14.3.4"></a>14.3.4　保罗《评告示》第三十卷

因为经理人有时甚至会把货物送到体面人家中出售。出售或购买的地点并不改变诉讼的性质，因为无论哪种情形，经理人都确实从事了购买或出售。

### <a id="14.3.5"></a>14.3.5　乌尔比安《评告示》第二十八卷

<a id="14.3.5.pr."></a>

**序言（pr.）** 因此，无论某人受任管理何种业务，都可以正当地称为经理人。

<a id="14.3.5.1"></a>

**1.** 塞尔维乌斯在《致布鲁图书》第一卷中说，如果某人与公寓楼管理员，或与受任管理房屋的人，或与受任采购谷物的人进行交易，任命人都应对全部债务承担责任。

<a id="14.3.5.2"></a>

**2.** 拉贝奥也写道，如果某人任命经理人经营放贷、耕种土地、贸易或承揽业务，任命人应对全部债务承担责任。

<a id="14.3.5.3"></a>

**3.** 如果某人任命奴隶在钱币兑换柜台经营，也应以任命人的名义承担责任。

<a id="14.3.5.4"></a>

**4.** 人们也同意，应将经理人这一称呼用于服装商或亚麻布商交给衣物、让其携带并出售的人；通常称他们为巡回售货人。

<a id="14.3.5.5"></a>

**5.** 有人也可以适当地把赶骡人称为经理人，

<a id="14.3.5.6"></a>

**6.** 同样，洗衣工和裁缝的受任管理人也属于经理人。马厩经营者也应视为经理人。

<a id="14.3.5.7"></a>

**7.** 拉贝奥写道，如果店主派自己的奴隶到外地购买货物并寄回，也应将该奴隶视为经理人。

<a id="14.3.5.8"></a>

**8.** 拉贝奥还说，如果殡葬业者有一名负责料理尸体的奴隶，而该奴隶盗取死者财物，应准许对其提起类似经理人之诉；尽管也可以提起盗窃之诉和侵害之诉。

<a id="14.3.5.9"></a>

**9.** 同一位拉贝奥说，如果面包师惯常派奴隶到特定地点出售面包，后来奴隶收取现钱，答应每天向付款人交付面包，却破产了；只要面包师允许如此预收款项，就毫无疑问应由面包师承担责任。

<a id="14.3.5.10"></a>

**10.** 洗衣工到外地去时，请人指挥自己留下的学徒；他把设备齐全的店铺交给这些学徒经营。洗衣工离开后，一名学徒收走衣物逃跑。如果该学徒只是以代理人身份留下，洗衣工不承担责任；如果他是以经理人身份留下，洗衣工就应承担责任。不过，如果洗衣工曾向我保证可以放心把衣物交给他的工人，就不应提起经理人之诉，而应提起租赁之诉。

<a id="14.3.5.11"></a>

**11.** 但是，与经理人所做的一切交易并非都使任命人承担责任；只有交易属于经理人受任管理的业务时，任命人才承担责任，也就是说，责任仅限于任命其经营的事项。

<a id="14.3.5.12"></a>

**12.** 因此，如果我任命经理人出售货物，交易相对人就可以依买受人之诉（*actio empti*）对我起诉；如果我任命他购买货物，则只能依出卖人之诉（*actio venditi*）对我起诉。反之，若他受任购买却出售，或受任出售却购买，我就不应承担责任；卡西乌斯也赞同这一点。

<a id="14.3.5.13"></a>

**13.** 如果有人向受任购买货物的经理人出借钱款，可以提起经理人之诉；若钱款是为支付店铺租金而借，也同样适用。我认为这项规则是正确的，除非经理人被禁止借款。

<a id="14.3.5.14"></a>

**14.** 如果我任命某人出售或购买橄榄油，而有人把橄榄油借给了他，应当认为经理人之诉可以提起。

<a id="14.3.5.15"></a>

**15.** 如果经理人出售橄榄油后，以定金名义收下一枚戒指，却不予返还，所有人应依经理人之诉承担责任，因为这笔交易属于经理人受任经营的事项；除非经理人受命只接受现钱出售。相应地，如果经理人为价款而接受质物，也可以提起经理人之诉。

<a id="14.3.5.16"></a>

**16.** 为经理人提供保证的人也可以提起经理人之诉，因为该保证属于经理人所经营交易的附随事项。

<a id="14.3.5.17"></a>

**17.** 如果经理人由某人任命，而该任命人后来去世，其继承人继续使用同一经理人，继承人无疑应承担责任。即使在继承人承受遗产之前就与该经理人订约，对不知情的继承人也应公平地准许提起经理人之诉。

<a id="14.3.5.18"></a>

**18.** 如果我的代理人、监护人或保佐人任命了经理人，也应当认为可以提起经理人之诉，就如同经理人是由我任命的一样。

### <a id="14.3.6"></a>14.3.6　保罗《评告示》第三十卷

如果代理人是受任管理全部事务的人，也应准许对该代理人本人提起经理人之诉。

### <a id="14.3.7"></a>14.3.7　乌尔比安《评告示》第二十八卷

<a id="14.3.7.pr."></a>

**序言（pr.）** 如果某人在处理我的事务时任命了经理人，而我对此予以追认，也应作相同处理。

<a id="14.3.7.1"></a>

**1.** 经理人的身份并不重要：无论是男性还是女性，是自己的奴隶还是他人的奴隶，都一样。任命人的身份也不重要：即使是女性任命经理人，也可依照船舶经营人之诉的例子提起经理人之诉；如果受任经理人的是女性，她本人也应承担责任。即使受任的是家女或女奴，也可以提起经理人之诉。

<a id="14.3.7.2"></a>

**2.** 未适婚人任命经理人后，该未适婚人应依经理人之诉承担责任，因为任命经理人是其自身应承担的风险。

### <a id="14.3.8"></a>14.3.8　盖尤斯《评行省告示》第九卷

许多人确实会任命男童和女童管理店铺。

### <a id="14.3.9"></a>14.3.9　乌尔比安《评告示》第二十八卷

但是，如果是未适婚人本人任命经理人，且有监护人授权，他就应承担责任；没有监护人授权则不承担责任。

### <a id="14.3.10"></a>14.3.10　盖尤斯《评行省告示》第九卷

不过，对他的诉讼仅限于其因该交易而增加的财产利益。

### <a id="14.3.11"></a>14.3.11　乌尔比安《评告示》第二十八卷

<a id="14.3.11.pr."></a>

**序言（pr.）** 如果未适婚人继承了任命经理人的人，只要经理人的任命仍然有效，让未适婚人承担责任是最公平的；如果监护人不愿继续使用经理人的服务，就应当将其撤换。

<a id="14.3.11.1"></a>

**1.** 如果任命人未满二十五岁，他可以援用年龄救济，但是否给予救济应经过案件审查。

<a id="14.3.11.2"></a>

**2.** 如果有人已公开张贴告示，禁止与某人订约，那么该人不再被视为经理人。不得一方面允许他人继续与经理人订约，另一方面又声称不愿订约；若不愿他人订约，就应当禁止。否则，任命人应仅因任命行为本身承担责任。

<a id="14.3.11.3"></a>

**3.** 所谓公开张贴，是指用清楚的文字写明，使人在平地上即可正确读到；告示应张贴在店铺或经营场所前，而不是偏僻之处，必须位于显眼位置。告示应以希腊文还是拉丁文书写？我认为应根据当地情况决定，以免有人以不识该种文字为由提出抗辩。倘若有人说自己不识字，或没有注意到已张贴的告示，而许多人都读过告示，且告示明显公开张贴，就不应听从此种说法。

<a id="14.3.11.4"></a>

**4.** 告示必须持续公开张贴；如果在告示未张贴期间，或告示被遮蔽时发生交易，仍可以提起经理人之诉。因此，如果所有人张贴了告示，但告示被他人取下，或因陈旧、雨水等原因而无法看见或辨认，应当认为任命人仍须承担责任。但如果经理人本人为了欺骗我而取下告示，其欺诈不应损害任命人，除非与其订约的人也参与了欺诈。

<a id="14.3.11.5"></a>

**5.** 必须遵守经理人任命时所附条件。比如，任命人是否要求在特定规则、某人参与或提供质押的情况下订约，或者只就特定事项订约？最公平的做法是遵守任命范围。又如，任命人有数名经理人，可能要求只能与他们全体共同订约，也可能要求只与其中一人订约。如果任命人已通知某人不得与经理人订约，也不得提起经理人之诉；我们可以禁止特定的人、某类人或商人订约，也可以只准许特定的人订约。但是，如果任命人不断变更禁止订约的对象，就应当向所有与经理人订约的人提供诉权；否则订约人就会受骗。

<a id="14.3.11.6"></a>

**6.** 如果任命人全面禁止与其订约，此人就不再被视为经理人，而更像是看守人。因此，他既不能出售商品，也不能从店铺中出售任何小物件。

<a id="14.3.11.7"></a>

**7.** 如果经理人之诉可以正当地提起，依法就不适用分配之诉（*actio tributoria*），因为分配之诉不能适用于所有人的货物。反之，如果经理人经营的不是所有人的货物，分配之诉仍可提起。

<a id="14.3.11.8"></a>

**8.** 如果我向你的奴隶租用了其奴隶的劳务，并让该奴隶担任我的货物经理人，而他把我的货物卖给你，这就是买卖；因为主人向奴隶购买时，买卖关系仍可成立，尽管主人并不因此负担债务。其效力甚至达到：主人可以作为买受人取得占有并通过时效取得所有权：

### <a id="14.3.12"></a>14.3.12　尤利安《学说汇纂》第十一卷

因此，你可以对我提起准用经理人之诉；而我若要提起租赁之诉，则可以依该管事奴隶的特有财产对你起诉，或者依该次级奴隶的特有财产对你起诉，因为我曾命令该次级奴隶出售货物。由于你因此成为我奴隶的债务人，所付价款可以视为用于你的事务。

### <a id="14.3.13"></a>14.3.13　乌尔比安《评告示》第二十八卷

<a id="14.3.13.pr."></a>

**序言（pr.）** 某人有一名奴隶受任在阿雷拉特（*Arelate*）经营橄榄油买卖，同时也受任借入款项。该奴隶借入一笔钱；债权人以为借款用于购买货物，便提起告示规定的诉讼，但无法证明该笔钱是为购买货物而借。虽然该诉讼已经用尽，债权人不能再以奴隶也受任借款为由提起经理人之诉，尤利安仍说，可以给予其准用诉权。

<a id="14.3.13.1"></a>

**1.** 还应记住，只有在债权人未以更新债务为目的，通过与经理人或他人订立要式口约而更新原债务时，任命人才依经理人之诉承担责任。

<a id="14.3.13.2"></a>

**2.** 如果两人或多人共同经营店铺，并任命一名由他们按不同比例共有的奴隶为经理人，他们应按各自所有权份额、平均分担、货物份额，还是对全部债务承担责任？尤利安提出这一问题，并说较为正确的看法是，仿照船舶经营人之诉和特有财产之诉，每个人都可以被诉请承担全部债务；实际履行的被告可以通过合伙之诉或共有物分割之诉向其他人追偿。我们先前也赞同这一意见。

### <a id="14.3.14"></a>14.3.14　保罗《评普劳提乌斯》第四卷

如果一名他人所有的奴隶被任命经营共同货物，也应如此：应当允许对双方提起全部给付之诉；任何一人履行后，都可以通过合伙之诉或共有物分割之诉向他人追偿其应分担部分。当然，在无法提起合伙之诉或共有物分割之诉的情形下，应判令每人按自己的份额承担责任。例如，奴隶所欠债务的主人指定两名继承人，并让该奴隶获得自由；每名继承人都只能按自己的份额被起诉，因为继承人之间不能提起共有物分割之诉。

### <a id="14.3.15"></a>14.3.15　乌尔比安《评告示》第二十八卷

最后应当知道，这些诉讼具有永久时效，可以对继承人提起，也可以由继承人提起。

### <a id="14.3.16"></a>14.3.16　保罗《评告示》第二十九卷

如果某人与庄园管事订约，不得对主人提起诉讼，因为庄园管事受任是为了收取孳息，而不是经营获利。不过，如果我还任命庄园管事出售货物，那么依照经理人之诉的例子对我提起诉讼，也并非不公平。

### <a id="14.3.17"></a>14.3.17　保罗《评告示》第三十卷

<a id="14.3.17.pr."></a>

**序言（pr.）** 如果某人受任买卖奴隶、役畜或牲畜，不仅可以对任命人提起经理人之诉，也可以提起解除买卖之诉，或根据双倍或单倍担保的要式口约，要求其承担全部责任。

<a id="14.3.17.1"></a>

**1.** 如果你任命提提乌斯的奴隶为经理人，我可以依本告示对你起诉，也可以依后面的告示对提提乌斯起诉。但是，如果你禁止我与你订约，我就只能对提提乌斯起诉。

<a id="14.3.17.2"></a>

**2.** 如果未适婚人继承了父亲，而其父亲曾任命经理人，继承后又与经理人订约，应当认为可以对未适婚人提起诉讼，因为他从共同使用该经理人中受益；父亲的监护人授权任命经理人后、在其死亡之后与经理人订约，也同样处理。

<a id="14.3.17.3"></a>

**3.** 庞波尼也写道，对于承受遗产之前已经发生的交易，即使继承人是精神失常者，也应当准许提起诉讼。因为某人明知主人已经死亡，仍与继续经营货物的经理人订约，不应归咎于他。

<a id="14.3.17.4"></a>

**4.** 普罗库鲁斯说，如果我通知你不得向我任命的奴隶放贷，应当给予抗辩；其措辞是：“如果他没有通知对方不得向该奴隶放贷”（*Si ille illi non denuntiaverit, ne illi servo crederet*）。但是，如果该交易使奴隶的特有财产增加，或使我的财产增加，而我又不愿返还自己因此获得的利益，就应准许提出欺诈再抗辩；因为我若想从他人的损失中获利，显然是在实施欺诈。〔抗辩公式中的通知主体与前述情形关系不明，待核。〕

<a id="14.3.17.5"></a>

**5.** 对于这种情形，也可以提起债权返还之诉，这一点是正确的。

### <a id="14.3.18"></a>14.3.18　保罗《论异文》单卷本

经理人是指受任在店铺或经营场所负责购买、出售的人，也包括未被安排在某一固定场所、但受任从事同类活动的人。

### <a id="14.3.19"></a>14.3.19　帕皮尼安《答复集》第三卷

<a id="14.3.19.pr."></a>

**序言（pr.）** 如果某人任命代理人为自己借入钱款，应给予一项仿照经理人之诉的准用诉权。代理人有清偿能力，并以要式口约允诺付款时，也应作相同处理。

<a id="14.3.19.1"></a>

**1.** 主人曾任命自己的奴隶在柜台负责收取钱款；即使后来将其解放，仍通过该自由人经营同一事务，身份变化也不改变风险的承担。

<a id="14.3.19.2"></a>

**2.** 父亲任命家子管理店铺货物，家子为经营货物而借入钱款，父亲为他提供保证。也可以对父亲提起经理人之诉，因为父亲通过提供保证，将这笔钱款的借贷性质与店铺经营事务结合起来。

<a id="14.3.19.3"></a>

**3.** 奴隶仅受任放贷，却通过代为承担债务而接受他人债务，并不能依裁判官法使主人作为经理人对全部债务负责。但是，如果奴隶代表放贷人，通过债务移转向他人作出允诺，就可以正当地向主人请求给付；因为主人已取得针对委托债务移转者的、有关已贷出款项的诉权。

### <a id="14.3.20"></a>14.3.20　斯凯沃拉《学说汇纂》第五卷

卢基乌斯·提提乌斯经营钱币兑换柜台，并任命自己的自由人管理柜台。该自由人向盖尤斯·塞尤斯出具书信，内容如下：“奥克塔维乌斯·特米纳利斯，代表奥克塔维乌斯·费利克斯办事，致多米提乌斯·费利克斯：向你致意。你在我释主的柜台存有一千第纳里；我应于五月朔日前一日向你支付这笔钱。”有人问，卢基乌斯·提提乌斯去世且没有继承人，其财产出售后，特米纳利斯是否可以依据该信依法被起诉。答复：依这些文字，特米纳利斯并未依法负担债务；也没有公平理由可以起诉他，因为他是以经理人身份写下该信，用来证明柜台账目。（底本答复处拼作 *Tespondit*，疑为 *Respondit*。）
