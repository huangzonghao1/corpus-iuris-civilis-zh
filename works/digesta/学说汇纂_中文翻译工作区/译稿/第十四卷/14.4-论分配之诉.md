## 14.4.0　论分配之诉（*De tributoria actione*）

### <a id="14.4.1"></a>14.4.1　乌尔比安《评告示》第二十九卷

<a id="14.4.1.pr."></a>

**序言（pr.）** 这项告示也极为有用。主人在与奴隶订立的契约中原本享有优先地位，因为他仅在特有产（*peculium*）范围内承担责任，而且计算特有产时，应扣除主人自己对奴隶享有的债权。然而，如果主人知道奴隶以特有货物（*merx peculiaris*）经营商业，就应依本告示，像外部债权人一样参加分配。

<a id="14.4.1.1"></a>

**1.** “货物”一词的含义虽较狭窄，不包括为奴隶主人从事洗濯、修补衣物、织布或贩卖奴隶的奴隶，但佩狄乌斯在《评告示》第十五卷中写道，本告示应扩展适用于所有营业活动。

<a id="14.4.1.2"></a>

**2.** 特有营业货物不能像特有产那样理解；因为计算特有产时，应扣除所欠主人之债，而即使特有产中一无所有，特有营业货物仍会使主人依分配之诉承担责任，但前提是奴隶是在主人知情的情况下经营。

<a id="14.4.1.3"></a>

**3.** 此处所说的“知情”，包含意愿；但我认为，所需的不是意愿，而是容忍：主人不必愿意，只要未表示反对即可。因此，主人如果知情，既未提出异议，也未禁止经营，就应承担分配之诉的责任。

<a id="14.4.1.4"></a>

**4.** “权力支配”一词应作广义理解，适用于所有性别，也适用于所有受他人权利支配的人。

<a id="14.4.1.5"></a>

**5.** 分配之诉不仅适用于奴隶，也适用于那些以善意奴隶身份为我们服役的人，无论他们是自由人还是他人的奴隶，也适用于我们对其享有用益权的人；

### <a id="14.4.2"></a>14.4.2　保罗《评告示》第三十卷

但前提是，奴隶用以专门经营的货物应归属于我们。

### <a id="14.4.3"></a>14.4.3　乌尔比安《评告示》第二十九卷

<a id="14.4.3.pr."></a>

**序言（pr.）** 如果奴隶为数人共有，且两名主人都知情，可以对其中任何一人提起诉讼；如果一人知情而另一人不知情，则应对知情者提起诉讼，但应扣除欠不知情者的全部债务。如果原告起诉的是不知情者，由于起诉的是特有产之诉，还应扣除欠知情者的债务，而且要全额扣除；因为即使知情者本人被提起特有产之诉，其债权也应全额扣除。尤利安在《学说汇纂》第十二卷中也如此写道。

<a id="14.4.3.1"></a>

**1.** 如果未适婚人或精神失常者的奴隶，在监护人或监护官知情的情况下，以特有货物经营，我认为，不应因监护人或监护官的欺诈而使未适婚人或精神失常者受损，但也不应使他们因此获利。因此，他们仅在监护人的欺诈使利益归于自己时，才在相应范围内依分配之诉承担责任；精神失常者亦同。尽管庞波尼乌斯在《书信集》第八卷中写道，如果监护人有清偿能力，未适婚人应因监护人的欺诈承担责任；确实，未适婚人承担责任的范围仅限于将其对监护人享有的诉权让与债权人。

<a id="14.4.3.2"></a>

**2.** 如果未适婚人本人有欺诈行为，只要其年龄已足以理解欺诈，即使其知情不足以构成经营许可，也会因此承担责任。那么，如何处理？监护人或监护官的知情应使本诉得以提起；未适婚人自己的欺诈则只在对其不利的范围内发生效力。

### <a id="14.4.4"></a>14.4.4　保罗《评告示》第三十卷

监护人知情的未适婚人，达到适婚年龄后实施欺诈；或精神失常者恢复神志后实施欺诈，均依本告示承担责任。

### <a id="14.4.5"></a>14.4.5　乌尔比安《评告示》第二十九卷

<a id="14.4.5.pr."></a>

**序言（pr.）** 庞波尼乌斯和我们都毫不怀疑，代理人的知情和欺诈应使本人承担不利后果。

<a id="14.4.5.1"></a>

**1.** 如果我的代管奴隶（*vicarius*）经营，且我知情，我应依分配之诉承担责任；如果我不知情，但我的普通奴隶知情，庞波尼乌斯在《评萨宾》第六十卷中写道，应给予针对该普通奴隶特有产之诉；不应从代管奴隶的特有产中扣除其欠普通奴隶的债务，因为只应扣除其欠我的债务。但如果我和普通奴隶都知情，他说分配之诉和特有产之诉均可提起：以代管奴隶名义提起分配之诉，以普通奴隶名义提起特有产之诉。原告应选择提起哪一项诉讼，但应将我和奴隶各自的债权都纳入分配；因为如果普通奴隶不知情，他对代管奴隶享有的债权就应全部扣除。

<a id="14.4.5.2"></a>

**2.** 如果经营者是女奴，也应准许提起分配之诉。

<a id="14.4.5.3"></a>

**3.** 此外，交易对象是奴隶本人还是其经理人（*institor*），并无区别。

<a id="14.4.5.4"></a>

**4.** 告示特意加上“以货物为名”，理由充分：这样可以避免任何与奴隶进行的交易都产生分配之诉。

<a id="14.4.5.5"></a>

**5.** 依此诉，应命令分配该项营业货物以及因该货物而收取的财物。

<a id="14.4.5.6"></a>

**6.** 应与货物债权人一同参加分配的，是对奴隶享有支配权的人。

<a id="14.4.5.7"></a>

**7.** 有人问：主人是否仅在奴隶因营业货物而欠其债务时，才可从营业货物中分得一份；还是奴隶因其他原因欠其债务时也可以？拉贝奥说，只要奴隶因任何原因欠主人债务，主人都可参加分配；该债务是奴隶在取得营业货物之前还是之后开始欠下，并无多大关系。因为主人已经丧失优先扣除的特权。

<a id="14.4.5.8"></a>

**8.** 但如果交易债权人取得了营业货物本身作为质物，又该如何？我认为应当说，债权人依据质权优先于主人受偿。

<a id="14.4.5.9"></a>

**9.** 无论奴隶欠款的是主人本人，还是主人权力支配下的人，该债权均应纳入分配。

<a id="14.4.5.10"></a>

**10.** 如果奴隶有两名或更多主人，应按各主人债权的比例向他们分配。

<a id="14.4.5.11"></a>

**11.** 纳入分配的并非全部特有产，而仅限于来自营业货物的财产；无论营业货物仍然存在，还是其价款已经收取或转入特有产，均包括在内。

<a id="14.4.5.12"></a>

**12.** 如果奴隶通常向某些买受人出售货物，而这些买受人仍欠货款，尚未付清的货款也应按实际收取的情况纳入分配。

<a id="14.4.5.13"></a>

**13.** 如果奴隶除营业货物外，在店铺中还有营业设备，该设备是否也应纳入分配？拉贝奥说也应当分配，这非常公平，因为这类设备通常来自营业货物，实际上总是如此。但奴隶在特有产中持有的其他物品不应纳入分配，例如银器或黄金，除非这些物品是用营业货物购置的。

<a id="14.4.5.14"></a>

**14.** 同样，如果奴隶经营时拥有用营业货物购置的奴隶，这些奴隶也应纳入分配。

<a id="14.4.5.15"></a>

**15.** 如果奴隶有多名债权人，而其中一些债权人分别与特定营业货物有关，是否应把他们都混同于同一批货物，并让所有人共同参加分配？例如，奴隶经营两种生意，如经营斗篷业和亚麻布业，并分别有相应的债权人。我认为应分别分配；因为每名债权人主要是基于特定货物，而不是基于奴隶本人提供信用。

<a id="14.4.5.16"></a>

**16.** 如果奴隶经营两家相同类型的店铺，例如，我是他设在 Bucinum 的一家店铺的会计（*ratiocinator*），另一人则是他设在台伯河对岸的另一家店铺的会计，我认为最公平的做法是分别分配，以免有人从另一家店铺的财产或货物中获得清偿，而另一些人却承担损失。〔底本作 *ad bucinum*；地名具体所指未详。〕

<a id="14.4.5.17"></a>

**17.** 显然，如果货物都存放在同一家店铺，即使现存的这些货物（底本作 *extent*，并注异读 *exstent*）是用一名债权人的钱款购置的，也应将全部货物纳入分配，除非这些货物已质押给该债权人。

<a id="14.4.5.18"></a>

**18.** 但如果我把自己的货物交给奴隶出售，且货物仍然存在，那么将我纳入分配似乎不公平。如果货物已经转为对奴隶的信用债权，分配就有适用余地；但如果尚未转为信用债权，由于货物即使出售也不会立即丧失我的所有权，除非价款已经支付、提供保证人或以其他方式提供担保，就应认为我可以提起返还原物之诉。

<a id="14.4.5.19"></a>

**19.** 分配应按照各债权人债权的比例进行。因此，如果只有一名债权人请求分配，他会先取得全部相应份额；但由于还可能出现一名或数名其他营业货物债权人，该债权人应提供担保，承诺如果后来出现其他债权人，就按比例返还。

### <a id="14.4.6"></a>14.4.6　保罗《评告示》第三十卷

因为这项诉讼与特有产之诉不同，后者使先行起诉者处于更有利地位；分配之诉则使任何时候起诉的人都处于平等地位。

### <a id="14.4.7"></a>14.4.7　乌尔比安《评告示》第二十九卷

<a id="14.4.7.pr."></a>

**序言（pr.）** 债权人还应承诺：如果后来发现主人另有债权，也将按比例返还。设想主人另有一项附条件债权，或有一项隐而未现的债权；也应将其纳入考虑。即使主人已被要求参加分配，也不应使其遭受不公。

<a id="14.4.7.1"></a>

**1.** 如果主人不愿参加分配、也不愿承担这种麻烦，而愿意放弃特有产或营业货物，怎么办？佩狄乌斯记载，应听取他的意见；这一观点符合衡平。通常裁判官应为此指定仲裁人，由其促使分配特有营业货物。

<a id="14.4.7.2"></a>

**2.** 如果有人因恶意使分配未能按应有方式进行，可以对其提起分配之诉，请求其补足少分的数额；该诉旨在惩戒主人的恶意。少分也包括完全没有分配。如果主人当时不知奴隶从事营业而少分，不算出于恶意；但查明情况后仍不分配，就不能免于恶意责任。因此，如果主人从营业货物中给自己清偿，就应视为恶意少分。

<a id="14.4.7.3"></a>

**3.** 如果主人放任营业货物灭失、将其转移隐匿、故意以低价出售，或未向买受人收取价款，只要存在恶意，就应认定其依分配之诉承担责任。

<a id="14.4.7.4"></a>

**4.** 如果主人否认欠任何人债务，还须考察分配之诉是否适用。拉贝奥的意见更为正确：分配之诉仍可提起；否则，否认债务就会使主人获利。

<a id="14.4.7.5"></a>

**5.** 此项诉讼不受期间限制，可以对继承人提起；但仅限于实际归继承人的财产，

### <a id="14.4.8"></a>14.4.8　尤利安《学说汇纂》第十一卷

因为此诉并非基于欺诈，而是追索财物之诉；因此，即使奴隶已经死亡，主人及其继承人仍因奴隶的行为永久地就全部数额承担责任；尽管实施欺诈者已经死亡，本诉仍可提起。

### <a id="14.4.9"></a>14.4.9　乌尔比安《评告示》第二十九卷

<a id="14.4.9.pr."></a>

**序言（pr.）** 对继承人的规则，同样适用于其他继受人。

<a id="14.4.9.1"></a>

**1.** 起诉人应选择提起特有产之诉还是分配之诉，因为他知道自己不能再转而提起另一项诉讼。但如果有人基于不同原因，一项提起分配之诉，另一项提起特有产之诉，应当听取其请求。

<a id="14.4.9.2"></a>

**2.** 拉贝奥说，如果奴隶依遗嘱获得自由，其特有产也遗赠给他，继承人不应依分配之诉承担责任，因为相关财产既未归继承人所有，继承人也未实施欺诈。但庞波尼乌斯在《评萨宾》第六十卷中写道，除非继承人已要求奴隶提供担保，或从特有产中扣除了本应分配的财产，否则应依分配之诉承担责任。这个意见并非没有道理：继承人本人就是欺诈的实施者，因为他设法逃避分配。只有在继承人因死者的欺诈而被起诉时，我们才就实际归继承人的财产准许对其提起诉讼；如果是因继承人自己的欺诈而起诉，则不受此限。

### <a id="14.4.10"></a>14.4.10　保罗《评告示》第三十卷

即使奴隶已被出售，也可以对买受人提起特有产之诉，但不能对其提起分配之诉。

### <a id="14.4.11"></a>14.4.11　盖尤斯《评行省告示》第九卷

有时，债权人提起特有产之诉比提起分配之诉更有利。因为在我们讨论的分配之诉中，只有经营所用的营业货物及因这些货物而收取的财产才纳入分配；而在特有产之诉中，则要考察特有产的全部数额，其中也包括营业货物。奴隶经营所用的财产可能仅占特有产的一半、三分之一，甚至更少；此外，也可能奴隶根本不欠父亲或主人任何债务。

### <a id="14.4.12"></a>14.4.12　尤利安《学说汇纂》第十二卷

一名债权人以奴隶名义对主人提起特有产之诉，另一名债权人则提起分配之诉。问题是，主人是否应从特有产中扣除其将要向提起分配之诉的债权人支付的金额？答复说：只有在主人分配营业货物价款时没有遵守裁判官告示，才能提起分配之诉；也就是说，主人扣除自己债权的比例超过了分配给债权人的比例。例如，营业货物价值三十；主人本人对奴隶享有十五的债权，另有两名外部债权人合计享有三十的债权。主人如果扣除全部十五，再将剩余十五分给债权人，就构成不当分配；他本应只扣除十，并向两名外部债权人各分配十。既然主人如此行事，也不能认为他已经使奴隶免除其本人所负债务，因为之后仍须通过分配之诉支付五。因此，如果此时有人提起特有产之诉，而特有产中另有非营业货物的财产，主人仍应将这五作为奴隶尚欠自己的债务予以扣除。
