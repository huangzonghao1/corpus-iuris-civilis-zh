# D.14.6　论马其顿元老院决议

<a id="6"></a><a id="14.6"></a>

## 14.6.0　论马其顿元老院决议（*De senatus consulto Macedoniano*）

### <a id="14.6.1"></a>14.6.1

*乌尔比安《评告示》第二十九卷*

<a id="14.6.1.pr."></a>**序言（pr.）**：马其顿元老院决议（*senatus consultum Macedonianum*）的文字如下：

> *Cum inter ceteras sceleris causas Macedo, quas illi natura administrabat, etiam aes alienum adhibuisset, et saepe materiam peccandi malis moribus praestaret, qui pecuniam, ne quid amplius diceretur incertis nominibus crederet: placere, ne cui, qui filio familias mutuam pecuniam dedisset, etiam post mortem parentis eius, cuius in potestate fuisset, actio petitioque daretur, ut scirent, qui pessimo exemplo faenerarent, nullius posse filii familias bonum nomen exspectata patris morte fieri.*

**译文：**

> “马其顿除了天性使他具有的其他犯罪动因外，还因负债而增加了犯罪的诱因；他品行恶劣，常常为作恶提供机会。那些以不明名义放款、以免引起更多议论的人，〔元老院〕决议：凡向家子（*filius familias*）出借金钱者，即使在其曾处于其权力之下的父亲死亡后，也不得享有诉权或请求权；使那些以最恶劣方式放贷的人明白，任何家子的债务，都不能指望等其父死亡后再行清偿。”〔译者按：*incertis nominibus crederet* 可直译为“以不确定的名义放款”；本段从句主语和该语的具体所指较为紧缩，暂作此译。〕

<a id="14.6.1.1"></a>**1.** 如果家子是否仍处于父权之下尚未确定，例如其父被敌人俘虏，那么是否违反了元老院决议也处于未定状态：若家子重新回到父权之下，该决议即适用；若没有，则不适用。因此，在此期间应拒绝诉权。

<a id="14.6.1.2"></a>**2.** 当然，若被收养为家子者借入金钱，之后又被恢复原状而解除收养、取得独立身份，该元老院决议仍适用，因为他曾是家子。

<a id="14.6.1.3"></a>**3.** 家子的身份地位高低，不影响马其顿元老院决议的适用；即使他是执政官或身居任何其他显贵职位，该决议仍然适用；但若他有军旅特有产（*peculium castrense*），则该决议不适用。

### <a id="14.6.2"></a>14.6.2

*乌尔比安《评告示》第六十四卷*

**正文：** 元老院决议在军旅特有产数额范围内不适用，因为家子就军旅特有产而言，地位等同于家父。

### <a id="14.6.3"></a>14.6.3

*乌尔比安《评告示》第二十九卷*

<a id="14.6.3.pr."></a>**序言（pr.）**：若某人相信借款人是家父，并非因轻信或不懂法律而受骗，而是因为借款人在公众看来就是家父——其行为、订约方式及所承担的公职均如此——则马其顿元老院决议不适用。

<a id="14.6.3.1"></a>**1.** 因此，尤利安在《学说汇纂》第十二卷中写道：若某人承租了公税征收权，元老院决议即不适用；此事也常有裁定。

<a id="14.6.3.2"></a>**2.** 同样，尤利安在《学说汇纂》第十二卷中说，若某人无法知道借款人是否为家子，元老院决议也不适用，例如出借人是未适婚人或未满二十五岁者。对未满二十五岁的出借人，裁判官应查明情况后给予救济。若出借人是未适婚人，尤利安还应当指出元老院决议不适用的另一理由：未适婚人未经监护人同意而出借的金钱，并不构成借款。正如尤利安在《学说汇纂》第十二卷中所说，即使家子获准自由管理特有产，若其出借金钱，元老院决议仍不适用，因为这并不构成借款：父亲允许其管理特有产，并不意味着允许他处分并损失该特有产。因此，尤利安说，父亲仍可对钱币提起返还原物之诉（*rei vindicatio*）。

<a id="14.6.3.3"></a>**3.** 只有向家子实际交付借款的人，才违反元老院决议；通过其他方式订约的人不在此列，例如出售、出租或以其他方式订约，因为被视为会危害家子父母的，正是金钱的实际交付。因此，即使我与家子订立信用关系，例如基于买卖或其他未实际交付金钱的合同，即使我取得了要式口约，元老院决议仍不适用，因为并未发生现金交付。不过，只有在未以此作为规避元老院决议的手段时，才能这样说；如果放贷人不能直接借钱给家子，便改为向他出售物品，使家子取得价款并以此替代借款，则属欺诈规避。

<a id="14.6.3.4"></a>**4.** 若我先与家子订立要式口约，待他成为家父后才向其出借金钱，无论他是因身份减等，还是因父亲死亡或其他原因而在未发生身份减等的情况下取得独立身份，都应认为元老院决议不适用，因为此时借款已是交付给家父的：

### <a id="14.6.4"></a>14.6.4

*斯凯沃拉《疑义集》第二卷*

**正文：** 因为通常所说“不得向家子出借”，针对的不是订约文字，而是金钱的实际交付。

### <a id="14.6.5"></a>14.6.5

*保罗《疑义集》第三卷*

**正文：** 因此，在这种情况下，他也应被判决承担全部债务，而不是仅在其有能力偿付的范围内承担责任。

### <a id="14.6.6"></a>14.6.6

*斯凯沃拉《疑义集》第二卷*

**正文：** 反过来说，若你先从家父处取得要式口约，之后在他成为家子时才向其出借，元老院的禁令应予适用也是正确的，因为债务的实质是在金钱交付完成时才成立的。

### <a id="14.6.7"></a>14.6.7

*乌尔比安《评告示》第二十九卷*

<a id="14.6.7.pr."></a>**序言（pr.）**：此外，若家子充任保证人，内拉提乌斯在《答复集》第一、二卷中说，马其顿元老院决议不适用；塞尔苏斯在《学说汇纂》第四卷中也持同一观点。但尤利安补充说，若有人用虚假安排规避决议——原本要借款的家子转而充当保证人，并另找一名主债务人——这种欺诈安排仍受该决议禁止，应给予抗辩，不仅家子可以援用，主债务人也可以援用；因为家子的保证人同样应受保护。

<a id="14.6.7.1"></a>**1.** 尤利安还说，若我接受家子和提提乌斯两人为共同债务人，而金钱实际上会交给家子；但我之所以另接受提提乌斯为债务人，是为了不让家子借助元老院决议的保护，那么应给予针对这种欺诈的准用抗辩。

<a id="14.6.7.2"></a>**2.** 若家子的父亲被放逐或长期不在，家子替女儿许诺提供嫁资，并以父亲的财物设定质押，元老院决议不适用。不过，父亲的财物不因此承担责任；显然，若家子继承了父亲并主张质权，就会因诈欺抗辩（*exceptio doli*）而被驳回。

<a id="14.6.7.3"></a>**3.** 应当考察，所谓给予借款，是否仅指交付现金，还是也包括一切可以作为借用物交付的东西。我认为，决议的文字似乎指现金，因为元老院说的是“交付了借款”。但若有人以欺诈方式规避决议，例如把谷物、葡萄酒或橄榄油借给家子，让他出售后以所得款项作为借款使用，则应给予家子救济。

<a id="14.6.7.4"></a>**4.** 若给予借款时家子处于一人的父权之下，如今却处于另一人的父权之下，元老院决议的宗旨仍不改变；因此应给予抗辩。

<a id="14.6.7.5"></a>**5.** 若其父亲不是因死亡，而是因其他原因不再属于罗马共同体，也应认为元老院决议适用。

<a id="14.6.7.6"></a>**6.** 不仅向家子出借金钱的人，其继承人也应被拒绝诉权。

<a id="14.6.7.7"></a>**7.** 因此，若一人交付借款，另一人取得要式口约，也应给予针对后者的抗辩，尽管他本人并未交付金钱。若两人中有一人不知道借款人处于父权之下，更严格的观点是，此事对二人均有不利影响。两名共同要式口约债权人的情形也一样。

<a id="14.6.7.8"></a>**8.** 同样，若我接受两名家子作为共同债务人，却误以为其中一人是家父，则应考察金钱实际交给了谁：若我明知收款者是家子，我就会被抗辩驳回；若金钱交给了我不知道是家子的那一人，我便不会因该抗辩而被驳回。

<a id="14.6.7.9"></a>**9.** 无论借款约定支付利息还是不计利息，均适用元老院决议。

<a id="14.6.7.10"></a>**10.** 虽然元老院决议没有说明谁可以援用抗辩，但应当知道：若家子之父已经死亡，家子的继承人可以援用；若家子已经死亡，其父亲也可以援用。

<a id="14.6.7.11"></a>**11.** 有时，即使元老院决议适用，诉权仍可针对另一人提起。例如，家子作为店铺经理（*institor*）借入金钱：尤利安在《学说汇纂》第十二卷中写道，若经理被诉，他本人可以援用元老院决议的抗辩；但可以对任命他的主事人提起店铺经理之诉（*actio institoria*）。尤利安说，若是家父亲自委派他经营自己的业务，或者允许他经营特有产业务，则元老院决议不适用，因为该合同被视为依家父意愿订立。家父若知道家子经商，便被认为也允许他接受货物，除非家父明确禁止他收取货物。

<a id="14.6.7.12"></a>**12.** 因此，若家子收取金钱并将其用于家父的事务，元老院决议即不适用，因为他是为父亲而非为自己借款。即使他起初并非如此借款，而是后来将钱用于家父事务，尤利安在《学说汇纂》第十二卷中也说，元老院决议不适用；并应理解为他自始就是为了家父的事务借款。但若家子将借款用于清偿自己对父亲所负的债务，就不视为已将钱用于父亲事务；因此，若父亲对此并不知情，元老院决议仍然适用。

<a id="14.6.7.13"></a>**13.** 对于为求学而离家、并因此借款的家子，所谓元老院决议不适用，仅限于借款数额没有超过合理范围，至少没有超过其父通常供给的数额。

<a id="14.6.7.14"></a>**14.** 若家子借款，是为了替一名即使遭到起诉也不会因该抗辩而获驳回的人清偿债务，则元老院决议的抗辩不适用。

<a id="14.6.7.15"></a>**15.** 此外，若家父开始偿还家子所借的款项，元老院决议即不适用，因为这相当于家父追认了该债务。

<a id="14.6.7.16"></a>**16.** 若家子成为家父后偿还了部分债务，元老院决议即不适用，而且他不得请求返还已支付的款项。

### <a id="14.6.8"></a>14.6.8

*保罗《评告示》第三十卷*

**正文：** 但若监护人因误解而支付了款项，则应准许请求返还。

### <a id="14.6.9"></a>14.6.9

*乌尔比安《评告示》第二十九卷*

<a id="14.6.9.pr."></a>**序言（pr.）**：但若某人在成为家父后提供了质物，则应当说，元老院决议的抗辩在质物价值范围内不得给予。

<a id="14.6.9.1"></a>**1.** 若家子用他人赠给自己的金钱偿还债权人，父亲是否可以请求返还或主张所有权？尤利安说，若赠与金钱时附有“用于清偿债权人”的条件，应认为金钱是由赠与人直接转交债权人，并由受领人取得所有权；但若赠与时没有附加条件，家子便无权处分这些钱。因此，若他用钱清偿债务，父亲在任何情况下都享有返还请求权。

<a id="14.6.9.2"></a>**2.** 该元老院决议也适用于家女；即使有人声称用借款购买了装饰品，也不影响结论。因为元老院以决议拒绝了向家子出借金钱者的诉权；无论钱币已经花掉，还是仍在特有产中，都不影响。由此可见，元老院决议以更严格的态度否定了向家女提供借款的合同。

<a id="14.6.9.3"></a>**3.** 不仅家子及其父亲受到保护，为其提供保证的人和受其委任而介入的人也受保护；他们自己也享有基于委任关系的追偿权。但若他们是出于赠与意思而介入，则另当别论：此时他们没有追偿权，元老院决议也不适用。若他们并非出于赠与意思，而是依父亲意愿介入，则整个合同应视为已经得到父亲认可。

<a id="14.6.9.4"></a>**4.** 但未经家子父亲同意而为其介入的人，清偿后不得请求返还；神圣哈德良皇帝曾作此规定，也可以这样理解：他们无权请求返还。诚然，他们受到永久抗辩的保护；家子本人也同样受保护，却仍不得请求返还。因为不得请求返还的，是那些为制裁债权人而被免于诉追的人；法律并非意在使他们摆脱自己已经履行的给付。

<a id="14.6.9.5"></a>**5.** 尽管他们清偿后不得请求返还〔底本异文：*repetant*〕，

*保罗《评告示》第三十卷*

**正文：** 因为自然债务仍然存在，

### <a id="14.6.11"></a>14.6.11

*乌尔比安《评告示》第二十九卷*

**正文：** 但是，若他们未提出抗辩便被判决，仍可援用元老院决议的抗辩；尤利安如此写道，并以家子本人为例，将其与妇女介入他人债务的情形相比较。

### <a id="14.6.12"></a>14.6.12

*保罗《评告示》第三十卷*

**正文：** 若家父只是知情而有人向其子出借金钱，应当说元老院决议不适用。但若家父曾命人向其子出借，之后在债权人不知情时改变主意，则元老院决议仍不适用，因为应当考察合同开始成立时的情形。

### <a id="14.6.13"></a>14.6.13

*盖尤斯《评行省告示》第九卷*

**正文：** 若我们曾向他人出借金钱，后来为更新债务而要求家子作出要式口约，尤利安写道，元老院决议并不妨碍此事。

### <a id="14.6.14"></a>14.6.14

*尤利安《学说汇纂》第十二卷*

**正文：** 我有一个儿子，并有一个由他所生的孙子。有人依孙子的父亲——也就是我儿子——的命令，向我的孙子出借金钱。有人询问，这是否违反元老院决议。我答复说，尽管该决议的文字提到的是“儿子”，但对孙子也应适用同一规则。孙子父亲的命令并不能使该借款不被视为违反元老院决议，因为他本人也处于这样的情形：未经自己的父亲同意，他不能借入金钱。

### <a id="14.6.15"></a>14.6.15

*马尔基安《法学阶梯》第十四卷*

**正文：** 向家子出借的人是谁，并不重要：无论是私人还是城市共同体，均然；神圣塞维鲁和安东尼努斯皇帝曾以敕答确认，该元老院决议也适用于城市共同体。

### <a id="14.6.16"></a>14.6.16

*保罗《答复集》第四卷*

**正文：** 若家子在父亲不在时，仿佛依据父亲的委任而借入金钱，并为此提供担保，随后写信给父亲，请其在行省偿还该笔钱；父亲若不认可儿子的行为，就应立即郑重声明自己持相反意见。

### <a id="14.6.17"></a>14.6.17

*保罗《格言集》第二卷*

**正文：** 若家子借入金钱，是为了替自己的姐妹支付嫁资，父亲应依据特有产投入所得之诉（*actio de in rem verso*）承担责任；因为若该女子在婚姻存续期间死亡，返还嫁资的请求权归借款的家子本人。

### <a id="14.6.18"></a>14.6.18

*维诺尼乌斯《要式口约》第二卷*

**正文：** 尤利安写道，家子死亡后，其债权人不能再接受保证人的保证，因为已不存在可由保证责任附随的民事债务或自然债务。不过，债权人仍可接受其父亲为保证人，以担保其对父亲享有的特有产之诉（*actio de peculio*）。

### <a id="14.6.19"></a>14.6.19

*庞波尼《异文集》第七卷*

**正文：** 尤利安写道，除非债权人知道或本可知道其借款对象是家子，否则不得以马其顿元老院决议的抗辩对抗该债权人。

### <a id="14.6.20"></a>14.6.20

*庞波尼《元老院决议集》第五卷*

**正文：** 若某人在仍处于父亲权力之下时曾借入金钱，后来成为家父，却因不知事实而通过更新债务作出偿还该笔钱的承诺；若债权人依据该要式口约请求给付，就应提出事实抗辩（*exceptio in factum*）。
