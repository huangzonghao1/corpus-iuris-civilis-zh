# D.49.9–D.49.14　上诉程序与国库法

<!-- source-p 231 -->
<a id="9"></a><a id="49.9"></a>49.9.0　能否由他人陈述上诉理由（*An per alium causae appellationum reddi possunt*）

<!-- source-p 232 -->
<a id="49.9.1"></a>49.9.1

<!-- source-p 233 -->
乌尔比安《论上诉》第四卷

<!-- source-p 234 -->
人们常问，上诉理由能否由他人陈述；这一问题通常出现在财产案件和刑事案件中。对于财产案件，复函曾确认可以由他人代理进行。复函内容如下：“神圣的皇帝兄弟致朗基努斯：如果提起上诉的人委托你，就波利亚对他提出的上诉为其辩护，而且案件属于财产案件，没有任何规定禁止你以其名义答辩。但如果案件并非财产案件，而是死刑案件，则不得由诉讼代理人进行。不过，如果案件可能导致流放以下的刑罚，也不应由他人陈述上诉理由；应当知道，本人须亲自到庭。”当然，如果是可能导致名誉减损的财产案件，也可以由诉讼代理人处理。对提起控告者而言，无论是其本人上诉，还是有人针对其提起上诉，也应证明这一点。总而言之，某类案件既不得由他人代理进行，该案的上诉也不应由他人代理进行。

<!-- source-p 235 -->
<a id="49.9.2"></a>49.9.2

<!-- source-p 236 -->
马克尔《论上诉》第二卷

<!-- source-p 237 -->
缺席者的诉讼代理人提起上诉后，即使已经交还账目，仍应由该代理人本人答辩。不过，若其不再处理案件，诉讼当事人本人能否参照未成年人案件中的规则答辩，尚须考察；但通常遵循的做法是，在陈述上诉理由的案件中，应当听取其缺席期间由诉讼代理人代为提起上诉的本人。

<!-- source-p 238 -->
<a id="10"></a><a id="49.10"></a>49.10.0　监护人、保佐人或被任命的官员提起上诉时（*Si tutor vel curator magistratusve creatus appellaverit*）

<!-- source-p 239 -->
<a id="49.10.1"></a>49.10.1

<!-- source-p 240 -->
乌尔比安《论执政官职责》第三卷

<!-- source-p 241 -->
凡因被提名担任公共职务而提起上诉、却未能证明上诉理由成立者，应当知道：如果上诉拖延使共同体遭受任何损失，该损失将由其承担。如果查明他们确有必要提起上诉，则应由总督或元首评定该损失应归责于谁。

<!-- source-p 242 -->
<a id="49.10.2"></a>49.10.2

<!-- source-p 243 -->
赫尔莫革尼亚努斯《法学摘要》第五卷

<!-- source-p 244 -->
监护人或保佐人被留任后提起上诉，并在案件审理之前死亡的，为避免中间期间发生损害，其继承人必须陈述上诉理由。

<!-- source-p 245 -->
<a id="11"></a><a id="49.11"></a>49.11.0　应在行省内为上诉人辩护（*Eum qui appellaverit in provincia defendi*）

<!-- source-p 246 -->
<a id="49.11.1"></a>49.11.1

<!-- source-p 247 -->
乌尔比安《论上诉》第四卷

<!-- source-p 248 -->
神圣的皇帝兄弟在致菲隆的第十号复函中指出，即使上诉人因上诉而身在外地，也应当在行省内就其其他案件为其辩护。

<!-- source-p 249 -->
<a id="49.11.2"></a>49.11.2

<!-- source-p 250 -->
马尔基安《论上诉》第二卷

<!-- source-p 251 -->
给予他们这项便利，是为了使因公事离开的人不必亲自出庭辩护。

<!-- source-p 252 -->
<a id="12"></a><a id="49.12"></a>49.12.0　应责令其在受上诉的裁判者面前审理其他案件（*Apud eum, a quo appellatur, aliam causam agere compellendum*）

<!-- source-p 253 -->
<a id="49.12.1"></a>49.12.1

<!-- source-p 254 -->
乌尔比安《论上诉》第四卷

<!-- source-p 255 -->
若某人因一项案件而对裁判者提起上诉，是否必须在另一案件中仍由同一裁判者审理，尚须考察。如今我们依此规则处理：即使已经提出上诉，他仍应在其提起上诉的同一裁判者面前被责令审理自己可能涉及的其他案件；他不得以此为借口，声称不应在一名对其不满的裁判者面前诉讼，因为他仍可再次提起上诉。

<!-- source-p 256 -->
<a id="13"></a><a id="49.13"></a>49.13.0　上诉待决期间发生死亡时（*Si pendente appellatione mors intervenerit*）

<!-- source-p 257 -->
<a id="49.13.1"></a>49.13.1

<!-- source-p 258 -->
马克尔《论上诉》第二卷

<!-- source-p 259 -->
<a id="49.13.1.pr."></a>上诉人死亡后，如果没有继承人，无论上诉属于何种类型，上诉均告消灭。如果上诉人有继承人，那么，若无人另有利益要求陈述上诉理由，不得强迫继承人继续上诉；但如果国库或被上诉的另一方对此有利害关系，继承人就必须陈述上诉理由。所谓无人有利害关系，例如仅被判处流放而未被剥夺财产的情形。反之，如果某人被判处剥夺财产并流放、被驱逐至岛屿或被判处矿场劳役，在提出上诉后死亡，我们的皇帝亚历山大曾如此复函军人普莱托里乌斯：“尽管被告死亡使刑事追诉在上诉待决期间消灭，但若判决同时涉及其部分财产，该判决仍然存在。享有继承利益的人只有在陈述上诉理由时揭示判决不公，才能获得胜诉。”

<!-- source-p 260 -->
<a id="49.13.1.1"></a>1. 监护人为未适婚人事务提起上诉后死亡的，其继承人也必须陈述上诉理由，即使继承人已经交还监护账目；因为只要监护人在死亡时仍负有陈述上诉理由的义务，即已足够。不过，神圣的塞维鲁与安敦尼曾以复函指出，监护人在交还账目后，不得再被强迫陈述上诉理由。

<!-- source-p 261 -->
<a id="14"></a><a id="49.14"></a>49.14.0　论国库法（*De iure fisci*）

<!-- source-p 262 -->
<a id="49.14.1"></a>49.14.1

<!-- source-p 263 -->
卡利斯特拉图斯《论国库权》第一卷

<!-- source-p 264 -->
<a id="49.14.1.pr."></a>通常会向国库报告各种事项：有人声明自己无权取得以秘密方式留给自己的财产，或被他人抢先报告；继承人未追究死者的行为；有人被报告为不适格继承人；元首被指定为继承人，而遗嘱或附录被报告为遭人窃取；有人据称发现了宝藏；有人以低于其价值的价格从国库购得高价值物品；国库因串通而在诉讼中败诉；被告死于死刑指控之中；某人在死后仍被控告；房屋遭毁坏；控告被撤回；争议中的物品被出售；因私人契约而欠付国库罚款；或有人实施了违反法律的行为。

<!-- source-p 265 -->
<a id="49.14.1.1"></a>1. 无力清偿债务的财产是否依法当然归国库所有，曾有争议。拉贝奥认为，即使无力清偿债务的财产，也依法当然属于国库。但《永久告示》所载规则与其意见相反：只有当出售这些财产不能使国库取得任何利益时，才按该规则出售。

<!-- source-p 266 -->
<a id="49.14.1.2"></a>2. 神君庇护曾以复函答复凯利乌斯·阿马兰图斯：无人继承财产的报告，须在四年内提出；期间应自可以确定既无继承人、亦无遗产占有人之日起计算。

<!-- source-p 267 -->
<a id="49.14.1.3"></a>3. 神君提图斯敕令所规定的二十年时效期间，也适用于追查被列记者的财产；该期间通常自相关财产可能归国库所有之日起计算。

<!-- source-p 268 -->
<a id="49.14.1.4"></a>4. 及时启动并审理、但延续超过二十年的案件，在二十年届满后仍可继续审理。

<!-- source-p 269 -->
<a id="49.14.1.5"></a>5. 据称由先前报告人已经揭发的事项，即使经过上述时效期间，仍可向国库报告。

<!-- source-p 270 -->
<a id="49.14.2"></a>49.14.2

<!-- source-p 271 -->
卡利斯特拉图斯《论国库权》第二卷

<!-- source-p 272 -->
<a id="49.14.2.pr."></a>在某些情况下，报告事项的人不会因此名誉受损，例如并非为了取得奖赏而报告的人、为了报复而报告对方的人，以及代表其共同体办理事务的人。多项元首敕令均指示应如此遵行。

<!-- source-p 273 -->
<a id="49.14.2.1"></a>1. 神君哈德良曾以复函答复弗拉维乌斯·阿里安努斯，内容如下：“能够出示与国库案件有关文书的人却不予出示，若无法以其他方式查明真相，是否应因此对其不利，并推定其隐匿了会损害其案件的文书，这一点毫无疑问。也不应再有疑问：不利后果只能涉及索取这些文书所针对的事项，不得延及其他事项。”

<!-- source-p 274 -->
<a id="49.14.2.2"></a>2. 神圣的皇帝兄弟也在答复科尔内利乌斯·鲁弗斯的奏章时指出：每当争议涉及取得财产的权利、所有权，或其他类似的财产金钱事项时，均应出示文书；若审理的是死刑案件，则不在此限。

<!-- source-p 275 -->
<a id="49.14.2.3"></a>3. 元老院裁定：报告人和占有人经三次告示传唤仍未到庭的，报告人的保证人应承担责任，且该报告人此后丧失提出公共案件报告的权利；至于占有人，其法律地位应与根本无人报告该事项时相同。

<!-- source-p 276 -->
<a id="49.14.2.4"></a>4. 但是，报告人经命令到庭却不出席，且不能证明这是占有人欺诈所致时，神君哈德良以复函指出，应作出有利于占有人的裁判，并在判决中载明报告人也曾依告示受到传唤。

<!-- source-p 277 -->
<a id="49.14.2.5"></a>5. 神君庇护曾以复函答复凯基利乌斯·马克西穆斯：其父敕令要求报告人披露委托其报告者的身份，拒不披露则将其拘禁；该敕令的目的不是使报告人因有委托人而免于受罚，而是使委托人也如同亲自报告一样受罚。

<!-- source-p 278 -->
<a id="49.14.2.6"></a>6. 我们的皇帝塞维鲁·奥古斯都规定，不得受理奴隶对其主人的报告，而应对奴隶处以刑罚；行省总督也应惩罚那些委托被释奴控告其主人的人。

<!-- source-p 279 -->
<a id="49.14.2.7"></a>7. 有许多元首复函规定：某人因不知自己享有权利而报告了自己，不应因此遭受不利。但也有同一批皇帝的一份复函，据此可以主张：只有当报告人因乡野无知或女性身份而可能不知自己权利时，自我报告才不损害其利益。

<!-- source-p 280 -->
<a id="49.14.3"></a>49.14.3

<!-- source-p 281 -->
卡利斯特拉图斯《论国库权》第三卷

<!-- source-p 282 -->
<a id="49.14.3.pr."></a>受人请求而公开返还财产的人，不被视为规避法律。但有人在遗嘱中写道：“我请求你们信守我所托付之事；我还以神明之名恳求你们照办。”有人因此询问，这是否属于公开遗赠。尤利安答复说，这些措辞并未表明立遗嘱人要求继承人做什么。但通常会讨论何时可以认定有人以其信用规避法律；如今大致认为，若立遗嘱人并未在遗嘱或附录中作出请求，而是以私下文书或债务凭据约束自己，将财产交给无权取得之人，通常即属规避法律。因此，可以说前述措辞并未规避法律。

<!-- source-p 283 -->
<a id="49.14.3.1"></a>1. 若某人既被公开请求、又被秘密请求，曾有人争论究竟何者优先：秘密请求是否使其受损，还是公开请求对其有利。神君哈德良以复函指出，对于以公开方式托付给某人信义之事，不应认为其以信用规避法律。

<!-- source-p 284 -->
<a id="49.14.3.2"></a>2. 还应考察何时构成规避法律：应看最终结果，还是看作出安排时的意图？例如，秘密设立遗嘱信托时，受领人无权取得；但立遗嘱人死亡时，他可能已经有权取得，反之亦然。规则认为应看最终结果。

<!-- source-p 285 -->
<a id="49.14.3.3"></a>3. 秘密遗嘱信托经常通过以下方式揭露：出示一份书面承诺，其中被选定的人保证，自己从死者遗产中取得财产后将予返还。其他确凿无疑的证据也能证明这一点。

<!-- source-p 286 -->
<a id="49.14.3.4"></a>4. 因秘密遗嘱信托而使财产归国库时，遗嘱中以有效方式作出的处分仍然有效；神君庇护曾以复函作此说明。

<!-- source-p 287 -->
<a id="49.14.3.5"></a>5. 神圣的皇帝兄弟曾以复函规定，国库出售财产时，应要求代理人诚信并尽到审慎义务；合理价格应依当前估价确定，而不应依据先前交易价格。土地经精心耕作，价值会提高；若管理疏忽，其价值自然会降低。

<!-- source-p 288 -->
<a id="49.14.3.6"></a>6. 某人为公共承租人承担的租期超过五年后，对后续期间不再负责；多份元首复函均有此规定。神君哈德良也曾作如下复函：“这种习惯极不人道：公共税收或土地的承租人若无法以相同条件续租，就被强行留任。倘若他们知道，五年期满后希望退出即可免于继续承担责任，便更容易找到承租人。”

<!-- source-p 289 -->
<a id="49.14.3.7"></a>7. 国库继受次顺位债权人时，享有其前手原本可享有的权利。

<!-- source-p 290 -->
<a id="49.14.3.8"></a>8. 多份元首复函规定，国库原则上只有在其主要债务人无力偿债时，才能向这些债务人的债务人追偿；或者，相关债权已在国库账簿中明确登记；又或者，被追偿者是基于与国库订立的契约而负债。

<!-- source-p 291 -->
<a id="49.14.3.9"></a>9. 神君哈德良曾以复函答复弗拉维乌斯·普罗库鲁斯：有人主张自己属于归国库所有的财产并要求确认自由身份时，法院应当在国库事务代理人到场并参与诉讼的情况下审理此案。此类自由身份案件若未有国库辩护人参与即作出裁判，应恢复原状重新审理。

<!-- source-p 292 -->
<a id="49.14.3.10"></a>10. 神圣的皇帝兄弟规定，若在国库、公共或宗教场所，或纪念建筑中发现宝藏，其中一半应由国库主张取得；若在凯撒占有的地方发现，同样有一半应由国库主张取得。

<!-- source-p 293 -->
<a id="49.14.3.11"></a>11. 除非宝藏中有一部分应归国库所有，否则无人被强制要求报告自己发现了宝藏。有人在国库土地上发现宝藏，却隐匿应归国库的部分，则必须交出全部宝藏，并另行支付同等数额。

<!-- source-p 294 -->
<a id="49.14.4"></a>49.14.4

<!-- source-p 295 -->
乌尔比安《论告示》第六卷

<!-- source-p 296 -->
在国库案件中，若报告人收取了哪怕少量价金，其与对方达成的协议即视为承认事实。

<!-- source-p 297 -->
<a id="49.14.5"></a>49.14.5

<!-- source-p 298 -->
乌尔比安《论告示》第十六卷

<!-- source-p 299 -->
<a id="49.14.5.pr."></a>序　凯撒的财产管理人出售某项物品时，即使承诺在发生权利瑕疵追夺时支付双倍或三倍，国库仍仅承担支付单倍价额的责任。

<!-- source-p 300 -->
<a id="49.14.5.1"></a>1. 由获准处分国库财产的人出售国库物品后，只要价金已经支付，该物品即归买受人所有。

<!-- source-p 301 -->
<a id="49.14.6"></a>49.14.6

<!-- source-p 302 -->
乌尔比安《论告示》第六十三卷

<!-- source-p 303 -->
<a id="49.14.6.pr."></a>国库继受私人债权时，对于其继受之前的期间适用私人债权人的权利；但自继受之后，即享有国库自身的优先权。问题在于：该优先权是自债权开始归属于国库时即发生，还是自国库向债务人主张时发生，抑或自债权记入债务人名下的国库账目时发生。国库自向债务人明确主张债权之日起，即可请求利息，即使其请求的期间较短。但关于优先权，复函说法不一；我认为，应自该债权记入债务人的国库账目之日起适用优先权。

<!-- source-p 304 -->
<a id="49.14.6.1"></a>1. 国库享有的任何优先权，凯撒的财务机关和皇后通常也同样享有。

<!-- source-p 305 -->
<a id="49.14.7"></a>49.14.7

<!-- source-p 306 -->
乌尔比安《论告示》第五十四卷

<!-- source-p 307 -->
国库若对某人提出身份争议，国库辩护人必须到场。因此，若未有国库辩护人参与即作出裁判，神君马可曾以复函指出，该程序不发生效力，应重新审理。

<!-- source-p 308 -->
<a id="49.14.8"></a>49.14.8

<!-- source-p 309 -->
莫德斯丁《规则集》第五卷

<!-- source-p 310 -->
国库代理人不得出售已被判归国库所有的遗产中的管事奴隶；敕令规定，即使已经出售，该买卖也应宣告无效。

<!-- source-p 311 -->
<a id="49.14.9"></a>49.14.9

<!-- source-p 312 -->
莫德斯丁《复答集》第十七卷

<!-- source-p 313 -->

<a id="49.14.13.pr."></a>序　我所引神君图拉真告示的意思是：若某人在事项被报告至国库之前，已经申报自己无权取得其所占有的物品，则应将该物品的一部分交给国库，另一部分由其保留。

<!-- source-p 326 -->
<a id="49.14.13.1"></a>1. 神君图拉真后来在告示中还规定：某人申报有人以公开或秘密方式将自己无权取得的财产留给自己，并证明该财产已经归国库所有时，即使该人并未占有该财产，也可以从国库主管官员收取的财产中取得一半。

<!-- source-p 327 -->
<a id="49.14.13.2"></a>2. 妨碍取得权的原因为何，并不重要。

<!-- source-p 328 -->
<a id="49.14.13.3"></a>3. 应予报告的是尚未揭露的事项，而非本已属于国库的财产。

<!-- source-p 329 -->

<!-- source-p 330 -->
<a id="49.14.13.5"></a>5. 还保存有神君哈德良的一封书信：有权自我报告的人若因死亡而未能报告，其继承人报告后也可获得奖赏。他说：“但若能明确查知死者本有意自我报告……”；反之，若其隐瞒只是希望继续藏匿财产，其继承人除通常的奖赏外，不得取得其他利益。

<!-- source-p 331 -->
<a id="49.14.13.6"></a>6. 神圣的皇帝兄弟还以复函规定：受秘密遗嘱信托的人仅在受领人因死亡而无法报告、故未能及时自我报告的情况下，才能依图拉真的恩典进行报告。

<!-- source-p 332 -->
<a id="49.14.13.7"></a>7. 受秘密信托的人在遗嘱开启前已经报告此事，受信人却在遗嘱开启后才报告的，神君安敦尼命令接受后者的申报；因为前者仓促抢先报告，不值得奖赏。某人自称无权取得某物时，实际上是承认自己无权利，而非报告他人的事项。

<!-- source-p 333 -->
<a id="49.14.13.8"></a>8. 图拉真的恩典适用于依死者意愿受留财产、却无权取得该财产的人。因此，我也不能报告留给我奴隶的财产。

<!-- source-p 454 -->
<a id="49.14.45"></a>49.14.45

<!-- source-p 455 -->
保罗《判例集》第五卷

<!-- source-p 456 -->
<a id="49.14.45.pr."></a>以欺诈国库为目的处分的财产，不仅赠与可以撤销，任何形式的处分均可撤销；即使没有人提出请求，规则也相同，因为对所有形式的欺诈都要处罚。

<!-- source-p 457 -->
<a id="49.14.45.1"></a>1. 在看守、拘禁或戴着脚镣时死亡者的财产，不向其继承人追夺；无论其依遗嘱还是无遗嘱死亡，均同。

<!-- source-p 458 -->
<a id="49.14.45.2"></a>2. 有人自杀的，须先查明其自杀所涉犯罪，才能将其财产收归国库。若其因自己实施某项恶行而自杀，财产应判归国库；但若其因厌世、羞于负债或不能忍受疾病而自杀，则不应追究，其财产仍由其继承人取得。

<!-- source-p 459 -->
<a id="49.14.45.3"></a>3. 国库债务人以欺诈方式授予的自由应予撤销。但并不禁止债务人从他人处购买奴隶以便将其释放；因此，在此情形下仍可以授予奴隶自由。

<!-- source-p 460 -->
<a id="49.14.45.4"></a>4. 从已报告归国库的财产中，应依请求返还涉及私人权利的文书、债务凭据及诉讼记录。

<!-- source-p 461 -->
<a id="49.14.45.5"></a>5. 任何人均不得被要求出示针对国库的文书或诉讼记录。

<!-- source-p 462 -->
<a id="49.14.45.6"></a>6. 国库出示自己的诉讼记录副本时，附有一项条件：获准抄录之人不得以这些记录针对自己或国家。此人须作出担保；若其违反禁令使用记录，即丧失案件。

<!-- source-p 463 -->
<a id="49.14.45.7"></a>7. 在国库案件中，应申请取得使用诉讼记录的许可，并由书记官在记录上注明。若未经许可而以其他方式出示记录，出示者即丧失案件。

<!-- source-p 464 -->
<a id="49.14.45.8"></a>8. 同一案件再次在国库审理时，依法可以依职权要求宣读此前未经申请许可使用的旧诉讼记录。

<!-- source-p 465 -->
<a id="49.14.45.9"></a>9. 为他人向国库清偿债务的人，合理地可以请求追索被代偿者的财产；通常也可以通过官署获得协助。

<!-- source-p 466 -->
<a id="49.14.45.10"></a>10. 国库债务人请求延期以筹措钱款的，不应拒绝。是否准许及期限长短由裁判者酌定：大额债务延期不得超过三个月，小额债务不得超过两个月；更长的期限应向皇帝申请。

<!-- source-p 467 -->
<a id="49.14.45.11"></a>11. 主要债务人的财产若归入国库，其保证人即获免责；但若保证人的偿付能力较差，且其保证系为未清偿余额所提供，则不在此限。

<!-- source-p 468 -->
<a id="49.14.45.12"></a>12. 国库出售债务人财产后若收取超过债务的价款，债务人依法有理由请求返还超出部分。

<!-- source-p 469 -->
<a id="49.14.45.13"></a>13. 国库土地的承租人不得从土地上移走任何物品，不得出售柏木材，不得在未补植新橄榄树的情况下出售橄榄树，也不得砍伐其他结果树；经估价后，须向其追缴四倍金额。

<!-- source-p 470 -->
<a id="49.14.45.14"></a>14. 不得将土地或税收承包给未满二十五岁者，以免他们援引年龄利益对抗这些义务。

<!-- source-p 481 -->
<a id="49.14.46.8"></a>8. 凯撒的奴隶依代理人命令接受遗产后，若凯撒愿意，该遗产即由凯撒取得。

<!-- source-p 482 -->
<a id="49.14.46.9"></a>9. 多人共同欺诈国库时，与盗窃之诉中各人均须承担全部责任不同，他们只须按各自份额共同承担一次四倍罚金。确有偿付能力者，应代无偿付能力者承担追偿。

<a id="49.14.47"></a>49.14.47

<!-- source-p 484 -->
保罗《裁判集》第一卷

<!-- source-p 485 -->
<a id="49.14.47.pr."></a>莫斯基丝因承租税收而欠国库款项，并有数名继承人。继承人接受遗产后，法里娅·塞尼拉等人从他们处购买了土地。国库因莫斯基丝所欠余款向这些买受人追偿；继承人称莫斯基丝的继承人有偿付能力，而且还有许多人从同一遗产购得土地。皇帝认为，应先向继承人追偿，余额再向所有占有人追偿，并据此作出裁判。

<!-- source-p 486 -->
<a id="49.14.47.1"></a>1. 埃米利乌斯·托勒密从国库承租一处土地，之后分批转租给多人，收取的租金高于其本人承担的租金。凯撒代理人按他转租所得的金额向他追偿。皇帝认为此举对他不公、对国库也无益，因为他仍须自行承担向转租人追偿的风险；因此裁定，只能按其本人作为承租人所承担的租金额向他追偿。

<a id="49.14.48"></a>49.14.48

<!-- source-p 488 -->
保罗《裁判集》第二卷

<!-- source-p 489 -->
<a id="49.14.48.pr."></a>序　斯塔提乌斯·弗洛鲁斯在遗嘱中秘密托付继承人庞培的信义，要求其向无权取得遗产者交付一块土地及确定数额的钱款，并要求庞培为此作出担保，承诺返还其通过先取方式取得的财物。后来，弗洛鲁斯另立遗嘱，仍指定庞培与福斯蒂努斯为继承人，却未向庞培设定任何先取遗赠。那名无权取得财产的人自我报告了此事。皇帝应代理人咨询后复函：除非能证明立遗嘱人已改变意思，应履行遗嘱信托。庞培因此被判承担义务；他主张该负担应由遗产承担，因为他未曾取得先取遗赠，而且不能认为立遗嘱人仅在第一份遗嘱中部分维持其意思，而应认为其整体维持。裁判指出，第一份遗嘱已不存在；即使立遗嘱人在第一份遗嘱中曾作出先取遗赠，也不能根据后一份遗嘱请求，除非该遗嘱另有请求。最终裁定：庞培仅凭自己所作担保，不能证明曾获赠先取遗赠，因此只能履行遗嘱信托。

<!-- source-p 490 -->
<a id="49.14.48.1"></a>1. 科尔内利乌斯·费利克斯的母亲被指定为继承人，并受托在自己死亡后返还遗产。该指定继承人被国库判令承担责任，妇人的全部财产亦被查封。费利克斯主张自己在受到处罚前已能请求遗嘱信托，因为这是既定规则。但若遗嘱信托的到期日尚未到来，母亲可能先于他死亡，也可能另行取得其他财产；因此，他当时的请求被驳回。

<a id="49.14.49"></a>49.14.49

<!-- source-p 492 -->

<!-- source-p 493 -->
受领秘密遗嘱信托的人报告称自己无权取得财产；问题在于，依神君图拉真的恩典，他应收取九分之十二遗产中的一半，还是全部十二分中的一半。关于此事，保存有安敦尼皇帝如下复函：“皇帝安敦尼致尤利乌斯·鲁弗斯：有人将秘密信托托付给他，要求其将遗产返还给无权取得者；若其扣除四分之一后返还，就不应保留任何部分。加诸继承人的四分之一应予剥夺并转归国库。”因此，自我报告的人仅取得九分之十二中的一半。

<!-- source-p 494 -->
<a id="49.14.50"></a>49.14.50

<!-- source-p 495 -->
保罗《裁判集》第三卷

<!-- source-p 496 -->
皇帝代理人瓦莱里乌斯·帕特鲁伊努斯曾以确定价格将土地判售给弗拉维乌斯·斯塔提基乌斯。后来进行竞价，斯塔提基乌斯在接受该竞价后再次竞得土地，并被引入空置占有。对于期间收取的孳息发生争议：帕特鲁伊努斯主张孳息属于国库。当然，若孳息是在第一次判售与随后加价之间取得，应归出卖人所有；通常也会这样处理：土地先按附解除条件方式判售，之后又有人提出更优条件。但我们不应因两次判售的买受人是同一人而改变这一点。可是，两次判售都在葡萄收获季节的期间进行，于是放弃了上述处理方式，认为孳息应归买受人。帕比尼安与梅西乌斯提出新的意见：土地既由佃户耕种，将全部孳息剥夺并不公平；应由佃户收取孳息，而买受人取得当年租金，以免国库因佃户未能使用土地而对其承担责任；这就如同买卖时已有此项约定。最终裁判仍采纳他们的意见：若土地由所有人亲自耕种，买受人取得全部孳息；若土地由佃户耕种，买受人取得租金。特里丰尼努斯接着询问，如何处理判售前已经收取、尚存于土地上的干燥果实；保罗答复说，若判售时该年度租金的到期日尚未到来，买受人也应取得这些果实。
