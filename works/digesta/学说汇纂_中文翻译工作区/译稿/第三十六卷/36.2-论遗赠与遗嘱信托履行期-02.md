# D.36.2 论遗赠或遗嘱信托履行期何时届至（*Quando dies legatorum vel fideicommissorum cedat*，第二段）

<a id="36.2.7.4"></a>**4.**从未适婚年龄子女的替补继承人处所作的遗赠也同样如此：遗赠会移转给受遗赠人的继承人。

<!-- source-p 483 -->
<a id="36.2.7.5"></a>**5.**不过，仍可讨论以下情形：替补继承人受命在未适婚年龄的儿子于达到适婚年龄前死亡时，向塞伊乌斯给付一百；若塞伊乌斯在受监护人仍在世时死亡，他是否会将遗赠移转给自己的继承人，仿佛遗嘱中明示了该条件？更可取的见解是，遗赠会移转给受遗赠人的继承人。

<!-- source-p 484 -->
<a id="36.2.7.6"></a>**6.**但有时，继承人接受继承会使遗赠履行期延后，例如遗赠给获释奴隶，或遗赠给某人一名奴隶、并因此另有某物遗赠给该奴隶的情形：给奴隶的遗赠，在继承被接受之前，其履行期不会开始。

<!-- source-p 499 -->
<a id="36.2.12.pr."></a>**序言。**该遗赠的履行期并非仅开始一次，而是在每一年分别开始。

<!-- source-p 500 -->
<a id="36.2.12.1"></a>**1.**不过，履行期究竟在每年年初开始，还是在该年结束时开始，曾有争议。拉贝奥、萨宾、塞尔苏斯、卡西乌斯和尤利安对于所有逐年遗留的遗赠均赞同：该遗赠的履行期在每一年年初开始。

<!-- source-p 501 -->
<a id="36.2.12.2"></a>**2.**因此，尤利安说，如果该遗赠给奴隶，而奴隶在第一年或第二年之后获得自由，他便自行取得该遗赠。

<!-- source-p 502 -->
<a id="36.2.12.3"></a>**3.**塞尔苏斯还写道，尤利安也赞同此说：该遗赠的履行期自死亡之日起开始，而非自继承被接受之日起开始；即使多年后才接受继承，受遗赠人仍有权取得所有年度的遗赠。

<!-- source-p 503 -->
<a id="36.2.12.4"></a>**4.**若遗赠按年给付，我认为也应当考虑每年的起始日；但若立遗嘱人的意思显然是将款项分作年度分期，只为继承人着想，使其不必急于给付，则另当别论。

<!-- source-p 504 -->
<a id="36.2.12.5"></a>**5.**若遗赠如此写作“按年”或“每年”提供住所或教育，则应推定立遗嘱人的意思是：在住所租金或教育费用应付的同一日期给付遗赠。

<!-- source-p 505 -->
<a id="36.2.12.6"></a>**6.**最后，庞波尼乌斯写道，遗赠写作“逐年”或“每年”，还是“逐月”或“每月”，又或“逐日”或“每日”，并无区别。我也赞同这一见解。因此，即使遗嘱写作“每年给付若干枚金币”，也应作相同处理。

<!-- source-p 506 -->
<a id="36.2.12.7"></a>**7.**若某人概括地受遗赠一名奴隶，而他在通过请求取得该奴隶之前死亡，该遗赠会移转给他的继承人。

<!-- source-p 507 -->
<a id="36.2.12.8"></a>**8.**若遗赠如此写道：“由塞伊乌斯选定的人归提提乌斯所有”，而塞伊乌斯在作出选择后死亡，则受遗赠人已取得请求该物的权利。

<a id="36.2.14"></a>**36.2.14**

<!-- source-p 512 -->
乌尔比安《萨宾评注》第二十四卷。

<!-- source-p 513 -->
<a id="36.2.14.pr."></a>**序言。**遗嘱规定，由受遗赠人在用益权与十个单位的钱款中任选其一时，应分别考察立遗嘱人死亡与继承被接受这两个时间：对十个单位的钱款而言，应考察死亡；对用益权而言，应考察继承被接受。尽管选择权属于受遗赠人，但在立遗嘱人尚未死亡，或立遗嘱人已经死亡而继承尚未被接受时，均还不能进行选择。

<!-- source-p 514 -->
<a id="36.2.14.1"></a>**1.**尤利安接着询问：如果受遗赠人在立遗嘱人死亡后去世，十个单位的钱款是否会移转给其继承人？他在《学说汇纂》第三十七卷中写道，可以认为这笔钱会移转，因为受遗赠人死亡时，遗赠履行期已经开始。尤利安以如下遗赠作为论据：“我的继承人应给塞娅十个单位的钱款；若她生育，则给她一处庄园。”他说，如果她在分娩前死亡，十个单位的钱款会移转给她的继承人。

<!-- source-p 515 -->
<a id="36.2.14.2"></a>**2.**若遗赠给家子并明定应直接给付给他，该遗赠可以有效成立，继承人也不应因没有向父亲而向儿子给付而被追责。设想遗嘱明确写道“应给付给儿子”：如果父亲请求给付，便会因抗辩而被驳回。

<!-- source-p 516 -->
<a id="36.2.14.3"></a>**3.**遗赠履行期开始后，受遗赠人若转入他人权力之下，遗赠应归属于对其享有权力的人；随其转入权力之下，其应得之物也一并移转。但若遗赠附有条件，遗赠不会立即移转，而应等待条件成就；条件成就时，遗赠归属于对受遗赠人享有权力的人。如果届时受遗赠人已成为自权人，则遗赠归其本人取得。
