# D.36.1 论特雷贝利安元老院决议（*Ad senatus consultum Trebellianum*）

<!-- source-p 001 -->
<a id="1"></a><a id="36.1"></a>**36.1.0 论特雷贝利安元老院决议**（*Ad senatus consultum Trebellianum*）。

<!-- source-p 002 -->
<a id="36.1.1"></a>**36.1.1**

<!-- source-p 003 -->
乌尔比安《遗嘱信托论》第三卷。

<!-- source-p 004 -->
<a id="36.1.1.pr."></a>**序言**　关于单项财产遗嘱信托的论述既已结束，现在让我们转而解释特雷贝利安元老院决议。

<!-- source-p 005 -->
<a id="36.1.1.1"></a>**1**　该元老院决议制定于尼禄在位期间，日期为九月朔日前第八日；当时安奈乌斯·塞涅卡与特雷贝利乌斯·马克西穆斯担任执政官。其条文如下：

<!-- source-p 006 -->
<a id="36.1.1.2"></a>**2**　“既然在一切遗嘱信托继承中，若就该遗产发生诉讼，理应由取得权利及收益之人承担这些诉讼，而不应使任何人因其诚信而陷于危险，这最为公平；因此，元老院决议：通常可以对继承人及其继承人提起，或由继承人及其继承人提起的诉讼，不得对或由依遗嘱嘱托返还遗产的人提起；而应对或由依遗嘱返还给遗嘱信托受益人的人提起诉讼，以便今后更有力地保障死者的最后意愿。”

<!-- source-p 007 -->
<a id="36.1.1.3"></a>**3**　该元老院决议消除了某些人的疑虑；他们原本拒绝接受继承，或是担心诉讼，或是以担心诉讼为借口。

<!-- source-p 008 -->
<a id="36.1.1.4"></a>**4**　元老院固然意在救济继承人，但也救济了遗嘱信托受益人。继承人被起诉时可以援引抗辩，这一方面救济了继承人；另一方面，继承人提起诉讼时会因抗辩而被驳回，而遗嘱信托受益人则有权起诉，这无疑是对受益人的保护。

<!-- source-p 009 -->
<a id="36.1.1.5"></a>**5**　该元老院决议既适用于某人依据遗嘱成为继承人并受嘱托返还遗产，也适用于某人依法定继承成为继承人并受嘱托返还遗产。

<!-- source-p 010 -->
<a id="36.1.1.6"></a>**6**　该元老院决议也适用于军人家子的遗嘱处分；军人家子可以就军营特有产或准军营特有产订立遗嘱。

<!-- source-p 011 -->
<a id="36.1.1.7"></a>**7**　遗产占有人或其他继受人，也可以依特雷贝利安元老院决议返还遗产。

<!-- source-p 012 -->
<a id="36.1.1.8"></a>**8**　问题在于：某人依特雷贝利安元老院决议，基于遗嘱信托事由取得返还的遗产后，是否也可以通过再次返还遗产，依据同一元老院决议移转诉权？尤利安写道，他本人再次返还时也会移转诉权；梅基安努斯也赞同此说，我们认为同样正确。

<!-- source-p 013 -->
<a id="36.1.1.9"></a>**9**　此外，若某人受嘱托将遗产返还给两人：一人无条件或于将来某日取得，另一人附条件取得；而该继承人声称遗产有疑虑，元老院决议认为，应暂将全部遗产返还给受嘱托无条件或定期取得遗产之人。条件成就后，若另一遗嘱信托受益人愿意承受其份额，诉权即依法移转给该受益人。

<!-- source-p 014 -->
<a id="36.1.1.10"></a>**10**　若家子或奴隶被指定为继承人并受嘱托返还遗产，而其父亲或主人代为返还，则诉权依特雷贝利安元老院决议移转；即使他们是以自己的名义受嘱托返还，法律亦同。

<!-- source-p 015 -->
<a id="36.1.1.11"></a>**11**　若父亲本人受嘱托将遗产返还给自己的儿子，法律亦同。

<!-- source-p 016 -->
<a id="36.1.1.12"></a>**12**　若受嘱托返还遗产的是未成年人或精神错乱者的监护人或保佐人，毫无疑问，应适用特雷贝利安元老院决议。

<!-- source-p 017 -->
<a id="36.1.1.13"></a>**13**　曾有人提出问题：若未成年人受嘱托将遗产返还给自己的监护人，是否可以在监护人同意的情况下返还？神圣塞维鲁皇帝的裁决是：不得在监护人同意下返还遗产，因为任何人都不能作为自己事务的同意人。

<!-- source-p 018 -->
<a id="36.1.1.14"></a>**14**　但是，未成年人可以将遗产返还给自己的保佐人，因为返还遗产并不需要保佐人同意。

<!-- source-p 019 -->
<a id="36.1.1.15"></a>**15**　若受嘱托返还遗产的是某一社团或团体，则应由其成员作出决议，并分别审查各成员的身份；如此作出的返还有效。因为不能认为该团体中的任何成员是在向自己返还遗产。

<!-- source-p 020 -->
<a id="36.1.1.16"></a>**16**　若继承人受命先取一座庄园，并受嘱托返还遗产，则应依特雷贝利安元老院决议返还遗产。庄园已设质押也不会造成太大影响，因为针对债务人的人的诉权并不随庄园移转，而是归属于依据该元老院决议取得遗产的人。但遗嘱信托受益人应向继承人提供担保：若债权人追夺庄园，继承人将获得担保。尤利安则认为无需提供担保，而应评估未提供担保时庄园的价值，即继承人不提供担保可以出售的价格。若不提供担保仍可按相当于遗产四分之一的价格出售，则诉权依特雷贝利安元老院决议移转；若只能以更低价格出售，则应保留不足部分，并按同一决议返还其余遗产。这一见解解决了许多疑问。

<!-- source-p 021 -->
<a id="36.1.1.17"></a>**17**　若某人拥有四百，却遗赠三百；扣除二百后又嘱托继承人将遗产返还给塞伊乌斯，那么遗嘱信托受益人是否应承担三百的负担，还是只在其从遗产中实际取得的范围内承担？尤利安说，可以向其请求三百，但对遗嘱信托受益人的诉权不得超过二百；对继承人则可请求一百。我认为尤利安的见解正确，以免遗嘱信托受益人承受超过其从遗产中取得部分的损失。任何人所承担的遗赠给付，不应超过其从遗产中所得；即使法尔奇狄亚法不适用，也是如此，正如神圣庇乌斯皇帝敕答所确认的。

<!-- source-p 022 -->
<a id="36.1.1.18"></a>**18**　因此，即使依军人的遗嘱，遗赠给付也不得超过扣除债务后遗产的数额。但不允许遗嘱信托受益人保留四分之一。

<!-- source-p 023 -->
<a id="36.1.1.19"></a>**19**　因此，涅拉提乌斯写道：若继承人受嘱托返还全部遗产，且不得扣除法尔奇狄亚份额，并且又受嘱托将其取得的遗产返还给他人，则其未必应从第二顺位遗嘱信托受益人处扣除四分之一；除非继承人意在仅使第一顺位受益人获得该项利益。

<!-- source-p 024 -->
<a id="36.1.1.20"></a>**20**　但是，若某人拥有四百，将二百遗赠给提图斯，并嘱托继承人将遗产的一半返还给森普罗尼乌斯，尤利安说，应依特雷贝利安元老院决议返还遗产；遗赠请求权应予分割：一百可向继承人请求，另一个一百则由受遗赠人向遗嘱信托受益人请求。尤利安如此主张，是因为按此计算，继承人可以完整取得四分之一，即完整的一百。

<!-- source-p 025 -->
<a id="36.1.1.21"></a>**21**　尤利安还写道：若某人拥有四百，遗赠三百，并嘱托继承人在扣除一百后将遗产返还给森普罗尼乌斯，则应认为，遗产在扣除一百后返还时，遗赠诉权即对遗嘱信托受益人发生。

<a id="36.1.2"></a>**36.1.2**

某人留下四百，遗赠给提图斯三百，并嘱托继承人将遗产返还给你；继承人依裁判官命令，因认为遗产有疑虑而接受继承，随后将遗产返还。有人询问你应向受遗赠人给付多少。应答称：推定立遗嘱人意在附带遗赠负担返还遗嘱信托，因此你应向提图斯给付全部三百。因为继承人应被理解为受嘱托代替你的位置；如果继承人未受嘱托返还遗产，而是履行了所有遗产事务，即给付遗赠后，自己本来会剩下的部分，现在就应由其返还给你。那么他会剩下多少？当然是一百；继承人受嘱托交给你的正是这一百。因此，应如此计算法尔奇狄亚份额：仿佛继承人被判令给提图斯三百，并被判令给你一百。由此可知，若继承人自愿接受继承，他应给提图斯二百二十五，给你七十五。因此，提图斯所得不会超过遗产未经裁判官命令而被接受时本应取得的数额。

<a id="36.1.3.pr."></a>**序言**　马尔切鲁斯在尤利安那里如此论述这一情形：若立遗嘱人说遗赠应由继承人承担，且继承人自愿接受继承，则应这样计算法尔奇狄亚份额：仿佛遗嘱信托为四百，遗赠为三百；将三百分成七份，遗嘱信托受益人取得四份，受遗赠人取得三份。但若继承人声称遗产有疑虑，并非自愿接受继承而是随后返还遗产，则继承人本会从四百中取得的一百仍归遗嘱信托受益人；至于其余三百，仍按同一比例分配，即受益人取得四份，受遗赠人取得三份。因为若遗产被认为有疑虑，受遗赠人便取得比继承人自愿接受时更多的利益，这是极不公平的。

<!-- source-p 032 -->
<a id="36.1.3.1"></a>**1**　关于有疑虑遗产所作的上述论述，也适用于法尔奇狄亚法不适用的遗嘱，例如军人遗嘱及其他类似情形。

<!-- source-p 033 -->
<a id="36.1.3.2"></a>**2**　庞波尼乌斯还写道：若某人受嘱托在扣除遗赠后返还遗产，问题是，他是否应完整给付遗赠，只能从遗嘱信托中扣除四分之一；还是可以同时从遗赠和遗嘱信托中扣除四分之一？他转述阿里斯顿答称，应从所有项目中扣除，即从遗赠和遗嘱信托中均予扣除。

<!-- source-p 034 -->
<a id="36.1.3.3"></a>**3**　继承人已经转让的财产，应计入继承人可保留的四分之一。

<!-- source-p 035 -->
<a id="36.1.3.4"></a>**4**　某人将子女指定为份额不等的继承人，并给予他们先取遗赠，从而将大部分财产分给子女；他嘱托其中无子女而死亡的人，将自己的份额返还给兄弟。我们的皇帝敕答称，先取遗赠也包含在遗嘱信托之中，因为立遗嘱人提到的不是遗产份额，而只是一般意义上的份额；而先取遗赠也应视为包含在该份额之内。

<!-- source-p 036 -->
<a id="36.1.3.5"></a>**5**　若受嘱托返还遗产的人在进行家族身份调查前，就开启遗嘱、接受继承，或实施元老院决议所禁止的其他行为，因而遗产被公告归公，则国库将连同遗产负担一并取得该遗产。因此，指定继承人原本可取得的四分之一利益归于国库，诉权依特雷贝利安元老院决议移转。即使继承人阻止遗嘱执行人出庭、阻止证人到场，未为立遗嘱人的死亡抗辩，或因其他原因导致国库请求取得遗产，四分之一利益同样归于国库，而其余四分之三应返还给遗嘱信托受益人。

由于指定继承人可能担心遭受损失而不愿接受继承，法律已作出安排：若遗嘱信托受益人表示愿自行承担风险接受继承，并要求将遗产返还给自己，裁判官便可强令指定继承人接受继承并返还遗产。若如此处理，诉权依特雷贝利安元老院决议移转；继承人返还遗产时不得享有四分之一利益，因为他是在他人承担风险的情况下接受继承，理应被剥夺一切利益。遗产是否有清偿能力并不重要；只要指定继承人拒绝接受继承即可。也不必调查遗产有无清偿能力。应考察的是拒绝接受继承之人的意见、恐惧或借口，而非遗产的实际状况；这并非没有道理。不能责备指定继承人为何担心接受遗产，或为何不愿接受，因为人们的考虑各不相同：有些人害怕事务繁多，有些人害怕受人骚扰，有些人担心债务累积，即使遗产看似富足；有些人担心怨恨或嫉妒；还有些人想要无须自己承担负担，便对遗产留给的人施以恩惠。

<a id="36.1.6.pr."></a>**序言**　不仅在场者可以拒绝接受继承，缺席者也可以，或可通过书信表示拒绝。即使针对缺席者，也可以请求作出裁决；无论他们拒绝接受继承并返还遗产的意思明确与否，均可如此处理。因此，他们无须亲自到场。

<!-- source-p 046 -->
<a id="36.1.6.1"></a>**1**　应当记住，元老院决议所说的是指定继承人。因此，尤利安曾讨论其是否适用于无遗嘱继承。较为正确且为我们所遵循的法律规则是：该元老院决议也适用于无遗嘱继承，无论继受人是法定继承人还是依裁判官法取得继承权之人。

<!-- source-p 047 -->
<a id="36.1.6.2"></a>**2**　该元老院决议也适用于处于家父权下的儿子及其他必然继承人；裁判官可以强令他们接受遗产，继而予以返还。若他们如此行事，即视为已移转诉权。

<!-- source-p 048 -->
<a id="36.1.6.3"></a>**3**　若无人继承的遗产被交付国库，而国库不愿承认该遗产并返还给遗嘱信托受益人，则最公平的做法是将国库视为已请求取得遗产，并由其作出返还。

<!-- source-p 049 -->
<a id="36.1.6.4"></a>**4**　同样，若作为指定继承人的市镇居民声称遗产有疑虑，应认为可以强令他们承认继承并返还遗产。对于社团也应如此处理。

<!-- source-p 050 -->
<a id="36.1.6.5"></a>**5**　提图斯被指定为继承人，塞姆普罗尼乌斯被指定为替补继承人；提图斯受嘱托将遗产返还给塞姆普罗尼乌斯。提图斯声称遗产有疑虑。问题是，是否应强令他接受继承并返还遗产？对此可以讨论；但较为正确的见解是，应强令他如此行事，因为塞姆普罗尼乌斯作为指定继承人而非替补继承人取得遗产，可能有利害关系；替补继承权还可能附有遗赠或释放奴隶的负担。若遗嘱信托受益人本身是法定继承人，法律规则也相同。

<!-- source-p 051 -->
<a id="36.1.6.6"></a>**6**　若某人受命在另一地点接受继承，却声称遗产有疑虑，尤利安写道，应强令其接受继承；其情形类似受嘱托在将来某日返还遗产的人。

<a id="36.1.9.pr."></a>**序言**　尤利安还说，若某人受命在另一地点接受继承，却因公务而缺席，也应强令其接受继承并返还遗产；他缺席期间亦然。

<a id="36.1.9.1"></a>**1**　当然，若某人请求并获准取得考虑是否接受继承的期限，随后在该期限届满后接受继承并返还遗产，就不能认为他是受强迫行事。因为他并非因被强令而接受有疑虑的遗产，而是在考虑期限届满后自愿接受。

<!-- source-p 062 -->
<a id="36.1.9.2"></a>**2**　若某人声称遗产有疑虑，就应声明接受继承对自己并无益处；不应仅说遗产没有清偿能力，而应声明自己认为接受该遗产并不有利。

<!-- source-p 063 -->
<a id="36.1.9.3"></a>**3**　若某人被指定为附条件继承人，在条件悬而未决期间，即使他准备返还遗产，也不能采取任何行动。

<!-- source-p 064 -->
<a id="36.1.10"></a>**36.1.10**

<!-- source-p 065 -->
盖尤斯《遗嘱信托论》第二卷。

<!-- source-p 066 -->
若遗产在期限届满或条件成就前即被返还，诉权不会移转，因为遗产并未按立遗嘱人嘱托的方式返还。当然，条件成就或期限届满后，若受益人认可此前的遗产返还，较为宽厚的解释是：应认为诉权自此时起已经移转。

<!-- source-p 067 -->
<a id="36.1.11"></a>**36.1.11**

<!-- source-p 068 -->
乌尔比安《遗嘱信托论》第四卷。

<!-- source-p 069 -->
<a id="36.1.11.pr."></a>**序言**　尤利安曾记载：遗嘱将遗赠留给指定继承人，条件是“若其不成为继承人”；继承人因此声称遗产有疑虑，以免丧失遗赠。遗嘱信托受益人应向他提供相当于遗赠数额的担保，之后即可强令其接受继承。尤利安不接受如下做法：继承人仿佛未曾接受继承那样，向共同继承人请求遗赠（因为他已经接受继承）；他更倾向于由遗嘱信托受益人向其给付遗赠。若继承人还主张其他自身利益，也不得强令其接受继承，除非遗嘱信托受益人补偿其损失或利益损失，或者裁判官免除其所拒绝承担的负担。

<!-- source-p 070 -->
<a id="36.1.11.1"></a>**1**　尤利安还说：若父亲指定两人作为继承人，其中一人是未适婚的儿子，并将两人互相指定为替补继承人，则在后位遗嘱中取得遗嘱信托的人，只要能强令一名指定继承人接受父亲的遗产即可。如此，父亲的遗嘱便得到确认；两名指定继承人均可因替补继承的安排而被强令接受遗产并予返还。

<!-- source-p 071 -->
<a id="36.1.11.2"></a>**2**　还应考察：若遗嘱信托受益人不在场，由代理人向裁判官提出申请，能否为其返还遗产？我认为，即使受益人缺席，也可以强令指定继承人接受继承并返还遗产；继承人不必担心因此遭受损失，因为裁判官能够给予救济，无论受益人是否已提供担保，亦无论受益人在遗产返还前死亡与否。神圣庇乌斯皇帝的敕答中有一个类似案例，可作为此事的先例。安提斯提娅临终时指定提图斯为继承人，并以直接方式释放阿尔比娜；她以遗嘱信托方式将阿尔比娜的女儿留给提图斯，并嘱托他释放该女儿；她还嘱托提图斯将遗产返还给已获释放的阿尔比娜之女。提图斯声称遗产有疑虑后，神圣庇乌斯皇帝敕答称，应强令其接受继承。提图斯接受继承后，阿尔比娜即可取得自由，且其女儿应交给她，由她释放；并应为获释的女儿指定监护人，由监护人同意后立即将遗产返还给该女儿，尽管提图斯原受嘱托要等她达到适婚年龄时才返还。皇帝又说，可能发生这样的情形：获得遗嘱信托所授自由和遗产的人先行死亡，而受嘱托接受继承者不应因此遭受损失；因此设立救济：若发生上述任何一种情况，便准许出售安提斯提娅的财产，犹如无人继承她的遗产。既然神圣庇乌斯皇帝已表明，应救济被强令接受继承的指定继承人，那么在其他类似情形中，也应遵循这一先例；即使情况有所不同，也应将遗嘱信托遗产返还给迫使继承人接受继承并要求其返还遗产的人。

<a id="36.1.12"></a>**36.1.12**

<!-- source-p 073 -->
帕比尼安《疑问集》第二十卷。

<!-- source-p 074 -->
但是，若遗嘱信托遗产附条件留给按份指定的继承人，皇帝提图斯·安敦尼乌斯敕答称，其先前的敕令不适用，也不应通过非常救济帮助未适婚人；尤其是该救济是一项新的恩惠，却会损害他人利益。

<a id="36.1.13"></a>**36.1.13**

<!-- source-p 076 -->
乌尔比安《遗嘱信托论》第四卷。

<!-- source-p 077 -->
<a id="36.1.13.pr."></a>**序言**　遗嘱信托附有条件时，受益人不能以某种理由为由拒绝接受遗产，致使条件无法成就、诉讼悬而未决，因为这不会造成任何损失。

<!-- source-p 078 -->
<a id="36.1.13.1"></a>**1**　根据我们已经说明的内容，继承人到场已不再是必要条件。

<!-- source-p 079 -->
<a id="36.1.13.2"></a>**2**　若对遗嘱的效力提出问题，继承人声称遗产有疑虑时，不应听取其意见。即使有人主张立遗嘱人没有遗嘱能力、遗嘱效力存疑，或立遗嘱人身份有问题，也不应听取继承人的意见。

<!-- source-p 080 -->
<a id="36.1.13.3"></a>**3**　那么，若争议涉及遗嘱信托的效力，应如何处理？裁判官不能置之不理。但若遗嘱信托受益人说：“请他先接受继承，然后再审理此事”，又该如何？我认为，若案件审理需要较长时间，有时应听取遗嘱信托受益人的意见。例如，遗嘱信托的措辞需从远处调取，或遗嘱信托数额需要充分审议；此时应强令继承人先接受继承，以免继承人在遗嘱信托受益人受欺骗前死亡。

<!-- source-p 081 -->
<a id="36.1.13.4"></a>**4**　适时应当考察，谁能强令人接受继承并返还遗产。例如，若被指定为继承人的是裁判官或执政官，并声称遗产有疑虑，能否强令其接受继承并返还？应当说，裁判官无权命令另一裁判官，执政官也无权命令另一执政官；不过，若他们服从对方的司法管辖，裁判官通常会对他们行使司法权。若裁判官本人被指定为继承人并声称遗产有疑虑，他也不能强令自己接受继承，因为他不能同时兼任三个职务：提出遗产有疑虑、受强令之人以及强令人。在所有这些或类似情形中，应请求皇帝给予救济。

<!-- source-p 082 -->
<a id="36.1.13.5"></a>**5**　若某人为家子并担任公职，他可以强令处于自己权力下的父亲接受其声称有疑虑的遗产并予返还：

<a id="36.1.14"></a>**36.1.14**

<!-- source-p 084 -->
赫莫杰尼安《法学概要》第四卷。

<!-- source-p 085 -->
因为就公法而言，家父权并不适用。

<!-- source-p 086 -->
<a id="36.1.15"></a>**36.1.15**

<!-- source-p 087 -->
乌尔比安《遗嘱信托论》第四卷。

<!-- source-p 088 -->
<a id="36.1.15.pr."></a>**序言**

<!-- source-p 089 -->
<a id="36.1.15.1"></a>**1**　已经抛弃继承的人，若提出正当理由，也会被强令接受该继承并返还遗产。

<!-- source-p 090 -->
<a id="36.1.15.2"></a>**2**　当然，若遗产已被出售，裁判官不应命令任何人返还遗产，甚至不应命令未适婚人返还，除非有正当理由；神圣庇乌斯皇帝敕答也作如是说。

<!-- source-p 091 -->
<a id="36.1.15.3"></a>**3**　若某人被强令接受一份包含后位遗嘱的遗嘱所设继承，问题是：接受继承是否也使后位遗嘱生效；该后位遗嘱原本似乎因未接受父亲遗产而失效？尤利安在《学说汇纂》第十五卷写道，后位遗嘱也应得到确认。这一见解最为正确：没有人会怀疑，遗嘱中的遗赠应予履行、释放自由应发生效力，以及遗嘱中的其他处分均应有效，仿佛继承人是自愿接受继承一样。

<!-- source-p 092 -->
<a id="36.1.15.4"></a>**4**　被强令接受继承的人既然不能享有其他利益，在此情形下也不得因事后反悔而保留四分之一；我发现，我们的皇帝和他的神圣父亲均曾作出这样的敕答。

<!-- source-p 093 -->
<a id="36.1.15.5"></a>**5**　但并非任何人都能因有疑虑的遗产被抛弃而强令接受继承并返还遗产；只有诉权可以移转给他的人才能如此。因为若强令某人接受继承只是为了返还遗产利益，而让其本人仍受遗产负担拘束，就不公平了。

<!-- source-p 094 -->
<a id="36.1.15.6"></a>**6**　因此，若某人只获遗赠一笔钱款，则不能强令其接受继承，即使已提出赔偿其损失的担保，也不例外。

<!-- source-p 095 -->
<a id="36.1.15.7"></a>**7**　因此，只有受嘱托返还“遗产”之人，才会被强令返还。

<!-- source-p 096 -->
<a id="36.1.15.8"></a>**8**　但是，若有人受嘱托返还“财产”“家产”或“钱款”，或受嘱托返还“我的全部财产”——

<!-- source-p 097 -->
<a id="36.1.16"></a>**36.1.16**

<!-- source-p 098 -->
保罗《遗嘱信托论》第二卷。

<!-- source-p 099 -->
或“我的一切财产”，

<!-- source-p 100 -->
<a id="36.1.17"></a>**36.1.17**

<!-- source-p 101 -->
乌尔比安《遗嘱信托论》第四卷。

<!-- source-p 102 -->
<a id="36.1.17.pr."></a>**序言**　此人可以被强令接受继承。若受嘱托返还“我的财产”“我的资产”“我所有的一切”“我的财产清单”或“我的财富”，也同样可以被强令接受继承。若立遗嘱人说“我的特有产”，该人也应被强令接受继承，因为许多人惯于用亲昵的说法将自己的全部财产称为特有产。立遗嘱人在此同样是嘱托返还其遗产。我知道梅基安努斯对其中一些措辞存有疑问，认为应根据立遗嘱人的意思判断，他说的究竟只是钱款，还是其全部遗产。但在含义不明时，我认为立遗嘱人较可能指的是全部遗产，以免遗嘱信托落空。

<!-- source-p 103 -->
<a id="36.1.17.1"></a>**1**　若某人如此受嘱托：“请将你从我的遗产或财产中所取得的一切返还”，则可强令其依特雷贝利安元老院决议接受继承并返还遗产，尽管严格说来，只有扣除负担后实际归于某人的财产，才称得上“到达”该人手中。

<!-- source-p 104 -->
<a id="36.1.17.2"></a>**2**　概括而言，只有受嘱托返还某项特定物或特定数额的人，才不能被强令接受继承并返还遗产。除此之外，只要能看出立遗嘱人指的是全部遗产，就毫无疑问：无论其声称遗产有疑虑，还是自愿接受继承，均可强令其接受；而诉权会依特雷贝利安元老院决议移转。

<!-- source-p 105 -->
<a id="36.1.17.3"></a>**3**　由此产生问题：若某人受嘱托在扣除债务或遗赠后返还遗产，声称遗产有疑虑时，能否强令其接受继承并返还？因为严格说来，他受嘱托返还的似乎不是遗产本身，而是遗产剩余部分。有人（例如梅基安努斯）认为，这种扣除无效；因为法律不允许扣除特定数额，正如某人受嘱托在扣除债务或遗赠后返还庄园时，不能作此扣除；庄园本身并不能扣减债务或遗赠。但尤利安认为，特雷贝利安元老院决议仍适用。为避免遗嘱信托受益人承受双重负担——继承人先扣除债务或遗赠，又由债权人和受遗赠人向其追索——遗产依该决议返还后，受益人应拒绝继承人的扣除，或者由继承人作出担保，保证受益人不会受到受遗赠人及其他人的追索。

<!-- source-p 106 -->
<a id="36.1.17.4"></a>**4**　若指定继承人受嘱托返还的不是全部遗产，而只是其中一部分；或者受嘱托将遗产返还给两人，但其中一人请求返还，另一人拒绝，则元老院决议规定，在这两种情形下，声称遗产有疑虑的人均可免除责任，全部遗产转归强令接受继承之人。

<!-- source-p 107 -->
<a id="36.1.17.5"></a>**5**　若立遗嘱人并非嘱托继承人返还其自己遗产的一半，而是嘱托返还塞娅遗产（该遗产归其所有），无论返还全部还是其中一部分；指定继承人又声称遗产有疑虑，那么，既然帕比尼安所说的诉权依特雷贝利安元老院决议移转应予认可，就可以说：若继承人声称遗产有疑虑，应强令其接受并返还遗产，全部遗产也都归于受返还之人。

<!-- source-p 108 -->
<a id="36.1.17.6"></a>**6**　若军人嘱托返还意大利的财产或行省的财产，也应认为，声称遗产有疑虑的人会被强令接受继承并返还。正如梅基安努斯在《遗嘱信托论》第六卷中精确指出的：军人既可指定某项特定财产的受遗赠人，并使诉权归属于该人；同理，诉权也会依特雷贝利安元老院决议移转。虽然我们认可这样一项规则：若某人嘱托返还其继承所得的遗产，或其在某一地区拥有的财产，诉权不会依特雷贝利安元老院决议移转；梅基安努斯仍说，军人遗嘱应作相反处理。正如他所言，既然允许军人在指定继承人时区分不同类别的财产，那么，若其通过遗嘱信托要求指定继承人作同样区分，也应适用特雷贝利安元老院决议。

<!-- source-p 109 -->
<a id="36.1.17.7"></a>**7**　若某人指定两名继承人，并将两人互相指定为替补继承人；他嘱托两人，无论是一人还是两人均成为继承人，都应在五年后将其遗产的一半返还给某人。指定继承人声称遗产有疑虑，而遗嘱信托受益人请求由自己承担风险接受继承；元老院决议认为，可强令两名继承人或其中一人接受继承并返还遗产，使遗嘱信托受益人得以对其提起诉讼，犹如遗产已依特雷贝利安元老院决议返还。

<!-- source-p 110 -->
<a id="36.1.17.8"></a>**8**　梅基安努斯写道：若一名遗嘱信托受益人缺席，在场的受益人请求由自己承担风险接受继承，并使诉权全部移转给强令继承人之人；若缺席者愿意接受遗嘱信托，就可向在场者请求给付。梅基安努斯接着说，在场者不得对其他受益人主张保留四分之一，因为继承人本人也不能保留。

<!-- source-p 111 -->
<a id="36.1.17.9"></a>**9**　同一梅基安努斯还提出问题：某人受嘱托向两人或多人返还遗产，其中一人强令其接受继承时，他能否针对未提出请求者的份额享有法尔奇狄亚法利益？无论这些人之后也请求返还，还是由他人继受其权利，均如此。既然我们现行法律规定全部遗产转归强令接受继承之人，那么应当认为，被强令者已丧失保留四分之一的权利，因为诉权已经全部转移给强令人。当然，若遗嘱信托受益人并未要求将全部遗产转给自己，那么其他受益人开始请求返还遗产时，应认为继承人仍可享有法尔奇狄亚法利益。因此，梅基安努斯正确指出，关键在于受益人请求返还的是全部遗产还是仅其自己的份额。若仅转移其份额，剩余部分仍可适用法尔奇狄亚法；若全部遗产均已转移，该法的利益便不再适用。

<!-- source-p 112 -->
<a id="36.1.17.10"></a>**10**　若某人受嘱托将遗产返还给两人共有的奴隶，其中一位主人声称遗产有疑虑并要求强令继承人接受继承，另一位主人却拒绝接受返还，则应依两名受益人的情形处理：其中一人愿意承受遗产，另一人不愿意。

<!-- source-p 113 -->
<a id="36.1.17.11"></a>**11**　若父亲受嘱托将遗产返还给处于其权力下的儿子，儿子能否在父亲声称遗产有疑虑时强令其接受继承？毫无疑问，儿子可以通过裁判官强令父亲接受继承。

<!-- source-p 114 -->
<a id="36.1.17.12"></a>**12**　若该遗嘱信托涉及军营特有产，而儿子是服役中的家子，或担任其他公职，则更应当认为，他可以请求强令父亲接受并返还遗产，尽管这种请求看起来违背了儿子对父亲应尽的服从义务。

<!-- source-p 115 -->
<a id="36.1.17.13"></a>**13**　若某人受嘱托在释放自己的奴隶后返还遗产，无论释放是直接作出还是以遗嘱信托方式作出，可以说，该奴隶不能强令自己的主人接受继承；尽管主人若自愿接受继承，便必须履行以遗嘱信托方式给予奴隶的自由和返还遗产义务。梅基安努斯在《遗嘱信托论》第七卷也这样写道。

<!-- source-p 116 -->
<a id="36.1.17.14"></a>**14**　同一梅基安努斯提出问题：若某人准备向主人提供赔偿损失的担保，尤其是在已提出奴隶价款时，是否可以强令主人接受继承？他正确地说，不应在担保内容不确定的情况下，让主人承担接受继承的风险。

<!-- source-p 117 -->
<a id="36.1.17.15"></a>**15**　若某人不能完整取得遗产，却被指定为全部遗产的继承人并受嘱托返还全部遗产，由于他不会留下任何负担，便应强令其接受继承并返还遗产。

<!-- source-p 118 -->
<a id="36.1.17.16"></a>**16**　若我被指定为继承人并受嘱托释放斯提库斯，或者另有受遗赠人承担释放义务；同时我受嘱托将遗产返还给提图斯，而提图斯又受嘱托将同一遗产返还给斯提库斯，则斯提库斯可以强令我接受继承并返还遗产。

<!-- source-p 119 -->
<a id="36.1.17.17"></a>**17**　神圣庇乌斯皇帝曾裁断如下情形：某位继承人通过遗嘱信托被要求释放一名奴隶，另一位继承人则受嘱托返还遗产。神圣庇乌斯皇帝曾向卡西乌斯·德克斯特作出如下敕答：“潘菲卢斯立遗嘱时，将赫尔米亚遗赠给按份指定的继承人莫斯库斯·特奥多图斯。特奥多图斯接受继承后、潘菲卢斯的另一共同继承人尚未接受继承前，使赫尔米亚依法获得自由；因此，局面变为遗赠人不能被视为无遗嘱死亡。依赫尔米亚的请求，我认为，尤阿瑞斯图斯应承担风险，强令该继承人接受继承，并基于遗嘱信托事由返还遗产。”

<!-- source-p 122 -->
<a id="36.1.18.pr."></a>**序言**　有人曾根据一个案件讨论，能否通过遗嘱信托嘱托某人指定他人为继承人。元老院认为，不能嘱托任何人指定他人为继承人；但此类嘱托应被理解为要求该人将自己的遗产返还给对方，也就是返还其从遗产中取得的一切。

<!-- source-p 123 -->
<a id="36.1.18.1"></a>**1**　尤利安在《学说汇纂》第四十卷也说，以下遗嘱信托有效：“我嘱托你将提图斯的遗产返还”；前提是受嘱托人被提图斯指定为继承人。

<!-- source-p 124 -->
<a id="36.1.18.2"></a>**2**　我不仅可以嘱托自己指定的继承人另行指定继承人，也可以在遗赠或其他处分中作出同样嘱托；但他们仅在实际取得遗产利益的范围内负有义务。

<!-- source-p 125 -->
<a id="36.1.18.3"></a>**3**　若某人写道：“我请求你将某物给他”，或“请你为他留下遗嘱信托”，或“请你在遗嘱中给予他自由”，均应承认这些处分有效。既然元老院已认定指定继承人的相关处分有效，其他处分也应作同样理解。

<!-- source-p 126 -->
<a id="36.1.18.4"></a>**4**　若某人受嘱托在无子女而死亡时返还遗产，帕比尼安在《答复集》第八卷写道，自然子女也会使该条件不能成就；他对自由人和其共同获释者的情形也这样写道。至于自然子女，我认为应根据立遗嘱人的意思判断其所指的是哪类子女；这应结合嘱托遗嘱信托之人的身份、意思和处境确定。

<!-- source-p 127 -->
<a id="36.1.18.5"></a>**5**　我记得曾有一案件：一名女子嘱托儿子，若他无子女而死，便将遗产返还给其兄弟。儿子后来被流放到岛上，并在那里生育子女。问题是遗嘱信托条件是否未能成就。我们的意见是：若子女在流放前受孕，即使在流放后才出生，也会使条件不能成就；若子女在流放后才受孕，则如同是与他人所生，不会产生该效果，尤其是他的财产也可能因某种事由被国库请求取得。〔底本末句有异读或文字疑误，保留其大意待总校。〕

<!-- source-p 128 -->
<a id="36.1.18.6"></a>**6**　若某人受嘱托将遗产返还给自己的子女，或返还给其所选择的一名子女，帕比尼安在《答复集》第八卷认为，即使该人被流放，也可选择获释后将遗嘱信托返还给哪一名子女。但是，若某人被判处奴隶身份，且此前没有受孕的子女，则其不能再履行条件，且应视为无子女而死。但其死亡时，不应给予他帕比尼安给予被流放者的选择权。

<!-- source-p 129 -->
<a id="36.1.18.7"></a>**7**　若某人曾生有儿子，但儿子在他生前死亡，则应视为该人无子女而死。但若父子在海难、房屋倒塌、遇袭或其他事故中一同死亡，条件是否未能成就？我认为较妥当的是，条件并未未能成就，因为不能说儿子比父亲活得更久。因此，要么儿子活过父亲，从而使遗嘱信托条件消灭；要么儿子未活过父亲，条件便已成就。若无法查明谁先死，应较宜认定遗嘱信托条件已经成就。

<!-- source-p 130 -->
<a id="36.1.18.8"></a>**8**　神圣庇乌斯皇帝敕答称，若遗嘱信托如此写道：“儿子，我嘱托你：若我死时由他人继承我的遗产，你就将遗产返还给塞伊乌斯”，则应认为立遗嘱人指的是其子女。因此，某人无子女而死，虽有舅父依法取得遗产占有，敕答仍认定遗嘱信托条件已经成就。

<a id="36.1.23.pr."></a>**序言**　一名女子留下两个仍处于父亲权力下的儿子，随后改嫁他人；她指定后夫为继承人，并嘱托他在儿子们的父亲死亡后，将自己的遗产返还给儿子们或仍在世的儿子。儿子们后来被父亲解放，继父据称已将遗产返还给他们；不久，其中一个儿子在父亲仍在世时死亡。问题是，仍在世的儿子能否请求返还已给其兄弟的份额，理由是该份额过早给付？斯凯沃拉记载，神圣马尔库斯皇帝曾在御前审理类似案件：一名曾任法务官的斯巴达人布拉西达斯与妻子离婚后，妻子留下遗嘱信托，规定若其儿子们在其父亲死亡后已成为自权人，则应向他们给付；布拉西达斯遂解放了儿子们。解放后，儿子们请求给付遗嘱信托。神圣马尔库斯皇帝裁定，应立即向他们给付遗嘱信托；应从母亲的意思理解这一安排：她原本不相信父亲会解放儿子，故将给付推迟到父亲死亡之后；若她曾希望父亲会解放他们，就不会将遗嘱信托推迟到父亲去世。因此，我认为所述案件也应适用神圣马尔库斯皇帝的裁决；遗嘱信托已正确地向两个儿子均予给付。

<!-- source-p 151 -->
<a id="36.1.23.1"></a>**1**　毫无疑问，可以强令指定继承人接受继承并向奴隶返还遗产，无论给予他们的是直接自由还是遗嘱信托自由。继承人不得轻视提出强制请求之人的身份：即使奴隶尚不能请求遗嘱信托自由，也不能主张直接自由，但由于他有望取得自由和遗产，仍可自行向裁判官提出申请。

<!-- source-p 152 -->
<a id="36.1.23.2"></a>**2**　若继承人在很久之后才返还遗产，而遗嘱信托本应立即给付，则应扣除四分之一。因为请求人疏忽而未能收取的孳息，并非依死者的意思取得。若遗嘱信托附有条件或期限，则情形不同：在这种情况下，若期间所收孳息达到四分之一及其孳息的数额，便排除适用法尔奇狄亚法；因为期间取得的孳息，应视为依立遗嘱人的意思取得。

<!-- source-p 153 -->
<a id="36.1.23.3"></a>**3**　若某人受嘱托返还遗产，但奴隶死亡或其他财物灭失，公认的法律规则是，不应强令其返还其已不再拥有之物；不过，若其有过错，仍须承担责任，而且该过错须接近故意。涅拉提乌斯在《答复集》第一卷也如此写道。若其本应变卖财物却未变卖，且该疏忽属于重大过失，而非轻微或对自己财产一贯的疏忽，也须对此负责。若房屋因其过错被烧毁，也须承担责任。此外，现存的子畜及其后代也应纳入，因为它们不属于孳息。继承人本人为遗产财产支出的费用，也应予扣除。若房屋因时间经过而在未归责于继承人的情况下被他人取得时效，则因继承人无过错，最公平的处理是不令其承担任何给付义务。

<!-- source-p 154 -->
<a id="36.1.23.4"></a>**4**　某人指定女儿为继承人，并嘱托她若无子女而死，便将遗产返还给提图斯；女儿将确定数额的嫁资交给丈夫，随后在无子女的情况下死亡，并指定丈夫为继承人。有人询问，能否从遗产中扣除嫁资。我说，不能认定此举意在破坏遗嘱信托，因为该行为符合女子的贞洁，也符合父亲的意愿。因此应当认为，嫁资应从遗产中扣除，犹如她受嘱托返还剩余财产。若女子从遗产中取得的孳息足以支付嫁资，则应优先认为嫁资由孳息负担，而非由遗嘱信托负担。

<!-- source-p 155 -->
<a id="36.1.23.5"></a>**5**　适用特雷贝利安元老院决议，不仅要求受嘱托人返还遗产，还要求其被嘱托为继承人。最后，若遗产的一部分被遗赠给某人——我们认可遗产份额也可以作为遗赠——而该人受嘱托返还该份额，毫无疑问，不适用元老院决议；因此他也不得保留四分之一。

<a id="36.1.28"></a>**36.1.28**

<!-- source-p 172 -->
尤利安《学说汇纂》第四十卷。

<!-- source-p 173 -->
<a id="36.1.28.pr."></a>**序言**　但应由取得遗产返还之人选定代理人，以提起诉讼并应对诉讼。

<!-- source-p 174 -->
<a id="36.1.28.1"></a>**1**　继承人被强令接受继承后，命令遗产奴隶接受他人留给该奴隶的继承；随后该继承人又返还其声称有疑虑的遗产。问题是，他是否还应返还遗产奴隶通过接受该继承所取得的遗产？我答称，该继承不应纳入返还范围，正如奴隶接受继承后订立的要式口约、通过交付取得的财物，或从遗产财产中取得的孳息均不纳入一样，前提是没有迟延返还遗嘱信托。但若奴隶在该继承被接受前已经订立要式口约或通过交付取得财物，该财物就应返还；接受继承前取得的孳息也同样应纳入返还。

<!-- source-p 175 -->
<a id="36.1.28.2"></a>**2**　声称遗产有疑虑的人，不得取得其若未被指定为继承人或未接受继承便无法取得的任何遗嘱利益。因此，若其被指定为未适婚人的替补继承人，遗嘱写道：“无论谁成为我的继承人，同一人也应成为我儿子的继承人”，则应强令其返还其依替补继承所取得的遗产。若删去“无论谁成为我的继承人”这一条款，而改写为“提图斯应成为我儿子的继承人”，那么，若提图斯是父亲唯一的继承人，即使如此也应强令其返还未适婚人的遗产；但若提图斯另有共同继承人，则可保留未适婚人的遗产，因为即使他放弃了父亲的遗产，也可以在共同继承人接受父亲遗产后，依替补继承接受儿子的遗产。

<!-- source-p 176 -->
<a id="36.1.28.3"></a>**3**　若父亲指定处于其权力下的儿子为继承人，并嘱托他将遗产返还给塞姆普罗尼乌斯，而儿子声称遗产有疑虑，则可以依特雷贝利安元老院决议返还遗产。因此，即使儿子未介入遗产事务，原本可由其提起或针对其提起的诉讼也会移转给塞姆普罗尼乌斯。

<!-- source-p 177 -->
<a id="36.1.28.4"></a>**4**　某人被父亲指定为继承人，又在被剥夺继承权的儿子之后被指定为替补继承人，并受嘱托返还其通过替补继承取得的遗产。只要未适婚的儿子仍在世，就不得强令该继承人接受父亲的遗产：首先，遗嘱信托附有条件；其次，未适婚儿子在世时，不应就其遗产采取不当行动。但未适婚儿子死亡后，则应强令他接受父亲的遗产。

<!-- source-p 178 -->
<a id="36.1.28.5"></a>**5**　若父亲指定两名继承人，并嘱托两人返还被剥夺继承权的儿子的遗产，只要强令其中一人接受继承即可。如此，未接受父亲遗产的另一人，也会被强令接受儿子的遗产并予返还。

<!-- source-p 179 -->
<a id="36.1.28.6"></a>**6**　被解放的儿子依违背遗嘱之诉取得遗产占有时，没有理由强令继承人返还遗产。继承人既不必给付遗赠或其他遗嘱信托，也不应被强令返还遗产。马尔切鲁斯补充说：若儿子已经取得遗产占有，继承人当然不应被强令接受继承，以免继承人死亡而儿子又放弃遗产占有，致使遗嘱信托落空。

<!-- source-p 180 -->
<a id="36.1.28.7"></a>**7**　依据特雷贝利安元老院决议返还遗产的人，无论向遗产债务人请求给付，还是被他人请求给付，均可凭借遗产已返还的抗辩获得救济或排除请求。遗嘱信托受益人取得的诉权，是继承人在返还遗嘱信托时所拥有的诉权。马尔切鲁斯说，即使某些诉权附有条件、其期限当时尚未届至，也应允许遗嘱信托受益人行使。但在遗产返还前，不应以任何抗辩救济继承人，因为他届时返还的遗产会少于遗嘱信托所要求的范围。

<!-- source-p 181 -->
<a id="36.1.28.8"></a>**8**　只要某人嘱托继承人将其遗产全部或部分返还，就适用特雷贝利安元老院决议。

<!-- source-p 182 -->
<a id="36.1.28.9"></a>**9**　因此，若梅维乌斯指定你为继承人，并嘱托你返还提图斯的遗产（你原本就是由提图斯指定为继承人），而你接受了梅维乌斯的遗产，那么向你请求遗嘱信托的方式，与提图斯遗赠给你一座庄园并嘱托你返还的情形相同。因此，即使你声称梅维乌斯的遗产有疑虑，也不应强令你接受该遗产。

<!-- source-p 183 -->
<a id="36.1.28.10"></a>**10**　若梅维乌斯嘱托你返还其遗产和提图斯的遗产，而你自愿接受继承，则可享有法尔奇狄亚法利益，并保留梅维乌斯遗产的四分之一；你应返还梅维乌斯遗产的一半，以及提图斯遗产的四分之一。无论梅维乌斯嘱托你将两份遗产都返还给同一人，还是分别返还给不同的人，均无区别。但是，若你声称梅维乌斯的遗产有疑虑，就会被强令接受并返还该遗产。受嘱托取得提图斯遗产的人则不能强令你接受继承。

<!-- source-p 184 -->
<a id="36.1.28.11"></a>**11**　继承人依特雷贝利安元老院决议返还遗产后，若仍保有土地孳息或土地本身，或者是立遗嘱人的债务人，必须给予遗嘱信托受益人针对继承人的诉权。马尔切鲁斯说，返还部分遗产后，若返还人与受领人之间提起遗产分割之诉，也必须如此处理。

<!-- source-p 185 -->
<a id="36.1.28.12"></a>**12**　继承人受嘱托将遗产返还给被解放的儿子时，即使儿子可以依违背遗嘱之诉取得遗产占有，也应强令继承人接受继承并返还遗产。

<!-- source-p 186 -->
<a id="36.1.28.13"></a>**13**　若庇护人作为法定份额继承人被指定为继承人，并受嘱托返还遗产，却声称遗产有疑虑，我认为裁判官强令其接受继承并返还遗产更为妥当，尽管他可以改变主意，保留该遗产份额。

<!-- source-p 187 -->
<a id="36.1.28.14"></a>**14**　继承人受嘱托返还遗产，却又获准先取某些财物；若其被强令接受继承，他是否仍可先取？我答称，受裁判官命令接受继承的人，应被剥夺一切利益。

<!-- source-p 188 -->
<a id="36.1.28.15"></a>**15**　但是，若同一人获得遗赠，条件是“若他不成为继承人”，而他声称遗产有疑虑，则只有在受遗赠人向其返还以“若其不成为继承人”为条件所作的遗赠时，才能强令其接受继承。该遗赠不应由共同继承人给付，以免使他们承担负担，而应由取得遗产返还之人给付。既然为履行遗嘱信托可以强令其接受继承，就不应因此使其遭受损失。

<!-- source-p 189 -->
<a id="36.1.28.16"></a>**16**　我的表亲被指定为全部遗产的继承人，并受嘱托立即将遗产的一半返还给普布利乌斯·梅维乌斯，另一半则在她死亡时返还给同一普布利乌斯·梅维乌斯；此外，遗嘱还向其他人作了遗赠。梅维乌斯立即取得了遗产的一半，并提供担保，保证若取得的数额超过法尔奇狄亚法许可范围，就予以返还；其他人也完整取得了遗赠，并同样担保返还其超额取得的部分。我的表亲死亡后，普布利乌斯·梅维乌斯请求将遗产的另一半连同孳息返还给他。因此我询问：我应当返还多少给他？是仅返还表亲所保留的超过遗产四分之一的部分，不再返还其他任何财产？还是我也应从已获遗赠给付的其他人处请求返还，若是，应请求多少？我还询问：若我依据担保从他们处取得的财物，加上表亲所保留的超过四分之一的部分，仍不足遗产的一半，那么我是否应以该超出四分之一部分的增值和孳息补足，但以所返还数额不超过遗产一半为限？还是如普布利乌斯·梅维乌斯所请求，凡扣除遗产四分之一及该四分之一孳息后所取得的财产，都应返还给他？答称：若表亲保留的超过四分之一部分，加上孳息后不少于遗产在死亡时的一半，就应将全部返还给普布利乌斯·梅维乌斯；不得依据担保从已获遗赠给付的人处请求返还任何财物。若该部分及孳息超过遗产一半，则超出部分应归入你的四分之一及其孳息。若表亲所保留的超过四分之一部分之孳息不足遗产一半，则可以依据担保请求给付。总之，计算时应确保你无论如何均保留四分之一及其孳息；此外，若超出四分之一部分的孳息累积到超过遗产一半的数额，你也应保留超出部分。

<!-- source-p 190 -->
<a id="36.1.28.17"></a>**17**　某人受嘱托释放自己的奴隶，并将遗产返还给他们时，应扣除奴隶的价款后返还遗产。

<a id="36.1.29.pr."></a>**序言**　某人被指定为全部遗产的继承人，受嘱托将遗产的一部分无条件返还给我，另一部分则附条件返还给你。他声称遗产有疑虑；在我请求后，他接受了继承，并依据元老院决议将全部遗产返还给我。条件成就后，他是否应将你那一份遗产的孳息返还给你？对此确有疑问，多数人认为不应给付孳息，因为继承人若自愿接受继承，也无需给付这些孳息；只要你的权利得以完整保全即可，没有必要使你的处境优于原先。

<a id="36.1.31.pr."></a>**序言**　若出使者声称遗产有疑虑，即使在出使期间，也应强令其接受审判，因为这不会严重妨碍其公务。即使他说自己正在考虑是否接受继承，也应强令其接受；但不应立即强令其返还遗产。他回家后，若认为接受继承对自己有利，可以享有法尔奇狄亚法或遗嘱上的利益；若认为无利，则应返还全部遗产，以免承担遗产负担。

<!-- source-p 202 -->
<a id="36.1.31.1"></a>**1**　若某人受嘱托返还“他的财产”或“他的一切”，应理解为遗嘱信托返还；因为“我的财产”和“你的财产”的说法也应包括诉权。

<!-- source-p 203 -->
<a id="36.1.31.2"></a>**2**　若家子或奴隶在家父或主人不知情时返还遗产，而其父亲或主人后来予以追认，诉权便依特雷贝利安元老院决议移转。

<!-- source-p 204 -->
<a id="36.1.31.3"></a>**3**　应区分继承人是否依法保留四分之一，还是以具体物或钱款形式保留：前一种情形中，诉权在继承人与遗嘱信托受益人之间分割；后一种情形中，诉权均归受益人。

<!-- source-p 205 -->
<a id="36.1.31.4"></a>**4**　被指定为继承人并受嘱托返还遗产的人，即使获准先取一定数额或财物，即便所先取者少于四分之一，皇帝也不会允许其再请求更多。

<!-- source-p 206 -->
<a id="36.1.31.5"></a>**5**　即使继承人未获准先取任何财物而受嘱托返还遗产，皇帝通常也会准许其保留四分之一；神圣图拉真、哈德良和安敦尼乌斯皇帝均曾作出这样的敕答。
