# D.36.2 论遗赠或遗嘱信托履行期何时届至（*Quando dies legatorum vel fideicommissorum cedat*，第三段）

> **底本范围：**依 d-36.htm source-p 521–581 翻译；保留原有段落、锚点、题名及出处。

<!-- source-p 521 -->
尤利安《学说汇纂》第三十五卷。

<!-- source-p 522 -->
<a id="36.2.16.pr."></a>**序言。**遗嘱写道：“我的继承人应将斯提库斯，或者潘菲拉所生的子女，交付给受遗赠人。”在潘菲拉所生子女出生，或已确定不可能出生之前，该遗赠的履行期不会开始。

<!-- source-p 523 -->
<a id="36.2.16.1"></a>**1.**奴隶被遗赠后，在遗赠人的遗产尚未被接受之前，另一人又将该奴隶的用益权遗赠出去；而用益权遗赠人的遗产先被接受。在该奴隶遗赠所依附的遗产被接受之前，没有理由认为用益权遗赠的履行期已经开始：因为此时遗产尚未取得任何利益，而且若奴隶期间死亡，该遗赠便会消灭。因此，遗产被接受后，应认为用益权归取得该奴隶遗赠的人所有。

<!-- source-p 524 -->
<a id="36.2.16.2"></a>**2.**但若被遗赠用益权的奴隶本人并未被遗赠，则应当说，用益权归入遗产，因为其履行期在遗产被接受前尚未开始。

<!-- source-p 525 -->
<a id="36.2.17"></a>**36.2.17**

<!-- source-p 526 -->
尤利安《学说汇纂》第三十六卷。

<!-- source-p 527 -->
向受遗赠的奴隶另行遗赠某物时，该奴隶所受遗赠的履行期并非在死亡时开始，而是在遗产被接受时开始。因此，纵使奴隶获释，该遗赠仍应给付，并不受法律规则阻碍。即使家父立即死亡，也不会使遗赠利益与法律上的债务都归于同一主体。由此可见，本案如同遗赠给父亲、同时指定儿子为继承人一样；之所以可以成立，是因为即使父亲即刻死亡，获解放出父权的儿子仍可接受遗产，从而使遗赠成为对父亲的债务。

<a id="36.2.19"></a>**36.2.19**

<!-- source-p 532 -->
尤利安《学说汇纂》第七十卷。

<!-- source-p 533 -->
<a id="36.2.19.pr."></a>**序言。**遗嘱未限定期限，如此写道：“我的继承人应将储藏食品交给我的妻子；若未交付，则给她一百。”应视为只设立了一项一百的遗赠，并可立即请求。提及储藏食品，只是为了规定：在争讼程序之前交付储藏食品，继承人即可免除给付义务。

<!-- source-p 534 -->
<a id="36.2.19.1"></a>**1.**若遗嘱如此写道：“如果未在下月初一之前交付储藏食品，则给一百”，这并非两项遗赠，而是将一百作为附条件遗赠。因此，若妻子在下月初一之前死亡，她既不能将储藏食品留给自己的继承人，因为该物并未遗赠给她；也不能将一百留给继承人，因为遗赠履行期必须在受遗赠人生前开始。

<!-- source-p 535 -->
<a id="36.2.19.2"></a>**2.**遗嘱信托若由一名受遗赠人以遗嘱信托方式留给我，而该受遗赠人本身受遗赠附有条件，我的遗嘱信托履行期仍会立即开始；这就如同遗嘱将某物无条件留给我，而指定继承人附有继承条件一样。

<!-- source-p 536 -->
<a id="36.2.19.3"></a>**3.**若债务人将自己附条件所欠的债务遗赠给自己，这是一项现时遗赠，可以立即依据遗嘱提起诉讼，请求免除债务；而且，若债务人在立遗嘱人死亡后死亡，该诉讼请求权会移转给其继承人。

<!-- source-p 537 -->
<a id="36.2.19.4"></a>**4.**若同样的遗赠不是给债务人本人，而是给任何其他人，也应作此处理。

<!-- source-p 538 -->
<a id="36.2.20"></a>**36.2.20**

<!-- source-p 539 -->
马尔基安《法学原理》第六卷。

<!-- source-p 540 -->
若遗赠附有年限，例如“给提提乌斯十枚金币，逐年给付十年”，尤利安在《学说汇纂》第三十卷写道，应视情形而定：如果遗赠是作为生活给养，则属于多项遗赠；受遗赠人死亡后，未来年度的遗赠不移转给其继承人。反之，若立遗嘱人并非为生活给养而遗赠，只是为减轻继承人的负担，将给付分成多期，那么在此情形下，所有年度的给付构成一项遗赠；若受遗赠人在十年期满前死亡，未来年度的遗赠也移转给其继承人。这一见解是正确的。

<!-- source-p 541 -->
<a id="36.2.21"></a>**36.2.21**

<!-- source-p 542 -->
保罗《维泰利乌斯评注》第二卷。

<!-- source-p 543 -->
<a id="36.2.21.pr."></a>**序言。**遗赠未附日期的，应立即给付，或立即归属于受遗赠人。即使附有很远的日期，只要日期确定，例如“第一百个一月初一”，遗赠履行期仍立即开始，但在该日期之前不得请求给付。若日期不确定，例如“等他达到适婚年龄”“等他嫁入某家族”“等他就任公职”，或等他完成任何便于写遗嘱者记载的事情，则除非该日期届至或条件成就，否则遗赠既不发生效力，履行期也不会开始。

<!-- source-p 544 -->
<a id="36.2.21.1"></a>**1.**若遗赠所附条件与受遗赠人被指定为继承人时所附条件相同，庞波尼乌斯认为，该遗赠履行期应视为已经开始，如同无条件遗留一样，因为一旦其成为继承人，债务就确定会发生。继承条件不会使遗赠债务变得不确定；这也与遗赠写作“若他成为继承人，则给付”并无太大区别。

<!-- source-p 545 -->
<a id="36.2.22"></a>**36.2.22**

<!-- source-p 546 -->
庞波尼乌斯《昆图斯·穆基乌斯评注》第五卷。

<!-- source-p 547 -->
<a id="36.2.22.pr."></a>**序言。**若遗赠给提提乌斯并规定“在他年满十四岁时给付”，而他在十四岁之前死亡，那么遗赠确实不会移转给其继承人，因为该遗赠不仅含有日期，也含有条件，即“如果他年满十四岁”；既然他已经死亡，就不能认为他会年满十四岁。无论遗嘱写作“若他年满十四岁”，还是如前一种写法，以日期表达条件，均无区别；两种情况下都是同一条件。

<!-- source-p 548 -->
<a id="36.2.22.1"></a>**1.**有些条件是多余的。例如，遗嘱如此写道：“提提乌斯为继承人；若提提乌斯接受我的遗产，就给梅维乌斯十。”该条件应视为未曾写入；因此，即使梅维乌斯在遗产被接受前死亡，遗赠仍会移转给他的继承人。同样，如果遗嘱写道：“若提提乌斯接受我的遗产，则在一百日内给梅维乌斯十”，这项遗赠也不是附条件，而是附有确定日期；因为应赞同拉贝奥的界定：只有在遗产被接受时即可确定应予给付的遗赠，才会移转给受遗赠人的继承人。

<!-- source-p 549 -->
<a id="36.2.22.2"></a>**2.**但如果我指定两名继承人，并规定其中一人接受继承时，所有继承人须共同向某人遗赠某物，那么这一条件并非多余：就共同继承人的份额而言，条件有效；就遗嘱中点名的那名继承人而言，条件则属多余，情形如同仅指定该人为继承人并以同样方式作出遗赠。

<!-- source-p 550 -->
<a id="36.2.23"></a>**36.2.23**

<!-- source-p 551 -->
乌尔比安《尤利亚—帕皮亚法评注》第四卷。

<!-- source-p 552 -->
遗赠逐年给付时，毫无疑问，应逐年考察受遗赠人是否具备受领资格。若奴隶为数人共有，则应分别考察各共有主人的身份。

<a id="36.2.24"></a>**36.2.24**

<!-- source-p 554 -->
保罗《尤利亚—帕皮亚法评注》第六卷。

<!-- source-p 555 -->
<a id="36.2.24.pr."></a>**序言。**如果遗嘱命令继承人交付储藏食品，或交付一处庄园；若未交付，则给十，我认为，储藏食品的遗赠已转为十的给付：若继承人不愿交付储藏食品，便应给付十。只有继承人受到催告仍不交付庄园时，金钱才到期；若受遗赠人在此期间死亡，其继承人仅能请求庄园。因为遗嘱写道“但应将庄园交给普布利乌斯”，该遗赠即告完成；后文又说“若不交付，则给一百”，应视为在一百开始到期时，附条件撤回庄园遗赠。由于受遗赠人生前该条件并未成就——例如继承人尚未受到催告——撤回便不发生效力，庄园遗赠仍然有效。

<!-- source-p 556 -->
<a id="36.2.24.1"></a>**1.**当然，如果遗嘱如此写道：“若未交付储藏食品，则给十”，我们就会说，储藏食品并未被遗赠。

<!-- source-p 557 -->
<a id="36.2.25"></a>**36.2.25**

<!-- source-p 558 -->
帕皮尼安《疑问集》第十八卷。

<!-- source-p 559 -->
<a id="36.2.25.pr."></a>**序言。**若遗赠列出这个或那个物品，以选择关系并列数项物品，并不会因此成为多项遗赠。即使无条件遗赠其中一处庄园，而另一处附条件遗赠，结论也相同：条件尚未成就时还不能选择；若此时受遗赠人死亡，该遗赠便不移转给其继承人。

<!-- source-p 560 -->
<a id="36.2.25.1"></a>**1.**遗嘱如此写道：“我的继承人应将塞伊乌斯欠我的款项给提提乌斯。”若塞伊乌斯是未成年受监护人，未经监护人认可而收取钱款，且其财产并未因此增加；同时，债权人所说的是现时债务，那么由于塞伊乌斯并不负债，该遗赠无效。但如果遗嘱人用“债务”一词指自然债务及将来清偿，则提提乌斯暂时不能请求给付，仿佛默示附加了一个条件。这就如同遗嘱如此写道：“给提提乌斯未成年受监护人将来清偿的款项”，或者遗赠“潘菲拉所生的子女”或“那处庄园将收获的果实”一样。下述情形并不与此相矛盾：受遗赠人在期间死亡，随后子女出生、果实收获或未成年受监护人清偿款项，受遗赠人的继承人便可以请求；因为未明示附加条件的遗赠，其履行期即使须等待外部事项，也已开始。

<a id="36.2.26"></a>**36.2.26**

<!-- source-p 562 -->
帕皮尼安《答复集》第九卷。

<!-- source-p 563 -->
<a id="36.2.26.pr."></a>**序言。**遗嘱写道：“我希望从我的庄园收益中，在来年稍后给我的兄弟菲尔米乌斯·赫利奥多鲁斯五十。”我答复说，这不是附加了条件，而是推迟了款项的给付时间。若未取得指定款项所生的收益，则须以第二年的收益补足。

<!-- source-p 564 -->
<a id="36.2.26.1"></a>**1.**立遗嘱人命令继承人给其受抚养人一百，并将这笔钱交给另一人保管，直至男孩二十五岁；受抚养人在此期间取得该笔款项的三分之一利息，达到该年龄后取得本金。男孩在二十五岁前死亡。我答复说，遗嘱信托已移转给男孩的继承人，因为立遗嘱人只是为本金设定了确定的给付年龄，并未在无条件遗嘱信托中附加条件。由于立遗嘱人不希望男孩向实际保管钱款的人请求遗嘱信托，鉴于遗嘱写道“你应在上述年龄之后将钱返还给我的受抚养人”，遗嘱信托应向继承人请求；继承人本应约定收回该笔款项。但不应向保管人请求提供保证，因为死者更愿意信赖此人的信用。

<!-- source-p 565 -->
<a id="36.2.26.2"></a>**2.**父亲遗赠给妻子一项财产，并命妻子将该财产的年度收益交给儿子，计入儿子的财产，直至其二十五岁；此外还命妻子向儿子提供生活供养。可以看出，这不是多项遗嘱信托，而是一项按确定期次分割的遗嘱信托。因此，若儿子在上述年龄之前死亡，剩余期间的遗嘱信托会移转给其继承人；但款项不得在每年年初请求，因为父亲希望从给妻子的孳息中供养儿子。反之，若父亲将固定年款指定为儿子的生活给养，则随着受益人死亡，给付原因显然也已消灭。

<a id="36.2.27.pr."></a>**序言。**某人无条件指定一名家子为部分遗产的继承人，并向其设立遗嘱信托；他又在同一遗嘱中规定：“我指定卢基乌斯·提提乌斯为继承人，并希望他只有在脱离父权后才能接受遗产。”有人询问，共同继承人接受遗产后，给家子的遗赠履行期是否已经开始。答复说，如果该遗赠是无条件作出的，家子可以向共同继承人请求其应得份额内的遗嘱信托。
