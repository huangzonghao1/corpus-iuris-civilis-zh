如果遗赠写作“在继承人死亡时给付”，这就是附条件遗赠；因此，继承人尚在世而受遗赠人死亡的，遗赠不移转给受遗赠人的继承人。反之，若遗赠给某人并写作“在受遗赠人本人死亡时给付”，那么遗赠确定会移转给其继承人。

<!-- source-p 461 -->
<a id="36.2.5"></a>**36.2.5**

<!-- source-p 462 -->
乌尔比安《萨宾评注》第二十卷。

<!-- source-p 463 -->
<a id="36.2.5.pr."></a>**序言。**遗赠履行期开始后，受遗赠人才死亡的，该遗赠移转给其继承人。

<!-- source-p 464 -->
<a id="36.2.5.1"></a>**1.**因此，无条件遗赠自死亡之日起开始届期；若遗赠规定在某一日期之后给付，其届期方式也与无条件遗赠相同，但有些遗赠不会移转给继承人的情形除外。此类遗赠的履行期不会提前届至，例如遗赠规定一年后才开始的用益权；我们赞同这一见解。

<!-- source-p 465 -->
<a id="36.2.5.2"></a>**2.**若遗赠附有条件，在条件成就之前，遗赠的履行期不会开始；即使该条件取决于受遗赠人本人，也不例外。

<!-- source-p 466 -->
<a id="36.2.5.3"></a>**3.**但若裁判官免除该条件，遗赠的履行期即刻开始。

<!-- source-p 467 -->
<a id="36.2.5.4"></a>**4.**不可能成就的条件也同样处理，因为该遗赠被视为无条件遗赠。

<!-- source-p 468 -->
<a id="36.2.5.5"></a>**5.**如果条件未能成就并非受遗赠人所致，而是继承人或遗嘱命令其履行条件之人所致，遗赠的履行期也会开始，因为该条件被视为已经成就。例如，我被命令向继承人给付十，而继承人拒绝收取。又如，遗赠以我娶塞伊娅为条件，而她不愿结婚；也应认定遗赠履行期已经开始，因为我本人并未阻碍条件履行，条件未能成就是他人造成的。

<!-- source-p 469 -->
<a id="36.2.5.6"></a>**6.**遗赠应在与受遗赠人原本获给付相同的日期，也就是相同的分期，向继承人给付。

<!-- source-p 470 -->
<a id="36.2.5.7"></a>**7.**遗赠履行期开始时，若某人仍处于他人权力之下，遗赠便应归属于当时对其享有权力的人。因此，若遗赠为无条件遗赠，而受遗赠人在履行期开始后才成为自权人，该遗赠仍归其主人。但若遗赠的是用益权，受遗赠人在立遗嘱人死亡后、继承被接受前成为自权人，则用益权归其本人取得。

<!-- source-p 471 -->
<a id="36.2.6"></a>**36.2.6**

<!-- source-p 472 -->
保罗《萨宾评注》第三卷。

<!-- source-p 473 -->
<a id="36.2.6.pr."></a>**序言。**无条件给付的遗赠若以条件方式撤回，应视为附条件遗赠。

<!-- source-p 474 -->
<a id="36.2.6.1"></a>**1.**如果遗赠的履行因遗嘱之外的事由而暂缓，即使受遗赠人在此之前死亡，我们也认为遗赠已经移转给其继承人。例如，丈夫将嫁资物遗赠给外人，又将相当于嫁资物价值的钱款遗赠给妻子；妻子尚在考虑是否选择嫁资物时，受遗赠人死亡，随后妻子作出选择。人们认为，遗赠会移转给受遗赠人的继承人。尤利安也作了同样的答复：遗嘱所附的更像是迟延，而非条件。

<!-- source-p 475 -->
<a id="36.2.6.2"></a>**2.**遗嘱附录中所作遗赠，其履行期开始的时间与遗嘱中所作的遗赠相同。

<!-- source-p 476 -->
<a id="36.2.7"></a>**36.2.7**

<!-- source-p 477 -->
乌尔比安《萨宾评注》第二十卷。

<!-- source-p 478 -->
<a id="36.2.7.pr."></a>**序言。**继承人接受继承会推迟请求遗赠的时间，却不会推迟遗赠履行期的开始。

<!-- source-p 479 -->
<a id="36.2.7.1"></a>**1.**因此，无论遗嘱指定的继承人无条件继承却迟延接受，还是其附有条件而受条件阻碍，均不损害受遗赠人的利益。

<!-- source-p 480 -->
<a id="36.2.7.2"></a>**2.**即使指定继承人尚未出生，或身处敌国，也同样不损害受遗赠人，因为遗赠履行期已经开始。

<!-- source-p 481 -->
<a id="36.2.7.3"></a>**3.**由替补继承人作出的遗赠也适用同一规则：指定继承人仍在考虑是否接受继承期间，受遗赠人死亡并不使其受损；如果指定继承人后来拒绝继承，遗赠请求权便已经移转给受遗赠人的继承人。
