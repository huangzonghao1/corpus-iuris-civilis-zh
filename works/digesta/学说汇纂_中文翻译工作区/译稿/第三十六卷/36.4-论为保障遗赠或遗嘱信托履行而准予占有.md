# D.36.4　论为保障遗赠或遗嘱信托履行而准予占有（*Ut in possessionem legatorum vel fideicommissorum servandorum causa esse liceat*）

> **底本范围：**依 d-36.htm source-p 667–758 翻译；共92个源段落，逐段保留编号、署名与锚点。

<!-- source-p 667 -->
<a id="4"></a><a id="36.4"></a>**36.4.0　论为保障遗赠或遗嘱信托履行而准予占有**（*Ut in possessionem legatorum vel fideicommissorum servandorum causa esse liceat*）。

<!-- source-p 668 -->
<a id="36.4.1"></a>**36.4.1**

<!-- source-p 669 -->
乌尔比安《告示评注》第五十二卷。

<!-- source-p 670 -->
<a id="36.4.1.pr."></a>**序言**　若某人虽被禁止接受担保，却仍接受了担保，这项担保能否请求返还，使继承人得以请求免除其债务？若继承人明知该担保没有债务依据而仍提供担保，便不能请求返还。那么，若继承人不知道自己已获免除提供担保的义务，又如何？他可以提起返还之诉。若他误以为担保义务不可免除，因不知法律而提供担保的人是否也可提起返还之诉？仍可宽厚地认为，可以请求返还担保。再者，若基于担保的要式口约已经开始发生效力，保证人能否援用抗辩？较妥当的意见是，他们可以援用抗辩，因为担保的原因本不应成立。

<!-- source-p 671 -->
<a id="36.4.1.1"></a>**1.**裁判官不要求继承人必须阻止提供担保；只要受遗赠人或遗嘱信托受益人没有阻止担保提供即可。因此，若没有人可以就担保向其提出催告，也就是说，遗赠或遗嘱信托所针对的一方无人可被催告提供担保，则无论如何，受遗赠人或遗嘱信托受益人均可依据本告示获准占有；因为确实是本应获得担保的人未能使担保得以提供。不过，向受遗赠人提出担保要约并非必要；只要其曾提出请求而未获担保，或者根本无人可供其请求担保，就已足够。

<!-- source-p 672 -->
<a id="36.4.1.2"></a>**2.**若遗嘱遗赠给债务人的是债务免除，则不要求提供担保，因为遗赠利益已在其手中；若他被起诉，可以对已经受领遗赠之人援用恶意抗辩。

<!-- source-p 673 -->
<a id="36.4.1.3"></a>**3.**既然确定遗赠并非应付之债，神圣的庇乌斯皇帝在致埃米利乌斯·埃奎斯特鲁斯的敕答中规定，裁判官不得准许请求提供担保。

<!-- source-p 674 -->
<a id="36.4.1.4"></a>**4.**在接受继承之前，只有在是否接受继承尚不确定时，才应就遗赠提供担保。反之，若已确定继承被拒绝或放弃，或必然继承人已拒绝承受，则援引本告示毫无意义，因为遗赠或遗嘱信托确定不负给付义务。

<!-- source-p 675 -->
<a id="36.4.2"></a>**36.4.2**

<!-- source-p 676 -->
乌尔比安《告示评注》第七十九卷。

<!-- source-p 677 -->
若已确定继承尚未被接受，则既不适用担保，也不适用准予占有。

<!-- source-p 678 -->
<a id="36.4.3"></a>**36.4.3**

<!-- source-p 679 -->
乌尔比安《告示评注》第五十二卷。

<!-- source-p 680 -->
<a id="36.4.3.pr."></a>**序言**　若被请求提供担保之人提出通过审理查明事实，并说：“今天就查明遗嘱信托，今天就审理”，应认定担保义务不再适用，因为可以先查明遗嘱信托是否成立，再决定是否提供担保。〔底本原话为：“*hodie constet de fideicommisso, hodie agamus*”。〕

<!-- source-p 681 -->
<a id="36.4.3.1"></a>**1.**若有人声称担保请求系出于诬告，继承人也应请求对此进行审理；这是所有担保请求的共同规则。神圣的庇乌斯皇帝曾以敕答规定，被请求提供担保之人应查明请求是否出于诬告；对此应作概要审理。

<!-- source-p 682 -->
<a id="36.4.3.2"></a>**2.**若代理人请求就遗赠提供担保，且确有委任，则无须其担保本人会追认代理行为，但应向其提供担保；若委任是否存在尚有疑问，则应要求其提供追认担保。

<!-- source-p 683 -->
<a id="36.4.3.3"></a>**3.**若已提供过一次担保，后来有人声称保证人资力不足，是否还应重新提供担保？较妥当的意见是，无须再次担保。神圣的庇乌斯皇帝曾在致帕库维娅·利基尼娅的敕答中如此规定：她接受了资力较差的保证人，应自行承担这一选择的后果；不应使被请求提供担保之人不断承受负担。

<!-- source-p 684 -->
<a id="36.4.4"></a>**36.4.4**

<!-- source-p 685 -->
帕比尼安《疑问集》第二十八卷。

<!-- source-p 686 -->
当然，若提出新的事由，例如保证人死亡，或因突如其来的意外丧失全部家产，则公平的做法是要求重新提供担保。

<!-- source-p 687 -->
<a id="36.4.5"></a>**36.4.5**

<!-- source-p 688 -->
乌尔比安《告示评注》第五十二卷。

<!-- source-p 689 -->
<a id="36.4.5.pr."></a>**序言**　未获遗赠或遗嘱信托担保的人被准予占有，并不会因此成为所有人。他所取得的与其说是财物的占有，不如说是保管；因为他无权驱逐继承人，而是应与继承人共同占有，以持续保管带来的不便迫使继承人提供担保。

<!-- source-p 690 -->
<a id="36.4.5.1"></a>**1.**若一人因担心损害而获准占有，另一人则为保障遗赠而获准占有，为保障遗赠而获准占有者也可以就可能发生的损害提供担保。若他已提供该项担保，则除非另有人就他承担的损害责任向他提供担保，否则不得令其退出占有。

<!-- source-p 691 -->
<a id="36.4.5.2"></a>**2.**若数名受遗赠人请求获准占有，他们都应获准占有；因为基于遗赠原因占有的人是为自己占有，而非为他人占有。债权人为保全标的而获准占有则不同：占有人不是为自己，而是为所有债权人占有。

<!-- source-p 692 -->
<a id="36.4.5.3"></a>**3.**较早获准占有的受遗赠人，不优先于后来获准占有的人；我们不在受遗赠人之间确立顺位，而是同时平等保护他们。

<!-- source-p 693 -->
<a id="36.4.5.4"></a>**4.**为保全标的而获准占有的债权人开始占有后，为保障遗赠而获准占有者不得优先于债权人。

<!-- source-p 694 -->
<a id="36.4.5.5"></a>**5.**为保障遗赠而获准占有者，无论如何都可以占有属于遗产的财物，也就是仍处于遗产法律关系中的财物。至于不再处于遗产法律关系中的财物，只有在其因恶意而脱离该关系时，才可准予占有；而且并非一概准予，应在查明情况后决定。

<!-- source-p 695 -->
<a id="36.4.5.6"></a>**6.**“财产”一词似乎包括所有权归继承人的财物。

<!-- source-p 696 -->
<a id="36.4.5.7"></a>**7.**若有应缴租税的土地，或遗嘱人曾接受质押的财物，也准予占有这些财物。

<!-- source-p 697 -->
<a id="36.4.5.8"></a>**8.**受遗赠人及遗嘱信托受益人也同样可以占有女奴所生子女、牲畜胎产以及孳息。

<!-- source-p 698 -->
<a id="36.4.5.9"></a>**9.**即使死者善意购买了他人所有的财物，也已确认应准许受遗赠人占有该物，因为它仍属于遗产法律关系中的财物。

<!-- source-p 699 -->
<a id="36.4.5.10"></a>**10.**若死者受寄存或借用他人财物，则不得准予占有，因为这些不是遗产财物。

<!-- source-p 700 -->
<a id="36.4.5.11"></a>**11.**若两名继承人中一人准备提供担保，另一人不准备提供，则当然只应就后一人的份额准予占有。因此，获准占有的受遗赠人也会妨碍已提供担保的继承人管理财物。故应劝继承人就全部遗产提供担保，以免其管理受到妨碍。

<!-- source-p 701 -->
<a id="36.4.5.12"></a>**12.**若未适婚人的替补继承人作出遗赠，而未适婚人死亡，则准予占有的范围不仅包括遗嘱人的财产，也包括未适婚人取得的财产，因为这些财物也属于遗产；但未适婚人仍在世时，既不准予占有，也不要求提供担保。

<!-- source-p 702 -->
<a id="36.4.5.13"></a>**13.**若被请求履行遗嘱信托者并非继承人，而是以其他身份继受财产的人，应认定告示仍然适用，并应审查其是否有欺诈行为。

<!-- source-p 703 -->
<a id="36.4.5.14"></a>**14.**若实施欺诈的是继承人的继承人，亦应同样使其承担不利后果。

<!-- source-p 704 -->
<a id="36.4.5.15"></a>**15.**这里的欺诈应包括重大过失；但并非所有欺诈，而仅指意图损害受遗赠人或遗嘱信托受益人的行为。

<!-- source-p 705 -->
<a id="36.4.5.16"></a>**16.**皇帝安敦尼·奥古斯都以敕答规定，在特定情形下，若有管辖权者已受理案件并在法庭审理六个月后，继承人仍未履行给付，受遗赠人及遗嘱信托受益人也可获准占有继承人自己的财产，并取得该财产的孳息，直至死者的意思得到满足。该救济也适用于以任何理由拖延履行遗嘱信托的人。

<!-- source-p 706 -->
<a id="36.4.5.17"></a>**17.**“满足”一词虽含义较广，在此仍指清偿遗赠。

<!-- source-p 707 -->
<a id="36.4.5.18"></a>**18.**因此，即使担保义务已被免除，该敕答仍然适用，因为给付仍发生迟延。

<!-- source-p 708 -->
<a id="36.4.5.19"></a>**19.**我认为，六个月应按连续期间计算，而不是按占有期间计算。

<!-- source-p 709 -->
<a id="36.4.5.20"></a>**20.**若未适婚人没有监护人，或精神错乱者、未成年人没有保佐人，不应认定给付迟延；不能让此类无从为自己辩护的人因受挫延误而受损。当然，若遗产曾在一段期间内无人承受，则这段期间应从计算中扣除。

<!-- source-p 710 -->
<a id="36.4.5.21"></a>**21.**可能有人会问，这些孳息是否抵充遗嘱信托项下应付的利息。既然我们依照质押的规则处理，从孳息中取得的金额应先抵充利息；若尚有余额，再抵充本金。甚至，若受遗赠人取得的孳息超过其应得金额，也应依质押之诉的规则，给予适法诉权请求返还超额部分。不过，质物可以出售；本案中，皇帝敕令只允许受遗赠人取得孳息，目的是促使案件尽快作出裁判。

<!-- source-p 711 -->
<a id="36.4.5.22"></a>**22.**为保障遗赠而获准占有者，也应保管孳息及其他财物。他应允许继承人耕作土地并收取孳息，但须由受遗赠人保管孳息，以免继承人将其耗用。若继承人不愿收获孳息，则应允许受遗赠人收获并保管。若孳息适宜尽早出售，也应允许受遗赠人出售并保管价款。对于其他遗产财物，获准占有者也应将全部遗产财物收集起来，存放在死者住所；若无房屋，则应租赁住处或仓库，以保管收集的财物。我认为，受遗赠人应妥善保管遗产财物，既不得将其从继承人处夺走，也不得使其灭失或价值降低。

<!-- source-p 712 -->
<a id="36.4.5.23"></a>**23.**若某人依据皇帝敕令获准占有，应注意不得对使用或收取孳息的受遗赠人施加暴力。

<!-- source-p 713 -->
<a id="36.4.5.24"></a>**24.**“满足死者意思”应理解为：通过孳息或其他方式履行死者的意思。

<!-- source-p 714 -->
<a id="36.4.5.25"></a>**25.**神圣的安敦尼皇帝敕令适用于遗嘱信托可依法有效地留给之人，即使他们不是继承人；因为他们的利益相同。

<!-- source-p 715 -->
<a id="36.4.5.26"></a>**26.**为保障遗赠而获准占有者，若已就该事由提起诉讼并完成诉讼系属程序，在其就诉讼提供担保之前，不得退出占有。

<!-- source-p 716 -->
<a id="36.4.5.27"></a>**27.**获准占有者若遭拒绝进入，应可援用所规定的令状；应由执达员、长官的属员或行政长官引导其进入占有。

<!-- source-p 717 -->
<a id="36.4.5.28"></a>**28.**准予占有不仅适用于受托交付遗赠标的物本身的情形，也适用于受托返还该物的一部分或替代物的情形。

<!-- source-p 718 -->
<a id="36.4.5.29"></a>**29.**若遗赠无条件给提图斯，同时以遗嘱信托请求他在条件成就后返还给森普罗尼乌斯，尤利安写道：若受遗赠人在取得遗赠前未就附条件遗嘱信托提供担保，裁判官作如下规定并非不公平：允许森普罗尼乌斯行使遗赠请求权，并要求其向受遗赠人提供担保；若条件未成就，森普罗尼乌斯应返还十。尤利安还说，若提图斯已从继承人处收取十，公平的做法是强制提图斯提供相应担保，或者交付这十；同时要求森普罗尼乌斯向提图斯提供担保。我们也遵循此规则，马尔凯鲁斯亦持相同意见。

<!-- source-p 719 -->
<a id="36.4.5.30"></a>**30.**那么，若遗赠与遗嘱信托均附有条件，而受遗嘱信托受益人未提供担保，应如何处理？最公平的做法是：若受遗赠人不向受遗嘱信托受益人提供担保，则后者可请求继承人就遗赠提供担保；当然，受遗嘱信托受益人自己也应向受遗赠人提供担保。若受遗赠人已经从继承人处取得担保，则应裁定由受遗嘱信托受益人优先取得基于该担保的诉权，但仅限于其遗嘱信托条件成就的情形。若遗赠尚未清偿且其条件已经成就，受遗嘱信托受益人也应取得遗赠请求权，但须准备向受遗赠人提供担保。

<a id="36.4.6.pr."></a>**序言**　若遗嘱遗赠了现金的用益权，并规定该项遗赠无须提供担保，则遗赠的不是所有权；应允许受遗赠人提供担保后享有该现金的用益权。此种情形中，裁判官几乎没有介入余地，因为受遗赠人若不提供担保，就无法起诉继承人。

<!-- source-p 723 -->
<a id="36.4.6.1"></a>**1.**为保障遗嘱信托而获准占有者，在遗嘱信托履行或就此提供担保之前，不得退出占有。若在原物未受争议时本不应准予占有，那么一旦继承人提出履行该项遗嘱信托，受益人就应退出占有。

<a id="36.4.11.pr."></a>**序言**　若某人为保障遗嘱信托而获准占有，而该物正是以遗嘱信托留给我的物品，则公平的做法是由该物的受益人、也就是我来取得该物，而非由你取得——你是基于另一项遗嘱信托进入占有的。又如遗赠附有条件留给我，而你在条件成就前为保障遗赠而获准占有；其后条件成就，不得拒绝我完整行使该物的请求权。若某人因同一事由开始占有附条件自由奴隶，条件成就后，也不能阻碍该奴隶依法取得自由。

<!-- source-p 740 -->
<a id="36.4.11.1"></a>**1.**若继承人的个人债权人为了保全财物而获准占有，并取得了以遗嘱信托留给我的财物，已确认其行为不得损害我；这与该债权人直接从继承人处取得该物的质押并无不同。

可以向市镇共同体设立遗嘱信托，这一点毫无疑问。但若市镇共同体未提供担保，我们认为可依据本告示对抗该共同体而获准占有；反之，若市镇共同体未获担保，该共同体本身并不能获得同样救济。此时应采取非常救济，即由裁判官作出裁定，准许市镇共同体的代理人进入占有。

<!-- source-p 744 -->
<a id="36.4.13"></a>**36.4.13**

<!-- source-p 745 -->
卡利斯特拉图斯《告示解释集》第三卷。

<!-- source-p 746 -->
即使遗赠或遗嘱信托的标的价值很小，只要继承人未予给付，或在依法应提供担保时未提供担保，裁判官仍应为保障遗赠而准许受遗赠人或遗嘱信托受益人占有遗产中的全部财产。

<!-- source-p 747 -->
<a id="36.4.14"></a>**36.4.14**

<!-- source-p 748 -->
拉贝奥《后期著作》第二卷，雅沃莱努斯摘要。

<!-- source-p 749 -->
若某项财物属于遗产，且为保障遗赠而留存，则在计算生活供养时应予扣减；但受供养人若是未婚的女儿、孙女、曾孙女或妻子，且没有自己的任何财产，则不在此限。〔本段“*in causa vescendi deminuet*”句义不明，暂依字面译出。〕

<!-- source-p 750 -->
<a id="36.4.15"></a>**36.4.15**

<!-- source-p 751 -->
瓦伦斯《诉讼》第七卷。

<!-- source-p 752 -->
有时，即使继承人恶意使某物脱离遗产关系，也不得准许受遗赠人占有该物；例如，继承人将该场所变为宗教场所，或经皇帝许可将某物奉献给公共用途，或并非为损害债权人而释放某奴隶。

<!-- source-p 753 -->
<a id="36.4.16"></a>**36.4.16**

<!-- source-p 754 -->
……〔底本节略〕

<!-- source-p 755 -->
……若提图斯附条件将一名奴隶遗赠给麦维乌斯，而森普罗尼乌斯也附条件将该奴隶遗赠给同一人，在两个条件尚待成就期间，提图斯的继承人与麦维乌斯均有权请求森普罗尼乌斯的继承人提供担保。〔本段为节略残文，关系人及请求根据语法暂译。〕

<!-- source-p 756 -->
<a id="36.4.17"></a>**36.4.17**

<!-- source-p 757 -->
……〔底本节略〕

<!-- source-p 758 -->
……若父亲指定处于自己权力之下的儿子为继承人，并向该儿子作出遗赠，则不得强迫父亲为其儿子提供担保；但若父亲管理不善，应为留给儿子的财物指定保佐人，使该财物的收益同时用于父亲与儿子；若遗赠的是一笔金额，则应请求皇帝裁决。〔本段为节略残文；*ut reditus earum utrique praestet* 中“二者”所指仍需结合前文核实。〕
