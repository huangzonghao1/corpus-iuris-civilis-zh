遗产基于遗嘱信托而返还时，如果此前已经与继承人订立仲裁协议，我认为遗嘱信托受益人应向继承人提供担保；继承人在返还前处理了许多事务时，也是如此。所谓继承人应当保留财产，并非始终适用。试想，如果没有任何东西可供保留呢？例如，遗产全是债权，或是继承人并未占有的有体物。诚然，受领返还的人会追索一切；然而继承人仍受其已被提起的诉讼约束，也仍受其不得不作出的要式口约约束。因此，只有在遗嘱信托受益人为其提供担保后，继承人才会被迫返还遗产。

<a id="36.1.38.pr."></a>**序言。**遗产在下列情形下视为已经返还：继承人实际容许遗产中的全部或部分财物由他人占有，且其意图是让对方接收并承受这些财物；如果继承人仅因其他原因误以为你在占有，则不在此限。继承人后来追认的，也应作同样处理。即使他只是口头表示返还，或者通过信件、使者表示返还，也应认可。继承人依你的意思向他人返还时，诉权即移转给你。同样，如果他人奉我之命返还，或我追认了返还行为，也应视为诉权已经移转。

<!-- source-p 230 -->
<a id="36.1.38.1"></a>**1.**未适婚年龄者本人应在监护人同意下返还遗产；除非他是婴儿，监护人不得绕过未适婚年龄者而自行返还，因为监护人也不能替自己的被监护人委任诉讼代理人。神君塞维鲁曾就受尊敬的未适婚年龄者阿里乌斯作出裁定：该未适婚年龄者虽已在叔父兼监护人阿里乌斯·安东尼努斯同意下返还遗产，但仍不能认为其本人已经有效返还。

<a id="36.1.41.1"></a>**1.**特雷贝利安元老院决议所称的继承人，也包括遗嘱指定的继承人。不过，我们现今采用如下规则：继承人的继受人也可以依特雷贝利安元老院决议适当地返还遗产，例如继承人、遗产占有人，或因继承而取得利益的家父、家主。因为他们都应依该元老院决议返还自己所享有的权利。至于受命返还者是遗嘱指定的继承人，还是其家父或家主，并无区别。

**马尔凯卢斯：《学说汇纂》第十五卷。**

<!-- source-p 258 -->
<a id="36.1.46.pr."></a>**序言。**斯提库斯提出请求后——他在同一份遗嘱中既获释，又取得遗产遗嘱信托——继承人声称遗产状况可疑，仍然接受了遗产。不久，斯提库斯在请求接收遗产尚未迟延之前去世，留下提提乌斯为继承人。我询问：如果提提乌斯不愿接收遗产遗嘱信托，他是否享有元老院决议所赋予的诉权？我答复说：通常，被迫接受遗产的人会立即向获释奴隶返还遗产；元老院决议所规定的只是关于获释奴的情形，并未提及其继承人。不过，也可能发生继承人延迟返还的情况，例如死者曾欠继承人金钱，而继承人宁愿保留该款，也不愿请求清偿。除此之外，我认为，对获释奴的继承人应作与获释奴本人相同的处理：他为何要拒绝其被继承人无从拒绝之事？如果获释奴在遗产返还前去世且未留下继承人，就应准许遗产债权人出售其财产，犹如他在遗产返还后去世一样。

<!-- source-p 259 -->
<a id="36.1.46.1"></a>**1.**不过，对于这类问题，我请求你答复我先前的看法是否正确。一名女儿被指定为全部遗产的继承人，并受命在扣除少量遗赠和不多的债务后返还遗产的一半，因此法尔基第法并不适用；返还遗嘱信托并未发生迟延。我希望她以口头方式向我返还遗产，这样我便能依特雷贝利安元老院决议提起诉讼，并依由此取得的诉权，追索自遗嘱人死亡之日起至返还时应计的利息。我还询问租金问题，因为租赁关系所生的义务属于遗产的一部分。我并未向继承人请求任何孳息，但她希望我向她返还财物，或者将利息和租金请求权让与她。我无法说服她：既然她受命向我返还遗产，“遗产”一词也包括这项利息约定。我答复说：这些均包含在“遗产”之中。就此而言，这些项目与其他附条件约定的项目，或按年、按月给付的项目，并无区别。当然，它们是遗产中物品所生孳息的替代；如果不存在迟延，孳息并不归遗嘱信托受益人。可是，受益人并非请求继承人以继承人身份补足遗嘱信托；如我所说，他请求的是按现状返还遗产，继承人绝不应拒绝。元老院在某种意义上也希望遗嘱信托受益人加入遗产，并在遗产返还给他的份额范围内处于继承人的地位。但是，如果继承人将遗产金钱出借获利，或者收取地产孳息，在没有迟延的情况下，他无须就此向遗嘱信托受益人给付；这是因为他以自己的风险出借金钱，或投入劳力耕种土地、收取孳息；不应不公平地把他变成他人的代理人。并且，遗产以本案所问的这些方式增值时，继承人并未为此付出费用或劳力。

<!-- source-p 281 -->
继承人受命在扣除遗赠后，以遗嘱信托方式返还遗产时，不应扣除那些本不可请求给付的遗赠。但是，如果遗嘱先将嫁资作为优先遗赠留给被指定为部分继承人的妻子，随后又命她在扣除遗赠后返还遗产，即使她依据法尔基第法保留的四分之一与嫁资数额相同，她仍应按比例扣除优先遗赠的嫁资部分。因为她兼有这两种身份——受领优先遗赠者和继承人——她与任何其他被指定为继承人、同时又是债权人的人并无区别；后者也受命返还遗产。即使她是在未扣除遗赠的情况下被命设立遗嘱信托，结论也相同。

<a id="36.1.54"></a>**36.1.54**

<!-- source-p 283 -->
**帕比尼安：《疑义集》第十九卷。**

<!-- source-p 284 -->
<a id="36.1.54.pr."></a>**序言。**如果提提乌斯受遗赠的是他人之物，并请求已被指定为该物所有人的继承人向梅维乌斯返还遗产，那么梅维乌斯请求该项遗赠将无法律效力；因为他不能取得本来就不可能归于遗嘱指定继承人——即该物所有人——之物。

<!-- source-p 285 -->
<a id="36.1.54.1"></a>**1.**某奴隶从一名共同继承人处获释，又从另一名共同继承人处取得遗产遗嘱信托。如果两名继承人都不愿接受遗产，裁判官无从介入；因为不得仅为履行解放自由人的义务而强迫一人接受遗产，也不得为了尚未成为自由人的奴隶而强迫未授予其自由的另一人接受遗产。只有在所有人均授予直接解放或遗嘱信托解放，且遗产也由同一人留给受托者时，才适用该元老院决议。不过，如果授予自由的继承人放弃其份额，或因条件未成就而被排除，而其份额因此归于另一人，那么可以主张应强迫后一人接受遗产：毕竟，债务人何时、基于何种法律关系而同时成为解放奴隶义务与遗产义务的承担人，并无区别。

<!-- source-p 286 -->
<a id="36.1.55"></a>**36.1.55**

<!-- source-p 287 -->
**帕比尼安：《疑义集》第二十卷。**

<!-- source-p 288 -->
如果奴隶是由受遗赠人授予自由、由继承人留给遗产遗嘱信托，那么继承人不得被强迫接受其认为有风险的遗产，因为该人的身份取决于遗赠；任何人都不应仅因遗赠而被迫承担继承诉讼的责任。试想，在迟延期间，如果受遗赠人尚未解放奴隶，而奴隶已经去世呢？不过，如果受遗赠人在遗嘱人仍在世时先于遗嘱人死亡，出于宽厚，应答复说继承人必须接受遗产，因为他可以自行决定在解放奴隶后向其返还遗产。

**帕比尼安：《疑义集》第十九卷。**

<!-- source-p 291 -->
提提乌斯受命将遗产中剩余之物返还给梅维乌斯。其间被处分或减少的财产，原则上不得再请求；但若能证明处分或减少财产是为了阻挠、侵害遗嘱信托，则不在此限，因为遗嘱信托的措辞显然包含善意要求。神君马尔库斯审理遗产遗嘱信托时，遗嘱写道：“我请求你将我的遗产中剩余的一切返还。”他认为其中也包含善良之人的裁量；因此，他裁定，所谓遗产支出不应仅从遗嘱信托财产中扣除，而应按照继承人自有财产的比例分摊。我认为，他如此裁定，不仅出于公平考虑，也有先例可循。曾有人询问，被解放之子是否应向兄弟们归入财产；当时认为应将军人在军营中取得的特有财产作为优先财产留给该军人。皇帝受咨询后裁定：军人所作的支出，不仅应从须负归入义务的财产中扣除，也应按比例从军营财产中扣除。基于这类考虑，梅维乌斯应就遗嘱信托要求担保。其目的并非依要式口约请求遗嘱信托本身不能请求之物，而是使他能取得保证人，担保其依遗嘱信托本可请求的数额。

<a id="36.1.57"></a>**36.1.57**

<!-- source-p 293 -->
**帕比尼安：《疑义集》第二十卷。**

<!-- source-p 294 -->
<a id="36.1.57.pr."></a>**序言。**如果庇护人的儿子依据特雷贝利安元老院决议向外人返还遗产，无法移转的劳务诉权仍留在继承人手中；对继承人而言，抗辩也不构成妨碍，因为同一抗辩不能使遗嘱信托受益人获益。总而言之，应答复说，继承人既不因不属于返还事项的原因被排除，也不因此获释。

<!-- source-p 295 -->
<a id="36.1.57.1"></a>**1.**提图斯·安东尼努斯皇帝以敕答指出，如果自由是直接附期限授予的，而当时不存在可以向其返还遗产的人，就不应提前返还遗产。

<!-- source-p 296 -->
<a id="36.1.57.2"></a>**2.**某人因遗产状况可疑而依特雷贝利安元老院决议接收了全部遗产，并受命将遗产返还给他人，那么他也必须返还全部遗产；此次返还同样适用特雷贝利安元老院决议，因为遗嘱信托受益人不能依据法尔基第法保留四分之一。此前受益人请求继承人接受遗产，否则第二顺位遗嘱信托将落空，这一点并不影响结论；遗产一经接受，死者的全部意思即获确认。受益人只在四分之一范围内给付其他遗赠，并不与此矛盾：以继承人身份被起诉，与以死者本人名义受其遗愿约束，是两回事。由此可以说，仅因第一顺位受益人提出请求，不得强迫遗嘱指定继承人接受遗产，尤其是在继承人无任何份额可保留时；这包括受命立即返还，或在期限届至时连同孳息返还的情形。即使受命不附孳息返还，金额也不足以成为强迫其接受遗产的正当理由。第一顺位受益人同时获得解放自由，也无关紧要；如同取得金钱不足以强迫遗嘱指定继承人接受遗产，仅取得自由也同样不足。如果第一顺位受益人拒绝请求，则第二顺位受益人可以直接请求继承人接受遗产并向自己返还。

<!-- source-p 297 -->
<a id="36.1.57.3"></a>**3.**那么，如果继承人受命不是向他人、而是向其本人返还遗产，情况如何？因为不应再将其失去的四分之一返还给他，为此就保留该份额一事应听取他的主张。不过，还不能照例忽略另一点：对于被迫接受遗产的遗嘱指定继承人，是否应拒绝其提出的遗嘱信托请求？因为他既然拒绝履行死者最后的请求，似乎不配再依其遗愿取得任何利益。如果他是在条件成就后才被迫接受遗产，这一结论会更有说服力。若条件尚未成就，作此认定就显得严苛，因为继承人还可能通过放弃而使法尔基第法适用。我也不否认，可以主张绝不能拒绝这种人的遗嘱信托请求；〔本段关于墓地权利及其后的具体法律效果，底本文句疑有缺讹。〕元老院显然不愿让其保留他所放弃份额中的任何利益，以至于他不得主张法尔基第法、不得保留优先取得之物，而且也不得取得依如下方式作出的第二遗嘱书板上的替补：“无论谁成为我的继承人，均应成为我儿子的继承人。”

<!-- source-p 298 -->
<a id="36.1.57.4"></a>**4.**某人已经依特雷贝利安元老院决议接收提提亚的遗产；对于提提乌斯死后应依该决议返还给塞姆普罗尼乌斯的梅维亚遗产，他也可以像其他任何继受人一样予以返还。

<!-- source-p 299 -->
<a id="36.1.57.5"></a>**5.**在遗产由他人胜诉取回后，特雷贝利安元老院决议所赋予的临时诉权仍然存在：此处所指的是，继承人在遗产返还后败诉，而在返还之前诉讼已与其进行到争点确定阶段的情形。因为遗产被取回，表明先前的返还并非基于一项不存在的遗嘱信托。显然，如果后来胜诉取回遗产的人本人也负有遗嘱信托义务，结论则有争议：占有人在计算应返还的遗产时，会将其已经返还给遗嘱信托受益人的部分计入继承人一方；因此，可以主张特雷贝利安元老院决议所赋予的诉权仍然存续。

<a id="36.1.59.pr."></a>**序言。**遗嘱写道：“我的继承人应在各自死亡后，将其从我的遗产或财产中所得的一切返还给我的故乡贝内文托殖民市。”确认：这并未被理解为要求返还条件成就前取得的孳息。

<a id="36.1.60"></a>**36.1.60**

<!-- source-p 309 -->
**帕比尼安：《答复集》第九卷。**

<!-- source-p 310 -->
<a id="36.1.60.pr."></a>**序言。**某继承人受命在扣除四分之一后返还遗产；在返还之前，他成为遗产债务人的继承人。由于诉权因债权债务归于同一人而消灭，特雷贝利安元老院决议不能使该诉权恢复。因此，作为遗嘱信托，仍可请求该债务金额的四分之三。但应计算债权债务归于同一人之日以前已经产生的利息——无论该利息已属于债权关系，还是应由法官裁量判给；此后的利息则只有在遗嘱信托发生迟延时才计算。

<!-- source-p 311 -->
<a id="36.1.60.1"></a>**1.**如果遗嘱信托要求在将来某一时点返还遗产，继承人曾向部分债务人追讨金钱，并不因此就要承担债权不能收回的风险。

<!-- source-p 312 -->
<a id="36.1.60.2"></a>**2.**受命在将来返还遗产的人，无须返还其从遗产债务人处收取的利息；该利息在债权人死亡后才到期。如果他未收取这些利息，所有利息请求权——因为这是遗产上的要式口约——都将依特雷贝利安元老院决议移转，因此也不会发生返还非债给付的问题。同样，如果遗产债务人未在中间期间支付利息，遗嘱信托受益人也可以依据特雷贝利安元老院决议请求这些利息；不能因为继承人未用依法取得的孳息支付利息而提出异议。如果继承人已支付中间期间的利息，也不得因此保留遗产，因为他处理的是自己的事务；他虽被迫向债权人返还本金，却不能将中间期间的利息转由遗嘱信托受益人负担。

<!-- source-p 313 -->
<a id="36.1.60.3"></a>**3.**某人取得一百，并受命返还全部遗产，他似乎有权依据法尔基第法取得这笔全部金钱；神君哈德良的敕答也应作此理解，仿佛他可以从遗产中保留金钱。被命令向共同继承人返还部分遗产时，结论也相同。地产则不同：继承人虽可从自己的份额中保留全部金钱，但地产的其他部分只能从享有所有权的共同继承人处取得。如果地产价值超过遗产份额，而遗嘱信托受益人请求超出部分，似乎应适用法尔基第法；因为应以同时取得的金钱抵销。

<!-- source-p 314 -->
<a id="36.1.60.4"></a>**4.**某人受命在自己死亡后返还遗产，但可以保留收益；他不得保留女奴所生子女，也不得保留为维持畜群而留下的牲畜幼崽。

<!-- source-p 315 -->
<a id="36.1.60.5"></a>**5.**遗嘱信托的请求权期限届至之前产生的孳息和利息——即使遗产债务人是在期限届至后才支付的利息——以及继承人取得的地产租金，都应计入继承人保留的四分之一份额。

<!-- source-p 316 -->
<a id="36.1.60.6"></a>**6.**继承人受命在自己死亡后返还遗产时，并不因此被迫出售遗产物品；他也不因中间期间使用物品而被认为取得了相应价款的利息。他无须承担奴隶或城市地产的灭失风险；但这些物品的使用利益以及意外损失，仍会相应减少其四分之一份额。

<!-- source-p 317 -->
<a id="36.1.60.7"></a>**7.**受命在自己去世时返还遗产剩余部分的人，并不因此被认为还须返还剩余孳息；上述措辞允许遗产减少，却不包括孳息的增加。

<!-- source-p 318 -->
<a id="36.1.60.8"></a>**8.**某继承人受命在自己死后返还剩余遗产；其继承人若并未以诈害为目的，不必解除对遗产物品所设的质押。

<a id="36.1.61"></a>**36.1.61**

**保罗：《疑义集》第四卷。**

<!-- source-p 321 -->
<a id="36.1.61.pr."></a>**序言。**债务人以质押物担保债权人，并指定该债权人为继承人，又请求其将遗产返还给自己的女儿，即遗嘱人的女儿。债权人认为遗产状况可疑，不愿接受；在裁判官命令下，他被迫接受并返还遗产。由于他找不到质押物的买受人，希望获准以所有权人身份占有该物。我答复说：接受遗产时，债权债务确因混同而消灭；但还须考察，自然债务既已消灭，质押是否也随之解除。无论债权人兼请求人暨继承人是否占有该物，都须考察其法律效果。如果他占有该物，遗嘱信托受益人不能对他提起任何诉讼：既不能提起质押诉讼，因为这是遗产诉权；也不能以遗嘱信托为由，主张他返还不足。这就像从未设立质押一样，因为他是以债权人身份占有该物。但即使遗嘱信托受益人持有该物，塞尔维安诉仍可提起：金钱事实上尚未清偿，正如抗辩使诉权丧失时，我们仍认为债务未清偿。因此，不仅可以留置质押物，也可以提起质押物返还请求，且已清偿的金钱不得请求返还。由此可见，质押关系使自然债务仍然存在。若事情尚未处理，我认为不应强迫他接受遗产，除非先为其提供不受损失的担保，或先行清偿金钱。类似地，如果遗嘱指定继承人可能获利——例如遗嘱人规定他若不接受遗产便可取得遗赠——答复认为，除非先给付遗赠，不得强迫他接受遗产。有人或许会说，不应违背死者的意思强迫继承人接受遗产，因为遗嘱人以遗赠将是否接受遗产置于继承人自己的意愿之下；但既然遗嘱人给了两种选择，我们便都应向其提供。

<!-- source-p 322 -->
<a id="36.1.61.1"></a>**1.**一名嫁资给付人曾与丈夫约定，如果她在婚姻关系存续期间死亡，应将部分嫁资返还给她的母亲；母亲并未就此订立要式口约。她后来指定母亲和丈夫为继承人，并请求母亲将遗产返还给提提乌斯。受命分割遗产的法官依据有益的约定，将部分嫁资判给母亲；问题是，这一部分是否也须以遗嘱信托名义给付。我认为无须返还，因为母亲不是以继承人身份，而是以母亲身份依据约定取得该部分；她取得该部分也不是因为遗产继承，而是依据约定。

<a id="36.1.65"></a>**36.1.65**

<!-- source-p 334 -->
**盖尤斯：《遗嘱信托论》第二卷。**

<!-- source-p 335 -->
<a id="36.1.65.pr."></a>**序言。**遗产一经以遗嘱信托方式返还，其全部财物即归受领遗产的人所有，即使他尚未实际取得占有也是如此。

<!-- source-p 336 -->
<a id="36.1.65.1"></a>**1.**如果某人通过要式口约要求继承人向其返还遗产，并据此提起要式口约之诉，而遗产已经返还给他，诉权仍然移转。这一规则适用于被起诉的人返还遗产的情形。但如果被起诉的人因未返还遗产而被判处按遗产价值赔偿，遗产诉权仍留在被判决者手中；请求人则取得判决确定的金额。

<!-- source-p 337 -->
<a id="36.1.65.2"></a>**2.**遗嘱指定继承人返还遗产后，又因遗产发生争议而败诉，或在诉讼中认输；已移转给遗嘱信托受益人的诉权仍继续归其所有，这一点已经确定。

<!-- source-p 338 -->
<a id="36.1.65.3"></a>**3.**如果某人返还的遗产超过受命返还的数额，超出部分的诉权并不移转。但是，如果继承人受命先行取走某物或某笔金额后再返还遗产，却未作保留而返还全部遗产，则应认为诉权已移转。

<!-- source-p 339 -->
<a id="36.1.65.4"></a>**4.**如果继承人在返还遗产之前，命令遗产中的奴隶接受他人遗产的继承指定，尤利安认为，无须返还这份新取得的遗产，因为遗嘱信托并未涉及该遗产；这一意见应予承认。不过还须考察，继承人是否受命返还包括增益在内的遗产。如果确属如此，他也必须返还这份遗产；除非继承人以明确证据证明，遗嘱人指定该奴隶为继承人是为继承人本人的利益。

<!-- source-p 340 -->
<a id="36.1.65.5"></a>**5.**神君安东尼努斯的敕答表明：某人收取提提乌斯给付的金钱——相当于遗产的四分之一——并受命将遗产返还给提提乌斯，即使金钱较迟才给付，也应无息返还。因为给付越迟，受领人取得遗嘱信托也越迟，并失去中间期间的孳息。因此，如果他在收到金钱之前持有遗产，就应向继承人返还他所取得的孳息。

<!-- source-p 341 -->
<a id="36.1.65.6"></a>**6.**如果遗嘱人将遗嘱信托托付给继承人，并写道：“我请求你，如果提提乌斯给你一百，就将我的遗产返还给他”，法律同样适用。

<!-- source-p 342 -->
<a id="36.1.65.7"></a>**7.**如果某人附条件被指定为继承人，并声称遗产状况可疑；而条件既无任何困难或不名誉之处，也不造成费用负担，那么应命他履行条件、接受遗产并予以返还。如果条件不名誉或难以履行，强迫他为了他人利益履行条件，显然不公平。并且，从一开始免除该条件似乎也是妥当的；裁判官给予遗嘱信托请求人超过遗嘱人本意的利益，实属荒谬。遗嘱人显然意在：条件不成就，遗嘱指定继承人便不取得遗产，也不通过该继承人返还遗产。

<!-- source-p 343 -->
<a id="36.1.65.8"></a>**8.**如果遗嘱对继承人附加给付金钱的条件，请求遗嘱信托的人就应向其提出给付金钱，使其能够在条件成就后接受遗产并返还。

<!-- source-p 344 -->
<a id="36.1.65.9"></a>**9.**如果遗嘱附加的条件属于裁判官准予免除的条件，尤利安说，适用裁判官告示即可：只须命遗嘱指定继承人决定是行使裁判官法上的诉权，还是依遗嘱书板请求遗产占有；他取得诉权后，再依该元老院决议在返还遗产时移转诉权。

<!-- source-p 345 -->
<a id="36.1.65.10"></a>**10.**如果条件是承担某一姓名——这是裁判官要求履行的条件——那么履行条件显然是妥当的；采用一个体面之人的姓名并无不当，裁判官也不会要求承担名声败坏或不名誉的姓名。但是，如果当事人拒绝承担该姓名，尤利安说，应免除该条件，并准许其行使有益诉权，或依遗嘱书板准予其遗产占有，使其取得诉权后再依元老院决议移转诉权。

<!-- source-p 346 -->
<a id="36.1.65.11"></a>**11.**“如果我声称遗产状况可疑，你依我请求并奉裁判官命令接受遗产，再将遗产返还给我，那么，如果你本人也有权适用法尔基第法，我就会以该法对抗受遗赠人，并且仅在你依法可以主张的范围内如此主张。”因为如果我另有遗嘱信托给付，该给付不作为遗赠计入该法的计算，而是另行计算。

<!-- source-p 347 -->
<a id="36.1.65.12"></a>**12.**如果提提乌斯受命将遗产返还给梅维乌斯，而梅维乌斯受命向塞尤斯给付确定金额，且提提乌斯依据保留四分之一的权利对梅维乌斯主张了法尔基第法，涅拉提乌斯写道：梅维乌斯也应相应减少向塞尤斯给付的数额，以免其本人遭受财产损失。

<!-- source-p 348 -->
<a id="36.1.65.13"></a>**13.**尤利安说，如果提提乌斯被指定为继承人并受命向提提乌斯返还遗产，而替补继承人梅维乌斯声称遗产状况可疑，那么依提提乌斯的请求，应命梅维乌斯接受遗产并予返还。

<!-- source-p 349 -->
<a id="36.1.65.14"></a>**14.**如果有人将遗产返还义务托付给遗产占有人，而该占有人任由取得遗产占有的期限届满；或者受领遗产返还的人因某种原因，在该期间无法到裁判官处请求遗产占有，并请求将遗产返还给自己，则应予以救济：为履行遗嘱信托，应使其取得遗产占有的期限恢复。

<!-- source-p 350 -->
<a id="36.1.65.15"></a>**15.**还应注意：如果无力清偿债务的人指定提提乌斯为继承人，命令某奴隶获释，并请求提提乌斯将遗产返还给该奴隶，那么提提乌斯若拒绝接受遗产，恐怕不能强迫他接受。因为即使提提乌斯应奴隶请求接受了遗产，奴隶的解放也不能生效，仿佛这是为诈害债权人而作出的解放；即便提提乌斯富有，结论也是如此。因此，遗产也不能返还给奴隶。不过，依该法律的意思，应将此情形视同只有该奴隶一人被解放并指定为继承人，而提提乌斯并非继承人。

<!-- source-p 351 -->
<a id="36.1.66"></a>**36.1.66**

<!-- source-p 352 -->
**梅基安努斯：《遗嘱信托论》第四卷。**

<!-- source-p 353 -->
<a id="36.1.66.pr."></a>**序言。**如果依据该元老院决议，将一名未经监护人同意而借出金钱给未适婚年龄者的人的遗产返还给我，我若向债权人清偿，便不得请求返还。然而，继承人在遗产返还后清偿的，却可以请求返还；这是因为自然债务被理解为已经从他移转给我。反过来，如果将曾未经监护人同意而向未适婚年龄者借款之人的遗产返还给我，该未适婚年龄者向我清偿后不得请求返还；但如果他向继承人清偿，就可以请求返还；若在遗产返还之前清偿，则不得请求返还。

<!-- source-p 354 -->
<a id="36.1.66.1"></a>**1.**如果必然继承人是附有哪怕极轻微条件而被指定的，而他们通常会履行该条件，那么应认为：在遗嘱信托受益人提出请求时，可以强迫其返还遗产；因为必然继承人也必须为返还遗产遗嘱信托而履行条件。

<!-- source-p 355 -->
<a id="36.1.66.2"></a>**2.**某人受命返还遗产，却在返还前去世；其继承人可以返还遗产，诉权也依特雷贝利安元老院决议移转。如果他留下两名继承人，则每一人返还多少，诉权就按该比例移转；更准确地说，即使死者本人只返还部分遗产，诉权也应暂按比例移转。同样，如果受命返还遗产的人有数名继承人，而其中一些先行返还；或者应受返还的人有数名继承人，则凡受领返还者均应依本元老院决议按相应份额取得诉权。

<!-- source-p 356 -->
<a id="36.1.66.3"></a>**3.**如果受庇护人被指定为应得份额的继承人，并受命将该份额返还给死者所遗弃的子女；若他自愿接受遗产，法尔基第法适用；若他是被迫接受，则全部诉权依本元老院决议移转。

<!-- source-p 357 -->
<a id="36.1.67"></a>**36.1.67**

<!-- source-p 358 -->
**梅基安努斯：《遗嘱信托论》第五卷。**

<!-- source-p 359 -->
<a id="36.1.67.pr."></a>**序言。**未经奴隶同意或在奴隶不知情的情况下，不得有效地向奴隶返还遗产；但奴隶后来追认的，返还即获得确认，不过诉权归奴隶的主人取得。该项返还类似于取得遗产，因此本应先有主人命令；然而并非如此，正如上文所说，也可以事后追认，这与遗产占有的情形相同。就此而言，无论请求返还遗产的人是主人本人还是奴隶，并无区别；也不需要奴隶同意或参与返还。相反，在取得遗产占有或接受遗产时，则需要奴隶同意。因此，如果继承人声称遗产状况可疑，主人提出请求后，应强迫其接受并返还遗产。

<!-- source-p 360 -->
<a id="36.1.67.1"></a>**1.**如果遗嘱人请求继承人将遗产返还给一名女性，条件是她未再婚；继承人声称遗产状况可疑，应当命其接受遗产并返还给该女性，即使她已经再婚。尤利安也赞同对其他类似条件作同样处理，因为这些条件只有到生命终结时才可能确定是否履行。依照这一意见，继承人应向有利害关系的人提供担保，然后将遗产返还给遗嘱指定的受益人；该受益人受命在相同条件下返还遗产。〔底本文句中 *poss...* 一词形疑有粘连或讹误，以上依上下文译。〕

<!-- source-p 361 -->
<a id="36.1.67.2"></a>**2.**裁判官查明情况后，即使因错误或徇私命令以遗嘱信托方式返还遗产，基于裁判既判力的权威，返还仍关系公共利益。

<!-- source-p 362 -->
<a id="36.1.67.3"></a>**3.**如果某人受命向婴儿返还遗产，而他自愿接受遗产，那么遗产可以在监护人同意下返还给婴儿本人或其奴隶。婴儿尚不能说话，并不比能言语的未适婚年龄者更妨碍此事；后者愿意受领遗产即可。若继承人拒绝接受遗产，则如何处理颇为困难：监护人提出请求，也不能让婴儿承担风险而接受遗产，以致特雷贝利安元老院决议无法适用；婴儿本人又不能提出请求，因为他尚不会说话。对于聋哑者，此事还较易处理；如果他们能够听见，或者可以用动作表示愿意自担风险接受遗产，就与缺席者通过使者表示意思相同。但我毫不怀疑，应当在一切情形下救济婴儿，并参照市民法或裁判官法作出规定。如果他被指定为继承人，显然可以在监护人同意下代为管理遗产；如果争议的是遗产占有，也可由监护人代为请求。因此，也可以通过监护人强迫继承人接受并返还遗产。依同一先例，对于完全不能理解事物的聋哑者，也应由保佐人予以协助。

<!-- source-p 363 -->
<a id="36.1.67.4"></a>**4.**如果继承人依我的命令，将个别物品交付给我已出售这些物品的买受人，我们不应怀疑该返还应视为向我作出。同样，如果他依我命令将物品交给我基于遗嘱信托或其他原因应向其给付的人、向其放贷的人，或我想赠与的人，也应如此。

<!-- source-p 364 -->
<a id="36.1.68"></a>**36.1.68**

<!-- source-p 365 -->
**保罗：《遗嘱信托论》第二卷。**

<!-- source-p 366 -->
<a id="36.1.68.pr."></a>**序言。**某人被附条件指定为继承人，条件是其共同继承人已经接受遗产；即使共同继承人是被迫接受遗产，只要他本人并非被迫接受，仍可依照法尔基第法主张权利。

<!-- source-p 367 -->
<a id="36.1.68.1"></a>**1.**尤利安写道：如果遗嘱信托受益人请求，也可以向缺席者的代理人返还遗产，但代理人须就缺席者追认提供担保，除非缺席者的意思明确。应当指出，如果缺席者是否曾委任代理人尚不确定，即使代理人提供担保，也不得强迫声称遗产状况可疑的继承人接受遗产；因为担保本身不够可靠。但如果继承人自愿接受遗产，风险便不大；如果缺席者没有授权，诉权会在其追认时移转。

<!-- source-p 368 -->
<a id="36.1.68.2"></a>**2.**如果遗产奴隶受到损害，尽管继承人可以通过该奴隶开始取得诉权，阿奎利亚法上的诉权仍不移转给遗嘱信托受益人；因为移转的只是以死者财产为基础的诉权。

<!-- source-p 369 -->
<a id="36.1.68.3"></a>**3.**如果受遗赠人在罗马被迫接受遗产并予返还，遗嘱信托受益人也必须在罗马应诉，尽管继承人本人并未被迫接受。

<!-- source-p 370 -->
<a id="36.1.68.4"></a>**4.**遗嘱信托受益人是否也应在死者本应被起诉的地方应诉？应当考察：如果继承人自愿接受并返还遗产，遗嘱信托受益人是否应在三个地方应诉——死者住所地、继承人住所地，以及其本人住所地。因而，应在遗嘱信托受益人住所地，或者返还遗产的大部分所在地起诉他。

<!-- source-p 371 -->
<a id="36.1.69"></a>**36.1.69**

<!-- source-p 372 -->
**瓦伦斯：《遗嘱信托论》第三卷。**

<!-- source-p 373 -->
<a id="36.1.69.pr."></a>**序言。**如果我请求你声称遗产状况可疑，并依裁判官裁定接受遗产，而我后来既不愿让遗产返还给自己，也不想介入遗产事务，那么应如此处理：裁判官应向我授予诉权，仿佛我已经接受了遗产。奥克塔维努斯认为这种处理并非不妥；如此做更为公正。

<!-- source-p 374 -->
<a id="36.1.69.1"></a>**1.**即使你在筹划诈害债权人时声称遗产状况可疑，并接受遗产后返还给我，也不会因此承担诈害禁令的风险；因为即使没有遗嘱信托，你本来就可以拒绝接受遗产，以此便利诈害自己的债权人；而我接受遗产，也没有任何不名誉之处，因为如果不是我提出请求，债权人原本无权强迫你接受遗产。

<!-- source-p 375 -->
<a id="36.1.69.2"></a>**2.**如果父亲指定自己的儿子为继承人，并要求儿子将遗产返还给我；儿子为了诈害自己的债权人而筹划逃避责任，随后又依裁判官裁定，声称遗产状况可疑并将遗产返还给我，那么诈害禁令恐怕不适用；因为父亲的财产经出售后，他自己的债权人无法从该遗产取得任何财物。除非儿子的个人债权人也应获准主张：在父亲的财产不再被出售后，允许他们出售儿子的财产。

<!-- source-p 376 -->
<a id="36.1.69.3"></a>**3.**如果继承人以赠与为由声称遗产状况可疑，并将遗产返还给无权取得全部遗产的人，那么该受领人无权取得的部分应从其所得中扣除。即使信托继承人并无赠与意图而如此办理，结论也相同。

<!-- source-p 377 -->
<a id="36.1.70"></a>**36.1.70**

<!-- source-p 378 -->
**瓦伦斯：《遗嘱信托论》第四卷。**

<!-- source-p 379 -->
<a id="36.1.70.pr."></a>**序言。**如果遗嘱人在死亡时无力清偿债务，却请求继承人返还遗产；继承人声称遗产状况可疑，那么毫无疑问，如今他可以在被迫的情况下，依据特雷贝利安元老院决议返还遗产。即使他自愿接受遗产，也应依同一元老院决议返还；尽管对于无力清偿债务的人以遗嘱信托方式留给他的一笔金额或特定物品，其效力与遗赠相同，并不产生更多义务。因为在这种情形中，受遗嘱信托之人处于受遗赠人的地位，而前述情形中则处于继承人的地位。

<!-- source-p 380 -->
<a id="36.1.70.1"></a>**1.**如果你受命返还全部遗产，并自愿接受后未扣除四分之一便予返还，那么很难相信你这样做是出于无知，而非为了不履行遗嘱信托；但是，如果你证明未保留四分之一是因错误所致，就可以请求取回。

<a id="36.1.72"></a>**36.1.72**

<!-- source-p 385 -->
**庞波尼乌斯：《遗嘱信托论》第二卷。**

<!-- source-p 386 -->
<a id="36.1.72.pr."></a>**序言。**遗嘱指定继承人受命向提提乌斯返还遗产，而提提乌斯又受命在期限届至后向继承人返还遗产；继承人可通过直接诉权获得充分救济。

<!-- source-p 387 -->
<a id="36.1.72.1"></a>**1.**如果继承人在返还遗嘱信托遗产之前，处分了遗产中的物品，解放了遗产奴隶，或者毁损、破坏、焚烧了物品，那么遗产返还后，依据特雷贝利安元老院决议，不得对其提起市民法诉讼；已灭失之物应以遗嘱信托为由请求。如果继承人在返还遗产后实施上述行为，则可以依据阿奎利亚法对其提起诉讼，例如他伤害或杀死了遗产奴隶。

<!-- source-p 388 -->
<a id="36.1.72.2"></a>**2.**如果遗产中有一项附期限的诉权，继承人在返还遗产之前本可行使诉权的期间，应计入遗产返还受益人一方。

<!-- source-p 389 -->
<a id="36.1.73"></a>**36.1.73**

<!-- source-p 390 -->
**梅基安努斯：《遗嘱信托论》第十卷。**

<!-- source-p 391 -->
如果遗嘱信托受益人愿意自行承担风险接受遗产，那么所有正在考虑是否接受遗产的人都会被迫接受；但他们不必立即返还遗产，而是在考虑期间届满后，若发现接受遗产对自己有利，就可依自愿接受遗产时适用的法律享有遗嘱利益；若认为遗产反而负担沉重，则应返还遗产，并免于承担遗产诉讼。

继承人受命先取一块地产，再返还遗产；但该地产并非遗产所有。阿里斯托说，应当查明遗嘱人是无论如何都想让继承人保有该地产，还是仅在该地产属于遗产时才如此安排。他赞同后一种理解；因此应由继承人保留该地产的估价金额。

<a id="36.1.75"></a>**36.1.75**

<!-- source-p 396 -->
**梅基安努斯：《遗嘱信托论》第十三卷。**

<!-- source-p 397 -->
<a id="36.1.75.pr."></a>**序言。**如果继承人将遗产金钱借出并收取质押物，那么遗产返还后，受领人无权针对质押物提起诉讼。不过，如果继承人在遗嘱人所订合同中承接债权，并在返还遗产前取得质押，仍会留下疑问。但即使如此，受领人也不能直接提起诉讼；然而他可以基于遗嘱信托对继承人提起诉讼，要求继承人将质押物所生利益对应的诉权让与他。

<!-- source-p 398 -->
<a id="36.1.75.1"></a>**1.**依据特雷贝利安元老院决议返还遗产时，继承人与遗嘱人各自地产之间相互享有的地役权仍然有效。

<a id="36.1.76"></a>**36.1.76**

<!-- source-p 400 -->
**保罗：《裁决集》第二卷。**

<!-- source-p 401 -->
<a id="36.1.76.pr."></a>**序言。**某人有一子一女，立遗嘱时对女儿写道：“*entellomai soi my diativesvai, prin tekna soi genesvai*〔即：我命令你在生育子女之前不得订立遗嘱〕。”皇帝宣告，根据这段文字应履行遗嘱信托；仿佛遗嘱人因禁止女儿立遗嘱而请求她将其兄弟指定为继承人。该段文字应如此理解，犹如遗嘱人请求女儿返还自己的遗产。

<!-- source-p 402 -->
<a id="36.1.76.1"></a>**1.**法比乌斯·安东尼努斯留下未适婚年龄的儿子安东尼努斯和女儿霍诺拉塔，并将二人排除继承，随后指定他们的母亲尤尼娅·瓦莱里安娜为继承人，向女儿留了三百及若干物品，并命其在儿子安东尼努斯年满二十岁时将其余全部遗产返还给儿子；如果儿子在年满二十岁前去世，则命将该遗产返还给霍诺拉塔。母亲无遗嘱去世，留下两个子女作为法定继承人。后来，儿子在已满十九岁、进入二十岁但尚未满二十岁时去世；女儿指定法比娅·瓦莱里安娜为自己的继承人。姑母以遗嘱信托及其父亲遗嘱中的遗产份额为由向法比娅请求给付，并已在总督处胜诉。法比娅的监护人提出她无力承担，并援引神君哈德良的敕令：该敕令就市政义务而言，规定某人一旦进入某一年龄年度，即按该年龄已经届满计算。我们的皇帝则基于本案的公平以及遗嘱中“年满二十岁时”的措辞而受到触动；尽管他知道神君马尔库斯曾规定，年满七十岁者进入该年龄年度后仍不得免除监护职责；尽管我们又援引埃利亚·森提亚法的理由及其他论据，皇帝仍裁定驳回请求人的主张。

<!-- source-p 403 -->
<a id="36.1.77"></a>**36.1.77**

<!-- source-p 404 -->
**谢沃拉：《学说汇纂》第十八卷。**

<!-- source-p 405 -->
<a id="36.1.77.pr."></a>**序言。**某人致函其继承人：“提提乌斯致其继承人科尔内利乌斯：科尔内利乌斯，因为我母亲的份额以及我昔日监护人塞姆普罗尼乌斯的份额现已归你——他遭遇了相反的命运——我希望我的全部遗产都归你；我请求你将十二分之四返还给盖乌斯·塞尤斯。”问题是，塞姆普罗尼乌斯已被皇帝恢复原状——他先前遭到流放——并已接受遗产，那么是否也受命从其份额中返还遗产。我答复说，材料并未显示塞姆普罗尼乌斯受命返还；科尔内利乌斯作为继承人，则应按比例从死者母亲的遗产财产中向塞尤斯返还。

<!-- source-p 406 -->
<a id="36.1.77.1"></a>**1.**一名女性请求遗嘱指定继承人保留四分之一后，将其余部分返还给自己昔日的儿媳；她对继承人写道：“我请求你，将你从我的财产中取得之物转交给你的儿子。”问题是，应在何时返还这项遗嘱信托——在该女性去世后，还是现在。我答复说，应将遗嘱信托的给付期限确定为儿媳去世之时。

<a id="36.1.78"></a>**36.1.78**

<!-- source-p 408 -->
**谢沃拉：《学说汇纂》第十九卷。**

<!-- source-p 409 -->
谢沃拉答复说：父亲指定未适婚年龄的儿子为全部遗产的继承人，又在遗嘱信托文件中为其指定替补继承人；儿子随后在未适婚年龄时去世。尽管这种替补无效，因为遗嘱信托文件不能指定或撤销继承人，但依宽厚解释，仍应认为：从未订立遗嘱的未适婚年龄者处取得继承权的母亲，受该替补遗嘱信托的约束。如果子女相互替补，那么遗嘱信托中的替补也有效；其中一人去世后，尚存者取得全部遗产。

<a id="36.1.79"></a>**36.1.79**

<!-- source-p 411 -->
**谢沃拉：《学说汇纂》第二十卷。**

<!-- source-p 412 -->
<a id="36.1.79.pr."></a>**序言。**某人指定男女子女为继承人，并分别请求他们：如果有人无子女去世，应将其遗产份额返还给其姐妹或兄弟；如果没有兄弟姐妹，则返还给母亲。他还加上如下文字：“我最亲爱的子女们，我希望你们彼此负有这项遗嘱信托义务，直至你们各自抚养两个子女成人。”问题是，如果其中一名子女曾生育两名儿子，虽未留下尚存子女，其继承人是否仍负有遗嘱信托义务。我答复说，依所陈述的情况，似乎应免除遗嘱信托义务。

<!-- source-p 413 -->
<a id="36.1.79.1"></a>**1.**提提乌斯指定其女儿所生的孙子以及患精神错乱的女儿为继承人，并委托女儿：如果她无子女去世，应将留给她的遗产份额归于共同继承人。提提乌斯亲自为患精神错乱的女儿安排婚姻；她在父亲去世后生下一名女儿。问题是，该女儿去世时留下了这段婚姻所生的女儿，遗嘱信托是否应归共同继承人。我答复说，既然她留下了女儿，遗嘱信托便不应给付。克劳狄乌斯补充说：尽管与患精神错乱者缔结的婚姻并非有效婚姻，但上述条件仍已得到满足。

<!-- source-p 414 -->
<a id="36.1.80"></a>**36.1.80**

<!-- source-p 415 -->
**谢沃拉：《学说汇纂》第二十一卷。**

<!-- source-p 416 -->
<a id="36.1.80.pr."></a>**序言。**卢基乌斯·提提乌斯自知将无遗嘱而死，当时有妻子和一名已被解放的女儿；他在遗嘱信托文件中写道：“本文件涉及我的妻子和女儿。因此，我请求，无论我留下什么财产，或你们自己拥有何种财产，都由你们共有；即使我不请求，你们也会基于孝心如此办理。”女儿依无遗嘱继承规则取得其父财产的遗产占有。问题是，女儿是否应以遗嘱信托为由，将卢基乌斯·提提乌斯的遗产份额给付母亲。我答复说，依所陈述的情况，如果妻子也愿意将自己的财产纳入共有，则应给付一半。

<!-- source-p 417 -->
<a id="36.1.80.1"></a>**1.**梅维娅留下两个儿子为继承人，并在同一遗嘱中作如下安排：“我将遗嘱信托托付给我的继承人：我的全部财产应作为无息寄存款存放在盖乌斯·塞尤斯和卢基乌斯·提提乌斯处；如果法律允许，我也会排除他人而指定他们为我财产的管理人，以便他们在我的孙子各自年满二十五岁时，按份额向其返还，或者在仅有一名孙子的情况下，将全部遗产返还给他。”问题是，遗嘱指定的继承人卢基乌斯·提提乌斯和盖乌斯·塞尤斯是否应履行该遗嘱信托。我答复说，依所陈述的情况，卢基乌斯·提提乌斯和盖乌斯·塞尤斯均不得请求该遗嘱信托。〔底本在 *fidei committo* 附近有校勘形式 *heredem*，与语法不合，需核对校本。〕

<!-- source-p 418 -->
<a id="36.1.80.2"></a>**2.**遗嘱指定其兄弟梅维乌斯取得十二分之九、塞尤斯取得十二分之二、塞尤斯的奴隶斯提库斯取得十二分之一为继承人；另指定梅维乌斯的亲生儿子为继承人，取得十二分之一，并委托塞尤斯解放斯提库斯，遗嘱写道：“塞尤斯，我请求你解放斯提库斯；我已给你足够财产来办理此事。”遗嘱信托文件又写道：“如果塞尤斯对我指定斯提库斯为继承人所留的十二分之一提出任何争议，我希望该份额归还给我的兄弟梅维乌斯。兄弟，请依你的诚信和孝义，将你从我的遗产中所得的一切返还给你的儿子斯提库斯；我将此事托付给你的诚信。”问题是，塞尤斯接受遗产，并因此被迫解放斯提库斯后，是否应将指定斯提库斯为继承人所对应的十二分之一返还给已获释的斯提库斯。我答复说，材料并未表明曾请求塞尤斯将该十二分之一返还给斯提库斯。

<!-- source-p 419 -->
<a id="36.1.80.3"></a>**3.**同一人又问：如果塞尤斯就指定斯提库斯为继承人所对应的十二分之一提出争议，而梅维乌斯以遗嘱信托为由从塞尤斯处取得该十二分之一，他应将这一个十二分之一返还给斯提库斯，还是还应返还梅维乌斯本人作为继承人所取得的十二分之九。我答复说，遗嘱人意在让梅维乌斯以任何方式取得的一切均予返还。

<!-- source-p 420 -->
<a id="36.1.80.4"></a>**4.**父亲指定一名男孩和一名女孩为继承人，并令他们相互替补；如果二人都未成为继承人，又指定数名替补继承人，并令这些替补者彼此替补，遗嘱写道：“我指定替补继承人相互替补。”父亲还委托这对子女：其中一人活过另一人，并在三十岁前无子女去世时，应将遗产返还给父亲所指定的替补继承人。儿子活过姐姐，并在三十岁前无子女去世。问题是，如果一名替补继承人在儿子之前去世，其份额归尚存的其他替补继承人时，应按人头平均分配，还是按照他们被指定的遗产份额分配。我答复说，遗嘱信托应依替补继承人各自被指定的份额分配。

<!-- source-p 421 -->
<a id="36.1.80.5"></a>**5.**梅维娅指定儿子取得十二分之五、女儿提提娅取得四分之一、儿子塞普提基乌斯取得三分之一为继承人，并将遗嘱信托托付给塞普提基乌斯，写道：“儿子塞普提基乌斯，我请求你，如果你在二十岁前无子女去世，就将你从我遗产中取得的一切返还给你的兄弟姐妹。”问题是，塞普提基乌斯在二十岁前无子女去世时，这项遗嘱信托应按其兄弟姐妹的继承份额分配，还是应平均分配。我答复说，应按继承份额分配。

<!-- source-p 422 -->
<a id="36.1.80.6"></a>**6.**提提娅被指定为全部遗产的继承人，并受命返还梅维娅遗产的一半。她不愿清偿遗嘱人设定负担的地产债务；债权人出售该地产时，她却指示塞娅赎回地产。问题是，提提娅是否应以遗嘱信托为由对梅维娅承担责任。我答复说，既然她受命返还遗产，就没有理由认为她不承担责任。克劳狄乌斯补充说：她至少应给付地产价值超过债权人本应取得数额的部分。

<!-- source-p 423 -->
<a id="36.1.80.7"></a>**7.**盖乌斯·塞尤斯被指定为十二分之六的继承人，提提娅为四分之一继承人，其他人则取得剩余份额；遗嘱写道：“盖乌斯·塞尤斯和卢基娅·提提娅，我将遗嘱信托托付给你们：在你们去世后，将我留给你们的遗产及份额中的十二分之六返还给提提乌斯和塞姆普罗尼乌斯。”二人均接受遗产后，盖乌斯·塞尤斯去世，卢基娅·提提娅被指定为其继承人。问题是，卢基娅·提提娅是否应立即返还盖乌斯·塞尤斯受命返还的十二分之六中的一半，还是要等自己去世后，再将她本人及盖乌斯·塞尤斯所负担的全部遗嘱信托一并返还。我答复说，卢基娅·提提娅应立即承担义务，返还盖乌斯·塞尤斯份额中十二分之六的一半。

<!-- source-p 424 -->
<a id="36.1.80.8"></a>**8.**某人指定女儿为继承人，并指定女儿所生的孙子为替补继承人，另写道：“我将二百枚金币留给我的兄弟之子、女婿卢基乌斯·提提乌斯。我知道他会满足于这项遗赠，因为我已指定女儿和孙子为继承人，从而使他们共有我的全部财产。我将他们彼此托付。”女儿接受父亲遗产后与丈夫离婚。问题是，提提乌斯这位她的前夫能否以自己或其子之名，在前妻生前或其死后，以遗嘱信托为由取得财产共有权。我答复说，材料仅表明遗嘱信托给付给了女婿二百枚金币。

<!-- source-p 425 -->
<a id="36.1.80.9"></a>**9.**同一人又问：该女性指定丈夫为继承人，并以遗嘱信托委托他在去世时，将自己从遗产中取得的一切返还给二人共同的儿子；那么，先前作为嫁资给付、离婚后已返还给该女性的物品和地产，是否也包含在遗嘱信托中。我答复说，该女性留在自己财产中的物品包含在遗嘱信托中。克劳狄乌斯补充说：我也曾就同一事实受咨询，并作如下答复：无论嫁资物品已经返还，还是尚未返还——如果尚未返还，是因为已订立返还嫁资的要式口约，故应返还——均应计入女性的财产，并据此计算遗产价值。

<!-- source-p 426 -->
<a id="36.1.80.10"></a>**10.**某女性有一子，且有该子所生之孙；二人均处于其丈夫的权力之下。她指定丈夫为全部遗产的继承人，并将遗嘱信托托付给丈夫，写道：“如果我的丈夫提提乌斯成为我的继承人，我请求并将遗嘱信托托付给他：在他开始临终时，将从我的遗产中取得的一切给付并返还给我们的儿子盖乌斯；但须如此分配：盖乌斯取得十二分之十，孙子塞尤斯取得十二分之二。我的继承人提提乌斯，我将此事托付给你的诚信。”丈夫解放了儿子；孙子先于父亲去世，父亲在儿子仍在世时去世。问题是，遗嘱前文是否以遗嘱信托名义将全部遗产留给儿子，而后文“儿子取得十二分之十，孙子取得十二分之二”只有在遗嘱信托期限届至时二人均仍在世才适用；既然孙子未能活到期限届至，后文是否失效。我答复说，依所述情况，表明仅有十二分之十留给儿子。

<!-- source-p 427 -->
<a id="36.1.80.11"></a>**11.**遗嘱指定继承人受命向妻子返还全部遗产，但扣除四分之一后已返还。问题是：妻子又受遗嘱人请求，将遗产的四分之一立即返还给他人，其余部分则在期限届至后返还；继承人从其遗产中扣除的四分之一，能否计入妻子应返还的遗嘱信托。我答复说，在她取得的范围内，她受遗嘱信托约束。

<!-- source-p 428 -->
<a id="36.1.80.12"></a>**12.**遗嘱人将遗嘱信托托付给继承人：当盖乌斯·梅维乌斯——遗嘱人的受供养者——年满十五岁时，应将他们从遗产三分之一份额中取得的一切返还给他。遗嘱人又写道：“在此期间，你们应以从遗产收益中取得的金额，按相应数额计算利息，用以供养他。此外，我的受供养者还应取得一名卡莱塔奴隶和一名本地出生的鞋匠奴隶，后者可以凭其手艺挣取费用供养他。”问题是，遗嘱指定继承人给付的生活费远低于按本金计算的利息数额，他们是否应被迫补足全部期间的差额，还是只须补足受供养者年满十五岁之后的差额？又因为专门遗赠给他的奴隶很快被出售，以便他靠奴隶的收入生活，他应请求租金收入还是利息？我答复说，依所述情况，遗嘱人似乎意在返还全部收益及奴隶所得。

<!-- source-p 429 -->
<a id="36.1.80.13"></a>**13.**遗嘱指定数名继承人，其中三名被释奴取得十二分之九；遗嘱人又以优先取得方式将若干地产留给他们，请求他们不得出售，并规定其中活得最久者完整保有这些地产。随后，遗嘱人将遗嘱信托托付给其中名为奥塔基利乌斯的一名被释奴：将其从遗产或财产中取得的一切，在按其份额扣除债务、遗赠以及给自己留下的二十枚金币后，返还给提提乌斯。问题是，是否还应扣除遗嘱人以优先取得方式留给该被释奴及其同伴的地产三分之一份额。我答复说，依所述情况，无须返还优先取得的地产，因为遗嘱人本人已表示遗赠应予扣除。

<!-- source-p 430 -->
<a id="36.1.80.14"></a>**14.**丈夫指定妻子为三分之一份额的继承人，又留给她多项遗嘱信托，并以优先遗赠方式留给她嫁资，写道：“我希望由我的儿子们向我的妻子塞娅给付她嫁资的金额，即她为嫁资而交付给我的金额。”他又将遗嘱信托托付给妻子，命她在去世后将遗产份额以及他留给她的一切返还给二人共同的儿子提提乌斯。问题是，她是否也应以遗嘱信托为由，将嫁资金额连同其他遗赠一起返还给儿子。我答复说，只有在遗嘱人显然也意在返还嫁资时才应如此；即使证明遗嘱人确有此意，儿子也只有在妻子依据法尔基第法保留的金额不低于嫁资金额时，才能请求返还。

<!-- source-p 431 -->
<a id="36.1.80.15"></a>**15.**继承人受命在塞普提基乌斯年满二十岁时向其返还遗产。其间，继承人出售了死者取得质押的地产，因此被债务人依据质押诉起诉；他留下继承人塞姆普罗尼乌斯，诉讼尚未终结时便将遗产返还给塞普提基乌斯。问题是，继承人是否仍应在诉讼中被判决承担责任，因为他本可保留或要求担保其依据判决应给付的金额。我答复说，即使遗产已经返还，诉讼执行仍可针对继承人继续进行。

<!-- source-p 432 -->
<a id="36.1.80.16"></a>**16.**某继承人受命在自己去世后返还全部遗产。他只将其声称是遗产全部财产的极小金额返还给遗嘱信托受益人；后来找到的账册显示，遗产实际金额为此前所称的四倍。问题是，能否以遗嘱信托为由请求其给付余额。我答复说，依所述情况，如果双方尚未达成和解，就可以请求。

<!-- source-p 433 -->
<a id="36.1.81"></a>**36.1.81**

<!-- source-p 434 -->
**谢沃拉：《公开讨论疑义集》单卷。**

<!-- source-p 435 -->
如果未适婚年龄者成为父亲的继承人，并已返还遗嘱信托所涉的部分遗产，后来又拒绝接受父亲的遗产，那么应将选择权交给遗嘱信托受益人：他可以接受未适婚年龄者的份额，也可以放弃全部遗产。或者，应出售全部财产，将剩余部分留给未适婚年龄者；如果财产不能全部出售，就应一概拒绝遗嘱信托受益人的诉权。因为受益人原本可以选择接受全部遗产，并将超出部分留给未适婚年龄者。

<!-- source-p 436 -->
<a id="36.1.82"></a>**36.1.82**

<!-- source-p 437 -->
**谢沃拉：《学说汇纂》第五卷。**

<!-- source-p 438 -->
卢基乌斯·提提乌斯指定其母亲和舅父——他们也是他的债权人——为继承人，并将遗嘱信托托付给二人，命他们在去世后将其家产中剩余之物返还给塞普提基乌斯。继承人耗用了遗嘱人相当一部分财产，并留下许多继承人；这些继承人知情，仍有大量卢基乌斯·提提乌斯的遗产物品由塞普提基乌斯占有。问题是，塞普提基乌斯能否向他们请求给付卢基乌斯·提提乌斯所欠其母亲和舅父的债务。我答复说，不能。克劳狄乌斯补充说：继承人接受遗产后，债权债务因混同而消灭；但原本仍可基于遗嘱信托请求返还。只是对于被指称耗用了遗产相当部分的人而言，这项请求已不再公平。

<!-- source-p 439 -->
<a id="36.1.83"></a>**36.1.83**

<!-- source-p 440 -->
**保罗：《帝国审判案件裁决集》第六卷第一卷本，亦即《裁决集》第二卷。**

<!-- source-p 441 -->
尤利乌斯·福埃布斯订立遗嘱，指定三个子女为继承人：同母所生的福埃布斯和赫拉克利娅，以及异母所生的波吕克拉忒斯，三人各得相等份额。他请求弟弟波吕克拉忒斯在取得一处特定地产后，将遗产让给兄弟姐妹；并规定，同母兄弟姐妹中任何一人未能成为继承人时，另一人替补。对于波吕克拉忒斯，他另立第二遗嘱书板：如果其在未适婚年龄时去世，便由其母亲开启。随后他请求先前指定的继承人：若其中有人无子女去世，应将其份额扣除其母系财产和祖父财产后，返还给尚存者一人或数人。姐妹赫拉克利娅无子女去世后，指定其兄福埃布斯为继承人。波吕克拉忒斯以遗嘱信托为由向亚细亚行省总督奥勒留·普罗库卢斯请求给付，并获支持。提起上诉后，福埃布斯单独进行诉讼（*monomerōs*〔即仅一方当事人出庭〕），却败诉，因为“给他一人或数人”的措辞涵盖两名兄弟。然而，遗嘱人只将那两名兄弟彼此指定为替补继承人；而且父亲似乎也有此意，因为他排除了他们的母系财产；波吕克拉忒斯有另一位母亲，而且她当时仍在世。遗嘱人还将遗嘱信托托付给这位母亲，命她在去世时将遗嘱留给她的遗赠返还给儿子波吕克拉忒斯。〔原文此处以省略点截断。〕
