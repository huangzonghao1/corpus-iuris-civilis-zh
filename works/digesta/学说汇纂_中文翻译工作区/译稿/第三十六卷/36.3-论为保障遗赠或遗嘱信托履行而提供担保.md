# D.36.3 为保障遗赠或遗嘱信托履行而提供担保（*Ut legatorum seu fideicommissorum servandorum causa caveatur*）

<!-- source-p 582 -->
<a id="3"></a><a id="36.3"></a>**36.3.0 为保障遗赠或遗嘱信托履行而提供担保**（*Ut legatorum seu fideicommissorum servandorum causa caveatur*）。

<!-- source-p 583 -->
<a id="36.3.1"></a>**36.3.1**

<!-- source-p 584 -->
乌尔比安《告示评注》第七十九卷。

<!-- source-p 585 -->
<a id="36.3.1.pr."></a>**序言**　裁判官认为，应就遗赠提供担保，以确保遗嘱人希望给付或实施的事项能在指定日期给付或实施；受遗赠人还应以要式承诺取得保证，确保不存在恶意。

<!-- source-p 586 -->
<a id="36.3.1.1"></a>**1**　继承人无论地位或财产状况如何，均须提供担保。

<!-- source-p 587 -->
<a id="36.3.1.2"></a>**2**　裁判官如此规定并非没有道理：既然继承人可以占有遗产，受遗赠人也不应被排除在死者的遗产之外。因此，继承人要么向他们提供担保；若不提供担保，裁判官便允许他们占有遗产。

<!-- source-p 588 -->
<a id="36.3.1.3"></a>**3**　不仅应向所有受遗赠人提供担保，现已确认，也应向受遗赠人的继承人提供担保，尽管后者并非基于死者的处分，而是因继承关系而如同债权人一般获得请求权。

<!-- source-p 589 -->
<a id="36.3.1.4"></a>**4**　也应向受遗赠人的代理人提供担保；我们遵循这一法律规则。

<!-- source-p 590 -->
<a id="36.3.1.5"></a>**5**　当然，若遗赠留给处于他人权力下之人，则应向该人所从属之权力人提供担保。

<!-- source-p 591 -->
<a id="36.3.1.6"></a>**6**　不仅继承人须就遗赠提供担保，其继承人也须如此。

<!-- source-p 592 -->
<a id="36.3.1.7"></a>**7**　即使某人依据元老院决议取得遗产返还，也仍会被强令提供担保。

<!-- source-p 593 -->
<a id="36.3.1.8"></a>**8**　通过其他继承人取得权利的人，或依裁判官法取得继承权的继受人，也会被强令提供担保。

<!-- source-p 594 -->
<a id="36.3.1.9"></a>**9**　当然，若某人未要求订立要式承诺便已就遗赠提起诉讼，应认可该要式承诺不再适用。

<!-- source-p 595 -->
<a id="36.3.1.10"></a>**10**　遗嘱信托也应适用同一规则。

<!-- source-p 596 -->
<a id="36.3.1.11"></a>**11**　若某人获遗赠或遗嘱信托，且规定若其丧失所获财产便再次给予他，问题是，他能否请求就后一次遗赠或遗嘱信托提供担保。这引出数个问题：该遗嘱信托或遗赠是否应给付、应给付多少次，以及受遗赠人本人是否应担保自己不会丧失该财产。关于这些问题，神圣庇乌斯皇帝曾向尤尼乌斯·毛里库斯作出如下敕答：“根据来信所述，克洛狄乌斯·费利克斯的遗嘱所留给克洛狄乌斯·弗鲁克图乌斯的遗赠或遗嘱信托均应予给付，无须其担保不会减少其中任何财产。该立遗嘱人嘱托继承人：若弗鲁克图乌斯丧失遗嘱留给他的财产，继承人应再次交给他；这一安排并非要求弗鲁克图乌斯就先前遗赠提供担保，也不是使继承人负无限责任，以致每次弗鲁克图乌斯丧失财产时都必须再次给付同等财产；而是使后一次遗嘱信托加倍于其遗赠，并且在后一次遗嘱信托给付后，弗鲁克图乌斯若再消耗其中任何财产，便不再使继承人承担风险。”因此，敕答表明，受遗赠人无须向继承人担保自己不会丧失财产。反过来，继承人是否应就后一次遗赠或遗嘱信托提供担保，则另有疑问。我认为无须向继承人提供担保，因为是否丧失留给自己的财产，取决于继承人本人的选择；不过，若有人审查附条件所留遗赠的情形，或许会认为应要求提供担保。

<!-- source-p 597 -->
<a id="36.3.1.12"></a>**12**　无论某人按全部遗产还是按份额承担遗赠义务，无论其是指定继承人还是替补继承人，都必须提供担保。

<!-- source-p 598 -->
<a id="36.3.1.13"></a>**13**　一个极有意义的问题是：该担保要式承诺是否包括孳息或利息的增加？正确的意见是，发生迟延时，要式承诺的责任应随之增加，以涵盖届时应给付的数额。

<!-- source-p 599 -->
<a id="36.3.1.14"></a>**14**　若某人就附条件遗赠订立担保要式承诺，却在条件成就前死亡，该要式承诺即告消灭，因为遗赠也不会移转给其继承人。应当知道，该担保要式承诺具有与遗赠相同的原因和条件。因此，若请求遗赠的人通常会受到某项抗辩，该抗辩也应当可以对抗依据担保要式承诺提起诉讼的人。

<!-- source-p 600 -->
<a id="36.3.1.15"></a>**15**　若继承人向声称受遗赠人缺席之人的代理人承诺，就遗赠提供担保，奥菲利乌斯说，担保应以“若其所代表之人仍在世”为条件作出，以免该人先行死亡后，继承人仍负担保责任。

<!-- source-p 601 -->
<a id="36.3.1.16"></a>**16**　还提出问题：担保要式承诺的标的是遗赠的原物，还是其价额？较为正确的意见是，原物或其价额均可纳入该担保要式承诺。

<!-- source-p 602 -->
<a id="36.3.1.17"></a>**17**　若遗嘱将箱中的十遗赠给我，又将其用益权遗赠给你，并且两项遗赠均为无条件遗赠，则取得所有权的人依法请求交付该十；关于用益权人，已确认其可依据元老院决议提起诉讼，请求五的用益权。但所有权人请求该十时，可以因用益权人已担保将五返还给继承人，而受到恶意抗辩的阻却。当然，若受遗赠人已占有这十枚金币，马尔切鲁斯说，只要有人向其提供担保，可以给予继承人或用益权人针对该受遗赠人的适法诉权。若十枚金币附条件遗赠给该受遗赠人，则用益权人暂时取得这十，但须提供担保；至于获赠所有权的人，继承人暂时应向其提供遗赠担保。马尔切鲁斯说，若其未要求订立担保要式承诺，条件成就后可提起出示之诉。若继承人不知情而将十交给用益权人，显然不能对用益权人提起出示之诉；但是，马尔切鲁斯说，应给予受遗赠人针对用益权人的救济。

<!-- source-p 603 -->
<a id="36.3.1.18"></a>**18**　若遗产份额归于国库，该担保要式承诺即不再适用，因为通常不要求国库提供担保。

<!-- source-p 604 -->
<a id="36.3.1.19"></a>**19**　某人虽为大部分遗产的继承人，却仅占有较小份额。若遗产份额依法减少，继承人的处境更为有利，因为其依据担保要式承诺对受遗赠人承担的责任，不超过其作为继承人所占的份额。若继承人身份所对应的份额仍完整存在，但实际取得的遗产份额较小，而且他已就遗赠提供担保，则其似乎承担了过重负担，因为依法应由他按继承份额给付遗赠。然而，最公平的做法是不让继承人向受遗赠人给付超过其实际取得利益的数额。若遗产的一部分依据特雷贝利亚努姆元老院决议返还，便会发生这种情形：继承人应按比例免除其责任，免除范围相当于其已丧失利益的那部分遗产。

<!-- source-p 605 -->
<a id="36.3.1.20"></a>**20**　若遗赠留给处于他人权力下之人，且到期日不确定，则应向对其行使权力之人提供担保；但担保不应无条件作出，而应附加条件：“若遗赠到期时，该人仍处于其权力之下。”反之，若该人届时已成为自权人，认为其父亲获得担保是不公平的，因为遗赠应给付给他人。即使未附加该条件而提供担保，若条件成就时该人不再处于父亲或主人的权力之下，也应以抗辩阻却父亲或主人的请求。然而，由此会出现一种情形，即遗赠可能根本未获担保：因为条件成就时若受遗赠人已成为自权人，担保便不发生效力。

<!-- source-p 615 -->
<a id="36.3.5"></a>**36.3.5**

<!-- source-p 616 -->
帕比尼安《疑问集》第二十八卷。

<!-- source-p 617 -->
<a id="36.3.5.pr."></a>**序言**　继承人被敌人俘虏后，遗赠条件成就；就此遗赠，先前已订立担保要式承诺。我答称，保证人暂时不承担责任，因为既无相应的权利关系，也没有可以适用该要式承诺措辞的人。

<!-- source-p 618 -->
<a id="36.3.5.1"></a>**1**　皇帝马尔库斯·安敦尼乌斯曾敕答尤利乌斯·巴尔布斯：被请求返还遗嘱信托之物的人提起上诉时，应提供担保；若对方提供担保，则应将占有移交给对方。皇帝正确地认定，即使上诉后也应提供遗嘱信托担保：因为在判决前，若请求权的到期日延后，本应提供担保；胜诉后不应因请求延期而丧失该项权利。但是，若提起上诉的人未就遗嘱信托提供担保，而对方已担保，皇帝为何敕答应将占有移交给对方？这与告示规定的情形不同。因为并非要求受遗赠人提供相互担保，而是为保管财物之目的，将占有临时交由其掌管；胜诉者由裁判官或行省总督引入占有。裁判官为保障遗嘱信托，可以允许受益人占有所有仍属于遗产的财物；皇帝则允许对已作出判决的财物提供相互担保。类似地，儿子取得遗产占有后，若须将其自有财产并入遗产，却不能提供担保——因为我们不准许他行使诉权——则依司法管辖规则，要求其兄弟提供担保：儿子开始并入自己的财产时，应返还其从兄弟份额中取得的财物。若兄弟们也不能提供担保，通行做法是由双方选定一名公正之人作为保管人，将孳息交其保管，并由其行使裁判官授予的适法诉权。根据前述敕答，只有请求遗嘱信托的人提供担保后，占有才会移交给他；即使对方并非因无力而是因抗命拒绝提供担保，也同样如此。但若胜诉者无力提供担保，则应将财物提存，或恢复原有的司法管辖状态。

<!-- source-p 619 -->
<a id="36.3.5.2"></a>**2**　若有人声称遗赠或遗嘱信托的到期日或条件会推迟请求权或诉权，因此请求提供担保；而继承人则以对方恶意为由，主张遗嘱中并无该项处分，则只有在请求提供担保者出示能证明遗赠确已作出的书面文件后，才应听取其请求。

<!-- source-p 620 -->
<a id="36.3.5.3"></a>**3**　有人询问，应在何处为保障遗嘱信托而提供担保。皇帝提图斯·安敦尼乌斯敕答：若继承人不在罗马设有住所，且遗产全部位于行省，则遗嘱信托受益人应前往行省请求提供担保。因此，若继承人请求在其住所地提供担保，而受遗赠人要求在遗产所在地提供担保，则不得要求继承人前往受遗赠人指定的地点。皇帝提图斯·安敦尼乌斯也曾作出这样的敕答。

<!-- source-p 621 -->
<a id="36.3.5.4"></a>**4**　敕答还补充说，即使财产已依立遗嘱人许可或受遗赠人同意而出售，出售所得也应提存，以保障遗嘱信托的履行。

<a id="36.3.15.pr."></a>**序言**　即使遗赠应立即给付，也适用这项担保义务，因为行使诉讼权仍可能遭遇延误。

<!-- source-p 654 -->
<a id="36.3.15.1"></a>**1**　若受遗赠人既从指定继承人处，也从依据特雷贝利亚努姆元老院决议返还遗产的遗嘱信托受益人处取得遗赠担保，两项担保要式承诺都会发生效力；但继承人可以援引抗辩，因为他本不应提供担保。若遗产仅返还了一部分，则双方都应提供担保。

<!-- source-p 655 -->
<a id="36.3.15.2"></a>**2**　即使遗嘱信托应由无遗嘱继承人给付，也适用这项担保要式承诺。

<!-- source-p 656 -->
<a id="36.3.16"></a>**36.3.16**

<!-- source-p 657 -->
盖尤斯《行省告示评注》第二十七卷。

<!-- source-p 658 -->
若两名同名之人就遗赠发生争议，应向两人分别提供担保。继承人不会因此负担过重，因为他可以在两项担保要式承诺中使用同一批保证人；保证人也不会负担过重，因为最终只需对其中一人承担责任。

<!-- source-p 659 -->
<a id="36.3.17"></a>**36.3.17**

<!-- source-p 660 -->
保罗《告示评注》第四十八卷。

<!-- source-p 661 -->
若遗赠由所有继承人共同承担，我却只从其中一名继承人处取得遗赠担保；其共同继承人的份额若归并给该承诺人，而他因此开始负有给付全部遗赠的义务，保证人便应对全部债务承担责任。

<!-- source-p 662 -->
<a id="36.3.18"></a>**36.3.18**

<!-- source-p 663 -->
斯凯沃拉《学说汇纂》第二十九卷。

<!-- source-p 664 -->
<a id="36.3.18.pr."></a>**序言**　一名女子留下婚生儿子，指定自己的父亲（也是她的共同获释者）为全部遗产的继承人，并嘱托他在自己死亡时，将从其遗产中取得的一切返还给该女子的儿子，即自己的外孙。她还加上如下措辞：“我禁止向我的父亲塞伊乌斯要求担保。”塞伊乌斯正在挥霍财产，遗嘱信托受益人的父亲担心遗嘱信托将落空，便询问能否强令死者的父亲就遗嘱信托提供担保。答称：依所述情形，不应强令其提供担保。

<!-- source-p 665 -->
<a id="36.3.18.1"></a>**1**　同一人还询问：立遗嘱人曾将财物寄存在丈夫处，未要求其提供保管担保；该财物是否应返还给父亲继承人？还是因为全部遗产的利益最终应归于死者之子，且嫁资仍留在丈夫处，该财物也应留在丈夫处？答称：凡属于该女子所有、且不属于嫁资的财物，均应返还给继承人。

<!-- source-p 666 -->
<a id="36.3.18.2"></a>**2**　一名监护人同时也是未成年人的共同继承人；未成年人不在场时，受遗赠人提醒监护人后，监护人以自己的名义就全部遗产提供了遗嘱信托担保。问题是，未成年人成年后能否取得适法诉权？答称：应当授予该诉权。
