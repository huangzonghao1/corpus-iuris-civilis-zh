## D.47.2　论盗窃（*De furtis*）（续）

<!-- source-p 250 -->
<a id="47.2.46.9"></a>9. 如果被盗物已经返还给所有人，之后又再次遭到窃取，则可以提起另一项盗窃之诉。

<!-- source-p 251 -->
<a id="47.2.47"></a>47.2.47

<!-- source-p 252 -->
保罗《萨宾评注》第九卷

<!-- source-p 253 -->
如果被盗物的所有权因任何原因发生变更，例如因继承、取得遗产占有、收养父亲或受遗赠人而变更，则所有人享有盗窃之诉。

<!-- source-p 254 -->
<a id="47.2.48"></a>47.2.48

<!-- source-p 255 -->
乌尔比安《萨宾评注》第四十二卷

<!-- source-p 256 -->
<a id="47.2.48.pr."></a>序　某人遗失了一只银器，并因此提起盗窃之诉。双方对银器的重量发生争议，原告称银器原本更重；窃贼于是拿出银器，原所有人将其取回。窃贼仍被判处双倍额。判决极为正确：因为在罚金之诉中，不把被盗的物本身计算在内；无论提起的是现行盗窃之诉还是非现行盗窃之诉，都是如此。

<!-- source-p 257 -->
<a id="47.2.48.1"></a>1. 知道窃贼是谁的人，无论是否告发他，都不是窃贼；因为窝藏窃贼与不告发窃贼大有区别。知道其身份的人不因盗窃承担责任；窝藏他的人则仅因窝藏这一行为而承担责任。

<!-- source-p 258 -->
<a id="47.2.48.2"></a>2. 某人经所有人同意而接收奴隶，显然既非窃贼，也非拐卖人口者：得到所有人同意的人，怎么可能被称为窃贼呢？

<!-- source-p 259 -->
<a id="47.2.48.3"></a>3. 但是，如果所有人禁止而此人仍接收奴隶，若其并无窝藏的意图，就不是窃贼；若他加以窝藏，此时才开始成为窃贼。因此，即使违背所有人意愿而接收奴隶，只要没有窝藏，就不是窃贼。我们所说的所有人“禁止”，也包括所有人并不知情的情形，即其未表示同意。

<!-- source-p 260 -->
<a id="47.2.48.4"></a>4. 假如我委托你修整衣服，你却在我不知情或不同意的情况下把衣服借给提图斯，而衣服在提图斯处被盗：你可以提起盗窃之诉，因为该物的保管责任属于你；我也可以对你提起诉讼，因为你本不应把东西借出，你这样做即构成盗窃。由此便出现了窃贼可以提起盗窃之诉的情形。

<!-- source-p 261 -->
<a id="47.2.48.5"></a>5. 怀孕的女奴如果遭到窃取，或者在窃贼处受孕，其子女属于被盗物；无论在窃贼处出生，还是在善意占有人处出生，均是如此。不过在后一种情形，盗窃之诉不再成立。相反，如果她在善意占有人处受孕并在那里分娩，就会出现子女不属于被盗物、甚至可以因时效取得的结果。牲畜及其所生幼畜，也应依照关于女奴所生子女的规则处理。

<!-- source-p 262 -->
<a id="47.2.48.6"></a>6. 被盗马匹所生的幼马，立即归善意买受人所有，这是适当的，因为幼马被算作孳息；而女奴所生子女则不算作孳息。

<!-- source-p 263 -->
<a id="47.2.48.7"></a>7. 窃贼出售被盗物后，物主以暴力夺取了窃贼收到的价款；对此，正确的答复是：物主窃取了这些钱。他也将依强夺财物之诉承担责任。由被盗物变现所得之物显然不属于被盗物；因此，这笔由被盗物价款转化而来的钱，并非被盗物。

<!-- source-p 264 -->
<a id="47.2.49"></a>47.2.49

<!-- source-p 265 -->
盖尤斯《行省告示评注》第十卷

<!-- source-p 266 -->
<a id="47.2.49.pr."></a>序　有时，某人虽有利益使该物得以保全，却并不享有盗窃之诉。例如，债务人的物品被盗，债权人不能提起盗窃之诉，即使他无法从其他财产中实现债权也是如此。当然，我们说的是该物并未依质权而负担债务的情形。

<!-- source-p 267 -->
<a id="47.2.49.1"></a>1. 同样，对于风险由妻子承担的嫁资物，享有盗窃之诉的不是妻子，而是丈夫。

<!-- source-p 268 -->
<a id="47.2.50"></a>47.2.50

<!-- source-p 269 -->
乌尔比安《告示评注》第三十七卷

<!-- source-p 270 -->
<a id="47.2.50.pr."></a>序　在盗窃之诉中，双倍或四倍计算的不是利害关系额，而是该物的真实价值。即使在作出判决时该物已不复存在，仍应判令被告承担相应金额。同样，如果该物现已贬值，应以盗窃发生时为估价基准。若该物后来升值，则应按其升值后当时的价值判处双倍额，因为可以更准确地说，盗窃是在该物升值时发生的。

<!-- source-p 271 -->
<a id="47.2.50.1"></a>1. 切尔苏斯说，以帮助或建议方式实施盗窃，不仅包括为了让同伙行窃而实施的情形，也包括并非为了让同伙行窃、但出于敌意而实施的情形。

<!-- source-p 272 -->
<a id="47.2.50.2"></a>2. 佩迪乌斯正确指出：正如无人能在没有恶意的情况下实施盗窃，也无人能在没有恶意的情况下提供建议或帮助。

<!-- source-p 273 -->
<a id="47.2.50.3"></a>3. 劝说、怂恿并出谋划策促成盗窃的人，被认为是提供建议者；为窃取财物提供劳务或协助的人，则是提供帮助者。

<!-- source-p 274 -->
<a id="47.2.50.4"></a>4. 某人展示红布并驱赶牲畜，使牲畜冲入窃贼之中：如果他是出于恶意而为，可以对他提起盗窃之诉。即使他并非为了促成盗窃，也不应让这种极其有害的恶作剧不受惩罚；因此，拉贝奥写道，应给予事实之诉。

<!-- source-p 275 -->
<a id="47.2.51"></a>47.2.51

<!-- source-p 276 -->
盖尤斯《行省告示评注》第十三卷

<!-- source-p 277 -->
如果牲畜因此坠落受损，也应给予类似于《阿奎利亚法》之诉的适用之诉，以追究不法损害。

<!-- source-p 278 -->
<a id="47.2.52"></a>47.2.52

<!-- source-p 279 -->
乌尔比安《告示评注》第三十七卷

<!-- source-p 280 -->
<a id="47.2.52.pr."></a>序　某人若帮助或出谋划策，使妻子窃取丈夫的物品，应承担盗窃责任。

<!-- source-p 281 -->
<a id="47.2.52.1"></a>1. 他若与妻子共同实施盗窃，也应承担盗窃责任，尽管妻子本人不承担该责任。

<!-- source-p 282 -->
<a id="47.2.52.2"></a>2. 妻子本人若帮助窃贼，不承担盗窃责任，而应依取走财物之诉承担责任。

<!-- source-p 283 -->
<a id="47.2.52.3"></a>3. 毫无疑问，妻子仍须就其奴隶实施的盗窃承担责任。

<!-- source-p 284 -->
<a id="47.2.52.4"></a>4. 家子军人也应适用同一规则：他本人不因盗窃而对父亲承担责任；但如果其奴隶窃取父亲的物品，他应就该奴隶承担军营特有产范围内的责任。

<!-- source-p 285 -->
<a id="47.2.52.5"></a>5. 如果我的儿子有军营特有产而窃取我的物品，我是否可以对他提起适用之诉，尚须考察，因为他有财产可以清偿。我认为可以起诉。

<!-- source-p 286 -->
<a id="47.2.52.6"></a>6. 再看父亲若窃取儿子军营特有产中的物品，是否应对儿子承担责任。我认为应当承担。因此，他不仅是对儿子实施了盗窃，也应依盗窃之诉承担责任。

<!-- source-p 287 -->
<a id="47.2.52.7"></a>7. 梅拉说，债权人在债务清偿后仍不返还质物的，如果是出于窝藏的意图而扣留，应承担盗窃责任；我认为这是真确的。

<!-- source-p 288 -->
<a id="47.2.52.8"></a>8. 如果土地上有硫磺矿，有人从中挖出并取走矿土，所有人可以提起盗窃之诉；随后承租人可以通过租赁之诉，请求将该物本身交付给自己。

<!-- source-p 289 -->
<a id="47.2.52.9"></a>9. 如果你的奴隶或儿子接收衣物进行修整，问题是你是否享有盗窃之诉。如果该奴隶的特有产足以清偿，你可以提起盗窃之诉；如果不足以清偿，则应说你不享有该诉。

<!-- source-p 290 -->
<a id="47.2.52.10"></a>10. 即使某人不知情而买下被盗物，之后该物又被盗，他也享有盗窃之诉。

<!-- source-p 291 -->
<a id="47.2.52.11"></a>11. 拉贝奥记载：某人对卖谷者说，无论何人以他的名义来领取谷物，都交给那人；一个路人听见后，便以该人的名义请求并领走谷物。对这个路人，享有盗窃之诉的是卖谷者，而不是我；因为卖谷者是为自己办事，并非为我办事。

<!-- source-p 292 -->
<a id="47.2.52.12"></a>12. 有人把我的逃奴冒充为自己的奴隶，带到二人官或其他有权者面前，使其从监狱或拘禁处获释，该人是否承担盗窃责任？通说认为：如果他提供了保证人，所有人应对保证人提起诉讼，使保证人把自己的诉权让与我；如果未接受保证人，而是把奴隶交给冒充所有人的人，则所有人可以对该拐卖者提起盗窃之诉。

<!-- source-p 293 -->
<a id="47.2.52.13"></a>13. 某人从他人手中击落金币、银币或其他物品，只有在其意图是让另一个人拾取且该人确已拾取时，才承担盗窃责任。

<!-- source-p 294 -->
<a id="47.2.52.14"></a>14. 有人窃取我的银锭并将其制成杯子，我可以就杯子或银锭提起盗窃之诉，也可以提起返还之诉。葡萄、葡萄汁及葡萄渣也同样如此：我可以就葡萄、葡萄汁及葡萄渣的名义提起盗窃之诉，也可以提起返还之诉。

<!-- source-p 295 -->
<a id="47.2.52.15"></a>15. 奴隶谎称自己是自由人，以便使他人向自己出借钱款，并不构成盗窃；因为他不过是声称自己是有偿债能力的债务人。一个家子冒充家父，以便更容易借到钱，也适用同一规则。

<!-- source-p 296 -->
<a id="47.2.52.16"></a>16. 尤利安在《学说汇纂》第二十二卷中写道：某人从我这里收到钱，受托用来偿还我的债权人；但他自己也欠同一债权人等额债务，随后却以自己的名义偿还了债务，该人构成盗窃。

<!-- source-p 297 -->
<a id="47.2.52.17"></a>17. 提提乌斯出售他人之物并从买受人处收取钱款，不被认为窃取了这些钱。

<!-- source-p 298 -->
<a id="47.2.52.18"></a>18. 两名合伙人组成全部财产合伙，其中一人取得某物作为质物，而该物后来被盗。梅拉写道，只有取得质物的合伙人享有盗窃之诉，另一合伙人不享有。

<!-- source-p 299 -->
<a id="47.2.52.19"></a>19. 任何人都不会仅凭言语或书写实施盗窃；我们适用的法律规则是，没有对物的实际触取就不构成盗窃。因此，提供帮助或建议只有在随后发生实际触取时才会产生责任。

<!-- source-p 300 -->
<a id="47.2.52.20"></a>20. 某人驱赶我的驴，只是为了让它与自己的母马交配（*tys gonys dumtaxat xarin*），如果没有盗窃的意图，就不承担盗窃责任。我也曾就此答复我在达尔马提亚的学生赫伦尼乌斯·莫德斯提努斯所提出的咨询：据称，有人为了同样目的将自己的母马放到他的马匹旁边；只有在其出于盗窃故意时，才依盗窃之诉承担责任；否则，应提起事实之诉。

<!-- source-p 301 -->
<a id="47.2.52.21"></a>21. 我想把钱借给品行端正的提提乌斯，你却把另一个贫穷的提提乌斯冒充为富人介绍给我，并与他瓜分收到的钱款。你应承担盗窃责任，因为盗窃是借助你的帮助和建议实施的；提提乌斯也应承担盗窃责任。

<!-- source-p 302 -->
<a id="47.2.52.22"></a>22. 某人借给你较重的砝码，而你按重量购买货物。梅拉写道，他对卖方承担盗窃责任；如果你知情，你也承担责任。因为卖方在称重上发生错误时，你并非依卖方的真实意思取得货物。〔底本此处有方括号标记及文字疑误：*nam [] non [enim]*。〕

<!-- source-p 303 -->
<a id="47.2.52.23"></a>23. 某人劝说我的奴隶从一份文书——例如买卖文书——中删去自己的姓名，梅拉写道，我也认为可以提起盗窃之诉。

<!-- source-p 304 -->
<a id="47.2.52.24"></a>24. 但如果有人劝说奴隶抄录我的文书，我认为：若是劝说奴隶实施此事，应提起腐蚀奴隶之诉；若劝说者亲自实施，则应给予欺诈之诉。

<!-- source-p 305 -->
<a id="47.2.52.25"></a>25. 如果一串珍珠被盗，应说明其颗数。就葡萄酒提起盗窃之诉时，也必须说明被盗的酒坛数量。器皿被盗的，同样应说明数量。

<!-- source-p 306 -->
<a id="47.2.52.26"></a>26. 我的奴隶有权自由管理其特有产；若他并非以赠与为目的，与窃取其特有产物品的人达成和解，该和解应被认为有效。尽管盗窃之诉归属于所有人，但有关利益属于奴隶的特有产。即使盗窃罚金的全部双倍额已付给奴隶，窃贼也无疑因此免责。同理，如果奴隶从窃贼处收取了其认为足以弥补该物的数额，也应认为和解有效。

<!-- source-p 307 -->
<a id="47.2.52.27"></a>27. 某人宣誓称自己未实施盗窃，之后却实际触取被盗物，盗窃之诉虽因此消灭，所有人仍保有对该物的追索权。

<!-- source-p 308 -->
<a id="47.2.52.28"></a>28. 被盗奴隶若被指定为继承人，原告可以通过盗窃诉讼取得遗产价值，但须该奴隶在奉所有人之命接受继承以前死亡。通过返还之诉，原告也可以取得同一价值。

<!-- source-p 309 -->
<a id="47.2.52.29"></a>29. 如果受解放条件拘束的奴隶或附条件遗赠之物被盗，而在遗产被接受以前条件成就，就不能再提起盗窃之诉，因为继承人已不再有利害关系；条件尚未成就时，则应按该物可能找到买受人的价格估价。

<!-- source-p 310 -->
<a id="47.2.53"></a>47.2.53（52.30）

<!-- source-p 311 -->
乌尔比安《告示评注》第三十八卷

<!-- source-p 312 -->
某人从一间无人的房屋中抢走财物，应依强夺财物之诉被判处四倍额；如果无人当场发现他正在拿取，则依非现行盗窃之诉承担责任。

<!-- source-p 313 -->
<a id="47.2.54"></a>47.2.54（53）

<!-- source-p 314 -->
保罗《告示评注》第三十九卷

<!-- source-p 315 -->
<a id="47.2.54.pr."></a>序　某人出于侵害他人的意图砸开大门，尽管财物随后由他人取走，他也不承担盗窃责任；因为区分各种不法行为的是行为人的意愿和目的。

<!-- source-p 316 -->
<a id="47.2.54.1"></a>1. 借用人的奴隶窃取物品，而遭窃者具有清偿能力时，萨宾认为，可以对借用人提起借用之诉，并以奴隶之名对其主人提起盗窃之诉；但如果主人返还了其追索的钱款，盗窃之诉即消灭；主人免除借用之诉时，也同样如此。

<!-- source-p 317 -->
<a id="47.2.54.2"></a>2. 如果你的奴隶窃取了借给你的物品，不能对你提起盗窃之诉，因为该物的风险由你承担；只能提起借用之诉。

<!-- source-p 318 -->
<a id="47.2.54.3"></a>3. 自愿承担他人事务管理的人，即使因其过失导致物品灭失，也不享有盗窃之诉；但在事务管理之诉中，只有所有人将其诉权让与他时，才应判令其承担责任。为监护人管理事务的人、负有注意义务的监护人，以及数名遗嘱指定的监护人中，在提供担保后独自承担管理事务的监护人，均适用同一规则。

<!-- source-p 319 -->
<a id="47.2.54.4"></a>4. 如果你基于他人的赠与而占有我的物品，而我把该物品窃走，尤利安说，只有在你有利益保有占有时，才可以对我提起盗窃之诉；例如，你曾在针对受赠奴隶提起的私犯诉讼中为其辩护，或者曾照料患病的奴隶，以致你对主张该物的人享有正当留置权。

<!-- source-p 320 -->
<a id="47.2.55"></a>47.2.55（54）

<!-- source-p 321 -->
盖尤斯《行省告示评注》第十三卷

<!-- source-p 322 -->
<a id="47.2.55.pr."></a>序　债权人若使用质押物，应承担盗窃责任。

<!-- source-p 323 -->
<a id="47.2.55.1"></a>1. 有答复认为，某人把获准使用的物品又借给他人，应承担盗窃责任。由此足以看出，即使只是把他人之物的使用转为自己的利益，也会构成盗窃。无人应以为此人并未为自己谋取利益而感到疑惑：把他人之物转赠他人并使自己成为受惠者，正是一种利益。因此，为了把物品赠给他人而将其取走的人，也承担盗窃责任。

<!-- source-p 324 -->
<a id="47.2.55.2"></a>2. 《十二表法》规定，只有在白天被发现的窃贼以武器自卫时，才可以将其杀死。所谓“武器”，包括刀剑、棍棒、石块，以及一切被用作伤害他人的物品。

<!-- source-p 325 -->
<a id="47.2.55.3"></a>3. 盗窃之诉旨在追究罚金，而返还之诉与所有物返还诉旨在取回物品。因此，物品已经返还时，盗窃之诉仍然保留，但所有物返还诉与返还之诉消灭；反过来说，双倍或四倍罚金已经支付后，所有物返还诉与返还之诉仍然保留。

<!-- source-p 326 -->
<a id="47.2.55.4"></a>4. 某人明知而借出工具供人砸开门或柜子，或者明知而借出梯子供人攀爬，即使他并未直接参与策划盗窃，仍应依盗窃之诉承担责任。

<!-- source-p 327 -->
<a id="47.2.55.5"></a>5. 管理事务的监护人或保佐人与窃贼达成和解的，盗窃之诉即消灭。

<!-- source-p 332 -->

<!-- source-p 333 -->
<a id="47.2.57.pr."></a>序　有时，尽管窃贼仍负有罚金责任，在某些情形下又会再次负担责任，以致同一人可以就同一物反复对他提起盗窃之诉。第一种情形是占有原因发生变更，例如物品回到所有人控制之下后，同一窃贼再次窃取该物，无论是从所有人处，还是从所有人借出或卖给的人处窃取。即使只是所有人发生变更，也会产生另一项罚金责任。

<!-- source-p 334 -->
<a id="47.2.57.1"></a>1. 某人把窃贼带到警备长官或行省总督面前，应认为他选择了追索该物的途径。如果在那里案件已经终结，窃贼被判刑且交还了所取财物的单倍额，可以认为盗窃案件的追诉已告终，尤其是法官命窃贼返还被盗物以外，还对他作出其他裁判时。即使法官只命其返还被盗物，仅凭窃贼已被置于可能受到更重处罚的风险之中，也应认为盗窃案件的追诉已经终结。

<!-- source-p 335 -->
<a id="47.2.57.2"></a>2. 被盗的特有产物品如果回到奴隶的控制之下，盗窃瑕疵即告消除；在这种情况下，该物重新成为特有产的一部分，并由主人占有。

<!-- source-p 336 -->
<a id="47.2.57.3"></a>3. 奴隶意图盗窃而取走属于自己特有产的物品，只要仍由他占有，其法律地位就不改变（因为主人并未因此遭受损失）；但若他把物品交给他人，就构成盗窃。

<!-- source-p 337 -->
<a id="47.2.57.4"></a>4. 管理监护事务的人可以与窃贼和解；如果他将被盗物收归自己控制，该物便不再是被盗物，因为监护人被视同所有人。对于精神障碍者的保佐人，也应作相同处理；他如此代表所有人，以致即便把精神障碍者的物品交付他人，也被认为能够使其所有权发生转移。监护人以及精神障碍者的保佐人，也可以代表被监护人或被保佐人提起返还之诉。

<!-- source-p 338 -->
<a id="47.2.57.5"></a>5. 你的两名奴隶窃取了衣物和银器；你以其中一名奴隶之名就衣物被起诉，又以另一名奴隶之名就银器被起诉。不得以已经就衣物提起过诉讼为由，给予抗辩。

<!-- source-p 351 -->
<a id="47.2.62"></a>47.2.62（62）

<!-- source-p 352 -->
阿非利加努斯《疑问集》第八卷

<!-- source-p 353 -->
<a id="47.2.62.pr."></a>序　共有奴隶若对其一名共有人实施盗窃，通说认为应提起共有物分割之诉，并由法官裁量命其赔偿损失，或让出自己在共有奴隶中的份额。由此似可推知，即使他转让了自己的份额，也可以同样对买受人起诉，仿佛私犯责任随奴隶转移。不过，阿非利加努斯说，此规则不应扩张到这样的程度：即使奴隶已获自由，也认为可以对其本人起诉，正如他原本就是该共有人单独所有的奴隶时也不能对其起诉一样。由此可见，奴隶死亡后，原告不能再就此向他人取得任何利益；但若有人从被盗物中取得利益，则属例外。

<!-- source-p 354 -->
<a id="47.2.62.1"></a>1. 他还说，由此也可推知：你把一名奴隶交给我作质押，而该奴隶窃取我的物品时，我可以通过反向质押之诉请求法官作出裁判，使其赔偿损失，或让我取得该奴隶作为代偿。

<!-- source-p 355 -->
<a id="47.2.62.2"></a>2. 对于因解除买卖而应返还的奴隶，也应作同样处理：正如买受人必须返还附属物及孳息，卖方反过来也应被迫赔偿损失，或交出奴隶作为私犯责任的代偿。

<!-- source-p 356 -->
<a id="47.2.62.3"></a>3. 不过，这些情形另有一点：如果某人明知对方不知情，仍把窃贼奴隶作为质物交付，就必须在任何情况下赔偿损失；这符合诚信原则。

<!-- source-p 357 -->
<a id="47.2.62.4"></a>4. 至于买卖之诉，应尤其考察卖方曾对奴隶的品质作出何种保证。

<!-- source-p 358 -->
<a id="47.2.62.5"></a>5. 关于委任之诉，阿非利加努斯说，他不确定是否也应在任何情况下都赔偿损失；但他认为，该规则甚至应比上述情形适用得更广：即使委托他购买特定奴隶的人不知道该奴隶是窃贼，也仍应被迫赔偿损失。代理人完全可以正当地主张：如果没有接受该委任，自己就不会遭受这项损失。在寄托关系中，这一点尤其明显。虽然通常认为任何人所遭受的损失不应超过该奴隶本身的价值，但更公平的是，不应使任何人为履行其所承担的事务而遭受损失，尤其是该事务并非为了自己的利益而承担的。正如前述，买卖、租赁和质押等契约中，明知而隐瞒事实者的欺诈应受惩罚；在这些关系中，因事务委托方的过失造成的损失，应由委托方自己承担。委托方确有过失，因为他委托购买这样的奴隶；寄托人也同样有过失，因为他在寄托这样的奴隶时没有更加谨慎地作出说明。

<!-- source-p 359 -->
<a id="47.2.62.6"></a>6. 至于借用关系，理应采取不同的看法，因为只有请求借用的人从中获益。因此，出借人如同出租人一样，若有欺诈行为，其损失不应超过奴隶的价值。甚至对于欺诈的解释，我们也应从宽，因为如前所述，出借人并未从借用关系中获益。

<!-- source-p 360 -->
<a id="47.2.62.7"></a>7. 我认为，只有在接受委任或寄托的人自身并无过失时，上述意见才是正确的；否则，如果他主动委托此人保管银器或钱币，而所有人平时本来从不作这种托付，就应作不同处理。

<!-- source-p 361 -->
<a id="47.2.62.8"></a>8. 我把土地出租给你；通常双方会约定，为担保租金，土地上的孳息质押给我。他说，如果你秘密运走这些孳息，我可以对你提起盗窃之诉。即使你把尚未收获的孳息卖给他人，而由买受人运走，也应认为这些孳息转为被盗物。因为孳息只要仍附着于土地，就属于土地；承租人似乎是经所有人同意收取孳息，因而可以取得孳息的所有权。但在题述情形中则不能如此说：买受人以自己的名义收取孳息，承租人又怎能因此取得其所有权呢？

<!-- source-p 362 -->
<a id="47.2.62.9"></a>9. 某受解放条件拘束的奴隶被命令支付十枚钱后即可获得自由；继承人以私犯诉讼为其辩护。诉讼进行期间，该奴隶向继承人支付十枚钱而取得自由。问题是，是否只有继承人把收到的十枚钱交给原告，才能作出免责判决。阿非利加努斯认为，应取决于这笔钱的来源：如果钱来自特有产以外，继承人至少应将其交付，因为若该奴隶尚未获得自由，他在被判交付作为代偿时本会把这笔钱给付受领人；如果钱来自特有产，则因奴隶交付的是继承人的钱——继承人当然不会允许他把自己的钱交给受领人——所以应作相反的处理。

<a id="47.2.67.pr."></a>序　设质人若出售质物，即使他仍是所有人，也构成盗窃；无论他曾把质物交给债权人，还是仅以特别约定使该物负担质权，均是如此。尤利安也持此见解。

<!-- source-p 378 -->
<a id="47.2.67.1"></a>1. 某人被窃取的物品仍在窃贼处时，将该物遗赠给我；窃贼后来又实际触取该物，我是否享有盗窃之诉？按照奥克塔维努斯的意见，只有我享有该诉，继承人本人不享有；因为众所周知，无论所有权因何种原因发生变更，盗窃之诉均归属于所有人。

<!-- source-p 379 -->
<a id="47.2.67.2"></a>2. 古代法学家曾答复：某人出于恶意把骡夫传唤至法庭，如果在此期间骡子死亡，他应承担盗窃责任。

<!-- source-p 380 -->
<a id="47.2.67.3"></a>3. 尤利安答复说，受命追收钱款的人若在获释后仍继续追收，应承担盗窃责任。由此也应得出结论：对已达适婚年龄的人，若监护人是在其成年后才收到清偿，也应适用同一规则。

<!-- source-p 381 -->
<a id="47.2.67.4"></a>4. 你把提提乌斯介绍给我，称他是值得信赖的人，可以向他放贷；我对提提乌斯作了调查，之后你却另带一人来冒充提提乌斯。你构成盗窃，因为我相信此人就是提提乌斯；当然，前提是被带来的人也知情。若他不知情，你不构成盗窃；而由于盗窃并未发生，也不能认为带他来的人提供了帮助，但应对带他来的人给予事实之诉。

<!-- source-p 382 -->
<a id="47.2.67.5"></a>5. 假如我向你要式口约：“你须保证，不会因你的行为而使那名奴隶未能在该日历月前交付给我。”即使该奴隶被窃取会使我遭受损失（若奴隶被窃而非因你的行为导致未能交付，你不因要式口约承担责任），我仍不享有盗窃之诉。

<a id="47.2.68.pr."></a>序　否认受托寄存物的存在，并不构成盗窃（因为单纯否认本身不是盗窃，尽管与盗窃十分接近）；但若为侵夺该物而取得其占有，就构成盗窃。无论受托保管的戒指戴在手指上，还是放在首饰盒中，只要保管人意图把它据为己有，都是如此。

<!-- source-p 386 -->
<a id="47.2.68.1"></a>1. 如果有人窃取你的物品，导致你因未能在约定日期前交付而必须支付罚金，该损失也应计入盗窃之诉的估价。

<!-- source-p 387 -->
<a id="47.2.68.2"></a>2. 一个婴儿奴隶在窃贼处长大；窃贼既窃取了婴儿时期的奴隶，也窃取了他成年后的奴隶；但仍只构成一次盗窃。因此，窃贼应按该奴隶在其处价值最高时的价值承担双倍额。至于只能对他提起一次盗窃之诉，这与所讨论的问题何干？假如该奴隶后来被另一窃贼从窃贼手中窃走，而第一个窃贼又把他夺回，即便他实施了两次盗窃，也仍只能对其提起一次盗窃之诉。我毫不怀疑，估价应以奴隶成年后的价值为准。认为盗窃行为持续存在反而使窃贼处境更有利，还有什么比这更荒谬的呢？

<!-- source-p 388 -->
<a id="47.2.68.3"></a>3. 奴隶未被买受人接受时，买受人不能因该奴隶在买卖后、返还前窃取物品而对卖方提起盗窃之诉。

<!-- source-p 389 -->
<a id="47.2.68.4"></a>4. 通说认为，若被盗的奴隶窃取了窃贼本人的物品，窃贼可以奴隶之名对奴隶主人提起诉讼；否则，这类奴隶的恶行不仅使其本人免受惩罚，也会使其主人获利，因为这类奴隶实施的盗窃往往增加他们自己的特有产。

<!-- source-p 390 -->
<a id="47.2.68.5"></a>5. 承租人在租赁期满后又多收了一年的孳息，且未经所有人同意，是否可以对其提起盗窃之诉，应予考察。我认为毫无疑问，即使窃贼已经耗用了被盗物，所有人仍可向其请求返还。

森普罗尼娅拟好几份文书，原打算交给百夫长，再由其转送机关，但实际上并未交出。卢基乌斯在法庭席上宣读这些文书，声称它们已经送交机关；然而，这些文书既未在机关中找到，也未交给百夫长。我询问：擅自从宅中取走文书并在法庭席上宣读、而这些文书原本未曾交出的，构成何种罪？莫德斯提努斯答复：如果他是秘密取走文书，就构成盗窃。

<!-- source-p 407 -->
<a id="47.2.74"></a>47.2.74（73）

<!-- source-p 408 -->
雅沃勒努斯《卡西乌斯论著》第十五卷

<!-- source-p 409 -->
接受质物的人在双方未约定出售质物的情况下将其出售，或者在出售期限届至前、债务尚未清偿时出售质物，均须承担盗窃责任。

<!-- source-p 410 -->
<a id="47.2.75"></a>47.2.75（74）

<!-- source-p 411 -->
雅沃勒努斯《书信》第四卷

<!-- source-p 412 -->
我以善意买受人的身份，用两枚金币买下一名被盗女奴并占有她；阿提乌斯又从我这里窃走她。我和所有人都对阿提乌斯提起盗窃之诉。我询问应如何分别估价。答复是：对买受人，应按其利害关系额的双倍估价；对所有人，则按该女奴价值的双倍估价。不得因盗窃罚金须向两人支付而感到疑惑；虽然罚金针对同一物支付，但向买受人支付，是基于其占有利益；向所有人支付，则是基于其所有权。

<!-- source-p 413 -->
<a id="47.2.76"></a>47.2.76（75）

<!-- source-p 414 -->

<!-- source-p 415 -->
某人冒充代理人，使我向他本人或他指定的人作出要式口约，我不能对其提起盗窃之诉，因为并未发生任何可由其出于盗窃意图而实际触取的有体物。

<!-- source-p 416 -->
<a id="47.2.77"></a>47.2.77（76）

<!-- source-p 417 -->
庞波尼乌斯《致昆图斯·穆基乌斯》第三十八卷

<!-- source-p 418 -->
<a id="47.2.77.pr."></a>序　获准借用或受托保管某物的人，若以不同于约定或受托时的方式使用该物，而认为自己这样做并未违背所有人意愿，则不承担盗窃责任，也绝不承担寄托责任。至于是否承担借用责任，应依据其过失程度判断，也就是看他是否不应认为所有人会允许这种使用。

<!-- source-p 419 -->
<a id="47.2.77.1"></a>1. 某人窃取他人之物，之后又有人从他手中窃走该物；所有人可以对后一个窃贼提起盗窃之诉，第一个窃贼则不能起诉，因为该物是否安全关乎所有人而非先前窃贼的利益。昆图斯·穆基乌斯记载了这一意见，我认为是正确的。虽然窃贼也有利害关系，因为他负有返还之诉责任，但只有基于正当原因享有利害关系的人，才能提起盗窃之诉。我们不采纳塞尔维乌斯的意见；他认为，如果被盗物没有、也不可能有所有人，窃贼就可以提起盗窃之诉。即便如此，也不能认为该物属于可能从中获利的人。因此，所有人可以分别对两名窃贼提起盗窃之诉；即使已经开始对其中一人提起诉讼，对另一人的诉权仍然保留。所有人也可以提起返还之诉，因为两名窃贼分别基于不同的行为承担责任。

<!-- source-p 420 -->
<a id="47.2.78"></a>47.2.78（77）

<!-- source-p 421 -->
庞波尼乌斯《杂录》第十三卷

<!-- source-p 422 -->
窃取装有钱款的钱袋的人，即使没有窃取钱袋的意图，也因钱袋承担盗窃责任。

<!-- source-p 423 -->
<a id="47.2.79"></a>47.2.79（78）

<!-- source-p 424 -->
帕比尼安《疑问集》第八卷

<!-- source-p 425 -->
某人交付物品供他人查验；若该物的风险由受领人承担，则受领人本人可以提起盗窃之诉。

<!-- source-p 426 -->
<a id="47.2.80"></a>47.2.80（79）

<!-- source-p 427 -->
帕比尼安《疑问集》第九卷

<!-- source-p 428 -->
债务人若窃取质物，依盗窃之诉已经给付的款项，不能以任何方式取回。

<!-- source-p 429 -->
<a id="47.2.81"></a>47.2.81（80）

<!-- source-p 430 -->
帕比尼安《疑问集》第十二卷

<!-- source-p 431 -->
<a id="47.2.81.pr."></a>序　我已经出售奴隶，但尚未交付；若该奴隶并非因我的过错而被盗，更有理由认为我享有盗窃之诉。因为所有权仍在我，或者我负有提供诉权的义务，我显然具有利害关系。

<!-- source-p 432 -->
<a id="47.2.81.1"></a>1. 盗窃之诉虽基于所有权而归属于所有人，但除非原告具有利害关系，否则并不成立。不过，在估算该物价值时，如果原告的利害关系没有超过物本身的价值，就应以该物价值为准。对于受解放条件拘束的奴隶和附条件遗赠之物，也能证明这一点；否则，面对主张不同意见的人，就很难确定相应金额。因此，只有在所有权已经消灭、但盗窃之诉仍可提起时，才单独以原告的利益确定估价；在上述情形中，盗窃之诉的估价不能脱离物本身的价值。

<!-- source-p 433 -->
<a id="47.2.81.2"></a>2. 如果我提起出示之诉，准备接受遗赠给我的奴隶，而家中一名奴隶被窃，继承人享有盗窃之诉，因为他有利害关系；提供保管义务的原因是什么，并不重要。

<!-- source-p 434 -->
<a id="47.2.81.3"></a>3. 劫掠者无论如何都构成盗窃，因此应被视为现行窃贼。

<!-- source-p 435 -->
<a id="47.2.81.4"></a>4. 但出于其欺诈而发生劫掠的人，不承担盗窃责任，而应依强夺财物之诉承担责任。

<!-- source-p 436 -->
<a id="47.2.81.5"></a>5. 某人以提提乌斯之名收取钱款，而收款者其实是假冒的代理人；如果提提乌斯追认该收款，他本人可以提起事务管理之诉。向假代理人支付了非债款的人，可以对提提乌斯提起非债清偿返还之诉；对假代理人的盗窃之诉仍然保留。既然已经选择向提提乌斯主张权利，要求以欺诈抗辩为条件，使付款人能够获得对假代理人的盗窃返还请求权，并非不公。如果所付钱款本来就是债务，提提乌斯追认后，盗窃之诉即消灭，因为债务人因此获释。

<!-- source-p 437 -->
<a id="47.2.81.6"></a>6. 假代理人只有在冒用债权人真正代理人的名义，欺骗另一债务人付款时，才构成盗窃钱款。对于冒充塞姆普罗尼乌斯债权人继承人、谎称有人欠自己钱款，而实际上另有继承人的情形，也应作同样处理。

<!-- source-p 438 -->
<a id="47.2.81.7"></a>7. 某人为提提乌斯处理事务，却以其名义向债权人的假代理人付款；提提乌斯追认了付款。提提乌斯不因此取得盗窃之诉；该诉在付款时即归属于付款人，因为钱币的所有权和占有均不曾属于提提乌斯。提提乌斯可以提起非债清偿返还之诉，付款人则享有盗窃返还之诉；如果有人通过事务管理之诉起诉提提乌斯，法官应裁量命其向付款人履行该返还请求。

<!-- source-p 439 -->
<a id="47.2.82"></a>47.2.82（81）

<!-- source-p 440 -->
帕比尼安《答复》第一卷

<!-- source-p 441 -->
某人窃取城市的钱款，应依盗窃之诉承担责任，而不构成侵吞公款罪。

<!-- source-p 442 -->
<a id="47.2.83"></a>47.2.83（82）

<!-- source-p 443 -->
保罗《判例集》第二卷

<!-- source-p 444 -->
<a id="47.2.83.pr."></a>序　洗衣人和衣物修补人接收衣物，供其洗涤或修补；如果他们使用衣物，就因实际触取而被认为实施盗窃，因为交付衣物的目的并非供其使用。

<!-- source-p 445 -->
<a id="47.2.83.1"></a>1. 土地上的谷物被窃时，承租人和所有人都可以提起盗窃之诉，因为双方均有利益追索该物。

<!-- source-p 446 -->
<a id="47.2.83.2"></a>2. 某人出于淫欲而窃取一名并非娼妓的女奴，应承担盗窃责任；若他将女奴藏匿，还应依《法比亚法》受到惩罚。

<!-- source-p 447 -->
<a id="47.2.83.3"></a>3. 窃取账簿或债务凭证的人，应按其中记载的金额依盗窃之诉承担责任；无论文书上的文字是否已经注销，均不影响，因为这些文书可以证明债务已经清偿。

<!-- source-p 448 -->
<a id="47.2.84"></a>47.2.84（83）

<!-- source-p 449 -->
涅拉提乌斯《答复》第一卷

<!-- source-p 450 -->
<a id="47.2.84.pr."></a>序　某人认为一个人已经死亡，但此人其实仍然在世；前者从其财产中以继承人身份取走物品，并不构成盗窃。

<!-- source-p 451 -->
<a id="47.2.84.1"></a>1. 某人已以自己的名义被提起盗窃之诉；若随后又以其奴隶之名，就另一物品对他起诉，不应给予他“同一盗窃行为已被起诉”的抗辩。

<!-- source-p 452 -->
<a id="47.2.85"></a>47.2.85（84）

<!-- source-p 453 -->
保罗《致涅拉提乌斯》第二卷

<!-- source-p 454 -->
虽然被盗物在返还给所有人以前不能通过时效取得，但如果已就该物确定了诉讼估价，或所有人已将该物出售给窃贼，就应认为时效取得不再受妨碍。

<!-- source-p 455 -->
<a id="47.2.86"></a>47.2.86（85）

<!-- source-p 456 -->
保罗《手册》第二卷

<!-- source-p 457 -->
某人若有利害关系使物品不被窃取，只有在其经所有人同意而占有该物时才享有盗窃之诉，例如承租该物的人。自愿为他人管理事务的人——包括以监护人身份管理事务的人——以及监护人或保佐人，若物品因自身过失被窃，则不享有盗窃之诉。同样，即使受益人有利害关系，因要式口约或遗嘱而有权取得奴隶的人也不享有盗窃之诉；为承租人提供保证的人也不享有该诉。

<!-- source-p 469 -->

<!-- source-p 473 -->
<a id="47.2.91.1"></a>1. 自己不能形成盗窃故意的人，不能向他人提供帮助或建议。

<a id="3"></a><a id="47.3"></a>47.3.0　论附合木材（*De tigno iuncto*）

<!-- source-p 481 -->
<a id="47.3.1"></a>47.3.1

<!-- source-p 482 -->
乌尔比安《告示评注》第三十七卷

<!-- source-p 483 -->
<a id="47.3.1.pr."></a>序　《十二表法》既不允许拆除附合于房屋或葡萄园的被盗木材，也不允许就该木材提起所有物返还诉讼（法律对此作出审慎规定，以免有人借此拆毁建筑，或妨碍葡萄园耕作）；但法律允许对被证明实施附合的人提起诉讼，请求双倍额。

<!-- source-p 484 -->
<a id="47.3.1.1"></a>1. “木材”一词包括构成建筑物的一切材料，以及葡萄园所需材料。因此，有人说，瓦片、石块、砖块和其他建筑所需材料也包括在内（*tigna* 一词源于覆盖之意）；不仅如此，石灰和沙子也包括在“木材”一词之内。对于葡萄园，凡葡萄园所需物品也都包括在“木材”一词之中，例如支柱和撑杆。

<!-- source-p 485 -->
<a id="47.3.1.2"></a>2. 还应给予出示之诉；因为不应宽容明知他人之物而将其嵌入或固定于建筑物的人。我们起诉他，并非把他当作占有人，而是因为他以欺诈方式使自己不再占有该物。

<!-- source-p 486 -->
<a id="47.3.2"></a>47.3.2

<!-- source-p 487 -->
乌尔比安《萨宾评注》第四十二卷

<!-- source-p 488 -->
如果提起的是针对附合于房屋之被盗木材的诉讼，可以讨论是否还可以另外提起所有物返还诉讼。我对此并不怀疑。

<!-- source-p 489 -->
<a id="4"></a><a id="47.4"></a>47.4.0　论遗嘱命令获得自由的人在主人死亡后、遗产接受前窃取或损坏财物的情形（*Si is, qui testamento liber esse iussus erit, post mortem domini ante aditam hereditatem subripuisse aut corrupisse quid dicetur*）

<!-- source-p 490 -->
<a id="47.4.1"></a>47.4.1

<!-- source-p 491 -->
乌尔比安《告示评注》第三十八卷

<!-- source-p 492 -->
<a id="47.4.1.pr."></a>序　如果有人主张：遗嘱命令获得自由的人，在主人死亡后、遗产被接受前，以恶意对命令其自由的主人原有财产实施行为，致使这些财产中的某物未能归于继承人，则应给予对该人的诉讼，请求双倍额；诉讼期间为一年。

<!-- source-p 493 -->
<a id="47.4.1.1"></a>1. 正如拉贝奥所写，这一诉讼更多地建立在自然衡平而非市民法衡平之上，因为市民法诉权并不存在。自然衡平要求不得让此人免受惩罚；他因即将获得自由而变得大胆，既不认为自己还能像奴隶那样被约束，也不认为自己会像自由人那样被判罪，因为他侵害的是遗产，也就是女主人之物。主人或女主人不能对自己的奴隶提起盗窃之诉，即使奴隶后来获得自由或被转让也不例外，除非奴隶此后又实施了实际触取。因此，裁判官认为，为了公共利益，应以双倍额之诉惩治那些掠夺遗产的狡诈放肆之人。

<!-- source-p 494 -->
<a id="47.4.1.2"></a>2. 只有在主张该获自由者以恶意耗散财产时，他才承担责任。获得自由后，奴隶的过失和疏忽可以免责；但与欺诈极为接近的重大过失，视为欺诈。因此，如果他造成损害时并无欺诈，该诉就不成立，尽管他仍可能因以任何方式造成损害而依《阿奎利亚法》承担责任。因此，此诉有明确界限：行为人必须出于欺诈，行为必须发生于主人死亡后、遗产接受前。否则，若无欺诈，或者虽有欺诈但发生在主人生前，他不承担此诉责任；若行为发生在主人死亡后、但遗产已经接受，也不成立此诉，因为遗产一经接受，他便可以像自由人一样被起诉。

<!-- source-p 495 -->
<a id="47.4.1.3"></a>3. 但是，如果他是附条件获得自由呢？他此时尚未成为自由人，却可以作为奴隶受约束；因此应认为，此诉不成立。

<!-- source-p 496 -->
<a id="47.4.1.4"></a>4. 如果自由立即生效，则应认为可以且必须对已经获得自由的人给予此诉。

<!-- source-p 497 -->
<a id="47.4.1.5"></a>5. 如果奴隶被无条件遗赠，而在遗产接受前对遗产中的财物实施了某种行为，由于其所有权发生变更，应认为可以提起此诉。

<!-- source-p 498 -->
<a id="47.4.1.6"></a>6. 一般而言，凡奴隶的所有权发生变更或消灭，或者在遗产接受后经过短暂间隔即取得自由的情形，都应给予此诉。

<!-- source-p 499 -->
<a id="47.4.1.7"></a>7. 如果以遗嘱信托方式给予奴隶自由，他在遗产中实施了任何不法行为，继承人是否可以要求他先行赔偿，然后才履行解放义务？神君马可与我们的皇帝及其父亲曾多次答复：无条件给予的遗嘱信托自由不得受到阻碍。神君马可当然答复，应立即指定一名仲裁人，由其核算账目；但该答复针对的是奴隶管理事务的账目。我认为在此情形下也可以提起本诉。

<!-- source-p 500 -->
<a id="47.4.1.8"></a>8. “遗产接受前”应理解为“尚未有任何一名继承人接受遗产前”；因为只要有一人接受遗产，自由即告生效。

<!-- source-p 501 -->
<a id="47.4.1.9"></a>9. 如果未成年人被指定为继承人，而其替补继承人给予奴隶自由，期间奴隶实施了某些行为：若行为发生在该未成年人仍在世时，此诉不成立；若行为发生在其死亡后、而尚无人继承未成年人遗产以前，则此诉成立。

<!-- source-p 502 -->
<a id="47.4.1.10"></a>10. 此诉不仅适用于属于遗嘱人财产的物品；如果继承人因恶意行为而无法取得某物，只要继承人具有利害关系，也适用此诉。因此，斯凯沃拉更全面地讨论了如下情形：奴隶窃取了死者曾接受质押的物品，仍可提起这一裁判官诉讼。此处应广义理解财产原因，即包括利益。因为如果裁判官设此诉是为了替代因奴隶身份而不能提起的盗窃之诉，那么可以合理推知，在一切本可提起盗窃之诉的情形中，裁判官都设立了替代诉。因此，通说认为，该诉也适用于质押物、善意占有的他人之物，以及死者借用的物品。

<!-- source-p 503 -->
<a id="47.4.1.11"></a>11. 如果这个期待获得自由的奴隶，在遗嘱人死后实际触取了已收获的孳息，也可以提起此诉。若他实际触取的是遗嘱人死后才出生的子女或幼畜，也应作同样处理。

<!-- source-p 504 -->
<a id="47.4.1.12"></a>12. 此外，如果未成年人在父亲死后取得某物的所有权，而该物在未成年人的遗产被接受以前遭到窃取，应认为此诉成立。

<!-- source-p 505 -->
<a id="47.4.1.13"></a>13. 一般而言，凡继承人有利害关系使某物不被侵夺，此诉均可适用。

<!-- source-p 506 -->
<a id="47.4.1.14"></a>14. 此诉不仅适用于盗窃，也适用于奴隶对遗产造成的一切损害。

<!-- source-p 507 -->
<a id="47.4.1.15"></a>15. 斯凯沃拉说，盗窃可以针对占有实施；因此，如果没有占有人，他否认构成盗窃。遗产本身不享有占有，因为占有由事实和意思构成，所以不能说盗窃遗产。继承人在实际取得占有以前也不享有占有，因为继承只把遗产中已有的权利转给继承人，而遗产并未拥有占有。

<!-- source-p 508 -->
<a id="47.4.1.16"></a>16. 但有一点是正确的：如果继承人可以通过其他方式取得自己的权利，就不应给予这项裁判官诉讼，因为判决金额以其利害关系为限。

<!-- source-p 509 -->
<a id="47.4.1.17"></a>17. 显然，除本诉外，继承人也可以提起所有物返还诉，因为本诉类似于盗窃之诉。

<!-- source-p 510 -->
<a id="47.4.1.18"></a>18. 还应认为，继承人及其他继受人均享有此诉。

<!-- source-p 511 -->
<a id="47.4.1.19"></a>19. 如果数名奴隶被给予自由，并共同实施恶意行为，可以分别对每一人提起诉讼，请求全部金额，即双倍额。由于他们因私犯而被起诉，依盗窃规则，即使其中一人已经履行，也不能使其余人免责。

<!-- source-p 512 -->
<a id="47.4.2"></a>47.4.2

<!-- source-p 513 -->
盖尤斯《行省告示评注》第十三卷

<!-- source-p 514 -->
如果奴隶在获准自由的时间到来前不久移走或损坏某物，主人不知情并不产生此诉。因此，即使继承人或其他奴隶主人完全不知该受解放条件拘束的奴隶曾移走或损坏某物，也不能在奴隶获得自由后对他提起任何诉讼，尽管在许多其他情形下，正当的不知情可以作为免责理由。

<!-- source-p 515 -->
<a id="47.4.3"></a>47.4.3

<!-- source-p 516 -->
乌尔比安《告示评注》第十三卷

<!-- source-p 517 -->
拉贝奥认为，附条件获释者若移走某物，而条件很快成就，应依本诉对其起诉。〔底本在 *rem* 一词处标有异文：*res [rem]*。〕

<!-- source-p 518 -->
<a id="5"></a><a id="47.5"></a>47.5.0　论针对船舶经营人、客店经营人及马厩经营人的盗窃之诉（*Furti adversus nautas caupones stabularios*）

<!-- source-p 519 -->
<a id="47.5.1"></a>47.5.1

<!-- source-p 520 -->
乌尔比安《告示评注》第三十八卷

<!-- source-p 521 -->
<a id="47.5.1.pr."></a>序　如果主张：在船舶、客店或马厩经营人处，由他们本人或其雇用的人实施盗窃，应给予针对经营人的诉讼；无论盗窃是以经营人的帮助或建议实施，还是由船上为航行而雇用的人实施，均是如此。

<!-- source-p 522 -->
<a id="47.5.1.1"></a>1. 所谓“为航行而雇用的人”，应理解为受雇使船舶得以航行的人，也就是船员。

<!-- source-p 523 -->
<a id="47.5.1.2"></a>2. 这是一项双倍额之诉。

<!-- source-p 524 -->
<a id="47.5.1.3"></a>3. 如果物品在客店或船上灭失，根据裁判官告示，船舶经营人或客店经营人应承担责任；遭窃物所有人可以选择依裁判官法对经营人起诉，或依市民法对窃贼起诉。

<!-- source-p 525 -->
<a id="47.5.1.4"></a>4. 但如果客店经营人或船员承诺物品会安全保存，享有盗窃之诉的不是遭窃物所有人，而是作出承诺的人本人，因为其接受物品时承担了保管风险。

<!-- source-p 526 -->
<a id="47.5.1.5"></a>5. 对于自己的奴隶，经营人可以通过交付其作为私犯代偿而免责。那么，为什么不判令经营人承担责任——毕竟他让这样恶劣的奴隶上船？而且，为什么他要就自由人承担全部责任，却不就奴隶承担责任？或许是因为，雇用自由人时，经营人本应事先查明其品行；对于自己的奴隶，则可宽宥其家内之恶，只要他愿意交付奴隶作为代偿。如果他雇用的是他人奴隶，则应像雇用自由人一样承担责任。

<!-- source-p 527 -->
<a id="47.5.1.6"></a>6. 客店经营人对为经营客店而在店内工作的人，以及为居住而住在店内的人之行为承担责任；但不对旅客的行为承担责任。因为客店经营人或马厩经营人并未选择旅客，也不能拒绝接待途经者；而对于长期居住者，经营人某种程度上作出了选择，因为他没有拒绝接纳他们，因此应对他们的行为负责。船舶经营人也不对乘客的行为承担责任。

<!-- source-p 528 -->
<a id="6"></a><a id="47.6"></a>47.6.0　论家内奴隶实施盗窃的情形（*Si familia furtum fecisse dicetur*）

<!-- source-p 529 -->
<a id="47.6.1"></a>47.6.1

<!-- source-p 530 -->
乌尔比安《告示评注》第三十八卷

<!-- source-p 531 -->
<a id="47.6.1.pr."></a>序　裁判官颁布这一极有用的告示，是为了保护主人免受奴隶不法行为的侵害；显然，如果数名奴隶共同实施盗窃，主人若被迫交出所有奴隶，或为每名奴隶分别提供诉讼估价，财产就会被耗尽。因此，告示赋予主人选择权：如果他愿意以奴隶造成损害为由进行抗辩，可以交出所有参与盗窃的奴隶；如果他更愿意支付估价，则只须支付一名自由人实施该盗窃时应支付的数额，并可保留其奴隶群体。

<!-- source-p 532 -->
<a id="47.6.1.1"></a>1. 只有在主人不知情时，才给予他这种选择；若主人知情，则不赋予该选择，因为原告可以就主人本人以及每名奴隶分别依私犯代偿诉讼起诉，主人不能只支付一名自由人所应承担的估价了事。所谓知情，是指知道且能够阻止；我们所看重的知情，必须兼有阻止的意思。反之，若他虽知情但曾加以阻止，应认为他仍可享有告示所赋予的利益。

<!-- source-p 533 -->
<a id="47.6.1.2"></a>2. 数名奴隶因过失造成损害时，最公平的做法是给予主人同样的选择权。

<!-- source-p 534 -->
<a id="47.6.1.3"></a>3. 数名奴隶共同窃取同一物，而诉讼已经以其中一名奴隶之名对主人提起时，在原告能够通过先前诉讼取得与一名自由人实施该盗窃相同数额以前，对其他奴隶之名提起的诉讼应暂停。

<!-- source-p 535 -->
<a id="47.6.2"></a>47.6.2

<!-- source-p 536 -->
尤利安《学说汇纂》第二十三卷

<!-- source-p 537 -->
也就是说，作为罚金应支付双倍额，作为返还应支付单倍额。

<!-- source-p 538 -->
<a id="47.6.3"></a>47.6.3

<!-- source-p 539 -->
乌尔比安《告示评注》第三十八卷

<!-- source-p 540 -->
<a id="47.6.3.pr."></a>序　主人若支付与一名自由人实施盗窃时相同的金额，就不再能以其他奴隶之名起诉；不仅不能起诉奴隶本人，如果共同实施盗窃的奴隶之一被出售，也不能仅以此为由对买受人起诉。奴隶获释时同样如此。但如果获释奴隶已先行赔付，仍可以家内奴隶之名起诉主人；因为不能说获释奴隶所支付的金额等同于家内奴隶所支付。显然，如果买受人已经赔付，我认为应拒绝对卖方提起的诉讼；因为从某种意义上说，卖方已经履行了赔偿，尤其是他曾承诺因盗窃及私犯代偿而免责。

<!-- source-p 541 -->
<a id="47.6.3.1"></a>1. 如果已因受遗赠奴隶或受赠奴隶实施盗窃而对受遗赠人或受赠人起诉，是否还可以对其他奴隶的主人起诉？我认为应当允许。

<!-- source-p 542 -->
<a id="47.6.3.2"></a>2. 本告示给予的减免，不仅适用于占有奴隶并因此被判支付相当于一名自由人实施盗窃时应付金额的主人，也适用于因以欺诈方式使自己不再占有奴隶而被判决的人。

<!-- source-p 543 -->
<a id="47.6.4"></a>47.6.4

<!-- source-p 544 -->
尤利安《学说汇纂》第二十二卷

<!-- source-p 545 -->
对于数名同一奴隶群体的奴隶共同实施盗窃的情形，遗嘱人的继承人也应享有与遗嘱人相同的诉权；也就是说，他们取得的总额不得超过一名自由人实施该盗窃时可以取得的数额。

<!-- source-p 546 -->
<a id="47.6.5"></a>47.6.5

<!-- source-p 547 -->
马尔凯卢斯《学说汇纂》第八卷

<!-- source-p 548 -->
共有奴隶在一名共有人知情的情况下实施盗窃，可以以全体奴隶之名对知情的共有人提起盗窃之诉；对另一共有人，则可以依告示规定的方式起诉。前者已经支付的金额，未以全体奴隶之名支付的部分，可以向该合伙人请求相应份额。如果共有奴隶受一名共有人命令而造成损害，只要也可以依据《阿奎利亚法》或《十二表法》对其起诉，已赔付的共有人也可以向合伙人追偿，如同共有物受到损害时一样。因此，如果我只有两名共有奴隶，且一名共有人知情，可以以两名奴隶之名对其起诉；但向另一合伙人追偿的金额，不得超过其为其中一名奴隶支付的金额。如果我选择对不知情的共有人起诉，只能取得双倍额。还须考察，是否已不得以另一奴隶之名对其合伙人判决，如同该合伙人已就所有奴隶作出和解一样；除非这种情形下裁判官应作出更严格的规定，不宽宥知情的共有人。

<!-- source-p 549 -->
<a id="47.6.6"></a>47.6.6

<!-- source-p 550 -->
斯凯沃拉《疑问集》第四卷

<!-- source-p 551 -->
<a id="47.6.6.pr."></a>序　拉贝奥认为，如果我的共同继承人因家内奴隶实施盗窃而取走了双倍额，这并不妨碍我提起双倍额之诉；若不如此，就会规避告示，也不公平，因为继承人承受的金额将超过我们本人所能承受的金额。

<!-- source-p 552 -->
<a id="47.6.6.1"></a>1. 同样，如果死者取走的金额少于双倍额，各继承人仍可分别正当地提起诉讼。斯凯沃拉答复：我认为更正确的做法是由继承人追索死者遗留的份额，但两名继承人各自能够取得的金额，加上死者已取走的部分，不得超过双倍额。

<!-- source-p 553 -->
<a id="7"></a><a id="47.7"></a>47.7.0　论秘密砍伐树木（*Arborum furtim caesarum*）

<!-- source-p 554 -->
<a id="47.7.1"></a>47.7.1

<!-- source-p 555 -->
保罗《萨宾评注》第九卷

<!-- source-p 556 -->
如果树木被秘密砍伐，拉贝奥说，应同时给予《阿奎利亚法》之诉和《十二表法》之诉；但特雷巴提乌斯主张，两项诉讼都应给予，不过在后一诉讼中，法官应扣除原告通过前一诉讼已经取得的金额，再就剩余部分判决。

<!-- source-p 557 -->
<a id="47.7.2"></a>47.7.2

<!-- source-p 558 -->
盖尤斯《十二表法评注》第一卷

<!-- source-p 559 -->
应当知道，砍伐树木、尤其是葡萄藤的人，也会被作为强盗处罚。

<!-- source-p 560 -->
<a id="47.7.3"></a>47.7.3

<!-- source-p 561 -->
乌尔比安《萨宾评注》第四十二卷

<!-- source-p 562 -->
<a id="47.7.3.pr."></a>序　许多古代法学家认为，葡萄藤包括在“树木”一词之内。

<!-- source-p 563 -->
<a id="47.7.3.1"></a>1. 常春藤和芦苇也可以恰当地称为树木。

<!-- source-p 564 -->
<a id="47.7.3.2"></a>2. 柳树林也应作同样处理。

<!-- source-p 565 -->
<a id="47.7.3.3"></a>3. 但是，某人为了栽种柳林而插下柳枝；在其尚未生根以前，柳枝就被砍断或拔出。庞波尼乌斯正确地写道，不能就砍伐树木提起诉讼，因为未曾扎根的东西严格说来还不算树木。

<!-- source-p 566 -->
<a id="47.7.3.4"></a>4. 但如果有人从苗圃连根移植树木，庞波尼乌斯在《萨宾评注》第十九卷中认为，即使树木尚未在新土中扎根，也仍可视为树木。

<!-- source-p 567 -->
<a id="47.7.3.5"></a>5. 因此，即使某棵树的根正在停止生长，也仍应视为树木。

<!-- source-p 568 -->
<a id="47.7.3.5a"></a>5a. 不过，树根本身不包括在“树木”一词之内，即使它仍附着于土地也是如此；拉贝奥也赞同这一意见。

<!-- source-p 569 -->
<a id="47.7.3.6"></a>6. 拉贝奥还认为，树木即使连根倾倒，只要仍可重新扶起；或虽被移植但仍可重新栽种，也应恰当地称为树木。

<!-- source-p 570 -->
<a id="47.7.3.7"></a>7. 橄榄树的枝条应更多地视为树木，无论它们是否已经生根。

<!-- source-p 571 -->
<a id="47.7.3.8"></a>8. 因此，对于我们列举的上述各种树木，均可提起本诉。

<!-- source-p 572 -->
<a id="47.7.4"></a>47.7.4

<!-- source-p 573 -->
盖尤斯《十二表法评注》

<!-- source-p 574 -->
当然，毫无疑问，如果树苗尚且十分幼嫩，形同草本，就不应算作树木。

<!-- source-p 575 -->
<a id="47.7.5"></a>47.7.5

<!-- source-p 576 -->
保罗《萨宾评注》第九卷

<!-- source-p 577 -->
<a id="47.7.5.pr."></a>序　“砍伐”不仅指砍倒，也包括为了砍伐而砍伤；“环剥”指剥去树皮；“锯切”指用锯子锯开，因为使用锯子的人不能被理解为砍伐了树木。

<!-- source-p 578 -->
<a id="47.7.5.1"></a>1. 本诉与《阿奎利亚法》之诉适用同一规则。

<!-- source-p 579 -->
<a id="47.7.5.2"></a>2. 土地用益权人不享有本诉；但享有公租土地权的人享有本诉，正如其享有防止雨水侵害之诉和界限确定之诉一样。

<!-- source-p 580 -->
<a id="47.7.6"></a>47.7.6

<!-- source-p 581 -->
庞波尼乌斯《萨宾评注》第二十卷

<!-- source-p 582 -->
<a id="47.7.6.pr."></a>序　数人秘密砍伐同一棵树时，可以分别对每个人请求全部金额。

<!-- source-p 583 -->
<a id="47.7.6.1"></a>1. 但如果同一棵树属于数人，则对所有人只支付一次罚金。

<!-- source-p 584 -->
<a id="47.7.6.2"></a>2. 如果树根延伸进入邻人的土地，邻人不得砍除树根；但可以提起诉讼，主张对方无权使树根伸入其土地，如同梁木或屋檐伸入邻地的情形。如果邻人的树从该根部吸取养分，该树仍属于其根源所在土地的所有人。

<!-- source-p 585 -->
<a id="47.7.7"></a>47.7.7

<!-- source-p 586 -->
乌尔比安《告示评注》第三十八卷

<!-- source-p 587 -->
<a id="47.7.7.pr."></a>序　所谓秘密砍伐的树木，是指在所有人不知情、并为了对其隐瞒而砍伐的树木。

<!-- source-p 588 -->
<a id="47.7.7.1"></a>1. 佩迪乌斯写道，这并非盗窃之诉，因为即使不构成盗窃，也可能发生某人秘密砍伐树木的情形。

<!-- source-p 589 -->
<a id="47.7.7.2"></a>2. 某人连根拔起或铲除树木，不承担本诉责任；因为他既未砍伐、砍倒，也未锯切树木。但他仍依《阿奎利亚法》承担责任，因为这相当于毁损了树木。

<!-- source-p 590 -->
<a id="47.7.7.3"></a>3. 即使树木并未被完全砍倒，仍可以仿佛树木已被砍倒而提起本诉。

<!-- source-p 591 -->
<a id="47.7.7.4"></a>4. 无论某人亲自砍伐树木，还是命令奴隶环剥、锯切或砍伐树木，都应承担本诉责任；命令自由人实施时，也适用同一规则。

<!-- source-p 592 -->
<a id="47.7.7.5"></a>5. 但如果主人没有命令自己的奴隶，而奴隶自行实施砍伐，萨宾说，可以提起私犯代偿之诉，如同其他不法行为一样。这个意见是正确的。

<!-- source-p 593 -->
<a id="47.7.7.6"></a>6. 即使本诉具有罚金性质，也不因时间经过而消灭；但不能对继承人提起。继承人及其他继受人则可以提起。

<!-- source-p 594 -->
<a id="47.7.7.7"></a>7. 此诉的判决金额为双倍额。

<!-- source-p 598 -->
<a id="47.7.8.1"></a>1. 秘密砍伐树木的人，就是暗中砍伐的人。

<!-- source-p 599 -->
<a id="47.7.8.2"></a>2. 因此，某人砍倒树木后又出于牟利目的取走木材，还应就木材承担盗窃责任，并可对其提起返还之诉和出示之诉。

<!-- source-p 600 -->
<a id="47.7.8.3"></a>3. 某人明知而在所有人面前以暴力砍伐树木，不属于本诉适用的情形。

<!-- source-p 613 -->
<a id="8"></a><a id="47.8"></a>47.8.0　论强夺财物之诉及群聚致害（*Vi bonorum raptorum et de turba*）

<!-- source-p 614 -->
<a id="47.8.1"></a>47.8.1

<!-- source-p 615 -->
保罗《告示评注》第二十二卷

<!-- source-p 616 -->
抢夺物品的人，既须依非现行盗窃之诉承担双倍额，也须依强夺财物之诉承担四倍额。但若先提起强夺财物之诉，就应拒绝盗窃之诉；若先提起盗窃之诉，则不应拒绝强夺财物之诉，不过原告只能取得后诉超过前诉的部分。

<!-- source-p 617 -->
<a id="47.8.2"></a>47.8.2

<!-- source-p 618 -->
乌尔比安《告示评注》第五十六卷

<!-- source-p 619 -->
<a id="47.8.2.pr."></a>序　裁判官说：“如果有人主张，某人恶意召集他人后造成损害，或其财物遭到抢夺，我将对被主张实施该行为的人给予诉讼。又如有人主张奴隶实施了该行为，我将给予针对其主人的私犯代偿诉讼。”

<!-- source-p 620 -->
<a id="47.8.2.1"></a>1. 裁判官以此告示处理暴力实施的行为。如果某人能够证明自己遭受暴力，可以通过公诉程序提起暴力之诉；有些人认为，不应让私人诉讼预先影响公诉判决。但人们认为，更有用的做法是：即使这可能预先影响《尤利亚私暴力法》所规定的案件，仍不得拒绝选择私法救济的人提起诉讼。

<!-- source-p 621 -->
<a id="47.8.2.2"></a>2. 告示所说的“恶意实施”，不仅指实施抢夺的人，也包括先行策划并召集武装人员、意图造成损害或抢夺财物的人。

<!-- source-p 622 -->
<a id="47.8.2.3"></a>3. 因此，无论某人亲自召集人员，还是利用他人召集的人实施抢夺，都被认为是恶意行为。

<!-- source-p 623 -->
<a id="47.8.2.4"></a>4. 所谓召集人员，应理解为召集他们以造成损害。

<!-- source-p 624 -->
<a id="47.8.2.5"></a>5. 告示并未说明这些人员的身份；无论是何种人，包括自由人或奴隶，均属其范围。

<!-- source-p 625 -->
<a id="47.8.2.6"></a>6. 即使只召集了一人，我们仍然会说“召集人员”。

<!-- source-p 626 -->
<a id="47.8.2.7"></a>7. 另外，如果只主张某人单独造成损害，我认为告示的措辞仍然适用。告示说“召集人员”，应理解为无论行为人独自实施暴力，还是召集他人后实施暴力，都受告示约束；即使召集的是武装或未持武器之人，也一样。

<!-- source-p 627 -->
<a id="47.8.2.8"></a>8. 这里提到恶意，也包括暴力。实施暴力的人必有恶意，但恶意行为并非一概都包含暴力。因此，恶意本身可以包含暴力；即使以狡诈手段实施而没有使用暴力，也同样在告示范围内。

<!-- source-p 628 -->
<a id="47.8.2.9"></a>9. 裁判官说“损害”，所以该词包括一切损害，也包括秘密造成的损害。但我认为，这里所指不是纯粹秘密实施的行为，而是与暴力相结合的行为。也有人可以正确地主张：某人单独实施且未使用暴力的行为不在本告示范围内；而召集他人实施的行为，即使未使用暴力，只要是恶意实施，也属于本告示。

<!-- source-p 629 -->
<a id="47.8.2.10"></a>10. 本告示并未合并盗窃之诉或《阿奎利亚法》之诉，尽管有时这些诉讼可以与本告示之诉同时适用。尤利安写道，以暴力抢夺财物的人比窃贼更为恶劣；如果有人召集他人造成损害，也当然可能依《阿奎利亚法》承担责任。

<!-- source-p 630 -->
<a id="47.8.2.11"></a>11. 裁判官说“财物遭抢夺”。他说“财物”时，应理解为即使只抢夺财产中的一件物品，也包括在内。

<!-- source-p 631 -->
<a id="47.8.2.12"></a>12. 某人若没有亲自召集他人，但自己加入被召集的人群并实施抢夺或造成损害，也应依本诉承担责任。问题是，告示是否只包括被告恶意召集人员后造成损害或抢夺财物的情形，还是也包括被告恶意抢夺或造成损害、但人员由他人召集的情形？较好的意见是后者也在告示范围内；该告示包括所有这些情形，也包括他人召集人员后造成损害的情形，因此召集者与受召集而实施行为者似乎都在其适用范围内。

<!-- source-p 632 -->
<a id="47.8.2.13"></a>13. 依据本诉，在一年除斥期间内，按物的真实价值判处四倍额，而不将利害关系额另行计入。

<!-- source-p 633 -->
<a id="47.8.2.14"></a>14. 本诉也可以针对家内奴隶群体提起，不必指出其中哪些人实施了抢夺或造成损害。所谓“家内奴隶群体”，包括奴隶，也包括从事家内事务的人；即使有人声称他们是自由人，或是他人所有但由我善意役使的奴隶，也在其内。

<!-- source-p 634 -->
<a id="47.8.2.15"></a>15. 我认为，原告不能以每一名奴隶之名分别对其主人提起本诉，因为主人只要一次支付四倍额即已足够。

<!-- source-p 635 -->
<a id="47.8.2.16"></a>16. 依据本诉提出私犯代偿时，不应交付整个奴隶群体，只应交付被查明以恶意实施行为的奴隶或奴隶们。

<!-- source-p 636 -->
<a id="47.8.2.17"></a>17. 通常称本诉为强夺财物之诉。

<!-- source-p 637 -->
<a id="47.8.2.18"></a>18. 只有实施恶意的人才依本诉承担责任。因此，如果某人抢回自己的物品，虽不依强夺财物之诉承担责任，仍会以其他方式受处罚。又如，某人抢回自己的逃奴，而该奴隶正被他人善意占有，他也不依本诉承担责任，因为他取回的是自己的财物。如果该物已质押给他人呢？则他仍应承担责任。

<!-- source-p 638 -->
<a id="47.8.2.19"></a>19. 对于未达青春期且没有恶意能力的未成年人，不得提起强夺财物之诉；但若其奴隶或奴隶群体实施了该行为，则可以奴隶或奴隶群体之名，依强夺财物之诉提起私犯代偿诉讼。

<!-- source-p 639 -->
<a id="47.8.2.20"></a>20. 如果税务承包人带走我的牲畜，认为我违反了租税法的规定，尽管他判断有误，拉贝奥说，仍不能依强夺财物之诉起诉他，因为他并无恶意。但是，如果他把牲畜关起来，是为了不让它们吃草并使其饿死，也可以依《阿奎利亚法》的适用之诉起诉。

<!-- source-p 640 -->
<a id="47.8.2.21"></a>21. 某人以暴力带走牲畜后将其关起来，当然可以依强夺财物之诉起诉。

<!-- source-p 641 -->
<a id="47.8.2.22"></a>22. 在本诉中，我们并不必然考察物品是否属于原告的财产；无论该物是否属于其所有，只要该物来自其财产范围，本诉就适用。因此，如果物品是借给我的、出租给我的、质押给我的，或寄存于我处且物品被取走会使我遭受损失；或者我善意占有该物、享有其用益权或其他权利，以致我有利益使其不被抢夺，那么都应认为我享有本诉。我们不应只看所有权，而应看被取走之物是否来自我的财产，也就是我的财产总体。

<!-- source-p 642 -->
<a id="47.8.2.23"></a>23. 一般来说，凡秘密取走物品时我享有盗窃之诉的情形，我也享有本诉。有人会说：对于寄存物，我们并不享有盗窃之诉。但我加上了“如果我们有利益使该物不被抢夺”这一条件；因为即使是寄存物，如果我对其承担过失责任，或者收取寄存报酬而该报酬并非单纯的费用补偿，我也享有盗窃之诉。

<!-- source-p 643 -->
<a id="47.8.2.24"></a>24. 更好的意见是，即使因寄存关系而不能提起盗窃之诉，仍可以提起强夺财物之诉，因为秘密行为人与抢夺者之间存在极大区别：前者掩饰其不法行为，后者则公然实施，并且犯下公开的不法行为。因此，只要某人能够证明自己哪怕仅有轻微的利害关系，就应允许其提起强夺财物之诉。

<!-- source-p 644 -->
<a id="47.8.2.25"></a>25. 如果我的逃奴为给自己配备物品而购买了某些东西，这些物品又被抢走，由于它们属于我的财产，我可以就此提起强夺财物之诉。

<!-- source-p 645 -->
<a id="47.8.2.26"></a>26. 对于被抢夺的物品，也可以提起盗窃之诉、不法损害之诉或返还之诉；或者至少可以分别提起所有物返还诉。

<!-- source-p 646 -->
<a id="47.8.2.27"></a>27. 继承人及其他继受人可以提起本诉；但不能对继承人或其他继受人提起本诉，因为罚金诉讼不针对他们。还应考察，能否在他们因该行为而获益的范围内起诉他们。我认为，裁判官没有承诺可以在继承人获益的范围内对其起诉，是因为他认为返还之诉已足够。

<!-- source-p 647 -->
<a id="47.8.3"></a>47.8.3

<!-- source-p 648 -->
保罗《告示评注》第五十四卷

<!-- source-p 649 -->
奴隶实施抢夺并与自由人共同被起诉时，即使原告本可以对主人起诉，也不能在一年后再对已获释的奴隶正当地提起诉讼，因为只要原告曾有机会对任何一人起诉，就会被排除。拉贝奥说，如果在一年内已对主人起诉，之后又对获释奴隶起诉，则可以对其提出既判力抗辩。

<!-- source-p 650 -->
<a id="47.8.4"></a>47.8.4

<!-- source-p 651 -->
乌尔比安《告示评注》第五十六卷

<!-- source-p 652 -->
<a id="47.8.4.pr."></a>序　裁判官说：“如果主张某人恶意在群聚中造成损害，我将给予诉讼：自首次有机会就该事起诉之日起一年内请求双倍额；一年后请求单倍额。”

<!-- source-p 653 -->
<a id="47.8.4.1"></a>1. 这一告示适用于某人在群聚中造成的损害。

<!-- source-p 654 -->
<a id="47.8.4.2"></a>2. 拉贝奥说，“群聚”一词源于骚乱之类的情形；该词由希腊语转写 *apo tou vorubein*（*id est: a tumultuando*，即“因喧闹而起”）引申而来。

<!-- source-p 655 -->
<a id="47.8.4.3"></a>3. 我们应以多少人为“群聚”？如果两人发生斗殴，当然不能说是在群聚中实施，因为严格说来，两人不能称为群体；但如果有多人，例如十人或十五人，就称为群聚。那么三四个人如何？当然不构成群聚。拉贝奥极为正确地指出，群聚与斗殴大不相同：群聚是许多人造成的骚动和集会，而斗殴则可能只有两人。

<!-- source-p 656 -->
<a id="47.8.4.4"></a>4. 依本告示承担责任的，不仅是亲自在群聚中造成损害的人，也包括以恶意促使群聚中发生损害的人，无论他是否亲自到场；因为未在场的人也可能有恶意。

<!-- source-p 657 -->
<a id="47.8.4.5"></a>5. 还应认为，如果某人到场并在群聚中煽动他人造成损害，只要损害发生时他也身处群聚之中且具有恶意，就依本告示承担责任；不能否认损害是因他的恶意而在群聚中发生的。

<!-- source-p 658 -->
<a id="47.8.4.6"></a>6. 某人到场后引起或召集群聚，无论是通过呼喊、某种行为、指控他人，还是激起他人怜悯；若因其恶意造成损害，即使他无意召集群聚，也应承担责任。因为可以说，损害是在他的恶意作用下于群聚中造成的；裁判官并未要求群聚必须由他亲自召集，而是要求有人恶意地在群聚中造成损害。因此，本告示与前一告示有所不同：前一告示涉及恶意召集人员后造成损害或抢夺财物的情形，也包括没有召集人员而抢夺财物的情形；本告示则涉及在群聚中恶意造成损害的情形，即使被告本人没有召集群聚，而群聚是因其呼喊、言语或激起怜悯而形成，或者由他人召集，或者他本人只是群聚中的一员。

<!-- source-p 659 -->
<a id="47.8.4.7"></a>7. 因为前一告示针对行为的严重性规定了四倍罚金，而本告示只规定双倍罚金。

<!-- source-p 660 -->
<a id="47.8.4.8"></a>8. 本告示和前一告示都允许在一年内起诉；一年后则只能请求单倍额。

<!-- source-p 661 -->
<a id="47.8.4.9"></a>9. 本告示谈到造成的损害和物品的灭失，但不包括抢夺；对于抢夺，可以依据前一告示提起强夺财物之诉。

<!-- source-p 662 -->
<a id="47.8.4.10"></a>10. 所谓“灭失”，是指物品虽仍留在某人手中但已受损，例如被撕裂或打碎。

<!-- source-p 663 -->
<a id="47.8.4.11"></a>11. 这是一项事实之诉，判处该物价值的双倍额；此处应按物品真实价值计算。估价以当前价值为准。一年内始终可以请求双倍额。

<!-- source-p 664 -->
<a id="47.8.4.12"></a>12. 原告必须证明损害是在群聚中造成的；如果损害发生在其他地点，本诉就不成立。

<!-- source-p 665 -->
<a id="47.8.4.13"></a>13. 提提乌斯殴打我的奴隶时，群聚随之形成，该奴隶在群聚中失去某物，我可以起诉殴打者，因为损害是在群聚中恶意造成的；但须殴打者是为了造成损害才开始殴打。若他殴打另有原因，则本诉不成立。

<!-- source-p 666 -->
<a id="47.8.4.14"></a>14. 某人为实施侮辱而召集群聚，让众人在群聚面前殴打奴隶，虽无造成损害的意图，本告示仍然适用。因为出于侮辱而殴打的人具有恶意；而为造成损害提供原因的人，也被认为造成了损害。

<!-- source-p 667 -->
<a id="47.8.4.15"></a>15. 裁判官也针对奴隶及奴隶群体给予本诉。

<!-- source-p 668 -->
<a id="47.8.4.16"></a>16. 关于强夺财物之诉中继承人及其他继受人的规则，在此也同样适用。

<!-- source-p 673 -->
