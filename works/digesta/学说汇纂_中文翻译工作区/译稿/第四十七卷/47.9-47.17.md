## D.47.9　论因火灾、坍塌、海难、木筏或船舶遭袭而发生的抢掠（*De incendio ruina naufragio rate nave expugnata*）

<!-- source-p 0675 -->
<a id="9"></a><a id="47.9"></a>**47.9.0**　论因火灾、坍塌、海难、木筏或船舶遭袭而发生的抢掠。

<!-- source-p 0676 -->
<a id="47.9.1"></a>**47.9.1**

<!-- source-p 0677 -->
乌尔比安《告示评注》第56卷。

<!-- source-p 0678 -->
<a id="47.9.1.pr."></a>**序言**　裁判官告示称：“若有人被指称在火灾、坍塌、海难，或木筏、船舶遭袭时，以恶意欺诈抢夺或收受任何物品，或在这些情形下造成损害，我将于首次可以就此事提起诉讼之日起一年内，判令其支付四倍额；一年之后，则判令其支付单倍额。我也将对奴隶及家奴提起诉讼。”

<!-- source-p 0679 -->
<a id="47.9.1.1"></a>**1**　这项告示的实用价值显而易见，其严厉程度也极为公正，因为公共利益要求不得利用此类灾祸抢掠财物。尽管对这些行为也可以通过刑事程序追诉，裁判官仍正确地规定民事诉讼亦可针对此类犯罪提起。

<!-- source-p 0680 -->
<a id="47.9.1.2"></a>**2**　“因火灾”应如何理解？是指从火焰本身抢取，还是从发生火灾的地点抢取？较妥当的理解是，因火灾而抢取，即因火灾引起的混乱或恐慌而抢取。正如我们通常所说，某物在战争中丧失，是指因战争这一事由而丧失。因此，若有人从火灾发生地点邻近的土地上抢走物品，也应认为本告示适用，因为这确实属于因火灾而抢取。

<!-- source-p 0681 -->
<a id="47.9.1.3"></a>**3**　“坍塌”一词也应联系坍塌发生的时点理解；不仅从坍塌物中取走物品如此，从邻近处取走也如此。

<!-- source-p 0682 -->
<a id="47.9.1.4"></a>**4**　若当时仅有火灾或坍塌的疑虑，而实际并未发生火灾或坍塌，应考察本告示是否适用。较妥当的意见是不适用，因为并未有任何物品因火灾或坍塌而被抢走。

<!-- source-p 0683 -->
<a id="47.9.1.5"></a>**5**　裁判官还说：“若有人从海难中……”这里的问题是：仅指海难发生时取走物品，还是也包括其他时间，即海难发生之后？因为所谓海难中的物品，也包括海难之后被遗留在岸上的物品。较妥当的理解是，应以海难发生的时点为准。

<!-- source-p 0684 -->
<a id="47.9.2"></a>**47.9.2**

<!-- source-p 0685 -->
盖尤斯《行省告示评注》第21卷。

<!-- source-p 0686 -->
以及地点……

<!-- source-p 0687 -->
<a id="47.9.3"></a>**47.9.3**

<!-- source-p 0688 -->
乌尔比安《告示评注》第56卷。

<!-- source-p 0689 -->
<a id="47.9.3.pr."></a>**序言**　若有人在海难正在发生或已经发生之时抢走财物，应认为其落入本告示的适用范围。但若有人在海难发生之后，从海岸上取走遗留的物品，则其情形更接近盗窃，而非受本告示约束；取走从车辆上掉落物品的人也是如此。从海岸上捡走遗留物，通常不被视为抢夺。

<!-- source-p 0690 -->
<a id="47.9.3.1"></a>**1**　接着，裁判官说：“木筏或船舶遭袭。”所谓“遭袭”，是指有人在如同战斗或交战的过程中，从木筏或船舶上抢取物品；无论是其本人实施袭击，还是在海盗袭击时进行抢掠，均属此类。

<!-- source-p 0691 -->
<a id="47.9.3.2"></a>**2**　拉贝奥写道，若有人从遭袭的房屋或乡间别墅抢走物品，本告示也应适用，这样处理才公平；因为在乡间遭遇盗匪骚扰或侵袭，并不亚于在海上遭遇海盗。

<!-- source-p 0692 -->
<a id="47.9.3.3"></a>**3**　承担责任的不仅是实施抢夺的人，也包括基于上述事由收受赃物的人，因为收赃者的违法程度不亚于抢夺者。但告示增加了“以恶意欺诈”的限定，因为并非每个收受者都立即构成违法，只有以恶意欺诈收受的人才构成违法。若收受者并不知情，或者其收受是为了保管物品并使之安全返还给失主，又该如何处理？在这些情形下当然不应使其承担责任。

<!-- source-p 0693 -->
<a id="47.9.3.4"></a>**4**　承担本诉责任的不仅是抢夺者，也包括取走、移走、造成损害或收受物品的人。

<!-- source-p 0694 -->
<a id="47.9.3.5"></a>**5**　“抢夺”与“移走”显然不同，因为移走可以不使用暴力，而抢夺则不可能不使用暴力。

<!-- source-p 0695 -->
<a id="47.9.3.6"></a>**6**　船舶被抛上岸后，有人从中抢走物品，也受本告示约束。“被抛上岸”，即希腊人所说的 *ecebrasvy*〔底本以拉丁字母转写，词形待核〕。

<!-- source-p 0696 -->
<a id="47.9.3.7"></a>**7**　裁判官所说的“造成损害”，只有在损害系以恶意造成时才适用；若不存在恶意欺诈，告示便不适用。那么，拉贝奥所写的情形应如何处理：火灾发生后，我为保护自己的房屋而拆毁邻人的建筑，是否应以我本人及家奴为被告提起诉讼？既然我是为了保护自己的房屋才这样做，当然不存在恶意欺诈。因此，我认为拉贝奥的说法并不正确。是否仍可基于《阿奎利亚法》起诉此人？我也认为不能，因为此人只是为了保护自己，且除此之外别无他法，并非不法地实施行为。凯尔苏斯也持此说。

<!-- source-p 0697 -->
<a id="47.9.3.8"></a>**8**　在克劳狄乌斯时期，元老院作出决议：若有人从海难中取走一枚钉子，或其中一枚钉子，应就全部物品承担责任。另一项元老院决议又规定：若有人以欺诈或计谋妨碍海难遇险者脱险，使其不能登船或未能获得救助，应依《科尔内利亚法》（该法针对杀人者制定）的刑罚处罚；至于以恶意欺诈从海难者极其不幸的处境中抢取或牟利的人，其责任金额应与裁判官告示准许提起的诉讼金额相同，并应向国库缴纳。

<a id="47.9.4.pr."></a>**序言**　佩狄乌斯说，在海难发生时的慌乱中抢取物品，也可以称为从海难中抢掠。

<!-- source-p 0701 -->
<a id="47.9.4.1"></a>**1**　神圣的安敦尼皇帝就从海难中抢掠财物的人作出如下敕答：“你写信向我询问，关于船舶和木筏遭遇海难一事，应当以何种刑罚处罚那些被证明从中抢走财物的人。依我看，这一点很容易确定：关键在于，他们取走的是否是本会毁损的物品，还是可予保全却被他们无耻侵占的物品。因此，若所抢取的财物价值较大，且显然是以暴力夺取的，你应命令自由人受杖击，并流放三年；若其身份较低，则应令其服同等期限的公共劳役；奴隶应受鞭笞并判处矿场劳役。若涉及的财物价值不大，你可以命令自由人受杖击、奴隶受鞭笞后予以释放。”总之，处理此类案件与其他案件一样，均须结合行为人的身份和财物性质谨慎衡量，不得判处超过或轻于案件情形所要求的刑罚。

<!-- source-p 0702 -->
<a id="47.9.4.2"></a>**2**　这些诉讼也可以由继承人提起；对继承人提起诉讼的范围，以利益实际归于继承人的部分为限。

<!-- source-p 0703 -->
<a id="47.9.5"></a>**47.9.5**

<!-- source-p 0704 -->
盖尤斯《行省告示评注》第21卷。

<!-- source-p 0705 -->
若有人从海难、火灾或坍塌中救出的物品已被移至他处，而他人又将其取走或抢走，则当然可以提起盗窃之诉或暴力抢夺财物之诉，尤其是在行为人不知道该物来自海难、火灾或坍塌时。多数法学家也对被海浪冲到岸边的海难遗物作同样处理。只有在海难发生后已经经过一段时间时，才应如此认定；否则，若行为发生于海难当时，无论行为人是从海中、海难遗物中还是从海岸上抢取，均无区别。对于从遭袭的木筏或船舶上抢取的物品，也应作同样解释。

## D.47.10　论不法侵害与诽谤性文书（*De iniuriis et famosis libellis*）

<!-- source-p 0728 -->
<a id="10"></a><a id="47.10"></a>**47.10.0**　论不法侵害与诽谤性文书。

<!-- source-p 0729 -->
<a id="47.10.1"></a>**47.10.1**

<!-- source-p 0730 -->
乌尔比安《告示评注》第56卷。

<!-- source-p 0731 -->
<a id="47.10.1.pr."></a>**序言**　*Iniuria* 一词源于行为不合法，因为一切不合法实施的行为，都称为 *iniuria*。这是该词的一般含义。特定意义上，*iniuria* 则指侮辱。有时该词也指因过失造成的损害，正如我们在《阿奎利亚法》中通常所说的那样；有时我们用 *iniuria* 指不公正，例如有人不公平或不合法地作出判决，我们便说该判决构成 *iniuria*，因为它欠缺法律与正义，仿佛“无法”；而 *contumelia*（侮辱）一词则源于轻蔑。

<!-- source-p 0732 -->
<a id="47.10.1.1"></a>**1**　拉贝奥说，不法侵害可以通过行为或言词实施：以行为实施，是指有人动手；以言词实施，则是在没有动手时辱骂他人。

<!-- source-p 0733 -->
<a id="47.10.1.2"></a>**2**　每一不法侵害都涉及身体、尊严或名誉：殴打他人，是对身体的侵害；带走贵妇的随从，是对尊严的侵害；侵犯他人贞操，则是对名誉的侵害。

<!-- source-p 0734 -->
<a id="47.10.1.3"></a>**3**　此外，不法侵害既可直接针对某人实施，也可通过他人间接实施。直接针对某人，是指直接侵害家父或家母本人；间接实施，则是侵害我的子女、奴隶、妻子或儿媳，因为发生在受我们权力支配或与我们有密切情感关系之人身上的侵害，也关系到我们。

<!-- source-p 0735 -->
<a id="47.10.1.4"></a>**4**　若有人侵害死者的尸体，而我们已成为该死者的继承人或遗产占有人，我们可以自己的名义提起侵辱之诉；因为对死者的任何侵害都关系到我们的名誉。若有人损害我们所继承之人的名声，也适用同一规则。

<!-- source-p 0736 -->
<a id="47.10.1.5"></a>**5**　对我们子女所实施的不法侵害，竟会影响我们的名誉，以至于即使有人应儿子的要求将其出卖，父亲仍可以自己的名义提起侵辱之诉；但不能以儿子的名义起诉，因为自愿接受的行为并不构成针对该人的不法侵害。

<!-- source-p 0737 -->
<a id="47.10.1.6"></a>**6**　若有人侵害遗嘱人的葬礼或尸体，且侵害发生在接受遗产之后，应当说该侵害在某种意义上是针对继承人的，因为继承人始终有利益维护死者的名誉。若侵害发生在接受遗产之前，则该侵害更直接关系到遗产，并通过遗产使继承人取得诉权。尤利安写道，若遗嘱人的尸体在接受遗产前遭到扣留，毫无疑问，诉权归于遗产。他还认为，若遗产中的奴隶在接受遗产前遭受不法侵害，也应如此处理：继承人通过遗产取得诉权。

<!-- source-p 0738 -->
<a id="47.10.1.7"></a>**7**　拉贝奥写道，若有人在接受遗产前殴打遗嘱中已获解放的遗产奴隶，继承人可以提起侵辱之诉；若殴打发生在接受遗产后，无论该奴隶知道自己已经自由还是对此并不知情，均可由其本人起诉。

<!-- source-p 0739 -->
<a id="47.10.1.8"></a>**8**　涅拉提乌写道，无论行为人知道那是我的儿子或妻子，还是对此并不知情，我都可以自己的名义提起诉讼。

<!-- source-p 0740 -->
<a id="47.10.1.9"></a>**9**　涅拉提乌还说，一项不法侵害有时会产生三项侵辱之诉，任何一人的诉权也不会因他人提起诉讼而消灭。例如，我的妻子是家子，她受到不法侵害；我、她的父亲以及她本人都因此取得侵辱之诉。

<!-- source-p 0741 -->
<a id="47.10.2"></a>**47.10.2**

<!-- source-p 0742 -->
保罗《告示评注》第50卷。

<!-- source-p 0743 -->
若丈夫遭受不法侵害，妻子不得起诉；因为由丈夫保护妻子是公平的，反过来由妻子保护丈夫则非如此。

<!-- source-p 0744 -->
<a id="47.10.3"></a>**47.10.3**

<!-- source-p 0745 -->
乌尔比安《告示评注》第56卷。

<!-- source-p 0746 -->
<a id="47.10.3.pr."></a>**序言**　一般而言，能够遭受不法侵害的人，也能够实施不法侵害。

<!-- source-p 0747 -->
<a id="47.10.3.1"></a>**1**　当然，有些人不能实施不法侵害，例如精神失常者，以及不具备欺诈能力的未适婚人；他们通常只能遭受不法侵害，而不能实施不法侵害。由于不法侵害取决于行为人的主观意思，因此应当说，这些人无论殴打他人还是辱骂他人，都不视为实施了不法侵害。

<!-- source-p 0748 -->
<a id="47.10.3.2"></a>**2**　因此，一个人即使没有感知到侵害，也可以遭受不法侵害；但除非行为人知道自己正在实施不法侵害，否则无人能够实施不法侵害，即使他不知道侵害的对象是谁，也不影响这一点。

<!-- source-p 0749 -->
<a id="47.10.3.3"></a>**3**　所以，若有人出于玩笑或在竞技时击打他人，不承担侵辱之诉的责任。

<!-- source-p 0750 -->
<a id="47.10.3.4"></a>**4**　若有人殴打自由人，却以为那是自己的奴隶，则不应令其承担侵辱之诉的责任。

<!-- source-p 0751 -->
<a id="47.10.4"></a>**47.10.4**

<a id="47.10.5"></a>**47.10.5**

<!-- source-p 0755 -->
乌尔比安《告示评注》第56卷。

<a id="47.10.5.pr."></a>**序言**　《科尔内利亚不法侵害法》适用于希望提起侵辱之诉的人；其所主张的事由是自己遭到殴打或鞭打，或者有人以暴力侵入自己的住所。该法规定，若审理法官与起诉人之间存在翁婿、继父与继子、堂表亲等亲属或姻亲关系，或与上述任何人存在此类关系，或法官是上述任何人或其父母的释奴保护人，就不得担任该案法官。因此，《科尔内利亚法》基于三种事由赋予诉权：有人遭殴打、遭鞭打，或其住所被暴力侵入。由此可见，一切以手实施的不法侵害均为该法所涵盖。

<!-- source-p 0757 -->
<a id="47.10.5.1"></a>**1**　奥菲利乌斯写道，殴打与击打的区别在于：击打是造成疼痛的打击，殴打则是不造成疼痛的打击。

<!-- source-p 0758 -->
<a id="47.10.5.2"></a>**2**　“住所”应理解为居所，而非房屋所有权。因此，无论某人住在自己的房屋、租来的房屋、免费居住的房屋，还是作为客人借住的房屋，本法均适用。

<!-- source-p 0759 -->
<a id="47.10.5.3"></a>**3**　若有人居住在乡间别墅或花园中，是否也适用？应作同样认定。

<!-- source-p 0760 -->
<a id="47.10.5.4"></a>**4**　若土地所有人出租土地，而有人侵入该土地，应由佃农起诉，而非土地所有人。

<!-- source-p 0761 -->
<a id="47.10.5.5"></a>**5**　但若有人侵入他人土地，而该土地由所有人亲自耕种，拉贝奥否认土地所有人可以基于《科尔内利亚法》起诉，因为所有人不可能在其所有的每一处乡间别墅都设立住所。我认为，本法适用于家父实际居住的任何住所，即使他并未在那里设立法定居所。假设某人为了求学而在罗马居住，他当然没有在罗马设立法定居所；但若有人以暴力侵入其房屋，仍应认为《科尔内利亚法》适用。因此，本法不适用于客栈或马厩；除此之外，凡实际居住于某处而非仅短暂停留者，即使没有在那里设立法定居所，本法仍适用。

<!-- source-p 0762 -->
<a id="47.10.5.6"></a>**6**　有人问，父亲能否基于《科尔内利亚法》，就家子遭受的不法侵害提起侵辱之诉？通说认为不能，此点没有争议。但父亲享有裁判官法上的侵辱之诉，儿子则享有基于《科尔内利亚法》的诉权。

<!-- source-p 0763 -->
<a id="47.10.5.7"></a>**7**　依据《科尔内利亚法》，家子可以基于任何事由起诉，无须提供担保确保父亲追认其行为；尤利安写道，家子以自己的名义提起其他侵辱之诉时，也不得强令其提供追认担保。

<!-- source-p 0764 -->
<a id="47.10.5.8"></a>**8**　本法允许原告要求被告宣誓，证明自己未实施不法侵害。萨宾说，在辅助审判中，裁判官也会依照本法先例行事；实践确实如此。

<!-- source-p 0765 -->
<a id="47.10.5.9"></a>**9**　若有人撰写、编造或发表损害他人名誉的书籍，或以恶意欺诈促成上述行为，即使以他人名义或匿名发表，也可以就此提起诉讼；行为人被判有罪后，应依法律丧失作遗嘱见证人的资格。

<!-- source-p 0766 -->
<a id="47.10.5.10"></a>**10**　根据元老院决议，若有人不以书面方式发表讽刺诗或其他损害他人名誉的内容，或安排买卖此类作品，也受同一刑罚处罚。

<!-- source-p 0767 -->
<a id="47.10.5.11"></a>**11**　告发者无论是自由人还是奴隶，均可依被告的财产状况及法官的估价获得相应奖赏；奴隶或许还应获释。毕竟，如果此事关系公共利益，为什么不应如此处理？

<a id="47.10.7.pr."></a>**序言**　裁判官告示说：“提起侵辱之诉的人，应明确说明发生了何种不法侵害。”因为提起可能损害名誉的诉讼者，不得含混其词，以免危及他人的名誉；他必须指明并具体说明自己主张遭受了何种不法侵害。

<!-- source-p 0774 -->
<a id="47.10.7.1"></a>**1**　若有人主张某人遭不法杀害，裁判官是否不应允许私诉预断《科尔内利亚法》之诉？若有人以“你为了杀人而给了那个人毒药吗？”为由起诉，也应如此处理。因此，裁判官若不准许此类私诉，做法会更妥当。我们通常说，凡属于公诉审理的事由，并不妨碍当事人同时提起私诉。这话是对的，但前提是私诉并非主要针对本身已有公诉追诉程序的事项。那么，《阿奎利亚法》之诉又如何？该诉主要处理的是对所有人造成的损害；而侵辱之诉针对的是杀人或投毒行为本身，目的在于惩罚，而非赔偿损害。若有人因为自己的头部被剑击中而提起侵辱之诉，又该如何？拉贝奥说不应禁止，因为原告并非在请求对具有公诉刑罚的事项作出裁判。此说不正确：谁会怀疑此人也可能依据《科尔内利亚法》被起诉？

<!-- source-p 0775 -->
<a id="47.10.7.2"></a>**2**　要求明确说明所受侵害的性质，还有一项目的：据此判断是否应准许释奴对释奴保护人提起侵辱之诉。应当记住，释奴并非总能对释奴保护人提起该诉，但若所受侵害极其严重，例如如对奴隶般对待，便可起诉。对于轻微管教，我们当然应允许释奴保护人对释奴实施；除非侵害的严重程度足以促使裁判官受理，否则裁判官不会接受释奴声称遭受不法侵害的申诉。毕竟，某人昨天还是奴隶、今天已获自由，不能仅因主人辱骂他、轻微殴打他或管教他，就要求裁判官受理。但若释奴保护人鞭打、殴打或严重伤害了他，裁判官给予救济就极为公平。

<!-- source-p 0776 -->
<a id="47.10.7.3"></a>**3**　若不受父权支配的子女要与其父母起诉，也不应轻率地准许侵辱之诉，除非侵害严重到足以支持该诉。至于仍受父权支配的子女，即使侵害极为严重，也完全不享有该诉。

<!-- source-p 0777 -->
<a id="47.10.7.4"></a>**4**　裁判官说“应明确说明发生了何种不法侵害”，该如何理解？拉贝奥说，原告须指出侵害的具体名称，不得列举“这一种或那一种”等备选情形，而应明确说自己遭受的是哪一种侵害。

<!-- source-p 0778 -->
<a id="47.10.7.5"></a>**5**　若你同时对我实施多项不法侵害，例如纠集一群人闯入某人的住宅，并且因此使我同时遭到辱骂和殴打，我能否就每项侵害分别起诉你？马尔切鲁斯遵循涅拉提乌的意见，认为应强令原告将同时遭受的各项侵害合并起诉。

<!-- source-p 0779 -->
<a id="47.10.7.6"></a>**6**　我们的皇帝曾以敕答确认，如今任何不法侵害，包括严重不法侵害，都可以通过民事诉讼追究。

<!-- source-p 0780 -->
<a id="47.10.7.7"></a>**7**　“严重不法侵害”，应理解为更具侮辱性且程度更重的侵害。

<!-- source-p 0781 -->
<a id="47.10.7.8"></a>**8**　拉贝奥说，严重不法侵害可能因行为人的身份、行为发生的时间或行为本身的性质而成立。身份方面，例如侵害对象是官员、父母或释奴保护人，便更为严重。时间方面，例如侵害发生于竞技活动期间并在众目睽睽之下；他指出，侵害是在裁判官面前还是在偏僻之处发生，区别很大，因为当众实施的侵害更为严重。行为本身方面，例如造成创伤或击打他人的面部，也构成严重不法侵害。

<a id="47.10.11.pr."></a>**序言**　承担侵辱之诉责任的，不仅是直接实施侵害的人，也就是实际击打他的人，还包括以欺诈方式促成侵害，或安排他人用拳头伤害受害人的人。

<!-- source-p 0798 -->
<a id="47.10.11.1"></a>**1**　侵辱之诉以善意公平为基础，权利人若以不作为表示放弃，诉权便消灭。若某人放弃对不法侵害的追究，即在遭受侵害时没有立即放在心上，后来不能又反悔，重新主张该侵害未获宽恕。因此，该诉的公平性意味着：凡有人违反公平原则，均应消除其对该诉的畏惧。由此，若双方就不法侵害达成协议、和解，或要求受害人宣誓，便不再产生侵辱之诉。

<!-- source-p 0799 -->
<a id="47.10.11.2"></a>**2**　当事人既可以亲自提起侵辱之诉，也可以通过他人提起，例如代理人、监护人以及通常代表他人参与诉讼的人。

<!-- source-p 0800 -->
<a id="47.10.11.3"></a>**3**　若有人依我的委任对他人实施不法侵害，多数法学家认为，委任者与受委任实施侵害的人都应承担侵辱之诉的责任。

<!-- source-p 0801 -->
<a id="47.10.11.4"></a>**4**　普罗库鲁斯正确地说，若我雇用你实施不法侵害，我们两人都可被提起侵辱之诉，因为该侵害是通过我的行为实施的：

<!-- source-p 0802 -->
<a id="47.10.11.5"></a>**5**　他还说，即使我命令自己的儿子对你实施不法侵害，也适用同一规则。

<!-- source-p 0803 -->
<a id="47.10.11.6"></a>**6**　阿提利基努斯则说，即使我说服原本不愿意的人，让其听从我而对他人实施不法侵害，也可以对我提起侵辱之诉。

<!-- source-p 0804 -->
<a id="47.10.11.7"></a>**7**　尽管释奴不得对释奴保护人提起侵辱之诉，但释奴的丈夫可以妻子的名义对该释奴保护人起诉；因为丈夫似乎是以自己的名义，就妻子遭受的不法侵害提起诉讼，马尔切鲁斯也承认这一点。不过，我曾批注认为，这不适用于所有不法侵害：为什么释奴保护人不能对已婚的释奴作轻微管教，或说并非淫秽的辱骂之词？若她嫁给另一名释奴，我们会说丈夫绝不能对释奴保护人提起侵辱之诉，许多人也持此见解。由此可见，我们的释奴不仅不能就自己遭受的侵害对我们提起侵辱之诉，也不能就其所关切之人遭受的侵害起诉我们。

<!-- source-p 0805 -->
<a id="47.10.11.8"></a>**8**　但若释奴的儿子或妻子想提起侵辱之诉，由于其父亲或丈夫不能起诉，不应因此拒绝他们；因为他们是以自己的名义起诉。

<!-- source-p 0806 -->
<a id="47.10.11.9"></a>**9**　若有人被称为奴隶，却主张自己是自由人，毫无疑问，他可以对声称自己是其主人的人提起侵辱之诉。无论此人以自由人身份被请求判为奴隶，还是以奴隶身份主张自由，均应适用此规则；我们对此不作区分。

<a id="47.10.13.pr."></a>**序言**　侵辱之诉既不对继承人提起，也不由继承人提起。若不法侵害发生于我的奴隶身上，也适用同一规则：我的继承人不能就此提起侵辱之诉。但争讼程序一经成立，该诉权也会转移给继受人。

<!-- source-p 0813 -->
<a id="47.10.13.1"></a>**1**　行使公法权利的人，不被视为以实施不法侵害为目的行事；因为依法行使权利并不构成不法侵害。

<!-- source-p 0814 -->
<a id="47.10.13.2"></a>**2**　若有人因未遵守裁判官的命令而被拘提，他不能以此为由提起侵辱之诉，因为拘提是依裁判官命令实施的。

<!-- source-p 0815 -->
<a id="47.10.13.3"></a>**3**　若有人为骚扰我而无理地把我传唤到某人的法庭，我可以提起侵辱之诉。

<!-- source-p 0816 -->
<a id="47.10.13.4"></a>**4**　若有人阻止为他人授予荣誉，例如不准为某人树立肖像或授予其他类似荣誉，是否应承担侵辱之诉的责任？拉贝奥说，即使此人是出于侮辱目的，也不承担责任；因为出于侮辱目的而实施某事，与不准许他人为某人授予荣誉，大不相同。

<!-- source-p 0817 -->
<a id="47.10.13.5"></a>**5**　拉贝奥还写道，若某项使节职责本应由他人承担，市政官员却把这项负担强加给另一人，则不得仅因被加派了劳务而提起侵辱之诉；因为加派劳务与实施不法侵害是两回事。其他不法强加的义务和荣誉也应适用同一规则。因此，若某人不公正地作出判决，也应作相同处理。

<!-- source-p 0818 -->
<a id="47.10.13.6"></a>**6**　官员依职权实施的行为，不属于侵辱之诉的范围。

<!-- source-p 0819 -->
<a id="47.10.13.7"></a>**7**　若有人禁止我在海上捕鱼，或拖曳渔网（希腊语称 *sagēnē*），我能否通过侵辱之诉起诉他？有人认为我可以提起该诉；庞波尼及多数法学家也认为，这与禁止他人在公共浴场洗浴、在公共剧场就座，或在其他公共地点活动、坐卧、交往，或者不准他人使用其自己的财物相同；实施此类禁止的人也可以被起诉。古代法学家曾向公共承租人提供禁令，若其确实承租了该项公共权利，就应禁止他人以暴力妨碍其享受租赁权。但若我禁止他人在我的房屋或法庭前捕鱼，该如何处理？我是否承担侵辱之诉责任？海洋与海岸，如同空气一样，为所有人共有；敕答也屡次指出，不得禁止他人捕鱼；同样不得禁止他人捕鸟，除非其进入他人的土地。但人们仍沿袭了禁止他人在我房屋或法庭前捕鱼的做法，尽管此做法没有法律依据；因此，若有人被如此禁止，仍可提起侵辱之诉。不过，在属于我所有的湖泊中，我当然可以禁止他人捕鱼。

<a id="47.10.15"></a>**47.10.15**

乌尔比安《告示评注》第77卷。

<!-- source-p 0825 -->
<a id="47.10.15.pr."></a>**序言**　拉贝奥还讨论：若有人用药物或其他方法使他人精神失常，是否可以提起侵辱之诉？他说，可以对该人提起侵辱之诉。

<!-- source-p 0826 -->
<a id="47.10.15.1"></a>**1**　若某人没有被殴打，但有人多次向他举起手，威吓他仿佛要殴打他，却始终没有动手，则该人应承担准侵辱之诉的责任。

<!-- source-p 0827 -->
<a id="47.10.15.2"></a>**2**　裁判官说：“若有人被指称违背善良风俗辱骂他人，或促使他人违背善良风俗辱骂某人，我将对其准许诉讼。”

<!-- source-p 0828 -->
<a id="47.10.15.3"></a>**3**　拉贝奥说，聚众喧骂构成不法侵害。

<!-- source-p 0829 -->
<a id="47.10.15.4"></a>**4**　*Convicium* 一词或源于众人聚集，或源于众声汇合。多人一同发声，便称为 *convicium*，仿佛是“共同发声”。

<!-- source-p 0830 -->
<a id="47.10.15.5"></a>**5**　裁判官加上“违背善良风俗”一语，表明他并非要惩处所有聚众喧哗，而只惩处为善良风俗所不容、并意在损害某人名誉或使其蒙受非议的喧哗。

<!-- source-p 0831 -->
<a id="47.10.15.6"></a>**6**　裁判官所说“违背善良风俗”，并非指行为人自己的道德标准，而应一般地理解为违背本城邦的善良风俗。

<!-- source-p 0832 -->
<a id="47.10.15.7"></a>**7**　拉贝奥写道，聚众喧骂既可以针对在场者，也可以针对不在场者。因此，若有人趁你不在场来到你家门前辱骂你，也构成聚众喧骂。在营业场所或店铺前发生的情形，也应作同样认定。

<!-- source-p 0833 -->
<a id="47.10.15.8"></a>**8**　实施聚众喧骂的，不仅是高声叫喊的人，也包括煽动他人叫喊或派人前来叫喊的人。

<!-- source-p 0834 -->
<a id="47.10.15.9"></a>**9**　告示特别加上“某人”一语并非没有原因；若聚众喧骂针对不确定的人，就无法追诉。

<!-- source-p 0835 -->
<a id="47.10.15.10"></a>**10**　若有人安排辱骂某人，但辱骂最终并未发生，该人不承担责任。

<!-- source-p 0836 -->
<a id="47.10.15.11"></a>**11**　由此可见，并非一切辱骂之词都构成聚众喧骂；只有伴随高声叫喊而说出的话，

<!-- source-p 0837 -->
<a id="47.10.15.12"></a>**12**　无论由一人还是多人说出，只要是在聚众场合说出，就构成聚众喧骂；若并非聚众而言，也没有高声叫喊，就不严格属于聚众喧骂，而是出于损害名誉的目的说出的言词。

<!-- source-p 0838 -->
<a id="47.10.15.13"></a>**13**　若有人向占卜师或承诺从事非法占卜的人咨询，而对方将并非盗窃者的人说成盗窃者，不能对其提起侵辱之诉，但应依皇帝敕令追究其责任。

<!-- source-p 0839 -->
<a id="47.10.15.14"></a>**14**　因聚众喧骂而产生的侵辱之诉，不应针对继承人提起，也不由继承人提起。

<!-- source-p 0840 -->
<a id="47.10.15.15"></a>**15**　若有人称呼一群女子为处女，但她们穿着奴婢的服装，其行为似乎较轻；若女子穿着妓女的服装，而非家母的服装，则更加如此。〔底本疑误：*vestitae fuissententiarum*，此处有词语粘连，按上下文仅作暂译。〕因此，若女子没有穿着家母的服装，而有人称呼她或带走她的随从，该人仍应承担侵辱之诉的责任。

<!-- source-p 0841 -->
<a id="47.10.15.16"></a>**16**　“随从”应理解为陪同、跟随某人的人；依拉贝奥所说，无论其是自由人还是奴隶、男性还是女性，均可成为随从。拉贝奥这样定义随从：“为经常陪伴某人而被安排跟随其左右的人，无论其在公共场所还是私人场所被带走，均属此类。”随从当然也包括家庭教师。

<!-- source-p 0842 -->
<a id="47.10.15.17"></a>**17**　拉贝奥说，只有当一个人最终使随从不再与其同行，才算“带走随从”；仅仅开始带走还不够。

<!-- source-p 0843 -->
<a id="47.10.15.18"></a>**18**　所谓“带走”，不仅包括以暴力带走，也包括劝说随从离开其所陪同之人。

<!-- source-p 0844 -->
<a id="47.10.15.19"></a>**19**　不仅带走随从的人受本告示约束，称呼或尾随随从所陪伴之人的，也受本告示约束。

<!-- source-p 0845 -->
<a id="47.10.15.20"></a>**20**　“称呼”是指以言辞温和的方式侵犯他人的贞操；这不属于聚众喧骂，而是违背善良风俗的侵犯行为。

<!-- source-p 0846 -->
<a id="47.10.15.21"></a>**21**　使用猥亵言语的人，并非企图侵犯他人的贞操，但仍须承担侵辱之诉的责任。

<!-- source-p 0847 -->
<a id="47.10.15.22"></a>**22**　“称呼”与“尾随”不同：称呼是以言语侵犯他人的贞操，尾随则是沉默地反复跟随。持续频繁的跟随本身便可能使人蒙受某种恶名。

<!-- source-p 0848 -->
<a id="47.10.15.23"></a>**23**　应当记住，并非所有尾随者或称呼者都可以依本告示起诉；若有人出于玩笑或礼貌行事，便不会立即落入告示范围。只有违背善良风俗行事者才受其约束。

<!-- source-p 0849 -->
<a id="47.10.15.24"></a>**24**　我认为未婚夫也应获准提起侵辱之诉，因为凡发生在其未婚妻身上的侵害，都关系到对他的侮辱。

<!-- source-p 0850 -->
<a id="47.10.15.25"></a>**25**　裁判官说：“不得实施任何意在损害他人名誉的行为。若有人违反此禁令，我将依具体情形予以处理。”

<!-- source-p 0851 -->
<a id="47.10.15.26"></a>**26**　拉贝奥说，这项告示多余，因为我们可以依据一般的不法侵害规则起诉。但拉贝奥本人似乎也承认（事实确实如此），裁判官出于同一理由，仍希望特别规定此事；因为对特别显著的行为，若未作专门规定，便容易显得仿佛遭到忽视。

<!-- source-p 0852 -->
<a id="47.10.15.27"></a>**27**　裁判官一般性地禁止实施任何损害他人名誉的行为。因此，凡有人为损害他人名誉而实施任何行为或说出任何言词，均可提起侵辱之诉。通常，为损害名誉而实施的行为包括：穿着哀服或污秽的衣服以引起他人对某人的恶感，蓄长胡须或留长发，或者创作、张贴、演唱伤害某人名誉的诗歌。

<!-- source-p 0853 -->
<a id="47.10.15.28"></a>**28**　裁判官所说“若有人违反该禁令，我将依具体情形处理”，应理解为裁判官可以更充分地行使裁量权：无论是原告、被告的身份，还是行为本身及侵害的性质，凡令裁判官认为有理由不受理原告请求的情形，均可据此决定。

<!-- source-p 0854 -->
<a id="47.10.15.29"></a>**29**　帕皮尼安说，若有人向皇帝或其他人递交请愿书，借此攻击他人名誉，应提起侵辱之诉。

<!-- source-p 0855 -->
<a id="47.10.15.30"></a>**30**　帕皮尼安还说，若某人把仿佛能够影响判决结果一事拿来出售，索取金钱作为交换，总督用杖击处罚此人后，应视为其已因不法侵害被判有罪。显然，他确实侵害了其兜售判决结果之人的名誉。

<!-- source-p 0856 -->
<a id="47.10.15.31"></a>**31**　若有人以不法方式占有他人的全部财产或某一项物品，应承担侵辱之诉的责任。

<!-- source-p 0857 -->
<a id="47.10.15.32"></a>**32**　塞尔维乌斯说，若有人声称自己从我处取得质物，张贴公告要将其出售，目的在于损害我的名誉，可以提起侵辱之诉。

<!-- source-p 0858 -->
<a id="47.10.15.33"></a>**33**　若有人为了实施不法侵害，称未负债的人为债务人，该人应承担侵辱之诉的责任。

<!-- source-p 0859 -->
<a id="47.10.15.34"></a>**34**　裁判官说：“若有人被指称违背善良风俗殴打他人的奴隶，或未经主人许可对该奴隶施以刑讯，我将准许对其提起诉讼。若被指称实施了其他行为，我将审查具体情形后再准许诉讼。”

<!-- source-p 0860 -->
<a id="47.10.15.35"></a>**35**　若有人以侮辱主人为目的侵害奴隶，我认为主人可以自己的名义提起侵辱之诉。若行为人并非为了羞辱主人而为，则不应让奴隶本人遭受的侵害不受裁判官救济，尤其是以鞭打或刑讯方式实施的侵害；显然，奴隶本人也能感受到这类行为。

<!-- source-p 0861 -->
<a id="47.10.15.36"></a>**36**　若有人殴打共有奴隶，不承担本诉责任，因为其行为属于所有权人权利的行使。

<!-- source-p 0862 -->
<a id="47.10.15.37"></a>**37**　若用益权人实施了殴打，所有权人不得起诉他；若所有权人实施了殴打，用益权人也不得起诉所有权人。

<!-- source-p 0863 -->
<a id="47.10.15.38"></a>**38**　告示加上“违背善良风俗”这一限定，意味着并非所有殴打奴隶者都承担责任，只有违背善良风俗殴打者才承担责任；若行为人是为了纠正或管教奴隶，则不承担责任。

<!-- source-p 0864 -->
<a id="47.10.15.39"></a>**39**　因此，拉贝奥问：若市政官员用皮鞭抽打我的奴隶，我能否以其违背善良风俗殴打为由起诉？他说，法官应查明我的奴隶当时在做什么，官员为何殴打他；若奴隶傲慢地要求荣誉和职位标志而遭殴打，则应判官员无罪。

<!-- source-p 0865 -->
<a id="47.10.15.40"></a>**40**　“殴打”一词也可以宽泛地包括用拳头击打。

<!-- source-p 0866 -->
<a id="47.10.15.41"></a>**41**　“刑讯”应理解为为了查明真相而施加的拷打和身体痛苦。仅仅询问，或轻微威吓，不属于该告示所指的刑讯。“刑讯”一词也包括所谓恶劣拘禁。因此，只有以暴力和酷刑进行讯问，才属于这里所说的刑讯。

<!-- source-p 0867 -->
<a id="47.10.15.42"></a>**42**　拉贝奥说，即使有人依主人命令实施刑讯，若超出限度，也应承担责任。

<!-- source-p 0868 -->
<a id="47.10.15.43"></a>**43**　裁判官说：“若有人被指称实施了其他行为，我将审查具体情形后再准许诉讼。”因此，若奴隶遭到殴打或被刑讯，无须审查具体情形即可起诉行为人；若奴隶遭受其他侵害，则只有在审查具体情形后方可起诉。

<!-- source-p 0869 -->
<a id="47.10.15.44"></a>**44**　因此，裁判官并非在所有不法侵害案件中都承诺准许以奴隶名义起诉：若奴隶仅被轻微击打或轻微辱骂，裁判官不会准许诉讼。但若有人以行为或书写诗歌损害奴隶名誉，我认为裁判官审查具体情形时，还应考量奴隶的身份与品性；因为奴隶的类型大有区别：他可能是品行良好者、家内奴隶或管事，也可能只是普通奴隶、杂役，或其他任何身份的人。若奴隶戴着镣铐、名声恶劣或恶劣至极，又该如何处理？因此，裁判官既要考量所称侵害的性质，也要考量据称遭受侵害的奴隶身份，再决定准许或拒绝诉讼。

<!-- source-p 0870 -->
<a id="47.10.15.45"></a>**45**　奴隶遭受的侵害有时会转而影响主人，有时则不会。若奴隶表现得像自由人，或行为人误以为该奴隶属于他人而非我所有，且若知道其属于我就不会殴打他，梅拉写道，不能以其侵害了我的名义起诉。

<!-- source-p 0871 -->
<a id="47.10.15.46"></a>**46**　若有人就奴隶遭殴打提起侵辱之诉，后来又提起因不法造成损害之诉，拉贝奥写道，两者并非同一事项：前一诉针对侮辱，后一诉则针对因过失造成的损害。

<!-- source-p 0872 -->
<a id="47.10.15.47"></a>**47**　若我对奴隶享有用益权，而你殴打了该奴隶或对其刑讯，提起侵辱之诉的权利更属于所有权人，而非我。若你殴打了我善意占有的他人奴隶，也应作同样认定：侵辱之诉更属于所有人。

<!-- source-p 0873 -->
<a id="47.10.15.48"></a>**48**　若有人殴打一个善意为我服役的自由人，应区分处理：若殴打是为了侮辱我，我便享有侵辱之诉。对善意为我服役的他人奴隶，也应如此处理：只有当对奴隶的侵害旨在侮辱我时，才准许我提起侵辱之诉。奴隶本人遭受侵害时，我们会准许主人提起侵辱之诉；若侵害也针对我，我同样可以提起该诉。用益权人的情形也可作同样区分。

<!-- source-p 0874 -->
<a id="47.10.15.49"></a>**49**　若我殴打了数人共有的奴隶，显然所有共有人均享有侵辱之诉：

<a id="47.10.17"></a>**47.10.17**

<!-- source-p 0879 -->
乌尔比安《告示评注》第57卷。

<!-- source-p 0880 -->
<a id="47.10.17.pr."></a>**序言**　但若我是在其中一名共有人许可下实施殴打，且以为奴隶仅属于该人，则无人享有侵辱之诉。若我知道奴隶属于数人，则许可我殴打的共有人不享有诉权，其他共有人则享有。

<!-- source-p 0881 -->
<a id="47.10.17.1"></a>**1**　若刑讯是在监护人、代理人或保佐人的命令下实施，应当认为侵辱之诉不成立。

<!-- source-p 0882 -->
<a id="47.10.17.2"></a>**2**　我的奴隶因你的控告或申诉，被我们的官员用鞭子打伤。梅拉认为，我可以对你提起侵辱之诉，金额由法官酌情确定；若奴隶因此死亡，拉贝奥说，其主人也可以起诉，因为该诉针对的是不法行为造成的损害。特雷巴提乌斯也认可此说。

<!-- source-p 0883 -->
<a id="47.10.17.3"></a>**3**　自由人实施的某些不法侵害似乎较轻，虽并非毫无影响；但由奴隶实施时就显得严重得多，因为侵害的侮辱程度会随着实施侮辱者的身份而加重。

<!-- source-p 0884 -->
<a id="47.10.17.4"></a>**4**　奴隶实施不法侵害，显然构成私犯。因此，正如其他私犯一样，也应准许针对该奴隶提起诺克萨诉讼。但主人可以选择是否将奴隶交出供受害人鞭打，以此作为赔偿；主人并非必须交出奴隶供鞭打，而是可以选择交出奴隶接受鞭打；若鞭打仍不足以使受害人满意，主人还可以交出奴隶承担诺克萨责任，或者支付诉讼估定的金额。

<!-- source-p 0885 -->
<a id="47.10.17.5"></a>**5**　裁判官说“由法官裁量”，显然是指按照善良家父的标准，由法官确定适当的鞭打程度。

<!-- source-p 0886 -->
<a id="47.10.17.6"></a>**6**　若主人在法官面前交出奴隶供鞭打，以使受害人获得满足，且鞭打符合某人的裁量；此后原告仍坚持提起侵辱之诉，就不应受理。已经得到满足的人，视为放弃了自己的侵害请求。即使受害人只是自愿放弃侵害请求，也毫无疑问会使侵辱之诉消灭，正如经过期间后该侵害不再可诉。

<!-- source-p 0887 -->
<a id="47.10.17.7"></a>**7**　若奴隶依主人命令实施不法侵害，当然可以以主人自己的名义起诉主人。但若奴隶已被解放，拉贝奥认为可以对该奴隶本人提起诉讼，因为诺克萨责任随行为人之身而转移；奴隶并非在所有事项上都必须服从主人。反之，若奴隶依主人命令杀人，我们会依据《科尔内利亚法》使其免责。

<!-- source-p 0888 -->
<a id="47.10.17.8"></a>**8**　但若奴隶是为了保护主人而实施某行为，显然其行为具有正当理由；对此类诉讼，应向原告提出抗辩。

<!-- source-p 0889 -->
<a id="47.10.17.9"></a>**9**　若我对某奴隶享有用益权，而该奴隶侵害了我，我可以针对其主人提起诺克萨诉讼；不能因为我享有用益权，便使我的处境反而比不享有用益权时更差。共有奴隶则不同：此时我们不会准许一名共有人起诉另一名共有人，因为该共有人自己也应承担侵辱之诉的责任。

<!-- source-p 0890 -->
<a id="47.10.17.10"></a>**10**　裁判官说：“若有人被指称遭受不法侵害，而其受他人权力支配，且掌权人不在场，也没有任何代理人代表其起诉，我将在审查具体情形后，准许据称遭受侵害的人本人提起诉讼。”

<!-- source-p 0891 -->
<a id="47.10.17.11"></a>**11**　若家子遭受不法侵害，其父虽在场，却因精神失常或其他类似原因无法起诉，我认为家子享有侵辱之诉；在这种情况下，父亲应视为不在场。

<!-- source-p 0892 -->
<a id="47.10.17.12"></a>**12**　但若父亲在场而不愿起诉，无论是打算延迟起诉，还是宽恕并放弃该侵害，较妥当的意见是不给予儿子诉权。儿子在父亲不在场时之所以可以起诉，是因为可以推断，父亲若在场也会起诉。

<!-- source-p 0893 -->
<a id="47.10.17.13"></a>**13**　不过，有时即使父亲放弃诉讼，我们仍认为应给予儿子侵辱之诉；例如，父亲身份卑微而儿子身份尊贵。身份极其低下的父亲不应以自己的卑微衡量对儿子的侮辱。假设父亲的状况严重到裁判官有正当理由为其指定保佐人，也应如此处理。

<!-- source-p 0894 -->
<a id="47.10.17.14"></a>**14**　但若父亲在争讼程序确定后开始不在场，或怠于执行判决，且父亲身份卑微，则应在审查具体情形后，准许诉权移转给儿子。若儿子已被解放，也应作同样处理。

<!-- source-p 0895 -->
<a id="47.10.17.15"></a>**15**　裁判官优先考虑父亲的代理人，而非遭受侵害的人本人。但若代理人疏忽、串通，或无力对抗实施侵害的人，则应由遭受侵害者本人提起侵辱之诉。

<!-- source-p 0896 -->
<a id="47.10.17.16"></a>**16**　所谓代理人，不一定是专门受委任提起侵辱之诉的人；只要某人受委任管理全部事务就已足够。

<!-- source-p 0897 -->
<a id="47.10.17.17"></a>**17**　裁判官说，经过审查具体情形后，才准许据称遭受侵害者本人起诉。此项审查应考量父亲离开有多远、何时会回来，以及想提起侵辱之诉的人是否过于怠惰或无能，以致无法胜任其所管理的事务，因而也无法胜任诉讼。

<!-- source-p 0898 -->
<a id="47.10.17.18"></a>**18**　裁判官所说“遭受不法侵害的人”，有时也应理解为其父亲享有诉权。例如，孙子遭受不法侵害，父亲在场而祖父不在场；尤利安写道，应将侵辱之诉给予父亲，而非孙子，因为即使祖父尚在世，保护儿子的一切事务也属于父亲的职责。

<!-- source-p 0899 -->
<a id="47.10.17.19"></a>**19**　尤利安还写道，儿子不仅可以亲自起诉，也可以指定代理人；否则，若儿子因疾病无法行动，又无人能够提起侵辱之诉，诉权便会受到阻碍。

<!-- source-p 0900 -->
<a id="47.10.17.20"></a>**20**　尤利安还说，若孙子遭受不法侵害，但无人能以祖父名义起诉，应准许父亲提起诉讼，且父亲可以指定代理人。所有以自己名义享有诉权的人，都应有权指定代理人。尤利安说，儿子被视为以自己名义起诉，是因为在父亲不作为时，裁判官准许儿子本人提起诉讼。

<!-- source-p 0901 -->
<a id="47.10.17.21"></a>**21**　若家子提起侵辱之诉，父亲不因此取得诉权。

<!-- source-p 0902 -->
<a id="47.10.17.22"></a>**22**　尤利安还说，只要无人以父亲名义起诉，就应准许家子以不法侵害为由起诉；在此情形下，家子仿佛被视为家父。因此，即使家子已被解放、仅被指定为部分继承人、被剥夺继承权，或放弃父亲的遗产，也应将诉讼的后续执行权交给他。若裁判官既已认可，在父权仍存续时应准许家子起诉，却又剥夺其作为家父追究不法侵害的权利，将诉权转给父亲——而父亲已尽其所能弃置了儿子——甚至更不合理地转给父亲的继承人，就十分荒谬；毫无疑问，父亲的继承人并不承受针对家子的侵害。

## D.47.11　论非常程序追诉的犯罪（*De extraordinariis criminibus*）

<!-- source-p 0994 -->
<a id="11"></a><a id="47.11"></a>**47.11.0**　论非常程序追诉的犯罪。

<!-- source-p 0995 -->
<a id="47.11.1"></a>**47.11.1**

<!-- source-p 0996 -->
保罗《判例》第5卷。

<!-- source-p 0997 -->
<a id="47.11.1.pr."></a>**序言**　诱使他人破坏婚姻，或干预他人婚姻关系的人，即使未能达到犯罪目的，也会因其恶劣的淫欲意图而受非常程序处罚。

<!-- source-p 0998 -->
<a id="47.11.1.1"></a>**1**　违背善良风俗的侵害包括：有人将粪便泼向他人，以污泥或烂泥涂抹他人，污染水源、输水管、水池或其他公共设施。此类行为通常会受到严厉惩处。

<!-- source-p 0999 -->
<a id="47.11.1.2"></a>**2**　有人引诱少年，与其发生性关系，或把少年带走、诱使其随从堕落；有人勾引妇女或少女，或为不贞行为作出其他安排，提供住所或金钱以劝诱其为非作歹；若其犯罪既遂，应处死刑；未遂则流放至岛屿。腐蚀少年随从者应受最严厉的刑罚。

## D.47.12　论侵害坟墓（*De sepulchro violato*）

<!-- source-p 1032 -->
<a id="12"></a><a id="47.12"></a>**47.12.0**　论侵害坟墓。

<!-- source-p 1033 -->
<a id="47.12.1"></a>**47.12.1**

<!-- source-p 1034 -->
乌尔比安《裁判官告示评注》第2卷。

<!-- source-p 1035 -->
侵害坟墓之诉会导致不名誉后果。

<!-- source-p 1036 -->
<a id="47.12.2"></a>**47.12.2**

<!-- source-p 1037 -->
乌尔比安《裁判官告示评注》第18卷。

<!-- source-p 1038 -->
若有人拆毁坟墓，《阿奎利亚法》之诉不再适用，但仍可提起“以暴力或秘密方式造成损害”之诉；凯尔苏斯对从墓碑上拆下雕像也作同样论述。他还讨论，若雕像既未用铅固定也未钉牢，是否因此成为墓的一部分，还是仍属于我们的财产；凯尔苏斯写道，它与骨灰瓮一样属于墓的一部分，因此可以适用“以暴力或秘密方式造成损害”禁令。

<!-- source-p 1039 -->
<a id="47.12.3"></a>**47.12.3**

<!-- source-p 1040 -->
乌尔比安《裁判官告示评注》第25卷。

<!-- source-p 1041 -->
<a id="47.12.3.pr."></a>**序言**　裁判官说：“若有人被指称以恶意欺诈侵害坟墓，我将准许对其提起事实诉讼，并判令其向相关权利人支付依具体情形认为公平的金额。若没有相关权利人，或权利人不愿起诉，我将准许任何愿意起诉的人请求一百奥里金币。若有数人愿意起诉，我将准许最有正当理由者起诉。若有人以恶意欺诈居住在坟墓内，或在其中设置非为墓葬目的而建造的其他建筑，任何人愿意就此起诉的，我将准许其请求二百奥里金币。”

<!-- source-p 1042 -->
<a id="47.12.3.1"></a>**1**　告示的开头表明，只有以恶意欺诈侵害坟墓的人才受其处罚。因此，若不存在故意，该诉便不成立。没有欺诈能力的人，例如年幼的未适婚人，以及所有并非出于侵害目的而进入坟墓的人，均可免责。

<!-- source-p 1043 -->
<a id="47.12.3.2"></a>**2**　“坟墓”一词应理解为涵盖所有用于埋葬的地点。

<!-- source-p 1044 -->
<a id="47.12.3.3"></a>**3**　若有人将遗体葬入家族共有的坟墓，即使其本人是继承人，若此举违背遗嘱人的意思，也仍可能承担侵害坟墓之诉的责任。遗嘱人可以禁止他人葬入其墓；安敦尼皇帝的敕答确认了这一点，因为应尊重遗嘱人的意愿。因此，即使遗嘱人规定只有一名继承人可以葬入，也应遵守该规定，仅准该继承人葬入。

<!-- source-p 1045 -->
<a id="47.12.3.4"></a>**4**　神圣的塞维鲁皇帝以敕令规定，未被永久用于埋葬的遗体可以迁移；敕令还命令不得扣留或骚扰遗体，也不得禁止其经过城镇辖区运送。神圣的马尔库斯皇帝则以敕答指出，途中经村镇运送死者遗体的人不应受罚；不过，未经有权准许的人许可，不得如此行事。

<!-- source-p 1046 -->
<a id="47.12.3.5"></a>**5**　神圣的哈德良皇帝以敕答规定，对在城市内埋葬的人处以四十奥里金币罚款，并命令将该款缴入国库；允许埋葬的官员也受同一处罚，埋葬地点应收归公有，遗体则应迁出。但若市政法允许在城市内埋葬，该如何处理？我们将考察，皇帝敕答作出后，是否已不再允许这种做法；因为这些敕答具有普遍适用性，皇帝的规定应具有效力并在所有地方施行。

<!-- source-p 1047 -->
<a id="47.12.3.6"></a>**6**　若有人居住在坟墓内或在其中设置建筑，任何愿意起诉的人均可提起诉讼。

<!-- source-p 1048 -->
<a id="47.12.3.7"></a>**7**　总督应更严厉地惩治盗掘遗体的人，尤其是持械袭击者。神圣的塞维鲁皇帝以敕答说，若他们持械如同强盗般行事，甚至应处以死刑；若未持械，则应处罚至矿场劳役。

<!-- source-p 1049 -->
<a id="47.12.3.8"></a>**8**　审理侵害坟墓之诉的法官应估算原告的利益，考量所受侵害、侵害者的获利、实际造成的损害，以及行为人的鲁莽程度；但判决金额不得低于由无利害关系的第三人起诉时通常判处的金额。

<!-- source-p 1050 -->
<a id="47.12.3.9"></a>**9**　若数人共同享有坟墓权利，我们应将诉权给予所有人，还是仅给予实际起诉者？拉贝奥正确地说，应给予所有人，因为诉讼涉及各自的个人利益。

<!-- source-p 1051 -->
<a id="47.12.3.10"></a>**10**　若对侵害坟墓享有利益的人原先不愿起诉，在他人使诉讼系属成立之前，他可以改变主意，表示自己愿意起诉；其请求应获受理。

<!-- source-p 1052 -->
<a id="47.12.3.11"></a>**11**　若奴隶居住在坟墓内或在其中建造房屋，则不再适用诺克萨诉讼，裁判官承诺可直接对该奴隶提起本诉。但若奴隶并未居住其中，只是在那里有一间小屋，且看来有能力占有该屋，则应准许诺克萨诉讼。

<!-- source-p 1053 -->
<a id="47.12.3.12"></a>**12**　本诉属于任何人均可提起的公益诉讼。

## D.47.14　论盗驱牲畜（*De abigeis*）

<!-- source-p 1085 -->
<a id="14"></a><a id="47.14"></a>**47.14.0**　论盗驱牲畜。

<!-- source-p 1086 -->
<a id="47.14.1"></a>**47.14.1**

<!-- source-p 1087 -->
乌尔比安《总督职务》第8卷。

<!-- source-p 1088 -->
<a id="47.14.1.pr."></a>**序言**　神圣的哈德良皇帝在贝提卡行省议事会上就惩治盗驱牲畜者作出如下敕答：“盗驱牲畜者受到最严厉处罚时，通常会被判处死刑。但并非各地都适用最严厉的刑罚，只有此类犯罪较为频繁的地方才如此；其他地方则会判处劳役，有时也只判处限期劳役。”

<!-- source-p 1089 -->
<a id="47.14.1.1"></a>**1**　严格而言，盗驱牲畜者是指从牧场或畜群中赶走牲畜，近乎公开掠夺，并将盗驱牲畜作为专门行当的人，例如从马群中赶走马匹，或从牛群中赶走牛只。反之，若有人赶走一头走失的牛，或赶走遗弃在荒野的马匹，其身份更接近盗贼，而非盗驱牲畜者。

<!-- source-p 1090 -->
<a id="47.14.1.2"></a>**2**　若有人赶走一头母猪、山羊或公绵羊，其处罚应轻于赶走大型牲畜的人。

<!-- source-p 1091 -->
<a id="47.14.1.3"></a>**3**　尽管哈德良规定了矿场劳役、公共劳役乃至死刑，但出身较为尊贵的人不应受这些刑罚；他们应被流放，或被剥夺其身份等级。若盗驱牲畜者持械作案，将其投入兽群也并非不公。

<!-- source-p 1092 -->
<a id="47.14.1.4"></a>**4**　若有人赶走牲畜，但对牲畜所有权存在争议，萨图尔尼努斯写道，应将其交由民事审理。但只有在行为人确实基于正当理由相信牲畜属于自己，而非假借权属争议掩饰盗驱行为时，才应如此处理。

<!-- source-p 1093 -->
<a id="47.14.2"></a>**47.14.2**

<!-- source-p 1094 -->
马凯尔《公诉》第1卷。

<!-- source-p 1095 -->
盗驱牲畜罪不属于公诉，因为其本质更接近盗窃。但盗驱者通常携带武器，因此一经抓获，往往会受到严厉处罚。

<!-- source-p 1096 -->
<a id="47.14.3"></a>**47.14.3**

<!-- source-p 1097 -->
卡利斯特拉《裁判》第6卷。

<!-- source-p 1098 -->
<a id="47.14.3.pr."></a>**序言**　应根据被赶走的绵羊数量，区分普通盗贼与盗驱牲畜者。有人认为十只绵羊才构成一群；若赶走五只或四只猪，或一匹马、一头牛，也可构成盗驱牲畜罪。

<!-- source-p 1099 -->
<a id="47.14.3.1"></a>**1**　若有人从畜栏中赶走已驯养的牲畜，而非从森林或畜群中赶走，也应对其从严惩治。

<!-- source-p 1100 -->
<a id="47.14.3.2"></a>**2**　若有人多次实施盗驱，即使每次只偷走一头或两头牲畜，也仍属于盗驱牲畜者。

<!-- source-p 1101 -->
<a id="47.14.3.3"></a>**3**　神圣的图拉真皇帝以书信规定，应将窝藏盗驱牲畜者的人流放至意大利以外地区十年。

## D.47.15　论串通妨碍追诉（*De praevaricatione*）

<!-- source-p 1102 -->
<a id="15"></a><a id="47.15"></a>**47.15.0**　论串通妨碍追诉。

<!-- source-p 1103 -->
<a id="47.15.1"></a>**47.15.1**

<!-- source-p 1104 -->
乌尔比安《裁判官告示评注》第6卷。

<!-- source-p 1105 -->
<a id="47.15.1.pr."></a>**序言**　*Praevaricator*（串通妨碍追诉者）近似于“反复改变立场的人”，指背弃自己的案件、转而帮助对方的人。拉贝奥说，该名称源于双方交替争辩；因为串通妨碍追诉者站在两方之间，甚至转到另一方。

<!-- source-p 1106 -->
<a id="47.15.1.1"></a>**1**　严格而言，只有在公诉案件中提出控告的人，才称为串通妨碍追诉者；辩护人并不严格属于此类。那么，对辩护人应如何处理？无论其在私诉还是公诉中背弃自己的案件、帮助对方，通常都应依非常程序处罚。

<!-- source-p 1107 -->
<a id="47.15.2"></a>**47.15.2**

<!-- source-p 1108 -->
乌尔比安《总督职务》第9卷。

<!-- source-p 1109 -->
应知悉，现今串通妨碍追诉者通常受非常程序处罚。

<!-- source-p 1110 -->
<a id="47.15.3"></a>**47.15.3**

<!-- source-p 1111 -->
马凯尔《公诉》第1卷。

<!-- source-p 1112 -->
<a id="47.15.3.pr."></a>**序言**　追究串通妨碍追诉行为的诉讼，一种属于公诉，另一种则是依惯例形成的程序。

<!-- source-p 1113 -->
<a id="47.15.3.1"></a>**1**　若被告在公诉案件中提出抗辩，称自己此前已因同一罪名被他人控告并获判无罪，《尤利亚公诉法》规定，在先前控告者被认定串通妨碍追诉、且法院作出判决之前，不得再次控告被告。因此，对前一控告者的串通妨碍追诉行为所作判决，属于公诉程序。

<!-- source-p 1114 -->
<a id="47.15.3.2"></a>**2**　若控告辩护人串通妨碍追诉，则不属于公诉；无论被指称在公诉还是私诉中实施该行为，均不影响这一点。

<!-- source-p 1115 -->
<a id="47.15.3.3"></a>**3**　若有人因被指称放弃公诉案件而遭控告，该诉讼不属于公诉，因为没有法律就此作出规定；元老院虽决议对放弃案件者处以五磅黄金的罚金，但并未因此设立公诉。

<!-- source-p 1116 -->
<a id="47.15.4"></a>**47.15.4**

<!-- source-p 1117 -->
马凯尔《公诉》第2卷。

<!-- source-p 1118 -->
若某人被禁止以诬告罪起诉，却在公诉案件中被判定串通妨碍追诉，则其将被列为不名誉者。

<!-- source-p 1119 -->
<a id="47.15.5"></a>**47.15.5**

<!-- source-p 1120 -->
维努莱乌·萨图尔尼努《公诉》第2卷。

<!-- source-p 1121 -->
控告人因串通妨碍追诉而被判有罪后，不得再依据法律提出控告。

<!-- source-p 1122 -->
<a id="47.15.6"></a>**47.15.6**

<!-- source-p 1123 -->
保罗《公诉单篇》。

<!-- source-p 1124 -->
我们的皇帝与其父亲曾作出敕答：对于非常程序追诉的犯罪，串通妨碍追诉者应受与被告若非因该串通行为获判无罪、而由其本人实施犯罪时相同的刑罚。

<!-- source-p 1125 -->
<a id="47.15.7"></a>**47.15.7**

<!-- source-p 1126 -->
乌尔比安《人口调查》第4卷。

<!-- source-p 1127 -->
除涉及人命的案件外，依元老院决议，贿赂告发人的人被视为败诉。

## D.47.16　论窝藏者（*De receptatoribus*）

<!-- source-p 1128 -->
<a id="16"></a><a id="47.16"></a>**47.16.0**　论窝藏者。

<!-- source-p 1129 -->
<a id="47.16.1"></a>**47.16.1**

<!-- source-p 1130 -->
马尔基安《公诉》第2卷。

<!-- source-p 1131 -->
窝藏者是最恶劣的一类人；没有他们，盗匪就不可能长期藏匿。因此，法律规定他们应像强盗一样受罚。若有人本可抓捕盗匪，却收受金钱或赃物的一部分后将其放走，也应视为同等情形。

<!-- source-p 1132 -->
<a id="47.16.2"></a>**47.16.2**

<!-- source-p 1133 -->
保罗《平民刑罚单篇》。

<!-- source-p 1134 -->
若盗匪被其姻亲或亲属窝藏，不应将窝藏者完全开释，也不应过度严厉地处罚；因为他们的过错，与窝藏毫无亲属关系的盗匪者并不相同。

## D.47.17　论浴场窃贼（*De furibus balneariis*）

<!-- source-p 1135 -->
<a id="17"></a><a id="47.17"></a>**47.17.0**　论浴场窃贼。

<!-- source-p 1136 -->
<a id="47.17.1"></a>**47.17.1**

<!-- source-p 1137 -->
乌尔比安《总督职务》第8卷。

<!-- source-p 1138 -->
夜间盗贼应由总督以非常程序审理，并在查明案情后予以处罚；但须知处罚不得超过限期公共劳役。浴场窃贼也适用同一规则。若窃贼、破门者或其他类似行为人持械自卫，却没有打伤任何人，则应判处矿场劳役；身份较高者则应流放。

<!-- source-p 1139 -->
<a id="47.17.2"></a>**47.17.2**

<!-- source-p 1140 -->
马尔基安《公诉》第2卷。

<!-- source-p 1141 -->
但若盗窃发生在白天，应依通常法律程序处理。

<!-- source-p 1142 -->
<a id="47.17.3"></a>**47.17.3**

<!-- source-p 1143 -->
保罗《军人刑罚单篇》。

<!-- source-p 1144 -->
在浴场盗窃时被抓获的士兵，应予以不名誉退伍。
