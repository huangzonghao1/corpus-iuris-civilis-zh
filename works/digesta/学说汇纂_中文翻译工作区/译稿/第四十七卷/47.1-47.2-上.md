# D.47.1–D.47.2 论私犯与盗窃（上）

<!-- source-p 0001 -->
<a id="1"></a><a id="47.1"></a>**47.1.0**　论私犯。

<!-- source-p 0002 -->
<a id="47.1.1"></a>**47.1.1**

<!-- source-p 0003 -->
乌尔比安《萨宾评注》第四十一卷。

<!-- source-p 0004 -->
<a id="47.1.1.pr."></a>**序言**　市民法规定，继承人及其他继受人不承担惩罚性诉讼的责任，因此不能对他们提起盗窃之诉。不过，尽管他们不受盗窃之诉追究，若其占有该物，或以欺诈方式使自己不再占有该物，仍可对他们提起展示原物之诉；若其展示该物，也可对其提起所有物返还之诉。此外，也可对其提起返还之诉。

<!-- source-p 0005 -->
<a id="47.1.1.1"></a>**1**　继承人可以提起盗窃之诉，这一点同样明确；因为某些不法行为的诉权可以由继承人行使。例如，继承人也享有《阿奎利亚法》之诉；但继承人不享有侵害之诉。

<!-- source-p 0006 -->
<a id="47.1.1.2"></a>**2**　不仅对于盗窃之诉，对于其他因私犯产生的诉讼，无论其属于市民法还是裁判官法，均适用“诺克萨责任随行为人转移”（*noxa caput sequitur*）的规则。

<!-- source-p 0007 -->
<a id="47.1.2"></a>**47.1.2**

<!-- source-p 0008 -->
乌尔比安《萨宾评注》第四十三卷。

<!-- source-p 0009 -->
<a id="47.1.2.pr."></a>**序言**　数项不法行为同时发生，绝不能使其中任何一项获得免责；一项不法行为不会因为另一项不法行为而减轻其处罚。

<!-- source-p 0010 -->
<a id="47.1.2.1"></a>**1**　因此，某人偷走并杀害一名奴隶：他因盗窃而受盗窃之诉追究，因杀害而受《阿奎利亚法》之诉追究；这两项诉讼互不吸收。

<!-- source-p 0011 -->
<a id="47.1.2.2"></a>**2**　若某人抢夺并杀害他人财物，也应作同样判断：他既受暴力掠夺之诉追究，也受《阿奎利亚法》之诉追究。

<!-- source-p 0012 -->
<a id="47.1.2.3"></a>**3**　有人曾问，若已基于盗窃原因对某人提起返还之诉，是否仍可依《阿奎利亚法》起诉。庞波尼写道，可以，因为《阿奎利亚法》之诉与基于盗窃原因的返还之诉，其估价方式不同：前者包括该物在当年曾达到的最高价值；后者的估价则不追溯到诉讼要式陈述成立的时间以前。不过，若实施这些行为的是奴隶，无论基于哪一项诉讼将其交付作诺克萨责任清偿，另一项诉讼即告消灭。

<!-- source-p 0013 -->
<a id="47.1.2.4"></a>**4**　又如，某人偷走财物后遭鞭打，应同时承担盗窃之诉和侵害之诉；若其又杀害了同一受害人，则应承担三项诉讼。

<!-- source-p 0014 -->
<a id="47.1.2.5"></a>**5**　又如，某人偷走他人的女奴并对她实施淫辱，应同时承担两项诉讼，因为既可提起使奴隶堕落之诉，也可提起盗窃之诉。

<!-- source-p 0015 -->
<a id="47.1.2.6"></a>**6**　又如，某人偷走一名奴隶后又将其打伤，《阿奎利亚法》之诉和盗窃之诉两项诉讼均可提起。

<!-- source-p 0016 -->
<a id="47.1.3"></a>**47.1.3**

<!-- source-p 0017 -->
乌尔比安《论总督职责》第二卷。

<!-- source-p 0018 -->
若某人希望行使因不法行为产生的诉权：若其希望请求金钱赔偿，应将其交由通常司法程序处理，不得强迫他签署刑事控告；但若其希望依非常程序施加该行为的刑罚，则必须签署刑事控告。

<!-- source-p 0019 -->
<a id="2"></a><a id="47.2"></a>**47.2.0**　论盗窃。

<!-- source-p 0020 -->
<a id="47.2.1"></a>**47.2.1**

<!-- source-p 0021 -->
保罗《告示评注》第三十九卷。

<!-- source-p 0022 -->
<a id="47.2.1.pr."></a>**序言**　拉贝奥说，*furtum*（盗窃）一词源自 *furvus*，即“黑暗”，因为盗窃是在隐蔽和黑暗中实施，且通常发生于夜间；萨宾则认为该词源于欺诈；也有人认为源于“搬运、拿走”；又或源于希腊语，他们称窃贼为 *fwras*；希腊人还说 *apo tou ferein fwras*（据称意为“因搬运而为窃贼”）。

<!-- source-p 0023 -->
<a id="47.2.1.1"></a>**1**　因此，仅有实施盗窃的想法，并不会使人成为窃贼。

<!-- source-p 0024 -->
<a id="47.2.1.2"></a>**2**　同样，否认自己受寄存的财物，并不立即构成盗窃；只有其为侵吞该物而将其藏匿时，才构成盗窃。

<!-- source-p 0025 -->
<a id="47.2.1.3"></a>**3**　盗窃是为了牟利而欺诈性地触碰或处分财物；所图利益既可以是取得该物本身，也可以是取得对该物的使用或占有。自然法禁止实施这种行为。

<!-- source-p 0026 -->
<a id="47.2.2"></a>**47.2.2**

<!-- source-p 0027 -->
盖尤斯《告示评注》第十三卷。

<!-- source-p 0028 -->
盗窃分为两类：现行盗窃与非现行盗窃。

<!-- source-p 0029 -->
<a id="47.2.3"></a>**47.2.3**

<!-- source-p 0030 -->
乌尔比安《萨宾评注》第四十一卷。

<!-- source-p 0031 -->
<a id="47.2.3.pr."></a>**序言**　现行窃贼，是希腊人所称的 *ep' autofwrw*，也就是在实施盗窃时被抓获的人。

<!-- source-p 0032 -->
<a id="47.2.3.1"></a>**1**　抓获他的人是谁，毫不重要；无论是财物所有人还是其他人，均可。

<!-- source-p 0033 -->
<a id="47.2.3.2"></a>**2**　但现行窃贼是否仅指在实施盗窃时被抓获的人，还是也包括在其他地点被抓获的人？较妥当的看法是，正如尤利安所写，即使不是在实施盗窃之处被抓获，只要窃贼携带被盗之物，在到达其预定目的地之前被抓获，仍属现行窃贼。

<!-- source-p 0034 -->
<a id="47.2.4"></a>**47.2.4**

<!-- source-p 0035 -->
保罗《萨宾评注》第九卷。

<!-- source-p 0036 -->
“某人意欲将赃物带往何处”，应理解为：他打算在盗窃发生当日携赃停留的地点。

<!-- source-p 0037 -->
<a id="47.2.5"></a>**47.2.5**

<!-- source-p 0038 -->
乌尔比安《萨宾评注》第四十一卷。

<!-- source-p 0039 -->
<a id="47.2.5.pr."></a>**序言**　无论是在公共场所还是私人场所，只要窃贼携带被盗之物、尚未将其带到预定地点前被抓获，便属于现行窃贼；卡西乌斯也如此记载。

<!-- source-p 0040 -->
<a id="47.2.5.1"></a>**1**　但若他已经将该物带到预定地点，即使被抓获时仍携带赃物，也不属于现行窃贼。

<!-- source-p 0041 -->
<a id="47.2.6"></a>**47.2.6**

<!-- source-p 0042 -->
保罗《萨宾评注》第九卷。

<!-- source-p 0043 -->
虽然盗窃往往通过持续触碰财物实施，但窃贼是否属于现行窃贼，仍应在行为开始时，也就是盗窃实施之时确定。

<!-- source-p 0044 -->
<a id="47.2.7"></a>**47.2.7**

<!-- source-p 0045 -->
乌尔比安《萨宾评注》第四十一卷。

<!-- source-p 0046 -->
<a id="47.2.7.pr."></a>**序言**　若奴隶在奴役期间实施盗窃，获释后才被抓获，应考察其是否属于现行窃贼。庞波尼在《萨宾评注》第十九卷中说，不能以现行盗窃之诉起诉他，因为该盗窃的起始并非现行盗窃。

<!-- source-p 0047 -->
<a id="47.2.7.1"></a>**1**　庞波尼在同一处精当地写道，抓获行为使盗窃成为现行盗窃。反之，若我从你家中偷窃时，你为了避免被我杀害而躲藏起来，即使你看见了盗窃行为，也不构成现行盗窃。

<!-- source-p 0048 -->
<a id="47.2.7.2"></a>**2**　但塞尔苏斯认为，还应将以下情形视为抓获：你看见他正在偷窃，便赶去抓他，而他丢下赃物逃走；此人仍属现行窃贼。

<!-- source-p 0049 -->
<a id="47.2.7.3"></a>**3**　他认为，抓获者是所有人、邻居还是任何路过的人，并不重要。

<!-- source-p 0050 -->
<a id="47.2.8"></a>**47.2.8**

<!-- source-p 0051 -->
盖尤斯《行省告示评注》第十三卷。

<!-- source-p 0052 -->
非现行盗窃的含义显而易见：凡不属于现行盗窃者，即属非现行盗窃。

<!-- source-p 0053 -->
<a id="47.2.9"></a>**47.2.9**

<!-- source-p 0054 -->
庞波尼《萨宾评注》第六卷。

<!-- source-p 0055 -->
<a id="47.2.9.pr."></a>**序言**　对于享有盗窃之诉的人而言，窃贼继续触碰该物，不会因此再产生一项盗窃之诉；即使被盗之物后来价值增加，也不另行产生诉权。

<!-- source-p 0056 -->
<a id="47.2.9.1"></a>**1**　但若我已对窃贼提起所有物返还之诉，仍保有基于盗窃原因的返还之诉。不过，也可以说，审理所有权的法官有权命令返还该物，但以请求人放弃返还之诉为条件。若被告此前已因返还之诉被判决并支付诉讼估价，则法官应当要么完全判其胜诉；要么——此说较可取——若原告准备返还已收取的估价，而被告仍未将奴隶交还给他，则应判令占有人支付原告在诉讼中宣誓确定的金额。

<!-- source-p 0057 -->
<a id="47.2.10"></a>**47.2.10**

<!-- source-p 0058 -->
乌尔比安《萨宾评注》第二十九卷。

<!-- source-p 0059 -->
凡因财物未被盗而具有利益的人，均享有盗窃之诉。

<!-- source-p 0060 -->
<a id="47.2.11"></a>**47.2.11**

<!-- source-p 0061 -->
保罗《萨宾评注》第九卷。

<!-- source-p 0062 -->
只有其利益具有正当理由时，利害关系人才享有盗窃之诉。

<!-- source-p 0063 -->
<a id="47.2.12"></a>**47.2.12**

<!-- source-p 0064 -->
乌尔比安《萨宾评注》第二十九卷。

<!-- source-p 0065 -->
<a id="47.2.12.pr."></a>**序言**　承接衣物并负责清洗或熨烫的漂洗工，始终享有盗窃之诉，因为他负有保管责任。若其无清偿能力，诉权便回归所有人；因为一个没有可供承担损失之财产的人，不承担该物的风险。

<!-- source-p 0066 -->
<a id="47.2.12.1"></a>**1**　恶意占有人虽因该物处于其风险之下而有利益，但不得提起盗窃之诉；因为任何人不得从自己的不诚实行为中取得诉权。因此，只有善意占有人可以提起盗窃之诉，恶意占有人则不可以。

<!-- source-p 0067 -->
<a id="47.2.12.2"></a>**2**　若财物已设定质押，我们也赋予债权人盗窃之诉，尽管该物并非其财产；不仅可对第三人提起，甚至也可对所有人本人提起，尤利安亦如此记载。所有人本人也可提起该诉；因此，同一人既可能负盗窃责任，也可以提起盗窃之诉。之所以双方都享有该诉，是因为双方都有利益。问题在于，债权人是否始终具有利益，还是仅在债务人无清偿能力时才有利益。庞波尼认为，债权人始终有保有质物的利益，帕皮尼安《问题集》第十二卷也赞同此说。较妥当的看法是，债权人在任何情况下均有利益，尤利安也多次如此记载。

<!-- source-p 0068 -->
<a id="47.2.13"></a>**47.2.13**

<!-- source-p 0069 -->
保罗《萨宾评注》第五卷。

<!-- source-p 0070 -->
因要式口约而有权请求交付某物的人，若该物被盗，不享有盗窃之诉；因为未能交付该物是债务人自身造成的。

<!-- source-p 0071 -->
<a id="47.2.14"></a>**47.2.14**

<!-- source-p 0072 -->
乌尔比安《萨宾评注》第二十九卷。

<!-- source-p 0073 -->
<a id="47.2.14.pr."></a>**序言**　塞尔苏斯写道，买受人尚未受领标的物时，不享有盗窃之诉，该诉权仍属于出卖人。不过，出卖人应当授权买受人行使盗窃之诉、返还之诉和所有物返还之诉；若买受人通过其中任何一项诉讼取得利益，出卖人应将其交给买受人。此说正确，尤利安也如此认为。事实上，标的物的风险由买受人承担，但交付前出卖人仍须履行保管义务。

<!-- source-p 0074 -->
<a id="47.2.14.1"></a>**1**　买受人在交付前尚无盗窃之诉，甚至因此有人问：买受人自己偷取标的物是否构成盗窃。尤利安在《学说汇纂》第二十三卷中写道：若买受人已支付价款，偷取了本应由出卖人保管的标的物，则不承担盗窃之诉；但若在支付价款之前便偷取该物，则应承担盗窃之诉，如同偷取质物一样。

<!-- source-p 0075 -->
<a id="47.2.14.2"></a>**2**　承租农地的人也享有盗窃之诉，尽管他们不是所有人，因为他们有利益。

<!-- source-p 0076 -->
<a id="47.2.14.3"></a>**3**　寄存物的受寄人是否享有盗窃之诉，尚须考察。由于他仅对欺诈承担责任，认为他不享有盗窃之诉是适当的：若他没有欺诈，其利益何在？若他确有欺诈，该物便处于他的风险之下；但他不得从自己的欺诈中取得盗窃之诉。

<!-- source-p 0077 -->
<a id="47.2.14.4"></a>**4**　尤利安在《学说汇纂》第二十二卷也写道：对所有窃贼均适用一项规则，即不得就其本人所盗之物提起盗窃之诉。因此，即使寄存物已因触碰该物之人承担风险，受寄人仍不享有盗窃之诉。

<!-- source-p 0078 -->
<a id="47.2.14.5"></a>**5**　帕皮尼安讨论：我以两名奴隶为质借出十奥里，若其中一名被盗，而留下的另一名奴隶价值并不低于十，我的盗窃之诉是否仅限于五，因为我仍保有价值五的担保？还是应认为我可以就十提起诉讼，因为留下的奴隶可能死亡，即使其价值很高亦然？帕皮尼安赞同后一见解：我们应当着眼于被盗的质物，而非未被盗的质物。

<!-- source-p 0079 -->
<a id="47.2.14.6"></a>**6**　他还写道：若我有权请求十，而作为质物的奴隶被盗；我通过盗窃之诉已取得十，之后该奴隶再次被盗时，我便不再享有盗窃之诉，因为我已一次取得全部利益。若该奴隶是在我无过失的情况下被盗，规则如此；若由于我的过失而被盗，则不同，因为我须依据质押之诉承担责任，故仍有利益。若我没有过失，显然所有人享有诉权，而债权人没有；庞波尼《萨宾评注》第十卷也赞同此说。

<!-- source-p 0080 -->
<a id="47.2.14.7"></a>**7**　他们还说，若两名奴隶同时被盗，债权人就两名奴隶均可提起盗窃之诉，但不是就全部债务分别请求，而应按所欠债务在两名奴隶之间分配的份额，分别确定其利益。若两名奴隶分别被盗，而债权人就其中一名已取得全部债额，则就另一名不再取得任何利益。

<!-- source-p 0081 -->
<a id="47.2.14.8"></a>**8**　庞波尼《萨宾评注》第十卷也写道，借用人若就借用物实施欺诈，便不能提起盗窃之诉。

<!-- source-p 0082 -->
<a id="47.2.14.9"></a>**9**　庞波尼对受他人委托、负责转交物品的人也持同一见解。

<!-- source-p 0083 -->
<a id="47.2.14.10"></a>**10**　有人问，借用物交给家子后，父亲是否享有盗窃之诉。尤利安说，父亲不得以此起诉，因为他不负保管责任；正如为借用人提供保证的人也不享有盗窃之诉。因为并非任何对财物不灭失具有利益的人都享有盗窃之诉，而只有因财物由于其过失灭失而须承担责任的人才享有。塞尔苏斯《学说汇纂》第十二卷也赞同此说。

<!-- source-p 0084 -->
<a id="47.2.14.11"></a>**11**　有人请求并获准依可撤回的临时许可占有一名奴隶；该奴隶被盗后，须考察此人是否享有盗窃之诉。由于市民法上并无可对抗他的诉讼（依请求而暂时授予之物类似赠与），所以法律才认为有必要设置令状；因此，他不享有盗窃之诉。不过，令状作出后，我认为他也须对过失负责，故可以提起盗窃之诉。

<!-- source-p 0085 -->
<a id="47.2.14.12"></a>**12**　若某人租用了财物，只要该物因他的过失被盗，他便享有盗窃之诉。

<!-- source-p 0086 -->
<a id="47.2.14.13"></a>**13**　若家子被盗，显然父亲享有盗窃之诉。

<!-- source-p 0087 -->
<a id="47.2.14.14"></a>**14**　借用物的受领人死亡后，尽管不能为遗产提起盗窃之诉，借用人的继承人因此也不能起诉，但出借人仍可提起盗窃之诉；质押物和租赁物亦同。虽然遗产本身不取得盗窃之诉，但该诉权可以归属于其他具有利益的人。

<!-- source-p 0088 -->
<a id="47.2.14.15"></a>**15**　借用人享有的盗窃之诉，不仅适用于借用物本身，也适用于从该物派生或附随的物，因为后者也由他负责保管。例如，我把一名奴隶借给你，你可以就其衣物提起盗窃之诉，尽管我并未把他所穿的衣物借给你。同样，若我把役畜借给你，而有一匹小马驹随行，我认为即使没有借出小马驹，也可以就其提起盗窃之诉。

<!-- source-p 0089 -->
<a id="47.2.14.16"></a>**16**　有人问，借用物的受领人享有何种盗窃之诉。我认为，凡承担他人财物风险的人，例如借用人、承租人以及质权人，若财物被盗，均享有盗窃之诉；但只有所有人享有返还之诉。

<!-- source-p 0090 -->
<a id="47.2.14.17"></a>**17**　若我寄给你的信被截取，谁享有盗窃之诉？首先应考察该信属于寄信人还是收信人。若我把信交给收信人的奴隶，信即刻成为收信人的；若我交给其代理人，也同样属于收信人，因为可以通过自由人取得占有，尤其是收信人有利益取得该信时。若我寄信时约定将信返还给我，则所有权仍属于我，因为我并不想放弃或转让所有权。那么谁可以提起盗窃之诉？是对信不被盗具有利益的人，也就是信中所记内容对其有利的人。因此，还可以问，负责转交信件的人是否也能提起盗窃之诉。若他负有保管责任，可以；若将信交还与他有利害关系，他也享有该诉。设想该信记载了应向他返还或为他办理某事，他便可以提起盗窃之诉；或者他已承担保管责任，或收取了送信报酬，也可以起诉。他与旅店主人或船舶经营人的情况相似：由于财物风险由他们承担，只要他们有清偿能力，我们便赋予他们盗窃之诉。

<!-- source-p 0095 -->

<a id="47.2.17.pr."></a>**序言**　我们的奴隶和儿子确实会对我们实施盗窃，但他们本人不因此对我们承担盗窃责任；能够惩治窃贼的人，无须与窃贼进行诉讼。因此，古人也没有为此创设诉权。

<!-- source-p 0102 -->
<a id="47.2.17.1"></a>**1**　由此有人问，若奴隶被转让或获释，是否应承担盗窃之诉。通说认为不承担：针对该窃贼的诉权起初并未产生，之后也不可能再产生。不过，若他获释后才实施触碰财物的行为，则应认为他依盗窃之诉承担责任，因为盗窃是在今日实施的。

<!-- source-p 0103 -->
<a id="47.2.17.2"></a>**2**　我买下一名奴隶并受领交付后，若该奴隶被退货解除买卖，不能将其视为从未属于我；他曾属于我，后来才不再属于我。因此，萨宾说，若他曾实施盗窃，退货者不能就该奴隶的行为提起盗窃之诉。尽管如此，仍须将奴隶实施的行为计入考量，因为退货诉讼已经启动，而该问题包含在退货之诉中。

<!-- source-p 0104 -->
<a id="47.2.17.3"></a>**3**　有人问，若奴隶逃亡期间对主人实施盗窃，主人能否对后来善意占有该奴隶、而该奴隶仍未回到主人权力之下的人提起盗窃之诉。问题在于：尽管我似乎在奴隶逃亡期间仍占有他，但我并不承担盗窃之诉，仿佛他不处于我的权力之下；尤利安写道，这种占有仅对取得时效有利。庞波尼在《萨宾评注》第十七卷中则说，奴隶逃亡期间的主人可以提起盗窃之诉。

<a id="47.2.19.pr."></a>**序言**　提起盗窃之诉时，只须描述该物，使其能够被辨认即可。

<!-- source-p 0111 -->
<a id="47.2.19.1"></a>**1**　无须说明器皿的重量；只要称其为“盘”“碟”或“浅杯”即可，但还应说明材质：是银制、金制，还是其他材质。

<!-- source-p 0112 -->
<a id="47.2.19.2"></a>**2**　若请求返还未加工的白银，则应称其为银块，并写明重量。

<!-- source-p 0113 -->
<a id="47.2.19.3"></a>**3**　若为带印记的银币，应写明数量，例如有多少枚或更多金币被盗。

<!-- source-p 0114 -->
<a id="47.2.19.4"></a>**4**　有人问，描述衣物时是否须说明颜色。正确答案是应说明颜色；如同描述器皿时称其为金制浅杯，描述衣物时也应说明颜色。当然，若有人宣誓称自己确实无法说出颜色，则应免除其说明颜色的义务。

<!-- source-p 0115 -->
<a id="47.2.19.5"></a>**5**　将物交付质押的人又偷取该物，应承担盗窃之诉。

<!-- source-p 0116 -->
<a id="47.2.19.6"></a>**6**　质押物的所有人实施盗窃，不仅指他从占有或持有该物的债权人手中取走该物；即使在债权人不占有该物时取走，例如已经出售质押物后取回该物，也构成盗窃。尤利安也如此记载。

<a id="47.2.20"></a>**47.2.20**

<!-- source-p 0118 -->
保罗《萨宾评注》第九卷。

<!-- source-p 0119 -->
<a id="47.2.20.pr."></a>**序言**　若有人交付铜器作为质物，即使谎称其为黄金，虽行为可耻，却不构成盗窃。但若交付的是黄金，之后声称要称重或加印记，却偷偷换成铜器，便构成盗窃，因为他侵夺了已经交付质押的财物。

<!-- source-p 0120 -->
<a id="47.2.20.1"></a>**1**　若你善意购买了我的财物，而我又偷取该物；或者该物上设有你的用益权，我触碰该物，尽管我是所有人，仍应对你承担盗窃之诉。不过，在这些情形下，该物即使被视为准被盗之物，也不妨碍取得时效；因为即便由他人偷取，之后该物回到我的权力之下，也可以取得时效。

<!-- source-p 0121 -->
<a id="47.2.21"></a>**47.2.21**

<!-- source-p 0122 -->
保罗《萨宾评注》第四十卷。

<!-- source-p 0123 -->
<a id="47.2.21.pr."></a>**序言**　有人从谷堆中取走一斗谷物，这是常见问题：他是对整堆谷物实施盗窃，还是仅对取走的部分实施盗窃？奥菲利乌斯认为，他是整堆谷物的窃贼；特雷巴提乌斯说，触碰某人的一只耳朵，就视为触碰了整个人。因此，打开酒桶并取走少量葡萄酒的人，似乎不只是所取部分的窃贼，而是整桶酒的窃贼。但正确的看法是，他们仅就所取走的部分承担盗窃之诉。又如，某人打开一只自己无法搬走的箱柜，触碰其中所有物品后离开；之后又回来取走其中一件，并在将其带到预定地点之前被抓获；他就同一物品既构成现行盗窃，也构成非现行盗窃。白天收割并触碰庄稼的人，对其收割的部分也构成现行和非现行盗窃。

<!-- source-p 0124 -->
<a id="47.2.21.1"></a>**1**　某人寄存了一袋二十枚钱币，交付人误将另一袋、其中有三十枚钱币的袋子给了他；他知道袋中有三十枚，却以为其中有自己寄存的二十枚。通说认为，他就多出的十枚承担盗窃责任。

<!-- source-p 0125 -->
<a id="47.2.21.2"></a>**2**　若某人偷走铜器，却以为偷的是黄金，或反之；又如庞波尼《萨宾评注》第八卷所述，以为所取之物少于实际数量；他对自己实际偷走之物构成盗窃。乌尔比安也持此见解。

<!-- source-p 0126 -->
<a id="47.2.21.3"></a>**3**　若某人偷走两袋钱币，一袋有十枚，另一袋有二十枚；他以为其中一袋属于自己，而知道另一袋属于他人，则应认为他仅对自己以为属于他人的那一袋构成盗窃。如同他拿走两个杯子，其中一个以为属于自己、另一个知道属于他人时，也仅对其中一个构成盗窃。

<!-- source-p 0127 -->
<a id="47.2.21.4"></a>**4**　但若杯子的把手是他自己的，或确实属于他，庞波尼写道，他对整个杯子实施了盗窃。

<!-- source-p 0128 -->
<a id="47.2.21.5"></a>**5**　若某人从装载货物的船上偷走一升谷物，他是对全部货物还是仅对该升谷物实施盗窃？在装满谷物的仓库中，这个问题更容易提出；但说他偷了全部货物显然过于严苛。若是葡萄酒窖呢？若是水池呢？若是一艘装满葡萄酒的船（许多船将葡萄酒直接装入船舱），我们该如何看待舀走葡萄酒的人？他是全部货物的窃贼吗？较妥当的看法是，此处也不能说他偷了全部货物。

<!-- source-p 0129 -->
<a id="47.2.21.6"></a>**6**　当然，若酒窖里有数个装葡萄酒的双耳瓶，而有人将其偷走，构成的是对每个双耳瓶的盗窃，而非对整个酒窖的盗窃；如同有人从仓库中锁存的数件动产里拿走一件。

<!-- source-p 0130 -->
<a id="47.2.21.7"></a>**7**　某人为实施盗窃而进入一间房屋，虽有盗窃目的，但尚未成为窃贼。那么，他应承担何种诉讼？当然是侵害之诉；若其以暴力闯入，也可以暴力犯罪控告他。

<!-- source-p 0131 -->
<a id="47.2.21.8"></a>**8**　同样，若某人打开或撬坏了一件很重、自己无法搬走的物品，不能就全部物品对其提起盗窃之诉，只能就他实际带走的物品提起，因为他无法搬走整体。因此，若他打开自己无法搬走的包裹以便触碰其内物品，随后触碰其中若干物品；即使他能分别搬走包裹中的每件物品，只要他不能搬走整个包裹，他也仅是所带走物品的窃贼，并非其他物品的窃贼。反之，若他能够搬走整个器皿，即使他只是为了拿走其中一件或几件物品而打开器皿，我们仍认为他是整个器皿的窃贼；萨宾也如此认为。

<!-- source-p 0132 -->
<a id="47.2.21.9"></a>**9**　若两人或多人共同偷走一根单人无法搬动的梁木，应认为他们每人均就全部财物承担盗窃责任；即使任何一人单独都不能触碰并搬走它，我们仍如此处理。每个人不能说自己只偷了其中一部分，而应认为他们共同偷了全部，因此每个人均承担全部盗窃责任。

<!-- source-p 0133 -->
<a id="47.2.21.10"></a>**10**　虽然某人也会对自己没有带走的财物承担盗窃责任，但不能对其就这些物品提起返还之诉，因为返还之诉只能针对被带走之物；庞波尼也如此写道。

<a id="47.2.27.pr."></a>**序言**　有人拿走账簿或债权文书时，所承担的盗窃责任不只限于文书本身的价额，还包括所有人因此所受的利益损失；其估价取决于文书所载债权金额。例如，若债权文书记载十奥里，我们便认为该金额应加倍。但若文书已经空白，因为债务据称已经清偿，是否只应按文书本身的价值估价？毕竟所有人有何利益损失？不过，也可以说，债务人有时会请求返还文书，因为债务人偶尔会诬称债务已经清偿；债权人有利益保有文书，以避免因此发生争议。总之，应按利益损失的数额加倍计算。

<!-- source-p 0157 -->
<a id="47.2.27.1"></a>**1**　由此还可以问，若有人持有其他证据及账簿记录，却遭窃贼偷走债权文书，是否应将该文书所载债务金额加倍估价？若他可通过其他证据证明债务，是否便没有利益损失？例如，债权记载在两份文书中；若另一份仍然完好，债权人似乎并未遭受损失，反而更为稳妥。

<!-- source-p 0158 -->

<a id="47.2.46.2"></a>**2**　我们所说的双倍，应理解为若属于现行盗窃，也可以提起四倍之诉。

<!-- source-p 0244 -->
<a id="47.2.46.3"></a>**3**　若某人仅对该奴隶享有使用权，这项诉权也可能归属于他。

<!-- source-p 0245 -->
<a id="47.2.46.4"></a>**4**　若该奴隶还设定了质押，收受质押的人也享有盗窃之诉；此外，若债务人对该奴隶的利益超过质押担保的债额，债务人也享有盗窃之诉。

<!-- source-p 0246 -->
<a id="47.2.46.5"></a>**5**　这些人享有的诉权彼此如此不同，以致若其中一人以窃贼身份赔偿损害，只能认为他丧失了自己享有的诉权，其他人的诉权仍然存在。例如，共有奴隶被偷，其中一名共有人已按窃贼身份和解，未和解的另一人仍享有盗窃之诉。

<!-- source-p 0247 -->
<a id="47.2.46.6"></a>**6**　若所有人为隐瞒或压制所有权而实施某种行为，所有人也可以依据盗窃之诉起诉用益权人。

<!-- source-p 0248 -->
<a id="47.2.46.7"></a>**7**　通说正确地认为，若某人以为自己是在所有人同意下触碰财物，便不是窃贼：无论其对所有人会同意这一点的判断是正确还是错误，他并未出于欺诈行事。因此，只有明知所有人不同意，仍触碰财物的人，才是窃贼。

<!-- source-p 0249 -->
<a id="47.2.46.8"></a>**8**　反过来，有人问：若我以为自己违背所有人意愿行事，但所有人其实同意，是否构成盗窃之诉？庞波尼说我构成盗窃。不过，较妥当的规则是：若我愿意让他使用该物，即使他不知道我的意愿，也不因此承担盗窃责任。
