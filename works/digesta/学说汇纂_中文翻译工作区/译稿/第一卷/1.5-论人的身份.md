# 第一卷

## <a id="1.5"></a>1.5　论人的身份

### <a id="1.5.1"></a>1.5.1　盖尤斯（Gaius）《法学阶梯》第一卷

我们所适用的全部法，或涉及人，或涉及物，或涉及诉讼。

### <a id="1.5.2"></a>1.5.2　赫莫革尼安《法律概要》第一卷

既然全部法均为人的缘故而设，我们将首先论述人的身份，其后再论其他事项；我们依循《永久告示》的次序，并在事项允许的范围内，将彼此相邻、相关的标题相接编排。

### <a id="1.5.3"></a>1.5.3　盖尤斯《法学阶梯》第一卷

因此，人法的基本区分在于：所有人或者是自由人，或者是奴隶。

### <a id="1.5.4"></a>1.5.4　弗洛伦提努斯（Florentinus）《法学阶梯》第九卷

<a id="1.5.4.pr."></a>**序言。** 自由是自然赋予的能力，使每个人可以做其所愿之事，除非受到暴力或法律的禁止。

<a id="1.5.4.1"></a>**1.** 奴隶制是万民法所设立的一种制度；依此制度，某人违背自然地受制于他人的支配权。

<a id="1.5.4.2"></a>**2.** 奴隶（*servi*）之名源于“保存”（*servare*）：统帅通常出售俘虏，从而使他们免于被杀。

<a id="1.5.4.3"></a>**3.** *Mancipia* 一词，则被解释为源于他们被敌人徒手捕获。

### <a id="1.5.5"></a>1.5.5　马尔西安《法学阶梯》第一卷

<a id="1.5.5.pr."></a>**序言。** 奴隶的身份只有一种；自由人则有些是自由出生者，有些是自由释奴。

<a id="1.5.5.1"></a>**1.** 奴隶可依市民法或万民法纳入我们的支配之下。依市民法，年满二十岁的人若允许自己被出售以分享价款，便成为奴隶。依万民法，遭敌人俘获者以及由我们的女奴所生者，均为我们的奴隶。

<a id="1.5.5.2"></a>**2.** 自由出生者，是由自由母亲所生的人。母亲在其分娩时为自由人即已足够，即使受孕时她是女奴亦然。反之，若母亲受孕时为自由人，后来成为女奴而分娩，通说认为所生之人仍为自由人。（受孕于合法婚姻还是非婚关系，并无区别。）因为母亲的不幸不应损害其腹中之人。〔底本将 *concepit* 与 *et* 连写为 *concepitet*；译文依上下文断句。〕

<a id="1.5.5.3"></a>**3.** 因此有人提出这样的问题：女奴怀孕后获释，后来又成为女奴或被逐出公民团体，随后分娩，所生者是自由人还是奴隶？然而，更妥当的见解是，所生者为自由人；只要腹中之人在某一中间期间曾有过自由母亲，即已足够。

### <a id="1.5.6"></a>1.5.6　盖尤斯《法学阶梯》第一卷

自由释奴，是指从合法奴隶身份中获释的人。

### <a id="1.5.7"></a>1.5.7　保罗（Paulus）《关于判罪者子女所得份额》单卷

判罪者的子女得以享有的份额如下：凡在母腹中的人，每当涉及其自身利益时，均按其已出生、身处人世处理；但在其出生以前，绝不能使他人因此受益。

### <a id="1.5.8"></a>1.5.8　帕比尼安（Papinianus）《疑问集》第三卷

皇帝提图斯·安东尼努斯（Titus Antoninus）以敕答指出，子女的身份不应因文书措辞不当而受损。

### <a id="1.5.9"></a>1.5.9　帕比尼安《疑问集》第三十一卷

在我们法律的许多方面，妇女的地位劣于男子。

### <a id="1.5.10"></a>1.5.10　乌尔比安（Ulpianus）《萨宾评注》第一卷

有人问：双性人应归入哪一性别？我更倾向于认为，应依其身上占优势的性别认定。

### <a id="1.5.11"></a>1.5.11　保罗《答复集》第十八卷

保罗答复：某人在其父仍在世、且其父不知悉其女儿之结合时受孕；即使该人在祖父死后才出生，也不得视为其受孕所自之人的婚生子。〔原文所指人物及亲属关系不够明晰，见疑难表。〕

### <a id="1.5.12"></a>1.5.12　保罗《答复集》第十九卷

妊娠七个月出生者已被承认为成熟可活产之儿，这一点因最博学之人希波克拉底（Hippocrates）的权威而成为通说。因此，应当承认：凡在合法婚姻中于第七个月出生者，均为婚生子。

### <a id="1.5.13"></a>1.5.13　赫莫革尼安《法律概要》第一卷

主人将奴隶交由裁判者在重大刑事案件中裁定其命运，即使该奴隶被宣告无罪，也不会因此成为自由人。

### <a id="1.5.14"></a>1.5.14　保罗《判例集》第四卷

以反常方式、违背人类通常形态所生者，不属于子女；例如，妇人生下某种怪形或异象。至于肢体有所增生的后代，其出生在一定程度上仍被视为成形，因而列入子女之列。〔原文关于肢体“功能有所扩展”的表述含义未详，见疑难表。〕

### <a id="1.5.15"></a>1.5.15　特里福尼努斯（Tryphoninus）《论辩集》第十卷

阿雷斯库萨（Arescusa）曾依遗嘱被命令：生下三胎后即可成为自由人。她第一次分娩生下一人，第二次生下三人。于是有人提出，究竟哪些孩子是自由人？

这一附加于该女子获释条件的条件，现已必须履行。但毫无疑问，最后出生的孩子是自由人；因为自然不允许两个婴儿在一次分娩中同时离开母体，以致出生先后无法确定，从而不能判断哪一个出生时仍为奴隶、哪一个出生时已属自由。

因此，分娩开始时若该条件已经成就，其后出生的孩子便是由自由母亲所生；这就如同附加于该女子获释的其他任何条件，在她分娩时成就一样。又如，某女奴获释附有这样的条件：向继承人或提图斯交付一万；如果她在分娩时经由他人履行了该条件，也应认为她是在自由身份下分娩。〔底本未说明“一万”的币种。〕

### <a id="1.5.16"></a>1.5.16　乌尔比安《论辩集》第六卷

如果同一位阿雷斯库萨第一次生下双胞胎，后来又生下三胞胎，结论也相同：不能说两个孩子都属于自由出生者，只能说后出生的那个孩子是自由出生者。因此，这主要是事实问题，而非法律问题。

### <a id="1.5.17"></a>1.5.17　乌尔比安《告示评注》第二十二卷

依安东尼努斯皇帝的敕令，罗马世界中的人均成为罗马公民。

### <a id="1.5.18"></a>1.5.18　乌尔比安《萨宾评注》第二十七卷

皇帝哈德良曾以敕答告知普布利基乌斯·马尔凯卢斯（Publicius Marcellus）：一名被判处极刑的自由女子若怀有身孕，所生之子为自由人；通常应将该女子留至分娩后。可是，若一名在合法婚姻中受孕的女子被处以水火禁断（*aquae et ignis interdictio*），她所生之子仍是罗马公民，并处于父亲的家父权之下。

### <a id="1.5.19"></a>1.5.19　塞尔苏斯（Celsus）《学说汇纂》第二十九卷

凡由合法婚姻所生的子女，随父；非婚所生者，随母。

### <a id="1.5.20"></a>1.5.20　乌尔比安《萨宾评注》第三十八卷

开始精神失常的人，视为仍保有其身份、地位、官职和权力，正如其仍保有对自己财产的所有权一样。

### <a id="1.5.21"></a>1.5.21　莫德斯蒂努斯（Modestinus）《规则》第七卷

自由人自卖为奴后，获释时并不恢复其所放弃的原身份，而成为自由释奴。

### <a id="1.5.22"></a>1.5.22　莫德斯蒂努斯《答复集》第十二卷

莫德斯蒂努斯答复：女奴若在依捐赠法本应获释的时点分娩，而依皇帝敕令她已属自由人，则由她所生者为自由出生者。

### <a id="1.5.23"></a>1.5.23　莫德斯蒂努斯《学说汇纂》第一卷

所谓非婚受孕者，是指无法确定其父亲的人，或虽能确定其父亲、但其父亲依法不得为其父的人。他们也称为私生子（*spurii*）；该称谓源自希腊语“在播种之外”（*para tyn sporan*）。〔底本以拉丁字母转写希腊语；此处依其含义翻译。〕

### <a id="1.5.24"></a>1.5.24　乌尔比安《萨宾评注》第二十七卷

自然法则是：未在合法婚姻中出生的人随母，除非特别法另作规定。

### <a id="1.5.25"></a>1.5.25　乌尔比安《朱利亚与帕皮亚法评注》第一卷

即使某人原为自由释奴，只要已有判决认定其为自由出生者，我们也应将其视为自由出生者；因为既判事项被当作真实。

### <a id="1.5.26"></a>1.5.26　尤利安（Iulianus）《学说汇纂》第六十九卷

几乎在整个市民法中，母腹中的人都被视为已存在于现实之中。因此，合法继承也为他们保留；如果怀孕女子被敌人俘获，其所生之人享有复归权（*postliminium*）；该人也随父亲或母亲的身份。此外，怀孕的女奴若被盗，即使她在善意买受人处分娩，所生者也不因时效取得而成为买受人的所有物，因为该子仍属盗得之物。由此还可推知，只要释奴保护人的儿子仍可能出生，该自由释奴就应适用那些仍有释奴保护人的人的法律规则。

### <a id="1.5.27"></a>1.5.27　乌尔比安《意见集》第五卷

某人承认自己是自由释奴，即使其释奴保护人收养了他，也不能因此使其成为自由出生者。
