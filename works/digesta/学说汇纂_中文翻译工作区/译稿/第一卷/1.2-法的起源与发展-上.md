# 第一卷

## <a id="1.2"></a>1.2 论法的起源、各级官职的起源及法学家的传承

### <a id="1.2.1"></a>1.2.1　盖尤斯《十二表法评注》第一卷

在着手解释古代法律时，我认为有必要先追溯罗马城的起源。这并非因为我想写冗长的评注，而是因为我注意到，任何事物只有由其各个部分共同构成，才算完备；而一事物最重要的部分，无疑是它的开端。再者，在法庭上，诉讼代理人若不先作引言便向法官陈述案件，似乎是不妥的——姑且这样说。既然如此，承诺作出解释的人若不追溯开端与起源，便仿佛手尚未洗净就直接讨论解释的主题，岂不更加不合宜？倘若我没有弄错，这些引言既能使我们更乐于阅读所提出的主题，也能在我们读到该主题时帮助我们理解得更清楚。

### <a id="1.2.2"></a>1.2.2　庞波尼乌斯（Pomponius）《手册》（*Enchiridii*）单卷

<a id="1.2.2.pr."></a>**序言。** 因此，我们认为有必要说明法本身的起源及其发展过程。

<a id="1.2.2.1"></a>**1.** 我们这个共同体初创之时，人民起初在没有确定法律、没有确定法制的情况下行事，一切都由国王亲自行使权力治理。

<a id="1.2.2.2"></a>**2.** 后来，共同体有所发展。据传，罗慕路斯将人民划分为三十个部分，并称这些部分为“库里亚”（*curiae*）；当时他通过各部分的表决处理公共事务，因此如此命名。他本人也曾向人民提出若干库里亚法；继任的国王们也提出了法律。这些法律均有抄本，见于塞克斯图斯·帕皮里乌斯（Sextus Papirius）的著作。帕皮里乌斯生活在塔克文·苏佩布（Tarquin Superbus）时期；后者是科林斯人德马拉图斯之子，出身显贵。正如前文所说，这部著作称为《帕皮里乌斯市民法》，并非帕皮里乌斯在其中增添了自己的法律，而是因为他把那些未经编排而颁行的法律汇集为一部。

<a id="1.2.2.3"></a>**3.** 国王被驱逐之后，根据保民官法，这些法律全都逐渐失效。罗马人民又开始更多地依循不确定的法律和某种习惯，而非依循正式颁布的法律；这种状态持续了将近二十年。

<a id="1.2.2.4"></a>**4.** 为免这种状况延续下去，人们决定以公共权力任命十人，由他们向希腊各城邦征求法律，并以法律奠定共同体的制度基础。他们将法律刻写在象牙表板上，陈列于演讲台前，使人民能够更清楚地了解法律。该年，这十人在共同体中获得最高权力，可以在必要时修改和解释法律；与其他官职人员不同，他们的决定不得上诉。他们发现最初制定的法律尚有缺漏，于是在次年又增补两表，与原有表板合在一起。因此，这些法律后来被称为《十二表法》。有人记载，曾流亡意大利的以弗所人赫尔莫多鲁斯（Hermodorus）是协助十人制定这些法律的人。

<a id="1.2.2.5"></a>**5.** 这些法律颁行后，法庭中的法律论辩也就成为必要——因为法律的解释自然需要法学家的权威。法学家所进行的这种论辩，以及由他们汇编、未以书面形式颁行的这部分法律，并不像其他法律部门那样另有专名；其他部门各有名称，而这一部分仅以共同名称称为市民法。

<a id="1.2.2.6"></a>**6.** 此后，大约在同一时期，人们又依据这些法律制定了诉讼程式，使当事人能够彼此解决争议。为了避免人民随意创设诉讼方式，这些程式被规定为确定而正式的形式。这部分法律称为“法定诉讼”（*legis actiones*），也就是依法定形式进行的诉讼。于是，差不多在同一时期产生了三种法律制度：《十二表法》催生了市民法，法定诉讼也由同一法律体系制定。不过，对这些法律的解释知识以及诉讼程式，均掌握在祭司团手中；祭司团从内部选定人员，每年负责主持私人法事务。人民大约一百年来基本沿用这一做法。

<a id="1.2.2.7"></a>**7.** 后来，阿庇乌斯·克劳狄乌斯（Appius Claudius）提出并整理了这些诉讼程式。他的书记官格奈乌斯·弗拉维乌斯（Gnaeus Flavius）是获释奴隶之子，暗中取得该书后将其交给人民。这项功绩深受人民欢迎，他因此当选平民保民官，继而成为元老和库鲁尔市政官。这部收录诉讼程式的书称为《弗拉维乌斯市民法》，如同前述《帕皮里乌斯市民法》；格奈乌斯·弗拉维乌斯并未在书中增添自己的内容。随着共同体不断扩大，某些诉讼方式仍有缺漏；不久之后，塞克斯图斯·埃利乌斯又制定了其他诉讼程式，并将一部著作交给人民，称为《埃利乌斯法》。

<a id="1.2.2.8"></a>**8.** 此后，共同体中既有《十二表法》和市民法，也有法定诉讼。平民与贵族发生冲突并退出共同体，为自己制定法律；这些法律称为平民决议。平民被召回后，由于围绕平民决议发生了许多争议，《霍滕西亚法》遂规定这些决议应与法律一样得到遵守。由此，平民决议与法律在制定程序上有所不同，但法律效力相同。

<a id="1.2.2.9"></a>**9.** 后来，平民难以经常集会；在人口如此众多的情况下，人民大会更难召开。现实需要于是使公共事务的处理转由元老院承担。元老院由此开始介入，其所作的一切决议均得到遵守；这种法律形式称为元老院决议。

<a id="1.2.2.10"></a>**10.** 同一时期，各级官员也行使司法裁判权。为了使公民知道各官员将就不同事项作出何种裁判，并据此做好准备，他们会公布告示。裁判官的告示构成了名誉法；之所以称为“名誉法”，是因为它源于裁判官的官职荣誉。

<a id="1.2.2.11"></a>**11.** 最后，现实发展似乎使法律制定途径逐步集中于少数形式。由于元老院不能同样妥善地治理所有行省，公共事务需要由一人统筹；于是设立元首，并赋予其权力，使其所作决定具有法律效力。

<a id="1.2.2.12"></a>**12.** 因此，在我们的共同体中，法可以通过成文法制定；也可以表现为一种特有的市民法，即仅由法学家的解释形成、未以书面形式颁行的法律；也可以表现为规定诉讼方式的法定诉讼；也可以是未经贵族同意而制定的平民决议；也可以是官职人员发布、由此产生名誉法的告示；也可以是由元老院单独作出、无须法律授权而产生的元老院决议；还可以是元首敕令，即元首所制定的规则应如同法律一样得到遵守。

<a id="1.2.2.13"></a>**13.** 既已了解法的起源与发展，接下来就应了解各级官职的名称及其起源。正如我们已说明的，负责宣示法律的官员使法律得以落实：城邦中即使有法，如果没有能够掌理法律的人，又有什么意义？此后我们还要谈法学家的传承；倘若没有法学专家，使法律得以日复一日地发展完善，法律便不可能稳定延续。
