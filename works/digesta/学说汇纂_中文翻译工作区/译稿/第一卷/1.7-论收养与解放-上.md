# 第一卷

## <a id="1.7"></a>1.7　论收养、解放及其他解除家父权的方式

### <a id="1.7.1"></a>1.7.1　莫德斯蒂努斯《规则》第二卷

<a id="1.7.1.pr."></a>**序言。** 家子不仅可以因自然生育而形成，也可以通过收养形成。

<a id="1.7.1.1"></a>**1.** “收养”一词具有一般含义，又分为两种：一种同样称为收养（*adoptio*），另一种称为自权人收养（*adrogatio*）。受家父权支配的家子可以被收养；自权人则可以被自权人收养程序纳入他人的权力之下。

### <a id="1.7.2"></a>1.7.2　盖尤斯《法学阶梯》第一卷

<a id="1.7.2.pr."></a>**序言。** 一般而言，收养有两种方式：通过元首的权威，或通过官员的权力。通过元首权威，我们收养自权人；这种收养称为自权人收养（*adrogatio*）。这是因为收养者要被询问，即被问及是否愿意让其所欲收养之人成为自己的合法儿子；被收养者也要被询问是否允许此事发生。通过官员的权力，我们收养受父母权力支配的人，无论其属于第一代子女，即儿子或女儿，还是较远代次的后代，即孙子、孙女、曾孙或曾孙女。

<a id="1.7.2.1"></a>**1.** 两种收养的共同点是：即使是不能生育的人，例如无生育能力者，也可以收养。

<a id="1.7.2.2"></a>**2.** 通过元首进行的自权人收养则有其独特之处：一个人若将自己交由他人收养，且其家子原已处于自己权力之下，那么他本人不仅受收养者的权力支配，其家子也一并处于收养者的权力之下，如同收养者的孙辈。

### <a id="1.7.3"></a>1.7.3　保罗《萨宾评注》第四卷

如果执政官或行省总督本身是家子，可以在其本人面前将自己解放出父权，或交付他人收养；这一点没有疑问。

### <a id="1.7.4"></a>1.7.4　莫德斯蒂努斯《规则》第二卷

涅拉提乌斯认为，对其得进行法定诉讼的官员，可以在自己面前解放自己的儿子出父权，也可以将儿子交付他人收养。

### <a id="1.7.5"></a>1.7.5　塞尔苏斯《学说汇纂》第二十八卷

收养自权人时，只需查明其本人的意愿；但若某人由父亲交付收养，则应考察双方的意思，可以明示同意，也可以不表示反对。

### <a id="1.7.6"></a>1.7.6　保罗《告示评注》第三十五卷

若某人被收养为仿佛由儿子所生的孙子，就必须取得该儿子的同意；尤利安也作此论。

### <a id="1.7.7"></a>1.7.7　塞尔苏斯《学说汇纂》第三十九卷

收养发生时，无须取得收养后将在其间产生宗亲关系效力之人的授权。

### <a id="1.7.8"></a>1.7.8　莫德斯蒂努斯《规则》第二卷

此前曾认为，自权人收养时不必有监护人授权；克劳狄乌斯在位时，这一规则被正确地改变了。

### <a id="1.7.9"></a>1.7.9　乌尔比安《萨宾评注》第一卷

盲人既可以收养，也可以被收养。

### <a id="1.7.10"></a>1.7.10　保罗《萨宾评注》第二卷

某人若经其儿子同意，收养一名原本处于自己权力之下、且仿佛由该儿子所生的孙子，那么该孙子不会因此成为祖父的自家继承人（*suus heres*）；因为祖父死后，此人会仿佛回到其父亲的权力之下。

### <a id="1.7.11"></a>1.7.11　保罗《萨宾评注》第四卷

某人已有儿子，又将另一人收养为孙子，视同此人由该儿子所生；若其儿子并未表示同意，那么祖父去世后，该孙子不处于其儿子的权力之下。

### <a id="1.7.12"></a>1.7.12　乌尔比安《萨宾评注》第十四卷

脱离家父权的人，之后若要正当地重新处于家父权之下，只能通过收养实现。

### <a id="1.7.13"></a>1.7.13　帕比尼安《疑问集》第三十六卷

几乎在所有法律关系中，养父的家父权终止后，原有身份不再留下任何痕迹。因此，连通过收养取得的家族身份与尊荣，也会随着收养关系终止而丧失。

### <a id="1.7.14"></a>1.7.14　庞波尼乌斯《萨宾评注》第五卷

即使孙辈是在其父已被收养并处于养父家中的期间受孕、出生，该父一旦被解放出家父权，孙辈仍会丧失全部相关权利。〔原文“孙辈”所承接的法律关系，见疑难表。〕
