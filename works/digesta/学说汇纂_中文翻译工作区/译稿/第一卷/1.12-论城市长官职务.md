# 第一卷

## <a id="1.12"></a>1.12　论城市长官的职务

### <a id="1.12.1"></a>1.12.1　乌尔比安《论城市长官职务》单卷

<a id="1.12.1.pr."></a>**序言。** 城市长官职权涵盖一切犯罪；不仅包括在城内实施的犯罪，也包括在城外、意大利境内实施的犯罪。这一点由神皇塞维鲁致城市长官法比乌斯·基洛（Fabius Cilo）的书信予以说明。

<a id="1.12.1.1"></a>**1.** 奴隶若逃到雕像前避难，或以自己的钱财买下自己以求获释，并就主人行为提出申诉，城市长官应当听取。

<a id="1.12.1.2"></a>**2.** 城市长官也应听取贫困的释奴保护人对其自由释奴提出的申诉；尤其是保护人声称自己患病，并希望由自由释奴供养时。

<a id="1.12.1.3"></a>**3.** 城市长官有权将人放逐，或将其流放至元首指定的岛屿。

<a id="1.12.1.4"></a>**4.** 塞维鲁皇帝书信的开头写道：“我们已将本城托付于你的忠诚。”因此，在城内实施的任何行为，似乎都属于城市长官的职权范围。在距城一百罗马里程以内实施的行为，也属于其职权范围；超过这一界石，则已超出城市长官的管辖范围。

<a id="1.12.1.5"></a>**5.** 如果有人声称自己的奴隶与自己的妻子通奸，应由城市长官审理。

<a id="1.12.1.6"></a>**6.** 城市长官也可以审理各类禁令之诉，包括因暴力、秘密侵占以及以暴力剥夺占有而提起的诉讼。

<a id="1.12.1.7"></a>**7.** 对于履行监护或保佐职责不当、需要受到更严厉惩处的监护人或保佐人，通常会移交城市长官处理；仅将其宣告为可疑监护人或保佐人，并不足够。例如，可以证明某人行贿以谋取监护职务，或收受报酬以促使他人被指定为不适任的监护人，或在申报财产时故意少报数额，或以明显欺诈手段处分被监护人的财产。

<a id="1.12.1.8"></a>**8.** 至于前述城市长官应听取奴隶对主人的申诉，应理解为并非允许奴隶控告主人——除非存在法律承认的事由，否则绝不允许奴隶如此行事——而是允许奴隶恭敬地陈述：主人对他们施以残暴、严苛对待或饥饿，使他们备受煎熬；或强迫、正在强迫他们遭受淫秽之事。神皇塞维鲁也赋予城市长官这一职责，使其保护奴隶不被迫卖淫。

<a id="1.12.1.9"></a>**9.** 此外，城市长官还应确保钱币兑换商妥善处理其各项业务，并遵守禁令。

<a id="1.12.1.10"></a>**10.** 如果保护人声称自由释奴轻视自己，或申诉自由释奴对自己出言侮辱，或对方曾辱骂自己、自己的子女、妻子或类似亲属，通常会向城市长官提出申诉。城市长官应依申诉情节予以纠正，可以警告、施以杖刑，或进一步加重处罚；因为自由释奴往往也应受到惩罚。尤其是，如果保护人证明自由释奴曾告发自己，或与自己的敌人合谋反对自己，就应判处其服矿刑。

<a id="1.12.1.11"></a>**11.** 确保各类肉食以合理价格供应，属于城市长官职权范围；因此，猪肉市场也由其管理。其他用于此类供应的牲畜和家畜，也由其管理。

<a id="1.12.1.12"></a>**12.** 民众的安宁和公共表演秩序，也属于城市长官职责范围。因此，他确实应安排士兵驻守指定地点，以维护民众安宁，并向其报告各处正在发生之事。

<a id="1.12.1.13"></a>**13.** 城市长官可以禁止某人进入本城，也可以禁止其进入其他惯常管辖区域；还可以禁止其从事贸易、职业、辩护活动或进入市场，期限可以是暂时或永久。他也可以禁止某人观看公共表演；如果将某人逐出意大利，还可以将其逐出其所属行省。

<a id="1.12.1.14"></a>**14.** 神皇塞维鲁以敕答指出，据称参与非法结社的人，也应在城市长官面前受到控告。

### <a id="1.12.2"></a>1.12.2　保罗《论城市长官职务》单卷

依神皇哈德良的书信，在金钱诉讼中，银行家可以向城市长官起诉，也可以成为被诉一方。

### <a id="1.12.3"></a>1.12.3　乌尔比安《告示评注》第二卷

城市长官离开城界后即无权行使其职权；但在城外仍可命令进行审判。〔底本未明确此处受命审判者，见疑难表。〕
