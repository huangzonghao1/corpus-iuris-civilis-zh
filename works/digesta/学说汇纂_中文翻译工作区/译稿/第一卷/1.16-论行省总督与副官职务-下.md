# 第一卷

## 1.16　论行省总督与副官的职务（续）

### <a id="1.16.7"></a>1.16.7　乌尔比安《论行省总督职务》第二卷

<a id="1.16.7.pr."></a>**序言。** 如果总督到达的不是著名城市或行省首府，而是其他城市，他应允许该城向他陈述本城的美德，并不厌其烦地听取对自己的赞誉；行省居民有权以此表示对他的敬意。他还应依照既往惯例和习俗准许举行节庆。

<a id="1.16.7.1"></a>**1.** 总督应巡视神庙和公共工程，检查其是否完好、是否需要修缮；对于已经开工的工程，应尽可能按照该城市的财力促其完工。他还应依照惯例郑重任命勤勉的工程监理人；如有需要，也应调派军中人员协助监理人。

<a id="1.16.7.2"></a>**2.** 既然总督享有最完整的管辖权，那么在罗马以官职身份或以非常程序行使司法权者所负职责，均归总督管辖。

### <a id="1.16.8"></a>1.16.8　乌尔比安《评告示》第三十九卷

因此，在该行省中，除元首以外，总督的统治权高于所有其他人。

### <a id="1.16.9"></a>1.16.9　乌尔比安《论行省总督职务》第一卷

<a id="1.16.9.pr."></a>**序言。** 行省中没有任何事务不由总督处理。当然，如果是涉及元首财政代理官的金钱请求案件，总督最好回避。

<a id="1.16.9.1"></a>**1.** 如有必要作出裁断，总督不能通过书面申请处理；凡是需要审理事实的案件，均不能仅凭书面申请解决。

<a id="1.16.9.2"></a>**2.** 对于诉讼辩护人，总督应当宽容，但也须有分寸，以免显得可受轻视。如果发现有人操弄诉讼或买卖诉讼案件，应予以制止；只有依其告示获准出庭陈述的人，才可以提出请求。

<a id="1.16.9.3"></a>**3.** 总督可以不经正式审理而简易处理下列事项：命令子女尊敬父母、释奴尊敬保护人以及保护人的子女；对于父亲带来、据称行为不端的儿子，也可以当场加以告诫和威吓。同样，对于不服从的自由释奴，总督可以口头训诫，或用杖责加以纠正。

<a id="1.16.9.4"></a>**4.** 因此，总督应安排一定的请求受理次序，使所有人的请求都能得到听取；否则，若优先考虑显贵请求者，或屈从于无理要求，那些地位普通的人便可能无法陈述自己的诉求——他们或许根本没有聘请辩护人，或所聘辩护人的人数较少、也不具显要地位。

<a id="1.16.9.5"></a>**5.** 通常，总督应准许为请求者提出的辩护人申请：对于妇女、未成年人、其他弱势者或精神不健全者，如有人代为申请，应予准许；如无人代为申请，总督也应主动为其指派辩护人。如果有人称自己因对方势力强大而找不到辩护人，总督同样应为他指派辩护人。不得任由任何人因对方的势力而受压迫。若有人如此专横，以至人人都害怕接受委托、为其对方辩护，这也会使行省长官蒙受非议。

<a id="1.16.9.6"></a>**6.** 以上各项也是所有行省长官共同适用、并都应遵守的规则。

### <a id="1.16.10"></a>1.16.10　乌尔比安《论行省总督职务》第十卷

<a id="1.16.10.pr."></a>**序言。** 总督应当记住，在继任者到达之前，他必须处理一切事务。因为总督职务只有一个，而行省的利益要求始终有人处理行省居民的事务。因此，他应持续行使司法权，直至继任者到达。

<a id="1.16.10.1"></a>**1.** 总督不得在自己离开之前先让副官离开行省。《朱莉娅反勒索法》以及神皇哈德良致亚该亚行省总督卡尔普尔尼乌斯·鲁弗斯的敕答，都对此作了告诫。

### <a id="1.16.11"></a>1.16.11　维诺尼乌斯《论行省总督职务》第二卷

如果某事需要更严厉的惩处，副官应将其移交总督处理；因为副官没有惩罚、强制或施以严酷鞭打的权力。

### <a id="1.16.12"></a>1.16.12　保罗《评告示》第二卷

总督副官受命行使司法管辖权后，〔原文止于 *iudicis*，句意未完。〕

### <a id="1.16.13"></a>1.16.13　庞波尼乌斯《评昆图斯·穆基乌斯》第十卷

总督副官本身不享有任何固有职权，除非总督已将管辖权委托给他。

### <a id="1.16.14"></a>1.16.14　乌尔比安《评朱莉娅法与帕皮娅法》第二十卷

行省总督所用的束棒至多为六束。

### <a id="1.16.15"></a>1.16.15　利基尼乌斯《规则》第三卷

行省总督的副官可以指定监护人。

### <a id="1.16.16"></a>1.16.16　乌尔比安《评告示》第二卷

行省总督进入罗马城门后，即放弃其统治权（*imperium*）。
