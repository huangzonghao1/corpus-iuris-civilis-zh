# 第一卷

## <a id="1.19"></a>1.19　论皇帝代理官或财务官的职务

### <a id="1.19.1"></a>1.19.1　乌尔比安《评告示》第十六卷

<a id="1.19.1.pr."></a>**序言。** 皇帝代理官（*procurator Caesaris*）所实施和办理的事项，均由皇帝予以认可，效力如同由皇帝亲自实施。

<a id="1.19.1.1"></a>**1.** 如果皇帝的代理官把皇帝的财产当作自己的财产交付，我认为他不能移转该财产的所有权。只有当他在办理皇帝事务、并经皇帝同意而交付时，才发生所有权移转。因此，如果他以买卖、赠与或和解为由处分皇帝财产，其行为均不发生效力；他受命的职责是勤勉管理皇帝财产，而非将其让与他人。

<a id="1.19.1.2"></a>**2.** 皇帝代理官有一项特殊职权：皇帝的奴隶经皇帝命令，可以接受遗产；若皇帝被指定为继承人，代理官通过接受一项丰厚遗产，可以使皇帝成为继承人。

### <a id="1.19.2"></a>1.19.2　保罗《箴言》第五卷

如果指定皇帝为继承人的遗产不足以清偿债务，就应在查明情况后请示皇帝；因为，对于这类遗产，必须查明作为指定继承人的皇帝愿意接受还是抛弃继承。

### <a id="1.19.3"></a>1.19.3　卡利斯特拉图《审判论》第六卷

<a id="1.19.3.pr."></a>**序言。** 皇帝的财务官（*curator Caesaris*）没有放逐权，因为他们无权作出这种刑罚。

<a id="1.19.3.1"></a>**1.** 不过，如果他们以某人扰乱秩序或侵害皇帝佃户为由，禁止其进入皇帝的庄园，就应当停止这样做；神皇庇护曾以敕答告知尤利乌斯此事。〔*abstinere debebit* 的具体所指待核，见疑难表。〕

<a id="1.19.3.2"></a>**2.** 此外，他们也无权准许任何人返回；皇帝塞维鲁与安敦宁曾针对赫尔米亚的请求以敕答作此规定。〔返回的对象及其所涉放逐、入庄园禁令的关系，底本文段未详。〕
