# 第一卷

## 1.2　论法的起源、各级官职的起源及法学家的传承（续）

<a id="1.2.2.14"></a>**14.** 就官职而言，可以确定，在罗马共同体初创之时，国王拥有全部权力。

<a id="1.2.2.15"></a>**15.** 同一时期还设有“迅捷骑兵统帅”（*tribunus celerum*）。此人统领骑兵，地位仅次于国王。朱尼乌斯·布鲁图（Junius Brutus）便曾担任这一职务；他主张驱逐国王。

<a id="1.2.2.16"></a>**16.** 国王被驱逐之后，设立了两名执政官。法律规定，最高权力由他们掌握；他们的名称据说源于其最为关切共和国事务。为防止他们全面攫取王权，法律赋予人民向其提出申诉的权利，并禁止他们未经人民许可便对罗马公民判处死刑。他们仅保留惩戒权，并可命令将人押入公立监狱。

<a id="1.2.2.17"></a>**17.** 后来，人口普查需要耗费更多时间，执政官又不足以兼理这项职责，于是设立了监察官。

<a id="1.2.2.18"></a>**18.** 随着人民增加，战争频繁发生，邻近民族有时发动更为猛烈的战争；在情势需要之时，人们决定设立权力更大的官职，于是任命独裁官。独裁官的决定不得上诉，并被授予判处死刑的权力。由于这一官职权力至高无上，不得任职超过六个月。

<a id="1.2.2.19"></a>**19.** 独裁官还配有骑兵长官，其设置方式如同国王配有迅捷骑兵统帅。这个职位大致相当于今日近卫军长官的职位，但当时仍属于法定官职。

<a id="1.2.2.20"></a>**20.** 同一时期，国王被驱逐约十七年后，平民与贵族发生分裂并退出共同体；平民在圣山上为自己选出保民官，作为平民的官职人员。其所以称为保民官，有一种说法是：人民过去分为三个部分，每部分各选一人；另一种说法是：他们由各部族投票选出。

<a id="1.2.2.21"></a>**21.** 平民还选出两名出身平民的官员，负责管理平民存放其决议的神庙；这两名官员也称为市政官。

<a id="1.2.2.22"></a>**22.** 后来，人民的国库日益充实；为有人管理国库，遂设立财务官，由其掌管钱款。其名称据说源于他们受任调查并保管钱款。

<a id="1.2.2.23"></a>**23.** 正如前文所说，法律不允许执政官未经人民许可便对罗马公民的生死事项行使司法权。因此，人民另行设立负责刑事案件的财务官，称为“弑亲罪财务官”（*quaestores parricidii*）；《十二表法》也提及此职。

<a id="1.2.2.24"></a>**24.** 后来，人们决定制定法律，并向人民提出一项议案，要求所有官员辞去职务，以便选出十人团。十人团任职一年后自行延长任期，且行为横暴；他们不愿再选出继任官员，企图使自己及其派系永久把持共和国。他们统治过度严苛，终于使军队脱离共和国。相传，分裂的导火索是一个名叫维尔吉尼乌斯（Verginius）的人。他发现阿庇乌斯·克劳狄乌斯违背自己所参与制定、并从旧法移入《十二表法》的法律，否认其女儿的自由身份主张，反而判令其女儿归属一名声称她是自己奴隶的人。阿庇乌斯迷恋维尔吉尼娅（Virginia），因而混淆一切正当与不正当。维尔吉尼乌斯对此愤慨不已：最古老的法律惯例竟在自己的女儿身上失效了。此前，罗马首任执政官布鲁图曾在维泰利乌斯家族一名奴隶的身份诉讼中，判令其按自由人身份对待；该奴隶曾以证词揭露一项叛国阴谋。维尔吉尼乌斯认为，女儿的贞洁甚至重于她的生命，便从屠夫店中取刀杀死女儿，意在以她的死阻止对她的性侵凌辱。他刚杀死女儿，手上还沾着女儿的鲜血，便立即逃往战友那里。战友们当时驻扎在阿尔吉杜斯，正在那里作战；他们抛下原有的将领，把军旗移至阿文丁山。城内平民随后也纷纷前往那里。经人民共同决议，有些人被处死于狱中。共和国由此恢复原有秩序。

<a id="1.2.2.25"></a>**25.** 数年后，《十二表法》颁行。平民与贵族发生争执，平民希望从自己阶层中选出执政官，贵族则予以拒绝。于是，人们设立拥有执政官权力的军事保民官，其中有些出身平民，有些出身贵族。其人数并不固定：有时二十人，有时更多，有时更少。

<a id="1.2.2.26"></a>**26.** 后来，人们同意也从平民中选出执政官，执政官遂开始由两个阶层共同产生。为使贵族人数略占优势，人们决定从贵族中选出两人。

<a id="1.2.2.27"></a>**27.** 库鲁尔市政官由此产生。执政官经常因邻近地区的战争而离城，城内便无人能够行使司法裁判权，于是又设立裁判官，并称为“城市裁判官”，因为他在城内行使司法权。

<a id="1.2.2.28"></a>**28.** 数年后，由于该裁判官不足以应付大量来到城内的外邦人，遂又设立另一名裁判官，称为“外邦人裁判官”，因为他通常在外邦人之间行使司法权。

<a id="1.2.2.29"></a>**29.** 后来，由于需要设置主持以长矛为标志的司法拍卖的官员，人们设立了十人诉讼裁判官。

<a id="1.2.2.30"></a>**30.** 同一时期还设立了四人道路管理官、三人铸币官（负责铸造铜币、银币和金币），以及三人刑务官，负责看守监狱；需要执行刑罚时，也由他们参与办理。

<a id="1.2.2.31"></a>**31.** 官员在晚间不便公开处理事务，因此又设立五人官，在台伯河此岸及彼岸各自履职，以代行其他官员的职务。

<a id="1.2.2.32"></a>**32.** 罗马先后征服撒丁尼亚、西西里、西班牙以及纳尔榜行省后，所征服的每个行省均相应增设裁判官：有些负责城内事务，有些负责行省事务。〔此处底本网页出现粘连文字 *praessententiarum Deinde*；译文据句法分开处理，待以校本复核。〕此后，科尔涅利乌斯·苏拉设立若干公诉审理程序，例如伪造、弑亲和杀人案件的审理程序，并增设四名裁判官。后来，盖乌斯·尤利乌斯·恺撒又增设两名裁判官和两名负责粮食事务的市政官；后者因谷物女神刻瑞斯（Ceres）之名而称为“刻瑞斯市政官”。至此，共设十二名裁判官和六名市政官。其后，神圣的奥古斯都设立十六名裁判官；神圣的克劳狄乌斯又增设两名裁判官，负责处理遗嘱信托事务。神圣的提图斯撤去其中一人；神圣的涅尔瓦则增设一人，负责审理国库与私人之间的争议。这样，城内共有十八名裁判官行使司法权。

<a id="1.2.2.33"></a>**33.** 只要各级官员留在共和国境内，上述安排便照常实行；他们离城时，则留下一人行使司法权，此人称为城市长官。城市长官原先早已有之；后来通常为拉丁节庆而设置，此后每年均照此办理。粮食长官和警卫长官并非通常官职，而是为实际需要特别设置的官员。不过，前文所称台伯河两岸的官员，后来依据元老院决议改由市政官担任。

<a id="1.2.2.34"></a>**34.** 因此，在这些官员之中，有十名平民保民官、两名执政官、十八名裁判官和六名市政官在城内行使司法权。

<a id="1.2.2.35"></a>**35.** 许多杰出人物都曾公开讲授市民法知识。此处应当提及其中最受罗马人民尊崇的人物，以说明这些法律由何人、以何种方式创制并传承。人们记载，在所有掌握这门知识的人中，提比略·科伦卡尼乌斯（Tiberius Coruncanius）之前，没有人公开讲授法律；其他人则倾向于私下保有市民法知识，只接待前来咨询的人，而不向愿意学习的人传授。

<a id="1.2.2.36"></a>**36.** 首先有精通法律的普布利乌斯·帕皮里乌斯（Publius Papirius），他将国王颁布的法律汇编在一起。其后是十人团成员之一阿庇乌斯·克劳狄乌斯，他在编写《十二表法》时发挥了重要作用。此后，同族的另一位阿庇乌斯·克劳狄乌斯也极为精通法律，人称“百手者”（*centemmanus*）；他修建了阿庇亚大道，引入克劳狄乌斯水道，并主张不应允许皮洛士进入罗马城。据传，他还撰写了诉讼程式，并最早论述占有的中断（*usurpationes*）；该书今已不存。另一位似乎承继其事业的阿庇乌斯·克劳狄乌斯，还引入了字母 e，使“瓦莱西”（*Valesii*）变为“瓦莱里”（*Valerii*），使“福西”（*Fusii*）变为“福里”（*Furii*）。〔底本所列字母与所举姓名变化似不相符，暂依底本文字保留，列入疑难表。〕

<a id="1.2.2.37"></a>**37.** 此后，塞姆普罗尼乌斯（Sempronius）以极高的法律造诣闻名；罗马人民称他为“智者”（*sofon*），此前和此后都没有人获此称号。盖乌斯·西庇阿·纳西卡（Gaius Scipio Nasica）被元老院称为“最优秀者”；元老院还在圣道旁拨给他一处公宅，使人们更容易向他咨询。再后来，昆图斯·穆基乌斯（Quintus Mucius）受命出使迦太基。当时摆着两枚签牌，一枚代表和平，一枚代表战争；人们让他任选一枚带回罗马。他把两枚都拿走，并说应由迦太基人请求罗马，告知他们愿意接受哪一枚。

<a id="1.2.2.38"></a>**38.** 此后有提比略·科伦卡尼乌斯，正如前文所说，他是第一个开始公开讲授法律的人。他没有留下著作，但留下许多重要且令人难忘的法律解答。接着，塞克斯图斯·埃利乌斯（Sextus Aelius）、他的兄弟普布利乌斯·埃利乌斯（Publius Aelius）和普布利乌斯·阿提利乌斯（Publius Atilius）都以公开讲授法律而享有盛名；两位埃利乌斯都曾任执政官，阿提利乌斯则是第一个被人民称为“智者”的人。恩尼乌斯（Ennius）也赞扬过塞克斯图斯·埃利乌斯；他的著作《三部论》（*Tripertita*）至今尚存，被视为法律的摇篮。《三部论》之所以得名，是因为它先列《十二表法》，继而附上解释，最后再接续法定诉讼。另有三部著作也被认为出自他手，但有人否认；加图曾在一定程度上承袭这些著作。此后还有波尔基乌斯家族的始祖马尔库斯·加图（Marcus Cato），他的著作也留存至今；其后世多由他的众多儿子繁衍而来。
