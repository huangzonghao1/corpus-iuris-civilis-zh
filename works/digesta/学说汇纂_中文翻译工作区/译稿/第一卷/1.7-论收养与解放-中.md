# 第一卷

## 1.7　论收养、解放及其他解除家父权的方式（续）

### <a id="1.7.15"></a>1.7.15　乌尔比安《萨宾评注》第二十六卷

<a id="1.7.15.pr."></a>**序言。** 家父被自权人收养时，其原有且依法可能取得的一切财产，均依法默示转归收养者。此外，处于其家父权之下的子女也随其转归收养者；依据复归权返归者，以及在其被自权人收养时已在母腹中的子女，也同样被置于收养者的家父权之下。

<a id="1.7.15.1"></a>**1.** 某人有两个儿子，并有一个由其中一子所生的孙子。若他想将该孙子收养为仿佛由另一子所生，可以先将孙子解放出家父权，再将其收养为仿佛由另一子所生。因为他此时的身份如同任何收养者，而非祖父；既然任何人都可以收养某人，使其视同由自己所生，同理也可以使其视同由另一子所生。

<a id="1.7.15.2"></a>**2.** 在自权人收养中，应查明收养者是否未满六十岁，因为他通常应更专注于生育子女；但若有疾病、身体状况或其他正当收养理由，例如希望收养与自己关系亲近之人，则不在此限。

<a id="1.7.15.3"></a>**3.** 除非有正当理由，任何人均不得自权人收养多人；也不得自权人收养他人的自由释奴，未成年人亦不得自权人收养比自己年长之人。

### <a id="1.7.16"></a>1.7.16　雅沃勒努斯《卡西乌斯评注》第六卷

收养只能适用于自然关系亦可能存在的那些人之间。

### <a id="1.7.17"></a>1.7.17　乌尔比安《萨宾评注》第二十六卷

<a id="1.7.17.pr."></a>**序言。** 若被自权人收养者未满二十五岁，不得允许曾担任其监护人或保佐人的人收养他，以免此人借收养逃避交代账目。还应查明收养是否另有不正当动机。

<a id="1.7.17.1"></a>**1.** 只有基于自然亲属关系或至深情感而收养未成年被监护人的，才可准许该项自权人收养；其他情形均应禁止，以免监护人得以自行终止监护，并消灭父母已作出的替补安排。

<a id="1.7.17.2"></a>**2.** 首先应查明未成年人的财产状况以及拟收养人的财产状况，并据此衡量该收养是否有利于未成年人；其次，应考察拟收养人的生活品行；第三，应考察他的年龄，以判断他是否更应考虑生育子女，而非将他人从另一家庭纳入自己的权力之下。

<a id="1.7.17.3"></a>**3.** 此外，还应考察是否应允许已经有一个或多个子女的人再收养他人，以免其婚生子女各自通过孝顺为自己争取的前途受到损害，或被收养者所得少于其应得之份。

<a id="1.7.17.4"></a>**4.** 有时也可以允许富人收养穷人，前提是富人的生活俭朴有目共睹，或其情意诚挚、为人熟知。

<a id="1.7.17.5"></a>**5.** 在这些情形中，通常须提供担保。

### <a id="1.7.18"></a>1.7.18　马尔凯卢斯（Marcellus）《学说汇纂》第二十六卷

只有在自权人收养未成年被监护人者提供了担保后，才应同意其收养意愿；该担保应确保：若被收养者仍保持原身份时相关财产本应归属某些人，那么收养者应将其从被收养者财产中取得之物返还给这些人。担保应向公奴提供。
