# 第一卷

## <a id="1.11"></a>1.11　论禁卫军长官的职务

### <a id="1.11.1"></a>1.11.1　奥勒利乌斯·阿尔卡狄乌斯·卡里西乌斯（Aurelius Arcadius Charisius），御札长官（*magister libellorum*），《论禁卫军长官职务》单卷

<a id="1.11.1.pr."></a>**序言。** 有必要简要说明禁卫军长官职务的设立起源于何处。有些作者记载，古时设立禁卫军长官，是为了代行骑兵长官的职务。因为在古人时代，独裁官会暂时受托行使最高权力，并为自己选任骑兵长官；后者与独裁官共同承担职责，协助处理军事事务，并行使仅次于独裁官的权力。国家治理权转移到终身执政的皇帝手中后，元首便仿照骑兵长官选任禁卫军长官，并赋予他们更广泛的权限，以整饬公共秩序。

<a id="1.11.1.1"></a>**1.** 禁卫军长官的权威由此起步，并不断增强，最终达到其裁决不得上诉的程度。此前人们曾探讨能否对禁卫军长官的裁决提出上诉；法律确实允许上诉，也有上诉的先例。后来，在元首的裁决公开宣读之后，上诉权被禁止。元首认为，获选担任这一重要职务的人，既具有卓越的才干，忠诚和庄重也经过考察；凭借他们的智慧以及职务所赋予的显赫地位，他们作出的裁判不会有异于元首本人作出的裁判。

<a id="1.11.1.2"></a>**2.** 禁卫军长官还享有另一项特权：未成年人若因其裁决而需要恢复原状，只能由禁卫军长官本人予以恢复，其他官员均无权办理。
