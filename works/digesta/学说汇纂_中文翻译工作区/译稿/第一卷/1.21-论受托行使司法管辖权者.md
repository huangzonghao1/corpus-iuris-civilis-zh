# 第一卷

## <a id="1.21"></a>1.21　论受托行使司法管辖权者的职务

### <a id="1.21.1"></a>1.21.1　帕皮尼安《法律问题》第一卷

<a id="1.21.1.pr."></a>**序言。** 凡由法律、元老院决议或元首敕令特别授予的权限，均不因司法管辖权的委托而转移；但因官员身份而享有的权限，可以委托。因此，官员若依法或依元老院决议被授权审理公诉案件，例如依据《朱莉娅通奸法》或其他类似法律被授权审理此类案件，却委托他人行使自己的管辖权，看起来便是错误的。对此最有力的证明是，《朱莉娅暴力法》明确规定，获分配审理权的人若启程离开，可以委托他人行使该权。因此，只有在他开始离开时才可以作此委托；其他情形下，即使官员本人在场，也可以委托司法管辖权。如果有人被指控遭其家奴杀害，裁判官依据元老院决议享有的审查权，也不得委托他人行使。

<a id="1.21.1.1"></a>**1.** 接受司法管辖权委托的人，本身不享有任何固有权限，而是行使委托者的管辖权。更妥当的说法是，依祖先的惯例，司法管辖权虽可转移，但依法授予的纯粹统治权（*merum imperium*）不能转移。因此，没有人会说，行省总督的副官仅凭受托的管辖权就享有惩处权。**保罗注：**与司法管辖权相连的统治权，在委托司法管辖权时也可以一并转移；这种说法更为妥当。

### <a id="1.21.2"></a>1.21.2　乌尔比安《论所有法庭》第三卷

<a id="1.21.2.pr."></a>**序言。** 总督委托司法管辖权后，受托者不得行使总督的顾问会议职权（*consilium*）。〔*consilium* 的具体职权含义见疑难表。〕

<a id="1.21.2.1"></a>**1.** 如果监护人或保佐人想要出售不动产，裁判官或行省长官应在审查具体情形后予以许可。若其已委托司法管辖权，就绝不能再把此项审查权委托出去。

### <a id="1.21.3"></a>1.21.3　尤利安《学说汇纂》第五卷

即使执行他人管辖权的人本身是裁判官，他行事时也不是依据自己的统治权，而是依据委托其行使司法权者的统治权；凡是他代行委托者职责时，均是如此。

### <a id="1.21.4"></a>1.21.4　马凯尔《论行省长官职务》第一卷

<a id="1.21.4.pr."></a>**序言。** 对可疑监护人的审查可以委托他人。事实上，为了未成年人的利益，即使一般管辖权已经委托出去，受托者也可以审理此类案件；相关决定如下：“皇帝塞维鲁与安敦宁致阿非利加行省总督布拉杜阿：既然你已将自己的管辖权授予副官，他们也可以审理可疑监护人案件，理所当然。”

<a id="1.21.4.1"></a>**1.** 下列事项可以委托他人办理：授予遗产占有；在未提供损害可能发生的担保时，命令申请人占有有关财产；以胎儿利益为由，将妇女置于占有状态；以及为保全遗赠，将遗赠受领人置于占有状态。

### <a id="1.21.5"></a>1.21.5　保罗《评普劳提乌斯》第十八卷

<a id="1.21.5.pr."></a>**序言。** 显然，受托行使司法管辖权的人不能再将其转委托给他人。

<a id="1.21.5.1"></a>**1.** 将司法管辖权委托给私人时，似乎也一并授予了非纯粹的统治权（*imperium non merum*），因为司法管辖权若没有少许强制权，便无从行使。
