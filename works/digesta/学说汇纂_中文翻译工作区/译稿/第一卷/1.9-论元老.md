# 第一卷

## <a id="1.9"></a>1.9　论元老

### <a id="1.9.1"></a>1.9.1　乌尔比安《告示评注》第六十二卷

<a id="1.9.1.pr."></a>**序言。** 毫无疑问，具有执政官级身份的女子应当让位于具有执政官级身份的男子。但具有裁判官级身份的男子是否也应优先于前者，仍须考察。我认为应当优先，因为男子的性别具有更高的身份尊荣。

<a id="1.9.1.1"></a>**1.** 我们所谓具有执政官级身份的女子，是指执政官的妻子。萨图尼努斯还将执政官之母列入其中，但这一说法既无任何记载，也从未被接受。

### <a id="1.9.2"></a>1.9.2　马尔凯卢斯《学说汇纂》第三卷

卡西乌斯·隆吉努斯认为，因品行卑劣而被逐出元老院、且未获恢复元老身份的人，不得担任裁判者，也不得作证，因为《尤利亚敲诈法》禁止此事。

### <a id="1.9.3"></a>1.9.3　莫德斯蒂努斯《规则》第六卷

神皇塞维鲁和安东尼努斯准许被逐出元老院者不发生人格减等（*capitis deminutio*），并继续留居罗马。

### <a id="1.9.4"></a>1.9.4　庞波尼乌斯《杂读集》第十二卷

不配居于较低位阶者，更不配居于较高位阶。

### <a id="1.9.5"></a>1.9.5　乌尔比安《朱利亚与帕皮亚法评注》第一卷

我们所称的元老之子，不仅包括自然子，也包括养子。养子由谁收养、以何种方式收养，均无关紧要；元老是在取得元老身份之后还是之前收养此人，也不影响这一点。

### <a id="1.9.6"></a>1.9.6　保罗《朱利亚与帕皮亚法评注》第二卷

<a id="1.9.6.pr."></a>**序言。** 元老所收养之人也是元老之子，但前提是仍留在其家族之中；若被解放出父权，则因解放行为而丧失儿子的身份。

<a id="1.9.6.1"></a>**1.** 元老将儿子交付给身份较低者收养，该子仍视为元老之子；因为被身份较低者收养，不会使其丧失元老身份，正如执政官不会因此不再是执政官。

### <a id="1.9.7"></a>1.9.7　乌尔比安《朱利亚与帕皮亚法评注》第一卷

<a id="1.9.7.pr."></a>**序言。** 通说认为，由元老父亲解放出父权的人，仍视同元老之子。

<a id="1.9.7.1"></a>**1.** 拉贝奥还写道，元老之子即使在父亲死后出生，也视同元老之子。但如果某人在其父被逐出元老院之后才受孕并出生，普罗库鲁斯和佩加苏斯认为此人不视同元老之子；这一意见是正确的，因为父亲在此人出生前已被逐出元老院，严格而言，此人便不应称为元老之子。

若某人在父亲被逐出元老院之前已经受孕，却在父亲丧失身份之后才出生，则更应将其视同元老之子，因为多数人认为应以受孕时点为准。

<a id="1.9.7.2"></a>**2.** 某人若有元老父亲和元老祖父，则既视同元老之子，也视同元老之孙。但若其父亲在该人受孕之前已丧失身份，那么即使此人不视同元老之子，是否仍应视同元老之孙，便值得探讨。较妥当的结论是应当如此，使祖父的身份对他有利，而不使父亲遭遇的变故对他不利。

### <a id="1.9.8"></a>1.9.8　乌尔比安《遗嘱信托论》第六卷

嫁给显贵男子的女子，也包括在“显贵者”（*clarissimae personae*）这一称谓之内。元老的女儿，除非嫁给显贵男子，否则不被称为“显贵妇人”（*clarissima femina*）。因为妇女的显贵身份由丈夫赋予；父母只能在女儿嫁给平民之前赋予她该身份。因此，只要显贵妇人仍嫁给元老或显贵男子，或者虽已与其分离、但未再嫁给身份较低者，她就仍保持显贵身份。

### <a id="1.9.9"></a>1.9.9　帕比尼安《答复集》第四卷

元老之女若与自由释奴结婚，不会仅因其父后来遭遇身份变故，就因此成为该男子的合法妻子；因为子女已经取得的身份尊荣，不应因父亲被逐出元老院而被剥夺。〔首句 *patris casus non facit uxorem* 的法律指向仍有歧义，见疑难表。〕

### <a id="1.9.10"></a>1.9.10　乌尔比安《告示评注》第三十四卷

我们所称的元老子女，不仅是元老的儿子，也包括所有被认为由元老本人或其子女所生的人；这些子女可以是自然子女，也可以是元老子女的养子女。但如果某人由元老的女儿所生，则应考察其父亲的身份。

### <a id="1.9.11"></a>1.9.11　保罗《告示评注》第四十一卷

元老虽被认为在罗马城设有住所，但也被认为在其出身之地设有住所；因为其身份似乎只是为住所增加一处，而非将住所迁往他处。

### <a id="1.9.12"></a>1.9.12　乌尔比安《户籍论》第二卷

<a id="1.9.12.pr."></a>**序言。** 曾嫁给执政官的女子，通常会向元首请求，虽然极少获准：即使她再嫁给身份较低的男子，仍保持执政官级身份。我知道，安东尼努斯皇帝曾将这一恩典给予其表亲尤利娅·玛梅娅（Iulia Mamaea）。

<a id="1.9.12.1"></a>**1.** 所谓元老，应理解为从贵族和执政官直到所有显贵男子；因为只有这些人可以在元老院发表意见。
