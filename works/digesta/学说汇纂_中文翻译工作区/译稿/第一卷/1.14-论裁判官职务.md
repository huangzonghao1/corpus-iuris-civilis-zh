# 第一卷

## <a id="1.14"></a>1.14　论裁判官的职务

### <a id="1.14.1"></a>1.14.1　乌尔比安《萨宾评注》第二十六卷

父亲可以在身为家子、并担任裁判官的儿子面前释放奴隶。

### <a id="1.14.2"></a>1.14.2　保罗《萨宾评注》第四卷

此外，通说也认为，裁判官本人可以在自己面前被解放出父权，或被交付他人收养。

### <a id="1.14.3"></a>1.14.3　乌尔比安《萨宾评注》第三十八卷

巴尔巴里乌斯·菲利普斯（Barbarius Philippus）是逃亡奴隶，却在罗马谋求裁判官职位，并被指定为裁判官。庞波尼乌斯说，奴隶身份并未妨碍他担任裁判官，仿佛他不曾是裁判官；然而，事实上他确已履行裁判官职务。〔底本文字此处逻辑关系疑有问题，见疑难表。〕

但是，我们还应考察：如果某人在隐匿奴隶身份期间履行了裁判官职务，那么我们应当如何看待此事？他所发布的告示和作出的裁定，是否全都毫无法律效力？还是说，鉴于那些依法或依据其他权利在他面前进行诉讼之人的利益，这些行为应当有效？我认为这些行为均不应被否定，因为这样处理更为仁厚。罗马人民本可以将这种权力授予奴隶；即使他们知道此人是奴隶，也会使其获得自由。这一规则尤其应适用于元首。

### <a id="1.14.4"></a>1.14.4　乌尔比安《所有审判庭论》第一卷

裁判官不得自行指定自己为监护人或特定案件的裁判者。
