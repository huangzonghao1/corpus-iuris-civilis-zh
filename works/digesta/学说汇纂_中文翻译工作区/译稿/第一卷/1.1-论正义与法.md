# 第一卷

## <a id="1.1"></a>1.1 论正义与法

### <a id="1.1.1"></a>1.1.1　乌尔比安（Ulpianus）《法学阶梯》（*Institutionum*）第一卷

<a id="1.1.1.pr."></a>**序言。** 有志研习法律者，须先知“法”（*ius*）之名源于何处。所谓法，得名于“正义”（*iustitia*）；正如塞尔苏斯（Celsus）所精辟界定的，法是善与公平的技艺。

<a id="1.1.1.1"></a>**1.** 因此，人们有理由称我们为正义的祭司：我们奉行正义，宣示对善与公平的认识，分辨公平与不公，辨明合法与非法；我们希望借助刑罚的威慑，也借助奖赏的鼓励，使人趋善；倘若我没有弄错，我们所追求的是真正的哲学，而非徒具其表的哲学。

<a id="1.1.1.2"></a>**2.** 这门学问分为公法与私法两个领域。公法关乎罗马国家的整体状况；私法则关乎个人利益：有些事物有益于公共，有些则有益于私人。公法由宗教祭祀、祭司和各级官职构成。私法分为三部分：它由自然法、万民法或市民法的规则汇集而成。

<a id="1.1.1.3"></a>**3.** 自然法是自然教给一切动物的法；这种法并非人类独有，而是陆生动物、海生动物乃至鸟类共同享有的。男女结合（我们称之为婚姻）、生育后代和养育后代，均由此而来。我们看到，其他动物乃至野兽，也被认为熟习这种法。

<a id="1.1.1.4"></a>**4.** 万民法是各民族共同采用的法律。很容易看出，它与自然法有所不同：自然法为一切动物所共有，万民法则仅为人类彼此共同采用。

### <a id="1.1.4"></a>1.1.4　乌尔比安《法学阶梯》第一卷

释奴同样源自万民法。所谓释奴（*manumissio*），即从支配之手中释放出来，也就是赋予自由：只要某人仍处于奴隶身份，便受制于他人的支配和权力；获释之后，便脱离这种权力。释奴制度源自万民法，因为依自然法，人皆生而自由；既然奴隶制尚未为人所知，释奴制度也就无从谈起。但后来奴隶制随万民法而兴起，释奴这一恩惠制度随之产生。起初，自然法仅以一个名称将人统称为人；自万民法施行后，开始有三种身份：自由人、与之相对的奴隶，以及第三类自由释奴，即已经不再为奴的人。

### <a id="1.1.6"></a>1.1.6　乌尔比安《法学阶梯》第一卷

<a id="1.1.6.pr."></a>**序言。** 市民法既非全然背离自然法或万民法，也非处处受其支配；因此，当我们对共同法有所增益或减损时，便形成自身特有的法律，即市民法。

<a id="1.1.6.1"></a>**1.** 因此，我们的法律或为成文，或为不成文，正如希腊人所说：“法律中有些是成文的，有些是不成文的。”〔原站以拉丁字母转写：*twn nomwn ohi men eggrafoi, ohi de agrafoi*。〕

### <a id="1.1.9"></a>1.1.9　盖尤斯（Gaius）《法学阶梯》第一卷

所有依法律与习惯治理的民族，既适用本民族特有的法律，也适用全体人类共同享有的法律。每个民族为自身制定的法律，是该共同体所特有的，称为市民法，犹如该共同体自身的特有法律；自然理性为全体人类共同确立的法律，则为所有人同等遵守，称为万民法，仿佛是所有民族共同采用的法律。

### <a id="1.1.10"></a>1.1.10　乌尔比安《规则》（*Regularum*）第二卷

<a id="1.1.10.pr."></a>**序言。** 正义是坚定而持久的意志，旨在使每个人获得其应得之物。

<a id="1.1.10.1"></a>**1.** 法的准则如下：诚实生活，不害他人，各得其所。

<a id="1.1.10.2"></a>**2.** 法学是关于神事与人事的知识，是关于正当与不正当的学问。

### <a id="1.1.11"></a>1.1.11　保罗（Paulus）《萨宾评注》（*ad Sabinum*）第十四卷

“法”（*ius*）一词有多种含义。第一种含义是：凡始终符合公平与善者，称为法，如自然法。第二种含义是：在每个共同体内，对全体或多数人有益的法律，如市民法。市民法中的名誉法也同样可以称为法。即使裁判官作出不公正的裁决，也称其为“宣示法律”（*ius reddere*）；这里所依据的不是裁判官实际做了什么，而是裁判官本应当做什么。法另有一种含义，指宣示法律之处，即以所实施之事的名称，转称实施该事之处。对此处所可以这样界定：凡裁判官决定在不损其帝权尊严、不违祖先习俗的条件下宣示法律之地，皆可正当地称为“法庭”（*ius*）。
