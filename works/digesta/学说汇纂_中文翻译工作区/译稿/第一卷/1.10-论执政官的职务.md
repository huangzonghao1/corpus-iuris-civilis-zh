# 第一卷

## <a id="1.10"></a>1.10　论执政官的职务

### <a id="1.10.1"></a>1.10.1　乌尔比安《论执政官职务》第二卷

<a id="1.10.1.pr."></a>**序言。** 执政官的职责，是为有意释放奴隶的人提供意见。

<a id="1.10.1.1"></a>**1.** 两位执政官可以分别单独办理释奴；但若某人已向其中一位执政官提交了待释奴隶的名册，就不能再向另一位执政官办理释奴，因为两位执政官所办理的是彼此独立的释奴程序。当然，如果某位执政官因疾病或其他正当理由不能办理，元老院曾决议，由另一位执政官完成释奴程序。

<a id="1.10.1.2"></a>**2.** 执政官在自己面前释放自己的奴隶，毫无疑问是允许的。但是，如果某位执政官未满二十岁，他就不能在自己面前办理释奴，因为依元老院决议，由他本人审查释奴理由；但如果理由已获认可，他可以在同僚面前办理。
