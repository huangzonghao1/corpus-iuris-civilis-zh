# 第一卷

## 1.7　论收养、解放及其他解除家父权的方式（续）

### <a id="1.7.19"></a>1.7.19　乌尔比安《萨宾评注》第二十六卷

<a id="1.7.19.pr."></a>**序言。** 关于自权人收养者必须提供的担保，其文书使用“向与此事有关之人负责”这一表述；毫无疑问，这一担保保障了遗嘱第二表中给予的自由，并且更应保障遗嘱指定的替补奴隶及受遗赠人。

<a id="1.7.19.1"></a>**1.** 若未提供该项担保，可以对自权人收养者提起有益诉讼。

### <a id="1.7.20"></a>1.7.20　马尔凯卢斯《学说汇纂》第二十六卷

只有在未达青春期年龄者死亡时，才适用上述担保。尽管本段谈的是男性未达青春期年龄者，女性亦应同样适用。

### <a id="1.7.21"></a>1.7.21　盖尤斯《规则》单卷

根据元首的敕答，女性也可以被自权人收养。

### <a id="1.7.22"></a>1.7.22　乌尔比安《萨宾评注》第二十六卷

<a id="1.7.22.pr."></a>**序言。** 如果自权人收养者留下了一名被收养的未成年儿子，而该未成年者不久后也去世，那么自权人收养者的继承人是否负有责任？应当认为，继承人也须返还被自权人收养者的财产，并另加四分之一。〔底本此处的 *restituturus* 语法疑有讹误，见疑难表。〕

<a id="1.7.22.1"></a>**1.** 有人问：自权人收养者能否为未达青春期年龄的被收养者指定替补继承人？我认为不得指定；但若仅就收养者从其财产中取得的四分之一指定替补继承人，且该替补仅在被收养者达到青春期年龄前有效，或可允许。除此之外，若收养者以信托方式要求继承人日后返还财产，则不应准许该信托，因为财产并非依据被收养者本人的意思归其所有，而是依元首的保障措施而来。

<a id="1.7.22.2"></a>**2.** 无论某人将未成年人自权人收养为儿子，还是自权人收养为孙子，上述各项均适用。

### <a id="1.7.23"></a>1.7.23　保罗《告示评注》第三十五卷

被交付收养的人，与因收养而与其发生宗亲关系者成为法律上的亲属；与其并未发生宗亲关系者，则不成为法律上的亲属。因为收养带来的是宗亲关系之法，而非血缘关系之法。因此，若我收养某人为儿子，我的妻子并不因此成为他的母亲；她不因此成为他的法律亲属（*cognata*），因为收养不会使她与他发生宗亲关系。同样，我的母亲也不会成为他的祖母，因为她与我家族之外的人不发生宗亲关系。至于我收养的人，则会成为我女儿的兄弟，因为我女儿属于我的家族；不过，他们之间仍禁止通婚。

### <a id="1.7.24"></a>1.7.24　乌尔比安《论辩集》第一卷

不得在本人缺席或不同意的情况下自权人收养该人。

### <a id="1.7.25"></a>1.7.25　乌尔比安《意见集》第五卷

<a id="1.7.25.pr."></a>**序言。** 某人的女儿以家母身份生活，仿佛已依法脱离父权，后依遗嘱指定继承人而死亡。其父不得反悔并提出异议，声称自己未依法解放女儿出父权，因为当时没有证人在场。

<a id="1.7.25.1"></a>**1.** 任何人均不得在本人缺席时进行收养或自权人收养，也不得通过他人代行此类仪式。

### <a id="1.7.26"></a>1.7.26　尤利安《学说汇纂》第七十卷

我的儿子在脱离我的家父权后所收养的人，不是我的孙子。

### <a id="1.7.27"></a>1.7.27　尤利安《学说汇纂》第八十五卷

由养子所生之人，在市民法上取得养子的地位。

### <a id="1.7.28"></a>1.7.28　盖尤斯《法学阶梯》第一卷

对于处于家父权之下、既有儿子又有孙子的人，法律允许其自行决定：既可以使儿子脱离家父权而保留孙子，也可以反过来保留儿子的家父权地位而解放孙子；还可以使所有人都成为自权人。对曾孙辈亦应作相同理解。

### <a id="1.7.29"></a>1.7.29　卡利斯特拉图斯《法学阶梯》第二卷

如果自然父亲虽不能说话，却能以言语以外的方式明确表示愿将其儿子交付收养，则应确认该收养，其效力与依法完成的收养相同。
