# 第一卷

## 1.2　论法的起源、各级官职的起源及法学家的传承（续）

<a id="1.2.2.39"></a>**39.** 此后有普布利乌斯·穆基乌斯（Publius Mucius）、布鲁图（Brutus）和曼尼利乌斯（Manilius），他们奠定了市民法。他们之中，普布利乌斯·穆基乌斯留下十卷小著，布鲁图留下七卷，曼尼利乌斯留下三卷；曼尼利乌斯的著作仍以卷册形式流传。后两人都曾任执政官，布鲁图曾任裁判官，普布利乌斯·穆基乌斯还曾任最高祭司长。

<a id="1.2.2.40"></a>**40.** 他们之后有普布利乌斯·鲁提利乌斯·鲁弗斯（Publius Rutilius Rufus），他曾任罗马执政官和亚细亚行省总督；还有保卢斯·维尔吉尼乌斯（Paulus Verginius），以及那位斯多亚学派人物昆图斯·图贝罗（Quintus Tubero），他曾师从潘萨，也曾任执政官。同一时期还有塞克斯图斯·庞培（Sextus Pompeius），他是格奈乌斯·庞培的叔父；还有撰写历史著作的科埃利乌斯·安提帕特（Coelius Antipater），但他用功于修辞胜过法律知识。另有卢基乌斯·克拉苏（Lucius Crassus），他是普布利乌斯·穆基乌斯的兄弟，也称“穆尼亚努斯”；西塞罗称他为最善辞令的法学家。

<a id="1.2.2.41"></a>**41.** 此后，普布利乌斯之子昆图斯·穆基乌斯（Quintus Mucius）担任最高祭司长，并首次将市民法系统编排为十八卷。

<a id="1.2.2.42"></a>**42.** 昆图斯·穆基乌斯有许多学生，其中最具声望的有阿奎利乌斯·加卢斯（Aquilius Gallus）、卢基利乌斯·巴尔布斯（Lucilius Balbus）、塞克斯图斯·帕皮里乌斯（Sextus Papirius）和盖乌斯·尤文提乌斯（Gaius Iuventius）。塞尔维乌斯说，加卢斯在人民中最有声望。不过，这些人都是由塞尔维乌斯·苏尔皮基乌斯（Servius Sulpicius）提及的；若只看他们各自留下的著作，其内容并不足以使所有人争相研读。事实上，他们的著作几乎不在人们手中流传；塞尔维乌斯却在自己的著作中充分吸收了这些人的成果，因此他们的学说也借由他的著作得以保存。

<a id="1.2.2.43"></a>**43.** 塞尔维乌斯·苏尔皮基乌斯在诉讼辩论方面位居首位；或者可以确定地说，他仅次于马尔库斯·图利乌斯·西塞罗（Marcus Tullius Cicero）。据传，他曾为一位朋友的案件向昆图斯·穆基乌斯请教法律。昆图斯向他作出解答，但塞尔维乌斯未能理解，便再次询问；昆图斯再次回答，他仍未能领会。昆图斯于是责备他说：身为贵族、名门之后，又以诉讼辩论为业，却不懂自己所从事领域的法律，实在可耻。这番话仿佛一种羞辱，促使塞尔维乌斯·苏尔皮基乌斯（底本此处作 *Servius Tactus*）投身市民法研究。他广泛听取前文所述诸人的讲授，先由卢基利乌斯·巴尔布斯启蒙，尤其受阿奎利乌斯·加卢斯指导；加卢斯来自切尔基纳岛，因此塞尔维乌斯有许多著作在切尔基纳岛完成。塞尔维乌斯出使期间去世后，罗马人民在演讲台前为他立像；这尊像至今仍矗立在奥古斯都演讲台前。他留下许多卷册，著作近一百八十卷。

<a id="1.2.2.44"></a>**44.** 许多人从塞尔维乌斯受益，其中大多撰写过著作，包括：阿尔费努斯·瓦鲁斯（Alfenus Varus）、盖乌斯（Gaius）、奥卢斯·奥菲利乌斯（Aulus Ofilius）、提图斯·凯西乌斯（Titus Caesius）、奥菲狄乌斯·图卡（Aufidius Tucca）、奥菲狄乌斯·纳穆萨（Aufidius Namusa）、弗拉维乌斯·普里斯库斯（Flavius Priscus）、盖乌斯·阿泰乌斯（Gaius Ateius）、帕库维乌斯·拉贝奥（Pacuvius Labeo）、安提斯提乌斯·拉贝奥（Antistius Labeo）之父、辛纳（Cinna）和普布利基乌斯·盖利乌斯（Publicius Gellius）。其中十人合计撰写了十八卷；奥菲狄乌斯·纳穆萨将他们的著作汇编为一百四十卷。在这些学生中，阿尔费努斯·瓦鲁斯和奥卢斯·奥菲利乌斯最具声望。瓦鲁斯曾任执政官；奥菲利乌斯则一直保持骑士阶层身份。他是凯撒最亲近的人之一，留下许多市民法著作，足以奠定这门学问各个部分的基础。他最早撰写遗产五分之一税法（*lex vicensima*）的著作；在司法管辖方面，他也是第一个认真整理裁判官告示的人。在他之前，塞尔维乌斯只为布鲁图写过两卷关于告示的短篇评注。

<a id="1.2.2.45"></a>**45.** 同一时期还有特雷巴提乌斯（Trebatius），他也曾师从科尔涅利乌斯·马克西穆斯（Cornelius Maximus）；还有奥卢斯·卡斯凯利乌斯（Aulus Cascellius），他曾师从昆图斯·穆基乌斯·沃卢修斯（Quintus Mucius Volusius）。卡斯凯利乌斯官至财务官，此后不愿再谋求晋升；即使奥古斯都向他提出执政官职位，他也没有接受。他在遗嘱中指定普布利乌斯·穆基乌斯的孙子为继承人，以示对其尊崇。人们说，特雷巴提乌斯比卡斯凯利乌斯更博学，卡斯凯利乌斯比特雷巴提乌斯更善辞令，而奥菲利乌斯比二人都更有学问。卡斯凯利乌斯的著作只存一卷《格言集》，特雷巴提乌斯虽留下多部著作，却较少为人研读。

<a id="1.2.2.46"></a>**46.** 此后还有图贝罗（Tubero），他曾师从奥菲利乌斯。他出身贵族，后来由诉讼辩论转而研究市民法，尤其是在他控告昆图斯·利加里乌斯（Quintus Ligarius）而未能说服盖乌斯·凯撒之后。此人即昆图斯·利加里乌斯：他控制非洲海岸时，不允许身体虚弱的图贝罗登陆，也不让他取水。图贝罗因此控告他，西塞罗则为他辩护。西塞罗的演说《为昆图斯·利加里乌斯辩护》至今尚存，颇为出色。图贝罗被认为精通公法与私法，留下多部相关著作。他还刻意使用古语写作，因此他的著作不太受人欢迎。

<a id="1.2.2.47"></a>**47.** 此后最具声望的是阿泰乌斯·卡皮托（Ateius Capito）和安提斯提乌斯·拉贝奥（Antistius Labeo）。卡皮托追随奥菲利乌斯；拉贝奥则听过上述诸人讲授，并师从特雷巴提乌斯。卡皮托曾任执政官。奥古斯都曾向拉贝奥提出接任执政官的职位，拉贝奥却不愿接受这一荣誉，而是全心投入学术。他把全年分成两半：六个月留在罗马与学生相处，六个月则退居别处专心著述。因此他留下四百卷著作，其中许多至今仍在人们手中流传。这两人最初形成了仿佛不同的学派：卡皮托坚持沿用传授给他的学说；拉贝奥则凭借天赋和对自身学识的信心——他还研究其他哲学学科——着手作出大量创新。

<a id="1.2.2.48"></a>**48.** 此后，马苏里乌斯·萨宾努斯（Massurius Sabinus）继承卡皮托的学说，涅尔瓦（Nerva）继承拉贝奥的学说；他们使双方的分歧进一步扩大。涅尔瓦也是凯撒的亲信。马苏里乌斯·萨宾努斯出身骑士阶层，是第一个获准公开作出法律解答的人；这一特许后来成为制度，但当时是提比略·凯撒特别授予他的。

<a id="1.2.2.49"></a>**49.** 顺便说明，在奥古斯都之前，元首并不授予公开作出法律解答的权利。凡是对自身学识有信心的人，都会回答来咨询者的问题。他们并不总是出具加盖印记的书面答复，通常是直接写给法官，或由咨询者证明自己曾向其请教。神圣的奥古斯都为了提高法律权威，首次规定法学家应依据他的权威作出解答。从那时起，人们开始将这种权利视为一项恩惠而请求授予。因此，最优秀的元首哈德良曾收到几位前裁判官的请求，希望获准公开作出法律解答；他以敕答告知他们：这种权利通常不是请求而来，而是由元首授予。只要有人对自己的能力有信心，他很乐意让其准备好向人民作出解答。

<a id="1.2.2.50"></a>**50.** 因此，提比略·凯撒准许萨宾努斯向人民作出法律解答。萨宾努斯出身骑士阶层，获准时已年事渐高，约五十岁。他并不富有，主要靠自己的学生供养。

<a id="1.2.2.51"></a>**51.** 萨宾努斯之后是盖乌斯·卡西乌斯·隆吉努斯（Gaius Cassius Longinus），他是图贝罗之女的儿子；图贝罗之女又是塞尔维乌斯·苏尔皮基乌斯的孙女，因此隆吉努斯称塞尔维乌斯为自己的曾祖父。他在提比略时期与夸尔蒂努斯（Quartinus）一同任执政官；他在共同体中享有极高声望，直到皇帝将他流放。

<a id="1.2.2.52"></a>**52.** 卡西乌斯被皇帝流放到撒丁尼亚，后来由韦斯巴芗召回，最终去世。普罗库鲁斯（Proculus）继承涅尔瓦的学说。同一时期还有涅尔瓦之子；另有一位隆吉努斯，出身骑士阶层，后来升至裁判官职位。但普罗库鲁斯的声望更高，影响也更大。法学家遂有一部分被称为卡西派，一部分被称为普罗库派；这两派的源头始于卡皮托和拉贝奥。

<a id="1.2.2.53"></a>**53.** 卡西乌斯之后由凯利乌斯·萨宾努斯（Caelius Sabinus）继承其学说；普罗库鲁斯之后由佩加苏斯（Pegasus）继承。凯利乌斯·萨宾努斯之后有普里斯库斯·雅沃勒努斯（Priscus Iavolenus）；佩加苏斯之后有塞尔苏斯（Celsus）。老塞尔苏斯之后，有其子塞尔苏斯和普里斯库斯·涅拉提乌斯（Priscus Neratius）；二人都曾任执政官，塞尔苏斯还第二次担任该职。普里斯库斯·雅沃勒努斯之后，则有阿布尔尼乌斯·瓦伦斯（Aburnius Valens）、图斯基亚努斯（Tuscianus）以及萨尔维乌斯·尤利安努斯（Salvius Iulianus）。
