# 第一卷

## 1.18　论行省长官的职务（续）

### <a id="1.18.10"></a>1.18.10　赫莫革尼安《法学摘要》第二卷

城市长官、禁卫军长官、执政官、裁判官以及罗马其他官员有权审理的所有案件，均属于行省纠察官和行省长官的审理范围。

### <a id="1.18.11"></a>1.18.11　马尔基安《法学阶梯》第三卷

因为，行省居民提出的所有请求——它们在罗马由不同裁判者管辖——都属于行省长官的职务范围。

### <a id="1.18.12"></a>1.18.12　普罗库鲁斯《书信集》第四卷

虽然行省长官应代行罗马所有官员的职责和职权，但仍应考察应当如何处理，而不是考察在罗马实际上如何处理。

### <a id="1.18.13"></a>1.18.13　乌尔比安《论行省总督职务》第七卷

<a id="1.18.13.pr."></a>**序言。** 正直而有威严的行省长官，理当使自己治理的行省保持安定与和平。若他勤勉履职，使行省不受恶人侵扰，并搜捕这些人，便不难做到这一点。他应搜捕亵渎神明者、强盗、拐掠者和窃贼，并依各人所犯之罪施以惩处；还应惩治窝藏、包庇他们的人，因为没有这些人，强盗便不能长期藏匿。

<a id="1.18.13.1"></a>**1.** 对于无法由亲属看管的精神失常者，行省长官应采取相应措施加以处置，即将其收容于监狱。神皇庇护曾以敕答作此规定。神皇兄弟还认为，就一名弑亲者而言，应查明其是否假装精神失常以实施犯罪，或确实丧失心智；若属假装，就应惩罚；若确实精神失常，则应将其收容于监狱。

### <a id="1.18.14"></a>1.18.14　马凯尔《公诉案件》第二卷

神皇马可·奥勒留与康茂德曾以如下文字敕答斯卡普拉·特图卢斯：“如果你已确切查明，埃利乌斯·普里斯库斯精神错乱至持续丧失心智、完全不具理解能力，而且没有任何迹象表明他是以假装痴狂的方式杀害其母，那么你可以不再追究他的刑罚，因为他已充分受到其精神错乱本身的惩罚。不过，仍须严加看管；如你认为必要，也可以用锁链约束他，因为这既关乎对他的惩罚，也关乎保护他本人和确保邻人的安全。

“但如果，如通常发生的那样，他有时神志较为清醒，并且犯罪并非发生在他可能具有辨认能力的那一刻，就不能以其疾病为由免除责任。你应当仔细调查；如果查明确有此种情形，就应请示我们，以便我们判断：若其在似乎能够辨认事理时实施如此残暴的犯罪，是否应处以刑罚。

“我们从你的信中得知，他处于这样的境况和身份，可以由家人或在自己的庄园中看管。如果你传唤当时负责看管他的人，查明发生如此重大疏忽的原因，并根据你认为每个人的过错应减轻还是加重，对他们分别作出处理，你这样做就是妥当的。因为看管精神失常者，不仅是为了防止他们谋划对自己造成严重伤害，也是为了防止他们危害他人。如果发生此类危害，将责任归于那些怠于履行职责的看管者，并非不当。”

### <a id="1.18.15"></a>1.18.15　马尔基安《公诉案件》第一卷

应当遵守的规则是：治理行省的人不得越出其行省疆界，除非是为履行誓愿；但他不得在外过夜。

### <a id="1.18.16"></a>1.18.16　马凯尔《论行省长官职务》第一卷

元老院决议规定，对于行省长官、其随员或其自由释奴在尚未进入行省之前所订立的交易，应极为谨慎地审理；因这些交易而未提起的诉讼，应在相关人员离开该行省后予以恢复。不过，如果某事违背其意愿而发生，例如他遭受侵害或盗窃，则仅应在以下范围内向他提供司法救济：使诉讼成立，并要求出示、交存被夺之物；或者要求其提供担保，承诺将该物带到庭上或予以出示。

### <a id="1.18.17"></a>1.18.17　塞尔苏斯《学说汇纂》第三卷

如果行省长官在得知继任者已经到达之前，释奴或指定监护人，这些行为仍然有效。

### <a id="1.18.18"></a>1.18.18　莫德斯蒂努斯《规则》第五卷

平民决议规定，任何行省长官都不得收受职务馈赠，但可以收受食物或饮料，条件是这些物品应在随后几日内消耗完毕。

### <a id="1.18.19"></a>1.18.19　卡利斯特拉图《审判论》第一卷

<a id="1.18.19.pr."></a>**序言。** 行使司法权者应注意：有人前来时，他应当容易接近，但不能让人轻视。因此，任命训令特别规定，行省长官不得与行省居民过分亲密；因为平等往来会使人轻视其尊严。

<a id="1.18.19.1"></a>**1.** 审理案件时，他既不应对自己认为有罪的人勃然大怒，也不应因不幸者的恳求而落泪；这不符合坚定、正直的裁判者的品格，因为其面容会泄露内心的情绪。总而言之，行使司法权应当使他凭借自身才干提升其职务的权威。

### <a id="1.18.20"></a>1.18.20　帕皮尼安《答复集》第一卷

皇帝的副官，即行省长官或行省纠察官，即使辞去职务，也不因此丧失其统治权（*imperium*）。

### <a id="1.18.21"></a>1.18.21　保罗《论司法顾问职务》单卷

行省长官审理奴隶被诱使败坏、女奴被夺去贞操或奴隶遭受性侵害的案件时，如果据称被诱使为非的是事务管理人的代理人（*actor rerum agentis*），或者所涉之人属于其行为不仅造成财产损失、还足以导致整个家宅败坏的那类人，便应施以最严厉的惩处。〔本段有关 *actor rerum agentis* 及其与后续条件从句的句法关系不明，见疑难表。〕
