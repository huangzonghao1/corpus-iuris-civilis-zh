# 第一卷

## <a id="1.8"></a>1.8　论物的分类与性质

### <a id="1.8.1"></a>1.8.1　盖尤斯《法学阶梯》第二卷

<a id="1.8.1.pr."></a>**序言。** 对物的基本分类可以归为两大类：有些属于神法，有些属于人法。属于神法的物，例如祭祀圣物和宗教性之物；受特别保护之物，例如城墙和城门，也在某种意义上属于神法。凡属于神法之物，均不属于任何人的财产；属于人法之物，通常归属于某人，但也可能不属于任何人的财产。例如，在尚无人取得继承人身份以前，遗产不属于任何人的财产。属于人法之物又分为公物与私物。公物不属于任何个人的财产，被认为属于共同体本身；私物则属于个别个人。

<a id="1.8.1.1"></a>**1.** 此外，有些物是有体物，有些是无体物。有体物是可以触摸的，例如土地、奴隶、衣物、金、银，乃至其他不可胜数之物。无体物则不能触摸，指存在于法律关系中的事物，例如继承权、用益权，以及以各种方式成立的债。继承中包含有体物，并不影响这一分类：从土地上取得的果实是有体物；依据某项债而应向我们给付的通常也是有体物，例如土地、奴隶或金钱。继承的权利本身、使用并收益的权利本身，以及债的权利本身，均属无体物。城市不动产和乡村不动产上的各项权利也属于无体物，这些权利亦称地役权。

### <a id="1.8.2"></a>1.8.2　马尔西安《法学阶梯》第三卷

<a id="1.8.2.pr."></a>**序言。** 有些物依自然法为全体人类所共有，有些属于共同体，有些不属于任何人；大多数则属于个人，并由各人基于不同原因取得。

<a id="1.8.2.1"></a>**1.** 依自然法为全体人类所共有的物包括：空气、流动的水、海洋，以及由此及于海岸。

### <a id="1.8.3"></a>1.8.3　弗洛伦提努斯《法学阶梯》第六卷

此外，我们在海岸发现的卵石、宝石及其他物，依自然法立即成为我们所有。

<a id="1.8.4.pr."></a>**序言。** 因此，任何人均不得被禁止为了捕鱼而前往海岸；但应避开他人的建筑物和纪念物，因为这些并不像海洋那样属于万民法。神皇安敦宁·庇护（Antoninus Pius）曾以敕答向福尔米亚和卡佩纳的渔民确认了这一点。〔底本此处语句有疑误，见疑难表。〕

<a id="1.8.4.1"></a>**1.** 然而，几乎所有河流和港口都属于公物。

### <a id="1.8.5"></a>1.8.5　盖尤斯《日常法或黄金论》第二卷

<a id="1.8.5.pr."></a>**序言。** 依万民法，河岸与河流本身一样，供公众使用。因此，任何人均可将船靠岸，使用岸边生长的树木系缆，晾晒渔网，并将渔网从海中拖回岸上；任何人也可在河岸放置物品，正如任何人均可在河流中航行一样。然而，河岸仍归附着该河岸的土地所有人所有；因此，在河岸生长的树木也归这些土地所有人所有。

<a id="1.8.5.1"></a>**1.** 在海中捕鱼的人，可以自由地在海岸搭建一间小屋，以便在那里休息避身。

### <a id="1.8.6"></a>1.8.6　马尔西安《法学阶梯》第三卷

<a id="1.8.6.pr."></a>**序言。** 以至于在海岸建造房屋的人，也会成为该土地的所有人；但仅限于房屋存续期间。否则，房屋坍塌后，该处即仿佛依据复归权恢复原状；若他人在同一地点建造房屋，该处便归后建造者所有。

<a id="1.8.6.1"></a>**1.** 有些物属于共同体而非个人，例如城市中的剧场、竞技场以及其他共同设施。因此，城市的共同奴隶不被视为任何个人按份所有，而属于共同体。神皇二兄弟曾以敕答指出，城市奴隶既可以针对某位市民，也可以为某位市民而受拷问。因此，城市的自由释奴若传唤本城某位市民到庭，无须请求告示所规定的许可。

<a id="1.8.6.2"></a>**2.** 祭祀圣物、宗教性之物和受特别保护之物，均不属于任何人的财产。

<a id="1.8.6.3"></a>**3.** 祭祀圣物，是指经公共方式奉献者，而非私人奉献者。因此，如果某人私下将某物奉献为圣物，即使他宣称“已将其奉献为圣物”，该物仍非圣物，而是凡俗之物。不过，祭祀圣殿一经建成，即使建筑后来毁坏，该处仍为圣地。

<a id="1.8.6.4"></a>**4.** 每个人可以依自己的意愿，将自己的土地变为宗教性场所，方法是把死者安葬于自己的土地上。即使共同墓地的其他人不同意，也可以将死者安葬其中。经土地所有人同意，也可以安葬于他人土地；即使土地所有人在安葬之后才追认，安葬之处仍成为宗教性场所。

<a id="1.8.6.5"></a>**5.** 较为通行的见解也认为，空墓属于宗教性场所；维吉尔（Vergilius）可以证明这一点。

### <a id="1.8.8"></a>1.8.8　马尔西安《规则》第四卷

<a id="1.8.8.pr."></a>**序言。** 所谓受特别保护之物，是指受到防护和保障、免受人类侵害之物。

<a id="1.8.8.1"></a>**1.** “受特别保护”（*sanctum*）一词据说源自“护草”（*sagmina*）。护草是一种草本植物，罗马人民的使节通常携带，以免遭人侵害；希腊人的使节也携带称为“传令杖”（*cerycia*）的物品。

<a id="1.8.8.2"></a>**2.** 卡西乌斯记载，萨宾努斯正确地认为，市镇城墙也属于受特别保护之物，因此应禁止任何人在城墙上或城墙中置入物件。

### <a id="1.8.9"></a>1.8.9　乌尔比安《告示评注》第六十八卷

<a id="1.8.9.pr."></a>**序言。** 祭祀圣地，是指经公共方式奉献的场所，无论位于城市还是乡野。

<a id="1.8.9.1"></a>**1.** 公共场所只有在元首亲自奉献，或元首授权他人奉献时，才能成为祭祀圣地。

<a id="1.8.9.2"></a>**2.** 应当注意，祭祀圣地与圣物存放处（*sacrarium*）并非一物。祭祀圣地是经奉献的场所；圣物存放处则是存放祭祀圣物的地点，也可以位于私人建筑内。人们若希望使某处摆脱宗教属性，通常会将祭祀圣物迁出该处。

<a id="1.8.9.3"></a>**3.** 严格而言，受特别保护之物既非祭祀圣物，也非法俗之物，而是经某种法律制裁予以确认之物。例如，法律属于受特别保护之物，因为它们由某种制裁加以保障。凡由某种制裁予以保障者，即属受特别保护之物，即使并未奉献给神明亦然。有时，制裁条款还规定，在该处实施某种行为者应处以死刑。

<a id="1.8.9.4"></a>**4.** 未经元首或总督授权，不得修缮市镇城墙，也不得在城墙上连接或增建任何物件。

<a id="1.8.9.5"></a>**5.** 祭祀圣物不得折价估值。

### <a id="1.8.10"></a>1.8.10　庞波尼乌斯《普劳提乌斯评注》第六卷

阿里斯托（Aristo）说，正如建于海中的物会成为私物，被海水占据的物也会成为公物。

### <a id="1.8.11"></a>1.8.11　庞波尼乌斯《杂读集》第二卷

任何人若毁坏城墙，应处以死刑；使用梯子攀越城墙或以任何其他方式越墙者，亦同。罗马公民不得从城门以外的地方出城，因为越墙是敌对且可憎的行为。据传，罗慕路斯的兄弟雷穆斯正因企图越过城墙而被杀。
