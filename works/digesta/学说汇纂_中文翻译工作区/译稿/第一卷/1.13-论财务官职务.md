# 第一卷

## <a id="1.13"></a>1.13　论财务官的职务

### <a id="1.13.1"></a>1.13.1　乌尔比安《论财务官职务》单卷

<a id="1.13.1.pr."></a>**序言。** 设立财务官一职的起源极为古老，几乎早于所有其他官职。尤尼乌斯·格拉坎努斯（Iunius Gracchanus）在其《论权力》第七卷中记载，罗慕路斯和努马·庞皮利乌斯各自也曾设有两名财务官；这两名财务官并非由君王亲自选任，而是由人民投票选出。不过，罗慕路斯和努马在位时是否已有财务官，尚不确定；图卢斯·霍斯提利乌斯（Tullus Hostilius）为王时已有财务官，则是确定的。事实上，古人中更为普遍的看法是，图卢斯·霍斯提利乌斯最先在国家制度中设立财务官。

<a id="1.13.1.1"></a>**1.** 尤尼乌斯、特雷巴提乌斯（Trebatius）和费奈斯特拉（Faenestella）都写道，财务官最初因其负责“查问”（*quaerere*）而得名。

<a id="1.13.1.2"></a>**2.** 有些财务官过去会依元老院决议抽签分派行省；该决议是在德基穆斯·德鲁苏斯（Decimus Drusus）和波尔基纳（Porcina）担任执政官时作出的。但并非所有财务官都抽签分派行省；由元首提名的人除外，因为他们只负责在元老院宣读元首的文书。

<a id="1.13.1.3"></a>**3.** 如今，贵族和平民均可一视同仁地获任财务官。这一官职确实是开始担任公职并在元老院发表意见的起点。

<a id="1.13.1.4"></a>**4.** 其中有些人，正如我们所说，被称为元首提名的候选人；他们负责在元老院宣读元首的书信。
