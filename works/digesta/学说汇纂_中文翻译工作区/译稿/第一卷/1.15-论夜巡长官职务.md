# 第一卷

## <a id="1.15"></a>1.15　论夜巡长官的职务

### <a id="1.15.1"></a>1.15.1　保罗《论夜巡长官职务》单卷

在古代，防止火灾的职责由三人委员会（*triumviri*）负责。他们因夜间值守而被称为夜巡官。有时市政官和平民保民官也会介入此事。当时有公家奴隶部署在城门和城墙周边，必要时可以召来；另有私人奴隶队伍，按约定报酬或出于善意协助灭火。后来，神皇奥古斯都决定由自己亲自处理此事。

### <a id="1.15.3"></a>1.15.3　保罗《论夜巡长官职务》单卷

<a id="1.15.3.pr."></a>**序言。** 皇帝认为，维护国家安全最适合由他本人负责，也没有其他人足以胜任此事。因此，他在合适地点设置了七个大队，每队负责守卫城市的两个区；并为各队任命军事护民官（*tribuni*），在所有人之上则任命一位显贵人士，称为夜巡长官。

<a id="1.15.3.1"></a>**1.** 夜巡长官审理纵火者、破门者、盗贼、劫掠者以及窝藏罪犯者的案件；但若案件涉及极其凶恶、声名狼藉之人，则应移交城市长官。火灾往往因住户过失而起：对于用火疏忽的人，夜巡长官可以施以杖刑；也可以通过严厉的训诫加以警告，随后免除杖刑。

<a id="1.15.3.2"></a>**2.** 破门盗窃通常发生在多层公寓或仓库中；人们将自己最贵重的财物存放在那里，窃贼会撬开储藏室、柜子或箱子。看守者通常会受到惩罚；神皇安敦宁曾以敕答告知埃鲁基乌斯·克拉鲁斯（Erucius Clarus）。敕答指出，即使仓库中的货物有一部分属于皇帝本人，仓库遭破门时，夜巡长官仍可对负责看守的奴隶进行拷问。〔*in illis* 所指见疑难表。〕

<a id="1.15.3.3"></a>**3.** 应当知道，夜巡长官必须彻夜值守，携带钩具和斧具巡行〔底本作 *coerrare*，词形疑误〕，并注意提醒所有住户，以免因疏忽而发生火灾。

<a id="1.15.3.4"></a>**4.** 他还应命令每一位住户在其楼上住房备水。

<a id="1.15.3.5"></a>**5.** 夜巡长官也受命审理浴场衣物保管人（*capsarii*）的案件；这些人收取报酬，为浴客看管衣物，若他们在保管衣物时实施欺诈，应由夜巡长官审理。

### <a id="1.15.4"></a>1.15.4　乌尔比安《论城市长官职务》单卷

神皇塞维鲁和安东尼努斯曾以敕答告知夜巡长官尤尼乌斯·鲁菲努斯（Iunius Rufinus）：“你可以命令楼宇管理人以及在自己住处用火疏忽的人接受杖打或鞭打；至于经证明故意纵火的人，你应将其移交给我们的朋友、城市长官法比乌斯·基洛。你还应搜寻逃亡奴隶，并将他们交还给主人。”
