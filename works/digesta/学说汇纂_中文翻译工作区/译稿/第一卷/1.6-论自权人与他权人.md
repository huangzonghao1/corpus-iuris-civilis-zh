# 第一卷

## <a id="1.6"></a>1.6　论自权人与他权人

### <a id="1.6.1"></a>1.6.1　盖尤斯《法学阶梯》第一卷

<a id="1.6.1.pr."></a>**序言。** 关于人的法，还可以作另一种区分：有些人属于自权人（*sui iuris*），有些人则受他人的权力支配（*alieni iuris*）。因此，我们先考察受他人权力支配者；了解了这些人，也就同时明白哪些人属于自权人。现在考察处于他人权力之下的人。

<a id="1.6.1.1"></a>**1.** 奴隶处于主人的权力之下。（这种权力属于万民法；因为我们可以看到，几乎所有民族都承认主人对奴隶享有生杀之权。）奴隶所取得的一切，均由主人取得。

<a id="1.6.1.2"></a>**2.** 但在现今，处于罗马帝国统治之下的人，不得对自己的奴隶施以过度虐待，亦不得在法律认可的事由之外任意施暴。依据神皇安东尼努斯（Antoninus）的敕令，无正当理由杀死自己奴隶的人，应受与杀死他人奴隶者同等的惩罚。同一皇帝的敕令也制止了主人的过度严酷。

### <a id="1.6.2"></a>1.6.2　乌尔比安《总督职务论》第八卷

如果主人虐待奴隶，或强迫奴隶遭受猥亵及可耻的侵犯，总督应当采取何种措施，可由神皇安敦宁·庇护（Antoninus Pius）致贝提卡行省总督埃利乌斯·马尔基安努斯（Aelius Marcianus）的敕答得知。敕答原文如下：

“主人的权力应当完整保留，不应剥夺任何人的权利；但对于那些有正当理由提出请求的人，主人也有责任确保他们不会因残暴、饥饿或无法忍受的侵害而得不到救助。因此，请调查逃至皇帝雕像前避难的尤利乌斯·萨比努斯（Iulius Sabinus）家奴的申诉；如果查明他们所受待遇过于严酷，超出了公平限度，或遭受了可耻的侵害，就命令将他们出售，使其不再回到主人的权力之下。若有人规避我的敕令，他将知道，我会对已发生之事采取更为严厉的处置。”

神皇哈德良还曾将一位名叫翁布里基娅（Umbricia）的贵妇流放五年，因为她仅以极轻微的事由便极其残酷地对待女奴。

### <a id="1.6.3"></a>1.6.3　盖尤斯《法学阶梯》第一卷

我们的子女若由合法婚姻所生，也处于我们的权力之下；这是罗马公民所特有的法。

### <a id="1.6.4"></a>1.6.4　乌尔比安《法学阶梯》第一卷

罗马公民中，有些是家父（*patres familiarum*），有些是家子（*filii familiarum*）；有些是家母（*matres familiarum*），有些是家女（*filiae familiarum*）。家父是指处于自身权力之下的人，无论其已成年还是未成年；家母亦然。家子和家女则是受他人权力支配的人。由我与妻子所生的人处于我的权力之下；同样，由我儿子与其妻所生的人，即我的孙子、孙女，也处于我的权力之下；曾孙、曾孙女以及其后的其他直系后代亦然。

### <a id="1.6.5"></a>1.6.5　乌尔比安《萨宾评注》第三十六卷

祖父去世后，通过其儿子而生的孙辈，通常转入其父亲（即祖父之子）的家父权之下。曾孙辈及其后代亦同：他们或者处于其父亲的家父权之下（若父亲在世且仍属于家族），或者处于其上一代仍享有家父权的尊亲属之下。这一规则不仅适用于自然血亲，也适用于收养关系中的后代。

### <a id="1.6.6"></a>1.6.6　乌尔比安《萨宾评注》第九卷

我们将由男子与其妻所生者界定为儿子。不过，假设丈夫离家十年，回来时发现家中有一名一岁的孩子；我们赞同尤利安的意见：此人不是该丈夫的儿子。尤利安又说，若某人一直与妻子共同生活，却借口孩子不是自己的而拒绝承认，这种行为不可容忍。

但我认为，正如谢沃拉（Scaevola）所赞同的，如果能够证明丈夫因疾病或其他原因曾有一段时间未与妻子同房，或者家父的健康状况使其无法生育，那么即便某人在家中出生，且邻人对此知情，也不能认定此人为其子。

### <a id="1.6.7"></a>1.6.7　乌尔比安《萨宾评注》第二十五卷

如果父亲受到的刑罚是丧失公民身份，或成为受刑奴隶（*servus poenae*），那么毫无疑问，其孙子便递补于儿子之位。

### <a id="1.6.8"></a>1.6.8　乌尔比安《萨宾评注》第二十六卷

<a id="1.6.8.pr."></a>**序言。** 父亲精神失常时，子女仍处于父亲的权力之下。其他拥有家父权的父母亦同。家父权是经习惯确立的法律制度；除非发生法律规定的使子女脱离家父权的情形，否则一个人不会失去对子女的权力。因此，毫无疑问，子女仍处于该权力之下。父亲不仅对子女在精神失常前所生者保有权力；对那些在其精神失常前受孕、却在其精神失常期间出生的子女，也同样保有权力。

如果妻子在丈夫精神失常期间受孕，则应考察孩子出生后是否处于父亲的权力之下。精神失常者虽不能缔结婚姻，却能够维持既有婚姻；既然如此，孩子便处于其权力之下。同样，如果妻子精神失常，在此之前受孕的孩子出生后也处于父亲的权力之下；如果妻子在精神失常期间受孕，而丈夫并未精神失常，孩子当然也处于父亲的权力之下，因为婚姻关系仍然维持。即使夫妻双方均处于精神失常状态并在此期间受孕，所生子女仍处于父亲的权力之下，仿佛精神失常者尚存意愿的残余一般。既然一方精神失常时婚姻关系仍然维持，双方均精神失常时亦应如此。

<a id="1.6.8.1"></a>**1.** 精神失常的父亲仍保有家父权；因此，儿子所取得的利益也归其父亲取得。

### <a id="1.6.9"></a>1.6.9　庞波尼乌斯《昆图斯·穆基乌斯评注》第十六卷

家子在公共事务中视同家父，例如可以担任官职，也可以被指定为监护人。

### <a id="1.6.10"></a>1.6.10　乌尔比安《朱利亚与帕皮亚法评注》第四卷

如果裁判者判令某人应受抚育或供养，就应查明事实，判断此人是否为其子；不能仅因供养之诉而预断真实的亲子关系。

### <a id="1.6.11"></a>1.6.11　莫德斯蒂努斯《学说汇纂》第一卷

未经其本人同意，自然子女或已经解放出父权的子女，均不会重新被置于父亲的家父权之下。
