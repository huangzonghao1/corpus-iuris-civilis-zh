# 第一卷

## <a id="1.18"></a>1.18　论行省长官的职务

### <a id="1.18.1"></a>1.18.1　马凯尔《论行省长官职务》第一卷

“行省长官”（*praeses*）是一个一般称谓；因此，无论是行省总督、皇帝的副官，还是所有治理行省的人，即使是元老，都称为行省长官。“行省总督”（*proconsul*）则是特定称谓。

### <a id="1.18.2"></a>1.18.2　乌尔比安《评萨宾》第二十六卷

行省长官可以在自己面前办理收养，正如他可以使儿子脱离家父权，也可以释放奴隶。

### <a id="1.18.3"></a>1.18.3　保罗《评萨宾》第十三卷

行省长官仅对其行省内的居民享有统治权，而且只在他身处该行省时享有此权；一旦离开行省，他便成为私人。有时，即使是对行省之外的人，他也享有统治权，例如这些人以暴力实施某种行为时。因为元首训令也规定，行省长官应负责清除行省内的恶人，并不区分这些人来自何处。

### <a id="1.18.4"></a>1.18.4　乌尔比安《评告示》第三十九卷

行省长官在其行省内的统治权，除元首以外，高于所有其他人。

### <a id="1.18.5"></a>1.18.5　乌尔比安《论所有法庭》第一卷

行省长官不能自行指定自己为监护人，正如他不能自行指定自己为特别裁判者一样。

### <a id="1.18.6"></a>1.18.6　乌尔比安《意见集》第一卷

<a id="1.18.6.pr."></a>**序言。** 行省长官应禁止非法征收、以暴力实施的行为，以及因恐惧而被迫进行的买卖和作出的担保；即使未支付价金，也应予以禁止。行省长官还应采取措施，避免任何人遭受不公的获利或损失。

<a id="1.18.6.1"></a>**1.** 事实不会因处理时发生错误而失其真实性。因此，行省长官应依照诚信，遵循已经证明的事实所支持的正确处理方式。

<a id="1.18.6.2"></a>**2.** 不得让势力强大者侵害地位低微者，也不得让他们的辩护人以诬告性指控追诉无辜者；防止此类情形属于行省长官应尽的职责。

<a id="1.18.6.3"></a>**3.** 有些人假借协助军人的名义，实施非法差役以勒索民众。行省长官应制止此类行为，并惩处被查获者；还应禁止以税赋为名非法征收。

<a id="1.18.6.4"></a>**4.** 行省长官应留意：不得禁止合法经营，不得放任被禁止的经营，也不得对无辜者施加刑罚。

<a id="1.18.6.5"></a>**5.** 行省长官应保障生活贫困者不因官署人员或士兵到来为借口而遭侵扰，例如他们唯一的一盏灯或少量家具被搬去供他人使用。

<a id="1.18.6.6"></a>**6.** 行省长官应防止有人借军人之名，非法攫取与军人共同利益无关、而仅有利于个人的好处。

<a id="1.18.6.7"></a>**7.** 正如不应因病人的死亡结果而归责于医生，也应将医生因缺乏医术而犯下的过错归责于他。对于欺骗他人并使其陷入危险者的过失，不应以人的脆弱为由而不予追究。〔末句句法关系仍待核，见疑难表。〕

<a id="1.18.6.8"></a>**8.** 治理整个行省的人享有刑杀权（*ius gladii*），并获准将人判处矿场劳役。

<a id="1.18.6.9"></a>**9.** 如果行省长官发现，其所判处的罚金不能从受罚者现有财产中收足，就应减轻缴纳义务，并遏止征收人员非法的贪婪。行省长官因贫困而免除的罚金，不得再向受罚者征收。

### <a id="1.18.7"></a>1.18.7　乌尔比安《意见集》第三卷

行省长官应当检查建筑物；经审理后，可以强制其所有人修缮。如有人拒不修缮，长官应通过适当的救济消除建筑物的破败状态。

### <a id="1.18.8"></a>1.18.8　尤利安《学说汇纂》第一卷

我常听我们的皇帝说，“你可以向行省长官提出请求”这一敕答，并未强令行省总督、其副官或行省长官必须受理并审理案件；他们应当自行判断，是亲自审理，还是应当指定裁判者。

### <a id="1.18.9"></a>1.18.9　卡利斯特拉图《审判论》第一卷

一般而言，每当元首通过敕答将事务交由行省长官处理，例如说“你可以向行省长官提出请求”，或附加说“由他判断哪些事项属于其职掌”时，并未强令行省总督或其副官必须受理并审理案件；即使没有附加“由他判断哪些事项属于其职掌”这句话，结论也相同。行省长官应自行判断，是亲自审理，还是指定裁判者。
