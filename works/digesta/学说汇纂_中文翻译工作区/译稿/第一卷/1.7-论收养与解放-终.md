# 第一卷

## 1.7　论收养、解放及其他解除家父权的方式（续）

### <a id="1.7.30"></a>1.7.30　保罗《规则》第二卷

没有妻子的人也可以收养子女。

### <a id="1.7.31"></a>1.7.31　马尔西安《规则》第五卷

处于父亲权力之下的儿子，无论是自然子女还是养子，均不得以任何方式迫使父亲使其脱离该权力。

### <a id="1.7.32"></a>1.7.32　帕比尼安《疑问集》第三十一卷

<a id="1.7.32.pr."></a>**序言。** 有时，对于未达青春期年龄的被收养人，在其达到青春期年龄后若请求脱离家父权，应当听取其意见；法官应在查明具体情况后作出裁定。

<a id="1.7.32.1"></a>**1.** 皇帝提图斯·安东尼努斯（Titus Antoninus）以敕答指出，应允许某人收养其继子。

### <a id="1.7.33"></a>1.7.33　马尔西安《规则》第五卷

如果某人达到青春期年龄后证明，继续处于养父权力之下对自己并无益处，那么由养父将其解放出父权、使其恢复原有法律地位，是公平的。

### <a id="1.7.34"></a>1.7.34　保罗《疑问集》第十一卷

有人提出这样的问题：如果某人将儿子交付你收养，并约定例如三年后你再将同一儿子交还给我，是否可以提起诉讼？拉贝奥（Labeo）认为不存在可提起的诉讼；因为依我们的习俗，不允许有一个仅在一定期限内属于自己的儿子。

### <a id="1.7.35"></a>1.7.35　保罗《答复集》第一卷

收养不会降低人的身份尊荣，反而会使其提高。因此，元老即使被平民收养，仍保有元老身份；元老的儿子也同样保有其身份。

### <a id="1.7.36"></a>1.7.36　保罗《答复集》第十八卷

<a id="1.7.36.pr."></a>**序言。** 父亲可以在任何地方解放儿子出父权，使其脱离家父权；这一点没有疑问。

<a id="1.7.36.1"></a>**1.** 依通说，即使是在总督未获分派管辖权的行省，也可以在总督面前释放奴隶或将某人交付收养。

### <a id="1.7.37"></a>1.7.37　保罗《判例集》第二卷

<a id="1.7.37.pr."></a>**序言。** 即使没有儿子，某人也可以收养他人为孙子。

<a id="1.7.37.1"></a>**1.** 某人曾经收养的人，若后来被解放出父权或又被交付他人收养，该人不得再次收养。

### <a id="1.7.38"></a>1.7.38　马尔凯卢斯《学说汇纂》第二十六卷

由皇帝确认后，未依法完成的收养也可以发生效力。

### <a id="1.7.39"></a>1.7.39　乌尔比安《总督职务论》第三卷

神皇马尔库斯曾以敕答告知欧提基亚努斯（Eutychianus）：“你所请求的事项是否应获准，应由法官在听取反对者——也就是会因确认该收养而受到损害之人——的意见后作出判断。”

### <a id="1.7.40"></a>1.7.40　莫德斯蒂努斯《区别论》第一卷

<a id="1.7.40.pr."></a>**序言。** 家父被自权人收养时，处于其权力之下的子女成为收养者的孙辈，并与其父亲一同转入收养者的家父权之下。普通收养则不同：由该人所生的孙辈仍处于其自然祖父的权力之下。

<a id="1.7.40.1"></a>**1.** 无论是普通收养还是自权人收养，收养者都必须比被收养为儿子的人年长，并已达到完全成熟的年龄；也就是说，收养者至少应年长十八岁。

<a id="1.7.40.2"></a>**2.** 无生育能力者（*spado*）也可以通过自权人收养为自己取得自家继承人；其身体状况并不构成障碍。

### <a id="1.7.41"></a>1.7.41　莫德斯蒂努斯《规则》第二卷

如果父亲解放其儿子出父权，而该儿子有一名处于父亲权力之下的孙子，之后父亲又收养该儿子，那么儿子去世后，该孙子不会回到其父亲的权力之下。如果祖父在将其儿子交付收养时，将该孙子留在自己权力之下，之后又重新收养该儿子，该孙子也不会回到其父亲的权力之下。

### <a id="1.7.42"></a>1.7.42　莫德斯蒂努斯《学说汇纂》第一卷

我们甚至可以将婴儿交付收养。

### <a id="1.7.43"></a>1.7.43　庞波尼乌斯《昆图斯·穆基乌斯评注》第二十卷

收养不只可以收养儿子，也可以收养仿佛是孙辈的人，使某人被视为我们的孙辈，仿佛他由我们的儿子或某个不确定之人所生。

### <a id="1.7.44"></a>1.7.44　普罗库鲁斯（Proculus）《书信集》第八卷

如果某人已有儿子所生的孙子，又收养一人为孙子，我认为祖父去世后，两个孙子之间不会因此产生亲属关系。但如果收养时明确使被收养者依法也成为自己的孙子，例如使其视同由我的儿子卢基乌斯（Lucius）与其家母所生，则我认为应作相反结论。

### <a id="1.7.45"></a>1.7.45　保罗《朱利亚与帕皮亚法评注》第三卷

被交付收养者所负的义务转由养父承担。

### <a id="1.7.46"></a>1.7.46　乌尔比安《朱利亚与帕皮亚法评注》第四卷

若某人的儿子在其本人尚处于奴隶身份时出生，元首可以通过恩典使该子纳入其家父权之下；但毫无疑问，该子仍保持自由释奴身份。
