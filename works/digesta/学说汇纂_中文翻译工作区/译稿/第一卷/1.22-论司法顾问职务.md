# 第一卷

## <a id="1.22"></a>1.22　论司法顾问的职务

### <a id="1.22.1"></a>1.22.1　保罗《论司法顾问职务》单卷

法律学子藉以履行其职责的司法顾问职务，大体包括以下事项：参与审理、处理申请、书面请求、告示、裁断和书信。

### <a id="1.22.2"></a>1.22.2　马尔基安《公诉案件》第一卷

自由释奴可以担任司法顾问。虽然法律并未禁止名誉受损者担任司法顾问，但我认为，正如某项元首敕令所确立的，他们不能履行司法顾问的职务。

### <a id="1.22.3"></a>1.22.3　马凯尔《论行省长官职务》第一卷

如果某行省后来被划分为两个行省、分别由两位长官治理，例如日耳曼尼亚和默西亚，那么出生于其中一个行省的人可以在另一个行省担任司法顾问；这不被视为在自己的行省担任此职。

### <a id="1.22.4"></a>1.22.4　帕皮尼安《答复集》第四卷

皇帝副官去世后，若其随员没有在同一时期转而陪同其他官员，应向其随员支付余下任期的薪俸；该薪俸数额由副官预先确定。对于任期未满便有继任者接替的情形，适用不同规则。

### <a id="1.22.5"></a>1.22.5　保罗《箴言》第一卷

司法顾问在履行顾问职务期间，不得在自己的审判厅处理其他事务；但法律并不禁止他在他人的审判厅处理事务。

### <a id="1.22.6"></a>1.22.6　帕皮尼安《答复集》第一卷

同一城市的居民可以参加城市监理官（*curator rei publicae*）的顾问会议，因为他并不领取公帑薪俸。
