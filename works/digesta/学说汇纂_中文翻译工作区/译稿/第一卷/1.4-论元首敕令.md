# 第一卷

## <a id="1.4"></a>1.4　论元首敕令

### <a id="1.4.1"></a>1.4.1　乌尔比安（Ulpianus）《法学阶梯》第一卷

<a id="1.4.1.pr."></a>**序言。** 元首所决定者具有法律效力；因为依据授予其统治权的王法，人民已将自己的全部统治权与权力授予元首，并集中于其一身。

<a id="1.4.1.1"></a>**1.** 因此，皇帝以书信或批示作出的任何规定、经审理案件后作出的任何裁断、当场口头作出的任何决定，或以告示发布的任何命令，显然都具有法律效力。这些便是通常所称的“敕令”（*constitutiones*）。

<a id="1.4.1.2"></a>**2.** 当然，其中有些敕令仅针对特定个人，不得援为一般先例：元首因某人的功绩而给予的恩惠、对某人施加的刑罚，或对某人作出的无先例救济，均不超出该特定个人的范围。

### <a id="1.4.2"></a>1.4.2　乌尔比安《遗嘱信托论》第四卷

确立新规则时，必须有明显的利益，方可背离长期以来被认为公平的既有法律。

### <a id="1.4.3"></a>1.4.3　雅沃勒努斯（Iavolenus）《书信集》第十三卷

皇帝的恩惠显然源自其神圣的宽宥；对此，我们应作尽可能宽泛的解释。

### <a id="1.4.4"></a>1.4.4　莫德斯蒂努斯《免责事由论》第二卷

后出的敕令效力强于此前的敕令。〔底本以拉丁字母转写希腊文；此处据其含义翻译。〕
