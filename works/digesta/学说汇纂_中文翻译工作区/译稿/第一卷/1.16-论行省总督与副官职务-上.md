# 第一卷

## <a id="1.16"></a>1.16　论行省总督与副官的职务

### <a id="1.16.1"></a>1.16.1　乌尔比安《论论辩》第一卷

行省总督（*proconsul*）一经离开罗马城，便随处具有总督的仪仗标志；但他只在划归给他的那个行省内行使权力。

### <a id="1.16.2"></a>1.16.2　马尔基安《法学阶梯》第一卷

<a id="1.16.2.pr."></a>**序言。** 所有行省总督自离开罗马城之时起即有管辖权，但这不是争讼管辖，而是自愿管辖。例如，子女可以在他们面前脱离家父权，奴隶可以在他们面前获释，也可以办理收养。

<a id="1.16.2.1"></a>**1.** 但在行省总督的副官（*legatus proconsulis*）面前，无人可以办理释奴，因为副官不具有这种管辖权。

### <a id="1.16.3"></a>1.16.3　乌尔比安《评萨宾》第二十六卷

副官也不能办理收养：因为在他面前根本没有法定诉讼程序可供进行。

### <a id="1.16.4"></a>1.16.4　乌尔比安《论行省总督职务》第一卷

<a id="1.16.4.pr."></a>**序言。** 行省总督在提供住宿时应当谨慎，不得因此加重行省的负担；我们的皇帝与其父曾就此事致敕答给奥菲狄乌斯·塞维里安努斯。

<a id="1.16.4.1"></a>**1.** 行省总督不得拥有自己的侍从（*stratores*）；在行省中，由士兵代行他们的职务。

<a id="1.16.4.2"></a>**2.** 行省总督最好独自赴任；不过，也可以携妻同行，但他须知：科塔与梅萨拉任执政官之年，元老院曾决议，凡赴任者的妻子如有违法行为，均应向赴任者本人追究责任并加以惩处。

<a id="1.16.4.3"></a>**3.** 行省总督进入划归给他的行省之前，应先发布关于其到任的告示。告示中应说明他与行省居民是否有熟识或亲属关系；尤其应表示免除居民在公、私场合前来迎接他的义务。因为由每个人在自己的家乡接待他，才是合宜的做法。

<a id="1.16.4.4"></a>**4.** 如果行省总督将告示送交前任总督，并告知自己哪一天将进入行省疆界，那就既妥当又合乎程序；此类日期若常常不确定、出人意料，便会扰乱行省居民并妨碍公务。

<a id="1.16.4.5"></a>**5.** 行省总督入境时还应注意，应循惯常路线进入行省，并遵循希腊人所谓的 *epidymiai*（到访礼仪）或 *kataploun*（航抵礼仪），留意自己最先抵达或停靠哪座城市。行省居民会十分看重其惯例得到遵守，也会重视这类优先待遇。有些行省还规定，总督须从海路进入该行省，例如亚细亚行省。其要求甚至如此严格，以至我们的皇帝安敦宁·奥古斯都应亚细亚人的请求，以敕答规定：总督必须乘船抵达亚细亚，并须在其都会中首先到达以弗所（*kai twn mytropolewn Efeson primam attingere*）。

<a id="1.16.4.6"></a>**6.** 行省总督进入行省后，应将管辖权委托给自己的副官；在进入行省之前不得这样做。因为在他本人尚未取得管辖权时便把管辖权委托给他人，显然极不合理；总督只有抵达该行省后才享有管辖权，不能将自己并不拥有的权力委托出去。不过，如果他先行委托，进入行省后仍维持这一意思，那么应认为副官自总督进入行省之时起，而非自委托之时起，取得管辖权。

### <a id="1.16.5"></a>1.16.5　帕皮尼安《法律问题》第一卷

有时，即使行省总督尚未抵达行省，也可以委托管辖权。比如，他若在途中不得不耽搁，而副官却能很快抵达行省，情况又该如何呢？

### <a id="1.16.6"></a>1.16.6　乌尔比安《论行省总督职务》第一卷

<a id="1.16.6.pr."></a>**序言。** 总督也常将羁押审查委托给副官，即令副官先行审查被羁押者，再将他们送回总督处，以便总督亲自释放无辜者。但这类委托属于非常规授权：任何人都不能把授予自己的刑罚权或其他强制权转授他人；因此，他也不能将释放被告人的权力转授他人，因为这些人不能在该副官面前受到控告。

<a id="1.16.6.1"></a>**1.** 行省总督是否委托管辖权，属于其裁量范围；同样，他虽可撤销已经委托的管辖权，却不应未经请示元首便这样做。

<a id="1.16.6.2"></a>**2.** 副官不应请示元首，而应请示自己的总督；总督应答复副官提出的咨询。

<a id="1.16.6.3"></a>**3.** 总督不应一概拒绝接受礼物（*xenia*），但应为其设定限度，既不可拘泥到完全不受，也不可贪婪地超出礼物的限度。神皇塞维鲁与皇帝安敦宁在一封书信中对此作了极为妥善的节制。书信说：“关于礼物，听听我们的意见。古谚云：*oute panta oute pantote oute para pantwn*（不是一概接受，不是时时接受，也不是从所有人那里接受）。因为无人馈赠而一概不受，实在不近人情；但不加区别地收受，则极其卑劣，而且十分贪婪。”敕令中规定，总督本人或在其他职务任职者不得接受或购买礼物，日常饮食所需者除外；这项规定不适用于小额的待客礼品，而适用于超出日常食物所需的物品。但也不得把待客礼品提升到正式馈赠的规格。
