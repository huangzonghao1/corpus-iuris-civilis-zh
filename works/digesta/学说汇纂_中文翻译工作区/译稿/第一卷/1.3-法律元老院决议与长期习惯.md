# 第一卷

## <a id="1.3"></a>1.3　论法律、元老院决议与长期习惯

### <a id="1.3.1"></a>1.3.1　帕比尼安（Papinianus）《定义》第一卷

法律是普遍适用的规范，是贤明人士的议决，是对故意或因无知而实施之违法行为的惩戒，也是共和国的共同约定。

### <a id="1.3.2"></a>1.3.2　马尔西安（Marcianus）《法学阶梯》第一卷

演说家德摩斯梯尼（Demosthenes）曾如此界定法律：“法律是所有人基于诸多理由、尤其应当遵守的规范；因为每一法律都是神的发现与恩赐，是明智之人的决定，是对故意和非故意过失的矫正，也是城邦的共同约定；依此约定，城邦中的所有人都应生活。”

斯多亚学派最卓越的哲学家克律西波斯（Chrysippus）在其《论法律》一书开篇也说：“法律是支配一切神事与人事的王。法律应当是善与恶的守护者、统治者和领导者；因此，它是正当与不正当的准则，也是针对天性上具有社会性的生物所应做之事的命令，以及对不应做之事的禁令。”〔底本以拉丁字母转写希腊文；此处据其含义翻译。〕

### <a id="1.3.3"></a>1.3.3　庞波尼乌斯（Pomponius）《萨宾评注》第二十五卷

正如泰奥弗拉斯托斯（Theophrastus）所说，法律应当针对最常发生之事制定，而非针对偶然发生之事制定。

### <a id="1.3.4"></a>1.3.4　塞尔苏斯（Celsus）《学说汇纂》第五卷

法律不得针对偶然只在某个情形下发生的事情制定。

### <a id="1.3.5"></a>1.3.5　塞尔苏斯《学说汇纂》第十七卷

法应当适用于频繁而容易发生的事情，而不是极少发生的事情。

### <a id="1.3.6"></a>1.3.6　保罗（Paulus）《普劳提乌斯评注》第十七卷

正如泰奥弗拉斯托斯所说，立法者往往忽略只发生一两次的事情。〔底本以拉丁字母转写希腊文；此处据其含义翻译。〕

### <a id="1.3.7"></a>1.3.7　莫德斯蒂努斯（Modestinus）《规则》第二卷

法律的效力体现为命令、禁止、许可和惩罚。

### <a id="1.3.8"></a>1.3.8　乌尔比安（Ulpianus）《萨宾评注》第三卷

法律不是针对个别人制定的，而是普遍制定的。

### <a id="1.3.9"></a>1.3.9　乌尔比安《告示评注》第十六卷

元老院能够创制法律，这一点并无疑义。

### <a id="1.3.10"></a>1.3.10　尤利安（Iulianus）《学说汇纂》第五十九卷

法律和元老院决议不可能写得面面俱到，以涵盖将来可能出现的所有情形；只要涵盖通常发生的情形，就已足够。

### <a id="1.3.11"></a>1.3.11　尤利安《学说汇纂》第九十卷

因此，对于最初制定的事项，应当通过解释，或者通过最优秀元首的敕令，作出更为确定的规定。

### <a id="1.3.12"></a>1.3.12　尤利安《学说汇纂》第十五卷

法律或元老院决议不可能逐一涵盖所有个别情形；但在某一案件中，如果其意旨明确，主持司法管辖者就应将该意旨适用于类似情形，并据此裁判。

### <a id="1.3.13"></a>1.3.13　乌尔比安《库鲁尔市政官告示评注》第一卷

正如佩狄乌斯（Pedius）所说，每当法律仅就一两事项作出规定时，对于其他旨在实现同一利益的事项，便有充分理由通过解释，或至少通过司法管辖予以补充。

### <a id="1.3.14"></a>1.3.14　保罗《告示评注》第五十四卷

凡违背法律理性而被采纳的规则，不得进一步推演适用。

### <a id="1.3.15"></a>1.3.15　尤利安《学说汇纂》第二十七卷

对于那些违反法律原理而制定的规定，我们不能遵循通常的法律规则。

### <a id="1.3.16"></a>1.3.16　保罗《特别法》单卷

特别法（*ius singulare*）是立法者基于某种利益，以其权威创设、且与通常法律理性相悖的法律。

### <a id="1.3.17"></a>1.3.17　塞尔苏斯《学说汇纂》第二十六卷

理解法律，并非掌握其字句，而是把握其力量与效力。

### <a id="1.3.18"></a>1.3.18　塞尔苏斯《学说汇纂》第二十九卷

法律应作较为宽厚的解释，以保存其意旨。

### <a id="1.3.19"></a>1.3.19　塞尔苏斯《学说汇纂》第三十三卷

法律用语含义不明时，应当采纳没有瑕疵的那种解释，尤其是在据此也能够推知法律意旨的情况下。

### <a id="1.3.20"></a>1.3.20　尤利安《学说汇纂》第五十五卷

祖先所制定的一切规定，并非都能说明其理由。

### <a id="1.3.21"></a>1.3.21　涅拉提乌斯（Neratius）《札记》第六卷

因此，不应探究这些规定何以如此制定；否则，许多已经确定的规则都会被推翻。

### <a id="1.3.22"></a>1.3.22　乌尔比安《告示评注》第三十五卷

法律若对过去的事项予以宽免，便是禁止将来再发生此类事项。

### <a id="1.3.23"></a>1.3.23　保罗《普劳提乌斯评注》第四卷

对于始终具有确定解释的事项，绝不应轻易改变。

### <a id="1.3.24"></a>1.3.24　塞尔苏斯《学说汇纂》第九卷

不通览整部法律，只提出其中某一片段便据此裁判或作出法律意见，是不合规范的。〔底本此处作 *In civile est*，疑为 *Incivile est* 的连写或转录错误。〕

### <a id="1.3.25"></a>1.3.25　莫德斯蒂努斯《答复》第八卷

无论法律理性还是衡平的宽厚，都不允许我们以更严苛的解释，把那些为人类利益而有益地创设的规则推向严酷结果，反而损害人们自身的利益。

### <a id="1.3.26"></a>1.3.26　保罗《疑问集》第四卷

将先前的法律适用于后来发生的情形，并非新事。

### <a id="1.3.27"></a>1.3.27　特尔图良（Tertullianus）《疑问集》第一卷

既然将较早的法律适用于较后的情形已成惯例，就应始终认为法律本身包含这样的意思：其效力也及于后来出现的、与原先情形相类似的人和事。

### <a id="1.3.28"></a>1.3.28　保罗《朱利亚与帕皮亚法评注》第五卷

较后的法律也适用于较早的法律，除非二者相互抵触；这一点可以由许多论据证明。

### <a id="1.3.29"></a>1.3.29　保罗《辛基亚法评注》单卷

实施法律所禁止之事的人，是违反法律；而以不违背法律字句的方式规避其意旨的人，则是诈欺法律。

### <a id="1.3.30"></a>1.3.30　乌尔比安《告示评注》第四卷

当某事虽非法律所禁止，却是法律不愿发生而仍被实施时，便构成对法律的诈欺。字面与意旨之别，正如诈欺法律与直接违反法律之别。〔底本以拉丁字母转写希腊语“字面与意旨”。〕

### <a id="1.3.31"></a>1.3.31　乌尔比安《朱利亚与帕皮亚法评注》第十三卷

元首不受法律拘束。奥古斯塔虽不享有不受法律拘束的地位，元首仍会将自己享有的同等特权授予她。

### <a id="1.3.32"></a>1.3.32　尤利安《学说汇纂》第八十四卷

<a id="1.3.32.pr."></a>**序言。** 对于没有适用成文法的事项，应遵守由习惯引入的规则；如果该规则缺失，就适用与之最为接近、最为相应的规则；如果连这一规则也无法确定，就应遵守罗马城所适用的法律。

<a id="1.3.32.1"></a>**1.** 长期沿袭的习惯被当作法律遵守，确有正当理由；这就是所谓由习惯确立的法。法律之所以约束我们，只是因为它们经人民表决而获接受；因此，人民未以书面形式制定、却以行为认可的规则，也理应约束所有人。人民以投票表达意愿，与以实际行为表达意愿，有何不同？所以，人们也完全正确地接受了这一点：法律不仅能由立法者投票废除，也能因长期不再适用、并由全体人民默示同意而废止。

### <a id="1.3.33"></a>1.3.33　乌尔比安《总督职务论》第一卷

对于并非源自成文法的事项，长期习惯通常被作为“法”与“法律规范”遵行（*pro iure et lege*）。

### <a id="1.3.34"></a>1.3.34　乌尔比安《总督职务论》第四卷

有人主张应依某城邦或某行省的习惯行事时，我认为首先应查明：是否曾有针对该习惯的异议，而法院仍以裁判确认了该习惯。

### <a id="1.3.35"></a>1.3.35　赫莫革尼安（Hermogenianus）《概要》第一卷

长期习惯所认可、并经多年遵行的规则，犹如公民之间的默示约定，应当像成文法一样作为法律遵守。

### <a id="1.3.36"></a>1.3.36　保罗《萨宾评注》第七卷

事实上，这种法具有很高的权威，因为它已获得如此充分的认可，以至无须再以书面形式加以规定。

### <a id="1.3.37"></a>1.3.37　保罗《疑问集》第一卷

如果争议涉及法律解释，首先应考察共同体过去在类似案件中适用何种法律；因为习惯是解释法律的最佳依据。

### <a id="1.3.38"></a>1.3.38　卡利斯特拉图斯（Callistratus）《疑问集》第一卷

我们的皇帝塞维鲁曾以敕答指出：对于法律引起的歧义，习惯，或长期以来持续以相同方式作出的裁判所形成的权威，应当具有法律效力。

### <a id="1.3.39"></a>1.3.39　塞尔苏斯《学说汇纂》第二十三卷

某种做法最初并非基于理性而引入，而是源于错误，后来又因习惯而沿袭；这种做法不适用于其他类似情形。

### <a id="1.3.40"></a>1.3.40　莫德斯蒂努斯《规则》第二卷

因此，一切法律或者由合意创设，或者因必要而确立，或者由习惯巩固。

### <a id="1.3.41"></a>1.3.41　乌尔比安《法学阶梯》第二卷

全部法律都涉及取得、保有或减少：法律所处理的，要么是如何使某物归属于某人，要么是某人如何保有其物或权利，要么是如何处分或接纳该物或权利。〔底本作 *admittat*，字面为“接纳”；若作其他校本的 *amittat*，则为“丧失”。底本文字与上下文不尽协调，见疑难表。〕
