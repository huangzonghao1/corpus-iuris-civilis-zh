# D.27.10 论为精神失常者及未成年人以外之人指定保佐人（*De curatoribus furioso et aliis extra minores dandis*）

<!-- source-p 001 -->
<a id="10"></a><a id="27.10"></a>**27.10.0. 论为精神失常者及未成年人以外之人指定保佐人。**

<!-- source-p 002 -->
<a id="27.10.1"></a>**27.10.1**

<!-- source-p 003 -->
**乌尔比安：《评萨宾》第一卷。**

<!-- source-p 004 -->
<a id="27.10.1.pr."></a>**序言。**《十二表法》规定，应禁止挥霍者管理自己的财产；这一制度自古以来即依习惯确立。如今，如果裁判官或行省长官发现某人花销没有节制，挥霍财物、任意耗散，以致既不知节度，也无止境，就会仿照精神失常者的制度为其指定保佐人。挥霍者和精神失常者均持续处于保佐之下，直至精神失常者恢复神志，或挥霍者恢复正常的生活方式；一旦如此，二人依法当然脱离保佐人的权力。

<!-- source-p 005 -->
<a id="27.10.1.1"></a>**1.**过去不允许将被禁止管理财产者的保佐职责交给其子；但现存一份神圣庇护皇帝的敕答规定：如果儿子品行端正，可以优先将其指定为精神失常父亲的保佐人。

<!-- source-p 006 -->
<a id="27.10.2"></a>**27.10.2**

<!-- source-p 007 -->
**保罗：《论行省总督职务》第一卷。**

<!-- source-p 008 -->
行省总督也会为其他无法处理自己事务的人指定保佐人，或命令为他们指定保佐人；总督也会毫不犹豫地指定儿子担任父亲的保佐人。

<!-- source-p 009 -->
<a id="27.10.3"></a>**27.10.3**

<!-- source-p 010 -->
**乌尔比安：《评萨宾》第三十一卷。**

<!-- source-p 011 -->
在遗嘱指定的继承人决定是否接受继承期间，裁判官会为遗产指定一名保佐人。

<!-- source-p 012 -->
<a id="27.10.4"></a>**27.10.4**

<!-- source-p 013 -->
**乌尔比安：《评萨宾》第三十八卷。**

<!-- source-p 014 -->
精神失常母亲的保佐职责应由儿子承担。因为子女应当以同等之孝敬奉父母，即使父母与子女之间的权力地位并不相同。

<!-- source-p 015 -->
<a id="27.10.5"></a>**27.10.5**

<!-- source-p 016 -->
**盖尤斯：《行省告示评注》第九卷。**

<!-- source-p 017 -->
元老院决议规定：如果某位显贵，例如元老或其妻子，陷入其财产应当被变卖的情形，就应为其指定保佐人。为使债权人能够尽可能体面地从其财产中受偿，裁判官或行省中的行省长官应指定保佐人，负责变卖其财产。

<!-- source-p 018 -->
<a id="27.10.6"></a>**27.10.6**

<!-- source-p 019 -->
**乌尔比安：《论各级审判庭》第一卷。**

<!-- source-p 020 -->
裁判官应当谨慎，不得未经查明案情便轻率地为任何人指定权能最为广泛的保佐人，因为许多人会假装精神失常或痴呆，以便在取得保佐人后逃避公民义务。

<!-- source-p 021 -->
<a id="27.10.7"></a>**27.10.7**

<!-- source-p 022 -->
**尤利安：《学说汇纂》第二十一卷。**

<!-- source-p 023 -->
<a id="27.10.7.pr."></a>**序言。**保佐人应通过自己的建议和协助，不仅维护精神失常者的财产，也应保护其人身及安全。

<!-- source-p 024 -->
<a id="27.10.7.1"></a>**1.**一名精神失常者的保佐人经裁定指定，且被要求提供担保，但他未提供担保，却仍以合法方式变卖了其财产中的某些物品。若精神失常者的继承人主张取回保佐人已变卖的物品，而对方提出抗辩：“如果这些物品并非由保佐人出售”；则应准许其提出再抗辩：“或者，如果保佐人是在依裁定提供担保后出售这些物品”。如果保佐人收取价款后免除了精神失常者的债务人，诈欺三重抗辩将使善意占有人免受追索。

<!-- source-p 025 -->
<a id="27.10.7.2"></a>**2.**精神失常者的保佐人未提供担保且管理不善，行省总督遂将其撤换，并另行指定一名保佐人。后任保佐人本人也未提供担保，却对被撤换者提起事务管理之诉。之后，精神失常者的继承人又对后任保佐人提起事务管理之诉，而后任保佐人援引其与被撤换者之间的既判事项抗辩。此时，应准许继承人提出再抗辩：“或者，如果提起该诉之人已提供担保。”但该再抗辩是否对保佐人有利，应由法官酌情判断；因为如果后任保佐人将其通过判决取得的钱款用于精神失常者的事务，诈欺三重抗辩就会阻却继承人提出的再抗辩。

<!-- source-p 026 -->
<a id="27.10.7.3"></a>**3.**有人询问：向精神失常者的数名保佐人中的一人清偿，是否有效；以及其中一人能否变卖精神失常者的财物。我答复说：向一人清偿有效。若有人从其中一名保佐人处合法购买精神失常者的土地，他也会因取得时效而取得所有权。因为清偿、买卖和交付主要属于事实行为，而非法律行为；因此，只需有一名保佐人参与即可，因为通常推定另一人同意。相反，如果另一名保佐人在场并禁止清偿、出售或交付，那么债务人不能因此免责，买受人也不能取得该土地的所有权。

<!-- source-p 027 -->
<a id="27.10.8"></a>**27.10.8**

<!-- source-p 028 -->
**乌尔比安：《论行省总督职务》第六卷。**

<!-- source-p 029 -->
应当为遗腹子名下的财产指定保佐人；行省总督应命其按照善良人的判断提供财产无损担保。但如果保佐人是在调查后指定的，则无须提供该项担保。

<!-- source-p 030 -->
<a id="27.10.9"></a>**27.10.9**

<!-- source-p 031 -->
**涅拉提乌斯：《书简集》第一卷。**

<!-- source-p 032 -->
元老院允许为某人的财产指定保佐人，以便变卖该人的财产；但并未允许其债权人自行变卖财产，即使在获得该项优待后，债权人宁愿由自己变卖财产也是如此。因为，正如在事务尚未处理时，他们可以选择是否自行变卖一样，一旦选择了其中一种方式，就应放弃另一种。即使已经指定了一名负责变卖财产的保佐人，而该保佐人在事务尚未办结时死亡，也更应遵守这一规则。此时应重新指定另一名保佐人，不应使前任保佐人的继承人承担该项负担；因为后任继承人可能因性别、年龄导致的体力不足，或其身份尊卑与前任保佐人不同，而不适合处理该事务；前任保佐人也可能有多名继承人，未必适宜由他们全体共同管理此事，也没有理由只让其中某一人承担该项负担。

<!-- source-p 033 -->
<a id="27.10.10"></a>**27.10.10**

<!-- source-p 034 -->
**乌尔比安：《告示评注》第十六卷。**

<!-- source-p 035 -->
<a id="27.10.10.pr."></a>**序言。**尤利安写道：经裁判官裁定被禁止管理财产的人，不得将任何财产转让给他人，因为他们无权处分自己的财产；他们已被禁止减少其财产。

<!-- source-p 036 -->
<a id="27.10.10.1"></a>**1.**精神失常者的保佐人可以将自己的财物作为精神失常者的财物交付，从而转移所有权；但如果他把精神失常者的财物当作自己的财物交付，则不应认为所有权已经转移，因为他并非以管理精神失常者事务的身份交付该物。

<!-- source-p 037 -->
<a id="27.10.11"></a>**27.10.11**

<!-- source-p 038 -->
**保罗：《评普劳提乌斯》第七卷。**

<!-- source-p 039 -->
如果精神失常者的保佐人因其本人利益需要而以该人的财物设质，则该质押有效。

<!-- source-p 040 -->
<a id="27.10.12"></a>**27.10.12**

<!-- source-p 041 -->
**马尔凯卢斯：《学说汇纂》第一卷。**

<!-- source-p 042 -->
可以确定，宗亲或其他保佐人不得将精神失常者的财物奉献为祭祀圣物。宗亲并非在任何情况下都有权处分该人的财物；只有在事务管理所需的范围内，方可处分。

<!-- source-p 043 -->
<a id="27.10.13"></a>**27.10.13**

<!-- source-p 044 -->
**盖尤斯：《行省告示评注》第三卷。**

<!-- source-p 045 -->
依据《十二表法》，精神失常者或挥霍者的保佐职责常由一人承担；但若该法定保佐人似乎不适合处理此事，裁判官便会将管理事务的职责交给另一人。

<!-- source-p 046 -->
<a id="27.10.14"></a>**27.10.14**

<!-- source-p 047 -->
**帕皮尼安：《答复集》第五卷。**

<!-- source-p 048 -->
不应指定丈夫担任精神失常妻子的保佐人。

<!-- source-p 049 -->
<a id="27.10.15"></a>**27.10.15**

<!-- source-p 050 -->
**保罗：《裁判集》第三卷。**

<!-- source-p 051 -->
<a id="27.10.15.pr."></a>**序言。**对于奢侈挥霍的妇女，也可以禁止其管理自己的财产。

<!-- source-p 052 -->
<a id="27.10.15.1"></a>**1.**精神失常男子或女子对保佐人财产享有的优先权，应予保留。挥霍者以及其他所有人——即使告示未提及他们——经裁定后，也对保佐人的财产享有优先权。

<!-- source-p 053 -->
<a id="27.10.16"></a>**27.10.16**

<!-- source-p 054 -->
**特里福尼努斯：《论争论》第十三卷。**

<!-- source-p 055 -->
<a id="27.10.16.pr."></a>**序言。**如果父亲在遗嘱中为已经达到青春期、且超过二十五岁的精神失常者指定保佐人，裁判官应遵从父亲的意愿并指定此人；因为指定保佐人的权力仍属于裁判官，神圣马尔库斯皇帝的敕答对此已有说明。

<!-- source-p 056 -->
<a id="27.10.16.1"></a>**1.**由此可知，如果父亲为挥霍者指定了保佐人，裁判官也应遵从其意愿并指定该保佐人。但这是在任何情况下都应如此，还是仅限于这样的情形：若父亲未在遗嘱中作出规定，裁判官本会禁止此人管理财产？尤其是，如果该挥霍者有子女呢？

<!-- source-p 057 -->
<a id="27.10.16.2"></a>**2.**不过，父亲也可以通过其他方式为孙辈作安排：例如指定他们为继承人，剥夺其父（即自己的儿子）的继承权，并以遗赠方式留给他足以维持生活的供养，同时说明其作此处分的理由和必要性；又或者，如果父亲无权支配这些孙辈——因为他们是在其子被解放出家父权后出生的——则可附条件指定他们为继承人，条件是他们须由挥霍的父亲解放出家父权。

<!-- source-p 058 -->
<a id="27.10.16.3"></a>**3.**但如果挥霍者连这项安排也不同意，又该如何？无论如何都应遵从立遗嘱人的意思，以免父亲基于正当判断认定其子挥霍，而行政官却因某种自身过失认为此人适任。

<!-- source-p 059 -->
<a id="27.10.17"></a>**27.10.17**

<!-- source-p 060 -->
**盖尤斯：《论释放奴隶》第一卷。**

<!-- source-p 061 -->
精神失常者的保佐人无论如何都不能授予自由，因为此事不属于事务管理的范围。只有在事务管理所需的范围内，保佐人才可以交付精神失常者的财物并转移其所有权。因此，如果保佐人以赠与为目的处分财物，交付即不发生效力；除非经法官审查后认定，该行为对精神失常者具有重大利益。
