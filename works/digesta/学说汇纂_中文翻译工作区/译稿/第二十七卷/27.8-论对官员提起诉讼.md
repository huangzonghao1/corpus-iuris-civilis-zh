# D.27.8 论对官员提起诉讼（*De magistratibus conveniendis*）

<!-- source-p 001 -->
<a id="8"></a><a id="27.8"></a>**27.8.0　论对官员提起诉讼**

<!-- source-p 002 -->
<a id="27.8.1"></a>**27.8.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第三十六卷。**

<!-- source-p 004 -->
<a id="27.8.1.pr."></a>**序言。**补充之诉（*actio subsidiaria*）不得针对城市议会整体提起，而应针对官员提起；也不得针对这些官员的保证人提起，因为他们保证的是公共财产安全，而非被监护人财产安全。因此，依此事由，提名城市官员的人也不承担责任；但若城市议会已自行承担风险，则应认定在场参与决议者承担责任。无论他们曾经提名、提供保证，还是自行承担风险，差别都不大；故可对他们提起准诉。不过，若监护人由城市官员指定，则不能认为其系由城市议会选任。

<!-- source-p 005 -->
<a id="27.8.1.1"></a>**1.**执法官或其他有权指定监护人的人，不因该项诉讼而承担责任。

<!-- source-p 006 -->
<a id="27.8.1.2"></a>**2.**若行省总督仅要求官员报告监护人的财产状况，以便由总督本人指定监护人，应考察官员是否以及在何种范围内承担责任。神圣马尔库斯有一项敕答，规定向总督报告情况的人，不与自行指定监护人的人同等承担责任；但若他们以徇私或收受金钱等方式欺骗总督，则应承担责任。显然，若行省总督命令他们要求提供担保，他们即应承担责任，即使监护人是由总督指定的亦然。

<!-- source-p 007 -->
<a id="27.8.1.3"></a>**3.**若行省总督收到他人提出的候选人姓名后，将其交给城市官员调查核实，再据此指定监护人，须考察城市官员是否应如同向执法官提供候选人资料者那样承担责任。毕竟，他们自行遴选名单后交给总督，与仅调查总督从他人处收到的姓名，并不相同。我认为，无论哪种情形，只要他们有欺诈或重大过失行为，就应承担责任。

<!-- source-p 008 -->
<a id="27.8.1.4"></a>**4.**不仅被监护人本人，其权利继受人也可以提起补充之诉。

<!-- source-p 009 -->
<a id="27.8.1.5"></a>**5.**若指定的保佐人不适格，且总督系依据城市官员的建议或其所提供的姓名作出指定，则应认定官员承担责任。若总督命令他们自行指定保佐人，或者在指定后命令他们要求提供担保，风险也由他们承担。

<!-- source-p 010 -->
<a id="27.8.1.6"></a>**6.**若根本没有指定监护人或保佐人，这也应归责于城市官员；但只有在他们经催告仍未指定时，才承担责任。因此，未成年人或少年在此期间所遭受的损失，无疑应由未履行所受职务委托的官员承担。

<!-- source-p 011 -->
<a id="27.8.1.7"></a>**7.**还应知道，若城市官员故意将监护任命拖延至继任者任内，或者故意拖延要求担保，直至继任者上任，他们不得因此获益。

<!-- source-p 012 -->
<a id="27.8.1.8"></a>**8.**神圣哈德良曾作敕答，规定也可以对受任评估监护人担保是否充分的人提起诉讼。

<!-- source-p 013 -->
<a id="27.8.1.9"></a>**9.**若城市官员约定仅由其中一人承担指定监护人的风险，神圣哈德良敕答称，该约定不得损害被监护人的利益；因为两名执政官之间的约定不能改变公法。不过，我认为应先起诉承担该义务的人；待其财产不足以清偿后，方可向其同僚追索。这与若由一人单独作出指定时，应先起诉该人、再起诉其同僚的规则相同。

<!-- source-p 014 -->
<a id="27.8.1.10"></a>**10.**若被监护人所属城市内没有适格人选，官员有职责从邻近城市中寻找最有声望者，并将其姓名报送行省总督；不得自行主张指定人选的裁量权。

<!-- source-p 015 -->
<a id="27.8.1.11"></a>**11.**若官员起初指定了适格监护人，却未要求提供担保，仅此并不足够。但若其已要求提供适当担保，而监护人当时也确属适格，即便监护人或保证人后来丧失清偿能力，也不应归责于指定官员；官员不必为被监护人未来可能遭遇的事故与命运负责。

<!-- source-p 016 -->
<a id="27.8.1.12"></a>**12.**即使官员未要求担保，只要监护人在可以提起监护之诉的期间仍有清偿能力，也足以使官员免责。

<!-- source-p 017 -->
<a id="27.8.1.13"></a>**13.**证明责任不由被监护人承担；被监护人无须证明保证人在被接受担保时没有清偿能力。相反，应由官员证明保证人当时具有清偿能力。

<!-- source-p 018 -->
<a id="27.8.1.14"></a>**14.**被监护人对官员的财产不享有优先权，而应与其他债权人共同按比例受偿。

<!-- source-p 019 -->
<a id="27.8.1.15"></a>**15.**官员要求提供担保时，应使被监护人的奴隶或被监护人本人（如果他能够表达且当时在场）与监护人及其保证人订立要式口约，保证被监护人的财产安全。若无人能够订立该口约，应由公奴为被监护人的财产安全订立口约；至少也应由官员本人订立。

<!-- source-p 020 -->
<a id="27.8.1.16"></a>**16.**若由公奴或官员本人订立口约，应认为可以为被监护人授予准诉。

<!-- source-p 021 -->
<a id="27.8.1.17"></a>**17.**若官员是家子，因其过失未为被监护人安排担保，或者担保并不适当，是否应当以及在何种范围内对其父亲提起诉讼，尚有疑问。尤利安认为，可以对其父亲提起特有产之诉（*actio de peculio*），不论其子是经父亲同意还是未经同意成为市议员。因为即使儿子经父亲同意担任官职，也不应使父亲承担超过特有产范围的责任；父亲允许儿子成为市议员，仿佛只是承诺公共财产安全。

<!-- source-p 022 -->
<a id="27.8.2"></a>**27.8.2**

<!-- source-p 023 -->
**乌尔比安：《论题集》第三卷。**

<!-- source-p 024 -->
有人提出如下情形：城市官员指定了两名监护人，却未要求担保；其中一人死亡且无力清偿，另一人被要求承担全部责任，并已向被监护人提供足额担保。问题是，这名监护人明知共同监护人未提供担保，能否对城市官员提起某种诉讼。我说，既然监护人已向被监护人提供足额担保，被监护人便不能再向官员追索；监护人也不能，因为监护人从来没有针对官员的诉权。元老院决议所救济的是被监护人。尤其是监护人有可归责之处：他没有要求共同监护人提供担保；若如所述，他知道官员未要求共同监护人提供担保，却没有将其告发为可疑者，也应归责于他。

<!-- source-p 025 -->
<a id="27.8.3"></a>**27.8.3**

<!-- source-p 026 -->
**尤利安：《学说汇纂》第二十一卷。**

<!-- source-p 027 -->
若监护人在此事上没有过失，则对官员授予诉权并无不公。

<!-- source-p 028 -->
<a id="27.8.4"></a>**27.8.4**

<!-- source-p 029 -->
**乌尔比安：《论题集》第三卷。**

<!-- source-p 030 -->
官员的继承人并不像官员本人那样承担责任；正如监护人的继承人也不因疏忽而承担责任。官员本人承受一切风险，而其继承人仅在欺诈或最接近欺诈的过失（重大过失）范围内继受责任。

<!-- source-p 031 -->
<a id="27.8.5"></a>**27.8.5**

<!-- source-p 032 -->
**尤利安：《学说汇纂》第二十一卷。**

<!-- source-p 033 -->
两名监护人彼此分配了监护事务的管理；其中一人死亡且无继承人。问题是，被监护人应对未确保担保的官员提起诉讼，还是对另一名监护人提起诉讼。我答复说，对另一名监护人提起诉讼较为公平：他既然知道被监护人没有获得担保，就本应管理全部事务；对于他交由另一监护人处理的部分，他如同从未参与被监护人某些事务管理的人。即使他管理了被监护人的一部分事务，对于其未管理但本应管理的事务，也仍须承担责任。

<!-- source-p 034 -->
<a id="27.8.6"></a>**27.8.6**

<!-- source-p 035 -->
**乌尔比安：《告示评注》第一卷。**

<!-- source-p 036 -->
关于官员的继承人，现有虔敬者庇护的敕答：经查明事实后，应决定是否授予诉讼。若官员疏忽至完全没有要求任何担保，公平起见，应将其视同保证人，其继承人也应承担责任。反之，若官员已经要求担保，且保证人当时确有清偿能力，只是后来丧失清偿能力，那么官员本人本可正当地拒绝承担该诉讼，其继承人更应如此。最后，敕答说，只有官员明显与不适格的保证人订立保证时，才可对其继承人提起诉讼。

<!-- source-p 037 -->
<a id="27.8.7"></a>**27.8.7**

<!-- source-p 038 -->
**凯尔苏斯：《学说汇纂》第十一卷。**

<!-- source-p 039 -->
请你就针对指定监护人的官员所提起的诉讼作出答复：该诉讼应按各官员的份额分别提起，还是由曾为被监护人的人自行选择起诉其中哪一人？答复如下：若官员出于欺诈，致使被监护人未能获得充分担保，则被监护人可以选择任何一人，并向其请求全额偿付；若官员仅有过失而无欺诈，我认为依公平应按各自份额对每一人提起诉讼，只要被监护人的财产安全得以保障即可。

<!-- source-p 040 -->
<a id="27.8.8"></a>**27.8.8**

<!-- source-p 041 -->
**莫德斯汀：《答复集》第六卷。**

<!-- source-p 042 -->
官员要求成年人的保佐人提供财产安全保证；其中一名保佐人死亡且无继承人。我问：其同僚是否应全额赔偿损失？莫德斯汀答复：没有理由认为其不应如此。

<!-- source-p 043 -->
<a id="27.8.9"></a>**27.8.9**

<!-- source-p 044 -->
**莫德斯汀：《法学大全》第四卷。**

<!-- source-p 045 -->
曾有人询问：对官员提起诉讼时，是否应连本金一并追索利息；还是如同已规定不得请求惩罚性利息那样，不得请求利息？神圣塞维鲁与安敦尼的敕答确认，可以请求利息；因为针对官员的诉讼与针对监护人的诉讼相同。
