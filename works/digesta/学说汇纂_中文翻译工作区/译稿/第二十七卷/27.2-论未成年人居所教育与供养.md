# D.27.2 论受监护未成年人应在何处受教育或居住，以及应向其提供的供养（*Ubi pupillus educari vel morari debeat et de alimentis ei praestandis*）

<!-- source-p 001 -->
<a id="2"></a><a id="27.2"></a>**27.2.0. 论受监护未成年人应在何处受教育或居住，以及应向其提供的供养。**

<!-- source-p 002 -->
<a id="27.2.1"></a>**27.2.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第三十四卷。**

<!-- source-p 004 -->
<a id="27.2.1.pr."></a>**序言。**裁判官常常受人请求，以裁定子女应在哪里接受抚育或居住；此事不仅涉及遗腹子，也普遍涉及未成年子女。

<!-- source-p 005 -->
<a id="27.2.1.1"></a>**1.**裁判官通常根据当事人的具体情况、身份状况和时势，裁定子女较宜在何处受抚育；有时也会不遵从父亲的意愿。确有一人曾在遗嘱中规定，其子应由遗嘱替补继承人抚养；神圣的塞维鲁皇帝敕答称，裁判官应在子女的其他亲属到场时作出判断。裁判官应确保子女得到抚养和教育，不致引起任何恶意猜疑。

<!-- source-p 006 -->
<a id="27.2.1.2"></a>**2.**裁判官虽通常不承诺将强迫拒绝在自己家中抚养未成年人的人接受抚养，但仍有一个问题：是否应当强迫此人违背其意愿承担抚养，例如自由释奴、父母，或其他姻亲、血亲。较可取的意见是，裁判官有时应当这样做。

<!-- source-p 007 -->
<a id="27.2.1.3"></a>**3.**如果受遗赠人或继承人拒绝履行遗嘱加诸其身的抚养义务，那么可以认为，应当仿照遗嘱指定的监护人，拒绝给予其诉权；但只有在遗嘱处分正是以此为条件时，方可如此。反之，如果立遗嘱人即使知道其将拒绝抚养，仍会作出该项遗赠或继承安排，就不得拒绝给予其诉权。神圣的塞维鲁皇帝曾多次如此裁定。

<!-- source-p 008 -->
<a id="27.2.2"></a>**27.2.2**

<!-- source-p 009 -->
**乌尔比安：《告示评注》第三十六卷。**

<!-- source-p 010 -->
<a id="27.2.2.pr."></a>**序言。**审理监护事务的法官，依其职务，应当准许监护人在账目中列入合理支出；例如监护人主张曾为受监护未成年人的生活供养或教育支付费用。

<!-- source-p 011 -->
<a id="27.2.2.1"></a>**1.**如果裁判官已经确定了供养金额，就应遵守裁判官所定数额；如果未曾请求裁判官裁定，则由法官酌情根据受监护未成年人的财力确定数额。不得允许监护人将其实际支付的全部金额都列入账目，因为其支出可能超过合理范围。

<!-- source-p 012 -->
<a id="27.2.2.2"></a>**2.**此外，即使裁判官已经确定供养数额，但裁定金额超出受监护未成年人的财力，而监护人又未向裁判官说明其财产状况，那么全部供养支出都不应计入账目；因为如果监护人曾作出说明，裁判官就会减少已裁定的金额，或者不会裁定如此高的数额。

<!-- source-p 013 -->
<a id="27.2.2.3"></a>**3.**但是，如果父亲为其指定为继承人的子女确定了供养数额，监护人实际支付后可以在账目中列支；但父亲所定数额若超出子女的财力，则监护人应负责，因为他未曾请求裁判官减少供养数额。

<!-- source-p 014 -->
<a id="27.2.3"></a>**27.2.3**

<!-- source-p 015 -->
**乌尔比安：《论各级审判庭》第一卷。**

<!-- source-p 016 -->
<a id="27.2.3.pr."></a>**序言。**裁判官有权裁定向受监护未成年人提供供养，并由其确定监护人或保佐人应向受监护未成年人或青年人支付的数额。

<!-- source-p 017 -->
<a id="27.2.3.1"></a>**1.**裁定供养数额时，应考虑受监护未成年人的财产规模；裁定应当适度，不得将其全部财产收益都用于供养，而应始终留有部分收益。

<!-- source-p 018 -->
<a id="27.2.3.2"></a>**2.**裁定时还应考虑为受监护未成年人服务的奴隶、未成年人的收入、衣物和住所，以及接受供养者所处的年龄阶段。

<!-- source-p 019 -->
<a id="27.2.3.3"></a>**3.**不过，对于拥有大量财产的人，供养数额不应按其财产总量确定，而应以足以维持其节俭生活为限。

<!-- source-p 020 -->
<a id="27.2.3.4"></a>**4.**如果财产状况及其数额尚不明确，裁判官应听取监护人和请求裁定供养者双方的陈述，进行调查，不得轻率裁定，以免偏向任何一方。但首先应要求监护人申报其掌管的财产总额，并警告他：如查明其掌管的财产超过申报数额，将对超出部分加收较高利息。

<!-- source-p 021 -->
<a id="27.2.3.5"></a>**5.**裁判官通常也会根据受教育者的财力和年龄，裁定为受监护未成年人、受监护的青年女子或未满二十岁者提供教育费用。

<!-- source-p 022 -->
<a id="27.2.3.6"></a>**6.**如果受监护未成年人贫困，不得强迫监护人以自己的财产供养他们。如果供养数额裁定后，受监护未成年人后来陷于贫困，就应减少已裁定的金额；同样，若其财产有所增加，供养金额通常也应增加。

<!-- source-p 023 -->
<a id="27.2.4"></a>**27.2.4**

<!-- source-p 024 -->
**尤利安：《学说汇纂》第二十一卷。**

<!-- source-p 025 -->
某人指定其子为继承人；其女儿嫁入夫家时，他以嫁资名义遗赠二百，除此之外未再给她其他财物，并为子女指定塞姆普罗尼乌斯为监护人。受监护女孩的亲属和近亲将塞姆普罗尼乌斯带到长官面前，长官命令他以女孩名义支付供养费和教师报酬，使她得以学习自由技艺。后来，受监护男孩达到青春期，而其妹妹当时也已达到青春期，于是他向妹妹支付了作为遗赠的二百。有人询问：监护人能否在监护诉讼中请求承认其为受监护女孩支付的供养费和教师报酬？我答复认为：即使监护人未取得长官裁定，仍为其受监护人的妹妹提供供养并教授她自由技艺——因为若非如此，她便无法获得这些条件——监护人也不因此须在监护诉讼中向受监护人或其遗嘱替补继承人支付任何款项。

<!-- source-p 026 -->
<a id="27.2.5"></a>**27.2.5**

<!-- source-p 027 -->
**乌尔比安：《论行省总督职务》第三卷。**

<!-- source-p 028 -->
如果就受监护未成年人应当居住或受教育之处发生争议，行省长官应在查明案情后作出裁定。调查此事时，应当避开那些可能侵害未达青春期年龄者贞操的人。

<!-- source-p 029 -->
<a id="27.2.6"></a>**27.2.6**

<!-- source-p 030 -->
**特里福尼努斯：《论争论》第十四卷。**

<!-- source-p 031 -->
如果监护人不在，而受监护未成年人请求供养，那么，若有人指控监护人疏忽且在事务管理中严重怠惰，且其怠慢还可由下列事实证明：因监护人缺席，未成年人的事务已被搁置、无人处理——此时，裁判官应发布告示，传唤监护人的姻亲和友人，并在查明案情后，即使监护人缺席，也可裁定撤换被认为不配担任监护人的人，或另行指定保佐人与其共同履职；被指定者应安排向未成年人提供供养。反之，如果监护人因必要且不可预见的事由缺席，例如突然前往参加主要审判，以致既不能料理自己的事务，也不能照管未成年人；且预计他会返回，其人选适任，另行指定他人也无必要，而未成年人请求从自己的财产中支付供养，那么可以适当地仅为此事指定一人，使其从未成年人的财产中安排支付供养。
