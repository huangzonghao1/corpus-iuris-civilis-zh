# D.27.6 论据称经虚假监护人授权实施的行为（*Quod falso tutore auctore gestum esse dicatur*）

<!-- source-p 001 -->
<a id="6"></a><a id="27.6"></a>**27.6.0. 论据称经虚假监护人授权实施的行为。**

<!-- source-p 002 -->
<a id="27.6.1"></a>**27.6.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第十二卷。**

<!-- source-p 004 -->
<a id="27.6.1.pr."></a>**序言。**本告示所体现的衡平原则并无疑义，旨在避免交易当事人因请一名虚假监护人参与而受骗。

<!-- source-p 005 -->
<a id="27.6.1.1"></a>**1.**裁判官告示的原文如下：

<!-- source-p 006 -->
<a id="27.6.1.2"></a>**2.**裁判官说：“凡经并非监护之人的授权所为之事。”但告示措辞省略了许多情形。因为，如果某人虽为监护人，却无权作出监护人认可，会如何？例如，此人患有精神障碍，或被指定在另一个行省任职。

<!-- source-p 007 -->
<a id="27.6.1.3"></a>**3.**不过，庞波尼乌斯在《学说汇纂》第三十卷中写道：有时，尽管某事由非监护人实施，却不属于告示本部分的适用范围。例如，两名监护人中一人是假监护人，另一人是真监护人，而二人均作出认可；此时所为行为难道不会有效吗？

<!-- source-p 008 -->
<a id="27.6.1.4"></a>**4.**庞波尼乌斯在《学说汇纂》第三十卷中还写道：尽管这项告示采用单数表述，但如果有数名并非监护人的人参与其中，告示仍应适用。

<!-- source-p 009 -->
<a id="27.6.1.5"></a>**5.**同一位庞波尼乌斯还写道：即使某人只是以监护人身份管理事务，却作出了监护人认可，本告示仍然适用；除非裁判官已裁定，承认经此人认可所实施的行为。在这种情况下，行为因裁判官的保护而有效，而非依市民法当然有效。

<!-- source-p 010 -->
<a id="27.6.1.6"></a>**6.**裁判官说：“如果原告对此不知情，我将给予恢复原状救济。”对于知情者，裁判官不予帮助，这是适当的，因为他是自取其骗。

<!-- source-p 011 -->
<a id="27.6.2"></a>**27.6.2**

<!-- source-p 012 -->
**保罗：《告示评注》第十二卷。**

<!-- source-p 013 -->
他说：“如果原告对此不知情。”拉贝奥认为，即使有人已经告知原告，只要原告出于善意而未予相信，也属于不知情。

<!-- source-p 014 -->
<a id="27.6.3"></a>**27.6.3**

<!-- source-p 015 -->
**乌尔比安：《告示评注》第十二卷。**

<!-- source-p 016 -->
当然，如果当事人不需要此项救济，知情也不会对其不利。例如，未成年人之间发生诉讼时，未成年人即使知情也不受影响，因为在这种情况下，法律上并未发生有效行为。

<!-- source-p 017 -->
<a id="27.6.4"></a>**27.6.4**

<!-- source-p 018 -->
**保罗：《告示评注》第十二卷。**

<!-- source-p 019 -->
即使未成年人知道此事，也应给予未满二十五岁者救济。

<!-- source-p 020 -->
<a id="27.6.5"></a>**27.6.5**

<!-- source-p 021 -->
**乌尔比安：《告示评注》第十二卷。**

<!-- source-p 022 -->
不过，有时即使知情会对当事人不利，仍应给予恢复原状救济，例如，当事人受到裁判官强迫而不得不接受诉讼审理时。

<!-- source-p 023 -->
<a id="27.6.6"></a>**27.6.6**

<!-- source-p 024 -->
**保罗：《告示评注》第十二卷。**

<!-- source-p 025 -->
应计算监护人的知情，而不计算受监护未成年人的知情。即便已为受监护未成年人提供担保，较可取的意见仍是，应将财物本身返还给他，而不是让他承受担保最终能否实现的不确定性。尤利安也曾就受监护未成年人在其他方面遭受欺骗的情形作出同样答复。

<!-- source-p 026 -->
<a id="27.6.7"></a>**27.6.7**

<!-- source-p 027 -->
**乌尔比安：《告示评注》第十二卷。**

<!-- source-p 028 -->
<a id="27.6.7.pr."></a>**序言。**裁判官最后说：“对于被指称虽非监护人，却以恶意欺诈作出监护人认可之人，我将给予诉权，并判令其支付该事项价值相当的金钱。”

<!-- source-p 029 -->
<a id="27.6.7.1"></a>**1.**并非任何情形都可起诉监护人；仅仅是他明知而作出认可还不够，只有他以恶意欺诈作出认可时才可起诉。如果他是受到强迫才作出认可，或者出于畏惧而作出认可——唯恐自己会受到强迫——难道不应免除其责任吗？

<!-- source-p 030 -->
<a id="27.6.7.2"></a>**2.**裁判官所说的“该事项价值相当的金钱”，我认为，其措辞所指的不是惩罚，而是实际价值。

<!-- source-p 031 -->
<a id="27.6.7.3"></a>**3.**庞波尼乌斯在《学说汇纂》第三十卷中正确写道：在这项诉讼中，也应计算原告提起恢复原状之诉时将支出的费用。

<!-- source-p 032 -->
<a id="27.6.7.4"></a>**4.**如果有数人作出了认可，一人已受领给付后，其他人即获免责；免责依据是实际受领，而非原告对被告的选择。

<!-- source-p 033 -->
<a id="27.6.8"></a>**27.6.8**

<!-- source-p 034 -->
**保罗：《告示评注》第十二卷。**

<!-- source-p 035 -->
因此，如果财物未获返还，或未全部返还，萨宾写道，对于尚未返还的部分，不得拒绝原告向其他责任人提起诉讼。

<!-- source-p 036 -->
<a id="27.6.9"></a>**27.6.9**

<!-- source-p 037 -->
**乌尔比安：《告示评注》第十二卷。**

<!-- source-p 038 -->
<a id="27.6.9.pr."></a>**序言。**庞波尼乌斯在《学说汇纂》第三十一卷中写道，可以仿照本诉，对以恶意欺诈促使他人在不知情的情况下作出认可之人给予诉权。

<!-- source-p 039 -->
<a id="27.6.9.1"></a>**1.**拉贝奥写道，这些事实诉讼可以由继承人及其他继受人提起，但不得针对这些人提起；即使针对行为人本人，也不得在一年之后提起，因为这些诉讼惩罚的是特定行为，且以欺诈为基础。若被告属于受他人权力支配者，则应提起诺克萨尔之诉（*actio noxalis*）。

<!-- source-p 040 -->
<a id="27.6.10"></a>**27.6.10**

<!-- source-p 041 -->
**盖尤斯：《行省告示评注》第四卷。**

<!-- source-p 042 -->
如果某事是在虚假监护人认可下实施的，而在此期间诉权期间届满，或标的物已因取得时效而归他人所有，则承担全部不利后果的方式，应与当事人在当时取得真正监护人的认可后提起诉讼相同。

<!-- source-p 043 -->
<a id="27.6.11"></a>**27.6.11**

<!-- source-p 044 -->
**乌尔比安：《告示评注》第三十五卷。**

<!-- source-p 045 -->
<a id="27.6.11.pr."></a>**序言。**虚假监护人若在与未满十二岁或十四岁的未成年人缔约时作出认可，应因恶意欺诈而承担事实诉讼责任。

<!-- source-p 046 -->
<a id="27.6.11.1"></a>**1.**无论作出恶意欺诈认可者属于何种身份，无论其为自权人还是他权人，均应依本告示承担责任。

<!-- source-p 047 -->
<a id="27.6.11.2"></a>**2.**如果有人认可家父权下的女儿订立契约，也应承担责任。若有人在监护人认可下向女奴出借款项，法律亦同。因为在上述各种情形中，缔约人均因监护人而受骗：倘若未成年子女没有得到监护人的认可，缔约人就不会与其订立契约。

<!-- source-p 048 -->
<a id="27.6.11.3"></a>**3.**尤利安在《学说汇纂》第二十一卷中讨论：对于将未满十二岁的女儿嫁出的父亲，是否应给予此项诉权。他更倾向于认为，应宽宥这位父亲，因为他只是想让女儿较早进入未婚夫的家中；看来他是出于更深的亲情，而非恶意欺诈，才这样做。

<!-- source-p 049 -->
<a id="27.6.11.4"></a>**4.**但是，如果该女孩未满十二岁时死亡，且曾有嫁资，尤利安认为：如果嫁资归属的一方以恶意欺诈行事，那么在婚姻若已成立时，丈夫本可全部或部分取得嫁资的情形下，丈夫可以援引恶意欺诈抗辩，阻却对其提起的返还之诉。

<!-- source-p 050 -->
<a id="27.6.12"></a>**27.6.12**

<!-- source-p 051 -->
**乌尔比安：《答复集》第一卷。**

<!-- source-p 052 -->
仅因某人受询问时答称自己是监护人，并不使其承担任何诉讼责任；但是，如果他并非监护人，却以该答复诱使青年人陷入某种损失，则应准许对其提起准用之诉。
