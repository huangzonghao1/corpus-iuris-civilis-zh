# D.27.3 论监护诉讼、账目侵吞之诉及因保佐而提起的有用之诉（*De tutelae et rationibus distrahendis et utili curationis causa actione*）

<!-- source-p 001 -->
<a id="3"></a><a id="27.3"></a>**27.3.0. 论监护诉讼、账目侵吞之诉及因保佐而提起的有用之诉。**

<!-- source-p 002 -->
<a id="27.3.1"></a>**27.3.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第三十六卷。**

<!-- source-p 004 -->
<a id="27.3.1.pr."></a>**序言。**在监护人所做的所有本不应做的事项，以及所有本应做而未做的事项上，均应通过本诉要求其交账；其责任标准为诈欺、过失，以及其处理自身事务时所尽的注意。

<!-- source-p 005 -->
<a id="27.3.1.1"></a>**1.**因此，尤利安在《学说汇纂》第二十一卷中提出：如果监护人同意未成年人作出死因赠与，是否应在监护诉讼中承担责任？他说应当承担；因为正如未成年人不享有立遗嘱能力，也不应允许其作出死因赠与。

<!-- source-p 006 -->
<a id="27.3.1.2"></a>**2.**同样，如果监护人同意未成年人作出非死因赠与，尤利安写道，多数人认为赠与无效，而且通常确实如此；但也可能出现一些情形，在不受指责的情况下，监护人可经裁定同意未成年人减少财产。例如，如果监护人为无力自立的母亲或姐妹提供生活费：由于监护诉讼属于诚信诉讼，没人会容许未成年人或其替补继承人抱怨说监护人供养了如此亲近的亲属；相反，尤利安认为，如果监护人未履行此种职责，甚至可以对其提起监护诉讼。

<!-- source-p 007 -->
<a id="27.3.1.3"></a>**3.**监护人的职责还包括编制并向未成年人提交其管理账目；如果他没有编制，或编制后拒不出示，就应在监护诉讼中就此承担责任。人们也认为，依该诉讼中的法官职权，可以询问并讯问奴隶。神圣的塞维鲁皇帝曾裁定：如果监护人未能提交财产清册和拍卖记录，应采用补救办法，要求曾经处理事务的奴隶提交账目。如果监护人声称奴隶以恶意编造账目，也可以讯问这些奴隶。

<!-- source-p 008 -->
<a id="27.3.1.4"></a>**4.**如果监护人供养未成年人的母亲，拉贝奥认为可将此项支出计入账目；但较正确的意见是，只有母亲极度贫困、而未成年人财产充足时，监护人才可计入该项支出。因此，两项条件都必须具备：母亲贫困，儿子则拥有充足财产。

<!-- source-p 009 -->
<a id="27.3.1.5"></a>**5.**拉贝奥写道，如果监护人给未成年人的母亲送婚礼礼物，不得将其计入未成年人的账目；这种赠与并非十分必要。

<!-- source-p 010 -->
<a id="27.3.1.6"></a>**6.**如果父亲为子女指定数名监护人，其中包括自己的自由人，并希望由该自由人管理监护事务，而其他监护人又为他确定了一笔固定报酬，因为他若无此报酬便无法维持生活，梅拉认为应将该固定报酬计入账目。

<!-- source-p 011 -->
<a id="27.3.1.7"></a>**7.**因此，如果某监护人因熟悉事务而经调查程序指定，共同监护人又为其规定生活费，也应将此项费用计入账目，因为支付该费用有正当理由。

<!-- source-p 012 -->
<a id="27.3.1.8"></a>**8.**如果监护人为奴隶或自由人提供口粮，而且他们确为未成年人事务所必需，也应当计入账目；如果为自由民提供口粮，只要有正当理由，同样处理。

<!-- source-p 013 -->
<a id="27.3.1.9"></a>**9.**同样，监护人可以计入诉讼费用和旅费，但前提是他因履行职责而必须前往某地。

<!-- source-p 014 -->
<a id="27.3.1.10"></a>**10.**现在讨论：如果有数名监护人管理未成年人的事务，应按何种份额起诉每一人。

<!-- source-p 015 -->
<a id="27.3.1.11"></a>**11.**如果他们共同管理监护事务，且人人都有清偿能力，最公平的做法是仿照保证人规则，按各自份额在他们之间分配诉讼请求。

<!-- source-p 016 -->
<a id="27.3.1.12"></a>**12.**如果并非人人都有清偿能力，则应在有清偿能力的人之间分配诉讼请求；并可依每个人的清偿能力分别起诉。

<!-- source-p 017 -->
<a id="27.3.1.13"></a>**13.**如果监护人因共同监护人的行为而被判承担责任并已给付，或者因共同管理的事务而被判承担责任并已给付，而他又未获让与针对共同监护人的诉权，神圣的皮乌斯皇帝、本朝皇帝及其神圣父皇均规定，应给予该监护人针对共同监护人的有用之诉。

<!-- source-p 018 -->
<a id="27.3.1.14"></a>**14.**当然，如果监护人因共同诈欺而被起诉并已给付，不应让与诉权，也不应给予有用之诉，因为他是在承担自己犯罪行为的处罚；他不配从其他共同诈欺者处取得任何利益。毕竟，犯罪行为之间不存在合法的合伙关系，也不存在共同分担犯罪所生损失的合法关系。

<!-- source-p 019 -->
<a id="27.3.1.15"></a>**15.**只要共同监护人有清偿能力，就不会马上转而起诉指定他们的官员或保证人；应先起诉这些共同监护人。本朝皇帝曾以敕答告知乌尔皮乌斯·普罗库卢斯。马尔凯卢斯在《学说汇纂》第八卷中的论述以及多次敕答所说，只要监护人中至少有一人适任，就不得转而起诉指定他们的官员，应作如下理解：不得以共同监护人未将另一人控告为可疑监护人或未要求其提供担保为由起诉该共同监护人。

<!-- source-p 020 -->
<a id="27.3.1.16"></a>**16.**可以确定，该诉也可向监护人的继承人提起。

<!-- source-p 021 -->
<a id="27.3.1.17"></a>**17.**未成年人的继承人以及类似身份的人，也同样享有该诉权。

<!-- source-p 022 -->
<a id="27.3.1.18"></a>**18.**监护人不仅可在判决前请求将针对共同监护人的诉权让与自己；即使已经被判承担责任，也可作此请求。

<!-- source-p 023 -->
<a id="27.3.1.19"></a>**19.**账目侵吞之诉不仅适用于法定监护人，也适用于所有依法具有监护人身份且实际管理监护事务的人。

<!-- source-p 024 -->
<a id="27.3.1.20"></a>**20.**应考察本诉判赔的范围究竟仅为财物价额的双倍，还是还包括未成年人所受利益损失。我认为较为可取的意见是，本诉不包括利益损失，仅包括财物的估价。

<!-- source-p 025 -->
<a id="27.3.1.21"></a>**21.**可以确定，监护关系所生的一项债务包含两种诉讼：因此，若已提起监护诉讼，就不能再提起账目侵吞之诉；反之，若已提起账目侵吞之诉，就该事项而言，监护诉讼即告消灭。

<!-- source-p 026 -->
<a id="27.3.1.22"></a>**22.**帕皮尼安说，侵吞未成年人款项的监护人也负盗窃责任。即使他应对盗窃负责，在本诉中被起诉也不会使盗窃之诉消灭；因为盗窃责任与监护责任并非同一债务，不能说同一行为仅产生数项诉讼，而是产生数项债务：他既负监护责任，也负盗窃责任。

<!-- source-p 027 -->
<a id="27.3.1.23"></a>**23.**应知，本诉为永久性诉讼；对于未成年人在世时被侵吞的财物，该诉权也给予其继承人及类似身份的人。但不得向监护人的继承人及其他继受人提起，因为该诉具有惩罚性质。

<!-- source-p 028 -->
<a id="27.3.1.24"></a>**24.**只有在监护诉讼也可提起时，亦即监护关系终止后，才可提起本诉。

<!-- source-p 029 -->
<a id="27.3.2"></a>**27.3.2**

<!-- source-p 030 -->
**保罗：《萨宾评注》第八卷。**

<!-- source-p 031 -->
<a id="27.3.2.pr."></a>**序言。**只有在管理监护事务时从未成年人的财产中取走财物的人，才承担账目侵吞之诉的责任。

<!-- source-p 032 -->
<a id="27.3.2.1"></a>**1.**如果他怀有盗窃故意，则也承担盗窃责任。他同时负有两项责任，任何一项都不消灭另一项。不过，也可以提起基于盗窃原因的返还请求之诉；如果未成年人通过该诉取回被拿走的财物，账目侵吞之诉即告消灭，因为未成年人已未遭受损失。

<!-- source-p 033 -->
<a id="27.3.2.2"></a>**2.**虽然本诉判赔双倍，但其中只包含对财物本身的追偿，并非全部都是双倍的惩罚。

<!-- source-p 034 -->
<a id="27.3.3"></a>**27.3.3**

<!-- source-p 035 -->
**庞波尼乌斯：《萨宾评注》第五卷。**

<!-- source-p 036 -->
如果提起监护诉讼或事务管理之诉，而对方应向监护人或代理人给付多少尚不确定，应依照法官裁量提供担保，保证他们不会因此蒙受损失。

<!-- source-p 037 -->
<a id="27.3.4"></a>**27.3.4**

<!-- source-p 038 -->
**保罗：《萨宾评注》第八卷。**

<!-- source-p 039 -->
<a id="27.3.4.pr."></a>**序言。**监护关系尚未终止时，不能提起监护诉讼。监护关系不仅因未成年人达到青春期而终止，也因监护人或未成年人死亡而终止。

<!-- source-p 040 -->
<a id="27.3.4.1"></a>**1.**尤利安认为，脱离父权的家子若管理监护事务，也直接承担责任。

<!-- source-p 041 -->
<a id="27.3.4.2"></a>**2.**如果未成年人尚未达到青春期就提起监护诉讼，不发生诉权消灭的效果。

<!-- source-p 042 -->
<a id="27.3.4.3"></a>**3.**对于精神失常者的保佐人，应提起事务管理之诉，而非监护诉讼；即使其仍在管理事务，也可提起该诉。因为此类诉讼并无如下规则：只要被照管者仍未达到青春期，就不得提起监护诉讼。

<!-- source-p 043 -->
<a id="27.3.5"></a>**27.3.5**

<!-- source-p 044 -->
**乌尔比安：《萨宾评注》第四十三卷。**

<!-- source-p 045 -->
如果监护人不返还未成年人父亲交由其保管或借给他的财物，他不仅应承担保管之诉或借用之诉的责任，也应承担监护诉讼的责任。如果监护人收到款项以便返还，多数人认为可以通过保管之诉、借用之诉或返还请求之诉请求给付；这是有道理的，因为他不当收取了该款项。

<!-- source-p 046 -->
<a id="27.3.6"></a>**27.3.6**

<!-- source-p 047 -->
**乌尔比安：《告示评注》第三十一卷。**

<!-- source-p 048 -->
如果家子曾管理监护事务，后来脱离父权并实施诈欺，父亲是否也因此在监护诉讼中承担责任？有人提出这一问题。公平的做法是，仅令父亲对儿子脱离父权之前实施的诈欺负责。

<!-- source-p 049 -->
<a id="27.3.7"></a>**27.3.7**

<!-- source-p 050 -->
**乌尔比安：《告示评注》第三十五卷。**

<!-- source-p 051 -->
<a id="27.3.7.pr."></a>**序言。**如果未成年人继承了监护人曾为其管理事务之人的遗产，他就可基于继承关系向自己的监护人提起诉讼。

<!-- source-p 052 -->
<a id="27.3.7.1"></a>**1.**如果监护人被敌人俘虏，由于监护关系被视为已经终止，可以正当地起诉为其保证财产妥善保全的保证人；也可以起诉愿意代其接受监护诉讼的辩护人，或为其财产指定的保佐人：

<!-- source-p 053 -->
<a id="27.3.8"></a>**27.3.8**

<!-- source-p 054 -->
**帕皮尼安：《疑问集》第二十八卷。**

<!-- source-p 055 -->
尽管依返还原状原则，他可以恢复先前的监护关系。

<!-- source-p 056 -->
<a id="27.3.9"></a>**27.3.9**

<!-- source-p 057 -->
**乌尔比安：《告示评注》第二十五卷。**

<!-- source-p 058 -->
<a id="27.3.9.pr."></a>**序言。**如果监护人开始因公缺席，并因此获准免责，仍可提起监护诉讼。但如果他不再因公缺席，代替他担任监护人的人也随之不再任职；而原监护人可以被起诉。

<!-- source-p 059 -->
<a id="27.3.9.1"></a>**1.**如果某人被指定为两名未成年兄弟的监护人，而其中一人后来达到完全年龄并成为其兄弟的法定监护人，涅拉提乌斯说，原先指定的监护人就不再是另一人的监护人。因此，即使通过未成年人本人也可以提起监护诉讼；但如果该监护人是由遗嘱指定的，则其仍继续担任尚未成年的另一人的监护人，因为法定监护始终让位于遗嘱监护。

<!-- source-p 060 -->
<a id="27.3.9.2"></a>**2.**如果某人依遗嘱附条件被指定为监护人，而另一人在此期间经调查程序获指定，那么条件成就时即可提起监护诉讼，因为遗嘱指定的监护人届时不再担任监护人。

<!-- source-p 061 -->
<a id="27.3.9.3"></a>**3.**如果某人依遗嘱仅在一定期限内被指定为监护人，也应作同样处理。

<!-- source-p 062 -->
<a id="27.3.9.4"></a>**4.**一般所说未成年人不得对自己的监护人提起监护诉讼，仅在监护关系仍为同一关系时才正确；因为要求监护人就仍由其管理的事务交账，实属荒谬。但如果监护人曾停止任职，后来又重新成为监护人，那么就其先前管理期间而言，他对未成年人负有债务，犹如曾从未成年人的父亲处借入款项一样。我们来考察这一规则如何适用：如果只有一名监护人，他当然不能起诉自己。对此，可以为未成年人指定特别保佐人；或者假设另有一名共同监护人，由其起诉该监护人，就此提起监护诉讼。更有甚者，如果前一监护人在此期间丧失清偿能力，还会归责于共同监护人，理由是他们为何未起诉他。

<!-- source-p 063 -->
<a id="27.3.9.5"></a>**5.**如果监护人另有一名保佐人，即使已有人请求将监护人认定为可疑监护人，也不得强令监护人接受监护诉讼，因为他仍然是监护人。

<!-- source-p 064 -->
<a id="27.3.9.6"></a>**6.**同样，如果监护人的财产被国库没收，显然应允许为代替该监护人而指定的保佐人或其共同监护人对国库提起诉讼。

<!-- source-p 065 -->
<a id="27.3.9.7"></a>**7.**除监护诉讼以外的其他诉讼，也可以在监护人仍管理监护事务期间对其提起，例如盗窃之诉、不法损害之诉和返还请求之诉。

<!-- source-p 066 -->
<a id="27.3.10"></a>**27.3.10**

<!-- source-p 067 -->
**保罗：《简要告示评注》第八卷。**

<!-- source-p 068 -->
但是，在监护人仍管理监护事务期间，不向未成年人授予这些诉权。虽然监护人死亡后，这些诉权会消灭，未成年人仍可对其继承人提起诉讼，因为监护人本应向自己清偿。

<!-- source-p 069 -->
<a id="27.3.11"></a>**27.3.11**

<!-- source-p 070 -->
**乌尔比安：《告示评注》第三十五卷。**

<!-- source-p 071 -->
如果家子管理了监护事务，后来脱离父权，尤利安说，他仍然是监护人。未成年人达到青春期后起诉他时，就脱离父权前的期间，家子仅在其履行能力范围内承担责任；就脱离父权后的期间，则承担全部责任；父亲仅在特有财产范围内承担责任。针对父亲的特有财产之诉即使在未成年人达到青春期后仍然存续，因为在监护关系终止前，特有财产之诉的一年期间尚未开始计算。

<!-- source-p 072 -->
<a id="27.3.12"></a>**27.3.12**

<!-- source-p 073 -->
**保罗：《简要告示评注》第八卷。**

<!-- source-p 074 -->
家子监护人不能因自己管理不当而在未成年人达到青春期前起诉其父亲，因为在监护关系终止前，尚不能要求家子承担此项责任。

<!-- source-p 075 -->
<a id="27.3.13"></a>**27.3.13**

<!-- source-p 076 -->
**乌尔比安：《告示评注》第三十五卷。**

<!-- source-p 077 -->
如果监护人在未成年人达到青春期后继续管理事务，监护诉讼仅涵盖与监护事务管理不可分割的事项。但是，如果他在未成年人达到青春期后出售其土地、购买奴隶或土地，那么这些买卖均不包含在监护诉讼中。与监护事务相互关联的事项确实属于该诉讼范围；但如果某人在监护关系终止后才开始管理事务，监护诉讼就转化为事务管理之诉，因为他本应向自己请求交还监护事务。即使某人管理监护事务后，又被指定为成年未成年人的保佐人，也可以对其提起事务管理之诉。

<!-- source-p 078 -->
<a id="27.3.14"></a>**27.3.14**

<!-- source-p 079 -->
**盖尤斯：《行省告示评注》第十二卷。**

<!-- source-p 080 -->
如果监护人在未成年人达到青春期后曾中断管理事务，即使中断时间极短，之后又恢复管理，也毫无疑问可以同时对他提起监护诉讼和事务管理之诉。

<!-- source-p 081 -->
<a id="27.3.15"></a>**27.3.15**

<!-- source-p 082 -->
**乌尔比安：《论争论》第一卷。**

<!-- source-p 083 -->
如果有人与两名监护人中的一人和解，即使双方存在共同诈欺，该和解也不使另一人受益；如此处理并非不公，因为每个人都应承担自己诈欺行为的处罚。反之，如果另一名监护人被起诉并已给付，该给付会使未被起诉者受益。虽然两人均涉及诈欺，但只要一人履行了给付义务就已足够，正如数人共同受托借用、保管或受委任时的规则一样。

<!-- source-p 084 -->
<a id="27.3.16"></a>**27.3.16**

<!-- source-p 085 -->
**乌尔比安：《告示评注》第七十四卷。**

<!-- source-p 086 -->
<a id="27.3.16.pr."></a>**序言。**如果依据要式承诺起诉监护人或为其提供担保的人，就会产生疑问：既然尚不能提起监护诉讼，是否也不能提起要式承诺之诉？多数人认为，基于同一理由，这项诉讼也应延期。

<!-- source-p 087 -->
<a id="27.3.16.1"></a>**1.**可以起诉未成年人的保佐人或成年未成年人的保佐人，即使保佐关系仍在持续。

<!-- source-p 088 -->
<a id="27.3.17"></a>**27.3.17**

<!-- source-p 089 -->
**乌尔比安：《执政官职务论》第三卷。**

<!-- source-p 090 -->
两位皇帝塞维鲁和安敦尼曾以敕答规定如下：“既然现在所询问的，正是监护人或保佐人是否欠你任何款项，那么你请求他们先行提供诉讼费用，并为此向你给付钱款，并无道理。”

<!-- source-p 091 -->
<a id="27.3.18"></a>**27.3.18**

<!-- source-p 092 -->
**帕皮尼安：《疑问集》第二十五卷。**

<!-- source-p 093 -->
监护人管理未成年人事务后，使其放弃父亲的遗产；父亲的财产因此被变卖。通常会讨论是否应将有用之诉留给未成年人，还是应交给父亲的债权人。较为可取的意见是，应在未成年人和父亲的债权人之间分配该诉权：由于监护人的行为而使遗产账目短缺的部分，应归还债权人；而监护人因诈欺或过失、使未成年人不当放弃遗产而导致的损失，则应留给未成年人。未成年人的诉权要到其达到青春期后才产生；债权人则可立即提起诉讼。

<!-- source-p 094 -->
<a id="27.3.19"></a>**27.3.19**

<!-- source-p 095 -->
**乌尔比安：《答复集》第一卷。**

<!-- source-p 096 -->
如果最后一任保佐人已确认某项债权凭据，再就该债权凭据起诉监护人便属徒劳。

<!-- source-p 097 -->
<a id="27.3.20"></a>**27.3.20**

<!-- source-p 098 -->
**帕皮尼安：《答复集》第二卷。**

<!-- source-p 099 -->
<a id="27.3.20.pr."></a>**序言。**如果一名保佐人的继承人因被判承担过高金额而获得恢复原状救济，这并不能成为对另一名保佐人重新提起诉讼的依据，仿佛该保佐人只被判承担较低金额一样；但前提是原告已不属于应获得救济的年龄。尽管如此，若基于衡平仍应提供救济，就应通过有用之诉，在另一名保佐人获减免的范围内给予救济。

<!-- source-p 100 -->
<a id="27.3.20.1"></a>**1.**监护诉讼因监护人被判承担较低金额而失败，但在未成年人年满二十五岁后、仍处于请求恢复原状的期间内，该诉讼并非当然无效，即使保佐人也因同一过失被判承担责任。因此，如果保佐人尚未履行判决，可以通过诈欺抗辩，请求将该诉权让与自己。

<!-- source-p 101 -->
<a id="27.3.21"></a>**27.3.21**

<!-- source-p 102 -->
**帕皮尼安：《定义集》第一卷。**

<!-- source-p 103 -->
未成年人在监护诉讼中将针对一名监护人的诉权让与另一名监护人，而后者被法官判令承担全部责任；即使后来作出判决，该诉权仍未消灭，因为对于承担责任的监护人所对应的份额，未成年人并非提起了监护诉讼，而只是收取了债权凭据的价款。

<!-- source-p 104 -->
<a id="27.3.22"></a>**27.3.22**

<!-- source-p 105 -->
**保罗：《疑问集》第十三卷。**

<!-- source-p 106 -->
监护人的诉讼辩护人被判承担责任，并不消除未成年人的优先权，因为未成年人并非自愿与该辩护人订约。

<!-- source-p 107 -->
<a id="27.3.23"></a>**27.3.23**

<!-- source-p 108 -->
**保罗：《答复集》第九卷。**

<!-- source-p 109 -->
如果监护人的继承人已在监护诉讼中被起诉，不应认为同一监护人的保佐人当然免责，也不应给予其既判事项抗辩；对行政官的继承人也应适用同一规则。

<!-- source-p 110 -->
<a id="27.3.24"></a>**27.3.24**

<!-- source-p 111 -->
**保罗：《意见集》第二卷。**

<!-- source-p 112 -->
如果遗嘱为尚未出生的遗腹子指定监护人，但该遗腹子最终未出生，则该人既不承担监护诉讼的责任，因为并不存在未成年人；也不承担事务管理之诉的责任，因为该人既未出生，就不能认为他管理了其事务。因此，应给予对其提起的有用之诉。

<a id="27.3.25"></a>**27.3.25**

<!-- source-p 114 -->
**赫莫革尼安努斯：《法学撮要》第五卷。**

<!-- source-p 115 -->
未成年人的财产中，不仅享有针对监护人的优先权，也享有针对代行监护事务者的优先权；如果未成年人、未成年女孩或精神失常者的保佐债务没有相应担保，也应享有该优先权。
