# D.27.4 论反向监护之诉及有用之诉（*De contraria tutelae et utili actione*）

<!-- source-p 001 -->
<a id="4"></a><a id="27.4"></a>**27.4.0. 论反向监护之诉及有用之诉。**

<!-- source-p 002 -->
<a id="27.4.1"></a>**27.4.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第三十六卷。**

<!-- source-p 004 -->
<a id="27.4.1.pr."></a>**序言。**裁判官提出并使反向监护诉讼得以适用，使监护人更容易着手管理事务，因为他们知道，未成年人也会因其管理而对自己负债。诚然，未成年人未经监护人授权并不负债，监护人也不能使未成年人就监护人自己的事务负债；但人们仍接受这样的规则：未成年人因监护人管理事务而在民法上对自己的监护人负债，当然，这种负债源于该项管理。毕竟，应当以此激励监护人，使其更愿意先行拿出自己的财物为未成年人支出，因为他们知道自己将取回所支出的款项。

<!-- source-p 005 -->
<a id="27.4.1.1"></a>**1.**本诉不仅应属于监护人，也应属于以监护人身份管理事务的人。

<!-- source-p 006 -->
<a id="27.4.1.2"></a>**2.**如果某人是未成年人、青少年、精神失常者或挥霍者的保佐人，也应当说他们可以提起反向之诉。对胎儿财产管理人的情形，也应认可同一意见。萨宾的看法是，基于相同原因，其他保佐人也应享有反向裁判之诉；这一看法应予采纳。

<!-- source-p 007 -->
<a id="27.4.1.3"></a>**3.**我们应当说，监护人只有在职责终了后才享有本诉；职责仍在持续期间，本诉尚不得提起。但如果某人以监护人身份管理事务，或者以保佐人身份管理事务，则可以立即提起本诉，因为在这种情况下，针对该管理人本人的诉讼也立即发生。

<!-- source-p 008 -->
<a id="27.4.1.4"></a>**4.**此外，如果某人因监护诉讼被起诉，可以将其为未成年人利益所作的支出列入核算。因此，由他决定是主张抵销，还是请求偿还费用。若法官未考虑其抵销主张，他能否提起反向之诉？当然可以；但如果该项核算主张已被驳回，而他又接受了这一结果，法官就不应再通过反向之诉弥补此事。

<!-- source-p 009 -->
<a id="27.4.1.5"></a>**5.**问题是，本诉是否不仅包括为未成年人或为其利益所作的支出，也包括原本应付给监护人的款项，例如未成年人的父亲欠监护人的债务。我更倾向于认为，只要监护人仍保有完整的诉权，这些款项就不应纳入反向裁判之诉。

<!-- source-p 010 -->
<a id="27.4.1.6"></a>**6.**然而，如果监护人因为自己是监护人而等待、因此没有请求清偿，该怎么办？我们应当考察，他能否通过反向监护之诉获得补偿。较可取的答案是肯定的：正如他通过反向裁判之诉可以取回自己为未成年人利益所办理的任何其他事务的费用，他也应当取回欠付自己的款项，或者取得相应担保。

<!-- source-p 011 -->
<a id="27.4.1.7"></a>**7.**我还认为，如果存在一项因期限届满而消灭的债务，也可以对其提起反向监护裁判之诉。

<!-- source-p 012 -->
<a id="27.4.1.8"></a>**8.**人们认可，即使未提起监护诉讼，也可以给予本诉。因为未成年人有时不愿提起监护诉讼，是由于并无任何款项应付给他；甚至监护人向他支出的数额超过其所受损失。不得因此妨碍监护人提起反向之诉。

<!-- source-p 013 -->
<a id="27.4.2"></a>**27.4.2**

<!-- source-p 014 -->
**尤利安：《学说汇纂》第二十一卷。**

<!-- source-p 015 -->
较之上述情形，更应当在提起账目侵吞之诉时给予该反向之诉。

<!-- source-p 016 -->
<a id="27.4.3"></a>**27.4.3**

<!-- source-p 017 -->
**乌尔比安：《告示评注》第三十六卷。**

<!-- source-p 018 -->
<a id="27.4.3.pr."></a>**序言。**那么，如果监护人为未成年人支出的数额超过其财产能力，能否请求偿还？拉贝奥写道，可以。只是应当这样理解：以这种方式管理监护事务对未成年人有利。反之，如果这对未成年人并无益处，就应说应当免除未成年人的责任；设立监护并非为了使未成年人陷入困境。因此，审理反向裁判之诉的法官应考察未成年人的利益，以及监护人是否因履行职责而作出这些支出。

<!-- source-p 019 -->
<a id="27.4.3.1"></a>**1.**还应考察，反向裁判之诉是否也可用于请求未成年人免责。没有人说，某人可以通过反向之诉请求免除其在监护诉讼中的责任；他只能就因监护事务而由自己承担的支出请求偿还。他可以取回自己支出的款项，并请求利息：利率可以是三分利率、当地通行的利率，或者他为此借款所负担的利率——如果他为了有正当理由延长未成年人的付款期限而不得不借款；也可以按其为使未成年人免责而支付的利率计算；如果未成年人因款项已经支付而获益甚多，也可以计入监护人因此未能使用该款项所受的损失。

<!-- source-p 020 -->
<a id="27.4.3.2"></a>**2.**当然，如果监护人本来应将某些款项用于放贷，却有一部分由他自己代未成年人支付，那么他既不得请求利息，也不必向未成年人支付利息。

<!-- source-p 021 -->
<a id="27.4.3.3"></a>**3.**因此，即使他曾将款项挪作己用，后来又为未成年人事务支出其中一部分，则就已支出的部分而言，不再视为挪用，因而无需就此支付利息。反过来，如果他先为未成年人事务支出款项，之后又将款项挪作己用，那么与欠付他本人的款项数额相抵的部分，就不视为他已挪用；就该数额无需支付利息。

<!-- source-p 022 -->
<a id="27.4.3.4"></a>**4.**监护人可以请求利息至何时：仅在其仍为监护人期间，还是监护关系终止后也可以请求，抑或只能请求迟延期间的利息？较可取的意见是，他可以请求利息，直至款项返还给他为止；毕竟，这笔钱不应对他毫无收益。

<!-- source-p 023 -->
<a id="27.4.3.5"></a>**5.**不过，如果未成年人的财产中有可供偿付监护人的款项，就应当说，监护人不得向未成年人请求利息。

<!-- source-p 024 -->
<a id="27.4.3.6"></a>**6.**那么，如果监护人不能从未成年人的财产中偿还自己，是因为款项已作为购置不动产之用而寄存，该怎么办？如果他没有请求裁判官准许提取该款，或者请求减少寄存数额，那就应归咎于他自己；但如果他已提出请求而未获准许，就应当说，他并不因此丧失利息。

<!-- source-p 025 -->
<a id="27.4.3.7"></a>**7.**在反向裁判之诉中，只要监护人善意并勤勉地管理了事务，即为足够，即使其管理结果不利亦然。

<!-- source-p 026 -->
<a id="27.4.3.8"></a>**8.**通过反向监护裁判之诉，也可以请求偿还在监护关系开始前或终止后为未成年人利益支出的款项，但须证明这些支出与监护期间办理的事务有关。在监护关系开始前支出的款项，如果该人曾以监护人身份管理事务、后来又被指定为监护人，或者曾任胎儿财产管理人，也应计入。即使他当时并非以监护人身份管理事务，先前的支出也应纳入；因为凡其为未成年人利益所作的支出，均可计入监护诉讼的核算，但以其善意支出为限。

<!-- source-p 027 -->
<a id="27.4.3.9"></a>**9.**显然，本诉不受时效限制；该诉既可由继承人及其他权利继受人提起，也可对继承人、其他权利继受人以及与该事项有关的人提起。

<!-- source-p 028 -->
<a id="27.4.4"></a>**27.4.4**

<!-- source-p 029 -->
**尤利安：《学说汇纂》第二十一卷。**

<!-- source-p 030 -->
被免职的监护人应视同监护关系已经终止；正如在这种情况下，他会受到诉讼追究，犹如未成年人已经达到法定成年年龄一样，他也应能通过反向裁判之诉追索自己因此承担的支出。毕竟，即使可疑监护人曾为未成年人利益支出许多款项，也不妨碍其作为可疑监护人；但不应使他因此丧失这些款项。

<!-- source-p 031 -->
<a id="27.4.5"></a>**27.4.5**

<!-- source-p 032 -->
**乌尔比安：《答复集》第一卷。**

<!-- source-p 033 -->
我答复说：监护人的继承人如果已经支付未成年人所负债务的款项，可以对未成年人提起反向之诉。

<!-- source-p 034 -->
<a id="27.4.6"></a>**27.4.6**

<!-- source-p 035 -->
**保罗：《普劳提乌斯评注》第五卷。**

<!-- source-p 036 -->
监护人如果为未成年人承担债务，在尚未清偿之前即可提起反向之诉。
