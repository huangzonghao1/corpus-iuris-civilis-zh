### <a id="27.1.31"></a>27.1.31

<!-- 源段落 200 -->
保罗《疑义集》第六卷

<!-- 源段落 201 -->
<a id="27.1.31.pr."></a>

**序言（pr.）** 某人原已管理三项监护职责，又经不同裁定被指定为两名未适婚人的监护人，本来可以申请免责；但在他提出免责事由之前，他已经管理监护事务的一名未适婚人死亡。自此，他便不再享有免责事由；先前作出的指定立即对其发生效力，仿佛应以第四项监护职责替代第三项。因为依法律，在获得免责以前，他即已是监护人。因此，可以申请免除其目前承担的第四项监护职责；但既未获免责，他就必须承担这项监护职责的负担。有人或许会提出异议，认为只有实际管理监护事务时才承担责任；但这一点只是为了说明管理职责尚未终止。若他面临因怠于履职而承担风险的可能，我认为第四项监护职责也应归责于他。

<!-- 源段落 202 -->
<a id="27.1.31.1"></a>

**1.** 若某人原已承担三项监护职责，后来依据两份遗嘱又被指定为监护人，也可能发生同样情形。此时，判断哪项监护职责先行授予，不应查看遗嘱何时开启，而应查看何时接受遗产或条件何时成就。

<!-- 源段落 203 -->
<a id="27.1.31.2"></a>

**2.** 前述监护职责还存在另一差异：若授予第三项和第四项监护职责，即使他先被要求承担第四项监护职责，对第四项职责，自其被命令管理之日起承担风险；对第三项职责，则自被指定之日起承担风险。

<!-- 源段落 204 -->
<a id="27.1.31.3"></a>

**3.** 我曾认为，若某人使未适婚人不承受父亲遗产，就应视为其已卸下原有职责，而将他留在第四项监护职责中。

<!-- 源段落 205 -->
<a id="27.1.31.4"></a>

**4.** 另一方面，若某项监护职责范围广、事务繁重，足以相当于数项职责，我认为裁判官可以正确地将这一项视为足以构成免责事由。因此，数名共同继承的兄弟不应被视为数名未适婚人；若并非兄弟但共有同一财产、且须以同一方式制作并提交账目，也不应视为数项职责。相反，若兄弟各自分有财产，则构成两项监护职责。正如我所说，应当考虑的是账目的编制和提交有多困难，而不是未适婚人的人数。

### <a id="27.1.32"></a>27.1.32

<!-- 源段落 207 -->
保罗《疑义集》第七卷

<!-- 源段落 208 -->
内森尼乌斯·阿波利纳里斯致尤利乌斯·保罗：“一位母亲将自己的未适婚儿子，或任何外人将另一名与其无关的未适婚人，指定为继承人；又将遗赠给予提提乌斯，并指定提提乌斯担任该未适婚人的监护人。提提乌斯经确认后申请免责。我询问：他是否会丧失遗赠？又若遗嘱未指定提提乌斯为监护人，但他仍接受遗赠，后来由裁判官指定其为监护人，而他申请免责，是否同样应剥夺其遗赠？若监护人由父亲指定，或由已脱离家父权的未适婚人指定，或者由适婚但未满二十五岁者指定保佐人，是否有区别？”

我答复：“父亲指定某人为监护人或保佐人，若该指定不合法，而该人经裁判官确认后选择行使免责特权，则应剥夺其遗赠；我们的斯凯沃拉也持此意见。因为裁判官确认其担任监护人时，应遵循死者的意思。母亲的遗嘱也应如此处理。任何将未适婚人指定为继承人并希望通过指定监护人照料他的人，都与母亲相似；我们抚养的门生也属此类。因此，正确的意见是：拒绝遗嘱人所遗留的负担者，应被排除在其所请求取得、且正是同一遗嘱人所给予的遗赠之外。不过，我并不认为凡拒绝承担监护负担的人都应被剥夺遗赠；只有在显然可见遗赠是因为遗嘱人将子女的监护职责一并交付给他才作出的情况下，才应如此，而非遗嘱人即使未指定其担任监护人也会给予该遗赠。若遗嘱中先写明遗赠，之后又在附遗嘱中指定其为监护人，就可能表明这一点；在此情形中，可以认为遗赠并非因遗嘱人希望受遗赠人担任监护人而给予。”

### <a id="27.1.36"></a>27.1.36

<!-- 源段落 219 -->
保罗《答复集》第九卷

<!-- 源段落 220 -->
<a id="27.1.36.pr."></a>

**序言（pr.）** 父母通常会为子女选择最亲近、最可信赖的人担任监护人，并且常以遗赠酬谢他们，促使其承担监护职责。但题述之人在遗嘱中获得遗赠，并被指定为未适婚人的替补继承人；不大可能认为遗嘱人只有在他同时承担监护职责时，才希望指定他为替补继承人。因此，若未适婚人仍在世，题述之人原本应被排除在遗赠之外；但不应将其排除在替补继承之外，因为即使他已承担监护职责，发生替补继承时，该职责也会终止。

<!-- 源段落 221 -->
<a id="27.1.36.1"></a>

**1.** 卢基乌斯·提提乌斯有三个仍健在的儿子，其中一人已脱离家父权，且已到应指定保佐人的年龄。我询问：若这名脱离家父权的儿子请求法院指定父亲为自己的保佐人，父亲能否援引公法特权，并仍以有三个儿子为由申请豁免？我答复：不应剥夺父亲因子女数量而享有的利益。但在请求为自己儿子指定保佐人的情形下，父亲若试图援引此项免责事由，便违背了自然亲情。

<!-- 源段落 222 -->
### <a id="27.1.37"></a>27.1.37

<!-- 源段落 223 -->
斯凯沃拉《答复集》第二卷

<!-- 源段落 224 -->
<a id="27.1.37.pr."></a>

**序言（pr.）** 一名遗嘱指定的监护人向裁判官表示自己有三个子女；此外，他还称，某未适婚人已有父亲的兄弟作为法定监护人，因此指定他担任监护人有误。裁判官作出如下裁定：“若你被指定为已有法定监护人的人的监护人，你无须申请免责。”我询问：既然实际上并无叔父担任该未适婚人的监护人，此人是否仍继续担任监护人？我答复：依所陈述的事实，尽管他有正当免责事由，仍不能认为已经免责，因为裁判官的宣告存在错误。

<!-- 源段落 225 -->
<a id="27.1.37.1"></a>

**1.** 我又询问：若他接受该裁判，是否应仅因未管理监护事务而对其给予准诉权？我答复：若他停止管理，是出于错误，相信自己已凭所主张的“三子女权利”获得免责，而非出于恶意，则不应给予准诉权。

<!-- 源段落 226 -->
### <a id="27.1.38"></a>27.1.38

只有在提出免责事由的阶段，才适用五十日的期间；至于办理相关事务，自被指定之日起规定连续四个月的期间。

<!-- 源段落 232 -->
### <a id="27.1.40"></a>27.1.40

<!-- 源段落 233 -->
保罗《判例集》第二卷

<!-- 源段落 234 -->
<a id="27.1.40.pr."></a>

**序言（pr.）** 承担监护职责后，监护人若失明、失聪、失语、精神错乱或患病，可以辞去监护职责。

<!-- 源段落 235 -->
<a id="27.1.40.1"></a>

**1.** 贫困若使某人无力承担监护职责的工作及负担，通常可以成为豁免的理由。

<!-- 源段落 236 -->
### <a id="27.1.41"></a>27.1.41

<!-- 源段落 237 -->
赫尔莫革尼安《法律摘要》第二卷

<!-- 源段落 238 -->
<a id="27.1.41.pr."></a>

**序言（pr.）** 经皇帝特许而管理皇帝事务的人，即使未持有书面任命，在管理期间也可免除监护和保佐职责。

<!-- 源段落 239 -->
<a id="27.1.41.1"></a>

**1.** 担任粮食供应长官或夜间巡逻长官者，同样适用这一规则。

<!-- 源段落 240 -->
<a id="27.1.41.2"></a>

**2.** 因公务而随同离任或出发者，只要人数未超过规定名额，就可免除在其离任期间或即将出发时授予的监护职责；但不得辞去此前已经承担的监护职责。
<!-- 源段落 241 -->
<a id="27.1.41.3"></a>

**3.** 因所属团体或社团的法律地位而获得豁免的人，不能因此免除对其同僚子女所负的监护职责；但特定授予此项特权的人除外。

<!-- 源段落 242 -->

监护人不必承担距离罗马城一百罗马里以外的同僚子女的监护职责。

### <a id="27.1.43"></a>27.1.43

<!-- 源段落 246 -->
赫尔莫革尼安《法律摘要》第二卷

<!-- 源段落 247 -->
担任元老子女监护人的释奴，不得免除其他监护职责。

<!-- 源段落 248 -->
### <a id="27.1.44"></a>27.1.44

<!-- 源段落 249 -->
特里福尼努《论争议问题》第二卷

<!-- 源段落 250 -->
<a id="27.1.44.pr."></a>

**序言（pr.）** 根据神圣马尔库斯皇帝的敕令，自由民若被指定为释奴的监护人，应当申请免责。我们的皇帝与其父神圣塞维鲁皇帝曾以敕答规定，取得佩戴金戒指权利的人也享有同一免责事由。

<!-- 源段落 251 -->
<a id="27.1.44.1"></a>

**1.** 因此，若自由民被指定为享有佩戴金戒指权利的释奴未适婚人的监护人或保佐人，由于双方身份不同，其免责申请不应获准。

<!-- 源段落 252 -->
<a id="27.1.44.2"></a>

**2.** 但若卢基乌斯·提提乌斯在未适婚人或未满二十五岁的青年取得佩戴金戒指的权利之前，已被指定为监护人，并以自由民身份申请免责，则该人取得此项特许后，可以再次被指定为同一人的监护人或保佐人。这与如下规则相同：某人因公共事务缺席而在离任后一年内获得免责；该期限经过后，仍可将其重新指定到原来的位置。

<!-- 源段落 253 -->
<a id="27.1.44.3"></a>

**3.** 尽管为元老庇护人管理事务的释奴可以免除其他监护职责，但取得佩戴金戒指权利、并由此进入自由民阶层的人，不能援用此项免责。

<!-- 源段落 254 -->
### <a id="27.1.45"></a>27.1.45

<!-- 源段落 255 -->
特里福尼努《论争议问题》第十三卷

<!-- 源段落 256 -->
<a id="27.1.45.pr."></a>

**序言（pr.）** “提提乌斯担任我儿子的监护人，直至他因公共事务离任为止。”提提乌斯依遗嘱承担监护职责，之后因公共事务开始缺席，后来结束公务并返回。现在能否因他再次受命担任监护人而准许其以公务缺席为由免责？还是因为遗嘱上的指定先于其公务缺席，且他已经开始管理监护事务，所以不应免责？若他在此期间又有了子女，或具备其他免责事由，又该如何？较可取的意见是，这仍属于同一项监护职责；因此他既不能因此取得免责，也不能就此前期间提起监护之诉。

<!-- 源段落 257 -->
<a id="27.1.45.1"></a>

**1.** 但若遗嘱这样写道：“提提乌斯担任监护人；因公共事务离任期间，不得担任监护人；返回后，恢复担任监护人”，则应讨论其能否因公务缺席或之后出现的其他事由申请免责。首先还涉及另一问题：遗嘱指定某人自某日起或在某条件成就时担任监护人，他是否必须在该日期或条件成就之前申请免责？尤其是，申请免责的五十日期限是否已经开始计算？正确的意见是，在日期到来之前，他尚非监护人；这正如遗产尚未被接受前的情形。因此，若同一遗嘱下他已经管理过监护事务，且曾因公务缺席；在其返回后，他便立即继续承担此前已接受的监护职责，即使尚未满一年亦然。但本案中，他依据遗嘱已不再是监护人，故可以针对第二次监护职责申请免责。〔底本作 *ante suspectis*，此处依语义暂读为 *ante susceptis*〕

<!-- 源段落 258 -->
<a id="27.1.45.2"></a>

**2.** 若裁判官为精神失常者、哑者或胎儿指定保佐人，该保佐人可以援引子女数目作为免责事由。

<!-- 源段落 259 -->
<a id="27.1.45.3"></a>

**3.** 所谓在罗马指定的监护人，仅指由城市长官或裁判官指定者，或者依在罗马或其毗连地区订立的遗嘱所指定者。

<!-- 源段落 260 -->
<a id="27.1.45.4"></a>

**4.** 若释奴因身体或精神疾病严重到无法处理事务，甚至不足以料理自己的事务，就应顾及现实必要性，不可强加其无法履行的监护职责；否则将使未适婚人遭受不便，并有损其利益。

<!-- 源段落 261 -->
### <a id="27.1.46"></a>27.1.46

<!-- 源段落 262 -->
保罗《论审判程序》单卷

**序言（pr.）** 面包师公会成员可以免除监护职责，但前提是他们亲自经营面包坊；我认为，只有在该公会规定名额以内的人才能免责。

<!-- 源段落 264 -->
<a id="27.1.46.1"></a>

**1.** 罗马城内的面包师还可免除对其同僚子女的监护职责。

<!-- 源段落 265 -->
<a id="27.1.46.2"></a>

**2.** 若某人主张自己在受指定担任监护人的地方没有住所，也属于免责事由；安敦尼努斯皇帝与其神圣父皇曾对此作出说明。
