# <a id="9"></a><a id="27.9"></a>27.9.0 论受监护人或受保佐人的财产未经裁定不得处分或设定质押

<!-- 源段落 002 -->
### <a id="27.9.1"></a>27.9.1

<!-- 源段落 003 -->
乌尔比安《评告示》第三十五卷

<!-- 源段落 004 -->
<a id="27.9.1.pr."></a>

**序言（pr.）** 塞维鲁皇帝在元老院演说中禁止监护人和保佐人出售农地或城郊地产。

<!-- 源段落 005 -->
<a id="27.9.1.1"></a>

**1.** 该演说于特尔图鲁斯和克莱门斯担任执政官之年六月十三日，在元老院宣读；其内容如下：

<!-- 源段落 006 -->
<a id="27.9.1.2"></a>

**2. 拉丁原文：**

> *Praeterea, patres conscripti, interdicam tutoribus et curatoribus, ne praedia rustica vel suburbana distrahant, nisi ut id fieret, parentes testamento vel codicilllis caverint. Quod si forte aes alienum tantum erit, ut ex rebus ceteris non possit exsolvi, tunc praetor urbanus vir clarissimus adeatur, qui pro sua religione aestimet, quae possunt alienari obligarive debeant, manente pupillo actione, si postea potuerit probari obreptum esse praetori. Si communis res erit et socius ad divisionem provocet, aut si creditor, qui pignori agrum a parente pupilli acceperit, ius exsequetur, nihil novandum censeo.*

**译文：** “此外，元老们，我将禁止监护人和保佐人出售农地或城郊地产，除非父母已在遗嘱或附遗嘱中规定可以这样做。若债务确实数额巨大，无法以其他财产清偿，则应请求杰出人士、罗马城裁判官处理，由其依其审慎判断，决定哪些财产可以处分或设定质押；但若日后能够证明裁判官受到了欺骗，未适婚人仍保有诉权。若财产为共有，且共有人请求分割；或者债权人已从未适婚人的父亲处取得土地质押并行使其权利，我认为不应改变现状。”

<!-- 源段落 007 -->
<a id="27.9.1.3"></a>

**3.** 若死者生前曾将财物列为待售，但未在遗嘱中规定可以出售，则应停止出售；因为某人生前曾出售财物，并不当然意味着他希望死后也出售该物。

<!-- 源段落 008 -->
<a id="27.9.1.4"></a>

**4.** 未满二十五岁者购买地产，并约定在价款付清前以该地产为出卖人设定质押的，我认为质押无效；因为未成年人一旦取得所有权，该地产便不能再被设定质押。

<!-- 源段落 009 -->
### <a id="27.9.2"></a>27.9.2

<!-- 源段落 010 -->
保罗《论神圣塞维鲁皇帝演说》单卷

<!-- 源段落 011 -->
但此处似乎有一点值得斟酌：质权是随所有权一并取得的，且自始即附着于该地产。若买受人从国库购得地产，毫无疑问，质权仍然有效。因此，若私人出卖人处发生同类情形，就需要皇帝的特许，以便通过敕答确认质权。

<!-- 源段落 012 -->
### <a id="27.9.3"></a>27.9.3

<!-- 源段落 013 -->
乌尔比安《评告示》第三十五卷

<!-- 源段落 014 -->
<a id="27.9.3.pr."></a>

**序言（pr.）** 若以一名未适婚人的钱款为另一名未适婚人购买地产，并将地产交付给该未适婚人或未满二十五岁者，出资的未适婚人能否取得质权？较妥当的意见是，依照我们皇帝及其神圣父皇的敕令，应保全出资购买地产的未适婚人所享有的质权。

<!-- 源段落 015 -->
<a id="27.9.3.1"></a>

**1.** 经市政官员、省长官或其他有权机关命令，可以对未适婚人的地产设定质权并予以出售。裁判官也可以命令将未适婚人的财产交付占有，并由此成立质权；无论这是为了保全遗赠，还是为了避免尚未发生的损害，均可命令占有该财产。此类债务或处分之所以有效，是因为其并非出于监护人或保佐人的意思，而是依据官员的权力作出。

<!-- 源段落 016 -->
<a id="27.9.3.2"></a>

**2.** 还可以询问：若有人对未适婚人的地产提起返还之诉，而监护人未返还该地产，是否因提出诉讼标的估价并支付相应金额而发生处分效力？较妥当的意见是会发生该效力，因为此种处分并非监护人自愿作出。

<!-- 源段落 017 -->
<a id="27.9.3.3"></a>

**3.** 若有人对原属未适婚人的地产提起诉讼，而判决对未适婚人不利，监护人遂将地产返还，也应作同样处理；此处的处分因既判力而有效。

<!-- 源段落 018 -->
<a id="27.9.3.4"></a>

**4.** 若未适婚人享有 *emphyteutikon* 或 *embateutikon* 权利，应考察监护人能否出售该权利。较妥当的意见是不得出售，尽管该权利更接近地产本身的权利。

<!-- 源段落 019 -->
<a id="27.9.3.5"></a>

**5.** 用益权也不得转让，即使未适婚人仅享有用益权，亦是如此。若监护人导致用益权因未行使而消灭，是否也不应允许？显然，应当恢复该权利。若未适婚人享有所有权，也不得转让其用益权或使用权，尽管元老院演说未提及用益权。以同样理由，未适婚人或青少年的土地上不得设定役权，也不得免除既存役权；嫁资土地亦适用此规则。

<!-- 源段落 020 -->
<a id="27.9.3.6"></a>

**6.** 若未适婚人拥有采石场或其他矿场，用于开采 *stypteriae* 或其他矿物，或者拥有黏土矿、银矿或类似设施，

<!-- 源段落 022 -->
保罗《论神圣塞维鲁皇帝演说》单卷

<!-- 源段落 023 -->
但是，私人可以拥有的此类设施：

<!-- 源段落 024 -->
### <a id="27.9.5"></a>27.9.5


<!-- 源段落 025 -->
乌尔比安《评告示》第三十五卷

<!-- 源段落 026 -->
<a id="27.9.5.pr."></a>

**序言（pr.）** 我认为，依该演说的旨意，处分行为应当受到禁止。

<!-- 源段落 027 -->
<a id="27.9.5.1"></a>

**1.** 若未适婚人拥有盐场，也应作同样处理。

<!-- 源段落 028 -->
<a id="27.9.5.2"></a>

**2.** 若未适婚人善意占有其从他人处购买的地产，我认为监护人不得处分该地产。底本接称：“因为……这项出售有效。”〔原文：*ea enim, quae quasi pupillaris vero distractus est, venditio valet.* 语句有疑，所指及论证关系未明。〕

<!-- 源段落 029 -->
<a id="27.9.5.3"></a>

**3.** 若地产已质押给未适婚人，监护人能否出售？因为他们出售的似乎是债务人的地产，也就是他人所有的地产。但若未适婚人或其父亲已取得裁定，准许其依所有权占有该地产，便应认为监护人不得出售，因为该地产应视为未适婚人的地产。若其依据避免尚未发生损害的程序而获准占有，也应作同样处理。

<!-- 源段落 030 -->
<a id="27.9.5.4"></a>

**4.** 若未适婚人作为继承人，将一处地产遗赠或以遗嘱信托方式留给塞尤斯，监护人能否未经裁判官许可而返还该地产？我认为，若遗赠的是死者自己的财物，则该演说不适用；若处分的是未适婚人的财物，则应认为该演说适用，未经裁判官许可不得处分。

<!-- 源段落 031 -->
<a id="27.9.5.5"></a>

**5.** 若未适婚人向要式口约的相对人作出承诺，未经裁判官许可，他能否清偿？较妥当的意见是不能；否则便会找到规避禁止处分的途径。

<!-- 源段落 032 -->
<a id="27.9.5.6"></a>

**6.** 但若父亲曾向要式口约的相对人承诺交付地产，而未适婚人继受该项口约债务，则更有理由认为，他可以未经裁判官许可而履行该债务。若未适婚人依法定继承继受了另一名负有该债务之人的地位，也应作同样处理。

<!-- 源段落 033 -->
<a id="27.9.5.7"></a>

**7.** 依同一理由，若父母或未适婚人所继受的其他人已经出售地产，也可以认为未适婚人能够在未经裁判官许可的情况下完成买卖的其余事项。

<!-- 源段落 034 -->
<a id="27.9.5.8"></a>

**8.** 未适婚人未经裁判官许可，不得拒绝接受遗赠的地产；既然该地产属于未适婚人的财物，此种拒绝也构成处分，这一点毫无疑问。

<!-- 源段落 035 -->
<a id="27.9.5.9"></a>

**9.** 不应允许监护人随意以存在债务为由出售地产；法律并未授予他们一般处分地产的权力。因此，元老院将此事的裁量权交给裁判官；裁判官的职责首先是查明，能否通过其他途径取得资金以减少债务。他应调查未适婚人是否持有现金、可以追索的债权、已收取的收益，或者预期收入与其他收益。他还应调查，除地产以外是否存在其他可以出售、并可用所得价款清偿债务的财物。若查明只有出售地产才能清偿债务，且债权人催促清偿，或者利息数额足以促使人偿还债务，才可准许出售。

<!-- 源段落 036 -->
<a id="27.9.5.10"></a>

**10.** 裁判官还应判断，是准许出售还是设定质押；并须审慎确保以地产设定质押所收取的利息，不超过清偿债务所需的数额。裁判官也可以决定出售地产，以免仅因数额不大的债务而出售大片地产；若另有面积较小或对未适婚人较不重要的地产，应优先命令出售该地产，而非面积较大且更有价值的地产。

<!-- 源段落 037 -->
<a id="27.9.5.11"></a>

**11.** 因此，每当有人请求裁判官准许出售财产时，裁判官首先应询问一名能够说明未适婚人财产状况的人，不应过于相信监护人或保佐人；他们有时会为谋取私利，向裁判官断言必须出售或设定质押。裁判官应询问未适婚人的近亲、父母、可信赖的释奴，或其他了解其财产状况的人。若找不到任何人，或找到的人有嫌疑，就应命令提出账目及未适婚人财产概况，并为未适婚人指定律师，由律师协助裁判官审慎判断是否应准许出售或设定质押。

<!-- 源段落 038 -->
<a id="27.9.5.12"></a>

**12.** 可以询问：若有人请求裁判官准许出售位于行省的地产，该许可是否有效？我认为有效，但前提是监护职责在罗马进行，且这些监护人也承担了管理该地产的职责。

<!-- 源段落 039 -->
<a id="27.9.5.13"></a>

**13.** 为避免监护人仅仅声称存在债务，便滥用借入的款项，裁判官应确保所借款项实际用于偿还债权人，并应对此作出裁定，同时派遣传令官，要求其报告款项确已用于申请处分或设定质押时所称的目的。

<!-- 源段落 040 -->
<a id="27.9.5.14"></a>

**14.** 即使不存在债务，监护人仍可能主张出售这些地产有利，可以用所得款项购买其他地产，或者干脆处置现有地产。应考察裁判官能否准许他们这样做。较妥当的意见是不能：裁判官并未获得自由裁量权，可以任意处分未适婚人的财产；只有债务迫近时才可准许。因此，若裁判官在未查明债务的情况下仍准许处分，就应认为买卖及裁定均无效。裁判官并未被授予随意命令出售地产的权力；只有债务迫在眉睫时才可如此。

<!-- 源段落 041 -->
<a id="27.9.5.15"></a>

**15.** 若日后能够证明裁判官受到了欺骗，未适婚人仍保有诉权。应考察应给予他对物诉权还是对人诉权。较妥当的意见是应给予对物诉权；其诉权不应仅限于对监护人或保佐人提起对人诉讼。

<!-- 源段落 042 -->
<a id="27.9.5.16"></a>

**16.** 我们所说的共有地产，是指按未分割份额共有的地产（*pro indiviso*）。若各共有人的份额已经分割（*pro diviso*），则该演说不适用，应依裁判官裁定处理。

### <a id="27.9.7"></a>27.9.7

<!-- 源段落 047 -->
乌尔比安《评告示》第三十五卷

<!-- 源段落 048 -->
<a id="27.9.7.pr."></a>

**序言（pr.）** 若不同监护人管理的未适婚人共有地产，应考察能否处分该地产。由于必须提出异议，我认为处分应受到阻止：任何一名监护人都不能单独提出异议，而应由二人共同提出。若这些未适婚人由同一监护人管理，则更应认为处分受阻。

<!-- 源段落 049 -->
<a id="27.9.7.1"></a>

**1.** 若未适婚人经裁判官许可设定质押，能否阻止处分，仍有疑问。但应认为债权人可以行使其权利；不过，若先向裁判官申请许可，则做法更为稳妥。

<!-- 源段落 050 -->
<a id="27.9.7.2"></a>

**2.** 若父亲或其他尊亲属是其子女中某人的监护人，而他希望为地产设定质押，是否应先请求裁判官许可？较妥当的意见是应当请求；但裁判官应更倾向于同意父亲的申请。

<!-- 源段落 051 -->
<a id="27.9.7.3"></a>

**3.** 若裁判官准许监护人出售地产，但监护人反而设定质押，或者相反，已经实施的行为是否有效？我的意见是，监护人所为若不同于裁判官裁定准许的行为，就不发生效力。

<!-- 源段落 052 -->
<a id="27.9.7.4"></a>

**4.** 若裁判官裁定：“准许出售或设定质押”，监护人能否自行选择？较妥当的意见是可以；但应当知道，裁判官并未妥善履行其职责，因为他本应亲自决定并选择究竟准许设定质押还是出售。

<!-- 源段落 053 -->
<a id="27.9.7.5"></a>

**5.** 监护人未经裁定为财物设定质押的，尽管质押无效，仍可适用恶意抗辩；但仅限于监护人已将借入的款项支付给原先以该物为担保的债权人时。

<!-- 源段落 054 -->
<a id="27.9.7.6"></a>

**6.** 还应考察，监护人能否为该物设定质押。应当认为，若所借本金数额相同，利息又未提高，则后续质押有效，原债权人的权利转移给后来的债权人。


<!-- 源段落 055 -->
### <a id="27.9.8"></a>27.9.8

<!-- 源段落 056 -->
乌尔比安《论各类审判机关》第二卷

<!-- 源段落 057 -->
<a id="27.9.8.pr."></a>

**序言（pr.）** 某些人既非依法当然成为监护人，也非依法成为保佐人，只是以监护人或保佐人身份管理事务；毫无疑问，他们不得处分未适婚人或青少年的财物。

<!-- 源段落 058 -->
<a id="27.9.8.1"></a>

**1.** 若某人是精神错乱者或其他非青少年的保佐人，应考察买卖究竟依旧法有效，还是也适用该演说。我认为，由于皇帝在演说中谈到未适婚人，且保佐人与监护人并列提及，该规则应予适用；我还认为，根据该演说的旨意，对其他人也应作同样处理。

<!-- 源段落 059 -->
<a id="27.9.8.2"></a>

**2.** 有人询问共有财物能否设定质押；我认为，未经裁定不得设定质押。因为演说规定的例外，仅适用于终止共有关系，而非增加共有关系中的困难。

<!-- 源段落 060 -->

前任省长官曾裁定，可以出售某些地产；未适婚人的监护人将另一买受人的姓名写在表面上，实际却为自己购买。若继任者查明该监护人欺诈行事，违反元老院决议及受托诚信，则应判断是否应将这一狡诈伎俩作为典型予以惩处，以及惩处到何种程度。

### <a id="27.9.10"></a>27.9.10

<!-- 源段落 064 -->
乌尔比安《意见集》第六卷

<!-- 源段落 065 -->
未适婚人或青少年的地产在元老院决议颁布后被违法出售，若已在监护之诉或准诉中由法官估定价额，且该价额已经支付，则基于公平，不应准许对该地产提起返还所有物之诉。

<!-- 源段落 066 -->
### <a id="27.9.11"></a>27.9.11

<!-- 源段落 067 -->
乌尔比安《论前总督的职务》第三卷

<!-- 源段落 068 -->
若有人请求出售未满二十五岁者的地产，行省长官应在查明事实后决定是否准许。若保佐人希望出售精神错乱者、挥霍者或其他任何人的地产，也应遵守同一规则。

<!-- 源段落 069 -->
### <a id="27.9.12"></a>27.9.12

<!-- 源段落 070 -->
马尔基安《论抵押诉式》单卷

<!-- 源段落 071 -->
若某人的监护人为未适婚人父亲的债权人清偿债务，从而代位取得该债权人的地位，则不违反元老院决议。

### <a id="27.9.13"></a>27.9.13

<!-- 源段落 073 -->
保罗《论神圣塞维鲁皇帝演说》单卷

<!-- 源段落 074 -->
<a id="27.9.13.pr."></a>

**序言（pr.）** 若某地产贫瘠、多石或受疫病侵害，应考察是否仍不得出售。安敦尼努斯皇帝及其神圣父皇曾以如下文字作出敕答：

**拉丁原文：**

> *Quod allegastis infructuosum esse fundum, quem vendere vultis, movere nos non potest, cum utique pro fructuum modo pretium inventurus sit.*

**译文：** “你们所称拟出售的地产毫无收益，不能使我们改变看法；该地产仍会依其收益状况取得相应价款。”

<!-- 源段落 075 -->
<a id="27.9.13.1"></a>

**1.** 尽管监护人不得处分或设定质押于未适婚人的地产，帕皮尼安在《答复集》第五卷中仍说：监护人未经裁判官裁定，不得依法出售未适婚人的地产。但他说，若监护人因错误而出售了地产，并将所得价款支付给未适婚人的父亲的债权人；此后，所有权人请求返还地产及孳息时，若其未提出价款以及期间利息，而其他财产又不足以清偿债务，则可以对其提出恶意抗辩。我另作如下评注：即使债务本可清偿，若其他财产足以保全，且可用其价款清偿债务，仍应认为恶意抗辩可以阻却返还请求；否则，未适婚人便会从他人所受损害中获利。

<!-- 源段落 076 -->
### <a id="27.9.14"></a>27.9.14

<!-- 源段落 077 -->
保罗《答复集》第九卷

<!-- 源段落 078 -->
保罗答复：即使后来发现父亲的遗嘱无效，只要未适婚人的监护人或该未适婚人（儿子）的保佐人是依照遗嘱所载死者意思出售了农地，就不应认为他们违反了神圣皇帝的演说。
