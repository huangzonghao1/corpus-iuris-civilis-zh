# D.19.4 论物之互易

<!-- source-p 001; 原文导航锚点 4、题名锚点 19.4 -->
<a id="4"></a><a id="19.4"></a>**19.4.0. 论物之互易（*De rerum permutatione*）**

<!-- source-p 002 -->
<a id="19.4.1"></a>**19.4.1**

<!-- source-p 003 -->
**保罗：《告示评注》第三十二卷。**

<!-- source-p 004 -->
<a id="19.4.1.pr."></a>**序言。**出售不同于购买，买受人不同于出卖人；同样，价款也不同于商品。但在互易中，无法辨别谁是买受人、谁是出卖人，而双方承担的义务有很大差异。买受人若未使金钱归受领人所有，就须承担买受之诉的责任；出卖人只须就标的被追夺承担责任、交付占有并无恶意欺诈。因此，若标的未被追夺，他便不负其他责任。但在互易中，若双方给付之物都被视为价款，则双方均须使各自给付物的所有权归于对方；若双方给付之物都被视为商品，则双方均无须转移所有权。然而，既然买卖必须同时有标的物和价款，互易便不能构成买卖，因为无法辨别二者之中何者是商品、何者是价款；理性也不允许同一物既是被出售的商品，又是购买该商品的价款。

<!-- source-p 005 -->
<a id="19.4.1.1"></a>**1.**因此，若我所收受或交付的物后来被他人依法追夺，答复认为应给予一项以事实为基础的诉讼。

<!-- source-p 006 -->
<a id="19.4.1.2"></a>**2.**此外，买卖仅凭当事人一致的意思即可订立；互易则须一方交付标的，才开始产生债务。否则，我们就会说，仅凭合意也能成立债务；但这只适用于具有特定名称的契约，例如买卖、租赁和委任。

<!-- source-p 007 -->
<a id="19.4.1.3"></a>**3.**因此，佩迪乌斯说，交付他人之物的人并未成立互易契约。

<!-- source-p 008 -->
<a id="19.4.1.4"></a>**4.**因此，若一方已经交付，而另一方拒绝交付，我们提起诉讼，并非请求返还已经交付给我们的物，而是请求赔偿未能取得约定之物所造成的利益损失。不过，若要请求对方返还交付给我们的物，则可以提起返还之诉，理由是约定的给付并未实现。

<!-- source-p 009 -->
<a id="19.4.2"></a>**19.4.2**

<!-- source-p 010 -->
**保罗：《普劳提乌斯评注》第五卷。**

<!-- source-p 011 -->
阿里斯托说，由于互易接近买卖，基于互易交付的奴隶也应保证身体健康、无盗窃或致害责任负担，并且不是逃亡奴隶。
