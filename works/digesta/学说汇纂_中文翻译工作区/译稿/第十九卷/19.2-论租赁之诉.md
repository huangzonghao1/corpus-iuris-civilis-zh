# D.19.2 论租赁之诉

<!-- source-p 001; 原文导航锚点 2、题名锚点 19.2 -->
<a id="2"></a><a id="19.2"></a>**19.2.0. 论租赁（*Locati conducti*）**

<!-- source-p 002 -->
<a id="19.2.1"></a>**19.2.1**

<!-- source-p 003 -->
**保罗：《告示评注》第三十四卷。**

<!-- source-p 004 -->
租赁是自然法上的、为各民族共同采用的契约；与买卖一样，它并非以言辞，而是以合意订立。

<!-- source-p 005 -->
<a id="19.2.2"></a>**19.2.2**

<!-- source-p 006 -->
**盖尤斯：《日常事务》（又称《金篇》）第二卷。**

<!-- source-p 007 -->
<a id="19.2.2.pr."></a>**序言。**租赁与买卖最为相近，并受相同法律规则支配：买卖在价款达成合意时订立；同样，租赁也在租金达成合意时成立。

<!-- source-p 008 -->
<a id="19.2.2.1"></a>**1.**买卖与租赁彼此如此相近，以至于有些情形常会引起疑问：究竟是买卖，还是租赁？例如，我若与金匠约定由他用自己的黄金为我制作一定重量、一定样式的戒指，并向他支付三百，那么这是买卖还是租赁？但通说认为这是一项单一交易，且更应认定为买卖。反之，若我提供黄金，并约定以一定报酬支付其劳务，那么毫无疑问，这是租赁。

<!-- source-p 009 -->
<a id="19.2.3"></a>**19.2.3**

<!-- source-p 010 -->
**庞波尼乌斯：《萨宾评注》第九卷。**

<!-- source-p 011 -->
出租农庄时，若佃户同时按估价接收农庄经营用具，普罗库鲁斯说，双方的意思是让佃户将这些用具作为买得之物持有；估价物作为嫁资交付时，也作同样处理。

<!-- source-p 012 -->
<a id="19.2.4"></a>**19.2.4**

<!-- source-p 013 -->
**庞波尼乌斯：《萨宾评注》第十六卷。**

<!-- source-p 014 -->
若租赁或以恳请方式交付使用的约定是持续至出租人或交付人愿意为止，那么，该约定因作出出租或交付之人的死亡而终止。

<!-- source-p 015 -->
<a id="19.2.5"></a>**19.2.5**

<!-- source-p 016 -->
**乌尔比安：《告示评注》第二十八卷。**

<!-- source-p 017 -->
若我把住所租给你，之后又免除租金，就应提起出租人之诉或承租人之诉。

<!-- source-p 018 -->
<a id="19.2.6"></a>**19.2.6**

<!-- source-p 019 -->
**盖尤斯：《行省告示评注》第十卷。**

<!-- source-p 020 -->
承租人无须返还其就租赁物提起盗窃之诉而获得的赔偿。

<!-- source-p 021 -->
<a id="19.2.7"></a>**19.2.7**

<!-- source-p 022 -->
**保罗：《告示评注》第三十二卷。**

<!-- source-p 023 -->
若我以五十将他人的公寓楼租给你，而你又以六十将同一公寓楼转租给提提乌斯；此后提提乌斯被所有人禁止居住，那么你对我提起承租人之诉时，应当可以请求六十，因为你自己对提提乌斯负有六十的责任。

<!-- source-p 024 -->
<a id="19.2.8"></a>**19.2.8**

<!-- source-p 025 -->
**特里丰尼努斯：《论辩》第九卷。**

<!-- source-p 026 -->
我们还应考察：所应赔偿的是否既非六十，也非五十，而应是因不能享有租赁物使用利益所造成的损失；中间出租人所能取得的金额，也应等于他须向自己的承租人赔偿的金额。因为，将租赁所带来的利益与较高租金相比较，会使判决金额增加。不过，第一位出租人仍可扣除五十；若公寓楼所有人没有禁止最后一位承租人居住，他本可从中间出租人处收取该五十。我们现行法采取这一规则。

<!-- source-p 027 -->
<a id="19.2.9"></a>**19.2.9**

<!-- source-p 028 -->
**乌尔比安：《告示评注》第三十二卷。**

<!-- source-p 029 -->
<a id="19.2.9.pr."></a>**序言。**若有人将其善意买得的房屋或农庄租给我，而该物随后被他人依法追夺，且这并非出于出租人的恶意或过失，庞波尼乌斯说，出租人仍须依承租人之诉承担责任，确保承租人能够享有其所租用之物。不过，若所有人不允许承租人使用，而出租人愿意提供另一处同样便利的住所，那么免除出租人的责任最为公平。

<!-- source-p 030 -->
<a id="19.2.9.1"></a>**1.**此处还可以补充马尔凯卢斯在《学说汇纂》第六卷中的论述：用益权人将农庄出租五年后死亡，其继承人不负有确保承租人继续享用农庄的责任；正如公寓楼烧毁时，出租人也不再对承租人负此责任。但承租人是否仍须按其实际享用的期间支付相应租金？马尔凯卢斯提出疑问，正如他租用了用益权人奴隶的劳务或住所时是否应支付相应租金一样。他更倾向于认为承租人应当支付；这也最为公平。他又问，承租人若以为自己能享用农庄五年而为农庄支出费用，能否取回这些费用？他说不能，因为承租人应预见到这种情形可能发生。然而，如果出租人并非以用益权人的身份，而是以农庄所有人的身份出租呢？显然，他应承担责任，因为他欺骗了承租人；安敦尼皇帝与神圣塞维鲁皇帝的复诏也如此规定。复诏还规定，建筑物烧毁时，应支付房屋仍然存在期间的租金。

<!-- source-p 031 -->
<a id="19.2.9.2"></a>**2.**尤利安在《学说汇纂》第十五卷中说，若有人出租农庄时约定，即使发生不可抗力，相关损失也由承租人承担，就应遵守该约定。

<!-- source-p 032 -->
<a id="19.2.9.3"></a>**3.**若出租农庄时约定佃户可以使用不会造成损害的火，并已将此约定告知佃户，那么，若意外事故引发火灾，出租人不承担风险；若损害是由出租人的过失造成，而出租人依法须对此负责，则出租人应承担责任。

<!-- source-p 033 -->
<a id="19.2.9.4"></a>**4.**安敦尼皇帝与其父亲曾就某人租用的羊群被盗一事作出如下复诏：“若能通过出租人之诉证明，盗贼是在你并无欺诈的情况下赶走山羊的，那么你无须承担意外损失；并且，对于此后期间支付的租金，你可以作为不当给付请求返还。”

<!-- source-p 034 -->
<a id="19.2.9.5"></a>**5.**塞尔苏斯在《学说汇纂》第八卷中还写道，缺乏专业技能也应计入过失：若有人承租照料牛犊，或承接修补、抛光等工作，他应对过失负责；因不熟练而犯错，也属于过失。因为，正如他所说，此人是以专业工匠的身份承揽工作的。

<!-- source-p 035 -->
<a id="19.2.9.6"></a>**6.**若你把他人的房屋租给我，而该房屋后来遗赠或赠与给我，我不必再因租金向你承担出租人之诉的责任。不过，对于过去的期间仍须考察：若在遗赠生效日以前有租金到期未付，我认为仍须支付：

<!-- source-p 036 -->
<a id="19.2.10"></a>**19.2.10**

<!-- source-p 037 -->
**尤利安：《致费罗克斯书》。**

<!-- source-p 038 -->
我也可以正当地对你提起承租人之诉，包括请求使我免于该项租赁义务。

<!-- source-p 039 -->
<a id="19.2.11"></a>**19.2.11**

<!-- source-p 040 -->
**乌尔比安：《告示评注》第三十二卷。**

<!-- source-p 041 -->
<a id="19.2.11.pr."></a>**序言。**我们应当考察，承租人是否还须对奴隶以及由其带入的人所犯的过失负责？其责任范围如何？他是应以交出奴隶以免除自己责任，还是以自己的名义承担责任？对于他带入的人，承租人是否只须承受针对这些人的诉讼后果，还是还须像对自己的过失一样承担责任？我认为，即使没有特别约定，只要承租人在挑选带入的人时有过失——例如带入此类奴隶或客人——他就应以自己的名义对这些人的过失负责。庞波尼乌斯在《告示评注》第六十三卷中也认可这一意见。

<!-- source-p 042 -->
<a id="19.2.11.1"></a>**1.**若租赁约定写明“不得生火”，而承租人仍生了火，即使意外事故因此引发火灾，他也须承担责任，因为他本不应生火。允许使用无害之火是另一回事：这只允许使用火，而不是使用会造成损害的火。

<!-- source-p 043 -->
<a id="19.2.11.2"></a>**2.**承租人还应注意，不得使租赁物的法律权利或实体状况变差，也不得放任他人造成这种结果。

<!-- source-p 044 -->
<a id="19.2.11.3"></a>**3.**有人承租运输坎帕尼亚的葡萄酒，后因第三人提出争议，将酒放入仓库，并在酒上加盖自己和另一人的印章。除非承租人没有过失，否则他须依承租人之诉向出租人返还不受争议的葡萄酒占有。

<!-- source-p 045 -->
<a id="19.2.11.4"></a>**4.**承租人与出租人约定，不得在城市别墅内堆放干草；承租人仍堆放了干草，后来其奴隶点火将干草烧毁。拉贝奥说，承租人须依承租人之诉承担责任，因为他违反租赁约定堆放干草，造成了火灾的原因。

<!-- source-p 046 -->
<a id="19.2.12"></a>**19.2.12**

<!-- source-p 047 -->
**赫尔莫革尼安：《法律摘要》第二卷。**

<!-- source-p 048 -->
即使是任何第三人纵火，损失也应在出租人之诉中予以考虑。

<!-- source-p 049 -->
<a id="19.2.13"></a>**19.2.13**

<!-- source-p 050 -->
**乌尔比安：《告示评注》第三十二卷。**

<!-- source-p 051 -->
<a id="19.2.13.pr."></a>**序言。**另有疑问：若马车夫（即驾驶轻便马车者）为了抢在他人之前通行而倾覆了轻便马车，使奴隶受伤或死亡，应如何处理？我认为可对他提起出租人之诉，因为他本应谨慎驾驶；此外，还可提起有益的阿奎利亚之诉。

<!-- source-p 052 -->
<a id="19.2.13.1"></a>**1.**若船主承揽将货物运往明图尔奈，因该船无法驶入明图尔奈河，便将货物转装至另一艘船，而该船在河口沉没，那么第一位船主是否承担责任？拉贝奥说，若他没有过失，就不承担责任；但如果他违背货主意愿行事、在不应转运的时间转运，或转装到不适航的船上，则可对他提起出租人之诉。

<!-- source-p 053 -->
<a id="19.2.13.2"></a>**2.**若船长未配备舵手便将船驶入河中，风暴发生后又无法控制船只，最终导致船只灭失，乘客可以对他提起出租人之诉。

<!-- source-p 054 -->
<a id="19.2.13.3"></a>**3.**若有人承租训练一名奴隶，却带他远行，结果奴隶被敌人俘获或死亡，通说认为可以提起出租人之诉；但若承租时已约定将奴隶带往国外，则不在此列。

<!-- source-p 055 -->
<a id="19.2.13.4"></a>**4.**尤利安在《学说汇纂》第八十六卷中还写道：若鞋匠因男孩做工不够好，用鞋楦猛烈击打男孩颈部，致使男孩失去一只眼睛，男孩的父亲可以提起出租人之诉。虽然允许教师轻微惩戒，但鞋匠显然超过了限度；关于阿奎利亚法之诉，我们此前也已论述。尤利安否认可以提起侮辱之诉，因为鞋匠并非出于侮辱故意，而是为了教训男孩。

<!-- source-p 056 -->
<a id="19.2.13.5"></a>**5.**若宝石交付他人镶嵌或雕刻，却发生破裂：若因材料本身有瑕疵而破裂，不得提起出租人之诉；若因工匠缺乏技能而破裂，则可以提起。还应补充一点：若工匠也承受了风险，即使破裂是由材料瑕疵造成，也可以提起出租人之诉。

<!-- source-p 057 -->
<a id="19.2.13.6"></a>**6.**若漂洗工接收衣物准备熨烫，却被老鼠咬坏，他须承担出租人之诉的责任，因为他本应防范此事。若漂洗工将斗篷调换，把别人的衣物交给他人，即使是不知情所为，也须依出租人之诉承担责任。

<!-- source-p 058 -->
<a id="19.2.13.7"></a>**7.**军队到来时，承租人迁离住所；随后士兵拆走住所的窗户及其他物品。若承租人未通知房主便迁离，他须承担出租人之诉的责任。拉贝奥说，若承租人本可阻止士兵而没有阻止，也应负责；这一意见是正确的。但若承租人无法通知房主，我认为他不承担责任。

<!-- source-p 059 -->
<a id="19.2.13.8"></a>**8.**有人出租度量器具，行政官命令将其毁坏。若度量器具确有不准确，萨宾区分承租人是否知情：承租人知情的，可以提起出租人之诉；不知情的，则不可以。若度量器具准确，只有在行政官因承租人的过失而下令毁坏时，承租人才承担责任。拉贝奥和梅拉也这样写道。

<!-- source-p 060 -->
<a id="19.2.13.9"></a>**9.**租赁关系中可以有两名对全部义务承担责任的当事人。

<!-- source-p 061 -->
<a id="19.2.13.10"></a>**10.**若工程租赁约定，工程未在指定日期完成时可以另行委托他人完成，那么，只有在确依同一约定将工程另行委托他人后，先前的承揽人才须承担出租人之诉的责任；并且，在工程完成期限届满之前，不得另行委托。

<!-- source-p 062 -->
<a id="19.2.13.11"></a>**11.**承租期限届满后仍继续承租的人，不仅被视为续租，质物也被认为继续承担担保责任。但只有在原租赁中没有第三人为他提供质物时，这一规则才成立；若曾有第三人提供质物，就需要该人重新同意。公共土地的租赁也适用同一规则。我们说双方保持沉默时，佃户被视为续租，应理解为：仅在双方沉默的当年，视为续订同一租赁；此后的年份则不当然如此，即使最初约定了一个五年租期也是如此。但是，五年租期届满后，若第二年双方也没有采取相反行动，就应认为该年度租赁仍然延续；因为双方当年的沉默本身表明同意。此后每一年均依此处理。城市房产则适用另一规则：承租人居住多久，就在相应期间承担义务，除非书面约定了明确的租赁期限。

<!-- source-p 063 -->
<a id="19.2.14"></a>**19.2.14**

<!-- source-p 064 -->
**乌尔比安：《告示评注》第七十一卷。**

<!-- source-p 065 -->
承租人在确定期限届满后仍可继续作为佃户；因为只要所有人容许佃户继续留在农庄，就应理解为重新出租。此类契约不必然要求使用特定言辞或书面形式，仅凭合意即可成立。因此，若在此期间所有人开始精神失常或死亡，马尔凯卢斯说，租赁不可能重新成立；这一看法是正确的。

<!-- source-p 066 -->
<a id="19.2.15"></a>**19.2.15**

<!-- source-p 067 -->
**乌尔比安：《告示评注》第三十二卷。**

<!-- source-p 068 -->
<a id="19.2.15.pr."></a>**序言。**承租人享有承租人之诉。

<!-- source-p 069 -->
<a id="19.2.15.1"></a>**1.**通常在以下情形可以提起该诉：例如，承租人不能享用其所租之物（可能是整块土地或其中一部分的占有未交付，或房屋、马厩等未予修缮，或未提供其畜群应当停放的场所）；又或者，租赁约定了某项义务而出租人未予履行。遇此情形，可以提起承租人之诉。

<!-- source-p 070 -->
<a id="19.2.15.2"></a>**2.**若发生严重的风暴灾害，我们要考察出租人是否应向承租人承担某种责任。塞尔维乌斯说，所有无法抵御的力量均应由土地所有人对佃户承担，例如河水泛滥、寒鸦、椋鸟等造成的损害，或敌军入侵。但若土地本身产生瑕疵，则损失应由佃户承担，例如葡萄酒变酸，或谷物被野草、杂草损坏。若发生山体滑坡并毁掉全部收成，损失也不应由佃户承担，否则他除了损失种子，还须支付土地租金。若橄榄果因霉病受损，或因异常炎热而遭受损害，损失应由所有人承担；若没有发生超出常态的情况，损失则由佃户承担。过路军队任意拿走东西的，也应作同样处理。若土地因地震而塌陷，以至于不复存在，损失应由所有人承担；因为出租人必须向承租人提供土地，使其能够享用。

<!-- source-p 071 -->
<a id="19.2.15.3"></a>**3.**有人以农庄发生火灾为由请求减免租金，皇帝作出如下复诏：“若你曾耕种该农庄，那么因突发火灾而给予你救济，并非不合理。”

<!-- source-p 072 -->
<a id="19.2.15.4"></a>**4.**帕比尼安在《答复》第四卷中说，若出租人因某一年收成歉薄而减免佃户租金，而后续年份收成丰盛，该减免并不使出租人受损；即使对已减免租金的那一年，也可以请求支付全额租金。他对公税损失也作出相同答复。若出租人以“赠与”为名，因某年歉收而减免租金，也应作同样处理，因为这不是赠与，而是和解。不过，若出租人减免租金的那一年恰好是租期最后一年，情况如何？更妥当的意见是：即使此前年份收成丰盛，且出租人对此知情，也不应将那些年份纳入结算。

<!-- source-p 073 -->
<a id="19.2.15.5"></a>**5.**神圣安敦尼皇帝的复诏记载，有人抱怨收成太少，但该项因素不应予以考虑。另一份复诏也记载：“你提出了一个新请求：以葡萄园年久为由，要求减免租金。”

<!-- source-p 074 -->
<a id="19.2.15.6"></a>**6.**另有一人丢失船只后，有人向他追讨其以借款名义收取的运费。安敦尼皇帝复诏说，凯撒的代理人向他追讨运费并非不合理，因为他并未履行运输职责；这一规则对所有人均应同样适用。

<!-- source-p 075 -->
<a id="19.2.15.7"></a>**7.**但是，在基于上述原因准许减免时，承租人取得的并非其所遭受损失的赔偿，而只是按比例免除租金；前文已经说明，种子的损失应由佃户承担。

<!-- source-p 076 -->
<a id="19.2.15.8"></a>**8.**当然，若所有人不允许承租人享用租赁物，无论是所有人亲自出租，还是他人以代理人身份出租他人的物、或以所有人的身份出租他人的物，均应赔偿承租人的利益损失。普罗库鲁斯就代理人出租的情形作过此种答复。

<!-- source-p 077 -->
<a id="19.2.15.9"></a>**9.**尤利安在《学说汇纂》第十五卷中写道，有时可以提起出租人之诉，以使当事人摆脱租赁关系。例如，我将农庄租给提提乌斯；他指定一名未成年人为继承人后死亡。监护人决定让该未成年人放弃继承，我便以更高价格将农庄另租他人；此后，该未成年人恢复对其父亲遗产的权利。该未成年人依承租人之诉所能取得的，不会超过免除其租赁义务；因为我有正当理由另行出租，〔底本此段至此中断，原句未完〕

<a id="19.2.19"></a>**19.2.19**

<!-- source-p 088 -->
**乌尔比安《评告示》第三十二卷**

<!-- source-p 089 -->
<a id="19.2.19.pr."></a>**序言（pr.）** 但还应在尤利安的意见中补充：如果我与监护人串通，我应依承租之诉，在未成年人所受损害的范围内承担责任。

<!-- source-p 090 -->
<a id="19.2.19.1"></a>**1.** 如果某人不知桶有瑕疵而将其出租，之后酒漏失，他仍应就利害关系承担责任，不能以不知情为由免责；卡西乌斯也是这样写的。若出租的是一片牧场，牧场上长有有害牧草，情形则不同：如果牲畜因此死亡或状况变差，出租人若知情，应赔偿损失；若不知情，则不得请求租金。这是塞尔维乌斯、拉贝奥和萨宾努斯的意见。

<!-- source-p 091 -->
<a id="19.2.19.2"></a>**2.** 还须考察，土地出租人通常应向承租人提供哪些农具；若未提供，出租人应依出租之诉承担何种责任。涅拉提乌斯致阿里斯托的书信指出，出租人至少应提供配备绳索的酒桶、榨机和橄榄压榨机；若未提供，就应由土地所有人备齐。榨机若有损坏，也应由土地所有人修理；但若因佃农的过失而损坏其中任何一件，佃农应依出租之诉承担责任。涅拉提乌斯写道，用来压榨橄榄的压榨垫应由佃农自备；若以压杆压榨橄榄，则土地所有人应备好榨机、绞盘、压杆、横木以及抬升榨机所用的螺旋器具。土地所有人还应提供用热水清洗橄榄的锅，以及其他橄榄加工器具；与酒桶相同，供当季使用的酒桶则应由佃农涂沥青。以上规则均以双方未另作特别约定为前提。

<!-- source-p 092 -->
<a id="19.2.19.3"></a>**3.** 如果土地所有人在租赁合同中保留一项权利，即按约定价格收取一定数量的谷物；后来却不肯收取谷物，也不肯从租金中扣除相应金额，那么他固然可以通过出租之诉请求全部租金，但裁判官依职权仍应考虑：承租人以谷物而非金钱履行该保留部分，对其有何利害关系。若提起承租之诉，也应作同样处理。

<!-- source-p 093 -->
<a id="19.2.19.4"></a>**4.** 如果房客为房屋加装了门或其他设施，可以提起何种诉讼？拉贝奥所写更为正确：房客可以提起承租之诉，请求允许其拆除这些设施；但须就可能发生的损害提供担保，确保其拆除时不会使房屋状况恶化，并使房屋恢复原状。

<!-- source-p 094 -->
<a id="19.2.19.5"></a>**5.** 如果房客将一只带有铜箍的箱子搬进房屋，房屋所有人却堵窄了房屋入口，那么无论其知情与否，房屋所有人均应依承租之诉及展示之诉承担责任。裁判官依职权应命令其向房客提供通道和搬走箱子的机会；相关费用当然由出租人承担。

<!-- source-p 095 -->
<a id="19.2.19.6"></a>**6.** 某人租住一年并预付了全年租金；六个月后，该公寓楼倒塌或被火焚毁。梅拉写道，承租人可依承租之诉请求返还剩余期间的租金，这一意见最为妥当；他并非以误付为由提起返还诉，而是因为这笔款项是为租赁关系而支付的。与此不同，若某人议定租金为十，却支付了十五：如果他误以为议定金额是十五而支付，则不能提起承租之诉，只能提起返还诉。误付者与预付整笔租金者，二者大不相同。

<!-- source-p 096 -->
<a id="19.2.19.7"></a>**7.** 某人租船运送一名女子，之后婴儿在船上出生。应认定婴儿无须另付运费，因为其运送成本不高，也没有使用航海者所需的那些设备。

<!-- source-p 097 -->
<a id="19.2.19.8"></a>**8.** 承租之诉显然也可以由继承人提起。

<!-- source-p 098 -->
<a id="19.2.19.9"></a>**9.** 一名速记员出租自己的劳务，之后雇用其劳务的人去世。安托尼努斯皇帝与神圣塞维鲁皇帝就该速记员的请愿书作出如下答复：“既然你陈述说，未能向安东尼乌斯·阿奎拉支付已约定的劳务报酬并非你的原因，而且你在同一年没有从他人处取得报酬，那么履行合同义务才是公平的。”

<!-- source-p 099 -->
<a id="19.2.19.10"></a>**10.** 帕比尼安在《答复》第四卷中也写道，凯撒的使节去世后，应向其随从支付剩余期间的薪酬，但以这些随从在同一期间未为他人服务为限。

**保罗《评告示》第三十四卷**

<!-- source-p 119 -->
<a id="19.2.24.pr."></a>**序言（pr.）** 如果租赁条款规定，工作是否合格由土地所有人自行判断，其效果应与规定由善良之人判断相同；若约定由任何其他人判断，也应如此。诚信要求作出符合善良之人标准的判断。该判断涉及工作的质量，不涉及延长合同约定的工期，除非合同明确作此规定。因此，若承租人以欺诈方式取得验收，验收即属无效，出租人可以提起出租之诉。

<!-- source-p 120 -->
<a id="19.2.24.1"></a>**1.** 佃农将土地转租后，后手承租人的财物不对土地所有人承担物上责任；但其收获物仍处于质押状态，正如这些收获物由第一位佃农收取时一样。

<!-- source-p 121 -->
<a id="19.2.24.2"></a>**2.** 房屋或土地以五年为期、按期支付租金而出租时，如果佃农或房客弃置房屋或停止耕作，土地所有人可以立即对其提起诉讼。

<!-- source-p 122 -->
<a id="19.2.24.3"></a>**3.** 对于本应在特定日期完成的义务，例如完成某项工作或进行嫁接，也可以同样提起诉讼。

<!-- source-p 123 -->
<a id="19.2.24.4"></a>**4.** 如果佃农不能享用土地，即使土地所有人在其余年份允许其使用，佃农仍可立即就整个五年期间提起诉讼；土地所有人并不总能因为第二年或第三年曾允许使用土地而免责。被逐出土地、另行承租其他农场的人，既不能同时耕作两处土地，也不再负有支付原租金的义务；他还可以请求其每年本可获得的收益。土地所有人迟至佃农已被其他事务牵绊、不能再享用土地时才表示愿意允许其使用，已为时过晚。若土地所有人只在数日内阻止使用，之后改变主意，使佃农仍能完整享用土地，则这数日的迟延不会减少其义务。凡出租人或其能够制止的第三人违反约定，未向承租人提供约定的使用利益，承租人也可提起有用之承租诉。

<!-- source-p 124 -->
<a id="19.2.24.5"></a>**5.** 某人将土地出租多年，并在遗嘱中命令继承人解除承租人的租赁关系。如果继承人不允许承租人在剩余期间继续使用土地，承租人可以提起承租之诉；若继承人允许其继续使用却不免除租金，则应依遗嘱承担责任。

<a id="19.2.25"></a>**19.2.25**

<!-- source-p 126 -->
**盖尤斯《评行省告示》第十卷**

<!-- source-p 127 -->
<a id="19.2.25.pr."></a>**序言（pr.）** 如果约定的租金笼统地交由第三人决定，就不能认为租赁合同已经成立。但如果约定由提图斯评定租金，合同便附有条件：只要被指定的人确定租金，就必须依其评定支付租金，租赁合同也随之生效；如果他不愿或不能确定租金，则租赁合同视为没有成立，仿佛双方未约定租金。

<!-- source-p 128 -->
<a id="19.2.25.1"></a>**1.** 某人将土地出租供他人使用，或将房屋出租供他人居住，之后因某种原因出售土地或房屋，应确保买受人仍按同一约定允许佃农使用土地或房客居住；否则，受阻者可以对其提起承租之诉。

<!-- source-p 129 -->
<a id="19.2.25.2"></a>**2.** 邻人建造房屋，遮挡了楼上房间的采光，出租人应对房客承担责任。毫无疑问，佃农或房客可以解除租赁。若出租人请求租金，也应考虑承租人已经解除合同这一事实。出租人不修复损坏严重的门窗时，也适用同一规则。

<!-- source-p 130 -->
<a id="19.2.25.3"></a>**3.** 承租人必须依租赁条款行事。首先，佃农应按适当时节完成农事，不得因耕作失时而使土地状况恶化；此外，还应妥善照料农庄建筑，使其保持完好。

<!-- source-p 131 -->
<a id="19.2.25.4"></a>**4.** 如果邻人因承租人结怨而砍伐树木，也应将此归责于承租人自身的过失。

<!-- source-p 132 -->
<a id="19.2.25.5"></a>**5.** 承租人自己砍伐树木时，不仅应依出租之诉承担责任，还应依《阿奎利亚法》以及《十二表法》关于秘密砍伐树木的诉权，并受 *quod vi aut clam* 禁令拘束。不过，审理出租之诉的法官依职权应令土地所有人放弃其他诉权。

<!-- source-p 133 -->
<a id="19.2.25.6"></a>**6.** 重大不可抗力——希腊人称为 *veou bian*〔原文转写，意为“神的力量”〕——若使收成遭受超过可容忍程度的损害，不应由承租人承担；否则，佃农应平静承受轻微损失，因为他也不会被剥夺超额收益。显然，这里说的是按固定金额承租土地的佃农；分成佃农则依类似合伙的关系，与土地所有人共同分担损失并分享收益。

<!-- source-p 134 -->
<a id="19.2.25.7"></a>**7.** 某人承揽运输一根柱子，若柱子在吊起、搬运或放置时折断，只有在承揽人或其雇用之人的过失导致折断时，他才承担风险。若已采取最谨慎之人通常会采取的一切措施，即不存在过失。有人承揽运输酒桶、木梁或其他物品时，也适用同一规则。

<!-- source-p 135 -->
<a id="19.2.25.8"></a>**8.** 如果洗衣工或衣物修补匠遗失衣物，并已就此向物主作出赔偿，物主必须将对盗窃者的所有物返还诉和返还之诉权利转让给他。

<!-- source-p 159 -->
**阿尔费努《学说汇纂》第五卷，经保罗摘要**

<!-- source-p 160 -->

<a id="19.2.54.pr."></a>**序言（pr.）** 我问：租赁债务的保证人是否也须就逾期未付租金承担利息？规定为替他人支付金钱者仅须承担本金损失的敕令，对其是否有利？保罗答复：如果保证人保证了承租关系中的全部责任，那么依佃农迟延支付租金时承担责任的规则，保证人也应就佃农迟延支付租金承担利息。在诚信诉讼中，利息虽非严格基于债务约定，而是由法官依职权加以判给，但保证人既然为全部承租责任提供担保，让其也承担利息负担似属公平，仿佛他曾作出如下保证：“凡依诚信原则应判令债务人承担的金额，你是否均以保证承担？”或者：“你是否保证使我免受损失？”

<!-- source-p 236 -->
<a id="19.2.54.1"></a>**1.** 土地出租人与承租人约定：在租期内，不得违背承租人塞尤斯的意愿将其逐出土地；若将其驱逐，出租人提图斯应向承租人塞尤斯支付十的罚金。双方还互相约定：若塞尤斯想在租期内离开土地，也应向出租人提图斯支付同额罚金。我问：塞尤斯连续两年未付租金，是否可以在不承担罚金的情况下将其驱逐？保罗答复：虽然罚金要式口约中没有明确提到支付租金这一条件，但看来双方约定在规定期限内不得驱逐佃农，前提是其已支付租金并按要求耕种。因此，如果未支付租金的一方开始请求罚金，出租人可以提出诈欺抗辩。

<!-- source-p 237 -->
<a id="19.2.54.2"></a>**2.** 保罗答复说，估价后交由女佃农使用并登记在其名下的奴隶，其风险由女佃农承担；因此，该奴隶死亡后，女佃农的继承人应支付相应估价。

<a id="19.2.57"></a>**19.2.57**

<!-- source-p 247 -->
**雅沃勒努《拉贝奥后论》第九卷**

<!-- source-p 248 -->
某人拥有一所房屋，将与之相连的一块地出租给近邻。近邻在自己的土地上建造房屋时，把土堆积在该地块上，堆积高度超过出租人砌筑的基础。持续降雨使土堆被水浸透，水分渗入出租人墙体，最终导致房屋倒塌。拉贝奥说，只能提起出租之诉。因为造成损害的并非堆土行为本身，而是其后由堆土引起的潮湿。损害不法之诉针对的是直接造成损害的行为，而非另有外因介入后才造成损害的情形。我赞同这一意见。

<!-- source-p 249 -->
<a id="19.2.58"></a>**19.2.58**

<!-- source-p 250 -->
**拉贝奥《后论》第四卷，经雅沃勒努摘要**

<!-- source-p 251 -->
<a id="19.2.58.pr."></a>**序言（pr.）** 你以一个总价出租整栋公寓楼，之后又将其出售，并约定房客租金归买受人。即使承租人以更高租金转租，买受人取得的仍只是承租人应向你支付的租金。

<!-- source-p 252 -->
<a id="19.2.58.1"></a>**1.** 工程租赁中未约定工程应于何日完成，但承揽人承诺，若届时未完成，应支付相当于出租人利害关系的金额。我认为，该项债务应以善良之人对所需工期的判断为限，因为显然双方的意思是：应在合理可行的时间内完成工程。

<!-- source-p 253 -->
<a id="19.2.58.2"></a>**2.** 某人在市镇承租公共浴场，每年租金为二十钱币；双方还约定向其提供一百钱币，用于修缮炉灶、管道及类似设施。承租人请求支付这一百钱币。我认为，只有在其提供担保，保证该款用于修缮这些设施时，才应向其支付。

<a id="19.2.59"></a>**19.2.59**

<!-- source-p 255 -->
**雅沃勒努《拉贝奥后论》第五卷**

<!-- source-p 256 -->
马尔基乌斯承揽为弗拉库斯建造房屋。工程完成一部分后，建筑因地震而震动受损。马苏里乌斯·萨宾努斯说，如果这是由地震等自然力量造成的，风险由弗拉库斯承担。

<!-- source-p 257 -->
<a id="19.2.60"></a>**19.2.60**

<!-- source-p 258 -->
**拉贝奥《后论》第五卷，经雅沃勒努摘要**

<!-- source-p 259 -->
<a id="19.2.60.pr."></a>**序言（pr.）** 房屋租期为数年时，出租人应确保承租人不仅可以从每年相应的月初起居住，还可以在其适当的时候将房屋转租给房客。因此，如果房屋从一月初起便一直搭着支撑架，直至六月初仍未拆除，致使任何人既不能居住，也不能向他人展示，那么承租人无须向出租人支付任何租金；即使房屋在七月初修缮完毕，也不能强迫承租人入住，除非出租人愿意提供一处适宜居住的房屋。

<!-- source-p 260 -->
<a id="19.2.60.1"></a>**1.** 我认为，佃农的继承人虽然不是佃农，对土地所有人而言仍是占有人。

<!-- source-p 261 -->
<a id="19.2.60.2"></a>**2.** 洗衣工遗失了你的衣服，你有可追索之人，却不愿向其追偿；你仍可依出租之诉起诉洗衣工。不过，法官应判断你是否可以向盗窃者起诉，并由洗衣工承担费用取回自己的财物。如果法官认定此举对你不可能，则应判令洗衣工向你赔偿，但同时强制你将对盗窃者的诉权转让给洗衣工。

<!-- source-p 262 -->
<a id="19.2.60.3"></a>**3.** 房屋依书面条款出租建造，工程是否验收由出租人或其继承人决定。承揽人依出租人的意思变更了部分工程。我答复说，该工程虽然没有依书面条款完成，但既然是依出租人的意思变更，承揽人就应免责。

<!-- source-p 263 -->
<a id="19.2.60.4"></a>**4.** 我委托你估算建造别墅所需费用；你报告说需二百。于是我按确定报酬将工程交由你承揽，之后才发现建造该别墅至少需三百。我已给你一百，你支出其中一部分后，我命令你停止施工。我说，如果你仍继续施工，我将依出租之诉起诉你，要求你返还余款。

<!-- source-p 264 -->
<a id="19.2.60.5"></a>**5.** 佃农查看收成时，你明知谷物属于他人却将其拿走。拉贝奥说，所有人可以通过返还之诉向你请求该谷物；为实现此请求，佃农可以依承租之诉对土地所有人起诉。

<!-- source-p 265 -->
<a id="19.2.60.6"></a>**6.** 仓库出租人曾公告，不对存入的黄金、白银和珍珠承担风险。后来他明知有人存入这些物品，却仍允许其存放。我说，出租人因此仍对你承担责任；既然他允许存入，原先的公告就视为撤回。

<!-- source-p 266 -->
<a id="19.2.60.7"></a>**7.** 你承租了我的奴隶，让他替你赶骡子；由于他的疏忽，你的骡子死亡。如果奴隶是自行出租劳务，我认为，他仅以其特有产及用于你事务的财产承担赔偿；如果是我把他出租给你，我对你的责任不超过我本人的故意和过失。但如果你向我承租的是一名未指明身份的赶骡人，而我把那名奴隶交给你，其疏忽导致牲畜死亡，那么我也应对选任该人时的过失负责，因为是我选择了一个会使你遭受此类损失的人。

<!-- source-p 267 -->
<a id="19.2.60.8"></a>**8.** 你承租了一辆车，以便运载货物并与你同行。车辆过桥时，该桥的承包人向驾车人收取通行费。问题是，是否也应仅就车辆本身缴纳通行费？我认为，如果赶车人在出租车辆时知道车辆将经过该桥，就应由赶车人承担费用。

<!-- source-p 268 -->
<a id="19.2.60.9"></a>**9.** 我认为，整个仓库的出租人无须向仓库管理人承担仓库管理人应对承租人承担的财物保管责任，除非出租时另有约定。

<a id="19.2.61"></a>**19.2.61**

<!-- source-p 270 -->
**谢沃拉《学说汇纂》第七卷**

<!-- source-p 271 -->
<a id="19.2.61.pr."></a>**序言（pr.）** 租赁条款中未约定佃农须种植葡萄，但佃农仍在土地上栽种了葡萄藤；因这些葡萄藤带来的收益，土地年租金增加了十余枚金币。问题是，土地所有人将佃农逐出并请求欠付租金时，佃农能否提出诈欺抗辩，将种植葡萄藤所作的有益支出计入？答复说，佃农要么可以取回其支出，要么无须再支付更多。

<!-- source-p 272 -->
<a id="19.2.61.1"></a>**1.** 某人以确定运费承租一艘船，约定从昔兰尼加行省驶往阿奎莱亚，船上装载三千量桶橄榄油和八千摩底谷物。可是船只在装货后仍被留在该行省达九个月，所装货物又因发生没收事由而被取走。问题是，船主能否依租赁合同向承租人请求约定运费？答复说，根据所陈述的情形，可以请求。

<a id="19.2.62"></a>**19.2.62**

<!-- source-p 274 -->
**拉贝奥《可信论》第一卷**

<!-- source-p 275 -->
如果你承揽开凿一条沟渠并已完成，但在业主验收之前，工程因滑坡而毁坏，风险由你承担。保罗说：不对；如果毁坏是土地本身的瑕疵所致，风险由出租人承担；如果是工程本身的瑕疵所致，损失才由承揽人承担。
