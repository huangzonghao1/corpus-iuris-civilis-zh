# D.19.3 论估价之诉

<!-- source-p 001; 原文导航锚点 3、题名锚点 19.3 -->
<a id="3"></a><a id="19.3"></a>**19.3.0. 论估价之诉（*De aestimatoria*）**

<!-- source-p 002 -->
<a id="19.3.1"></a>**19.3.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第三十二卷。**

<!-- source-p 004 -->
<a id="19.3.1.pr."></a>**序言。**设立估价之诉，旨在消除疑义。因为，将按估价交付的物品交由他人出售时，人们曾对此存有较大争议：究竟应因该估价提起出卖之诉，还是提起出租之诉，仿佛我把该物交付给对方出售；抑或提起承租之诉，仿佛我雇用了对方的劳务；又或者提起委任之诉。因而，较妥当的做法是设立这一诉讼：凡对某一契约的名称有所疑问，但仍认为应当给予某种诉权时，就应给予以特定事实为基础的估价之诉。因为这是一项依市民法实施的交易，而且是诚信交易。因此，我们在论述诚信诉讼时所说的一切规则，在此也都适用。

<!-- source-p 005 -->
<a id="19.3.1.1"></a>**1.**估价使承受该物者负担风险：因此，他要么应将该物完好无损地返还，要么应支付约定的估价。
