# D.19.1 论买受之诉与出卖之诉

<!-- source-p 001; 原文导航锚点 1、题名锚点 19.1 -->
<a id="1"></a><a id="19.1"></a>**19.1.0. 论买受之诉与出卖之诉（*De actionibus empti venditi*）**

<!-- source-p 002 -->
<a id="19.1.1"></a>**19.1.1**

<!-- source-p 003 -->
**乌尔比安：《萨宾评注》第二十八卷。**

<!-- source-p 004 -->
<a id="19.1.1.pr."></a>**序言。**出卖人未交付出售之物时，可以起诉请求赔偿利益损失，即买受人因未能取得该物所受的损失。如果买受人的利益损失高于该物的价值或买价，赔偿额有时也会超过该物的价值或买价。

<!-- source-p 005 -->
<a id="19.1.1.1"></a>**1.**出卖人明知某项地役权存在却加以隐瞒，而买受人对此不知情的，仍须承担买受之诉的责任，即使出卖人曾承诺双倍赔偿亦然；凡违背诚信的行为，均可在买受之诉中审理。所谓出卖人明知而隐瞒，不仅包括未提醒买受人，也包括买受人询问时否认该地役权存在。即使出卖人声称：“当然不存在任何地役权；但若意外出现地役权，我不承担责任”，我认为仍应由其承担买受之诉的责任，因为地役权确实存在，而且出卖人知情。若出卖人设法使买受人无法发现地役权，我认为也应承担责任。总之，出卖人若以不正当方式隐瞒地役权，就应负责；但若其只是为了保障自身，不应因此承担责任。以上结论以买受人不知道地役权为前提，因为明知者谈不上被隐瞒；已经知情者也无须再被告知。

<!-- source-p 006 -->
<a id="19.1.2"></a>**19.1.2**

<!-- source-p 007 -->
**保罗：《萨宾评注》第五卷。**

<!-- source-p 008 -->
<a id="19.1.2.pr."></a>**序言。**买卖中约定了数量或面积而出卖人未予交付的，买受人享有买受之诉。

<!-- source-p 009 -->
<a id="19.1.2.1"></a>**1.**如果他人基于遗赠或信托的执行而占有该物，或者债权人占有该物，便不能认为已经向买受人交付了无负担的占有。胎儿利益的保全而取得占有时，也应作同样处理；“无负担”这一称谓也包括这种情形。

<!-- source-p 010 -->
<a id="19.1.3"></a>**19.1.3**

<!-- source-p 011 -->
**庞波尼乌斯：《萨宾评注》第九卷。**

<!-- source-p 012 -->
<a id="19.1.3.pr."></a>**序言。**出卖人应当交付的占有，应达到这样的程度：如果他人依法将占有从买受人处夺回，就不应视为已经完成占有交付。

<!-- source-p 013 -->
<a id="19.1.3.1"></a>**1.**买受人虽约定由出卖人交付无负担的占有，并依口约之诉起诉，但该诉讼不包括孳息。因为约定交付农庄的人，通常也被认为约定交付无负担的占有；然而该口约并不包括孳息的交付，口约所负义务也不应被扩张。不过，买受人仍可依据买受之诉请求交付孳息。

<!-- source-p 014 -->
<a id="19.1.3.2"></a>**2.**如果我从你处买下经过你土地的通行权、驱赶牲畜权或引水权，就不存在交付无负担占有的问题。因此，你应作出担保，保证不会因你的行为妨碍我行使这些权利。

<!-- source-p 015 -->
<a id="19.1.3.3"></a>**3.**若因出卖人的迟延而未能交付葡萄酒，应判令其按酒价较高时的价格赔偿；该时点可以是订立买卖时，也可以是诉讼进入判决阶段时。还应考虑地点：以订约地或审理地中酒价较高者为准。

<!-- source-p 016 -->
<a id="19.1.3.4"></a>**4.**但若迟延是由买受人造成，评估时应采用起诉时的价格，并考虑酒价较低的地点。若不存在任何妨碍出卖人交付的困难，尤其是出卖人一直准备交付，就应认定买受人迟延。评估也不应采用审理地的价格，而应采用约定交付地的价格：例如，葡萄酒从布伦迪西运来，即使买卖在别处订立，也应在布伦迪西交付。

<!-- source-p 017 -->
<a id="19.1.4"></a>**19.1.4**

<!-- source-p 018 -->
**保罗：《萨宾评注》第五卷。**

<!-- source-p 019 -->
<a id="19.1.4.pr."></a>**序言。**你明知某奴隶是盗贼或应承担诺克萨责任，却将其卖给不知情的我；即使你承诺双倍赔偿，仍须依据买受之诉承担责任，赔偿我若知道该情形本会避免的损失。因为在实际发生损失之前，我不能就此依据口约之诉起诉你。

<!-- source-p 020 -->
<a id="19.1.4.1"></a>**1.**如果土地的面积少于约定，出卖人应按短少的尤格面积承担担保责任；因为土地面积不足时，无法评估并不存在的那部分土地的品质。即使并非整块土地面积短少，而只是其中一部分短少，也可以起诉出卖人；例如约定葡萄园或橄榄园有一定面积，实际面积却不足。在这些情形下，应按土地品质评估损失。〔译注：底本首字作“I”，句义似需 *Si*（“若”）；暂按条件句译，未改动底本文字。〕

<!-- source-p 021 -->
<a id="19.1.5"></a>**19.1.5**

<!-- source-p 022 -->
**保罗：《萨宾评注》第三卷。**

<!-- source-p 023 -->
<a id="19.1.5.pr."></a>**序言。**继承人依遗嘱负有出售某物的义务并已出售后，若涉及其他随买卖而产生的附随事项，可以对其提起买受之诉，也可以依据遗嘱起诉。

<!-- source-p 024 -->
<a id="19.1.5.1"></a>**1.**但如果他误以为自己负有出售义务而出售了该物，就不能对其提起买受之诉，因为他可以援引恶意抗辩以排除原告；正如有人误以为自己负有交付义务而作出承诺时，若对方起诉，他也可以援引恶意抗辩。庞波尼乌斯还说，他可以提起不确定额的返还之诉，以解除自身义务。

<!-- source-p 025 -->
<a id="19.1.6"></a>**19.1.6**

<!-- source-p 026 -->
**庞波尼乌斯：《萨宾评注》第九卷。**

<!-- source-p 027 -->
<a id="19.1.6.pr."></a>**序言。**即使出卖人不知道土地面积不足，仍须依据买受之诉承担责任。

<!-- source-p 028 -->
<a id="19.1.6.1"></a>**1.**我以一定价款把一幢公寓楼卖给你，并约定你为我修缮另一幢公寓楼，我可以依据出卖之诉起诉，要求你修缮。若双方只约定你应修缮该楼，却未约定买卖事项，则不视为成立买卖，涅拉提乌斯也如此记载。

<!-- source-p 029 -->
<a id="19.1.6.2"></a>**2.**但如果我以确定价款将一块建筑用地卖给你并已交付，约定你建成公寓楼后将其中一半返还给我，那么我可以依据出卖之诉请求你建造，并在建成后将其返还给我。只要出售之物仍有任何部分留在你手中，就可以确认我享有出卖之诉。

<!-- source-p 030 -->
<a id="19.1.6.3"></a>**3.**如果你买下一处墓地，在有人埋葬于此之前，出卖人却在墓地附近建造了房屋，你可以向出卖人主张权利。

<!-- source-p 031 -->
<a id="19.1.6.4"></a>**4.**如果你把某个容器卖给我，并声明它能容纳确定容量或具有确定重量，实际未达到的，我可以依据买受之诉起诉你。如果你卖给我容器时保证它完好，而它并不完好，你还应赔偿我因此遭受的全部损失。若双方并未约定你须保证容器完好，你只对恶意欺诈负责。拉贝奥持相反意见，认为除非另有约定，否则无论如何都应保证容器完好；这一意见是正确的。米尼基乌斯记载，萨宾对出租的酒桶也作了同样答复。

<!-- source-p 032 -->
<a id="19.1.6.5"></a>**5.**如果你把通行权卖给我，只有在我拥有意图取得该地役权之土地时，我才能要求你承担担保责任。若我不能取得地役权只是因为我并非邻地所有人，却要你对此负责，这是不公平的。

<!-- source-p 033 -->
<a id="19.1.6.6"></a>**6.**但如果你把土地卖给我，并称通行权将随该土地一并取得，那么你无论如何都须就通行权承担责任，因为你作为出卖人，对两项标的均负有义务。

<!-- source-p 034 -->
<a id="19.1.6.7"></a>**7.**家子把某物卖给我并交付该物的，应如家父一样承担责任。

<!-- source-p 035 -->
<a id="19.1.6.8"></a>**8.**出卖人对出售之物实施了任何恶意行为，买受人就该行为享有买受之诉。因为该诉讼也应评估恶意；出卖人曾承诺向买受人履行的事项，均应当履行。

<!-- source-p 036 -->
<a id="19.1.6.9"></a>**9.**出卖人明知某物负有负担或属于他人，却在买卖中加上“出卖人不就此承担责任”的约定，应当评估其恶意；在诚信诉讼中，恶意始终不得存在。

<!-- source-p 037 -->
<a id="19.1.7"></a>**19.1.7**

<!-- source-p 038 -->
**庞波尼乌斯：《萨宾评注》第十卷。**

<!-- source-p 039 -->
我把土地卖给你时扣除了用益权，并说该用益权属于提提乌斯，尽管它实际上仍由我保留。如果我开始主张该用益权，在提提乌斯仍然生存、且尚未发生即使其享有该用益权也会丧失该权利的情形之前，你不能向我追责；一旦提提乌斯丧失人格或死亡，你就可以向作为出卖人的我主张权利。如果我说用益权属于提提乌斯，而实际上属于塞伊乌斯，法律也相同。

<!-- source-p 040 -->
<a id="19.1.8"></a>**19.1.8**

<!-- source-p 041 -->
**保罗：《萨宾评注》第五卷。**

<!-- source-p 042 -->
<a id="19.1.8.pr."></a>**序言。**如果我把一块无须承受地役权的土地交付给你，而我本应交付的是负有地役权的土地，我也可以提起不确定额的返还之诉，请求你容许该土地设定其本应承受的地役权。

<!-- source-p 043 -->
<a id="19.1.8.1"></a>**1.**相反，如果我交付给你的是负有地役权的土地，而我本应交付无负担的土地，你可以提起买受之诉，请求免除你本不应承受的地役权。

<!-- source-p 044 -->
<a id="19.1.9"></a>**19.1.9**

<!-- source-p 045 -->
**庞波尼乌斯：《萨宾评注》第二十卷。**

<!-- source-p 046 -->
如果有人买下土地上的石料，却不愿将其运走，可以依据出卖之诉起诉，要求其移走石料。

<!-- source-p 047 -->
<a id="19.1.10"></a>**19.1.10**

<!-- source-p 048 -->
**乌尔比安：《萨宾评注》第四十六卷。**

<!-- source-p 049 -->
同一人就同一事项同时负有两项债务，并非新鲜事。例如，某人对出卖人享有债权，后来又继承了另一项同样针对该出卖人的债权，就可以确认同一人同时享有两项诉权：一项属于其本人，一项属于遗产。指定继承人若想分别利用两项诉权，应在接受遗产前先以本人名义起诉出卖人，接受遗产后再以继承人身份起诉。若先接受遗产，则虽只能提起一项诉讼，但可在该诉中一并取得两项契约的利益。反过来，若出卖人成为另一出卖人的继承人，显然他必须就两次买卖分别承担被追夺的责任。

<!-- source-p 050 -->
<a id="19.1.11"></a>**19.1.11**

<!-- source-p 051 -->
**乌尔比安：《告示评注》第三十二卷。**

<!-- source-p 052 -->
<a id="19.1.11.pr."></a>**序言。**买受人使用买受之诉。

<!-- source-p 053 -->
<a id="19.1.11.1"></a>**1.**首先应当知道，该诉讼只审理双方约定应当履行的事项。既然这是诚信诉讼，没有什么比履行缔约双方约定的事项更符合诚信。如果双方没有约定，则应履行依其性质属于该诉讼范围的义务。

<!-- source-p 054 -->
<a id="19.1.11.2"></a>**2.**首先，出卖人应当交付标的物。若出卖人是所有人，交付即使买受人成为所有人；若出卖人不是所有人，只要价款已经支付或已就价款提供担保，出卖人便仅须就标的物被追夺承担责任。买受人则有义务使出卖人取得价款。

<!-- source-p 055 -->
<a id="19.1.11.3"></a>**3.**拉贝奥和萨宾均认为，买受之诉也包括解除买卖（*redhibitio*）；我们赞同这一意见。

<!-- source-p 056 -->
<a id="19.1.11.4"></a>**4.**出卖动物时，也应担保动物健康；出卖役畜的人通常会承诺：“能够按其应有的方式饮食。”

<!-- source-p 057 -->
<a id="19.1.11.5"></a>**5.**某人以为自己买的是处女，实际买到的却是妇女；出卖人知道买受人误解而未予纠正。虽不能因此解除买卖，但买受人享有买受之诉以撤销买卖；返还价款后，应将妇女交还。

<!-- source-p 058 -->
<a id="19.1.11.6"></a>**6.**某人买酒时交付了一定数额的定金，之后双方又约定解除买卖。尤利安说，可以提起买受之诉请求返还定金；他还认为，买受之诉也可以作为撤销买卖的适当诉讼。我提出另一问题：如果以戒指作为定金，买卖随后成立，价款已经支付、标的物也已交付，但戒指未被返还，应提起何种诉讼？是因为交付的原因已经终结而提起返还之诉，还是应提起买受之诉？尤利安会认为可以提起买受之诉；当然，也可以提起返还之诉，因为此时戒指已无原因地留在出卖人处。

<!-- source-p 059 -->
<a id="19.1.11.7"></a>**7.**涅拉提乌斯说，即使出卖人并不知道奴隶会逃跑，仍应向买受人担保该奴隶不是逃奴。

<!-- source-p 060 -->
<a id="19.1.11.8"></a>**8.**涅拉提乌斯还说，即使出售的是他人所有的奴隶，出卖人也被普遍认为应担保该奴隶不涉及盗窃责任或诺克萨责任；买受人享有买受之诉，请求出卖人保证自己能够保有该奴隶，并将占有交付给自己。

<!-- source-p 061 -->
<a id="19.1.11.9"></a>**9.**涅拉提乌斯还说，未交付标的物的出卖人应按买受人的利益损失承担判决责任；未提供担保人的，则应按可能使担保人承担的最高责任额负责。

<!-- source-p 062 -->
<a id="19.1.11.10"></a>**10.**涅拉提乌斯还说，对于上述一切事项，出卖人履行最高额的责任即足够；也就是说，在后续诉讼中，应扣除已经履行的部分，再评估争议。

<!-- source-p 063 -->
<a id="19.1.11.11"></a>**11.**涅拉提乌斯正确地说，如果上述事项中有一项未履行，而其他事项均已履行，判决时不得扣减任何数额。

<!-- source-p 064 -->
<a id="19.1.11.12"></a>**12.**涅拉提乌斯在《答复录》第二卷中说，买受人因诺克萨诉讼被判承担责任的，可以通过买受之诉请求其以最低费用即可免除责任的数额。若买受人依据口约之诉起诉，亦同。无论买受人是否在诺克萨诉讼中进行辩护，既然该奴隶显然负有诺克萨责任，他仍可依据口约之诉或买受之诉起诉。

<!-- source-p 065 -->
<a id="19.1.11.13"></a>**13.**涅拉提乌斯说，交付标的物时，出卖人应确保买受人在占有诉讼中处于较优地位。尤利安在《学说汇纂》第十五卷中赞同：如果买受人不能在占有上取得优先地位，就不应认为标的物已交付。因此，未做到这一点的，买受人享有买受之诉。

<!-- source-p 066 -->
<a id="19.1.11.14"></a>**14.**卡西乌斯说，某人依据双倍赔偿口约取得诉讼估价额后，不得再就买卖中通常约定担保的其他事项请求赔偿。尤利安认为，若双倍赔偿口约不能适用，则应提起买受之诉。

<!-- source-p 067 -->
<a id="19.1.11.15"></a>**15.**尤利安在《米尼基乌斯》第十卷中还说：某人出售奴隶，约定在三十日内作出双倍赔偿的承诺，且此后不再承担其他责任；买受人没有要求其在期限内作出承诺的，只有在出卖人不知道奴隶属于他人时，出卖人才不承担责任。因为在这种情形下，约定只是要求出卖人本人及其继承人确保买受人能够保有该奴隶。若出卖人明知奴隶属于他人仍予出售，尤利安说，他不能免于欺诈责任，因此仍受买受之诉追究。

<!-- source-p 068 -->
<a id="19.1.11.16"></a>**16.**我认为，尤利安的意见在质物买卖中也完全正确。如果债权人依其权利出售质物，后来质物被追夺，债权人不因买受之诉而承担返还价款的责任；多项皇帝敕令已确立这一点。当然，出卖人仍须对欺诈承担责任，因此通常还会就欺诈作出复诺。即使他没有作出复诺，但明知标的物并未向自己设定质权，或并非设定质权者所有，仍予出售，也应承担买受之诉的责任，因为我们已经说明出卖人须对欺诈负责。

<!-- source-p 069 -->
<a id="19.1.11.17"></a>**17.**如果出卖人出售某物，并称另有某物将随同附属于该物出售，那么前述关于所售标的物的规则也都适用；但是，出卖人不承担双倍的追夺责任，只负有确保买受人能够保有该物的义务，而且不仅须确保买受人能够对抗出卖人本人，也须确保其能够对抗所有人。

<!-- source-p 070 -->
<a id="19.1.11.18"></a>**18.**如果出卖人承诺买受人能够保有该物，我们应当考察他须承担何种义务。我认为，关键在于他承诺的是：不因其本人及从其取得权利的人而妨碍买受人保有该物，还是保证任何人均不得妨碍。若只是前一种承诺，就不能认为他保证买受人不会被他人追夺。因此，标的物被追夺时，无论曾订立口约还是未订立口约，出卖人均不分别依口约之诉或买受之诉承担责任。但尤利安在《学说汇纂》第十五卷中写道：即使出卖人明确声明仅保证自己及其继承人不妨碍买受人保有标的物，仍可主张他虽不对买受人的利益损失负责，却应返还价款。同卷还说，即使买卖中明确约定出卖人不承担任何追夺责任，标的物被追夺时仍应返还价款，但不赔偿买受人其他利益损失；诚信契约不允许买受人丧失标的物而出卖人仍保有价款。除非有人将上述全部约定视作另一种特殊交易，例如渔夫尚未撒网捕鱼、猎人尚未布网围猎时，买受人购买其将来捕获的鱼或猎物，或从捕鸟人处买下将来捕获的豹子：即使一无所获，买受人仍须支付价款。但前述关于追夺责任的约定不应如此处理。若出卖人明知出售的是他人之物，则应依我们上文引述的尤利安意见，认定其因欺诈而须承担买受之诉的责任。

<a id="19.1.13"></a>**19.1.13**

<!-- source-p 075 -->
**乌尔比安：《告示评注》第三十二卷。**

<!-- source-p 076 -->
<a id="19.1.13.pr."></a>**序言。**尤利安在《学说汇纂》第十五卷中区分出卖人明知或不知情而出售的情形，并区分买受之诉中的判决责任。他说，出卖人出售患病的牲畜或有瑕疵的木料而不知情，只须依据买受之诉赔偿买受人若知道该情况便会少付的价款；若出卖人知情却隐瞒并欺骗买受人，则须赔偿买受人因该买卖遭受的一切损失。因此，若房屋因木料有瑕疵而倒塌，应赔偿房屋价值；若牲畜因接触患病牲畜而死亡，则应赔偿本可买到健康牲畜时的价差。

<!-- source-p 077 -->
<a id="19.1.13.1"></a>**1.**出卖人出售盗贼或逃奴时，若明知其身份，应赔偿买受人未受欺骗本可避免的全部损失；若不知情而出售，关于逃奴，出卖人仍应赔偿买受人若知道其为逃奴本会少付的价款；关于盗贼则不承担责任。区别在于：逃奴不能由买受人合法保有，出卖人因类似被追夺的责任而负责；盗贼则仍可以由买受人保有。

<!-- source-p 078 -->
<a id="19.1.13.2"></a>**2.**我们所说的“买受人未受欺骗本可避免的损失”包括：该奴隶若还诱使其他奴隶逃跑，或偷走了某些财物，也应予以赔偿。

<!-- source-p 079 -->
<a id="19.1.13.3"></a>**3.**然而，如果出卖人虽不知道该奴隶是盗贼，却断言其品行良好、可靠，且因此以高价出售，是否应依买受之诉承担责任？我认为应当承担。虽说他并不知情，但不应轻率地断言自己不知道的事情。因此，知情的出卖人本应预先告知奴隶是盗贼；不知情的出卖人则不应轻率作出这种保证。

<!-- source-p 080 -->
<a id="19.1.13.4"></a>**4.**如果出卖人为了抬高价款而欺诈，例如谎称奴隶拥有某种技艺或特有产，应依买受之诉对其起诉，使其赔偿买受人：若奴隶确有该特有产或掌握所称技艺，买受人本会多付的价款。

<!-- source-p 081 -->
<a id="19.1.13.5"></a>**5.**尤利安还从相反方向写道：特伦提乌斯·维克托去世后，由其兄弟继承；一名军人盗走遗产中的某些物品、文书和奴隶，随后利用这些物品被盗、遗产看起来价值很低这一点，说服继承人以低价将遗产卖给自己。能否依据出卖之诉起诉该买受人？尤利安说，可以提起出卖之诉，要求赔偿这些物品未被盗时遗产本可增加的价值。〔底本本句末有文字粘连疑误，详见疑难记录〕

<!-- source-p 082 -->
<a id="19.1.13.6"></a>**6.**尤利安还说明，在下列情形中，出卖人通常也须对欺诈负责：出卖人明知土地须向多个自治市缴纳遗赠款，却在清单上只记载欠一个自治市的款项，之后又在条款中写明，买受人应承担一切税款、公共税赋、特别征收款或道路摊派。出卖人因此应承担买受之诉的责任，因为他欺骗了买受人。这一意见是正确的。

<!-- source-p 083 -->
<a id="19.1.13.7"></a>**7.**关于监护人出售被监护人的财物时实施了同样行为，有人提出问题：被监护人是否应对监护人的欺诈承担责任？如果是监护人亲自出售，毫无疑问应由监护人承担买受之诉的责任；但若被监护人在监护人授权下出售，则被监护人只在因交易而变得较为富有的范围内承担责任，监护人则应永久承担剩余部分的责任，因为监护人的欺诈不会在被监护人成年后转由被监护人承担。

<!-- source-p 084 -->
<a id="19.1.13.8"></a>**8.**买受人提起买受之诉时，应提出支付价款；因此，只提出支付部分价款的，还不能提起买受之诉。出卖人可以像保留质物一样保留已出售之物。

<!-- source-p 085 -->
<a id="19.1.13.9"></a>**9.**由此产生问题：若价款仅支付一部分、标的物已交付，后来标的物被追夺，买受人依据买受之诉应取得全部价款，还是仅能取得已支付的部分？我认为，鉴于恶意抗辩，应以其已支付的数额为限。

<!-- source-p 086 -->
<a id="19.1.13.10"></a>**10.**如果出售的是已经成熟果实的土地，除非另有约定，果实显然归买受人所有。

<!-- source-p 087 -->
<a id="19.1.13.11"></a>**11.**如果土地已经出租，租金当然归出租人所有；城市地产也同样处理，除非双方明确另有约定。

<!-- source-p 088 -->
<a id="19.1.13.12"></a>**12.**此外，如果出售之物遭受损害，相关诉权也应移转给买受人，例如针对可能发生的损害的担保、阻止雨水损害之诉、阿奎利亚法之诉，或针对以暴力或秘密方式实施行为的禁令。

<!-- source-p 089 -->
<a id="19.1.13.13"></a>**13.**奴隶的劳务、役畜或船舶运输所取得的收益，也应交给买受人；奴隶特有产增加的财物亦然，但出卖人自己的财物不在此列。

<!-- source-p 090 -->
<a id="19.1.13.14"></a>**14.**提提乌斯出售一块实际有九十尤格的土地，买卖条款却写明土地有一百尤格；在土地面积尚未查明之前，因冲积又增加了十尤格。我赞同涅拉提乌斯的意见：如果出卖人明知土地只有九十尤格，仍应允许买受人提起买受之诉；尽管后来增加了十尤格，出卖人的欺诈并未因此消除。若出卖人不知情，则不得提起买受之诉。

<!-- source-p 091 -->
<a id="19.1.13.15"></a>**15.**如果你把他人所有的土地卖给我，而我后来因无偿取得该土地的事由成为其所有人，我仍可对你提起买受之诉。

<!-- source-p 092 -->
<a id="19.1.13.16"></a>**16.**对于通常随出售之物一并履行的事项，我认为出卖人不仅须对欺诈负责，也须对过失负责。塞尔苏斯在《学说汇纂》第八卷中写道：如果约定由出卖人收取过去的租金并交给买受人，出卖人不仅对欺诈，也对过失负责。

<!-- source-p 093 -->
<a id="19.1.13.17"></a>**17.**同一卷中，塞尔苏斯还写道：你与提提乌斯共有一块土地，并出售了自己的份额；在交付前，你被迫接受分割共有物之诉。如果法院将土地判归共有人，你应把因此从提提乌斯处取得的款项交给买受人。如果法院将整块土地判给你，那么你应将整块土地交给买受人，但买受人须支付你因此被判向提提乌斯给付的款项。对于你出售的那一份额，你应提供被追夺担保；对于另一份额，你只须作出关于恶意欺诈的复诺。因为买受人的处境应当与由其本人参加分割共有物之诉时相同。如果法官已经按明确界线在你与提提乌斯之间分割土地，毫无疑问，你应将判归你的那一部分交给买受人。

<!-- source-p 094 -->
<a id="19.1.13.18"></a>**18.**出卖人在奴隶交付前赠与该奴隶的财物，也应返还给买受人。通过该奴隶取得的遗产和一切遗赠同样如此，无须区分遗产或遗赠是为谁而留。该奴隶为出卖人提供劳务所得，也应交给买受人；但如果双方约定延后交付日，目的就是让劳务归出卖人享有，则不在此限。

<!-- source-p 095 -->
<a id="19.1.13.19"></a>**19.**出卖人享有出卖之诉，以取得买受人应向其履行的事项。

<!-- source-p 096 -->
<a id="19.1.13.20"></a>**20.**下列事项可以列入该诉讼。首先是价款，即标的物的成交价；其次是交付日之后的价款利息。既然买受人正在享用该物，由其支付价款利息显然最为公平。

<!-- source-p 097 -->
<a id="19.1.13.21"></a>**21.**即使交付的是可随时撤回的占有，也应视为已经交付占有；因为只需考察买受人是否有能力取得孳息。

<!-- source-p 098 -->
<a id="19.1.13.22"></a>**22.**此外，出卖人依据出卖之诉还可以请求买受人偿付为出售之物支出的费用，例如出售房屋时为房屋支出的费用。拉贝奥和特雷巴提乌斯写道，出卖人就此享有出卖之诉。交付前为患病奴隶的治疗所支出的费用，或为奴隶所受训练支出的、买受人也很可能愿意支付的费用，也同样可以请求。拉贝奥还说，如果奴隶死亡并非因出卖人的过失，出卖人可以依据出卖之诉请求买受人支付葬礼费用。

<!-- source-p 099 -->
<a id="19.1.13.23"></a>**23.**如果买卖时约定由买受人提供一名有清偿能力的被告，出卖人可以依据出卖之诉起诉，要求买受人履行该约定。

<!-- source-p 100 -->
<a id="19.1.13.24"></a>**24.**如果不动产买受人与出卖人约定：买受人或其继承人日后以更高价格转售该不动产时，应将价差的一半交给出卖人；而买受人的继承人确实以更高价格转售了该不动产，那么出卖人可以依据出卖之诉请求取得该价差的一半。

<!-- source-p 101 -->
<a id="19.1.13.25"></a>**25.**如果代理人出售标的物并向买受人提供担保，问题是应否赋予买受人对家父的诉权，或赋予家父对买受人的诉权。帕皮尼安在《答复录》第三卷中认为，只要家父曾委托出售该物，就可以类推经理人之诉，对家父提起准用的买受之诉。因此，反过来也应说，家父享有准用的买受之诉。〔译注：底本末句明确作 *utilem ex empto actionem domino competere*（家父享有准用的买受之诉）；家父在此似为出卖人，诉权名称与交易角色不相合，暂保留底本文字。〕

<!-- source-p 102 -->
<a id="19.1.13.26"></a>**26.**帕皮尼安同卷还答复说，如果双方约定价款到期未付时买受人须支付双倍金额，那么超出法定利息的部分似乎是为了规避法律上的限制而加上的。他说，这与解除约款性质不同；在后一种情形中，并非订立违法的高利贷，而是约定法律并不禁止的交易条款。

<!-- source-p 103 -->
<a id="19.1.13.27"></a>**27.**如果有人与我的代理人串通后从其处买下标的物，是否可以提起买受之诉？我认为，处理方式只能是维持买卖，或者解除买卖。

<!-- source-p 104 -->
<a id="19.1.13.28"></a>**28.**如果有人欺骗未满二十五岁者，我们也只在前述情形所述的范围内赋予其买受之诉。

<!-- source-p 105 -->
<a id="19.1.13.29"></a>**29.**有人未经监护人授权便从未成年人处买物，契约只有一方成立：买受人对未成年人负有义务，未成年人却不因此对买受人负有义务。

<!-- source-p 106 -->
<a id="19.1.13.30"></a>**30.**如果出卖人保留房屋居住权，允许承租人继续居住，或允许佃户在一定期间内继续使用土地，塞尔维乌斯更倾向于认为出卖人享有出卖之诉。图贝罗说，如果佃户造成损害，买受人可以提起买受之诉，迫使出卖人依据租赁关系起诉佃户，并将所得交给买受人。

<!-- source-p 107 -->
<a id="19.1.13.31"></a>**31.**出售或遗赠房屋时，通常把那些视为房屋组成部分或因房屋而存在的物品也称为房屋的一部分，例如井口石圈。

<a id="19.1.17.pr."></a>**序言。**土地只包括附着于地面的物；房屋却有许多并未固定在房屋上的组成物，例如门闩、钥匙和锁具，这一点不应被忽视。埋在地下的许多物品也不因此成为土地或庄园的一部分，例如储酒容器和榨酒器具；这些更属于设备，即使它们与建筑相连也是如此。

<!-- source-p 120 -->
<a id="19.1.17.1"></a>**1.**葡萄酒和已经收获的果实显然也不属于庄园本身。

<!-- source-p 121 -->
<a id="19.1.17.2"></a>**2.**土地出售或遗赠时，堆肥和稻草归买受人或受遗赠人所有；木材则归出卖人或继承人所有，因为木材不属于土地，即使它是为土地用途而购置的。对于堆肥，应当采用特雷巴提乌斯的区分：若购置堆肥是为给土地施肥，就随土地归买受人；若是为出售，则归出卖人，除非另有约定。无论堆肥放在畜栏中还是堆成一堆，都不影响这一点。

<!-- source-p 122 -->
<a id="19.1.17.3"></a>**3.**嵌入墙面灰泥中的彩绘板，以及大理石贴面，都属于房屋。

<!-- source-p 123 -->
<a id="19.1.17.4"></a>**4.**柱子周围的格栅、墙边的矮屏，以及奇里乞亚帘幕，都不属于房屋。

<!-- source-p 124 -->
<a id="19.1.17.5"></a>**5.**为公寓楼准备的材料，如果尚未完工，即使已经放在建筑物中，也不视为房屋的一部分。

<!-- source-p 125 -->
<a id="19.1.17.6"></a>**6.**如果买卖中排除了挖出或砍伐之物，那么挖出之物包括已经挖出的沙、白垩等；砍伐之物包括已经砍下的树木、木炭等。梅拉转述了阿奎利乌斯·加卢斯的意见，他正确地说，买卖条款中无需专门列明挖出或砍伐之物，因为如果这些物品没有被特别出售，可以提起展示之诉请求交出。出卖人无须比对其他价值更高的物品承担更多义务，特地就砍下的木材、石料或沙作出担保。

<!-- source-p 126 -->
<a id="19.1.17.7"></a>**7.**拉贝奥概括地写道：为建筑物永久使用而设置的物品属于建筑物；仅为眼前使用而设置的则不属于。例如，临时安装的管道不属于房屋；若永久安装，则属于房屋。

<!-- source-p 127 -->
<a id="19.1.17.8"></a>**8.**铅制蓄水池、井、井盖、与管道焊接的水阀，以及埋在土中但并未固定的物品，均显然属于房屋。

<!-- source-p 128 -->
<a id="19.1.17.9"></a>**9.**雕像、柱子以及从其口部喷水的面具，也显然属于庄园。

<!-- source-p 129 -->
<a id="19.1.17.10"></a>**10.**从建筑物拆下、准备重新装回的物品仍属于建筑物；准备安装但尚未装上的物品则不属于建筑物。

如果出卖人出售两块土地，分别声明每块土地的面积，却以一个总价一并交付；其中一块土地面积不足，即使另一块面积有余，也不能据此补足。例如，出卖人称一块有一百尤格，另一块有二百尤格，实际一块有二百一十尤格，另一块却短少十尤格，也不能因其中一块面积多出十尤格而免除责任。拉贝奥也曾如此记载。不过，出卖人能否援引恶意抗辩，仍有疑问；例如树林面积只短少一点，而葡萄园面积多于承诺时，是否应作不同处理？合法行使永久权利的人，难道就不构成恶意吗？毕竟，某一土地面积超过此前约定的部分，利益应归买受人而非出卖人；只有某一块土地面积不足时，出卖人才承担责任。然而，如果在同一块土地中葡萄园的面积多于约定、草地面积少于约定，而总面积相同，买受人是否无权抱怨？这与两块土地的情形类似。又如有人以一个总价出售两名附条件获释的奴隶，并称其中一人只须支付十即可获释，而实际上他须支付十五；即使买受人将从两人处总共取得二十，也仍可提起买受之诉。较妥当的看法是，在上述所有情形中，应当以得抵失；买受人若因土地面积或品质不足而受损，应予补偿。

<a id="19.1.45.pr."></a>**序言。**阿非利卡努记载，尤利安也讨论过这一点；这一意见是公允的：如果奴隶在买受人处状况变差，后来被追夺时，出卖人的责任也应相应减少。

<!-- source-p 229 -->
<a id="19.1.45.1"></a>**1.**另一种情形较容易处理：你把他人所有的建筑用地卖给我，我在其上建了房屋，后来所有人将土地追夺。如果所有人请求返还时，我可以援引恶意抗辩，除非其偿付房屋建造费用，否则便不能取回土地，那么此事较不应归入出卖人的风险。同样，如果奴隶被追夺为他人的奴隶而不是被宣告自由，所有人应支付其劳务报酬及费用。如果买受人不占有建筑物或奴隶，则可依据买受之诉起诉。但在所有这些情形中，若出卖人明知标的物属于他人仍予出售，就无论如何都应承担责任。

<!-- source-p 230 -->
<a id="19.1.45.2"></a>**2.**还剩第三个问题：拒绝买受人成为释奴主的阿雷斯库莎应成为谁的释奴？有理由认为，她应成为将她出售之人的释奴，也就是继承人的释奴，因为继承人也受买受之诉追究。但只有在阿雷斯库莎没有选择买受人作为释奴主时，才如此处理；若她选择买受人，她仍是买受人的释奴，买受人也不再享有买受之诉，因为他已有她作为释奴，不再有利益损失。

<a id="19.1.54.pr."></a>**序言。**如果你出售一名奴隶后，又命令他做某事，而他因此折断了腿，只有在你所命令的是他出售前惯常从事的事情，而且即使没有出售该奴隶，你也会命令他做同样事情时，才不由你承担风险。保罗说：完全不是这样。如果他出售前惯常从事危险活动，那么损害似乎就是你的过失所致；例如，该奴隶曾惯于沿着绳索滑降，或被放入下水道作业。如果你惯于命令奴隶做审慎勤勉的家父不会命令奴隶去做的事情，也应适用同一规则。那么，如果双方对此作了特别约定呢？即便如此，你仍可能命令该奴隶做一件新的事情，而若他未被出售，你本不会命令他去做；例如，命令他去寻找身在外地的买受人。显然，此时不应由你承担风险。因此，出卖人是否承担责任，完全取决于其恶意或过失。

<a id="19.1.54.1"></a>**1.**如果约定八十只酒缸随土地一并出售，且酒缸埋在地下，而实际数量多于八十只，出卖人应让买受人从中挑选八十只完好的酒缸交付；如果实际只有八十只，则无论酒缸状况如何，均归买受人，出卖人不因其中有不完好的而承担责任。
