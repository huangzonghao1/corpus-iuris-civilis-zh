# 第二卷

## 2.4　论传唤到庭（续）

### <a id="2.4.8"></a>2.4.8　乌尔比安《评告示》第五卷

<a id="2.4.8.pr."></a>**序言。** 只要子女仍处于养父权力之下，就不得将养父传唤到庭；这是家父权的效力，而非裁判官告示的命令。但如果该子女拥有军役特有财产（*peculium castrense*），经审查具体情形后，可以准许传唤。即使自然父母已将子女交给他人收养，也不得传唤他们到庭。

<a id="2.4.8.1"></a>**1.** 告示所称“保护人”或“女保护人”，是指曾将自由释奴从奴隶身份中释放的人；也包括揭露了串通行为的人；以及经先决裁断被宣告为自由释奴、而其实际上并非自由释奴的人；或我曾以宣誓确认其为我的自由释奴的人。相反，如果已有判决认定我不是其保护人，或者经我要求，他已宣誓称自己不是自由释奴，那么我就不被视为保护人。

<a id="2.4.8.2"></a>**2.** 如果我曾要求自由释奴宣誓不娶妻或不出嫁，他便可以不受处罚地将我传唤到庭。塞尔苏斯认为，在这种自由释奴身上，我作为保护人的权利在我生前不会转移给我的儿子；尤利安则持相反意见。多数法学家赞同尤利安。因此，可能发生保护人本人可被传唤、而其儿子因无过错不应被传唤的情形。

### <a id="2.4.9"></a>2.4.9　保罗《评告示》第四卷

受遗嘱信托安排而释放奴隶的人，不应被传唤到庭，尽管他本人可能因履行释放义务而被传唤到庭。

### <a id="2.4.10"></a>2.4.10　乌尔比安《评告示》第五卷

<a id="2.4.10.pr."></a>**序言。** 如果我是在约定释放奴隶的条件下买下他的，并且他依据神皇马可的敕令获释，那么我作为其保护人，不得被传唤到庭。但如果我用奴隶自己的钱买下他，却违背承诺不予释放，我就不被视为其保护人。

<a id="2.4.10.1"></a>**1.** 如果奴隶女违反买卖条件而被迫卖淫，出卖人仍是她的保护人；买卖条件规定，若她被迫卖淫，她即可获释。但如果保留亲自对她行使强制拘束权的出卖人本人迫使她卖淫，那么她虽依据该条件、从出卖人处获得自由，出卖人却不应因此享有保护人的尊荣；马尔凯卢斯《学说汇纂》第六卷也持此见解。

<a id="2.4.10.2"></a>**2.** 即使保护人后来发生身份减等，也仍属于告示所称保护人；即使自由释奴在被人以欺诈手段收养时发生身份减等，亦同。因为收养本身掩盖了他的身份，不能认为其目的在于使他成为自由出生者。

<a id="2.4.10.3"></a>**3.** 如果自由释奴取得金戒指权，我认为他仍应向保护人表示敬重，尽管他已享有自由出生者的全部特权。如果他是被恢复为自由出生身份，则情况不同：此时元首使他成为自由出生者。

<a id="2.4.10.4"></a>**4.** 如果某人是由团体、社团或城市释放为自由人，他可以传唤其中的个人到庭，因为他不是这些个人的自由释奴。但他仍应尊重城市共同体；如果他想对城市共同体或法人团体提起诉讼，就应请求裁判官准许其不受该告示限制，即使他要传唤的是该团体指定的代理人，也同样如此。

<a id="2.4.10.5"></a>**5.** “保护人的子女和父母”应理解为包括男性和女性保护人的子女及父母。

<a id="2.4.10.6"></a>**6.** 如果保护人因放逐刑而被降为外邦人，庞波尼乌斯认为他已丧失保护人应享的敬重。但如果他后来恢复身份，仍应享有该告示给予的利益。
