# 第二卷

## 2.1　论司法管辖权（续）

### <a id="2.1.11"></a>2.1.11　盖尤斯《评行省告示》第一卷

<a id="2.1.11.pr."></a>**序言。** 如果同一原告针对同一被告提起数项诉讼，且每项诉讼的金额均在审理者的管辖限额以内，但各项金额合计超过其管辖限额，萨宾、卡西乌斯和普罗库鲁斯认为，仍可在该审理者面前起诉。皇帝安敦宁也以敕答确认了这一意见。

<a id="2.1.11.1"></a>**1.** 如果双方互有诉讼请求，一方请求的金额较小，另一方请求的金额较大，那么请求较小金额的一方应在同一审理者面前起诉；否则，我能否在其面前诉讼，便会取决于对方是否恶意操纵。

<a id="2.1.11.2"></a>**2.** 如果某一诉讼由多人共同提起，例如遗产分割诉讼、共有物分割诉讼或界址确定诉讼，那么在判断受理者的管辖权时，应当分别考察各人的份额——这是奥菲利乌斯和普罗库鲁斯的意见，因为每个人仅就自己的份额诉讼；还是应当考察全部标的，因为整个事项均提交裁判，而且全部标的可以判归其中一人——这是卡西乌斯和佩加苏斯的意见。后者的意见确实更为可取。

### <a id="2.1.12"></a>2.1.12　乌尔比安《评告示》第十八卷

市政官员不得对奴隶施以死刑，但不得因此否认其施以轻微体罚的权限。

### <a id="2.1.13"></a>2.1.13　乌尔比安《评萨宾》第五十一卷

<a id="2.1.13.pr."></a>**序言。** 命令他人担任裁判者的人，必须是官员。

<a id="2.1.13.1"></a>**1.** 官员或享有某种统治权的人，例如行省总督、裁判官或其他治理行省者，不得在其即将成为私人、卸任的那一天命令他人审判。

### <a id="2.1.14"></a>2.1.14　乌尔比安《评告示》第三十九卷

已经承认并据以行事的规则是：如果某个地位较高或与对方地位相当的人，自愿服从另一人的司法管辖，那么该人可以就其事务对他行使司法权，他也可以对该人行使司法权。

### <a id="2.1.15"></a>2.1.15　乌尔比安《论所有法庭》第二卷

如果有人误向另一位裁判官而非有管辖权的裁判官提出请求，已经进行的程序均不发生效力。也不能容许有人主张，当事人同意由该行省长官审理；正如尤利安所写，因错误而为之者并非出于同意。还有什么比揭示无知的错误更与同意相悖呢？

### <a id="2.1.16"></a>2.1.16　乌尔比安《论所有法庭》第三卷

裁判官通常会委托司法管辖权：可以委托全部管辖权，也可以只委托其中一类。受托者履职时，是代替委托者行事，而不是以自己的名义行事。

### <a id="2.1.17"></a>2.1.17　乌尔比安《意见集》第一卷

裁判官既可以将全部司法管辖权委托他人，也可以只就特定的人或某一类案件作出委托；尤其是，当他此前基于正当理由在官员面前为另一方担任过诉讼辩护人时，更可以如此。

### <a id="2.1.18"></a>2.1.18　阿非利加努斯《法律问题》第七卷

如果当事人约定由另一位裁判官——而非本来有管辖权的裁判官——行使司法权，但在向其提出请求之前又改变了主意，显然无人可以被强迫遵守该约定。

### <a id="2.1.19"></a>2.1.19　乌尔比安《遗嘱信托论》第六卷

<a id="2.1.19.pr."></a>**序言。** 一名少女曾在有管辖权的裁判者面前参加诉讼，随后被判败诉；此后，她嫁给一名受另一司法管辖权支配的男子。于是有人询问，先前裁判者的判决是否可以执行。我答复说可以，因为判决已经先行作出。即使在审理已经开始、判决尚未作出时发生婚姻，我也认为结论相同，原裁判者仍可合法作出判决。所有此类情形一般均应遵循这一规则。

<a id="2.1.19.1"></a>**1.** 每当需要确定某项请求是否属于管辖金额范围时，总应考察请求的金额，而非实际应得的金额。

### <a id="2.1.20"></a>2.1.20　保罗《评告示》第一卷

在其管辖区域以外行使司法权者，其命令可以不受处罚地不予遵从。若其试图在自身管辖权范围以外行使司法权，也是如此。
