# 第二卷

## 2.14　论协议（续）

### <a id="2.14.7"></a>2.14.7　乌尔比安《评告示》第四卷（上）

<a id="2.14.7.pr."></a>**序言。** 万民法上的协议，有些产生诉权，有些产生抗辩。

<a id="2.14.7.1"></a>**1.** 产生诉权的协议，并不保留其原有名称，而是转入特定合同的名称之下，例如买卖、租赁、合伙、使用借贷、寄托及其他类似合同。

<a id="2.14.7.2"></a>**2.** 如果某项安排未转入其他合同名称之下，但存在一项基础原因，阿里斯托对凯尔苏斯作了精当答复：即使如此，仍存在债务关系。例如，我交付某物给你，要求你另行交付某物给我；或者我交付某物给你，要求你为我完成某事。这构成 *synallagma*（相互给付关系），并由此产生市民法上的债务关系。因此，我认为毛里基亚努斯对尤利安的批评是正确的：我交给你奴隶斯提库斯，要求你释放潘菲卢斯；你已经释放潘菲卢斯，但斯提库斯后来被他人追夺。尤利安写道，裁判官应授予事实之诉；毛里基亚努斯则认为，以限定词句提出的不确定之诉已经足够。因为存在一项阿里斯托称为 *synallagma* 的合同，而该诉讼即由此产生。

<a id="2.14.7.3"></a>**3.** 如果约定的是不实施某项违法行为，那么该协议不产生债务关系。

<a id="2.14.7.4"></a>**4.** 如果没有任何基础原因，通说认为，不能仅凭协议设立债务关系。因此，单纯协议不产生债务关系，但会产生抗辩。

<a id="2.14.7.5"></a>**5.** 然而，有时协议本身会形成诉权，例如在诚信诉讼中。我们通常说，约定纳入诚信诉讼。对此应作如下理解：如果协议紧接合同订立而达成，即在同一交易过程中达成，那么它也会从原告一方纳入诉讼；如果协议是在间隔一段时间后达成，就不纳入合同，也不能由原告据此请求产生协议之诉。例如，离婚后，双方约定不按通常规定的期限，而立即返还嫁资；马尔凯卢斯也写道，这不会产生协议之诉。又如，在监护之诉中，双方约定支付高于法定标准的利息，也不得据此产生诉权。只有那些构成合同规范的协议，才纳入诉讼，也就是在合同成立时达成的协议。帕皮尼安也曾作出同样答复：买卖合同成立一段时间后，双方就合同性质之外的事项达成协议，也不得因此提起买卖之诉；同一规则适用于所有诚信诉讼。不过，被告一方仍可援用该协议，因为后来达成的协议通常会产生抗辩。

<a id="2.14.7.6"></a>**6.** 在诚信诉讼中，若后来达成的协议源自同一合同，也会纳入抗辩；因此，在买卖及其他诚信诉讼中，在合同尚未履行之前，当事人可以退出交易。如果整个交易都可以解除，为什么不能通过协议变更其中一部分？庞波尼乌斯在《评告示》第六卷中如此写道。既然如此，交易尚未履行时，当事人一方后来达成的协议，也可以产生诉讼上的效果，理由相同：如果整个交易都可以解除，为什么不能予以变更？如此一来，该合同在某种意义上仿佛重新订立。此说并非毫无道理。因此，我同样赞同庞波尼乌斯《讲习集》中的意见：通过协议仅就买卖的一部分退出交易，也可以理解为该部分交易重新订立。若买受人有两名继承人，出卖人与其中一名继承人约定解除买卖，尤利安认为该协议有效，买卖关系就该继承人的份额解除；因为该继承人也可能通过其他合同订立的协议为自己取得抗辩。因此，尤利安和庞波尼乌斯的两种意见均属正确。
