# 第二卷

## <a id="2.3"></a>2.3　论不服从行使司法权者的命令

### <a id="2.3.1"></a>2.3.1　乌尔比安《评告示》第一卷

<a id="2.3.1.pr."></a>**序言。** 除双人官（*duumviri*）外，所有官员均获准依其职权范围，通过罚金诉讼维护自己的司法管辖权。

<a id="2.3.1.1"></a>**1.** 如果某人没有履行行使司法权者所作的最后命令，便视为不服从。例如，某人不允许对其动产作司法主张，却允许该物被牵走或搬走；但若他连后续命令也拒绝履行，便视为不服从。

<a id="2.3.1.2"></a>**2.** 如果你的代理人、监护人或保佐人不服从行使司法权者的命令，应受处罚的是代理人、监护人或保佐人本人，而不是主人或未成年人。

<a id="2.3.1.3"></a>**3.** 拉贝奥认为，不仅不服从的被告受该告示约束，原告也受其约束。

<a id="2.3.1.4"></a>**4.** 此项诉讼的金额不是按利害关系人的实际损失计算，而是按该物的价值计算。由于该诉讼仅包含罚金，诉讼须在一年内提起，且不得针对继承人提起。
