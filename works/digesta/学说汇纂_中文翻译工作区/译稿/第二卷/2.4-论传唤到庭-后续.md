# 第二卷

## 2.4　论传唤到庭（续）

### <a id="2.4.11"></a>2.4.11　保罗《评告示》第四卷

虽然裁判官没有补充说明，自己将在审查具体情形后准许提起罚金诉讼，但拉贝奥认为，裁判官仍应节制行使司法权。例如，自由释奴后悔而撤回诉讼；保护人虽被传唤却没有到庭；或者传唤并非违背被传唤者本人意愿，尽管告示字面并未明示允许这些例外。

### <a id="2.4.12"></a>2.4.12　乌尔比安《评告示》第五十七卷

如果自由释奴违反裁判官告示，将其保护人的儿子传唤到庭，而该儿子仍处于其父的家父权之下，那么应当承认：即使父亲不在场，也应给予该儿子救济，使其可以针对自由释奴提起一项事实之诉；该诉罚金为五十奥里金币。

### <a id="2.4.13"></a>2.4.13　莫德斯蒂努斯《学说汇纂》第十卷

一般而言，对于所有应当受到敬重的人，未经裁判官命令，我们不得将其传唤到庭。

### <a id="2.4.14"></a>2.4.14　帕皮尼安《答复集》第一卷

自由释奴由保护人列为被告后，已经准备在法庭上为自己辩护，并多次向行省长官提出请求；这并不被视为他将作为原告的保护人传唤到庭。

### <a id="2.4.15"></a>2.4.15　保罗《法律问题》第一卷

自由释奴针对保护人提交了一份书面申请，并未隐瞒自己是其自由释奴。有人问：如果皇帝依其请求作出敕答，是否也应视为免除了告示规定的处罚？我答复说，我认为裁判官告示不适用于此种情形。向元首或行省长官递交书面申请的人，并不因此被视为将保护人传唤到庭。

### <a id="2.4.16"></a>2.4.16　保罗《答复集》第二卷

有人询问：监护人能否代表未成年人，在未经裁判官许可的情况下将自己的女保护人传唤到庭？我答复说，所询问的监护人可以代表未成年人，在未经裁判官许可的情况下将其女保护人传唤到庭。

### <a id="2.4.17"></a>2.4.17　保罗《箴言》第一卷

有人若已向官署提供担保、承诺交出某人，就必须将该人交出。又有一人虽未向官署提供正式担保，但已在官署记录中承诺交出某人，他同样必须交出该人。

### <a id="2.4.18"></a>2.4.18　盖尤斯《评《十二表法》》第一卷

许多人认为，不得将任何人从自己的住宅中传唤到庭，因为住宅是每个人最安全的避难所和庇护处；从住宅中传唤他的人，似乎是在对他施加强力。

### <a id="2.4.19"></a>2.4.19　保罗《评告示》第一卷

如果被传唤者没有人替他辩护，而他又躲藏起来，对他施加的制裁显然已经足够，因为对方会被准许占有他的财产。但如果他允许他人进入自己所在之处，或在公共场所被人看见，尤利安认为，可以依法将他传唤到庭。
