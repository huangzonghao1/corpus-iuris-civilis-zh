# 第二卷

## <a id="2.5"></a>2.5　论受传唤者未到庭，或传唤了告示禁止传唤之人

### <a id="2.5.1"></a>2.5.1　乌尔比安《评告示》第一卷

受传唤到庭的人如果提供了担保人，以保证自己出庭，而该担保人并不受传唤者所涉裁判官的管辖，那么该担保应视为未提供；除非担保人已明确放弃其特别特权。

### <a id="2.5.2"></a>2.5.2　保罗《评告示》第一卷

<a id="2.5.2.pr."></a>**序言。** 无论基于何种原因被传唤到裁判官或其他行使司法管辖权者面前，被传唤者都应到庭，以便确认传唤他的裁判者是否享有管辖权。

<a id="2.5.2.1"></a>**1.** 如果受传唤者未到庭，管辖该事项的裁判者可以在其权限范围内判处罚金；但应体谅此人的朴拙无知。此外，如果原告并无必要在该时点要求对方到庭，裁判官也会免除处罚，例如当日是停止办公的节日。

### <a id="2.5.3"></a>2.5.3　乌尔比安《评萨宾》第四十七卷

如果某人承诺到庭，却未约定未到庭时须支付罚金，那么应对其提起不确定之诉，要求赔偿原告因此所受的利益损失；这是最妥当的处理方式，塞尔苏斯也持此意见。
