# 第二卷

## <a id="2.15"></a>2.15　论和解

### <a id="2.15.1"></a>2.15.1　乌尔比安《评告示》第四十卷

进行和解的人，是在争议事项尚不确定、诉讼尚未终结时，就该事项达成和解。仅仅订立协议的人，则出于赠与目的，以慷慨方式免除一项确定无疑的债务。

### <a id="2.15.2"></a>2.15.2　乌尔比安《评告示》第七十四卷

所谓已经和解，不仅包括附加了阿奎利亚要式承诺的情形，也包括当事人订立协议的情形。

### <a id="2.15.3"></a>2.15.3　斯凯沃拉《学说汇纂》第一卷

<a id="2.15.3.pr."></a>**序言。** 安东尼努斯皇帝和维鲁斯皇帝曾作如下答复：“毫无疑问，私人协议不得损害他人的权利。因此，继承人与死者之母之间订立的和解，既不能视为撤销遗嘱，也不能剥夺已获解放的奴隶或遗赠受领人的诉权。因此，凡依据遗嘱提出请求的人，都应起诉遗嘱指定的继承人。该继承人如果在遗产和解中，就遗产所负债务为自己提供了担保，应按其担保处理；如果没有提供担保，就不得将自己的疏忽归咎于他人并使他人受损。”

<a id="2.15.3.1"></a>**1.** 如果当事人因遗嘱信托而达成和解，后来又发现补充遗嘱文件，我问：死者之母从和解中所得少于其应得份额的部分，是否可以依据遗嘱信托请求？答复：可以。

<a id="2.15.3.2"></a>**2.** 一名债务人所提供的质物已由债权人出售。债务人以极低金额与麦维乌斯达成和解；麦维乌斯自称是债权人的合法继承人。后来出示遗嘱，才发现塞普提基乌斯才是继承人。我问：如果债务人依据质押之诉起诉塞普提基乌斯，后者是否可以援用与麦维乌斯达成的和解抗辩，因为麦维乌斯当时并非继承人？塞普提基乌斯能否通过债权返还之诉，追回债务人作为继承人名义向麦维乌斯支付的款项，仿佛麦维乌斯是借继承之名收取该款？答复：根据所陈述的事实，不能；因为塞普提基乌斯本人并未订立和解，麦维乌斯也不是以管理塞普提基乌斯事务之人的身份收取款项。

### <a id="2.15.4"></a>2.15.4　乌尔比安《评萨宾》第四十六卷

阿奎利亚要式承诺无论如何都会更新并消灭此前的一切债务关系；其本身又会通过要式免债行为而消灭。这是我们遵循的规则。因此，即使是附条件遗赠，也可以纳入阿奎利亚要式承诺。

### <a id="2.15.5"></a>2.15.5　帕皮尼安《定义集》第一卷

订立阿奎利亚要式承诺时，该承诺以当事人合意为基础；但未曾考虑到的争议，仍保持原有状态。法学家的解释限制了利用慷慨之名进行欺诈的行为。

### <a id="2.15.6"></a>2.15.6　盖尤斯《评行省告示》第十七卷

对于源自遗嘱的争议，除非查阅并了解遗嘱的文字，否则既不能和解，也无法通过其他方式查明真相。
