# 第二卷

## 2.4　论传唤到庭（续）

#### 2.4.10　乌尔比安《评告示》第五卷（续）

<a id="2.4.10.7"></a>**7.** 保护人的养父母也受告示保护，但仅限收养关系持续期间。

<a id="2.4.10.8"></a>**8.** 如果我的儿子被交付收养，他不得被我的自由释奴传唤到庭；进入收养家庭的孙子也同样如此。但如果我已解放出家父权的儿子收养了一个儿子，那么这个孙子可以被传唤到庭，因为他与我无亲属关系。

<a id="2.4.10.9"></a>**9.** 关于“子女”的范围，依卡西乌斯之见，与“父母”的范围相同，也包括三世孙以后的后代。

<a id="2.4.10.10"></a>**10.** 如果一名自由女释奴为其保护人生了孩子，她与该子不得相互传唤到庭。

<a id="2.4.10.11"></a>**11.** 如果保护人的子女指控其父亲的自由释奴犯有死罪，或请求将其交付为奴，他们便不应享有保护人子女所应受的敬重。

<a id="2.4.10.12"></a>**12.** 裁判官规定：“未经我的许可，任何人不得将他人传唤到庭。”如果诉讼并非使人蒙受恶名，或并非有损其名誉，裁判官就会准许传唤；涉及保护人或父母的案件，均应如此。裁判官必须审查具体情形后作出决定。佩狄乌斯认为，有时即使案件可能使人蒙受恶名，也应准许自由释奴传唤保护人；例如保护人对其造成极其严重的侵害，甚至用鞭子抽打他。

<a id="2.4.10.13"></a>**13.** 即使保护人以监护人、保佐人、辩护人或代理人的身份参与诉讼，也始终应当向其表示这种敬重。但如果出庭的是保护人的监护人或保佐人，庞波尼乌斯写道，可以不受处罚地传唤他们；这一意见更为正确。
