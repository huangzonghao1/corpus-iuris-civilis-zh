# 第二卷

## <a id="2.12"></a>2.12　论休庭日、延期及各种期限

### <a id="2.12.1"></a>2.12.1　乌尔比安《论各类审判庭》第四卷

<a id="2.12.1.pr."></a>**序言。** 神圣马尔库斯皇帝的诏谕规定，任何人不得在收获季或葡萄采收季强令对方前往法庭，因为忙于农事者不应被强行召至法庭。

<a id="2.12.1.1"></a>**1.** 但是，如果裁判官因不知情或疏忽而仍坚持传唤这些人，而他们又自愿到庭：若他们在场且自愿进行诉讼，裁判官作出判决的，该判决有效，尽管传唤他们的人行事不当。反之，如果他们坚持不到庭，而裁判官在他们缺席时作出判决，则应认为该判决毫无效力（因为裁判官的行为不应减损法律效力）；因此，无须提起上诉，该判决即告无效。

<a id="2.12.1.2"></a>**2.** 有些特定事由例外；即使在收获季或葡萄采收季，我们也可能被强令到裁判官处。例如，争议事项可能因时间经过而灭失，也就是延期将使诉权消灭。每当情况紧迫，我们固然必须到裁判官处，但公平而言，只能强令我们到庭至足以使争讼程序确定为止；马尔库斯皇帝的诏谕措辞也明确表达了这一点。最后，正式受理诉讼后，如果任一方拒绝继续诉讼，诏谕准许延期。

### <a id="2.12.2"></a>2.12.2　乌尔比安《评告示》第五卷

神圣马尔库斯皇帝在元老院宣读的同一诏谕还规定，即使在休庭日，遇有其他特定事项，也可以请求裁判官处理，例如：指定监护人或保佐人；提醒怠于履行职责者履职；提出免责事由；确定扶养费；证明年龄；为胎儿利益准许占有；为保存财产、遗赠或信托利益、预防未发生的损害而准许占有；请求出示遗嘱；为继承人身份尚不确定者的遗产指定管理人；扶养子女、父母或保护人；接受可能负债的遗产；当场评定侵害是否严重；以及履行遗嘱信托所指定的解放奴隶义务。

### <a id="2.12.3"></a>2.12.3　乌尔比安《评告示》第二卷

<a id="2.12.3.pr."></a>**序言。** 即使在收获季或葡萄采收季，也通常会审理那些可能因时间经过或当事人死亡而灭失的事项。因当事人死亡而可能灭失的事项，例如盗窃、非法造成损害、严重侵害，以及被指称在火灾、房屋倒塌、船舶失事或船只遭袭后实施掠夺的案件；其他类似案件亦同。争议事项可能因时间经过而灭失，或诉权期限即将届满的，也同样如此。

<a id="2.12.3.1"></a>**1.** 涉及自由身份的诉讼，也可以在任何时候审结。

<a id="2.12.3.2"></a>**2.** 对于以集市名义、违背公共利益收取财物的人，也可以在任何时候进行审理。

### <a id="2.12.4"></a>2.12.4　保罗《评告示》第一卷

行省总督通常依各地习惯，为收获季和葡萄采收季确定相应期限。

### <a id="2.12.5"></a>2.12.5　乌尔比安《评告示》第六十二卷

元旦前一日，官职人员通常既不行使司法职权，也不提供处理本人事务的机会。

### <a id="2.12.6"></a>2.12.6　乌尔比安《评告示》第七十七卷

法律规定，如果在休庭日作出判决，除非当事人同意，否则该日不得进行诉讼；凡违反此规定作出的判决，任何人均无须据以执行或履行，也无须据以付款；任何人亦不得强迫因该事项而向其请求司法救济者执行该判决。

### <a id="2.12.7"></a>2.12.7　乌尔比安《论执政官职务》第一卷

神圣马尔库斯皇帝的诏谕明确规定，因提交诉讼文书而提出的延期，不得给予超过一次。但是，为顾及诉讼当事人的利益，经查明具体情形后，通常也会准许第二次延期；无论所涉文书来自同一行省还是另一行省，延期时间均应依路程等具体情况酌定，尤其是在出现意外情形时。还应考虑：如果死者曾因诉讼文书获准延期，其继承人是否也应获准延期，还是因为已经给予一次延期而不得再给？较妥当的看法是，此处也应在查明具体情形后准许延期。

### <a id="2.12.8"></a>2.12.8　保罗《评萨宾》第十三卷

依罗马人的计算方法，一日自午夜开始，至次日午夜结束。因此，在这二十四小时内，也就是两个半夜及其间白昼之内所实施的任何行为，均视同在白昼的任一时刻实施。

### <a id="2.12.9"></a>2.12.9　乌尔比安《论行省总督职务》第七卷

神圣图拉真皇帝曾向米尼基乌斯·纳塔利斯作出书面答复：休庭日仅使人免于办理司法事务；涉及军事纪律的事项，即使在休庭日也必须办理，其中也包括对羁押事项的审查。

### <a id="2.12.10"></a>2.12.10　保罗《格言集》第五卷

在所有金钱案件中，每一案件获准延期不得超过一次；在死刑案件中，被告可以获准延期三次，控告人可以获准延期两次；两类案件均应根据具体情形决定。
