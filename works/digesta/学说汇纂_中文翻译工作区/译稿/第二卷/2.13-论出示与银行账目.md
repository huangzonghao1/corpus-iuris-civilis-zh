# 第二卷

## <a id="2.13"></a>2.13　论出示（诉讼依据与账簿）

### <a id="2.13.1"></a>2.13.1　乌尔比安《评告示》第四卷

<a id="2.13.1.pr."></a>**序言。** 任何人想依据某项诉权提起诉讼，都必须将该诉权出示。因为由准备起诉者出示其诉权，显然最为公平；这样，被告便知道自己应当承认请求还是继续争辩；如果他认为有必要继续争辩，也可以在知悉自己被依据何种诉权起诉后，准备应诉。

<a id="2.13.1.1"></a>**1.** 所谓出示，也包括提供抄录的机会：可以将诉权写入书面文件交给对方，也可以口头宣读。拉贝奥认为，带对方到告示板前，指出自己准备宣读的内容，或者说明自己准备使用何种诉权，也属于出示。

<a id="2.13.1.2"></a>**2.** 出示诉权时不应写明日期和执政官姓名，以免在出示后另行编造内容，再将其伪装成较早形成的文书。裁判官排除的是文书制作的日期和执政官姓名，而非约定清偿的日期；因为清偿日与金额一样，都是要式承诺的重要部分。不过，账目出示时应写明日期和执政官姓名，因为若不列出日期和执政官姓名，收支便无法辨明。

<a id="2.13.1.3"></a>**3.** 凡某人准备在法官面前提交的一切材料，均应出示；但不得强令他出示其并不打算使用的文书。

<a id="2.13.1.4"></a>**4.** 未完整出示整项要式承诺者，不视为已出示。

<a id="2.13.1.5"></a>**5.** 因年龄、朴拙无知或性别而疏忽未出示的人，或者因其他正当事由未出示的人，应获救济。

### <a id="2.13.2"></a>2.13.2　保罗《评告示》第三卷

如果有人请求遗赠，裁判官不命令其出示遗嘱原文；或许是因为继承人通常持有遗嘱副本。

### <a id="2.13.3"></a>2.13.3　毛里基乌斯《论刑罚》第二卷

元老院决议规定：有人代表国库向某人请求财物时，不得强令被请求者向告发人出示与其所申报事由无关的其他文书；告发人只能要求出示与其所称告发依据有关的文书。

### <a id="2.13.4"></a>2.13.4　乌尔比安《评告示》第四卷

<a id="2.13.4.pr."></a>**序言。** 裁判官规定：“银行业经营者应出示与请求人有关的账目，并注明日期和执政官姓名。”

<a id="2.13.4.1"></a>**1.** 该告示的理由最为公允：银行家为每个人编制账目，既然他是为我而编制，那么将其作为某种属于我的文书出示给我，当然公平。

<a id="2.13.4.2"></a>**2.** 家子也包括在这些措辞之内，因此可以强令家子本人出示账目。至于父亲是否也包括在内，则有疑问。拉贝奥写道，除非父亲知情，否则不得强令父亲出示；但萨宾的答复较为妥当：如果父亲从该项业务中取得收益，就应准许强令其出示。

<a id="2.13.4.3"></a>**3.** 如果奴隶经营银行业（这是可能的），若其经主人同意而经营，则应强令主人出示账目，并应像主人亲自经营一样对其授予诉权。若奴隶未经主人知情而经营，主人只须宣誓自己并无该等账目，即已足够。如果奴隶以特有产经营银行业，主人依特有产之诉或利益归入之诉承担责任；但是，如果主人持有账目却不出示，则应承担全部责任。

<a id="2.13.4.4"></a>**4.** 已停止经营银行业的人，仍可被强令出示账目。

<a id="2.13.4.5"></a>**5.** 某人应在其经营银行业的地点被强令出示账目，这是既定规则。如果账簿存放在一个行省，而银行业务在另一行省经营，我认为，应在其经营银行业务的地点强令出示；因为他首先违反规则之处，就是将账簿转移到别处。如果银行业务在一地经营，却在另一地被要求出示账簿，则不得强令其亲自前往；但如果请求人愿意承担费用，可以要求他在诉讼进行地提供抄件。

### <a id="2.13.5"></a>2.13.5　保罗《评告示》第三卷

还应给予其足够时间，以便将这些账目送达。

### <a id="2.13.6"></a>2.13.6　乌尔比安《评告示》第四卷

<a id="2.13.6.pr."></a>**序言。** 如果某位银行家像其中许多人那样，把账簿放在别墅或仓库里，他可以带请求人前往该处，或者交付账目的抄本。

<a id="2.13.6.1"></a>**1.** 银行家的继承人也会被强令出示账目。如果有数名继承人，而只有一人持有账目，则仅强令该人出示；但如果所有继承人都持有账目，即使其中一人已经出示，也应强令其他人一并出示。因为，如果出示账目的人地位低微、名声不佳，以致人们有理由怀疑其出示内容的可信性呢？因此，为了能够相互比对账目，其他人也应出示账目，或至少在其中一人的出示本上签名。请求数名银行家出示账目时，同样适用此规则。如果数名监护人共同管理监护事务，也应由所有人出示账目，或在一人的出示本上签名。

<a id="2.13.6.2"></a>**2.** 银行家的对方当事人必须宣誓，其请求出示账目并非为了诬诉或骚扰；以免有人仅为骚扰银行家而请求出示多余账目，或请求出示自己已经持有的账目。

<a id="2.13.6.3"></a>**3.** 拉贝奥认为，账目是为自身营业目的而进行的双向给付、收受、借贷、负担义务及清偿等业务；单纯清偿一项债务，并不开始形成账目。如果某人收受了质物或接受委托，也不得强令其出示账目，因为这些事项不属于账目业务。但是，银行家承诺支付的款项也应当记入并出示，因为这同样属于银行业务。

<a id="2.13.6.4"></a>**4.** 依此告示，可以提起诉讼，请求赔偿未出示账目所造成的利益损失。

<a id="2.13.6.5"></a>**5.** 由此可见，该告示仅在账目与请求人有关时才适用。如果你是依我的委托处理账目，该账目便与我有关。如果我不在场时，我的诉讼代理人曾作出委托，那么是否也应出示账目，因为账目与我有关？较妥当的看法是应当出示。我的诉讼代理人也有权要求出示与其本人有关的账目，我对此并无疑问；若他并未受我委托，则应承诺我将追认其行为。

<a id="2.13.6.6"></a>**6.** 如果账簿开头标明日期，记载提图斯的账目；此后记载我的账目时却未标明日期和执政官姓名，那么也应为我的账目补出日期和执政官姓名；因为日期和执政官姓名是所有账目共同的标题。

<a id="2.13.6.7"></a>**7.** 所谓出示，可以是口头宣读、交付书面文件，或出示账簿。

<a id="2.13.6.8"></a>**8.** 裁判官规定：“经查明具体情形后，我将命令银行家或再次请求出示账目的人出示账目。”

<a id="2.13.6.9"></a>**9.** 裁判官基于如下理由，禁止银行家请求他人向自己出示账目：银行家本人能够查阅其专业账簿；既然他正是负有出示义务的人，再请求他人向自己出示，实属荒谬。至于是否也不应向银行家的继承人出示账目，则有待考察。如果银行家的账簿已经由继承人取得，就不应向该继承人出示；如果继承人未取得账簿，则可根据具体情形命令出示。即使银行家本人，也可基于正当事由请求出示账目：例如他证明自己因船舶失事、房屋倒塌、火灾或类似事故而丢失账目，或者账目存放在遥远之处，例如海的另一边。

<a id="2.13.6.10"></a>**10.** 裁判官不命令再次请求者出示账目，除非存在正当事由。

### <a id="2.13.7"></a>2.13.7　保罗《评告示》第三卷

<a id="2.13.7.pr."></a>**序言。** 例如，请求人证明先前出示的账目存放在外地；或者先前出示并不完整；或者账目因重大意外而丢失，并非因疏忽而丢失。如果账目因可获宽恕的事故灭失，裁判官将命令重新完整出示。

<a id="2.13.7.1"></a>**1.** “再次”一词有两种含义：一种表示第二次，也就是希腊语所称的 *deuteron*；另一种也包括此后的多次，也就是希腊语所称的 *palin*，意为“每当有必要时”。某人可能两次出示账目后又将其遗失；因此，“再次”一词也可解释为“多次”。

### <a id="2.13.8"></a>2.13.8　乌尔比安《评告示》第四卷

<a id="2.13.8.pr."></a>**序言。** 银行家只有以恶意欺诈不出示账目时，才依该告示受罚；除非其过失已接近恶意欺诈，否则不承担责任。以恶意欺诈不出示账目，既包括恶意地出示账目，也包括完全不予出示。

<a id="2.13.8.1"></a>**1.** 受到该告示约束的人，应赔偿的，是裁判官作出命令时我因账目未获出示所受的利益损失，而不是我今天的利益损失。因此，即使我的利益损失后来消失，或变得较少、较多，也不得因此免除或增加诉额。

### <a id="2.13.9"></a>2.13.9　保罗《评告示》第三卷

<a id="2.13.9.pr."></a>**序言。** 有些人虽有义务向我们出示账目，但裁判官并不依据此项告示强令其出示。例如，诉讼代理人管理了我们的事务或账目，裁判官不会以可能提起事实之诉为压力强令其出示；因为我们可以通过委任之诉实现这一目的。又如，合伙人以欺诈方式处理事务，裁判官也不依据此项告示介入，因为可以提起合伙之诉。裁判官也不强令监护人向被监护人出示账目；通常可以通过监护之诉强令其出示。

<a id="2.13.9.1"></a>**1.** 如果银行家的继承人、父亲或主人从事同一职业，则是否与银行家相同，并不重要；因为他们承继银行家的地位和权利，应履行其职责。银行家将账目遗赠给某人，该受遗赠人不属于此处所指之人，因为这些措辞所说的是法律上的继受人；如同银行家生前将账目赠与他人，情形亦然。继承人也不承担责任，因为他既不持有账目，也未以欺诈手段造成不出示。但是，如果继承人在将账目交给受遗赠人之前，已被告知暂不得交付，那么他将像实施欺诈一样承担责任；在实际交付账目之前，他也可能承担责任。如果他并未实施欺诈，则经查明具体情形后，可以强令受遗赠人出示账目。

<a id="2.13.9.2"></a>**2.** 庞波尼乌斯写道，强令货币兑换人出示账目也并非不公；因为货币兑换人与银行家一样编制账目，他们分次收取并支出款项，而这些款项的证明主要记载在他们的账簿和记录中；人们也经常依赖这些记录的可信性。

<a id="2.13.9.3"></a>**3.** 此外，裁判官规定：凡请求出示与自身有关账目并宣誓并非为了诬诉者，均应获准请求出示。

<a id="2.13.9.4"></a>**4.** 账目与我们有关，不仅包括我们本人订立交易或继承订立交易者的情形，也包括受我们权力支配的人订立交易的情形。

### <a id="2.13.10"></a>2.13.10　盖尤斯《评行省告示》第一卷

<a id="2.13.10.pr."></a>**序言。** 裁判官命令银行家出示账目；争议究竟发生在请求人与银行家之间，还是与其他人之间，并不重要。

<a id="2.13.10.1"></a>**1.** 裁判官之所以只强令银行家出示账目，而不强令其他类似职业者出示，是因为银行家的职务和服务涉及公共利益；其主要职责就是认真编制自身业务的账目。

<a id="2.13.10.2"></a>**2.** 所谓出示账目，应理解为从头开始出示；如果不从账目开头查阅，就无法理解账目。也就是说，并非任何人都可以查阅和抄录整本账簿及全部账页，而只能查阅并抄录与其证明案件有关的账目部分。

<a id="2.13.10.3"></a>**3.** 依据此项诉讼，请求人可以请求赔偿因账目未被出示而受到的利益损失。因此，如果某人被判败诉，或因没有账目来支持自己的主张而未能获得所请求之物，那么他可以通过此项诉讼追回因此丧失的利益。但这是否可行，还应进一步考察：如果他现在能够在审理他与银行家争议的法官面前证明自己本可在先前败诉的案件中胜诉，那么他当时也本可提出证明；如果他没有提出证明，或者虽提出证明而法官不予考虑，他就应当责怪自己或法官。但事实并非总是如此：有可能他现在才从银行家处或通过其他方式取得账目，或者取得其他文书或证人证言；这些材料是他当时因某种原因无法使用的，而现在足以证明他本可胜诉。正如担保文书被窃取或毁坏时，可以提起债权返还之诉及非法损害之诉一样：先前因担保文书被扣留而无法证明、并因此丧失的事项，现在可以用当时无法使用的其他文书或证人证言加以证明。

### <a id="2.13.11"></a>2.13.11　莫德斯蒂努斯《规则集》第三卷

通说认为，文书副本即使没有出示者的签名，也可以出示。

### <a id="2.13.12"></a>2.13.12　卡利斯特拉图斯《告示集》第一卷

妇女不得从事银行家职务，因为该项工作属于男性之职。

### <a id="2.13.13"></a>2.13.13　乌尔比安《评告示》第四卷

此项诉讼不得在一年之后提起，也不得针对继承人提起，除非责任源于继承人本人的行为。但是，此项诉讼可以由继承人提起。
