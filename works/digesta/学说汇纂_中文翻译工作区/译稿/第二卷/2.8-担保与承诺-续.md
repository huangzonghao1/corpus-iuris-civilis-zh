# 第二卷

## 2.8　论应提供担保、宣誓承诺或依其承诺承担责任者（续）

### <a id="2.8.8"></a>2.8.8　保罗《评告示》第十四卷

<a id="2.8.8.pr."></a>**序言。** 诉讼当事人通常会约定在担保要式中写明履行日期。如果双方未作约定，佩狄乌斯认为，由约定担保的一方在合理期限内确定日期；具体期限应由裁判者裁定。

<a id="2.8.8.1"></a>**1.** 以妇女作为担保人，不视为已提供有效担保；军人和未满二十五岁者也不得被认可为担保人。但如果这些人是为自己的利益提供担保，例如为自己的代理人担保，则不在此限。有人还认为，如果丈夫请求交付嫁资土地，妻子可以为自己的利益提供担保。

<a id="2.8.8.2"></a>**2.** 如果发现某奴隶在诉讼正式受理之前，就曾承诺保证判决获得履行，应当救济原告，令其重新取得担保。未满二十五岁者也应获得救济；或许妇女因缺乏经验，也应如此。

<a id="2.8.8.3"></a>**3.** 如果保证判决履行的保证人成为担保受领人的继承人，或担保受领人成为保证人的继承人，就应重新提供担保。

<a id="2.8.8.4"></a>**4.** 监护人和保佐人为了保证未成年人财产无损，应获准前往市镇提供担保，因为此处的担保属于强制担保。关于返还财产给所有权人的担保——该所有权人的财产使用收益权已授予他人——也适用同一规则。遗赠受领人为了在遗产被追夺时返还遗赠，以及返还其依据《法尔基第法》多取得的部分，也应获准前往市镇提供担保。继承人为遗赠提供担保的，同样应获准前往市镇。

“显然，如果遗赠受领人已被准许占有财产，而继承人又阻止其提供担保；此后继承人请求退出占有，并表示愿意在市镇提供担保，就不应准许他这样做。但如果遗赠受领人并非由于继承人的过错或恶意而被准许占有，情况则不同。”

<a id="2.8.8.5"></a>**5.** 应要求当事人宣誓并非出于诬诉或恶意，以免有人只是为了骚扰对方，明明可以在罗马提供担保，却故意要求前往市镇。某些人可以免除此项反诬诉宣誓，例如父母和保护人。被准许前往市镇的人应宣誓：“我在罗马无法提供担保，但在请求前往的地方可以提供；我这样做并非出于恶意。”不得强迫他宣誓“除该地以外，我在任何地方都不能提供担保”；因为如果他在罗马不能提供、但在其他几个地方可以提供，就会被迫作伪证。

<a id="2.8.8.6"></a>**6.** 只有在存在正当理由时，才会准许他这样做。比如，他先前在市镇时就不愿提供担保，那么此时便不应准许；因为他本人造成了自己未能在所请求前往的地点提供担保这一结果。
