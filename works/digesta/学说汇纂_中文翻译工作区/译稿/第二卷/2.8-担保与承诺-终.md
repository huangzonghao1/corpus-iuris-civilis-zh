# 第二卷

## 2.8　论应提供担保、宣誓承诺或依其承诺承担责任者（续）

### <a id="2.8.9"></a>2.8.9　盖尤斯《评行省告示》第五卷

设仲裁人负责审查保证人是否适格；如果其裁断在任一方面显失公允，当事人可以像对法官的裁判那样向其提起上诉。〔译注：底本此处作“ab ed atque”；疑为“ab eo atque”之讹，译文据上下文处理。〕

### <a id="2.8.10"></a>2.8.10　保罗《评告示》第七十五卷

如果保证人已获仲裁人认可，就应视为有清偿能力，因为当事人本可向有管辖权的法官申诉；该法官可以根据具体情形否定仲裁人认可的保证人，也可以认可仲裁人否定的保证人。更何况，如果当事人自愿接受这些保证人，就应满足于此。但是，如果在此期间保证人遭遇重大灾祸或陷入严重贫困，经审查具体情形后，应重新提供担保。

### <a id="2.8.11"></a>2.8.11　乌尔比安《评告示》第七十五卷

尤利安说：如果我尚未委托你请求取得一块土地时，你已因准备请求该土地而收受担保，之后又依我的委托开始提起诉讼，则保证人应承担责任。〔译注：底本在 *antequam* 后又附有“ante, quam”，其性质不明，译文保留句义，异文见疑难表。〕

### <a id="2.8.12"></a>2.8.12　乌尔比安《评告示》第七十七卷

众所周知，附条件继承人于条件尚未成就时占有遗产的，应向替代继承人就遗产提供担保；如果条件未成就，替代继承人可以接受遗产并请求返还遗产；如果其胜诉，担保要式承诺即告发生效力。多数情况下，即使条件尚未成就，或者请求遗产的日期尚未到来，裁判官也常依具体情形命令当事人订立该项担保要式承诺。

### <a id="2.8.13"></a>2.8.13　保罗《评告示》第七十五卷

如果有数名替代继承人，也应分别向每一人提供担保。

### <a id="2.8.14"></a>2.8.14　保罗《答复集》第二卷

家子为其缺席的父亲进行诉讼防御。我问：他是否应提供保证判决获得履行的担保？保罗答复：为缺席者进行诉讼防御的人，即使他是其子或父亲，也应依告示规定的形式，向提出请求者提供担保。

### <a id="2.8.15"></a>2.8.15　马克尔《论上诉》第一卷

<a id="2.8.15.pr."></a>**序言。** 应当知道，不得强令不动产占有人提供担保。

<a id="2.8.15.1"></a>**1.** 所谓占有人，是指在乡间或城市占有土地者，无论其占有全部还是部分。占有缴纳地租的土地——即永佃土地——的人，也视为占有人。同样，仅享有所有权的人，也视为占有人。乌尔比安则写道，仅享有用益权的人不属于占有人。

<a id="2.8.15.2"></a>**2.** 取得质物的债权人不是占有人，即使占有已移交给他，或者他已将该物以容许占有的方式交还债务人占有，也不例外。

<a id="2.8.15.3"></a>**3.** 如果一块土地已作为嫁资交付，妻子和丈夫均因占有该土地而被视为占有人。

<a id="2.8.15.4"></a>**4.** 对土地享有债权性请求权的人，情形则不同。

<a id="2.8.15.5"></a>**5.** 监护人无论是其被监护人占有，还是监护人本人占有，均视为处于占有人地位；如果数名监护人中有一人是占有人，也应作同样处理。

<a id="2.8.15.6"></a>**6.** 如果你向我请求返还我所占有的土地，继而法院判决对你有利，而我提起上诉，那么我是否仍是该土地的占有人？正确的说法是，我仍为占有人，因为我依然占有该土地；即使该占有可能被剥夺，也与此无关。

<a id="2.8.15.7"></a>**7.** 某人是否为占有人，应以提供担保时为判断时点。正如某人在提供担保后出售其占有的土地，不会因此受不利影响；同样，某人在提供担保后才开始占有土地，也不会因此受益。

### <a id="2.8.16"></a>2.8.16　保罗《评告示》第六卷

以宣誓方式承诺将到庭的人，如果基于法律所准许的事由而未能到庭，不视为作了伪证。
