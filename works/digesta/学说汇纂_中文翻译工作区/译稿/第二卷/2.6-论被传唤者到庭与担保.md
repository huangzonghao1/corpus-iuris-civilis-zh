# 第二卷

## <a id="2.6"></a>2.6　论被传唤者应到庭或提供担保

### <a id="2.6.1"></a>2.6.1　保罗《评告示》第一卷

告示规定，为保证被传唤者到庭而提供的担保人，应依被告的具体情形具有相应的清偿能力；但特定的亲属或受敬重者除外——对于这些人，告示命令接受任何担保人。例如，被传唤者是父母或保护人的情形，

### <a id="2.6.2"></a>2.6.2　卡利斯特拉图《警示告示论》第一卷

同样，被传唤者是女保护人、其子女、其妻或儿媳的情形也属例外。对于这些情形，应接受任何担保人；如果有人明知这些人的特殊关系，却拒绝接受担保，就可以对其提起罚金为五十奥里金币的诉讼，

### <a id="2.6.3"></a>2.6.3　保罗《评告示》第四卷

因为对于这些有特殊关系的人，担保人可以不具备通常要求的清偿能力。

### <a id="2.6.4"></a>2.6.4　乌尔比安《评告示》第四十八卷

如果某人承诺保证两人到庭，却只带到一人、未带到另一人，就不能认为其已履行承诺，因为其中一人并未被带到庭。
