# 第二卷

## <a id="2.7"></a>2.7　论不得强行带离将被传唤到庭之人

### <a id="2.7.1"></a>2.7.1　乌尔比安《评告示》第五卷

<a id="2.7.1.pr."></a>**序言。** 裁判官发布该告示，是为了以刑罚相威慑，制止那些以暴力将被传唤到庭者带离的人。

<a id="2.7.1.1"></a>**1.** 因此，庞波尼乌斯写道，即使行为人是奴隶，也应就奴隶提起诺克萨诉讼；但如果主人知情，则应受理针对主人的诉讼，而不要求主人交付奴隶承担责任。

<a id="2.7.1.2"></a>**2.** 奥菲利乌斯认为，如果被带离之人本来就不得被传唤到庭，例如父母、保护人及其他此类人，那么该告示不适用。我认为这一意见更为正确。事实上，如果传唤者有过错，带离者便没有过错。

### <a id="2.7.2"></a>2.7.2　保罗《评告示》第四卷

<a id="2.7.2.pr."></a>**序言。** 因为双方都违反告示：自由释奴传唤保护人到庭，另一方又以暴力将保护人带离。不过，自由释奴的处境更为不利，因为在同类违法行为中，他是提起诉讼的一方。

<a id="2.7.2.1"></a>**1.** 对于被传唤到错误地点的人，也应适用同样的公平原则；更确切地说，如果某人有权不在该处应诉，就不应视为有人以暴力将其带离。

### <a id="2.7.3"></a>2.7.3　乌尔比安《评告示》第五卷

<a id="2.7.3.pr."></a>**序言。** 如果有人将被传唤到庭的奴隶带离，佩狄乌斯认为该告示不适用，因为奴隶并非可以被传唤到庭的主体。那么应如何处理？可以提起要求出示奴隶之诉。

<a id="2.7.3.1"></a>**1.** 如果有人将被传唤到基层裁判官（*iudex pedaneus*）面前的人带离，该告示的罚则不适用。

<a id="2.7.3.2"></a>**2.** 裁判官说的是“以暴力带离”：这要求暴力，还是也包括恶意？即使没有恶意，只要使用了暴力，也已足够。

### <a id="2.7.4"></a>2.7.4　保罗《评告示》第四卷

<a id="2.7.4.pr."></a>**序言。** 庞波尼乌斯说，“带离”一词含义广泛。“强行夺走”是指用抢夺方式从他人手中夺走；“带离”则是以任何方式将人移走。例如，有人没有把某人抢走，却拖延不让他到庭，直至诉讼期间届满，或使其因时效而丧失权利，这就视为已经带离，尽管并未在身体上将其带走。即使将他留在原处、没有把他带走，也属于该用语涵盖的情形。

<a id="2.7.4.1"></a>**1.** 如果有人将因恶意诉讼而被传唤的人带离，公认他仍受该告示约束。

**2.** 裁判官还规定：“也不得以恶意行事，使某人更容易被带离。”有时即使没有恶意，也可能发生这种情形，例如带离者有正当理由。

### <a id="2.7.5"></a>2.7.5　乌尔比安《评告示》第五卷

<a id="2.7.5.pr."></a>**序言。** 如果某人通过他人将被传唤者带离，无论他在场还是不在场，都受本条款约束。

<a id="2.7.5.1"></a>**1.** 对以暴力带离他人的人，可以提起事实之诉。诉讼金额并非按实际损失计算，而是按原告对争议标的所作的估价计算。增设这一规则，是为了明确：即使被传唤者是恶意诉讼人，这项罚则仍可适用。

<a id="2.7.5.2"></a>**2.** 原告必须证明，由于被告带离被传唤者，该人因此未能被带到庭上。相反，如果尽管发生带离，该人仍被带到庭上，罚则便不适用；因为应当结合实际效果理解告示的文字。

<a id="2.7.5.3"></a>**3.** 这是一项事实之诉；如果多人均有违法行为，可以分别对每个人提起诉讼；即使如此，被带离者仍须对原诉承担责任。

<a id="2.7.5.4"></a>**4.** 只有在继承人自身利害关系所及的范围内，才可以对继承人提起该诉讼；不得针对继承人提起，也不得在一年之后提起。

### <a id="2.7.6"></a>2.7.6　乌尔比安《评告示》第三十五卷

以暴力带离债务人的人，即使支付了罚金，也不能使债务人免除债务，因为他支付的是自己的罚金。
