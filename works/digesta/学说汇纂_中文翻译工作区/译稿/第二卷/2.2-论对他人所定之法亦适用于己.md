# 第二卷

## <a id="2.2"></a>2.2　论任何人为他人所定之法，自己亦须适用同一法

### <a id="2.2.1"></a>2.2.1　乌尔比安《评告示》第三卷

<a id="2.2.1.pr."></a>**序言。** 该告示极为公平正义，且不会引起任何人的不满：谁会鄙弃同一规则适用于自己，而这规则正是他曾适用于他人或促使他人适用的呢？

<a id="2.2.1.1"></a>**1.** 告示规定：“凡担任官职或掌有权力者，如果曾对某人确立一项新的法律规则，那么在日后其对方提出请求时，他自己也必须适用同一规则。如果有人曾在担任官职或掌有权力者面前取得一项新的法律规则，那么日后应其对方请求，也应依同一规则对他作出裁断。”也就是说，一个人既然认为某规则适用于他人是公平的，就应容许该规则同样适用于自己。

<a id="2.2.1.2"></a>**2.** 我们对“行使司法管辖权者所确立的规则”这一用语，应按其实际效果理解，而不能只看字面。因此，如果某人本想确立规则，却受到阻止，且裁断没有发生效力，该告示便不适用。“确立”一词指已经完成的行为和已经造成的侵害，而非仅仅着手实施。由此，如果某人在自己并无管辖权的人之间作出裁断，因为这种裁断被视为无效、并非真正判决，我们认为该告示不适用。毕竟，若侵害没有造成任何效果，单有企图又造成了什么损害呢？

### <a id="2.2.2"></a>2.2.2　保罗《评告示》第三卷

该告示应惩罚行使司法权者的欺诈。如果由于司法顾问疏忽、不慎，裁判者作出了不当的法律处理，这不应使官员本人受不利影响，而应由司法顾问本人承担后果。

### <a id="2.2.3"></a>2.2.3　乌尔比安《评告示》第三卷

<a id="2.2.3.pr."></a>**序言。** 如果有人请求并取得对他人不公的法律处理，只有在该处理系应其请求而作出时，他才可以援用该处理；如果并非应他请求作出，则不对他加以制裁。不过，只要他曾请求取得该处理，无论他已经援用了该规则，还是虽未实际援用但已取得以该规则为其所用的裁断，均应依该告示受到处罚。

<a id="2.2.3.1"></a>**1.** 如果我的代理人提出了请求，谁应适用同一规则？庞波尼乌斯认为，只有我本人适用；当然，前提是我曾特别授权他这样做，或事后予以追认。不过，如果提出请求的是精神失常者或未成年人的监护人、保佐人，那么依该告示受制裁的是监护人或保佐人本人。代理人若是为自己的利益而受任，也适用同一规则。

<a id="2.2.3.2"></a>**2.** 该项制裁适用于所有落入告示范围的人；提出请求的人不必是曾受其侵害者，任何日后提起诉讼的人都可以请求适用该制裁。

<a id="2.2.3.3"></a>**3.** 如果你为某人提供了承诺担保，而该人取得一项规则，使其债务人不得对他提出抗辩；随后你在自己曾提供担保的事务中也想援用该抗辩，那么你和该债务人都不应取得这一规则所赋予的利益；即使债务人无清偿能力、你有时因此受损，也是如此。不过，如果是你本人落入该告示的范围，被告仍可援用抗辩，而你不得援用。对你所作的制裁不及于该承诺的债务人，因此你也无权提起委任之诉。〔本段有关债务人抗辩、担保人责任及委任之诉的关系较为复杂，见疑难表。〕

<a id="2.2.3.4"></a>**4.** 如果我的儿子在担任官职期间违反该告示，那么我以其身份为据提起的诉讼是否也受该告示限制？我认为不应如此，以免使我的法律地位变得更不利。

<a id="2.2.3.5"></a>**5.** 裁判官说，行为人应适用同一规则。那么该项制裁是否也传及其继承人？尤利安写道，不仅应拒绝行为人本人提起诉讼，也应拒绝其继承人提起诉讼。

<a id="2.2.3.6"></a>**6.** 他还合理地写道，该告示的制裁不仅适用于行为人违反告示时已经拥有的诉讼，也适用于此后取得的诉讼。

<a id="2.2.3.7"></a>**7.** 尤利安认为，基于此原因已经支付的款项不得请求返还；因为仍存在阻止返还请求的自然债务原因。

### <a id="2.2.4"></a>2.2.4　盖尤斯《评行省告示》第一卷

裁判官以精当的方式规定了一项例外：“但如果他们中的任何人曾对某人作出过同样的行为，则不在此限。”规定这一例外是正确的，以免官员在努力维护该告示时，或诉讼当事人在试图援用该告示的利益时，自己反而违反告示并受其处罚。
