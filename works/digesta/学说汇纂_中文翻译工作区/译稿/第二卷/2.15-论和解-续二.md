# 第二卷

## 2.15　论和解（续）

### 2.15.8　乌尔比安《论各类审判庭》第五卷（续）

<a id="2.15.8.12"></a>**12.** 如果某人就扶养费达成和解，不应视为他也就住所或衣物供给达成和解；因为神圣马尔库斯皇帝曾明确规定，这些事项也必须分别处理。

<a id="2.15.8.13"></a>**13.** 同样，如果某人就扶养费达成和解，并不意味着他必须违背意愿，就住所或其他供养内容也一并和解；因此，当事人可以就全部事项一并和解，也可以只就其中某些事项和解。

<a id="2.15.8.14"></a>**14.** 鞋履费也应由裁判官酌情决定是否准许和解。

<a id="2.15.8.15"></a>**15.** 如果土地被遗赠给一人或数人作为扶养来源，而他们希望出售该土地，则裁判官必须裁定是否准许出售并和解。如果土地被遗赠给数人作为扶养来源，而他们彼此达成和解，未经裁判官授权的和解不发生效力。如果土地被抵押以保障扶养费，也不得未经裁判官审查而解除抵押。

<a id="2.15.8.16"></a>**16.** 和解全部扶养费或其中一部分，必须经裁判官裁定，这一点再清楚不过。

<a id="2.15.8.17"></a>**17.** 如果当事人请求裁判官处理，裁判官却未调查具体情形便准许和解，该和解毫无效力；此事项委托裁判官调查，而非任其疏忽或将利益拱手让出。如果裁判官未调查诏谕要求考察的全部事项——即和解事由、金额及当事人身份——即使他已调查其中某些事项，也应认为该和解无效。

<a id="2.15.8.18"></a>**18.** 无论行省总督还是裁判官，均不得将此类事项的司法管辖权委托他人。

<a id="2.15.8.19"></a>**19.** 如果扶养费是向国库请求的，也可以在皇帝代理官面前达成和解。依此规则，也可以在国库长官面前和解。

<a id="2.15.8.20"></a>**20.** 如果扶养费事项确有诉讼，而当事人通过和解解决了该诉讼，未经裁判官授权的和解不得生效，以免规避皇帝诏谕；否则当事人可能虚构诉讼，以便不经裁判官授权而和解。

<a id="2.15.8.21"></a>**21.** 如果某人既获遗赠扶养费，也获遗赠一笔应立即给付的遗赠；而当事人未经裁判官授权便达成和解，那么已支付的款项应先抵充该笔应立即给付的遗赠，超出部分再抵充扶养费。

<a id="2.15.8.22"></a>**22.** 如果某人未经裁判官授权就扶养费达成和解，已支付的款项应抵充此前到期的扶养费。无论所欠金额等于、多于或少于已支付金额，凡已支付的款项均应抵充既往扶养费。如果受领人因该项支付而变得更加富有，则公平而言，应准许返还请求，以返还其因此获得的利益；因为任何人都不应因他人受损而获利。

<a id="2.15.8.23"></a>**23.** 如果某位社会地位较高者获遗赠一笔固定的年度金额，例如年俸或用益权，则即使未经裁判官授权，也可以和解。但是，如果仅遗赠少量用益权作为扶养费，则我认为，未经裁判官授权的和解毫无效力。

<a id="2.15.8.24"></a>**24.** 如果遗赠给某人的并非金钱，而是谷物、橄榄油及其他生活必需品，无论按年还是按月给付，均不得就其达成和解。但是，如果当事人未经裁判官授权而约定以金钱代替这些物品按年或按月给付，且未改变给付日期或金额，只改变给付种类；或者反过来，约定以物品代替遗赠的金钱；或者以葡萄酒换橄榄油、以橄榄油换葡萄酒或换其他物品；或者改变领取地点，例如原本应在罗马领取的扶养费改在市镇或行省领取，或反之；或者改变受领人，例如原本应从数人处受领的改为从一人处受领；或者将一名债务人更换为另一名债务人，那么所有这些事项均应提交裁判官审查，并在有利于扶养费受领人时予以准许。

<a id="2.15.8.25"></a>**25.** 如果有人获遗赠一笔年度固定金额作为住所费用，而当事人未经裁判官授权，约定改为提供住所，则该和解有效，即使住所可能因房屋倒塌或火灾而受损亦然。反过来，如果原本遗赠的是住所，而双方约定改为支付固定金额，该和解即使未经裁判官授权也有效。
