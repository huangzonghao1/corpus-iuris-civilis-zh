# 第二卷

## <a id="2.10"></a>2.10　论因某人所为而致他人不能到庭

### <a id="2.10.1"></a>2.10.1　乌尔比安《评告示》第七卷

<a id="2.10.1.pr."></a>**序言。** 裁判官认为，惩治以欺诈手段阻止他人到庭的人，最为公允。

<a id="2.10.1.1"></a>**1.** 被认为实施恶意欺诈的，不仅包括亲自或通过自己的人扣留他人者〔译注：底本在 *retinuerit* 后附有“retinuit”，性质不明〕，也包括请求他人扣留或带走该人、以阻止其到庭者；无论受请求者是否知道其所策划之事，均是如此。

<a id="2.10.1.2"></a>**2.** 我们对恶意欺诈作如下理解：如果有人向正要前往法庭的人宣告某种令人悲痛之事，以致该人不得不到庭，那么依此告示，此人应承担责任；尽管有人认为，轻信此事者应归咎于自己。

<a id="2.10.1.3"></a>**3.** 如果被告因原告的欺诈而未能到庭，被告不得依据本告示对原告提起诉讼，因为如果原告依据要式承诺请求其支付未到庭的罚金，被告可满足于提出抗辩。若被告是受第三人阻止而未能到庭，则情形不同：被告可以对该第三人行使告示所规定的诉权。

<a id="2.10.1.4"></a>**4.** 如果数人均以欺诈方式实施该行为，所有人均承担责任；但其中一人已支付罚金的，其余人即获免责，因为没有必要再行追究。

<a id="2.10.1.5"></a>**5.** 众人一致认为，因上述事由应以奴隶为对象提起诺克萨之诉。

<a id="2.10.1.6"></a>**6.** 此项诉权也授予继承人，但不得超过一年。至于对继承人提起此项诉讼，我认为仅应限于防止继承人因被继承人的欺诈而获利。

### <a id="2.10.2"></a>2.10.2　保罗《评告示》第六卷

如果原告的奴隶明知主人知情且有能力阻止，却仍以欺诈手段致使我未能到庭，奥菲利乌斯认为，应准许我对主人提出抗辩，以免主人因奴隶的欺诈而获利。反之，如果奴隶未经主人同意而为，萨宾认为，应准许提起诺克萨之诉；奴隶的行为不应使主人受不利，除非主人因此丧失该奴隶，因为主人本人并无过错。

### <a id="2.10.3"></a>2.10.3　尤利安《学说汇纂》第二卷

<a id="2.10.3.pr."></a>**序言。** 依此告示，对以欺诈手段阻止被传唤到庭者到庭的人，可提起事实之诉，请求赔偿原告因该人未能到庭所遭受的利益损失。在该诉讼中，应计算原告因此所丧失的一切；例如，被告因时间经过而取得争议物的所有权，或者被告因诉权消灭而获释。

<a id="2.10.3.1"></a>**1.** 如果以欺诈手段阻止被传唤者到庭的人无清偿能力，那么应允许原告对被告本人提起回复原状之诉；这样可以防止被告因他人的欺诈而获利，并使原告免受损失。

<a id="2.10.3.2"></a>**2.** 如果要式承诺受领人因提图斯的欺诈、而要式承诺人因麦维乌斯的欺诈，分别被阻止到庭，那么双方均可对实施欺诈、阻止自己到庭之人提起事实之诉。

<a id="2.10.3.3"></a>**3.** 如果要式承诺受领人因要式承诺人的欺诈、而要式承诺人因要式承诺受领人的欺诈，彼此均被阻止到庭，裁判官不应救济其中任何一方，因为双方的欺诈应相互抵销。

<a id="2.10.3.4"></a>**4.** 如果我向保证人要式约定：若被告不到庭，保证人应支付五十；而我原本准备向被告请求一百；其后塞姆普罗尼乌斯以恶意欺诈阻止被告到庭，那么我可以向塞姆普罗尼乌斯请求一百。因为对我而言，所受利益损失显然是这一百：如果被告到庭，我本可对被告或其继承人提起请求一百的诉讼，尽管保证人向我承诺的金额较少。
