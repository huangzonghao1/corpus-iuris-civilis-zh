# 第二卷

## <a id="2.11"></a>2.11　论未遵守为到庭而作出的担保者

### <a id="2.11.1"></a>2.11.1　盖尤斯《评行省告示》第一卷

裁判官命令，按每日二万步计算行程，但不计提供到庭担保之日，也不计应当到庭之日。因为如此计算路程，对任何一方当事人都没有不当负担。

### <a id="2.11.2"></a>2.11.2　乌尔比安《评告示》第七十四卷

<a id="2.11.2.pr."></a>**序言。** 如果到庭担保所针对的争议已在应当到庭之日以前和解，我们不再要求被告到庭。但是，若在应当到庭之日以后才和解，则应提出欺诈抗辩：争议既已和解，谁还会为先前承诺的罚金而烦恼？即使有人认为，关于争议已经和解的抗辩会产生不利后果，仿佛连罚金也一并和解了，除非当事人明确约定相反情形，亦应如此处理。

<a id="2.11.2.1"></a>**1.** 如果某人因履行市镇职务而受阻、且并无自己的恶意欺诈，以致未依其承诺到庭，给予其抗辩最为公允。

<a id="2.11.2.2"></a>**2.** 同样，如果某人被要求出庭作证，却未能到庭，也应给予救济。

<a id="2.11.2.3"></a>**3.** 如果某人承诺到庭，却因疾病、暴风雨或河水暴涨而不能到庭，应以抗辩救济他，这样做并无不当。既然此项承诺要求本人到场，因疾病而受阻者又如何能够到庭？因此，《十二表法》也规定，如果法官或任何一方当事人因严重疾病受阻，审判日期应予延期。

<a id="2.11.2.4"></a>**4.** 如果妇女未到庭并非因病，而是因为怀孕，拉贝奥认为应给予她抗辩；但如果她在分娩后卧床不起，则应认为她是因疾病受阻。

<a id="2.11.2.5"></a>**5.** 某人开始精神失常时，亦同；因为受精神失常所阻，也属于因疾病受阻。

<a id="2.11.2.6"></a>**6.** 我们说，因暴风雨或河水暴涨而未能到庭者也应获救济；这里的暴风雨既包括海上的，也包括陆上的。所谓暴风雨，是指足以阻碍陆路行程或航行的天气。

<a id="2.11.2.7"></a>**7.** 河水暴涨的阻碍，即使没有暴风雨，也应纳入考虑。所谓河水暴涨，是指水势本身构成阻碍，或者桥梁被冲毁，或者没有可用的船只。

<a id="2.11.2.8"></a>**8.** 但是，如果某人本可因提早出发或在适当时机航行而避免遇上暴风雨或河水暴涨，却自行使自己陷入困境，那么抗辩是否不应适用于他？这应在查明具体情形后决定。既不能过分苛求他说“为何不在承诺到庭之日很久以前就出发”，也不能允许他在确有可归责于自己的情形时，仍以暴风雨或河水暴涨为借口。例如，某人在承诺到庭之时身处罗马，既无任何必要，却为了消遣前往市镇；难道这种人值得此项抗辩保护吗？又如，海上确有暴风雨，但他可以走陆路前往；或者可以绕过河流。也应说，此项抗辩并非总对他有利；除非地形狭窄等客观限制使其无法走陆路或绕行。但是，如果河水泛滥，淹没了应当到庭的整个地点；或者某种偶发灾祸摧毁了该地点，或使前往到庭者面临危险，那么依公平原则，也应给予他此项抗辩。

<a id="2.11.2.9"></a>**9.** 同样，如果某人本想前往法庭，却被官职人员扣留，而且扣留并非因其自身的恶意欺诈，也应给予抗辩；如果他自己促成了扣留，或提供了被扣留的理由，则不得适用此项抗辩。本人自己的欺诈对他不利；他人实施欺诈使其被扣留，则不对他不利。但是，如果扣留他的是私人，此项抗辩绝不适用。

### <a id="2.11.3"></a>2.11.3　保罗《评告示》第六十九卷

但是，被扣留者可以对扣留他的人提起诉讼，请求赔偿其利益损失。

### <a id="2.11.4"></a>2.11.4　乌尔比安《评告示》第七十四卷

<a id="2.11.4.pr."></a>**序言。** 如果某人在被判处死刑或流放后，因此无法到庭，理应宽恕他。所谓被判处死刑者，是指受到死刑或流放处罚的人。有人或许会问：既然如此，这项抗辩对已被定罪者有何用？对此可以答复：其保证人需要此项抗辩；或者，如果他被允许离开而未危及国家、并已前往流放地，那么此项抗辩可由他的诉讼防御人提出。

<a id="2.11.4.1"></a>**1.** 应当知道，某人若因成为死刑案件被告而未到庭，其情形并不允许他使用此项抗辩，因为该抗辩是给予已被定罪者的。但是，如果某人因枷锁或军事拘禁而受阻、因而未到庭，则可以使用此项抗辩。

<a id="2.11.4.2"></a>**2.** 此外，某人因家中丧葬之事受阻而未到庭，也应给予他抗辩。

<a id="2.11.4.3"></a>**3.** 同样，如果某人被敌人俘虏，因而未能到庭，也应以抗辩救济他。

<a id="2.11.4.4"></a>**4.** 有人问，能否约定在到庭承诺未履行时不得提出任何抗辩。阿提利基努斯认为，这种约定无效。但我认为，如果当事人明确列出承诺人自愿放弃的各项抗辩事由，该约定即为有效。

<a id="2.11.4.5"></a>**5.** 另外，如果某人本无须为到庭提供担保，却在提供担保后作出了承诺，能否给予其保证人抗辩？我认为，应区分该项承诺是因错误而作出，还是依约定作出：若因错误而作出，应给予保证人抗辩；若依约定作出，则不应给予。尤利安也写道，如果某人因不知情而承诺超过规定金额，应给予抗辩；但如果其依约定承诺如此金额，尤利安认为，应以约定抗辩的再抗辩驳回该抗辩。

### <a id="2.11.5"></a>2.11.5　保罗《评告示》第六十九卷

<a id="2.11.5.pr."></a>**序言。** 如果有两名共同的要式承诺受领人，债务人只向其中一人承诺以罚金担保到庭，而另一人阻止债务人到庭，那么仅在二人属于合伙关系时，才应给予债务人针对后一人的抗辩；以免一方因共同关系而得益于另一方的欺诈。

<a id="2.11.5.1"></a>**1.** 同样，如果有两名共同的要式承诺人，其中一人无视自己为到庭所作的承诺而未到庭，原告却向另一人请求债务本金、向未到庭者请求弃诉罚金，那么原告请求该罚金时，应受抗辩阻却。

<a id="2.11.5.2"></a>**2.** 同样，如果父亲因家子所订合同而作出到庭承诺，之后原告就争议标的向家子提起诉讼；原告再依据父亲的承诺向父亲请求罚金时，应受抗辩阻却。反之，如果家子作出承诺，而原告就特有产向父亲提起诉讼，也应作同样处理。

### <a id="2.11.6"></a>2.11.6　盖尤斯《论十二表法》第一卷

如果提供保证人的人因公务而未能到庭，使保证人不得不代替他到庭，实属不公；因为该人本人本可自由选择不出庭。

### <a id="2.11.7"></a>2.11.7　保罗《评告示》第六十九卷

如果某人承诺使奴隶或其他处于他人权力之下的人到庭，他可以援用的抗辩，与为自由人或家父提供保证时相同；但若称奴隶因公务而缺席，则不得援用这一抗辩，因为奴隶不能因公务而缺席。除此抗辩之外，其他抗辩均为共同抗辩，既适用于自由人，也适用于奴隶。

### <a id="2.11.8"></a>2.11.8　盖尤斯《评行省告示》第二十九卷

如果被告承诺到庭的日期已过三日、五日或更多日后，他已使原告能够对其提起诉讼，而且迟延并未使原告的权利处于更不利地位，那么应当让他以抗辩获得保护。

### <a id="2.11.9"></a>2.11.9　乌尔比安《评告示》第七十七卷

<a id="2.11.9.pr."></a>**序言。** 如果奴隶承诺自己到庭，无论对奴隶本人还是对其保证人，都不发生要式承诺的责任。

<a id="2.11.9.1"></a>**1.** 如果以一项要式承诺担保数名奴隶到庭，拉贝奥认为，即使其中一人未到庭，全部罚金仍告发生，因为数名奴隶确实并非都已到庭。但如果有人按其中一名奴隶所占比例提出罚金，那么依据此项要式承诺被起诉的人可以援用欺诈抗辩。

### <a id="2.11.10"></a>2.11.10　保罗《评普劳提乌斯》第一卷

<a id="2.11.10.pr."></a>**序言。** 如果我承诺使某人到庭，而此人据称在当时已经因经过一定期间而获得自由，因为或许已不再受某项诉权约束，那么可以对我提起诉讼，要求我出示此人或为其进行诉讼防御，以查明事实。

<a id="2.11.10.1"></a>**1.** 如果承诺到庭的人在应到庭日期之前因承诺人的欺诈而死亡，依确定的法律规则，在约定日期到来之前不得请求罚金；因为整个要式承诺被视为延期至该日履行。

<a id="2.11.10.2"></a>**2.** 某人准备提起侵害之诉，在争讼程序确定前已约定其对方应到庭；要式承诺发生责任后，该人死亡。通说认为，其继承人无权提起要式承诺之诉，因为这类承诺是基于诉讼事项本身作出的，而侵害之诉不得由继承人提起。虽然此项为到庭而作的要式承诺可以移转给继承人，但在这种情形下不得提起诉讼：即使死者愿意放弃侵害之诉而改以要式承诺提起诉讼，也不会被允许。如果我准备对其提起侵害之诉的人，在此类要式承诺发生责任后死亡，也应作同样处理：我不得对其继承人提起要式承诺之诉；尤利安也这样写道。依此，如果已提供保证人，被告死亡后也不得对保证人提起诉讼。庞波尼乌斯亦持同一看法，但以死者并非在很久以后才死亡为限；因为如果其曾到庭，原告本可与其正式进行诉讼。

### <a id="2.11.11"></a>2.11.11　乌尔比安《评萨宾》第四十七卷

如果某人承诺使他人到庭，就应使其以同一状态到庭（底本在 *promiserit* 后附有“promisit”，性质不明）。所谓以同一状态到庭，是指原告追索权所处的地位未因此恶化，尽管追偿标的物可能变得更为困难。即使追偿较为困难，也应认为其以同一状态到庭：例如，即使他另行负债或损失金钱，仍视为以同一状态到庭。因此，对他人负有给付判决债务的人到庭，也视为处于同一状态。

### <a id="2.11.12"></a>2.11.12　保罗《评萨宾》第十一卷

<a id="2.11.12.pr."></a>**序言。** 但是，援用新的特权者，不视为以同一状态到庭。

<a id="2.11.12.1"></a>**1.** 应当记住，原告利益损失的估价，应以应当到庭之时为准，而非以提起诉讼之时为准，即使到诉讼时该项利益已不复存在，亦是如此。

### <a id="2.11.13"></a>2.11.13　尤利安《学说汇纂》第五十五卷

如果奴隶为了自己作为当事人进行诉讼，而作为要式承诺受领人向他人约定，或自己作出到庭承诺，则无论哪种情形，要式承诺均不发生责任，保证人也不承担责任，因为奴隶既不能被起诉，也不能提起诉讼。

### <a id="2.11.14"></a>2.11.14　内拉提乌斯《论札记》第二卷

如果诉讼代理人仅约定其所代表的人到庭，而未约定其未到庭时支付罚金，这项要式承诺几乎毫无意义，因为就诉讼代理人自身利益而言，该人是否到庭与其无关。但是，既然诉讼代理人在订立要式承诺时处理的是他人事务，可以主张应考虑其所处理事务的本人之利益，而非代理人自己的利益：被告未到庭时，诉讼代理人可依据该项要式承诺请求相当于诉讼当事人因被告到庭本可获得的利益。如果诉讼代理人约定“该事项价值多少”，同样的理由甚至更充分；应将这种措辞解释为涉及诉讼当事人的利益，而非代理人自身的利益。

### <a id="2.11.15"></a>2.11.15　帕皮尼安《问题集》第二卷

如果监护人承诺到庭却未履行，而与此同时被监护人已成年、死亡，或拒绝接受继承，则不得提起要式承诺之诉。已经确立的规则是：如果监护人就被请求的标的物被判负给付判决，而上述情形之一随后发生，也不得对监护人提起判决之诉。
