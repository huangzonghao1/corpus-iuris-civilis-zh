# 第二卷

## 2.15　论和解（续）

### <a id="2.15.9"></a>2.15.9　乌尔比安《意见集》第一卷

<a id="2.15.9.pr."></a>**序言。** 某人曾仅就自己管理监护事务所得的份额与监护人起诉并达成和解；此后，他以其兄弟继承人的身份对同一监护人起诉，不得以先前和解抗辩阻却其诉讼。

<a id="2.15.9.1"></a>**1.** 任何和解，均应视为仅涉及当事人已经同意的事项。

<a id="2.15.9.2"></a>**2.** 如果某人受共同继承人欺骗，在不知悉全部真实情况时、又未订立阿奎利亚要式承诺，便签署和解文书，与其说他是在订立协议，不如说他是受到了欺骗。

<a id="2.15.9.3"></a>**3.** 某人尚不确定自己是否有权针对其父亲的遗嘱提出异议，却就其他事由与对方订立协议。该协议只对能够证明双方曾约定的事项发生效力。即使该人订立协议时已超过二十五岁，和解也只涉及能够证明曾经约定的事项。后来才发现他有权就其他事项提起诉讼；以协议消灭这些诉权并不公平。未能证明当时曾考虑过这些事项。

### <a id="2.15.10"></a>2.15.10　乌尔比安《答复集》第一卷

父亲就自己不再享有权力的儿子的财产进行和解，通说认为该和解不应对这些儿子不利。

### <a id="2.15.11"></a>2.15.11　乌尔比安《评告示》第四卷

判决作出后，即使没有提起上诉，如果有人否认曾经作出判决，或者不能确定是否已作出判决，仍可达成和解；因为诉讼仍可能产生不利后果。

### <a id="2.15.12"></a>2.15.12　凯尔苏斯《学说汇纂》第三卷

如果有人就遗嘱留给自己的财产概括地达成和解，后来却辩称自己只考虑了遗嘱前半部分、没有考虑后半部分所遗赠的财产，就不应支持他。但是，如果后来又出示补充遗嘱文件，他似乎可以正当地说，自己当时只考虑了其已知文书中所记载的内容。

### <a id="2.15.13"></a>2.15.13　马克尔《论遗产税》第一卷

未经元首批准，任何元首代理官均不得达成和解。

### <a id="2.15.14"></a>2.15.14　斯凯沃拉《答复集》第二卷

合法继承人与遗嘱指定继承人之间发生争议，双方通过和解并依特定条件解决争议。我问：债权人可以起诉谁？答复：如果债权人就是订立和解的那些人，应依他们就债务达成的约定处理；如果债权人并非这些人，由于继承关系尚不确定，应按双方在和解中各自声明的遗产份额，对双方提起有用诉讼。

### <a id="2.15.15"></a>2.15.15　保罗《格言集》第一卷

当事人在协议后通常会附加阿奎利亚要式承诺；但更为审慎的做法是同时附加罚金要式承诺，因为如果协议后来被撤销，可以依据要式承诺请求罚金。

### <a id="2.15.16"></a>2.15.16　赫莫革尼安《法学概要》第一卷

违反合法和解之信任的人，不仅会被和解抗辩阻却；如果他违反协议，而协议仍保持效力，他还必须支付曾向要式承诺受领人作出的罚金承诺。

### <a id="2.15.17"></a>2.15.17　帕皮尼安《问题集》第二卷

遗产出卖人受遗产买受人委托，与一名遗产债务人达成和解，而该债务人并不知道遗产已经出售。如果遗产买受人想向债务人追索该项债务，鉴于债务人并不知情，应准许其援用和解抗辩。通过遗嘱信托取得遗产的人，也适用同一答复；如果继承人与不知情的债务人达成和解，该债务人也可以援用和解抗辩。
