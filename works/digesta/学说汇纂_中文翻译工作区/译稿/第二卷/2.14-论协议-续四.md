# 第二卷

## 2.14　论协议（续）

### <a id="2.14.21"></a>2.14.21　保罗《评告示》第三卷

<a id="2.14.21.pr."></a>**序言。** 此项协议也对父亲的继承人有利，但以家子仍在世为限；家子死亡后，该协议既不对其父亲有利，也不对父亲的继承人有利，因为这是一项针对特定人的协议。

<a id="2.14.21.1"></a>**1.** 如果奴隶约定不得向其本人请求，该协议无效；但是否可以援用欺诈抗辩，仍应考察。如果奴隶订立的是针对事项本身的协议，则其主人及主人的继承人可以援用协议抗辩；如果协议针对特定人，主人仍可援用欺诈抗辩。

<a id="2.14.21.2"></a>**2.** 我们不能通过订立协议使处于我们权力之下的人受益；但如果我们因其名义而被起诉，普罗库鲁斯认为，该协议会对我们有利。若订立协议时确有此意，则此说正确。反之，如果我约定不得向提图斯请求，之后却因其名义而对我提起诉讼，则不应准许我援用协议抗辩；因为对本人无效的事，也不能由诉讼防御人援用。尤利安也写道，如果父亲约定不得向自己或家子请求，较妥当的看法是，不应给予家子协议抗辩，但可以给予其欺诈抗辩。

<a id="2.14.21.3"></a>**3.** 家女在成为自权人后，可以约定不就嫁资提起诉讼。

<a id="2.14.21.4"></a>**4.** 家子也可以就附条件遗赠订立有效协议。

<a id="2.14.21.5"></a>**5.** 对于数人各自均须就同一笔债务承担全部责任，或者数人均为同一笔债务的债务人的情形，协议抗辩在何种范围内对其他人有利或不利，存在疑问。针对事项本身的协议，对所有那些协议订立人有利益使其债务消灭的人均有利。因此，债务人订立的协议也会使保证人受益——

### <a id="2.14.22"></a>2.14.22　乌尔比安《评告示》第四卷

除非当事人约定仅不得向债务人请求、但仍可向保证人请求；在这种情况下，保证人不得援用抗辩。

### <a id="2.14.23"></a>2.14.23　保罗《评告示》第三卷

<a id="2.14.23.pr."></a>**序言。** 保证人订立的协议不会使债务人受益，因为债务人并不因债权人不向保证人请求偿还而获得利益。该协议也不会使共同保证人受益。

<a id="2.14.23.1"></a>**1.** 并非任何关联利益都会使协议对他人有利。只有在获得抗辩之人通过该协议，能够直接使订立协议者受益时，协议才对其有利；债务人及为该债务承担责任之人之间的关系即属此例。

### <a id="2.14.24"></a>2.14.24　保罗《评普劳提乌斯》第三卷

但是，如果保证人是为自己的利益而作出承诺，在这种情形下，保证人应视为主债务人；与保证人订立的协议也应视为与主债务人订立的协议。

### <a id="2.14.25"></a>2.14.25　保罗《评告示》第三卷

<a id="2.14.25.pr."></a>**序言。** 对于两名共同的要式承诺人，以及两名共同经营银行业务的合伙人，也适用同一规则。

<a id="2.14.25.1"></a>**1.** 拉贝奥说，针对特定人的协议不得及于他人，正如不得及于继承人一样。

<a id="2.14.25.2"></a>**2.** 尽管保证人订立的协议不使债务人受益，尤利安仍写道，很多时候欺诈抗辩会使债务人受益——

### <a id="2.14.26"></a>2.14.26　乌尔比安《评告示》第四卷

也就是说，当事人约定不得向主债务人请求时，债务人可以援用该抗辩。共同保证人之间也适用同一规则。
