# 第二卷

## 2.14　论协议（续）

### 2.14.7　乌尔比安《评告示》第四卷（续）

<a id="2.14.7.7"></a>**7.** 裁判官规定：“我将维护当事人达成的协议，但协议不得出于恶意欺诈，不得违反法律、平民会决议、元老院决议、裁判官命令或元首敕令，也不得以规避上述任何规范为目的。”

<a id="2.14.7.8"></a>**8.** 有些协议针对事项本身，有些则针对特定人。凡协议一般性地约定“我不请求”，即属针对事项本身；凡协议约定“不向某人请求”，例如“不向卢基乌斯·提图斯请求”，即属针对特定人。协议属于哪一种，不仅要根据协议措辞，也应根据当事人的真实意思判断。正如佩狄乌斯常说的，协议中写入某人的姓名，通常不是为了使协议成为针对该人的个人协议，而是为了指出协议是与谁订立的。

<a id="2.14.7.9"></a>**9.** 裁判官说，他不会维护以恶意欺诈方式订立的协议。恶意欺诈通过狡猾和欺骗实施；佩狄乌斯说，为规避他人而表面做一事、实际另做一事时，即以恶意欺诈订立协议。

<a id="2.14.7.10"></a>**10.** 如果有人称协议是为欺诈而订立，裁判官没有另行增添规定；但拉贝奥精当地说，这样规定要么不公，要么多余。如果债权人曾本着诚信免除债务，后来却试图推翻该免除，就是不公；如果债权人是受骗后作出免除，则该情形已包含在恶意欺诈和欺骗之中，另作规定便是多余。

<a id="2.14.7.11"></a>**11.** 无论协议自始以恶意欺诈方式订立，还是协议订立后又以恶意欺诈实施了某事，依告示中的“不得实施”这一措辞，均可据此提出抗辩。

<a id="2.14.7.12"></a>**12.** 协议末尾通常会写道：“提图斯请求，麦维乌斯承诺。”这些措辞不仅可视为协议，也可视为要式承诺。因此，通常可以提起要式承诺之诉；但如果有人特别证明这些措辞并非当事人以订立要式承诺的意思作出，而仅是以达成协议的意思作出，则另当别论。

<a id="2.14.7.13"></a>**13.** 如果我约定不就判决债务或被焚毁房屋的事项提起诉讼，该协议有效。

<a id="2.14.7.14"></a>**14.** 如果我约定不继续执行新工程告知，有人认为该协议无效，仿佛此事项属于裁判官的权力范围。但拉贝奥加以区分：如果新工程告知涉及私人财产，就可以达成协议；如果涉及公共事务，则不可以。此项区分是正确的。因此，凡涉及裁判官告示、但关乎私人事务而非公共损害的其他事项，也都可以通过协议处理；法律甚至允许当事人就盗窃达成协议。
