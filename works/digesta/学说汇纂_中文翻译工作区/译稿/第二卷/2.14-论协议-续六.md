# 第二卷

## 2.14　论协议（续）

### <a id="2.14.28"></a>2.14.28　盖尤斯《评行省告示》第一卷

<a id="2.14.28.pr."></a>**序言。** 违反市民法规则的协议，不发生效力。例如，未成年家子未经监护人同意，约定不向自己的债务人请求债务，或者约定在一定期限内（例如五年内）不请求；此类协议无效，因为未成年家子未经监护人同意也不能受领清偿。反之，如果未成年家子约定不得向其请求所负债务，该协议有效；因为即使未经监护人同意，也允许未成年家子使自己的法律地位得到改善。

<a id="2.14.28.1"></a>**1.** 如果精神失常者或挥霍者的保佐人约定不得向被保佐人请求，通说认为该协议对被保佐人有利；但反过来则不然。

<a id="2.14.28.2"></a>**2.** 如果家子或奴隶约定不得向其本人请求，该协议无效。如果他们订立的是针对事项本身的协议，也就是约定不得请求该笔款项，那么在家子或奴隶获准自由管理特有产、且协议所涉事项属于特有产时，该协议对父亲或主人有效。不过，此规则本身仍不明确：尤利安认为，即使某人获准管理特有产，也无权赠与特有产；因此，如果他为赠与目的而约定不请求款项，该协议不应有效。但如果其订立协议后，获得的对价不低于、甚至高于所放弃的款项，那么该协议应当有效。

### <a id="2.14.29"></a>2.14.29　乌尔比安《评告示》第四卷

但是，如果奴隶贷出的是主人的钱，凯尔苏斯说，其在借贷时订立的协议有效。

### <a id="2.14.30"></a>2.14.30　盖尤斯《评行省告示》第一卷

<a id="2.14.30.pr."></a>**序言。** 对于家子而言，还应考察其订立的不诉协议是否有时有效；因为家子有时也享有诉权，例如侵害之诉。〔译注：底本此处作“puis”，疑有脱字，译文依句义处理。〕又因为家父也享有针对侵害其家子的诉权，因此，如果家子所订协议会妨碍家父提起诉讼，就无疑不应如此。

<a id="2.14.30.1"></a>**1.** 有人向奴隶要式约定一笔款项，而该款项原是提图斯欠他的；如果他转而向提图斯请求，是否可以且应当以协议抗辩阻却其请求，因为他似乎已经约定不得向提图斯请求？尤利安认为，如果请求人可以对奴隶的主人提起特有产之诉，就应阻却其请求；也就是说，如果奴隶介入此事有正当理由，例如奴隶也欠提图斯同等数额的款项。反之，如果奴隶只是以保证人身份介入，而该情形不产生特有产之诉，则不得阻止债权人向提图斯请求。如果债权人误以为该奴隶是自由人，也同样不得阻止其请求。

<a id="2.14.30.2"></a>**2.** 如果我以附条件方式向你作出要式承诺，承诺履行提图斯无条件欠我的债务；后来条件未成就，而我向提图斯请求该债务，能否且应否以协议抗辩阻却我的请求？较妥当的意见是，不应对我提出协议抗辩。

### <a id="2.14.31"></a>2.14.31　乌尔比安《评市政营造官告示》第一卷

无论在买卖进行之时还是之后，当事人均可约定排除市政营造官告示的适用。

### <a id="2.14.32"></a>2.14.32　保罗《评普劳提乌斯》第三卷

如前所述，如果与主债务人订立协议，约定不再请求债务，则保证人也可以援用该协议抗辩；这是基于主债务人的身份而作出的安排，以免保证人被提起委任之诉。因此，如果不存在委任之诉，例如保证人是出于赠与意思而提供保证，则应认为该抗辩不使保证人受益。

### <a id="2.14.33"></a>2.14.33　凯尔苏斯《学说汇纂》第一卷

祖父以其通过儿子所生孙女的名义承诺提供嫁资，并约定不得向自己或儿子请求嫁资。如果儿子的共同继承人请求嫁资，不得以协议抗辩保护祖父；但儿子可以正当地援用协议抗辩。因为法律允许为继承人提供保护，并不妨碍只使一名成为继承人的共同继承人受益，而不使其他人受益。

### <a id="2.14.34"></a>2.14.34　莫德斯蒂努斯《规则集》第五卷

尤利安认为，阿格纳特亲属关系上的权利不得通过协议放弃；这与某人不能仅以协议或声明拒绝自己的身份地位相同。
