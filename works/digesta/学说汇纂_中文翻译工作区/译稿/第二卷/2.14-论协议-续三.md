# 第二卷

## 2.14　论协议（续）

### 2.14.7　乌尔比安《评告示》第四卷（终）

<a id="2.14.7.15"></a>**15.** 同样，如果有人约定不提起寄托之诉，庞波尼乌斯认为该协议有效。如果有人约定，就寄托事项承担全部风险，庞波尼乌斯也认为该约定有效，并非因其违反法律形式而不得遵守。

<a id="2.14.7.16"></a>**16.** 一般而言，凡偏离一般法律规则的协议，均不应予以遵守。马尔凯卢斯在《学说汇纂》第二卷中写道：此类事项不得作为遗赠，也不得遵守被强令作出的“不起诉”宣誓。如果当事人就法律不允许通过协议处分的事项订立要式承诺，该要式承诺也不得遵守，而应在任何情况下予以撤销。

<a id="2.14.7.17"></a>**17.** 如果某人在接受遗产之前与债权人约定少偿还一部分债务，该协议有效。

<a id="2.14.7.18"></a>**18.** 但是，如果订立协议的是一名奴隶，他尚未获得自由或取得继承资格，因为他是附条件指定的继承人，温狄乌斯写道，该协议对他并无利益。马尔凯卢斯则在《学说汇纂》第十八卷中认为：被无条件指定为家内继承人或必然继承人的奴隶，在尚未介入遗产事务之前与债权人订立协议，属于有效协议；此说是正确的。对外来继承人也同样如此：如果其依债权人的委托接受遗产，他还可以提起委任之诉。但是，正如我们前面提及的，如果某人在奴隶身份期间订立协议，马尔凯卢斯否认该协议有效，因为奴隶身份期间所实施的行为通常不会使其在获得自由后受益；协议抗辩也应适用这一规则。不过，欺诈抗辩是否也对其有利，仍有疑问。马尔凯卢斯在类似情形中虽曾有所迟疑，最终仍予以承认。例如，某家子被指定为继承人，他与债权人订立协议，之后获释并接受遗产；马尔凯卢斯认为他可以援用欺诈抗辩。他还认可另一种情形：家父仍在世时，家子与其父亲的债权人订立协议；此时欺诈抗辩也对家子有利。甚至对奴隶，也不应拒绝其援用欺诈抗辩。

<a id="2.14.7.19"></a>**19.** 但是，如今此类协议只有在债权人全体聚集并以共同意思表示愿意接受债务的某一比例时，才对债权人发生效力。如果他们意见不一，则必须由裁判官介入，并以裁定遵从多数债权人的意思。
