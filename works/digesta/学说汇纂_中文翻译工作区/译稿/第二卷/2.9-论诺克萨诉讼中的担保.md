# 第二卷

## <a id="2.9"></a>2.9　论提起诺克萨之诉时如何提供担保

### <a id="2.9.1"></a>2.9.1　乌尔比安《评告示》第七卷

<a id="2.9.1.pr."></a>**序言。** 如果某人承诺使负诺克萨之诉责任之人到庭，裁判官规定：在诉讼正式受理之前，应使该人以其当时所处的同一状态到庭。

<a id="2.9.1.1"></a>**1.** 我们来考察“处于同一状态”是什么意思。我认为，较为妥当的理解是：只要其到庭审理不会使原告的权利处于更不利地位，就可认为其以同一状态到庭。拉贝奥说，如果该奴隶不再处于承诺人权力之下，或者诺克萨之诉已经消灭，就不能认为其仍处于同一状态；如果原本在诉讼中处于同等地位的人变得更为不利，无论是诉讼地位还是当事人身份发生变化，也同样如此。因此，如果该奴隶被卖给一个在承诺人所属法庭不能对其提起诉讼的人，或者被交给一个更有势力的人，拉贝奥认为，更妥当的说法是：不能认为该奴隶仍以同一状态到庭。奥菲利乌斯还认为，如果该奴隶已被诺克萨交付，也不能认为其以同一状态到庭；因为他认为，诺克萨交付会使其他人的诺克萨之诉消灭。

### <a id="2.9.2"></a>2.9.2　保罗《评告示》第六卷

<a id="2.9.2.pr."></a>**序言。** 但我们采用不同的规则。因先前事由而被诺克萨交付的人，并不因此免除责任；因为诺克萨责任随行为人而转移，正如该人已被出卖一样。

<a id="2.9.2.1"></a>**1.** 如果某奴隶缺席，而有人对其享有诺克萨之诉：如果主人不否认该奴隶处于其权力之下，温狄乌斯认为，应强令主人承诺使奴隶到庭，或者接受诉讼；若主人不愿为奴隶进行诉讼防御，则应提供担保，承诺其一旦能够做到便交出奴隶。反之，如果主人谎称奴隶不在其权力之下，就应在不要求诺克萨交付的情况下接受诉讼。尤利安写道，即使主人以欺诈手段使奴隶脱离其权力，也应如此处理。但是，如果奴隶本人在场，主人缺席且无人为奴隶进行诉讼防御，裁判官应命人将奴隶带走。经查明具体情形后，应允许主人在之后进行诉讼防御；庞波尼乌斯和温狄乌斯均如此记载，以免主人因缺席而受不利。于是，也应恢复原告的诉权；原告的诉权此前因该奴隶被带走而消灭，因为奴隶由此开始成为原告财产中的一部分。

### <a id="2.9.3"></a>2.9.3　乌尔比安《评告示》第七卷

如果有人对用益权人提起诺克萨之诉，而该用益权人不为奴隶进行诉讼防御，裁判官将拒绝其主张用益权的请求。

### <a id="2.9.4"></a>2.9.4　盖尤斯《评行省告示》第六卷

如果诺克萨之诉针对数名共有人中的一人提起，他是否应就其共有人所占份额提供担保？萨宾认为不应如此；因为在某种意义上，他是在为整个奴隶进行防御，而他负有对该奴隶承担全部防御的义务。如果他仅愿意作部分防御，法院不予受理。

### <a id="2.9.5"></a>2.9.5　乌尔比安《评萨宾》第四十七卷

如果有人承诺使奴隶以同一状态到庭，而到庭时该奴隶已获自由：如果争议涉及针对奴隶的死刑案件或侵害之诉，则不应认为其已适当到庭；因为对奴隶可施以死刑或鞭打，以此对侵害作出补偿；对自由人则以宣告其有罪或判处罚金的方式处理。但是，就其他诺克萨事由而言，该奴隶似乎已处于更有利的状态。

### <a id="2.9.6"></a>2.9.6　保罗《评萨宾》第十一卷

如果承诺使一名附条件自由的奴隶到庭，即使其到庭时已经自由，也视为以同一状态到庭，因为其获得自由这一情形本已包含在该承诺之中。
