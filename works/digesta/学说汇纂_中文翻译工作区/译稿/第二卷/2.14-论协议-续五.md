# 第二卷

## 2.14　论协议（续）

### <a id="2.14.27"></a>2.14.27　保罗《评告示》第三卷

<a id="2.14.27.pr."></a>**序言。** 如果数名共同经营银行业务的合伙人中，一人与债务人订立协议，该协议抗辩是否也对另一名合伙人有利？内拉提乌斯、阿提利基努斯和普罗库鲁斯认为，即使协议是针对事项本身的，也不会对另一人有利；因为既定规则仅是允许另一人请求全部债务。拉贝奥也持此意见：另一人不能代其更新债务，尽管可以向其有效清偿。正如向处于我们权力之下的人清偿其借出的款项，也会发生有效清偿，即使其不能更新债务一样。两名共同的要式承诺受领人也适用同一规则。

<a id="2.14.27.1"></a>**1.** 如果与债务人约定在一段确定期间内不得请求，则该协议在该期间届满后，既不使债务人也不使保证人受益。如果债务人未将自己列为协议对象，而是约定不得向保证人请求，有些人认为，即使债务人对此有利害关系，该协议也不使保证人受益，因为保证人只能提出与债务人相同的抗辩。我所受教导的规则则是：该抗辩对保证人有利；因为这并非通过另一自由人替保证人取得权利，而应视为对订立协议者本人的救济；我们也遵循此规则。

<a id="2.14.27.2"></a>**2.** 某人先约定不得请求，之后又约定可以请求；后来的协议会排除先前的协议，但并非依法自动排除，如同双方有此意思时后订立的要式承诺会消灭先前要式承诺一样。因为要式承诺属于法律关系，协议则属于事实行为。因此，应通过再抗辩排除协议抗辩。依同一理由，先前协议也就不再使保证人受益。

但是，如果先前协议本身消灭了诉权，例如侵害之诉，那么之后再约定可以提起诉讼，也不能使诉权恢复；因为最初的诉权已经消灭，后来的协议又不足以产生新的诉权。侵害之诉是因受侵害而产生，而非因协议产生。诚信合同也应适用同一规则：如果协议消灭了全部合同义务，例如买卖义务，后来的协议不会使原有义务复活；但该协议可以作为订立新合同的基础。如果协议并未消灭整个合同，只是减少其义务，那么后来的协议可以恢复原合同。这一规则也适用于嫁资之诉。例如，妇女约定在当日返还嫁资，后来又约定应在法律规定的期限内返还；此时嫁资关系恢复至其通常的法律状态。不能说协议使嫁资处于更不利地位；嫁资之诉只是恢复其法律本来规定的形式。斯凯沃拉也赞同这些意见。

<a id="2.14.27.3"></a>**3.** 任何协议均不得免除恶意欺诈责任。即使有人约定不提起寄托之诉，该约定也应视为当然涵盖不就欺诈提起诉讼；此项协议有效。

<a id="2.14.27.4"></a>**4.** 包含不正当目的的协议不得遵守。例如，约定“如果你实施盗窃或侵害，我就不提起盗窃之诉或侵害之诉”，不得遵守；因为使人畏惧盗窃或侵害的处罚，本身具有积极意义。但是，在盗窃或侵害已经发生后，当事人可以达成协议。同样，涉及公共利益的部分，如果约定不请求禁止暴力侵占的令状救济，也不得允许。总之，如果协议脱离私人事务、涉及公共利益，就不得遵守；首先必须注意，针对某事或与某人订立的协议，不应损害另一事项或另一人的利益。

<a id="2.14.27.5"></a>**5.** 如果我本有十的债权，却约定不向你请求二十，通说认为，你可以就十援用协议抗辩或欺诈抗辩。同样，如果你欠我二十，而我约定不请求其中十，那么通过对我提出抗辩，我只能请求剩余的十。

<a id="2.14.27.6"></a>**6.** 如果我约定你应交付十或奴隶斯提库斯，而后约定不得请求十，但我又请求斯提库斯或十，那么协议抗辩将全部阻却我的请求。正如通过清偿、请求或受领清偿解除其中一项给付，可使全部债务消灭；同样，约定不请求其中一项给付，也会使全部债务不能再请求。但是，如果我们约定不交付十、而改为交付斯提库斯，我可以有效地请求交付斯提库斯，不得以协议抗辩阻却。约定不请求斯提库斯时，也适用同一规则。

<a id="2.14.27.7"></a>**7.** 如果你一般性地欠我一名奴隶，而我约定不请求斯提库斯，那么我请求斯提库斯时会受到协议抗辩阻却；但如果我请求另一名奴隶，仍可依法起诉。

<a id="2.14.27.8"></a>**8.** 同样，如果我约定不请求遗产，却以继承人的身份逐项请求遗产中的物品，应根据协议内容提出协议抗辩。若约定不请求土地、我却请求该土地的用益权，或者约定不请求船舶或建筑物、我却在其拆解后请求各个组成物，也应如此处理；除非双方另有明确约定。

<a id="2.14.27.9"></a>**9.** 如果要式免债行为无效，应认为双方通过默示协议约定不得请求。

<a id="2.14.27.10"></a>**10.** 遗产中的奴隶不能以未来继承人的名义特定订立协议，因为继承人尚未成为所有权人；但是，如果协议是针对事项本身订立的，可以为继承人取得利益。
