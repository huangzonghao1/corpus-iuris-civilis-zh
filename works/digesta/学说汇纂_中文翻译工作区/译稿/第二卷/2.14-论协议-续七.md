# 第二卷

## 2.14　论协议（续）

### <a id="2.14.35"></a>2.14.35　莫德斯蒂努斯《答复集》第五卷

提图斯、麦维乌斯和塞娅三兄妹分割共同遗产，并订立文书，声明已分割母亲的遗产，彼此之间不再有任何共同财产。后来，麦维乌斯和塞娅在母亲死亡时均不在场，得知其兄弟提图斯私自取走了一笔金币，而分割遗产的文书没有提及该笔金币。我问：在分割协议订立后，兄妹能否就这笔被窃取的金币对其兄弟提起诉讼？莫德斯蒂努斯答复：如果提图斯对其兄妹请求分割其所称被提图斯窃取的款项，并援用概括性协议抗辩，那么对于订立协议时不知提图斯实施欺诈的人，可以有效提出欺诈再抗辩。

### <a id="2.14.36"></a>2.14.36　普罗库鲁斯《书信集》第五卷

如果你占有我的土地，而我与你约定由你将该土地的占有交给阿提乌斯；此后我向你请求返还土地，则只有在你已经交付土地，或者该约定是为你的利益而订立且未能交付并非由于你的原因时，你才可以援用协议抗辩阻止我请求返还土地。

### <a id="2.14.37"></a>2.14.37　帕皮里乌斯《敕令集》第二卷

安东尼努斯皇帝与维鲁斯皇帝作出答复：共同体的保佐官不得准许欠共同体债务的人免除其款项；如果已经准许腓立比人免除该项款项，应予撤销。

### <a id="2.14.38"></a>2.14.38　帕皮尼安《问题集》第二卷

公共法不得通过私人协议加以变更。

### <a id="2.14.39"></a>2.14.39　帕皮尼安《问题集》第五卷

古人认为，含糊或有歧义的协议应由出卖人或出租人承担不利后果，因为条款是否写得更为明确，本由他们决定。

### <a id="2.14.40"></a>2.14.40　帕皮尼安《答复集》第一卷

<a id="2.14.40.pr."></a>**序言。** “我确认你不承担责任”这样的协议，并非仅针对某一特定人；由于其内容具有一般性，在继承人之间发生争议时也适用。

<a id="2.14.40.1"></a>**1.** 提起上诉的人约定，如果未在特定期限内支付和解确定的款项，就应依判决履行债务。上诉法官不再审查实体争议，直接按照该公平约定处理，仿佛上诉人已经承认债务。

<a id="2.14.40.2"></a>**2.** 财产和债务分割后，各债权人没有办理债务移转，却分别向各继承人接受利息，并约定各继承人对全部债务负责。如果各继承人没有分别提出全部债务的给付，以履行交易诚信，则债权人针对所有继承人、按其份额享有的诉权不受妨碍。

<a id="2.14.40.3"></a>**3.** 父亲承诺提供嫁资，并约定：若女儿婚后无子女而在父亲死后先亡，部分嫁资仍归其兄弟——即父亲的继承人。女婿后来另有子女，父亲也通过遗嘱指定继承人；该约定仍可通过欺诈抗辩对抗他们。因为缔约双方的意思是照顾继承人；在父亲尚无其他子女时，他似乎已将最终处置安排交给自己的兄弟。

### <a id="2.14.41"></a>2.14.41　帕皮尼安《答复集》第十一卷

“如果你在那一日之前向我清偿部分债务，我就将剩余债务视为已清偿并解除你。”虽然债务人不能依据该约定提起诉讼，但通说认为，债务人可以提出协议抗辩。

### <a id="2.14.42"></a>2.14.42　帕皮尼安《答复集》第十七卷

债务人与债权人约定，债权人不承担已设质土地的税赋，而由债务人承担缴税义务。我答复说，就国库的权利而言，该协议不得遵守；因为通说不允许以私人协议改变财政法的规范。

### <a id="2.14.43"></a>2.14.43　保罗《问题集》第五卷

在买卖中，我们知道债务人应履行何种义务，以及买受人相应应履行何种义务；如果双方在订立合同时对某项内容作了特别约定，就应遵守该约定。

### <a id="2.14.44"></a>2.14.44　斯凯沃拉《答复集》第五卷

一名未成年人即将拒绝接受其父亲的遗产，监护人与多数债权人商定，使他们接受某一确定比例；保佐人也与其他债权人作了同样安排。我问：作为父亲债权人的监护人，是否也应当接受同一比例？我答复：既然该监护人要求其他债权人接受一定比例，他本人也应满足于同一比例。

### <a id="2.14.45"></a>2.14.45　赫莫革尼安《法学概要》第二卷

如果分割协议未通过交付或要式承诺而得到履行，该协议就如同单纯协议一样，不会使任何人取得诉权或其他利益。

### <a id="2.14.46"></a>2.14.46　特里丰尼努斯《论争议》第二卷

继承人与遗赠受领人约定不要求后者提供担保；神圣马尔库斯皇帝的敕令记载于其《半年纪事》中，并确认此种情形也应尊重死者的意思，该协议有效。遗赠受领人通过协议免除继承人的担保后，不得因反悔而撤销此项免除；因为当事人可以自行使其法律权利的行使或日后获得给付的希望处于较不利地位。
