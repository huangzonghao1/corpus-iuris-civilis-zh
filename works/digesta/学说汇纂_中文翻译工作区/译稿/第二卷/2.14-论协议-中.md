# 第二卷

## 2.14　论协议（续）

### <a id="2.14.8"></a>2.14.8　帕皮尼安《答复集》第十卷

多数债权人的意见，应按其债权金额计算，而非按人数计算。如果债权总额相等，则应优先考虑人数较多的一方。如果债权人人数相等，裁判官应遵从其中地位较高者的意见。如果各方面均完全相等，裁判官应选择较为宽厚的意见。此规则可以从神圣马尔库斯皇帝的答复中推知。

### <a id="2.14.9"></a>2.14.9　保罗《评告示》第六十二卷

<a id="2.14.9.pr."></a>**序言。** 如果数人享有同一项诉权，他们应视为一人。例如，数名共同的要式承诺受领人，或其姓名一并记载的数名银行家，均只算一人，因为只有一项债务。如果数名未成年债权人的监护人共同订立协议，也只算一人，因为他们是代表同一名未成年人订立协议。同样，如果一名监护人代表数名主张同一笔债务的被监护人订立协议，也只算一人。因为很难让一人承受两人的地位。反过来说，享有多项诉权的人，在面对仅享有一项诉权的人时，也不因此被视为数人。

<a id="2.14.9.1"></a>**1.** 债权总额也应按数项债务合并计算。例如，若有人欠一人许多笔小额债务，合计一百奥里金币；另欠他人一笔五十奥里金币，则应考察前者的多笔债务，因为这些债务合并后总额更高。

<a id="2.14.9.2"></a>**2.** 计算债权金额时，也应计入利息。

### <a id="2.14.10"></a>2.14.10　乌尔比安《评告示》第四卷

<a id="2.14.10.pr."></a>**序言。** 神圣马尔库斯皇帝的答复似乎要求全体债权人均应聚集。那么，如果有些债权人缺席，应如何处理？是否应令缺席者遵从到场者的决定？此外，如果享有优先权的债权人缺席，这项协议是否也对其不利，值得仔细考察；前提是该协议能够对缺席者发生效力。我再补充一点：在神圣马尔库斯皇帝规定上述形式之前，神圣庇护皇帝已经作出答复：在国库没有抵押权的情形下，国库以及其他享有优先权的债权人，也应遵从普通债权人所作的安排。所有这些规则，都应在没有抵押权的债权人之间予以维持。

<a id="2.14.10.1"></a>**1.** 如果协议附有罚金要式承诺，那么应适用协议抗辩，还是可以提起要式承诺之诉？萨宾认为，较妥当的意见是：由作出承诺的人选择使用其中任一途径；但如果他依据协议抗辩，公平而言，应视为他已通过受领清偿而解除该项要式承诺。

<a id="2.14.10.2"></a>**2.** 我们通常说，欺诈抗辩是协议抗辩的补充救济。尤利安和许多其他法学家都写道，有些人虽不能使用协议抗辩，仍可使用欺诈抗辩。例如，我的诉讼代理人订立协议时，特雷巴提乌斯认为欺诈抗辩对我有利；他认为，既然诉讼代理人的协议会对我不利，也就应对我有利——

### <a id="2.14.11"></a>2.14.11　保罗《评告示》第三卷

因为该项给付也可以向他作出。

### <a id="2.14.12"></a>2.14.12　乌尔比安《评告示》第四卷

此外，通说认为，无论我是委托他订立协议，还是他是管理我全部事务的诉讼代理人，该协议都会对我不利。普特奥拉努斯在《顾问集》第一卷中也如此写道，因为裁判者已经同意让诉讼代理人将此事项提交诉讼。

### <a id="2.14.13"></a>2.14.13　保罗《评告示》第三卷

<a id="2.14.13.pr."></a>**序言。** 但是，如果诉讼代理人仅受任处理某项诉讼，他订立的协议就不会对本人不利，因为给付也不能向该诉讼代理人作出。

<a id="2.14.13.1"></a>**1.** 如果诉讼代理人是为自己的利益而受任，则其地位视同本人，因此应遵守已经达成的协议。

### <a id="2.14.14"></a>2.14.14　乌尔比安《评告示》第四卷

众所周知，合伙事务负责人订立的协议既可能有利于合伙人，也可能对合伙人不利。

### <a id="2.14.15"></a>2.14.15　保罗《评告示》第三卷

尤利安写道，监护人订立的协议也有利于被监护人。

### <a id="2.14.16"></a>2.14.16　乌尔比安《评告示》第四卷

<a id="2.14.16.pr."></a>**序言。** 如果协议是在遗产买受人与出卖人之间订立，而遗产出卖人又向债务人请求给付，债务人可以援用欺诈抗辩。因为神圣庇护皇帝作出答复、准许遗产买受人提起有用诉讼后，遗产债务人当然可以对遗产出卖人提出欺诈抗辩。

<a id="2.14.16.1"></a>**1.** 同样，如果被出售物的所有人与买受人约定，买受人应返还所买的人；而代表所有人出售该物的人再请求买受人支付价款时，买受人可以对其提出欺诈抗辩。

### <a id="2.14.17"></a>2.14.17　保罗《评告示》第三卷

<a id="2.14.17.pr."></a>**序言。** 如果我交付你十，并约定你应欠我二十，则超过十的部分不产生债务关系；因为以交付之物成立的债务，只能在实际交付的范围内成立。

<a id="2.14.17.1"></a>**1.** 有些诉权会因协议而依法直接消灭，例如侵害之诉和盗窃之诉。

<a id="2.14.17.2"></a>**2.** 质押之诉可依据长官法上的协议产生；但如果我约定不再请求，质押之诉就会因抗辩而消灭。

<a id="2.14.17.3"></a>**3.** 如果我约定不得向我请求、但可以向我的继承人请求，该继承人不得援用此项抗辩。

<a id="2.14.17.4"></a>**4.** 如果我约定不得向我或提图斯请求，该协议不使提图斯受益，即使他后来成为我的继承人也是如此，因为事后不能使该协议发生追溯效力。尤利安以父亲订立协议为例：父亲约定不得向自己或女儿请求，而女儿后来成为父亲的继承人。

<a id="2.14.17.5"></a>**5.** 与出卖人订立的协议，如果是针对事项本身的协议，依多数意见也有利于买受人；庞波尼乌斯写道，我们遵循此规则。依萨宾的意见，即使协议针对特定人，也对买受人有效；他认为，即使通过赠与发生继承，也适用此规则。

<a id="2.14.17.6"></a>**6.** 多数法学家认为，如果他人遗产的占有人订立了协议，而真正继承人后来追夺遗产，该协议既不对继承人不利，也不使继承人受益。

<a id="2.14.17.7"></a>**7.** 如果家子或奴隶约定不得向其父亲或主人请求——

### <a id="2.14.18"></a>2.14.18　盖尤斯《评行省告示》第一卷

无论该协议涉及与家子或奴隶本人订立的合同，还是与其父亲或主人订立的合同，——

### <a id="2.14.19"></a>2.14.19　保罗《评告示》第三卷

<a id="2.14.19.pr."></a>**序言。** 他们均可取得抗辩。同样的规则也适用于基于善意而服役的奴隶。

<a id="2.14.19.1"></a>**1.** 如果家子约定不得向其本人请求，该协议对家子有利；如果原告依据特有产之诉起诉，该协议也对其父亲有利。

### <a id="2.14.20"></a>2.14.20　盖尤斯《评行省告示》第一卷

在利益归入之诉中对父亲起诉，或者经父亲选择而将其作为家子的准诉讼防御人起诉时，该协议也对父亲有利。
