# 第二卷

## 2.14　论协议（续）

### <a id="2.14.47"></a>2.14.47　斯凯沃拉《学说汇纂》第一卷

<a id="2.14.47.pr."></a>**序言。** 不动产买受人提供担保，承诺支付二十，并向要式承诺受领人作出保证。此后，出卖人通过担保文件约定接受十三，并在规定期限内收取。债务人就此约定：如果未在规定期限内支付该款项，出卖人可以依据最初的担保文件向他请求给付。我问：如果债务人未履行后来的约定，出卖人能否依据最初的担保文件请求全部债务？我答复：根据所陈述的事实，可以。

<a id="2.14.47.1"></a>**1.** 卢基乌斯·提图斯与货币兑换人盖尤斯·塞乌斯往来账目复杂，因此将其认定为自己的债务人，并收到对方一封信，信中写道：“根据你我在银行往来的账目，截至今日，多项合同尚有三百八十六留在我处，并应计付相应利息。你未在账目中记载、留在我处的金币总额，我将退还给你。你此前交付给我的任何金额、基于任何原因留在我处的任何文书——也就是书面凭证——均视为无效并予注销。”有人问：卢基乌斯·提图斯在收到这封债务确认信之前，曾委托货币兑换人塞乌斯向其保护人偿还三百；鉴于信中约定任何合同项下的担保文书均无效并视为注销，卢基乌斯·提图斯及其儿子是否不得再就该款向塞乌斯主张权利？我答复：如果该账目仅计算收支，其他债务仍依其原有法律关系存续。

### <a id="2.14.48"></a>2.14.48　盖尤斯《论十二表法》第三卷

在物的交付中，当事人无论作出何种协议，该协议显然均有效。

### <a id="2.14.49"></a>2.14.49　乌尔比安《评萨宾》第三十六卷

如果有人借出钱款，并约定仅在债务人有能力清偿的范围内起诉，该协议是否有效？较妥当的意见是协议有效。如果有人只要求在债务人财力允许的范围内向其请求，并无不当。

### <a id="2.14.50"></a>2.14.50　乌尔比安《评萨宾》第四十二卷

我认为，在寄托、使用借贷、租赁以及其他类似合同中，订立如下协议并非不可能：“不得使我的奴隶成为窃贼或逃奴。”也就是说，不得怂恿奴隶成为窃贼或逃奴；也不得疏于照管，以致奴隶沦为窃贼。正如奴隶被教唆、腐化时可以提起相应诉讼，同样也可以订立旨在防止奴隶被腐化的协议。

### <a id="2.14.51"></a>2.14.51　乌尔比安《评告示》第二十六卷

<a id="2.14.51.pr."></a>**序言。** 如果你认为自己的债务人因遗赠而欠你债务，并与其约定不得向他请求，那么正如凯尔苏斯在第二十卷所写，债务人既不因此依法直接免责，也不能在你向其请求时以协议抗辩阻却。

<a id="2.14.51.1"></a>**1.** 同样，如果你命令自己的债务人向提图斯付款，而你误以为提图斯因遗赠而欠你债务；你的债务人随后与提图斯订立协议，而提图斯由此成为他的债务人，那么你对自己债务人的诉权，以及你债务人对提图斯的诉权，均未消灭。

### <a id="2.14.52"></a>2.14.52　乌尔比安《意见集》第一卷

<a id="2.14.52.pr."></a>**序言。** 某人通过书信确认另一人为其共同继承人，该书信并不使其取得针对遗产占有人的请求权。

<a id="2.14.52.1"></a>**1.** 如果债务人与一名以债务事务管理人身份从债权人处买下设质土地的人约定，在抵销孳息并清偿剩余债务后，将土地返还债务人，那么，即使债务人死亡，其继承人也应履行死者订立的协议。

<a id="2.14.52.2"></a>**2.** 双方约定，如果债权人代为支付设质土地所涉的税费，可以向债务人追回；而由债务人缴纳该土地的税费。此协议正当，应予遵守。

<a id="2.14.52.3"></a>**3.** 有人准备以父亲遗嘱违反义务为由提起诉讼，并约定继承人在生存期间每年支付一定金额；其后又请求将该协议扩展为永久给付。皇帝答复说，该请求既无法律依据，也不符合公平，不应准许。

### <a id="2.14.53"></a>2.14.53　乌尔比安《意见集》第四卷

替诉讼当事人预付费用是正当的；但约定不返还实际支出的金额及合法利息，而仅返还该诉讼所获款项的一半，则不允许。

### <a id="2.14.54"></a>2.14.54　斯凯沃拉《尤利安学说汇纂》第二十二卷札记

如果我约定不请求本应交付给我的奴隶斯提库斯，这不构成对方迟延履行；我认为，如果斯提库斯在此后死亡，而被告在协议之前并未迟延，就不应由被告承担责任。
