# 第二卷

## <a id="2.4"></a>2.4　论传唤到庭

### <a id="2.4.1"></a>2.4.1　保罗《评告示》第四卷

传唤到庭，就是为审理法律争议而召人出庭。

### <a id="2.4.2"></a>2.4.2　乌尔比安《评告示》第五卷

不得传唤执政官、长官、裁判官、行省总督或其他享有统治权的官员到庭；他们既可以行使强制权，也可以命人入狱。不得在祭司举行祭祀时传唤祭司；因场所具有宗教神圣性而不能离开的人，也不得传唤；为公共事务乘坐公马出行的人，同样不得传唤。此外，不得传唤正在娶妻的男子或正在出嫁的女子；不得传唤正在审理案件的裁判者，也不得传唤当事人正在裁判官面前陈述案件时的任何一方；正在主持亲属丧礼或为死者举行正当葬仪的人，也不得传唤：

### <a id="2.4.3"></a>2.4.3　卡利斯特拉图《审判论》第一卷

送葬者也不得传唤；神皇兄弟的敕答似乎也确认了这一点：

### <a id="2.4.4"></a>2.4.4　乌尔比安《评告示》第五卷

<a id="2.4.4.pr."></a>**序言。** 因诉讼之故必须在法庭或某一特定地点出庭的人，也不得传唤；精神失常者和婴幼儿也不得传唤。

<a id="2.4.4.1"></a>**1.** 裁判官告示规定：“未经我的许可，任何人不得将父母、保护人或女保护人，以及保护人或女保护人的子女和父母传唤到庭。”

<a id="2.4.4.2"></a>**2.** 此处所称“父母”，包括父亲和母亲。但这一称谓是否无限延伸，曾有疑问。有人认为，“父母”只包括上至高祖父母（*tritavus*）的祖先，更高世代的称为远祖。庞波尼乌斯记载，古人持此见解；盖尤斯·卡西乌斯则认为，所有世代的祖先都属于父母之列。后者更合乎情理，也已被适当地采纳。

<a id="2.4.4.3"></a>**3.** 拉贝奥认为，父母也包括在奴隶身份期间生育子女的人；并且，正如塞维鲁所说，保护范围不限于合法婚生子女。即使儿子是非婚受孕，也不得将其母亲传唤到庭，

### <a id="2.4.5"></a>2.4.5　保罗《评告示》第四卷

因为母亲身份始终可以确定，即使她是非婚受孕；父亲则由婚姻关系显示。

### <a id="2.4.6"></a>2.4.6　保罗《箴言》第一卷

任何人都不得将自己的自然父母传唤到庭，因为所有父母都应受到同等的敬重。

### <a id="2.4.7"></a>2.4.7　保罗《评告示》第四卷

可以不受处罚地传唤收养父亲的父母，因为他们并非他的父母；他只与那些同时成为其宗亲的人建立亲属关系。〔此处 *cognatus* 与 *adgnatus* 的关系依收养身份而异，译文按底本文字暂译，见疑难表。〕
