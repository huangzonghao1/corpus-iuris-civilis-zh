# 第二卷

## <a id="2.14"></a>2.14　论协议

### <a id="2.14.1"></a>2.14.1　乌尔比安《评告示》第四卷

<a id="2.14.1.pr."></a>**序言。** 此项告示具有自然法上的公平性。还有什么比遵守人们之间达成的约定，更符合人类诚信呢？

<a id="2.14.1.1"></a>**1.** *Pactum*（协议）一词源自 *pactio*（约定）；“和平”一词也由此而来。

<a id="2.14.1.2"></a>**2.** 所谓 *pactio*，是两个或更多人就同一事项达成约定并取得合意。

<a id="2.14.1.3"></a>**3.** *Conventio*（合意）是一个涵盖范围广泛的词语，适用于相互交易或缔约之人因订立交易或解决争议而达成合意的一切情形。正如来自不同地点的人聚集并来到同一地点，被称为“会合”；同样，心意各不相同的人达成合意、归于同一意见，也被称为 *conventio*。该词的涵盖范围如此广泛，以至于佩狄乌斯精当地指出：没有任何合同或债务关系不包含合意，无论合同以物还是以言词成立；因为以言词作出的要式承诺，如果没有合意，也不发生效力。

<a id="2.14.1.4"></a>**4.** 但是，大多数合意会转入其他名称之下，例如买卖、租赁、质押或要式承诺。

### <a id="2.14.2"></a>2.14.2　保罗《评告示》第三卷

<a id="2.14.2.pr."></a>**序言。** 拉贝奥说，可以通过交付物品达成协议；即使当事人身处异地，也可以通过书信或使者达成协议。以默示合意达成协议，也是可以理解的。

<a id="2.14.2.1"></a>**1.** 因此，如果我将债务凭证交还给我的债务人，就可认为我们已经达成协议，我不再向其请求偿还；通说认为，债务人可以援用协议抗辩。

### <a id="2.14.3"></a>2.14.3　莫德斯蒂努斯《规则集》第三卷

如果质物已返还债务人，而债务尚未清偿，债权人仍可请求偿还债务，这一点毫无疑问；除非能够证明双方明确约定了相反内容。

### <a id="2.14.4"></a>2.14.4　保罗《评告示》第三卷

<a id="2.14.4.pr."></a>**序言。** 既然默示协议也有效，通说认为，在出租城市住宅时，承租人搬入的物品即为出租人的质物，即使双方没有就此作出任何明确约定。

<a id="2.14.4.1"></a>**1.** 依此规则，不能说话的人也可以订立协议。

<a id="2.14.4.2"></a>**2.** 为设定嫁资而作出的要式承诺，也可说明这一规则。若在婚前请求该项给付，属于不当请求；这仿佛双方已明确约定以婚姻成立为条件。若婚姻最终未成，要式承诺即依法自行失效。尤利安也持此见解。

<a id="2.14.4.3"></a>**3.** 有人就具体情形请示：双方约定，在利息清偿之前不得请求本金，但要式承诺却写成无条件的。对此答复认为，该条件应视为已包含于要式承诺之中，犹如双方已将其明文写出。

### <a id="2.14.5"></a>2.14.5　乌尔比安《评告示》第四卷

协议有三种：基于公共事由的协议和基于私人事由的协议；私人协议又分为法定协议和万民法协议。所谓公共协议，是指通过和平条约达成的协议，例如交战双方的统帅彼此约定某些事项。

### <a id="2.14.6"></a>2.14.6　保罗《评告示》第三卷

法定协议，是指经某项法律确认的协议。因此，有时协议会产生诉权或消灭诉权，这是因为法律或元老院决议对此予以支持。
