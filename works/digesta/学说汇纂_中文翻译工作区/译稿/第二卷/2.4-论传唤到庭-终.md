# 第二卷

## 2.4　论传唤到庭（续）

### <a id="2.4.20"></a>2.4.20　盖尤斯《评《十二表法》》第一卷

毫无疑问，任何人都可以从门口、浴场或剧场被传唤到庭。

### <a id="2.4.21"></a>2.4.21　保罗《评告示》第一卷

即使有时可以传唤在家中的人到庭，也不得将任何人从自己的住宅中强行拖出。

### <a id="2.4.22"></a>2.4.22　盖尤斯《评《十二表法》》第一卷

<a id="2.4.22.pr."></a>**序言。** 不得将尚未达到青春期、且处于他人权力之下的女孩传唤到庭。

<a id="2.4.22.1"></a>**1.** 被传唤到庭的人在两种情形下应获释：有人为其出庭辩护；或者在前往法庭途中，双方已就争议事项达成和解。

### <a id="2.4.23"></a>2.4.23　马尔基安《法学阶梯》第三卷

即使一名自由释奴有数位保护人，他也应请求裁判官许可自己传唤其中某一位保护人，以免受到裁判官告示的处罚。

### <a id="2.4.24"></a>2.4.24　乌尔比安《评告示》第五卷

对于违反上述规定的人，可以提起罚金为五十奥里金币的诉讼；该诉讼不得由继承人提起，不得针对继承人提起，也不得在一年之后提起。

### <a id="2.4.25"></a>2.4.25　莫德斯蒂努斯《论刑罚》第一卷

如果自由释奴未经裁判官准许，便将保护人传唤到庭，保护人提出申诉后，自由释奴要么支付上述罚金，即五十奥里金币；要么，如果查明其确实贫困，则由城市长官以不敬之名对其予以惩戒。
