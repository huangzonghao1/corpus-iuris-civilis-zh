# 第二卷

## <a id="2.8"></a>2.8　论应提供担保、宣誓承诺或依其承诺承担责任者

### <a id="2.8.1"></a>2.8.1　盖尤斯《评行省告示》第五卷

“提供担保”（*satisdatio*）与“满足要求”（*satisfactio*）使用相同词根。正如我们说，满足某人的要求，就是实现其所愿；我们说向对方提供担保，就是指对方为其向我们提出的请求要求我们作出保证，使我们通过提供保证人令其获得保障。

### <a id="2.8.2"></a>2.8.2　乌尔比安《评告示》第五卷

<a id="2.8.2.pr."></a>**序言。** 为保证被传唤者到庭而提供的保证人，是否具备清偿能力，不仅取决于其财产，也取决于能否方便地对其提起诉讼。

<a id="2.8.2.1"></a>**1.** 如果某人为依法不得起诉的人提供了到庭保证人，该项担保即属无效。

<a id="2.8.2.2"></a>**2.** 裁判官规定：“如果有人将父母、保护人或女保护人、保护人或女保护人的子女或父母、自己的子女、处于自己权力之下的人、妻子或儿媳传唤到法庭，应接受任何保证人，以确保其到庭。”

<a id="2.8.2.3"></a>**3.** 裁判官所说的“自己的子女”，也包括经由女性后代而来的子女。“父母”也适用这一优待，不仅包括自权人，也包括处于他人权力之下的人；庞波尼乌斯作此说明。儿子即使处于他人的权力之下，也可以为父亲充当保证人。此处所称“儿媳”，还包括孙媳及其后代的妻子。

<a id="2.8.2.4"></a>**4.** 裁判官所说“应接受任何保证人”，是指就财产资力而言，即使保证人并无足够资力也应接受。

<a id="2.8.2.5"></a>**5.** 对于承诺保证某人到庭的保证人，裁判官准许提起以案件价值为金额的诉讼。该金额究竟应依实际价值，还是依其他数量确定？较妥当的意见是：保证人应按实际价值承担责任，除非他明确只就某一确定金额提供担保。

### <a id="2.8.3"></a>2.8.3　盖尤斯《评行省告示》第一卷

无论该项诉讼请求赔偿双倍、三倍还是四倍，我们都认为同一保证人应始终按该倍数承担责任，因为该物即被视为具有相应价值。

### <a id="2.8.4"></a>2.8.4　保罗《评告示》第四卷

如果提供到庭保证的当事人死亡，裁判官就不应命令保证人交出该当事人。如果裁判官不知情而已经下令，或者作出命令后、约定交人之日之前该当事人死亡，就应拒绝针对保证人的诉讼。但如果他在约定交人之日之后死亡，或丧失罗马公民身份，则仍可有效地针对保证人提起诉讼。

### <a id="2.8.5"></a>2.8.5　盖尤斯《评行省告示》第一卷

<a id="2.8.5.pr."></a>**序言。** 如果某人为已被判决承担责任的人提供了保证，而该被判决者随后死亡或丧失罗马公民身份，仍可合法地对其保证人提起诉讼。

<a id="2.8.5.1"></a>**1.** 如果有人拒绝接受明显具备清偿能力的保证人，或者在资力存疑时拒绝接受经认可的保证人，就可能对其提起侵害之诉。因为拒绝一个已提供充分适格保证人的被传唤者，确实并非轻微侵害。被拒绝的保证人本人也可以就其所受侵害提出申诉。

### <a id="2.8.6"></a>2.8.6　保罗《评告示》第十二卷

每当担保或保证书以不合规则的方式作出时，就视为没有提供担保。

### <a id="2.8.7"></a>2.8.7　乌尔比安《评告示》第十四卷

<a id="2.8.7.pr."></a>**序言。** 如果没有人否认保证人具有适格性，只是指出他享有本地法院管辖特权，而原告担心他会援用这一特权，就要考察法律对此如何规定。神皇庇护曾以敕答致科尔内利乌斯·普罗库卢斯——庞波尼乌斯《书信集》、马尔凯卢斯《学说汇纂》第三卷和帕皮尼安《法律问题》第三卷也都记载了这封敕答——指出原告拒绝这样的保证人有正当理由；但如果无法以其他方式取得担保，应事先告知保证人：若有人对其起诉，他不得援用该特权。

<a id="2.8.7.1"></a>**1.** 如果担保属于强制担保，而被告难以在受诉地点提供，若他愿意在同一行省的另一座城市提供担保，可以准许他这样做。但如果担保是自愿提供的，就不应让他改到别处提供；因为这是他自己给自己设定的义务，他不值得获得这种便利。

<a id="2.8.7.2"></a>**2.** 如果涉及动产的担保尚未提供，而相关人员又有可疑之处，经裁判者认为适当，应将有关财物交由官署保管，直至提供担保或诉讼终结。
