# 第二卷

## <a id="2.1"></a>2.1　论司法管辖权

### <a id="2.1.1"></a>2.1.1　乌尔比安《规则》第一卷

行使司法权者的职务范围极广：他可以授予遗产占有，可以命令将人置于占有状态，可以为没有监护人的未成年人指定监护人，也可以为诉讼当事人指定裁判者。

### <a id="2.1.2"></a>2.1.2　雅沃列努斯《摘自卡西乌斯》第六卷

凡被授予司法管辖权的，也视为同时获授行使该管辖权所不可缺少的权限。

### <a id="2.1.3"></a>2.1.3　乌尔比安《论财务官职务》第二卷

统治权（*imperium*）有纯粹统治权与混合统治权之分。所谓纯粹统治权，是指享有刑杀权（*gladii potestas*），得以惩治犯罪者；这也称为强制权（*potestas*）。混合统治权则包含司法管辖权，其内容包括授予遗产占有。司法管辖权还包括指定裁判者的权限。

### <a id="2.1.4"></a>2.1.4　乌尔比安《评告示》第一卷

命令提供裁判官程式上的担保，以及命令将人置于占有状态，较属于统治权，而非司法管辖权。

这是因为，该人并未独立取得司法管辖权，法律本身也没有授予该权；法律只是确认已经委托的司法管辖权。因此，拉贝奥认为，如果委托司法管辖权的人在受托者开始处理案件之前死亡，委托即告终止，与其他委托情形相同。

### <a id="2.1.7"></a>2.1.7　乌尔比安《评告示》第三卷

<a id="2.1.7.pr."></a>**序言。** 如果有人出于恶意，毁损张贴在公告板、纸张或其他材料上的内容，而该内容是为持续公布司法管辖权之用，并非仅因个案发生而临时张贴，则可对其提起罚金为五百奥里金币的公众诉讼。

<a id="2.1.7.1"></a>**1.** 告示的文字也涵盖奴隶和家子；裁判官还明确包括男女两性。

<a id="2.1.7.2"></a>**2.** 如果有人在内容张贴过程中或张贴之前将其毁损，告示的字面规定虽不适用，庞波尼乌斯却认为，应将告示的意旨扩及这些情形。

<a id="2.1.7.3"></a>**3.** 对于奴隶，如果主人不为其辩护；以及对于贫困者，应对其施以身体拷问。

<a id="2.1.7.4"></a>**4.** 告示之所以提到恶意，是因为如果某人是出于不熟练或无知，或受裁判官命令，或偶然为之，就不承担责任。

<a id="2.1.7.5"></a>**5.** 该告示也适用于移走公告内容的人，即使他没有毁损内容；也适用于亲手实施者以及命令他人实施者。如果他人并无恶意，而命令者有恶意，则由命令者承担责任；如果双方均出于恶意实施行为，则双方都承担责任。如果多人实施、毁损或下令实施，则所有人都承担责任：

### <a id="2.1.9"></a>2.1.9　保罗《评告示》第三卷

如果某人的家内奴仆毁损公告板，本告示不像盗窃告示那样规定：只要主人愿意为奴仆辩护，并以该奴仆名义支付相当于自由人应支付的数额，就不得再对其他奴仆提起诉讼。或许这是因为，此处还要惩治对裁判官威严的蔑视，并且被视为发生了多个行为；这就如同多个奴隶共同实施侵害或造成损害，因为那是多个行为，而不像盗窃那样视为一个行为。奥克塔维努斯认为，此处也应救济主人；但只有在他们出于恶意安排他人毁损公告板时，才可以这样说，因为此时只有一个共同计划，而非多个行为。庞波尼乌斯在其《评昆图斯·穆基乌斯》第十卷中也作此注。

### <a id="2.1.10"></a>2.1.10　乌尔比安《评告示》第三卷

行使司法管辖权的人，不得就涉及自己、妻子、子女、自由释奴或其他随行人员的事项行使司法权。
