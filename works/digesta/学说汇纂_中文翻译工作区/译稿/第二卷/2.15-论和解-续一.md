# 第二卷

## 2.15　论和解（续）

### <a id="2.15.7"></a>2.15.7　乌尔比安《论争议》第一卷

<a id="2.15.7.pr."></a>**序言。** 判决作出后，如果已经提起上诉，或者当事人仍可以提起上诉，仍可达成和解。

<a id="2.15.7.1"></a>**1.** 如果保证人被起诉并被判负给付判决，其后主债务人与保证人所代表的债权人达成和解，该和解是否有效？我认为有效，因为主债务人与保证人所负的全部责任均因此解除。但是，如果是已被判负给付判决的保证人本人达成和解，尽管和解并未消灭既有判决效力，已支付的款项仍应抵减判决债务。

<a id="2.15.7.2"></a>**2.** 即使支付的款项不足以构成和解，也会减少判决债务。因此，未经裁判官授权而就扶养费达成和解时，已支付的款项仍应抵作扶养费；如果依据扶养费关系尚有更多款项应予支付，只须支付尚欠部分，并将已支付款项予以抵扣。

### <a id="2.15.8"></a>2.15.8　乌尔比安《论各类审判庭》第五卷

<a id="2.15.8.pr."></a>**序言。** 有些人获遗赠扶养费后，往往轻易与继承人达成和解，只满足于立即收到一笔少量款项。神圣马尔库斯皇帝在元老院宣读诏谕，规定除非经裁判官授权，否则扶养费和解不发生效力。因此，裁判官通常会介入，即使双方已达成一致，也会判断是否应准许和解，或应准许何种和解。

<a id="2.15.8.1"></a>**1.** 无论遗赠的是住所、衣物供给，还是来自土地收益的扶养费，均由同一裁判官审理和解事宜。

<a id="2.15.8.2"></a>**2.** 该诏谕适用于以遗嘱或补充遗嘱文件留下的扶养费，无论其与遗嘱相关还是由无遗嘱继承安排留下；也适用于因死亡而赠与的扶养费，以及受领死亡赠与的人后来留下的扶养费；若扶养费是为履行某项条件而留下，也适用同一规则。但是，非因死亡而赠与的扶养费，可以不经裁判官授权而和解。

<a id="2.15.8.3"></a>**3.** 无论扶养费是按月、按日还是按年留下，该诏谕均适用；即使并非永久给付，而仅约定给付若干年，也适用同一规则。

<a id="2.15.8.4"></a>**4.** 如果有人遗赠一笔完整的本金，要求受领人以其利息维持生活，并在死亡时返还本金，该诏谕仍适用，尽管该给付看起来并非按年支付。

<a id="2.15.8.5"></a>**5.** 如果遗赠给提图斯一笔确定金额或一项财产，要求其以此供给塞乌斯扶养费，较妥当的意见是提图斯可以和解，因为提图斯的和解不会减少塞乌斯的扶养费。若通过遗嘱信托将扶养费留给遗赠受领人，也适用同一规则。

<a id="2.15.8.6"></a>**6.** 该诏谕所反对的，是为提前取得款项并立即花用而进行的和解。那么，如果有人未经裁判官授权和解，将原本每年取得的款项改为每月取得，或者将每月取得改为每日取得，又或者将每年年终取得改为年初取得，应如何处理？我认为此类和解有效，因为受领扶养费者的地位因此得到改善；该诏谕旨在防止当事人通过和解截断扶养费，并非禁止有利于受领人的安排。

<a id="2.15.8.7"></a>**7.** 不论获遗赠扶养费的是自由民还是自由释奴，也不论其资力是否充足，均不影响适用该诏谕。

<a id="2.15.8.8"></a>**8.** 因此，该诏谕要求裁判官考察这些事项：首先是和解事由，其次是和解金额，第三是和解当事人的身份。

<a id="2.15.8.9"></a>**9.** 就和解事由而言，应考察当事人为何和解；若无正当理由，裁判官不会受理任何和解请求。通常提出的理由包括：继承人和扶养费受领人居住在不同住所；或者其中一方计划迁居；或者有某种原因使其急需现款；或者扶养费是由多人分别留下、逐一向各人请求十分困难；或者存在其他正当理由——此类情形往往很多——足以使裁判官准许和解。

<a id="2.15.8.10"></a>**10.** 还应评估和解所涉金额，例如和解金额的大小；和解的诚信也会依据金额加以判断。金额应根据和解者的年龄及健康状况确定：显然，与儿童、青年或老年人和解时，标准各不相同，因为扶养费在受领人死亡时终止。

<a id="2.15.8.11"></a>**11.** 还应考察当事人的情况，即获遗赠扶养费者的生活状况：他们是否生活节俭、能够自给，还是较为挥霍、依赖扶养费。对于留下扶养费的人，则应考察其财产状况、意图及声誉；由此才能看出，他是否意图利用和解欺骗对方。
