# 第二卷

## 2.14　论协议（续）

### <a id="2.14.55"></a>2.14.55　尤利安《学说汇纂》第三十五卷

如果债务人是用益权人，而其享有用益权的奴隶约定不得向债务人请求，该奴隶通过协议使债务人的法律地位得到改善。同样，如果债权人是用益权人，并约定不再请求债务；而享有用益权的奴隶约定应当请求债务，那么债权人也可以依该奴隶订立的协议有效请求债务。

### <a id="2.14.56"></a>2.14.56　尤利安《致米尼基乌斯》

如果土地所有人与佃户约定土地所有人不向佃户请求某项给付，而且该协议有正当理由，佃户仍可以向土地所有人提出请求。

### <a id="2.14.57"></a>2.14.57　弗洛伦提努斯《法学阶梯》第八卷

<a id="2.14.57.pr."></a>**序言。** 如果某人预先收取债务人的利息，应视为其默示约定，在该期间内不请求本金。

<a id="2.14.57.1"></a>**1.** 如果协议一方将协议针对事项本身作出，另一方则将协议针对特定人作出，例如一方约定“我不请求”，另一方约定“不得向你请求”，那么我的继承人仍可向你们所有人请求；而对于你们的继承人，我们所有人仍可请求。

### <a id="2.14.58"></a>2.14.58　内拉提乌斯《札记》第三卷

毫无疑问，在买卖、租赁以及其他类似合同中，只要双方尚未履行任何义务，所有负有合同义务的人均可通过合意解除合同。阿里斯托的看法更进一步：如果我已履行买卖合同中应向你履行的义务，而你尚欠我价款；我们约定你向我返还我先前交付给你的买卖标的物，而我不再支付价款；你也已经向我返还了这些物品，那么你就不再欠我价款。因为一切均依诚信解释，该解释也允许此种约定。无论双方是在尚未履行任何义务时约定解除交易，还是在我已经履行自己义务后同意你不再向我履行任何给付，均无区别。但是，如果双方约定解除既有交易，就不能由此使你负有返还我已经履行给付的义务；因为那样做并非单纯解除原交易，而是在双方之间设立新的债务关系。

### <a id="2.14.59"></a>2.14.59　保罗《规则集》第三卷

通说认为，凡可以通过其人以要式承诺为我们取得利益者，也可以通过其人订立协议，使我们的法律地位得到改善。

### <a id="2.14.60"></a>2.14.60　帕皮里乌斯《敕令集》第八卷

安东尼努斯皇帝答复阿维狄乌斯·卡西乌斯：如果债权人愿意从财产中接受一部分清偿，即使是由第三人提供，该安排也应优先考虑必要关系人，但以他们具有清偿能力为限。

### <a id="2.14.61"></a>2.14.61　庞波尼乌斯《评萨宾》第九卷

任何人均不得通过协议使自己无权将自己的土地奉献为宗教场所、不得在自己的土地上埋葬死者，或者不得违背邻居意愿出售土地。

### <a id="2.14.62"></a>2.14.62　福里乌斯《评告示》第一卷

如果债务人先前约定不再请求债务，因此该协议开始使保证人也受益；之后债务人又约定可以向自己请求，那么先前协议对保证人产生的利益是否也随之消失？较妥当的意见是，一旦保证人取得协议抗辩，就不得违背其意愿再将该抗辩从其手中夺走。
