<a id="33.2.34.pr."></a>**33.2.34 序言**　他在遗嘱附录中以如下文字设立遗嘱信托：“我愿将我希望安葬之处的庄园交给我的自由男女释奴以及我在遗嘱附录中释放的人；他们之中谁先去世，其份额即归其余者增加，直至最后一人；我愿在最后一人去世后，该庄园归阿雷拉特人的公共团体。此外，我的自由男女释奴在世期间，得居住于宅中；帕克提亚和特罗菲玛可居住其惯常使用的全部房间；我愿在她们去世后，该宅归公共团体。”问题是，遗赠给公共团体的遗嘱信托究竟是由继承人承担，还是由自由人承担。答称，依所陈述的情形，这些文字可以解释为：遗嘱信托是委托给最后去世的受遗赠人。又问，若若干获留居住权的自由人已经去世，他们曾居住的房屋份额是否已归公共团体。答称，只要其中仍有一人存世，就不应向公共团体履行遗嘱信托。

<a id="33.2.36.pr."></a>**序言**　斯提库斯依遗嘱获释，并获遗赠一座庄园的用益权；立遗嘱人又将继承人置于信托之下，要求他们在斯提库斯停止使用和收益该庄园时，将庄园交给卢基乌斯·提图斯。然而，斯提库斯在自己的遗嘱中将同一庄园的所有权遗赠给其孙辈，斯提库斯的继承人遂依其遗嘱将庄园交给这些受遗赠的孙辈。问题是，受遗赠的孙辈不知前一份遗嘱所设定的上述庄园条件，并已占有超过规定期间，他们是否取得了该庄园。答称，依所陈述的情形，受遗赠人已为自己取得该庄园。

<!-- source-p 247 -->

<a id="4"></a><a id="33.4"></a>**33.4.0 论预先遗赠的嫁资**（*De dote praelegata*）。

<!-- source-p 267 -->
<a id="33.4.1"></a>**33.4.1**

<!-- source-p 268 -->
乌尔比安《萨宾评注》第十九卷。

<!-- source-p 269 -->
<a id="33.4.1.pr."></a>**序言**　嫁资被重新遗赠时，确实应认为，该嫁资遗赠包含嫁资诉讼中所包含的权利。

<!-- source-p 270 -->
<a id="33.4.1.1"></a>**1**　因此，若丈夫与妻子约定：丈夫死亡、婚姻解除且有共同儿子时，嫁资留在丈夫继承人手中；而丈夫临终时又将嫁资重新遗赠，则不得因嫁资已被重新遗赠而遵守该约定。即使没有重新遗赠，也应认可这一结论。因为允许在子女介入时使嫁资状况恶化的规则，仅在妻子于婚姻关系存续期间死亡或发生离婚时适用。

<!-- source-p 271 -->
<a id="33.4.1.2"></a>**2**　而且，确实，重新遗赠嫁资有立即交付这一利益，即使嫁资原应按年度日期给付：

<!-- source-p 272 -->
<a id="33.4.1.3"></a>**3**　此外，若立遗嘱人未改变其意思，根据元老院决议，今日对赠与之物不再进行任何追索。

<!-- source-p 273 -->
<a id="33.4.1.4"></a>**4**　费用依法当然减少嫁资。但我们所说的“费用依法当然减少嫁资”，并非指逐一减少各个物，而是应就作为整体的嫁资而言。

<!-- source-p 274 -->
<a id="33.4.1.5"></a>**5**　重新遗赠嫁资所包含的嫁资诉讼权如此完整，以至于若丈夫生前已将嫁资返还给妻子（当然，仅限法律允许的情形），该遗赠即告终止。

<!-- source-p 275 -->
<a id="33.4.1.6"></a>**6**　此外，若嫁资中包括未作价的奴隶，而这些奴隶已经死亡，则针对这些奴隶的嫁资遗赠即告消灭。

<!-- source-p 276 -->
<a id="33.4.1.7"></a>**7**　又若妻子承诺提供嫁资却未曾给付，而丈夫临终时将嫁资预先遗赠给妻子，则妻子所得仅为免除给付义务。因为，若某人遗赠“我箱中所存的一百”或“某人寄存在我处的物品”，而该物并不存在，显然无需给付任何东西，因为并无此等物存在。

<!-- source-p 277 -->
<a id="33.4.1.8"></a>**8**　若某人以如下文字将提提乌斯庄园遗赠给妻子：“因为该庄园是因她而归我所有的”，则无论如何都应给付该庄园；因为对已经充分特定之物再作补充说明，纯属多余。

<!-- source-p 278 -->
<a id="33.4.1.9"></a>**9**　塞尔苏斯在《学说汇纂》第二十卷中写道：若岳父将嫁资重新遗赠给儿媳，若其意在重新遗赠嫁资诉讼权，该遗赠便毫无效力，因为儿媳已婚；但若他意在使她取回嫁资钱款，则遗赠有效。不过，即使儿媳已取回嫁资，丈夫仍有权追索嫁资：若丈夫被指定为继承人，可提起遗产分割诉讼；若未被指定为继承人，则可提起准诉讼。我认为，由于岳父并非意在使继承人两次给付嫁资，妻子依遗嘱提起诉讼时，应作出担保，确保继承人将受到对丈夫的抗辩保护。反过来，丈夫若先行起诉，也应作出同样担保，确保继承人将受到对妻子的抗辩保护。

<!-- source-p 279 -->
<a id="33.4.1.10"></a>**10**　相反，尤利安在《学说汇纂》第三十七卷中讨论：若岳父将嫁资遗赠给其被剥夺继承权之子的新妇，他说，虽不得向被剥夺继承权的丈夫请求嫁资，但丈夫仍可基于遗赠追索嫁资；不过，只有在他承诺继承人将受到对该女子的抗辩保护时，才能取得遗赠。他还区分了嫁资被重新遗赠给某人、以及将特有产遗赠给亡主释奴的情形：他说，亡主释奴仍可就特有产被起诉，但继承人不能，因为该特有产已不再由其占有；而嫁资诉讼则仍可提起，即使丈夫已不再持有嫁资。

<!-- source-p 280 -->
<a id="33.4.1.11"></a>**11**　同一尤利安又问：岳父若将嫁资重新遗赠给女婿，而嫁资已向妻子清偿，女婿的遗赠是否消灭。他说应消灭，因为已无任何东西可向女婿给付。

<!-- source-p 281 -->
<a id="33.4.1.12"></a>**12**　他又问：若嫁资遗赠给第三人，并要求该人返还给妻子，《法尔基丢法》是否适用于该遗赠。他说适用；但遗嘱信托中不足的部分，妻子可通过嫁资诉讼取得。我则问，在此种遗赠中，是否也应承认立即交付的利益，如同嫁资重新遗赠给妻子本人一样。我认为应当承认。

<!-- source-p 282 -->
<a id="33.4.1.13"></a>**13**　同一尤利安又问：嫁资若重新遗赠给妻子，并要求妻子返还嫁资，《法尔基丢法》是否适用。他否认适用，因为他也否认遗嘱信托有效。若此外还向妻子遗赠其他财产，他认为应从剩余部分履行遗嘱信托；该部分当然应在考虑《法尔基丢法》后给付妻子。又若岳父将嫁资预先遗赠给被指定为部分继承人的丈夫，该嫁资遗赠仍受《法尔基丢法》扣减，因为婚姻仍存续时，重新遗赠嫁资似乎尚非债务；但丈夫可在遗产分割诉讼中预先取得《法尔基丢法》所扣减之数额，正如若未重新遗赠，他本可预先取得全部嫁资。

<!-- source-p 283 -->
<a id="33.4.1.14"></a>**14**　梅拉写道：若嫁资中包含一处庄园，且庄园被特别遗赠，随后又以一般文字重新遗赠嫁资，则该庄园只应给付一次，而非两次。

<!-- source-p 284 -->
<a id="33.4.1.15"></a>**15**　梅拉在同处补充：若丈夫将嫁资中的庄园出租至特定期限，妻子只有在承诺允许承租人继续使用庄园的条件下，才能基于重新遗赠取得该庄园；但租金应由妻子收取。

<!-- source-p 285 -->
<a id="33.4.2"></a>**33.4.2**

<!-- source-p 286 -->
乌尔比安《讨论》第五卷。

<!-- source-p 287 -->
<a id="33.4.2.pr."></a>**序言**　某人将嫁资重新遗赠给妻子，并将遗嘱信托托付给她时，该遗嘱信托应依妻子因重新遗赠所取得的利益评定；塞尔苏斯在《学说汇纂》第二十卷中也如此写道。若发生依法当然减少嫁资的必要费用，还可进一步认为：若丈夫将其收受的嫁资全额重新遗赠，则应认为该笔可供履行遗嘱信托的金额也包括依法当然减少嫁资的部分，因为无人会怀疑妻子是受遗赠人。又若遗赠给妻子的并非嫁资本身，而是以嫁资为名的其他财物，仍应视为重新遗赠了嫁资。尤利安还写道，即使未明言遗赠是以嫁资为名，只要留下该遗赠的意思如此，也仍属此种性质。因此，妻子若被要求返还嫁资本身、以嫁资名义遗赠的财物，或被记入账目以代替嫁资的财物，仅须在我们前述范围内返还。故妻子若被指定为继承人，并被要求返还继承财产数额，她仅须返还超过嫁资数额的部分，以及她因立即交付而取得的利益。又若某人收受儿媳的嫁资后指定儿子为继承人，并要求儿子返还其从遗产所得的一切，后来儿子因妻子去世而取得嫁资，则他无须返还从嫁资所得之物，因为他是基于婚姻关系而取得，并非基于父亲的遗嘱安排。

<!-- source-p 288 -->
<a id="33.4.2.1"></a>**1**　某女子承诺提供四百的嫁资，其中以两处庄园交付二百，此外又以债务人债权记账抵偿其余二百。其后丈夫去世，遗赠给她两处并非其收受为嫁资的庄园；此外，又将那两处作为嫁资收受且已估价的庄园遗赠给她，并托付她在去世时将从其遗产中取得的一切返还给塞尤斯。问题是，女子去世后，遗嘱信托的数额应为多少。我答称：该女子虽受托返还从遗嘱中所得的一切，但她只须返还扣除嫁资数额后所得之物；因为她与其说是收取嫁资，不如说是取回嫁资，但仍须保留其因立即交付的利益而可托付返还之部分。因此，就丈夫以嫁资名义遗赠给她的财物而言，若其价值未超过嫁资数额，她无须返还；其余额外遗赠给她的财物，则须连同其所取得的孳息返还。因此，她可优先取得嫁资及其孳息；至于额外遗赠给她的财物，则应将其实际取得的孳息一并返还。

<!-- source-p 303 -->
帕皮尼安《疑义》第十八卷。

<!-- source-p 304 -->
<a id="33.4.7.pr."></a>**序言**　父亲将从儿媳处收受的嫁资遗赠给被剥夺继承权的儿子。若父亲的继承人提出诈欺抗辩，在有人就婚姻解除时的补偿作出担保以前，不得强令其清偿遗赠。

<!-- source-p 305 -->
<a id="33.4.7.1"></a>**1**　但若在向儿子清偿遗赠以前，妻子已经取回嫁资，则儿子基于该遗赠提起诉讼徒劳无益。

<!-- source-p 306 -->
<a id="33.4.7.2"></a>**2**　但若《法尔基丢法》适用于向被剥夺继承权的儿子所作的嫁资遗赠，且妻子认可了清偿，则就继承人扣留的金额，可向其提起准嫁资诉讼。若妻子不认可该清偿，继承人虽应受其丈夫已承诺提供的抗辩保护；但若丈夫独自承受全部诉讼，而又未作担保，则就依《法尔基丢法》可请求的数额，可向继承人提起判决之诉。

<!-- source-p 307 -->
<a id="33.4.7.3"></a>**3**　若妻子在向儿子清偿遗赠之前离婚，尽管她本人尚不能预先取得嫁资，儿子的诉权也不因此延期；因为已有答复认为，在父亲的遗产被部分继承、且儿子取得继承人身份后，婚姻解除时，儿子可在同一到期日取得嫁资。

<!-- source-p 308 -->
<a id="33.4.7.4"></a>**4**　若因错误而遗漏抗辩担保，儿子基于遗嘱信托原因取得嫁资，便不应请求返还其所取得的非债务给付。因为提供担保的义务只是延缓清偿，并不使原本应付之物变成非债务给付；不过，给予继承人救济也并非不公。

<!-- source-p 309 -->
<a id="33.4.7.5"></a>**5**　那么，若父亲的继承人无清偿能力呢？是否不应公正地允许妻子向丈夫提起准嫁资诉讼？嫁资不应因此灭失，因为继承人只是错误地没有作出担保。

<a id="33.5.9.pr."></a>**序言**　若遗嘱写道：“我将斯提库斯交付并遗赠给提图斯，但以他未选择潘菲卢斯为条件；若他未选择斯提库斯，则将潘菲卢斯交付并遗赠给同一提图斯”，这与写道“我将斯提库斯或潘菲卢斯交付并遗赠给提图斯，由其选择其中一人”相同。

<!-- source-p 375 -->
<a id="33.5.9.1"></a>**1**　有人问：若命令斯提库斯附条件获释，同时我获遗赠奴隶选择权，或者一般性地遗赠给我一名奴隶，法律应如何处理。我答称：作出附条件释放斯提库斯并给予奴隶选择权的人，较合理的理解是并未将斯提库斯纳入考虑；正如已知，给予即时自由的人也未将该人纳入考虑。因此，若我选择或指定斯提库斯，选择便不发生效力，我仍可从其余奴隶中选择。

<!-- source-p 376 -->
<a id="33.5.9.2"></a>**2**　在同一情形中又问：已给予奴隶选择权，但在我作出选择之前，所附释放条件未成就，我能否选择斯提库斯。我认为应赞同穆基乌斯的见解：使遗赠消灭的是自由本身，而不是预定给予自由。因此，无论释放条件在立遗嘱人生前，还是在其死后、遗产被接受之前未成就，遗赠均可有效实现；因为附条件自由与无条件自由一样，自遗产被接受时起才发生效力。因此，我可以选择斯提库斯。
