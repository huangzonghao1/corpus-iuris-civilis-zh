# D.33.6–D.33.7（底本 source-p 425–636）分段译稿

〔范围说明：本底本范围实际自 D.33.6.3 起，至 D.33.7.26 止；卷内题名与锚点均依底本保留。〕

<!-- source-p 425 -->
<a id="33.6.3"></a>**33.6.3**

<!-- source-p 426 -->
**乌尔比安：《萨比努斯评注》第二十三卷。**

<!-- source-p 427 -->
<a id="33.6.3.pr."></a>**序言。**如果遗赠给某人一百安瓿葡萄酒，而立遗嘱人没有留下任何葡萄酒，继承人应购买葡萄酒并予以给付，而不应给付虽曾被列入葡萄酒之数、但实际上是醋的液体。

<!-- source-p 428 -->
<a id="33.6.3.1"></a>**1.**如果遗赠了葡萄酒，应考察是否也包括容器。塞尔苏斯说，即使没有明确将容器一并遗赠，遗赠葡萄酒时也应认为容器一并遗赠；这并非因为容器是葡萄酒的一部分——正如银器上的镶嵌装饰（例如酒杯或镜子的装饰）并非银器本身的一部分——而是因为可以相信立遗嘱人的意思是将安瓿作为葡萄酒的附属物。他说，我们平常也会说自己没有一千只安瓿，是以葡萄酒的计量方式来表达。至于大酒瓮，我认为，遗赠葡萄酒时不应认为它们也被遗赠；尤其是酒瓮埋在酒窖中，或因体积巨大而难以移动时。对于桶或小桶，我认为可以认定其也被遗赠；但若同样固定在土地上，犹如土地的生产设备，则不在此列。遗赠葡萄酒时，不包括皮囊，也不包括大型革制酒袋。

<!-- source-p 429 -->
<a id="33.6.4"></a>**33.6.4**

<!-- source-p 430 -->
**保罗：《萨比努斯评注》第四卷。**

<!-- source-p 431 -->
如果遗赠了一定重量的橄榄油，却未说明质量等级，通常不考察立遗嘱人惯常使用哪一等级的油，也不考察该地区的人惯常使用哪一等级的油。因此，继承人可以自行选择任何等级的橄榄油给付受遗赠人。

<!-- source-p 432 -->
<a id="33.6.5"></a>**33.6.5**

<!-- source-p 433 -->
**尤利安：《学说汇纂》第十五卷。**

<!-- source-p 434 -->
遗嘱遗赠了若干安瓿葡萄酒，并规定须从塞姆普罗尼乌斯土地上所产葡萄酒中给付；但该土地的产量不足。通说认为，不应给付超过实际产量的数量；“该土地所产”一语起到了限定数额的作用。

<!-- source-p 435 -->
<a id="33.6.6"></a>**33.6.6**

<!-- source-p 436 -->
**普罗库鲁斯：《书信集》第五卷。**

<!-- source-p 437 -->
如果继承人被判令给付葡萄酒，应给付装在安瓿和酒坛中的葡萄酒，即使遗嘱未提及容器也是如此。同样，即使遗赠的葡萄酒附带容器，也应认为包括大酒瓮中的葡萄酒；这正如某人将所有奴隶连同每人的特有产一并遗赠时，即使某些奴隶没有特有产，也仍应认为他们一并被遗赠。

<!-- source-p 438 -->
<a id="33.6.7"></a>**33.6.7**

<!-- source-p 439 -->
**雅沃勒努斯：《拉贝奥后编》第二卷。**

<!-- source-p 440 -->
<a id="33.6.7.pr."></a>**序言。**某人命令继承人向妻子给付葡萄酒、橄榄油、谷物、醋、蜂蜜和腌鱼。特雷巴提乌斯认为，各项物品不应超过继承人愿意给妻子的数量，因为遗嘱未规定每种物品各给多少。奥菲利乌斯、卡斯凯利乌斯和图贝罗认为，立遗嘱人留下的全部此类物品均为遗赠。拉贝奥赞同后一意见；此说正确。

<!-- source-p 441 -->
<a id="33.6.7.1"></a>**1.**遗嘱写道：“我的继承人应给卢基乌斯·提提乌斯一百摩狄乌斯小麦，每一摩狄乌斯均重一百磅。”奥菲利乌斯认为没有遗赠，因为世间并不存在这种小麦；拉贝奥也赞同。我认为这才是正确的意见。

<!-- source-p 442 -->
<a id="33.6.8"></a>**33.6.8**

<!-- source-p 443 -->
**庞波尼乌斯：《书信集》第六卷。**

<!-- source-p 444 -->
如果继承人被判令给付大酒瓮中的葡萄酒，而受遗赠人妨碍其接受，继承人倒掉葡萄酒就会面临风险。但通说认为，如果受遗赠人不赔偿因其迟延而使继承人遭受的损失，继承人可以对其请求葡萄酒的诉讼提出诈欺抗辩，使其请求被驳回。

<!-- source-p 445 -->
<a id="33.6.9"></a>**33.6.9**

<!-- source-p 446 -->
**乌尔比安：《萨比努斯评注》第二十三卷。**

<!-- source-p 447 -->
<a id="33.6.9.pr."></a>**序言。**如果某人遗赠葡萄酒，所有由葡萄藤所产且仍保持为葡萄酒的酒均包括在内。如果葡萄酒制成了蜂蜜酒，严格说来不包括在“葡萄酒”一词之内，除非家父确有此意。确实，在某些行省用小麦、大麦或面包制成的啤酒（*zythum*）不包括在内；同理，*camum*、啤酒（*cervesia*）和蜂蜜水（*hydromeli*）也不包括在内。香料酒是否包括在内？我认为也不包括，除非立遗嘱人另有意思。葡萄蜜酒（*oenomeli*），即最甜的葡萄酒，显然包括在内；葡萄干酒（*passum*）也包括在内，除非立遗嘱人意思相反；葡萄汁浓缩液（*defrutum*）不包括在内，因为它更像调味品。葡萄干酿的 *acinaticium* 显然属于葡萄酒。榅桲饮料（*cydoneum*）及其他并非由葡萄藤制成的饮料，不包括在“葡萄酒”一词之内；醋也不包括在内。但以上各物只有在立遗嘱人没有将其视为葡萄酒时，才不按葡萄酒处理。否则，萨比努斯写道，凡家父视为葡萄酒的，均包含在“葡萄酒”之中；因此，家父视为葡萄酒的醋，以及 *zythum*、*camum* 和其他依人们的认识与习惯被视为葡萄酒的饮料，也都包括在内。如果家父所拥有的全部葡萄酒都变酸，遗赠并不因此消灭。

<!-- source-p 448 -->
<a id="33.6.9.1"></a>**1.**如果有人遗赠醋，则遗赠不包括立遗嘱人视为葡萄酒的醋；但包括调味醋汁（*embamma*），因为它被视为醋。

<!-- source-p 449 -->
<a id="33.6.9.2"></a>**2.**同样，如果某人遗赠自己所拥有的葡萄酒，之后这些酒变酸，即使家父后来将其转入醋类，仍包括在葡萄酒遗赠中；因为所指的是立遗嘱时属于葡萄酒的物品。除非遗嘱人的意思相反，否则此说正确。

<!-- source-p 450 -->
<a id="33.6.9.3"></a>**3.**如果遗赠父亲留下的葡萄酒，只有立遗嘱人本人视为葡萄酒的部分才属于遗赠，而非其父亲视为葡萄酒的部分。同样，如果遗赠奴隶的特有产中的葡萄酒，则包括奴隶所拥有的葡萄酒。为何规则不同？因为父亲的葡萄酒已开始成为立遗嘱人本人使用的物品，而特有产中的葡萄酒仍供奴隶使用。

<!-- source-p 451 -->
<a id="33.6.9.4"></a>**4.**同样，如果遗赠的是陈年葡萄酒，……

<!-- source-p 452 -->
<a id="33.6.10"></a>**33.6.10**

<!-- source-p 453 -->
**赫莫杰尼安努斯：《法学摘要》第二卷。**

<!-- source-p 454 -->
应依立遗嘱人的惯常做法确定遗赠范围，也就是他将陈年多少年的酒视为陈年酒。若无法查明，……

<!-- source-p 455 -->
<a id="33.6.11"></a>**33.6.11**

<!-- source-p 456 -->
**乌尔比安：《萨比努斯评注》第二十三卷。**

<!-- source-p 457 -->
陈年酒应理解为并非新酒；因此，前一年的酒也包括在“陈年酒”之中。

<!-- source-p 458 -->
<a id="33.6.12"></a>**33.6.12**

<!-- source-p 459 -->
**保罗：《萨比努斯评注》第四卷。**

<!-- source-p 460 -->
否则，遵循其他解释的人又将以何时为陈年酒的界限或起点呢？

<!-- source-p 461 -->
<a id="33.6.13"></a>**33.6.13**

<!-- source-p 462 -->
**乌尔比安：《萨比努斯评注》第二十三卷。**

<!-- source-p 463 -->
遗嘱写道：“我的继承人应当每年给付十安瓿葡萄酒，取自该土地所产的葡萄酒。”萨比努斯认为，如果某年没有收成，继承人应从该土地上一年所产葡萄酒中给付十安瓿。只要立遗嘱人的意思不相反，我也赞同这一意见。

<!-- source-p 464 -->
<a id="33.6.14"></a>**33.6.14**

<!-- source-p 465 -->
**庞波尼乌斯：《萨比努斯评注》第六卷。**

<!-- source-p 466 -->
遗赠葡萄酒时，只有未被保留作长期使用、而是用于盛酒的容器随同给付，例如安瓿和酒坛。

<!-- source-p 467 -->
<a id="33.6.15"></a>**33.6.15**

<!-- source-p 468 -->
**普罗库鲁斯：《书信集》第二卷。**

<!-- source-p 469 -->
某人将葡萄酒连同容器一并遗赠。特雷巴提乌斯否认大酒瓮中的葡萄酒应予给付，并认为立遗嘱人的意思与遗嘱文字不同；他还认为大酒瓮不属于盛酒容器。即使大酒瓮并非这类盛酒容器，我也不会赞同特雷巴提乌斯的意见，认为大酒瓮中的葡萄酒（即未装在上述容器中的葡萄酒）不属于遗赠。我认为，遗赠葡萄酒连同容器时，受遗赠人取得我们用来盛装葡萄酒的安瓿和酒坛。我们将葡萄酒倒入安瓿和酒坛，是为了让酒留在其中直至适于饮用；显然，我们出售葡萄酒时也连同这些安瓿和酒坛一并出售。至于将酒倒入大酒瓮，则出于不同目的：此后可再将酒分装到安瓿和酒坛中，也可连同大酒瓮一起出售。〔底本此段有 *non essententiarum* 等疑似粘连或讹误文字，译文依上下文暂作通顺处理。〕

<!-- source-p 470 -->
<a id="33.6.16"></a>**33.6.16**

<!-- source-p 471 -->
**普罗库鲁斯：《拉贝奥后编》第三卷。**

<!-- source-p 472 -->
<a id="33.6.16.pr."></a>**序言。**某人将全部葡萄酒遗赠给你，包括以瓮盛装的苏伦廷葡萄酒。拉贝奥和特雷巴提乌斯答复说，以皮制量器盛装的葡萄酒也属于遗赠。

<!-- source-p 473 -->
<a id="33.6.16.1"></a>**1.**如果遗赠了“甜食”，而遗嘱未作其他说明，则包括所有下列物品：蜂蜜酒、葡萄干酒、葡萄汁浓缩液及类似饮料，也包括葡萄、无花果、椰枣和干无花果。

<!-- source-p 474 -->
<a id="33.6.16.2"></a>**2.**如果遗嘱如此规定：“阿米奈乌姆葡萄酒、希腊安瓿酒以及所有甜食”，拉贝奥根据“安瓿葡萄酒”一词认为，“甜食”仅包括饮料，不包括其他物品；我不反对这一解释。

<!-- source-p 475 -->
<a id="7"></a><a id="33.7"></a>**33.7.0　论设备或生产用具遗赠**

<!-- source-p 476 -->
<a id="33.7.1"></a>**33.7.1**

<!-- source-p 477 -->
**保罗：《萨比努斯评注》第四卷。**

<!-- source-p 478 -->
<a id="33.7.1.pr."></a>**序言。**无论遗赠的是连同生产用具的土地，还是设备齐全的土地，均应视为作出了两项遗赠。

<!-- source-p 479 -->
<a id="33.7.1.1"></a>**1.**土地连同生产用具一并遗赠后，如果该土地被转让，就不得依据死者的意思主张取回生产用具。

<!-- source-p 480 -->
<a id="33.7.2"></a>**33.7.2**

<!-- source-p 481 -->
**帕比尼安：《答复集》第七卷。**

<!-- source-p 482 -->
<a id="33.7.2.pr."></a>**序言。**父亲指定数名儿子为继承人，并在各自继承份额之外，将祖母遗产中的若干财产以先取遗赠方式给其中两人。通说认为，受遗赠人应按与共同继承人相等的人头份额取得。

<!-- source-p 483 -->
<a id="33.7.2.1"></a>**1.**土地所负担的担保，希腊语称 *ennykae*（原文作 *envykai*），若遗赠的并非设备齐全的土地，则不应由受遗赠人承担。〔*ennykae* 的确切含义及底本拼写有待核查。〕

<!-- source-p 484 -->
<a id="33.7.3"></a>**33.7.3**

<!-- source-p 485 -->
**帕比尼安：《答复集》第八卷。**

<!-- source-p 486 -->
<a id="33.7.3.pr."></a>**序言。**主人在遗嘱中将设备齐全的土地遗赠给被释奴；后来他在遗嘱补编中请求：每名被释奴死亡时，都应将其土地份额返还给仍在世者，却未提及土地的设备。通说认为，土地应按遗赠时的状况交付；期间所增生的幼畜、后代，以及因意外而发生的损失，也包括在遗嘱信托范围内。

<!-- source-p 487 -->
<a id="33.7.3.1"></a>**1.**一名未满二十岁的人希望将设备齐全的地产给其表亲，并在生前释放了若干地产奴隶。不能因为这些奴隶原属地产设备就将其交付，因为他们已获得自由。同样，基于任何其他原因已取得自由的，也适用相同规则。

<!-- source-p 488 -->
<a id="33.7.4"></a>**33.7.4**

<!-- source-p 489 -->
**雅沃勒努斯：《拉贝奥后编》第二卷。**

<!-- source-p 490 -->
某人有两块相连的土地；牛在一块土地上劳作后，会返回另一块土地。他将两块土地连同生产用具一并遗赠。拉贝奥和特雷巴提乌斯认为，牛应归于其实际劳作的土地，而非惯常居住的土地；卡斯凯利乌斯持相反意见。我赞同拉贝奥的意见。

<!-- source-p 491 -->
<a id="33.7.5"></a>**33.7.5**

<!-- source-p 492 -->
**拉贝奥：《高论》第一卷。**

<!-- source-p 493 -->
如果你想将土地及其生产用具遗赠给某人，采用何种文字并无区别，无论写“土地连同生产用具”“土地和生产用具”，还是“设备齐全的土地”，均可。保罗说：恰恰相反，这些遗赠文字有所区别；如果立遗嘱人在以“土地连同生产用具”遗赠后、死亡前转让了土地，则该文字下没有任何物品被遗赠；但采用其他两种文字，生产用具仍可能构成遗赠。

<!-- source-p 494 -->
<a id="33.7.6"></a>**33.7.6**

<!-- source-p 495 -->
**斯凯沃拉：《学说汇纂》第十六卷。**

<!-- source-p 496 -->
遗嘱将遗嘱人在某一地区拥有的地产遗赠给其外孙，并规定依当时状况连同葡萄酒、谷物和账簿一并交付；又补充道：“我死亡时在该地区的一切，不论属于何种类别，只要是我的财产，均包括在内。”立遗嘱人还在世时，一名债务人被判令还款，却未履行判决。有人问，该项判决债权是否归外孙取得。答复说，没有理由认为该债权不应给付。

<!-- source-p 497 -->
<a id="33.7.7"></a>**33.7.7**

<!-- source-p 498 -->
**斯凯沃拉：《学说汇纂》第二十二卷。**

<!-- source-p 499 -->
某人以遗嘱将店铺连同楼上房间遗赠给获释女奴帕杜拉，并附带遗赠店铺中的货物、用具和家具；他还遗赠了酒窖，连同其中的葡萄酒、容器、用具及其惯常雇用的经理。立遗嘱人仍在世时，楼上房间所在的公寓楼被烧毁；两年后在原址建起新楼。遗赠给帕杜拉的酒窖则被立遗嘱人出售，但葡萄酒的出售被推迟，以便获得较好的价款。有人问，帕杜拉能否取得全部遗赠。答复说，立遗嘱人已改变意思的那些物品不应给付。

<!-- source-p 500 -->
<a id="33.7.8"></a>**33.7.8**

<!-- source-p 501 -->
**乌尔比安：《萨比努斯评注》第二十卷。**

<!-- source-p 502 -->
<a id="33.7.8.pr."></a>**序言。**萨比努斯在《维特利乌斯评注》中明确列举了土地生产用具的范围：凡为取得、收集或保存收成而备置的物品均属此类。取得收成所需的物品，例如耕种土地的人，以及管理、监督他们的人；管理者中包括管事和监工。此外还有驯养的牛、为施肥而饲养的牲畜，以及农耕用具，如犁、锄、耙、修枝镰、双齿锄等类似物品。收集收成所需的物品，例如榨汁机、篮筐、收割镰、割草镰、采葡萄和收葡萄用的镰刀，以及搬运葡萄的容器。保存收成所需的物品，例如大酒瓮，即使没有埋入地下，以及桶。

<!-- source-p 503 -->
<a id="33.7.8.1"></a>**1.**在某些地区，如果庄园较为精致，还包括室内管事和清扫工；若庄园有花园，还包括园丁；若土地包括林地和牧场，则包括牲畜群、牧人和林地看守人。

<!-- source-p 504 -->
<a id="33.7.9"></a>**33.7.9**

<!-- source-p 505 -->
**保罗：《萨比努斯评注》第四卷。**

<!-- source-p 506 -->

<a id="33.7.12"></a>**33.7.12**

<!-- source-p 514 -->
**乌尔比安：《萨比努斯评注》第二十卷。**

<!-- source-p 515 -->
<a id="33.7.12.pr."></a>**序言。**有人问，为耕作者备作口粮的谷物是否属于生产用具。多数人认为不属于，因为口粮会被消耗；生产用具是指能够长期存在、且为经营土地所必需的设备。此外，口粮主要为生活而非耕作准备。不过我认为，为口粮准备的谷物和葡萄酒也包括在生产用具中；塞尔维乌斯的学生们记载，他曾如此答复。还有人认为，为播种而储存的谷物也属于生产用具；我认为这是因为播种属于耕作，并且这些谷物虽会被消耗，却会不断补充。但种子与口粮的理由并无不同。

<!-- source-p 516 -->
<a id="33.7.12.1"></a>**1.**为保存收成而准备的物品也包括在内，例如谷仓，因为收成储存在其中；还有盛放收成的坛子和小箱。为运走收成而备置的物品也属于生产用具，例如牲畜、车辆、船只、木桶和大型皮囊。

<!-- source-p 517 -->
<a id="33.7.12.2"></a>**2.**阿尔费努斯认为，如果遗嘱另行遗赠了若干奴隶，土地上其余奴隶就不包括在生产用具中，因为他认为有生命的生物不属于用具。这并不正确：显然，因耕作土地而在土地上工作的奴隶属于生产用具。

<!-- source-p 518 -->
<a id="33.7.12.3"></a>**3.**有人问，像佃农一样在土地上生活的奴隶，是否包括在遗赠的生产用具内。拉贝奥和佩加苏斯正确地否认这一点，因为该奴隶并非作为土地的生产用具而置于该处，即使他惯常命令其他家奴也不例外。

<!-- source-p 519 -->
<a id="33.7.12.4"></a>**4.**关于林地看守人，拉贝奥认为，只有为保护收成而设置的看守人才包括在内；为看守边界而设置的则不包括。奈拉提乌斯也将后者包括在内；我们采用此规则，即所有林地看守人均包括在内。

<!-- source-p 520 -->
<a id="33.7.12.5"></a>**5.**特雷巴提乌斯还认为，为乡村家奴服务而备置的面包师和理发师也包括在内；为修缮庄园而备置的工匠，以及烤面包、照管庄园的妇女也包括在内。若磨坊工为乡村使用而备置，也包括在内；若炉灶女工和女管事以某种职责协助男管事，也包括在内；为乡村家奴制衣的纺织女工，以及为他们烹制食物的妇女，同样包括在内。

<!-- source-p 521 -->
<a id="33.7.12.6"></a>**6.**有人问，生产用具本身的辅助设备是否也包含在生产用具遗赠中：为乡村家奴准备的纺织女工、羊毛、理发师、洗衣工和炉灶女工，并非土地的设备，而是土地设备的辅助物。我认为，炉灶女工〔底本异文作男厨工〕也包括在内；前述纺织女工及其他人员亦然。塞尔维乌斯的学生们记载，他也曾作此答复。

<!-- source-p 522 -->
<a id="33.7.12.7"></a>**7.**可以相信，立遗嘱人还希望将上述人员的妻子和幼儿一并包括在遗赠中，因为他们也住在同一庄园；不能认为他意在强行拆散他们。

<!-- source-p 523 -->
<a id="33.7.12.8"></a>**8.**如果牲畜一年中只有一部分时间在土地上放牧，其余时间另行租用饲料；或者奴隶只在部分时间耕作土地，其余时间被出租收取租金，他们仍属于生产用具。

<!-- source-p 524 -->
<a id="33.7.12.9"></a>**9.**账务管事，即被安排负责账簿安全的人，以及门房和骡夫，显然也属于生产用具。

<!-- source-p 525 -->
<a id="33.7.12.10"></a>**10.**磨盘和机器、干草、秸秆、用于驱动机器的驴、谷物加工机、用于熬煮葡萄汁浓缩液和制作浓缩葡萄汁的铜锅，以及为饮水和供家奴洗涤而准备的水，都属于生产用具；筛子和用于运出粪肥的车辆也包括在内。

<!-- source-p 526 -->
<a id="33.7.12.11"></a>**11.**卡西乌斯写道，附着于土地的物品不属于土地生产用具，例如尚未砍伐的芦苇丛和柳树林，因为土地本身不可能成为土地的生产用具。但如果已经砍伐，我认为就应包括在内，因为这些物品用于取得收成。木桩也适用同一规则。

<!-- source-p 527 -->
<a id="33.7.12.12"></a>**12.**如果土地上有狩猎活动，我认为猎人、追踪者、猎犬及其他狩猎所需物品也属于生产用具；如果该土地以狩猎取得收益，尤其如此。

<!-- source-p 528 -->
<a id="33.7.12.13"></a>**13.**如果土地收益来自捕鸟，捕鸟人、捕鸟网及其他捕鸟用具也包括在土地生产用具中。这并不奇怪，因为萨比努斯和卡西乌斯认为，鸟类也像蜜蜂一样属于生产用具。

<!-- source-p 529 -->
<a id="33.7.12.14"></a>**14.**如果同一套生产用具用于多块土地，应考察它属于哪块土地。我认为，如果能看出家父意在将其指定给哪一块土地，那么它就属于该土地；其他土地只是从这块土地借用设备。如果无法查明，则不属于任何一块土地；因为我们不能将生产用具按份额分割。

<!-- source-p 530 -->
<a id="33.7.12.15"></a>**15.**庄园中为了使家父生活更为齐备而置备的其他家具，并不包括在土地生产用具中。

<!-- source-p 531 -->
<a id="33.7.12.16"></a>**16.**如果遗赠的是房屋用具，应考察包括哪些物品。佩加苏斯说，房屋用具是为防风雨或防火而准备的物品，不包括为了享乐而准备的物品。因此，屋内用于御寒或遮阳的玻璃窗板和帘幕均不应给付。卡西乌斯也持此意见；他认为，用具与装饰之间有重大区别：用具是与房屋保护有关的物品，装饰则取决于个人喜好，例如绘画。

<!-- source-p 532 -->
<a id="33.7.12.17"></a>**17.**卡西乌斯认为，基利基亚帘布属于房屋用具，因为它们用于防止建筑物受风雨损害。

<!-- source-p 533 -->
<a id="33.7.12.18"></a>**18.**多数人和佩加苏斯认为，为灭火而备置的醋、厚毯、消防水管、长杆、梯子、钩具、海绵、水桶和扫帚也包括在内。〔若干器具名称 *formiones*、*amas* 的含义不详，译文暂按消防及清洁器具处理。〕

<!-- source-p 534 -->
<a id="33.7.12.19"></a>**19.**若瓦片和梁木是为房屋之需而备置，且专供此用途而不能另作他用，也属于房屋用具。同样，若有房屋必需的支撑物，也包括在房屋用具中。

<!-- source-p 535 -->
<a id="33.7.12.20"></a>**20.**塞尔苏斯写道，庭院露天部分张挂的帘幕，以及柱子周围的帘幕，更应列入家具；萨比努斯和卡西乌斯也如此认为。

<!-- source-p 536 -->
<a id="33.7.12.21"></a>**21.**水管、抓钩和水桶显然包括在房屋用具中。

<!-- source-p 537 -->
<a id="33.7.12.22"></a>**22.**此外，用以清除蜘蛛网的长杆、擦拭柱子、地面和台座的海绵，以及放在天花板旁使用的梯子，都属于用具，因为它们能使房屋更加洁净。

<!-- source-p 538 -->
<a id="33.7.12.23"></a>**23.**帕比尼安在《答复集》第七卷中也说，固定在房屋上的印章和雕像不属于房屋用具，而是房屋的一部分；未固定的则不属于房屋用具，因为应列入家具。未固定的铜制日晷除外：他认为它也属于房屋用具。同样，如果房屋门廊有帘幕，他说帘幕也属于房屋用具。

<!-- source-p 539 -->
<a id="33.7.12.24"></a>**24.**喷泉水管、水槽、蓄水盆，以及其他用于喷水的必需物品，还有门闩和钥匙，更应视为房屋的一部分，而非房屋用具。

<!-- source-p 540 -->
<a id="33.7.12.25"></a>**25.**我也认为，固定安装的玻璃窗板更属于房屋的一部分。买卖房屋时，玻璃窗板和脚手架均随房屋转移，不论它们当时安装在建筑物上，还是暂时拆下。但如果这些物品虽未安装，却专为补缺而储存，则更应包括在房屋用具中。

<!-- source-p 541 -->
<a id="33.7.12.26"></a>**26.**我认为，栏栅也包括在房屋用具中。

<!-- source-p 542 -->
<a id="33.7.12.27"></a>**27.**如果遗赠的不是“连同生产用具的土地”，而是“设备齐全的土地”，有人问其范围是否更广。萨比努斯在《维特利乌斯评注》中写道，必须承认，遗赠“设备齐全的土地”比遗赠“连同生产用具的土地”范围更广；我们看到这一意见日益普及并得到巩固。那么，这项遗赠究竟广泛到何种程度？萨比努斯作出界定，卡西乌斯在《维特利乌斯评注》中补充说：凡为使家父生活更为齐备而放置在该处的物品，均包括在“设备齐全”之中，也就是他为使自己生活更为齐备而放在那里的物品。因此，这种遗赠似乎留下的不是土地的生产用具，而是立遗嘱人自己的全部用具。

<!-- source-p 543 -->
<a id="33.7.12.28"></a>**28.**因此，若遗赠的是设备齐全的土地，也包括在那里供立遗嘱人自己使用的家具；被褥和他惯常在那里穿用的衣物不仅包括床上用品，也包括其他衣物；还有象牙桌或其他桌子、玻璃器皿、金银器。若那里有为立遗嘱人自用而存放的葡萄酒，也包括在内；其他日用物品亦然。

<!-- source-p 544 -->
<a id="33.7.12.29"></a>**29.**但若某些物品并非为立遗嘱人自己使用，而是为保管而堆放在那里，则不包括在内；储藏室中的葡萄酒也不随土地转移。我们适用此规则：家父像在仓库中那样存放于该处的物品，不包括在内。

<!-- source-p 545 -->
<a id="33.7.12.30"></a>**30.**塞尔苏斯在《学说汇纂》第十九卷中也写道，若收成储存在那里是为了出售，或用于与该土地无关的其他用途，则不属于设备齐全土地的遗赠。

<!-- source-p 546 -->
<a id="33.7.12.31"></a>**31.**塞尔苏斯在同卷还说，家具搬运工及此类奴隶也包括在内，即在该土地上为立遗嘱人服务的奴隶，但已获得自由者除外；他们惯常住在乡村。

<!-- source-p 547 -->
<a id="33.7.12.32"></a>**32.**如果遗赠设备齐全的土地，立遗嘱人为自己在那里到来时能在餐厅随时得到服务而安排的随侍少年，也包括在内。

<!-- source-p 548 -->
<a id="33.7.12.33"></a>**33.**设备齐全土地的遗赠也包括奴隶的同居伴侣，即妻子，以及他们的子女；这一点正确。

<!-- source-p 549 -->
<a id="33.7.12.34"></a>**34.**显然，若遗赠的是设备齐全的土地，为立遗嘱人到来时使用而放置在那里的图书馆和书籍也包括在内。但如果他把那里当作图书仓库，则应作相反解释。

<!-- source-p 550 -->
<a id="33.7.12.35"></a>**35.**奈拉提乌斯在《书信集》第四卷中答复鲁菲努斯说，遗赠设备齐全的土地时，家具、葡萄酒和奴隶均包括在内；奴隶不仅包括为庄园耕作、看守而置备者，也包括在那里供家父本人役使者。

<!-- source-p 551 -->
<a id="33.7.12.36"></a>**36.**只有用于装饰庄园的画像才应视为已遗赠。

<!-- source-p 552 -->
<a id="33.7.12.37"></a>**37.**帕比尼安还说，遗赠设备齐全的地产时，暂时停留在那里的奴隶不包括在内；立遗嘱人并无意将其纳入该土地或其个人用具。

<!-- source-p 553 -->
<a id="33.7.12.38"></a>**38.**帕比尼安还答复说，遗赠设备齐全的地产时，为整理事务而被派往行省、并将在事务处理完毕后返回原岗位的管事也随地产遗赠，即使他尚未返回。

<!-- source-p 554 -->
<a id="33.7.12.39"></a>**39.**帕比尼安还答复说，遗赠设备齐全的花园时，为使主人在那里生活更为齐备而存放的葡萄酒也包括在内。但如果主人在那里设有仓库，以便为城市或其他地产提供设备，则属于另一种情况。

<!-- source-p 555 -->
<a id="33.7.12.40"></a>**40.**帕比尼安还答复说，翁布里乌斯·普里穆斯以遗嘱信托将房屋连同家具留给显贵克劳狄乌斯·希罗尼米亚努斯；家父赴任总督之前，为将桌子及其他家具放在更安全之处而移至花园的物品，也包括在房屋遗赠中。

<!-- source-p 556 -->
<a id="33.7.12.41"></a>**41.**帕比尼安还答复说，立遗嘱人为休养而留在那里的解毒药及其他药品，以及因休养而存放在那里的衣物，也包含在设备齐全土地的遗赠中。

<!-- source-p 557 -->
<a id="33.7.12.42"></a>**42.**帕比尼安还答复说，遗赠设备齐全、并附带全部权利的房屋时，城市家奴以及其劳务也供其他地产使用的工匠不包括在内。但门房、园丁、房间侍者和水务仆役若仅服务于该房屋，则包括在内。他关于工匠的意见并不正确：如果工匠是为该房屋而备置，即使也借给其他地产使用，仍应包括在内。

<!-- source-p 558 -->
<a id="33.7.12.43"></a>**43.**帕比尼安还答复说，遗赠设备齐全的房屋时，象牙桌和书籍不包括在内；这一意见也不正确，因为房屋中凡为使家父在那里生活更为齐备而置备的物品，均应包括在内，毫无疑问，家父的家具属于房屋用具。奈拉提乌斯在《书信集》第四卷中答复其兄马尔凯卢斯说，遗赠设备齐全的房屋也包括房屋衣物；他指出，尤其在所述情形中更是如此：立遗嘱人明确排除了银器和账簿；既然排除了这两类物品，就应认为他意在遗赠房屋中的其他物品。帕比尼安本人也在同卷中说，一名商人兼放贷人指定两个儿子和两个女儿为继承人，并遗赠：“我将设备齐全的房屋给我的儿子，并命令予以交付。”有人问，货物和质物是否包括在内；审判员在考察父亲其他财产后，容易推断其意思。

<!-- source-p 559 -->
<a id="33.7.12.44"></a>**44.**塞尔苏斯写道，遗赠在地产上居住的奴隶时，其替代奴隶不包括在内，除非能够看出立遗嘱人也考虑了替代奴隶。

<!-- source-p 560 -->
<a id="33.7.12.45"></a>**45.**帕比尼安在《答复集》第七卷中还答复说，丈夫希望女儿作为继承人将房屋中的一切交给妻子；但债务凭证和购买奴隶的契据并不视为遗赠，除非从其他部分看出丈夫也考虑了奴隶，也就是他希望遗赠购买那些自己也意在归妻子所有的奴隶的价款。

<!-- source-p 561 -->
<a id="33.7.12.46"></a>**46.**如果有人遗赠“设备齐全的土地”，又补充遗赠家具、奴隶或其他某一项原未明确列出的物品，有人问该补充是否缩小了遗赠范围。帕比尼安答复说，不能认为遗赠被缩小；相反，该项补充只是为了更加明确。

<!-- source-p 562 -->
<a id="33.7.12.47"></a>**47.**帕比尼安在《答复集》第七卷中说：母亲将设备齐全的花园遗赠给儿子，却将女用银器遗赠给女儿。答复说，若母亲在花园中放置女用银器是为了使自己在那里生活更为齐备，该银器仍归女儿。

<a id="33.7.13"></a>**33.7.13**

<!-- source-p 564 -->

<!-- source-p 565 -->
<a id="33.7.13.pr."></a>**序言。**奈拉提乌斯认为，遗赠旅店店铺的用具时，也包括经理。但应考察旅店店铺的设备与旅店经营业务的设备是否有所区别：店铺设备可能仅指场所本身的器具，如大酒瓮、器皿、餐钩、酒杯、酒勺等用餐时惯常传递的物品，以及铜壶、量酒器和其他类似物品；而“旅店”既指一种营业活动，也包括经营经理。

<a id="33.7.15.pr."></a>**序言。**如果遗嘱如此规定：“我将为经营、布置店铺、面包房和旅店所制作、准备的一切物品遗赠给你”，塞尔维乌斯答复说，这些文字视为遗赠了面包房中的马匹和面包师、旅店中的经理和炉灶女工，以及这些店铺中的货物。

<!-- source-p 573 -->
<a id="33.7.15.1"></a>**1.**有人答复说，遗赠设备齐全的房屋时，家具也被遗赠，但葡萄酒不包括在内，因为房屋不能被认为是以葡萄酒配备齐全。

<!-- source-p 574 -->
<a id="33.7.15.2"></a>**2.**如果遗赠的是连同生产用具或设备齐全的土地，长期负责看守庄园的女管事也包括在内，正如林地看守人一样；理由相同：庄园和土地都需要看守。林地看守人负责防止邻人侵占土地或收成；庄园看守人则负责防止他人侵占庄园里的其他物品。毫无疑问，庄园本身是土地的一部分。

**马尔基安：《法学阶梯》第七卷。**

<!-- source-p 582 -->
<a id="33.7.17.pr."></a>**序言。**遗赠画师用具时，蜡、颜料及类似物品均包括在内；画笔、烙具和颜料碟也包括在内。

<!-- source-p 583 -->
<a id="33.7.17.1"></a>**1.**阿里斯托说，捕鱼用具包括为捕捉鱼类而购置的小船；较妥当的意见还认为，渔夫也包括在内。

<!-- source-p 584 -->
<a id="33.7.17.2"></a>**2.**有人说，遗赠浴场用具时，浴场管理员也随浴场用具遗赠；正如遗赠土地用具时包括林地看守人和园丁，遗赠旅店用具时包括旅店经理一样，因为浴场没有浴场管理员便不能正常使用。

<!-- source-p 585 -->
<a id="33.7.18"></a>**33.7.18**

<!-- source-p 586 -->
**保罗：《维特利乌斯评注》第二卷。**

<!-- source-p 587 -->
<a id="33.7.18.pr."></a>**序言。**考察肉铺用具时，应排除肉类本身；为切割肉类而备置的桌子、秤和工具，以及磅秤、刀、斧等，均属于肉铺用具。

<!-- source-p 588 -->
<a id="33.7.18.1"></a>**1.**遗赠某项用具时，有时也必须考察立遗嘱人本人的身份。例如，遗赠面包房用具时，如果家父本人经营面包房，面包师也可能包括在内；因为关键在于这些用具是为面包师本人准备，还是为面包房经营准备。

<!-- source-p 589 -->
<a id="33.7.18.2"></a>**2.**奈拉提乌斯否认磨坊驴和磨盘属于土地生产用具。

<!-- source-p 590 -->
<a id="33.7.18.3"></a>**3.**我们认为，锅和煎锅属于土地生产用具，因为没有这些器皿便无法烹制食物。悬在炉火上方的铜锅与普通炖锅并无重大区别：前者加热饮水，后者烹煮食物。如果铜锅属于生产用具，那么向铜锅中注水的水罐也会被归入同类；如此一来，便会无限延展，将每一种相邻的物品逐一并入。佩狄乌斯因此说，最好的办法不是拘泥于词语的专门含义，而应首先考察立遗嘱人意在表示什么，然后再考察当地居民通常如何理解。

<!-- source-p 591 -->
<a id="33.7.18.4"></a>**4.**有人问管事是否包括在生产用具中，问题尚未确定，遂咨询斯凯沃拉。斯凯沃拉答复说，如果管事不是按固定租金耕作土地，而是以对主人的忠诚负责经营，就应当给付。

<!-- source-p 592 -->
<a id="33.7.18.5"></a>**5.**有人又就磨坊下磨石咨询斯凯沃拉。斯凯沃拉答复说，如果它用于为该土地的乡村劳动者磨粮，也应给付。下磨石是磨盘的下部，上磨石则是磨盘的上部。

<!-- source-p 593 -->
<a id="33.7.18.6"></a>**6.**关于牛倌，斯凯沃拉也作如下答复：无论询问的是在该处驱牛耕地的人，还是饲养该土地耕牛的人，都应予给付。

<!-- source-p 594 -->
<a id="33.7.18.7"></a>**7.**关于修枝工，斯凯沃拉也答复说，如果他们是为该土地而雇用的，就包括在内。

<!-- source-p 595 -->
<a id="33.7.18.8"></a>**8.**牧人和挖沟工也属于受遗赠人。

<!-- source-p 596 -->
<a id="33.7.18.9"></a>**9.**遗嘱写道：“我将塞尤斯土地遗赠给梅维乌斯，按其最佳状态连同全部乡村和城市用具，以及当地的奴隶。”有人问，种子是否应予给付。答复说，较妥当的意见是应当给付，除非继承人证明立遗嘱人的意思相反。对于为奴隶口粮而储存的谷物，也作同样答复。

<!-- source-p 597 -->
<a id="33.7.18.10"></a>**10.**卡西乌斯写道，医生用具包括眼药、膏药及其他同类物品。

<!-- source-p 598 -->
<a id="33.7.18.11"></a>**11.**某人遗赠设备齐全的土地，并明确列名遗赠了若干奴隶。有人问，其余未列名的奴隶是否随生产用具一并遗赠。卡西乌斯说，虽然后者可能属于设备齐全土地的用具，但既然仅列名的奴隶被认为是遗赠对象，就应认为家父没有意识到奴隶也被计算在设备齐全的土地之中。

<!-- source-p 599 -->
<a id="33.7.18.12"></a>**12.**萨比努斯说，如果某人遗赠土地以及土地上的一切物品，就应认为土地及其上惯常存放、每年大部分时间停留在那里的物品均已遗赠；惯常进入该处居住的人也在其中。但若某些物品是故意集中、搬入土地，目的只是扩大遗赠范围，则不视为已遗赠。

<!-- source-p 600 -->
<a id="33.7.18.13"></a>**13.**某人如此遗赠：“我将我占有的庄园连同家具、桌子、应派驻那里的城市及乡村奴隶、我死亡时存放在那里的葡萄酒，以及十枚金币一并遗赠。”有人问：立遗嘱人死亡时，那里还有书籍、玻璃器皿和衣物；既然遗嘱特别列举了某些物品，其他物品是否也包括在内？斯凯沃拉答复说，仅包括特别列举的物品。

<!-- source-p 601 -->
<a id="33.7.18.14"></a>**14.**某人将设备齐全且附有全部固定装置的房屋遗赠给他人。有人问，债务文书能否由受遗赠人取得。答复说，根据所述事实，不能取得。

<a id="33.7.19"></a>**33.7.19**

**保罗：《答复集》第十三卷。**

<!-- source-p 604 -->
<a id="33.7.19.pr."></a>**序言。**我答复说，遗嘱订立后，立遗嘱人将奴隶迁入遗赠给塞娅的土地，若这些奴隶在那里为耕作土地而工作，也包括在该土地生产用具中。虽然立遗嘱人提到了遗赠时在那里的人，但他提及奴隶显然不是为了缩小遗赠范围，而是为了扩大遗赠范围。毫无疑问，为耕作土地而迁入的奴隶属于土地生产用具。

<!-- source-p 606 -->
<a id="33.7.20"></a>**33.7.20**

<!-- source-p 607 -->
**斯凯沃拉：《答复集》第三卷。**

<!-- source-p 608 -->
<a id="33.7.20.pr."></a>**序言。**某人指定塞娅为部分继承人，并规定她成为继承人时，可先取设备齐全的土地，连同土地用具、家具、牲畜、管事及佃户的其他财物。他在遗嘱补编中又写道：“此后我想到：我希望塞娅取得我遗赠给她的土地，并按现状连同乡村用具、家具、牲畜、管事、佃户的其他财物及储藏室一并取得。”有人问，家父为日常使用而放在土地上的物品是否也属于遗赠。答复说，根据遗嘱所述，土地确已先取遗赠给塞娅；但应给付的仅限于遗嘱补编中的“设备齐全”一语所包含的物品，因为该补编显然是在立遗嘱人忘记自己遗嘱文字之后写成的。

<!-- source-p 609 -->
<a id="33.7.20.1"></a>**1.**某人以如下文字将地产遗赠给其被释奴：“我将这些土地遗赠给我的被释奴塞尤斯，按现状连同嫁资、佃户的其他财物、林地看守人及其同居伴侣和子女一并给付。”有人问，奴隶斯提库斯耕作其中一处地产，并留下大笔欠款，是否应依据遗嘱信托给塞尤斯。答复说，如果斯提库斯不是以对主人的忠诚经营土地，而是像外来佃农一样按租金耕作，则不应给付。

<!-- source-p 610 -->
<a id="33.7.20.2"></a>**2.**遗嘱写道：“我希望将这些土地按设备齐全的状态交给我的受养人盖乌斯·塞尤斯，并将上层房屋一并给付。”有人问，立遗嘱人是否也意在交付设备齐全的房屋。答复说，根据所述情况，应认为他意在如此遗赠，除非被请求的一方明确证明立遗嘱人的意思不同。但是，如果遗赠的是居所，即建筑物的用具，则为劳务或其他用途而备置的奴隶不随同遗赠。

<!-- source-p 611 -->
<a id="33.7.20.3"></a>**3.**某人遗赠土地，按设备齐全的状态连同佃户嫁资、佃户的其他财物、管事、奴隶、全部牲畜、特有产及管理人一并给付。有人问，租约期满后迁离土地、并已提供担保的佃户所欠财物，是否根据上述文字一并遗赠。答复说，不能认为立遗嘱人考虑了这些欠项。

<!-- source-p 612 -->
<a id="33.7.20.4"></a>**4.**又有人问：遗赠管理人时，如果该管理人并未住在地产而是住在城市，他的妻子和女儿是否随同遗赠。答复说，没有事实表明她们应当一并遗赠。

<!-- source-p 613 -->
<a id="33.7.20.5"></a>**5.**又有人问：立遗嘱人订立遗嘱后前往行省；此后或其死亡后，有些奴隶未经任何人许可，自行前往遗赠的土地，投靠其父母或熟识的人，这些奴隶是否也随土地遗赠。答复说，偶然经过该处的奴隶不属于遗赠。〔底本末尾作 *transissententiarum*，疑有粘连或讹误；译文仅据可辨部分暂译。〕

<!-- source-p 614 -->
<a id="33.7.20.6"></a>**6.**遗嘱写道：“我希望将提提安努斯土地连同生产用具，以及我死亡时在那里的一切，给我的被释女奴潘菲拉。”有人问，奴隶斯提库斯在立遗嘱人死亡前一年从土地上被调走并送去学习，此后没有返回，是否应给付。答复说，如果送他去学习并非为了将他迁离土地，而只是为了求学，他仍应给付。

<!-- source-p 615 -->
<a id="33.7.20.7"></a>**7.**遗嘱写道：“我将我的格拉埃基安努斯土地连同马厩和全部乡村用具留给我的姐妹提兰娜。”有人问，随土地一并转归该地且一直供该地产使用的牧场，是否也属于“土地”遗赠。答复说，如果立遗嘱人将草地与格拉埃基安努斯土地结合，使其被视为同一土地名称之下的财产，则草地也应给付。

<!-- source-p 616 -->
<a id="33.7.20.8"></a>**8.**某人遗赠设备齐全的房屋。提提娅死亡时，一张镀银的床榻不在房屋中，而是暂时存放在仓库。有人问，该床榻是否也应给付。答复说，如果床榻惯常放在房屋中，只是为了存放在更安全之处而暂时搬入仓库，仍应给付。

<!-- source-p 617 -->
<a id="33.7.20.9"></a>**9.**遗嘱人补充的“按我占有时的状况”，是否表示“按我死亡时设备齐全的状况”，即连同奴隶、牲畜和乡村用具？答复说，这不是法律问题。

<a id="33.7.25"></a>**33.7.25**

<!-- source-p 632 -->
**雅沃勒努斯：《拉贝奥后编》第二卷。**

<!-- source-p 633 -->
<a id="33.7.25.pr."></a>**序言。**图贝罗认为，遗赠土地生产用具时，随土地遗赠的牲畜数量应以该土地能够承载的数量为限。拉贝奥持相反意见：“如果土地本可承载一千只羊，却有两千只羊在那里，我们应认为遗赠了哪一些羊呢？”不应追问为土地生产用具本应准备多少牲畜，而应考察实际准备了多少；遗赠范围不能按照牲畜数量或群体规模评定。我赞同拉贝奥的意见。

<!-- source-p 634 -->
<a id="33.7.25.1"></a>**1.**某人在土地上有制陶作坊，陶工一年中大部分时间都从事乡村劳作；他后来遗赠该土地的生产用具。拉贝奥和特雷巴提乌斯认为，陶工不属于土地生产用具。

<!-- source-p 635 -->
<a id="33.7.25.2"></a>**2.**同样，若遗赠了全部生产用具但排除牲畜，奥菲利乌斯认为牧人、羊倌和羊圈也包含在遗赠中；此说不正确。

<!-- source-p 636 -->
<a id="33.7.26"></a>**33.7.26**
