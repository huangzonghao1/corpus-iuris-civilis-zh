# D.45.1 论言词债务（*De verborum obligationibus*）

<!-- source-p 0001 -->
<a id="1"></a><a id="45.1"></a>**45.1.0**　论言词债务。

<!-- source-p 0002 -->
<a id="45.1.1"></a>**45.1.1**

<!-- source-p 0003 -->
乌尔比安《萨宾评注》第四十八卷。

<!-- source-p 0004 -->
<a id="45.1.1.pr."></a>**序言**　要式口约只有双方都在说话时才能成立。因此，哑者、聋者和婴儿均不能订立要式口约；不在场者也不能，因为双方必须能够彼此听见。上述任何人若想取得要式口约之诉，应由在场的奴隶代其订立，从而使其取得要式口约之诉。同样，若某人要使自己负债，可以发出指令；如此即构成依命令而负债。

<!-- source-p 0005 -->
<a id="45.1.1.1"></a>**1**　提问人在场，但尚未得到回答就离开，便使要式口约无效。反之，若他在场提问，随后离开，而答允是在他返回后作出的，则债务成立；其间的时间间隔并未使债务失效。

<!-- source-p 0006 -->
<a id="45.1.1.2"></a>**2**　若有人问“你给付吗？”，对方回答“为何不呢？”，应当认为债务成立；但若对方只以点头作答，则不同。以点头作答者不仅不负市民法上的债务，也不负自然债务。因此，即便有人为其提供保证人，该保证人也不负债，此说正确。

<!-- source-p 0007 -->
<a id="45.1.1.3"></a>**3**　若某人被直接问及是否给付，却回答“若某事发生，我就给付”，显然不负债。又如，有人被问“在朔日前第五日内给付吗？”，回答“我在伊德斯日给付”，同样不负债，因为回答与提问不一致。反过来，若提问附有条件而回答没有附条件，也应认为不负债。回答中增添或删去任何内容，原则上均应认为债务因不一致而无效；除非要式口约债权人在当场接受回答与提问之间的差异，因为此时应视为成立了另一项要式口约。

<!-- source-p 0008 -->
<a id="45.1.1.4"></a>**4**　我向你请求十，你回答二十，显然债务仅在十的范围内成立。反过来，我请求二十而你回答十，债务也仅在十的范围内成立。虽然金额原则上应当一致，但显然二十之中包含十。

<!-- source-p 0009 -->
<a id="45.1.1.5"></a>**5**　但若我请求你给付潘菲卢斯，你承诺给付潘菲卢斯和斯提库斯，我认为应将加上的斯提库斯视为多余。因为若每一件物分别成立一项要式口约，则这里仿佛有两项要式口约：一项有效，另一项无效；无效的一项不会使有效的一项也失效。

<!-- source-p 0010 -->
<a id="45.1.1.6"></a>**6**　以同一种语言还是另一种语言作答，并不重要。因此，若有人用拉丁语提问，对方用希腊语回答，只要回答与提问相符，债务便成立；反过来亦同。这一规则是否只适用于希腊语，还是也适用于其他语言，例如布匿语、亚述语或其他语言，存在疑问。萨宾努斯的论述以及法理本身均支持这样的结论：任何语言都可以成立言词债务，但双方必须能够理解对方的语言，无论是亲自理解，还是借助合格的翻译。

<!-- source-p 0011 -->
<a id="45.1.2"></a>**45.1.2**

<!-- source-p 0012 -->
保罗《萨宾评注》第十二卷。

<!-- source-p 0013 -->
<a id="45.1.2.pr."></a>**序言**　有些要式口约以给付为内容，有些则以作为为内容。

<!-- source-p 0014 -->
<a id="45.1.2.1"></a>**1**　其中有些可以分割履行，例如约定给付十；有些则不能分割履行，例如约定设立通行道路或驱赶牲畜的役权。还有些事项就其性质而言可部分给付，但若未全部给付，仍不算履行了要式口约，例如概括地约定给付一名奴隶、一只盘子或任何器皿。若给付了斯提库斯的一部分，尚未因此在要式口约的任何部分获得免责；剩余部分可以立即请求，也可以暂处未决状态，直至另行给付一名奴隶。以下要式口约也属同一情形：“给付斯提库斯或潘菲卢斯吗？”

<!-- source-p 0015 -->
<a id="45.1.2.2"></a>**2**　因此，在这些要式口约中，只要所有继承人尚未给付同一标的，即使各继承人按份给付，也不能免除责任；义务性质不会因继承人的身份而改变。因此，若约定标的不可分，例如通行道路，承诺人的各继承人均负全部责任。但若其中一名继承人已履行全部给付，可通过遗产分割之诉向共同继承人追偿。庞波尼说，由此可能出现如下结果：道路或通行役权的受约人之各继承人，也分别享有就全部请求的诉权。有人却认为此种情形下要式口约消灭，因为役权不能由每名继承人分别取得。不过，履行困难并不会使要式口约无效。

<!-- source-p 0016 -->
<a id="45.1.2.3"></a>**3**　但若我就给付奴隶一事只起诉承诺人的一名继承人，则其余继承人的债务仅在相应部分继续存在，因而也可以按份清偿。若仅对一名继承人作出免债承认，亦同。

<!-- source-p 0017 -->
<a id="45.1.2.4"></a>**4**　我们关于继承人所说的规则，也适用于承诺人本人及其保证人。

<!-- source-p 0018 -->
<a id="45.1.2.5"></a>**5**　若要式口约以作为为内容，例如我曾约定“你或你的继承人不得妨碍我通行或驱赶牲畜”，而数名继承人中有一人加以禁止，则其共同继承人也承担责任；但他们可以通过遗产分割之诉向该继承人追偿自己所付之款。尤利安和庞波尼均赞同此说。

<!-- source-p 0019 -->
<a id="45.1.2.6"></a>**6**　反之，若作为受约人死亡，他曾约定自己及其继承人均可通行，而其继承人中一人遭到禁止，则须区分要式口约是否因全部违约而触发，还是仅因该名继承人被禁止而按份触发。若约定了罚金，则全部罚金债务均被触发；但未被禁止的继承人可以提出恶意抗辩而获排除。若未约定罚金，则要式口约仅按受禁止继承人的份额触发。

<a id="45.1.3"></a>**45.1.3**

<!-- source-p 0021 -->
乌尔比安《萨宾评注》第四十九卷。

<!-- source-p 0022 -->
<a id="45.1.3.pr."></a>**序言**　“准许我及我的继承人占有吗？”这一要式口约也适用同一法律规则。

<!-- source-p 0023 -->
<a id="45.1.3.1"></a>**1**　两种情形的区别在于：若一名继承人遭到禁止，其他继承人不能提起要式口约之诉，因为此事与他们无关；但若约定了罚金，则不同，因为罚金的约定使全部继承人均可提起诉讼，本案不再考察谁具有利益。反过来，若一名继承人实施禁止行为，则所有继承人都承担责任，因为被禁止者本人有权不受任何人的阻碍。

<!-- source-p 0024 -->
<a id="45.1.4"></a>**45.1.4**

<!-- source-p 0025 -->
保罗《萨宾评注》第十二卷。

<!-- source-p 0026 -->
<a id="45.1.4.pr."></a>**序言**　若我约定你及你的继承人均不得实施恶意行为，而承诺人或要式口约债权人在留有数名继承人的情况下死亡，也应作同样处理。

<!-- source-p 0027 -->
<a id="45.1.4.1"></a>**1**　卡托在《法学论说集》第十五卷写道：有人承诺若行为不按约定进行即支付特定金额的罚金；承诺人死亡后，若数名继承人中的一人作出了与约定相反的行为，应由所有继承人按其继承份额承担罚金，还是仅由该人按其份额承担？若约定的行为不可分，例如“不得妨碍通行”，则所有继承人均视为触发罚金，因为不可分割之事只能以整体方式违反。若约定的行为可以分割，例如“不得再行起诉”，则仅由违反约定的继承人按其份额承担罚金。区别的理由在于：前一种情形中，除非整体违反，否则不能构成违反；这类似“你不得妨碍我通行”的要式口约。不过，我们还应考察，此处是否并非同一规则，而是更接近如下约定：“提图斯及其继承人将予以追认”。依据该约定，只有未予追认的人承担责任，也只有被请求之人可以起诉；马尔凯鲁斯也持此见解，尽管所有人本人不能仅按部分予以追认。

<!-- source-p 0028 -->
<a id="45.1.4.2"></a>**2**　若约定加倍赔偿的人在留有数名继承人的情况下死亡，各继承人就被追夺的自己那一份，按其份额享有诉权。用益物担保、潜在损害担保及新工程告知担保的要式口约，也适用同一规则。不过，新工程告知之诉中的工程不能按部分恢复原状。为受约人利益起见，法律接受了按份主张；但承诺人本人既不能获得部分恢复，也不能仅就部分获得辩护。

<a id="45.1.5"></a>**45.1.5**

<!-- source-p 0030 -->
庞波尼《萨宾评注》第二十六卷。

<!-- source-p 0031 -->
<a id="45.1.5.pr."></a>**序言**　要式口约有司法上的、裁判官法上的、合意上的，以及兼具裁判官法与司法性质的。司法要式口约仅源于法官本身的职权，例如恶意担保；裁判官法上的要式口约仅源于裁判官本身的职权，例如潜在损害担保。裁判官法上的要式口约应作广义理解，其中也包括市政官告示所设的担保，因为这类担保同样源于管辖权。合意上的要式口约则由当事人的协议成立，其种类几乎与可以缔结的交易种类一样多：有些是为言词债务本身而设，有些则从属于已经缔结的交易。共同性质的要式口约，例如未适婚人财产完好的担保，既可由裁判官命令提供，有时也由法官命令提供——若没有其他办法处理该事项；加倍赔偿的要式口约也可能由法官命令，或依据市政官告示成立。

<!-- source-p 0032 -->
<a id="45.1.5.1"></a>**1**　要式口约，是一种言词表达：受问者回答说将给付或实施提问中所问之事。

<!-- source-p 0033 -->
<a id="45.1.5.2"></a>**2**　担保受领，是指一种使承诺人负债、并由此接受共同承诺人（即作出同一承诺的人）提供担保的要式口约。

<!-- source-p 0034 -->
<a id="45.1.5.3"></a>**3**　“接受足够担保”一语，与“作出足够给付”同理。因为向某人提供了足以使其满意的给付，所以称为足额给付；同样，因为所提供的人足以使其满意，并以言词承担债务，所以称为接受足额担保。

<!-- source-p 0035 -->
<a id="45.1.5.3a"></a>**3a**　若你承诺返还本金，并约定未清偿时支付罚金，即使你的某一继承人已经偿还了本金中属于自己的部分，在共同继承人偿还其份额之前，罚金仍会触发。

<!-- source-p 0036 -->
<a id="45.1.5.4"></a>**4**　妥协约定所生罚金也适用同一规则：一方遵从法官裁决，另一方却不遵从的，后者的共同继承人应向其作出清偿。否则便会不公正地损害要式口约债权人。

要式口约约定：“若你未在某月朔日之前交付斯提库斯，就答应给付十吗？”斯提库斯死亡后，有人问能否在该月朔日之前立即起诉。萨宾努斯和普罗库鲁斯认为，原告应当等到约定日期；此说更为正确，因为整个债务既以条件为前提，也被推迟到特定日期。虽然看起来条件已经触发，但约定日期尚未到来。不过，若有人承诺“若在某月朔日前未用手指触到天空”，则可以立即起诉。马尔凯鲁斯也赞同此说。

<a id="45.1.38"></a>**45.1.38**

<!-- source-p 0139 -->
乌尔比安《萨宾评注》第四十九卷。

<!-- source-p 0140 -->
<a id="45.1.38.pr."></a>**序言**　“你答应使我可以占有吗？”这一要式口约包含的内容是：我应当能够占有，且任何人都不得妨碍我占有。因此，承诺人似乎承诺要确保所有人都使你能够占有；这便像是在承诺他人的行为，而依通说，任何人都不因承诺他人的行为而负债。但承诺人仍须承担不亲自妨碍占有的义务；他还须确保自己的继承人不妨碍占有，且其他继受人也不致使占有无法实现。

<!-- source-p 0141 -->
<a id="45.1.38.1"></a>**1**　因此，若有人承诺不让第三人妨碍占有，除其继承人以外，应认为该人对他人行为所作承诺无效。

<!-- source-p 0142 -->
<a id="45.1.38.2"></a>**2**　但若有人愿意为他人行为作出承诺，可以约定罚金，或约定按该物价值给付。那么，何种情况下才算保证他人能够占有？只要无人提出争议即可，也就是说，承诺人本人、其继承人以及继承人的继受人均不得提出争议。

<!-- source-p 0143 -->
<a id="45.1.38.3"></a>**3**　若有人争议的不是所有权，而仅是占有、用益权、使用权或被转让物上的其他权利，显然也会触发该要式口约：对其权利有所减损的人，便不能说能够占有该物。

<!-- source-p 0144 -->
<a id="45.1.38.4"></a>**4**　有人问，能否仅为自己的物承诺使他人能够占有，还是也可以就他人之物作此承诺。较妥当的见解是，也可以承诺他人之物；若该物后来成为承诺人的所有物，承诺即产生效力。因此，若该物始终属于他人，则应认为要式口约未被触发；除非另行约定罚金，因为承诺人及其继受人均未实施任何妨碍行为。

<!-- source-p 0145 -->
<a id="45.1.38.5"></a>**5**　正如被告一方的继受人要与被告本人一同承担责任，原告一方的继受人也可以请求履行该要式口约；前提是要式口约债权人本人无法占有该物。若只是其他人无法占有，则毫无疑问要式口约未被触发；此时无论约定“能够占有”还是“我能够占有”，均无区别。

<!-- source-p 0146 -->
<a id="45.1.38.6"></a>**6**　处于他人权力之下的人，可以为对其行使权力的人约定使其能够占有，理由与他们可以为该权力人约定其他事项相同。但若奴隶约定使自己能够占有，是否为有效约定，曾有疑问。尤利安在《学说汇纂》第五十二卷中说：若奴隶约定使自己能够占有，或承诺人不得妨碍要式口约债权人占有，虽有人可以从奴隶处夺走该物，奴隶本人也可能夺走该物，要式口约仍未被触发，因为该约所涉及的是权利，而非事实。相反，若约定承诺人不得妨碍奴隶通行或驱赶牲畜，涉及的便不是要式口约权利，而是事实。不过我认为，尽管“能够占有”包含权利用语，该要式口约仍应如此解释：对奴隶和家父权下的儿子而言，约定的是保有占有或不被剥夺占有；因而该要式口约有效。

<!-- source-p 0147 -->
<a id="45.1.38.7"></a>**7**　“你答应使我能够占有吗？”这一要式口约也有效。我们还应考察，奴隶能否以自己名义有效订立此类要式口约。虽然奴隶依市民法并不占有，但应当将其理解为自然占有；因此，毫无疑问，奴隶也可以有效地作出此种约定。

<!-- source-p 0148 -->
<a id="45.1.38.8"></a>**8**　若奴隶约定“准许自己持有”，其要式口约有效，此点没有争议。虽然奴隶不能依市民法占有，但毫无疑问，他们可以持有。

<!-- source-p 0149 -->
<a id="45.1.38.9"></a>**9**　“占有”一词有两种含义：我们既称物的所有人为占有该物，也称并非所有人、但实际持有该物的人为占有者。因此，我们通常也会说，寄存在我们处的物由我们占有。

<!-- source-p 0150 -->
<a id="45.1.38.10"></a>**10**　若某人约定“准许自己使用并收益”，该要式口约不及于其继承人。

<!-- source-p 0151 -->
<a id="45.1.38.11"></a>**11**　即使未加上“自己”一词，我也认为关于用益权的要式口约不移转给继承人；我们适用的正是此规则。

<!-- source-p 0152 -->
<a id="45.1.38.12"></a>**12**　但若某人约定准许自己及其继承人使用并收益，应考察继承人能否依据要式口约提起诉讼。我认为可以，即便继承人享有的孳息并不相同；若某人约定自己及继承人均可通行或驱赶牲畜，也应作同样判断。

<!-- source-p 0153 -->
<a id="45.1.38.13"></a>**13**　若某人想约定承诺人及其继承人均不实施恶意行为，只须约定“现时及将来均无恶意”即可。若想担保多人均无恶意，则须补充如下内容：“若任何人现已实施或将来实施恶意行为，应答应给付与该事项价值相等的金钱吗？”

<!-- source-p 0154 -->
<a id="45.1.38.14"></a>**14**　某人可以在自己的身份之外，再加上继承人的身份。

<!-- source-p 0155 -->
<a id="45.1.38.15"></a>**15**　也可以将养父的身份加进约定。

<!-- source-p 0156 -->
<a id="45.1.38.16"></a>**16**　不确定的期限与确定的期限之间的区别还在于：约定在确定日期给付时，承诺人甚至可以立即给付，因为两者之间的全部时间均由承诺人自由决定何时履行。相反，若某人承诺“某事发生时”或“若某事发生”，除非该事发生后即予给付，否则不视为履行其承诺。

<!-- source-p 0157 -->
<a id="45.1.38.17"></a>**17**　除奴隶为主人、儿子为父亲约定外，任何人不得为他人订立要式口约。设立此类债务的目的，是使每个人为自己取得与自身利益有关之物；至于让他人取得，对我并无利益。不过，若我想实现此目的，可以约定罚金；若未按约定履行，即使受益人本人没有利益，该要式口约也会被触发。因为约定罚金时，所考察的并非受益人有何利益，而是罚金数额及要式口约所附条件。

<!-- source-p 0158 -->
<a id="45.1.38.18"></a>**18**　要式口约中若对约定内容发生疑问，应作不利于要式口约债权人的解释。

<!-- source-p 0159 -->
<a id="45.1.38.19"></a>**19**　某人说“给我十，并给提图斯十”，应认为是指同一笔十，而非另加一笔十。

<!-- source-p 0160 -->
<a id="45.1.38.20"></a>**20**　若我为他人订立要式口约，但此事与我有利害关系，应考察该要式口约是否触发。马尔凯鲁斯说，下述情形中的要式口约有效：某人开始管理未适婚人的监护事务后，将管理职责交给共同监护人，并约定未适婚人的财产应保持完整。马尔凯鲁斯认为，可主张该要式口约有效，因为要式口约债权人有利害关系，约定之事必须实现；否则，他将对未适婚人承担责任。

<!-- source-p 0161 -->
<a id="45.1.38.21"></a>**21**　若某人承诺或受雇建造一栋出租楼房，之后又向他人约定由其为要式口约债权人建造该楼房；或者某人承诺给提图斯梅维乌斯土地，若未给付便支付罚金，随后又向梅维乌斯约定由其将土地交付提图斯；又或者某人将自己受雇承建的工程转包给他人，通说认为，此人享有基于租赁契约的实益诉权。

<!-- source-p 0162 -->
<a id="45.1.38.22"></a>**22**　因此，若某人约定向自己有利害关系之人给付，属于要式口约有效的情形。

<!-- source-p 0163 -->
<a id="45.1.38.23"></a>**23**　由此，若我约定将物交付给我的代理人，该要式口约也有效；若约定交付给我的债权人，也有效，因为我有利害关系：如此便不会触发罚金，也不会导致作为质押物的土地被变卖。

<!-- source-p 0164 -->
<a id="45.1.38.24"></a>**24**　若某人约定“你应使某人到庭吗？”，没有理由认为该债务不能成立。

<!-- source-p 0165 -->
<a id="45.1.38.25"></a>**25**　我们可以约定建造神庙或宗教场所；否则，我们也无法基于租赁契约提起诉讼。

<a id="45.1.56.pr."></a>**序言**　某人约定“你答应给我和提提乌斯十吗？”，较为可信的理解是，他为自己和提提乌斯共同约定一笔十；正如遗嘱将十遗赠给提提乌斯和塞姆普罗尼乌斯，应理解为共同遗赠一笔十，而非各遗赠十。

<!-- source-p 0235 -->
<a id="45.1.56.1"></a>**1**　约定“你答应由你及你的继承人提图斯给付十吗？”其中提图斯的身份是多余的：无论他成为唯一继承人而承担全部责任，还是仅成为部分继承人，都与其他共同继承人一样承担相应责任。即使似乎约定只能向提图斯而不得向其他继承人请求，这一合意对其他共同继承人也无效。

<!-- source-p 0236 -->
<a id="45.1.56.2"></a>**2**　某人约定给付自己或自己的儿子，显然将儿子列入约定，是为了准许向儿子清偿。无论约定给付自己或任意第三人，还是约定给付自己或自己的儿子，均无区别。因此，无论儿子仍处于家父权下，还是已经解放，都可以向其有效清偿。至于为儿子约定给付时，权利为何归父亲取得，与此无关；因为要式口约债权人将自己的身份与儿子的身份并列，表明列入儿子身份的目的不是取得债权，而是使清偿可以向儿子作出。

<!-- source-p 0237 -->

<!-- source-p 0238 -->
<a id="45.1.56.4"></a>**4**　若某人约定“在我有生之年给付十”，可以立即请求给付十；但其继承人应以合意抗辩排除。显然，要式口约债权人的意思是不得由其继承人请求，就如某人约定在朔日前给付，虽然朔日后仍可提起请求，但会被合意抗辩排除。若某人授予土地役权，并约定受益人在其生前享有通行权，其继承人也会被合意抗辩排除。

<!-- source-p 0239 -->
<a id="45.1.56.5"></a>**5**　约定“下一个朔日前给付”与约定“在朔日给付”没有区别。

<!-- source-p 0240 -->
<a id="45.1.56.6"></a>**6**　仅有土地所有权而没有用益权的人，可以有效约定向自己授予用益权；因为他将自己尚不享有、但可以取得的权利纳入债务。

<!-- source-p 0241 -->
<a id="45.1.56.7"></a>**7**　若我曾向你约定给付塞姆普罗尼乌斯土地，后来又向他人约定给付同一土地但扣除用益权，则先前的要式口约不会被后约替代，因为仅给付扣除用益权后的土地并不能使你免责；我仍可向你请求土地的用益权。结果是：你将土地交付给我后，另一名曾承诺交付扣除用益权后土地的人也会免责。

<!-- source-p 0242 -->
<a id="45.1.56.8"></a>**8**　若我曾无条件地向提提乌斯约定给付斯提库斯，塞乌斯后来附条件承诺给付同一奴隶；在条件未成就期间，斯提库斯因提提乌斯迟延而死亡，我可以立即起诉提提乌斯；即使条件成就，塞乌斯也不承担责任。但若我已经免除提提乌斯的债务，条件成就时塞乌斯仍可能承担责任。之所以作此区别，是因为奴隶死亡后，塞乌斯所负债务的标的即不复存在；但在发生免债承认后，塞乌斯承诺给付的奴隶仍然存在于法律关系中。

<a id="45.1.65.1"></a>**1**　若对标的物名称或当事人姓名有所差异，也不妨碍要式口约有效。例如，要式口约债权人请求给付若干第纳尔，而承诺人答应给付同等价值的金币，仍应承担责任。又如，奴隶为其主人卢基乌斯提出要式口约，承诺人答应向与卢基乌斯为同一人的提提乌斯给付，也应承担责任。

<a id="45.1.67.pr."></a>**序言**　“你答应确保一万钱款完整无损吗？”这一要式口约有效。

<a id="45.1.72"></a>**45.1.72**

<!-- source-p 0291 -->
乌尔比安《告示评注》第二十卷。

<!-- source-p 0292 -->
<a id="45.1.72.pr."></a>**序言**　以不可分割之物为标的的要式口约，不得分割，例如道路、通行权、驱赶牲畜的权利、引水权及其他地役权。我认为，若有人约定完成某项行为，也应如此处理，例如交付一块土地、挖掘沟渠、建造一栋出租楼房、提供劳务或其他类似事项；因为分割这些履行会破坏要式口约。不过，塞尔苏斯在《学说汇纂》第三十八卷中记载，图贝罗认为，以行为为内容的约定若未履行，应给付金钱，因此这类要式口约也可以分割。塞尔苏斯据此说，可以按照公平估价请求履行该行为。

<!-- source-p 0293 -->
<a id="45.1.72.1"></a>**1**　若某人约定“若工程未能在三月朔日前完工，则给付该工程的价值”，给付期限并非从工程承包之日开始，而是自三月朔日之后开始；因为在三月朔日前，不能起诉承诺给付的人。

<!-- source-p 0294 -->
<a id="45.1.72.2"></a>**2**　但若某人约定支撑加固一栋出租楼房，不必等到楼房倒塌后才能起诉；若约定建造楼房，也不必等到足以建成楼房的期限届满才起诉。只要建造楼房已经发生迟延，便可以起诉，债务的履行日期也随之到来。

<!-- source-p 0295 -->
<a id="45.1.73"></a>**45.1.73**

<!-- source-p 0296 -->
保罗《告示评注》第二十四卷。

<!-- source-p 0297 -->
<a id="45.1.73.pr."></a>**序言**　有时，纯粹要式口约因事项本身的性质而含有履行宽限，例如约定交付尚在母腹中的胎儿、将来产生的孳息，或建造房屋；这些情形中，只有依事物自然规律可以履行时，才产生诉权。同样，若某人在罗马约定在迦太基给付，默示包含了抵达迦太基所需的时间。又如，某人约定由被释奴提供劳务，只有在劳务已经被指派而未获提供时，该劳务的履行日才到期。

<!-- source-p 0298 -->
<a id="45.1.73.1"></a>**1**　若遗产中的奴隶订立要式口约，除非继承已经接受，该要式口约不发生效力，仿佛附有条件一样。某人被敌人俘获时其奴隶订立要式口约，也适用同一规则。

<!-- source-p 0299 -->
<a id="45.1.73.2"></a>**2**　若承诺人约定给付斯提库斯，在构成迟延后又提出交付，即消除迟延。拒绝接受已经提出的金钱者，当然会受到恶意抗辩的阻却。
