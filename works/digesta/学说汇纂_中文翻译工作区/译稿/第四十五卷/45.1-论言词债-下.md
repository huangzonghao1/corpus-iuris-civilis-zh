# D.45.1　论言词债（*De verborum obligationibus*）（下）

> 底本：*Digesta Iustiniani*，EPUB `book-45.xhtml`，source-p 301–593。

<!-- source-p 301 -->
盖尤斯《论行省告示》第8卷。

<!-- source-p 302 -->
要式口约有些是确定的，有些是不确定的。所谓确定，是指仅从口头表述本身即可看出其为何物、何种品质及数量，例如十枚金币、图斯库卢姆庄园、奴隶斯提库斯、一百摩迪乌斯优质非洲小麦、一百安福拉优质坎帕尼亚酒。

<!-- source-p 303 -->
<a id="45.1.75"></a>**45.1.75**

<!-- source-p 304 -->
乌尔比安《告示评注》第22卷。

<!-- source-p 305 -->
<a id="45.1.75.pr."></a>**序言**　如果无法从要式口约中看出其为何物、何种品质及数量，就应称该要式口约为不确定。

<!-- source-p 306 -->
<a id="45.1.75.1"></a>**1**　因此，若有人未以专名指明某庄园，或仅一般地提及某人而未指明其姓名，或者要求给付未说明品质的酒或谷物，即将不确定之物纳入债务。

<!-- source-p 307 -->
<a id="45.1.75.2"></a>**2**　甚至，若有人约定给付“一百摩迪乌斯优质非洲小麦”或“一百安福拉优质坎帕尼亚酒”，也被认为约定了不确定之物，因为还可能找到比“优质”更好的品质。由此可见，“优质”一词并不表示确定之物，因为比优质更好的东西本身也仍属优质。然而，若有人约定给付“最优质”的物品，则应理解为约定给付其品质达到最高等级者；因此，该用语表示确定之物。

<!-- source-p 308 -->
<a id="45.1.75.3"></a>**3**　若有人就一处确定的庄园约定给付用益权，应认为其将不确定之物纳入债务；我们采用的正是这一法律见解。

<!-- source-p 309 -->
<a id="45.1.75.4"></a>**4**　有一点尚有疑问：若有人约定给付女奴阿瑞图萨所生之物，或者给付在图斯库卢姆庄园长成的果实，是否应认为约定了确定之物？然而，依事物本身的性质，这种要式口约显然是不确定的。

<!-- source-p 310 -->
<a id="45.1.75.5"></a>**5**　但是，若有人约定给付仓库中的酒、油或小麦，即应认为其约定了确定之物。

<!-- source-p 311 -->
<a id="45.1.75.6"></a>**6**　有人向提提乌斯约定：“你允诺给付塞尤斯欠我的一切吗？”或者约定：“你允诺给付你依遗嘱欠我的一切吗？”即将不确定之物纳入债务，即使塞尤斯所欠的是确定之物，或依遗嘱所欠的是确定之物亦然。尽管这些情形与前述存放于仓库中的酒、油或小麦之例几乎难以区分，但仍须注意：保证人似乎承诺的是确定之物，前提是其所担保之人负有确定债务，因为对保证人的询问是：“你以信用担保此事吗？”

<!-- source-p 312 -->
<a id="45.1.75.7"></a>**7**　有人约定给付一项作为或不作为，即被认为约定了不确定之物。作为的例子有：“挖掘沟渠”“建造房屋”“交付空置占有”；不作为的例子有：“不得由你妨碍我经由你的庄园通行、驱赶牲畜”“不得由你妨碍我占有奴隶埃罗”。

<!-- source-p 313 -->
<a id="45.1.75.8"></a>**8**　有人约定“给付这个或那个”，例如“十枚金币或奴隶斯提库斯”，究竟将确定还是不确定之物纳入债务，确有疑问：因为虽已指明确定的物品，但究竟应给付其中哪一项，仍不确定。不过，若约定者以“由我选择”之语为自己保留选择权，可以认为其约定的是确定之物，因为他可以仅请求给付奴隶或仅请求给付十枚金币。若未为自己保留选择权，则其约定的是不确定之物。

<!-- source-p 314 -->
<a id="45.1.75.9"></a>**9**　有人约定给付本金以及任意数额的利息，应认为其同时约定了确定与不确定之物；其中有多少项给付，就有多少项要式口约。

<!-- source-p 315 -->
<a id="45.1.75.10"></a>**10**　“交付图斯库卢姆庄园”这一要式口约表明其为确定之物，并包含使庄园所有权以任何方式完整归属于要式口约债权人的意思。

<!-- source-p 318 -->
<a id="45.1.76.pr."></a>**序言**　若我约定“给付这个或那个，由我选择”，此项选择权属于特定个人。因此，若该个人是奴隶或子女，选择权即附着于该奴隶或子女本人。但债务仍由继承人承受，即使要式口约债权人在作出选择之前死亡亦然。

<!-- source-p 319 -->
<a id="45.1.76.1"></a>**1**　若我们约定“你应给付或实施的一切”，纳入要式口约的仅是截至当日已经到期的债务，而不像诉讼中那样还包括将来债务。因此，要式口约中须加上“将应当”一词，或者表述为“现在或将来应当”。这是因为，约定“你现在应给付的一切”的人，指明的是已经到期的金钱；若他想指明全部债务，就应说“现在或将来应当给付”。

<a id="45.1.81.pr."></a>**序言**　有人允诺使他人到庭，却未约定违约金，例如允诺使自己的奴隶或某个自由人到庭，问题是要式口约是否因此生效。塞尔苏斯说，即使未在该要式口约中加上“若其未到庭，应给付违约金”，该承诺仍涵盖不使其到庭所造成的利益损失。塞尔苏斯的说法是正确的：允诺使他人到庭者，承诺的是自己将采取行动使其到庭。

<!-- source-p 336 -->
<a id="45.1.81.1"></a>**1**　代理人约定使某人到庭而未约定违约金时，可以主张，他纳入该事项的并非自己的利益，而是其所管理事务之本人的利益。如果代理人约定“按该事项的价值赔偿”，则更应如此认定。

<a id="45.1.82.2"></a>**2**　宁愿诉讼而不愿返还的人，也被认为已经迟延。

<a id="45.1.83"></a>**45.1.83**

<!-- source-p 343 -->
保罗《告示评注》第72卷。

<!-- source-p 344 -->
<a id="45.1.83.pr."></a>**序言**　要式口约债权人与允诺人之间成立法律关系。因此，为他人作出允诺的人，不因此而负有使他人给付或作为的义务；每个人都应当就自己作出允诺。有人允诺“现在和将来均无恶意欺诈”，并非仅作出单纯的否认，而是允诺自己将确保不存在恶意欺诈。“保证能够占有”以及“不得由你或你的继承人妨碍该行为”这类要式口约，也应作相同理解。

<!-- source-p 345 -->
<a id="45.1.83.1"></a>**1**　若我约定奴隶斯提库斯，而我所指的是一人，你所指的是另一人，则未成立任何约定。阿里斯托在诉讼中也持此见解；不过，在这里更应认为，所请求的是原告心中所指之人。因为要式口约须以双方合意为基础才能成立，而诉讼即使在被告不情愿时也会提起，因此应以原告的理解为准；否则，被告总会否认自己曾表示同意。

<!-- source-p 346 -->
<a id="45.1.83.2"></a>**2**　我向你约定“给付奴隶斯提库斯或潘菲卢斯”，你却允诺只给付其中一人。公认，你不因此负有义务，因为你没有针对所受询问作出回答。

<!-- source-p 347 -->
<a id="45.1.83.3"></a>**3**　金额的情形不同，例如询问“你允诺给付十或二十吗？”即使你只允诺给付十，也可认为你作出了有效回答，因为在金额的约定中，较低数额总被认为包含在允诺之内。

<!-- source-p 348 -->
<a id="45.1.83.4"></a>**4**　同样，若我约定多个标的，例如奴隶斯提库斯和潘菲卢斯，即使你只允诺给付其中一个，也仍负有义务，因为可以认为你是对两个要式口约中的一个作出了回答。

<!-- source-p 349 -->
<a id="45.1.83.5"></a>**5**　我不能有效约定给付神圣物、宗教物、永久供公众使用之物（如广场或巴西利卡），或自由人，即使神圣物可能变为世俗物，永久供公众使用之物可能转为私人用途，自由人也可能成为奴隶。因为，若有人允诺交付世俗物或奴隶斯提库斯，而其后该物未经允诺人行为即成为神圣物，或斯提库斯获得自由，允诺人即告免责；即使后来依某项法律，该神圣物又成为世俗物，或斯提库斯由自由人变为奴隶，也不会使其重新负担债务。原因在于，使其免责与重新负债的理由本应相同：即该物是否能够交付。譬如，所有人拆散了自己允诺交付的船只，后来又用同一批木板重新拼装；如果是同一艘船，就会重新负债。佩迪乌斯认为，也可以这样说明另一种情形：若我约定交付庄园所产的一百安福拉酒，我应等待酒酿成；若酒酿成后，未经允诺人过错即被耗尽，我还应再次等待，直至酒再次酿成并可交付。因此，要式口约会在各个阶段时而不生效、时而恢复效力。然而这些情形并不相同。允诺交付自由人时，不应考察其成为奴隶的期间；以自由人为标的的要式口约本身也不应得到认可，例如“你允诺在某人开始成为奴隶时交付他吗？”或“你允诺在某处不再是神圣或宗教场所、而成为世俗之地时交付该地吗？”因为此种约定既不能使现在的债务关系成立，能够纳入债务的也仅限于依其性质可能实现之事。酒的约定并非针对某一特定种类，而是针对一个种类；其中默示包含了等待时间。自由人则属于确定的特定对象。以自由人的偶然遭遇或不幸为考虑因素，既不符合市民法，也不符合自然法；因为只有能够立即置于我们使用与支配之下的事物，才可以成为有效交易的对象。至于船只，若拆解船只的目的在于将木板改作他用，即使后来改变主意将船修复，也应认为原船已灭失，修成的是另一艘船；但若拆下所有木板只是为了修船，船舶尚未灭失，重新拼装后仍是原来那艘船。正如房屋的木梁若为日后重新使用而拆下，仍属于房屋的一部分；但若房屋已被拆至地基，后来即使以同样材料重建，也应视为另一座房屋。本段论述同样适用于裁判官程式上的担保，其中会约定返还某物，而问题在于返还的是否仍为同一物。

<!-- source-p 350 -->
<a id="45.1.83.6"></a>**6**　若我基于无偿取得的原因约定给付某物，而后又基于无偿取得的原因取得了该物，要式口约即失去效力。但若我继承了该物所有人的遗产，要式口约即告消灭。反之，若死者将该物遗赠给我，而我是其继承人，则仍可基于要式口约提起诉讼；〔原句 *a me herede defunctus eam legavit* 的语法及人物身份关系待核。〕若遗赠附有条件，也应如此，因为即使债务人本人将该物附条件遗赠出去并交付，也不会因此免责。但若条件未成就，该请求即失去依据。

<!-- source-p 351 -->
<a id="45.1.83.7"></a>**7**　若我约定给付已经死亡的斯提库斯，萨宾认为：如果即使其死亡仍可基于返还请求要求给付，例如对窃贼提起返还之诉，则我所作的约定有效；若基于其他原因，则约定无效，因为即使该物原本负有债务，允诺人也会因其死亡而免责。若我约定给付一名在允诺人迟延后死亡的人，也应作相同处理。

<!-- source-p 352 -->
<a id="45.1.83.8"></a>**8**　有人允诺使一名怀孕女奴在某地到庭，即使其未能分娩便到庭，也应认为她是以约定时的同一状态到庭。

<a id="45.1.85.pr."></a>**序言**　在债务的执行中，应知有四种情形：有时，债权人可以分别向各个继承人请求相应部分；有时，必须请求全部给付，且不能分割给付；有时，可以按份请求，但只有全部给付后才能清偿；还有时，必须请求全部给付，尽管分次给付也可导致债务消灭。

<!-- source-p 359 -->
<a id="45.1.85.1"></a>**1**　第一种情形涉及允诺给付确定数额金钱者：请求和清偿均依继承份额分别计算。

<!-- source-p 360 -->
<a id="45.1.85.2"></a>**2**　第二种情形涉及立遗嘱人命令完成的工程：每一继承人均对全部工程负有义务，因为工程成果不能分割为数个部分。

<!-- source-p 361 -->
<a id="45.1.85.3"></a>**3**　若我约定：“不得由你或你的继承人妨碍我通行；若违反此约定，应给付一定金额”，而允诺人的数名继承人中有一人阻止我通行，那么认为一人行为使所有继承人承担责任的见解更为正确。因为虽然我只是被一人阻止，但并非只在部分范围内受到阻止；其他继承人则可通过遗产分割诉讼获得补偿。

<!-- source-p 362 -->
<a id="45.1.85.4"></a>**4**　第三种情形是可以按份请求、但只有全部给付才能清偿的情形，例如我约定给付一名未特定的奴隶：请求可以按份分割，但给付必须是完整的一名奴隶。否则，若标的是不同的人，按份给付本来完全可行；而死者无法这样履行，我也就无法取得自己约定的给付。允诺人约定给付一万或一名奴隶时，法律也相同。

<!-- source-p 363 -->
<a id="45.1.85.5"></a>**5**　第四种情形必须请求全部给付，但部分给付也可使债务消灭，例如我们基于追夺原因提出请求时。出卖人的继承人均须就全部标的受到通知，并且都应出庭应诉；任何一人逃避应诉，所有人均须承担责任，但每人只按其继承份额承担给付。

<!-- source-p 364 -->
<a id="45.1.85.6"></a>**6**　又如要式口约约定：“若未交付提提乌斯庄园，即给付一百”，庄园未全部交付，给付一百的罚则即告发生。即使已交付庄园的一部分，只要另有一名继承人仍未履行，罚则仍不能避免；这正如债权人须收到全部款项，才能解除全部质押。

<!-- source-p 365 -->
<a id="45.1.85.7"></a>**7**　任何附条件负债之人若设法阻止条件成就，仍应承担债务。

<a id="45.1.91.pr."></a>**序言**　若我约定给付一名奴隶，而奴隶在未发生任何迟延时死亡：若允诺人杀死了他，问题很明了。若允诺人疏于照料病弱的奴隶，是否应由其负责？我们应考虑，是否应如在奴隶返还之诉中，奴隶因占有人疏于照料而死亡时，占有人须就其过错负责那样，在允诺给付奴隶时也应如此；抑或就要式口约而言，过错应理解为未实施某种作为，而非未实施某种不作为。后一种观点更可取，因为允诺交付的人负有交付义务，而非实施作为的义务。

<!-- source-p 384 -->
<a id="45.1.91.1"></a>**1**　若标的仍存在于人间，但已不能交付，例如庄园成为宗教物或神圣物、奴隶被释放，或者标的被敌人俘获，过错应按以下方式判断：若在订立要式口约时或其后，该物曾属于允诺人，而后发生上述情形之一，允诺人仍应负责；即使该物已由其转让给他人，而其后又发生上述情形，也同样如此。反之，若该物原本属于他人，且上述情形是由他人造成，允诺人不负责任，因为他并未实施任何行为；但若此事发生在其迟延履行之后，则仍应负责。尤利安也采用这一区分。同样，若曾属于允诺人的奴隶因先前存在的原因被他人取走，例如该奴隶原属附条件释放者，则应视同允诺人允诺交付他人的奴隶，因为并非由于允诺人的行为，该奴隶才不再属于他。

<!-- source-p 385 -->
<a id="45.1.91.2"></a>**2**　还须考虑，不知自己负有债务而杀死标的物的人是否也应负责。尤利安认为应负责，例如某人不知有人曾以附录请求其返还奴隶，便将奴隶释放。

<!-- source-p 386 -->
<a id="45.1.91.3"></a>**3**　接下来应考察古人所确立的规则应如何理解：债务人一旦有过错，债务即永久存续。若允诺人使自己无法清偿，规则的含义很明确；若他只是发生了迟延，而其后不再迟延，先前的迟延是否消灭，仍有疑问。青年塞尔苏斯写道：允诺给付斯提库斯而发生迟延的人，后来仍可提出给付，从而补正迟延。因为这是关于公平与衡平的问题；他说，在这类问题中，人们往往在法律学说的权威之下作出有害的错误判断。这一见解确实颇为合理，尤利安也赞同：既然问题关乎损害，而双方处境相同，为什么应当让占有标的物的一方优于请求标的物的一方？

<!-- source-p 387 -->
<a id="45.1.91.4"></a>**4**　现在考察这一规则适用于哪些人。此项考察有两方面：首先，要查明哪些人会使债务永久存续；其次，要查明债务会对哪些人延续。主债务人当然会使债务永久存续。附属债务人是否也会如此，尚有疑问。庞波尼认为会延续：保证人何以能以自己的行为消灭自己的债务？这一见解是正确的。因此，主债务人及其继承人的债务均会延续；其附属债务人，也就是保证人，也会使债务延续，因为他们是就整个债务承担保证。

<!-- source-p 388 -->
<a id="45.1.91.5"></a>**5**　家子经父亲命令作出允诺后，若杀死了奴隶，是否会使父亲的债务延续，尚须考察。庞波尼认为会延续，因为可以将发出命令的父亲理解为附属债务人。

<!-- source-p 389 -->
<a id="45.1.91.6"></a>**6**　这一规则的效果是，仍可请求交付该奴隶；并且据认为，也可以将其作为已受领而免除债务，或者就该债务接受保证人。此项债务能否更新，尚有疑问，因为我们不能约定交付一个已不存在的人，也不能约定给付一笔并不存在的金钱。我认为，若当事人间有此合意，债务仍可更新；尤利安也持此见解。〔底本此处作 *huius*，并附异文 *huis*。〕

<a id="45.1.112.1"></a>**1**　有人如此约定：“你愿意提供价值一百金币的担保吗？”，并指定允诺人为承担该数额的人。普罗库鲁斯说，在担保要式口约中，约定者的利害关系总会成为判断内容：有时包括全部本金，例如允诺人没有偿付能力；有时数额较少，例如债务人对部分债务有偿付能力；有时则完全不包括，例如允诺人富有到足以使约定者无利害关系，不必接受其担保。通常，偿付能力不仅依财产判断，也依个人信用判断。

<a id="45.1.113.pr."></a>**序言**　我曾向你约定：“若工程未能依我的判断于六月一日前完成，应支付违约金。”后来我延长了期限。我是否还能真实地说，依我的判断，工程未能在六月一日前完成？毕竟，我依自己的判断给了工程另一个更宽裕的期限。普罗库鲁斯答复：应当区分，六月一日前工程未能按要式口约所定方式完成，是否因允诺人发生迟延所致；以及在工程已经不可能于六月一日前完成时，债权人才将期限延长至八月一日。若债权人是在工程已不可能于六月一日前完成时才延长期限，我认为违约金已经发生；债权人此前曾有一段时间没有要求工程在六月一日前完成，并不影响这一点——也就是说，他在工程已不可能于六月一日前完成时，没有判断要求其按期完成。若这种解释不正确，那么即使债权人在六月一日前一日死亡，违约金也不会发生，因为死者已不能作出判断，而其死亡后尚有一段时间可以完成工程。甚至可以说，只要在六月一日前，工程已开始显然无法于该日期前完成，违约金就已经发生。

<a id="45.1.115.pr."></a>**序言**　我如此约定：“你应在某一确定地点到庭；若未到庭，应给付五十金币。”若要式口约中因错误而遗漏了日期，而当事人原本打算使你在某一确定日期到庭，该要式口约即不完整。这与我约定交付某种依重量、数量或度量确定的物品，却没有说明重量、数量或度量；或者约定建造岛状建筑，却没有说明地点；或者约定交付庄园，却未注明庄园名称，情形相同。反之，若当事人从一开始就打算让你在任何一天到庭，而你未到庭时即给付金钱，则该要式口约如同任何附条件约定一样有效；只有明确表明允诺人无法到庭时，才会触发。

<!-- source-p 470 -->
<a id="45.1.115.1"></a>**1**　同样，若我约定：“若你未登上卡比托利欧山”或“未前往亚历山大里亚，即给付一百”，即使你原本能够登上卡比托利欧山或到达亚历山大里亚，要式口约也不会立即触发；只有当你已确定无法登山或前往亚历山大里亚时，才会触发。

<!-- source-p 471 -->
<a id="45.1.115.2"></a>**2**　若有人如此约定：“若你不交付潘菲卢斯，你允诺给付一百吗？”佩伽苏斯答复：只有在潘菲卢斯已不可能交付时，要式口约才发生效力。萨宾则认为，应依当事人订约时的意思，在奴隶原本可以交付之后即可立即起诉；只要并非由于允诺人之故而未能交付奴隶，就不得依该要式口约起诉。萨宾以遗嘱所遗赠的食品为例支持其见解。穆基乌斯曾写道：继承人若本来能够交付遗赠的食品却未交付，即应立即承担支付遗赠金钱的责任；这一规则是出于实用而被接受的，因为它符合死者的意愿以及标的物本身的性质。因此，若要式口约并非以条件开头，例如“若你不交付潘菲卢斯，就允诺给付这么多吗？”，而是如此订立：“你允诺交付潘菲卢斯吗？若你不交付，就允诺给付这么多吗？”，则可采纳萨宾的见解。毫无疑问，若能证明当事人约定的是：若未交付奴隶，则奴隶和金钱均为债务标的，结论也应如此。但若约定仅在奴隶未交付时才应给付金钱，也应作相同解释，因为可以证明当事人意在由奴隶履行，或请求给付金钱。

<a id="45.1.126.pr."></a>**序言**　若我如此约定：“若提提乌斯成为执政官，从今日起每年给付十”，那么在三年后条件成就时，可以请求三十。

<!-- source-p 516 -->
<a id="45.1.126.1"></a>**1**　提提乌斯约定梅维乌斯交付庄园，但保留用益权；又向同一人约定该庄园的用益权。这是两项要式口约。单独约定给付用益权，所包含的内容少于随所有权一并产生的用益权。因此，若允诺人给付了用益权，而要式口约债权人因未行使而丧失了该用益权，允诺人后来交付保留用益权的庄园，即可免责。对另一种情形则不然：允诺人以完整所有权允诺交付庄园，随后给付用益权，又在用益权丧失后交付不附用益权的所有权；在该例中，允诺人并未因任何部分而解除债务，除非要式口约债权人取得了庄园的完整所有权。

<!-- source-p 517 -->
<a id="45.1.126.2"></a>**2**　奴隶契约代理人克律索戈努斯书写道：“我的主人在场并签署确认：他已从尤利乌斯·佐萨处收到一千第纳里借款；佐萨代表不在场的尤利乌斯·昆提利安行事。佐萨是昆提利安的获释奴。佐萨作为昆提利安的代理人约定，应于即将到来的十一月一日将该款交付给昆提利安或其继承人、亦即有权取得该款之人；弗拉维乌斯·坎狄杜斯，我的主人，作出允诺。若在上述日期未就此提供足够担保，则此后每月应支付八第纳里作为利息；尤利乌斯·佐萨约定，弗拉维乌斯·坎狄杜斯，我的主人，作出允诺。”主人签署确认。我答复：我们不能通过一个自由人取得债务关系，除非该人受我们的法律权力支配，或基于善意为我们服役。诚然，若自由人以我们的名义交付自己的金钱或我们的金钱，供他人向我们清偿，我们可以取得借贷金钱债务；但获释奴为其主人约定给付的款项无效，且即使在原本主要为之取得债务的缺席债权人名下附加此约定，也不会使其有效。接下来要问的是，实际交付款项的人能否基于借贷本身请求返还：因为每当我们交付借款同时又约定受领该款时，并非产生两项债务，而仅产生一项言词债务。诚然，若先交付金钱、其后再作要式口约，不能说自然债务已经消灭。随后订立的要式口约中，佐萨未附加任何人名而约定利息；该约定不受同样瑕疵影响，因为不能恶意地将其理解为只向同一人约定了利息和本金。因此，关于利息的要式口约对获释奴而言有效，并且他有义务将其让与主人。通常，在要式口约中应考察产生债务的措辞；只有在少数情形下，才能根据当事人的行为推知其中包含期限或条件；至于约定的对象，则绝不能如此推知，除非已明确写明。

<a id="45.1.137.2"></a>**2**　若我如此约定：“你允诺在以弗所给付吗？”，其中包含了时间期限。问题是，应如何理解所约定的给付期限。更合理的做法是将全部问题交由法官，也就是善良之人判断；由其评估一个勤勉的家父能够在多长时间内完成其允诺之事。允诺在以弗所给付的人，不应被迫不分昼夜、不顾天气，乘坐快船赶路；也不应过于悠闲，以致显得应受指责。应考虑时间、年龄、性别和健康状况；其目标应是及时抵达，也就是与多数处境相同之人通常抵达的时间相当。期限届满后，即使其仍留在罗马而无法在以弗所给付，也仍可以向其提起返还之诉；因为未能在以弗所给付可能是由其自身造成，也可能由他人在以弗所代为给付，或者因为他可以在任何地点清偿。约定于将来日期到期的债务也可以提前清偿，虽然尚不能提前起诉。反之，若其乘坐快船或因航行顺利而比通常更早抵达以弗所，债务即刻发生，因为期限和行为均已明确完成，不存在推测的余地。

<!-- source-p 564 -->
<a id="45.1.137.3"></a>**3**　同样，允诺建造岛状建筑的人，不必四处搜罗工匠并雇用大量工人以求赶工，也不应仅满足于雇用一名或两名工人；应依勤勉建造者的标准，并考虑时间和地点，确定适当程度。同样，若工程尚未开始，只应评估在该期间本可完成多少工作。完成岛状建筑所需期限届满后，若允诺人此后才建成建筑，即告免责；正如允诺给付之人无论何时最终交付，均可免责。

<!-- source-p 565 -->
<a id="45.1.137.4"></a>**4**　应查明允诺给付一百的人是否立即负有责任，抑或在其能够筹得金钱之前，债务暂不生效。那么，若他既没有现款，也找不到放款人，该如何处理？这些情形并非自然障碍，而是涉及给付能力。个人的给付能力取决于其自身的便利与不利，而非所允诺之物的性质。否则，若有人允诺交付斯提库斯，我们就会询问斯提库斯在哪里；或者，若“我允诺在以弗所给付”与“我允诺在罗马给付已在以弗所的钱”看起来没有多大区别，因为允诺人身在罗马，那么这同样属于给付能力问题。金钱和斯提库斯共有的情形是，允诺人当下无法给付。总之，困难源于允诺人的不便，而非债权人的障碍；否则就会得出这样的结论：允诺交付他人所有且其所有人不愿出售的奴隶的人，也不能给付。

<!-- source-p 566 -->
<a id="45.1.137.5"></a>**5**　萨宾写道：即使允诺人本人无法履行，但他人可以履行，债务仍依法有效成立。

<!-- source-p 567 -->
<a id="45.1.137.6"></a>**6**　若有人约定：若提提乌斯出售神圣物、宗教物，或广场、巴西利卡等永久留供公众使用之物，则应发生某项后果；若该条件根本无法依法成就，或允诺人无权实施该行为，要式口约即无效，如同其中附加了自然上不可能的条件。法律可能改变，现在不可能的事将来可能实现，这一点无关紧要；要式口约应根据现行法律，而非未来法律来判断。

<!-- source-p 568 -->
<a id="45.1.137.7"></a>**7**　若我们约定实施某事，拉贝奥说，较为惯常且恰当的违约金条款是：“若未如此实施”；若约定不得实施某事，则应使用“若实施了相反行为”之语；若同时约定既须实施某事、又不得实施另一事，则应表述为：“若你未实施，或实施了相反行为”。

<!-- source-p 569 -->
<a id="45.1.137.8"></a>**8**　此外应知，若我们约定给付某物，该债权不能仅由一名继承人取得，而必须由所有继承人共同取得；但若约定实施某事，则可以仅针对其中一名继承人作出有效约定。

<a id="45.1.138.1"></a>**1**　若我无条件约定给付这个或那个，你可以随时改变自己打算给付何物，因为明确表达的选择意愿与内含于约定中的意愿性质不同。

若我们基于双倍追夺担保提出请求，所有出卖人的继承人均应被一并起诉，并且所有人都必须出庭应诉；任何一人逃避应诉，其余继承人出庭也无济于事，因为出卖人所作的担保具有不可分割的性质，必须就全部交易予以抗辩。但若其中一人逃避应诉，视为所有人均逃避应诉，因此所有人都负有责任；不过，每人只按其继承份额承担给付。

<a id="45.1.140"></a>**45.1.140**

<!-- source-p 578 -->
保罗《评涅拉提乌斯》第3卷。

<!-- source-p 579 -->
<a id="45.1.140.pr."></a>**序言**　在列明数项事项后，若要式口约约定“交付以上所列全部事项吗？”，更接近正确的解释是：有多少项标的，就成立多少项要式口约。

<!-- source-p 580 -->
<a id="45.1.140.1"></a>**1**　对于这一要式口约：“每年、第二年和第三年，在相应日期给付该金钱”，古人意见不一。保罗认为，更正确的见解是：这是三项分别针对三个数额的要式口约。

<!-- source-p 581 -->
<a id="45.1.140.2"></a>**2**　即使有人认为，若债务陷入其无法成立的状态，债务即告消灭，这一规则也不适用于所有情形。例如，共有人不能约定对共同庄园设立道路、通行和驱赶牲畜的地役权；但若作出约定的人留下两名继承人，该要式口约并不消灭。地役权不能通过部分所有人取得，但取得后可由仅拥有部分所有权的人继续维持；例如，供役地或需役地的一部分开始属于另一名所有人时，即属此种情形。

<!-- source-p 582 -->
<a id="45.1.141"></a>**45.1.141**

<!-- source-p 583 -->
盖尤斯《言词债务》第2卷。

<!-- source-p 584 -->
<a id="45.1.141.pr."></a>**序言**　若奴隶或家子如此约定：“给付这个或那个，由我选择”，应由该子女或奴隶本人决定给付哪一项，而非由父亲或主人决定。

<!-- source-p 585 -->
<a id="45.1.141.1"></a>**1**　若约定中也列入了第三人的选择，例如“提提乌斯选择其中哪一项”，则只有提提乌斯作出选择后，要式口约债权人才有权请求给付其中一项。

<!-- source-p 586 -->
<a id="45.1.141.2"></a>**2**　未成年人自能够说话起即可有效约定给付；但是，若其处于父权之下，即使父亲给予同意，也不能使其负担债务。达到适婚年龄而仍处于父权之下的人，则可以像家父一样承担债务。对未成年人的上述规则，同样适用于处于父权之下的未婚女子。

<!-- source-p 587 -->
<a id="45.1.141.3"></a>**3**　若我如此约定：“给付给我或提提乌斯”，而你允诺给付给我，依公认见解，你是针对所受询问作出了回答；因为债务仅由我取得，但可以有效地向提提乌斯清偿。

<!-- source-p 588 -->
<a id="45.1.141.4"></a>**4**　若身在罗马的人如此约定：“你允诺今日在迦太基给付吗？”，有人认为，并非总应视为要式口约包含不可能的内容；因为要约定在某日于迦太基给付，约定者和允诺人可以分别提前通知各自的管家。允诺人指示自己的管家届时付款，约定者则指示自己的管家届时收款。若事实确实如此，要式口约便可能有效。

<!-- source-p 589 -->
<a id="45.1.141.5"></a>**5**　若我约定“给付给我或提提乌斯”，据说不能为我和提提乌斯分别指定不同的标的，例如“给我十，或给提提乌斯一名奴隶”。若已向提提乌斯给付了指定给他的标的，尽管允诺人依法律本身尚未免责，仍可通过抗辩获得保护。

<!-- source-p 590 -->
<a id="45.1.141.6"></a>**6**　可以指定不同的日期，例如“于一月一日给付给我，或于二月一日给付给提提乌斯”；也可以把较早日期指定给提提乌斯，例如“于二月一日给付给我，于一月一日给付给提提乌斯”。在后一种情形中，应将要式口约理解为：“若未于一月一日给付提提乌斯，你允诺于二月一日给付我吗？”

<!-- source-p 591 -->
<a id="45.1.141.7"></a>**7**　我可以附条件约定给付给我，或者无条件给付给提提乌斯。反之，若我约定附条件给付给我，或者无条件给付给提提乌斯，整个要式口约即无效，除非针对我的条件已经成就；因为除非债务关系对我发生效力，附加提提乌斯的名字就不能产生任何效力。不过，只有在明显可以看出提提乌斯是无条件地被附加时，才适用这一规则；否则，若我如此约定：“若船舶从非洲抵达，你允诺给付给我或提提乌斯吗？”，也应认为提提乌斯同样是在该条件下被附加。

<!-- source-p 592 -->
<a id="45.1.141.8"></a>**8**　由此可见，若对我和提提乌斯分别设定了不同条件，而针对我的条件未成就，则整个要式口约均无效。若我的条件成就，而提提乌斯的条件也成就，可以向提提乌斯清偿；但若其条件未成就，就应视为未曾附加提提乌斯。

<!-- source-p 593 -->
<a id="45.1.141.9"></a>**9**　由以上各点可见，即使他人的名字被无效地附加，也不妨碍要式口约对我们本人有效成立。
