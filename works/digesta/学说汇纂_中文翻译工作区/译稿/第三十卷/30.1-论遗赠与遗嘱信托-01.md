# D.30.1 论遗赠与遗嘱信托（*De legatis et fideicommissis*）——第一部分

<!-- 依随附原始网页 HTML 补回篇题；题名锚点 1 在整理后的 EPUB 中未保留。 -->
<a id="1"></a>**30.0**　论遗赠与遗嘱信托（*De legatis et fideicommissis*）。

<!-- source-p 001 -->
<a id="30.1"></a>**30.1**

<!-- source-p 002 -->
**乌尔比安：《评告示》第六十七卷。**

<!-- source-p 003 -->
遗赠与遗嘱信托在所有方面均已同等对待。

<!-- source-p 004 -->
<a id="30.2"></a>**30.2**

<!-- source-p 005 -->
**乌尔比安：《遗嘱信托》第一卷。**

<!-- source-p 006 -->
应当知道，只有享有订立遗嘱权的人才能设立遗嘱信托。

<!-- source-p 007 -->
<a id="30.3"></a>**30.3**

<!-- source-p 008 -->
**乌尔比安：《评萨宾》第四卷。**

<!-- source-p 009 -->
立遗嘱人使用“上述之人中，凡成为我继承人的”或“若塞尤斯成为继承人”或“若其接受继承”这类措辞，并不会使其随后附加的遗赠或遗嘱信托成为附条件处分。

<!-- source-p 010 -->
<a id="30.4"></a>**30.4**

<!-- source-p 011 -->
**乌尔比安：《评萨宾》第五卷。**

<!-- source-p 012 -->
<a id="30.4.pr."></a>**序言。**若某人误称地产名称，把塞姆普罗尼乌斯地产说成科尔涅利乌斯地产，仍应给付塞姆普罗尼乌斯地产；但若他弄错了所指的实物，就无须给付。又如某人想遗赠衣物，却写成家用器具，因为他以为衣物包含在家用器具之内；庞波尼乌斯写道，不应给付衣物。正如有人以为黄金包括琥珀金或黄铜，甚至更荒谬地以为“衣物”一词也包括银器，结论亦同。物的名称不可改变，人的名称则可以改变。

<!-- source-p 013 -->
<a id="30.4.1"></a>**1.**若某人指定继承人后写道：“凡成为我高卢财产继承人的，都应负有给付义务”，则应认为该遗赠由所有继承人承担，因为高卢财产属于他们全体。

<!-- source-p 014 -->
<a id="30.5"></a>**30.5**

<!-- source-p 015 -->
**保罗：《评萨宾》第一卷。**

<!-- source-p 016 -->
<a id="30.5.pr."></a>**序言。**对于以选择方式遗赠的奴隶，我们只能选择一次。

<!-- source-p 017 -->
<a id="30.5.1"></a>**1.**拉贝奥说，若以“我死亡时属于我的某物或某人，由继承人给付”这样的方式遗赠一项特定财产或特定之人，而该物或该人属于共有，则应给付全部。卡西乌斯则写道，特雷巴提乌斯答复说只应给付相应份额；此说更为正确。

<!-- source-p 018 -->
<a id="30.5.2"></a>**2.**若遗赠一处共有地产而未注明份额，只写“我的地产”，确定应给付立遗嘱人的份额。

<!-- source-p 019 -->
<a id="30.6"></a>**30.6**

<!-- source-p 020 -->
**尤利安：《学说汇纂》第三十三卷。**

<!-- source-p 021 -->
“将我死亡时属于我的斯提库斯给我的继承人。”显然，家父借此为遗赠附加了条件，而非仅仅想指明奴隶身份；若意在指明身份，应写成“属于我的斯提库斯”，而非“将属于我的斯提库斯”。不过，该条件应理解为“在其属于我的范围内”：若已将其全部转让，遗赠即告消灭；若只转让一部分，则应按其在立遗嘱人死亡时仍属于立遗嘱人的份额给付。

<!-- source-p 022 -->
<a id="30.7"></a>**30.7**

<!-- source-p 023 -->
**保罗：《评萨宾》第二卷。**

<!-- source-p 024 -->
主人可以拒绝给予其奴隶的遗赠。

<!-- source-p 025 -->
<a id="30.8"></a>**30.8**

<!-- source-p 026 -->
**庞波尼乌斯：《评萨宾》第二卷。**

<!-- source-p 027 -->
<a id="30.8.pr."></a>**序言。**若立遗嘱人把整处地产遗赠出去后，转让了其中一部分，意见认为只应给付剩余部分；因为如果他在该地产上增添财产，增添部分也会归受遗赠人。

<!-- source-p 028 -->
<a id="30.8.1"></a>**1.**若遗嘱写道：“我的继承人卢基乌斯·提提乌斯或我的继承人梅维乌斯，应给塞尤斯十枚钱币”，那么塞尤斯可以选择起诉其中一人；若已向一人起诉且给付完成，另一人即获免责，如同两名连带允诺人各自对全部债务负有责任。〔底本此句末有连写疑误〕若塞尤斯只向其中一人请求部分给付，仍可自由向任一人请求剩余部分；其中一人已经给付部分时，也适用同一规则。

<!-- source-p 029 -->
<a id="30.8.2"></a>**2.**若遗赠写道：“八名轿夫，或者由受遗赠人选择，按每名奴隶给付一定金额”，受遗赠人不得请求部分奴隶、另以金钱替代其余奴隶，因为遗赠只能在两种给付方式中择一。五十磅油或按每磅给付一定金钱的遗赠，也同样如此；否则，连遗赠一名奴隶都可以拆分。无论金额是分别列出还是合并列出，均不影响这一点。遗赠八名奴隶或以一笔确定金钱替代全部奴隶时，也不能违背继承人的意愿，强令其以部分金钱、部分奴隶履行。

<!-- source-p 030 -->
<a id="30.9"></a>**30.9**

<!-- source-p 031 -->
**庞波尼乌斯：《评萨宾》第三卷。**

<!-- source-p 032 -->
奥克塔维努斯写道，处于敌人手中的财产也可以遗赠，并可依复归权规则维持其效力。

<!-- source-p 033 -->
<a id="30.10"></a>**30.10**

<!-- source-p 034 -->
**保罗：《评萨宾》第二卷。**

<!-- source-p 035 -->
尤利安认为，家子未经父亲命令不得作出选择，而且在遗产尚未被接受之前也不得选择；此说正确。

<!-- source-p 036 -->
<a id="30.11"></a>**30.11**

<!-- source-p 037 -->
**帕比尼安：《疑问集》第九卷。**

<!-- source-p 038 -->
若遗赠或继承被给予处于家父权之下的儿子或他人的奴隶，可以嘱托其父亲或主人履行遗嘱信托；但只有在遗嘱信托是留给儿子或奴隶本人——即借其身份使父亲或主人获得遗赠或继承利益之人——时，该遗嘱信托才对他们发生效力。尤利安基于颇为妥当的理由答复：若某人的儿子被指定为继承人，父亲受嘱托向外人返还遗产，父亲应在考虑《法尔基第法》的前提下返还，因为其责任源于儿子的身份；但若受嘱托对象是儿子本人，就不适用《法尔基第法》，因为儿子不能以自己的身份使自己承担义务，而父亲被嘱托履行遗嘱信托，是以父亲身份而非继承人身份受嘱托。因此，若父亲被嘱托在自己死后返还儿子所得遗赠或继承的财产，而儿子先于父亲死亡，父亲无论如何都可保留该财产，因为遗嘱信托是基于父亲的身份才发生效力。

<!-- source-p 039 -->
<a id="30.12"></a>**30.12**

<!-- source-p 040 -->
**庞波尼乌斯：《评萨宾》第三卷。**

<!-- source-p 041 -->
<a id="30.12.pr."></a>**序言。**若同一物品遗赠给我和你，之后在遗赠请求权发生之日我成为你的继承人，拉贝奥说，我可以选择通过自己的遗赠取得该物，或以继承你的身份取得遗赠；若我愿意让该物依我自己的遗赠归我、并由我单独所有，也可以作为你的继承人请求给付该物。

<!-- source-p 042 -->
<a id="30.12.1"></a>**1.**普罗库鲁斯说，若某人以在罗马临终时订立的遗嘱，命令继承人在其死亡后三日内把其在加迪斯的奴隶交给我，该遗赠有效；时间短暂不会使遗赠失效。

<!-- source-p 043 -->
<a id="30.12.2"></a>**2.**民法有一项规则：凡我们可以遗赠给某些人的，也可以遗赠给这些人的奴隶。

<!-- source-p 044 -->
<a id="30.12.3"></a>**3.**对于遗赠，最后写下的文字有效，因为先前遗赠的依据可以通过附加日期、条件或完全撤销而改变。但若以不同条件多次撤销遗赠，应以最后一次撤销为准。有时，遗赠并非以后写下的文字，而是先前的文字有效。例如，若我写道：“我在下文所遗赠的，均不再给予或遗赠”，下文所列遗赠便无效。又有意见认为，将现在给予的遗赠延至将来履行的措辞，也适用于其后写下的遗赠。因此，决定遗嘱所写内容是否有效的，是立遗嘱人的意思。

<!-- source-p 045 -->
<a id="30.13"></a>**30.13**

<!-- source-p 046 -->
**庞波尼乌斯：《评萨宾》第四卷。**

<!-- source-p 047 -->
若遗赠给你的是某个不确定的人，继承人却依你主人的意思把斯提库斯交给你的奴隶，内拉提乌斯答复说：若继承人是依主人意愿交付，或主人事后认可，该继承人即告免责，如同斯提库斯本身被遗赠给你一样。

<!-- source-p 048 -->
<a id="30.14"></a>**30.14**

<!-- source-p 049 -->
**乌尔比安：《评萨宾》第十五卷。**

<!-- source-p 050 -->
<a id="30.14.pr."></a>**序言。**若遗嘱写道：“我遗赠给同一人的财产若重复写了两次，继承人只须给付一次”或“只须履行一次”，而同一人又被写明取得两笔金额或两处地产，是否两项都应给付？阿里斯托认为只构成一项遗赠。依塞尔苏斯和马尔凯卢斯的意见，已被撤销的事项不应视为又被第二次给予；这一意见正确。

<!-- source-p 051 -->
<a id="30.14.1"></a>**1.**但帕比尼安在《疑问集》第十九卷说，即使立遗嘱人在遗赠之后多次写下同一条款，表示只愿履行一次，并且是在遗嘱完成之前写下，也应依法视为撤销其余遗赠。但究竟哪项遗赠被撤销，并不清楚。他说，可以认为只须履行较小的给付。

<!-- source-p 052 -->
<a id="30.15"></a>**30.15**

<!-- source-p 053 -->
**保罗：《评萨宾》第三卷。**

<!-- source-p 054 -->
<a id="30.15.pr."></a>**序言。**某人想遗赠其财产的四分之一，却写成二分之一。普罗库鲁斯正确地说，可以主张遗赠的是四分之一，因为四分之一包含在二分之一之内。若某人想遗赠五十，却写成一百，亦同，应给付五十。若他想遗赠较多，却写下较少的金额，遗赠仍然有效。

<!-- source-p 055 -->
<a id="30.15.1"></a>**1.**若某人将一笔总额遗赠给女儿们，并希望遗腹女儿也能取得份额，而遗腹女儿未能出生，则生存的女儿应取得全部遗赠。
