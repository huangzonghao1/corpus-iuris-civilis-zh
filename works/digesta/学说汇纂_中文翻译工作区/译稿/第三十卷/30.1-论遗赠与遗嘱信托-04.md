# D.30.1 论遗赠与遗嘱信托（*De legatis et fideicommissis*）——第四段

<!-- source-p 322 -->
<a id="30.66"></a>**30.66**

<!-- source-p 323 -->
**盖尤斯：《评行省告示》第十八卷。**

<!-- source-p 324 -->
即使立遗嘱人命令继承人以公平价格买入或卖出，遗赠仍然有效。试想，受遗赠人必须向继承人买入某处地产，但因迫不得已要出售该地产而找不到买主，结果会如何？反过来说，若受遗赠人十分需要买入该地产，而继承人若非立遗嘱人有此命令便不会出售，又该如何？

<!-- source-p 325 -->
<a id="30.67"></a>**30.67**

<!-- source-p 326 -->
**盖尤斯：《论遗赠与城市裁判官告示》第一卷。**

<!-- source-p 327 -->
<a id="30.67.pr."></a>**序言。**若奴隶被遗赠给某一继承人，却有人指称他在遗产中实施了欺诈行为，例如涂改账目，除非共同继承人愿意对其进行讯问，否则不得将该奴隶交付给受遗赠人。遗赠给遗产外之人的，也适用同一规则。

<!-- source-p 328 -->
<a id="30.67.1"></a>**1.**若数名继承人按不同份额被指定，其中两人取得同一物品的遗赠，他们应按人头而非按各自继承份额取得该遗赠。

<!-- source-p 329 -->
<a id="30.68"></a>**30.68**

<!-- source-p 330 -->
**盖尤斯：《评行省告示》第十八卷。**

<!-- source-p 331 -->
<a id="30.68.pr."></a>**序言。**若遗赠在父亲死亡后留给其儿子，毫无疑问，父亲死亡时遗赠即归儿子所有；儿子是否成为父亲的继承人，并不重要。

<!-- source-p 332 -->
<a id="30.68.1"></a>**1.**但若遗赠在奴隶主人死亡后留给该奴隶，只要奴隶继续处于原有身份，该遗赠就归主人的继承人所有；即使主人在遗嘱中命令释放奴隶，也适用这一规则。因为在主人的任何继承人出现之前，遗赠请求权就已开始发生；遗赠由遗产取得后，待继承人出现，即归该继承人。但若某人依主人的遗嘱成为自权继承人或必然继承人，则属例外。此时，成为继承人与遗赠请求权开始发生恰好同时，较可取的意见是，遗赠归受遗赠人本人，而非归那个使其取得自由的主人的继承人。

<!-- source-p 333 -->
<a id="30.68.2"></a>**2.**若奴隶被无条件遗赠，却被命令在条件成就时获得自由，遗赠便以与自由条件相反的条件为准。因此，若自由条件成就，遗赠消灭；若条件未成就，遗赠归受遗赠人。由此，若受遗赠人在自由条件尚未确定时死亡，之后该自由条件未成就，遗赠也不归受遗赠人的继承人。

<!-- source-p 334 -->
<a id="30.68.3"></a>**3.**若同一奴隶被无条件遗赠，又被命令自某日起获得自由，则遗赠在任何情况下都无效，因为该日期确定会到来。尤利安也持此意见。他说，若奴隶遗赠给提提乌斯，又被命令在提提乌斯死亡后获得自由，遗赠即无效，因为提提乌斯必然会死亡。

<!-- source-p 335 -->
<a id="30.69"></a>**30.69**

<!-- source-p 336 -->
**盖尤斯：《论遗赠与城市裁判官告示》第二卷。**

<!-- source-p 337 -->
<a id="30.69.pr."></a>**序言。**已经承认，可以把遗赠留给一名同时被遗赠的奴隶；因为继承一经接受，该奴隶即归受遗赠人所有，随后留给奴隶的遗赠也由此发生效力。

<!-- source-p 338 -->
<a id="30.69.1"></a>**1.**若奴隶被附条件遗赠，而继承人在条件成就前将其转让，条件后来成就时，受遗赠人仍可请求返还该奴隶；遗赠并不因此消灭。

<!-- source-p 339 -->
<a id="30.69.2"></a>**2.**若立遗嘱人命令某些继承人清偿债务，债权人无权起诉这些继承人；有权起诉的是因债务清偿而享有利益的共同继承人。不仅在这种情形下，立遗嘱人指定的受益人以外之人才有诉权，其他情形也是如此。例如，立遗嘱人命令以女儿名义向女婿或未婚夫交付嫁资，享有诉权的并非女婿或未婚夫，而是女儿，因为最关心自己不致没有嫁资的人是她。

<!-- source-p 340 -->
<a id="30.69.3"></a>**3.**若被遗赠的地产负有已经设定的地役权，就应按现状交付；但若遗赠写明应以“最佳、最完整的状态”给付，则应不受地役权负担地交付。

<!-- source-p 341 -->
<a id="30.69.4"></a>**4.**正在处理事务的奴隶被遗赠时，应等其结清账目后再交付；若案件已经进入诉讼，也应由法官履行相同职责。

<!-- source-p 342 -->
<a id="30.69.5"></a>**5.**若遗赠物是否存在尚不确定，例如不清楚被遗赠之人是否仍然在世，意见认为，可以依据遗嘱提起诉讼，但应由法官依其职权命令提供担保：继承人保证将追索该物；若取得该物，则返还给受遗赠人。〔底本保留异文 *restiturum*〕

<!-- source-p 343 -->
<a id="30.70"></a>**30.70**

<!-- source-p 344 -->
**盖尤斯：《评行省告示》第十八卷。**

<!-- source-p 345 -->
<a id="30.70.pr."></a>**序言。**若提提乌斯的奴隶曾盗窃我的财物，之后提提乌斯指定我为继承人，又将该奴隶遗赠给你，将该奴隶按其在提提乌斯处的状态交付给你并无不公；也就是说，你应使我不因该奴隶在提提乌斯处实施的盗窃而受损。

<!-- source-p 346 -->
<a id="30.70.1"></a>**1.**若一处对我的地产负有地役权的地产遗赠给你，也适用类似规则：交付给你时，必须恢复原有地役权负担。

<!-- source-p 347 -->
<a id="30.70.2"></a>**2.**这与受他人委托购买奴隶的人或解除买卖并取回奴隶的人，情形相同；他们都只有在结算该奴隶于交易成立前后所实施的盗窃后，才必须返还奴隶。

<!-- source-p 348 -->
<a id="30.70.3"></a>**3.**因此，若奴隶在遗产被接受后、交付前盗窃了继承人的财物，交付奴隶时应由受遗赠人向继承人补偿该侵害的诉讼估价。

<!-- source-p 349 -->
<a id="30.71"></a>**30.71**

<!-- source-p 350 -->
**乌尔比安：《评告示》第五十一卷。**

<!-- source-p 351 -->
<a id="30.71.pr."></a>**序言。**若某人只笼统地遗赠“一所房屋”，未说明是哪一所，继承人就必须从立遗嘱人拥有的房屋中选一所交给受遗赠人。若立遗嘱人没有留下任何房屋，这项遗赠便徒具戏谑之意，而无实际效用。

<!-- source-p 352 -->
<a id="30.71.1"></a>**1.**我们应考察，依据遗赠交付奴隶的人是否须为追夺提供担保。一般而言，遗赠物未经诉讼便已交付，之后又被他人追夺的，可以依据遗嘱请求给付；但若遗赠物是经诉讼取得，法官应依其职权要求提供担保，以便受遗赠人可以提起要式口约之诉。

<!-- source-p 353 -->
<a id="30.71.2"></a>**2.**对于金钱遗赠，若继承人承认其负有给付义务，应给予合理的短期付款时间，不应急于令其应诉；裁判官应依公平原则确定该期间。

<!-- source-p 354 -->
<a id="30.71.3"></a>**3.**若某人承认自己确有给付义务，却提出不能履行的正当理由，应当听取其意见。例如，遗赠之物属于他人，而继承人称物主不肯出售或索价过高；又如，继承人称遗赠的是遗产奴隶，但该奴隶是他的父亲、母亲或亲生兄弟。基于此种原因，允许继承人依照法官职权给付该物的估价，是最为公平的。

<!-- source-p 355 -->
<a id="30.71.4"></a>**4.**若某人被遗赠一只杯子，而继承人因认为将杯子与自己分开不公平，愿意给付其估价，却未获裁判官准许。因为对人的处理不同于对其他物品；对于人，应采取我们先前认可的宽厚做法。

<!-- source-p 356 -->
<a id="30.71.5"></a>**5.**若向市镇遗赠一处由市镇缴纳租税的地产，该遗赠是否有效并可请求？尤利安在《学说汇纂》第三十八卷写道：尽管该地产由市镇租用，但遗赠人对其享有某种权利，因此遗赠有效。

<!-- source-p 357 -->
<a id="30.71.6"></a>**6.**若该租税地产不是遗赠给市镇，而是遗赠给他人，则不应认为遗赠了该物的所有权；而是遗赠了我们对租税地产所享有的权利。

<!-- source-p 358 -->
<a id="30.72"></a>**30.72**

<!-- source-p 359 -->
**保罗：《评告示》第四十八卷。**

<!-- source-p 360 -->
若某人遗赠科尔涅利乌斯地产，但排除其死亡时尚存的葡萄园，而他死亡时并无葡萄园，则遗赠的地产不因此减少。

<!-- source-p 361 -->
<a id="30.73"></a>**30.73**

<!-- source-p 362 -->
**盖尤斯：《论遗赠与城市裁判官告示》第三卷。**

<!-- source-p 363 -->
<a id="30.73.pr."></a>**序言。**若继承人受命使卢基乌斯取得一百，继承人就必须给付一百，因为除非把一百交给我，否则无人能使我拥有一百。

<!-- source-p 364 -->
<a id="30.73.1"></a>**1.**我国皇帝以敕答指出，遗赠给村社的财产也可以由村社受领，处理方式与遗赠给城市相同。

<!-- source-p 365 -->
<a id="30.74"></a>**30.74**

<!-- source-p 366 -->
**乌尔比安：《论争》第四卷。**

<!-- source-p 367 -->
皇帝与其父亲的敕答虽指出，原指定继承人留下的遗赠，由替补继承人承受时，应视为符合立遗嘱人的意思；但只有在不存在明显相反意思时才如此。是否存在相反意思，应根据多项情况判断：立遗嘱人是否不愿替补继承人承担原指定继承人所留的遗赠或遗嘱信托。例如，立遗嘱人另行将不同的物品遗嘱信托给替补继承人，或因某种特殊原因只向原指定继承人作出遗赠，而该原因并不适用于替补继承人；又如，替补继承人是某一遗嘱信托的受益人，而立遗嘱人仅对原指定继承人留下该信托。在立遗嘱人的意思不明时，才应适用该敕答。

<!-- source-p 368 -->
<a id="30.75"></a>**30.75**

<!-- source-p 369 -->
**乌尔比安：《论争》第五卷。**

<!-- source-p 370 -->
<a id="30.75.pr."></a>**序言。**若遗赠或遗嘱信托以“继承人认为估价合适”“继承人认可”或“继承人认为公正”为条件，遗赠或遗嘱信托仍应履行；因为立遗嘱人是将此事托付给一名善良之人，而非完全交由继承人任意决定。

<!-- source-p 371 -->
<a id="30.75.1"></a>**1.**若某人遗赠“提提乌斯欠我的债”，而提提乌斯并不欠他任何债务，应知该遗赠无效。若没有写明金额，则显然不欠付任何数额，因为无法确定遗赠了多少。又如，我把自己欠提提乌斯的债遗赠给他，却未写明金额，遗赠同样无效。但若我明确遗赠自己欠提提乌斯的十枚钱币，即使我实际并不欠他钱，既定金额这一错误说明也不使遗赠失效；尤利安在遗赠嫁资的情形中也作出过这样的答复。

<!-- source-p 372 -->
<a id="30.75.2"></a>**2.**但若某人写道：“我遗赠提提乌斯欠我的十枚钱币”，而提提乌斯实际上并不欠钱，遗赠无疑无效；因为错误说明与错误条件或原因大不相同。因此，若我把塞尤斯欠我的十枚钱币遗赠给提提乌斯，遗赠也无效；债务必须确实存在。若我生前已经向债务人追偿，遗赠就会消灭；若债务仍然存在，我的继承人只须向受遗赠人提供针对债务人的诉权。

<!-- source-p 373 -->
<a id="30.75.3"></a>**3.**若某人在要式口约中约定：“斯提库斯或十枚钱币，由我选择其一”，之后又将对方欠他的债予以遗赠，其继承人就须向受遗赠人提供诉权，由受遗赠人选择请求斯提库斯或十枚钱币。

<!-- source-p 374 -->
<a id="30.75.4"></a>**4.**因此，若某人遗赠斯提库斯，而债务人原本对他负有给付斯提库斯或十枚钱币的义务，如尤利安在《学说汇纂》第三十三卷所写，受遗赠人可以对继承人提起不确定之诉，迫使继承人向债务人追偿。若继承人取得斯提库斯，就应将他交给受遗赠人；若取得的是十枚钱币，受遗赠人则不能取得该钱币。由此，受遗赠人是否能取得斯提库斯，取决于债务人的选择。

<!-- source-p 375 -->
<a id="30.76"></a>**30.76**

<!-- source-p 376 -->
**尤利安：《学说汇纂》第三十四卷。**

<!-- source-p 377 -->
若某人约定由他人向自己给付斯提库斯或潘菲鲁斯，却把斯提库斯遗赠给塞姆普罗尼乌斯、把潘菲鲁斯遗赠给梅维乌斯，那么继承人即承担了两项负担：必须向一人提供自己的诉权，向另一人给付斯提库斯或潘菲鲁斯的估价。

<!-- source-p 378 -->
<a id="30.77"></a>**30.77**

<!-- source-p 379 -->
**乌尔比安：《论争》第五卷。**

<!-- source-p 380 -->
若有人将钱款寄存于他人处，并以遗嘱信托嘱托继承人交付该钱款，依神圣庇护皇帝的敕答，遗嘱信托应当履行；因为这应视为继承人受嘱托免除债务人的债务。若继承人起诉债务人，债务人可以提出诈欺抗辩。由此，遗嘱信托便具有实效。因此，任何债务人的债务都可以通过遗嘱信托处理。
