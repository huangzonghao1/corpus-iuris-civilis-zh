# D.30.1 论遗赠与遗嘱信托（第三段：30.41–30.65.1）

<!-- source-p 183 -->
<a id="30.41"></a>**30.41**

<!-- source-p 184 -->
**乌尔比安：《萨宾评注》第二十一卷。**

<!-- source-p 185 -->
<a id="30.41.pr."></a>**序言。**现在，让我们考察除此以外的其他事项。原则上，一切有体物、权利和地役权，均可以遗赠。

<!-- source-p 186 -->
<a id="30.41.1"></a>**1.**但与房屋结合的物件不得遗赠，因为阿维奥拉和潘萨任执政官时，元老院决议规定这些物件不得遗赠。

<!-- source-p 187 -->
<a id="30.41.2"></a>**2.**不过，如果大理石或柱子已从房屋分离，遗赠是否因此有效，仍可讨论。如果遗赠自始未成立，事后也不会因此有效；正如遗嘱订立后，我的物被让与他人，我遗赠给自己的遗赠也不会有效，因为该遗赠自始即不具效力。但如果遗赠附有条件，那么在条件成就时，只要该物不属于我，或者未与房屋结合，遗赠便可能有效；这是按照那些认为，可以附条件买入自己的物、向自己承诺给付该物，或将该物遗赠给自己的法学家所作的理解。因此，卡托规则会阻却无条件遗赠，却不阻却附条件遗赠，因为卡托规则不适用于附条件事项。

<!-- source-p 188 -->
<a id="30.41.3"></a>**3.**同样可以讨论：某人有两处房屋，将其中一处遗赠，并将另一处房屋上与被遗赠房屋相连的某物遗赠给受遗赠人，这项遗赠是否有效。问题在于，元老院决议和皇帝敕令允许我们从自己的房屋拆下物件，移至他人的房屋，供该房屋未来的所有人使用；但该未来所有人不得转售这些物件。我们的皇帝与神圣塞维鲁皇帝也曾以敕答作此规定。那么，是否也可以将该物遗赠给另一处房屋的受遗赠人？应当否定，因为受遗赠人不会成为该房屋的占有人。

<!-- source-p 189 -->
<a id="30.41.4"></a>**4.**如果某人将塞姆普罗尼乌斯家的房屋遗赠给两人，并将该房屋中的大理石遗赠给其中一人，用以建造他遗赠给此人的塞伊乌斯家的房屋，那么可以适当地讨论此遗赠是否有效，因为受遗赠人是两处房屋的所有人。又如某人将房屋遗赠，但先拆下大理石；这些大理石原是立遗嘱人打算留给继承人、供其建造自己保留在遗产中的房屋使用的，该如何处理？不过，更妥当的说法是，在这两种情形中，拆除均不发生效力；但遗赠仍然有效，继承人应支付这些物件的估价。

<!-- source-p 190 -->
<a id="30.41.5"></a>**5.**但如果某人遗赠物件供公共工程使用，我认为遗赠有效。帕比尼安在《答复集》第十一卷中也记载，我们的皇帝与神圣塞维鲁皇帝曾规定：向公共团体承诺提供物件以用于工程的人，可以从其城内或乡间房屋拆下物件，将其用于该工程，因为他们持有这些物件并非为了交易。那么，是否只能遗赠给该物所在地域的城市，还是也可以将物件从一座城市移往另一座城市？我认为不应允许后一种情形，尽管已有规定，允许某人将自己房屋中的物件移至另一城市的房屋中。

<!-- source-p 191 -->
<a id="30.41.6"></a>**6.**这项元老院决议不仅适用于罗马城，也适用于其他城市。

<!-- source-p 192 -->
<a id="30.41.7"></a>**7.**此外，神圣皇帝兄弟曾就普罗克利安努斯与埃皮廷卡努斯的请愿作出敕答：二人因负有公共债务，请求准许其出售相关物件；皇帝拒绝承认他们享有出售该物件的权利。

<!-- source-p 193 -->
<a id="30.41.8"></a>**8.**这项元老院决议不仅适用于房屋，也适用于浴场或其他建筑物、独立于房屋的柱廊，以及商铺或酒馆。

<!-- source-p 194 -->
<a id="30.41.9"></a>**9.**同样，禁止遗赠这样的物件：其给付只能通过从房屋上拆卸、取下方能实现，例如大理石或柱子。元老院对瓦片、梁木和门也作了同样规定；对于嵌在墙内的书架，亦然。

<!-- source-p 195 -->
<a id="30.41.10"></a>**10.**但是，栏栅或帷幕可以遗赠；管道或蓄水池则不能遗赠。

<!-- source-p 196 -->
<a id="30.41.11"></a>**11.**然而，自动装置，或使水喷涌的喷泉器具，可以遗赠，尤其是可拆卸安装的器具。

<!-- source-p 197 -->
<a id="30.41.12"></a>**12.**雕像应如何处理？如果雕像嵌在墙内，就不得遗赠；如果雕像另行存在，则可能产生疑问。不过，应更充分地理解元老院的意思：如果某些物件永久设置于房屋之中，作为房屋的一部分，就不得将其拆下出售。

<!-- source-p 198 -->
<a id="30.41.13"></a>**13.**因此，应当说，固定在墙上或与墙相连的画板，以及镶嵌其中的单个小雕像，也不得遗赠。

<!-- source-p 199 -->
<a id="30.41.14"></a>**14.**但如果立遗嘱人购置某些物件，原本打算将其移至另一房屋，却又将其遗赠，遗赠是否有效仍可讨论；我认为有效。

<!-- source-p 200 -->
<a id="30.41.15"></a>**15.**但是，如果立遗嘱人将所遗赠的物件与房屋结合，遗赠即告消灭。

<!-- source-p 201 -->
<a id="30.41.16"></a>**16.**但如果是继承人将这些物件与房屋结合，我认为遗赠不因此消灭，

<a id="30.43"></a>**30.43**

<!-- source-p 206 -->
**乌尔比安：《萨宾评注》第二十一卷。**

<!-- source-p 207 -->
<a id="30.43.pr."></a>**序言。**元老院允许遗赠并非房屋组成部分的物件；而这些物件在立遗嘱人死亡时已不属于房屋组成部分。因此，继承人应支付其估价。但如果继承人将物件拆下以便交付，就应适用处罚；即使他拆下物件并非为了出售，而是为了履行给付，也仍然如此。

<!-- source-p 208 -->
<a id="30.43.1"></a>**1.**马尔凯鲁斯还写道：如果丈夫在作为嫁资取得的妻子园地内建造起居室，他可以拆下将供自己使用的物件，但不得使妻子遭受损失；这项元老院决议也不妨碍他这样做。因此，如果拆除不会妨碍他拆下这些物件，就应当说，他可以遗赠那些自己能够拆下的物件。

<!-- source-p 209 -->
<a id="30.43.2"></a>**2.**遗赠可以取决于他人的意思，却不能取决于继承人的意思。

<!-- source-p 210 -->
<a id="30.43.3"></a>**3.**从敌人手中赎回的人，可以将自己遗赠给赎回他的人；该遗赠有助于解除赎回人对其享有的质权负担。

<!-- source-p 211 -->
<a id="30.44"></a>**30.44**

<!-- source-p 212 -->
**乌尔比安：《萨宾评注》第二十二卷。**

<!-- source-p 213 -->
<a id="30.44.pr."></a>**序言。**父亲可以遗赠其子军营特有产中的奴隶。如果儿子在父亲生前死亡，而该特有产仍留在父亲手中，那么遗赠成立；因为儿子未行使自己的权利时，应追溯认定父亲曾对特有产中的奴隶享有所有权。

<!-- source-p 214 -->
<a id="30.44.1"></a>**1.**某人尚不知道一物已遗赠给自己，却又将该物遗赠；此后他得知此事，并希望该物归自己所有，那么该遗赠有效。因为受遗赠人未拒绝遗赠时，该物应视为自继承被接受时起即属于他；但如果他拒绝了遗赠，则该物应追溯视为属于继承人。

<!-- source-p 215 -->
<a id="30.44.2"></a>**2.**如果某人遗赠了杯具，而杯具后来熔成金属块，或者反过来由金属块制成杯具；又如遗赠羊毛，而羊毛后来被制成衣物，尤利安在《学说汇纂》第三十二卷中写道，在上述所有情形中，遗赠仍然成立，应给付现存之物。我认为这一见解正确，但以立遗嘱人未改变其意思为限。

<!-- source-p 216 -->
<a id="30.44.3"></a>**3.**如果某人遗赠一只盘子，后来将其制成金属块，再将其制成杯子，只要其意思仍然持续，就应给付杯子。

<!-- source-p 217 -->
<a id="30.44.4"></a>**4.**如果房屋建在已遗赠的土地上，受遗赠人应取得该房屋，除非立遗嘱人改变了意思。

<!-- source-p 218 -->
<a id="30.44.5"></a>**5.**遗赠债务文书的人，遗赠的是债权而非仅仅文书本身；这一点可以从买卖中得到证明：因为债务文书出售时，通常被认为债权本身也已出售。

<!-- source-p 219 -->
<a id="30.44.6"></a>**6.**但如果遗赠的是债权，也应从宽解释为包括所欠债务；因此，应将对债务人的诉权让与受遗赠人。

<!-- source-p 220 -->
<a id="30.44.7"></a>**7.**如果同一奴隶既被遗赠，又被命令获得自由，有时可能仅遗赠发生效力。例如，自由是为诈害债权人而授予的；如果该奴隶是被永久出售的奴隶，结论也相同；若该奴隶已被出质，亦然。

<!-- source-p 221 -->
<a id="30.44.8"></a>**8.**如果继承人将附条件解放奴隶遗赠，继承人最好交付该附条件解放奴隶本身，而不是支付其估价。因为他应支付真实估价；但如果交付该人，条件成就时他不会遭受任何损失：此后不能再向他请求一名自由人的估价。

<!-- source-p 222 -->
<a id="30.44.9"></a>**9.**如果立遗嘱人拥有两处地产，将一处地产的用益权遗赠给我，将另一处地产遗赠给提图斯，那么遗嘱继承人无须向我提供通道；但继承人必须购买通道并予以提供。

<a id="30.45"></a>**30.45**

<!-- source-p 224 -->
**庞波尼乌斯：《萨宾评注》第六卷。**

<!-- source-p 225 -->
<a id="30.45.pr."></a>**序言。**如果我将未成年人的替补继承人所有的女奴遗赠给你，而你从该未成年人处买下这些女奴，在得知她们已遗赠给你之前又将其转让，涅拉提乌斯、阿里斯托和奥菲利乌斯均认可，该遗赠仍然有效。

<!-- source-p 226 -->
<a id="30.45.1"></a>**1.**继承人被概括地判令交付某物时，无须承诺交付健康的奴隶，但应承诺该奴隶不负有因盗窃或私犯而产生的责任；因为继承人应以受遗赠人能够占有该奴隶的方式交付。奴隶的健康状况与其所有权无关；但由于奴隶实施盗窃或造成私犯，所有人便可能无法占有该奴隶，正如土地负有债务时，所有人也可能无法占有该土地一样。

<!-- source-p 227 -->
<a id="30.45.2"></a>**2.**但如果遗赠的是特定的人，交付时应当保持其现状。

<a id="30.47"></a>**30.47**

<!-- source-p 232 -->
**乌尔比安：《萨宾评注》第二十二卷。**

<!-- source-p 233 -->
<a id="30.47.pr."></a>**序言。**遗赠特定物时，如果该物属于立遗嘱人且继承人能够取得该物，继承人不得迟延，应当交付。如果该物位于请求交付地点之外，通常应在其遗赠时所在之处交付，除非立遗嘱人希望在其他地点交付；如果立遗嘱人另有指定，就应在其指定地点交付，或者在可以推知立遗嘱人希望交付的地点交付。尤利安对于遗赠自有物和他人之物均作此论述。但如果遗赠物原在一处，却被继承人恶意转移至别处，那么除非在受请求之处交付，继承人将因其欺诈行为被判承担责任；若继承人并无恶意，则应在其转移物件之处交付。

<!-- source-p 234 -->
<a id="30.47.1"></a>**1.**但如果遗赠的是以重量、数量或计量确定的物品：若遗赠的是特定物，例如指定谷仓中的谷物或指定酒窖中的葡萄酒，就应在遗赠时所在之处交付，除非立遗嘱人另有意思；若未指定特定种类，则应在受请求之处交付。

<!-- source-p 235 -->
<a id="30.47.2"></a>**2.**因此，如果遗赠了斯提库斯，而他因继承人的过失未能交付，继承人应支付其估价；但如果继承人并无过失，就应为奴隶的返还提供担保，而无须支付估价。即使他人所有的奴隶在继承人无过失的情况下逃亡，也可以作同样处理；因为对他人之物也可能成立过失。继承人应如此提供担保：如果该奴隶被捕获，就交付奴隶本人或支付其估价。对于被敌人俘获的奴隶，也确定适用这一规则。

<!-- source-p 236 -->
<a id="30.47.3"></a>**3.**但如果遗赠的是斯提库斯或潘菲卢斯，而其中一人逃亡或被敌人俘获，应当交付仍在场的那一人，或者支付不在场者的估价。只有在不会使受遗赠人遭受迟延时，才应将选择权交给继承人。因此，已经决定：即使其中一人死亡，也必须交付另一人；或许还应支付死者的估价。但如果两人都在逃亡，担保内容不应是“如果二人都回到继承人的权力之下”，而应是“如果其中任何一人回到权力之下”，并且“应交付该人本人或支付不在场者的估价”。

<!-- source-p 237 -->
<a id="30.47.4"></a>**4.**同样，如果他人所有之物或遗产中的物件在继承人无过失的情况下灭失或无法找到，继承人只须提供担保；但如果物件因继承人的过失灭失，应立即判令继承人承担责任。

<!-- source-p 238 -->
<a id="30.47.5"></a>**5.**我们来考察过失应如何认定：是否不仅包括接近欺诈的过失，也包括轻微过失？或者是否还应要求继承人尽到注意义务？后一种看法更为正确。

<!-- source-p 239 -->
<a id="30.47.6"></a>**6.**同样，如果土地因地陷而灭失，拉贝奥说无须支付估价。如果这不是在迟延之后发生，这一说法当然正确；因为受遗赠人本可以在接受土地后将其出售。

<!-- source-p 244 -->
<a id="30.49"></a>**30.49**

<!-- source-p 245 -->
**乌尔比安：《萨宾评注》第二十三卷。**

<!-- source-p 246 -->
<a id="30.49.pr."></a>**序言。**如果遗赠规定某人在年满十四岁时取得遗赠，我们适用一项确定规则：他到实际年满十四岁时，才算年满十四岁。马尔凯鲁斯写道，皇帝也曾如此裁决。

<!-- source-p 247 -->
<a id="30.49.1"></a>**1.**因此，如果遗赠如此写道：“他年满十四岁时，分一年、两年、三年给付”，而受遗赠人在立遗嘱人死亡时已十七岁，那么遗赠即应立即给付。如果他十五岁，应当说两年后给付；如果十六岁，则一年后给付；如果距离十七岁尚差若干个月，就应在剩余月份届满后给付。以上适用于立遗嘱人误以为受遗赠人尚未满十四岁、而实际上他已超过该年龄的情形。但如果立遗嘱人知道其年龄，则应自遗嘱订立之日起计算三年，届时履行遗赠。

<!-- source-p 248 -->
<a id="30.49.2"></a>**2.**这项遗赠既附有条件，又附有期限：在年满十四岁这一条件成就之前，它是附条件的；此后则为附期限的遗赠。

<!-- source-p 249 -->
<a id="30.49.3"></a>**3.**因此，如果受遗赠人在年满十四岁之前死亡，遗赠不移转给其继承人；年满十四岁之后死亡的，遗赠则移转给其继承人。如果立遗嘱人在订立遗嘱时，儿子尚未满十四岁，我认为，一年、两年、三年给付的期限应立即自儿子年满十四岁时起算，除非有明确证据证明立遗嘱人另有意思。

<!-- source-p 250 -->
<a id="30.49.4"></a>**4.**如果我遗赠给提图斯十个我所欠的银币，并嘱托他将同一笔钱交给我的债权人，那么对债权人设立的遗嘱信托无效，因为此事与债权人无关。但继承人可以对受遗赠人提起诉讼，因为继承人有利害关系，必须向债权人清偿，以免债权人起诉自己。因此，该遗赠仍然有效。

<!-- source-p 251 -->
<a id="30.49.5"></a>**5.**但如果立遗嘱人欠我十个银币，并由保证人提供担保，那么遗嘱信托请求权不仅属于继承人，也属于保证人；因为保证人有利害关系，希望立遗嘱人向我清偿，否则保证人可能被起诉，并提起委任诉讼。保证人是否有清偿能力，并不影响这一点。

<!-- source-p 252 -->
<a id="30.49.6"></a>**6.**尤利安在《学说汇纂》第三十九卷中写道：如果保证人将自己对债权人所负的债务遗赠给债权人，该遗赠是否有效？他认为，债权人并无利害关系，但债务人可以依据遗嘱提起诉讼；因为债务人有利害关系，欲获得免责，毕竟保证人的继承人不能再起诉他。

<!-- source-p 253 -->
<a id="30.49.7"></a>**7.**但如果同一保证人将某物遗赠给提图斯，并委托提图斯向债权人清偿，那么债务人和保证人的继承人均可基于遗嘱信托向提图斯起诉，因为受遗赠人履行给付与双方均有利害关系。

<!-- source-p 254 -->
<a id="30.49.8"></a>**8.**还应记住：某人仅被判令“出售土地”时，并非被判令无偿出售，而只是被判令以真实价格出售。

<!-- source-p 255 -->
<a id="30.49.9"></a>**9.**但如果某人被判令以特定价格出售，就必须按判令所定价格出售。

<!-- source-p 256 -->
<a id="30.50"></a>**30.50**

<!-- source-p 257 -->
**乌尔比安：《萨宾评注》第二十四卷。**

<!-- source-p 258 -->
<a id="30.50.pr."></a>**序言。**如果奴隶由数人共有，他将按各共有人所有权份额取得留给他的遗赠。

<!-- source-p 259 -->
<a id="30.50.1"></a>**1.**如果遗产诉讼的法官在继承人未答辩或以虚假方式答辩时作出对其不利的判决，该判决不损害受遗赠人。那么，如果判决虽属不公，却未提起上诉，又应如何？正如萨宾努斯所指出，对继承人的不公不会损害受遗赠人。但如果判决支持替补继承人，我们还须考察该替补继承人是否对受遗赠人负有责任。既然这项判决对替补继承人本人产生法律效力，他是否也应对受遗赠人负责？毕竟，他不能如此恶劣地主张，法院因偏袒而作出有利于他的判决。因此，他也应像对债权人那样，对受遗赠人承担责任。

<!-- source-p 260 -->
<a id="30.50.2"></a>**2.**如果某人在对家属进行审讯之前便接受遗产，或者未为立遗嘱人被杀一事作辩护，受遗赠人可以向国库请求给付。但如果国库拒绝承认该项遗产呢？遗赠负担就不得不回落到继承人身上。但如果继承人安排告发者对自己提出指控，以便遗产被判归国库而使自己免于负担；或者没有充分为案件辩护，他就不能援引曾以串通方式进行遗产诉讼者的例子而免除责任。

<!-- source-p 261 -->
<a id="30.50.3"></a>**3.**如果遗赠仅写明钱币的数额，却未说明是哪一种钱币，首先应查明家父本人的习惯，其次查明他所居住地域的习惯；还应考察家父的意思、受遗赠人的身份、亲近程度与关系，以及文书中前后所列的金额。

<!-- source-p 262 -->
<a id="30.51"></a>**30.51**

<!-- source-p 263 -->
**帕比尼安：《疑义集》第四卷。**

<!-- source-p 264 -->
但如果遗赠的是特定钱币，例如某人在钱箱中存放的那些钱币，或特定的一只盘子，那么遗赠的不是尚未交付的钱款，而是钱币或该物本身；其不允许以其他物替代，应当像任何特定物一样估价。

<a id="30.52"></a>**30.52**

<!-- source-p 266 -->
**保罗：《萨宾评注》第四卷。**

<!-- source-p 267 -->
<a id="30.52.pr."></a>**序言。**如果某人遗赠给受遗赠人全部奴隶及其特有产，那么即使某些奴隶没有特有产，也应当交付这些奴隶。

<!-- source-p 268 -->
<a id="30.52.1"></a>**1.**如果未成年儿子附条件作出遗赠，且儿子成为继承人后死亡，那么可以说：父亲附条件地从儿子处作出遗赠，随后又由替补继承人作出无条件的遗赠，表明父亲意在儿子在条件成就前死亡时，立即由替补继承人给付遗赠。

<!-- source-p 269 -->
<a id="30.53"></a>**30.53**

<!-- source-p 270 -->
**乌尔比安：《萨宾评注》第二十五卷。**

<!-- source-p 271 -->
<a id="30.53.pr."></a>**序言。**那么，如果立遗嘱人从替补继承人处留下了更多的数额，该如何处理？超出原先数额的部分，就是从替补继承人处所留的遗赠；与先前遗嘱文书记载的数额相同的部分，则应依该先前文书给付。

<!-- source-p 272 -->
<a id="30.53.1"></a>**1.**但如果遗赠是与他人共同留下的，例如立遗嘱人将一处土地遗赠给我，却又在未成年儿子的继承人处重新遗赠给我和塞伊乌斯，那么这一重新遗赠会使我取得相应份额。

<!-- source-p 273 -->
<a id="30.53.2"></a>**2.**如果某人指定两名继承人，并命令每一人均向受遗赠人给付全部特定物，其效力如同在两份遗嘱中分别作出遗赠。因为，即使同一遗嘱将遗赠给予我及我的儿子或奴隶，两项遗赠也无疑均有效；马尔凯鲁斯在尤利安的著作中也补充了这一点。

<!-- source-p 274 -->
<a id="30.53.3"></a>**3.**如果继承人因被遗赠的奴隶犯罪而杀死该奴隶，也就是杀死一个罪有应得之人，那么无疑应当说，继承人不依据遗嘱承担责任。

<!-- source-p 275 -->
<a id="30.53.4"></a>**4.**但如果继承人以奴隶承担诺克萨责任，他是否仍负责任，因为他可以将奴隶赎回？我认为应负责任。

<!-- source-p 276 -->
<a id="30.53.5"></a>**5.**如果继承人杀死被遗赠的动物，我认为他应负责任；他无须交付尸体或其他残余物，而应支付该动物活着时的价款。〔底本文字疑误：*leiqana*；据上下文暂解为 *reliqua*。〕

<!-- source-p 277 -->
<a id="30.53.6"></a>**6.**同样，如果继承人容许他人因担心未来损害而占有被遗赠的房屋，我认为他应负责任；因为他本应提供承诺。

<!-- source-p 278 -->
<a id="30.53.7"></a>**7.**但如果继承人将死者埋入被遗赠的土地，使该处成为宗教场所：如果埋葬的是立遗嘱人本人，而且他无法在他处埋葬，或在那里埋葬并不便利，继承人不依据遗嘱承担责任。那么，继承人是否仍须支付该处土地的价款？如果是立遗嘱人本人希望埋葬于此，继承人不依据遗嘱承担责任；但如果继承人自行决定将死者埋在那里，只要遗产中有可用于支付价款的财产，他就应当支付。因为立遗嘱人遗赠该土地，原本是希望死者埋葬于他处，或者希望向受遗赠人提供该土地的价款。

<!-- source-p 279 -->
<a id="30.53.8"></a>**8.**同样，如果继承人没有亲自杀死奴隶，却迫使他实施不法行为，导致他被他人杀死或处以刑罚，那么由继承人支付价款最为公平；但如果奴隶出于自己的恶意而实施该行为，就不应估价给付。

<!-- source-p 280 -->
<a id="30.53.9"></a>**9.**被遗赠的奴隶若非因继承人的欺诈而被敌人俘获，无须交付；若因继承人的欺诈而被俘获，则应当交付。

**庞波尼乌斯：《萨宾评注》第八卷。**

<a id="30.54.pr."></a>**序言。**为了羞辱或指摘受遗赠人而写下的可耻遗赠，因厌恶立遗嘱人而视为未曾书写。

<!-- source-p 284 -->

<!-- source-p 285 -->
<a id="30.54.2"></a>**2.**但如果某项遗赠以你解放某奴隶为条件而留给你，而奴隶之死阻止了其获释，那么该遗赠仍应给付给你，因为未能使他获得自由并非你的过错。

<!-- source-p 286 -->
<a id="30.54.3"></a>**3.**如果遗赠中只列出部分继承人，继承人应按人数平均承担份额；如果列出全部继承人，则按各自的继承份额承担。

<a id="30.65.1"></a>**1.**“如果他愿意，我将斯提库斯遗赠给他”：这是一项附条件遗赠；只有受遗赠人愿意时，该遗赠才移转给他的继承人。通常，未附加“如果他愿意”这一语句的遗赠会移转给受遗赠人的继承人。因为法律默示包含某事，与以言辞明确表达某事，并不相同。
