# D.30.1 论遗赠与遗嘱信托（第五段：30.91–30.108）

<!-- source-p 454 -->
<a id="30.91"></a>**30.91**

<!-- source-p 455 -->
**尤利安：《学说汇纂》第三十六卷。**

<!-- source-p 456 -->
<a id="30.91.pr."></a>**序言。**有人问：如果一名家子被指定为继承人，而他本人和其儿子都处于他人父权之下，能否由该儿子作出遗赠？我答复说，既然儿子可以将遗赠留给父亲，同理也可以留给自己的兄弟、儿子，甚至父亲的奴隶。

<!-- source-p 457 -->
<a id="30.91.1"></a>**1.**如果立遗嘱人给予奴隶即时自由，可以纯粹地或附条件地向该奴隶遗赠；但如果自由权附有条件，有时纯粹遗赠有效，有时则无效。例如，自由条件若可以在家父死亡后、遗产被接受前立即成就，例如“斯提库斯若给提提乌斯十枚金币〔或若登上卡皮托利山〕，即获自由”，那么纯粹遗赠有效。相反，如果条件是“若他给继承人十枚金币”或“若他在遗产被接受后登上卡皮托利山”，就会使遗赠无效。不过，如果某人被指定为全部遗产的唯一继承人，即使所附条件可以在遗产被接受前履行，也会使纯粹遗赠无效。

<!-- source-p 458 -->
<a id="30.91.2"></a>**2.**立有两名继承人时，立遗嘱人将斯提库斯遗赠给其中一人，又将十枚金币遗赠给斯提库斯本人。斯提库斯在立遗嘱人生前获得自由后，他应取得全部遗赠。遗赠原因在他本人身上已经全部确定；这一点也可由下述情况证明：即使被遗赠人所属的继承人没有接受遗产，他仍可以向另一名继承人请求全部遗赠。

<!-- source-p 459 -->
<a id="30.91.3"></a>**3.**有人把遗赠给予一名被遗赠的奴隶；如果立遗嘱人后来将该奴隶让与他人，该遗赠便归买受人取得。

<!-- source-p 460 -->
<a id="30.91.4"></a>**4.**如果奴隶被遗赠给提提乌斯，同时又有某物遗赠给该奴隶，可以通过遗嘱信托要求提提乌斯将奴隶交还他人，或者把遗赠给奴隶的物品交给奴隶；此外，还可以通过遗嘱信托要求提提乌斯将某物交给该奴隶本人，待奴隶获得自由后由其取得。

<!-- source-p 461 -->
<a id="30.91.5"></a>**5.**如果某人先遗赠斯提库斯，后来又将他让与他人或释放他，随后再以遗嘱补编将遗赠给同一人，该遗赠应交付给被释放的斯提库斯或买受人。

<!-- source-p 462 -->
<a id="30.91.6"></a>**6.**如果你作为继承人将奴隶遗赠给我，而另有人又将某物遗赠给该奴隶；在把奴隶遗赠给我的立遗嘱人仍在世时，给予奴隶的遗赠请求权期限已经届至，那么该项遗赠立即归入遗产。因此，即使后来把奴隶遗赠给我的立遗嘱人死亡，遗赠给奴隶的物品也不归我取得。

<!-- source-p 463 -->
<a id="30.91.7"></a>**7.**有人依据遗嘱请求交付某人时，应向请求人交付其在诉讼系属时的状态；正如女奴所生子女以及土地在此期间收取的孳息都应计入该诉讼，奴隶在此期间以遗赠或继承名义取得的任何财物，也必须交付给请求人。

<!-- source-p 464 -->
<a id="30.92"></a>**30.92**

<!-- source-p 465 -->
**尤利安：《学说汇纂》第三十九卷。**

<!-- source-p 466 -->
<a id="30.92.pr."></a>**序言。**如果某一继承人因遗产债务，依该土地的收益估价买下通过遗嘱信托留给他人的土地，而遗嘱信托受领人在场并参与估价，那么通说认为，应返还土地的价款，而非土地本身。马尔凯卢斯注：如果继承人更愿意返还土地，我认为应准许他这样做。

<!-- source-p 467 -->
<a id="30.92.1"></a>**1.**尤利安说：如果遗赠给提提乌斯一笔钱，并托付其诚信释放他人的奴隶，而奴隶所有人不愿出售该奴隶，提提乌斯仍可取得遗赠，因为未能履行遗嘱信托并非他的过错；即使该奴隶已经死亡，也不会使他丧失遗赠。

<!-- source-p 468 -->
<a id="30.92.2"></a>**2.**正如任何人都可以向将依法继承其遗产或取得遗产占有的人设立遗嘱信托，也可以正当地向将依法继承未成年儿子遗产或取得其遗产占有的人设立遗嘱信托。

<!-- source-p 469 -->
<a id="30.93"></a>**30.93**

<!-- source-p 470 -->
**乌尔比安：《遗嘱信托论》第一卷。**

<!-- source-p 471 -->
遗嘱信托仅在未成年人未达成年年龄便死亡时有效；如果他成年后死亡，遗嘱信托即告失效。

<!-- source-p 472 -->
<a id="30.94"></a>**30.94**

<!-- source-p 473 -->
**尤利安：《学说汇纂》第三十九卷。**

<!-- source-p 474 -->
<a id="30.94.pr."></a>**序言。**但是，如果父亲剥夺未成年儿子的继承资格，法定继承人无须履行遗嘱信托；除非该法定继承人同时也是父亲的继承人。

<!-- source-p 475 -->
<a id="30.94.1"></a>**1.**某人被嘱托返还一项遗产，而该遗产中有一名奴隶被指定为继承人；此人后来把奴隶卖给了他人。有人问，因买受该奴隶而取得遗产的人，是否也必须返还遗产。我认为，出售自己所有、且被指定为继承人的奴隶的人应被迫履行遗嘱信托，因为他已经取得了被嘱托返还的遗产价款。至于因买受该奴隶而取得遗产的人，只有在原奴隶所有人无清偿能力时，才应基于具体事由被迫履行遗嘱信托。

<!-- source-p 476 -->
<a id="30.94.2"></a>**2.**如果遗赠人把选择权交给受遗赠人，使其在斯提库斯和达马之间择一取得，并嘱托受遗赠人将斯提库斯交给他人，那么即使受遗赠人选择请求达马，仍须基于遗嘱信托交付斯提库斯。如果达马价值较高，他应被迫买下斯提库斯；如果达马价值较低，他同样应当正当地交付斯提库斯，因为正是他导致自己无法依遗嘱取得遗嘱信托所要求的物品。

<!-- source-p 477 -->
<a id="30.94.3"></a>**3.**依遗嘱获得释放、但未取得遗赠或遗产的人，不得被迫履行遗嘱信托；受嘱托释放遗赠奴隶的人也同样如此。只有依遗嘱取得同类或类似利益的人，才应被迫基于遗嘱信托给付金钱。

<!-- source-p 478 -->
<a id="30.95"></a>**30.95**

<!-- source-p 479 -->
**乌尔比安：《遗嘱信托论》第一卷。**

<!-- source-p 480 -->
但还应考察，如果立遗嘱人以劳务作为对价要求某人实施某事，该遗嘱信托是否有效。绝不可如此认为，因为这类劳务既不得强加给获释人，也不得强制其履行，即使立遗嘱人曾作出这样的安排。

<!-- source-p 481 -->
<a id="30.96"></a>**30.96**

<!-- source-p 482 -->
**尤利安：《学说汇纂》第三十九卷。**

<!-- source-p 483 -->
<a id="30.96.pr."></a>**序言。**某人在遗嘱或遗嘱补编中这样立下遗赠：“我希望将四百枚金币交给潘菲拉，按下列方式筹给她：由管家尤利乌斯给付若干枚，我在军营中所有的若干枚，以及我持有现款中的若干枚。”许多年后，他在意思未变的情况下死亡，但上述各笔款项都已转作他用。我问，潘菲拉是否仍有权请求遗嘱信托。答复是：更可能的是，家父只是向继承人说明，可以从何处筹集四百枚金币，而不损害家产；他并非意在为原本无条件给付的遗嘱信托附加条件。因此，应向潘菲拉给付四百枚金币。

<!-- source-p 484 -->
<a id="30.96.1"></a>**1.**根据《尤利亚法》，无人继承的财产归入国库时，仍应履行遗赠和遗嘱信托，正如原本应由被继承人指定的继承人履行一样。

<!-- source-p 485 -->
<a id="30.96.2"></a>**2.**如果奴隶被遗赠给你，并要求你向提提乌斯给付某物，但数额以该奴隶的价值为限，之后奴隶死亡，你便不必以遗嘱信托名义给付任何财物。

<!-- source-p 486 -->
<a id="30.96.3"></a>**3.**如果按份额被指定为继承人的人受嘱托预先取出一笔钱，再分给遗嘱中列明的受遗赠人，那么附条件遗赠的款项只有在条件成就时才能预先取出；在此之前，应由该继承人或受遗赠人提供担保。

<!-- source-p 487 -->
<a id="30.96.4"></a>**4.**如果某人命令附条件获释的奴隶向某人交付一笔钱，也可以通过遗嘱信托要求受领人将同一笔钱交还他人。立遗嘱人既然可以通过遗嘱补编无条件给予自由、从而消灭自由条件，为什么不能也通过遗嘱信托保留收回同一笔钱的权利呢？

<!-- source-p 488 -->
<a id="30.97"></a>**30.97**

<!-- source-p 489 -->
**尤利安：《学说汇纂》第四十二卷。**

<!-- source-p 490 -->
如果斯提库斯被遗赠给我，并托付我的诚信，要求我将斯提库斯或我自己的奴隶潘菲卢斯交还他人，而我因《法尔基迪亚法》从斯提库斯的遗赠中少得一部分，那么我必须将我自己的奴隶潘菲卢斯全部交给提提乌斯，或者交付我以遗赠名义取得的斯提库斯份额。

<!-- source-p 491 -->
<a id="30.98"></a>**30.98**

<!-- source-p 492 -->
**尤利安：《学说汇纂》第五十二卷。**

<!-- source-p 493 -->

<!-- source-p 495 -->

<!-- source-p 496 -->

<!-- source-p 502 -->

<a id="30.101.1"></a>**1.**如果遗赠给某个处于敌人控制下的人，而他在敌境死亡，该遗赠无效，尽管他本来可以通过复归权使该遗赠得到确认。

<a id="30.104"></a>**30.104**

<!-- source-p 511 -->
**尤利安：《致乌尔塞乌斯·费罗克斯》第一卷。**

<!-- source-p 512 -->
<a id="30.104.pr."></a>**序言。**遗嘱规定由全体继承人承担遗赠，文字如下：“凡成为我继承人的人，均须向提提乌斯给付一百枚金币。”但遗嘱随后又载明，其中一名继承人不应向提提乌斯给付。于是有人问：其余继承人应否给付全部一百枚金币，还是应扣除该名继承人的继承份额？尤利安答复说，较妥当的解释是其余继承人仍应给付全部一百枚金币，因为文字的含义并不妨碍这一解释，且也符合立遗嘱人的意思。

<!-- source-p 513 -->
<a id="30.104.1"></a>**1.**遗嘱写道：“若卢基乌斯·提提乌斯将我曾向他承诺金钱的文书交给我的继承人，则给付一百枚金币。”此后，提提乌斯在将文书交还继承人之前死亡。有人问，其继承人能否请求该遗赠。卡西乌斯答复说，如果那些文书确实存在，则不能请求，因为文书尚未交还，遗赠请求权尚未到期。尤利安补充指出：如果立遗嘱时并不存在那些文书，则可以基于一个理由认为该遗赠应给付提提乌斯，即该条件应视为未记载。〔底本作 *adunatos condicio*，疑有讹误；此处暂依上下文译作“该条件视为未记载”，待核校勘本。〕

<!-- source-p 514 -->
<a id="30.104.2"></a>**2.**萨比努斯说，即使是敌人所有之物，也可以作为遗赠，只要在某种情况下能够买得。

<!-- source-p 515 -->
<a id="30.104.3"></a>**3.**如果遗赠给阿提乌斯的条款是：“凡成为我继承人的人，均须向继承人阿提乌斯给付十枚金币”，阿提乌斯在扣除自己所占份额后，可以请求给付这十枚金币。

<!-- source-p 516 -->
<a id="30.104.4"></a>**4.**同样，如果继承人受命给付十枚金币并为自己保有土地，他应扣除自己所占份额后给付十枚金币。

<!-- source-p 517 -->
<a id="30.104.5"></a>**5.**最后，若遗赠条款是：“凡成为我继承人的人，均须向我的继承人给付十枚金币”，则已确定，各继承人的份额因此而相互均衡，因为每一人都被视为受命向自己及其共同继承人给付。

<!-- source-p 518 -->
<a id="30.104.6"></a>**6.**某人指定一人为继承人，条件是其母死亡；随后又指定第二继承人，并由第二继承人向第一名受条件指定的继承人留下遗赠。第一继承人在其母仍在世时死亡；遗赠请求权期限届至后，有人问该遗赠是否应给付给他的继承人。较妥当的意见是，遗赠应给付给该继承人的继承人：无论替补继承人是无条件地向第一继承人留下遗赠，还是附有“若其未成为继承人”的条件，均如此，因为第一继承人死亡时，该条件即告成就。

<!-- source-p 519 -->
<a id="30.104.7"></a>**7.**萨比努斯答复说，若女婿被指定为继承人，并将遗产的一部分遗赠给他人，女婿应在扣除嫁资后给付该遗赠的遗产份额；这正如若女婿因借贷而欠岳父金钱，他也会先扣除该项债务，再给付遗产份额。

<a id="30.107.pr."></a>**序言。**如果遗赠由数名继承人承担，而其中一人受命先取该遗赠并予以给付，阿非利卡努斯说，受遗赠人应有权选择：向各继承人分别请求，或向受命先取遗赠的人请求。因此，受命先取的人应提供担保，使共同继承人免受损失。

<a id="30.107.1"></a>**1.**如果某人把一名未获自由的奴隶遗赠给他人，同时规定在该奴隶死亡时再作遗赠，则无疑该遗赠有效；因为奴隶死亡时，遗赠给奴隶本人的物品将归于该奴隶所被遗赠给的人。〔此句的条件结构存在解释空间，译文依结果从句所示法律效果处理。〕

<a id="30.108"></a>**30.108**

<!-- source-p 531 -->
**阿非利卡努斯：《问题集》第五卷。**

<a id="30.108.pr."></a>**序言。**如果说遗赠给某人的奴隶在立遗嘱人生前逃走了，就应由受遗赠人承担费用和风险而将其交付；因为继承人应在立遗嘱人留下遗赠物时该物所在之地交付遗赠物。

<!-- source-p 533 -->
<a id="30.108.1"></a>**1.**如果任何第三人把你依据遗嘱应给付我的东西赠与我的奴隶，我依据遗嘱享有的诉权仍然存在；尤其是在我不知道该物已归我所有时。否则就会得出这样的结果：即使是你本人把该物赠与我的奴隶，也会在违背我意愿的情况下使你获得免责；这绝不能接受，因为即使违背我的意愿而作出清偿，你也不会因此免责。

<!-- source-p 534 -->
<a id="30.108.2"></a>**2.**某人将一名奴隶遗赠给提提乌斯，有人问：应由继承人决定交付哪一名奴隶，还是应由受遗赠人决定？我答复说，较妥当的解释是，选择权属于有权决定采用何种诉讼方式的人，也就是受遗赠人。

<!-- source-p 535 -->
<a id="30.108.3"></a>**3.**阿非利卡努斯说，以下遗赠“给那两人中的一人，即先登上卡皮托利山者”有效；显而易见的根据是，向被释奴遗赠用益权，而将所有权有效遗赠给其中生存较久者，这一点已为公认。他认为，指定继承人时也应作同样解释。

<!-- source-p 536 -->
<a id="30.108.4"></a>**4.**我曾向你要约并约定取得斯提库斯，提提乌斯后来以你为继承人，将斯提库斯遗赠给我。如果该项要约并非基于获利原因，则遗赠应属有效；但如果是基于两个原因〔底本作 *sin e duabus*，语句不完整或有讹误〕，则较妥当的意见似为遗赠无效，因为并无任何利益缺失，而且同一物也不可能给付两次。

<!-- source-p 537 -->
<a id="30.108.5"></a>**5.**但是，如果你依据提提乌斯的遗嘱应向我给付斯提库斯，而塞姆普罗尼乌斯又以你为继承人，将同一斯提库斯遗赠给我，并托付我的诚信，由我将其返还给他人，那么该遗赠有效，因为我并不能实际取得该奴隶。若他遗赠给我的不是奴隶而是金钱，法律结论也相同；如果先前的遗嘱中设有遗嘱信托，则更应如此。同样，如果先前遗嘱中的遗赠应受法尔基狄法扣减，我可依据后来的遗嘱取得依该法所扣减的部分。

<!-- source-p 538 -->
<a id="30.108.6"></a>**6.**同样，如果我继承了一个无清偿能力的所有人，而你受命将其土地交给我，你的义务仍然存在；这正如我买下该土地时，你的义务仍会存在一样。

<!-- source-p 539 -->
<a id="30.108.7"></a>**7.**如果遗嘱写道：“超过我已遗赠给提提乌斯的部分，我的继承人应给塞尤斯十枚金币”，则毫无疑问，提提乌斯仍取得其遗赠，而塞尤斯所得不超过十枚金币。通常的遗赠方式也大抵如此，例如：“给卢基乌斯·提提乌斯若干，并在此之外给他的妻子和子女若干。”

<!-- source-p 540 -->
<a id="30.108.8"></a>**8.**如果某人此前未受任何遗赠，而遗嘱在“此外”一语之后又向其遗赠某物，则无疑该项遗赠应予给付。更无疑问的是：若我向一个并不欠我任何东西的人作如下要约：“你是否承诺在欠我的数额之外另给我十枚金币？”则这十枚金币应当给付。

<!-- source-p 541 -->
<a id="30.108.9"></a>**9.**阿非利卡努斯说，如果他人所有的奴隶被命令获得自由并同时被遗赠，可以依据遗赠请求该奴隶；因为给予自由并无效力，若因此使本来单独作出便有效的遗赠失效，显然不合道理。

<!-- source-p 542 -->
<a id="30.108.10"></a>**10.**某人在箱中有五枚金币，却遗赠或向要约人允诺“箱中的十枚金币”。遗赠和要约均有效，但无论依据要约还是遗嘱，只应给付五枚金币。至于能否依据遗嘱请求缺少的五枚金币，法律上几乎难以允许：因为这项遗赠在某种意义上似乎指向一个事实上并不存在的特定物。如果立遗嘱人死亡时箱中已有足额金币，而其后其中一部分灭失，那么毫无疑问，该灭失应由继承人承担。

<!-- source-p 543 -->
<a id="30.108.11"></a>**11.**如果奴隶被遗赠，而继承人迟延交付，该奴隶的生死及其状况恶化均由继承人承担风险；因此，即使继承人后来交付的是一名残疾奴隶，也仍须承担责任。

<!-- source-p 544 -->
<a id="30.108.12"></a>**12.**如果某物遗赠给你，或以遗嘱信托托付你的诚信，要求你将其返还给我，那么，如果你未从遗嘱中取得其他利益，我认为，你在请求该项遗赠时仅对故意欺诈承担责任；否则，你还应对过失向我负责。这与诚信契约中的规则相同：如果契约双方均有利益，则过失也应负责；如果仅一方有利益，则仅对故意欺诈负责。

<!-- source-p 545 -->
<a id="30.108.13"></a>**13.**某人将玛尔加丽塔交给提提乌斯作质押，指定儿子为继承人，并剥夺女儿的继承资格；随后作如下嘱托：“提提乌斯，我请求并托付你的诚信，请你出售我交给你作质押的玛尔加丽塔；扣除你应得的全部债权后，如有余额，请将其全部返还给我的女儿。”根据这一文字，女儿可以向其兄请求履行遗嘱信托，要求兄长向她提供其对债务人享有的诉权；因为在此情形下，就超出债务数额的质物价款而言，原债权人应被视为女儿的债务人。

<!-- source-p 546 -->
<a id="30.108.14"></a>**14.**若受嘱托的人与因遗嘱信托而负担义务的人并非同一人，也不值得惊讶。比如遗嘱写道：“提提乌斯，我请求你在收取一百枚金币后释放那名奴隶”，或者“请向塞姆普罗尼乌斯给付某物”；这种写法固然不够妥当，但仍应同样理解为遗嘱信托是托付继承人履行的，即由其向提提乌斯给付金钱。因此，提提乌斯本人也可以对继承人提起诉讼；而提提乌斯应被迫向奴隶给予自由，或向塞姆普罗尼乌斯履行所受嘱托的事项。

<!-- source-p 547 -->
<a id="30.108.15"></a>**15.**阿维狄乌斯以遗嘱信托嘱托其子，向自己的四名被释奴出借确定数额的金钱，并规定较低的利息；通说认为，这一遗嘱信托整体有效。
