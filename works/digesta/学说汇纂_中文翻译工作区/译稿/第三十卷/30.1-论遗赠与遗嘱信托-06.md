# D.30.1 论遗赠与遗嘱信托（*De legatis et fideicommissis*）——第六段

<!-- source-p 387 -->
<a id="30.80"></a>**30.80**

<!-- source-p 388 -->
**马尔凯卢斯：《尤利安〈学说汇纂〉第三十二卷札记》。**

<!-- source-p 389 -->
某人只留下三十，却遗赠给提提乌斯三十、塞尤斯二十、梅维乌斯十。马苏里乌斯·萨宾认为，提提乌斯应取得十五，塞尤斯十，梅维乌斯五；但应从各自所得中按比例满足《法尔基第法》的要求。

<!-- source-p 390 -->
<a id="30.81"></a>**30.81**

<!-- source-p 391 -->
**尤利安：《学说汇纂》第三十二卷。**

<!-- source-p 392 -->
<a id="30.81.pr."></a>**序言。**若某处地产附条件遗赠，继承人在条件尚未成就时又附条件遗赠给他人，而第一份遗嘱中预设的条件成就后，继承人遗赠时附加的条件才成就，则所有权并不因此脱离第一位受遗赠人。

<!-- source-p 393 -->
<a id="30.81.1"></a>**1.**若某物遗赠给共有奴隶，其中一名主人可以承认该遗赠，另一名主人则可以拒绝；因为在此情形下，共有奴隶仿佛是两个奴隶。

<!-- source-p 394 -->
<a id="30.81.2"></a>**2.**“我把斯提库斯给并遗赠给塞姆普罗尼乌斯；若塞姆普罗尼乌斯在一年内不释放斯提库斯，我就把同一斯提库斯给并遗赠给提提乌斯。”有人询问应适用何种法律。我答复：在此期间，塞姆普罗尼乌斯取得全部奴隶；若他在一年内释放斯提库斯，就使其成为自由人；若未释放，斯提库斯全部归提提乌斯。

<!-- source-p 395 -->
<a id="30.81.3"></a>**3.**若某人遗赠地产，但排除建筑物，“建筑物”可以仅指地上建筑，也可以包括其所依附的土地。若仅排除地上建筑，仍可依据遗赠请求整处地产；但继承人可以提出诈欺抗辩，要求获准在宅邸居住；这也包括在地产上通行和驾车通行的权利。若土地也被排除，则应请求返还除宅邸以外的地产；宅邸依法当然享有地役权，如同某人拥有两处地产并遗赠其中一处、但令其为另一处提供役使一样。不过，应倾向于认为立遗嘱人也打算排除建筑物所依附的土地，因为没有土地，建筑物便无法存在。

<!-- source-p 396 -->
<a id="30.81.4"></a>**4.**若释奴将其主人指定为遗产的七个十二分额继承人，其他人取得其余份额，并写道：“上述之人中除我的主人外，凡成为我继承人的，我把某某奴隶遗赠给提提乌斯；我估价每名奴隶为二十枚金币”，应理解为该遗赠仅由主人的共同继承人承担；因此，提提乌斯对这些奴隶最多只能主张五个十二分额。附加语“我估价每名奴隶为二十枚金币”并不改变遗赠的性质；若须考虑《法尔基第法》，仍应按奴隶的实际价值计入估价。

<!-- source-p 397 -->
<a id="30.81.5"></a>**5.**“若提提乌斯给我的继承人十枚钱币，我就把地产给并遗赠给提提乌斯。”若继承人原本欠提提乌斯十枚钱币，而提提乌斯收下后免除了继承人的债务，他就可以请求该地产。

<!-- source-p 398 -->
<a id="30.81.6"></a>**6.**若斯提库斯被遗赠给提提乌斯，而提提乌斯在得知遗赠归自己之前死亡，并在自己的遗嘱中将同一斯提库斯遗赠给塞尤斯；若提提乌斯的继承人未拒绝该遗赠，塞尤斯可以请求返还斯提库斯。

<!-- source-p 399 -->
<a id="30.81.7"></a>**7.**若家父遗赠一处地产给未适婚的儿子提提乌斯，又由替补继承人将同一地产遗赠给同一提提乌斯，而未适婚者后来成为父亲的继承人，那么，无论提提乌斯请求还是拒绝第一项遗赠，即使儿子后来死亡，也不能再向替补继承人请求该地产。替补继承人再次遗赠的部分，应视为重复遗赠。〔底本此处有连写疑误〕因此，若儿子无条件遗赠，而替补继承人附条件遗赠，一切应按只有儿子作出遗赠处理。反之，若儿子附条件遗赠、替补继承人无条件遗赠，而未适婚者在条件尚未成就时死亡，则只有替补继承人的遗赠有效。

<!-- source-p 400 -->
<a id="30.81.8"></a>**8.**遗嘱写道：“我把地产给并遗赠给卢基乌斯和提提乌斯，或其中仍在世的人”，属于有效遗赠；若二人都在世，应给付二人；若仅一人在世，则给付该人。

<!-- source-p 401 -->
<a id="30.81.9"></a>**9.**若一名附条件自由人被附条件遗赠，而遗赠条件尚未成就时，其自由条件未能成就，遗赠便转为有效。正如附条件的自由仅在自由条件发生效力时才使遗赠消灭，遗赠也只有在遗赠请求权开始发生时才可能消灭。

<!-- source-p 402 -->
<a id="30.81.10"></a>**10.**若奴隶由未适婚者遗赠，并由替补继承人命令其获得自由；若该未适婚者达到适婚年龄，受遗赠人可向他请求返还奴隶；若未适婚者死亡，则奴隶取得自由。若同一奴隶由未适婚者附条件遗赠，而儿子在条件未成就时、尚未达到适婚年龄便死亡，则更应遵守此规则。

<!-- source-p 403 -->
<a id="30.82"></a>**30.82**

<!-- source-p 404 -->
**尤利安：《学说汇纂》第三十三卷。**

<!-- source-p 405 -->
<a id="30.82.pr."></a>**序言。**并非遗赠请求权开始发生时，只要遗赠物以任何方式成为受遗赠人的财产，遗赠义务就消灭；只有在该物以不可分离的方式归其所有时，才发生消灭。比如，某项财产无条件遗赠给我；遗赠请求权开始发生时，我从继承人处通过交付取得该财产，而继承人此前又附条件地把同一财产遗赠给他人。我仍可依据遗嘱提起诉讼，因为该财产的状态是：一旦条件成就，所有权就会脱离我。同样，若依据要式口约有人欠我斯提库斯，而该奴隶附条件遗赠给他人，我虽因无偿取得的原因成为其所有人，条件成就时仍可依据要式口约起诉。

<!-- source-p 406 -->
<a id="30.82.1"></a>**1.**若我从因公离开的人之财产中通过时效取得某物，而该物在被他人追夺之前又遗赠给我，后来该物确被追夺，我仍可以依据遗嘱请求将其交给我。

<!-- source-p 407 -->
<a id="30.82.2"></a>**2.**某处地产遗赠给我；我买下该地产的所有权，但扣除了用益权。后来，出卖人发生身份减等，用益权开始归我所有。若我依据遗嘱提起诉讼，法官应按我所欠缺的利益估定争议金额。

<!-- source-p 408 -->
<a id="30.82.3"></a>**3.**马尔凯卢斯：若我只买下该地产的一部分，而只有一部分遗赠或赠与给我，结论亦同；我只能请求该部分。

<!-- source-p 409 -->
<a id="30.82.4"></a>**4.**尤利安：若遗赠给我的是潘菲拉所生的子女，而我买下了潘菲拉，且她在我处生下子女，则不能认为我因无偿取得而已经取得该子女，因为我是买下其母亲而取得该子女。此事可由下列情况证明：若该子女被他人追夺，我仍可依据买卖之诉起诉。

<!-- source-p 410 -->
<a id="30.82.5"></a>**5.**若某人对盖乌斯和卢基乌斯各享有同一笔债权，并写道：“盖乌斯欠我的债，由我的继承人向塞姆普罗尼乌斯给付；卢基乌斯欠我的债，由我的继承人向梅维乌斯给付”，他便为继承人设定了如下义务：必须向一人提供自己的诉权，向另一人给付诉讼估价。但若立遗嘱人生前已免除盖乌斯的债务，塞姆普罗尼乌斯和梅维乌斯的遗赠就必然无效。

<!-- source-p 411 -->
<a id="30.82.6"></a>**6.**若斯提库斯或潘菲鲁斯分别依据两份遗嘱遗赠给我，而我依据其中一份遗嘱取得斯提库斯，仍可依据另一份遗嘱请求潘菲鲁斯；因为即使同一份遗嘱遗赠给我斯提库斯或潘菲鲁斯，而斯提库斯因无偿取得的原因已归我所有，我仍可请求潘菲鲁斯。

<!-- source-p 412 -->
<a id="30.83"></a>**30.83**

<!-- source-p 413 -->
**马尔凯卢斯：《学说汇纂》第十三卷。**

<!-- source-p 414 -->
提提乌斯遗赠给你斯提库斯的一部分，塞尤斯又遗赠给你同一斯提库斯的一部分；你可以分别依据二人的遗嘱取得相应份额。

<!-- source-p 415 -->
<a id="30.84"></a>**30.84**

<!-- source-p 416 -->
**尤利安：《学说汇纂》第三十三卷。**

<!-- source-p 417 -->
<a id="30.84.pr."></a>**序言。**如下遗赠有效：“若提提乌斯向我的继承人提供担保，保证将给付一百给梅维乌斯，我的继承人就应向提提乌斯给付一百。”这与基于遗嘱信托原因要求某人返还财产的遗赠相同。

<!-- source-p 418 -->
<a id="30.84.1"></a>**1.**基于同一理由，下列遗赠也有效：“若提提乌斯向我的继承人提供担保，保证在市镇中用一百枚金币兴建工程，我的继承人就负有向他给付一百枚金币的义务。”

<!-- source-p 419 -->
<a id="30.84.2"></a>**2.**若塞姆普罗尼乌斯指定提提乌斯为继承人，并命令他在两年后将某处地产给付梅维乌斯；提提乌斯后来又在自己的遗嘱中命令继承人立即将同一地产遗赠给梅维乌斯，而梅维乌斯已从提提乌斯的继承人处取得地产价款；若他仍依据塞姆普罗尼乌斯的遗嘱请求地产，而不愿接受价款，就可以对其提出抗辩。

<!-- source-p 420 -->
<a id="30.84.3"></a>**3.**若某人被遗赠一名奴隶，而受遗赠人阻止自己接受斯提库斯——尽管继承人愿意交付——之后斯提库斯死亡，继承人可以对受遗赠人提出诈欺抗辩。

<!-- source-p 421 -->
<a id="30.84.4"></a>**4.**遗赠给受遗赠人的房屋原本对继承人的房屋负有地役权，但交付时未附加该地役权。我认为，受遗赠人可以依据遗嘱提起诉讼，因为他取得的遗赠并不完整；同样，若继承人交付给受遗赠人的奴隶已经受损，受遗赠人也可依据遗嘱起诉。

<!-- source-p 422 -->
<a id="30.84.5"></a>**5.**某人不知道遗嘱已将奴隶遗赠给自己，便从继承人处买下该奴隶。得知遗赠后，他依据遗嘱起诉并取得奴隶的，应在出卖之诉中免除责任，因为该诉讼本着诚信审理，并包含诈欺抗辩。若已支付价款后才依据遗嘱起诉，他应取得该奴隶，并可依据买卖之诉取回价款，如同奴隶被追夺时一样。若先提起买卖之诉，此时原告才发现奴隶已遗赠给自己并依据遗嘱起诉，除非继承人返还价款并使奴隶归原告所有，否则不得免除其责任。

<!-- source-p 423 -->
<a id="30.84.6"></a>**6.**若父亲以嫁资名义为女儿允诺给付一百，后来又将同一笔一百遗赠给女儿；若女婿依据允诺请求给付，而女儿依据遗嘱请求遗赠，继承人可提出诈欺抗辩以保护自己。因为二人必须达成协议，只能选择其中一种诉讼。

<!-- source-p 424 -->
<a id="30.84.7"></a>**7.**若遗嘱写道：“若某人将我的借据交还给我的继承人，我的继承人就应给他十枚钱币”，该条件的效力相当于“若他免除继承人的债务”。因此，若借据仍然存在，除非债权人正式确认继承人已受清偿，否则不得认为条件已经满足；若借据已经不存在，只要债权人免除了继承人的债务，就应视为满足条件。借据是在订立遗嘱时已经遗失、之后遗失，还是在立遗嘱人死亡后遗失，均不影响这一点。

<!-- source-p 425 -->
<a id="30.84.8"></a>**8.**若斯提库斯属于提提乌斯，却遗赠给提提乌斯和梅维乌斯，则应向梅维乌斯给付斯提库斯的一部分；因为提提乌斯虽不能作为受遗赠人取得该奴隶，仍应计为一份。

<!-- source-p 426 -->
<a id="30.84.9"></a>**9.**“将斯提库斯或潘菲鲁斯给提提乌斯，由我的继承人选择其一。”若继承人表示愿意给付斯提库斯，而斯提库斯随后死亡，继承人即获免责。继承人一旦表示选择给付何物，就不得改变其决定。

<!-- source-p 427 -->
<a id="30.84.10"></a>**10.**遗嘱写道：“我的继承人应将科尔涅利乌斯地产，以及我死亡时属于我的、位于该地产上的奴隶，给付提提乌斯。”一名惯常住在该地产的女奴在立遗嘱人死亡时正在逃亡，并在逃亡期间生下子女；问题是女奴或其子女是否属于遗赠范围。我答复：尽管女奴在逃亡，仍视为已被遗赠；即使她是逃奴，也如同家父死亡时她仍在该地产上一样处理。由此，子女也随母亲，并应视为属于遗赠，如同其在该地产上出生一样。

<!-- source-p 428 -->
<a id="30.84.11"></a>**11.**若遗赠给提提乌斯的是斯提库斯或潘菲鲁斯，由他选择其一；之后立遗嘱人又将潘菲鲁斯赠给提提乌斯，则斯提库斯仍是遗赠义务的标的。

<!-- source-p 429 -->
<a id="30.84.12"></a>**12.**若遗嘱写道：“我把奴隶分别遗赠给提提乌斯和梅维乌斯”，可以确定，不会把同一名奴隶同时给付二人；正如遗嘱写道“我把一名奴隶遗赠给提提乌斯，再把另一名奴隶遗赠给梅维乌斯”时，不会产生同一问题。

<!-- source-p 430 -->
<a id="30.84.13"></a>**13.**若受遗赠人在决定采用何种诉讼之前死亡，并留下两名继承人，二人不能同时取得遗赠，除非彼此同意。因此，只要其中一人坚持对物提起返还之诉，另一人就不能提起对人之诉。但若二人同意，就共同取得该物。二人必须自愿同意，或者在法官主持下达成一致。

<!-- source-p 431 -->
<a id="30.85"></a>**30.85**

<!-- source-p 432 -->
**保罗：《评普劳提乌斯》第十一卷。**

<!-- source-p 433 -->
某处地产共同遗赠给两人，其中一人通过对人之诉取得了相当于其份额的估价。若另一人想请求返还整处地产，可以对其提出诈欺抗辩，驳回其二分之一的请求，因为死者只想让该遗赠整体归二人一次。

<!-- source-p 434 -->
<a id="30.86"></a>**30.86**

<!-- source-p 435 -->
**尤利安：《学说汇纂》第三十四卷。**

<!-- source-p 436 -->
<a id="30.86.pr."></a>**序言。**若他人将你先前出质的奴隶遗赠给你，你可以对继承人提起遗嘱之诉，要求其赎回质物。

<!-- source-p 437 -->
<a id="30.86.1"></a>**1.**若一名继承人在遗嘱中将斯提库斯遗赠给梅维乌斯，而所有继承人又在遗嘱附录中将同一斯提库斯遗赠给他；若梅维乌斯在附录开启前已取得诉讼估价，就不能依法依据遗嘱附录再次请求斯提库斯，因为立遗嘱人只想让他取得一项遗赠。

<!-- source-p 438 -->
<a id="30.86.2"></a>**2.**遗赠一名奴隶时，该奴隶本人的身份以及所有涉及其身份的事项，都处于待定状态。若受遗赠人拒绝遗赠，该奴隶从未被视为属于他；若未拒绝，则从继承被接受之日起视为属于他。依照这一规则，也应判断奴隶通过交付取得或以要式口约取得的权利，以及遗赠或赠与给他的物品；应视具体情况将奴隶的行为归属于继承人或受遗赠人。

<!-- source-p 439 -->
<a id="30.86.3"></a>**3.**若所有继承人共同遗赠一处属于其中一名继承人的地产，该地产所有人只须交付自己的份额；其他继承人则对其余份额承担责任。

<!-- source-p 440 -->
<a id="30.86.4"></a>**4.**若地上建筑物遗赠给土地所有人，遗赠仍然有效；尽管此人已经是土地所有人，他仍可因此免除地役权负担并取得地上建筑物。

<!-- source-p 441 -->
<a id="30.87"></a>**30.87**

<!-- source-p 442 -->
**帕比尼安：《疑问集》第十八卷。**

<!-- source-p 443 -->
父亲留下遗赠给仍处于自己权力之下、并被指定取得部分遗产的儿子。若儿子拒绝接受父亲的遗产，便否认其遗赠请求权，是极为严苛的意见；因为儿子基于正当理由不愿卷入遗产事务，并非要推翻父亲的意思。

<!-- source-p 444 -->
<a id="30.88"></a>**30.88**

<!-- source-p 445 -->
**马尔基安努斯：《法学阶梯》第六卷。**

<!-- source-p 446 -->
但若父亲只想在儿子保留继承的情况下让其取得遗赠，则依阿里斯托的意见，儿子甚至不得对共同继承人提起遗赠之诉；因为儿子本人认为遗产已无清偿能力。即使父亲没有明文附加条件，只要能明显认定这是他的意思，也应如此处理。

<a id="30.89"></a>**30.89**

<!-- source-p 448 -->
**尤利安：《学说汇纂》第三十六卷。**

<!-- source-p 449 -->
即使是已解放的家子，也不因放弃继承而被禁止向继承人请求遗赠。裁判官准许曾处于父权之下的人放弃父亲的遗产，显然是在他们身上赋予了相应权利，如同他们原本可以自由决定是否接受继承一样。〔底本此处有连写疑误〕

<a id="30.90"></a>**30.90**

<!-- source-p 451 -->
**帕比尼安：《疑问集》第十八卷。**

<!-- source-p 452 -->
<a id="30.90.pr."></a>**序言。**那么，若遗嘱写道“此外再给我的儿子”，毫无疑问，这将成为立遗嘱人意思如何的问题；但除非能够证明父亲有明显相反的意思，否则该情形与前述为儿子利益所作的安排并无不同。

<a id="30.90.1"></a>**1.**若某人指定数名儿子为继承人，并用遗赠措辞在他们之间分配财产，那么，依立遗嘱人的意思，不应准许未接受遗产的儿子提起遗赠之诉。
