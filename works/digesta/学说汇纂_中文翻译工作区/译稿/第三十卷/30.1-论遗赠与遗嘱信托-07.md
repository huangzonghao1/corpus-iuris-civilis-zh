# D.30.1.109–128　论遗赠与遗嘱信托（第七部分）

<!-- source-p 548 -->
<a id="30.109"></a>
### 30.109

<!-- source-p 549 -->
阿非利卡努斯《疑问集》第六卷

<!-- source-p 550 -->
<a id="30.109.pr."></a>
**序言**　阿非利卡努斯说，若某人将生前以通常方式赠与妻子的物品遗赠给她，应认为他所指的只是那些依法并未有效完成的赠与；否则，这种遗赠便毫无意义。这就如同他明确写道：“我依法赠与妻子的物品”（quae uxori iure donavero），或“我为释放奴隶而赠与妻子的物品，现遗赠给她”（quae uxori manumissionis causa donavero, ea ei lego）；因为这些情形下的遗赠将是无效的。

<!-- source-p 551 -->
<a id="30.109.1"></a>
**1**　某继承人受托向我给付一处庄园或一百钱，却将庄园卖给了提图斯。虽然继承人可以选择愿意给付哪一项，但必须完整给付其中一项；我认为，应由裁判官行使职权：若提图斯提出给付钱款，便应制止受遗赠人追索庄园。这样，情形便会与庄园未被处分时相同。因为即使是针对继承人本人，裁判官或仲裁人的职权也应如此行使：若不交付庄园，其估价不得高于或低于一百钱。

<!-- source-p 552 -->
<a id="30.110"></a>
### 30.110

<!-- source-p 553 -->
阿非利卡努斯《疑问集》第八卷

<!-- source-p 554 -->
若继承人受命概括地交付一名由其自行选择的奴隶，却明知某奴隶是窃贼仍将其交付，而该奴隶又偷窃了受遗赠人的财物，阿非利卡努斯说，可以提起恶意之诉。但既然继承人确实负有不得交付最差奴隶的责任，他就应另行交付一名奴隶，并将这名窃贼奴隶留给受遗赠人，供其作为诺克萨交付对象（pro noxae dedito）。

<!-- source-p 555 -->
<a id="30.111"></a>
### 30.111

<!-- source-p 556 -->
马尔基安《法学阶梯》第二卷

<!-- source-p 557 -->
即使监护人仅以遗产的一部分为由请求免责，例如仅涉及意大利境内或行省财产，他依据遗嘱所获的一切也应被剥夺。神圣的塞维鲁与安敦尼皇帝曾以敕答作此规定。

<!-- source-p 558 -->
<a id="30.112"></a>
### 30.112

<!-- source-p 559 -->
马尔基安《法学阶梯》第六卷

<!-- source-p 560 -->
<a id="30.112.pr."></a>
**序言**　若某人遗赠佃户，却未一并遗赠佃户所依附的土地，该遗赠无效。但是否应给付其估价，应根据死者的意思确定；神圣的马可皇帝与康茂德皇帝曾以敕答如此裁定。

<!-- source-p 561 -->
<a id="30.112.1"></a>
**1**　若继承人被命令交付自己的奴隶，却将其释放，应对该奴隶的估价负责；其是否知道该奴隶已被遗赠，并无区别。若继承人将该奴隶赠与他人，而受赠人又将其释放，继承人也应负责，即使他不知道自己曾遗赠该奴隶也是如此。

<!-- source-p 562 -->
<a id="30.112.2"></a>
**2**　若遗赠写作“我将某物给付并遗赠给提图斯与塞尤斯”，则该遗赠同时给予二人；正如遗赠“庄园连同弗米亚房屋”时，两者也都包含在遗赠之内。

<!-- source-p 563 -->
<a id="30.112.3"></a>
**3**　若某人在遗嘱中写入违反法律或善良风俗的内容，该处分无效；例如，写入违反法律或裁判官告示的内容，或写入不道德之事。

<!-- source-p 564 -->
<a id="30.112.4"></a>
**4**　神圣的塞维鲁与安敦尼皇帝以敕答指出，遗嘱中所载、违反法律效力及法律权威的宣誓，不发生任何效力。

<!-- source-p 565 -->
<a id="30.113"></a>
### 30.113

<!-- source-p 566 -->
马尔基安《法学阶梯》第七卷

<!-- source-p 567 -->
<a id="30.113.pr."></a>
**序言**　可以将遗赠给他人的奴隶附加如下限制：“在他仍为奴隶期间”（quoad serviat），或“如果他将成为提图斯的奴隶”（si servus Titii erit）；马尔切鲁斯也持此见解。

<!-- source-p 568 -->
<a id="30.113.1"></a>
**1**　若某人将自己奴隶的自由延至某一时间，并在此期间请求继承人供给奴隶食物，神圣的塞维鲁与安敦尼皇帝以敕答指出，应当遵从立遗嘱人的意思。

<!-- source-p 569 -->
<a id="30.113.2"></a>
**2**　若某人命第一顺位继承人向某人遗赠一百钱，又命第二顺位继承人向同一人遗赠二百钱，随后又概括地重申遗赠，则视为他重申了三百钱的遗赠。

<!-- source-p 570 -->
<a id="30.113.3"></a>
**3**　但若父亲为其未适婚儿子指定替补继承人，并要求替补继承人重申遗赠；而未适婚人后来成为继承人，却在达到适婚年龄前死亡，则该重申无效，因为死者的意思是遗赠只应给付一次。

<!-- source-p 571 -->
<a id="30.113.4"></a>
**4**　若遗赠由未适婚人作出，并附有“若其达到适婚年龄”（si ad pubertatem pervenerit）的条件，随后又由替补继承人重申，则替补继承人仍负给付遗赠的义务；而使遗赠无效的该项条件，不视为也被重申。

<!-- source-p 572 -->
<a id="30.113.5"></a>
**5**　帕比尼安在《答复集》第三卷写道，死者关于葬礼的荒谬意思不发生效力，例如要求将衣物或其他多余物品用于葬礼开支。

<!-- source-p 573 -->
<a id="30.114"></a>
### 30.114

<!-- source-p 574 -->
马尔基安《法学阶梯》第八卷

<!-- source-p 575 -->
<a id="30.114.pr."></a>
**序言**　军人或退伍军人身份家子即使未立遗嘱而死亡，也可以要求其父承担遗嘱信托，因为他本来就可以订立遗嘱。

<!-- source-p 576 -->
<a id="30.114.1"></a>
**1**　若被释自由人无遗嘱死亡，仍可通过遗嘱信托使其保护人给付财产，但以法定应得份额为限；因为若该自由人立有遗嘱，也只允许其留下法定应得的份额。〔疑义：*a patrono* 与 *partem debitam* 的句法及其指向不够明确，暂按保护人负担给付、以法定份额为限处理。〕

<!-- source-p 577 -->
<a id="30.114.2"></a>
**2**　若某人无遗嘱死亡，且知道其财产将作为无人继承的遗产归入国库，他可以将财产托付给国库作为遗嘱信托。

<!-- source-p 578 -->
<a id="30.114.3"></a>
**3**　马尔切鲁斯《学说汇纂》第十二卷讨论了如下问题。某人将一处庄园遗赠给一名受遗赠人，并托付该人于其死后将庄园返还给塞姆普罗尼乌斯；他又托付该受遗赠人给提图斯一百钱。适用何种法律？马尔切鲁斯说，若立遗嘱人将一百钱遗嘱信托留给提图斯，指定由受遗赠人生前收取的孳息中给付，而受遗赠人在经过足够长时间、孳息累计达到一百钱后才死亡，则提图斯应取得这一百钱。若受遗赠人在取得遗赠后立即死亡，提图斯的遗嘱信托即告消灭，因为公认不得要求受托人返还超过其所受领的数额。

<!-- source-p 579 -->
<a id="30.114.4"></a>
**4**　但若提图斯的遗嘱信托未被约定在受遗赠人死亡时才给付，马尔切鲁斯说，应立即向提图斯给付遗嘱信托，不过须要求受遗赠人提供担保，以返还其所取得的超额部分；若受遗赠人在孳息累计达到一百钱之前死亡，该担保即发生效力。但很难认为立遗嘱人意在要求受遗赠人在收取孳息之前就从庄园收益中给付。若受遗赠人愿意提供担保以返还庄园，法院确应听取其意见；毕竟，要求他以自己的财产给付一百钱十分荒谬，尤其是在庄园价值仅为一百钱或略高于一百钱时。我们即依此规则处理。

<!-- source-p 580 -->
<a id="30.114.5"></a>
**5**　若某物或其他权利被合法留给某人，而该人因自身身体缺陷、所留事物的性质或其他任何正当理由不能取得，但他人却可以取得，则应向其给付该项标的通常可购得的估价。

<!-- source-p 581 -->
<a id="30.114.6"></a>
**6**　不得要求某人指定另一人为继承人。不过，元老院决议规定，这种情形应按受托人被要求返还遗产处理。

<!-- source-p 582 -->
<a id="30.114.7"></a>
**7**　那么，若继承人被要求在自己死亡后返还其遗产的四分之一呢？我认为更为正确的看法是，斯凯沃拉所指出、帕皮里乌斯·弗龙托所写的意见：该遗嘱信托有效，如同此人被要求返还自己的遗产一样；返还范围应以立遗嘱人的遗产所能负担者为限，并依一般法律规则处理。

<!-- source-p 583 -->
<a id="30.114.8"></a>
**8**　但若有人被要求解放自己的子女，则无须照办；因为家父权无法估价。

<!-- source-p 584 -->
<a id="30.114.9"></a>
**9**　不得遗赠或以遗嘱信托留下一栋应予拆毁的房屋；元老院曾作此规定。

<!-- source-p 585 -->
<a id="30.114.10"></a>
**10**　若遗嘱信托留给一名未获解放的他人奴隶，而该奴隶后来获得自由，应当认为可以准许他取得遗嘱信托。

<!-- source-p 586 -->
<a id="30.114.11"></a>
**11**　神圣的塞维鲁与安敦尼皇帝以敕答指出，若某人受托在其兄死亡这一条件成就时向其兄的子女返还财产，在条件成就日到来之前，即使这些子女同意，也不得提前返还；若子女仍处于其父的家父权之下，更是如此。待遗嘱信托的给付期限届至、子女已成为自权人时，才应向他们返还；若其中有人已先行死亡，则不得向全体返还。

<!-- source-p 587 -->
<a id="30.114.12"></a>
**12**　同一皇帝又以敕答指出，无须在遗嘱信托期限届至前将母亲的遗产返还给子女；继承人可以提供通常的担保。若其不能提供担保，可以为保全遗嘱信托之目的，将子女置于遗产占有之中，使其如同质权人而非所有人占有：他们没有处分权，只能将遗产作为质物持有。子女通过其父取得孳息，奴隶则通过其主人取得孳息。

<!-- source-p 588 -->
<a id="30.114.13"></a>
**13**　若某人受托在无子女而死亡时通过遗嘱信托返还财产，而其子女比他活得更久，则该条件应视为未成就；无须再问这些子女是否成为继承人。

<!-- source-p 589 -->
<a id="30.114.14"></a>
**14**　神圣的塞维鲁与安敦尼皇帝以敕答指出，若立遗嘱人禁止处分某物，却不说明其意思所依据的原因，且无法查明立遗嘱人是为谁的利益作此安排，则遗嘱中的文字毫无效力，视为仅留下一个空洞的命令；立遗嘱人不能在遗嘱中创设此类规则。但若立遗嘱人表明此意在于照顾子女、后代、被释自由人、继承人或其他特定人，则应遵守该意思；不过，这种安排不得损害债权人或国库。若继承人的财产因立遗嘱人的债权人而被出售，遗嘱信托受益人也须共同承受这一风险。

<!-- source-p 590 -->
<a id="30.114.15"></a>
**15**　父亲指定儿子为继承人；该儿子有三名孙子。父亲以遗嘱信托嘱咐儿子不得处分某庄园，并须使其留在家族中。儿子临终时指定两名继承人，将第三人排除在继承之外，又把该庄园遗赠给家族外之人。神圣的塞维鲁与安敦尼皇帝以敕答指出，儿子确实没有遵从死者的意思。

<!-- source-p 591 -->
<a id="30.114.16"></a>
**16**　即使儿子将两名子女排除在继承之外，仅指定一人为继承人，却将庄园遗赠给家族外之人，马尔切鲁斯仍认为，被排除的子女可以请求遗嘱信托。若儿子生前解放了子女，之后又处分庄园，也会产生同样结果。

<!-- source-p 592 -->
<a id="30.114.17"></a>
**17**　若所有儿子都被指定为继承人，但继承份额不相等，他们不能要求依据份额较少的继承人所立遗嘱取得遗嘱信托，并据此按人头平均而非按继承份额分配。因为，即使庄园只留给其中一人，也可以说立遗嘱人已使其留在家族之中。

<!-- source-p 593 -->
<a id="30.114.18"></a>
**18**　同样，若立遗嘱人只指定一人为继承人，未作任何遗赠，那么，只要财产仍留在家族之中，被排除在继承之外的人就暂时无权请求任何财产。

<!-- source-p 594 -->
<a id="30.114.19"></a>
**19**　有时，遗赠或以遗嘱信托留出的奴隶死亡，继承人反而因此获益；例如奴隶属于他人，或者虽然是继承人自己的奴隶，却分别留给数人，且每人均获准取得全部标的——当然，前提是该奴隶并非因继承人的过失而死亡。

<!-- source-p 595 -->
<a id="30.115"></a>
### 30.115

<!-- source-p 596 -->
乌尔比安《法学阶梯》第二卷

<!-- source-p 597 -->
即使采用如下措辞，也构成遗嘱信托：“我希望你给付”（cupio des）、“我选择你给付”（opto des）、“我相信你会给付”（credo te daturum）。

<!-- source-p 598 -->
<a id="30.116"></a>
### 30.116

<!-- source-p 599 -->
弗洛伦提努斯《法学阶梯》第十一卷

<!-- source-p 600 -->
<a id="30.116.pr."></a>
**序言**　遗赠是对遗产的扣减：立遗嘱人希望将本来全部归属于继承人的财产中的某物，转给他人。

<!-- source-p 601 -->
<a id="30.116.1"></a>
**1**　继承人不得将遗赠给予自己，但可以由共同继承人给予。因此，若一处庄园遗赠给一名取得遗产二分之一份额的继承人和两名外人，则该继承人可取得庄园的六分之一，因为他不能向自己请求返还；对于取得遗产二分之一份额的共同继承人，在两名外人一同参与时，该受遗赠继承人不得取得超过三分之一。至于两名外人，他们可以向受遗赠继承人请求庄园的二分之一，并向另一继承人请求三分之一。

<!-- source-p 602 -->
<a id="30.116.2"></a>
**2**　被指定为继承人的他人奴隶，不得将遗赠给予自己，无论是全部还是一部分。

<!-- source-p 603 -->
<a id="30.116.3"></a>
**3**　即使遗产尚未被接受，也可以有效地向遗产奴隶作出遗赠，因为遗产代替留下该遗产之死者的人格。

<!-- source-p 604 -->
<a id="30.116.4"></a>
**4**　遗赠的庄园应按其被遗赠时的状态交付。因此，无论是该庄园对继承人的土地负有役权，还是继承人的土地对该庄园负有役权，即使役权因所有权混同而消灭，也应恢复原有的权利状态。若受遗赠人不允许设定役权，而仍请求取得遗赠，继承人可以对其提出恶意抗辩；反之，若遗赠的庄园未获恢复原有役权，受遗赠人仍可提起遗嘱诉讼。

<!-- source-p 605 -->
<a id="30.117"></a>
### 30.117

<!-- source-p 606 -->
马尔基安《法学阶梯》第十三卷

<!-- source-p 607 -->
凡留给城邦的财产，均属有效遗赠，无论用于分配、公共工程、供养、儿童教育或其他用途。

<!-- source-p 608 -->
<a id="30.118"></a>
### 30.118

<!-- source-p 609 -->
涅拉提乌斯《规则》第十卷

<!-- source-p 610 -->
即使以如下措辞留下财产，遗嘱信托仍然有效：“我要求”（exigo）、“我希望你给付”（desidero, uti des）；以下措辞也一样：“我希望我的遗产归提图斯所有”（volo hereditatem meam Titii esse）、“我知道你会将我的遗产返还给提图斯”（scio hereditatem meam restituturum te Titio）。

<!-- source-p 611 -->
<a id="30.119"></a>
### 30.119

<!-- source-p 612 -->
马尔基安《规则》第一卷

<!-- source-p 613 -->
若立遗嘱人禁止奴隶交账，这并不意味着奴隶可以不返还其所持有之物并据为己有；该禁令的作用是避免进行琐细查核，也就是说，不追究过失，只追究欺诈。因此，不能仅因立遗嘱人禁止奴隶交账，就认为遗嘱已将其特有产遗赠给该奴隶；即便该奴隶后来获得自由，也一样。

<!-- source-p 614 -->
<a id="30.120"></a>
### 30.120

<!-- source-p 615 -->
乌尔比安《答复集》第二卷

<!-- source-p 616 -->
<a id="30.120.pr."></a>
**序言**　没有理由禁止继承人出售房屋建筑，只要保留为支付遗赠款而指定的收益，并确保遗赠仍可实现。

<!-- source-p 617 -->
<a id="30.120.1"></a>
**1**　所有获遗嘱信托的人均同意出售的，就不再存在请求遗嘱信托的诉权。

<!-- source-p 618 -->
<a id="30.120.2"></a>
**2**　庄园被无条件遗赠后，遗产接受时点之后由受遗赠人收取的孳息归受遗赠人所有；但佃户仍可基于租赁关系向继承人提起诉讼。

<!-- source-p 619 -->
<a id="30.121"></a>
### 30.121

<!-- source-p 620 -->
马尔基安《规则》第三卷

<!-- source-p 621 -->
若遗赠写作“给提图斯与梅维乌斯”（Titio cum Maevio），其中一人即使没有另一人，也可以取得遗赠。正如裁判官所说：“我命令将胎儿连同子女置于占有之中”（ventrem cum liberis in possessionem esse iubeo）；即使没有子女，胎儿仍会被置于占有之中。

<!-- source-p 622 -->
<a id="30.122"></a>
### 30.122

<!-- source-p 623 -->
保罗《规则》第三卷

<!-- source-p 624 -->
<a id="30.122.pr."></a>
**序言**　可以向城邦作出遗赠，内容也可以是有助于城邦荣誉或装饰之物。用于装饰的，例如遗赠财物以修缮或装备广场、剧院、竞技场；用于荣誉的，例如遗赠财物以举行公共演出（munus）、狩猎表演、舞台演出或竞技比赛，或用于向每位市民分配财物、举办公共宴席。除此之外，为年老体弱者提供供养而留下的财物——例如供老人、男童或女童使用——也被认为关乎城邦的荣誉。

<!-- source-p 625 -->
<a id="30.122.1"></a>
**1**　遗嘱写道：“卢基乌斯·提图斯与盖乌斯·塞尤斯应向普布利乌斯·梅维乌斯给付十钱”（Lucius Titius et Gaius Seius Publio Maevio decem dare damnas sunto）。盖乌斯·塞尤斯未成为继承人。萨宾认为，只有提图斯负担该遗赠；塞尤斯应视为未曾写入遗嘱。此说正确，也就是说，提图斯应给付全部十钱。

<!-- source-p 626 -->
<a id="30.122.2"></a>
**2**　若庄园遗赠附有条件，即受遗赠人须向继承人给付一百钱，而庄园价值恰与其被命令给付的数额相等，则不得强迫受遗赠人履行其另行留下的遗嘱信托；因为若某人所支出者与其所得相等，就应认为其并未从遗嘱中取得任何利益。

<!-- source-p 627 -->
<a id="30.123"></a>
### 30.123

<!-- source-p 628 -->
马尔切鲁斯《答复集》单卷

<!-- source-p 629 -->
<a id="30.123.pr."></a>
**序言**　卢基乌斯·提图斯有两个儿子，并以遗嘱指定二人为继承人，遗嘱如此规定：“凡我的子女中成为我继承人的，我托付其信义：若他们中有人无子女而死亡，应在其死亡时将我遗产的三分之二返还给其兄弟”（Quisquis mihi liberorum meorum heres erit, eius fidei committo, ut si quis ex is sine liberis decedat, hereditatis meae bessem cum morietur fratribus suis restituat）。后来，一名兄弟死亡，并将自己的兄弟指定为其十二分之九份额的继承人。我问，这是否满足了遗嘱信托？马尔切鲁斯答复说，除非能证明死者另有意思，否则，可以就另一继承人实际取得的份额，请求其履行卢基乌斯·提图斯遗嘱中原本应向该兄弟承担的遗嘱信托。这种情况与其他情形并无显著差别，例如债权人成为其债务人的继承人。但若共同继承人能够证明，立遗嘱人指定其兄弟为继承人的意思，是要使该兄弟以继承人身份为满足，而不再请求遗嘱信托，则应听取共同继承人的主张。

<!-- source-p 630 -->
<a id="30.123.1"></a>
**1**　遗嘱如此写道：“我的继承人应将某物、某物给盖乌斯·塞尤斯。我请求你，塞尤斯，并托付你的信义，将上述一切毫不迟延地交还”（Gaio Seio illud et illud heres meus dato. Et te rogo, Sei, fideique tuae mando, uti ea omnia quae supra scripta sunt reddas sine ulla mora）。〔底本原文在 *reddas* 后又重复出现 *redderes ipse*。〕问题是：立遗嘱人未在遗嘱中指出希望返还给谁，这是否构成一项未明示受益人的遗嘱信托？马尔切鲁斯答复说，若塞尤斯为规避法律而接受秘密信托，即使家父与他使用了上述措辞，也不能使他获益；不能因此认为他就没有规避法律，因为立遗嘱人意欲照顾何人仍然无法确定。

<a id="30.124"></a>
### 30.124

<!-- source-p 632 -->
涅拉提乌斯《札记》第五卷

<!-- source-p 633 -->
若立遗嘱人逐一指名命继承人给付某物，较妥当的看法是，他们应按人头平均份额给付。因为逐一列举人名的效果，是使各人的遗赠给付份额相等；若未指名列举，他们原本应按各自继承份额负担给付。〔原文疑误：本段末尾出现拼接文字 “debituri essententiarum”。〕

<a id="30.125"></a>
### 30.125

<!-- source-p 635 -->
鲁提利乌斯·马克西穆斯《评法尔基第法》单卷

<!-- source-p 636 -->
若继承人受命先行取得一百钱，并返还遗产，而保护人又请求取得遗嘱表外遗产占有（bonorum possessio contra tabulas），则如同遗赠一样，先行取得的这笔款项也应按保护人所取走的份额予以削减。

<a id="30.126"></a>
### 30.126

<!-- source-p 638 -->
保罗《论第二顺位遗嘱》单卷

<!-- source-p 639 -->
<a id="30.126.pr."></a>
**序言**　若遗赠由被排除继承人的替补继承人作出，该遗赠无效。因此，也不能命被排除继承人的法定继承人履行遗嘱信托；法定继承人所负义务与其被指定为遗嘱继承人时相同。〔原文疑误：此处底本将 “fuissent” 与后文连写为 “fuissententiarum”；以下据上下文断句。〕但若某名子女启动裁判官告示——该告示承诺准许取得遗嘱表外遗产占有（bonorum possessio contra tabulas）——而遗嘱指定的儿子也请求取得遗嘱表外遗产占有，则该儿子的替补继承人应按实际归于该儿子的财产数额履行遗赠，仿佛儿子是从父亲处经由遗产占有取得这些财产一样。

<!-- source-p 640 -->
<a id="30.126.1"></a>
**1**　若遗嘱如此遗赠给遗腹子：“若他成为继承人”（si heres erit），而遗腹子尚未出生时替补继承人便已接受继承，则应认为替补继承人须给付遗腹子若仍在世本应承担的遗赠。

### 30.127

<!-- source-p 642 -->
保罗《论附录遗嘱法》单卷

可以为兄弟的遗腹子设立遗嘱信托，因为遗嘱信托只遵循立遗嘱人的意思；而且加卢斯·阿奎利乌斯的见解已成为通说：并非家内继承人的遗腹子，也可以成为我们的法定继承人。

<a id="30.128"></a>
### 30.128

<!-- source-p 645 -->
马尔基安《法学阶梯》第二卷

<!-- source-p 646 -->
若监护人违反元老院决议，娶自己的未适婚女被监护人为妻，则该女子可以依据他的遗嘱取得财产，但监护人本人不得依据她的遗嘱取得财产。这是理所当然的：违反婚姻禁令者有过错，应受惩罚；而该女子受监护人欺骗，不能归咎于她。
