# D.30.1.16–40　论遗赠与遗嘱信托（第二部分）

<!-- source-p 056 -->
<a id="30.16"></a>
### 30.16

<!-- source-p 057 -->
庞波尼《评萨宾论》第五卷

<!-- source-p 058 -->
<a id="30.16.pr."></a>
**序言**　我认为，若同一物被共同遗赠给二人，即使其中一人尚未出生，另一人也只能取得其应有的部分；此说是正确的。

<!-- source-p 059 -->
<a id="30.16.1"></a>
**1**　若继承人受命向某人给付遗赠，而遗嘱中又附加了一个并非继承人的人的姓名，则继承人应给付全部遗赠。因为，即使立遗嘱人指名命其两个自家继承人承担遗赠，而其中一人未接受继承，已接受者也应给付全部；但以未接受者的份额归属于已接受者为前提。

<!-- source-p 060 -->
<a id="30.16.2"></a>
**2**　若遗赠给提图斯及遗腹子，而遗腹子未出生，提图斯得请求返还全部遗赠。即使立遗嘱人原本希望提图斯与遗腹子按人头平均分配，或者明确如此表示，只要遗腹子没有出生，全部遗赠仍应归提图斯。

<!-- source-p 061 -->
<a id="30.17"></a>
### 30.17

<!-- source-p 062 -->
乌尔比安《评萨宾论》第十五卷

<!-- source-p 063 -->
<a id="30.17.pr."></a>
**序言**　某人将遗赠留给其女儿，而又在遗嘱某处提及遗腹女儿的，视为其在遗赠给女儿时也考虑了遗腹女儿。

<!-- source-p 064 -->
<a id="30.17.1"></a>
**1**　若某人如此遗赠：“如果我生有女儿，我的继承人应给她一百”，则若生有数名女儿，视为立遗嘱人给每人都遗赠了同样数额；除非立遗嘱人的相反意思显而易见。

<!-- source-p 065 -->
<a id="30.17.2"></a>
**2**　若遗赠留给数名继承人中的一人，显然应由分割遗产诉讼的审判官命令向其给付；即使该人拒绝接受继承，也确认其仍可取得该遗赠。

<!-- source-p 066 -->
<a id="30.18"></a>
### 30.18

<!-- source-p 067 -->
尤利安《学说汇纂》第三十一卷

<!-- source-p 068 -->
即使遗赠人曾无效地将遗赠留给自己，他仍可请求取得全部遗赠。

<!-- source-p 069 -->
<a id="30.19"></a>
### 30.19

<!-- source-p 070 -->
乌尔比安《评萨宾论》第十五卷

<!-- source-p 071 -->
<a id="30.19.pr."></a>
**序言**　帕比尼安在《疑问集》中认为，无效作出的遗赠可以通过重申而获确认，例如后来在附录遗嘱中写道：“此外，我的继承人还应给他……”但以下文字则不同：“凡我已遗赠而未附给付日期的款项，我命令我的继承人分别于一年、两年和三年期满时给付。”立遗嘱人并非意在确认原本无效的处分，而是要延后有效遗赠的给付期限。

<!-- source-p 072 -->
<a id="30.19.1"></a>
**1**　同一作者在同一处还论及未适婚继承人的替补继承人：若未适婚人所作遗赠无效，则在替补继承人应当给付该遗赠的情况下，只有当未适婚人又另行遗赠某物，使用了“此外”之类的措辞，并且他未成为其父的继承人而后死亡时，替补继承人才负给付义务。

<!-- source-p 073 -->
<a id="30.19.2"></a>
**2**　向数人作出遗赠而未指明各自份额的，应平均分配。

<!-- source-p 074 -->
<a id="30.20"></a>
### 30.20

<!-- source-p 075 -->
庞波尼《评萨宾论》第五卷

<!-- source-p 076 -->
若某人有两名奴隶，遗嘱遗赠其中一名，却未能辨明其所指的是哪一名，则选择权属于受遗赠人。

<!-- source-p 077 -->
<a id="30.21"></a>
### 30.21

<!-- source-p 078 -->
乌尔比安《评萨宾论》第十五卷

<!-- source-p 079 -->
遗赠了一个畜群的，后来加入该畜群的牲畜也归受遗赠人所有。

<!-- source-p 080 -->
<a id="30.22"></a>
### 30.22

<!-- source-p 081 -->
庞波尼《评萨宾论》第五卷

<!-- source-p 082 -->
若遗赠畜群，在立遗嘱人生前其中一些牲畜死亡，另有牲畜补入，则应视为同一畜群。即使该畜群有所减少，且只剩下一头牛，也可以请求返还该牛，尽管它已不再构成畜群；正如遗赠岛屿后，岛屿若被焚毁，仍可请求返还其土地。

<!-- source-p 083 -->
<a id="30.23"></a>
### 30.23

<!-- source-p 084 -->
保罗《评萨宾论》第三卷

<!-- source-p 085 -->
若某人遗赠遗产的一部分——如今通常如此——应当不连同孳息一并返还，但继承人迟延的情形除外。

<!-- source-p 086 -->
<a id="30.24"></a>
### 30.24

<!-- source-p 087 -->
庞波尼《评萨宾论》第五卷

<!-- source-p 088 -->
<a id="30.24.pr."></a>
**序言**　尚未存在于现实中的事物也可以被遗赠，这一点已经确定，例如“那名女奴所生的一切”；又如“我庄园里所产的葡萄酒”，或者“只给付胎儿”。

<!-- source-p 089 -->
<a id="30.24.1"></a>
**1**　若我享有某物的用益权并将其遗赠，除非我后来取得该物的所有权，否则该遗赠无效。

<!-- source-p 090 -->
<a id="30.24.2"></a>
**2**　立遗嘱后，若立遗嘱人将一部分土地添入已遗赠的提提乌斯庄园，并将其指定为该庄园的一部分，则受遗赠人可以请求取得所添入的部分（其情形与土地因冲积而增加相似）；尤其是在这部分土地取自立遗嘱人立遗嘱时所有的另一块田地之时。

<!-- source-p 091 -->
<a id="30.24.3"></a>
**3**　反之，若立遗嘱后立遗嘱人从提提乌斯庄园中取出某物并添入另一庄园，则应考察受遗赠人是否也能请求取得该部分，抑或该部分已不再属于提提乌斯庄园，因而不能请求。毕竟，庄园与房屋的名称及其范围，是由我们的指定而非自然本身确定的。

<!-- source-p 092 -->
<a id="30.24.4"></a>
**4**　较妥当的看法是，某物一旦被指定用于其他用途，即视为已被排除在外。若我遗赠一艘船，并特别注明是“我的船”，而后又将其各部分全部修造一新，只要龙骨仍是原来的，受遗赠人仍可正当地请求返还该船。

<!-- source-p 093 -->
<a id="30.25"></a>
### 30.25

<!-- source-p 094 -->
保罗《评萨宾论》第三卷

<!-- source-p 095 -->
父亲可以从被指定为继承人的儿子处受遗赠，即使该遗赠是无条件的也可以；遗赠权利发生时儿子是否仍处于父亲的家父权之下，并无区别。因此，即使继承是在父亲命令下接受的，该遗赠也应计入《法尔基第法》规定的四分之一。

<!-- source-p 096 -->
<a id="30.26"></a>
### 30.26

<!-- source-p 097 -->
庞波尼《评萨宾论》第五卷

<!-- source-p 098 -->
<a id="30.26.pr."></a>
**序言**　任何人以遗赠名义可取得的，不得超过扣除为满足条件而给付的部分后所剩余的数额。

<!-- source-p 099 -->
<a id="30.26.1"></a>
**1**　若继承人被命令给付某一特定物，却未能在该物原所在之处交付；此后该物又在继承人无故意或过失的情况下灭失，则受遗赠人的地位因此恶化。

<!-- source-p 100 -->
<a id="30.26.2"></a>
**2**　遗赠遗产的一部分时，究竟应给付实物份额还是其估价，存在疑问。萨宾与卡西乌斯认为应给付估价；普罗库鲁斯与涅尔瓦则认为遗赠的是实物份额。不过，应当对继承人予以救济，使其可以自行选择给付实物份额或其估价。但对于能够无损分割的物，允许继承人给付其中一部分；若物在性质上不可分，或者无法在不造成损害的情况下分割，继承人则必须给付其估价。

<!-- source-p 101 -->
<a id="30.27"></a>
### 30.27

<!-- source-p 102 -->
保罗《评普劳提乌斯论》第九卷

<!-- source-p 103 -->
继承人可以将遗赠份额以较少数目的物，甚至以一件物给付受遗赠人；具体给付哪些物，可由受遗赠人同意，或由审判官评定。这样，受遗赠人便无须对每一件物都请求返还其份额。

<!-- source-p 104 -->
<a id="30.28"></a>
### 30.28

<!-- source-p 105 -->
乌尔比安《评萨宾论》第十九卷

<!-- source-p 106 -->
<a id="30.28.pr."></a>
**序言**　若我将欠债人所欠我的债务遗赠给该债权人，而该债权人原本可以援引对我的抗辩，则该遗赠有效，因为视为抗辩已被放弃。正如阿里斯托所说，若将因裁判官法上的诉权而欠我的债务遗赠给我，该遗赠有效，因为我因此取得民法上的诉权，以取代裁判官法上的诉权。

<!-- source-p 107 -->
<a id="30.28.1"></a>
**1**　马尔切鲁斯在《评尤利亚法与帕皮亚法》第二十八卷认为，若你将依要式口约对我所负的债务遗赠给我，该遗赠有效，因此《法尔基第法》也不会削减这笔债务。

<!-- source-p 108 -->
<a id="30.29"></a>
### 30.29

<!-- source-p 109 -->
保罗《评尤利亚法与帕皮亚法》第六卷

<!-- source-p 110 -->
若债务在数额、期限、条件或地点方面均未被延期履行，则该遗赠无效。

<!-- source-p 111 -->
<a id="30.30"></a>
### 30.30

<!-- source-p 112 -->
乌尔比安《评萨宾论》第十九卷

<!-- source-p 113 -->
<a id="30.30.pr."></a>
**序言**　如下文字：“凡我已遗赠而未附给付日期的款项，我的继承人应在一年、两年和三年期满时给付”，不适用于特定物的遗赠，而适用于以重量、数量或度量确定的物。

<!-- source-p 114 -->
<a id="30.30.1"></a>
**1**　而且，这一条款仅适用于未附给付日期的遗赠。因此，若遗赠是无条件作出的，该条款就会延后其给付期限。

<!-- source-p 115 -->
<a id="30.30.2"></a>
**2**　如果遗赠给我一百钱，且应立即给付，那么究竟应在一年期满时给付，还是仍应立即给付？塞尔维乌斯和拉贝奥说，应立即给付。因此，尽管就遗赠的效力及法律后果而言，该附加条款多余，但它仍能发挥作用，使遗赠在当下即可请求给付。

<!-- source-p 116 -->
<a id="30.30.3"></a>
**3**　但若遗赠是逐年或逐月给付的，该条款便不适用，因为此种遗赠本身已有起始和终止时间。

<!-- source-p 117 -->
<a id="30.30.4"></a>
**4**　若遗赠附有条件，也可以说年度给付条款不适用，因为条件被称为不确定的期限。

<!-- source-p 118 -->
<a id="30.30.5"></a>
**5**　这与特雷巴提乌斯的见解相符：若遗赠约定在某人年满二十岁时给付，通常的这一条款便不适用。

<!-- source-p 119 -->
<a id="30.30.6"></a>
**6**　同样，若遗赠的是箱中的钱，或仓库里的酒，也应认为该条款不适用；因为我们已经说过，每逢遗赠的是特定物，该条款即不适用。

<!-- source-p 120 -->
<a id="30.30.7"></a>
**7**　加卢斯·阿奎利乌斯、奥菲利乌斯和特雷巴提乌斯答复说，该文字不仅适用于此前写下的遗赠，也适用于遗嘱中载明的一切遗赠；此说是正确的。

<!-- source-p 121 -->
<a id="30.31"></a>
### 30.31

<!-- source-p 122 -->
保罗《评萨宾论》第三卷

<!-- source-p 123 -->
该条款也适用于后来在经遗嘱确认的附录遗嘱中作出的遗赠。

<!-- source-p 124 -->
<a id="30.32"></a>
### 30.32

<!-- source-p 125 -->
乌尔比安《评萨宾论》第二十卷

<!-- source-p 126 -->
<a id="30.32.pr."></a>
**序言**　某人指定其未适婚儿子为继承人，并遗赠一笔钱，且在儿子进入自权人地位时，又由替补继承人重申这些遗赠；若儿子未适婚即死亡，第二顺位继承人无须给付该遗赠。塞克斯图斯和庞波尼都认为，只有当遗赠重申采用如下形式时，才是如此：“凡我遗赠给我儿子的，以及我命令他给付的，若他成为我的继承人，我的继承人应在相同日期给付。”但若重申为：“凡我遗赠给我儿子的，我的继承人应给付”，则遗赠视为被无条件重申，且只是对遗赠作了指明。因此，本案所讨论的这一遗赠也应立即给付。

<!-- source-p 127 -->
<a id="30.32.1"></a>
**1**　某人有数名名为斯提库斯的奴隶，却遗赠一名斯提库斯，而无法辨明其所指为何人，则应由继承人选择并交付其中一名。

<!-- source-p 128 -->
<a id="30.32.2"></a>
**2**　若某物遗赠给城邦的一部分，且该物有助于装饰或增进城邦公共利益，则毫无疑问应当给付。

<!-- source-p 129 -->
<a id="30.33"></a>
### 30.33

<!-- source-p 130 -->
保罗《规则》第三卷

<!-- source-p 131 -->
若同一物被遗赠给数人，且为共同遗赠，即使其中一人以物权诉讼请求返还，另一人提起遗嘱诉讼，后者所能取得的也不超过其份额。若分别遗赠，且显然立遗嘱人在撤回给先一受遗赠人的遗赠后，转而将其遗赠给后一人，则只有后者取得遗赠。若无法明确认定这一点，所有人应按各自应有份额取得遗赠；但立遗嘱人的文字若明确显示其意在使二人各自取得全部标的，则属例外：此时一人取得价金，另一人取得实物。对实物或价金的选择权，归于最先就遗赠或遗嘱信托提起诉讼并使诉讼系属者；但其一经作出选择，不得再改选另一者。

<!-- source-p 132 -->
<a id="30.34"></a>
### 30.34

<!-- source-p 133 -->
乌尔比安《评萨宾论》第二十一卷

<!-- source-p 134 -->
<a id="30.34.pr."></a>
**序言**　当然，若立遗嘱人意在将遗赠转给最后一名受遗赠人，则先前受遗赠人无权取得，即使最后一人属于遗赠未能在其身上成立的情形也是如此。但若共同受遗赠人与分别受遗赠人混合指定，则共同受遗赠人按一人看待。

<!-- source-p 135 -->
<a id="30.34.1"></a>
**1**　若同一物在同一遗嘱中被遗赠数次，最多只能请求一次；取得该物本身或其估价，任一即可满足请求。

<!-- source-p 136 -->
<a id="30.34.2"></a>
**2**　但若同一物在两份遗嘱中均遗赠给我，我可以请求两次：根据一份遗嘱取得该物，根据另一份遗嘱取得其估价。

<!-- source-p 137 -->
<a id="30.34.3"></a>
**3**　但若遗赠的不是特定物，而是在同一遗嘱中数次遗赠同一数额，神圣的安敦尼·庇护皇帝曾以敕答指出，只有在最明确的证据证明立遗嘱人意在使遗赠数额倍增时，才应数次给付该数额；他对遗嘱信托也作了相同裁断。其理由很明显：同一物不能重复给付，而立遗嘱人可以希望同一笔钱款多次给付。

<!-- source-p 138 -->
<a id="30.34.4"></a>
**4**　不过，若数次遗赠的是一笔特定的钱款，例如立遗嘱人数次遗赠其箱中一百钱，则应作不同理解；我认为此时应将其与遗赠一处土地相提并论。

<!-- source-p 139 -->
<a id="30.34.5"></a>
**5**　但若数次遗赠的是一定重量的金或银，帕比尼安答复说，较应将其视同金钱数额的遗赠；这是有道理的，因为它看起来并非遗赠某一特定物。

<!-- source-p 140 -->
<a id="30.34.6"></a>
**6**　因此，其他以重量、数量或度量确定的物若被数次遗赠，也应作相同处理：只要立遗嘱人有此意思，就应数次给付。

<!-- source-p 141 -->
<a id="30.34.7"></a>
**7**　若我买下了遗赠给我的物，则在我尚未获得的价款范围内，我享有遗嘱诉权。

<!-- source-p 142 -->
<a id="30.34.8"></a>
**8**　若同一物在两份遗嘱中都遗赠给我，则更应如此：其中一份遗嘱请求我返还该物本身或以其他物替代，或者附条件遗赠某物以供替代。因为就我必须为此作出给付的范围而言，该物才可说尚未归我。

<!-- source-p 143 -->
<a id="30.34.9"></a>
**9**　若某物被共同遗赠，各受遗赠人的份额自始即已确定。形成份额的不仅包括遗赠在其身上成立的人，也包括遗赠未能在其身上成立的人，例如遗赠给提图斯和立遗嘱人自己的奴隶，而该奴隶并未获释。

<!-- source-p 144 -->
<a id="30.34.10"></a>
**10**　但若立遗嘱人在未适婚人遗嘱中，将同一物遗赠给他人，而在自己的遗嘱中又将该物遗赠给我，尤利安写道，我们应因这两项遗赠并存而分配份额。因此，暂时由立遗嘱人在自己遗嘱中指定的受遗赠人取得其份额。

<!-- source-p 145 -->
<a id="30.34.11"></a>
**11**　若某物遗赠给二人，其中一人又被指定为继承人，则他从自己处接受遗赠显然无效；因此，他遗赠给自己的部分归共同受遗赠人所有。

<!-- source-p 146 -->
<a id="30.34.12"></a>
**12**　由此可知，若有两名继承人，一人取得十二分之一，另一人取得十二分之十一，而一处庄园遗赠给二人，则取得十二分之一遗产份额的继承人将取得该庄园的十二分之十一，另一共同继承人则取得十二分之一。

<!-- source-p 147 -->
<a id="30.34.13"></a>
**13**　当然，若某一受遗赠人成为遗赠该物的继承人的继承人，这并不妨碍共同受遗赠人取得其份额；因为该受遗赠人仍按其份额保有遗赠。

<!-- source-p 148 -->
<a id="30.34.14"></a>
**14**　若遗赠给提图斯时这样写道：“让他取得塞尤斯庄园，或该庄园的用益权”，则这是两项遗赠；是否请求返还用益权，由提图斯自行决定。

<!-- source-p 149 -->
<a id="30.34.15"></a>
**15**　若有人如此遗赠给提图斯：“我给付并遗赠该庄园，使他取得其中一部分”，我认为可以说他将取得庄园的一部分；因为“庄园”一词在此可理解为部分庄园，而非全部庄园。毕竟，将庄园的一部分称为庄园也是恰当的。

<!-- source-p 150 -->
<a id="30.35"></a>
### 30.35

<!-- source-p 151 -->
保罗《评萨宾论》第三卷

<!-- source-p 152 -->
若继承人被命令交付一个属于他人的奴隶，而该奴隶后来由其所有人释放，则依据这项遗赠不再负有任何给付义务。

<!-- source-p 153 -->
<a id="30.36"></a>
### 30.36

<!-- source-p 154 -->
庞波尼《评萨宾论》第六卷

<!-- source-p 155 -->
<a id="30.36.pr."></a>
**序言**　遗嘱如此写道：“我将我的织工奴隶全部遗赠给提提娅，但本遗嘱中已遗赠给他人的除外。我将我的家生奴隶全部遗赠给普洛提娅，但已遗赠给他人的除外。”其中有些奴隶既是家生奴隶又是织工。拉贝奥说，就本案所问的那些奴隶而言，除非先查明其中哪些已遗赠给普洛提娅，否则无法确定哪些织工未遗赠给提提娅；同样，除非先查明哪些家生奴隶未遗赠给普洛提娅，也无法确定这一点。因此，这些奴隶不属于任何一项遗赠中的除外对象，故为两项遗赠共有。即使两项遗赠中均没有作任何除外规定，法律结论也相同。

<!-- source-p 156 -->
<a id="30.36.1"></a>
**1**　但若遗嘱如此遗赠：“所有织工，家生奴隶除外”；又如此遗赠：“所有家生奴隶，织工除外”，那么同时属于家生奴隶和织工的人就没有被遗赠给任何一方。

<!-- source-p 157 -->
<a id="30.36.2"></a>
**2**　遗赠写作“给提图斯和梅维乌斯”，还是“给提图斯与梅维乌斯”，并无差别；两种情形均视为共同遗赠。

<!-- source-p 158 -->
<a id="30.36.3"></a>
**3**　若继承人将应交给二人的斯提库斯交给其中一人，而在另一人提出要求之前斯提库斯便已死亡，继承人不负责任，因为不能认为该结果是由继承人的行为造成的。

<!-- source-p 159 -->
<a id="30.37"></a>
### 30.37

<!-- source-p 160 -->
乌尔比安《评萨宾论》第二十一卷

<!-- source-p 161 -->
<a id="30.37.pr."></a>
**序言**　若遗赠仅作概括表述，例如遗赠“一个奴隶”，盖乌斯·卡西乌斯写道，应当遵循不得交付最好或最差者的规则。我们的皇帝与神圣的塞维鲁皇帝以敕答支持了这一意见：他们答复说，遗赠奴隶时，不得指定交付一名家内管理奴隶。

<!-- source-p 162 -->
<a id="30.37.1"></a>
**1**　若立遗嘱人意在遗赠某一特定庄园，但无法辨明他想到的是哪一处，则继承人有权选择交付哪一处；若能够辨明所指庄园，则可请求返还该庄园。若立遗嘱人遗赠了一只盘子，却无法辨明是哪一只，同样由继承人选择交付哪一只。

<!-- source-p 163 -->
<a id="30.38"></a>
### 30.38

<!-- source-p 164 -->
庞波尼《评萨宾论》第六卷

<!-- source-p 165 -->
<a id="30.38.pr."></a>
**序言**　受遗赠人不得一部分取得遗赠、一部分放弃遗赠；但其继承人可以如此处理，使其中一人取得自己的部分，另一人放弃自己的部分。

<!-- source-p 166 -->
<a id="30.38.1"></a>
**1**　若我们表示不愿取得留给我们的遗赠，其效果如同该遗赠从未作出。因此我们说，役权不会因此发生混同——例如遗赠给我的土地原本对我自己的土地负有役权；又如，若遗赠给我的奴隶曾使受遗赠人得以提起盗窃之诉，该诉权也仍完整保留。

<!-- source-p 167 -->
<a id="30.39"></a>
### 30.39

<!-- source-p 168 -->
乌尔比安《评萨宾论》第二十一卷

<!-- source-p 169 -->
<a id="30.39.pr."></a>
**序言**　若遗赠的奴隶正在逃亡，或者远在他处而受遗赠人请求交付，继承人应尽力寻获该奴隶并予以交付；尤利安即如此写道。尤利安在《书信集》第二十卷中援引阿非利卡努斯，询问继承人是否应为此支出费用；阿非利卡努斯认为应由继承人负担这项费用。我也认为应采纳此说。

<!-- source-p 170 -->
<a id="30.39.1"></a>
**1**　请求中应计入的孳息，并非继承人实际收取的孳息，而是受遗赠人本可收取的孳息。奴隶的劳务、役畜的运输服务以及船舶的运费，也应作相同处理。关于孳息的规则，同样适用于城市房屋的租金。利息数额则应遵循当地惯例，因此由审判官评定并确定利息标准。继承人也应赔偿该物在迟延后灭失的价值，正如要式口约中，若标的物在债务人迟延后灭失，债务人须给付其估价。除此之外，若遗赠的是女奴，继承人还应给付其所生子女；若遗赠的是奴隶，继承人也应给付该奴隶所取得的遗产、遗赠或其他一切财产。

<!-- source-p 171 -->
<a id="30.39.2"></a>
**2**　若提图斯向我买下一物，在我尚未交付该物之前又将同一物遗赠给我，而后我将该物交付给他并收取价款，乍看之下，他遗赠给我的似乎是我自己的物，因此遗赠并未成立。但若我因遗赠而免于买卖之诉，我当然可以依据遗赠请求返还已经交付的该物。若价款尚未付给我，尤利安写道，我可以提起卖方之诉以追索价款；也可以依据遗嘱，请求取回我已出售并交付的物。他接着说，若价款已付给我、但我尚未交付该物，则我提起遗嘱之诉可以获得解除交付义务的效果。

<!-- source-p 172 -->
<a id="30.39.3"></a>
**3**　同一尤利安还写道，若立遗嘱人将其从他人处买来的庄园遗赠给我，而该物尚未交付给死者或其继承人，则应强制继承人向我提供买卖诉权。

<!-- source-p 173 -->
<a id="30.39.4"></a>
**4**　若某人遗赠给他人开采石料的权利，曾有人询问这项遗赠是否也转移给受遗赠人的继承人。马尔切鲁斯否认可以转移给继承人，除非遗赠中同时写明继承人。

<!-- source-p 174 -->
<a id="30.39.5"></a>
**5**　继承人必须为遗赠的土地缴纳已到期的地租或土地税、地面使用费、排污费以及供水设施费用。

<!-- source-p 175 -->
<a id="30.39.6"></a>
**6**　我知道曾有人依据一项事实讨论此问题：某人拥有两处同名庄园，遗嘱遗赠“科尔内利乌斯庄园”；一处价高，一处价低。继承人主张遗赠的是较低价的庄园，受遗赠人则主张较高价的。通常的看法是，若受遗赠人不能证明遗赠的是较高价的庄园，就应认定遗赠的是较低价的。

<!-- source-p 176 -->
<a id="30.39.7"></a>
**7**　公认，他人所有的物也可以被遗赠，只要能够购得即可，即便购得该物颇为困难也是如此。

<!-- source-p 177 -->
<a id="30.39.8"></a>
**8**　但若某人遗赠了属于奥古斯都的萨卢斯特花园，或供皇帝专用的阿尔巴努斯庄园，则在遗嘱中写入此类遗赠，实属疯狂。

<!-- source-p 178 -->
<a id="30.39.9"></a>
**9**　同样，显然不得遗赠战神广场、罗马广场或神庙。

<!-- source-p 179 -->
<a id="30.39.10"></a>
**10**　若遗赠凯撒的土地——此类土地已划归皇帝私产并由私产总管管理——也无须给付其估价，因为这些土地通常不得出售；未经元首命令，它们不属于可进行私法交易的财产。

<!-- source-p 180 -->
<a id="30.40"></a>
### 30.40

<!-- source-p 181 -->
乌尔比安《遗嘱信托论》第二卷

<!-- source-p 182 -->
若某物属于他人，受遗赠人又无权交易该物，而立遗嘱人通过遗嘱信托将其留给一个没有占有权的人，我认为应当给付该物的估价。
