# D.24.3 婚姻解除后如何请求返还嫁资（*Soluto matrimonio dos quemadmodum petatur*）

> 分稿范围：D.24.3 题名至 D.24.3.67；按源段落顺序逐段译出。

<!-- source-p 001; 原文导航锚点 3、题名锚点 24.3 -->
<a id="3"></a><a id="24.3"></a>**24.3.0. 婚姻解除后如何请求返还嫁资（*Soluto matrimonio dos quemadmodum petatur*）**

<!-- source-p 002 -->
<a id="24.3.1"></a>**24.3.1**

<!-- source-p 003 -->
**庞波尼乌斯：《萨宾评注》第十五卷。**

<!-- source-p 004 -->
嫁资事务始终且在任何场合都具有首要地位；因为保存妇女的嫁资也关乎公共利益，妇女有嫁资对于生育后代、充实公民共同体尤为必要。

<!-- source-p 005 -->
<a id="24.3.2"></a>**24.3.2**

<!-- source-p 006 -->
**乌尔比安：《萨宾评注》第三十五卷。**

<!-- source-p 007 -->
<a id="24.3.2.pr."></a>**序言。**婚姻解除后，应向妻子清偿嫁资。丈夫无须向最初约定受领嫁资的其他人作出返还承诺，除非这样做对丈夫没有任何不利；因为若丈夫认为这会给自己造成某种不便，就应当认为不得强迫他向妻子以外的人作出承诺。以上规则适用于妻子为自权人的情形。

<!-- source-p 008 -->
<a id="24.3.2.1"></a>**1.**如果妻子处于父权之下，且嫁资由其父亲提供，那么嫁资既属于父亲，也属于女儿。因此，父亲只有经女儿同意，才能请求返还嫁资；既不得自行请求，也不得通过代理人请求。萨宾认为，返还承诺也应按此规则作出。因此，承诺应向父亲与女儿共同指定的人作出。若只有父亲作出指定，女儿日后成为自权人时，其嫁资之诉并未被剥夺。反之，若仅依女儿的意思作出承诺，父亲的嫁资之诉仍完整保留。问题在于，父亲能否单独起诉，还是只有与女儿一同起诉才可主张？我认为，女儿参与后本可享有的诉权并未丧失。如果女儿后来成为自权人，该要式承诺则会对她发生不利效力。

<!-- source-p 009 -->
<a id="24.3.2.2"></a>**2.**父亲请求返还嫁资时，女儿的意思应如何理解：是必须表示同意，还是只要女儿不反对即可？安敦尼努斯皇帝曾作敕答：除非女儿明确反对，否则应视为她同意父亲。尤利安在《学说汇纂》第四十八卷中写道：如果父亲的女儿精神失常，父亲提起诉讼也应视为依女儿的意思行事；因为女儿因精神失常而不能反对时，人们有理由认为她同意父亲。但若女儿不在场，则应认为该行为并非依她的意思作出，并要求父亲保证女儿事后会予以追认。因为女儿神志清醒时，我们要求她知情，方可视为她没有反对。

<!-- source-p 010 -->
<a id="24.3.3"></a>**24.3.3**

<!-- source-p 011 -->
**保罗：《萨宾评注》第七卷。**

<!-- source-p 012 -->
不但请求返还父亲与女儿共有的嫁资时需要双方同意，支付这笔嫁资时也需要双方同意；任何一方都不得使另一方的处境恶化。但如果女儿已经收取的款项转而到了父亲手中，双方的嫁资之诉都将消灭。

<!-- source-p 013 -->
<a id="24.3.4"></a>**24.3.4**

<!-- source-p 014 -->
**庞波尼乌斯：《萨宾评注》第十五卷。**

<!-- source-p 015 -->
父亲未经女儿同意便向丈夫请求返还嫁资，随后又以女儿名义将同一笔嫁资交给另一名丈夫；父亲死亡后，女儿向前夫提起诉讼的，应以恶意抗辩驳回。

<!-- source-p 016 -->
<a id="24.3.5"></a>**24.3.5**

<!-- source-p 017 -->
**乌尔比安：《萨宾评注》第三十卷。**

<!-- source-p 018 -->
关于离婚发生当年应如何分配收益，有人询问：丈夫应从结婚之日，还是从土地交付给丈夫之日起计算期间？在丈夫保留收益的情形下，应以嫁资土地首次设立之日为准，也就是交付占有之日；既非以约定嫁资之日，也非以结婚之日为准。

<!-- source-p 019 -->
<a id="24.3.6"></a>**24.3.6**

<!-- source-p 020 -->
**保罗：《萨宾评注》第七卷。**

<!-- source-p 021 -->
若土地在婚前交付，则应从结婚之日起计算一年，至次年同一日届满；其后各年也依此计算，直至离婚为止。因为如果土地在婚前交付，且由此取得孳息，那么离婚时仍应返还这些孳息，仿佛它们已成为嫁资的一部分。

<!-- source-p 022 -->
<a id="24.3.7"></a>**24.3.7**

<!-- source-p 023 -->
**乌尔比安：《萨宾评注》第三十一卷。**

<!-- source-p 024 -->
<a id="24.3.7.pr."></a>**序言。**众所周知，扣除费用后剩余的部分才是孳息。斯凯沃拉认为，这既适用于丈夫支出的费用，也适用于妻子支出的费用。譬如，妻子在葡萄采收前一日将土地作为嫁资交付；丈夫随即收取葡萄后，双方离婚。斯凯沃拉不认为只应向妻子返还十一月的孳息；在计算孳息份额之前，还必须扣除费用。因此，如果丈夫在同一年也支出了费用，双方的费用应一并计算。同样，如果妻子的支出也要计入，而婚姻持续了多年，就必须将土地交付前的那段时间也计入第一年的期间。

<!-- source-p 025 -->
<a id="24.3.7.1"></a>**1.**帕比尼安在《疑难》第十一卷中说，离婚后分配孳息，不应以租赁开始之日为准，而应考虑此前妻子处于婚姻关系中的期间。譬如，土地在葡萄采收季作为嫁资交付，丈夫自十一月一日起将其出租以供耕作；若次年一月三十一日离婚，丈夫既保留葡萄收成，又保留该年度四分之一租金，并不公平。否则，如果葡萄收完次日就离婚，丈夫便会保留全部孳息。因此，若在一月底离婚，且婚姻已持续四个月，就应将葡萄收成与当年应收租金的四分之一合并计算，再从该款项中留给丈夫三分之一。

<!-- source-p 026 -->
<a id="24.3.7.2"></a>**2.**反过来也应适用同一规则：妻子收完葡萄后立即将土地作为嫁资交给丈夫，丈夫自三月一日起将土地出租，次年四月一日离婚的，丈夫保留的不能仅是十二分之一的租金；而应按照该土地作为嫁资的全部期间所占比例，从应收租金中保留相应份额。

<!-- source-p 027 -->
<a id="24.3.7.3"></a>**3.**同样，如果离婚当年的收成依租约应归佃户所有，那么即使在葡萄收成前婚姻已经解除，也仍应将该笔收成款连同对未来收成的预期一并计入。

<!-- source-p 028 -->
<a id="24.3.7.4"></a>**4.**由此可见，妻子在结婚前收取的孳息，不应纳入分配计算。

<!-- source-p 029 -->
<a id="24.3.7.5"></a>**5.**对于赠与财物，以及离婚后收取的孳息中被取走的财物，可以进行抵销。

<!-- source-p 030 -->
<a id="24.3.7.6"></a>**6.**关于一年期间的规则，也可以适用于六个月；例如在灌溉地，一年可收获两次孳息。

<!-- source-p 031 -->
<a id="24.3.7.7"></a>**7.**同一规则也可以适用于数年，例如轮伐林地。

<!-- source-p 032 -->
<a id="24.3.7.8"></a>**8.**如果农地租约规定，除年度租金外，五年期满时还须另行给付一笔款项，那么对于这笔额外款项，应按五年期间计算。

<!-- source-p 033 -->
<a id="24.3.7.9"></a>**9.**不但土地如此，牲畜也适用同一规则；羊毛以及牲畜所生的幼畜均应给付。否则，若丈夫在母羊即将产羔时将其作为嫁资受领，另有一些又即将剪毛；随后母羊产羔并剪毛，紧接着便离婚，难道丈夫就不必返还任何东西吗？在此情形中，我们也应按照照料牲畜的整个期间计算，而非仅按实际收取孳息的时点计算。

<!-- source-p 034 -->
<a id="24.3.7.10"></a>**10.**奴隶的劳务也按年度计算；例如其劳务以一年为期出租的，离婚前已经经过期间的劳务归丈夫，离婚后的劳务则归妻子。

<!-- source-p 035 -->
<a id="24.3.7.11"></a>**11.**城市土地的租金，也适用农村土地孳息的同一规则。

<!-- source-p 036 -->
<a id="24.3.7.12"></a>**12.**如果妻子将土地作为嫁资交给丈夫，而丈夫砍伐了该土地上的树木，那么，若这些树木被视为孳息，就应按年度比例返还。我认为，如果这些树木属于可定期砍伐的树木，或是围绕建筑物生长的树木，应当认为其计入孳息；否则，丈夫应因使土地状况恶化而承担责任。但即使树木因风暴而倒下，也应认为其价款须返还给妻子，且不计入孳息；这与发现宝藏相同：宝藏不计入孳息，而应将其一半返还给妻子，仿佛是在他人土地上发现的财物。

<!-- source-p 037 -->
<a id="24.3.7.13"></a>**13.**若丈夫在妻子的嫁资土地上发现大理石采石场，使土地更有收益，那么，已经开采但尚未运走的大理石归丈夫所有，妻子也无须偿付相关费用，因为大理石不属于孳息；除非该类石料能够再生，例如高卢和亚洲的某些采石场。

<!-- source-p 038 -->
<a id="24.3.7.14"></a>**14.**但是，若土地中有黏土矿、银矿、金矿或其他矿产，或有砂矿，这些都应计入孳息。

<!-- source-p 039 -->
<a id="24.3.7.15"></a>**15.**有时，丈夫就孳息向妻子提供担保；若妻子收回土地时孳息仍然附着于土地，丈夫便无须保留任何孳息。有时，丈夫只保留而不返还；也就是说，他所保留的并未超过其按份额应得的数额。还有时，若他收取的超过应保留的份额，就必须返还超出部分。若就嫁资向岳父或任何一方的继承人提起诉讼，也适用同一规则。

<!-- source-p 040 -->
<a id="24.3.7.16"></a>**16.**庞波尼乌斯说，为取得孳息而支出的费用，包括耕地、播种的费用，以及维修建筑物或照料患病奴隶的费用；当然，前提是建筑物或奴隶能够产生某种孳息。但是，如果丈夫保留了整年的全部孳息，就不得再请求偿还这些费用，因为应先从孳息中扣除先前支出的费用。显然，如果他为必要目的新建一座别墅，或在无过错的情况下重建一座完全倒塌的旧别墅，则可以请求偿还这类费用；开垦葡萄园也是如此。因为这些费用用于必要或有益之事，并使丈夫取得诉权。

<!-- source-p 041 -->
<a id="24.3.8"></a>**24.3.8**

<!-- source-p 042 -->
**保罗：《萨宾评注》第七卷。**

<!-- source-p 043 -->
<a id="24.3.8.pr."></a>**序言。**作为嫁资给付的土地上若有采石场，众所周知，采石场带来的利益归丈夫；因为显然，妻子交付土地时即有意使该收益归丈夫，除非她在给付嫁资时表明了相反的意思。

<!-- source-p 044 -->
<a id="24.3.8.1"></a>**1.**若播种所支出的费用没有带来收成，应从葡萄收成中扣除，因为整年只产生一项孳息。

<!-- source-p 045 -->
<a id="24.3.9"></a>**24.3.9**

<!-- source-p 046 -->
**庞波尼乌斯：《萨宾评注》第十卷。**

<!-- source-p 047 -->
如果妻子造成迟延，以致丈夫无法收回嫁资，那么丈夫对此仅就欺诈承担责任，而不就过失承担责任；否则，妻子的行为会迫使他永久耕种她的土地。不过，已经归丈夫取得的孳息仍应返还。

<!-- source-p 048 -->
<a id="24.3.10"></a>**24.3.10**

<!-- source-p 049 -->
**庞波尼乌斯：《萨宾评注》第十五卷。**

<!-- source-p 050 -->
<a id="24.3.10.pr."></a>**序言。**如果一名已婚女儿被敌人俘获，并在那里死亡，而她的嫁资由父亲提供，我认为，应按她在婚姻存续期间死亡的情形处理全部事项；因此，即使女儿当时已不处于父亲的权力之下，由父亲提供的嫁资也应返还给父亲。

<!-- source-p 051 -->
<a id="24.3.10.1"></a>**1.**普罗库鲁斯说，如果丈夫杀害妻子，应将嫁资之诉交给妻子的继承人；这一意见是正确的，因为不应允许丈夫因自己的犯罪而期待取得嫁资利益。反过来的情形也应作同样处理。

<!-- source-p 052 -->
<a id="24.3.11"></a>**24.3.11**

<!-- source-p 053 -->
**庞波尼乌斯：《萨宾评注》第十六卷。**

<!-- source-p 054 -->
如果妻子明知财物属于他人仍将其作为嫁资给付，就应将该物返还给她，仿佛该物原本属于她一样；此外，还应按离婚发生当年的年度比例返还孳息。

<!-- source-p 055 -->
<a id="24.3.12"></a>**24.3.12**

<!-- source-p 056 -->
**乌尔比安：《萨宾评注》第三十六卷。**

<!-- source-p 057 -->
众所周知，丈夫应在其力所能及的范围内被判令承担责任；但是，这项规则不适用于其继承人，

<!-- source-p 058 -->
<a id="24.3.13"></a>**24.3.13**

<!-- source-p 059 -->
**保罗：《萨宾评注》第七卷。**

<!-- source-p 060 -->
因为这项利益具有人身专属性，并随本人死亡而消灭。

<!-- source-p 061 -->
<a id="24.3.14"></a>**24.3.14**

<!-- source-p 062 -->
**乌尔比安：《萨宾评注》第三十六卷。**

<!-- source-p 063 -->
<a id="24.3.14.pr."></a>**序言。**辩护人的责任则不同；人们认为，只要其向妻子给付的金额达到妻子直接起诉丈夫本可取得的数额，就足以视为已妥善履行辩护职责。

<!-- source-p 064 -->
<a id="24.3.14.1"></a>**1.**庞波尼乌斯在《萨宾评注》第十五卷中精当地提出疑问：如果丈夫约定自己不再仅在其力所能及的范围内承担责任，而要承担全部责任，该约定是否应遵守？他认为不应遵守；我也认为此说正确。最好认为该约定有悖善良风俗，因为它显然违背了应当给予丈夫的既有尊重。

<!-- source-p 065 -->
<a id="24.3.15"></a>**24.3.15**

<!-- source-p 066 -->
**保罗：《萨宾评注》第七卷。**

<!-- source-p 067 -->
<a id="24.3.15.pr."></a>**序言。**应以判决作出时为准，考察丈夫在多大范围内具有履行能力。

<!-- source-p 068 -->
<a id="24.3.15.1"></a>**1.**即使丈夫的继承人被判令承担全部责任，涉及金钱事务的抵销仍对其有利，从而减少其债务；例如因赠与财物、被取走的财物以及支出费用而产生的抵销。但关于婚姻行为的惩戒规则并不适用于他。

<!-- source-p 069 -->
<a id="24.3.15.2"></a>**2.**儿媳就嫁资向岳父起诉时，岳父也应享有同样的优待，即仅在其力所能及的范围内被判令承担责任，

<!-- source-p 070 -->
<a id="24.3.16"></a>**24.3.16**

<!-- source-p 071 -->
**庞波尼乌斯：《萨宾评注》第十六卷。**

<!-- source-p 072 -->
因为岳父居于父亲的地位。

<!-- source-p 073 -->
<a id="24.3.17"></a>**24.3.17**

<!-- source-p 074 -->
**保罗：《萨宾评注》第七卷。**

<!-- source-p 075 -->
<a id="24.3.17.pr."></a>**序言。**反过来说，如果岳父因丈夫作出的允诺而被起诉，是否也应给予他同样的优待，通常会成为问题。涅拉提乌斯在《格言集》中以及普罗库鲁斯均认为，这样做是公正的。

<!-- source-p 076 -->
<a id="24.3.17.1"></a>**1.**同样，如果妻子因允诺而被起诉，较为可取的意见是应当通过抗辩保护她；普罗库鲁斯也持此说：正如她曾是合伙人时应给予她抗辩一样，即使依市民法她负有债务，也应给予她抗辩。

<!-- source-p 077 -->
<a id="24.3.17.2"></a>**2.**如果审理嫁资诉讼的法官因不知法律而错误地判令丈夫承担全部责任，涅拉提乌斯和萨宾认为，他应当援用诈欺抗辩，并可据此免受不利后果。

<!-- source-p 078 -->
<a id="24.3.18"></a>**24.3.18**

<!-- source-p 079 -->
**庞波尼乌斯：《萨宾评注》第十六卷。**

<!-- source-p 080 -->
<a id="24.3.18.pr."></a>**序言。**拉贝奥说，妻子的儿子若继承其父亲，也应仅在其力所能及的范围内被判令承担责任。

<!-- source-p 081 -->
<a id="24.3.18.1"></a>**1.**丈夫对嫁资财物不仅须就诈欺负责，也须就过失负责；然而，在嫁资诉讼中考察他是否有能力履行时，只计入诈欺，因为在管理其自身事务时，不应要求他承担过失责任。不过，我认为，只有他为了对付妻子而实施的诈欺，才会使他在无履行能力时承受不利后果；其他任何诈欺均不在此列。奥菲利乌斯则说，如果嫁资财物因丈夫的诈欺而灭失，而他本来已无清偿能力，即使他并未以诈欺使自己陷于无清偿能力，也应就该嫁资财物判令其承担责任，犹如其诈欺导致他无力履行一样。至于嫁资财物灭失一事，若丈夫既无恶意诈欺，也无过失，则仅须向妻子提供他作为丈夫因该事由所享有的诉权，例如盗窃之诉或不法损害之诉。

<!-- source-p 083 -->
**乌尔比安：《萨宾评注》第三十六卷。**

<!-- source-p 084 -->
如果妻子离开丈夫，且嫁资诉讼已经进入诉讼系属状态后又返回婚姻关系，那么婚姻关系恢复后，该诉讼即告终止，一切仍维持原状。

即使妻子在婚姻关系存续期间收取嫁资，并非为了偿还债务或购买适宜的土地，而是为了照顾她与另一男子所生且生活窘迫的子女、兄弟或父母，或者为了赎回被敌人俘虏的亲属，由于此种理由正当且合乎诚信，不能认为她不当收取，因此向她给付是适当的；家女也同样适用这一规则。

<a id="24.3.21"></a>**24.3.21**

<!-- source-p 089 -->
**乌尔比安：《论争论》第三卷。**

<!-- source-p 090 -->
如果丈夫从嫁资中支出款项，是为了使妻子的必要亲属免遭强盗拘押，或者为了使妻子替其必要亲属中的某人脱离束缚，那么无论该支出仅占嫁资的一部分，还是耗尽全部嫁资，都应将该支出计入妻子的应得额；若支出的是全部嫁资，嫁资诉讼即告消灭。更应如此的是，如果岳父提起嫁资诉讼，就应当考虑为岳父本人所作的支出，无论是丈夫亲自支出的，还是交给女儿让她支出的。即使并非父亲起诉，而是父亲死后女儿独自请求返还嫁资，也应作同样处理。因为嫁资诉讼与其他诚信诉讼一样，内含诈欺抗辩；因此，如塞尔苏斯所见，可以认为该项支出也包含在嫁资诉讼之中，尤其是在该支出经女儿同意作出的情况下。

<!-- source-p 091 -->
<a id="24.3.22"></a>**24.3.22**

<!-- source-p 092 -->
**乌尔比安：《告示评注》第三十三卷。**

<!-- source-p 093 -->
<a id="24.3.22.pr."></a>**序言。**如果父亲或第三人为女子给付嫁资时，仅就一种情形约定返还——即婚姻解除或妻子死亡——那么应当说，对于未约定的另一情形，该女子仍享有诉权。

<!-- source-p 094 -->
<a id="24.3.22.1"></a>**1.**婚姻解除后，家女未经父亲同意而耗用共同嫁资的，无论女儿尚在世还是已经死亡，父亲仍享有诉权，得请求将嫁资给付给自己。只有在给付后嫁资将被耗尽的情形下，这一规则才是正确的；反之，如果给付不会导致嫁资被耗尽，且给付具有正当理由，则诉权不再存在。父亲死亡后，其继承人和该女子均不得起诉。

<!-- source-p 095 -->
<a id="24.3.22.2"></a>**2.**婚姻解除后，妻子因受欺骗而通过更新债务的方式接受一个无力清偿嫁资债务的人作为债务人，她仍保有嫁资诉权。

<!-- source-p 096 -->
<a id="24.3.22.3"></a>**3.**父亲在女儿缺席时提起嫁资诉讼，即使未提供关于事后追认的担保，也应拒绝女儿的诉权；无论女儿后来继承了父亲的遗产，还是仅通过遗赠取得足以抵偿嫁资的财产，均是如此。尤利安在多处都写道，父亲所给付的财产应在女儿的嫁资请求中予以抵销，并计入女儿的利益；如果她从父亲处取得的数额已等同于丈夫——即向父亲给付嫁资者——应当向她给付的嫁资数额，更应如此。

<!-- source-p 097 -->
<a id="24.3.22.4"></a>**4.**如果父亲因在罗马被判处刑罚而不得居留，女儿应获得足额嫁资；但她须承诺父亲将追认该诉讼行为。

<!-- source-p 098 -->
<a id="24.3.22.5"></a>**5.**女儿应在争讼程序确定之时同意父亲起诉。因此，如果女儿表示同意父亲起诉，却在争讼程序确定前改变主意，或者已经脱离父权，父亲的起诉即属徒劳。

<!-- source-p 099 -->
<a id="24.3.22.6"></a>**6.**我们也赞同拉贝奥的意见：有时应拒绝父亲的诉权，如果父亲的品行如此卑劣，以至于令人担心他取得嫁资后会将其耗尽。因此应由法官介入，以妥善照顾女儿和父亲双方的利益。如果女儿藏匿起来，是为了避免被迫同意这样一位父亲起诉，我认为可以在查明事实后给予父亲诉权。因为，如果女儿只是出于羞怯，才在父亲不在场时表示反对，为什么不能说不应给予父亲诉权？另一方面，如果父亲无论如何都值得女儿同意，也就是说，他一向品行端正，而女儿轻率放荡、年纪尚轻，或者对不值得敬重的丈夫过分偏袒，那么应当说，裁判官更应采纳父亲的意见并给予其诉权。

<!-- source-p 100 -->
<a id="24.3.22.7"></a>**7.**我们来讨论婚姻关系存续期间，丈夫或妻子开始精神失常时应当如何处理。毫无疑问，应遵守这样的规则：陷于精神失常、因而丧失辨识能力的一方，不能发出离婚通知。至于是否可以与其离婚，则须进一步考察。如果精神失常时有清醒间歇，或者虽属持续性疾病，但与其共同生活的人尚可忍受，那么在任何情况下都不应解除婚姻；如果在本人神志清醒时，另一方已如前述向精神失常者发出离婚通知，则该人应知婚姻因自己的过错而解除。因为还有什么比让妻子分担丈夫或让丈夫分担妻子遭遇的偶然不幸更合乎人道呢？但如果精神失常极其严重，狂暴而有害，完全看不到恢复健康的希望，对照护人员也极为危险，或许另一方因精神失常者的暴烈而困扰，或因没有子女而希望生育，那么神志健全的一方可以向精神失常者发出离婚通知，使婚姻的解除不归咎于任何一方，也不使任何一方遭受损失。

<!-- source-p 101 -->
<a id="24.3.22.8"></a>**8.**如果妻子处于极其严重的精神失常状态，丈夫虽不愿以诡计解除婚姻，却漠视妻子的不幸，对她毫无怜悯，显然也不为她提供适当照料，反而侵用嫁资，那么应允许精神失常妻子的监护人或亲属向有管辖权的法官申请，责令丈夫承担妻子全部必要的供养费用、提供生活资料、为其提供医疗救助，并且不得遗漏丈夫依嫁资数额应为妻子办理的任何事项。反之，如果显然丈夫将会挥霍嫁资，以至于其行为不合正派人的行事方式，那么应将嫁资交由第三人保管，使妻子及其家属得以从中获得适当供养；婚姻开始时双方订立的嫁资约款仍维持效力，并等待另一方康复或死亡的结果。

<!-- source-p 102 -->
<a id="24.3.22.9"></a>**9.**同样，精神失常者的父亲可以有效请求将嫁资返还给自己或其女儿；虽然精神失常者本人不能发出离婚通知，但其父亲显然可以。

<!-- source-p 103 -->
<a id="24.3.22.10"></a>**10.**婚姻解除后，如果父亲精神失常，其监护人可以依女儿的意思请求返还嫁资；如果没有监护人可用，则应允许女儿起诉，并应要求她提供关于事后追认的担保。

<!-- source-p 104 -->
<a id="24.3.22.11"></a>**11.**父亲被敌人俘虏时，也应作同样裁定，即应允许女儿提起请求返还嫁资之诉。

<!-- source-p 105 -->
<a id="24.3.22.12"></a>**12.**现在转到这一问题：嫁资诉权可以向哪些人提起。显然，可以向丈夫本人提起，无论嫁资是给付给他本人，还是经丈夫同意给付给他人；该受领人无论受丈夫支配与否，均不影响此结论。但是，如果丈夫是家子，嫁资又给付给岳父，则应向岳父起诉。确实，如果嫁资是经岳父命令给付给家子的，岳父仍应无条件承担责任；但如果嫁资未经父亲命令而给付给家子，萨宾和卡西乌斯答复说，仍应向父亲起诉：因为嫁资被视为已归父亲取得，毕竟家子所占有的是由父亲掌管的特有财产。不过，判令父亲承担责任，以其特有财产中的现有财物，或者以用于父亲事务的财物为限。如果嫁资给付给岳父，则除非女儿继承了父亲的遗产，否则不能向丈夫起诉。

<!-- source-p 106 -->
<a id="24.3.22.13"></a>**13.**如果女子误以为丈夫具有自由人身份，实际丈夫却是奴隶，应当允许该女子在丈夫的财产上享有类似特权的优先地位。也就是说，如果还有其他债权人，在特有财产之诉中该女子应居于优先；但如果该奴隶对其主人负有债务，女子不得优先于主人，只有对给付为嫁资的财物或用嫁资购得的财物，才应优先对待，仿佛这些财物也属于嫁资。

<a id="24.3.24"></a>**24.3.24**

<!-- source-p 111 -->
**乌尔比安：《告示评注》第三十三卷。**

<!-- source-p 112 -->
<a id="24.3.24.pr."></a>**序言。**如果婚姻关系存续期间，妻子因丈夫贫困而想要起诉，我们应从何时起算其请求返还嫁资的起点？人们一致认为，自丈夫财力显然不足以返还嫁资之时起，妻子即享有请求返还嫁资的诉权。

<!-- source-p 113 -->
<a id="24.3.24.1"></a>**1.**如果妻子在丈夫被剥夺继承权后起诉，较为可取的意见是，自父亲的遗产被接受之日起，她开始享有请求返还嫁资之权。

<!-- source-p 114 -->
<a id="24.3.24.2"></a>**2.**凡妻子须提供担保，保证在一定期限届满后返还嫁资，而丈夫无力提供该担保时，应扣除期限利益后，就剩余部分立即判决；但是，如果丈夫有能力提供担保却拒绝提供，梅拉说，应判令其承担全部责任，不考虑期限利益。因此，依职权法官应当要么在丈夫提供担保后判其免责，要么考虑期限利益扣减后判其承担责任；如今后一种做法更为通行。若妻子表示宁愿承受延期，也不愿因立即履行而作扣减，不应准许。

<!-- source-p 115 -->
<a id="24.3.24.3"></a>**3.**无论嫁资风险由丈夫还是妻子承担，丈夫均应在法定期限内给付。

<!-- source-p 116 -->
<a id="24.3.24.4"></a>**4.**如果丈夫经妻子同意释放嫁资奴隶为自由人：若妻子意在赠与，则丈夫不负担为释放而附加的给付义务；但如果双方就此进行的是事务安排，丈夫当然须承担责任，并应依照法官的职权作出担保：凡其从获释者的财产或其义务中取得的利益，均将返还给妻子。

<!-- source-p 117 -->
<a id="24.3.24.5"></a>**5.**如果丈夫对嫁资奴隶十分残酷，应考察能否据此起诉他。如果他只对妻子的奴隶残酷，确认其应就此承担责任；如果他天性如此，对自己的奴隶也同样残酷，仍应说，本诉可以制止其过度残酷。虽然妻子对他仅能要求他以管理自己事务时同样的注意程度行事，不能要求更多；但是，在对待自有奴隶时应受谴责的残酷行为，在对待他人奴隶时则应予以制止，也就是说，在对待嫁资奴隶时应予制止。

<!-- source-p 118 -->
<a id="24.3.24.6"></a>**6.**如果妻子将丈夫的财物借用给他人，该物灭失，应考察她能否就此主张抵销。我认为，如果丈夫曾禁止她出借，应立即扣除相应数额；如果他未禁止，则应由法官裁量，给予她适当期限，并要求她提供担保。

<!-- source-p 119 -->
<a id="24.3.24.7"></a>**7.**如果妻子的财产有一部分被没收，她仍可请求返还嫁资中相应的其余部分；我认为还应进一步说，即使嫁资有一部分在争讼程序确定后才被没收，也只须由法官裁量，就该部分作出判决。如果全部嫁资均被没收，诉讼即告终止。

<a id="24.3.25"></a>**24.3.25**

<!-- source-p 121 -->
**保罗：《告示评注》第三十六卷。**

<!-- source-p 122 -->
<a id="24.3.25.pr."></a>**序言。**如果嫁资未经父亲命令而给付给家子，可以提起特有财产之诉；但是，无论是家子支出费用，还是家子赠与财物，或妻子取走特有财产中的财物，由于父亲基于家子的身份享有诉权，特有财产的数额都会相应增加；因此，应将特有财产中的全部财物交付给妻子，因为妻子仍享有应受偿的债权。

<!-- source-p 123 -->
<a id="24.3.25.1"></a>**1.**丈夫返还嫁资时，应就诈欺和过失提供担保。如果他以诈欺方式使自己不能返还，应按照妻子在诉讼中宣誓确定的数额判令其承担责任，因为未经我们同意，任何人都不应留置我们的财物。

<!-- source-p 124 -->
<a id="24.3.25.2"></a>**2.**如果离婚后嫁资财物变得较差，而丈夫迟延返还嫁资，则无论如何均由丈夫承担损失。

<!-- source-p 125 -->
<a id="24.3.25.3"></a>**3.**如果嫁资奴隶中有人逃跑，丈夫应担保将依善良家父的判断追捕并交还他们。

<!-- source-p 126 -->
<a id="24.3.25.4"></a>**4.**如果丈夫将土地出租五年，例如在第一年之后发生离婚，萨宾说，只有妻子担保：凡丈夫除第一年租赁之外还被判令给付的，她均将予以承担，土地才应返还给妻子；妻子也应担保，将丈夫因第一年之后的租赁所取得的一切利益返还给他。

<a id="24.3.30.pr."></a>**序言。**妻子不因再婚而丧失向前夫请求嫁资的权利。

<!-- source-p 143 -->
<a id="24.3.30.1"></a>**1.**每当因丈夫的过错，导致嫁资无法向岳父或其他任何代表妻子作出嫁资允诺的人请求返还时，如果女儿在婚姻关系存续期间死亡，或者成为家母后指定该允诺人为继承人，可以确认，丈夫无须承担更多责任，只须使这些人免于债务关系。

<!-- source-p 144 -->
<a id="24.3.31"></a>**24.3.31**

<!-- source-p 145 -->
**尤利安：《学说汇纂》第十八卷。**

<!-- source-p 146 -->
<a id="24.3.31.pr."></a>**序言。**如果丈夫因公诉而被判刑，其部分财产被没收，国库必须清偿其债权人；妻子也属于这些债权人。

<!-- source-p 147 -->
<a id="24.3.31.1"></a>**1.**如果父亲以女儿嫁资为名允诺二百，并约定不得向自己请求超过一百；婚姻解除后提起诉讼时，约定不予请求的一百不被视为嫁资。但如果父亲死亡后，丈夫开始向其继承人起诉，则该笔款项也属于嫁资。

<!-- source-p 148 -->
<a id="24.3.31.2"></a>**2.**如果依女儿的意思，父亲指定的代理人就嫁资使诉讼系属成立，且判决有利于该代理人，而父亲此后死亡，应当将判决之诉权给予女儿，而不是父亲的继承人。

<!-- source-p 149 -->
<a id="24.3.31.3"></a>**3.**如果嫁资给付给父亲，而父亲的儿子被指定为附条件的部分继承人；条件尚未成就时，其他共同继承人已按各自份额向妻子给付嫁资，那么该儿子应从嫁资中少给付相应数额，因为他对共同继承人并无请求返还该笔款项的诉权。

<!-- source-p 150 -->
<a id="24.3.31.4"></a>**4.**如果妻子收回嫁资土地时，未按其未处于婚姻关系中的那一年占全年比例计算收益，她仍可提起嫁资诉讼，因为她取得的嫁资较少。这属于嫁资的增加，正如她未取得女奴所生子女，或者嫁资奴隶在离婚后为丈夫取得的遗赠或继承一样。〔底本文字异常：本段末尾拉丁文“fuissententiarum”疑为相邻文字误连；此处据可辨语义译出。〕

<!-- source-p 151 -->
<a id="24.3.32"></a>**24.3.32**

<!-- source-p 152 -->
**尤利安：《致乌尔塞乌斯·费罗克斯》第二卷。**

<!-- source-p 153 -->
如果前夫以妻子债务人的身份，向后夫允诺给付嫁资，则作为嫁资的数额不得超过前夫所能履行的范围。

<!-- source-p 154 -->
<a id="24.3.33"></a>**24.3.33**

<!-- source-p 155 -->
**阿非利卡努斯：《疑问集》第七卷。**

<!-- source-p 156 -->
一名女子以嫁资为名允诺给付一笔确定的金钱，并安排若干人为要式承诺受领人，约定婚姻解除时向他们支付嫁资的一部分。她未实际给付任何嫁资便死亡，并指定其丈夫为继承人；丈夫接受了负债超过资产的遗产。尽管如此，他仍须对要式承诺受领人承担责任，因为他接受债务人的遗产，就被视为已经将债务与自身利益一并衡量；遗产无力清偿并不影响此结论，因为他对其他债权人同样负有责任。

<!-- source-p 157 -->
<a id="24.3.34"></a>**24.3.34**

<!-- source-p 158 -->
**阿非利卡努斯：《疑问集》第八卷。**

<!-- source-p 159 -->
提提娅与塞尤斯离婚。提提乌斯称她仍受其父权支配，并请求将嫁资返还给自己；她则称自己是家母，并打算就嫁资起诉。有人询问法官应如何处理。我答复：除非父亲证明女儿不仅仍受其父权支配，而且同意由父亲起诉，否则应拒绝父亲的诉权；即使已经确定女儿受其父权支配，也应作同样处理。

<!-- source-p 160 -->
<a id="24.3.35"></a>**24.3.35**

<!-- source-p 161 -->
**马尔基安努斯：《法学阶梯》第十卷。**

<!-- source-p 162 -->
经保护人同意离开的自由女奴，可以就保护人给付给她的嫁资向保护人起诉。

<!-- source-p 163 -->
<a id="24.3.36"></a>**24.3.36**

<!-- source-p 164 -->
**保罗：《论通奸》第二卷。**

<!-- source-p 165 -->
如果丈夫仅有有限的履行能力，而嫁资又已被没收，丈夫应在其力所能及的范围内对国库承担责任，以免妻子因丈夫破产而受到惩罚。

<!-- source-p 166 -->
<a id="24.3.37"></a>**24.3.37**

<!-- source-p 167 -->
**乌尔比安：《答复集》第二卷。**

<!-- source-p 168 -->
如果女儿没有反对父亲的理由，尤其是父亲后来又以更大数额为她给付嫁资，那么应认为父亲是经女儿同意而收回嫁资的。

<!-- source-p 169 -->
<a id="24.3.38"></a>**24.3.38**

<!-- source-p 170 -->
**马尔凯卢斯：《答复集》单卷本。**

<!-- source-p 171 -->
卢基乌斯·提提乌斯是家子，经父亲同意娶梅维娅为妻，嫁资由父亲受领。梅维娅向提提乌斯发出离婚通知。后来，父亲在儿子缺席时，以儿子的名义同梅维娅订立婚约。此后梅维娅又解除婚约，并嫁给他人。我询问：如果梅维娅向其前夫卢基乌斯·提提乌斯以及作为父亲继承人的人请求嫁资，并证明婚姻因她的过错而解除，丈夫能否以妻子的过错为由保留嫁资？马尔凯卢斯答复：即使提提乌斯作为父亲的继承人被起诉，只要他未同意订立婚约，仍应因妻子的过错而对她施以惩罚。

<!-- source-p 172 -->
<a id="24.3.39"></a>**24.3.39**

<!-- source-p 173 -->
**帕皮尼安：《疑问集》第十一卷。**

<!-- source-p 174 -->
丈夫和妻子相互指责对方品行不端，裁定双方均构成离婚事由。对此应理解为：双方均不得依据彼此都违反的规则获得制裁；因为相同的过错通过相互抵销而归于消灭。

<!-- source-p 175 -->
<a id="24.3.40"></a>**24.3.40**

<!-- source-p 176 -->
**帕皮尼安：《疑问集》第二十八卷。**

<!-- source-p 177 -->
嫁资给付且婚姻缔结后，父亲未经女儿同意作出要式承诺，约定婚姻因离婚解除时返还嫁资。如果要式承诺的条件成就，而女儿此后无子女死亡，不应阻止父亲提起要式承诺之诉；但女儿尚在世并希望起诉时，应以抗辩阻却父亲的诉讼。

<!-- source-p 178 -->
<a id="24.3.41"></a>**24.3.41**

<!-- source-p 179 -->
**帕皮尼安：《疑问集》第三十七卷。**

<!-- source-p 180 -->
如果父亲不知道女儿已经离婚，仍依允诺原因支付嫁资，这笔款项不得通过非债清偿返还请求诉讼请求，而应通过嫁资诉讼请求返还。

<!-- source-p 181 -->
<a id="24.3.42"></a>**24.3.42**

<!-- source-p 182 -->
**帕皮尼安：《答复集》第四卷。**

<!-- source-p 183 -->
<a id="24.3.42.pr."></a>**序言。**为女儿给付嫁资的父亲被流放至某岛后，嫁资诉权归女儿享有。离婚后，父亲即使被判刑，如果嫁资诉权原本是经女儿同意而属于父亲，妻子也同样享有嫁资诉权。

<!-- source-p 184 -->
<a id="24.3.42.1"></a>**1.**人们认为，妻子以善意取得的嫁资土地收益，在涉及自由身份的诉讼之前已用于妻子的必要支出，即使后来查明她原为奴隶，也不得请求返还。至于在当时被认为属于嫁资的土地上所作必要和有益支出，应先抵销已取得的收益；若仍有超额，宜留待最终结算时处理。

<!-- source-p 185 -->
<a id="24.3.42.2"></a>**2.**女儿在婚姻关系存续期间死亡后，父亲依要式承诺请求已支付嫁资的利息；女婿则曾就尚未给付的允诺嫁资约定利息。只有在女婿以自己的支出供养妻子的情况下，才可正当地以应付金额相互抵销；否则，如果妻子是由父亲出资供养，则以空洞的利息约定主张抵销并无帮助。

<!-- source-p 186 -->
<a id="24.3.42.3"></a>**3.**妻子离婚后又回到丈夫身边的，如果此前已经依据要式承诺受理诉讼，而该承诺是给付嫁资的第三人作出的，那么该诉讼并不因此终止，法官也无权据此判令丈夫免责。

<!-- source-p 187 -->
<a id="24.3.43"></a>**24.3.43**

<!-- source-p 188 -->
**斯凯沃拉：《疑问集》第二卷。**

<!-- source-p 189 -->
如果丈夫仅在其力所能及的范围内被判令承担责任，而现有债权凭据的金额恰与嫁资数额相等且没有更多财产，他就必须将这些债权诉权让与妻子。

<!-- source-p 190 -->
<a id="24.3.44"></a>**24.3.44**

<!-- source-p 191 -->
**保罗：《疑问集》第五卷。**

<!-- source-p 192 -->
<a id="24.3.44.pr."></a>**序言。**如果岳父被女婿指定为继承人并接受了遗产，内尔瓦和卡托答复说，父亲死亡后，女儿得向其继承人请求嫁资；阿里斯托在庞波尼乌斯《学说汇纂》第五卷中记载了这一答复，并在该处表示赞同阿里斯托。因此我也会说，即使父亲已使女儿脱离父权，父亲本人也可以被起诉。

<!-- source-p 193 -->
<a id="24.3.44.1"></a>**1.**卢基乌斯·提提乌斯以其女儿名义向盖乌斯·塞尤斯允诺一百作为嫁资。盖乌斯·塞尤斯与该女子之父卢基乌斯·提提乌斯约定，只要卢基乌斯·提提乌斯尚在世，丈夫不得请求嫁资。后来因丈夫的过错而离婚，婚姻解除；女子之父死亡时指定其他人为继承人，并剥夺女儿的继承权。我询问：丈夫将把嫁资返还给妻子，能否向岳父的继承人请求嫁资？我答复：既然女儿在父亲指定其他人为继承人后，已经取得请求返还自己嫁资的诉权，丈夫就必须向她给付已经收回的嫁资，或者向她提供相应诉权。岳父的继承人不得对他主张任何抗辩；说丈夫因不把嫁资返还给自己而是返还给他人便属诈欺，实在荒谬。否则，如果婚姻是在父亲死亡后、嫁资尚未收回时解除，丈夫也会被排除在请求嫁资之外，而这不可接受。即使女儿仅按份额继承父亲，也应由丈夫按其应继份额向共同继承人请求嫁资，再返还给妻子或向她提供相应诉权。

<!-- source-p 194 -->
<a id="24.3.45"></a>**24.3.45**

<!-- source-p 195 -->
**保罗：《疑问集》第六卷。**

<!-- source-p 196 -->
外祖父盖乌斯·塞尤斯以嫁资名义，将一笔确定金额给付给受父权支配的外孙女塞娅的丈夫卢基乌斯·提提乌斯，并在嫁资文书中载入如下约定和要式承诺：“如果卢基乌斯·提提乌斯丈夫与塞娅之间的婚姻在女方无过错的情况下解除，全部嫁资应返还并交付给妻子塞娅或其外祖父盖乌斯·塞尤斯。”我询问：外祖父塞尤斯立即死亡，而塞娅后来在其仍受父权支配的父亲在世时、且本人无过错地离婚，那么根据该约定和要式承诺，诉权归谁享有，是外祖父的继承人依要式承诺享有诉权，还是外孙女享有？我答复：该要式承诺似乎是以外孙女名义无效作出的，因为记载显示，外祖父是为她作出要式承诺的。既然如此，女子离婚时，要式承诺受领人的继承人似乎享有诉权。但是，应当说可以将嫁资给付给塞娅，尽管她并不直接享有诉权；其情形犹如外祖父约定将款项给付给自己或她一样。为避免外孙女丧失嫁资利益，应允许她根据这项外祖父所订约定提起有用之诉；这是为了婚姻利益，尤其是考虑到有关当事人之间的亲属感情，才采取的救济。

<!-- source-p 197 -->
<a id="24.3.46"></a>**24.3.46**

<!-- source-p 198 -->
**保罗：《疑问集》第十九卷。**

<!-- source-p 199 -->
某人向妻子允诺嫁资，并在遗嘱中向她遗赠若干财物，但附有不得向其继承人请求嫁资的条件；妻子未能取得遗赠财物。我答复：不得拒绝妻子向继承人提起嫁资诉讼。

<!-- source-p 200 -->
<a id="24.3.47"></a>**24.3.47**

<!-- source-p 201 -->
**斯凯沃拉：《疑问集》第十九卷。**

<!-- source-p 202 -->
如果妻子因丈夫的纵容而通奸，不得从嫁资中扣留任何财物；丈夫为何要谴责他自己先前败坏、或后来认可的品行？不过，如果有人依据法律本意主张，纵容妻子通奸的丈夫不得提起控告，那么此主张应予听取。

<!-- source-p 203 -->
<a id="24.3.48"></a>**24.3.48**

<!-- source-p 204 -->
**卡利斯特拉图斯：《疑问集》第二卷。**

<!-- source-p 205 -->
如果嫁资文书载有要式承诺，约定丈夫为子女利益保留嫁资，那么为孙辈利益也应保留嫁资。

<!-- source-p 206 -->
<a id="24.3.49"></a>**24.3.49**

<!-- source-p 207 -->
**保罗：《答复集》第七卷。**

<!-- source-p 208 -->
<a id="24.3.49.pr."></a>**序言。**梅维娅将若干嫁资财物交给丈夫，其中包括一份十枚金币的债权凭据；奥塔基利乌斯曾向梅维娅承诺，待她结婚时给付一万。丈夫没有依据该凭据请求给付，因为他事实上无法请求。有人询问：如果妻子向丈夫请求嫁资，是否也应责令丈夫返还凭据中记载的该笔款项？我答复：受让诉权的人本可以起诉债务人；但如果丈夫并非因诈欺或过失而未能收回款项，则既不能以嫁资之名起诉他，也不能依据委任之诉起诉他。

<!-- source-p 209 -->
<a id="24.3.49.1"></a>**1.**一块估价后作为嫁资给付的土地，被先前的债权人基于质押原因取走。有人询问：妻子请求返还嫁资估价时，是否应受抗辩阻却？她说自己不负责任，因为父亲曾代她给付嫁资，而她并未继承父亲。保罗答复：如果丈夫既无诈欺也无过失，土地遭追夺后妻子请求其价额，则诈欺抗辩将妨碍其请求；因为允许她取得被追夺土地的价额，显然有失公允，父亲的诈欺应当由她承受其不利后果。

<!-- source-p 210 -->
<a id="24.3.50"></a>**24.3.50**

<!-- source-p 211 -->
**斯凯沃拉：《答复集》第二卷。**

<!-- source-p 212 -->
如果财物经估价后作为嫁资给付，双方约定：无论因何种原因应返还嫁资，均应返还原物，并由善良家父依增值或贬值情况作相应调整；至于已经不存在的财物，则返还最初估定的价额。有人询问：丈夫曾出售的某些财物仍然存在时，依照该约定，这些财物是否也应归妻子？我答复：仍然存在的财物，如果未经妻子同意出售，或妻子未予追认，就应当返还，犹如从未作过估价一样。

<!-- source-p 213 -->
<a id="24.3.51"></a>**24.3.51**

<!-- source-p 214 -->
**赫莫革尼安努斯：《法学撮要》第二卷。**

<!-- source-p 215 -->
即使因妻子的使用，经过估价的嫁资财物变得较差，风险仍由丈夫承担。

<!-- source-p 216 -->
<a id="24.3.52"></a>**24.3.52**

<!-- source-p 217 -->
**特里福尼努斯：《论争论》第七卷。**

<!-- source-p 218 -->
丈夫离婚后因错误而支付了自己从未收到的嫁资。他可以请求返还，因为他曾承诺该嫁资尚未支付；事实上也无法向他强制请求这笔款项。

<!-- source-p 219 -->
<a id="24.3.53"></a>**24.3.53**

<!-- source-p 220 -->
**特里福尼努斯：《论争论》第十二卷。**

<!-- source-p 221 -->
如果嫁资给付给家子，家子本人因嫁资诉讼承担责任，其父亲则依特有财产之诉承担责任；特有财产中是否包含嫁资财物或嫁资款项，并无区别。不过，家子也只应在其力所能及的范围内被判令承担责任；而他能够履行的范围，应以判决时特有财产中的财物为准。可是，如果起诉的是父亲，就应从特有财产中扣除家子欠父亲或受父亲支配之人的债务；但如果直接起诉家子，在计算其履行能力时不得扣除其他债务。

<!-- source-p 222 -->
<a id="24.3.54"></a>**24.3.54**

<!-- source-p 223 -->
**保罗：《特别法论》单卷本。**

<!-- source-p 224 -->
通常认为，丈夫有能力履行，且不扣除任何债务；合伙人、保护人或父母也同样如此。至于因赠与而被起诉的人，则应在扣除全部债务后，判断其是否有能力履行。

<!-- source-p 225 -->
<a id="24.3.55"></a>**24.3.55**

<!-- source-p 226 -->
**保罗：《普劳提乌斯评注》第五卷。**

<!-- source-p 227 -->

<a id="24.3.64"></a>**24.3.64**

<!-- source-p 253 -->
**乌尔比安：《尤利亚法与帕皮亚法评注》第七卷。**

<!-- source-p 254 -->
<a id="24.3.64.pr."></a>**序言。**但是，如果丈夫经妻子同意而为妻子处理事务，并释放嫁资奴隶为自由人，就应将其所得返还给妻子。

<!-- source-p 255 -->
<a id="24.3.64.1"></a>**1.**如果丈夫为了释放自由人而向其附加了任何给付义务，也应向妻子履行该项义务。

<!-- source-p 256 -->
<a id="24.3.64.2"></a>**2.**当然，如果自由人为丈夫提供了劳务，而这些劳务没有估价，那么就此要求丈夫向妻子给付任何款项并不公平。

<!-- source-p 257 -->
<a id="24.3.64.3"></a>**3.**但是，如果自由人在获释后又被附加了某项义务，则应将该项利益给付妻子。

<!-- source-p 258 -->
<a id="24.3.64.4"></a>**4.**如果丈夫接受了债务人或保证人，也同样应向妻子提供对其本人的债权关系。

<!-- source-p 259 -->
<a id="24.3.64.5"></a>**5.**同样，丈夫从自由人的财产中取得的任何利益，也应予以给付，但须该利益是以保护人身份取得的；如果是基于其他法律关系取得，则无须给付。丈夫并不欠妻子自由人给予他的恩惠，而只欠妻子其依保护人身份已经或本可取得的利益。当然，如果自由人指定丈夫为继承人所得超过其依法应得的份额，超出部分无须给付；如果自由人并不欠丈夫任何利益却指定他为继承人，丈夫也无须向妻子返还任何财物。

<!-- source-p 260 -->
<a id="24.3.64.6"></a>**6.**法律称丈夫应给付其所取得的利益。所谓已经取得，是指他已经收取，或者可以请求收取，因为诉权已经转归于他。

<!-- source-p 261 -->
<a id="24.3.64.7"></a>**7.**法律还补充规定，如果有人以恶意诈欺方式阻止某项利益归于丈夫，致使该利益未能归于丈夫，丈夫也应承担责任。

<!-- source-p 262 -->
<a id="24.3.64.8"></a>**8.**如果保护人剥夺其儿子的继承权，而自由人的遗产归于该保护人，应考察其继承人是否就此承担责任。既然财物既未归于保护人，也未归于其继承人，又如何能使其继承人就此承担责任呢？

<!-- source-p 263 -->
<a id="24.3.64.9"></a>**9.**该法仅提及丈夫及其继承人；法律中没有提及岳父及岳父的继承人。拉贝奥指出，这属于法律的遗漏。因此，法律未规定的情形，不应给予有用之诉。

<!-- source-p 264 -->
<a id="24.3.64.10"></a>**10.**法律所说“给付多少金钱，就给付同额金钱”，表明法律意在要求给付自由人的遗产或财产的估价，而非遗产本身；除非丈夫愿意交付原物。对这一点也应采纳较宽厚的解释。

<!-- source-p 269 -->
**雅沃勒努斯：《拉贝奥后期作品》第六卷。**

<!-- source-p 270 -->
<a id="24.3.66.pr."></a>**序言。**塞尔维乌斯说，对于丈夫持有的嫁资财物，除已支付的金钱外，丈夫应就恶意诈欺和过失负责。此说出自普布利乌斯·穆基乌斯：格拉古之妻利基尼娅的嫁资财物，在格拉古被杀的那场骚乱中灭失；穆基乌斯认为，由于该骚乱是格拉古的过错所致，应向利基尼娅赔偿。

<!-- source-p 271 -->
<a id="24.3.66.1"></a>**1.**丈夫曾给妻子的奴隶一笔款项，用作购置衣物；衣物购置后的一年内，双方即离婚。拉贝奥和特雷巴提乌斯认为，应将离婚时现存的衣物原样返还给丈夫；如果丈夫自己买下衣物再交给奴隶，也应适用同一规则。如果衣物未能返还，则丈夫可将其价额从嫁资中抵销。

<!-- source-p 272 -->
<a id="24.3.66.2"></a>**2.**家女离婚后命令将嫁资返还给父亲；其后，部分嫁资已经给付，父亲便死亡。拉贝奥和特雷巴提乌斯认为，如果剩余部分既未被转让，也未以更新债务的意思允诺给父亲，则应将该部分给付妻子；这确属正确。

<!-- source-p 273 -->
<a id="24.3.66.3"></a>**3.**你接受了经估价后作为嫁资给付的奴隶。此后双方约定，离婚时按相同估价返还这些奴隶，却未提及嫁资女奴所生子女。拉贝奥说，所生子女归你所有，因为奴隶所涉风险应由你承担。

<!-- source-p 274 -->
<a id="24.3.66.4"></a>**4.**一名女子将一百作为嫁资交由丈夫持有。离婚后，丈夫因错误而接受她就二百作出的要式承诺。拉贝奥认为，无论女子明知而多作承诺，还是出于错误，丈夫均只应偿还嫁资原有的一百；我赞同拉贝奥的意见。

<!-- source-p 275 -->
<a id="24.3.66.5"></a>**5.**妻子离婚后取回部分嫁资，将其余部分留在丈夫处，随后另行结婚，又成为寡妇并返回前夫身边；她给付一百一十作为嫁资，却未提及前次嫁资的剩余部分。拉贝奥说，婚姻再次解除时，丈夫应在与前次离婚情形相同的日期返还前次嫁资的余额，因为前次嫁资的债务关系已经转入后一次嫁资之中；我认为这是正确的。

<!-- source-p 276 -->
<a id="24.3.66.6"></a>**6.**如果丈夫未经妻子同意，在婚姻关系存续期间让岳父收取已经受领的嫁资，即使此举是为了岳父贫困，拉贝奥说风险仍由丈夫承担；此说正确。

<!-- source-p 277 -->
<a id="24.3.66.7"></a>**7.**如果有人代表妻子向丈夫允诺嫁资，后来此人死亡并以妻子为继承人，拉贝奥说，在妻子继承其遗产的份额内，原由丈夫承担的嫁资风险也转由妻子承担；因为丈夫本来不能向妻子请求给付的款项，不应使妻子因丈夫遭受损失而反倒获益。我认为此说正确。
