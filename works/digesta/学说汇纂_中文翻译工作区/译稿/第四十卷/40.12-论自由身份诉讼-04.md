# D.40.12 论自由身份诉讼（*De liberali causa*）—第四部分

> 底本：*Digesta Iustiniani*，EPUB `book-40.xhtml`，source-p 1291–1333。接续 D.40.12.33，止于 D.40.12.44.2。

<!-- source-p 1291 -->
明知购买的是自由人者，即使该人也听任自己被出售，仍不得阻止其主张自由。但若该明知者又把此人出售给不知情的他人，则应拒绝其自由身份主张。

<!-- source-p 1304 -->
<a id="40.12.38"></a>**40.12.38**

<!-- source-p 1305 -->
保罗《答复集》第十五卷。

<!-- source-p 1306 -->
<a id="40.12.38.pr."></a>**序言**　保罗答复说，若如案情所述，买卖已经无条件完成，买受人此后才自行写信，表示将在确定期限届满后解放其所买的奴隶，则该书信不属于神圣马尔库斯皇帝敕令的适用范围。

<!-- source-p 1307 -->
<a id="40.12.38.1"></a>**1**　保罗还答复说，神圣马尔库斯皇帝的敕令确实适用于附有“期限届满后应予解放”条件而出售的奴隶；但为使奴隶获得自由，也应将同样有利于自由的规则适用于这种情形：主人收取价款，条件是解放自己的女奴，因为主人之后也会取得她作为自由女释奴的身份。

<!-- source-p 1308 -->
<a id="40.12.38.2"></a>**2**　有人问：价款尚未支付时，买受人能否有效地授予奴隶自由？保罗答复说，出卖人既已将奴隶交付买受人，若出卖人就价款已获得清偿保障，即使价款尚未实际付清，该奴隶也已成为买受人所有的财产。

<!-- source-p 1309 -->
<a id="40.12.38.3"></a>**3**　盖尤斯·塞尤斯将奴隶斯提库斯卖给卢基乌斯·提提乌斯，约定提提乌斯须在三年后解放斯提库斯，但条件是斯提库斯连续为其服役三年。三年期满前，斯提库斯逃亡；过了一段时间，提提乌斯死亡后，他才返回。我问：斯提库斯在三年期满前离开，是否妨碍他依买卖约定取得自由？保罗答复说，依所述案情，规定斯提库斯应获释的期限一经届满，自由即归属于他。

<!-- source-p 1310 -->
<a id="40.12.39"></a>**40.12.39**

<!-- source-p 1311 -->
保罗《法学格言》第五卷。

<!-- source-p 1312 -->
<a id="40.12.39.pr."></a>**序言**　若某人本无须承担证明自己为自由出生者的责任，但他主动希望证明这一点，也应听取其主张。

<!-- source-p 1313 -->
<a id="40.12.39.1"></a>**1**　审理自由出生身份问题的法官，可以对轻率提起争议者认定其恶意诉讼，并按流放的程度判处惩罚。

<!-- source-p 1314 -->
<a id="40.12.39.2"></a>**2**　曾经管理未成年人的监护事务及其财产的监护人或保佐人，之后不得再对该未成年人的身份提出争议。

<!-- source-p 1315 -->
<a id="40.12.39.3"></a>**3**　丈夫并未被禁止对其妻子——同时也是自己的被释女奴——提出身份争议。

<!-- source-p 1316 -->
<a id="40.12.40"></a>**40.12.40**

<!-- source-p 1317 -->
赫尔莫革尼安《法律摘要》第五卷。

<!-- source-p 1318 -->
若有人年满二十岁，依约定分割价款而听任自己被出售，则即使后来获释，也不得主张自由身份。

<!-- source-p 1319 -->
<a id="40.12.41"></a>**40.12.41**

<!-- source-p 1320 -->
保罗《自由身份诉讼问题》单行篇。

<!-- source-p 1321 -->
<a id="40.12.41.pr."></a>**序言**　若主张自由身份者此前处于何种身份状态尚不明确，应先听取希望证明自己处于自由身份占有之中的一方。

<!-- source-p 1322 -->
<a id="40.12.41.1"></a>**1**　审理自由身份问题的法官，还应调查是否有财物被取走或损害被造成。因为主张自由身份之人可能仗恃自己终将自由，胆敢从他曾为之服役之人的财产中偷取、毁坏或耗用某些财物。

<!-- source-p 1323 -->
<a id="40.12.42"></a>**40.12.42**

<!-- source-p 1324 -->
拉贝奥《后论》第四卷。

<!-- source-p 1325 -->
如果你买下的奴隶主张自由身份，而法官错误地判决其胜诉；在针对你作出判决后，该奴隶的主人又指定你为继承人，或该奴隶以其他原因归你所有，那么你仍可请求确认该奴隶属于你所有；既判力抗辩不得阻止你提出请求。雅沃勒努斯注：这些说法是正确的。

<!-- source-p 1326 -->
<a id="40.12.43"></a>**40.12.43**

<!-- source-p 1327 -->
庞波尼乌斯《元老院决议论》第三卷。

<!-- source-p 1328 -->
对于侵吞其服役对象财物后又主张自由身份的人，哈德良皇帝曾作出如下敕答：“正如某人不得仗恃依遗嘱信托应予授予的自由而侵吞遗产钱款一样，也不应借故拖延授予自由。因此，应尽快指定一名仲裁人，由其查明哪些财物可以留给继承人保存，然后再强制主人解放奴隶。”（原文关键词：*fiducia libertatis, quae ex fideicommissi causa praestanda est*；*nec libertati praestandae moram quaeri oportet*。）

<!-- source-p 1329 -->
<a id="40.12.44"></a>**40.12.44**

<!-- source-p 1330 -->
维诺尼乌斯《诉讼论》第七卷。

<!-- source-p 1331 -->
<a id="40.12.44.pr."></a>**序言**　此前虽曾有人疑问：奴隶因取得自由而承担的义务，其誓言究竟在其仍为奴隶时即约束他，还是仅在其成为自由释奴后才约束他；但更正确的意见是，只有在他成为自由人后，才受该誓言约束。主人之所以通常要求奴隶宣誓，是为了使其受宗教誓言拘束，在日后取得独立身份时必须履行所宣誓的义务；不过，奴隶必须在获释当时立即宣誓或作出允诺。

<!-- source-p 1332 -->
<a id="40.12.44.1"></a>**1**　在赠礼、职务性给付或劳务的约定中，也可以列入妻子本人。

<!-- source-p 1333 -->
<a id="40.12.44.2"></a>**2**　未适婚人若已宣誓——即他确有宣誓能力——应在其达到法定性成熟年龄后，准许以有用诉权请求劳务。未适婚人也可能提供劳务，例如担任报姓名者（*nomenclator*）或演员。
