<!-- source-p 422 -->

<a id="40.5.4"></a>**40.5.4**

<!-- source-p 430 -->
乌尔比安《告示评注》第六十卷。

<!-- source-p 431 -->
<a id="40.5.4.pr."></a>**序言。**因此，只要是否存在继承人尚不确定，该敕令便暂不适用；一旦确定继承人不存在，便可适用该敕令。

<!-- source-p 432 -->
<a id="40.5.4.1"></a>**1.**若有权请求恢复原状之人放弃继承，在其仍可请求恢复原状期间，我们是否应认为该敕令暂不适用，因为尚不能确定不存在无遗嘱继承人？不过，较妥当的看法是应当适用该敕令。

<!-- source-p 433 -->
<a id="40.5.4.2"></a>**2.**那么，若为保全释奴而将遗产判归之后，该人又获准恢复原状，应如何处理？当然，不应认为已经发生效力的释奴又被撤销。

<!-- source-p 434 -->
<a id="40.5.4.3"></a>**3.**我们还应考察：接受释奴安排的人是否必须在场？由于即使他们不愿意，也可以为了实现释奴而将遗产判归他人，当然也可以在他们不在场时这样处理。

<!-- source-p 435 -->
<a id="40.5.4.4"></a>**4.**那么，若有些人到场而另一些人缺席，缺席者是否也能取得自由？可以参照接受遗产的情形，认为缺席者也能取得自由。

<!-- source-p 436 -->
<a id="40.5.4.5"></a>**5.**若释奴被规定在某一日期生效，是否应等待该日到来？我认为应当等待；因此，在此之前不得将遗产判归。若释奴附有条件，又应如何处理？若有些奴隶无条件获释，另一些附条件获释，则遗产当然可以立即判归；若所有释奴均附条件，是否应等待条件成就，还是可以立即判归，并规定只有条件成就时释奴才生效？较可采的意见是后者。因此，遗产判归后，无条件的直接释奴立即生效；定期释奴于期限届至时生效；附条件释奴于条件成就时生效。即使所有释奴都附有条件，在条件尚未成就时，也不妨认为该敕令已经适用：既然存在获得自由的希望，只要出现一个细微的机会，且不会损害债权人，就应准许判归遗产。

<!-- source-p 437 -->
<a id="40.5.4.6"></a>**6.**若释奴附有支付十个单位的条件，无论受释奴人被要求向继承人给付，还是文书未写明应向谁给付，问题是：他向取得遗产判归之人给付后，是否即可获释？较妥当的看法是，他应向遗产受判归之人给付，仿佛给付条件已经转移给该人。若明确要求向继承人以外之人给付，则当然应向指定之人给付。

<!-- source-p 438 -->
<a id="40.5.4.7"></a>**7.**获得遗嘱信托式释奴安排的人，并不会在遗产判归之时立即成为自由人；他们只能取得遗嘱信托式释奴，也就是说，应由取得遗产判归之人实际为他们释奴。

<!-- source-p 439 -->
<a id="40.5.4.8"></a>**8.**敕令规定，只有在已适当地向债权人担保足额清偿每一笔债务时，才可将遗产判归。因此，担保必须适当。何为适当？当然，可以提供充分担保，或设定质押。但若债权人信任承诺人，未要求充分担保，也可视为担保适当。

<!-- source-p 440 -->
<a id="40.5.4.9"></a>**9.**应如何向债权人提供担保？是分别向每一位债权人担保，还是由债权人共同指定一人代表全体受领担保？应由法官职权促使债权人协商并指定一人，由其代表全体受领担保。

<!-- source-p 441 -->
<a id="40.5.4.10"></a>**10.**还应考察：是否须先向债权人提供担保，然后才能判归遗产；抑或只有在担保提供后，遗产判归才生效？我认为，判决应作如下表述：“若依马可神皇敕令所规定的一切事项均已完成，则……”

<!-- source-p 442 -->
<a id="40.5.4.11"></a>**11.**“足额清偿”应理解为包括本金及应付利息。

<!-- source-p 443 -->
<a id="40.5.4.12"></a>**12.**敕令说明，获得自由者将成为谁的自由释奴：直接获释者将成为死者的释奴，即所谓“奥尔库斯的释奴”；但请求将遗产判归自己的人，或许可以要求判归时附加条件，使这些直接获释者也成为他自己的释奴。

<!-- source-p 444 -->
<a id="40.5.4.13"></a>**13.**若请求这些人归自己为释奴，究竟应由取得遗产判归之人再为他们释奴，还是应在判归时即规定：直接获释者也归其为释奴？我认为应采后者，即将此事直接写入遗产判归决定；敕令文字也允许这样处理。

<!-- source-p 445 -->
<a id="40.5.4.14"></a>**14.**奴隶一旦取得自由，取得遗产判归之人当然也将承担对该自由释奴的监护职责。

<!-- source-p 446 -->
<a id="40.5.4.15"></a>**15.**若立遗嘱人请求继承人为他人的奴隶释奴，该敕令是否适用，还是应停止适用？较妥当的看法是仍应适用：遗产判归后，裁判官会强令取得遗产之人买下奴隶并使其自由。

<!-- source-p 447 -->
<a id="40.5.4.16"></a>**16.**若被请求释奴的不是继承人而是受遗赠人，是否因遗赠尚未到期、释奴义务也就不能发生，而使该敕令不适用？较妥当的看法是仍应给予同样的优待；因为立法者概括地希望，凡在继承人接受遗产时本可获释者，都能取得自由。

<!-- source-p 448 -->
<a id="40.5.4.17"></a>**17.**同一敕令还规定，若国库接受遗产，释奴仍然有效。因此，无论遗产无人继承而由国库拒绝，还是由国库接受，该敕令均可能适用。若国库基于其他理由接受遗产，显然该敕令应停止适用；因此，若遗产作为无主财产被移交给军团，也应采用同一看法。

<!-- source-p 449 -->
<a id="40.5.4.18"></a>**18.**同样，若未满二十岁者作出直接释奴安排，该释奴不生效；但遗嘱信托式释奴除外。若此人尚在人世时作出释奴安排，只要其能够证明正当原因，遗嘱信托式释奴本可生效。

<!-- source-p 450 -->
<a id="40.5.4.19"></a>**19.**若一个人在死亡时已无力清偿债务，却以诈害债权人为目的安排释奴，释奴是否生效？若国库未接受遗产，释奴或许仍然有效，因为债权人可获足额偿付；但若有人接受了遗产，释奴便不生效。若国库接受遗产，释奴更可能被认定为不生效；但也有人依敕令文义主张，请求遗产判归且以释奴生效为条件的人，应自行承担这一结果。不过，若参照继承人接受遗产的情形，只要存在诈害债权人的意图且实际造成了该结果，直接释奴便不生效；若债权人确因该安排而受损，遗嘱信托式释奴也不应履行。

<!-- source-p 451 -->
<a id="40.5.4.20"></a>**20.**若国库未接受遗产，而遗产已为保全释奴而判归他人，国库此后还能接受该遗产吗？较妥当的意见是不能。若在未通知国库长官的情况下，遗产为保全释奴而判归他人，则应考察该敕令是否适用：若该遗产本应由国库接受，判归即告无效；若不应由国库接受，则判归有效。

<!-- source-p 452 -->
<a id="40.5.4.21"></a>**21.**取得遗产判归之人的地位应比照遗产占有人；据此，他也可以享有墓地权利。

<!-- source-p 453 -->
<a id="40.5.4.22"></a>**22.**还应考察：遗产债权人能否依据遗产诉权向其请求，还是只能依据他提供的担保请求？较妥当的意见是，只能依据他实际提供的担保向其请求。

<!-- source-p 454 -->
<a id="40.5.4.23"></a>**23.**若遗产判归两人或数人，他们将共同拥有遗产及共同释奴，并可彼此提起遗产分割之诉。

<!-- source-p 458 -->
<a id="40.5.6"></a>**40.5.6**

<!-- source-p 459 -->
保罗《告示评注》第六十卷。

<!-- source-p 460 -->
遗赠十个单位，并要求受遗赠人购买奴隶斯提库斯后使其自由；《法尔基第法》限制遗赠份额，而该奴隶又不能以低于其价值的价格买下。有人认为，受遗赠人应取得四分之三的遗赠，且不应被强迫购买奴隶。他们也认为，若受遗赠人被请求释放自己的奴隶，即使已取得四分之三遗赠，也不应被强迫释奴。我们应考察此案是否应另作处理。对于前一种情形，有人认为受遗赠人既已接受四分之三遗赠，就应被强迫赎买奴隶，因其自愿承担了该负担。但若其愿意返还所受领之物，是否应听从，仍待考察。继承人则应被强迫支付全部十个单位，仿佛立遗嘱人明言应足额给付。

<a id="40.5.10"></a>**40.5.10**

<!-- source-p 471 -->
马尔切卢斯《学说汇纂》第十六卷。

<!-- source-p 472 -->
<a id="40.5.10.pr."></a>**序言。**有人在遗嘱中写道：“我不希望某某奴隶被出售。”若其不愿奴隶被出售，是为了使奴隶一旦被出售便能获得自由，那么就应当使其自由。立遗嘱人写道“我不愿他服侍你以外的任何人”，也应理解为留下了自由。因此，只要继承人以任何方式试图出售奴隶，奴隶便可立即请求自由；即使继承人又将其买回，也不能阻止释奴，因为条件已经成就。

<!-- source-p 473 -->
<a id="40.5.10.1"></a>**1.**负有释奴义务的人已经出售了奴隶。若奴隶希望由继承人释奴，而继承人在场、买受人却藏匿不出，则不应阻止奴隶；因为他可以依据元老院决议，仿佛依遗嘱一样取得自由。

<!-- source-p 474 -->
<a id="40.5.10.2"></a>**2.**负有遗嘱信托式释奴义务的人资不抵债，却任由该奴隶被交给善意买受人。你认为，能否仿照有人以虚构奴役身份欺骗自由人买受人的情形，为该人设置一项使其成为自由人的诉权？我也倾向于认为，可以对已被出售的人给予诉权；其情形更类似附条件获释的奴隶：后者在依遗嘱取得自由的前一日，容许他人对自己实施同样的行为。

<!-- source-p 502 -->
斯凯沃拉《学说汇纂》第二十四卷。

<!-- source-p 503 -->
<a id="40.5.19.pr."></a>**序言。**某人指定丈夫为继承人，并以遗嘱信托方式请求他释放若干奴隶，其中包括丈夫的事务代理人斯提库斯。主人不在场时，这些奴隶向行省总督请求释奴，理由是继承人有正当事由缺席；总督宣告他们应获自由。我问：能否要求斯提库斯就自己管理的事务向他人交账？答复说：不能。

<!-- source-p 504 -->
<a id="40.5.19.1"></a>**1.**某人将嫁资及其他多项财物遗赠给妻子，并以遗嘱信托请求她在审议会前释放其自有奴隶阿奎利努斯。妻子称，阿奎利努斯是她自己的奴隶，因此她没有义务释奴。我问：阿奎利努斯是否有权请求自由？答复说，若妻子希望依遗嘱取得嫁资及其他遗赠，就应依遗嘱信托释放阿奎利努斯；阿奎利努斯成为自由人后，也可以请求取得遗嘱遗赠给他的财物。

帕比尼安《疑义集》第十九卷。

<!-- source-p 510 -->
“我请求不要让斯提库斯受他人奴役。”皇帝认可此话可以理解为设立了遗嘱信托式释奴。还有什么比自由更与奴役相反呢？但这不应被理解为要到继承人死亡后才释奴；其意义在于，若继承人生前转让奴隶，可以立即请求其自由；即使继承人后来又将奴隶买回，也不得阻止该请求，因为条件一经成就，便不能撤销。若继承人并非自愿转让，也应作同样处理；不能以转让并非由他主动造成而否定释奴。因为该奴隶仿佛是附条件获释者，无论以何种方式，条件都已成就。

<a id="40.5.22"></a>**40.5.22**

<!-- source-p 512 -->
帕比尼安《疑义集》第二十二卷。

<!-- source-p 513 -->
<a id="40.5.22.pr."></a>**序言。**若某受遗赠人被遗赠一块土地及十个单位，条件是释放自己的奴隶，即使他接受了土地遗赠，若因《法尔基第法》介入而拒绝接受钱款，也应强令其在计入该法所定份额后接受钱款，并依遗嘱信托为奴隶释奴；因为他既已接受土地遗赠，就应履行该义务。

<!-- source-p 514 -->
<a id="40.5.22.1"></a>**1.**某人有两名继承人及三名奴隶；立遗嘱人请求两名继承人从中选择两名释放。一名继承人藏匿，另一名则说明了自己所选的奴隶。可以认为所选奴隶应获自由，仿佛在场的继承人能够独自完成释奴一样。若一名奴隶死亡，而另一继承人因正当事由缺席，或受请求释奴之人无法表达意思，则裁判官宣告剩余两名奴隶自由，是妥当的。

<!-- source-p 515 -->
<a id="40.5.22.2"></a>**2.**若负有遗嘱信托式释奴义务之人因正当事由缺席或藏匿；若有些人到场，有些人因正当事由缺席，另一些人则为逃避遗嘱信托而故意不露面；若负有释奴义务之人没有继承人；或者若家内继承人放弃继承，裁判官都应宣告依卢基乌斯·提图斯的遗嘱，遗嘱信托式释奴已经到期。元老院决议对此已有规定，并为避免不清楚谁将成为自由释奴而规定：裁判官应宣告哪些人因正当事由缺席，哪些人意在逃避释奴义务。

<a id="40.5.23"></a>**40.5.23**

<!-- source-p 517 -->
帕比尼安《答复集》第九卷。

<!-- source-p 518 -->
<a id="40.5.23.pr."></a>**序言。**不得以继承财产被侵吞或奴隶曾管理账目为借口，拖延遗嘱信托式释奴。

<!-- source-p 519 -->
<a id="40.5.23.1"></a>**1.**若继承人未履行遗嘱信托式释奴义务，而其继承人依据特雷贝利乌斯元老院决议返还遗产，且选择了应被释放之人，则该继承人也应被强令履行释奴义务。

<!-- source-p 520 -->
<a id="40.5.23.2"></a>**2.**父亲以遗嘱信托用语，请求由其法定继承人释放一名属于军役特有产的奴隶。我答复说，若儿子是军人或曾服军役，并且成为父亲的继承人，则应强令其释奴；因为父亲是在将财产赠与儿子之后，才认为该奴隶属于儿子本人。不得为了实现释奴意愿而强迫同为主人的兄弟赎买其份额，否则将损害立遗嘱人的意思。也不得因同一误解，而要求仍受父权支配的兄弟返还父亲赠给出征儿子的其他财物；因为即使在法定继承人之间，儿子仍可优先保有其军役特有产。
<!-- source-p 521 -->
<a id="40.5.23.3"></a>**3.**此外，儿子以遗嘱信托方式指定奴隶在儿子达到某一年龄后获释；若儿子未活到该年龄，应由儿子的继承人在预定日期履行释奴义务。此项见解虽作为一项特别法理而获承认，但不宜扩张适用于其他遗嘱信托。

<!-- source-p 522 -->
<a id="40.5.23.4"></a>**4.**立遗嘱人希望儿子在五年后释放某奴隶，条件是该奴隶在此期间向儿子提供每日劳务。该奴隶在前两年四处游荡，未提供劳务，表面看来条件已落空。但若作为继承人的儿子（或其监护人）曾在两年内选用该奴隶提供劳务，则已确定：因继承人一方造成的过去期间之事，不得妨碍剩余条件的成就。

<!-- source-p 523 -->
<a id="40.5.24"></a>**40.5.24**

<!-- source-p 524 -->
乌尔比安《遗嘱信托论》第五卷。

<!-- source-p 525 -->
<a id="40.5.24.pr."></a>**序言。**一般而言，凡能够设定金钱遗嘱信托者，均可附加遗嘱信托式释奴。

<!-- source-p 526 -->
<a id="40.5.24.1"></a>**1.**以遗嘱信托方式为皇帝的奴隶、市镇的奴隶或其他任何人的奴隶设定释奴，均属有效。

<!-- source-p 527 -->
<a id="40.5.24.2"></a>**2.**若以遗嘱信托方式为敌人的奴隶设定释奴，可以讨论其是否无效。或许有人会说，罗马公民沦为敌人奴隶，实属不当；但若遗嘱信托是为其重新成为我方之奴隶时而设，又有什么理由不承认释奴有效呢？

<!-- source-p 528 -->
<a id="40.5.24.3"></a>**3.**若遗嘱信托为一自由人设定释奴，而此人后来被置于奴隶身份，可以设想：只要在死亡时或条件成就时他确为奴隶，即可请求获得自由。

<!-- source-p 529 -->
<a id="40.5.24.4"></a>**4.**以遗嘱信托方式为尚未出生之人的奴隶设定释奴，属于有效。

<!-- source-p 530 -->
<a id="40.5.24.5"></a>**5.**若奴隶被判处矿山劳役，便不能期待获得自由。那么，若已为其设定遗嘱信托式释奴，而皇帝宽免其矿山劳役之刑，情形又如何？我们的皇帝曾作敕答，称此人不恢复为先前主人的所有物；但敕答未说明他究竟属于谁。可以确定的是，若其成为国库所有，他便可以期待获得遗嘱信托式释奴。〔底本末尾作 *libertaten*，疑为 *libertatem* 之误。〕

<!-- source-p 531 -->
<a id="40.5.24.6"></a>**6.**对于由被判处矿山劳役的妇女所怀孕并生下的孩子，可以设定遗嘱信托式释奴。这有什么奇怪呢？神圣的庇护皇帝皮乌斯甚至曾作敕答，称此子可以如同奴隶一样被出售。

<!-- source-p 532 -->
<a id="40.5.24.7"></a>**7.**若立遗嘱人请求不得再让斯提库斯服役，应认为其已设定遗嘱信托式释奴；因为请求不得再令其服役的人，显然是在请求给予他自由。

<!-- source-p 533 -->
<a id="40.5.24.8"></a>**8.**若立遗嘱人写道“不得让他被转让”或“不得出售他”，只要其用意是使奴隶获得自由，也应作同样解释。反之，若其用意不同，例如劝告继承人留用这样一名奴隶，或意在惩罚、折磨奴隶，使其无法遇到更好的主人，或出于其他并非给予自由的目的，则应认为释奴义务不发生；凯尔苏斯在《学说汇纂》第二十三卷中也如此写道。因为通常赋予遗嘱信托式自由的，不仅是遗嘱信托的文字，还有立遗嘱人的意思。但既然依推定应认为立遗嘱人已给予自由，就应由继承人证明立遗嘱人有相反意思。〔底本作 *Nnon tantum*，疑为 *Non tantum* 之误。〕

<!-- source-p 534 -->
<a id="40.5.24.9"></a>**9.**若某人因为认为某奴隶是自由人而指定其为监护人，则毫无疑问，该奴隶既不能请求自由，也不能以监护职责作为要求履行释奴义务的依据。马尔凯卢斯在《学说汇纂》第十五卷中如此记载，我们的皇帝与其父也曾作敕答确认此点。

<!-- source-p 535 -->
<a id="40.5.24.10"></a>**10.**若有人为已设质的奴隶直接授予自由，依严格法理虽似属无效，但该奴隶仍可仿佛立遗嘱人设定了遗嘱信托式释奴一样，请求依遗嘱信托获得自由。因为对自由的偏护要求我们将遗嘱用语解释为也足以支持自由之请求，仿佛该奴隶是依遗嘱信托而被命令获得自由。毕竟，许多有利于自由的规定，早已为通融严格法理而设。

<!-- source-p 536 -->
<a id="40.5.24.11"></a>**11.**对于因遗腹女出生而被打破的遗嘱，若家父并未同时要求法定继承人释放奴隶，则显然，遗嘱中的直接释奴不生效，遗嘱信托式释奴也不负履行义务。

<!-- source-p 537 -->
<a id="40.5.24.12"></a>**12.**若某人受请求释放他人或自己的奴隶，而按立遗嘱人的判断，其所得遗赠金额低于奴隶的价格，应考虑是否可强令其赎买他人之奴隶或释放自己的奴隶。马尔凯卢斯写道：若此人已经取得遗赠，就应无条件强令其释放自己的奴隶。事实上，现行法区分受请求释放自己的奴隶还是他人的奴隶，这一点十分重要：若是自己的奴隶，即使所得甚少，也应被强令释放；若是他人的奴隶，只有在其可用所得遗赠金额赎买该奴隶时，才应被强令赎买并释放。

<!-- source-p 538 -->
<a id="40.5.24.13"></a>**13.**因此，马尔凯卢斯接着说，某人虽被指定为继承人，但若扣除债务后仍有所得，也应被强令释放自己的奴隶；若一无所获，则不应强令其释放。

<!-- source-p 539 -->
<a id="40.5.24.14"></a>**14.**当然，若某人最初所得遗赠较少，但因某种事由遗赠数额后来增加，那么强令其按实际所得金额赎买奴隶，才最为公平；他不得以最初所得较少为由抗辩，因为其遗赠已因遗嘱而增加。同样，若因迟延而产生孳息或利息并归入遗嘱信托，也应认为应当履行释奴义务。

<!-- source-p 540 -->
<a id="40.5.24.15"></a>**15.**因此，即使奴隶的价格已经降低，也应认为受请求者仍应被强令赎买。

<!-- source-p 541 -->
<a id="40.5.24.16"></a>**16.**若遗赠数额减少，应考虑曾期待取得较大遗赠的人是否仍须释放奴隶。我认为，若此人愿意返还遗赠，就不应强令其释放；因为他是在另一种预期下接受遗赠，而遗赠后来意外减少。故应允许其放弃遗赠；但若剩余遗赠仍足以支付奴隶价格，则另当别论。

<!-- source-p 542 -->
<a id="40.5.24.17"></a>**17.**那么，若某人受请求释放数名奴隶，而所获遗赠仅足以支付其中一些人的价格，不足以支付所有人的价格，是否应强令其释放其中若干人？我认为，应当强令其释放遗赠金额足以支付其价格的奴隶。那么，究竟应释放哪些人？由受遗赠人自行选择，还是由遗赠人——即负有遗赠义务的人——选择？或许有人会正确地认为，应依遗嘱书写的顺序；若无法确定顺序，则应抽签，以免裁判官遭受偏袒或徇私的嫌疑；或者，应根据各人的功绩作出裁量。

<!-- source-p 543 -->
<a id="40.5.24.18"></a>**18.**若某人受命赎买奴隶并给予其自由，而遗赠的钱款不足以赎买所有获授自由的奴隶，也应作同样解释：此处应适用我们上文认可的规则。

<!-- source-p 544 -->
<a id="40.5.24.19"></a>**19.**若某人获遗赠，并受请求释放自己的奴隶，同时将该项遗赠交付给该奴隶，是否应履行遗嘱信托式释奴？有些人对此感到疑惑，因为若受请求者被强令履行释奴，便也必须因而被强令履行遗嘱信托给付；也有人认为不应强令其释奴。设若我获得遗赠，并受请求立即将遗赠返还给提图斯，此外还受请求释放自己的奴隶，毫无疑问，我们会说，不应强令我履行释奴义务，因为我似乎并未因释奴而取得任何对价。不过，若我受请求在一段时间之后返还所得遗赠，则可以说，基于这段期间所得的孳息，应强令我释放奴隶，……

<!-- source-p 545 -->
<a id="40.5.24.20"></a>**20.**若某人受请求在自己死亡时将一块土地交给一人，并在从土地取得的孳息达到遗嘱信托金额时向另一人交付一百，则应强令其履行。由此，金钱遗嘱信托的履行与遗嘱信托式释奴便处于待定状态。

<!-- source-p 546 -->
<a id="40.5.24.21"></a>**21.**若有效设定了遗嘱信托式释奴，则该自由不会因奴隶被转让或被他人取得时效而消灭。因为该奴隶无论归于何人，均可强令其释放奴隶；这一点已屡经敕令确认。因此，若受请求释奴之人希望由受让人释放该奴隶，受让人就会被强令履行遗嘱信托式释奴。对此规则应作较宽解释：即使释奴附有条件，而奴隶在条件成就前被转让，转让时仍连同其既有法律关系一并转移。若奴隶不愿由受让人释放，而宁愿由原受请求者使其获得自由，神圣的哈德良皇帝和神圣的皮乌斯皇帝曾作敕答，称应听从奴隶的选择。不仅如此，若奴隶已经被释放，却更愿意成为原受请求者的释奴，神圣的皮乌斯皇帝也曾作敕答，称应听从其选择。此外，若奴隶能够证明释放者的身份或其他事由使其权利因该次释奴而受到损害，或已经受损，也应依这些敕令给予救济，以免违背死者意思而使其处境更为不利。不过，若死者的意思是允许任何人释放该奴隶，则应认为上述敕令不适用。

乌尔比安《遗嘱信托论》第五卷。

<!-- source-p 552 -->
<a id="40.5.26.pr."></a>**序言。**若受请求者负有释放他人奴隶的义务，却因死亡或财产被没收而导致该奴隶转归他人，我认为应适用相关敕令，以免遗嘱信托式释奴的处境变得更差。若某人受请求在自己死亡时释放奴隶，却在未释放奴隶前死亡，已经确立的规则是，该奴隶应被视为仿佛已由此人使其获得自由一样；因为此人本可在遗嘱中直接授予其自由。因此，每当某奴隶获授遗嘱信托式自由，而实际释放他的人并非原受请求者时，该奴隶仍可援用敕令所定救济，并应视为仿佛由原受请求者释放；因为对遗嘱信托式释奴应予偏护，预定的遗嘱信托式自由通常不应落空。获得这种自由的人，暂且应被视为已占有其自由。

<!-- source-p 553 -->
<a id="40.5.26.1"></a>**1.**可见，法律给予遗嘱信托式释奴以救济：发生迟延时，应视为其自由已受到迟延；自可以请求释奴之日起，应将奴隶母亲交付他人，以便释放其子女；而自提出请求之日起，该子女应被视为自由出生者。因为通常，由于受请求释奴者怠惰、怯懦、不知自己的法律义务，或由于请求者的权威与身份，遗嘱信托式释奴请求被迟延提出，甚至根本未提出；此种情形不应损害自由。我们所主张的规则应作如下界定：子女自自由受到迟延之日起被视为自由出生者；而将其交付母亲以便释放，则应自可以请求释奴之日起发生，即使实际上并未提出请求亦然。当然，对于未满二十五岁者，也应给予此项救济，以便将其视为发生了法律迟延。因为既然神圣的塞维鲁皇帝已通过裁定确立：对于留给未满二十五岁者的金钱遗嘱信托，应视为发生法律迟延，那么在释奴事项上，更应承认同一规则。

<!-- source-p 554 -->
<a id="40.5.26.2"></a>**2.**某凯基利乌斯曾将一名已设质的女奴交给债权人作担保，并希望在债权人获清偿后通过遗嘱信托释放她。继承人未能使债权人解除质权，之后出生的婴儿被债权人出售。我们的皇帝与其父曾作敕答，依照神圣的皮乌斯皇帝的意见，为免孩子丧失其被预定的自由，在向买受人返还价金后，这些孩子应视为自由出生者，犹如其母在应当的时间已获释奴一样。

<!-- source-p 555 -->
<a id="40.5.26.3"></a>**3.**我们的皇帝与其父还曾作敕答：若在立遗嘱人死亡五年后才开启遗嘱或遗嘱附录，而期间已有子女出生，为免偶然的迟延使该子女陷于奴隶身份，应将该子女交给母亲，由母亲使其获得自由。

<!-- source-p 556 -->
<a id="40.5.26.4"></a>**4.**由此敕答，以及前文所述神圣的皮乌斯皇帝所作敕答，可见他们不愿偶然发生的释奴迟延损害由获遗嘱信托式自由的女奴所生子女。

<!-- source-p 557 -->
<a id="40.5.26.5"></a>**5.**但若未成年人的替补继承人受遗嘱信托之托，应释放女奴，而该女奴在未成年人仍在世时生育；或者女奴获授的自由附有期限或条件，而她在期限届满或条件成就前生育，则该子女不能因此获得自由，因为这些情形性质不同：其原因并非偶然迟延，而是立遗嘱人的意思使然。

<!-- source-p 558 -->
<a id="40.5.26.6"></a>**6.**若奴隶被遗赠给某人，而该遗赠被视为未曾书立，但立遗嘱人又以遗嘱信托方式请求此人释放该奴隶，那么问题在于：遗赠被视为未曾书立时，遗嘱信托式释奴是否也随之失效；或者，若奴隶请求遗嘱信托式释奴，向遗赠被视为未曾书立后仍留有奴隶的人提出请求，抑或如前所述奴隶本人即为遗赠对象，自由是否仍不应落空。我认为应认定遗嘱信托式释奴仍然有效，尽管原受请求者并未取得该奴隶；因此，应强令取得遗赠奴隶之人履行释奴义务，因为遗嘱信托式自由不应遭遇任何障碍。

<!-- source-p 559 -->
<a id="40.5.26.7"></a>**7.**元老院曾通过决议保障释奴。该决议是在神圣的图拉真皇帝在位期间、鲁布里乌斯·加卢斯和凯利乌斯·希斯波担任执政官时作出的，内容如下：“若负有给予自由义务之人经裁判官传唤而拒不到场，且裁判官经审理后宣告该奴隶应获自由，则应维持其身份，犹如其已被直接释放一样。”

<!-- source-p 560 -->
<a id="40.5.26.8"></a>**8.**该元老院决议适用于依遗嘱信托事由负有释奴义务之人。因此，若释奴义务原本并不存在，但裁判官因被蒙骗而宣告应给予自由，则不得依据该元老院决议取得自由。我们的皇帝与其父也曾作此敕答。

<!-- source-p 561 -->
<a id="40.5.26.9"></a>**9.**负有遗嘱信托式释奴义务之人必须由裁判官传唤；否则，鲁布里安元老院决议不适用。因此，应通过通知、告示和书信传唤他们。

<!-- source-p 562 -->
<a id="40.5.26.10"></a>**10.**该元老院决议适用于所有为逃避义务而藏匿的人。无论受请求者是继承人还是其他人，均适用该元老院决议；总之，所有负有履行遗嘱信托式释奴义务的人，均属于该决议所规范的情形。

<!-- source-p 563 -->
<a id="40.5.26.11"></a>**11.**因此，若继承人藏匿，而受请求释放奴隶的受遗赠人或遗嘱信托受益人到场，则该元老院决议不适用，释奴仍会受到阻碍；因为在此情形下，受遗赠人尚未取得该奴隶的所有权。

<!-- source-p 564 -->

<!-- source-p 566 -->
因此，在这种情况下，应向皇帝提出请求，以便在此类情形中也保障其自由。

<a id="40.5.28"></a>**40.5.28**

<!-- source-p 568 -->
乌尔比安《遗嘱信托论》第五卷。

<!-- source-p 569 -->
<a id="40.5.28.pr."></a>**序言。**若负有遗嘱信托式释奴义务者已将奴隶转让，而买受人藏匿，原受请求者却到场，是否适用鲁布里安元老院决议？马尔凯卢斯认为该决议适用，因为应释放奴隶之人缺席。

<!-- source-p 570 -->
<a id="40.5.28.1"></a>**1.**“拒不到场”这一用语并不必然要求负有释奴义务者藏匿；即使其并未藏匿，只是蔑视传唤而拒绝到场，该元老院决议也适用。

<!-- source-p 571 -->
<a id="40.5.28.2"></a>**2.**若数名继承人被指定，并受请求履行遗嘱信托式释奴义务，其中若干人无正当理由缺席并迟延释奴，也适用同一规则。

<!-- source-p 572 -->
<a id="40.5.28.3"></a>**3.**若裁定宣告某些人因正当事由缺席，则奴隶应成为那些因正当事由缺席者，以及到场且未迟延遗嘱信托式释奴者的释奴；其地位应如同只有受请求者在场并已使其获得适当自由一样。〔底本此句末尾出现 *perduxissententiarum* 粘连，疑有文本或标记讹误；据句法暂译为 *perduxissent*，需核原版校勘。〕

<!-- source-p 573 -->
<a id="40.5.28.4"></a>**4.**若受请求释放一名非遗产奴隶的人藏匿，埃米利乌斯·尤恩库斯和尤利乌斯·塞维鲁斯担任执政官时曾通过元老院决议，内容如下：“元老院决定，若有人基于任何事由负有通过遗嘱信托为奴隶释奴的义务，而该奴隶在请求释奴者死亡时并不属于其所有，且该负有义务者被称为不在场，则由裁判官调查；若裁判官认为此情形下，假如该人到场，便应被强令释放奴隶，则裁判官应宣告确属如此。作出该宣告后，应适用同一法律规则，犹如该奴隶已依遗嘱信托获释一样。”

<!-- source-p 574 -->
<a id="40.5.28.5"></a>**5.**所谓因正当事由缺席，应仅指没有不正当缺席理由者；只要其并非为妨碍释奴而缺席，即足以认为其因正当事由缺席；不必因公务而缺席。因此，若某人的住所位于一地，而遗嘱信托式释奴请求在另一地提出，则无需传唤被称为负有遗嘱信托式释奴义务的人；即使其缺席，只要能够确认释奴义务确实存在，仍可宣告其因正当事由缺席，而且该人不会因此失去其释奴。因为毫无疑问，居住在其住所地及定居地者，属于因正当事由缺席。

<!-- source-p 575 -->
<a id="40.5.29"></a>**40.5.29**

<!-- source-p 576 -->
保罗《遗嘱信托论》第三卷。

<!-- source-p 577 -->
若某人在开始负有依遗嘱信托释奴义务之后被转让，那么其暂时的所有人应被强令释放他；在此情形下，不区分缺席是否有正当事由；无论如何，该奴隶均应成为此人的释奴。

<!-- source-p 578 -->
<a id="40.5.30"></a>**40.5.30**

<!-- source-p 579 -->
乌尔比安《遗嘱信托论》第五卷。

<!-- source-p 580 -->
<a id="40.5.30.pr."></a>**序言。**若裁判官曾作出裁定，认定某人因正当事由缺席，而此人实际上已经死亡，我们的皇帝曾作敕答：该裁定应转移至其继承人身上，其继承人的法律地位应如同裁判官已据同一事由宣告该继承人本人缺席一样。

<!-- source-p 581 -->
<a id="40.5.30.1"></a>**1.**若负有释奴义务者中有一名婴儿，元老院决议规定：只要一人的年龄构成障碍，就应令依遗嘱信托事由应获自由的男女奴隶获得自由。

<!-- source-p 582 -->
<a id="40.5.30.2"></a>**2.**若唯一被指定的继承人是尚不能言语的幼儿，也应作同样解释。

<!-- source-p 583 -->
<a id="40.5.30.3"></a>**3.**若未成年人有监护人，而监护人不愿授权其释放奴隶，则此事不应妨碍奴隶获得自由，也不应使未成年人失去其释奴。神圣的兄弟皇帝曾作敕答：应依遗嘱信托事由释放该奴隶，犹如该未成年人经监护人授权而亲自释放奴隶一样。

<!-- source-p 584 -->
<a id="40.5.30.4"></a>**4.**因此，凡发生尚不能言语者涉入遗嘱信托式释奴的情形，均应依元老院决议的宗旨处理；该决议的适用也应扩及受请求者的继承人是婴儿的情形。

<!-- source-p 585 -->
<a id="40.5.30.5"></a>**5.**在此事由下，也应向裁判官提出请求。尤其是，神圣的皮乌斯皇帝曾作敕答：若受请求释奴者中，有些人到场，有些人藏匿，另一些人又因正当事由缺席，而其中还有一名婴儿，则该奴隶不应成为所有人的释奴，而仅成为婴儿、因正当事由缺席者，或到场者的释奴。

<!-- source-p 586 -->
<a id="40.5.30.6"></a>**6.**若数人被指定为继承人，其中有一名尚不能言语者，但并非由其本人受请求释放奴隶，则不应仅因婴儿无法将奴隶转让给共同继承人，而使释奴落空。虽有《维特拉西安元老院决议》，神圣的皮乌斯皇帝也曾向卡西乌斯·德克斯特作敕答，规定应按如下方式处理：依遗嘱信托获授自由的奴隶份额，应按公平价格估值，再由负有释奴义务之人释放该奴隶。释放奴隶者应就价金对其兄弟及共同继承人承担责任，其程度犹如共同继承人可以依判决之诉向其请求给付一样。

<!-- source-p 587 -->
<a id="40.5.30.7"></a>**7.**关于精神失常者，神圣的皮乌斯皇帝曾作敕答：即使遗嘱指定的继承人被称为精神失常，也不妨碍附条件设定的遗嘱信托式释奴。因此，若确认依遗嘱信托授予其自由是有效的，应以针对婴儿所用的方式作出裁定；该裁定应包括此项认定。〔底本在 *quo* 后有异文 *quod*。〕

<!-- source-p 588 -->
<a id="40.5.30.8"></a>**8.**因此，对哑者和聋者也应给予救济。

<!-- source-p 589 -->
<a id="40.5.30.9"></a>**9.**若负有履行遗嘱信托式释奴义务的人死亡，且没有继承人或其他继受人，元老院认为，应向裁判官提出请求，并履行释奴义务。

<!-- source-p 590 -->
<a id="40.5.30.10"></a>**10.**若家内继承人放弃继承，元老院决议也保障遗嘱信托式释奴；尽管拥有家内继承人者并非无继承人，即便该家内继承人放弃继承亦然。

<!-- source-p 591 -->
<a id="40.5.30.11"></a>**11.**若未满二十五岁者接受了负有遗嘱信托式释奴义务者的遗产，随后为免除义务而获得恢复原状，也应作同样解释。

<!-- source-p 592 -->
<a id="40.5.30.12"></a>**12.**还须查明该奴隶成为谁的释奴。依据敕令，该奴隶取得自由的情形犹如其已依遗嘱获得自由。因此，他应成为死者的释奴（*Orcinus libertus*），而非负有遗嘱信托式释奴义务者的释奴。

<!-- source-p 593 -->
<a id="40.5.30.13"></a>**13.**若一人死亡而无继受人，另一人则因正当事由缺席，神圣的马尔库斯和维鲁斯皇帝曾作敕答，称该奴隶将获得自由，其情形犹如前者已履行义务、后者又因正当事由缺席而未能履行释奴一样。

<!-- source-p 594 -->
<a id="40.5.30.14"></a>**14.**还可精确地提出这样的问题：若继承人死亡且无继受人，是否应等到确定不会出现继承人或遗产占有人后，方可给予奴隶自由；抑或即使继受人的出现尚不确定，例如遗嘱指定的继承人仍在考虑是否接受遗产，奴隶也能获得自由？较妥当的观点是，应等待至可以确定不会出现继受人时。

<!-- source-p 595 -->
<a id="40.5.30.15"></a>**15.**我们的皇帝安东尼努斯曾作敕答：负有遗嘱信托式释奴请求权的奴隶，也可以不以获得自由为条件，接受继承人遗嘱中的某项给付。

<!-- source-p 596 -->
<a id="40.5.30.16"></a>**16.**神圣的马尔库斯皇帝还曾作敕答：遗嘱信托式释奴不因受益者的年龄或条件，也不因义务人迟延履行或较晚给付，而遭到损害或被置于更不利的状态。

<!-- source-p 597 -->
<a id="40.5.30.17"></a>**17.**虽然无效的遗嘱附录不产生释奴义务，但若继承人认可该遗嘱附录，并依其内容作出某些给付，且希望奴隶为履行遗嘱信托式释奴而继续处于自由状态，我们的皇帝与其神圣的父皇曾作敕答，确认这些奴隶已合法获得自由。

<!-- source-p 598 -->
<a id="40.5.31"></a>**40.5.31**

<!-- source-p 599 -->
保罗《遗嘱信托论》第三卷。

<!-- source-p 600 -->
<a id="40.5.31.pr."></a>**序言。**可以通过遗嘱信托为他人的奴隶设定释奴，但该奴隶必须属于与立遗嘱人之间具有遗嘱能力关系的人。

<!-- source-p 601 -->
<a id="40.5.31.1"></a>**1.**某人在临终时将奴隶托付给其儿子，令其释放该奴隶；此后又有遗腹子出生。神圣的兄弟皇帝曾作敕答：因自由不可分割，两个儿子都应履行释奴义务。

<!-- source-p 602 -->
<a id="40.5.31.2"></a>**2.**负有遗嘱信托式释奴义务的人，即使当时被禁止转让财产，也能够释放奴隶。

<!-- source-p 603 -->
<a id="40.5.31.3"></a>**3.**若释奴保护人因其释奴未被列入遗嘱而依据违遗嘱取得遗产占有，则不应强令其出售自己所有、且原受请求释放的奴隶。

<!-- source-p 604 -->
<a id="40.5.31.4"></a>**4.**若奴隶所有人不愿出售奴隶以便使其获释，裁判官无权介入；若其坚持以高于公平价格出售，也同样如此。但若所有人愿以某一价格出售，而该价格乍看并不不公平，受请求释奴者却主张价格过高，则应由裁判官介入：在向愿意出售的所有人支付公平价格后，由买受人履行释奴义务。若所有人和奴隶都愿意出售并获释，则应强令继承人赎买并释放奴隶；除非所有人愿意亲自释放奴隶，并对继承人取得价金请求权。即使继承人藏匿，也应如此处理；安东尼努斯皇帝曾作敕答确认此点。

<!-- source-p 605 -->
<a id="40.5.32"></a>**40.5.32**

<!-- source-p 606 -->
梅基安努斯《遗嘱信托论》第十五卷。

<!-- source-p 607 -->
<a id="40.5.32.pr."></a>**序言。**若奴隶所有人虽然愿意出售，却坚持必须先向自己支付价金，则不得强令其释放奴隶，以免其既释放奴隶，却因受请求释奴者无清偿能力而最终得不到价金或仅得到部分价金。

<!-- source-p 608 -->
<a id="40.5.32.1"></a>**1.**未经奴隶同意，不应允许任何人，包括奴隶所有人，提起该项请求；因为这类遗嘱信托并非为了使所有人取得利益而设。否则，就应视为遗嘱信托是直接给予所有人的。例如，立遗嘱人希望奴隶以高于其价值的价格被赎买并释放；在这种情况下，所有人和奴隶都可以请求履行遗嘱信托：所有人有权取得超过实际价格、即立遗嘱人命其多支付的部分，奴隶则有权获得自由。

<!-- source-p 609 -->
<a id="40.5.32.2"></a>**2.**若继承人或受遗赠人被要求以特定金额赎买他人之物并交付给另一人，也会出现同样的情形：该物的所有人和应取得该物之人均有权请求履行；因为所有人有权取得立遗嘱人要求超出物之价格支付的部分，而受益人则有权取得该物。

<!-- source-p 610 -->
<a id="40.5.33"></a>**40.5.33**

<!-- source-p 611 -->
保罗《遗嘱信托论》第三卷。

<!-- source-p 612 -->
<a id="40.5.33.pr."></a>**序言。**若死者的儿子受请求释放其父亲的奴隶，则可以认为，该儿子既可依据遗嘱取得遗产占有（违遗嘱遗产占有），也可向该奴隶课以劳务；因为即使其直接获得释奴，他也可以这样做，仿佛是释奴保护人的儿子一样。

<!-- source-p 613 -->
<a id="40.5.33.1"></a>**1.**即使自由附有条件，只要条件未成就并非奴隶本人的过错，也适用鲁布里安元老院决议；无论条件在给付、作为或其他事由上发生，均无区别。更有甚者，若继承人妨碍条件成就，即使他是死者的儿子，也会失去该释奴；虽然依其他法律规则他本可取得该释奴。这是他所受的一种惩罚：若他请求将奴隶判为奴隶身份，或以重罪指控奴隶，也会丧失违遗嘱遗产占有。

<!-- source-p 614 -->
<a id="40.5.33.2"></a>**2.**若奴隶被遗赠给某人，而此人又受请求释放该奴隶，却不愿接受该奴隶，则应强令其将自己的请求权让与奴隶所选择的人，以免自由落空。

<!-- source-p 615 -->
<a id="40.5.34"></a>**40.5.34**

<!-- source-p 616 -->
庞波尼乌斯《遗嘱信托论》第三卷。

<!-- source-p 617 -->
<a id="40.5.34.pr."></a>**序言。**受遗嘱信托授予自由的人，不得违背其意愿而被移交给他人，由他人释放，从而成为另一人的释奴，而非原受请求释奴者的释奴。

<!-- source-p 618 -->
<a id="40.5.34.1"></a>**1.**坎帕努斯说，若未满二十岁的某人请求继承人释放自己的奴隶，应给予该奴隶自由，因为《埃利乌斯·森提乌斯法》在此不适用。

<!-- source-p 619 -->
<a id="40.5.34.2"></a>**2.**一名奴隶被遗赠给卡尔普尔尼乌斯·弗拉库斯，并请求其释放奴隶；若他未释放，同一奴隶又被遗赠给提图斯，并同样请求提图斯释放；若提图斯也未释放，则命令奴隶获得自由。萨比努斯说，这些遗赠无效，奴隶应立即依遗嘱获得自由。

<!-- source-p 620 -->
<a id="40.5.35"></a>**40.5.35**

<!-- source-p 621 -->
梅基安努斯《遗嘱信托论》第十五卷。

<!-- source-p 622 -->
盖乌斯·卡西乌斯认为，在某些情形下，应免除继承人和受遗赠人释放自己奴隶的义务，例如奴隶承担的职务极为必要，以至于失去他并不适宜，诸如管家或子女的教师；或者奴隶所犯过错严重到不应宽恕。然而，这一见解并未获采纳。因为人们认为，他们原本可以自行决定是否接受：他们本可以放弃遗嘱所赋予的利益；既然没有放弃，就应遵从死者的意思。

<!-- source-p 623 -->
<a id="40.5.36"></a>**40.5.36**

<!-- source-p 624 -->
梅基安努斯《遗嘱信托论》第十六卷。

<!-- source-p 625 -->
<a id="40.5.36.pr."></a>**序言。**婴儿、精神失常者、被敌人俘获者，以及因宗教义务、较为高尚的事由、灾难、重大家事、身份或名誉遭受危险或其他类似事由而耽搁的人，不属于鲁布里安元老院决议所涵盖的范围。没有监护人的未成年人也不在其范围内；拥有监护人的未成年人，若监护人正因上述事由而受阻，亦同。即使这些人故意不让自己到场，我也认为不得因此剥夺未成年人的释奴；因为让未成年人因监护人的行为受损并不公平，尤其监护人可能没有清偿能力；而该元老院决议只涵盖依遗嘱信托事由负有释奴义务之人。那么，应如何处理？应以《达苏米安元老院决议》给予他们救济。该决议规定，对于因正当事由缺席者，不得阻碍释奴，也不得剥夺其释奴，只要他们没有欺诈。

<!-- source-p 626 -->
<a id="40.5.36.1"></a>**1.**若某人由代理人出庭辩护，则始终应认为其因正当事由缺席，且不得剥夺其释奴。

<!-- source-p 627 -->
<a id="40.5.36.2"></a>**2.**任何人的特权，无论是因其个人、市镇、团体或所任职务，还是因其身份而享有，均不影响审理遗嘱信托式释奴案件者的管辖权。

<!-- source-p 628 -->
<a id="40.5.37"></a>**40.5.37**

<!-- source-p 629 -->
乌尔比安《遗嘱信托论》第六卷。

<!-- source-p 630 -->
若遗嘱信托式释奴是无条件设定的，而据称该奴隶曾管理账目，神圣的马尔库斯皇帝曾作敕答：不得因此迟延释奴，但应立即指定一名仲裁人审查账目。敕答内容如下：“较为公平的做法，是依遗嘱信托事由使特罗菲穆斯获得自由；可以确认，授予他的自由并未附加返还账目的条件。仅因涉及金钱的争议而迟延释奴，也有悖人道。不过，一旦该奴隶获得自由，裁判官应立即指定仲裁人，由其诚信审查该奴隶显然曾管理的账目。”因此，该奴隶仅被强令返还账目。但他是否还应返还其他财物，敕答没有说明；我认为不应强令其返还，因为不能就他在奴隶身份期间所为之事，在其自由后对其提起诉讼。当然，裁判官应强令其返还账簿原件，以及其从账目中扣留的任何物品或金钱；还应强令其就每一项事项作出说明。

<!-- source-p 631 -->
<a id="40.5.38"></a>**40.5.38**

<!-- source-p 632 -->
保罗《裁决集》第三卷。

<!-- source-p 633 -->
某人在一份未完成的遗嘱中，授予其养女自由并设定了遗嘱信托。各方已按无遗嘱继承的方式处理遗产，遂向皇帝询问：该女子是否视为依遗嘱信托事由获释。皇帝当庭裁示：即使父亲未在无遗嘱继承的安排中提出请求，其儿子们仍应基于孝道释放父亲所珍爱之人。因此，皇帝宣告该女子已合法获释，并判令仍应向她履行遗嘱信托。

<!-- source-p 634 -->
<a id="40.5.39"></a>**40.5.39**

<!-- source-p 635 -->
保罗《答复集》第十三卷。

<!-- source-p 636 -->
<a id="40.5.39.pr."></a>**序言。**保罗答复说，即使立遗嘱人命令某一继承人释放的奴隶实际上属于他人，而非立遗嘱人本人，也应强令受请求者赎买并释放该奴隶；因为他认为，自由遗嘱信托与金钱遗嘱信托并非同一性质。

<!-- source-p 637 -->
<a id="40.5.39.1"></a>**1.**保罗答复说，下列文字：“*pisteuson de moi, zwile, hoti tas xaritas soi apodwsei ho uhios mou martialios kai soi kai tois sois paisin*”（“请相信我，佐伊卢斯，我的儿子马尔提阿利斯会报答你和你的子女所受的恩惠”），充分表达了死者希望对其亲近之人佐伊卢斯施恩的意思。若这些亲近之人是奴隶，那么对他们而言，没有什么比给予自由更为可喜；因此，行省总督应遵从死者的意思。〔保留底本希腊文拉丁转写；其人名拼写可能有异。〕

<!-- source-p 638 -->
<a id="40.5.40"></a>**40.5.40**

<!-- source-p 639 -->
保罗《答复集》第十五卷。

<!-- source-p 640 -->
<a id="40.5.40.pr."></a>**序言。**卢基乌斯·提图斯将其女儿、自然所生的塞普提基娅赠与自己的女奴孔科尔狄娅。后来，他又在遗嘱中将上述女奴与其他奴隶一同遗赠给女儿，并请求女儿释放她。我询问：自然所生的女儿塞普提基娅能否被强令释放上述女奴？保罗答复：若该女奴是在自然父亲在世时赠与的，而女儿并未接受父亲在遗嘱中对其他遗赠所作的安排，则不能依遗嘱信托事由强令她释放自己的女奴。

<!-- source-p 641 -->
<a id="40.5.40.1"></a>**1.**卢基乌斯·提图斯将奴隶斯提库斯遗赠给梅维乌斯，并请求梅维乌斯及其继承人永不得释放该奴隶。保罗答复说，立遗嘱人后来仍可使该奴隶获得自由，因为他并未为自己设定限制，而是为受遗赠人设定限制。

<!-- source-p 642 -->
<a id="40.5.41"></a>**40.5.41**

<!-- source-p 643 -->
斯凯沃拉《答复集》第四卷。

<!-- source-p 644 -->
<a id="40.5.41.pr."></a>**序言。**“我的女奴泰伊丝在为我的继承人服役十年后，应成为我的女释奴。”有人询问：立遗嘱人虽希望她成为自己的女释奴，但继承人未能做到这一点，且直接释奴也并非无条件授予；泰伊丝在十年后是否仍会继续处于奴隶身份？答复说，没有任何已提出的事实足以说明为何泰伊丝不应获得自由。

<!-- source-p 645 -->
<a id="40.5.41.1"></a>**1.**卢基乌斯·提图斯曾作如下安排：“我最亲爱的儿子梅维乌斯，我请求你：若斯提库斯、达马斯和潘菲卢斯使你满意，在清偿债务后，不要让他们服侍他人。”有人询问：若因继承人的缘故未能清偿债务，这些奴隶能否依遗嘱信托事由获得自由？答复说，若继承人为了妥善管理自己的利益而较晚清偿债务，这一点不应归责于他；但若能证明其明显故意不清偿债务，目的是迟延释奴，则应立即给予他们自由。

<!-- source-p 646 -->
<a id="40.5.41.2"></a>**2.**立遗嘱人曾将自己遗嘱中为子女指定的监护人也列为继承人，并将释放该监护人自己奴隶之事托付给他；但该监护人后来获准免除监护职责。有人询问：是否应由替代该被免职者、实际履行监护职责的监护人，给予这些奴隶自由？答复说，依所述情形，应认为遗嘱指定的继承人也已授予这些人自由。

<!-- source-p 647 -->
<a id="40.5.41.3"></a>**3.**“给塞尤斯三磅黄金及我的书记奴隶斯提库斯；我请求你释放他。”塞尤斯在同一遗嘱中被指定为监护人，但他免除了监护职责。有人询问：是否仍负有遗嘱信托式释奴义务？答复说，没有任何已提出的事实足以说明为何不负有该义务。

<!-- source-p 648 -->
<a id="40.5.41.4"></a>**4.**某人指定其姊妹为继承人，并就奴隶作如下安排：“我愿意并请求，我最亲爱的姊妹，将我的管事奴隶斯提库斯和达马斯托付照料；他们是我的管理人，我没有释放他们，直至他们交代账目。若你也认可他们，我便向你说明我的意思。”〔底本希腊文拉丁转写如下：*Boulomai kai parakalw, glukutaty mou adelfy, en parakatavyky se exein stixon kai daman tous pragmateutas mou, ohus egw ouk yleuverwsa, axris an tas qyfous apokatastyswsin: ean de kai soi areswsin, emynusa soi tyn gnwmyn mou*。底本随附拉丁释义：愿我最亲爱的姊妹受托照料我的管事奴隶斯提库斯和达马斯；我没有释放他们，直至交还账目；若你也认可他们，我已向你说明我的意思。〕有人询问：若这些管理人已准备好交代账目，而继承人仍不释放他们，称自己不喜欢他们，是否应准许继承人如此决定？答复说，不应考虑继承人是否不喜欢他们，而应考虑善良之人会如何判断；他们应因此获得自由。

<!-- source-p 649 -->
<a id="40.5.41.5"></a>**5.**卢基娅·提提娅将奴婢潘菲拉及其子女托付给继承人，要求继承人为西娅赎买并释放他们；法官已评定每人的赎买价格。其间，在价金支付前，潘菲拉生下孩子。有人询问：潘菲拉所生之子女应属于西娅的继承人，还是提提娅的继承人？答复说，潘菲拉所生之子女应属于她生产时的所有人；但若继承人迟延履行遗嘱信托式释奴义务，也应强令其使该子女获得自由。

<!-- source-p 650 -->
<a id="40.5.41.6"></a>**6.**卢基乌斯·提图斯在遗嘱中如此安排：“我将某某医生托付给你；是否留用他们，由你决定，好让你有优秀的释奴和医生。若我已给予他们自由，我担心他们会像我亲爱的姊妹的那些奴隶医生一样：她释放了他们，他们在领完工资后便离她而去。”有人询问：上述安排是否使这些奴隶享有遗嘱信托式释奴请求权？答复说，依所述情形，立遗嘱人并未对继承人施加义务，而是将决定权交给继承人。

<!-- source-p 651 -->
<a id="40.5.41.7"></a>**7.**提图斯为其奴隶斯提库斯授予自由，条件是斯提库斯交代账目。有人询问：如何计算斯提库斯所处理的账目，偶然发生的损失是否不应由他承担？答复说，若所述事项系经主人同意而由奴隶管理，则奴隶不得归责的偶然损失，不应由其承担。

<!-- source-p 652 -->
<a id="40.5.41.8"></a>**8.**另有人询问：若奴隶被命令返还全部特有产，特有产是否仅应计算为扣除奴隶因任何事由所欠主人之债后剩余的部分？答复说，在所询问的情形中，不应从特有产中扣除其所欠主人的债务。

<!-- source-p 653 -->
<a id="40.5.41.9"></a>**9.**又有人询问：若奴隶将特有产中的部分款项用于清偿债务，返还特有产时是否应将该部分扣除？答复说，若依所述事由从特有产中支出的款项已用于清偿债务，只要将剩余特有产交付，即已满足条件。

<!-- source-p 654 -->
<a id="40.5.41.10"></a>**10.**立遗嘱人如此授予自由：“我的管家奴隶库彼图斯，在我的儿子马尔基安努斯年满十六岁且交代账目后，应成为自由人。”立遗嘱人死后，监护人委托库彼图斯催收债款；库彼图斯收回款项后，将款项记作支付给这些监护人。后来，未成年的儿子死亡，其母亲成为继承人，并在监护事务诉讼中判令监护人承担责任。库彼图斯在马尔基安努斯若仍在世本应年满十六岁的日期请求自由，并提交截至立遗嘱人死亡时的一年账目；其余账目已有监护人签署。有人询问：库彼图斯是否还应被强令交代监护人自行负责管理期间的账目？答复说，若库彼图斯已妥善交代其经手账目中可以合理要求的全部事项，就应认为他已满足交账条件。至于另一项条件，则可依较为宽厚的解释：未成年人既已死亡，只要等到他若仍在世本应年满十六岁之时，即属足够。

<!-- source-p 655 -->
<a id="40.5.41.11"></a>**11.**“我的奴隶斯提库斯和达马斯，若你们交代账目，即成为自由人。”有人询问：为了获得自由，他们是否不仅应交代账目，还应补偿其以其他方式、通过合谋或欺诈所隐匿的财物？答复说，交代账目的条件包括奴隶以任何方式实施、且涉及其诚信的一切行为。

<!-- source-p 656 -->
<a id="40.5.41.12"></a>**12.**这些奴隶未在指定期限内满足交账条件，后来才表示愿意交账。有人询问：他们是否仍会获得自由？答复说，若未能在规定期限内满足条件是他们自己的原因所致，他们不能仅因后来愿意交账就成为自由人。

<!-- source-p 657 -->
<a id="40.5.41.13"></a>**13.**“我请求并托付我的继承人：待我的儿子年满十六岁后，让斯提库斯交代账目并释放他。”有人询问：立遗嘱人是否希望斯提库斯也交代其儿子达到法定成年之前所处理的事务？答复说，显然，立遗嘱人希望斯提库斯也交代这段期间所处理事务的账目。

<!-- source-p 658 -->
<a id="40.5.41.14"></a>**14.**“我的奴隶斯提库斯应向我的女儿和妻子——我的继承人——无争议地给付若干枚金币；我也将释放他一事托付给她们。”有人询问：妻子放弃继承后，应由两人还是仅由女儿取得给付？答复说，既然所述女儿是全部遗产的唯一继承人，就应将全部给付交给女儿。

<!-- source-p 659 -->
<a id="40.5.41.15"></a>**15.**立遗嘱人指定其儿子为全部遗产的继承人，并以如下文字授予自由：“我的管家奴隶狄凯姆贝尔、农庄管理人塞维鲁斯，以及塞维鲁斯的女管家维克托莉娜，均应在八年后成为自由人；我希望他们继续为我儿子服役。最亲爱的儿子塞维鲁斯，我请求你照料狄凯姆贝尔和塞维鲁斯。我未立即给予他们自由，是为了使你有称职的仆役；我希望你最终也会有称职的释奴。”有人询问：立遗嘱人制作遗嘱时，其儿子已九岁；立遗嘱人又在两年六个月后死亡。释奴延后八年，应从遗嘱制作之日还是死亡之日起计算？答复说，可以认为立遗嘱人所说的八年是从制作遗嘱之日起计算，除非能够证明立遗嘱人另有意思。

<!-- source-p 660 -->
<a id="40.5.41.16"></a>**16.**“我的奴隶斯彭多福鲁斯在我女儿成婚并进入夫家后，若能适当地向我女儿交代账目，即成为自由人。”女儿尚未进入青春期时，在父亲生前死亡，其替补继承人为塞尤斯。有人询问：斯彭多福鲁斯并未管理未成年女儿的账目，而是在家父仍在世时停止管理家父的账目；若提提娅仍在世，届时将已年满十二岁以上，他是否依遗嘱获得自由？答复说，若他未管理任何需要向继承人交代的账目，则依所述情形，他应当是自由人。

<!-- source-p 661 -->
<a id="40.5.41.17"></a>**17.**“我要在斯提库斯交代账目后释放他。”斯提库斯是出纳奴隶，在主人认可后登记账目并提交经主人签署的账册，之后未再登记任何事项。有人询问：若有些债务人无力偿付，且其他催收人已接手这些债务，是否仍应认为交账条件尚未满足？答复说，依所述情形，债务人无力偿付，不属于奴隶交代账目时所承担的责任。

<!-- source-p 672 -->
乌尔比安《论争辩》第五卷。

<!-- source-p 673 -->
<a id="40.5.45.pr."></a>**序言。**若债权人请求债务人释放自己已设质的女奴，应认为债务人有效地接受了通过遗嘱信托给予自由的安排。无论债权人遗留给他一笔确定金额，还是通过遗嘱信托为女奴设定自由，二者有何区别？无论奴隶价格高于还是低于该金额，只要债务人已承认债权人的意思，就应强令其履行释奴义务。所谓承认，是指债权人的继承人向债务人提出请求时，债务人曾援引抗辩，或以其他方式表明自己承认该意思。若债权人的继承人起诉债务人，则债务人可以援引欺诈抗辩，限于其因保有自己的女奴而获得利益的范围。

<!-- source-p 674 -->
<a id="40.5.45.1"></a>**1.**在遗嘱信托式释奴中，即使某人所得遗赠甚少，也必须释放自己的奴隶。若金钱遗嘱信托被分割履行，将对自由造成损害，其程度不亚于对遗嘱信托受益人的损害。因此，宁可使已经接受遗赠的人承担义务，也不应使自由落空。

<!-- source-p 675 -->
<a id="40.5.45.2"></a>**2.**每当通过遗嘱信托为男奴或女奴设定自由时，在其被释放之前，他仍处于奴隶身份。若负有释奴义务者没有造成释奴迟延，其身份不会发生任何变化。因此，可以将其遗赠，但遗赠应连同其现有法律关系一并移转。

<!-- source-p 676 -->
<a id="40.5.46"></a>**40.5.46**

<!-- source-p 677 -->
乌尔比安《论争辩》第六卷。

<!-- source-p 678 -->
<a id="40.5.46.pr."></a>**序言。**遗嘱信托式释奴可以如此设定：“继承人，若你愿意，我托付你释放斯提库斯。”虽然在遗嘱中，其他任何事项都不能仅凭继承人的意愿而有效，但释奴可以如此设定。

<!-- source-p 679 -->
<a id="40.5.46.1"></a>**1.**当然，也可以将奴隶本人的意愿作为条件，例如写道：“若斯提库斯愿意”。

<!-- source-p 680 -->
<a id="40.5.46.2"></a>**2.**若写道“若塞尤斯愿意，我希望斯提库斯成为自由人”，我认为也可认定释奴有效，因为这更像是一项条件，犹如“若提图斯登上卡皮托山，则将遗赠给我”。

<!-- source-p 681 -->
<a id="40.5.46.3"></a>**3.**但若写道“若继承人愿意”，则不发生效力；只有在一切均取决于继承人的意愿、由其自行决定是否愿意时，才如此。反之，若立遗嘱人将裁量交给继承人，要求其如善良之人那样判断，我们毫不怀疑释奴义务成立。例如，立遗嘱人写道“若你认为合适，请释放奴隶”，已被认可为产生释奴义务；此处应理解为“若你作为善良之人认为合适”。我认为，下列措辞也会产生同样效果：“若你认可我的意思”；以及“若他使你满意”，应理解为使善良之人满意；“若他没有冒犯你”，应理解为没有冒犯善良之人；“若你认可他”“若你没有否定他”或“若你认为他值得”。有人曾以希腊文设定遗嘱信托：“*tō deini, ean dokimasēs, eleutherian dothēnai boulomai*”（“若你认可某人，我希望给予其自由”）；神圣的塞维鲁皇帝曾作敕答，称可以请求履行该遗嘱信托。

<!-- source-p 682 -->
<a id="40.5.46.4"></a>**4.**是否负有义务，不能交由继承人裁量；但义务应于何时履行，则可以交由其裁量。

<!-- source-p 683 -->
<a id="40.5.46.5"></a>**5.**某人遗赠三名奴隶，并将从中选择两名释放之事托付给继承人，允许其自行选择。该遗嘱信托式释奴有效，继承人可以释放其中任意两名。因此，若受遗赠人请求取得继承人希望释放的奴隶，将因欺诈抗辩而被驳回。

<!-- source-p 685 -->

<!-- source-p 686 -->
<a id="40.5.47.pr."></a>**序言。**若父亲指定两名儿子为继承人，而遗腹子出生导致遗嘱被打破，即使两名儿子各自取得遗产的一半，也不应履行遗嘱信托式释奴；正如他们不必履行遗赠或其他遗嘱信托一样。

<!-- source-p 687 -->
<a id="40.5.47.1"></a>**1.**若受请求者受托释放他人所有、共同所有或他人享有用益权的奴隶，却藏匿不出席，元老院决议不无道理地为释奴提供救济。

<!-- source-p 688 -->
<a id="40.5.47.2"></a>**2.**若遗嘱信托规定斯提库斯在交代账目后获得自由，而继承人缺席时，他已准备交出剩余款项，则裁判官应选任一名善良之人，由其裁量核算账目；奴隶应存放依核算所得的款项，随后裁判官应宣告依遗嘱信托事由负有释奴义务。若继承人因正当事由缺席，宜如此处理；若其藏匿，则裁判官只须确认并非奴隶本人导致其未能满足条件，随后即应宣告释奴。

<!-- source-p 689 -->
<a id="40.5.47.3"></a>**3.**若遗赠奴隶附条件授予自由，则在向遗嘱信托受益人交付该奴隶时，必须要求其承诺：条件成就时将使奴隶获得自由。

<!-- source-p 690 -->
<a id="40.5.47.4"></a>**4.**一名女子病危时，在数名有身份的男子及其母亲在场的情况下——其母本可依法继承其遗产——她如此说道：“我希望我的女奴梅维娅和塞娅成为自由人。”随后她未订立遗嘱便死亡。有人询问：若其母未依据元老院决议主张法定继承，而遗产转归最近的旁系亲属，是否负有遗嘱信托式释奴义务？我答复说，仍负有该义务。因为在临终时说“我希望我的女奴某某和某某成为自由人”的人，应视为已请求所有将成为法定继承人或遗产占有人的人，使其实现这一意思。

<a id="40.5.51"></a>**40.5.51**

<!-- source-p 701 -->
马尔基安《法学阶梯》手册第九卷。

<!-- source-p 702 -->
<a id="40.5.51.pr."></a>**序言。**不仅受请求者本人可以使奴隶获得自由，其继承人也可以，无论通过买受或其他方式继受。若没有任何继受人出现，奴隶便转归国库，并由国库履行释奴义务。

<!-- source-p 703 -->
<a id="40.5.51.1"></a>**1.**受请求释奴之人即使在被禁止转让财产期间，也可以释放奴隶。

<!-- source-p 704 -->
<a id="40.5.51.2"></a>**2.**若某人受请求释放他人之奴隶，并获遗赠一笔确定金额用于买下并释放该奴隶，而奴隶所有人拒绝出售，则受请求者仍可依死者意思保有该笔遗赠。

<!-- source-p 705 -->
<a id="40.5.51.3"></a>**3.**依遗嘱信托负有自由请求权的奴隶，在某种意义上处于自由人地位；他也处于附条件获释奴隶（*statuliber*）的地位，甚至更应如此，因为不得将他转让给他人，以免妨碍其自由，或使他遭受更为严苛的释奴保护人权利。

<!-- source-p 706 -->
<a id="40.5.51.4"></a>**4.**《达苏米安元老院决议》规定：若负有遗嘱信托式释奴义务之人因正当事由缺席，且已作出此项宣告，则奴隶应享有释奴权利，其情形犹如已依遗嘱信托事由被适当地释放一样。

<!-- source-p 707 -->
<a id="40.5.51.5"></a>**5.**所谓缺席，是指未出现在法庭上。

<!-- source-p 708 -->
<a id="40.5.51.6"></a>**6.**由于该元老院决议最初仅对继承人作出规定，后来又增补规定：若因任何事由宣告某人或数人缺席，而其负有遗嘱信托式释奴义务，则应视为奴隶已依遗嘱信托事由被适当释放。

<!-- source-p 709 -->
<a id="40.5.51.7"></a>**7.**《阿尔提库雷安元老院决议》则规定，即使继承人不属于该行省，也由行省总督审理此类事项。

<!-- source-p 710 -->
<a id="40.5.51.8"></a>**8.**若受请求者受托释放的不是遗产奴隶，而是自己的奴隶，则依《尤恩基安元老院决议》，经宣告后奴隶即获得自由。

<!-- source-p 711 -->
<a id="40.5.51.9"></a>**9.**神圣的皮乌斯皇帝曾作敕答：无论受请求者因正当事由缺席、藏匿，还是虽在场却不愿释奴，均应视为其缺席。

<!-- source-p 712 -->
<a id="40.5.51.10"></a>**10.**同一元老院决议还明确规定，买受人也负有释奴义务。

<!-- source-p 713 -->
<a id="40.5.51.11"></a>**11.**到场的共同继承人应当释放奴隶，其情形犹如另一共同继承人已将奴隶交付给他。传述说，同一皇帝也曾对一名未受请求释奴的未成年共同继承人作出敕答，确认适用此规则。

<!-- source-p 714 -->
<a id="40.5.51.12"></a>**12.**若某人受请求释奴的目的是与奴隶结婚，则不得强令其娶该人为妻；履行遗嘱信托式释奴义务即已足够。

<a id="40.5.55.pr."></a>**序言。**若继承人并非故意迟延接受遗产，而是在考虑是否接受期间发生迟延，也应作相同处理。若女奴生育后，继承人才得知自己被指定为继承人，也应给予救济；但在此情形中，应由继承人本人释放子女，而非将子女交给母亲。

<a id="40.5.55.1"></a>**1.**若女奴被直接授予自由，并发生上述任一情形，应如何救济其子女？在遗嘱信托式释奴中，奴隶可以提出请求，裁判官也会为婴儿提供救济；但在直接授予自由的情形中，并无此种请求。即使如此，我仍认为应当救济婴儿：裁判官应向母亲授予对物诉权，参照遗嘱信托式释奴的规则。马尔凯卢斯在《学说汇纂》第十六卷中也如此写道；对于遗嘱中获释、但在继承人接受遗产前被他人取得时效的奴隶，也应提供救济，以便通过裁判官保全其自由，尽管也可以归责于他们为何会被取得时效。婴儿则不存在任何可归责之处。

<a id="40.5.56"></a>**40.5.56**

<!-- source-p 730 -->
马尔凯卢斯《答复集》单行本。

<!-- source-p 731 -->
卢基乌斯·提图斯在遗嘱中如此安排：“我希望我所留下的任何遗嘱附录均有效。若我与曾为我妻子的保拉在十个月内生下任何子女，该子女应取得一半遗产。盖乌斯·塞尤斯取得另一半遗产。我请求并托付我的继承人：当我的子女到达青春期时，释放我的奴隶斯提库斯和潘菲卢斯，以及厄洛斯和狄菲卢斯。”他随后又在遗嘱末尾规定：“若我没有子女出生，或子女在青春期前死亡，则穆基乌斯和梅维乌斯应各继承一半。我希望我在先前遗嘱中、即指定儿子和塞尤斯为继承人的遗嘱中所留下的遗赠，也由后继继承人履行。”他又在遗嘱附录中规定：“卢基乌斯·提图斯致最初继承人及替补继承人：我请求你们履行我在遗嘱中及遗嘱附录中所作的处分和遗赠。”我询问：既然卢基乌斯·提图斯没有子女出生，是否应立即以遗嘱信托方式释放奴隶斯提库斯、潘菲卢斯、厄洛斯和狄菲卢斯？马尔凯卢斯答复说，若立遗嘱人原本将奴隶自由附加条件——即其子女成为继承人——则该条件应认为没有被重复设定，因此最初继承人和替补继承人均应立即履行释奴义务。因为如上所述，立遗嘱人请求履行其在遗嘱中的安排，而其中确有对这些奴隶自由的安排。不过，他确实为释奴附加了条件；若是另一种条件，本应等待条件成就。但考虑到他将义务托付给替补继承人，而若该条件成就，替补继承人根本不会取得遗产，便不应认为立遗嘱人在此情形下有意等待该条件。
