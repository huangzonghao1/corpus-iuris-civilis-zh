# D.40.4 论遗嘱释奴（*De manumissis testamento*，第四段）

<!-- source-p 361 -->
<a id="40.4.46"></a>**40.4.46**

<!-- source-p 362 -->
庞波尼乌斯《异读集》第七卷。

<!-- source-p 363 -->
阿里斯托曾答复涅拉提乌斯·阿皮安努斯：某奴隶在年满三十岁时依遗嘱获释，但在达到该年龄之前被判处矿场刑罚，之后又被召回。毫无疑问，附有释奴安排的遗赠仍归该奴隶享有；被判处矿场刑罚不会改变他的权利。若该奴隶被附条件指定为继承人，结论也相同，因为他之后也会成为必然继承人。

<!-- source-p 364 -->
<a id="40.4.47"></a>**40.4.47**

<!-- source-p 365 -->
帕比尼安《疑问集》第六卷。

<!-- source-p 366 -->
<a id="40.4.47.pr."></a>**序言。**若继承人因错误而依据虚假的遗嘱附录释放奴隶，尽管依法并无释放义务，元首规定每一名获释者应向继承人缴纳二十索里德。

<!-- source-p 367 -->
<a id="40.4.47.1"></a>**1.**若继承人为履行条件而释放奴隶，之后儿子提起遗嘱失当之诉并胜诉，或者遗嘱被宣告为伪造，也应适用关于虚假遗嘱附录的同一规则。

<!-- source-p 368 -->
<a id="40.4.48"></a>**40.4.48**

<!-- source-p 369 -->
帕比尼安《疑问集》第十卷。

<!-- source-p 370 -->
若共有人的一方在遗嘱中如此给予自由：“若我的共有人释放潘菲卢斯，潘菲卢斯应获自由”，塞尔维乌斯答复说，共有人释放该奴隶时，他将同时成为全体共有人的释奴以及实际释放者的释奴。因为以不同法律方式使共有奴隶获得自由，并非新奇或罕见的做法。

<a id="40.4.49"></a>**40.4.49**

<!-- source-p 372 -->
帕比尼安《答复集》第六卷。

<!-- source-p 373 -->
军人在遗嘱中写道“我命令萨米娅处于自由状态”，通说认为该女奴依军人法取得直接自由。

<!-- source-p 374 -->
<a id="40.4.50"></a>**40.4.50**

<!-- source-p 375 -->
帕比尼安《答复集》第九卷。

<!-- source-p 376 -->
<a id="40.4.50.pr."></a>**序言。**神皇马尔库斯为维持释奴安排所作的规定，适用于遗嘱无效、财产将被出售的情形；但若财产因无人继承而归国库请求收取，该敕令明确不适用。

<!-- source-p 377 -->
<a id="40.4.50.1"></a>**1.**为受领遗产，遗嘱释奴也应依法提供适当担保，和死者的其他释奴或外人一样。若遗嘱指定未成年人为继承人，而其请求依通常方式获得保护遗产的救济，则不因此剥夺此项利益。

<!-- source-p 378 -->
<a id="40.4.51"></a>**40.4.51**

<!-- source-p 379 -->
帕比尼安《答复集》第十四卷。

<!-- source-p 380 -->
<a id="40.4.51.pr."></a>**序言。**一名百夫长在遗嘱中禁止出售其奴隶，并请求按照各奴隶的表现释放他们。他答复说，这些自由安排均有效，因为只要没有奴隶犯下过错，他们都可获得自由；若有人因过错被排除，其余奴隶仍可获得自由。

<!-- source-p 381 -->
<a id="40.4.51.1"></a>**1.**若遗嘱写道：“未犯过错的奴隶均应获得自由”，通说认为这是一项附加条件，应作如下解释：对于因受处罚而被排除，或被免除服务荣誉、被解除管理事务职务的人，遗嘱人并未打算给予自由。

<!-- source-p 382 -->
<a id="40.4.52"></a>**40.4.52**

<!-- source-p 383 -->
保罗《疑问集》第十二卷。

<!-- source-p 384 -->
皇帝们答复米塞尼乌斯·弗龙托：“某军人在遗嘱中以如下文字给予自由：‘我希望我的奴隶斯特法努斯自由’，或‘我命令……’遗产经接受后，自由安排即生效。因此，后来附加的文字——‘但他应留在我的继承人身边，直至〔原文：*invenis*〕；若他不愿意或轻慢此命令，则应依奴隶身份受拘束’——不能撤销已经生效的自由。”平民遗嘱也适用同一规则。

<!-- source-p 385 -->
<a id="40.4.53"></a>**40.4.53**

<!-- source-p 386 -->
保罗《答复集》第十五卷。

<!-- source-p 387 -->
卢基乌斯·提图斯给予一名奴隶自由，条件是该奴隶以诚信向其子盖尤斯·塞尤斯交代自己经手的账目。盖尤斯·塞尤斯成年后，奴隶经其保佐人允许，即使在法官面前也已履行一切义务；保佐人于是宣告条件已经成就、该奴隶成为自由人。现在，提图斯之子盖尤斯·塞尤斯声称，奴隶向他的保佐人交款并不合法。我问，这笔钱是否已依法清偿。保罗答复说：若仅向未成年人保佐人交代剩余账目，似乎并未依法履行遗嘱条件；但若在未成年人在场时交款，或已记入其账目，就应视为条件已经成就，如同直接向未成年人清偿一样。

<a id="40.4.54"></a>**40.4.54**

<!-- source-p 389 -->
斯凯沃拉《答复集》第四卷。

<!-- source-p 390 -->
<a id="40.4.54.pr."></a>**序言。**某人拥有奴隶克拉提斯图斯，并在遗嘱中写道：“我的奴隶克拉提努斯应获自由。”我问，既然遗嘱人没有名为克拉提努斯的奴隶，只有克拉提斯图斯，该奴隶能否获得自由。他答复说，遗嘱人写错一个音节并无妨碍。
