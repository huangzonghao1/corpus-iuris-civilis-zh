# D.40.16 论揭发串通（*De collusione detegenda*）

> **底本范围：**EPUB 全部段落元素的连续编号 source-p 1392–1412，共21段；按源序保留题名、出处、分题及锚点。

<!-- source-p 1392 -->
<a id="40.16"></a>**40.16.0 论揭发串通。**

<!-- source-p 1393 -->
<a id="40.16.1"></a>**40.16.1**

<!-- source-p 1394 -->
盖尤斯《城市裁判官告示评注·自由身份诉讼标题》。

<!-- source-p 1395 -->
为避免某些主人对奴隶过分宽纵，以致奴隶得以宣称自己是自由出生者并被判为自由人，从而玷污最尊贵的元老院等级，图密善在位时作出一项元老院决议。该决议规定：若有人证明某事系经串通而为，且该人实际上是奴隶，则此人应成为揭发该串通者的奴隶。

<!-- source-p 1396 -->
<a id="40.16.2"></a>**40.16.2**

<!-- source-p 1397 -->
乌尔比安《论执政官职责》第二卷。

<!-- source-p 1398 -->
<a id="40.16.2.pr."></a>**序言。**神圣的马尔库斯皇帝确认，在作出自由出生判决后五年内，可以揭发有关自由身份的串通。

<!-- source-p 1399 -->
<a id="40.16.2.1"></a>**1.**五年期间应理解为连续计算的期间。

<!-- source-p 1400 -->
<a id="40.16.2.2"></a>**2.**若被指串通者的年龄使人认为，应将复审推迟至其达到青春期或其他适当时点，则应认为五年期间尚未开始计算。

<!-- source-p 1401 -->
<a id="40.16.2.3"></a>**3.**我认为，规定五年期间，是为了启动复审，而非要求在此期间内完成复审。这与自由释奴声称自己是自由出生者的情形不同。

<!-- source-p 1402 -->
<a id="40.16.2.4"></a>**4.**神圣的马尔库斯皇帝在敕令中规定，即使是有权代他人提出请求的外人，也可以揭发串通。

<!-- source-p 1403 -->
<a id="40.16.3"></a>**40.16.3**

<!-- source-p 1404 -->
卡利斯特拉图《审判程序论》第四卷。

<!-- source-p 1405 -->
若某人并非在有适格对方参与的情况下被判定为自由出生者，该裁定即属无效，其情形犹如从未作出任何裁判；元首敕令对此已有规定。

<!-- source-p 1406 -->
<a id="40.16.4"></a>**40.16.4**

<!-- source-p 1407 -->
乌尔比安《尤利亚法与帕皮亚法评注》第一卷。

<!-- source-p 1408 -->
若自由释奴经串通被判为自由出生者，一旦串通被揭发，他在何种事项中开始按自由释奴身份处理？不过，在串通被揭发之前、且自由出生判决已经作出之后的中间期间，应一概视其为自由出生者。

<!-- source-p 1409 -->
<a id="40.16.5"></a>**40.16.5**

<!-- source-p 1410 -->
赫尔莫革尼安《法学撮要》第五卷。

<!-- source-p 1411 -->
<a id="40.16.5.pr."></a>**序言。**以串通为由，对宣告某人为自由出生者的判决，只准许复审一次。

<!-- source-p 1412 -->
<a id="40.16.5.1"></a>**1.**若数人同时提出揭发串通的请求，应在审理案情后，比较各人的品行、年龄及各自利益大小，再决定准许何人提出请求。
