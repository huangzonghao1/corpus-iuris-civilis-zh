<!-- source-p 1201 -->
<a id="40.12.13.pr."></a>**序言。**确定的是，在此项法定诉权中，只有因故意造成的损害才计入，过失造成的损害不计入。因此，即使被告在本诉中获判无责，仍可随后依《阿奎利亚法》对其提起诉讼，因为该法也使过失行为人承担责任。

<!-- source-p 1202 -->
<a id="40.12.13.1"></a>**1**　确定的是，我们自己的物以及他人的物，只要风险由我们承担，均可纳入此项诉讼，例如借用物或租赁物。至于寄存在我们处的物品，由于风险不由我们承担，不适用此项诉讼。

<a id="40.12.14.pr."></a>**序言。**裁判官十分妥当地制止了这样一些人的狡诈：他们明知自己是自由人，却出于恶意欺诈，听任自己被当作奴隶出售。

<!-- source-p 1206 -->
<a id="40.12.14.1"></a>**1**　裁判官为此类人设置了一项诉权。每当听任自己被出售的人并不属于不得主张自由身份的情形时，此项诉权即适用。

<a id="40.12.16"></a>**40.12.16**

<a id="40.12.16.pr."></a>**序言。**不如说，此项诉权针对的是这样的人：他假装自己是奴隶，并以奴隶身份出售自己，以此欺骗买受人。

<!-- source-p 1214 -->
<a id="40.12.16.1"></a>**1**　但若被出售者是受暴力或胁迫所逼，我们应认为他没有实施欺诈。

<!-- source-p 1215 -->
<a id="40.12.16.2"></a>**2**　买受人只有在不知道对方是自由人时才享有此项诉权；若他明知对方是自由人仍照样购买，那是他自己欺骗了自己。

<!-- source-p 1216 -->
<a id="40.12.16.3"></a>**3**　因此，若家子购买此人，而家子知道其为自由人、父亲却不知道，父亲不取得此项诉权；但这仅指家子以特有产名义购买的情形。若家子是奉父亲之命购买，则应讨论家子的知情是否对父亲不利；我认为仍然不利，正如代理人的知情也会产生同样效果。

<!-- source-p 1217 -->
<a id="40.12.16.4"></a>**4**　当然，若家子不知情而父亲知情，我仍认为应驳回父亲的请求；即使家子以特有产名义购买也如此，只要父亲当时在场且能够阻止儿子购买。

<a id="40.12.20"></a>**40.12.20**

<!-- source-p 1229 -->
乌尔比安《告示评注》第五十五卷。

<!-- source-p 1230 -->
<a id="40.12.20.pr."></a>**序言。**即使尚未给付而仅负有支付义务，也应按双倍承担。

<!-- source-p 1231 -->
<a id="40.12.20.1"></a>**1**　因此，若某人因该诉讼而依法向他人给付了任何款项，应认为该给付落入本告示的适用范围，须按双倍承担。

<!-- source-p 1232 -->
<a id="40.12.20.2"></a>**2**　我们应将“负有支付义务”理解为既包括对出卖人负有义务，也包括对他人负有义务。无论款项由其本人或他人支付，无论支付给出卖人本人，还是应出卖人之命支付给他人，均属适用范围。

<!-- source-p 1233 -->
<a id="40.12.20.3"></a>**3**　只有在其无法援引抗辩保护自己时，才应认为其负有支付义务；若其能够援引抗辩，则应认定其并无此项义务。

<!-- source-p 1234 -->
<a id="40.12.20.4"></a>**4**　有时，买受人可以提起双倍责任诉讼，从而获得四倍请求权：就明知而将自由人作为奴隶出售的人，买受人可依本告示对其提起双倍诉讼；此外，买受人还可对出卖人或承诺承担双倍责任者提起另一双倍诉讼，……

<!-- source-p 1235 -->
<a id="40.12.21"></a>**40.12.21**

<!-- source-p 1236 -->
莫德斯蒂努斯《刑罚论》第一卷。

<!-- source-p 1237 -->
<a id="40.12.21.pr."></a>**序言。**无论如何，均应按因买卖已支付或负有支付义务的金额计算双倍。由此，一方所支付的金额不影响另一方免责，因为该诉讼被认定为惩罚性诉讼。因此，超过一年不再准许提起该诉讼；由于其具有惩罚性，也不得对继承人提起。

<!-- source-p 1238 -->
<a id="40.12.21.1"></a>**1**　正确的说法是，因该告示产生的诉权不因释奴而消灭；因为可能出现这样的情形：真正实施该行为的人无法被起诉，随后请求便转向主张自由身份之人。〔此句中 *auctorem conveniri non posse, post quem ad eum ... perveniebatur* 的语法和程序关系较省略，译文暂按上下文处理。〕

<!-- source-p 1239 -->
<a id="40.12.22"></a>**40.12.22**

<!-- source-p 1240 -->
乌尔比安《告示评注》第五十五卷。

<!-- source-p 1241 -->
<a id="40.12.22.pr."></a>**序言。**不只有买受人本人能够依据此项法定诉权起诉，其继承人及其他继受人也可以。

<!-- source-p 1242 -->
<a id="40.12.22.1"></a>**1**　“购买”应作如下理解：即使某人通过他人购买，例如通过代理人购买，也属于购买。

<!-- source-p 1243 -->
<a id="40.12.22.2"></a>**2**　若有数名买受人，他们也都享有此项诉权；但若他们按份购买，则各自只能就相应份额的价金提起诉讼；若每人均按全部价金购买，则每人均可就全部价金提起诉讼。一人的知情不会损害另一人，一人的不知情也不会使另一人受益。

<!-- source-p 1244 -->
<a id="40.12.22.3"></a>**3**　若买受人购买时不知道对方是自由人，后来才知道，这对他没有不利，因为他购买时并不知情。反之，若他当时知道，后来才开始怀疑，则毫无益处。

<!-- source-p 1245 -->
<a id="40.12.22.4"></a>**4**　对于继承人及其他继受人而言，其自身的知情没有不利影响；其不知情也不能使其获益。
