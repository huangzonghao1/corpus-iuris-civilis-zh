# D.40.2 论以仪式杖释奴（*De manumissis vindicta*）

> 底本：*Digesta Iustiniani*，Mommsen–Krüger 文本，book-40.xhtml，source-p 103–194。

<!-- source-p 103 -->
<a id="40.2"></a>**40.2.0 论以仪式杖释奴**（*De manumissis vindicta*）。

<!-- source-p 104 -->
<a id="40.2.1"></a>**40.2.1**

<!-- source-p 105 -->
庞波尼乌斯《评萨宾》第一卷。

<!-- source-p 106 -->
可以确定，受监护的未成年人能够在裁判官面前、并由该裁判官兼任其监护人时，经该监护人认可而解放奴隶。

<!-- source-p 107 -->
<a id="40.2.2"></a>**40.2.2**

<!-- source-p 108 -->
乌尔比安《评萨宾》第十八卷。

<!-- source-p 109 -->
如果用益权人未满二十岁，他能否同意奴隶获得自由？我认为，他可以通过表示同意而使奴隶获得自由。

<!-- source-p 110 -->
<a id="40.2.3"></a>**40.2.3**

<!-- source-p 111 -->
乌尔比安《论争》第四卷。

<!-- source-p 112 -->
如果继承人解放了被遗赠的奴隶，之后受遗赠人又拒绝接受遗赠，则该奴隶的自由追溯发生。两人被无条件遗赠同一奴隶的情形也相同：一人解放奴隶后，另一人拒绝接受遗赠的，该奴隶的自由同样追溯发生。

<!-- source-p 113 -->
<a id="40.2.4"></a>**40.2.4**

<!-- source-p 114 -->
尤利安《学说汇纂》第四十二卷。

<!-- source-p 115 -->
<a id="40.2.4.pr."></a>**序言**　父亲准许儿子解放一名奴隶，此后父亲无遗嘱死亡；儿子不知父亲已经死亡，便使该奴隶获得自由。基于有利于自由的原则，应使该奴隶取得自由，因为看不出主人的意思曾经改变。反之，若父亲在儿子不知情时通过信使撤回许可，而儿子尚未获知此事便解放了奴隶，则该奴隶不能成为自由人。儿子解放奴隶而使其取得自由，必须以父亲的意思持续存在为前提；若父亲的意思已经改变，就不能说儿子是在父亲同意的情况下解放奴隶。

<!-- source-p 116 -->
<a id="40.2.4.1"></a>**1**　主人解放奴隶时，即使误以为该奴隶属于他人，仍应认为奴隶是依主人的意思被解放，因此成为自由人。反过来，即使斯提库斯误以为解放他的人不是自己的主人，也仍能取得自由。法律关系的实情重于当事人的认识；两种情形下，均应认为斯提库斯是依主人意思被解放。即使主人和奴隶都误以为双方之间不存在主人与奴隶的关系，法律也作相同处理。

<!-- source-p 117 -->
<a id="40.2.4.2"></a>**2**　未满二十岁的主人，即使要解放共有奴隶，也不得在没有顾问团参与的情况下合法解放。保罗注：但是，未满二十岁的人若允许解放以其为质权人之质物的奴隶，该解放仍属有效；因为应理解为他并非亲自解放奴隶，而只是没有阻止他人解放。

<!-- source-p 118 -->
<a id="40.2.5"></a>**40.2.5**

<!-- source-p 119 -->
尤利安《学说汇纂》第四十二卷。

<!-- source-p 120 -->
经常有人讨论：为释奴提供意见的人能否在自己面前解放奴隶。我记得，我的老师雅沃勒努斯在阿非利加和叙利亚任职、为人提供意见时，曾解放自己的奴隶。于是我效法他的做法，在担任裁判官和执政官期间，以仪式杖解放了自己的一些奴隶；有些裁判官征询我的意见时，我也向他们提出同样的建议。

<!-- source-p 121 -->
<a id="40.2.6"></a>**40.2.6**

<!-- source-p 122 -->
尤利安《评乌尔塞尤斯·费罗克斯》第二卷。

<!-- source-p 123 -->
毫无疑问，未满二十岁的共有人可以在顾问团面前解放共有奴隶，即使只有其中一名共有人证明了释奴的正当原因，亦不影响解放。

<!-- source-p 124 -->
<a id="40.2.7"></a>**40.2.7**

<!-- source-p 125 -->
盖尤斯《日常法律问题》（又称《黄金篇》）第一卷。

<!-- source-p 126 -->
释奴并非必须在法庭席前进行。因此，裁判官、行省总督或皇帝特使出外沐浴、乘车或观看表演时，奴隶常在途中获释。

<!-- source-p 127 -->
<a id="40.2.8"></a>**40.2.8**

<!-- source-p 128 -->
乌尔比安《评告示》第五卷。

<!-- source-p 129 -->
我曾与裁判官一同在别墅时，允许有人在他面前解放奴隶，即使当时没有执仪吏在场。

<!-- source-p 130 -->
<a id="40.2.9"></a>**40.2.9**

<!-- source-p 131 -->
马尔基安《法学阶梯》第十三卷。

<!-- source-p 132 -->
<a id="40.2.9.pr."></a>**序言**　奴隶曾使主人免于生命危险或名誉受损的，构成释奴的正当原因。

<!-- source-p 133 -->
<a id="40.2.9.1"></a>**1**　应当知道，只要某项原因已经得到证明并被认可，就应准予自由。神圣的安敦尼·庇护皇帝曾以敕答指出，已经证明的原因不应被撤销，但任何人不得因此解放他人的奴隶。反对意见应针对释奴原因的证明提出；原因一经证明，就不得再行翻案。

<!-- source-p 134 -->
<a id="40.2.10"></a>**40.2.10**

<!-- source-p 135 -->
马尔基安《规则》第三卷。

<!-- source-p 136 -->
聋哑父亲的儿子可以奉父亲之命解放奴隶；但父亲患精神错乱时，其儿子不得这样做。

<!-- source-p 137 -->
<a id="40.2.11"></a>**40.2.11**

<!-- source-p 138 -->
乌尔比安《论行省总督的职务》第六卷。

<!-- source-p 139 -->
未满二十岁者解放奴隶时，通常可被认可为释奴正当原因的有：该奴隶是其儿子或女儿，或是其同母异父或同父异母的兄弟、姐妹。

<!-- source-p 140 -->
<a id="40.2.12"></a>**40.2.12**

<!-- source-p 141 -->
乌尔比安《评〈埃利亚·森提亚法〉》第二卷。

<!-- source-p 142 -->
或者，该奴隶与释奴人有血亲关系（因为法律会考虑亲属关系）。

<!-- source-p 143 -->
<a id="40.2.13"></a>**40.2.13**

<!-- source-p 144 -->
乌尔比安《论行省总督的职务》。

<!-- source-p 145 -->
如果该奴隶是乳兄弟、养育者、释奴人的家庭教师、乳母，或上述任何人的儿子或女儿；如果该奴隶是由释奴人抚养长大的孩子、书籍携带者（*capsarius*，即携带书籍的人）；或者解放该奴隶是为了使其担任代理人，均可构成正当原因，但释奴人不得未满十八岁。此外还要求释奴人并非只有这一名奴隶。若以结婚为由解放未婚女子或妇女，还必须事先取得誓言，保证在六个月内娶她为妻；元老院即作此决议。

<!-- source-p 146 -->
<a id="40.2.14"></a>**40.2.14**

<!-- source-p 147 -->
马尔基安《规则》第四卷。

<!-- source-p 148 -->
<a id="40.2.14.pr."></a>**序言**　由妇女解放受其抚养的孩子更为适宜；不过，男子解放这类孩子也已为法律所承认。只要释奴人曾以更深厚的感情抚养该人，并准许其获释，就已足够。

<!-- source-p 149 -->
<a id="40.2.14.1"></a>**1**　有人认为，妇女也可以为结婚而解放奴隶，但前提是该奴隶曾作为同一奴隶主的奴隶，为此目的遗赠给她。阉人若愿为结婚而解放奴隶，可以这样做；被阉割者则不适用同一规则。

<!-- source-p 150 -->
<a id="40.2.15"></a>**40.2.15**

<!-- source-p 151 -->
保罗《评〈埃利亚·森提亚法〉》第一卷。

<!-- source-p 152 -->
<a id="40.2.15.pr."></a>**序言**　为履行附加条件，也应允许未满二十岁者解放奴隶；例如，某人被指定为继承人，条件是使一名奴隶取得自由。

<!-- source-p 153 -->
<a id="40.2.15.1"></a>**1**　过去发生的行为可以构成多种释奴原因，例如奴隶曾在战斗中帮助主人、保护主人免遭强盗侵害、治愈主人的疾病，或揭露针对主人的埋伏。若要逐一列举，篇幅将不胜其长，因为奴隶可能作出许多值得以裁定准予自由的贡献。审理此事的人应当评估这些行为。

<!-- source-p 154 -->
<a id="40.2.15.2"></a>**2**　可以同时以仪式杖解放数名奴隶；奴隶们在场即可，足以同时解放多人。

<!-- source-p 155 -->
<a id="40.2.15.3"></a>**3**　未到场的人也可以通过代理人证明释奴原因。

<!-- source-p 156 -->
<a id="40.2.15.4"></a>**4**　若两人都以结婚为由解放奴隶，不应认可该项原因。

<!-- source-p 157 -->
<a id="40.2.15.5"></a>**5**　住所设在意大利或其他行省的人，可以在另一行省总督面前，并由顾问团参与，解放奴隶。

<!-- source-p 158 -->
<a id="40.2.16"></a>**40.2.16**

<!-- source-p 159 -->
乌尔比安《评〈埃利亚·森提亚法〉》第二卷。

<!-- source-p 160 -->
<a id="40.2.16.pr."></a>**序言**　法官证明释奴原因时，应当记住，不应认可源于奢侈放纵的原因，而应认可出于情感的原因。应认为，《埃利亚·森提亚法》赋予正当自由，是基于正当情感，而非纵情享乐。

<!-- source-p 161 -->
<a id="40.2.16.1"></a>**1**　有人依据某项安排，将奴隶交给未满二十岁者，无论是收取价款还是作为赠与，目的都是使奴隶获释的，该未满二十岁者可以证明这项安排构成释奴原因，并据此使奴隶取得自由。因此，他必须证明双方确有此项约定；之后应依赠与的法律关系或交付人的情感，评估该项安排。

<!-- source-p 162 -->

<a id="40.2.19"></a>**40.2.19**

<!-- source-p 172 -->

<!-- source-p 173 -->
<a id="40.2.20"></a>**40.2.20**

<!-- source-p 174 -->
乌尔比安《论执政官的职务》第二卷。

<!-- source-p 175 -->
<a id="40.2.20.pr."></a>**序言**　未满二十五岁者若受遗嘱信托嘱托解放奴隶，应当毫不迟疑地准许其解放；但若受嘱托解放的是他自己的奴隶，则应比较其依嘱托人遗嘱所得利益的数额，与受嘱托解放的奴隶价值。

<!-- source-p 176 -->
<a id="40.2.20.1"></a>**1**　若奴隶是依“须将其解放”的条件赠与该人，也应准许解放，以免神圣的马尔库斯皇帝所作敕令使执政官的审理陷于迟延。

<!-- source-p 177 -->
<a id="40.2.20.2"></a>**2**　有人愿以结婚为由解放奴隶，且其本人并非不配娶取此等身份的妻子，则应准许他这样做。

<!-- source-p 178 -->
<a id="40.2.20.3"></a>**3**　马尔凯鲁斯还写道，妇女若愿解放自己的亲生儿子，或解放前述各类人，也应准许。

<!-- source-p 179 -->
<a id="40.2.20.4"></a>**4**　执政官可以在自己面前解放奴隶，即使其本人恰好未满二十岁。

<a id="40.2.22"></a>**40.2.22**

<!-- source-p 184 -->

<!-- source-p 185 -->

<a id="40.2.25"></a>**40.2.25**
