# D.40.4 论遗嘱释奴（*De manumissis testamento*，第五段）

<!-- source-p 391 -->
<a id="40.4.54.1"></a>**1.**遗嘱指定的继承人在接受遗产之前，曾与债权人约定只清偿一半债务，随后又经裁判官作出裁令而接受遗产。问题是，遗嘱中给予的自由是否有效。他答复说，若遗嘱人并无欺诈意图，释奴安排即有效。

<!-- source-p 392 -->
<a id="40.4.55"></a>**40.4.55**

<!-- source-p 393 -->
梅基安《遗嘱信托》第二卷。

<!-- source-p 394 -->
<a id="40.4.55.pr."></a>**序言。**奴隶附条件获得自由的规则现已发展至此：若条件未成就并非因附条件获释奴隶所致，即使也并非继承人的过错，该奴隶仍将获得自由。我认为，若遗嘱信托已经对属于遗产的奴隶给予自由，也应作同样答复。

<!-- source-p 395 -->
<a id="40.4.55.1"></a>**1.**对于继承人自己的奴隶，也可以合理地作同样解释。

<!-- source-p 396 -->
<a id="40.4.55.2"></a>**2.**但对于继承人必须赎回的奴隶，我们有理由对此存疑；因为若条件未成就并非附条件获释奴隶所致，而是主人阻止其遵守条件，继承人仍被迫如同条件已成就那样赎回该奴隶，这显然不公平。如此一来，主人既取得赎价，又无须面对奴隶履行条件所产生的后果。

<!-- source-p 397 -->
<a id="40.4.56"></a>**40.4.56**

<!-- source-p 398 -->
保罗《遗嘱信托》第一卷。

<!-- source-p 399 -->
若遗嘱既直接给予奴隶自由，又通过遗嘱信托给予自由，奴隶可以自行选择依据直接释奴安排还是遗嘱信托取得自由；皇帝马尔库斯也曾如此作出复函。

<!-- source-p 400 -->
<a id="40.4.57"></a>**40.4.57**

<!-- source-p 401 -->
盖尤斯《论释奴》第三卷。

<!-- source-p 402 -->
若贫困的遗嘱人有富裕之人作为继承人，我们应考察，这是否会使遗嘱所给予的自由安排有效，从而避免债权人受到诈害。确有一些人认为，这与遗嘱人本人后来增加财产、以富裕状态去世的情形相同。但我所受传授的法律规则是：继承人富裕还是贫困并不重要；重要的是遗嘱人去世时拥有什么财产。尤利安极力坚持这一规则，甚至认为：若资不抵债之人命令奴隶“债务清偿后，斯提库斯应获自由”，该奴隶也不能取得自由。但这一结论与萨宾和卡西乌斯的意见并不一致；尤利安似乎也接受他们的意见。他们认为应考察释奴人的意思：若某人以债务清偿为条件命令自己的奴隶获得自由，显然是为了避免诈害债权人，而非意图欺诈。

<!-- source-p 403 -->
<a id="40.4.58"></a>**40.4.58**

<!-- source-p 404 -->
梅基安《遗嘱信托》第三卷。

<!-- source-p 405 -->
某奴隶虽被遗嘱人命令获得自由，却被遗嘱人转让给他人；若在遗产被接受之前，该奴隶又重新成为遗产奴隶，随后遗产被接受，那么他确实可以取得自由。

<!-- source-p 406 -->
<a id="40.4.59"></a>**40.4.59**

<!-- source-p 407 -->
斯凯沃拉《学说汇纂》第二十三卷。

<!-- source-p 408 -->
<a id="40.4.59.pr."></a>**序言。**提提娅在遗嘱中明确给予数名男奴和女奴自由，之后又写道：“我希望所有在我的账目中记有姓名的侍女均获得自由。”有人询问：尤提基娅在订立遗嘱时属于侍女，已经获得自由；但遗嘱人死亡时，她被发现已交给一名管家作为同居伴侣。她能否依据关于侍女的一般条款取得自由？他答复说，尤提基娅仅在遗嘱人死亡时不再是侍女，并不妨碍她获得自由。

<!-- source-p 409 -->
<a id="40.4.59.1"></a>**1.**斯提库斯依据其主人遗嘱无条件、直接获得自由；但据称他以欺诈方式从遗产中取走许多财物。有人询问，他是否必须先将能够证明其从遗产中取走的财物返还给继承人，才可请求确认自由。他答复说，根据所述事实，该人是自由人。克劳狄乌斯补充说：看来答复已解决了所询问题，因为关于盗窃的告示已经充分保护继承人。

<!-- source-p 410 -->
<a id="40.4.59.2"></a>**2.**卢基乌斯·提图斯在遗嘱中写道：“欧尼西福鲁斯，若你未能勤勉核对账目，就不得获得自由。”我问，欧尼西福鲁斯能否依据这些文字主张自由。他答复说，依所述文字，所表达的更像是剥夺自由，而非给予自由。

<!-- source-p 411 -->
<a id="40.4.60"></a>**40.4.60**

<!-- source-p 412 -->
斯凯沃拉《学说汇纂》第二十四卷。

<!-- source-p 413 -->
遗嘱写道：“*Eudoni boulomai dovynai nomismata xilia, epei efvasen gennyvynai meta to tyn mytera autou genesvai eleuveran*”〔底本拉丁释义：*Eudoni dari volo aureos mille, quoniam postea natus est quam mater eius libera facta est*；即“我愿给欧多一千枚金币，因为他是在其母成为自由人之后出生的”〕。我问：若欧多不能证明自己是在母亲获释后出生，能否依据这些遗嘱文字主张自由？他答复说，不应让此类咨询预先决定其权利。

<!-- source-p 414 -->
<a id="40.4.61"></a>**40.4.61**

<!-- source-p 415 -->
庞波尼乌斯《书信集》第十一卷。

<!-- source-p 416 -->
<a id="40.4.61.pr."></a>**序言。**我知道有人为了使自己的奴隶永远无法获得自由，惯常写道：“斯提库斯死时应获自由。”但尤利安也说，将自由推迟至生命的最后时刻，该安排毫无效力；因为可以看出，遗嘱人这样写的目的更可能是阻止自由，而非给予自由。因此，即使写道“若斯提库斯不上卡庇托山，他就应获得自由”，若显然遗嘱人意在将自由推迟至生命的最后时刻，该安排也毫无效力，并且不适用穆基亚担保。

<!-- source-p 417 -->
<a id="40.4.61.1"></a>**1.**若遗嘱写道：“斯提库斯若前往卡普阿，就应获得自由”，则只有他前往卡普阿，才会获得自由。

<!-- source-p 418 -->
<a id="40.4.61.2"></a>**2.**此外，奥克塔维努斯说，若有人在遗嘱中以任何条件给予奴隶自由，又写道：“在条件成就之前，我不希望继承人释放他”，该附加语没有效力。
