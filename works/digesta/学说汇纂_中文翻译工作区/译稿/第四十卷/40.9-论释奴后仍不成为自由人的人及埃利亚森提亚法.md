# D.40.9 论哪些人经释奴仍不成为自由人及《埃利亚·森提亚法》（*Qui et a quibus manumissi liberi non fiunt et ad legem Aeliam Sentiam*）

<!-- source-p 969 -->
<a id="40.9"></a>**40.9.0 论哪些人经释奴仍不成为自由人及《埃利亚·森提亚法》**（*Qui et a quibus manumissi liberi non fiunt et ad legem Aeliam Sentiam*）。

<!-- source-p 970 -->
<a id="40.9.1"></a>**40.9.1**

<!-- source-p 971 -->
乌尔比安《评萨宾》第一卷。

<!-- source-p 972 -->
凯尔苏斯在《学说汇纂》第十二卷中出于实用考虑，认为可以解放天生聋人。

<!-- source-p 973 -->
<a id="40.9.2"></a>**40.9.2**

<!-- source-p 974 -->
乌尔比安《评萨宾》第三卷。

<!-- source-p 975 -->
如果奴隶被放逐后仍滞留在城中，他便不能取得自由。

<!-- source-p 976 -->
<a id="40.9.3"></a>**40.9.3**

<!-- source-p 977 -->
盖尤斯《论遗赠并评城市裁判官告示》第二卷。

<!-- source-p 978 -->
若遗嘱赋予受遗赠人选择某个奴隶的权利，或未明确特定对象而遗赠一名奴隶，继承人不得通过解放某些或全部奴隶，破坏或减损受遗赠人的选择权。因为既然奴隶是以“选择”或“选取”的方式遗赠，每个奴隶在某种意义上都被视为附条件遗赠。

<!-- source-p 979 -->
<a id="40.9.4"></a>**40.9.4**

<!-- source-p 980 -->
乌尔比安《论争》第三卷。

<!-- source-p 981 -->
我们不得解放已经设定质押的奴隶。

<!-- source-p 982 -->
<a id="40.9.5"></a>**40.9.5**

<!-- source-p 983 -->
尤利安《学说汇纂》第六十四卷。

<!-- source-p 984 -->
<a id="40.9.5.pr."></a>**序言**　即使继承人有清偿能力，只要遗产本身无力清偿债务，遗嘱所授予的自由仍然有效。

<!-- source-p 985 -->
<a id="40.9.5.1"></a>**1**　但若无清偿能力的人以如下方式授予自由：“若我的债权人获得全额清偿，斯提库斯便成为自由人”，则不能认为他命令释奴是为了诈害债权人。

<!-- source-p 986 -->
<a id="40.9.5.2"></a>**2**　若提提乌斯除斯提库斯和潘菲拉外没有其他财产，并向梅维娅作出要式允诺，承诺交付“斯提库斯或潘菲拉”，而后在没有其他债权人的情况下解放斯提库斯，则依《埃利亚·森提亚法》，斯提库斯的自由应被撤销。尽管提提乌斯可以选择交付潘菲拉，但只要他尚未交付她，由于她期间可能死亡，他解放斯提库斯就并非没有诈害受要式允诺债权人。反之，若他只允诺交付潘菲拉，我不会怀疑斯提库斯能够取得自由，尽管潘菲拉同样可能死亡。因为关键区别在于：被解放的奴隶本身是否包含在要式允诺的债务之中，还是在该债务之外。又如，某人为担保五枚金币而将斯提库斯与潘菲拉均设定质押，且两名奴隶各值五枚金币，那么两人都不得被解放；但若仅将斯提库斯设定质押，解放潘菲拉便不应视为诈害债权人。

<!-- source-p 987 -->
<a id="40.9.6"></a>**40.9.6**

<!-- source-p 988 -->
斯凯沃拉《疑难》第十六卷。

<!-- source-p 989 -->
尤利安所谈的是没有任何其他财产的人；否则，为何不能说可以解放其中一名奴隶？因为即使其中一人死亡，债务人仍有清偿能力；即使一人被解放，债务人也仍有清偿能力，而且不应把偶然发生的情况计入。否则，凡是允诺交付自己奴隶中某一名但未明确具体对象的人，就谁也不能解放。

<!-- source-p 990 -->
<a id="40.9.7"></a>**40.9.7**

<!-- source-p 991 -->
尤利安《评乌尔塞乌斯·费罗克斯》第二卷。

<!-- source-p 992 -->
<a id="40.9.7.pr."></a>**序言**　某人在财产尚足以清偿债务时确认了附录遗嘱；之后他产生诈害债权人的意图，并在附录遗嘱中授予自由。此时，不能阻止法律对这些自由的效力提出异议。因为判断遗嘱人的诈害意图，不应以确认附录遗嘱之时为准，而应以在附录遗嘱中授予自由之时为准。

<!-- source-p 993 -->
<a id="40.9.7.1"></a>**1**　未满二十岁的人想解放奴隶，却没有正当理由作为释奴依据，于是把奴隶交给你，让你代为解放。普罗库鲁斯认为该奴隶不会成为自由人，因为这是对法律的规避。

<!-- source-p 994 -->
<a id="40.9.8"></a>**40.9.8**

<!-- source-p 995 -->
阿非利卡努斯《疑难》第三卷。

<!-- source-p 996 -->
<a id="40.9.8.pr."></a>**序言**　负有附条件债务的人，为履行遗嘱信托而解放奴隶时，适用《埃利亚·森提亚法》。

<!-- source-p 997 -->
<a id="40.9.8.1"></a>**1**　军人依军法订立遗嘱，并为诈害债权人而授予自由，若其死亡时无清偿能力，则这些自由的效力受到阻却。

<!-- source-p 998 -->
<a id="40.9.9"></a>**40.9.9**

<!-- source-p 999 -->
马尔基安《法学阶梯》第一卷。

<!-- source-p 1000 -->
<a id="40.9.9.pr."></a>**序言**　奴隶若以暴力胁迫主人解放自己，主人因恐惧而写下奴隶自由，则该奴隶不会成为自由人。

<!-- source-p 1001 -->
<a id="40.9.9.1"></a>**1**　主人在奴隶被控重大犯罪时未为其辩护，而该奴隶后来获判无罪，也不能因此成为自由人。

<!-- source-p 1002 -->
<a id="40.9.9.2"></a>**2**　出售奴隶时附有不得解放的条件者、遗嘱禁止解放者，或行省总督命令不得解放者，即使被解放，也不会因此取得自由。

<!-- source-p 1003 -->
<a id="40.9.10"></a>**40.9.10**

<!-- source-p 1004 -->
盖尤斯《日常法论》或《黄金集》第一卷。

<!-- source-p 1005 -->
为诈害债权人而解放奴隶，是指解放人在解放时已经无清偿能力，或因授予自由而将失去清偿能力。人们常常高估自己的财产，认为财产多于实际数额。经营海外贸易、或在本人居住地以外地区通过奴隶和自由释奴开展贸易的人，尤常发生这种情况；经营长期衰退后，他们往往没有察觉，便在并无诈害意图的情况下解放奴隶，以此宽待他们。

<!-- source-p 1006 -->
<a id="40.9.11"></a>**40.9.11**

<!-- source-p 1007 -->
马尔基安《法学阶梯》第十三卷。

<!-- source-p 1008 -->
<a id="40.9.11.pr."></a>**序言**　依元老院决议，为诈害市镇共同体而解放的奴隶，不得取得自由。

<!-- source-p 1009 -->
<a id="40.9.11.1"></a>**1**　皇帝敕令也规定，为诈害国库而授予的自由不发生效力。不过，神圣皇帝兄弟曾作出敕答：并非国库债务人一旦解放奴隶，该奴隶的自由就受到阻却；只有债务人无清偿能力且为诈害国库而解放奴隶时，才如此处理。

<!-- source-p 1010 -->
<a id="40.9.12"></a>**40.9.12**

<!-- source-p 1011 -->
乌尔比安《论通奸罪》第四卷。

<!-- source-p 1012 -->
<a id="40.9.12.pr."></a>**序言**　立法者预见到奴隶可能通过释奴逃避审讯，因此禁止解放奴隶，并规定不得解放的特定期限。

<!-- source-p 1013 -->
<a id="40.9.12.1"></a>**1**　因此，离婚的妇女绝对不得解放或转让自己的任何奴隶，因为法条措辞表明，即使奴隶不曾服侍该妇女，而是在乡间或行省，也不得解放或转让。这固然十分严苛，但法律就是这样写的。

<!-- source-p 1014 -->
<a id="40.9.12.2"></a>**2**　即使妇女在离婚后才购买奴隶，或以其他方式取得奴隶，从法条措辞来看，她同样不得解放他们；塞克斯图斯·凯基利乌斯也作了这样的注释。

<!-- source-p 1015 -->
<a id="40.9.12.3"></a>**3**　女儿处于父亲权力之下时，法律仅禁止父亲解放或转让交给女儿使用的奴隶。

<!-- source-p 1016 -->
<a id="40.9.12.4"></a>**4**　法律也禁止母亲解放或转让她交给女儿服侍的奴隶。

<!-- source-p 1017 -->
<a id="40.9.12.5"></a>**5**　法律还禁止祖父母解放奴隶，因为法律认为也可以对他们的奴隶进行审讯。

<!-- source-p 1018 -->
<a id="40.9.12.6"></a>**6**　塞克斯图斯·凯基利乌斯正确指出，法律为转让或解放奴隶规定的期限极短。他说，试想一名妇女被控通奸后，案件在六十日内提出；通奸案件的审理怎能如此迅速，以至在六十日内结束？然而，就法律措辞而言，即使妇女已被控通奸，她仍可解放被怀疑参与通奸或审讯所需的奴隶。对此情形当然应予救济：在调查结束之前，不应解放那些被指定为知情人或嫌疑人的奴隶。

<!-- source-p 1019 -->
<a id="40.9.12.7"></a>**7**　若妇女的父亲或母亲在六十日期限内死亡，他们不得解放或转让交给女儿服侍的奴隶。

<!-- source-p 1020 -->
<a id="40.9.13"></a>**40.9.13**

<!-- source-p 1021 -->
保罗《论通奸罪》第三卷。

<!-- source-p 1022 -->
若在六十日期限内解放奴隶，该奴隶便成为附条件获释的奴隶。

<!-- source-p 1023 -->
<a id="40.9.14"></a>**40.9.14**

<!-- source-p 1024 -->
乌尔比安《论通奸罪》第四卷。

<!-- source-p 1025 -->
<a id="40.9.14.pr."></a>**序言**　但若丈夫在六十日期限内死亡，我们还要考察上述人士是否已可解放或转让奴隶。我认为仍然不可以，尽管丈夫死亡使妻子不再有控告人；因为父亲仍可提出控告。

<!-- source-p 1026 -->
<a id="40.9.14.1"></a>**1**　法律以一般措辞禁止妇女在离婚后的六十日内解放奴隶：

<!-- source-p 1027 -->
<a id="40.9.14.2"></a>**2**　无论是妇女提出离婚，还是被丈夫休弃，解放奴隶均受阻却。

<!-- source-p 1028 -->
<a id="40.9.14.3"></a>**3**　但若婚姻因丈夫死亡或丈夫受到某种刑罚而解除，则不阻却解放奴隶。

<!-- source-p 1029 -->
<a id="40.9.14.4"></a>**4**　若婚姻以和平方式结束，也可以说解放或转让奴隶不受阻却。

<!-- source-p 1030 -->
<a id="40.9.14.5"></a>**5**　但若婚姻仍存续，妇女在考虑离婚期间解放或转让奴隶，而有明确证据证明此事，则应视为此举意在规避法律；该转让或解放不应有效。

<!-- source-p 1031 -->
<a id="40.9.14.6"></a>**6**　我们应当把一切形式的财产转让均纳入“转让”一词的范围。

<!-- source-p 1032 -->
<a id="40.9.15"></a>**40.9.15**

<!-- source-p 1033 -->
保罗《评尤利乌斯法》第一卷。

<!-- source-p 1034 -->
<a id="40.9.15.pr."></a>**序言**　有人被控犯有叛国罪；在被定罪以前，他仍是主人，问题是他能否解放奴隶。安敦尼努斯皇帝答复卡尔普尔尼乌斯·克里托努斯说：从某人因考虑自己的罪行而已经可以确定将受何种刑罚之时起，也就是从其内心已知罪行之时起——这早于定罪——他便丧失了授予自由的权利。

<!-- source-p 1035 -->
<a id="40.9.15.1"></a>**1**　尤利安说，父亲准许儿子解放奴隶后，若儿子不知道父亲已经死亡，仍通过裁判官前的解放仪式解放了奴隶，该奴隶并不会成为自由人。即使父亲仍然在世，若父亲已经改变意愿，也不能认为儿子是在父亲同意下解放奴隶。

<!-- source-p 1036 -->
<a id="40.9.16"></a>**40.9.16**

<!-- source-p 1037 -->
保罗《评埃利亚·森提亚法》第三卷。

<!-- source-p 1038 -->
<a id="40.9.16.pr."></a>**序言**　若奴隶依遗嘱信托负有获释义务，未满二十岁的人出售该奴隶以便他人解放，或者因为自己当初是以解放为条件购得该奴隶而转让他，均不阻止该转让。

<!-- source-p 1039 -->
<a id="40.9.16.1"></a>**1**　未满二十岁的人为了释放奴隶，将自己对共有奴隶享有的份额交付他人，此举无效；但若他本人有能力证明正当原因而作出该交付，则不视为规避法律。

<!-- source-p 1040 -->
<a id="40.9.16.2"></a>**2**　法律规定，不得为诈害债权人而解放奴隶。这里的债权人，是指基于任何原因而对诈害者享有诉权的人。

<!-- source-p 1041 -->
<a id="40.9.16.3"></a>**3**　阿里斯托答复说，国库债务人无清偿能力时解放的奴隶，应在其未长期处于自由状态时被恢复为奴隶；所谓“未长期处于自由状态”，底本接作 *non minus decennio*（字面可解作“不少于十年”，与前句不易协调）；暂依上下文理解为自由状态未满十年。当然，为诈害国库而转入国库名下的财物应予追回。

<!-- source-p 1042 -->
<a id="40.9.16.4"></a>**4**　若有人仅在条件成就时才负有金钱债务，债务人解放的奴隶应视为附条件获释的奴隶；其自由取决于该条件是否成就。

<!-- source-p 1043 -->
<a id="40.9.16.5"></a>**5**　若儿子经父亲同意解放奴隶，而父亲或儿子知道父亲无清偿能力，则自由的效力受到阻却。

<!-- source-p 1044 -->
<a id="40.9.17"></a>**40.9.17**

<!-- source-p 1045 -->
保罗《论自由》单卷。

<!-- source-p 1046 -->
<a id="40.9.17.pr."></a>**序言**　私人被民众强迫而解放奴隶，即使他表示同意，奴隶仍不会成为自由人；神圣马尔库斯皇帝也禁止因民众喝彩而解放奴隶。

<!-- source-p 1047 -->
<a id="40.9.17.1"></a>**1**　主人为了不受官员惩罚而谎称奴隶已经自由，若其并无解放奴隶的意愿，该奴隶也不会成为自由人。

<!-- source-p 1048 -->
<a id="40.9.17.2"></a>**2**　对依法不得在特定期间内解放的奴隶，若遗嘱授予其自由，应审查自由应当生效的时间，而非遗嘱订立的时间。

<!-- source-p 1049 -->
<a id="40.9.18"></a>**40.9.18**

<!-- source-p 1050 -->
保罗《评普劳提乌斯》第十六卷。

<!-- source-p 1051 -->
<a id="40.9.18.pr."></a>**序言**　遗嘱人死亡时遗产有清偿能力，但继承人接受遗产时遗产已无清偿能力的，遗嘱人以诈害债权人为目的而遗赠的自由不发生效力。遗产增加有利于自由生效，遗产减少则损害自由生效。

<!-- source-p 1052 -->
<a id="40.9.18.1"></a>**1**　若遗嘱命令某人向继承人支付相当于其价值的金额后取得自由，我们要考察这是否仍会诈害债权人：因为继承人将因死亡原因取得该笔款项；还是说，若由他人代付，或此人支付的不是从其特有产中取得的钱款，便不存在诈害。若继承人有清偿能力，并不能使该奴隶获得自由；由他人代为给付钱款也同样无助于其取得自由。

<!-- source-p 1053 -->
<a id="40.9.19"></a>**40.9.19**

<!-- source-p 1054 -->
莫德斯提努斯《法律格言》第一卷。

<!-- source-p 1055 -->
某人授予他人自由，但之后自己被判定为奴隶的，该自由不发生效力。

<!-- source-p 1056 -->
<a id="40.9.20"></a>**40.9.20**

<!-- source-p 1057 -->
莫德斯提努斯《疑难案例摘编》单卷。

<!-- source-p 1058 -->
未经奴隶所有人同意而授予他人自由，不可能依法律权威发生效力；即使之后授予自由者成为该所有人的继承人，也不改变这一点。授予自由者虽依亲属关系成为其继承人，但继承的接受并不能使先前的自由授予获得效力。

<!-- source-p 1059 -->
<a id="40.9.21"></a>**40.9.21**

<!-- source-p 1060 -->
莫德斯提努斯《汇编》第一卷。

<!-- source-p 1061 -->
只有打算娶女奴为妻的人，才可以因婚姻目的解放她。若另一个人以结婚为由解放女奴，而后由他人娶她为妻，她并不会因此成为自由人。尤利安答复说，即使女奴在六个月内被休弃，原先解放她的人后来娶她为妻，她也不会因此成为自由人；因为元老院所考虑的，是解放后未插入其他行为、紧接着成立的婚姻。

<!-- source-p 1062 -->
<a id="40.9.22"></a>**40.9.22**

<!-- source-p 1063 -->
蓬波尼乌斯《评昆图斯·穆基乌斯》第二十五卷。

<!-- source-p 1064 -->
精神失常者的保佐人不能解放其奴隶。

<!-- source-p 1065 -->
<a id="40.9.23"></a>**40.9.23**

<!-- source-p 1066 -->
蓬波尼乌斯《杂论》第四卷。

<!-- source-p 1067 -->
明知自己无清偿能力而授予自由的，始终属于为诈害债权人而授予自由；即使他确实是出于善意，想把自由授予值得获释的人，也不例外。

<!-- source-p 1068 -->
<a id="40.9.24"></a>**40.9.24**

<!-- source-p 1069 -->
克莱孟提乌斯《评尤利乌斯与帕皮乌斯法》第九卷。

<!-- source-p 1070 -->
有债权人的人若解放多名奴隶，并非所有人的自由都会受阻；先被解放的人将成为自由人，直到债权人获得清偿。尤利安常用以下情形说明这一规则：若两人都被解放，其中一人的自由构成诈害，则受到阻却的不是两人的自由，而是其中一人的自由，通常是遗嘱中较后写明的那一人；但若较先写明者价值较高，且不足以仅将较后写明者恢复为奴隶，则较先写明者的价值足以清偿债权人。在此情形下，只有遗嘱中较后写明的人能够取得自由。

<!-- source-p 1071 -->
<a id="40.9.25"></a>**40.9.25**

<!-- source-p 1072 -->
帕比尼安《答复》第五卷。

<!-- source-p 1073 -->
遗嘱中为诈害债权人而授予的自由，即使原有债权人已经获清偿，若后来又出现新的债权人，仍然无效。

<!-- source-p 1074 -->
<a id="40.9.26"></a>**40.9.26**

<!-- source-p 1075 -->
斯凯沃拉《答复》第四卷。

<!-- source-p 1076 -->
债务人的继承人解放了已设定质押的奴隶，问题是该奴隶是否成为自由人。答复说，根据所述情况，若债务至今仍未清偿，该奴隶不会因解放而成为自由人。保罗补充说：因此，债务清偿后，该奴隶便依照先前的意愿成为自由人。

<!-- source-p 1077 -->
<a id="40.9.27"></a>**40.9.27**

<!-- source-p 1078 -->
赫尔莫革尼安《法学摘要》第一卷。

<!-- source-p 1079 -->
<a id="40.9.27.pr."></a>**序言**　若某人为诈害债权人而解放奴隶，其自由应被阻止；无论债务清偿期限已经届满，还是债务约定在将来某日或以条件成就为期限，均如此。附条件遗赠则不同：条件成就前，受遗赠人不被视为债权人。对于这一部分涉及的一切债权人，《埃利亚·森提亚法》均予以保护；人们也认为，遗嘱信托受托人属于债权人。

<!-- source-p 1080 -->
<a id="40.9.27.1"></a>**1**　设定质押的奴隶，在债务清偿前，未经债权人同意不得解放。但未成年人债权人未经监护人授权而表示同意，对解放不发生效力；正如仅有用益权的未成年人同样表示同意，也不发生效力。

<!-- source-p 1081 -->
<a id="40.9.28"></a>**40.9.28**

<!-- source-p 1082 -->
保罗《判决集》第三卷。

<!-- source-p 1083 -->
继承人解放遗嘱人遗赠给他人的自有奴隶，并无任何法律效果；因为人们认为，其是否知情或不知情均不予考虑。

<!-- source-p 1084 -->
<a id="40.9.29"></a>**40.9.29**

<!-- source-p 1085 -->
盖尤斯《论释奴》第一卷。

<!-- source-p 1086 -->
<a id="40.9.29.pr."></a>**序言**　一般而言，已经设定质押的奴隶在完整法律意义上仍属于债务人所有；如果《埃利亚·森提亚法》不阻碍其自由，也就是债务人有清偿能力且不会因此诈害债权人，则该奴隶可以从债务人处合法取得自由。

<!-- source-p 1087 -->
<a id="40.9.29.1"></a>**1**　附条件遗赠的奴隶，在条件尚未成就期间，完整法律意义上仍属于继承人；但他不能从继承人处取得自由，以免损害受遗赠人。

<!-- source-p 1088 -->
<a id="40.9.30"></a>**40.9.30**

<!-- source-p 1089 -->
乌尔比安《评埃利亚·森提亚法》第四卷。

<!-- source-p 1090 -->
<a id="40.9.30.pr."></a>**序言**　若某人附有解放奴隶的条件买下奴隶，却未解放他，奴隶依据神圣马尔库斯皇帝的敕令取得自由；问题是买主能否以该自由释奴忘恩负义为由控告他。可以说，由于买主并非实际解放者，他不享有此项权利。

<!-- source-p 1091 -->
<a id="40.9.30.1"></a>**1**　若我的儿子经我同意解放奴隶，我是否享有以释奴忘恩负义为由控告他的权利，可能存在疑问，因为实际解放者并非我。但我应被视为已经解放奴隶。

<!-- source-p 1092 -->
<a id="40.9.30.2"></a>**2**　但若我的儿子解放的是军役特有产中的奴隶，我显然不享有此项权利，因为并非我本人解放了他；儿子当然可以提起该控告。

<!-- source-p 1093 -->
<a id="40.9.30.3"></a>**3**　一个人只有在其释奴保护人身份存续期间，才能提起该控告。

<!-- source-p 1094 -->
<a id="40.9.30.4"></a>**4**　若多名释奴保护人打算以忘恩负义为由控告释奴，究竟需要所有人同意，还是其中一人即可？较可采的意见是：若释奴至少对其中一人实施了忘恩行为，该人即可控告；但若释奴保护人属于同一顺位，则需要所有人同意。

<!-- source-p 1095 -->
<a id="40.9.30.5"></a>**5**　若父亲将一名释奴指定给某一儿子，尤利安写道，只有该儿子可以控告；因为只有他是释奴保护人。

<!-- source-p 1096 -->
<a id="40.9.31"></a>**40.9.31**

<!-- source-p 1097 -->
特伦提乌斯·克莱孟《评尤利乌斯与帕皮乌斯法》第五卷。

<!-- source-p 1098 -->
有人问：若释奴保护人迫使女释奴宣誓，在她有未达适婚年龄的子女期间不得结婚，法律效果如何？尤利安说，若他没有强加永久守寡义务，就不能认为他违反了《埃利亚·森提亚法》。

<!-- source-p 1099 -->
<a id="40.9.32"></a>**40.9.32**

<!-- source-p 1100 -->
特伦提乌斯·克莱孟《评尤利乌斯与帕皮乌斯法》第八卷。

<!-- source-p 1101 -->
<a id="40.9.32.pr."></a>**序言**　若处于释奴保护人权力之下的人未经其同意，迫使女释奴宣誓或与她订立要式口约，规定她不得结婚，那么，除非释奴保护人免除该义务或解放这名女释奴，该行为便触犯法律；因为这显然是出于恶意。

<!-- source-p 1102 -->
<a id="40.9.32.1"></a>**1**　《埃利亚·森提亚法》并未禁止释奴保护人收取自由释奴支付的报酬，但禁止他们使自由释奴负担该项义务。因此，若自由释奴自愿向释奴保护人支付报酬，不会因此取得该法规定的利益。

<!-- source-p 1103 -->
<a id="40.9.32.2"></a>**2**　某人允诺提供劳务，或允诺每项劳务支付固定数额，均不属于该法所禁止的情形，因为他可以通过实际提供劳务而解除义务。奥克塔维努斯也持此意见，并补充说：若某人使自由释奴对自己负有义务，目的是收取劳务报酬，那么，即使他以劳务之名订立要式口约，只要其唯一目的确实是收取报酬，也属于此种情形。
