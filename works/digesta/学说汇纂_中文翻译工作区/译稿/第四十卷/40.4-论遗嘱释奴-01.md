# D.40.4 论遗嘱释奴（*De manumissis testamento*，第一段）

<!-- source-p 205 -->
<a id="40.4"></a>**40.4.0 论遗嘱释奴**（*De manumissis testamento*）。

<!-- source-p 206 -->
<a id="40.4.1"></a>**40.4.1**

<!-- source-p 207 -->
乌尔比安《萨宾评注》第四卷。

<!-- source-p 208 -->
若反复给予奴隶自由，应当本着有利于自由的原则，使最终使其获得自由的那项安排发生效力。

<!-- source-p 209 -->
<a id="40.4.2"></a>**40.4.2**

<!-- source-p 210 -->
乌尔比安《萨宾评注》第五卷。

<!-- source-p 211 -->
若某人如此指定继承人：“提图斯为继承人。若提图斯不成为继承人，斯提库斯为继承人。斯提库斯应获自由”，阿里斯托说，若提图斯成为继承人，斯提库斯就不能获得自由。我认为可以说，斯提库斯仍将获得自由；这并非因为他在另一顺位才获自由，而是因为自由被以两种方式授予。我们采用这一规则。

<!-- source-p 212 -->
<a id="40.4.3"></a>**40.4.3**

<!-- source-p 213 -->
庞波尼乌斯《萨宾评注》第一卷。

<!-- source-p 214 -->
未满二十岁的军人不得在其遗嘱中释放奴隶。

<!-- source-p 215 -->
<a id="40.4.4"></a>**40.4.4**

<!-- source-p 216 -->
庞波尼乌斯《萨宾评注》第二卷。

<!-- source-p 217 -->
<a id="40.4.4.pr."></a>**序言。**若有人写道：“斯提库斯应获自由，我的继承人应给他十枚钱币”，毫无疑问，即使家父在生前已释放斯提库斯，该款项仍应给付。

<!-- source-p 218 -->
<a id="40.4.4.1"></a>**1.**若写道：“斯提库斯应获自由”，无论立即获自由还是经过一段时间后获自由；并写道：“他获得自由时，我的继承人应给他十枚钱币”，结论亦同。

<!-- source-p 219 -->
<a id="40.4.4.2"></a>**2.**但可以确定的是，若先写明给予自由，之后又写道：“若我以权杖程序释放他，我的继承人应给他十枚钱币”，虽然由于过分拘泥形式，该遗赠与遗嘱相分离，但着眼于人道，若家父生前释放了他，该遗赠仍然有效。

<!-- source-p 220 -->
<a id="40.4.5"></a>**40.4.5**

<!-- source-p 221 -->
庞波尼乌斯《萨宾评注》第三卷。

<!-- source-p 222 -->
对于遗嘱中的释奴安排，应当采用最宽厚的文字解释；因此，若有数项安排，应视对被释放者最有利、最容易实现的那项为最宽厚的安排。但在遗嘱信托释奴中，应以最后一项安排为准。

<!-- source-p 223 -->
<a id="40.4.6"></a>**40.4.6**

<!-- source-p 224 -->
乌尔比安《萨宾评注》第十八卷。

<!-- source-p 225 -->
若所有权人指定用益权人为继承人，并对奴隶附条件给予自由，则由于该奴隶在此期间归继承人所有，用益权因混同而消灭；条件成就时，该奴隶便取得自由。

<!-- source-p 226 -->
<a id="40.4.7"></a>**40.4.7**

<!-- source-p 227 -->
乌尔比安《萨宾评注》第十九卷。

<!-- source-p 228 -->
涅拉提乌斯写道，若有人规定：“若我死时没有儿子，斯提库斯应获自由”，那么遗腹子出生会阻止斯提库斯获得自由。但在等待遗腹子出生期间，我们是说斯提库斯仍为奴隶，还是说若最终没有儿子出生，就追溯地认定斯提库斯自始获得自由？我认为后一意见更可取。

<!-- source-p 229 -->
<a id="40.4.8"></a>**40.4.8**

<!-- source-p 230 -->
庞波尼乌斯《萨宾评注》第五卷。

<!-- source-p 231 -->
若遗嘱写道：“斯提库斯若被认定已勤勉处理账目，即应获得自由”，则应要求他尽到对主人有益、而非对奴隶本人有益的勤勉，并在返还其余款项时同样遵守诚信。

<!-- source-p 232 -->
<a id="40.4.9"></a>**40.4.9**

<!-- source-p 233 -->
乌尔比安《萨宾评注》第二十四卷。

<!-- source-p 234 -->
<a id="40.4.9.pr."></a>**序言。**若某人被遗赠给他人并附有应释放他的指示，而他未被释放时，遗嘱又命令其获得自由并向其遗赠财物，法学家多次答复：其自由安排有效，遗赠也应给付。

<!-- source-p 235 -->
<a id="40.4.9.1"></a>**1.**遗嘱中规定不得释放某奴隶的规则，我认为仅适用于属于遗嘱人或继承人的奴隶；不能将这种禁止施加于他人所有的奴隶。

<!-- source-p 236 -->
<a id="40.4.10"></a>**40.4.10**

<!-- source-p 237 -->
保罗《萨宾评注》第四卷。

<!-- source-p 238 -->
<a id="40.4.10.pr."></a>**序言。**若遗嘱预先遗赠奴隶的特有产，并命令副奴获得自由，可以确定该副奴将获得自由。因为种类与特定物不同：特定物可以从种类中排除；奴隶特有产被预先遗赠而其中副奴被释放，就是这种情形。

<!-- source-p 239 -->
<a id="40.4.10.1"></a>**1.**若奴隶被遗赠，并被命令获得自由，他就会获得自由。但若先命令其获得自由，之后又将其遗赠，且遗嘱人显然意图撤销自由安排——如今通说认为自由也可以被撤销——我认为该奴隶应依遗赠处理；若遗嘱人的意思不明确，则更有利于自由的解释是认定其将获得自由。

<!-- source-p 240 -->
<a id="40.4.11"></a>**40.4.11**

<!-- source-p 241 -->
庞波尼乌斯《萨宾评注》第七卷。

<!-- source-p 242 -->
<a id="40.4.11.pr."></a>**序言。**若奴隶被遗赠，同时附有遗嘱信托释奴安排，继承人或受遗赠人均应被迫释放他。

<!-- source-p 243 -->
<a id="40.4.11.1"></a>**1.**若写道：“斯提库斯和潘菲卢斯各给付十枚钱币后即获自由”，其中一人给付五枚就可以获得自由，即使另一人没有给付亦然。

<!-- source-p 244 -->
<a id="40.4.11.2"></a>**2.**若遗嘱命令奴隶获得自由，则数名指定继承人中任何一人接受遗产后，该奴隶就立即获得自由。

<!-- source-p 245 -->
<a id="40.4.12"></a>**40.4.12**

<!-- source-p 246 -->
乌尔比安《告示评注》第五十卷。

<!-- source-p 247 -->
<a id="40.4.12.pr."></a>**序言。**若遗嘱将释奴附加于宣誓条件，裁判官告示不适用，不能免除该宣誓条件。这是合理的：因为若免除自由所附的条件，反而会妨碍自由本身；只有遵守该条件，自由安排才能生效。

<!-- source-p 248 -->
<a id="40.4.12.1"></a>**1.**因此，若某人接受附有自由安排的遗赠，只有遵守宣誓条件后才能取得遗赠。

<!-- source-p 249 -->
<a id="40.4.12.2"></a>**2.**但若某人无条件接受自由，而遗赠附有宣誓条件，尤利安在《学说汇纂》第三十一卷中认为，应免除他所受的遗赠宣誓条件。

<!-- source-p 250 -->
<a id="40.4.12.3"></a>**3.**若自由本身也附有条件，但遗嘱人在生前已经释放该奴隶，我认为也应作同样处理：遗赠所附条件亦应免除。

<!-- source-p 251 -->
<a id="40.4.13"></a>**40.4.13**

<!-- source-p 252 -->
乌尔比安《论争议》第五卷。

<!-- source-p 253 -->
<a id="40.4.13.pr."></a>**序言。**若遗嘱规定两名奴隶只有在建造一座公寓楼或竖立一尊雕像后才能获得自由，该条件不能分割。唯一有疑问的是，一人完成条件是否已满足遗嘱人的意思，因而使其获得自由。我认为更可取的意见是肯定的，除非遗嘱人另有明确表示。完成条件者为自己实现了条件，对另一人则没有实现；事实上，另一人的条件已经消灭，因为该条件既已一次性完成，他就不可能再遵守该条件。

<!-- source-p 254 -->
<a id="40.4.13.1"></a>**1.**若两名工匠或画家被要求绘制某个部位或建造一艘船，也可以提出同样的问题。应当查明遗嘱人的意思：他是否将一人的行为与另一人的行为结合为条件；若是如此，一人不履行就会使另一名愿意履行者也无法满足条件。但若从遗嘱人的文字或口头表示可以看出，只要其中一人完成即可，则问题迎刃而解：其中一人完成后，究竟是对自己和同伴都有利，还是仅对自己有利，应根据遗嘱人的意思判断。

<!-- source-p 255 -->
<a id="40.4.13.2"></a>**2.**若遗嘱规定两名奴隶只有在交出账目后才能获得自由，也要处理同样的问题。尤利安讨论：若一人愿意交账，另一人不愿意，前者是否会受后者阻碍。他极为正确地说：若两人分别记账，交出自己账目的人就足以取得自由；若两人共同记账，则除非清偿双方所欠余额，否则不能认为其中一人已经履行条件。这里所说的“其余账目”，应当理解为账簿本身也须交出。

<!-- source-p 256 -->
<a id="40.4.13.3"></a>**3.**若女奴被命令与其子女一同获得自由，即使她没有子女，她仍将获得自由；若她虽有子女，但子女不能获得自由，亦同。即使女奴本人不能获得自由，其子女仍会获得自由。因为“与子女一同”这一附加语并不构成条件，除非能证明遗嘱人有不同意思；在这种情况下，才应将这些文字视为条件。裁判官告示也可证明该语并不构成条件；告示规定：“我将命令孕妇及其子女进入占有。”即使没有已出生的子女，也认可应依告示将孕妇置于占有中。

<!-- source-p 257 -->
<a id="40.4.14"></a>**40.4.14**

<!-- source-p 258 -->
乌尔比安《论争议》第八卷。

<!-- source-p 259 -->
若遗嘱无条件命令奴隶获得自由，却附条件指定继承人，则条件未成就时，该奴隶仍可取得自由。
