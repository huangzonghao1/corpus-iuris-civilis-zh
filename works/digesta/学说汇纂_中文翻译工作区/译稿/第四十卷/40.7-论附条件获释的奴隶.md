# D.40.7 论附条件获释的奴隶（*De statuliberis*）

> 底本：*Digesta Iustiniani*，EPUB `book-40.xhtml`，source-p 736–940。

<!-- source-p 736 -->
<a id="40.7"></a>**40.7.0 论附条件获释的奴隶**（*De statuliberis*）。

<!-- source-p 737 -->
<a id="40.7.1"></a>**40.7.1**

<!-- source-p 738 -->
保罗《评萨宾》第五卷。

<!-- source-p 739 -->
<a id="40.7.1.pr."></a>**序言**　附条件获释的奴隶，是指其自由已被设定，并确定于某一时日或某一条件成就时发生的奴隶。

<!-- source-p 740 -->
<a id="40.7.1.1"></a>**1**　奴隶成为附条件获释的奴隶，既可能是因为明示了条件，也可能是依法律本身的效力。明示条件的情形显而易见。依法律本身效力的情形，是为欺骗债权人而解放奴隶：在债权人是否行使其权利尚未确定期间，奴隶暂时具有附条件获释的地位；因为《埃利亚·森提亚法》承认欺诈行为及其法律效果。

<!-- source-p 741 -->
<a id="40.7.2"></a>**40.7.2**

<!-- source-p 742 -->
乌尔比安《评萨宾》第四卷。

<!-- source-p 743 -->
<a id="40.7.2.pr."></a>**序言**　取得附条件获释奴隶地位的人，无论该奴隶被交付、转让，他在保有获释希望的状态下仍可被转让；无论被他人因时效取得，被取得时也连同其附带的法律地位一并取得；还是由他人解放，都不会丧失其成为奥尔库斯释奴（*Orcinus libertus*）的希望。不过，奴隶须待某一指定继承人接受遗产后，才取得附条件获释奴隶的地位。在接受遗产之前，无论奴隶被交付、被他人因时效取得或被解放，遗嘱所设定的自由希望都会消失。

<!-- source-p 744 -->
<a id="40.7.2.1"></a>**1**　如果奴隶的自由写在未适婚被监护人的遗嘱书板中，那么在该未适婚人仍然在世、且其父亲的遗产已被接受后，该奴隶是否属于附条件获释者？卡西乌斯持否定意见；尤利安则持相反意见，后者的意见被认为更为妥当。

<!-- source-p 745 -->
<a id="40.7.2.2"></a>**2**　尤利安还写道：若父亲的继承人将奴隶遗赠给他人，而奴隶依未适婚人所立遗嘱书板中的指示应当获得自由，则自由的授予仍应优先发生效力。

<!-- source-p 746 -->
<a id="40.7.2.3"></a>**3**　若在第一份遗嘱书板中，奴隶被指定为附条件继承人并获释一半，那么在共同继承人接受遗产时，他是否取得附条件获释奴隶的地位，使人可以连同此项法律地位对其完成时效取得？由于他是从自己那里取得自由，不能认为他取得附条件获释奴隶的地位。不过，如果继承条件未成就，而依尤利安的意见他因此取得自由，就应当说他取得附条件获释奴隶的地位，因为此时应认为他不是从自己、而是从共同继承人那里取得自由。

<!-- source-p 747 -->
<a id="40.7.2.4"></a>**4**　无论奴隶以何种顺位被指定为未适婚被监护人的自由替代继承人，他都取得必然继承人的地位。出于实用考虑，这一意见已获采纳，我们也予以认可。塞尔苏斯在《学说汇纂》第十五卷中也认为，被指定为自由替代继承人的奴隶取得附条件获释奴隶的地位。

<!-- source-p 748 -->
<a id="40.7.3"></a>**40.7.3**

<!-- source-p 749 -->
乌尔比安《评萨宾》第二十七卷。

<!-- source-p 750 -->
<a id="40.7.3.pr."></a>**序言**　只要没有人妨碍，且条件能够实现，附条件获释的奴隶就应当履行所附条件。

<!-- source-p 751 -->
<a id="40.7.3.1"></a>**1**　如果遗嘱规定奴隶应向继承人履行条件，应当如何处理？奴隶履行条件后，即使继承人反对，也立即成为自由人。若继承人不让奴隶履行条件（例如，继承人主动交出奴隶被命令给付的十个金币，却不让他给付），毫无疑问，奴隶即成为自由人，因为应认为是继承人阻碍了条件成就。至于奴隶是从自己的特有产中取钱交出，还是交出从他人处取得的钱，并不重要。通说认为，奴隶可以通过交付特有产中的钱而取得自由，无论他被命令向继承人本人还是向他人给付。

<!-- source-p 752 -->
<a id="40.7.3.2"></a>**2**　由此又产生问题：若继承人或第三人欠奴隶钱款——例如，奴隶为主人账目垫付过多，或第三人欠其钱款——而继承人既不愿起诉债务人，也不愿向附条件获释的奴隶偿付，奴隶是否应当因继承人迟延而取得自由？还须区分奴隶的特有产是否被遗赠给他。若特有产已被遗赠，塞尔维乌斯写道，只要主人账目上有应付给奴隶的款项，继承人却不予支付，就应认为奴隶取得自由受到迟延；拉贝奥也赞同此说。塞尔维乌斯还认为，若继承人不愿向债务人追偿而造成迟延，奴隶也会取得自由。我也认为塞尔维乌斯的意见正确。既然这一意见应予采纳，还要考察特有产未被遗赠给奴隶时是否也适用同一规则。可以确定，附条件获释的奴隶能够按遗嘱命令从其特有产中向继承人或他人给付；若有人阻止其给付，他就会取得自由。甚至可以把这视为对奴隶主的一种救济：奴隶主可阻止奴隶向第三人给付，以免奴隶获得自由时连同钱款一并失去。因此也可以主张，若继承人不愿收取债款，或不愿亲自向奴隶偿付，使奴隶无从取得履行条件所需的钱款，则自由仍应发生；卡西乌斯也这样写道。

<!-- source-p 753 -->
<a id="40.7.3.3"></a>**3**　继承人不仅不得阻止奴隶给付遗嘱指定的钱款，也不得阻止他完成其他条件。例如，奴隶被命令登上卡庇托利欧山，继承人不得阻止；奴隶被命令前往卡普阿给付钱款，继承人也不得阻止其前往。阻止奴隶出行的人，应被认为意在妨碍其取得自由，而非仅仅利用奴隶的劳务。

<!-- source-p 754 -->
<a id="40.7.3.4"></a>**4**　若一名继承人不允许奴隶向另一名共同继承人给付遗嘱指定的钱款，奴隶同样会成为自由人。不过，被指定为受领人、且奴隶本应向其给付的一方，可以通过遗产分割之诉，向阻挠给付的继承人请求赔偿其因奴隶未能成为自由人而遭受的利益损失。

<!-- source-p 755 -->
<a id="40.7.3.5"></a>**5**　奴隶被命令给付十个金币以取得自由，却只给付五个的，除非付清全部款项，否则不能取得自由。因此，期间主人仍可主张这五个金币归其所有。但若余款后来付清，此前尚未转移所有权的那部分钱款也随之转让。由此可见，先前给付部分的所有权转移处于待定状态；不过，这些钱并非追溯地在较早时点即归受领人所有，而是在余款付清时才一并归其所有。

<!-- source-p 756 -->
<a id="40.7.3.6"></a>**6**　附条件获释的奴隶给付超过遗嘱所命令的数额，例如受命给付十个金币却给付二十个，无论是当面点交还是装在钱袋中交付，均取得自由，并可请求返还多付的部分。

<!-- source-p 757 -->
<a id="40.7.3.7"></a>**7**　有人出售奴隶，遗嘱命令奴隶给付十个金币即可获得自由，但出售时未连同其特有产一并交付。问题是：该奴隶是否因此立即自由，因为买卖时未给他特有产，似乎等同于禁止其从特有产中给付；还是只有在他确实想要给付、却被人禁止动用特有产时才自由？我认为，只有在他愿意给付而遭到阻止时，才成为自由人；不能仅因奴隶被出售就立即自由。

<!-- source-p 758 -->
<a id="40.7.3.8"></a>**8**　遗嘱命令奴隶给付十个金币即可自由，继承人却禁止他工作；或者继承人拿走了奴隶以劳务所得的钱；又或者奴隶把自己积攒的工资交给继承人。在这些情形下，奴隶能否取得自由？我认为，若奴隶用劳务所得或其他来源的钱完成给付，他就会取得自由。但若继承人只是禁止他工作，他不会因此自由，因为他本应为主人工作。若继承人取走了奴隶通过劳务积攒的钱，我认为奴隶即成为自由人，因为他被禁止从特有产中给付。若遗嘱人明确命令奴隶以劳务所得履行给付条件，那么继承人禁止其工作时，毫无疑问奴隶会取得自由。

<!-- source-p 759 -->
<a id="40.7.3.9"></a>**9**　奴隶出售银器或其他物品、凑得钱款后完成给付，也会取得自由；但若他直接交付被窃取的钱款，则不能取得自由，因为这不被视为给付，更像是返还原物。即使奴隶窃取他人的钱款交给继承人，也不能因此取得自由，因为受领人可能被要求返还这些钱。只有在钱款已经被耗用，任何情形下都无法追回时，才应准予自由。

<!-- source-p 760 -->
<a id="40.7.3.10"></a>**10**　阻碍奴隶取得自由的，不仅可能是继承人，也可能是监护人、保佐人、代理人或其他负有促使条件履行义务的人；在这些情形下，也应认为自由发生。我们对附条件获释奴隶适用的规则是，只要条件未能成就并非因奴隶自身所致，就已足够。

<!-- source-p 761 -->
<a id="40.7.3.11"></a>**11**　若奴隶被命令在遗嘱人死亡后三十日内向继承人给付，而继承人迟延接受遗产，特雷巴提乌斯和拉贝奥认为：只要继承人并非出于恶意迟延，奴隶在继承人接受遗产后的三十日内给付，就会取得自由；这一意见是正确的。但若继承人故意拖延接受遗产，是否应认为一经接受遗产，奴隶便立即自由？倘若奴隶当时有能力给付，但接受遗产后已不再有能力呢？即使如此，仍应认为条件已经成就，因为未能履行并非奴隶所致。

<!-- source-p 762 -->
<a id="40.7.3.12"></a>**12**　若奴隶依如下表述取得自由：“能够给付十个金币时，即成为自由人”，特雷巴提乌斯认为，即使奴隶已经有十个金币，或有能力取得并保存特有产，也不能因此取得自由；只有在他实际给付，或未能给付并非因他所致时，才会取得自由。这一意见是正确的。

<!-- source-p 763 -->
<a id="40.7.3.13"></a>**13**　斯提库斯被命令在第一、第二、第三个周年日分别向继承人给付十枚金币，以此取得自由。若继承人在第一期阻止其给付十枚金币，通说认为仍须等到第三期，因为遗嘱还规定了时间，且尚有两期未届。若斯提库斯只有最初为第一期给付而提出的那十枚金币，他能否在第二期再次提出同一笔钱？若第二期款项未被接受，他能否在第三期仍以同一笔钱给付？我认为，同一笔钱足以履行各期条件，继承人不得反悔；庞波尼乌斯也赞同此说。

<!-- source-p 764 -->
<a id="40.7.3.14"></a>**14**　若奴隶被命令在第一、第二、第三个周年日分别给付十枚金币，却不等到约定日期、一次向继承人交出全部款项，或者在第一年给付十枚、第二年提出二十枚，如何处理？较为宽厚的意见是，应让他取得自由，因为双方的利益都能实现：奴隶可以更早自由，继承人也因不再延期而立即获得本来要等到以后才能取得的钱款。

<!-- source-p 765 -->
<a id="40.7.3.15"></a>**15**　若遗嘱规定奴隶为继承人服役五年后取得自由，而继承人在五年届满前便解放了他，则他立即成为自由人，因为这是继承人使其无法继续服役所造成的。若继承人只是阻止奴隶为自己服役，情况并不相同：奴隶不能立即取得自由，因为在五年期限内继承人仍可能让他继续服役。理由很清楚：奴隶一经解放，就不能再服役；但被禁止服役的人，继承人之后仍可在五年期限内允许其服役，哪怕服役时间不足五年。

<!-- source-p 766 -->
<a id="40.7.3.16"></a>**16**　尤利安在《学说汇纂》第十六卷中也写道：若遗嘱规定阿瑞图萨生育三名奴隶子女后取得自由，而继承人使她不能生育（例如给她药物以阻止受孕），她就立即成为自由人。还有什么需要等待的呢？若继承人促使她流产，也应作相同处理，因为她本来可能在一次妊娠中生下三名子女。

<!-- source-p 767 -->
<a id="40.7.3.17"></a>**17**　若附条件获释的奴隶被命令为继承人服役，而继承人将其出售并交付给买受人，我认为奴隶立即取得自由。

<!-- source-p 768 -->
<a id="40.7.4"></a>**40.7.4**

<!-- source-p 769 -->
保罗《评萨宾》第五卷。

<!-- source-p 770 -->
<a id="40.7.4.pr."></a>**序言**　若继承人因公务离开，而附条件获释的奴隶已有钱款，他应当等待自己须向其给付的人返回；或者将钱款封存后存放在神庙中。完成其中一项后，他立即取得自由。

<!-- source-p 771 -->
<a id="40.7.4.1"></a>**1**　若自由被附加了如此漫长的期限，以至于获释之人在期限届满前不可能仍然活着，就不构成有效的附条件释奴。若条件极为艰难、几乎不可能实现，使自由不可能通过其他方式取得，例如命令奴隶向继承人给付一百万，或规定奴隶在遗嘱人死亡时才自由，也属同样情形。这样的自由授予无效；尤利安也这样写道，因为遗嘱人并无真正授予自由的意思。

<!-- source-p 772 -->
<a id="40.7.4.2"></a>**2**　奴隶被命令为提提乌斯服役一年后取得自由；若提提乌斯先死亡，奴隶不会立即自由，而须待一年期满。这种自由不只是附条件授予，也附有期限。若奴隶尚未履行条件，却比履行条件本应更早取得自由，显然荒谬。

<!-- source-p 773 -->
<a id="40.7.4.3"></a>**3**　若奴隶被命令向两人给付十个金币以取得自由，其中一人拒绝接受其应得的五个金币，较妥当的意见是，奴隶可以把同样的五个金币交给另一人，从而取得自由。

<!-- source-p 774 -->
<a id="40.7.4.4"></a>**4**　遗嘱规定：“斯提库斯若为提提乌斯服役三年，或为他提供一百日劳务，即成为自由人。”可以确认，这样授予自由是有效的，因为他人所有的奴隶也可以为我们服役，自由人亦可如此，提供劳务更无问题；除非遗嘱人所说的“服役”意指所有权关系，而不是劳务。因此，若继承人禁止斯提库斯为提提乌斯服役，他就取得自由。

<!-- source-p 775 -->
<a id="40.7.4.5"></a>**5**　遗嘱规定：“斯提库斯若为我的继承人服役一年，即成为自由人。”一年应如何理解？是连续三百六十五日，还是以若干日累计（底本此处作 *an quibus [quibuslibet] libet []*，有异文及缺损）？庞波尼乌斯写道，前一种解释更可取。若奴隶因患病或其他正当原因，在若干日内无法服役，这些日子也应计入一年。我们照料生病的奴隶时，即使他因健康状况不佳而不能服役，仍应认为他是在为我们服役。

<!-- source-p 776 -->
<a id="40.7.4.6"></a>**6**　若奴隶被命令向继承人给付十个金币，出于有利于自由的原则，应强制继承人分期收取。

<!-- source-p 777 -->
<a id="40.7.4.7"></a>**7**　奴隶被命令：“如果提提乌斯登上卡庇托利欧山，即成为自由人。”若提提乌斯不愿登山，自由条件就无法成就。类似条件也适用同一规则。

<!-- source-p 778 -->
<a id="40.7.4.8"></a>**8**　卡西乌斯还说，奴隶被命令服役一年时，其逃亡期间或自由身份诉讼期间不计入这一年。

<!-- source-p 779 -->
<a id="40.7.5"></a>**40.7.5**

<!-- source-p 780 -->
庞波尼乌斯《评萨宾》第八卷。

<!-- source-p 781 -->
<a id="40.7.5.pr."></a>**序言**　附条件获释的奴隶被命令交代账目；对于账目中明确显示的余额，他已经支付；对于不够清楚的部分，他愿意提供担保。涅拉提乌斯和阿里斯托认为，这样就应使他成为自由人；否则，许多人可能仅因账目性质及其不确定性而无法取得自由。他们的意见是正确的。

<!-- source-p 782 -->
<a id="40.7.5.1"></a>**1**　附条件获释的奴隶若被命令给付钱款，而非交代账目，就应实际支付钱款，不能仅提供保证人。

乌尔比安《评萨宾》第二十七卷。

<!-- source-p 785 -->
<a id="40.7.6.pr."></a>**序言**　若附条件获释的女奴被判处刑罚，且其自由条件在判决后成就，虽然这对女奴本人不发生助益，但应当使其子女受益：孩子应当如同母亲未被判刑一样，以自由人身份出生。

<!-- source-p 786 -->
<a id="40.7.6.1"></a>**1**　那么，若一名妇女在奴隶身份期间受孕，之后被敌人俘获，并在自由条件成就后于敌境分娩，她生下的孩子是否自由？毫无疑问，在此期间孩子是敌人的奴隶。不过，更妥当的意见是，孩子依复归权（*postliminium*）返回后成为自由人，因为如果母亲身处本国，孩子本应以自由人身份出生。

<!-- source-p 787 -->
<a id="40.7.6.2"></a>**2**　若她在敌境受孕，且在自由条件成就后分娩，较为宽厚的意见是，孩子享有复归权并成为自由人。

<!-- source-p 788 -->
<a id="40.7.6.3"></a>**3**　附条件获释的奴隶可以在买受人名下履行条件而取得自由；应当知道，这一规则适用于各种性别的附条件获释奴隶。条件不仅在奴隶被出售时转由买受人承受，也转由所有以任何方式取得该奴隶所有权的人承受。因此，无论附条件获释的奴隶是由继承人遗赠给你、经裁判判归你、被你因时效取得、交付给你，或以其他法律方式归你所有，都毫无疑问可以在你名下履行条件。买受人的继承人也适用同一规则。

<!-- source-p 789 -->
<a id="40.7.6.4"></a>**4**　若家子被指定为继承人，奴隶被命令向他给付钱款以取得自由，那么奴隶无论向家子还是向其父亲给付，都会取得自由，因为遗产利益也归父亲享有。即使家子死亡后，奴隶把钱交给父亲，作为继承人的继承人受领，也会成为自由人。假如奴隶被命令向某个外人给付以取得自由，而该外人后来成为继承人的继承人，奴隶履行条件时也不是向外人本人给付，而应被视为向继承人给付。

<!-- source-p 790 -->
<a id="40.7.6.5"></a>**5**　附条件获释的奴隶被命令给付十个金币以取得自由，已给付五个后被出售的，应向买受人给付剩下的五个。

<!-- source-p 791 -->
<a id="40.7.6.6"></a>**6**　若你的奴隶买下附条件获释的奴隶，后者应把遗嘱命令其给付继承人的钱交给你。若他把钱交给你的另一名奴隶，只要该奴隶是以特有产购得附条件获释的奴隶，且你没有收回其特有产，我认为后者也会成为自由人；因为这应视为他已经以这种方式向你给付，犹如经你同意把钱交给你的任何其他奴隶。

<!-- source-p 792 -->
<a id="40.7.6.7"></a>**7**　若奴隶不是被命令给付十个金币以取得自由，而是被命令交代账目后取得自由，须考察这一条件是否转移给买受人。应当知道，通常只有要求给付的条件才转移给买受人；要求实施行为的条件则不转移，例如命令奴隶教其儿子读书，因为这类条件依附于指定承担行为的人。交代账目的条件，就支付账目余额而言，属于给付钱款；就提交账簿、询问和审查账目、核对并核查账目而言，则属于行为条件。那么，奴隶向买受人支付余额是否足以使其自由，而其他事项仍由继承人负责？我认为，支付余额的条件也转移给买受人；这样一来，条件便被分割。庞波尼乌斯在《评萨宾》第八卷中也这样写道。

<!-- source-p 793 -->

<a id="40.7.8"></a>**40.7.8**

<!-- source-p 797 -->

<a id="40.7.8.pr."></a>**序言**　奴隶依如下条件被命令取得自由：“如果给付十个金币，就成为自由人。”他应当向继承人给付；因为若无其他明确的受领人，向继承人给付即可使其取得自由。

<!-- source-p 799 -->
<a id="40.7.8.1"></a>**1**　若各继承人分别把自己的份额出售给不同买受人，附条件获释的奴隶就应向这些买受人给付其原本应向继承人给付的相应份额。拉贝奥说，如果遗嘱只写了继承人的姓名，应按人数均分给付；但若写的是“给付继承人”，则应按照遗产份额给付。

<!-- source-p 800 -->
<a id="40.7.9"></a>**40.7.9**

<!-- source-p 801 -->
乌尔比安《评萨宾》第二十八卷。

<!-- source-p 802 -->
<a id="40.7.9.pr."></a>**序言**　任何人都应当知道，在条件成就之前，附条件获释的奴隶仍是继承人的奴隶。因此，他可以被作为诺克萨责任的标的交付；即使已经交付，他仍可期待取得自由，因为诺克萨交付并未剥夺其自由希望。

<!-- source-p 803 -->
<a id="40.7.9.1"></a>**1**　继承人若不按照原有条件出售附条件获释的奴隶，该奴隶的法律地位仍不改变；他可以依与对继承人相同的方式向买受人给付以取得自由。但若继承人隐瞒奴隶的附条件获释身份，继承人须承担买卖之诉责任。明知而隐瞒自由条件、将奴隶当作普通奴隶出售的，还会招致更重的星点欺诈罪（*stellionatus*）指控。

<!-- source-p 804 -->
<a id="40.7.9.2"></a>**2**　有人讨论：把附条件获释的奴隶作为诺克萨责任标的交付的人，是否因此免责？奥克塔维努斯认为可以免责；他也认为，若某人因要式口约而负有交付斯提库斯的义务，却交付了附条件获释的斯提库斯，也应免责。因为若斯提库斯在交付前已经取得自由，全部债务都会消灭。债务只能是那些可以用金钱清偿或履行的事项；自由既不能用钱清偿，也不能恢复。这个意见在我看来是正确的。

<!-- source-p 805 -->
<a id="40.7.9.3"></a>**3**　只有在遗产已被接受后，附条件获释奴隶的条件才不可改变。在接受遗产之前，奴隶可能被他人作为奴隶因时效取得，其自由希望也会受损；但遗产后来一经接受，基于有利于自由的原则，自由希望又会恢复。

<!-- source-p 815 -->
<a id="40.7.13"></a>**40.7.13**

<!-- source-p 816 -->
尤利安《学说汇纂》第四十三卷。

<!-- source-p 817 -->
<a id="40.7.13.pr."></a>**序言**　若遗嘱人这样授予自由：“斯提库斯，若我的继承人没有在其遗嘱中解放你，你就成为自由人”，依遗嘱人的意思，应理解为“若继承人没有在其遗嘱中写明授予你自由”。因此，若继承人在自己的遗嘱中授予奴隶自由，条件就不成就；若没有授予，条件即告成就，奴隶在继承人生命的最后时点取得自由。

<!-- source-p 818 -->
<a id="40.7.13.1"></a>**1**　共有奴隶被命令“给付十个金币后取得自由”，可以从其以任何方式取得的特有产中给付；无论钱款在继承人还是共有人处，无论奴隶被命令向继承人还是向第三人给付，均无区别。因为所有附条件获释奴隶的规则都适用于此种情形；为履行条件，奴隶可以处分特有产中的钱款。

<!-- source-p 819 -->
<a id="40.7.13.2"></a>**2**　两名奴隶被命令分别交代账目后取得自由的，如果账目各自分开管理，他们当然可以分别履行条件。但若两人的业务账目混在一起，无法分开，其中一人的拖延就必然妨碍另一人取得自由。除非根据账目计算出的余额由两人共同付清，或由其中一人付清全部余额，否则不能认为另一人的条件已经成就。

<!-- source-p 820 -->
<a id="40.7.13.3"></a>**3**　奴隶被命令“若发誓自己将登上卡庇托利欧山，即成为自由人”，他一经发誓，即使尚未登山，也成为自由人。

<!-- source-p 821 -->
<a id="40.7.13.4"></a>**4**　继承人的奴隶被命令交付继承人自己的财物后取得自由的，也会取得自由，因为遗嘱人可以不附加任何交付条件，直接命令解放继承人的奴隶。

<!-- source-p 822 -->
<a id="40.7.13.5"></a>**5**　遗嘱写道：“斯提库斯年满三十岁时成为自由人。斯提库斯若不给付十个金币，就不得成为自由人。”其效力是：“斯提库斯若给付十个金币且年满三十岁，即成为自由人。”因为后来剥夺自由或遗赠的附条件安排，会对先前已经授予的自由或遗赠附加相反条件。

<!-- source-p 823 -->
<a id="40.7.14"></a>**40.7.14**

<!-- source-p 824 -->
阿尔菲努斯《学说汇纂》第四卷。

<!-- source-p 825 -->
<a id="40.7.14.pr."></a>**序言**　主人在遗嘱中命令奴隶给付继承人十个金币后取得自由。奴隶通常把自己劳务的报酬交给继承人；当继承人从报酬中收取的钱超过十个金币时，奴隶便主张自己已经自由。有人就此事咨询。答复是：奴隶并未成为自由人，因为他给付这笔钱是作为劳务报酬，而不是为了取得自由；这与他向主人租用一块土地并支付地租，并不会因此取得自由相同。

<!-- source-p 826 -->
<a id="40.7.14.1"></a>**1**　奴隶被命令为继承人服役七年后取得自由，但他逃亡了一年。七年期满后，答复认为他尚未自由，因为逃亡者没有为主人提供劳务。因此，除非他返还后服役的日数补足缺失日数，否则不会自由。但若遗嘱写的是奴隶服役七年后自由，那么他返还后继续服役，补足逃亡期间，便可以取得自由。

<!-- source-p 827 -->
<a id="40.7.15"></a>**40.7.15**

<!-- source-p 828 -->
阿非利卡努斯《疑问集》第九卷。

<!-- source-p 829 -->
<a id="40.7.15.pr."></a>**序言**　继承人死亡后，若附条件获释的奴隶以遗嘱要求给付的数额使遗产增值，例如替遗产清偿债权人，或为家中奴隶提供口粮，阿非利卡努斯认为，该奴隶立即取得自由。

<!-- source-p 830 -->
<a id="40.7.15.1"></a>**1**　继承人出售一名被命令给付十个金币后取得自由的奴隶时，已告知买受人该条件，并在交付时约定这十个金币应交给继承人而非买受人。问题是，奴隶向谁给付后才能取得自由？答复是应当向继承人给付。即使继承人约定奴隶须向某个第三人给付，也应认为该约定有效；因为奴隶依继承人意思向他人清偿，也等同于向继承人清偿。

<a id="40.7.17"></a>**40.7.17**

<!-- source-p 835 -->
涅拉提乌斯《札记》第三卷。

<!-- source-p 836 -->

<!-- source-p 843 -->
<a id="40.7.20"></a>**40.7.20**

<!-- source-p 844 -->
保罗《评普劳提乌斯》第十六卷。

<!-- source-p 845 -->
<a id="40.7.20.pr."></a>**序言**　若奴隶获遗赠特有产，但遗嘱又命令他向他人给付十个金币后取得自由；继承人阻止其给付，随后奴隶依据遗赠请求特有产，继承人能否通过诈欺抗辩扣除本应给付的数额，使自己获益而不让奴隶取得自由？抑或继承人不应因违反遗嘱人的意思而获利？既然奴隶没有遭受损失且已经取得自由，让继承人蒙受损失似乎有失公允。

<!-- source-p 846 -->
<a id="40.7.20.1"></a>**1**　还有一个问题：奴隶违背继承人意愿，或继承人不知情时给付钱款，钱款是否归受领人所有？尤利安确实认为，应当理解为法律为此种情形特许附条件获释的奴隶处分钱款，即使继承人反对，钱款也归受领人所有。

<!-- source-p 847 -->
<a id="40.7.20.2"></a>**2**　若奴隶被命令向继承人给付十个金币以取得自由，而继承人恰好欠奴隶同样数额，奴隶可以主张抵销该笔钱款，并因此取得自由。

<!-- source-p 848 -->
<a id="40.7.20.3"></a>**3**　奴隶被命令向某人给付钱款以取得自由，但该受领人在奴隶给付前死亡。萨宾认为，若奴隶当时已备好十个金币，他就成为自由人，因为未能给付并非因奴隶所致。尤利安则说，基于有利于自由的原则，法律已经确立：即使奴隶后来才有能力取得十个金币，也会取得自由。奴隶因此是依据法律规则而非遗嘱取得自由；所以，若受领人同时也是遗赠受领人，他死亡后奴隶虽取得自由，却不能取得遗赠，这一点尤利安也予以认可。在此问题上，奴隶与其他遗赠受领人相同。若是继承人阻止奴隶履行条件，情形则不同：奴隶是依遗嘱取得自由。

<!-- source-p 849 -->
<a id="40.7.20.4"></a>**4**　神圣的哈德良皇帝以敕答指出，奴隶被命令向继承人给付，也可以向继承人的继承人给付；若遗嘱人有此意思，对受遗赠人也应作相同处理。

<!-- source-p 850 -->
<a id="40.7.20.5"></a>**5**　有些条件因其性质不能同时完成，而必须分期履行，例如奴隶被命令给付十日劳务，因为劳务必须逐日提供。因此，即使附条件获释的奴隶逐日给付一枚金币，也可以认为条件已经履行。劳务条件不同，因为每一日的劳务都必须实际提供。但若继承人拒绝接受劳务，奴隶也不会立即自由，而须等到足以完成全部劳务的期间届满。奴隶被命令前往卡普阿而继承人阻止其前往的，亦同：只有到了他原本能够抵达卡普阿的时点，奴隶才取得自由，因为提供劳务与旅行都包含了相应的时间要求。

<!-- source-p 851 -->
<a id="40.7.20.6"></a>**6**　若奴隶依如下安排获得自由：“斯提库斯，若继承人没有解放你，你就成为自由人”，继承人仍可以解放他；这并不违背遗嘱人的意思而剥夺奴隶的自由。不过，不应要求继承人必须立即行动，以致迫使他中断旅行、匆忙返程释奴，或停止必要事务的管理；也不应拖延过久，任由释奴一直延至继承人生命终结。应给继承人一段合理期间，使其能在不遭受重大不便的情况下尽早解放奴隶。遗嘱若另行规定了期限，则依该期限处理。

<a id="40.7.21.pr."></a>**序言**　拉贝奥在《后论》中记载：“我的管家卡莱努斯若被认为认真办理账目，就成为自由人，并取得其全部财产及一百个金币。”我们要求的勤勉，应当是对主人有益的勤勉，而不是对奴隶本人有益的勤勉。这种勤勉还须伴有诚信，不仅体现在账目安排上，也体现在交付余额方面。遗嘱写作“若被认为”，应理解为“若可以认为”。古人解释《十二表法》中的“若雨水造成损害”时，也作相同理解，即“若雨水可能造成损害”。如果有人问，应由谁判断这种勤勉，则应依善良人标准行事，遵从继承人的合理判断。例如，奴隶被命令给付一笔确定金额后取得自由，但遗嘱没有写明向谁给付；他向继承人给付，就应像遗嘱写明“若向继承人给付”时一样取得自由。

<a id="40.7.29.1"></a>**1**　昆图斯·穆基乌斯写道：家父在遗嘱中写明：“我的奴隶安德洛尼库斯若向我的继承人给付十个金币，即成为自由人。”之后，围绕遗产发生争议。一方主张自己依法作为无遗嘱继承人取得遗产；另一方占有遗产，主张自己是遗嘱继承人。裁判作出有利于主张遗嘱继承的一方的判决。此后，安德洛尼库斯询问：如果自己向该人给付二十个金币，因判决有利于该人，自己是否会成为自由人；还是说，该判决对此并无影响？因此，如果安德洛尼库斯向遗嘱所指定的继承人给付二十个金币，而裁判结果又对遗产占有人不利，那么安德洛尼库斯仍将处于奴隶身份。拉贝奥认为，昆图斯·穆基乌斯所说的情形，只适用于胜诉者确实是依法取得无遗嘱继承权的人；若真正的遗嘱继承人仅因法官不当而败诉，他仍然是遗嘱继承人，安德洛尼库斯向其给付后，仍应认为已履行条件并成为自由人。不过，最为正确的意见是阿里斯托曾在致塞尔苏斯的答复中提出的：奴隶可以向依判决胜诉的无遗嘱继承人给付钱款，因为《十二表法》中的“买受”一词似乎涵盖所有形式的转让；由何种原因取得所有权并不重要。因此，判决确认的继承人也包括在该法的适用范围内，奴隶向其给付后即可自由。至于这名遗产占有人，若其因遗产请求之诉败诉，则应将包括该笔钱款在内的全部所得一并返还胜诉者。

<!-- source-p 901 -->
<a id="40.7.34.pr."></a>**序言**　奴隶被命令向继承人给付十个金币后成为自由人。继承人解放了附条件获释的奴隶，之后死亡。奴隶不必向继承人的继承人给付钱款。只有在前一继承人本应以所有权人身份收取钱款时，才应考虑向其继承人给付的规则。由此，条件可以说是具有可变动性：奴隶在前一继承人名下履行条件有两项依据，一是该继承人的所有权，二是遗嘱指定了该受领人。前一依据随着附条件获释奴隶的所有权转移，适用于其所有的继承人；后一依据则只附着于遗嘱指明的那个人。

<!-- source-p 902 -->
<a id="40.7.34.1"></a>**1**　安敦尼皇帝以敕答指出，奴隶被命令交代账目后取得自由，若继承人借口拒绝收取账目，奴隶仍会成为自由人。该敕答应当这样理解：若账目没有余额，奴隶即可自由；若有余额，则只有在他诚实地提出应当偿还的数额时才自由。继承人迟延并不足以使奴隶自由，除非奴隶作出了在没有迟延时本可使其取得自由的行为。比如，奴隶达马被命令“若明年去西班牙收取果实，即成为自由人”，继承人却把他留在罗马，不让他前往。我们能否说他在尚未收取果实前就立即自由？又比如，在罗马订立要式口约：“你承诺在西班牙给付一百吗？”通说认为，该口约包含了抵达西班牙所需的时间，在到达之前不能依法起诉。同样，若继承人收到账目并计算余额后，公开声明或写信告知奴隶：即使奴隶没有可用于偿还的余额，继承人也愿意免除其债务，则应认为自由条件已经成就。那么，若奴隶否认存在余额，并主张继承人阻止其提交账目、导致他成为自由人，而继承人则否认自己曾迟延、并主张奴隶确有余额，该如何处理？应由审理自由身份的人查明条件是否成就；其职务包括审查是否存在迟延并核算账目，若查明确有余额，就应判定奴隶尚未自由。反之，若奴隶从未否认欠有余额；继承人要求交代账目时，他已经提供账目，并表示愿意偿还经核实的余额，且具备偿付能力、已提出给付，而继承人仍然迟延，则应作有利于自由的判决。

<a id="40.7.39.2"></a>**2**　若继承人把钱交给奴隶用于经营，拉贝奥和特雷巴提乌斯答复说，奴隶不能通过把同一笔钱交还而依遗嘱取得自由，因为这更像返还而非给付。我认为，若这笔钱属于特有产，奴隶就可以依遗嘱取得自由。

<!-- source-p 920 -->
<a id="40.7.39.3"></a>**3**　遗嘱写道：“奴隶达马向我的继承人提供七年劳务后，即成为自由人。”若该奴隶在七年期限内成为公诉案件的被告，而七年期限已经届满，塞尔维乌斯认为他不应自由；拉贝奥认为，即使他之后补足七年劳务，也会自由。这一意见是正确的。

<!-- source-p 921 -->
<a id="40.7.39.4"></a>**4**　遗嘱写道：“斯提库斯若向阿提娅给付一千个金币，即成为自由人。”阿提娅在遗嘱人尚在世时死亡。拉贝奥和奥菲利乌斯答复说，斯提库斯不能成为自由人。特雷巴提乌斯认为，若阿提娅在遗嘱订立前死亡，结论相同；若她在遗嘱订立后死亡，奴隶就会自由。拉贝奥和奥菲利乌斯的意见确有其理，但我们适用的法律是，该奴隶仍应依遗嘱取得自由。

<!-- source-p 922 -->
<a id="40.7.39.5"></a>**5**　奴隶若被命令为第三人提供劳务，没有人能够以自己的劳务代替奴隶履行，从而使奴隶自由。钱款则适用不同规则，因为第三人可以替奴隶给付钱款而使其自由。

<a id="40.7.40"></a>**40.7.40**

<!-- source-p 924 -->
斯凯沃拉《学说汇纂》第二十四卷。

<!-- source-p 925 -->
<a id="40.7.40.pr."></a>**序言**　遗嘱人授予斯提库斯自由，并写道：“我请求并委托我的继承人，在他交代账目后解放斯提库斯。”遗嘱人死亡后，斯提库斯受托收取大笔钱款，却没有把从租佃人处收取的某些款项记入遗产账目；他还掏空遗产，偷偷打开仓库，取走家具和衣物，并耗尽储藏室的物品。问题是，是否必须等他返还账目不清所造成的损失及其盗取的财物，才能履行遗嘱信托式释奴？答复是，在他返还账目余额以及一切因其行为而短少的财物之前，不应履行遗嘱信托式释奴。

<!-- source-p 926 -->
<a id="40.7.40.1"></a>**1**　遗嘱写道：“潘菲卢斯交出其特有产的全部真实财物后，即成为自由人。”有人问：潘菲卢斯欠主人的债务超过其特有产价值，但他已诚信地将特有产中的全部财物交给继承人，能否依遗嘱取得自由？答复是，没有任何事实表明他不能取得自由。

<!-- source-p 927 -->
<a id="40.7.40.2"></a>**2**　遗嘱人将自由释奴潘菲卢斯指定为部分继承人，并预先遗赠奴隶斯提库斯给他；遗嘱以如下措辞授予斯提库斯自由：“从我死亡之日起，若斯提库斯连续五年每月给付你六十枚金币，你就解放他。”潘菲卢斯在五年届满前死亡，并指定儿子与妻子为继承人；他就斯提库斯作如下安排：“奴隶斯提库斯依我保护人的遗嘱附有特定条件遗赠给我。我命令他毫无争议地向我的儿子和妻子给付并履行义务；期限届满后，他们应解放他。”问题是，如果斯提库斯没有按月给付六十枚金币，五年期满后是否仍应向其履行遗嘱信托式释奴？答复是，若其未曾给付，不应履行遗嘱信托式释奴。

<!-- source-p 928 -->
<a id="40.7.40.3"></a>**3**　遗嘱以如下方式解放一名奴隶：“我的代理奴隶斯提库斯若向我的继承人交代其全部业务账目，并就此提供担保，即成为自由人；他自由后，我希望给他二十个金币及其特有产。”有人问：若斯提库斯愿意向继承人交代多年来经办、但遗嘱人未曾签名的账目，他能否依遗嘱自由？遗嘱人虽因重病不能在账目上签字，却在遗嘱上签了名。答复是，只要账目如实交代，余额也一并交付，他就会成为自由人。

<!-- source-p 929 -->
<a id="40.7.40.4"></a>**4**　又问：奴隶的助手收取某些款项，却未记入日记账，或以欺诈方式办理的事项，是否可归责于该奴隶，因为他担任主管？答复是，若该事项应当归因于他的过失，就属于其交代账目的义务范围。

<!-- source-p 930 -->
<a id="40.7.40.5"></a>**5**　又问：若该奴隶没有向土地承租人或庄园管事收取租金，反而还预先借钱给他们，这些事项是否也应计入账目？答复是，前面已经答复过。

<!-- source-p 931 -->
<a id="40.7.40.6"></a>**6**　又问：该奴隶在交代账目之前把自己的全部财物，也就是特有产，带走，是否因此承担责任？答复是，只要账目仍能如实交代，这一事实不妨碍条件成就。

<!-- source-p 932 -->
<a id="40.7.40.7"></a>**7**　提提乌斯在遗嘱中将代理奴隶分别遗赠给不同的人，并附加条件“若他们向继承人交代账目”；之后他又在遗嘱正文中写道：“我希望所有已遗赠或将被解放的代理奴隶，在我死亡后的第四个月内向继承人交代账目，并向我遗赠他们的主人交账。”其后，他又命令其他代理奴隶自由，也附有“若向继承人交代账目”的条件。有人问：若继承人阻止他们交账，他们是否不再是附条件获释的奴隶，还是说他们日后仍可在交账并偿还余额后依遗嘱取得自由？答复是，遗赠和自由只有在账目已经交代，或因继承人阻挠而未能交代时，才发生效力。不过，裁判者应判断，遗嘱是否把四个月规定为遗赠和自由条件本身的期限，还是说遗嘱人只是给继承人四个月时间，以便奴隶在有充分时间后交账并偿还余额；后一理解更符合遗嘱人担心继承人拖延、故意规定期限的情形。较妥当的做法是推定有利于附条件获释的奴隶。

<!-- source-p 933 -->
<a id="40.7.40.8"></a>**8**　某拍卖收款代理商的几乎全部财产都是债权。他按如下条件解放其代理奴隶达马：“无论谁成为我的继承人，若我的奴隶达马在我死亡后的六个月内，向继承人交代其本人及其同伴奴隶潘菲卢斯所经办的全部账目，并使账目收支相抵，即成为自由人。”有人问，“使账目相抵”是否适用于所有债权，但不包括已无法收回的款项；是否意指必须从所有债务人处收回全部钱款并交给继承人，或就此提供担保；若他们未能在六个月内追收债款，是否不能取得自由？答复是，遗嘱的上述措辞清楚设定了条件。因此，只有他们履行条件，或因继承人阻挠而不能履行时，才会成为自由人。
