# D.40.12 论自由身份诉讼（*De liberali causa*）—第一部分

<!-- source-p 1141 -->
<a id="40.12"></a>**40.12.0 论自由身份诉讼**（*De liberali causa*）。

<!-- source-p 1142 -->
<a id="40.12.1"></a>**40.12.1**

<!-- source-p 1143 -->
乌尔比安《告示评注》第五十四卷。

<!-- source-p 1144 -->
<a id="40.12.1.pr."></a>**序言**　如果某人处于奴隶身份占有之中，却不肯就自己的身份提起诉讼，例如，他想对自己及其家族造成某种损害，那么，在这种情形下，允许某些人代他提起诉讼是公平的。譬如，父亲主张儿子仍在其亲权之下，即使儿子不愿意，父亲也可代其诉讼。即便儿子不在父亲的亲权之下，也应赋予父亲此项权利，因为父亲始终有利害关系，不使儿子陷于奴隶身份。

<!-- source-p 1145 -->
<a id="40.12.1.1"></a>**1**　反过来说，对于不情愿的父母，也应赋予子女同样的权能；毕竟，若父亲处于奴隶身份，对儿子而言并非轻微的耻辱。

<!-- source-p 1146 -->
<a id="40.12.1.2"></a>**2**　因此，看来也应将此项权利赋予旁系亲属。

<!-- source-p 1147 -->
<a id="40.12.2"></a>**40.12.2**

<!-- source-p 1148 -->
盖尤斯《城市裁判官告示评注·自由身份诉讼题》。

<!-- source-p 1149 -->
奴隶身份会延及我们，使我们遭受痛苦与侵害。

<!-- source-p 1150 -->
<a id="40.12.3"></a>**40.12.3**

<!-- source-p 1151 -->
乌尔比安《告示评注》第五十四卷。

<!-- source-p 1152 -->
<a id="40.12.3.pr."></a>**序言**　我认为，生身父母也应获此同样权利：若儿子出生时处于奴隶身份，后来获释，父母即可主张其自由身份。

<!-- source-p 1153 -->
<a id="40.12.3.1"></a>**1**　军人也获准为对自己具有必要关系之人提起自由身份诉讼。

<!-- source-p 1154 -->
<a id="40.12.3.2"></a>**2**　若没有其他此类人能够为其诉讼，则必须允许其母亲、女儿、姐妹及其他女性亲属，乃至其妻子，前往裁判官处报告此事；经审理案情后，即使本人不愿意，也应为其提供救济。

<!-- source-p 1155 -->
<a id="40.12.3.3"></a>**3**　如果我主张某人是我的自由释奴或自由女释奴，也应作同样处理。

<!-- source-p 1156 -->
<a id="40.12.4"></a>**40.12.4**

<!-- source-p 1157 -->
盖尤斯《城市裁判官告示评注·自由身份诉讼题》。

<!-- source-p 1158 -->
但只有在自由释奴不知情的情况下，该释奴自行听任他人将其出售，释奴保护人才可获准代其提起自由身份诉讼。

<!-- source-p 1159 -->
<a id="40.12.5"></a>**40.12.5**

<!-- source-p 1160 -->
乌尔比安《告示评注》第五十四卷。

<!-- source-p 1161 -->
<a id="40.12.5.pr."></a>**序言**　毕竟，我们有利害关系去拥有自由释奴和自由女释奴。

<!-- source-p 1162 -->
<a id="40.12.5.1"></a>**1**　如果前述数人中有多人愿意为这些人提起诉讼，裁判官应介入，选定其认为最适宜者。这一规则在存在多名释奴保护人时也应遵守。

<!-- source-p 1163 -->
<a id="40.12.6"></a>**40.12.6**

<!-- source-p 1164 -->
盖尤斯《城市裁判官告示评注》。

<!-- source-p 1165 -->
处理此事应从宽：若被拖入奴隶身份的是精神失常者或婴幼儿，则不但近亲，连无亲属关系之人也应获准为其提起诉讼。

<!-- source-p 1166 -->
<a id="40.12.7"></a>**40.12.7**

<!-- source-p 1167 -->
乌尔比安《告示评注》第五十四卷。

<!-- source-p 1168 -->
<a id="40.12.7.pr."></a>**序言**　即使自由出生者，尤其是年满二十岁者，曾听任自己被出售，或以其他方式被置于奴隶身份，也不妨碍其主张自由身份；但若其听任自己被出售，是为了分得价款，则属例外。

<!-- source-p 1169 -->
<a id="40.12.7.1"></a>**1**　未满二十岁的人若听任自己被出售以分得价款，年满二十岁后，这一事实不再对其不利。但如果他在二十岁之前出售自己，却在年满二十岁后才分得价款，则可以拒绝其主张自由身份。

<!-- source-p 1170 -->
<a id="40.12.7.2"></a>**2**　若有人明知买下的是自由人，则无论被买者年龄多大，均不得拒绝其针对该买受人主张自由身份；因为明知而购买的人不值得宽宥，即使其明知买到的是自由人仍审慎地完成购买。可是，若后来另有一人从该知情买受人处购得此人，且该后来买受人并不知情，则应拒绝被买者主张自由身份。

<!-- source-p 1171 -->
<a id="40.12.7.3"></a>**3**　若两人共同购买此人，其中一人知情，另一人不知情，则应考虑知情者是否不应损害不知情者；较妥当的看法是肯定的。但随之而来的问题是：不知情者仅取得自己购买的份额，还是取得全部？另一份额又应归谁？是否归于知情者？然而，知情购买者既然不值得取得任何东西，就不应归给他。反过来说，不知情者也不能取得超过其所购买份额的所有权。这样一来，知情购买者竟因另一人不知情而获益。

<!-- source-p 1172 -->
<a id="40.12.7.4"></a>**4**　另有一些情形也会导致拒绝主张自由身份。例如，某人声称依据遗嘱获得自由，但裁判官禁止开启该遗嘱，因为据称立遗嘱人遭其家内人杀害；既然此人可能会被判处刑罚，就不应准许其提起自由身份诉讼。即使已经准许提起诉讼，若尚不确定此人究竟有罪还是无罪，也应延缓自由身份诉讼，直至查明被杀害者死亡的相关事实；届时即可确定此人是否应受刑罚。

<!-- source-p 1173 -->
<a id="40.12.7.5"></a>**5**　若某人从奴隶身份主张自己应为自由人，他便处于原告地位；若有人从自由身份主张某人应为奴隶，则主张此人为自己奴隶的人处于原告地位。因此，为使裁判程序得以进行，应先由审理自由身份案件的法官审查究竟是从自由身份主张奴隶身份，还是反之。倘若查明争讼之人曾处于自由身份占有之中且并无恶意欺诈，则自称为主人的人处于原告地位，并必须证明此人为自己的奴隶。反之，若裁判认定，在诉讼准备期间，此人并未处于自由身份占有之中，或其处于该状态时具有恶意欺诈，则应由其本人证明自己是自由人。

<!-- source-p 1174 -->
<a id="40.12.8"></a>**40.12.8**

<!-- source-p 1175 -->
乌尔比安《告示评注》第五十五卷。

<!-- source-p 1176 -->
<a id="40.12.8.pr."></a>**序言**　用益权人也可提起自由身份诉讼，即使所有权人——也就是主张自己为所有权人的人——也想对身份争议提起诉讼。

<!-- source-p 1177 -->
<a id="40.12.8.1"></a>**1**　若数人主张对同一奴隶享有共有所有权，则应将案件交由同一法官审理；元老院亦曾作此决议。反之，若每人都主张自己对该奴隶享有全部所有权，而非部分所有权，则不适用该元老院决议；因为每人均主张全部所有权，不存在裁判相互矛盾的风险。

<!-- source-p 1178 -->
<a id="40.12.8.2"></a>**2**　若一人主张对该奴隶享有全部用益权，另一人主张所有权；或者一人主张所有权，另一人主张该奴隶已质押给自己，也应由同一法官审理。至于该奴隶是由同一人还是由他人出质，与此无关。

<!-- source-p 1179 -->
<a id="40.12.9"></a>**40.12.9**

<!-- source-p 1180 -->
盖尤斯《城市裁判官告示评注·自由身份诉讼题》。

<!-- source-p 1181 -->
<a id="40.12.9.pr."></a>**序言**　若用益权人和所有权人同时针对主张自由身份之人提出主张，其中一人可能缺席。此时，裁判官是否会允许到场者单独对其诉讼，可能引起疑问，因为不应让一人的串通或怠惰损害另一人的权利。但较妥当的意见是，应允许二人中的任何一人提起诉讼，以使另一人的权利不受损害。若在裁判尚未终结前另一人到场，则应将案件交由同一法官审理；除非其提出正当理由说明不应交由该法官审理，例如声称该法官是自己的仇敌。

<!-- source-p 1182 -->
<a id="40.12.9.1"></a>**1**　若有两名或更多人被主张为所有权人，其中一些到场、另一些缺席，也应作同样处理。

<!-- source-p 1183 -->
<a id="40.12.9.2"></a>**2**　因此，在上述两种情形中都要考察：先行起诉者败诉后，后来胜诉是否对其有利，反之亦然；也就是说，其中任何一人胜诉，是否也使另一人受益，如同自由释奴的继承人会因奴隶曾为诈害释奴保护人而获释而受益。若采肯定说，则在后一人提起同一请求时，可以通过反驳已经裁判的抗辩予以回应。若采否定说，则还会产生以下疑问：有人败诉的那一份究竟归于无人、归于被起诉者，还是应归于胜诉者？于是应向胜诉者授予有用诉权，而裁判官绝不应容许某人一部分为奴、一部分为自由人。

<!-- source-p 1184 -->
<a id="40.12.10"></a>**40.12.10**

<!-- source-p 1185 -->
乌尔比安《告示评注》第五十五卷。

<!-- source-p 1186 -->
关于我们所说的“曾处于自由身份”，应如此理解：并非要求在自由身份诉讼中受审之人证明自己确为自由人，而是要求其曾在没有恶意欺诈的情况下占有自由身份。所谓“没有恶意欺诈”，我们还须考察。尤利安说，凡自认为是自由人者，只要依自由人的身份行事，即使实际为奴，也应视为曾在没有恶意欺诈的情况下处于自由身份。瓦鲁斯则写道，明知自己是自由人的人若处于逃亡状态，便不能视为在没有恶意欺诈的情况下处于自由身份；但只要他不再像逃亡奴隶那样躲藏，而开始以自由人身份行事，便从此开始符合这一条件。因为瓦鲁斯说，明知自己是自由人却仍以逃亡奴隶的方式行事之人，仅凭其处于逃亡状态这一事实，就是以奴隶身份行事；

<a id="40.12.11"></a>**40.12.11**

<!-- source-p 1188 -->
盖尤斯《城市裁判官告示评注·自由身份诉讼题》。

<!-- source-p 1189 -->
即使他在逃亡期间曾以自由人身份行事，我们仍会说，他处于同一情形。

<!-- source-p 1190 -->
<a id="40.12.12"></a>**40.12.12**

<!-- source-p 1191 -->
乌尔比安《告示评注》第五十五卷。

<!-- source-p 1192 -->
<a id="40.12.12.pr."></a>**序言**　因此应知，自由人也可能以恶意欺诈方式占有自由身份，而奴隶也可能在没有恶意欺诈的情况下占有自由身份。

<!-- source-p 1193 -->
<a id="40.12.12.1"></a>**1**　某婴儿虽为自由人，却被偷走，并在善意之下处于奴隶身份；后来，他不知自己的身份而离开，开始秘密地以自由人身份生活：这种情形不属于在没有恶意欺诈的情况下占有自由身份。

<!-- source-p 1194 -->
<a id="40.12.12.2"></a>**2**　奴隶也可能在没有恶意欺诈的情况下占有自由身份，例如，他依据遗嘱取得自由，却不知道该遗嘱无效；或者有人对他实施了仪式杖释奴，而他以为对方是主人，实际却不是；又或者他虽为奴隶，却一直被当作自由人抚养。

<!-- source-p 1195 -->
<a id="40.12.12.3"></a>**3**　一般而言，凡有人基于正当理由，甚至不正当理由，但并非出于狡诈，而认为自己是自由人并以自由人身份生活，就应认为其属于在没有恶意欺诈的情况下占有自由身份，因而享有占有人所享有的利益。
