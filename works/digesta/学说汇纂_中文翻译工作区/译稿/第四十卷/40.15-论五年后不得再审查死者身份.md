# D.40.15 论五年后不得再审查死者身份（*Ne de statu defunctorum post quinquennium quaeratur*）

> 底本：*Digesta Iustiniani*，EPUB `book-40.xhtml`，source-p 1373–1391。

<!-- source-p 1373 -->
<a id="40.15"></a>**40.15.0**　论不得在五年后再审查死者的身份。

<!-- source-p 1374 -->
<a id="40.15.1"></a>**40.15.1**

<!-- source-p 1375 -->
马尔基安《论告发者》单卷本。

<!-- source-p 1376 -->
<a id="40.15.1.pr."></a>**序言**　五年之后，不得再询问死者的身份，无论是以私人名义，还是以国库名义。

<!-- source-p 1377 -->
<a id="40.15.1.1"></a>**1**　即便某人在五年期限内死亡，若对其身份的审查会对一名已死亡超过五年者造成先决影响，也不得重新审查其身份。

<!-- source-p 1378 -->
<a id="40.15.1.2"></a>**2**　而且，若对生者身份的审查会对一名已死亡超过五年者的身份造成先决影响，也不得询问该生者的身份；神圣的哈德良皇帝如此规定。

<!-- source-p 1379 -->
<a id="40.15.1.3"></a>**3**　但有时，即使尚未经过五年，也不得审查死者的身份。因为神圣的马尔库斯皇帝在敕令中规定：若某人已被判决为自由出生者，可以请求重新审查其自由出生者身份判决；但只能在该人仍在世时提出，不得在其死后提出。甚至，若重新审查程序已经开始，也会因其死亡而终止；该敕令亦作此规定。

<!-- source-p 1380 -->
<a id="40.15.1.4"></a>**4**　若有人请求重新审查身份，意在使其身份降等，则应依我前述规则提出五年期间抗辩。那么，若是请求使其身份升等呢？例如，原本被视为奴隶者被主张为自由释奴，为何不应准许？又如，若有人被称作奴隶，仿佛其出生于一名在五年前死亡的女奴，为何不准许证明该女奴原是自由人？因为这同样是为那位死者主张身份。马尔凯鲁斯在《论执政官职务》第五卷写道，此事可以准许；我本人也在公开法庭遵循了相同意见。

<!-- source-p 1381 -->
<a id="40.15.2"></a>**40.15.2**

<!-- source-p 1382 -->
帕比尼安《答复集》第十四卷。

<!-- source-p 1383 -->
<a id="40.15.2.pr."></a>**序言**　众所周知，若父亲或母亲死亡后五年内，其身份未被重新审查，就不得仅因父母的身份而对其子女提起自由身份争议诉讼。〔底本异文：*memoriam* 后附 *memeriam*。〕

<!-- source-p 1384 -->
<a id="40.15.2.1"></a>**1**　在属于公共保护范围的事项中，即使未成年人提起诉讼，也不得给予其恢复原状的救济；因为他们在没有监护人的情况下，已经超过五年期间。

<!-- source-p 1385 -->
<a id="40.15.2.2"></a>**2**　保护死者身份的五年期间抗辩，不因有人声称在其死亡前已经提起诉讼而失效；若能证明，提起旧诉之人已经停止诉讼，且该案因长期沉默而终结，即应如此处理。

<!-- source-p 1386 -->
<a id="40.15.3"></a>**40.15.3**

<!-- source-p 1387 -->
赫莫革尼安《法学摘要》第六卷。

<!-- source-p 1388 -->
对一名死亡已逾五年者，主张其身份优于其死亡时被认为具有的身份，并不被禁止。因此，即使某人以奴隶身份死亡，五年之后仍可证明其死亡时其实是自由人。〔原文时间表达待核：*Ante quinquennium defuncto*。〕

<!-- source-p 1389 -->
<a id="40.15.4"></a>**40.15.4**

<!-- source-p 1390 -->
卡利斯特拉图斯《论国库法》第一卷。

<!-- source-p 1391 -->
最先以敕令禁止在任何人死亡五年后再审查其身份的，是神圣的涅尔瓦皇帝。神圣的克劳狄乌斯皇帝也曾复函克劳狄乌斯：如果在金钱事项的审查中，看来会对身份问题造成先决影响，就应停止该项审查。
