<!-- source-p 1248 -->
<a id="40.12.23"></a>**40.12.23**

<!-- source-p 1249 -->
保罗《告示评注》第五十卷。

<!-- source-p 1250 -->
<a id="40.12.23.pr."></a>**序言**　如果我把一个自由人的用益权出售给你并让与给你，昆图斯·穆基乌斯说，此人会成为奴隶；但只有在我善意出售的情况下，其所有权才会归我，否则此人将成为无主之人。

<!-- source-p 1251 -->
<a id="40.12.23.1"></a>**1**　总之应知，凡关于因被出售而不得主张自由身份的奴隶所作的论述，也可适用于受赠者、被作为嫁资交付者，以及听任自己被质押的人。

<!-- source-p 1252 -->
<a id="40.12.23.2"></a>**2**　若母亲与儿子就自由身份诉讼，应合并二人的案件，或者延缓儿子的案件，直至母亲的身份得到确定；神圣的哈德良皇帝也曾如此裁决。因为曾有母亲在一名法官面前诉讼，而儿子在另一名法官面前诉讼；奥古斯都说，应先确定母亲的身份，然后再审理儿子的案件。

<!-- source-p 1253 -->
<a id="40.12.24"></a>**40.12.24**

<!-- source-p 1254 -->
保罗《告示评注》第五十一卷。

<!-- source-p 1255 -->
<a id="40.12.24.pr."></a>**序言**　自由身份诉讼程序一经确定，争讼之人即被视同自由人；因此，即使面对自称为主人的人，也不得拒绝其提起任何他意欲主张的诉讼。倘若某些诉权会因期间经过或死亡而消灭，怎么办？所以，为何不允许他通过诉讼系属使这些权利获得保障？

<!-- source-p 1256 -->
<a id="40.12.24.1"></a>**1**　塞尔维乌斯甚至说，对于一年期诉讼，其期间应从自由身份诉讼程序确定之时起算。

<!-- source-p 1257 -->
<a id="40.12.24.2"></a>**2**　但若他想对其他人提起诉讼，就不应再查问自由身份诉讼程序是否已经确定，以免有人想到这样一种办法：安排某人提出身份争议，暂时排除其诉讼请求。无论如何，他的诉讼究竟有用还是落空，取决于自由身份诉讼的裁判结果。

<!-- source-p 1258 -->
<a id="40.12.24.3"></a>**3**　但如果主人提起诉讼，是否应强令该争讼之人应诉，仍有疑问。多数人认为，若主人提起对人诉讼，争讼之人应当应诉并使争讼程序，但审理应予暂缓，直至其自由身份得到裁判；这样既不构成对其自由身份的先决裁判，也不意味着他依主人的意愿而处于自由身份。因为自由身份诉讼程序确定后，他暂时被视为自由人；既然他可以提起诉讼，别人也可以对他提起诉讼。至于原诉最终是否有用，抑或若裁判其不享有自由身份便归于无效，则取决于裁判结果。

<!-- source-p 1259 -->
<a id="40.12.24.4"></a>**4**　若主张自由身份之人被他人控告盗窃或非法损害，梅拉说，他暂时应提供出庭担保，以免自由身份尚有疑问者反而处于比身份确定者更有利的地位；但审理仍应暂缓，以免对自由身份作出先决判断。同样，若有人已对该人的占有人提起盗窃诉讼，随后该占有人所代表之人主张自由身份，也应暂缓审理；如此，若裁判其为自由人，诉讼便转而针对其本人；若已作出判处罚决，则应转而对其本人授予判决之诉。

<!-- source-p 1260 -->
<a id="40.12.25"></a>**40.12.25**

<!-- source-p 1261 -->
盖尤斯《城市裁判官告示评注·自由身份诉讼题》。

<!-- source-p 1262 -->
<a id="40.12.25.pr."></a>**序言**　若有人在其自由身份诉讼中获遗赠选择权，则凡称依据遗嘱留给他的财产，关于选择权的事项也可作同样处理。

<!-- source-p 1263 -->
<a id="40.12.25.1"></a>**1**　有时可以重新提出自由身份请求，例如，有人称自己在第一次诉讼中败诉，是因为当时遗嘱授予的自由尚未归其取得，而他现在主张该自由已经归其取得。

<!-- source-p 1264 -->
<a id="40.12.25.2"></a>**2**　虽然通常说自由身份诉讼程序确定后，身份存在争议之人即被视同自由人，但如果他实际上是奴隶，那么，无论他获交付什么，或接受什么要式口约，所有权人仍会像其自由身份未受争议时那样取得利益。至于占有，我们还须考察：自由身份诉讼程序确定后，主人便不再占有此人；但较妥当的意见是，主人仍可取得占有利益，尽管此人并非由主人占有。既然我们认为甚至可以通过逃亡奴隶取得占有，那么通过这个身份受审之人取得占有，又有什么奇怪？

<!-- source-p 1265 -->
<a id="40.12.26"></a>**40.12.26**

<!-- source-p 1266 -->
盖尤斯《行省告示评注》第二十卷。

<!-- source-p 1267 -->
若有人主张某人从自由身份应被置于奴隶身份，并为保全追夺担保所涉诉讼而提出该主张，不得因此对其提起侮辱之诉。

<!-- source-p 1268 -->
<a id="40.12.27"></a>**40.12.27**

<!-- source-p 1269 -->
乌尔比安《执政官职务论》第二卷。

<!-- source-p 1270 -->
<a id="40.12.27.pr."></a>**序言**　神圣的两位皇帝曾致书普罗库卢斯和穆纳提乌斯：“罗穆卢斯的身份正受审查，且他尚未成年；其母瓦里娅·赫多涅坚持要求，监护人瓦里乌斯·赫耳墨斯也表示同意。是否有必要为其利益将案件延至其达到青春期时审理，请你们基于对相关人员诚信状况的判断，酌情决定何者最有利于该未成年人。”

<!-- source-p 1271 -->
<a id="40.12.27.1"></a>**1**　若对某人提出身份争议之人缺席审理，则主张自由身份之人的处境，与尚未遭遇该身份争议时相同。诚然，他因此获益之处，仅在于提出身份争议之人丧失其请求；此事不会使本非自由出生者成为自由出生者，因为对方缺席通常不会赋予任何人自由出生者身份。我认为，法官若遵循以下做法，便处理得当且有序：提出奴隶身份主张之人缺席时，应让对方选择，是终止审理，还是在听取案情后作出裁判。若选择审理，法官就应裁判此人不应被视为那个人的奴隶。这不会造成任何陷阱，因为裁判并未宣布其为自由出生者，而只是认定其不应被视为奴隶。反之，若此人主张自己从奴隶身份恢复为自由出生者，则法官最好终止审理，以免在无人对抗的情况下裁判其为自由出生者；除非重大理由足以支持作出这一裁判，且已有明确证据支持自由身份，方可如此处理；哈德良皇帝的复函也载有此规则。

<!-- source-p 1272 -->
<a id="40.12.27.2"></a>**2**　反之，若主张自由身份之人缺席，而提出相反主张的人到场，则较妥当的做法是继续审理并作出裁判：若事实明确证明其不享有自由身份，即应如此裁判。不过，缺席者也可能胜诉，因为裁判也可以作出有利于自由身份的认定。

<!-- source-p 1273 -->
<a id="40.12.28"></a>**40.12.28**

<!-- source-p 1274 -->
庞波尼《昆图斯·穆基乌斯评注》第十二卷。

<!-- source-p 1275 -->
奴隶若因主人不知道自己是其奴隶而处于自由身份，不得视为基于主人意愿而处于自由身份；此说正确。只有依主人意愿取得自由身份占有的人，才属于基于主人意愿而处于自由身份。

<!-- source-p 1276 -->
<a id="40.12.29"></a>**40.12.29**

<!-- source-p 1277 -->
阿里乌斯·梅南德《军事法论》第一卷。

<!-- source-p 1278 -->
<a id="40.12.29.pr."></a>**序言**　某人在自由身份诉讼中尚未获判决便从军服役，应与其他奴隶处于相同地位；尽管在某些情形下他被视为自由人，也不能因此免除这一后果。即使后来证明他是自由人，他也会被开除军籍，即解除服役并逐出营地；尤其是对其提起诉讼、主张他从奴隶身份应为自由人，或他并非在没有恶意欺诈的情况下处于自由身份之人。反之，若有人以诬告方式主张他应为奴隶，他仍将留在军中。

<!-- source-p 1279 -->
<a id="40.12.29.1"></a>**1**　若某人被裁判为自由出生者并已从军服役，而该裁判在五年内经复审撤销，则应将他交还新的主人。

<!-- source-p 1280 -->
<a id="40.12.30"></a>**40.12.30**

<!-- source-p 1281 -->
尤利安《摘自米尼基乌斯》第五卷。

<!-- source-p 1282 -->
若两人分别起诉，主张某人一半应为奴隶，而在一案中判其自由、在另一案中判其为奴，最合宜的做法是迫使两位法官继续审理，直至达成一致。若无法做到，萨宾认为，应由胜诉者带走该奴隶；卡西乌斯与我也持此见。但认为此人一半被带走为奴、另一半又受到自由身份保护，显然荒谬。更为妥当的是，基于有利于自由的原则，认定此人为自由人，但令其依善良公正之人的裁量，向胜诉者支付与其价额相应的一部分。
