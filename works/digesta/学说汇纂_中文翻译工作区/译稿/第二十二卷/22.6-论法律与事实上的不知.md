## 22.6.0　论法律与事实上的不知（*De iuris et facti ignorantia*）

### <a id="22.6.1"></a>22.6.1　保罗《评告示》第四十四卷

<a id="22.6.1.pr."></a>

**序言（pr.）** 不知既可能是不知事实，也可能是不知法律。

<a id="22.6.1.1"></a>

**1.** 例如，若某人不知道向其开放遗产占有的被继承人已经死亡，申请遗产占有的期间便不会开始计算。但若他知道自己的亲属已经死亡，却不知道自己因亲属关系而可请求遗产占有；或者知道自己在遗嘱中被指定为继承人，却不知道裁判官允诺向遗嘱指定继承人给予遗产占有，则期间仍会开始计算，因为他是对法律发生错误。被继承人的同父兄弟误以为母亲的继承顺位优先时，也应作同样处理。

<a id="22.6.1.2"></a>

**2.** 若某人不知道自己属于被继承人的亲属，有时是对法律发生错误，有时是对事实发生错误。若他知道自己是自由人，也知道自己的出生来源，只是不知道亲属关系法赋予自己的权利，那么他是对法律发生错误。相反，若某人（例如被遗弃后收养的人）不知道自己的父母是谁，或许还为某人服役，并误以为自己是奴隶，那么他主要是对事实而非法律发生错误。

<a id="22.6.1.3"></a>

**3.** 同样，若某人知道遗产占有权已归他人，却不知道该他人的申请期间已经届满，是对事实发生错误；他误以为该人已经取得遗产占有时，也一样。但若他知道对方未曾申请且申请期间已经届满，却不知道自己可依继承顺位取得遗产占有，则该期间仍会开始计算，因为他是对法律发生错误。

<a id="22.6.1.4"></a>

**4.** 若某人被指定为全部遗产的继承人，却认为必须等遗嘱书开启后才能请求遗产占有，也应作同样处理；但若他不知道遗嘱书存在，则是对事实发生错误。

### <a id="22.6.2"></a>22.6.2　涅拉提乌斯《札记》第五卷

在任何情形下，对法律发生错误都不应与对事实的无知同等对待：法律既能够也应当是确定的；而事实的解释却往往会使最审慎的人也发生错误。

### <a id="22.6.3"></a>22.6.3　庞波尼《评萨宾》第三卷

<a id="22.6.3.pr."></a>

**序言（pr.）** 一个人不知道他人的事由或事实，与他不知道自己的法律权利，大不相同。

<a id="22.6.3.1"></a>

**1.** 卡西乌斯记载，萨宾努斯认为，“无知”一词不应包括因本人怠惰或过度自满而造成的不知。

### <a id="22.6.4"></a>22.6.4　庞波尼《评萨宾》第十三卷

在取得时效中，不知法律被认为不能使人受益；不知事实则确定可以使人受益。

### <a id="22.6.5"></a>22.6.5　克莱门提乌《论尤利亚与帕皮亚法》第二卷

认为他人的知情会损害某人，或他人的不知会使另一人受益，似乎都是极不公平的。

### <a id="22.6.6"></a>22.6.6　乌尔比安《论尤利亚与帕皮亚法》第十八卷

既不应容忍某人对事实漠不关心、毫不知情，也不应要求其进行过分细致的调查。知情应作如下判断：既不能把严重疏忽或过分自满视为已尽注意，也不要求告密式的好奇探查。

### <a id="22.6.7"></a>22.6.7　帕比尼安《疑问集》第十九卷

不知法律不能使意图取得权利的人受益；但对于请求自己所有之物的人，不知法律也不使其受损。

### <a id="22.6.8"></a>22.6.8　帕比尼安《定义集》第一卷

事实错误即使对男性，在遭受损失或取得利益时也不造成不利；法律错误则即使对女性，在取得利益时也不产生利益。除此之外，法律错误在任何人因而失去自己的财物时，都不使其受损。

### <a id="22.6.9"></a>22.6.9　保罗《论法律与事实上的不知》单卷

<a id="22.6.9.pr."></a>

**序言（pr.）** 一般规则是：不知法律会使本人受损；不知事实则不会使本人受损。现在来看这一规则适用于哪些情形。首先，未满二十五岁的人可以不知法律；妇女在某些事项上也因性别上的弱势而享有此种宽宥。因此，若某人并无过错，只是不知法律，就不会受到损害。基于这一理由，若未满二十五岁的家子将钱借给另一家子，应给予其救济，使其不被视为向家子提供了借款。

<a id="22.6.9.1"></a>

**1.** 若作为军人的家子被同袍指定为继承人，却不知道依皇帝敕令，自己即使未获家父同意也可接受遗产，那么他可以主张不知法律；因此，为他接受遗产的期间开始计算。

<a id="22.6.9.2"></a>

**2.** 但只有在不能指责某人严重疏忽时，对事实的无知才不会使其受损。否则，若全城的人都知道某件事，唯独他不知道呢？拉贝奥正确地界定说，知情既不应以最为好事的人的标准判断，也不应以最为疏忽的人的标准判断，而应以能够通过勤勉调查知悉该事的人为准。

<a id="22.6.9.3"></a>

**3.** 拉贝奥认为，不知法律不能使人受益，应如此理解：若某人有机会咨询法学家，或本人具备相应学识，以致很容易知悉法律，那么不知法律就会使其受损；但这种情形应很少适用。

<a id="22.6.9.4"></a>

**4.** 某人不知道出卖人是标的物所有人，此事取决于物本身的状况，而非其内心的认识。因此，即使他以为自己并非从所有人处购买，只要所有人将该物交付给他，他就取得所有权。

<a id="22.6.9.5"></a>

**5.** 神圣的庇护皇帝曾以复函指出，某人若因不知法律而未援用《法尔基第亚法》，就应因此受损。但塞维鲁与安敦尼两位皇帝也曾作出如下复函：“以信托遗赠名义给付了本不应给付之物，若并非因错误而给付，就不得请求返还。因此，噶尔吉利安努斯的继承人根据其遗嘱，向基尔塔共同体支付了遗赠用于建造引水渠的款项；他们不仅没有要求提供通常所需的担保，以便在市镇共同体收受的数额超过《法尔基第亚法》所允许数额时返还超出部分，而且还约定该款不得用于其他用途，并且明知而允许该款用于建造引水渠；如今，他们却徒劳地请求基尔塔共同体返还款项，声称自己给付超过了应付数额。这两种做法都不公平：既不应追回用于建造引水渠的款项，也不应要求共同体从自己的财产中支出资金，用于一项完全彰显他人慷慨的工程。若他们认为，自己因不熟悉法律、未能援用《法尔基第亚法》的利益，便可以请求返还该款，那么他们应当知道：对事实的无知可以使人受益，对法律的无知则不能；法律不救济愚昧之人，只救济发生错误之人。”

<a id="22.6.9.6"></a>

**6.** 尽管这封复函提到市镇共同体，但同一规则适用于任何人。也不能认为，只有以建造引水渠为目的而遗赠款项的情形才不得请求返还。因为复函开头所述规则是一般性的：若某项本不应给付的信托遗赠并非因错误而支付，就不得请求返还。复函后面的规则同样是一般性的：因不知法律而未能援用《法尔基第亚法》利益的人，不得请求返还。依此，即便信托遗赠所留且已支付的款项并非专为完成某项事务而遗赠，即使款项尚未花用、仍在收款人手中，也不得请求返还。

### <a id="22.6.10"></a>22.6.10　帕比尼安《答复集》第六卷

未适婚人未经监护人协助而独自行事，应视为既无行为能力，也无知情能力。
