# D.22.5 论证人（*De testibus*）

<!-- source-p 001; 原文导航锚点 5、题名锚点 22.5 -->
<a id="5"></a><a id="22.5"></a>**22.5.0　论证人（*De testibus*）**

<!-- source-p 002 -->
<a id="22.5.1"></a>**22.5.1**

<!-- source-p 003 -->
**奥勒留·阿卡狄乌斯·卡里修斯：《论证人》单卷。**

<!-- source-p 004 -->
<a id="22.5.1.pr."></a>**序言。**证言的运用既频繁又必要，因此尤其应当要求那些信用可靠的人作证。

<!-- source-p 005 -->
<a id="22.5.1.1"></a>**1.**证人不仅可以用于刑事案件，也可以用于金钱争讼，只要案件需要；但证人不得属于法律禁止作证者，也不得属于依法免于作证者。

<!-- source-p 006 -->
<a id="22.5.1.2"></a>**2.**尽管某些法律规定了可采用证人的最高人数，皇帝敕令仍将这项自由限制在足够的证人数额内，使法官得以斟酌，并仅准许传唤其认为必要的证人；不得滥用权力，传唤过多证人以骚扰他人。

<!-- source-p 007 -->
<a id="22.5.2"></a>**22.5.2**

<!-- source-p 008 -->
**莫德斯蒂努斯：《规则集》第八卷。**

<!-- source-p 009 -->
审查证言时，应考察证人的身份地位、信用、品行和庄重程度。因此，对于其证言信用摇摆不定的证人，不应听取其证言。

<!-- source-p 010 -->
<a id="22.5.3"></a>**22.5.3**

<!-- source-p 011 -->
**卡利斯特拉图斯：《审判程序》第四卷。**

<!-- source-p 012 -->
<a id="22.5.3.pr."></a>**序言。**应当仔细审查证人的可信性。因此，首先应查明每名证人的身份情况：其属于市议员阶层，还是平民；其生活是否体面且无可指摘，抑或声名不佳、招人非议；其家境富裕还是贫困，以判断其是否容易为了获利而作出某种行为；其是否为作证所针对之人的敌人，或为其所支持之人的朋友。如果证言无可疑之处，无论是因证人本人品行端正，还是因作证原因并非牟利、求情或出于敌意，都应予以采纳。

<!-- source-p 013 -->
<a id="22.5.3.1"></a>**1.**神圣的哈德良皇帝曾致书奇里乞亚行省使节维比乌斯·瓦鲁斯，答复说，判断应当在多大程度上信赖证人，主要是法官的职权；法官能够了解证人的身份地位与名声，也能判断他们是否如实作证，是否带着同一套预先准备好的说辞前来，还是对法官所提问题作出了临场而可信的回答。该信相关文字如下：“你更能判断应当在多大程度上信赖证人，因为你知道他们的身份地位和声誉；你也能判断他们是否看起来是在如实陈述，究竟是带着同一套预先准备好的说辞前来，还是针对你所询问的问题临场作出了可信的回答。”

<!-- source-p 014 -->
<a id="22.5.3.2"></a>**2.**同一位皇帝还曾就审查证人信用致书瓦莱里乌斯·维鲁斯，答复如下：“哪些证据、以何种方式足以证明各类事项，无法用任何确定方法充分界定。真相并非总能、但往往能够在没有公文档案的情况下查明。有时，证人的人数可以证实所调查事项的可信性；有时，则是证人的身份地位与权威；有时，仿佛是公众一致的传闻。我能向你作的概括答复只有这一点：审理时不应立即拘泥于某一种证据形式，而应由你依自己的判断衡量，哪些事项可以相信，哪些事项在你看来尚未得到充分证明。”

<!-- source-p 015 -->
<a id="22.5.3.3"></a>**3.**神圣的哈德良皇帝还曾答复马其顿行省总督尤尼乌斯·鲁菲努斯说，他信赖证人本人，而非证言。该信相关文字如下：“亚历山大曾在我面前控告阿佩尔；他既不证明自己的指控，也不传唤证人，而是想使用书面证言；我这里不接受这种做法，因为我通常亲自询问证人。因此，我将他交还行省长官审理，由后者审查证人的信用；如果他未能证明自己所主张的事项，就应将其流放。”

<!-- source-p 016 -->
<a id="22.5.3.4"></a>**4.**同一位皇帝还曾以如下文字答复加比尼乌斯·马克西穆斯：“当庭到场的证人，与通常宣读的书面证言，其证明力并不相同。因此，你应当斟酌：如果希望他们留在当地，就应当支付他们的费用。”

<!-- source-p 017 -->
<a id="22.5.3.5"></a>**5.**《尤利亚暴力法》规定，下列人员不得依据该法为被告作证：由被告或其父母解放的被释奴；未达到法定成年年龄者；被公审判决定罪且未获恢复原状者；被关押或处于公家拘禁中的人；自愿受雇与野兽搏斗的人；公开卖淫的妇女或曾公开卖淫的妇女；以及被判定或证明曾为作证或拒绝作证而收取钱财的人。有些人因身份关系而应受尊重，有些人因判断容易动摇，还有些人因品行污点及恶名，都不得被接纳为可信证人。

<!-- source-p 018 -->
<a id="22.5.3.6"></a>**6.**不得轻率地要求证人远道而来；更不应为了作证而将军人从军旗或军务中调离。哈德良皇帝曾就此作出答复。两位神圣皇帝也曾答复说：“关于传唤证人，应由审理案件的法官审查其所在行省通常采用何种做法。”因此，如果查明该行省常有人为作证而被传唤至另一城市，那么，法官在审理案件时发现哪些人确属必要证人，就不应再对传唤他们有所疑虑。

<!-- source-p 019 -->
<a id="22.5.4"></a>**22.5.4**

<!-- source-p 020 -->
**保罗：《尤利亚法与帕皮亚法评注》第二卷。**

<!-- source-p 021 -->
《尤利亚公审法》规定，不得违背证人意愿，要求其在诉讼中针对下列亲属作证：岳父与女婿、继父与继子女、表亲及表亲的子女，以及比这些亲属关系更近一等的亲属；也不得要求其针对本人、子女、父母、丈夫或妻子的被释奴作证，亦不得要求其针对保护人或女保护人作证。并且，不得强迫保护人或女保护人针对其被释奴作证，也不得强迫被释奴针对其保护人作证。

<!-- source-p 022 -->
<a id="22.5.5"></a>**22.5.5**

<!-- source-p 023 -->
**盖尤斯：《尤利亚法与帕皮亚法评注》第四卷。**

<!-- source-p 024 -->
对于法律规定岳父或女婿不得被迫作证的情形，已有意见认为，“女婿”一词也包括女儿的未婚夫；同样，“岳父”一词也包括未婚妻的父亲。

<!-- source-p 025 -->
<a id="22.5.6"></a>**22.5.6**

<!-- source-p 026 -->
**利基尼乌斯：《规则集》第二卷。**

<!-- source-p 027 -->
那些可以被命令充当证人的人，似乎并不适合作证。

<!-- source-p 028 -->
<a id="22.5.7"></a>**22.5.7**

<!-- source-p 029 -->
**莫德斯蒂努斯：《规则集》第三卷。**

<!-- source-p 030 -->
只有在没有其他证据可以查明真相时，才应相信奴隶的答复。

<!-- source-p 031 -->
<a id="22.5.8"></a>**22.5.8**

<!-- source-p 032 -->
**斯凯沃拉：《规则集》第四卷。**

<!-- source-p 033 -->
老人、身体虚弱者、军人、因公随同长官外出者，以及依法不能前来者，不得在违背意愿时被强迫作证。

<!-- source-p 034 -->
<a id="22.5.9"></a>**22.5.9**

<!-- source-p 035 -->
**保罗：《评萨宾》第一卷。**

<!-- source-p 036 -->
父亲不得作为适格证人为儿子作证，儿子也不得作为适格证人为父亲作证。

<!-- source-p 037 -->
<a id="22.5.10"></a>**22.5.10**

<!-- source-p 038 -->
**庞波尼乌斯：《评萨宾》第一卷。**

<!-- source-p 039 -->
任何人都不被视为其本人事务中的适格证人。

<!-- source-p 040 -->
<a id="22.5.11"></a>**22.5.11**

<!-- source-p 041 -->
**庞波尼乌斯：《评萨宾》第三十三卷。**

<!-- source-p 042 -->
即使没有人要求某人作证，为证明某项事实确曾发生，该人也可被视为证人。

<!-- source-p 043 -->
<a id="22.5.12"></a>**22.5.12**

<!-- source-p 044 -->
**乌尔比安：《告示评注》第三十七卷。**

<!-- source-p 045 -->
法律未规定证人人数时，两名证人也足够；因为复数表达以两人为限即可满足。

<!-- source-p 046 -->
<a id="22.5.13"></a>**22.5.13**

<!-- source-p 047 -->
**帕皮尼安：《论通奸》第一卷。**

<!-- source-p 048 -->
我知道曾有人提出疑问：在公审中，因诬告而被定罪者能否在公审中作证？《雷米亚法》并未禁止他们作证，《尤利亚暴力法》、《勒索贿赂法》和《侵吞公款法》也未禁止此等人作证。然而，法律虽未提及之事，法官仍应本着职责予以审查；法官有责任衡量一个品行端正之人所作证言的可信性。

<!-- source-p 049 -->
<a id="22.5.14"></a>**22.5.14**

<!-- source-p 050 -->
**帕皮尼安：《论通奸》单卷。**

<!-- source-p 051 -->
我确实知道曾有人讨论：因通奸被定罪者能否被用作订立遗嘱的证人；当然，应当正当地剥夺其担任证人的资格。因此我认为，凡有此类证人参与订立的遗嘱，依市民法无效；依承接市民法的裁判官法也无效，以致既不能据此接受继承，也不能据此授予遗产占有。

<!-- source-p 052 -->
<a id="22.5.15"></a>**22.5.15**

<!-- source-p 053 -->
**保罗：《箴言集》第三卷。**

<!-- source-p 054 -->
<a id="22.5.15.pr."></a>**序言。**因勒索贿赂罪被定罪者，既不得作为遗嘱证人，也不得被用作证人。

<!-- source-p 055 -->
<a id="22.5.15.1"></a>**1.**两性特征中何者占优势，决定两性人能否被用作订立遗嘱的证人。

<!-- source-p 056 -->
<a id="22.5.16"></a>**22.5.16**

<!-- source-p 057 -->
**保罗：《箴言集》第五卷。**

<!-- source-p 058 -->
凡作出虚假或前后矛盾的证言，或背叛双方当事人者，均由法官依法惩处。

<!-- source-p 059 -->
<a id="22.5.17"></a>**22.5.17**

<!-- source-p 060 -->
**乌尔比安：《规则集》单卷。**

<!-- source-p 061 -->
父亲与受其父权支配的儿子可以共同担任证人；同样，受同一父亲父权支配的两名兄弟，也可以在同一遗嘱或同一法律事务中共同作证。多人来自同一家庭而为他人的事务作证，并无不妥。

<!-- source-p 062 -->
<a id="22.5.18"></a>**22.5.18**

<!-- source-p 063 -->
**保罗：《论通奸》第二卷。**

<!-- source-p 064 -->
从《尤利亚通奸法》禁止被定罪的妇女作证这一规定，可以推知妇女也享有在审判中作证的权利。

<!-- source-p 065 -->
<a id="22.5.19"></a>**22.5.19**

<!-- source-p 066 -->
**乌尔比安：《论总督职务》第八卷。**

<!-- source-p 067 -->
<a id="22.5.19.pr."></a>**序言。**公税承包人不必违背意愿作证；因非为逃避作证而离开的人，以及承包向军队提供物资之人，也不必违背意愿作证。

<!-- source-p 068 -->
<a id="22.5.19.1"></a>**1.**不得向未成年人发出作证通知。

<!-- source-p 069 -->
<a id="22.5.20"></a>**22.5.20**

<!-- source-p 070 -->
**维诺尼乌斯：《公审》第二卷。**

<!-- source-p 071 -->
控告人不得传唤下列人员作证：在公审中将成为被告的人，或者未满二十岁的人。

<!-- source-p 072 -->
<a id="22.5.21"></a>**22.5.21**

<!-- source-p 073 -->
**奥勒留·阿卡狄乌斯·卡里修斯：《论证人》单卷。**

<!-- source-p 074 -->
<a id="22.5.21.pr."></a>**序言。**因创作诽谤诗而被定罪者，丧失作证资格。

<!-- source-p 075 -->
<a id="22.5.21.1"></a>**1.**这一点也毫无疑问：只要案件需要，不仅私人，即使官员在场，也必须作证。元老院还曾决议，裁判官在通奸案件的审理中应当作证。

<!-- source-p 076 -->
<a id="22.5.21.2"></a>**2.**如果案件情形迫使我们接纳竞技场人员或类似身份者作证，那么，未经刑讯，不应相信其证言。

<!-- source-p 077 -->
<a id="22.5.21.3"></a>**3.**如果所有证人均具有同等的正直品行与声誉，且案件性质和法官的判断也与他们的证言相符，就应采信全部证言。如果其中有些证人作出不同陈述，即使其人数较少，也应采信符合案件性质且不受敌意或偏袒之嫌的证言。法官应当依据论据、证言以及其认定更切合案件、更接近真相的材料，确认自己的内心判断；因为不应看证人的人数，而应看证言是否真实可信，以及哪些证言更能彰显真相。

<!-- source-p 078 -->
<a id="22.5.22"></a>**22.5.22**

<!-- source-p 079 -->
**维诺尼乌斯：《论总督职务》第二卷。**

<!-- source-p 080 -->
各地官员应注意向希望作出证明的人提供协助，安排官员本人及其他证人或签署人到场，使事务能够更容易办理，并使证据得以保全。

<!-- source-p 081 -->
<a id="22.5.23"></a>**22.5.23**

<!-- source-p 082 -->
**维诺尼乌斯：《公审》第一卷。**

<!-- source-p 083 -->
不得传唤曾经在针对该被告的诉讼中作证的人，再次作为证人出庭。

<!-- source-p 084 -->
<a id="22.5.24"></a>**22.5.24**

<!-- source-p 085 -->
**保罗：《箴言集》第五卷。**

<!-- source-p 086 -->
不允许询问由控告人从自己家中带来的证人。

<!-- source-p 087 -->
<a id="22.5.25"></a>**22.5.25**

<!-- source-p 088 -->
**奥勒留·阿卡狄乌斯·卡里修斯：《论证人》单卷。**

<!-- source-p 089 -->
总督的指令规定，辩护人不得在其曾经提供辩护的案件中作证；同样的规则也应适用于诉讼事务的执行人。
