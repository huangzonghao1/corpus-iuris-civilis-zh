## 22.2.0　论航海借贷（*De nautico faenore*）

### <a id="22.2.1"></a>22.2.1　莫德斯蒂努《学说汇纂》第十卷

所谓航海借贷，是指借出的金钱被运往海上；但若在同一地点将其耗用，就不属于航海借贷。不过，还须考察以该笔钱购得的货物是否也属于此种情形。对此，关键在于货物航行时是否也由债权人承担风险；若是，则该笔钱即成为航海借贷。

### <a id="22.2.2"></a>22.2.2　庞波尼《论普劳提乌斯》第三卷

拉贝奥说，若不存在可以代表承诺人一方接受航海借贷催告的人，就应当以正式声明记载这一事实，使该声明能够代替催告。

### <a id="22.2.3"></a>22.2.3　莫德斯蒂努《规则》第四卷

航海借贷中，债权人自约定船舶启航之日起承担风险。

### <a id="22.2.4"></a>22.2.4　帕比尼安《答复》第三卷

<a id="22.2.4.pr."></a>

**序言（pr.）** 航海借贷在一开始就未由债权人承担风险，或者在约定日期届至且条件成就后，债权人不再承担风险，两者并无区别。因此，在这两种情况下，利息均不得超过法定利率；但前一种情形始终如此，后一种情形则自风险消灭后起如此。质押或抵押也不为超过法定利率的利息提供担保。

<a id="22.2.4.1"></a>

**1.** 为航海借贷而约定奴隶提供劳务，并就其每日劳务另行订立要式承诺的，按照月息百分之一的上限计算，所欠金额不得超过双倍。若在风险期间届满后另行订立利息要式承诺，则其中不足法定利息的部分，由另一项关于劳务的要式承诺补足。

### <a id="22.2.5"></a>22.2.5　斯凯沃拉《答复》第六卷

<a id="22.2.5.pr."></a>

**序言（pr.）** 即使所约定的条件（哪怕带有惩罚性质）未成就，你仍可收回已给付之物，并在金钱之外另取得某项利益，只要该交易不属于赌博性质，额外所得也可构成承担风险的对价。例如，常见的附条件给付：“若你不释放奴隶”“若你不做那件事”“若我未能康复”等。你也不会怀疑以下情形属于此类：我给渔夫一大笔钱购置渔具，约定他若捕到鱼就偿还；我给运动员钱供其维持生活和训练，约定他若获胜就偿还。

<a id="22.2.5.1"></a>

**1.** 在上述所有情形中，即使没有订立要式口约，约定也能增加债务的拘束力。

### <a id="22.2.6"></a>22.2.6　保罗《疑问集》第二十五卷

某放贷人以海上利息出借金钱，并以船上某些货物作为质物；又约定，若这些货物不足以清偿全部债务，则以装载在其他船舶、并已分别为其债权人设质的其他货物中所剩余的部分作为质物。主船沉没后，是否应由债权人承担损失——因为若船舶在约定期限内未灭失，债务原可全部清偿——还是可以请求以其他船舶货物的剩余部分清偿？我答复如下：通常，质物价值减少的损失由债务人承担，而非债权人承担；但若航海借贷约定，只有船舶在规定期限内安全到达，债权人才有权请求偿还，那么条件未成就，债权本身的拘束力似乎已经消灭。因此，质物的追索权也随之消灭，即使其中一些质物并未灭失。若船舶在约定期限内沉没，就应认为要式承诺的条件未成就；因此，再讨论追索其他船舶上的质物便没有根据。那么，债权人何时才能追索那些质物？只有在债务条件已经成就，而质物后来因其他原因灭失、以低价出售，或者船舶是在约定风险期间届满后才沉没时，方可追索。

### <a id="22.2.7"></a>22.2.7　保罗《评告示》第三卷

在某些契约中，即使没有另行订立要式口约，也应支付利息。例如，我若交付十个单位的航海借贷金，约定船舶安全到达时返还本金并支付确定利息，就应认为我可以请求返还本金及利息。

### <a id="22.2.8"></a>22.2.8　乌尔比安《评告示》第七十七卷

塞尔维乌斯说，若未能在指定期限内收取航海借贷金，是债权人一方造成的，就不能请求支付该项航海借贷的罚金。

### <a id="22.2.9"></a>22.2.9　拉贝奥《可能论》第五卷（保罗节本）

若已按惯例约定航海借贷的罚金，即使在借款最初应偿还之日，没有任何负有该笔债务的人仍然在世，罚金仍可如同债务人有继承人一样发生。
