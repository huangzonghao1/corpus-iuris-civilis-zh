# D.22.1 上半：论利息、孳息、原因、一切附加利益及迟延


<!-- source-p 001; 原文导航锚点 1、题名锚点 22.1 -->
<a id="1"></a><a id="22.1"></a>**22.1.0. 论利息、孳息、原因、一切附加利益及迟延（*De usuris et fructibus et causis et omnibus accessionibus et mora*）**

<!-- source-p 002 -->
<a id="22.1.1"></a>**22.1.1**

<!-- source-p 003 -->
**帕比尼安：《疑难》第二卷。**

<!-- source-p 004 -->
<a id="22.1.1.pr."></a>**序言。**在诚信诉讼中，利率由法官裁量，依合同订立地的惯例确定，但不得违反法律。

<!-- source-p 005 -->
<a id="22.1.1.1"></a>**1.**合伙人若因侵占共同资金或将其挪作私用而被判承担责任，无论是否发生迟延，都应支付利息。

<!-- source-p 006 -->
<a id="22.1.1.2"></a>**2.**但诚信诉讼的法官不应命令当事人提供担保，保证被判决承担责任的一方若迟延履行判决，还须支付此后期间的利息；因为原告可以自行申请执行判决。保罗注：判决作出之后未来期间的利息，怎会属于法官职权所应处理的事项？

<!-- source-p 007 -->
<a id="22.1.1.3"></a>**3.**关于返还监护事务中的财产，出于维护未适婚人利益的考虑，已采取较宽的解释。如今无人怀疑，无论是经法官裁判，还是无须法官裁判而返还监护财产，利息都应计算至实际返还之日。当然，若监护人主动向不愿提起监护之诉的一方提出款项，并将款项封缄寄存，则自该时起不再负担利息。

<!-- source-p 008 -->
<a id="22.1.2"></a>**22.1.2**

<!-- source-p 009 -->
**帕比尼安：《疑难》第六卷。**

<!-- source-p 010 -->
通常认为，即使提起的是对人之诉，诉讼系属后仍应按该时点的状态履行；这是因为给付之物应当与请求时的状态相同。因此，诉讼系属后取得的孳息及出生的子女也应返还。

<!-- source-p 011 -->
<a id="22.1.3"></a>**22.1.3**

<!-- source-p 012 -->
**帕比尼安：《疑难》第二十卷。**

<!-- source-p 013 -->
<a id="22.1.3.pr."></a>**序言。**在请求履行遗嘱信托的诉讼中，若继承人在法官判决后迟延履行，马可·安东尼皇帝命令：扣除判决债务人依法享有的履行期限，遗嘱信托受益人应取得截至判决之日的收益。这一敕令应当仅在判决前未发生迟延时适用；尽管在此前没有迟延却最终诉至法官的情形并不多见，但法尔基第法所涉情形或可作为例子。反之，若继承人在诉至法官之前已经迟延履行，他自迟延时起就负有交付孳息的义务；既然他又经判决败诉，究竟有什么理由使他在法定履行期限内免于交付孳息？这段期限只能推迟判决的履行，不应使其获利。

<!-- source-p 014 -->
<a id="22.1.3.1"></a>**1.**即使在不属自由裁量或诚信诉讼的案件中，争讼程序确定后也应向原告返还该物，返还状态应计算至宣告判决之日；判决确定后至履行期间，则不计孳息。

<!-- source-p 015 -->
<a id="22.1.3.2"></a>**2.**有时，遗产孳息或金钱利息虽未被明确遗赠，仍可能应予给付。例如，某人请求继承人在其死后将其财产中剩余的一切返还给提提乌斯：如同为诚信处分而减少的财产，只要与其他财产按比例减少，就不计入遗嘱信托的减损；同样，孳息中剩余的部分也应依遗嘱人的意思返还。

<!-- source-p 016 -->
<a id="22.1.3.3"></a>**3.**波利狄乌斯由其女性亲属指定为继承人，并受嘱在一名女孩达到一定年龄时，将自己从该女性财产中取得的一切返还给她的女儿。遗嘱中还写明，母亲之所以这样安排，是不愿把财产交给女儿的监护人，而更愿意交由亲属保管；她并命波利狄乌斯保留一处土地。我曾向禁卫军长官建议，波利狄乌斯本着诚信从死者财产中取得的孳息应予返还；无论是因为遗嘱人仅将该土地预先遗赠给他，还是因为母亲宁愿采用遗嘱信托救济，而不愿将财产置于监护制度的不稳定之中，结论均然。

<!-- source-p 017 -->
<a id="22.1.3.4"></a>**4.**遗嘱信托遗赠金器或银器后发生迟延时，是否应评定利息，常有讨论。若遗嘱人留下这些金银器物，目的在于将其变卖取得价款以履行遗嘱信托或支付扶养费，那么迟延不应免受惩罚；但若遗嘱人留下它们是为了让受益人使用，则请求利息未免有失体面，因此不应收取。

<!-- source-p 018 -->
<a id="22.1.4"></a>**22.1.4**

<!-- source-p 019 -->
**帕比尼安：《疑难》第二十七卷。**

<!-- source-p 020 -->
<a id="22.1.4.pr."></a>**序言。**如果你约定对方交付某物并移转无负担的占有，那么依照后面的“移转无负担占有”一语，理由上支持你可以通过内容不确定的要式承诺之诉，取得此后收取的孳息。至于女奴所生子女是否也可作相同回答，尚须考察。就前面的用语而言，无论它指承诺交付该物的行为，还是指通过交付而移转所有权的结果，都不包括子女。但如果买受人意图更新债务而向出卖人作出此种要式承诺，应理解为其约定的是交付行为；因为难以认为出卖人承诺承担超过其依买受之诉本来须承担的责任。不过，鉴于约定中有“移转无负担的占有”一语，也可以认为，子女亦落入内容不确定的要式承诺之诉范围；毕竟女奴交付之后出生的子女，本可成为要式承诺请求人财产的一部分。

<!-- source-p 021 -->
<a id="22.1.4.1"></a>**1.**如果买卖成立后、要式承诺订立前，女奴已生下子女，或奴隶为出卖人取得了某物，而买受人无法依据要式承诺取得这些利益，则可基于买受之诉请求；未纳入债务更新的事项，仍可依原有法律关系请求。

<!-- source-p 037 -->
<a id="22.1.9.pr."></a>**序言。**我答复：若生息借款未在确定期限内清偿，约定在法定利率之上再支付等额款项的双倍利息承诺，并非全部无效；因此，应扣除超出任何期间合理利率的部分，再依相应期间确定承诺的效力。

<!-- source-p 038 -->
<a id="22.1.9.1"></a>**1.**即使债务人未被起诉，利息要式承诺仍会触发。若承诺约定“未在到期日支付较低利息时”，即须支付法定利息，该承诺也不因此无效：这并非约定罚金，而是基于本金以正当理由约定较高利息。不过，如果债权人死亡后无人可以受领还款，则该期间的迟延显然无可归责。因此，若债权人请求此前期间的较高利息，债务人提出欺诈抗辩并非无益。

**保罗：《疑难》第二十五卷。**

<!-- source-p 044 -->
<a id="22.1.11.pr."></a>**序言。**盖乌斯·塞乌斯负责公共事务时，以通常利率贷出公共资金。惯例是，若债务人未在特定期限内支付利息，就须负担更高利息。有些债务人迟延支付利息，另一些人则支付了更多；结果，一些债务人所欠的利息，也由这些超额款项补足。有人问：依惯例以罚金名义向部分债务人多收的款项，应归塞乌斯本人，还是应归公共财产？我答复：如果盖乌斯·塞乌斯曾向债务人约定利息，则即使并非所有债权都能足额收回，也仅应将依该约定通常可以向债务人收取的利息支付给公共财产。

<!-- source-p 045 -->
<a id="22.1.11.1"></a>**1.**如果公共奴隶取得了对公共财产所负利息债务的请求权，又当如何？尽管依法利息应付给公共财产，但如果公共财产并未准备承担所有债务人的偿付风险，那么，以较高利息补足不足额的债权，仍属公平。马尔凯卢斯在监护人的情形中也记载了大致相同的规则。

<!-- source-p 046 -->
<a id="22.1.12"></a>**22.1.12**

<!-- source-p 047 -->
**保罗：《答复》第四卷。**

<!-- source-p 048 -->
塞娅向塞普提基乌斯借款。双方就利息约定：若每期利息未在约定日期支付，或未在第三个月届满前支付，塞娅即须负担较高利息；此后每一期也依相同条件处理，直至全部债务清偿。有人问，下列用语——“此后每一期，如在条件成就时未支付利息，应适用该条件”——是否意味着：即使第一项要式承诺已经触发，也不能就超出已过约定期限的那一期利息而请求更高金额？保罗答复：该承诺包含数个关于支付较高利息的条件；也就是说，应逐期考察较低利息是否在各自期限内支付。因此，可以避免后续各期利息的罚则。

<!-- source-p 049 -->
<a id="22.1.13"></a>**22.1.13**

<!-- source-p 050 -->
**斯凯沃拉：《答复》第一卷。**

<!-- source-p 051 -->
<a id="22.1.13.pr."></a>**序言。**某人承诺每年支付 *quincunces* 利息，多年来实际支付的利息低于此数；债权人的继承人请求其支付 *semisses* 利息。由于未支付较低利息并非债务人所致，我询问：欺诈抗辩或协议抗辩是否可以阻却该请求？我答复：如果在如此长的期间内，债务人并未迟延依惯例支付利息，那么，按照所述情形，可以提出该项抗辩。

<!-- source-p 052 -->
<a id="22.1.13.1"></a>**1.**有人问：在无因管理之诉或委任之诉中，若资金闲置，而本人从未将任何款项贷出，受托人是否仍应就闲置资金支付利息？他答复：如果受托人依委任人的惯例将该笔款项存放备用，则无须以利息名义支付任何款项。

<!-- source-p 056 -->
<a id="22.1.14.1"></a>**1.**遗嘱要求继承人在其死亡后返还遗产，且不保留收益。有人问：依遗嘱用语，立遗嘱人仅意在扣除收益时，继承人生前出生的奴隶女之子女是否也应返还？保罗答复：在遗嘱信托请求权届期之前出生的奴隶女之子女，不包括在该遗嘱信托之内。涅拉提乌斯在第一卷中记载了这样一项意见：某人受命返还一名妇女时，除非该妇女的子女是在其迟延履行遗嘱信托期间出生，否则不得强令其一并返还该子女。我认为，遗嘱信托的标的是奴隶女本人还是遗产，并无区别。

<!-- source-p 064 -->
<a id="22.1.17"></a>**22.1.17**

<!-- source-p 065 -->
**保罗：《论利息》单卷。**

<!-- source-p 066 -->
<a id="22.1.17.pr."></a>**序言。**某人约定每年支付 *quincunces* 利息；若某年未支付，则自借款之日起就全部本金按 *semisses* 计息。他连续数年支付利息后，相关要式承诺随即被触发。神圣的马可皇帝曾向福尔图纳图斯作如下敕复：“请向行省总督申诉；他将把你所指为不公的要式承诺，调整到正当收取的限度。”这项敕令将超出既定限度的部分加以限制。那么应如何处理？应作如下调节：此后仅自停止支付之日起累积利息。

<!-- source-p 067 -->
<a id="22.1.17.1"></a>**1.**神圣的庇护皇帝曾作如下敕复：“你请求支付过去的利息，颇不公允；长时间未曾主张，表明你当时并不认为应向债务人请求这些利息，显然是为了使自己在他眼中更受感激。”

<!-- source-p 068 -->
<a id="22.1.17.2"></a>**2.**神圣的庇护皇帝曾敕复：在秘密设立的遗嘱信托中，应剥夺继承人的一切利益，并将其交付国库。因此，继承人因利息取得的利益也应被剥夺。

<!-- source-p 069 -->
<a id="22.1.17.3"></a>**3.**神圣的庇护皇帝曾敕复：若遗嘱信托无法向没有监护人的未成年人履行，不得认为继承人发生迟延。因此，对于因公职原因离境，或因其他正当事由受阻而无法请求履行、并因此获准恢复原状的人，也不应向其支付利息。即使其愿意履行而事实上不能，又有何可归责于他？这与向未成年人提供救济、使其得以取得原本未曾取得之利益的情形，并不相同：利息并非为了使请求人获利而主张，而是对迟延履行者施加的负担。

<!-- source-p 070 -->
<a id="22.1.17.4"></a>**4.**因租赁关系被诉的人，除非双方约定迟延交付的款项也应计息，否则仅自发生迟延时起负担利息。

<!-- source-p 071 -->
<a id="22.1.17.5"></a>**5.**国库基于其自身订立的契约不支付利息，而是收取利息；例如向迟延缴款的 *foricarii* 以及纳税人收取利息。但国库承受私人之地位时，通常也会支付利息。

<!-- source-p 072 -->
<a id="22.1.17.6"></a>**6.**如果原先按低于 *semisses* 的利率支付利息的债务人转而成为国库的债务人，那么自债务转归国库后，应强令其按 *semisses* 利率支付。

<!-- source-p 073 -->
<a id="22.1.17.7"></a>**7.**众所周知，因管理城市共同体财产而被诉的人应负担利息。工程监理人若将款项留存于自己手中，也适用同一规则。但对于其交由承包人保管的款项，即使其交付时有过失，也免除其利息责任；然而，若有人证明存在欺诈，则仍应判令其支付利息。

<!-- source-p 074 -->
<a id="22.1.17.8"></a>**8.**如果遗赠设置雕像或肖像的人没有规定完成期限，总督应确定期限；继承人若未按期设置，则应向公共共同体支付利息，最高至 *tertia centesima*。

<!-- source-p 075 -->
<a id="22.1.18"></a>**22.1.18**

<!-- source-p 076 -->
**保罗：《答复》第三卷。**

<!-- source-p 077 -->
<a id="22.1.18.pr."></a>**序言。**土地被追夺时，如果当初约定出卖人应返还价款，那么追夺后也应支付利息；即使买受人在所有权诉讼开始后已将孳息返还给对方，亦同。因为期间内的损失应由买受人承担。

**尤利安：《学说汇纂》第七卷。**

<!-- source-p 103 -->
<a id="22.1.25.pr."></a>**序言。**某人明知土地与他人共有，未经共有人同意或共有人不知情而从该土地取得孳息，其取得的孳息不得超过其作为该土地所有人所占的份额。至于由其本人、共有人还是双方播种，并无区别，因为一切孳息均基于土地而取得，并非基于种子而取得。正如明知土地属于他人而占有整片土地的人，无论种子以何种方式播下，均不能取得任何部分的孳息；占有共有土地的人，也不能取得属于其共有人土地份额所对应的孳息。

<!-- source-p 104 -->
<a id="22.1.25.1"></a>**1.**我在他人土地上播种谷物；提图斯善意买下了该土地。他作为善意买受人，是否取得已经收获的孳息？我答复：从土地取得的孳息，应更接近奴隶以其劳动取得之物来理解；因为在取得孳息时，应更多考察产生孳息的土地本身之权利，而非孳息所由产生的种子。因此，从未有人怀疑：若我在自己的土地上播种你的谷物，庄稼以及收获所得都归我所有。此外，善意占有人取得孳息的权利，与土地所有人所享有的权利相同。再者，任何人播种的作物都归用益权人取得，那么，对在取得孳息方面享有更多权利的善意占有人，更应承认这一规则。用益权人须待其收取孳息后才取得孳息；善意占有人则在孳息以任何方式与土地分离时即取得孳息，正如享有缴纳地租之土地权利的人，在孳息与土地分离时即取得孳息。

<!-- source-p 105 -->
<a id="22.1.25.2"></a>**2.**善意买受人在土地上播种，但尚未收取孳息便得知该土地属于他人。有人问：其收取孳息时是否取得孳息所有权？我答复：就孳息的取得而言，该买受人应被视为善意买受人，直至土地被追夺为止。因为我善意买入的他人奴隶，也会因我的财物或其自身劳作而为我取得财物，直至该奴隶被追夺为止。

<a id="22.1.41.2"></a>**2.**盖尤斯·塞尤斯从奥卢斯·阿革里乌斯处借得一笔钱，借据写道：“我确认并已收到他的十笔借款，将于下一个约定日期连同双方约定的利息一并偿还。”有人问：能否依据该文书请求利息，以及可请求何种利息？莫德斯蒂努斯答复：如果不能确定双方约定的是何种利息，就不能请求利息。

**斯凯沃拉：《学说汇纂》第二十二卷。**

<!-- source-p 199 -->
