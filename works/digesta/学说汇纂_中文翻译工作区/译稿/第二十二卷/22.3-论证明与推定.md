## 22.3.0　论证明与推定（*De probationibus et praesumptionibus*）

### <a id="22.3.1"></a>22.3.1　帕比尼安《疑问集》第三卷

每当争议涉及某人是否具有某种出身或族属时，应由该人承担证明责任。

### <a id="22.3.2"></a>22.3.2　保罗《评告示》第六十九卷

主张者负证明责任，否认者不负证明责任。

### <a id="22.3.3"></a>22.3.3　帕比尼安《答复》第九卷

若将默示信托遗赠交付给某人，而该人在第一份及第二份遗嘱中均被指定为同一份额的继承人，或在后遗嘱中被指定为更大份额的继承人，则应由被追诉者承担证明遗嘱人改变意思的责任。因为财物所有人将秘密信托交付他人，通常正是出于信任而选择其为继承人。

### <a id="22.3.4"></a>22.3.4　保罗《答复》第六卷

他答复说，买方应证明争议中的奴隶是在买下之前逃跑的。

### <a id="22.3.5"></a>22.3.5　保罗《答复》第九卷

<a id="22.3.5.pr."></a>

**序言（pr.）** 若一方主张其对方依某一特定法律或敕令被禁止享有某项权利，则应由主张者证明这一点。

<a id="22.3.5.1"></a>

**1.** 他还答复说，若有人否认解放行为依法有效，应由该人承担证明责任。

### <a id="22.3.6"></a>22.3.6　斯凯沃拉《答复》第二卷

庇护人若要追回被释奴为损害其利益而处分的财产的一部分，必须明确证明被释奴确曾作出此种欺诈处分。

### <a id="22.3.7"></a>22.3.7　保罗《箴言集》第二卷

若无法证明奴隶先前曾逃跑，应采信对该奴隶刑讯所得的供述；因为看来刑讯是针对奴隶本人进行的，并非为了主人或针对主人而进行。

### <a id="22.3.8"></a>22.3.8　保罗《论普劳提乌斯》第十八卷

若儿子否认自己处于父亲的权力之下，裁判官应审查此事，并令儿子先行证明。作此安排，一方面符合儿子对父亲应尽的孝敬义务；另一方面，他也在某种意义上主张自己是自由的。因此，主张自己享有自由身份的人，也被要求先行证明。

### <a id="22.3.9"></a>22.3.9　凯尔苏斯《学说汇纂》第一卷

若协议中没有提及继承人，就会产生疑问：当事人是否约定协议仅对订约人本人有效。固然，通常由提出抗辩者证明抗辩所依据的事实；但此处应由原告而非提出抗辩者证明，双方约定只涉及订约人本人而不涉及其继承人，因为我们订立约定时，通常既为自己也为继承人作安排。

### <a id="22.3.10"></a>22.3.10　马尔凯卢斯《学说汇纂》第三卷

元老院决议认为，户籍登记和公文档案的证明力高于证人证言。

### <a id="22.3.11"></a>22.3.11　凯尔苏斯《学说汇纂》第十一卷

未成年人无须证明，在为监护人提供担保人时，那些担保人并不适格；应由负有职责、理应确保未成年人获得担保的人承担证明责任。

### <a id="22.3.12"></a>22.3.12　凯尔苏斯《学说汇纂》第十七卷

遗嘱将五百遗赠给你，后来所立的附录遗嘱中也作了相同记载。问题在于，遗嘱人是想把遗赠加倍，还是仅仅重复记载，并且忘了自己已在遗嘱中作过遗赠；应由谁证明这一点？乍看之下，似乎应由请求者证明其主张；但有些证明责任显然也应由被告承担。例如，我请求返还借款，被告答称款项已经清偿，就应由被告证明已经清偿。因此，此处原告既然出示了两份书面记载，继承人便应向法官证明后立附录遗嘱中的记载不发生效力。

### <a id="22.3.13"></a>22.3.13　凯尔苏斯《学说汇纂》第三十卷

有人就某人的年龄发生争议时，我国皇帝曾以如下文字作出复函：“在某人的年龄身份发生争议、且提出不同陈述时，采纳其中对其不利的一项，既严酷又不公平；应审查案情、查明真实情况，并优先依据在该事项上最有可信度的证据计算年龄。”

### <a id="22.3.14"></a>22.3.14　乌尔比安《论执政官职务》第二卷

若有人自称是自由出生者，而他被指称为自由释奴，应先确定谁承担原告一方的诉讼地位。若此人处于自由释奴身份的占有状态，无疑应由他提起自由出生身份之诉，并证明自己是自由出生者。相反，若他处于自由出生身份的占有状态，却被对方指称为自由释奴，就应由指称其为自己被释奴的人承担证明责任；毕竟，主张某人是自己的奴隶，与主张某人是自己的自由释奴，有何区别？但若有人基于自己自由出生的身份，自愿承担举证责任，以求法院作出有利于其自由出生身份的判决，也就是宣告其为自由出生者，法院是否应当准许，尚可讨论。我认为，允许其依惯例证明自己是自由出生者并作出对其有利的判决，并无不妥，因为这并未造成法律上的诈害。

### <a id="22.3.15"></a>22.3.15　莫德斯蒂努《答复集》第十二卷

某人自称是盖乌斯·塞伊乌斯与塞娅所生之子。盖乌斯·塞伊乌斯有兄弟；该人占有盖乌斯的遗产，并声称是依死者委托向其兄弟履行信托遗赠，还取得了有关清偿的担保。后来，兄弟们得知此人并非其兄弟之子，便询问：他们能否向此人请求返还其兄弟的遗产，尽管他们此前已将此人当作儿子那样释放？莫德斯蒂努答复说，兄弟们为信托遗赠已履行而作出的担保，并未确认此人的身份；兄弟们可以证明此人并非死者之子，但这一点应由兄弟们自己证明。

### <a id="22.3.16"></a>22.3.16　克莱门提乌《论尤利亚与帕皮亚法》第三卷

母亲关于其子女的声明也应予采纳；祖父的声明同样应予采纳。

### <a id="22.3.17"></a>22.3.17　凯尔苏斯《学说汇纂》第六卷

涉及《法尔基狄亚法》时，应由继承人证明该法确实适用。若他不能证明这一点，就理应被判承担责任。

### <a id="22.3.18"></a>22.3.18　乌尔比安《论答辩》第六卷

<a id="22.3.18.pr."></a>

**序言（pr.）** 若有人以被释奴身份向其请求提供劳务，应由自称为其庇护人的人承担证明责任。因此，尤利安写道，尽管在先决身份争议中，占有该身份的一方似乎是庇护人，但不应由被释奴承担原告一方的举证责任，而应由自称庇护人的人承担。

<a id="22.3.18.1"></a>

**1.** 若有人声称某项行为系出于欺诈，即使他是在提出抗辩，也必须证明欺诈确已发生。

<a id="22.3.18.2"></a>

**2.** 应由原告证明曾经进行过司法官前询问，也就是由声称某人在司法官前被问及并回答自己是唯一继承人的人证明。若有人声称被询问者保持沉默，也应作同样处理：证明责任仍由原告承担，而不是由提出“未曾作答”抗辩的人承担。

### <a id="22.3.19"></a>22.3.19　乌尔比安《论答辩》第七卷

<a id="22.3.19.pr."></a>

**序言（pr.）** 关于抗辩，应当认为被告承担原告一方的举证责任，并应证明其所提出的抗辩，就如同该抗辩是其请求一样。例如，被告若援用约定抗辩，就应证明确有该项约定。

<a id="22.3.19.1"></a>

**1.** 某人承诺出庭，却声称自己因公务在外而未能出庭，或对方以恶意欺诈阻止他出庭，或疾病、恶劣天气使他无法出庭，都应由他证明。

<a id="22.3.19.2"></a>

**2.** 同样，若有人提出代理人抗辩，理由是对方无权指定代理人或成为代理人，也应由提出抗辩者证明。

<a id="22.3.19.3"></a>

**3.** 若请求支付某笔据称已经抵销的款项，也应适用同一规则。

<a id="22.3.19.4"></a>

**4.** 此外，若有人主张当前请求的事项已受既判力拘束，或曾就该事项提出宣誓条件，又或者主张该事项系基于赌博，则均应由其承担举证责任。

### <a id="22.3.20"></a>22.3.20　尤利安《学说汇纂》第四十三卷

若某人以暴力掳走自由人并将其拘禁，他竟会不公正地取得占有人的利益，因为无法证明在诉讼最初确定争点之时，该人仍处于自由状态。

### <a id="22.3.21"></a>22.3.21　马尔基安《法学阶梯》第六卷

我认为，更妥当的做法是，由提起诉讼的人，也就是受遗赠人，证明死者明知遗赠之物属于他人或已设定负担仍将其遗赠；而不应要求继承人证明自己不知道该物属于他人或已设定负担。因为证明责任始终由提起诉讼的人承担。

### <a id="22.3.22"></a>22.3.22　乌尔比安《答复集》第一卷

主张意思已经改变的人，应当证明这一点。

### <a id="22.3.23"></a>22.3.23　马尔基安《抵押诉讼程式》单卷

首先，应当证明原告与债务人之间曾约定以某物设定质押或抵押；但即使原告证明了这一点，还必须证明：约定设质时该物属于债务人，或者设定抵押是经物主同意的。

### <a id="22.3.24"></a>22.3.24　莫德斯蒂努《规则》第四卷

若债务凭证已被划销，尽管依据推定，债务人似乎已经免责，但债权人若以明确证据证明仍有某一金额未获清偿，仍可就该金额向债务人提起诉讼。

### <a id="22.3.25"></a>22.3.25　保罗《疑问集》第三卷

<a id="22.3.25.pr."></a>

**序言（pr.）** 涉及非债清偿时，谁应证明债务原本不存在？对此应作如下区分：若被指称收受非债之物或款项的人否认曾经收受，而给付人以合法证据证明自己已经给付，那么否认收受的人若希望法院采纳其主张，就必须证明自己所收受的是应当偿还的债务。否则就会极为荒谬：某人起初否认收过钱，待其收受款项已被证明后，反而要求对方证明该给付不是债务。相反，若收受人一开始就承认收到了款项，只是说这笔钱并非作为非债清偿给付，那么无疑应作有利于收受人的推定。因为给付人通常不会如此轻率，随意抛弃自己的钱财、支付并不存在的债务；尤其当声称自己误付非债的人是谨慎而勤勉的家主时，更难相信他会轻易犯错。因此，主张自己支付了非债的人，必须证明自己是因收受人的欺诈，或因某种正当的认识错误而支付了非债；不能证明的，就没有返还请求权。

<a id="22.3.25.1"></a>

**1.** 但若主张支付非债的人是未成年人、较年长的未成年人、妇女，或者虽已成年却是士兵、农夫、不熟悉诉讼事务的人，或其他天性单纯、行事懒散之人，那么应由收受款项的人证明其收款有合法依据且款项确属应付；不能证明的，应予返还。

<a id="22.3.25.2"></a>

**2.** 以上规则以给付人主张全部款项均属非债为前提。若其仅主张一部分款项并非债务，例如债务原本确实存在，但债务消灭后他因不知情而再次支付；或者他因错误而支付了本可援用抗辩拒绝清偿的款项，那么无论如何都应由给付人证明自己支付了超过债务的款项、因错误重复支付了已清偿的款项，或因不知自己受抗辩保护而白白支付了款项。这符合一般规则：主张本可提出抗辩者，或主张债务已经清偿者，应当证明其主张。

<a id="22.3.25.3"></a>

**3.** 在上述所有情形中，都应允许负有举证责任的一方要求对方宣誓；但要求宣誓者须先宣誓自己并非出于诬告而提出请求。法官可依宣誓的信用形成判决，同时应保留将宣誓责任转交对方的权利。

<a id="22.3.25.4"></a>

**4.** 但以上规则适用于争议是关于非债清偿的情形。若据称不应作出的只是债务凭证，而该凭证笼统记载债务，则应由凭证所载债务人证明其所承认的债务确实存在；除非出具凭证的人特别说明了出具凭证的原因。在后一情形，他应受其书面承认拘束，除非准备以明确的书面证据证明自己作出了不应有的承诺。

### <a id="22.3.26"></a>22.3.26　帕比尼安《疑问集》第二十卷

普罗库拉想在其兄弟死后，与兄弟的继承人进行账目抵销，以抵销兄弟欠她的一大笔信托遗赠；但对方则主张，兄弟生前从未向她索要该笔遗赠，尽管兄弟曾因各种缘由多次向她支付款项。神圣的康茂德皇帝审理此案时，不准抵销，理由是应推定该笔信托遗赠已被默示免除。

### <a id="22.3.27"></a>22.3.27　斯凯沃拉《学说汇纂》第三十三卷

立遗嘱人向一名依法只能在一定限额内受领财产的人遗赠了法律允许的数额，随后又这样写道：“我给并遗赠提图斯一百，因为他曾交给我此款。之所以没有要求他提供担保，是因为他从母亲处取得的全部财产及财产总额——若有的话——都在我手中，无须任何担保。我还希望从我的财产中向同一提图斯返还并支付一百五十：这笔钱来自其地产的收益（我曾取得并出售了这些地产的孳息），也来自账簿中记载的款项（提图斯若曾从母亲处取得款项，而我将其用于自己的事务）。”我问，提图斯能否请求这些款项。答复说，若提图斯能够证明上述款项是从其财产中转入立遗嘱人手中的，就可以请求返还；因为立遗嘱人似乎是利用遗嘱作出这些补充，以规避提图斯依法不得超过的受领限额。

### <a id="22.3.28"></a>22.3.28　拉贝奥《可能论》第七卷（保罗节本）

若仲裁人须判断某项工程是否仍有记忆存续，应查明是否有人记得该工程曾经建成。保罗说：不应如此理解。仲裁人要判断的是，关于该工程建成的记忆是否仍然存在；所要查明的并非是否有人记得工程建成于哪一天或哪位执政官任期内，而是能否以某种方式证明该工程是在何时建成的；希腊语通常称之为 *en platei*（概括地、宽泛地）。因为人们可能并不记得具体时间。例如，假设工程是在一年之内建成的，但没有人记得自己是在哪几位执政官任期内看到它建成；然而，所有人都认为自己既未听说也未亲眼看见工程施工，也没有从曾经看见或听说的人那里听说此事。若工程建成的记忆不存在，同样的推论便可以无穷无尽地向更早时期追溯。

### <a id="22.3.29"></a>22.3.29　斯凯沃拉《学说汇纂》第九卷

<a id="22.3.29.pr."></a>

**序言（pr.）** 安敦尼与维鲁斯两位奥古斯都皇帝曾向克劳狄乌斯·阿波利纳里复函，内容如下：“关于子女身份所提出的证据，并不只限于证人的陈述；此外，若能确认寄给妻子的信件真实可靠，经主张援用后，裁定其也可在一定程度上替代书面证据。”

<a id="22.3.29.1"></a>

**1.** 一名怀孕的妇女遭丈夫休弃，生下一子后，在丈夫不在场时于公文记录中声明该子为非婚生子。有人询问：该子是否处于其父的权力之下？若母亲未立遗嘱而死亡，该子能否依父亲的指示继承母亲的遗产？母亲因愤怒所作的声明是否会妨碍此事？答复说，仍应允许查明真实情况。
