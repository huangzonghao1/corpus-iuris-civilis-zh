# D.21.3 论已出售并交付之物的抗辩

<!-- source-p 001; 原文导航锚点 3、题名锚点 21.3 -->
<a id="3"></a><a id="21.3"></a>**21.3.0. 论已出售并交付之物的抗辩（*De exceptione rei venditae et traditae*）**

<!-- source-p 002 -->
<a id="21.3.1"></a>**21.3.1**

<!-- source-p 003 -->
**乌尔比安：《论告示》第七十六卷。**

<!-- source-p 004 -->
<a id="21.3.1.pr."></a>**序言。**马尔凯鲁斯写道：如果你出售了他人所有的土地，后来该土地归你所有，而你又请求返还该土地，则应当以这一抗辩正当地驳回你的请求。

<!-- source-p 005 -->
<a id="21.3.1.1"></a>**1.**即使土地所有人继承了出卖人，也应作同样判断。

<!-- source-p 006 -->
<a id="21.3.1.2"></a>**2.**如果某人受我委托出售我的物品，我请求返还该已售物品时，这一抗辩将对我不利；但如果能够证明，我曾指示其在价款付清前不得交付该物，则不在此限。

<!-- source-p 007 -->
<a id="21.3.1.3"></a>**3.**塞尔苏斯说：如果某人以低于我所授权的价格出售我的物品，该物品并不因此视为已被处分；如果我请求返还该物，这一抗辩也不妨碍我。此说正确。

<!-- source-p 008 -->
<a id="21.3.1.4"></a>**4.**如果一名奴隶用特有产购买货物，之后主人在其取得这些货物的所有权之前，以遗嘱命其自由，并将特有产遗赠给他，而出卖人开始向该奴隶请求返还货物，则适用基于事实的抗辩，因为他订立买卖时仍是奴隶。

<!-- source-p 009 -->
<a id="21.3.1.5"></a>**5.**如果某人买下某物，但该物尚未交付给他，而他以无瑕疵方式取得了该物的占有，则可以对出卖人主张抗辩；但出卖人若有正当理由请求返还该物，则不在此限。即使出卖人已经交付占有，只要其请求返还该物具有正当理由，也可以提出反抗辩，以对抗这一抗辩。

<!-- source-p 010 -->
<a id="21.3.2"></a>**21.3.2**

<!-- source-p 011 -->
**庞波尼乌斯：《普劳提乌斯论著》第二卷。**

<!-- source-p 012 -->
如果你从提提乌斯处买下一块原属塞姆普罗尼乌斯的土地，并且该土地已交付给你；你付清价款后，提提乌斯继承了塞姆普罗尼乌斯，继而又将同一土地出售并交付给梅维乌斯。尤利安认为，较为公平的做法是优先保护你：因为即使提提乌斯本人向你请求返还土地，也会被这一抗辩驳回；如果提提乌斯本人占有该土地，你则可以提起普布利奇安诉讼。

<!-- source-p 013 -->
<a id="21.3.3"></a>**21.3.3**

<!-- source-p 014 -->
**赫莫革尼安：《法学概要》第六卷。**

<!-- source-p 015 -->
<a id="21.3.3.pr."></a>**序言。**已出售并交付之物的抗辩，不仅有利于受领交付之人，也有利于其继受人以及第二买受人，即使该物尚未交付给第二买受人亦然；因为第一买受人有利害关系，不使该物从第二买受人处被追夺。

<!-- source-p 016 -->
<a id="21.3.3.1"></a>**1.**基于同一理由，这一抗辩也将对出卖人的继受人不利，无论其是概括继受出卖人的全部权利，还是仅继受该项物。
