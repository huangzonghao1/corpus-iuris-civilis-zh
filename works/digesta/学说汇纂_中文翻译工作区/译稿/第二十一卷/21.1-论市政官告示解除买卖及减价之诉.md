<a id="1"></a><a id="21.1"></a>

## 21.1.0　论市政官告示、解除买卖及减价之诉（*De aedilicio edicto et redhibitione et quanti minoris*）

### <a id="21.1.1"></a>21.1.1　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.1.pr."></a>

**序言（pr.）** 拉贝奥写道，库鲁尔市政官有关买卖的告示，适用于土地等不动产，也适用于动产和能够自行移动的物。

<a id="21.1.1.1"></a>

**1.** 市政官规定：“出售奴隶的人，应使买受人确切知悉每名奴隶患有何种疾病或存在哪些瑕疵，是否为逃亡奴隶或流浪奴隶，是否尚未因诺克萨责任而获释；出售这些奴隶时，也应将上述事项如实公开说明。如果奴隶的出售违反上述规定，或者出售时曾就奴隶作出与实际情形不符的陈述或承诺，而依此应由出卖人负责，我们将给予买受人及所有与该事项有关的人诉权，请求解除买卖并返还该奴隶。但如果出售和交付后，因买受人、其家内人员或管理人的行为使奴隶状况恶化，或者奴隶在出售后生育或取得其他财物，或者买卖时另有附随物，或者买受人从该奴隶处取得任何孳息，买受人应将这些一并返还。买受人自己提供的附随物，也应返还给他。此外，出售奴隶时，应公开说明该奴隶是否犯下死罪、是否曾试图自杀、是否曾被送入竞技场与野兽搏斗；我们将就这些事由给予诉权。除此之外，如果有人被指称明知而以欺诈方式违反上述规定出售奴隶，我们也将给予诉权。”

<a id="21.1.1.2"></a>

**2.** 颁布该告示，是为了防止出卖人欺诈，并救济被出卖人欺骗的买受人。应当知道，即使出卖人不知道市政官要求其负责的事项，他仍须承担责任。这并不不公平：出卖人本可以查明相关情况；而对买受人而言，自己为何受骗并不重要，无论是出卖人不知情还是蓄意欺骗，均不影响其受骗的事实。

<a id="21.1.1.3"></a>

**3.** 应当知道，该告示不适用于国库财产的出售。

<a id="21.1.1.4"></a>

**4.** 但如果由市镇共同体出售财物，该告示仍然适用。

<a id="21.1.1.5"></a>

**5.** 对受监护未成年人的财产进行出售时，也适用该告示。

<a id="21.1.1.6"></a>

**6.** 如果奴隶的瑕疵或疾病显而易见，例如通常可以通过某些标记看出瑕疵，就可以说该告示不再适用；因为该告示唯一关注的是买受人不得受骗。

<a id="21.1.1.7"></a>

**7.** 但应当知道，萨宾努斯将疾病定义为：身体的某种状态违反自然，并使身体较之自然赋予其健康时所具有的用途更为不适用。这种情况有时发生于全身，有时发生于身体某一部分；例如发热属于全身疾病，失明则是局部疾病，即使此人天生失明亦然。〔底本此处作 *fvisis febris*，疑有讹字；本译按上下文暂译为“发热”。〕瑕疵与疾病大不相同，例如口吃的人，更应说其有瑕疵，而非患病。我认为，市政官为了消除疑义，才用希腊语 *bis kata tou autou*〔底本转写，意为“同一事项说了两次”〕重复表达同一意思，以免仍有任何疑问。

<a id="21.1.1.8"></a>

**8.** 因此，如果存在妨碍一个人使用或履行职责的瑕疵或疾病，就可以请求解除买卖；但须记住，并非任何再轻微不过的情形都会使奴隶被认定有病或有瑕疵。轻微发热、可以忽略的旧有间歇热，或小伤口，均不构成这里所说的瑕疵；这类情形本可不予理会。以下举例说明哪些情形属于患病或有瑕疵。

<a id="21.1.1.9"></a>

**9.** 维维安努斯讨论：如果某奴隶在狂信者之间并非总是摇头，也只是偶尔说些话，是否仍应视为健康？维维安努斯说，此人仍属健康。他说，我们不应仅因某些人有精神方面的缺陷，就认为他们不健康；否则，按此理由，我们会无限扩大范围，将许多健康之人也认定为不健康，例如轻度迷信、易怒、傲慢，以及其他类似的精神缺陷。他说，出卖人作出的承诺主要涉及身体健康，而非精神方面的缺陷。不过，有时身体瑕疵会影响精神，例如 *frenytikw*〔底本希腊语转写〕所指的发热谵妄。那么，如果存在一种严重到出卖人应予说明的精神缺陷，而出卖人明知却未作说明，买受人可以提起买受之诉。

<a id="21.1.1.10"></a>

**10.** 同一位维维安努斯说，即使有人曾在神庙附近狂舞并作出预言，只要现在不再如此，就不构成瑕疵；过去曾有过这种表现，也不产生诉权，正如曾经发热一样。但如果这种缺陷持续存在，使此人经常在神庙附近狂舞，并像疯子一样作出预言，即使这是出于放纵，仍然属于瑕疵；不过这是精神瑕疵，不是身体疾病，因此不得解除买卖，因为市政官的告示针对的是身体瑕疵。尽管如此，买受人仍可提起买受之诉。

<a id="21.1.1.11"></a>

**11.** 维维安努斯还说，过度胆怯、贪欲、吝啬或易怒的人，也适用同一规则。

### <a id="21.1.2"></a>21.1.2　保罗《评库鲁尔市政官告示》第一卷

或者，放荡、驼背、弯曲、皮肤瘙痒或患疥癣的人；以及哑者和聋者。

### <a id="21.1.4"></a>21.1.4　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.4.pr."></a>

**序言（pr.）** 对于这些并不产生解除买卖请求权的瑕疵，仍可提起买受之诉。

<a id="21.1.4.1"></a>

**1.** 但如果身体瑕疵影响到精神，例如因发热而胡言乱语，或有人在街巷中像疯子一样说些惹人发笑的话，且其精神缺陷是由身体瑕疵造成的，就可以解除买卖。

<a id="21.1.4.2"></a>

**2.** 庞波尼说，有些人答复称，赌徒和酒馆经营者不属于该告示所列范围；贪食者、骗子、说谎者和好诉讼者也不包括在内。

<a id="21.1.4.3"></a>

**3.** 庞波尼还说，出卖人虽应保证奴隶不会过于愚钝，但如果他将奴隶作为傻子或小丑出售，以致其毫无用途，就应认为这是瑕疵。依现行法律，疾病或瑕疵之称似乎仅指身体；对于精神瑕疵，只有出卖人作出承诺时才负责，否则不负责。因此，告示特别列举迷路奴隶和逃亡奴隶；因为这属于精神瑕疵，而非身体瑕疵。由此，有人说，胆怯、爱踢人的牲畜不应列为患病，因为这是精神瑕疵，而非身体瑕疵。

<a id="21.1.4.4"></a>

**4.** 总之，如果仅有精神瑕疵，除非出卖人曾声明不存在该瑕疵而实际存在，否则不得解除买卖；但如果出卖人明知精神瑕疵却隐瞒，仍可提起买受之诉。如果瑕疵仅属身体方面，或身体与精神瑕疵兼有，则可以解除买卖。

<a id="21.1.4.5"></a>

**5.** 应当注意，告示此处一般提到“疾病”，并未特指严重疾病。庞波尼说，这并不奇怪，因为这里处理的并非妨碍特定诉讼进行的疾病。

<a id="21.1.4.6"></a>

**6.** 庞波尼还说，并非任何疾病都会产生解除买卖的请求权，例如轻微眼疾、轻微牙痛或耳痛、中度溃疡；总之，无论多轻微的发热，都不属于该告示调整的情形。

### <a id="21.1.6"></a>21.1.6　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.6.pr."></a>

**序言（pr.）** 庞波尼正确地说，该告示不仅适用于永久性疾病，也适用于暂时性疾病。

<a id="21.1.6.1"></a>

**1.** 特雷巴提乌斯说，若患有皮肤疥癣，但仍能正常使用受影响的身体部位，就不属于患病；我认为特雷巴提乌斯的意见正确。

<a id="21.1.6.2"></a>

**2.** 我认为，更为正确的意见是，阉人不属于患病或有瑕疵，而应视为健康；只有一个睾丸但仍能够生育的人，也是如此。

但如果某人是阉人，以至于身体这一必要部分完全缺失，他就属于患病。

有人舌头被割去，能否认为他健康？奥菲利乌斯的著作中记载了这一问题，并以马为例；他说，这匹马似乎不能算健康。

萨宾努斯说，哑者属于患病，因为没有声音显然是一种疾病。但说话很费力的人并非患病，发音不清的人也不一定患病；不过，说话含混不清的人当然属于患病。〔底本的 *asafws*、*asemws* 为希腊语转写，语义区分暂依上下文处理。〕

### <a id="21.1.10"></a>21.1.10　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.10.pr."></a>

**序言（pr.）** 奥菲利乌斯还说，如果某人手指被切断或肢体受伤，即使伤口已经痊愈，只要因此而不能像从前那样使用身体，就不能视为健康。

<a id="21.1.10.1"></a>

**1.** 我还读到加图写道，手或脚上有一根手指被切除的人属于患病；依照上述区分，这一意见是正确的。

<a id="21.1.10.2"></a>

**2.** 但如果某人手上或脚上多出几根手指，只要手指数量并不妨碍其使用，就不属于可以解除买卖的情形。因此，关键不在手指的数量，而在于此人能否不受妨碍地使用手指，无论其数量多于还是少于通常数量。

<a id="21.1.10.3"></a>

**3.** 有人问，近视者是否健康；我认为可以解除与其所订的买卖。

<a id="21.1.10.4"></a>

**4.** 也已确认，患有 *nuktalwpa*〔底本转写〕者属于患病，即其人早晨和傍晚都看不见。希腊人称这种病为 *nuktalwpa*。有人认为，所谓夜盲，是指有光照时仍完全看不见。

<a id="21.1.10.5"></a>

**5.** 有人问，口吃、咬舌、*atypus*〔底本转写，所指不明〕、说话迟缓、内八字或外八字的人是否健康；我认为他们是健康的。

### <a id="21.1.11"></a>21.1.11　保罗《评萨宾》第十一卷

**正文** 缺少一颗牙齿的人不属于患病者：因为大多数人都缺少某一颗牙齿，却不因此患病；尤其是我们出生时本来就没有牙齿，在长出牙齿以前也并非因此不健康；否则，就没有一个老年人是健康的。

### <a id="21.1.12"></a>21.1.12　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.12.pr."></a>

**序言（pr.）** 有鸡眼的人属于患病者；有鼻息肉的人也是如此。

<a id="21.1.12.1"></a>

**1.** 佩狄乌斯写道，如果某人一只眼睛或一侧颌骨较大，但能正常使用，仍应视为健康。他说，颌骨、眼睛或手臂不对称，只要不妨碍履行其应提供的功能，就不构成解除买卖的事由。不过，躯干一侧或一条腿较短也可能造成妨碍；因此，这种情形也可以解除买卖。

<a id="21.1.12.2"></a>

**2.** 某人天生患甲状腺肿，或眼球突出，仍应视为健康。

<a id="21.1.12.3"></a>

**3.** 还应知道，左撇子不属于患病或有瑕疵，除非其右手无力，以致较多地使用左手；但这种人应称为残缺者，而非左撇子。

<a id="21.1.12.4"></a>

**4.** 有人问，口中有异味的人是否健康。特雷巴提乌斯说，口腔本身有异味，例如有羊膻味或恶臭，并不构成疾病，因为这通常是口腔污秽所致。但若异味源于身体疾病，例如肝、肺或其他类似部位患病，则此人属于患病者。

### <a id="21.1.13"></a>21.1.13　盖尤斯《评库鲁尔市政官告示》第一卷

**正文** 此外，跛足者属于患病者。

### <a id="21.1.14"></a>21.1.14　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.14.pr."></a>

**序言（pr.）** 有人询问，一名总是产下死胎的妇女是否患病。萨宾努斯说，如果这是由子宫的瑕疵造成的，她就属于患病者。

<a id="21.1.14.1"></a>

**1.** 所有人都同意，若妇女怀孕时出售，应视为健康；因为接受并孕育胎儿是妇女最大且最重要的职责。

<a id="21.1.14.2"></a>

**2.** 产妇也应视为健康，只要没有外在事由导致其身体患病。

<a id="21.1.14.3"></a>

**3.** 关于不育者，凯利乌斯说，特雷巴提乌斯作了区分：若因天生原因不育，则属于健康；若因身体瑕疵而不育，则相反。

<a id="21.1.14.4"></a>

**4.** 另有人询问遗尿者的情形。佩狄乌斯说，不能仅因某人睡眠中受酒力压制，或因懒于起身而在床上排尿，就认为他不健康；但若其因膀胱瑕疵而不能控制积存的尿液，则可以解除买卖。理由不是他在床上排尿，而是其膀胱有瑕疵。佩狄乌斯的意见更为妥当。

<a id="21.1.14.5"></a>

**5.** 佩狄乌斯还说，若某人的悬雍垂被切除，与其说这使解除买卖之诉成立，不如说它排除了该诉，因为疾病已减轻。我认为，若疾病消失，就无从提起解除买卖之诉；若瑕疵仍然存在，则该诉仍可提起。

<a id="21.1.14.6"></a>

**6.** 某人出生时手指相连，不能视为健康；但只有在此妨碍其使用手部时，才是如此。

<a id="21.1.14.7"></a>

**7.** 可以确定，妇女的阴道若狭窄到使其不能进行性交，就不能视为健康。

<a id="21.1.14.8"></a>

**8.** 有人患有 *antiades*，能否以其有瑕疵为由解除买卖，尚有疑问。若我所理解的 *antiades* 是指久已存在、无法消退的咽喉肿胀，那么患有这种病的人就属于有瑕疵者。

<a id="21.1.14.9"></a>

**9.** 若卖方明确排除某种疾病，并声明或承诺除此之外标的健康，就应遵守双方约定（因为当事人放弃其诉权后，不应再给予回复抗辩）；但若卖方明知疾病而故意隐瞒，则应准许买方提出基于恶意欺诈的回复抗辩。

<a id="21.1.14.10"></a>

**10.** 若未明确排除某种疾病，但疾病显而易见、人人都可能看见，例如出售的是盲人，或其头部或身体其他部位有明显且危险的疤痕，凯基利乌斯说，卖方对此不负责任，如同已明确排除该疾病一样。应当认为，市政官告示适用于买方不知道且不可能知道的疾病和瑕疵。

### <a id="21.1.15"></a>21.1.15　保罗《评萨宾》第十一卷

### <a id="21.1.16"></a>21.1.16　庞波尼《评萨宾》第二十三卷

**正文** 某物若已治愈并恢复原状，就应视为从未患病。

### <a id="21.1.17"></a>21.1.17　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.17.pr."></a>

**序言（pr.）** 奥菲利乌斯界定了何谓逃亡奴隶：逃亡奴隶，是指为了逃跑并躲避主人，在主人家宅之外逗留的人。

<a id="21.1.17.1"></a>

**1.** 凯利乌斯则说，逃亡奴隶是怀着不再回到主人身边的意图离开的人；即使后来改变主意而返回，也仍是如此。因为他说，不会因其悔悟而使犯下这种过错的人不再有责。

<a id="21.1.17.2"></a>

**2.** 卡西乌斯也写道，逃亡奴隶是有明确意图而离开主人的人。

<a id="21.1.17.3"></a>

**3.** 维维安努斯的著作还记载，逃亡奴隶通常应从其内心意图判断，不必然以是否实际逃走为准。逃避敌人、强盗、火灾或房屋倒塌的人，虽确实是逃离，却不因此成为逃亡奴隶。同样，逃离受托管教自己的教师者，也不算逃亡奴隶，若其逃离是因为教师对他管束过度。若他因同一原因逃离借用他的借用人，维维安努斯也认为结论相同；若借用人对待他过于严酷，亦然。以上情形均以奴隶逃离后又回到主人处为前提；若未回到主人处，他说，无疑应视为逃亡奴隶。

<a id="21.1.17.4"></a>

**4.** 维维安努斯还说，有人问普罗库鲁斯：某奴隶藏在家中，意在伺机逃走并脱身，该如何认定？普罗库鲁斯回答，尽管留在家中的人似乎不能说是在逃跑，但此人仍是逃亡奴隶。相反，若他只是藏起来，直到主人的怒气平息，就不是逃亡奴隶；因看见主人将要鞭打自己而赶紧躲到朋友处，请朋友代为求情的人，也不是逃亡奴隶。为了跳下去而走到高处的人也不算逃亡奴隶；否则，难道要把在家中登上高处准备跳下的人也称为逃亡奴隶吗？此人更可能是想自杀。维维安努斯说，不明事理的人常说，只要某人未经主人许可在外过夜，就属于逃亡奴隶；这并不正确，而应根据每个人的内心意图判断。

<a id="21.1.17.5"></a>

**5.** 维维安努斯还说，有人问，一个孩子离开教师后又回到母亲处，是否为逃亡奴隶。若他是为了躲藏、不再回到主人身边而逃走，就属于逃亡奴隶；若只是想借母亲之助，更容易为某项过错求得宽恕，则不属于逃亡奴隶。

<a id="21.1.17.6"></a>

**6.** 凯利乌斯还写道，若你买下的奴隶跳入台伯河，且他离开主人仅仅是为了自杀，则不属于逃亡奴隶；但若他起初打算逃跑，后来才改变主意跳入台伯河，仍属于逃亡奴隶。关于从桥上跳下的人，也适用同一结论。凯利乌斯所写的这些都正确。

<a id="21.1.17.7"></a>

**7.** 凯利乌斯还说，若你的奴隶逃跑时带走了他的代役奴隶，而后者是在不知情或违背意愿的情况下跟随，且一旦有机会回到你身边就没有放弃这一机会，则不应视为逃亡奴隶；但若其在逃跑之初已明白发生了什么，或者后来得知事情原委后本可返回却不愿返回，则结论相反。被拐奴隶带走的人也应作同样处理。

<a id="21.1.17.8"></a>

**8.** 凯利乌斯还说，奴隶在农庄时离开庄园，意在逃走，但在尚未离开你的地产之前就被人抓获，也应视为逃亡奴隶；因为构成逃亡的是逃亡的意图。

<a id="21.1.17.9"></a>

**9.** 凯利乌斯还说，即使某人只朝逃跑方向迈出一两步，甚至刚开始奔跑，但因无法摆脱追赶的主人而未能逃脱，也不因此成为逃亡奴隶。

<a id="21.1.17.10"></a>

**10.** 凯利乌斯正确地说，逃跑具有某种自由的外观，即暂时摆脱主人的权力。

<a id="21.1.17.11"></a>

**11.** 作为质物交付的奴隶，仍以债务人为其主人；但若债权人行使了自己的权利后，该奴隶逃离债权人控制，他可能被视为逃亡奴隶。

<a id="21.1.17.12"></a>

**12.** 拉贝奥与凯利乌斯讨论过：某人逃入庇护所，或前往那些自称愿意被出售的人通常聚集的地方，是否属于逃亡奴隶。我认为，做其自以为法律允许公开去做之事的人，不属于逃亡奴隶。我也不认为逃到凯撒雕像前的人属于逃亡奴隶，因为他这样做并非出于逃跑意图。逃入庇护所或其他类似场所的人也是如此，因为他并非意在逃跑；但若他此前已逃跑，后来才前往该处，则不会因此不再是逃亡奴隶。

<a id="21.1.17.13"></a>

**13.** 凯利乌斯还写道，人们认为，前往主人无法将其追回之处的人也属于逃亡奴隶；前往主人甚至无法将其带离之处的人，更是如此。〔底本此处在 *esse* 与 *qui* 之间有空缺标记“[]”，原文关系不明。〕

<a id="21.1.17.14"></a>

**14.** 拉贝奥如此界定 *erro*：他是“小型逃亡奴隶”；反过来说，逃亡奴隶是“大型 *erro*”。但严格说来，我们这样界定 *erro*：他虽未逃跑，却经常无故游荡，把时间耗费在琐事上，迟迟才回家。

<a id="21.1.17.15"></a>

**15.** 凯利乌斯的著作记载如下：某奴隶为一名住在庇护人家中的被释奴服务；该被释奴的住所由一道门锁独自封闭。奴隶怀着不再返回的意图离开被释奴住所，虽仍在庇护人宅内，却在外逗留了一整夜。凯利乌斯说，此人应视为逃亡奴隶。但若该住所并未受到这样的封闭看守，而被释奴住在一间与其他房间共用通道、可以自由出入的房间，凯利乌斯说则应作相反认定，拉贝奥也赞同。

<a id="21.1.17.16"></a>

**16.** 凯利乌斯还说，某奴隶被主人派往行省，后来听说主人已死，并在遗嘱中将自己释放，便继续留在原职，只是开始以自由人的身份行事；此人不属于逃亡奴隶。因为他说，此人虽谎称自己已获自由，却不是以逃跑的意图这样做。

<a id="21.1.17.17"></a>

**17.** 市政官所说“尚未解除诺克萨责任”，应如此理解：不应宣告此人未实施任何诺克萨侵害，而应理解为其尚未免除诺克萨责任，也就是仍受诺克萨诉讼拘束。因此，若他实施过诺克萨侵害，但该责任已不再持续，就应视为已经解除诺克萨责任。

<a id="21.1.17.18"></a>

**18.** 我们所说的诺克萨侵害，应理解为私法上的侵害，即任何由私犯引起的侵害，而不是公共犯罪；前者可提起诺克萨诉讼。下文还专门规定了有关重大犯罪的情形。私法侵害会产生金钱损害；例如，若有人不愿交付加害人以代偿，而选择承担诉讼估价，就会产生该损害。

<a id="21.1.17.19"></a>

**19.** 若某奴隶依敕令绝对不得被释放，或主人将其出售时附有不得解除束缚的条件（或其已被某项权力判处相应刑罚），又或者依法必须遣出境外，那么市政官也预先声明这些情形，是最为公平的。

<a id="21.1.17.20"></a>

**20.** 若有人声称奴隶具备某项品质而实际不具备，或声称不具备某项品质而实际具备，例如声称他不是窃贼而他确是窃贼，或声称他是某种技艺的行家而他并非如此，那么由于其未能保证所作陈述属实，似乎就是违反了陈述或承诺。

### <a id="21.1.18"></a>21.1.18　盖尤斯《评库鲁尔市政官告示》第一卷

<a id="21.1.18.pr."></a>

**序言（pr.）** 若卖方就奴隶作出陈述，而买方主张事实并非如此，可以提起解除买卖之诉，或者估价之诉（即减价之诉）。例如，卖方声称奴隶性情坚定、勤勉、行动敏捷、警觉，或能靠节俭积累特有产，而该奴隶实际却轻浮、放肆、懒惰、嗜睡、迟缓、行动迟钝或贪吃。这些规定的意思似乎是，不应严厉要求卖方为其所作陈述承担责任，而应适度衡量。例如，卖方若称某人性情坚定，不应像要求哲学家那样，要求他达到极端庄重和坚定；卖方若称某人勤勉而警觉，也不应要求他日夜不息地劳动。上述品质均应依诚信与公平原则适度要求。对于卖方所作的其他陈述，也应作同样理解。

<a id="21.1.18.1"></a>

**1.** 卖方若称某人是最优秀的厨师，就应保证他在该技艺上确属最优秀；若只是笼统称其为厨师，只要提供的厨师水平一般，就足以履行义务。其他各种技艺也同样如此。

<a id="21.1.18.2"></a>

**2.** 同样，若有人只笼统地说奴隶有特有产，只要该奴隶确实有哪怕很少的特有产，就足够了。

### <a id="21.1.19"></a>21.1.19　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.19.pr."></a>

**序言（pr.）** 还应知道，即使卖方说过某些话，也不必保证其真实性；特别是那些仅仅赞美奴隶的话，例如称他节俭、正直、听话。正如佩狄乌斯所写，卖方为了推介奴隶而说了什么，与卖方承诺要保证其所说属实，二者大不相同。

<a id="21.1.19.1"></a>

**1.** 但若卖方说奴隶不是赌徒、不是窃贼、从未逃到凯撒雕像前避难，就应保证这些陈述属实。

<a id="21.1.19.2"></a>

**2.** 陈述与承诺应作如下区分：陈述，是仅以言语作出、到此为止的说法；承诺则可以指单纯的许诺或允诺，也可以指以要式口约作出的承诺。由此，对此类事项向要式口约的请求人作出承诺的人，既可依要式口约之诉被追究，也可受解除买卖之诉追究。这并非新奇之事，因为可依买卖之诉追究的人，也同样可以依解除买卖之诉追究。

<a id="21.1.19.3"></a>

**3.** 只有那些以履行为目的，而非仅为夸耀而作出的陈述或承诺，才应被承认具有此种效力。

<a id="21.1.19.4"></a>

**4.** 还应知道，若有人承诺或声称奴隶是某种技艺的行家，并不必然要提供技艺完美无缺的人，而只须在一定程度上熟练；既无须精通到最高水平，也不能完全不懂该技艺。因此，只要其水平达到通常所谓技艺人的程度，就足够了。

<a id="21.1.19.5"></a>

**5.** 接着，市政官告示说：“我们将向买方以及所有与该事项有关的人给予诉权。”他们承诺向买方及概括继受其全部权利的人给予诉权。我们所说的买方，应理解为支付价金而购买的人。但若有人以物易物，应认为双方兼具买方与卖方身份，双方均可依据该告示起诉。

<a id="21.1.19.6"></a>

**6.** 解除买卖的期间为六个有效月；若不请求解除买卖，而是请求减价，则有效期间为一年。解除买卖期间自买卖之日开始计算；若有陈述或承诺，则自作出该陈述或承诺之日起算。

### <a id="21.1.20"></a>21.1.20　盖尤斯《评库鲁尔市政官告示》第一卷

**正文** 但若在买卖前已作出陈述，数日后才订立要式口约，凯利乌斯·萨比努斯写道，应依据先前的理由起诉；因为他认为，自该奴隶一经出售之时起，买方就已经能够以此为由提起诉讼。

### <a id="21.1.21"></a>21.1.21　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.21.pr."></a>

**序言（pr.）** “解除买卖”是使卖方重新取得其原先所有之物。由于这是通过返还而实现的，所以称为 *redhibitio*，意即返还。

<a id="21.1.21.1"></a>

**1.** 买方将奴隶返还卖方时，庞波尼说，买方应向卖方作出不涉及恶意欺诈的担保。因此，有必要要求提供担保，以免该奴隶已被买方设质，或依买方指示对他人实施了盗窃或造成损害。

<a id="21.1.21.2"></a>

**2.** 庞波尼还说，有时应分别就过去和将来作出两项担保。例如，就被解除买卖的奴隶而言，买方或其代理人曾以奴隶名义应诉，或曾被他人起诉；又或者买方曾以该奴隶名义起诉。庞波尼说，应担保如下：若买方并非出于恶意欺诈而被判承担责任，或已作出给付，则应妥善履行该责任；若买方因其所提诉讼而取得任何利益，应予返还；若因买方的恶意欺诈或过失，致使该利益在相同期间内未能到手，也应赔偿。

<a id="21.1.21.3"></a>

**3.** 庞波尼还说，对明知而出售的卖方，通常须就未来作出如下担保：若奴隶在买方无过错的情况下逃亡，而卖方仍被判承担责任，则买方应承诺追捕该奴隶，并在将其重新置于自己控制之下后返还卖方，

### <a id="21.1.22"></a>21.1.22　盖尤斯《评库鲁尔市政官告示》第一卷

**正文** 且不得由买方本人或其继承人妨碍卖方重新取得该奴隶。

### <a id="21.1.23"></a>21.1.23　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.23.pr."></a>

**序言（pr.）** 解除买卖时，若买方在主观或身体方面使奴隶状况恶化，就应向卖方赔偿；例如，买方使奴隶遭受性侵，或因买方残酷对待而开始逃亡。因此，庞波尼说，无论因何种原因导致状况恶化，都应由法官酌情评估并赔偿卖方。若买方未经过司法程序便返还奴隶，而又不愿返还前述其他利益，卖方提起买卖之诉即可。

<a id="21.1.23.1"></a>

**1.** 市政官命令买方返还随买卖一并取得的物品，以及买方本人交付的任何附属物，使买卖解除后，双方均不再取得任何利益，犹如买卖从未发生。

<a id="21.1.23.2"></a>

**2.** 告示还排除实施了重大犯罪的人。实施重大犯罪，是指犯下应处死刑的罪行；古人常以“欺诈”一词表示刑罚。只有出于恶意欺诈和恶劣动机，才算实施重大犯罪；若因错误或偶然而为，则告示不适用。因此，庞波尼说，未适婚人或精神失常者不应视为实施了重大犯罪。

<a id="21.1.23.3"></a>

**3.** 告示还排除为了自杀而实施行为的人。人们认为这种奴隶品行恶劣：他做出使自己脱离人世的行为，例如套上绞索、把药物当作毒药服下、从高处跳下，或实施其他自以为会导致死亡的行为；这是因为，一个竟敢如此对待自己的人，似乎也可能对他人实施恶行。

<a id="21.1.23.4"></a>

**4.** 若卖方是奴隶，或是家子，市政官诉权可就特有产对主人或家父提起。尽管这些诉权似乎带有惩罚性质，但由于它们源于契约，应当认为也可针对处于他人权力之下的人提起。因此，若出卖人是家女或女奴，也同样应认为市政官诉权适用。

<a id="21.1.23.5"></a>

**5.** 由该告示产生的这些诉权，也可以向所有继承人提起。

<a id="21.1.23.6"></a>

**6.** 若出卖人是为我们善意服役的自由人，或他人的奴隶，也可以说这些人同样受该告示调整。

<a id="21.1.23.7"></a>

**7.** 尤利安说，解除买卖之诉的判决应以某种方式使双方——即卖方与买方——都恢复原状。

<a id="21.1.23.8"></a>

**8.** 因此，无论奴隶是从买方还是从其他任何人处实施盗窃，若买方因此作了给付，只有在买方使卖方免受损失后，才命令其将奴隶返还卖方。那么，尤利安说，若卖方不愿接收奴隶怎么办？他说，不得强迫卖方作任何给付；卖方承担的责任不得超过价金。买方应因自己的过错承受这一损失，因为他本可交付奴隶以代偿，却宁愿承担诉讼估价。在我看来，尤利安的意见较为宽厚。

<a id="21.1.23.9"></a>

**9.** 解除奴隶买卖时，买方取得的，或因其过失而未能取得的任何利益，都应予以返还。这不只包括买方本人收取的孳息，或从奴隶及其承租人处取得的劳务报酬，也包括买方因迟延向卖方返还奴隶而从卖方处取得的利益；即使买方是从任何其他占有人处取得孳息，也必须返还。此外，买方因孳息名义取得的任何利益也应交付；奴隶所受遗赠或继承亦然。卖方若未出售奴隶，本来能否取得这些利益，并不重要。比如，假设奴隶依法不得从遗嘱中取得任何利益，也不影响上述规则。佩狄乌斯甚至认为，无须考察立遗嘱人是出于何种考虑而指定奴隶为继承人或向其遗赠；因为即使买卖仍然有效，这一指定也不会使买方获益。反过来说，佩狄乌斯说，即使奴隶是因卖方的缘故而被指定为继承人，若卖方不愿解除买卖，我们仍会认为买方无须向卖方返还该利益。

### <a id="21.1.24"></a>21.1.24　盖尤斯《评库鲁尔市政官告示》第一卷

**正文** 因此，概括而言，凡该奴隶为买方取得、且并非源于买卖标的本身的利益，均应公平地返还。

### <a id="21.1.25"></a>21.1.25　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.25.pr."></a>

**序言（pr.）** 市政官还要求买方就奴隶状况恶化承担责任，但仅限于在买卖并交付之后发生的恶化；此前发生的，不属于本诉所审理的事项。

<a id="21.1.25.1"></a>

**1.** 无论是买方本人、其家内奴仆还是其代理人使奴隶状况恶化，均可对买方提起诉讼。

<a id="21.1.25.2"></a>

**2.** “家内奴仆”一语包括一切为其服役之人，也包括为其善意服役的自由人或他人的奴隶；还包括受其权力支配的人。

<a id="21.1.25.3"></a>

**3.** 本诉提到了代理人。涅拉提乌斯说，这里的代理人并非任何人，而是受托处理全部事务，或至少受托处理导致奴隶状况恶化之事务的人。

<a id="21.1.25.4"></a>

**4.** 佩狄乌斯说，公平而言，只有因代理人或家内奴仆的行为而造成、且若奴隶未出售便不会承受的损害，才应归责于买方；至于即使奴隶未出售也会遭受的行为，应允许买方以交付奴隶代为承担其奴隶所致的诺克萨责任。他还说，若是代理人实施了该行为，则只应使买方负有提供相应诉权的义务。

<a id="21.1.25.5"></a>

**5.** 那么，若奴隶的状况恶化是由于买方的过失而非故意，结论如何？买方仍同样承担判决责任。

<a id="21.1.25.6"></a>

**6.** 奴隶状况恶化，不仅指身体状况，也包括性情上的恶习。例如，他在买方处受其他奴隶影响而染上恶习，成为赌徒、酒徒或 *erro*。

<a id="21.1.25.7"></a>

**7.** 但应注意，买方不得以此类事由交付自己的奴隶以代偿诺克萨责任；因为他应为自己奴隶及代理人的行为负责。

<a id="21.1.25.8"></a>

**8.** 还应知道，市政官告示列出的所有这些事项，均须在案件交由法官审理前发生，买方才应承担责任。之所以必须逐一列明，是为了使这些情形若在争讼程序确定前发生，买方承担责任。相反，案件一经交由法官审理，整个案件均围绕返还奴隶而由法官裁判；孳息、奴隶状况恶化所致损失以及其他事项也都纳入审理。法官一经受任，就有义务处理诉讼中的一切事项；诉讼开始前发生的事项则与其关系不大，除非已明确交由其处理。

<a id="21.1.25.9"></a>

**9.** 此外，告示还补充说：“为该奴隶支付的价金及以附属物名义支付的款项，不予返还；任何人因该款项而负有债务的，也不予免除。”

<a id="21.1.25.10"></a>

**10.** 市政官的安排顺序是：买方先向卖方履行上述各项义务，然后才取回价金。

### <a id="21.1.26"></a>21.1.26　盖尤斯《评库鲁尔市政官告示》第一卷

**正文** 但我们还应考察，若卖方有时因无力偿付而无须给付任何款项，却强迫买方先交还奴隶、再提起判决之诉，是否有失公平。此种情形下，更妥当的安排或许是：买方作出担保，若卖方在特定期间内向其支付款项，买方就返还奴隶。

### <a id="21.1.27"></a>21.1.27　乌尔比安《评库鲁尔市政官告示》第一卷

**正文** 卖方应返还买方为该奴隶所支付的价金，以及以附属物名义支付的款项。所谓“支付”，不仅指交到卖方手中的钱，例如价金及其利息，也包括因买卖而支出的其他费用。但只有依卖方意愿支出的款项才予扣除；若买方自行决定支付某项费用，则不予计入，因为任何人都不应要求卖方偿还自己擅自支付的款项。那么，若买方支付了某项税费，而该税费本应由买方承担，又该如何？我们应说，这项费用也须返还；因为买方应在解除买卖后不受损失。

### <a id="21.1.28"></a>21.1.28　盖尤斯《评库鲁尔市政官告示》第一卷

**正文** 若卖方未就市政官告示所列事项作出担保，市政官承诺，买方可在两个月内提起解除买卖之诉，或在六个月内提起诉讼，请求赔偿其利益损失。

### <a id="21.1.29"></a>21.1.29　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.29.pr."></a>

**序言（pr.）** 应当知道，若买方未向卖方履行本诉所要求的事项，法院就不能判卖方败诉；相反，若卖方未向买方履行这些事项，则应判卖方败诉。

<a id="21.1.29.1"></a>

**1.** 卖方还应使买方免于承担其所负债务，无论债权人是卖方本人还是他人。

<a id="21.1.29.2"></a>

**2.** 判决金额依该事项的价值确定。那么，判决额会不会超过价金？我们来看。判决额确实包括价金及附属费用。那么，买方能否获得价金利息，以使其取得其所受损失的补偿，尤其是还须返还孳息？意见认为，买方可以取得利息。

<a id="21.1.29.3"></a>

**3.** 但若买方蒙受了损失，或为奴隶支出了费用，应由法官酌情处理。正如尤利安所说，不应因此直接判卖方支付这些款项；其作用在于，除非卖方使买方免受损失，否则不得要求买方将奴隶返还给卖方。

### <a id="21.1.30"></a>21.1.30　保罗《评库鲁尔市政官告示》第一卷

<a id="21.1.30.pr."></a>

**序言（pr.）** 同样，若买方因解除奴隶买卖而应诉，或以该奴隶名义提起诉讼，双方都应作出担保：若买方并非出于恶意欺诈而被判承担责任，或因其所提诉讼取得任何利益，或因其恶意欺诈导致本可取得的利益未能到手，则应予返还。

<a id="21.1.30.1"></a>

**1.** 争讼程序确定后，买方为治疗奴隶而必要支出的费用，可以列入计算。佩狄乌斯认为，争讼程序确定前的费用也应明确列入。阿里斯托则认为，不应计入奴隶的食物费用，因为买方也不能向奴隶追讨其在买方服役期间所获给养的费用。

### <a id="21.1.31"></a>21.1.31　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.31.pr."></a>

**序言（pr.）** 若卖方不愿接收奴隶，盖尤斯说，对卖方的判决金额不得超过价金。因此，对于买方因奴隶而遭受的损害，只能允许买方继续占有该奴隶作为保全；除此之外，卖方若拒绝接收奴隶，便可避免支付损害赔偿，但仍无法避免返还价金及随价金一并返还的其他款项。

<a id="21.1.31.1"></a>

**1.** 若卖方声明或承诺奴隶不是窃贼，而奴隶确实实施了盗窃，卖方就其承诺承担责任。此处所谓窃贼，不仅指窃取外人财物的人，也包括窃取其主人财物的人。

<a id="21.1.31.2"></a>

**2.** 若解除女奴的买卖，出售后由她所生的子女也应返还，无论她生了一名还是多名子女。

<a id="21.1.31.3"></a>

**3.** 同样，若用益权并入所有权，该用益权也无疑应予返还。

<a id="21.1.31.4"></a>

**4.** 若奴隶在买方处取得特有产，应如何处理？若该特有产是由买方的财产增加而来，应认为仍留归买方；若是从其他来源增加，则应返还卖方。

<a id="21.1.31.5"></a>

**5.** 若买方有多名继承人，是否必须全体同意解除买卖？我们来看。庞波尼说，全体继承人都应同意解除买卖，并指定一名代理人办理，以免卖方遭受不公：卖方可能不得不从一人处收回部分奴隶，而又被判向另一人支付该奴隶价值的相应部分。

<a id="21.1.31.6"></a>

**6.** 庞波尼还说，奴隶死亡或已经被解除买卖后，各继承人可以分别就自己的份额提起诉讼。他们按份额取回价金和附属费用；孳息、附属物以及奴隶状况恶化所造成的损失，也由他们按份额承担。但若事项不可分，例如女奴所生子女，则另当别论；此时应遵循对女奴本人适用的规则，因为我们已否定可以按份额解除女奴的买卖。

<a id="21.1.31.7"></a>

**7.** 马尔凯鲁斯还写道，若共有奴隶购买了另一奴隶，而后者属于可解除买卖的情形，共有人的任何一人都不能仅就自己的份额解除该奴隶的买卖。他说，这与买方有多名继承人、但并非全体同意解除买卖的情形并无不同。

<a id="21.1.31.8"></a>

**8.** 马尔凯鲁斯还说，共有人中的一人不能依据买卖之诉要求卖方仅按其份额向自己交付标的，即使他愿按份支付价金也是如此。他说，对多个买方也应适用这一规则，因为卖方将已出售的物品保留为质物，直至买方履行完毕。

<a id="21.1.31.9"></a>

**9.** 庞波尼说，若某一继承人、其家内奴仆或代理人因过失或故意使物的状况恶化，依照法官裁量，让该人对全部损失承担责任是公平的；若所有继承人共同指定一名代理人起诉，这样处理尤其便利。若因某继承人的过错使奴隶状况恶化，并已就此作出赔偿，其他继承人可对其提起遗产分割之诉，因为正是他使他们遭受损失并妨碍解除买卖。

<a id="21.1.31.10"></a>

**10.** 若卖方有多名继承人，可按各自的继承份额向每人解除奴隶买卖。若奴隶由数人共同出售，亦应如此处理。若数名卖方作为整体出售一个标的，则应更正确地认为，可向每名卖方解除全部买卖；但若各人只出售自己的份额，则可以向其中一人解除买卖，同时对另一人提起减价之诉。同样，若数名买方各自购买一部分，每人仅能就自己的份额行使权利；但若他们作为整体共同购买，每人都可以解除全部买卖。

<a id="21.1.31.11"></a>

**11.** 若应予解除买卖的奴隶已经死亡，应考察其死亡是否由于买方、买方家内奴仆或代理人的过错所致。若奴隶因买方过错死亡，应将其视同仍然存活，并由买方履行奴隶存活时本应履行的一切义务。

<a id="21.1.31.12"></a>

**12.** 这里的过错包括一切过错，而不只是重大过失。因此，应认为，只要买方提供了任何导致死亡的机会，就应由买方负责；例如，即使买方未请医生使奴隶获得治疗，或虽请医生但选错医生，只要这是其自身过错，就应负责。

<a id="21.1.31.13"></a>

**13.** 以上规则适用于奴隶在案件交由法官审理前死亡的情形。若奴隶是在案件交由法官审理后死亡，则应由法官裁量死亡原因；正如佩狄乌斯所认为的，争讼程序确定后发生的一切事项，都须由法官酌情处理。

<a id="21.1.31.14"></a>

**14.** 我们对代理人所说的，也适用于监护人、保佐人及其他因职务而代他人行事的人。佩狄乌斯持此见解，并补充说，既然这些人负责管理事务，要求主人保证没有过失并非不公平。

<a id="21.1.31.15"></a>

**15.** 佩狄乌斯还说，“家内奴仆”一语也包括家子，因为提出解除买卖之诉的人应对家内人员的行为负责。

<a id="21.1.31.16"></a>

**16.** 若买方先因奴隶逃亡而提起减价之诉，之后又因奴隶患病而起诉，判决额应如何确定？毫无疑问，买方可以多次提起减价之诉；但尤利安说，应避免使买方获利，也避免其就同一事项重复取得估价赔偿。

<a id="21.1.31.17"></a>

**17.** 若奴隶已经被解除买卖，买方可提起事实诉讼请求取回价金。该诉所审查的不是奴隶是否原本具备解除买卖的条件，只审查买卖是否已经解除；这样规定并非没有理由。因为卖方既已接收奴隶、承认其属于可以解除买卖的情形，就不公平地再追问该奴隶本来是否应被解除买卖。也不再审查是否在规定期间内解除买卖。

<a id="21.1.31.18"></a>

**18.** 但该诉明确要求买卖已经解除；若尚未解除，即使双方仅以合意约定解除，也不能提起此诉。因此，解除买卖的协议本身不足以产生该诉；必须实际完成解除买卖。

<a id="21.1.31.19"></a>

**19.** 依据该诉，还应返还买卖时随奴隶一并交付的物品。

<a id="21.1.31.20"></a>

**20.** 由于双倍价金的要式口约十分常见，因此若卖方未就奴隶作出双倍价金担保，也允许买方提起买卖之诉。因为在诚信诉讼中，应当考虑交易惯例和习惯。

<a id="21.1.31.21"></a>

**21.** 出售奴隶的人必须说明每名奴隶的族属；因为奴隶的族属往往会吸引或劝退买方，所以我们有必要知悉。有些奴隶因出身于名声较好的族属而被推定品行优良；另一些奴隶则因出身于声名较坏的族属而被视为品行不良。若卖方未说明族属，应向买方及所有与该事项有关的人给予诉权，使买方能够解除奴隶买卖。

<a id="21.1.31.22"></a>

**22.** 若约定某物在买方不满意时可于指定期间内解除买卖，该约定有效。若未约定期间，则应给予买方事实诉讼，使其可在六十个有效日内解除买卖，逾期则不得为之。若双方约定可以无限期解除买卖，我认为此约定有效。

<a id="21.1.31.23"></a>

**23.** 若解除买卖的六十日指定期间已过，经审查案情，仍可给予诉权。审查时应考虑：卖方是否迟延，是否没有人在场接受返还，或是否存在其他正当原因，致使买方未能在期限内返还其已不满意的奴隶。

<a id="21.1.31.24"></a>

**24.** 在这些诉讼中，对子女、孳息、附属物以及解除已死亡奴隶买卖的规则，均应同样适用。

<a id="21.1.31.25"></a>

**25.** 法学家认为，随买卖标的一并交付的附属物，构成买卖的一部分。

### <a id="21.1.32"></a>21.1.32　盖尤斯《评库鲁尔市政官告示》第二卷

**正文** 因此，正如前文所述，卖方应依市政官告示声明奴隶没有疾病、瑕疵及告示所列其他情形，并且还必须承诺奴隶不具备这些情形；当奴隶作为另一标的的附属物时，卖方也同样必须作出声明和承诺。这不仅适用于明确约定某一名叫斯提库斯的奴隶随地产一并交付的情形，也适用于概括约定地产上的全部奴隶均随买卖一并出售的情形。

### <a id="21.1.33"></a>21.1.33　乌尔比安《评库鲁尔市政官告示》第一卷

<a id="21.1.33.pr."></a>

**序言（pr.）** 因此，庞波尼说，既然约定某物为买卖附属物，就应当如同主要标的那样，以完好状态交付。按照市民法，若约定酒桶等物随地产一并交付，则可提起买卖之诉，要求作为附属物交付的物品完好无缺。但这仅适用于约定交付某一特定物的情形。若出售奴隶时一并出售其特有产，卖方无须保证特有产中的奴隶均健康，因为卖方未承诺交付某一特定奴隶，只承诺交付如此这般的特有产；正如卖方无须保证特有产达到某个确定数额，也无须作此保证。庞波尼说，同一理由也适用于遗产或奴隶的特有产一并出售的情形：市政官告示不适用于遗产或特有产中的各项具体物品。若地产连同设备出售，而奴隶属于设备的一部分，亦应作同样理解。我认为这一意见正确，但若能够证明双方另有特别约定，则不在此限。

<a id="21.1.33.1"></a>

**1.** 若买卖标的被解除买卖，作为其附属物的奴隶也应一并解除买卖，即使该奴隶本身并无任何瑕疵。

<a id="21.1.38"></a>**21.1.38**

<!-- source-p 233 -->
**乌尔比安：《库鲁尔市政官告示评注》第二卷。**

<!-- source-p 234 -->
<a id="21.1.38.pr."></a>**序言。**市政官告示规定：“出售役畜者，应当公开并如实说明每一头役畜患有何种疾病或存在何种瑕疵；役畜若为出售而装饰，应按其出售时的装饰状态交付买受人。未遵守上述规定的，买受人可以请求返还装饰物，或者以装饰物为由解除役畜买卖，期间为六十日；因疾病或瑕疵请求解除买卖的，期间为六个月；请求按较低价格继续购买的，期间为一年。役畜成对一并出售，而其中一头属于应当解除买卖的情形时，我们将给予请求解除两头役畜买卖的诉讼。”

<!-- source-p 235 -->
<a id="21.1.38.1"></a>**1.**市政官在该告示中谈到役畜买卖的解除。

<!-- source-p 236 -->
<a id="21.1.38.2"></a>**2.**该告示的理由与解除奴隶买卖的理由相同。

<!-- source-p 237 -->
<a id="21.1.38.3"></a>**3.**就疾病或瑕疵而言，役畜与奴隶大体适用相同规则。因此，我们在奴隶方面所说的一切，在此也应适用。如果役畜死亡，也可以像奴隶死亡时那样解除买卖。

<!-- source-p 238 -->
<a id="21.1.38.4"></a>**4.**我们来考察，“役畜”一词是否包括所有牲畜。似乎很难说该词涵盖所有牲畜，因为“役畜”与“牲畜”是不同的概念。

<!-- source-p 239 -->
<a id="21.1.38.5"></a>**5.**因此，告示后附有如下补充条款：“我们就役畜健康状况所作的规定，卖方对其他一切牲畜也应遵守。”

<!-- source-p 240 -->
<a id="21.1.38.6"></a>**6.**由此便不再有疑问：该告示也包括牛。更准确地说，“役畜”一词本身并不包括牛，但“牲畜”一词则包括牛。

<!-- source-p 241 -->
<a id="21.1.38.7"></a>**7.**有些情形在人身上会构成疾病，在役畜身上却不一定如此。例如，骡子被阉割，似乎既不患病也无瑕疵，因为这既未削弱其力气，也未降低其用途；毕竟，骡子本来就不能繁殖。凯利乌斯也写道，并非所有被阉割的动物都因此有瑕疵，除非其因阉割而变得虚弱；所以骡子并非有瑕疵。凯利乌斯还记载，奥菲利乌斯认为，阉割过的马仍属健康，正如阉人也可以是健康的一样。但如果买受人不知道、出卖人却知道，就可以提起买受之诉。奥菲利乌斯的意见是正确的。

<!-- source-p 242 -->
<a id="21.1.38.8"></a>**8.**有人问，一头不能与另一头套在一起拉车的母骡是否健康。庞波尼乌斯说是健康的；事实上，许多用于拉车的骡子都不能与另一头配套。

<!-- source-p 243 -->
<a id="21.1.38.9"></a>**9.**他又说，如果某头役畜天生性情或体格如此，以致不能承受另一头牲畜与其配成一组，就不算健康。

<!-- source-p 244 -->
<a id="21.1.38.10"></a>**10.**役畜买卖不仅因疾病或瑕疵可以解除；如果役畜与出卖人所陈述或承诺的情况不符，也可以像奴隶买卖一样解除。

<!-- source-p 245 -->
<a id="21.1.38.11"></a>**11.**凯利乌斯说，役畜只有在出售当时为出售而装饰，才算“为出售而装饰”；并非在出售前一段时间（例如两日前）装饰，就属于这种情况。或者说，役畜因为已经装饰而在出售时被买受人查看，也属于为出售而装饰。告示和诉讼在处理装饰物时一贯附加如下要求：“应系为出售而装饰、带来”；因为役畜也可能先为旅途而装饰带出，之后才出售。

<!-- source-p 246 -->
<a id="21.1.38.12"></a>**12.**如果出售了多头役畜，不会仅因其中一头的装饰物有瑕疵，就必须解除所有役畜的买卖；正如一组役畜中一对有瑕疵，也不因此解除其他各对役畜的买卖。

<!-- source-p 247 -->
<a id="21.1.38.13"></a>**13.**如果一对母骡中有一头存在瑕疵，评估价款差额时，不应只看有瑕疵的一头，而应以这一对骡子为整体进行评估。既然两头是以一个价款出售，就不应拆分各自价格；应考察这对骡子整体出售时价格降低了多少，而非只考察有瑕疵的一头。

<!-- source-p 248 -->
<a id="21.1.38.14"></a>**14.**役畜成对出售时，告示明确规定，其中一头属于应解除买卖的情形，就应解除两头役畜的买卖。此规则兼顾买受人与出卖人的利益，因为役畜不应被拆散。同理，如果出售的是三马车或四马车的成组役畜，也应解除整组买卖。但如果有两对骡子，其中一头骡子或一对中的一头有瑕疵，只解除有瑕疵的那一对，不解除另一对。如果四头骡子尚未组成两对，而是以一个总价简单出售，则只解除有瑕疵那一头的买卖，而非解除全部买卖。出售成组马匹时也是如此：应解除有瑕疵的一匹，而不应解除整组。但对于以一个总价出售的多名奴隶，也适用同一规则，除非他们不可分开，例如一组悲剧演员或哑剧演员。

<a id="21.1.43.1"></a>**1.**奴隶为了向主人的朋友求情而前往朋友处，并不构成逃亡；即使他打算在求情失败时不回家，也尚未构成逃亡，因为“逃亡”一词既指逃离的意图，也指实际逃离行为。

<!-- source-p 266 -->
<a id="21.1.43.2"></a>**2.**奴隶受他人劝诱而离开主人，即使没有劝诱者的建议他原本不会离开，也构成逃亡。

<!-- source-p 267 -->
<a id="21.1.43.3"></a>**3.**如果我的奴隶在他人善意占有时逃跑，无论他知道自己是我的奴隶还是并不知道，均构成逃亡；但如果他是为了回到我身边而离开，则不在此限。

<!-- source-p 268 -->
<a id="21.1.43.4"></a>**4.**奴隶因品行恶劣、习惯不良或实施某种可耻行为而想要自杀的，属于意图自杀；如果他只是因为无法忍受身体疼痛而自杀，则不属于此类。

<!-- source-p 269 -->
<a id="21.1.43.5"></a>**5.**有人买下一名奴隶，该奴隶被抢走后，买受人提起暴力劫掠之诉并取得四倍赔偿，后来又解除买卖，则买受人应返还其已经取得的赔偿。但如果买受人因该奴隶而遭受侮辱，并已提起侮辱之诉，则不应向出卖人返还所得赔偿。若买受人因奴隶被人用鞭子抽打或遭受审讯而起诉，或许应作不同处理。

<!-- source-p 270 -->
<a id="21.1.43.6"></a>**6.**有时，即使买受人提起的是估价之诉，即请求按较低价格继续购买，也仍应解除奴隶买卖。例如，该奴隶毫无价值，以致主人拥有这样的奴隶都无益处，如奴隶是疯子或患有癫痫。此时，即使买受人提起估价之诉，法官仍应依职权命令其返还奴隶，并取回价款。

<!-- source-p 271 -->
<a id="21.1.43.7"></a>**7.**如果有人原本无意解除买卖，只是为了欺诈债权人而解除奴隶买卖，那么出卖人仍应就该奴隶向债权人承担责任。

<!-- source-p 272 -->
<a id="21.1.43.8"></a>**8.**即使奴隶买卖已解除，质押仍继续有效。正如如果买受人已将奴隶或其用益权出卖给他人，除非买回该奴隶或用益权，否则不得解除原买卖；同样，解除买卖时也必须先解除质押。

<!-- source-p 273 -->
<a id="21.1.43.9"></a>**9.**如果附条件购买了某人，在条件成就前提起解除买卖之诉并无效力，因为买卖尚未完成，不能由法官裁量使其解除。因此，即使在条件成就前已经提起买受之诉、出卖之诉或解除买卖之诉，条件成就后仍可再次起诉。

<!-- source-p 274 -->
<a id="21.1.43.10"></a>**10.**有时，即使买卖本身是无条件的，也会因法律上的身份关系而处于待定状态。例如，一个奴隶享有用益权、另一人享有所有权，而该奴隶购买了某物。只要尚不确定价款来自谁的财产，就不确定该物归谁取得，因此任何一方均无权提起解除买卖之诉。

<a id="21.1.51"></a>**21.1.51**

<!-- source-p 308 -->
**阿非利加努斯：《疑问集》第八卷。**

<!-- source-p 309 -->
<a id="21.1.51.pr."></a>**序言。**如果奴隶购买了一名患病或有瑕疵的奴隶，而主人提起解除买卖之诉或买受之诉，阿非利加努斯说，应当始终考察奴隶本人的知情情况，而非主人的知情情况；无论奴隶是以自己的特有产还是以主人的名义购买，也无论主人是否指示其以确定或不确定的方式购买，均如此。因为依据诚信原则，与买受人订立交易的奴隶不应受欺骗；反过来，奴隶在订约时实施的过错也应由主人承担。但如果奴隶奉主人之命购买某人，而主人明知其有瑕疵，出卖人就不承担责任。

<!-- source-p 310 -->
<a id="21.1.51.1"></a>**1.**至于代理人，如果代理人本人知道奴隶患病或有瑕疵，毫无疑问，即使代理人依据委任之诉或无因管理之诉对主人负有责任，也不能因此就该事由提起诉讼。但如果代理人并不知道奴隶有瑕疵，而是奉明知此事的主人之命购买，随后代理人提起解除买卖之诉，阿非利加努斯认为，不应允许出卖人援引以主人身份为根据的准用抗辩。

<a id="21.1.57"></a>**21.1.57**

<!-- source-p 327 -->
**保罗：《疑问集》第五卷。**

<!-- source-p 328 -->
<a id="21.1.57.pr."></a>**序言。**如果奴隶买下另一名奴隶，而主人提起解除买卖之诉，出卖人只有在主人履行该诉所包含的全部义务且足额履行后，才须交付该奴隶；主人不能仅在特有产范围内承担责任。即使主人提起买受之诉，也只有在其付清全部价款后，才能取得相应救济。

<!-- source-p 329 -->
<a id="21.1.57.1"></a>**1.**如果奴隶或家子出售了奴隶，可以在特有产范围内提起解除买卖之诉。特有产中也应计入因解除买卖而产生的返还请求。不要因此认为，在返还奴隶之前，该返还请求尚未构成特有产（毕竟，在奴隶仍属于买受人的时候，他不能被计入特有产）；解除买卖本身产生的请求也应计入特有产。因此，如果奴隶以一万购买、以五千出售，这五千也应计入特有产。但如果奴隶欠主人更多，结果就可能是买受人交还奴隶，却得不到任何返还。

**保罗：《答复集》第五卷。**

<!-- source-p 332 -->
<a id="21.1.58.pr."></a>**序言。**我问：如果奴隶在买受人处逃跑，并被认定属于可以解除买卖的情形，买受人是否须先赔偿奴隶盗取财物的估价，才能把奴隶交还给出卖人？保罗答复说，出卖人应被迫不仅返还奴隶价款，还应赔偿被盗财物的估价；除非出卖人愿意接受该奴隶承担诺克萨责任。

<!-- source-p 333 -->
<a id="21.1.58.1"></a>**1.**我又问：如果买受人不愿支付被盗财物的估价和价款，是否可以留置该奴隶，并提起特有产之诉，或依据双倍担保请求返还已解除买卖的奴隶之价款？保罗答复说，买受人可以依据双倍担保就奴隶价款提起返还之诉；对于被盗财物，先前已经作出答复。

<!-- source-p 334 -->
<a id="21.1.58.2"></a>**2.**我以双倍价款买下一名奴隶，他盗取财物后逃跑。后来奴隶被找到，在诚实可靠的人在场时接受询问，承认自己在出卖人家中也曾逃跑。我问：是否应相信奴隶的答复？保罗答复说，如果另有证据也证实他此前曾逃跑，就应相信奴隶的答复。〔底本文字此处有缺损〕

<a id="21.1.65.pr."></a>**序言。**例如，某人总想看戏或专注地欣赏绘画；或者他爱说谎，或有其他类似缺陷，这些更属于性格缺陷，而非身体缺陷。

<a id="21.1.65.1"></a>**1.**卡西乌斯说，提到严重疾病时，指的是有害的疾病；所谓有害，是指持续性的疾病，而非会随时间结束的疾病。只有在人出生后才发生的疾病，才算严重疾病；因为“有罪者”一词指有害之人。

<!-- source-p 360 -->
<a id="21.1.65.2"></a>**2.**奴隶既可以被称为老练奴隶，也可以被称为新奴隶。凯利乌斯说，判断其是否老练，不应看服役时间长短，而应看其类别与取得原因：任何从新奴隶市场买来、并被安排从事某种劳役的人，立即就属于老练奴隶。所谓新奴隶，并非指心智尚未训练，而是指其奴隶身份的状况。至于他是否会说拉丁语，并不重要；如果他受过自由学科教育，则可以因此称为老练奴隶。
