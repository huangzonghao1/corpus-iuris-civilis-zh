# D.23.3 论嫁资法（*De iure dotium*）

<!-- source-p 001; 原文导航锚点 3、题名锚点 23.3 -->
<a id="3"></a><a id="23.3"></a>**23.3.0　论嫁资法（*De iure dotium*）**

<!-- source-p 002 -->
<a id="23.3.1"></a>**23.3.1**

<!-- source-p 003 -->
**保罗：《评萨宾》第十四卷。**

<!-- source-p 004 -->
嫁资的目的具有持续性；依给付人的意愿设立嫁资时，双方订立安排，使嫁资始终留在丈夫手中。

<!-- source-p 005 -->
<a id="23.3.2"></a>**23.3.2**

<!-- source-p 006 -->
**保罗：《告示评注》第六十卷。**

<!-- source-p 007 -->
保障妇女的嫁资不受损失，符合公共利益；妇女正是由于有嫁资，才得以缔结婚姻。

<!-- source-p 008 -->
<a id="23.3.3"></a>**23.3.3**

<!-- source-p 009 -->
**乌尔比安：《告示评注》第六十三卷。**

<!-- source-p 010 -->
“嫁资”一词不适用于无法成立的婚姻，因为没有婚姻便不可能有嫁资。因此，凡不存在婚姻关系之处，也就不存在嫁资。

<!-- source-p 011 -->
<a id="23.3.4"></a>**23.3.4**

<!-- source-p 012 -->
**保罗：《评萨宾》第六卷。**

<!-- source-p 013 -->
如果向受赠的裸所有权添附用益权，该用益权应视为嫁资的增益，而非另一份嫁资；这与土地因冲积而增加的情形相同。

<!-- source-p 014 -->
<a id="23.3.5"></a>**23.3.5**

<!-- source-p 015 -->
**乌尔比安：《评萨宾》第三十一卷。**

<!-- source-p 016 -->
<a id="23.3.5.pr."></a>**序言。**父亲或其他尊亲属以自己的财产，或通过自己的行为所给付的嫁资，是父系来源的嫁资（*dos profecticia*）。

<!-- source-p 017 -->
<a id="23.3.5.1"></a>**1.**无论是尊亲属本人给付嫁资、其代理人代为给付、尊亲属指示他人给付，还是他人作为尊亲属事务管理人先行给付而后经其追认，该嫁资均属于父系来源的嫁资。

<!-- source-p 018 -->
<a id="23.3.5.2"></a>**2.**如果某人给父亲财物是为了赠与父亲，马尔切鲁斯在《学说汇纂》第六卷中写道，这份嫁资也应视为源自父亲；此说正确。

<!-- source-p 019 -->
<a id="23.3.5.3"></a>**3.**如果精神失常者、挥霍者或其他任何人的监护人代为给付嫁资，我们同样应认为该嫁资是父系来源的嫁资。

<!-- source-p 020 -->
<a id="23.3.5.4"></a>**4.**假设裁判官或行省总督裁定，应从父亲的财产中，或从被俘者、遭强盗袭击者的财产中拨出一定数额给女儿作为嫁资；这份嫁资也应视为父系来源的嫁资。

<!-- source-p 021 -->
<a id="23.3.5.5"></a>**5.**如果父亲为了设立嫁资而放弃继承遗产，例如丈夫被指定为替补继承人，或有人本可依法定继承请求该遗产，尤利安说，这不构成父系来源的嫁资。如果父亲为使遗产留在女婿处、以便设立嫁资而放弃遗赠，尤利安也认为该财产并非源自父亲的财产，因为父亲并未支出自己的财物，而只是没有取得财物。

<!-- source-p 022 -->
<a id="23.3.5.6"></a>**6.**如果父亲并非以父亲身份，而是因他人承诺给付嫁资而提供保证，并以保证人身份履行，涅拉提乌斯说，该嫁资不属于父系来源的嫁资；即使父亲无法向主债务人追回其所支付的款项，亦同。

<!-- source-p 023 -->
<a id="23.3.5.7"></a>**7.**但如果父亲承诺给付嫁资，并指定保证人或主债务人为其履行，我认为该嫁资属于父系来源的嫁资：只要父亲对主债务人或保证人负有债务，就已足够。

<!-- source-p 024 -->
<a id="23.3.5.8"></a>**8.**如果受父权支配的儿子借款后，指定债权人替其女儿给付嫁资，或者儿子本人收取款项后再行给付，涅拉提乌斯说，只要祖父本来就会为孙女设立嫁资，该嫁资即可视为源自祖父；因为此事应视为为祖父的利益而办理。

<!-- source-p 025 -->
<a id="23.3.5.9"></a>**9.**如果有人将确定数额的钱财赠与父亲，并约定父亲须为女儿将其作为嫁资给付，尤利安在《学说汇纂》第十七卷中写道，该嫁资不属于父系来源的嫁资：受赠人负有给付义务；若未给付，则须承担返还之诉的责任。尤利安说，若母亲在此类条件下将财物交给丈夫，要求丈夫为女儿向女婿给付嫁资，结论亦同。严格说来，也不能认为妻子把财物赠与了丈夫；她给付财物并非为了让丈夫据为己有，而是为了让他为女儿将财物支出给女婿；所以，如果丈夫没有给付，就须承担返还之诉的责任。因此，尤利安认为这份嫁资属于其他来源的嫁资（*dos adventicia*）；我们也依此办理。

<!-- source-p 026 -->
<a id="23.3.5.10"></a>**10.**受父权支配的儿子承诺给付嫁资，之后取得自主权并履行承诺的，嫁资仍属于父系来源的嫁资。因为他并非替父亲偿还债务，而是在自己作为受父权支配者时承担了自己的债务；成为家父后，他才清偿该债务。

<!-- source-p 027 -->
<a id="23.3.5.11"></a>**11.**父亲为已脱离父权的女儿给付嫁资，毫无疑问，这仍属于父系来源的嫁资；使其成为父系来源嫁资的不是父权，而是父亲这一身份。但须以父亲是以父亲身份给付为限；如果父亲是因为欠女儿债务，并依女儿意愿给付，则该嫁资属于其他来源的嫁资。

<!-- source-p 028 -->
<a id="23.3.5.12"></a>**12.**帕皮尼安在《疑问集》第十卷说，父亲担任已取得自主权之女儿的监护人并为她设立嫁资时，与其说他是以监护人身份行事，不如说是以父亲身份行事。

<!-- source-p 029 -->
<a id="23.3.5.13"></a>**13.**尤利安在《学说汇纂》第十九卷说，养父亲自给付嫁资的，也有权请求返还。

<!-- source-p 030 -->
<a id="23.3.5.14"></a>**14.**如果某人为他人之女承诺给付嫁资，而该女子的父亲后来成为承诺人的继承人，尤利安区分父亲是在婚前还是婚后继承承诺人，并已给付嫁资：若在婚前继承，应视为嫁资源自父亲，因为父亲本可通知解除婚约安排，从而解除嫁资；若在婚后继承，则该嫁资不属于父系来源的嫁资。

<!-- source-p 031 -->
<a id="23.3.6"></a>**23.3.6**

<!-- source-p 032 -->
**庞波尼乌斯：《评萨宾》第十四卷。**

<!-- source-p 033 -->
<a id="23.3.6.pr."></a>**序言。**法律为父亲提供了救济：女儿去世后，如果父亲所给付的嫁资返还给他，便可聊作慰藉，使他不至于既失去女儿，又蒙受钱财损失。

<!-- source-p 034 -->
<a id="23.3.6.1"></a>**1.**如果父亲将自己善意购买的他人土地作为嫁资给付，该土地也视为源自父亲。

<!-- source-p 035 -->
<a id="23.3.6.2"></a>**2.**如果在给付嫁资时有一方受到欺诈，即使其已年满二十五岁，亦应给予救济；因为一方获利而使另一方受损，或一方因另一方获利而受损，均不符合善良与公平。

<!-- source-p 036 -->
<a id="23.3.7"></a>**23.3.7**

<!-- source-p 037 -->
**乌尔比安：《评萨宾》第三十一卷。**

<!-- source-p 038 -->
<a id="23.3.7.pr."></a>**序言。**公平原则表明，嫁资的孳息应归丈夫所有；既然由丈夫承担婚姻的负担，也应由他取得孳息。

<!-- source-p 039 -->
<a id="23.3.7.1"></a>**1.**婚姻存续期间取得的孳息不属于嫁资；婚前取得的孳息则转化为嫁资，但未来丈夫与预定妻子另有约定的除外。若有此约定，该孳息即视为赠与，不予返还。

<!-- source-p 040 -->
<a id="23.3.7.2"></a>**2.**如果以用益权作为嫁资给付，应当考虑是否须返还孳息。塞尔苏斯在《学说汇纂》第十卷说，应查明当事人约定了什么；如果看不出另有约定，他认为作为嫁资的是用益权本身，而不包括已经取得的孳息。

<!-- source-p 041 -->
<a id="23.3.7.3"></a>**3.**如果将物作为嫁资给付，我认为该物会归入丈夫的财产，并且应准许丈夫承接妻子先前占有的期间。婚姻存续期间给付的物，确会成为丈夫所有。那么，如果在婚前给付，情况如何？如果女子给付时的意思是该物立即归丈夫所有，该物便即刻归其所有；但如果给付附有条件，约定结婚后该物才归其所有，则无疑应认为物在婚姻成立时才归丈夫所有。因此，如果后来没有结婚，而是解除了婚约：如果女子给付时约定该物立即归丈夫所有，那么解除婚约后，她应提起返还之诉请求返还该物；但如果她约定须结婚后该物才归丈夫所有，解除婚约后她可以直接请求确认并取回该物。在解除婚约前若先行请求取回，出卖人可以提出恶意抗辩或事实抗辩；因为已指定作为嫁资的物不应被请求返还。

<!-- source-p 042 -->
<a id="23.3.8"></a>**23.3.8**

<!-- source-p 043 -->
**卡利斯特拉图斯：《疑问集》第二卷。**

<!-- source-p 044 -->
除非明确约定另有安排，否则应当认为，当事人的意思是使物立即成为未婚夫的财产；如果后来没有结婚，物应予返还。

<!-- source-p 045 -->
<a id="23.3.9"></a>**23.3.9**

<!-- source-p 046 -->
**乌尔比安：《评萨宾》第三十一卷。**

<!-- source-p 047 -->
<a id="23.3.9.pr."></a>**序言。**如果我将物交给塞娅，让她以自己的名义将其作为嫁资给付，该物即归她所有，尽管给付时还不是嫁资；但她须承担返还之诉的责任。如果我替她给付财物，则若在婚前给付，要看我以何种条件给付：是立即使受领人取得所有权，还是待婚姻成立后才取得。如果约定立即移转所有权，婚约解除后我可以提起返还之诉；如果约定并非立即移转，我可以请求返还所有权，因为物仍属我所有。因此，如果因婚姻禁令而无法结婚，在后一种情形下，财物仍归我所有。

<!-- source-p 048 -->
<a id="23.3.9.1"></a>**1.**如果我将物交给某人，约定只有结婚后该物才成为嫁资，而我在婚前死亡，婚后该物是否开始成为嫁资？我担心该物不能归受领人所有，因为给付人死亡后，所有权才开始离开其本人；而赠与须待结婚之日才生效，婚姻条件成就时，所有权已属于继承人。未经继承人同意，物的所有权不可能离开继承人。然而，基于维护嫁资的善意原则，应强制继承人同意被继承人所作的安排；若继承人拖延或不在场，即使其不同意，所有权也应依法直接转归丈夫，以免妻子没有嫁资。

<!-- source-p 049 -->
<a id="23.3.9.2"></a>**2.**我们应当将为嫁资目的而给付之物理解为实际给付作嫁资的物。

<!-- source-p 050 -->
<a id="23.3.9.3"></a>**3.**至于财物若被交付为希腊人所称的 *paraferna*、高卢人所称的 *peculium*，我们应当考察这些财物是否立即归丈夫所有。我认为，如果当事人给付时有使其归丈夫所有的意思，该物即归丈夫所有；婚姻解除后，应提起返还之诉，不应请求确认并取回财物，也不得通过嫁资之诉请求返还。神圣的马尔库斯皇帝与我父亲曾以敕答作出此项说明。显然，如果妻子向丈夫交付一份财物清单——正如我们看到的罗马通常做法：妻子将她在丈夫家中日常使用、但未作为嫁资给付的物品列入清单，再把清单交给丈夫签署，仿佛丈夫已收受这些物品；妻子则保留其签署的书证，以证明清单所列财物已被带入丈夫家中——那么，这些物品是否归丈夫所有，仍须考察。我认为它们并不归丈夫所有；并非因为没有交付（毕竟，经丈夫同意把物品带入其家，与交付给他有何区别？），而是因为夫妻之间似乎没有使所有权转移给丈夫的意思；其目的仅在于确定物品已带入丈夫家中，以免日后分居时丈夫否认。丈夫通常还会承诺保管这些物品，除非妻子已将其委托给他。若丈夫不返还这些物品，妻子可以提起何种诉讼？要看丈夫是否承担了保管义务：若承担，可以提起寄托之诉或委任之诉；若未承担，丈夫若有意据为己有，妻子可提起取回被移走物品之诉；若丈夫并未试图移走物品，则可提起出示之诉。

<!-- source-p 051 -->
<a id="23.3.10"></a>**23.3.10**

<!-- source-p 052 -->
**乌尔比安：《评萨宾》第三十四卷。**

<!-- source-p 053 -->
<a id="23.3.10.pr."></a>**序言。**通常，对丈夫而言，不评估嫁资物的价值很重要，这样物品灭失或受损的风险就不会由他承担；尤其是他收受的嫁资为牲畜或妻子使用的衣物时。因为如果物品经过估价而后被妻子磨损，即使如此，丈夫仍须支付其估价额。因此，作为嫁资给付的物品若未经估价，无论价值增加还是减少，利益和损失均归妻子。

<!-- source-p 054 -->
<a id="23.3.10.1"></a>**1.**未经估价的嫁资土地若有增益，归妻子受益；若有减损，则由妻子承担损失。

<!-- source-p 055 -->
<a id="23.3.10.2"></a>**2.**奴隶生下后代，不构成丈夫的获利。

<!-- source-p 056 -->
<a id="23.3.10.3"></a>**3.**但是，作为嫁资给付的牲畜所生幼畜归丈夫所有，因为幼畜按孳息计算；不过，应先补足牲畜原有的数量。以死去牲畜的后代补入其数后，剩余的幼畜才归丈夫作为孳息，因为嫁资的孳息归他所有。

<!-- source-p 057 -->
<a id="23.3.10.4"></a>**4.**如果嫁资物在婚前经过估价，该估价只是附条件的，因为所附条件是“婚姻成立”。婚姻成立后，物品估价才最终确定，并转化为真正的买卖。

<!-- source-p 058 -->
<a id="23.3.10.5"></a>**5.**由此可以进一步询问：如果奴隶在婚前经估价后灭失，是否应由妻子承担损失？结论应当是如此。因为这是一项附条件的买卖，条件未成就期间若发生死亡，即使买卖消灭；因此应说奴隶灭失的损失由妻子承担，因为买卖尚未完成；估价在此即为买卖。

<!-- source-p 059 -->
<a id="23.3.10.6"></a>**6.**如果物品即使经过估价仍作为嫁资给付，但当事人约定应给付估价额或返还物品，那么，若双方补充约定“由妻子选择”，妻子可以选择请求物品或估价额；若补充约定“由丈夫选择”，则由丈夫选择。若未约定由谁选择，应由丈夫选择给付物品还是其价款；如承诺给付的是两种物品之一，通常也由债务人选择其一给付。但如果物品已不存在，丈夫无论如何都应给付估价额。

<!-- source-p 060 -->
<a id="23.3.11"></a>**23.3.11**

<!-- source-p 061 -->
**保罗：《评萨宾》第七卷。**

<!-- source-p 062 -->
丈夫当然也可以返还已经变差的物品。

<!-- source-p 063 -->
<a id="23.3.12"></a>**23.3.12**

<!-- source-p 064 -->
**乌尔比安：《评萨宾》第三十四卷。**

<!-- source-p 065 -->
<a id="23.3.12.pr."></a>**序言。**如果婚姻成立后，丈夫同意以赠与为由保留一件经估价作为嫁资给付的物品，该估价无效；因为夫妻之间的赠与不发生效力，物品也不能因此被视为已出售。因此，该物品仍属于嫁资。但如果在婚前作出这种安排，更应认为赠与被推迟到婚姻成立时生效；因此，该赠与无效。

<!-- source-p 066 -->
<a id="23.3.12.1"></a>**1.**如果妻子称自己受到欺骗，因而将奴隶按低于其价值估价，应区分她受欺骗之处：若欺骗在于她交付了奴隶，而不仅在于估价过低，她可以请求返还奴隶；若她仅在估价数额上受欺骗，则由丈夫选择给付公允估价额还是返还奴隶。以上以奴隶仍然存活为前提。若奴隶已经死亡，马尔切鲁斯说，更应给付估价额，但应按当时作出的估价给付，而非按公允价值给付；妻子应当接受当初估价的结果。否则，如果妻子只是直接给付奴隶而未作估价，奴隶死亡的风险无疑由妻子而非丈夫承担。马尔切鲁斯也认可，对未满二十五岁者所受的欺骗，应作同样处理。不过，如果妻子已有愿以公允价格购买该奴隶的人选，则应认为须给付公允估价额；马尔切鲁斯写道，这仅适用于未成年妻子。斯凯沃拉则指出，如果丈夫有恶意，就应给付公允估价额；我认为斯凯沃拉的意见更为正确。

<!-- source-p 067 -->

<a id="23.3.43.pr."></a>**序言。**嫁资通常可以通过免除债务而设立；但是，如果免除债务发生在婚前，而婚姻并未成立，斯凯沃拉说，为婚姻目的所作的免除因婚姻未成立而无效，原债务仍应依其本来状态存续；此说正确。

<!-- source-p 167 -->
<a id="23.3.43.1"></a>**1.**第三人以设立嫁资为目的，免除了妻子债务人的债务；如果婚姻没有成立，债务人不会因此获得解除，除非第三人的意思是将该款项完全赠与妻子。若是如此，应认为第三人是先从妻子处收取，再转交给丈夫；除此之外，妻子不能通过自由人取得返还之诉。

<!-- source-p 168 -->
<a id="23.3.43.2"></a>**2.**婚姻成立后，婚姻解除时，妻子可以请求追索嫁资；但若第三人免除债务时的意思是，无论婚姻以何种方式解除，返还之诉均由其本人享有，则妻子不享有诉权。依此，如果通过免除债务设立嫁资且婚姻成立，其法律效果如下：若被免除的债务为无期限债务，该债务不必恢复原状，而应依嫁资所定期限给付。若该债务附有期限，且婚姻解除前期限尚未届满，则应恢复原期限的债务；若原债务附有保证，也应重新提供保证。同样，如果转作嫁资的债务附有条件，且婚姻在条件未成就时解除，较可取的意见是恢复原条件下的债务；但如果条件在婚姻存续期间成就，追索期限应从离婚之日起计算。

<!-- source-p 169 -->
<a id="23.3.44"></a>**23.3.44**

<!-- source-p 170 -->
**尤利安：《学说汇纂》第十六卷。**

<!-- source-p 171 -->
<a id="23.3.44.pr."></a>**序言。**如果父亲代表女儿承诺给付嫁资，而后在婚前使女儿脱离父权，该承诺并不因此解除；正如父亲在婚前死亡时，其继承人仍依该承诺负有债务。

<!-- source-p 172 -->
<a id="23.3.44.1"></a>**1.**如果一名女子的债务人是受父权支配的儿子，而她向该儿子的父亲承诺：“你欠我的，或你儿子欠我的，将作为给付给你的嫁资”，该承诺并不产生新的债务；但原先可以通过特有产之诉向父亲追索的部分，得作为嫁资。马尔切鲁斯说：因此，如果女子此后起诉儿子或其父亲，二人均可提出约定抗辩；但若她提起嫁资之诉，可以取得在承诺嫁资时属于特有产的部分；当然，前提是嫁资在婚后承诺。若在婚前承诺，则应以婚姻成立时特有产的状况为准。

<!-- source-p 173 -->
<a id="23.3.45"></a>**23.3.45**

<!-- source-p 174 -->
**特里丰尼努斯：《论辩》第八卷。**

<!-- source-p 175 -->
<a id="23.3.45.pr."></a>**序言。**如果女子将要嫁给受父权支配的债务人之子，并承诺仅将她对该子享有的特有产之诉权作为嫁资，则应考察婚姻成立时该原因所产生的债务数额。

<!-- source-p 176 -->
<a id="23.3.45.1"></a>**1.**如果她将要嫁给他人，却指示受父权支配的债务人之子以特有产为嫁资作出承诺，则应考察承诺嫁资之时的特有产，以确定当时有多少财产属于其中。

<!-- source-p 177 -->
<a id="23.3.46"></a>**23.3.46**

<!-- source-p 178 -->
**尤利安：《学说汇纂》第十六卷。**

<!-- source-p 179 -->
<a id="23.3.46.pr."></a>**序言。**正如奴隶即使违背主人的意愿而作出要式承诺，仍可为主人取得权利一样，如果奴隶允许他人以其主人名义向自己承诺嫁资，该项债务也为主人取得。但主人不必承担风险，例如妻子的债务人承诺给付嫁资时，主人不负责任；主人也不必承担过失责任。即使嫁资物交付给奴隶或受父权支配的儿子，嫁资仍得以设立，所有人或父亲同样不承担风险或过失责任。因此，我认为，在所有人或父亲追认该承诺或赠与期间，这份嫁资的风险由妻子承担；即使婚姻仍在继续，妻子也可以通过返还之诉请求取回已交付的物品，并可通过不确定给付返还之诉，取得免除该项承诺的救济。

<!-- source-p 180 -->
<a id="23.3.46.1"></a>**1.**如果女子将要嫁给自己的债务人，并承诺：“你欠我的钱，或塞姆普罗尼乌斯农庄，将作为你的嫁资”，则由女子选择何者成为嫁资。如果她希望丈夫保有对她的债务，她可以对丈夫请求该农庄时援用抗辩；如果她给付了农庄，则可以向丈夫提起返还之诉，请求返还金钱。

<!-- source-p 181 -->
<a id="23.3.46.2"></a>**2.**父亲即使错误地认为自己欠女儿债务，并据此承诺给付嫁资，仍须承担债务。

<!-- source-p 182 -->
<a id="23.3.47"></a>**23.3.47**

<!-- source-p 183 -->
**尤利安：《学说汇纂》第十八卷。**

<!-- source-p 184 -->
婚前将奴隶作为嫁资给付后，若有人在婚前又向该奴隶赠与或遗赠财物，嫁资便因此增加；这与婚前交付土地后，该土地产生孳息的情形相同。

<a id="23.3.48"></a>**23.3.48**

<!-- source-p 186 -->
**尤利安：《评乌尔塞乌斯·费罗克斯》第二卷。**

<!-- source-p 187 -->
<a id="23.3.48.pr."></a>**序言。**如果要式承诺如此订立：“你是否承诺在下一年内以嫁资名义给付十个钱币？”问题是，一年应从何时起算：从订立要式承诺之日，还是从嫁资可能成立之日，也就是婚姻之日？答复说，一年应从婚姻之日起计算；否则，若婚姻未在一年内成立，可能会被误认为该项债务虽源自该要式承诺，仍应作为嫁资给付。

<!-- source-p 188 -->
<a id="23.3.48.1"></a>**1.**岳父曾遗赠如下：“我的继承人应以我女儿之名向卢基乌斯·提提乌斯给付一百个钱币。”普罗库鲁斯答复说，女婿应请求给付该款；他收取后，该款按遗赠处理，但若婚姻解除，应依据嫁资之诉返还给妻子，而且该款仍已构成嫁资。尤利安批注说，即使女儿本人希望提起此类诉讼，也不应拒绝她。

<!-- source-p 189 -->
<a id="23.3.49"></a>**23.3.49**

<!-- source-p 190 -->
**尤利安：《摘录米尼基乌斯》第五卷。**

<!-- source-p 191 -->
丈夫向一名有意为其妻给付嫁资的人承诺给付特定款项，之后又免除了该项债务。问题是，这笔钱是否属于嫁资？答复说，如果丈夫没有免除债务，而承诺人后来变得无清偿能力，我们会考察丈夫是否因过错没有收取该款。既然丈夫已经免除债务，风险无论如何都由丈夫承担；这就如同丈夫收取了款项后，又将同一款项赠与承诺人。

<!-- source-p 193 -->

<a id="23.3.50.pr."></a>**序言。**一名曾将农庄作为嫁资的女子离婚后，又与丈夫复婚；她与丈夫约定，丈夫收取十个钱币作为嫁资，并将农庄返还给她。女子交付十个钱币后，农庄尚未返还，她便在婚姻存续期间死亡。依诚信原则及双方所订事务，应允许请求返还农庄，因为丈夫如今持有该农庄已无任何原因。

<a id="23.3.53"></a>**23.3.53**

<!-- source-p 203 -->
**涅拉提乌斯：《札记》第三卷。**

<!-- source-p 204 -->
丈夫希望赠与妻子，但妻子的债务人无清偿能力，却向丈夫承诺给付嫁资。在债务人有能力清偿的范围内，该债务由丈夫承担风险；如果债务人的清偿能力有所增加，丈夫承担的风险也相应增加，即使债务人后来再次变得贫困，已经增加的风险仍继续存在。因为在承诺嫁资时，赠与只涉及债务人无力清偿的那部分；而债务人后来恢复清偿能力时，该财物便不再属于赠与。其情形应如同债务人在最初承诺嫁资时就有清偿能力一样。

<!-- source-p 211 -->
<a id="23.3.56"></a>**23.3.56**

<!-- source-p 212 -->
**保罗：《评普劳提乌斯》第六卷。**

<!-- source-p 213 -->
<a id="23.3.56.pr."></a>**序言。**如果一名欠女子奴隶斯提库斯的人被指定向丈夫给付该奴隶作为嫁资，而债务人尚未给付时斯提库斯便死亡；既非债务人阻止给付，也非丈夫请求给付时迟延，那么斯提库斯的死亡风险由妻子承担。即使丈夫请求给付时确有迟延，只要斯提库斯即使由丈夫占有也会死亡，丈夫仍不须依据嫁资之诉承担责任。

<!-- source-p 214 -->
<a id="23.3.56.1"></a>**1.**嫁资应当归于承担婚姻负担之人。

<!-- source-p 215 -->
<a id="23.3.56.2"></a>**2.**父亲死亡后，婚姻的负担立即由儿子承担，正如子女和妻子的生活负担也随之由其承担。

<!-- source-p 216 -->
<a id="23.3.56.3"></a>**3.**所谓必要费用依法减少嫁资，并不意味着嫁资土地会有一部分不再属于嫁资；而是如果费用没有偿还，丈夫可以保留土地的一部分或全部。但若为嫁资土地支付的分项必要费用已经达到土地全部价值，我们的斯凯沃拉说，除非妻子自愿在一年内向丈夫提供费用，否则该土地不再属于嫁资。如果嫁资既包括金钱也包括土地，而必要费用用于该土地，涅尔瓦说，金钱部分的嫁资会减少。那么，如果妻子向丈夫偿还费用，嫁资是因此增加，还是应视为重新给付？依我们斯凯沃拉的意见，土地方面的结果尤其明显地不公平：土地若不再属于嫁资，便可能被出售；但怎么可能仅因给付金钱，土地就重新成为嫁资？或者，金钱是否应视为此时才成为嫁资的一部分？更可取的意见是，土地应恢复嫁资的法律性质，但在此期间应禁止出售该土地。

<!-- source-p 217 -->
<a id="23.3.57"></a>**23.3.57**

<!-- source-p 218 -->
**雅沃列努斯：《摘录普劳提乌斯》第一卷。**

<!-- source-p 219 -->
女子将要嫁给受父权支配的儿子，并向岳父承诺：“你儿子欠我的，将作为给付给你的嫁资。”我认为应当区分，这项承诺指的是儿子本人的债务，还是父亲基于特有产之诉或所得利益之诉所负的责任。如果指儿子应给付之物，则儿子所负的全部债务都包括在嫁资承诺中；但如果指父亲应基于特有产或所得利益承担的责任，则应评估承诺时该责任的数额，以确定当时父亲应以儿子名义被判承担多少金额。如果无法清楚查明女子是针对谁的债务作出承诺，应推定她针对的是儿子的债务，除非有明确证据证明并非如此。

<a id="23.3.58"></a>**23.3.58**

<!-- source-p 221 -->
**塞尔苏斯：《学说汇纂》第十九卷。**

<!-- source-p 222 -->
<a id="23.3.58.pr."></a>**序言。**如果在订立婚约之前，你已以塞娅的名义向提提乌斯承诺给付嫁资，尽管她当时不愿嫁给提提乌斯，但她后来若与提提乌斯结婚，你仍须给付嫁资；若其间另有婚姻，则不在此限。

<!-- source-p 223 -->
<a id="23.3.58.1"></a>**1.**如果女子向提提乌斯要式承诺取得女奴潘菲拉，之后将要嫁给他，并允许其将欠自己的债务作为嫁资，那么，即使潘菲拉并非该男子所有，潘菲拉本人是否仍属于嫁资，且由女子承担风险？她所生子女是否也应返还给女子？如果原先的要式承诺仍按其本来债务关系存续，子女便不会被返还。除非还须考察：设立嫁资时，丈夫是否实际取得了所欠之物；若已取得，则可以认为该物本身已归其所有。若未取得，则更应认为只有债务得到免除，而非该物本身已归其所有；因此，潘菲拉所生子女不必返还。

<!-- source-p 224 -->
<a id="23.3.59"></a>**23.3.59**

<!-- source-p 225 -->
**马尔切鲁斯：《学说汇纂》第七卷。**

<!-- source-p 226 -->
<a id="23.3.59.pr."></a>**序言。**如果女子如此承诺嫁资：“十个钱币将作为给付给你的嫁资，或给付给提提乌斯”，则可以认为，此时允许向提提乌斯给付，但丈夫仍须对嫁资承担责任，就如同女子指示向提提乌斯给付一样。这并不奇怪：女子即使承诺向丈夫给付嫁资，也可以在丈夫指示下向他人作出承诺，尽管通常认为，女子不能以嫁资名义对丈夫以外之人负债。在这些情形下，嫁资都是为丈夫设立的。我们不应认为，女子作出此种承诺时，曾考虑过嫁给提提乌斯。

<!-- source-p 227 -->
<a id="23.3.59.1"></a>**1.**某人被指定为全部遗产的继承人，并被嘱托将遗产四分之三返还给一名女子；他依女子指示，向丈夫承诺以其所欠之债作为嫁资。我担心他并未因此负有责任：他对女子负有的义务，是返还遗产，并通过返还遗产移转自己享有的诉权以及自己所受拘束的诉权；但他不能将这些诉权移转给遗嘱信托受益人以外的人。有人或会说，可以对他提起不确定给付之诉，请求给付遗嘱信托的估价额。我不能赞同此说：只有在丈夫可以取得女子所应得的同一财物时，才可公平地使女子的债务人对丈夫负有责任。为了不使女子没有嫁资，应当规定：依据《特雷贝利亚努斯元老院决议》，将遗嘱留给女子的遗产份额返还给她，由她再作为嫁资给付丈夫；因为遗嘱信托的权利及负担均属于她。鉴于这一特殊情形的必要性，不应拘泥于债务移转形式过于精细的要求。

<!-- source-p 228 -->
<a id="23.3.59.2"></a>**2.**如果你以一名看似自由的女子名义给付十个钱币作为嫁资，你可以在与以下情形相同的条件下提起返还之诉：如果你以一名自由女子名义给付财物，而婚姻未成立。如果该女子后来获释并与你结婚，只有在你给付时意在婚姻最终成立后将该款作为嫁资的情况下，才构成嫁资。因此，如果你给付财物是为了赠与女子，则真正物主可以提起返还之诉；这与有人本想赠与女子，却由女子指示其直接向自己赠与相同。

**塞尔苏斯：《学说汇纂》第十一卷。**

<!-- source-p 231 -->
我问：监护人同意已成年的女子承诺给付嫁资时，应当准许她承诺多少金额？答复说，应当根据女子的财产状况与身份地位，以及丈夫的身份状况，在合理限度内确定金额。

<a id="23.3.61"></a>**23.3.61**

<!-- source-p 233 -->
**克莱门提乌斯：《尤利亚法与帕皮亚法评注》第三卷。**

<!-- source-p 234 -->
<a id="23.3.61.pr."></a>**序言。**无论设立的是一般监护人，还是专为给付嫁资而设的监护人，如果承诺的嫁资超过女子的财产能力，该承诺依法无效，因为法律不承认以恶意作出的授权。仍须考察：是全部债务无效，还是仅超过应许诺数额的部分无效？较为有益的意见是，仅使超出部分无效。

<!-- source-p 235 -->
<a id="23.3.61.1"></a>**1.**该监护人应当以物品设立嫁资，而非将物品卖给他人、再将价款作为嫁资给付。对此仍可提出疑问：如果女子除以金钱作为嫁资外，便无法体面地结婚，而且以金钱给付对她更为有利，情况又如何？何况，嫁资物通常可以出售，并将价款转作嫁资。为解决此问题，如果丈夫愿意收受物品作为嫁资，就无须再作讨论；但如果丈夫不接受以物品设立嫁资，除非以金钱给付，则监护人应向任命他的同一法官提出申请；该法官审查情况后，即使丈夫缺席，也可再次准许监护人出售物品并设立嫁资。

<!-- source-p 236 -->
<a id="23.3.62"></a>**23.3.62**

<!-- source-p 237 -->
**莫德斯蒂努斯：《答复》第五卷。**

<!-- source-p 238 -->
提提娅未满二十五岁时，将她与兄弟们共有的母亲遗产四分之一份额作了交换，并通过类似买卖的安排取得一处农庄；她随后将该农庄及其他物品作为嫁资给付。我问：如果准许她恢复原状、取回自己的四分之一份额并返还该农庄，丈夫应当如何处理？是否只须保留其他嫁资物品即可？我还问：如果提提娅去世，她的继承人以她的身份请求恢复原状，要求取回四分之一份额并将农庄返还给兄弟，丈夫是否必须返还农庄，而仅保留其他嫁资物品所带来的利益？莫德斯蒂努斯答复说，没有理由夺走丈夫的嫁资；但女子或其继承人应按农庄的真实估价承担责任，估价应以农庄作为嫁资给付时为准。

<!-- source-p 239 -->
<a id="23.3.63"></a>**23.3.63**

<!-- source-p 240 -->
**莫德斯蒂努斯：《法学发现》单卷。**

<!-- source-p 241 -->
第三人承诺返还嫁资的要式承诺，在离婚时即告触发；即使婚姻恢复，承诺权利人已经取得的诉权也不会消灭。因此，应经承诺人再次同意，重新设立嫁资，以免女子在后一婚姻中没有嫁资。但如果嫁资原本由女子本人给付，只是另一人经她许可作出承诺，则不需要她再次同意。

<!-- source-p 242 -->
<a id="23.3.64"></a>**23.3.64**

<!-- source-p 243 -->
**雅沃列努斯：《摘录卡西乌斯》第四卷。**

<!-- source-p 244 -->
离婚时丈夫没有就嫁资提供任何担保；女子后来嫁给他人，之后又回到前夫身边，则该嫁资应视为默示恢复。

<!-- source-p 245 -->
<a id="23.3.65"></a>**23.3.65**

<!-- source-p 246 -->
**庞波尼乌斯：《评昆图斯·穆基乌斯》第五卷。**

<!-- source-p 247 -->
如果遗赠或继承使嫁资奴隶取得财物，而立遗嘱人不愿该财物归丈夫所有，则婚姻解除后应将其返还给妻子。

<!-- source-p 248 -->
<a id="23.3.66"></a>**23.3.66**

<!-- source-p 249 -->
**庞波尼乌斯：《评昆图斯·穆基乌斯》第八卷。**

<!-- source-p 250 -->
如果我从土地所有权人处取得该土地的用益权作为嫁资，而妻子原本并不拥有该土地的所有权，那么离婚后将该权利返还妻子会遇到困难。我们曾说，用益权人只能将用益权让与土地所有权人；如果让与给他人，也就是不享有所有权的人，则用益权不会移转给受让人，而会回归土地所有权人。因此，有人正确地认为，应当引入一种救济方式：丈夫可以将该用益权出租给妻子，或者以一个钱币的价格卖给她；这样，用益权本身仍由丈夫保有，孳息的取得则归妻子。

<!-- source-p 251 -->
<a id="23.3.67"></a>**23.3.67**

<!-- source-p 252 -->
**普罗库鲁斯：《书信》第七卷。**

<!-- source-p 253 -->
普罗库鲁斯致其侄孙问候。女奴结婚后，以嫁资名义将钱款交给丈夫；无论她知道自己是女奴还是对此不知情，都不能使丈夫取得该款所有权。该款仍属于交付给丈夫之前的物主，除非丈夫已通过取得时效取得该款。即使后来她在同一丈夫处获得自由，也不能改变该款的法律性质。因此，即使离婚，她也不能依据嫁资规则或返还之诉正当地请求该款；真正物主则可以正当地提起返还原物之诉。如果丈夫作为自己的财物占有该款并通过取得时效取得之，显然是因为他误以为女子是自由人；我更倾向于认为丈夫因此取得该款，尤其是在婚姻开始之前已经完成取得时效的情形。如果他在该款成为嫁资之前用它购置了物品，我也持同样意见；但须以丈夫既未占有该物，也未出于恶意使自己无法占有为限。

<!-- source-p 254 -->
<a id="23.3.68"></a>**23.3.68**

<!-- source-p 255 -->
**帕皮尼安：《疑问集》第十卷。**

<!-- source-p 256 -->
如果父亲起初不知情，婚姻便未成立，但之后父亲表示同意，那么，嫁资承诺不会因此无效，因为所有嫁资承诺都默含未来婚姻成立这一条件。例如，未满十二岁的女孩若被当作成年妇女带入丈夫家中，只有在她年满十二岁并开始与同一男子共同生活时，才可请求嫁资。通常说，嫁资承诺仅为第一次婚姻而设；如果女子后来嫁给他人，再与承诺嫁资之人结婚，该债务便不继续存续。此说仅适用于其间确已另行结婚的情形。

<!-- source-p 257 -->
<a id="23.3.69"></a>**23.3.69**

<!-- source-p 258 -->
**帕皮尼安：《答复》第四卷。**

<!-- source-p 259 -->
<a id="23.3.69.pr."></a>**序言。**离婚后，丈夫知情而妻子仍长期占有其承诺作为嫁资给付的土地，应视为双方默示约定不再请求该嫁资。若丈夫开始请求嫁资，妻子可以援用约定抗辩使其请求被驳回。

<!-- source-p 260 -->
<a id="23.3.69.1"></a>**1.**妻子在承诺嫁资时，说明其对塞伊乌斯享有的债权包括未来期间的利息；其中在婚后到期的利息也属于嫁资的一部分，这一意见是合理的。

<!-- source-p 261 -->
<a id="23.3.69.2"></a>**2.**如果婚姻解除后，嫁资利息连同嫁资本金被纳入要式承诺，已有意见认为，从第二次婚姻之日起不必给付利息，因为本金也尚未开始收取；但中间期间的利息仍须给付。

<!-- source-p 262 -->
<a id="23.3.69.3"></a>**3.**妻子被送入丈夫的住宅时，丈夫不在场；在此期间，丈夫的财产没有用于妻子的任何开支。丈夫回来后，仍请求妻子为生活供养而承诺的利息，这是不当的。

<!-- source-p 263 -->
<a id="23.3.69.4"></a>**4.**女婿向岳父订立要式承诺，约定嫁资应在某一确定日期按岳父的裁量给付，但未说明具体财物或数额。已有意见认为，即使排除岳父的裁量，该承诺仍然有效。此情形与未说明土地标的便无法成立土地遗赠或要式承诺并不相同，因为确定嫁资数额与标的物本身不明之间存在重大差异：嫁资数额可以依父亲的财产能力及丈夫的身份地位确定。

<!-- source-p 264 -->
<a id="23.3.69.5"></a>**5.**如果父亲同意女儿与其监护人的儿子结婚，监护人可以按照女儿的财产能力及出生身份，正当地为她设立嫁资。

<!-- source-p 265 -->
<a id="23.3.69.6"></a>**6.**如果被释女忘恩负义，其女保护人不得扣留依法承诺给她的嫁资。

<!-- source-p 266 -->
<a id="23.3.69.7"></a>**7.**如果约定婚姻解除时返还经估价作为嫁资给付的物品，则只是确定金额，并未成立买卖。因此，物品遭到追夺时，如果妻子是善意给付，丈夫没有诉权；否则，丈夫须对恶意承担责任。

<!-- source-p 267 -->
<a id="23.3.69.8"></a>**8.**经估价并交付作为嫁资的物品，即使妻子继续使用，也应视为所有权已经归丈夫。

<!-- source-p 268 -->
<a id="23.3.69.9"></a>**9.**嫁资女奴所生子女属于嫁资的一部分；因此，丈夫约定子女由妻子与自己共有，是徒劳无效的。

<!-- source-p 269 -->
<a id="23.3.70"></a>**23.3.70**

<!-- source-p 270 -->
**保罗：《疑问集》第六卷。**

<!-- source-p 271 -->
在含义不明的情形下，作有利于嫁资的答复更为妥当。

<!-- source-p 272 -->
<a id="23.3.71"></a>**23.3.71**

<!-- source-p 273 -->
**保罗：《疑问集》第十三卷。**

<!-- source-p 274 -->
如果第三人以妇女名义承诺给付嫁资，风险由妇女承担；但如果丈夫追索该债权并收取利息，据答复，风险便转由丈夫承担。

<!-- source-p 275 -->
<a id="23.3.72"></a>**23.3.72**

<!-- source-p 276 -->
**保罗：《答复》第八卷。**

<!-- source-p 277 -->
<a id="23.3.72.pr."></a>**序言。**妇女将自己的全部财产作为嫁资给付。我问：丈夫是否应当像继承人一样，对这些财产的负担承担责任？保罗答复说，丈夫若依据返还嫁资的承诺保有了妇女的全部财产，妇女的债权人不能因此起诉丈夫；但财产承诺所及的范围，不得超过扣除债务后所剩的财产。

<!-- source-p 278 -->
<a id="23.3.72.1"></a>**1.**保罗答复说，对于嫁资物品，丈夫的父亲也应对恶意和过失承担责任。

<!-- source-p 279 -->
<a id="23.3.72.2"></a>**2.**保罗答复说，若妇女以自己的财产给付嫁资，并请母亲为该嫁资订立要式承诺，她后来可以变更嫁资文书。

<!-- source-p 280 -->
<a id="23.3.73"></a>**23.3.73**

<!-- source-p 281 -->
**保罗：《判决集》第二卷。**

<!-- source-p 282 -->
<a id="23.3.73.pr."></a>**序言。**哑者、聋者和盲者均可因嫁资承诺而负担债务，因为他们也可以缔结婚姻。

<!-- source-p 283 -->
<a id="23.3.73.1"></a>**1.**婚姻存续期间，妻子可为下列事项请求返还嫁资，而不因此丧失嫁资：供养自己及家人、购买适当的农庄、供养被放逐或流放至岛上的父母，或扶助贫困的丈夫、兄弟或姐妹。

<!-- source-p 284 -->
<a id="23.3.74"></a>**23.3.74**

<!-- source-p 285 -->
**赫莫革尼安：《法学概要》第五卷。**

<!-- source-p 286 -->
未婚妻给付嫁资后未能结婚，或未满十二岁却被当作妻子对待时，基于保护嫁资的考虑，已有意见认为，应类推嫁资返还之诉的规则，给予她优先受偿的特权；该特权属于人身诉讼债权中的优先权。

<!-- source-p 287 -->
<a id="23.3.75"></a>**23.3.75**

<!-- source-p 288 -->
**特里丰尼努斯：《争论集》第六卷。**

<!-- source-p 289 -->
尽管嫁资属于丈夫的财产，它仍然是妇女的财产；因此，如果妇女将未经估价的农庄作为嫁资给付，并就该农庄取得双倍担保要式承诺，而后该农庄遭到追夺，她应当可以立即依据要式承诺起诉。进一步说，妇女有利益使嫁资物不遭追夺；她之所以被认为遭受追夺，是因为该物已不再作为嫁资由她享有。即使婚姻仍在存续，虽然农庄所有权在丈夫手中，她仍应被认为享有利益；丈夫也正是因此承担婚姻的负担。

<!-- source-p 290 -->
<a id="23.3.76"></a>**23.3.76**

<!-- source-p 291 -->
**特里丰尼努斯：《争论集》第九卷。**

<!-- source-p 292 -->
如果女子的父亲为自己死亡之事承诺给付嫁资，该承诺有效；因为他即使承诺在自己死亡时给付，也会因此负有债务。但如果父亲后来康复，为什么不允许其通过返还之诉解除该项债务？这与他人向要求给付者承诺，或以他人名义承诺给付嫁资相同。正如已经移转的物品或金钱可以提起死亡原因返还之诉，已经设立的债务也可以提起同一返还之诉。若由女子本人以自己死亡为条件承诺给付嫁资，结论则不同；因为嫁资若不用于承担婚姻负担，便不构成嫁资。

<!-- source-p 293 -->
<a id="23.3.77"></a>**23.3.77**

<!-- source-p 294 -->
**特里丰尼努斯：《争论集》第十卷。**

<!-- source-p 295 -->
如果女子将嫁给自己的债务人，并承诺将该债务作为嫁资，那么婚姻成立后所产生的利息不属于嫁资；因为原债务已全部消灭，这就如同债务已经清偿，而女子再将所收款项作为嫁资给付。

<!-- source-p 296 -->
<a id="23.3.78"></a>**23.3.78**

<!-- source-p 297 -->
**特里丰尼努斯：《争论集》第十一卷。**

<!-- source-p 298 -->
<a id="23.3.78.pr."></a>**序言。**如果妻子对丈夫的农庄享有用益权，并以嫁资名义将该用益权交给丈夫，尽管用益权因此离开妻子，丈夫取得的并不是一个独立的用益权，而是像所有人那样使用自己的农庄；他通过嫁资取得了整个农庄的所有权，而不是附有独立用益权的所有权。因此，丈夫不会因为不行使用益权而丧失该权利。离婚时，丈夫应在同一农庄上为妻子设立用益权。如果妻子在婚姻存续期间死亡，丈夫似乎不能因此取得嫁资利益；因为即使他未娶该妻，用益权也会因用益权人的死亡而终止，并回归所有权。因此，丈夫也不应因妻子的丧葬费用而扣留该项利益。

<!-- source-p 299 -->
<a id="23.3.78.1"></a>**1.**如果父亲为了给女儿设立嫁资，将自己对女婿农庄享有的用益权给付出去，而女儿在婚姻存续期间死亡，父亲可以以自己的名义请求用益权。

<!-- source-p 300 -->
<a id="23.3.78.2"></a>**2.**如果妻子为了设立嫁资，在自己的农庄上为丈夫设立用益权，该用益权便归丈夫本人；他可能因不行使而丧失用益权。若发生这种情形，还须考察妻子是否仍有嫁资。若农庄所有权仍属于妻子，用益权因丧失而回归所有权并与之合并，则妻子已无任何嫁资可通过嫁资之诉向丈夫请求；不能将丈夫因未行使用益权而丧失该权利归责于他，因为妻子反而因此获利；所以她将没有嫁资。若妻子将所有权转让给他人，所有权虽变得完整，妻子却没有得到任何利益，她仍然享有嫁资，因为丈夫应受嫁资之诉追究：在可以行使用益权时，他因不行使而使其丧失。假使丈夫一直保有用益权直到离婚，返还用益权便会使妻子受益；即使该权利不会立即移转给她，也仍可以有偿或以其他方式，在不使妻子受损的情况下使其与所有权合并。若丈夫未丧失用益权，妻子死亡本身并不使丈夫享有的用益权终止。离婚后，无论在本款还是前述情形下，还应考察该年度的孳息是否按时间比例分配；应当肯定这一点。用益权本身应当如此返还：如果妻子拥有该农庄，就将用益权让与她，使之与所有权合并。即使妻子并非土地所有人，仍享有嫁资之诉，可以要求丈夫放弃用益权；因为妻子仍可能基于买受之诉负有提供用益权的义务，或者希望取得用益权的价款；依市民法，她也可以将该权利转让给任何自己更愿意惠顾的人，而不让其留在敌对者手中。

<!-- source-p 301 -->
<a id="23.3.78.3"></a>**3.**妻子以嫁资名义将用益权交给丈夫；婚姻存续期间，她又将农庄出售给丈夫。问题是，离婚后她可以依据嫁资之诉取回什么？我说，这取决于农庄的售价：如果估价时仅计算裸所有权，妻子可以依据嫁资之诉请求用益权的价款。那么，如果丈夫在争讼程序确定前死亡，继承人是否须给付任何财物？他们无须给付；因为即使是其他人购买了所有权，其继承人也无须向妻子给付，显然用益权已回归所有权。反之，如果农庄是按包含用益权的完整价值出售，就应视为妻子在婚姻存续期间已经收取嫁资。

<!-- source-p 302 -->
<a id="23.3.78.4"></a>**4.**如果共有农庄被作为嫁资给付，而共有人对丈夫提起共有物分割之诉，农庄最终判归共有人，则判令丈夫给付共有人之数额属于嫁资；如果未进行竞价，农庄被判归第三人，则出售所得价款中的相应份额属于嫁资。不过，这一数额不应被视为原物，也不应在离婚时立即返还，而应到约定期限才给付。如果农庄判归丈夫，已作为嫁资给付的份额当然仍为嫁资；离婚时，与农庄判归丈夫相伴的另一份额也应纳入返还安排，也就是说，妻子应向丈夫偿还其因被判给共有人而支付的价款。任何一方都不得拒绝这一公平安排：妻子不得拒绝取得另一份额，丈夫也不得拒绝返还该份额。还须考察婚姻存续期间，嫁资是否仅包括最初给付的份额，还是也包括另一份额。尤利安只说其中嫁资部分属于嫁资；我也曾在法庭上说，只有该部分属于嫁资。

<!-- source-p 303 -->
<a id="23.3.78.5"></a>**5.**如果某人因错误而向承诺嫁资的丈夫作出要式承诺，尽管其原本可以援用抗辩而免于给付，仍会被迫履行；此后，他可以向妻子或其父亲提起返还之诉，具体取决于二人中谁指示他作出该项不应给付的承诺或付款。

<a id="23.3.79"></a>**23.3.79**

<!-- source-p 305 -->
**拉贝奥：《后论》第六卷（雅沃列努斯节本）。**

<!-- source-p 306 -->
<a id="23.3.79.pr."></a>**序言。**祖父以孙女名义，为自己儿子所生的女儿向女婿给付嫁资，之后祖父死亡。塞尔维乌斯否认嫁资应返还给孙女的父亲，我也赞同塞尔维乌斯；因为不能认为嫁资源自该父亲，他并未拥有其中任何财物。

<!-- source-p 307 -->
<a id="23.3.79.1"></a>**1.**父亲代表女儿承诺给付一百个钱币作为嫁资，并约定“在最方便的时候给付”。阿泰乌斯写道，塞尔维乌斯答复说，只要能够在不致蒙受耻辱或恶名的情况下给付，就应当尽早给付。

<!-- source-p 308 -->
<a id="23.3.80"></a>**23.3.80**

<!-- source-p 309 -->
**雅沃列努斯：《摘录拉贝奥〈后论〉》第六卷。**

<!-- source-p 310 -->
如果女子的债务人向其未婚夫承诺给付嫁资，拉贝奥说，女子可以在婚前向债务人请求该款；此后，债务人不会因此再对丈夫负债。我认为此说错误，因为在该债务仍处于这种状态期间，承诺仍未确定生效。

<!-- source-p 311 -->
<a id="23.3.81"></a>**23.3.81**

<!-- source-p 312 -->
**帕皮尼安：《疑问集》第八卷。**

<!-- source-p 313 -->
父亲以女儿名义将自己借来或以信贷方式取得的他人钱币作为嫁资给付。该款项被消费后，嫁资便成为父系来源的嫁资。

<!-- source-p 314 -->
<a id="23.3.82"></a>**23.3.82**

<!-- source-p 315 -->
**普罗库鲁斯：《书信》第五卷。**

<!-- source-p 316 -->
妻子指示丈夫将他所欠妻子的钱作为共同女儿的嫁资给付，并称丈夫已经这样做。我认为应查明丈夫是以自己的名义，还是以妻子的名义给付嫁资：若以自己的名义给付，丈夫仍然欠妻子该款；若以妻子的名义给付，丈夫便已解除对妻子的债务。

<!-- source-p 317 -->
<a id="23.3.83"></a>**23.3.83**

<!-- source-p 318 -->
**雅沃列努斯：《摘录拉贝奥〈后论〉》第六卷。**

<!-- source-p 319 -->
如果女子的债务人向其未婚夫承诺给付嫁资，女子在婚前不得向债务人请求该款，因为婚姻成立前，该项承诺仍处于待定状态。

<!-- source-p 320 -->
<a id="23.3.84"></a>**23.3.84**

<!-- source-p 321 -->
**拉贝奥：《可能论》第六卷（保罗节本）。**

<!-- source-p 322 -->
如果有人因已承诺的嫁资而被起诉，不应仅在其有清偿能力的范围内判令其承担责任。保罗说，涉及第三人的情形，确实一贯如此。但是，如果婚姻关系仍存续，女婿向岳父请求其已承诺的嫁资，岳父当然只应在其有清偿能力的范围内被判承担责任。若在婚姻解除后才请求给付，我认为应根据具体原因和当事人身份作出判断：例如，岳父若以将来设立嫁资为由诱使女婿，而自己明知无力给付嫁资，仍蓄意设局损害女婿，情况又当如何？

<!-- source-p 323 -->
<a id="23.3.85"></a>**23.3.85**

<!-- source-p 324 -->
**斯凯沃拉：《学说汇纂》第八卷。**

<!-- source-p 325 -->
父亲曾以女儿名义将农庄作为嫁资给付。父亲死亡后，女儿成为其唯一继承人；在父亲的债权人催促清偿时，较为有利的做法似乎是出售作为嫁资的农庄，因为其收益较少，并保留其他收益较高的遗产农庄；丈夫对此表示同意，前提是不会因此遭受损失。我问：婚姻存续期间，是否可以将嫁资中对应于该农庄的部分正当地给付给妻子？答复说，如果出售所得的价款用于支付债权人，该项给付即属正当。
