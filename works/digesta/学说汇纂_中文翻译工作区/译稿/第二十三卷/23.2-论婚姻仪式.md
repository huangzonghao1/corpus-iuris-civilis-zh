# D.23.2 论婚姻仪式（上：23.2.1–34.3）

<!-- source-p 001; 原文导航锚点 2、题名锚点 23.2 -->
<a id="2"></a><a id="23.2"></a>**23.2.0. 论婚姻仪式（*De ritu nuptiarum*）**

<!-- source-p 002 -->
<a id="23.2.1"></a>**23.2.1**

<!-- source-p 003 -->
**莫德斯蒂努斯：《规则》第一卷。**

<!-- source-p 004 -->
婚姻是男女的结合，是终身共同生活，也是神法与人法的共同参与。

<!-- source-p 005 -->
<a id="23.2.2"></a>**23.2.2**

<!-- source-p 006 -->
**保罗：《论告示》第三十五卷。**

<!-- source-p 007 -->
除非所有人均同意，婚姻不能成立；这里所说的所有人，是指缔结婚姻的双方以及对双方享有家父权的人。

<!-- source-p 008 -->
<a id="23.2.3"></a>**23.2.3**

<!-- source-p 009 -->
**保罗：《萨宾评注》第一卷。**

<!-- source-p 010 -->
如果我对一个儿子所生的孙子和另一个儿子所生的孙女均享有家父权，庞波尼乌斯写道，只须我一人同意，他们便可以结婚；此说正确。

<!-- source-p 011 -->
<a id="23.2.4"></a>**23.2.4**

<!-- source-p 012 -->
**庞波尼乌斯：《萨宾评注》第三卷。**

<!-- source-p 013 -->
未满十二岁的女子虽已出嫁，但只有在夫家年满十二岁时，才成为合法妻子。

<!-- source-p 014 -->
<a id="23.2.5"></a>**23.2.5**

<!-- source-p 015 -->
**庞波尼乌斯：《萨宾评注》第四卷。**

<!-- source-p 016 -->
通说认为，女子可以凭未婚夫寄来的书信或派来的使者与身在远方的未婚夫结婚，条件是她随后被引入其住所。反之，女子若身在远方，丈夫不能仅凭她的书信或使者将她迎娶；因为应当引入的是丈夫之家，而非妻子之家，仿佛婚姻住所即为丈夫的住所。

<!-- source-p 017 -->
<a id="23.2.6"></a>**23.2.6**

<!-- source-p 018 -->
**乌尔比安：《萨宾评注》第三十五卷。**

<!-- source-p 019 -->
辛纳最后写道：有人娶了身在远方的女子为妻，后来他赴宴归来，经过台伯河时遇难；答复认为，应由其妻为他服丧。

<!-- source-p 020 -->
<a id="23.2.7"></a>**23.2.7**

<!-- source-p 021 -->
**保罗：《法尔基第亚法》单卷评注。**

<!-- source-p 022 -->
因此，在这种情形下，某位女子可能既享有嫁资，也享有针对嫁资的诉权。

<!-- source-p 023 -->
<a id="23.2.8"></a>**23.2.8**

<!-- source-p 024 -->
**庞波尼乌斯：《萨宾评注》第五卷。**

<!-- source-p 025 -->
被释奴不得娶其同为被释奴的母亲或姐妹为妻，因为这一规则源于习俗，而非法律。

<!-- source-p 026 -->
<a id="23.2.9"></a>**23.2.9**

<!-- source-p 027 -->
**乌尔比安：《萨宾评注》第二十六卷。**

<!-- source-p 028 -->
<a id="23.2.9.pr."></a>**序言。**如果孙子想在祖父精神失常时娶妻，无论如何都需要其父的同意；但如果其父精神失常而祖父神志清醒，祖父同意即已足够。

<!-- source-p 029 -->
<a id="23.2.9.1"></a>**1.**某人的父亲被敌人俘获后，若三年内未归，此人可以娶妻。

<!-- source-p 030 -->
<a id="23.2.10"></a>**23.2.10**

<!-- source-p 031 -->
**保罗：《论告示》第三十五卷。**

<!-- source-p 032 -->
如果父亲离开，以致其所在何处、是否仍然在世均不得而知，应当如何处理，确实令人疑惑。如果自父亲的所在及生死状况彻底不明起已经过了三年，则不禁止其子女，无论男女，缔结婚姻或合法婚姻。

<!-- source-p 033 -->
<a id="23.2.11"></a>**23.2.11**

<!-- source-p 034 -->
**尤利安：《学说汇纂》第六十二卷。**

<!-- source-p 035 -->
如果身陷敌境或离家未满三年的父亲，其儿子在父亲被俘或离家期间娶妻，或其女儿出嫁，我认为婚姻可以有效成立；但儿子所娶之妻或女儿所嫁之人，必须是确定其父不会拒绝的人。

<!-- source-p 036 -->
<a id="23.2.12"></a>**23.2.12**

<!-- source-p 037 -->
**乌尔比安：《萨宾评注》第二十六卷。**

<!-- source-p 038 -->
<a id="23.2.12.pr."></a>**序言。**如果某女子曾是我的妻子，后被我休弃，继而嫁给塞尤斯，而我后来又收养了塞尤斯，他们之间的婚姻并非乱伦婚姻。

<!-- source-p 039 -->
<a id="23.2.12.1"></a>**1.**我与我父亲的未婚妻不得结婚，尽管严格说来她并不称为我的继母。

<!-- source-p 040 -->
<a id="23.2.12.2"></a>**2.**反过来说，我的未婚妻也不能嫁给我父亲，尽管她严格说来并不称为我的儿媳。

<!-- source-p 041 -->
<a id="23.2.12.3"></a>**3.**如果我的妻子在离婚后嫁给他人并生下一女，尤利安认为，此女并非我的继女，但我仍应避免与她结婚。

<!-- source-p 042 -->
<a id="23.2.12.4"></a>**4.**我可以娶养姐妹之女为妻，因为该女并非我的血亲：收养不会使人成为舅父，而收养仅产生那些在法律上成立、亦即产生父系亲属关系的亲属关系。同理，如果养父的姐妹并非与养父同父所生，我也可以娶她为妻。

<!-- source-p 043 -->
<a id="23.2.13"></a>**23.2.13**

<!-- source-p 044 -->
**乌尔比安：《萨宾评注》第三十四卷。**

<!-- source-p 045 -->
如果女主人身份并不显贵，以致她与自己的被释奴结婚至少不失体面，那么，审理此事的法官不应禁止该婚姻。

<!-- source-p 046 -->
<a id="23.2.14"></a>**23.2.14**

<!-- source-p 047 -->
**保罗：《论告示》第三十五卷。**

<!-- source-p 048 -->
<a id="23.2.14.pr."></a>**序言。**养子若被解除养父权，不得娶曾为养父之妻的女子，因为她处于继母的地位。

<!-- source-p 049 -->
<a id="23.2.14.1"></a>**1.**同样，某人收养一个儿子后，不得娶该儿子的妻子；该女子处于儿媳的地位，即使儿子后来被解除养父权也不例外，因为她曾是其儿媳。

<!-- source-p 050 -->
<a id="23.2.14.2"></a>**2.**奴隶身份下形成的血亲关系，在这项规则中也应受到尊重。因此，被释奴不得娶自己的母亲；姐妹及姐妹之女亦然。反过来说，如果父女均曾为奴而后获释，父亲也不得娶其女，即使父女关系尚有疑问。由此，即使是私生女，其生父也不得娶她为妻，因为缔结婚姻时应考察自然法与廉耻；父亲娶女儿为妻，显然有违廉耻。

<!-- source-p 051 -->
<a id="23.2.14.3"></a>**3.**奴隶身份下形成的姻亲关系，也应适用同一规则。例如，我不得娶曾与我父亲以奴隶同居关系生活的女子，如同她是继母；反过来说，父亲也不得娶曾与其儿子以奴隶同居关系生活的女子，如同她是儿媳。同样，某人在奴隶身份下曾娶为妻的女子，其母亲也应视为岳母，不得与之结婚。既然承认奴隶身份下的血亲关系，为何不承认姻亲关系？不过，若事实存疑，避免此类婚姻更为稳妥而合乎礼法。

<!-- source-p 052 -->
<a id="23.2.14.4"></a>**4.**现在来考察继母、继女、岳母和儿媳如何界定，以便明确哪些人不得结婚。有人将继母仅理解为父亲之妻，将儿媳理解为儿子之妻，将继女理解为妻子与前夫所生之女；但就此问题而言，更妥当的意见是，祖父或曾祖父之妻也不得娶为妻。因此，不能娶两名或更多继母；这并不奇怪，因为养子既不能娶生父之妻，也不能娶养父之妻。即使父亲曾有多名妻子，我也不能娶其中任何一人。所谓岳母，不仅包括妻子的母亲，也包括其祖母和曾祖母，我都不得娶为妻。所谓儿媳，不仅包括儿子之妻，也包括孙子和曾孙之妻，尽管有人称后两者为“再儿媳”。所谓继女，也不仅包括妻子的女儿，还包括其孙女和曾孙女，我均不得娶为妻。奥古斯都还解释说，我不得娶曾为我未婚妻之母的女子，因为她曾处于岳母的地位。

<!-- source-p 053 -->
<a id="23.2.15"></a>**23.2.15**

<!-- source-p 054 -->
**帕比尼安：《答复录》第四卷。**

<!-- source-p 055 -->
继父不应与继子的前妻结婚；曾为继女之夫者，也不得娶其继母为妻。

<!-- source-p 056 -->
<a id="23.2.16"></a>**23.2.16**

<!-- source-p 057 -->
**保罗：《论告示》第三十五卷。**

<!-- source-p 058 -->
<a id="23.2.16.pr."></a>**序言。**神圣的马可皇帝在其演说中规定：如果参议员之女嫁给被释奴，该婚姻即不成立；此后元老院也作出了相应决议。

<!-- source-p 059 -->
<a id="23.2.16.1"></a>**1.**孙子娶妻时，其父也必须同意；孙女出嫁时，祖父的意愿和同意即已足够。

<!-- source-p 060 -->
<a id="23.2.16.2"></a>**2.**精神失常使婚姻不能成立，因为婚姻需要合意；但精神失常不妨碍已经有效缔结的婚姻继续存在。

<!-- source-p 061 -->
<a id="23.2.17"></a>**23.2.17**

<!-- source-p 062 -->
**盖尤斯：《行省告示评注》第十一卷。**

<!-- source-p 063 -->
<a id="23.2.17.pr."></a>**序言。**收养所产生的兄弟姐妹关系，仅在收养关系存续期间阻止婚姻。因此，我父亲收养某女子后又将她解放，我便可以娶她为妻。同样，如果我被解放后，养父仍将她置于其权力之下，我们也可以结婚。

<!-- source-p 064 -->
<a id="23.2.17.1"></a>**1.**因此，想要收养女婿的人，通常会被建议先解除其女儿的父权〔底本保留 *emanciparet [emancipet]* 异读〕；想要收养儿媳的人，也会被建议先解除其儿子的父权。

<!-- source-p 065 -->
<a id="23.2.17.2"></a>**2.**我们不得娶姑母、姨母，也不得娶姑祖母、姨祖母，尽管姑祖母和姨祖母属于第四亲等。无论如何，即使姑母或姑祖母是因收养而与我们形成亲属关系，我们也不得娶她们为妻。

<!-- source-p 066 -->
<a id="23.2.18"></a>**23.2.18**

<!-- source-p 067 -->
**尤利安：《学说汇纂》第十六卷。**

<!-- source-p 068 -->
同一双方之间的婚姻，除非经父母同意重新缔结，否则不被视为合法婚姻。

<!-- source-p 069 -->
<a id="23.2.19"></a>**23.2.19**

<!-- source-p 070 -->
**马尔基安：《法学阶梯》第十六卷。**

<!-- source-p 071 -->
《尤利亚法》第三十五章规定：凡无正当理由阻止其权力下的子女娶妻或出嫁者，或依据神圣的塞维鲁皇帝和安东尼皇帝的敕令而拒绝提供嫁资者，行省总督和行省长官应强制其安排子女结婚并提供嫁资。未调查拟婚对象的身份，也被视为阻止婚姻。

<!-- source-p 072 -->
<a id="23.2.20"></a>**23.2.20**

<!-- source-p 073 -->
**保罗：《神圣的安东尼努斯与康茂德皇帝演说》单卷评注。**

<!-- source-p 074 -->
应当知道，受监护女子是否结婚不属于其事务管理人的职责，因为其职责在于管理事务。塞维鲁皇帝和安东尼皇帝也作出如下答复：“事务管理人的职责在于管理受监护女子的事务；至于结婚与否，受监护女子可以自行决定。”

<!-- source-p 075 -->
<a id="23.2.21"></a>**23.2.21**

<!-- source-p 076 -->
**克莱门提乌斯：《尤利亚法与帕皮亚法》第三卷。**

<!-- source-p 077 -->
家子不受强制娶妻。

<!-- source-p 078 -->
<a id="23.2.22"></a>**23.2.22**

<!-- source-p 079 -->
**塞尔苏斯：《学说汇纂》第十五卷。**

<!-- source-p 080 -->
如果父亲强迫儿子娶一名女子，而儿子若能自行决定本不会娶她，但他仍缔结了婚姻，那么婚姻已经成立，因为婚姻不能在双方均不愿意的情况下缔结；可以认为，他最终还是选择了该婚姻。

<!-- source-p 081 -->
<a id="23.2.23"></a>**23.2.23**

<!-- source-p 082 -->
**塞尔苏斯：《学说汇纂》第三十卷。**

<!-- source-p 083 -->
《帕皮亚法》规定，除参议员及其子女以外，所有自由出生者均可娶被释女为妻。

<!-- source-p 084 -->
<a id="23.2.24"></a>**23.2.24**

<!-- source-p 085 -->
**莫德斯蒂努斯：《规则》第一卷。**

<!-- source-p 086 -->
与自由女性持续同居，若她并非以身体取财为业，应认定为婚姻，而非姘居关系。

<!-- source-p 087 -->
<a id="23.2.25"></a>**23.2.25**

<!-- source-p 088 -->
**莫德斯蒂努斯：《规则》第二卷。**

<!-- source-p 089 -->
被解除父权的儿子即使未获父亲同意，也可以娶妻；其所生之子将成为他的继承人。

<!-- source-p 090 -->
<a id="23.2.26"></a>**23.2.26**

<!-- source-p 091 -->
**莫德斯蒂努斯：《答复录》第五卷。**

<!-- source-p 092 -->
答复说，已被指控通奸的女子，即使尚未定罪，也不得在丈夫目睹的情形下被娶为妻。〔底本作 *vidente marito*，句义存疑。〕

<!-- source-p 093 -->
<a id="23.2.27"></a>**23.2.27**

<!-- source-p 094 -->
**乌尔比安：《尤利亚法与帕皮亚法》第三卷。**

<!-- source-p 095 -->
若某人身居参议员阶层而娶被释女为妻，尽管在此期间她尚不具有妻子的身份，但如果该男子失去其身份，她便会开始成为他的合法妻子。

<!-- source-p 096 -->
<a id="23.2.28"></a>**23.2.28**

<!-- source-p 097 -->
**马尔基安：《法学阶梯》第十卷。**

<!-- source-p 098 -->
被释者的原主人不得违背她的意愿娶她为妻。

<!-- source-p 099 -->
<a id="23.2.29"></a>**23.2.29**

<!-- source-p 100 -->
**乌尔比安：《尤利亚法与帕皮亚法》第三卷。**

<!-- source-p 101 -->
据说阿泰乌斯·卡皮托在其执政官任内也曾作出同样裁断。但只有在原主人并非为了娶她为妻而将其解放时，才应遵守这一规则。

<!-- source-p 102 -->
<a id="23.2.30"></a>**23.2.30**

<!-- source-p 103 -->
**盖尤斯：《尤利亚法与帕皮亚法》第二卷。**

<!-- source-p 104 -->
虚假缔结的婚姻不发生任何效力。

<!-- source-p 105 -->
<a id="23.2.31"></a>**23.2.31**

<!-- source-p 106 -->
**乌尔比安：《尤利亚法与帕皮亚法》第六卷。**

<!-- source-p 107 -->
如果参议员经元首特许而获准娶被释女为合法妻子，该女子即可成为其合法妻子。

<!-- source-p 108 -->
<a id="23.2.32"></a>**23.2.32**

<!-- source-p 109 -->
**马尔凯鲁斯：《尤利亚法与帕皮亚法》第一卷。**

<!-- source-p 110 -->
应当知道，某被释奴自愿受一名自由出生者收养，即使他因此在该人的家族中取得自由出生者的权利，仍不得与参议员缔结婚姻。

<!-- source-p 111 -->
<a id="23.2.33"></a>**23.2.33**

<!-- source-p 112 -->
**马尔凯鲁斯：《尤利亚法与帕皮亚法》第三卷。**

<!-- source-p 113 -->
多数人认为，同一女子回到同一男子身边时，婚姻仍属同一婚姻。我赞同这一意见，但须双方在相隔时间不长后即和好，且在此期间该女子未嫁他人、该男子未娶他人；尤其是在该男子未返还嫁资时。

<!-- source-p 114 -->
<a id="23.2.34"></a>**23.2.34**

<!-- source-p 115 -->
**帕比尼安：《答复录》第四卷。**

<!-- source-p 116 -->
<a id="23.2.34.pr."></a>**序言。**给家子的概括授权，不能据此为其安排婚姻；因此，为使婚姻成立，必须将拟婚对象告知其父亲，并由父亲表示同意。

<!-- source-p 117 -->
<a id="23.2.34.1"></a>**1.**丈夫依法起诉妻子通奸的，指控撤销后，不禁止该女子再次结婚。即使丈夫并非依丈夫身份依法起诉，婚姻仍应视为依法成立。

<!-- source-p 118 -->
<a id="23.2.34.2"></a>**2.**继子女之间可以结婚，即使其父母后来另行结婚并生育了一个共同的兄弟。

<!-- source-p 119 -->
<a id="23.2.34.3"></a>**3.**参议员之女若嫁给被释奴，父亲被逐出参议院并不使她因此成为合法妻子；因为子女已取得的身份不应因父亲犯罪而被剥夺。

<!-- source-p 120 -->
### <a id="23.2.35"></a>23.2.35

<!-- source-p 121 -->
帕比尼安《答复集》第六卷

<!-- source-p 122 -->
处于父权之下的军人，未经父亲同意，不得缔结婚姻。

<!-- source-p 123 -->
### <a id="23.2.36"></a>23.2.36

<!-- source-p 124 -->
保罗《疑问集》第五卷

<!-- source-p 125 -->
除非未成年受监护人已由父亲订立婚约、指定婚配对象，或在遗嘱中指定婚配对象，并且婚姻依该条件缔结，否则监护人或保佐人不得与已成年的被监护女子结婚。

<!-- source-p 126 -->
### <a id="23.2.37"></a>23.2.37

<!-- source-p 127 -->
保罗《答复集》第七卷

<!-- source-p 128 -->
应当禁止女子的保佐人的被释奴与该女子结婚。

<!-- source-p 129 -->
### <a id="23.2.38"></a>23.2.38

<!-- source-p 130 -->
保罗《箴言集》第二卷

<!-- source-p 131 -->
<a id="23.2.38.pr."></a>

**序言（pr.）** 某人在行省任职期间，不得娶该行省出生或在当地设有住所的女子为妻；但法律并不禁止他与该女子订立婚约。也就是说，若女子在其卸任后不愿缔结婚姻，只要返还所收定金，即可解除婚约。〔底本在 *liceat* 后附有异文 *[libeat]*。〕

<!-- source-p 132 -->
<a id="23.2.38.1"></a>

**1.** 某人在其任职行省中，可以娶早已订婚的女子为妻；已交付的嫁资也不因此被没收。

<!-- source-p 133 -->
<a id="23.2.38.2"></a>

**2.** 某人在行省任职，并不因此被禁止在该行省为女儿安排婚姻或设定嫁资。

<!-- source-p 134 -->
### <a id="23.2.39"></a>23.2.39

<!-- source-p 135 -->
保罗《论普劳提乌斯》第六卷

<!-- source-p 136 -->
<a id="23.2.39.pr."></a>

**序言（pr.）** 我不得娶我姐妹的曾孙女为妻，因为我对她处于如同父母的地位。

<!-- source-p 137 -->
<a id="23.2.39.1"></a>

**1.** 若有人娶了习俗禁止其娶为妻的女子，就被认为犯了乱伦罪。

<!-- source-p 138 -->
### <a id="23.2.40"></a>23.2.40

<!-- source-p 139 -->
庞波尼《论普劳提乌斯》第四卷

<!-- source-p 140 -->
阿里斯托答复说，继女的女儿不能比继女本人更适合作妻子；也就是说，两人都不得娶为妻。

<!-- source-p 141 -->
### <a id="23.2.41"></a>23.2.41

<!-- source-p 142 -->
马尔凯卢斯《学说汇纂》第二十六卷

<!-- source-p 143 -->
<a id="23.2.41.pr."></a>

**序言（pr.）** 过失污名也适用于生活放荡、以卖淫为生的妇女，即使她们并非公开卖淫。

<!-- source-p 144 -->
<a id="23.2.41.1"></a>

**1.** 若某妇女与其庇护人以外的人保持姘居关系，我认为她不具备家主妇的体面身份。

<!-- source-p 145 -->
### <a id="23.2.42"></a>23.2.42

<!-- source-p 146 -->
莫德斯蒂努《论婚姻仪式》单卷

<!-- source-p 147 -->
<a id="23.2.42.pr."></a>

**序言（pr.）** 对任何结合，不仅应考察法律是否允许，也应考察其是否合乎体面。

<!-- source-p 148 -->
<a id="23.2.42.1"></a>

**1.** 若元老的女儿、孙女或曾孙女嫁给自由释奴，或嫁给从事过舞台表演技艺的人，或其父母曾从事该技艺的人，该婚姻不成立。

<!-- source-p 149 -->
### <a id="23.2.43"></a>23.2.43

<!-- source-p 150 -->
乌尔比安《论尤利亚与帕皮亚法》第一卷

<!-- source-p 151 -->
<a id="23.2.43.pr."></a>

**序言（pr.）** 所谓公开卖淫，不仅包括在妓院中卖淫的女子，也包括在酒馆或其他场所不顾自身贞操、公开卖淫的女子。

<!-- source-p 152 -->
<a id="23.2.43.1"></a>

**1.** “公开”应理解为在众人之间、不作选择地卖淫；并非指某女子与通奸者或奸淫者交往，而是指她实际上充当妓女。

<!-- source-p 153 -->
<a id="23.2.43.2"></a>

**2.** 同样，若女子收取钱财后只与一两人发生性关系，不应视为公开以身体营利。

<!-- source-p 154 -->
<a id="23.2.43.3"></a>

**3.** 但奥克塔维努斯极为正确地说，即使女子并未收取报酬，只要她公开卖淫，也应列入此类。

<!-- source-p 155 -->
<a id="23.2.43.4"></a>

**4.** 法律所标记的，不仅是女子正在实施的行为，也包括她过去实施过的行为，即使她后来已经停止；因为后来中断的污行并不会因此消除。

<!-- source-p 156 -->
<a id="23.2.43.5"></a>

**5.** 女子以贫困为借口而过极其卑劣的生活，不应得到宽恕。

<!-- source-p 157 -->
<a id="23.2.43.6"></a>

**6.** 经营拉皮条，不亚于亲自以身体营利。

<!-- source-p 158 -->
<a id="23.2.43.7"></a>

**7.** 我们所说的拉皮条者，是指安排营利性卖淫妇女卖淫的人。

<!-- source-p 159 -->
<a id="23.2.43.8"></a>

**8.** 以他人名义从事此种营生的女子，也属于拉皮条者。

<!-- source-p 160 -->
<a id="23.2.43.9"></a>

**9.** 若有人经营酒馆，并在酒馆中安排卖淫女子——许多人常以酒馆用工为掩护安排女子卖淫——也应认为此人属于拉皮条者。

<!-- source-p 161 -->
<a id="23.2.43.10"></a>

**10.** 元老院认为，任何元老都不适宜娶或继续留用一名经公诉程序判罪的女子为妻；该程序允许任何人提起诉讼，但依法无权提起公诉的人除外。

<!-- source-p 162 -->
<a id="23.2.43.11"></a>

**11.** 若某女子因公诉案件中的诬告而被判罪，或因诉讼串通而被判罪，就不应视为经公诉程序判罪。

<!-- source-p 163 -->
<a id="23.2.43.12"></a>

**12.** 在通奸时被当场发现的女子，视同经公诉程序判罪。因此，若有人主张女子因通奸被判罪，她不仅因被当场发现而蒙受污名，也因经公诉程序判罪而蒙受污名。若她未被当场发现，却被判罪，就因经公诉程序判罪而蒙受污名；若她被当场发现但未被判罪，是否仍蒙受污名？我认为，即使她在被发现后获判无罪，该污名仍应对她不利，因为她确实是在通奸时被发现；法律所标记的是行为事实，而非判决。

<!-- source-p 164 -->
<a id="23.2.43.13"></a>

**13.** 此处不像《尤利亚通奸法》那样补充规定由谁或在何处发现女子。因此，无论是丈夫还是其他人发现她，都应认为她蒙受污名；而且，即使她不是在丈夫或父亲家中被发现，也应依法律文字认定她蒙受污名。

<!-- source-p 165 -->
### <a id="23.2.44"></a>23.2.44

<!-- source-p 166 -->
保罗《论尤利亚与帕皮亚法》第一卷

<!-- source-p 167 -->
<a id="23.2.44.pr."></a>

**序言（pr.）** 《尤利亚法》规定如下：“现任元老，以及元老的儿子、孙子（系其儿子所生）或曾孙（系其孙子所生），任何人均不得明知而以恶意欺诈使自由释奴，或本人、或其父亲、母亲曾从事舞台表演技艺的女子，成为自己的未婚妻或妻子。元老的女儿、孙女（系其儿子所生）或曾孙女（系其孙子所生），不得明知而与自由释奴，或本人、其父亲或母亲从事过舞台表演技艺的人订婚或结婚；这些男子也不得明知而以恶意欺诈使此类女子成为自己的未婚妻或妻子。”

<!-- source-p 168 -->
<a id="23.2.44.1"></a>

**1.** 本条禁止元老娶自由释奴，或娶其父亲、母亲曾从事舞台表演技艺的女子；同样也禁止自由释奴娶元老的女儿。

<!-- source-p 169 -->
<a id="23.2.44.2"></a>

**2.** 祖父或祖母曾从事舞台表演技艺，不构成障碍。

<!-- source-p 170 -->
<a id="23.2.44.3"></a>

**3.** 法律并未区分父亲是否对女儿行使家父权。尽管如此，奥克塔维努斯说，此处应理解为合法的父亲；至于母亲，即使其与人私通而受孕，也仍计入。

<!-- source-p 171 -->
<a id="23.2.44.4"></a>

**4.** 同样，父亲是生父还是养父，并无区别。

<!-- source-p 172 -->
<a id="23.2.44.5"></a>

**5.** 若父亲在收养前曾从事舞台表演技艺，是否也会造成障碍？若生父在女儿出生前曾从事该技艺，是否也会造成障碍？若具有这种污名的人收养女儿后又将她解放，她是否仍不得出嫁？若这样的生父已经死亡，又该如何？庞波尼正确地认为，对于这些情形，应依法律相反的意思处理，不将她们列入禁止范围。

<!-- source-p 173 -->
<a id="23.2.44.6"></a>

**6.** 若自由出生妻子的父亲或母亲在婚后才开始从事舞台表演技艺，由于婚姻缔结时合乎体面，而且或许已经生育子女，要求丈夫休弃妻子极不公平。

<!-- source-p 174 -->
<a id="23.2.44.7"></a>

**7.** 但若妻子本人开始从事舞台表演技艺，就必须休弃她。

<!-- source-p 175 -->
<a id="23.2.44.8"></a>

**8.** 其他自由出生者依法不得娶为妻的女子，元老同样不得娶为妻。

<!-- source-p 176 -->
### <a id="23.2.45"></a>23.2.45

<!-- source-p 177 -->
乌尔比安《论尤利亚与帕皮亚法》第三卷

<!-- source-p 178 -->
<a id="23.2.45.pr."></a>

**序言（pr.）** 法律规定，未经庇护人同意，与庇护人结婚的女被释奴不得再嫁他人。这里所说的庇护人，也包括依照法律买下奴隶并负有将其释放义务的人；因为被释放后，该女子被视为买受人的被释奴。这一点载于我国皇帝及其神圣先父的复函。

<!-- source-p 179 -->
<a id="23.2.45.1"></a>

**1.** 但仅仅宣誓自称为庇护人的人，并不享有同样权利。

<!-- source-p 180 -->
<a id="23.2.45.2"></a>

**2.** 用他人钱款购买奴隶的人，也不应享有该项权利。

<!-- source-p 181 -->
<a id="23.2.45.3"></a>

**3.** 但若某人是处于父权之下的军人，他以军中特有产释放女奴，我们无疑认为该权利归其享有：依皇帝敕令，他是庇护人；其父亲则不享有该项权利。

<!-- source-p 182 -->
<a id="23.2.45.4"></a>

**4.** 本条仅适用于已经与庇护人结婚的女被释奴，不适用于未婚妻。因此，若女被释奴未婚妻在庇护人不同意时解除婚约，她仍可与他人缔结合法婚姻。

<!-- source-p 183 -->
<a id="23.2.45.5"></a>

**5.** 法律接着说“未经庇护人同意”。所谓“不同意”，应理解为庇护人不赞成解除婚姻。因此，女被释奴即使与精神失常的庇护人离婚，也不能免除该法的限制；若庇护人在不知情的情况下发生离婚，亦然。与“持异议”相比，此处更准确地应理解为庇护人不愿意。

<!-- source-p 184 -->
<a id="23.2.45.6"></a>

**6.** 若庇护人被敌人俘获，我担心女被释奴嫁给他人后是否能缔结合法婚姻，如同庇护人已经死亡时那样。赞同尤利安意见的人会说她不能缔结合法婚姻，因为尤利安认为，出于对庇护人的敬重，女被释奴与庇护人的婚姻在庇护人被俘期间仍然存续。若庇护人被置于其他奴役之下，婚姻无疑就会解除。

<!-- source-p 185 -->
### <a id="23.2.46"></a>23.2.46

<!-- source-p 186 -->
盖尤斯《论尤利亚与帕皮亚法》第八卷

<!-- source-p 187 -->
是否共同享有该项权利，尚有疑问：若有人娶一名由数人共有的女被释奴为妻，能否享有庇护人的这项权利？雅沃勒努斯否认，理由是她若也属于他人，就不能严格说是他一人的被释奴。另一些人则持相反意见，因为即使她同时也是他人的被释奴，也不能否认她是此人的被释奴。多数法学家正确地赞同后一意见。

<!-- source-p 188 -->
### <a id="23.2.47"></a>23.2.47

<!-- source-p 189 -->
保罗《论尤利亚与帕皮亚法》第二卷

<!-- source-p 190 -->
元老的女儿若曾以身体营利、从事舞台表演技艺，或经公诉程序被判罪，可以不受处罚地嫁给自由释奴；因为她既已使自己陷入如此卑贱的关系，就不再保有其身份所带来的尊荣。

<!-- source-p 191 -->
### <a id="23.2.48"></a>23.2.48

<!-- source-p 192 -->
克莱门提乌《论尤利亚与帕皮亚法》第八卷

<!-- source-p 193 -->
<a id="23.2.48.pr."></a>

**序言（pr.）** 按照法律本意，庇护人的儿子若娶了其父亲的女被释奴为妻，并与她保持婚姻关系，应享有法律赋予庇护人本人的同等权利。若另一名庇护人的儿子在该庇护人仍在世时娶了共同被释奴为妻，也应作同样处理。

<!-- source-p 194 -->
<a id="23.2.48.1"></a>

**1.** 若庇护人娶了自己声名不佳的女被释奴为妻，意见认为，由于该丈夫违反法律，他不能享有法律赋予庇护人的利益。

<!-- source-p 195 -->
<a id="23.2.48.2"></a>

**2.** 若父亲将一名被释奴指定给其中一名儿子，而另一名儿子娶了该女子为妻，就不得给予其与庇护人相同的权利；他不享有任何权利，因为元老院已将关于被指定给某人的被释奴的一切权利，转归父亲指定的那名儿子。

<!-- source-p 196 -->
### <a id="23.2.49"></a>23.2.49

<!-- source-p 197 -->
马尔凯卢斯《论尤利亚与帕皮亚法》第一卷

<!-- source-p 198 -->
应遵守如下规则：低等身份者可以娶法律因身份原因禁止较高身份者娶的女子；反过来，较高身份者不得娶法律禁止低等身份者娶的女子。

<!-- source-p 199 -->
### <a id="23.2.50"></a>23.2.50

<!-- source-p 200 -->
马尔凯卢斯《论尤利亚与帕皮亚法》第三卷

<!-- source-p 201 -->
最近有人作出规定：若某人娶了自己因信托遗赠而释放的女奴为妻，该女被释奴即使未经其同意，也可以另行结婚。我认为这是因为，不能要求一个因法律义务而释放女奴、并非出于自己意愿的人承担这种限制；他履行的是应当履行的释放义务，并未因此向该女子施予任何恩惠。

<!-- source-p 202 -->
### <a id="23.2.51"></a>23.2.51

<!-- source-p 203 -->
利基尼乌斯《规则》第一卷

<!-- source-p 204 -->
<a id="23.2.51.pr."></a>

**序言（pr.）** 女奴因结婚目的被释放后，除释放她的人以外，不得由任何其他人娶为妻；但庇护人若放弃对其婚姻的权利，则不在此限。

<!-- source-p 205 -->
<a id="23.2.51.1"></a>

**1.** 若处于父权之下的儿子经父亲同意，为结婚目的释放女奴，尤利安认为，应将她视为由其父亲释放。因此，该儿子可以娶她为妻。

<!-- source-p 206 -->
### <a id="23.2.52"></a>23.2.52

<!-- source-p 207 -->
保罗《评萨宾》第六卷

<!-- source-p 208 -->
乱伦婚姻不产生嫁资；因此，凡已收取的财物均可追回，包括已作为孳息取得的财物。

<!-- source-p 209 -->
### <a id="23.2.53"></a>23.2.53

<!-- source-p 210 -->
盖尤斯《评行省告示》第十一卷

<!-- source-p 211 -->
处于父母与子女关系中的人之间，不得成立婚姻；无论亲等接近还是疏远，均无区别，此限制可无限延伸。

<!-- source-p 212 -->
### <a id="23.2.54"></a>23.2.54

<!-- source-p 213 -->
斯凯沃拉《规则》第一卷

<!-- source-p 214 -->
血亲关系是否源于合法婚姻，并无区别；例如，法律也禁止某人娶其非婚生的姐妹为妻。

<!-- source-p 215 -->
### <a id="23.2.55"></a>23.2.55

<!-- source-p 216 -->
盖尤斯《评行省告示》第十一卷

<!-- source-p 217 -->
<a id="23.2.55.pr."></a>

**序言（pr.）** 与通过收养而成为自己女儿或孙女的女子结婚，也被认为是违背人伦的；即使通过解放而解除收养关系，婚姻禁令仍然有效。

<!-- source-p 218 -->
<a id="23.2.55.1"></a>

**1.** 若我仍处于养父家族之中，就不得娶养父的母亲、姨母或其孙女为妻。相反，若我已被养父解放，婚姻无疑不受妨碍，因为解放后我被视为家族之外的人。

<!-- source-p 219 -->
### <a id="23.2.56"></a>23.2.56

<!-- source-p 220 -->
乌尔比安《论答辩》第三卷

<!-- source-p 221 -->
即使某人将其姐妹的女儿纳为姘妇——即使该女子是自由释奴——也构成乱伦。

<!-- source-p 222 -->
### <a id="23.2.57"></a>23.2.57

<!-- source-p 223 -->
马尔基安《法学阶梯》第二卷

<!-- source-p 224 -->
在行省任职的人，也被禁止同意自己的儿子娶该行省的女子为妻。

<!-- source-p 225 -->
### <a id="23.2.57a"></a>23.2.57a

<!-- source-p 226 -->
马尔西安《对帕比尼安〈论通奸〉第二卷的札记》

<!-- source-p 227 -->
神圣的马尔库斯与卢基乌斯两位皇帝通过一名自由释奴（*mensor*）向弗拉维娅·特尔图拉作出如下复函：“我们考虑到你不知法律而与舅父结婚的时间已经很长，也考虑到你是由祖母安排这桩婚姻，以及你们共同生育的子女数量。由于这些情形同时具备，我们确认你们在四十年前缔结的婚姻中所生子女的合法身份，视同婚姻自始合法、子女系合法受孕。”

<!-- source-p 228 -->
### <a id="23.2.58"></a>23.2.58

<!-- source-p 229 -->
马尔西安《规则》第四卷

<!-- source-p 230 -->
神圣的庇护皇帝曾作出复函：若女被释奴谎称自己是自由出生者，欺骗元老并与其结婚，应仿照裁判官告示给予对她的诉权，因为该女子不能从嫁资中获利——该嫁资本来就不存在。

<!-- source-p 231 -->
### <a id="23.2.59"></a>23.2.59

<!-- source-p 232 -->
保罗《论被释奴指定》单卷

<!-- source-p 233 -->
禁止监护人将被监护女子嫁给自己或自己的儿子的元老院决议，也包括监护人的孙子。

<!-- source-p 234 -->
### <a id="23.2.60"></a>23.2.60

<!-- source-p 235 -->
保罗《论神圣安敦尼与康茂德皇帝敕谕》单卷

<!-- source-p 236 -->
<a id="23.2.60.pr."></a>

**序言（pr.）** 若某人并非监护人，但仍须承担监护责任风险，是否也属于皇帝敕谕的规范范围？例如，被监护女子被敌人俘获，或某人通过虚假陈述为自己免除监护职责，以致依皇帝敕令仍须承担责任。应当说，这些人也在元老院决议的范围内；因为此类责任风险也已被认可计入可据以申请免除监护的“三项监护”之数。

<!-- source-p 237 -->
<a id="23.2.60.1"></a>

**1.** 但若某人是因他人的身份而承担责任风险，我们应考察其是否不在元老院决议的范围内。例如，行政官因他人监护事务承担风险，或有人为监护人或保佐人提供保证；这些情形均不计入“三项监护”之数，因此应当认定不在规范范围内。

<!-- source-p 238 -->
<a id="23.2.60.2"></a>

**2.** 那么，若某人是出于荣誉而被指定为监护人，又应如何？既然此类监护也不计入“三项监护”之数，是否应作同样处理？但理由似乎指向相反结论：人们认为，即使是荣誉监护人，若其放任监护事务管理不善，也通常要承担责任风险。

<!-- source-p 239 -->
<a id="23.2.60.3"></a>

**3.** 毫无疑问，某人被指定为监护人后，虽未实际履行管理职责，却仍属于皇帝敕谕的范围；因为依皇帝敕令，即使他未曾管理，也应如同已经管理一样承担责任。

<!-- source-p 240 -->
<a id="23.2.60.4"></a>

**4.** 那么，若某人想依据某项理由申请免除监护职责，却当时没有现成证据，免除申请因此被延期，而在等待期间被监护女子已达到成年，这是否属于元老院决议的范围？问题在于，监护职责终止、女子达到法定年龄后，是否仍应受理其免除申请：若受理且其获准免除，就可以不受处罚地结婚；若职责终止后不应再受理，则其结婚就不合法。帕比尼安在《答复集》第五卷中说，职务终止后不应再受理免除申请，因此他仍须承担任职期间的责任风险。但我完全不赞同这一点：若迟延并非出于欺诈，而是出于必要，因而不准其免除监护职责，或者虽已受理免除申请仍阻碍其结婚，都是不公平的。

<!-- source-p 241 -->
<a id="23.2.60.5"></a>

**5.** 虽然皇帝敕谕的文字规定监护人不得娶自己的被监护女子为妻，但也应理解为不得与她订立婚约；因为通常不得与之结婚的人，也不得与之订婚。可以合法娶为妻的女子，才可以依法订婚。

<!-- source-p 242 -->
<a id="23.2.60.6"></a>

**6.** 若监护人的养子违法娶了被监护女子，之后又被解放，应如何处理？可以认为，元老院并未将被解放的养子列入规范范围，因为解放后，养亲家族关系便被彻底遗忘。

<!-- source-p 243 -->
<a id="23.2.60.7"></a>

**7.** 亲生子女即使已被交由他人收养，也仍在元老院决议的范围内。

<!-- source-p 244 -->
<a id="23.2.60.8"></a>

**8.** 若被指定为监护人的人提起上诉，其继承人后来败诉，应如何处理？他应对上诉前期间的责任风险承担责任。若其子成为继承人并败诉，是否也属于皇帝敕谕的范围？应当认定属于，因为其子负有交代账目的义务。

<!-- source-p 245 -->
### <a id="23.2.61"></a>23.2.61

<!-- source-p 246 -->
帕比尼安《疑问集》第三十二卷

<!-- source-p 247 -->
因婚姻违法而被没收的嫁资，应扣除通常依法直接从嫁资中扣除的必要费用；丈夫还应支付其在嫁资诉讼中本应返还的数额。

<!-- source-p 248 -->
### <a id="23.2.62"></a>23.2.62

<!-- source-p 249 -->
帕比尼安《答复集》第四卷

<!-- source-p 250 -->
<a id="23.2.62.pr."></a>

**序言（pr.）** 即使父亲曾将共同女儿应嫁给何人的决定交由母亲裁量，母亲指定的监护人也不能因此被当作可供选择的婚配对象；因为不能认为父亲曾考虑由监护人本人来决定，父亲之所以特别优先选择母亲，正是为了不把女儿的婚事交给监护人。

<!-- source-p 251 -->
<a id="23.2.62.1"></a>

**1.** 妇女与其丈夫兼庇护人的被释奴结为夫妻，理由不正当。

<!-- source-p 252 -->
<a id="23.2.62.2"></a>

**2.** 已向保佐人交代账目的监护人，不得在被监护女子达到规定年龄之前娶她为妻，也不得娶她后来与他人婚姻所生的母亲。

<!-- source-p 253 -->
### <a id="23.2.63"></a>23.2.63

<!-- source-p 254 -->
帕比尼安《定义集》第一卷

<!-- source-p 255 -->
大队步兵长、骑兵长或军事保民官若违反禁令，在自己任职的行省娶妻，婚姻不成立；此情形应与监护人娶被监护女子相比，因为权势地位使婚姻受到禁止。但若处女嫁给此人，是否应剥夺她依遗嘱取得的财物，尚可讨论。依照被监护女子嫁给监护人的例子，该女子可以取得遗嘱留给她的财物。不过，已作为嫁资交付的款项必须返还给该女子的继承人。

<!-- source-p 256 -->
### <a id="23.2.64"></a>23.2.64

<!-- source-p 257 -->
卡利斯特拉《疑问集》第二卷

<!-- source-p 258 -->
<a id="23.2.64.pr."></a>

**序言（pr.）** 元老院决议规定，若某人既是自由释奴又是被监护女子的监护人，却将该女子嫁给自己或自己的儿子，应把他流放。

<!-- source-p 259 -->
<a id="23.2.64.1"></a>

**1.** 禁止监护人及其儿子娶被监护女子的元老院决议，我认为也涵盖监护人的非亲属继承人；因为禁止这种婚姻，正是为了防止那些必须向被监护人交代监护账目的人侵吞她们的家产。

<!-- source-p 260 -->
<a id="23.2.64.2"></a>

**2.** 但男孩的监护人并未被禁止将自己的女儿嫁给自己的被监护人。

<!-- source-p 261 -->
### <a id="23.2.65"></a>23.2.65

<!-- source-p 262 -->
保罗《答复集》第七卷

<!-- source-p 263 -->
<a id="23.2.65.pr."></a>

**序言（pr.）** 在本国服役的人，即使娶同一行省的女子，也不应视为违反皇帝的命令；某些命令中也载有此意。

<!-- source-p 264 -->
<a id="23.2.65.1"></a>

**1.** 同一部著作接着说：他答复认为，即使某人在行省任职期间违反皇帝命令缔结了婚姻，只要卸任后仍维持同一结婚意愿，该婚姻就成为合法婚姻。因此，之后所生子女都是合法婚姻所生的婚生子女。

<!-- source-p 265 -->
### <a id="23.2.66"></a>23.2.66

<!-- source-p 266 -->
保罗《箴言集》第二卷

<!-- source-p 267 -->
<a id="23.2.66.pr."></a>

**序言（pr.）** 若监护人或保佐人在被监护女子年满二十六岁之前娶她为妻，而女子并非由父亲订婚、也未由父亲在遗嘱中指定婚配对象，或者监护人将她嫁给自己的儿子，该婚姻不成立。实施此行为的双方都会蒙受污名，并依被监护女子的身份受到特别惩处。儿子是自权人还是处于父权之下，并无区别。

<!-- source-p 268 -->
<a id="23.2.66.1"></a>

**1.** 若管理被监护女子财产的保佐人的被释奴娶该女子为妻，极其违反公序。

<!-- source-p 269 -->
### <a id="23.2.67"></a>23.2.67

<!-- source-p 270 -->
特里丰尼努《论答辩》第九卷

<!-- source-p 271 -->
<a id="23.2.67.pr."></a>

**序言（pr.）** 不仅在监护人仍在世时禁止其儿子娶该女子，监护人死亡后也禁止；只要其父曾负有向该女子交代监护账目的义务，其子便不得娶她为妻。我认为，儿子是否继承父亲遗产，并无区别；无论儿子继承遗产、放弃继承，还是根本没有成为继承人（例如被剥夺继承权、被遗漏或已被解放），结论都一样；因为也可能有人为逃避监护责任，欺诈性地将父亲财产转给儿子，届时这些财产应被追回。

<!-- source-p 272 -->
<a id="23.2.67.1"></a>

**1.** 有一种情形可以讨论：祖父曾担任其已被解放的儿子所生孙女的监护人，祖父能否将该孙女嫁给另一名儿子的儿子，无论该孙子已经被解放还是仍处于父权之下？由于亲情同等，可以消除欺诈嫌疑。即使元老院决议从严格法律上说禁止所有监护人如此行事，但考虑到祖孙之间极深的亲情，此类婚姻仍应准许。

<!-- source-p 273 -->
<a id="23.2.67.2"></a>

**2.** 若处于父权之下的儿子担任女孩的监护人或保佐人，我认为女孩更不应嫁给他的父亲；那么，她是否也不得嫁给与其父亲同处一权力之下的兄弟？

<!-- source-p 274 -->
<a id="23.2.67.3"></a>

**3.** 再看如下情形：提图斯的儿子娶了曾是你的被监护女子的女子，之后你收养了提图斯或其儿子；婚姻是否因此解除（如同收养女婿的情形），还是应阻止收养？更妥当的意见是阻止收养。若一名保佐人在履行职责期间收养其所保佐女子的丈夫，也应如此处理。但若女子的监护职责已经结束，且她已经嫁给他人，我担心再以防止收养其丈夫为由，禁止收养就过于苛刻；因为这似乎是为阻止其交代监护账目而安排的，而神圣马尔库斯皇帝的敕谕所禁止婚姻的理由正是防止此事。

<!-- source-p 275 -->
<a id="23.2.67.4"></a>

**4.** 若某人被指定为胎儿及其财产的保佐人，也适用同一元老院决议的婚姻禁令；因为他同样负有交代账目的义务。任职期间长短不应影响判断，因为对监护人或保佐人均不区分其履职时间长短。

<!-- source-p 276 -->
<a id="23.2.67.5"></a>

**5.** 若提图斯担任女子的监护人或管理其事务的保佐人，在尚未交代账目时死亡，并留下女儿作为继承人；有人询问提图斯能否将该女子嫁给自己的儿子。我答复说可以，因为此处只产生继承债务，是一般债务；否则，任何对某女子负有某种债务的人，都不得将她嫁给自己或自己的儿子。

<!-- source-p 277 -->
<a id="23.2.67.6"></a>

**6.** 若某人阻止被监护女子取得其父亲的财产，也必须就此事交代账目；即使他考虑不周，也可能因此被判承担责任。即便他基于最佳判断，借助裁判官的管辖权行事，因为女子的父亲死于无清偿能力，婚姻仍受阻；因为此事必须经诉讼证明。即使有人忠实且妥善地履行监护职责，也仍受婚姻禁令约束。

<!-- source-p 278 -->
### <a id="23.2.68"></a>23.2.68

<!-- source-p 279 -->
保罗《论《图尔皮利安元老院决议》》单卷

<!-- source-p 280 -->
依万民法，娶直系尊亲或卑亲为妻的人犯乱伦罪。至于娶法律禁止的旁系亲属，或娶法律禁止与之结婚的姻亲，若公开实施，处罚较轻；若暗中实施，处罚较重。区别理由在于：对于旁系亲属之间未能合法缔结的婚姻，公开违法者被视为发生错误，因而得以较轻处罚；暗中实施者则被视为公然抗命，应受较重惩处。
