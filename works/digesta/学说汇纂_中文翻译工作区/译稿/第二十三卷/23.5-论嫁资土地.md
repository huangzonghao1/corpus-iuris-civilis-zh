# D.23.5 论嫁资土地

<!-- source-p 001; 原文导航锚点 5、题名锚点 23.5 -->
<a id="5"></a><a id="23.5"></a>**23.5.0. 论嫁资土地（*De fundo dotali*）**

<!-- source-p 002 -->
<a id="23.5.1"></a>**23.5.1**

<!-- source-p 003 -->
**保罗：《论告示》第三十六卷。**

<!-- source-p 004 -->
<a id="23.5.1.pr."></a>**序言。**有时，《尤利亚法》对嫁资土地的限制不适用：如果丈夫未就可能发生的损害提供担保，邻人因此被交付嫁资地产的占有，随后又被命令继续占有，那么邻人即取得所有权，因为此种处分并非自愿。

<!-- source-p 005 -->
<a id="23.5.1.1"></a>**1.**在可能范围内，该地产也会通过概括继受移转给他人，例如移转给丈夫的继承人；但地产仍保有其自身的法律负担，因而不得被处分。

<!-- source-p 006 -->
<a id="23.5.2"></a>**23.5.2**

<!-- source-p 007 -->
**乌尔比安：《论通奸》第五卷。**

<!-- source-p 008 -->
如果丈夫沦为奴隶，奴隶所有人是否不得处分这块土地？我认为较为正确的意见是不得处分。因此，即使土地归于国库，土地的出售仍然受阻，尽管国库一向是适格且有清偿能力的继受人。

<!-- source-p 009 -->
<a id="23.5.3"></a>**23.5.3**

<!-- source-p 010 -->
**保罗：《论告示》第三十六卷。**

<!-- source-p 011 -->
<a id="23.5.3.pr."></a>**序言。**遗赠给作为嫁资一部分的奴隶之土地，依《尤利亚法》应视同嫁资土地。

<!-- source-p 012 -->
<a id="23.5.3.1"></a>**1.**只要妻子已经享有或必然将享有嫁资之诉，土地就不得被处分。

<!-- source-p 013 -->
<a id="23.5.4"></a>**23.5.4**

<!-- source-p 014 -->
**盖尤斯：《行省告示评注》第十一卷。**

<!-- source-p 015 -->
《尤利亚法》为保护嫁资地产，禁止丈夫设定担保或处分该地产；对此应作更广义的解释，使未婚夫适用与丈夫相同的规则。

<!-- source-p 016 -->
<a id="23.5.5"></a>**23.5.5**

<!-- source-p 017 -->
**乌尔比安：《论各种审判庭》第二卷。**

<!-- source-p 018 -->
尤利安在《学说汇纂》第十六卷中写道：丈夫既不能免除嫁资地产所负担的地役权，也不能在其上另行设定地役权。

<!-- source-p 019 -->
<a id="23.5.6"></a>**23.5.6**

<!-- source-p 020 -->
**乌尔比安：《论通奸》第五卷。**

<!-- source-p 021 -->
对于嫁资城市地产所负担的地役权，也不得予以免除，以免该地产的状况因此恶化。

<!-- source-p 022 -->
<a id="23.5.7"></a>**23.5.7**

<!-- source-p 023 -->
**尤利安：《学说汇纂》第十六卷。**

<!-- source-p 024 -->
<a id="23.5.7.pr."></a>**序言。**如果丈夫取得了提提乌斯所有、且为嫁资地产提供地役权的土地，地役权因所有权归于一人而消灭；在这种情况下，丈夫应支付诉讼估价。但如果丈夫无清偿能力，妻子可以对提提乌斯提起准用之诉，以恢复该地役权。

<!-- source-p 025 -->
<a id="23.5.7.1"></a>**1.**如果妻子将一块为丈夫地产提供地役权的土地作为嫁资交付，土地归丈夫所有时，地役权因混同而消灭，因此不能说丈夫使该土地的权利状况恶化。那么应如何处理？审理嫁资之诉的法官应依职权命令恢复地役权，并将土地返还给妻子或其继承人。

<!-- source-p 026 -->
<a id="23.5.8"></a>**23.5.8**

<!-- source-p 027 -->
**阿尔费努斯：《保罗节编》第三卷。**

<!-- source-p 028 -->
一名丈夫应妻子请求，砍伐其嫁资土地上的橄榄树，以便重新种植幼树。后来丈夫去世，并将嫁资遗赠给妻子。答复说，应将从橄榄园砍下的木材返还给妻子。

<!-- source-p 029 -->
<a id="23.5.9"></a>**23.5.9**

<!-- source-p 030 -->
**阿非利加努斯：《疑问集》第八卷。**

<!-- source-p 031 -->
<a id="23.5.9.pr."></a>**序言。**如果丈夫欠付某块土地，而妻子将该笔债务作为嫁资承诺给丈夫，该土地即成为嫁资土地。

<!-- source-p 032 -->
<a id="23.5.9.1"></a>**1.**但如果妻子将某人所欠的一块土地或十个钱款单位作为嫁资承诺给丈夫，则由丈夫选择何者作为嫁资。

<!-- source-p 033 -->
<a id="23.5.9.2"></a>**2.**如果丈夫欠付斯提库斯奴隶或一块土地，而妻子将该项债务作为嫁资承诺给他，那么斯提库斯死亡后，该土地成为嫁资。

<!-- source-p 034 -->
<a id="23.5.9.3"></a>**3.**据他说，由此可得：如果丈夫欠付科尔内利亚努斯土地或塞姆普罗尼亚努斯土地，而妻子将该项债务承诺为嫁资，丈夫便可以选择其中一块作为嫁资。无论选择哪一块，他均可处分该块，另一块则不得处分。不过，如果他又买回原先并非嫁资的土地，他仍可选择是否处分先前保留的那块土地。

<!-- source-p 035 -->
<a id="23.5.10"></a>**23.5.10**

<!-- source-p 036 -->
**保罗：《疑问集》第五卷。**

<!-- source-p 037 -->
因此，由于债务原本属于嫁资，依该法享有的处分权会随之变动。那么，在尚未买回其中一块土地时，是否也可以处分另一块，因为他仍可买回前一块？或者不能接受这种解释，以免嫁资中竟没有任何土地？无论如何，从事后情况看，若后来买回其中一块，则先前处分另一块应视为有效。

<!-- source-p 038 -->
<a id="23.5.11"></a>**23.5.11**

<!-- source-p 039 -->
**阿非利加努斯：《疑问集》第八卷。**

<!-- source-p 040 -->
如果土地经估价后作为嫁资交付，且由妻子选择以土地还是估价额计入嫁资，则土地不得处分；如果选择权属于丈夫，则应作相反处理。

<!-- source-p 041 -->
<a id="23.5.12"></a>**23.5.12**

<!-- source-p 042 -->
**帕比尼安：《论通奸》第一卷。**

<!-- source-p 043 -->
<a id="23.5.12.pr."></a>**序言。**即使婚姻已经解除，该地产仍应视为嫁资地产。

<!-- source-p 044 -->
<a id="23.5.12.1"></a>**1.**岳父是否同意出售嫁资地产，并无影响。

<!-- source-p 045 -->
<a id="23.5.13"></a>**23.5.13**

<!-- source-p 046 -->
**乌尔比安：《论通奸》第五卷。**

<!-- source-p 047 -->
<a id="23.5.13.pr."></a>**序言。**嫁资地产包括城市地产和乡村地产；《尤利亚法》适用于一切建筑物。

<!-- source-p 048 -->
<a id="23.5.13.1"></a>**1.**“地产”一词也包括地产的一部分。因此，无论整块地产还是其中一部分被作为嫁资交付，均不得处分；我们遵循这一规则。

<!-- source-p 049 -->
<a id="23.5.13.2"></a>**2.**只有在丈夫取得该地产所有权时，才视为嫁资地产；自此才禁止处分。

<!-- source-p 050 -->
<a id="23.5.13.3"></a>**3.**妻子的继承人也享有与妻子相同的救济。

<!-- source-p 051 -->
<a id="23.5.13.4"></a>**4.**如果妻子被指定为继承人，而一块嫁资地产又被遗赠给她，那么，如果扣除遗赠后她仍能从遗产中取得相当于嫁资数额的财产，该遗赠有效；否则其是否有效便成问题。斯凯沃拉说，即使妻子只能请求返还该地产的一部分，而非全部，只要嫁资仍有不足，应留给妻子的也仅是补足嫁资所需的部分。

<!-- source-p 052 -->
<a id="23.5.14"></a>**23.5.14**

<!-- source-p 053 -->
**保罗：《论通奸》第三卷。**

<!-- source-p 054 -->
<a id="23.5.14.pr."></a>**序言。**如果某女子即将嫁给提提乌斯，并经提提乌斯同意，将一块土地以嫁资名义交付给梅维乌斯，该嫁资土地应具有与她直接将土地交付给提提乌斯时相同的法律地位。

<!-- source-p 055 -->
<a id="23.5.14.1"></a>**1.**如果有人以某女子的名义将土地作为嫁资交付，该土地即成为嫁资土地，因为该土地被视为因妻子之故而归丈夫所有。

<!-- source-p 056 -->
<a id="23.5.14.2"></a>**2.**如果丈夫欠妻子一块属于他人的土地，而妻子又将该土地承诺给丈夫作为嫁资，该土地是否成为嫁资尚未确定；只有在丈夫取得该土地时，它才成为嫁资。

<!-- source-p 057 -->
<a id="23.5.14.3"></a>**3.**如果妻子放弃了因嫁资目的而遗赠给她的土地，或者在丈夫作为替补继承人时放弃遗产或遗赠，该土地便成为嫁资土地。

<!-- source-p 058 -->
<a id="23.5.15"></a>**23.5.15**

<!-- source-p 059 -->
**帕比尼安：《答复录》第三卷。**

<!-- source-p 060 -->
丈夫在寄给妻子的信中声明某地产不再属于嫁资后，仍继续占有该嫁资地产。妻子在婚姻存续期间死亡后，裁定丈夫可以继续保有该地产，因为妻子并无基于约定提起的诉权。

<!-- source-p 061 -->
<a id="23.5.16"></a>**23.5.16**

<!-- source-p 062 -->
**特里丰尼努斯：《论辩集》第十一卷。**

<!-- source-p 063 -->
提提乌斯善意占有某块土地，原本可以通过长期占有取得该土地；妻子却将自己声称所有的土地作为嫁资交给丈夫。丈夫本可请求返还该土地，却未这样做，因此自行承担风险。因为《尤利亚法》禁止处分嫁资土地的规定，也适用于此种取得；但是，如果长期占有在土地成为嫁资地产之前已经开始，该法并不妨碍长期占有继续进行。当然，如果距长期占有完成仅剩极短时间，则不应归责于丈夫。

<!-- source-p 064 -->
<a id="23.5.17"></a>**23.5.17**

<!-- source-p 065 -->
**马尔基安：《学说汇纂》第七卷。**

<!-- source-p 066 -->
丈夫出售并交付嫁资地产；如果妻子在婚姻存续期间死亡，且嫁资归丈夫所有，则不得从买受人处追回该地产。

<!-- source-p 067 -->
<a id="23.5.18"></a>**23.5.18**

<!-- source-p 068 -->
**雅沃勒努斯：《拉贝奥后期论著》第六卷。**

<!-- source-p 069 -->
<a id="23.5.18.pr."></a>**序言。**丈夫在嫁资地产上开采大理石。离婚后，有人问：已经开采但尚未运走的大理石归谁所有？妻子还是丈夫应补偿开采采石场的支出？拉贝奥说，大理石归丈夫所有；但妻子无须向丈夫支付任何费用，因为该支出并非必要，而且使地产状况恶化。我认为，妻子不仅应补偿必要费用，也应补偿有益费用；如果采石场中的石料能够继续生成，我也不认为地产状况因此恶化。

<!-- source-p 070 -->
<a id="23.5.18.1"></a>**1.**如果妻子迟延支付地产部分的估价，使丈夫无法依约取回土地，拉贝奥认为，期间收取的孳息归丈夫所有。我认为，丈夫更应按其份额取得孳息，其余孳息则应返还妻子；我们遵循这一规则。
