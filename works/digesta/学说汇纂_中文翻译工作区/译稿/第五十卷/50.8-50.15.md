<a id="8"></a><a id="50.8"></a>50.8.0　论城市公共财产的管理（*De administratione rerum ad civitates pertinentium*）

<!-- source-p 554 -->
<a id="50.8.1"></a>50.8.1

<!-- source-p 555 -->
乌尔比安《论争议》第十卷

<!-- source-p 556 -->
为某一特定用途留给城市的财产，不得改作其他用途。

<!-- source-p 557 -->
<a id="50.8.2"></a>50.8.2

<!-- source-p 558 -->
乌尔比安《意见集》第三卷

<!-- source-p 559 -->
<a id="50.8.2.pr."></a>序　不应以后来出租的做法作为先前租赁的标准；先前租赁应依其自身约定处理。

<!-- source-p 560 -->
<a id="50.8.2.1"></a>1. 某人不得以自己名义从事的事项，也不得通过其从属之人从事。因此，若市议员借他人名义耕种公共土地，而法律禁止市议员承租该土地，则应依法律追回被违法占用的土地。

<!-- source-p 561 -->
<a id="50.8.2.2"></a>2. 从粮食供应款中挪作他用的款项，应按其原定用途连同应计增额一并返还。即使判决是在缺席者未到庭时作出的，也不得以此提出无效申诉。不过，管理账目仍应依收支凭据诚信编列。

<!-- source-p 562 -->
<a id="50.8.2.3"></a>3. 欠付粮食供应款的人，应尽快以自己的财产清偿；粮食供应款为所有城市共同体所必需，不得拖延支付。至于其基于同一事由享有债权的人，应由行省总督责令其清偿。

<!-- source-p 563 -->
<a id="50.8.2.4"></a>4. 为购买粮食而拨付的款项，应返还城市，不得与其他支出相抵销。若粮食供应款被挪用于其指定用途之外，例如用于公共浴场工程，即使证明支出是善意作出的，也不得与粮食供应款相抵；城市监理官仍应命令清偿。

<!-- source-p 564 -->
<a id="50.8.2.5"></a>5. 若为补偿粮食供应款债务而同时计入利息，不得采用过度且违法的计算方式；也就是说，不得将利息再计入本金，或使利息产生利息。

<!-- source-p 565 -->
<a id="50.8.2.6"></a>6. 若粮食在购买后遭人不法夺走，其估价已记入公共账目，城市监理官应命令将该价值返还物主。

<!-- source-p 566 -->
<a id="50.8.2.7"></a>7. 某人在获任命时有偿付能力，后来却因财力衰败而使城市共同体债务受损的，由于人的判断无法预见偶然事件，任命他的人不应因此承担责任。

<!-- source-p 567 -->
<a id="50.8.2.8"></a>8. 对于法律允许官员因同僚事务而被追诉的情形，不得以协议改变城市共同体的权利，使其不能追诉该官员。

<!-- source-p 568 -->
<a id="50.8.2.9"></a>9. 对同僚承担此类责任后代为付款的人，依衡平原则通常享有诉权。

<!-- source-p 569 -->
<a id="50.8.2.10"></a>10. 若证明某人在担任官员期间曾代同僚付款，行省总督应命令其继承人偿还该款。

<!-- source-p 570 -->
<a id="50.8.3"></a>50.8.3

<!-- source-p 571 -->
乌尔比安《意见集》第三卷

<!-- source-p 572 -->
<a id="50.8.3.pr."></a>序　工程承包人受到处罚后，为其提供保证的人又将同一工程转包给另一承包人。工程完成后，该保证人的继承人不得拒付第二承包人的利息；因为最初的诚信契约已使保证人承担全部责任，后来转包又因其自愿承担风险而使其替代承包人，负责向城市共同体全额履行。

<!-- source-p 573 -->
<a id="50.8.3.1"></a>1. 为公共税收承包人就整个租赁提供保证的人，依法也须对利息承担责任；除非保证义务的措辞明确规定其个人责任限于其他范围。

<!-- source-p 574 -->
<a id="50.8.3.2"></a>2. 但若土地租赁协议约定，因某年度歉收而减少租金的数额由善良之人裁定，则应查明租赁合同内容并遵循诚信。

<!-- source-p 575 -->
<a id="50.8.4"></a>50.8.4

<!-- source-p 576 -->
帕比尼安《复答集》第一卷

<!-- source-p 577 -->
共同职务的城市监理官即使将已裁定由他们对公共债务承担连带责任的款项分开处理，也不得以相互分担风险为由免责。乌尔比安补充说，应仿照监护人的规则，首先向实际管理事务的人追偿。

<!-- source-p 578 -->
<a id="50.8.5"></a>50.8.5

<!-- source-p 579 -->
帕比尼安《复答集》第一卷

<!-- source-p 580 -->
<a id="50.8.5.pr."></a>序　城市监理官未要求提供足额担保，即将公共土地出租五年。其后各年度的承租人若拖欠租金，且土地孳息及租金不足清偿，负责后续出租的人应承担责任。近期对公共税收也已作出同样规定，即每个人只承担自己任期内的风险。

<!-- source-p 581 -->
<a id="50.8.5.1"></a>1. 城市共同体的债权人在管理期间与某人订立更新债务的协议、由其提供担保的，不应在其卸任后拒绝对其提起诉讼。作出清偿承诺者则不同，因为其地位类似于公开出售或出租财产的人。

<!-- source-p 582 -->
<a id="50.8.5.2"></a>2. 不应强迫被任命为城市监理官之人的儿子，为其父提供保证。即使父亲在获任命前已将部分财产赠与这个被解放出父权的儿子，结论也不改变。

<!-- source-p 583 -->
<a id="50.8.5.3"></a>3. 有人被要求为官员提供保证，并另行特别设定了质押。该质押应仅适用于保证人依法可被追诉的情形，也就是其所担保之人无法履行义务之后。

<!-- source-p 584 -->
<a id="50.8.6"></a>50.8.6

<!-- source-p 585 -->
瓦伦斯《遗嘱信托论》第二卷

<!-- source-p 586 -->
未经元首授权，不得将遗赠给市镇共同体的钱款改作死者未指定的其他用途。因此，若死者命令修建某一工程，但因《法尔基第法》适用而不能修建，允许将该项应付金额改用于最符合城市共同体需要的事项；若遗赠了数笔款项用于修建多个工程，而《法尔基第法》适用后剩余款项不足以修建全部工程，则允许将其用于城市共同体所选择的一项工程。但是，元老院禁止将遗赠给市镇共同体、并指定用其收益举行狩猎或演出的款项用于这些活动；此类遗赠款允许用于市民认为最有必要的事项，并应以铭文标示立遗赠人的慷慨。

<!-- source-p 587 -->
<a id="50.8.7"></a>50.8.7

<!-- source-p 588 -->
保罗《判例集》第一卷

<!-- source-p 589 -->
<a id="50.8.7.pr."></a>序　不得强迫市议员以低价供应粮食；该粮食属于其本地当季的粮食供应。

<!-- source-p 590 -->
<a id="50.8.7.1"></a>1. 除非钱款被明确遗赠用于新工程，否则应以该款修缮旧工程。

<!-- source-p 591 -->
<a id="50.8.8"></a>50.8.8

<!-- source-p 592 -->
乌尔比安《论裁判官告示》第一卷

<!-- source-p 593 -->
城市共同体的官员不仅应避免欺诈，也应避免重大过失；此外，甚至还须尽到高度注意义务。

<!-- source-p 594 -->
<a id="50.8.9"></a>50.8.9

<!-- source-p 595 -->
保罗《论裁判官告示》第一卷

<!-- source-p 596 -->
家子经父亲同意担任官职的，尤利安认为，若以其名义欠城市共同体款项，父亲应承担全部责任。

<!-- source-p 597 -->
<a id="50.8.10"></a>50.8.10

<!-- source-p 598 -->
莫德斯丁《规则集》第八卷

<!-- source-p 599 -->
<a id="50.8.10.pr."></a>序　即使经过十年或二十年，仍允许纠正计算错误。

<!-- source-p 600 -->
<a id="50.8.10.1"></a>1. 但若账目上的款项据称是出于恩惠而勾销的，则不得重新追究。

<!-- source-p 601 -->
<a id="50.8.11"></a>50.8.11

<!-- source-p 602 -->
帕皮里乌斯《敕令汇编》第二卷

<!-- source-p 603 -->
<a id="50.8.11.pr."></a>序　安敦尼与维鲁斯皇帝以复函规定，应对留在城市监理官手中的钱款请求利息；工程承包人无法偿还的款项，仅本金损失由城市监理官承担。

<!-- source-p 604 -->
<a id="50.8.11.1"></a>1. 两位皇帝还以复函规定，工程风险也由城市监理官的继承人承担。

<!-- source-p 605 -->
<a id="50.8.11.2"></a>2. 两位皇帝又以复函规定，城市监理官应追回城市共同体的土地，即使该土地已由善意买受人占有；因为买受人可以向自己的出卖人追索。

<!-- source-p 606 -->
<a id="50.8.12"></a>50.8.12

<!-- source-p 607 -->
帕皮里乌斯《敕令汇编》第二卷

<!-- source-p 608 -->
<a id="50.8.12.pr."></a>序　安敦尼与维鲁斯皇帝以复函规定，不得在未取得担保的情况下委托追收工程款项。

<!-- source-p 609 -->
<a id="50.8.12.1"></a>1. 两位皇帝还规定，城市监理官处分财产时若有过失，应承担单倍责任；若系欺诈，则承担双倍责任；该项惩罚不由其继承人承担。

<!-- source-p 610 -->
<a id="50.8.12.2"></a>2. 两位皇帝还规定，财产出售后，城市监理官应追收指定用于粮食供应的款项。

<!-- source-p 611 -->
<a id="50.8.12.3"></a>3. 两位皇帝还依据哈德良书信规定，若粮食供应商没有懈怠履职，就应免于承担损失。

<!-- source-p 612 -->
<a id="50.8.12.4"></a>4. 两位皇帝还规定，不应要求市镇借贷账簿管理人提供担保，因为其系由总督经调查后选任。

<!-- source-p 613 -->
<a id="50.8.12.5"></a>5. 两位皇帝还规定，若城市监理官能够介入并阻止同僚的行为，却未予阻止，也应就同僚的名义承担责任。

<!-- source-p 614 -->
<a id="50.8.12.6"></a>6. 两位皇帝还规定，债权在城市监理官任职期间变得难以收回的，风险由其承担；但若债权在其上任前就已无偿付能力，则认为风险不应由其承担是公平的。

<!-- source-p 615 -->
<a id="50.8.13"></a>50.8.13

<!-- source-p 616 -->
帕皮里乌斯《敕令汇编》第二卷

<!-- source-p 617 -->
安敦尼与维鲁斯皇帝曾以复函规定，官员在任职期间及卸任后一段不短的时间内占有公共钱款的，应当支付利息；除非其能提出延迟缴款的正当理由。

<!-- source-p 625 -->
<a id="50.9.3"></a>50.9.3

<!-- source-p 626 -->
乌尔比安《论上诉》第三卷

<!-- source-p 627 -->

<!-- source-p 628 -->
<a id="50.9.4"></a>50.9.4

<!-- source-p 629 -->
乌尔比安《论城市监理官职责》单卷

<!-- source-p 630 -->
<a id="50.9.4.pr."></a>序　市议员为博取好感而作出的决议应予撤销，无论其内容是免除某人的债务，还是向其赠与财物。

<!-- source-p 631 -->
<a id="50.9.4.1"></a>1. 因此，若议事会像通常那样决议以公共财产向某人提供土地、庄园、房屋或特定金额，此类决议均不发生效力。

<!-- source-p 632 -->
<a id="50.9.4.2"></a>2. 但若市议员决议向某人支付报酬，该决议有时仍有效，例如因其从事自由技艺或行医而支付报酬；这些事由允许设立报酬。

<!-- source-p 633 -->
<a id="50.9.5"></a>50.9.5

<!-- source-p 634 -->
卡利斯特拉图斯《审判论》第二卷

<!-- source-p 635 -->

<!-- source-p 636 -->
<a id="50.9.6"></a>50.9.6

<!-- source-p 637 -->
斯凯沃拉《学说汇纂》第一卷

<!-- source-p 638 -->
市镇法律作出如下规定：希腊文底本转写为“*Ean tis ecw tou sunedriou dikasytai, tou te sunedriou eirgesvw kai prosapotinnutw draxmas xilias*”；拉丁释文为“*Si quis extra curiam iudicabit, curia movetor et praeterea multam mille denarium dato*”（若有人在议事会之外作出裁判，应将其逐出议事会，并另处罚金一千第纳里）。有人问：不知情而违反决议者是否也应受罚？答复说，这类刑罚是为明知而为之者设定的。

<!-- source-p 639 -->
<a id="10"></a><a id="50.10"></a>50.10.0　论公共工程（*De operibus publicis*）

<!-- source-p 640 -->
<a id="50.10.1"></a>50.10.1

<!-- source-p 641 -->
乌尔比安《意见集》第二卷

<!-- source-p 642 -->
<a id="50.10.1.pr."></a>序　受任为公共工程监理官的人，曾以时效抗辩为由，主张其在世期间因停滞而得免除责任。正如他应就自己在世期间的停滞使继承人承担责任，他也未使继承人对其死后发生的迟延承担任何责任。

<!-- source-p 643 -->
<a id="50.10.1.1"></a>1. 某人已担任另一项公职，后来又承担引水渠工程的管理。他如今同时负担两项职务后才请求免除先前职务，似乎为时已晚；如果他只需承担一项职务，较妥当的做法本应是在接受后一职务之前，以自己先前已有公职为由请求免除后一职务。

<!-- source-p 644 -->
<a id="50.10.2"></a>50.10.2

<!-- source-p 645 -->
乌尔比安《意见集》第三卷

<!-- source-p 646 -->
<a id="50.10.2.pr."></a>序　某人并非因负有债务，而是出于慷慨，暂时拿出自己的收入以完成工程；不得因嫉妒而禁止他取得其慷慨行为的成果，例如在其所建工程上题写自己的姓名。

<!-- source-p 647 -->
<a id="50.10.2.1"></a>1. 工程监理官与承包人处理事务，而城市共同体则与其指定来完成工程的人发生关系。因此，当事人各自对谁负有何种义务，应由行省总督裁定。

<!-- source-p 648 -->
<a id="50.10.2.2"></a>2. 行省总督应行使职权，防止有人擦去慷慨建造工程者的姓名，改刻他人姓名，以免因此打消其他市民为本城作出慷慨捐献的意愿。

<!-- source-p 649 -->
<a id="50.10.3"></a>50.10.3

<!-- source-p 650 -->
马克尔《论总督职责》第二卷

<!-- source-p 651 -->
<a id="50.10.3.pr."></a>序　私人可以未经元首授权建造新工程，但若该工程旨在与另一城市竞相攀比、可能引发骚乱，或位于马戏场、剧场或圆形竞技场周围，则除外。

<!-- source-p 652 -->
<a id="50.10.3.1"></a>1. 敕令明确规定，未经元首授权，不得使用公共经费建造新工程。

<!-- source-p 653 -->
<a id="50.10.3.2"></a>2. 公共工程上只得刻写元首的姓名，或出资建造该工程之人的姓名，不得刻写其他人的姓名。

<!-- source-p 654 -->
<a id="50.10.4"></a>50.10.4

<!-- source-p 655 -->
莫德斯丁《法学汇编》第十一卷

<!-- source-p 656 -->
甚至也不得在工程上方刻写行省总督的姓名。

<!-- source-p 657 -->
<a id="50.10.5"></a>50.10.5

<!-- source-p 658 -->
乌尔比安《论城市监理官职责》单卷

<!-- source-p 659 -->
<a id="50.10.5.pr."></a>序　若有人遗赠或设立遗嘱信托用于工程，利息何时开始、按何种标准计收，神君庇护的复函作如下规定：“若遗赠设置雕像或肖像的人未确定期限，应由行省总督确定期限；继承人未按期设置的，前六个月按较低利率计息，此后应向城市共同体支付半额利息。若已确定期限，而继承人声称找不到雕像，或就设置地点提出争议，则应在期限内将钱款提存；否则应立即支付半额利息。”

<!-- source-p 660 -->
<a id="50.10.5.1"></a>1. 私人不得占有公共边界土地。若行省总督发现此类公共土地，应将其与私人土地分开，并优先增加公共收入；若发现公共场所或建筑被私人使用，应评估是否应追回归公，还是对其征收租税，并采取其认为最有利于城市共同体的做法。

<!-- source-p 661 -->
<a id="50.10.6"></a>50.10.6

<!-- source-p 662 -->
莫德斯丁《法学汇编》第十一卷

<!-- source-p 663 -->
神君马可曾以复函规定，涉及城墙、城门或公共财产的工程，或新建城墙时，总督应向其请示元首。

<!-- source-p 664 -->
<a id="50.10.7"></a>50.10.7

<!-- source-p 665 -->
卡利斯特拉图斯《审判论》第二卷

<!-- source-p 666 -->
<a id="50.10.7.pr."></a>序　神君庇护曾以复函指出，遗赠用于新工程的钱款，若城市已有足够工程且难以找到资金修缮这些工程，应优先用于维护现有工程，而非用于启动新工程。

<!-- source-p 667 -->
<a id="50.10.7.1"></a>1. 某人承诺依人民意愿，以大理石或其他方式装饰他人建造的工程，并在工程上刻写自己的姓名时，元老院裁定：原建造者的铭文应予保留。若私人以自己的钱款为公共资金建造的工程另行出资，也应依同一指示在铭文中刻写其捐献的金额。

<a id="11"></a><a id="50.11"></a>50.11.0　论集市日（*De nundinis*）

<!-- source-p 669 -->
<a id="50.11.1"></a>50.11.1

<!-- source-p 670 -->
莫德斯丁《规则集》第三卷

<!-- source-p 671 -->
某人从元首处获准举办集市，却未加利用的，十年后即丧失该权利。

<!-- source-p 672 -->
<a id="50.11.2"></a>50.11.2

<!-- source-p 673 -->
卡利斯特拉图斯《审判论》第三卷

<!-- source-p 674 -->
若有人命令农夫或渔民本人将货物运到城市并亲自出售，就会妨碍粮食供应，因为农民会因此离开农事；他们把货物运到后，应立即交付并返回自己的工作。最后，希腊人中极具智慧和威望的柏拉图，在论述如何使城市生活安定幸福时，首先认为这类商人不可或缺。他在《理想国》第二卷说道：〔希腊文拉丁字母转写：*dei gar pleionwn ara gewrgwn te kai twn allwn dymiourgwn kai twn allwn diakonwn twn ge eisacontwn kai ecacontwn hekasta. ohutoi de eisin emporoi. komisas de ho gewrgos eis tyn agoran ti hwn poiei y tis allos twn dymiourgwn my eis ton auton xronon hyky tois deomenois ta par' autou antallacasvai, argysei tys ahutou dymiourgias kavymenos en agora oudamws, y d' hos, all' eisin ohi touto horwntes heautous epi tyn diakonian tattousi tautyn.*；底本拉丁释文：*Indiget enim [civitas] maiore numero rusticorum aliorumque opificum et ministrorum tam invehentium species quam exportantium: hi autem sunt negotiantes. [Quod si] rusticus aliusve qui opificum earum rerum quid quas facit in forum affereus non eo ipso tempore venerit, quo eo veniunt qui species ab eo allatas permutare cupiunt, num operam perdet in foro sedens? Minime, inquit ille, sunt enim qui id intellegentes ad hoc ministerium se accingunt.*〕〔译文：城市需要更多农夫、工匠及其他服务者，也需要负责运入和运出各类商品的人；这些人就是商人。农夫或其他工匠把自己制作的物品带到市场后，若未在那些希望以物易物的人到来的同一时间到场，难道就要坐在市场上白白耗费劳力吗？“当然不必，”他说，“因为有些人懂得这一点，便专门承担这种服务。”〕

<a id="12"></a><a id="50.12"></a>50.12.0　论允诺（*De pollicitationibus*）

<!-- source-p 676 -->
<a id="50.12.1"></a>50.12.1

<!-- source-p 677 -->
乌尔比安《论城市监理官职责》单卷

<!-- source-p 678 -->
<a id="50.12.1.pr."></a>序　某人若承诺为城市共同体建造工程或捐献钱款，在迟延履行之前不得向其请求利息；但若其开始迟延，则应计收利息，我国皇帝与其神君父皇曾以复函作此规定。

<!-- source-p 679 -->
<a id="50.12.1.1"></a>1. 应知，承诺人并非总是负有义务。若其因获得或将获得荣誉而作出承诺，或因其他正当理由作出承诺，则须履行允诺；若无正当理由作出承诺，则不负义务。多项新旧敕令均载有此规则。

<!-- source-p 680 -->
<a id="50.12.1.2"></a>2. 即使承诺人原本无正当理由作出承诺，只要已经开始履行，就负有义务。

<!-- source-p 681 -->
<a id="50.12.1.3"></a>3. 若已打下地基或清理场地，即视为开始履行。若城市已按其请求指定地点，也较宜认为其已经开始。其已将设备或经费放置在公共场所的，也同样处理。

<!-- source-p 682 -->
<a id="50.12.1.4"></a>4. 若并非承诺人本人开始工程，而城市共同体因为其承诺了一定金额而开始工程，则应视同工程已经开始，承诺人仍负有义务。

<!-- source-p 683 -->
<a id="50.12.1.5"></a>5. 某人承诺捐献柱子时，我国皇帝与其神君父皇曾作如下复函：“未基于正当事由向城市共同体允诺钱款的人，不得被强迫履行其慷慨承诺。但你既已向公民承诺捐献柱子，且工程已因此由城市共同体或私人出资开工，就不应放弃已开始的工程。”

<!-- source-p 684 -->
<a id="50.12.1.6"></a>6. 某人完成工程并将其交付后，工程又因偶然事件受损的，我国皇帝以复函指出，损失不应由建造者承担。

<!-- source-p 685 -->
<a id="50.12.2"></a>50.12.2

<!-- source-p 686 -->
乌尔比安《疑问集》第一卷

<!-- source-p 687 -->
<a id="50.12.2.pr."></a>序　某人若以誓愿将某物奉献给神明，即受其誓愿拘束。誓愿拘束的是立誓者本人，而非所誓奉之物。奉献该物确可履行誓愿，但该物本身并不因此成为神圣物。

<!-- source-p 688 -->
<a id="50.12.2.1"></a>1. 家父权下的家父只在成年且具有自权身份时受其誓愿拘束；家子或奴隶未经其父亲或主人的同意，不受誓愿拘束。

<!-- source-p 689 -->
<a id="50.12.2.2"></a>2. 某人若誓愿捐献其财产的十分之一，该十分之一在分离出来之前仍属于其财产。若立誓者在分离之前死亡，其继承人仍以继承人身份受该十分之一义务拘束；因为誓愿债务显然由继承人承受。

<!-- source-p 690 -->
<a id="50.12.3"></a>50.12.3

<!-- source-p 691 -->
乌尔比安《疑问集》第四卷

<!-- source-p 692 -->
<a id="50.12.3.pr."></a>序　协议是双方的合意与约定，而允诺只是提出承诺之人的单方承诺。因此，规则规定，若允诺是为获得荣誉而作，应如同债务一样予以追偿。此外，即使工程并非为荣誉而承诺，只要已经开工，承诺人也必须完成；此项规则亦已确定。

<!-- source-p 693 -->
<a id="50.12.3.1"></a>1. 若某人想追回自己依据允诺交给市镇共同体的物品，应驳回其请求；因为向城市作出的这类自愿捐献，最公平的是不得因反悔而撤回。即使市镇共同体已不再占有该物品，也应承认其享有诉权。

<!-- source-p 694 -->
<a id="50.12.4"></a>50.12.4

<!-- source-p 695 -->
马尔基安《法学阶梯》第三卷

<!-- source-p 696 -->
城市共同体遭受火灾、地震或其他灾祸时，某人若承诺提供援助，即受该承诺拘束。

<a id="50.12.5"></a>50.12.5

<!-- source-p 698 -->
乌尔比安《复答集》第一卷

<!-- source-p 699 -->
有人缺席时寄信承诺举行公共表演，乌尔比安答复卡里德摩斯说，不得强迫该人举行表演。

乌尔比安《论总督职责》第五卷

<a id="50.12.6.1"></a>1. 我国皇帝安敦尼以复函规定，某人为获得荣誉而承诺捐款并已经开始支付的，应如同工程已经开工一样履行其义务。

<!-- source-p 704 -->
<a id="50.12.6.2"></a>2. 应知，若女性为获得荣誉而作出允诺，她们与男性一样必须履行；我国皇帝与其神君父皇的复函均有规定。

<a id="50.12.8"></a>50.12.8

Procedent autem usurae in praemia artificum sic ut de unoquoque spectaculo ordo statuet.*；译文：我承诺并奉献三万第纳里的资金，每四年举办一次竞赛；本金由我保留，并向十人长提供足额担保，按惯例支付三万第纳里的利息，由我丈夫举办并主持竞赛，此后由我所生子女主持。利息将用于支付表演者奖金，具体数额由议事会按每场竞赛决定。〕我问：依允诺的措辞和条件，塞普提基娅的儿子们能否受到不利对待，以致不得亲自主持竞赛？赫伦尼乌斯·莫德斯丁答复：只要举办竞赛本身合法，就应遵守允诺所规定的条件。

<!-- source-p 735 -->
<a id="13"></a><a id="50.13"></a>50.13.0　论各种审判及裁判者被认为使诉讼成为自己的案件（*De variis et extraordinariis cognitionibus et si iudex litem suam fecisse dicetur*）

<!-- source-p 736 -->
<a id="50.13.1"></a>50.13.1

<!-- source-p 737 -->
乌尔比安《论各审判庭》第八卷

<!-- source-p 738 -->
<a id="50.13.1.pr."></a>序　行省总督通常审理报酬请求，但仅限于自由技艺教师。所谓自由技艺，是希腊人称为 *eleuveria* 的学问，包括修辞学教师、语法教师和几何学教师。

<!-- source-p 739 -->
<a id="50.13.1.1"></a>1. 医生与教师适用相同规则，但医生的理由更为正当：医生负责人的健康，教师负责人的学业。因此，医生的报酬请求也应由总督以非常程序审理。

<!-- source-p 740 -->
<a id="50.13.1.2"></a>2. 也应受理助产士的请求，因为她显然提供医疗服务。

<!-- source-p 741 -->
<a id="50.13.1.3"></a>3. 有人或许会把治疗身体某一部位或特定疼痛的人也算作医生，例如耳科医生、治疗瘘管或牙齿的人。但若其使用咒语、诅咒，或用俗称骗子的手法实施驱魔，则不在此列；这些都不属于医疗，尽管有人大肆声称自己从中受益。

<!-- source-p 742 -->
<a id="50.13.1.4"></a>4. 哲学家是否也属于教师？我认为不属于，并非因为哲学不是神圣的学问，而是因为他们首先应当宣示自己鄙弃受雇谋生。

<!-- source-p 743 -->
<a id="50.13.1.5"></a>5. 因此，总督也不审理民法教师的报酬请求。民法学问固然极其神圣，不应以金钱估价或加以贬损；诉讼中所求取的荣誉，本应在委托开始时作为敬意给予。有些款项即使收取时并不失体，索取时却可能有失体面。

<!-- source-p 744 -->
<a id="50.13.1.6"></a>6. 尽管初等学校教师不属于专业教师，但惯例上也由总督审理他们的请求；抄写员、书记员、计算员或账房人员亦如此。

<!-- source-p 745 -->
<a id="50.13.1.7"></a>7. 至于其他不从事文字或文书工作的行业工匠或技艺者，总督不应以非常程序审理其请求。

<!-- source-p 746 -->
<a id="50.13.1.8"></a>8. 随从若请求报酬，也适用教师的同一规则。

<!-- source-p 747 -->
<a id="50.13.1.9"></a>9. 总督也应审理针对上述所有人的案件，因为神圣的皇帝兄弟曾以复函规定，可以针对辩护人提起诉讼。

<!-- source-p 748 -->
<a id="50.13.1.10"></a>10. 法官确定辩护人的报酬时，应考虑诉讼规模、辩护人的口才、法庭惯例以及其将要出庭的法院；但报酬不得超过法定限额。我国皇帝与其父皇的复函作此规定：“若你指定的诉讼辩护人尤利乌斯·马特努斯准备履行其所承担的信用义务，你只得请求返还超出法定限额的款项。”

<!-- source-p 749 -->
<a id="50.13.1.11"></a>11. 凡以任何方式参与办理案件的人，均属于辩护人；但仅提供意见、不出庭办理案件而收取款项的人，不属于辩护人。

<!-- source-p 750 -->

<!-- source-p 751 -->
<a id="50.13.1.13"></a>13. 神君塞维鲁禁止辩护人死亡后向其继承人请求返还报酬，因为未能办理案件并非辩护人自身所致。

<!-- source-p 752 -->
<a id="50.13.1.14"></a>14. 总督或裁判官也负责审理乳母的请求；乳母可因照料婴儿而向总督请求应得的生活供养。乳母请求供养的期间，以婴儿仍由其哺乳为限；此后，总督或裁判官不再处理此类请求。

<a id="50.13.5.pr."></a>序　审判因多种事由而产生，除非作概括划分，否则难以容易地归入不同种类。因此，审判大致可分为四类：争议涉及担任荣誉职务或履行公共职务；涉及财产金钱；审查某人的名誉身份；或审理死刑罪名。

<a id="50.13.5.2"></a>2. 只要自由身份仍然保留，但因身份尊严方面的处罚而受制裁，名誉身份就会减损。例如某人被流放、从其所属等级中除名、被禁止担任公共荣誉职务、平民被杖打或判处公共劳役，或者其行为落入《永久告示》所列导致名誉受损的事由。

<!-- source-p 768 -->
<a id="50.13.5.3"></a>3. 发生重大人格减等、也就是丧失自由时，名誉身份即彻底丧失，例如被禁止使用水火而遭驱逐至远地。平民被判处矿场劳役或矿场刑罚，也属此类；公共劳役与矿场刑罚的性质没有不同，只有公共劳役逃跑者并非被处死，而是改受矿场刑罚。

<!-- source-p 805 -->

<!-- source-p 806 -->
<a id="50.15.4.pr."></a>序　人口登记规则规定，土地应按下列方式登记：每一地产的名称、所在城市及乡区、最近的两处邻地；在最近十年期间播种的耕地面积；葡萄园中的葡萄株数；橄榄林面积及树木数量；在最近十年期间收割的草地面积；牧场面积；以及可砍伐的林地。申报人应自行估价全部财产。

<!-- source-p 807 -->
<a id="50.15.4.1"></a>1. 人口登记官应适用衡平原则；若申报人因特定原因不能享用其在公共簿册中申报的财产，应依其职权予以减免。因此，若土地的一部分因地陷而灭失，登记官应准予减免。葡萄藤或树木枯死的，不应将其数量不公平地计入登记；但若有人砍掉树木或葡萄藤，仍应按登记时的数量申报，除非他向登记官证明砍伐的理由。

<!-- source-p 808 -->
<a id="50.15.4.2"></a>2. 某人在另一城市拥有土地的，应在土地所在地的城市申报；因为土地赋税应由该土地所在辖区的城市征收。

<!-- source-p 809 -->
<a id="50.15.4.3"></a>3. 虽然某些给予个人的免税利益会随本人消灭，但普遍给予某地或某城市的免税，似应视为可以传给后代。

<!-- source-p 810 -->
<a id="50.15.4.4"></a>4. 若我占有土地时已作申报，而主张土地归其所有的人未作申报，后者仍保有诉权。

<!-- source-p 811 -->
<a id="50.15.4.5"></a>5. 申报奴隶时，应逐一申报其族属、年龄、职务和技艺。

<!-- source-p 812 -->
<a id="50.15.4.6"></a>6. 物主也应在人口与财产登记中申报渔业湖泊及港口。

<!-- source-p 813 -->
<a id="50.15.4.7"></a>7. 若地产中有盐场，也必须申报。〔底本作 *si [sie] quae sunt*，保留其疑似讹误。〕

<!-- source-p 814 -->
<a id="50.15.4.8"></a>8. 未申报房客或佃户的人，应受登记义务的强制拘束。

<!-- source-p 815 -->
<a id="50.15.4.9"></a>9. 人口登记完成后出生或取得的财产，可以在登记程序结束前补充申报。

<!-- source-p 816 -->
<a id="50.15.4.10"></a>10. 某人申请许可，以便更正自己的登记；获准后却发现其实无须更正的，多份复函规定，其提出更正申请这一事实不会对其造成任何不利。

<a id="50.15.5"></a>50.15.5

<!-- source-p 818 -->

<!-- source-p 819 -->
<a id="50.15.5.pr."></a>序　为处理事务而仅向一名土地占有人追缴赋税时，国库应授予该占有人针对其他同样以地产承担税款者的诉权，使各人按其地产份额分担税款。即使国库已经收回自己的钱款，授予该诉权仍非无用，因为这相当于国库已收取出售这些债权所得的价款。

<!-- source-p 821 -->
<a id="50.15.5.2"></a>2. 土地应以质权方式出售以清偿到期未付的赋税债务；为阻止出售而提出的延期担保不予接受。遗赠受领人若以过去期间的赋税为由反对出售，也不应获听取；因为继承人有偿付能力，而且受托征收赋税的人也负有相关责任。
