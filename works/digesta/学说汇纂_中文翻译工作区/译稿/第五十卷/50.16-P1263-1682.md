<!-- source-p 1265 -->
奈波斯致普罗库鲁，问候。有人作出如下嫁资允诺：“条件便利时，我将给你一百金币，作为我女儿的嫁资。”你认为婚姻一经成立，嫁资是否即可请求？如果他作出的是这样的允诺：“我能够时，这笔钱将作为嫁资”，又该如何？如果后一种义务具有一定效力，你如何解释“能够”一词，是指扣除债务后仍有能力，还是指尚未扣除债务？普罗库鲁答：有人这样允诺嫁资：“我能够时，将一百金币给你作为嫁资”，我认为应依当事人所为之事解释；含混表达者所说的，应当按照其表达内容所显示的意思理解。不过，更可能的是，应认为其意思是“扣除债务后我有能力时”。也可以将其理解为“在不损害我尊严的情况下有能力时”；若允诺写作“条件便利时”，也就是“在不使我遭受不便的情况下能够时”，则更应采用这种解释。

盖尤斯《十二表法评注》第六卷

<!-- source-p 1640 -->

2. “质物”（*pignus*）一词源于拳头，因为作为质押交付的物品是用手交付的。因此，有些人认为质押严格说来只能设立于动产，这一看法似乎也确有道理。

**50.16.239**

<!-- source-p 1645 -->
庞波尼《手册》单行本

<!-- source-p 1646 -->
<a id="50.16.239.pr."></a>
序：“未适婚人”（*pupillus*）是指尚未达到适婚年龄、却因死亡或脱离家父权而不再处于父亲权力之下的人。

<!-- source-p 1647 -->
<a id="50.16.239.1"></a>
1. “奴隶”一词据说源自这样的做法：我们的皇帝通常出售俘虏，以此使他们免于死亡、保全其性命。

<!-- source-p 1648 -->
<a id="50.16.239.2"></a>
2. “居住者”（*incola*）是指将住所迁至某地区的人；希腊人称其为 *paroikos*。居住者不仅包括在城镇居住的人，也包括在某城镇辖区内拥有土地并以该土地为住所的人。

<!-- source-p 1649 -->
<a id="50.16.239.3"></a>
3. “公共职务”是私人承担的一项职责，该职责依行政长官的特别命令，使个别或全体公民及其财产获得利益。

<!-- source-p 1650 -->
<a id="50.16.239.4"></a>
4. “外来居住者”（*advena*）是希腊人所称的 *apoikos*。

<!-- source-p 1651 -->
<a id="50.16.239.5"></a>
5. 有人说，“城市议员”（*decuriones*）一词源自殖民地最初建立时的做法：被派去建城的人中，每十人选出一人列入公共议事名册。

<!-- source-p 1652 -->
<a id="50.16.239.6"></a>
6. “城市”（*urbs*）一词源自 *urbo*；*urbare* 是用犁划界。瓦鲁斯说，*urbum* 指犁的弯曲部分，建城划界时会用到。

<!-- source-p 1653 -->
<a id="50.16.239.7"></a>
7. “城镇”（*oppidum*）一词源于“保护”（*ops*），因为城墙是为保护而建。

<!-- source-p 1654 -->
<a id="50.16.239.8"></a>
8. “辖区”（*territorium*）是某城市边界内所有土地的整体。有人说，此词源于该地行政长官有权在这些边界内恐吓他人，即命其离开。

<!-- source-p 1655 -->
<a id="50.16.239.9"></a>
9. “自己的”一词含义不明，可能指全部，也可能指一部分。因此，若有人宣誓某物不属于自己，还应补充说明该物也不与自己共有。

<!-- source-p 1657 -->
保罗《皇帝裁判中所作判决汇编》六卷本第一卷

有人询问，约定“婚姻解除时返还嫁资”，是否不仅包括离婚，也包括死亡；换言之，缔约人是否也考虑了后一种情形。许多人认为其意思确实如此，但另一些人持相反意见。皇帝基于上述考量作出裁判，认定当事人的约定是：无论发生何种情形，嫁资均不得留在丈夫手中。

<a id="50.16.242"></a>
**50.16.242**

<!-- source-p 1663 -->
雅沃勒努斯《拉贝奥遗著》第二卷

<!-- source-p 1664 -->
<a id="50.16.242.pr."></a>
序：拉贝奥说，船桅是船舶的一部分，但 *artemon* 不是；因为大多数船舶没有主桅便无法使用，所以主桅被视为船舶的一部分；而 *artemon* 更像是附加物，而非船舶的一部分。

<!-- source-p 1665 -->
<a id="50.16.242.1"></a>
1. 拉贝奥说，“突出物”与“嵌入物”的区别在于：突出物是向外伸出且不在任何地方支承的东西，例如阳台和屋檐；嵌入物则是以某种方式在一处获得支承的东西，例如嵌入墙中的椽子或横梁。

<!-- source-p 1666 -->
<a id="50.16.242.2"></a>
2. 拉贝奥说，铺在瓦片上的铅属于建筑物；但为覆盖露天部分而铺设的铅则不属于建筑物。

<!-- source-p 1667 -->
<a id="50.16.242.3"></a>
3. 拉贝奥说，“寡妇”不仅指曾经结过婚的妇女，也指从未有过丈夫的妇女；因为据说 *vidua*（寡妇）一词的构成类似于 *vecors*（无心智）和 *vesanus*（失常），意指缺少心智或理智；同样，寡妇被称为缺少 *duitas*〔底本所述词源含义不详〕。

<!-- source-p 1668 -->
<a id="50.16.242.4"></a>
4. 拉贝奥说，以木板铺设的房间地板，夏季拆下、冬季铺设，属于房屋的一部分，因为它是为持续使用而准备的；其间被拆下并不影响这一点。

**50.16.243**

<a id="50.16.244"></a>
**50.16.244**

<!-- source-p 1673 -->
拉贝奥《可行论》第四卷，保罗摘要

<!-- source-p 1674 -->
拉贝奥说：“凡属刑罚的，都是罚款；凡属罚款的，都是刑罚。”保罗说：这两种说法都不正确。二者的差异也表现在：刑罚不得上诉；一旦某人因被规定刑罚的犯罪而败诉，刑罚即立即到期。罚款则可以上诉；只有在未提起上诉，或上诉人败诉时，罚款才到期；而且必须由有权科处罚款的人作出。二者还有一项区别：每一种犯罪均有确定的刑罚；罚款则由裁判者自行决定数额，但法律规定数额的情形除外。
