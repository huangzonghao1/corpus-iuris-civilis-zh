## D.50.1　论市民与居住者（*Ad municipalem et de incolis*）

<!-- source-p 0001 -->
50.1.0　论市民与居住者（*Ad municipalem et de incolis*）

<!-- source-p 0002 -->
<a id="1"></a><a id="50.1.1"></a>50.1.1

<!-- source-p 0003 -->
乌尔比安《告示评注》第二卷

<!-- source-p 0004 -->
<a id="50.1.1.pr."></a>序　取得市民身份的原因包括出生、释奴和收养。

<!-- source-p 0005 -->
<a id="50.1.1.1"></a>1. 严格说来，“市民”是指参与公共负担、加入某一城市并与我们共同承担公共事务的人；但如今“市民”一词也被宽泛地用于指各城市的本地居民，例如坎帕尼亚人、普特奥利人。

<!-- source-p 0006 -->
<a id="50.1.1.2"></a>2. 因此，父母都是坎帕尼亚人的人所生子女，也是坎帕尼亚人。但如果父亲是坎帕尼亚人、母亲是普特奥利人，子女同样是坎帕尼亚市民；除非另有特权规定应依母亲的籍贯确定身份，在这种情况下，子女才是母亲籍贯地的市民。例如，伊利昂人获准规定，母亲是伊利昂人的，其子女即为该城的市民。德尔斐人也获准并维持了同一规则。凯尔苏斯还记载，庞培大帝给予本都人一项特权：母亲是本都人的，其子女即为本都人。有些人认为，这项特权只适用于非婚生子女。凯尔苏斯不赞同这种看法：因为无需特别规定非婚生子女应随母亲身份——他们还能有何种其他籍贯？该规则应适用于父母来自不同城市的人。

<!-- source-p 0007 -->
<a id="50.1.2"></a>50.1.2

<!-- source-p 0008 -->
乌尔比安《论辩》第一卷

<!-- source-p 0009 -->
<a id="50.1.2.pr."></a>序　家子经父亲同意而被选为市议员的，父亲对交付给该子的一切市议员职务负担，均如同保证人一般承担责任。父亲在提名时身在现场而未提出异议的，应视为同意其子担任市议员。因此，儿子在城市公共事务中所做的一切，父亲均应以保证人身份负责。

<!-- source-p 0010 -->
<a id="50.1.2.1"></a>1. 所谓在城市公共事务中行事，是指经手公款，或者决定公款应当如何支出。

<!-- source-p 0011 -->
<a id="50.1.2.2"></a>2. 如果儿子被任命为公共工程或其他城市事务的监察人，父亲也承担责任。

<!-- source-p 0012 -->
<a id="50.1.2.3"></a>3. 如果儿子为自己指定继任者，也会使父亲承担责任。

<!-- source-p 0013 -->
<a id="50.1.2.4"></a>4. 如果儿子承包了公共税收的征收，父亲也承担责任。

<!-- source-p 0014 -->
<a id="50.1.2.5"></a>5. 如果儿子没有为未适婚人指定监护人，或选任的人不适任，或未要求提供充分担保，或接受了不适任的担保人，毫无疑问，儿子本人须承担责任。但父亲只有在保证人通常也因这种事由承担责任时才负有义务；然而保证人通常不承担此类责任，相关规定也曾经作出说明并以复函确认。因为保证人承诺确保城市公共事务不受损害，而未适婚人是否获得监护人，并不使城市在金钱方面具有利害关系。

<!-- source-p 0015 -->
<a id="50.1.2.6"></a>6. 超出准假期限，或超出准假令所规定范围而离开的市议员，可以被征召承担公共职务。

<a id="50.1.6.pr."></a>序　虚构籍贯的采用不会消灭自然事实：错误不会使真实籍贯丧失，谎称自己来自某地也不会使真实籍贯消失。无论拒绝承认自己出生的故乡，还是谎称来自自己并非出生于其中的城市，都不能改变真实情况。

<!-- source-p 0028 -->
<a id="50.1.6.1"></a>1. 子女应随其父亲的自然籍贯，而非父亲的住所，取得城市身份。

<!-- source-p 0029 -->

<!-- source-p 0045 -->
<a id="50.1.11.pr."></a>序　皇帝提图斯·安敦尼曾致伦图卢斯复函，说明官职的职责不可分割，责任由同僚共同承担。对此应作如下理解：只有在无法从实际履职者本人或代其介入者处追回财物，且该履职者在离任时已无力清偿的情况下，才将责任归于其同僚。反之，如果本人或担保适格，或者在可以向其追偿时仍有清偿能力，则每个人只对其经管的事项负责。

<!-- source-p 0046 -->
<a id="50.1.11.1"></a>1. 如果由其承担风险而提名官员的人有清偿能力，应先像对保证人那样向其提起诉讼，还是只有在无法从同僚处追回财物时才可以起诉？裁定认为，应先向提名者追偿，视同其为保证人；因为对同僚的追诉基于其疏忽及处罚责任，而对提名者的追诉则基于其保证责任。

<!-- source-p 0047 -->
<a id="50.1.12"></a>50.1.12

<!-- source-p 0048 -->
帕比尼安《答复集》第一卷

<!-- source-p 0049 -->
不应给予该人针对被提名者之同僚的有益诉权。〔该句所指的“该人”及诉权关系，因上下文节录简略而待核。〕

<!-- source-p 0050 -->
<a id="50.1.13"></a>50.1.13

<!-- source-p 0051 -->
帕比尼安《疑义集》第二卷

<!-- source-p 0052 -->
那么，如果某一官员整年缺席，或者虽在任，却因抗命、懈怠或身体欠佳而不处理城市事务，所有事务均由其同僚独自管理，而仍无法从该同僚处追回全部财物，应如何处理？应按以下顺序追责：首先，实际处理城市事务的官员及为其提供担保的人承担全部责任；待对他们的追偿程序结束后，再追究提名不适任官员者的责任；最后，追究另一名未参与城市事务的官员的责任。提名者不能正当地拒绝承担全部风险，因为他本应知道，被提名者将承担不可分割的职务和共同风险。即使两人都实际履职，若无法从其中一人处追回全部应付款项，提名其同僚的人也应对全部款项承担责任。

帕比尼安《答复集》第一卷

<!-- source-p 0058 -->
<a id="50.1.15.pr."></a>序　市议员一度被逐出议事会，后来又恢复议事会成员身份并担任官职的，如同被处迁居限制者，应在与其失去身份尊荣的期间相同的期间内不得任职。不过，两种情况下都应审查他们因何种罪行被定罪而受到此类判决。受到较重刑罚者，经历一段时间后可如同事情已经了结般解除名誉受损；但受到法律所允许的较轻刑罚者，仍应列为名誉受损者，因为对事实的判断属于裁判者的权限，而法律的权威并不由裁判者决定。

<!-- source-p 0059 -->
<a id="50.1.15.1"></a>1. 如果某人以自己承担风险的方式指定继任者，而继任者在任期结束时有清偿能力，则不得对指定者提起诉讼。

<!-- source-p 0060 -->
<a id="50.1.15.2"></a>2. 为逃避城市公共义务而通过秘密信托转移的土地，应归国库所有；而另一名被禁止事项的参与者，仅被要求以自己的财产偿付其中一人的份额。

<!-- source-p 0061 -->
<a id="50.1.15.3"></a>3. 通过收养不能改变其籍贯地所产生的担任官职及承担公共负担的义务；但养父还可以使儿子承担新的公共负担。

<a id="50.1.17"></a>50.1.17

<!-- source-p 0066 -->
帕比尼安《答复集》第一卷

<!-- source-p 0067 -->
<a id="50.1.17.pr."></a>序　被释奴不会仅因其保护人而免于城市公共负担；无论他是否为保护人提供劳务，或在保护人失明后侍奉保护人，都不影响这一点。

<!-- source-p 0068 -->
<a id="50.1.17.1"></a>1. 但是，替元老保护人处理事务的被释奴，依元老院决议可以免于担任监护人。

<!-- source-p 0069 -->
<a id="50.1.17.2"></a>2. 父亲希望儿子担任市议员的，城市应先以儿子本人的身份向儿子追责，而非先以儿子身份向父亲追责。儿子是否仅拥有军营特有产并不影响这一点，无论该特有产是在服役前还是服役后取得。

<!-- source-p 0070 -->
<a id="50.1.17.3"></a>3. 为担任官职或承担其他公共职务而规定的期间抗辩，只适用于其所针对的人，不适用于其他人。

<!-- source-p 0071 -->
<a id="50.1.17.4"></a>4. 同一人不得同时在两个城市担任官职。因此，如果两个城市同时授予其官职，应优先考虑其籍贯地。

<!-- source-p 0072 -->
<a id="50.1.17.5"></a>5. 仅以持有财产为由，不能在没有城市特别特权的情况下，要求财产占有人承担城市公共负担。

<!-- source-p 0073 -->
<a id="50.1.17.6"></a>6. 依回归权返回故乡的人，即使身处他城境内，也必须履行故乡的公共负担。

<!-- source-p 0074 -->
<a id="50.1.17.7"></a>7. 征收税款不属于卑贱的公共负担，因此也可以交由市议员承担。

<!-- source-p 0075 -->
<a id="50.1.17.8"></a>8. 某人因遗嘱信托而被释奴的，在承担城市公共负担时随释奴者的籍贯地，而非随遗嘱中指定其获得自由的人之籍贯地。

<!-- source-p 0076 -->
<a id="50.1.17.9"></a>9. 神君庇护认为，某人被收养进入养家后，即使不存在任何欺诈嫌疑，也应参照已授予公共职务的规则，在其自然祖父的籍贯地承担城市公共负担。

<!-- source-p 0077 -->
<a id="50.1.17.10"></a>10. 某人误以为自己是某城市的市民或殖民地居民，因而承诺承担城市公共负担的，该错误不排除其提出法律抗辩。

<!-- source-p 0078 -->
<a id="50.1.17.11"></a>11. 父亲的住所，不会使其居住于其他城市的儿子承担该城市的公共负担；因为即使对父亲本人而言，住所也是可变的。

<!-- source-p 0079 -->
<a id="50.1.17.12"></a>12. 在重大刑事案件中被正式控告的人，在案件审结前不得被任命担任新的官职；但其原有的身份尊荣暂时不受影响。

<!-- source-p 0080 -->
<a id="50.1.17.13"></a>13. 仅在他城拥有一所房屋，不会使该城成为其住所。

<!-- source-p 0081 -->
<a id="50.1.17.14"></a>14. 为继任者指定的保证人，不对提名继任者的人承担责任。

<!-- source-p 0082 -->
<a id="50.1.17.15"></a>15. 承诺确保城市公共事务不受损害的保证人，以及以自己承担风险的方式提名官员的人，不承担其所介入担保之人可能招致的惩罚性诉讼责任；他们承诺承担城市损失，已经足够。

保罗《答复集》第一卷

<!-- source-p 0094 -->
<a id="50.1.21.pr."></a>序　卢基乌斯·提提乌斯仍处于父亲家父权下时，行省官员未经父亲同意，在其他人之中任命他负责采购粮食。提提乌斯既未同意此事，也未收取钱款、未提供担保，亦未参与与其他采购者的交易。父亲去世后，他开始被要求承担其同僚留下的欠款。问题是，他是否应基于此事承担责任。保罗答复说，官员委任某人承担公共职务，而其拒绝接受的，可以因城市遭受损失而对其提起诉讼，即使他在被任命时仍处于他人的家父权之下。

<!-- source-p 0095 -->
<a id="50.1.21.1"></a>1. 保罗答复说，因其所管理的职务而被起诉、且责任并非源于契约而是源于职务的人，通常只对本金损失承担替代责任，不对利息承担责任。

<!-- source-p 0096 -->
<a id="50.1.21.2"></a>2. 他还答复说，不得因儿子在父亲死后承担的公共职务而依法起诉父亲的继承人。父亲指定儿子担任市议员、但儿子在父亲死后才承担该职务的，也适用这一答复。

<!-- source-p 0097 -->
<a id="50.1.21.3"></a>3. 他还答复说，收养市议员的人应视为承担了该市议员职务的负担；这与父亲同意儿子担任市议员时，父亲承担相应责任的规则相同。

<!-- source-p 0098 -->
<a id="50.1.21.4"></a>4. 他还答复说，婚姻存续期间嫁资属于丈夫的财产；但如果按特定财产数额征收市政负担，嫁资不应计入。

<!-- source-p 0099 -->
<a id="50.1.21.5"></a>5. 他还答复说，如果并非控告人的过错导致其未能在规定期间内追诉重大犯罪，被告在此期间不应谋求担任官职。

<!-- source-p 0100 -->
<a id="50.1.21.6"></a>6. “皇帝塞维鲁与安敦尼致塞普蒂米乌斯·泽诺努斯。你希望你尚未成年的儿子担任市议员；尽管你已为其将来的责任作出保证，但在此期间不得强迫你承担相关负担，因为你似乎只是同意他承担可以委任的那些职务。”

<!-- source-p 0101 -->
<a id="50.1.21.7"></a>7. 他还答复说，如果城市没有关于准许加价竞投的专门法律，就不得退出已经完成的公有土地租赁或出售；因为准许加价竞投的期限，属于国库事务的规则。

<!-- source-p 0104 -->

<a id="50.1.36.pr."></a>序　提提乌斯因求学而身在罗马，其本籍地官员寄给他一封信，要求他向皇帝呈递该城邦的一项决议；该决议随信一并寄出。负责归还该信的人与他人串通，将信交给了卢基乌斯·提提乌斯；后者也因个人事务而居于罗马。此人划去原本应由其呈递决议的提提乌斯之名，写上自己的名字，遂依城邦的委托向皇帝呈递了决议。我问：谁本可请求旅费？未将信交还给受托收信之人者，以及划去他人姓名、写上自己姓名，仿佛自己是受本籍地委托而向皇帝呈递决议者，各自似乎实施了何种不法行为？赫雷尼乌斯·莫德斯蒂努斯答复说，提提乌斯本人无权请求旅费；请求权属于那个划改姓名的人。〔“qui nomen incidisset”所指的行为及旅费请求权归属，原文语义待核。〕

<!-- source-p 0159 -->
<a id="50.1.36.1"></a>1. 提提乌斯以自己贷出的公款为担保，收取了质物，并与债务人约定：债务未清偿时，无须任何另行保证即可变卖质物。此后接任者依次认可了提提乌斯的债权名义及质权，直至梅维乌斯。由于负责出售的官员曾就土地面积作出保证，质物变卖所得不足以清偿债务。于是有人询问，谁应对城邦负责。赫雷尼乌斯·莫德斯蒂努斯答复说：我认为，既然提提乌斯的继任者已经承认该债权名义所涉风险，提提乌斯就不再因该名义负担责任；负责出售的官员也不负此责，尽管据称他们因说明土地面积而以较高价格售出，而在查明土地实际面积较小后，又被命令返还因此多收的部分。因此，最后一位认可该债权名义的人应使城邦免受损失，除非能够证明他已将该债权名义移交给有偿付能力的继任者。

<!-- source-p 0174 -->
<a id="2"></a><a id="50.2"></a>50.2.0　论市议员及其子女

<!-- source-p 0175 -->
<a id="50.2.1"></a>50.2.1

<!-- source-p 0176 -->
乌尔比安《意见集》第二卷

<!-- source-p 0177 -->
经证明，市议员离开其所属城邦的住所而迁往别处的，行省总督应促使其返回本籍地，并履行与其身份相称的公共负担。

<!-- source-p 0178 -->
<a id="50.2.2"></a>50.2.2

<!-- source-p 0179 -->
乌尔比安《论辩集》第一卷

<!-- source-p 0180 -->
<a id="50.2.2.pr."></a>序　市议员若被处以暂时迁居限制，就不再是市议员。其返回后当然不能恢复原有席位，但也并非永远不得再成为市议员；因此，他不会恢复原席位（因为可以另选一人填补该席），如果议员名额已满，他就必须等到有空缺时再任职。暂时被免除议员身份者则不同：期限届满后，他即恢复市议员身份。当然，其席位也可能已经由他人填补；若名额已满，他同样应等待席位空缺。

<!-- source-p 0181 -->
<a id="50.2.2.1"></a>1. 不过，恢复议员身份后，他应保有原先的议员顺序，还是取得当前所处的顺序，仍可讨论，例如在确定发表意见的先后次序时。我认为，他应保有先前的顺序。暂时受迁居限制者则不然，因为他是以新任议员的身份进入议事会。

<!-- source-p 0182 -->
<a id="50.2.2.2"></a>2. 关于市议员之子，问题在于：只有受孕并出生于市议员任内者才算市议员之子，还是在其父成为市议员之前出生的儿子也包括在内？就不得以棍杖惩罚或判处矿场劳役而言，父亲原为平民并无妨碍，只要此后取得了市议员身份。关于祖父，帕皮尼安也作了相同答复，以免父亲的污名玷污儿子。

<!-- source-p 0183 -->
<a id="50.2.2.3"></a>3. 但是，如果此人的父亲被免除议员身份：若父亲在此人受孕前即被免职，我认为，在荣誉身份上应将此人视为平民之子；若父亲在此人受孕后才丧失身份，则应本于宽厚，将此人视为市议员之子。

<!-- source-p 0184 -->
<a id="50.2.2.4"></a>4. 同理，此人若在父亲被处迁居限制后出生：如在限制前已受孕，应视同元老之子；如在限制后才受孕，该限制则对其不利。

<!-- source-p 0185 -->
<a id="50.2.2.5"></a>5. 如果父亲暂时被免除议员身份，而儿子在此期间受孕并出生；即使其父在恢复议员身份之前已经去世，儿子是否仍作为市议员之子出生？对此应作有利于当事人的解释，予以承认。

<!-- source-p 0186 -->
<a id="50.2.2.6"></a>6. 此外，某人受孕时其父为平民，后来父亲在其出生前取得市议员身份，却又在其出生前丧失该身份；有人可以有利地答复说，中间取得身份的期间应对该子有利，仿佛他当时已经出生。

<!-- source-p 0187 -->
<a id="50.2.2.7"></a>7. 父亲的任何犯罪都不得使无辜的儿子受罚；因此，也不得因此禁止儿子进入市议会或取得其他荣誉身份。

<!-- source-p 0188 -->
<a id="50.2.2.8"></a>8. 敕令禁止违背本人意愿，召年满五十五岁者担任市议员。但若其同意，即使已年满七十岁，也不必承担城市公共负担，却仍须担任荣誉职务。

<!-- source-p 0189 -->
<a id="50.2.3"></a>50.2.3

<!-- source-p 0190 -->
乌尔比安《论行省总督职责》第三卷

<!-- source-p 0191 -->
<a id="50.2.3.pr."></a>序　一般而言，应当维护如下规则：因被暂时处以迁居限制而受较轻判决的人，应当珍视这一体现宽仁的判决，不得要求恢复市议员身份。

<!-- source-p 0192 -->
<a id="50.2.3.1"></a>1. 但是，某人若因虚假事由或其他较重事由，并非被暂时处以迁居限制，而只是暂时被免除议员身份，则其可以恢复议员身份。皇帝安敦尼曾发布敕令规定：任何人无论因何事由，暂时被禁止担任议员、从事辩护或履行其他职务的，期限届满后仍可担任其荣誉职务或履行其职务。这一规定正确，因为不应加重已经限定禁止期限的判决。

<!-- source-p 0193 -->
<a id="50.2.3.2"></a>2. 私生子可以被列入市议会，这一点毫无疑问；但若有一名通过合法婚姻所生的适格竞争者，应优先选任后者。神圣的兄弟皇帝曾就此复函给比提尼亚总督洛利安努斯·阿维图斯。若无此类竞争者，品行和生活均正当的私生子也可获准担任市议员；这绝不会使议会蒙羞，因为议会始终保持满额，符合其利益。

<!-- source-p 0194 -->
<a id="50.2.3.3"></a>3. 神圣的塞维鲁与安敦尼允许遵从犹太教信仰者取得荣誉职务，但也令他们承担不侵害其信仰所必需的公共义务。

帕皮尼安《答复集》第一卷

<!-- source-p 0206 -->

<!-- source-p 0207 -->
<a id="50.2.6.4"></a>4. 儿子被选为市议员后提出异议的父亲，即使因时效抗辩而被排除在外，只要他没有认可已经进行的事项，就不必代儿子承担城市公共负担。

<!-- source-p 0208 -->
<a id="50.2.6.5"></a>5. 在其他特权不适用时，同时依法凭借多个票数获得市议员身份者，在发表意见时应居于较优顺序。此外，子女较多者，在其所属议事会中优先被征询意见，并按荣誉顺序居于他人之前。

<!-- source-p 0213 -->
<a id="50.2.7.2"></a>2. 非市议员不得担任二人执政官或其他荣誉职务，因为禁止平民担任市议员所享有的荣誉职务。

贩卖日用商品的人，虽然会被市政官鞭打，却不应因此被当作卑贱之人而忽视。因此，并不禁止此类人在本籍地申请市议员身份或其他荣誉职务，因为他们并非不名誉者。即使曾被市政官依法以鞭刑处罚，也不因此被排除于荣誉职务之外。不过，我认为，让受过鞭打的人进入议会并不体面，尤其是在有大量正派人士的城邦中；但是，需要承担公共负担的人数不足时，只要此类人有财产，也必须让其取得市镇身份。

<!-- source-p 0241 -->

<!-- source-p 0248 -->
<a id="4"></a><a id="50.4"></a>50.4.0　论公共负担与荣誉职务

<!-- source-p 0249 -->
<a id="50.4.1"></a>50.4.1

<!-- source-p 0250 -->
赫莫革尼安《法学撮要》第一卷

<!-- source-p 0251 -->
<a id="50.4.1.pr."></a>序　城市公共负担有些属于财产负担，有些属于人身负担。

<!-- source-p 0252 -->
<a id="50.4.1.1"></a>1. 财产负担包括车辆运输业务、船舶运输业务以及十人首长职务；因为这些职务的承担者须自担风险，负责征收常规税款。

<!-- source-p 0253 -->
<a id="50.4.1.2"></a>2. 城市人身负担包括：为城邦辩护，即担任代理人；负责征收人口税或财产税的使团；书记员职务；“kamylasia”〔原文用词含义未详〕；负责粮食供应及类似事务；管理公有土地；采购粮食；管理输水道；负责马戏表演用马；修缮公路；管理粮仓；为浴场供热；分配粮食，以及其他类似的事务。根据长期形成的习惯，也可以依每个城邦的法律认定上述事项之外的其他负担。

<!-- source-p 0254 -->
<a id="50.4.1.3"></a>3. 一般应当牢记：人身负担是通常要求以身体劳作，并同时投入注意力与警觉性的事务；财产负担则主要要求支出费用。

<!-- source-p 0255 -->
<a id="50.4.1.4"></a>4. 监护、对成年受监护人或精神失常者的保佐、挥霍者的保佐、哑者的保佐，以及为胎儿提供给养、饮水、住所等事务，也同样属于人身负担。另有一种财产管理人，其职责在于阻止取得时效完成，并防止债务人获释；对于依据《卡尔博尼安告示》请求遗产占有、却未提供担保者，为保管财产而指定的管理人，也承担人身负担。为管理被敌人俘获、且预期将返回者的财产而指定的管理人，以及为保管尚无人依市民法或裁判官法继承之人的遗留财产而指定的管理人，也属于类似情形。

<!-- source-p 0256 -->
<a id="50.4.2"></a>50.4.2

<!-- source-p 0257 -->
乌尔比安《萨宾评注》第二十一卷

<!-- source-p 0258 -->
就荣誉职务而言，即使儿子处于父亲的家父权之下，也认为父亲对其具有支配权。

<!-- source-p 0259 -->
<a id="50.4.3"></a>50.4.3

<!-- source-p 0260 -->
乌尔比安《意见集》第二卷

<!-- source-p 0261 -->
<a id="50.4.3.pr."></a>序　出身于罗马城的人，如果在别处设定住所，也应承担该地的公共负担。

<!-- source-p 0262 -->
<a id="50.4.3.1"></a>1. 对于正在军营服役的人，不得加派任何市镇公共负担。其他平民即使是军人的亲属，也应服从其本籍地和行省的法律。

<!-- source-p 0263 -->
<a id="50.4.3.2"></a>2. 被判处矿场劳役者若获准恢复原状，应视同从未被定罪，因而可以被征召承担公共负担或荣誉职务；他不得仅以自己曾遭不幸和不利命运为由，主张自己不再适合作为本籍地的公民。

<!-- source-p 0264 -->
<a id="50.4.3.3"></a>3. 女性因其性别而免于身体劳作性质的公共负担。

<!-- source-p 0265 -->
<a id="50.4.3.4"></a>4. 儿子若无任何免责事由，父亲即使仍对其行使家父权，也无权阻止向其分派荣誉职务或公共负担。

<!-- source-p 0266 -->
<a id="50.4.3.5"></a>5. 父亲不同意儿子担任荣誉职务或承担公共负担，是为了避免其财产被置于责任之下；此举可以构成抗辩，但不得在可能范围内剥夺本籍地利用其公民服务的机会。

<!-- source-p 0267 -->
<a id="50.4.3.6"></a>6. 父亲虽已年满七十五岁，且有五名健在子女，因而免于城市公共负担，但其子仍须以自己的名义承担适用于他们的负担；这正是因子女而给予父亲免除负担特权的对应安排，即由子女承担这些负担。

<!-- source-p 0268 -->
<a id="50.4.3.7"></a>7. 继父在法律上无须以继子名义承担城市公共负担。

<!-- source-p 0269 -->
<a id="50.4.3.8"></a>8. 被释奴应在其保护人的籍贯地承担公共负担，但以其拥有足以承担这些负担的自有财产为限；保护人的财产不受被释奴所承担公共负担的拘束。

<!-- source-p 0270 -->
<a id="50.4.3.9"></a>9. 父亲因某项犯罪而受追诉，不应妨碍其子取得荣誉职务。

<!-- source-p 0271 -->
<a id="50.4.3.10"></a>10. 早已确定，未满二十五岁的非军人也可以担任“十人首长”（decaproti），因为这更像是一种财产负担。

<!-- source-p 0272 -->
<a id="50.4.3.11"></a>11. 已确定，征收贡税属于财产负担。

<!-- source-p 0273 -->
<a id="50.4.3.12"></a>12. 采购粮食属于公共负担；年满七十岁或有五名健在子女者，可以免除该负担。

<!-- source-p 0274 -->
<a id="50.4.3.13"></a>13. 对于来到城邦后必须获提供住宿的军人，应由所有负有该项义务的人轮流接待。

<!-- source-p 0275 -->
<a id="50.4.3.14"></a>14. 在家中接待客人的负担，属于财产负担而非人身负担。

<!-- source-p 0276 -->
<a id="50.4.3.15"></a>15. 行省总督应依年龄和身份，安排城邦中的公共负担与荣誉职务，使其按次序轮流承担；应依照古来确立的公共负担和荣誉职务等级分派，以免不加区别、频繁地压在同一批人身上，致使城邦同时失去人员与财力。

<!-- source-p 0277 -->
<a id="50.4.3.16"></a>16. 两名儿子均处于父亲家父权之下的，父亲不得被迫在同一时期承担两人的公共负担。

<!-- source-p 0278 -->
<a id="50.4.3.17"></a>17. 某人有两名儿子，却未在临终安排中规定应从共同财产中为其中一名儿子准备资金以履行公共负担的，该儿子应自费承担分派给他的负担及荣誉职务；即使其父在世时曾为另一名儿子支付此类费用，亦不例外。

<!-- source-p 0279 -->
<a id="50.4.4"></a>50.4.4

<!-- source-p 0280 -->
乌尔比安《意见集》第三卷

<!-- source-p 0281 -->
<a id="50.4.4.pr."></a>序　在城邦内兴建或修缮公共工程的管理属于公共负担；有五名健在子女的父亲可以免除该项负担。即使该负担是被强行加派的，也不会因此丧失其原本针对其他公共负担享有的免责。

<!-- source-p 0282 -->
<a id="50.4.4.1"></a>1. 因财产不足而被征召承担公共负担或荣誉职务者，享有的免责并非永久，而是暂时的；如果财产因正当理由而有所增加，应在适当时候评估此人是否有能力承担所任命的职务。

<!-- source-p 0283 -->
<a id="50.4.4.2"></a>2. 贫困者因无财产而不承担财产负担，但应履行加派给其本人的劳务。

<!-- source-p 0284 -->
<a id="50.4.4.3"></a>3. 某人本来负有本市公共负担，却为逃避该负担而报名服兵役；他不能因此使公共利益处于更不利的境地。

<!-- source-p 0285 -->
<a id="50.4.5"></a>50.4.5

<!-- source-p 0286 -->
斯卡埃沃拉《规则集》第一卷

<!-- source-p 0287 -->
船主和橄榄油商人若将其大部分财产投入该行业，可以免除五年的公共负担。

<!-- source-p 0288 -->
<a id="50.4.6"></a>50.4.6

<!-- source-p 0289 -->
乌尔比安《论行省总督职责》第四卷

<!-- source-p 0290 -->
<a id="50.4.6.pr."></a>序　神圣的兄弟皇帝给鲁提利乌斯·卢普斯的复函中作了如下说明：“某项敕令规定，市议员应依其被选任的先后顺序取得官职；每当所有人都具备适任资格和充分财力时，就应遵守该规定。另一方面，如果有些人贫困且财产耗尽，以至不仅无力承担公共荣誉职务，甚至难以维持自己的生活，那么让这些人担任官职既无益处，也绝不合乎体面；尤其是存在能够胜任职务、且与其自身境况及公共尊严相称的人时。富裕者应当知道，不得以此法律为借口逃避义务；只有在财产足以承担荣誉职务的人之间，才应考察各自何时被列入议会。”

<!-- source-p 0291 -->
<a id="50.4.6.1"></a>1. 公共团体的债务人不得被邀请担任荣誉职务，这一点是确定的；但他们先行清偿对公共团体所负债务后，即可担任。这里所谓公共团体的债务人，仅指因管理公共事务而留下亏欠者；若债务并非因管理公共事务而产生，而是从公共团体借入金钱，则不属于应被排除于荣誉职务之外的情形。当然，提供适当质押或保证人担保，足以替代清偿；神圣的兄弟皇帝曾就此复函给奥菲迪乌斯·赫雷尼安努斯。若某人因一项无法拒绝的允诺而负债，也属于应被排除于荣誉职务之外的情形。

<!-- source-p 0292 -->
<a id="50.4.6.2"></a>2. 某人若无人控告，不应被禁止担任荣誉职务；控告人撤回控告者，亦同。我们的皇帝曾与其神圣的父亲一同作出此项复函。

<!-- source-p 0293 -->
<a id="50.4.6.3"></a>3. 应知，某些公共负担属于人身负担，某些属于财产负担；荣誉职务也有若干种类。

<!-- source-p 0294 -->
<a id="50.4.6.4"></a>4. 加派给财产的公共负担或摊派，不因年龄、子女数量或通常可以免除人身负担的其他优先事由而免除。

<!-- source-p 0295 -->
<a id="50.4.6.5"></a>5. 加派给财产的公共负担有两类：有些加派给财产占有人，不论其是否为本市市民；另一些则只加派给市民或居住者。对土地或建筑物征收的摊派加于占有人；而被视为财产负担的其他公共负担，则只加于市民或居住者。

<!-- source-p 0296 -->
<a id="50.4.7"></a>50.4.7

<!-- source-p 0297 -->
马尔基安《公法论》第二卷

<!-- source-p 0298 -->
<a id="50.4.7.pr."></a>序　皇帝敕令禁止已遭控告的被告在判决作出前申请荣誉职务；其为平民或市议员，均不影响此规则。但被控告满一年后，不再禁止其申请，除非因其自身原因导致案件未能在一年内审结。

<!-- source-p 0299 -->
<a id="50.4.7.1"></a>1. 神圣的塞维鲁皇帝复函称，对因荣誉职务问题提起上诉的人，若其在上诉待决期间擅自行使该荣誉职务，应予惩处。因此，已被判决禁止担任荣誉职务的人提出上诉后，在上诉待决期间也应暂时停止申请该职务。

<!-- source-p 0300 -->
<a id="50.4.8"></a>50.4.8

<!-- source-p 0301 -->
乌尔比安《裁判官告示评注》第十一卷

<!-- source-p 0302 -->
在未满二十五岁之前，不应允许未成年人管理公共事务，也不应允许他们承担非财产性质的公共负担或荣誉职务。因此，他们既不会被选为市议员，也不能在议会投票。不过，为了有利于当事人，对于并未将公共事务托付给其处理的荣誉职务，年满二十五岁的年份一经开始，就视为已经达到完整年龄。反之，若将公共事务交由未成年人处理，即使可能损害其自身，也不得认为此举正当。

乌尔比安《论执政官职责》第三卷

<!-- source-p 0305 -->
某人在市镇被选为官员后，若拒绝履行所加派的公共负担，行省总督应运用通常迫使监护人接受其所指定职责的救济手段，强制其承认该负担。

<!-- source-p 0307 -->
莫德斯蒂努斯《区别论》第五卷

<!-- source-p 0308 -->

<a id="50.4.11"></a>50.4.11

<!-- source-p 0310 -->
莫德斯蒂努斯《学说汇纂》第十一卷

<!-- source-p 0311 -->
<a id="50.4.11.pr."></a>序　神圣的庇护皇帝致提提安努斯的敕书，以及相关敕令均明确规定，荣誉职务应逐级授予，即从较低者升至较高者。

<!-- source-p 0312 -->
<a id="50.4.11.1"></a>1. 即使市镇法律规定某些身份的人应优先担任荣誉职务，也应知，只有他们具备适任资格时，才应遵守该规定；神圣的马尔库斯皇帝复函中确立了这一点。

<!-- source-p 0313 -->
<a id="50.4.11.2"></a>2. 每当缺乏担任官职的人时，豁免特权就会在一定程度上受到限制；神圣的兄弟皇帝曾以复函作此规定。

<!-- source-p 0314 -->
<a id="50.4.11.3"></a>3. 即使某位医生曾获城邦认可，城邦仍可将其撤换；神圣的伟大皇帝安敦尼与其父曾以复函作此规定。

<!-- source-p 0315 -->
<a id="50.4.11.4"></a>4. 神圣的伟大皇帝安敦尼复函称，教授初级读写的教师不享有免责。

<!-- source-p 0316 -->
<a id="50.4.12"></a>50.4.12

<!-- source-p 0317 -->
雅沃莱努斯《卡西乌斯著作评注》第六卷

<!-- source-p 0318 -->
获准免除公共负担的人，并不因此免于担任官员，因为担任官职更属于荣誉职务，而非公共负担。要求在特定时期临时完成的其他事务，例如修缮道路，也不得向此类人征收。

<!-- source-p 0319 -->
<a id="50.4.13"></a>50.4.13

<!-- source-p 0320 -->
雅沃莱努斯《卡西乌斯著作评注》第十五卷

<!-- source-p 0321 -->
给予某人子女及其后代的免责或豁免，仅适用于属于该人家族的人。

<!-- source-p 0322 -->
<a id="50.4.14"></a>50.4.14

<!-- source-p 0323 -->
卡利斯特拉图《审判程序论》第一卷

<!-- source-p 0324 -->
<a id="50.4.14.pr."></a>序　市镇荣誉职务是对公共事务的管理，并带有一定等级的尊荣；它可能要求支出费用，也可能不要求支出。

<!-- source-p 0325 -->
<a id="50.4.14.1"></a>1. 公共负担或私人负担均有之。所谓公共负担，是指我们在管理公共事务时承担的、需要支出费用但不附带荣誉身份的职务。

<!-- source-p 0326 -->
<a id="50.4.14.2"></a>2. 修缮道路以及对土地进行摊派，属于地点的负担，而非个人的负担。

<!-- source-p 0327 -->
<a id="50.4.14.3"></a>3. 在决定谁应承担荣誉职务或公共负担时，首先应考虑被授予荣誉职务或管理职责者的个人情况；还应考虑其出身和财力是否足以承担所加派的职务，以及其应遵循的公共负担法律。

<!-- source-p 0328 -->
<a id="50.4.14.4"></a>4. 平民家庭中的家子，应由提名他的人承担相应风险。我们的皇帝塞维鲁·奥古斯都曾以如下文字作出复函：“如果你的儿子属于平民之列，尽管不得违背你的意愿，强迫你因儿子的身份而承担荣誉职务，但你也不得凭借家父权，阻止他服从本籍地的要求；阻止之举应由提名者承担风险。”

<!-- source-p 0329 -->
<a id="50.4.14.5"></a>5. 担任荣誉职务并非人人可以随意为之，而有确定的顺序。未先担任较低官职者，不得担任较高官职；担任官职也有年龄限制，并且不得连续担任荣誉职务。

<!-- source-p 0330 -->
<a id="50.4.14.6"></a>6. 多项敕令规定，如果没有其他人可以担任荣誉职务，可以强制曾经担任过该职务的人再次任职。神圣的哈德良皇帝也曾就重复承担公共负担作出如下复函：“我同意，如果没有其他适任者履行该项职务，可以从已经履行过该职务的人中选任。”

<!-- source-p 0331 -->
<a id="50.4.15"></a>50.4.15

<!-- source-p 0332 -->
帕皮尼安《答复集》第五卷

<!-- source-p 0333 -->
父亲虽希望儿子成为市议员，但父亲去世后，因儿子作为市议员而应承担、且在父亲去世后才加派给他的荣誉职务，不得成为该儿子共同继承人的负担；前提是父亲已为儿子留下足够财产。

<!-- source-p 0334 -->
<a id="50.4.16"></a>50.4.16

<!-- source-p 0335 -->
保罗《箴言集》第一卷

<!-- source-p 0336 -->
<a id="50.4.16.pr."></a>序　有人提出以金钱估价荣誉职务或公共负担，代替实际履行的，不应准许。

<!-- source-p 0337 -->
<a id="50.4.16.1"></a>1. 某人承诺为取得荣誉职务而支付款项后，若已开始支付，就应像已经开始履行工作一样，被强制支付全部款项。

<!-- source-p 0338 -->
<a id="50.4.16.2"></a>2. 不得违背儿子的意愿，强迫他代父亲保证公共事务将得到妥善处理。

<!-- source-p 0339 -->
<a id="50.4.16.3"></a>3. 除非情势所迫，无人应被强迫承担两次以上为公共团体辩护的职责。

<!-- source-p 0340 -->
<a id="50.4.17"></a>50.4.17

<!-- source-p 0341 -->
赫莫革尼安《法学撮要》第一卷

<!-- source-p 0342 -->
<a id="50.4.17.pr."></a>序　任何人都不因自愿重复担任行省祭司职务而被禁止。

<!-- source-p 0343 -->
<a id="50.4.17.1"></a>1. 享有荣誉职务和城市公共负担豁免者，若同意其处于家父权下的儿子成为市议员，就应被迫为儿子承担荣誉职务和公共负担所需的费用。

<!-- source-p 0344 -->
<a id="50.4.18"></a>50.4.18

<!-- source-p 0345 -->
档案主管奥勒利乌斯·阿尔卡狄乌斯·卡里西乌斯《城市公共负担论》单卷

<!-- source-p 0346 -->
<a id="50.4.18.pr."></a>序　城市公共负担分为三类：有些是人身负担，有些属于财产负担，另有一些是混合负担。

<!-- source-p 0347 -->
<a id="50.4.18.1"></a>1. 人身负担是以心力计划并投入身体劳作完成，且不给履行者造成财产损失的事务，例如监护、保佐以及管理账簿。

<!-- source-p 0348 -->
<a id="50.4.18.2"></a>2. 在某些城邦，财务官职不被视为荣誉职务，而属于人身负担。

<!-- source-p 0349 -->
<a id="50.4.18.3"></a>3. 征集新兵或马匹，以及征集其他必须供应的动物、运输或追索物资、提供国库款项、粮食或衣物，均属于个人负担。

<!-- source-p 0350 -->
<a id="50.4.18.4"></a>4. 管理车辆运输，以及提供强制运输劳务，也属于人身负担。

<!-- source-p 0351 -->
<a id="50.4.18.5"></a>5. 在某些城邦，负责采购粮食和橄榄油的人——按惯例，这类管理人称为 sitonas 和 elaiōnas——也被列为人身负担；如果某城邦以其收入向管理人提供资金，为公共浴场供热同样如此。

<!-- source-p 0352 -->
<a id="50.4.18.6"></a>6. 管理和看守输水道的职责，也归入人身负担。

<!-- source-p 0353 -->
<a id="50.4.18.7"></a>7. 负责公共纪律和整饬风俗的治安官（irenarchae），以及通常被选派修筑道路、但无须投入自有财产的人，也承担人身负担；此外，在某些城邦，负责面包及其他供居民日常生活所需商品的监督官（episkopoi），也承担人身负担。

<!-- source-p 0354 -->
<a id="50.4.18.8"></a>8. 负责接受、征收或分配粮食供应者，以及按人头征收款项的征收员，承担人身负担的职责。

<!-- source-p 0355 -->
<a id="50.4.18.9"></a>9. 通常被选派征收城邦公共收入的管理人，也受人身负担拘束。

<!-- source-p 0356 -->
<a id="50.4.18.10"></a>10. 被任命为房屋看守人、档案保管人、账目记录人、档案官、（某些城邦称作）客舍供应官或港口监督官的人，以及负责新建或修缮公共建筑、宫殿、船坞或驿站的管理人，如以公款支付工程费用；还有在需要时负责建造或修理船舶的人，均受人身负担拘束。

<!-- source-p 0357 -->
<a id="50.4.18.11"></a>11. 驼队管理（camelasia）同样是人身负担；应考虑给养和骆驼的费用，向骆驼队负责人支付确定数额，使其仅负担身体劳务。除非明确规定，只有身体受伤、不能胜任或体弱者，才可免于此项名册所列职责。〔“camelasia”及免除名册职责的句法关系待核。〕

<!-- source-p 0358 -->
<a id="50.4.18.12"></a>12. 派往皇帝圣所的使者，有时会领取称作 legativum 的旅费；此外，nycostrategi 和面包作坊管理人也承担人身负担。〔nycostrategi 的具体职掌待核。〕

<!-- source-p 0359 -->
<a id="50.4.18.13"></a>13. 代理人——希腊人称 syndikoi——以及为处理或辩护某一特定案件而选任的人，都承担人身负担所要求的劳务。

<!-- source-p 0360 -->
<a id="50.4.18.14"></a>14. 担任裁判员的义务，也属于人身负担。

<!-- source-p 0361 -->
<a id="50.4.18.15"></a>15. 若某人被选任，负责强制公共道路沿线土地的占有人铺设道路，这也属于人身负担。

<!-- source-p 0362 -->
<a id="50.4.18.16"></a>16. 同样，被派去接收或接受人口与财产申报的人，也承担人身负担所要求的职责。

<!-- source-p 0363 -->
<a id="50.4.18.17"></a>17. 在竞技比赛中伴随竞技主持人的持鞭者（mastigophori），以及官员的书记员，也履行人身负担。

<!-- source-p 0364 -->
<a id="50.4.18.18"></a>18. 财产负担是以财产支出费用，并使管理者承受损失的公共负担。

<!-- source-p 0365 -->
<a id="50.4.18.19"></a>19. 在亚历山大里亚，elemporia 和 pratura 被视为财产负担。〔这两个术语所指的具体业务待核。〕

<!-- source-p 0366 -->
<a id="50.4.18.20"></a>20. 在阿非利加行省，负责接收葡萄酒的人也承担财产负担。

<!-- source-p 0367 -->
<a id="50.4.18.21"></a>21. 财产负担有两类：有些负担加派给土地或财产，例如供应军队行进所需的马匹或骡子、强制运输劳务，以及提供驿马。

<!-- source-p 0368 -->
<a id="50.4.18.22"></a>22. 因此，即使不是本市市民或居住者，也会被强制承担此类劳务。

<!-- source-p 0369 -->
<a id="50.4.18.23"></a>23. 另有复函规定，从事放贷取息者即使是退伍军人，也必须承担此类摊派。

<!-- source-p 0370 -->
<a id="50.4.18.24"></a>24. 不论第一百人队长、退伍军人、其他军人或凭某种特权获益者，均不因其身份而免除此类负担；祭司也不例外。

<!-- source-p 0371 -->
<a id="50.4.18.25"></a>25. 此外，有些城邦享有一项特权：其领土内的土地占有人每年应按土地面积提供一定数量的粮食。这类摊派属于占有财产所生的负担。

<!-- source-p 0372 -->
<a id="50.4.18.26"></a>26. 十人首长职务和二十人首长职务属于混合负担；赫雷尼乌斯·莫德斯蒂努斯在批注及论述中均以充分理由作出这一正确认定。因为十人首长和二十人首长征收贡税时，既履行身体劳务，又对已故者造成的国库亏损承担补偿责任，因此该职务理应列为混合负担。

<!-- source-p 0373 -->
<a id="50.4.18.27"></a>27. 然而，上文列为人身负担的职责，若承担者依本市法律或习惯必须动用自有财产支付费用，或者在征收粮食供应时要承担被遗弃土地造成的损失，则应归入混合负担。

<!-- source-p 0374 -->
<a id="50.4.18.28"></a>28. 我们分作三类的所有这些公共负担，均可用一个名称概括：人身负担、财产负担和混合负担，都称为城市或公共负担。

<!-- source-p 0375 -->
<a id="50.4.18.29"></a>29. 即使有人获准免除人身负担，或免除一切城市公共负担，除军人和退伍军人外，也不能据此免除粮食供应、强制运输、提供驿马、接待住宿、提供船舶或人头税。

<!-- source-p 0376 -->
<a id="50.4.18.30"></a>30. 神圣的韦斯帕芗与哈德良皇帝曾以复函规定，享有城市公共负担豁免的教师，以及语法学家、演说家、医生和哲学家，均获准免于接待来客。

<!-- source-p 0377 -->
<a id="5"></a><a id="50.5"></a>50.5.0　论公共负担的豁免与免责

<!-- source-p 0378 -->
<a id="50.5.1"></a>50.5.1

<!-- source-p 0379 -->
乌尔比安《意见集》第二卷

<!-- source-p 0380 -->
<a id="50.5.1.pr."></a>序　任何免责都应有其公平理由。但如果不经裁判便相信主张免责者，或允许任何人随意提出免责而不受期限限制，就不会有人承担公共事务中必不可少的负担。因此，以有健在子女为由主张免除城市公共负担者，也必须提出上诉；未遵守此类上诉程序规定期限的人，理应因期间届满而被驳回。

<!-- source-p 0381 -->
<a id="50.5.1.1"></a>1. 以某项免责事由抗辩的人，每次被任命时都必须提出上诉，即使他此前已经获得免责亦然。但若证明对方明知此人享有永久免责，却仍出于骚扰目的，以诬告方式屡次起诉，则应命令其依皇帝敕令所示范的方式，支付诉讼费用，以赔偿无端反复受扰者。

<!-- source-p 0382 -->
<a id="50.5.1.2"></a>2. 某些人本可在市镇担任较高荣誉职务，却为逃避较重负担，违反荣誉职务的顺序，转而成为公有土地的佃户，以便只承担较轻负担；他们不能因此取得免责。

<!-- source-p 0383 -->
<a id="50.5.1.3"></a>3. 某人即使年满六十五岁且有三名健在子女，也不得仅以这些理由免除城市公共负担。

<!-- source-p 0384 -->
<a id="50.5.2"></a>50.5.2

<!-- source-p 0385 -->
乌尔比安《意见集》第三卷

<!-- source-p 0386 -->
<a id="50.5.2.pr."></a>序　不应召集年仅十六岁者承担粮食采购的公共负担；但若本籍地没有特别规定禁止任用未满二十五岁者承担公共负担或荣誉职务，就应遵守通常的适任年龄。

<!-- source-p 0387 -->
<a id="50.5.2.1"></a>1. 子女数量或年满七十岁，不足以免除荣誉职务或与之相连的负担，只能免除城市公共负担。

<!-- source-p 0388 -->
<a id="50.5.2.2"></a>2. 养子女不计入通常可以使父母免责的子女人数。

<!-- source-p 0389 -->
<a id="50.5.2.3"></a>3. 被征召承担公共负担的人，应证明在其请求以子女为由免责的时点，自己有相应数量的健在子女；后来子女人数达到要求，不会使此前已经接受的公共负担消灭。

<!-- source-p 0390 -->
<a id="50.5.2.4"></a>4. 财产负担不因子女数量而免除。

<!-- source-p 0391 -->
<a id="50.5.2.5"></a>5. 健在子女即使已不再处于父亲的家父权之下，也足以使父亲免除城市公共负担。

<!-- source-p 0392 -->

<!-- source-p 0466 -->

<!-- source-p 0467 -->
<a id="50.6.6.pr."></a>序　我们的城邦一向尊重年长者；祖先几乎给予他们与官员同等的荣誉。承担市镇公共负担时，也给予老年人同样的尊重。但某人若到老年才变得富有，且此前从未承担公共负担，则可以认为，不应仅凭年龄特权使其免于此项负担；尤其是所加派的职务与其说使身体劳累，不如说要求财产支出，并且该城邦不易找到财力充足、能够承担公共负担的人时。

<!-- source-p 0468 -->
<a id="50.6.6.1"></a>1. 还应审查各地法律，看其在逐项列明某些豁免时，是否同时规定了年龄要求。神圣的庇护皇帝致阿非利加行省总督恩尼乌斯·普罗库鲁斯的敕书，也可以证明这一点。

<!-- source-p 0469 -->
<a id="50.6.6.2"></a>2. 神圣的赫尔维乌斯·佩蒂纳克斯复函显示，子女数量并非一概、绝对地使人免除市镇公共负担。他曾以如下文字复函西尔维乌斯·坎狄杜斯：“E kai my paswn leitourgiwn afiysin tous pateras, all' oun epeidy hekkaideka paidas exein dia tou bibliou edylwsas, ouk estin alogon, hwste sugxwrysai sxolazein ty paidotrofia kai anesvai se twn leitourgiwn.”（“即使子女数量不能免除父亲的一切公共负担，然而，你已在申请书中说明自己有十六名子女；因此，准许你专心抚养子女并免除公共负担，并非毫无道理。”）

<!-- source-p 0470 -->
<a id="50.6.6.3"></a>3. 协助罗马城粮食供应的商人，以及为该供应服务的船主，只要仍从事此类业务，就享有公共负担豁免。已经确定，应当补偿他们所承担的风险，甚至应以奖励鼓励他们，因为他们在外地以风险和劳苦履行公共职责，理应免于本地的烦扰和支出；他们为罗马城粮食供应服务时，也可以说是为公共事务而离开本地。

<!-- source-p 0471 -->
<a id="50.6.6.4"></a>4. 给予船主的豁免有确定范围：仅船主本人享有，不延及其子女或被释奴；皇帝敕令对此已有说明。

<!-- source-p 0472 -->
<a id="50.6.6.5"></a>5. 神圣的哈德良皇帝复函称，只有服务于罗马城粮食供应的海船船主才享有豁免。

<!-- source-p 0473 -->
<a id="50.6.6.6"></a>6. 某人即使属于船主团体，但没有船舶，或不具备皇帝敕令规定的其他全部条件，也不得享有授予船主的特权。神圣的兄弟皇帝曾以如下文字复函：“ysan kai alloi tines epi profasei twn nauklyrwn kai ton siton kai elaion emporeuomenwn eis tyn agoran tou dymou tou hrwmaikou ontwn atelwn aciountes tas leitourgias diadidraskein, myte epipleontes myte to pleon meros tys ousias en tais nauklyriais kai tais emporiais exontes. afairevytw twn toioutwn hy ateleia.”（“另有一些人借口自己是船主，或经营向罗马人民市场供应粮食与橄榄油的贸易者，虽既不从事航运，也未将其大部分财产投入船运和贸易，却要求免除公共负担；应撤销此类人的豁免。”）〔希腊文为底本的拉丁字母转写；中文译文亦参照随后的拉丁释文。〕

<!-- source-p 0474 -->
<a id="50.6.6.7"></a>7. 关于各项豁免，应作如下处理：某人若在开始经营之前，或在加入能够产生豁免的团体之前，或在年满七十岁之前，或在公开开始执教之前，或在生育子女之前，已被征召承担公共负担，就应被强制履行该职务。

<!-- source-p 0475 -->
<a id="50.6.6.8"></a>8. 经营业务应当是为了增加财产。反之，若某人将大部分财产投入经营，后来又变得富有，却仍以相同规模经营，就仍须承担公共负担；那些仅用少量资金购置船舶、企图借此逃避公共负担的富人，也是如此。神圣的哈德良皇帝敕书规定应遵守此规则。

<!-- source-p 0476 -->
<a id="50.6.6.9"></a>9. 神圣的庇护皇帝也曾复函称，每当有人请求以船主身份取得豁免，应查明他是否只是为逃避公共负担而假扮船主。

<!-- source-p 0477 -->
<a id="50.6.6.10"></a>10. 国库税收承包人不因市镇公共负担而负有必须履行的义务；神圣的兄弟皇帝复函称应遵守此规则。从该项皇帝复函可以理解，免除承包人的市镇公共负担并非给予其荣誉，而是为了避免其财产——这些财产已经向国库登记担保——受到削减。因此，可以进一步讨论：即使承包人自愿申请担任市镇职务，总督或皇帝代理人是否仍应禁止；较妥当的主张是应予禁止，除非据称他们已向国库提供相等财产。〔“paria fisco fecisse”的具体法律效果待核。〕

<!-- source-p 0478 -->
<a id="50.6.6.11"></a>11. 皇帝的佃户也免除公共负担，以便使他们更有能力经营国库土地。

<!-- source-p 0479 -->
<a id="50.6.6.12"></a>12. 法律准许成立的某些团体或行业组织享有豁免；具体而言，是为各自行业而吸收成员的团体，例如工匠团体，以及其他基于同一理由、为向公共利益提供必要劳务而设立的组织。但并非所有加入此类团体的人都享有豁免，只有从事相应工艺的人可以享有。依神圣的庇护皇帝所定规则，不能不论年龄一概接纳成员；高龄或身体极度虚弱者曾被拒绝加入。多项规定还表明，财产增加且有能力承担城邦公共负担的人，不得利用原本给予由团体吸收的贫困者的特权。

<!-- source-p 0480 -->
<a id="50.6.6.13"></a>13. 我获悉，加入享有船主豁免的团体者，如接受市议员荣誉职务，仍应被强制承担公共负担；神圣的佩蒂纳克斯复函似乎也确认了这一点。

塔伦图努斯·佩特尔努斯《军法论》第一卷

<!-- source-p 0483 -->
某些人的身份使其免除较重的公共负担，例如测量员、医院副官、医生、药箱管理员、工匠、挖掘壕沟者、兽医、建筑师、舵手、造船工、弩炮操作员、玻璃工、铁匠、弓箭手、铜匠、修筑牛栏者、车匠、铺瓦工、角斗士、引水工、号手、号角手、弓匠、铅匠、铁匠、石匠、烧石灰者、劈木者、砍伐并烧制木炭者。通常也将屠夫、猎人、祭牲屠宰者、兵工厂副官、照料病者的人、能够教学的抄写员、粮仓抄写员、寄存物登记员、无主遗产登记员、百夫长助理、马夫、理发师、武器看守人、传令官及号角手列入其中。上述人员均被视为享有豁免。

<!-- source-p 0484 -->
<a id="7"></a><a id="50.7"></a>50.7.0　论使团

<!-- source-p 0485 -->
<a id="50.7.1"></a>50.7.1

<!-- source-p 0486 -->
乌尔比安《萨宾评注》第八卷

<!-- source-p 0487 -->
市镇使者若擅自放弃使团职责，应受特别惩处，通常还会被免除其议员身份。

<!-- source-p 0488 -->
<a id="50.7.2"></a>50.7.2

<!-- source-p 0489 -->
乌尔比安《意见集》第二卷

<!-- source-p 0490 -->
<a id="50.7.2.pr."></a>序　市镇使者可以通过他人向皇帝提出某项请求，即使该请求不利于派遣其出使的公共团体。

<!-- source-p 0491 -->
<a id="50.7.2.1"></a>1. 某人究竟是擅自放弃使团职责，还是因必要原因而延误，都应由其本籍地的议会查明。

<!-- source-p 0492 -->
<a id="50.7.2.2"></a>2. 一名使者怠于履职，不损害已适当履行职责的另一名使者。

<!-- source-p 0493 -->
<a id="50.7.3"></a>50.7.3

<!-- source-p 0494 -->
乌尔比安《意见集》第二卷

<!-- source-p 0495 -->
未无偿接受使团职责的人，应依规定偿还其旅费。

<!-- source-p 0496 -->
<a id="50.7.4"></a>50.7.4

<!-- source-p 0497 -->
阿非利加努斯《疑义集》第三卷

<!-- source-p 0498 -->
在判断是否应对身处使团中的人提起诉讼时，重要的并非某人在何处借出款项或约定要式口约，而在于当事人是否约定应在使团期间清偿。

<!-- source-p 0499 -->
<a id="50.7.5"></a>50.7.5

<!-- source-p 0500 -->
马尔基安《法学阶梯》第十二卷

<!-- source-p 0501 -->
<a id="50.7.5.pr."></a>序　应知，公共团体的债务人不得担任使者；神圣的庇护皇帝曾就此复函给克劳狄乌斯·萨图尔尼努斯和福斯蒂努斯。

<!-- source-p 0502 -->
<a id="50.7.5.1"></a>1. 神圣的塞维鲁与安敦尼复函称，无权出庭主张权利的人也不得担任使者；因此，被送入角斗场的人不可能依法受派为使者。

<!-- source-p 0503 -->
<a id="50.7.5.2"></a>2. 但国库债务人并不因此被禁止担任使者。

<!-- source-p 0504 -->
<a id="50.7.5.3"></a>3. 若已公开提起对某人的控告，不应强迫控告人担任使者，前往其所控告之人处出使；后者声称自己是控告人的朋友或家中成员。神圣的兄弟皇帝曾就此复函给埃米利乌斯·鲁弗斯。

<!-- source-p 0505 -->
<a id="50.7.5.4"></a>4. 使者只能指定自己的儿子担任替代使者。

<!-- source-p 0506 -->
<a id="50.7.5.5"></a>5. 每个人都应依次承担使团职责；只有先前列入议会的人已经履行使团职责后，才可强制其后的人员承担此职。但若使团需要由最显要的人士担任，而依次序被征召者身份较低，则不应遵循顺序；神圣的哈德良皇帝曾复函给克拉佐美奈人作此规定。

<!-- source-p 0507 -->
<a id="50.7.5.6"></a>6. 神圣的韦斯帕芗皇帝在敕令中命令所有城邦，派出的使者不得超过三人。

<!-- source-p 0508 -->
<a id="50.7.6"></a>50.7.6

<!-- source-p 0509 -->
斯卡埃沃拉《规则集》第一卷

<!-- source-p 0510 -->
<a id="50.7.6.pr."></a>序　使者享有的期限利益，自其被选任为使者之日起计算，而非自其抵达罗马之日起计算。

<!-- source-p 0511 -->
<a id="50.7.6.1"></a>1. 使者身份存在争议时，由罗马的裁判官审理。

<!-- source-p 0512 -->
<a id="50.7.7"></a>50.7.7

<!-- source-p 0513 -->
乌尔比安《论行省总督职责》第四卷

<!-- source-p 0514 -->
我们的皇帝与其父克劳狄乌斯·卡利斯图斯曾以如下文字复函：不得因为父亲担任使者，就准许儿子免于使团职责。“你请求因父亲担任使者而免除自己的使团职责；在涉及需要支出的荣誉职务之间，遵循这一规则是恰当的；但对于仅须提供劳务而不须支出的使团，情形则不同。”

<!-- source-p 0515 -->
<a id="50.7.8"></a>50.7.8

<!-- source-p 0516 -->
帕皮尼安《答复集》第一卷

<!-- source-p 0517 -->
市议员之子代父亲履行使团职责。这一事实并不能使儿子免于依其自身顺序出任使者；但父亲可以主张两年的豁免期，因为可视为他已通过儿子履行使团职责。

<!-- source-p 0518 -->
<a id="50.7.9"></a>50.7.9

<!-- source-p 0519 -->
保罗《答复集》第一卷

<!-- source-p 0520 -->
<a id="50.7.9.pr."></a>序　保罗答复说，已经履行使团职责的人，在规定的豁免期限内，不应再次被强迫为公共事务辩护，即使争议仍涉及同一事项。

<!-- source-p 0521 -->
<a id="50.7.9.1"></a>1. “皇帝安敦尼与塞维鲁·奥古斯都致日耳曼努斯·西尔瓦努斯。履行使团职责者享有两年豁免期；无论使团职责是在我们身处罗马城时，还是在我们身处行省时委派的，均不影响此规则。”

<!-- source-p 0522 -->
<a id="50.7.9.2"></a>2. 保罗答复说，履行使团职责的人不得介入他人事务或自己的事务。但在此情形中，不应包括这样的人：他无偿地与身为裁判官的朋友讨论意见。

<!-- source-p 0523 -->
<a id="50.7.10"></a>50.7.10

<!-- source-p 0524 -->
保罗《答复集》第三卷

<!-- source-p 0525 -->
保罗答复说，使者在履行使团职责期间遭受的损害，即使仍在使团期间，也可以提起诉讼。

<!-- source-p 0526 -->
<a id="50.7.11"></a>50.7.11

<!-- source-p 0527 -->
保罗《箴言集》第一卷

<!-- source-p 0528 -->
<a id="50.7.11.pr."></a>序　使者履行完使团职责之前，不得为自身利益采取任何法律行动；但为制止针对其本人的侵害或损害而采取的行动除外。

<!-- source-p 0529 -->
<a id="50.7.11.1"></a>1. 某人履行使团职责期间、返回本籍地之前死亡的，不必退还出发时发给他的费用。

<!-- source-p 0530 -->
<a id="50.7.12"></a>50.7.12

<!-- source-p 0531 -->
保罗《论申请书法》单卷

<!-- source-p 0532 -->
<a id="50.7.12.pr."></a>序　某人不在场时被委派为使者，且无偿接受该职务的，可以通过他人履行使团职责。

<!-- source-p 0533 -->
<a id="50.7.12.1"></a>1. 履行使团职责的人虽然不得处理自己的事务，但伟大的安敦尼准许他以未成年被监护人的名义准备并辩护案件；即使他尚未辞去所接受的使团职责，亦然，尤其是因为他声称共同承担该职责的人不在场。

<!-- source-p 0534 -->
<a id="50.7.13"></a>50.7.13

<!-- source-p 0535 -->
斯卡埃沃拉《学说汇纂》第一卷

<!-- source-p 0536 -->
某人由其本籍地选任为使者，接受使团职责后前往罗马；在使团尚未完成时，他购买了位于其城邦尼科波利斯的房屋。有人问，他是否违反了禁止使者在使团完成前介入业务或私人事务的元老院决议。答复说，看来他并未受该决议拘束。

<!-- source-p 0537 -->
<a id="50.7.14"></a>50.7.14

<!-- source-p 0538 -->
帕皮尼安《答复集》第一卷

<!-- source-p 0539 -->
某人自愿被指定为他人公共负担的替代承担者，不得援用两年期间的抗辩；他仍应依其自己的顺序接受使团职责。

<!-- source-p 0540 -->
<a id="50.7.15"></a>50.7.15

<!-- source-p 0541 -->
乌尔比安《裁判官告示评注》第七十四卷

<!-- source-p 0542 -->
以自由使者身份离开本籍地的人，不视为因公共事务而离开；他离开并非为了公共利益，而是为了自身利益。

<!-- source-p 0543 -->
<a id="50.7.16"></a>50.7.16

<!-- source-p 0544 -->
莫德斯蒂努斯《规则集》第七卷

<!-- source-p 0545 -->
履行使团职责的人，未经皇帝许可，不得就自己的其他事务提交申请书。

<!-- source-p 0546 -->
<a id="50.7.17"></a>50.7.17

<!-- source-p 0547 -->
莫德斯蒂努斯《规则集》第八卷

<!-- source-p 0548 -->
<a id="50.7.17.pr."></a>序　法律并未禁止同一人接受多个使团职责，尤其是在费用和行程安排均有利时。

<!-- source-p 0549 -->
<a id="50.7.17.1"></a>1. 某人在接受使团职责之前如被提起诉讼，即使其不在场，也应为其辩护；接受使团职责之后，他只能履行所委派的任务。

<!-- source-p 0550 -->
<a id="50.7.18"></a>50.7.18

<!-- source-p 0551 -->
庞波尼乌斯《昆图斯·穆奇乌斯评注》第三十七卷

<!-- source-p 0552 -->
如果某人袭击了敌国使者，应视为违反万民法，因为使者被认为神圣不可侵犯。因此，某一民族的使者身在我国时，即使后来我国对该民族宣战，也有答复认为使者仍应保持自由；这符合万民法。昆图斯·穆奇乌斯通常答复说，袭击使者的人应被交付给使者所属的敌国。如果敌国拒绝接受此人，则有人询问他是否仍保有罗马公民身份：一些人认为仍保有；另一些人则持相反意见，因为人民一旦决定交付某人，就仿佛已将其逐出公民共同体，如同禁止其用水用火。普布利乌斯·穆奇乌斯似乎持后一种意见。此问题主要见于霍斯提利乌斯·曼基努斯一案：努曼提亚人拒绝接受被交付的曼基努斯；不过，此后仍通过法律规定他是罗马公民，据说他还担任过裁判官。
