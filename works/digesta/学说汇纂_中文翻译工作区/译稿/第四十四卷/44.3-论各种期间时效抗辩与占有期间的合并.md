# D.44.3 论各种期间时效抗辩与占有期间的合并（*De diversis temporalibus praescriptionibus et de accessionibus possessionum*）

<!-- source-p 0202 -->
<a id="3"></a><a id="44.3"></a>**44.3.0**　论各种期间时效抗辩与占有期间的合并。

<!-- source-p 0203 -->
<a id="44.3.1"></a>**44.3.1**

<!-- source-p 0204 -->
乌尔比安《告示评注》第七十四卷。

<!-- source-p 0205 -->
由于关于“有用日”的论述经常出现，我们来考察何谓具有行使诉权的可能。首先必须要求当事人确有起诉的能力。仅仅被告允许原告对其提起诉讼，或者有适格之人可以为被告进行辩护，并不足够；原告本人还必须未因正当理由而受阻、无法起诉。因此，若原告身处敌境、因公离境、被拘禁，或因风暴滞留某地或某区域，以致既不能起诉也不能委任代理人，就不具有行使诉权的可能。当然，若原告因健康状况受阻，但仍能委任代理人，则仍属于具有行使诉权可能的情形。无人不知，未能获得裁判官接见的人不具有行使诉权的可能；因此，在裁判官开庭审理案件的日子，期间才开始计算。

<!-- source-p 0206 -->
<a id="44.3.2"></a>**44.3.2**

<!-- source-p 0207 -->
马尔凯鲁斯《学说汇纂》第六卷。

<!-- source-p 0208 -->
对于以固定期间作出的判决，闰日是否应计入判决所定期间，存在疑问。关于诉讼期间届满，则毫无疑问，应将闰日计入延长后的诉讼期间。例如，取得时效须在特定期间届满时完成；又如某些诉权受固定期间限制，多数市政官诉权即属此类。再如，某人出售土地时约定，若三十日内未付价款，土地即视为未曾买卖，闰日应计入买受人的期间。我对此持相反看法。

<!-- source-p 0209 -->
<a id="44.3.3"></a>**44.3.3**

<!-- source-p 0210 -->
莫德斯汀《区别论》第六卷。

<!-- source-p 0211 -->
显然，长期占有时效既适用于土地，也适用于要式物。

<!-- source-p 0212 -->
<a id="44.3.4"></a>**44.3.4**

<!-- source-p 0213 -->
雅沃勒努斯《书信集》第七卷。

<!-- source-p 0214 -->
如果遗产奴隶，或处于敌人权力之下者，已经受领担保，担保期间便立即开始计算。我们应当考察的是，能否针对负有债务的人行使诉权，而不是使标的物负担债务的人能否起诉；否则，因原告自身的处境而延长被告的债务期间——而被告并未做任何妨碍原告起诉的事——将极不公平。

<!-- source-p 0215 -->
<a id="44.3.5"></a>**44.3.5**

<!-- source-p 0216 -->
乌尔比安《论辩录》第三卷。

<!-- source-p 0217 -->
<a id="44.3.5.pr."></a>**序言**　应当考察：如果我的前手、赠与人，或将物遗赠给我的人存在瑕疵，是否会对我不利；例如，我的前手没有合法的占有起始根据。我认为，这既不会对我有利，也不会对我不利。毕竟，我可以通过取得时效取得我的前手无法通过取得时效取得的物。

<!-- source-p 0218 -->
<a id="44.3.5.1"></a>**1**　所提出的事实是：某人将物出质后又将其出售，其继承人将该物赎回。问题在于，该继承人能否对质权追索提出长期占有时效抗辩。我认为，该继承人从第三人处赎回质物后，可以提出此项抗辩，因为他承继的是第三人的地位，而非出质人的地位；这如同他先前赎回质物，之后才成为继承人。

<!-- source-p 0219 -->
<a id="44.3.6"></a>**44.3.6**

<!-- source-p 0220 -->
阿非利加努《疑义》第九卷。

<!-- source-p 0221 -->
<a id="44.3.6.pr."></a>**序言**　如果我分别将同一物出售给两人，那么，在两次买卖之前已经开始的占有期间，只对先买且已受交付的买受人有利。甚至，如果我把某物卖给你，之后又从你处买回，再卖给提提乌斯，我本人的占有期间以及你的占有期间都会归并到提提乌斯的占有期间中；显然，你应向我移转占有，而我又应向他移转占有。

<!-- source-p 0222 -->
<a id="44.3.6.1"></a>**1**　我把奴隶卖给你，并约定：若未在确定日期前付款，买卖即视为未成立。约定情形发生后，问题是，你的占有期间能否加上此前期间。答复说，应依解除买卖后的返还情形处理：该人应视同倒转而回到我处。因此，如果出卖人后来重新取得占有，那么，从他重新占有之时起的期间、买卖之前的期间，以及这段可归并的期间，都应与买受人（退还奴隶者）此前的占有期间合并计算。

<!-- source-p 0223 -->
<a id="44.3.7"></a>**44.3.7**

<!-- source-p 0224 -->
马尔基安《法学阶梯》第三卷。

<!-- source-p 0225 -->
如果有人多年来独自在公有河流的支汊中捕鱼，就有权阻止他人以同一权利在那里捕鱼。

<!-- source-p 0226 -->
<a id="44.3.8"></a>**44.3.8**

<!-- source-p 0227 -->
乌尔比安《规则论》第一卷。

<!-- source-p 0228 -->
在合并占有期间时，奴隶逃亡期间也计入其主人的期间，这一理解是正确的。

<!-- source-p 0229 -->
<a id="44.3.9"></a>**44.3.9**

<!-- source-p 0230 -->
马尔基安《规则论》第五卷。

<!-- source-p 0231 -->
神君安敦宁大帝的若干敕答规定，动产也适用长期占有时效。

<!-- source-p 0232 -->
<a id="44.3.10"></a>**44.3.10**

<!-- source-p 0233 -->
帕比尼安《答复集》第十三卷。

<!-- source-p 0234 -->
<a id="44.3.10.pr."></a>**序言**　在无人主张的遗产案件中，有人于四年期间内提出告知，随后却放弃追索。四年期满后，第二名告知人提出主张；除非揭露第一名告知人曾经串通舞弊，否则，先前告知不能使第二人免于因期间届满而被排除。一旦揭露串通舞弊，不仅时效抗辩失效，对相关事务的审理也将终结。

<!-- source-p 0235 -->
<a id="44.3.10.1"></a>**1**　关于无人主张遗产的告知，规定了四年期间；该期间应从无人主张遗产这一事实本身起算，而非依人们的主观认识计算。四年应从遗嘱无效、所有有权依次请求遗产占有的人均已放弃无遗嘱继承的遗产占有，或者各人分别被规定的期间届满之时起算。

<!-- source-p 0236 -->
<a id="44.3.11"></a>**44.3.11**

<!-- source-p 0237 -->
帕比尼安《判定义》第三卷。

<!-- source-p 0238 -->
继承人承受死者的全部法律地位，因此，不得仅因自身不知情而排除死者所负的瑕疵。例如，死者明知物属于他人，仍依可撤销许可占有该物。尽管这种容许占有不拘束不知情的继承人，也不能正当地对其提起相关禁令，但继承人仍无法通过取得时效取得死者本不能取得的物。长期占有的判断同样如此：既然善意根据不支持占有的起始，继承人就不能据此提出有效抗辩。

<!-- source-p 0239 -->
<a id="44.3.12"></a>**44.3.12**

<!-- source-p 0240 -->
保罗《答复集》第十六卷。

<!-- source-p 0241 -->
债权人本可通过长期占有时效抗辩，排除质物占有人提出的请求，却将质物出售。有人询问：占有人能否保留针对买受人的抗辩？保罗答复说，即使针对买受人，占有人也享有同一抗辩。

<!-- source-p 0242 -->
<a id="44.3.13"></a>**44.3.13**

<!-- source-p 0243 -->
赫尔莫革尼安《法学摘要》第六卷。

<!-- source-p 0244 -->
<a id="44.3.13.pr."></a>**序言**　在所有涉及国库的争议中，除特别规定适用较短期间的案件外，均适用二十年时效。

<!-- source-p 0245 -->
<a id="44.3.13.1"></a>**1**　已经核签并销账的公款账目，不得在二十年之后再针对经办人追查，也不得在十年之后再针对其继承人追查。

<!-- source-p 0246 -->
<a id="44.3.14"></a>**44.3.14**

<!-- source-p 0247 -->
斯凯沃拉《公开提出的疑义》单卷。

<!-- source-p 0248 -->
<a id="44.3.14.pr."></a>**序言**　关于占有期间的合并，我们无法作出永久且一般性的规定，因为它完全取决于衡平。

<!-- source-p 0249 -->
<a id="44.3.14.1"></a>**1**　当然，在因契约或他人意愿而承继他人地位的人之间，可以给予期间合并。继承人以及被视为继承人的人，均可加上遗嘱人的占有期间。

<!-- source-p 0250 -->
<a id="44.3.14.2"></a>**2**　因此，如果你把奴隶卖给我，我可以加上你的占有期间。

<!-- source-p 0251 -->
<a id="44.3.14.3"></a>**3**　又如，你把物出质给我，而我又将同一物出质给他人，我的债权人可以加上你的占有期间；在我尚未向你清偿之前，无论对抗第三人还是对抗你本人，均可如此。因为他优先于我，而我又将优先于你；既然如此，他当然更应能够对抗你。但如果你已向我清偿，此时他便不能加上你的占有期间。

<!-- source-p 0252 -->
<a id="44.3.14.4"></a>**4**　又如，你不在场时，负责管理你事务的人把奴隶卖给我；你返回后追认该行为，我无论如何都可以加上他的占有期间。

<!-- source-p 0253 -->
<a id="44.3.14.5"></a>**5**　又如，你把物出质给我，并约定若你未清偿，我可以依约出售质物；我后来将其出售，那么，即使质物系违背你的意愿而被出售，买受人也应能够加上你的占有期间。因为在订立协议时，既然你约定未付款即可出售，就应视为你已经同意此项出售。

<!-- source-p 0254 -->
<a id="44.3.15"></a>**44.3.15**

<!-- source-p 0255 -->
维诺尼乌斯《禁令论》第五卷。

<!-- source-p 0256 -->
<a id="44.3.15.pr."></a>**序言**　在取得时效中，规则是：即使物仅在最后一日的极短片刻内处于占有之下，取得时效仍告完成；无需等到该日整日届满，才算完成所规定的期间。

<!-- source-p 0257 -->
<a id="44.3.15.1"></a>**1**　占有期间的合并，不仅包括你从其处购买的人的占有期间，也包括该出卖人从其前手购买时前手的占有期间。但如果前手与后手之间有某一中间前手未曾占有该物，则更早的前手占有期间不能使你受益，因为占有期间并未连续衔接；正如不占有的人也不能加上其前手的占有期间。

<!-- source-p 0258 -->
<a id="44.3.15.2"></a>**2**　此外，还应加上你购买该物的人的占有期间；若你委托某人代为购买，也应加上该受托人的前手以及委托其出售该物之人的占有期间。但如果受托出售者又委托他人代为出售，拉贝奥说，只有在所有人允许其实施该项行为时，后续委托人的占有期间才能合并。

<!-- source-p 0259 -->
<a id="44.3.15.3"></a>**3**　此外，如果我从家子或奴隶处购买物，只有在家父或主人同意的情况下出售，或者该家子或奴隶有权管理特有产时出售，我才可以加上该物先前处于家父或主人占有之下的期间。

<!-- source-p 0260 -->
<a id="44.3.15.4"></a>**4**　如果你从未成年人的监护人处购买物，而该监护人在管理监护事务期间曾为未成年人占有该物，也应加上未成年人的占有期间。从未成年人的保佐人或精神失常者的保佐人处购买物时，也应遵循同一规则；如果发生以胎儿名义作出的财产减损，或者一名为保全自身嫁资而受置于占有之中的妇女发生财产减损，相关期间也应合并计算。〔原文疑难：*deminutio facta sit* 的对象及其与胎儿、嫁资占有的关系待核。〕

<!-- source-p 0261 -->
<a id="44.3.15.5"></a>**5**　但是，对这些期间合并规则的解释，不应像其文字表面所显示的那样宽泛，以至于认为：即使买卖并交付之后，物仍留在出卖人处，该期间也应使买受人受益。只有买卖之前的占有期间可以合并；即使出卖人在买卖时并未占有该物，此前的占有期间仍可合并。

<!-- source-p 0262 -->
<a id="44.3.15.6"></a>**6**　继承人出售遗产物时，买受人应当能够加上继承人和死者的占有期间。

<!-- source-p 0263 -->
<a id="44.3.16"></a>**44.3.16**

保罗《萨宾评注》第三卷。
