# D.44.4 论恶意欺诈与胁迫抗辩（*De doli mali et metus exceptione*）

<!-- source-p 0266 -->
<a id="4"></a><a id="44.4"></a>**44.4.0**　论恶意欺诈与胁迫抗辩。

<!-- source-p 0267 -->
<a id="44.4.1"></a>**44.4.1**

<!-- source-p 0268 -->
保罗《告示评注》第七十一卷。

<!-- source-p 0269 -->
<a id="44.4.1.pr."></a>**序言**　为更清楚地理解这项抗辩，我们先考察其提出的理由，再考察何谓欺诈以及欺诈如何实施；据此便能理解该抗辩何时阻却请求，以及可以针对何人提出。最后，我们还要考察该抗辩可在何种期间内提出。

<!-- source-p 0270 -->
<a id="44.4.1.1"></a>**1**　裁判官之所以提出这项抗辩，是为了不让任何人借助市民法的机会，使自己的欺诈行为违背自然衡平而获利。

<!-- source-p 0271 -->
<a id="44.4.1.2"></a>**2**　某行为是否出于欺诈，应根据具体事实判断。

<!-- source-p 0272 -->
<a id="44.4.1.3"></a>**3**　欺诈既可能发生在契约中，也可能发生在遗嘱中，还可能发生在法律中。

<!-- source-p 0273 -->
<a id="44.4.2"></a>**44.4.2**

<!-- source-p 0274 -->
乌尔比安《告示评注》第七十六卷。

<!-- source-p 0275 -->
<a id="44.4.2.pr."></a>**序言**　显然，这项抗辩与恶意欺诈之诉基于同一理由而设。

<!-- source-p 0276 -->
<a id="44.4.2.1"></a>**1**　接下来，我们考察该抗辩适用于哪些情形，又可以针对何人提出。首先应注意：必须明确指出所指控的是何人的欺诈。公式不应泛泛写作“在此事中未发生恶意欺诈”（*si in ea re nihil dolo malo factum est*），而应写作“在此事中，原告未实施恶意欺诈”（*si in ea re nihil dolo malo actoris factum est*）。因此，提出抗辩者必须证明原告实施了恶意欺诈；仅证明该事项中存在欺诈并不足够。若其主张欺诈系他人所为，则必须具体列明此人的身份，且此人须属于其欺诈能够产生不利影响之人。

<!-- source-p 0277 -->
<a id="44.4.2.2"></a>**2**　但从提出抗辩者一方的角度看，这项抗辩是针对事项本身提出的；因为所要考察的不是欺诈针对何人实施，而是原告一方在该事项中是否实施了恶意欺诈。

<!-- source-p 0278 -->
<a id="44.4.2.3"></a>**3**　就第一类情形——即该抗辩基于何种理由适用——可以讨论以下事项。若某人无正当原因而向他人取得要式允诺，随后又依据该允诺起诉，恶意欺诈抗辩当然会对其不利。尽管他在取得允诺时并未实施任何恶意欺诈，但应当说，他在争讼程序确定时仍坚持依据该允诺请求给付，便是在欺诈；即使订立允诺时曾有正当原因，如今也似乎已无适当原因。因此，如果某人为了将来放贷而取得允诺，却没有实际放贷；或者允诺原有确定原因，但该原因后来未发生或已消灭，也应当说恶意欺诈抗辩会阻却其请求。

<!-- source-p 0279 -->
<a id="44.4.2.4"></a>**4**　又有人问：若某人无条件地取得一定金额的允诺，这是当事人原先的约定；但在作出允诺后，双方又约定，在确定日期之前不得请求给付，该抗辩是否会产生恶意欺诈抗辩？毫无疑问，也可以提出基于协议的抗辩；但当事人若想援用本项抗辩，同样可以如此，因为任何人都不能否认，违反协议请求给付者是在欺诈。

<!-- source-p 0280 -->
<a id="44.4.2.5"></a>**5**　一般而言，应当知道，任何事实抗辩都可能引出恶意欺诈抗辩。凡请求给付之事可以被任何一种抗辩排除，请求该给付的人便是在欺诈。因为即使其起初并未实施恶意欺诈，如今提出请求时仍是在欺诈；但若其对有关情形的无知足以排除欺诈，则属例外。

<!-- source-p 0281 -->
<a id="44.4.2.6"></a>**6**　有人提出如下问题，并非没有道理：债权人若预先收取未来期间的利息，却在该期间届满前仍请求偿还本金，是否会被恶意欺诈抗辩阻却？可以说，他是在欺诈：收取利息，表明他已将请求推迟到已付息期间之后，并默示约定在此之前不请求给付。

<!-- source-p 0282 -->
<a id="44.4.2.7"></a>**7**　又有人提出如下问题：某人买下一名附条件释奴；该奴隶被命令给付十枚金币后方可自由，但买受人对此并不知情，并取得了双倍价款的要式允诺。其后，奴隶给付十枚金币，因满足条件而被确认获得自由；买受人可以依据双倍要式允诺起诉，但若不扣除其为满足条件而收到的十枚金币，就应以抗辩驳回其请求。尤利安也如此写道。不过，如果该附条件释奴是用买受人的财物，或用属于买受人的特有产给付这笔钱，则可以说该抗辩不对其不利，因为他并未实施欺诈。

<!-- source-p 0283 -->

<!-- source-p 0284 -->

<!-- source-p 0285 -->
又如，在所有权转移给我之前，买受人已向出卖人给付十枚金币，而我提起买卖之诉请求返还这十枚金币；我认为，只有在我准备解除其双倍要式允诺责任的情况下，我才享有该诉权。

<!-- source-p 0286 -->
<a id="44.4.4"></a>**44.4.4**

<!-- source-p 0287 -->
乌尔比安《告示评注》第七十六卷。

<!-- source-p 0288 -->
<a id="44.4.4.pr."></a>**序言**　塞尔苏斯讨论过如下情形：遗产债权人曾委托提提乌斯接受继承，但其中一人为了欺骗提提乌斯而未作委托；若提提乌斯不接受继承，该债权人原本也会作出委托。之后，此人提起诉讼，是否应以抗辩驳回？塞尔苏斯说，应以恶意欺诈抗辩驳回其请求。

<!-- source-p 0289 -->
<a id="44.4.4.1"></a>**1**　尤利安写道：某人病重时，向妻子的表亲允诺给付一百枚金币，显然意在使这笔钱最终归其妻所有；后来他康复了。若其被起诉，能否援用抗辩？尤利安记载，拉贝奥认为他可以援用恶意欺诈抗辩。

<!-- source-p 0290 -->
<a id="44.4.4.2"></a>**2**　如果我们约定将争议交由仲裁人裁决，而我因患病未能履行约定，导致罚金发生，我能否援用恶意欺诈抗辩？庞波尼乌斯说，这项抗辩对我有利。

<!-- source-p 0291 -->
<a id="44.4.4.3"></a>**3**　又有人问：若你与一名欠你六十的债务人约定仲裁，却因疏忽而向他取得一百的罚金允诺，应如何处理？拉贝奥认为，仲裁人的职责是命令对方仅给付实际所欠数额；若未能如此，也不应禁止请求超过该数额的给付。但即使仲裁人没有作此处理，拉贝奥仍说，债权人可以请求其实际应得之债；若请求罚金，则恶意欺诈抗辩对被请求人有利。

<!-- source-p 0292 -->
<a id="44.4.4.4"></a>**4**　若有人未经监护人同意，向未成年人清偿其应得债务，而未成年人因该清偿而增加财产，正确的意见是：未成年人请求给付时，恶意欺诈抗辩会对其不利。即使未成年人借入钱款，或基于其他契约增加财产，也应给予该项抗辩。其他不能有效接受清偿的人亦同；只要他们因此增加财产，抗辩就适用。

<!-- source-p 0293 -->
<a id="44.4.4.5"></a>**5**　拉贝奥还写道：若某人明知奴隶是逃亡者仍将其买下，并取得“该奴隶并非逃亡者”的允诺，之后依据允诺起诉，不应以抗辩驳回其请求，因为双方对此已有约定，尽管他不能提起买卖之诉。若双方未曾作此约定，则应以抗辩驳回。

<!-- source-p 0294 -->
<a id="44.4.4.6"></a>**6**　又如，债权人与债务人达成和解，随后将债权让与塞尤斯；而债务人曾委托塞尤斯购买该债权。买受人据此取得要式允诺。之后，原债权人仍保留其通过法院从债务人处执行取得的钱款。买受人能否依据允诺起诉？奥菲利乌斯认为，如果债权出卖人不准备返还从买受人处收到的钱，恶意欺诈抗辩就不会对其不利；我认为奥菲利乌斯的意见正确。

<!-- source-p 0295 -->
<a id="44.4.4.7"></a>**7**　拉贝奥说：若就某奴隶提起的请求已判原告胜诉，且依裁判官命令提供担保，保证在确定日期前交付该奴隶；未交付时，原告又取得罚金允诺，那么，原告既请求返还奴隶又请求罚金，应以抗辩驳回。因为同时占有奴隶并请求罚金是不公平的。

<!-- source-p 0296 -->
<a id="44.4.4.8"></a>**8**　又有人问：若我把珍珠质押给你，并约定清偿债务后返还，而珍珠因你的过错灭失，你却请求债务给付，如何处理？涅尔瓦和阿提利基努斯认为，应提出如下抗辩：“我与你并未约定在债务清偿后将珍珠返还给我。”但更正确的意见是，恶意欺诈抗辩应当对你不利。

<!-- source-p 0297 -->
<a id="44.4.4.9"></a>**9**　如果未成年人将一名幼年奴隶赠与我，随后又请求返还该奴隶，应以恶意欺诈抗辩驳回其请求；但我须返还其供养费用，以及为该奴隶支出的其他合理费用。

<!-- source-p 0298 -->
<a id="44.4.4.10"></a>**10**　此外，应当知道，若有人依据遗嘱提出违背遗嘱人意思的请求，通常会以恶意欺诈抗辩驳回。因此，未依遗嘱人意思行事的继承人，也会因该抗辩而被驳回。

<!-- source-p 0299 -->
<a id="44.4.4.11"></a>**11**　若某人被指定为十二分之一份额的继承人，按此本可取得二百；但为了不受遗产事务的烦扰，他优先选择了一项价值一百的遗赠。若他后来请求该遗赠，是否应以恶意欺诈抗辩驳回？尤利安说，不应驳回。但如果他从替补继承人处收取了价款或可视为价款的利益，以此换取自己不接受继承；那么，他请求遗赠时便被视为实施欺诈，因此应以恶意欺诈抗辩驳回。

<!-- source-p 0300 -->
<a id="44.4.4.12"></a>**12**　有人提出如下问题：我享有某土地的用益权，而你经我同意出售了该土地；此后我主张用益权时，是否应对我提出抗辩？我们采用的法律规则是，恶意欺诈抗辩会对我不利。

<!-- source-p 0301 -->
<a id="44.4.4.13"></a>**13**　马尔凯鲁斯说，针对恶意欺诈抗辩，不得给予恶意欺诈再抗辩。拉贝奥也持同一意见。他说，让双方共同的恶意使原告获益、却使被告受罚，是不公平的；公平得多的做法是，不让原告从其背信行为中取得任何利益。

<!-- source-p 0302 -->
<a id="44.4.4.14"></a>**14**　同样，对于《马其顿元老院决议》抗辩，可以给予恶意欺诈再抗辩，这一点毫无疑问；敕令和法学家意见也确认，这种再抗辩应当发生阻却效力。

<!-- source-p 0303 -->
<a id="44.4.4.15"></a>**15**　拉贝奥说，即使因设有欺诈条款而可以提起要式允诺之诉，若发生了与该条款相反的行为，恶意欺诈抗辩仍会对原告不利。因为原告可能在允诺尚未生效前没有实施恶意欺诈，但在请求给付时才开始欺诈；因此仍有必要提出这项抗辩。

<!-- source-p 0304 -->
<a id="44.4.4.16"></a>**16**　针对父母和释奴保护人，不得提出恶意欺诈抗辩，也不得提出任何会损害其良好声誉或有悖善良风俗的其他抗辩。不过，可以提出事实抗辩；例如，若主张钱款并未实际交付，就可以提出未交付钱款抗辩。父亲或释奴保护人是因其本人订立的契约还是因他人订立的契约而被起诉，并无区别：无论其生前还是死后，都应始终给予尊敬。但若释奴保护人起诉被释奴的继承人，我认为，被释奴的继承人可以提出针对释奴保护人欺诈的抗辩。至于被释奴本人，即使释奴保护人的继承人起诉他，也绝不应提出针对释奴保护人欺诈的抗辩；因为释奴保护人生前和死后，被释奴都应给予尊敬。当然，要式允诺中的欺诈条款不应删除，因为依据欺诈条款提起的并非恶意欺诈之诉，而是要式允诺之诉。

<!-- source-p 0305 -->
<a id="44.4.4.17"></a>**17**　提出这项抗辩时，我们也可以主张奴隶或其他受我们权力支配之人的欺诈，也可以主张为我们取得利益之人的欺诈。如果诉讼是因奴隶或家子的特有产事务提起，就可以不受限制地提出其欺诈抗辩；如果并非特有产事务，则只能针对其在所涉交易中参与实施的欺诈提出抗辩，不能以其后来实施的欺诈为由提出抗辩。奴隶的欺诈不应使主人承受更大的不利，超出主人使用奴隶劳力所导致的不利。

<!-- source-p 0306 -->
<a id="44.4.4.18"></a>**18**　有人询问：能否提出代理人的欺诈抗辩，而该代理人仅获授权提起诉讼？我认为，较为正确的意见是：若代理人是为自己的利益而受任，即使其先前的欺诈——也就是在诉讼成立前实施的欺诈——也应作为抗辩提出；若并非为其自身利益而受任，则抗辩中只能提出其当前的欺诈。涅拉提乌斯写道，如果该代理人获准管理一切事务，就可以针对其任何欺诈提出抗辩。

<!-- source-p 0307 -->
<a id="44.4.4.19"></a>**19**　我委托提提乌斯向你取得要式允诺，随后提提乌斯又委托塞尤斯；塞尤斯向你取得允诺并提起诉讼。拉贝奥说，应当针对我和塞尤斯的欺诈均提出抗辩。

<!-- source-p 0308 -->
<a id="44.4.4.20"></a>**20**　又有人问：若我的债务人欺骗了你，并把你指定为我的债务人；我随后向你取得要式允诺，再起诉请求给付，恶意欺诈抗辩是否会阻却我的请求？更好的意见是，不得允许你以我的债务人的欺诈为由对我提出抗辩，因为欺骗你的不是我。你可以对我自己的债务人提起诉讼。

<!-- source-p 0309 -->
<a id="44.4.4.21"></a>**21**　如果妇女在实施欺诈后，将自己的债务人委托给丈夫作为嫁资，同样应认定不得以该妇女的欺诈为由对丈夫提出抗辩，以免她变得没有嫁资。

<!-- source-p 0310 -->
<a id="44.4.4.22"></a>**22**　尤利安讨论过如下问题：岳父的继承人被请求给付嫁资时，提出针对丈夫和女儿欺诈的抗辩；款项本应使女儿受益，那么，基于女儿身份的抗辩是否会阻却请求？尤利安说，如果丈夫依据嫁资允诺向岳父的继承人请求给付，而继承人提出女儿欺诈的抗辩，该抗辩会发生阻却效力。因为丈夫向岳父继承人请求的嫁资，尤利安说，应视为归女儿取得，因为她会因此取得嫁资。尤利安没有说明能否再提出丈夫欺诈的抗辩；我认为，他的意思是，即使看起来并非为女儿请求嫁资，丈夫欺诈的抗辩也应产生不利效果。

<!-- source-p 0311 -->
<a id="44.4.4.23"></a>**23**　许多人还讨论过：未成年人起诉时，能否以监护人的欺诈为由向其提出抗辩？我认为，更有益的意见是：虽然法律通过这些人保护未成年人，但仍应当说，如果有人从监护人处购买未成年人的财物，或与监护人就未成年人事务订立契约，或者监护人实施欺诈并使未成年人因此增加财产，该欺诈应对未成年人不利。无论监护人是否提供担保、是否有清偿能力，都无须区别，只要他确实管理事务即可。与监护人订约的人怎能预知这些情形？当然，如果有人与监护人串通，其自身行为会对其不利。

<!-- source-p 0312 -->
<a id="44.4.4.24"></a>**24**　如果某人并非监护人，而是以监护人身份管理事务，其欺诈是否会对未成年人不利？我们来考察这一点。我认为不会。因为如果以监护人身份管理事务的人出售某物，且该物已经被他人通过取得时效取得，未成年人在主张返还自己的物时，不应受到恶意欺诈抗辩的阻却，即使买受人已获得担保亦然；因为未成年人的事务管理并未托付给他。

<!-- source-p 0313 -->
<a id="44.4.4.24a"></a>**24a**　依照以上论述，我更倾向于认为，可以针对未成年人提出监护人欺诈的抗辩。

<!-- source-p 0314 -->
<a id="44.4.4.25"></a>**25**　我们对监护人所说的，对精神失常者的保佐人也同样适用；也适用于 [] 挥霍者或未满二十五岁者的保佐人。

<!-- source-p 0315 -->
<a id="44.4.4.26"></a>**26**　未满二十五岁者本人的欺诈，当然可以作为抗辩提出。毫无疑问，有时也可以针对未成年人的欺诈提出抗辩，因为其年龄已足以实施欺诈。尤利安也屡次写道，接近青春期的未成年人能够实施欺诈。试想，若债务人依未成年债权人的指示，将钱交给其债权人，尤利安说，应将未成年人视为已达青春期，以免他因不知欺诈而重复取得同一笔钱。若有人误以为精神失常者心智健全，精神失常者便命令债务人向其债权人清偿，或者把收取的钱款留在家中，也应遵循同一规则。

<!-- source-p 0316 -->
<a id="44.4.4.27"></a>**27**　不得以其前手的欺诈为由对买受人提出抗辩。但如果买受人加上前手的占有期间，认为公平的是：基于前手身份而加上其占有期间的人，也应承受前手的欺诈。通常认为，附着于物本身的抗辩也会对买受人不利；但因个人违法行为而产生的抗辩，不应对买受人不利。

<!-- source-p 0317 -->
<a id="44.4.4.28"></a>**28**　如果盖乌斯·塞尤斯的法定继承本应归你，而我被指定为继承人；你以恶意欺诈劝说我不要接受继承；我放弃继承后，你又收取价款，将该继承权让与塞姆普罗尼乌斯，而他向我请求遗产——他无需承受基于让与人欺诈而提出的抗辩。

<!-- source-p 0318 -->
<a id="44.4.4.29"></a>**29**　又如，某人基于遗赠请求返还财物，或者基于赠与取得财物的人请求返还该物：他是否会因其所承继之人的欺诈而受到抗辩？庞波尼乌斯更倾向于认为应当驳回其请求；我也认为，应以抗辩驳回这些人，因为他们是基于无偿获利的原因取得利益。毕竟，购买不同于基于这些原因而承继。

<!-- source-p 0319 -->
<a id="44.4.4.30"></a>**30**　庞波尼乌斯对接受质押的人也作同样论述：若其依据塞尔维安之诉或抵押之诉起诉，庞波尼乌斯认为也应驳回其请求，因为该物最终会回到实施欺诈之人手中。

<!-- source-p 0320 -->
<a id="44.4.4.31"></a>**31**　如前所述，不得以前手的欺诈为由对买受人提出抗辩。但我们只对买受人适用此规则；也适用于以物易物取得财物的人、以物抵债取得财物的人，以及类似处于买受人地位的人。此外，如果某人因诺克萨交付而取得奴隶，庞波尼乌斯认为，他应承受本可对诺克萨交付人提出的抗辩。因此，若某人基于其他接近无偿获利的原因取得财物，就会承受针对其前手欺诈所提出的抗辩。只有以价款或可替代价款的给付取得财物，且为善意买受人，才足以不受针对前手欺诈的抗辩；当然，他本人必须没有欺诈。若其本人也有欺诈，则仍会遭遇恶意欺诈抗辩，并承受针对其本人欺诈提出的抗辩。

<!-- source-p 0321 -->
<a id="44.4.4.32"></a>**32**　如果你从提提乌斯处买下原属于塞姆普罗尼乌斯的土地，并已付价款、受领交付；此后，提提乌斯成为塞姆普罗尼乌斯的继承人，又把同一土地出售并交付给梅维乌斯。尤利安说，裁判官保护你的做法更为公平。因为如果提提乌斯本人向你请求该土地，他会被通过事实设定的抗辩或恶意欺诈抗辩驳回；如果他自己占有该土地，而你提起普布利基安对物之诉，他提出“该物并非原属于你”的抗辩时，你可以提出再抗辩。由此可见，提提乌斯再次出售的土地并不属于他的财产。

<!-- source-p 0322 -->
<a id="44.4.4.33"></a>**33**　卡西乌斯没有提出胁迫抗辩，因为他认为一般性的恶意欺诈抗辩已经足够；但后来认为，另行提出胁迫抗辩更为有益。胁迫抗辩与恶意欺诈抗辩确有区别：恶意欺诈抗辩以实施欺诈者本人为对象；而胁迫抗辩则以“在此事中未发生胁迫”（*si in ea re nihil metus causa factum est*）为内容，属于针对事项本身的抗辩。因此，我们无须考察起诉者是否实施了胁迫，只须考察任何人是否在此事中实施了胁迫，而不只限于起诉者。尽管不得以其前手的欺诈为由提出抗辩，我们仍依此法律规则，允许以任何人（包括前手）所施加的胁迫为由提出抗辩。

<!-- source-p 0323 -->
<a id="44.4.4.34"></a>**34**　应当知道，遭受胁迫者若当时处于父母的权力之下，且胁迫系父母所施加，就不得提出这项胁迫抗辩；因为父母有权在涉及特有产的事务中使子女处于较不利地位。但如果该子女放弃父亲的遗产，则应像其他情形一样给予救济。

保罗《告示评注》第七十一卷。

<!-- source-p 0326 -->
<a id="44.4.5.pr."></a>**序言**　你无条件地欠我十枚金币，而我附条件将这十枚金币遗赠给你。在此期间，如果继承人请求给付，不应以恶意欺诈抗辩驳回其请求，因为条件仍可能不成就；因此，继承人应当提供遗赠担保。但如果继承人不提供担保，就应以恶意欺诈抗辩驳回其请求；因为与被迫进入遗产财产占有相比，受遗赠人保留这笔钱更为有利。

<!-- source-p 0327 -->
<a id="44.4.5.1"></a>**1**　如果有人受遗赠取得通行权，而《法尔基第法》适用，他却未提出四分之一份额的估价便请求确认全部通行权，马尔凯鲁斯说，应以恶意欺诈抗辩驳回其请求，因为他是在为自己谋利。

<!-- source-p 0328 -->
<a id="44.4.5.2"></a>**2**　如果我将物赠与某人，却尚未交付；受赠人未取得占有便在该物所在处修建房屋，我明知此事；待其建成后，我又取得该处占有，而受赠人向我请求赠与之物，我则以赠与超过法定限额为由提出抗辩。能否提出恶意欺诈再抗辩？我让他建造房屋却不偿还费用，确实是我在欺诈。

<!-- source-p 0329 -->
<a id="44.4.5.3"></a>**3**　受命追收款项的代理人，即使后来实施欺诈，也会使其委托人受到不利影响。

<!-- source-p 0330 -->
<a id="44.4.5.4"></a>**4**　奴隶由主人授权之人出售，之后又被退还给主人。出卖人请求价款时，可以对其提出退货抗辩，即使出售者已经向主人交付价款亦然；即使未交付货物的抗辩，也会驳回已将钱交给主人的出售者的请求。因此，出售者才会起诉主人。佩迪乌斯说，为我们管理事务的人出售物品时，情形也相同。

<!-- source-p 0331 -->
<a id="44.4.5.5"></a>**5**　如果我将一个人委托给自己的债权人作为债务人，而此人原本想向我作超过法定限额的赠与，他不能对请求给付的债权人提出抗辩，因为债权人请求的是自己的债权。丈夫也处于同一地位：以自己名义起诉者不应被抗辩驳回。那么，丈夫请求嫁资时，能否以妻子的欺诈为由对他提出抗辩？丈夫本不会娶妻，若非取得嫁资；但若夫妻已经离婚，则可以如此。因此，委托他人承担债务的债务人或妻子，应负返还之诉责任，使被委托的债务人免责；若该债务人已经清偿，则应向其返还钱款。

<!-- source-p 0332 -->
<a id="44.4.5.6"></a>**6**　恶意欺诈之诉有确定的时效期间，但恶意欺诈抗辩并不受同一期间限制。该抗辩永久适用，因为原告可以自行决定何时行使权利，而被起诉者无法决定何时被起诉。

斯凯沃拉《学说汇纂》第二十七卷。

<!-- source-p 0371 -->
<a id="44.4.17.pr."></a>**序言**　一名父亲为女儿允诺给付嫁资，并约定由自己供养女儿及其全家。〔译疑：*eiusque omnes* 所指“全家/随从”待核。〕此人是乡民，他还写信给女婿，仿佛是就嫁资允诺所生的既往利息作出承诺。有人询问：既然父亲已经供养女儿，丈夫也未支出任何费用，女婿依据借据提起要式允诺之诉时，是否应以抗辩阻却其请求？答复说，若如所述，父亲供养女儿时是因错误而作出允诺，则恶意欺诈抗辩适用。

<!-- source-p 0372 -->
<a id="44.4.17.1"></a>**1**　祖父将一百遗赠给女儿所生的每一名孙辈，并补充说：“请原谅我；若不是你们的父亲弗龙托曾恶意对待我，我本可以给你们留下更多。我曾借给他十五，他却不肯偿还；最后，敌人又夺走了我几乎全部财产。”有人询问：祖父的继承人若向这些孙辈——即其父亲的继承人——请求十五，是否违背死者意思，因此应以恶意欺诈抗辩驳回？答复说，抗辩会阻却该请求。

<!-- source-p 0373 -->
<a id="44.4.17.2"></a>**2**　某人被指定为四分之一份额的继承人；他从被指定为四分之三份额继承人的共同继承人处，以确定金额买下其份额，并向对方允诺给付其中一笔款项，以便对方将其列入账簿。〔译疑：*in nominibus ex kalendario* 涉及账簿/到期债权记载，具体文义待核。〕遗产出卖人死亡后，塞普提基乌斯开始主张遗嘱系伪造，并向买受人请求遗产，且获准不得减少遗产财产。有人询问：伪造遗嘱之诉尚在审理期间，出卖人的继承人依据要式允诺请求给付时，是否应以恶意欺诈抗辩驳回？答复说，如果出卖人的继承人在伪造遗嘱之诉结果确定前就继续请求，应可用恶意欺诈抗辩驳回。

<!-- source-p 0374 -->
<a id="44.4.17.3"></a>**3**　遗嘱指定丈夫和他们共同的儿子各继承一半，又以如下条件指定其前一段婚姻所生的女儿为继承人：“我的女儿梅维娅，你应继承我十二分之六的遗产；条件是，你须就我所占份额，与共同继承人作出同等结算，结算事项为截至我死亡之日尚未了结的、因你受监护而产生的事务；该监护事务由提提乌斯（我的父亲、你的祖父）管理。〔原文句法疑难：*pro mea portione in diem mortis meae eius actus* 的结算范围和截止时点待总校。〕”有人询问：既然女儿是附条件被指定为继承人，如果她放弃继承以保全监护诉权，能否取得母亲遗赠给她的遗赠？答复说，依所述事实，她的请求违背死者意思，因此恶意欺诈抗辩会阻却该请求。
