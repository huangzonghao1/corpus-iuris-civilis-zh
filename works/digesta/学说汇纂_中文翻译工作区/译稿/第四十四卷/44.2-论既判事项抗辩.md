# D.44.2 论既判事项抗辩（*De exceptione rei iudicatae*）

<!-- source-p 0080 -->
<a id="2"></a><a id="44.2"></a>**44.2.0**　论既判事项抗辩。

<!-- source-p 0081 -->
<a id="44.2.1"></a>**44.2.1**

<!-- source-p 0082 -->
乌尔比安《告示评注》第二卷。

<!-- source-p 0083 -->
既判事项发生在他人之间时，不对其他人产生先决效力。因此，在遗嘱中授予自由或遗赠诉权的，即使该遗嘱被主张已经撤销、失效或不合法，仍可依据遗嘱主张自由或遗赠；遗赠受领人败诉，也不对自由身份产生先决效力。

<!-- source-p 0084 -->
<a id="44.2.2"></a>**44.2.2**

<!-- source-p 0085 -->
乌尔比安《告示评注》第十三卷。

<!-- source-p 0086 -->
某人曾起诉一名继承人；被继承人原本应在遗嘱中指定的儿子却被遗漏。该人因被提出如下抗辩而败诉：“除非遗嘱书板的情形足以准许针对遗嘱授予遗产占有，否则不得起诉。”后来，被解放的儿子未申请遗产占有，有人认为应当恢复其对继承人的诉权，使其得以起诉。尤利安在《学说汇纂》第四卷中也如此写道。

<!-- source-p 0087 -->
<a id="44.2.3"></a>**44.2.3**

<!-- source-p 0088 -->
乌尔比安《告示评注》第十五卷。

<!-- source-p 0089 -->
尤利安在《学说汇纂》第三卷中答称，只要同一争议在同一当事人之间重新提出，既判事项抗辩即构成障碍。因此，若先请求遗产中的个别物，之后又请求遗产整体，或反之，均会被该抗辩排除。

<!-- source-p 0090 -->
<a id="44.2.4"></a>**44.2.4**

<!-- source-p 0091 -->
乌尔比安《告示评注》第七十二卷。

<!-- source-p 0092 -->
既判事项抗辩默示包含所有通常会将争议提交审判的人。

<!-- source-p 0093 -->
<a id="44.2.5"></a>**44.2.5**

<!-- source-p 0094 -->
乌尔比安《告示评注》第七十四卷。

<!-- source-p 0095 -->
即使某人没有沿用最初的诉权，而改用另一种诉权，只要争议的仍是同一事项，也视为就同一事项起诉。例如，某人原可提起委任之诉；对方曾承诺为应诉而到庭，他却就同一事项改提事务管理之诉或返还诉，仍是在就同一事项起诉。正确的界定是：只有完全没有追索该事项本身的人，才不算“就该事项”起诉；其余情形，只要追索的是同一事项，即使改用不同种类的诉讼，也视为就该事项起诉。

<!-- source-p 0096 -->
<a id="44.2.6"></a>**44.2.6**

<!-- source-p 0097 -->
保罗《告示评注》第七十卷。

<!-- source-p 0098 -->
通常认为，每项争议各以一次诉讼和一项终局判决为足，理由充分；否则，诉讼数量一旦增加，便会造成巨大且难以解决的困难，尤其是不同判决彼此矛盾时。因此，既判事项抗辩经常适用。

<!-- source-p 0099 -->
<a id="44.2.7"></a>**44.2.7**

<!-- source-p 0100 -->
乌尔比安《告示评注》第七十五卷。

<!-- source-p 0101 -->
<a id="44.2.7.pr."></a>**序言**　某人先请求全部，随后又请求其中一部分的，既判事项抗辩构成障碍，因为部分包含在整体之中。对整体提出请求后，再请求其一部分，也视为请求同一事项。无论涉及的是具体物、数量还是权利，均无区别。因此，若某人先请求一块土地，后来再请求其中一部分，无论按份分割还是未分割共有，均应认为该抗辩构成障碍。即使后来只请求该土地中的某一特定地点，抗辩也构成障碍。两件物先被一并请求，后来再单独请求其中一件，也同样如此。又如，先请求一块土地，后来请求从该地砍下的树木；先请求一栋楼房，后来请求其基地、梁木或石料；先请求一艘船，后来请求其中各块船板；或者先请求一名怀孕女奴，在争讼程序确定后她受孕并生产，后来又请求其子女：这些究竟属于请求同一事项还是不同事项，是一个重大问题。对此可以作如下概括：凡后案法官所审理的问题，已在前案法官面前审理过的，即视为就同一事项再次起诉。

<!-- source-p 0102 -->
<a id="44.2.7.1"></a>**1**　上述情形大体均受该抗辩阻却，但水泥块和梁木属于例外。若某人请求一栋楼房，随后另行请求水泥块、梁木或其他属于自己的物，便属于请求不同事项。因为楼房所有人并不当然也拥有这些材料；事实上，附合于他人建筑物的物品，所有人分离后仍可请求返还。

<!-- source-p 0103 -->
<a id="44.2.7.2"></a>**2**　孳息和子女也有同样的问题：起诉时它们尚未存在于人世，虽然是从已请求的物产生的，但更妥当的见解是该抗辩不妨碍请求。不过，若孳息或子女已计入返还范围或估价，则应当允许提出该抗辩。

<!-- source-p 0104 -->
<a id="44.2.7.3"></a>**3**　尤利安作了一般性界定：只要同一争议在同一当事人之间重新提出，即使改用另一种诉讼程序，既判事项抗辩也构成障碍。因此，先请求遗产整体、后来请求其中个别物，或先请求个别物、后来请求遗产整体，均应被该抗辩排除。

<!-- source-p 0105 -->
<a id="44.2.7.4"></a>**4**　若某人先向遗产债务人请求清偿债务，后来再请求遗产整体，或先请求遗产、后来再请求该项债务，也应作同样判断：此处亦有既判事项抗辩阻却。因为请求遗产整体时，遗产所包含的全部物和诉权均视为纳入请求。

<!-- source-p 0106 -->
<a id="44.2.8"></a>**44.2.8**

<!-- source-p 0107 -->
尤利安《学说汇纂》第五十一卷。

<!-- source-p 0108 -->
对土地的一部分提出请求后，若又提起遗产分割之诉或共有物分割之诉，同样会被该抗辩排除。

<!-- source-p 0109 -->
<a id="44.2.9"></a>**44.2.9**

<!-- source-p 0110 -->
乌尔比安《告示评注》第七十五卷。

<!-- source-p 0111 -->
<a id="44.2.9.pr."></a>**序言**　若我向你请求遗产，而当时你并未占有遗产；后来你开始占有其中某物，我再请求遗产，既判事项抗辩是否构成障碍？我认为，无论先前判决确认遗产属于我，还是因对方当时未占有遗产而判其胜诉，均不妨碍我再次请求。

<!-- source-p 0112 -->
<a id="44.2.9.1"></a>**1**　某人曾为自己占有某土地进行抗辩，后来才买下该土地；判决支持请求人时，他是否必须返还？内拉提乌说，如果请求人再次请求时被提出既判事项抗辩，他应当以先前判决支持自己的事实提出再抗辩。

<!-- source-p 0113 -->
<a id="44.2.9.2"></a>**2**　尤利安写道，既判事项抗辩通常从权利来源人移转给买受人，但不得反向从买受人移转给权利来源人。因此，若你出售一项遗产中的物，我向买受人请求该物并胜诉；后来你再向我请求时，我不得对你提出“该事项并未在我与你出售该物之人之间判决”的抗辩。

<!-- source-p 0114 -->
<a id="44.2.10"></a>**44.2.10**

<!-- source-p 0115 -->
尤利安《学说汇纂》第五十一卷。

<!-- source-p 0116 -->
同样，若我败诉，你也不得对我提出该抗辩。

<!-- source-p 0117 -->
<a id="44.2.11"></a>**44.2.11**

<!-- source-p 0118 -->
乌尔比安《告示评注》第七十五卷。

<!-- source-p 0119 -->
<a id="44.2.11.pr."></a>**序言**　未适婚人之母依据元老院决议请求遗产占有，理由是她认为其子之父的遗嘱已被撤销，且无人被指定为替补继承人；她后来败诉，因为父亲的遗嘱并未撤销。之后，未适婚人遗嘱书板开启，显示并未为其指定替补继承人；母亲若再次请求遗产，内拉提乌说，将受到既判事项抗辩阻却。我毫不怀疑，该抗辩确实适用于既判事项；但应基于具体情形给予她救济，因为她此前只以遗嘱已撤销为由提起诉讼。

<!-- source-p 0120 -->
<a id="44.2.11.1"></a>**1**　因此，塞尔苏斯也写道：某人请求一名奴隶，认为奴隶因他人交付而归自己所有；实际上奴隶是因继承而归其所有。他若再次请求该奴隶，将受到既判事项抗辩阻却。

<!-- source-p 0121 -->
<a id="44.2.11.2"></a>**2**　但若某人主张土地因提提乌斯向其交付而属于自己，后来又基于另一项原因提出请求，并陈述新的原因，则不应以该抗辩将其排除。

<!-- source-p 0122 -->
<a id="44.2.11.3"></a>**3**　尤利安还写道：我与你共同继承提提乌斯的遗产。若你向塞姆普罗尼乌斯请求一块土地的一部分，主张该土地整体属于遗产，并败诉；后来我又从塞姆普罗尼乌斯处买下同一部分，当你对我提起遗产分割之诉时，将受到抗辩阻却，因为该事项已在你与我的出卖人之间判决。即使我在你起诉之前已经请求同一部分，而你再提起遗产分割之诉，也会受到“该事项已在我与你之间判决”的抗辩阻却。

<!-- source-p 0123 -->
<a id="44.2.11.4"></a>**4**　请求所依据的原因也会使案件成为同一案件。但若我请求一块土地或一名奴隶，之后在请求提出后取得一项新的原因，而该原因使我获得所有权，这一抗辩不会排除我；唯一例外是，我先前中断的所有权后来因返归权而恢复。例如，我请求的奴隶被敌人俘获，后来又依据返归权回到罗马；此时抗辩会排除我，因为法律上仍视为同一物。但若我基于另一原因取得所有权，抗辩便不妨碍请求。因此，若某物附条件遗赠给我，我在条件成就前取得该物所有权；条件成就后又基于遗赠请求该物，我认为该抗辩不构成障碍，因为前后所有权的原因不同，后来又出现了新的原因。

<!-- source-p 0124 -->
<a id="44.2.11.5"></a>**5**　因此，后来取得所有权确实构成新的原因；但请求人改变自己的认识，并不构成新的原因。例如，他原先认为自己基于继承取得所有权，后来改认为自己是基于赠与取得；这不会产生新的请求，因为无论通过何种方式、基于何种原因取得所有权，他在第一次所有物返还请求中已经将所有权问题提交审判。

<!-- source-p 0125 -->
<a id="44.2.11.6"></a>**6**　若某人先请求通行权，后来请求驱赶牲畜的权利，我认为较有力的见解是：前后请求的对象不同，因此既判事项抗辩不适用。

<!-- source-p 0126 -->
<a id="44.2.11.7"></a>**7**　我们适用以下规则：在既判事项抗辩中，原告一方包括所有将争议提交审判的人，其中有受委任的代理人、监护人、精神失常者或未适婚人的保佐人，以及市镇的代理人。被告一方也包括辩护人，因为对辩护人提起诉讼的人，已将争议提交审判。

<!-- source-p 0127 -->
<a id="44.2.11.8"></a>**8**　某人先向家父权下的儿子请求一名奴隶，后来又向其父亲请求同一奴隶的，适用本项抗辩。

<!-- source-p 0128 -->
<a id="44.2.11.9"></a>**9**　若我与你提起排除雨水之诉，之后我们任何一方出售土地，买受人再提起诉讼或成为被诉方，该抗辩均构成障碍；但其效力仅及于法院受理诉讼时已经完成的工程。

<!-- source-p 0129 -->
<a id="44.2.11.10"></a>**10**　提图斯曾将你所请求的物质押给塞乌斯，后来塞乌斯对你提起质押之诉，应区分提图斯何时设立质押。若是在你起诉之前质押，抗辩不应损害你：提图斯本应提起请求，而我也应保有质押之诉。若是在你起诉之后才质押，则较妥当的见解是既判事项抗辩构成障碍。

<!-- source-p 0130 -->
<a id="44.2.12"></a>**44.2.12**

<!-- source-p 0131 -->
保罗《告示评注》第七十卷。

<!-- source-p 0132 -->
判断该抗辩是否构成障碍时，应当考察争议是否涉及同一物体；

<!-- source-p 0133 -->
<a id="44.2.13"></a>**44.2.13**

<!-- source-p 0134 -->
乌尔比安《告示评注》第七十五卷。

<!-- source-p 0135 -->
数量是否相同，权利是否相同；

<!-- source-p 0136 -->
<a id="44.2.14"></a>**44.2.14**

<!-- source-p 0137 -->
保罗《告示评注》第七十卷。

<!-- source-p 0138 -->
<a id="44.2.14.pr."></a>**序言**　还要考察请求原因是否相同、当事人的身份是否相同；这些条件若未全部具备，便属于不同事项。不过，本项抗辩中的“同一物体”并不要求此前与此后物体在所有性质和数量上完全相同，亦不要求毫无增减；为共同利益起见，应从宽理解。

<!-- source-p 0139 -->
<a id="44.2.14.1"></a>**1**　某人原有部分用益权，曾请求全部用益权，后来再请求因增益而取得的部分，不受既判事项抗辩排除；因为用益权是归于人而非份额而增益。

<!-- source-p 0140 -->
<a id="44.2.14.2"></a>**2**　对人诉权与对物诉权的区别在于：若同一债务人基于不同原因分别对我负有同一物之给付义务，各项债务分别有其原因，其中一项请求不会使其他请求失效。相反，提起对物诉讼时，若未明确说明主张所有权的原因，则所有可能的所有权原因都由同一请求一并涵盖。因为同一物不可能多次成为我的所有物，但同一给付却可能多次成为应向我履行的债务。

<!-- source-p 0141 -->
<a id="44.2.14.3"></a>**3**　某人曾以禁令就占有提起诉讼，之后再提起对物诉讼，不受该抗辩排除，因为禁令程序争议的是占有，而诉讼争议的是所有权。

<!-- source-p 0142 -->
<a id="44.2.15"></a>**44.2.15**

<!-- source-p 0143 -->
盖尤斯《行省告示评注》第三十卷。

<!-- source-p 0144 -->
若我与你之间存在遗产争议，而你占有遗产中的某些物，我占有另一些物，则我可以向你请求遗产，你也可以反过来向我请求遗产。若法院判决后你再对我提出请求，须区分判决是确认遗产属于我，还是认定遗产不属于我：若判决确认遗产属于我，则既判事项抗辩会损害你，因为既然判决确认遗产属于我，便意味着判决相应认定遗产不属于你；若判决认定遗产不属于我，则不能认为判决已经裁定你的权利，因为遗产可能既不属于我，也不属于你。

<!-- source-p 0154 -->
<a id="44.2.19"></a>**44.2.19**

<!-- source-p 0155 -->
马尔凯鲁斯《学说汇纂》第十九卷。

<!-- source-p 0156 -->
某人在两个不同时间将同一物质押给两人。后设质押的债权人对先设质押的债权人提起质押之诉并胜诉；后来，先设质押的债权人又提起同一种诉讼。有人问，既判事项抗辩是否构成障碍。若他提出了“该物先前已质押给自己”的抗辩，且没有补充任何新的有效理由，该抗辩无疑构成障碍，因为他将同一争议重新提交审判。

<!-- source-p 0157 -->
<a id="44.2.20"></a>**44.2.20**

<!-- source-p 0158 -->
庞波尼《萨宾评注》第十六卷。

<!-- source-p 0159 -->
遗赠受领人曾依据遗嘱对继承人起诉；遗嘱将全部银器遗赠给他，但他误以为只有银桌遗赠给自己，便仅就这些桌子在诉讼中请求估价。特雷巴提乌说，他后来仍可请求其余遗赠银器，既判事项抗辩不构成障碍，因为原告并未认为自己请求其余银器，法官在审理中也未考虑其余银器。

<!-- source-p 0160 -->
<a id="44.2.21"></a>**44.2.21**

<!-- source-p 0161 -->
庞波尼《萨宾评注》第三十一卷。

<!-- source-p 0162 -->
<a id="44.2.21.pr."></a>**序言**　若遗嘱遗赠给我银器，我曾对继承人起诉；后来出示附遗嘱文书，才发现另有附录遗赠给我衣物，则衣物并未纳入先前诉讼，因为诉讼双方和法官都知道，争议的仅是银器。

<!-- source-p 0163 -->
<a id="44.2.21.1"></a>**1**　某人先请求一群牲畜，后来即使牲畜数量增加或减少，又请求同一群牲畜，也会受到既判事项抗辩阻却。即使请求的是该群牲畜中的某一特定牲畜，只要它曾属于该群，抗辩也会构成障碍。

<!-- source-p 0164 -->
<a id="44.2.21.2"></a>**2**　若你曾请求确认斯提库斯和潘菲卢斯属于你，且对方获判胜诉；随后你再向同一人请求确认斯提库斯属于你，既判事项抗辩显然构成障碍。

<!-- source-p 0165 -->
<a id="44.2.21.3"></a>**3**　若我曾请求确认土地属于我，之后又以同一所有权原因为由请求该土地的用益权，抗辩将构成障碍，因为土地所有人不得另行请求确认自己的用益权。但若我在拥有土地所有权之前曾请求用益权，后来取得所有权，再次请求用益权，则可以认为属于不同事项：取得土地所有权后，先前的用益权消灭；而基于土地所有权这一新原因，用益权又重新成为我的权利。

<!-- source-p 0166 -->
<a id="44.2.21.4"></a>**4**　若你为我的奴隶作保，之后有人对我提起特有产之诉，后来又以同一事由对你起诉，应当提出既判事项抗辩。

<!-- source-p 0167 -->
<a id="44.2.22"></a>**44.2.22**

<!-- source-p 0168 -->
保罗《告示评注》第三十一卷。

<!-- source-p 0169 -->
若有人对一名继承人提起寄托之诉，仍可对其他继承人适当起诉，既判事项抗辩对他们没有帮助。虽然各诉讼审理的是同一问题，但因各自以不同当事人名义起诉，主体发生变化，便构成不同事项。若先对继承人提起被继承人恶意之诉，之后再就继承人自己的恶意起诉，既判事项抗辩也不构成障碍，因为争议的是另一事项。

<a id="44.2.23"></a>**44.2.23**

<!-- source-p 0171 -->
乌尔比安《论议》第三卷。

若某人在诉讼中只请求利息，不必担心既判事项抗辩会阻却其请求本金；因为本金请求权当时并未提出，抗辩也就不构成障碍。若有人在诚信诉讼中只请求利息，道理相同：将来期间的利息仍会继续发生，因为只要诚信契约持续存在，利息便会继续计算。

<a id="44.2.25.pr."></a>**序言**　某人原本不是继承人，曾请求遗产；后来他成为继承人，再次请求同一遗产，不受既判事项抗辩排除。

<!-- source-p 0179 -->
<a id="44.2.25.1"></a>**1**　买受人有权在六个月内选择提起解除买卖之诉，或者提起请求减价之诉。后一诉讼也包含解除买卖的救济：若标的物具有某种瑕疵，以致原告若知情便不会购买，则可以解除买卖。因此，可以确切地说，某人提起这两种诉讼中的一种后，若又提起另一种，将受到既判事项抗辩排除。

<!-- source-p 0180 -->
<a id="44.2.25.2"></a>**2**　若你主动提出替我处理事务，并以我的名义请求一块土地；我没有追认你的请求，而是委托你重新起诉同一土地，则既判事项抗辩不构成障碍，因为委任介入后，诉讼事项已经改变。先前提起对物诉讼、后来提起对人诉讼的，也作同样处理。

<a id="44.2.26.pr."></a>**序言**　我曾起诉请求确认自己有权将房屋加高至十尺，之后又起诉请求确认有权将房屋加高至二十尺，毫无疑问，既判事项抗辩构成障碍。若我再起诉请求确认自己另有权加高十尺，抗辩仍然构成障碍，因为只有下层部分本身合法，加盖的上层才可能合法。

<a id="44.2.30"></a>**44.2.30**

<!-- source-p 0196 -->
保罗《疑难论》第十四卷。

<!-- source-p 0197 -->
<a id="44.2.30.pr."></a>**序言**　某人按六分之一份额被指定为继承人，同时又可能成为无遗嘱继承的法定继承人。他就遗嘱效力提起争议时，曾向一名被指定继承人请求遗产的一半，但未能胜诉。该请求也视为包含对六分之一份额的主张；因此，若他后来又依据遗嘱向同一被指定继承人请求同一份额，将受到既判事项抗辩阻却。

<!-- source-p 0198 -->
<a id="44.2.30.1"></a>**1**　拉提努斯·拉尔古斯说：梅维乌斯是遗产继承权人，提图斯则对其继承权提出争议；二人就遗产达成和解，由提图斯将遗产中的物交付给梅维乌斯继承人。交付时，提图斯还基于和解，将一块属于提图斯本人所有的土地交给梅维乌斯；多年前，提图斯曾将该土地质押给同一继承人梅维乌斯的祖父，后来又将其作为债务担保给了他人。上述事项处理完毕后，提图斯的另一名债权人追索其权利并胜诉。该案判决后，继承人梅维乌斯在祖传文书中发现一份提图斯多年前写下的借据；该借据显示，纳入和解的同一土地也曾由提图斯质押给他的祖父。既然可以确定，梅维乌斯败诉所涉的土地此前已经质押给其祖父，我想知道，他能否在当时不知道祖父享有该权利、且未提出任何抗辩的情况下，继续主张祖父的权利。我的答复是：若诉讼争议的是土地所有权，且判决支持原告，我们会说，先前败诉者再次请求该土地时，将受既判事项抗辩阻却；因为原告既已证明其请求，败诉者的权利也视为经过审理。反之，若占有人获判胜诉，后来丧失占有，再向先前未能胜诉的同一人请求该土地，则既判事项抗辩不妨碍请求：其权利并未在前案中得到裁断。但若先前债权人被提起质押之诉，仍可能没有审理占有人的权利。所有权诉讼中，“属于我的物”便不属于他人；但在债务关系中，一物负担一项债务，并不必然意味着它不能同时对另一人负债；本案请求人可以证明该物也对自己负有责任。较有说服力的见解是，既判事项抗辩不构成障碍，因为占有人的权利未受审理，审理的只是该物是否负有某项债务。至于题述问题，更使我在意的是：取得所有权后，质权是否已经消灭？毕竟，债权人成为所有人后，质权不能继续存在。不过，质权之诉仍然可以提起：该物确曾被质押，而债权尚未获清偿。因此，我认为既判事项抗辩不构成障碍。
