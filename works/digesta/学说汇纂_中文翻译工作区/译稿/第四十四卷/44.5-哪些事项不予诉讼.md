# D.44.5 不予诉权的事项（*Quarum rerum actio non datur*）

<!-- source-p 375 -->
<a id="5"></a><a id="44.5"></a>**44.5.0**　不予诉权的事项。

<!-- source-p 376 -->
<a id="44.5.1"></a>**44.5.1**

<!-- source-p 377 -->
乌尔比安《告示评注》第七十六卷。

<!-- source-p 378 -->
<a id="44.5.1.pr."></a>**序言**　宣誓并非毫无理由地具有与既判事项相同的效力，因为一方将宣誓之事提交给对方，实际上就是让对方充当自己案件的裁判者。

<!-- source-p 379 -->
<a id="44.5.1.1"></a>**1**　若未适婚人未经监护人认可而提出宣誓，则应认为该抗辩不妨碍诉讼；只有在诉讼中由监护人认可后才提出宣誓时，方可提出该抗辩。

<!-- source-p 380 -->
<a id="44.5.1.2"></a>**2**　若土地请求人向对方提出宣誓，约定若其权利来源人曾宣誓该土地是其所有并已交付给我，他便退出该争议，则应给予土地占有人抗辩。

<!-- source-p 381 -->
<a id="44.5.1.3"></a>**3**　若保证人宣誓，且仅就其本人宣誓自己不负债务，则对主债务人没有帮助；若其就争议事项宣誓，则也应给予主债务人抗辩。

<!-- source-p 382 -->
<a id="44.5.1.4"></a>**4**　若我释放了一名曾在奴隶身份下替我处理事务的奴隶，随后又与他订立承诺，约定他应向我给付：倘若处理我事务时他已是自由人，因其处理事务而本应给我的一切；之后我依据该承诺起诉，则不应以抗辩驳回我的请求。释奴不能因此声称其自由受到加重，因为他并未从为保护人事务而处理的事项中取得利益。

<!-- source-p 383 -->
<a id="44.5.1.5"></a>**5**　凡我为加重释奴的自由而与其订立的承诺，均不得向释奴请求履行。所谓以加重自由为目的订立的承诺，最恰当的定义是：承诺被如此设定，以致释奴若冒犯保护人，保护人便可不断向其请求履行，使其始终处于担心被追索的状态；释奴因这种恐惧，便会忍受保护人所命令的一切。

<!-- source-p 384 -->
<a id="44.5.1.6"></a>**6**　总之，若某项义务在释奴获释后立即加诸其身，且成为其自由的负担（*epaiwroumenon*），应认为可以提出该抗辩。若经过一段时间后才作出承诺，虽有疑问——因为无人强迫他作出承诺——仍应适用相同规则；但须先查明具体情况，若显然释奴仅因恐惧或对保护人过度敬畏而屈从，甚至接受了带有罚则的承诺，则应准许提出抗辩。

<!-- source-p 385 -->
<a id="44.5.1.7"></a>**7**　若释奴为获得自由而与保护人成立合伙，保护人又依据合伙关系对释奴起诉，是否需要该项抗辩？我认为，依法律本身，释奴即可免受保护人的请求。

<!-- source-p 386 -->
<a id="44.5.1.8"></a>**8**　应知，为防止加重释奴自由负担而设的抗辩，不仅不得拒绝给予保证人，也不得拒绝给予应释奴请求而成为被告的人；同样可以给予释奴本人，无论其诉讼由代理人应诉，还是由其继承人承受。裁判官既然旨在此类债务关系中救济被告，若不同时保护保证人及应释奴之请求而成为被告的人免遭保护人追索，便未实现其目的。因为保护人立即强令释奴给付，与通过保证人或被请求成为被告的其他人间接强令给付，并无多大区别。

<!-- source-p 387 -->
<a id="44.5.1.9"></a>**9**　无论承诺是向保护人本人作出，还是经保护人同意向他人作出，均视为以加重释奴自由负担为目的，因此可以提出该项抗辩。

<!-- source-p 388 -->
<a id="44.5.1.10"></a>**10**　若保护人将释奴指定给债权人，释奴是否可以对该债权人提出此项抗辩——因为他是为加重自由负担而向债权人承诺的——仍须考察。卡西乌斯曾认为，乌尔塞乌斯记载债权人绝不应被此项抗辩驳回，因为他只是收取属于自己的债权；不过，除非该承诺是为解决争议而作，释奴可以向保护人提起返还请求之诉。

<!-- source-p 389 -->
<a id="44.5.1.11"></a>**11**　同样，若释奴将自己的债务人指定给保护人，保护人不得被任何抗辩驳回；释奴应通过返还请求之诉向保护人追回该款项。

<!-- source-p 390 -->
<a id="44.5.1.12"></a>**12**　此项抗辩不仅应给予释奴本人，也应给予其继受人。反过来说，若保护人的继承人就此请求履行，也应知道该继承人应被抗辩驳回。

<!-- source-p 391 -->
<a id="44.5.2"></a>**44.5.2**

<!-- source-p 392 -->
保罗《告示评注》第七十一卷。

<!-- source-p 393 -->
<a id="44.5.2.pr."></a>**序言**　若有人向家子提出宣誓，家子宣誓其父无须给付，则应给予父亲抗辩。

<!-- source-p 394 -->
<a id="44.5.2.1"></a>**1**　若我为赌博而出售某物以便继续赌博，后来该物被追夺，买受人因此起诉我，则买受人将被抗辩驳回。

<!-- source-p 395 -->
<a id="44.5.2.2"></a>**2**　若奴隶承诺向主人给付金钱以换取释放，而主人若非收取该款原本不会释放他；奴隶获释后又作出该承诺，则据说，若保护人请求该款，抗辩并不妨碍其请求。因为该项金钱承诺并非以加重自由负担为目的。否则，主人既失去奴隶，又得不到价款，便显失公平。因此，只有在主人自行决定释放奴隶，并因此要求释奴承诺给付金钱，目的不是实际索取该款，而是使释奴畏惧并服从自己时，才认为该金钱承诺是为了加重自由负担。
