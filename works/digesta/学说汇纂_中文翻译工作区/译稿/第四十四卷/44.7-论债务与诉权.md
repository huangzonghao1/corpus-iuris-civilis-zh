# D.44.7　论债务与诉权（*De obligationibus et actionibus*）

> 底本：*Digesta Iustiniani*，EPUB book-44.xhtml，source-p 407–645。

<!-- source-p 407 -->
<a id="7"></a><a id="44.7"></a>**44.7.0**　论债务与诉权。

<!-- source-p 408 -->
<a id="44.7.1"></a>**44.7.1**

<!-- source-p 409 -->
盖尤斯《金言集》第二卷。

<!-- source-p 410 -->
<a id="44.7.1.pr."></a>**序言**　债务要么源于契约，要么源于不法行为，要么依据某种特有规则、从各种原因类型中产生。

<!-- source-p 411 -->
<a id="44.7.1.1"></a>**1**　契约债务或者以物成立，或者以言词成立，或者以合意成立。

<!-- source-p 412 -->
<a id="44.7.1.2"></a>**2**　借贷给付使债务以物成立。借贷给付涉及按重量、数量或度量确定的物，例如葡萄酒、橄榄油、谷物或现钱。我们交付这些物，是为了使其成为受领人的所有物，日后再收回其他同种同质的物。

<!-- source-p 413 -->
<a id="44.7.1.3"></a>**3**　把物借给他人使用的人，也因该物而对我们负有债务；但他负有返还其所受领的那件物本身的义务。

<!-- source-p 414 -->
<a id="44.7.1.4"></a>**4**　借款人无论因何种原因丧失所借之物，仍继续负有债务。借用人若因人力无法抵抗的较大事故而丧失所受领之物，例如火灾、房屋倒塌或船舶失事，则不负责任。但在其他情形中，他必须对保管该物尽到最严格的注意；如果另有人可以更加谨慎地保管，仅仅做到像照管自己财物那样谨慎，并不足够。不过，即便发生较大事故，只要有他的过错介入，他仍须负责。例如，他为了邀请朋友来家中用餐而借用银器，却在出远门时执意携带这些银器，结果在海难中，或遭遇海盗、敌人袭击时丧失银器。

<!-- source-p 415 -->
<a id="44.7.1.5"></a>**5**　我们寄存物品之人，也因该物而对我们负有债务；他同样负有返还所受领之物的义务。但即使他因保管疏忽而丧失该物，也不负责任。因为他受领该物并非为了自己的利益，而是为了寄存人的利益；只有该物因故意而灭失时，他才负责。他不因疏忽负责，是因为把物交给疏忽的朋友保管的人，应当责怪自己。不过，法学家认为，严重疏忽可以归入故意的范畴。

<!-- source-p 416 -->
<a id="44.7.1.6"></a>**6**　受领质物的债权人，也因该物而负有债务；他同样负有返还其所受领之物的义务。

<!-- source-p 417 -->
<a id="44.7.1.7"></a>**7**　以言词成立债务，是通过一问一答订立要式口约，例如我们约定你应向我给付某物或完成某事。

<!-- source-p 418 -->
<a id="44.7.1.8"></a>**8**　每个人要么以自己的名义负债，要么以他人的名义负债。以他人名义负债的人称为保证人。通常，我们还会要求以自己名义承担债务的人找来其他人，使他们也受同一债务约束；这是为了确保我们已经纳入债务关系的给付能更可靠地得到偿付。

<!-- source-p 419 -->
<a id="44.7.1.9"></a>**9**　如果约定给付的标的物不可能给付，显然依自然法理，该要式口约无效。例如，双方都不知道某人是自由人、已经死亡，或房屋已经焚毁，却约定交付该自由人、已死之人或焚毁的房屋。约定向自己交付神圣物或宗教物，也适用同一规则。

<!-- source-p 420 -->
<a id="44.7.1.10"></a>**10**　某人不知道某物属于自己，却约定向自己给付该物，这项要式口约同样无效。

<!-- source-p 421 -->
<a id="44.7.1.11"></a>**11**　众所周知，以不可能条件订立的要式口约无效。

<!-- source-p 422 -->
<a id="44.7.1.12"></a>**12**　疯癫者无论提出要式口约还是作出允诺，依自然法理都不能实施有效行为，这是显而易见的。

<!-- source-p 423 -->
<a id="44.7.1.13"></a>**13**　与疯癫者相近的是尚未达到能够理解所发生事项年龄的人。但对后者，法律作了较宽厚的处理：只要能够说话，就推定其可以有效地提出要式口约或作出允诺。

<!-- source-p 424 -->
<a id="44.7.1.14"></a>**14**　依自然法理，哑者不能参与以言词成立债务，这显而易见。

<!-- source-p 425 -->
<a id="44.7.1.15"></a>**15**　聋者也一样。即使他能够说话，在他作出允诺时，也必须听见要式口约提出人的言词；在他提出要式口约时，也必须听见允诺人的言词。因此可知，这里说的不是听觉迟缓者，而是完全听不见的人。

<!-- source-p 426 -->
<a id="44.7.2"></a>**44.7.2**

<!-- source-p 427 -->
盖尤斯《法学阶梯》第三卷。

<!-- source-p 428 -->
<a id="44.7.2.pr."></a>**序言**　买卖、租赁、合伙和委任中的债务，均以合意成立。

<!-- source-p 429 -->
<a id="44.7.2.1"></a>**1**　我们说这些方式下的债务以合意成立，是因为既不要求特定的言词，也不要求书面形式；只要处理事务的人达成合意即可。

<!-- source-p 430 -->
<a id="44.7.2.2"></a>**2**　因此，即使当事人不在同一地点，也可以订立这类契约，例如通过书信或使者。

<!-- source-p 431 -->
<a id="44.7.2.3"></a>**3**　在这些契约中，双方互负义务，各自应依诚信与公平向对方履行其应为的给付。

<!-- source-p 432 -->
<a id="44.7.3"></a>**44.7.3**

<!-- source-p 433 -->
保罗《法学阶梯》第二卷。

<!-- source-p 434 -->
<a id="44.7.3.pr."></a>**序言**　债务关系的本质，不在于使某个有体物或某项地役权归我们享有，而在于使他人对我们负担义务，向我们给付某物、实施某行为或提供某种履行。

<!-- source-p 435 -->
<a id="44.7.3.1"></a>**1**　仅有钱币原属给付人所有、后来成为受领人所有，还不足以成立债务；还必须以成立债务关系为目的而交付和受领。因此，若某人为了赠与而把自己的钱给我，尽管这些钱原属于赠与人、后来成为我的财产，我仍不对他负债，因为我们之间并未约定成立债务关系。

<!-- source-p 436 -->
<a id="44.7.3.2"></a>**2**　以言词成立的债务也要求当事人有订立债务关系的意思。比如我只是开玩笑，或为了检验你是否理解而问“你承诺吗？”，你回答“我承诺”，并不会因此成立债务。

<!-- source-p 437 -->
<a id="44.7.4"></a>**44.7.4**

<!-- source-p 438 -->
盖尤斯《金言集》第三卷。

<!-- source-p 439 -->
因不法行为而产生的债务，例如因盗窃、损害、抢夺或侵害而产生的债务。这些都属于同一类型，因为它们仅以不法行为本身为基础。相反，契约债务则不只以物成立，也可以以言词或合意成立。

<!-- source-p 440 -->
<a id="44.7.5"></a>**44.7.5**

<!-- source-p 441 -->
盖尤斯《金言集》第三卷。

<!-- source-p 442 -->
<a id="44.7.5.pr."></a>**序言**　某人若受委任管理他人事务，显然当事人之间会因契约产生委任之诉；双方可以据此相互起诉，请求对方依诚信应当履行的给付。若其未经委任而管理事务，法学家仍认为双方互负义务，并因此创设了我们称为“无因管理之诉”的诉权；双方同样可以相互起诉，请求对方依诚信应当履行的给付。但这些诉权既非源于契约，也非源于不法行为：管理事务的人与不在场者此前并未被认为订立契约；未经委任而承担事务管理，也不构成不法行为。更不可能把不知情的事务本人视为订立了契约或实施了不法行为。不过，为了实际需要，法律承认双方互负义务。之所以如此，是因为人们往往怀着很快返回的想法出远门，因而不委托任何人照料自己的事务，后来却因新情况而不得不长期滞留。若这些人的事务因此败坏，并不公平；如果主动承接事务管理的人无法请求偿还其为事务有益支出的费用，或者事务本人无法依法起诉擅自介入其事务的人，事务就很可能败坏。

<!-- source-p 443 -->
<a id="44.7.5.1"></a>**1**　依监护诉讼承担责任的人，也不应被认为严格意义上是因契约负债，因为监护人与未成年人之间并无契约。但既然他们显然并非因不法行为负责，就被视为类似因契约而负责。在此情形下，双方也互有诉权：未成年人不仅可以起诉监护人，监护人也可以起诉未成年人，例如监护人为未成年人事务支出费用、为其承担债务，或以自己的财产为未成年人的债权人设质。

<!-- source-p 444 -->
<a id="44.7.5.2"></a>**2**　负有支付遗赠义务的继承人，也不被认为因契约或不法行为负债：受遗赠人既未与死者订立契约，也未与继承人订立契约；至于其中不涉及任何不法行为，更是显而易见。

<!-- source-p 445 -->
<a id="44.7.5.3"></a>**3**　某人因付款人的错误而受领并非其应得之物，固然会被视为类似因借贷给付而负债，并承担债务人对债权人所负的同一诉权；但不能认为他是因契约而负债，因为错误付款的人似乎更是怀着消灭债务关系、而非创设债务关系的意思给付。

<!-- source-p 446 -->
<a id="44.7.5.4"></a>**4**　法官若使案件成为自己的案件，并不被认为严格意义上是因不法行为负债；但他显然既非因契约负债，又必定做错了什么，即便只是出于轻率，因此被视为类似因不法行为而承担责任。

<!-- source-p 447 -->
<a id="44.7.5.5"></a>**5**　若有人从其居室中（无论是自有房屋、承租房屋，还是免费居住的房屋）抛出或倾倒物品并因此致人损害，该人被视为类似因不法行为承担责任。之所以不认为他严格意义上因不法行为负债，是因为他通常是为他人的过错负责，例如奴隶或自由人的过错。另有一种类似情形：有人把物品放置或悬挂在通常供公众通行的地方，若物品坠落可能伤人。因此，若家子与父亲分开居住，从其居室抛出、倾倒了物品，或放置、悬挂了有坠落危险的物品，尤利安认为，不应对父亲提起特有产诉讼或诺克萨诉讼，而应直接起诉家子本人。

<!-- source-p 448 -->
<a id="44.7.5.6"></a>**6**　同样，船舶、客店或马厩经营人，对其船舶、客店或马厩内发生的损害或盗窃，被视为类似因不法行为承担责任；前提是经营人本人并无不法行为，而是由其用来经营船舶、客店或马厩的人实施了不法行为。既然针对经营人的此项诉权并非基于契约设立，而经营人又在某种程度上因使用不良之人而有过错，所以他被视为类似因不法行为承担责任。

<a id="44.7.44.pr."></a>**序言**　债务大致有四类附加事项：期限、条件、选择给付和附加人或物。

<!-- source-p 577 -->
<a id="44.7.44.1"></a>**1**　对于期限，需要作两种区分：债务可以自某日起开始，或者规定在某个期限之前履行。例如，“你承诺在三月一日给付吗？”此类期限的性质是，在期限到来前不得请求履行。另一种是“你承诺在三月一日之前给付吗？”法学家认为，债务不能只在一段期间内成立，正如遗赠也不能如此；因为某项给付一旦开始成为债务，只能依确定方式消灭。当然，期限经过后，允诺人可以提出合意抗辩或恶意抗辩，以驳回要式口约受诺人的请求。同样，在交付土地时，即使有人说自己只交付土地而不交付地上建筑物，也不能阻止地上建筑物一并转移，因为按其自然属性，地上建筑物附属于土地。

<!-- source-p 578 -->

<a id="44.7.52"></a>**44.7.52**

<!-- source-p 605 -->
莫德斯汀《规则集》第二卷。

<!-- source-p 606 -->
<a id="44.7.52.pr."></a>**序言**　债务关系可以因物、言词、物与言词并用、合意、法律、裁判官法、必要情形或不法行为而产生。

<!-- source-p 607 -->
<a id="44.7.52.1"></a>**1**　物使我们负债，是因为有物本身介入。

<!-- source-p 608 -->
<a id="44.7.52.2"></a>**2**　言词使我们负债，是因为先有提问，随后作出与之相应的回答。

<!-- source-p 609 -->
<a id="44.7.52.3"></a>**3**　物与言词共同使我们负债，是指在当事人就某一事项达成合意时，既有实际给付之物介入，也有相应的言词问答。

<!-- source-p 610 -->
<a id="44.7.52.4"></a>**4**　我们显然是依自己的意思而因合意负债。

<!-- source-p 611 -->
<a id="44.7.52.5"></a>**5**　我们因法律负债，是指我们遵守法律时，实施了法律命令的行为，或实施了违反法律命令的行为。

<!-- source-p 612 -->
<a id="44.7.52.6"></a>**6**　我们依裁判官法负债，是指基于永久告示或长官命令实施了某种作为或不作为。

<!-- source-p 613 -->
<a id="44.7.52.7"></a>**7**　因必要情形而负债的人，是指只能实施被命令之事、不能采取其他做法的人；必然继承人即属此类。

<!-- source-p 614 -->
<a id="44.7.52.8"></a>**8**　我们因不法行为负债，是指争议的核心取决于行为事实。

<!-- source-p 615 -->
<a id="44.7.52.9"></a>**9**　即使债务本可通过言词表达，单纯合意也足以成立债务关系。

<!-- source-p 616 -->
<a id="44.7.52.10"></a>**10**　此外，许多法律关系仅凭点头表示同意即可成立。

<a id="44.7.61.pr."></a>**序言**　塞乌斯的代理人在银器商银行家（*argentarius vascularius*）处作出如下书面确认：〔希腊文转写〕*Loukios Kalandios epegnwn, kavws progegraptai: estin loipa par' hymin, ofeilomena tw deini, tosa*（卢基乌斯·卡兰狄乌斯确认，正如上文所写：我们这里尚有欠某人的余额，共计若干）；〔底本附拉丁文释义〕*L. <a id="44.7.61.1"></a>**1**　塞娅想要确定一笔年俸，于是发出如下书信：“卢基乌斯·提图斯，您好。若你对我的心意与感情仍如往常，请一收到我的信便变卖你的财产，来到我这里。在我有生之年，我每年给你十。因为我知道你非常爱我。”有人问：卢基乌斯·提图斯是否可以根据这封信请求年俸，因为他已经卖掉自己的财产、前往塞娅处，并从此与她共同生活？答：应由负责审理的人根据当事人的身份和案件原因，判断是否应给予诉权。
