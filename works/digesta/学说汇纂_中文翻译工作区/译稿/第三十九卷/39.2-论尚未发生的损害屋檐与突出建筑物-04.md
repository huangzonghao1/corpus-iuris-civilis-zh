乌尔比安《萨宾评注》第四十二卷。

<!-- source-p 368 -->
若共有墙不够坚固，就应当拆除；拆除者不应对因此造成的任何损害承担责任，除非其以过度奢侈或质量过差的新墙予以重建。若被拆除的墙原本适用，则应依尚未发生损害之诉，判给原告因该墙未能继续存在所遭受的损失。理由充分：既然本不应拆除，就应由拆除者自费重建。萨宾还认为，因拆除而失去的租金收入也应予以赔偿。若住户因此迁出，或无法像以前那样方便地居住，该损失可归责于施工者。

<!-- source-p 369 -->
<a id="39.2.38"></a>**39.2.38**

<!-- source-p 370 -->
保罗《萨宾评注》第十卷。

<!-- source-p 371 -->
<a id="39.2.38.pr."></a>**序言。**房屋买受人在取得交付占有之前订立要式允诺并无用处，因为出卖人应向其尽到一切注意。只有在出卖人并无任何过失时，例如出卖人以容许占有的方式允许买受人暂住该房屋，并在将要离开时把保管责任交给买受人，买受人此时订立要式允诺才有用。

<!-- source-p 372 -->
<a id="39.2.38.1"></a>**1.**若未就土地提供担保，应将申请人置于土地中存在危险的部分占有。其理由是，房屋中有瑕疵的部分会牵连其余部分；土地则并非如此。但应当说，对于较大的房屋，裁判官有时也须查明情况后决定：未获担保者应被置于哪一部分的占有中。

<!-- source-p 373 -->
<a id="39.2.38.2"></a>**2.**估价时应扣除旧墙的价值；若新墙的价值较高，只能就超出部分估价。若旧墙的任何材料被用于新墙，也应从估价中扣除。

<!-- source-p 374 -->
<a id="39.2.39"></a>**39.2.39**

<!-- source-p 375 -->
庞波尼乌斯《萨宾评注》第二十一卷。

<!-- source-p 376 -->
<a id="39.2.39.pr."></a>**序言。**共有墙的共有人，通常会就各自所有的房屋订立尚未发生损害的要式允诺。但只有在一方独自施工、瑕疵将由其工程造成，或者一方拥有价值较高的房屋、墙倒塌时将遭受更大损害的情况下，该担保才有必要。否则，若双方遭受的危险相同，一方向邻人承担多少责任，也能从邻人处取得相同数额。

<!-- source-p 377 -->
<a id="39.2.39.1"></a>**1.**若房屋的所有权存在争议，应当说尚未发生损害的担保义务由占有人承担，因为其已支付的费用可向土地所有人请求抵扣。若占有人不提供担保，应将占有转交给请求担保的原告；因为若强迫担保权利人离开其担心受损的土地、另行寻找所有人，显失公平。

<!-- source-p 378 -->
<a id="39.2.39.2"></a>**2.**尚未发生损害的要式允诺适用范围更广。因此，拥有地上建筑权的公寓楼权利人，若地上建筑物遭受损害，也可以使用该允诺；土地所有人同样可以使用该允诺。若土地受损，以致整个地上建筑物被拆除，土地所有人也可主张该允诺，因为他将无法收取租金。

<!-- source-p 379 -->
<a id="39.2.39.3"></a>**3.**可以以他人名义订立要式允诺，并将所有人所受损害纳入其中。但订立允诺的人应取得所有人对该事项予以追认的承诺，并应像遗赠要式允诺那样，在要式允诺中加入代理人抗辩。若未能获得该项承诺，则无论如何都应将代理人置于占有中，以免代理人受代理人抗辩所损害。

<!-- source-p 380 -->
<a id="39.2.39.4"></a>**4.**估价新墙时，应考虑对旧墙进行装饰所花费的合理费用；不得计入不致增加其价值的费用。

<!-- source-p 381 -->
<a id="39.2.40"></a>**39.2.40**

<!-- source-p 382 -->
乌尔比安《萨宾评注》第四十三卷。

<!-- source-p 383 -->
<a id="39.2.40.pr."></a>**序言。**依据尚未发生损害的要式允诺，不应作出无限或过度的估价，例如对墙面涂饰和绘画作此估价。虽然这些项目可能花费甚巨，但仍应对尚未发生损害的损失作适度估价，因为应遵守合理尺度，不应迁就任何人的奢侈浪费。

<!-- source-p 384 -->
<a id="39.2.40.1"></a>**1.**若因共有墙本身的瑕疵发生损害，共有人之间无须相互赔偿，因为损害源于共有物本身的瑕疵。但若一方对墙施加压力或增加荷载，因此造成损害，则应当说由此获益的一方必须赔偿损失。若墙因双方施加的荷载相同而倒塌，萨宾极为正确地写道，双方责任相同。但若一方损失了更多物品或价值更高的物品，更好的意见是：既然双方均对墙施加荷载，任何一方均不得对另一方提起诉讼。

<!-- source-p 385 -->
<a id="39.2.40.2"></a>**2.**若数人因同一房屋遭受损害而提起尚未发生损害之诉，每个人都不得请求全部赔偿，而只能就其份额起诉。因为损害虽由多人共同遭受，却不能认为每个人都遭受了全部损害，而是各自遭受其中一部分。因此，尤利安写道，每个人仅能就其份额提起诉讼。

<!-- source-p 386 -->
<a id="39.2.40.3"></a>**3.**同样，若危险房屋有数名所有人，原告是可以对每名所有人请求全额赔偿，还是只能请求其份额？尤利安写道，各所有人应按其所有份额承担责任，萨宾也赞同此说。

<!-- source-p 387 -->
<a id="39.2.40.4"></a>**4.**若有数名危险房屋的所有人，均希望就尚未发生的损害获得保障，但无人提供担保，则应将他们全部置于占有中，而且应当平等分配占有份额，即使各自所有权份额不同；庞波尼乌斯如此写道。

<a id="39.2.43"></a>**39.2.43**

<!-- source-p 395 -->
阿尔费努斯《学说汇纂》第二卷。

<!-- source-p 396 -->
<a id="39.2.43.pr."></a>**序言。**有人向邻人作出关于尚未发生损害的本人名义允诺。他的建筑物上的瓦片被风吹落，砸在邻人的瓦片上并将其打碎。问题是应否承担赔偿责任。他答复说：如果是建筑物的瑕疵及不坚固所造成，就应赔偿；但如果风力极强，即使坚固建筑也会被掀翻，则不应赔偿。允诺中所说的“若其中有任何物件倒塌”，在他看来，不包括因风力或其他外部力量而倒下的物件，而是指物件自身倒塌。

<!-- source-p 397 -->
<a id="39.2.43.1"></a>**1.**某人想与邻人共同建造共有墙，在拆除旧墙之前，向邻人作出尚未发生损害的本人名义允诺，并且邻人也向他作出反向允诺。墙拆除后，邻近楼层的住户迁出，邻人想向他请求住户未能支付的租金。问题是，这一请求是否正当。他答复说，双方共同建墙时，本不应相互作出本人名义允诺，任何一方也不得以任何方式强迫另一方允诺；即使双方确已作出允诺，责任也不应超过各自二分之一，任何人为建造共有墙，均不应向非共有墙的第三人作出超过该份额的允诺。但既然双方已就全部损失作出允诺，邻人因租金损失而遭受的一切损害都应得到赔偿。

<!-- source-p 398 -->
<a id="39.2.43.2"></a>**2.**他还询问：允诺人能否取回因该事项而支付的钱款？因为邻人向他作出了反向允诺，承诺赔偿因该工程使其遭受的任何损害；而他所支付的这笔钱也正是因该工程而损失的。他答复说不能，因为他损失该款并非由于工程瑕疵，而是由于其允诺。

<!-- source-p 399 -->
<a id="39.2.44"></a>**39.2.44**

<!-- source-p 400 -->
阿非利卡努斯《疑问集》第九卷。

<!-- source-p 401 -->
<a id="39.2.44.pr."></a>**序言。**我曾请求你就尚未发生的损害向我作出允诺，你拒绝了；在我请求裁判官之前，你的房屋倒塌并使我受损。他说，更妥当的做法是不应要求裁判官另作裁定；损害是由于我的过失而发生，因为我开始诉讼太迟。但若裁判官已经命令你作出允诺，而你拒绝允诺，裁判官便命令我进入占有；在我尚未到达该处之前，房屋就倒塌了，他认为应当适用所有与我已经进入占有后才发生损害时相同的规则。

<!-- source-p 402 -->
<a id="39.2.44.1"></a>**1.**某人以尚未发生损害为由被置于占有中，并通过占有取得所有权；此后，债权人想追索已为其设定质权的房屋。可以合理地说，除非债权人准备向我偿还我为修缮房屋所支出的费用，否则应禁止其对我追索。为何不也将这一规则适用于买受人，例如某人买下设有质权的公寓楼？两种情形不可不当地相提并论，因为买受人是自愿从事该交易，因此既能够、也应当要求出卖人为其提供更充分的保障；这对未获尚未发生损害允诺的人而言则并非如此。

涅拉提乌斯《札记》第六卷。

<!-- source-p 412 -->
若同一所有人将一处房屋中的一间房改作另一处房屋使用，则不仅在支撑该房间的楼梁从其所服务的房屋部分延伸出来时，该房间属于那处房屋；即使横向楼梁全部搁置在另一处房屋的墙上，也同样属于该房屋。拉贝奥在《后札记》中也写道：一人拥有两处房屋，在两处房屋上方架设门廊，并从其中一处房屋设置通道；随后，他出售另一处房屋，并为维持门廊而在该房屋上设定役权。整个门廊属于他保留的那处房屋，因为门廊沿两座房屋的长度延伸，其横梁由被出售房屋两侧的墙壁支撑。但这并不意味着，建筑物上方未与任何建筑相连、也没有其他通道的部分，就属于其下方建筑的所有人以外的其他人。
