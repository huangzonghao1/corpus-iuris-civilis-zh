# D.39.2 论尚未发生的损害、屋檐与突出建筑物（*De damno infecto et de suggrundis et proiectionibus*，第二段）

> **底本范围：**EPUB 全部 `<p>` 元素的连续编号 source-p 241–310；保留题名、出处、分题、段落及锚点。

<!-- source-p 241 -->
<a id="39.2.15.13"></a>**13.**但是，如果房屋分成数个部分，应将申请人置于其中一部分还是整座房屋的占有中？若房屋十分宽敞，瑕疵部分与无瑕疵部分之间有空间相隔，应当仅将其置于该部分的占有中；若各建筑相连成一体，则应将其置于整座房屋的占有中。因此，即便房屋宽阔，也宜认为应将其置于与有瑕疵部分相连的房屋部分占有。否则，如果极大房屋的一小部分有瑕疵，怎能说应命令未获尚未发生损害担保者占有整座房屋呢？

<!-- source-p 242 -->
<a id="39.2.15.14"></a>**14.**同样，如果毗邻住宅的公寓楼造成瑕疵，我们应将申请人置于该公寓楼的占有中，还是整座住宅的占有中？更妥当的做法是，不将其置于住宅的占有中，而置于公寓楼的占有中。

<!-- source-p 243 -->
<a id="39.2.15.15"></a>**15.**若有数人请求对其提供担保，通常将他们全都置于占有中。拉贝奥也认可这一点；即使一人先被置于占有中，另一人随后也请求如此处理，结论亦同：我们不看先后次序，而是让两人都取得占有。但如果先前那人已被命令取得占有，另有人请求就尚未发生的损害提供担保，那么在未提供担保时，后来者将被置于占有中。

<!-- source-p 244 -->
<a id="39.2.15.16"></a>**16.**尤利安写道，以尚未发生的损害为由被置于占有中的人，只有在裁判官以第二道裁令确立其为所有人之后，才开始通过长期时效取得所有权。

<!-- source-p 245 -->
<a id="39.2.15.17"></a>**17.**若在该裁令作出之前，另有一人也被置于占有中，那么在两人均被命令取得占有时，他们平等地成为房屋所有人。但若裁判官已确立先被置于占有中的人为所有人，此后提图斯请求就尚未发生的损害向其提供担保，而先前之人未提供担保，则只有提图斯处于占有中。

<!-- source-p 246 -->
<a id="39.2.15.18"></a>**18.**数人被置于占有中时，应平等置于占有中，而非按照各自可能遭受的损害比例分配；这是合理的。因为即便只有一人被置于占有中，也不是按照损害比例，而是就全部损害置于占有中。因此，数人被置于占有中时，他们相遇后应平等分有各自份额，如同每个人都是就全部损害被置于占有中一样。

<!-- source-p 247 -->
<a id="39.2.15.19"></a>**19.**若其中一名被置于占有中的人支出了费用，随后又被命令取得占有，他能否请求返还费用？应通过何种诉讼？通说认为，他可以通过共有物分割之诉请求返还。

<!-- source-p 248 -->
<a id="39.2.15.20"></a>**20.**若某人已被置于占有中，但尚未被命令取得占有，我们应考察所有人是否应当丧失占有。拉贝奥说不应如此，正如债权人或受遗赠人被置于占有中时所有人也不因此丧失占有；这一意见更为正确。

<!-- source-p 249 -->
<a id="39.2.15.21"></a>**21.**裁判官并非一将某人置于占有中，就立即命令其取得占有；只有在认为存在正当理由时才会这样命令（因此两者之间应有一定间隔）。例如，所有人长期不发一言，以致房屋被视为已被抛弃；或者某人被置于占有中并停留一段时间后，仍无人提供担保。

<!-- source-p 250 -->
<a id="39.2.15.22"></a>**22.**若所有人因公事或其他正当理由离开，或者属于通常应受救济的年龄，应当认可裁判官不应仓促作出命令、命人取得占有的裁令。即便裁判官已经作出该裁令，也无人怀疑他会准予恢复原状。

<!-- source-p 251 -->
<a id="39.2.15.23"></a>**23.**某人一旦被命令取得占有，所有人就应被剥夺该占有。

<!-- source-p 252 -->
<a id="39.2.15.24"></a>**24.**若有任何债权属于本可就尚未发生损害提供担保之人，则不得允许其对已被置于占有中的人行使该等权利；拉贝奥认可这一意见。

<!-- source-p 253 -->
<a id="39.2.15.25"></a>**25.**同样，关于质权债权人，问题在于：对已被命令取得占有的人，是否应拒绝其行使质权追索权？更妥当的意见是，若债务人既未作承诺，债权人也未提供要式担保，则应拒绝质权追索权。塞尔苏斯正确地指出，用益权人亦同。

<!-- source-p 254 -->
<a id="39.2.15.26"></a>**26.**若在负担公地租税的房屋上未提供担保，应当说可以将申请人置于占有中，但不得命其取得占有（因为他不能通过占有取得所有权）；而应作出裁令，使其处于与未提供担保者相同的法律地位。作出该裁令后，他可以提起公地租税之诉。

<!-- source-p 255 -->
<a id="39.2.15.27"></a>**27.**但在负担公地租税的土地上，若市镇居民未提供担保，应当说可以通过长期时效取得所有权。

<!-- source-p 256 -->
<a id="39.2.15.28"></a>**28.**一个颇有意味的问题是：裁判官正在考虑是否准予作出要式允诺时，若损害已经发生，能否予以补偿？此时固然应停止将申请人置于占有中的措施；但裁判官仍应作出裁令，要求就已经发生的任何损害提供担保；或者，如果他认为适宜准予诉权，也可以作出相应裁令。

<!-- source-p 257 -->
<a id="39.2.15.29"></a>**29.**若未成年人没有监护人，不能在监护人授权下就尚未发生的损害作出允诺，则应视为无人为其提供保障，因而可以将申请人置于占有中。

<!-- source-p 258 -->
<a id="39.2.15.30"></a>**30.**有人认为，以尚未发生的损害为由被置于占有中的人应当支撑并修缮公寓楼，且应像质权受领人那样对过失负责。但我们采用不同规则：他被置于占有中，只是为了替代担保而保有占有；因此，即使他没有修缮，也不应归责于他。

<!-- source-p 259 -->
<a id="39.2.15.31"></a>**31.**同样，我们应考察：某人被置于占有中后，若对方才提出提供担保，他是否只有在该担保也涵盖其被置于占有中以后发生的损害时，才应退出占有？这一意见更为可取。因此，允诺时应将担保期限追溯至先前日期。此外，他若曾支出费用，也应就该费用获得担保。

<!-- source-p 260 -->
<a id="39.2.15.32"></a>**32.**问题还在于，应从何时起计算损害：从进入占有之时起，还是从裁判官作出准许进入占有的裁令时起？拉贝奥主张从裁令作出时起；萨宾主张从实际进入占有时起。我认为，应查明具体情形，再认可其中一种意见。通常，即使某人因某种原因未进入占有，或迟延进入占有，也会给予救济。

<!-- source-p 261 -->
<a id="39.2.15.33"></a>**33.**裁判官一旦依据所有权法理命令某人取得占有，就不再允许提出提供担保；拉贝奥也持此见。否则，正如他说的，这件事将永无止境。撇开因年龄或其他正当理由应受救济的人不论，这一意见确实完全正确。

<!-- source-p 262 -->
<a id="39.2.15.34"></a>**34.**若房屋已经倒塌，我们应考察未获担保者是否仍应被置于废墟或房屋基地的占有中。更妥当的意见是应当如此，拉贝奥也这样认为；但他补充说，须是裁判官作出准许其进入占有的裁令之后，房屋才倒塌。我认为拉贝奥的意见正确。因此，即使该人已经修缮了某些部分，也应认定：除非其费用得到偿还，且过去的损害已获担保，他不得退出占有。他还可以通过事实诉权取回所支出的费用，但不得超过善良人的判断所认可的数额。若另一人经我的指示或请求，在无恶意的情况下做了上述事情，而我因此被判承担责任或已无恶意地给付，亦同。

<!-- source-p 263 -->
<a id="39.2.15.35"></a>**35.**若某人因害怕房屋倒塌而退出占有，拉贝奥写道：如果他是因为无力挽救房屋才这样做，其权利仍完整保留，犹如他一直留在占有中；但如果他本可采取措施，却宁愿离开，则已丧失裁判官给予的利益，后来再请求援助，也不应听从。卡西乌斯则说，若他因害怕房屋倒塌而离开，但并无抛弃建筑物的意思，应恢复其占有；不过，已被置于占有中却未曾前往的人，若房屋倒塌，就丧失裁判官给予的利益。应这样理解：这是指他怠于前往占有，而非在其前往途中房屋倒塌。

<!-- source-p 264 -->
<a id="39.2.15.36"></a>**36.**依据本告示被裁判官置于占有中的人若未获准进入，可以行使事实诉权，请求赔偿如同就该事项已经提供担保时本应获得的数额。该诉权的期间延伸至损害发生之时。

<!-- source-p 270 -->
<a id="39.2.17.pr."></a>**序言。**若某人受他人权力支配，且未准许被置于占有中的人进入，多数法学家认为，就此可以提起针对家父的替代责任诉讼。

<!-- source-p 271 -->
<a id="39.2.17.1"></a>**1.**那么，如果是代理人禁止其进入，我们应当对代理人本人还是对委托人提起诉讼？更正确的意见是，应对代理人本人提起。

<!-- source-p 272 -->
<a id="39.2.17.2"></a>**2.**对于市镇的代理人、监护人以及其他代表他人行事的人，也应作同样处理。

<!-- source-p 273 -->
<a id="39.2.17.3"></a>**3.**这一事实诉权是永久诉权；既可以由继承人提起，也可以对继承人提起，并同样适用于其他相关主体。

<!-- source-p 274 -->
<a id="39.2.17.4"></a>**4.**审理尚未发生损害案件的法官，即使被诉人在诉讼期间转让了土地，通常仍会评估此前已经发生的一切损害。

<a id="39.2.18"></a>**39.2.18**

<!-- source-p 276 -->
保罗《告示评注》第四十八卷。

<!-- source-p 277 -->
<a id="39.2.18.pr."></a>**序言。**尚未发生损害的要式允诺，不仅适用于财产属于其所有的人，也适用于对财产承担风险的人。

<!-- source-p 278 -->
<a id="39.2.18.1"></a>**1.**庞波尼乌斯说，允诺人因工程施工而通过取得时效获得所有权的，不因此承担责任，因为其取得所有权并非源于土地或工程的瑕疵，而是基于公法。

<!-- source-p 279 -->
<a id="39.2.18.2"></a>**2.**房屋用益权人无需就该房屋的瑕疵提供担保，即使他另有毗邻房屋亦然，因为他有权修缮房屋。既然他应依善良人的判断行使用益权，也就取得修缮的权能。因此，所有权人若要求用益权人为其毗邻用益权人的房屋提供担保，也不应予以支持；因为所有权人可对用益权人提起诉讼，要求其依善良人的判断行使用益权。

<!-- source-p 280 -->
<a id="39.2.18.3"></a>**3.**若我的承租人有毗邻房屋，我应就该等房屋向其提供尚未发生损害的担保。

<!-- source-p 281 -->
<a id="39.2.18.4"></a>**4.**若某人在租赁土地上建有地上建筑，土地所有人无需就土地瑕疵可能造成的损害向地上建筑权利人提供担保；地上建筑权利人也无需向土地所有人提供担保，因为双方彼此享有租赁之诉。不过，这些诉讼所涉及的责任仅限于过失。尚未发生损害的要式允诺所涵盖的范围则更广，其中所说的瑕疵被视为归属于允诺人。

<!-- source-p 282 -->
<a id="39.2.18.5"></a>**5.**若某人拥有一处房屋并已订立要式允诺，之后又购入毗邻房屋，问题是：允诺人是否也对其在要式允诺订立后购入的房屋承担责任？尤利安写道，应考察担保是否仅限于其与允诺人最初约定的房屋。由此也可认为，若两名共有人就共有房屋的名义订立要式允诺，担保似乎也仅限于各共有人在房屋份额中遭受的损害。因此，无论其中一人后来买下另一份额，还是经裁判分得该份额，允诺的责任均不扩大。庞波尼乌斯转述尤利安的意见后说，他并不反对。

<!-- source-p 283 -->
<a id="39.2.18.6"></a>**6.**但若要式允诺订立后，允诺权利人在房屋内开始存放物品，而这些物品因毗邻房屋倒塌而毁损，他可以依据要式允诺提起诉讼，尽管订立允诺时这些物品尚不在房屋内。

<!-- source-p 284 -->
<a id="39.2.18.7"></a>**7.**土地买受人若在交付前订立要式允诺，即已就交付后发生的损害获得担保。

<!-- source-p 285 -->
<a id="39.2.18.8"></a>**8.**房屋出卖人应在交付占有之前订立要式允诺，因为他也须就此承担过失责任。

<!-- source-p 286 -->
<a id="39.2.18.9"></a>**9.**但如果出卖人并无过失却未能订立要式允诺，而买受人因此自行订立，结果会如何？难道买受人不会遭受损害吗？这是否属于发生在他人财产上的损害，而又转由买受人承担，因为他没有买卖之诉？然而，在这种情形下，要式允诺并无助益，除非针对交付后发生的损害；因为在出卖人负保管责任期间，应由出卖人订立要式允诺并向买受人尽到一切注意。凡可通过其他诉讼请求的损害，绝不纳入尚未发生损害的要式允诺。

<!-- source-p 287 -->
<a id="39.2.18.10"></a>**10.**但若出卖人已经订立要式允诺，该允诺也涵盖交付后买受人遭受的损害。阿里斯托认为这极不公平，因为如果买受人也就尚未发生的损害订立了要式允诺，允诺人便会就同一事项对两人承担责任。除非应当认为这种情形对出卖人不利，因为要式允诺以该物的价值为限；因此可以认为出卖人已不再具有利害关系。

<!-- source-p 288 -->
<a id="39.2.18.11"></a>**11.**订立尚未发生损害的要式允诺后，萨宾认为：若在允诺期限内施工时，房屋倒塌到我的墙上并使其受损，即使墙是在允诺期限届满后才倒塌，我仍可提起诉讼，因为墙在变成有瑕疵时，我就已经遭受损害。即使墙尚未倒塌，也不妨碍我提起诉讼；如果墙受到剧烈震动，以致无论如何都无法修复，因而必须拆除，其诉讼标的的估价不应低于墙已经倒塌时的估价。

<!-- source-p 289 -->
<a id="39.2.18.12"></a>**12.**若我们拥有毗邻房屋，且彼此请求就尚未发生的损害提供担保，我被置于你的房屋占有中、你被置于我的房屋占有中，均不受妨碍。

<!-- source-p 290 -->
<a id="39.2.18.13"></a>**13.**若未成年人禁止他人进入以取得尚未发生损害的占有，通说认为可以正当地对其提起这一事实诉权。

<!-- source-p 291 -->
<a id="39.2.18.14"></a>**14.**若他人受我委托而禁止进入，则该诉权适用于我。

<!-- source-p 292 -->
<a id="39.2.18.15"></a>**15.**裁判官不仅处罚阻止他人进入占有的人，也处罚不容许他人取得占有的人。否则，若某人依裁判官命令开始取得占有并可通过占有取得所有权，却未获准进入或被逐出，他本可提起有用的《因暴力夺占禁令》或《普布利基安对物之诉》。但若他已提起事实诉权，就不能再行使这些诉权；因为裁判官旨在避免原告遭受损害，而非使其获利。

<!-- source-p 293 -->
<a id="39.2.18.16"></a>**16.**若我的代理人订立了尚未发生损害的要式允诺，经查明情况后，我可以依据该允诺提起诉讼。

若家子是承租人，我们应考察是否应以尚未发生的损害为由，将其置于毗邻房屋的占有中（问题在于：若财产属于其特有财产，家子是否就不被认为会遭受损害），以及父亲能否就可能遭受的损害订立要式允诺。通说认为，两人均可被置于占有中；但若家子租赁时约定房屋风险由其承担，则应仅将家子置于占有中，因为只有他依租赁之诉承担责任。

<a id="39.2.22"></a>**39.2.22**

<!-- source-p 305 -->
保罗《普劳提乌斯评注》第十卷。

<!-- source-p 306 -->
<a id="39.2.22.pr."></a>**序言。**若所有权人曾就尚未发生的损害作出允诺或实际给付，或者用益权人曾作出相应给付，则让另一方毫无损失地使用房屋或占有房屋，显失公平。若所有权人已经提出给付，就不应允许用益权人继续使用，除非其也作出分担；反过来，也应要求所有权人向用益权人分担。因此，即使房屋倒塌，用益权人仍可保有土地，直至其损害得到给付。这样，用益权人便处于与已获准进入占有并补偿邻人损害者相同的地位。即使损害极小，也适用同一规则。普劳提乌斯。

<!-- source-p 307 -->
<a id="39.2.22.1"></a>**1.**普劳提乌斯说：若我主张某人并非所有人，却想要求其在“如果他不是所有人”的条件下提供要式担保；同时又想要求我主张为所有人的另一人无条件作出允诺，通说认为我不能如此请求，而应当选择由谁向我提供担保。
