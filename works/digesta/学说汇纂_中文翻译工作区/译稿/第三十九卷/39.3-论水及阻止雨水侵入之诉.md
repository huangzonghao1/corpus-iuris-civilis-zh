<a id="39.3"></a>**39.3.0 论水及阻止雨水侵入之诉**（*De aqua et aquae pluviae arcendae*）。

<!-- source-p 417 -->
<a id="39.3.1"></a>**39.3.1**

<!-- source-p 418 -->
乌尔比安《告示评注》第五十三卷。

<!-- source-p 419 -->
<a id="39.3.1.pr."></a>**序言。**若雨水将给某人造成损害，可以通过阻止雨水侵入之诉使水改道。所谓雨水，是从天而降、因降雨而增多的水；无论如图贝罗所说，是这种天降之水本身造成损害，还是它与其他水混合后造成损害，均属此列。

<!-- source-p 420 -->
<a id="39.3.1.1"></a>**1.**本诉适用于损害尚未发生、但工程已经完成的情形，也就是针对可能造成损害的工程；凡人为实施工程会使水危害土地的，均可提起本诉。换言之，若某人以人为方式改变水流，使其不再按自然状态流动，例如把水引入某处，或使水量增多、流速加快、势头增强，或者因阻塞而使水溢出，均属此种情形。若水是因自然原因造成损害，则不在本诉范围内。

<!-- source-p 421 -->
<a id="39.3.1.2"></a>**2.**涅拉提乌斯写道：有人修筑工程，意在阻挡沼泽水泛滥时通常回流至其土地的水；若雨水使沼泽水量增加，而该工程又把水挡回，以致邻人的土地受害，则可通过阻止雨水侵入之诉强令其拆除工程。

<!-- source-p 422 -->
<a id="39.3.1.3"></a>**3.**昆图斯·穆基乌斯认为，为耕种土地而用犁实施的工程，不适用本诉。特雷巴提乌斯则只将为取得谷物而用犁进行的土地作业排除在本诉之外，并非将一切耕地作业都排除。

<!-- source-p 423 -->
<a id="39.3.1.4"></a>**4.**穆基乌斯还说，为使土地干燥而开挖的沟渠，是为耕种土地而设；但不得为了汇集水流而开沟。其理由是：任何人均应改善自己的土地，却不得使邻人的土地恶化。

<!-- source-p 424 -->
<a id="39.3.1.5"></a>**5.**若某人即使不挖灌溉沟也能耕种和播种，那么即使他所做之事表面上是为了耕地，只要因此造成有关后果，仍须承担责任；但若不挖灌溉沟便无法播种，则不承担责任。奥菲利乌斯说，为耕种土地而开挖、并朝同一方向延伸的沟，可以合法修筑。

<!-- source-p 425 -->
<a id="39.3.1.6"></a>**6.**塞尔维乌斯的学说门人曾记载：某人种植柳树，因而使水积滞；若该水损害邻人，可以提起阻止雨水侵入之诉。

<!-- source-p 426 -->
<a id="39.3.1.7"></a>**7.**拉贝奥还写道，凡为收取谷物或其他果实而实施的工程，均不属于本诉范围；至于该工程究竟是为收取哪一种果实而实施，并不重要。

<!-- source-p 427 -->
<a id="39.3.1.8"></a>**8.**萨宾努斯和卡西乌斯也说，人工实施的工程原则上属于本诉范围，但为耕种土地而实施的工程除外：

<!-- source-p 428 -->
<a id="39.3.1.9"></a>**9.**不过，若有人开挖称为 *helikes* 的灌溉沟，他说，此人须承担阻止雨水侵入之诉的责任。

<!-- source-p 429 -->
<a id="39.3.1.10"></a>**10.**他们还说，水若自然流淌，阻止雨水侵入之诉即不适用；但若因工程而将水向上游回挡，或引向下游，则可以提起阻止雨水侵入之诉。

<!-- source-p 430 -->
<a id="39.3.1.11"></a>**11.**他们还说，任何人都有权把雨水留在自己的土地上，或者把从邻地漫溢到自己土地上的水引入自己的土地，只要没有在他人土地上施工即可；因为任何人均不被禁止在不损害他人的前提下使自己受益。任何人也不因此承担责任。

<!-- source-p 431 -->
<a id="39.3.1.12"></a>**12.**最后，马尔凯鲁斯写道，若某人在自己的土地上挖掘，因而截断邻人的泉水，不能对其提起任何诉讼，也不能提起欺诈之诉。确实，若其目的不是损害邻人，而是改善自己的土地，就不应使其承担责任。

<!-- source-p 432 -->
<a id="39.3.1.13"></a>**13.**还应知道，上游土地所有人可以对下游土地所有人提起本诉，以阻止其通过施工妨碍自然流经其土地的水继续流下；下游土地所有人也可以对上游土地所有人提起本诉，以阻止其以不同于自然流向的方式放水。

<!-- source-p 433 -->
<a id="39.3.1.14"></a>**14.**还应补充一点：若损害源于土地本身的自然状况，绝不适用本诉。因为更准确地说，造成损害的不是水，而是土地的自然状况。

<!-- source-p 434 -->
<a id="39.3.1.15"></a>**15.**总之，我认为，只有雨水或因降雨而增多的水并非自然地、而是因人为工程造成损害时，才适用阻止雨水侵入之诉；但为耕种土地而实施的工程除外：

<!-- source-p 435 -->
<a id="39.3.1.16"></a>**16.**所谓水因降雨而增多，是指水的颜色发生变化，或者水量增加。

<!-- source-p 436 -->
<a id="39.3.1.17"></a>**17.**还应知道，只有雨水损害土地时，才适用本诉；若损害的是建筑物或城镇，则本诉不适用，但可以提起诉讼，请求确认对方无权将屋檐滴水或水流排入该处。因此，拉贝奥和卡斯凯利乌斯说，阻止雨水侵入之诉是特别诉权，而关于水流和屋檐滴水的诉讼则是一般诉讼，可在任何地点提起。所以，损害土地的水应通过阻止雨水侵入之诉加以制止。

<!-- source-p 437 -->
<a id="39.3.1.18"></a>**18.**我们也不必追问水从何处发源。拉贝奥说，即使水源于公共场所，或从神圣场所经邻人的土地流下，而邻人又因施工把水改道流入我的土地，他也须承担阻止雨水侵入之诉的责任。

<!-- source-p 438 -->
<a id="39.3.1.19"></a>**19.**卡西乌斯也写道，若水从城内建筑物流出，损害田地或乡间建筑物，应提起关于水流和屋檐滴水的诉讼。

<!-- source-p 439 -->
<a id="39.3.1.20"></a>**20.**我在拉贝奥的著述中读到：若水从我的田地流出，损害城镇连续建成区内的地点，即建筑物，我不因阻止雨水侵入之诉而被起诉；反之，若水从连续建成区流出，流入并损害我的田地，则可以提起阻止雨水侵入之诉。

<!-- source-p 440 -->
<a id="39.3.1.21"></a>**21.**人为工程使雨水损害我，属于本诉范围；与此相反的问题是：若邻人施工，阻止原本流经其土地、并会使我的土地受益的水流入我的土地，我能否提起阻止雨水侵入之诉？奥菲利乌斯和拉贝奥认为不能，即使水流入我的土地对我有利亦然；因为本诉只在雨水造成损害时适用，而不在雨水未能带来利益时适用。

<!-- source-p 441 -->
<a id="39.3.1.22"></a>**22.**若邻人拆除了工程，水因而按自然流向流入下游土地并造成损害，拉贝奥认为不能提起阻止雨水侵入之诉；因为下游土地一向负有接受自然流下之水的地役义务。不过，若拆除工程导致水势更猛或水流汇集，拉贝奥也承认可以提起阻止雨水侵入之诉。

<!-- source-p 442 -->
<a id="39.3.1.23"></a>**23.**他还说，基于各土地的条件，有些土地适用特别规则。例如，若某些土地有大河流经，可以允许我在你的土地上修筑堤坝或沟渠。但若没有针对该土地制定此类规则，就应遵守土地的自然状况：下游土地一向受上游土地役使，自然承受上游流下之水所造成的不利，并应以其他利益加以补偿。正如土壤的肥力全都流向下游，下游也会承受水流带来的不利。若找不到针对该土地的规则，则长久习惯可代替法律。设定地役权时也遵循同一原则：若未发现地役权曾被设定，而某人长期以和平、非请求许可且不秘密的方式行使该地役权，则可视为其因长期习惯而取得如同依法设定的地役权。因此，我们不会强迫邻人修筑堤坝，而会在其土地上由自己修筑；这便形成一种准地役权，对此可以提起有用诉讼或申请禁令。

<!-- source-p 445 -->
<a id="39.3.2.pr."></a>**序言。**总之，下游土地受上游土地役使有三种依据：法律、土地的自然状况和长久习惯；为减少诉讼，长久习惯始终被视同法律。

<!-- source-p 446 -->
<a id="39.3.2.1"></a>**1.**拉贝奥举例说，有一条古老沟渠是为使土地干燥而挖掘的，但已无人记得它何时开挖；下游邻人不清理沟渠，因积水而使水损害我们的土地。拉贝奥说，可以对下游邻人提起阻止雨水侵入之诉，要求其清理沟渠，或容许你将沟渠恢复原状。

<!-- source-p 447 -->
<a id="39.3.2.2"></a>**2.**此外，若沟渠位于边界，而邻人不容许你清理属于你这一侧的沟渠部分，拉贝奥说，你可以提起阻止雨水侵入之诉。

<!-- source-p 448 -->
<a id="39.3.2.3"></a>**3.**卡西乌斯写道，若某项引水工程是经公共权力机关批准而建造的，该工程不属于阻止雨水侵入之诉的范围；其情形与年代久远、无人记得何时建成的工程相同。

<!-- source-p 449 -->
<a id="39.3.2.4"></a>**4.**但据记载，阿泰乌斯认为，若水经某沟渠流向下游土地，无论是否还记得该沟渠何时开挖，都应强令邻人清理沟渠。我也认为这一意见应当采纳。

<!-- source-p 450 -->
<a id="39.3.2.5"></a>**5.**瓦鲁斯还说：邻人土地上的堤坝被水势冲毁，结果雨水损害了我的土地。瓦鲁斯认为，若堤坝原本是自然形成的，我不能通过阻止雨水侵入之诉强令邻人重筑或容许重筑；即使堤坝是人工修筑但年代久远、无人记得，也同样如此。若记得该堤坝是人工修筑的，他认为邻人须承担阻止雨水侵入之诉的责任。拉贝奥则认为，即使人工堤坝年代久远、无人记得，也可以起诉要求重筑；因为本诉不能强迫任何人使邻人受益，只能阻止其造成损害，或阻止其妨碍对方依法行事。不过，即使不能提起阻止雨水侵入之诉，我仍认为，若我想在邻人土地上恢复一座对我有利、而对邻人并无损害的堤坝，可以对邻人提起有用诉讼或申请禁令。即使严格法律救济不可用，公平原则也要求如此。

<!-- source-p 451 -->
<a id="39.3.2.6"></a>**6.**据纳穆萨记载，若流动的水因粪秽阻塞了水道，积水因而损害上游土地，可以起诉下游土地所有人，要求其容许清理水道；因为本诉不仅适用于人为修筑的工程，也适用于一切非出于人的意愿而形成的情形。拉贝奥反对纳穆萨的意见：他认为土地本身的自然状况可能发生变化；因此，土地的自然状况自行改变时，每个人都应平静承受，无论其土地状况变好还是变坏。故若地震或暴风雨改变了土地状况，也不能强令任何人容许将土地恢复原状。不过，我们也在这种情形下承认可以依公平原则处理。

<!-- source-p 452 -->
<a id="39.3.2.7"></a>**7.**拉贝奥还说，若水流汇集在你的土地上冲出一处沟壑，邻人不能对你提起阻止雨水侵入之诉；但若你开挖的沟渠依法应当开挖，或年代久远、无人记得，则邻人可以起诉要求你修复沟渠。

<!-- source-p 453 -->
<a id="39.3.2.8"></a>**8.**拉贝奥还说，判断人工工程是否年代久远、仍有人记得时，无须精确查明工程修筑的日期和当时的执政官姓名；只要有人知道工程曾经修筑，也就是其修筑一事毫无疑问，即已足够。并非一定要还有亲历者在世；即使有人听说过那些记得此事的人所作的陈述，也足以证明。

<!-- source-p 454 -->
<a id="39.3.2.9"></a>**9.**拉贝奥还说，若邻人为了阻止水流向自己而改道引走急流，结果使你受损，不能对其提起阻止雨水侵入之诉；因为“排除水”就是设法不让水流入。不过，若邻人这样做并非意在损害你，而只是为了不使自己受损，这一意见更为妥当。

<!-- source-p 455 -->
<a id="39.3.2.10"></a>**10.**我还认为奥菲利乌斯所写的意见是正确的：若你的土地负有为邻地接纳水流的地役义务，阻止雨水侵入之诉即不适用，但以损害没有超过限度为前提。由此可推知，拉贝奥认为，若某人已让邻人取得向其土地引水的权利，就不能再对邻人提起阻止雨水侵入之诉。

<a id="39.3.3.pr."></a>**序言。**据特雷巴提乌斯记载，某人的土地上有泉水涌出，他在泉边开设洗呢作坊，并开始把作坊用水排入邻人的土地；特雷巴提乌斯说，此人不承担阻止雨水侵入之诉的责任。不过，若有人汇集水流，或排入污水，多数法学家认为可以制止。

<!-- source-p 459 -->
<a id="39.3.3.1"></a>**1.**特雷巴提乌斯还认为，若流动的热水损害某人，该人可以对邻人提起阻止雨水侵入之诉；这并不正确，因为热水并非雨水。

<!-- source-p 460 -->
<a id="39.3.3.2"></a>**2.**邻人原先每年在固定季节灌溉旱地，后来在该处修建草地，并开始持续灌溉，以致损害邻人。奥菲利乌斯说，除非此人平整土地、因而使水更快流向邻地，否则不能对其提起未发生损害之诉，也不能提起阻止雨水侵入之诉。

<!-- source-p 461 -->
<a id="39.3.3.3"></a>**3.**公认只有在自己的土地上实施工程的人才承担阻止雨水侵入之诉的责任，我们也遵循这一规则。因此，若有人在公共土地上施工，本诉不适用；未通过未发生损害担保保护自己的人，应自行承担后果。不过，若工程是在私人土地上实施，而公共土地介于其间，拉贝奥说，可以就全部情形提起阻止雨水侵入之诉。

<!-- source-p 462 -->
<a id="39.3.3.4"></a>**4.**用益权人既不承担阻止雨水侵入之诉的责任，也不得对其提起该诉。

<!-- source-p 465 -->
<a id="39.3.4.pr."></a>**序言。**阻止雨水侵入之诉只能对工程所有人提起。不过，拉贝奥写道，若有人建造坟墓，因而使水造成损害，即使其后来因土地成为宗教场所而不再是工程所有人，仍以使其承担阻止雨水侵入之诉责任的意见较为可取；因为其修筑工程时曾是所有人。若其依裁判人命令被迫恢复工程原状，则不得对其提起侵害坟墓之诉。

<!-- source-p 466 -->
<a id="39.3.4.1"></a>**1.**尤利安也写道，若提起阻止雨水侵入之诉后，被诉人将土地转让，法官就已经发生的损害和恢复工程原状，应作出假设没有转让时本应作出的裁判。因为即使土地已经转让，诉讼仍继续；转让期间发生的损害也应予考虑。

<!-- source-p 467 -->
<a id="39.3.4.2"></a>**2.**同一尤利安写道，阻止雨水侵入之诉只能对所有人提起。因此，若承租人在土地所有人不知情时施工，土地所有人只须容忍恢复工程原状；承租人则可依《暴力或秘密行为禁令》（*interdictum quod vi aut clam*）被强令承担恢复工程的费用，以及由此造成的损害。但若土地所有人要求可能受损害者向自己提供担保，要求其提供担保是极为公平的。

<!-- source-p 468 -->
<a id="39.3.4.3"></a>**3.**同样，若实施此类工程、使雨水损害邻人的不是我而是我的代理人，对我的诉讼责任与对承租人的责任相同。依尤利安的意见，即使工程已经恢复原状，仍可依据《暴力或秘密行为禁令》起诉代理人。

若承租人在土地所有人不知情时施工，因而使雨水损害邻人，拉贝奥答复说，承租人应依《暴力或秘密行为禁令》承担责任；土地所有人则承担阻止雨水侵入之诉的责任，因为只有土地所有人能够恢复工程原状。不过，若有人以尚未发生损害担保为土地所有人提供了保障，土地所有人只须容忍恢复工程原状；若其为恢复工程支出了费用，可以通过租赁之诉向承租人追偿。也有人可能认为，他并无必要亲自恢复，因此不应追偿。但若承租人是奉土地所有人之命施工，土地所有人也须依《暴力或秘密行为禁令》承担责任。

<!-- source-p 475 -->
<a id="39.3.6.1"></a>**1.**若水从数人的土地流下并造成损害，或数人的土地受到损害，已经确立并且我们也遵循以下规则：若受损土地属于数人，各人可就自己的份额分别起诉，判决也按份额作出；若对数人提起诉讼，则各人分别就其份额被诉，判决亦按份额作出。

<!-- source-p 476 -->
<a id="39.3.6.2"></a>**2.**由此产生一个问题：若水从你自己的土地流来，损害我与你共有的土地，能否提起阻止雨水侵入之诉？我认为可以起诉，但只能请求赔偿相应份额的损害。

<!-- source-p 477 -->
<a id="39.3.6.3"></a>**3.**反过来，若造成损害的是共有土地，而受损的是某人的个人土地，也可以提起阻止雨水侵入之诉以取得损害赔偿，但只限于相应份额。

<!-- source-p 478 -->
<a id="39.3.6.4"></a>**4.**若某人在提起阻止雨水侵入之诉前将土地所有权转让给他人，他便不再享有本诉；该诉权转归取得该土地的人。因为本诉涉及将来损害，所以土地所有权转移后，诉权即归属于新的所有人，即使邻人是在土地仍属于前手时施工也是如此。

<!-- source-p 479 -->
<a id="39.3.6.5"></a>**5.**应知，阻止雨水侵入之诉不是对物之诉，而是对人之诉。

<!-- source-p 480 -->
<a id="39.3.6.6"></a>**6.**法官的职责是：若工程由邻人实施，应命其恢复原状，并赔偿争讼程序确定后发生的损害；若损害在争讼程序确定前已经发生，则只须命其恢复工程原状，不命其赔偿该损害。

<!-- source-p 481 -->
<a id="39.3.6.7"></a>**7.**凯尔苏斯写道，若我实施某项工程，以致雨水损害你，应强令我自费拆除工程；若实施工程的是与我无关的他人，只须容许你拆除即可。但若工程是我的奴隶实施的，我应交付该奴隶以代偿（*noxae deditio*）；若是我所继承之人实施的，则视同我本人实施。

<!-- source-p 482 -->
<a id="39.3.6.8"></a>**8.**法官应依事实估价，也就是依已经显现的损害数额估价。

<a id="39.3.24.pr."></a>**序言。**上游土地的邻人以这样的方式耕犁草地，使水沿犁沟和田垄流向下游。有人询问，能否通过阻止雨水侵入之诉的裁判程序强令他转向另一方向耕作，以免犁沟朝向其土地。答复是，不能阻止邻人按照自己意愿耕种土地。

<!-- source-p 561 -->
<a id="39.3.24.1"></a>**1.**但若他开挖横向灌溉沟，使水经沟流入对方土地，可以通过阻止雨水侵入之诉的裁判程序强令他填平这些沟渠。

<!-- source-p 562 -->
<a id="39.3.24.2"></a>**2.**若他开挖的沟渠可能使雨水造成损害，而未来损害已显而易见，裁判人应命其填平沟渠；若其不遵从，则应判令其承担责任，即使在裁判人作出裁决前，雨水从未流经这些沟渠亦然。

<!-- source-p 563 -->
<a id="39.3.24.3"></a>**3.**湖泊上涨或缩小时，邻人不得据此取得湖泊扩张部分（*accessio*），也不得要求填补湖泊缩小部分（*decessio*）。
