# D.39.1 论新工程告示（*De operis novi nuntiatione*）

> **底本范围：**EPUB 全部段落元素的连续编号 source-p 1–148；保留题名、出处、分题、段落及锚点。

<!-- source-p 1 -->
<a id="1"></a><a id="39.1"></a>**39.1.0 论新工程告示**（*De operis novi nuntiatione*）。

<!-- source-p 2 -->
<a id="39.1.1"></a>**39.1.1**

<!-- source-p 3 -->
乌尔比安《告示评注》第五十二卷。

<!-- source-p 4 -->
<a id="39.1.1.pr."></a>**序言。**本告示承诺：无论工程是否合法，均可通过新工程告示予以制止；随后，仅在告示人无权制止的范围内，才解除该项禁止。

<!-- source-p 5 -->
<a id="39.1.1.1"></a>**1.**新工程告示及其救济，是为针对尚未完成的未来工程而设，并非针对已经完成的工程；也就是说，它针对尚未实施、应当阻止其实施的工程。若本不应实施的工程已经完成，新工程告示的告示条款便不再适用，而应转向要求恢复因暴力或秘密方式所实施工程的禁令，以及针对神圣或宗教场所、公共河流或公共河岸所实施工程的禁令。若这些地方有违法施工，即可依这些禁令请求恢复原状。

<!-- source-p 6 -->
<a id="39.1.1.2"></a>**2.**依本告示提出新工程告示，无须先向裁判官申请；即使未曾向裁判官请求，任何人也可以提出告示。

<!-- source-p 7 -->
<a id="39.1.1.3"></a>**3.**我们既可以以自己的名义，也可以以他人的名义提出告示。

<!-- source-p 8 -->
<a id="39.1.1.4"></a>**4.**新工程告示可以在任何日子提出。

<!-- source-p 9 -->
<a id="39.1.1.5"></a>**5.**即使工程实施者不在场、违背其意愿或不知情，也可以向其提出新工程告示。

<!-- source-p 10 -->
<a id="39.1.1.6"></a>**6.**在新工程告示程序中，我们使占有人成为对方当事人。

<!-- source-p 11 -->
<a id="39.1.1.7"></a>**7.**若收到新工程告示之人在告示解除前继续施工，随后又提起诉讼，主张自己有权保有已经建成的工程，裁判官应拒绝其诉请，并对其发布恢复工程原状的禁令。

<!-- source-p 12 -->
<a id="39.1.1.8"></a>**8.**即使告示人不知道正在实施何种工程，也可以提出新工程告示。

<!-- source-p 13 -->
<a id="39.1.1.9"></a>**9.**提出新工程告示后，当事人便受裁判官管辖。

<!-- source-p 14 -->
<a id="39.1.1.10"></a>**10.**由此，塞尔苏斯在《学说汇纂》第十二卷提出问题：新工程告示提出后，若你与对方达成协议，允许你继续施工，是否应准许对方援引协议抗辩？塞尔苏斯说，应当准许；而且无须担心这会使私人协议凌驾于裁判官的命令之上。裁判官除此之外还能做什么呢？无非是解决他们之间的争议。既然当事人自愿放弃争议，裁判官就应承认该协议有效。

<!-- source-p 15 -->
<a id="39.1.1.11"></a>**11.**无论通过建造还是拆除某物，只要改变了工程原有的面貌，就被视为实施新工程。

<!-- source-p 16 -->
<a id="39.1.1.12"></a>**12.**本告示并不涵盖所有工程，只涵盖与土地相连的工程；建造或拆除建筑物，才属于这里所说的新工程。因此，即使收割庄稼、砍伐树木或修剪葡萄藤也算是实施工程，仍不属于本告示的范围，因为本告示适用于在土地上实施的工程。

<!-- source-p 17 -->
<a id="39.1.1.13"></a>**13.**若有人加固一座旧建筑，我们能否对其提出新工程告示？较妥当的看法是不能；因为此人并非实施新工程，而是在加固旧建筑，为旧建筑提供支撑。

<!-- source-p 18 -->
<a id="39.1.1.14"></a>**14.**无论是在城镇内，还是在城镇外的别墅或田地中实施新工程，均可依据本告示提出告示；无论工程是在私人土地还是公共土地上实施，均是如此。

<!-- source-p 19 -->
<a id="39.1.1.15"></a>**15.**现在应当考察：基于哪些事由提出告示，哪些人可以提出、可以向哪些人提出，告示可以在哪些地方提出，以及告示会产生何种效果。

<!-- source-p 20 -->
<a id="39.1.1.16"></a>**16.**提出新工程告示，可能是为了保全自己的权利、防止损害，或保护公共权利。

<!-- source-p 21 -->
<a id="39.1.1.17"></a>**17.**我们提出告示，是因为享有禁止他人施工的权利：例如，为使可能在公共或私人土地上施工之人向我们提供防止将来损害的担保；又如，有人将实施违反法律或皇帝敕令的工程，而这些规范规定了建筑方式；或者工程将在神圣、宗教场所、公共土地或公共河岸上实施。这些情形也都有相应禁令。

<!-- source-p 22 -->
<a id="39.1.1.18"></a>**18.**若有人在海中或海岸上建造，即使他并非在自己的土地上建造，依万民法，建筑物仍归其所有。因此，若有人想禁止他在那里建造，并无任何法律依据；只有一种情形可以提出新工程告示，即告示人希望对方为可能发生的损害提供担保。

<!-- source-p 23 -->
<a id="39.1.1.19"></a>**19.**与争议财物有关的人，可以为保全自己的权利或防止损害而提出新工程告示。

<!-- source-p 24 -->
<a id="39.1.1.20"></a>**20.**用益权人不得以自己的名义提出新工程告示，但可以代理人名义提出；或者，也可以对实施新工程之人提起用益权之诉。该诉将使其获得相当于因未实施新工程而使其避免的损失。

<!-- source-p 25 -->

<!-- source-p 26 -->
尤利安《学说汇纂》第四十九卷。

<!-- source-p 27 -->
若用益权人向土地所有人提出告示，该告示无效。因为，用益权人不能像对邻人那样起诉土地所有人，主张土地所有人未经其同意不得加高建筑物。但若此举会损害用益权，他应提起用益权之诉。

<!-- source-p 28 -->
<a id="39.1.3"></a>**39.1.3**

<!-- source-p 29 -->
乌尔比安《告示评注》第五十二卷。

<!-- source-p 30 -->
<a id="39.1.3.pr."></a>**序言。**即使工程是在行省土地上实施，也适用新工程告示。

<!-- source-p 31 -->
<a id="39.1.3.1"></a>**1.**若有人在共有土地上实施工程，可以向邻人提出告示。当然，若我们的共有人之一在共有土地上施工，我作为共有人不能向他提出新工程告示；但我可以通过共有物分割之诉或请求裁判官介入来制止他。

<!-- source-p 32 -->
<a id="39.1.3.2"></a>**2.**若我的共有人在共有公寓楼中实施新工程，而我另有一处自有房屋会受到损害，我能否向他提出新工程告示？拉贝奥认为不能，因为我可以通过其他方式禁止其施工，也就是请求裁判官或共有物分割之诉中的仲裁人介入。此说正确。

<!-- source-p 33 -->
<a id="39.1.3.3"></a>**3.**若我是地上权人，邻人却实施新工程，我能否提出告示？虽然这使人想到我仿佛只是房屋承租人，但裁判官会给予我一项准对物之诉，因此也会给予我地役权之诉，并应准许我提出新工程告示。

<!-- source-p 34 -->
<a id="39.1.3.4"></a>**4.**若有人在公共土地上实施工程，所有公民都可以提出新工程告示：

<!-- source-p 35 -->
<a id="39.1.4"></a>**39.1.4**

<!-- source-p 36 -->
保罗《告示评注》第四十八卷。

<!-- source-p 37 -->
这符合公共利益，因为应尽可能准许更多人维护公共事务。

<!-- source-p 38 -->
<a id="39.1.5"></a>**39.1.5**

<!-- source-p 39 -->
乌尔比安《告示评注》第五十二卷。

<!-- source-p 40 -->
<a id="39.1.5.pr."></a>**序言。**有人询问未适婚年龄者的情形。尤利安在《学说汇纂》第十二卷写道，除非工程关系到该未适婚年龄者的私人利益，例如遮挡其采光或妨碍其视野，否则不应准许其执行新工程告示。并且，只有在监护人参与并表示同意后，未适婚年龄者提出的告示才有效。

<!-- source-p 41 -->
<a id="39.1.5.1"></a>**1.**可以向奴隶提出新工程告示；但奴隶本人不能提出告示，而且奴隶提出的告示不发生任何效力。

<!-- source-p 42 -->
<a id="39.1.5.2"></a>**2.**应当记住，新工程告示必须在现场提出，也就是在工程施工地点提出，无论对方正在建造，还是刚要开始建造。

<!-- source-p 43 -->
<a id="39.1.5.3"></a>**3.**告示不一定要向土地所有人本人提出；在现场向任何在场之人提出即可。因此，甚至可以向在现场施工的工匠或工人提出告示。一般而言，可以向任何以土地所有人或工程实施者名义在现场之人提出告示；在场者是谁、具有何种身份均无关紧要。即使向奴隶、妇女、男童或女童提出，告示也有效。只要是在现场提出告示，并且能够将告示转达给土地所有人即可。

<!-- source-p 44 -->
<a id="39.1.5.4"></a>**4.**若有人在广场向土地所有人提出新工程告示，该告示显然毫无效力。告示必须在现场提出，我几乎可以说，应当在工程本身、也就是施工地点提出。之所以如此，是为了使施工者立即因告示而停止施工。否则，若在别处提出告示，在前往施工地点的途中，可能因不知情而继续施工，从而违反裁判官告示。

<!-- source-p 45 -->
<a id="39.1.5.5"></a>**5.**若实施工程的土地为数人共有，而告示只向其中一人提出，该告示仍然有效，并视为已向所有共有人提出。但若只有一人于告示提出后继续施工，其他未曾施工之人不承担责任；因为不应使未曾实施行为的人受他人行为损害。

<!-- source-p 46 -->
<a id="39.1.5.6"></a>**6.**若工程损害数名所有人的财物，究竟只需其中一名共有人提出告示，还是所有人都必须提出？较正确的看法是，仅由一人提出不足以对所有人发生效力，必须由每个人分别提出；因为可能一名告示人有权禁止施工，而另一名并无此权。

<!-- source-p 47 -->
<a id="39.1.5.7"></a>**7.**若有人想直接向裁判官提出新工程告示，应先声明自己无法向施工者提出告示；若他后来提出告示，则在此之前已经建成的部分也必须拆除，仿佛告示是从先前所声明的日期起提出的。

<!-- source-p 48 -->
<a id="39.1.5.8"></a>**8.**若有人把某物伸入我们的房屋，或在我们的土地上建造，我们以新工程告示保全自己的权利，也属公平。

<!-- source-p 49 -->
<a id="39.1.5.9"></a>**9.**塞克斯图斯·佩狄乌斯精当地将新工程告示的事由分为三类：自然事由、公共事由和设定事由。自然事由，是指有人将某物伸入我们的房屋，或在我们的土地上建造；公共事由，是指我们通过新工程告示维护法律、元老院决议及皇帝敕令；设定事由，是指某人后来减损了自己的权利、增加了他人的权利，也就是说，他后来为自己的房屋设定地役权，却又实施违反该地役权的行为。

<!-- source-p 50 -->
<a id="39.1.5.10"></a>**10.**应当记住，若有人想在我们的土地上建造，或把某物伸入、悬出于我们的土地，最好请求裁判官介入或直接以物理方式制止，例如投掷小石，而不宜提出新工程告示；否则，提出告示便会使受告示人取得占有人地位。但若有人在自己的土地上实施损害我们的工程，此时就必须提出新工程告示。若有人执意在我们的土地上施工，最公平的做法是对其适用“因暴力或秘密施工”之禁令，或“维持占有”禁令。

<!-- source-p 51 -->
<a id="39.1.5.11"></a>**11.**若有人想修理或清理水渠、下水道，不应允许他人以新工程告示加以阻止；因为清理下水道和水渠关系公共健康与安全。

<!-- source-p 52 -->
<a id="39.1.5.12"></a>**12.**此外，裁判官还概括排除了其他因延迟而可能造成危险的工程；对于这些工程，他也认为不应理会新工程告示。谁会怀疑，与其阻碍紧急必要工程的修建，不如不提出新工程告示更为妥当？只有在延迟会造成危险时，才适用本告示的这一部分。

<!-- source-p 53 -->
<a id="39.1.5.13"></a>**13.**因此，若有人在工程延误会造成危险时提出新工程告示，或有人在修理下水道、河岸时提出告示，应当由法官考察工程是否属于不应理会告示的类型。若查明工程涉及下水道、水渠或河岸，或者任何延误都会造成危险，就应当说不必担心该告示产生阻碍效力。

<!-- source-p 54 -->
<a id="39.1.5.14"></a>**14.**提出新工程告示之人必须宣誓，其提出告示并非出于诬告。该誓言由裁判官命令提出；因此，要求对方宣誓之人无须事先宣誓。

<!-- source-p 55 -->
<a id="39.1.5.15"></a>**15.**提出告示之人必须说明其禁止新工程的地点，使收到告示之人知道可以在哪里施工、又应当暂时停止在哪里施工。只有在告示仅针对工程的一部分时，才必须具体说明地点；若告示针对整个工程，则无须逐一说明，只须说明告示针对整个工程即可。

<!-- source-p 56 -->
<a id="39.1.5.16"></a>**16.**若工程在数个地点实施，是一份告示就足够，还是必须提出数份告示？尤利安在《学说汇纂》第四十九卷说，由于告示必须在现场提出，所以需要提出数份告示；相应地，也需要数次解除告示。

<!-- source-p 57 -->
<a id="39.1.5.17"></a>**17.**若收到告示之人已经提供担保或作出允诺，或者未能按照善良人的判断提供担保或作出允诺并非由其所致，则视同新工程告示已经解除。这项救济的好处在于，可以免去当事人前往裁判官处请求解除告示的麻烦。

<!-- source-p 58 -->
<a id="39.1.5.18"></a>**18.**若代理人名义的告示人不能提供担保，保证本人会追认该告示，则无论该代理人是否真有代理权，告示均应解除。

<!-- source-p 59 -->
<a id="39.1.5.19"></a>**19.**若有人代表不在场之人请求解除告示，无论该告示涉及私人权利还是公共权利，他都必须提供担保；因为他承担了诉讼防御人的职能。不过，这项担保并非为了确保本人追认，而是针对新工程告示本身。

<!-- source-p 60 -->
<a id="39.1.5.20"></a>**20.**若我的代理人向施工者提出新工程告示并收取了担保，后来我又对他提起禁令之诉，要求他不得以暴力阻止我施工，那么他应当依该禁令提供判决履行担保，因为他承担了诉讼防御人的职能：

<!-- source-p 62 -->
尤利安《学说汇纂》第四十一卷。

<!-- source-p 63 -->
因此，不应对其提出代理关系方面的抗辩，也不应强令其提供本人将予追认的担保。

<a id="39.1.7.1"></a>**1.**监护人和保佐人均可以正当地提出新工程告示。

<!-- source-p 70 -->
<a id="39.1.8.pr."></a>**序言。**我不仅可以向紧邻的邻人提出告示，也可以向在较高处施工的人提出告示；因为地役权也可能跨越中间的公共或私人土地而存在。

<!-- source-p 71 -->
<a id="39.1.8.1"></a>**1.**提出新工程告示之人若发现已有部分工程完成，应将其记入现场记录，以便查明此后又实施了哪些工程。

<!-- source-p 72 -->
<a id="39.1.8.2"></a>**2.**若我有权依法禁止你施工，并已向你提出新工程告示，你只有在提供担保后才有权继续建造。

<!-- source-p 73 -->
<a id="39.1.8.3"></a>**3.**但若我告示你不得在公共场所实施违反法律的工程，你就应当作出允诺，因为我主张的是他人的权利，而非自己的权利；作为主张他人权利之人，我应满足于对方作出允诺。

<!-- source-p 74 -->
<a id="39.1.8.4"></a>**4.**应当知道，新工程告示提出后，收到告示之人必须停止施工，直到其提供担保或告示被解除为止；届时，若他有权建造，便可以合法施工。

<!-- source-p 75 -->
<a id="39.1.8.5"></a>**5.**为了证明此后又建造了什么，提出告示之人应当测量工程尺寸；裁判官通常会下令进行测量并予以比对。

<!-- source-p 76 -->
<a id="39.1.8.6"></a>**6.**提出告示之人死亡，告示即告消灭；转让相关财产也有同样效果，因为这些情形会终止禁止施工的权利。

<!-- source-p 77 -->
<a id="39.1.8.7"></a>**7.**但若收到告示之人死亡或转让了房屋，新工程告示并不消灭。这一点从基于告示订立的要式口约中也能看出：其中还提及继承人。

<a id="39.1.20"></a>**39.1.20**

<!-- source-p 115 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 116 -->
<a id="39.1.20.pr."></a>**序言。**裁判官说：“在已经提出告示、禁止实施新工程的地点，就本案所争议之事，若在告示被解除之前，或在告示已处于应予解除的情形之前，于该地点所实施的工程，你应当恢复原状。”

<!-- source-p 117 -->
<a id="39.1.20.1"></a>**1.**本禁令针对如下情形发布：新工程告示提出后，在告示被解除之前，或者在以提供恢复工程原状的担保代替解除告示之前，不得再实施任何工程。因此，即使施工者本有权施工，只要他在此期间施工，也被视为违反裁判官禁令，因而必须拆除其所建工程。

<!-- source-p 118 -->
<a id="39.1.20.2"></a>**2.**无论提出告示的地点原本是空地，还是已经建有建筑物，均可适用本禁令。

<!-- source-p 119 -->
<a id="39.1.20.3"></a>**3.**裁判官说：“你应当恢复已经实施的工程。”他命令恢复已经实施的工程，并不问该工程是否合法；无论其依法还是违法实施，均适用本禁令。

<!-- source-p 120 -->
<a id="39.1.20.4"></a>**4.**在告示解除之前实施的任何工程，或者在法律上视为告示已经解除时实施的工程，都应当视为未经权利依据而实施。

<!-- source-p 121 -->
<a id="39.1.20.5"></a>**5.**若有人已经准备提供担保，但原告拒绝订立要式口约，则应视为告示应予解除；因为既然是原告造成这一结果，就显然属于应解除告示的情形。

<!-- source-p 122 -->
<a id="39.1.20.6"></a>**6.**本禁令为永久性禁令，也适用于继承人及其他继受人。

<!-- source-p 123 -->
<a id="39.1.20.7"></a>**7.**即使是亲自实施工程或追认他人所实施工程的人，也可以成为本禁令的对象。

<!-- source-p 124 -->
<a id="39.1.20.8"></a>**8.**若有人询问，本禁令能否针对实施工程之人的继承人提起，应当知道，拉贝奥认为，只能在继承人实际取得利益的范围内，或者在继承人以恶意阻止利益归其取得的情形下，准许提起禁令。有些人认为应当给予事实诉讼而非禁令；这才是正确的看法。

<!-- source-p 125 -->
<a id="39.1.20.9"></a>**9.**随后，裁判官说：“在已经提出告示、禁止实施新工程的地点，就本案所争议之事，若已就该事提供担保，或因你而使担保无法提供，我禁止任何人以暴力阻止其在该地点施工。”

<!-- source-p 126 -->
<a id="39.1.20.10"></a>**10.**这是一项禁止性禁令，禁止任何人阻止已提供担保之人施工；因为不让建筑物荒废，关系到城市的体面。

<!-- source-p 127 -->
<a id="39.1.20.11"></a>**11.**施工者依法还是违法施工并不重要，因为新工程告示人已在提供担保后获得保障。

<!-- source-p 128 -->
<a id="39.1.20.12"></a>**12.**这项禁令适用于已经提供担保的人；裁判官还补充说：“或者，因你而使担保无法提供。”

<!-- source-p 129 -->
<a id="39.1.20.13"></a>**13.**因此，若施工者并未提供正式担保，而只是作出允诺，则不适用该禁令；因为在尚未查明施工者依据何种权利施工之前，不应允许其在公共场所建造。

<!-- source-p 130 -->
<a id="39.1.20.14"></a>**14.**即使已经提供担保，但担保未能持续有效，该禁令也不再适用。

<!-- source-p 131 -->
<a id="39.1.20.15"></a>**15.**若告示人曾一度阻挠对方提供担保，但现在已不再阻挠，则该禁令不再适用。

<!-- source-p 132 -->
<a id="39.1.20.16"></a>**16.**即使一年期间届满，该禁令仍可适用；继承人及其他继受人也可以提起。

<a id="39.1.21"></a>**39.1.21**

<!-- source-p 134 -->
乌尔比安《告示评注》第八十卷。

<!-- source-p 135 -->
<a id="39.1.21.pr."></a>**序言。**每当邻人主张自己有权禁止对方未经其同意实施新工程时，通常就应订立关于新工程告示的要式口约。

<!-- source-p 136 -->
<a id="39.1.21.1"></a>**1.**若有人希望在提出新工程告示后仍可不受制裁地继续建造，应向告示人提供正式担保。如此一来，双方都得到保障：告示人获得了工程应予恢复的担保，收到告示之人的施工也不再受阻。因为在提供担保之前，无论其建造了什么，都可依恢复性禁令被迫拆除。

<!-- source-p 137 -->
<a id="39.1.21.2"></a>**2.**该要式口约附有条件：只有在作出判决，或在判决前发生某种情形且诉讼未获防御时，才发生效力；其中还附有关于恶意的条款。

<!-- source-p 138 -->
<a id="39.1.21.3"></a>**3.**所谓工程已经完成，并非只是在建筑物上放置了一两块砖；而是应当已经呈现某种工程规模，具有已形成工程的大致外形。

<!-- source-p 139 -->
<a id="39.1.21.4"></a>**4.**无论法院作出判决，还是诉讼未获防御，要式口约均发生效力：工程应依善良人的裁量恢复原状；若未按此恢复，且原告愿意，则应按该工程的价值支付相应金钱。

<!-- source-p 140 -->
<a id="39.1.21.5"></a>**5.**有人问，若数名所有人共同施工，是否人人都应提供担保？拉贝奥说，只需一人提供担保，因为工程无法仅恢复其中一部分。

<!-- source-p 141 -->
<a id="39.1.21.6"></a>**6.**拉贝奥还说，若有数名告示人，应设法由一人接受担保，只要他们彼此同意；若不能达成一致，则应分别向每人提供担保。

<!-- source-p 142 -->
<a id="39.1.21.7"></a>**7.**拉贝奥说，要式口约中还应补充：若告示人愿意，担保金额应以各人自身的利益为限。否则，若担保写作“按该工程的价值”，就会产生疑问：这几个字指整个工程的价值，还是指提出要式口约之人的利益？我认为，即使只向一人提供“按该工程的价值”担保，也可以主张该担保足够，因为这里说的是工程本身的规模。
