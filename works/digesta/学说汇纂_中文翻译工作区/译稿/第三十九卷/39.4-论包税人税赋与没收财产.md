# D.39.4 论包税人、税赋与没收财产（*De publicanis et vectigalibus et commissis*）

> **底本范围：**EPUB 全部段落元素的连续编号 source-p 570–667；共98段，保留题名、出处、分题、段落及锚点。

<!-- source-p 570 -->
<a id="39.4"></a>**39.4.0 论公税承包人、税赋与没收财产**（*De publicanis et vectigalibus et commissis*）。

<!-- source-p 571 -->
<a id="39.4.1"></a>**39.4.1**

<!-- source-p 572 -->
乌尔比安《告示评注》第五十五卷。

<!-- source-p 573 -->
<a id="39.4.1.pr."></a>**序言。**裁判官说：“对于公税承包人以该项公共收入为名而以暴力夺取的财物，或者其帮役人员所夺取的财物，若未予返还，我将准许提起双倍额诉讼；若在一年之后提起，则准许提起单倍额诉讼。此外，若有人声称发生了不法损害或盗窃，我也将准许提起诉讼。若不向有权取得该物之人出示相关人员，我将不允许以诺克萨交付免除责任，而准许对其主人提起诉讼。”

<!-- source-p 574 -->
<a id="39.4.1.1"></a>**1.**本标题涉及公税承包人。公税承包人，是指享有公共收入承包权的人，因此得此名称；无论他们是向国库缴纳税赋，还是负责征收税款，凡向国库承包事务者，均可适当地称为公税承包人。

<!-- source-p 575 -->
<a id="39.4.1.2"></a>**2.**有人或会问：既然裁判官已在其他告示中规定了盗窃、不法损害和暴力夺取之诉，为何还要另行公布本告示，仿佛那些规定并不存在？但裁判官认为，专门针对公税承包人另行发布告示，确有必要。

<!-- source-p 576 -->
<a id="39.4.1.3"></a>**3.**本告示在某些方面较为宽缓，因为依本告示仅判处双倍额；而暴力夺取财物之诉判处四倍额，现行犯盗窃（*furtum manifestum*）之诉也同样判处四倍额。

<!-- source-p 577 -->
<a id="39.4.1.4"></a>**4.**本告示还允许公税承包人返还其以暴力夺取之物；若其返还，便免除全部责任，并免受本告示此部分所规定的惩罚性诉讼。因此，有人问：当事人能否不依据本告示，而依据一般的暴力夺取财物之诉、不法损害之诉或盗窃之诉起诉公税承包人？通说认为可以，庞波尼乌斯也这样写道。否则，认为公税承包人的地位竟优于其他人的地位，实在荒谬。

<!-- source-p 578 -->
<a id="39.4.1.5"></a>**5.**这里所说的“帮役人员”不只包括公税承包人的奴隶，也包括属于公税承包人帮役队伍的其他人；因此，无论是自由人还是他人的奴隶，只要为公税承包人征收该项税赋而服务，均受本告示约束。所以，若公税承包人的奴隶实施了夺取行为，但并不属于为公共税赋服务的那支帮役队伍，本告示便不适用。

<!-- source-p 579 -->
<a id="39.4.1.6"></a>**6.**裁判官最后说：“若不出示这些人，我将不允许以诺克萨交付免除责任，而准许对主人提起诉讼。”这是本告示特有的规定：若奴隶未被出示，即使主人不再对其拥有权力、无法将其出示，或者虽有权力却无法出示，仍可对主人提起无须诺克萨交付的诉讼，

<!-- source-p 580 -->
<a id="39.4.2"></a>**39.4.2**

<!-- source-p 581 -->
盖尤斯《行省告示评注》第二十一卷。

<!-- source-p 582 -->
而且，不得由主人代替缺席之人进行答辩，

<!-- source-p 583 -->
<a id="39.4.3"></a>**39.4.3**

<!-- source-p 584 -->
乌尔比安《告示评注》第五十五卷。

<!-- source-p 585 -->
<a id="39.4.3.pr."></a>**序言。**因为若将这些奴隶出示，便会对他们提起诺克萨诉讼。之所以使他们承担如此严厉的责任，是因为公税承包人本应为这项职务挑选品行良好的奴隶。

<!-- source-p 586 -->
<a id="39.4.3.1"></a>**1.**裁判官所说的“对主人”，应理解为“对税赋承包合伙人”，即使这些人并非奴隶的主人。

<!-- source-p 587 -->
<a id="39.4.3.2"></a>**2.**原告应先说明希望出示哪一个或哪些人；若其未被出示，便可据此起诉。但若原告说：“把所有人都出示出来，以便我辨认究竟是谁”，我认为应当听从其请求。

<!-- source-p 588 -->
<a id="39.4.3.3"></a>**3.**若数名奴隶共同实施盗窃或造成损害，应遵循如下规则：只要支付的数额达到假使由一名自由人实施该行为时所应支付的数额，即应判决免责。

<!-- source-p 589 -->
<a id="39.4.4"></a>**39.4.4**

<!-- source-p 590 -->
保罗《告示评注》第五十二卷。

<!-- source-p 591 -->
<a id="39.4.4.pr."></a>**序言。**若以暴力夺取财物的公税承包人死亡，拉贝奥认为，应对其继承人在其所受利益范围内给予诉讼。

<!-- source-p 592 -->
<a id="39.4.4.1"></a>**1.**关于总督为自身用途委托他人运送进来的物品，哈德良神皇曾致函各总督：每当有人为行省或军队长官本人，或为其代理人个人使用而派人购买某物时，应由委托人亲笔签署一份书面说明，并将该人送交公税承包人；若其所运物品超过委托范围，超出部分便作为赠与处理。

<!-- source-p 593 -->
<a id="39.4.4.2"></a>**2.**对于几乎所有税赋，通常都要考虑既有惯例；皇帝敕令也对此作了规定。

<!-- source-p 594 -->
<a id="39.4.5"></a>**39.4.5**

<!-- source-p 595 -->
盖尤斯《城市裁判官关于公税承包人的告示评注》。

<!-- source-p 596 -->
<a id="39.4.5.pr."></a>**序言。**本告示规定：在诉讼系属发生之前，若物已返还，诉权即消灭；诉讼系属发生后，惩罚责任仍继续。不过，即使在诉讼系属发生后才准备返还财物，也应判决其免责。

<!-- source-p 597 -->
<a id="39.4.5.1"></a>**1.**我们曾讨论：双倍额是否全属惩罚，除此之外还可另行追索财物；抑或双倍额中已经包括财物追索，因而惩罚本身只是单倍额。较妥当的看法是，财物价值已计入双倍额。

<!-- source-p 598 -->
<a id="39.4.6"></a>**39.4.6**

<!-- source-p 599 -->
莫德斯提努《刑罚论》第二卷。

<!-- source-p 600 -->
若有多名公税承包人非法征收某项款物，双倍额诉讼不会因人数而倍增；他们应共同承担全部给付责任。若其中一人无力给付的部分无法向其追取，则可向另一人追取。塞维鲁与安东尼努斯神皇曾以敕答作此规定，因为他们指出，作为犯罪参与者与作为欺诈共谋者之间存在重大区别。

<!-- source-p 601 -->
<a id="39.4.7"></a>**39.4.7**

<!-- source-p 602 -->
帕皮里乌斯《皇帝敕令汇编》第二卷。

<!-- source-p 603 -->
<a id="39.4.7.pr."></a>**序言。**安东尼努斯与维鲁斯皇帝敕答：在税赋事务中，应对土地本身而非个人提起诉讼；因此，土地的占有人也必须缴纳前期欠缴的税赋；即使其对此并不知情，也可依该先例取得诉权。

<!-- source-p 604 -->
<a id="39.4.7.1"></a>**1.**他们还敕答：若未适婚年龄者在三十日内缴纳税赋，应免除其因没收而受的处罚。

<!-- source-p 605 -->
<a id="39.4.8"></a>**39.4.8**

<!-- source-p 606 -->
帕比尼安《答复集》第十三卷。

<!-- source-p 607 -->
<a id="39.4.8.pr."></a>**序言。**逃避税赋之罪，基于没收规则而及于实施该欺诈者的继承人。

<!-- source-p 608 -->
<a id="39.4.8.1"></a>**1.**但是，若数名继承人之一为逃避税赋而窃取共有物，其他继承人的份额并不因此被剥夺。

<!-- source-p 609 -->
<a id="39.4.9"></a>**39.4.9**

<!-- source-p 610 -->
保罗《箴言集》第五卷。

<!-- source-p 611 -->
<a id="39.4.9.pr."></a>**序言。**若竞标者竞价过热，使税赋承包价格高于通常水平，只有在中标者愿意提供适格保证人及担保时，才应准许将税赋承包给他。

<!-- source-p 612 -->
<a id="39.4.9.1"></a>**1.**不得强迫任何人承包税赋。因此，承包期限届满后，应当重新招租。

<!-- source-p 613 -->
<a id="39.4.9.2"></a>**2.**拖欠税赋承包款项的人，在其尚未履行前一承包期的义务之前，不得获准再次承包。

<!-- source-p 614 -->
<a id="39.4.9.3"></a>**3.**国库或市政共同体的债务人不得承包税赋，以免其债务因另一项原因而进一步加重；但若其提供的保证人愿意代为清偿其债务，则属例外。

<!-- source-p 615 -->
<a id="39.4.9.4"></a>**4.**若税赋承包合伙人分别管理各自份额，任何一方都有权要求将资信较差合伙人的份额转由自己承担。

<!-- source-p 616 -->
<a id="39.4.9.5"></a>**5.**凡以非法方式向公私主体征收的款项，应向受损害者返还，并另行给付等额款项。若系以暴力勒索，则应返还三倍额；此外，还应依非常程序另行惩处。前一种处理是私人利益所要求，后一种处理则是公共纪律之威慑所要求。

<!-- source-p 617 -->
<a id="39.4.9.6"></a>**6.**对于从未征收过税赋的物品，不得征收该项税赋。但若某项惯常征收的税赋只是因公税承包人疏忽而被遗漏，其他人并不因此被禁止征收。

<!-- source-p 618 -->
<a id="39.4.9.7"></a>**7.**不应对为军队准备的物资征收税赋。

<!-- source-p 619 -->
<a id="39.4.9.8"></a>**8.**国库免缴一切税赋。但是，惯常从国库地产购买货物的商人，不得据此主张免缴公共税赋。

<!-- source-p 620 -->
<a id="39.4.10"></a>**39.4.10**

<!-- source-p 621 -->
赫莫吉尼安《摘要集》第五卷。

<!-- source-p 622 -->
<a id="39.4.10.pr."></a>**序言。**未经皇帝命令，总督、管理官或市政议会均不得设立税赋、变更既有税制，亦不得增加或减少税赋。

<!-- source-p 623 -->
<a id="39.4.10.1"></a>**1.**承包人未缴纳税赋分期款项时，在承包期限尚未届满之前，不得将其驱逐；也不得向其请求迟延利息。

<!-- source-p 624 -->
<a id="39.4.11"></a>**39.4.11**

<!-- source-p 625 -->
保罗《箴言集》第五卷。

<!-- source-p 626 -->
<a id="39.4.11.pr."></a>**序言。**不得将用于磨砺铁器的磨刀石出售给敌人；这与铁、粮食和盐一样，违者可能被处以死刑。

<!-- source-p 627 -->
<a id="39.4.11.1"></a>**1.**永久出租的公有土地，管理官未经皇帝授权不得收回。

<!-- source-p 628 -->
<a id="39.4.11.2"></a>**2.**若船主本人或乘客在船上装载非法物品，该船也应被国库没收。但若船主不在场时，是船长、舵手、领航员或其他船员所为，则这些人应被处死，非法货物予以没收，而船舶应返还船主。

<!-- source-p 629 -->
<a id="39.4.11.3"></a>**3.**对非法货物的追索也及于继承人。

<!-- source-p 630 -->
<a id="39.4.11.4"></a>**4.**物品因没收而被国库收取后，其原所有人仍可亲自购买该物，也可委托他人代为购买。

<!-- source-p 631 -->
<a id="39.4.11.5"></a>**5.**若某些人通过承包税赋获得了极高收益，而此后该项承包无法以同样高的价格招租，则应强制他们按先前的承包款继续承包。

<!-- source-p 632 -->
<a id="39.4.12"></a>**39.4.12**

<!-- source-p 633 -->
乌尔比安《告示评注》第三十八卷。

<!-- source-p 634 -->
<a id="39.4.12.pr."></a>**序言。**无人不知公税承包人团伙何等放肆、何等肆无忌惮。因此，裁判官为遏制其横行，发布了如下告示：

<!-- source-p 635 -->
<a id="39.4.12.1"></a>**1.**“若有人声称公税承包人的帮役人员实施了盗窃，或不法造成损害，而有权取得该物之人未能将其出示，我将不允许以诺克萨交付免除责任，而准许对主人提起诉讼。”

<!-- source-p 636 -->
<a id="39.4.12.2"></a>**2.**应当知道，这里所说的“帮役队伍”包括奴隶队伍。但若他人的奴隶基于善意为公税承包人服役，也同样包括在内；或许即使其出于恶意服役，通常也包括在内，因为流浪奴隶和逃奴往往为人所知，却仍被用于这类工作。因此，即使服务者是自由人，本告示也适用。

<!-- source-p 637 -->
<a id="39.4.12.3"></a>**3.**所谓公税承包人，是指承包公共税赋的人。

<!-- source-p 638 -->
<a id="39.4.13"></a>**39.4.13**

<!-- source-p 639 -->
盖尤斯《行省告示评注》第十三卷。

<!-- source-p 640 -->
<a id="39.4.13.pr."></a>**序言。**经营盐场、采土场和矿山的人，也属于公税承包人一类。

<!-- source-p 641 -->
<a id="39.4.13.1"></a>**1.**此外，若有人承包某市镇共同体的税赋，本告示同样适用。

<!-- source-p 642 -->
<a id="39.4.13.2"></a>**2.**无论奴隶是被出卖、被释放，还是逃走，拥有如此成群结伙的帮役队伍的公税承包人仍应就该奴隶承担责任。

<!-- source-p 643 -->
<a id="39.4.13.3"></a>**3.**但是，若奴隶已经死亡，公税承包人是否应视为对自己的行为负责？对此应予考察。但我认为，由于其无法出示奴隶，且并无欺诈行为，应当免除其责任。

<!-- source-p 644 -->
<a id="39.4.13.4"></a>**4.**本诉权为永久诉权，并可由继承人及其他继受人提起。

<!-- source-p 645 -->
<a id="39.4.14"></a>**39.4.14**

<!-- source-p 646 -->
乌尔比安《论辩集》第八卷。

<!-- source-p 647 -->
以税赋为由发生的没收也及于继承人。因为被没收的物品一经没收，便立即不再属于实施违法行为之人，而其所有权转归国库。因此，没收物的追索既可对任何占有人提起，也可对继承人提起。

<!-- source-p 648 -->
<a id="39.4.15"></a>**39.4.15**

<!-- source-p 649 -->
阿尔芬努斯《学说汇纂》第七卷。

<!-- source-p 650 -->
恺撒出租克里特岛的科托里亚斯矿区时，订立了如下规则：“自三月十五日之后，除承包人外，任何人不得在克里特岛采掘、取出或凿取磨刀石。”有一艘装载磨刀石的船在三月十五日之前从克里特港口出发，因风势被吹回港口；此后，它又在三月十五日之后启航。有人询问：这些磨刀石是否被视为在三月十五日之后违反规则离开克里特岛？答复是：尽管岛上的港口似乎也都属于该岛，但那艘在三月十五日之前已从港口出发、后因风暴被迫返回岛上的船，若此后再度离开，并不视为违反规则；况且，船一旦从港口启航，磨刀石便已被视为开始运出。

<!-- source-p 651 -->
<a id="39.4.16"></a>**39.4.16**

<!-- source-p 652 -->
马尔基安努斯《告发人论》单卷。

<!-- source-p 653 -->
<a id="39.4.16.pr."></a>**序言。**有时，即使奴隶已被判归没收，也不应将其出售，而应由主人支付其估价。塞维鲁与安东尼努斯神皇曾敕答：若某奴隶因被称为曾代主人办理事务而遭没收，该奴隶不应出售；主人应依善良人的判断支付相应估价。

<!-- source-p 654 -->
<a id="39.4.16.1"></a>**1.**他们在同一敕书中还答复说：若奴隶未曾申报，并被证明应予没收，且有人声称他诱奸了主人的妻子或实施了其他更严重的行为，应由总督代理人调查；若查明属于此类情形，则应估价该奴隶，并将其交给主人处罚。

<!-- source-p 655 -->
<a id="39.4.16.2"></a>**2.**塞维鲁与安东尼努斯神皇还敕答：对于被判没收的奴隶，其特有产物品并不当然处于同一没收状态；只有该特有产本身因其自身事由而落入没收范围时，才属例外。

<!-- source-p 656 -->
<a id="39.4.16.3"></a>**3.**无论为出售还是自用，凡有人未申报运入奴隶，若这些奴隶属于新近进口者，便应受没收处罚；若属于长期在本地服役者，则不在此限。所谓长期服役者，是指已在罗马城连续服役一年的奴隶；新近进口者，则指尚未服役满一年的奴隶。

<!-- source-p 657 -->
<a id="39.4.16.4"></a>**4.**逃亡中的奴隶不受没收，因为他们未经主人同意便越过边界；皇帝敕令对此已有规定。正如安东尼努斯·庇乌斯神皇也屡次敕答所说：“不得使奴隶能够通过逃跑，在主人不愿或不知情时脱离主人的权力。”

<!-- source-p 658 -->
<a id="39.4.16.5"></a>**5.**哈德良神皇规定，即使有人声称自己并不知情，仍应承担税赋方面的没收处罚。

<!-- source-p 659 -->
<a id="39.4.16.6"></a>**6.**马可与康茂德神皇也敕答说，不应因公税承包人未能对违规者作出指示而归责于公税承包人；但应当注意，不得欺骗那些愿意申报的人。

<!-- source-p 660 -->
<a id="39.4.16.7"></a>**7.**与税赋有关的物品包括：肉桂（*cinnamomum*）；长胡椒（*piper longum*）；白胡椒（*piper album*）；五球果叶（*folium pentasphaerum*）；异域叶（*folium barbaricum*）；香根（*costum*）；香豆蔻（*costamomum*）；甘松穗（*nardi stachys*）；土耳其桂皮（*cassia turiana*）；木桂皮（*xylocassia*）；没药（*smurna*）；豆蔻属香料（*amomum*）；生姜（*zingiberi*）；马拉巴树叶（*malabathrum*）；印度香料（*aroma indicum*）；松脂香胶（*chalbane*）；阿魏脂（*laser*）；*alche*；*lucia*；*sargogalla*；阿拉伯玛瑙（*onyx arabicus*）；小豆蔻（*cardamomum*）；木桂皮（*xylocinnamomum*）；细亚麻织物（*opus byssicum*）；巴比伦皮革（*pelles babylonicae*）；帕提亚皮革（*pelles parthicae*）；象牙（*ebur*）；印度铁（*ferrum indicum*）；*carpasum*；各类石料（*lapis universus*）；珍珠（*margarita*）；缟玛瑙（*sardonyx*）；雷石（*ceraunium*）；风信子石（*hyacinthus*）；绿宝石（*smaragdus*）；金刚石（*adamas*）；蓝宝石类石（*saffirinus*）；青绿石（*callainus*）；绿柱石（*beryllus*）；龟甲（*chelyniae*）；印度鸦片或申报过的鸦片（*opia indica vel adserta*）；生丝（*metaxa*）；丝绸或半丝绸衣料（*vestis serica vel subserica*）；染色亚麻帆布（*vela tincta carbasea*）；丝线（*nema sericum*）；印度宦官（*spadones indici*）；雄狮、雌狮（*leones, leaenae*）；豹（*pardi*）；花豹（*leopardi*）；黑豹（*pantherae*）；紫色染料（*purpura*）；摩尔人的羊毛（*marocorum lana*）；染料植物（*fucus*）；印度人的头发（*capilli indici*）。

<!-- source-p 661 -->
<a id="39.4.16.8"></a>**8.**若因遭遇风暴等不利天气而不得不卸下货物，两位神皇兄弟敕答，不应据此将货物判归没收。

<!-- source-p 662 -->
<a id="39.4.16.9"></a>**9.**安东尼努斯·庇乌斯神皇还敕答：若有人声称自己尚未达到法定年龄，且其为自用而运入奴隶，只是在申报内容上发生错误，应当宽恕他。

<!-- source-p 663 -->
<a id="39.4.16.10"></a>**10.**两位神皇兄弟还敕答：若有人并非出于欺诈，而是由于错误而使物品落入没收事由，应允许公税承包人以双倍税额为满足，并返还奴隶。

<!-- source-p 664 -->
<a id="39.4.16.11"></a>**11.**伟大的安东尼努斯敕答：若庄园的佃农或庄园主的奴隶在庄园内非法炼铁，而庄园主对此并不知情，则庄园主不承担任何处罚。

<!-- source-p 665 -->
<a id="39.4.16.12"></a>**12.**若有人已向公税承包人申报，却未缴纳税赋，而公税承包人允许其如此——他们通常会这样做——塞维鲁与安东尼努斯神皇敕答：物品不应被判归没收。因为他们说，申报一经记载，没收便不再适用；国库可以从公税承包人的财产或保证人的财产中获得清偿。

<!-- source-p 666 -->
<a id="39.4.16.13"></a>**13.**若被处罚者生前尚未启动相关程序，不得向其继承人请求支付罚款；其他罚则如此，税赋罚则亦然。

<!-- source-p 667 -->
<a id="39.4.16.14"></a>**14.**若公税承包人因付款人错误而收取了不应给付之物，塞维鲁与安东尼努斯神皇敕答，公税承包人应将其返还。
