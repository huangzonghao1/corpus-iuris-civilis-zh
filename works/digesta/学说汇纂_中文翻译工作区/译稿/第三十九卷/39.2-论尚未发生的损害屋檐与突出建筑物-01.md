<a id="39.2"></a>**39.2.0 论尚未发生的损害、屋檐与突出建筑物**（*De damno infecto et de suggrundis et proiectionibus*）。

<!-- source-p 150 -->
<a id="39.2.1"></a>**39.2.1**

<!-- source-p 151 -->
乌尔比安《告示评注》第一卷。

<!-- source-p 152 -->
若尚未发生损害的事项需要迅速处理，而裁判官认为延误会造成危险，他认为，将此事委托给市镇行政长官妥当，因为若将此类案件的管辖权保留给自己，反而会造成迟延。

<!-- source-p 153 -->
<a id="39.2.2"></a>**39.2.2**

<!-- source-p 154 -->
盖尤斯《行省告示评注》第二十八卷。

<!-- source-p 155 -->
所谓尚未发生的损害，是指损害尚未发生，但我们担心它将来会发生。

<!-- source-p 156 -->
<a id="39.2.3"></a>**39.2.3**

<!-- source-p 157 -->
保罗《告示评注》第四十七卷。

<!-- source-p 158 -->
“损害”和“判处”一词，均源于剥夺或减少财产，仿佛财产有所减损。

<!-- source-p 159 -->
<a id="39.2.4"></a>**39.2.4**

<!-- source-p 160 -->
乌尔比安《告示评注》第一卷。

<!-- source-p 161 -->
<a id="39.2.4.pr."></a>**序言。**若担保所定期限届满，裁判官或行省总督应视具体情形记载被告违约，或延长其期限；若需在当地调查，则应将此事交由市镇行政长官处理。

<!-- source-p 162 -->
<a id="39.2.4.1"></a>**1.**若当事人未在裁判官确定的期限内提供担保，应将请求担保者置于该物的占有之中。这里的“该物”既指全部财产，也指财产的一部分。

<!-- source-p 163 -->
<a id="39.2.4.2"></a>**2.**未让请求人进入占有的人，是否还应由市镇行政长官扣押其财物加以强制？我认为不应如此，但他应受事实诉权追究；即使裁判官准许请求人占有，而对方仍不让其进入，也应适用同一诉权。

<!-- source-p 164 -->
<a id="39.2.4.3"></a>**3.**因此，裁判官或行省总督将两项事务交由市镇行政长官处理，即担保和占有；其他事项则保留在自己的管辖权内。

<!-- source-p 165 -->
<a id="39.2.4.4"></a>**4.**若有人坚持不提供担保，以致请求人无法取得占有——此类事项通常须经审理案情后决定——则准许请求人取得占有的权力属于裁判官或行省总督，而非二人执政官。同样，只有裁判官或行省总督可以基于具体事由命令其退出占有。

<!-- source-p 166 -->
<a id="39.2.4.5"></a>**5.**裁判官说：“我命令先在缺席者住所向其送达通知。”所谓缺席，也包括未到法庭者；庞波尼乌斯也赞同这一解释。不过，裁判官谨慎地命令送达通知，而非将人从家中强行带出。我们应将“通知送至其住所”理解为：即使他住在他人家中，也应在其居住处通知。若他没有住所，则应通知该土地上的人，或其代理人，至少也应通知住户。

<!-- source-p 167 -->
<a id="39.2.4.6"></a>**6.**只有在确有可受通知的人时，才应理解为裁判官要求送达通知。若无此人，例如房屋属于遗产而尚无人接受继承，或者没有继承人、房屋亦无人居住，则告示这一部分不适用。但将通知文书张贴在房屋本身更为稳妥；因为受到通知的人可能因此派出代表。

<!-- source-p 168 -->
<a id="39.2.4.7"></a>**7.**对于未采取上述措施的人，将授予诉权，请求赔偿未提供尚未发生损害担保的相关财产价值。这里的价值并非指数量，而是指利益损失；诉权旨在补偿，而非处罚。

<!-- source-p 169 -->
<a id="39.2.4.8"></a>**8.**不过，该诉权以曾提出请求为条件；未曾请求者不得提起诉讼。这里所说的“请求”，严格而言是指在法庭席前提出请求，而非在其他地方提出。

<!-- source-p 170 -->
<a id="39.2.4.9"></a>**9.**若市镇离罗马城很近，以致即使没有市镇行政长官介入，当事人也能向裁判官或行省总督提出请求，那么可以说针对行政长官的此项诉权不适用；因为当事人本可自行请求裁判官或行省总督准许其取得占有。

<!-- source-p 171 -->
<a id="39.2.4.10"></a>**10.**由于此项诉权具有追偿财产利益的性质，故可对继承人提起、由继承人提起，且不受时效限制。

<!-- source-p 172 -->
<a id="39.2.5"></a>**39.2.5**

<!-- source-p 173 -->
保罗《告示评注》第一卷。

<!-- source-p 174 -->
<a id="39.2.5.pr."></a>**序言。**裁判官的职责，是使被准许占有的人也能经长期占有而取得该物的所有权。

<!-- source-p 175 -->
<a id="39.2.5.1"></a>**1.**若数名所有人都应提供担保，而其中一人未提供，则应将请求人置于其份额的占有之中。反之，若有数人请求他人提供担保，而一人拥有较贵重的房屋、另一人拥有较便宜的房屋，或者数人分别拥有同一房屋中价值不同的部分，则无论各自所有权份额大小如何，都应将他们平等地置于占有之中。

<!-- source-p 176 -->
<a id="39.2.5.2"></a>**2.**若所有权人和用益权人都请求对方提供尚未发生损害的担保，两人都应获准提出请求；因为承诺人不会因此受到不公待遇，他向各人承担的责任不会超过各人的利益。

<!-- source-p 177 -->
<a id="39.2.6"></a>**39.2.6**

<!-- source-p 178 -->
盖尤斯《行省告示评注》第一卷。

<!-- source-p 179 -->
有时，即使损害已经发生，若事先未订立担保，我们仍无权提起诉讼。例如，邻居的破败房屋倒塌并压毁我的房屋；大多数法学家甚至认为，若邻居将一切落下的瓦砾视为遗弃物，他也不得被强迫清除。

<!-- source-p 180 -->
<a id="39.2.7"></a>**39.2.7**

<!-- source-p 181 -->
乌尔比安《告示评注》第五十三卷。

<!-- source-p 182 -->
<a id="39.2.7.pr."></a>**序言。**裁判官说：“对于因本人名义提出的请求，我命令其作出承诺；对于以他人名义提出的请求，我命令其提供保证。请求人须宣誓，自己提出此请求并非出于诬告，且若其所代表的人亲自提出请求，也会提出此请求；担保期限依我审理案情后确定。若争议提供担保者是否为所有人，我将命令其在保留抗辩的条件下提供保证。对于在公共河流或其岸边实施的工程，我命令其提供十年期保证。未获担保的人，我将命令其进入为请求担保而指明的财产之占有；若有正当理由，也命令其取得该财产的占有。对于既不提供担保，又不允许他人进入占有或取得占有的人，我将授予诉权，使其承担的责任等同于：若就该事项依据我的裁定，或依据曾对该事项享有与我相同管辖权者的裁定，已提供担保时本应承担的责任。对于我已命人进入占有的财产，若现占有人就尚未发生损害提供保证，我将命令此前未获保证的人也同时进入该财产的占有。”

<!-- source-p 183 -->
<a id="39.2.7.1"></a>**1.**该告示旨在防范尚未发生的损害；其他诉权则旨在补偿已经发生的损害，例如《阿奎利亚法》之诉及其他诉权。告示未规定对已发生损害的救济：因为造成损害的动物通常至多使我们承担交付致害动物以代替赔偿的责任，那么没有生命的物体更不应使我们承担超过此限的责任；尤其是造成损害的动物仍然存在，而因倒塌造成损害的房屋已经不复存在。

<!-- source-p 184 -->
<a id="39.2.7.2"></a>**2.**因此，有人问：若房屋在提供担保前已经倒塌，所有人又不愿清除瓦砾并将其遗弃，是否可对他提起诉讼？尤利安曾被问及：若在订立尚未发生损害的口头担保前，存在瑕疵的房屋已经倒塌，瓦砾落入他人的房屋，该他人应如何获得损害赔偿？他答复说，若倒塌房屋的所有人愿意清除，就必须要求他清除全部瓦砾，包括无用的部分；他不仅应为未来损害提供担保，也应为已经发生的损害提供担保。若倒塌房屋的所有人不采取任何措施，则应向瓦砾落入其房屋的人颁发禁令，迫使邻居清除瓦砾，或将整座房屋视为遗弃物。

<!-- source-p 185 -->
<a id="39.2.8"></a>**39.2.8**

<!-- source-p 186 -->
盖尤斯《裁判官告示中有关尚未发生损害的标题》评注。

<!-- source-p 187 -->
只有在当事人并非因自身疏忽，而是由于某种障碍未能为自己寻求保护时，才可如此妥当地处理。

<!-- source-p 188 -->
<a id="39.2.9"></a>**39.2.9**

<!-- source-p 189 -->
乌尔比安《告示评注》第五十三卷。

<!-- source-p 190 -->
<a id="39.2.9.pr."></a>**序言。**此外，尤利安还认为，可以强迫所有人为已经发生的损害提供担保：既然损害尚未发生时采取保护措施尚且合理，房屋倒塌后也同样应提供保护。损害尚未发生时，每个人都必须提供担保，或者放弃其不愿维护的房屋。尤利安还说，若有人因时间紧迫或为公共事务离开而无法订立尚未发生损害的口头担保，裁判官公正地应当设法使有瑕疵房屋的所有人赔偿损害，或失去房屋。实际需要证明了尤利安意见的妥当性。

<!-- source-p 191 -->
<a id="39.2.9.1"></a>**1.**有人问：对于被河水冲来的物品，是否可以颁发禁令。特雷巴提乌斯记载，台伯河泛滥，将许多人的财物冲进他人的房屋时，裁判官颁发禁令，不得阻止所有人取回自己的财物，但前提是他们须就尚未发生的损害提供反向承诺。

<!-- source-p 192 -->
<a id="39.2.9.2"></a>**2.**阿尔费努斯也写道：若一片土层从你的土地滑落到我的土地，而你请求取回该土层，应授予我针对你的诉权，以追究已经发生的损害；拉贝奥赞同此意见。法官在审理返还滑落物的请求时，不得将我先前遭受的损害纳入裁量；而且，只有在你清除所有滑落物时，才应授予诉权。阿尔费努斯还说，只有土层尚未与我的土地结合、尚未成为其组成部分时，你才可以主张返还。同样，你不能主张取回已经移入我的土地并与我的土地结合的树木。我也不能起诉要求你无权保有该土层，因为它既已与我的土地结合，就已成为我的财产。

<!-- source-p 193 -->
<a id="39.2.9.3"></a>**3.**奈拉提乌斯写道，若一艘木筏被河水冲到我的土地上，只有在你也就过去的损害向我提供担保后，才可准许你取走。

<!-- source-p 194 -->
<a id="39.2.9.4"></a>**4.**有人问：若土地所有权属于一人，而地上建筑权属于另一人，地上权人应就尚未发生的损害作出承诺，还是应提供保证？尤利安写道，只要地上建筑存在瑕疵，土地所有人就应就土地和建筑物的瑕疵作出承诺；或者，由地上权人就二者提供保证。若两人均不履行，邻居应被置于占有之中。

<!-- source-p 195 -->
<a id="39.2.9.5"></a>**5.**塞尔苏斯明确写道，若提提娅享有你房屋的用益权，则应由所有人作出尚未发生损害的承诺，或由提提娅提供保证。若请求担保的人被置于占有之中，他就会阻止提提娅行使用益权。同一法学家还说，若用益权人不修缮房屋，所有人也应阻止他继续行使用益权。因此，若所有人不提供损害担保而被迫作出承诺，也应禁止其享有该项用益权。

<!-- source-p 196 -->
<a id="39.2.10"></a>**39.2.10**

<!-- source-p 197 -->
保罗《告示评注》第四十八卷。

<!-- source-p 198 -->
即使用益权属于他人，卡西乌斯也认为，所有人仍应作出承诺。除非所有权人就全部事项作出承诺，或用益权人提供保证，否则应将未获担保的请求人置于占有之中。尤利安写道，若所有人已作出承诺，而用益权人未向所有人提供保证，则应拒绝用益权人请求取得收益。若用益权人已就土地瑕疵承担责任，则所有人的相应权利应转移给用益权人。

<!-- source-p 199 -->
<a id="39.2.11"></a>**39.2.11**

<!-- source-p 200 -->
乌尔比安《告示评注》第五十三卷。

<!-- source-p 201 -->
对于取得质押物的债权人，我们应如何处理？他维护自己的权利，是否应作出承诺；还是因为他并非所有人而应提供保证？马尔凯鲁斯曾从相反角度讨论：是否应向质权人提供尚未发生损害的担保。他答复说，向质权人提供担保没有实际意义；从非所有人处买受的人也是如此，因为该口头担保不能对其发生效力。不过，我认为，最公平的办法仍是通过口头担保保护该债权人。

<!-- source-p 202 -->
<a id="39.2.12"></a>**39.2.12**

<!-- source-p 203 -->
保罗《告示评注》第四十八卷。

<!-- source-p 204 -->
在取得质押物的人之间，未获尚未发生损害担保的人享有更优地位，但以准许其取得占有并经长期占有取得该物为条件。

<!-- source-p 205 -->
<a id="39.2.13"></a>**39.2.13**

<!-- source-p 206 -->
乌尔比安《告示评注》第五十三卷。

<!-- source-p 207 -->
<a id="39.2.13.pr."></a>**序言。**以善意从非所有人处买受的人，是否应作出承诺而无需提供保证？有人持此见解。该意见有其理由：此人以自己的名义行事，与其提供保证相比，更应作出承诺。

<!-- source-p 208 -->
<a id="39.2.13.1"></a>**1.**无论是有体物的所有人，还是享有某项权利的人——例如地役权——就尚未发生的损害提供担保时，我认为均应作出承诺，而非提供保证，因为他们是以自己的名义行事，而非以他人名义行事。

<!-- source-p 209 -->
<a id="39.2.13.2"></a>**2.**若我的房屋与你的房屋之间另有其他并无瑕疵的房屋，应当考察：是否只有你应向我提供担保，还是该房屋所有人也应提供；是只有他提供，还是你们二人都应提供？较妥当的意见是二人都应提供，因为有瑕疵的房屋可能倒塌在无瑕疵的房屋上，进而使我受损。有人或许会说，若有其他房屋倒塌在无瑕疵的房屋上，损害便不是该无瑕疵房屋所致；但无瑕疵房屋的所有人本可通过请求尚未发生损害的担保保护自己，却没有这样做，因此理应承担责任。

<!-- source-p 210 -->
<a id="39.2.13.3"></a>**3.**请求尚未发生损害担保的人，必须先就不作诬告宣誓。因此，凡作此项宣誓的人，均可订立口头担保；无需调查其是否具有利害关系，或是否拥有邻近房屋。不过，是否应当提供担保，仍须由裁判官依其管辖权判断。

<!-- source-p 211 -->
<a id="39.2.13.4"></a>**4.**不应向在我的土地上散步、洗澡，或在我的客栈住宿的人提供担保。

<!-- source-p 212 -->
<a id="39.2.13.5"></a>**5.**拉贝奥说，应向邻居、其住户及住户的妻子提供担保，也应向与他们共同居住的人提供担保。

<!-- source-p 213 -->
<a id="39.2.13.6"></a>**6.**有人问：房屋所有人能否向自己的住户提供担保？萨宾认为，不应向住户提供担保：他们要么从一开始就租住有瑕疵的房屋，应自行承担责任；要么是房屋后来出现瑕疵，他们可以提起租赁之诉。后一意见更为妥当。

<!-- source-p 214 -->
<a id="39.2.13.7"></a>**7.**若有人在墓地旁建造房屋，或允许在自己的房屋旁建造墓地，之后不得请求其就尚未发生的损害提供担保，因为他实施了不合法行为。但若房屋会损害墓地，而墓地权利人对此并无可归责之处，则应由享有墓地权利的人请求担保。

<!-- source-p 215 -->
<a id="39.2.13.8"></a>**8.**现已确认，地上权人和用益权人均可有效地订立尚未发生损害的口头担保。

<!-- source-p 216 -->
<a id="39.2.13.9"></a>**9.**但马尔凯鲁斯认为，以善意从非所有人处买受的人，不享有尚未发生损害的口头担保请求权。

<!-- source-p 217 -->
<a id="39.2.13.10"></a>**10.**有人发布新工程告示后，是否仍应为其提供尚未发生损害的担保？尤利安对此作过讨论。他更赞成应当提供担保；同样，对于起诉主张对方无权加高建筑物的人，也应提供担保。尤利安还说，若某人可能受到 *quod vi aut clam* 禁令的追究，也应提供担保，因为有关房屋瑕疵或工程损害均未得到担保。

<!-- source-p 218 -->
<a id="39.2.13.11"></a>**11.**若某人因未获担保而被置于房屋占有之中，随后原房屋所有人虽拥有其他房屋，却请求现占有人就其现占有的房屋向自己提供尚未发生损害的担保，我们应考察此请求是否应予受理。尤利安写道：放弃有瑕疵房屋而保留无瑕疵房屋的人，是否会不当地向已开始占有有瑕疵房屋的人要求担保？毕竟他正是因为自己未提供此类损害担保，才丧失占有。确实，他为自己曾未提供担保的房屋请求他人担保，并不妥当。此意见是正确的。

<!-- source-p 219 -->
<a id="39.2.13.12"></a>**12.**若某人已为订立口头担保宣誓，却最终没有订立；此后他又想订立担保，是否还应再宣誓？我认为应当重新宣誓，因为他可能当时或现在才是在诬告。

<!-- source-p 220 -->
<a id="39.2.13.13"></a>**13.**若我请求以他人名义向我提供尚未发生损害的担保，我应宣誓：我所代表的人若亲自提出请求，也不会出于诬告。

<!-- source-p 221 -->
<a id="39.2.13.14"></a>**14.**但若我以一名即使亲自提出请求也无须宣誓的人之名义提出请求，例如释奴保护人或父母，则应认为无须宣誓。因为他本人无需宣誓，其代理人请求订立此项口头担保时也不应宣誓。

<!-- source-p 222 -->
<a id="39.2.13.15"></a>**15.**该口头担保中应写明期限：只有在期限内发生损害时，担保才适用；因为承诺人不应无限期受该担保拘束。因此，裁判官应根据案件情况及预期损害的性质，为该担保确定期限。

<a id="39.2.15"></a>**39.2.15**

<!-- source-p 227 -->
乌尔比安《告示评注》第五十三卷。

<!-- source-p 228 -->
<a id="39.2.15.pr."></a>**序言。**担保中规定的期限届满后，应依裁判官裁量重新提供担保。

<!-- source-p 229 -->
<a id="39.2.15.1"></a>**1.**若口头担保未约定期限：若这是当事人约定的结果，则期限届满时可提起承诺之诉；若系错误所致，较妥当的做法是在通常应当提供担保的期限届满后，请求裁判官免除该担保。

<!-- source-p 230 -->
<a id="39.2.15.2"></a>**2.**随后裁判官说：“对于在公共河流或其岸边实施的工程，我命令其提供十年期保证。”这里要求提供保证并为口头担保设定期限，是因为工程在公共土地上实施；若工程在他人私人土地上实施，裁判官也会命令提供保证。

<!-- source-p 231 -->
<a id="39.2.15.3"></a>**3.**应注意，此处仅就工程瑕疵提供担保，并不就土地瑕疵提供担保；但若工程在私人土地上实施，则须就土地和工程瑕疵提供担保。由于这里是公共土地，工程实施者无须就工程本身以外的其他土地瑕疵，提供尚未发生损害的保证。

<!-- source-p 232 -->
<a id="39.2.15.4"></a>**4.**因此，十年内发生的任何损害，均属于该口头担保的范围。

<!-- source-p 233 -->
<a id="39.2.15.5"></a>**5.**裁判官说“对于该工程”，应理解为“对于由该工程造成的损害”。

<!-- source-p 234 -->
<a id="39.2.15.6"></a>**6.**若工程在公共道路上实施，由于其位于他人土地上，必须提供保证。

<!-- source-p 235 -->
<a id="39.2.15.7"></a>**7.**裁判官应在审理案情后，依工程的性质确定期限。

<!-- source-p 236 -->
<a id="39.2.15.8"></a>**8.**无论某人是在修建公共道路，还是在公共道路上实施其他工程，都应适用担保，以免私人因此遭受损害。

<!-- source-p 237 -->
<a id="39.2.15.9"></a>**9.**对于其他公共场所，法律没有作特别规定；但依一般措辞，由于工程如同在他人土地上实施，仍应就尚未发生损害提供保证。

<!-- source-p 238 -->
<a id="39.2.15.10"></a>**10.**若公共场所由公共机构修缮，拉贝奥的意见最为正确，我们也遵循这一规则：若因场所或工程瑕疵造成损害，无须提供尚未发生损害的担保；但应为工程制定规则，确保其不损害邻人或造成损害。

<!-- source-p 239 -->
<a id="39.2.15.11"></a>**11.**若依据本告示未提供担保，裁判官应命令请求人进入看起来有倒塌危险的那一部分财产的占有。

<!-- source-p 240 -->
<a id="39.2.15.12"></a>**12.**但是否应准许其进入整座房屋的占有？我们应当考察此问题。萨宾认为，应准许其占有整座房屋；否则，若担心地上建筑部分造成损害，问题便无法解决。准许某人占有其既不能占有、也不能从中获益的部分，更毫无用处。萨宾的意见更为正确。
