# D.39.2 论尚未发生的损害、屋檐与突出建筑物（*De damno infecto et de suggrundis et proiectionibus*，第三段）

乌尔比安《告示评注》第八十一卷。

<!-- source-p 313 -->
<a id="39.2.24.pr."></a>**序言。**公共河流的使用为共同使用，正如公共道路和海岸一样。因此，任何人均可在这些地方进行公共工程、建造或拆除，但不得因此给任何人造成不便。故只就工程本身提供担保，且须有充分担保；对于场地瑕疵则不提供担保。这指的是某人实施的工程。反之，若担心损害源自场地瑕疵，绝不能说应当订立尚未发生损害的要式允诺：场地本身依其性质造成损害，而无人实施任何行为，难道还会有人怀疑找不到可以要求作出允诺的人吗？

<!-- source-p 314 -->
<a id="39.2.24.1"></a>**1.**因此，只有私人实施的工程才适用要式允诺。那么，若工程由公共机关实施，对其瑕疵应如何处理？显然，应向元首提出请求；若工程在行省实施，则应向行省总督提出请求。但所谓“工程瑕疵”，也应理解为不仅包括工程施工期间造成损害，也包括工程完工后发生的损害：例如，若建筑因施工不当而倒塌，又该如何处理？

<!-- source-p 315 -->
<a id="39.2.24.1a"></a>**1a.**本要式允诺还应写入继承人、继受人以及与该事项有关之人的名称。这里的“继受人”不仅包括概括继受全部财产的人，也包括仅继受该物所有权的人。

<!-- source-p 316 -->
<a id="39.2.24.2"></a>**2.**此外，还会订立一项不要求提供充分担保的要式允诺，内容是房屋、场地或工程不得因其瑕疵而造成损害。该允诺不仅适用于整座房屋，也适用于房屋的一部分。拉贝奥说，房屋或场地的瑕疵，是指外部因素作用于其上并使其变得不稳固的情形。因此，没有人会仅因土地沼泽或沙质而视其为有瑕疵、从而认为要式允诺违反；这是土地的自然瑕疵。因此，既不订立该项允诺，即使已经订立，也不会因此违反。

<!-- source-p 317 -->
<a id="39.2.24.3"></a>**3.**这一要式允诺所涵盖的，是仅限于违法造成的损害，还是包括一切由外部因素造成的损害？拉贝奥写道，若损害是由地震、河流之力或其他偶然事故造成，就不能据此提起损害之诉。

<!-- source-p 318 -->
<a id="39.2.24.4"></a>**4.**塞尔维乌斯也认为，若允诺人房屋上的瓦片被风吹落并损害邻人，只有在因建筑物本身瑕疵而发生时，他才承担责任；若是风势猛烈或其他具有神力的原因所致，则不承担责任。拉贝奥还提出理由：若不接受这一点，结论将不公平。究竟有哪座建筑足够坚固，能够抵御河流、海洋、风暴、火灾造成的倒塌或地震之力呢？

<!-- source-p 319 -->
<a id="39.2.24.5"></a>**5.**塞尔维乌斯还认为，若河水冲刷使一座公寓楼被毁，继而允诺权利人的房屋倒塌，他不能依据要式允诺取得任何赔偿，因为这既非工程瑕疵，也非场地瑕疵所致。但若水流损害了地基，房屋因此倒塌，他说要式允诺即被违反。两者差别很大：原本坚固的房屋是立即被河流之力冲毁，还是先遭到损害，随后才倒塌。拉贝奥认可这一意见。因为就阿奎利亚法而言，杀死一个健康的人与杀死一个已经变得虚弱的人，显然差异重大。

<!-- source-p 320 -->
<a id="39.2.24.6"></a>**6.**虽然因工程瑕疵造成损害时，要式允诺即被违反，但若工程由允诺人无法阻止之人实施，则该允诺不被违反。若允诺人本可阻止，则允诺会被违反。但若工程是由允诺人本人、其允诺所为之人，或其他本可被阻止之人实施，则该要式允诺会被违反。

<!-- source-p 321 -->
<a id="39.2.24.7"></a>**7.**此外，若有人已就炉窑可能造成的损害提供担保，而损害是由炉窑经营者的过失造成，多数人认为不属于该要式允诺的范围。

<!-- source-p 322 -->
<a id="39.2.24.8"></a>**8.**卡西乌斯也写道，若损害是以任何方式都无法避免的情形造成，该要式允诺便不适用。

<!-- source-p 323 -->
<a id="39.2.24.9"></a>**9.**维维亚努斯记载：若邻人土地上的树木被风暴折断，倒在我的土地上，并因此损害我的葡萄藤或庄稼，或者毁坏建筑物，那么包含“若因树木或场地瑕疵发生任何事情”字样的要式允诺并无效用，因为损害是由风力造成，而非树木瑕疵所致。但若这是树木年久造成的，我们可以说损害是由树木瑕疵所致。

<!-- source-p 324 -->
<a id="39.2.24.10"></a>**10.**维维亚努斯还说，若我已就我的房屋向你作出尚未发生损害的允诺，之后我的房屋因风暴之力倒在你的建筑物上并将其毁坏，则不应依据该要式允诺承担任何责任，因为你的损害并非由我房屋的瑕疵造成；除非我的房屋本身有瑕疵，以致即使最轻微的风暴也会使其倒塌。上述意见均属正确。

<!-- source-p 325 -->
<a id="39.2.24.11"></a>**11.**拉贝奥的以下意见也是正确的：须区分建筑物是因河流冲力而倒塌，还是此前已变得不坚固、之后才倒塌。

<!-- source-p 326 -->
<a id="39.2.24.12"></a>**12.**我们还应考察，何时才算造成损害；因为要式允诺涵盖的是因房屋、场地或工程的瑕疵所生损害。例如，我在自己的房屋中挖井，井挖成后切断了水脉，我是否应承担责任？特雷巴提乌斯说，我不因此承担尚未发生损害之责；因为在依法行使自己权利的情形中，不能认为损害是由我的工程瑕疵造成。但若我在自己土地上挖得过深，以致你的墙无法稳固，则尚未发生损害的要式允诺即被违反。

普罗库鲁斯说，某人在自己的土地上依法实施行为，即使曾向邻人作出尚未发生损害的允诺，也不因此受该允诺约束。例如，你的房屋毗邻我的房屋，而你依法加高了自己的房屋；又如，你在毗邻土地上挖掘水道或沟渠，引走我的水。虽然你在前一种情形中遮挡了我的采光，在后一种情形中引走了我的水，但我仍不能依据该要式允诺提起诉讼。原因是：若某人只是被阻止继续享有此前一直利用的利益，不应视为其造成损害。造成损害，与被阻止继续享有此前的利益，差别很大。我认为普罗库鲁斯的意见正确。

<a id="39.2.30.pr."></a>**序言。**若我在自己的土地上为引水而实施工程，并因该工程的瑕疵遭受损害，也适用尚未发生损害的要式允诺。工程通常会在他人土地上实施，因为某人依设于他人土地上的役权，可以在他人土地上施工。

<!-- source-p 345 -->
<a id="39.2.30.1"></a>**1.**我们应考察，对此项工程是应作出允诺，还是提供充分担保。问题在于，他是在他人土地上施工；就他人财产提供担保者应提供充分担保，就自己的财产提供担保者则作出本人名义下的允诺。因此，拉贝奥认为，为测量水道或修建水渠而施工的人也应提供充分担保，因为他是在他人土地上施工。但既然要求就其将要实施的工程作出要式允诺，结论就应是本人名义下的允诺已经足够；因为从某种意义上说，他是在就自己的事项提供担保。

<!-- source-p 346 -->
<a id="39.2.30.2"></a>**2.**“为引水”只是举例而言；此外，该要式允诺适用于一切工程。

若我的房屋毗邻我自己的其他房屋及你的房屋，问题是：若这些房屋对我造成瑕疵，你是否应就我的其他房屋可能遭受的损害向我提供担保，当然仅限于你作为所有人所占的份额？多数人的意见是肯定的。但我对此有所疑虑，因为我自己可以修缮自己的房屋，并通过合伙之诉或共有物分割之诉按份额请求偿还费用。又如，我与你共有一处房屋，该房屋有瑕疵，而你似乎不愿修缮，我们这一派的法学家认为你无须提供担保，因为我自己可以修缮，并通过合伙之诉或共有物分割之诉请求按份偿还支出。因此，订立该项担保也不会有多大用处，因为我可以通过其他方式补偿损害。显然，我们这一派法学家的意见是：若损害可以通过其他诉讼得到补偿，尚未发生损害的要式允诺就没有用处；前一种情形也应作同样理解。
