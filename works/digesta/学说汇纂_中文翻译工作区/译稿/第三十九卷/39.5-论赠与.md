<a id="5"></a>
# D.39.5 论赠与（*De donationibus*）

<!-- source-p 668 -->
<a id="39.5"></a>**39.5.0 论赠与**（*De donationibus*）。

<!-- source-p 669 -->
<a id="39.5.1"></a>**39.5.1**

<!-- source-p 670 -->
尤利安《学说汇纂》第十七卷。

<!-- source-p 671 -->
<a id="39.5.1.pr."></a>**序言**　赠与有数种。有人以使受领人立即取得所有权、且在任何情况下均不返还给自己为目的而给付；其所为别无其他原因，只为施行慷慨与宽厚：这才是严格意义上的赠与。有人给付财物，意在待某事发生后受领人才取得财物；这不称为严格意义上的赠与，而是附条件的赠与。又有人给付财物时，虽意在使受领人立即取得财物，但若某事发生或未发生，便希望财物返还给自己；这也不称为严格意义上的赠与，而是附解除条件的赠与。因死亡原因的赠与即属此类。

<!-- source-p 672 -->
<a id="39.5.1.1"></a>**1**　因此，我们说未婚夫与未婚妻之间的赠与有效时，是在严格意义上使用“赠与”一词，所指的是赠与人出于慷慨而给付某物，使受领人立即取得，且不希望因任何事由再取回。至于我们说，未婚夫若以未举行婚礼时取回财物为目的而向未婚妻赠与，可以请求返还，我们并非与前述规则矛盾，而是承认此种当事人之间可以成立附解除条件的赠与。

<!-- source-p 673 -->
<a id="39.5.2"></a>**39.5.2**

<!-- source-p 674 -->
尤利安《学说汇纂》第六十卷。

<!-- source-p 675 -->
<a id="39.5.2.pr."></a>**序言**　家子欲赠与钱款，依父亲命令为该钱款作出允诺的，赠与有效，犹如他提供了保证人。

<!-- source-p 676 -->
<a id="39.5.2.1"></a>**1**　若父亲打算将钱赠与提提乌斯，命令自己的家子为该钱款作出允诺，则应区分家子是否欠其父亲债务：若家子欠父亲的数额恰与其允诺的数额相同，则赠与应视为有效，犹如父亲命令其他任何债务人为该钱款作出允诺。

<!-- source-p 677 -->
<a id="39.5.2.2"></a>**2**　但若我打算把钱赠与提提乌斯，并命令你向提提乌斯作出允诺，而你原本也想赠与我同额钱款，则该赠与在所有相关当事人之间均已完成。

<!-- source-p 678 -->
<a id="39.5.2.3"></a>**3**　如果我依你的命令，向你想赠与的人允诺给付我自以为欠你的钱，法律处理则有所不同：我可以援用恶意抗辩保护自己；此外，我还可以提起不确定之诉，迫使要式口约债权人免除该要式口约。

<!-- source-p 679 -->
<a id="39.5.2.4"></a>**4**　同样，若我依你的命令，向你以为是你债权人的人允诺给付我自以为欠你的钱，我可以用恶意抗辩排除其请求；此外，我还可对要式口约债权人提起不确定之诉，使其免除该要式口约。

<!-- source-p 680 -->
<a id="39.5.2.5"></a>**5**　提提乌斯未作任何要式口约便把钱给我，但附有这样的条件：待塞伊乌斯成为执政官时，钱才归我所有。即使塞伊乌斯在精神失常或死亡后才就任执政官，该钱仍归我所有。

<!-- source-p 681 -->
<a id="39.5.2.6"></a>**6**　但是，某人打算赠钱给我，便把钱交给他人让其转交给我；若该人在转交前死亡，则该钱并未成为我的所有物，这一点是明确的。

<!-- source-p 682 -->
<a id="39.5.2.7"></a>**7**　我附条件赠与提提乌斯十枚钱币，让他用这笔钱为自己购买斯提库斯。我问：若奴隶在购买前死亡，我能否通过某种诉讼取回十枚钱币？答复是：这主要是事实问题，而非法律问题。若我给提提乌斯十枚钱币，目的仅在让他购买斯提库斯，除此之外便不会给付，那么斯提库斯死亡后，我可以提起返还之诉取回钱款。反之，若我原本也打算赠与提提乌斯十枚钱币，只因他当时正准备购买斯提库斯，才说我给钱是为了让他购买该奴隶，则购买奴隶只是赠与的原因，而非给付钱款的条件；斯提库斯死亡后，钱款应留在提提乌斯手中。

<!-- source-p 683 -->
<a id="39.5.3"></a>**39.5.3**

<!-- source-p 684 -->
乌尔比安《告示评注》第七十六卷。

<!-- source-p 685 -->
一般而言，赠与应当依此区分：给付的原因究竟是赠与本身，还是一项条件。若只是原因，则不得请求返还；若是条件，则可以请求返还。

<!-- source-p 687 -->

<!-- source-p 688 -->

<a id="39.5.5"></a>**39.5.5**

<!-- source-p 690 -->
乌尔比安《评萨宾》第三十二卷。

<!-- source-p 691 -->

<!-- source-p 692 -->
<a id="39.5.6"></a>**39.5.6**

<!-- source-p 693 -->
乌尔比安《评萨宾》第四十二卷。

<!-- source-p 694 -->
某人出于赠与目的，允许我从其土地上开采石块；石块一经开采，便立即成为我的所有物。他后来禁止我将石块运走，也不能使石块不再属于我，因为石块在某种意义上已通过交付归我所有。当然，若是我的雇工开采石块，则是替我开采。但若某人向我购买石块，或租用土地以便依法为自己开采石块，在他开采之前我改变主意，石块仍属我；若我在他开采之后才改变主意，则不能撤回他已完成的行为，因为所有人同意开采时，似乎已经完成交付。砍伐或移除树木，也适用同一规则。

<!-- source-p 695 -->
<a id="39.5.7"></a>**39.5.7**

<!-- source-p 696 -->
乌尔比安《评萨宾》第四十四卷。

<!-- source-p 697 -->
<a id="39.5.7.pr."></a>**序言**　家子不得赠与，即使他可以自由管理特有产也不得赠与；授予其特有产自由管理权，并不是为了让他挥霍财物。

<!-- source-p 698 -->
<a id="39.5.7.1"></a>**1**　那么，若家子基于正当理由而赠与，能否认为赠与有效？较可采的意见是肯定的。

<!-- source-p 699 -->
<a id="39.5.7.2"></a>**2**　再看另一种情况：某人授予家子特有产自由管理权，并明确补充说，授予此权也使其可以赠与；赠与是否有效？我毫不怀疑，他也可以赠与。

<!-- source-p 700 -->
<a id="39.5.7.3"></a>**3**　有时也可以根据家子的身份得出这一结论。比如家子具有元老院成员或其他显贵身份；那么，若父亲没有明确剥夺其赠与能力，既然授予他特有产自由管理权，何不认为父亲也授予了赠与能力？

<!-- source-p 701 -->
<a id="39.5.7.4"></a>**4**　禁止家子赠与的理由，同样禁止其作因死亡原因的赠与。尽管家子经父亲同意可以作因死亡原因的赠与，但父亲的同意一旦不存在，这种赠与也应被禁止。

<!-- source-p 702 -->
<a id="39.5.7.5"></a>**5**　但是应当记住：即使某人获准赠与，若未被特别准许作因死亡原因的赠与，他仍不得如此赠与。

<!-- source-p 703 -->
<a id="39.5.7.6"></a>**6**　以上规则适用于平民。至于拥有军营特有产或准军营特有产的人，由于他们具有订立遗嘱的能力，既可以作因死亡原因的赠与，也可以作其他赠与。

<!-- source-p 704 -->
<a id="39.5.8"></a>**39.5.8**

<!-- source-p 705 -->
保罗《评萨宾》第十五卷。

<!-- source-p 706 -->
自由释奴者为取得自由而承担的义务，不属于赠与；因为对此已有对价。

<!-- source-p 707 -->
<a id="39.5.9"></a>**39.5.9**

<!-- source-p 708 -->
蓬波尼乌斯《评萨宾》第三十三卷。

<!-- source-p 709 -->
<a id="39.5.9.pr."></a>**序言**　在他人房屋中免费居住，视为受赠；因为居住人未支付房租，本身就是取得了利益。赠与无须以有体物为对象也可以有效；例如，我出于赠与目的与债务人约定，在特定期限届满前不向其请求清偿。

<!-- source-p 710 -->
<a id="39.5.9.1"></a>**1**　从受赠财物中取得的孳息，不计入赠与数额；但若我赠与你的不是土地，而是取得孳息的权利，则已取得的孳息应计入赠与数额。

<!-- source-p 711 -->
<a id="39.5.9.2"></a>**2**　家子依父亲命令或同意所作的赠与，等同于父亲亲自赠与；也如同我同意你以自己的名义把我的财物赠与提提乌斯。

<!-- source-p 712 -->
<a id="39.5.9.3"></a>**3**　只有受赠人取得所有权的财物，才可能构成赠与。

<!-- source-p 713 -->
<a id="39.5.10"></a>**39.5.10**

<!-- source-p 714 -->
保罗《评萨宾》第十五卷。

<!-- source-p 715 -->
可以向不在场的人有效赠与：既可以派人送去，也可以命令对方保有其已经持有的物品。但若对方不知道自己持有的物品已赠与自己，或没有收受寄给自己的物品，他就不会取得该物品的所有权。即使物品是寄给受赠人的奴隶，也适用此规则；除非赠与人交给该奴隶时，意在使物品立即归受赠人所有。

<!-- source-p 716 -->
<a id="39.5.11"></a>**39.5.11**

<!-- source-p 717 -->
盖尤斯《论遗赠并评城市裁判官告示》第三卷。

<!-- source-p 718 -->

<!-- source-p 719 -->
<a id="39.5.12"></a>**39.5.12**

<!-- source-p 720 -->
乌尔比安《论争》第三卷。

<!-- source-p 721 -->
因赠与而承担债务的人，根据神圣安敦尼努斯·庇乌斯的敕答，仅在其履行能力范围内承担责任。但应扣除其对债权人所负的债务；对于其基于同一原因向他人承担的债务，则不应扣除。

<!-- source-p 722 -->
<a id="39.5.13"></a>**39.5.13**

<!-- source-p 723 -->
乌尔比安《论争》第七卷。

<!-- source-p 724 -->
某人想赠与我财物，便将财物交给我与提提乌斯共有的奴隶。该奴隶收受时，可能意在为其一名共有人取得财物，也可能意在为我与提提乌斯共同取得财物。问题是我可以采取什么行动。较可采的意见是：即使奴隶收受时意在为我的共有人，或为我与共有人共同取得财物，财物仍为我取得；因为若某人把物品交给我的代理人，意在使我取得，而代理人收受时却意在为自己取得，该代理人也不能为自己取得，反而是为我取得。

<!-- source-p 737 -->
<a id="39.5.18"></a>**39.5.18**

<!-- source-p 738 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 739 -->
<a id="39.5.18.pr."></a>**序言**　阿里斯托说，若某项交易兼有赠与性质，则在属于赠与的范围内不成立债务；蓬波尼乌斯记载，他也持此见解。

<!-- source-p 740 -->
<a id="39.5.18.1"></a>**1**　阿里斯托还认为：若我把奴隶交给你，条件是你五年后释放他，五年届满前不能起诉，因为其中似乎包含某种赠与。他说，若我交给你奴隶是要你立即释放他，则不同；此时不构成赠与，因此债务成立。不过，蓬波尼乌斯说，即使前一种情形，也应查明当事人实际约定了什么；设置五年期限，未必是为了赠与什么利益。

<!-- source-p 741 -->
<a id="39.5.18.2"></a>**2**　阿里斯托还说：若某人出于赠与目的将奴隶交付给你，条件是五年后释放，而该奴隶实属他人，则可以怀疑是否能因时效取得所有权，因为其中可能包含某种赠与。蓬波尼乌斯说，这类问题也会出现在因死亡原因的赠与中；他更倾向于认为，若赠与奴隶的条件是五年后释放，可以说随之发生时效取得。

<!-- source-p 742 -->
<a id="39.5.18.3"></a>**3**　拉贝奥说，若某人把他人之物赠与我，我为该物支出巨额费用，之后该物又被他人追夺，我对赠与人不享有任何诉权；但若赠与人有欺诈行为，我当然可以对其提起恶意之诉。

<!-- source-p 743 -->
<a id="39.5.19"></a>**39.5.19**

<!-- source-p 744 -->
乌尔比安《告示评注》第七十六卷。

<!-- source-p 745 -->
<a id="39.5.19.pr."></a>**序言**　我们适用这样的法律规则：涉及公共事务的赠与时，只考察某人是否出于正当公共原因作出或提出允诺。因此，若某人因公职或荣誉称号而允诺给付，便受该允诺拘束；否则不受拘束。

<!-- source-p 746 -->
<a id="39.5.19.1"></a>**1**　拉贝奥写道，下列服务的报酬不属于赠与：例如，我为你出庭、为你提供担保，或你在任何事情上利用了我的劳务或帮助。

<!-- source-p 747 -->
<a id="39.5.19.2"></a>**2**　受赠人不愿接受的，不能取得赠与利益。

<!-- source-p 748 -->
<a id="39.5.19.3"></a>**3**　某人把钱借给提提乌斯，约定由提提乌斯偿还给塞伊乌斯，而塞伊乌斯正是出借人想赠与钱款的人；之后，据说提提乌斯在出借人死亡后把钱交给塞伊乌斯。无论付款人知道还是不知道出借人已死亡，都应说钱归塞伊乌斯所有，因为钱原属付款人。不过，若提提乌斯不知道出借人已死亡，而且他借款时约定向塞伊乌斯偿还，则他即获解除债务。若我委托你把钱交给提提乌斯——我本想把钱赠给他——而你不知道我已死亡仍照办，则你可以对我的继承人提起委任之诉；若你明知我已死亡，则不得起诉。

<!-- source-p 749 -->
<a id="39.5.19.4"></a>**4**　某人把钱借给一名奴隶，之后该奴隶获释并就该钱作出要式口约，这不构成赠与，而是清偿债务。对未获监护人同意而负债的未成年人，也应作同样处理：若其之后在监护人同意下作出允诺，便是清偿债务。

<!-- source-p 750 -->
<a id="39.5.19.5"></a>**5**　此外，为某种原因而订立的要式口约，也不构成赠与。

<!-- source-p 751 -->
<a id="39.5.19.6"></a>**6**　因此，佩加苏斯认为，若我允诺给你一百枚钱币，条件是你宣誓会使用我的姓名，这不构成赠与；因为允诺是为取得某事，而该事已经实现。

<!-- source-p 752 -->
<a id="39.5.20"></a>**39.5.20**

<!-- source-p 753 -->
马尔凯鲁斯《学说汇纂》第二十二卷。

<!-- source-p 754 -->
<a id="39.5.20.pr."></a>**序言**　若释奴保护人被指定为法定应继份额的继承人，而释奴又嘱托他给付某物，且保护人已向请求履行遗嘱信托的受托人作出允诺，则不得强迫其给付，以免减少法律为保护人保留的应继份额。

<!-- source-p 755 -->
<a id="39.5.20.1"></a>**1**　对于这样的人，尚有疑问：他本可依《法尔基第法》保留一部分遗产，却为了遵从遗嘱人的意愿而允诺给付；较妥当的意见是，他不能违背自己已经承认的内容。正如他若已给付，便被视为履行了对遗嘱人的信义，且不得请求返还；同样，既然他已经承认遗嘱人的意愿，现又通过要式口约的诉讼程序违背该意愿，也理应遭到驳回。

<!-- source-p 756 -->
<a id="39.5.21"></a>**39.5.21**

<!-- source-p 757 -->
凯尔苏斯《学说汇纂》第二十八卷。

<!-- source-p 758 -->
<a id="39.5.21.pr."></a>**序言**　你接受我的委托，向我的债权人作出允诺，以便向我赠与钱款；此行为有效，因为债权人已收到其应得之物。

<!-- source-p 759 -->
<a id="39.5.21.1"></a>**1**　但若我命令自己的债务人向你作出允诺，作为对你的过度赠与，是否可以用赠与抗辩排除你的请求，尚有争议。我的债务人不能援用该抗辩排除你的诉讼，因为这等同于我先向债务人收取该款，再把钱赠给你，而你又把钱借给债务人。但是，若我的债务人尚未付款，我可以对其提起恢复原状之诉，要求撤销其超过法律限额向你作出的允诺，使其仅在限额内对你负债；若你已经从我的债务人处收取钱款，则我可以对你提起返还之诉，取回超过法定限额的部分。

<a id="39.5.33"></a>**39.5.33**

<!-- source-p 801 -->
赫尔莫革尼安《法学摘要》第六卷。

<!-- source-p 802 -->
<a id="39.5.33.pr."></a>**序言**　某人因赠与而向要式口约债权人允诺给付，之后又约定该钱款应予支付；债权人可以通过约定款项之诉追索，但该人仅在其履行能力范围内负责，而非承担全部责任。人们认为，优先适用约定款项的原因与起源，而非该诉讼本身的效力。因赠与而被判决承担责任的人，在判决执行之诉中请求仅在其履行能力范围内承担责任，也并非没有理由。

<!-- source-p 803 -->
<a id="39.5.33.1"></a>**1**　某人以赠与为由向提提乌斯支付钱款，约定提提乌斯立即将钱借给赠与人；此约定不妨碍所有权转移。因此，同一批钱币借给赠与人后，赠与人就这些钱币取得了新的所有权。

<!-- source-p 804 -->
<a id="39.5.33.2"></a>**2**　聋哑人并未被禁止赠与。

<!-- source-p 805 -->
<a id="39.5.33.3"></a>**3**　第一人想赠与你财物，而你也想把财物赠给第二人；第一人依你的意愿向第二人作出允诺，赠与即告完成。由于第一人并未赠与向其主张权利的第二人任何财物，他应承担全部责任，而非仅在履行能力范围内承担责任。若赠与人经受赠人委托，向其债权人作出允诺，也适用这一规则；因为在此情形下，债权人是在处理自己的事务。
