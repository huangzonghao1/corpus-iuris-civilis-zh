## 16.3.0　论寄托之诉及其反诉（*Depositi vel contra*）

### <a id="16.3.1"></a>16.3.1

**乌尔比安《评告示》第三十卷**

<a id="16.3.1.pr."></a>

**序言（pr.）** 寄托，是指将某物交给他人保管；其名称源于将物放置之意。前缀 *de-* 有加强语义的作用，表明与保管该物有关的事项均已整体托付于受寄人的信赖。

<a id="16.3.1.1"></a>

**1.** 裁判官告示规定：“对于并非因骚乱、火灾、房屋倒塌或海难而寄托的物品，我将授予按单倍额请求的诉讼；对于上述情形下寄托的物品，对受寄人本人授予按双倍额请求的诉讼；对其继承人，若所称行为系死者以恶意欺诈所为，则按单倍额；若系继承人本人所为，则按双倍额授予诉讼。”

<a id="16.3.1.2"></a>

**2.** 裁判官有理由将这些寄托事由区别开来，因为它们涉及因紧急情况而发生、并非出于自愿的偶发寄托。

<a id="16.3.1.3"></a>

**3.** 但是，只有在寄托人除因上述事由所生的迫近危险外，别无其他寄托原因时，才应认为其是因骚乱、火灾或其他类似事由而寄托。

<a id="16.3.1.4"></a>

**4.** 对这些原因作出区分有其正当理由：某人选择信赖他人而寄托物品，若物品未获返还，就应满足于请求单倍额；但若是在紧急情况下寄托，背信的罪责便更重，为维护国家利益，公共利益也要求予以惩戒。在这类情形下背弃信赖，实属有害。

<a id="16.3.1.5"></a>

**5.** 随寄托物一并交付的附属物，并不因此成为寄托物。例如，若将穿着衣服的人交付保管，衣服本身并未寄托；同样，若将系着笼头的马交付，寄托的也只是马。

<a id="16.3.1.6"></a>

**6.** 若双方约定，受寄人对过失也应负责，该约定有效；因为合同的规则由当事人约定确定。

<a id="16.3.1.7"></a>

**7.** 但是，若双方约定受寄人不对恶意欺诈负责，这种约定不能成立；因为它违反诚信与善良风俗，因而不应予以遵循。

<a id="16.3.1.8"></a>

**8.** 如果交给浴场经营者保管的衣物遗失，而他并未收取保管衣物的报酬，我认为应依寄托之诉追究其责任，且仅令其对恶意欺诈负责；但如果他收取了报酬，则应依租赁关系之诉处理。

<a id="16.3.1.9"></a>

**9.** 如果有人把奴隶送进面包坊，令其在那里受保管，而保管是有偿的，我认为可依雇赁关系之诉起诉面包坊经营者；但如果我因该奴隶被带入面包坊而收取报酬，我可以依出租关系之诉起诉。若奴隶的劳务被计入保管费用，则形成一种租赁关系；但因未支付金钱，应授予以限定词句提出之诉。反之，若对方只提供食物，而双方并未就劳务作任何约定，则适用寄托之诉。

<a id="16.3.1.10"></a>

**10.** 在雇赁关系以及我们说应授予以限定词句提出之诉的事务中，接收奴隶的人应对恶意欺诈和过失负责；但如果对方只提供食物，则仅对恶意欺诈负责。不过，我们应依庞波尼乌斯所说，考察对方公布了什么条件或双方约定了什么；但须知，即使公布了条件，接收者仍应对恶意欺诈负责，因为寄托关系中仅此一项责任属于其承担范围。

<a id="16.3.1.11"></a>

**11.** 如果我请你把我的物品带给提图斯，让他替我保管，我可以对你提起何种诉讼？庞波尼乌斯讨论了这一问题。他认为，我可以对你提起委任之诉，对实际接收物品的人提起寄托之诉；但若该人是以你的名义接收，你就应依委任关系对我负责，而他依寄托关系对你负责；在我依委任之诉起诉你时，你应使我能够行使对他的寄托之诉。

<a id="16.3.1.12"></a>

**12.** 如果我把物品交给你，并约定若提图斯不接收，你便负责保管，而他确未接收，那么应当考察适用的仅是寄托之诉，还是也包括委任之诉。庞波尼乌斯对此有所疑问；但我认为应适用委任之诉，因为委任的内容较为完整，并包含保管条件。

<a id="16.3.1.13"></a>

**13.** 庞波尼乌斯还讨论：如果我委任你保管某人代表我接收的物品，而你已经这样做，你应依委任关系还是寄托关系承担责任？他更赞同适用委任之诉，因为委任是这里首先成立的合同。

<a id="16.3.1.14"></a>

**14.** 庞波尼乌斯还讨论：如果我愿意在你处寄托物品，你却指示我改交给你的自由释奴，我能否对你提起寄托之诉？他说，如果我是以你的名义寄托，也就是仿佛由你负责保管，我可以对你提起寄托之诉；但若是你劝我改交给那名自由释奴，则我对你没有诉讼，而可对其提起寄托之诉。你也不依委任关系负责，因为我是在处理自己的事务。不过，如果你委任我在你承担风险的条件下把物品寄托给他，我看不出为何不能提起委任之诉。显然，如果你为他作了保证，拉贝奥说，无论如何保证人都要负责：不仅在接收寄托物的人实施恶意欺诈时如此，即使他没有实施欺诈，只要物品仍在其处，也应负责。试想，若接收寄托的人精神失常、是未成年人，或者根本没有继承人、遗产占有人或其他继受人，又该如何？因此，保证人应履行通常可依寄托之诉请求的事项。

<a id="16.3.1.15"></a>

**15.** 对于未经监护人同意而接收寄托物的未成年人，是否可以提起寄托之诉，存在疑问。但可以确认的是，如果物品寄托给了已经能够理解恶意欺诈的未成年人，且其实施了欺诈，就可以起诉；即使没有欺诈，只要他因此变得更富有，也可在其获益范围内对其提起诉讼。

<a id="16.3.1.16"></a>

**16.** 如果寄托物返还时已经受损，可以如同未曾返还一样提起寄托之诉；因为物品既已受损，可以说它并非在没有恶意欺诈的情况下返还。

<a id="16.3.1.17"></a>

**17.** 即使是我的奴隶寄托了物品，我仍可提起寄托之诉。

<a id="16.3.1.18"></a>

**18.** 如果我把物品寄托给奴隶，随后对获释后的奴隶起诉，马尔凯鲁斯说诉讼不能成立。虽然我们通常认为，某人应对其在奴隶身份期间实施的恶意欺诈负责，因为违法行为及诺克萨责任均随行为人本人，但此处仍应转而寻求其他可适用的诉讼。

<a id="16.3.1.19"></a>

**19.** 该诉讼也可由遗产占有人及其他〔底本尖括号补入：继受人〕提起；依《特雷贝利安元老院决议》受返还遗产的人，亦可提起。

<a id="16.3.1.20"></a>

**20.** 在寄托之诉中，不仅可追究先前的恶意欺诈，也可追究后续的恶意欺诈，即争讼程序确定之后发生的欺诈。

<a id="16.3.1.21"></a>

**21.** 因此，涅拉提乌斯写道：如果寄托物并非因恶意欺诈而遗失，却在诉讼成立后重新找回，仍可正当地强制被告返还；在其返还之前，不应判其免责。涅拉提乌斯还说，即使起诉时你无法返还，例如仓库恰好关闭，只要你在判决前已经能够返还，就应判令你返还；否则应判令你承担责任，因为此时物品已在你处。只有在物品不在你处时，才需要考察你当时未持有物品是否出于恶意欺诈。

<a id="16.3.1.22"></a>

**22.** 尤利安《学说汇纂》第十三卷也记载，寄托人可以立即提起寄托之诉；因为接收人仅因寄托人请求返还而拒绝返还，就已构成欺诈。马尔凯鲁斯则说，拒绝返还并非总是恶意欺诈：例如物品在行省，或存于仓库且在判决时无法开启；又或者寄托所附条件尚未成就。

<a id="16.3.1.23"></a>

**23.** 毫无疑问，寄托之诉属于诚信诉讼。

<a id="16.3.1.24"></a>

**24.** 因此，应认为孳息、物品的一切附随利益以及子畜也纳入该诉讼范围，以免请求仅及于物品本身。

<a id="16.3.1.25"></a>

**25.** 如果你出售了寄托物，后来又将其买回并恢复寄托状态，即使此后物品并非因恶意欺诈而灭失，你仍须依寄托之诉承担责任，因为你出售物品时已经实施欺诈。

<a id="16.3.1.26"></a>

**26.** 在寄托之诉中，也可以就诉讼标的的价值宣誓。

<a id="16.3.1.27"></a>

**27.** 不仅在我的奴隶寄托物品时如此；如果以善意为我服役之人寄托了属于我的物品，公平起见，也应授予我诉讼。

<a id="16.3.1.28"></a>

**28.** 同样，如果我对奴隶享有用益权，而他所寄托之物属于与我有关的特有产，或者是我的物品，我也可以提起同一诉讼。

<a id="16.3.1.29"></a>

**29.** 同样，如果遗产中的奴隶寄托了物品，后来接受遗产的继承人可以提起诉讼。

<a id="16.3.1.30"></a>

**30.** 如果奴隶寄托了物品，无论他仍然活着还是已经死亡，主人均可有效提起该诉讼；奴隶本人获释后则不能起诉。但即使奴隶已被转让，仍由他寄托时的主人享有诉权，因为应考察合同成立之时。

<a id="16.3.1.31"></a>

**31.** 如果寄托人是由两人共有的奴隶，各主人仅就其份额享有寄托之诉。

<a id="16.3.1.32"></a>

**32.** 如果你把奴隶寄托的物品返还给提图斯，而你误以为他是该奴隶的主人、实际上并非如此，塞尔苏斯说，你不依寄托之诉承担责任，因为你并无欺诈。该奴隶的主人可以对接收物品的提图斯起诉；若提图斯交出物品，主人可提起所有物返还之诉；但如果提图斯明知物品属于他人仍将其耗用，就应被判承担责任，因为他以欺诈方式使自己不再占有该物。

<a id="16.3.1.33"></a>

**33.** 尤利安提出了一个精妙问题：如果奴隶把钱寄托在我处，约定我将钱交给主人以换取奴隶的自由，而我确已交付，我是否依寄托之诉承担责任？他在《学说汇纂》第十三卷中写道，如果我明确告知你该款是以寄托方式交给我的，并据此为其自由支付，你就不能对我提起寄托之诉，因为你明知情形而寄托，我没有欺诈。但如果我把钱当作自己的钱支付，以换取奴隶的自由，我就应承担责任。我认为这一意见正确：此处我不仅是在没有恶意欺诈的情况下未返还，而且事实上并未返还；返还寄托物与以自己的财物作出给付，是两回事。

<a id="16.3.1.34"></a>

**34.** 如果钱款自始以这样的条件寄托于你：你愿意时可以使用，那么在你实际使用之前，你仍依寄托之诉承担责任。

<a id="16.3.1.35"></a>

**35.** 经常会发生寄托物或钱币的风险由受寄人承担的情形，例如双方对此作了明确约定。尤利安还写道，如果某人主动提出接收寄托物，也就使自己承担了寄托物的风险；不过，他承担的不仅是恶意欺诈，还包括过失和保管责任，但不包括意外事故。

<a id="16.3.1.36"></a>

**36.** 如果钱款存放在封印的钱袋中，寄托人的一名继承人前来请求返还，应如何满足其请求？应在裁判官面前，或在受尊敬之人在场时取出钱款，并按其继承份额支付。即使拆开封印，只要是在裁判官授权下或有受尊敬之人在场，也不违反寄托规则。剩余钱款可以在先由裁判官或见证封印拆除的人重新加盖封印后留在受寄人处，但该继承人须愿意如此；若其不愿意，则应将钱款存放在神庙中。若寄托物不可分割，继承人应全部交付，但请求人须就超过其份额的部分提供适当担保；若未提供担保，则应将物品存放于神庙，受寄人由此免除一切诉讼责任。

<a id="16.3.1.37"></a>

**37.** 尤利安《学说汇纂》第十三卷记载了这样一个案例：寄托人死亡后，两人争执不下，各自声称自己是唯一继承人。尤利安说，应将物品交给愿意对另一人承担责任、使受寄人免受追诉的一方；如果双方都不愿承担这一责任，他认为最妥当的做法是，不强迫受寄人接受裁判官的审判，而应将物品存放于某座神庙，直至遗产归属得到裁判。

<a id="16.3.1.38"></a>

**38.** 如果某人在多人面前宣读寄托在其处的遗嘱文书，拉贝奥说，可以依寄托之诉就遗嘱文书起诉。我认为，如果其在一些人在场时宣读遗嘱，是为了泄露立遗嘱人的秘密意思，也可以提起侮辱之诉。

<a id="16.3.1.39"></a>

**39.** 如果侵夺者或窃贼寄托了物品，马尔凯鲁斯在《学说汇纂》第六卷中也认为，他们可以正当地提起寄托之诉；因为他们也有利益，即可能因该物而承担责任。

<a id="16.3.1.40"></a>

**40.** 如果有人请求返还寄托的银器或金器，是否既应说明其种类，也应说明重量？较妥当的做法是两者都说明，例如称其为酒杯、盘子或酒钵，并补充材质和重量。紫色织物或羊毛也一样，应列明重量；但如果重量数量不确定，应允许请求人通过宣誓获得救济。

<a id="16.3.1.41"></a>

**41.** 如果寄托的是封印的箱子，诉请应仅涉及箱子，还是也应列明箱内物品？特雷巴提乌斯说，应请求返还箱子，而不应逐项就箱内物品提起寄托之诉；即使箱中物品已经展示并一并寄托，也应补充列明衣物等具体物品。拉贝奥则说，寄托箱子的人也应视为一并寄托了其中每件物品，因此也应就这些物品起诉。若接收寄托的人不知道箱内有物品，又该如何？这并无太大影响，因为他已经接收了该寄托物。因此，我认为，即使箱子是封印的，也可以就其中物品提起寄托之诉。

<a id="16.3.1.42"></a>

**42.** 家子依寄托关系承担责任，这是确定的，因为他也依其他诉讼承担责任；但也可以对其父亲起诉，不过仅限于特有产范围。奴隶亦同，应对其主人起诉。尤利安确曾写道，我也认为，如果诉讼是以处于他人权力之下的人之名提起，判决时还应计入支配者通过该人取得或被其欺诈侵占的利益；因此，不仅应计入订约之人的欺诈，也应计入其权力支配者的欺诈。

<a id="16.3.1.43"></a>

**43.** 如果物品寄托给两人，可以对其中任何一人提起诉讼；即使已对一人起诉，另一人也不因此免责，因为他们是通过履行而非通过债权人选择其中一人而免责。因此，如果两人都实施欺诈，而其中一人已给付损害额，另一人就不再被起诉；此与两名监护人的情形相同。但如果其中一人完全无力给付或只能部分给付，就应转而向另一人追索。如果其中一人没有实施欺诈而获判免责，也同样可以转而起诉另一人。

<a id="16.3.1.44"></a>

**44.** 但如果物品由两人共同寄托，且约定其中任何一人均可取走全部物品，那么每一人都可以就全部物品提起诉讼；如果约定各人仅寄托与其利益相应的部分，则应仅就该部分作出判决。

<a id="16.3.1.45"></a>

**45.** 如果我把物品寄托给你，并约定你死后返还，那么我既可对你提起寄托之诉，也可对你的继承人提起；因为我可以改变意思，在你死亡之前请求返还寄托物。

<a id="16.3.1.46"></a>

**46.** 同样，如果我约定在我死后返还，我和我的继承人都可以提起寄托之诉；我本人则可通过改变意思，在生前请求返还。

<a id="16.3.1.47"></a>

**47.** 由于该诉讼仅追究恶意欺诈，因此有人问：如果继承人不知道遗嘱人曾将物品寄托或借用出去，便把该物卖掉，是否承担责任？因为他没有欺诈，不应就物品本身承担责任。但他是否仍应就实际到手的价款承担责任？较妥当的意见是应承担责任，因为他不返还已经到手的价款，本身即构成欺诈。

### <a id="16.3.2"></a>16.3.2

**保罗《评告示》第三十一卷**

那么，如果继承人尚未收取价款，或者以低于应有价格出售，该怎么办？他只须让与自己所享有的诉权。

### <a id="16.3.3"></a>16.3.3

**乌尔比安《评告示》第三十一卷**

显然，如果他能够买回物品并返还却不愿这样做，就不能免除过失责任；这与他已经买回物品，或因其他原因重新取得物品，却以自己曾在不知情时将其出售为由而拒绝返还，并无不同。

### <a id="16.3.4"></a>16.3.4

即使他并非继承人，只是误以为自己是继承人而出售物品，也应同样剥夺其所得利益。

### <a id="16.3.5"></a>16.3.5

**乌尔比安《评告示》第三十卷**

<a id="16.3.5.pr."></a>

**序言（pr.）** 对被指称接收了寄托物的人，授予寄托反诉。在该诉讼中，正当地不允许宣誓确定诉讼标的价值：因为争议并非涉及背弃信赖，而是涉及接收寄托物之人的损失补偿。

<a id="16.3.5.1"></a>

**1.** 对寄托给诉讼保管人的物品，可以提起寄托之诉。但如果与该保管人约定在某一特定地点出示寄托物，而他未在该处出示，显然应由他承担责任；如果约定了多个地点，则由他选择在哪一处出示。若未约定地点，则应通知他到裁判官处出示。

<a id="16.3.5.2"></a>

**2.** 如果诉讼保管人想要辞去职务，应当如何处理？庞波尼乌斯说，他应向裁判官申请，并在裁判官授权后通知选任他的人，将物品返还给届时到场的一方。但我认为，这并非总是正确的：通常不应允许他违反寄托约定而辞去已经接受的职务，除非确有极为正当的理由。即使允许辞任，也很少应将物品返还给先到的一方；而应依裁判官的裁量，将物品存放在某座神庙中。

### <a id="16.3.6"></a>16.3.6

**保罗《评告示》第二卷**

严格而言，诉讼保管人所受领的寄托，是指多人将物品交付给他，约定由他在特定条件下共同为各方保管，并在条件满足时返还。

### <a id="16.3.7"></a>16.3.7

**乌尔比安《评告示》第三十卷**

<a id="16.3.7.pr."></a>

**序言（pr.）** 如果诉讼保管人受寄了一名奴隶，约定要对其施以审讯，并因怜悯而解开奴隶的镣铐，或让其离开受拘禁的恶劣住处，我认为该行为近似恶意欺诈；因为他知道该奴隶将被用于何种目的，却不合时宜地施以怜悯。他本可以拒绝接收这类寄托，而不应欺骗寄托人。

<a id="16.3.7.1"></a>

**1.** 因死者的欺诈，可以对其继承人提起寄托之诉，要求其承担全部责任。虽然通常继承人仅在其实际取得的遗产范围内因死者欺诈而负责，但此处的欺诈源于合同，并涉及对物的追索，因此一名继承人应承担全部责任；有数名继承人的，各按其继承份额负责。

<a id="16.3.7.2"></a>

**2.** 银行业者破产时，通常优先考虑存款人的利益，也就是将钱款寄存于银行者的利益；这不包括把钱款交给银行家收取利息、与银行家共同经营，或通过银行家经营的人。在出售破产人财产清偿债务时，即使尚未讨论其他优先权，也应优先清偿存款人；但后来收取过利息的人不在此列，因为这表明他们已放弃寄托关系。

<a id="16.3.7.3"></a>

**3.** 还有人问，应按各寄托人的先后顺序处理，还是同时考虑所有存款人？确定的规则是，应同时受理；这由元首的敕答所表明。

### <a id="16.3.8"></a>16.3.8

**帕皮尼安《疑义集》第九卷**

这项优先权并不只在银行家财产中查获的寄托款项数额范围内行使，而适用于该欺诈人全部财产。这一做法基于公共利益而确立，因为银行业为必要之用。当然，必要支出始终应优先扣除；通常须先扣除该项支出，再计算可供清偿的财产。

### <a id="16.3.9"></a>16.3.9

**保罗《评告示》第十七卷**

在寄托之诉中，如果因死者的行为而起诉其数名继承人中的一人，我应仅按其继承份额起诉；但如果所追究的是该继承人自己的不法行为，则不按份额起诉。这是有理由的，因为责任金额取决于该继承人本人所实施的欺诈，而其欺诈使其承担全部责任。

### <a id="16.3.10"></a>16.3.10

**尤利安《米尼基乌斯著作》第二卷**

对没有实施欺诈的共同继承人，也不得提起寄托之诉。

### <a id="16.3.11"></a>16.3.11

**乌尔比安《评萨宾著作》第四十一卷**

奴隶所寄托的物品，受寄人依诚信原则将其返还给奴隶，是完全正当的；因为收受某物后否认曾经收受，不符合诚信，而应返还给交付者。但前提是返还时毫无欺诈，也不存在任何过失嫌疑。萨宾对此作了解释，并补充说：“也没有任何理由使他认为主人不愿意返还。”这句话适用于受寄人确有理由怀疑的情形；除此之外，只须具备善意即可。即使奴隶此前曾窃取该物，只要受寄人并不知情，或者认为主人不会反对这次返还，也可以免责；因为法律要求的是善意。不仅在奴隶仍为奴隶时返还如此；即使返还给获释或被转让的奴隶，只要存在正当理由，例如受寄人不知道奴隶已获释或被转让，也可免责。庞波尼乌斯写道，所有债务人均适用同一规则。

### <a id="16.3.12"></a>16.3.12

**庞波尼乌斯《评萨宾著作》第二十二卷**

<a id="16.3.12.pr."></a>

**序言（pr.）** 如果物品在亚洲寄托，并约定在罗马返还，应视为双方意在由寄托人而非受寄人承担将物品运至罗马的费用。

<a id="16.3.12.1"></a>

**1.** 寄托物应在受寄人现时能够无欺诈地返还该物之处返还；最初在哪一地点寄托，并不重要。所有诚信诉讼通常均适用同一规则。但若原告愿意自负费用和风险将物品运至罗马，就应准许其如此请求；因为在出示之诉中也适用这一做法。

<a id="16.3.12.2"></a>

**2.** 对诉讼保管人，应正当地提起诉讼保管寄托之诉；对其继承人也应授予该诉讼。

<a id="16.3.12.3"></a>

**3.** 正如依要式口约或遗嘱应给付的物品，在诉讼正式成立后若因物品灭失而发生损失，由原告承担；寄托物也一样，自提起寄托之诉之日起由受寄人承担风险，但前提是被告在诉讼正式成立时能够返还而未予返还。

### <a id="16.3.13"></a>16.3.13

**保罗《评告示》第三十一卷**

<a id="16.3.13.pr."></a>

**序言（pr.）** 如果某人拒绝承认自己接收了寄托物，并非为了对抗物主，而是因为他不认为请求该物的人是真正的代理人，或不认为其是寄托人的继承人，那么他没有实施恶意欺诈。但后来如果他得知对方确有该身份，而仍不愿返还，就可以对他提起诉讼，因为从那时起，他才开始实施欺诈。

<a id="16.3.13.1"></a>

**1.** 也可以就寄托物本身提起返还之诉，但只有在发生欺诈之后才可提起；并非某人仅因接收寄托物这一事实便负有返还之诉上的责任，而是因为他实施了恶意欺诈。

### <a id="16.3.14"></a>16.3.14

**盖尤斯《评行省告示》第九卷**

<a id="16.3.14.pr."></a>

**序言（pr.）** 如果寄托人有数名继承人，据说只要多数继承人已经接受继承，就应将物品返还给到场者。这里的多数并非按人数计算，而应按各继承份额的大小判断；并应提供适当担保。

<a id="16.3.14.1"></a>

**1.** 无论是对受寄人本人还是对其继承人提起诉讼，如果物品依其性质在判决前灭失，例如奴隶死亡，萨宾与卡西乌斯都说，被诉者应获免责；因为自然灭失的风险理应由原告承担，尤其是即使物品已经返还给原告，也同样会灭失时。

### <a id="16.3.15"></a>16.3.15

**尤利安《学说汇纂》第十三卷**

允许他人把自己所有的物品寄托在自己处，或请求使用自己所有物品的人，不因寄托或借用之诉承担责任；正如出租自己所有的物品或请求暂时无偿使用该物的人，不因此依租赁或容许占有关系承担责任。

### <a id="16.3.16"></a>16.3.16

**阿非利卡努斯《疑义集》第七卷**

如果你寄托给我的物品被我转而寄托给他人，而该人实施欺诈，那么我仅因其欺诈而承担责任，且责任仅限于应将我对他的诉权让与给你。

### <a id="16.3.17"></a>16.3.17

**弗洛伦提努《法学阶梯》第七卷**

<a id="16.3.17.pr."></a>

**序言（pr.）** 一人或数人均可寄托物品，但交给诉讼保管人的，只能由数人共同寄托；因为只有在某项物品发生争议时，才会采用这种方式。因此，在这种情况下，每一人都被视为就全部物品作出寄托；多人寄托共有物时则并非如此。

<a id="16.3.17.1"></a>

**1.** 寄托物的所有权仍属于寄托人；占有通常也仍属于寄托人，除非物品交给诉讼保管人，此时才由诉讼保管人占有。设立这种寄托，是为了使该期间不计入任何一方的占有期间。

### <a id="16.3.18"></a>16.3.18

**涅拉提乌斯《札记》第二卷**

对于因骚乱、火灾、房屋倒塌或海难而寄托的物品，可以因死者的欺诈对其继承人提起诉讼；继承人按其继承份额承担单倍额责任，且诉讼期间为一年。对受寄人本人，则可请求全部责任、双倍额，并且诉权永久存续。

### <a id="16.3.19"></a>16.3.19

**乌尔比安《评告示》第十七卷**

尤利安与马尔凯鲁斯认为，家子可以正当地提起寄托之诉。

### <a id="16.3.20"></a>16.3.20

**保罗《评告示》第十八卷**

如果你并非因恶意欺诈而遗失寄托物，你既不依寄托之诉承担责任，也无须保证日后找回时予以返还；但如果该物后来又到了你手中，你就依寄托之诉承担责任。

### <a id="16.3.21"></a>16.3.21

**保罗《评告示》第六十卷**

<a id="16.3.21.pr."></a>

**序言（pr.）** 如果物品寄托给家子，而他脱离家父权后仍持有该物，就不应在一年期间内对其父亲提起特有产之诉；应直接起诉家子本人。

<a id="16.3.21.1"></a>

**1.** 特雷巴提乌斯认为得更进一步：即使物品原先寄托给奴隶，而该奴隶获释后仍持有物品，也应对其本人授予诉讼，而不是对主人提起；尽管在其他事由下，通常不对获释者授予诉讼。

### <a id="16.3.22"></a>16.3.22

**马尔凯鲁斯《学说汇纂》第五卷**

如果两名继承人以欺诈方式处分了寄托于死者处的物品，在某些情形下，他们应按份承担责任。例如，死者处寄托了一万钱币，两名继承人将其分开，各取五千，而且两人都有清偿能力，那么他们应按份负责，因为原告的利益并未受到更大的损害。但如果他们将一只盘子熔化，或容许他人将其熔化，或以欺诈方式处分其他特定物品，就可以对他们请求全部责任，仿佛他们各自都承诺保管该物；因为显然，每个人都以欺诈方式对全部物品行事，而若不返还全部物品就无法完成返还。不过，认为只有完整返还物品才能使被诉者免责的人，也并非毫无道理；但若物品未获返还，仍应判令其按自己取得继承人身份的份额承担责任。

### <a id="16.3.23"></a>16.3.23

**莫德斯蒂努《区别论》第二卷**

因寄托之诉被起诉的人，可以就向奴隶提供的口粮费用，在同一法官面前有效提起诉讼。

### <a id="16.3.24"></a>16.3.24

**帕皮尼安《疑义集》第九卷**

“卢基乌斯·提图斯致塞姆普罗尼乌斯：我以此亲笔书信告知你，今日经代理奴隶斯蒂库斯点交给我的一百钱币现由我持有，供你知悉；你愿在何时何地取回，我都会立即交付。”问题涉及利息的累积。我答复说，寄托之诉可以适用；因为“托付”与“寄托”还有什么区别？但只有在双方约定返还原来的那些钱币时，才确属寄托；若约定返还同等数额的钱款，该关系便超出了寄托的通常界限。在这种情形下，如果约定返还同等数额而非原物，寄托之诉不适用，就很难说还能计付利息。诚信诉讼中，关于利息，裁判官的裁量权确实可以与要式口约相当；但要求一名曾以收受款项给予他人便利的受寄人支付迟延发生之前的利息，违反诚信及寄托的性质。不过，如果双方自始约定应付利息，就应遵循合同约定。

### <a id="16.3.25"></a>16.3.25

**帕皮尼安《答复》第三卷**

<a id="16.3.25.pr."></a>

**序言（pr.）** 父亲接收了一名自权女子在订婚当日或其后获赠的物品。对其继承人，可以正当地提起出示之诉，也可以提起寄托之诉。

<a id="16.3.25.1"></a>

**1.** 某人将未封缄的钱款寄托在自己处，约定返还同等数额，却把钱款挪作己用；迟延后，应在寄托之诉中判令其连同利息一并给付。

### <a id="16.3.26"></a>16.3.26

**保罗《答复》第四卷**

<a id="16.3.26.pr."></a>

**序言（pr.）** 普布利娅·梅维娅前往丈夫处时，将一只上锁的箱子连同衣物和用品托付给盖娅·塞娅，并对她说：“我若平安归来，你就把东西还给我；倘若我遭遇不测，就交给我与前夫所生的儿子。”她无遗嘱死亡后，我询问受托保管的物品应返还给儿子还是丈夫。保罗答复：应返还给儿子。

<a id="16.3.26.1"></a>

**1.** 卢基乌斯·提图斯作出如下书面承诺：“E labon kai exw eis logon parakatavykys ta progegrammena tou arguriou dynaria muria, kai panta poiysw kai sumfwnw kai hwmologysa, hws progegraptai: kai sunevemyn xorygysai soi tokon hekastys mnas hekastou mynos obolous tessaras mexri tys apodosews pantos tou arguriou.”〔底本以拉丁字母转写希腊文。〕其意为：“我已收讫并以寄托名义持有上述一万第纳尔；我将依前述内容办理、同意并承诺；我还承诺，在全部银币返还前，每月按每一米那支付四奥波尔的利息；底本所附拉丁释义则记作四阿斯。”我问能否请求利息。保罗答复：本案所涉合同已超出寄托金钱的通常范围，因此也可以依寄托之诉，按照约定请求利息。

<a id="16.3.26.2"></a>

**2.** “提图斯致塞姆普罗尼乌斯诸人：我持有你们交给我的约十磅黄金、两只圆盘及一个封印的钱袋。其中有十是你们在提图斯处寄托的；另有十项记在 *trophimati* 名下；此外按你们父亲的账目，还有十及其余款项。”我问，这类书面记录是否产生了某种债务，尤其就金钱关系而言。答复说：所问书信似乎并未产生债务，但可以作为寄托物品的证明；至于同一书信中记载对方欠自己十的那个人，能否证明其所写内容，应由法官判断。

### <a id="16.3.27"></a>16.3.27

**保罗《答复》第七卷**

卢基乌斯·提图斯有一名处于其权力之下的女儿塞娅，将她嫁给他人所有的奴隶潘菲卢斯，并给付嫁资；他在书面凭证中将这笔嫁资记作寄托。后来奴隶的主人未作任何通知，提图斯便去世，不久奴隶潘菲卢斯也死亡。我问，塞娅既已继承其父，能依何种诉讼请求返还这笔钱？保罗答复：既然嫁资无法有效设立，应基于寄托原因提起以特有产为限的诉讼，追回钱款。

### <a id="16.3.28"></a>16.3.28

**斯凯沃拉《答复》第一卷**

昆图斯·凯基利乌斯·坎迪杜斯致帕基乌斯·罗加提阿努斯的信如下：“凯基利乌斯·坎迪杜斯致他的帕基乌斯·罗加提阿努斯：我以此信告知你，你要我替你保管的二十五枚钱币，已经记入我的账簿；我会设法使这笔钱不闲置，也就是让你取得利息。”有人询问，是否可以依据这封信请求利息。我答复：依诚信诉讼应支付利息，无论其已经实际收取利息，还是把钱用于自己的事务。

### <a id="16.3.29"></a>16.3.29

**保罗《判例集》第二卷**

<a id="16.3.29.pr."></a>

**序言（pr.）** 如果我将钱袋或封印的银器寄托给你，而你未经我同意擅自取用，我可以对你提起寄托之诉和盗窃之诉。

<a id="16.3.29.1"></a>

**1.** 如果经我许可，受寄人使用寄托的钱款，那么与其他诚信诉讼相同，他应向我支付该款项的利息。

### <a id="16.3.30"></a>16.3.30

**涅拉提乌斯《答复》第一卷**

如果为受寄人提供保证的人因受寄事项被判按诉讼估价给付，寄托物即归受寄人所有。

### <a id="16.3.31"></a>16.3.31

**特里丰尼努《论争》第九卷**

<a id="16.3.31.pr."></a>

**序言（pr.）** 合同所要求的善意，要求达到最高程度的公平；但我们是仅依万民法本身，还是也结合市民法和裁判官法的规则来衡量这种公平？例如，一名死罪案件的被告寄托一百钱给你，后来他被流放，财产被没收：这些钱应返还给他本人，还是应交入国库？如果我们只考察自然法与万民法，应返还给交付钱款的人；如果考察市民法及法律秩序，则更应将其交入国库。因为在公共领域作恶之人，应当承受贫困，以此为他人树立警戒，阻止不法行为。

<a id="16.3.31.1"></a>

**1.** 这里还涉及另一项考察：我们是否仅应在订约双方之间衡量善意，而不考虑外部因素；还是也要顾及该交易所涉及的其他人？例如，强盗把从我处抢来的赃物寄存在不知其恶行的塞尤斯那里。塞尤斯应将物品返还给强盗，还是返还给我？如果只看交付者和接收者本人，善意要求将受托物返还给交付者；如果考察涉及交易的所有人之间的整体公平，就应返还给我，因为物品是以极恶劣的行为从我处夺走的。我赞同这样的正义：将各自应得之物归还本人，不应让任何人的权利被他人更为正当的请求排除。如果我没有前来请求这些物品，也仍应返还给寄托人，尽管其取得物品的方式不正当；马尔凯鲁斯对侵夺者与窃贼也作同样论述。不过，如果强盗不知道自己抢的是某人的儿子或奴隶之物，便将其寄存在不知情的父亲或主人处，那么依万民法也不能成立寄托关系；因为寄托制度的功能，是由非物主之人将他人的物品交给他人保管，而非由物主把自己的物品当作他人之物交付保管。同样，如果窃贼把我所有、但我尚不知道被窃的物品寄存在我处，也应正确地说寄托合同并未成立，因为诚信不要求物主把自己的物品返还给强盗。即使不知情的物主后来将物品交出，仿佛基于寄托而为之，仍可提起非债清偿返还之诉。

### <a id="16.3.32"></a>16.3.32

**塞尔苏斯《学说汇纂》第十一卷**

涅尔瓦认为，重大过失就是恶意欺诈；普罗库鲁斯不赞同这一观点，我认为该说完全正确。某人若未达到人之常情所要求的谨慎程度，且在保管寄托物时甚至没有做到对待自己事务时的谨慎，就不能免于欺诈责任；因为依诚信原则，他对他人事务的注意不得低于对自己事务的注意。

### <a id="16.3.33"></a>16.3.33

**拉贝奥《后论》第六卷（雅沃勒努节编）**

你的奴隶与阿提乌斯约定将钱寄托给梅维乌斯作为诉讼保管人，条件是：若你证明钱归你所有，便返还给你；否则返还给阿提乌斯。我答复说，你可以对实际接收寄托的人提起不确定之诉，也就是出示之诉；待物品出示后，再提起所有物返还之诉，因为奴隶在寄托时不能使你的权利处于较不利的地位。

### <a id="16.3.34"></a>16.3.34

**拉贝奥《Pithanon》（《可能论》）第二卷**

你可以对这样的人提起寄托之诉：他声称只有在收到你交付的钱币后，才愿意把寄托物返还给你；即使他此前没有迟延，且返还的物品完好无损，亦然。
