## 16.1.0　论韦莱亚努斯元老院决议（*Ad senatus consultum Velleianum*）——上篇

### <a id="16.1.1"></a>16.1.1　保罗《评告示》第三十卷

<a id="16.1.1.pr."></a>

**序言（pr.）** 韦莱亚努斯元老院决议以最为全面的方式规定，妇女不得为任何人承担债务。

<a id="16.1.1.1"></a>

**1.** 正如依习惯，妇女不得担任民事职务，其许多行为依法律本身也不生效；同样，更应剥夺她们承担这种职责的资格。因为此种职责并非仅涉及她们的劳务和事务处理，还使她们面临家庭财产的风险。

<a id="16.1.1.2"></a>

**2.** 但认为应以这样的方式救济妇女才属公平：允许对原债务人，或对曾使妇女代其成为债务人的人提起诉讼。因为欺骗妇女的，与其说是债权人，不如说是那名原债务人。

### <a id="16.1.2"></a>16.1.2　乌尔比安《评告示》第二十九卷

<a id="16.1.2.pr."></a>

**序言（pr.）** 起初，在神圣的奥古斯都时代，继而在克劳狄时代，皇帝敕令禁止妇女为丈夫承担债务。

<a id="16.1.2.1"></a>

**1.** 后来颁布了元老院决议，对所有妇女作了最全面的救济。该决议的文字如下：“执政官马尔库斯·西拉努斯和维勒乌斯·图托尔就妇女为他人承担债务、因而成为债务人一事向元老院陈述意见后，元老院就此作出如下决议：关于妇女为他人提供保证，或为他人借款而承担债务的情形，尽管此前似乎已有法律意见认为，不得以此为由向她们主张，也不得对她们提起诉讼，因为她们履行男性职责并受此类债务约束并不公平；元老院认为，凡就此事向其寻求法律救济的人，如努力确保元老院意旨得到遵行，即属正当而适当。”

<a id="16.1.2.2"></a>

**2.** 因此，我们先来仔细考察元老院决议的文字，同时赞扬这个最高等级的机构具有远见；妇女因性别上的弱势，遭遇并承受过许多此类情形，元老院遂为她们提供救济。

<a id="16.1.2.3"></a>

**3.** 但只有妇女并非以欺诈方式行事时，元老院决议才救济她们；这是神圣的庇护者安敦宁·庇护和塞维鲁在敕答中所作的说明。因为该决议帮助的是受欺骗者，而非欺骗他人者。塞维鲁的敕答还以希腊文写道：*tais apatwsais gunaicin to dogma tys sugklytou boulys ou boyvei*（“元老院决议不帮助欺骗他人的妇女”）。底本所附拉丁释义为：*id est: decipientibus mulieribus senatus consultum non opilatur*〔底本作 *opilatur*〕。值得救济的是妇女的弱势，而不是她们的狡诈。

<a id="16.1.2.4"></a>

**4.** 韦莱亚努斯元老院决议涵盖一切债务关系，无论妇女是以言辞、以物，还是以任何其他契约方式承担他人债务。

<a id="16.1.2.5"></a>

**5.** 妇女若充任他人的诉讼代理人，也无疑属于为他人承担债务；因为她把他人的债务承担到自己身上，毕竟可能因此被判令承担责任。因此，不允许妇女为丈夫、儿子或父亲辩护。

### <a id="16.1.3"></a>16.1.3　保罗《评告示》第三十卷

但是，如果她为某人辩护，而该人在败诉后可以向她追偿，例如她为自己所购买遗产的出卖人或自己的保证人辩护，就不视为她为他人承担债务。

### <a id="16.1.4"></a>16.1.4　乌尔比安《评告示》第二十九卷

<a id="16.1.4.pr."></a>

**序言（pr.）** 但是，如果我从一开始就是与该妇女订约，而且不知道她想把款项用于谁，我毫不怀疑，元老院决议不适用。神圣的庇护者安敦宁·庇护和我们当今的皇帝也以敕答作了同样说明。

<a id="16.1.4.1"></a>

**1.** 因此，如果妇女想把钱赠给提提乌斯，便向我借款并将钱赠给他，元老院决议就不适用。同样，如果妇女为了赠与而替你向你的债权人支付钱款，也不属于为他人承担债务。因为元老院意在救济已受债务约束的妇女，而不是救济赠与者；这是因为妇女较容易使自己负债，却不那么容易向他人赠与。

### <a id="16.1.5"></a>16.1.5　盖尤斯《评行省告示》第九卷

妇女究竟是为清偿债务而交付钱款，还是以自己的任何财物抵作清偿，并无区别。即使她出售自己的财物，再以所得价款替他人清偿债务，或指示买受人向他人的债权人付款，我认为元老院决议也不适用。

### <a id="16.1.6"></a>16.1.6　乌尔比安《评告示》第二十九卷

如果有人受其母亲委任，为一名不在场的家子之诉讼代理人提供保证，问题是，这些保证人是否也受元老院决议救济。帕皮尼安在《疑义集》第九卷中说，他们可以援用该决议的抗辩；他们是为诉讼代理人提供保证这一点，并无太大关系，因为他们是基于母亲的委任而介入的。他还说：当然，如果接受这些保证的人不知道是该母亲委任了他们，就可以用欺诈再抗辩（*replicatio doli*）驳回他们所提出的元老院决议抗辩。

### <a id="16.1.7"></a>16.1.7　帕皮尼安《疑义集》第九卷

因此，尽管保证人提出欺诈再抗辩后，会失去其原有抗辩的保护，但他对妇女并无任何再抗辩可言，因为他不能主张自己不知道相关事实。不过，允许其对诉讼代理人提起无因管理之诉并无不公，因为元老院决议使委任关系无效，并使保证人因给付而获免责。〔底本作 *amittit*，并列异读 *amittat*。〕

### <a id="16.1.8"></a>16.1.8　乌尔比安《评告示》第二十九卷

<a id="16.1.8.pr."></a>

**序言（pr.）** 虽然提供质物构成代为承担债务，但尤利安在《学说汇纂》第十二卷中写道，如果一名女性债权人把她收受的质物返还给债务人，这种返还并不构成代为承担债务。

<a id="16.1.8.1"></a>

**1.** 如果妇女出面劝阻其儿子的监护人，不要变卖儿子的土地，并向他们保证使其不受损害，帕皮尼安在《疑义集》第九卷中认为，她并未代为承担债务。因为她既未承担他人的债务，也未承担旧债或新债，而是自行创设了这项债务。

<a id="16.1.8.2"></a>

**2.** 如果妇女先在第一债权人面前为第二债务人承担债务，随后又在第二债务人的债权人面前为第一债务人承担债务，尤利安在《学说汇纂》第十二卷中写道，发生了两次代为承担债务：一次是她在第一债权人面前为第二债务人承担债务，另一次是她在第一债务人的债权人面前为第一债务人承担债务。因此，原先针对第一债务人的债务关系也应恢复，并可对其提起诉讼。马尔切鲁斯则附注说，情形可能有所不同：应看双方究竟是从一开始就安排让妇女代替另一人，并承担债权人原想移转的债务负担；还是把她当作债务人而予以指定。如果她是作为债务人受指定，便只有一次代为承担债务。依照这一分类，对于后一种情形，即妇女被当作债务人指定的情形，马尔切鲁斯不会准许她提出元老院决议抗辩；但她被判决后，或在判决前，仍可向指定她的人提起返还之诉，追索她所受的损失；如果尚未实际受损，也可请求解除债务。

<a id="16.1.8.3"></a>

**3.** 有时，为他人承担债务的妇女也享有返还之诉；例如，她违反元老院决议承担债务后，指定自己的债务人代为清偿。在这种情况下，她本人可以提起返还之诉，如同她亲自支付了钱款一样；因为指定自己的债务人，也被视为已经清偿。

<a id="16.1.8.4"></a>

**4.** 但是，如果妇女指定的人并非她的债务人，该人可以援用元老院决议抗辩，如同妇女的保证人一样。

<a id="16.1.8.5"></a>

**5.** 当然，如果妇女为了代他人承担债务而指定自己的债务人，元老院决议就不适用；因为即使她亲自支付钱款，决议也不会适用。元老院决议旨在使妇女免于债务，而不是返还她已处分的财物。

<a id="16.1.8.6"></a>

**6.** 但是，如果她指定的人并非自己的债务人，就应视为有人欺诈元老院决议，因此应准许提出抗辩。

<a id="16.1.8.7"></a>

**7.** 每当妇女为债务人承担债务时，即使在她承担债务之前，该债务人已经通过要式免债行为（*acceptilatio*）获得免责，仍应恢复对该债务人的原有诉权。

<a id="16.1.8.8"></a>

**8.** 如果债权人与债务人约定，由债务人另行指定一名新债务人，原债务人因而通过要式免债行为（*acceptilatio*）获得免责，随后他指定了一名受元老院决议保护的妇女，那么可对原债务人提起返还之诉，仿佛他并未作出该项指定。因为不作指定和指定这样一名妇女，有什么区别呢？因此，无须准许补充诉权，因为返还之诉已经可以提起。

<a id="16.1.8.9"></a>

**9.** 马尔切鲁斯也写道，如果债权人在妇女代为承担债务后，以要式免债行为免除她的债务，仍应向债权人恢复回复原状之诉（*actio restitutoria*）；因为他所免除的只是一项无效债务。

<a id="16.1.8.10"></a>

**10.** 如果妇女代为承担债务后作出清偿，且不能请求返还，原债务人就有正当理由拒绝承担责任。但是，如果妇女以不能请求返还的方式清偿，债务人便获免责；同样，如果债权人以要式免债行为免除了那名已无权请求返还的妇女，债务人也同样获免责。

<a id="16.1.8.11"></a>

**11.** 尽管对所有已经获免责的人都可以恢复诉权，却并非对所有人都恢复诉权。例如，原有两名共同承担要式口约债务的人，妇女只为其中一人承担债务；那么，只向妇女承担债务的那一人恢复原有债务关系。

<a id="16.1.8.12"></a>

**12.** 如果债权人继承了妇女的遗产，应考察他是否仍可使用回复原状之诉。尤利安在《学说汇纂》第十二卷中说，他仍可使用该诉，并非没有道理，因为他继承的并不是一项实际有效的债务。事实上，在法尔基迪亚遗产扣减中，这项债务不计入遗产债务。

<a id="16.1.8.13"></a>

**13.** 当然，如果妇女继承了原债务人的地位，应当说可以对她提起回复原状之诉，也可以对她提起直接之诉；她并不在意以何种诉讼被起诉。

<a id="16.1.8.14"></a>

**14.** 如果我原本打算与你订约，妇女却出面介入，使我改为与她订约，就应视为她代为承担债务。在这种情况下，对你提起的诉讼不是恢复而是创设债务关系的诉讼；其效果是，使你依妇女原先承担的同一债务形式承担责任。例如，如果妇女是通过要式口约承担债务，就以准要式口约之诉起诉你。

<a id="16.1.8.15"></a>

**15.** 还应考察：如果妇女替某人承担债务，而该人在债权人直接与其订约时本不会承担责任，是否应当对该人提起恢复之诉？例如，妇女替一名未经监护人授权便不负债务的未适婚人承担债务。我认为，除非该未适婚人因该交易而变得富有，否则不得使其承担责任。同样，如果妇女替未满二十五岁的人承担债务，该人可以请求恢复原状；家子若违反元老院决议订约，也应如此。

### <a id="16.1.9"></a>16.1.9　保罗《规则集》第六卷

如果妇女替他人的奴隶承担债务，就如同对家父恢复针对原债务人的诉权一样，也应对奴隶主人恢复诉权。

### <a id="16.1.10"></a>16.1.10　乌尔比安《评告示》第二十九卷

对妇女所替代承担债务之人提起的这些诉讼，均可永久地向其继承人提起，也可由其继承人提起；因为这些诉讼是追索特定财产的诉讼。对其他概括继受人，也应准许这些诉讼，或向其提起。

### <a id="16.1.11"></a>16.1.11　保罗《评告示》第三十卷

如果妇女以仿佛是供自己使用为由收取钱款，实际上打算再借给他人，元老院决议就不适用；否则，没有人会与妇女订约，因为人们无法知道她打算如何使用钱款。

### <a id="16.1.12"></a>16.1.12　保罗《简要规则集》第六卷

恰恰相反，只有在债权人知道妇女是在为他人承担债务时，元老院决议才适用。

### <a id="16.1.13"></a>16.1.13　盖尤斯《评行省告示》第九卷

<a id="16.1.13.pr."></a>

**序言（pr.）** 有时，妇女虽承担了他人的债务，却不受元老院决议帮助；这是因为她表面上承担的是他人债务，实际上承担的却是自己的债务。比如，女奴因约定获得自由，先指定一名新债务人；获释后，她又承担该新债务人所负的同一债务；又如，她买下一项遗产，并把遗产债务转由自己承担；或她为自己的保证人承担债务。

<a id="16.1.13.1"></a>

**1.** 对原债务人的质物，债权人无须另行提起新诉；准用准萨尔维安之诉（亦称抵押诉，*actio quasi Serviana / hypothecaria*）即可，因为双方确已就质物达成约定，而债务尚未清偿。

<a id="16.1.13.2"></a>

**2.** 如果妇女为他人承担的是附条件或定期债务，即使条件尚未成就或期限尚未届至，债权人愿意对原债务人起诉时，也应准许其提起回复原状之诉。因为原债务人的处境既然仍是无论如何都应由其承受该诉讼，就没有理由等候条件成就或期限届至。

### <a id="16.1.14"></a>16.1.14　尤利安《学说汇纂》第十二卷

如果妇女违反元老院决议承担债务，公平的做法不仅是恢复对原债务人的诉权，也恢复对其保证人的诉权；因为元老院决议使债权人不得向妇女主张，故应将原有法律关系完整恢复。

### <a id="16.1.15"></a>16.1.15　尤利安《学说汇纂》第五十一卷

如果我把自己欠你的款项付给妇女，并要求她约定你会追认该项清偿，而你后来没有追认，我便依要式口约之诉起诉她，那么妇女不能援用关于妇女代为承担债务的元老院决议抗辩。因为我仍负有债务，不能说她是在拒绝承担他人的债务；她是在谋取利益，并且与其说她是在替他人清偿，不如说她被迫返还了自己无债而取得的钱款。

### <a id="16.1.16"></a>16.1.16　尤利安《论乌尔塞乌斯·费罗克斯》第四卷

<a id="16.1.16.pr."></a>

**序言（pr.）** 如果妇女违反韦莱亚努斯元老院决议为我向提提乌斯承担债务，而我又向妇女清偿，提提乌斯再向她请求该笔款项，则该元老院决议抗辩对她没有帮助。因为她已经持有该笔钱，不存在因钱款灭失而遭受损失的风险。

<a id="16.1.16.1"></a>

**1.** 如果我从一名违反元老院决议代为承担债务的妇女处取得保证，盖尤斯·卡西乌斯答复说，只有在保证人受该妇女委托时，才应准许保证人提出抗辩。尤利安则正确地认为，即使保证人对妇女没有委任之诉，也应准许其提出抗辩；因为元老院否定的是整个债务关系，而裁判官会把原债务人恢复为债权人的债务人。
