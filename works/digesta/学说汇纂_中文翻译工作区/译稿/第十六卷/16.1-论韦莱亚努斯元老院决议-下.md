## 16.1.17 起（下篇）

### <a id="16.1.17"></a>16.1.17　阿非利加努《疑义集》第四卷

<a id="16.1.17.pr."></a>

**序言（pr.）** 丈夫为了赠与妻子，以低于物品价值的价格将物品卖给她，并把应收价款指定给自己的债权人。答复说，该买卖不发生效力；如果债权人向妇女请求付款，即使债权人误以为妇女是丈夫的债务人，她仍可提出准用的抗辩。此结论与另一规则并不矛盾：妇女若为向丈夫借款而借钱再贷给丈夫，倘若债权人不知道妇女借款的用途，妇女不得提出抗辩。因为两种情形有重大区别：究竟是从一开始就与妇女订约，还是把他人的债务移转给她；在后一种情况下，债权人本应更加审慎。

<a id="16.1.17.1"></a>

**1.** 如果妇女声称某物因嫁资关系而归她，并由债权人安排将嫁资款付给她，而债权人取得同一物作为质物，那么妇女也对借款负有债务。如果占有质物的债权人对她提起准萨尔维安之诉，而她以“质物未经其同意提供”为由提出抗辩，妇女不能再以元老院决议抗辩作出再抗辩；除非债权人知道她还欠有另一笔钱款。

<a id="16.1.17.2"></a>

**2.** 妇女与提提乌斯为共同事务借款，因同一笔钱而成为共同债务人，并不当然意味着妇女为共同债务人的份额承担了他人债务。因为，如果他们借款是为避免妇女遭受更大损害，例如共同所有的公寓楼若不加固就会倒塌，或共同土地将被没收归入公产，那么更妥当的看法是，元老院决议不适用。但如果借款用于购买某物，就应视为妇女仅为相应份额承担债务，债权人因此只能向妇女请求该部分款项；如果债权人请求全部款项，妇女可以按其份额提出抗辩。

### <a id="16.1.18"></a>16.1.18　保罗《评普劳提乌斯》第八卷

如果提提乌斯和一名妇女为我的债务人共同承担债务，也应适用同一规则。

### <a id="16.1.19"></a>16.1.19　阿非利加努《疑义集》第四卷

<a id="16.1.19.pr."></a>

**序言（pr.）** 一名未适婚人的监护人死亡，并指定提提乌斯为继承人。提提乌斯担心监护事务管理不善将使其承担责任，因而犹豫是否接受遗产；在未适婚人之母劝说他由自己承担风险接受遗产后，他接受了遗产，并要求她约定就此使他不受损害。如果提提乌斯因这项原因向未适婚人给付某物，而后又向其母请求偿付，答复认为元老院决议抗辩不适用，因为几乎不能说该妇女是为提提乌斯本人而向同一人承担了债务。

<a id="16.1.19.1"></a>

**1.** 有一项依事实提出的案件，与上述情形相似。某位担任过裁判官的男子死亡，留下两个儿子；其中一个尚未适婚，另一个是其弟的法定监护人，并打算使弟弟不得承受父亲的遗产。依已故男子妻子——亦即未适婚人之母——的委托，在使未适婚人不得承受遗产后，哥哥独自参与继承。尤利安说，他对此也作了同样答复：如果哥哥后来因未适婚人的起诉而受损，元老院决议并不妨碍他向该妇女请求补偿。

<a id="16.1.19.2"></a>

**2.** 对于上述情形，还应讨论：如果提提乌斯是依妇女的委托接受遗产，后来因遗产债务人无清偿能力而遭受损失，元老院决议是否适用，仿佛妇女以某种方式承担了这些债务人的债务？更妥当的意见是，即使在这一原因下，元老院决议也不适用；因为妇女并非意在替遗产债务人承担债务，而只是要保证继承人不会因监护人对未适婚人及其他债权人的责任而遭受损失。

<a id="16.1.19.3"></a>

**3.** 最后，假设妇女因购买遗产而遭受损失，原因是遗产债务人无清偿能力，我认为毫无疑问元老院决议不适用，即使她已经向债权人支付了相当数额也一样。

<a id="16.1.19.4"></a>

**4.** 那么，如果提提乌斯之所以犹豫接受遗产，是因为债务人的债权凭证看起来并不可靠，而妇女又承诺：无论向任何一名债务人能够追回多少不足之数，她都负责补足，该如何处理？这种情形接近于代为承担债务。

<a id="16.1.19.5"></a>

**5.** 假设你有提提乌斯这个债务人，妇女想为他承担债务，但你因元老院决议而不愿接受她作为债务人。妇女于是向我借钱，打算替你清偿；她向我作出要式口约时，我不知道她借款的用途，她还指示我把款项交给你。接着，因为我手边没有现钱，我又向你作出要式口约。问题是，如果我向妇女请求这笔钱，她能否提出元老院决议抗辩？答复认为，不无道理的看法是，我应被视为妇女的保证人：正如保证人即使不知道妇女是在为他人承担债务，也可对债权人提出抗辩，因而债权人不得对妇女提起委任之诉；同样，我也应能对你提出准用的抗辩，而不得对妇女提起诉讼，因为这项诉讼会使妇女承担风险。保罗认为，如果我在向你支付钱款之前就查明她是在为他人承担债务，这一结论更容易成立。但如果我已先行支付，就须考察：妇女是否仍可对我提出抗辩，而我则向你提起返还之诉请求钱款；还是应当把情形视同我起初把钱借给妇女，而你又反过来把钱贷给我。保罗认为后一处理更为可取，因此元老院决议不适用；正如妇女指定自己的债务人时，决议也不适用。后来有人认为，这两种情形不能这样类比，因为妇女指定自己的债务人后并不负债；而在本案中，她却把他人的债务移转到自己身上——这正是元老院所禁止的。

### <a id="16.1.20"></a>16.1.20　阿非利加努《疑义集》第八卷

如果妇女为共同债务人中的一人承担债务，债权人可以对两名债务人一并恢复原有诉权。

### <a id="16.1.21"></a>16.1.21　卡利斯特拉图《法学原理》第三卷

<a id="16.1.21.pr."></a>

**序言（pr.）** 如果妇女替他人承担债务，但所取得的款项转用于她自己的事务，元老院决议抗辩就不适用，因为她的财产并未减少。

<a id="16.1.21.1"></a>

**1.** 同样，如果妇女出于慷慨而行事，例如为免其父亲因清偿而在判决后遭受骚扰，就不能受元老院决议保护；元老院决议救济的是她们所承担的负担。

### <a id="16.1.22"></a>16.1.22　保罗《规则集》第六卷

如果我把钱交给妇女，让她替我向我的债权人付款，或代我允诺承担债务；而她确实以新债务人身份作出允诺，庞波尼乌斯写道，元老院决议不适用，因为她受委任之诉约束，故应视为为自己的事务承担了债务。

### <a id="16.1.23"></a>16.1.23　保罗《论韦莱亚努斯元老院决议》单卷

如果妇女在法庭上受询问时回答自己是继承人，而她明知自己并非继承人仍如此回答，就不应视为她为他人承担债务，因为她欺骗了对方。反之，如果她误以为自己是继承人而作出该回答，多数法学家认为可以对她提起诉讼，但她仍可援用元老院决议抗辩。

### <a id="16.1.24"></a>16.1.24　保罗《论妇女代为承担债务》单卷

<a id="16.1.24.pr."></a>

**序言（pr.）** 妇女本身是债务人，债权人却指定她代替另一人承担债务；妇女于是为被指定之人作出允诺，她不得援用抗辩。

<a id="16.1.24.1"></a>

**1.** 但如果她为了不被指定承担债务而允诺支付钱款，就应视为她已为他人承担债务。

<a id="16.1.24.2"></a>

**2.** 如果元老院决议的保护适用，那么对原债务人的诉权是在妇女一承担债务时立即产生，还是要等妇女清偿后再请求返还？我认为诉权立即产生，无须等待清偿。

<a id="16.1.24.3"></a>

**3.** 如果妇女为一名仅受期间限制之诉约束的人承担债务，恢复的也应是该期间限制之诉；恢复后，仍从原先的原因开始连续计算期间，尽管妇女一承担债务，该诉便已可以提起。

### <a id="16.1.25"></a>16.1.25　莫德斯汀《法学发现集》单卷

<a id="16.1.25.pr."></a>

**序言（pr.）** 如果女主人命令他人向自己的奴隶提供信用，她应依裁判官法上的诉权承担责任。

<a id="16.1.25.1"></a>

**1.** 但如果她为该奴隶提供保证，并因而被债权人起诉，她可以在诉讼中援用韦莱亚努斯元老院决议抗辩；除非她是为处理自己的事务而作出保证。

### <a id="16.1.26"></a>16.1.26　乌尔比安《评告示》第三十七卷

如果妇女为了代他人承担债务，回答说别人的奴隶是自己的奴隶，她可以援用元老院决议的保护。但如果她回答该人是善意为她服役的自由人，就不应视为她代为承担债务。

### <a id="16.1.27"></a>16.1.27　帕皮尼安《答复集》第三卷

<a id="16.1.27.pr."></a>

**序言（pr.）** 如果某人订约时出于善意而信赖妇女本人，对于夫妻之间以取得的钱款进行的交易，不得以元老院决议抗辩将其排除。

<a id="16.1.27.1"></a>

**1.** 如果受命经营的奴隶与他人订约时，是基于妇女的信用而把她当作有清偿能力的人，元老院决议的抗辩就会排除对主人的诉讼。因为不能说主人的处境因奴隶而变差；更确切地说，主人并未因此取得任何利益，正如奴隶买下有争议的土地或自由人一样。

<a id="16.1.27.2"></a>

**2.** 妻子把自己的债务人指定给丈夫，让丈夫替她的债权人付款；如果她为自己指定的债务人向丈夫提供信用保证，元老院决议抗辩就不适用，因为妇女是在处理自己的事务。

### <a id="16.1.28"></a>16.1.28　斯凯沃拉《答复集》第一卷

<a id="16.1.28.pr."></a>

**序言（pr.）** 塞娅买入奴隶，并在丈夫提供保证的情况下借得钱款，再将钱款付给卖方。后来丈夫死亡且无清偿能力，为欺诈债权人，他在遗嘱中承认自己欠下全部钱款。问题是，妇女是否应视为为他人承担了债务。我答复说，依照所述事实，她并未代为承担债务。

<a id="16.1.28.1"></a>

**1.** 丈夫因租赁关系，将妻子的土地抵押给塞姆普罗尼乌斯。随后，妇女以自己的信用向努梅里乌斯借款，并以同一块土地设定担保，立即代丈夫向塞姆普罗尼乌斯清偿。问题是，她是否违反元老院决议承担了债务。我答复说，如果努梅里乌斯知道她是在代他人承担债务，所讨论的元老院决议就适用。

### <a id="16.1.29"></a>16.1.29　保罗《答复集》第十六卷

<a id="16.1.29.pr."></a>

**序言（pr.）** 某人原想把钱借给卢基乌斯·提提乌斯的继承人并与他们订约；但他怀疑他们的财产状况，便改为把钱借给被继承人的妻子，并从她处取得质物。妇女把同一笔钱交给继承人，又从他们处取得质物。我询问：她是否视为代为承担债务？她取得的质物是否应对该妇女的债权人承担责任？保罗答复说，如果债权人原想与卢基乌斯·提提乌斯的继承人订约，却避开他们，转而选择妇女作为债务人，则元老院决议适用于妇女本人，她提供的质物不负担责任。妇女从她所替代承担债务之人处取得的物品，也不对妇女的债权人设定担保。不过，裁判官采取以下做法并非没有道理：不仅因排除妇女本人而对原债务人提起诉讼，也对已抵押给妇女的物品提起诉讼。

<a id="16.1.29.1"></a>

**1.** 保罗答复说，凡经证明是为规避关于妇女代为承担债务的元老院决议而设计的安排，均不应予以承认。

### <a id="16.1.30"></a>16.1.30　保罗《格言集》第二卷

<a id="16.1.30.pr."></a>

**序言（pr.）** 如果妇女为了欺骗他人，或明知自己不负债务，仍替某人承担债务，她不得提出元老院决议抗辩；因为元老院并未排除针对妇女欺诈行为所享有的诉权。

<a id="16.1.30.1"></a>

**1.** 如果代理人受妇女委任而替他人承担债务，他可以援用韦莱亚努斯元老院决议抗辩，以免其诉权以其他方式消灭。

### <a id="16.1.31"></a>16.1.31　保罗《论内拉提》第一卷

保罗说：如果妇女不愿请求返还自己因代为承担债务而支付的钱款，而是愿意提起委任之诉，并承诺使被告不受损害，应当听取她的请求。

### <a id="16.1.32"></a>16.1.32　庞波尼乌《元老院决议》第一卷

<a id="16.1.32.pr."></a>

**序言（pr.）** 如果妇女接受他人遗产，以承担其债务，那么她几乎不应获得救济；除非该安排是为欺诈遗产债权人而设计。妇女并非在所有方面都应视同遭受欺骗的未满二十五岁人。

<a id="16.1.32.1"></a>

**1.** 如果妇女想取回自己因代为承担债务而提供的质物，她也可取回已经产生的孳息；如果该物有所减损，其价值也应相应估定。但是，如果因代为承担债务而取得质物的债权人已将其出售给他人，较正确的看法是，应准许妇女提起返还之诉，即使针对善意买受人也如此，以免买受人处于优于出卖人的地位。

<a id="16.1.32.2"></a>

**2.** 同样，如果妇女把自己的土地卖给丈夫的债权人并交付土地，约定买受人将其收取的价款记入丈夫账下，而妇女后来请求返还土地，买受人可以提出买卖并交付之抗辩；但妇女可以再抗辩：“除非该买卖违反元老院决议。”无论是债权人本人购买，还是他安排他人介入以使妇女失去自己的财物，均适用此规则。如果妇女不是为丈夫，而是为另一名债务人交付自己的财物，也同样如此。

<a id="16.1.32.3"></a>

**3.** 如果妇女为了自己不亲自代为承担债务，而委托他人去做，那么受妇女请求而行事的人能否援用该元老院决议？元老院决议全文所针对的，是不得向妇女本人提出请求。我认为应作如下区分：如果某债权人因妇女的委托而使我对其负债，并且他为规避元老院决议、避免妇女本人介入而安排他人代替，就应以针对违反元老院决议的欺诈抗辩排除其请求。反之，如果债权人对此并不知情而我知情，那么我对妇女提起委任之诉时应被排除，但我仍应对债权人承担责任。

<a id="16.1.32.4"></a>

**4.** 如果妇女愿意为她所代为承担债务之人接受诉讼，使诉权不必恢复至原债务人，那么由于她可以提出元老院决议抗辩，她应提供担保，承诺不使用该抗辩，然后再到法官面前应诉。

<a id="16.1.32.5"></a>

**5.** 即使妇女是为不能承担债务的人承担债务，也应视为她已代为承担债务，例如她为他人的奴隶承担债务；但撤销该项代为承担债务后，应对奴隶主人恢复诉权。
