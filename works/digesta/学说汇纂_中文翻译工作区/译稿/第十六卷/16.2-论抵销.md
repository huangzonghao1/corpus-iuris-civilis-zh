## 16.2.0　论抵销（*De compensationibus*）

### <a id="16.2.1"></a>16.2.1　莫德斯丁《学说汇纂》第六卷

抵销，是债务与债权之间的相互核算。

### <a id="16.2.2"></a>16.2.2　尤利安《学说汇纂》第九十卷

只要某人愿意抵销，就可以拒绝向起诉追偿的债权人履行；因为该债权人同时也是他的债务人。

### <a id="16.2.3"></a>16.2.3　庞波尼《评萨宾》第二十五卷

抵销之所以必要，是因为对我们而言，与其先行清偿再请求返还，不如一开始就不予清偿。

### <a id="16.2.4"></a>16.2.4　保罗《评萨宾》第三卷

涅拉提乌斯持有的观点是正确的，庞波尼也如此说：在一切契约中，保证人依法所负债务，均应减少主债务人可通过抵销保留的数额。正如我向主债务人请求全部债务时，所请求的数额过高；同样，保证人依法承担的责任，也不得超过主债务人可能被判决承担的数额。

### <a id="16.2.5"></a>16.2.5　盖尤斯《评行省告示》第九卷

如果有人向保证人请求给付，最公平的做法是让保证人选择：究竟抵销欠他本人的债务，还是抵销欠主债务人的债务；如果他希望两项都抵销，也应准许。

### <a id="16.2.6"></a>16.2.6　乌尔比安《评萨宾》第三十卷

自然债务也可以抵销。

### <a id="16.2.7"></a>16.2.7　乌尔比安《评告示》第二十八卷

<a id="16.2.7.pr."></a>

**序言（pr.）** 尚未到清偿期的债务，在期限届至之前不得抵销，即使该债务届时应予给付亦然。

<a id="16.2.7.1"></a>

**1.** 如果法官没有考虑抵销，原请求权仍然保留，因为不得提出既判力抗辩。若法官以债务不存在为由驳回抵销，则情况不同；此时，既判力抗辩将对我不利。

### <a id="16.2.8"></a>16.2.8　盖尤斯《评行省告示》第九卷

已经与原告就某项请求进入诉讼系属的债权，也可以纳入抵销；否则，若拒绝抵销，行事更为谨慎的一方反而会处于较不利的地位。

### <a id="16.2.9"></a>16.2.9　保罗《评告示》第三十二卷

<a id="16.2.9.pr."></a>

**序言（pr.）** 如果合伙关系是与家子或奴隶订立，而由家父或主人起诉，我们应通过抵销保全全部债权；尽管若由我们起诉，只能在特有产范围内取得给付。

<a id="16.2.9.1"></a>

**1.** 如果对家子提起诉讼，他能否抵销其家父所欠的债务，仍有疑问。较妥当的观点是允许抵销，因为这是同一项合伙契约；但家子须保证其家父会予以认可，也就是说，家父不会再追索家子已经抵销的数额。

### <a id="16.2.10"></a>16.2.10　乌尔比安《评告示》第六十三卷

<a id="16.2.10.pr."></a>

**序言（pr.）** 如果合伙双方对合伙事务都存在程度相同的疏忽，应当说，双方因相互抵销疏忽所造成的损失，依法不再彼此负有债务。同样，如果一方从共有事务中取得某物，另一方则表现出程度相同、价值相当的疏忽，也应认为双方已经抵销，并依法相互免责。

<a id="16.2.10.1"></a>

**1.** 因此，有能力主张抵销的人若仍然付款，可以提起返还之诉，主张该款属于非债清偿。

<a id="16.2.10.2"></a>

**2.** 如果诉权源于不法行为，例如盗窃或其他不法行为，且诉讼以金钱为标的，就可以抵销；基于盗窃原因提起返还之诉时，也同样如此。在诺克萨诉讼中被起诉的人，也可以提出抵销抗辩。

<a id="16.2.10.3"></a>

**3.** 在具有诉讼性质的口约中——也就是裁判官法上的口约——也可以抵销。根据尤利安的观点，无论在口约本身中，还是在依据口约提起的诉讼中，都可以提出抵销。

### <a id="16.2.11"></a>16.2.11　乌尔比安《评告示》第三十二卷

如果一方欠另一方无息债务，而另一方所欠的是计息债务，神圣的塞维鲁皇帝已规定：双方债务数额重合的部分，不应支付利息。

### <a id="16.2.12"></a>16.2.12　乌尔比安《评告示》第六十四卷

同一法律规则不仅适用于私人之间，也适用于国库事务。如果双方互负计息债务，但利率不同，彼此所欠债务仍然可以抵销。

### <a id="16.2.13"></a>16.2.13　乌尔比安《评告示》第六十六卷

拉贝奥所说并非没有道理：如果抵销被专门规定适用于某一种请求，就不应在其他请求中提出抵销。

### <a id="16.2.14"></a>16.2.14　雅沃勒努《卡西乌斯著作》第十五卷

凡可以通过抗辩而消灭的债务，均不得用于抵销。

### <a id="16.2.15"></a>16.2.15　雅沃勒努《书信集》第二卷

我以口约承诺在特定地点向提提乌斯支付款项；提提乌斯向我请求我所欠他的款项。我询问：是否也应考虑我因约定在特定地点付款而享有的利益？答复是：如果提提乌斯提起请求，我承诺在特定地点支付的款项也应计入抵销，但须按照该款本身的性质核算，也就是说，应考虑提提乌斯对按约定地点收到款项具有多大的利益。

### <a id="16.2.16"></a>16.2.16　帕皮尼安《疑义解答》第三卷

<a id="16.2.16.pr."></a>

**序言（pr.）** 如果一名士兵的军中财产由一人继承，其余财产由另一人继承，而一个对其中一名继承人负有债务的债务人，想以自己所欠另一名继承人的债务进行抵销，不应准许。

<a id="16.2.16.1"></a>

**1.** 已被判决承担债务的人，在获准履行判决的期限内起诉提提乌斯，而提提乌斯此前也已被判决对其负有债务时，应准许抵销。因为债务履行期限尚未届至，与出于宽厚而给予延期清偿，是两回事。

### <a id="16.2.17"></a>16.2.17　帕皮尼安《答复录》第一卷

某人因在其担任市政官期间“使粮食供应趋于紧张”（*artiorem annonam praebuit*）而被判决承担责任，因此不应被视为仍欠有粮食供应款；故其可以主张抵销。

### <a id="16.2.18"></a>16.2.18　帕皮尼安《答复录》第三卷

<a id="16.2.18.pr."></a>

**序言（pr.）** 某人在争讼程序确定后被指定为处理自己事务的代理人；若双方互相起诉，他可以依据公平原则主张抵销。

<a id="16.2.18.1"></a>

**1.** 债权人不必将自己对第三人所负的债务，与其对自己债务人的债权抵销；即使该第三人——也就是债权人的债权人——愿意代被起诉者抵销其自身债务，亦然。

### <a id="16.2.19"></a>16.2.19　帕皮尼安《答复录》第十一卷

债务人未经有关人员同意，向一名公奴支付公款；这些人员本可以合法地接受清偿。原有债务仍然存续，但债务人可以在该公奴所持有的特有产范围内主张抵销。

### <a id="16.2.20"></a>16.2.20　帕皮尼安《答复录》第十三卷

某管理人受委托在远征期间办理军需事务，后因此被判决承担责任。认为该人可以依据抵销权保留款项，并不妥当，因为这类款项不得抵销。

### <a id="16.2.21"></a>16.2.21　保罗《疑义解答》第一卷

既然已经确立，彼此所负的债务依法相互抵销，那么如果缺席者的代理人被起诉，就不必为本人追认诉讼提供担保；因为代理人并非通过抵销而免责，而是从一开始就只被请求给付较少的数额。

### <a id="16.2.22"></a>16.2.22　斯凯沃拉《疑义解答》第二卷

如果你欠对方十枚金币，或者欠他一名奴隶——由对方选择其一履行——只有在对方明确表示自己选择哪一项时，才准许就该债务进行抵销。

### <a id="16.2.23"></a>16.2.23　保罗《答复录》第九卷

如果监护人以被监护人的名义请求给付，被告不得以监护人以其个人名义所欠的款项主张抵销。

### <a id="16.2.24"></a>16.2.24　保罗《裁断录》第三卷

皇帝命令，应听取能够证明国库欠其款项、且该款正是他本人被起诉所涉款项的人。
