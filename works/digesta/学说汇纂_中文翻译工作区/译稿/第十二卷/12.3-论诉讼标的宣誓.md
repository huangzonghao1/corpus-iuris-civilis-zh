## 12.3.0　论诉讼标的宣誓（*De in litem iurando*）

### <a id="12.3.1"></a>12.3.1　乌尔比安《评萨宾》第五十一卷

**正文** 我们不认为，已经提交法院审理的标的会因此增值：由于拒不返还者抗命，判决金额可以因诉讼标的估价宣誓（*iusiurandum in litem*）而提高。因为标的物并非因此增值，而是因其抗命行为，其估价超过该物的价格。

### <a id="12.3.2"></a>12.3.2　保罗《评萨宾》第十三卷

**正文** 无论我们请求返还自己的物，还是提起出示之诉（*actio ad exhibendum*），有时只估算原告的利益，例如，因未返还或未出示者的过失而对其予以制裁时；但如果未返还或未出示者存在诈欺或抗命，则按照原告在诉讼标的估价宣誓中所宣誓的金额确定。

### <a id="12.3.3"></a>12.3.3　乌尔比安《告示评注》第三十卷

**正文** 对于寄存的钱款，法官不应准许作诉讼标的估价宣誓，让任何人宣誓其利益数额，因为钱款的估价是确定的。除非有人所宣誓的是：钱款若能在到期日返还给自己，对自己有何利益。例如，他是否因此负有附违约金的债务？或者，他是否以质物担保债务，而质物因寄存的钱款遭拒不返还而被变卖？

### <a id="12.3.4"></a>12.3.4　乌尔比安《告示评注》第三十六卷

<a id="12.3.4.pr."></a>

**序言（pr.）** 我们来考察，在监护事务中，何人可以宣誓，又可以向何人宣誓。被监护人本人若尚未达到青春期（*impubes*），不能宣誓；对此已有多次敕答。但是，神君兄弟（*divi fratres*）敕答指出，不得强迫监护人宣誓，也不得准许被监护人的母亲宣誓，即使她已准备好宣誓。因为让不了解情况且不情愿的监护人，为他人利益承担可能构成伪誓的风险，似乎过于严苛。本朝皇帝及其神君父亲的敕答也确认，不得强迫被监护人或青年的保佐人作诉讼标的估价宣誓。不过，如果监护人或保佐人愿意向其被监护人或青年表达如此深厚的关爱，法律权威并不妨碍他们之间已经进行的诉讼以此种方式终结。因为宣誓估价并非为宣誓者自身利益而作，而是为了被监护人（*dominus*）的利益；监护账目正是以被监护人的名义提出请求。至于青年（*adulescens*），如果愿意，可以宣誓。

<a id="12.3.4.1"></a>

**1.** 应由法官提出宣誓要求；否则，如果由他人提出宣誓要求，或者未经要求便自行宣誓，就不产生任何宗教拘束力，也不构成有效宣誓。当今皇帝及其神君父亲的敕令对此已有明确规定。

<a id="12.3.4.2"></a>

**2.** 宣誓金额原则上可以不设上限。但我想知道，法官能否为宣誓规定一个限额，使宣誓金额不得超过某一确定数额，以免有人借机漫无限度地宣誓。显然，是否提出宣誓要求，属于法官的裁量权。那么，既然法官可以不提出宣誓要求，是否也可以为宣誓金额设定上限？不过，将此事交由善意诉讼法官裁量，也符合其职权。

<a id="12.3.4.3"></a>

**3.** 还应考察：提出宣誓要求的法官，能否不采纳宣誓结果，而径行判决被告无罪，或者判处低于宣誓金额的数额？较可取的意见是，若有重大理由，且此后发现新的证据，法官可以这样做。

<a id="12.3.4.4"></a>

**4.** 可以确定，因过失不得提出宣誓要求，而应由法官自行估价。

### <a id="12.3.5"></a>12.3.5　马尔基安《规则》第四卷

<a id="12.3.5.pr."></a>

**序言（pr.）** 在对物诉讼（*actiones in rem*）、出示之诉以及善意诉讼（*bonae fidei iudicia*）中，可以进行诉讼标的估价宣誓。

<a id="12.3.5.1"></a>

**1.** 但是，法官可以预先确定宣誓金额的上限；因为他原本就有权一开始不提出宣誓要求。

<a id="12.3.5.2"></a>

**2.** 同样，即使已经宣誓，法官仍可判决被告无罪，或者判处低于宣誓金额的数额。

<a id="12.3.5.3"></a>

**3.** 但是，在上述所有诉讼中，只有因诈欺才进行诉讼标的估价宣誓，不因过失而宣誓；过失应由法官估价。

<a id="12.3.5.4"></a>

**4.** 当然，有时在严法诉讼（*actio stricti iudicii*）中也应进行诉讼标的估价宣誓。例如，允诺交付奴隶斯提库斯的人迟延履行，而斯提库斯后来死亡；因为对于已经不存在的标的，法官若不参考宣誓，便无法估价：

### <a id="12.3.6"></a>12.3.6　保罗《告示评注》第二十六卷

**正文** 至于其他情形，如果依据要式口约或遗嘱提起诉讼，通常不进行诉讼标的估价宣誓。

### <a id="12.3.7"></a>12.3.7　乌尔比安《告示评注》第八卷

**正文** 通常认为，除诉讼权利主体（*dominus litis*）外，不应由他人进行诉讼标的估价宣誓。因此，帕比尼安说，只有以自己名义使诉讼正式成立（*litem suo nomine contestatus est*）的人，才可以宣誓。

### <a id="12.3.8"></a>12.3.8　马尔凯卢斯《学说汇纂》第八卷

**正文** 监护人不愿将其占有的一项财物返还给已经成年的被监护人。我询问：应当按该物的价值判决，还是按诉讼标的估价宣誓所确定的金额判决？答复是：按该物的价格，也就是按其价值估算诉讼标的，并不公平，因为既应惩罚抗命行为，又应将标的物价格更多地交由权利人裁定；请求人已获准就诉讼标的宣誓估价。

### <a id="12.3.9"></a>12.3.9　雅沃莱努斯《卡西乌斯著作》第十五卷

**正文** 提起盗窃之诉时，宣誓应当表述为“盗窃发生时该物价值若干”（*tanti rem fuisse cum furtum factum sit*），不得加上“或价值更高”（*eo plurisve*）；因为该物即使价值更高，也必然至少值所宣誓的数额。

### <a id="12.3.10"></a>12.3.10　卡利斯特拉图《疑难集》第一卷

**正文** 对于某人拒不出示的文书，允许原告就出示该等文书对自己具有何种利益作诉讼标的估价宣誓，并据此判令被告给付相应金额；神君康茂德也曾以敕答确认此规则。

### <a id="12.3.11"></a>12.3.11　保罗《答复集》第三卷

**正文** 对于依法必须作出的诉讼标的估价宣誓，通常不易追究宣誓者的伪誓责任。
