## 12.6.0　论不当给付返还之诉（*De condictione indebiti*）

### <a id="12.6.1"></a>12.6.1　乌尔比安《评告示》第二十六卷

<a id="12.6.1.pr."></a>

**序言（pr.）** 现在应当讨论不当给付之后的返还。

<a id="12.6.1.1"></a>

**1.** 如果某人不知道给付并非其债务而予以清偿，就可以提起本诉请求返还；但如果他明知自己不负债仍予清偿，则不得请求返还。

### <a id="12.6.2"></a>12.6.2　乌尔比安《评萨宾》第十六卷

<a id="12.6.2.pr."></a>

**序言（pr.）** 如果某人付款时约定：若后来证明该款并非债务，或者《法尔基第法》的扣减事由出现，就应将款项返还，那么可以请求返还；因为双方之间已经订立了契约。

<a id="12.6.2.1"></a>

**1.** 如果有人依据遗嘱付款，而该遗嘱后来被证明是伪造的、违反义务的、无效的或被撤销的，可以请求返还；即使经过很长时间才发现遗产负有债务，也可以请求返还。又如，长期被隐匿的遗嘱附录后来被出示，其中撤销了已经支付的遗赠，或者由于还向他人留下遗赠而减少了原遗赠，也可以请求返还。神圣的哈德良皇帝曾就违反义务的遗嘱和伪造遗嘱作出敕答：应向遗产归属已由判决确定的一方授予诉权。

### <a id="12.6.3"></a>12.6.3　帕比尼安《问题集》第二十八卷

遗赠已经支付后，如果出现新的、出乎意料的事由而使继承人丧失遗产，结论也相同。例如，后来出生了遗腹子，而继承人原先不知道该子在母腹中；或者儿子从敌方归来，而父亲曾错误地以为他已经死亡。神圣的提图斯·安敦尼皇帝曾作出敕答：应准许遗腹子或通过诉讼取得遗产的儿子，对已受领遗赠的人提起准诉权之诉。其理由是，善意占有人仅在其所获利益范围内承担责任；无过错付款的人不承担此类债权不能实现的风险。

### <a id="12.6.4"></a>12.6.4　保罗《评萨宾》第三卷

神圣的哈德良皇帝还曾就后来出示另一份遗嘱的情形作出相同敕答。

### <a id="12.6.5"></a>12.6.5　乌尔比安《评萨宾》第十六卷

由一人付款、另一人请求返还，并非新例。例如，未满二十五岁者轻率地接受继承并支付遗赠后，获得恢复原状时，阿里乌斯·提提安努斯收到的敕答认为，请求返还的权利不属于该未成年人本人，而属于取得遗产的人。

### <a id="12.6.6"></a>12.6.6　保罗《评萨宾》第三卷

<a id="12.6.6.pr."></a>

**序言（pr.）** 拉贝奥在《后书》中写道：如果你的代理人支付了不应支付的款项，而你不予追认，可以请求返还。塞尔苏斯则认为，如果支付的是应付款，就不得请求返还。因为某人委任代理人处理自己的事务时，也被认为委托了他向债权人付款；无须再等待委任人事后追认。

<a id="12.6.6.1"></a>

**1.** 拉贝奥还说，如果代理人收到不当给付，而本人不予追认，可以请求返还。

<a id="12.6.6.2"></a>

**2.** 塞尔苏斯说，向代理人支付应付款的人立即获得免责，无须考察本人是否追认。但如果代理人收取了不应支付的款项，就必须有本人追认；因为代理人似乎并未获委托收取这类款项。因此，如果本人不予追认，应向代理人请求返还。

<a id="12.6.6.3"></a>

**3.** 尤利安说，监护人或代理人付款后都不能请求返还；无论他们支付的是自己的钱，还是未适婚人或本人的钱，结论均相同。

### <a id="12.6.7"></a>12.6.7　庞波尼《评萨宾》第九卷

因错误而支付的不当给付，可以请求返还原物或同等之物。

### <a id="12.6.8"></a>12.6.8　保罗《评萨宾》第六卷

如果有人代无清偿能力的丈夫向妻子付款，就不得请求返还；因为该款本来就是妻子有权取得的债务。

### <a id="12.6.9"></a>12.6.9　乌尔比安《评告示》第六十六卷

丈夫即使已无力履行义务，仍支付嫁资的，也处于不得请求返还的情形。

### <a id="12.6.10"></a>12.6.10　保罗《评萨宾》第七卷

约定在将来某日履行的债务人，仍然是债务人；因此，他不能请求返还在期限届满前已经支付的款项。

### <a id="12.6.11"></a>12.6.11　乌尔比安《评萨宾》第三十五卷

如果某人因特有财产之诉而被起诉，却因疏忽支付了超过该特有财产数额的款项，不得请求返还。

### <a id="12.6.12"></a>12.6.12　保罗《评萨宾》第七卷

我误以为自己有义务把我土地的用益权授予你，便将其授予你；如果我在请求返还之前死亡，返还之诉也会转移给我的继承人。

### <a id="12.6.13"></a>12.6.13　保罗《评萨宾》第十卷

<a id="12.6.13.pr."></a>

**序言（pr.）** 奴隶在自然法上也负有债务。因此，如果有人以奴隶名义付款，或者奴隶本人获释后付款，正如庞波尼所写，若款项来自该奴隶可以自由管理的特有财产，就不得请求返还。由此，以奴隶为债务人而接受的保证人也应承担责任；为该奴隶提供的质押物也有效。如果获准管理特有财产的奴隶将某物质押以担保其债务，应给予准用质押之诉。

<a id="12.6.13.1"></a>

**1.** 同样，未适婚人在监护人未授权的情况下借款，并因此变得富有；他成年后偿还的，不得请求返还。

### <a id="12.6.14"></a>12.6.14　庞波尼《评萨宾》第二十一卷

因为按照自然公平原则，任何人都不应因他人受损而变得富有。

### <a id="12.6.15"></a>12.6.15　保罗《评萨宾》第十卷

<a id="12.6.15.pr."></a>

**序言（pr.）** 不当给付返还之诉属于自然法；因此，给付之物所增加的部分也包括在返还请求中，例如女奴所生的孩子或因河流冲积而增加的土地。受领人善意取得的孳息也应纳入返还之诉。

<a id="12.6.15.1"></a>

**1.** 即使交付的是他人的钱币，也可以提起返还之诉，以请求返还其占有。例如，我错误地以为自己有义务向你交付某物的占有，便将该物交付给你；我可以提起返还之诉。又如，我使你取得某物的占有，以至于你可以通过长期时效使该占有不被剥夺，即使如此，我仍可正确地对你提起不当给付返还之诉。

<a id="12.6.15.2"></a>

**2.** 如果所交付之物上的用益权属于他人，我可以扣除用益权后向你提起返还之诉。

### <a id="12.6.16"></a>12.6.16　庞波尼《评萨宾》第十五卷

<a id="12.6.16.pr."></a>

**序言（pr.）** 对附条件债务因错误而作出的清偿，在条件尚未成就时可以请求返还；条件一旦成就，就不得请求返还。

<a id="12.6.16.1"></a>

**1.** 对于约定在不确定日期履行的债务，期限届至后不得请求返还。

### <a id="12.6.17"></a>12.6.17　乌尔比安《评告示》第二卷

如果我承诺在自己死亡时给付，却在此之前付款，塞尔苏斯说我不得请求返还；这一意见正确。

### <a id="12.6.18"></a>12.6.18　乌尔比安《评萨宾》第四十七卷

如果债务所附条件必然会成就，清偿后不得请求返还；相反，如果所附条件是否成就尚不确定，在条件成就前付款，则可以请求返还。

### <a id="12.6.19"></a>12.6.19　庞波尼《评萨宾》第二十二卷

<a id="12.6.19.pr."></a>

**序言（pr.）** 如果债务人因对其有利的罚则抗辩而获释，债务的自然效力仍然存在，因此已付款不得请求返还。

<a id="12.6.19.1"></a>

**1.** 即使某人所受领的是对他本人确实存在的债务，如果付款人并不负有该债务，仍可请求返还。例如，某人错误地以为自己是继承人或遗产占有人，便向遗产债权人付款；真正的继承人并未因此免责，付款人也可以请求返还其所付之款。虽然受领人取得的确是对他本人负有的债务，但只要付款人本人不负有该债务，就可以请求返还。

<a id="12.6.19.2"></a>

**2.** 如果我误以为自己负有债务而支付钱币，其中一半属于他人，另一半属于我，我可以请求返还该款项的一半，而不是请求返还具体钱币。

<a id="12.6.19.3"></a>

**3.** 如果我以为自己欠你斯提库斯或潘菲卢斯，但实际上只欠斯提库斯，却把潘菲卢斯交给你，我可以将其作为不当给付请求返还；因为我并未以该奴隶清偿自己所欠的债务。

<a id="12.6.19.4"></a>

**4.** 如果两名连带债务人共欠十枚钱币，却同时支付了二十枚，塞尔苏斯说，每人可以请求返还五枚。因为二人原本共欠十枚，却支付了二十枚；双方都可以请求返还超过债务的部分。

### <a id="12.6.20"></a>12.6.20　尤利安《学说汇纂》第十卷

如果主债务人与保证人同时清偿，在这种情形下，他们与两名共同允诺债务人没有区别。因此，关于后者的一切规则，也都可以适用于前者。

### <a id="12.6.21"></a>12.6.21　保罗《问题集》第三卷

但是，如果你设定两名债务人所负的并非同一笔金钱债务，而是择一给付的债务，例如应交付斯提库斯或潘菲卢斯，或者应交付一件托加袍或一千第纳里，那么，两人同时给付时不能依前述规则请求返还各自的一部分，因为他们起初也不能按这种方式履行。在这种情况下，应由债权人选择向谁受领，以排除另一方的返还请求。

### <a id="12.6.22"></a>12.6.22　庞波尼《评萨宾》第二十二卷

<a id="12.6.22.pr."></a>

**序言（pr.）** 如果我以为自己曾承诺向你或提提乌斯给付，但实际上我既未向任何一方作出承诺，或要式口约中并未包含提提乌斯，那么，即使我向提提乌斯付款，也可以向他请求返还。

<a id="12.6.22.1"></a>

**1.** 我本应保留通行权，却因错误将土地作为无地役权负担的土地交付；我可以提起不确定给付返还之诉，请求准许我通行。

### <a id="12.6.23"></a>12.6.23　乌尔比安《评萨宾》第四十三卷

<a id="12.6.23.pr."></a>

**序言（pr.）** 庞波尼提出了一个精当的问题：如果某人以为自己本人或自己代理的当事人已经达成和解，并以为是根据该和解而付款，但实际上并未达成和解，是否可以请求返还？他认为可以，因为付款所依据的是虚假的原因。我认为，如果付款所期待的和解最终没有成立，或者和解后来被撤销，也应作相同处理。

<a id="12.6.23.1"></a>

**1.** 如果判决作出后有人达成和解并付款，可以请求返还，因为和解被认为不发生效力；神圣的安敦尼皇帝与其神圣的父亲曾就此作出敕答。不过，因这类和解而支付的款项仍可予以保留，并抵充判决债务。那么，如果有人提起上诉，或判决是否已经作出、判决是否有效本身尚不确定，又应如何处理？更可取的意见是，和解此时有效。应当认为，只有在当事人就一项确定无疑、且不得再以任何救济方式挑战的判决达成和解时，前述敕答才适用。

<a id="12.6.23.2"></a>

**2.** 同样，如果有人就遗嘱所留的扶养给付达成和解并付款，显然可以请求返还，因为元老院决议使该和解无效。

<a id="12.6.23.3"></a>

**3.** 如果有人在和解后仍被判决承担责任，虽属欺诈，但判决仍然有效。若在争讼程序确定前达成和解，对方想继续诉讼时，可以提出欺诈抗辩；如果在争讼程序确定后和解，仍可以在随后诉讼中提出欺诈抗辩，因为违背和解、进一步请求给付的人是在实施欺诈。因此，被判决承担责任的人可以请求返还其依和解支付的款项。诚然，他是基于某种原因而付款；通常，基于某种原因给付、且该原因已经实现的款项不得请求返还。但这里不能认为原因已经实现，因为和解并未得到遵守。既然返还之诉因此发生，和解抗辩就不适用；返还之诉和抗辩不能同时发生效力。

<a id="12.6.23.4"></a>

**4.** 如果某项法律一开始就规定双倍或四倍诉讼，那么，基于虚假原因而支付的款项可以请求返还。

### <a id="12.6.24"></a>12.6.24　乌尔比安《评萨宾》第四十六卷

如果某人知道自己可以依永久抗辩保护自己，却仍承诺给付某物以求免责，就不得提起返还之诉。

### <a id="12.6.25"></a>12.6.25　乌尔比安《评萨宾》第四十七卷

两名保证人共同为债务人担保十枚钱币，债务人随后支付三枚，之后两名保证人各支付五枚。意见认为，后付款的保证人可以请求返还三枚。这样处理是有道理的：债务人支付三枚后，只剩七枚债务；保证人清偿后，超额支付了三枚。

### <a id="12.6.26"></a>12.6.26　乌尔比安《评告示》第二十六卷

<a id="12.6.26.pr."></a>

**序言（pr.）** 如果某人没有偿还本金，而是支付了不应支付的利息，只要本金本身确实到期，他就不得请求返还。但如果所付利息超过法定上限，神圣的塞维鲁皇帝曾作出敕答——我们也依此规则处理——款项虽不得立即请求返还，却应抵充本金；如果此后又偿还本金，则可以将该利息作为不当偿还的本金请求返还。反之，如果本金先已偿还，超过法定上限的利息就可以像不当支付的本金那样请求返还。如果本金和利息同时偿还，又当如何？可以认为此时也可以请求返还。

<a id="12.6.26.1"></a>

**1.** 超过本金两倍的利息，以及利息上的利息，既不得写入要式口约，也不得请求支付；已经支付的，应予返还。未来利息的利息也适用同一规则。

<a id="12.6.26.2"></a>

**2.** 如果某人误以为自己欠有本金而支付利息，可以请求返还；不能认为他是明知不负债而付款。

<a id="12.6.26.3"></a>

**3.** 不当给付不仅包括根本不存在债务的情形，也包括因某项永久抗辩而不得请求给付的情形。因此，这类付款也可以请求返还，除非付款人明知自己可以援用抗辩保护自己。

<a id="12.6.26.4"></a>

**4.** 如果我只欠一百，却误以为欠二百而交付了一块价值二百的土地，马尔凯卢斯在《学说汇纂》第二十卷中写道，我可以请求返还，而原有的一百债务仍然存在。虽然以物抵债可以使债务人免责，但如果债务人因误认债额而交付价值更高的物，就不会使该物的一部分与金钱债务相混同；因为无人会被迫接受共有关系。整块土地的返还之诉仍然存在，债务也未消灭；在钱款债务清偿前，土地可以继续留置。

<a id="12.6.26.5"></a>

**5.** 马尔凯卢斯还说，如果某人欠的是钱，却误以为自己欠得更多而交付了价值较高的橄榄油；或者他欠的是橄榄油，却误以为欠的数量更多而交付了过量橄榄油，应当仅请求返还多出的橄榄油，而非请求返还全部橄榄油并据此消灭债务。

<a id="12.6.26.6"></a>

**6.** 马尔凯卢斯又补充说，如果我只应取得某土地的一部分，却误以为应取得整块土地，并按整块土地的估价支付了价款，可以请求返还的不是全部价款，而是相当于不应支付部分的价款。

<a id="12.6.26.7"></a>

**7.** 永久抗辩竟能产生返还之诉，其效力甚至达到如下程度：尤利安在《学说汇纂》第十卷中写道，如果土地买受人遗嘱命令继承人解除出卖人的买卖债务，出卖人随后在不知情的情况下交付土地，出卖人可以请求返还土地。同样，如果债权人命令继承人免除自己的债务，而债务人在不知情的情况下付款，也可以请求返还。

<a id="12.6.26.8"></a>

**8.** 如果有人向家父权下的儿子付款，而该付款人本来是儿子的特有财产债务人；若其不知道特有财产已被撤销，就因付款而免责。如果他明知特有财产已被撤销仍付款，则不得提起返还之诉，因为他明知该款并非债务。

<a id="12.6.26.9"></a>

**9.** 家父权下的儿子违反《马其顿元老院决议》借款后予以清偿，后来成为其父的继承人并想请求返还钱币的，可以通过抗辩阻却其所有物返还请求。

<a id="12.6.26.10"></a>

**10.** 如果某人误以为自己因仲裁协议而被判决承担责任，并据此付款，可以请求返还。

<a id="12.6.26.11"></a>

**11.** 对遗产继承人或遗产占有人付款时，如果受领人确实为遗产进行抗辩或主张权利，可以请求返还不应支付的款项；但如果受领人不为遗产进行抗辩，甚至已经支付的应付款也可以请求返还。

<a id="12.6.26.12"></a>

**12.** 自由人以为自己欠释主（*patronus*）劳务，便向释主提供劳务。尤利安在《学说汇纂》第十卷中写道，即使他以为自己负有义务而提供劳务，也不得请求返还，因为自由人依自然法确实负有向释主提供劳务的义务。如果自由人并未提供劳务，而是释主要求其提供服务、双方就此折价结算并由自由人付款，他也不得请求返还。

但如果自由人向释主提供的不是礼仪性劳务，而是绘画等专业劳务；他以为自己有义务提供这些劳务，那么是否可以请求返还，仍须考察。塞尔苏斯在《学说汇纂》第六卷中认为，劳务有其特殊性质：不同的人提供的劳务并不相同，也不是向同一人提供；人的体力、年龄、时机和自然禀赋常常改变劳务的性质，因此，即使愿意，也不可能返还相同劳务。他还说，这类劳务可以估价；有时我们虽交付一物，却可以请求返还另一物。例如，我不当交付一块土地，可以请求返还其孳息；我不当交付一名奴隶，而你并无欺诈地以低价出售，那么你只须返还实际取得的价款；或者我出钱使奴隶增值，这些费用难道不应估价吗？塞尔苏斯认为，本案中也可以请求返还相当于雇用这些劳务所需支付的金额。

如果释主拒绝接受礼仪性劳务，马尔凯卢斯在《学说汇纂》第二十卷中讨论了这一问题。他说，自由人不承担责任，除非劳务属于专业技能；因为这类劳务即使释主指示，也可以向他人提供。但是，如果受委托者已经提供了礼仪性劳务，就不得请求返还：既不能向接受劳务的债权人请求，因为该人是基于他人之故而受领、且只是取得自己应得之物；也不能向释主请求，因为自由人依自然法本来就欠他这些劳务。

<a id="12.6.26.13"></a>

**13.** 如果我约定给付十枚钱币或交付斯提库斯，却支付了五枚，能否请求返还？问题在于，支付五枚是否使我部分免责：如果免责，就不得请求返还；如果没有免责，便可以请求返还。塞尔苏斯在《学说汇纂》第六卷、马尔凯卢斯在第二十卷中写道，债务并未因支付一半而部分消灭。因此，支付五枚的人是否免责仍处于待定状态；债权人可以请求其再付五枚或交付斯提库斯。如果他又支付五枚，就应认为前后两次支付的五枚都是清偿债务；但如果他交付了斯提库斯，就可以把先前的五枚作为不当给付请求返还。后一项给付将决定先前五枚究竟是清偿了债务，还是属于不当给付。

如果支付五枚后又交付斯提库斯，而我宁愿保留五枚、返还斯提库斯，能否得到支持？塞尔苏斯提出这一问题，并认为此时已经产生了针对五枚钱币的返还之诉，尽管两项给付同时完成时，我原本可以选择保留其中一项。

<a id="12.6.26.14"></a>

**14.** 他还说，如果受诺人有两名继承人，向其中一人支付五枚、向另一人交付斯提库斯的一部分，也不可以；允诺人有两名继承人时同样如此。因此，只有向两名继承人各付五枚，或者向两人各交付斯提库斯的相应部分，债务才会消灭。

### <a id="12.6.27"></a>12.6.27　保罗《评告示》第二十八卷

如果某人以为自己应在某一确定地点履行债务，却在该地支付了不应支付的款项，可以在任何地点请求返还；请求返还的方式并不必然与付款人原先的想法一致。

### <a id="12.6.28"></a>12.6.28　保罗《告示论摘要》卷一

如果法官错误地宣告被告无责，而被宣告无责的人自愿付款，就不得请求返还。

### <a id="12.6.29"></a>12.6.29　乌尔比安《论答辩》第二卷

有时，付款人的身份本身使返还之诉得以成立；例如，未适婚人在监护人未授权时付款、精神错乱者付款，或被禁止管理财产的人付款，通常都可以请求返还。如果钱币仍然存在，可以提起所有物返还之诉；如果已被花用，则可以提起返还之诉。

### <a id="12.6.30"></a>12.6.30　乌尔比安《论答辩》第十卷

在某些不得抵销的情形中，同一人既是债权人又是债务人；如果他在这种情况下付款，就不能以不当给付为由提起返还之诉，而应请求清偿自己的债权。

### <a id="12.6.31"></a>12.6.31　乌尔比安《意见集》第一卷

某人因错误而向债权人承诺的金额超过其继承份额所及，可以通过返还之诉请求返还其不当允诺的部分。

### <a id="12.6.32"></a>12.6.32　尤利安《学说汇纂》第十卷

<a id="12.6.32.pr."></a>

**序言（pr.）** 如果某人欠交潘菲卢斯或斯提库斯中的一人，却同时把两人都交付了；事后若其中一人或两人都不复存在，他不得请求返还，因为尚存之物仍属于清偿给付。

<a id="12.6.32.1"></a>

**1.** 如果保证人与债权人约定债权人不得向他请求给付，而保证人因疏忽仍付款，他可以向作出要式口约的债权人请求返还。因此，主债务人仍然负有债务，但保证人可以援用自己的抗辩保护自己。无论由保证人本人还是其继承人付款，结论均相同；但如果主债务人成为该保证人的继承人并付款，就不得请求返还，同时也因此免责。

<a id="12.6.32.2"></a>

**2.** 如果妇女以为自己负有提供嫁资的义务，那么她以嫁资名义交付的一切都不得请求返还。因为即使消除了她的错误认识，仍存在出于亲情义务而给付的原因；基于这一原因给付的款项不得请求返还。

<a id="12.6.32.3"></a>

**3.** 概括承诺交付“一个奴隶”的人，与承诺交付“一个奴隶或十枚钱币”的人相同。因此，如果他以为自己允诺交付斯提库斯而交付了斯提库斯，可以请求返还；但交付任何其他奴隶都足以使其免责。

### <a id="12.6.33"></a>12.6.33　尤利安《学说汇纂》第三十九卷

如果我在你的土地上建造房屋，而你占有该房屋，就不能提起返还之诉，因为我们之间并未订立任何交易。支付不应支付的钱款的人毕竟实施了某种交易；但土地所有人占有他人在自己土地上建造的房屋时，并未订立任何交易。如果在他人土地上建造房屋的人亲自交付了占有，也不能提起返还之诉，因为他没有使受领人取得财产；所有人只是开始占有自己的财产。因此，众所周知，如果某人误以为自己是继承人而修缮遗产中的公寓楼，他只能通过留置该物保全费用，不能以其他方式请求返还。

### <a id="12.6.34"></a>12.6.34　尤利安《学说汇纂》第四十卷

有人通过信托遗赠取得全部遗产，并另获遗赠一块土地，条件是向继承人支付十枚钱币。继承人认为遗产负债过重，遂依据《特雷贝利安元老院决议》返还遗产。此时，他没有支付该款的法律原因；因此，他若以满足条件为名付款，可以通过返还之诉请求返还。

### <a id="12.6.35"></a>12.6.35　尤利安《学说汇纂》第四十五卷

某人因对方未进行诉讼防御而付款，即使后来准备进行防御，也不得请求返还已付之款。

### <a id="12.6.36"></a>12.6.36　保罗《阿尔费努《学说汇纂》摘要》第五卷

某人的奴隶未经主人知情，借出一只酒盆（*magis*）。受借人把酒盆设为质物后逃走；质权人声称，除非收到钱款，否则不会返还酒盆。质权人从小奴隶处收取钱款后，便返还了酒盆。有人问，该笔钱是否可以向质权人请求返还。答复是：如果质权人明知酒盆属于他人，却接受其作为质物，就构成盗窃；因此，如果他从小奴隶处收钱是为了摆脱盗窃责任，可以请求返还。但如果他不知道酒盆属于他人，就不构成盗窃。同样，如果奴隶以提供质物之人的名义向质权人付款，则不得向质权人请求返还。

### <a id="12.6.37"></a>12.6.37　尤利安《致乌尔塞乌斯·费罗克斯》第三卷

我不知情地从你处买下了我自己的奴隶，并向你支付了价款。我认为，无论你知道还是不知道该奴隶属于我，我都可以通过返还之诉向你请求返还价款。

### <a id="12.6.38"></a>12.6.38　阿非利加努《问题集》第九卷

<a id="12.6.38.pr."></a>

**序言（pr.）** 两名兄弟同处于父亲的权力之下，其中一人向另一人借款，并在父亲去世后偿还。有人问，他能否请求返还。答复是：对于自己作为父亲继承人所取得的份额，他当然可以请求返还；对于兄弟继承的份额，只有在兄弟从他的特有财产中取得的金额不少于该债务时，他才可以请求返还。因为兄弟继承了该特有财产的一部分，这一事实被视为已经消灭了原有的自然债务。即使该特有财产被特别遗赠给作为债务人的儿子，也应从特有财产中扣除该债务。

这一观点尤其符合尤利安所采的意见：如果兄弟欠的是外人，并在父亲死后向外人偿还，那么，在遗产分割之诉中，他可以从共同继承人处取回相当于债权人原本可以通过特有财产之诉向他们请求的金额。因此，即使尚未清偿时就提起遗产分割之诉，也应公平地分割特有财产，使其共同继承人赔偿相应数额。既然对外部债权人应当保护该兄弟，那么，对于他欠兄弟的债务，就更应由共同继承人使他免受损失。

<a id="12.6.38.1"></a>

**1.** 有人问，如果父亲借钱给儿子，而儿子被解放出父权后偿还，能否请求返还。答复是：如果父亲没有留下儿子的任何特有财产，就不得请求返还。自然债务仍然存在的证据是，外人若在一年内提起特有财产之诉，父亲可以扣除儿子欠自己的债务。

<a id="12.6.38.2"></a>

**2.** 相反，如果父亲向已经被解放出父权的儿子清偿自己所欠的债务，也不得请求返还。自然债务仍然存在的证据相同：外人若在一年内提起特有财产之诉，父亲欠儿子的款项也应计入特有财产。外人作为继承人向被剥夺继承权的儿子支付父亲所欠款项时，结论也相同。

<a id="12.6.38.3"></a>

**3.** 我为遗赠取得了充分担保，保证人向我付款后，才发现该遗赠并非应付之款。有人认为保证人可以请求返还。

### <a id="12.6.39"></a>12.6.39　马尔基安《制度论》第八卷

如果某人本可要求信托遗赠受益人提供担保，却没有要求；他后来支付了超过债务的金额，神圣的塞维鲁皇帝和安敦尼皇帝曾作出敕答，确认他可以通过返还之诉请求返还。

### <a id="12.6.40"></a>12.6.40　马尔基安《规则集》第三卷

<a id="12.6.40.pr."></a>

**序言（pr.）** 持有永久抗辩的人，因错误而付款后可以请求返还；但这并非绝对规则。如果抗辩是为保护被起诉的人而设，就可以请求返还，例如关于代为承担债务的元老院决议所设的抗辩。反之，如果抗辩是为了惩罚债权人而设，错误付款后也不得请求返还；例如，家父权下的儿子违反《马其顿元老院决议》借款，后来成为家父并偿还，就不得请求返还。

<a id="12.6.40.1"></a>

**1.** 如果通过信托遗赠于某一将来日期交付的房屋一部分在该日期前被烧毁，而继承人自行出资修复，修缮费用显然应从信托遗赠中扣除。如果继承人未作扣除便交付房屋，可以提起不确定给付返还之诉，因为其交付超过了应交付的数额。

<a id="12.6.40.2"></a>

**2.** 如果释主与自由人约定不再向其请求劳务，自由人此后支付的任何款项都可以请求返还。

### <a id="12.6.41"></a>12.6.41　内拉齐乌斯《札记》第六卷

未适婚人在监护人未授权的情况下向要式口约债权人作出允诺并付款，可以请求返还，因为他在自然法上也不负有该债务。

### <a id="12.6.42"></a>12.6.42　乌尔比安《评告示》第六十八卷

罚金一经支付，通常不得请求返还。

### <a id="12.6.43"></a>12.6.43　保罗《评普劳提乌斯》第三卷

如果某人宣誓称自己没有给付义务，争议便全部终结；据此支付的钱款应当可以请求返还。

### <a id="12.6.44"></a>12.6.44　保罗《评普劳提乌斯》第十四卷

即使款项是由非真正债务人支付，只要受领人取得的是自己应得之物，就不得向其请求返还。

### <a id="12.6.45"></a>12.6.45　雅沃勒努《普劳提乌斯论》第二卷

如果有人出售并交付了遗产，却没有扣留死者欠自己的债权，可以请求返还，因为通过返还之诉追回超过债务的给付是适当的。

### <a id="12.6.46"></a>12.6.46　雅沃勒努《普劳提乌斯论》第四卷

某人以继承人的名义，用继承人自己的钱支付了不应支付的遗赠；该付款人本人不得请求返还。但如果他未经继承人知情便交付其钱币，雅沃勒努说，所有人可以通过所有物返还之诉将其追回。对有体物也适用相同规则。

### <a id="12.6.47"></a>12.6.47　塞尔苏斯《学说汇纂》第六卷

你因错误而允诺了一笔本不应给付的钱；为你提供保证的人已经支付了这笔钱。我认为，如果保证人以你的名义付款，你应当对保证人负有义务，而要式口约债权人则对你负有返还义务；无须等你追认，因为可以认为你所委托的正是以你的名义付款。反之，如果保证人以自己的名义支付了本不应支付的钱，他可以向要式口约债权人请求返还，因为他依万民法支付了不当之款。不过，他若不能从受领人处追回款项，可以通过委任之诉向你请求，前提是他并非因不知情、未以抗辩驳回对方的请求而致其受损。

### <a id="12.6.48"></a>12.6.48　塞尔苏斯《学说汇纂》第六卷

某人允诺：若自己完成某事，或某事发生，便给付十；如果他在该事发生以前便交付了十，就不视为已经履行所允诺之事，因此可以请求返还。

### <a id="12.6.49"></a>12.6.49　莫德斯蒂努斯《规则集》第三卷

只有向实际受领钱款的人，才可以通过返还之诉请求返还；不能向仅因该给付而受益的人请求。

### <a id="12.6.50"></a>12.6.50　庞波尼乌斯《评昆图斯·穆基乌斯》第五卷

某人明知给付并无义务，却抱着日后请求返还的意思而给付的，不得请求返还。

### <a id="12.6.51"></a>12.6.51　庞波尼乌斯《评昆图斯·穆基乌斯》第六卷

对于某些原因，我们虽有留置的抗辩，却没有请求权；如果我们在这些情形下已经付款，就不得请求返还。

### <a id="12.6.52"></a>12.6.52　庞波尼乌斯《评昆图斯·穆基乌斯》第二十七卷

给付可以是基于原因（*ob causam*），也可以是为实现某一目的（*ob rem*）。基于既存原因给付，例如我因从你处取得某物，或因你已经做了某事而给付；即使该原因并不真实，也不得请求返还。为实现目的而给付，则是希望某事随后发生；如果该事没有发生，便可以请求返还。

### <a id="12.6.53"></a>12.6.53　普罗库鲁斯《书信集》第七卷

某主人在遗嘱中规定，奴隶支付十便可获得自由。奴隶不知遗嘱无效，便向我交付了十。有人问，谁可以请求返还。普罗库鲁斯答：如果奴隶交付的是其特有财产中的钱，而主人并未准许他如此处分，这些钱仍属于主人；主人应当通过所有物返还之诉请求返还，而非提起债权返还之诉。如果第三人应奴隶请求交付自己的钱，这些钱便成为我的财产；该奴隶的主人可以通过债权返还之诉请求返还，因为钱是以该奴隶的名义交付的。不过，更为宽厚而且更为妥当的做法，是让交付钱款的人直接取回自己的钱。

### <a id="12.6.54"></a>12.6.54　帕皮尼安《疑义集》第二卷

凡基于法律上无效或未能发生效力的事由而给付，且系因错误而为之者，均可提起债权返还之诉。

### <a id="12.6.55"></a>12.6.55　帕皮尼安《疑义集》第六卷

掠夺性占有人（*praedo*）出租城市不动产后，承租人以租金名义向其支付的款项，不得向付款人请求返还；但该占有人应对所有人负担义务。船舶运费亦同：如果船舶是由该占有人本人出租或经营的；奴隶劳务的报酬亦同：如果奴隶的劳务是由其本人出租的。反之，若未被出租的奴隶将报酬作为交给主人之物交给该掠夺性占有人，该钱并不因此成为受领人的财产。如果他收取的是由所有人出租的船舶运费，或出租公寓楼所得租金，他就应对未因付款而获免责的人承担返还责任。因此，通常所说的可以向掠夺性占有人请求返还孳息，只适用于孳息原本属于所有人的情形。

### <a id="12.6.56"></a>12.6.56　帕皮尼安《疑义集》第八卷

对于不当给付的判断，只要抗辩究竟是暂时性的还是永久性的尚不确定，便已足够。例如，某人约定在提图斯成为执政官之前不受起诉；提图斯若先去世，暂时性的抗辩可能转为永久抗辩；而提图斯一旦就任执政官，该抗辩便仅为暂时性的。因此，极有理由认为，在此期间已经支付的钱可以请求返还。正如将不得起诉的约定延至确定时点，并不比债务人依约定日期付款更能产生返还之诉；同样，效力根据不确定的法律抗辩，具有返还之诉的作用。

### <a id="12.6.57"></a>12.6.57　帕皮尼安《答复集》第三卷

<a id="12.6.57.pr."></a>

**序言（pr.）** 监护人以未适婚人的名义支付了不当之款，返还请求权属于该未适婚人。

<a id="12.6.57.1"></a>

**1.** 债权人指示债务人将所欠款项交给自己的代理人。若代理人收取了超过债务的金额，可以因不当受领而被起诉。反之，如果债权人明确指示代理人收取较大数额，则针对不当给付的诉权应当对指示付款的人提起；即使先前对代理人提起诉讼而未能成功，也不认为该诉权已经消灭。

### <a id="12.6.58"></a>12.6.58　帕皮尼安《答复集》第九卷

某人将信托遗赠留给一名被解放的奴隶，条件是他依遗嘱取得自由。该奴隶在不经裁判的情况下收取钱款后，被宣告为自由人（*ingenuus*）；此时可以请求返还该不当给付的信托遗赠。

### <a id="12.6.59"></a>12.6.59　帕皮尼安《定义集》第二卷

保证人依法已经免责，却因错误而支付钱款的，不妨碍其请求返还。反之，允诺债务人本人若先因错误付款，之后又支付钱款，则不得请求返还：先前那次无效给付既未消灭自然债务关系；如果允诺债务人确负有债务，也未消灭市民法上的债务。

### <a id="12.6.60"></a>12.6.60　保罗《疑义集》第三卷

<a id="12.6.60.pr."></a>

**序言（pr.）** 尤利安认为，真实债务人在诉讼标的确定后、裁判程序仍在进行时付款，不得请求返还，因为无论被判免责还是被判承担责任，他都不得请求返还。即使被判免责，他在自然法上仍是债务人。他说，这与某人作出如下允诺相似：“无论船舶是否从亚洲抵达，我都给付”；因为另一项给付的根据，均由同一原因产生。

<a id="12.6.60.1"></a>

**1.** 如果某人对于自己无条件负担的债务，以更新债务为目的作出附条件的允诺，许多人认为，在更新债务尚未确定期间，已经支付的钱可以请求返还，因为付款究竟是基于哪一项债务，尚不确定。即使设想不同的人分别以更新债务为目的，对同一笔钱作出无条件允诺和附条件允诺，结论也相同。不过，这一情形并不相同：在无条件和附条件的要式口约中，确定的是同一债务人将负担债务。

### <a id="12.6.61"></a>12.6.61　斯凯沃拉《答复集》第五卷

未适婚人的监护人以父亲遗产中的财产向若干父亲的债权人付款；后来遗产不足清偿债务，未适婚人便拒绝承受该遗产。有人问，监护人替债权人多付的部分，或者债权人收到的全部款项，是否应当返还。我答复：如果不存在欺诈，监护人或未适婚人对这些债权人没有请求权；但这些债权人应向其他债权人承担责任，返还其所收超过自身债权的部分。

### <a id="12.6.62"></a>12.6.62　麦基安《信托遗赠论》第四卷

即使在要式口约中列入的信托遗赠原本并非债务，只要允诺人明知这一点，仍以履行信义义务为目的作出允诺，该项给付便成为债务。

### <a id="12.6.63"></a>12.6.63　盖尤斯《论卡西乌斯》单卷本

内拉提乌斯举出这样一种情形：某人给付之物被视为债务，因而不得请求返还，但给付也不使其免责。例如，某人本应交付一个确定的奴隶，却交付了一个附条件解放奴隶（*statuliber*）。他之所以未获免责，是因为债权人没有取得对该奴隶的完整权利；但他也不得请求返还，因为他给付的是债务之物。

### <a id="12.6.64"></a>12.6.64　特里丰尼努斯《论争集》第七卷

主人将自己欠奴隶的钱支付给已获解放的自由人，即使他以为自己会因此对自由人负有某种诉权，也不得请求返还，因为他承认了自然债务。自由权由自然法确立，所有权则由万民法引入；同样，在返还之诉中，是否存在债务也应依自然法加以理解。

### <a id="12.6.65"></a>12.6.65　保罗《评普劳提乌斯》第十七卷

<a id="12.6.65.pr."></a>

**序言（pr.）** 总而言之，若要一般地讨论返还请求，应当知道，给付可以是基于和解、基于原因、基于条件、为实现目的，或者属于不当给付；所有这些情形都涉及是否可以请求返还。

<a id="12.6.65.1"></a>

**1.** 以和解名义给付的，即使双方之间并无其他实质关系，也不得请求返还。因为如果曾有诉讼，仅仅是双方不再继续争讼这一点，就可视为给付的原因。但是，如果明显揭露出恶意诬告，且和解尚未完成，则可以请求返还。

<a id="12.6.65.2"></a>

**2.** 基于原因给付的款项亦同。例如，我以为对方已经处理了我的事务，因而给付；即使事情实际上并未完成，只要我是出于赠与意思而给付，尽管我对事实的认识有误，也不得请求返还。

<a id="12.6.65.3"></a>

**3.** 如果遗赠或继承以某条件为基础，而遗赠并未留给我，或者遗赠已被撤回，我可以提起债权返还之诉，取回已经给付之物；因为我给付时并无缔结契约之意，给付所依据的原因并未发生。若我不愿或不能承受遗产，结论也相同。如果我的奴隶被附条件指定为继承人，而我先行给付，之后奴隶获释并承受遗产，则不能作相同处理，因为在这种情形下，预期之事已经发生。

<a id="12.6.65.4"></a>

**4.** 为实现某一目的而给付的，依公平与善意，可以请求返还；例如，我给你某物，是为了让你做某事，而你并未去做。

<a id="12.6.65.5"></a>

**5.** 请求返还不当给付的人，也应取回孳息和产物，但须扣除费用。

<a id="12.6.65.6"></a>

**6.** 不当给付谷物时，应当考虑其品质；如果受领人已经消费谷物，给付人可以请求其价额。

<a id="12.6.65.7"></a>

**7.** 如果给付的是居住利益，我可以请求返还钱款；其数额不是该住所本可出租的租金，而是你原本愿意支付的租金。

<a id="12.6.65.8"></a>

**8.** 如果我将不应给付的奴隶交给你，而你将其解放：你若明知该奴隶不应归你，便应承担其价额；你若不知情，则不承担该项价额责任，但仍应返还该自由人劳务的价值，并返还其遗产。

<a id="12.6.65.9"></a>

**9.** 不当给付不仅指根本不负债务而给付，也包括本应向甲给付却向乙给付，或者某人将他人所负的债务当作自己所负而予以清偿。

### <a id="12.6.66"></a>12.6.66　帕皮尼安《疑义集》第八卷

这项债权返还之诉基于公平与善意而设；凡发现一方在他方处持有无正当原因之物，通常均可通过该诉追回。

### <a id="12.6.67"></a>12.6.67　斯凯沃拉《学说汇纂》第五卷

<a id="12.6.67.pr."></a>

**序言（pr.）** 斯提库斯接受了遗嘱自由；立遗嘱人是他所认为的主人，并规定他须自死亡之日起连续十年，每年向继承人支付十。斯提库斯遵照命令，连续八年交付约定数额；后来他得知自己本为自由出生人，遂不再支付其余年份的款项，并获宣告为自由出生人。有人问，他能否将交给继承人的钱作为不当给付请求返还，以及应提起何种诉讼。我答复：如果他支付的钱既非通过自己的劳务取得，也非通过其善意服役之人的财产取得，则可以请求返还。

<a id="12.6.67.1"></a>

**1.** 监护人向其未适婚被监护人的债权人偿还了超过债务的数额，却未在监护事务之诉中将超额部分计入被监护人的账目。我问：他是否可以向债权人请求返还？答复：可以。

<a id="12.6.67.2"></a>

**2.** 提提乌斯有许多债权人，其中包括塞尤斯；他通过私下出售，将自己的财产交给梅维乌斯，以便清偿债权人。梅维乌斯把一笔钱支付给塞尤斯，认为该款仍属应付之债；但提提乌斯此前已经支付了该款。后来发现提提乌斯持有部分已付款项的收据。有人问，谁更有权请求返还这笔不当给付：债务人提提乌斯，还是为自身利益而被指定为代理人的梅维乌斯？答复：依所述事实，应由后来付款的人请求返还。

<a id="12.6.67.3"></a>

**3.** 同一人又问，在清算（*pariationes*）中通常记载的如下约款——“双方就本合同再无任何争议”——是否妨碍请求返还。答复：没有提出任何足以说明该约款会妨碍返还请求的理由。

<a id="12.6.67.4"></a>

**4.** 卢基乌斯·提提乌斯向未满二十五岁的盖尤斯·塞尤斯出借一笔确定数额的钱，并从他处收取了若干利息。盖尤斯·塞尤斯的继承人针对普布利乌斯·梅维乌斯向行省总督请求恢复原状，获准不清偿继承债务；但当时既未讨论，也未裁定继承人能否请求返还塞尤斯未满二十五岁期间已经支付的该笔本金利息。有人问，继承人能否请求返还盖尤斯·塞尤斯生前支付给债权人的利息。答复：依所述事实，死者以利息名义所支付的款项不得请求返还。又问：如果不能请求返还，继承人能否从另一笔债务中扣留这些利息？答复：也不能。
