## 12.5.0　论因不道德或不法原因的返还诉讼（*De condictione ob turpem vel iniustam causam*）

### <a id="12.5.1"></a>12.5.1　保罗《评萨宾》第十卷

<a id="12.5.1.pr."></a>

**序言（pr.）** 凡给付之物，或为某项事务而给付，或基于某项原因而给付；该事务或原因可以是不道德的，也可以是正当的。不道德又有三种情形：不道德性仅在给付人一方，而不在受领人一方；仅在受领人一方，而不在给付人一方；或者双方均有不道德之处。

<a id="12.5.1.1"></a>

**1.** 因正当事务而给付的，只有在所欲实现的事务未能实现时，才可以请求返还。

<a id="12.5.1.2"></a>

**2.** 但是，如果不道德原因在受领人一方，即使所欲实现的事务已经实现，仍可请求返还：

### <a id="12.5.2"></a>12.5.2　乌尔比安《告示评注》第二十六卷

<a id="12.5.2.pr."></a>

**序言（pr.）** 例如，我给你钱，是为了让你不犯亵渎圣物罪、不实施盗窃或不杀人。对于这种情形，尤利安写道，如果我给你钱让你不杀人，可以提起返还之诉（*condictio*）：

<a id="12.5.2.1"></a>

**1.** 同样，如果我给你钱，要求你返还我寄存在你处的物品，或者将文书返还给我，也可以请求返还。

<a id="12.5.2.2"></a>

**2.** 但是，如果我给你钱，是为了让法官在一个本应作出对我有利判决的案件中作出有利于我的判决，据说可以提起返还之诉；然而，此人也构成犯罪（因为他似乎贿赂了法官），而不久前本朝皇帝已规定，应使其败诉。

### <a id="12.5.3"></a>12.5.3　保罗《评萨宾》第十卷

**正文** 如果给付人和受领人双方均有不道德之处，我们认为不得请求返还；例如，给付钱款是为了使法官作出不公正判决。

### <a id="12.5.4"></a>12.5.4　乌尔比安《告示评注》第二十六卷

<a id="12.5.4.pr."></a>

**序言（pr.）** 如果给付是为了换取不正当性行为（*stuprum*），或者某人因通奸被当场发现后花钱赎身，也不得请求返还；萨宾和佩加苏斯均作此答复。

<a id="12.5.4.1"></a>

**1.** 同样，如果窃贼给钱让他人不要告发自己，由于双方均有不道德之处，不得请求返还。

<a id="12.5.4.2"></a>

**2.** 如果不道德之处仅在受领人一方，凯尔苏斯说，可以请求返还；例如，我给你钱，让你不要侵害我的人格权益。

<a id="12.5.4.3"></a>

**3.** 但是，给妓女的钱不得请求返还；拉贝奥和马尔凯卢斯如此写道。他们提出的是另一种理由，并非因为双方均有不道德之处，而是因为不道德之处仅在给付人一方：她作为妓女，其行为虽不道德，但她作为妓女受领钱款并非不道德。

<a id="12.5.4.4"></a>

**4.** 如果我给你钱，让你告发我的逃奴或盗窃我财物的窃贼，已给付的钱不得请求返还，因为你受领钱款并无不道德之处。但是，如果你从我的逃奴那里收钱，以便不告发他，我可以像对窃贼那样对你提起返还之诉。如果窃贼本人为了告发窃贼或逃奴的同伙而从我这里收钱，我认为也可以提起返还之诉。

### <a id="12.5.5"></a>12.5.5　尤利安《评乌尔塞乌斯·费罗克斯》第三卷

**正文** 如果有人从我的奴隶那里收钱，承诺不告发该奴隶实施的盗窃，无论他后来是否告发，普罗库鲁斯答复说，这笔钱都可以请求返还。

### <a id="12.5.6"></a>12.5.6　乌尔比安《评萨宾》第十八卷

**正文** 萨宾始终赞同古人所持的意见：某人基于不法原因持有的财物，可以通过返还之诉请求返还。凯尔苏斯也持此说。

### <a id="12.5.7"></a>12.5.7　庞波尼乌斯《评萨宾》第二十二卷

**正文** 如果依据一项以暴力胁迫订立的要式口约追缴了钱款，可以确定，得请求返还。

### <a id="12.5.8"></a>12.5.8　保罗《疑难集》第三卷

**正文** 如果你基于不道德原因向提提乌斯作出允诺，即使他请求给付时，你可以通过恶意抗辩或事实抗辩（*exceptio doli mali vel in factum*）驳回其请求，但如果你已经给付，便不得请求返还。因为要式口约这一直接原因，因抗辩而失去效力后，原先的原因——即不道德性——仍然存在。此外，如果给付人和受领人双方的原因均不道德，则占有人地位较优，因此不得请求返还，即使给付是依据要式口约作出的。

### <a id="12.5.9"></a>12.5.9　保罗《评普劳提乌斯》第五卷

<a id="12.5.9.pr."></a>

**序言（pr.）** 如果我把衣物借给你使用，之后又给你钱，以取回衣物，据答复，我可以正当地提起返还之诉。尽管给付是为某项事务而作，且该事务已经实现，但该给付仍是不道德的。

<a id="12.5.9.1"></a>

**1.** 如果你收了我的钱，以返还我租给你的物品、你卖给我的物品，或者我委托你返还的物品，我可以对你提起租赁之诉、买卖之诉或委任之诉。但是，如果我给你钱，是为了让你返还依据遗嘱或要式口约而欠我的物品，则只能就以此为目的给付的钱款提起返还之诉。庞波尼乌斯也这样写道。
