## 12.1.0　论信用给付之物、确定请求及返还之诉（*De rebus creditis si certum petetur et de condictione*）

### <a id="12.1.1"></a>12.1.1　乌尔比安《评告示》第二十六卷

<a id="12.1.1.pr."></a>

**序言（pr.）** 在解释标题用语之前，先简要说明本标题本身的含义，是有益的。

<a id="12.1.1.1"></a>

**1.** 裁判官在本标题下纳入了许多涉及不同契约的法律规则，因此先列出“信用给付之物”这一标题。它涵盖了我们基于他人信用而订立的各种契约。正如塞尔苏斯在《问题集》第一卷中所说，“给予信用”是一个一般性称谓。因此，裁判官在本标题下也规定了使用借贷和质押。只要我们基于他人的信用同意交付某物，并预期随后收回某种给付，就被认为订立了信用契约。裁判官也选择了“物”一词，因为它具有一般含义。

### <a id="12.1.2"></a>12.1.2　保罗《评告示》第二十八卷

<a id="12.1.2.pr."></a>

**序言（pr.）** 我们以消费借贷方式交付财物，预期收回的不是与所交付之物完全相同的个体（否则就是使用借贷或寄托），而是同一类物。因此，如果约定以另一类物返还，例如以葡萄酒返还小麦，就不构成消费借贷。

<a id="12.1.2.1"></a>

**1.** 消费借贷的交付适用于依重量、数量或度量确定的物，因为交付这类物可以产生信用债务；它们可以通过返还同类物履行，而不必返还原物。其他物之所以不能作为信用给付，是因为未经债权人同意，不得以一种物代替另一种物清偿。

<a id="12.1.2.2"></a>

**2.** “消费借贷”（*mutui datio*）这一名称，来自“我的物成为你的物”这一含义。因此，如果交付的物没有成为受领人所有，就不会产生债务。

<a id="12.1.2.3"></a>

**3.** 因此，信用给付与消费借贷的区别，如同属与种的区别：信用给付还包括那些不依重量、数量或度量确定的物；如果约定返还同一物，也属于信用给付。此外，消费借贷只有在钱款实际交付时才能成立；而信用债务有时即使没有任何物实际交付，也可以成立，例如婚后承诺嫁资。

<a id="12.1.2.4"></a>

**4.** 在消费借贷的交付中，交付人必须是所有权人。但家父权下的儿子或奴隶交付其特有财产中的钱款也能使受领人承担债务，并不妨碍这一规则；这种情形如同我授权你交付钱款，因此诉权归我取得，即使交付的钱并非我的所有物。

<a id="12.1.2.5"></a>

**5.** 我们也可以通过言词给予信用，即通过某种为产生债务而进行的行为，例如要式口约（*stipulatio*）。

### <a id="12.1.3"></a>12.1.3　庞波尼《评萨宾》第二十七卷

即使我们交付消费借贷之物时没有约定返还的物品应同样优良，债务人也不得返还同类但品质较差之物，例如以新酒替代陈酒。因为订立契约时，双方所做的安排应视为已经约定；而应当认为，双方约定返还与交付之物类别相同、品质相当的物。

### <a id="12.1.4"></a>12.1.4　乌尔比安《评萨宾》第三十四卷

<a id="12.1.4.pr."></a>

**序言（pr.）** 如果某人既无放贷的理由，也无放贷的意图，而你为了购买田产向他借钱，又不愿在买下田产之前以借贷名义受领这笔钱；于是，债权人因恰好必须出行，便将同一笔钱寄存在你处，约定你一旦买下田产就因此负有借款债务，那么这笔寄存的钱应由受领人承担风险。正如受托出售某物并可使用价款的人，也须自行承担该物的风险。

<a id="12.1.4.1"></a>

**1.** 以金钱清偿债务后，可以通过返还之诉请求返还已交付的质押物。基于不正当原因取得的孳息也可以请求返还。例如，租佃人在租期届满后取得的孳息，原则上可以请求返还；但仅限于其未经土地所有人同意而取得的情形。如果取得孳息得到所有人同意，显然不得提起返还之诉。

<a id="12.1.4.2"></a>

**2.** 被河水冲来并带入他人土地的物，可以通过返还之诉请求返还。

### <a id="12.1.5"></a>12.1.5　庞波尼《评萨宾》第二十二卷

如果某物本应由你交付给我，而该物在你未能向我交付之后才灭失，显然该损失应由你承担。至于是否应认定是你导致未能交付，不仅要考察该物是否曾处于你的控制之下，以及你是否以恶意使其不复存在或使其灭失；还应考察，是否存在某种正当理由，使你本应明白自己负有交付义务。

### <a id="12.1.6"></a>12.1.6　保罗《评告示》第二十八卷

凡债务标的的种类或数量已确定，无论是以该物的名称，还是以能够替代名称的描述，表明其为何种、何量，即为确定之物。佩狄乌斯在《口约论》第一卷中也说，以专名称呼该物、用手指示该物，或用某些词语描述该物，并无区别；只要这些方式能够互相替代并指向同一给付即可。

### <a id="12.1.7"></a>12.1.7　乌尔比安《评告示》第二十六卷

凡可以写入要式口约的事项，也都可以附加于钱款的实际交付；因此，条件也可以附加。

### <a id="12.1.8"></a>12.1.8　庞波尼《普劳提乌斯论》卷六

因此，消费借贷的交付有时处于待定状态，须以后发生的事实使其确定。例如，我以消费借贷方式交付钱币，约定某项条件成就时钱币才归你所有、你才对我负债。又如，继承人将遗赠的钱款借给他人，而后受遗赠人拒绝接受遗赠；因为从继承人接受继承之日起，这些钱币似乎一直属于继承人，所以可以作为借款请求返还。尤利安说，继承人作出的交付也应追溯至其接受继承之时；无论遗赠后来被拒绝，还是被追加（*adpositum*；此处词义待核），均是如此。

### <a id="12.1.9"></a>12.1.9　乌尔比安《评告示》第二十六卷

<a id="12.1.9.pr."></a>

**序言（pr.）** 凡基于任何原因或任何债务而请求确定给付的，均可提起确定额返还之诉（*certi condictio*），无论该请求源自确定的契约还是不确定的契约。我们可以基于任何契约提起确定额返还之诉，但债务必须已经届期；如果债务约定于将来某日履行或附有条件，在期限届至或条件成就前，我不得起诉。

<a id="12.1.9.1"></a>

**1.** 遗赠和《阿奎利亚法》也可以成为此项诉讼的依据。因盗窃而生的请求，也可以通过此诉提出。依据元老院决议提起诉讼时，同样可以适用此诉；例如，接受信托返还遗产的人想要起诉时，即属此种情形。

<a id="12.1.9.2"></a>

**2.** 无论某人以自己的名义负有债务，还是以他人的名义负有债务，都可以通过此项诉讼对其适当起诉。

<a id="12.1.9.3"></a>

**3.** 既然此项确定额返还之诉适用于各种契约——无论契约因物、因言词，或兼由两者而成立——就应列举一些值得深入讨论的情形，考察此诉是否足以请求这些给付。

<a id="12.1.9.4"></a>

**4.** 我给你数了十枚钱币，并以自己的名义为他人订立口约；该口约无效。我能否通过此项诉讼请求返还这十枚钱币，理由是这里发生了两个契约：一个是因物成立的契约，即实际交付；另一个是因言词成立的契约，但后者无效，因为我不能为他人订立口约？我认为可以。

<a id="12.1.9.5"></a>

**5.** 如果我在监护人未予授权的情况下与未适婚人订立口约，而我是经监护人授权才借钱给他，结论也相同；此时我仍可基于钱款交付提起返还之诉。

<a id="12.1.9.6"></a>

**6.** 同样，如果我在交付给你钱款时，以不可能实现的条件订立口约，也会产生同一问题。既然口约无效，返还之诉仍然存在。

<a id="12.1.9.7"></a>

**7.** 如果我把钱交给后来被禁止管理其财产的人，随后又与他订立口约，我认为应将其比作未适婚人，因为他通过口约也能为自己取得权利。

<a id="12.1.9.8"></a>

**8.** 我在你不在场且不知情时，以你的名义交付我自己的钱，仿佛那是你的钱；阿里斯托写道，你因此取得返还之诉。尤利安在《学说汇纂》第十卷中也答复说，阿里斯托的意见正确。这一点毫无疑问：如果我经你同意，以你的名义交付我的钱，你就取得债权；因为我们每天都可能为了借出钱款而向他人借钱，再让债权人以我们的名义把钱交给将要成为我们债务人的人。

<a id="12.1.9.9"></a>

**9.** 我把十枚钱币寄存在你处，后来允许你使用。涅尔瓦和普罗库鲁斯认为，即使钱币尚未被动用，也可以请求你返还，仿佛钱币是以消费借贷方式交付的；马尔凯卢斯也持同一意见，这确实正确，因为你已在心中开始占有这些钱币。因此，风险转由请求借款的人承担，也可以对其提起返还之诉。

### <a id="12.1.10"></a>12.1.10　乌尔比安《评告示》第二卷

但是，如果我在寄存之初就允许你随意使用这笔钱，那么在钱币实际被动用之前，它还不算是借出的，因为是否会产生债务尚不确定。

### <a id="12.1.11"></a>12.1.11　乌尔比安《评告示》第二十六卷

<a id="12.1.11.pr."></a>

**序言（pr.）** 你请求我借钱给你；我当时没有钱，于是交给你一只银盘或一块金料，让你出售后使用所得钱币。如果你卖掉了，我认为便成立了消费借贷。如果你在出售前并无过错地遗失银盘或金料，损失应由我还是由你承担？对此存在疑问。我认为涅尔瓦的区分最为正确：关键在于我是否原本就打算出售该银盘或金料。如果我本来打算出售，那么损失由我承担，如同我把它交给他人代为出售一样；但如果我原本无意出售，只是为了让你使用钱款才出售，那么损失由你承担，尤其是在我无息借钱给你的情况下。

<a id="12.1.11.1"></a>

**1.** 如果我交给你十枚钱币，约定你只须偿还九枚，普罗库鲁斯认为——而且是正确的——依法律你只负有九枚钱币的债务。但如果我交给你十枚，却约定你偿还十一枚，普罗库鲁斯认为不能通过返还之诉请求超过十枚的部分。

<a id="12.1.11.2"></a>

**2.** 如果逃亡奴隶把钱借给你，主人能否对你提起返还之诉？对此存在疑问。若我的奴隶获准管理特有财产，并把钱借给你，就成立消费借贷；但逃亡奴隶或其他未经主人同意的奴隶借出钱款，并不会使受领人取得这些钱的所有权。那么，应如何处理？如果钱币仍然存在（底本重复作 *extant "exstant"*），主人可以提起所有物返还之诉（*vindicatio*）；如果受领人因恶意而不再占有这些钱币，可以提起出示之诉（*actio ad exhibendum*）。但如果你并无恶意地花掉了钱币，我可以对你提起返还之诉。

### <a id="12.1.12"></a>12.1.12　庞波尼《普劳提乌斯论》卷六

如果你从一个精神错乱者处收取钱款，以为他神志清醒，并将钱款用于自己的事务，尤利安说返还之诉归属于该精神错乱者。因为，在我们不知情时可以取得诉权的那些情形中，精神错乱者也同样可以取得诉权。同样，如果某人把钱借给奴隶后开始精神错乱，而该奴隶随后将钱用于主人的事务，也可以以精神错乱者的名义请求返还。如果某人为了借贷而交付他人的钱，之后开始精神错乱，而该钱已被花掉，返还之诉也归属于该精神错乱者。

### <a id="12.1.13"></a>12.1.13　乌尔比安《评告示》第二十六卷

<a id="12.1.13.pr."></a>

**序言（pr.）** 即使盗贼怀着借贷之意把钱币交给你，也不会使你取得所有权；但是，钱币一经花用，返还之诉便随之发生。

<a id="12.1.13.1"></a>

**1.** 因此，帕比尼安在《问题集》第八卷中说：如果我把他人的钱币借给你，在你花用之前，你并不对我负债。如果你分批花用，我能否分批请求返还？他认为可以：如果有人提醒我这些钱币属于他人，而我因此只请求返还其中一部分，是因为我尚未查明钱币是否全部花完，便可以分批提起返还之诉。

<a id="12.1.13.2"></a>

**2.** 如果共有奴隶借出十枚钱币，我认为，无论主人是否准许该奴隶管理特有财产，只要钱币已被花用，每位共有人都可就五枚钱币提起诉讼。帕比尼安在《问题集》第八卷中也写道：即使一百枚钱币是共有的，我也可以请求返还其中的五十枚，即使每一枚钱币本身都属于共有。

### <a id="12.1.14"></a>12.1.14　乌尔比安《评告示》第二十九卷

如果家父权下的儿子违反元老院决议借款并偿还，父亲请求返还钱币时，不得对其提出抗辩。但是，如果债权人已经花掉钱币，马尔凯卢斯说，返还之诉即不再适用，因为只有在交付钱币的原因本来足以产生诉权（假如所有权已转给受领人时）时，才给予返还之诉；本案并非如此。总之，对于因错误而偿还、违反元老院决议所借的钱款，更应认为不得请求返还。

### <a id="12.1.15"></a>12.1.15　乌尔比安《评告示》第三十一卷

关于信用给付的钱款，有若干特别规则。如果我指示自己的债务人把钱交给你，你就对我负有债务，尽管你没有收到我的钱币。因此，既然在两人之间承认这一规则，在同一人之间也应承认：如果你因委任关系而欠我钱，后来我们约定你将该款作为借款保留，那么就应视为我已把钱交给你，且该钱由我转给你。

### <a id="12.1.16"></a>12.1.16　保罗《评告示》第三十二卷

合伙人以自己的钱作消费借贷，无论其他合伙人是否同意，都能使该款成为借款；但如果他交付的是共有款项，只有其他合伙人也同意时，才成立借款，因为他只能处分自己的份额。

### <a id="12.1.17"></a>12.1.17　乌尔比安《论答辩》第一卷

家父权下的儿子在罗马求学期间，把自己的旅费借给他人。斯凯沃拉答复说，应通过特别审理程序给予他救济。

### <a id="12.1.18"></a>12.1.18　乌尔比安《论答辩》第七卷

<a id="12.1.18.pr."></a>

**序言（pr.）** 如果我给你钱时以为是赠与，而你以为是借款，尤利安写道，这不构成赠与；至于是否构成借款，则须考察。我认为这既不构成消费借贷，也不构成借款，因为你是基于不同的意思受领钱款。既然钱币没有依照交付人的意思转移所有权，若你花掉钱币，虽可对你提起返还之诉，你仍可援用欺诈抗辩，因为钱币是依交付人的意愿被花用的。

<a id="12.1.18.1"></a>

**1.** 如果我以寄托为名把钱交给你，而你以消费借贷为名受领，既不成立寄托，也不成立消费借贷。你若以消费借贷为名交付钱款，而我以使用借贷为名、仅为展示而受领，也是如此。不过，在这两种情形中，钱币一经花用，均可以提起返还之诉，且不得援用欺诈抗辩。

### <a id="12.1.19"></a>12.1.19　尤利安《学说汇纂》第十卷

<a id="12.1.19.pr."></a>

**序言（pr.）** 并非每次交付钱款都会使受领人负债；只有当交付的目的就是使其立即负债时，才会如此。因临终处分而赠与钱款的人也会交付钱款，但只有约定所针对的情形发生后，受领人才负债；例如，赠与人康复，或者受领人先于赠与人死亡。又如，交付钱款是为了促成某事，在该事是否发生尚未确定期间，债务不发生；但一旦确定该事不会发生，受领人便负债。例如，我交给提提乌斯十枚钱币，要求他在下一个月初之前释放斯提库斯；在该日期之前，我无权起诉；日期届满后，只有在斯提库斯仍未获释时，我才可以起诉。

<a id="12.1.19.1"></a>

**1.** 如果未适婚人在监护人未授权的情况下借出钱款，或者为清偿债务而交付钱款，钱币一经花用，他便取得返还之诉，或者因此免除债务；其理由仅在于，受领人取得钱款被视为未适婚人行为的结果。因此，如果一个人以借贷或清偿债务为由受领钱款，又把钱款转而借给他人或用于清偿，钱币一经花用，他便对未适婚人负债，或使未适婚人对自己免责；同时，他也可以使其受领钱款的第三人负债，或使自己对该第三人免责。总之，凡为借贷而交付他人钱款的人，受领人花用钱款后，便对交付人负债；凡为清偿而交付款项的人，则因受领人受领而获得免责。

### <a id="12.1.20"></a>12.1.20　尤利安《学说汇纂》第十八卷

如果我把钱赠给你，条件是你再把同一笔钱借给我，这是否成立借款？我说，在这类情形中，我们没有使用准确的法律用语：这种契约既不是赠与，也不是信用借贷。它不是赠与，因为交付钱款时，并非意在使受领人无论如何都保有该款；它也不是借款，因为交付的目的更像是清偿，而非使另一方负债。因此，如果受领人是基于“将钱借给我”的条件而收款，并随后把钱交给我，就不构成借款；我应被视为受领的是自己的钱。不过，这只是拘泥于用语精确性的结论；较宽厚的处理是承认两种法律行为均有效。

### <a id="12.1.21"></a>12.1.21　尤利安《学说汇纂》第四十八卷

**1.** 我不知情，善意地从窃贼处买下了你的奴隶；该奴隶用属于你的特有财产中的钱买了另一个奴隶，后者又被交付给我。萨宾和卡西乌斯认为，你可以向我请求返还这个奴隶；但如果我因该奴隶所处理的事务遭受损失，我也可以反过来起诉你。这一意见正确。尤利安还说，应当考察：主人是否可以完整地享有买受之诉，而出卖人却可以对善意买受人提起返还之诉。至于特有财产中的钱币，如果仍然存在，主人可以提起所有物返还之诉予以追回，但仍须依特有财产之诉向出卖人承担责任并支付价款。如果钱币已被花用，特有财产之诉便不再适用。不过，尤利安本应补充：只有主人向出卖人支付全部价款，以及在与自由人订约时本应支付的其他款项，出卖人才对奴隶主人负有买受之诉上的责任。如果我向善意占有人付款，结论也相同，但条件是我愿意把自己对该占有人享有的诉权让与主人。

### <a id="12.1.32"></a>12.1.32　塞尔苏斯《学说汇纂》第五卷

### <a id="12.1.36"></a>12.1.36　雅沃勒努《书信集》第一卷

我对你享有一笔无条件债权；经我指示，你有条件地向阿提乌斯作出允诺。在条件成就之前，你对我的债务仍处于原有状态，仿佛你是以相反条件向我作出允诺。如果我在条件待定期间请求给付，是否会一无所获？答复如下：我毫不怀疑，我以无条件要式口约取得的债权仍然是借款，即使阿提乌斯——他是经我同意才就同一笔钱有条件地订立口约——所涉条件没有成就，也不影响这一点，因为这就如同根本没有订立那项口约一样。但是，在条件是否成就尚未确定时，我不能请求同一给付；因为尚不确定能否根据该口约请求给付，我若此时起诉，就属于过早请求。

### <a id="12.1.37"></a>12.1.37　帕比尼安《定义集》第一卷

如果条件指向现在的事实，要式口约不因此处于待定状态；条件若为真，要式口约即有效，即使订约人不知道该条件是否为真。例如：“如果帕提亚王仍然活着，你允诺给我一百吗？”条件指向过去的事实时，结论也相同。

### <a id="12.1.40"></a>12.1.40　保罗《问题集》第三卷

法学家兼近卫军长官埃米利乌斯·帕比尼安的听证厅宣读过如下债务文书（底本拉丁原文）：

> *Lucius Titius scripsi me accepisse a Publio Maevio quindecim mutua numerata mihi de domo et haec quindecim proba recte dari kalendis futuris stipulatus est Publius Maevius, spopondi ego Lucius Titius. Si die supra scripta summa Publio Maevio eive ad quem ea res pertinebit data soluta satisve eo nomine factum non erit, tunc eo amplius, quo post solvam, poenae nomine in dies triginta inque denarios centos denarios singulos dari stipulatus est Publius Maevius, spopondi ego Lucius Titius. Convenitque inter nos, uti pro Maevio ex summa supra scripta menstruos refundere debeam denarios trecenos ex omni summa ei heredive eius.*

“我，卢基乌斯·提提乌斯，写明我从普布利乌斯·麦维乌斯处收到十五枚钱币作为借款，该款由其家中交付给我。普布利乌斯·麦维乌斯约定，这十五枚钱币应于下一个月初如数妥善偿还；我，卢基乌斯·提提乌斯，作出允诺。如果在上述日期未向普布利乌斯·麦维乌斯或有权承受该款之人交付、清偿或提供适当担保，那么，作为罚则，普布利乌斯·麦维乌斯还约定，每逾三十日，每一百枚钱币应另付一枚；我，卢基乌斯·提提乌斯，作出允诺。我们还约定，我应就上述全部款项，每月向麦维乌斯或其继承人支付三百枚钱币。”

有人就利息债务提出问题，因为允许清偿的月份已经届满。我当时说，由于同时订立的协议被认为包含在要式口约之中，这种情形就如同约定每月支付确定款项，并在迟延清偿时加计利息。因此，第一个月届满时，第一期款项开始计息；第二、第三期届满后，尚未支付的各期款项也同样开始累积利息。未付本金尚未到期、不能请求时，也不得先请求其利息。

但是，有些人认为，附加的协议仅涉及本金清偿，不涉及此前已无条件纳入要式口约的利息；该协议只产生抗辩效力。因此，如果未在约定的分期日期支付款项，就应自订立要式口约之日起支付利息，仿佛文书已明确写明这一点。但既然本金请求已被延期，相应地，利息也应从债务人迟延之时起发生。即使如前述意见所主张，协议仅产生抗辩效力——尽管最终采纳了不同观点——利息债务仍不会依法当然发生；因为债务人若因抗辩而不能被请求给付，就不构成迟延。

不过，我们可以约定条件成就时支付期间累积的金额，正如孳息的处理方式；利息也可以作同样约定，使得如果款项在到期日未支付，就应支付自订立要式口约之日起按利息计算的相应金额。

### <a id="12.1.41"></a>12.1.41　阿非利加努《问题集》第八卷

某人在行省内任命奴隶斯提库斯负责债务账簿。后来，其遗嘱在罗马宣读，遗嘱中指定斯提库斯为自由人，并使其取得部分遗产。斯提库斯并不知道自己的身份已经改变，于是继续收取死者的款项或将款项借出，有时还订立要式口约并收取质押物。有人就这些行为的法律效力征询意见。答复认为：如果债务人也不知道主人已经死亡，向斯提库斯清偿的债务人应获免责。至于斯提库斯收取的款项，共同继承人不能提起遗产分割之诉，但应准许提起无因管理之诉。

至于斯提库斯自己借出的款项，其处分效力仅及于他作为继承人所占的份额。因为，即使我交钱给你，是让你把钱借给斯提库斯，而你在我死后不知情仍把钱交给他，也不会使受领人取得所有权。我们虽承认债务人向斯提库斯清偿后可以免责，却不能据此认为斯提库斯借出钱款也能使钱款所有权转移。因此，如果没有订立要式口约，共同继承人既不能按其份额请求返还借款，质押物也不发生效力。

如果斯提库斯还订立了要式口约，则须考察其具体措辞：如果他明确约定，款项应在主人提提乌斯死亡后交付给提提乌斯，显然该口约无效；如果他约定交付给自己，则应认为他为遗产取得了该债权。正如自由人或他人的奴隶基于我们的财产，为我们取得权利；遗产也可以基于遗产中的财产取得权利。

但共同继承人接受继承之后，不能同样处理，尤其是他们知道斯提库斯被指定为共同继承人时；因为他们既无占有的意思，就不能被视为善意占有人。如果共同继承人不知道此事——例如他们自己也属于必然继承人——仍可以作出相同答复。在这种情况下，如果该奴隶有与其身份相同的共同继承人，就会出现他们彼此之间被视为善意服役的结果。

### <a id="12.1.42"></a>12.1.42　塞尔苏斯《学说汇纂》第六卷

<a id="12.1.42.pr."></a>

**序言（pr.）** 如果我先与提提乌斯订立要式口约，请求其支付十枚钱币，随后又与塞伊乌斯约定，由其补足我无法从提提乌斯处取得的部分，那么，如果我向提提乌斯请求十枚，塞伊乌斯并不因此免责；否则，他向我作出的保证便毫无意义。但是，如果提提乌斯已依判决履行，塞伊乌斯就不再承担任何责任。反之，如果我起诉塞伊乌斯，那么，在我与塞伊乌斯的诉讼系属时，无论我尚有多少金额无法从提提乌斯处收取，我后来都只能向提提乌斯请求相应减少后的金额。

<a id="12.1.42.1"></a>

**1.** 拉贝奥说，如果你约定应支付或确保支付十枚钱币，就不能据此主张对方负有支付十枚钱币的义务，因为允诺人也可以通过提供一个有清偿能力的债务人而免责。拉贝奥的意思显然是，如果允诺人提出一个有清偿能力的债务人，不应强迫受诺人接受诉讼。
