## 12.2.0　论宣誓：自愿宣誓、必要宣誓或司法宣誓（*De iureiurando sive voluntario sive necessario sive iudiciali*）

### <a id="12.2.1"></a>12.2.1　盖尤斯《评行省告示》第五卷

诉讼得以迅速处理的一项重要救济，已因宣誓的宗教效力而付诸适用；借助宣誓，争议可以依诉讼当事人之间的协议，或依裁判官的权威而获得解决。

### <a id="12.2.2"></a>12.2.2　保罗《评告示》第十八卷

宣誓具有和解的性质，其效力高于既判事项。

### <a id="12.2.3"></a>12.2.3　乌尔比安《评告示》第二十二卷

<a id="12.2.3.pr."></a>

**序言（pr.）** 裁判官说：“如果被诉之人经对方提出宣誓后作出宣誓。”我们应将“被诉之人”理解为被告本人。“经对方提出宣誓后”并非无故增添：如果被告在无人向其提出宣誓的情况下自行宣誓，裁判官不会保护该宣誓；因为他只是向自己宣誓。否则，任何轻率之人都可以在无人向其提出宣誓时随意宣誓，从而摆脱诉讼负担。

<a id="12.2.3.1"></a>

**1.** 无论某人因何种诉讼被起诉，只要其作出宣誓，该宣誓即对其有利；无论所提起的是对人之诉、对物之诉、事实诉讼、刑罚之诉或其他任何诉讼，抑或涉及令状，均是如此。

<a id="12.2.3.2"></a>

**2.** 如果宣誓涉及某人的身份状况，裁判官也会保护该宣誓。例如，我向你提出宣誓，而你宣誓说自己不受我的权力支配；对此宣誓应予保护。

<a id="12.2.3.3"></a>

**3.** 因此，马尔凯鲁斯写道，也可以就某妇女是否怀孕作出宣誓，并应遵从该宣誓。他还说，如果争议涉及占有——例如，妇女因怀孕而请求取得占有，对方对此提出异议——则应依宣誓处理：她可以宣誓自己怀孕，也可以由对方对她宣誓说她并未怀孕。若她本人宣誓，就可以无所顾虑地取得占有；若对她作出相反的宣誓，即使她事实上确已怀孕，也不得取得占有。马尔凯鲁斯说，妇女作出的宣誓对她有利，使其不致因以胎儿名义取得占有而被指控为诬告，也不致在占有期间遭受暴力。至于宣誓的效力是否延及分娩之后，使人不得再查明所生子女是否确为所称男子之子，马尔凯鲁斯对此有所讨论；他说仍应查明事实，因为宣誓既不使他人受益，也不使他人受损。因此，母亲的宣誓不使所生子女受益；如果母亲提出宣誓并有人宣誓她并非怀有某男子的孩子，该宣誓也不使子女受损。

<a id="12.2.3.4"></a>

**4.** 宣誓应依对方提出的方式作出。比如，我要求你以神为誓，你却以自己的性命为誓——

### <a id="12.2.4"></a>12.2.4　保罗《评告示》第十八卷

或者以你儿子们的性命为誓，——

### <a id="12.2.5"></a>12.2.5　乌尔比安《评告示》第二十二卷

<a id="12.2.5.pr."></a>

**序言（pr.）** 这种宣誓不应得到认可。反之，如果我要求你以自己的安危为誓，而你也照此宣誓，就应遵从该誓言。凡合法的宣誓，无论何种形式，只要一方希望另一方为自己作出该宣誓，即属适当；如已据此宣誓，裁判官就会予以保护。

<a id="12.2.5.1"></a>

**1.** 神圣的庇乌斯皇帝曾以敕答规定：依个人特有的宗教信仰作出的宣誓，应予遵从。

<a id="12.2.5.2"></a>

**2.** 宣誓既已作出，所须查明的仅是当事人是否已经宣誓；至于其是否确负给付义务，则无须再查，因为宣誓已足以证明该事项。

<a id="12.2.5.3"></a>

**3.** 如果有人提出不合法的宣誓，也就是说，所涉宗教为公然不受认可者，我们应考察是否应将其视同未曾宣誓；我认为应作此处理。

<a id="12.2.5.4"></a>

**4.** 如果既未作出宣誓，也未免除该宣誓，应视同该事项从未交付宣誓裁断。因此，即使当事人后来准备宣誓，该宣誓也对其毫无帮助，因为其并未就对方提出的事项作出宣誓。

### <a id="12.2.6"></a>12.2.6　保罗《评告示》第十九卷

提出宣誓的一方，如果对方已表示愿意宣誓，而其因对方同意接受宣誓便免其宣誓，就属于免除该宣誓。若对方尚未接受宣誓，即使其后来准备宣誓而原告不愿再提出，也不视为宣誓已被免除；因为只有已经接受的宣誓才能被免除。

### <a id="12.2.7"></a>12.2.7　乌尔比安《评告示》第二十二卷

裁判官说：“对于已经提出宣誓的事项，我既不对被诉之人，也不对该事项所归属之人授予诉讼。”这里的“事项”应理解为既可以是全部标的，也可以是其中一部分；裁判官承诺，对宣誓所及事项不授予诉讼，无论是针对作出宣誓之人，还是针对代替被提出宣誓之人而取得其地位者，——

### <a id="12.2.8"></a>12.2.8　保罗《评告示》第十八卷

即使他们是通过对物继受取得该地位，也同样如此。

### <a id="12.2.9"></a>12.2.9　乌尔比安《评告示》第二十二卷

<a id="12.2.9.pr."></a>

**序言（pr.）** 宣誓作出后，诉讼即不予受理。如果因此发生争议，也就是说，对是否已经作出宣誓存在疑问，则可以提出抗辩。

<a id="12.2.9.1"></a>

**1.** 宣誓已作出或已被免除后，被告为自己及他人取得抗辩；原告则取得诉权，而该诉中仅须审查：其是否曾宣誓称应向其给付，或者其已准备宣誓而对方免除了该宣誓。

<a id="12.2.9.2"></a>

**2.** 如果某人在一项会导致不名誉污名的诉讼中宣誓后仍被判负，较妥当的见解是，该判决仍属不名誉判决。

<a id="12.2.9.3"></a>

**3.** 如果某人原本因临时诉权对我负有义务，他向我提出宣誓，要求我宣誓其应当给付，而我也作出该宣誓，则他不会因期间届满而免责；因为争讼程序确定后，对其的义务即转为永久义务。

<a id="12.2.9.4"></a>

**4.** 如果未满二十五岁者提出宣誓，并称自己正因该宣誓而受人利用，就应准许其针对宣誓抗辩提出再抗辩，庞波尼对此已有论述。但我认为，并非任何情形下都应准许这种再抗辩；通常应由裁判官亲自审查其是否确受利用，并据此准许恢复原状。因为未成年人并非仅凭年龄就当然证明自己受了欺骗。此外，该项抗辩或审查不得超出二十五岁之后法定的期间。

<a id="12.2.9.5"></a>

**5.** 如果有人为损害债权人而向债务人提出宣誓，则应准许债权人提出欺诈再抗辩，以对抗基于宣誓提出的抗辩。此外，如果欺诈者向债权人提出宣誓，要求债权人宣誓称其应向自己给付十奥雷，而后欺诈者的财产被拍卖，其又想提起诉讼，则应拒绝该诉，或者准许提出债权人受欺诈的抗辩。

<a id="12.2.9.6"></a>

**6.** 尤利安写道，对方提出宣誓后，由诉讼防御人或诉讼代理人作出的宣誓，可以产生抗辩，并使委托人取得该抗辩。因此，如果受任提起请求的代理人应被告之请而作出宣誓，称应向我给付，也应适用同一规则；该宣誓为我创设诉权。这一见解有其道理。

<a id="12.2.9.7"></a>

**7.** 占有人提出宣誓后，请求者宣誓称该物属于自己，则应授予原告诉权；但该诉权仅可针对提出宣誓之人及其继受人行使。若其想在对另一人的诉讼中援用该宣誓所带来的优先效力，则毫无帮助，——

### <a id="12.2.10"></a>12.2.10　保罗《评告示》第十八卷

因为当事人之间所作的处理，不应损害他人。

### <a id="12.2.11"></a>12.2.11　乌尔比安《评告示》第二十二卷

<a id="12.2.11.pr."></a>

**序言（pr.）** 但是，如果占有人被提出宣誓，并宣誓说该物不属于请求者，那么只要他仍占有该物，在请求者向其主张权利时，他就可以对提出宣誓之人援用宣誓抗辩。若他丧失占有，则不享有诉权；即使占有人恰是当初向他提出宣誓之人，也同样如此。因为他宣誓的不是该物属于自己，而是该物不属于对方。

<a id="12.2.11.1"></a>

**1.** 因此，如果请求者向占有人提出宣誓，占有人宣誓称该物属于自己，则即使其后来丧失占有，而提出宣誓之人取得了占有，也应准许其提起事实诉讼。我认为，他还应取回从该物取得的孳息；而且，提出宣誓后出生的子女及牲畜所产幼畜，也应返还，这一点已无疑义。

<a id="12.2.11.2"></a>

**2.** 同样，如果我宣誓某物的用益权属于我，或应由他人向我设立，则我仅在该用益权若真实存在时本可持续的期间内享有诉权；若依法律该用益权本应消灭，则我不享有诉权。但如果所涉之物因使用即消耗，不能设立通常意义上的用益权，而某人宣誓自己享有或应享有其用益权，我认为应遵从宣誓的效力。因此，我认为此时也应认定其宣誓有效；只要其提供担保，即可基于该宣誓请求用益权。

<a id="12.2.11.3"></a>

**3.** 如果我与你之间就遗产发生争议，而我宣誓该遗产属于我，我应取得如同法院判决遗产归我时本可取得的一切。你不仅应返还当时占有的遗产物；即使你后来才开始占有其中某些物，也应返还。宣誓所确认的事项应视同已经证明。因此，我享有准用之诉。反过来说，如果我占有同一遗产，而你向我请求该遗产，并且我曾对你作出上述宣誓，我应得援用宣誓抗辩。显然，如果另一人开始向我请求该遗产，正如尤利安所写，我的宣誓对我毫无帮助。

### <a id="12.2.12"></a>12.2.12　尤利安《学说汇纂》第九卷

如果我想向任何其他占有人请求遗产物，也同样如此；因为即使我曾向你请求遗产并证明其属于我，向另一人请求时仍须再次证明同一事项。

### <a id="12.2.13"></a>12.2.13　乌尔比安《评告示》第二十二卷

<a id="12.2.13.pr."></a>

**序言（pr.）** 如果有两名释奴保护人，而自由释奴在其中一人提出宣誓后，宣誓称自己并非该人的释奴，那么另一名保护人应取得全部应归保护人的遗产占有份额，还是仅取得其中一半？乌尔比安说，如果向其提出宣誓的人确为保护人，则另一人取得其应有份额的遗产占有；自由释奴针对前一人所作的宣誓，对另一人并无帮助。但该自由释奴宣誓称另一人并非保护人这一点，在法官面前仍具有相当的诚信价值和证明力，有助于后一人证明自己是唯一的保护人。

<a id="12.2.13.1"></a>

**1.** 尤利安说，某人宣誓称土地属于自己，经过长期时效后，也应享有准用之诉。

<a id="12.2.13.2"></a>

**2.** 同一尤利安还写道，某人宣誓自己未实施盗窃，应视为其就整个事项作了宣誓，因此既不负盗窃之诉责任，也不负盗窃返还之诉责任；因为他说，只有窃贼才承担后者的责任。那么，如果某人仅就自己未实施盗窃这一点作出宣誓，而其后因返还之诉被起诉，是否可以援用抗辩？但是，如果提起返还之诉的人主张自己是以窃贼继承人的身份起诉，就不应将其驳回；应准许其对窃贼的继承人提起单一返还之诉。法官也不得允许被告在该诉中开始试图证明窃贼的身份。

<a id="12.2.13.3"></a>

**3.** 如果某人宣誓称我以一百售予其某物，他可以提起买卖之诉，请求我履行其余义务，也就是说，交付该物并就追夺担保。但其是否也可以通过买卖之诉被请求支付价金，尚待考察。如果他也就价金已经支付这一点作了宣誓，则不再有请求价金的诉权；若未就此宣誓，则相应地仍须对价金负责。

<a id="12.2.13.4"></a>

**4.** 某人宣誓称已与我成立合伙时，也应作同样处理：他仍可被提起合伙之诉。

<a id="12.2.13.5"></a>

**5.** 马尔凯鲁斯还写道：某人宣誓称自己为取得十的借款而将土地设为质物时，除非已偿还十，否则不得提起质权之诉；或许还应补充说，他也可以因自己的宣誓而被请求支付十，这一见解更为可取。昆图斯·萨图尔尼努斯赞同此说，并以另一例为论据：某人宣誓称自己的妻子曾将某物作为嫁资交付给他。马尔凯鲁斯说，此时也应准许妻子提起准用的嫁资之诉。我不否认，这一见解并未超出公平的范围。

<a id="12.2.13.6"></a>

**6.** 如果有人在金钱事务中以皇帝的守护神为誓，宣誓称自己不负给付义务，或者宣誓称对方应向自己给付，而其作了伪誓；又或者他宣誓称将在特定期间内付款，却未付款，我们的皇帝与其父曾以敕答规定，应以杖责惩处后将其逐出，并对其宣告：“*propetws my omnue*〔切勿轻率起誓〕。”

### <a id="12.2.14"></a>12.2.14　保罗《评告示》第三卷

凡就某一财物或事务作出宣誓，都不得由父母或释奴保护人免除该宣誓。所谓就某一事务宣誓，例如债务人借款后，原告宣誓称应向自己给付，或者被告宣誓称自己无须给付；就已约定的金钱债务要求作出宣誓，也同样如此。

### <a id="12.2.15"></a>12.2.15　保罗《评告示》第六卷

对于显贵之人以及因疾病而不能出庭者，应派人前往其住所令其宣誓。

### <a id="12.2.16"></a>12.2.16　乌尔比安《评告示》第十卷

如果释奴保护人娶其女自由释奴为妻，不得强迫他在妻子移取财物之诉中宣誓。即使他本人向该女自由释奴提出宣誓，也不应要求他作出反诬诉宣誓。

### <a id="12.2.17"></a>12.2.17　保罗《评告示》第十八卷

<a id="12.2.17.pr."></a>

**序言（pr.）** 依当事人协议而在诉讼之外提出的宣誓，不得转由对方作出。

<a id="12.2.17.1"></a>

**1.** 未成年人应在监护人认可下提出宣誓；如果其未经监护人认可便提出宣誓，对方固可提出抗辩，但应允许其再抗辩，因为未成年人没有自行管理事务的权利。

<a id="12.2.17.2"></a>

**2.** 正在执行监护事务的监护人，或精神失常者、挥霍者的保佐人提出宣誓时，应予认可；因为他们能够处分财物、受领清偿，并可以通过提起诉讼将事项交由法院裁判。

<a id="12.2.17.3"></a>

**3.** 代理人提出的宣誓也应予认可，但须满足下列情形之一：代理人负责管理委托人的全部财产；委托人已就此事项作出特别授权；或者代理人是为自身利益而受任。

### <a id="12.2.18"></a>12.2.18　乌尔比安《评告示》第二十六卷

但是，尤利安在《学说汇纂》第十卷中写道，其他代理人提出宣誓时，不应予以听取，以免被告既已宣誓，委托人后来又向其起诉。即使代理人已就委托人追认其行为提供担保，对他也没有多大帮助：如果委托人起诉被告，被告就必须明确证明自己确已宣誓，当然须提出相应抗辩；如果代理人依据追认担保的要式口约提起诉讼，他本人则必须证明自己作了伪誓。

### <a id="12.2.19"></a>12.2.19　乌尔比安《评告示》第二十六卷

因此，如果委托人授权代理人提出请求，而代理人却提出宣誓，他所做的就超出了授权。

### <a id="12.2.20"></a>12.2.20　保罗《评告示》第十八卷

如果奴隶有权管理其特有产，则应认可其所提出或作出的宣誓：

### <a id="12.2.21"></a>12.2.21　盖尤斯《评行省告示》第五卷

因为可以向该奴隶有效清偿，而且他有权使债务更新。

### <a id="12.2.22"></a>12.2.22　保罗《评告示》第十八卷

有些法学家认为，如果奴隶向原告提出宣誓，应准许原告对主人提起特有产之诉。家子提出宣誓时，也应适用同一规则。

### <a id="12.2.23"></a>12.2.23　乌尔比安《评告示》第二十六卷

如果奴隶宣誓称主人无须给付，应当给予主人抗辩；对方既向奴隶提出宣誓，就只能归咎于自己。

### <a id="12.2.24"></a>12.2.24　保罗《评告示》第二十八卷

在能够对家子本人提起诉讼的情形下，家子的诚信与虔敬对家父更为有利。但家子本人将宣誓转向其所受支配之人的，对这些人的法律地位并无不利。

### <a id="12.2.25"></a>12.2.25　乌尔比安《评告示》第二十六卷

此外，如果有人向我的奴隶提出宣誓，或将宣誓转由他作出，而他宣誓称某物属于主人，或应交付给主人，我认为，基于宣誓的神圣效力及当事人之间的约定，应给予我诉权或基于约定的抗辩。

### <a id="12.2.26"></a>12.2.26　保罗《评告示》第十八卷

<a id="12.2.26.pr."></a>

**序言（pr.）** 据称某人已宣誓的，不论其性别或年龄为何，只要提出宣誓的一方在提出时愿意接受该誓言，就必须遵守该宣誓。不过，未成年人似乎不构成伪誓，因为其似乎不能明知而欺骗。

<a id="12.2.26.1"></a>

**1.** 如果父亲宣誓称其子无须给付，卡西乌斯答复说，应当给予父亲和儿子双方宣誓抗辩。如果父亲宣誓特有产中没有财物，仍可起诉儿子；但也可以起诉父亲，并在此时将其后来取得的特有产纳入核算。

<a id="12.2.26.2"></a>

**2.** 宣誓所产生的条件，似乎可以归入债务更新或债务转让的范畴，因为它源于当事人的约定，尽管也具有判决的某些性质。

### <a id="12.2.27"></a>12.2.27　盖尤斯《评行省告示》第五卷

宣誓也具有清偿的效力。

### <a id="12.2.28"></a>12.2.28　保罗《评告示》第十八卷

<a id="12.2.28.pr."></a>

**序言（pr.）** 在共同享有要式口约债权的两人中，一人提出宣誓，对另一人也有不利影响。

<a id="12.2.28.1"></a>

**1.** 被告所作的宣誓也使保证人受益。卡西乌斯与尤利安说，向保证人要求并由其作出的宣誓，也使主债务人受益；因为宣誓取代清偿，因此在此也应作相同处理，但须以该宣誓针对债务合同及其标的，而非针对宣誓者本人为限。

<a id="12.2.28.2"></a>

**2.** 如果有人向承诺将我的债务人带到法庭之人提出宣誓，而此人宣誓称自己根本未曾承诺带其到庭，这不应使我的债务人受益。如果他宣誓称自己不负任何给付义务，则须作出区分，并通过再抗辩予以调整：他究竟是因为承诺之后已将债务人带到庭上，还是因为已经清偿而作出该宣誓？对于债务保证人，也应作同样区分。

<a id="12.2.28.3"></a>

**3.** 两名就同一笔金钱承担要式口约义务的共同债务人中，一人作出宣誓，也应使另一人受益。

<a id="12.2.28.4"></a>

**4.** 宣誓抗辩不只应在当事人提起提出宣誓时所针对的诉讼中援用；如果另一诉讼所审理的也是同一问题，也可以援用。例如，因委任、无因管理、合伙或其他类似诉讼而要求作出宣誓，之后又基于同一事由提起确定给付之返还诉讼；因为其中一项诉讼会消灭另一项诉讼。

<a id="12.2.28.5"></a>

**5.** 如果某人宣誓称自己未曾抢夺某物，该宣誓不得使其在盗窃之诉或盗窃返还之诉中受益；因为抢夺与盗窃并非同一行为，盗窃也可以秘密实施。

<a id="12.2.28.6"></a>

**6.** 如果佃农因砍伐树木而被提起租赁之诉，并宣誓称自己未砍伐，那么此后无论依据《十二表法》中关于砍伐树木的规定、《阿奎利亚法》关于不法致害的规定，还是以暴力或秘密行为为由提起令状诉讼，他都可以援用宣誓抗辩。

<a id="12.2.28.7"></a>

**7.** 如果妇女宣誓称自己并未因离婚而移取财物，而有人对她提起对物之诉，她不得援用抗辩为自己辩护；如果她主张该物属于自己，则须另行作出宣誓。反之，如果她已宣誓称该物属于自己，在移取财物之诉中就应为她提供抗辩。总之，即使同一问题是在另一诉讼中提出，只要情况相同，也应遵循这一规则，使宣誓抗辩得以适用。

<a id="12.2.28.8"></a>

**8.** 因此，如果某人宣誓称自己未被判处给付，即使其后来因判决履行担保的要式口约而被起诉，也可以依据抗辩获得保护。反之，如果某人因该要式口约被起诉，并宣誓称自己无须给付，该抗辩并非必然阻却判决债权人提起诉讼：即使已有判决，也可能并未触发该要式口约；除非其宣誓的理由是其否认自己曾被判处给付。

<a id="12.2.28.9"></a>

**9.** 庞波尼还说，某人宣誓称某物遭人盗窃，并不因此当然取得提起返还之诉的依据。

<a id="12.2.28.10"></a>

**10.** 此外，本款既使宣誓产生诉权，也产生抗辩。如果诉讼之外，因原告提出要求，被告宣誓称自己无须给付；随后又因被告提出要求，原告宣誓称应向自己给付——或反之——则以后作出的宣誓效力更优先。但这并不预先认定另一方作了伪誓，因为所要查明的不是该人是否负有给付义务，而是原告是否作出了宣誓。

### <a id="12.2.29"></a>12.2.29　特里丰尼努斯《论辩集》第六卷

如果你向我提出宣誓，而我宣誓称你并未宣誓应向你给付，那么，即使有人提起准用之诉以查明你是否曾宣誓称应向你给付，我也可以提出宣誓抗辩；该抗辩将消除该诉所包含的争议事项。

### <a id="12.2.30"></a>12.2.30　保罗《评告示》第十八卷

<a id="12.2.30.pr."></a>

**序言（pr.）** 佩迪乌斯说，如果某人在一种因否认而使责任增加的诉讼中宣誓称有人欠其某物，他因此取得的只是请求单倍额的诉权，而非双倍额。因为这已足以免除原告证明的负担；即使不适用告示中有关宣誓的这一部分，双倍额之诉仍完整保留。因此，可以说，该诉讼审理的并非原始债务本身，而是为了维持原告宣誓的效力。

<a id="12.2.30.1"></a>

**1.** 如果我宣誓称你应向我交付奴隶斯提库斯，而该奴隶已不复存在，除非涉及盗窃之债或迟延履行，被告无须向我支付估价；但在这些情形下，即使奴隶已经死亡，也仍须支付估价。

<a id="12.2.30.2"></a>

**2.** 如果妇女宣誓称有人欠她十作为嫁资，则应给付全部十；但如果她宣誓称自己曾交付十作为嫁资，则不应再查明该款是否实际交付，而应如同已经交付一般，给付依法应返还的数额。

<a id="12.2.30.3"></a>

**3.** 在任何人均可提起的诉讼中，所作宣誓只有在善意提出时，才对他人有利；同样，某人提起此类公共诉讼，只有其并非串通诉讼，才会使该公共诉讼归于消灭。

<a id="12.2.30.4"></a>

**4.** 如果自由释奴在保护人提出宣誓后，宣誓称自己并非其自由释奴，应认可该宣誓；因此不得再请求其提供劳务，也不得授予违反遗嘱的遗产占有。

<a id="12.2.30.5"></a>

**5.** 如果我宣誓称用益权应归我，只有在我提供担保、保证依善良之人的判断行使用益权，并在用益权终止后返还标的物时，才应将该用益权交付给我。

### <a id="12.2.31"></a>12.2.31　盖尤斯《评行省告示》第三十卷

应当提醒的是，根据元首的敕令，有时即使已经要求当事人宣誓，仍允许其重新审理案件，前提是其声称发现了新的文书，且现在仅打算依据这些文书主张权利。但这些敕令似乎只适用于某人已经由法官判决免责的情形；因为法官在事实不明的案件中，要求宣誓后，往往依宣誓者一方作出判决。如果当事人之间已经通过宣誓解决争议，则不得再就同一案件重新争讼。

### <a id="12.2.32"></a>12.2.32　莫德斯蒂努《区别论》

未成年人不得免除宣誓。

### <a id="12.2.33"></a>12.2.33　乌尔比安《评萨宾》第二十八卷

以自己的安危为誓的人，虽然看似是在以神为誓——因为其宣誓确实提及神圣神祇——但如果对方并未特别要求他以这种方式宣誓，就不视为已经作出宣誓。因此，他必须从头依正式方式重新宣誓。

### <a id="12.2.34"></a>12.2.34　乌尔比安《评告示》第二十六卷

<a id="12.2.34.pr."></a>

**序言（pr.）** 宣誓既可涉及金钱，也可涉及所有其他事项；甚至可以要求对方就劳务作出宣誓。对方不能仅因宣誓事项而提出不公之诉，因为他可以将宣誓转由对方作出。不过，如果被告称自己已经免责，因为他认为自己曾承诺交付的奴隶斯提库斯已经死亡，该宣誓就不适合转由其作出。因此，马尔凯鲁斯认为——而且此说正确——要么应免除该宣誓，要么应给予其一段时间，使其查明情况后再作宣誓。

<a id="12.2.34.1"></a>

**1.** 如果有授权，市镇或任何团体的诉讼代表可以提出宣誓。

<a id="12.2.34.2"></a>

**2.** 不得向受监护的未成年人提出宣誓。

<a id="12.2.34.3"></a>

**3.** 代理人和诉讼防御人均不受强制作出宣誓。尤利安在《学说汇纂》第十卷中写道，不得强迫诉讼防御人宣誓；只要其准备接受诉讼，就足以构成完整的诉讼防御。

<a id="12.2.34.4"></a>

**4.** 如有要求，提出宣誓者应先作反诬诉宣誓，然后对方才作出其所要求的宣誓。此种反诬诉宣誓，对释奴保护人和父母也同样可以免除。

<a id="12.2.34.5"></a>

**5.** 如果当事人对宣誓的具体内容发生争议，应由审理案件的法官决定宣誓措辞。

<a id="12.2.34.6"></a>

**6.** 裁判官说：“我将强令被要求宣誓之人付款或宣誓。”因此，被告应当二选一：要么付款，要么宣誓；若其不宣誓，裁判官就应强令其付款。

<a id="12.2.34.7"></a>

**7.** 被告还有另一种选择：如果愿意，可以将宣誓转由原告作出。若原告不接受宣誓所附条件，裁判官就不向其授予诉讼。如此处理极为公平，因为提出该宣誓条件的人不应随后又对该条件不满。但在转由对方作出宣誓时，不得提出反诬诉宣誓；因为如果原告自己提出了宣誓条件，就不得要求对方宣誓称原告并非出于诬诉目的行事。

<a id="12.2.34.8"></a>

**8.** 转由对方作出的宣誓，并非始终能够与原先提出的宣誓在各方面完全一致；有时因事项或当事人不同，会出现导致宣誓内容必须有所变化的情形。因此，如果发生此类情况，应由法官依其职权确定该宣誓的具体措辞。

<a id="12.2.34.9"></a>

**9.** 如果事项已交付宣誓处理，法官应使作出宣誓的一方免责；若对方将宣誓转回，法官应予听取。原告宣誓的，法官应判令被告承担责任。被告不愿宣誓但已付款的，法官应判其免责；未付款的，则应判其承担责任。原告在宣誓被转回后不愿宣誓的，法官应判被告免责。

### <a id="12.2.35"></a>12.2.35　保罗《评告示》第二十八卷

<a id="12.2.35.pr."></a>

**序言（pr.）** 在其他证据均告缺乏时，受监护未成年人的监护人提出宣誓，应予听取；因为有时法院会拒绝向未成年人授予诉讼。

<a id="12.2.35.1"></a>

**1.** 挥霍者提出宣誓的，不应予以听取；其他与其情形相似之人也同样处理。因为宣誓无论具有约定、清偿还是判决的效力，都不应认可不具备相应行为资格之人所提出的宣誓。

<a id="12.2.35.2"></a>

**2.** 不得在罗马被强令接受诉讼的人，也不得被强令宣誓，例如行省使节。

### <a id="12.2.36"></a>12.2.36　乌尔比安《评告示》第二十七卷

如果原告只就已约定的金钱债务提出宣誓，而被告作出宣誓，则在被告因该项约定被起诉时，他可以援用抗辩；但如果他因原始债务本身被起诉，抗辩就不适用，除非对方也曾就该项债务提出宣誓而他同样作了宣誓。

### <a id="12.2.37"></a>12.2.37　乌尔比安《评告示》第三十三卷

提出宣誓之人如果没有免除该宣誓，而对方又没有作出反诬诉宣誓，相应地应拒绝向其授予诉讼。因为他在未先要求对方作反诬诉宣誓的情况下就启动宣誓程序，只能归咎于自己；这种情形应视同其已免除了该宣誓。

### <a id="12.2.38"></a>12.2.38　保罗《评告示》第三十七卷

既不愿宣誓，也不愿将宣誓转由对方作出，表明其品行显然不端，并等同于承认。

### <a id="12.2.39"></a>12.2.39　尤利安《学说汇纂》第十卷

如果某人与债务人约定：只要债务人宣誓自己没有登上卡皮托利诺山，或宣誓自己曾做或未做任何其他事情，债权人便不请求其付款；而债务人确已作出该宣誓，就应给予其宣誓抗辩，已经支付的款项也可以请求返还。因为只要当事人约定将任何事项作为宣誓的条件，该约定就是正当的。

### <a id="12.2.40"></a>12.2.40　尤利安《学说汇纂》第十三卷

债务人被要求宣誓后，其质物即解除担保；因为这与承认清偿相似，而且当然产生永久抗辩。因此，即使债权人请求支付罚金，也应以抗辩阻却其诉请；已经支付的款项可以请求返还。宣誓一经介入，所有争议即告终结。

### <a id="12.2.41"></a>12.2.41　庞波尼《规则集》单卷

拉贝奥答复说，可以免除缺席者或不知情者的宣誓；甚至可以通过书信免除宣誓。

### <a id="12.2.42"></a>12.2.42　庞波尼《书信集》第十八卷

<a id="12.2.42.pr."></a>

**序言（pr.）** 债权人就借款向受监护的未成年人主张权利，并向他提出宣誓；未成年人宣誓称自己无须给付。随后，债权人向该未成年人的保证人请求同一笔款项。保证人能否以宣誓抗辩排除该请求？请回信告知你的意见。尤利安对此事作了更清楚的说明。如果债权人与未成年人之间争议的是未成年人是否曾经借到该笔款项，并且双方约定，只要未成年人宣誓称自己无须给付，一切请求即告终结，而未成年人也确已如此宣誓，那么该约定就会消灭自然债务；已经支付的款项也可以请求返还。但如果债权人主张自己已交付借款，而未成年人仅以监护人未参与为由抗辩，并且双方作出的正是这种内容的宣誓，则裁判官不会保护保证人。如果无法明确证明双方究竟约定了什么，而情况又不清楚——这种情形往往会发生——即债权人提出宣誓后，未成年人究竟是就事实还是就法律问题与其发生争议，我们应当认定双方的约定是：只要未成年人宣誓称自己无须给付，一切请求即告终结。据此，我们认为，已支付的款项可以请求返还，保证人也应得到抗辩。

<a id="12.2.42.1"></a>

**1.** 如果保证人宣誓称自己无须给付，主债务人可以援用宣誓抗辩而获得保护；但如果保证人宣誓的意思是自己根本未曾成为保证人，该宣誓就不应使主债务人受益。

<a id="12.2.42.2"></a>

**2.** 如果原告提出宣誓后，为缺席或到庭之人进行诉讼防御的防御人宣誓称其所防御之人无须给付，就应向该被代理之人授予宣誓抗辩。保证人的防御人宣誓时，也适用同一理由；因此，应向主债务人授予抗辩：

<a id="12.2.42.3"></a>

**3.** 同样，如果被告作出宣誓，保证人也应受其保护，因为依据对其中任一人作出的既判事项，另一人也会受益。
