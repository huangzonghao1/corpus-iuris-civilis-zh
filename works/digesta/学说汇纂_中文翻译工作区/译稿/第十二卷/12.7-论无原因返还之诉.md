## 12.7.0　论无原因返还之诉（*De condictione sine causa*）

### <a id="12.7.1"></a>12.7.1　乌尔比安《评萨宾》第四十三卷

<a id="12.7.1.pr."></a>

**序言（pr.）** 返还之诉（*condictio*）还有一种类型：某人无原因（*sine causa*）地作出允诺，或者清偿了非债（*indebitum*）。无原因作出允诺的人，不能请求返还其未曾给付的金额，而只能请求消灭债务本身。

<a id="12.7.1.1"></a>

**1.** 如果某人基于某项原因作出允诺，但该原因最终未能实现，也应当说可以提起返还之诉。

<a id="12.7.1.2"></a>

**2.** 无论允诺自始没有原因，还是原先存在的允诺原因后来消灭或未能实现，都应当说可以提起返还之诉。

<a id="12.7.1.3"></a>

**3.** 可以确定，只有某物并非基于正当原因（*non ex iusta causa*）而归于某人，或者其返还系基于不正当原因（*redit ad non iustam causam*）时，才可以对该人提起返还之诉。

### <a id="12.7.2"></a>12.7.2　乌尔比安《告示评注》第三十二卷

**正文** 洗衣工（*fullo*）承接了洗涤衣物的工作，后来衣物遗失；经衣物所有人以租赁之诉（*actio ex locato*）追索，他已支付衣物价款。此后所有人又找到了衣物。洗衣工应当通过何种诉讼取回已经支付的价款？卡西乌斯说，他不仅可以提起基于租赁关系的诉讼（*actio ex conducto*），还可以对所有人提起返还之诉。我认为，他无论如何都享有基于租赁关系的诉讼（*ex conducto*）；但他是否也可以提起返还之诉，仍有疑问，因为他支付的并非非债给付。除非我们认为，可以将该给付视为无原因给付而请求返还：毕竟，衣物被找到后，这笔给付似乎就成了无原因给付。

### <a id="12.7.3"></a>12.7.3　尤利安《学说汇纂》第八卷

**正文** 无原因负担债务的人，可以通过不确定给付之诉（*condictio incerti*）请求免除债务。某人是自始无原因地承担全部债务，还是承担了超过其本应承担的债务，并无区别；区别仅在于，有时提起返还之诉是为了使其免除全部债务，有时则是为了使其免除部分债务。例如，某人允诺给付十：如果其对作出任何允诺均无原因，可以通过不确定给付之诉请求以受领清偿（*acceptilatio*）的方式消灭整个要式口约（*stipulatio*）；但如果他本应只允诺给付五，却允诺给付十，则可以通过不确定给付之诉请求免除其中五。

### <a id="12.7.4"></a>12.7.4　阿非利卡努斯《疑难集》第八卷

**正文** 给付之物究竟自始无原因，还是给付所依据的原因最终未能实现，并无区别。

### <a id="12.7.5"></a>12.7.5　帕比尼安《疑难集》第十一卷

<a id="12.7.5.pr."></a>

**序言（pr.）** 一名女子准备与其舅父（*avunculus*）成婚，便给付钱款作为嫁资（*dos*），但最终没有成婚。有人询问，她能否请求返还该笔钱款。我答复说，如果钱款是基于给付人和受领人双方的不道德原因而支付的，返还之诉便不适用；在双方过错相当时，占有人地位较优。有人或许据此会答复说，该女子不能提起返还之诉。但是，在本案中，主张给付原因并非不道德、而是根本不存在，才是正确的；因为所给钱款不可能转作嫁资。毕竟，该钱款并非为不正当性行为（*stuprum*）而给付，而是为缔结婚姻而给付。

<a id="12.7.5.1"></a>

**1.** 继母（*noverca*）给继子（*privignus*）、儿媳（*nurus*）给公公（*socer*）钱款作为嫁资，但双方没有成婚。乍看之下，似乎不得提起返还之诉，因为依万民法（*ius gentium*），此种婚姻构成乱伦（*incestum*）；然而，在这种情形下，更应认为给付嫁资的原因根本不存在。因此，可以提起返还之诉。
