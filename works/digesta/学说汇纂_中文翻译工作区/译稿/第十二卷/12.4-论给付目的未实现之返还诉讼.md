## 12.4.0　论因给付目的未实现之返还诉讼（*De condictione causa data causa non secuta*）

### <a id="12.4.1"></a>12.4.1　乌尔比安《评告示》第二十六卷

<a id="12.4.1.pr."></a>

**序言（pr.）** 如果钱款是为正当目的而交付，例如为了使儿子脱离家父权（*emancipatio*）、释放奴隶（*manumissio*），或使对方退出诉讼，那么目的既已实现，就不得请求返还。

<a id="12.4.1.1"></a>

**1.** 如果我为使你履行某项条件而交给你十枚钱币，之后却拒绝接受遗产或遗赠，我可以提起返还之诉（*condictio*）。

### <a id="12.4.2"></a>12.4.2　赫莫革尼安《法学概要》第二卷

但如果遗嘱被宣告为伪造，且给付人对此并无不法行为，或者遗嘱被宣告为违反遗嘱扶养义务，那么由于给付目的未实现，十枚钱币可以请求返还。

### <a id="12.4.3"></a>12.4.3　乌尔比安《评告示》第二十六卷

<a id="12.4.3.pr."></a>

**序言（pr.）** 我给你钱，是为了不让案件诉诸法官，仿佛双方已经和解。我能否在你未向我提供不再诉诸法官的担保（*cautio*）时提起返还之诉？对此，确实应区分：我究竟仅仅为了不使案件诉诸法官而给你钱，还是还要求你承诺不诉诸法官。如果我还要求你作出此项承诺，而你未作承诺，我可以提起返还之诉（*condictio*）；如果我只是为了不使案件诉诸法官而给你钱，只要案件尚未诉诸法官，就不得提起返还之诉。

<a id="12.4.3.1"></a>

**1.** 如果我给你钱，是为了不让你释放斯提库斯，也应依上述区分决定：要么准许请求返还，要么不准许。

<a id="12.4.3.2"></a>

**2.** 但如果我给你钱，是为了让你释放斯提库斯，而你没有释放，或者我后来改变主意，我可以请求返还。

<a id="12.4.3.3"></a>

**3.** 如果我约定你应在特定期限内释放斯提库斯，又该如何？期限尚未届满时，除非我改变主意，否则应阻止我请求返还；期限届满后，则可以请求返还。但如果斯提库斯死亡，已经给付的钱能否请求返还？普罗库鲁斯认为：如果他是在本可被释放的期限届满后死亡，可以请求返还；如果他在此之前死亡，则不得请求返还。

<a id="12.4.3.4"></a>

**4.** 不仅如此，即使我没有实际给你任何东西，只是约定将给你某物以便你释放奴隶，基于此项契约产生的诉讼——也就是返还之诉（*condictio*）——仍由你享有；即使该奴隶已经死亡，也不例外。

<a id="12.4.3.5"></a>

**5.** 如果一名以善意为奴隶身份服役的自由人给我钱，要求我释放他，而我确已释放；后来他被确认是自由人，他能否向我请求返还，尚有疑问。尤利安在《学说汇纂》第十一卷中写道，被释放的人可以请求返还。涅拉提乌斯在《文书集》中也记载，哑剧演员帕里斯曾通过法官向多米提娅——尼禄皇帝之女——请求返还他为获得自由而交给她的十枚钱币；法官并未追问多米提娅收钱时是否知道他是自由人。

<a id="12.4.3.6"></a>

**6.** 如果某人自以为是附条件获得自由的奴隶（*statuliber*），未经命令便交给我十枚钱币，塞尔苏斯写道，他可以请求返还这十枚钱币。

<a id="12.4.3.7"></a>

**7.** 如果某奴隶依遗嘱受命向继承人交付十枚钱币后即可获得自由，却在遗嘱信令中被无条件给予自由；他对此并不知情，仍将十枚钱币交给继承人，那么他能否请求返还？塞尔苏斯记载，他的父亲认为不得请求返还；但塞尔苏斯本人出于自然衡平，认为可以请求返还。此意见较为正确。诚然，如塞尔苏斯本人所承认，如果给付人抱有这样的期待——认为受领人会回报自己或因此对自己更友善——即使这一想法是错误的，也不能请求返还。

<a id="12.4.3.8"></a>

**8.** 此外，塞尔苏斯还细致探讨了如下问题：某人以为自己是附条件获得自由的奴隶，因此将钱交给继承人时，并未使受领人取得钱币所有权；因为他交付钱币时，以为自己是在给继承人本人的钱，而不是给自己的钱；事实上，在依据遗嘱获得自由之后取得的钱币，当然已经属于他本人。我认为，如果他确是抱有这种意思而给付，钱币就不会归受领人所有。因为，即使我把自己的钱交给你，误以为那是你的钱，也不会因此使钱币成为你的。那么，如果此人没有把钱交给继承人，而是交给他人呢？如果交付的是特有产（*peculium*）中的钱币，受领人也不会取得所有权；但如果是他人代为交付，或者他已获得自由后亲自交付，钱币就会归受领人所有。

<a id="12.4.3.9"></a>

**9.** 虽然附条件获得自由的奴隶可以从特有产中给付钱币，以履行条件；但如果继承人想保全这些钱币，可以禁止他给付。这样一来，该奴隶因被禁止履行其应当服从的条件，仍可视为已经履行条件并获得自由，而钱币也不会灭失。不过，遗嘱人希望受领钱币的人，可以对继承人提起事实之诉（*actio in factum*），请求使遗嘱人的安排得到遵行。

### <a id="12.4.4"></a>12.4.4　乌尔比安《评告示》第三十九卷

如果某人以要式免债行为（*acceptilatio*）免除其债务人的债务，条件是债务人应另行提供一名代为承担债务的人（*expromissor*），但债务人没有提供，可以认为，能够对因免除而获释的债务人提起返还之诉。

### <a id="12.4.5"></a>12.4.5　乌尔比安《论辩集》第二卷

<a id="12.4.5.pr."></a>

**序言（pr.）** 如果你收取钱款，是为了前往卡普阿，随后你已准备出发，却因时势或健康状况受阻而未能成行，应考察能否请求返还。既然未能成行并非你的过错，可以认为不得请求返还；但是，给付人可以改变主意，因此毫无疑问，已给付之物仍可请求返还，除非对你而言，不为此目的收取钱款反而更有利。比如，尽管你尚未出发，却已安排妥当，因而必然要成行；或者你已支付为此次行程所必需的费用，甚至显然支出可能超过所收钱款，那么返还之诉就不成立。但如果支出少于所收钱款，则可以提起返还之诉，不过应赔偿你已经支出的费用，使你不受损失。

<a id="12.4.5.1"></a>

**1.** 如果某人交付奴隶，约定受领人应在一定期限内释放该奴隶；交付人后来改变主意并将此事通知受领人，而受领人在交付人改变主意之后才释放奴隶，交付人仍可因其改变主意而提起诉讼。不过，如果受领人没有释放奴隶，相应的敕令（*constitutio*）便会取代约定，使奴隶获得自由，前提是交付人尚未改变主意。

<a id="12.4.5.2"></a>

**2.** 同样，如果某人给提图斯十枚钱币，让他买下奴隶并予以释放，之后交付人改变主意：如果奴隶尚未买下，交付人告知提图斯自己已改变主意后，即可提起返还之诉，以免提图斯之后购买奴隶而遭受损失；如果奴隶已经买下，交付人改变主意便不会使买下奴隶的人受损。提图斯应交付用这十枚钱币买下的奴隶；如果据称该奴隶此前已经死亡，只要并非提图斯所致，提图斯就无须给付任何东西。如果奴隶逃走，且逃走并非提图斯的过失，提图斯也无须给付；但他应承诺，如果奴隶重新落入其控制之下，就将其返还。

<a id="12.4.5.3"></a>

**3.** 如果有人收取钱款，答应释放奴隶，但奴隶在获得自由前逃走，尚须考察能否请求返还已收钱款。如果受领人原本打算出售该奴隶，只是因为收取了释放奴隶的钱款才没有出售，就不得请求其返还这笔钱；不过，受领人应提供担保：如果奴隶重新落入其控制之下，就返还已收钱款，但应扣除奴隶因逃亡而贬值的部分。显然，如果给付人仍希望释放奴隶，而受领人因奴隶逃亡而不愿释放，就应返还全部已收钱款。如果给付十枚钱币的人选择取得奴隶本人，那么受领人要么应将奴隶交给他，要么返还给付的钱款。但如果受领人原本并不打算出售奴隶，就应返还所收钱款；除非受领人若未收取释放奴隶的钱款，本会更加悉心照料奴隶。若属此种情形，让其既失去奴隶又失去全部价款便不公平。

<a id="12.4.5.4"></a>

**4.** 如果某人收钱答应释放奴隶，而后奴隶死亡：如果受领人迟延释放，就应认定他必须返还所收钱款。如果他并未迟延，而是在前往总督或其他有权释放奴隶的人处的途中，奴隶死亡，那么更为妥当的意见是：如果受领人原本打算出售奴隶，或者打算自己使用奴隶，就不必返还任何钱款。但是，如果他原本并无这类打算，奴隶仍因自身原因死亡，因为即使受领人没有收钱答应释放奴隶，该奴隶也会死亡。除非前往办理释放一事导致奴隶死亡，例如奴隶被强盗杀害、在客店被倒塌物压死、被车辆碾死，或因其他若非为释放奴隶而出行便不会发生的原因死亡。

### <a id="12.4.6"></a>12.4.6　乌尔比安《论辩集》第三卷

如果第三人替女子给付嫁资（*dos*），并约定无论婚姻以何种方式终止，嫁资都应返还给他；但婚姻最终没有缔结，因为双方约定的仅是婚姻成立后才可能发生的各种情形，而婚姻并未成立，那么应考察究竟是女子还是给付嫁资的人享有返还之诉。可以认为，即使在此情形下，给付人也是为自己作安排：他是为了缔结婚姻而给付，而婚姻没有成立，因此可以提起因给付目的未实现（*causa non secuta*）之返还之诉；除非女子以明确证据证明，给付人这样做是为了照顾她本人，而非照顾自己。如果父亲替女儿给付，并以此约定，除非明确证明另有约定，马尔凯卢斯认为返还之诉属于父亲。

### <a id="12.4.7"></a>12.4.7　尤利安《学说汇纂》第十六卷

<a id="12.4.7.pr."></a>

**序言（pr.）** 某人以为自己欠女子一笔钱，经女子指示，以嫁资名义向其未婚夫作出允诺并付清钱款；之后婚姻没有缔结。问题是，究竟由给付钱款的人本人请求返还，还是由女子请求返还？涅尔瓦和阿提利基努斯答复说：此人虽以为自己欠钱，但本可通过恶意抗辩（*exceptio doli mali*）保护自己，因此应由其本人请求返还。如果此人明知自己不欠女子钱却作出允诺，则诉权属于女子，因为钱款归女子所有。如果此人确实是债务人，并在婚姻缔结前清偿，但婚姻后来没有成立，他本人可以提起返还之诉（*condictio*）；女子对原债务的权利仍然完整，但除此之外，她只能要求债务人将返还诉权让与她。

<a id="12.4.7.1"></a>

**1.** 以嫁资名义交付的土地，如果婚姻没有缔结，可以通过返还之诉请求返还；孳息也可以请求返还。女奴及其所生子女亦适用同一规则。

### <a id="12.4.8"></a>12.4.8　涅拉提乌斯《文书集》第二卷

塞尔维乌斯在《论嫁资》中写道，如果两人结婚时其中一人尚未达到法定婚龄，暂时以嫁资名义给付的物可以请求返还。对此应作如下理解：如果双方在都达到法定婚龄之前离婚，就可以请求返还这笔钱；但只要双方仍维持婚姻关系，就不能请求返还，正如未婚女子以嫁资名义给未婚夫的财物，只要两人之间仍存在姻亲关系（*adfinitas*），就不得请求返还。因为，这些财物虽在婚姻尚未缔结时给付，却是以其将来成为嫁资为目的；只要它们仍有可能成为嫁资，就不得请求返还。

### <a id="12.4.9"></a>12.4.9　保罗《评普劳提乌斯》第十七卷

<a id="12.4.9.pr."></a>

**序言（pr.）** 如果我应女子的请求，将钱交给其未婚夫，意在赠与该女子，而婚姻没有缔结，则女子可以提起返还之诉（*condictio*）。但如果我与未婚夫订立契约并将钱交给他，约定婚姻若缔结则女子取得嫁资，婚姻若未缔结则钱款返还给我，那么这属于为实现某一目的而给付；目的未实现时，我可以向未婚夫提起返还之诉。

<a id="12.4.9.1"></a>

**1.** 如果某人因错误，经女子指示，向其未婚夫承诺给付一笔本不应给付的钱款，而婚姻后来缔结，该人不得援用恶意抗辩（*exceptio doli mali*）。因为丈夫是在处理自己的事务，并无欺诈，也不应使其受骗；否则就会导致他被迫接受没有嫁资的妻子。因此，该人对女子享有返还之诉（*condictio*），可以向她请求返还已经交给丈夫的钱；如果尚未给付，则可以请求免除给付义务。但如果婚姻解除后丈夫提出请求，只有在女子将能取回相应款项的范围内，恶意抗辩才会阻却其请求。

### <a id="12.4.10"></a>12.4.10　雅沃勒努斯《评普劳提乌斯》第一卷

如果女子想把他人欠她的钱作为嫁资交给自己即将结婚的对象，于是以要式免债行为（*acceptilatio*）免除了对方的债务，但婚姻没有缔结，那么她可以正确地提起返还之诉，因为钱款无原因地到达受领人手中，无论是通过实际交付，还是通过免除债务，均无区别。

### <a id="12.4.11"></a>12.4.11　尤利安《学说汇纂》第十卷

如果继承人受命按照被释奴的决定，以确定金额建造纪念物，却将钱交给被释奴，而被释奴收钱后并未建造纪念物，被释奴应承担返还之诉。

### <a id="12.4.12"></a>12.4.12　保罗《尤利娅法与帕皮娅法》第六卷

如果赠与人恢复健康后请求返还其因死亡而为之作出的赠与（*donatio mortis causa*），他也可以请求返还受赠财物的孳息、所生子女及添附之物。

### <a id="12.4.13"></a>12.4.13　马尔西安《规则集》第三卷

如果某个儿子给其兄弟钱款，以便自己能加入并取得遗产占有（*bonorum possessio*），但后来没有加入，马尔凯卢斯在《学说汇纂》第五卷中写道，他可以请求返还。

### <a id="12.4.14"></a>12.4.14　保罗《评萨宾》第三卷

如果本不应给付的钱款付给了冒名代理人（*falsus procurator*），只有在本人追认的情况下，才不得向代理人请求返还；但本人应承担责任，尤利安即如此写道。如果本人没有追认，即使所付钱款原本确实是债务，也可以向代理人请求返还：这并非作为误付而请求返还，而是因为钱款是为某一目的而给付，但由于本人没有追认，目的未能实现。或者，冒名代理人取得钱款构成盗窃；对他不仅可以提起盗窃之诉，也可以提起返还之诉。

### <a id="12.4.15"></a>12.4.15　庞波尼乌斯《评萨宾》第二十二卷

你的奴隶被阿提乌斯怀疑实施盗窃，你便将奴隶交给阿提乌斯拷问，并约定如果没有从奴隶身上查出此事，就应将其还给你。阿提乌斯却以奴隶在犯罪时被当场抓获为由，将其交给警备队长；警备队长对奴隶处以极刑。你可以请求阿提乌斯向你返还该奴隶，因为在奴隶死亡之前，阿提乌斯就应将其返还给你。拉贝奥说，也可以提起出示之诉（*actio ad exhibendum*），因为阿提乌斯使奴隶无法出示。普罗库鲁斯则说，只有在你已使该奴隶成为他的财产时，才可以请求对方给付该奴隶；在这种情况下，你不能提起出示之诉。〔底本此处作“*si fecisses eius hominem*”，句法与指代有疑；以上暂依上下文译出。〕但如果奴隶仍是你的，你也可以对阿提乌斯提起盗窃之诉（*actio furti*），因为他使用他人之物时，明知未经所有人同意而使用，或者明知所有人若知情就会禁止其使用。

### <a id="12.4.16"></a>12.4.16　塞尔苏斯《学说汇纂》第三卷

我给你钱，目的是让你把斯提库斯交给我：这种契约类型究竟部分属于买卖，还是除此之外并无其他债务关系，而只是为某一目的给付、但目的未实现（*ob rem dati re non secuta*）？我倾向于后一种意见。因此，如果斯提库斯死亡，我可以提起返还之诉（*condictio*），请求返还为取得斯提库斯而交给你的钱。假设斯提库斯属于他人，但你仍将他交给我；我可以向你请求返还钱款，因为你没有使该奴隶成为受领人的所有物。反过来说，如果斯提库斯属于你，而你不愿就其被第三人追夺承担担保责任，你也不能因此免于向我返还钱款。
