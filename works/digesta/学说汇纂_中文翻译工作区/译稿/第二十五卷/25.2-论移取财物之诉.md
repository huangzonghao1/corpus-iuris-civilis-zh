# D.25.2 论移取财物之诉

<!-- source-p 001 -->
<a id="2"></a><a id="25.2"></a>**25.2.0. 论移取财物之诉（*De actione rerum amotarum*）**

<!-- source-p 002 -->
<a id="25.2.1"></a>**25.2.1**

<!-- source-p 003 -->
**保罗《萨宾评注》第七卷。**

<!-- source-p 004 -->
针对曾为妻子的妇女，创设了一项独特的移取财物之诉，因为法律不允许对她提起盗窃之诉。有些人认为她甚至不构成盗窃，例如涅尔瓦与卡西乌斯；他们认为，共同生活的关系在某种程度上使她成为财物的所有人。另一些人，如萨宾与普罗库鲁斯，则认为她确实实施了盗窃，正如女儿会对父亲实施盗窃一样；但依既定法，不得对她提起盗窃之诉。尤利安完全正确地采纳了后一见解：

<!-- source-p 005 -->
<a id="25.2.2"></a>**25.2.2**

<!-- source-p 006 -->
**盖尤斯《裁判官告示评注·既判事项篇》。**

<!-- source-p 007 -->
因为出于维护婚姻尊严的考虑，不允许针对妻子提起这种有失体面的诉讼。

<!-- source-p 008 -->
<a id="25.2.3"></a>**25.2.3**

<!-- source-p 009 -->
**保罗《萨宾评注》第七卷。**

<!-- source-p 010 -->
<a id="25.2.3.pr."></a>**序言。**因此，若妻子在离婚后再次接触这些物品，也应承担盗窃责任。

<!-- source-p 011 -->
<a id="25.2.3.1"></a>**1.**同样，如果妻子的奴隶实施盗窃，我们可以对妻子提起盗窃之诉。

<!-- source-p 012 -->
<a id="25.2.3.2"></a>**2.**如果妻子偷窃了我们继承之人的物品，或者在她与我们结婚之前偷窃了我们的物品，也可以对她提起盗窃之诉。但出于对当事人身份的尊重，我们说，这两种情形下都只能提起盗窃物返还之诉，不能提起盗窃之诉。

<!-- source-p 013 -->
<a id="25.2.3.3"></a>**3.**同样，奥菲利乌斯所说确属正确：妇女在离婚时消费、出售、赠与或以任何方式耗尽的物品，也包括在移取财物之诉的范围内。

<!-- source-p 014 -->
<a id="25.2.3.4"></a>**4.**若家女取走财物，梅拉与富尔基尼乌斯认为，应准许提起特有产之诉，因为不允许使她承担盗窃责任；或者，也可以直接对她提起移取财物之诉。但若父亲与女儿共同提起嫁资之诉，只有在女儿以移取财物之诉承担全部责任，并提供担保的情况下，才应准许父亲提起该诉。普罗库鲁斯说，女儿死亡后，不应对父亲准许移取财物之诉，除非父亲因该事而获益。

<!-- source-p 015 -->
<a id="25.2.4"></a>**25.2.4**

<!-- source-p 016 -->
**庞波尼乌斯《萨宾评注》第十六卷。**

<!-- source-p 017 -->
或者以恶意阻止该物到达他手中。

<!-- source-p 018 -->
<a id="25.2.5"></a>**25.2.5**

<!-- source-p 019 -->
**帕比尼安《问题集》第十一卷。**

<!-- source-p 020 -->
女儿尚在世时，父亲因取走财物而取得的利益，也应通过准用诉讼请求返还。

<!-- source-p 021 -->
<a id="25.2.6"></a>**25.2.6**

<!-- source-p 022 -->
**保罗《萨宾评注》第七卷。**

<!-- source-p 023 -->
<a id="25.2.6.pr."></a>**序言。**阿提利基努斯与富尔基尼乌斯说，在嫁资给付给处于父权之下的儿子时，也应准许岳父对儿媳提起本诉：

<!-- source-p 024 -->
<a id="25.2.6.1"></a>**1.**岳父不得就因离婚而取走的物品提起盗窃之诉。

<!-- source-p 025 -->
<a id="25.2.6.2"></a>**2.**同样，对丈夫也可以提起移取财物之诉；若丈夫是处于父权之下的家子，应对其特有产提起诉讼，还是直接对本人提起诉讼？我们将重复前文关于家女所说的规则。

<!-- source-p 026 -->
<a id="25.2.6.3"></a>**3.**离婚后丈夫死亡的，其继承人可以提起移取财物之诉。

<!-- source-p 027 -->
<a id="25.2.6.4"></a>**4.**同样，妻子的继承人也应基于此事承担责任，正如其因盗窃原因承担返还之诉的责任一样。

<!-- source-p 028 -->
<a id="25.2.6.5"></a>**5.**但若婚姻因丈夫死亡而解除，丈夫的继承人可以通过遗产请求之诉或出示之诉取回这些物品。阿里斯托正确地认为，也可以对妻子提起返还之诉，因为这些物品是基于不正当原因留在她手中的〔底本文字有疑〕。

<!-- source-p 029 -->
<a id="25.2.6.6"></a>**6.**若妻子在丈夫死亡后才取走物品，她并未实施盗窃，因为对尚未占有的遗产物不构成盗窃。因此，这些物品可以被请求返还原物，或者纳入遗产请求之诉。

<!-- source-p 030 -->
<a id="25.2.7"></a>**25.2.7**

<!-- source-p 031 -->
**乌尔比安《萨宾评注》第三十六卷。**

<!-- source-p 032 -->
妻子可以对丈夫提起移取财物之诉，并可将该诉与丈夫拟提起的移取财物之诉相抵销。

<!-- source-p 033 -->
<a id="25.2.8"></a>**25.2.8**

<!-- source-p 034 -->
**庞波尼乌斯《萨宾评注》第十六卷。**

<!-- source-p 035 -->
<a id="25.2.8.pr."></a>**序言。**若在向妻子返还嫁资或提供嫁资担保时，没有约定不得就取走财物提起诉讼，仍然可以提起该诉；因为即使没有嫁资，也会准许同一诉讼。

<!-- source-p 036 -->
<a id="25.2.8.1"></a>**1.**萨宾说，如果妻子不返还其取走的物品，应按丈夫在诉讼中所作宣誓的金额予以估价。

<!-- source-p 037 -->
<a id="25.2.9"></a>**25.2.9**

<!-- source-p 038 -->
**保罗《告示评注》第三十七卷。**

<!-- source-p 039 -->
（毕竟，不能不公平地强迫某人按自己所定的价格出售自己的物品。）

<!-- source-p 040 -->
<a id="25.2.10"></a>**25.2.10**

<!-- source-p 041 -->
**庞波尼乌斯《萨宾评注》第十六卷。**

<!-- source-p 042 -->
因此，他也无须就追夺承担担保责任，因为事情之所以如此，是由于妻子的抗拒行为。

<!-- source-p 043 -->
<a id="25.2.11"></a>**25.2.11**

<!-- source-p 044 -->
**乌尔比安《告示评注》第三十三卷。**

<!-- source-p 045 -->
<a id="25.2.11.pr."></a>**序言。**马尔凯卢斯在《学说汇纂》第八卷中写道：无论是丈夫将妻子逐出家门，还是妻子将丈夫逐出家门，只要他们取走了物品，就应承担移取财物之诉的责任。

<!-- source-p 046 -->
<a id="25.2.11.1"></a>**1.**提起移取财物之诉的人若选择向对方提出宣誓要求，对方就必须宣誓离婚时并未取走任何物品；但提出宣誓要求的人应先宣誓自己并非出于恶意滋扰而提出该要求。

<!-- source-p 047 -->
<a id="25.2.11.2"></a>**2.**丈夫和妻子都必须宣誓。但取走财物者的父亲无须宣誓，因为要求他人就别人的行为宣誓并不公平；因此，应由被指称取走物品的人宣誓。并且，被指称取走物品者的继承人也无须宣誓。

<!-- source-p 048 -->
<a id="25.2.11.3"></a>**3.**如果被要求宣誓的人想把宣誓要求转回给对方，裁判官似乎并未予以准许，

<!-- source-p 049 -->
<a id="25.2.12"></a>**25.2.12**

<!-- source-p 050 -->
**保罗《简要论集》第七卷。**

<!-- source-p 051 -->
正如某人向提起盗窃之诉的人提出宣誓要求，询问他自己是否为盗窃者时，裁判官也不会准许对方反向要求其宣誓。

<!-- source-p 052 -->
<a id="25.2.13"></a>**25.2.13**

<!-- source-p 053 -->
**乌尔比安《告示评注》第三十三卷。**

<!-- source-p 054 -->
因此，拉贝奥写道，不应允许妻子将宣誓要求转回给丈夫；该告示看起来正是如此安排的。

<!-- source-p 055 -->
<a id="25.2.14"></a>**25.2.14**

<!-- source-p 056 -->
**保罗《告示评注》第十八卷。**

<!-- source-p 057 -->
对于被取走的物品，应允许丈夫或妻子就其中某些物品要求对方宣誓，就另一些物品则通过证明加以主张。

<!-- source-p 058 -->
<a id="25.2.15"></a>**25.2.15**

<!-- source-p 059 -->
**乌尔比安《告示评注》第三十四卷。**

<!-- source-p 060 -->
<a id="25.2.15.pr."></a>**序言。**双方是否共同居住并无区别，因为即使妻子从她未与丈夫共同居住的房屋中取走物品，也可以对她提起移取财物之诉。

<!-- source-p 061 -->
<a id="25.2.15.1"></a>**1.**妻子、儿媳和孙媳可以对丈夫、岳父和曾祖父实施盗窃，但不承担盗窃责任；除非其丈夫已脱离父权。此时，儿媳便对其丈夫的父亲实施盗窃，并承担盗窃责任。

<!-- source-p 062 -->
<a id="25.2.16"></a>**25.2.16**

<!-- source-p 063 -->
**赫尔莫格尼安《法律提要》第二卷。**

<!-- source-p 064 -->
丈夫的财产归入国库时，妻子因取走财物只按单倍金额被诉，尽管其他人可能被判处四倍金额。

<!-- source-p 065 -->
<a id="25.2.17"></a>**25.2.17**

<!-- source-p 066 -->
**乌尔比安《告示评注》第三十卷。**

<!-- source-p 067 -->
<a id="25.2.17.pr."></a>**序言。**若妾取走财物，我们依盗窃规则处理，使其承担盗窃责任。因此可以说，凡婚姻不成立之处，例如与自己的监护人结婚、违反委任限制而缔结婚姻，或其他婚姻不成立的情形，移取财物之诉即不适用，因为此时可以提起盗窃之诉。

<!-- source-p 068 -->
<a id="25.2.17.1"></a>**1.**所谓为离婚而取走的物品，不仅包括妇女已经产生离婚意图后取走的物品，也包括她在婚姻存续期间取走、并在离开时加以隐藏的物品。

<!-- source-p 069 -->
<a id="25.2.17.2"></a>**2.**尤利安说，移取财物之诉不仅适用于仍然存在的物品，也适用于已经不复存在的物品；同样，也可以就确定物提起返还之诉。

<!-- source-p 070 -->
<a id="25.2.17.3"></a>**3.**妻子若取走了丈夫交付给她作为质物的物品，应承担本诉的责任：

<!-- source-p 071 -->
<a id="25.2.18"></a>**25.2.18**

<!-- source-p 072 -->
**保罗《问题集》第六卷。**

<!-- source-p 073 -->
物主也可以提起返还之诉；应允许双方中的一方提起诉讼。

<!-- source-p 074 -->
<a id="25.2.19"></a>**25.2.19**

<!-- source-p 075 -->
**乌尔比安《告示评注》第三十四卷。**

<!-- source-p 076 -->
如果妻子在离婚时将窃贼带入丈夫家中，并让他们取走物品，即使她本人没有接触这些物品，也应承担移取财物之诉的责任。因此，拉贝奥所写确属正确：即使物品没有到达妻子手中，妻子仍应对取走财物承担责任。

<!-- source-p 077 -->
<a id="25.2.20"></a>**25.2.20**

<!-- source-p 078 -->
**马尔凯卢斯《学说汇纂》第七卷。**

<!-- source-p 079 -->
如果妻子为离婚而取走了丈夫善意买入的物品，或帮助窃贼实施盗窃，将依移取财物之诉判令其承担责任。

<!-- source-p 080 -->
<a id="25.2.21"></a>**25.2.21**

<!-- source-p 081 -->
**保罗《告示评注》第三十七卷。**

<!-- source-p 082 -->
<a id="25.2.21.pr."></a>**序言。**如果妻子因认为丈夫性命垂危，秘密取走某些物品后与丈夫离婚，而丈夫后来康复，应向丈夫准许移取财物之诉。

<!-- source-p 083 -->
<a id="25.2.21.1"></a>**1.**若妻子的奴隶奉女主人之命，为离婚而取走物品，佩迪乌斯认为，奴隶既未实施盗窃，也没有帮助盗窃者，因为他并非为自己获利而接触这些物品；又因妻子并未实施盗窃，不能认为奴隶帮助了盗窃者。尽管奴隶不应在犯罪行为中听从主人的命令，仍应适用移取财物之诉。

<!-- source-p 084 -->
<a id="25.2.21.2"></a>**2.**但若作为嫁资给付的奴隶对丈夫实施盗窃，妻子若知道该奴隶有此行为倾向，就应向丈夫赔偿全部损失；若她并不知情，则不得在超过诺克萨责任判决范围内判令她受罚。

<!-- source-p 085 -->
<a id="25.2.21.3"></a>**3.**移取财物之诉立即赔偿损失，即使此后另有请求返还嫁资的诉权。

<!-- source-p 086 -->
<a id="25.2.21.4"></a>**4.**若丈夫因物品被取走而丧失任何利益，也应将该利益计入。

<!-- source-p 087 -->
<a id="25.2.21.5"></a>**5.**该诉虽因不法行为而发生，却包含对物的追索，因此不像盗窃物返还之诉那样受一年期间限制；此外，继承人也可以提起该诉。

<!-- source-p 088 -->
<a id="25.2.21.6"></a>**6.**在本诉中，丈夫或妻子若无法亲自实施诉讼行为，并不能因此获得有利地位；因为该诉以盗窃为基础。

<!-- source-p 089 -->
<a id="25.2.22"></a>**25.2.22**

<!-- source-p 090 -->
**尤利安《学说汇纂》第十九卷。**

<!-- source-p 091 -->
<a id="25.2.22.pr."></a>**序言。**若我就取走物品对妻子提起诉讼，且诉讼标的已经估价，那么她丧失占有后是否应获准提起诉讼？我对此有所疑虑，因为她是以恶意取得占有。答复如下：承担诉讼标的估价责任的人，应视为买受人。因此，若妻子因移取财物之诉而支付了估价款，对于主张权利的丈夫或其继承人，她享有抗辩；若她丧失占有，应向她准许对物之诉。

<!-- source-p 092 -->
<a id="25.2.22.1"></a>**1.**妻子若因丈夫将死而取走物品，之后丈夫死亡，其继承人可以通过遗产请求之诉或出示之诉取回被取走的物品。

<!-- source-p 093 -->
<a id="25.2.23"></a>**25.2.23**

<!-- source-p 094 -->
**阿非利卡努斯《问题集》第八卷。**

<!-- source-p 095 -->
若婚姻恢复后再次离婚，他认为，先前离婚时因取走物品而产生的诉权，以及因前次婚姻中的费用与赠与而产生的诉权，仍然存续。

<!-- source-p 096 -->
<a id="25.2.24"></a>**25.2.24**

<!-- source-p 097 -->
**乌尔比安《规则》第五卷。**

<!-- source-p 098 -->
对于被取走的丈夫自有物或嫁资物，丈夫均可对妻子提起返还原物之诉或返还之诉；丈夫可以选择其中任何一种诉讼。

<!-- source-p 099 -->
<a id="25.2.25"></a>**25.2.25**

<!-- source-p 100 -->
**马尔基安《规则》第三卷。**

<!-- source-p 101 -->
只有在物品系出于离婚意图而被取走，且其后确实发生离婚时，才适用移取财物之诉。但如果妻子在婚姻存续期间从丈夫处取走物品，虽然移取财物之诉不适用，丈夫仍可提起返还之诉；因为我认为，依万民法，可以对无合法原因占有物品的人提起返还之诉。

<!-- source-p 102 -->
<a id="25.2.26"></a>**25.2.26**

<!-- source-p 103 -->
**盖尤斯《行省告示评注》第四卷。**

<!-- source-p 104 -->
移取财物之诉属于返还之诉。

<!-- source-p 105 -->
<a id="25.2.27"></a>**25.2.27**

<!-- source-p 106 -->
**帕比尼安《答复集》第四卷。**

<!-- source-p 107 -->
即使妇女因通奸罪被起诉，对她提起移取财物之诉也不应因此延期。

<!-- source-p 108 -->
<a id="25.2.28"></a>**25.2.28**

<!-- source-p 109 -->
**保罗《问题集》第六卷。**

<!-- source-p 110 -->
如果妻子从丈夫借给他人的物品受领人处窃取该物，该受领人可以提起盗窃之诉，尽管丈夫本人无权提起。

<!-- source-p 111 -->
<a id="25.2.29"></a>**25.2.29**

<!-- source-p 112 -->
**特里丰尼努斯《论辩集》第十一卷。**

<!-- source-p 113 -->
被取走物品的估价应以其被取走时为准；因为该行为本质上属于盗窃，只是对妻子的制裁较轻。因此，即使善意占有人占有了被取走的物品，也不能据此取得时效；但若被取走的物品因价值上涨而未获返还，估价也随之增加，正如盗窃物返还之诉中的规则。

<!-- source-p 114 -->
<a id="25.2.30"></a>**25.2.30**

<!-- source-p 115 -->
**帕比尼安《问题集》第十一卷。**

<!-- source-p 116 -->
婚姻解除后若对妻子提起移取财物之诉，而婚姻此后恢复，该诉讼即告消灭。
