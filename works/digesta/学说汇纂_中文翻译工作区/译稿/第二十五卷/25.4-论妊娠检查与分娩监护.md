# D.25.4 论妊娠检查与分娩监护

<!-- source-p 001 -->
<a id="4"></a><a id="25.4"></a>**25.4.0. 论妊娠检查与分娩监护（*De inspiciendo ventre custodiendoque partu*）**

<!-- source-p 002 -->
<a id="25.4.1"></a>**25.4.1**

<!-- source-p 003 -->
**乌尔比安《告示评注》第二十四卷。**

<!-- source-p 004 -->
<a id="25.4.1.pr."></a>**序言。**神圣皇帝兄弟在位时，曾发生丈夫称妻子怀孕而妻子否认的情形。城市裁判官瓦莱里乌斯·普里斯基安努斯就此请示，皇帝复函如下：“鲁提利乌斯·塞维鲁似乎提出了一项新要求：他的妻子已经离开他，并声称自己并未怀孕，他却要求为她安排看护。因此，如果他坚持这一请求，任何人都不会惊讶；如果我们也提出一项新的考虑和救济办法，更不足为奇。于是，若他仍坚持原来的请求，最妥当的做法是选定一位品行最端正的妇女的住所，让多米提娅前往那里，并由你选任三位在医术和诚信方面均经认可的助产士为她检查。如果三人中全体或两人报告称她看来已经怀孕，就应劝说该妇女接受看护，仿佛这是她自己提出的请求。若她最终并未分娩，丈夫就应知道，这关系到他本人的声誉与评价，足以使人认为，他提出此要求可能是为了以某种方式伤害该妇女。反之，如果全体或多数人报告称她并未怀孕，就没有监护的理由。”

<!-- source-p 005 -->
<a id="25.4.1.1"></a>**1.**从这封复函可以十分清楚地看出：如果妇女隐瞒自己怀孕，甚至否认怀孕，关于承认子女的元老院决议便不适用。这并非没有道理，因为胎儿在出生以前，是妇女身体的一部分，属于她的腹中之物。孩子出生后，丈夫当然可以依法主张自己的权利，依禁令请求将儿子交付给自己，或者准许自己将其带走。因此，元首在这一必要案件中以特别程序提供救济。

<!-- source-p 006 -->
<a id="25.4.1.2"></a>**2.**依照该复函，可以将妇女传唤至裁判官面前，并在那里询问她是否认为自己怀孕；应当强制她作出答复。

<!-- source-p 007 -->
<a id="25.4.1.3"></a>**3.**那么，如果她不答复或不前往裁判官面前，该怎么办？难道要适用元老院决议的制裁，即允许丈夫不承认该子女吗？但设想丈夫并不满足于此，他宁愿确认自己是父亲，也不愿失去孩子。那么，就必须运用裁判官的救济手段，强制她到庭；若她到庭，则应强制其答复。若她仍藐视命令，可以扣押并变卖她的财物，或者以其他强制手段处罚她。

<!-- source-p 008 -->
<a id="25.4.1.4"></a>**4.**那么，如果受询问的妇女称自己怀孕，应如何处理？应依元老院决议所规定的程序进行。若她否认怀孕，裁判官就应依照这封复函安排助产士检查。

<!-- source-p 009 -->
<a id="25.4.1.5"></a>**5.**还应注意，不允许丈夫或妻子自行安排助产士；所有助产士均应由裁判官选任。

<!-- source-p 010 -->
<a id="25.4.1.6"></a>**6.**同样，裁判官应当选定一位品行端正的主妇之家，让妇女前往那里，以便接受检查。

<!-- source-p 011 -->
<a id="25.4.1.7"></a>**7.**那么，如果妇女不允许检查，或不前往该住所，该怎么办？此时同样应由裁判官行使权威介入。

<!-- source-p 012 -->
<a id="25.4.1.8"></a>**8.**如果全体或多数助产士报告称妇女并未怀孕，她能否据此提起人格侵害之诉？我更倾向于认为，她可以提起该诉，但前提是丈夫要求检查的目的在于侵害她。反之，若丈夫并无侵害之意，而是有正当理由相信她怀孕，或因强烈的求子愿望而提出要求，或是妻子在婚姻存续期间假装怀孕、诱使他相信此事，那么，最合乎公平的做法就是宽恕丈夫。

<!-- source-p 013 -->
<a id="25.4.1.9"></a>**9.**还应记住，该复函没有规定期间，尽管关于承认子女的元老院决议为妇女规定了三十日期限。那么，我们是否要说，丈夫可以随时将妻子传唤至裁判官面前，还是也应为丈夫设定三十日期限？我认为，裁判官应查明案情，并在三十日之后仍受理丈夫的请求。

<!-- source-p 014 -->
<a id="25.4.1.10"></a>**10.**关于检查妊娠并监护分娩，裁判官如此规定：

> “若妇女在丈夫死亡后声称自己怀孕，她应安排每月两次通知对该事项有利害关系的人或其代理人，使他们能够在愿意时派人检查孕腹。检查人员仅限五名自由妇女；她们应同时共同检查，但检查时任何人均不得违背妇女意愿触摸其腹部。妇女应在我指定的一位最为贤淑的主妇家中分娩。妇女应在预计分娩日三十日前通知对该事项有利害关系的人或其代理人，使他们能够在愿意时派人监护孕腹。妇女分娩所在的房间不得有两个以上入口；若有多个入口，应从两侧用木板封闭。该房间门外应由三名自由男子和三名自由女子看守，各自另有两名随从。每当该妇女前往另一房间或浴室时，看守人如愿意，可以事先检查该处，并搜查进入者。设置在房间门前的看守人，如愿意，可以搜查所有进入该房间或住宅的人。妇女开始临产时，应通知对该事项有利害关系的人或其代理人，使他们能够派人在场见证分娩。派来的人仅限五名自由妇女；除两名助产士外，该房间内的自由妇女不得超过十人，女奴不得超过六人。所有将在室内的人均应接受搜查，以免其中有怀孕者。室内至少应点燃三盏灯，因为黑暗更便于调换婴儿。新生儿如对该事项有利害关系的人或其代理人愿意检查，应向他们展示。孩子应由父母指定的人抚养。若父母未作指定，或者其指定的抚养人不愿承担照料责任，我将在查明案情后指定抚养人。抚养孩子的人应按下列时间和地点向人展示孩子：孩子未满三个月时，每月两次；自三个月至六个月时，每月一次；自六个月至一岁时，每两个月一次；自一岁起至孩子能够说话时，每六个月一次；展示地点由其选择。若有人不允许检查孕腹、监护分娩，或实施任何妨碍上述措施的行为，我将在查明案情后不向其授予占有；若新生儿未能依上述规定接受检查，我所承诺向依我的告示获准占有遗产的人提供的诉权，如我认为存在正当理由，也将不予其享有。”

<!-- source-p 015 -->
<a id="25.4.1.11"></a>**11.**虽然裁判官的告示极为明晰，对其作出的解释仍不应忽视。

<!-- source-p 016 -->
<a id="25.4.1.12"></a>**12.**因此，妇女应通知那些有利害关系的人，即希望孩子不出生的人；他们可能依无遗嘱继承取得全部遗产或其中一部分，也可能依遗嘱取得全部遗产或其中一部分。

<!-- source-p 017 -->
<a id="25.4.1.13"></a>**13.**即使在没有孩子出生时，奴隶被指定为继承人，阿里斯托也写道，裁判官仍应依其裁量，允许该奴隶就监护分娩获得某些措施，尽管并非全部措施。我认为这一见解正确：防止调换婴儿关乎公共利益，旨在维护等级与家族的尊严。因此，该奴隶既然有望继承遗产，无论其身份如何，都应得到听取；他是在处理公共事务，也是在处理自己的事务。

<!-- source-p 018 -->
<a id="25.4.1.14"></a>**14.**应当通知最有可能继承遗产的人，例如被指定为第一顺位继承人的人，但不包括替补继承人；如果家父在无遗嘱的情况下死亡，则应通知依法无遗嘱继承的第一顺位继承人。若有数人将共同继承，则应通知所有人。

<!-- source-p 019 -->
<a id="25.4.1.15"></a>**15.**裁判官所说的“查明案情后不授予占有”或“不授予诉权”，其意在于：如果因不熟悉规则而遗漏了裁判官要求遵守的某些事项，不应因此损害孩子的利益。若因未遵守裁判官告示中某些较为轻微的程序要求，就拒绝给予孩子遗产占有，岂非不当？应当考察当地习俗，并依当地习俗检查孕腹、监护分娩及照料婴儿。

<!-- source-p 022 -->
<a id="25.4.2.pr."></a>**序言。**关于监护分娩的告示，排除了依卡尔博尼安裁定范例拟定的程序。

<!-- source-p 023 -->
<a id="25.4.2.1"></a>**1.**但若未能检查孕腹或监护分娩并非出于妇女的恶意，而是由于其不熟悉规则，裁判官有时应当免除这些要求。

<a id="25.4.4"></a>**25.4.4**

<!-- source-p 028 -->
**斯凯沃拉《学说汇纂》第二十卷。**

<!-- source-p 029 -->
某人曾以遗嘱信托的方式，将自己无子女死亡时从其财产中取得的一切留给其姐妹；此人后来死亡，遗腹女被指定为继承人，并另有替补继承人。有人问：死者的妻子声称自己怀孕时，是否应依告示的规定，允许该姐妹或其代理人检查孕腹并监护分娩？我答复说，在所询问的这种情形中，可以认为有必要为遗嘱信托受益人的利益而进行检查；应当查明案情后作出决定。
