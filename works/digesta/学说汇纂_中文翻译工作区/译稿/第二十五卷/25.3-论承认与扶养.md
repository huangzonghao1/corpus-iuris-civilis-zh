# D.25.3 论子女的认领以及对子女、父母、释奴保护人或被释奴的扶养（*De agnoscendis et alendis liberis vel parentibus vel patronis vel libertis*）

<!-- source-p 001; 原文导航锚点 3、题名锚点 25.3 -->
<a id="3"></a><a id="25.3"></a>**25.3.0　论子女的认领以及对子女、父母、释奴保护人或被释奴的扶养（*De agnoscendis et alendis liberis vel parentibus vel patronis vel libertis*）**

<!-- source-p 002 -->
<a id="25.3.1"></a>**25.3.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第三十四卷。**

<!-- source-p 004 -->
<a id="25.3.1.pr."></a>**序言。**关于认领子女的元老院决议，包含两类规定：一类涉及承认子女的男子，另一类涉及以他人所生子女冒充自己所生子女的妇女。

<!-- source-p 005 -->
<a id="25.3.1.1"></a>**1.**因此，如果妇女自认为已经怀孕，她本人、对她行使家父权的尊亲属，或受上述任一方委托的人，可以在离婚后三十日内通知丈夫本人或对丈夫行使家父权的尊亲属；若无法找到这些人，也可以向其住处发出通知。

<!-- source-p 006 -->
<a id="25.3.1.2"></a>**2.**“住处”应理解为丈夫的住所：若丈夫住在城市，就是其城里的居所；若不住在城市，而住在别墅或自治市镇，则应通知到他们在婚姻中安置家宅神位之处。

<!-- source-p 007 -->
<a id="25.3.1.3"></a>**3.**妇女发出通知，仅须说明自己怀有该男子的胎儿。因此，她发出通知并不是为了要求丈夫派人看守孕腹；妇女只要告知自己已怀孕即可。此后，丈夫可以派人看守，也可以通知她说胎儿并非由他所孕育；此事既可由丈夫本人办理，也可由他人代表丈夫办理。

<!-- source-p 008 -->
<a id="25.3.1.4"></a>**4.**对丈夫的制裁是：如果他既未预先派人看守，也未反向通知说胎儿并非由他所孕育，就应被迫认领出生的子女；若仍不认领，则以特别程序予以制裁。因此，他应答复说胎儿并非由他所孕育，或者由他人代表他作出答复。若已如此答复，除非该子女确为其子，否则他便不再必须认领。

<!-- source-p 009 -->
<a id="25.3.1.5"></a>**5.**应当注意，通知程序并非由丈夫启动，而是由妇女启动。

<!-- source-p 010 -->
<a id="25.3.1.6"></a>**6.**但是，如果丈夫主动提出派人看守，而妇女不接受；或者妇女没有发出通知；又或者她虽已发出通知，却不接受由法官裁量指定的看守人，则丈夫或其尊亲属可以不认领出生的子女。

<!-- source-p 011 -->
<a id="25.3.1.7"></a>**7.**如果妇女未在三十日内通知自己已怀孕，之后才发出通知的，法官应在查明案情后听取其主张。

<!-- source-p 012 -->
<a id="25.3.1.8"></a>**8.**不仅如此，即使妇女完全没有发出通知，尤利安也说，这不会损害出生子女的利益。

<!-- source-p 013 -->
<a id="25.3.1.9"></a>**9.**这里的三十日应自离婚之日起连续计算，而非以可用日（*dies utiles*）计算。

<!-- source-p 014 -->
<a id="25.3.1.10"></a>**10.**尤利安在《学说汇纂》第十九卷中恰当地提出：如果妇女未在三十日内通知丈夫，却在这三十日内已经生产，是否适用普兰奇亚努斯元老院决议？他的意见是该决议不适用，因为该决议似乎并未涉及在第三十日届满之前出生的子女；毕竟，元老院设定的通知期限就是三十日。不过，我认为此事不应对该子女的身份产生先决效力。

<!-- source-p 015 -->
<a id="25.3.1.11"></a>**11.**反过来说，如果丈夫在妻子通知后派人看守，这也不会对他产生先决效力。因此，他仍可否认出生的子女是自己的；他曾看守孕腹一事，也不会对他不利。马尔切卢斯在《学说汇纂》第七卷中也如此写道：无论某人否认该女子是自己的妻子，还是否认她怀有自己的孩子，他均可在不产生先决效力的情况下派人看守；尤其是他能声明自己此次派人看守并不表示承认亲子关系时。

<!-- source-p 016 -->
<a id="25.3.1.12"></a>**12.**尤利安在《学说汇纂》第十九卷中写道：元老院决议规定，如果妇女通知丈夫自己怀了他的孩子，而受通知者既未派人看守并检查孕腹，也未正式声明胎儿并非由他所孕育，则必须认领出生的子女。这一规定并不意味着，若某人表示认领孩子，即使孩子是由他人所孕育，也会因此成为他的继承人；正如尤利安所说，一旦诉讼开始，父亲的承认就会给有利于子女的主张带来重大先决影响。

<!-- source-p 017 -->
<a id="25.3.1.13"></a>**13.**尤利安反过来也说，如果妇女离婚后未履行元老院决议所要求的程序，使父亲得以不认领子女，这并不意味着出生的子女不能主张自己是父亲之子；它仅意味着，只有在确定该子女确为其子后，父亲才被迫扶养他。

<!-- source-p 018 -->
<a id="25.3.1.14"></a>**14.**尤利安还写道，如果妻子通知丈夫自己已经怀孕，而丈夫没有否认，该子女并不会因此当然成为他的子女；但丈夫仍被迫扶养子女。否则，如果某人长期离家，回来时发现妻子已怀孕，便因此拒绝承认亲子关系，而他又遗漏了元老院决议所规定的某项程序，那么这就相当不公：一个并非其子的人竟会成为他的继承人。

<!-- source-p 019 -->
<a id="25.3.1.15"></a>**15.**由此可见，只要出生的孩子确为其子，妻子未遵守元老院决议所规定的程序，并不会对孩子产生先决影响；依神圣庇护皇帝的敕答，无论在其自权继承人权利方面，还是在扶养方面，都不受影响。反之，如果丈夫未履行元老院决议要求他履行的事项，就必须无论如何扶养出生的子女，但仍可否认其为自己的孩子。

<!-- source-p 020 -->
<a id="25.3.1.16"></a>**16.**当然，如果妇女发出通知后，丈夫否认胎儿是自己的，即使他没有派人看守，也不能避免法院查明妇女是否怀有他的孩子。若此案已在法官面前审理，且法官就妇女是否怀有其子作出认定，判定该子女应由其认领，那么无论该子女实际上是否为他的孩子，法律上都视为其子。

<!-- source-p 022 -->
**尤利安：《学说汇纂》第十九卷。**

<!-- source-p 023 -->
在所有相关事项中（因此，他也将成为其兄弟的同父兄弟）：

<!-- source-p 024 -->
<a id="25.3.3"></a>**25.3.3**

<!-- source-p 025 -->
**乌尔比安：《告示评注》第三十四卷。**

<!-- source-p 026 -->
<a id="25.3.3.pr."></a>**序言。**如果法官反向判定该子女并非其子，即使实际上确为其子，结论亦然；因为原则上，法官对此事项所作的判断具有确定法律关系的效力。马尔切卢斯在《学说汇纂》第七卷中也赞同此说，我们现行法亦如此。

<!-- source-p 027 -->
<a id="25.3.3.1"></a>**1.**普兰奇亚努斯元老院决议仅适用于离婚后出生的子女；因此，在神圣哈德良统治时期又作出另一项元老院决议，规定即使子女是在婚姻存续期间出生，也可以就是否认领该子女进行诉讼。

<!-- source-p 028 -->
<a id="25.3.3.2"></a>**2.**那么，如果某人在父亲死亡后出生，而祖父仍然在世，且若能证明该子女由祖父之子所生，便会重新归入祖父的权力之下，应当如何处理？对此应审慎判断。可以肯定的是，应当同样允许针对祖父提起关于认领子女的先决程序。

<!-- source-p 029 -->
<a id="25.3.3.3"></a>**3.**如果争议本身就在于子女是在婚姻存续期间还是在婚姻之后出生，也应依据元老院决议就此提起诉讼。

<!-- source-p 030 -->
<a id="25.3.3.4"></a>**4.**如果争议在于双方是否曾为夫妻，又该如何处理？尤利安答复塞克斯图斯·凯基利乌斯·阿非利加努斯说，可以提起先决程序。

<!-- source-p 031 -->
<a id="25.3.3.5"></a>**5.**应当记住，如果父母一方死亡后，尚有一名子女不会重新归入其权力之下的人在世，这些元老院决议便不再适用。那么应如何处理？在子女提起的遗产请求诉讼中，应查明他是否由其所请求继承之人的遗产所有人所生。此点十分明确：尤利安在《学说汇纂》第十九卷中写道，如果父亲在世时已经作出先决裁判，而父亲在判决作出前死亡，就应转而适用卡尔博尼亚告示。

<!-- source-p 032 -->
<a id="25.3.3.6"></a>**6.**此外，这些元老院决议适用于将成为自权继承人的子女；若其并不会重新归入某人的权力之下，更妥当的意见是这些决议不再适用。

<!-- source-p 033 -->
<a id="25.3.4"></a>**25.3.4**

<!-- source-p 034 -->
**保罗：《法律意见集》第二卷。**

<!-- source-p 035 -->
不仅使胎儿窒息的人被视为杀人，遗弃子女、拒绝提供扶养，或以怜悯为名将子女遗弃在公共场所、而其本人并无怜悯之心的人，也被视为杀人。

<!-- source-p 036 -->
<a id="25.3.5"></a>**25.3.5**

<!-- source-p 037 -->
**乌尔比安：《论执政官职务》第二卷。**

<!-- source-p 038 -->
<a id="25.3.5.pr."></a>**序言。**如果有人要求子女扶养自己，或者子女要求父母扶养自己，法官应审理此事。

<!-- source-p 039 -->
<a id="25.3.5.1"></a>**1.**应考察某人是否仅须扶养处于自己权力之下的子女，还是也须扶养已经解放或因其他原因成为自权人的子女。我更倾向于认为，即使子女不处于父母权力之下，父母仍应扶养他们；反过来，子女也应扶养父母。

<!-- source-p 040 -->
<a id="25.3.5.2"></a>**2.**还应考察，我们是否仅须扶养父亲、祖父、曾祖父及其他男性尊亲属，还是也须扶养母亲及其他尊亲属，包括通过女性一系相联系的亲属。我更倾向于认为，法官在两方面都应介入，以便较容易救助某些人的急困，或缓解另一些人的疾病。既然此事源于衡平和血亲之爱，法官就应逐一权衡各人的请求。

<!-- source-p 041 -->
<a id="25.3.5.3"></a>**3.**父母扶养子女时，也应作同样的判断。

<!-- source-p 042 -->
<a id="25.3.5.4"></a>**4.**因此，我们也会命令母亲扶养子女，尤其是非婚生子女；子女也同样应扶养母亲。

<!-- source-p 043 -->
<a id="25.3.5.5"></a>**5.**此外，神圣庇乌斯似乎还表明，外祖父也可能被命令扶养子女。

<!-- source-p 044 -->
<a id="25.3.5.6"></a>**6.**神圣庇护皇帝还作出敕答：如果经法院确认女儿系合法所生，父亲就应扶养自己的女儿。

<!-- source-p 045 -->
<a id="25.3.5.7"></a>**7.**如果儿子能够自行维持生活，法官应予考量，以免不应判给扶养却仍作出扶养裁定。事实上，神圣庇乌斯曾作如下敕答：“你向有管辖权的法官提出申请后，法官会命令你父亲按其财力扶养你；但前提是，尽管你说自己是工匠，你的健康状况确实使你无法胜任工作。”

<!-- source-p 046 -->
<a id="25.3.5.8"></a>**8.**如果父母否认某人为其子女，并据此主张自己无须扶养；或者子女否认某人为其父母，法官应对此作简要调查。如果确认双方确有父母子女关系，就应命令提供扶养；如果未能确认，就不应裁定扶养。

<!-- source-p 047 -->
<a id="25.3.5.9"></a>**9.**应当记住，即使法官判令应予扶养，该裁定也不对亲子关系的真实与否产生先决效力；法院裁定的不是此人就是其子，而只是其应当予以扶养。神圣马尔库斯也曾如此作出敕答。

<!-- source-p 048 -->
<a id="25.3.5.10"></a>**10.**如果上述任何一方拒绝提供扶养，法官应按照其财力确定扶养数额；若仍不履行，就应扣押并变卖其财产，迫使其履行裁判。

<!-- source-p 049 -->
<a id="25.3.5.11"></a>**11.**法官还应判断父母是否拥有财产，或者父亲是否有正当理由不愿扶养子女。特雷巴提乌斯·马里努斯曾收到一项敕答：父亲有理由不愿扶养该子，因为该子曾告发父亲。

<!-- source-p 050 -->
<a id="25.3.5.12"></a>**12.**敕答还规定，法官可以命令父亲提供的不仅是扶养，还包括子女所需的其他一切负担。

<!-- source-p 051 -->
<a id="25.3.5.13"></a>**13.**如果已解放的儿子尚未成年，也会被命令扶养贫困的父亲；毕竟，当儿子拥有财产时，若父亲仍陷于贫困，任何人都会认为这极不公平。

<!-- source-p 052 -->
<a id="25.3.5.14"></a>**14.**如果母亲请求父亲偿还她为儿子所支出的扶养费用，法院只应在一定限度内受理。神圣马尔库斯就此向安东尼娅·蒙塔娜作出如下敕答：“法官也会评定，你为必要扶养女儿而支出的费用中，应由其父亲向你偿还多少；你不应请求取得那些费用——即使女儿由其父亲抚养，你出于母爱仍会为她支出的部分。”

<!-- source-p 053 -->
<a id="25.3.5.15"></a>**15.**即使儿子是军人，只要他拥有财产，基于孝道，他也应扶养父母。

<!-- source-p 054 -->
<a id="25.3.5.16"></a>**16.**敕答指出，父母虽然依自然法应由子女扶养，但子女不应被迫偿还父母的债务。

<!-- source-p 055 -->
<a id="25.3.5.17"></a>**17.**另有敕答指出，子女在世时基于孝道所提供的扶养，其继承人不得被迫继续提供；但如果父亲已陷入极度贫困，则不在此限。

<!-- source-p 056 -->
<a id="25.3.5.18"></a>**18.**如果就扶养问题在释奴保护人与被释奴之间发生诉讼，法官通常也会审理。因此，如果一方否认自己是被释奴，法官应予调查；若查明其确为被释奴，才裁定其应提供扶养。但扶养裁定并不剥夺被释奴通过先决程序争讼的权利，即使他否认自己是被释奴。

<!-- source-p 057 -->
<a id="25.3.5.19"></a>**19.**扶养应按被释奴的财力提供，当然前提是释奴保护人确实贫困；若其有足够财产维持生活，法官便不再介入。

<!-- source-p 058 -->
<a id="25.3.5.20"></a>**20.**是否只应扶养释奴保护人，还是也应扶养释奴保护人的子女，尚可讨论。我认为，法官查明案情后，也可以裁定扶养保护人的子女；虽然不应像扶养保护人本人那样轻易作出此项裁定，但有时也应如此，因为不仅对保护人，而且对其子女也负有敬顺义务。

<!-- source-p 059 -->
<a id="25.3.5.21"></a>**21.**母亲的被释奴也可能被命令承担扶养义务。

<!-- source-p 060 -->
<a id="25.3.5.22"></a>**22.**如果有人请求由被释奴的被释奴扶养，或由该被释奴依遗产信托事由予以解放、并以自有钱款赎回的人扶养，不应受理；马尔切卢斯也如此写道。他将这种情形与因索取报酬而丧失释奴保护人法上权利的人等同处理。

<!-- source-p 061 -->
<a id="25.3.5.23"></a>**23.**此外，若释奴保护人的儿子曾以死罪指控其父亲的被释奴，据说该被释奴也无须扶养此子。

<!-- source-p 062 -->
<a id="25.3.5.24"></a>**24.**女被释奴也应扶养其释奴保护人。

<!-- source-p 063 -->
<a id="25.3.5.25"></a>**25.**对于释奴保护人的扶养，通常会指定一名仲裁人，评定其财产状况，以便相应确定扶养数额；扶养应持续提供，直至被释奴仍有余力而保护人已无力维持生活为止。

<!-- source-p 064 -->
<a id="25.3.5.26"></a>**26.**如果释奴保护人及其子女均已不在人世，其父母生活贫困，而被释奴本人有相应财力，则被释奴也会被命令扶养保护人的父母。

<!-- source-p 065 -->
<a id="25.3.6"></a>**25.3.6**

<!-- source-p 066 -->
**莫德斯汀：《论释奴》单卷本。**

<!-- source-p 067 -->
<a id="25.3.6.pr."></a>**序言。**如果释奴请求扶养而释奴保护人拒不提供，保护人将受到处罚，丧失因授予自由而附加的权利以及对该被释奴遗产的权利；但即使保护人有能力，也并非必须提供扶养。

<!-- source-p 068 -->
<a id="25.3.6.1"></a>**1.**现引述康茂德皇帝的一项敕令：“如果查明被释奴以侮辱方式冒犯释奴保护人，或以暴力殴打保护人，或者在保护人陷入贫困或身体患病时弃之不顾，首先应将这些被释奴重新置于保护人的权力之下，并强令其为主人提供劳务；如果即使如此仍未能使其悔改，行省总督就可以将其判归买受人所有，并把价款交给保护人。”

<!-- source-p 069 -->
<a id="25.3.7"></a>**25.3.7**

<!-- source-p 070 -->
**莫德斯汀：《答复集》第五卷。**

<!-- source-p 071 -->
如果被称为丈夫的人否认双方曾缔结婚姻，并准备证明自称曾为其妻的女子其实是奴隶，我的答复是：在此期间，应当强令其扶养子女；但如果后来查明该女子确为奴隶，这一扶养事实不应对曾经照料子女的人产生先决效力。

<a id="25.3.8"></a>**25.3.8**

<!-- source-p 073 -->
**马尔切卢斯：《尤利亚—帕皮亚法评注》第一卷。**

<!-- source-p 074 -->
我们的男性子女所生的子女会成为我们的负担；女性子女所生的子女则并非如此。显然，女儿所生的子女应由其父亲，而非外祖父承担扶养负担；但如果其父亲不在人世或陷于贫困，则另当别论。

<!-- source-p 075 -->
<a id="25.3.9"></a>**25.3.9**

<!-- source-p 076 -->
**保罗：《论释奴保护人法》单卷本。**

<!-- source-p 077 -->
对于尚在人世的被释奴之财产，释奴保护人及其子女原则上全无权利；只有在向行省总督证明自己体弱且贫困到确有理由每月接受被释奴扶养的程度时，才属例外。多位皇帝的敕令都确立了这一规则。
