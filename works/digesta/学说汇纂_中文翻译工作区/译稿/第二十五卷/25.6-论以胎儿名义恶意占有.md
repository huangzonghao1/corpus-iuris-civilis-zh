# D.25.6 论妇女被指以胎儿名义恶意取得遗产占有（*Si mulier ventris nomine in possessione calumniae causa esse dicetur*）

<!-- source-p 001; 原文导航锚点 6、题名锚点 25.6 -->
<a id="6"></a><a id="25.6"></a>**25.6.0　论妇女被指以胎儿名义恶意取得遗产占有（*Si mulier ventris nomine in possessione calumniae causa esse dicetur*）**

<!-- source-p 002 -->
<a id="25.6.1"></a>**25.6.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第三十四卷。**

<!-- source-p 004 -->
<a id="25.6.1.pr."></a>**序言。**如果争议涉及妇女以胎儿名义取得遗产占有，而她应继承人的要求宣誓自己确已怀孕，就应遵守该誓言；不得以她是恶意取得占有为由追究其责任，也不得在她宣誓后对她施加强制。但如果她后来分娩，仍应查明她是否确实怀有被继承人的孩子。毕竟，发生在他人之间的宣誓既不使第三人受益，也不使第三人受损；因此，该宣誓也不会损害出生的子女。

<!-- source-p 005 -->
<a id="25.6.1.1"></a>**1.**本告示也出于与前述告示相同的理由：裁判官既然在授予妇女胎儿名义的遗产占有时应当宽容，也不应放任她的恶意行为而不予惩处。

<!-- source-p 006 -->
<a id="25.6.1.2"></a>**2.**明知自己并未怀孕，却仍有意取得遗产占有的妇女，应视为恶意占有人。

<!-- source-p 007 -->
<a id="25.6.1.3"></a>**3.**裁判官承诺在一年可用期间内授予此诉，超过该期间则不再授予；显然，这是因为该诉具有惩罚性质。

<!-- source-p 008 -->
<a id="25.6.1.4"></a>**4.**同样，在此情形下，裁判官也承诺授予以原告利益数额为限的诉权。

<!-- source-p 009 -->
<a id="25.6.1.5"></a>**5.**如果妇女之所以恶意取得遗产占有，是由于其尊亲属所为，裁判官也承诺对该尊亲属授予诉权。

<!-- source-p 010 -->
<a id="25.6.1.6"></a>**6.**此诉授予任何因妇女未取得遗产占有而具有利益的人。例如，期待胎儿出生的共同继承人、遗嘱指定的替补继承人，或者如果没有胎儿出生便可依无遗嘱继承的人，均可提起此诉。

<!-- source-p 011 -->
<a id="25.6.1.7"></a>**7.**首先，利害关系似乎包括为胎儿所支出的扶养费用；除非妇女是恶意取得遗产占有，否则这些费用不得请求返还。反之，如果并无恶意，妇女即使以胎儿为由而无根据地获得扶养，也无须偿付任何费用。

<!-- source-p 012 -->
<a id="25.6.1.8"></a>**8.**在某些情况下，利害关系的数额还会增加。例如，某人因不确定妇女是否怀孕而被排除在继承之外，尤利安说，此诉也应授予该被排除者的继承人；因为妇女若非恶意取得占有，该被排除者本身也有利益。若没有这种情形，他本可接受继承，从而为自己的继承人留下更丰厚的遗产。此外，遗产中的许多财物因而减少，也应计入妇女的责任；这是因为该人考虑到胎儿而没有接受继承。

<!-- source-p 013 -->
<a id="25.6.1.9"></a>**9.**尤利安在《学说汇纂》第十九卷中还如此写道：如果替补继承人在妇女仍占有遗产时死亡，其继承人可以基于同一诉权向妇女请求遗产价额。

<!-- source-p 014 -->
<a id="25.6.1.10"></a>**10.**至于遗赠以及遗产的其他负担是否因此消灭，尚须考察。我认为，遗赠受领人可以对妇女提起此诉，因为他们也有利益使遗产得到接受。

<!-- source-p 015 -->
<a id="25.6.1.11"></a>**11.**对于因继承遗产而提起此诉的人，应当救济遗嘱中被信托解放的奴隶；具体而言，应强令取得遗产价额的人履行信托解放，因为他毕竟也取得了这些奴隶的价款。我还认为，裁判官也应救济遗嘱直接解放的奴隶，并通过其介入保障他们的自由。

<!-- source-p 016 -->
<a id="25.6.1.12"></a>**12.**如果处于家父权下的女儿实施了欺诈，而其父亲也是欺诈的参与者，父亲就应以自己的名义承担责任。
