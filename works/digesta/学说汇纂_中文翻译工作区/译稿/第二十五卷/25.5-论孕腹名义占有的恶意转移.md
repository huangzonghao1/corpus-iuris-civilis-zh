# <a id="5"></a><a id="25.5"></a>25.5.0 论以腹中胎儿名义准许女子占有后，该占有被称为因恶意转移给他人的情形

<!-- 源段落 283 -->
### <a id="25.5.1"></a>25.5.1

<!-- 源段落 284 -->
乌尔比安《评告示》第三十四卷

<!-- 源段落 285 -->
<a id="25.5.1.pr."></a>

**序言（pr.）** 裁判官在这项告示中作了极为妥当的规定，以免他在为胎儿利益允诺占有时，反而给他人提供掠夺财物的机会：

<!-- 源段落 286 -->
<a id="25.5.1.1"></a>

**1.** 因此，他设立诉权，针对以恶意将该占有转移给他人的女子提起诉讼。裁判官所制裁的不仅是该女子，也包括处于其家父权之下的人；也就是说，若因他们的恶意而使他人得以进入占有，裁判官便允诺针对他们提起诉讼，金额以原告的利益为限。

<!-- 源段落 287 -->
<a id="25.5.1.2"></a>

**2.** 裁判官还作出必要补充：通过欺诈进入占有的人必须被迫退出占有。但他不会运用裁判官权力或借助执行人员的强制力迫使此人退出；更妥当且更文明的做法，是通过禁令将其交由普通司法程序处理。

<!-- 源段落 288 -->
<a id="25.5.1.3"></a>

**3.** 原告的利益在于，不应准许他人进入占有。例如，获准进入占有的人或许已善意取得并消耗孳息；又或者进入占有的是恶意掠夺者，而原告无法向其追取孳息，因为该人无清偿能力。

<!-- 源段落 289 -->
<a id="25.5.1.4"></a>

**4.** 即使一年期限已经届满，也可以提起此项诉讼，因为它属于追索物的诉讼。

<!-- 源段落 290 -->
<a id="25.5.1.5"></a>

**5.** 若实施欺诈的是处于父权之下的女儿，只要有任何利益归于其父亲，就可以对父亲提起诉讼。

<!-- 源段落 291 -->
### <a id="25.5.2"></a>25.5.2

<!-- 源段落 292 -->
保罗《评告示》第三十七卷

<!-- 源段落 293 -->
<a id="25.5.2.pr."></a>

**序言（pr.）** 妇女实施欺诈，并非指她没有阻止他人进入占有；而是指她为了欺骗某人，暗中以某种诡计使他人进入占有。

<!-- 源段落 294 -->
<a id="25.5.2.1"></a>

**1.** 若指控父亲和女儿都实施了该行为，原告可以选择向其中任何一人提起诉讼。由于诉讼金额以原告的利益为限，若处于家父权之下的人能够弥补原告所受损失，那么除诉讼费用外，原告提起此项诉讼便无实际必要。
