# D.25.1 论对嫁资物所作费用（*De impensis in res dotales factis*）

<!-- source-p 001; 原文导航锚点 1、题名锚点 25.1 -->
<a id="1"></a><a id="25.1"></a>**25.1.0　论对嫁资物所作费用（*De impensis in res dotales factis*）**

<!-- source-p 002 -->
<a id="25.1.1"></a>**25.1.1**

<!-- source-p 003 -->
**乌尔比安：《评萨宾》第三十六卷。**

<!-- source-p 004 -->
<a id="25.1.1.pr."></a>**序言。**费用有若干种：必要费用、有益费用，以及享乐性费用。

<!-- source-p 005 -->
<a id="25.1.1.1"></a>**1.**所谓必要费用，是指其本身具有支出必要性的费用；反之，若并无必要，则应依其他规则处理。

<!-- source-p 006 -->
<a id="25.1.1.2"></a>**2.**关于必要费用，应知只有对嫁资本身所作的费用，才会减少嫁资；若费用并非用于嫁资本身，则不得将其计入嫁资扣减。

<!-- source-p 007 -->
<a id="25.1.1.3"></a>**3.**拉贝奥说，修筑伸入海中或河中的堤坝，也属于必要费用。他还说，若为必要而建造磨坊或谷仓，也应列为必要费用。因此，富尔奇尼乌斯说：如果丈夫修复了正在坍塌、且对妻子有用的建筑物，或者修复了荒废的橄榄园，或者依防止损害发生的要式口约承担责任，以免该口约因损害发生而被触发，

<!-- source-p 008 -->
<a id="25.1.2"></a>**25.1.2**

<!-- source-p 009 -->
**保罗：《评萨宾》第七卷。**

<!-- source-p 010 -->
或为奴隶的健康支出了费用，

<!-- source-p 011 -->
<a id="25.1.3"></a>**25.1.3**

<!-- source-p 012 -->
**乌尔比安：《评萨宾》第三十六卷。**

<!-- source-p 013 -->
<a id="25.1.3.pr."></a>**序言。**又如，丈夫若培植葡萄藤、照料树木，或为农地的收益而设置苗圃，也应视为支出了必要费用。

<!-- source-p 014 -->
<a id="25.1.3.1"></a>**1.**我们将作一般性区分：费用究竟是为了农地的永久利益，或至少为了并非仅限于当年利益的用途而支出，还是仅为了当年的收成而支出。如果只是为了当年收成，就应与当年收获相抵；如果该项支出并非仅适用于当年，则应计入必要费用。

<!-- source-p 015 -->
<a id="25.1.4"></a>**25.1.4**

<!-- source-p 016 -->
**保罗：《告示评注》第三十六卷。**

<!-- source-p 017 -->
总的来说，必要费用似乎包括这样一类支出：如果丈夫未作该项支出，法官就会按妻子因该支出本应获得的利益判令丈夫承担责任。但两种情形有所不同：已经支出的费用，即使事务处理不当，仍予以计算；未支出的费用，则只有因未支出而导致事务处理不当时，才予以计算。因此，若丈夫支撑了正在坍塌的公寓楼而该楼后来被焚毁，他仍可请求扣除其支出的费用；若他没有支撑，而楼房被焚毁，则不负任何给付责任。

<!-- source-p 018 -->
<a id="25.1.5"></a>**25.1.5**

<!-- source-p 019 -->
**乌尔比安：《评萨宾》第三十六卷。**

<!-- source-p 020 -->
<a id="25.1.5.pr."></a>**序言。**所谓必要费用减少嫁资，应依庞波尼乌斯所说作如下理解：并非嫁资中的有体物本身因此在物理上减少，例如农庄或其他任何有体物；毕竟，因金钱支出而使有体物本身减少，是荒谬的。相反，该支出将使整座嫁资农庄或其中一部分不再属于嫁资〔底本作 *faciet*，并列方括号异文为 *efficiet*〕。因此，在费用获得补偿之前，丈夫仍可留置有关物品；减少的并非有体物本身，而是嫁资。何种情形下承认嫁资依法当然减少？是在标的不是有体物而是金钱时，因为金钱可以依法发生减少。因此，若以经估价的有体物作为嫁资给付，必要费用便依法当然减少嫁资。以上说的是对嫁资本身所作的费用；若费用来自嫁资以外，则不减少嫁资。

<!-- source-p 021 -->
<a id="25.1.5.1"></a>**1.**如果妻子已经偿付必要费用，嫁资是增加了，还是应说嫁资恢复原状？我认为，嫁资为金钱时，毫无疑问应视为嫁资已经增加。

<!-- source-p 022 -->
<a id="25.1.5.2"></a>**2.**如果全部嫁资已经返还而未计入费用，应考察是否可以提起返还之诉，请求通常以必要费用抵扣的数额。马尔切鲁斯承认可以提起返还之诉；即使多数人否认，也应基于衡平接受马尔切鲁斯的意见。

<!-- source-p 023 -->
<a id="25.1.5.3"></a>**3.**有益费用，是丈夫以有益方式支出、并使妻子的财产——也就是嫁资——得到改善的费用，

<!-- source-p 024 -->
<a id="25.1.6"></a>**25.1.6**

<!-- source-p 025 -->
**保罗：《评萨宾》第七卷。**

<!-- source-p 026 -->
例如，在农庄中开辟新葡萄园，或在住宅内增建磨坊、店铺，或教奴隶学习技艺。

<!-- source-p 027 -->
<a id="25.1.7"></a>**25.1.7**

<!-- source-p 028 -->
**乌尔比安：《评萨宾》第三十六卷。**

<!-- source-p 029 -->
享乐性费用，是丈夫为满足享受而支出、并使物品外观更为美观的费用。其中的有益费用虽不依法当然减少嫁资，但仍可请求取回。

<!-- source-p 030 -->
<a id="25.1.8"></a>**25.1.8**

<!-- source-p 031 -->
**保罗：《评萨宾》第七卷。**

<!-- source-p 032 -->
有人说，有益费用只有在妻子同意的情况下支出，才可以扣除。理由是，如果妻子无法从其他来源偿付，就迫使她出售财产以偿付为该财产所支出的费用，实属不公；这一意见极有衡平根据。

<!-- source-p 033 -->
<a id="25.1.9"></a>**25.1.9**

<!-- source-p 034 -->
**乌尔比安：《评萨宾》第三十六卷。**

<!-- source-p 035 -->
对于享乐性费用，若妻子不准备让丈夫取走其添置的物品，丈夫即可请求妻子偿付该项费用。妻子若想保有该物，就应将支出返还给丈夫；若不想保有，就应允许丈夫取走，但以该物能够与其他物分离为限。若不能分离，则应留置原处。因此，只有在丈夫取走的装饰物仍归其所有时，才应允许他取回自己添置的装饰物。

<!-- source-p 036 -->
<a id="25.1.10"></a>**25.1.10**

<!-- source-p 037 -->
**保罗：《告示评注》第三十六卷。**

<!-- source-p 038 -->
如果所支费用的物品属于待售商品，则该等费用不是享乐性费用，而是有益费用。

<!-- source-p 039 -->
<a id="25.1.11"></a>**25.1.11**

<!-- source-p 040 -->
**乌尔比安：《评萨宾》第三十六卷。**

<!-- source-p 041 -->
<a id="25.1.11.pr."></a>**序言。**阿里斯托写道，即使享乐性费用是在妻子同意下支出的，也不产生取回请求权。

<!-- source-p 042 -->
<a id="25.1.11.1"></a>**1.**萨宾确实写道，禁止夫妻之间的赠与，这一禁令也适用于费用。

<!-- source-p 043 -->
<a id="25.1.12"></a>**25.1.12**

<!-- source-p 044 -->
**保罗：《评萨宾》第七卷。**

<!-- source-p 045 -->
总之，对于建造房屋、重新栽种或嫁接葡萄藤以及奴隶健康方面的适度支出，审判官不应予以处理；否则，这看起来就不是嫁资之诉，而更像是无因管理之诉。

<!-- source-p 046 -->
<a id="25.1.13"></a>**25.1.13**

<!-- source-p 047 -->
**保罗：《短篇论集》第七卷。**

<!-- source-p 048 -->
丈夫不得要求妻子偿还为嫁资农庄支付的土地贡赋或税赋；这些支出属于收取孳息所负的费用。

<!-- source-p 049 -->
<a id="25.1.14"></a>**25.1.14**

<!-- source-p 050 -->
**乌尔比安：《规则》第五卷。**

<!-- source-p 051 -->
<a id="25.1.14.pr."></a>**序言。**必要费用，是指不支出便会使嫁资减少的费用，例如修筑堤坝、改道河流、支撑并修缮旧建筑，以及在枯死树木的位置补种树木。

<!-- source-p 052 -->
<a id="25.1.14.1"></a>**1.**有益费用，例如将牲畜放入农庄，也就是以牲畜施肥。

<!-- source-p 053 -->
<a id="25.1.14.2"></a>**2.**享乐性费用，例如兴建浴场。

<!-- source-p 054 -->
<a id="25.1.15"></a>**25.1.15**

<!-- source-p 055 -->
**涅拉提乌斯：《论札记》第二卷。**

<!-- source-p 056 -->
所谓对嫁资物所作的必要费用会减少嫁资，应作如下解释：若对嫁资物的支出超出必要保护所需，则该支出属于可以扣除的情形，因为丈夫应以自己的费用维护嫁资物。否则，为嫁资奴隶提供食物、对嫁资建筑物所作的任何小额修缮，以及耕作农田等，都会减少嫁资；这些全都属于必要费用的例子。但应认为，物品本身能够提供相应收益，因此，与其说丈夫为这些物品支出了费用，不如说扣除该等费用后，他从物品中取得的收益较少。依照上述区分，哪些费用应从嫁资中扣除，不容易作一般性界定，而应根据每项费用的性质和数额分别判断。

<!-- source-p 057 -->
<a id="25.1.16"></a>**25.1.16**

<!-- source-p 058 -->
**涅拉提乌斯：《论札记》第六卷。**

<!-- source-p 059 -->
首先，凡为取得孳息而支出的费用，即便同时也是为耕作而支出，并因此不仅是为收取孳息、而且也是为保存物本身及其形态所必需，均由丈夫自行承担；丈夫不得以此为由从嫁资中扣除任何金额。
