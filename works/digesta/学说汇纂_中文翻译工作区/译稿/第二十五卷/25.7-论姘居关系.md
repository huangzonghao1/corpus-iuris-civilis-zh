# D.25.7 论姘居关系（*De concubinis*）

<!-- source-p 001; 原文导航锚点 7、题名锚点 25.7 -->
<a id="7"></a><a id="25.7"></a>**25.7.0　论姘居关系（*De concubinis*）**

<!-- source-p 002 -->
<a id="25.7.1"></a>**25.7.1**

<!-- source-p 003 -->
**乌尔比安：《尤利亚—帕皮亚法评注》第二卷。**

<!-- source-p 004 -->
<a id="25.7.1.pr."></a>**序言。**处于姘居关系中的女被释奴，能否违背释奴保护人的意愿离开他，再将自己交付给另一人，无论是与其结为合法婚姻，还是与其建立姘居关系？我认为，如果她违背释奴保护人的意愿离开，就应剥夺她缔结合法婚姻的资格（*conubium*）；毕竟，对释奴保护人而言，让自己的女被释奴作姘居伴侣，比让她成为家内正妻（*mater familias*）更为体面。

<!-- source-p 005 -->
<a id="25.7.1.1"></a>**1.**我赞同阿提利奇努斯和森提乌斯的意见，并认为，只有与之发生性关系不构成罗马法上 *stuprum*（违禁性关系）之罪的妇女，才可在不必担心因此受刑罚的情况下作为姘居伴侣。

<!-- source-p 006 -->
<a id="25.7.1.2"></a>**2.**某人若将被判犯有通奸罪的妇女作为姘居伴侣，我认为他不受《尤利亚通奸法》的追究；但如果他娶她为妻，则应受该法追究。

<!-- source-p 007 -->
<a id="25.7.1.3"></a>**3.**如果某妇女曾是释奴保护人的姘居伴侣，后来又成为其儿子或孙子的姘居伴侣，或者反过来，我认为她的行为并不正当，因为此种结合近乎悖伦，因此必须禁止此类行为。

<!-- source-p 008 -->
<a id="25.7.1.4"></a>**4.**显而易见，任何年龄的妇女都可以成为姘居伴侣，但未满十二岁者除外。

<!-- source-p 009 -->
<a id="25.7.2"></a>**25.7.2**

<!-- source-p 010 -->
**保罗：《尤利亚—帕皮亚法评注》第十二卷。**

<!-- source-p 011 -->
如果释奴保护人以女被释奴为姘居伴侣，后来开始精神失常，较为人道的意见是，她仍处于姘居关系中。

<!-- source-p 012 -->
<a id="25.7.3"></a>**25.7.3**

<!-- source-p 013 -->
**马尔基安：《法学阶梯》第十二卷。**

<!-- source-p 014 -->
<a id="25.7.3.pr."></a>**序言。**姘居伴侣可以是他人的被释奴，也可以是自由出生的妇女；尤其常见的是出身卑微，或曾以身体谋生的妇女。反之，如果男子希望将一名出身自由、品行端正的妇女作为姘居伴侣，除非他以正式声明明确表明这一点，否则不予准许。但他必须要么娶她为妻，要么在她拒绝婚姻时与她发生构成罗马法上违禁性关系（*stuprum*）的性关系：

<!-- source-p 015 -->
<a id="25.7.3.1"></a>**1.**此外，男子本人并不因姘居关系而构成通奸罪。正如马尔切卢斯在《学说汇纂》第七卷中所写，姘居关系既已为法律所承认，便不受该法刑罚的规制。

<!-- source-p 016 -->
<a id="25.7.4"></a>**25.7.4**

<!-- source-p 017 -->
**保罗：《答复集》第十九卷。**

<!-- source-p 018 -->
是否构成姘居关系，应仅依当事人的内心意图判断。

<!-- source-p 019 -->
<a id="25.7.5"></a>**25.7.5**

<!-- source-p 020 -->
**保罗：《法律意见集》第二卷。**

<!-- source-p 021 -->
某人可以在自己负责管理事务的行省保有姘居伴侣。
