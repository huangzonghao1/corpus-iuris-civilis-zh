# D.31.1 论遗赠与遗嘱信托（*De legatis et fideicommissis*）——第三段

<!-- source-p 211 -->
<a id="31.55.1"></a>**1.**若遗赠给予遗产中的奴隶，而遗嘱指定的继承人全无资格或无资格取得全部遗赠，那么，在审查取得资格时，须判断应以继承人、死者还是任何一方的资格为准。经多种意见争论后，较可取的结论是：由于不存在可据以审查资格的所有人，遗赠应毫无障碍地归入遗产；因此，日后无论谁成为继承人，均应在其能够取得的范围内取得全部遗赠；其余部分则归依法被召集继承的人。

<!-- source-p 212 -->
<a id="31.56"></a>**31.56**

<!-- source-p 213 -->
**盖尤斯：《朱利亚—帕皮亚法》第十四卷。**

<!-- source-p 214 -->
若遗赠给予元首，而元首在遗赠请求权开始发生之前已离世，依神圣安敦尼努斯的敕令，该遗赠应给付其继承人。

<!-- source-p 215 -->
<a id="31.57"></a>**31.57**

<!-- source-p 216 -->
**毛里基乌斯：《朱利亚—帕皮亚法》第二卷。**

<!-- source-p 217 -->
若你把遗赠给予皇后，而她已不在人世，那么留给她的遗赠即告失效；正如神圣哈德良在普洛蒂娜皇后之事中所裁定的，近来皇帝安敦尼努斯也就福斯蒂娜皇后作出同样裁定：立遗嘱人死亡之前，她已不在人世。

<!-- source-p 218 -->
<a id="31.58"></a>**31.58**

<!-- source-p 219 -->
**盖尤斯：《朱利亚—帕皮亚法》第十四卷。**

<!-- source-p 220 -->
若某物遗赠给某人，而此人希望该物哪怕有一部分归自己所有，他便取得全部。

<!-- source-p 221 -->
<a id="31.59"></a>**31.59**

<!-- source-p 222 -->
**克莱门提乌斯：《朱利亚—帕皮亚法》第十五卷。**

<!-- source-p 223 -->
若同一物无条件遗赠给我，又无条件或附条件遗赠给我的奴隶，而我拒绝给我的遗赠；此后条件成就时，我又希望归给奴隶的遗赠归我所有，那么，据答复，遗赠的一部分即告失效。除非有人怀疑：条件成就时，若奴隶仍在世，我曾经表示希望归我所有的遗赠是否无论如何都应全部归我；后一意见看来更为公允。若同一物遗赠给我的两名奴隶，亦同。

<!-- source-p 224 -->
<a id="31.60"></a>**31.60**

<!-- source-p 225 -->
**乌尔比安：《朱利亚—帕皮亚法》第十六卷。**

<!-- source-p 226 -->
尤利安说：若某人的儿子被指定为继承人，并由其遗赠给塞尤斯，又委托塞尤斯以诚信为保证，在条件成就时把遗赠交给提提乌斯；而提提乌斯在条件尚未成就时死亡，那么，未能实现的遗嘱信托仍归塞尤斯所有，不归儿子的继承人；因为元老院希望在遗嘱信托中，受托诚信之人享有较优地位。

<!-- source-p 227 -->
<a id="31.61"></a>**31.61**

<!-- source-p 228 -->
**乌尔比安：《朱利亚—帕皮亚法》第十八卷。**

<!-- source-p 229 -->
<a id="31.61.pr."></a>**序言。**某人留下四百，指定提提乌斯和梅维乌斯为继承人；他遗赠给提提乌斯二百，并将一百遗赠给无论谁成为继承人之人。若梅维乌斯未接受遗产，提提乌斯应给付三百。

<!-- source-p 230 -->
<a id="31.61.1"></a>**1.**尤利安确实说过：若法定继承人之一拒绝其份额，而立遗嘱人曾要求他履行遗嘱信托，不应强迫其共同继承人履行该信托；因为该份额归共同继承人时不附带负担。但塞维鲁皇帝敕答之后，规则已有变化：依该敕答，遗嘱指定继承人所负的遗嘱信托义务由替补继承人承担；因此，此处共同继承人取得归并份额时，也应如同替补继承人一样承受其负担。

<!-- source-p 231 -->
<a id="31.62"></a>**31.62**

<!-- source-p 232 -->
**利基尼乌斯：《规则》第四卷。**

<!-- source-p 233 -->
若他人的奴隶被指定为继承人，可以要求其主人履行遗嘱信托。但只有在奴隶使主人取得继承人身份时，主人方须履行。若奴隶尚未依主人命令接受遗产便获释，并自行决定接受遗产，主人便不负给付义务，因为他未因此成为继承人；奴隶也不负义务，因为并未要求他履行信托。因此，此种情形可提起有益诉讼，强制实际取得遗产利益之人履行遗嘱信托。

<!-- source-p 234 -->
<a id="31.63"></a>**31.63**

<!-- source-p 235 -->
**卡利斯特拉图：《警示告示评注》第四卷。**

<!-- source-p 236 -->
继承人不知道某物已被遗赠，便将其用于丧葬，因此不承担出示之诉的责任，因为他既未占有该物，也未以恶意使自己不再占有。不过，可通过事实之诉救济受遗赠人，使其获得继承人的赔偿而不受损失。

<!-- source-p 237 -->
<a id="31.64"></a>**31.64**

<!-- source-p 238 -->
**帕比尼安：《疑问集》第十五卷。**

<!-- source-p 239 -->
遗嘱信托文书写明信托附条件留给数人，但因错误遗漏了相互替补条款；立遗嘱人却在第二份遗嘱文书中指定这些人为替补继承人时明确写出了相互替补。神圣马尔库斯与科莫杜斯皇帝敕答说，立遗嘱人相互替补的意思显而易见。毕竟，在遗嘱信托中，虽须以请求方式探求立遗嘱人的意思，仍可凭推论予以认定。

<!-- source-p 240 -->
<a id="31.65"></a>**31.65**

<!-- source-p 241 -->
**帕比尼安：《疑问集》第十六卷。**

<!-- source-p 242 -->
<a id="31.65.pr."></a>**序言。**若特有产中的财物后来开始或不再属于特有产，遗赠的特有产可以随之增加或减少。家内奴隶亦同：无论遗赠的是全部家内奴隶，还是其中特定的一组（例如城市奴隶或乡村奴隶），若之后改变奴隶的职务或服务安排，亦应如此。遗赠轿夫或随行侍从，也适用同一规则。

<!-- source-p 243 -->
<a id="31.65.1"></a>**1.**有人认为，四马战车中的一匹马死亡，战车遗赠即告失效，但仅限于死去的正是用来确定该战车身份的那匹马；若之后补足减少的马匹，战车仍归受遗赠人。

<!-- source-p 244 -->
<a id="31.65.2"></a>**2.**斯提库斯遗赠给提提乌斯，却在提提乌斯死后才获得自由；遗赠须待继承人接受遗产后方可请求，自由也在提提乌斯死后发生效力。若奴隶奉命在提提乌斯临终时获得自由，亦同。

<!-- source-p 245 -->
<a id="31.65.3"></a>**3.**但若奴隶遗赠给被指定为部分继承人的提提乌斯，并被命令在提提乌斯死后获得自由，那么无论提提乌斯是否接受遗产——自由是在其死亡后授予的——提提乌斯死亡时，该奴隶均取得自由。

<!-- source-p 246 -->
<a id="31.66"></a>**31.66**

<!-- source-p 247 -->
**帕比尼安：《疑问集》第十七卷。**

<!-- source-p 248 -->
<a id="31.66.pr."></a>**序言。**梅维乌斯附条件遗赠给我和提提乌斯一处地产；他的继承人又附同一条件将同一地产遗赠给我。尤利安说，条件成就时，我可能依据两份遗嘱各自取得同一份额，这是令人担忧的。但这仍是立遗嘱人意思的问题：继承人意在使同一份额被同一人取得两次，难以置信；较可能的是，他考虑了另一份额。确实，元首敕令规定，不应因同一遗嘱反复遗赠同一物而加重继承人的负担；但该规则只适用于一份遗嘱。债务人并非总能以遗赠的方式有效遗赠其所负债务，只有当遗赠物的价值高于债务时才可以；若同一债务附同一条件被遗赠，遗赠究竟带来何种利益？

<!-- source-p 249 -->
<a id="31.66.1"></a>**1.**两份遗嘱均将梅维乌斯所享有的地产份额遗赠给提提乌斯。较为妥当的意见是：一名继承人给付梅维乌斯原有的地产份额后，提提乌斯即因另一份遗嘱而获解除该遗赠义务；该份额后来被让与他人，也不能使已经消灭的诉权复活。

<!-- source-p 250 -->
<a id="31.66.2"></a>**2.**但若遗赠的是地产的一部分，而不是“梅维乌斯原有的那一部分”，先前的给付便不消灭另一项诉权；另一名继承人也可给付同一份额，尽管该份额已以某种方式归其所有。因为数人可在法律观念上、而非按实体分割，共同享有一处地产的所有权。

<!-- source-p 251 -->
<a id="31.66.3"></a>**3.**若两份遗嘱概括遗赠的是一名奴隶，答复则不同：一名继承人给付后，该奴隶即归受遗赠人所有；即使之后奴隶被让与他人，另一名继承人也不能再给付同一奴隶。口约的理由亦同。遗赠“奴隶”这一表述，以简略方式涵盖每一名奴隶；正如一开始便不包括已成为受遗赠人所有的奴隶，对受遗赠人后来取得所有权的奴隶，即使其后不再是所有人，给付也属徒劳。

<!-- source-p 252 -->
<a id="31.66.4"></a>**4.**遗赠的地产上若有继承人埋葬死者，估价须依埋葬前整处地产本可达到的价值计算。因此，即使已支付估价，因埋葬之地成为法律上的宗教场所，依据遗嘱的诉权仍应存续。

<!-- source-p 253 -->
<a id="31.66.5"></a>**5.**若受遗赠人从一名唯一承担遗赠义务的继承人处取得遗赠物的诉讼估价，之后开启附录，发现所有继承人均将同一物遗赠给他，我认为他不会因此取得所有权。因为一人运用数种法律依据，并非反复将同一物遗赠给同一人，而只是多次提及此事。

<!-- source-p 254 -->
<a id="31.66.6"></a>**6.**地产遗赠上附有他人享有的用益权时，仍应向继承人请求返还该地产：用益权虽是法律上的权利而非物的一部分，仍包含该物的经济利益。反之，若遗赠地产，受遗赠人可以就其他随遗赠而来的给付请求诉讼，例如地产已被出质，或由他人占有。其他地役权则不适用同一意见。若遗赠给我的正是我自己的物，因上述理由，该遗赠无效。

<!-- source-p 255 -->
<a id="31.66.7"></a>**7.**若市镇共同体被指定为继承人，可以扣除用益权而遗赠所有权，因为市镇共同体可能因不行使用益权而丧失该权利。

<!-- source-p 256 -->
<a id="31.67"></a>**31.67**

<!-- source-p 257 -->
**帕比尼安：《疑问集》第十九卷。**

<!-- source-p 258 -->
<a id="31.67.pr."></a>**序言。**遗嘱信托指定，应在其死亡时从家内奴隶中选出一人；继承人必须作出选择。立遗嘱人又以自己的遗嘱把财产遗赠给所选之人，而此人获选之后，可能依据另一份遗嘱请求该财产，这种遗赠徒劳无益。那么，所给付之物是否尚未确定，因而仿佛遗赠给了债权人？还是说，只要选择仍可变更，就不能将其恰当地比作债权人？无论如何，若选择持续有效，该人似乎已成为债权人；若选择改变，则依据两份遗嘱均无请求权。

<!-- source-p 259 -->
<a id="31.67.1"></a>**1.**若涉及《法尔基第法》，一切均应依如下情形处理：仿佛第一份遗嘱已明确将遗嘱信托留给后来被选中之人。因为必须作出的选择，并非立遗嘱人给予此人的特别利益；毕竟，立遗嘱人无论如何都须返还所留下之物，又怎能说他处分了自己的财产？

<!-- source-p 260 -->
<a id="31.67.2"></a>**2.**因此，若遗嘱信托指定，应在立遗嘱人家内奴隶中选出一人，而这些奴隶无论同等或不同等地位共有三人，只要遗嘱信托留给其中一人即已足够；一旦立遗嘱人的意思得到遵从，其余人便不符合条件。

<!-- source-p 261 -->
<a id="31.67.3"></a>**3.**但若立遗嘱人指定其中一名家内奴隶为继承人，并把地产遗赠给外人，那么，对该外人的遗嘱信托请求应如同家内无人取得继承人身份一样处理。不过，依诈欺抗辩，指定继承人被认为须从遗产中向其他请求遗嘱信托者分出一份；因为准许其他人请求的同一理由，也默示引入了相应的抵扣。

<!-- source-p 262 -->
<a id="31.67.4"></a>**4.**若立遗嘱人指定家内两人为继承人，但给他们的份额并不相等，又将同一地产的四分之一遗赠给外人，那么，就二人依法保留的继承份额而言，不得请求遗嘱信托；这与立遗嘱人将地产预先遗赠给其中一人相同。但就转给外人的另一部分而言，家内奴隶可按人均份额请求遗嘱信托，同时须考虑到以继承份额补偿人均份额。

<!-- source-p 263 -->
<a id="31.67.5"></a>**5.**若继承人将地产遗赠给家内一人，并委托此人把地产返还给外人，有人询问能否请求履行这项遗嘱信托。我认为，只有在地产价值足以实现该信托时，才可以请求。若最初立遗嘱人如此留下遗嘱信托：“请你把地产留给家内你所愿意的一人或数人”，问题便迎刃而解。但若措辞是：“我请求地产不得脱离家内”，则应认定该继承人的继承人也受后来转给外人的遗嘱信托所拘束；其他家内之人此后可依据第一份遗嘱请求信托，当然须待最初被选中之人死亡之后。

<!-- source-p 264 -->
<a id="31.67.6"></a>**6.**因此，若选定一人后，遗嘱信托并未转给外人，那么只有在先行提供担保的情况下，才须向被选中之人履行遗嘱信托：“若我死时地产未能实际留在家内，请将其返还。”

<!-- source-p 265 -->
<a id="31.67.7"></a>**7.**“我请求你在死时把地产返还给你愿意选择的自由民之一。”就措辞而言，选择权属于受托人；只要仍可能优先选择他人，任何人都不能请求返还。若受托人在选择之前死亡，所有人均可请求。因此，受托人在多人仍在世时，某物已给其中一人，其他人便不能请求；但某物并未给所有人时，他们都可以请求。只有当受托人死亡时，仅剩一人存活，该人才能单独请求。

<!-- source-p 266 -->
<a id="31.67.8"></a>**8.**若我把你的物误认为自己的物，在指定提提乌斯为继承人时遗赠给他，涅拉提乌斯·普里斯库斯的意见及那项规定——继承人不应被强迫交付遗赠——均不适用。该规则原为保护继承人，使其不必买回立遗嘱人误以为属于自己的物；立遗嘱人较愿意遗赠自己的物，而非购置他人物品并加重继承人负担。本案并非如此，因为该物的所有权属于继承人。

<!-- source-p 267 -->
<a id="31.67.9"></a>**9.**若遗嘱信托的措辞有所遗漏，但实际写下的其他内容与本应写下的内容相符，则应依指定继承人和遗赠的规则，认定处分有效，只是文字书写得不完整。我们最优秀的皇帝塞维鲁也采纳了这一意见。

<!-- source-p 268 -->
<a id="31.67.10"></a>**10.**马尔库斯皇帝还敕答说，应将立遗嘱人的下列措辞认定为遗嘱信托：“我不怀疑我的妻子会把她所取得的一切返还给我的子女。”这项敕答极有意义：不能让一位曾善意信任妻子的父亲，因美满婚姻的体面及共同子女的信赖而受欺骗。因此，最具远见且最尊重法律的元首注意到，虽未出现遗嘱信托的措辞，该表述仍应依敕答作为遗嘱信托处理。

<!-- source-p 269 -->
<a id="31.68"></a>**31.68**

<!-- source-p 270 -->
**保罗：《疑问集》第十一卷。**

<!-- source-p 271 -->
有人接着询问，丈夫生前以赠与方式给予妻子的财物，是否也属于请求遗嘱信托的范围。我答复：这些财物应排除在死者遗产之外，因此不包含在遗嘱信托中，因为即使由他人继承，妻子仍会保有这些财物。当然，丈夫可以明确委托妻子连同这些财物一并返还。

<!-- source-p 272 -->
<a id="31.69"></a>**31.69**

<!-- source-p 273 -->
**帕比尼安：《疑问集》第十九卷。**

<!-- source-p 274 -->
<a id="31.69.pr."></a>**序言。**“我请求你，卢基乌斯·提提乌斯，满足于一百枚金币。”意见认为遗嘱信托有效，皇帝也曾作出此种敕答。若立遗嘱人指定某人为部分继承人，并这样说：“卢基乌斯·提提乌斯，我请求你就自己的份额满足于一百枚金币”，又应如何处理？其他共同继承人可以请求其继承份额；被指定满足于一百金币的人则保留或优先取得死者希望他满足于此的利益。后一解释无疑比前一种解释更容易成立，因为前一种情形中，是向立遗嘱人并未交谈之人请求遗嘱信托。若立遗嘱人指定某人为全部遗产的继承人，却为可能依法继承的兄弟而这样说，结论亦同：“我请求你，就我留给你的遗产中依法应归我兄弟的部分，满足于一百枚金币。”

<!-- source-p 275 -->
<a id="31.69.1"></a>**1.**以家内奴隶名义留给家内之人的地产，若并非自愿让与，而是因继承人的财产被拍卖，则买受人只能保有该地产，直至债务人若未被拍卖财产时本可保有该地产的时点；债务人死亡后，便不再保有该地产，外部继承人也不会因此被迫交付。

<!-- source-p 276 -->
<a id="31.69.2"></a>**2.**母亲指定未适婚的儿子为继承人，并为其指定监护人，委托该监护人诚信保证：若儿子在十四岁之前死亡，就把遗产返还给塞姆普罗尼乌斯。不能仅因母亲无权指定监护人，便认为遗嘱信托并未有效设立。即使父亲在不符合法律的遗嘱中委托监护人履行信托，也同样应履行，仿佛遗嘱系依法订立；因为只要看起来是由未适婚者设立遗嘱信托，而设立者指定或认为将成为其监护人的人受托，即已足够。未适婚者或未成年人的保佐人亦应适用此规则。无论监护人在父亲生前依法死亡、基于特权获得豁免，还是因年龄不适任，遗嘱信托均不因此失效，因为这项信托仍视为由被监护人设立。因此，意见认为，未受领任何财产的监护人不能为被监护人设立遗嘱信托；因为他向外人留下的财产，并非依据其自身权利给付，而是依据被监护人的权利给付。

<!-- source-p 277 -->
<a id="31.69.3"></a>**3.**某人指定兄弟为继承人，请求其不得出卖宅邸，而应使宅邸留在家内。若继承人不遵从其意思而出卖宅邸，或指定外人为继承人后死亡，所有家内之人均可请求遗嘱信托。若他们并非同一亲等，又应如何？应调整为亲等最近之人首先获邀取得。但不得因此使后续之人的地位永久受先位者损害；只有在亲等最近者愿意提供担保、保证将宅邸返还家内时，才应准其先行取得。若未要求首先获准之人提供担保，则不会因此产生返还之诉；但若宅邸日后落入外人之手，家内之人仍可提起遗嘱信托之诉。我认为，以诈欺抗辩为依据要求提供担保是正当的，即使家内再无其他后位之人。

<!-- source-p 278 -->
<a id="31.69.4"></a>**4.**若其中一些人后来被解放出家父权，可以讨论他们是否也能适当请求遗嘱信托。我认为可以，因为“家内之人”这一称谓也包括这些人。

<!-- source-p 281 -->
<a id="31.70.pr."></a>**序言。**安敦尼努斯皇帝敕答说：受遗赠人若未从遗赠中取得任何财物，可以将自己的诉权让与负有遗嘱信托义务之人，且不得强迫受遗赠人给付。那么，若受遗赠人受托返还遗赠物的一部分，却拒绝返还，究竟应强迫其让与全部诉权，还是仅让与遗嘱信托所涵盖数额的诉权？理据支持后一做法。但即使其已取得遗赠，也不得强迫其超出所得范围履行遗嘱信托。

<!-- source-p 282 -->
<a id="31.70.1"></a>**1.**若受遗赠人被要求返还遗赠的一百金币的双倍，应认为返还数额以遗赠金额为限；若遗嘱信托附有期限，则只可增加利息。即使受遗赠人在取得遗赠后通过某项交易获利甚丰，或因此免于承担口约罚金，也不得改变结论。此规则适用于以数额对数额作比较的情形。反之，若受遗赠人取得钱款后，受托返还其自有之物，即使该物价值更高，也不得只按其所收遗赠金额计算。衡平不允许受遗赠人把其因遗赠取得的数额作为全部履行而交付。

<!-- source-p 283 -->
<a id="31.70.2"></a>**2.**某人指定儿子为部分继承人，又让儿子的叔父与其共同继承，并请求叔父让儿子与自己的子女按人均份额共同继承。若该人均份额低于其兄弟所取得的遗产份额，便不得再请求更多；若高于该份额，答复认为，还须计入叔父已经取得的孳息，或本可取得却因欺诈而未取得的孳息，如同遗赠一百万元后又受托返还更大金额的情形。

<!-- source-p 284 -->
<a id="31.70.3"></a>**3.**若受托人在死后返还遗产剩余部分，却用出售财物所得购买其他财物，则不应认为其减少了所出售的财物……

<!-- source-p 299 -->
<a id="31.75.pr."></a>**序言。**一名军人写信给妹妹，并命令她在自己死后开启，信中写道：“我希望你知道，我赠与你八百枚金币。”意见认为，妹妹享有遗嘱信托请求权；任何人作出的最终意思表示中，也不必证明其他事项。遗嘱信托可以成立，即使死者是对其以恩惠方式给予报偿之人作此表达。

<!-- source-p 300 -->
<a id="31.75.1"></a>**1.**某人被指定为部分继承人，并获准优先取得若干财物；遗赠请求权开始发生后、接受遗产之前，他便死亡。意见认为，遗产份额归其共同继承人的替补继承人；但就共同继承人份额所产生、归并于他的优先取得份额，则转归他的继承人。

<!-- source-p 301 -->
<a id="31.76"></a>**31.76**

<!-- source-p 302 -->
**帕比尼安：《答复集》第七卷。**

<!-- source-p 303 -->
<a id="31.76.pr."></a>**序言。**儿子在不同审判庭提起撤销其母亲遗嘱的诉讼，各审判员作出了不同裁判。意见认为，击败儿子的继承人，不得取得因儿子胜诉而从其他共同继承人处扣出的、遗嘱指定给他的优先取得财物；正如其他受遗赠人也不能就此行使诉权。尽管儿子仅就母亲遗嘱的一部分提起诉讼，仍可依据遗嘱主张自由权。此规则不应扩及无法按份额减少的地役权：儿子败诉时，受遗赠人可请求完整的地役权，但须给付儿子相应份额的估价；或者，若儿子愿以收取价款为条件提供地役权，而受遗赠人不提出该份额估价，则可对其提出诈欺抗辩予以驳回，准用《法尔基第法》的原则。

<!-- source-p 304 -->
<a id="31.76.1"></a>**1.**“我把普布利乌斯·梅维乌斯的全部遗产遗赠给卢基乌斯·塞姆普罗尼乌斯。”塞姆普罗尼乌斯只承担梅维乌斯遗产原有、且持续至成为梅维乌斯继承人之人死亡时的负担；同样，凡本可提出的诉权，也应相互移转。

<!-- source-p 305 -->
<a id="31.76.2"></a>**2.**所有人指定享有用益权之人为继承人，并附条件遗赠地产。依立遗嘱人的意思，继承人不得以用益权为由保留利益。对于继承人享有的其他地产役权，答复则不同，因为用益权相当于一个份额。

<!-- source-p 306 -->
<a id="31.76.3"></a>**3.**“我的继承人应给付提提乌斯依塞姆普罗尼乌斯遗嘱所欠我的财物。”受遗赠人——亦即立遗嘱人——此前依更新所生效力，使该遗嘱项下债务已不再存在。意见认为，错误的说明不应损害受遗赠人；而且该说明并非全然虚假，因为其起初确有事实依据。

<!-- source-p 307 -->
<a id="31.76.4"></a>**4.**奴隶虽被无条件释放，但因法律障碍，在接受遗产后仍不能取得自由；其身份又因外部事由而处于待定状态，例如涉及通奸指控。此人不得期待依据同一遗嘱取得无条件遗赠或遗嘱信托，因为其请求权开始发生的日期并无法律效力。

<!-- source-p 308 -->
<a id="31.76.5"></a>**5.**父亲指定女儿继承二分之一份额，并在遗嘱中这样写道：“我请求你在死时，即使另有子女，也多给我的孙子塞姆普罗尼乌斯一份，以彰显我的家名。”看来，女儿首先负有向孙辈返还人均份额的义务；但父亲把决定权交给女儿，由她斟酌如何调整自己希望多给一名孙子的份额。

<!-- source-p 309 -->
<a id="31.76.6"></a>**6.**母亲遗赠财物，却未依法指定监护人。若其同意由裁判官裁定确认，而裁判官认为该人不适任，则不得因此拒绝受遗赠人的诉权。

<!-- source-p 310 -->
<a id="31.76.7"></a>**7.**某人就不实施特定行为提供了穆基乌斯担保；若其后实施该行为，也必须返还遗赠所生的孳息（孳息原本就须承诺给付）。

<!-- source-p 311 -->
<a id="31.76.8"></a>**8.**受遗赠人不得同时依不同诉权请求遗赠，因为已经给付的遗赠不得再分割。设立这些诉权，并非要让受遗赠人同时行使多项诉讼，而是给予较宽泛的起诉选择，使其可选择一种诉权请求遗赠。

<!-- source-p 312 -->
<a id="31.76.9"></a>**9.**若死者被判处记忆抹煞，且之后查明其遗嘱无效，则可请求返还依据该遗嘱已给付的遗赠；但须以刑事叛逆罪的指控是在遗赠给付之后提出为限。

<!-- source-p 315 -->
<a id="31.77.pr."></a>**序言。**父亲指定子女及其母亲为继承人，并写道：“女儿，我请求你从我的遗产中取得一百枚金币和图斯库卢姆地产作为你的份额后，将遗产的一部分返还给你的母亲。”我答复：女儿可通过共有物分割之诉取得遗产中的地产；但金币应由她从自己的份额中保留。
