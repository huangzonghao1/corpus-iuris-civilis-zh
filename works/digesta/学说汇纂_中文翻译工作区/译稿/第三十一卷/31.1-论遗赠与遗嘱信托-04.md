# D.31.1 论遗赠与遗嘱信托（*De legatis et fideicommissis*）——第四段

<!-- source-p 316 -->
<a id="31.77.1"></a>**1.**可以在任何时候委托受领死因赠与之人履行遗嘱信托。继承人应履行该信托，同时保留《法尔基第法》所规定的份额；意见认为，该法也应像适用于遗赠那样，适用于此类赠与。若赠与的一部分受遗嘱信托拘束，该信托也应承担《法尔基第法》所规定的扣减负担。但若立遗嘱人意在给付扶养费，则依死者意思，应认定全部扣减负担由赠与的剩余部分承担；死者显然希望较大数额完整给付。

<!-- source-p 317 -->
<a id="31.77.2"></a>**2.**一名母亲以死因赠与方式将嫁资给予非婚生子女，并允许子女为此订立要式口约。她指定他人为继承人后，请求儿子们将嫁资返还给丈夫。若不适用《法尔基第法》，丈夫可请求全部嫁资作为遗嘱信托给付；因此，意见认为丈夫可以保留嫁资。否则，若丈夫以要式口约之诉起诉儿子们，儿子们应通过事实之诉将嫁资中的《法尔基第法》份额返还给继承人。

<!-- source-p 318 -->
<a id="31.77.3"></a>**3.**可以有效地委托聋哑受遗赠人，在死亡时返还遗赠物；因为即使受遗赠人并不知情，也会受遗嘱信托拘束，正如不知情者仍可能依据遗嘱取得利益。

<!-- source-p 319 -->
<a id="31.77.4"></a>**4.**某人受托在自己死亡时将遗产返还给自己的儿子，或返还给他所选择的其中一人。期间，该受托人被流放至岛上。意见认为，刑罚并未剥夺其选择权，遗嘱信托的条件也要到作为继承人的儿子死亡时才成就；至于份额，应在因无法再从其他人中选择时仍在世之人之间按人均分配。

<!-- source-p 320 -->
<a id="31.77.5"></a>**5.**某人违反《朱利亚法》出售嫁资地产，遗赠给妻子，并委托买受人在价金之外再向妻子返还一笔钱。意见认为，买受人不受遗嘱信托拘束。但若妻子在接受遗赠后使买卖失效，则在买受人提出价金后，可依据诈欺抗辩驳回妻子的请求。

<!-- source-p 321 -->
<a id="31.77.6"></a>**6.**某被告命令承担要式口约的债务人梅维乌斯，将所欠的钱支付给提提乌斯；他将钱以死因赠与方式给予提提乌斯。梅维乌斯明知债权人已经死亡，仍支付了钱款。意见认为，此项支付并未使债务消灭；即使梅维乌斯无清偿能力，也不得向提提乌斯请求全部债款，或依《法尔基第法》扣减后的部分，因为提提乌斯不被视为取得了死因赠与。若梅维乌斯不知道债权人已死亡，因错误而付款，结论则不同：此时应依《法尔基第法》追回相应份额。

<!-- source-p 322 -->
<a id="31.77.7"></a>**7.**父亲依据母亲的遗嘱，欠女儿一项有关地产的遗嘱信托；他指定女儿为部分继承人，并规定以继承份额抵销遗嘱信托，又希望同一地产给付其被剥夺继承权的儿子。意见认为，即使女儿不愿接受父亲的遗产，父亲的继承人仍应向儿子履行遗嘱信托；父亲的继承人取得了原本归于女儿的遗产份额。若父亲为女儿指定了另一名替补继承人，该替补继承人也应向儿子返还遗嘱信托财产。

<!-- source-p 323 -->
<a id="31.77.8"></a>**8.**父亲误以为自己是所有人，并以遗嘱信托措辞将地产留给儿子；若该地产被追夺，儿子不得向兄弟及共同继承人提起诉讼。但若父亲曾在儿子之间分割财产，裁判官不得仅凭对意思的推测，便允许某儿子向共同继承人请求返还父亲预先分给他们的份额；除非这些共同继承人也愿意维持父亲对其兄弟所作的安排。

<!-- source-p 324 -->
<a id="31.77.9"></a>**9.**父亲以遗嘱信托的方式，将一笔确定的钱留给被剥夺继承权的女儿，并希望在她结婚时由儿子作为嫁资给付，而儿子则约定嫁资的返还。若儿子给付的嫁资低于应有数额，意见认为剩余部分应返还给女儿。即使之后离婚，女儿仍可适当请求履行遗嘱信托，使要式口约之诉权交给她；因为父亲不大可能意在使女儿在第一次婚姻结束后处于没有嫁资的状态。但若她之后再次结婚，该担保不应延及第二次婚姻。

<!-- source-p 325 -->
<a id="31.77.10"></a>**10.**父亲请求女儿在死时将地产返还给她愿意选择的子女之一；女儿生前将地产赠与其中一名子女。遗嘱信托的确定期限尚未到来，因此似乎还不能作出选择；但财产可指定给那些在排除母亲选择后仍能在其他人中取得遗嘱信托之人。

<!-- source-p 326 -->
<a id="31.77.11"></a>**11.**“我委托我的继承人诚信保证，不得让图斯库卢姆地产脱离我家之名。”依立遗嘱人的意思，应认为受托对象也包括那些由外部继承人履行遗嘱信托自由的人。

<!-- source-p 327 -->
<a id="31.77.12"></a>**12.**“妻子，我委托你诚信保证：你死时，应将以我财产的任何名义归于你的所有财物，返还给我的女儿。”该妻子后来依据遗嘱附录取得的财物也包括在遗嘱信托中，因为文书的书写顺序不妨碍法律关系与立遗嘱人意思。但预先遗赠的嫁资应由妻子保留，因为这更像是返还而不是给付。

<!-- source-p 328 -->
<a id="31.77.13"></a>**13.**“我希望将地产给我的自由民；若他们中有人无子女而死，我希望其份额归其余之人。”意见认为，依立遗嘱人意思，父亲的共同释奴、同时又是其儿子的人，排除替补安排。

<!-- source-p 329 -->
<a id="31.77.14"></a>**14.**某人委托自己的保佐人诚信保证，向作为继承人的兄弟交代事务管理账目，这一委托似乎徒劳无益。尽管遗嘱规定，兄弟恢复其原有身份后才向其付款，仍认为兄弟由另一名保佐人辅助而提起诉讼是适当的；因为这些措辞更像是为了保护兄弟，而非推迟本应正当作出的给付。

<!-- source-p 330 -->
<a id="31.77.15"></a>**15.**某人指定外人为继承人，并以遗嘱信托措辞规定，其死时应将地产留给自由民，且不得使地产脱离家族名号。我答复：依死者意思，替补继承人应交付该地产；但究竟立即交付还是附同一条件交付，须解释立遗嘱人的意思。应依据其意思推断是否等待指定继承人死亡。

<!-- source-p 331 -->
<a id="31.77.16"></a>**16.**若以遗嘱信托方式承接银行业务，并通过担保使继承人免受损失，则该交易看来类似买卖；因此，无须再问债务是否超过经营收益。

<!-- source-p 332 -->
<a id="31.77.17"></a>**17.**父亲希望以遗嘱信托措辞，将女儿结婚时给她的奴隶交付给她。我答复，即使奴隶母亲在立遗嘱之前已经死亡，她们所生的子女也应依遗嘱信托交付。此前在妻子获确认的赠与情形中，也遵循同一规则。

<!-- source-p 333 -->
<a id="31.77.18"></a>**18.**若受托人在自己死亡后返还遗产，已经通过分割并以债权让与等方式分配给共同继承人的债权风险，不由其承担；地产亦同，因物品互换使共有关系得以划分。

<!-- source-p 334 -->
<a id="31.77.19"></a>**19.**“我希望我的女儿先行取得并保有其母亲的财物。”父亲在此期间取得的孳息，若未单独保管，而是耗用或并入自己的财产，则不视为留给女儿。

<!-- source-p 335 -->
<a id="31.77.20"></a>**20.**“我希望把我在帕姆菲利亚、吕基亚或其他地方剩余的母系财产，交给我最亲爱的兄弟、也就是你的舅舅，并希望你不要与他们发生任何争议。”母亲遗产中仍保持原有所有权状态的全部财物，均属于遗嘱信托的意思范围。因此，由同一财产取得的钱款若已并入自有财产，或财物已依分割而成为个人所有，就不必交付；立遗嘱人意在平息亲属间因共有关系而常生的争端。

<!-- source-p 336 -->
<a id="31.77.21"></a>**21.**父亲指定多个儿子为继承人，临终时把钥匙和戒指交给长女保管，又命令在场的自由民将其照管的物品交给长女。此事被视为子女共同事务，不因此使长女在遗产分割裁决中享有优先地位。

<!-- source-p 337 -->
<a id="31.77.22"></a>**22.**发现不完整文书时，只有在口头表述与书面内容相符的情况下，才将前后有关遗赠或遗嘱信托的措辞解释为共有。

<!-- source-p 338 -->
<a id="31.77.23"></a>**23.**儿子指定母亲为继承人，并在文书中请求她依宣誓的神圣约束履行遗嘱信托。即使遗嘱在任何法律上均不成立，我仍答复，母亲作为法定继承人，仍应被强制履行遗嘱信托；因为恳切表达的意思似乎涵盖所有继承方式。

<!-- source-p 339 -->
<a id="31.77.24"></a>**24.**“我因关心我女儿的安危而嘱托她，在生育子女之前不要立遗嘱；这样她便可安然生活。”这并未将遗嘱信托继承留给作为共同继承人的妹妹；其意不在处分自己的财产，而是借建议之名禁止女儿立遗嘱，以限制她的遗嘱权利。

<!-- source-p 340 -->
<a id="31.77.25"></a>**25.**“女儿，我请求你在某时将财产分给你的子女，由他们各自依对你的孝行取得。”意见认为，该遗嘱信托留给所有子女，即使他们的功绩并不相同；母亲未作选择时，只要子女未曾冒犯母亲，就已足够。我认为，若母亲选择了其中一人，所选之人应优先，仿佛只有他值得取得；若母亲没有选择，则仅排除那些曾冒犯母亲的人。

<!-- source-p 341 -->
<a id="31.77.26"></a>**26.**母亲未告知儿子，便将一封关于赠与地产的信件存放在神庙中；信中没有遗嘱信托措辞。她又给看守神庙之人写信：“我希望在我死后，将我的意思文书交给我的儿子。”她有数名继承人而无遗嘱死亡。我答复：应认定她为儿子设立了遗嘱信托；无须追问她临终时是与谁谈话，而应看其意思指向谁。

<!-- source-p 342 -->
<a id="31.77.27"></a>**27.**某人将地产留给自由民，并请求他们不得出卖，且使地产留在自由民家内。若除一人外，其余人都出卖了自己的份额，未出卖之人可请求其余人所持份额的全部，因为立遗嘱人并未授权其余之人出卖；看起来，他仅邀请遵从其意思的人履行遗嘱信托。否则，若一人因出卖自己的份额而丧失权利，却反过来请求他人返还出卖的份额，就会非常荒谬。但这仅适用于他们同时出卖的情形；若先后出卖，则先出卖者不能为后出卖者取得份额。较晚出卖之人被视为已在先前出卖者的份额中，为未出卖之人保留了一份。若无人出卖，而最后一人无子女而死，遗嘱信托请求权便不再存在。

<!-- source-p 343 -->
<a id="31.77.28"></a>**28.**自由民获得地产遗赠时，也包括一名女自由民；但立遗嘱人请求地产不得脱离家内之名。意见认为，女自由民的继承人即其儿子，可保留其母亲所取得的地产份额。

<!-- source-p 344 -->
<a id="31.77.29"></a>**29.**某人以为自己的财产只会归表亲所有，便在附录中委托表亲履行多项遗嘱信托。后来依继承法，财产占有权转归两名同一亲等之人。我答复，依公平理由并参照永久告示，应免除该女子二分之一的责任；但她仍须履行自由授予，因为让这些自由权因财产损失而失效，看来过于严苛。

<!-- source-p 345 -->
<a id="31.77.30"></a>**30.**父亲将遗产二分之一给儿子、四分之一给未适婚的女儿，并指定儿子为她们的监护人。他写道：“儿子，你可就你的二分之一份额满足于二百枚金币；女儿们，你们各自可就自己的四分之一份额满足于一百枚金币。”这并非父亲相互为子女留下了遗嘱信托，而是父母通常会对自己的财产作出估价；因此，儿子不会被排除于监护之诉之外，也不能以所估定的数额为由，在善意账目审查中提出抗辩。

<!-- source-p 346 -->
<a id="31.77.31"></a>**31.**梅维乌斯受托在自己死后将其从指定继承人塞尤斯处所得遗产返还给兄弟提提乌斯；梅维乌斯又指定提提乌斯为继承人，并请求提提乌斯死后将自己的遗产以及塞尤斯的遗产返还给塞姆普罗尼乌斯。提提乌斯在此期间从孳息中取得了相当于遗嘱信托债权数额的利益。我答复，该遗嘱信托不应作为债务扣除，因为依抵销原理，他似乎已经取得了应得债权。但若梅维乌斯指定提提乌斯为继承人时，要求他不得保留塞尤斯遗嘱中的遗嘱信托，则《法尔基第法》足以适用于抵销，不过这会造成不公平。提提乌斯更明智的做法，是拒绝依其兄弟遗嘱继承遗产，而取得无遗嘱遗产占有；这样做不构成诈欺，因为他排除了欺诈。

<!-- source-p 347 -->
<a id="31.77.32"></a>**32.**“丈夫，我请求你，若你有子女，就把地产留给他们；若没有，就留给你或我的亲属，或者留给我们的自由民。”我答复，这并非授予选择权，而是依书写顺序设定了替补继承。

<!-- source-p 348 -->
<a id="31.77.33"></a>**33.**遗赠给城市的村镇拥有自己的边界。意见认为，即使立遗嘱人曾表示将另以文书说明这些边界及其希望每年举行的竞赛形式，之后却因死亡而未能完成，城市仍有权取得这些村镇；其未完成说明不影响遗赠。

<!-- source-p 351 -->
<a id="31.78.pr."></a>**序言。**受遗嘱信托人请求全部给付，却因继承人提出《法尔基第法》抗辩而未能成功；若他随后请求先给付其中一部分但仍未获给付，应认为他在该部分上已遭迟延。

<!-- source-p 352 -->
<a id="31.78.1"></a>**1.**最优秀、最伟大的皇帝塞维鲁下令，在买受人死亡后撤销将公有地产出售的交易，并将价金返还给继承人。我答复：若买受人又将该地产遗赠给受遗赠人，应依据立遗嘱人的意思，从金钱中按估价比例给付相应份额。

<!-- source-p 353 -->
<a id="31.78.2"></a>**2.**即使公有财产也须在迟延履行遗嘱信托后给付利息；若迟延履行判决导致损失，应由判决作出后仍拒绝履行之人赔偿。诉讼费用亦同：若无诉讼理由，不应判给费用；不能以懈怠为借口求得宽免。监护人也适用此规则。

<!-- source-p 354 -->
<a id="31.78.3"></a>**3.**父亲以遗嘱信托措辞禁止将子女家内的地产让与他人。最后一名有权请求该遗嘱信托的子女，虽无子女而死且有外人为其继承人，仍应被视为将该诉权留在自己的财产中。

<!-- source-p 355 -->
<a id="31.78.4"></a>**4.**若债权人依质权出售债务人交付的房屋，即使买受人知道死者的意思，也不得基于遗嘱信托对买受人作出裁判。

<!-- source-p 361 -->
遗赠使受遗赠人取得物的所有权，正如继承使继承人取得各项财物的所有权。其意义在于：若某物被无条件遗赠，且受遗赠人未拒绝死者的意思，原属遗产的所有权便直接转归受遗赠人，而从未先成为继承人的所有权。

**保罗：《疑问集》第十卷。**

<!-- source-p 367 -->
<a id="31.82.pr."></a>**序言。**债务人欠债权人十枚金币，约定一年后以物作质担保偿还；他又将这十枚金币遗赠给债权人。与某些人的看法不同，受遗赠人不仅可依据遗嘱请求期间利益，而是可以请求全部十枚金币；一年在此期间届满也不消灭请求权，因为遗赠请求权的起始时间已有效发生。若立遗嘱人生前一年期已届满，则应认为遗赠虽起初成立，后来仍失效。预先遗赠嫁资也适用同一意见：可依据遗嘱请求全部嫁资。否则，若遗赠仅及中间利息，那么在地产于特定日期才到期给付的情形，又应如何处理？既不能请求未曾遗赠的钱款，也很难找出地产中可作为期间利益请求的部分。

<!-- source-p 368 -->
<a id="31.82.1"></a>**1.**若遗嘱依次指定第一、第二、第三顺位继承人，并如此遗赠：“若第一人不成为我的继承人，第二人应给付提提乌斯十枚金币；若第二人不成为我的继承人，第一人应给付塞尤斯图斯库卢姆地产。”第一人与第二人都拒绝继承后，有人询问：他们各自指定的替补继承人是否应履行遗赠，若应履行，由谁给付？意见认为，两名替补继承人都负有遗赠给付义务。

<!-- source-p 369 -->
<a id="31.82.2"></a>**2.**瓦伦斯写道，可以将所有人的物遗赠给他人的奴隶；也可遗赠所有人无条件欠其奴隶之物。我们把财物遗赠给他人的奴隶时，只在判断所有人与受遗赠人之间是否具备遗嘱能力时才考察所有人；遗赠本身则根据奴隶的身份成立。因此，尤利安最为妥当地界定：只有奴隶获释后自己能够取得之物，才可遗赠给他人的奴隶。有人恶意注释说，某物也可以遗赠给奴隶，且奴隶在继续为奴时即可取得；但遗赠仍是基于奴隶身份而产生效力。否则，我们还得注释说，有些奴隶虽不能取得自由，却能为主人取得遗赠或继承。正因遗嘱法上会考察奴隶本人的身份，遗产中的奴隶也可成为遗赠对象。因此，所有人的财物以及欠所有人的债务，尽管不能有效遗赠给所有人自己，却可以无条件遗赠给其奴隶，这并不奇怪。

**拉丁努斯·拉尔古斯：**最近出现了如下实际情形。一名释奴指定其主人为二分之一遗产的继承人，又指定女儿继承另一半；他委托女儿在主人所拥有的若干女奴获释后，将遗产信托给她们；若女儿不成为继承人，则由同一批女奴作为她的替补继承人。女儿不愿成为继承人，于是女奴依其主人的命令——也就是释奴主人之命——接受了死者的遗产。过了一段时间，这些女奴获释，询问能否向同一主人请求遗嘱信托。请答复你对此如何看待。我答复：这并非在此情形下重复设立遗嘱信托，而是二选一地给予遗嘱信托或遗产本身。更妥当的解释是，她们在同一情形下被指定为替补继承人，而这正是她们取得遗嘱信托的情形，因此应召其继承。若某继承人附自由条件向他人的奴隶留下遗嘱信托，并将同一奴隶指定为继承人的替补继承人，即使替补继承无条件作出，也应视为附有取得遗嘱信托时所附的同一自由条件。

<a id="31.84"></a>**31.84**

**保罗：《疑问集》第二十一卷。**

<!-- source-p 375 -->
某人以遗嘱信托授予自己的奴隶自由，又附加其他处分。有人认为，因为该奴隶应由继承人释放，他便不能取得遗嘱信托；这种看法不公正。对于这类人而言，自由请求权与金钱请求权的到期日仿佛同时开始；我甚至认为，若释放自由发生迟延，遗嘱信托也应视为迟延，且须负担利息。正如适当地答复所指出的，主人迟延授予自由期间，奴隶取得的其他财物也应返还给该奴隶。

<!-- source-p 381 -->
<a id="31.86.pr."></a>**序言。**遗嘱写道：“我的曾孙盖乌斯·塞尤斯应继承我遗产的一半，但不包括我居住的宅邸，包括父亲的宅邸及其中所有财物；这些财物均不计入我给予你的继承份额。”这些宅邸中有银器、债权文书、家用器具和奴隶。我询问这些财物是否均应归其他指定继承人。保罗答复：债权文书不在排除范围内，而应由所有继承人共有；至于其他财物，曾孙无权取得。

<!-- source-p 382 -->
<a id="31.86.1"></a>**1.**提提乌斯把地产和城市宅邸遗赠给兄弟之子，其中包括塞伊乌斯地产。提提乌斯生前以一个名称整体拥有该地产，只是为更容易找到承租人，才将其分作两部分出租，并依地点特征称为上塞伊乌斯地产与下塞伊乌斯地产。我询问该地产是否应整体归兄弟之子。保罗答复：若立遗嘱人以一个名称整体拥有塞伊乌斯地产，尽管他按部分分别出租，仍应依遗嘱信托整体交付；除非继承人能明确证明立遗嘱人所指仅为其中某一部分。

<a id="31.87"></a>**31.87**

<!-- source-p 384 -->
**保罗：《答复集》第十四卷。**

<!-- source-p 385 -->
<a id="31.87.pr."></a>**序言。**提提娅希望在自己死后三十日，为塞尤斯买一份粮食配给凭证。若塞尤斯在立遗嘱人生前已基于无偿取得而得到粮食配给凭证，且不能请求取得自己已有之物，那么他是否仍享有诉权？保罗答复：应给付该凭证的价款，因为这项遗嘱信托规定的是一定数额，而非特定实物。

<!-- source-p 386 -->
<a id="31.87.1"></a>**1.**我答复：少女年满二十五岁后，遗嘱信托的利息自发生迟延之时起算。尽管已有规定，对未满二十五岁者无论如何都应给付利息，但此处不应将之理解为仅因迟延而产生；迟延一经发生一次，利息即永久应付。

<!-- source-p 387 -->
<a id="31.87.2"></a>**2.**塞娅将地产遗赠给自己的自由民，并委托他们诚信保证：“我真诚而谨慎地委托你们，不得出售该地产；你们中最后死亡之人死时，应将地产返还给我的自由民、我的继承人辛福罗，以及我后来释放的贝里鲁斯、萨皮杜斯，或届时仍在世的他们的继承人。”我询问：立遗嘱人在第一部分预先遗赠地产时未指定替补继承人，却在第二部分加入“最后死亡之人”一语，先死亡者的份额是否归另一人。保罗答复：在这项遗嘱信托中，立遗嘱人似乎设立了两层替补关系：第一，二人中先死亡之人应向另一人返还；第二，最后死亡之人应向后来明确列举的那些人返还。

<!-- source-p 388 -->
<a id="31.87.3"></a>**3.**亚历山大·塞维鲁皇帝致城市长官克劳狄乌斯·尤利安努斯：“我最亲爱的尤利安努斯，若你查明祖母为避免他人提起违背义务之诉，曾向孙子赠与财产以致耗尽其财产，则依理应追回所赠财产的二分之一。”

<!-- source-p 389 -->
<a id="31.87.4"></a>**4.**卢基乌斯·提提乌斯有五名子女，将他们全部解放出家父权；他以赠与方式把大量财产给了一个儿子盖乌斯·塞尤斯，仅为自己留下一小部分；又指定所有子女及妻子为继承人。遗嘱中，他把自己保留的两处地产预先遗赠给盖乌斯·塞尤斯，并请求他以生前赠给他的地产收益，为女儿梅维娅给付若干金币，并为另一名兄弟给付另一笔相同数额。梅维娅起诉兄长，兄长援引《法尔基第法》。我询问：既然如上所述，至为神圣的皇帝曾命令违背赠与人的意思追回已赠之物，盖乌斯·塞尤斯是否应依父亲意思，从赠与财产中向其姊妹的继承人履行遗嘱信托。保罗答复：皇帝敕令之后，不应怀疑在本案也须救济那些因财产赠与集中给一个儿子而使份额减少的子女；尤其是此处父亲的意思也支持请求遗嘱信托之人。但若《法尔基第法》适用，则因赠与数额过大，遗嘱信托仍应全额履行。

<a id="31.88"></a>**31.88**

<!-- source-p 391 -->
**斯凯沃拉：《答复集》第三卷。**

<!-- source-p 392 -->
<a id="31.88.pr."></a>**序言。**卢基乌斯·提提乌斯在遗嘱中规定：“若我曾将任何财物给予、赠与或许可我的任何子女使用，或子女自行取得任何财物，或任何人给予或遗赠给子女任何财物，他们均可优先取得并保有该物。”他以儿子的名义设立了一本债权簿。之后作出裁判，认定债权簿中仍以儿子名义记载的款项归儿子所有，但父亲已收取并转入自己账簿的款项不归儿子。我询问：若父亲在立遗嘱之前已经收取了原记在儿子名下的款项，立遗嘱后又将款项记回儿子名下，是否依该裁判归儿子所有。斯凯沃拉答复：若款项因同一事由收回后，又用于同一事由，该款应给付儿子。

<!-- source-p 393 -->
<a id="31.88.1"></a>**1.**“提提乌斯，我请求你并委托你诚信保证，负责安排我的遗体安葬；为此，你可先从遗产中取得若干金币。”若卢基乌斯·提提乌斯花费不足十枚金币，剩余部分是否归继承人所有？斯凯沃拉答复：依所述事实，剩余部分应归继承人。

<!-- source-p 394 -->
<a id="31.88.2"></a>**2.**一名女子作为丈夫的继承人，在遗嘱中规定：“我最亲爱的儿子梅维乌斯和塞姆普罗尼乌斯，应优先取得我丈夫、你们父亲提提乌斯死亡时归于我的一切财物；但你们须承担该遗产过去及未来的一切负担，包括提提乌斯死后发生的负担。”我询问：若女子收取孳息后，在丈夫死后支付了某项费用，该费用是否属于儿子的负担。斯凯沃拉答复：依所述事实，她只将遗产中剩余的负担加于受遗赠人。

<!-- source-p 395 -->
<a id="31.88.3"></a>**3.**“凡将成为我继承人的人，此外还应由卢基乌斯·欧提库斯从遗产中优先取得并保有铁器铺的经营用具，连同我命令获得自由的潘菲鲁斯；你们应共同经营该铺。”卢基乌斯·欧提库斯在立遗嘱人生前死亡，其遗产份额归于共同继承人。我询问：潘菲鲁斯虽由同一遗嘱释放，却因经营铺子的意思无法实现，是否仍可请求取得经营用具的一部分。斯凯沃拉答复：可以。

<!-- source-p 396 -->
<a id="31.88.4"></a>**4.**塞姆普罗尼娅被指定为继承人的替补继承人，并受遗赠，条件是她未成为继承人。她对指定继承人提起诉讼，称是因为此人的欺诈，才使立遗嘱人改变原先将她列为第一顺位继承人的意思；她未能胜诉。我询问她是否仍保有请求遗赠的权利。斯凯沃拉答复：依所述事实，她仍保有该权利。

<!-- source-p 397 -->
<a id="31.88.5"></a>**5.**立遗嘱人禁止在五年期满之前请求或给付遗赠，但继承人自愿提前给付其中一些遗赠。有人询问，能否将提前给付计入其后应付遗赠的数额。斯凯沃拉答复：即使某些遗赠在期限届满前已给付，其余部分仍应照常给付。

<!-- source-p 398 -->
<a id="31.88.6"></a>**6.**卢基乌斯·提提乌斯在遗嘱中规定：“我希望把我的小地产给我的男女自由民、我依本遗嘱释放的人以及我的养女塞娅；该地产不得脱离我家族名号，直至所有权归于一人。”我询问塞娅是否与自由民共有该地产，还是可主张取得地产二分之一。斯凯沃拉答复：立遗嘱人的意思显而易见，是让所有人按人均份额取得。

<!-- source-p 399 -->
<a id="31.88.7"></a>**7.**某人指定未适婚的儿子为继承人，并将嫁资、首饰、奴隶及十枚金币预先遗赠给妻子；若未适婚者死亡，又指定替补继承人，并写道：“我希望我在第一份遗嘱中给予的所有财物，也由我的继承人的继承人加倍给付。”有人询问：若未适婚者死亡，替补继承人是否还须再次给付嫁资。斯凯沃拉答复：立遗嘱人看来无意将嫁资遗赠加倍。又有人询问，若遗赠的实物目前仍基于无偿取得而由受遗赠人占有，是否可以向替补继承人请求。答复：不可以。

<!-- source-p 400 -->
<a id="31.88.8"></a>**8.**“我将盖乌斯·塞尤斯的债权文书给予并遗赠给我的同乡。”立遗嘱人之后在附录中禁止向塞尤斯追债，并请求继承人从附录中列明的另一名债务人处收回同一数额后交给市镇共同体。有人询问，若后来指定的债务人无清偿能力，继承人是否应全额给付。斯凯沃拉答复：继承人只须向市镇共同体提供对附录最后指定之债务人的诉权。

<!-- source-p 401 -->
<a id="31.88.9"></a>**9.**立遗嘱人指定女儿为全部遗产的继承人，并以孙子作为其替补继承人，又规定：“若我所厌恶的情形发生，即女儿和孙子都不成为我的继承人，我希望我的自由民取得那处地产二分之一份额中的我的部分。”女儿和孙子都先于立遗嘱人死亡，遗产转归其曾孙作为无遗嘱继承人。有人询问自由民是否仍能请求遗嘱信托。斯凯沃拉答复：依所述事实，若除女儿和孙子外，立遗嘱人未指定其他继承人或替补继承人，则应认为法定继承人受托履行该遗嘱信托。

<!-- source-p 402 -->
<a id="31.88.10"></a>**10.**“无论谁成为我的继承人，都应知道我欠我的叔父德米特里乌斯三枚第纳里乌斯；我还收存着我的叔父塞琉古交给我的三枚第纳里乌斯，我命令立即向他们返还并给付。”有人询问，若实际并不欠款，是否仍有诉权。斯凯沃拉答复：若并不欠款，不存在基于债务的准诉权，但仍有基于遗嘱信托的诉权。

<!-- source-p 403 -->
<a id="31.88.11"></a>**11.**卢基乌斯·提提乌斯在自己死前两年让其自由民达马和潘菲鲁斯离开住所，并停止提供食物；之后他立遗嘱，规定：“无论谁成为我的继承人，都应按月给付我所有自由民一定数额的扶养费，包括我依本遗嘱释放之人、我先前释放之人以及我曾请求予以释放之人。”有人询问达马和潘菲鲁斯是否有权请求遗嘱信托。斯凯沃拉答复：依所述事实，只有当请求者明确证明，主人立遗嘱时已开始对他们抱有这样的意思——也希望给予他们遗赠——才应给付；否则不应给付。

<!-- source-p 404 -->
<a id="31.88.12"></a>**12.**立遗嘱人依遗嘱释放达马和潘菲鲁斯，并将地产给他们，条件是他们死后返还给自己的儿子。他又在同一遗嘱中请求继承人释放潘菲拉；潘菲拉是潘菲鲁斯的亲生女儿。潘菲鲁斯在遗赠请求权开始发生后指定梅维乌斯为继承人，并委托梅维乌斯诚信保证：当潘菲拉获得自由时，将自己的遗产——也就是上述地产中他仅依据其女主人遗嘱取得的一半份额——返还给女儿。我询问：潘菲拉获释后，能否依据其父亲女主人先前的遗嘱请求该份额，还是只能依据其生父的遗嘱请求遗嘱信托，并适用《法尔基第法》。斯凯沃拉答复：依所述情况，可以证明潘菲拉只能依据前一份遗嘱请求遗嘱信托。克劳狄乌斯补充：人们认为，“子女”一词也包括亲生子女，即在奴隶身份期间所生的子女。

<!-- source-p 405 -->
<a id="31.88.13"></a>**13.**斯凯沃拉：有人在遗嘱附录中将一百枚金币遗赠给盖乌斯·塞尤斯，并委托他诚信保证把金币交给立遗嘱人的女奴。我询问这项遗嘱信托是否有效，因为受遗赠人被命令将财物给予立遗嘱人的奴隶。斯凯沃拉答复：无效。若无效，受遗赠人是否必须将财物返还给其所有人——即继承人？答复：不必；但受遗赠人本人也不能请求该遗赠。

<!-- source-p 406 -->
<a id="31.88.14"></a>**14.**某人把一处岛上的产业遗赠给男女自由民，规定男性从收益中取得双份，女性取得单份，并禁止让与。继承人经所有人同意出售该岛。我询问，男性是否仍可从价金中取得双份，女性取得单份。斯凯沃拉答复：原则上不能依据价金请求遗嘱信托；除非他们同意出售时，意在依相同方式取得价金，即男性双份、女性单份。

<!-- source-p 407 -->
<a id="31.88.15"></a>**15.**立遗嘱人指定儿子为继承人，并令由此产生的已解放出家父权的孙辈承受相关处分。他如此写道：“Boulomai de tas emas oikias my pwleisvai hupo twn klyronomwn mou myde daneizesvai kat' autwn, alla menein autas akeraias autois kai uhiois kai ekgonois eis ton hapanta chronon. ean de tis boulyvy autwn pwlysai to meros autou y daneisasvai kat' autou, ecousian exetw pwlysai tw sugklyronomw autou kai daneizesvai par'autou. Ean de tis para tauta poiysy, estai to xrymatizomenon axryston kai akuron”〔底本另附拉丁释文：*Volo autem domus meas nec venumdari ab heredibus meis neque hypothecae dari sed integras manere ipsis et filiis et nepotibus in sempiternum. Quod si quis eorum partem suam vendere volet vel hypothecae dare, liceat ei vendere eam vel hypothecae dare coherendi suo. Si quis contra fecerit, quod actum est inutile esto et irritum.*〕（意为：“我希望我的宅邸既不得由我的继承人出售，也不得设定抵押，而应完整地永久留给他们、他们的子女及孙辈。若其中有人希望出售或抵押自己的份额，可将其出售或抵押给共同继承人。若有人违反此规定，其行为无效。”）有人询问：若死者之子向弗拉维娅·狄奥尼西亚借款，又将出租房屋中按其份额应得的租金让与债权人，是否视为遗嘱条件成就，从而使其子女负有遗嘱信托义务。斯凯沃拉答复：依所述事实，条件并未成就。

<!-- source-p 408 -->
<a id="31.88.16"></a>**16.**立遗嘱人指定母亲和妻子为继承人，并如此嘱托：“我最亲爱的妻子，我请求你死后不要把任何财物留给你的兄弟；你还有姐妹的子女可以受领。你知道，你的一个兄弟为了抢夺财物而杀死了我们的儿子；另一个兄弟对我的所作所为甚至更恶劣。”我询问：妻子无遗嘱死亡后，其法定继承人是她的兄弟，姐妹的子女能否向兄弟请求遗嘱信托。斯凯沃拉答复：可以主张遗嘱信托应予给付。

<!-- source-p 409 -->
<a id="31.88.17"></a>**17.**“我，卢基乌斯·提提乌斯，在未求助任何法学家的情况下订立本遗嘱，宁愿遵从自己的意思，也不作繁复而可悲的谨慎安排；若有任何内容不够合法或不够熟练，应将一个神志健全之人的意思视为合法。”此后他指定继承人。有人询问：若有人请求其无遗嘱遗产占有，是否仍可基于遗嘱信托请求遗嘱所列份额。斯凯沃拉答复：依所述事实，可以请求。

<!-- source-p 410 -->
<a id="31.89"></a>**31.89**

<!-- source-p 411 -->
**斯凯沃拉：《答复集》第四卷。**

<!-- source-p 412 -->
<a id="31.89.pr."></a>**序言。**立遗嘱人指定儿子和妻子为继承人。据说他后来写了一封信，把特有产中的所有财物赠给儿子，并补充说，希望儿子在自己死后将这些财物作为优先取得之物归己、并以自权人身份保有。我询问：遗嘱虽写明，若收到任何密封文书，该文书应视同遗嘱附录；但这封信没有封印，信中财物是否仍归儿子。斯凯沃拉答复：若能证明这封信确由死者留下，则他表示愿意给付的财物应当给付。

<!-- source-p 413 -->
<a id="31.89.1"></a>**1.**某人与兄弟共有一项未分割的财物，并指定女儿们为继承人。他如此规定：“关于我与其叔父、也就是你们的叔父共同所有的一切财物，经估价共值二千枚金币，我委托你们诚信保证，按各自份额从你们的叔父卢克雷提乌斯·帕卡图斯处取得一千枚金币。”立遗嘱人在此后又生存了五年，并留下相当充足的遗产。有人询问：卢克雷提乌斯·帕卡图斯的继承人若依上述措辞给付一千枚金币，女儿们是否可取得遗嘱信托。斯凯沃拉答复：依所述事实，立遗嘱人并无意在给付一千枚金币后返还全部共有物；应给付的是死亡时相关财物的估价。

<!-- source-p 414 -->
<a id="31.89.2"></a>**2.**立遗嘱人将提提乌斯指定为替补继承人，并如此遗赠：“若塞尤斯不成为我的继承人，我希望给付塞尤斯及其妻子马尔切拉十五磅白银。”我询问：若塞尤斯最终成为继承人，马尔切拉是否仍有权取得遗赠的一半。斯凯沃拉答复：依所述事实，应当给付。

<!-- source-p 415 -->
<a id="31.89.3"></a>**3.**卢基乌斯·提提乌斯将无遗嘱死亡，当时有妻子及与妻子所生、已解放出家父权的女儿。他在遗嘱附录中写道：“本附录涉及我的妻子和女儿。首先，我请求你们像我在世时那样相处；我又请求，无论我留下什么，或你们各自拥有的财物，都由你们共有。”女儿取得父亲无遗嘱遗产的占有权。有人询问，女儿是否应依据遗嘱信托将卢基乌斯·提提乌斯遗产的某一份额给母亲，以及该份额为多少。斯凯沃拉答复：依所述事实，若妻子也准备把自己的财产并入共有财产，则应给付二分之一。

<!-- source-p 416 -->
<a id="31.89.4"></a>**4.**立遗嘱人指定四名儿子为等份继承人，并以预先取得方式将地产遗赠给每人。由于父亲的全部财产均已负担债务，儿子们借款清偿了遗产债权人，又将全部地产抵押给后来的一名债权人。该债权人未获清偿，便依质权法将全部地产出售给其中一名继承人。有人询问：该儿子既基于买卖占有地产，其兄弟及共同继承人是否仍有权请求遗嘱信托，还是因他们共同将地产抵押给后来的债权人而丧失权利。斯凯沃拉答复：遗嘱信托的对人诉权仍在各继承人之间相互存在；但在他们先向买受人——亦即其共同继承人——清偿债务之前，不必返还遗嘱信托财产。

<!-- source-p 417 -->
<a id="31.89.5"></a>**5.**立遗嘱人委托女儿诚信保证：“女儿，我请求你在我死后变更嫁资担保，并重新订立约定，使你的兄弟为嫁资债权人；若你在婚姻存续中无子女而死亡一人或数人，嫁资应归他们。”父亲死后，丈夫在嫁资担保尚未变更前死亡；女儿后来再婚，仍无子女而死，当时其兄弟提提乌斯尚在世。有人询问提提乌斯是否有权请求嫁资中的财物。斯凯沃拉答复：若未订立担保系因女儿造成，提提乌斯可向其姐妹的继承人请求遗嘱信托。

<!-- source-p 418 -->
<a id="31.89.6"></a>**6.**立遗嘱人指定儿子和女儿为继承人，又遗赠财物给自由民，并委托他们诚信保证：“我请求你们满足于我在你们生前所遗赠的一切，并在你们死后将其返还给我的儿子们。”立遗嘱人的女儿梅维娅死亡后，一名自由民也死亡，并指定其主人的儿子按应得份额、外人按其余份额为继承人。有人询问：主人的儿子接受遗产后，能否向共同继承人请求返还梅维娅依据母亲遗嘱给付梅维乌斯自由民的财物中属于他的一份。斯凯沃拉答复：他可以向共同继承人请求相应份额；该份额即为若他未接受遗产本可取得的份额。

<!-- source-p 419 -->
<a id="31.89.7"></a>**7.**丈夫指定妻子为全部遗产的继承人，并命令她死后开启遗嘱附录。妻子认为遗产中的地产无收益，便将其出售。买受人询问：妻子死后，附录中被发现以遗嘱信托方式取得遗产的人能否撤销这项买卖，还是只能向妻子的继承人请求价款。斯凯沃拉答复：由于妻子和买受人均有正当理由不知情，地产应留在买受人手中；妻子的继承人应向遗嘱信托受益人给付价款。
