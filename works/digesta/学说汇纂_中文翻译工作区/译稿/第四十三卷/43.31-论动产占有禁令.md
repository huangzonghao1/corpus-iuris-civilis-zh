# D.43.31　论动产占有禁令（*Utrubi*）

<!-- source-p 1064 -->
<a id="31"></a><a id="43.31"></a>**43.31.0**　“Utrubi”禁令。

<!-- source-p 1065 -->
<a id="43.31.1"></a>**43.31.1**

<!-- source-p 1066 -->
乌尔比安《告示评注》第七十二卷。

<!-- source-p 1067 -->
<a id="43.31.1.pr."></a>**序言**　裁判官说：“关于本案所涉奴隶，在本年度的大部分时间内由你们双方中的哪一方占有，我禁止任何人以暴力妨碍该方带走该奴隶。”

<!-- source-p 1068 -->
<a id="43.31.1.1"></a>**1**　本项禁令适用于动产占有；但其效力已被认为与针对不动产的“现占有者”禁令相同。因此，在本项禁令中，如果一方在对方就此提出干扰期间，持有该物且并非以暴力、秘密或可撤回许可的方式从对方处取得占有，该方就应胜诉。
