# D.43.33　论萨尔维乌斯禁令（*De Salviano interdicto*）

<!-- source-p 1082 -->
<a id="33"></a><a id="43.33"></a>**43.33.0**　论萨尔维乌斯禁令。

<!-- source-p 1083 -->
<a id="43.33.1"></a>**43.33.1**

<!-- source-p 1084 -->
尤利安《学说汇纂》第四十九卷。

<!-- source-p 1085 -->
<a id="43.33.1.pr."></a>**序言**　若佃农以质物名义把一名女奴带到土地上，后来又将她出售，为了取回她在买受人处所生的子女，应当给予准用禁令。

<!-- source-p 1086 -->
<a id="43.33.1.1"></a>**1**　若佃农以质物名义把物品带入两人共有的土地，且约定该物对两人均承担全部担保责任，那么两人各自都可以针对第三人正当地适用萨尔维乌斯禁令；但若该禁令在两人之间颁布，占有人的地位较为有利。若约定该物仅按份额承担担保责任，则应给予准用诉权，无论针对第三人还是在两人之间均可提起；据此，每人可取得该物二分之一的占有。

<!-- source-p 1087 -->
<a id="43.33.1.2"></a>**2**　若佃农以质物名义带入一件与他人共有的物品，也应适用同一规则；也就是说，只能按二分之一份额给予质物追索。

<!-- source-p 1088 -->
<a id="43.33.2"></a>**43.33.2**

<!-- source-p 1089 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 1090 -->
若有人把质物带入两人共有的土地，适用萨尔维乌斯禁令时，占有人将胜诉；另一方则必须转而提起塞尔维乌斯诉讼。
