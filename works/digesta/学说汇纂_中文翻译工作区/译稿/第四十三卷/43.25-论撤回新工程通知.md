# D.43.25 论新工程通知的撤回（*De remissionibus*）

<!-- source-p 877 -->
<a id="25"></a><a id="43.25"></a>**43.25.0**　论新工程通知的撤回。

<!-- source-p 878 -->
<a id="43.25.1"></a>**43.25.1**

<!-- source-p 879 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 880 -->
<a id="43.25.1.pr."></a>**序言**　裁判官说：“凡某人有权禁止未经其同意而实施的事项，就该事项所作的新工程通知应当有效；除此以外，我撤回该通知。”

<!-- source-p 881 -->
<a id="43.25.1.1"></a>**1**　本题讨论新工程通知的撤回。

<!-- source-p 882 -->
<a id="43.25.1.2"></a>**2**　裁判官的用语表明，只有在通知不发生效力的情形下，才撤回该通知；裁判官仅意在使通知人在有权禁止未经其同意而实施某事时，通知才发生效力。除此之外，无论是否提供担保，撤回通知的效果都仅及于通知未发生效力的部分。显然，若已提供担保，通知即已撤回，无须再行撤回。

<!-- source-p 883 -->
<a id="43.25.1.3"></a>**3**　有权发出新工程通知者，是享有所有权或地役权的人。

<!-- source-p 884 -->
<a id="43.25.1.4"></a>**4**　尤利安也认为，用益权人有权请求确认地役权；据此，他可以向邻人作新工程通知，并可有效地请求撤销该告知。然而，若他向土地所有人作告知，请求撤销便无效：他不能像对邻人那样，主张所有人无权违背他的意愿将建筑物建得更高。不过，若该行为使其用益权受损，他应当请求确认用益权。尤利安对其他享有邻人所负某种地役权的人，也作同样论述。

<!-- source-p 885 -->
<a id="43.25.1.5"></a>**5**　尤利安还写道，接受土地质押的人也可获准对地役权享有持有保护，此说并非不公。
