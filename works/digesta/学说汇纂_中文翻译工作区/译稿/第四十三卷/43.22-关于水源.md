# D.43.22 关于水源（*De fonte*）

<!-- source-p 677 -->
<a id="22"></a><a id="43.22"></a>**43.22.0**　关于水源。

<!-- source-p 678 -->
<a id="43.22.1"></a>**43.22.1**

<!-- source-p 679 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 680 -->
<a id="43.22.1.pr."></a>**序言**　裁判官说：“对于本案所涉及的水源，若你今年曾使用其水，且使用时并非以暴力、非秘密，也非基于可撤销的许可，我禁止妨碍你继续以同样方式使用。我也将就湖泊、井或蓄水池发布禁令。”

<!-- source-p 681 -->
<a id="43.22.1.1"></a>**1**　这项禁令是为被禁止使用泉水的人而设。地役权不仅可以是引水权，也可以是汲水权；正如引水地役权与汲水地役权有所区分，相关禁令也分别发布。

<!-- source-p 682 -->
<a id="43.22.1.2"></a>**2**　若某人被禁止使用水，即无论被禁止汲水，还是被禁止赶牲畜到水边饮水，均可适用此项禁令。

<!-- source-p 683 -->
<a id="43.22.1.3"></a>**3**　关于主体身份等事项，此处应作与前述各项禁令相同的处理。

<!-- source-p 684 -->
<a id="43.22.1.4"></a>**4**　此项禁令不适用于蓄水池，因为蓄水池没有持续的水源，也没有活水。由此可见，所有这些水源都必须有活水；蓄水池则靠雨水蓄满。因此，湖泊、蓄水池或井若没有活水，禁令即不再适用。

<!-- source-p 685 -->
<a id="43.22.1.5"></a>**5**　当然，若有人被禁止前往汲水之处，同样可依据禁令请求救济。

<!-- source-p 686 -->
<a id="43.22.1.6"></a>**6**　随后裁判官说：“我禁止妨碍你清理或修缮本案所涉及的水源，以便你能够控制水流；但不得以不同于今年此前使用的方式使用，且你此前对其使用，既非以暴力、非秘密，也非基于可撤销的许可。”

<!-- source-p 687 -->
<a id="43.22.1.7"></a>**7**　此项禁令与修缮水渠的禁令具有同样的功能：若不允许清理或修缮水源，其使用就会完全受阻。

<!-- source-p 688 -->
<a id="43.22.1.8"></a>**8**　清理和修缮水源，是为了控制水流，使人能够使用水；但其使用不得超过今年此前实际使用的方式。

<!-- source-p 689 -->
<a id="43.22.1.9"></a>**9**　所谓控制水流，是指将水蓄住，使其不流散、不流失；但不得准许使用者另行开辟或开凿水源，因为那样就超出了其前一年所使用的方式。

<!-- source-p 690 -->
<a id="43.22.1.10"></a>**10**　关于修缮或清理湖泊、井和蓄水池，也可以适用禁令。

<!-- source-p 691 -->
<a id="43.22.1.11"></a>**11**　所有有权请求夏季用水禁令的人，均可获得此项禁令。
