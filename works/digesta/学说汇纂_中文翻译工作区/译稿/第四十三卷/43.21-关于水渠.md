# D.43.21 关于水渠（*De rivis*）

<!-- source-p 643 -->
<a id="21"></a><a id="43.21"></a>**43.21.0**　关于水渠。

<!-- source-p 644 -->
<a id="43.21.1"></a>**43.21.1**

<!-- source-p 645 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 646 -->
<a id="43.21.1.pr."></a>**序言**　裁判官说：“我禁止妨碍他人修缮或清理水渠、隧道及水闸，以便引水；但不得以不同于去年夏季的方式引水，且该人去年夏季对你引水，既非以暴力、非秘密，也非基于可撤销的许可。”

<!-- source-p 647 -->
<a id="43.21.1.1"></a>**1**　这项禁令极为有用：若不允许某人修缮，水渠的使用就会因其他原因受到妨碍。

<!-- source-p 648 -->
<a id="43.21.1.2"></a>**2**　裁判官所说的“水渠、隧道”。所谓 *rivus*，是指一条纵向凹陷的通道，水可沿其流动；该词源自希腊语 *apo tou hrein*（“由流动而来”）。

<!-- source-p 649 -->
<a id="43.21.1.3"></a>**3**　*Specus* 是可以向下看的地方；“观景场所”（*spectacula*）一词即由此而来。

<!-- source-p 650 -->
<a id="43.21.1.4"></a>**4**　所谓水闸（*septa*），是设在引水口处、用于将水从河流分出或迫使河水改道的设施；其材料可以是木材、石头或其他任何为蓄水和引水而设计的材料。

<!-- source-p 651 -->
<a id="43.21.1.5"></a>**5**　所谓引水渠（*incile*），是河流一侧的低洼通道；其名称来自“切割”，因为人们会切削石头或土壤，使水可以从河流中流出。沟渠和井也包括在此项禁令之内。

<!-- source-p 652 -->
<a id="43.21.1.6"></a>**6**　随后裁判官说“修缮、清理”。修缮，是指将受损之物恢复至原有状态。“修缮”一词还包括覆盖、筑基、修补和建造，以及运入、搬来修缮所需的材料。

<!-- source-p 653 -->
<a id="43.21.1.7"></a>**7**　许多人认为，“清理”一词适用于完好的水渠；显然，该词也适用于需要修缮的水渠，因为水渠往往既需要修缮，也需要清理。

<!-- source-p 654 -->
<a id="43.21.1.8"></a>**8**　裁判官说“为引水之目的”。加上这几个字是恰当的：只有为引水而修缮或清理水渠的人，才获准这样做。

<!-- source-p 655 -->
<a id="43.21.1.9"></a>**9**　即使某人没有引水权，只要其在去年夏季或同一年内曾经引水，也可适用此项禁令；只须证明其引水并非以暴力、非秘密，也非基于可撤销的许可即可。

<!-- source-p 656 -->
<a id="43.21.1.10"></a>**10**　若有人想把土渠改成石砌水渠（*rivum signinum*），似乎不能正确地援用此项禁令；因为如此并非修缮。奥菲利乌斯也持此意见。

<!-- source-p 657 -->
<a id="43.21.1.11"></a>**11**　因此，若有人想改经另一处引水，也可以不受处罚地被阻止；若其想将同一水渠加深、抬高、拓宽、延长、覆盖原本敞开的水渠，或反之，亦同。我认为，其他此类改动均可被不受处罚地阻止；但若只是将敞开的水渠加以覆盖，或将其重新敞开，则不应阻止，除非对方证明自己享有更大的利益。

<!-- source-p 658 -->
<a id="43.21.2"></a>**43.21.2**

<!-- source-p 659 -->
保罗《告示评注》第六十六卷。

<!-- source-p 660 -->
拉贝奥说，不得将敞开的水渠改为土渠，因为这样会使土地所有人失去赶牲畜饮水或汲水的便利。庞波尼认为此说不妥，因为土地所有人的这种便利只是偶然取得，并非基于权利；但若在设立地役权时一开始就对此作了约定，则另当别论。

<!-- source-p 661 -->
<a id="43.21.3"></a>**43.21.3**

<!-- source-p 662 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 663 -->
<a id="43.21.3.pr."></a>**序言**　塞尔维乌斯写道，若先前通过隧道引水，如今改为露天引水，便属于以不同方式引水；若有人施工以便更好地保存或蓄住水，则不得不受处罚地阻止他。我认为，反之，在隧道中进行施工也应如此，除非对方享有更大的利益。

<!-- source-p 664 -->
<a id="43.21.3.1"></a>**1**　塞尔维乌斯和拉贝奥写道，若水渠起初是土渠，因不能蓄水而有人想将其改为水泥渠，应予准许；若将原本由砌体建成的水渠或其中一段改为土渠，也同样不得阻止。我认为，应允许进行紧迫且必要的修缮。

<!-- source-p 665 -->
<a id="43.21.3.2"></a>**2**　拉贝奥说，若有人想在水渠内铺设此前从未有过的新水槽或水管，应给予其有益禁令。我们也认为，应在此情形下考量引水人的利益，但不得使土地所有人遭受不便。

<!-- source-p 666 -->
<a id="43.21.3.3"></a>**3**　若将水引入一个蓄水池，再从该池分流至数条水道，想修缮该蓄水池的人也可适用有益禁令。

<!-- source-p 667 -->
<a id="43.21.3.4"></a>**4**　此项禁令适用于所有水渠，无论其位于公共场所还是私人土地上。

<!-- source-p 668 -->
<a id="43.21.3.5"></a>**5**　若水渠输送的是温泉水，也可就其修缮适用禁令。

<!-- source-p 669 -->
<a id="43.21.3.6"></a>**6**　阿里斯托认为，若需修复用于抽取浴场蒸汽的地下通道，也可给予有益诉权。应当说，在此事由下可以适用有益禁令。

<!-- source-p 670 -->
<a id="43.21.3.7"></a>**7**　此项禁令授予的主体及其所针对的主体，与前述有关水的禁令所列主体相同。

<!-- source-p 671 -->
<a id="43.21.3.8"></a>**8**　若有人在他人修缮水渠时发出新工程通知，有意见认为可以无视该通知，这是很有道理的：既然裁判官禁止以暴力妨碍修缮，就不合情理地允许通过新工程通知阻止修缮。当然，仍可依据对物之诉主张权利；毫无疑问，可以对其提起确认“他无此权利”的诉讼。

<!-- source-p 672 -->
<a id="43.21.3.9"></a>**9**　毫无疑问，此人也应就可能发生的损害提供担保。

<!-- source-p 673 -->
<a id="43.21.3.10"></a>**10**　奥菲利乌斯认为，若有人阻止修缮者运出或搬运修缮所需物品，也可适用此项禁令；此说正确。

<!-- source-p 674 -->
<a id="43.21.4"></a>**43.21.4**

<!-- source-p 675 -->
维努莱乌斯《禁令论》第一卷。

<!-- source-p 676 -->
关于修缮水渠的禁令，无须审查原告是否有权引水。道路的修缮并不像水渠修缮那样不可或缺；若不修缮水渠，水的使用将完全被剥夺，人们会因口渴而死亡。事实上，除非修缮水渠，否则水无法到达。道路未修缮只会增加通行和驱赶牲畜的困难，而在夏季这种困难较轻。
