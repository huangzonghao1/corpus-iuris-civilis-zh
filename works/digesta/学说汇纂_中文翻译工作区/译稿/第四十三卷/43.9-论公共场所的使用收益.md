# D.43.9 论公共场所的使用收益（*De loco publico fruendo*）

<!-- source-p 224 -->
<a id="9"></a><a id="43.9"></a>**43.9.0**　论公共场所的使用收益。

<!-- source-p 225 -->
<a id="43.9.1"></a>**43.9.1**

<!-- source-p 226 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 227 -->
<a id="43.9.1.pr."></a>**序言**　裁判官说：“我禁止妨碍某人承租公共场所的使用收益——该租赁系由有权出租的人作出——或妨碍承租人及其合伙人依租赁约定享用该场所。”

<!-- source-p 228 -->
<a id="43.9.1.1"></a>**1**　显然，这项禁令是为了公共利益而发布；它通过禁止任何人对承租使用该场所的人施加暴力，保护公共收入。

<!-- source-p 229 -->
<a id="43.9.1.2"></a>**2**　若承租人本人和其合伙人同时请求发布禁令，较妥当的意见是应优先保护承租人本人。

<!-- source-p 230 -->
<a id="43.9.1.3"></a>**3**　裁判官说：“不得妨碍依租赁约定享用该场所。”他这样说是恰当的：请求享用场所的人，不得超出租赁约定或违反该约定提出主张。

<!-- source-p 231 -->
<a id="43.9.2"></a>**43.9.2**

<!-- source-p 232 -->
保罗《判例集》第五卷。

<!-- source-p 233 -->
通常允许将作为未来城市装饰的画像和雕像设置在公共场所。
