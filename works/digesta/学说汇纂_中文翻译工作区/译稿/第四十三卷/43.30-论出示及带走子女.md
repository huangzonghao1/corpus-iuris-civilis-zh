# D.43.30 论出示子女及带走子女（*De liberis exhibendis, item ducendis*）

<!-- source-p 1037 -->
<a id="30"></a><a id="43.30"></a>**43.30.0**　论出示子女，以及带走子女。

<!-- source-p 1038 -->
<a id="43.30.1"></a>**43.30.1**

<!-- source-p 1039 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 1040 -->
<a id="43.30.1.pr."></a>**序言**　裁判官说：“处于卢基乌斯·提提乌斯权力之下的任何男子或女子，若该男子或女子在你处，或者由于你的恶意欺诈致使其不在你处，则你应当将其出示。”

<!-- source-p 1041 -->
<a id="43.30.1.1"></a>**1**　这项禁令针对被请求出示该人的持有人；请求人称，该人处于自己权力之下。从其措辞可见，该禁令应由对该人享有权力者援用。

<!-- source-p 1042 -->
<a id="43.30.1.2"></a>**2**　在这项禁令中，裁判官不像在前一项禁令中那样，允许提出理由说明应当出示之人为何在持有人处；相反，只要该人处于权力之下，裁判官就认为无论如何都应将其交出。

<!-- source-p 1043 -->
<a id="43.30.1.3"></a>**3**　然而，如果留住子女的是母亲，有时子女基于极为正当的理由应当更多地留在母亲而非父亲身边；神君安敦尼·庇乌斯曾对此作出裁决，马尔库斯和塞维鲁也曾以敕答确认。对此情形，同样应通过抗辩给予母亲救济。

<!-- source-p 1044 -->
<a id="43.30.1.4"></a>**4**　同样，如果已经判决该人不处于某人的权力之下，即使该判决系不法作出，在他人依据这项禁令起诉时，也应以既判事项抗辩相对抗；如此便无须再审查该人是否处于权力之下，只须查明是否已经作出判决。

<!-- source-p 1045 -->
<a id="43.30.1.5"></a>**5**　如果有人想带走自己的女儿（她已嫁给我），或者要求将她出示给自己，那么，倘若父亲意欲拆散一桩和睦的婚姻——而且这桩婚姻或许还有子女为纽带——是否应当给予抗辩以对抗该禁令？我们确实采用一项确定的法律规则：不得以父权扰乱和睦的婚姻。不过，适用这项规则时，应当劝说父亲不要严酷地行使父权。

<!-- source-p 1046 -->
<a id="43.30.2"></a>**43.30.2**

<!-- source-p 1047 -->
赫尔莫革尼安《法学摘要》第六卷。

<!-- source-p 1048 -->
更确切地说，丈夫可以就出示并带走妻子一事，向其父亲提起诉讼；即使该父亲仍对女儿行使权力，也可以如此。

<!-- source-p 1049 -->
<a id="43.30.3"></a>**43.30.3**

<!-- source-p 1050 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 1051 -->
<a id="43.30.3.pr."></a>**序言**　随后，裁判官说：“如果卢基乌斯·提提乌斯处于卢基乌斯·提提乌斯的权力之下，我禁止以暴力阻碍卢基乌斯·提提乌斯将其带往卢基乌斯·提提乌斯处。”

<!-- source-p 1052 -->
<a id="43.30.3.1"></a>**1**　先前诸项禁令均属出示性禁令，也就是说，涉及出示子女及我们上文提到的其他人；而这项禁令涉及带走，使某人能够带走其有权带走的人。因此，关于出示子女的前一项禁令，是这项禁令的准备程序：因为某人要带走他人，必须先将该人出示。

<!-- source-p 1053 -->
<a id="43.30.3.2"></a>**2**　应基于与我们所说可以适用出示子女禁令相同的理由，给予这项禁令。因此，我们在彼处所说的一切，在此也应同样理解。

<!-- source-p 1054 -->
<a id="43.30.3.3"></a>**3**　这项禁令并非针对某人想要带走的儿子本人，而必须有人为该儿子在禁令程序中进行抗辩；否则，这项禁令即不再适用，裁判官的审理程序便可接续进行，由裁判官裁定某人是否处于他人权力之下。

<!-- source-p 1055 -->
<a id="43.30.3.4"></a>**4**　尤利安说，每当有人就带走儿子而申请这项禁令，且争议所涉及的儿子尚未达青春期时，有时应将案件延至其达到青春期时再审，有时则应立即审理；这应根据争讼双方的身份及案件性质决定。若自称父亲者的声望、审慎和诚信均经查验可信，可让未达青春期者留在他身边，直至诉讼之日；但如果提出争议的人身份卑微、惯于诬告且声名恶劣，就应立即审理。同样，如果否认该未成年人处于他人权力之下的人品行端正、广受肯定，并且由遗嘱或裁判官指定的监护人保护该未成年人，直至诉讼日一直照管着他，而自称父亲的人却可疑，似乎是诬告者，就不应延后诉讼。反之，如果双方都可疑，或都被认为不可靠——或因能力不足，或因品行不端，他说，不妨决定在此期间由谁抚养该子女，并将争议延至其达到青春期时再审，以免双方任何一方因串通或无知，使一名自权人被交付于他人的权力之下，或使他人的儿子被置于家父地位。

<!-- source-p 1056 -->
<a id="43.30.3.5"></a>**5**　即使父亲确已充分证明儿子处于自己的权力之下，审理具体情形后，母亲在留住儿子一事上仍享有较优地位；神君安敦尼·庇乌斯的若干裁决中载有此意。事实上，由于父亲品行不端，母亲获准让儿子留在自己身边，而不因此减损父权。

<!-- source-p 1057 -->
<a id="43.30.3.6"></a>**6**　在这项禁令程序中，案件尚未裁判之前，裁判官命令将女性、身穿紫边托加的少年，以及年龄刚刚接近该少年的男子，暂时安置在一位家母（*materfamilias*）处。我们所说年龄刚刚接近身穿紫边托加的少年，是指刚进入青春期的人。这里所谓“家母”，应理解为一位有声望的妇人。

<!-- source-p 1058 -->
<a id="43.30.4"></a>**43.30.4**

<!-- source-p 1059 -->
阿非利加努《疑义》第四卷。

<!-- source-p 1060 -->
如果我主张那个自称家父的人处于我的权力之下，并且是奉我的命令承受了遗产，阿非利加努说，就遗产问题应提起诉讼，同时也应依据关于带走儿子的禁令提起程序。

<!-- source-p 1061 -->
<a id="43.30.5"></a>**43.30.5**

<!-- source-p 1062 -->
维努莱尤斯《禁令论》第四卷。

<!-- source-p 1063 -->
如果儿子自愿留在某人处，这项禁令就不适用，因为该儿子与其说是在受禁令指向的人处，不如说是在他自己那里；毕竟，他可以自由选择离开或留下。不过，如果争议发生在两个都自称为父亲的人之间，且其中一人要求另一人出示该儿子，则属例外。
