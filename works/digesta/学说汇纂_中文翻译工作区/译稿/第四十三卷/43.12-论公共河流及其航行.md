# D.43.12 论公共河流：不得在公共河流或其河岸实施妨碍航行的行为（*De fluminibus. Ne quid in flumine publico ripave eius fiat, quo peius navigetur*）

<!-- source-p 257 -->
<a id="12"></a><a id="43.12"></a>**43.12.0**　论河流。不得在公共河流或其河岸实施妨碍航行的行为。

<!-- source-p 258 -->
<a id="43.12.1"></a>**43.12.1**

<!-- source-p 259 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 260 -->
<a id="43.12.1.pr."></a>**序言**　裁判官称：“我禁止你在公共河流或其河岸实施任何行为，也禁止你向公共河流或其河岸投入任何物，以致停泊或船舶通行变得更为不便。”

<!-- source-p 261 -->
<a id="43.12.1.1"></a>**1**　河流与溪流应依其规模加以区分，或者依当地居民的判断加以区分。

<!-- source-p 262 -->
<a id="43.12.1.2"></a>**2**　河流有些是常流河，有些是季节性急流。所谓常流河，是指始终有水流动的河流，希腊语称 *aenaos*；所谓季节性急流，希腊语称 *ho xeimarrous*。但是，若一条通常全年流淌的河流在某个夏季干涸，也不因此丧失常流河的性质。

<!-- source-p 263 -->
<a id="43.12.1.3"></a>**3**　有些河流是公共河流，有些则不是。卡西乌斯将常流河界定为公共河流；卡西乌斯的这一见解也为塞尔苏斯所赞同，看来颇为合理。

<!-- source-p 264 -->
<a id="43.12.1.4"></a>**4**　本禁令适用于公共河流。若河流为私人所有，则本禁令不适用；私人河流与其他私人场所并无区别。

<!-- source-p 265 -->
<a id="43.12.1.5"></a>**5**　河岸可恰当地界定为河流在保持其自然水道时所容纳的区域。若河水因降雨、海水或其他原因暂时上涨，则不会改变河岸；毕竟从未有人说，尼罗河因泛滥淹没埃及就改变或扩张了自己的河岸。河流恢复至通常水位后，应当修固其河床两侧的河岸。不过，若河流自然增大并永久扩张，或者因与另一条河流汇合或其他原因而永久扩张，毫无疑问应说河岸也随之改变；河流改变河床并开始改道时亦是如此。

<!-- source-p 266 -->
<a id="43.12.1.6"></a>**6**　若公共河流中形成岛屿，在该岛上实施行为，不视为在公共场所实施。若土地已经划界，该岛归先占人所有；或者归与之相接的河岸所有人所有；若岛屿形成于河床中央，则归分别占有两岸附近土地的人所有。

<!-- source-p 267 -->
<a id="43.12.1.7"></a>**7**　同样，若河流离开原河床并开始改道，则在旧河床中实施的行为不受本禁令调整：因为该处已非公共河流，旧河床归两岸土地所有人共有；若土地已经划界，则归先占人所有。无论如何，它已不再是公共河流的一部分。河流为自己形成的新河床，即使此前属于私人，也开始成为公共河床，因为公共河流的河床不可能不是公共的。

<!-- source-p 268 -->
<a id="43.12.1.8"></a>**8**　若有人以人工开挖的沟渠引导公共河流流经其中，该沟渠仍成为公共河流的一部分。因此，在其中实施任何行为，都视为在公共河流中实施。

<!-- source-p 269 -->
<a id="43.12.1.9"></a>**9**　但若河流只是淹没某片土地，并未为自己形成河床，则被水淹没的土地不会因此成为公共土地。

<!-- source-p 270 -->
<a id="43.12.1.10"></a>**10**　同样，若河流绕过某块土地，该土地仍归原所有人。因此，在该处实施的行为不属于在公共河流中实施。本禁令不涉及在私人场所实施的行为，即使行为发生在私人河流中也是如此；在私人河流中的行为，与在其他私人场所中的行为相同。

<!-- source-p 271 -->
<a id="43.12.1.11"></a>**11**　凡在公共河流的水中实施的行为，均应视为在河流中实施；若行为发生在水域之外，就不属于在河流中实施。在河岸上实施的行为，也不视为在河流中实施。

<!-- source-p 272 -->
<a id="43.12.1.12"></a>**12**　裁判官并非禁止在公共河流或其河岸实施一切行为；只有造成停泊或航行状况恶化的行为才受禁止。因此，本禁令仅适用于可通航的公共河流，不适用于其他河流。不过，拉贝奥写道，即使某条河流不可通航，若有人在其中实施行为致使河流干涸或水流受阻，也不妨授予准禁令，禁止以暴力妨碍其依善良之人的判断，拆除、毁弃、清理或恢复那些在河床或河岸实施、以致河流通道或水流状况恶化的工程。

<!-- source-p 273 -->
<a id="43.12.1.13"></a>**13**　“停泊处”（*statio*）一词源于“停留”；因此，它指船舶能够安全停泊的任何地点。

<!-- source-p 274 -->
<a id="43.12.1.14"></a>**14**　裁判官称：“船舶通行变得更为不便。”这里的“通行”是指航行；不过，我们通常也用“船舶”一词指船本身，因此“船舶通行变得更为不便”也可以理解为“船只的航行变得更为不便”。“船舶”一词也包括木筏，因为木筏在许多情况下同样是必需的。即使妨碍的是步行通道，也仍可能使船舶通行变得更为不便。

<!-- source-p 275 -->
<a id="43.12.1.15"></a>**15**　若停泊处或船舶通道的使用受到损害、变得困难、范围缩小、使用频率降低，或完全被取消，就应视为停泊或航行状况恶化。因此，无论是引水改道使水量减少、河流变得不易通航，还是水面扩散而使水变浅，或相反，河道被压缩而使水流加快，抑或发生其他使航行不便、困难甚至完全受阻的情形，均可适用本禁令。

<!-- source-p 276 -->
<a id="43.12.1.16"></a>**16**　拉贝奥写道，不应准许被诉人援引“除非该行为是为保护河岸而实施”的抗辩；他说，抗辩应表述为：“但法律允许实施的行为除外。”

<!-- source-p 277 -->
<a id="43.12.1.17"></a>**17**　拉贝奥认为，若有人在海上实施行为，也可适用类似禁令：“不得在海上或海岸实施任何行为，以致港口、停泊处或船舶通道变得更为不便。”

<!-- source-p 278 -->
<a id="43.12.1.18"></a>**18**　他还认为，即使行为发生在不可通航的公共河流中，也适用同样规则。

<!-- source-p 279 -->
<a id="43.12.1.19"></a>**19**　接着，裁判官称：“若有人在公共河流或其河岸实施行为，或者将任何物投入该河流或其河岸，致使停泊或船舶通行变得更为不便，你应将其恢复原状。”

<!-- source-p 280 -->
<a id="43.12.1.20"></a>**20**　前述禁令是禁止性禁令；本禁令则是恢复原状禁令，二者针对同一事项。

<!-- source-p 281 -->
<a id="43.12.1.21"></a>**21**　凡实施或保有该工程、投入物的人，均被命令予以恢复，但前提是其所保有的工程或物确实使停泊或船舶通行状况恶化。

<!-- source-p 282 -->
<a id="43.12.1.22"></a>**22**　“你实施了”或“你投入了”这些用语表明，承担责任的不是最初实施或投入的人，而是目前保有该工程或投入物的人。拉贝奥据此写道，若你的前手曾使水流改道，而你仍利用该改道，只要你继续使用，便可依本禁令对你追责。

<!-- source-p 283 -->
<a id="43.12.2"></a>**43.12.2**

庞波尼乌斯《萨宾评注》第三十四卷。

只要公共河流中的水不用于公共用途，从中引水并无妨碍，除非皇帝或元老院禁止。可是，若该河流可供航行，或者从该河流引出的水形成另一条可通航的水道，则不得如此引水。

<a id="43.12.3"></a>**43.12.3**

<!-- source-p 287 -->
保罗《萨宾评注》第十六卷。

<!-- source-p 288 -->
<a id="43.12.3.pr."></a>**序言**　流动的公共河流及其河岸均属公共财产。

<!-- source-p 289 -->
<a id="43.12.3.1"></a>**1**　河岸是指能够容纳河水达到最高水位的区域。

<!-- source-p 290 -->
<a id="43.12.3.2"></a>**2**　河流两岸沿线的场所并非全都属于公共财产；河岸从地面开始倾斜向下、直至水边的部分，才属于河岸。
