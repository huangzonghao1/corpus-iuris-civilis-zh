# D.43.14 确保可以在公共河流通航（*Ut in flumine publico navigare liceat*）

<!-- source-p 311 -->
<a id="14"></a><a id="43.14"></a>**43.14.0**　确保可以在公共河流通航。

<!-- source-p 312 -->
<a id="43.14.1"></a>**43.14.1**

<!-- source-p 313 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 314 -->
<a id="43.14.1.pr."></a>**序言**　裁判官称：“我禁止以暴力妨碍某人在公共河流上驾船或行驶木筏，或者在河岸装载、卸下货物。我也将发布禁令，保障人们可以在公共湖泊、沟渠或池塘上航行。”

<!-- source-p 315 -->
<a id="43.14.1.1"></a>**1**　本禁令旨在防止任何人被禁止在公共河流上航行。正如裁判官此前规定禁令，防止任何人被禁止使用公共道路，他也认为应当规定本禁令。

<!-- source-p 316 -->
<a id="43.14.1.2"></a>**2**　若上述水域属于私人所有，本禁令即不适用。

<!-- source-p 317 -->
<a id="43.14.1.3"></a>**3**　湖泊是指常年有水的水域。

<!-- source-p 318 -->
<a id="43.14.1.4"></a>**4**　池塘是指水暂时聚集于一处的水域；这种水通常在冬季积聚。

<!-- source-p 319 -->
<a id="43.14.1.5"></a>**5**　沟渠是以人工方式挖成的蓄水处。

<!-- source-p 320 -->
<a id="43.14.1.6"></a>**6**　这些水域也可以是公共的。

<!-- source-p 321 -->
<a id="43.14.1.7"></a>**7**　萨宾赞同：若承包税收者租用了湖泊或池塘，却被禁止捕鱼，可以授予其准禁令。拉贝奥也持相同意见。因此，若其从市镇租用这些水域，基于税收利益而以禁令保护他，也最为公平。

<!-- source-p 322 -->
<a id="43.14.1.8"></a>**8**　若有人请求发布此类禁令，以便降低某处水边，好让牲畜前来饮水，不应准许；梅拉也这样写道。

<!-- source-p 323 -->
<a id="43.14.1.9"></a>**9**　梅拉还说，可以发布此类禁令，以免有人以暴力妨碍牲畜到公共河流或其河岸饮水。
