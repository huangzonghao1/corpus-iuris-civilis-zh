# D.43.32　论迁出及取回物品（*De migrando*）

<!-- source-p 1069 -->
<a id="32"></a><a id="43.32"></a>**43.32.0**　论迁出。

<!-- source-p 1070 -->
<a id="43.32.1"></a>**43.32.1**

<!-- source-p 1071 -->
乌尔比安《告示评注》第七十三卷。

<!-- source-p 1072 -->
<a id="43.32.1.pr."></a>**序言**　裁判官说：“本案所涉奴隶若不属于你与原告约定作为该住所租金担保的物品——即被搬入或带入该住所，或在那里出生、制作的物品；或者，虽属于这些物品，但相应租金已经向你支付，或已就租金作出清偿，或租金未付系由你所致——我禁止任何人以暴力妨碍以质物名义将该奴隶带入住所的人把他从那里带走。”

<!-- source-p 1073 -->
<a id="43.32.1.1"></a>**1**　本项禁令是为房客设立的；房客已支付租金而想迁出时可以适用。佃农则不能适用。

<!-- source-p 1074 -->
<a id="43.32.1.2"></a>**2**　对此种情形也可以通过非常程序给予救济。因此，本项禁令并不常用。

<!-- source-p 1075 -->
<a id="43.32.1.3"></a>**3**　不过，若有人免费居住，也可以获得适用本项禁令的准用救济。

<!-- source-p 1076 -->
<a id="43.32.1.4"></a>**4**　若租金尚未到期，拉贝奥说，本项禁令不适用，除非房客准备支付该租金。因此，若其已支付一段六个月期间的租金，而下一段六个月的租金已经到期，除非他也支付下一期租金，否则不能有效适用禁令；但前提是，房屋租赁中有特别约定，规定在一年期或某一确定期间届满前不得迁出。若某人租赁数年且租期尚未届满，也应作相同处理。因为质物担保的是整个租赁期间的债务，所以应当认为，除非这些质物已经解除担保，否则不得适用本项禁令。

<!-- source-p 1077 -->
<a id="43.32.1.5"></a>**5**　应当注意，裁判官在此并未要求物品属于承租人的财产，也没有要求该物本身依法设定质权；裁判官只要求该物是以质物名义带入的。因此，即使物品属于他人，或属于依法不能设质的种类，只要是以质物名义带入，仍可适用本项禁令。反之，若物品并非以质物名义带入，出租人便不能扣留。

<!-- source-p 1078 -->
<a id="43.32.1.6"></a>**6**　本项禁令为永久性禁令，可给予继受人，也可针对继受人提出。

<!-- source-p 1079 -->
<a id="43.32.2"></a>**43.32.2**

<!-- source-p 1080 -->
盖尤斯《行省告示评注》第二十六卷。

<!-- source-p 1081 -->
对房客而言，毫无疑问，本项禁令也可以通过准用方式适用于并非属于房客、而是借给他、租给他或寄存于他处的物品。
