# D.43.13 不得使公共河流的水流异于上一夏季（*Ne quid in flumine publico fiat, quo aliter aqua fluat, atque uti priore aestate fluxit*）

<!-- source-p 294 -->
<a id="13"></a><a id="43.13"></a>**43.13.0**　不得在公共河流中实施使水流异于上一夏季的行为。

<!-- source-p 295 -->
<a id="43.13.1"></a>**43.13.1**

<!-- source-p 296 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 297 -->
<a id="43.13.1.pr."></a>**序言**　裁判官称：“我禁止任何人在公共河流或其河岸实施行为，或向该河流或其河岸投入任何物，以致水流异于上一夏季的状况。”

<!-- source-p 298 -->
<a id="43.13.1.1"></a>**1**　裁判官设置本禁令，是为了防止未经许可的引水使河流泛滥，或者河道改变而损害邻人的利益。

<!-- source-p 299 -->
<a id="43.13.1.2"></a>**2**　本禁令适用于公共河流，无论其是否可供航行。

<!-- source-p 300 -->
<a id="43.13.1.3"></a>**3**　裁判官称：“使水流异于上一夏季的状况。”因此，并非每一个实施行为或投入物的人都承担责任；只有通过实施行为或投入物，导致水流异于上一夏季状况的人才承担责任。裁判官所说的“水流异于以往”，并非指水量，而是指水流的方式及其流势。概括而言，只有因所实施的行为改变水流，譬如河道被压低或变窄，水流因而加速并给沿岸居民造成不便时，才应依本禁令追责；若沿岸居民因被诉人的行为而遭受其他不利影响，也适用本禁令。

<!-- source-p 301 -->
<a id="43.13.1.4"></a>**4**　若有人想将原先在封闭渠道中流动的水改为露天流动，或者相反，将原先露天流动的水改为封闭渠道流动，只要该行为给周边居民带来不便，就应依本禁令追责。

<!-- source-p 302 -->
<a id="43.13.1.5"></a>**5**　同样，若有人开挖引水渠、在其他地点施工，或改变河流的河床，也应依本禁令追责。

<!-- source-p 303 -->
<a id="43.13.1.6"></a>**6**　有人认为，应在本禁令中加入“但为加固河岸所实施的行为除外”这一抗辩；也就是说，即使该行为改变了水流，只要是为加固河岸，就不适用本禁令。但也有人不同意：不得以给沿岸居民造成不便为代价加固河岸。我们如今采用的规则是，由裁判官依具体情形判断是否应准许这一抗辩；通常，为公共利益考虑，准许此项抗辩是适当的。

<!-- source-p 304 -->
<a id="43.13.1.7"></a>**7**　若实施行为的人另有正当利益，也应予考虑。设想河流经常造成重大损害并毁坏其土地，他为保护自己的土地修筑堤坝或其他防护设施，而这改变了部分水流：为何不应为他提供救济？我知道许多人为保护自己的土地，甚至完全改道河流、改变河床。处理这类事项时，应当衡量行为人的利益与防护需要，但不得侵害沿岸居民。

<!-- source-p 305 -->
<a id="43.13.1.8"></a>**8**　依本禁令承担责任的人，是使水流异于上一夏季状况的人。裁判官之所以特意规定参照“上一夏季”，据说是因为河流的自然水流在夏季比在冬季更为确定。本禁令不参照当前夏季，而参照上一夏季，因为上一夏季的水流状况更为明确。这里的夏季计算至秋分。若在夏季提出禁令，应考察紧邻其前的那个夏季；若在冬季提出，则不考察紧邻其前的冬季，而应考察此前的夏季。

<!-- source-p 306 -->
<a id="43.13.1.9"></a>**9**　本禁令属于任何公众成员均可提出的禁令，但并非针对所有人，而仅针对未经权利依据、却使水流发生改变的人。

<!-- source-p 307 -->
<a id="43.13.1.10"></a>**10**　本禁令也可对继承人提起。

<!-- source-p 308 -->
<a id="43.13.1.11"></a>**11**　接着，裁判官称：“若有人在公共河流或其河岸实施行为，或向河流或其河岸投入任何物，且因此使水流异于上一夏季的状况，你应将其恢复原状。”

<!-- source-p 309 -->
<a id="43.13.1.12"></a>**12**　这里规定的是恢复原状禁令；前述禁令则是禁止性禁令，适用于尚未实施的行为。因此，行为已经实施的，应依本禁令恢复原状；若要防止行为实施，则应适用前述禁令；若在禁令提出后仍实施了相关行为，也应依禁令加以制止。

<!-- source-p 310 -->
<a id="43.13.1.13"></a>**13**　如拉贝奥所说，在这项恢复原状禁令中，也应包括因恶意欺诈而使被告不再持有该物的情形；这样处理并无不公。
