# D.43.4 论不得妨碍被准入占有者（*Ne vis fiat ei, qui in possessionem missus erit*）

> 底本：*Digesta Iustiniani*，EPUB `book-43.xhtml`，source-p 60–88。

<!-- source-p 60 -->
<a id="4"></a><a id="43.4"></a>**43.4.0**　论不得妨碍被准入占有者。

<!-- source-p 61 -->
<a id="43.4.1"></a>**43.4.1**

<!-- source-p 62 -->
乌尔比安《告示评注》第七十二卷。

<!-- source-p 63 -->
<a id="43.4.1.pr."></a>**序言**　法务官说：“若某人以恶意阻止他人依我的许可，或依享有该管辖权之人的许可，占有财产，我将对其授予事实诉讼；判决金额为他人因此获准占有的财产之价值。”

<!-- source-p 64 -->
<a id="43.4.1.1"></a>**1**　法务官极有远见地发布了这项敕令：若不保护已被准入占有之人，并制裁阻止其进入占有者，那么为保全财产而准许其占有便毫无意义。

<!-- source-p 65 -->
<a id="43.4.1.2"></a>**2**　这项敕令具有一般适用性，涉及所有由法务官准许进入占有之人；法务官理应保护所有由自己准入占有之人。无论某人是为保全财产、保全遗赠，还是以胎儿名义而被准入占有，只要有人以欺诈或其他方式阻止他进入占有，他便享有该敕令所规定的事实诉权。

<!-- source-p 66 -->
<a id="43.4.1.3"></a>**3**　该诉权不仅针对阻止他人进入占有的人，也针对他人已进入占有后又将其驱逐的人；阻止者无须以暴力行事。

<!-- source-p 67 -->
<a id="43.4.1.4"></a>**4**　若某人因认为财物属于自己、已质押给自己，或不属于债务人的财产而阻止他人占有，则他不受此敕令约束。

<!-- source-p 68 -->
<a id="43.4.1.5"></a>**5**　法务官所说“其价值为多少——即某人因此获准进入占有的财产之价值”，是指债权人的利益：阻止占有的人应按债权人因不能占有而遭受的利益损失承担责任。因此，若某人基于虚假的债权或虚假的请求而被准入占有，或者本可通过抗辩将其排除，则此敕令对他毫无帮助，因为其准入占有并无正当根据。

<!-- source-p 69 -->
<a id="43.4.1.6"></a>**6**　可以确定，未适婚人和精神失常者不受此敕令约束，因为他们欠缺相应的辨识能力。但所谓未适婚人，应指不具备欺诈能力者；若其已具备欺诈能力，则应作相反判断。因此，若监护人实施欺诈，应对未适婚人授予诉权，但以监护人有清偿能力为限；尤利安还记载，也可以直接起诉监护人本人。

<!-- source-p 70 -->
<a id="43.4.1.7"></a>**7**　若某人经所有人或父亲同意而阻止他人占有，则应对所有人或父亲本人提起诉讼，视同他们是通过他人实施该行为。

<!-- source-p 71 -->
<a id="43.4.1.8"></a>**8**　除为保全遗赠而准入占有的情形外，该诉权仅在一年内适用，不得逾期提起，因为它具有惩罚性质；不得对继承人及类似继受人提起，但其所受利益范围内除外。不过，继承人及类似继受人可以行使该诉权。若某人因遗赠或遗嘱信托而被阻止取得占有，则该诉权不受期间限制，也可对继承人提起；因为继承人可以通过提供担保来避免该禁令。

<!-- source-p 72 -->
<a id="43.4.2"></a>**43.4.2**

<!-- source-p 73 -->
保罗《告示评注》第五十九卷。

<!-- source-p 74 -->
<a id="43.4.2.pr."></a>**序言**　某人是以自己的名义，还是以他人的名义被阻止占有，并无区别；因为“该财产的价值为多少”这一表述，应以所有人的利益为准。

<!-- source-p 75 -->
<a id="43.4.2.1"></a>**1**　无论以自己名义阻止他人占有，还是以他人名义阻止，行为人都承担责任。

<!-- source-p 76 -->
<a id="43.4.3"></a>**43.4.3**

<!-- source-p 77 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 78 -->
<a id="43.4.3.pr."></a>**序言**　若某人为保全遗嘱信托而被准入占有，却遭人拒绝准入，则应由准许其进入占有的人依其权限使其进入；若有人愿意使用禁令，也可以说该禁令适用。不过，更好的处理方式是由准许其占有的人依其职权自行非常规地执行自己的命令，有时甚至可以动用军队。

<!-- source-p 79 -->
<a id="43.4.3.1"></a>**1**　安敦尼皇帝曾规定，在某些情形下，也可以准许某人进入继承人的财产占有。因此，若他被阻止进入这些财产，应认为其享有准用诉权；此外，他也可以使用非常规执行程序。

<!-- source-p 80 -->
<a id="43.4.3.2"></a>**2**　法务官准许孕妇以胎儿名义进入占有；相应的禁令兼具禁止和命令返还的性质。但若该妇女更愿意仿照债权人提起事实诉讼，而不使用禁令，应当知道她可以这样做。

<!-- source-p 81 -->
<a id="43.4.3.3"></a>**3**　若有人指称某妇女以诬告为目的进入占有，理由是她并未怀孕，或并非因某人而怀孕；或者有人对该妇女的身份提出争议，则依神圣哈德良皇帝的书信，仿照卡尔博尼安告示所确立的推定，法务官承诺准许胎儿名义的占有。

<!-- source-p 82 -->
<a id="43.4.4"></a>**43.4.4**

<!-- source-p 83 -->
乌尔比安《告示评注》第六十九卷。

<!-- source-p 84 -->
<a id="43.4.4.pr."></a>**序言**　法务官也通过禁令救济因可能发生而尚未发生的损害而被准入占有的人，以免其遭受暴力妨碍。

<!-- source-p 85 -->
<a id="43.4.4.1"></a>**1**　拒绝作出承诺或提供担保的人所受的制裁，是让其对方进入占有。因此，若其已作出承诺，或未能作出承诺并非由其造成，则在提出诉讼者因抗辩而被驳回时，该禁令不再适用。

<!-- source-p 86 -->
<a id="43.4.4.2"></a>**2**　若某人既未提供担保，也不允许被准入占有的人占有，法务官承诺对其授予诉讼，判其承担假如已就该事提供担保时本应承担的数额。

<!-- source-p 87 -->
<a id="43.4.4.3"></a>**3**　法务官还基于另一原因规定了该诉讼：若某人在请求准入占有之时无法前往法务官处申请，而在此期间发生损害，则遭受损害的人享有诉讼。

<!-- source-p 88 -->
<a id="43.4.4.4"></a>**4**　此外，法务官还规定，若某人因其他原因被准入占有后遭人阻止，也享有事实诉权。
