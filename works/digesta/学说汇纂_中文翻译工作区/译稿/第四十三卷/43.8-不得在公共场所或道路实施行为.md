# D.43.8 不得在公共场所或道路实施行为（*Ne quid in loco publico vel itinere fiat*）

<!-- source-p 156 -->
<a id="8"></a><a id="43.8"></a>**43.8.0**　不得在公共场所或道路实施行为。

<!-- source-p 157 -->
<a id="43.8.1"></a>**43.8.1**

<!-- source-p 158 -->
保罗《告示评注》第六十四卷。

<!-- source-p 159 -->
在公共场所，裁判官禁止建造，并发布禁令。

<!-- source-p 160 -->
<a id="43.8.2"></a>**43.8.2**

<!-- source-p 161 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 162 -->
<a id="43.8.2.pr."></a>**序言**　裁判官说：“我禁止你在公共场所实施任何行为，或向该场所投入任何物品，以致对他人造成损害；但法律、元老院决议或元首的敕令、裁定所准许的行为除外。对于已经实施的行为，我不发布禁令。”

<!-- source-p 163 -->
<a id="43.8.2.1"></a>**1**　这是一项禁止性禁令。

<!-- source-p 164 -->
<a id="43.8.2.2"></a>**2**　该禁令既保护公共利益，也保护私人利益。公共场所当然供私人使用，但这是基于公民共同体的权利，并非如同各人私有；我们每个人所享有的维护公共场所的权利，与人民中任何人阻止侵害行为的权利相同。因此，若有人在公共场所实施某项工程，致使私人遭受损害，可以对其提起禁止性禁令；发布这项禁令的目的正在于此。

<!-- source-p 165 -->
<a id="43.8.2.3"></a>**3**　拉贝奥界定了“公共场所”的范围：该称谓也包括空地、岛屿、土地以及公共道路和公共通道。

<!-- source-p 166 -->
<a id="43.8.2.4"></a>**4**　我认为，这项禁令不适用于属于财政库财产的场所；私人既不得在其中实施行为，也无权禁止他人在其中实施行为，因为财政库财产类似于元首自己的私有财产。因此，若有人在这类场所实施行为，此禁令绝不适用；若对此类场所发生争议，则由其主管长官担任法官。

<!-- source-p 167 -->
<a id="43.8.2.5"></a>**5**　因此，这项禁令适用于指定供公众使用的场所；若有人在其中实施行为并损害私人，裁判官应以其禁令介入。

<!-- source-p 168 -->
<a id="43.8.2.6"></a>**6**　若有人在阳台上伸出遮阳帘，妨碍邻人的采光，可以适用有益禁令：“我禁止你向公共场所伸出任何物品，以致妨碍盖乌斯·塞尤斯的采光。”

<!-- source-p 169 -->
<a id="43.8.2.7"></a>**7**　阿里斯托认为，若有人想修缮其设置在公共场所的物件，可以适用此禁令以阻止其修缮。

<!-- source-p 170 -->
<a id="43.8.2.8"></a>**8**　若有人将堤坝投向海中，可能因该行为受损之人可以依据有益禁令请求救济；但若无人受损，应保护在岸边建造或向海中修筑堤坝的人。

<!-- source-p 171 -->
<a id="43.8.2.9"></a>**9**　若有人被禁止在海上捕鱼或航行，其不得请求禁令；正如有人被阻止在公共场地游戏、在公共浴场沐浴或在剧场观演时，也不能请求禁令。在这些情形中，均应提起侮辱之诉。

<!-- source-p 172 -->
<a id="43.8.2.10"></a>**10**　裁判官说“以致对他人造成损害”，确有道理：凡允许在公共场所实施某项行为，都必须以不侵害任何人为条件。每当有人请求准许建造新工程时，元首通常也会如此给予许可。

<!-- source-p 173 -->
<a id="43.8.2.11"></a>**11**　凡丧失其原本可从公共场所获得的任何利益之人，均可视为遭受损害，不论该利益为何。

<!-- source-p 174 -->
<a id="43.8.2.12"></a>**12**　因此，若某人的视野受到妨碍，或者通道变得更差或更窄，应当适用禁令。

<!-- source-p 175 -->
<a id="43.8.2.13"></a>**13**　拉贝奥认为，若我在公共场所建造某物，以阻止原本无权从我的土地流至你处的东西继续流去，我不受此禁令拘束。

<!-- source-p 176 -->
<a id="43.8.2.14"></a>**14**　当然，若该建筑导致你的公寓采光减少，则可以适用此禁令。

<!-- source-p 177 -->
<a id="43.8.2.15"></a>**15**　拉贝奥还说，若我在公共场所建造建筑物，而该建筑物妨碍你在公共场所所建的建筑，则此禁令不适用，因为你也在该处违法建造；但若你是依据授予你的权利建造，则另当别论。

<!-- source-p 178 -->
<a id="43.8.2.16"></a>**16**　若某人仅请求元首一般性地准许其在公共场所建造建筑物，不得认为元首准许其以损害他人为代价建造；此种许可并非如此授予，除非有人明确请求该许可。

<!-- source-p 179 -->
<a id="43.8.2.17"></a>**17**　若某人在无人反对的情况下于公共场所建造建筑物，不应强令其拆除，以免废墟使城市面貌受损；况且这是一项禁止性而非恢复原状的禁令。然而，若该建筑妨碍公共使用，负责公共工程的人当然应将其拆除；若未妨碍公共使用，则应向建造者征收“占地费”（*solarium*）。之所以称作 *solarium*，是因为该费用是为土地支付的。

<!-- source-p 180 -->
<a id="43.8.2.18"></a>**18**　但若尚未开始任何工程，法官的职务包括要求提供担保，保证不实施该工程；此类担保也应由其继承人及其他承受其地位之人提供。

<!-- source-p 181 -->
<a id="43.8.2.19"></a>**19**　神圣场所的情形不同：在神圣场所，我们不仅被禁止实施行为，而且被命令恢复已实施行为之前的状态；这是出于宗教理由。

<!-- source-p 182 -->
<a id="43.8.2.20"></a>**20**　裁判官说：“我禁止任何人在公共道路或公共通道上实施或投入任何物品，以致该道路或通道变得更差。”

<!-- source-p 183 -->
<a id="43.8.2.21"></a>**21**　我们所说的公共道路，是指其土地本身也属于公共财产的道路；公共道路与私人道路并非同一规则。私人道路的土地属于他人，我们仅享有通行和驱赶牲畜的权利；公共道路的土地则属于公共财产，由有权将其划为公共道路之人依特定界限留下，供公众往来通行。

<!-- source-p 184 -->
<a id="43.8.2.22"></a>**22**　道路有公共道路、私人道路和乡间道路之分。我们称公共道路为：希腊人所称的“王道”，罗马人所称的“裁判官道路”，另一些人所称的“执政官道路”。私人道路有些人称为“农道”。乡间道路是指位于村庄内或通往村庄的道路；有人也认为这类道路属于公共道路。若该道路并非由私人共同出资修建，此说是正确的。即使道路由私人共同出资修缮，也不因此成为私人道路；之所以共同出资修缮，正是因为该路供众人共同使用并使其受益。

<!-- source-p 185 -->
<a id="43.8.2.23"></a>**23**　私人道路有两种：一类位于田地之中，设有地役权，供人通往他人的土地；另一类通往田地，允许所有人通行。这类道路从执政官道路分出，并在该路之后接续通往庄园的道路、通道或畜群驱赶道。因此，我认为，那些从执政官道路分出、继续通往庄园或其他聚居地的道路，本身也可以是公共道路。

<!-- source-p 186 -->
<a id="43.8.2.24"></a>**24**　此项禁令仅适用于乡间道路，不适用于城市道路；城市道路由行政官员负责管理。

<!-- source-p 187 -->
<a id="43.8.2.25"></a>**25**　若公共道路的通行受到排除或道路被缩窄，行政官员应予介入。

<!-- source-p 188 -->
<a id="43.8.2.26"></a>**26**　拉贝奥写道，若有人将下水道排入公共道路，导致道路因下水道而变得不便通行，则其应受此禁令拘束；因为应视为他向道路投入了某物。

<!-- source-p 189 -->
<a id="43.8.2.27"></a>**27**　因此，若有人在自己的土地上挖沟，使积水流到道路上，也受此禁令拘束；因为此人也应视为向道路投入了某物。

<!-- source-p 190 -->
<a id="43.8.2.28"></a>**28**　拉贝奥还写道，若有人在自己的土地上建造某物，导致聚集的水滞留在道路上，他不受此禁令拘束，因为他并未将水排入道路，而只是没有接纳或排走积水。但涅尔瓦·梅利乌斯认为，这两种情形均应承担责任。

当然，若土地与公共道路相邻，从该土地引出的水使道路变差，而这股水是从邻人的土地流到你土地上的：若你必须接纳这股水，则可以依据禁令起诉邻人；若你并无接纳义务，则邻人不承担责任，但你仍应承担责任，因为应视为你实施了造成该结果的行为——你享有该水流的使用利益。

涅尔瓦还说，若有人对你提起禁令之诉，你不应被强令采取超过以下范围的行动：依起诉人的裁量，对邻人提起诉讼。否则，若依其他方式处理，即使你已善意起诉邻人，且妨碍你依起诉人裁量起诉邻人的原因并非出于你自身，你仍会承担责任。

<!-- source-p 191 -->
<a id="43.8.2.29"></a>**29**　同一法学家还说，若某处仅因气味而变成有害场所，针对该事提起禁令之诉并无不妥。

<!-- source-p 192 -->
<a id="43.8.2.30"></a>**30**　若有人在公共道路或公共通道上放牧，致使道路变差，此禁令也适用。

<!-- source-p 193 -->
<a id="43.8.2.31"></a>**31**　随后裁判官说：“以致该道路或通道变得更差。”无论道路立即变差还是之后才变差，都适用此规定；因为“以致变差”一语既包括立即造成损害的行为，也包括当下尚未造成损害、但预计将来会造成损害的行为。

<!-- source-p 194 -->
<a id="43.8.2.32"></a>**32**　所谓道路变差，是指其通行用途受到损害，也就是通行或驱赶牲畜受到妨碍；例如，原本平坦的道路变得陡峭，原本柔软的道路变得崎岖，原本宽阔的道路变得狭窄，或者原本干燥的道路变成沼泽。

<!-- source-p 195 -->
<a id="43.8.2.33"></a>**33**　我知道，人们曾讨论是否允许在公共道路下建造隧道或桥梁；多数人认为，行为人应受禁令拘束，因为不得使道路变差。

<!-- source-p 196 -->
<a id="43.8.2.34"></a>**34**　此项禁令不受期限限制，任何人均可提起；判决金额应按起诉人所受利益计算。

<!-- source-p 197 -->
<a id="43.8.2.35"></a>**35**　裁判官说：“凡你在公共道路或公共通道上实施或投入的行为，以致该道路或通道变得更差的，均应恢复原状。”

<!-- source-p 198 -->
<a id="43.8.2.36"></a>**36**　此项禁令基于与前一项禁令相同的原因；二者的区别仅在于，此项要求恢复原状，而前一项是禁止性禁令。

<!-- source-p 199 -->
<a id="43.8.2.37"></a>**37**　此项禁令约束的不是在公共道路上实施行为的人，而是占有或维持该行为结果的人。因此，若一人实施行为，另一人占有其结果，应由占有结果者承担责任；如此更为妥当，因为能够恢复原状的是占有该行为结果的人。

<!-- source-p 200 -->
<a id="43.8.2.38"></a>**38**　所谓占有该物，是指使用该物并享有占有权；无论是其本人建造，还是通过买卖、租赁、遗赠、继承或其他方式取得，均属此列。

<!-- source-p 201 -->
<a id="43.8.2.39"></a>**39**　因此，奥菲利乌斯认为，某人放弃自己建造的工程后，若该工程已损坏公共道路，他不受此项禁令拘束，因为他已不再占有其建造物。但是否应对其给予诉权，仍须考察。我认为，应给予有益禁令，命其恢复在公共道路上建造的部分。

<!-- source-p 202 -->
<a id="43.8.2.40"></a>**40**　若树木从你的土地倒在公共道路上并妨碍通行，而你将树木作为遗弃物放弃，拉贝奥写道，你不承担责任；但若起诉人愿自费移走该树木，就可以正确地依据修复公共道路的禁令起诉你。反之，若你并未将树木作为遗弃物放弃，则可以正确地依据该禁令起诉你。

<!-- source-p 203 -->
<a id="43.8.2.41"></a>**41**　拉贝奥还说，若我的邻人以工程损坏道路，尽管该工程对我和邻人都有用，只要邻人是为了自己的土地而建造，我仍不受此禁令追诉；但若我们共同安排建造该工程，我们二人都应承担责任。

<!-- source-p 204 -->
<a id="43.8.2.42"></a>**42**　若有人以恶意欺诈使自己不再占有或持有有关物，也可对其适用此项禁令；因为实际占有或持有该物之人，与因恶意欺诈而不再占有或持有该物之人，应处于相同地位。我认为，拉贝奥的意见是正确的。

<!-- source-p 205 -->
<a id="43.8.2.43"></a>**43**　裁判官说：“你应恢复原状。”所谓恢复原状，是指使事物回到原先状态；这既可通过拆除已经建造的物，也可通过重新设置被移走的物实现。有时还须由其自费恢复：若其本人建造，或他人奉其命令建造，或其已追认他人的建造行为，他就应自费恢复原状。若上述情形均未发生，而他只是占有其行为结果，则应说他仅须容许他人实施恢复原状的行为。

<!-- source-p 206 -->
<a id="43.8.2.44"></a>**44**　应知，此项禁令不受期限限制，因为它关系公共利益；判决金额应按照起诉人要求拆除该行为结果所享有的利益计算。

<!-- source-p 207 -->
<a id="43.8.2.45"></a>**45**　裁判官说：“我禁止以暴力妨碍他人在公共道路或公共通道上通行或驱赶牲畜。”
