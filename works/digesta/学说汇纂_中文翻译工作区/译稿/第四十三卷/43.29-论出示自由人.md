# D.43.29 论出示自由人（*De homine libero exhibendo*）

<!-- source-p 1005 -->
<a id="29"></a><a id="43.29"></a>**43.29.0**　论出示自由人。

<!-- source-p 1006 -->
<a id="43.29.1"></a>**43.29.1**

<!-- source-p 1007 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 1008 -->
<a id="43.29.1.pr."></a>**序言**　裁判官说：“你若以恶意欺诈拘留自由人，就应将其出示。”

<!-- source-p 1009 -->
<a id="43.29.1.1"></a>**1**　这项禁令是为了维护自由而设，亦即防止任何人拘留自由人：

<!-- source-p 1010 -->
<a id="43.29.2"></a>**43.29.2**

<!-- source-p 1011 -->
维努莱尤斯《禁令论》第四卷。

<!-- source-p 1012 -->
（因为他们与处于奴隶状态的人并无太大区别；后者没有离开的自由。）

<!-- source-p 1013 -->
<a id="43.29.3"></a>**43.29.3**

<!-- source-p 1014 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 1015 -->
<a id="43.29.3.pr."></a>**序言**　《法比亚法》对此也作了规定。但这项禁令并不排除依据《法比亚法》提起追诉：既可以依据此禁令起诉，也仍可提起《法比亚法》上的控告；反过来说，提起《法比亚法》控告的人，也仍可援用这项禁令，尤其是因为禁令可以由一人援用，而《法比亚法》之诉可以由另一人提起。

<!-- source-p 1016 -->
<a id="43.29.3.1"></a>**1**　“任何自由人”一语适用于所有自由人，无论已达青春期还是未达青春期，无论男性还是女性，无论一人还是多人，无论属于自权人还是他权人。我们所考察的仅是此人是否自由。

<!-- source-p 1017 -->
<a id="43.29.3.2"></a>**2**　但将某人置于自己权力之下的人，不受此禁令拘束，因为行使自己的权利不应被视为恶意欺诈。

<!-- source-p 1018 -->
<a id="43.29.3.3"></a>**3**　若有人拘留自己从敌人手中赎回的人，其情形不至于受此禁令拘束，因为他并非出于恶意欺诈。但若对方提出赎金，这项禁令便适用。又若赎回者未收取价款便释放了此人，其后又想拘留他，则应说这项禁令仍可适用。

<!-- source-p 1019 -->
<a id="43.29.3.4"></a>**4**　若有人拘留不受其权力支配的儿子，通常应认为其并无恶意欺诈；因为真正的亲情会使这种拘留不构成恶意欺诈，除非存在明显的恶意欺诈。若其拘留的是自己的被释奴、养育的孩子，或尚未达青春期而已交付承担诺克萨责任的人，也应作同样处理。总之，凡有正当理由将自由人留在身边，均不应视为出于恶意欺诈。

<!-- source-p 1020 -->
<a id="43.29.3.5"></a>**5**　若某人拘留的是自愿留下的人，不应视为出于恶意欺诈。但若此人表面上自愿留下，实际上却是被狡猾地蒙骗、诱骗或唆使，而且拘留者并无善意或合理理由，又该如何处理？应正确地说，此人是出于恶意欺诈而被拘留。

<!-- source-p 1021 -->
<a id="43.29.3.6"></a>**6**　若某人不知道自由人身处其处，便不构成恶意欺诈；但一旦得知仍继续拘留，就构成恶意欺诈。

<!-- source-p 1022 -->
<a id="43.29.3.7"></a>**7**　但若有人怀疑此人究竟是自由人还是奴隶，或其身份正处于争议之中，就应停止适用这项禁令，转而审理自由身份之诉。因为正确的意见是，只有在某人确定为自由人时，才适用这项禁令；若其身份尚待查明，则不应对另一程序的审理产生先决影响。

<!-- source-p 1023 -->
<a id="43.29.3.8"></a>**8**　裁判官说：“你应当出示。”出示，是将人带到公共场所，并使他人能够查看和接触此人；严格而言，出示就是使其处于隐蔽之处以外。

<!-- source-p 1024 -->
<a id="43.29.3.9"></a>**9**　任何人都可以援用这项禁令，因为不应阻止任何人维护自由。

<!-- source-p 1025 -->
<a id="43.29.3.10"></a>**10**　但若有理由认为某人可疑，例如有迹象表明他可能串通或诬告，则应将其排除。

<!-- source-p 1026 -->
<a id="43.29.3.11"></a>**11**　若妇女或未成年被监护人因关切其亲属、父母或姻亲而为之请求这项禁令，也应将禁令给予他们；因为在追究自己或亲属所受侵害时，他们也可以提起公诉。

<!-- source-p 1027 -->
<a id="43.29.3.12"></a>**12**　但若有多人希望提起诉讼，应由裁判官选出与此事关系最密切或最适任的人。最好依据其亲属关系、诚信和身份声望，选任此人为禁令申请人。

<!-- source-p 1028 -->
<a id="43.29.3.13"></a>**13**　但若已经有人依据这项禁令提起诉讼，之后又有他人希望援用，显然不应轻易再给予禁令，除非能够指出前一申请人有背信行为。因此，只有审查具体情况后，才可再次启动这项禁令。公诉程序也不允许对同一事项重复起诉，除非前一控告人被判定为串通包庇。但若被告被判决后宁愿支付诉讼标的估价，也不愿出示该人，则再次对其援用禁令并无不公；既可不受抗辩地对同一人再次援用，也可对另一人援用。

<!-- source-p 1029 -->
<a id="43.29.3.14"></a>**14**　拉贝奥写道，这项禁令也可以针对缺席者请求；但若其无人为之辩护，就应对其财产采取执行程序。

<!-- source-p 1030 -->
<a id="43.29.3.15"></a>**15**　这项禁令的期间是永久的。

<!-- source-p 1031 -->
<a id="43.29.4"></a>**43.29.4**

<!-- source-p 1032 -->
维努莱尤斯《禁令论》第四卷。

<!-- source-p 1033 -->
<a id="43.29.4.pr."></a>**序言**　若某人拘留一名自由人，而该自由人不知道自己的身份，但拘留者是出于恶意欺诈，仍应强制其出示此人。

<!-- source-p 1034 -->
<a id="43.29.4.1"></a>**1**　特雷巴提乌斯也说，若某人善意地将自由人当作奴隶买下并加以拘留，则不受此禁令拘束。

<!-- source-p 1035 -->
<a id="43.29.4.2"></a>**2**　任何时候都不得以恶意欺诈拘留自由人。有人甚至认为，不应给予任何短暂期限以便出示此人，因为应当为已经发生的行为承担惩罚。

<!-- source-p 1036 -->
<a id="43.29.4.3"></a>**3**　债权人无权援用禁令要求出示债务人；毕竟，没人会被强制出示躲藏的债务人，而应依裁判官告示对其财产采取执行程序。
