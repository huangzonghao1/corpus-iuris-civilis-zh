# D.43.17　论现占有者禁令（*Uti possidetis*）

> 底本：*Digesta Iustiniani*，EPUB book-43.xhtml，source-p 463–495。

<!-- source-p 463 -->
<a id="17"></a><a id="43.17"></a>**43.17.0**　现占有者禁令。

<!-- source-p 464 -->
<a id="43.17.1"></a>**43.17.1**

<!-- source-p 465 -->
乌尔比安《告示评注》第六十九卷。

<!-- source-p 466 -->
<a id="43.17.1.pr."></a>**原文**　裁判官说：“关于本案所涉房屋，你们双方中任何一方现占有该房屋，且其占有并非相对于另一方以暴力、秘密或可撤回许可取得的，我禁止任何人以暴力妨碍其继续如此占有。关于排水沟，我不颁布此项禁令。我准许在首次有机会提起程序之日起一年内请求；请求金额不得超过标的物的价值。”

<!-- source-p 467 -->
<a id="43.17.1.1"></a>**1**　本禁令是为土地占有人而写；裁判官认为，在土地占有方面，占有人应居于较有利地位。此为禁止性禁令，旨在维持占有。

<!-- source-p 468 -->
<a id="43.17.1.2"></a>**2**　提出此项禁令的理由，是占有应与所有权相区分。事实上，可能一方是占有人而非所有人，另一方虽为所有人却并非占有人；也可能同一人既是占有人又是所有人。

<!-- source-p 469 -->
<a id="43.17.1.3"></a>**3**　因此，在诉讼当事人之间发生所有权争议时，可能双方对于谁是占有人、谁是请求人意见一致，也可能意见不一。若意见一致，问题即已解决：经双方认可的占有人享有占有人的地位，对方则承担请求人的负担。但若双方争执谁占有，因为各自都主张自己占有得更多，那么在争议标的是土地时，他们应诉诸此项禁令。

<!-- source-p 470 -->
<a id="43.17.1.4"></a>**4**　此项禁令通常称为“现占有者禁令”，属于维持占有的禁令（其目的在于禁止对占有人施暴），因此列于“因暴力夺占而返还占有”禁令之后。后者是返还因暴力而丧失的占有；本禁令则保护占有，使其不致丧失。裁判官禁止对占有人施暴；前一禁令则针对占有人提出请求，本禁令则保护占有人。正如佩狄乌斯所说，一切占有争议，要么旨在使我们取回并未占有之物，要么旨在使我们可以继续占有现占有之物。返还占有，可以通过禁令程序或诉讼实现；维持占有则有两种途径，即抗辩或禁令。占有人可基于多种事由提出抗辩。

<!-- source-p 471 -->
<a id="43.17.1.5"></a>**5**　本项永久性禁令中包含下列文字：“你并非以暴力、秘密或可撤回许可从对方处占有该物。”

<!-- source-p 472 -->
<a id="43.17.1.6"></a>**6**　“现占有者”禁令保护不动产占有人。占有人并不因此取得主动请求的诉权，因为他已经处于占有状态，这一点对他已足够。

<!-- source-p 473 -->
<a id="43.17.1.7"></a>**7**　无论当事人主张占有整个土地、其中确定的一部分，还是按未分割份额占有，均可适用本禁令。

<!-- source-p 474 -->
<a id="43.17.1.8"></a>**8**　毫无疑问，只要可以占有，本禁令就适用于一切不动产占有。

<!-- source-p 475 -->
<a id="43.17.1.9"></a>**9**　裁判官在禁令中所说“你们双方中任何一方并非以暴力、秘密或可撤回许可从另一方处占有”，其意在于：若某人以暴力、秘密或可撤回许可占有，且该占有是从第三人处取得，则其占有对他有利；但若是从其对方处取得，则不得仅因其从对方处占有就使其胜诉。显然，此类有瑕疵的占有不应产生有利效果。

<!-- source-p 476 -->
<a id="43.17.2"></a>**43.17.2**

<!-- source-p 477 -->
保罗《告示评注》第六十五卷。

<!-- source-p 478 -->
[原文作 Usta，疑为 iusta。]占有相对于其他人是正当还是不正当，在此项禁令中并不重要：无论占有为何种性质，占有人仅因其为占有人，即享有比非占有人更多的权利。

<!-- source-p 479 -->
<a id="43.17.3"></a>**43.17.3**

<!-- source-p 480 -->
乌尔比安《告示评注》第六十九卷。

<!-- source-p 481 -->
<a id="43.17.3.pr."></a>**原文**　如果两人都主张完整占有，应如何处理？我们来讨论这种情形如何发生，例如一方主张其占有有正当原因，另一方的占有则不正当。我基于正当原因占有，你以暴力或秘密占有：若你是从我处取得占有，则我依据禁令居于优先地位；若你并非从我处取得，则我们双方都不能胜诉，因为你占有，我也占有。

<!-- source-p 482 -->
<a id="43.17.3.1"></a>**1**　本禁令是双方禁令；可适用者既是原告，也是被告。

<!-- source-p 483 -->
<a id="43.17.3.2"></a>**2**　此项禁令足以保护在自己土地上被禁止施工的人。阻止我行使对自己占有物的占有，就是对我制造占有争议。

<!-- source-p 484 -->
<a id="43.17.3.3"></a>**3**　房客阻止房屋所有人修缮房屋时，裁判官认为同样可以适用“现占有者”禁令；并应理解为，所有人禁止房客取得占有，而非禁止其居住。

<!-- source-p 485 -->
<a id="43.17.3.4"></a>**4**　再看这样的情形：你的权利前手把我土地上的葡萄藤引到他自己的树上，法律后果如何？庞波尼乌斯说，你可以向他提出告知并剪除葡萄藤；拉贝奥也这样写道。或者，你应就葡萄根所在之地适用“现占有者”禁令。因为若他以暴力阻止你剪除或移引葡萄藤，便是在妨碍你占有。庞波尼乌斯说，禁止某人耕作土地，也就是禁止其占有土地。

<!-- source-p 486 -->
<a id="43.17.3.5"></a>**5**　再看这样的情形：有人主张，其伸入邻地上空的突出部分并无法律依据；双方之间是否可以适用“现占有者”禁令？卡西乌斯记载说，该禁令对双方都不适用，因为一方占有土地，另一方则随房屋占有其上方空间。

<!-- source-p 487 -->
<a id="43.17.3.6"></a>**6**　拉贝奥还写道：“我的房屋有突出部分伸入你的房屋；如果我们占有该突出部分覆盖的地点，你便与我发生禁令争议。”为便于我维持对该突出部分的占有，我是否可以与你依下列措辞提出禁令：“关于现由你们占有的、突出部分所自出的房屋……”？

<!-- source-p 488 -->
<a id="43.17.3.7"></a>**7**　但若在我占有的房屋上方有一间楼上房间，另一人如同所有人一般居住其中，拉贝奥说我可以适用“现占有者”禁令，而住在楼上房间的人不可以；因为地上建筑物总是从属于土地。显然，若楼上房间有从公共道路通行的入口，拉贝奥说，似乎不是占有“kruptas”的人占有房屋，而是其房屋位于“kruptas essententiarum”之上的人占有。此处文字确有疑误；这一判断应适用于楼上房间可从公共道路进入的情形。除此之外，地上建筑权人可使用裁判官为其设置的专门禁令及诉权。土地所有人无论相对于他人还是地上建筑权人，均在“现占有者”禁令中居于优先地位；但裁判官会依租赁约定保护地上建筑权人。庞波尼乌斯也认可此说。

<!-- source-p 489 -->
<a id="43.17.3.8"></a>**8**　为保存财产而获准进入占有的债权人，不能适用“现占有者”禁令；这是正确的，因为他们并未占有。因保管目的而获准占有的其他人，也应作相同处理。

<!-- source-p 490 -->
<a id="43.17.3.9"></a>**9**　如果我的邻人把灰泥一部分抹在我的墙上，另一部分抹在自己的墙上，我可以有效地提出“现占有者”禁令，要求其拆除灰泥。

<!-- source-p 491 -->
<a id="43.17.3.10"></a>**10**　我从一个明知以暴力取得占有的人处受领土地，不因此被视为以暴力占有。

<!-- source-p 492 -->
<a id="43.17.3.11"></a>**11**　在此项禁令中，判决金额以标的物本身的估价为准。“标的物值多少”，应理解为“各当事人维持占有的利益有多少”。塞尔维乌斯认为，占有应按标的物本身的价值估价；但绝不能这样认为，因为物的价格与占有的价值相去甚远。

<!-- source-p 493 -->
<a id="43.17.4"></a>**43.17.4**

<!-- source-p 494 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 495 -->
总之，我认为，也应在用益权人之间颁布此项禁令，包括一方主张用益权、另一方主张占有的情形。若有人主张其享有用益权中的占有，也应作同样处理；庞波尼乌斯亦如此记载。同理，若一方主张使用权、另一方主张收益权，也应向双方颁布此项禁令。
