# D.43.27 论砍伐树木（*De arboribus caedendis*）

<!-- source-p 984 -->
<a id="27"></a><a id="43.27"></a>**43.27.0**　论砍伐树木。

<!-- source-p 985 -->
<a id="43.27.1"></a>**43.27.1**

<!-- source-p 986 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 987 -->
<a id="43.27.1.pr."></a>**序言**　裁判官说：“若有树木从你的建筑物上方伸入他人的建筑物，且因你不肯将其移除而致如此，我禁止以暴力阻止他人移除该树并将其据为己有。”

<!-- source-p 988 -->
<a id="43.27.1.1"></a>**1**　本项禁令属于禁止性禁令。

<!-- source-p 989 -->
<a id="43.27.1.2"></a>**2**　若树木伸入他人的建筑物，裁判官命令移除的是整棵树，还是仅移除越界伸出的部分，存在疑问。鲁提利乌斯认为应连根砍除；多数人认为此说较为妥当。拉贝奥说，若树木所有人不予移除，则可以准许受该树妨碍的人自行砍伐，并取走木材。

<!-- source-p 990 -->
<a id="43.27.1.3"></a>**3**　“树木”一词也包括葡萄藤。

<!-- source-p 991 -->
<a id="43.27.1.4"></a>**4**　不仅建筑物所有人可以提起本项禁令，用益权人也可以提起，因为树木伸入建筑物同样与用益权人的利益有关。

<!-- source-p 992 -->
<a id="43.27.1.5"></a>**5**　此外，应当承认，若树木伸入共有建筑物，各共有人均可提起本项禁令，且每人均可就全部请求；因为各共有人也都可以请求确认地役权。

<!-- source-p 993 -->
<a id="43.27.1.6"></a>**6**　裁判官说：“若因你不肯将树木移除而致如此，我禁止以暴力阻止他人移除该树。”因此，首先给予你移除树木的机会；若你不予移除，裁判官随后禁止以暴力阻止邻人愿意移除该树。

<!-- source-p 994 -->
<a id="43.27.1.7"></a>**7**　裁判官接着说：“若有树木从你的田地上方伸入他人的田地，且因你不肯修剪至距地面十五罗马尺以上而致如此，我禁止以暴力阻止他人按此方式修剪，并将木材据为己有。”

<!-- source-p 995 -->
<a id="43.27.1.8"></a>**8**　裁判官所说的规则，《十二表法》也意在实现，即将树木枝条修剪至距地面十五尺以上。制定此规则，是为避免树木的阴影损害邻近土地。

<!-- source-p 996 -->
<a id="43.27.1.9"></a>**9**　本项禁令两部分的区别如下：若树木伸入建筑物，则命令将树木砍除；若树木伸入田地，则仅要求将其修剪至距地面十五尺以上。

<!-- source-p 997 -->
<a id="43.27.2"></a>**43.27.2**

<!-- source-p 998 -->
庞波尼《萨宾评注》第三十四卷。

<!-- source-p 999 -->
若树木因风从邻人的土地倾斜至你的土地，你可以依据《十二表法》就移除该树提起诉讼，主张邻人无权使该树保持此种状态。
