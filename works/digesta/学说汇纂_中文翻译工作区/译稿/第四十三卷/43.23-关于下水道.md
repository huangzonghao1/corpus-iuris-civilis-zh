# D.43.23 关于下水道（*De cloacis*）

<!-- source-p 692 -->
<a id="23"></a><a id="43.23"></a>**43.23.0**　关于下水道。

<!-- source-p 693 -->
<a id="43.23.1"></a>**43.23.1**

<!-- source-p 694 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 695 -->
<a id="43.23.1.pr."></a>**序言**　裁判官说：“我禁止妨碍他人清理或修缮本案所涉下水道，该下水道从其房屋通至你的房屋。我将命令其就因工程瑕疵所造成的潜在损害提供担保。”

<!-- source-p 696 -->
<a id="43.23.1.1"></a>**1**　本标题下裁判官规定了两项禁令：一项为禁止性禁令，另一项为恢复原状的禁令；第一项是禁止性禁令。

<!-- source-p 697 -->
<a id="43.23.1.2"></a>**2**　裁判官通过这些禁令确保下水道得到清理和修缮；二者对于城市卫生及安全都很重要。若下水道不予修缮，其污物会造成有害空气并导致建筑物倒塌。

<!-- source-p 698 -->
<a id="43.23.1.3"></a>**3**　此项禁令针对私人下水道；公共下水道则应由公共机构负责管理。

<!-- source-p 699 -->
<a id="43.23.1.4"></a>**4**　所谓下水道，是供污物流过的中空通道。

<!-- source-p 700 -->
<a id="43.23.1.5"></a>**5**　首先发布的这项禁令是禁止性的，旨在禁止邻人以暴力妨碍下水道的清理或修缮。

<!-- source-p 701 -->
<a id="43.23.1.6"></a>**6**　下水道一词也包括管道和导管。

<!-- source-p 702 -->
<a id="43.23.1.7"></a>**7**　修缮和清理下水道似乎关系公共利益，因此裁判官认为，无须在禁令中加入“该人此前使用下水道时并非以暴力、非秘密，也非基于可撤销的许可”等条件。这样，即使某人此前的使用方式有此类瑕疵，也不妨碍其修缮或清理下水道。

<!-- source-p 703 -->
<a id="43.23.1.8"></a>**8**　随后裁判官说：“从其房屋通至你的房屋。”此处的“房屋”应理解为所有建筑物，也就是从其建筑物通到你的建筑物。此外，拉贝奥认为，即使下水道位于两所房屋之间的空地，也适用此项禁令；例如，下水道从城市建筑通至相邻田地时亦然。

<!-- source-p 704 -->
<a id="43.23.1.9"></a>**9**　拉贝奥还认为，若有人想将私人下水道接入公共下水道，也应保护其免受暴力妨碍。庞波尼写道，若有人要修建能够通入公共下水道的下水道，也不应阻止他。

<!-- source-p 705 -->
<a id="43.23.1.10"></a>**10**　裁判官所说的“通至”，意为从其房屋通到你的房屋，也就是“指向、延伸至并到达”。

<!-- source-p 706 -->
<a id="43.23.1.11"></a>**11**　此项禁令既适用于直接相邻的邻人，也可针对更远处的邻人；下水道也可能经过这些人的房屋。

<!-- source-p 707 -->
<a id="43.23.1.12"></a>**12**　因此，法比乌斯·梅拉写道，为清理下水道，可以依据此项禁令进入邻人房屋并拆开地板。庞波尼写道，应谨慎行事，以免因此触发潜在损害担保。但若进入房屋只是为修缮下水道所必需，且行为人愿意修复拆开的部分，则不触发该担保。

<!-- source-p 708 -->
<a id="43.23.1.13"></a>**13**　若有人在我清理或修缮下水道时发出新工程通知，可以正确地认为，我无须理会该通知，仍可继续修缮已经开始的工程。

<!-- source-p 709 -->
<a id="43.23.1.14"></a>**14**　若因工程瑕疵造成损害，裁判官又承诺提供潜在损害担保：正如应允许修缮和清理下水道，也应防止他人房屋遭受损害。

<!-- source-p 710 -->
<a id="43.23.1.15"></a>**15**　随后裁判官说：“凡你在公共下水道上实施或投入的行为，以致其使用变差的，均应恢复原状。我也将发布禁令，禁止实施或投入任何此类行为。”

<!-- source-p 711 -->
<a id="43.23.1.16"></a>**16**　此项禁令适用于公共下水道，禁止任何人在其中投入物品或实施行为，以致其使用变差或将来可能变差。

<!-- source-p 712 -->
<a id="43.23.2"></a>**43.23.2**

<!-- source-p 713 -->
维努莱乌斯《禁令论》第一卷。

<!-- source-p 714 -->
虽然本项禁令所涵盖的是修缮下水道，而非新建下水道，拉贝奥仍说，应同样发布禁令，不得以暴力妨碍某人建造下水道，因为二者具有相同的效用。裁判官确曾如此发布禁令，禁止以暴力妨碍某人在公共场所建造下水道；奥菲利乌斯和特雷巴提乌斯也赞同此说。维努莱乌斯本人认为，禁令应准许清理或修复已经建成的下水道；至于新建下水道，只有负责管理公共道路的人可以准许。
