# D.43.28 论拾取橡实（*De glande legenda*）

<!-- source-p 1000 -->
<a id="28"></a><a id="43.28"></a>**43.28.0**　论拾取橡实。

<!-- source-p 1001 -->
<a id="43.28.1"></a>**43.28.1**

<!-- source-p 1002 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 1003 -->
<a id="43.28.1.pr."></a>**序言**　裁判官说：“对于从他人的土地落到你土地上的橡实，我禁止以暴力阻止他每隔三日拾取并带走。”

<!-- source-p 1004 -->
<a id="43.28.1.1"></a>**1**　“橡实”一词包括所有果实。
