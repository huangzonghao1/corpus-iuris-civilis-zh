# D.43.16 论暴力与武装暴力（*De vi et de vi armata*）

<!-- source-p 334 -->
<a id="16"></a><a id="43.16"></a>**43.16.0**　论暴力与武装暴力。

<!-- source-p 335 -->
<a id="43.16.1"></a>**43.16.1**

<!-- source-p 336 -->
乌尔比安《告示评注》第六十九卷。

<!-- source-p 337 -->
<a id="43.16.1.pr."></a>**序言**　裁判官说：“无论你本人还是你的家内奴隶群体以暴力将某人驱逐之处，我将在一年内仅就该人当时在那里拥有的全部物品给予诉权；一年以后，则仅就到达实施暴力驱逐者手中的物品给予诉权。”

<!-- source-p 338 -->
<a id="43.16.1.1"></a>**1**　这项禁令是为遭暴力驱逐的人提出的；向遭暴力驱逐者提供救济确属最公平之举。因此，提出这项禁令，是为了使其恢复占有。

<!-- source-p 339 -->
<a id="43.16.1.2"></a>**2**　此外，《尤利娅公法》和《尤利娅私法》以及元首敕令，也都设法防止任何人实施暴力。

<!-- source-p 340 -->
<a id="43.16.1.3"></a>**3**　这项禁令并非适用于一切暴力，而是适用于遭剥夺占有的人。但它仅适用于严重暴力，也仅适用于从土地上被驱逐的人，例如从土地或建筑物中被驱逐；对其他情形则不适用。

<!-- source-p 341 -->
<a id="43.16.1.4"></a>**4**　若有人从空地上被驱逐，毫无疑问可以适用该禁令。总而言之，凡有人从与土地相连的财物上被驱逐，均可适用此禁令；无论其被暴力驱逐之处为何种场所，均可适用。

<!-- source-p 342 -->
<a id="43.16.1.5"></a>**5**　因此，即使某人是从一处地上权建筑物中被驱逐，也显然可以适用该禁令。

<!-- source-p 343 -->
<a id="43.16.1.6"></a>**6**　毫无疑问，这项禁令不适用于动产；对此可以提起盗窃之诉或强夺财物之诉，也可以提起出示之诉。但若某些物品位于被驱逐者离开的土地或房屋内，则毫无疑问，对这些物品也可适用该禁令。

<!-- source-p 344 -->
<a id="43.16.1.7"></a>**7**　若有人被暴力逐出船舶，则不适用此禁令；以从车辆中被拖下的人为例，没人说此人可以援用这项禁令。

<!-- source-p 345 -->
<a id="43.16.1.8"></a>**8**　但若有人从木造房屋中被驱逐，没人怀疑可以适用该禁令，因为凡与土地相连的事物，无论其为何种形态，从中被暴力驱逐者均可援用该禁令。

<!-- source-p 346 -->
<a id="43.16.1.9"></a>**9**　被驱逐者是指占有人，无论其是以市民法上的方式占有，还是以自然方式占有；因为自然占有也属于这项禁令的适用范围。

<!-- source-p 347 -->
<a id="43.16.1.10"></a>**10**　例如，丈夫将某物赠与妻子后，若妻子被驱逐，她可以援用该禁令；但承租人则不能。

<!-- source-p 348 -->
<a id="43.16.1.11"></a>**11**　裁判官说：“你本人或你的家内奴隶群体驱逐了他。”提及家内奴隶群体是有道理的：因为“你本人驱逐”一语指的是亲自实施驱逐的人，并不适用于其家内奴隶群体实施驱逐的情形——毕竟，若是我的家内奴隶群体驱逐了某人，不能说是我本人驱逐了他。因此，公式中还应加上“或你的家内奴隶群体驱逐了他”。

<!-- source-p 349 -->
<a id="43.16.1.12"></a>**12**　命令或指使他人驱逐某人的，也被视为实施了驱逐。因为认为是亲手驱逐还是借助他人驱逐，并无多大区别。因此，若我的家内奴隶群体依我的意思实施驱逐，也视为我本人实施了驱逐。

<!-- source-p 350 -->
<a id="43.16.1.13"></a>**13**　萨宾认为，若实际代理人实施驱逐，可以针对两人中的任一人提起诉讼，即本人或代理人；若其中一人已支付诉讼标的估价，另一人便可因此免责。不过，受他人命令而实施驱逐的人并不因此免责，正如受命杀人者亦不免责。若代理人是冒名的，则应仅对该代理人本人适用禁令。萨宾的意见是正确的。

<!-- source-p 351 -->
<a id="43.16.1.14"></a>**14**　即使他人实施驱逐而我随后予以追认，也有人依据萨宾和卡西乌斯的意见认为：既然追认等同于委托，我便被视为实施了驱逐，并须受此禁令拘束。这一意见是正确的；因为在不法行为中，追认应当等同于委托。

<!-- source-p 352 -->
<a id="43.16.1.15"></a>**15**　因此，“或你的家内奴隶群体驱逐了他”这一补充，理应适用于我的家内奴隶群体以暴力实施驱逐的情形。至于我若命令他们驱逐某人，则应视为我本人实施了驱逐。若主人没有下令，便不应因其奴隶的行为而加重其责任，即使奴隶并非奉其命令而驱逐了某人也是如此。主人不会因此受到加重：因为若有利益到达主人手中，他可以予以返还；若没有利益到达，他可以就奴隶的不法行为交付奴隶承担诺克萨责任，从而免于赔偿。主人不应将被迫交付奴隶承担诺克萨责任视为自身损失，因为奴隶实施的行为本可使主人处境恶化。

<!-- source-p 353 -->
<a id="43.16.1.16"></a>**16**　“家内奴隶群体”一语包括奴隶。

<!-- source-p 354 -->
<a id="43.16.1.17"></a>**17**　但问题是，这里的“家内奴隶群体”指多少名奴隶：必须是多人，还是两人、三人也算？更正确的说法是，即使只有一名奴隶以暴力驱逐某人，在这项禁令中也视为家内奴隶群体实施了驱逐。

<!-- source-p 355 -->
<a id="43.16.1.18"></a>**18**　应当说，“家内奴隶群体”一语也包括那些被我们置于奴隶地位的人。

<!-- source-p 356 -->
<a id="43.16.1.19"></a>**19**　然而，若有人否认自己有义务为奴隶或家内奴隶群体辩护，就应强制其接受这项禁令；目的仅在于使其返还到达其手中的利益。

<!-- source-p 357 -->
<a id="43.16.1.20"></a>**20**　若家子或雇工以暴力驱逐某人，可以适用有益禁令。

<!-- source-p 358 -->
<a id="43.16.1.21"></a>**21**　若在自由身份诉讼开始后，我对某人援用此禁令，而该诉讼是请求判定其摆脱奴隶身份而成为自由人，或反向请求判定其为奴隶；若此人最终被判定为自由人，且查明我是在其不知情的情况下被其奴隶以暴力驱逐的，则应恢复我的占有。

<!-- source-p 359 -->
<a id="43.16.1.22"></a>**22**　奴隶、代理人或承租人所持有的财物，视为由主人占有。因此，这些人遭驱逐时，主人也视为被剥夺占有，即使主人不知道他们已被驱逐亦然，因为主人正是通过他们占有财物。若我通过其他任何人占有，而该人被驱逐，毫无疑问我也可以援用此禁令。

<!-- source-p 360 -->
<a id="43.16.1.23"></a>**23**　这项禁令仅适用于被驱逐时正在占有的人；因为只有占有人才会被视为遭到驱逐。

<!-- source-p 361 -->
<a id="43.16.1.24"></a>**24**　无论某人是以实际控制还是仅凭意思维持占有，其遭驱逐时都显然属于被暴力驱逐。因此，若有人离开自己的土地或房屋时未留下任何家属，稍后返回却被阻止进入该土地或房屋；或者有人在途中拦住他并自行占有该物，他都视为被暴力驱逐。因为你剥夺了他以占有意思维持的占有，尽管他当时并未实际控制该物。

<!-- source-p 362 -->
<a id="43.16.1.25"></a>**25**　我曾听普罗库鲁斯举例说明，通常所说的夏季和冬季牧地，其占有可仅凭意思维持。实际上，凡离开某处财产时并无放弃占有之意的，均属此类。

<!-- source-p 363 -->
<a id="43.16.1.26"></a>**26**　更妥当的意见是：某人既未凭意思也未实际占有，只是被阻止进入并开始占有，不应视为遭驱逐。因为被驱逐的是丧失占有的人，而非尚未取得占有的人。

<!-- source-p 364 -->
<a id="43.16.1.27"></a>**27**　卡西乌斯写道，允许以暴力抗拒暴力；这项权利是依据自然法取得的。他说，可以此为证：允许以武器抵御武器。

<!-- source-p 365 -->
<a id="43.16.1.28"></a>**28**　应当将以下情形界定为以暴力占有：驱逐原占有人后，以暴力取得占有；或者某人专为此目的而装备并前来，违背善良风俗，借助他人力量防止自己进入占有时遭人阻止。但拉贝奥说，以暴力保有自己占有的人，并非以暴力占有。

<!-- source-p 366 -->
<a id="43.16.1.29"></a>**29**　同一位拉贝奥还说，某人因惧怕人群而惊恐逃走，应视为遭暴力驱逐。但庞波尼乌斯说，没有身体强力介入，就不存在暴力。因此，若某人被后来赶到的一群人驱走，而这些人以暴力夺取占有，也应视为其遭暴力驱逐。

<!-- source-p 367 -->
<a id="43.16.1.30"></a>**30**　若某人以暴力占有我的财物，而他又被第三人驱逐，他可以援用此禁令。

<!-- source-p 368 -->
<a id="43.16.1.31"></a>**31**　遭暴力驱逐者因被驱逐而遭受的任何损害，都应得到恢复；因为应使其恢复到未遭驱逐时本会处于的原有状态。

<!-- source-p 369 -->
<a id="43.16.1.32"></a>**32**　若我被暴力驱逐的土地已返还给我，但被暴力取走的其他物品没有返还，仍应适用这项禁令，因为我确实遭到了暴力驱逐。不过，若某人愿意就土地占有援用此禁令，而就动产提起出示之诉，可以由其自行决定；尤利安正是这样写的。他还写道，若有人愿意就这类物品提起强夺财物之诉，也可以如此处理。

<!-- source-p 370 -->
<a id="43.16.1.33"></a>**33**　裁判官所说的“他当时在那里拥有的全部物品”，应理解为包括所有物品，不仅包括其自有物，还包括寄存在其处、借用给他的、质押给他的物品，以及其享有使用权、用益权或保管责任的物品，也包括出租给他的物品。裁判官既然使用“拥有”一词，这些情形便都包括在“拥有”之中。

<!-- source-p 371 -->
<a id="43.16.1.34"></a>**34**　裁判官加上“当时在那里”一语，极为恰当。“当时”应理解为“遭驱逐之时”。因此，即使某物后来不再位于该处，也应认定其属于此禁令的范围。由此，即使人或牲畜在遭驱逐后死亡，也可以适用此禁令。

<!-- source-p 372 -->
<a id="43.16.1.35"></a>**35**　尤利安写道，某人从有人居住的土地上以暴力驱逐他人，即使这些人并非因其过失而死亡，较妥当地说，也应要求他通过此禁令返还他们的估价；正如即使奴隶已经死亡，窃贼仍须对其负责。他还说，同理，若乡舍或房屋因火灾被毁，也应责令其返还其价值。因为他说，某人一旦实施驱逐，便应视为是他导致无法返还。

<!-- source-p 373 -->
<a id="43.16.1.36"></a>**36**　因此，他说，实施暴力驱逐者，以及以暴力停止占有、但没有恶意欺诈者，均受此禁令拘束。

<!-- source-p 374 -->
<a id="43.16.1.37"></a>**37**　裁判官还说“在那里”，是为了不让任何人将其并未在那里拥有的物品也纳入请求。

<!-- source-p 375 -->
<a id="43.16.1.38"></a>**38**　裁判官所说的“在那里”，究竟应如何理解？是指某人被暴力驱逐之处，还是指全部占有范围？更妥当的说法是：不能将其限于某个角落或某人当时所在之处，而应包括其被驱逐时丧失占有的全部范围。

<!-- source-p 376 -->
<a id="43.16.1.39"></a>**39**　这项禁令适用一年的有效期间。

<!-- source-p 377 -->
<a id="43.16.1.40"></a>**40**　在这项禁令下，收益自某人遭驱逐之日起计算；其他禁令则自其发布之日起计算，不溯及既往。该规则也适用于当时位于该处的动产，因为这些物品的收益同样自某人遭暴力驱逐之日起计算。

<!-- source-p 378 -->
<a id="43.16.1.41"></a>**41**　这项禁令不仅考虑收益，也应考虑其他利益。维维亚努斯记载，在这项禁令下，遭驱逐者若未遭暴力驱逐本会拥有或取得的一切，都应予以返还，或者由法官评估其诉讼标的金额；其所获数额应等于其未遭暴力驱逐时所具有的利益。

<!-- source-p 379 -->
<a id="43.16.1.42"></a>**42**　即使某人并不占有，也可以依据“因暴力”禁令责令其返还。

<!-- source-p 380 -->
<a id="43.16.1.43"></a>**43**　由于这项禁令涉及严重的不法行为，曾有人问：被释奴能否对其保护人提起此禁令，子女能否对父母提起？更妥当的意见是，不应准许被释奴对保护人、子女对父母提起该禁令；最好允许他们提起事实诉权。但若保护人对被释奴，或父母对子女使用了武装暴力，则不同：此时可以适用该禁令。

<!-- source-p 381 -->
<a id="43.16.1.44"></a>**44**　继承人及其他继受人也可以援用此禁令。

<!-- source-p 382 -->
<a id="43.16.1.45"></a>**45**　只有占有人才能援用“因暴力”禁令，这一点可由维维亚努斯所记载的例子证明：若某人以暴力驱逐了我，却没有驱逐我的奴隶，我便不能依据此禁令起诉，因为我仍通过未被驱逐的奴隶维持占有。

<!-- source-p 383 -->
<a id="43.16.1.46"></a>**46**　维维亚努斯还记载：某人以暴力驱逐了部分奴隶，却扣留其他奴隶，将他们捆绑，或向他们发号施令；在这种情况下，你应被视为遭暴力驱逐，因为当奴隶由他人占有时，你便停止了占有。他说，对部分奴隶所作的论述，也同样适用于全部奴隶：例如，若无人被驱逐，但进入占有的人开始占有这些奴隶，也属于此种情形。

<!-- source-p 384 -->
<a id="43.16.1.47"></a>**47**　维维亚努斯探讨了以下问题：若在他人占有某物时，我也进入占有，并未驱逐原占有人，而只是将其捆绑、强迫其劳作，情况会如何？他说，问题就在于此。我认为，更妥当的看法是，连被捆绑在当地的人也应视为遭到驱逐。

<!-- source-p 385 -->
<a id="43.16.1.48"></a>**48**　基于这项禁令，可以对继承人、遗产占有人及其他继受人提起事实诉权，责任以到达其手中的利益为限。

<!-- source-p 391 -->
<a id="43.16.3.pr."></a>**序言**　若某人是以武装暴力被驱逐，也适用上述规则，因为针对死者的不法行为，可以就到达其继承人手中的利益提起诉讼。只要继承人没有获利便已足够，无须让其再遭受损失。

<!-- source-p 392 -->
<a id="43.16.3.1"></a>**1**　针对继承人及其他继受人的这项诉权永久存在，因为其中包含对财物本身的追索。

<!-- source-p 393 -->
<a id="43.16.3.2"></a>**2**　应如何理解“以武器驱逐”？武器包括一切兵器，棍棒和石块也包括在内，而不仅是剑、长矛和框矛（*frameae*，即 *rhomphaeae*）。

<!-- source-p 394 -->
<a id="43.16.3.3"></a>**3**　显然，即使只有一人或两人持有棍棒或剑，占有人也应视为遭武装暴力驱逐。

<!-- source-p 395 -->
<a id="43.16.3.4"></a>**4**　甚至可以说，即使来人起初没有武器，但在冲突过程中拿起棍棒或石块，也构成武装暴力。

<!-- source-p 396 -->
<a id="43.16.3.5"></a>**5**　有人持械前来，即便驱逐时没有使用武器，但确实实施了驱逐，也视为实施了武装暴力；因为武器本身造成的恐惧，足以使人被视为以武器驱逐。

<!-- source-p 397 -->
<a id="43.16.3.6"></a>**6**　若某人看见持械者，而这些人正前往别处，因害怕他们而逃走，不视为遭驱逐；因为持械者并非为此而来，而是另有去向。

<!-- source-p 398 -->
<a id="43.16.3.7"></a>**7**　同理，若某人听说持械者将至，因恐惧而离开占有，无论他听到的消息是真是假，都应说其并未遭武装暴力驱逐；除非这些人实际占有了该物。

<!-- source-p 399 -->
<a id="43.16.3.8"></a>**8**　但若原占有人欲进入占有，而已经侵占该处的持械者阻止了他，则应视为其遭武装暴力驱逐。

<!-- source-p 400 -->
<a id="43.16.3.9"></a>**9**　因此，我们可以持械抵御持械前来之人，但必须立即进行，不得间隔一段时间。须知，不仅可以抵抗以防自己遭驱逐；即使已遭驱逐，也可以立即、连续地将其驱逐出去，而不能等过一段时间再行驱逐。

<!-- source-p 401 -->
<a id="43.16.3.10"></a>**10**　代理人持械前来时，也视为主人本人实施了驱逐，无论主人曾下令，还是如尤利安所说，事后予以追认。

<!-- source-p 402 -->
<a id="43.16.3.11"></a>**11**　对家内奴隶群体也应作同样处理：家内奴隶群体未奉我命令而自行持械前来时，应视为前来者是奴隶群体而非我本人，除非我曾下令或事后追认。

<!-- source-p 403 -->
<a id="43.16.3.12"></a>**12**　这项禁令也适用于以恶意欺诈使某人遭武装暴力驱逐的人。一年以后，仍给予诉权，但仅限于到达阻止其占有者手中的利益。

<!-- source-p 404 -->
<a id="43.16.3.13"></a>**13**　有必要为用益权人设置禁令，这一点可由如下禁令公式看出：“若某人被阻止使用、享用土地的用益权。”

<!-- source-p 405 -->
<a id="43.16.3.14"></a>**14**　以暴力驱逐正在使用、享用用益权的人，或在其离开土地但并无放弃用益权之意时不允许其返回的人，视为阻止他人使用、享用用益权。但若某人从一开始就阻止他人着手使用、享用用益权，则不适用这项禁令。应如何处理？用益权人应提起用益权确认之诉。

<!-- source-p 406 -->
<a id="43.16.3.15"></a>**15**　这项禁令适用于被阻止使用、享用土地的人；被阻止使用、享用建筑物的人也可适用。进而可以说，若某人被阻止使用、享用动产，这项禁令不适用于动产；但若动产是土地的附属物，则不同：若这些动产位于该处，也应说这项禁令应适用于它们。

<!-- source-p 407 -->
<a id="43.16.3.16"></a>**16**　若遗留的不是用益权，而是单纯使用权，也可以适用这项禁令。无论使用权或用益权基于何种原因设立，均适用该禁令。

<!-- source-p 408 -->
<a id="43.16.3.17"></a>**17**　凡曾以用益权为名、以某种方式处于类似占有状态的人，均可援用这项禁令。但若其遭阻止后发生身份减等或死亡，便可正确地说，其继承人及继受人也可以援用该禁令；不过，这不是为了将来重新设立用益权，而是为了弥补过去的权利状态及既往损失。

<!-- source-p 409 -->
<a id="43.16.3.18"></a>**18**　同样，继承人也应提起事实诉权，责任以到达其手中的利益为限。

<!-- source-p 455 -->
<a id="43.16.18.pr."></a>**序言**　出租土地的人将土地出售，命令买受人进入空置占有，但承租人阻止其进入；此后，买受人以暴力驱逐了承租人。有人询问应如何适用“因暴力”禁令。意见认为，承租人应依该禁令对出卖人负责，因为承租人阻止出卖人本人，或阻止出卖人依其意思派来的人进入，并无区别。只有土地已交付买受人后，才可认为出卖人放弃了占有；毕竟，若买受人尚未取得占有，没人会因为买受人而放弃自己的占有。后来使用暴力的买受人也应依该禁令对承租人负责，因为土地占有是从出卖人处以暴力取得的，而出卖人此前已丧失占有。有人询问：若买受人奉出卖人之意，后来以暴力驱逐了承租人，是否应给予买受人救济？我认为，不应救济接受违法委托的人。
