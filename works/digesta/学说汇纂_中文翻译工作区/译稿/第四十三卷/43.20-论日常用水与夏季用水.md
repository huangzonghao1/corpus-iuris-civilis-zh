# D.43.20　论日常用水与夏季用水（*De aqua cottidiana et aestiva*）

> 底本：*Digesta Iustiniani*，EPUB book-43.xhtml，source-p 567–642。

<!-- source-p 567 -->
<a id="20"></a><a id="43.20"></a>**43.20.0**　论日常用水与夏季用水。

<!-- source-p 568 -->
<a id="43.20.1"></a>**43.20.1**

<!-- source-p 569 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 570 -->
<a id="43.20.1.pr."></a>**原文**　裁判官说：“关于本案所涉水，你在本年度内曾以非暴力、非秘密、非可撤回许可的方式从对方处引水；我禁止任何人以暴力妨碍你继续如此引水。”

<!-- source-p 571 -->
<a id="43.20.1.1"></a>**1**　本项禁令属于禁止性禁令，有时也具有返还性；其适用于日常用水。

<!-- source-p 572 -->
<a id="43.20.1.2"></a>**2**　所谓日常用水，并非指每天实际都引取的水，而是指某人若愿意便可每天使用的水；即使冬季引水并不便利，只要能够引取，仍属日常用水。

<!-- source-p 573 -->
<a id="43.20.1.3"></a>**3**　水有两类：日常用水和夏季用水。二者的区别在使用方式，而不在权利性质。日常用水，是指通常可以持续引取的水，不论夏季还是冬季；即使有时没有实际引取，也仍属日常用水。若某项地役权因间隔而分时使用，该水也称为日常用水。夏季用水，则是仅在夏季使用才便利的水，就如我们所说的夏季衣物、夏季牧场和夏季营地：有时冬季也会使用，但通常在夏季使用。我认为，应结合使用人的意图和地点的自然条件区分夏季用水与日常用水。若某水源本可全年持续引取，但我仅在夏季使用，应称为夏季用水；若某水源只能在夏季引取，也应称为夏季用水；若地点的自然条件只允许夏季有水，也应正确地称为夏季用水。

<!-- source-p 574 -->
<a id="43.20.1.4"></a>**4**　禁令中的“你在本年度内曾引水”，意思是：并非要求每天引水，只要本年度内曾在某一天或某一夜引过水即可。因此，日常用水是指可以在冬夏任一季节每天引取的水，即便只曾在某一时段实际引取过；夏季用水则是指虽可每天引取，但只在夏季引取，而冬季不引取的水——并非因为冬季不能引取，而是通常不在冬季引取。

<!-- source-p 575 -->
<a id="43.20.1.5"></a>**5**　裁判官在本项禁令中只谈到常流水，因为只有常流水才能被引取。

<!-- source-p 576 -->
<a id="43.20.1.6"></a>**6**　虽说本项禁令适用于常流水，但仅适用于可以引取的常流水。有些水虽为常流水却无法引取，例如井水，或潜藏地下、无法流出地面供人使用的水。不过，这些不能引取的水可以设定汲水地役权。

<!-- source-p 577 -->
<a id="43.20.1.7"></a>**7**　关于水以及水源的禁令，似乎适用于从水源处引出的水，而非其他来源之水；因为此类水可以依市民法设定地役权。

<!-- source-p 578 -->
<a id="43.20.1.8"></a>**8**　所谓水源，是指水开始涌出的地方：若水源于泉，泉本身就是水源；若水来自河流或湖泊，则从河流或湖泊引水进入首条水沟的初始入口或起点，就是水源。显然，若水由渗流而来，先流至某处并在那里显现，则水首次涌出之处就是水源。

<!-- source-p 579 -->
<a id="43.20.1.9"></a>**9**　无论水权是以何种方式设定，都应认为本项禁令可以适用。

<!-- source-p 580 -->
<a id="43.20.1.10"></a>**10**　即使某人依法并无引水权，但他以为自己有权引水，且其错误在事实而非法律方面，也应认为他可以适用本项禁令。我们采用的规则是：只要他以为自己有权引水，并且引水并非以暴力、秘密或可撤回许可的方式进行，即已足够。

<!-- source-p 581 -->
<a id="43.20.1.11"></a>**11**　尚有疑问：本项禁令所涵盖的水，是否仅限于用于灌溉土地的水，还是也包括供日常使用及其他利益之水？现行法认为后者也包括在内。因此，即使有人想把水引入城市土地，本项禁令也可以适用。

<!-- source-p 582 -->
<a id="43.20.1.12"></a>**12**　此外，拉贝奥写道，即使某些引水管道并非土地的附属物，因为可以引往任何地点，也仍属于本项禁令的适用范围。

<!-- source-p 583 -->
<a id="43.20.1.13"></a>**13**　拉贝奥还写道，即使裁判官在本项禁令中想到的是冷水，也不得拒绝颁布关于热水的禁令，因为热水同样可能有必要；有时将热水冷却后可以灌溉土地。有些地方即使使用热水灌溉也有必要，例如希耶拉波利斯：众所周知，亚洲的希耶拉波利斯人用热水灌溉土地。即便某水源并非灌溉所必需，也无人会怀疑本项禁令仍可适用。

<!-- source-p 584 -->
<a id="43.20.1.14"></a>**14**　无论水在城内还是城外，本项禁令都可以适用。

<!-- source-p 585 -->
<a id="43.20.1.15"></a>**15**　但应当理解，裁判官要求引水的方式与本年度内已经采用的方式相同。因此，不得认为裁判官允许引取更大量的水，或允许另行引水。若某人想引取与本年度内不同的水，或者虽引取同一水源却想改经另一地区引水，可以合法地阻止他。

<!-- source-p 586 -->
<a id="43.20.1.16"></a>**16**　拉贝奥说，水流入的那块土地，其各部分都应视为同一整体。因此，若请求人又买下相邻土地，后来想以新买土地的名义，从本年度曾引水的土地引水，人们认为，他只有在引水后进入自己的土地，并能从那里自由前往所欲之处，且引水来源未受损害时，才可像适用通行与驱畜禁令那样，正当地适用本项禁令。

<!-- source-p 587 -->
<a id="43.20.1.17"></a>**17**　还有人问：若某人把另一水源的水掺入其本年度已经引取的水中，是否可以合法地阻止他？奥菲利乌斯认为可以在另一水首次汇入水渠之处阻止他，但又说可以合法地禁止其引取全部水。我赞同奥菲利乌斯，认为不能把水分割；因为不可能只对其中一部分施加妨碍，而不影响全部水流。

<!-- source-p 588 -->
<a id="43.20.1.18"></a>**18**　特雷巴提乌斯认为，若赶到水边的牲畜超过许可数量，可以不受处罚地禁止全部牲畜饮水，因为额外牲畜与获准饮水的牲畜混在一起，会使整个牲畜群的饮水行为都变得有瑕疵。马尔切鲁斯则说，若某人有权赶牲畜到水边，却带了过多牲畜，不应禁止所有牲畜饮水。此说正确，因为牲畜可以分开。

<!-- source-p 589 -->
<a id="43.20.1.19"></a>**19**　阿里斯托认为，只有自以为有权使用水的人才可以适用本项禁令；明知自己毫无权利却仍使用水的人，不可以适用。

<!-- source-p 590 -->
<a id="43.20.1.20"></a>**20**　阿里斯托还说，某人在本年度内曾以非暴力、非秘密、非可撤回许可的方式引水，虽在同一年内又有瑕疵地使用，仍可正当地适用本项禁令；这应以其无瑕疵使用的期间为准。因为真实情形是，他在本年度内曾经无瑕疵地使用。

<!-- source-p 591 -->
<a id="43.20.1.21"></a>**21**　有人问：若某人在一年前引过水，之后的一年内水自行流入，而并非由他引取，本项禁令是否适用？瓦莱里乌斯·塞维鲁斯记载说，禁令对他适用，因为应视为他引过水，尽管仔细考察便会发现并非他亲自引水。

<!-- source-p 592 -->
<a id="43.20.1.22"></a>**22**　又有人问：某人以为自己有权每隔一天引水，因而只在某一天引水，是否可以认为他合法引水，且没有侵害占有人，因而可以适用本项禁令？裁判官说“你在本年度内曾引水”，即包括隔日引水。至于希望适用禁令的人究竟享有每五日、隔日还是每日引水权，并不重要；只要本年度内曾引水一天即已足够，因此其持有何种引水权并不影响。可是，若某人只有每五日引水一次的权利，却声称自己隔日引水，便不能从中获益。

<!-- source-p 593 -->
<a id="43.20.1.23"></a>**23**　此外应当知道，若你曾引水，后来对方禁止你引水，而你此后又丧失了引水权，那么应通过恢复原状，使本项禁令补偿你所丧失的权利。我认为此说正确。

<!-- source-p 594 -->
<a id="43.20.1.24"></a>**24**　若你出售并交付了你原先引水所至的土地，本项禁令对你仍然有用。

<!-- source-p 595 -->
<a id="43.20.1.25"></a>**25**　本项禁令可以针对阻止我引水的人提出；此人是否拥有土地所有权并不重要。因此，他受本项禁令约束，因为地役权也可以针对任何人请求确认。

<!-- source-p 596 -->
<a id="43.20.1.26"></a>**26**　若同一水渠的使用人，即同渠引水者之间，因用水发生争议，双方都主张自己享有用水权，则双方均可适用双方禁令。

<!-- source-p 597 -->
<a id="43.20.1.27"></a>**27**　拉贝奥认为，可以通过本项禁令禁止他人在土地上挖掘、播种、砍伐、修剪或建造，以免其行为污染、污损、破坏或使水质恶化——此水即对方本年度内无瑕疵地经由你的土地引取的水。他说，对夏季用水也应作同样的禁止。

<!-- source-p 598 -->
<a id="43.20.1.28"></a>**28**　若某人放弃了寻找水源的权利，该放弃有效。

<!-- source-p 599 -->
<a id="43.20.1.29"></a>**29**　裁判官接着说：“关于本案所涉水，你在上一夏季曾以非暴力、非秘密、非可撤回许可的方式从对方处引取；我禁止任何人以暴力妨碍你继续如此引水。我将颁布适用于继承人、买受人及遗产占有人之间的禁令。”

<!-- source-p 600 -->
<a id="43.20.1.30"></a>**30**　此项禁令适用于夏季用水。

<!-- source-p 601 -->
<a id="43.20.1.31"></a>**31**　既然我们说夏季用水与日常用水有所区别，就应知道二者适用的禁令也有差别：请求日常用水禁令时，措辞是“你在本年度内曾引水”；请求夏季用水禁令时，措辞是“你在上一夏季曾引水”。这并非没有道理，因为其冬季不使用，故裁判官应当以此前的夏季而非当前夏季为准。

<!-- source-p 602 -->
<a id="43.20.1.32"></a>**32**　较有经验者传述，夏季自春分开始，至秋分结束；如此，夏季和冬季各占六个月。

<!-- source-p 603 -->
<a id="43.20.1.33"></a>**33**　“上一夏季”应当通过比较相邻两个夏季来确定。

<!-- source-p 604 -->
<a id="43.20.1.34"></a>**34**　因此，若在夏季请求禁令，相关期间有时会达到一年半；例如水在春分之初引取，而禁令在次年夏季、秋分前一日请求。相应地，若在冬季请求禁令，期间甚至会延展到两年。

<!-- source-p 605 -->
<a id="43.20.1.35"></a>**35**　某人习惯仅在冬季引水而不在夏季引水，他可以适用准用禁令。

<!-- source-p 606 -->
<a id="43.20.1.36"></a>**36**　在本夏季引过水而未在上一夏季引过水的人，可以适用准用禁令。

<!-- source-p 607 -->
<a id="43.20.1.37"></a>**37**　裁判官说：“我将在继承人、买受人和遗产占有人之间颁布禁令。”应当知道，这些文字不仅适用于夏季用水，也适用于日常用水。正如关于通行权和驱畜权的禁令也给予继受人和买受人，裁判官认为此处也应如此。

<!-- source-p 608 -->
<a id="43.20.1.38"></a>**38**　裁判官说：“某人获有权者准许从公共水池引水；我禁止任何人妨碍其依获准方式引水。若请求就施工事项颁布禁令，我将命其提供未发生损害担保。”

<!-- source-p 609 -->
<a id="43.20.1.39"></a>**39**　这项禁令确有必要。前述禁令适用于从水源引水的人，不论其已设立地役权，还是仅认为地役权已经设立；裁判官认为，也应公平地把禁令给予从公共水池引水的人。所谓公共水池，是收纳公共用水的蓄水设施；此处“公共池”即指此物。

<!-- source-p 610 -->
<a id="43.20.1.40"></a>**40**　若某人获准从公共水池引水，应向其颁布本项禁令。

<!-- source-p 611 -->
<a id="43.20.1.41"></a>**41**　允许从公共水池、水渠或其他公共地点引水。

<!-- source-p 612 -->
<a id="43.20.1.42"></a>**42**　此种许可由皇帝授予；除皇帝外，无人有权授予引水权。

<!-- source-p 613 -->
<a id="43.20.1.43"></a>**43**　引水权有时授予土地，有时授予个人。授予土地的权利，不因个人死亡而消灭；授予个人的权利，则随个人死亡而消灭，因此既不转移给土地的另一所有人，也不转移给继承人或任何继受人。显然，土地所有权转移给受让人后，受让人可以申请取得许可：若他能证明水权附属于自己的土地，即便水流原先是以转让土地给他的前手名义获准引取，他也必定可以获得引水权。若有人竟不获准，这就不是优待，而是侵害。

<!-- source-p 614 -->
<a id="43.20.1.44"></a>**44**　我们应记住，在本项禁令中，关于授予水权的争议会得到最终解决。本项禁令不像前述禁令那样只是为确定权利作准备，也不涉及临时占有；当事人要么已经取得授予的权利，要么没有，本项禁令即终结争议。

<a id="43.20.3.pr."></a>**原文**　现行法认为，引水不仅可以用于灌溉，也可以用于牲畜饮水或环境美观。

<!-- source-p 621 -->
<a id="43.20.3.1"></a>**1**　多人可以从公共河流引水，但不得损害邻人；若河流狭窄，也不得损害位于对岸的人。

<!-- source-p 622 -->
<a id="43.20.3.2"></a>**2**　若你曾从公共河流引水，后来河道退去，你不能随着河流移动引水，因为新地点并未设立地役权，即使该地点属于我也一样。但若河流通过冲积逐渐向你的土地扩展，你可以随着河流引水，因为河流所流经的全部地点均负有供水地役权。可是，若河流改变河道并开始环绕土地流动，你就不能随着它引水，因为河道中间的地点并不负担地役权，地役权因此中断。

<!-- source-p 623 -->
<a id="43.20.3.3"></a>**3**　在水渠中自然涌出的水，默示地归引水人取得。

<!-- source-p 624 -->
<a id="43.20.3.4"></a>**4**　某条引水管道的设立已超出人们的记忆范围，应视为依法设立。

<!-- source-p 625 -->
<a id="43.20.3.5"></a>**5**　享有日常用水权的人，可以在水渠内设置水管或采取其他措施，但不得因此使土地所有人的土地或同渠引水人的水渠状况恶化。

<!-- source-p 626 -->
<a id="43.20.3.6"></a>**6**　若正在引水，另一股水流可通过横跨水渠上方的桥从其上方引过，但不得损害下方水渠。

<!-- source-p 636 -->
我们讨论夏季用水与日常用水的禁令时，首先认为应当确定何谓夏季用水。裁判官通常就此颁布专门禁令，并以先前夏季为判断期间。夏季用水究竟是指依法仅可在夏季使用的水，还是指引水人有意并计划在夏季引水的水，抑或指水本身的自然性质使其只能在夏季引取，抑或指引水地点的实际需要？我们最后认为，只有基于以下两项因素，才能准确地称为夏季用水：水的自然性质，以及引水地点的需要。因此，若水的自然性质使其只能在夏季引取，即使冬季也有人需要，仍属夏季用水；若水的自然性质允许全年引取，但受水人只在夏季需要使用，也应正当地称为夏季用水。

<a id="43.20.7"></a>**43.20.7**

<!-- source-p 638 -->
保罗《箴言集》第五卷。

<!-- source-p 639 -->
若诉讼涉及道路、通行权、驱畜权或引水权，应提供如下担保：在一方证明其权利期间，另一方不得妨碍其起诉、引水或通行。若一方否认对方有权起诉或引水，则应在不预断其是否丧失地役权的前提下提供担保；争议解决之前，他承诺不使用该地役权。

斯凯沃拉《定义集单卷本》。[底本作 *droon*，方括号补有 *definitionum*；书名文字疑有讹误。]

若某人有权经由他人土地引水，他可以在该土地上任意修筑水渠，但不得改变引水路线。
