# D.43.19　论私人通行权与驱畜权（*De itinere actuque privato*）

> 底本：*Digesta Iustiniani*，EPUB book-43.xhtml，source-p 512–566。

<!-- source-p 512 -->
<a id="19"></a><a id="43.19"></a>**43.19.0**　论私人通行权与驱畜权。

<!-- source-p 513 -->
<a id="43.19.1"></a>**43.19.1**

<!-- source-p 514 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 515 -->
<a id="43.19.1.pr."></a>**原文**　裁判官说：“关于本案所涉私人通行、驱畜通行或道路，你在本年度内曾以非暴力、非秘密、非可撤回许可的方式使用该路线，且不是从对方处以此类方式使用的，我禁止任何人以暴力妨碍你继续如此使用。”

<!-- source-p 516 -->
<a id="43.19.1.1"></a>**1**　本项禁令是禁止性禁令，仅用于保护乡村地役权。

<!-- source-p 517 -->
<a id="43.19.1.2"></a>**2**　裁判官通过此项禁令并不审查是否依法设立地役权；只审查本年度内是否以非暴力、非秘密、非可撤回许可的方式使用通行权或驱畜权。即使颁布禁令时并未正在使用，也受其保护。因此，无论是否依法享有道路权，只要在本年度内使用过，或曾在一段不短于三十日的期间内使用，就属于裁判官应保护的情形。是否在当前时点使用并不重要，因为我们通常只在需要时才使用通道或道路，并非始终使用。

<!-- source-p 518 -->
<a id="43.19.1.3"></a>**3**　裁判官把使用期间限定为一年。我们应从禁令颁布之日向前计算一年。

<!-- source-p 519 -->
<a id="43.19.1.4"></a>**4**　有人适用本项禁令时，只须证明其使用过通行权或驱畜权中的一项。

<!-- source-p 520 -->
<a id="43.19.1.5"></a>**5**　尤利安说，通行权所及范围只到实际进入之处；此说正确。

<!-- source-p 521 -->
<a id="43.19.1.6"></a>**6**　维维安努斯正确地指出：某人因河流不便通行，或因公路中断，而穿越邻人的土地；即使他多次这样做，也不能说他使用了该通道，因此禁令对他无效。这并非因为他以可撤回许可使用，而是因为他根本没有行使该通道。依此，不能认为他使用了任何一条路线；尤其是，他没有使用那条因河流不便或公路陡峭而未能通行的道路。如果那里没有公路，只有私人通道，也应作相同处理，因为问题相同。

<!-- source-p 522 -->
<a id="43.19.1.7"></a>**7**　某人的佃户、客人或其他人曾经通行至其土地，应视为该土地所有人使用了通道、驱畜路线或道路，因此他可以适用禁令。佩狄乌斯如此记载，并补充说，即使该人不知道所经过土地的所有人是谁，仍可保有地役权。

<!-- source-p 523 -->
<a id="43.19.1.8"></a>**8**　如果我的朋友以为土地属于自己，便以自己的名义通行，那么应认为他为自己而非为我取得了适用禁令的权利。

<!-- source-p 524 -->
<a id="43.19.1.9"></a>**9**　如果某人因洪水而未能在本年度使用通行权或驱畜权，但上一年度曾使用，他可以依据“若我认为存在正当理由”这一条款，请求恢复原状并补足期限，再适用本项禁令。马尔切鲁斯也认为，若因暴力导致未能使用，应准予恢复原状。此外，在其他通常可以请求恢复原状的情形中，也可补足期限后适用禁令。

<!-- source-p 525 -->
<a id="43.19.1.10"></a>**10**　还应知道，若准许对方延期会使我依据禁令提出请求的地位恶化，那么公平的做法是补足期间后重新颁布禁令。

<!-- source-p 526 -->
<a id="43.19.1.11"></a>**11**　假设我把一块负有通行地役权的土地以可撤回许可交给你；其后你又向该土地所有人请求，以可撤回许可使用通往该地的道路。若你针对曾准许你使用道路的人提出禁令，该许可是否会使其抗辩成立？较妥当的意见是会成立。此点可由尤利安所写的类似情形得出：他问，如果我把一块负有通行权的土地以可撤回许可交给你，而你又请求以可撤回许可使用该道路，我是否仍可适用准用禁令？他认为可以，因为正如我对自己的物不受可撤回许可关系约束，我也不因你而被视为以可撤回许可占有：每当我的佃户或我以可撤回许可交付土地的人使用道路时，都视为我在通行，故我可以正确地说自己使用了通道。他还说，同一理由表明，若我曾请求以可撤回许可使用道路，随后又把土地以可撤回许可交给你，即使你认为该道路是为我的土地设定的，我适用禁令也不会获准，并应认为我是在可撤回许可下使用道路；这并非没有道理，因为应考察的是我的认识，而非你的认识。不过，我认为你仍可以适用禁令，尽管尤利安没有就此明确记载。

<!-- source-p 527 -->
<a id="43.19.1.12"></a>**12**　如果某人在上述年度期间曾以非暴力、非秘密、非可撤回许可的方式使用道路，但后来不再使用，转而以秘密或可撤回许可方式使用，这是否对他不利，尚待考察。较妥当的意见是，就适用本项禁令而言，后来情形不应对他不利：

<!-- source-p 528 -->
<a id="43.19.2"></a>**43.19.2**

<!-- source-p 529 -->
保罗《告示评注》第六十六卷。

<!-- source-p 530 -->
正当完成的行为，不会因为后来发生不法行为而被追溯改变或败坏。

<!-- source-p 531 -->
<a id="43.19.3"></a>**43.19.3**

<!-- source-p 532 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 533 -->
<a id="43.19.3.pr."></a>**原文**　由此，拉贝奥还写道：若你原本正当地使用我的道路，我随后出售了你通行所经过的土地，而买受人又禁止你通行，那么尽管你似乎是在秘密使用道路（因为被禁止后仍继续使用即属秘密使用），你仍可在一年内适用禁令，因为你在本年度内曾以非暴力、非秘密、非可撤回许可的方式使用。

<!-- source-p 534 -->
<a id="43.19.3.1"></a>**1**　还应知道，不仅亲自受到禁止后仍使用的人属于秘密使用；若他人是通过某人保有该权利，而该人被禁止后，他仍继续使用，也属于秘密使用。但如果我不知道该人已被禁止，仍继续使用，则应认为这对我没有不利影响。

<!-- source-p 535 -->
<a id="43.19.3.2"></a>**2**　若某人曾以暴力、秘密或可撤回许可方式使用我的权利前手的道路，我可以正当地禁止其通行，本项禁令对他无效，因为从我的权利前手处有瑕疵地占有的人，应视为相对于我也以暴力、秘密或可撤回许可占有。佩狄乌斯也写道：若某人曾以这些有瑕疵的方式，从我通过继承、买卖或其他法律原因承继其地位的人处使用道路，也应作相同处理。既然我承继了前手的地位，就不公平地让我承受前手所不受的损害。

<!-- source-p 536 -->
<a id="43.19.3.3"></a>**3**　在此项禁令中，应审查禁止通行或驱畜会使请求人遭受多少损害。

<!-- source-p 537 -->
<a id="43.19.3.4"></a>**4**　我们也可以通过奴隶、佃户、朋友、客人，几乎所有为我们保有地役权的人使用地役权。但尤利安说，虽可通过用益权人保有地役权，所有人却不能因此适用本项禁令。

<!-- source-p 538 -->
<a id="43.19.3.5"></a>**5**　尤利安还写道：若我对你的土地享有用益权，而你享有所有权，我们二人都经由邻地通行，则我们都可适用拟制的通行禁令。无论用益权人被第三人禁止通行，还是被土地所有人禁止，或者土地所有人被用益权人禁止，都可以适用；任何人妨碍通行，均可对其提出禁令。

<!-- source-p 539 -->
<a id="43.19.3.6"></a>**6**　因赠与而取得土地空缺占有的人，也可以适用本项禁令。

<!-- source-p 540 -->
<a id="43.19.3.7"></a>**7**　若有人受我委托买入土地，公平的做法是把本项禁令给予我，并按受我委托买受人的使用情形判断。

<!-- source-p 541 -->
<a id="43.19.3.8"></a>**8**　买受用益权、使用权的人，以及受遗赠并已获交付该权利的人，也可以适用本项禁令。

<!-- source-p 542 -->
<a id="43.19.3.9"></a>**9**　因嫁资目的而受领土地的人，也可以通过本项禁令请求救济。

<!-- source-p 543 -->
<a id="43.19.3.10"></a>**10**　一般而言，凡基于买卖或其他契约关系而取得此种利益的，都应认为可以适用本项禁令。

<!-- source-p 544 -->
<a id="43.19.3.11"></a>**11**　裁判官说：“关于本案所涉通行权、驱畜权或道路，你在本年度内曾以非暴力、非秘密、非可撤回许可的方式从他人处使用；我禁止任何人以暴力妨碍你为依其权利修缮该通道或道路。请求适用本项禁令的人，应就因其过错所造成的损害提供未发生损害担保。”

<!-- source-p 545 -->
<a id="43.19.3.12"></a>**12**　出于实际需要，裁判官还颁布了这项禁令。使用通道的人自然需要一种禁令，使他可以修缮道路：若不修缮，他又如何能够便利地通行或驱畜？道路损坏后，通行或驱畜都会变得不便。

<!-- source-p 546 -->
<a id="43.19.3.13"></a>**13**　此项禁令与前一项不同：前一项禁令可由本年度内曾经使用道路的任何人适用；此项禁令只有本年度使用过道路且依法享有修缮权的人才能适用。依法享有修缮权的人，是享有该地役权的人。因此，适用本项禁令者必须证明两点：其一，本年度曾使用道路；其二，其享有地役权。若缺少其中一项，禁令即不能成立，这是有道理的。希望通行或驱畜的人，在地役权是否存在尚未查明时，无须先证明其权利；允许一名本年度曾使用道路的人通行，又有何损失？但希望修缮的人是在实施新的行为；除非他确实享有地役权，否则不得允许其在他人土地上施工。

<!-- source-p 547 -->
<a id="43.19.3.14"></a>**14**　可能有人享有通行权和驱畜权，却没有修缮权，因为设立地役权时约定不得修缮；也可能约定其修缮权仅限于特定范围。因此，裁判官正确地把修缮权作为条件，说：“依你的权利所许可的范围进行修缮。”所谓“依权利所许可”，就是按照设立地役权时所允许的方式。

<!-- source-p 548 -->
<a id="43.19.3.15"></a>**15**　修缮，是指使通道或驱畜路线恢复原有形态，也就是不得将其拓宽、延长、降低或垫高。修缮与另行建造截然不同。

<!-- source-p 549 -->
<a id="43.19.3.16"></a>**16**　拉贝奥讨论过这样的情形：有人为了铺筑道路，想要新建一座桥，是否应允许？他说应当允许，因为这类铺设属于修缮的一部分。我认为拉贝奥的意见正确，但以没有这座桥就无法通行为限。

<!-- source-p 552 -->
<a id="43.19.4.pr."></a>**原文**　古人曾特别补充规定，不得妨碍运送修缮所需材料的人；这一补充没有必要，因为若不允许运送修缮道路所不可缺少的材料，就属于妨碍修缮。

<!-- source-p 553 -->
<a id="43.19.4.1"></a>**1**　但是，若某人本可走近路运送修缮所需材料，却故意走较远的路线，使通行状况恶化，那么他遭受妨碍并不违法，因为他自己造成了修缮障碍。

<!-- source-p 554 -->
<a id="43.19.5"></a>**43.19.5**

<!-- source-p 555 -->
乌尔比安《告示评注》第二十卷。

<!-- source-p 556 -->
<a id="43.19.5.pr."></a>**原文**　因此，显然，不允许他人堆放修缮所需材料的人，属于妨碍其完成修缮。

<!-- source-p 557 -->
<a id="43.19.5.1"></a>**1**　显然，若某人可以在土地的另一处运送材料，且不会给土地所有人造成不便，却故意选择另一处运送，裁判官正确地认为，对其予以妨碍并不违法。

<!-- source-p 558 -->
<a id="43.19.5.2"></a>**2**　毫无疑问，本项禁令不仅应给予权利人本人，也应给予其继受人；也应给予买受人，并可对买受人提出。

<!-- source-p 559 -->
<a id="43.19.5.3"></a>**3**　某人虽未依法设立地役权，但因长期使用而取得类似长期占有的优先地位，也可以适用本项禁令。

<!-- source-p 560 -->
<a id="43.19.5.4"></a>**4**　适用本项禁令的人，应向对方就工程瑕疵提供担保。
