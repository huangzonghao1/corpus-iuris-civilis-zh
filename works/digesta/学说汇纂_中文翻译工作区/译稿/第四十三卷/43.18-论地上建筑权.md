# D.43.18　论地上建筑权（*De superficiebus*）

> 底本：*Digesta Iustiniani*，EPUB book-43.xhtml，source-p 496–511。

<!-- source-p 496 -->
<a id="18"></a><a id="43.18"></a>**43.18.0**　论地上建筑权。

<!-- source-p 497 -->
<a id="43.18.1"></a>**43.18.1**

<!-- source-p 498 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 499 -->
<a id="43.18.1.pr."></a>**原文**　裁判官说：“关于本案所涉地上建筑物，任何一方依租赁约定而使用收益，且其并非以暴力、秘密或可撤回许可从对方处取得使用收益的，我禁止任何人以暴力妨碍其继续如此使用收益。如果有人请求就地上建筑物提起其他诉讼，我将审查案情后予以准许。”

<!-- source-p 500 -->
<a id="43.18.1.1"></a>**1**　在他人土地上享有地上建筑权的人，受到市民法诉权的保护：若其租得该地上建筑物，可以基于租赁提起诉讼；若其买得，则可以基于买卖向土地所有人提起诉讼。若土地所有人本人妨碍他，他可通过请求赔偿利益受损而获得救济；若他是被第三人妨碍，土地所有人应向他提供自己的诉权并让与之。不过，为了提供更有效的救济，裁判官认为应当颁布此项禁令，并承诺给予一种类似对物诉权的救济：一方面，是否存在租赁关系尚不确定；另一方面，取得占有通常优于提起对人诉讼。

<!-- source-p 501 -->
<a id="43.18.1.2"></a>**2**　本禁令仿照“现占有者”禁令，为双方禁令。因此，裁判官如同依“现占有者”禁令那样，保护请求地上建筑权的人，并不要求他说明占有的原因；只审查他是否以暴力、秘密或可撤回许可从对方处占有。凡“现占有者”禁令所适用的一切规则，在此处也同样适用。

<!-- source-p 502 -->
<a id="43.18.1.3"></a>**3**　裁判官所说“如有人请求就地上建筑物提起诉讼，我将审查案情后予以准许”，应理解为：若有人仅在有限期间租得地上建筑物，则不应给予他对物诉权。审查案情后，应向租期并非短暂的人给予对物诉权。

<!-- source-p 503 -->
<a id="43.18.1.4"></a>**4**　地上建筑物所在土地的占有人，无须依赖拟制诉权，因为他享有与土地本身相同的对物诉权。但若他要对地上建筑权人主张权利，应认为他可以使用基于事实的抗辩；有人主张，既然我们给予某人诉权，就更应给予对方相应的抗辩。

<!-- source-p 504 -->
<a id="43.18.1.5"></a>**5**　若地上建筑权被他人追夺，公平的做法是对受影响者给予驱逐担保之诉，或至少给予买卖之诉以救济。

<!-- source-p 505 -->
<a id="43.18.1.6"></a>**6**　既然关于地上建筑物也给予对物诉权，那么应当认为，对请求权人也可就地上建筑物给予拟制诉权；地上建筑物之上也可以通过拟制诉权设定一种类似用益权或使用权的权利。

<!-- source-p 506 -->
<a id="43.18.1.7"></a>**7**　也应认为这种权利可以交付，因而可以遗赠或赠与。

<!-- source-p 507 -->
<a id="43.18.1.8"></a>**8**　若该权利由两人共有，我们也应给予拟制共有物分割诉讼。

<!-- source-p 508 -->
<a id="43.18.1.9"></a>**9**　也可以依裁判官法设定地役权，并仿照依市民法直接设定的地役权，通过拟制诉权请求保护；此外，对此类地役权也可以适用拟制禁令。

<!-- source-p 509 -->
<a id="43.18.2"></a>**43.18.2**

<!-- source-p 510 -->
盖尤斯《行省告示评注》第二十五卷。

<!-- source-p 511 -->
所谓地上建筑物，是指建于租用土地上的房屋；无论依市民法还是自然法，其所有权均属于土地所有人。
