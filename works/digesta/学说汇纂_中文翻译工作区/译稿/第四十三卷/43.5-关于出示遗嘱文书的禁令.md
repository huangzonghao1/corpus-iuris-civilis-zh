# D.43.5 关于出示遗嘱文书的禁令（*De tabulis exhibendis*）

> 底本：*Digesta Iustiniani*，EPUB `book-43.xhtml`，source-p 89–131。

<!-- source-p 89 -->
<a id="5"></a><a id="43.5"></a>**43.5.0**　关于出示遗嘱文书的禁令。

<!-- source-p 90 -->
<a id="43.5.1"></a>**43.5.1**

<!-- source-p 91 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 92 -->
<a id="43.5.1.pr."></a>**序言**　法务官说：“据称卢基乌斯·提提乌斯遗留下与其遗嘱有关的文书；若这些文书在你处，或因你的恶意行为而不再在你处，你应当向他出示。若据称他还遗留下书信或其他物品，我将以裁定处理。”

<!-- source-p 93 -->
<a id="43.5.1.1"></a>**1**　若某人承认遗嘱文书在其手中，应命其出示；若他不能当即出示，应给予其一定期限。但若他否认自己能够或有义务出示，则可适用此禁令。

<!-- source-p 94 -->
<a id="43.5.1.2"></a>**2**　该禁令不只适用于遗嘱文书，也适用于与遗嘱有关的一切文书，例如副遗嘱。

<!-- source-p 95 -->
<a id="43.5.1.3"></a>**3**　无论遗嘱有效或无效，无论该遗嘱自始无效、后来被废止或存在其他瑕疵，即使遗嘱被指为伪造，或被指由不具备遗嘱能力的人订立，也应认定该禁令适用。

<!-- source-p 96 -->
<a id="43.5.1.4"></a>**4**　无论是最后订立的遗嘱文书，还是先前订立的文书，该禁令都适用。

<!-- source-p 97 -->
<a id="43.5.1.5"></a>**5**　因此，应认为该禁令适用于一切遗嘱文书，无论其完整还是不完整。

<!-- source-p 98 -->
<a id="43.5.1.6"></a>**6**　若某人多次订立遗嘱，存在多份文书，该禁令也适用；因为凡在任何时候订立、且与遗嘱有关而应出示的文书，均在其范围内。

<!-- source-p 99 -->
<a id="43.5.1.7"></a>**7**　同样，若对遗嘱人的身份存在争议，指称遗嘱人是处于家父权下的儿子或奴隶，也应出示遗嘱文书。

<!-- source-p 100 -->
<a id="43.5.1.8"></a>**8**　若处于家父权下的儿子就军旅特有产订立遗嘱，该禁令同样适用。

<!-- source-p 101 -->
<a id="43.5.1.9"></a>**9**　遗嘱人死于敌境时，也适用同一规则。

<!-- source-p 102 -->
<a id="43.5.1.10"></a>**10**　该禁令不适用于生者的遗嘱文书，因为法务官使用了“遗留下”一词。

<!-- source-p 103 -->
<a id="43.5.1.11"></a>**11**　即使遗嘱是在没有欺诈的情况下被涂毁，也适用该禁令；

<a id="43.5.2"></a>**43.5.2**

<!-- source-p 105 -->
保罗《告示评注》第六十四卷。

<!-- source-p 106 -->
无论是全部文书还是其中一部分，

<!-- source-p 107 -->
<a id="43.5.3"></a>**43.5.3**

<!-- source-p 108 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 109 -->
<a id="43.5.3.pr."></a>**序言**　该禁令适用。

<!-- source-p 110 -->
<a id="43.5.3.1"></a>**1**　若遗嘱文书分别写在多份文书中，这些文书全部受该禁令约束，因为它们共同构成一份遗嘱。

<!-- source-p 111 -->
<a id="43.5.3.2"></a>**2**　若提提乌斯将遗嘱文书寄存于某人处，可以依此禁令对保管人和寄存人二者提起诉讼。

<!-- source-p 112 -->
<a id="43.5.3.3"></a>**3**　因此，若文书由神庙看守人或档案保管人负责保管，应认为该人也受此禁令约束。

<!-- source-p 113 -->
<a id="43.5.3.4"></a>**4**　若遗嘱文书在奴隶手中，其主人受此禁令约束。

<!-- source-p 114 -->
<a id="43.5.3.5"></a>**5**　若遗嘱人在世时声称遗嘱文书属于自己并请求出示，则该禁令不适用；应提起出示之诉，待文书出示后再提起所有物返还诉讼。凡有人声称某些实体文书属于自己，也应适用同一规则。

<!-- source-p 115 -->
<a id="43.5.3.6"></a>**6**　若某人以恶意行为使遗嘱文书不再由其持有，仍受此禁令约束；这并不妨碍《科尔内利亚遗嘱法》的适用，仿佛其以恶意隐匿遗嘱一样。任何人不能仅因自己犯下更严重的罪行，就有权不受惩罚地扣留文书；毕竟文书一经出示，其行为反而会更加明显。但某人也可能以恶意行事，以避免落入该法的适用范围；例如，他既未取走也未隐藏文书，只是将其交给他人，使他人不向依禁令请求者出示。这就是说，他并非意图或计划隐匿遗嘱，只是不愿向此人出示。

<!-- source-p 116 -->
<a id="43.5.3.7"></a>**7**　该禁令属于命令出示的禁令。

<!-- source-p 117 -->
<a id="43.5.3.8"></a>**8**　我们来考察何谓“出示”。出示，就是使他人能够接触文书本身。

<!-- source-p 118 -->
<a id="43.5.3.9"></a>**9**　应当在法务官面前出示文书，以便根据法务官的权威通知签封人到场核验印记。若证人不服从，拉贝奥写道，法务官应对其采取强制措施。

<!-- source-p 119 -->
<a id="43.5.3.10"></a>**10**　凡有人在遗嘱中被记载了某项利益，通常都可以请求出示遗嘱文书。

<!-- source-p 120 -->
<a id="43.5.3.11"></a>**11**　此项诉讼的判决金额，应依请求人因此具有的利益估算。

<!-- source-p 121 -->
<a id="43.5.3.12"></a>**12**　因此，若指定继承人依此禁令提起诉讼，估价应以遗产为依据：

<!-- source-p 122 -->
<a id="43.5.3.13"></a>**13**　若涉及遗赠，估价仅以遗赠的价值为限：

<!-- source-p 123 -->
<a id="43.5.3.14"></a>**14**　若遗赠附有条件，则应如同条件已经成就那样估价；不得强迫受遗赠人提供担保，保证若条件未成就便返还其所取得的一切，因为不出示文书的人所承担的只是藐视命令的制裁。

<!-- source-p 124 -->
<a id="43.5.3.15"></a>**15**　因此有人问，受遗赠人依此程序取得估价后，若后来再请求给付遗赠，是否应受理。我认为，若给付估价的是同一继承人，应以欺诈抗辩驳回其请求；若给付估价的是另一人，则不应驳回。若使用禁令并取得估价的人是继承人，也应作同样区分。

<!-- source-p 125 -->
<a id="43.5.3.16"></a>**16**　可以确定，该禁令在一年期满后仍可提起；继承人及其他继受人也享有该禁令。

<!-- source-p 126 -->
<a id="43.5.4"></a>**43.5.4**

<!-- source-p 127 -->
保罗《告示评注》第六十九卷。

<!-- source-p 128 -->
若遗嘱文书在未适婚人手中，而因监护人的欺诈行为不再由其持有，则应对监护人本人适用该禁令；使监护人对自己的不法行为负责，而不使未适婚人承担责任，才是公平的。
