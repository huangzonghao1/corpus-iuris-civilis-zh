# D.43.15 论加固河岸（*De ripa munienda*）

<!-- source-p 324 -->
<a id="15"></a><a id="43.15"></a>**43.15.0**　论加固河岸。

<!-- source-p 325 -->
<a id="43.15.1"></a>**43.15.1**

<!-- source-p 326 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 327 -->
<a id="43.15.1.pr."></a>**序言**　裁判官称：“我禁止以暴力妨碍某人在公共河流或其河岸施工，以保护河岸或河岸附近的土地；但不得因此妨碍航行，并且已依善良之人的判断为未来十年可能发生的损害提供担保或充分担保，或者未能提供此种担保并非因该人所致。”

<!-- source-p 328 -->
<a id="43.15.1.1"></a>**1**　修缮、加固公共河流的河岸极为有益。既然已规定修缮公共道路的禁令，也应规定加固河岸的禁令。

<!-- source-p 329 -->
<a id="43.15.1.2"></a>**2**　裁判官恰当地补充说“不得因此使航行状况恶化”，因为只有不妨碍船舶通行的修缮才可容许。

<!-- source-p 330 -->
<a id="43.15.1.3"></a>**3**　想要加固河岸的人，应依其身份和状况，就未来可能发生的损害提供担保或充分担保。本禁令明确规定，应依善良之人的判断，就未来十年可能发生的损害提供担保或充分担保。

<!-- source-p 331 -->
<a id="43.15.1.4"></a>**4**　应向邻人提供担保；河对岸的土地占有人也包括在内。

<!-- source-p 332 -->
<a id="43.15.1.5"></a>**5**　必须在工程实施前提供担保，因为工程完成后，即使后来发生损害，也已无法依据本禁令追索；届时只能依《阿奎利亚法》提起诉讼。

<!-- source-p 333 -->
<a id="43.15.1.6"></a>**6**　应注意，裁判官在此并未规定加固湖泊、沟渠或池塘河岸时须提供担保；但应遵循加固河流河岸时所适用的同一规则。
