# D.43.11 论修缮公共道路与公共通道（*De via publica et itinere publico reficiendo*）

<!-- source-p 243 -->
<a id="11"></a><a id="43.11"></a>**43.11.0**　论修缮公共道路与公共通道。

<!-- source-p 244 -->
<a id="43.11.1"></a>**43.11.1**

<!-- source-p 245 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 246 -->
<a id="43.11.1.pr."></a>**序言**　裁判官称：“我禁止以暴力妨碍某人开通或修缮公共道路或公共通道，但不得因此使该道路或通道的状况恶化。”

<!-- source-p 247 -->
<a id="43.11.1.1"></a>**1**　开通道路，是指使其恢复原有的高度和宽度。清理也是修缮的一部分；严格说来，清理是指除去覆盖其上的物，使道路恢复至其应有的水平。开通道路的人、清理道路的人，以及一切使道路恢复原状的人，都属于修缮道路。

<!-- source-p 248 -->
<a id="43.11.1.2"></a>**2**　若有人借修缮之名使道路状况恶化，可以对其施加阻力而不受处罚。因此，负责修缮的人不得借修缮之名使道路变得更宽、更长、更高或更低；也不得在土路上铺碎石或铺石，使原为土路的道路成为石路；反之，也不得把铺石道路改成土路。

<!-- source-p 249 -->
<a id="43.11.1.3"></a>**3**　本禁令为永久性禁令，任何人均可提出，且可针对任何人；判决额以原告的利益为准。

<!-- source-p 250 -->
<a id="43.11.2"></a>**43.11.2**

<!-- source-p 251 -->
雅沃莱努《卡西乌斯著作评注》第十卷。

<!-- source-p 252 -->
公共道路不会仅因公众未加使用而丧失其公共性质。

<!-- source-p 253 -->
<a id="43.11.3"></a>**43.11.3**

<!-- source-p 254 -->
保罗《法学格言》第一卷。

<!-- source-p 255 -->
<a id="43.11.3.pr."></a>**序言**　若有人将公共道路改道穿过邻人的土地，应向其授予 *actio viae receptae*（公共道路改道侵入之诉）；赔偿额为其土地遭受侵害之人的利益。

<!-- source-p 256 -->
<a id="43.11.3.1"></a>**1**　开垦或耕翻公共道路的人，应由其独自承担修筑、养护该道路的义务。
