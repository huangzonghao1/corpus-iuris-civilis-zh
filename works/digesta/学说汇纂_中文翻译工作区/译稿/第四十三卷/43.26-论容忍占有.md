# D.43.26 论容忍占有（*De precario*）

<!-- source-p 886 -->
<a id="26"></a><a id="43.26"></a>**43.26.0**　论容忍占有。

<!-- source-p 887 -->
<a id="43.26.1"></a>**43.26.1**

<!-- source-p 888 -->
乌尔比安《法学阶梯》第一卷。

<!-- source-p 889 -->
<a id="43.26.1.pr."></a>**序言**　所谓容忍占有（*precarium*），是指应请求而准许请求人使用某物，并持续至准许人不再容许之时。

<!-- source-p 890 -->
<a id="43.26.1.1"></a>**1**　这种施惠方式源于万民法。

<!-- source-p 891 -->
<a id="43.26.1.2"></a>**2**　它与赠与不同：赠与人给付时并不打算收回；而以容忍方式准许使用的人，则是如同准备在自己愿意终止容忍时收回该物那样予以准许。

<!-- source-p 892 -->
<a id="43.26.1.3"></a>**3**　它类似借用：出借人出借物品，并非使该物成为受领人的，而只是准许其使用所借之物。

<!-- source-p 893 -->
<a id="43.26.2"></a>**43.26.2**

<!-- source-p 894 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 895 -->
<a id="43.26.2.pr."></a>**序言**　裁判官说：“你以容忍方式从某人处取得的、或者你以恶意使自己不再持有的本案争议之物，应当返还给该人。”

<!-- source-p 896 -->
<a id="43.26.2.1"></a>**1**　本项禁令属于命令返还的禁令。

<!-- source-p 897 -->
<a id="43.26.2.2"></a>**2**　本项禁令体现了自然衡平：准许人愿意撤回容忍时，即可请求返还。自然衡平在于，你可以享用我的施惠，直至我愿意为止；我改变意愿时，也应能够撤回。因此，凡有容忍请求，不仅可以使用本项禁令，还可以提起源于诚信的以特定文字为诉因之诉（*actio praescriptis verbis*）。

<!-- source-p 898 -->
<a id="43.26.2.3"></a>**3**　若某人仅因提出请求并获准许，才取得某物或某项权利的占有或控制，从而可以占有或使用该物或权利，即视为其以容忍方式持有：

<!-- source-p 899 -->
<a id="43.26.3"></a>**43.26.3**

<!-- source-p 900 -->
盖尤斯《行省告示评注》第二十五卷。

<!-- source-p 901 -->
例如，你请求我准许你经由我的土地通行或驱赶牲畜；又如，你请求准许雨水从你的屋顶滴落到我房屋的屋顶或空地上，或者请求准许梁木嵌入我的墙内。

<!-- source-p 902 -->
<a id="43.26.4"></a>**43.26.4**

<!-- source-p 903 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 904 -->
<a id="43.26.4.pr."></a>**序言**　动产也可以成为容忍请求的对象。

<!-- source-p 905 -->
<a id="43.26.4.1"></a>**1**　应当记住，以容忍方式持有的人也属于占有人。

<!-- source-p 906 -->
<a id="43.26.4.2"></a>**2**　对本项禁令承担责任的未必是提出容忍请求的人，而是以容忍方式持有该物的人。因为可能有人没有提出请求，却以容忍方式持有；例如，我的奴隶提出请求，因而为我取得了容忍占有；或者提出请求的是其他受我权利支配的人。

<!-- source-p 907 -->
<a id="43.26.4.3"></a>**3**　同样，若我请求以容忍方式持有自己的物，我固然提出了此种请求，却并非以容忍方式持有该物，因为通说认为，自己的物不存在容忍占有。

<!-- source-p 908 -->
<a id="43.26.4.4"></a>**4**　又如，某人请求在一定期间内以容忍方式持有；期限届满后，即使他未再次提出请求，仍视为继续以容忍方式占有。因为所有人容许原请求人继续占有，即应理解为再次准许其以容忍方式占有。

<!-- source-p 909 -->
<a id="43.26.5"></a>**43.26.5**

<!-- source-p 910 -->
庞波尼《萨宾评注》第二十九卷。

<!-- source-p 911 -->
若容忍关系尚在存续期间，你又请求延长至更晚的期间，容忍期限即予延长：占有原因并未改变，也不是以此方式新设容忍关系，而是将原关系延展至更长期间。若你是在原定日期已经过去后才提出请求，则较妥当的看法是，既已终止的容忍关系不会恢复，而是另行成立一项新的容忍关系。

<!-- source-p 912 -->
<a id="43.26.6"></a>**43.26.6**

<!-- source-p 913 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 914 -->
<a id="43.26.6.pr."></a>**序言**　马尔凯鲁斯说，若其间所有人陷入精神失常或死亡，容忍关系便不可能恢复；此说正确。

<!-- source-p 915 -->
<a id="43.26.6.1"></a>**1**　若我的代理人奉我之命，或经我追认，提出容忍请求，严格说来，应当认为是我以容忍方式持有。

<!-- source-p 916 -->
<a id="43.26.6.2"></a>**2**　请求准许其在土地上居住的人并不占有该土地，占有仍归准许人。因为正如法学家所说，用益权人、佃户和房客虽住在土地上，却并不占有土地。

<!-- source-p 917 -->
<a id="43.26.6.3"></a>**3**　尤利安说，以暴力驱逐他人后，又向被驱逐者请求容忍的人，不再属于以暴力占有，而开始以容忍方式占有；不能认为其占有原因由自己单方改变，因为他是在被驱逐者同意后才开始以容忍方式占有。尤利安还说，若他从同一被驱逐者处买得该物，也可以开始以买受人身份取得时效。

<!-- source-p 918 -->
<a id="43.26.6.4"></a>**4**　有人提出疑问：若某人将自己的物质押给我，随后又请求以容忍方式占有，该禁令是否适用？问题在于，容忍占有能否成立于本人之物。我认为，若请求的是占有而非所有权，则质押物上可以成立容忍占有；此说更为妥当，也最有实益：债务人日常请求债权人以容忍方式将质押物交其占有，因此容忍占有理应能够成立。

<!-- source-p 919 -->
<a id="43.26.7"></a>**43.26.7**

<!-- source-p 920 -->
维努莱乌《禁令论》第三卷。

<!-- source-p 921 -->
即使我可以通过“如现占有”禁令保有某物的占有，尽管我终将因所有权问题承担责任，但若我以容忍方式准许你占有该物，你仍应对本项禁令承担责任。

<!-- source-p 922 -->
<a id="43.26.8"></a>**43.26.8**

<!-- source-p 923 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 924 -->
<a id="43.26.8.pr."></a>**序言**　曾有人问：提图斯请求我准许其使用塞姆普罗尼乌斯的物，随后我又请求塞姆普罗尼乌斯准许使用，他为了让我能向提图斯提供使用而予以准许。提图斯是从我处以容忍方式取得该物，我可以对他提起容忍占有禁令。塞姆普罗尼乌斯却不能对他提起，因为“你从某人处以容忍方式取得”这句话表明，只有被请求准许容忍的人才享有此项禁令，而非物的所有人。那么，塞姆普罗尼乌斯能否像对待直接向他请求的人那样，对我提起禁令？较妥当的看法是不能，因为我并非以容忍方式持有该物：我请求准许的是他人使用，而非自己使用。不过，他可以对我提起委任之诉，因为我是奉其委任而将物交给你的；或者，若有人认为他并非受我委任，而是信赖我才这样做，则应认为可对我给予事实之诉。

<!-- source-p 925 -->
<a id="43.26.8.1"></a>**1**　某人从提图斯处以容忍方式请求并取得之物，也视为从提图斯的继承人处以容忍方式取得；萨宾努斯和塞尔苏斯均如此写道，我们也遵循此规则。因此，也视为从其他继受人处以容忍方式取得。拉贝奥也赞同此说，并补充说，即使某人不知道对方是继承人，仍应视为其从继承人处以容忍方式取得。

<!-- source-p 926 -->
<a id="43.26.8.2"></a>**2**　不过，我们应考察如下情形：你向我请求容忍，我随后将该物转让他人，转让后容忍关系是否仍然存续？较妥当的看法是，若受让人没有撤回容忍，你可以对其提起禁令，视为你是从他而非从我处取得容忍；若他曾在一段时间内容许你以容忍方式从其处持有，你当然可以对其提起禁令。

<!-- source-p 927 -->
<a id="43.26.8.3"></a>**3**　裁判官还规定，以恶意使自己不再持有该物的人也应承担责任。应当注意，提出容忍请求的人不对过失负责，仅对故意负责；而接受借用的人不仅对故意，也对过失负责。提出容忍请求者仅对故意负责并非没有道理，因为容忍关系完全源于准许人的施惠，只要请求人对故意负责即可。不过，也有人有理由认为，重大过失应包括在与故意相近的情形之中。

<!-- source-p 928 -->
<a id="43.26.8.4"></a>**4**　依本项禁令，应恢复至原先状态；若未能恢复，判决金额应为自禁令发布之时起，原告因未能取回该物所遭受的利益损失。因此，自禁令发布之日起产生的孳息也应给付。

<!-- source-p 929 -->
<a id="43.26.8.5"></a>**5**　若提出容忍请求的人未行使地役权，因而该权利消灭，应考察其是否依本项禁令承担责任。我认为，只有在其故意造成这种结果时，才承担责任。

<!-- source-p 930 -->
<a id="43.26.8.6"></a>**6**　一般而言，应当说，恢复原状所涉及的责任仅包括故意和重大过失，不包括其他情形。但禁令发布之后，则应计入故意、过失以及一切致损原因：因为某人在容忍占有关系中构成迟延后，便应对一切致损原因负责。

<!-- source-p 931 -->
<a id="43.26.8.7"></a>**7**　拉贝奥写道，本项禁令即使在一年后仍可适用，我们也遵循此规则。因为容忍关系有时会被准许持续很长时间，若说一年后禁令便不再适用，显然荒谬。

<!-- source-p 932 -->
<a id="43.26.8.8"></a>**8**　提出容忍请求者的继承人，如同请求人本人一样，应对本项禁令承担责任：无论其持有该物，还是以恶意使自己不再持有或使该物未能归其取得，均应负责；但对被继承人的故意行为，仅在其实际取得利益的范围内负责。

<!-- source-p 933 -->

无论请求人与准许人在场还是不在场，都可以成立容忍占有，例如通过信件或使者为之。

<a id="43.26.11"></a>**43.26.11**

<!-- source-p 942 -->
<a id="43.26.12"></a>**43.26.12**

<!-- source-p 943 -->
塞尔苏斯《学说汇纂》第二十五卷。

<!-- source-p 944 -->
<a id="43.26.12.pr."></a>**序言**　某物以容忍方式交付时，若约定受领人可以持有至七月朔日，他是否应获得抗辩，以免在该日之前被剥夺占有？然而，这项约定并不能产生任何效力，使其得以违背所有人意愿占有他人之物。

<!-- source-p 945 -->
<a id="43.26.12.1"></a>**1**　容忍请求关系也延及准许人的继承人；但不延及提出容忍请求者的继承人，因为占有仅准许给请求人本人，并未准许给其继承人。

<!-- source-p 946 -->
<a id="43.26.13"></a>**43.26.13**

<!-- source-p 947 -->
庞波尼《昆图斯·穆齐乌斯评注》第三十三卷。

<!-- source-p 948 -->
若你的奴隶奉你之命提出容忍请求，或者你追认了他以你名义提出的请求，你应像以容忍方式持有一样承担责任。但若奴隶或儿子在你不知情时以自己名义提出请求，则不视为你以容忍方式持有；他们可以提起特有产之诉或利益转入之诉。

<!-- source-p 949 -->
<a id="43.26.14"></a>**43.26.14**

<!-- source-p 950 -->
保罗《萨宾评注》第十三卷。

<!-- source-p 951 -->
设立容忍占有禁令确有理由，因为民法并未为此设置诉权：容忍占有的性质更接近赠与和施惠，而非缔结的交易。

<!-- source-p 952 -->
<a id="43.26.15"></a>**43.26.15**

<!-- source-p 953 -->
庞波尼《萨宾评注》第二十九卷。

<!-- source-p 954 -->
<a id="43.26.15.pr."></a>**序言**　使每个人仅在我们愿意准许的范围内使用我们的物，具有最高的衡平性。

<!-- source-p 955 -->
<a id="43.26.15.1"></a>**1**　客人以及获准免费居住的人，不视为以容忍方式居住。

<!-- source-p 956 -->
<a id="43.26.15.2"></a>**2**　容忍占有也可以针对存在于权利中的事项成立，例如梁木伸入他人建筑物或屋檐突出。

<!-- source-p 957 -->
<a id="43.26.15.3"></a>**3**　若某人已取得要求返还其物的担保，则其不得提起容忍占有禁令。

<!-- source-p 958 -->
<a id="43.26.15.4"></a>**4**　某人请求准许其占有，毫无疑问，他由此取得了占有。但对于被请求准许的人是否也占有该物，曾有疑问。通说认为，以容忍方式交出的奴隶由双方共同占有：请求人因实际控制而占有，所有人则因其占有意思并未消失而占有。

<!-- source-p 959 -->
<a id="43.26.15.5"></a>**5**　就本项禁令而言，某人是在何处以容忍方式占有或开始占有，并不重要。

<!-- source-p 960 -->
<a id="43.26.16"></a>**43.26.16**

<!-- source-p 961 -->
庞波尼《萨宾评注》第三十二卷。

<!-- source-p 962 -->
若我收养了曾请求以容忍方式占有之人，我也将以容忍方式占有。

<!-- source-p 963 -->
<a id="43.26.17"></a>**43.26.17**

<!-- source-p 964 -->
庞波尼《萨宾评注》第二十三卷。

<!-- source-p 965 -->
以容忍方式占有土地的人，可以对除其所请求之人以外的所有人，提起“如现占有”禁令。

<!-- source-p 966 -->
<a id="43.26.18"></a>**43.26.18**

<!-- source-p 967 -->
尤利安《学说汇纂》第十三卷。

<!-- source-p 968 -->

<!-- source-p 969 -->
<a id="43.26.19"></a>**43.26.19**

<!-- source-p 970 -->
尤利安《学说汇纂》第四十九卷。

<!-- source-p 971 -->
<a id="43.26.19.pr."></a>**序言**　两人不能各自对同一物享有完整的容忍占有，正如两人不能各自对同一物实施完整的暴力占有或秘密占有；因为正当占有和不正当占有都不能同时并存两项。

<!-- source-p 972 -->
<a id="43.26.19.1"></a>**1**　某人请求以容忍方式占有我的奴隶，若我追认此事，即视为其从我处以容忍方式取得，因此他应对我承担容忍占有禁令的责任。

<!-- source-p 973 -->
<a id="43.26.19.2"></a>**2**　凡有人提出容忍请求，不仅可以使用禁令，还可以提起不确定之返还诉，即以特定文字为诉因之诉。

<!-- source-p 976 -->

<a id="43.26.21"></a>**43.26.21**

<!-- source-p 978 -->

<!-- source-p 979 -->
某人请求准许其本人在土地上居住时，再加上“本人及其家属”是多余的；因为准许其本人居住，即视为也准许其家属使用。

<!-- source-p 980 -->
<a id="43.26.22"></a>**43.26.22**

<!-- source-p 981 -->
维努莱乌《禁令论》第三卷。

<!-- source-p 982 -->
<a id="43.26.22.pr."></a>**序言**　以占有人身份占有的人请求所有人准许其继续保有该物，或者买受他人之物的人请求所有人准许其继续占有，都应视为以容忍方式占有。不能认为所有人准许其以容忍方式占有便改变了占有原因；因为即使你请求他人以容忍方式准许你占有你原先已占有的物，也应视为你不再基于原原因占有，而开始以容忍方式持有。反之，若有权将物从占有人处取回的人向该占有人请求容忍，则其应承担容忍占有责任，因为通过这一请求，他取得了某种利益，即他人之物的占有。

<!-- source-p 983 -->
<a id="43.26.22.1"></a>**1**　未适婚人未经监护人认可而提出容忍请求，拉贝奥说，其仍取得容忍占有，并应受本项禁令约束。因为就其自然占有而言，监护人认可并无适用余地；而且说“你以容忍方式持有”也完全正确，因为他持有该物的原因正是提出请求并获准许。无须裁判官另行创设规则：无论该未适婚人实际持有该物与否，依其职责均应作出相应处理——若其持有该物，便受法官职责约束；若未持有，则不受约束。
