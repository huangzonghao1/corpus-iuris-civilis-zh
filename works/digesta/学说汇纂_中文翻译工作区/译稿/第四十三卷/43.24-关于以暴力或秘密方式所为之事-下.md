# D.43.24 关于以暴力或秘密方式所为之事（*Quod vi aut clam*）—下

<!-- source-p 792 -->
<a id="43.24.11"></a>**43.24.11**

<!-- source-p 793 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 794 -->
<a id="43.24.11.pr."></a>**序言**　若有人向邻人的井中倒入某物，意图借此污染井水，拉贝奥说，应依本项禁令对其起诉。因为活水被视为土地的一部分，正如有人在水中施工一样。

<!-- source-p 795 -->
<a id="43.24.11.1"></a>**1**　有人问：若某人以暴力或秘密方式从市政公共场所搬走一尊雕像，是否应依本项禁令承担责任？卡西乌斯的意见传世如下：雕像置于市政公共场所的所有人，可以依据本项禁令起诉，因为他有利益使雕像不被搬走；市政居民也可以提起盗窃之诉，因为该物已成为他们的公共财产。不过，若雕像倒下，则由市政居民自行将其移走。此说正确。

<!-- source-p 796 -->
<a id="43.24.11.2"></a>**2**　若有人从坟墓上搬走一尊雕像，享有坟墓权利的人是否可以起诉？意见认为，本项禁令也适用于此种情形。确应认为，为装饰坟墓而放置的物品属于坟墓。同理，若有人拆下或砸毁墓门，也适用本项禁令。

<!-- source-p 797 -->
<a id="43.24.11.3"></a>**3**　若有人进入我的葡萄园并从中取走葡萄藤支架，应依本项禁令承担责任。

<!-- source-p 798 -->
<a id="43.24.11.4"></a>**4**　对于裁判官所说的“凡以暴力或秘密方式所为”，应考察其指向过去还是现在。尤利安努斯讨论了这一问题，并说本项禁令中的用语应理解为指现在。不过，他又说，若工程造成损害，土地所有人或其土地受损之人已自费将工程拆除，那么较可取的见解是，应同时赔偿损害并偿还费用；尤利安努斯曾尝试提出此说。

<!-- source-p 799 -->
<a id="43.24.11.5"></a>**5**　本项禁令涵盖一切以暴力或秘密方式所为之事。有时，同一工程的一部分以暴力实施，另一部分则秘密实施。例如，我禁止你施工，你仍然打下地基；后来我已与你交涉、禁止你继续施工，而你趁我不在且不知情时完成其余工程。反过来，也可能先秘密打下地基，随后在我禁止的情况下完成其余工程。我们适用的规则是：即使同一工程既有以暴力所为的部分，也有秘密所为的部分，只须适用本项禁令即可。

<!-- source-p 800 -->
<a id="43.24.11.6"></a>**6**　若工程是奉监护人或保佐人之命实施的，依卡西乌斯所赞同的意见，未适婚人或精神失常者不因监护人或保佐人的恶意而承担责任。由此，对监护人或保佐人可以适用有益诉权，或者有益禁令。但无论如何，未适婚人和精神失常者均须容许拆除工程，并承担诺克萨责任。

<!-- source-p 801 -->
<a id="43.24.11.7"></a>**7**　对于服从监护人或保佐人命令的奴隶，是否可以宽宥？奴隶服从主人或代主人行事之人的命令时，若所涉行为不构成严重不法或犯罪，对于某些行为可以宽宥；本案也应适用此规则。

<!-- source-p 802 -->
<a id="43.24.11.8"></a>**8**　若土地在工程以暴力或秘密方式实施后被出售，出卖人是否仍可依据本项禁令起诉？有意见认为，该禁令仍然适用，不因出售而终止。买受人也不能依据买卖之诉要求出卖人就出售前实施的工程承担责任；出卖人已经因该工程而以较低价格出售土地，这已足够。即使土地并未以较低价格出售，也应作相同判断。

<!-- source-p 803 -->
<a id="43.24.11.9"></a>**9**　不过，若工程是在土地出售后实施的，即使出卖人仍可起诉——因为土地尚未交付——他仍应依据买卖之诉对买受人承担责任；一切利益与不利益都应归于买受人。

<!-- source-p 804 -->
<a id="43.24.11.10"></a>**10**　若土地以出现更优条件时可改售他人的方式出售，本项禁令应归谁行使？尤利安努斯说，应由对不实施该工程具有利益之人行使。因为土地虽已附条件出售，在买卖尚未确定转移前，一切利益和不利益都归于买受人。因此，若在此期间有人以暴力或秘密方式实施工程，即使后来出现更优条件，买受人也享有有益禁令。不过，尤利安努斯说，买受人应在买卖诉讼中交付其间取得的果实。

<!-- source-p 805 -->
<a id="43.24.11.11"></a>**11**　阿里斯托则写道，通知不必送达占有人。例如，有人将土地出售给我，尚未交付；邻人打算施工，且知道我已经买下土地并住在其上，却向我发出通知，则该邻人就避免被指控秘密施工而言是安全的。此说确实正确。

<!-- source-p 806 -->
<a id="43.24.11.12"></a>**12**　若土地在出现更优条件后以可撤回许可方式交付，我认为买受人可以行使本项禁令。若尚未交付，或者已经请求以可撤回许可方式占有，则我认为毫无疑问应由出卖人行使本项禁令：即使风险已经转由买受人承担，也应由出卖人行使。买卖订立后，风险即归于买受人；但在交付之前，从未有人因此主张买受人享有本项禁令。若买受人以可撤回许可方式占有，我们还应考察：既然他无论以何种方式占有都具有自身利益，是否已经可以使用本项禁令。因此，若他是承租人，则更应如此；承租人可以依本项禁令起诉，这一点毫无疑问。不过，若在出现更优条件之后才有人以暴力或秘密方式施工，尤利安努斯也不会怀疑出卖人享有本项禁令。因为卡西乌斯与尤利安努斯的争议仅在于此前期间发生的事情，而不在于后来发生的工程。

<!-- source-p 807 -->
<a id="43.24.11.13"></a>**13**　若土地出售时约定买受人不满意即可视为未曾买卖，只要买受人已经占有土地，我们更容易承认其享有本项禁令。若是否解除买卖交由另一人决定，也应作同样判断。若约定发生某事时土地即视为未曾出售，或者依解除条款出售土地，也应作相同判断。

<!-- source-p 808 -->
<a id="43.24.11.14"></a>**14**　尤利安努斯还写道，本项禁令不仅属于土地所有人，也属于其他对不实施该工程具有利益的人。

<a id="43.24.13"></a>**43.24.13**

<!-- source-p 813 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 814 -->
<a id="43.24.13.pr."></a>**序言**　若有人砍伐提图斯享有用益权的土地上的树木，无论行为人是第三人还是土地所有人，提图斯均可分别依据《阿奎利亚法》和本项禁令对二人起诉。

<!-- source-p 815 -->
<a id="43.24.13.1"></a>**1**　拉贝奥写道，若儿子禁止施工而工程仍被实施，则无论工程是违背你还是违背你儿子的禁止而实施，你和你儿子都可以使用本项禁令。

<!-- source-p 816 -->
<a id="43.24.13.2"></a>**2**　拉贝奥还说，若行为人知道某人是家子，则不能认为他是秘密针对该家子行事；因为行为人确信该家子本人不能对他提起诉讼。

<!-- source-p 817 -->
<a id="43.24.13.3"></a>**3**　若共有土地的共有人之一砍伐树木，其他共有人可以依据本项禁令对其起诉，因为对不砍伐树木具有利益的人均可使用该禁令。

<!-- source-p 818 -->
<a id="43.24.13.4"></a>**4**　因此，塞尔维乌斯还记载，若你准许我砍伐你土地上的树木，而后来他人以暴力或秘密方式砍伐树木，我可以使用本项禁令，因为我具有利益。若我向你购买了砍伐权，或依据其他合同取得砍伐权，则更容易承认这一点。

<!-- source-p 819 -->
<a id="43.24.13.5"></a>**5**　有人问：若某土地一度无人所有时，有人以暴力或秘密方式实施了某行为，后来土地所有权归于某人，本项禁令是否可以适用？例如，遗产尚未被接受，后来提图斯接受了该遗产，他是否享有本项禁令？维维阿努斯多次记载，继承人可以就接受遗产前实施的行为使用本项禁令。拉贝奥说，未来继承人当时尚未确定，并不影响这一结论；即使遗产已被接受，也仍可提出同样理由。拉贝奥还说，行为发生时无人是所有人，也不妨碍适用本项禁令：坟墓也没有所有人，但若有人在坟墓中实施行为，我仍可依据本项禁令起诉。此外，遗产处于所有人的地位。正确的结论是，继承人及其他继受人均可使用本项禁令，无论有关行为发生在继承前还是继承后。

<!-- source-p 820 -->
<a id="43.24.13.6"></a>**6**　若我的承租人实施工程，并且我是表示同意或追认，则与我的代理人实施工程相同。若承租人依我的意思施工，我须承担责任；若代理人施工而我予以追认，我也须承担责任。

<!-- source-p 821 -->
<a id="43.24.13.7"></a>**7**　尤利安努斯说，若承租人砍伐有争议的树木或实施其他工程，且是奉土地所有人之命，则二人均须承担责任，不仅要容许恢复原状，还须支付恢复费用。若土地所有人未曾下令，则承租人须容许恢复原状并支付费用；土地所有人仅须容许恢复原状。

<a id="43.24.15"></a>**43.24.15**

<!-- source-p 826 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 827 -->
<a id="43.24.15.pr."></a>**序言**　本项禁令始终可以针对工程的占有人适用。因此，无论何人未经我知情，甚至违背我的意愿，在我的土地上施工，均可适用本项禁令。

<!-- source-p 828 -->
<a id="43.24.15.1"></a>**1**　你将土地出租给某人耕翻，他取走石块并将其抛到邻人的土地上。拉贝奥说，除非该行为奉你之命实施，否则你不因暴力或秘密施工而承担责任。我认为，承租人应承担责任；出租人仅在能够容许恢复原状或能够提供某项诉权时才承担责任，否则不应令其承担责任。

<!-- source-p 829 -->
<a id="43.24.15.2"></a>**2**　若奉我之命在他人坟墓上堆土，拉贝奥写道，可以依据“凡以暴力或秘密方式所为”对我起诉。若多人共同商议实施该行为，可以对其中一人或所有人起诉；多人共同实施不可分的工程时，每个人均负全部责任。但若他们各自独立决定实施该行为，则可以对所有人分别起诉，且每人均负全部责任。在后一情形中，对一人的起诉不使其他人免责；相反，对一人取得的给付也不免除其他人的责任。在前一情形中，对一人的起诉则使其他人免责。此外，也可以提起坟墓遭亵渎之诉。

<!-- source-p 830 -->
<a id="43.24.15.3"></a>**3**　本项禁令可以针对继承人及其他继受人提起，但责任以实际归于他们的利益为限。

<!-- source-p 831 -->
<a id="43.24.15.4"></a>**4**　一年后，本项禁令即不再适用。一年期间自工程完成之日，或工程停止之日起算，即使工程尚未完成亦然。否则，若从工程开始时起算，对于施工最慢的人，就不得不反复提起诉讼。

<!-- source-p 832 -->
<a id="43.24.15.5"></a>**5**　不过，若工程所在地点难以到达，例如在坟墓中或其他偏僻处以暴力或秘密方式施工，或者工程在地下、水下或下水道中实施，即使一年后，也可经查明具体情况后适用本项禁令。若存在重大且正当的理由导致不知情，经查明情况后，应免除一年期间的抗辩。

<!-- source-p 833 -->
<a id="43.24.15.6"></a>**6**　若某人为公共事务离境，返乡后打算使用本项禁令，较妥当的见解是，不得以一年期间排除其请求，而应自其返乡起算一年。即使某人未满二十五岁时因公共事务离境，在离境期间年满二十五岁，也应自返乡起算一年，而非自其年满二十五岁之日起算。神圣的皮乌斯皇帝及其后继的所有元首均曾如此答复。

<!-- source-p 834 -->
<a id="43.24.15.7"></a>**7**　本项禁令的诉讼金额，以原告对该工程未曾实施所具有的利益为准。法官应依职权判令恢复原状，使原告的处境与工程既未以暴力、也未秘密实施时完全相同。

<!-- source-p 835 -->
<a id="43.24.15.8"></a>**8**　因此，有时还须考虑所有权关系。例如，该工程导致地役权丧失或用益权消灭。此种情形不仅可能发生于有人建造工程，也可能发生于有人拆除工程并因此损害地役权、用益权或所有权本身。

<!-- source-p 836 -->
<a id="43.24.15.9"></a>**9**　原告的利益，应由其在诉讼中宣誓确定；若其不能宣誓，则由法官依职权评定。

<!-- source-p 837 -->
<a id="43.24.15.10"></a>**10**　若某人以恶意使自己无法恢复原状，应视同其能够恢复原状。

<!-- source-p 838 -->
<a id="43.24.15.11"></a>**11**　应认定过失也属于本项禁令的责任范围，但其程度应由法官酌情评定。

<!-- source-p 839 -->
<a id="43.24.15.12"></a>**12**　由于本项禁令涵盖原告的利益，若原告已通过其他诉讼取得了其因不实施该工程而享有的利益，则应认为其不得再依据本项禁令取得任何利益。

<a id="43.24.16"></a>**43.24.16**

<!-- source-p 841 -->
保罗《告示评注》第六十七卷。

<!-- source-p 842 -->
<a id="43.24.16.pr."></a>**序言**　只要具有相应利益，即使并非占有人，也可以适用本项禁令。

<!-- source-p 843 -->
<a id="43.24.16.1"></a>**1**　若有人以暴力或秘密方式砍伐不结果实的树木，例如柏树，只有土地所有人可以适用本项禁令。不过，若此类树木提供某种景致，用益权人也可能因享有观赏和骑乘游乐等利益而有权使用本项禁令。

<!-- source-p 844 -->
<a id="43.24.16.2"></a>**2**　总之，以暴力或秘密方式施工且占有工程的人，须容许拆除工程并支付费用；实施工程但不占有工程的人，只须支付费用；占有工程但并未实施工程的人，则只须容许拆除。

<a id="43.24.20"></a>**43.24.20**

<!-- source-p 856 -->
保罗《萨宾努斯评注》第十三卷。

<!-- source-p 857 -->
<a id="43.24.20.pr."></a>**序言**　无论是被禁止后仍然施工的人，还是设法使自己不受禁止而施工的人，都属于以暴力行事；例如，以威吓阻止对方发出通知，或将门对其关上。

<!-- source-p 858 -->
<a id="43.24.20.1"></a>**1**　所谓受到禁止，是指禁止者以任何方式表示禁止，例如口头说明禁止，或者伸手阻挡、为了制止而投掷石子。

<!-- source-p 859 -->
<a id="43.24.20.2"></a>**2**　受禁止者只有在情势仍未改变期间才属于以暴力行事；若后来与对方达成协议，即不再以暴力行事。

<!-- source-p 860 -->
<a id="43.24.20.3"></a>**3**　庞波尼乌斯说，受到禁止者的继承人，或从其处买受该物的人，若不知先前发生的情形而施工，则应认为其不受本项禁令约束。

<!-- source-p 861 -->
<a id="43.24.20.4"></a>**4**　在船舶或其他任何动产上实施的行为，即使该物体积庞大，也不属于本项禁令的适用范围。

<!-- source-p 862 -->
<a id="43.24.20.5"></a>**5**　无论工程是在私人土地、公共土地、神圣场所还是宗教场所实施，本项禁令均适用。

<!-- source-p 863 -->
<a id="43.24.21"></a>**43.24.21**

<!-- source-p 864 -->
庞波尼乌斯《萨宾努斯评注》第二十九卷。

<!-- source-p 865 -->
<a id="43.24.21.pr."></a>**序言**　若有人经法官命令依本项禁令恢复工程，而另一人又以暴力或秘密方式拆除了该工程，先前受命之人仍应无条件地恢复工程。

<!-- source-p 866 -->
<a id="43.24.21.1"></a>**1**　若我命自己的奴隶施工，就我本人而言并无秘密施工的嫌疑，但我的奴隶认为，若对方知道施工，就会禁止施工，那么我是否承担责任？我认为不承担责任，因为应考察的是我本人的情形。

<!-- source-p 867 -->
<a id="43.24.21.2"></a>**2**　对于新工程，应当同时测量土地及其上方空间。

<!-- source-p 868 -->
<a id="43.24.21.3"></a>**3**　若某人因已经实施的工程而丧失了土地上的某项权利，应依本项禁令恢复该权利。

<!-- source-p 869 -->
<a id="43.24.22"></a>**43.24.22**

<!-- source-p 870 -->
维努莱乌斯《禁令论》第二卷。

<!-- source-p 871 -->
<a id="43.24.22.pr."></a>**序言**　若你发现我的葡萄藤从我的土地蔓延到你的土地，并已在你的土地上扎根，一年内可以适用本项有益禁令。但若一年已经过去，则不再保留诉权；位于你土地中的根因添附而成为你的。

<!-- source-p 872 -->
<a id="43.24.22.1"></a>**1**　若有人以暴力或秘密方式耕犁土地，我认为其承担本项禁令责任，正如挖掘沟渠一样。本项禁令的适用并不取决于工程的性质，而取决于是否实施了附着于土地的工程。

<!-- source-p 873 -->
<a id="43.24.22.2"></a>**2**　若你把木板钉在我的门上，而我在通知你之前将其拆下，随后我们彼此依据本项禁令起诉，则除非你放弃对我的请求、使我获判免责，否则应判你承担我因未恢复原状所受的利益损失；或者，我至少可以提出如下抗辩：“你本人并非以暴力、秘密方式或基于可撤销许可实施该行为。”

<!-- source-p 874 -->
<a id="43.24.22.3"></a>**3**　若你违背我的禁止，将粪肥运过我的土地，尽管并未使我受损，也未改变我土地的状况，特雷巴提乌斯仍说，你须依“凡以暴力或秘密方式所为”承担责任。拉贝奥则持相反意见，以免仅仅经过我的土地，或者驱赶禽鸟、打猎而未实施任何工程的人，也受到本项禁令约束。

<!-- source-p 875 -->
<a id="43.24.22.4"></a>**4**　若有人将突出物伸入坟墓，或使滴水落入坟墓，即使未触及墓体本身，也可以正当地依据“凡以暴力或秘密方式在坟墓中所为”起诉。因为坟墓不仅包括容纳埋葬的地点，也包括其上方的整个空间。因此，还可以提起坟墓遭亵渎之诉。

<!-- source-p 876 -->
<a id="43.24.22.5"></a>**5**　若某人通知将要施工后立即施工，不视为秘密施工；若过了一段时间才施工，则视为秘密施工。
