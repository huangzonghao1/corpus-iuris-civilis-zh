# D.43.3 关于遗赠物的禁令（*Quod legatorum*）

> 底本：*Digesta Iustiniani*，EPUB `book-43.xhtml`，source-p 32–59。

<!-- source-p 32 -->
<a id="3"></a><a id="43.3"></a>**43.3.0**　关于遗赠物的禁令。

<!-- source-p 33 -->
<a id="43.3.1"></a>**43.3.1**

<!-- source-p 34 -->
乌尔比安《告示评注》第六十七卷。

<!-- source-p 35 -->
<a id="43.3.1.1"></a>**1**　通常将此禁令称为“关于遗赠物的禁令”。

<!-- source-p 36 -->
<a id="43.3.1.2"></a>**2**　该禁令本身也是为取得占有而设，其内容是：某人未经继承人同意，以遗赠为名占有财物的，应将该物返还给继承人。法务官认为，最为公平的做法是任何人不得自行以占有遗赠物的方式主张权利，而应向继承人请求给付。因此，法务官通过此禁令将以遗赠为名占有的财物交还给继承人，使受遗赠人能够相应地对继承人提起诉讼。

<!-- source-p 37 -->
<a id="43.3.1.3"></a>**3**　为实现该禁令的目的，应当认为，继承人的继承人、遗产占有人以及其他继受人也享有此禁令。

<!-- source-p 38 -->
<a id="43.3.1.4"></a>**4**　有时无法确定某人是以受遗赠人、继承人还是占有人身份占有财物。阿里安努斯非常妥当地写道：应提起遗产请求之诉，并同时发布此禁令；这样，无论某人是以继承人、占有人还是受遗赠人身份占有，均受该禁令约束。每当无法确定哪一种诉权更适用时，我们通常也如此处理：同时提出两项诉讼，并声明我们希望通过其中一项取得依法应归于我们的利益。

<!-- source-p 39 -->
<a id="43.3.1.5"></a>**5**　若某人基于死因赠与占有财物，该禁令当然不适用，因为《法尔基丢法》规定的份额依法仍归继承人所有，即使财物在事实上已经全部移转给受领人：

<!-- source-p 40 -->
<a id="43.3.1.6"></a>**6**　但依预取遗赠（*praeceptio*）方式受领财物的人，确实受此禁令约束；不过，仅就其依法作为遗赠取得的部分而言，而不包括其作为继承人所取得的部分。若某一继承人以其他种类的遗赠取得财物，也应作同样处理：就其作为继承人取得的部分，禁令不适用。

<!-- source-p 41 -->
<a id="43.3.1.7"></a>**7**　法务官所说的“或者因欺诈而不再占有”，应理解为“因欺诈而不再具有返还该物的能力”。

<!-- source-p 42 -->
<a id="43.3.1.8"></a>**8**　因此有人问，若某人占有了遗赠给他的用益权或使用权，是否应依此禁令被迫返还。问题在于，用益权和使用权并非作为物而被占有，而是被持有；不过，仍可主张此禁令适用。遗赠地役权时，也应作同样处理。

<!-- source-p 43 -->
<a id="43.3.1.9"></a>**9**　有人问，为保全遗赠而被准许进入占有的人，是否受此禁令约束并须返还。首先值得考虑的是，此人并非以占有遗赠物的方式占有，而只是保管该物；其次，准许其占有的是法务官。然而，更稳妥的说法是此禁令适用，尤其是他已经就遗赠提供了担保而仍不退出占有的情形；在这种情况下，他也被视为占有人。

<!-- source-p 44 -->
<a id="43.3.1.10"></a>**10**　以遗赠为名占有的人，不仅包括受遗赠人本人，也包括其继承人及其他继受人。

<!-- source-p 45 -->
<a id="43.3.1.11"></a>**11**　法务官所说的“经对该物享有权利之人的同意”，应作如下解释：若继承开始或遗产占有获承认后，该权利人同意受遗赠人占有该物，则禁令不适用；但若在继承开始或遗产占有获承认之前便作出同意，更妥当的意见是该同意不应对权利人产生不利影响。

<!-- source-p 46 -->
<a id="43.3.1.12"></a>**12**　若遗赠了两项财物，一项经权利人同意而被占有，另一项未经同意而被占有，则前者不得追回，后者可以追回。一项财物的不同部分分别在同意与未经同意的情况下被占有，也应作同样处理：只能通过禁令追回未经同意占有的部分。

<!-- source-p 47 -->
<a id="43.3.1.13"></a>**13**　应当遵循以下规则：无论某物是由你本人，还是由你所承继其地位之人开始占有，都适用此禁令。所谓承继其地位，包括概括继承，也包括对特定物的承继。

<!-- source-p 48 -->
<a id="43.3.1.14"></a>**14**　经对该物享有权利之人同意而开始占有，对占有人有利；即使该权利人后来才表示同意，也应使占有人受益。因此，若某人起初经权利人同意而开始占有，后来权利人撤回同意，也不产生不利后果，因为占有一开始就是经同意取得的。

<!-- source-p 49 -->
<a id="43.3.1.15"></a>**15**　若数名继承人或其他对该物享有权利之人中，一人同意受遗赠人占有该物，另一人不同意，则不同意者享有禁令；显然，同意者不享有禁令。

<!-- source-p 50 -->
<a id="43.3.1.16"></a>**16**　法务官所说的“除非已经提供担保”，应理解为“只要担保持续有效”。也就是说，若担保不再有效，应准许受遗赠人进入占有，以保全遗赠。

<!-- source-p 51 -->
<a id="43.3.1.17"></a>**17**　我认为，只有在受遗赠人依法律本身已经取得适当担保，或可通过委任之诉取得该担保时，才算提供了有效担保；此时该禁令才适用。

<!-- source-p 52 -->
<a id="43.3.1.18"></a>**18**　若某些财物已提供担保，另一些没有，则可不受阻碍地就已提供担保的财物提起诉讼；对其余财物则不得提起。

<!-- source-p 53 -->
<a id="43.3.2"></a>**43.3.2**

<!-- source-p 54 -->
保罗《告示评注》第六十三卷。

<!-- source-p 55 -->
<a id="43.3.2.pr."></a>**序言**　若之后又有一部分遗赠归入原遗赠，则保证人应就全部遗赠承担责任。

<!-- source-p 56 -->
<a id="43.3.2.1"></a>**1**　法务官所说的“若遗产占有人并未阻止提供担保”，应理解为其愿意提供担保。因此，他无须主动提出担保；只须在受遗赠人请求时，不对提供担保造成任何迟延。

<!-- source-p 57 -->
<a id="43.3.2.2"></a>**2**　不依此禁令返还财物的人，应按受遗赠人因此所受损失的金额被判承担责任。

<!-- source-p 58 -->
<a id="43.3.2.3"></a>**3**　若受遗赠人满足于对方作出的承诺，应当授予禁令。受遗赠人不愿接受质押担保时，也应作同样处理。

<!-- source-p 59 -->
<a id="43.3.2.4"></a>**4**　若因受遗赠人的原因未能提供担保，即使最终未提供担保，他仍受此禁令约束。但若受遗赠人曾阻挠提供担保，而在禁令发布之时又已准备好接受担保，则除非担保已经提供，否则禁令不适用。反之，若因遗产占有人阻挠而未提供担保，但他现在已准备好提供担保，则禁令仍然适用；因为应考察禁令发布之时的情形。
