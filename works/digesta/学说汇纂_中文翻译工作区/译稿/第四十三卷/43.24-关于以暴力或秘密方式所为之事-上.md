# D.43.24 关于以暴力或秘密方式所为之事（*Quod vi aut clam*）—上

<!-- source-p 715 -->
<a id="24"></a><a id="43.24"></a>**43.24.0**　关于以暴力或秘密方式所为之事。

<!-- source-p 716 -->
<a id="43.24.1"></a>**43.24.1**

<!-- source-p 717 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 718 -->
<a id="43.24.1.pr."></a>**序言**　裁判官说：“凡以暴力或秘密方式所为、且为本案争议对象的事项，在可以提起诉讼时，你应将其恢复原状。”

<!-- source-p 719 -->
<a id="43.24.1.1"></a>**1**　本项禁令属于恢复原状的禁令，用以应对那些以诡计施行暴力或秘密实施某些工程之人的行为；他们因此被命令恢复原状。

<!-- source-p 720 -->
<a id="43.24.1.2"></a>**2**　行为人是否有权实施该行为，并无多大关系：无论其有权还是无权，只要以暴力或秘密方式实施了该行为，仍须承担本项禁令的责任。因为他本应维护自己的权利，而不应制造侵害。

<!-- source-p 721 -->
<a id="43.24.1.3"></a>**3**　因此有人曾问，使用本项禁令的人是否可能遭遇如下抗辩：“我取得该物并非无权。”较妥当的见解是，此抗辩不得提出；对于暴力行为或秘密所为，任何正当抗辩都不能使行为人获得保护。

<!-- source-p 722 -->
<a id="43.24.1.4"></a>**4**　本项禁令仅适用于在土地上以暴力或秘密方式实施的工程。

<!-- source-p 723 -->
<a id="43.24.1.5"></a>**5**　现考察何为以暴力所为或秘密所为。昆图斯·穆齐乌斯写道，若有人违背他人禁止而行事，即视为以暴力所为。我认为，昆图斯·穆齐乌斯的定义完整无缺。

<!-- source-p 724 -->
<a id="43.24.1.6"></a>**6**　佩迪乌斯和庞波尼乌斯还写道，即使有人投掷了极小的石子以示禁止，而行为人仍坚持实施该行为，也应视为其以暴力所为；我们适用的正是这一规则。

<!-- source-p 725 -->
<a id="43.24.1.7"></a>**7**　卡斯凯利乌斯和特雷巴提乌斯认为，行为人违背正式声明或通知而行事，也适用同一规则；此说正确。

<!-- source-p 726 -->
<a id="43.24.1.8"></a>**8**　阿里斯托还说，若有人明知自己将被禁止，却以暴力方式预先行事，使自己不可能遭到制止，他也属于以暴力行事。

<!-- source-p 727 -->
<a id="43.24.1.9"></a>**9**　拉贝奥又说，若我制止某人施工，而他当时暂且停止，后来又开始施工，则视为其以暴力所为；但若他是在得到我的许可或出现其他正当理由后才开始施工，则不在此限。

<!-- source-p 728 -->
<a id="43.24.1.10"></a>**10**　不过，若某人因体弱而无法前来制止，或者为避免冒犯你或敬重你的人而没有前来，则不得认为对方是以暴力行事。拉贝奥即如此写道。

<!-- source-p 729 -->
<a id="43.24.1.11"></a>**11**　拉贝奥还说，若你本想前来制止，却被他人（例如持械者）吓阻，且这并非我的恶意所致，因此你没有前来，则不得认为我实施了暴力。

<!-- source-p 730 -->
<a id="43.24.2"></a>**43.24.2**

<!-- source-p 731 -->
维努莱乌斯《禁令论》第二卷。

<!-- source-p 732 -->
不应使无过错者的处境恶化，使其陷于他人支配之下。

<!-- source-p 733 -->
<a id="43.24.3"></a>**43.24.3**

<!-- source-p 734 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 735 -->
<a id="43.24.3.pr."></a>**序言**　禁止施工不必由权利人亲自作出；若其通过自己的奴隶或代理人予以禁止，也视为有效禁止。即使由我的雇工禁止，亦同。不要因为通常不能通过自由人取得诉权而感到疑惑：此处的禁止表明你是以暴力行事；你秘密对我施工时，我为何不能取得诉权？因此，我取得诉权，是因为你的不法行为归于你本人，而不是因为他人的行为。

<!-- source-p 736 -->
<a id="43.24.3.1"></a>**1**　应知，暴力并非在每一时刻都须重新实施；一旦在开始时发生，便持续存在。

<!-- source-p 737 -->
<a id="43.24.3.2"></a>**2**　不过，若权利人后来给予许可，对于使用本项禁令的人，有必要提出抗辩。

<!-- source-p 738 -->
<a id="43.24.3.3"></a>**3**　不仅我本人给予许可时如此；若我的代理人、实际管理监护事务的监护人，或者未适婚人、精神失常者或未成年人的保佐人给予许可，也应认为可以提出该抗辩。

<!-- source-p 739 -->
<a id="43.24.3.4"></a>**4**　但若行省总督或市政管理人许可他人在公共场所施工，内尔瓦写道，不能提出该抗辩。因为虽将公共场所的管理职责交给了他们，却未授予其特许他人使用的权力。若市政法赋予市政管理人更广泛的权限，则不在此限。若许可来自元首，或来自元首授予此项许可权的人，也应作相同判断。

<!-- source-p 740 -->
<a id="43.24.3.5"></a>**5**　若某人愿意在法庭上为自己辩护，以回应认为应发布禁令禁止施工的人，是否视为其不再以暴力行事？较妥当的见解是：只要他提出担保，并准备在有人起诉时应诉，即不再以暴力行事。萨宾努斯也如此写道。

<!-- source-p 741 -->
<a id="43.24.3.6"></a>**6**　若某人愿意为潜在损害提供担保，而他此前仅因未作辩护或未提供该项担保才遭到禁止，那么也应认为其不再以暴力行事。

<!-- source-p 742 -->
<a id="43.24.3.7"></a>**7**　卡西乌斯写道，若有人隐瞒施工，不通知对方，且他担心对方会提出争议或理应预见到该争议，则其属于秘密施工。

<!-- source-p 743 -->
<a id="43.24.3.8"></a>**8**　阿里斯托也认为，若某人有意隐瞒施工，且知道或理应知道对方将禁止施工，则该人属于秘密施工。

<!-- source-p 744 -->
<a id="43.24.4"></a>**43.24.4**

<!-- source-p 745 -->
维努莱乌斯《禁令论》第二卷。

<!-- source-p 746 -->
塞尔维乌斯认为，若某人理应预见到将发生争议，也属于秘密施工。判断时不应依行为人本人的意见——更不应依其轻率的判断——否则愚者反而会比有经验者处境更好。

<!-- source-p 747 -->
<a id="43.24.5"></a>**43.24.5**

<!-- source-p 748 -->
乌尔比安《告示评注》第七十卷。

<!-- source-p 749 -->
<a id="43.24.5.pr."></a>**序言**　以下情形也属于秘密施工：行为人所作与其通知的内容不同；欺骗有权要求其不施工的人后施工；明知对方无法制止，仍故意在此时通知；或者通知得太迟，以致对方即使想来制止，也无法在施工开始前赶到。阿里斯托说，拉贝奥赞同这些意见。

<!-- source-p 750 -->
<a id="43.24.5.1"></a>**1**　某人通知将要施工，并不意味着其通知后施工就绝不属于秘密施工。通知应当载明日期、时刻、地点及施工内容，拉贝奥也如此主张；不得敷衍或含糊地通知，也不得把时间压缩到使对方无法在当天赶来制止。

<!-- source-p 751 -->
<a id="43.24.5.2"></a>**2**　若当时没有可通知的人，且这种情形并非出于恶意，则应通知其朋友、代理人，或者通知其家中之人。

<!-- source-p 752 -->
<a id="43.24.5.3"></a>**3**　塞尔维乌斯正确地说，若要通知妇女，告知其丈夫将要施工即为足够；或者，只要对方知情而仍然施工，也足够。即使没有隐瞒的意图，本身也足以排除秘密施工。

<!-- source-p 753 -->
<a id="43.24.5.4"></a>**4**　塞尔维乌斯还说，若有人打算在市政公共场所施工，只须通知市政管理人即可。

<!-- source-p 754 -->
<a id="43.24.5.5"></a>**5**　若某人误以为地点属于你、实则属于我，并且为了不让你知晓而施工，则我有权使用本项禁令。

<!-- source-p 755 -->
<a id="43.24.5.6"></a>**6**　塞尔维乌斯还说，若施工是为了不让我的奴隶或代理人知晓，我也有权使用本项禁令。

<!-- source-p 756 -->
<a id="43.24.5.7"></a>**7**　若某人没有通知自己将要施工，而他人又通知他不得施工，但他仍然施工，我认为较妥当的见解是，应认定其以暴力所为。

<!-- source-p 757 -->
<a id="43.24.5.8"></a>**8**　穆齐乌斯说，裁判官用语“凡以暴力或秘密方式所为”，应理解为“你本人、你的人或奉你之命所为”。

<!-- source-p 758 -->
<a id="43.24.5.9"></a>**9**　不过，拉贝奥认为，这些用语还包括其他主体。他认为，穆齐乌斯列举之人的继承人当然也包括在内。

<!-- source-p 759 -->
<a id="43.24.5.10"></a>**10**　拉贝奥还说，可以就他人的事务，以他人名义对代理人、监护人、保佐人或市政当局的代表请求发布禁令。

<!-- source-p 760 -->
<a id="43.24.5.11"></a>**11**　若我的奴隶实施了某行为，并非仅因此就可以对我提起诉讼；只有其以我的名义或以自己的名义实施时，才可如此。若我雇用了你的奴隶，那么该奴隶以我的名义实施的任何行为，都应依本项禁令起诉我，而非起诉你——也就是应起诉其为之行事的人，或以其名义施工的人。

<!-- source-p 761 -->
<a id="43.24.5.12"></a>**12**　同样，若某行为是奉某人之命实施的，应就此起诉其所代表的人，而非发出命令的人。例如，代理人、监护人、保佐人或市政当局的二人执政官，代表其所管理事务之人命令施工，应起诉其所代表的人，而非发出命令的人。若我委托你命人施工，而你依我指示行事，乌尔比安说，应起诉我，而不是你。

<!-- source-p 762 -->
<a id="43.24.5.13"></a>**13**　本项禁令的用语是“凡以暴力或秘密方式所为”，而不是“凡你以暴力或秘密方式所为”；拉贝奥认为，因此其适用范围比我们上文列举的主体更广。

<!-- source-p 763 -->
<a id="43.24.5.14"></a>**14**　我们适用的规则是：无论行为由我亲自实施，还是由我命人实施，我都须承担本项禁令的责任。

<!-- source-p 764 -->
<a id="43.24.6"></a>**43.24.6**

<!-- source-p 765 -->
保罗《告示评注》第六十七卷。

<!-- source-p 766 -->
若我委托你实施新工程，而你又委托他人施工，便不能认为该工程是奉我之命实施的。因此，你和实际施工者均须承担责任。至于我是否也须承担责任，尚需考察。较妥当的见解是，我也须承担责任，因为我是该事的起始者；但三人中只要一人履行义务，其余人即获免责。

<!-- source-p 767 -->
<a id="43.24.7"></a>**43.24.7**

<!-- source-p 768 -->
乌尔比安《告示评注》第七十一卷。

<!-- source-p 769 -->
<a id="43.24.7.pr."></a>**序言**　若他人违背我的意愿施工，我所负的义务仅是容许其恢复原状。

<!-- source-p 770 -->
<a id="43.24.7.1"></a>**1**　涅拉提乌斯也写道，奴隶以暴力或秘密方式施工时，奴隶主应依本项禁令自费恢复工程，或者容许恢复原状并将奴隶交付以供诺克萨责任执行。但若奴隶已经死亡或被转让，奴隶主仅须容许恢复原状；买受人也可能依本项禁令被诉，须支付费用或交付奴隶以供诺克萨责任执行。工程所有人自费恢复原状，或因未恢复而被判承担诉讼估价时，买受人即获免责。奴隶主本人恢复工程或因未恢复而被判承担诉讼估价时，亦同。但若奴隶主仅交付奴隶以供诺克萨责任执行，则可以有效地对工程所有人使用有益禁令。

<!-- source-p 771 -->
<a id="43.24.7.2"></a>**2**　尤利安努斯说，若有人在新工程通知尚未撤回前，违背禁止而施工，则须承担两项禁令的责任：一项源于新工程通知，另一项即本项关于暴力或秘密所为的禁令。通知撤回后，即使仍有人禁止施工，也不再视为以暴力或秘密方式施工；提供担保者应当可以建造，因为其已据此取得占有人的地位。通知撤回前后，也都不应认为其属于秘密施工：发出新工程通知的人不能被视为遭到隐瞒或被抢先行事，因为在争议发生之前，他并未被蒙蔽。

<!-- source-p 772 -->
<a id="43.24.7.3"></a>**3**　尤利安努斯提出一个很有意思的问题：本项禁令中的抗辩“你并未以暴力或秘密方式行事”，是否也可用于反诉的情形？例如，我依据本项禁令对你起诉，你能否对我提出同一抗辩，即“你本人也曾以暴力或秘密方式行事”？尤利安努斯说，给予这一抗辩最为公平。比如，你以暴力或秘密方式建造，我又以暴力或秘密方式拆除，而你依据本项禁令起诉我，则该抗辩对我有利。但只有在重大且充分必要的理由下，才应如此处理；否则，这些事项均应由法官依职权处理。

<!-- source-p 773 -->
<a id="43.24.7.4"></a>**4**　还有另一项抗辩，凯尔苏斯不确定是否应当提出。例如，为了阻止火势蔓延，我拆毁邻人的房屋，随后他依据本项禁令或《阿奎利亚法》对我起诉。加卢斯怀疑是否应准许我提出如下抗辩：“该行为并非为防止火灾而实施。”塞尔维乌斯则认为，若该行为由行政长官实施，应准许提出；若由私人实施，则不应同样准许。不过，若以暴力或秘密方式所为，而火尚未蔓延到该房屋，则应按单倍金额评定诉讼标的；若火已蔓延至该处，则应判被告无责任。若依据《阿奎利亚法》起诉，也应如此，因为对于本来就将被焚毁的房屋，不会造成不法损害。拉贝奥说，若行为实施时并无火灾，后来才发生火灾，则不能作相同判断；应根据行为发生时的状态，而非事后情况，评定是否造成损害。

<!-- source-p 774 -->
<a id="43.24.7.5"></a>**5**　上文已经指出，尽管禁令文字的范围很广，本项禁令仍仅适用于在土地上实施的工程。触及果实的人不承担本项禁令责任，因为其并未在土地上施工。但砍伐树木的人当然承担责任，砍伐芦苇或柳树的人亦然，因为他们损害了土地，某种意义上是直接损害土地本身。砍伐葡萄藤也适用同一规则。至于摘取果实的人，应依盗窃之诉起诉。因此，只要是在土地上实施某种工程，本项禁令即适用。所谓在土地上实施，也包括对树木本身所作的行为，但不包括对树上果实所作的行为。

<!-- source-p 775 -->
<a id="43.24.7.6"></a>**6**　若有人把粪堆散布在肥沃的田地周围，可以依据“凡以暴力或秘密方式所为”对其起诉；此说正确，因为土地因此遭到损害。

<!-- source-p 776 -->
<a id="43.24.7.7"></a>**7**　不过，若某行为是为耕种土地而实施，且使土地状况得到改善，即使行为人以暴力或秘密方式违背禁止实施该行为，本项禁令也不适用。

<!-- source-p 777 -->
<a id="43.24.7.8"></a>**8**　此外，若你在公共林地挖了一条沟，我的牛掉进沟里，我可以依据本项禁令起诉，因为工程是在公共土地上实施的。

<!-- source-p 778 -->
<a id="43.24.7.9"></a>**9**　若某人拆毁建筑物，即使没有拆至地面，也已无疑属于本项禁令的适用范围。

<!-- source-p 779 -->
<a id="43.24.7.10"></a>**10**　同理，若有人从建筑物上拆走瓦片，较妥当的见解是，本项禁令也适用。
