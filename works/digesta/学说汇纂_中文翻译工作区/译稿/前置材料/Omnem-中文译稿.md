# 《Omnem》敕令

## 致法学教授

**皇帝凯撒·弗拉维乌斯·查士丁尼，阿勒曼尼库斯、哥特库斯、法兰克库斯、日耳曼尼库斯、安提库斯、阿兰尼库斯、汪达尔库斯、阿非利加库斯，虔敬者、幸运者、显赫者、胜利者、凯旋者，永远的奥古斯都，致显贵的法学教授塞奥菲卢斯、多罗塞乌斯、塞奥多罗斯、伊西多罗斯、阿纳托利乌斯、萨莱利乌斯（Thalelaeus）与克拉提努斯，以及极富雄辩才华的法学教授萨拉米尼乌斯：致意。**

<a id="Omnem.pr."></a>**序言**　谁比你们更清楚我们国家的全部法律规范如今已得到清理和编排：既有四卷《法学阶梯》（亦称《初阶》），又有五十卷《学说汇纂》（亦称《总汇》），还有十二卷皇帝敕令？凡我们原本应在开始时命令、并在全部工作完成后确定的事项，我们都欣然接受其已完成这一事实；而且，凡我们认为应当作出明确规定的事项，也已通过以希腊文和罗马语写成、并希望永世流传的诏令予以阐明。然而，既然你们受任为法学教师，还应当知道我们认为什么内容应在何时教授给学生，使他们由此成为卓越而博学之士。为此，我们认为有必要专门向你们颁布本敕令，使你们以及其他愿世代从事同一技艺的法学教授遵守我们的规则，得以行走在卓著的法学教育之路上。因此，毫无疑问，《法学阶梯》必须在所有学业中居于首位，因为它适度讲授每门学问的初步知识。至于我们的五十卷《学说汇纂》，我们认为其中仅三十六卷足以供你们讲授和教育青年。我们认为，现在适宜说明这些书卷的次序及其应循的学习路径，使你们回想此前所教授的内容，并表明我们这项新编纂的效用及其教学时序，从而不使这一学科的任何此类事项仍属未知。

<a id="Omnem.1"></a>**1**　从前，正如你们的智慧所知，法律数量如此庞大——卷册有两千卷，行文达三百万行——学生从教师口中所学的却不过六卷；即使这六卷本身也杂乱无章，极少包含有用法律，其余内容早已不再通行，几乎无人能够接触。在这六卷中，列有我们盖尤斯的《法学阶梯》，以及四部单行著作：第一部论古代夫妻财产制度，第二部论监护，第三、第四部论遗嘱与遗赠。学生既未依次完整学习这些书卷，还常把许多部分视为多余而略过。第一学年讲授此书时，不依《永恒告示》的体系，而是随意拼集、杂乱陈列，有用与无用混在一起，而且大半被当作无用之物。第二学年则以颠倒的次序讲授法律的第一部分，并从中抽去若干特定标题；学生在《法学阶梯》之后竟先读法律中并非排在首位、也未因此得名“第一部分”的内容，这实在荒谬。此后，学生虽读完这些内容——而且学习并不连贯，只是零散片段，其中大部分也无甚用处——又被讲授其他标题：一部分取自称为“诉讼”的法律卷册，但也只零星读到有用内容，仿佛其余整卷皆无用；另一部分取自称为“物”的法律卷册，共七卷，其中许多部分对学生并不开放，因为不适当，也不适于教学。第三学年，学生才依次学习第二学年未曾讲授的“物”与“诉讼”两部分内容，并由此接触最卓越的帕比尼安及其《解答集》。在这部以第十九卷为终卷的《解答集》中，他们只学习八卷；教师没有讲授其全部内容，而是从大量篇幅中择取少数，又从宏篇巨制中截取极短片段，使学生学后仍觉不足。教师讲授的仅此而已；保罗的《解答集》则由学生自行阅读，而且并非完整研读，只是沿着一种不完整、几乎已成坏习惯的断续路径进行。至此，第四学年便是全部古代法学教育的终点。若有人愿意逐项统计所讲授的内容，便会发现，面对如此浩瀚的法律，仅有六万行左右为学生通读并理解，其余内容都偏离教学、无人知晓；只有在司法实践迫使他们这样做时，或法学教师急于从中读出某些内容、以便比学生多懂一些时，才会有极少数内容被读到。这些便是古代教育的遗存，你们也以亲身所知证实了这一点。

<a id="Omnem.2"></a>**2**　我们发现法律如此匮乏，并认为这种情形极其可悲，于是向愿意求学者开放法学宝库；通过你们的审慎教导，学生将从中受益，成为极富学识的法律讲论者。第一学年，他们应学习我们的《法学阶梯》；此书几乎从古代《法学阶梯》的全部内容中精炼而成，将混浊水源中的材料汇聚为一泓清澈之湖。编纂者是显贵的特里波尼安，曾任我们神圣宫廷的法务官、财务官及执政官，以及你们中的两位，即雄辩出众的法学教授塞奥菲卢斯与多罗塞乌斯。我们又规定，在该学年其余时间，依最妥当的次序教授法律的第一部分；它以希腊语称为“普罗塔”（πρώτα），意为“第一”，因为居首者之前不可能另有其物。我们规定，这部分构成第一学年的开端与终点。我们不希望学习者再沿用古老而可笑的贬称“杜庞迪乌斯”（dupondii，意为二阿斯币者），而应称为“新查士丁尼生”；我们决定这一称谓永远通行。凡尚未熟悉法学、愿接受第一学年知识的人，均应获得我们的名号，因为他们立即要学习由我们创制并颁布的第一卷。过去，他们所得称谓与古代法律的混乱相称；如今，法律已清楚明白地展现在他们面前，易于铭记，因此我们认为改换称谓、使其焕然一新也是必要的。

<a id="Omnem.3"></a>**3**　第二学年，学生此前因学习《告示》而得名，且这一称谓为我们所认可；我们规定，他们应学习七卷“诉讼”或八卷“物”，具体取决于教学年度的轮换安排。我们命令严格遵守这一轮换次序。学生应当依次完整学习“诉讼”或“物”的整卷，不得遗漏任何内容，因为这些卷册都已焕然一新，其中绝无无用或废止之物。我们还希望，在第二学年的学习中，将四部单行著作附加于上述两组卷册之一。这四卷是我们从总计十四卷的编纂中选出的：从论嫁资的三卷中选一卷；从论监护与保佐的两卷中选一卷；从论遗嘱的两卷中选一卷；从论遗赠、遗嘱信托及相关事项的七卷中也选一卷。我们规定，只向学生讲授这些各组编纂开篇的四卷；其余十卷留待适当时机，因为不可能在第二学年内讲授这十四卷，且该学年的时间也不足以由教师逐卷讲完。

<a id="Omnem.4"></a>**4**　第三学年的教学也应按下列次序进行：无论学生依轮换安排学习“诉讼”还是“物”，都应配合讲授三部单行著作。首先讲授论抵押诉权的一卷；我们已将其置于论抵押的适当位置，使之靠近“物”卷册中关于质权诉权的内容，因为两者功能相近，不应彼此疏远；它们所涉及的事项相同，研究旨趣几乎一致。其次，应向学生开放另一部单行著作，其中汇集了市政官告示、解除买卖之诉、瑕疵担保及关于双倍给付的要式口约；后者是在驱逐买受人时提出的。法律在“物”卷册中突出规定了买卖事项；我们所说的这些规则原先都列于旧告示的末尾，因此我们有必要将其移至前部，使它们不再远离买卖——这些规则几乎是买卖的辅助制度。我们安排学生学习这三卷，并同时研读敏锐卓越的帕比尼安。学生第三学年原本就会读到帕比尼安的著作，但并非完整研读，只从中零散摘取少数内容；现在你们则可在我们的《学说汇纂》全书编排中读到这位卓越的帕比尼安，他的著作不仅包括编为十九卷的《解答集》，还包括三十七卷《疑问集》、两卷《定义集》、论通奸的著作以及几乎全部论述；各部分都以自身内容彰显其卓越。我们不愿第三学年的学生——他们被称为“帕比尼安派”——似乎失去帕比尼安之名及纪念他的庆典；于是我们以精巧安排再度将他纳入第三学年。我们在抵押法这一单行卷的开篇大量收入这位最伟大的帕比尼安的论述，使学生因之得名“帕比尼安派”，并在追忆他的同时欢欣鼓舞，举行他们初次学习其著作时惯常举行的节日；如此，这位显贵的前任长官帕比尼安之名将永垂不朽，第三学年的教学也由此结束。

<a id="Omnem.5"></a>**5**　第四学年的学生通常有一个希腊语称谓“吕塔斯”（λύτας，意为解除者）；他们愿意的话，可以保留此称谓。至于从前所学的最睿智的保罗《解答集》，学生经由上述混乱方式，只从二十三卷中勉强读到十八卷；如今，他们应当研读前述十四卷中剩余的十部单行著作，从中取得远比保罗《解答集》更为宏富的法学宝藏。如此，我们编纂并分为十七卷的全部单行著作体系，就会留存在学生心中；这些内容位于《学说汇纂》第二部分与第三部分，即按七部分划分中的第四、第五部分。由此，我们在本敕令开篇所说的便可实现：学生读完三十六卷后，成为成熟之士，能够胜任一切法律工作，不负我们时代之名。我们把《学说汇纂》第六、第七部分的另十四卷暂且留给他们，日后他们仍可阅读，并在诉讼中援引。如果他们确实认真学习了这些内容，并在第五学年——学生称为“普罗吕塔斯”（prolytae）——学习《敕令汇编》，力求透彻理解，那么他们就不会缺少法学知识，而能在心中把握法学从始至终的全部内容。其他学科几乎都不可能如此；即便最卑微的技艺也无不繁多无尽，唯有这门学问具有令人惊叹的终点，并已在我们时代达成。

<a id="Omnem.6"></a>**6**　既已向学生开启全部法学奥秘，他们便不应再有任何未知之事；在通读我们通过显贵特里波尼安及其他人之努力所编成的一切之后，他们应成为卓越的法律讲论者与正义的卫士，在任何地方、任何时代都成为优秀的司法斗士和治理者，并蒙受福祉。

<a id="Omnem.7"></a>**7**　我们仅希望在帝都以及贝鲁特这座美丽城市讲授我们编纂的三部著作；称贝鲁特为法学的养育者，实在恰当。这也符合先帝早已确立的规定，不得在未获前人此种特权的其他地方授课。我们听闻，在极其繁荣的亚历山大里亚、凯撒里亚以及其他地方，也有一些无知之徒四处游荡，向学生传授伪劣教义。我们以此项严厉命令禁止其继续从事此种行为：今后，若有人胆敢在帝都和贝鲁特都会之外这样做，应处以十磅黄金罚金，并逐出其非法讲授法律、实则违法之所在城市。

<a id="Omnem.8"></a>**8**　从前我们在命令编纂这项工程时已于敕令中规定，完成后又在另一篇帝国敕令中重申；如今仍有必要写明：任何抄写书卷的人，都不得加入缩写符号，以简略方式书写，从而给法律的解释或编纂造成重大危害。所有今后实施此行为的抄写者应知：除刑事处罚外，若其将此类书卷卖给不知情的所有人，还须向该所有人支付书价的双倍。至于购买此种书卷的人，该书对其毫无价值；任何法官均不得准许依据此书进行宣读，而应命其视同未曾写成。

<a id="Omnem.9"></a>**9**　我们还以最严厉的禁令作出一项十分必要的规定：无论在这座显赫的城市还是在贝鲁特这座美丽城镇，任何从事法学学习的人，都不得举办不合身份、恶劣、甚至近于奴役性凌辱的戏弄活动，也不得实施其他犯罪行为，侵害法学教师、同学，尤其是刚开始学习法律的学生。由此引发犯罪的活动，谁还会称之为游戏？我们绝不容许此事发生；相反，我们要在自己的时代确立最优秩序，并将其传至此后整个时代，因为应当先使心智、继而使言语受到教养。

<a id="Omnem.10"></a>**10**　在这座最繁荣的城市，显贵的首都长官应依青年学生及抄写者过错的性质，负责遵守并执行上述规定；在贝鲁特城，执行者则为尊贵的腓尼基沿海省总督、该城至圣的主教及法学教授。

<a id="Omnem.11"></a>**11**　因此，请在上帝引领下开始向学生讲授法律知识，为他们开启我们所发现的道路，使他们成为最优秀的正义与国家事务服务者；如此，世世代代都将尊崇你们。你们的时代曾发生如此重大的法律交换，正如万德之父荷马笔下格劳科斯与狄俄墨得斯彼此交换不同价值的武器：“以金换铜，以价值百头牛的物品换九头牛的物品。”（χρὑσεα χαλκείων, ἑκατόμβοια ἐννεαβοίων；即：金制品换青铜制品，价值百头牛的物品换价值九头牛的物品。）我们规定，上述一切永远有效，所有法学教授、法律学习者、抄写者及法官均应遵守。于我们主、永远的奥古斯都查士丁尼第三次任执政官时，在君士坦丁堡颁布，即十二月十六日（十二月日历前第十七日）。
