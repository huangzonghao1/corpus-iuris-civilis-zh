# 《Deo auctore》敕令

## 关于《学说汇纂》的编纂

**皇帝恺撒·弗拉维乌斯·查士丁尼，虔敬者、幸运者、显赫者、胜利者、凯旋者，永远的奥古斯都，致其财务官特里波尼安：致意。**

<a id="Deo auctore.pr."></a>**序言**　在上帝支持下，我们治理由天上威严授予我们的帝国；我们胜利地进行战争，光荣地维护和平，并维系国家秩序。为此，我们将心志举向全能上帝的援助：我们既不依赖武器，也不依赖军队、战争统帅或自身才智，而将一切希望寄托于至高三位一体的眷顾；世界的一切元素由此而出，其安排也由此展开，形成整个大地的秩序。

<a id="Deo auctore.1"></a>**1**　在人世诸事中，法律权威最为重要；它妥善安排神事与人事，并排除一切不公。我们发现，自罗马城建立、罗慕路斯时代以来流传下来的全部法律途径，已经如此混乱，以致无限扩张，超出人类理解能力所能把握的范围。因此，我们首先着手从神圣诸先帝的法令开始，加以修订，并使之呈现清晰的体系；将这些法令汇集为一部法典，排除一切多余重复和极不妥当的冲突，使所有人都能获得纯正法律所提供的现成保障。

<a id="Deo auctore.2"></a>**2**　这项工作完成、汇为一卷并以我们的名义彰显之后，我们本欲从较少且较简要的成果，进至对法律最全面、最彻底的修订；又想汇集、修订罗马的全部规范，并把众多作者散佚各处的卷帙收入一部法典。此前无人敢于希望或设想此事；它在我们看来极其艰难，甚至近乎不可能。然而，我们举手向天，祈求永恒的援助，凭借上帝的力量承担起这一职责；上帝能够以其伟力赐予并完成那些彻底绝望之事。

<a id="Deo auctore.3"></a>**3**　我们看重你忠诚而卓越的才干，首先将此项工作委托于你；你已凭借整理本法典所展现的才能取得我们的信任。我们命你从最有学识的法学教授和最有声望法庭中的杰出律师之中，选出你认为适任者，共同承担此项劳务。你召集这些人，将他们带入皇宫，并以你的证明使我们认可后，我们便将全部事务交由你们办理；但整个工作必须由你高度审慎而勤勉地统筹。

<a id="Deo auctore.4"></a>**4**　因此，我们命你们阅读并甄选古代法学家的著作。这些法学家曾获神圣诸先帝授权，得以撰写和解释法律。应从这些著作中汇集全部材料；在可能范围内，不得遗留重复或冲突；而应由此编成一部足以取代其余著作的汇编。其他人虽也撰写过法律著作，但其文字未获任何权威作者采纳，也未曾通行；我们认为，这些卷帙不值得扰乱我们的立法。

<a id="Deo auctore.5"></a>**5**　凭借至高神祇的慷慨恩赐，材料汇集完成后，便应以最优美的体例建构此项巨著，将它奉献为正义自身的圣殿。应将全部法律编排为五十卷，并分设确定的标题；至于具体编排方式，可参照我们的《敕令汇编》和《永恒告示》，以你们认为最为适宜者为准，不得遗漏任何应当纳入的内容。如此，经历近一千四百年而纷乱不堪、又经我们清理的全部古法，将由这五十卷如同一道城墙环护，不再有任何内容逸出其外。所有法学作者均应享有同等权威，不得给予任何人优先地位；因为没有哪位作者在所有事项上都胜过他人，各人只是在不同事项上各有优劣。

<a id="Deo auctore.6"></a>**6**　也不得因作者人数众多便判断何者较优、较公平；因为某一位作者的意见，即使出自较逊之人，也可能在某一事项上胜过许多更卓越者。因此，对于此前附于艾米利乌斯·帕皮尼安著作中的乌尔比安、保罗和马尔基安批注，虽因帕皮尼安享有崇高声誉而此前不具效力，也不要立即予以排斥。如果你们认为其中某些内容有助于补充这位卓越法学家的工作或解释其著作，就应将其纳入，并赋予法律效力。凡收入本汇编的法学家，均应具有权威；这就如同我们依其功绩将他们的研究成果据为己有，因为其权威将由我们授予。毕竟，精审地修正既有成果者，比最初发现它的人更值得称赞。

<a id="Deo auctore.7"></a>**7**　我们还希望你们留意：若发现古代著作编排不当、内容多余或论述不完善，应删去冗余、补足不完整之处，并使整部作品体例适度而尽可能优美。对于古代法学家著作中所载法律或敕令的错误文字，也应予以修正，并纳入妥当的体系；使经你们选定并置于其中的文本，呈现为真实、完善、仿佛自始如此书写，而无人得以拿旧卷帙比较并指责其文字有误。因为古称“王法”的法律已将罗马人民的一切法与权力转移给皇帝；我们不把自己的规范权分割给不同立法者，而是主张全部规范权归于我们。古代又能以何种方式废止我们的法律呢？我们希望，凡重新收入汇编的内容均取得同等效力；即使古代文本原本另有写法，而编纂时采用了相反的表述，也不得将文字之罪归于任何人，而应归因于我们的选择。

<a id="Deo auctore.8"></a>**8**　因此，在上述汇编的任何部分中，都不得容许规范冲突（底本称 *antinomia*，这是沿用自古代的希腊语名称）占据一席之地；全书应当和谐一致、前后一贯，不留下任何相互对立之处。

<a id="Deo auctore.9"></a>**9**　如前所述，我们也希望消除这部汇编中的重复。凡我们收入《敕令汇编》的神圣敕令已经规定之事项，不得再从古法中重复收录；但为划分体系、补充内容或作更充分考察所必需的情形除外。即便如此，也应极少为之，以免在连续编排中生出荆棘，妨碍全书整齐有序。

<a id="Deo auctore.10"></a>**10**　古代著作中已经废止而不再适用的法律，我们绝不允许你们收入。我们只希望保留司法程序中经常适用的规则，或经本城长期习惯确认的规则。萨尔维乌斯·尤利安的著作指出，所有城市都应遵循罗马的习惯；罗马是世界之首，并非罗马应当遵循其他城市的习惯。这里所说的罗马，不仅指旧罗马，也包括我们的帝都；蒙上帝庇佑，这座城市是在更佳的吉兆下建立的。

<a id="Deo auctore.11"></a>**11**　因此，我们命令，一切事务均依这两部法典治理：一部是敕令汇编；另一部是经过提炼的法律汇编，并将收入未来编成的法典。若我们另行颁布具有《法学阶梯》作用的规范，也应一并适用，使初学者的心智先由浅近内容培养，再较易提升至更高层次的法学知识。

<a id="Deo auctore.12"></a>**12**　我们规定，这项在上帝允助下由你们编成的成果，应称为《学说汇纂》（*Digesta*）或《总汇》（*Pandectae*）。今后，任何法学家均不得为其撰写评注，以免以冗长文字破坏上述汇编的简明体例；古代曾发生过此事，解释者的相互矛盾几乎扰乱了全部法律。仅可通过索引以及称为 *paratitla* 的精细标题，提供某些提示；这些提示不得因解释而产生任何弊病。

<a id="Deo auctore.13"></a>**13**　为避免今后因书写方式引起疑义，我们命令，本汇编的正文不得使用缩写符号或简略的谜式记号；这些记号自身的缺陷曾引发许多规范冲突。即使是表示卷数或其他内容，也不得使用专门的数字符号，而应以连续的文字完整写明。

<a id="Deo auctore.14"></a>**14**　因此，愿你的智慧在上帝垂允之下，与其他杰出之士共同完成上述各项工作，并以精审而迅速的方式收尾；将完成并编为五十卷的法典呈献给我们，使之成为永恒的伟业纪念、全能上帝眷顾的明证，以及我们帝权与诸位勤勉服务之荣光。于兰帕狄乌斯与奥雷斯特斯两位显贵执政官任职时，在君士坦丁堡颁布，即一月日历前第十八日（十二月十五日）。
