# 《Tanta》敕令

## 关于确认《学说汇纂》

**奉我主上帝耶稣基督之名。**

**皇帝凯撒·弗拉维乌斯·查士丁尼，阿勒曼尼库斯、哥特库斯、法兰克库斯、日耳曼尼库斯、安提库斯、阿兰尼库斯、汪达尔库斯、阿非利加库斯，虔敬者、幸运者、显赫者、胜利者、凯旋者，永远的奥古斯都，致元老院及万民：**

<a id="Tanta.pr."></a>**序言**　神圣仁慈的天意何其厚待我们，始终以永恒的恩惠扶助我们。帕提亚战争以永久和平告终，汪达尔人被击败，迦太基以及更确切地说整个利比亚重新归入罗马帝国之后，天意又使我们得以凭借勤勉，将因年久而沉重不堪的古代法律焕然一新，并整理为适度精简的体系。在我们统治之前，从无人敢于期望此事，也无人认为凭人类才智能够完成。自罗马建城直至我们时代，罗马法律规范历经近一千四百年，内部纷争使其摇摆不定，且不断延伸至皇帝敕令；能将其归于和谐一致，使其中不再有相互矛盾、重复或相似之处，也不再出现针对同一事项的双重法律，实在令人惊叹。这固然是上天眷顾的特恩，却绝非人类脆弱能力所能做到。于是，我们依照惯例寻求不朽天助，祈请至高神明成为此项工程的创始者和主宰；我们将全部工作托付给显贵特里波尼安——他曾任官署主管、我们神圣宫廷的财务官及执政官——并命他与其他显贵而审慎之士共同实现我们的愿望。我们的陛下也始终亲自考察、审阅他们编成的内容；凡发现疑难不明之处，便在天意启迪下加以修正，整理为适当形式。因此，主上帝耶稣基督赐予我们及参与此事之人完成这项工程的能力，一切现已完成。

<a id="Tanta.1"></a>**1**　我们此前已将主要敕令汇编为十二卷，收入以我们名义彰显的法典。其后，我们着手这项宏大工程，将古人以极大勤勉撰写、如今几近混乱散佚的著作交给上述显贵之士，命其搜集并依确定体系加以编排。我们审察全部情况时，这位显贵之士报告说：古人共写成近两千卷，篇幅超过三百万行，所有这些著作都必须逐一阅读、细加考察，并从中选取最优秀的内容。在天光与至高三位一体的庇佑下，此事依照我们从一开始交给这位显贵之士的指示得以完成：一切最有用的内容均已汇集为五十卷，全部疑难均已厘清，没有留下任何争议。我们为这些卷册命名为《学说汇纂》或《总汇》，因为其中包含法律上的各种论辩与裁断，并将四方搜集而来的内容纳入自身；全书约十五万行。我们又把它划分为七部分，并非任意行事或毫无理由，而是考察数目的性质与规律，据此作出与之协调的部分划分。

<a id="Tanta.2"></a>**2**　因此，全书第一部分以希腊语称为“普罗塔”（πρώτα），分为四卷。

<a id="Tanta.3"></a>**3**　第二部分有七卷，称为“诉讼”。

<a id="Tanta.4"></a>**4**　第三部分汇集一切称为“物”的内容，共编为八卷。

<a id="Tanta.5"></a>**5**　第四部分位居全书中央，仿佛整部编纂的中枢，共收八卷。其中预先安置了所有关于抵押的内容，使之靠近“物”卷册中关于质权诉讼的内容。另有一卷也编入该部分，收录市政官告示、解除买卖之诉，以及关于驱逐买受人而提出的双倍给付要式口约。上述内容均与买卖标题相协调；前述诉权从一开始便仿佛买卖的随从。在旧告示的编排中，它们游离于偏僻且相距甚远之处；经我们安排后，现被汇集在一起，因为凡几乎论及同一事项者，本应相邻编排。我们还特意在前述两卷之后编入另一卷，论利息、海上借贷、文书、证人、证明以及推定。上述三部单行卷册均置于论“物”的部分之后。此后，我们又收录法律中关于订婚、婚姻和嫁资的内容，并以三卷编成一组；另编两卷论监护与保佐。我们把上述八卷编排置于全书中部，其中汇集了来自各方、最有用且最完善的法律。

<a id="Tanta.6"></a>**6**　《学说汇纂》第五部分由此开始，其中收录古人关于私人及军人遗嘱和遗嘱附录的一切内容；该部分称为“遗嘱”。另编五卷论遗赠与遗嘱信托。

<a id="Tanta.6a"></a>**6a**　没有什么比这项安排更为特别：我们将关于法尔基狄亚法的论述置于遗赠部分，将关于特雷贝利安元老院决议的论述置于遗嘱信托部分，各自编成一卷，合为第五部分的九卷。我们认为只需编入特雷贝利安元老院决议；古人也厌恶佩加西安元老院决议中诡辩繁复的迂回，以及两项元老院决议彼此之间多余而琐细的差别。因此，我们舍弃这些内容，将关于此事的全部法律归由特雷贝利安元老院决议调整。

<a id="Tanta.6b"></a>**6b**　不过，我们在此没有提及无主遗产的归属，以免罗马人在事事不顺、国势悲惨的时期因内战而兴起的那项制度，继续留存于我们的时代。上天的恩宠和和平的力量已使我们的时代稳固，并使我们在对各民族的战争中取得胜利；我们不愿让这段悲哀的纪念笼罩欢乐的世代。

<a id="Tanta.7"></a>**7**　《学说汇纂》第六部分继而展开，其中编入关于所有权遗产占有的内容，既包括适用于自由出生者的，也包括适用于被释奴的；还将有关亲等与姻亲关系的一切规则、法定继承及全部无遗嘱继承，以及《特尔图良元老院决议》和《奥菲齐安元老院决议》——依据后两项决议，母亲与子女得相互继承——汇入两卷，由此将大量遗产占有制度纳入简明而清晰的体系。

<a id="Tanta.7a"></a>**7a**　此后，我们将古代作者关于新工程告知、未完成损害、建筑物拆毁及其危险、排除雨水，以及法律所规定的普布利齐安诉权与生前赠与、死因赠与等内容，汇编为一部单行卷册。

<a id="Tanta.7b"></a>**7b**　另有一卷专门论解放及自由身份之诉。

<a id="Tanta.7c"></a>**7c**　此外，关于取得所有权与占有以及引致取得的法律原因，众多不同论述均收入同一卷册。

<a id="Tanta.7d"></a>**7d**　另一卷则编入关于经判决或在法庭上自认之人、财产扣押与变卖，以及防止损害债权人利益的内容。

<a id="Tanta.7e"></a>**7e**　上述内容之后汇集了各种禁令；再后另编一部单行卷册，论抗辩、期间届满、债务及诉权。这样，《学说汇纂》第六部分共由八卷构成。

<a id="Tanta.8"></a>**8**　《学说汇纂》第七、亦即最后一部分，由六卷组成。其中将一切关于要式口约或言词债、保证人、委托担保人、债务更新、清偿、免责、裁判官担保等法律内容，收入两卷；在古代著作中，这些内容甚至无法计数。

<a id="Tanta.8a"></a>**8a**　此后编入两卷内容严峻的著作，论私人犯罪、非常犯罪及公罪，全面载有刑罚的严厉性与残酷性。其中还混编了针对胆大妄为、企图隐匿或抗命之人的规定，以及对受判决者施加或准予的刑罚和有关其财产的规则。

<a id="Tanta.8b"></a>**8b**　我们另编一部单行卷册，论针对民事或刑事终局裁判提出的上诉。

<a id="Tanta.8c"></a>**8c**　其余内容均收入第五十卷这一全书最后完成的卷册，包括古人发现并规则化确定的市政事务、十人委员会成员及其义务、公共工程、集市、允诺、公务审理、户籍，以及词语含义等事项。

<a id="Tanta.9"></a>**9**　上述一切由显贵而极为审慎的特里波尼安完成；他曾任财务官、执政官，兼具雄辩与法学之才，并在实际事务中表现卓越，从不认为有任何事务比我们的命令更重大、更珍贵。此项工作也由其他卓越而勤勉之士共同完成：显贵君士坦丁，神圣国库主管、敕书与神圣审判卷宗署主管；他始终以良好声誉和荣誉赢得我们的赞许；显贵塞奥菲卢斯，在这座辉煌城市担任法学教师，精通法律，并以卓越方式传授法律；显贵多罗塞乌斯，雄辩出众，曾在辉煌的贝鲁特城教导学生法律；我们因其卓越声誉与荣誉而召他前来，使之参与此项工程；显贵阿纳托利乌斯，在贝鲁特担任法学教师，也被选入此项工程。他出身于古老的法学世家，其父莱翁提乌斯、祖父欧多克修斯，以及曾任财务官、法学教授的尊贵先辈莱翁提乌斯——即其显赫的长子，曾任长官、执政官和贵族——都在法律领域留下卓越声名；还有显贵克拉提努斯，神圣国库主管，并任本城优秀的法学教授。上述诸人均被选入此项工程，并与斯特法努斯、墨纳斯、普罗多修斯、欧托尔米乌斯、提摩太、莱昂尼德、莱翁提乌斯、柏拉图、雅各布、君士坦丁和约翰共同承担工作；他们都是最审慎之士，在东方禁卫长官治下的最高审判机关担任讼务代理人，各方对其才干均有见证，我们也选他们完成这项宏业。他们在显贵特里波尼安的统领下共同会合，为了在我们授权之下完成这项宏伟工程；承蒙上帝眷顾，全书最终编成五十卷。

<a id="Tanta.10"></a>**10**　我们对古代怀有如此敬意，以致绝不容许隐去法学家的姓名；每一位曾创制法律的作者，其姓名都已记入我们的《学说汇纂》。我们所做的仅是：凡其法律中有多余、不完整或不适当之处，便予以必要增补或删减，并纳入最为妥当的规则。对于众多相似或相互矛盾的规定，我们选取其中更为妥当者，取代其余规定；同时赋予所有规定同等权威，使其中所载一切均成为我们的规范，依我们的意思编成。任何人均不得将古代文本与我们权威颁行的内容相比较，因为我们为使法律适应实际需要，已作出许多重大变更。即使某项皇帝敕令曾载于古代著作，我们也未予保留原状，而认为它同样应当修正并加以改善。我们保留古人的姓名，但凡符合法律真义且属必要的内容，均依我们的修订予以保存。因此，即使古人之间曾有任何疑义，如今一切也已归于最可靠的安定状态；我们没有留下任何摇摆不定之处。

<a id="Tanta.11"></a>**11**　我们认识到，尚未入门、仍站在法学门槛前便急于探寻其奥秘的人，不足以承受如此宏大的智慧；因此，我们决定先为他们准备适度的基础教育，使其在此阶段获得陶冶，仿佛已初步领会各项内容，然后才能进入法学内室，以不再蒙昧的目光理解这套优美的法律体系。于是，我们召来负责统筹全书的显贵特里波尼安，以及显贵而雄辩出众的法学教授塞奥菲卢斯与多罗塞乌斯，命他们分别搜集古人撰写、包含法学初步论题并称为《法学阶梯》的著作；从中选取一切有用、适当、经过提炼且符合当今实务的内容，编为四卷，为全部教育奠定最初基础与入门要素，使青年凭借这些基础，足以掌握更为艰深、完备的法律知识。我们还提醒他们牢记我们为修正法律而颁布的敕令，并及时将同样的修正纳入《法学阶梯》，以清楚显示法律此前何处摇摆不定、此后又何处归于稳定。此书由他们完成、呈交并经我们审阅后，我们欣然接受，认为与我们的判断相符，并命令这些书卷具有敕令的效力；我们置于这些书卷之前的敕令对此已有更明确的说明。

<a id="Tanta.12"></a>**12**　罗马法的全部体系既已编成，并汇入《法学阶梯》《学说汇纂》（亦称《总汇》）和《敕令汇编》三部著作，且在三年内完成——工程最初启动时，人们尚不敢指望十年内全部完成——我们便怀着虔敬之心，将这项造福人类的工作奉献给全能上帝，并向至高神明致以丰厚谢意。正是上帝使我们得以顺利作战、享有体面和平，并不仅在我们时代，而且为当下及后世的一切时代制定优良法律。**12（13）**　因此，我们认为有必要使所有人知晓本敕令，使他们明白自己摆脱了何等混乱与无穷繁复，又达到了何种适度与合法的真实状态。今后的法律既应明确、简要，也应便于所有人取得；法律书籍应容易购买，不应耗费大量财富才能获得庞杂无用的法书卷册。无论富人还是贫者，都应能以极低价格买到这些著作，以微薄费用获得宏富的法学知识。

<a id="Tanta.13"></a>**13**　如此浩大的法律编纂从无数书卷中汇集而成，偶尔可能发现相似内容；任何人都不应因此责难，而应首先将其归因于人类天生的脆弱，因为记住一切、绝不犯错，更属于神性而非凡人之能；古人也曾这样说。其次，应当知道，有些内容虽简短却以相似方式收入，并非毫无用处，也非违背我们的意图：或者某项法律确有必要，因事项相关而应列入不同标题；或者它与其他不同内容混编，若拆分开来便会使整体陷于混乱。对于那些完整论述古代制度的部分，若内容已零散穿插其间，彻底拆分并剥离便不合宜，以免扰乱读者的理解与阅读。

<a id="Tanta.14"></a>**14**　同理，我们绝不允许将皇帝敕令已经规定的事项编入《学说汇纂》，因为援引敕令已足以证明这些规则；只有基于前述相同理由，才极少数地例外收录。

<a id="Tanta.15"></a>**15**　本法典中不存在任何相互矛盾之处；若有人细致考察差异的缘由，便会发现这一点。某些内容只是新近创设或隐而未显的规则，它消除了不一致的指责，并引入一种能避开矛盾界限的新性质。

<a id="Tanta.16"></a>**16**　若在如此浩繁的法律中，或许还有某些内容深藏于卷帙深处而被遗漏；即使本应收录，却因晦暗不明而不得不舍弃，又有谁能以公允之心理解此事？首先，这是因为凡人智识有限；其次，事项自身有缺陷，它与大量无用内容混杂，无法提供任何线索使人将其发掘出来；再次，漏掉少数适当内容，远比让人被大量无用内容压垮更为有益。

<a id="Tanta.17"></a>**17**　从这些卷册中还显现出一项奇迹：面对古代浩瀚内容，我们如今的简编反而显得更为充实。从前争讼之人虽有许多法律可用，实际却只依据少数法律进行诉讼；或因缺乏书籍、无力购买，或因自身不知法。诉讼往往依裁判官意愿而非合法权威解决。如今，在我们完成的《学说汇纂》中，法律从如此众多的卷册中汇集而来；古人不仅不知道这些卷册的名称，甚至从未听说过。全部内容汇集成丰厚的宝藏，使古代那看似庞大的法律群落实则贫乏，而我们的简编则极为丰饶。卓越的特里波尼安尤其提供了古代智慧的丰富著作，其中许多连最博学之士也不知晓。全部阅读之后，凡其中最完善者均被挑选出来，纳入我们最佳的编纂。此项工程的编纂者不仅阅读了法律引文所出自的卷册，还阅读了许多其他著作；他们没有从中发现任何有用或新颖、可收入并适用于我们《学说汇纂》的内容，便以审慎态度将其舍弃。

<a id="Tanta.18"></a>**18**　神事虽极为完善，但人法的状态总是无穷变化，没有任何事物能够永恒不变；自然不断急切地创造出新的情形。因此，我们并不认为日后绝不会出现尚未被法律之网所拘束的事务。若发生此类情形，应祈请奥古斯都予以救济；上帝将帝国福运置于人类事务之上，正是为了使其能够修正、规定一切新近发生之事，并以适当方式与规则加以规范。这并非我们首创，而是承袭古老传统：即便最精通法律与《永恒告示》的制定者尤利安，也在其著作中记载，若发现法律不完整，应由皇帝敕令予以补足。不仅他如此主张，神圣的哈德良皇帝也在编纂《告示》以及其后的元老院决议中明确规定：若《告示》中没有相应条文，新的权威得依其规则、推论及仿效方式制定规范。

<a id="Tanta.19"></a>**19**　元老院诸贤及天下万民，既已知悉上述一切，就应向至高神明致以无上谢意；正是神明在你们的时代保存了这项极有益的工程。古代未获神意认定为适宜之事，如今已赐予你们。因此，应尊崇并遵守这些法律，令所有更早的法律归于停止；你们任何人都不得将其与旧法比较，或在两者有不一致之处时另行查考，因为我们规定，此处所载是唯一应当遵行的法律。在审判或其他需要法律的争端中，任何人均不得援引或出示其他书籍中的内容，只有我们的《法学阶梯》《学说汇纂》以及由我们编成或颁布的敕令除外。违反者将构成伪造罪；准许其陈述的法官也将与其一同承受最严厉的刑罚。

<a id="Tanta.20"></a>**20**　为使你们知晓本次编纂取材于哪些古代著作，我们命令在《学说汇纂》卷首写明此事，使人清楚知道这座罗马正义之殿由哪些法律作者、哪些著作以及多少卷册建成。

<a id="Tanta.20a"></a>**20a**　我们选定的立法者或评注者，均足以胜任这一宏大工程，且先前最虔敬的皇帝也不曾拒绝承认他们。我们赋予所有人同等尊荣，不允许任何人自称享有特殊优先权。既然我们已决定这些法律如同由我们颁布的敕令一样有效，那么当所有法律均获同等尊荣与权力时，怎能说某些规定比另一些多了或少了什么？

<a id="Tanta.21"></a>**21**　我们从一开始便认为有必要作出下列规定，当时我们是在上帝应允之下命令编纂这部作品；如今也认为应正式颁行：无论现今或今后任何精通法律之人，都不得为这些法律撰写评注；但可依照罗马原文的顺序和连贯次序，将其译成希腊文（希腊人称之为“逐句对应”，κατὰ πόδα），也可通过细分标题作简要批注，编写所谓“旁题”。除此之外，我们不准任何人散布对法律的其他解释，确切地说，是歪曲；以免冗长文辞造成混乱，损害我们的法律。古代《永恒告示》的评注者就曾如此行事：他们将原本适度编成的作品拆解成此处彼处互相歧异的意见，无限扩张，几乎使全部罗马法律规范陷于混乱。我们既未容许这种情形，怎能允许后世产生毫无意义的纷争？若有人胆敢如此行事，应按伪造罪追究，其书卷一律销毁。若如前所述遇有疑义，应由法官上报皇帝，并由皇帝权威予以澄清；唯有皇帝获准制定和解释法律。

<a id="Tanta.22"></a>**22**　我们对今后胆敢以缩写符号的晦涩方式抄写本法之人，也规定同样的伪造罪处罚。我们要求一切内容——包括法学家姓名、标题及卷册编号——均以完整字母拼写，不得使用缩写符号。因此，任何人若买到在任何卷册或部分中使用了缩写符号的书籍，都应知道自己持有的是无效法本；我们不准许任何人依据这种书籍在法庭上援引内容，只要书中任何部分含有缩写符号，即属此限。胆敢加入这些符号的抄写者，除按前述规定受到刑事处罚外，若书籍所有人并不知情而购买或委托编写，还应向所有人支付书价的双倍。我们此前致法学教授的敕令中已规定了同一事项。

<a id="Tanta.23"></a>**23**　我们规定，本法典中的法律——即《法学阶梯》（亦称《初阶》）和《学说汇纂》（亦称《总汇》）——自我们最幸运的第三次执政官任期起生效；在本年度第十二指示年，即十二月三十日（十二月日历前第三日）起永久有效，与我们的敕令具有同等权威，并在所有案件的审判中发挥效力，包括此后发生的案件，以及仍在审理中且尚未以判决或和解方式解决的案件。对于已经由裁判终结或通过友好协议平息的事项，我们绝不允许以任何方式重新提起。我们及时在第三次执政官任期内颁布这些法律，实属明智，因为至高的主上帝耶稣基督赐予国家极大福祉：本年度帕提亚战争已告终结并迎来永久和平；我们又增加了世界的第三部分——欧洲、亚洲之后，整个利比亚也并入我国疆域；并为这项宏大的法律工程加上最后的冠冕。所有天赐恩惠，均归于我们第三次执政官任期。

<a id="Tanta.24"></a>**24**　因此，我们所有法官均应在各自管辖范围内接受这些法律，并在其法庭及这座帝都加以持有和公布，尤其是显贵的首都长官。三位显贵的禁卫长官——东方、伊利里亚及利比亚的长官——应以各自权威，确保所有受其管辖者知悉这些法律。于我们主查士丁尼第三次任执政官时颁布，即十二月十六日（十二月日历前第十七日）。► 参见《查士丁尼法典》1.17.2。
