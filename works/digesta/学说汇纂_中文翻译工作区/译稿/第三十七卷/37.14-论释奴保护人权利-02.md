# D.37.14 论释奴保护人权利（*De iure patronatus*，第二段）

<!-- source-p 751 -->
<a id="37.14.8.pr."></a>**序言。**神圣的哈德良皇帝在敕答中指出：由军人家子解放的奴隶，应成为该军人的被释奴，而非其父亲的被释奴。

<!-- source-p 752 -->
<a id="37.14.8.1"></a>**1.**奴隶依买卖条件应在一定期限内被解放的，即使期限届满后尚未实际解放，也会取得自由，并成为买受人的被释奴。

<!-- source-p 753 -->
<a id="37.14.9"></a>**37.14.9**

<!-- source-p 754 -->
莫德斯汀《法律规则集》第九卷。

<!-- source-p 755 -->
<a id="37.14.9.pr."></a>**序言。**儿子放弃父亲遗产的，不因此丧失其对父亲的被释奴所享有的权利；儿子被解放出父权的，亦同。

<!-- source-p 756 -->
<a id="37.14.9.1"></a>**1.**法律规定某些人不得在被释奴的遗产中取得地位：被判处死刑且未获复权者；作为某项罪行的告发人或曾经担任告发人者；以及年满二十五岁后控告其父亲的被释奴犯有死罪者。

<!-- source-p 757 -->
<a id="37.14.10"></a>**37.14.10**

<!-- source-p 758 -->
克莱门修斯《尤利亚法与帕皮亚法评注》第九卷。

<!-- source-p 759 -->
释奴保护人若曾以死罪控告其被释奴，裁定认为应将其排除在违遗嘱遗产占有之外。拉贝奥认为，所谓死罪控告，是指所控罪名的刑罚为死刑或流放。告发者应视为已经提出控告，除非他请求撤销控告；塞维利乌斯报告说，普罗库鲁斯也持此见解。

此人也不得依《十二表法》取得所规定的法定继承权。

<!-- source-p 763 -->
<a id="37.14.12"></a>**37.14.12**

<!-- source-p 764 -->
莫德斯汀《答复集》第一卷。

<!-- source-p 765 -->
盖尤斯·塞尤斯立好遗嘱后去世，在遗嘱中将自己的被释奴尤利乌斯列为其子之一，并仿佛将他视为自己的儿子而指定其继承一份遗产。我问：这样的书写能否改变被释奴的身份？莫德斯汀答：不能改变其身份。

家子不得解放其特有产中的奴隶；但经父亲命令，可以解放该奴隶。该奴隶被解放后成为父亲的被释奴。

<a id="37.14.14"></a>**37.14.14**

<!-- source-p 770 -->
乌尔比安《尤利亚法与帕皮亚法评注》第五卷。

<!-- source-p 771 -->
如果我宣誓自己是释奴保护人，应当说，就继承而言我并非释奴保护人，因为宣誓并不能使人成为释奴保护人。若裁判已经判定我为释奴保护人，则属不同情形；此时应受该裁判拘束。

<!-- source-p 774 -->

<!-- source-p 775 -->
<a id="37.14.16"></a>**37.14.16**

<!-- source-p 776 -->
乌尔比安《尤利亚法与帕皮亚法评注》第十卷。

<!-- source-p 777 -->
<a id="37.14.16.pr."></a>**序言。**被释奴若为规避法律而使其财产低于 *centenarius* 等级，则其所为依法律当然无效；因此，释奴保护人得在该被释奴的财产中取得相当于 *centenarius* 等级被释奴遗产中的地位。故无论其以何种方式处分财产，该处分均不发生效力。若其虽为损害释奴保护人而处分财产，但处分后仍高于 *centenarius* 等级，则该处分有效；不过，依法维安诉权与卡尔维西亚诉权，仍可追回其为欺诈而处分的财产。尤利安屡次作此论述，我们也遵循该法。其区别理由如下：为规避法律而处分财产时，所实施的行为无效；所谓规避法律，是指某人使自己的财产低于 *centenarius* 等级，以逃避法律的规定。若处分财产后仍达到 *centenarius* 等级，则不视为规避法律，而仅是损害释奴保护人；因此，可通过法维安或卡尔维西亚之诉追回被处分的财产。

<!-- source-p 778 -->
<a id="37.14.16.1"></a>**1.**若某人一次处分数项财产，使其财产低于 *centenarius* 等级，而追回其中一项或按各项比例追回后，均足以使其财产重新高于该等级，那么应追回全部财产，还是按比例从各项财产中追回，使其达到该等级？较妥当的意见是，所有这些财产处分均不发生效力。

<!-- source-p 779 -->
<a id="37.14.16.2"></a>**2.**若某人并非一次处分财产，而是先后处分若干财产，则后来处分的财产不依法律当然被撤销，只有先前处分的财产如此；至于后来处分的财产，可适用法维安诉权。
