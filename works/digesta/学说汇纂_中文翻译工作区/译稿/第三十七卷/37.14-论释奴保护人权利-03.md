# D.37.14 论释奴保护人权利（*De iure patronatus*，第三段）

> **底本范围：**依 EPUB 中全部 `<p>` 元素的连续编号，翻译 source-p 781–809；保留原有段落、锚点、分题及出处。

<!-- source-p 781 -->
乌尔比安《尤利亚法与帕皮亚法评注》第十一卷。

<!-- source-p 782 -->
<a id="37.14.17.pr."></a>**序言。**神圣的两位皇帝曾作如下敕答：“我们获悉，法学家中有人曾疑问：若某人的祖父在年满二十五岁时以死罪控告自己的被释奴，该孙子能否对祖父的被释奴请求违遗嘱遗产占有？普罗库鲁斯——他确是不可轻视的法学权威——持此见解：在此类情形中，不应向孙子授予遗产占有。我们也曾采纳其意见，在答复凯西狄娅·隆吉娜的请愿书时作出同样答复。我们的友人沃卢修斯·麦基安努斯，不仅精通古老且根基深厚的市民法，而且勤勉审慎；他因顾及我们敕答的权威而心存敬畏，曾当面向我们确认，自己认为不能作出不同答复。然而，在邀请麦基安努斯及其他精通法律的友人共同参与、对此问题作更充分的讨论后，我们认为，更妥当的看法是：孙子不应仅因其父的身份或污名，而被排除在祖父的被释奴遗产之外；无论依法律或裁判官告示的文字，还是依其宗旨，均不应如此。许多法学权威以及我们的友人、显赫之士萨尔维乌斯·尤利安，也持此见解。”

<!-- source-p 783 -->
<a id="37.14.17.1"></a>**1.**另有人问：释奴保护人的儿子若以死罪控告被释奴，这是否会损害其子女？普罗库鲁斯确实认为，施加在释奴保护人之子身上的污名也会损害其子女；但尤利安否认这一点。此处应采纳与尤利安相同的意见。

<!-- source-p 793 -->
<a id="37.14.21"></a>**37.14.21**

<!-- source-p 794 -->
赫尔莫革尼安《法律概要》第三卷。

<!-- source-p 795 -->
<a id="37.14.21.pr."></a>**序言。**无论释奴保护人还是被释奴遭到流放而后获复权，均恢复其先前丧失的释奴保护关系，以及请求违遗嘱遗产占有的权利。释奴保护人或被释奴被判处矿场劳役而后获复权的，也适用同一规则。

<!-- source-p 796 -->
<a id="37.14.21.1"></a>**1.**即使释奴保护人被指定为全部遗产的唯一继承人，也会被排除在违遗嘱遗产占有之外；但若可由奴隶代表其在被释奴遗嘱中的利益，无条件且无迟延地请求补足法定应得份额，则属例外，无论该利益是通过继承、遗赠还是遗嘱信托取得。〔句义与程序关系待核〕

<!-- source-p 797 -->
<a id="37.14.21.2"></a>**2.**两名释奴保护人中，一人若已无条件且无迟延地被指定继承法定应得份额，就不得请求违遗嘱遗产占有；尽管若遗嘱留给他的份额较少，而他请求违遗嘱遗产占有，本可再取得另一份额的增益。

<!-- source-p 798 -->
<a id="37.14.21.3"></a>**3.**被释奴的自然子女若被剥夺继承权，同时另有继承人被指定；而他们又通过奴隶从遗产的另一部分继承其父母的遗产，则可据此对抗释奴保护人。

<!-- source-p 799 -->
<a id="37.14.21.4"></a>**4.**被释奴之子被指定为继承人后，若放弃遗产，释奴保护人不会因此被排除。

<a id="37.14.23"></a>**37.14.23**

<!-- source-p 804 -->
特里福尼努斯《论辩集》第十五卷。

<!-- source-p 805 -->
<a id="37.14.23.pr."></a>**序言。**若某子未为父亲被杀一事复仇，而该罪行是由一名奴隶揭发、该奴隶因此获得自由，我认为，不应将该子视为释奴保护人的儿子，因为他不配享有此地位。

<!-- source-p 806 -->
<a id="37.14.23.1"></a>**1.**有人依据伪造的副遗嘱释放奴隶；这些副遗嘱曾一度被当作真实文件，继承人不知其伪造，遂仿照遗嘱信托而给予奴隶自由。神圣的哈德良皇帝在敕答中规定：这些人确实是自由人，但必须支付其自身的估价。正确的看法是，他们是释放者的被释奴，因为释奴保护人对这些被释奴所享有的权利仍予保留。
