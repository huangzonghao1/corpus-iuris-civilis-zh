# D.37.10《论卡尔波尼安告示》（*De Carboniano edicto*；source-p 532–627）

<!-- source-p 532 -->
<a id="10"></a><a id="37.10"></a>**37.10.0 论卡尔波尼安告示**（*De Carboniano edicto*）

<!-- source-p 533 -->
<a id="37.10.1"></a>**37.10.1**

<!-- source-p 534 -->
**乌尔比安：《告示评注》第四十一卷。**

<!-- source-p 535 -->
<a id="37.10.1.pr."></a>**序言。**如果有人争议某人是否属于子女之列，而该人尚未适婚，则经查明案情后，应像不存在该项争议一样准予其遗产占有；其身份诉讼则经审查后延期至其适婚之时。

<!-- source-p 536 -->
<a id="37.10.1.1"></a>**1.**裁判官还命令提出争议的人同时占有遗产，但前提是他没有为未适婚者提供担保。

<!-- source-p 537 -->
<a id="37.10.1.2"></a>**2.**卡尔波尼安告示的利益不仅适用于男性，也适用于父系后裔中的女性。

<!-- source-p 538 -->
<a id="37.10.1.3"></a>**3.**一般而言，只有有权取得违遗嘱遗产占有的人才享有卡尔波尼安告示的利益；被排除在违遗嘱遗产占有之外的人则不享有。

<!-- source-p 539 -->
<a id="37.10.1.4"></a>**4.**如果争议某人不属于子女之列的，不是其他人而是其父亲本人——例如孙子声称祖父将自己留在家父权之下，而已被解放的父亲希望与他合并取得遗产占有——审理是否也应延期？较妥当的意见是应延期。因为由谁提出争议并不重要；即使立遗嘱人否认他属于子女，却没有在遗嘱中将其排除继承，也可以适用卡尔波尼安告示。

<!-- source-p 540 -->
<a id="37.10.1.5"></a>**5.**如果有人不仅被否认属于子女，而且还被指称是奴隶，例如被说成是女奴所生，尤利安写道仍适用卡尔波尼安告示；神君庇护也曾以敕答作同样说明。因为对面临更大风险的人尤其应予保护。若不如此处理，最为大胆的人就会找到办法，以更严重的不实指控伤害未适婚者。

<!-- source-p 541 -->
<a id="37.10.1.6"></a>**6.**如果被指称为奴隶的是死者本人，结论也相同。

<!-- source-p 542 -->
<a id="37.10.1.7"></a>**7.**如果国库向未适婚者提出身份争议，卡尔波尼安告示也可以适用。

<!-- source-p 543 -->
<a id="37.10.1.8"></a>**8.**庞波尼乌斯在《告示评注》第七十九卷中写道：如果儿子被指定为继承人或被排除继承，卡尔波尼安告示便不适用，即使有人否认他是儿子也是如此；因为即使他并非儿子，也可以作为遗嘱指定继承人取得遗产占有；又或者，即使他确属儿子，也会因被排除继承而被挡在遗产占有之外。不过，庞波尼乌斯说，如果遗嘱指定遗腹子为继承人，而有人否认出生者是儿子、称其为调包婴儿，那么只应授予他遗嘱所指定份额的遗产占有。

<!-- source-p 544 -->
<a id="37.10.1.9"></a>**9.**他还说：某人曾将儿子排除继承，理由是儿子被指为通奸所生；由于有人会争议该人是否属于子女之列，他仍可依告示这一部分取得遗产占有。因为如果他未附理由而被排除继承，便不能取得遗产占有。如果遗嘱写道：“无论谁自称是我儿子，均排除继承”，结论也相同；因为儿子本人并未被排除继承。

<!-- source-p 545 -->
<a id="37.10.1.10"></a>**10.**如果某人仅以极小份额指定自己的儿子为继承人，写道“某女子所生者为继承人”，而非称其为自己的儿子；随后该人主张父亲无遗嘱去世，自己是父亲的自权继承人，那么应考察共同继承人究竟是否否认他是儿子，还是主张遗嘱有效。如果他们主张遗嘱有效，就不应延期审理争议，卡尔波尼安告示也不适用；如果他们否认他是儿子，并主张遗产应以亲属身份归他们，则在授予未适婚者遗产占有后，应将争议延期至其适婚之时。

<!-- source-p 546 -->
<a id="37.10.1.11"></a>**11.**如果母亲被指控调包婴儿，是否应为保护子女身份而延期审理，尚有疑问。如果未适婚者本人的身份受到质疑，考虑到其辩护能力可能不足，审理应延期至其适婚之时。但如果母亲本人被作为被告起诉，她显然能够以完整诚信并在近期有力地为自己辩护，则毫无疑问应立即审理。审理结束后，如果证明该子女系调包而来，就应拒绝其遗产诉权；一切应视同他未被指定为继承人。

<!-- source-p 547 -->
<a id="37.10.2"></a>**37.10.2**

<!-- source-p 548 -->
**马尔西安：《法学原理》第十四卷。**

<!-- source-p 549 -->
即使被指称调包婴儿的女性已经去世，只要仍有共谋参与者，就应立即审理。如果无人可受处罚——例如所有共谋者都已去世——则应依卡尔波尼安告示将审理延期至未适婚者成年。

<!-- source-p 550 -->
<a id="37.10.3"></a>**37.10.3**

<!-- source-p 551 -->
**乌尔比安：《告示评注》第四十一卷。**

<!-- source-p 552 -->
<a id="37.10.3.pr."></a>**序言。**卡尔波尼安告示是为违遗嘱遗产占有及无遗嘱继承而设的；不过，在某些情形下，依遗嘱书板取得遗产占有也似乎需要适用该告示，例如家父在遗嘱中写道“遗腹子为继承人”或“遗腹女为继承人”，而有人否认遗嘱记载真实。

<!-- source-p 553 -->
<a id="37.10.3.1"></a>**1.**如果争议涉及遗嘱信托或遗赠，也可以将案件延期至未适婚者成年；神君庇护曾就此向克劳狄乌斯·哈德里安努斯作出敕答。

<!-- source-p 554 -->
<a id="37.10.3.2"></a>**2.**虽然确定遗嘱指定继承人不能依卡尔波尼安告示取得遗产占有，但身份争议无疑仍可延期至未适婚者成年。因此，如果同时争议父亲的财产及子女身份，该告示便适用；如果仅争议身份，案件也应延期至其成年，但这不是依卡尔波尼安告示，而是依皇帝敕令延期。

<!-- source-p 555 -->
<a id="37.10.3.3"></a>**3.**卡尔波尼安告示不救济已达适婚年龄、但未满二十五岁的人。如果某人已经适婚，却冒充未适婚者取得遗产占有，应当说其行为无效；因为即使他原本未适婚，后来达到适婚年龄，遗产占有的利益也会终止。

<!-- source-p 556 -->
<a id="37.10.3.4"></a>**4.**案情审查的重点在于：如果明显是请求为婴儿取得遗产占有的人恶意诬告，就不应授予遗产占有。因此，请求依卡尔波尼安告示取得遗产占有时，裁判官应调查案情。如果显然请求理由充分，且证据明确证明该人不是儿子，就应拒绝其取得卡尔波尼安遗产占有；如果案情尚有疑问，即有些许事实有利于该未适婚者，尚不能明确认定他不是儿子，就应授予其卡尔波尼安遗产占有。

<!-- source-p 557 -->
<a id="37.10.3.5"></a>**5.**案情审查有两种：一种是决定是否准予卡尔波尼安遗产占有；其利益在于，未适婚者可像不存在任何争议一样取得遗产占有。另一种审查则是决定案件应延期至其适婚之时，还是立即审理。裁判官必须极其审慎地考察，对未适婚者而言，是立即审理更有利，还是延期至成年更有利；尤其应向未适婚者的亲属、母亲和监护人了解情况。设想有些证人，争议延期后可能改变主意、去世，或因时间间隔而不再可信；或者有年迈的助产士、女奴可以说明生育事实；或者存在足以获胜的可靠文书或其他证据，使延期审理给未适婚者造成的损害大于立即审理未能带来的利益。又设想未适婚者无法提供担保，而获准占有财产的争议对方可能转移、隐匿财产或策划其他行为。若裁判官仍将案件延期至成年，使未适婚者承受重大不利，他要么愚蠢，要么不公，因为他本意是给予该人保护。神君哈德良也曾以敕答作如下说明：“案件通常延期至当事人成年，是为了保护未适婚者，使他们在能够自我辩护之前，不必面对身份争议。但如果他们有适当的人替自己辩护，案件又能迅速审结，及时裁判显然有利于他们，并且其监护人也愿意接受审判，就不应对未适婚者适用原为保护他们而设的规则，使其身份悬而未决；此时已经能够作出确定裁判。”

<!-- source-p 558 -->
<a id="37.10.3.6"></a>**6.**如果被指称调包婴儿的未适婚者之母作为被告并胜诉，仍可能继续争议子女身份；例如，有人声称该子女并非由死者所孕，或者虽由死者所孕，却并非在合法婚姻中出生。

<!-- source-p 559 -->
<a id="37.10.3.7"></a>**7.**如果对某人子女身份提出争议的人——该人只声称自己是儿子——去世，其母亲成为继承人，而母亲又对未适婚者提出同一争议；例如，该未适婚者声称自己与死者之子由不同母亲所生，而母亲否认他是儿子，并主张死者儿子的全部遗产应归自己，那么尤利安认为案件应延期至未适婚者成年，因为由母亲以个人名义还是以继承人身份提出争议，并无区别。显然，如果母亲承认该人也是死者之子，只主张父亲遗产的一半归自己，就不应将审判延期；因为此时争议的不是父亲财产，而是兄弟之间的财产。

<!-- source-p 560 -->
<a id="37.10.3.8"></a>**8.**尤利安在同一处又问：如果两名未适婚者相互争议对方的身份，其中一人先达到适婚年龄，是否应等待另一人也成年？应当等待，以便同时审理二人的身份争议；否则可能通过已成年的一方对未适婚者造成预决影响。

<!-- source-p 561 -->
<a id="37.10.3.9"></a>**9.**争议身份的当事人是请求人还是占有人，并无区别；无论其占有财产还是请求财产，案件都延期至适婚之时。

<!-- source-p 562 -->
<a id="37.10.3.10"></a>**10.**如果两名未适婚者相互争议身份，须考察各自究竟是声称自己是唯一的儿子，还是声称自己也是儿子。如果双方都声称自己是唯一的儿子，就应将争议延期至二人都成年；无论他们是请求人还是占有人，均是如此。如果一人声称自己是唯一的儿子，另一人声称自己也是儿子，那么前者成年而后者仍未适婚时，争议仍应延期，因为声称自己也是儿子的未适婚者仍需保护，但只延期有关部分的争议，而非全部；因为其余部分并无争议。如果声称自己也是儿子的人已经成年，而声称自己是唯一儿子的人仍未适婚，就不应延期；此时未适婚者并非承受身份争议，而是提出争议，因为成年者声称自己也是儿子，并未否认对方为儿子。

<!-- source-p 563 -->
<a id="37.10.3.11"></a>**11.**如果有人被命令获释并成为继承人，却对一名未适婚者提出身份争议；该未适婚者声称自己是儿子并使父亲的遗嘱无效，尤利安说，遗产诉讼与自由身份诉讼都应延期至其成年。因为这两项诉讼都无法在不预断其儿子身份的情况下处理。其他依遗嘱而生的自由身份争议也应延期至其成年。

<!-- source-p 564 -->
<a id="37.10.3.12"></a>**12.**如果有一名未适婚者声称自己是死者的儿子，而债务人否认他是死者的儿子，并主张遗产因无遗嘱继承应归某位远在海外的父系亲属，那么有必要对该未适婚者适用卡尔波尼安告示。但对于缺席的父系亲属也应予以保护，要求提供担保。

<!-- source-p 565 -->
<a id="37.10.3.13"></a>**13.**裁判官授予卡尔波尼安遗产占有，意在使受益人暂时成为占有人。如果他开始以卡尔波尼安占有人的身份请求遗产，或单独请求遗产中的物品，尤利安在《学说汇纂》第二十四卷中最为正确地写道，应以抗辩排除其请求；因为他应满足于裁判官暂时使其成为占有人这一优先利益。因此，如果他要请求遗产或个别物品，尤利安说，就应以继承人身份提起直接诉讼，以便通过该项请求裁判其是否作为子女继承人取得遗产；否则，卡尔波尼安遗产占有的推定可能损害对方。这一意见合理且公平。

<!-- source-p 566 -->
<a id="37.10.3.14"></a>**14.**这项遗产占有应在一年内请求；与授予子女的通常遗产占有一样，期限为一年。

<!-- source-p 567 -->
<a id="37.10.3.15"></a>**15.**声称自己是儿子的人不仅应取得卡尔波尼安遗产占有，也应请求取得通常的遗产占有。

<!-- source-p 568 -->
<a id="37.10.3.16"></a>**16.**两种遗产占有的期限分别计算。通常遗产占有的期限自其知道父亲去世且有条件请求遗产占有时起算；卡尔波尼安遗产占有的期限，则自其知道有人对自己提出身份争议时起算。

<!-- source-p 569 -->
<a id="37.10.4"></a>**37.10.4**

<!-- source-p 570 -->
**尤利安：《学说汇纂》第二十四卷。**

<!-- source-p 571 -->
如果某人未依据告示第一部分请求遗产占有，有时仍可依照卡尔波尼安规则依据告示后续部分取得遗产占有，有时则不能。如果父亲死后立即有人对其提出争议，质疑他是否属于子女、能否取得遗产占有，那么两项告示规定的一年期限似乎同时开始计算。反之，如果他过了一段时间才得知有人对其提出争议，即使依据告示第一部分请求遗产占有的期限已经届满，他仍可依据后续部分请求遗产占有；取得后，他将永久享有占有诉权。但如果他成年后被判败诉，诉权即应拒绝。

<!-- source-p 572 -->
<a id="37.10.5"></a>**37.10.5**

<!-- source-p 573 -->
**乌尔比安：《告示评注》第四十一卷。**

<!-- source-p 574 -->
<a id="37.10.5.pr."></a>**序言。**如果提出争议的人本身属于子女之列，那么无论身份受到争议的未适婚者是否提供担保，该人仍应同时被准许占有遗产。

<!-- source-p 575 -->
<a id="37.10.5.1"></a>**1.**如果未适婚者没有得到辩护，因而其对方也被准许占有遗产，那么谁来行使遗产诉权？尤利安在《学说汇纂》第二十四卷中说，应设立一名管理人，由其处理一切事务并行使诉权。他还写道，与未适婚者同时被准许占有遗产的人，也可以对管理人提起诉讼，不应禁止；因为这不会对遗产造成任何预决影响。毕竟，如果未适婚者本人提供了担保，对方也可以正当地对其提起诉讼。

<!-- source-p 576 -->
<a id="37.10.5.2"></a>**2.**每当未适婚者未提供担保，就应准许其对方占有遗产，无论对方是否提供担保。如果对方希望受托管理遗产，就必须向未适婚者提供担保；如果不提供担保，则应设立管理人管理财产。对方若已提供担保，就应出售将随时间灭失或变质的物品；也应向那些债务即将届期免除的债务人追讨债务；其余财产则与未适婚者共同占有。

<!-- source-p 577 -->
<a id="37.10.5.3"></a>**3.**我们来考察，依卡尔波尼安告示获准占有财产的人，是否可以为供养自己而减少财产。如果未适婚者已提供担保，无论总督是否作出裁定，他都可以为供养自己而减少财产；遗产请求人应少取得相应部分。如果他不能提供担保，且似乎无法以其他方式供养自己，就应准许其减少财产，但不得超过供养所必需的数额。即使被减少的遗产属于一名可能最终被判定并非儿子的人，也不应认为这很奇怪；所有有关遗腹子的告示都会准许占有，并为女性提供生活费，因为腹中胎儿也可能并未出生。相比于在证明其非子之后遗产请求人可能少得财产，更应慎重防止儿子因饥饿而死。

<!-- source-p 578 -->
<a id="37.10.5.4"></a>**4.**我认为，尤其应请求裁判官规定：如果争议对方获准占有遗产，不得将文书据为己有。否则，在其整理文书或将文书据为己有期间，未适婚者就会受到欺骗。

<!-- source-p 579 -->
<a id="37.10.5.5"></a>**5.**如果未适婚者及其对方都不提供担保，就应设立管理人管理财产，并在适当时候向诉讼胜诉者返还财产。不过，如果未适婚者的监护人愿意管理财产，如何处理？除非他们以未适婚者名义提供担保，或者他们本人也被指定为管理人，否则不应听从其请求。

<!-- source-p 580 -->
<a id="37.10.6"></a>**37.10.6**

<!-- source-p 581 -->
**保罗：《告示评注》第四十一卷。**

<!-- source-p 582 -->
<a id="37.10.6.pr."></a>**序言。**有人询问，关于母亲财产的争议是否应作出延期裁定。无须作出这种裁定，但应给予极长的延期，使相关事务延至未适婚者成年时处理。

<!-- source-p 583 -->
<a id="37.10.6.1"></a>**1.**尤利安答复说，如果同时争议父亲和母亲的财产，甚至兄弟的财产，这些争议也应延期至未适婚者成年。

<!-- source-p 584 -->
<a id="37.10.6.2"></a>**2.**即使子女依无遗嘱继承规则请求遗产占有，本告示也适用；虽然他们依据较低顺位提出请求——即作为自权继承人而归入法定继承人一类，或者依据准许旁系亲属继承的部分请求——仍然如此。

<!-- source-p 585 -->
<a id="37.10.6.3"></a>**3.**只有同时存在身份争议和遗产争议时，本告示才适用。如果只有身份争议——例如被指称为奴隶——而不存在任何财产争议，就应立即审理自由身份诉讼。

<!-- source-p 586 -->
<a id="37.10.6.4"></a>**4.**如果对未适婚者提出争议的人与其同时获准占有遗产，就不得从死者财产中供养自己，也不得减少任何财产；因为此项占有代替了担保。

<!-- source-p 587 -->
<a id="37.10.6.5"></a>**5.**不仅应向未适婚者提供生活费，还应依遗产财力为其教育及其他必要支出提供费用。

<!-- source-p 588 -->
<a id="37.10.6.6"></a>**6.**未适婚者成年后，依据卡尔波尼安告示获准占有遗产的人是否应承担请求人的诉讼地位？答复认为，他应处于被请求人的诉讼地位，尤其是在他已经提供担保时。即使他此前没有提供担保，只要现在愿意提供，也应将其作为占有人起诉。如果他现在仍不提供担保，而对方愿意提供，则占有权移转给对方；这与对方现在才首次向他请求遗产相同。

<!-- source-p 589 -->
<a id="37.10.7"></a>**37.10.7**

<!-- source-p 590 -->
**尤利安：《学说汇纂》第二十四卷。**

<!-- source-p 591 -->
<a id="37.10.7.pr."></a>**序言。**如果有人否认未适婚者是依法收养的子女，因此争议其是否有权取得父亲遗产，那么作出类似卡尔波尼安裁定并非不公平。

<!-- source-p 592 -->
<a id="37.10.7.1"></a>**1.**同样，如果有人声称未适婚者曾被交给他人收养，因此否认其有权取得自然父亲遗产，也适用卡尔波尼安告示；因为这种情形同样要考察他能否以儿子身份取得遗产。

<!-- source-p 593 -->
<a id="37.10.7.2"></a>**2.**但是，如果争议在于该子女是否被排除继承，就无须将案件延期至其成年，因为此时争议的不是儿子本人，而是遗嘱的效力。

<!-- source-p 594 -->
<a id="37.10.7.3"></a>**3.**如果有人同时争议某未适婚者的自由身份和其父亲遗产，而其母亲本人的自由身份也受到审查，对母亲的诉讼并非总要延期至未适婚者成年；因为对被指称为调包婴儿的人本人，有时也会根据案情立即审理。

<!-- source-p 595 -->
<a id="37.10.7.4"></a>**4.**作出卡尔波尼安裁定时，已取得遗产占有者的情形应视同没有人对其提出争议。

<!-- source-p 596 -->
<a id="37.10.7.5"></a>**5.**如果依据本裁定获准占有遗产的两名兄弟中，一人不愿为其份额辩护，另一人就会被迫为全部遗产辩护，或者将全部遗产让给债权人。

<!-- source-p 597 -->
<a id="37.10.7.6"></a>**6.**有时，被排除继承的儿子也会依据卡尔波尼安裁定取得遗产占有：如果他并非请求违遗嘱遗产占有，而是作为子女依据无遗嘱继承顺位请求，因为他否认父亲的遗嘱书板具有足以支持依遗嘱授予遗产占有的效力；同时又有人否认他是儿子。

<!-- source-p 598 -->
<a id="37.10.7.7"></a>**7.**如果未适婚者请求取得其父亲被释奴的遗产占有，而有人否认他是庇护人的儿子；由于此时并未争议父亲财产，不应延期审理。但如果在作出卡尔波尼安裁定后才提出这一争议，就应将该诉讼延期至未适婚者成年。

<!-- source-p 599 -->
<a id="37.10.7.8"></a>**8.**有人问：未适婚者能否同时依据卡尔波尼安告示取得遗产占有，而遗嘱指定继承人又依遗嘱书板取得遗产占有。我答复说，如果该未适婚者不是儿子，或者没有依据违遗嘱或无遗嘱规则取得遗产占有，那么他本人可以依卡尔波尼安告示取得遗产占有，遗嘱指定继承人也可以依据遗嘱书板取得遗产占有。

<!-- source-p 600 -->
<a id="37.10.8"></a>**37.10.8**

<!-- source-p 601 -->
**阿非利加努斯：《疑义集》第四卷。**

<!-- source-p 602 -->
<a id="37.10.8.pr."></a>**序言。**某人去世；我声称他是我的儿子且仍处于我的权力之下。此时出现一名未适婚者，声称死者本人是家父，并主张遗产应归自己。答复说，必须作出裁定。

<!-- source-p 603 -->
<a id="37.10.8.1"></a>**1.**同样，一名被解放者无遗嘱去世，留下未适婚的儿子；该儿子声称自己是其父亲的自权继承人。我则主张，他在解放之前已经受孕，因此仍处于我的权力之下，其财产应归我。该人确实是儿子；但争议仅涉及他的身份，即他是否曾处于父亲权力之下。不过，无疑应适用该告示的精神，并依卡尔波尼安规则处理。

<!-- source-p 604 -->
<a id="37.10.9"></a>**37.10.9**

<!-- source-p 605 -->
**涅拉提乌斯：《羊皮纸札记》第六卷。**

<!-- source-p 606 -->
拉贝奥写道：如果有人声称未适婚者是调包婴儿，并与其争议父亲遗产，裁判官应确保该未适婚者继续占有遗产。我认为，他所指的是这样一种人：家父认为自己将无子女而死；他死后，才有人开始声称该未适婚者是他的儿子。因为死者生前已经认领的子女，在此事项上的地位比遗腹子更为有利。

<!-- source-p 607 -->
<a id="37.10.10"></a>**37.10.10**

<!-- source-p 608 -->
**马尔凯卢斯：《学说汇纂》第七卷。**

<!-- source-p 609 -->
如果女性在继承人要求下宣誓自己怀有遗腹子，应依卡尔波尼安告示准予遗产占有；如果是她主动向继承人提出宣誓，则应拒绝准予。因为此项占有须经案情审查后准予：既不能因授予继承人遗产占有而对遗腹子造成预决影响，也不能因拒绝授予而剥夺未适婚者通常享有的权利。

<!-- source-p 610 -->
<a id="37.10.11"></a>**37.10.11**

<!-- source-p 611 -->
**帕比尼安：《疑义集》第十三卷。**

<!-- source-p 612 -->
如果遭遇身份争议的人无需裁判官的特别救济即可成为继承人——例如他已被指定为继承人——就不适用卡尔波尼安告示。同样，即使他确实是儿子，也确定不能成为继承人的情形，也不适用该告示；例如提提乌斯已被指定为继承人，有人却否认遗腹子或被排除继承的未适婚者是儿子。即使在某些情形中，确认儿子身份对其有利也无关紧要，例如有同母异父或同父异母兄弟的财产、被释奴权利或墓地权利；因为这些情形确定不适用卡尔波尼安告示。

<!-- source-p 613 -->
<a id="37.10.12"></a>**37.10.12**

<!-- source-p 614 -->
**帕比尼安：《疑义集》第十四卷。**

<!-- source-p 615 -->
未适婚者声称自己是儿子并依第一项告示请求遗产占有，而遗嘱指定继承人正是其诉讼对方；此时，不能类推法定继承人的规则，暂时准许遗嘱指定继承人依据遗嘱书板取得遗产占有。如果此后遗嘱指定继承人或本可取得无遗嘱遗产占有的人去世，应救济他们的继承人。因为试想，他们可能因法律规定的障碍，或因诉讼尚未解决而不能接受遗产。

<!-- source-p 616 -->
<a id="37.10.13"></a>**37.10.13**

<!-- source-p 617 -->
**保罗：《答复集》第十一卷。**

<!-- source-p 618 -->
提提娅在丈夫死后生下一名遗腹女。塞姆普罗尼乌斯在行省总督面前指控提提娅通奸。我询问，是否应将通奸案件延期至女儿成年，以免对遗腹女造成预决影响。保罗答复说，如果无人争议该未适婚女儿是否有权取得父亲遗产，监护人请求将通奸案件也延期至其成年便没有理由。

<!-- source-p 619 -->
<a id="37.10.14"></a>**37.10.14**

<!-- source-p 620 -->
**谢沃拉：《答复集》第二卷。**

<!-- source-p 621 -->
有人询问：依据卡尔波尼安告示取得遗产占有的未适婚者，如果在占有权实际移转给他之前已经成年，是否应承担请求人的诉讼地位。我答复说，对于他向占有人请求的财产，举证责任由他承担。
