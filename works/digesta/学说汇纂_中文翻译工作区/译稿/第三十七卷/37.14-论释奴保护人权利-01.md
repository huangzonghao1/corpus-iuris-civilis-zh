# D.37.14 论释奴保护人权利（*De iure patronatus*，第一段）

> **底本范围：**依 d-37.htm source-p 721–750 翻译；保留原有段落、锚点、题名及出处。

<!-- source-p 721 -->
<a id="14"></a><a id="37.14"></a>**37.14.0 论释奴保护人权利**（*De iure patronatus*）。

<!-- source-p 722 -->
<a id="37.14.1"></a>**37.14.1**

<!-- source-p 723 -->
乌尔比安《行省总督职务论》第九卷。

<!-- source-p 724 -->
总督应当听取释奴保护人对被释奴提出的申诉，并认真处理，不可敷衍了事；忘恩的被释奴不应逃脱惩罚。如果被释奴对释奴保护人、保护女，或他们的子女怠慢失礼，应予斥责，并警告其若再次引发申诉，将受到严厉惩罚，之后即可将其释放。但如果被释奴侮辱他们或出言辱骂，还应判处其限期流放；如果对他们动手，则应发配矿场。若被释奴捏造针对他们的指控、唆使告发人，或以其他方式企图对付他们，也适用同样处罚。

<!-- source-p 725 -->
<a id="37.14.2"></a>**37.14.2**

<!-- source-p 726 -->
乌尔比安《意见集》第一卷。

<!-- source-p 727 -->
释奴保护人不得禁止被释奴从事合法商业活动。

<!-- source-p 728 -->
<a id="37.14.3"></a>**37.14.3**

<!-- source-p 729 -->
马尔基安《法学原理》第二卷。

<!-- source-p 730 -->
某人被指定为监护人，同时遗赠给他一名女奴，并受托将她释放。他接受遗赠后便将女奴释放，并以此为由请求免除未成年人监护职责。塞维鲁皇帝与安东尼努斯皇帝在敕答中说，他确实成为释奴保护人，但不得享有任何释奴保护人的利益。

<!-- source-p 731 -->
<a id="37.14.4"></a>**37.14.4**

<!-- source-p 732 -->
马尔基安《法学原理》第五卷。

<!-- source-p 733 -->
塞维鲁皇帝与安东尼努斯皇帝极为宽厚地作出敕答：即使释奴保护人的父亲被判处叛国罪，其子女仍保有对被释奴的权利；其他原因受惩罚者的子女，同样保有被释奴关系所生的权利。

<!-- source-p 734 -->
<a id="37.14.5"></a>**37.14.5**

<!-- source-p 735 -->
马尔基安《法学原理》第十三卷。

<!-- source-p 736 -->
<a id="37.14.5.pr."></a>**序言。**神圣的克劳狄乌斯皇帝命令：若查明某被释奴唆使告发人对其释奴保护人的身份提出质疑，应命令该被释奴重新成为其保护人的奴隶。

<!-- source-p 737 -->
<a id="37.14.5.1"></a>**1.**我们皇帝的敕答规定，如果释奴保护人不供养自己的被释奴，就会丧失释奴保护人的权利。

<!-- source-p 738 -->
<a id="37.14.6"></a>**37.14.6**

<!-- source-p 739 -->
保罗《埃利乌斯·森提乌斯法评注》第二卷。

<!-- source-p 740 -->
<a id="37.14.6.pr."></a>**序言。**有人以宣誓迫使女被释奴不得结婚或生育子女；允许被释奴宣誓的人，也视为实施了这种强迫。但若处于释奴保护人权力之下的儿子在保护人不知情时迫使其宣誓，该行为不影响保护人；如果该儿子经释奴保护人命令而如此行事，则应认为保护人受此法拘束。

<!-- source-p 741 -->
<a id="37.14.6.1"></a>**1.**若保护人约定一百日劳务，或每次劳务给付五枚金币，不应认为其约定违反法律，因为被释奴有权选择是否提供劳务。

<!-- source-p 742 -->
<a id="37.14.6.2"></a>**2.**尽管该法没有明文排除任何特定人，但应理解为，法律所针对的是有生育能力的人。因此，如果有人迫使一名已被阉割的被释奴宣誓，应当说保护人不因此受到该法处罚。

<!-- source-p 743 -->
<a id="37.14.6.3"></a>**3.**若释奴保护人以宣誓迫使女被释奴嫁给自己：如果他迫使她宣誓时确实打算娶她，则似乎并未违反法律；但若他并不打算娶她，只是为了阻止她嫁给别人而迫使她宣誓，尤利安说，这就是规避法律，保护人应承担责任，如同他迫使女被释奴宣誓不得结婚一样。

<!-- source-p 744 -->
<a id="37.14.6.4"></a>**4.**《尤利亚婚姻法》免除下列宣誓：要求男被释奴不得娶妻、要求女被释奴不得结婚的宣誓，前提是他们希望合法缔结婚姻。

<!-- source-p 745 -->
<a id="37.14.7"></a>**37.14.7**

<!-- source-p 746 -->
莫德斯汀《释奴论》单卷。

<!-- source-p 747 -->
<a id="37.14.7.pr."></a>**序言。**神圣的维斯帕先皇帝裁定：某女奴被出售时附有不得卖淫的条件，并约定若她卖淫便获得自由；后来买受人又无条件地将她出售给他人，则依买卖约定，她应成为自由人及先前出卖人的被释奴。

<!-- source-p 748 -->
<a id="37.14.7.1"></a>**1.**皇帝的指令规定，行省总督也应依法审理释奴保护人的申诉，并根据被释奴所犯的行为判处相应处罚。有时会对忘恩的被释奴执行下列处罚：没收其部分财产并交给释奴保护人；或者用杖鞭打后释放。
