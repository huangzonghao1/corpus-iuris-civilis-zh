# D.37.5 请求违遗嘱的遗产占有时应履行的遗赠（*De legatis praestandis contra tabulas bonorum possessione petita*）

<!-- source-p 203 -->
<a id="5"></a><a id="37.5"></a>**37.5.0 请求违遗嘱的遗产占有时应履行的遗赠**（*De legatis praestandis contra tabulas bonorum possessione petita*）。

<!-- source-p 204 -->
<a id="37.5.1"></a>**37.5.1**

<!-- source-p 205 -->
乌尔比安《告示评注》第四十卷。

<!-- source-p 206 -->
<a id="37.5.1.pr."></a>**序言**　本标题体现了某种自然公平，也在某些方面创设了新规则：通过请求违遗嘱的遗产占有而推翻父亲遗嘱安排的人，仍应依父亲的遗嘱，向某些人履行遗赠和遗嘱信托；这些人包括子女、父母、妻子，以及以嫁资名义获遗赠的儿媳。

<!-- source-p 207 -->
<a id="37.5.1.1"></a>**1**　裁判官概括地将父母和子女列为例外，并未限定亲属的辈分，因此对他们应无限制地履行遗赠。裁判官也未区分亲属是经由男性还是女性一系而来。因此，凡属子女或父母者，均可请求遗赠，但前提是彼此之间存在血亲关系。

<!-- source-p 208 -->
<a id="37.5.1.2"></a>**2**　我们也允许已被送养的子女或养子女请求遗赠，但以他们仍保有子女身份为限。

<!-- source-p 209 -->
<a id="37.5.1.3"></a>**3**　留给遗腹子女的遗赠也当然应予履行：

<!-- source-p 210 -->
<a id="37.5.2"></a>**37.5.2**

<!-- source-p 211 -->
尤利安《学说汇纂》第二十三卷。

<!-- source-p 212 -->
因此，若儿子在妻子怀孕时被解放，并请求违遗嘱的遗产占有，他就应向其遗腹子履行遗赠。

<!-- source-p 213 -->
<a id="37.5.3"></a>**37.5.3**

<!-- source-p 214 -->
乌尔比安《告示评注》第四十卷。

<!-- source-p 215 -->
<a id="37.5.3.pr."></a>**序言**　若以因死亡而赠与的方式向列入例外范围的人作出赠与，我认为应予维持；若受赠人不在例外范围内，则我认为应从其处追回因死亡而赠与的财产。

<!-- source-p 216 -->
<a id="37.5.3.1"></a>**1**　裁判官仅保护子女和父母，并未将兄弟姐妹也列入遗赠的保留范围。

<!-- source-p 217 -->
<a id="37.5.3.2"></a>**2**　只有直接留给父母或子女本人的财产才应给付。若遗赠写给他们的奴隶，或写给受其权力支配的人，则无须给付；因为我们考察的不是谁取得该财产，而是立遗嘱人意在尊重谁。

<!-- source-p 218 -->
<a id="37.5.3.3"></a>**3**　若遗赠以共同方式留给例外范围内的人和无权请求遗赠的人，则仅为前者保留其自己的份额。

<!-- source-p 219 -->
<a id="37.5.3.4"></a>**4**　同样，若例外范围内的人受嘱托将留给自己的财产返还给第三人，则不应履行该遗赠，因为其本人并未取得该项利益。

<!-- source-p 220 -->
<a id="37.5.3.5"></a>**5**　但若遗赠留给第三人，并嘱托该第三人将遗赠交给子女或父母中的一人，则应相应地认为遗赠必须履行。

<!-- source-p 221 -->
<a id="37.5.3.6"></a>**6**　此外，若遗赠留给第三人时附加条件，要求其将财产交给某一子女，则最公平的做法是认为，裁判官不应拒绝给予该第三人诉权。

<!-- source-p 222 -->
<a id="37.5.3.7"></a>**7**　请求违遗嘱遗产占有的人，只须履行有效作出的遗赠；这些遗赠原本并非不应给付，只是由于儿子请求违遗嘱的遗产占有，才不应给付。〔底本此处句子未完，原文止于逗号。〕

<!-- source-p 224 -->

<a id="37.5.5"></a>**37.5.5**

<!-- source-p 227 -->
乌尔比安《告示评注》第四十卷。

<!-- source-p 228 -->
<a id="37.5.5.pr."></a>**序言**　某人指定未适婚的儿子为继承人，并为其指定替补继承人，却遗漏了已被解放的儿子。后来，两个儿子都取得遗产占有。替补继承人所留的遗赠不仅给子女和父母，也给了第三人。问题是，未适婚儿子死亡后，是否应强令替补继承人履行这些遗赠？若遗赠由未适婚儿子留下，则只须向子女和父母履行；若由替补继承人留下，则应向所有受遗赠人履行，但须考虑《法尔基第法》，即替补继承人应保留其从父亲遗产中取得的一半中的四分之一，也就是总遗产的八分之一。

<!-- source-p 229 -->
<a id="37.5.5.1"></a>**1**　若未适婚儿子仅按十二分之一的份额被指定为继承人，较为可取的意见是，考虑《法尔基第法》后，其遗赠给付义务以遗产的一半为限。虽然未适婚儿子最初仅被指定为十二分之一份额继承人，但其后来取得的遗产也会增加替补继承人所留遗赠的负担。

<!-- source-p 230 -->
<a id="37.5.5.2"></a>**2**　裁判官希望向所有子女履行遗赠，但将因前述理由而取得遗产占有的子女排除在外。因为既然裁判官已给予他们遗产占有，就认为他们无权请求遗赠。因此，每人都必须自行决定，是请求违遗嘱的遗产占有，还是请求遗赠；若选择前者，便不能取得遗赠；若选择遗赠，我们遵循的法律规则是不允许其请求违遗嘱的遗产占有。

<!-- source-p 231 -->
<a id="37.5.5.3"></a>**3**　若某人取得违遗嘱的遗产占有，之后却发现他并非有权取得该项遗产占有的子女之一，但属于有权取得遗赠的人，已确立的规则是，不得拒绝其请求遗赠；无论他请求的是通常的遗产占有，还是卡尔博尼亚遗产占有（*bonorum possessio Carboniana*），均如此。

<!-- source-p 232 -->
<a id="37.5.5.4"></a>**4**　不仅取得遗产占有的人不能请求遗赠，若其因立遗嘱人的意思另行取得了某项财产，也同样不能请求。由此可知，尤利安写道：若某人被指定为未适婚弟弟的替补继承人，并取得违遗嘱的遗产占有，则不得请求其已死亡弟弟的遗产；他原本是由父亲指定为替补继承人的。

<!-- source-p 233 -->
<a id="37.5.5.5"></a>**5**　若遗赠同时留给子女和第三人，即使两类受遗赠人都可能适用《法尔基第法》，致使子女所得遗赠减少，但现在由于遗赠不向第三人给付，子女所得遗赠反而增加。

<!-- source-p 234 -->
<a id="37.5.5.6"></a>**6**　若遗产份额留给子女或父母之一，该份额是否应像遗赠一样予以保留？尤利安屡次写道，遗产份额应与遗赠作相同处理；神圣庇乌斯皇帝的敕答也确认这一见解，因为继承权的赋予不仅名义更为尊贵，负担也更重。

<!-- source-p 235 -->
<a id="37.5.5.7"></a>**7**　应以如下方式救济这些人：若遗产份额高于按人头计算的份额，应保护其权利至该份额为止；若低于该份额，则只在其被指定的范围内给予诉权。对留给他们的遗赠、遗嘱信托以及因死亡而赠与，也应适用同一规则。

<!-- source-p 236 -->
<a id="37.5.5.8"></a>**8**　受保留遗产份额之人，是否必须履行所有遗赠，还是仅须向例外范围内的人履行？较为可取的见解是，只须向例外范围内的人履行；但这并非仅使其本人受益。若遗产份额同时负有向子女、父母和第三人给付遗赠的义务，我们毫不怀疑，不向第三人给付的部分应使子女和父母受益。因此，只有在遗赠不应给付给作为受遗赠人的子女或父母时，不给付第三人的部分才会与请求违遗嘱遗产占有之人分享。

<!-- source-p 237 -->
<a id="37.5.6"></a>**37.5.6**

<!-- source-p 238 -->
尤利安《学说汇纂》第二十三卷。

<!-- source-p 239 -->
萨尔维乌斯·阿里斯顿致尤利安。某人有一名已被解放的儿子，却遗漏了该儿子；他指定自己的父亲和一名第三人为继承人，并向父亲作出遗赠。儿子请求违遗嘱的遗产占有。我询问：若两名继承人都接受继承、其中一人接受，或两人都不接受，父亲应以遗赠名义取得多少？答称：我屡次注意到，告示中这一部分规定，被解放的儿子取得违遗嘱的遗产占有后，应向子女和父母履行遗赠；这项规定存在若干可批评之处。因为若遗赠总额为遗产四分之三，受遗赠人所得会超过被解放儿子。因此，应通过裁决予以调和：被解放儿子应将遗产的一部分给付给对方，但指定继承人取得的数额不得超过被解放儿子；同时还应调整遗赠的数额，使任何人所取得的遗赠利益不超过被解放儿人取得遗产占有后所保留的数额。

<a id="37.5.8.pr."></a>**序言**　我们来考察应如何确定按人头计算的份额。假定有两人请求违遗嘱的遗产占有，其中一人属于子女或父母，则按人头计算的份额为三分之一；若有三人请求该遗产占有，则按人头计算的份额为四分之一。遗赠也适用相同规则。但是，若只有一名子女取得违遗嘱遗产占有，而有数名子女或父母取得遗赠，则应作如下理解：被遗漏的儿子取得一半，其余子女或父母合计取得另一半。

<!-- source-p 246 -->
<a id="37.5.8.1"></a>**1**　若子女或父母之一既被指定为继承人又取得遗赠，我们是只保留其继承份额、同时也保留遗赠，还是让其择一取得？较为可取的见解是两者均予保留，但两者合计不得超过按人头计算的份额。

<!-- source-p 247 -->
<a id="37.5.8.2"></a>**2**　若其保留按人头计算的继承份额之人接受了遗产，因接受继承，释放奴隶的处分也必然发生效力。但应考察接受继承者是否负有恶意之诉的责任。较为可取的见解是：若取得遗嘱占有的被遗漏者已经通知他，并承诺给付按人头计算的份额，而他仍接受继承，则应归责于他，并可对其提起恶意之诉；因为奴隶获得自由会使遗产受损。

<!-- source-p 248 -->
<a id="37.5.8.3"></a>**3**　若遗赠给妻子或儿媳的财产并非嫁资，则请求违遗嘱遗产占有后不予给付。

<!-- source-p 249 -->
<a id="37.5.8.4"></a>**4**　毫无疑问，“儿媳”一词也包括孙媳及其他更远辈分的姻亲女性。

<!-- source-p 250 -->
<a id="37.5.8.5"></a>**5**　但若遗赠是以嫁资名义作出，我认为不应将妻子或儿媳的请求限制在按人头计算的份额，因为该女子属于债权人之一。

<!-- source-p 251 -->
<a id="37.5.8.6"></a>**6**　裁判官不仅保护预先留出的嫁资；若以替代嫁资的方式留给女子某物，也同样适用。例如，嫁资原本为实物，却改以一定数额遗赠给她，或反之；但必须明确写明该财产是作为嫁资替代物留给她。

<!-- source-p 257 -->
<a id="37.5.10.pr."></a>**序言**　若某人以嫁资名义将部分遗产留给她，并指定她为继承人，我认为也应保护她取得该部分。

<!-- source-p 258 -->
<a id="37.5.10.1"></a>**1**　我们要求妻子在立遗嘱人死亡时仍是其妻子。若立遗嘱人预先将嫁资留给儿媳，而儿媳在立遗嘱人死亡时仍处于婚姻关系中，则不存在遗赠，因为嫁资债务尚未到期；但是，既然婚姻存续期间也可以向公公的继承人提起诉讼，就应认为同样可以请求预留的嫁资。

<!-- source-p 259 -->
<a id="37.5.10.2"></a>**2**　请求违遗嘱遗产占有的人，不必履行所有继承顺位所留的遗赠，只须履行其取得遗产占有所针对的那一顺位所留的遗赠。但有时，请求的遗产占有针对一个顺位，遗赠却应由另一个顺位履行。例如，立遗嘱人设置了两个继承顺位，遗漏了已被解放的儿子，却在两个顺位中都给子女和父母留下遗赠。尤利安说：若第一顺位中仍有继承人在世，应履行第一顺位为子女和父母所留的遗赠；若第一顺位无人存活，则应履行后续顺位所留的遗赠。若立遗嘱人死亡时第一、第二顺位中均无人存活，则被遗漏的儿子应依法定继承取得遗产占有，无人须履行遗赠。若指定继承人在立遗嘱人死亡后、接受继承前死亡，则虽可认为请求的是针对他们的遗产占有，但他们所留的遗赠不应履行；只须履行替补继承人所留的遗赠。

<!-- source-p 271 -->
<a id="37.5.14.pr."></a>**序言**　有时，某人依据遗嘱书板取得遗产占有，却依违遗嘱的遗产占有规则行事。例如，已被解放的儿子被指定为继承人，另一名已被解放的儿子则遭遗漏；前者请求违遗嘱的遗产占有，后者予以放弃。在这种情况下，显然应强令前者履行所有遗赠，犹如告示规定并未生效一样。因为不得让已被遗漏者放弃其权利，反而使取得指定继承权的被解放儿子获利。

<!-- source-p 272 -->
<a id="37.5.14.1"></a>**1**　若一名指定继承人的儿子点名将遗赠留给某一子女或父母，而该继承人后来与其他人一同取得违遗嘱的遗产占有，较为妥当的意见是，所有取得该遗产占有的人均应被强令履行该项遗赠。

<!-- source-p 273 -->
<a id="37.5.15"></a>**37.5.15**

<!-- source-p 274 -->
保罗《告示评注》第四十一卷。

<!-- source-p 275 -->
<a id="37.5.15.pr."></a>**序言**　处于家父权下而遭遗漏的儿子，即使请求违遗嘱的遗产占有，也不负有履行遗赠的义务，因为即使不请求遗产占有，他也会依法定继承取得遗产。恶意抗辩也不能对其适用；若仅因他请求了遗产占有便强令其履行遗赠，就很荒谬，因为即使不请求，他也会基于自己的权利取得遗产。因此，若有两名被遗漏者，一人为已被解放的儿子，另一人为仍处于家父权下的儿子，有人认为，已被解放的儿子也不应履行遗赠，因为他实际上夺取了其兄弟的一半份额；若兄弟不请求遗产占有，原本也会独自取得全部遗产。那么应如何处理？若处于父权下的儿子遭遗漏，则适用上述较为正确的规则；但若该儿子被指定为继承人并体现了父亲的意愿，即使他放弃遗产占有，也应对受遗赠人承担义务。

<!-- source-p 276 -->
<a id="37.5.15.1"></a>**1**　若一名已被解放的儿子被指定为继承人，另一名儿子遭遗漏，而两人均取得违遗嘱的遗产占有，则指定继承人应履行与被遗漏者相同的遗赠。若只有指定继承人取得违遗嘱的遗产占有，则他应履行所有遗赠，犹如已经接受继承一样。但若指定继承人接受了遗产，而被遗漏者取得遗产占有，则取得遗产占有之人仅对特定的人负有遗赠义务；至于指定继承人是否也负此义务，尚有疑问。许多人认为，他也应向特定的人履行遗赠；我认为这更为正确，因为裁判官也基于这一理由保护他，即他属于有权请求违遗嘱遗产占有的子女。

<!-- source-p 277 -->
<a id="37.5.15.2"></a>**2**　只有在其被指定的份额超过或等于二分之一时，才应保护其取得二分之一份额；若其被指定的份额低于二分之一，则认为保护不得超过其受指定的份额。因为，既未取得遗产占有，也未被指定为超过其实际份额的继承人，他又有什么理由取得更大份额呢？

<!-- source-p 278 -->
<a id="37.5.15.3"></a>**3**　若女子并无嫁资，即使以嫁资名义遗赠给她，也不应给付任何遗赠。

<!-- source-p 279 -->
<a id="37.5.15.4"></a>**4**　若遗赠留给指定继承人以外之人，条件是该人给继承人十，而受赠人属于例外范围，则只有在他把十交给取得违遗嘱遗产占有之人时，才可请求遗赠；若交给指定继承人，则不能请求。因为让一人享有继承利益、却让另一人承担遗赠负担，是荒谬的。即使他受命将十交给提图斯，也应交给提图斯的儿子，而非提图斯本人。

<!-- source-p 280 -->
<a id="37.5.16"></a>**37.5.16**

<!-- source-p 281 -->
乌尔比安《论答辩》第四卷。

<!-- source-p 282 -->
若所述情形中，一名被遗漏的儿子仍处于家父权下，另一名已被解放的儿子则被指定为继承人，那么显然是处于父权下的儿子使告示生效。即使两人都请求违遗嘱的遗产占有，仍处于父权下的儿子因依法定继承取得遗产，不必向子女和父母履行遗赠。已被解放的儿子是否也无需履行，因为这会夺去另一人的财产，而若该人独自取得遗产占有，本来无须履行遗赠？较为正确的见解是，至少已被解放的儿子仍须向子女和父母履行遗赠。因此，若他并未请求违遗嘱的遗产占有，也应保护其取得相应份额，且他无论如何都应向子女和父母履行遗赠。但他是否也须向其他人履行，我有疑问；不过，既然他完整享有立遗嘱人的意愿所给予的利益，就应在自己份额范围内完整遵循该意愿。

<a id="37.5.25"></a>**37.5.25**

<!-- source-p 309 -->
马尔切鲁斯《学说汇纂》第九卷。

<!-- source-p 310 -->
<a id="37.5.25.pr."></a>**序言**　某人解放了儿子，却将该儿子所生的孙子留在自己的权力下；他在遗嘱中剥夺儿子的继承权，指定孙子为部分继承人，并遗漏另一名已被解放的儿子。可以主张，孙子也能够请求违遗嘱的遗产占有：凡父亲若不成为继承人、某人本可依法定继承取得的份额，均可据此获得遗产占有。

<!-- source-p 311 -->
<a id="37.5.25.1"></a>**1**　某人的儿子处于收养关系中；此人指定儿子后来所生的孙子为继承人，却遗漏了已被解放的儿子。孙子是否依告示有权请求遗产占有？仍应参照父母和子女的情形保护他，因为取得违遗嘱遗产占有的人必须向子女和父母履行遗赠。

<!-- source-p 312 -->
<a id="37.5.25.2"></a>**2**　若其从同一儿子处留有一名或数名孙子处于自己的权力下，则毫无疑问，应按同一份额保护他们；如果这些孙子是由女儿所生，或死者的母亲被指定为继承人，他们也会受到同等保护，因为他们与上述人等同。
