# D.37.1《论遗产占有》（*De bonorum possessionibus*；source-p 001–063）

<!-- source-p 001 -->
<a id="1"></a><a id="37.1"></a>**37.1.0 论遗产占有**（*De bonorum possessionibus*）

<!-- source-p 002 -->
<a id="37.1.1"></a>**37.1.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第三十九卷。**

<!-- source-p 004 -->
准予遗产占有，不仅赋予遗产中的利益，也使受益人承担遗产义务；同时，遗产中各项财物的所有权也归其取得，因为这些内容均与遗产相连。

<!-- source-p 005 -->
<a id="37.1.2"></a>**37.1.2**

<!-- source-p 006 -->
**乌尔比安：《告示评注》第十四卷。**

<!-- source-p 007 -->
因为遗产占有人在一切方面都被视同继承人。

<!-- source-p 008 -->
<a id="37.1.3"></a>**37.1.3**

<!-- source-p 009 -->
**乌尔比安：《告示评注》第三十九卷。**

<!-- source-p 010 -->
<a id="37.1.3.pr."></a>**序言。**此处所说的“财产”，如我们通常所说，应理解为对某一整体的继受，即继受死者的法律地位，并承受该整体的利益与义务。无论财产是否足以清偿债务、带来损失还是收益，也无论它由有体物还是诉权构成，在本篇中都应严格称为“财产”。

<!-- source-p 011 -->
<a id="37.1.3.1"></a>**1.**正如拉贝奥所写，遗产或财产占有不应像对物的占有那样理解，因为这主要是对权利的占有，而非对有体物的占有。最后，拉贝奥说，即使遗产中不存在任何有体物，也仍可正确地取得该遗产的占有。

<!-- source-p 012 -->
<a id="37.1.3.2"></a>**2.**因此，我们可以把遗产占有正确定义为：追索并保有某人在死亡时所拥有的财产整体或特定财产的权利。

<!-- source-p 013 -->
<a id="37.1.3.3"></a>**3.**未经本人同意，不得为任何人取得遗产占有。

<!-- source-p 014 -->
<a id="37.1.3.4"></a>**4.**市镇、团体、区会及法人团体均可取得遗产占有。因此，无论由其代理人提出请求，还是由其他人提出请求，遗产占有都可有效授予；而且，即使没有人以市镇名义请求或取得遗产占有，市镇仍可依裁判官告示取得遗产占有。

<!-- source-p 015 -->
<a id="37.1.3.5"></a>**5.**遗产占有既可授予家父，也可授予家子，但家子须对军营特有产或准军营特有产享有立遗嘱权。

<!-- source-p 016 -->
<a id="37.1.3.6"></a>**6.**毫无疑问，也可以准予已经死于敌方之手的人取得遗产占有，即使其死亡时处于奴役状态。

<!-- source-p 017 -->
<a id="37.1.3.7"></a>**7.**本人可以亲自取得遗产占有，也可以通过他人取得。如果未经我的委任而有人替我请求遗产占有，只有在我追认该行为后，遗产占有才归我取得。因此，如果我在追认之前去世，毫无疑问，我不能取得遗产占有；因为我本人没有追认，我的继承人也不能追认，因为遗产占有权不会移转给继承人。

<!-- source-p 018 -->
<a id="37.1.3.8"></a>**8.**如果遗产占有须经审查案情后准予，则只能在法庭上准予；因为裁判官既不能在法庭外作出该项裁定，也不能在法庭外经审查案情而准予遗产占有。

<!-- source-p 019 -->
<a id="37.1.3.9"></a>**9.**应当知道，遗产占有适用份额增益权。因此，如果有数人有权取得遗产占有，其中一人已经取得，而其他人尚未取得，

<!-- source-p 020 -->
<a id="37.1.4"></a>**37.1.4**

<!-- source-p 021 -->
**盖尤斯：《尤利亚法与帕皮亚法评注》第八卷。**

<!-- source-p 022 -->
例如，他们放弃了自己的权利，或者遗产占有期限届满而被排除，或者在请求遗产占有之前已经死亡，

<!-- source-p 023 -->
<a id="37.1.5"></a>**37.1.5**

<!-- source-p 024 -->
**乌尔比安：《告示评注》第三十九卷。**

<!-- source-p 025 -->
已取得遗产占有者还会增益取得其他人本可请求、但未请求的份额。

<!-- source-p 026 -->
<a id="37.1.6"></a>**37.1.6**

<!-- source-p 027 -->
**保罗：《告示评注》第四十一卷。**

<!-- source-p 028 -->
<a id="37.1.6.pr."></a>**序言。**裁判官向受庇护人承诺授予其对遗嘱书板外遗产特定份额的遗产占有，却向遗嘱指定继承人承诺依据遗嘱书板授予另一份额。〔底本作 *certae patris*，疑为 *certae partis*；此处暂按“特定份额”理解。〕因此，不发生份额增益权。于是，如果遗嘱指定继承人没有请求依据遗嘱书板取得另一份额，裁判官会明确承诺将该份额的遗产占有授予受庇护人；其他享有增益权的人则只须一次请求遗产占有。

<!-- source-p 029 -->
<a id="37.1.6.1"></a>**1.**遗产占有的利益有多种：有些是在违背死者意思的情况下授予，有些则依照死者意思授予；此外，还可依法定继承规则授予有权或无权继承的人。依市民法，因人格减等而不再是自权继承人的子女不享有继承权；但出于公平，裁判官会撤销其人格减等的效果。裁判官也为保护法律规定而授予遗产占有。

<!-- source-p 030 -->
<a id="37.1.6.2"></a>**2.**以符号写成的遗嘱书板不包括在告示所规定的范围内，因为佩狄乌斯在《告示评注》第二十五卷中写道，符号并非文字。

<!-- source-p 031 -->
<a id="37.1.7"></a>**37.1.7**

<!-- source-p 032 -->
**乌尔比安：《萨宾评注》第一卷。**

<!-- source-p 033 -->
<a id="37.1.7.pr."></a>**序言。**如果裁判官已查明奴隶的身份状况，奴隶也可以有效地请求遗产占有；因为即使请求人缺席或没有亲自提出请求，也可以授予遗产占有，只要裁判官知道这一情况。因此，女性也可以替他人请求遗产占有。

<!-- source-p 034 -->
<a id="37.1.7.1"></a>**1.**未适婚年龄者未经监护人同意，既不能取得遗产占有，也不能接受诉讼。

<!-- source-p 035 -->
<a id="37.1.7.2"></a>**2.**由于监护人可以替被监护人、父亲可以替婴儿子女请求遗产占有，因此应以监护人或父亲知悉相关事实之日作为期限起算日。

<!-- source-p 036 -->
<a id="37.1.8"></a>**37.1.8**

<!-- source-p 037 -->
**保罗：《普劳提乌斯评注》第八卷。**

<!-- source-p 038 -->
监护人不得放弃未适婚年龄者有权取得的遗产占有，因为监护人虽获准代为请求，却未获准代为放弃。

<!-- source-p 039 -->
<a id="37.1.9"></a>**37.1.9**

<!-- source-p 040 -->
**庞波尼乌斯：《萨宾评注》第三卷。**

<!-- source-p 041 -->
如果存在数个顺位的遗产占有请求权，在尚不确定前一顺位的人是否提出请求时，后一顺位人的请求期限尚未开始，这一点已获确认。

<!-- source-p 042 -->
<a id="37.1.10"></a>**37.1.10**

<!-- source-p 043 -->
**保罗：《萨宾评注》第二卷。**

<!-- source-p 044 -->
在遗产占有事项上，不知法律并不能阻止请求期限开始；因此，遗嘱指定继承人的期限甚至在遗嘱书板尚未开启之前便开始计算。知道死者已经死亡、自己是最近亲属，并且有条件向他人咨询，就已足够。这里所说的“知悉”并非指法学家所具备的法律知识，而是指本人已经知道，或通过咨询更有学识者即可获得的知识。

<!-- source-p 045 -->
<a id="37.1.11"></a>**37.1.11**

<!-- source-p 046 -->
**盖尤斯：《行省告示评注》第十四卷。**

<!-- source-p 047 -->
如果监护人为未适婚年龄者请求遗产占有，而该遗产占有带来的不利益超过利益，监护人应依监护诉讼承担责任。

<!-- source-p 048 -->
<a id="37.1.12"></a>**37.1.12**

<!-- source-p 049 -->
**乌尔比安：《告示评注》第四十八卷。**

<!-- source-p 050 -->
<a id="37.1.12.pr."></a>**序言。**毫无疑问，在许多情形中，即使是对抗国库或国家，也应准予某些人取得遗产占有；例如腹中胎儿、精神错乱者，以及请求取得被俘者财产的人。

<!-- source-p 051 -->
<a id="37.1.12.1"></a>**1.**凡法律、元老院决议或皇帝敕令禁止取得遗产的，遗产占有也不予准许。

<!-- source-p 052 -->
<a id="37.1.13"></a>**37.1.13**

<!-- source-p 053 -->
**阿非利加努斯：《疑义集》第五卷。**

<!-- source-p 054 -->
依裁判官告示，因重大罪行被判刑且未获恢复原状的人，不得取得遗产占有。所谓因重大罪行被判刑，是指被判处死刑或被处以水火不容之刑的人。如果某人被判处迁徙流放，则仍准其取得遗产占有。

<!-- source-p 055 -->
<a id="37.1.14"></a>**37.1.14**

<!-- source-p 056 -->
**帕比尼安：《疑义集》第十三卷。**

<!-- source-p 057 -->
某位亲属指控遗嘱为伪造，并在很长一段时间之后证明了指控。虽然他请求遗产占有的期限似乎已经届满——他本应在确定提起指控时请求——但既然他提出指控的目的是保全自己的权利，应当认为他并非无故已经接受了继承。

<!-- source-p 058 -->
<a id="37.1.15"></a>**37.1.15**

<!-- source-p 059 -->
**保罗：《答复集》第十一卷。**

<!-- source-p 060 -->
保罗答复说，母亲单独提出请求，并未使其未适婚年龄的女儿取得遗产占有；除非授予遗产占有的人明确意在将其授予该未适婚年龄者。

<!-- source-p 061 -->
<a id="37.1.16"></a>**37.1.16**

<!-- source-p 062 -->
**保罗：《判决集》第三卷。**

<!-- source-p 063 -->
如果他人为某人请求遗产占有，而该人后来陷入精神错乱，较妥当的意见是，应视其已经追认；因为追认的作用在于确认先前提出的请求。
