# D.37.9 论将胎儿置于遗产占有及其保佐人（*De ventre in possessionem mittendo et curatore eius*）

<!-- source-p 469 -->
<a id="9"></a><a id="37.9"></a>**37.9.0 论将胎儿置于遗产占有及其保佐人**（*De ventre in possessionem mittendo et curatore eius*）。

<!-- source-p 470 -->
<a id="37.9.1"></a>**37.9.1**

<!-- source-p 471 -->
乌尔比安《告示评注》第四十一卷。

<!-- source-p 472 -->
<a id="37.9.1.pr."></a>**序言**　裁判官既关照已经出生的子女，也没有因胎儿尚未出生而忽视他们，因为他们有出生的希望。告示的这一部分通过依照违遗嘱遗产占有的方式，准许孕妇以腹中胎儿名义占有遗产，从而保护了他们。

<!-- source-p 473 -->
<a id="37.9.1.1"></a>**1**　女子必须确实怀孕；仅仅声称自己怀孕并不足够。因此，若她在立遗嘱人死亡时，或在请求准许占有时，并未实际怀孕，则给予她遗产占有不发生效力。

<!-- source-p 474 -->
<a id="37.9.1.2"></a>**2**　只有在胎儿未被剥夺继承权，且其出生后将成为自权继承人时，才准许以胎儿名义占有遗产。若情形不确定，但仍有某种可能使出生的子女成为自权继承人，也应准许孕妇以胎儿名义占有遗产。因为即使有时徒然支出费用，也比拒绝向可能成为遗产所有人的胎儿提供生活给养更为公平。

<!-- source-p 475 -->
<a id="37.9.1.3"></a>**3**　因此，即使剥夺继承权的条款如此写道：“若我生下一个儿子，该子即被剥夺继承权”，由于可能生下女儿、多个儿子，或一儿一女，也应准许孕妇以胎儿名义占有遗产。因为，在胎儿身份尚不确定时，让可能被剥夺继承权的人也得到供养，总比让未被剥夺继承权的人饿死更为可取。即使最后出生的确实是遭排除之人，已经支出的费用也应视为有效支出。

<!-- source-p 476 -->
<a id="37.9.1.4"></a>**4**　若已经取得遗产占有的女子流产，法律规则也相同。

<!-- source-p 477 -->
<a id="37.9.1.5"></a>**5**　若遗腹子女附条件被剥夺继承权，在条件尚未成就时，我们采纳佩狄乌斯的意见，认为可以准许孕妇以胎儿名义占有遗产；因为身份尚不确定时，给予胎儿供养更为妥当。

<!-- source-p 478 -->
<a id="37.9.1.6"></a>**6**　若胎儿被指定继承人剥夺继承权，却被替补继承人遗漏，马尔切鲁斯否认在指定继承人仍在世时可以准许胎儿占有遗产，因为胎儿已被剥夺继承权。此说正确。

<!-- source-p 479 -->
<a id="37.9.1.7"></a>**7**　反之，若胎儿被指定继承人遗漏，却被替补继承人剥夺继承权，则在指定继承人仍在世时，应准许孕妇以胎儿名义占有遗产；若指定继承人已不在世，马尔切鲁斯否认应准许占有，因为继承权已转由胎儿被剥夺继承权的那个顺位取得。

<!-- source-p 480 -->
<a id="37.9.1.8"></a>**8**　若儿子被敌人俘虏，其怀孕的妻子应获准以胎儿名义占有公公的遗产。因为在某种情形下，出生的子女可能成为自权继承人，例如其父亲在敌人手中死亡。

<!-- source-p 481 -->
<a id="37.9.1.9"></a>**9**　若某人剥夺胎儿继承权，写道：“我死后三个月内出生之子，剥夺其继承权”，或“我死后三个月以后出生之子，剥夺其继承权”，仍应准许孕妇以胎儿名义占有遗产，因为在某种情形下，该子女仍可能成为自权继承人。裁判官在此应当给予更为宽厚的保护，免得杀死尚未出生、仍有出生希望的胎儿。

<!-- source-p 482 -->
<a id="37.9.1.10"></a>**10**　裁判官非常正确地没有在告示中提及妻子，因为立遗嘱人死亡时，声称怀有其子女的女子可能并非其妻子。

<!-- source-p 483 -->
<a id="37.9.1.11"></a>**11**　已被解放之子的胎儿也可以取得遗产占有。因此，尤利安在《学说汇纂》第二十七卷提出问题：某人在妻子已怀孕时解放了儿子，随后儿子死亡，其父亲也死亡，是否可以准许胎儿占有已解放父亲的遗产？尤利安极为正确地写道，没有理由拒绝告示所准许的胎儿占有。因为应当公平地保护胎儿利益；胎儿出生后将取得遗产占有。即使祖父仍在世，我们也同样准许胎儿取得遗产占有。

<!-- source-p 484 -->
<a id="37.9.1.12"></a>**12**　儿子被送养后死亡，留下怀孕的妻子；随后养父也死亡。此时应准许胎儿占有养祖父的遗产。至于能否占有将儿子送养之人的遗产，则有待考察。若自然祖父在遗嘱中指定该遗腹孙为继承人，也应准许其占有遗产；因为孙子出生后，若没有其他子女，可以依遗嘱书板取得遗产占有；若还有被遗漏的子女，也可以与他们一同取得违遗嘱的遗产占有。

<!-- source-p 485 -->
<a id="37.9.1.13"></a>**13**　若父亲在儿媳怀孕时解放了儿子，不应一概排除胎儿取得遗产占有；因为依新的告示，出生的子女通常可以与其父亲的家族相连。概括而言，凡出生后可以与父亲建立该关系的情形，均应准许孕妇以胎儿名义占有遗产。

<!-- source-p 486 -->
<a id="37.9.1.14"></a>**14**　若有人否认请求占有之女子是妻子或儿媳，或曾经是妻子或儿媳，或主张她并非怀有其子女，裁判官应仿照卡尔博尼亚告示作出裁定。神圣哈德良皇帝曾敕答裁判官克劳狄乌斯·普罗库鲁斯：应就此事作概括审查；若请求以胎儿名义取得占有的女子显然是在恶意主张，则不应作出新的命令；若事实尚有疑问，则应避免对腹中胎儿作出不利的先决判断，但仍须准许以胎儿名义占有遗产。因此可以看出，除非该女子明显属于恶意主张，否则应由她选择取得裁定；只要确实存在合理疑问，是否怀有该男子的子女就应通过裁定加以保护，以免对胎儿产生不利影响。若女子的身份受到争议，也应作同样处理。

<!-- source-p 487 -->
<a id="37.9.1.15"></a>**15**　概括而言，裁判官通常会基于某些理由给予儿童卡尔博尼亚遗产占有；对于胎儿，我们也毫不怀疑，应在同样理由下给予救济，因为胎儿的情形更值得优先保护。保护胎儿，是为了让其出生；保护儿童，则是为了使其被纳入家族。这个胎儿应当得到养育，因为他出生不仅是为了其被认为是父亲的人，也是为了国家。

<!-- source-p 488 -->
<a id="37.9.1.16"></a>**16**　若某人在第一任妻子怀孕后又娶了另一人，并使第二任妻子也怀孕，随后死亡，则告示足以同时保护两名孕妇，前提是无人提出异议或指称她们恶意主张。

<!-- source-p 489 -->
<a id="37.9.1.17"></a>**17**　准许孕妇以胎儿名义占有遗产时，女子通常会请求为胎儿指定保佐人，也会请求为遗产指定保佐人。但若只为胎儿指定保佐人，则应允许债权人保管遗产财产；若不仅为胎儿，也为遗产财产指定了保佐人，债权人便可以放心，因为风险由保佐人承担。因此，应经审查后为财产指定适任保佐人；债权人或其他期待继承的人也应参与审查。

<!-- source-p 490 -->
<a id="37.9.1.18"></a>**18**　我们遵循的规则是，为胎儿和遗产财产指定同一名保佐人。但若债权人提出请求，或有人期待继承遗产，就应更加谨慎周详地办理；若有需要，也应指定数名保佐人。

<!-- source-p 491 -->
<a id="37.9.1.19"></a>**19**　取得占有的女子，只应从遗产中支取维持胎儿存活并使其出生所必需的费用。应为此指定一名保佐人，根据死者财产状况以及死者和女子的身份地位，为女子提供饮食、衣物和住所。

<!-- source-p 492 -->
<a id="37.9.1.20"></a>**20**　这些费用应首先从现金中扣除；若没有现金，则从那些通常增加遗产支出、却不能增加收益的财产中扣除。

<!-- source-p 493 -->
<a id="37.9.1.21"></a>**21**　若存在财产可能因取得时效而归他人所有，或债务人可能因时效经过而获免责的风险，保佐人也应负责防止此类情况发生。

<!-- source-p 494 -->
<a id="37.9.1.22"></a>**22**　因此，保佐人应依照监护人和未成年人保佐人通常履行的职责管理事务。

<!-- source-p 495 -->
<a id="37.9.1.23"></a>**23**　保佐人可以从下列人员中选任：遗嘱为遗腹子女指定的监护人、近亲或姻亲、替补继承人、死者的朋友或债权人；但无论如何，均须是适任之人。若对上述人员的身份或资格有争议，则应选任公正之人。

<!-- source-p 496 -->
<a id="37.9.1.24"></a>**24**　若尚未指定保佐人——因为通常无人请求，或请求过晚，或指定迟延——塞尔维乌斯说，指定继承人或替补继承人不应封存遗产财产，而只应清点财物并交给女子。

<!-- source-p 497 -->
<a id="37.9.1.25"></a>**25**　塞尔维乌斯还说，对于没有看管便无法妥善保存的财产，例如牲畜，或尚未收割的庄稼和葡萄，应由继承人安排看管人；若对可以支出的数额发生争议，则应指定仲裁人。

<!-- source-p 498 -->
<a id="37.9.1.26"></a>**26**　我认为，指定保佐人后，上述安排均不再适用。不过，继承人在出售财产或制作财产清单时，仍应与保佐人共同记录。

<!-- source-p 499 -->
<a id="37.9.1.27"></a>**27**　准许孕妇以胎儿名义占有遗产，应持续至她分娩、流产，或确定她并未怀孕为止。

<!-- source-p 500 -->
<a id="37.9.1.28"></a>**28**　拉贝奥说，若女子明知自己未怀孕，却仍耗用遗产财产，则该支出应由她自己承担。

<a id="37.9.7.pr."></a>**序言**　凡某人可以依法定继承取得遗产占有之处，也应准许胎儿取得遗产占有；前提是，若腹中胎儿已经出生，他本可以请求遗产占有。因此，在告示的所有部分中，都应将腹中胎儿视为已经出生。

<!-- source-p 521 -->
<a id="37.9.7.1"></a>**1**　有时，只有经过对具体情形的审查，才能准许孕妇以胎儿名义占有遗产；这发生在有人提出争议时。但这仅适用于胎儿与子女一同取得遗产占有的情形。除此之外，若胎儿依据“依合法继承人顺位”或其他依据取得遗产占有，则应认为无需审查具体情形。因为若将争议推迟至胎儿达到适婚年龄时处理，却让他在此期间以他人财产维持生活，并不公平。另一方面，已决定，所有涉及身份争议的问题均应推迟至其达到适婚年龄时处理；但这并非意味着在占有状态下推迟审理身份争议，而是指先不准其占有，待其达到适婚年龄后再审。

<!-- source-p 522 -->
<a id="37.9.7.2"></a>**2**　虽然裁判官会准许胎儿与其他人一同取得遗产占有，但胎儿也可以单独取得遗产占有。
