# D.37.15 论对父母与释奴保护人应尽的敬礼义务（*De obsequiis parentibus et patronis praestandis*）

<!-- source-p 810 -->
<a id="15"></a><a id="37.15"></a>**37.15.0 论对父母与释奴保护人应尽的敬礼义务**（*De obsequiis parentibus et patronis praestandis*）。

<!-- source-p 811 -->
<a id="37.15.1"></a>**37.15.1**

<!-- source-p 812 -->
乌尔比安《意见集》第一卷。

<!-- source-p 813 -->
<a id="37.15.1.pr."></a>**序言**　即使是军人，也必须对父母保持孝敬之理。因此，若军人之子对父亲实施了某种不法行为，应按照其过错的程度予以惩处。

<!-- source-p 814 -->
<a id="37.15.1.1"></a>**1**　在共同被释奴之间，母亲与儿子之间依自然法则应有的孝敬之理，也必须保持完整。

<!-- source-p 815 -->
<a id="37.15.1.2"></a>**2**　若儿子以侮辱言辞对待其应予敬重的母亲或父亲，或对他们动手，城市长官应按照情节轻重惩处该项侵害公共孝敬秩序的违法行为。

<!-- source-p 816 -->
<a id="37.15.1.3"></a>**3**　若有人称其父母——他自己声称是由父母养育成人的——为恶人，应被判定为不配服兵役。

<!-- source-p 817 -->
<a id="37.15.2"></a>**37.15.2**

<!-- source-p 818 -->
尤利安《学说汇纂》第十四卷。

<!-- source-p 819 -->
<a id="37.15.2.pr."></a>**序言**　应当尊敬父母与释奴保护人；因此，即便他们经由代理人接受诉讼，也不得对他们提起欺诈之诉或侵辱之诉。虽然依告示的文字，因这些诉讼而被判决者并不被视为名誉受损者，但事实上，依人们的看法，他们仍无法摆脱名誉受损的污名。

<!-- source-p 820 -->
<a id="37.15.2.1"></a>**1**　对他们也不得发布 *unde vi* 禁令。

<!-- source-p 821 -->
<a id="37.15.3"></a>**37.15.3**

<!-- source-p 822 -->
马尔切卢斯《答复集》单卷。

<!-- source-p 823 -->
提丢斯买了一个男孩；多年以后，他命人将该男孩出卖。后来，他经男孩恳求，在收取男孩交付的价款后，将其释为自由人。我问：释奴保护人的儿子及继承人能否以忘恩为由控告该被释奴？答复说：若无其他妨碍，可以控告。因为，若有人在收取钱款后，释放自己的奴隶，或其朋友的奴隶，与释放一个原属他人、后来托付给自己照管的奴隶，大有区别。前一种情形，即便并非无偿，仍然给予了恩惠；后一种情形，则似乎不过是出借自己的劳务。

<!-- source-p 824 -->
<a id="37.15.4"></a>**37.15.4**

<!-- source-p 825 -->
马尔基安《公诉》第二卷。

<!-- source-p 826 -->
神圣塞维鲁与安东尼努斯皇帝曾以敕答确认：可以通过代理人控告忘恩的被释奴。

<!-- source-p 827 -->
<a id="37.15.5"></a>**37.15.5**

<!-- source-p 828 -->
乌尔比安《告示评注》第十卷。

<!-- source-p 829 -->
<a id="37.15.5.pr."></a>**序言**　父母、释奴保护人或女保护人、他们的子女，或者释奴保护人或女保护人的父母，即使被指称曾为实施或不实施某项事务而收受钱款，也不因事实诉讼而承担责任。

<!-- source-p 830 -->
<a id="37.15.5.1"></a>**1**　对他们既不准许提起导致名誉受损的诉讼，甚至也不准许提起提及欺诈或诈害的诉讼，

<!-- source-p 831 -->
<a id="37.15.6"></a>**37.15.6**

<!-- source-p 832 -->
保罗《告示评注》第十一卷。

<!-- source-p 833 -->
也不得提起诱坏奴隶之诉，

<!-- source-p 834 -->
<a id="37.15.7"></a>**37.15.7**

<!-- source-p 835 -->
乌尔比安《告示评注》第十卷。

<!-- source-p 836 -->
<a id="37.15.7.pr."></a>**序言**　尽管这些诉讼并不导致名誉受损，

<!-- source-p 837 -->
<a id="37.15.7.1"></a>**1**　他们仍仅在其有能力清偿的范围内被判承担责任。

<!-- source-p 838 -->
<a id="37.15.7.2"></a>**2**　他们不承受欺诈抗辩、基于暴力或胁迫的抗辩，也不承受 *unde vi* 或 *quod vi* 禁令的追究。

<!-- source-p 839 -->
<a id="37.15.7.3"></a>**3**　即使提出诬诉之誓，他们也不须宣誓。

<!-- source-p 840 -->
<a id="37.15.7.4"></a>**4**　此外，若有人声称女释奴保护人以腹中胎儿为由、出于恶意而被准许占有遗产，释奴提出这一说法也不会被采纳，因为不应审查释奴保护人是否恶意。告示的其他部分也同样尊重这些身份之人。

<!-- source-p 841 -->
<a id="37.15.7.5"></a>**5**　这种尊重仅给予这些本人，而不延及其代理人；但若他们本人为他人出面，则仍享有这种尊重。

<!-- source-p 842 -->
<a id="37.15.8"></a>**37.15.8**

<!-- source-p 843 -->
保罗《告示评注》第十卷。

<!-- source-p 844 -->
释奴的继承人针对已故释奴保护人，享有外人所享的一切完整权利。

<!-- source-p 845 -->
<a id="37.15.9"></a>**37.15.9**

<!-- source-p 846 -->
乌尔比安《告示评注》第六十六卷。

<!-- source-p 847 -->
对于被释奴及其儿子而言，应当始终将父亲与释奴保护人视为高尚而神圣之人。

<!-- source-p 848 -->
<a id="37.15.10"></a>**37.15.10**

<!-- source-p 849 -->
特里丰尼努斯《论辩集》第十七卷。

<!-- source-p 850 -->
对于被置于 *mancipium* 下的儿子，不发生因自由人身份而施加的权利或负担，因为通常不会对子女施加此类负担。也没有人说过，儿子应依誓言像被释奴对释奴保护人那样对作为解放者的父亲承担义务；子女对父母负有孝敬之义，而不负有劳务义务。

<!-- source-p 851 -->
<a id="37.15.11"></a>**37.15.11**

<!-- source-p 852 -->
帕比尼安《答复集》第十三卷。

<!-- source-p 853 -->
女被释奴仅因违背女释奴保护人的意愿而从事自己的技艺，并不构成忘恩。
