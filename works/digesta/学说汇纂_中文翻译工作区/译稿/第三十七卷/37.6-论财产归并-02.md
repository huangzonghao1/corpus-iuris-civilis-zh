# D.37.6 论财产归并（*De collatione bonorum*，第二段）

> **底本范围：**依 d-37.htm source-p 341–367 翻译；保留原有段落、锚点、题名及出处。

<!-- source-p 341 -->
<a id="37.6.2"></a>**37.6.2**

<!-- source-p 342 -->
保罗《告示评注》第四十一卷。

<!-- source-p 343 -->
<a id="37.6.2.pr."></a>**序言。**我们既然认为，解放出父权的儿子所生的遗腹孙子在祖父死后出生，仍应取得遗产占有，那么就必须说，即使他在祖父死亡时尚未存在于世，也须归并自己的财产。因而，无论他是从父亲处取得继承，还是取得遗赠，都必须将其归并。

<!-- source-p 344 -->
<a id="37.6.2.1"></a>**1.**应当理解，儿子的财产是扣除债务后剩余的部分。但若他所负债务附有条件，不应立即扣除；该债务也必须归并。反过来，处于父权之下的人应向他提供担保：条件成就时，将按他已归并的份额为其提供抗辩保护。

<!-- source-p 345 -->
<a id="37.6.2.2"></a>**2.**解放出父权的儿子在父亲死亡后无过错而灭失的财产，应由谁承担损失，这一点存在疑问。许多人认为，未因故意或过失而灭失的财产，不计入财产归并负担。这应从裁判官命令按善良人判断归并财产的文字中理解：善良人不会认为应归并本人既不拥有、也非因故意或过失而丧失的财物。

<!-- source-p 346 -->
<a id="37.6.2.3"></a>**3.**解放出父权的儿子依要式承诺负有附条件债务，该债务也应归并。附条件遗赠则不同：即使他仍处于父权之下，而条件在父亲死亡后成就，他本人仍可取得该项请求权。

<!-- source-p 347 -->
<a id="37.6.2.4"></a>**4.**解放出父权的儿子若享有侮辱之诉，无须归并该诉权，因为该请求主要是为惩罚而非为取得金钱。但若他享有盗窃之诉，就必须归并。

<!-- source-p 348 -->
<a id="37.6.2.5"></a>**5.**若有三名解放出父权的儿子、两名仍处于父权之下的儿子，盖尤斯·卡西乌斯在《市民法》第七卷认为应按三分之一份额归并；解放者彼此不归并，因此应视为一人。他们不应抱怨自己归并较多、取得较少，因为是否请求遗产占有由他们自行决定。尤利安也赞同卡西乌斯的见解。

<!-- source-p 349 -->
<a id="37.6.2.6"></a>**6.**若解放出父权的儿子所生的孙子，在父亲与祖父均死亡后取得两人的遗产占有，且两人都留下了自权继承人，可以如此说明财产归并：例如该孙子拥有一百财产，就应向叔父归并五十，向兄弟归并五十。无论按人数还是按份额计算，结果均如此。

<!-- source-p 350 -->
<a id="37.6.2.7"></a>**7.**若已故儿子所生的两名解放出父权的孙子请求取得祖父遗产占有，问题在于，他们应向叔父归并二分之一还是四分之一。更正确的见解是，他们应各自归并二分之一；因为若他们在祖父仍在世且自己尚处于祖父父权之下时取得二百，祖父去世后，其中一百应由其父亲取得，另一百由兄弟二人继承。

<!-- source-p 351 -->
<a id="37.6.2.8"></a>**8.**若两名解放出父权的儿子请求遗产占有，其中一人归并财产，另一人没有归并，那么该归并只应使处于父权之下的人受益，而不能使另一名解放者受益；因为诉权是为了仍处于父权之下者的利益而对未归并者予以拒绝。

<!-- source-p 352 -->
<a id="37.6.2.9"></a>**9.**若解放出父权的儿子因贫困而无力提供担保，不应立即将遗产占有转给他人；应等待至他能够找到保证人。但对于因迟延而将恶化的财物，应准许处于父权之下的人提起诉讼；他们也应提供担保，保证在他人已为其提供保障时，将来会把财产归并入共同财产。

<!-- source-p 353 -->
<a id="37.6.3"></a>**37.6.3**

<!-- source-p 354 -->
尤利安《学说汇纂》第二十三卷。

<!-- source-p 355 -->
<a id="37.6.3.pr."></a>**序言。**裁判官并非以财产归并为条件授予违遗嘱的遗产占有，而是说明取得遗产占有后应当如何处理。否则，若解放出父权的儿子必须先为财产归并提供担保才被视为取得遗产占有，就会遭受重大损失：假如他在此期间死亡，便不能给自己的继承人留下任何利益；又假如他的兄弟死亡，他也不得请求遗产占有。实际规则是：他可以在提供担保之前取得遗产占有；但如果他未提供担保，整个遗产仍应归处于父权之下的人所有。

<!-- source-p 356 -->
<a id="37.6.3.1"></a>**1.**解放出父权的儿子对一名未适婚年龄者提出争议；后者主张自己是父亲的儿子，且曾处于父权之下。我询问，解放者是否应向他归并自己的财产。保罗批注说：我认为应当归并，但须先提供担保；若其主张未获支持，就应返还其取得的遗产以及已经归并的财物。

<!-- source-p 357 -->
<a id="37.6.3.2"></a>**2.**尤利安说：凡授予违遗嘱的遗产占有，解放出父权的儿子都应只向仍处于父亲权力之下的人归并自己的财产。通常会有人问，应如何落实这一点：如果把父亲留下的财产与解放者的财产全部放在一起，再平均分配，那么解放者之间相互归并也会使他们自己受益。由此可见，最便利的做法是：解放者从父亲的财产中各取得四分之一，并从自己的财产中归并三分之一。举例说明：假设父亲留下四百，有两名儿子仍处于父权之下，另有两名解放者；其中一人的财产为一百，另一人为六十。拥有一百财产者最终可取得一百三十三又三分之一；拥有六十者可取得一百二十。这样，财产归并的利益就只归于仍处于父权之下的人。

<!-- source-p 358 -->
<a id="37.6.3.3"></a>**3.**解放出父权的儿子必须向仍处于父权之下的人归并自己的财产。

<!-- source-p 359 -->
<a id="37.6.3.4"></a>**4.**因此，正如仍处于父权之下的人可以先行取得其妻子的嫁资，解放出父权的儿子也应视为先行取得，而保留自己的嫁资。

<!-- source-p 360 -->
<a id="37.6.3.5"></a>**5.**被遗漏的解放出父权的儿子在考虑是否接受时，已就归并财产提供担保，之后却未请求遗产占有；若其兄弟依据要式承诺提起诉讼，他依法应受到保护。若他已经交付钱款，也可以通过返还之诉追回；因为他放弃遗产占有后，继承人便无正当根据继续持有该笔钱款。

<!-- source-p 361 -->
<a id="37.6.3.6"></a>**6.**某人有两名儿子处于父权之下，并有一名孙子为另一儿子所生。他解放了这个儿子的父权；该儿子后来生了一个儿子，祖父又将其收养为自己儿子的继承人。祖父随后无遗嘱死亡，或虽立遗嘱却遗漏了已解放出父权的儿子。有人询问应如何处理遗产占有及财产归并。答复说，应将相关财产分成三份：一份归仍处于父权之下的儿子；一份归被收养为儿子继承人的孙子；另一份归已解放出父权的儿子及仍处于父权之下的孙子。父亲只须向与其一同取得遗产占有的人归并财产。

<!-- source-p 362 -->
<a id="37.6.4"></a>**37.6.4**

<!-- source-p 363 -->
阿非利卡努斯《疑问集》第四卷。

<!-- source-p 364 -->
已解放出父权的儿子为其女儿的名义给付嫁资，不必将该嫁资归并；因为嫁资应视为妻子财产的一部分，却不因此成为给付嫁资的父亲的财产。

<!-- source-p 365 -->
<a id="37.6.5"></a>**37.6.5**

<!-- source-p 366 -->
乌尔比安《告示评注》第七十九卷。

<!-- source-p 367 -->
<a id="37.6.5.pr."></a>**序言。**某人有一名自权儿子，该儿子所生的孙子仍处于其父权之下。如果孙子取得已被解放出父权的父亲的遗产占有，就应当说，孙子也必须为归并自己的财产提供担保；其情形与被收养者相同。神圣的两位兄弟皇帝曾作敕答，命令祖父承担财产归并义务。敕答接着规定：“但若该祖父不愿从这些财产中取得任何孳息，并且准备将孙子解放出父权，使遗产占有的全部利益归于已经解放出父权的人，那么另当别论。不得因此认为，在解放之后出生并成为父亲继承人的女儿有正当理由抱怨，说她因此被排除在财产归并利益之外；因为祖父日后死亡时，她仍可与兄弟一同继承其遗产。”这项理由不能适用于养父；但即使在养父情形中，只要其解放养子并非出于恶意，也应作相同处理。
