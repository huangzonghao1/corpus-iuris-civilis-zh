# D.37.8　论已解放出家父权者与其子女共同取得遗产占有（*De coniungendis cum emancipato liberis eius*）

> **底本范围：**依 d-37.htm source-p 430–468 翻译，共39个源段落；保留原段落顺序、锚点、出处及份额结构。

<!-- source-p 430 -->
<a id="8"></a><a id="37.8"></a>**37.8.0　论已解放出家父权者与其子女共同取得遗产占有**（*De coniungendis cum emancipato liberis eius*）。

<!-- source-p 431 -->
<a id="37.8.1"></a>**37.8.1**

<!-- source-p 432 -->
乌尔比安《告示评注》第四十卷。

<!-- source-p 433 -->
<a id="37.8.1.pr."></a>**序言**　对于裁判官承诺给予遗产占有的人，若其在父亲死亡时已不再处于父权之下，且其子女仍与他同属一个家族；只要继承权依法归属于他们本人，且他们并未因遗嘱中的排除继承声明而丧失资格，就应将其本可在继续处于父权下时取得的那一份遗产占有给予他及其子女。该份额一半归他，另一半归其子女；他只须向这些子女归并自己的财产。

<!-- source-p 434 -->
<a id="37.8.1.1"></a>**1.**这项告示极为公平：既不让已解放者单独继承并排除仍处于家父权下的孙辈，也不让孙辈仅以权力关系为由排斥自己的父亲。

<!-- source-p 435 -->
<a id="37.8.1.2"></a>**2.**被送养并被指定为继承人的儿子，也适用该告示；因此，与其有亲属关系且仍处于其本生祖父权力下的孙子，应与他共同取得遗产占有。孙子应与已解放出家父权的父亲共同取得遗产占有，无论该父亲被遗漏还是被指定为继承人。被送养之人与已解放之人之间的区别在于：前者只有在被指定为继承人、且另一人触发告示适用时，孙子才与其共同取得遗产占有；后者则无论被指定为继承人还是被遗漏，孙子均可与之共同取得遗产占有。

<!-- source-p 436 -->
<a id="37.8.1.3"></a>**3.**若仍处于父权下的儿子被指定为继承人，取得遗产十二分之八；已解放的儿子被指定为继承人，取得十二分之四；尤利安说，若被遗漏的孙子请求违遗嘱的遗产占有，他将从其叔父处取得六分之一，从其父亲处取得十二分之一。

<!-- source-p 437 -->
<a id="37.8.1.4"></a>**4.**若父亲已被解放出家父权并被排除继承，而其子女仍处于祖父权下并在遗嘱中被遗漏，则这些孙辈应获准取得遗产占有。毕竟，若父亲被遗漏，他们尚且能与其共同取得遗产占有；若父亲被指定为继承人或被排除继承，却不准他们取得遗产占有，显然荒谬。

<!-- source-p 438 -->
<a id="37.8.1.5"></a>**5.**若仍处于家父权下的孙辈之叔父被遗漏，而他们的父亲被排除继承，孙辈也应获准取得遗产占有；因为其被排除继承的父亲应视为已经死亡。

<!-- source-p 439 -->
<a id="37.8.1.6"></a>**6.**斯凯沃拉说，若父亲仍处于家父权下，无论他被排除继承还是被指定为继承人，其子女——无论仍处于家父权下还是已解放出家父权——均不得也不应被召入祖父遗产。只有在父亲已解放出家父权时，才有必要保护孙子的利益。因此，子女必须仍在请求遗产占有之人的家族中，也就是仍属于被请求遗产占有者的家族。若已解放出家父权者在解放前受孕的遗腹子出生，也应作同样处理。

<!-- source-p 440 -->
<a id="37.8.1.7"></a>**7.**裁判官并非同时召集所有子女，而是按顺序召集：首先是自权继承人，即孙辈；若无孙辈，再召集更低辈分者；各辈分不得混合计算。当然，若已解放者有一名孙子，而该孙子另有一名曾孙，则两人均应与已解放者共同取得遗产占有，因为两人都继承了自权继承人的地位。

<!-- source-p 441 -->
<a id="37.8.1.8"></a>**8.**若孙子依归来权从敌人处返回，应认定他可与已解放出家父权的父亲共同取得遗产占有。

<!-- source-p 442 -->
<a id="37.8.1.9"></a>**9.**某人有两名处于家父权下的儿子；他解放其中一人出家父权，却将该儿子所生的孙子收养为自己的儿子；之后他遗漏已解放的儿子而死亡。尤利安说，应救济被收养为儿子的孙子，使其如同儿子一样取得份额；即使该孙子是由外部人收养，也应如此。因此，仍处于家父权下的儿子取得三分之一；被收养为儿子的孙子取得另一三分之一；剩余三分之一由已解放的儿子与另一名仍处于家父权下的孙子分享。尤利安说，被收养为儿子的孙子所得，不应少于由外部人收养时本可取得的份额。

<!-- source-p 443 -->
<a id="37.8.1.10"></a>**10.**孙子取得的份额具体有多大，并不重要，即使该份额极小也一样；因为即便份额很小，也应认为本告示的这一部分适用。

<!-- source-p 444 -->
<a id="37.8.1.11"></a>**11.**儿子与其子女之间应这样分割遗产：儿子取得一半，子女取得另一半。因此，假设只有一名已解放出家父权的儿子，另有两名仍处于家父权下的孙子，再无其他子女；已解放者取得遗产一半，两名孙子取得另一半，各得四分之一。若另有一名儿子，则没有子女的那名儿子取得遗产一半；另一名儿子与其子女分享另一半，儿子本人取得四分之一，另一四分之一由其子女分配。若两名儿子均已解放出家父权，且各自有子女，则每人都与自己的子女分享各自的一半遗产：父亲各得遗产四分之一，其子女分得剩余的四分之一。若一人有两名子女，另一人有三名子女，则一份四分之一由前者的两名子女分配，另一份四分之一由后者的三名子女分配。

<!-- source-p 445 -->
<a id="37.8.1.12"></a>**12.**若某一孙辈放弃自己的份额，该份额归其兄弟，而非其父亲。若所有孙辈均放弃，则该份额不增加叔父的份额，而仅归其父亲；若其父亲也放弃，该份额才增加叔父的份额。

<!-- source-p 446 -->
<a id="37.8.1.13"></a>**13.**若已解放出家父权的儿子没有仍处于祖父权下的孙子，他应向自己的兄弟归并财产；但若有孙子，裁判官希望他仅向仍处于家父权下的自己的子女归并。这是正确的，因为他请求取得遗产占有时，只损害这些子女的利益。

<!-- source-p 447 -->
<a id="37.8.1.14"></a>**14.**现在来看，他应向这些子女归并多少。通常，已解放者与其兄弟进行归并时，应先为自己扣除一个男性份额。此处是否也应扣除一个男性份额，还是因为他取得了遗产占有的一半，故应将其全部财产的一半归并？我认为，他只须向子女归并其财产的一半。因为若一名儿子已解放出家父权，另一名儿子仍处于家父权下，已解放者仅向那两名孙子归并一份，向其仍处于家父权下的兄弟（即孙子的叔父）给付一份，自己保留三分之一。并且，已解放的叔父归并给孙子的那部分，孙子无须再向自己的父亲归并；因为该部分并非来自祖父遗产，而是之后因相关财产关系归于他们。

<!-- source-p 448 -->
<a id="37.8.1.15"></a>**15.**因此，若已解放的父亲有一百财产，他应先为自己扣除五十，剩余五十归并给所有孙辈，也就是他的儿子们；或者，若他有一名孙子，另有两名由其他孙辈所生的曾孙，则应将五十分为两部分：孙子取得二十五，另一支系的两名曾孙合计取得二十五。因为在遗产占有中，双方各得一份。

<!-- source-p 449 -->
<a id="37.8.1.16"></a>**16.**若一名儿子仍处于家父权下，另一名儿子已解放出家父权；死者留下两名孙辈，一人仍处于家父权下，另一人已解放出家父权，斯凯沃拉精辟地讨论了已解放的叔父应向孙辈及其兄弟归并多少。他说，可以认为应分成三份：一份给自己，一份给兄弟，一份归并给孙辈。虽然这些孙辈因父亲仍在世而从祖父遗产中取得的份额，少于已解放的叔父所得，但此说正确。

<!-- source-p 450 -->
<a id="37.8.1.17"></a>**17.**若同一儿子有两名孙子，二人均已解放出家父权，而其中一人又有一名曾孙仍处于死者家父权下，则一名孙子取得一份，另一名孙子与其儿子共同取得另一份。又如有一名孙子，另一名已死亡的孙子留下两名曾孙；若其中一名曾孙已解放出家父权，他只须向自己的兄弟归并；若没有兄弟，则只向其叔父归并，而不向其曾叔父归并。

<!-- source-p 451 -->
<a id="37.8.2"></a>**37.8.2**

<!-- source-p 452 -->
保罗《告示评注》第四十一卷。

<!-- source-p 453 -->

<!-- source-p 454 -->
<a id="37.8.3"></a>**37.8.3**

<!-- source-p 455 -->
马尔凯鲁斯《学说汇纂》第九卷。

<!-- source-p 456 -->
某人有两个儿子，将其中一人解放出家父权，却让该儿子所生的孙子继续处于自己家父权下；已解放的儿子后来生子，又被父亲排除继承。我问：其兄弟（该兄弟本人也已解放出家父权且在遗嘱中被遗漏）也被遗漏，而已解放儿子所生的孙辈由祖父指定为继承人时，遗产占有应如何处理？若也假设孙辈之父——即被解放出家父权者——被遗漏，结论又有何不同？答复说，若某人解放儿子出家父权，却将该儿子所生的孙子留在自己权力下；其后该已解放儿子生子，祖父指定两名孙辈为继承人，而将他们的父亲排除继承、遗漏另一儿子，则只有被遗漏的儿子可以请求违遗嘱的遗产占有；被排除继承的父亲会妨碍其解放后所生子女提出请求。不过，留在祖父权下的孙子仍应取得遗产占有；因为若其父亲已解放出家父权并被遗漏，孙子本可依据尤利安引入告示的新条款，与父亲一同取得遗产占有。他不应仅因父亲被排除继承而处于更不利地位；即便孙子本人也被遗漏，也应给予同样保护。但其在解放后出生的兄弟地位不同；不过，仍应为该兄弟保留其男性份额，正如安敦尼努斯皇帝曾就女儿所生的孙子作出的敕答。

<!-- source-p 462 -->
若被排除继承的孙子成为祖父指定继承人的继承人，之后其已解放出家父权的父亲在祖父遗嘱中被遗漏，并请求违遗嘱的遗产占有，则该孙子不得与父亲共同取得遗产占有，而应如同外部人一样被排除；因为他并非以自己的名义成为祖父的继承人。

<!-- source-p 465 -->
若某人有一个仍处于家父权下的儿子，却收养一名外部人为孙子，仿佛该外部人是由该儿子所生；之后又解放儿子出家父权，则该孙子不得与已解放的儿子共同取得遗产占有，因为他已不再是该已解放者的子女。

<!-- source-p 466 -->
<a id="37.8.7"></a>**37.8.7**

<!-- source-p 467 -->
特里丰尼努斯《论辩集》第十六卷。

<!-- source-p 468 -->
若孙子在其父亲解放出家父权后出生，应为他保留遗产份额；但究竟应保留多少？假设祖父以遗嘱指定叔父为继承人，并指定该孙子为共同继承人；该孙子的父亲则被遗漏，并取得违遗嘱的遗产占有。依裁判官告示，本应将遗产分为两个二分之一；但神圣的庇乌斯皇帝作出敕令，要求为孙子保留一份后，究竟应保留男性份额还是四分之一？若孙子在祖父仍行使家父权时出生，他本应与父亲合并为一份。再假设同一孙子的另一名兄弟仍留在祖父家族中：若其父亲取得违遗嘱遗产占有，两兄弟原本会共同取得四分之一；那么现在是否应为未留在祖父家族中的孙子保留十二分之一又二分之一（即八分之一）？这项份额若归于该孙子，应从谁的份额中扣除——仅从其父亲，还是也从其叔父？我认为也应从叔父份额中扣除；因为叔父也应履行遗赠给该孙子的遗赠。
