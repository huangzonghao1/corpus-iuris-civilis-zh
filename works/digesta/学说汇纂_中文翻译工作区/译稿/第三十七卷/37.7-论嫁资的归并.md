# D.37.7　论嫁资的归并（*De dotis collatione*）

> **底本范围：**依 d-37.htm source-p 392–429 翻译，共38个源段落。此处 *collatio dotis* 译为“嫁资归并”，与一般遗产归并相区别。

<!-- source-p 392 -->
<a id="7"></a><a id="37.7"></a>**37.7.0　论嫁资的归并**（*De dotis collatione*）。

<!-- source-p 393 -->
<a id="37.7.1"></a>**37.7.1**

<!-- source-p 394 -->
乌尔比安《告示评注》第四十卷。

<!-- source-p 395 -->
<a id="37.7.1.pr."></a>**序言**　裁判官原则上只有在女儿请求遗产占有时，才强制其归并嫁资；但即使她没有提出该请求，只要她介入父亲遗产，也仍应归并。神圣的庇乌斯皇帝在致乌尔比乌斯·哈德里安努斯的敕答中规定，即使女儿没有请求遗产占有，也可由遗产分割之诉的裁判官强制她归并嫁资。

<!-- source-p 396 -->
<a id="37.7.1.1"></a>**1.**若嫁资已通过要式口约约定，若口约由妇女本人订立，或该交易是为她办理，则她同样必须归并；若该要式口约是为他人取得的，则应认为无须归并。即使嫁资只是被允诺，也应将其纳入归并。

<!-- source-p 397 -->
<a id="37.7.1.2"></a>**2.**若同一儿子有一名孙子和一名孙女，且孙女已有嫁资；同时另有一名并非该两人之父的儿子，则孙女应仅向其兄弟归并全部嫁资。若孙女已脱离家父权，她应仅向该孙子归并嫁资及自己的财产，而无须向其叔父归并。

<!-- source-p 398 -->
<a id="37.7.1.3"></a>**3.**但若只有孙女、没有同一儿子所生的孙子，则应向叔父归并；也应向其他儿子所生的孙子或孙女归并。

<!-- source-p 399 -->
<a id="37.7.1.4"></a>**4.**若有两名孙女，分别出自不同儿子，她们应彼此归并，也应向叔父归并；若两人出自同一父亲，则仅彼此归并。

<!-- source-p 400 -->
<a id="37.7.1.5"></a>**5.**归并嫁资时，应扣除必要费用，不扣除其他费用。

<!-- source-p 401 -->
<a id="37.7.1.6"></a>**6.**若婚姻已经解除，而丈夫无清偿能力，则不得将全部嫁资计入妇女所得；应仅计入她可能从丈夫处实际取得的数额，也就是丈夫有能力给付的数额。

<!-- source-p 402 -->
<a id="37.7.1.7"></a>**7.**若父亲或第三人附条件允诺提供嫁资，则须提供担保，使妇女仅在实际取得嫁资时才进行归并。

<!-- source-p 403 -->
<a id="37.7.1.8"></a>**8.**女儿依法成为父亲无遗嘱继承人时，应当归并嫁资；相应地，她应依据嫁资允诺，解除其兄弟所负一半义务。这样更公平，因为嫁资应当全部视为由她自己的财产提供。

<!-- source-p 404 -->
<a id="37.7.1.9"></a>**9.**若已解放的儿子请求并取得违遗嘱的遗产占有，而他有一名已获嫁资的女儿，则无须由他归并该女儿的嫁资，因为该嫁资不属于他的财产。

<!-- source-p 405 -->
<a id="37.7.2"></a>**37.7.2**

<!-- source-p 406 -->
盖尤斯《行省告示评注》第十四卷。

<!-- source-p 407 -->
被送养的女儿若被指定为继承人，应如同已解放出家父权的女儿一样，不仅归并自己的财产，也归并可能归她所有的嫁资。若养父仍在世，则应由养父进行归并。

<!-- source-p 408 -->
<a id="37.7.3"></a>**37.7.3**

<!-- source-p 409 -->
乌尔比安《论辩集》第四卷。〔底本书名处作 *quatro*，疑为拼写异文。〕

<!-- source-p 410 -->
若女儿被指定为继承人，她无须履行嫁资归并义务。因此，若另一项告示适用后，她不得不请求违遗嘱的遗产占有，应认为她并未损害其兄弟，无须归并嫁资；因为她依据遗嘱所取得的利益转化为违遗嘱的遗产占有。反之，若她仅按较小份额被指定为继承人，之后又因某些财产归于她而取得违遗嘱遗产占有，且其份额因此增加，则应认为她须履行归并义务；除非她满足于遗嘱指定给她的份额。在后一情形，应认为她依据父母遗嘱取得继承权，不应承担归并义务。

<!-- source-p 411 -->
<a id="37.7.4"></a>**37.7.4**

<!-- source-p 412 -->
庞波尼乌斯《昆图斯·穆基乌斯评注》第三卷。

<!-- source-p 413 -->
若父亲为女儿允诺嫁资，之后又将遗赠给被排除继承权、或已解放出家父权并在遗嘱中被遗漏的女儿，则该女儿还可先行取得嫁资，并取得遗赠。

<!-- source-p 414 -->
<a id="37.7.5"></a>**37.7.5**

<!-- source-p 415 -->
帕比尼安《答复集》第五卷。

<!-- source-p 416 -->
<a id="37.7.5.pr."></a>**序言**　已解放出家父权、原本可以请求违遗嘱遗产占有的儿子，却请求并取得了父亲无遗嘱继承的遗产占有。女儿仍处于家父权下，并与同一家族的兄弟一同被指定为继承人；她因跟随已解放兄弟的错误，也请求并取得父亲无遗嘱继承的遗产占有。她无须向遗嘱指定的兄弟归并嫁资，因为该项遗产占有请求并未产生效力；女儿仍依父亲的遗嘱取得男性份额。换言之，所有人各取得三分之一，并将“依子女身份”请求遗产占有视为已经请求违遗嘱遗产占有。〔“fini virilis partis”一语及本段末句关系较为晦涩，译文暂依上下文处理。〕

<!-- source-p 417 -->
<a id="37.7.5.1"></a>**1.**若婚姻解除后女儿应归并嫁资，却迟延归并，则应由善良公正之人酌定，强制她一并归并嫁资利息；因为已解放出家父权的兄弟也须归并孳息，而女儿则取得其份额的孳息。

<!-- source-p 418 -->
<a id="37.7.6"></a>**37.7.6**

<!-- source-p 419 -->
帕比尼安《答复集》第六卷。

<!-- source-p 420 -->
父亲指定已解放出家父权的儿子为继承人，并排除女儿继承。女儿以遗嘱不孝之诉取得遗产的一半。我答复说，不得强迫兄弟归并其自己的财产；因为奴隶解放处分也应得到履行。〔底本本段以冒号结束，似有省略；“libertates competere”所指仍待核。〕

<!-- source-p 421 -->
<a id="37.7.7"></a>**37.7.7**

<!-- source-p 422 -->
保罗《答复集》第十一卷。

<!-- source-p 423 -->
她本人也无须向兄弟归并嫁资，因为兄弟基于不同的法律地位成为继承人。

<!-- source-p 424 -->
<a id="37.7.8"></a>**37.7.8**

<!-- source-p 425 -->
帕比尼安《答复集》第十一卷。

<!-- source-p 426 -->
父亲在女儿结婚时，除嫁资外还给了她若干物品，并让她留在家族中；同时有条件地将女儿指定为兄弟的共同继承人，条件是她归并嫁资及其他为其婚姻交付的财物。女儿放弃继承后，兄弟请求返还未作为嫁资交付的物品；应以恶意抗辩阻却其请求，因为父亲希望女儿在两者中取得其一。

<!-- source-p 427 -->
<a id="37.7.9"></a>**37.7.9**

<!-- source-p 428 -->
特里丰尼努斯《论辩集》第六卷。

<!-- source-p 429 -->
问题是：女儿作为父亲的必然继承人，与兄弟一同继承；若她满足于嫁资并放弃遗产，是否仍应被强制归并嫁资？神圣的马尔库斯皇帝以敕答规定，放弃父亲遗产的人不得被强制归并。因此，不仅已交付的嫁资仍留在丈夫处，允诺给付的嫁资也可向兄弟请求；该允诺应作为债务处理，因为该项嫁资已从父亲的财产中脱离。
