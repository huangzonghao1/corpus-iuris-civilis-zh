# D.37.4《论违遗嘱的遗产占有》（*De bonorum possessione contra tabulas*；source-p 075–202）

<!-- source-p 075 -->
<a id="4"></a><a id="37.4"></a>**37.4.0 论违遗嘱的遗产占有**（*De bonorum possessione contra tabulas*）

<!-- source-p 076 -->
<a id="37.4.1"></a>**37.4.1**

<!-- source-p 077 -->
**乌尔比安：《告示评注》第三十九卷。**

<!-- source-p 078 -->
<a id="37.4.1.pr."></a>**序言。**在违遗嘱的遗产占有中，“子女”包括自然子女和收养子女，只要他们既未被指定为继承人，也未被排除继承。

<!-- source-p 079 -->
<a id="37.4.1.1"></a>**1.**子女依照市民法继承的权利和顺位，被召入违遗嘱的遗产占有。

<!-- source-p 080 -->
<a id="37.4.1.2"></a>**2.**这一条款似乎也适用于遗腹子。

<!-- source-p 081 -->
<a id="37.4.1.3"></a>**3.**庞波尼乌斯认为，如果儿子从敌方依返还权归来，也应准许其取得违遗嘱的遗产占有。

<!-- source-p 082 -->
<a id="37.4.1.4"></a>**4.**如果三名儿子中有一人被敌方俘获，留在本国的两人有权取得遗产的三分之二。

<!-- source-p 083 -->
<a id="37.4.1.5"></a>**5.**遗腹子也适用同一规则：只要仍有希望其出生，他就处于能够取得份额的地位。

<!-- source-p 084 -->
<a id="37.4.1.6"></a>**6.**裁判官还会将已成为自权人的子女纳入遗产占有（因此，无论是被解放，还是以其他方式脱离父亲的权力，均准其取得遗产占有）；但养父的收养子女不得如此请求。要获准取得遗产占有，该人必须属于自然子女。

<!-- source-p 085 -->
<a id="37.4.1.7"></a>**7.**某人有一子，以及该子所生的一名孙子；他解放了儿子，又将一人收养以替代孙子，随后又将其解放。问题是，这是否妨碍孙子取得遗产占有。我认为，较妥当的看法是，该孙子不因此被排除；无论其父在收养关系中仍作为孙子留在家族内，还是已经被解放，均是如此。因为我认为，即使其父已被解放，孙子也应与父亲一同依告示取得遗产占有。

<!-- source-p 086 -->
<a id="37.4.1.8"></a>**8.**某人有一子及该子所生的孙子；儿子被解放，或者仍处于父权之下却被流放。问题是，这是否损害孙子的权利。较妥当的意见是，两种情形下都应准许孙子取得遗产占有；因为被流放者视同已经死亡。

<!-- source-p 087 -->
<a id="37.4.1.9"></a>**9.**如果父亲和儿子都被流放，后来又都恢复原状，应当说儿子可以取得遗产占有。如果儿子被判处矿场劳役，或被判处其他使其成为奴隶的刑罚，后来又恢复原状，他仍可取得遗产占有；否则则不可以。

<!-- source-p 088 -->
<a id="37.4.2"></a>**37.4.2**

<!-- source-p 089 -->
**赫尔莫革尼安：《法学撮要》第三卷。**

<!-- source-p 090 -->
如果父亲也因刑罚而成为奴隶，后来又恢复原状，法律同样适用。

<!-- source-p 091 -->
<a id="37.4.3"></a>**37.4.3**

<!-- source-p 092 -->
**乌尔比安：《告示评注》第三十九卷。**

<!-- source-p 093 -->
<a id="37.4.3.pr."></a>**序言。**不仅被解放的子女本人可以取得遗产占有，他们所生的子女也可以。

<!-- source-p 094 -->
<a id="37.4.3.1"></a>**1.**某人有两个孙子，将其中一人解放并收养为自己的儿子；应考察是否只有该人可以作为儿子取得遗产占有。只有在他将该人收养为其所保留的另一孙子的父亲时，问题才会如此发生。较好的意见是，只有该人可以取得遗产占有。

<!-- source-p 095 -->
<a id="37.4.3.2"></a>**2.**但是，如果这名孙子后来被解放，就应当说他不能作为儿子取得遗产占有；因为他已不再作为儿子属于子女之列，收养关系的权利也因解放而终止。

<!-- source-p 096 -->
<a id="37.4.3.3"></a>**3.**如果我有一子及该子所生的孙子，又将孙子收养为我的儿子，那么二人都可以取得遗产占有。但如果孙子后来被解放，他便不能取得遗产占有，因为其父亲的顺位优先。

<!-- source-p 097 -->
<a id="37.4.3.4"></a>**4.**某人在被解放后生了儿子，又将该儿子交给自己的父亲收养，以替代原有的儿子；公平地说，应给予该人任何收养子女都可取得的权利，因此他应与其父亲纳入同一家庭关系。但是，如果事实是该孙子在被收养后又被解放，公平地说，应准其脱离该关系（他恢复了自己的身份），不应再将他与其父亲合并处理。

<!-- source-p 098 -->
<a id="37.4.3.5"></a>**5.**被解放的儿子未经父亲同意娶妻并生子；后来，在父亲去世后，孙子希望取得祖父遗产的遗产占有，应准许其请求。通过撤销遗嘱，不能使一个合法婚生子变成非婚生子，因为撤销是为了让其取得权利，而非剥夺权利。即使儿子娶了极不名誉的妻子，以至于这名女子令儿子和父亲都蒙羞，我们也应说该女子所生的孩子仍可取得祖父遗产的占有；祖父可以依自己的权利排除该孙子继承。审理遗嘱违背义务之诉的人，不仅会衡量孙子本人的品行，也会考量其父亲的过错。

<!-- source-p 099 -->
<a id="37.4.3.6"></a>**6.**如果被解放而在遗嘱中被遗漏的儿子，在请求遗产占有之前自愿被收养为他人之子，就会丧失违遗嘱的遗产占有请求权。

<!-- source-p 100 -->
<a id="37.4.3.7"></a>**7.**某人将自己所保留的孙子交给他人收养；如果该孙子的父亲先于祖父去世，该孙子可以取得祖父遗产违遗嘱的遗产占有，因为他属于其父亲的家庭，而其父亲本人也本来可以取得违遗嘱的遗产占有。

<!-- source-p 101 -->
<a id="37.4.3.8"></a>**8.**如果某人在被解放后才生了儿子，随后又将该儿子交给自己的父亲收养，之后去世，法律同样适用；该孙子应准许取得其父亲遗产的遗产占有，仿佛他不属于另一个家庭。

<!-- source-p 102 -->
<a id="37.4.3.9"></a>**9.**如果某人的父亲进入收养家庭，而儿子没有进入，那么儿子能否取得其父亲在收养家庭中去世后留下的遗产占有？我认为较为人道的意见是：尽管该儿子不属于其父亲所在的同一家庭，仍应准许其取得父亲遗产的遗产占有。

<!-- source-p 103 -->
<a id="37.4.3.10"></a>**10.**依法不得被指定为继承人的子女，也不得请求违遗嘱的遗产占有。“不得被指定为继承人”应以死亡时为判断时点。

<!-- source-p 104 -->
<a id="37.4.3.11"></a>**11.**如果某一子女已被指定为继承人，就不应准其请求违遗嘱的遗产占有；因为他可以依据遗嘱书板取得遗产占有，为何还要给予他违遗嘱的遗产占有？但如果另一人违反了告示规定，他本人也可以请求违遗嘱的遗产占有。

<!-- source-p 105 -->
<a id="37.4.3.12"></a>**12.**如果子女是附条件被指定为继承人，就不能取得违遗嘱的遗产占有；尤利安在《学说汇纂》第二十三卷中也这样写道。那么，如果条件未成就呢？可以确定，他可以取得违遗嘱的遗产占有。

<!-- source-p 106 -->
<a id="37.4.3.13"></a>**13.**如果被解放的儿子附有其无从控制的条件而被指定为继承人，由于他已被指定为继承人，可以并且应当依据遗嘱书板取得遗产占有，不能请求违遗嘱的遗产占有。如果条件未成就，裁判官应在其本可取得违遗嘱遗产占有的范围内予以保护。

<!-- source-p 107 -->
<a id="37.4.3.14"></a>**14.**如果孙子也以此类条件被指定为继承人，结论同样如此。

<!-- source-p 108 -->
<a id="37.4.3.15"></a>**15.**如果某一子女未被指定为继承人，但其奴隶被指定为继承人，且该子女命令奴隶接受遗产，就应拒绝该子女请求违遗嘱遗产占有。

<!-- source-p 109 -->
<a id="37.4.3.16"></a>**16.**如果该子女选择接受留给自己或其奴隶的遗赠，结论也相同；在这种情况下，也应拒绝其请求违遗嘱遗产占有。

<!-- source-p 110 -->
<a id="37.4.4"></a>**37.4.4**

<!-- source-p 111 -->
**保罗：《告示评注》第四十一卷。**

<!-- source-p 112 -->
<a id="37.4.4.pr."></a>**序言。**应注意，裁判官向子女承诺的违遗嘱遗产占有，无论是否有人成为继承人，都适用。这就是我们所说的：子女可以针对遗嘱本身取得遗产占有；受庇护人的情形则恰恰相反。

<!-- source-p 113 -->
<a id="37.4.4.1"></a>**1.**如果某人指定处于自己权力之下的儿子为继承人，或将其排除继承，却遗漏了由该子所生的孙子，则不适用遗产占有；因为该孙子本来不会成为其自权继承人。更后顺位的情形也相同。

<!-- source-p 114 -->
<a id="37.4.4.2"></a>**2.**违遗嘱遗产占有的告示不适用于女性的遗嘱，因为女性没有自权继承人。

<!-- source-p 115 -->
<a id="37.4.4.3"></a>**3.**如果遗嘱遗漏了腹中胎儿，即使胎儿尚未出生，另一名被指定为继承人的人也可以取得违遗嘱的遗产占有。因为如果在遗漏的胎儿尚未出生期间，既不准他依据遗嘱书板取得遗产占有，又不准他请求违遗嘱遗产占有，显然有失公平；而在胎儿出生之前，遗嘱中的遗漏又尚未成立。这样，即使他在胎儿出生前去世，遗产占有利益也能移转给他的继承人。对于被解放后又被指定为继承人的儿子而言，这一点尤其必要，因为在此期间他无法接受遗产。

<!-- source-p 116 -->
<a id="37.4.5"></a>**37.4.5**

<!-- source-p 117 -->
**尤利安：《学说汇纂》第二十四卷。**

<!-- source-p 118 -->
即使他们在请求遗产占有之前已经去世，裁判官也不应拒绝裁定，令其继承人仍可享有依遗嘱书板或违遗嘱方式取得遗产占有的利益。

<!-- source-p 119 -->
<a id="37.4.6"></a>**37.4.6**

<!-- source-p 120 -->
**保罗：《告示评注》第四十一卷。**

<!-- source-p 121 -->
<a id="37.4.6.pr."></a>**序言。**如果被解放的儿子生有一子，随后去世，而其祖父又去世，那么孙子可以取得祖父遗产的遗产占有。

<!-- source-p 122 -->
<a id="37.4.6.1"></a>**1.**如果祖父也解放了儿子和孙子，在儿子生前，孙子不得请求；儿子去世后，孙子则可请求取得祖父遗产的遗产占有。

<!-- source-p 123 -->
<a id="37.4.6.2"></a>**2.**如果只有孙子被解放，祖父去世后其父亲又去世，则被遗漏的孙子可以取得父亲遗产的遗产占有；因为如果他未因祖父解放而脱离父权，本会成为父亲的自权继承人。

<!-- source-p 124 -->
<a id="37.4.6.3"></a>**3.**如果儿子被解放而孙子仍留在家父权之下，并且二人均被遗嘱遗漏，则二人都可取得遗产占有。

<!-- source-p 125 -->
<a id="37.4.6.4"></a>**4.**如果被解放的儿子在收养家庭中生了孙子，该孙子也不得请求其自然祖父遗产的遗产占有。即使被解放的儿子生有孙子后又将自己交给他人收养，使其子女随同进入收养家庭，结论也相同。但如果某人在养祖父的权力下出生，后来又被解放，他便可取得自然祖父遗产的遗产占有。只要某人仍在他人家庭中，收养就会对其不利；除此之外，被解放后，他可以取得自然父母遗产的遗产占有，但须在自然父母仍在世时被解放，而非在他们死后被解放。这才是较妥当的意见：自然父母死后才被解放的人，不得取得其遗产占有。

<!-- source-p 126 -->
<a id="37.4.7"></a>**37.4.7**

<!-- source-p 127 -->
**盖尤斯：《行省告示评注》第十四卷。**

<!-- source-p 128 -->
如果儿子被解放，而孙子仍处于权力之下，那么即使祖父尚在人世，孙子也可取得其父亲遗产的遗产占有。

<!-- source-p 129 -->
<a id="37.4.8"></a>**37.4.8**

<!-- source-p 130 -->
**乌尔比安：《告示评注》第四十卷。**

<!-- source-p 131 -->
<a id="37.4.8.pr."></a>**序言。**裁判官认为，被遗嘱排除并撤销继承资格的人，不应获准取得违遗嘱的遗产占有；依市民法，他们也不能推翻父母的遗嘱。当然，如果他们愿意提起遗嘱违背义务之诉，则由他们自行决定。

<!-- source-p 132 -->
<a id="37.4.8.1"></a>**1.**仅在遗嘱书板的某一部分将儿子排除继承，并不足够；必须是在他请求遗产占有所针对的那个顺位中将其排除。因此，如果儿子在第一顺位被排除继承、在第二顺位被遗漏，而第一顺位被指定的人没有请求遗产占有，他就可以取得违遗嘱的遗产占有。

<!-- source-p 133 -->
<a id="37.4.8.2"></a>**2.**并非任何排除继承都足以使儿子丧失违遗嘱遗产占有；只有依法作出的排除才有此效力。

<!-- source-p 134 -->
<a id="37.4.8.3"></a>**3.**如果儿子仅被一名继承人排除继承，马尔凯卢斯在《学说汇纂》第九卷中写道，不应认为儿子已被排除继承；因此，他可以对两名继承人均请求违遗嘱的遗产占有。

<!-- source-p 135 -->
<a id="37.4.8.4"></a>**4.**如果儿子既被排除继承，又在另一顺位被指定为继承人；在其获准依指定顺位继承的情况下，我认为，如果另一名儿子触发告示，他可以请求违遗嘱的遗产占有。

<!-- source-p 136 -->
<a id="37.4.8.5"></a>**5.**儿子在第一顺位被遗漏，在第二顺位被排除继承。如果立遗嘱人死亡时第一顺位的被指定继承人都已不在人世，应当说被遗漏者不能请求违遗嘱的遗产占有：因为遗产处于第二顺位，而非第一顺位；在第二顺位既不能接受遗产，也不能请求遗产占有。但是，如果被指定继承人在立遗嘱人死后才去世，同一马尔凯卢斯认为，已经产生的违遗嘱遗产占有请求权仍然存在。如果指定继承人的条件未成就，马尔凯卢斯也认为，被遗漏的儿子仍可对该顺位请求违遗嘱的遗产占有。如果被指定为继承人的遗腹子没有出生，他也写道，儿子仍可取得违遗嘱的遗产占有。

<!-- source-p 137 -->
<a id="37.4.8.6"></a>**6.**如果某人亲手在遗嘱中写明将自己排除继承，他是否还能取得违遗嘱的遗产占有？我们来考察这一问题。马尔凯卢斯在《学说汇纂》第九卷中说，这种排除对他不利；因为元老院决议并未将对其不利的这类记载视为未曾书写。

<!-- source-p 138 -->
<a id="37.4.8.7"></a>**7.**如果某人排除了已被解放的儿子，随后又收养该儿子为自权人，帕比尼安在《疑义集》第十二卷中说，自然关系的权利在此居于优先地位；因此，排除继承仍对其不利。

<!-- source-p 139 -->
<a id="37.4.8.8"></a>**8.**但是，对于外人，乌尔比安赞同马尔凯卢斯的意见：后来收养该外人，不使先前的排除继承对其发生不利。

<!-- source-p 140 -->
<a id="37.4.8.9"></a>**9.**儿子依返还权归来时，应当说先前作出的排除继承仍对其不利。

<!-- source-p 141 -->
<a id="37.4.8.10"></a>**10.**如果自然父亲排除了处于收养家庭中的儿子，随后该儿子又被解放，排除继承仍对其不利。

<!-- source-p 142 -->
<a id="37.4.8.11"></a>**11.**裁判官不希望排除被交给他人收养的子女，只要他们被指定为继承人；拉贝奥说，裁判官如此规定极为公正，因为他们并非完全的外人。因此，如果他们被指定为继承人，就可以取得违遗嘱的遗产占有；但只有他们本人时，不会触发告示，除非另有通常能够触发告示的子女被遗漏。如果本人未被指定，而能替其取得遗产的人被指定为继承人，则不应准许他请求违遗嘱的遗产占有。

<!-- source-p 143 -->
<a id="37.4.8.12"></a>**12.**要准许其取得遗产占有，这些人必须属于子女之列。反之，如果我将养子交给他人收养，又指定其为继承人，即使他人触发了告示，也不得授予该养子违遗嘱的遗产占有。

<!-- source-p 144 -->
<a id="37.4.8.13"></a>**13.**处于收养家庭中的人，如果在可以请求遗产占有的那个顺位被指定为继承人，也可以取得违遗嘱的遗产占有。

<!-- source-p 145 -->
<a id="37.4.8.14"></a>**14.**这并不新奇：被遗漏的解放子女可能使其被指定为继承人的兄弟取得比他们原本更多的权利。因为，如果处于父权之下的儿子被指定为十二分之一继承人，而其解放的兄弟被遗漏，那么前者会因解放兄弟的利益取得遗产的一半；如果没有被解放的兄弟，他原本只能取得十二分之一。但是，如果他仅被指定为极小份额的继承人，告示触发后，裁判官并不只按指定份额保护他，他可以通过遗产占有取得更多。因为裁判官准予违遗嘱的遗产占有时，意在将每名子女在父亲无遗嘱死亡、且该子女仍处于父权之下时本可取得的份额授予他们。因此，无论被解放者、仍处于父权之下者，还是被交给他人收养者，只要被指定为小份额继承人，均不受该份额限制，而可按人头取得份额。

<!-- source-p 146 -->
<a id="37.4.9"></a>**37.4.9**

<!-- source-p 147 -->
**盖尤斯：《行省告示评注》第十四卷。**

<!-- source-p 148 -->
养父在世还是已经去世，并无区别；唯一要考察的是，该人是否仍处于收养家庭之中。

<!-- source-p 149 -->
<a id="37.4.10"></a>**37.4.10**

<!-- source-p 150 -->
**乌尔比安：《告示评注》第四十卷。**

<!-- source-p 151 -->
<a id="37.4.10.pr."></a>**序言。**如果在立遗嘱人死亡后，被指定为继承人的儿子将自己交给他人收养，他仍可取得违遗嘱的遗产占有；因为收养通常不损害遗嘱指定的继承人。

<!-- source-p 152 -->
<a id="37.4.10.1"></a>**1.**如果自然父亲指定被外祖父收养的儿子为继承人，且另一人触发告示，较妥当的意见是准许该儿子取得遗产占有；因为并不要求他接受遗产，只要遗产已经归其取得并且可以被其取得，就已足够。

<!-- source-p 153 -->
<a id="37.4.10.2"></a>**2.**被交给他人收养的人，依养父命令接受遗产后又被解放，可以取得违遗嘱的遗产占有；遗产应由其本人而非养父取得。

<!-- source-p 154 -->
<a id="37.4.10.3"></a>**3.**应注意，被交给他人收养的人即使已经接受遗产，也可以取得违遗嘱的遗产占有。反之，如果某人接受了留给自己或其奴隶的遗赠，就应排除其取得违遗嘱遗产占有的权利。

<!-- source-p 155 -->
<a id="37.4.10.4"></a>**4.**不能取得违遗嘱遗产占有的子女，即使他人触发告示，也不计入确定份额的人数；既然他们不会取得任何财产，帮助他们参与分配又有什么益处？

<!-- source-p 156 -->
<a id="37.4.10.5"></a>**5.**被排除继承的子女既不能触发告示，也不会在他人触发告示后与其共同取得遗产占有；他们只剩下提起遗嘱违背义务之诉的权利。

<!-- source-p 157 -->
<a id="37.4.10.6"></a>**6.**因他人触发告示而请求遗产占有的人，无须等到被遗漏者取得遗产占有；他们自己也可以请求违遗嘱的遗产占有。因为他们既然已经因他人的利益而获准享有此项利益，就不再在意那些人是否请求遗产占有。

<!-- source-p 158 -->
<a id="37.4.11"></a>**37.4.11**

<!-- source-p 159 -->
**保罗：《告示评注》第四十一卷。**

<!-- source-p 160 -->
<a id="37.4.11.pr."></a>**序言。**如果自然父亲附条件指定已被交给他人收养的人为继承人，而另一人触发了违遗嘱告示，该收养子女也可以共同请求；但如果条件未成就，他便被排除在该遗产占有之外。我认为，对纯粹指定但依法无效的继承人，也适用同一规则。

<!-- source-p 161 -->
<a id="37.4.11.1"></a>**1.**违遗嘱遗产占有依照法定继承规则分配。因此，同一儿子所生的数名孙子共同取得一份。

<!-- source-p 162 -->
<a id="37.4.12"></a>**37.4.12**

<!-- source-p 163 -->
**盖尤斯：《行省告示评注》第十四卷。**

<!-- source-p 164 -->
<a id="37.4.12.pr."></a>**序言。**如果两名儿子及其中一名儿子所生的两名孙子均有权取得遗产占有，而其中一名孙子没有请求，其份额便增益归于其兄弟。如果两名儿子中有一人没有请求，则此事同时有利于兄弟和孙子：因为这时分为两个二分之一份额，一个由儿子取得，一个由孙子们取得。

<!-- source-p 165 -->
<a id="37.4.12.1"></a>**1.**如果先前存在一份依法有效的遗嘱，其中某儿子被排除继承；之后又有一份不完备的遗嘱遗漏了该儿子，那么他可以依据后一份遗嘱正确请求遗产占有，但前提是：即使排除该儿子，后一份遗嘱指定的继承人仍优先取得遗产。确切地说，如果对方在排除该儿子后本可取得遗产，那么儿子也可以正确请求遗产占有；如果对方不能取得遗产，儿子也会被排除。

<!-- source-p 166 -->
<a id="37.4.13"></a>**37.4.13**

<!-- source-p 167 -->
**尤利安：《学说汇纂》第二十三卷。**

<!-- source-p 168 -->
<a id="37.4.13.pr."></a>**序言。**被解放者取得违遗嘱的遗产占有后，遗嘱指定的继承人应在其请求时被迫向其交付遗产地产和奴隶。因为遗嘱指定继承人因继承而取得的一切权利，都应移转给裁判官置于继承人地位的人。

<!-- source-p 169 -->
<a id="37.4.13.1"></a>**1.**某人有两个儿子及其中一人所生的孙子；他将孙子交给他人收养，并指定其为继承人，却遗漏另一名儿子。问题是，孙子应取得其父亲那一份，还是应取得人头份额。我答复说：孙子虽被收养并指定为继承人，但只要其父亲仍处于父权之下或已经被解放，孙子就不能取得违遗嘱的遗产占有；即使其父亲在取得遗产占有之前去世，孙子也不准取得遗产占有。

<!-- source-p 170 -->
<a id="37.4.13.2"></a>**2.**如果父亲遗漏已被解放的儿子，却指定两名继承人：一人为仍处于自己权力之下的儿子，另一人为交给他人收养的儿子；后者又在其家庭中留下两名孙子，而两名孙子也被遗嘱遗漏，那么已被解放的儿子取得三分之一，仍处于父权之下的儿子取得三分之一，被交给他人收养的儿子及其子女共同取得三分之一；其中六分之一归其父亲，六分之一归孙子们。

<!-- source-p 171 -->
<a id="37.4.13.3"></a>**3.**父亲有两个儿子，其中一人有子女；父亲解放该儿子，又将此前已解放的一名孙子收养为儿子，随后在遗嘱中遗漏已解放的儿子而去世。较公平的做法是救济被收养为儿子的孙子，并将遗产分为三份：一份归仍处于父权之下的儿子，一份归被收养为儿子的孙子，另一份由被解放的儿子及其儿子（即孙子）共同取得。如果儿子去世后，父亲又将另一名孙子收养为儿子，遗产仍应分为三份；因为公平地说，被收养为儿子的人不应少于被收养的外人。

<!-- source-p 172 -->
<a id="37.4.14"></a>**37.4.14**

<!-- source-p 173 -->
**阿非利加努斯：《疑义集》第四卷。**

<!-- source-p 174 -->
<a id="37.4.14.pr."></a>**序言。**如果两名被解放的儿子中，一人被指定为继承人，另一人被遗漏；前者接受了遗产，尽管告示措辞并未充分说明，答复仍认为他不能请求遗产占有，因为他遵循了父亲的遗嘱意思。已被解放的人若接受遗赠，也不得请求遗产占有；无论遗赠是由遗嘱指定的继承人给付，还是由请求违遗嘱遗产占有的人给付，均是如此。不过，应注意：对于已被指定为继承人并接受遗产的人，裁判官应按其被指定的份额予以保护，但不得超过其如果取得遗产占有本可获得的份额。也就是说，如果他被指定的份额较小，他只能保留该份额，而且还必须履行向外人给付遗赠的义务。至于处于父权之下的儿子，如果被指定为继承人，他就是必然继承人；因此，只要尚未介入遗产事务，也应认为他可以请求遗产占有。如果他已经介入，则因为他似乎认可父亲的意思，应与被解放者处于相同地位。

<!-- source-p 175 -->
<a id="37.4.14.1"></a>**1.**某人在收养家庭中娶妻生子；养父去世后，他解放了儿子。答复认为，该孙子可以依据裁定请求其自然祖父遗嘱违背的遗产占有。同样，如果被解放的儿子生有儿子并解放了他，随后又将自己交给他人收养，待养父去世后自己也去世，那么毫无疑问，他可以依裁定请求违背其父亲和祖父遗嘱的遗产占有；否则他将被排除在所有人的遗产之外。

<!-- source-p 176 -->
<a id="37.4.15"></a>**37.4.15**

<!-- source-p 177 -->
**马尔西安：《规则集》第五卷。**

<!-- source-p 178 -->
如果被遗漏的解放子女以恶意抗辩回应父亲继承人针对其提起的债务诉讼，主张其欠父亲的债务，我认为他不得请求违遗嘱的遗产占有；因为他以此行为仿佛已经放弃遗产占有。只有在如下情形中才能这样理解：儿子并未使用“如果儿子不能取得违遗嘱的遗产占有”这一抗辩来阻止继承人请求债务，而是改用恶意抗辩。

<!-- source-p 179 -->
<a id="37.4.16"></a>**37.4.16**

<!-- source-p 180 -->
**庞波尼乌斯：《萨宾评注》第四卷。**

<!-- source-p 181 -->
如果一名被解放的儿子将遗嘱信托遗产留给仍处于祖父权力之下的孙子，并规定只有孙子脱离祖父权力后才能取得；如果祖父似乎可能耗尽孙子的财产而被认为遗产状况可疑，则不得向祖父准予遗产占有。

<!-- source-p 182 -->
<a id="37.4.17"></a>**37.4.17**

<!-- source-p 183 -->
**乌尔比安：《萨宾评注》第三十五卷。**

<!-- source-p 184 -->
如果父亲将自己交给他人收养，而先前已经被解放的儿子没有随其进入收养家庭，原因是父子分属不同家庭，那么该儿子不能取得违遗嘱的遗产占有；尤利安曾如此写道。马尔凯卢斯则说，如果父亲将自己交给他人收养，排除该儿子取得遗产占有似乎不公平。因为儿子并未被交给他人收养，而是父亲自行进入收养家庭，此举并未为儿子指定一位父亲。这个意见并非没有道理。

<!-- source-p 185 -->
<a id="37.4.18"></a>**37.4.18**

<!-- source-p 186 -->
**赫尔莫革尼安：《法学撮要》第三卷。**

<!-- source-p 187 -->
<a id="37.4.18.pr."></a>**序言。**在附条件的情况下被排除继承者，可以请求违遗嘱的遗产占有；但附条件被指定为继承人者，则被排除在违遗嘱的遗产占有之外。因为必须通过明确的遗嘱意思将子女排除于父母的继承之外。

<!-- source-p 188 -->
<a id="37.4.18.1"></a>**1.**取得违遗嘱遗产占有的人，不得请求遗赠或遗嘱信托给付，也不得保留因死亡而为的赠与；无论其本人还是他人代为请求，均无区别。

<!-- source-p 189 -->
<a id="37.4.19"></a>**37.4.19**

<!-- source-p 190 -->
**特里福尼努斯：《论辩集》第十五卷。**

<!-- source-p 191 -->
通常所谓“给予子女的遗产占有是 *contra lignum*”，应如此理解：只要在父亲死亡时存在遗嘱书板，并且依据该遗嘱书板可以接受遗产或请求遗产占有，就已足够；即使之后两者都未发生，或已不可能发生，也不影响。但如果所有被指定的继承人及其替补继承人都先于立遗嘱人死亡，或者被指定的人与立遗嘱人之间不存在订立遗嘱的法律能力，那么请求违遗嘱的遗产占有便毫无意义，因为遗嘱根本不会产生任何效力。

<!-- source-p 192 -->
<a id="37.4.20"></a>**37.4.20**

<!-- source-p 193 -->
**特里福尼努斯：《论辩集》第十九卷。**

<!-- source-p 194 -->
<a id="37.4.20.pr."></a>**序言。**父亲排除处于自己权力之下的儿子，却遗漏了已被解放的儿子。问题是，被解放者可以取得多少遗产占有。我答复说，如果外人被指定为继承人并接受遗产，仍处于父权之下的儿子就被排除。如果这些人放弃遗产——由于违遗嘱遗产占有已授予被解放的儿子，他们很容易这样做，因为他们从遗产中得不到任何东西——那么该儿子就成为父亲无遗嘱时的自权继承人；而被解放的儿子请求违遗嘱遗产占有后，将单独取得遗产占有。但是，如果遗产尚未被接受，遗嘱中的排除继承便毫无效力。因此，尤利安正确答复说，它既不妨碍被遗漏的儿子取得违遗嘱遗产占有，也不妨碍其取得父亲被释奴的遗产占有；否则，遗嘱会在所有方面都无效，却只使排除继承的记载发生效力。于是，应按无遗嘱继承处理：裁判官应以遗产一半保护被解放的儿子，使其对抗本来可以单独作为自权继承人的儿子。这样，外人继承人的指定就成了可供利用的利益：外人依法接受遗产，本身虽一无所获，却能排除仍处于父权下的儿子，并使被解放的儿子依据违遗嘱遗产占有取得全部遗产；如果外人放弃遗产，则被排除继承者会因遗产产生的效果取得其中一份，成为依法唯一的自权继承人。不过，正如遗产未被接受时裁判官会保护被解放者，遗产一经接受，也不得将仍处于父权下的儿子彻底排除；应允许他提起遗产请求之诉，并以遗嘱违背义务为由对被解放者提起诉讼。

<!-- source-p 195 -->
<a id="37.4.20.1"></a>**1.**还须考察，在两人都来请求父亲遗产的情形下，被解放者是否应将自己的财产归入遗产。根据他凭以取得违遗嘱遗产占有的告示文字，他并无义务如此办理；该告示要求被解放者向那些依据该项遗产占有取得利益的人提供归入财产的担保。但在本案中，仍处于父权下的儿子因被明确排除继承，并未被召入违遗嘱遗产占有。依另一项告示规定，父亲无遗嘱死亡时，被解放者取得遗产占有须将财产归入遗产；本案也不适用，因为即使兄弟是无遗嘱继承人，被解放者也不是依据无遗嘱规则取得遗产占有。我担心，外人继承人不接受遗产这一事实，只使仍处于父权下的儿子得以取得父亲财产的一份，而不包括被解放者的自有财产。与此相应：如果处于父权下的儿子被父亲指定为较小份额的继承人，而其被解放的兄弟取得违遗嘱遗产占有，前者虽因后者的利益而取得较多财产，即使告示文字要求归入财产，仍应依裁判官的意思答复说，不应要求归入。更何况，在本案中，被解放者被父亲排除继承，裁判官也未召其取得违遗嘱遗产占有；他只是由于遗嘱指定继承人放弃遗产而取得自权继承人的身份，而该指定继承人原本因被解放者已获裁判官授予违遗嘱遗产占有，不会从遗产取得任何利益。

<!-- source-p 196 -->
<a id="37.4.20.2"></a>**2.**但是，该被解放者仍须以自己的份额向子女和父母履行遗赠义务；他所负担的数额并非全部，而应减半，因为遗产中有一半留给仍处于父权之下的人。对于依法成为无遗嘱继承人的人，也不得仅因遗赠而对其提起诉讼。

<!-- source-p 197 -->
<a id="37.4.20.3"></a>**3.**但是，已经取得违遗嘱遗产占有的人，即使遗嘱指定继承人尚未接受遗产，也应履行遗嘱中该部分所列的遗赠；他正是针对该部分取得了违遗嘱遗产占有。因此，在本案中，仍留在家族中的儿子处境会比未被排除继承时更好。

<!-- source-p 198 -->
<a id="37.4.21"></a>**37.4.21**

<!-- source-p 199 -->
**莫德斯蒂努斯：《学说汇纂》第六卷。**

<!-- source-p 200 -->
<a id="37.4.21.pr."></a>**序言。**某人有一子及该子所生的孙子，二人均处于其权力之下；他将儿子交给他人收养，但把孙子留在自己权力之下。此后，儿子被养父解放，并在指定外人为继承人后去世。留在祖父权力之下的儿子之子，可以请求违其父亲遗嘱的遗产占有，即使他从未处于父亲权力之下。因为他似乎本来就不应处于父亲权力之下。否则，如果儿子被解放，留在祖父权力之下的孙子也不能请求违其父亲遗嘱的遗产占有。

<!-- source-p 201 -->
<a id="37.4.21.1"></a>**1.**如果儿子被解放后，其子仍留在祖父权力之下，后来孙子又被交给自己的父亲收养，法律同样适用；也就是说，孙子可以请求违其祖父遗嘱的遗产占有，因为通过收养，他并未进入他人的家庭。

<!-- source-p 202 -->
<a id="37.4.21.2"></a>**2.**但是，如果我被解放的儿子收养了一名外人为子，该被收养者不得请求违我遗嘱的遗产占有，因为他从未在我家中处于孙子的地位。
