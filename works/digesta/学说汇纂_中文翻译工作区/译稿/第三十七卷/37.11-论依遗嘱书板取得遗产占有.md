# D.37.11　论依遗嘱书板取得遗产占有（*De bonorum possessione secundum tabulas*）

<!-- source-p 628 -->
<a id="11"></a><a id="37.11"></a>**37.11.0　论依遗嘱书板取得遗产占有**（*De bonorum possessione secundum tabulas*）。

<!-- source-p 629 -->
<a id="37.11.1"></a>**37.11.1**

<!-- source-p 630 -->
乌尔比安《告示评注》第三十九卷。

<!-- source-p 631 -->
<a id="37.11.1.pr."></a>**序言**　我们所说的遗嘱书板，应包括各种形制和材质：无论是木板、其他材料制成的板片、纸张、羊皮纸，还是某种动物的皮革，均可称为遗嘱书板。

<!-- source-p 632 -->
<a id="37.11.1.1"></a>**1.**裁判官在告示本部分所承认的，并非所有遗嘱书板，而是最后制作的书板，即制作之后再未制作其他书板者。所谓“最后”，并非指最接近死亡时制作，而是指其后没有再制作其他书板；因此，即使这些书板制作得较早，仍属最后书板。

<!-- source-p 633 -->
<a id="37.11.1.2"></a>**2.**只要能够确定书板确实存在，即使未将其提出，也已足够。因此，若书板在窃贼或受寄存之人手中，也不应怀疑可以准予遗产占有；要依遗嘱书板取得遗产占有，并不需要先将书板开启。

<!-- source-p 634 -->
<a id="37.11.1.3"></a>**3.**所要求的是：遗嘱人在死亡时，书板曾经存在过，即便此后不再存在亦然。因此，即使书板后来毁失，也可以请求遗产占有。

<!-- source-p 635 -->
<a id="37.11.1.4"></a>**4.**但我们要求继承人知悉书板存在，并确定遗产占有已经归属于自己。

<!-- source-p 636 -->
<a id="37.11.1.5"></a>**5.**若某人制作了两份遗嘱副本，其中一份尚存，另一份不存，仍视为遗嘱书板尚存，可以请求遗产占有。

<!-- source-p 637 -->
<a id="37.11.1.6"></a>**6.**若遗嘱人在两份同时加盖印记的文书中，分别指定不同的继承人，且两份均尚存，则可依据两份文书分别取得遗产占有，犹如依据一份遗嘱；因为应将它们视为同一套书板，并且两份均应视为最后遗嘱书板。

<!-- source-p 638 -->
<a id="37.11.1.7"></a>**7.**但是，若遗嘱人一份文书是作为遗嘱制作，另一份仅作为副本制作，则若遗嘱人意欲作为遗嘱的那份尚存，可以请求遗产占有；若尚存的只是副本，则不得请求遗产占有。庞波尼乌斯如此记载。

<!-- source-p 639 -->
<a id="37.11.1.8"></a>**8.**裁判官要求，获准遗产占有之人在制作遗嘱时和死亡时这两个时点，均须具有遗嘱能力。因此，未适婚人、精神失常者或其他无权制作遗嘱之人制作遗嘱，之后虽取得遗嘱能力而死亡，仍不得请求遗产占有。又如家子误以为自己是家父而制作遗嘱，死亡时却发现自己确为家父，也不得请求依遗嘱书板取得遗产占有。但是，若退伍军人身份的家子就军营特有产制作遗嘱，之后被解放出家父权或以其他方式成为家父而死亡，则可以请求其遗产占有。反之，若某人在上述两个时点均有遗嘱能力，只是在中间一段时间丧失该能力，仍可以请求依遗嘱书板取得遗产占有。

<!-- source-p 640 -->
<a id="37.11.1.9"></a>**9.**若某人制作遗嘱后，因精神失常或被剥夺财产处分权而丧失遗嘱能力，仍可以请求其遗产占有，因为该遗嘱依法有效。对于所有在死亡时丧失遗嘱能力、但遗嘱制作时遗嘱有效的人，一般均作此处理。

<!-- source-p 641 -->
<a id="37.11.1.10"></a>**10.**若捆扎书板的线被割断，且系他人违背遗嘱人意愿所为，可以请求遗产占有；若由遗嘱人本人割断，则书板不视为已经加封，因此不得请求遗产占有。

<!-- source-p 642 -->
<a id="37.11.1.11"></a>**11.**若书板被老鼠咬坏，或捆扎线以其他方式断裂、因年久而腐朽、受潮或意外损坏，只要书板看起来曾经加封，仍应如此认定；尤其是尚有一段捆扎线留存时。假如捆扎线缠绕了三圈或四圈，即使其中一圈的部分线段被割断或咬坏，也应认定遗嘱书板仍然处于加封状态。

<!-- source-p 643 -->
<a id="37.11.2"></a>**37.11.2**

<!-- source-p 644 -->
乌尔比安《告示评注》第四十一卷。

<!-- source-p 645 -->
<a id="37.11.2.pr."></a>**序言**　裁判官遵循了最为公平的顺序：他首先希望违遗嘱的遗产占有归于子女；若子女未据此取得遗产占有，才应遵从死者的遗嘱。因此，应等待子女请求遗产占有，直至其请求期限届满；或者，若子女此前死亡、放弃请求，或丧失请求遗产占有的权利，遗产占有才转归遗嘱指定的继承人。

<!-- source-p 646 -->
<a id="37.11.2.1"></a>**1.**尤利安始终认为，若儿子被指定为附条件继承人，他作为遗嘱中指定之人，可以依遗嘱书板取得遗产占有，无论条件为何，即使条件是“若船自亚洲归来”亦然。即使条件最终未成就，裁判官仍应保护已经接受依遗嘱书板所授遗产占有的儿子，如同他是依据违遗嘱的遗产占有取得遗产；对于已解放出家父权的儿子，这种保护尤其必要。

<!-- source-p 647 -->
<a id="37.11.2.2"></a>**2.**遗嘱指定继承人各按其被指定的份额取得遗产占有；但若没有其他人参与该份额，其一人即可取得全部遗产占有。然而，只要一名共同继承人仍在考虑是否接受遗产占有，该人的份额就不会转归另一共同继承人。

<!-- source-p 648 -->
<a id="37.11.2.3"></a>**3.**若第一继承人被规定为在十年内死亡时由第二人替补，而第二人仅在十年之后、十四年内死亡时替补：若第一人在十年内死亡，第一替补人即为唯一继承人并取得遗产占有；若第一人在十年之后、十四年以内死亡，则第二替补人即为唯一继承人并取得遗产占有。两人不共同取得，因为每个人都是针对各自不同的情形被指定为替补继承人。

<!-- source-p 649 -->
<a id="37.11.2.4"></a>**4.**依遗嘱书板给予遗产占有时，首先给予第一顺位指定的继承人；他们不请求时，再给予后顺位者。这不仅包括替补继承人，也包括替补继承人的替补继承人；我们依替补顺序逐级准许其请求。所谓第一顺位指定者，是指所有被列于第一顺位的人：正如他们是最先有权接受继承的人，也同样最先有权接受遗产占有。

<!-- source-p 650 -->
<a id="37.11.2.5"></a>**5.**若遗嘱如此规定：“第一人取得某一份额的继承权；若第一人不成为继承人，则第二人取得继承权。第三人取得另一半份额的继承权；若第三人不成为继承人，则第四人取得继承权”，则第一人和第三人最先获准请求遗产占有。

<!-- source-p 651 -->
<a id="37.11.2.6"></a>**6.**若有人如此指定继承人：“我的兄弟中，谁娶了塞娅为妻，谁就取得我遗产的四分之三；谁没有娶她，谁就取得四分之一”，若塞娅死亡，则继承人应取得相等份额，这一点没有疑问；若其中一人娶了她，则二人分别取得四分之三与四分之一。但条件尚未成就之前，任何一人都不得请求遗产占有。

<!-- source-p 652 -->
<a id="37.11.2.7"></a>**7.**若继承人的姓名是故意添写进去的，则毫无疑问，此人不得请求遗产占有；正如未得遗嘱人本意而被写为继承人的人也不得请求一样。遗嘱人不愿写入其姓名之人，应视为未被写入遗嘱。

<!-- source-p 653 -->
<a id="37.11.2.8"></a>**8.**若第一人和第二人被指定为继承人，第三人被指定为第二人的替补继承人，则第二人不请求遗产占有时，由第三人继受；若第三人不愿接受继承或取得遗产占有，遗产占有便回归第一人。第一人无须另行请求，遗产占有依法自行归增于他；正如遗嘱指定继承人取得的继承份额会归增于他，其遗产占有份额也会如此归增。

<!-- source-p 654 -->
<a id="37.11.2.9"></a>**9.**若奴隶被指定为继承人，遗产占有即归于将取得该遗产的主人；因为遗产占有随所有权转移。因此，若遗嘱人死亡时，奴隶斯提库斯被指定为继承人，且属于塞姆普罗尼乌斯；塞姆普罗尼乌斯未命令其接受继承，而后死亡或将其出卖，使其转归塞普提基乌斯；若塞普提基乌斯命令该奴隶接受继承，遗产占有就归于塞普提基乌斯，因为遗产归他所有。因此，若该奴隶先后转归多个主人——三人或更多——我们应将遗产占有给予最后一位主人。

<a id="37.11.5.pr."></a>**序言**　若某人被指定为附条件继承人，并在取得依遗嘱书板所授的遗产占有后，条件未成就，有时仍会发生应将遗产交由占有人保有的情形。例如，已解放出家父权的儿子被指定为附条件继承人；尤利安记载，即使条件未成就，仍应准许他依遗嘱书板取得遗产占有。尤利安还记载，若某人本可依无遗嘱继承取得遗产占有，也应予以保护；我们现行法即依此处理。

<!-- source-p 664 -->
<a id="37.11.5.1"></a>**1.**还须考察他们是否负有支付遗赠的义务。儿子取得依违遗嘱的遗产占有后，似乎是基于该占有而持有遗产；其他人则似乎是依无遗嘱继承持有。因此，儿子仅须向子女和父母支付遗嘱留给他们的遗赠，不须向其他人支付。显然，若有人依无遗嘱继承而获遗嘱信托，儿子仍须履行；因为此人似乎正是由于有人依遗嘱请求取得遗产占有，才遭受了损害。

<a id="37.11.8.pr."></a>**序言**　若遗嘱如此写道：“塞姆普罗尼乌斯取得二分之一份额的继承权。蒂提乌斯若船自亚洲归来，取得三分之一份额的继承权；同一蒂提乌斯若船未自亚洲归来，取得六分之一份额的继承权”，则不应认为蒂提乌斯被指定为两个份额的继承人，而应认为他是自己的替补继承人；因此，他被指定的份额不得超过三分之一。依此解释，既然有六分之一份额空缺，蒂提乌斯取得遗产占有时，不仅取得三分之一份额，也取得由该六分之一份额归增而来的部分。

<!-- source-p 674 -->
<a id="37.11.8.1"></a>**1.**若某人如此为未适婚的儿子指定替补继承人：“若我的儿子在达到适婚年龄、脱离监护之前死亡，则提提乌斯为我之继承人”，则该替补人既可请求继承遗产，也可取得该遗产的遗产占有；其效力犹如其中没有加上“为我”一词。

<!-- source-p 675 -->
<a id="37.11.8.2"></a>**2.**即使遗嘱人的名字或家族名写错，真正有权取得遗产的人也可以取得遗产占有。

<!-- source-p 676 -->
<a id="37.11.8.3"></a>**3.**若某人的姓名系遗嘱人有意从遗嘱中划去，则无论请求接受继承还是请求遗产占有，都不得认为此人已被指定为继承人，即使遗嘱中仍能读出其姓名亦然。

<!-- source-p 677 -->
<a id="37.11.8.4"></a>**4.**有人以书板为自己制作遗嘱，却以口头宣告的方式为未适婚的儿子指定替补继承人。我答复说，裁判官准予遗产占有时的意思是，应分别认定父亲和儿子的继承人。因此，正如儿子的书面指定继承人可以与父亲的书面指定继承人分别取得遗产占有，口头指定的替补继承人也可被认为能够与父亲的书面指定继承人分别取得遗产占有。

<a id="37.11.11.pr."></a>**序言**　遗嘱写道：“我的子女中，最后一个在未适婚时死亡者，由提提乌斯为其继承人。”若两名子女均在国外死亡，而替补继承人无法确定谁最后死亡，应采纳尤利安的意见：由于条件是否成就尚不确定，较早死亡的子女的遗产占有也可以请求。

<!-- source-p 687 -->
<a id="37.11.11.1"></a>**1.**儿子被指定为继承人，在父亲死亡后从敌人处归来：他可以取得遗产占有，其一年期间自归来之日起计算。

<!-- source-p 688 -->
<a id="37.11.11.2"></a>**2.**提提乌斯制作遗嘱后，自愿接受他人收养；其后恢复自权人身份，并在此状态下死亡。若遗嘱指定的继承人请求遗产占有，将以恶意抗辩将其排除；因为遗嘱人自愿接受收养时，其人身身份和财产也一并转入他人的家族与家宅。显然，若其恢复自权人身份后，在补充遗嘱或其他文书中声明自己仍愿依同一遗嘱死亡，则应认为已经消失的意愿因其新的意思表示而恢复；这与某人另立一份遗嘱、又将最新书板割毁，从而使先前的书板重新成为最后遗嘱书板相同。但不可因此认为仅凭裸露的意愿即可成立遗嘱：此处主要争论的并非遗嘱是否依法成立，而是恶意抗辩的效力。该抗辩虽在本案中针对请求人提出，其判断仍应依据提出抗辩之人的情形。

我认为，为使遗嘱指定的继承人能够主张遗产占有，必须以明确的个别指定指明其身份，并且能够查明其被指定的份额；即使其被指定为未分份额的继承人，也应如此。因为未分份额而被指定为继承人的人，可以取得空缺份额或其他一阿斯份额。反之，若某人被指定为继承人的方式是：由于找不到其受指定的份额，他有时会被排除在遗嘱之外，则其也不得请求遗产占有。例如，有人如此指定：“提提乌斯按我在先前遗嘱中指定其为继承人的份额，取得继承权”，或“按我在补充遗嘱中指定其为继承人的份额，取得继承权”，但实际上找不到该指定；此种情形即属此类。若我如此写道：“提提乌斯，若我在先前遗嘱中曾指定你取得二分之一份额的继承权，你即取得二分之一份额的继承权”，或“若我在补充遗嘱中曾指定你取得二分之一份额的继承权，你即取得二分之一份额的继承权”，则此人作为附条件指定的继承人，可以取得遗产占有。
