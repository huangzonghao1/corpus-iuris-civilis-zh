# D.37.6 论财产归并（*De collatione bonorum*，第一段）

> **底本范围：**依 d-37.htm source-p 313–340 翻译；保留原有段落、锚点、题名及出处。

<!-- source-p 313 -->
<a id="6"></a><a id="37.6"></a>**37.6.0 论财产归并**（*De collatione bonorum*）。

<!-- source-p 314 -->
<a id="37.6.1"></a>**37.6.1**

<!-- source-p 315 -->
乌尔比安《告示评注》第四十卷。

<!-- source-p 316 -->
<a id="37.6.1.pr."></a>**序言。**本标题体现了明显的公平原则：裁判官既准许解放出父权的子女取得违遗嘱的遗产占有，使他们与仍处于父权之下的人共同分有父亲的财产，那么请求取得父亲遗产的人，也应将自己的财产归并入共同财产。

<!-- source-p 317 -->
<a id="37.6.1.1"></a>**1.**财产归并义务发生于所有已经获准遗产占有的人之间。

<!-- source-p 318 -->
<a id="37.6.1.2"></a>**2.**当然，若未成年人或其他通常可由裁判官准予恢复原状的人，因请求违遗嘱的遗产占有时有所遗漏而获准恢复原状，那么裁判官也会恢复其享有财产归并利益的地位。

<!-- source-p 319 -->
<a id="37.6.1.3"></a>**3.**如果处于父权之下的儿子被指定为四分之三遗产的继承人，外人被指定为四分之一的继承人，尤利安说，解放出父权的儿子取得违遗嘱遗产占有时，只须按四分之一的份额归并自己的财产，因为他只从兄弟处取得了四分之一。庞波尼乌斯以此作为该见解的论据：解放出父权的儿子仅被要求向自己所生的孙辈归并财产。

<!-- source-p 320 -->
<a id="37.6.1.4"></a>**4.**父亲在遗嘱中指定一名处于父权之下的儿子及一名外人为继承人，却遗漏了已解放出父权的儿子；两名儿子都取得了违遗嘱的遗产占有。可以合理地说，解放出父权的儿子只有在因继承取得某项利益、从而使兄弟受损时，才应向兄弟归并财产。如果处于父权之下的儿子被指定的继承份额不足遗产的一半，却要求解放出父权的儿子归并财产，就显得不公平，因为正是后者使他能够从父亲的遗产中取得更多。

<!-- source-p 321 -->
<a id="37.6.1.5"></a>**5.**因此，只有在解放出父权的儿子介入并使处于父权之下的人遭受不利时，才适用财产归并；除此之外，归并义务不发生。

<!-- source-p 322 -->
<a id="37.6.1.6"></a>**6.**尤其是，若解放出父权的儿子已依父亲的遗嘱安排取得利益，且所得并未超过父亲给他的财物，就不应要求他归并财产。

<!-- source-p 323 -->
<a id="37.6.1.7"></a>**7.**如果他通过遗赠取得半数遗产，或仅取得其依违遗嘱遗产占有本可取得的份额，也应认为不必强迫其归并财产。

<!-- source-p 324 -->
<a id="37.6.1.8"></a>**8.**尤利安还说，如果处于父权之下的兄弟在接受遗产占有后死亡，解放出父权的兄弟就应被要求归并财产，向死者的继承人归并相当于其兄弟仍在世时本应归并的数额。但如果自权继承人在接受遗产占有前死亡，裁判官应当保护其继承人，使其取得原指定继承人应得的份额，但不超过每位继承人的等额份额。尤利安说，在这种情形下，不得要求该继承人归并财产，因为遗产占有并未被接受。

<!-- source-p 325 -->
<a id="37.6.1.9"></a>**9.**裁判官命令以提供担保的方式进行财产归并。庞波尼乌斯说，应通过担保要式承诺提供该担保。我们还须考察能否以质物担保；庞波尼乌斯在《告示评注》第七十九卷写道，可以由保证人或以质物适当担保财产归并，我也赞同此说。

<!-- source-p 326 -->
<a id="37.6.1.10"></a>**10.**若兄弟无力提供担保，应为其份额指定一名管理人，将收回的钱款交其保管；只有在他归并自己的财产后，才可以领取所收回的钱款。若因其抗拒而拒绝给予诉权，之后他提出担保，便可恢复原有权利。

<!-- source-p 327 -->
<a id="37.6.1.11"></a>**11.**尽管裁判官告示谈到提供担保，庞波尼乌斯在《告示评注》第七十九卷仍写道，也可以通过实际归并财产来履行。他说，归并可以通过实际分割财产，也可以通过提供担保。因此，他应与兄弟分割自己的财产；即使没有提供担保，也算遵守告示。若他将某些财产分割、对另一些财产提供担保，也应认为已履行义务。但由于有些财产可能被隐匿，仅分割财产而未提供担保，并不足以履行归并义务。因此，如果各方对解放出父权者的财产范围没有争议，通过分割已足以完成归并；如果范围不明，且有人主张某些财产未纳入共同财产，就应当针对不确定部分提供担保。

<!-- source-p 328 -->
<a id="37.6.1.12"></a>**12.**如果解放出父权的儿子从父亲的财产中放弃的数额，恰好相当于自权继承人经财产归并本应取得的数额，也应认为解放出父权的儿子已充分归并。若他将父亲债务人的债权让与他人，或将庄园及其他财物按其应归并的份额交出，也同样如此。

<!-- source-p 329 -->
<a id="37.6.1.13"></a>**13.**如果他本应向两人归并，却只向一人归并，无论是以提供担保还是分割财产的方式，问题在于：应仅剥夺其六分之一的利益，还是应扣除整个三分之一。我认为，如果他出于抗拒而未提供担保，应剥夺其全部三分之一的诉权，因为没有为所有人提供担保，就不算已经提供担保。但若他因贫困而无法担保，则只应剥夺六分之一的诉权；不过，他可以通过补充担保，或以上述其他方式归并财产来补足，也可以为他指定一名管理人，确保其财物安全。毕竟，应考虑到未出于抗拒而未完成财产归并的人。

<!-- source-p 330 -->
<a id="37.6.1.14"></a>**14.**属于收养家庭的人也被要求归并财产；准确地说，并非由其本人，而是由收养父亲归并，前提是其愿意接受违遗嘱的遗产占有。当然，如果该收养父亲在请求遗产占有之前已将其解放出父权，则不必归并；神圣的两位兄弟皇帝在敕答中已明确说明此点。但只有在解放出父权并非出于诈欺时，养子才会因此使兄弟丧失财产归并利益。

<!-- source-p 331 -->
<a id="37.6.1.15"></a>**15.**军旅特有产或准军旅特有产无须向兄弟归并；多项敕令均规定，这些财产应作为预留给本人的财物。

<!-- source-p 332 -->
<a id="37.6.1.16"></a>**16.**我们还须考察，父亲因子女取得名望或地位而给付或尚欠的财物，是否也必须归并。帕皮尼安在《疑问集》第十三卷说，不应强迫归并，因为这类财物应作为因担任该职务所需费用而预留给本人。但如果该款项仍属债务，就应如此解释：不应只由取得该地位的人承担，而应作为所有继承人的共同债务。

<!-- source-p 333 -->
<a id="37.6.1.17"></a>**17.**某人被敌人俘获，父亲死亡后才返回；虽然父亲死亡时他身在敌国而无任何财产，仍准许其取得遗产占有，并须归并财产，具体而言，应归并其若未被俘获、在父亲死亡时本会拥有的财物。若他已从敌人手中赎回，并在父亲死亡时处于自由状态，也同样应当归并。

<!-- source-p 334 -->
<a id="37.6.1.18"></a>**18.**如果父亲遗赠给解放出父权的儿子，并规定在父亲死亡时给付，该儿子也必须将此项遗赠纳入财产归并。

<!-- source-p 335 -->
<a id="37.6.1.19"></a>**19.**若父亲指定儿子为继承人，并嘱托继承人于儿子死亡时设立遗嘱信托，问题在于：由于该遗嘱信托对儿子有利，是否应当归并？结果应视为该遗嘱信托是在父亲死亡后才设立；该儿子不必归并，因为父亲死亡时该遗嘱信托尚未归属于他。

<!-- source-p 336 -->
<a id="37.6.1.20"></a>**20.**解放出父权的儿子若从妻子处收取了嫁资，即使妻子先于他死亡，该嫁资也应从其应归并的财产中扣除。

<!-- source-p 337 -->
<a id="37.6.1.21"></a>**21.**依神圣的庇乌斯皇帝敕答，被收养的未适婚年龄者应得四分之一；若他请求其生父遗产的遗产占有，是否应归并这四分之一，尚须考察。问题在于，他是否将该四分之一的诉权留给自己的继承人。更可取的见解是，诉权会移转给继承人，因为这是一项人身诉权。因此，他也应为归并该四分之一提供担保；但只有在请求该四分之一的权利已经发生后才如此。若解放他的养父仍然在世，则应认为无需提供担保，因为要求归并尚为时过早：应给付四分之一的养父仍在世。

<!-- source-p 338 -->
<a id="37.6.1.22"></a>**22.**若负有财产归并义务的人有一名儿子，而该儿子拥有军旅特有产，原则上无须将该特有产归并。但如果其儿子在遗产占有权利人死亡前已经死亡，并且在该人死亡时仍有军旅特有产，是否必须归并？既然父亲无须通过遗产请求取得该特有产，就应当说必须归并；因为该财产并非此时才取得，而是没有被剥夺。进一步说，即使该儿子指定他为继承人、他尚未接受继承且儿子另有替补继承人，也应归并，因为他此时既未取得该特有产，也未将其转让。

<!-- source-p 339 -->
<a id="37.6.1.23"></a>**23.**即使某项财产并非属于他，但若其因恶意行为而使该财产不再属于自己，也应当归并。不过，这应仅指因恶意行为而不再属于他的财产；若他只是设法不让自己取得某物，该物不计入归并，因为他损害的是自己。

<!-- source-p 340 -->
<a id="37.6.1.24"></a>**24.**财产归并份额应作如下计算。假设有两名儿子仍处于父权之下，另有一名解放出父权的儿子拥有三百；他应向兄弟归并二百，自己保留一百。尽管他通常并非财产归并义务所及之人，他也应计入份额分配。若有两名解放出父权的儿子各自拥有三百，另有两名儿子处于父权之下，则每名解放者应向每名仍处于父权下的儿子归并一百，并各自保留一百；解放者彼此之间无须归并。嫁资也应按同样方式归并；凡进行归并者，在计算份额时也应将自己计入人数。
