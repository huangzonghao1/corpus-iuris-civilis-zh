## 13.7.0　论质权之诉及其反诉（*De pigneraticia actione vel contra*）

### <a id="13.7.1"></a>13.7.1　乌尔比安《评萨宾》第四十卷

<a id="13.7.1.pr."></a>

**序言（pr.）** 质权的设立不只通过交付，也可以仅凭当事人的合意；即使质物尚未交付，质权也能成立。〔底本作 *tradidione*，疑为 *traditione*；据上下文译作“交付”，待校。〕

<a id="13.7.1.1"></a>

**1.** 因此，如果质权仅凭合意成立，我们应当考察：某人仿佛要交付黄金作为质物，却交付了铜器，黄金是否因此受质权约束。结论应是黄金受质权约束，而铜器不受约束，因为双方并未就铜器达成合意。

<a id="13.7.1.2"></a>

**2.** 但是，如果某人在交付铜器作质时，声称它是黄金，并以此作为质物交付，就应考察铜器是否已受质权约束；也可以说，由于双方就该有体物达成了合意，它似乎已经成为质物。我认为后一种看法较为可取。不过，交付人仍应承担质权反诉责任，此外还应对其所犯的诈害罪（*stellionatus*）负责。

### <a id="13.7.2"></a>13.7.2　庞波尼《评萨宾》第六卷

如果债务人已经出售并交付质物，而你又借钱给他，他用这笔钱偿还了原先接受质物的债权人；你与他约定，已经售出的该物再作为你的质物，那么可以确定，你并未取得任何权利，因为你接受他人之物作为质物。买受人由此取得不再负担质权的物；你出资使质权解除，并不影响这一点。

### <a id="13.7.3"></a>13.7.3　庞波尼《评萨宾》第十八卷

如果你准备从债务人处当面收款，便把质物交还给他；他却把质物从窗户扔给一个人，而那人是他特意安排在那里接物的，拉贝奥说，你可以对债务人提起盗窃之诉和出示物之诉。如果你提起质权反诉，债务人以你已将质物交还给他为由提出抗辩，则可提出欺诈和诡计的再抗辩；因为这并非交还质物，而是债务人以欺骗手段将其夺走。

### <a id="13.7.4"></a>13.7.4　乌尔比安《评萨宾》第四十一卷

如果当事人从一开始或后来约定可以出售质物，不仅出售有效，买受人也开始取得该物所有权。即使当事人没有约定出售质物，我们仍依此规则处理：只要没有约定不得出售，债权人就可以出售。但如果当事人约定不得出售，债权人仍予出售，就应承担盗窃责任；除非债务人已被三次催告付款而仍未履行。

### <a id="13.7.5"></a>13.7.5　庞波尼《评萨宾》第十九卷

此规则适用，无论当事人完全约定不得出售，还是出售时在价格、条件或地点方面违反约定。

### <a id="13.7.6"></a>13.7.6　庞波尼《评萨宾》第三十五卷

<a id="13.7.6.pr."></a>

**序言（pr.）** 即使你已约定可以出售作为质物的土地，也不能因此强迫你出售；即使提供质物的债务人已经无清偿能力，结论仍然如此，因为该约定是为你的利益作出的。然而，阿提利基努斯认为，在特定情形下应强制债权人出售：如果债务额远低于质物价值，而且质物现在能卖得比以后更高呢？较好的意见是，提供质物的人可以出售，并以所得价款清偿债务；不过，如果质物是动产，债务人须先向债权人提供充分担保，确保其不受损害，债权人才有义务出示质物。强迫债权人违背意愿出售，实在过于苛刻。

<a id="13.7.6.1"></a>

**1.** 如果债权人以高于债务的价格出售质押土地，并将所得价款用于放债，就应向提供质物的人支付该笔钱的利息；如果债权人自己使用了这笔钱，也应支付利息。如果他将钱款存放起来，则不负支付利息的义务。

### <a id="13.7.7"></a>13.7.7　保罗《箴言集》第二卷

如果债权人迟延返还寄存于其处的剩余价款，也应被强制向债务人支付因迟延产生的利息。

### <a id="13.7.8"></a>13.7.8　庞波尼《评萨宾》第三十五卷

<a id="13.7.8.pr."></a>

**序言（pr.）** 如果我为作为质物交给我的奴隶或土地支付了必要费用，我不仅有权留置，也有权提起质权反诉。比如，奴隶生病时我支付了医生费用，但奴隶后来死亡；又比如，我支撑或修缮了公寓楼，但它后来被烧毁，且我已无任何质物可以留置。

<a id="13.7.8.1"></a>

**1.** 如果数名奴隶作为质物交付，债权人以确定价格出售其中一些，并承诺承担追夺担保责任，而其债权已获清偿，那么债权人可以留置其余奴隶，直到有人向他提供担保，确保他不会因已承诺的追夺责任而受损。

<a id="13.7.8.2"></a>

**2.** 如果债务人的一名继承人清偿了自己应负的份额，作为质物的整个财产仍可以出售，正如债务人本人只清偿部分债务时一样。

<a id="13.7.8.3"></a>

**3.** 如果我约定分三期、分别于一年后、两年后和三年后取得三十，并接受质物；又约定每一期未在各自到期日支付时，我便可出售质物，那么在全部分期的到期日尚未届至前，我不得出售质物，因为这些措辞是指全部分期；而且，在全部到期日届至前，不能说某一期款项已经逾期未付。但所有分期的到期日都已届至后，即使只欠一期未付，也可以出售质物。反之，如果约定的措辞是“如有任何一笔钱未在其到期日支付”，则债权人立即取得依约行事的权利。

<a id="13.7.8.4"></a>

**4.** 质物出售的约定应以对物方式订立，使所有相关人均受其约束；不过，即使约定只涉及债权人本人，除非另有相反约定，其继承人也有权出售。

<a id="13.7.8.5"></a>

**5.** 依约可以出售质物时，不仅可以因本金未付而出售，也可以因其他欠款出售，例如利息或为质物支出的费用。

### <a id="13.7.9"></a>13.7.9　乌尔比安《评告示》第二十八卷

<a id="13.7.9.pr."></a>

**序言（pr.）** 如果债务人把他人之物交给我作质物，或者以欺诈手段处置质物，应当认为可以提起质权反诉。

<a id="13.7.9.1"></a>

**1.** 质物的设定不仅可以担保金钱，也可以基于其他原因；例如，某人交付质物，是为了让他人为自己提供保证。

<a id="13.7.9.2"></a>

**2.** 严格而言，质物（*pignus*）是指移转给债权人的物；抵押（*hypotheca*）则是指物及占有均未移转给债权人的情形。

<a id="13.7.9.3"></a>

**3.** 欲使质权之诉发生，所有债款都必须已经清偿，或者以其他方式使债权人得到满足。所谓得到满足，是指按债权人所希望的方式获得保障，即使钱款并未实际支付也包括在内：债权人可以要求另以质物担保，使其放弃原质物；也可以要求提供保证人、更换债务人、支付某项价款，或者仅订立协议。一般而言，每当债权人愿意放弃质物，只要他已按自己希望的方式取得保障，即使因此受骗，也应视为已得到满足。

<a id="13.7.9.4"></a>

**4.** 将他人之物交付作质的人，在钱款清偿后也可以提起质权诉讼。

<a id="13.7.9.5"></a>

**5.** 某人在清偿前便提起质权诉讼，虽属不当，但如果他在诉讼中提出付款，仍应取得质物以及其利益损失的赔偿。

### <a id="13.7.10"></a>13.7.10　盖尤斯《评行省告示》第九卷

如果他准备的不是清偿，而是以其他方式使债权人得到满足，例如愿意提供一名替代债务人，这对他并无帮助。

### <a id="13.7.11"></a>13.7.11　乌尔比安《评告示》第二十八卷

<a id="13.7.11.pr."></a>

**序言（pr.）** 如果债务人与债权人就债务本身的诉讼已经系属，或者保证人已被起诉，就不应认为债务已经清偿。

<a id="13.7.11.1"></a>

**1.** 债务更新后，质权即告消灭；除非当事人约定恢复质权。

<a id="13.7.11.2"></a>

**2.** 如果我收取质物，本打算向你借出钱款，却最终没有借出，我仍须承担质权之诉的责任，尽管尚未发生任何清偿。将钱款记入账内却未实际交付、设立质权所依据的条件未成就，或者当事人订立了应予遵守的不请求给付协议，也都适用相同规则。

<a id="13.7.11.3"></a>

**3.** 如果质权仅担保本金或利息，清偿其所担保的债务后，即可以提起质权之诉。无论利息是否列入要式口约，只要质权也担保利息，在利息仍有未付部分时，质权之诉就不成立。超过法律许可限额而允诺的利息则属另一情形，因为这类利息完全违法。

<a id="13.7.11.4"></a>

**4.** 如果债权人有数名继承人，而其中一人收到了其应得部分，其他债权人继承人不应因此受损；只要债务人向他们提出其已付给共同继承人的金额，他们仍可以出售整块土地。这一意见并非毫无道理。

<a id="13.7.11.5"></a>

**5.** 所谓钱款已清偿，不仅包括向质物所担保的债权人本人付款，也包括经其同意向他人付款，或者向其继承人、代理人、受命追收款项的奴隶付款。因此，如果你承租了一栋公寓楼，把其中一部分转租给我，而我把租金付给你的出租人，我可以对你提起质权诉讼；因为尤利安写道，可以向该出租人付款。如果我把一部分租金付给你，另一部分付给出租人，也应作相同处理。不过，我带入或带来的物品，仅以我所承租房间的租金数额为限而受质权约束；不能认为双方曾约定，以我的琐细动产担保整栋公寓楼的全部租金。还应认为，我与房屋所有人之间也默示订有约定：转租人所订的约款并不使房屋所有人受益，只有他自己订立的约定才使其受益。

<a id="13.7.11.6"></a>

**6.** 通过自由人，我们通常不能为自己取得质权；甚至通过代理人或监护人，也往往不能取得。因此，应由他们本人承担质权之诉的责任。即使我们的皇帝曾规定可以通过自由人取得占有，也不会改变这一点：该规定的意义在于，我们可以通过代理人或监护人取得交给我们作质物的占有；但自由人并非总能为我们取得质权本身。

<a id="13.7.11.7"></a>

**7.** 如果我的代理人或监护人交付质物，他本人可以提起质权诉讼。对代理人而言，只有在他受命交付质物时，结论才适用（底本此处将 *fuerit* 置于引号中，照录其特殊形式）。

### <a id="13.7.12"></a>13.7.12　盖尤斯《评行省告示》第九卷

或者，委托人曾将全部财产交由代理人管理；该委托人平时惯常以质物担保借入钱款。

### <a id="13.7.13"></a>13.7.13　乌尔比安《评告示》第三十八卷

<a id="13.7.13.pr."></a>

**序言（pr.）** 如果债权人出售质物时与买受人约定：债务人若把价款付给买受人，就可以取回自己的物，尤利安曾写道，敕答也确认，债权人因该约定而应依质权之诉承担责任，并须将买卖之诉让与债务人，使其得以对买受人起诉。不过，债务人本人也可以提起所有物返还之诉，或者对买受人提起事实之诉。

<a id="13.7.13.1"></a>

**1.** 本诉涉及故意、过失，如同使用借贷之诉；也涉及保管责任，但不涉及不可抗力。

### <a id="13.7.14"></a>13.7.14　保罗《评告示》第二十九卷

因此，债权人应当承担勤勉家父通常在处理自己事务时所承担的注意义务。

### <a id="13.7.15"></a>13.7.15　乌尔比安《评告示》第二十八卷

债权人交还质物时，应向债务人承诺自己未实施欺诈；如果质物是不动产，也应就该物的权利作出保证，以免债权人停止行使地役权后，地役权因不行使而丧失。

### <a id="13.7.16"></a>13.7.16　保罗《评告示》第二十九卷

<a id="13.7.16.pr."></a>

**序言（pr.）** 如果法律并不禁止，监护人将未适婚人的物交付作质，应当予以承认，当然以借款是为未适婚人的利益而取得为限。对于未成年人或精神失常者的保佐人，也作相同处理。

<a id="13.7.16.1"></a>

**1.** 可以确定，债权人有权提起质权反诉。因此，如果债务人交付他人之物、已经质押给他人之物，或已为公共债务设定担保之物，债务人应承担责任，即使其行为同时构成诈害罪亦然。问题是：只有债务人明知时才承担责任，还是不知情也要承担？就刑事罪责而言，不知情可以免责；但就质权反诉而言，不知情不能免责，正如马尔凯卢斯在《学说汇纂》第六卷所写。不过，如果债权人明知而接受他人之物、已负担他人债务之物或有瑕疵之物，就不得对债务人提起质权反诉。

<a id="13.7.16.2"></a>

**2.** 缴纳地租的土地也可以作为质物；地上权也可以，因为如今地上权人享有准用诉权。

### <a id="13.7.17"></a>13.7.17　马尔基安《论抵押公式》单卷本

当然，神圣的塞维鲁皇帝和安敦尼皇帝曾作出敕答，规定土地仍应负担该项义务，而不减少其地租收入。（原文 *sine deminutione mercedis soli obligabitur* 的句法和具体所指不甚明确。）

### <a id="13.7.18"></a>13.7.18　保罗《评告示》第二十九卷

<a id="13.7.18.pr."></a>

**序言（pr.）** 如果约定将我的债务人对你的债权作为质物，该约定应受裁判官保护，使你可以追收该款，也使债务人在我对他起诉时得到保护。因此，如果该项债权是金钱债权，你收取该款后应将其抵充我欠你的债务；如果该项债权是对某一有体物的权利，你所取得的该物便作为质物。

<a id="13.7.18.1"></a>

**1.** 如果质押的只是裸所有权，后来增加的用益权也将成为质物；因河流冲积而增加的部分亦同。

<a id="13.7.18.2"></a>

**2.** 质押土地即使被出售，质权仍然存续，因为土地连同其负担一并移转；奴隶女在出售后所生的孩子，也适用相同规则。

<a id="13.7.18.3"></a>

**3.** 如果约定森林作为质物，卡西乌斯认为，用该森林木材建造的船舶不属于质物，因为木材与船舶是不同之物。因此，他说，设定质权时应明确加上“从该森林制成或由其造出的物品”。

<a id="13.7.18.4"></a>

**4.** 如果奴隶将特有财产中的物交付作质，只要他获准自由管理特有财产，就应承认该质权；因为他也有权处分这些物。

### <a id="13.7.19"></a>13.7.19　马尔基安《论抵押公式》单卷本

对于家子，也应作相同理解。

### <a id="13.7.20"></a>13.7.20　保罗《评告示》第二十九卷

<a id="13.7.20.pr."></a>

**序言（pr.）** 经所有人同意，他人之物可以设定质权；即使未经所有人知情而设定，只要所有人事后追认，质权也有效。

<a id="13.7.20.1"></a>

**1.** 同一物同时质押给数人时，各债权人的地位相同。

<a id="13.7.20.2"></a>

**2.** 如果因债权人的原因而未能向其清偿，债务人可以正当地提起质权之诉。

<a id="13.7.20.3"></a>

**3.** 有时即使钱款已经清偿，也应阻却质权之诉；例如，债权人从债务人处买下了自己的质物。

### <a id="13.7.21"></a>13.7.21　保罗《简编》第六卷

房屋作为质物交付时，其占地也受质权约束，因为占地是房屋的一部分；反过来，建筑物的权利也随土地法则而定。

### <a id="13.7.22"></a>13.7.22　乌尔比安《评告示》第三十卷

<a id="13.7.22.pr."></a>

**序言（pr.）** 如果质物被盗，债权人提起盗窃之诉，帕皮尼安确认，债权人所取得的一切都应抵充债务；即使盗窃是因债权人的过失而发生，结论也正确。债权人通过债权返还之诉取得的款项，更应作相同处理。不过，如果债务人通过盗窃之诉或债权返还之诉向债权人给付，是否也应抵充债务？一贯的意见和学说认为，债务人依盗窃之诉所付的款项无需返还；帕皮尼安在《疑义集》第九卷中也这样写道。

<a id="13.7.22.1"></a>

**1.** 同一位帕皮尼安还说，如果债权人因胁迫而将质押奴隶交还给债务人，而他原先是善意接受该奴隶作质，那么债权人若提起胁迫之诉并取得四倍赔偿，无须返还所获款项，也无须将其抵充债务。

<a id="13.7.22.2"></a>

**2.** 如果掠夺性占有人将某物交付作质，也可以提起质权反诉请求孳息，尽管孳息并不归其所有；因为掠夺性占有人仍在的孳息可以通过所有物返还之诉追回，已经消费的孳息可以通过债权返还之诉请求返还。因此，债权人曾是善意占有人这一点，对他有利。

<a id="13.7.22.3"></a>

**3.** 质物出售后，曾请求以借用或租赁方式继续占有质物的债务人，如果不返还占有，应承担质权反诉的责任。

<a id="13.7.22.4"></a>

**4.** 债权人出售质物时承诺承担双倍追夺担保；此后买受人因追夺请求起诉债权人，债权人又被判败诉。债权人能否通过质权反诉向债务人追偿？如果债权人出售时没有欺诈或过失，而且处理方式符合勤勉家父的标准，可以认为能够追偿。反之，如果这种出售未给债权人带来任何收益，而他只是以尽可能高的价格出售，即使没有作出双倍担保也会如此办理，那么他就无权追偿。

### <a id="13.7.23"></a>13.7.23　特里丰尼努斯《论争集》第八卷

债权人从债务人处所得，不得超过债务总额。但是，如果利息曾以要式口约允诺，债权人因质物被追夺而在五年后向买受人返还价款，即使如此，仍可向债务人请求这段期间的利息，因为既已证明债权人并未保有任何给付，该款就不得被取走。反之，如果债权人只支付了本金，就应以欺诈抗辩驳回其利息请求，因为他已使用从买受人处取得的价款。

### <a id="13.7.24"></a>13.7.24　乌尔比安《评告示》第三十卷

<a id="13.7.24.pr."></a>

**序言（pr.）** 有人曾精当地向我提出问题：如果债权人请求皇帝准许其占有质物，之后该物又被他人追夺，他是否享有质权反诉？看来，质权关系已经终结，当事人也已退出原合同。实际上，应给予他准用买卖之诉，就如同该物已作为清偿交付给他，使其债权在债务数额或其利益范围内得到满足。债权人也可以在债务人以质权诉讼或其他事由起诉时主张抵销。

<a id="13.7.24.1"></a>

**1.** 如果债务人向债权人支付了不合格的钱币，能否视为已经清偿，进而提起质权之诉？问题在于：此人既不能提起质权之诉，也不能因此免责，因为不合格的钱币不能使付款人免责；债权人当然应当退还这些不合格钱币。

<a id="13.7.24.2"></a>

**2.** 如果债权人出售质物的价格高于债务额，却尚未向买受人收取价款，债权人能否被质权诉讼起诉，要求返还超额部分？还是应等待买受人付款，或者将针对买受人的诉权让与债务人？我认为，不应强迫债权人先行付款；债务人应当等待，或者在不愿等待时，由债权人将针对买受人的诉权让与他，但风险仍由出卖人承担。如果债权人已经收到钱款，就应返还超额部分。

<a id="13.7.24.3"></a>

**3.** 在质权诉讼中，如果债权人不当处置质物，或使奴隶受伤，也应承担责任。但如果债权人因奴隶的不法行为而惩戒、拘束奴隶，或将其交给行省长官或总督，就不应认为债权人应依质权之诉负责。因此，如果债权人使女奴卖淫，或迫使她做其他不被允许之事，她所负的质权立即解除。

### <a id="13.7.25"></a>13.7.25　乌尔比安《评告示》第三十一卷

如果债权人使作为质物的奴隶掌握某种技艺：若奴隶原已掌握该技艺，或这是经债务人同意进行的，便有权提起质权反诉；若两种情况都不存在，但该技艺属于必要技能，也有质权反诉。不过，不得因此使债务人被迫按费用数额放弃奴隶。正如债权人不得疏忽履行其应负的故意和过失责任，他也不得把质物变得难以由债务人赎回。例如，某人把一片大树林作为质物交付；他几乎无力赎回，更谈不上开垦。你接受质物后却将土地开垦，使其价值大增。否则，要求我另寻其他债权人、强迫我出售原本想赎回的财产，或者因我贫困而迫使我把财产留给你，都不公平。因此，法官应居中审酌，既不应听任奢纵的债务人，也不应迁就苛刻的债权人。

### <a id="13.7.26"></a>13.7.26　乌尔比安《论争集》第三卷

<a id="13.7.26.pr."></a>

**序言（pr.）** 如果官员基于任何原因命令将某人置于占有中，并因此设立质权，这并不奇怪；我们的皇帝与其父皇也曾多次作出敕答，确认遗嘱同样可以设立质权。

<a id="13.7.26.1"></a>

**1.** 应当知道，只有在依官员命令实际取得占有后，才成立由官员命令设定的质权。

### <a id="13.7.27"></a>13.7.27　乌尔比安《意见集》第六卷

有人向债权人请求借款，但债务人手头没有钱，便交给债权人一些黄金制品，让债权人把它们放在另一名债权人处作为质物。如果收取黄金制品的人已经在清偿后取回这些制品，并仍持有它们，就应命令其出示；如果这些制品仍在该债权人的债权人处，则应认为它们是经所有人同意而被设定担保的。不过，所有人可以对自己的债权人提起独立诉讼，请求其将这些物解除担保后交还。

### <a id="13.7.28"></a>13.7.28　尤利安《学说汇纂》第十一卷

<a id="13.7.28.pr."></a>

**序言（pr.）** 接受质物的债权人丧失其占有后，通过塞尔维安之诉请求该物，并取得诉讼标的估价款的，如果债务人随后请求返还同一物，应以抗辩驳回；除非债务人向债权人提出偿还其代为支付的款项。

<a id="13.7.28.1"></a>

**1.** 如果奴隶以特有财产债务为由接受质物，债务人可以对奴隶主人提起质权之诉。

### <a id="13.7.29"></a>13.7.29　尤利安《学说汇纂》第四十四卷

如果你善意买下他人之物，将其交给我作质，并请求以容忍占有方式继续持有；后来该物的所有人指定我为继承人，质权便会消灭，只剩下容忍占有的请求。因此，你的取得时效将被中断。（底本写作 *desinet*，随即在引号中列出 *desinit*，照录此异文。）

### <a id="13.7.30"></a>13.7.30　保罗《阿尔芬努斯〈学说汇纂〉节编》第五卷

某人借钱给一名木筏经营者；到期未收到钱款，便自行扣留河上的木筏。后来河水上涨，把木筏冲走。答复是：如果债权人未经木筏经营者同意而扣留木筏，木筏灭失的风险由债权人承担；但如果债务人自愿同意债权人扣留，债权人只对过失负责，不对不可抗力负责。

### <a id="13.7.31"></a>13.7.31　阿非利加努《问题集》第八卷

如果作为质物交付的奴隶偷了债权人的东西，债务人可以选择将该奴隶交付以承担诺克萨责任。但如果债务人明知奴隶是窃贼仍将其交付作质，即使债务人愿意将奴隶交给我承担诺克萨责任，我仍可提起质权之诉，要求债务人使我免受损失。尤利安说，如果受寄托或借用的奴隶偷窃，也应遵循同一规则。

### <a id="13.7.32"></a>13.7.32　马尔基安《规则集》第四卷

对于将他人之物交付作质的债务人，即使债务人有清偿能力，债权人仍可以对其提起质权反诉。

### <a id="13.7.33"></a>13.7.33　马尔基安《论抵押公式》单卷本

债务人清偿钱款后，可以通过质权之诉请求取回 *antixrysin*（底本如此拼写；该术语的规范拼写及所指待核），因为既然这也属于质物，他便可以使用这一称谓。

### <a id="13.7.34"></a>13.7.34　马尔凯卢斯《答复集》单卷本

提提乌斯曾借钱给塞姆普罗尼乌斯，并为此接受质物。由于债务未获清偿，债权人将要出售质物，债务人便请求债权人以特定价格买下土地。请求获准后，债务人寄出一封信，声明已将土地出售给债权人。我问：债务人能否通过提出应付本金及利息而撤销这项出售？马尔凯卢斯答复：按照所述事实，不能撤销。

### <a id="13.7.35"></a>13.7.35　弗洛伦提努《制度论》第八卷

<a id="13.7.35.pr."></a>

**序言（pr.）** 如果债务人既欠本金也欠利息，且以质物担保，那么无论出售质物取得多少价款，都应先用于清偿当时已经到期的利息；如有余额，再抵充本金。债务人若明知自己清偿能力不足，却选择希望以何种债务解除质权，就不应听从。

<a id="13.7.35.1"></a>

**1.** 质权不移转债务人的所有权，只将占有移转给债权人；不过，债务人仍可基于容忍占有或租赁而使用自己的物。

### <a id="13.7.36"></a>13.7.36　乌尔比安《评告示》第十一卷

<a id="13.7.36.pr."></a>

**序言（pr.）** 有人以铜冒充黄金交给债权人作质，应承担何种责任？在这种情形下，萨宾正确地写道：如果先交付黄金，后来再以铜调换，就构成盗窃责任；如果交付时便以铜冒充黄金，其行为虽可耻，却不构成盗窃。我认为，此时也可以提起质权诉讼，庞波尼也这样写道。此外，按照多次敕答，还应依特别程序以诈害罪名予以惩处。

<a id="13.7.36.1"></a>

**1.** 如果有人明知而将他人之物交给我作质，或者将已质押给别人的物再次质押给我，却没有告知我，也应以同一罪名惩处。不过，如果该物价值很高，而第二次质押所担保的金额很小，就应认为不仅不构成诈害罪，也不发生质权反诉或欺诈之诉；因为第二顺位接受质物的人并未受骗或遭受损失。

### <a id="13.7.37"></a>13.7.37　保罗《评普劳提乌斯》第五卷

如果我把交付给我的质物出租给其所有人，我仍通过租赁保有占有；因为债务人承租之前并未占有该物：我仍有保有占有的意思，而承租人并无取得占有的意思。

### <a id="13.7.38"></a>13.7.38　莫德斯蒂努《差异论》第一卷

未适婚人接受质物时，因其可能承担质权之诉的责任，必须取得监护人的授权。

### <a id="13.7.39"></a>13.7.39　莫德斯蒂努《答复集》第四卷

盖尤斯·塞尤斯因借款，将自己的土地交给卢基乌斯·提提乌斯作质。后来双方约定，债权人可以在一定期限内占有该质物，以抵偿自己的债权。期限届满前，债权人安排遗嘱时，规定由其一名儿子取得该土地，并补充说“这是我从卢基乌斯·提提乌斯处买来的”；事实上他并未买下土地。遗嘱由他人共同见证，债务人盖尤斯·塞尤斯也在其中签名。我问：既然没有提出任何买卖文书，只有债权人在一定期限内取得土地孳息的约定，债务人签署债权人遗嘱这一事实是否会对他造成不利。赫伦尼乌斯·莫德斯蒂努答复：所述债务人签署了债权人的遗嘱、而遗嘱中说债权人已买下质物，这一事实不影响质权契约。

### <a id="13.7.40"></a>13.7.40　帕皮尼安《答复集》第三卷

<a id="13.7.40.pr."></a>

**序言（pr.）** 债务人向债权人买回自己交付作质的物，属于无效买卖，因为不可能买卖自己的物。即使他以低价买回质物，并请求返还质物或主张其所有权，只要他没有提出清偿全部债务，债权人就不必返还占有。

<a id="13.7.40.1"></a>

**1.** 仍处于父亲权力之下的债务人之子，想用特有财产中的钱从父亲的债权人处买回质物，同样属于无效买卖。因此，如果债务人的释主依遗嘱外继承规则取得其财产的占有，释主将取得所有权的一部分；因为儿子用父亲财产支付的价款使质权获得清偿。

<a id="13.7.40.2"></a>

**2.** 清偿钱款后，债权人应返还其实际占有的质物，不必再承担其他责任。因此，如果债权人在此期间把质物再次交付作质，所有人清偿第二项质权所担保的债务后，既不能向债权人追索，也不能留置质物。

### <a id="13.7.41"></a>13.7.41　保罗《疑义集》第三卷

你将他人之物交付作质，后来成为该物所有人，债权人便可以提起准用质权之诉。如果我继承了提提乌斯，而提提乌斯未经我的同意便将我的物质押给别人，则不能作相同处理；此时不应允许债权人追及质物，仅仅因为所有人与欠款人是同一人，也不足以使准用质权之诉成立。但是，如果双方曾约定设定质权，那么债务人以自己所作的虚假陈述为由抗辩、阻碍准用之诉，就属于不当抵抗。

### <a id="13.7.42"></a>13.7.42　帕皮尼安《答复集》第三卷

债权人依有关质物的诉讼，应被判令返还超出债务的价款及利息；债权人若想把买受人指定为给付人，不应予以听从，因为在依其行为发生的出售中，债权人处理的是自己的事务。

### <a id="13.7.43"></a>13.7.43　斯凯沃拉《学说汇纂》第五卷

<a id="13.7.43.pr."></a>

**序言（pr.）** 某人将一块空地质押给债权人，并把购买该地的文书交给他。此人打算在空地上建造房屋，却因邻人就地块宽度提出争议而无法证明自己的主张；于是他请求债权人出示自己交付的文书。债权人未予出示，债务人只得建造较小的房屋，因而遭受损失。有人问：如果债权人请求给付钱款或主张质物所有权，债务人提出欺诈抗辩后，法官是否应考虑这项损失。答复是：如果债权人没有故意隐匿文书、借此使债务人落入陷阱，那么债务人清偿后可以提起质权之诉；但如果债权人曾故意如此，那么债务人即使尚未清偿，也可以请求债权人赔偿其利益损失。

<a id="13.7.43.1"></a>

**1.** 提提乌斯从盖乌斯·塞尤斯处借入金钱，并以若干皮囊作质。塞尤斯将皮囊存放在仓库期间，粮食供应署派来的百夫长把皮囊取去用于粮食供应；后来，经债权人盖乌斯·塞尤斯催促，皮囊才被取回。我问：因这些操作造成的耗损，应由债务人提提乌斯还是债权人塞尤斯承担？答复是：依所述情形，因该事由发生的耗损，债权人不承担责任。
