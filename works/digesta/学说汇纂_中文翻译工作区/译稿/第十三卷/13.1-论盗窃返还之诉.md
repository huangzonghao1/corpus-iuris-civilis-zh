# 第十三卷

<a id="1"></a>
<a id="13.1"></a>

## 13.1.0　论盗窃返还之诉（*De condictione furtiva*）

### <a id="13.1.1"></a>13.1.1　乌尔比安《评萨宾》第十八卷

**正文** 对于被盗之物，只有所有权人享有盗窃返还之诉（*condictio furtiva*）。

### <a id="13.1.2"></a>13.1.2　庞波尼乌斯《评萨宾》第十六卷

**正文** 如果精神失常者或婴幼儿成为必然继承人，他们也会因盗窃原因而负返还之诉的债务，尽管不得对他们提起该诉。

### <a id="13.1.3"></a>13.1.3　保罗《评萨宾》第九卷

**正文** 如果基于盗窃原因请求返还一名奴隶，可以确定，诉讼估价应以原告的利益为准。例如，该奴隶被指定为继承人，而所有权人面临失去遗产的风险，估价便应考虑此项利益。尤利安也这样写道。他还说，如果原告就一名已经死亡的人请求返还，应当取得遗产的价值。

### <a id="13.1.4"></a>13.1.4　乌尔比安《评萨宾》第四十一卷

**正文** 如果奴隶或家子实施盗窃，应对所有权人提起返还之诉，但仅限于实际归于他的利益；对于其余部分，所有权人可以将奴隶交付以承担诺克萨责任。

### <a id="13.1.5"></a>13.1.5　保罗《评萨宾》第九卷

**正文** 可以基于盗窃原因对家子提起返还之诉；因为该项返还之诉从不使实施盗窃者以外的人承担责任，除非其为实施者的继承人。

### <a id="13.1.6"></a>13.1.6　乌尔比安《告示评注》第三十八卷

**正文** 因此，即使有人以帮助或教唆的方式参与盗窃，也不负返还之诉责任，尽管其须承担盗窃之诉的责任。

### <a id="13.1.7"></a>13.1.7　乌尔比安《评萨宾》第四十二卷

<a id="13.1.7.pr."></a>

**序言（pr.）** 如果已就窃贼所致损害达成和解，返还之诉确实不因此受阻；因为和解消灭的是盗窃之诉，而不是返还之诉。

<a id="13.1.7.1"></a>

**1.** 盗窃之诉请求法定罚金，返还之诉则请求返还物本身。因此，盗窃之诉不会因返还之诉而消灭，返还之诉也不会因盗窃之诉而消灭。被盗者因此享有盗窃之诉、返还之诉和所有物返还之诉，也享有出示之诉。

<a id="13.1.7.2"></a>

**2.** 盗窃物返还之诉追索的是物本身，因此也使窃贼的继承人承担责任；无论被盗奴隶仍然活着，还是已经死亡，均同。即使被盗奴隶是在窃贼的继承人处死亡，或者并非在其处死亡、而是在窃贼死亡后死亡，也应当说，对继承人的返还之诉仍然存续。我们对继承人所说的规则，同样适用于其他概括继受人。

### <a id="13.1.8"></a>13.1.8　乌尔比安《告示评注》第二十七卷

<a id="13.1.8.pr."></a>

**序言（pr.）** 对于被盗之物，返还之诉直接针对物本身提起；但该诉是否仅在物仍然存在时才可提起，还是即使物已不复存在也可提起？如果窃贼已经提出返还该物，当然不得再提起返还之诉；如果他没有提出返还，返还之诉仍可就该物的价值继续进行，因为物本身已无法交付。

<a id="13.1.8.1"></a>

**1.** 如果基于盗窃原因请求返还某物，应以何时的价值估价，尚有疑问。不过，通说认为，应以该物曾经达到最高价值的时点为准；尤其是窃贼不能因交付已经贬值的物而免责，因为窃贼始终被视为处于迟延状态。

<a id="13.1.8.2"></a>

**2.** 最后还应当说，本项诉讼也包括孳息。

### <a id="13.1.9"></a>13.1.9　乌尔比安《告示评注》第三十卷

**正文** 在基于盗窃原因提起的返还之诉中，只要我们是唯一继承人，就应承担全部责任，而不以实际归于我们的份额为限；如果是共同继承人，则各继承人仅按其继承份额承担责任。

### <a id="13.1.10"></a>13.1.10　乌尔比安《告示评注》第三十八卷

<a id="13.1.10.pr."></a>

**序言（pr.）** 无论窃贼属于现行犯还是非现行犯，均可对其提起返还之诉。但是，只有在所有权人未能发现并取回占有的情况下，现行犯窃贼才负返还之诉责任；否则，所有权人一旦取回占有，便不得再对任何窃贼提起返还之诉。因此，尤利安为了说明对现行犯窃贼提起返还之诉何以成立，设想窃贼被发现时，已经杀死、毁坏或倾倒了其所窃取之物。

<a id="13.1.10.1"></a>

**1.** 尤利安在《学说汇纂》第二十二卷中指出，对因暴力劫掠之诉（*actio vi bonorum raptorum*）负有责任的人，也可以提起返还之诉。

<a id="13.1.10.2"></a>

**2.** 只要所有权人尚未通过自己的行为丧失该物的所有权，返还之诉就仍然可以提起。因此，如果所有权人已经让与该物，就不得再提起返还之诉。

<a id="13.1.10.3"></a>

**3.** 因此，凯尔苏斯在《学说汇纂》第十二卷中写道：如果所有权人将被盗之物无条件遗赠给窃贼，继承人不得对窃贼提起返还之诉。即使遗赠对象不是窃贼本人，结论也相同，返还之诉仍然不适用，因为所有权已因遗嘱人——也就是所有权人——的行为而转移。

### <a id="13.1.11"></a>13.1.11　保罗《告示评注》第三十九卷

**正文** 受遗赠人也不得提起返还之诉；因为该项返还之诉属于被盗者或其继承人。但是，受遗赠人可以向窃贼提起所有物返还之诉，请求返还遗赠物。

### <a id="13.1.12"></a>13.1.12　乌尔比安《告示评注》第三十八卷

<a id="13.1.12.pr."></a>

**序言（pr.）** 因此，马尔凯卢斯在《学说汇纂》第七卷中作出了精当界定。他说：“如果被盗之物仍归你所有，你可以提起返还之诉。”即使你并非因自己的行为而丧失所有权，也同样可以提起返还之诉。

<a id="13.1.12.1"></a>

**1.** 因此，他又精当地指出，在共有物上，关键在于：究竟是你主动提起共有物分割之诉，还是你作为被告应诉。若你主动提起共有物分割之诉，便丧失返还之诉；若你是应诉的一方，则仍保有返还之诉。

<a id="13.1.12.2"></a>

**2.** 涅拉提乌斯在《札记》中记载，阿里斯托认为：质权人所质押的物被盗时，可以提起不确定给付之诉（*condictio incerti*）。

### <a id="13.1.13"></a>13.1.13　保罗《告示评注》第三十九卷

**正文** 福尔基尼乌斯说，由被盗白银制成的杯子可以通过返还之诉请求返还。因此，在针对杯子提起的返还之诉中，还应计入窃贼出资所制成的雕饰价值；正如被盗幼儿长大后，应按成年青年的价值估价，尽管其成长是靠窃贼的照料和费用实现的。

### <a id="13.1.14"></a>13.1.14　尤利安《学说汇纂》第二十二卷

<a id="13.1.14.pr."></a>

**序言（pr.）** 如果被盗奴隶被附条件遗赠，在条件尚未成就期间，继承人仍享有返还之诉；如果条件在争讼程序确定后成就，就应判决被告免责。这与同一奴隶被附条件命令释放、且条件在争讼程序确定后成就的情形相同：因为此时原告已无须再取得该奴隶，而且该物已非因窃贼的恶意而脱离其所有。若在条件尚未成就时作出判决，法官应当估算该奴隶能够卖给买受人的价款。〔底本疑误：此处作 *Qquod*，译文按 *Quod* 理解。〕

<a id="13.1.14.1"></a>

**1.** 原告依据本项诉讼请求时，无须向被告提供担保。

<a id="13.1.14.2"></a>

**2.** 牛被盗并被杀死后，所有权人可以就牛、牛皮和牛肉提起返还之诉，前提是牛皮和牛肉也已被窃取〔底本作 *contrectata fuerint*，并附异文 *fuerunt*〕；牛角也可以请求返还。但是，如果所有权人已经通过返还之诉取得牛的价款，之后再就上述任何部分请求返还，均会被抗辩驳回。反之，如果他先就牛皮提起返还之诉并取得其价款，之后再就牛提起返还之诉，那么窃贼如提出牛的价款扣除牛皮价款后的余额，即可通过恶意抗辩驳回该请求。

<a id="13.1.14.3"></a>

**3.** 葡萄被盗时，法律规则相同；葡萄汁和葡萄渣也可以通过返还之诉请求返还。

### <a id="13.1.15"></a>13.1.15　凯尔苏斯《学说汇纂》第十二卷

**正文** 奴隶从他人处窃取之物，可以就此对自由人提起盗窃之诉；但是，除非该自由人本人实施了窃取行为，不得对其提起返还之诉。

### <a id="13.1.16"></a>13.1.16　庞波尼乌斯《评昆图斯·穆基乌斯》第三十八卷

**正文** 某人因使用借用物或寄存物而实施盗窃，也会因盗窃原因负返还之诉责任。这与借用物之诉不同：即使该物并非因其恶意或过失而灭失，他仍须承担返还之诉责任；而在借用物之诉中，被告通常不对超过过失的责任负责，在寄存之诉中，被告通常不对超过诈欺的责任负责。

### <a id="13.1.17"></a>13.1.17　帕比尼安《疑难集》第十卷

**正文** 为消灭返还之诉，窃贼是否提出返还被盗奴隶，或者是否将债务转为另一名称、另一法律状态，并无太大区别。我也不认为该奴隶当时是否仍然在场会影响判断，因为盗窃所引起的迟延，可以如同通过某种债务承担转移（*delegatio*）而终结。

### <a id="13.1.18"></a>13.1.18　斯凯沃拉《疑难集》第四卷

**正文** 既然明知钱款并非债务而予以受领，即构成盗窃，就应考察：如果代理人以自己的钱款清偿，是否对代理人本人构成盗窃。庞波尼乌斯在《书信集》第八卷中说，代理人本人可以基于盗窃原因提起返还之诉；如果我追认该项非债给付，也可以提起返还之诉。但是，一项返还之诉会使另一项返还之诉消灭。

### <a id="13.1.19"></a>13.1.19　保罗《评涅拉提乌斯》第三卷

**正文** 尤利安答复说，对于擅自取走财物的女儿，应准许以特有产为限对其父亲提起返还之诉。

### <a id="13.1.20"></a>13.1.20　特里福尼努斯《论辩集》第十五卷

**正文** 即使窃贼曾准备应对返还之诉，而在该物尚存在时未提起返还之诉是由于我自己的原因，后来该物又被毁灭，古代法学家仍认为返还之诉继续存续。因为，最初违背所有权人意愿而擅自处理该物的人，似乎始终处于迟延返还的状态；毕竟，他本来就不应取走该物。
