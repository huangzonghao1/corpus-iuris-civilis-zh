## 13.5.0　论约定金钱债务（*De pecunia constituta*）

### <a id="13.5.1"></a>13.5.1　乌尔比安《评告示》第二十七卷

<a id="13.5.1.pr."></a>

**序言（pr.）** 通过这项告示，裁判官支持自然衡平：凡依合意作出的给付约定（*constitutum*），都应遵守，因为背弃信用是严重之事。

<a id="13.5.1.1"></a>

**1.** 裁判官说：“凡约定清偿所欠金钱的人。”这里的“人”应解释为“任何人”，因为妇女也会因约定给付而承担责任，但以她们并非通过介入他人债务（*intercessio*）的方式承担责任为限。

<a id="13.5.1.2"></a>

**2.** 告示虽未明确提及未成年人，但未适婚人（*pupillus*）未经监护人授权（*auctoritas tutoris*）而作出给付约定，并不因此负有义务。

<a id="13.5.1.3"></a>

**3.** 如果家父权下的儿子作出给付约定，他是否承担责任，尚有疑问。我认为，作出约定的儿子本人确实承担责任，其父亲则在特有产的范围内承担责任。

<a id="13.5.1.4"></a>

**4.** 某人虽曾无效地订立要式口约，但其本意是希望对方以要式口约向自己承担义务，而不是向自己作出给付约定；应当认为，他不能提起约定金钱之诉（*actio de constituta pecunia*），因为其行为并非出于作出给付约定的意思，而是出于作出允诺的意思。

<a id="13.5.1.5"></a>

**5.** 能否约定以不同于债务标的的物清偿，曾有疑问。既然现已认可可以以一种物代替另一种物清偿，就没有理由禁止以不同于债务标的的物作出给付约定。因此，某人欠一百，约定以等值谷物给付，我认为该约定有效。

<a id="13.5.1.6"></a>

**6.** 无论债务基于何种原因，均可作出给付约定；也就是说，无论债务源自确定给付或不确定给付之契约，均可约定给付。例如，某人因买卖、嫁资、监护或其他任何契约而负有债务。

<a id="13.5.1.7"></a>

**7.** 自然债务也足以构成给付约定的基础。

<a id="13.5.1.8"></a>

**8.** 此外，即使某人仅依裁判官法诉权、而非依市民法负有义务，只要其作出给付约定，也应承担责任；因为依裁判官法所负之债同样被视为债务。因此，父亲或主人如果就特有产承担的债务作出给付约定，就应在作出约定时特有产的数额范围内承担责任；反之，如果他以自己的名义约定给付超过该数额的款项，则对超过部分不承担责任。

### <a id="13.5.2"></a>13.5.2　尤利安《学说汇纂》第十一卷

如果某人以其家父权下儿子的名义，约定自己将给付十枚钱币，即使儿子的特有产中只有五枚，他仍应依约定金钱之诉对十枚钱币承担责任。

### <a id="13.5.3"></a>13.5.3　乌尔比安《评告示》第二十七卷

<a id="13.5.3.pr."></a>

**序言（pr.）** 如果丈夫就嫁资约定给付超过其所能负担的数额，因为他已约定清偿债务，原则上应对全部数额承担责任；但对妻子判处给付时，以其实际负担能力为限。

<a id="13.5.3.1"></a>

**1.** 如果某人依市民法负有债务，却因抗辩而不依裁判官法负有责任，那么他作出给付约定后是否承担责任，尚有疑问。真实的意见是，如庞波尼乌斯所写，他不承担责任，因为被约定给付的款项并非依任何法律关系所负之债。

<a id="13.5.3.2"></a>

**2.** 如果某人依市民法和裁判官法均负有债务，但该债务约定于未来某日履行，他作出给付约定后是否承担责任？拉贝奥说，给付约定有效；佩狄乌斯也赞同。拉贝奥还补充说，创设给付约定制度，尤其是为了处理尚未到期、当时还不能请求的款项。我也乐于赞同这一意见：这样一来，负有定期债务的人可以约定届期时给付，并因该约定而负有在该日清偿的义务。

### <a id="13.5.4"></a>13.5.4　保罗《评告示》第二十九卷

如果某人约定在更早的日期清偿，同样应承担责任。

### <a id="13.5.5"></a>13.5.5　乌尔比安《评告示》第二十七卷

<a id="13.5.5.pr."></a>

**序言（pr.）** 某人在以弗所允诺清偿，却约定在另一地点清偿，显然应承担责任。

<a id="13.5.5.1"></a>

**1.** 尤利安认为，如果某人身在罗马，就其在行省受领的遗赠作出给付约定，应当可以对其起诉；这一意见是正确的。但如果他作出在罗马清偿的约定时并不在罗马，而仍在行省，则不应准许对其提起约定金钱之诉。

<a id="13.5.5.2"></a>

**2.** 我们要求被约定给付的必须是债务，这一要求针对的是债务本身，而并非要求给付约定的受领人一定是债权人。因为，对我负有的债务，你作出给付约定后便承担责任；而对你负有的债务，如果约定向我给付，该债务也就应向我履行。

<a id="13.5.5.3"></a>

**3.** 尤利安在《学说汇纂》第十一卷中也写道：“提图斯给我寄来如下信件：‘依塞乌斯的委托，如果证实你对我享有任何债权，我将为你提供担保，并毫无争议地向你清偿。’”提图斯应依约定金钱之诉承担责任。

<a id="13.5.5.4"></a>

**4.** 如果某人约定由他人清偿，而不是约定自己代他人清偿，则不承担责任。庞波尼乌斯在《评萨宾》第八卷中也如此写道。

<a id="13.5.5.5"></a>

**5.** 如果你向我约定由你清偿，你就应承担责任；但如果你向我约定由你向塞姆普罗尼乌斯清偿，你就不承担责任。

<a id="13.5.5.6"></a>

**6.** 尤利安在《学说汇纂》第十一卷中写道，可以向代理人作出给付约定。庞波尼乌斯将此解释为：你向代理人本人约定清偿，而不是向委托人约定清偿。

<a id="13.5.5.7"></a>

**7.** 也可以向未成年人的监护人、市政团体的代理人，以及精神失常者的监护人作出给付约定。

<a id="13.5.5.8"></a>

**8.** 作出给付约定的人本人也应承担责任。

<a id="13.5.5.9"></a>

**9.** 如果有人向市政团体、未适婚人（*pupillus*）、精神失常者或青年（*adulescens*）约定给付，并且约定是向其代理人、未适婚人的监护人、精神失常者或青年的监护官作出的，我认为，为了他们的利益，应给予市政团体、未适婚人、精神失常者或青年准用诉权。

<a id="13.5.5.10"></a>

**10.** 也可以向奴隶作出给付约定。如果约定向奴隶的主人给付，或向奴隶本人给付，无论奴隶属于何种身份，均会使主人取得一项债权。

### <a id="13.5.6"></a>13.5.6　保罗《箴言集》第二卷

如果向一名以善意为奴隶身份替我服役的人作出给付约定，规则也相同。

### <a id="13.5.7"></a>13.5.7　乌尔比安《评告示》第二十七卷

<a id="13.5.7.pr."></a>

**序言（pr.）** 如果约定向家父权下的儿子给付，该约定同样有效。

<a id="13.5.7.1"></a>

**1.** 如果我以“向我或提图斯给付”为条件订立要式口约，尤利安说，不能以提图斯本人名义向其作出给付约定，因为他没有请求权，尽管可以向他实际清偿。

### <a id="13.5.8"></a>13.5.8　保罗《评告示》第二十九卷

如果你约定向我或提图斯清偿，我享有诉权；但如果你先前只向我约定清偿，后来却向提图斯清偿，你仍对我负有责任。

### <a id="13.5.9"></a>13.5.9　帕比尼安《疑义》第八卷

但是，提图斯应承担误付返还之诉，以便将错误支付给他的款项返还给付款人。

### <a id="13.5.10"></a>13.5.10　保罗《评告示》第二十九卷

如果要式口约中有两名共同债权人，而向其中一人作出给付约定后又向另一人付款，规则也相同；因为作出给付约定之人，应视为取代已经受领清偿的人。

### <a id="13.5.11"></a>13.5.11　乌尔比安《评告示》第二十七卷

<a id="13.5.11.pr."></a>

**序言（pr.）** 因此，只要约定给付的确属债务，即使暂时没有能够承担该债务的人，给付约定仍然有效。例如，在债务人的继承人接受继承之前，或债务人被敌人俘获后，有人约定自己将清偿；庞波尼乌斯也写道，该约定有效，因为所约定清偿的确是债务。

<a id="13.5.11.1"></a>

**1.** 某人欠一百枚奥里金币，却约定给付二百枚，他只对一百枚承担责任，因为只有这部分是债务。因此，某人约定给付本金以及并不应付的利息，也仅对本金承担责任。

### <a id="13.5.12"></a>13.5.12　保罗《评告示》第十三卷

如果应付十枚钱币，却约定给付十枚钱币和斯提库斯，可以认为，他仅就十枚钱币承担责任。

### <a id="13.5.13"></a>13.5.13　保罗《评告示》第二十九卷

如果某人欠二十枚钱币，却约定自己将给付十枚，他仍应就该约定承担责任。

### <a id="13.5.14"></a>13.5.14　乌尔比安《评告示》第二十七卷

<a id="13.5.14.pr."></a>

**序言（pr.）** 凡约定自己将清偿的人，均应承担责任，无论其是否附加了确定数额。

<a id="13.5.14.1"></a>

**1.** 如果某人约定提供质物，鉴于质押的实用价值已为人们认可，也应承认这种给付约定有效。

<a id="13.5.14.2"></a>

**2.** 如果某人约定由特定的人为自己作保证，他仍应承担责任，庞波尼乌斯即如此写道。如果该人不愿作保，又该如何？我认为，作出约定的人仍应负责，除非另有约定。如果该特定人在此之前已经死亡，又该如何？如果已经发生迟延，公平的做法是令作出约定的人承担责任，或赔偿利益损失，或提供另一名同样适格的保证人；如果并未发生迟延，我更倾向于认为他不承担责任。

<a id="13.5.14.3"></a>

**3.** 无论当事人在场还是不在场，我们都可以作出给付约定，如同可以订立协议一样；既可以通过使者，也可以亲自为之，并且可以使用任何措辞。

### <a id="13.5.15"></a>13.5.15　保罗《评告示》第二十九卷

即使为你作出给付约定的人是自由人，也不妨碍你通过自由人取得权利，因为在这种情形下，他似乎仅仅提供了劳务。

### <a id="13.5.16"></a>13.5.16　乌尔比安《评告示》第二十七卷

<a id="13.5.16.pr."></a>

**序言（pr.）** 如果两人以共同债务人的身份作出给付约定，可以向其中任何一人请求全部给付。

<a id="13.5.16.1"></a>

**1.** 某人可以约定在特定地点、特定时间给付；但债权人并非只能在约定地点请求给付，而是仿照裁量诉讼，可以在任何地点起诉。

<a id="13.5.16.2"></a>

**2.** 裁判官说：“如果查明作出给付约定的人既未清偿，也未履行约定，而且履行未能发生并非因原告所致。”

<a id="13.5.16.3"></a>

**3.** 因此，只要未履行并非原告所致，即使是客观情况使履行未能发生，诉权仍然成立；不过，更妥当的说法是，应当给予被告救济。

<a id="13.5.16.4"></a>

**4.** 裁判官这段话——“被告没有履行其所约定的事项”——究竟是指给付约定所定的履行期限，还是应延伸至争讼程序之时，尚有疑问。我认为，应以给付约定所定的期限为准。

### <a id="13.5.17"></a>13.5.17　保罗《评告示》第二十九卷

即使被告在另一日提出给付，而原告拒绝受领，且拒绝受领并无正当理由，公平的做法仍是通过抗辩或妥当解释救济被告，使原告的行为直到判决时都对其不利。“被告没有履行”这句话应理解为：被告既未在约定的日期履行，也未在此后履行。

### <a id="13.5.18"></a>13.5.18　乌尔比安《评告示》第二十七卷

<a id="13.5.18.pr."></a>

**序言（pr.）** 裁判官所说“未履行并非由原告造成”，同样引起疑问。庞波尼乌斯不确定：如果原告没有在给付约定所定日期阻止履行，却在此前或此后曾加以阻止，应如何处理？我认为，此处也应以约定的履行日期为准。因此，庞波尼乌斯写道，如果请求人因疾病、暴力或风暴受阻而未能到场，应由请求人自己承担不利后果。

<a id="13.5.18.1"></a>

**1.** “并且该笔钱在作出给付约定时应为债务”这一附加语，需要作更充分的解释。首先，这意味着：如果某笔钱在作出约定时确属债务，即使此后不再是债务，给付约定仍然有效，因为诉权具有追溯效力。因此，塞尔苏斯和尤利安写道，受有期限限制的诉权所涉债务人作出给付约定后，即使该期限在约定作出后届满，他仍应承担责任。由此，如果某人约定在原债务期限届满后清偿，尤利安仍认为他承担责任，因为作出约定时债务尚在，尽管他约定在自己已不再负有责任的时间履行。

<a id="13.5.18.2"></a>

**2.** 在此应顺便考察：此项诉讼是包含罚金，还是旨在追索债物？更妥当的意见是，如马尔凯卢斯也认为的那样，此诉旨在追索债物。

<a id="13.5.18.3"></a>

**3.** 过去曾有疑问：提起此项诉讼的人，是否因此使本金债务消灭。较稳妥的意见是，因依此诉清偿而免责，而不是因争讼程序而免责，因为清偿对两项债务关系均发生效力。

### <a id="13.5.19"></a>13.5.19　保罗《评告示》第二十九卷

<a id="13.5.19.pr."></a>

**序言（pr.）** 对于附条件到期的债务，无论以无条件方式还是约定在特定日期清偿，给付约定都受同一条件制约：条件成就时，债务人承担责任；条件不成就时，两项诉权均消灭。

<a id="13.5.19.1"></a>

**1.** 庞波尼乌斯说，如果本来无条件负有债务的人附条件作出给付约定，可以对其提起准用诉讼。

<a id="13.5.19.2"></a>

**2.** 如果父亲或主人约定清偿特有产中的债务，其特有产不会因为他因此开始承担责任而减少；即使特有产已经灭失，他也不因此免责。

### <a id="13.5.20"></a>13.5.20　保罗《评普劳提乌斯》第四卷

特有产的增减与约定给付之诉无关。

### <a id="13.5.21"></a>13.5.21　保罗《评告示》第二十九卷

<a id="13.5.21.pr."></a>

**序言（pr.）** 某人允诺交付斯提库斯，因其迟延而导致斯提库斯死亡；如果他随后约定支付斯提库斯的价款，就应承担责任。

<a id="13.5.21.1"></a>

**1.** 如果某人未约定履行日期，尽管告示措辞涵盖甚广，仍可以说他不承担责任；否则，如果他作出约定后没有立即清偿，就可以马上对其起诉。但应当确定一个合理期限，且不得少于十日，以便进行催收。

<a id="13.5.21.2"></a>

**2.** 某人既已约定将清偿，纵使提出提供足额担保，也不算履行该给付约定。反之，如果他仅约定提供担保，并交付保证人或质物，则不承担约定金钱之诉的责任，因为以何种方式提供担保并无区别。

### <a id="13.5.22"></a>13.5.22　保罗《简要论著》第六卷

如果有人向你作出金钱给付约定后，你依据《特雷贝利安元老院决议》返还遗产，由于你已将本金请求权移转给他人，就不应再准许你提起约定金钱之诉。遗产占有人在遗产被他人追夺后，也适用同一规则。但更妥当的做法是，将此项诉权授予遗嘱信托受益人或胜诉取得遗产的人。

### <a id="13.5.23"></a>13.5.23　尤利安《学说汇纂》第十一卷

某人允诺交付奴隶，却因其迟延致使奴隶死亡；即使他约定仍将交付该奴隶，也应依约定金钱之诉承担责任，并支付奴隶的价款。

### <a id="13.5.24"></a>13.5.24　马尔凯卢斯《答复集》单卷

提图斯给塞乌斯寄了一封信，内容如下：“阁下，卢基乌斯·提图斯依据我所监护的未适婚人与您订立的契约，从您处借取的五十枚钱币仍由我保管；我应于五月十五日将足额、成色合格的钱币交还给您。如果我未在上述日期交付，就应支付如此数额的利息。”我问：卢基乌斯·提图斯是否因这一书面担保而取代未成年人，成为债务人？马尔凯卢斯答复说，如果已经订立要式口约，他便取代未成年人成为债务人。我又问：如果他并未取代未成年人，是否应依约定金钱之诉承担责任？马尔凯卢斯答复说，他只对本金承担责任；这种解释较为宽厚，也较有实益。

### <a id="13.5.25"></a>13.5.25　帕比尼安《疑义》第八卷

<a id="13.5.25.pr."></a>

**序言（pr.）** 某人对一项或另一项债务负有责任，却只就其中一项作出给付约定；问题是，他是否可以清偿未作约定的另一项债务。我说，如果他今天想要背弃对已约定事项的信用，就不应听从他。

<a id="13.5.25.1"></a>

**1.** 如果对方提出宣誓，你宣誓确认其对你负有债务，而你因此享有诉权，那么正确的做法是提起约定金钱之诉。即使不是我主动提出宣誓，而是因被迫要求对方宣誓才如此处理，结论也相同；因为无人怀疑，要求对方宣誓的人比自己亲自宣誓更为谦谨。即使你宽容、我有所顾忌，才导致必须要求对方宣誓，也不应作不同处理。

### <a id="13.5.26"></a>13.5.26　斯凯沃拉《答复集》第一卷

某人给债权人写了这样一封信：“阁下，卢基乌斯·提图斯从您的钱箱借取的十枚钱币，连同利息核算在内，仍由我保管。”他答复说，依所陈述的事实，该人应依约定金钱之诉承担责任。

### <a id="13.5.27"></a>13.5.27　乌尔比安《评告示》第十四卷

某人在债务人到场或不在场时作出给付约定，并无区别。此外，庞波尼乌斯在《评萨宾》第三十四卷中还写道，即使债务人不同意，也可以为其作出给付约定。因此，他认为拉贝奥的意见是错误的。拉贝奥认为：某人已经为他人作出给付约定后，如果债务人通知其不要清偿，应当给予事实抗辩。庞波尼乌斯的意见并非没有道理：作出约定的人既已承担责任，就不应因债务人的行为而免责。

### <a id="13.5.28"></a>13.5.28　盖尤斯《评行省告示》第五卷

某人为他人约定自己将清偿时，原债务人仍然负有债务。

### <a id="13.5.29"></a>13.5.29　保罗《评告示》第二十四卷

凡因侵辱、盗窃或暴力劫掠财物而承担诉讼责任的人，也会因作出给付约定而承担责任。

### <a id="13.5.30"></a>13.5.30　保罗《箴言集》第二卷

如果某人约定向你或提图斯给付一笔钱，即使依严格法理，他仍因约定金钱之诉而负有债务，尽管他已经向提图斯清偿，但仍应通过抗辩给予其救济。

### <a id="13.5.31"></a>13.5.31　斯凯沃拉《学说汇纂》第五卷

卢基乌斯·提图斯去世时欠塞乌斯兄弟钱款。塞乌斯兄弟使普布利乌斯·梅维乌斯相信，遗产已经归他所有，并促使他向兄弟二人寄信，承认自己作为叔父的继承人而欠他们债务；他还在信中补充说，这笔钱已进入自己的账簿。我问：既然普布利乌斯·梅维乌斯并未从卢基乌斯·提图斯的遗产中取得任何财物，他能否依据所述书信按约定金钱之诉被起诉？他能否援用恶意抗辩？答复说，依所述情形，他既不因此享有市民法诉权，也不应依约定金钱之诉被起诉。又问：依据上述原因给付的利息能否请求返还？答复说，依所述情形，可以请求返还。
