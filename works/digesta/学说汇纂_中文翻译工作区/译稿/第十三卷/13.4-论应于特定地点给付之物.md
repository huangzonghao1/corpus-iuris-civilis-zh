## 13.4.0　论应于特定地点给付之物（*De eo quod certo loco dari oportet*）

### <a id="13.4.1"></a>13.4.1　盖尤斯《评行省告示》第九卷

如果在某人约定受领给付地点以外的地点起诉，原本似乎并无提起诉讼的可能。但若允诺人始终不前往其承诺给付的地点——无论是故意如此，还是因为不得不在别处处理事务——要式口约债权人便无法实现其请求，这显然不公平。因此，人们认为应为此设立一项准用诉讼（*actio utilis*）。

### <a id="13.4.2"></a>13.4.2　乌尔比安《评告示》第二十七卷

<a id="13.4.2.pr."></a>

**序言（pr.）** 附裁判指令的诉讼（*actio arbitraria*）兼顾原告与被告双方的利益。如果考虑被告的利益，判决金额应低于原告请求的数额；如果考虑原告的利益，判决金额则应高于该数额。

<a id="13.4.2.1"></a>

**1.** 本诉源自这样的要式口约：我约定由你在以弗所向我给付十。

<a id="13.4.2.2"></a>

**2.** 如果某人约定在以弗所给付十，或在卡普阿交付一名奴隶，而他提起诉讼，就不得排除其中一个地点后再行主张；否则会剥夺被告选择地点所带来的利益。

<a id="13.4.2.3"></a>

**3.** 斯凯沃拉在《问题集》第十五卷中说，要式口约中默示包含的事项，并非一概都由被告支配：他可以决定应当给付什么，却不能决定是否负有给付义务。因此，某人允诺交付斯提库斯或潘菲卢斯时，只要两人都在世，就可以选择交付其中哪一个；但一人死亡后，其选择权即告消灭，以免他以拒绝交付仍在世的那一个为由，得以自行决定是否负有给付义务——毕竟此时他只欠交付仍在世的那一个。由此可见，对于承诺在以弗所或卡普阿给付的人，如果由他决定债权人可以在哪一地起诉，他就总会选择另一地点；如此一来，是否负债便落入他自己的决定。斯凯沃拉因此认为，可以在另一地点起诉，而且即使未指定地点也可以起诉；所以应当把选择请求地点的权利交给原告。斯凯沃拉概括说：原告选择请求给付的地点，被告选择履行地点，但这项选择须在起诉前作出。因此，他说，标的物可在数项给付中选择的情形，与给付地点可选的情形相结合时，必然使地点及诉讼标的的选择权归于原告；否则，保留被告选择权的结果就是剥夺原告的诉权。

<a id="13.4.2.4"></a>

**4.** 如果某人以“在以弗所和卡普阿给付”为内容作出要式口约，斯凯沃拉说，这意味着可以在以弗所请求一部分，在卡普阿请求另一部分。

<a id="13.4.2.5"></a>

**5.** 如果某人约定建造一栋公寓楼，却未指定地点，该要式口约无效。

<a id="13.4.2.6"></a>

**6.** 某人约定“在以弗所给付十”。如果他在按情形尚不可能抵达以弗所的日期之前起诉，就是在履行期届至前错误起诉；因为尤利安认为，这种要式口约默示包含了期限。因此，我认为尤利安所说是正确的：某人在罗马约定当日于迦太基受领给付，这项要式口约无效。

<a id="13.4.2.7"></a>

**7.** 尤利安还讨论：某人约定在以弗所向自己或提提乌斯给付；如果债务人在别处向提提乌斯付款，债权人是否仍可主张该款应向自己给付。尤利安写道，债务人并未免责，因此可以请求其利益损失。马尔凯卢斯也讨论过此事，并在评述尤利安时指出，可以认为即使债务人在别处向我付款，也已经免责，尽管我不必被迫违背意愿受领。马尔凯卢斯明确说，如果债务人并未免责，便应允许请求全部债额；正如某人没有在约定地点建造公寓楼，就完全没有免责。不过，我认为，支付钱款与建造公寓楼不同，因此只应请求利益损失。

<a id="13.4.2.8"></a>

**8.** 现在应当讨论审理此项诉讼的法官应如何行使职权：判决是否必须受合同数额限制，还是可以高于或低于该数额？例如，如果被告有利益在以弗所而非被起诉地付款，就应将这种利益纳入考虑。尤利安遵循拉贝奥的意见，也考虑了原告的利益，因为原告有时会有在以弗所受领给付的利益。因此，原告的利益也应纳入计算。比如，原告曾给出一笔海上借款，预期在以弗所收回；在那里，钱款本应附有违约罚则或以质押物担保，但因你的迟延，质押物被出售，或者罚则已经触发。又如，原告欠国库款项，而其财产被以极低价格出售。在这项附裁判指令的诉讼中，应计入原告的利益，甚至可以超过法定利息上限。若原告通常用这笔钱购买货物，是否也应考虑利润，而不仅是损失？我认为利润也应计算。〔本段 *traiecticiam pecuniam dederat* 后底本另有引号内 *dederit*，与前文形式不一致；此处暂按“曾给出”理解，待核。〕

### <a id="13.4.3"></a>13.4.3　盖尤斯《评行省告示》第九卷

本诉交由法官裁量，是因为我们知道，各城市和地区的物价差异很大，尤其是葡萄酒、橄榄油和谷物。钱币在各地虽似乎具有相同价值，但有些地方较容易以低息取得资金，另一些地方则较难取得，且利息较高。

### <a id="13.4.4"></a>13.4.4　乌尔比安《评告示》第二十七卷

<a id="13.4.4.pr."></a>

**序言（pr.）** 如果在以弗所请求给付，就只能请求约定的该笔数额，不得再请求其他款项；但另有要式口约约定，或涉及时间利益的，不在此限。

<a id="13.4.4.1"></a>

**1.** 有时，审理本诉的法官既然享有裁量权，就应要求被告作出担保，保证在约定地点给付钱款，然后判其免责。比如，被告已经在该地提出付款，或者已将钱款提存，或者很容易便能付款，难道法官不应有时判其免责吗？总之，受命审理本诉的法官也必须把公平原则置于眼前。

<a id="13.4.7.1"></a>

**1.** 但是，如果某人以要式口约承诺在特定地点交付，就应当使用本诉。

### <a id="13.4.8"></a>13.4.8　阿非利加努《问题集》第三卷

你约定在卡普阿给付一百，并取得一名保证人；向保证人请求该款时，应当与向允诺债务人请求一样处理。也就是说，如果在卡普阿以外的地点起诉，应当提起附裁判指令的诉讼，并根据原告或被告在卡普阿而非别处给付该数额的利益来评定诉讼金额。即使被告导致未能在卡普阿支付全部一百，也不应因此增加保证人的责任。因为这种情形不能与利息债务相提并论：后一情形中存在两项要式口约，而此处只有一项借款债务；该债务如何实现，应由法官裁量评估。我认为，这一区别最明显的证据是：如果迟延后已支付一部分，而原告请求其余部分，法官应评估的只是原告对于所请求的这一部分在卡普阿受领所具有的利益。

### <a id="13.4.9"></a>13.4.9　乌尔比安《评萨宾》第四十七卷

允诺在特定地点给付的人，未经要式口约债权人同意，不得在其他地点履行。

### <a id="13.4.10"></a>13.4.10　保罗《疑义集》第四卷

如果在未能于卡普阿给付而发生迟延后，债权人打算提起附裁判指令的诉讼，并以该诉为名接受保证人担保，我们应当考察：法官判决可能增加的金额，是否并非债务，因而不属于保证责任。这样一来，如果现在本金已经付清，或者债权人在卡普阿请求给付，法官的裁量是否也就不再适用？除非有人认为：如果法官本应判处给付一百二十，而债务人支付一百，那么这笔总额支付应视为同时清偿了本金和罚款；如此，超出本金的部分仍可请求，罚款也按相同数额增加。我认为不应采纳这种看法，尤其是因为债权人受领钱款，似乎也表明其已免除罚款。
