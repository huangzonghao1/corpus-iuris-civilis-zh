# D.13.6 论借用物之诉及其反诉

<a id="6"></a><a id="13.6"></a>

## 13.6.0　论借用物之诉及其反诉（*Commodati vel contra.*）

### <a id="13.6.1"></a>13.6.1

*乌尔比安《评告示》第二十八卷*

<a id="13.6.1.pr."></a>**序言（pr.）**：裁判官说：“凡被称为某人曾出借之物，我将就该物给予诉讼。”

<a id="13.6.1.1"></a>**1.** 对这项告示的解释并不困难。只须注意一点：拟定告示的人提到了借用物，而帕科尼乌斯提到的是供使用之物。拉贝奥说，借用与交付使用之间的差别，犹如种与属之间的差别：动产可以作为借用物出借，不动产则不可；而交付使用既可以针对动产，也可以针对不动产。不过，显然，不动产也可严格意义上称为借用物；卡西乌斯也持此见。维维安努斯还说，住宅也可以出借供人居住。

<a id="13.6.1.2"></a>**2.** 未适婚人不因借用物之诉（*actio commodati*）而承担责任，因为未经监护人同意，借用关系对受监护人并未成立；即使其后来达到适婚年龄并有欺诈（*dolus*）或过失（*culpa*），也不因该诉承担责任，因为该关系自始未成立。

### <a id="13.6.2"></a>13.6.2

*保罗《评告示》第二十九卷*

**正文：** 对精神失常者也不得提起借用物之诉。不过，可以对其提起展示之诉（*actio ad exhibendum*），以便在物品展示后提起返还原物之诉（*rei vindicatio*）。

### <a id="13.6.3"></a>13.6.3

*乌尔比安《评告示》第二十八卷*

<a id="13.6.3.pr."></a>**序言（pr.）**：但我认为，若受监护人因此变得较为富有，应依神圣庇护皇帝的敕答，给予借用物之诉的准诉权。

<a id="13.6.3.1"></a>**1.** 借用物虽已返还，但返还时已劣化的，不应视为已经返还，除非赔偿了利益损失；因为劣化返还的物，严格说来就是未予返还。

<a id="13.6.3.2"></a>**2.** 在本诉中，如同其他诚信诉讼（*iudicium bonae fidei*）一样，也可就诉讼标的宣誓；应以裁判时的物价为准，尽管在严法诉讼（*strictum iudicium*）中以争讼程序确定时为准。

<a id="13.6.3.3"></a>**3.** 接受借用者的继承人，按其继承份额承担被诉责任；但若其有能力返还全部物品而不返还，则应对全部承担判决责任，因为依诚信裁判官的裁量，这样处理是适当的。

<a id="13.6.3.4"></a>**4.** 若借用物交给家子或奴隶，应仅就特有产（*peculium*）提起诉讼；也可以直接对家子本人提起诉讼。若出借给女奴或家女，也应仅就特有产提起诉讼。

<a id="13.6.3.5"></a>**5.** 但家父或主人不仅因上述人的欺诈而被判决承担责任，家父或主人本人的欺诈也包括在内；尤利安在《质权之诉》卷11中对此作了区分。

<a id="13.6.3.6"></a>**6.** 消耗物不能作为借用物出借，除非有人是为了仪典或展示而接受该物。

### <a id="13.6.4"></a>13.6.4

*盖尤斯《口头债务》第一卷*

**正文：** 有时也出借金钱，使其仅仅名义上充作支付款项。

### <a id="13.6.5"></a>13.6.5

*乌尔比安《评告示》第二十八卷*

<a id="13.6.5.pr."></a>**序言（pr.）**：若约定借用物须于特定地点或特定时间返还，裁判官的职务要求其考虑地点或时间。

<a id="13.6.5.1"></a>**1.** 某人提起本诉后，接受了对方提出的诉讼标的估价（*litis aestimatio*）款，该物即归提出估价款者所有。

<a id="13.6.5.2"></a>**2.** 现在要考察，在借用物之诉中应承担何种责任：仅欺诈，还是还包括过失，抑或一切风险。合同中有时我们仅对欺诈负责，有时也对过失负责。寄托中只对欺诈负责：因为寄托物对受寄人没有任何利益，故仅使其对欺诈负责是合理的；除非另有报酬（在此情形下，如已有规定，也须对过失负责），或者自始约定受寄人应对过失和风险负责。但在双方均有利益的情形，例如买卖、租赁、嫁资、质押、合伙中，则须对欺诈和过失负责。

<a id="13.6.5.3"></a>**3.** 借用通常只给接受借用者带来利益，因此昆图斯·穆基乌斯认为应承担过失责任并尽到注意义务，这一观点更为正确；若物品是按估价交付的，则接受者承诺按估价赔偿的，应承担全部风险（*periculum*）。

<a id="13.6.5.4"></a>**4.** 因年久而损坏、因疾病而损坏、被强盗以暴力夺走，或发生类似事件的，应认为均不得归责于接受借用者，除非其有过失。因此，若物品因火灾、倒塌或其他灾难性事故而受损，接受者也不承担责任；但若其本可保全借用物，却优先保全自己的物品，则另当别论。

<a id="13.6.5.5"></a>**5.** 接受借用者显然也应对借用物尽到妥善保管（*custodia*）义务。

<a id="13.6.5.6"></a>**6.** 古代法学家曾疑问，借来的人也是否应负保管责任。有时确实应对借来的人负保管责任，例如借来的是被捆绑的人，或其年龄小到需要照管；当然，若约定请求借用者负责照管，也应认为其负有该责任。

<a id="13.6.5.7"></a>**7.** 有时，请求借用者还须承担借来的人死亡所造成的损失。例如，我把马借给你，让你带到别墅去，你却把它带去打仗，你应对我承担借用物之诉的责任；借来的是人时也一样。显然，如果我借给你时约定可以带去打仗，风险就由我承担。纳穆萨还说，若我把一名石匠奴隶借给你，他从脚手架上坠落，风险由我承担；但我认为，只有在我借给你就是为了让他在脚手架上作业时，这一说法才正确。反之，如果我是让他在平地作业，你却让他上脚手架；或者事故是因脚手架有缺陷、未由他本人牢固捆扎，或绳索、木杆陈旧所致，那么我认为，凡因请求借用者的过失而发生的风险，都应由其本人承担。梅拉也写道：若石匠奴隶借给某人后，在脚手架下丧生，因搭建脚手架疏忽而负有责任的工匠应承担借用物之诉的责任。

<a id="13.6.5.8"></a>**8.** 不仅如此，借用物被用于其他用途的人，除承担借用物之诉的责任外，也承担盗窃之诉（*actio furti*）的责任；尤利安在《学说汇纂》卷11中如此写道。他举例说：假如我把账簿借给你，你让债务人在其中签署债务承认书，而我把该记载划掉；如果我借账簿给你正是为了让债务人在其中作此承认，我应受你提起的借用物反诉（*actio commodati contraria*）追究。若借用并非为此目的，你也没有告知我账簿里写有债务承认书，那么他说，你也应对我承担借用物之诉的责任；不仅如此，他还说，你也承担盗窃之诉的责任，因为你以不同于借用约定的方式使用了物品；正如他所说，以不同于约定的方式使用借来的马或衣服的人，也承担盗窃之诉的责任。

<a id="13.6.5.9"></a>**9.** 对借用物应尽到如此程度的注意，以至于随借用物一并交付的物也应受到照管。例如，我把一匹母马借给你，另有一匹幼驹跟随着它；古代法学家答复说，你也应对幼驹负保管责任。

<a id="13.6.5.10"></a>**10.** 有时，请求借用者对借用物只承担欺诈（*dolus*）责任，例如双方作此约定；又如某人仅为自己的利益出借物品，例如为使未婚妻或妻子穿戴得体而把衣物借给她，以便她体面地来到自己身边；或者裁判官举办比赛时把物品借给演出者；又或者有人主动把物品借给裁判官。

<a id="13.6.5.11"></a>**11.** 现在要考察，借用物之诉适用于哪些情形。古代法学家曾对这类情形有所疑问。

<a id="13.6.5.12"></a>**12.** 我把一件物品交给你，让你拿去作你债权人的质物；你已经交付质押，却未能赎回以便返还给我。拉贝奥说，这种情形可以提起借用物之诉；我认为该说法正确，但若有报酬介入则除外：此时应提起事实之诉（*actio in factum*）或租赁之诉（*actio locati vel conducti*）。显然，如果我经你同意替你把物品设定质押，应提起委任之诉（*actio mandati*）。拉贝奥还正确地说，如果我没有过失，已经赎回质物，但债权人拒绝返还，那么你对我享有借用物之诉，但仅限于要求我把对他的诉权交给你。若我已经付清款项，或已准备付款，就应认为我没有过失。至于诉讼费用及其他支出，由接受借用者承担是公平的。

<a id="13.6.5.13"></a>**13.** 如果你请求我把奴隶连同银盘借给你，而奴隶遗失了银盘，卡蒂利乌斯说，风险应由你承担，因为银盘也应视为一并借出；因此，你对银盘也须承担过失责任。显然，若奴隶带着银盘逃走，接受借用者不承担责任，除非其对逃跑负有过失。

<a id="13.6.5.14"></a>**14.** 你曾请求我为你铺设宴席用的三床榻，并提供宴饮用银器；我照办了。之后你又请求我次日照样办理，但因无法方便地把银器带回家，我便将其留在原处，结果银器遗失。此时可以提起何种诉讼，风险又由谁承担？拉贝奥论及风险时写道，关键在于我是否安排了看守：若安排了，风险由我承担；若没有，则由银器被留置之处的占有人承担。我认为可以提起借用物之诉；但银器留置之处的人应负保管责任，除非另有明确约定。

<a id="13.6.5.15"></a>**15.** 若车辆同时借给或租给两人，塞尔苏斯之子在《学说汇纂》卷6中写道“写道”〔底本如此，疑有文字重复〕，可以问：他们各自是对全部承担责任，还是按份承担责任？他说，两人不可能共同对全部物享有所有权或占有；也没有人是物体某一部分的所有人，而是各人按份共有整个物体（*pro indiviso*）。至于浴场、柱廊或场地的使用，每个人都可对全部行使（因为他人也使用，并不妨碍我使用）；但对借用或租赁的车辆而言，我实际上只能按份使用，因为我不能占用车辆的所有空间。不过，他说，更为正确的看法是，我应对全部承担欺诈、过失、注意及保管责任。因此，两人可在某种意义上视为共同债务人；若其中一人被诉并履行，另一人即获免责；而两人都享有盗窃之诉，

### <a id="13.6.6"></a>13.6.6

*庞波尼《评萨宾》第五卷*

**正文：** 因而，若其中一人提起诉讼，另一人针对盗贼的诉权即告消灭。

### <a id="13.6.7"></a>13.6.7

*乌尔比安《评告示》第二十八卷*

<a id="13.6.7.pr."></a>**序言（pr.）**：由此产生疑问：若其中一人提起盗窃之诉，是否只应由其本人被提起借用物之诉？塞尔苏斯说，若未提起盗窃之诉的另一人被诉，而他愿意以自身风险为条件，要求提起盗窃之诉并从借用物中获利的另一人也一并被诉，则应听取其请求并判其免责。

<a id="13.6.7.1"></a>**1.** 若出借人对接受借用者的合伙人享有阿奎利亚法之诉（*actio legis Aquiliae*），而损害系由该合伙人造成，且被提起借用物之诉者被迫赔偿此损害，那么应考察其是否应让与该诉权。即使出借人对被诉者本人享有阿奎利亚法之诉，也极为公平：出借人提起借用物之诉时应放弃该诉权。但也有人可能会说，若出借人提起阿奎利亚法之诉，其所得可能少于按借用关系所能取得的赔偿；这种说法似乎有道理。

### <a id="13.6.10"></a>13.6.10

*乌尔比安《评萨宾》第二十九卷*

<a id="13.6.10.pr."></a>**序言（pr.）**：接受借用物的人若按借用目的使用该物，且没有因自身任何方面的过失使其劣化，则不承担责任，这一说法是正确的；若因其过失使物品劣化，则应承担责任。

<a id="13.6.10.1"></a>**1.** 我把物品交给一名检验者，问题是这是否类似于把物品借给他。若我为自己的利益交付，例如想探明价钱，他只对欺诈负责；若为他的利益，则还须负保管责任；因此，他享有盗窃之诉。若物品在送还途中遗失，且是我指定由谁送还，则风险由我承担；若接受者自行委托他人送还，而他是为自身利益接受物品，则同样须对我承担过失责任，

<a id="13.6.12.1"></a>**1.** 某人受命取回借出的物品，取回后却带着它逃走了。若物主曾指示将物品交给他，则损失由物主承担；若物主派他去只是为了告知接受借用者返还该物品，则损失由接受借用者承担。

### <a id="13.6.13"></a>13.6.13

*庞波尼《评萨宾》第十一卷*

<a id="13.6.13.pr."></a>**序言（pr.）**：接受借用者若因物品未能找到而被判决承担借用物之诉责任，应要求其作出担保：若物品后来找到，物主应将其交给该接受者。

<a id="13.6.13.1"></a>**1.** 若接受某物供试用的人因此取得收益，例如所接受的是牲畜，且牲畜被出租，那么提供物品供试用的人应将该收益交付；因为在风险尚未由某人承担之前，不应由其取得该物的收益。〔译者按：原文此句的行为主体及“id ipsum”的指向不够明确，此处暂按出借人负有交付该项收益的义务理解，待核。〕

<a id="13.6.13.2"></a>**2.** 我把某物借给一名自由人；他以善意为我服役，我把他当作奴隶看待。应考察我是否享有借用物之诉。塞尔苏斯之子曾说，若我命令他做某事，我可以对他提起委任之诉或无名之诉；那么借用物的情形也应作同样解释。此处并不妨碍这一点：我们与为我们善意服役的自由人订约时，并无意把他当作负有债务之人；因为常常会发生这样的情形：除所处理事项之外，另有默示债务关系产生，例如因错误而以清偿不存在的债务为目的给付。

### <a id="13.6.17"></a>13.6.17

*保罗《评告示》第二十九卷*

<a id="13.6.17.pr."></a>**序言（pr.）**：在借用关系中，约定不承担欺诈责任的条款无效。

<a id="13.6.17.1"></a>**1.** 即使尚未提起主诉，也可以提起借用物反诉；其他所谓反诉也是如此。

<a id="13.6.17.2"></a>**2.** 若因继承人的行为提起借用物之诉，即使其仅为部分继承人，也应判其对全部承担责任。

<a id="13.6.17.3"></a>**3.** 正如出借物品更多出于自愿与善意，而非法律义务，出借人也有权规定借用的期限及目的。然而，一旦出借人已经这样做，也就是物品已经借出，其再规定期限、追溯变更约定并不合时宜地收回借用物，就不仅为善意所不容，也为交付和接受之间已经承担的义务所不容。双方由此建立了相互关系，因此法律也相应设立了双方的诉权；这表明，起初仅属恩惠与单方意愿的关系，已经转化为相互给付和民事诉权。情形犹如某人开始处理他人不在场时的事务：他不能任意放弃事务而任其损失，因为倘若他未开始，或许另有人会接手。接受委任是出于自愿，完成委任则是义务。因此，若你把写字板借给我，以便我的债务人在其中向我作出债务承认，你不应不合时宜地要求取回；因为你若当初拒绝，我本可购买写字板或请证人在场。你把梁木借给我支撑公寓楼，之后却抽走梁木，或者明知梁木有瑕疵而仍然出借，也属于同一情形；我们应当因他人的恩惠而得到帮助，而不应受其欺骗。基于这些理由，也应认为可以给予借用物反诉的准诉权。

<a id="13.6.17.4"></a>**4.** 维维安努斯写道，若两件物品一并借出，可以只就其中一件提起借用物之诉。庞波尼说，这一观点似乎是正确的，但须以两物彼此独立为限；例如，某人借出一辆车或一顶轿舆，就不能只针对其个别部件提起诉讼。

<a id="13.6.17.5"></a>**5.** 我遗失了借用物并为此支付了价款，之后该物又到了你的控制之下。拉贝奥说，你应通过反诉把物品交还给我，或者返还你从我处收取的款项。

### <a id="13.6.18"></a>13.6.18

*盖尤斯《评行省告示》第九卷*

<a id="13.6.18.pr."></a>**序言（pr.）**：对于借用物，应尽到这样的注意：犹如最为谨慎的家父对待自己的物品。只有在无法抵御的事故中，接受借用者才不承担责任，例如奴隶死亡并非因其欺诈或过失所致，强盗或敌人来袭、海盗袭击、海难、火灾，以及通常不受看管的奴隶逃跑。至于我们所说的强盗、海盗及海难，应理解为物品是借给某人、供其携带到外地使用的情形；否则，若我因某人说要邀请朋友赴宴而借给他银器，他却把银器带到外地，那么毫无疑问，即使银器遭海盗或强盗劫夺，或发生海难，他也应承担责任。以上规则适用于物品仅为接受者利益而借出的情形；若双方均有利益，例如我们共同邀请一位朋友赴宴，你负责筹办此事，我遂借给你银器，我确实发现有些法学家著作记载，此时你似乎仅对欺诈负责；但应考察是否也须对过失负责，并依质物和嫁资物所采用的标准来衡量过失。

<a id="13.6.18.1"></a>**1.** 无论是质物、借用物还是寄托物，若因接受者而劣化，除我们正在讨论的这些诉讼外，也可以提起阿奎利亚法之诉；但其中任何一项诉讼一经提起，其他诉讼即告消灭。

<a id="13.6.18.2"></a>**2.** 可能出现正当理由，使接受借用者可以对出借人提起诉讼，例如为奴隶治病所支出的费用，或奴隶逃跑后为寻找并带回他而支出的费用。食物费用依自然法理应由接受使用者承担。至于我们所说的治病费用或寻找逃奴费用，也应指较大额支出；因为更正确的说法是，少量费用如同食物费用一样，应由接受借用者承担。

<a id="13.6.18.3"></a>**3.** 同样，若某人明知器皿有瑕疵仍将其借出，而倒入其中的葡萄酒或橄榄油因此变质或漏出，则应就此承担判决责任。

<a id="13.6.18.4"></a>**4.** 某人通过反诉本可取得的利益，在对其提起的主诉中，也可以依法通过抵销保全。不过，可能出现应由对方反向给付的数额更大，或者法官未考虑抵销，或者没有通过诉讼要求返还物品，因为该物品意外灭失或已在审判外返还；在这些情形下，我们认为有必要提起反诉。

### <a id="13.6.19"></a>13.6.19

*尤利安《学说汇纂》第一卷*

**正文：** 毫无疑问，对于受托保管物品或接受物品供使用的人而言，他人不法造成的损害不应由其承担；因为我们凭借何种照料或注意，能够防止他人不法使我们遭受损害呢？

### <a id="13.6.20"></a>13.6.20

*尤利安《评乌尔塞乌斯·费罗克斯》第三卷*

**正文：** 我把借用的银器交给我的一名奴隶，让他送到你处；该奴隶如此可靠，任何人都不应预料他会遭恶人欺骗。若恶人截取银器，损失应由你而非我承担。

### <a id="13.6.21"></a>13.6.21

*阿非利加努《疑义集》第八卷*

<a id="13.6.21.pr."></a>**序言（pr.）**：你把某物借给我，之后又把它窃走。后来你提起借用物之诉，而我不知道是你偷走了该物；法官判我败诉，我也已履行判决。此后我才发现该物是你偷走的。有人询问我对你享有什么诉权。答复是：我没有盗窃之诉，但可以享有借用物反诉的准诉权。

<a id="13.6.21.1"></a>**1.** 在军队中，我把器皿交给同帐篷的伙伴使用，风险由我们共同承担；此后，我的奴隶偷走器皿逃往敌方，后来他被带回时器皿已不在身边。可以确定，我对同帐篷伙伴享有借用物之诉，并按各自份额追究责任；他们也可以以我的奴隶为对象对我提起盗窃之诉，因为损害赔偿责任随奴隶本人而转移（*noxa caput sequitur*）。若我把物品借给你，风险由你承担，而该物又被我的奴隶偷走，你也可以以该奴隶为对象对我提起盗窃之诉。

### <a id="13.6.22"></a>13.6.22

*保罗《评告示》第二十二卷*

**正文：** 若我借给你的奴隶实施了盗窃，有人问：借用物反诉是否已经足够（例如，你为奴隶治疗而支出费用时可以提起该反诉），还是还应提起盗窃之诉？毫无疑问，请求借用该奴隶的人享有针对奴隶的盗窃诺克萨之诉（*actio noxalis*）；而只有当他明知该奴隶有此类情形，却仍借给不知情者时，才应对借用物反诉承担责任。

### <a id="13.6.23"></a>13.6.23

*庞波尼《评昆图斯·穆基乌斯》第二十一卷*

**正文：** 若我把一匹马借给你，约定你只骑到某个特定地点，而在途中并非因你的过失，马匹状况变差，你不承担借用物之诉的责任；因为应由我承担过失，是我把马借给你走这样漫长的路程，而它无法承受这段劳累。
