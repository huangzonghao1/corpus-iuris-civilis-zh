## 13.3.0　论谷物返还之诉（*De condictione triticiaria*）

### <a id="13.3.1"></a>13.3.1　乌尔比安《告示评注》第二十七卷

<a id="13.3.1.pr."></a>

**序言（pr.）** 请求给付确定数量的钱币的人，应当使用“请求确定给付”之诉（*si certum petetur*）；请求其他标的的人，则应当提起谷物型返还之诉（*condictio triticaria*）。一般而言，除确定数量的钱币以外，其他标的均可通过本项诉讼请求，无论其按重量或度量确定，也无论属于动产还是不动产。因此，我们也可以通过本项诉讼请求返还土地，即使该土地属于缴纳地租的土地；如果某人通过要式口约取得某项权利，也可以请求该权利，例如土地的用益权或两处土地之间的地役权。

<a id="13.3.1.1"></a>

**1.** 任何人都不得通过本项诉讼请求返还自己的物，但法律允许的情形除外，例如基于盗窃原因请求返还，或请求返还遭暴力夺取的动产。

### <a id="13.3.2"></a>13.3.2　乌尔比安《评萨宾》第十八卷

**正文** 萨宾写道，对于以暴力将他人逐出土地的人，可以提起返还之诉请求该土地；凯尔苏斯也持此说，但仅限于被逐出者作为所有权人提起返还之诉的情形。否则，凯尔苏斯说，被逐出者可以请求返还占有。

### <a id="13.3.3"></a>13.3.3　乌尔比安《告示评注》第二十七卷

**正文** 在本项诉讼中，如果争议在于应按何时的价值估算请求返还的标的，那么较为正确的意见是依塞尔维乌斯所说，以判决时为准。如果标的已经不复存在，则以其灭失时为准；不过，依凯尔苏斯，应当宽泛地考量时间（希腊语转写 *en platei*）。因为不应按生命的最后时刻估价，以免估价被压低至极小数额，例如奴隶身受致命重伤的情形。无论上述哪种情形，如果标的在迟延之后变得更差，马尔凯卢斯在《学说汇纂》第二十卷中写道，应当按照标的变差的程度估价。因此，如果有人在迟延之后交付一名被弄瞎的奴隶，他仍不因此免责。故在这些情形中，估价应回溯至迟延发生之时。

### <a id="13.3.4"></a>13.3.4　盖尤斯《评行省告示》第九卷

**正文** 如果请求返还某项应于确定日期给付的商品，例如葡萄酒、橄榄油或谷物，卡西乌斯说，应当按其应给付之日的价值估算诉讼标的；如果双方未约定日期，则按诉讼正式受理时的价值估算。地点也适用同一规则：首先，应以标的原本应当给付之地的价值估算；如果双方未约定地点，则以提起请求之地为准。其他标的也适用这一规则。
