# <a id="3"></a><a id="28.3"></a>28.3.0 论不合法、被撤销及失效遗嘱

<!-- source-p 002 -->
### <a id="28.3.1"></a>28.3.1

<!-- source-p 003 -->
帕皮尼安《法律定义集》第一卷

<!-- source-p 004 -->
遗嘱因欠缺法律要求的形式而被称为不合法作成（*non iure factum*）；若遗嘱人处于父权下的儿子被遗漏，则该遗嘱完全不发生效力（*nullius momenti*）；遗嘱也可能因另一份能够产生继承人的遗嘱，或因自权继承人的出生而被撤销（*rumpitur*）；若无人接受遗产，遗嘱则归于失效（*irritum*）。

<!-- source-p 005 -->
### <a id="28.3.2"></a>28.3.2

<!-- source-p 006 -->
乌尔比安《评萨宾》第二卷

<!-- source-p 007 -->
只有在后一份遗嘱依法有效作成时，前一份遗嘱才被撤销；但若后一份遗嘱依军人法作成，或者后一份遗嘱指定了本可按法定继承取得遗产的人，则即使后一份遗嘱未有效作成，前一份遗嘱也会被撤销。

<!-- source-p 008 -->
### <a id="28.3.3"></a>28.3.3

<!-- source-p 009 -->
乌尔比安《评萨宾》第三卷

<!-- source-p 010 -->
<a id="28.3.3.pr."></a>

**序言（pr.）** 男系后出生子女应像儿子一样被逐名剥夺继承权，以免他们因出生而作为自权继承人出现并撤销遗嘱。

<!-- source-p 011 -->
<a id="28.3.3.1"></a>

**1.** 我们所说的后出生子女，仅指父母死亡后出生的人；但对于遗嘱作成后、遗嘱人仍在世时出生的人，依据《尤尼娅·维莱娅法》，只有在遗嘱中逐名剥夺其继承权，才能阻止其撤销遗嘱。

<!-- source-p 012 -->
<a id="28.3.3.2"></a>

**2.** 因此，可以在指定继承人之前、在数名继承人指定条款之间，或在不同继承顺位之间，剥夺其继承权。神圣马尔库斯皇帝曾裁定，对后出生子女应适用与儿子相同的规则；两者之间并无可说明的差异。

<!-- source-p 013 -->
<a id="28.3.3.3"></a>

**3.** 由此可见，遗嘱作成时已存在的子女与后出生子女，情形不同：前者使遗嘱不合法，后者使遗嘱被撤销；前者无论如何都会产生此种效果，后者则只有在出生后发现自己未被剥夺继承权时才会如此。

<!-- source-p 014 -->
<a id="28.3.3.4"></a>

**4.** 即使另有一份遗嘱在先，且已剥夺后出生子女的继承权，若该子女出生，无论是在遗嘱人死亡后还是其生前，仍认为两份遗嘱均被撤销：前一份因后一份而撤销，后一份则因后出生子女而撤销。

<!-- source-p 015 -->
<a id="28.3.3.5"></a>

**5.** 后出生子女被视为逐名剥夺继承权，无论遗嘱人写道“凡我所生之人”，或写道“塞娅所生之人”，抑或写道“腹中胎儿应被剥夺继承权”，均是如此。若写道“后出生子女应被剥夺继承权”，无论其在遗嘱人死后或生前出生，均不撤销遗嘱。

<!-- source-p 016 -->
<a id="28.3.3.6"></a>

**6.** 尽管被遗漏的后出生子女会因出生而撤销遗嘱，但有时遗嘱仅部分被撤销。例如，遗嘱在第一顺位中剥夺了后出生子女的继承权，却在第二顺位中遗漏了他；此时，第一顺位仍有效，第二顺位则被撤销。

<!-- source-p 017 -->
### <a id="28.3.4"></a>28.3.4

<!-- source-p 018 -->
乌尔比安《争议问题》第四卷

<!-- source-p 019 -->
因此，即使第一顺位的遗嘱指定继承人仍在考虑是否接受遗产，第二顺位中指定的继承人也不能取得遗产；因为该顺位一旦被撤销并失去效力，便不能再据此取得遗产。

<!-- source-p 020 -->
### <a id="28.3.5"></a>28.3.5

<!-- source-p 021 -->
乌尔比安《评萨宾》第三卷

<!-- source-p 022 -->
若某人被附条件指定为继承人，而遗嘱未剥夺后出生子女的继承权，即使条件尚未成就，该顺位仍会被撤销；尤利安也作此记载。即使另有替补继承人，若第一顺位条件未成就，替补继承人也不得继承，因为遗嘱同样未剥夺后出生子女对其顺位的继承权。因此，我认为，若第一顺位条件成就，后出生子女应优先于第一顺位继承人取得遗产；但若条件未成就，后出生子女在此后出生便不会撤销该顺位，因为该顺位已经不存在。后出生子女通常通过撤销遗嘱为自己取得继承位置；即使遗嘱人在后续顺位中剥夺其继承权，该顺位仍可能有效。但若遗嘱在第一顺位中遗漏后出生子女、在第二顺位中剥夺其继承权，而该子女恰在某一遗嘱指定继承人仍在世时出生，则整份遗嘱均被撤销；因为撤销第一顺位后，他便为自己取得继承位置。

<!-- source-p 023 -->
### <a id="28.3.6"></a>28.3.6

<!-- source-p 024 -->
乌尔比安《评萨宾》第十卷

<!-- source-p 025 -->
<a id="28.3.6.pr."></a>

**序言（pr.）** 若某人剥夺儿子的继承权，留下怀孕的儿媳后死亡，并附条件指定外人为继承人；在条件尚未成就或遗嘱指定继承人仍在考虑是否接受遗产期间，已被剥夺继承权的儿子死亡，其后孙子出生，那么该孙子是否会撤销遗嘱？我们会说，遗嘱不会被撤销，因为祖父无须剥夺这种孙子的继承权；在继承顺序上，孙子之前尚有其父亲。显然，若遗嘱指定继承人放弃遗产，该孙子将作为祖父的法定继承人取得遗产。两种结论各有其理由：就因后出生而撤销遗嘱而言，只有在祖父死亡时无人先于他的人，才会撤销遗嘱；就法定继承而言，只有在遗产尚未先行归属他人时，后顺位者才继承。由于遗嘱指定继承人仍在考虑是否接受遗产时儿子已经死亡，显然遗产并未先行归属于该儿子。不过，以上规则以祖父死亡时孙子已经在胎中为前提。若孙子是在此后才受胎，马尔凯卢斯记载，他既不能作为自权继承人、孙子或其他亲属，也不能以其他身份取得遗产或遗产占有。
<!-- source-p 026 -->
<a id="28.3.6.1"></a>

**1.** 但若祖父死亡时，孙子尚在胎中，而其父亲正被敌人俘虏；其父亲又在祖父死后仍处于同一状态时死亡，则该孙子继承遗产时会撤销遗嘱，因为上位于他的那个人不再构成阻碍。其父亲在这种状态下死亡，法律上便不被视为仍在人世；但若该被俘父亲后来返回，因自己被遗漏而使父亲的遗嘱不合法。

<!-- source-p 027 -->
<a id="28.3.6.2"></a>

**2.** 无论孙子是在罗马境内受胎，还是在敌人控制的地方受胎，既然出生者也享有归还权（*postliminium*），他继承遗产时便会撤销遗嘱。

<!-- source-p 028 -->
<a id="28.3.6.3"></a>

**3.** 因此，自权继承人后继取得遗产时，不会撤销遗嘱；前提是他们在遗产归属的那个顺位中已被指定为继承人或被剥夺继承权，且该顺位本身有效。

<!-- source-p 029 -->
<a id="28.3.6.4"></a>

**4.** 无论在先的父母以何种方式不再处于家父权之下，后继取得遗产的子女只要已被指定为继承人或被剥夺继承权，就不会撤销遗嘱；无论先前者是因被敌人俘虏、死亡还是受罚而退出家父权，均是如此。

<!-- source-p 030 -->
<a id="28.3.6.5"></a>

**5.** 每当遗嘱人本人发生某种情形，遗嘱即告失效，例如遗嘱人突然沦为奴隶而丧失公民身份，比如被敌人俘虏；或者已满二十岁的人允许自己被出卖，以便提供劳务或分享价款。

<!-- source-p 031 -->
<a id="28.3.6.6"></a>

**6.** 若某人被判处死刑，例如被判处遭野兽吞噬、斩首或其他剥夺生命的刑罚，其遗嘱也会失效；遗嘱并非在其实际受刑时才失效，而是在判决作出时即失效，因为他从那时起成为刑罚奴隶。但若他是因军事犯罪被判刑的军人，通常允许其立遗嘱，正如神圣哈德良皇帝所作敕答；我认为，他将依军人法立遗嘱。既然允许此类被判刑者立遗嘱，那么，他在判刑前已经立下的遗嘱，若判刑后仍获准立遗嘱，是否有效？还是应认为，该遗嘱因刑罚而失效，须重新作成？若他有权依军人法立遗嘱，就不应怀疑，只要他希望原遗嘱继续有效，便应视为已使其继续有效。

<!-- source-p 032 -->
<a id="28.3.6.7"></a>

**7.** 被判处流放者的遗嘱不会立即失效，只有皇帝批准该判决时才失效；此时他才丧失身份。若省长官拟处罚某城镇议员或其子孙，并已奏请皇帝，我认为该人不会立即成为刑罚奴隶，尽管有时会为加强看守而将其收押。此人的遗嘱也不会立即失效，须待皇帝以敕答命令执行刑罚后才失效。因此，若他在此之前死亡，其遗嘱仍然有效，除非他自杀。根据皇帝敕令，因自知犯罪而宁愿死亡、不愿受判刑者的遗嘱无效，即使他们是在本国境内死亡亦然。若某人是因厌倦生活、无法忍受疾病，或出于炫耀——有些哲学家便是如此——而自杀，其遗嘱仍然有效。神圣哈德良皇帝在致庞波尼乌斯·法尔科的信中，对军人遗嘱也作了同一区分：若军人因自知犯有军事罪行而宁愿死亡，其遗嘱无效；若因厌倦或痛苦而死，遗嘱仍然有效；若未立遗嘱而死亡，遗产应归其亲属；若无亲属，则归其军团。

<!-- source-p 033 -->
<a id="28.3.6.8"></a>

**8.** 我们说过，所有这些人的遗嘱都会因判刑而失效；但若他们提出上诉，其身份不会因此减等，故先前所立遗嘱不会失效，他们也可以继续立遗嘱。此规则已屡经确立。他们不会因为自己的身份尚未确定而被视为缺乏立遗嘱能力；其身份已有确定，只是他们本人暂时不能确定自身处境。

<!-- source-p 034 -->
<a id="28.3.6.9"></a>

**9.** 若省长官不受理某人的上诉，而是通过奏请皇帝延缓执行刑罚，又该如何？我认为，此人也暂时保有原有身份，其遗嘱不会失效。神圣马尔库斯皇帝在演说中明确规定：即使上诉者本人或代其上诉者的上诉未获受理，仍应暂停执行刑罚，直至皇帝答复省长官的奏请；被告的陈情书应随奏请一并呈送。除非遇到明显的强盗犯罪、暴发性的叛乱或流血暴动，或其他正当事由——省长官应随后在奏书中说明——而不能拖延；此时允许立即执行刑罚，是为避免危险，而非为了加速惩罚，因此可先行处罚，再行奏报。

<!-- source-p 035 -->
<a id="28.3.6.10"></a>

**10.** 若某人受到违法判决，但刑罚尚未执行，其遗嘱是否失效？例如，城镇议员被判处遭野兽吞噬，是否因此身份减等、遗嘱失效？我认为，只要判决并未对他发生效力，就不会失效。因此，若某人判处了不属于其管辖权范围内的人，受判者的遗嘱也不会失效；法律已对此作出规定。

<!-- source-p 036 -->
<a id="28.3.6.11"></a>

**11.** 对于那些在死后被判罪、名誉被剥夺的人，其遗嘱也不发生效力或将归于失效，例如因叛国罪或其他类似事由被判罪者。

<!-- source-p 037 -->
<a id="28.3.6.12"></a>

**12.** 我们说被敌人俘虏者的遗嘱会失效；还应补充，若其依据归还权（*postliminium*）返回，其遗嘱将恢复效力；若其仍死于敌境，则依《科尔内利亚法》确认遗嘱。因此，若某人被判处身份减等，后来又经皇帝恩准恢复原状，其遗嘱也将恢复效力。

<!-- source-p 038 -->
<a id="28.3.6.13"></a>

**13.** 家子因父亲死亡而成为自权人，其遗嘱不会因此失效，这一点已属确定。就立遗嘱处分军营特有产而言，家子应视同家父；因此，军人或退伍军人的遗嘱也不会因其脱离家父权而失效。

**序言（pr.）** 被遗漏的遗腹子在立遗嘱人仍在世时出生，随后死亡：尽管依严格而过分细密的法律解释，遗嘱似乎已被撤销，但若遗嘱曾加封，指定继承人仍可取得依遗嘱书所为的遗产占有，并将取得遗产；神圣哈德良皇帝和我皇帝均曾以敕答作此规定。因此，受遗赠人和受遗嘱信托利益者可以安心取得留给他们的利益。对于不合法或无效的遗嘱，也应作相同处理：如果遗产占有已授予某一能够依无遗嘱继承取得遗产的人，亦属如此。

<!-- source-p 058 -->
<a id="28.3.12.1"></a>

**1.** 某平民已经订立一份遗嘱，后来又另立遗嘱，并在其中写道：“将此事托付继承人的诚信，使先前的遗嘱书仍然有效。”无论如何，先前的遗嘱已经被撤销。遗嘱既已撤销，便可进一步讨论它是否应具有遗嘱附书的效力。既然这些文字表达的是遗嘱信托，毫无疑问，先前遗嘱书中所载的一切都应作为遗嘱信托处理；不仅包括遗赠和遗嘱信托，还包括自由权的授予和继承人的指定。

### <a id="28.3.13"></a>28.3.13

<!-- source-p 060 -->
盖尤斯《法学阶梯》第二卷

<!-- source-p 061 -->
有些人也处于遗腹子相同的地位：他们继承自权继承人的地位，仿佛因后出生而成为家属，从而成为其父母的自权继承人。例如，我若将儿子以及儿子所生的孙子或孙女置于我的权力之下，由于儿子辈分在先，只有儿子享有自权继承人的权利，尽管其子孙也同在我的权力之下。但是，若我的儿子在我生前死亡，或因任何原因脱离我的权力，其孙子或孙女便开始承接儿子的地位，并以这种方式仿佛因亲属关系的新增而取得自权继承人的权利。因此，为免此种情形撤销我的遗嘱，我必须像对儿子本人那样，明确指定该孙子或孙女为继承人或将其剥夺继承权，否则遗嘱即非依法作成；否则，若儿子在我生前死亡，孙子或孙女承接其地位，仿佛因亲属关系新增而撤销遗嘱。对此，《尤尼亚·维莱亚法》已作出规定。

雅沃勒努斯《书信》第四卷

<!-- source-p 067 -->
某人有一名怀孕的妻子，后来被敌人俘虏。我询问：儿子出生时，在罗马境内订立的遗嘱何时被撤销？若儿子先于父亲死亡，指定继承人能否取得遗产？答复是：毫无疑问，依据《科尔内利亚法》——该法旨在确认那些死于敌人控制之下者的遗嘱——儿子出生之时，处于敌人控制之下者的遗嘱即被撤销。因此，该遗嘱不可能使遗产归于任何人。

<!-- source-p 068 -->
### <a id="28.3.16"></a>28.3.16

<!-- source-p 069 -->
庞波尼乌斯《评昆图斯·穆齐乌斯》第二卷

<!-- source-p 070 -->
若我们在第二份遗嘱中指定一名在世者为继承人，无论是无条件指定，还是附条件指定（只要该条件有可能实现，即使实际上未实现），先前的遗嘱即被撤销。条件的种类很重要：条件可以针对过去、现在或将来。过去的条件例如：“如果提图斯曾任执政官。”若此条件为真，也就是说，提图斯确曾任执政官，则其继承人指定将使先前遗嘱被撤销，原文作 *rumpatur*〔异文：*rumpatar*〕；因为如此，他便可依这份遗嘱成为继承人。若提图斯未曾任执政官，先前遗嘱则不被撤销。若继承人的指定附有针对现在的条件，例如：“如果提图斯现为执政官”，结果也相同：若条件为真，他便可以成为继承人，先前遗嘱亦被撤销；若条件为假，他既不能成为继承人，先前遗嘱也不被撤销。至于针对将来的条件，只要其可能实现，即使实际上未实现，也足以使先前遗嘱被撤销；若条件不可能实现，例如：“提图斯若以手指触天，令其为继承人”，通说认为这等同于没有附加条件，因为该条件不可能实现。

<!-- source-p 071 -->
### <a id="28.3.17"></a>28.3.17

<!-- source-p 072 -->
帕比尼安《解答》第五卷

<!-- source-p 073 -->
被遗漏且处于父亲权力之下的儿子，若从兄弟处取走了部分遗产，便既无权取得自由权授予，也不得请求履行遗赠；但若他放弃父亲的遗产，尽管严格法理似乎与此相悖，仍应本于诚信与衡平维护立遗嘱人的意愿。

### <a id="28.3.18"></a>28.3.18

<!-- source-p 075 -->
斯凯沃拉《疑问》第五卷

<!-- source-p 076 -->
若被立遗嘱人指定为继承人者后来被其收养为养子，可以说已经满足了要求，因为在被收养之前，该继承人指定对外人也能发生效力。

### <a id="28.3.19"></a>28.3.19

<!-- source-p 078 -->
斯凯沃拉《疑问》第六卷

<!-- source-p 079 -->
<a id="28.3.19.pr."></a>

**序言（pr.）** 若我和提图斯被指定为继承人，我们虽已剥夺遗腹子的继承权，但我们的替补继承人并未剥夺其继承权；提图斯死亡后，我也不能承受遗产。因为，鉴于原被指定的继承人——即剥夺了遗腹子继承权的人——的地位，其替补继承人将承接其位置；但该替补继承人并未剥夺遗腹子的继承权，所以遗嘱已经被撤销。

<!-- source-p 080 -->
<a id="28.3.19.1"></a>

**1.** 但是，若我和提图斯互为替补继承人，尽管替补继承的条款中未剥夺遗腹子的继承权，我认为提图斯死亡或拒绝承受遗产后，我仍可承受遗产，并成为全部遗产的继承人。

<!-- source-p 081 -->
<a id="28.3.19.2"></a>

**2.** 不过，在第一种情形中，即使提图斯仍在世，我不能不与他一同承受遗产，他也不能不与我一同承受；因为尚不确定其中一人不承受时，遗嘱是否仍会被撤销。因此，我们可以共同承受遗产。

<!-- source-p 082 -->
### <a id="28.3.20"></a>28.3.20

<!-- source-p 083 -->
斯凯沃拉《学说汇纂》第十三卷

<!-- source-p 084 -->
卢基乌斯·提图斯在精神健全、身体健康时，依照法定方式订立遗嘱；后来他患病，精神失常，将同一份遗嘱书撕毁。我询问：遗嘱书中指定的继承人能否承受遗产？答复是：依所述事实，他们仍然可以承受遗产。
