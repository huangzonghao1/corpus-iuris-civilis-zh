# D.28.2 论对子女及遗腹子女指定继承人或剥夺其继承人资格（*De liberis et postumis heredibus instituendis vel exheredandis*）

<!-- source-p 001 -->
<a id="2"></a><a id="28.2"></a>**28.2.0. 论对子女及遗腹子女指定继承人或剥夺其继承人资格。**

<!-- source-p 002 -->
<a id="28.2.1"></a>**28.2.1**

<!-- source-p 003 -->
**乌尔比安：《萨宾评注》第一卷。**

<!-- source-p 004 -->
我们来考察，何谓以姓名明确剥夺继承人资格。是否必须说出其姓名、教名和家族名，还是其中任意一个就够了？答案已经确定：说出其中一个便足够。

<!-- source-p 005 -->
<a id="28.2.2"></a>**28.2.2**

<!-- source-p 006 -->
**乌尔比安：《规则集》第六卷。**

<!-- source-p 007 -->
以姓名明确剥夺继承人资格的儿子，也可如此表述：“我的儿子不得为继承人”；即使没有写明他的姓名，只要他是独子，仍然有效。若有数名儿子，多数人更倾向于作宽厚解释，认为没有任何一人因此被剥夺继承人资格。

<!-- source-p 008 -->
<a id="28.2.3"></a>**28.2.3**

<!-- source-p 009 -->
**乌尔比安：《萨宾评注》第一卷。**

<!-- source-p 010 -->
<a id="28.2.3.pr."></a>**序言。**即使立遗嘱人没有称他为“儿子”，而是说他出自塞娅，也能有效地剥夺其继承人资格。即便立遗嘱人以侮辱性言辞称他“不可称名者”“不是我的儿子”“强盗”或“角斗士”，较可取的意见仍是其继承人资格已被有效剥夺；称他为通奸所生者，也同样如此。

<!-- source-p 011 -->
<a id="28.2.3.1"></a>**1.**尤利安认为，剥夺儿子继承人资格必须以无条件方式作出；我们采纳这一意见。

<!-- source-p 012 -->
<a id="28.2.3.2"></a>**2.**在数个继承人指定之间剥夺儿子继承人资格，也是有效的；他因此从整个继承顺位中被排除，除非立遗嘱人只针对其中一名继承人剥夺其资格。如果立遗嘱人如此办理，剥夺就有瑕疵。若写道：“无论谁成为我的继承人，我的儿子均不得为继承人”，也同样有瑕疵。正如尤利安所写，此种剥夺有瑕疵，因为立遗嘱人意图在遗产已被接受后才将儿子排除，这不可能实现。

<!-- source-p 013 -->
<a id="28.2.3.3"></a>**3.**在指定继承人之前剥夺儿子继承人资格的，他就从所有继承顺位中被排除。

<!-- source-p 014 -->
<a id="28.2.3.4"></a>**4.**在两个继承顺位之间剥夺继承人资格的，依斯凯沃拉之见，该儿子在两个顺位中都被排除；我认为此意见正确。

<!-- source-p 015 -->
<a id="28.2.3.5"></a>**5.**对于混合设定两个继承顺位的遗嘱，毛里基亚努斯正确地认为剥夺有效，例如：“第一顺位继承人取得一半遗产；如果第一顺位继承人未能成为继承人，第二顺位继承人取得一半遗产；第三顺位继承人取得另一半遗产。我的儿子不得为继承人；如果第三顺位继承人未能成为继承人，第四顺位继承人即为继承人。”在此情形中，儿子已从两个顺位中都被排除。

<!-- source-p 016 -->
<a id="28.2.3.6"></a>**6.**如果家父作成的遗嘱是：在第一顺位中略过儿子，而仅在第二顺位中剥夺其继承人资格，那么，萨宾、卡西乌斯和尤利安认为，第一顺位被排除后，遗嘱就从儿子被剥夺继承人资格的那个顺位开始发生效力。此意见已经获得认可。

<!-- source-p 017 -->
<a id="28.2.4"></a>**28.2.4**

<!-- source-p 018 -->
**乌尔比安：《萨宾评注》第三卷。**

<!-- source-p 019 -->
任何男性都可以指定遗腹子女为继承人，无论他已经结婚还是尚未娶妻。因为已婚者可以与妻子离婚，未婚者日后也可能结婚。即使丈夫指定遗腹子女为继承人，也不能认为他只指定了与现任妻子所生、或当时已经在妻子腹中的孩子；他也可以指定其与任何妻子所生的孩子。

<!-- source-p 020 -->
<a id="28.2.5"></a>**28.2.5**

<!-- source-p 021 -->
**雅沃勒努斯：《卡西乌斯评注》第一卷。**

<!-- source-p 022 -->
因此，指定遗腹子女为继承人的人，如果立遗嘱后改变了婚姻关系，那么该指定应理解为指向后一次婚姻所生的孩子。

<!-- source-p 023 -->
<a id="28.2.6"></a>**28.2.6**

<!-- source-p 024 -->
**乌尔比安：《萨宾评注》第三卷。**

<!-- source-p 025 -->
<a id="28.2.6.pr."></a>**序言。**有人提出疑问：不能轻易生育的人能否指定遗腹子女为继承人？卡西乌斯和雅沃勒努斯写道，可以；因为此人仍能娶妻，也能收养。拉贝奥和卡西乌斯还写道，天生不育者（*spado*）也可以指定遗腹子女为继承人，因为年龄和不育都不构成障碍。

<!-- source-p 026 -->
<a id="28.2.6.1"></a>**1.**但如果此人已被阉割，尤利安遵循普罗库鲁斯学派的意见，认为他不能指定遗腹子女为继承人；我们采用这一法律规则。

<!-- source-p 027 -->
<a id="28.2.6.2"></a>**2.**至于两性人，如果其男性性征占优势，就可以指定遗腹子女为继承人。

<!-- source-p 028 -->
<a id="28.2.7"></a>**28.2.7**

<!-- source-p 029 -->
**保罗：《萨宾评注》第一卷。**

<!-- source-p 030 -->
若处于家父权力下的儿子被略过，并在父亲生前死亡，遗嘱即无效，且不会因此使先前的遗嘱被撤销；我们采用这一法律规则。

<!-- source-p 031 -->
<a id="28.2.8"></a>**28.2.8**

<!-- source-p 032 -->
**庞波尼乌斯：《萨宾评注》第一卷。**

<!-- source-p 033 -->
如果我指定第一顺位继承人并剥夺儿子的继承人资格，却没有在第二顺位替补继承人中剥夺其资格，而在第一顺位继承人是否接受遗产尚未确定期间，儿子死亡，那么，依我们所采纳的意见，第二顺位替补继承人不会成为继承人，因为他自始即属无效指定：儿子的继承人资格未被该替补继承人所剥夺。如果同样情形发生在遗腹子女身上，即父亲在世时遗腹子女出生，随后被剥夺其继承人资格而死亡，那么对替补继承人也应作同样判断；因为儿子出生后，就居于尚在人世的儿子之位。

<!-- source-p 034 -->
<a id="28.2.9"></a>**28.2.9**

<!-- source-p 035 -->
**保罗：《萨宾评注》第一卷。**

<!-- source-p 036 -->
<a id="28.2.9.pr."></a>**序言。**如果某人指定遗腹子女为继承人，而依其年龄或健康状况，他也许无法生育遗腹子女，先前所立的遗嘱仍会被撤销。对此应主要考察人的自然生育能力和通常情形，而不应仅因暂时的身体缺陷或疾病就否定其生育能力。

<!-- source-p 037 -->
<a id="28.2.9.1"></a>**1.**如果某人指定与他人有婚姻关系的女子所生的遗腹子女为继承人，该指定依法当然无效，因为这种指定有违善良风俗。

<!-- source-p 038 -->
<a id="28.2.9.2"></a>**2.**如果我剥夺儿子的继承人资格，略过他的孙子，另指定他人为继承人，而儿子在我死亡后仍然在世，即使他在遗产被接受之前死亡，尤利安、庞波尼乌斯和马尔凯卢斯仍认为孙子不会撤销遗嘱。相反，如果儿子处于敌人权力之下，并在仍处于该状态时死亡，孙子就会撤销遗嘱。因为在这些情形下，祖父死亡时，儿子的权利仍处于悬而未决的状态；这不同于前一种情形，儿子的权利并未中断。此外，如果指定的继承人拒绝接受遗产，合法继承人就会继承；因为“若无遗嘱而死亡”一语，指遗嘱失效之时，而非立遗嘱人死亡之时。

<!-- source-p 039 -->
<a id="28.2.9.3"></a>**3.**如果我指定与依法不得结婚的女子所生的遗腹子女为继承人，庞波尼乌斯认为遗嘱不会因此被撤销。

<!-- source-p 040 -->
<a id="28.2.9.4"></a>**4.**如果某女子因收养而成为我的姐妹，我仍可指定与她所生的遗腹子女为继承人，因为收养关系解除后，我可以娶她为妻。

<!-- source-p 041 -->
<a id="28.2.10"></a>**28.2.10**

<!-- source-p 042 -->
**庞波尼乌斯：《萨宾评注》第一卷。**

<!-- source-p 043 -->
指定尚未出生的人为继承人，最妥当的方式是写道：“无论其在我生前还是死后出生，均为继承人”；也可以不提及任何一段期间而作无条件指定。如果遗漏了其中任何一种情形，那么在所遗漏的情形下出生的人就会撤销遗嘱，因为遗嘱并未涵盖在该遗漏情形下出生的孩子；他甚至不能被理解为附条件指定的继承人。

<!-- source-p 044 -->
<a id="28.2.11"></a>**28.2.11**

<!-- source-p 045 -->
**保罗：《萨宾评注》第二卷。**

<!-- source-p 046 -->
在自权继承人身上，所有权的连续性表现得尤为明显：这种连续性使事情看起来仿佛并不存在继承，因为他们早已是所有人；即使父亲在世时，他们在某种意义上也被认为是所有人。因此，他们既称为“家子”，也称为“家父”；所加的区别，仅仅在于区分生父与其所生之人。所以父亲死亡后，他们看起来并非取得继承，而是取得对财产的自由管理权。基于这一原因，即使他们没有被指定为继承人，他们仍是所有人；他们可以被剥夺继承人资格这一点，并不妨碍上述结论，正如他们曾经也可以被杀死一样。

<!-- source-p 047 -->
<a id="28.2.12"></a>**28.2.12**

<!-- source-p 048 -->
**乌尔比安：《萨宾评注》第九卷。**

<!-- source-p 049 -->
<a id="28.2.12.pr."></a>**序言。**所谓儿子出生会撤销遗嘱，其中“出生”应包括剖腹产取出的孩子；如果该孩子出生时处于父权之下，他同样会撤销遗嘱。

<!-- source-p 050 -->
<a id="28.2.12.1"></a>**1.**不过，如果出生的并非完整的人体，但仍有生命气息，遗嘱是否仍会被撤销？即便如此，遗嘱仍会被撤销。

<!-- source-p 051 -->
<a id="28.2.13"></a>**28.2.13**

<!-- source-p 052 -->
**尤利安：《学说汇纂》第二十九卷。**

<!-- source-p 053 -->
<a id="28.2.13.pr."></a>**序言。**如果遗嘱写道：“若我有儿子出生，他取得遗产的六分之四；其余部分由我的妻子继承。若我有女儿出生，她取得遗产的三分之一；其余部分由我的妻子继承”，而儿子和女儿都出生了，那么应将遗产总额分为七份：儿子取得四份，妻子取得两份，女儿取得一份。这样，儿子所得恰为妻子的两倍，妻子所得又恰为女儿的两倍。尽管依严格的法律规则，遗嘱本应被撤销；但由于立遗嘱人希望无论儿子还是女儿出生，妻子都能取得一部分遗产，因而基于人道考虑，采取了这种解释。尤文提乌斯·塞尔苏斯也极为明确地赞同此解释。

<!-- source-p 054 -->
<a id="28.2.13.1"></a>**1.**民法有一项规则，规定继承人资格不得被剥夺。基于该规则，即使遗嘱人在同一份遗嘱中撤销了奴隶的自由身安排，只要遗嘱曾命令该奴隶获得自由并成为继承人，他仍将同时取得自由和继承人资格。

<!-- source-p 055 -->
<a id="28.2.13.2"></a>**2.**遗嘱若写道：“提图斯在我儿子死后成为继承人；我的儿子不得为继承人”，则毫无法律效力，因为儿子是在自己死亡后才被剥夺继承人资格。因此，该儿子仍可针对其父的自由民请求取得违遗嘱的遗产占有（*bonorum possessio contra tabulas paternorum libertorum*）。

<!-- source-p 056 -->
<a id="28.2.14"></a>**28.2.14**

<!-- source-p 057 -->
**阿弗里卡努斯：《疑义集》第四卷。**

<!-- source-p 058 -->
<a id="28.2.14.pr."></a>**序言。**如果遗腹子女在第一顺位中被剥夺继承人资格、在第二顺位中却被略过，即使他是在遗产应归第一顺位指定继承人时出生，人们仍认为第二顺位有瑕疵；其效果是，指定继承人若拒绝接受遗产，该遗腹子女就成为继承人。甚至在他死亡后，指定继承人若拒绝接受遗产，替补继承人也不得接受遗产。因此，如果遗腹子女在第一顺位中被剥夺继承人资格、在第二顺位中被略过、在第三顺位中又被剥夺资格，而他在第一顺位继承人仍在世并考虑是否接受遗产时死亡，人们常问：第一顺位继承人拒绝接受后，遗产应归第三顺位指定继承人，还是应归合法继承人？阿弗里卡努斯认为，即使在这种情况下，较为正确的看法也是遗产归合法继承人。因为如果指定了两名继承人，并分别为其指定替补继承人，而遗腹子女在第一顺位中被剥夺继承人资格、在第二顺位中被略过，那么，即使其中一名指定继承人拒绝接受遗产，尽管遗腹子女被排除，也不应因此允许其替补继承人接受遗产。

<!-- source-p 059 -->
<a id="28.2.14.1"></a>**1.**通常所说“儿子被略过的那个顺位无效”，并非在任何情况下都正确。若儿子在第一顺位被指定为继承人，就不必在替补继承人中再次剥夺他的继承人资格。因此，若儿子与提图斯被指定为继承人，而梅维乌斯被指定为提图斯的替补继承人，那么提图斯拒绝接受遗产时，梅维乌斯可以接受遗产，即使儿子在第二顺位中并未被剥夺继承人资格。

<!-- source-p 060 -->
<a id="28.2.14.2"></a>**2.**如果某人写道：“某某——我知道他并非我所生——不得为继承人”，阿弗里卡努斯说，如果证明此人确由立遗嘱人生育，这一剥夺就毫无法律效力；因为不能认为他已被作为儿子而剥夺继承人资格。父亲在剥夺儿子资格时，陈述了理由，并指出正是由于该理由才剥夺其资格；既然后来证明父亲对剥夺资格的原因存在错误，结论便应如此。

<!-- source-p 061 -->
<a id="28.2.15"></a>**28.2.15**

<!-- source-p 062 -->
**乌尔比安：《萨宾评注》第一卷。**

<!-- source-p 063 -->
如果立遗嘱人也写道：“某某——某人的儿子——不得为继承人”，并因错误而将通奸所生的父亲指认为其父，结论也相同。

<!-- source-p 064 -->
<a id="28.2.16"></a>**28.2.16**

<!-- source-p 065 -->
**阿弗里卡努斯：《疑义集》第四卷。**

<!-- source-p 066 -->
如果儿子被指定为继承人，却略过遗腹子女，并为儿子指定了他的儿子作为替补继承人；那么在遗腹子女尚未出生时儿子死亡，该孙子将分别成为其父亲和祖父的自权继承人。但如果没有人为儿子指定替补继承人，只有儿子本人被指定为继承人，那么儿子死亡时，才确定无人能依该遗嘱成为继承人；此时儿子就成为父亲的无遗嘱继承人。这就像儿子被指定为附有某项由其本人控制之条件的继承人，却在条件成就之前死亡的情形。

<!-- source-p 067 -->
<a id="28.2.17"></a>**28.2.17**

<!-- source-p 068 -->
**弗洛伦提努斯：《法学阶梯》第十卷。**

<!-- source-p 069 -->
儿子也可以用以下方式剥夺其继承人资格：“儿子不得为继承人”，或者“儿子将不得为继承人”。

<!-- source-p 070 -->
<a id="28.2.18"></a>**28.2.18**

<!-- source-p 071 -->
**乌尔比安：《告示评注》第五十七卷。**

<!-- source-p 072 -->
许多人剥夺儿子的继承人资格，并非出于羞辱，也不是为了损害他们，而是为了他们的利益；例如，儿子尚未达到法定成年年龄，父亲便为他设定遗嘱信托继承。

<!-- source-p 073 -->
<a id="28.2.19"></a>**28.2.19**

<!-- source-p 074 -->
**保罗：《维特利乌斯评注》第一卷。**

<!-- source-p 075 -->
某人指定女儿取得全部遗产，并向受其家父权力支配的儿子遗赠十；随后又加写：“其余部分中，他也不得为我的继承人。”有人问，这是否构成有效的继承人资格剥夺。斯凯沃拉答复说，不构成。他在论证中补充：这项剥夺无效，因为若某人被命令不得继承某块土地，也不能因此认为他已被有效剥夺继承人资格；此外，继承人的指定另有其理，应作有利解释；但剥夺继承人资格不应获得补救。

<!-- source-p 076 -->
<a id="28.2.20"></a>**28.2.20**

<!-- source-p 077 -->
**莫德斯蒂努斯：《潘德克顿》第二区。**

<!-- source-p 078 -->
儿子被指定为附条件继承人，如果在条件尚未成就期间将自己交由他人收养为家子，就不会成为当然继承人。

<!-- source-p 079 -->
<a id="28.2.21"></a>**28.2.21**

<!-- source-p 080 -->
**庞波尼乌斯：《昆图斯·穆基乌斯评注》第二卷。**

<!-- source-p 081 -->
如果我以姓名明确剥夺儿子的继承人资格，之后又指定他为继承人，他仍将成为继承人。

<!-- source-p 082 -->
<a id="28.2.22"></a>**28.2.22**

<!-- source-p 083 -->
**克莱门提乌斯：《尤利乌斯—帕皮乌斯法评注》第十七卷。**

<!-- source-p 084 -->
遗腹子女若被指定为附条件继承人，而条件在其出生前已经成就，则该遗腹子女出生不会撤销遗嘱。

<a id="28.2.23"></a>**28.2.23**

<!-- source-p 086 -->
**帕皮尼安：《疑义集》第十二卷。**

<!-- source-p 087 -->
<a id="28.2.23.pr."></a>**序言。**我曾说，父亲在先行解放儿子后又将其重新收养为家子，先前书面的继承人资格剥夺对他仍有不利效力。因为几乎所有法律都遵循这样的规则：自然父亲重新收养自己的儿子时，不将其视为从他人处收养来的养子，以免自然关系的真实被收养关系的表象遮蔽；换言之，此人看起来并非被转移而来，而是被送还。就本案而言，我认为，父亲收养的究竟是已被剥夺继承人资格的儿子，还是孙子，并无太大区别。〔译义待核：*veri patris adoptivus filius numquam intellegatur*〕

<!-- source-p 088 -->
<a id="28.2.23.1"></a>**1.**如果提图斯以孙子的身份被收养，后来那位被视为其父亲的儿子死亡，那么提图斯以孙子身份递补继承，不会使遗嘱被撤销；他仍是被认定的继承人。〔句义待核〕

<!-- source-p 094 -->
<a id="28.2.25.pr."></a>**序言。**提提乌斯在遗嘱中指定继承人，并有一名儿子受其家父权力支配。他写道：“我的其余所有儿子和女儿均不得为继承人。”保罗答复说，该儿子应视为已被有效剥夺继承人资格。后来有人进一步询问：父亲以为已经死亡的人是否也可视为被剥夺继承人资格？保罗答复说，事实是儿子和女儿已按姓名逐一被剥夺继承人资格；但据称父亲曾发生错误，此事应由法官审理。

<!-- source-p 095 -->
<a id="28.2.25.1"></a>**1.**卢基乌斯·提提乌斯在城中安排身后事务时，其女儿所生的孙女怀有身孕，正在乡间。他写道，要将孙女腹中的孩子指定为部分遗产的继承人。我问：提提乌斯在城中订立遗嘱的那一天，约为正午时分；同日乡间天色将明时，梅维娅生下一名男孩。由于提提乌斯书写遗嘱时孩子已经出生，该继承人指定是否有效？保罗答复说，遗嘱文字似乎是指向遗嘱作成后出生的曾孙；但如果如题设所述，立遗嘱人的孙女在遗嘱书写之前、且在同一天已经生下孩子，那么，即使立遗嘱人对此并不知情，仍可正确地答复说，该继承人指定依法有效。

<!-- source-p 102 -->
<a id="28.2.28"></a>**28.2.28**

<!-- source-p 103 -->
**特里丰尼努斯：《论辩集》第二十卷。**

<!-- source-p 104 -->
<a id="28.2.28.pr."></a>**序言。**某人的儿子受其家父权力支配，被指定为附有非其本人所能控制之条件的继承人；遗嘱还规定，条件不成就时剥夺他的继承人资格。儿子在指定继承人与剥夺资格的条件均尚未成就时死亡。我说，他应作为无遗嘱继承人死亡，因为他生前既非遗嘱继承人，也未被剥夺继承人资格。儿子死后，仍可指定他人为部分遗产的继承人，与遗嘱中已指定的继承人共同继承。

<!-- source-p 105 -->
<a id="28.2.28.1"></a>**1.**一名服兵役的家子，以军营特有财产订立遗嘱；当时他有一名儿子也受同一家父权力支配。此人停止服兵役后，其父即祖父死亡；问题是该遗嘱是否会被撤销。此人既未收养儿子，儿子也不是在此时才出生；而且，先前在权力之下的人退出后，也没有因此使更远一代的自权继承人递补到最近一代的位置。不过，他确实开始将原本不受自己权力支配的人纳入自己的权力之下，同时也成为家父；其儿子于是重新处于他的权力之下。因此，遗嘱会被撤销。但如果该儿子已被指定为继承人或被剥夺继承人资格，遗嘱就不会被撤销，因为儿子重新处于其权力之下，并非由于针对儿子采取了新的行为，而是基于自然顺序发生的变化。

<!-- source-p 106 -->
<a id="28.2.28.2"></a>**2.**如果某人写明，只有与特定妻子所生的孩子才是继承人，那么，他与其他女子所生的子女就可能导致遗嘱被撤销。

<!-- source-p 107 -->
<a id="28.2.28.3"></a>**3.**如果某人在某女子尚不能成为其合法妻子时，写明与她所生的孩子为继承人，那么，在之后缔结合法婚姻后出生的孩子能否依遗嘱成为继承人？例如，今天写明“凡与提提娅所生者，均为我的继承人”，但提提娅当时是女奴，或未满二十五岁，且其父曾由立遗嘱人管理监护事务，或者立遗嘱人本人曾是她的监护人；后来，提提娅成为立遗嘱人的合法妻子，或获得自由，或年满二十五岁，并已届满相应的一年期间且履行了账目申报义务。如此出生的孩子能否成为继承人？毫无疑问，即使订立遗嘱时，提提娅因年龄限制而不能成为其妻，立遗嘱人后来娶她为妻，与她所生的孩子仍可成为继承人。概而言之，凡遗嘱作成后出生并被指定为继承人的孩子，只要生母后来依法成为立遗嘱人的妻子，无论遗嘱作成时生母处于何种身份，该孩子均可接受遗产。

<!-- source-p 108 -->
<a id="28.2.28.4"></a>**4.**如果某人指定遗嘱作成后出生的儿子取得遗产的六分之四，指定遗嘱作成后出生的女儿取得三分之一，却没有另指定共同继承人，也没有互相指定替补继承人，那么，如果只出生了其中一个孩子，该孩子就单独依遗嘱成为继承人。

<!-- source-p 109 -->
<a id="28.2.29"></a>**28.2.29**

<!-- source-p 110 -->
**斯凯沃拉：《疑义集》第六卷。**

<!-- source-p 111 -->
<a id="28.2.29.pr."></a>**序言。**加卢斯提出，可以如此指定遗腹孙辈为继承人：“如果我的儿子在我生前死亡，那么凡在我死后、我儿子死亡后接下来的十个月内，由我儿子所生的孙子或孙女，均为继承人。”

<!-- source-p 112 -->
<a id="28.2.29.1"></a>**1.**有人认为，这种指定应予认可，即使遗嘱没有明言儿子死亡这一条件，而只是以能够从遗嘱文字推知的情形作了概括指定，并使其在该情形下有效。

<!-- source-p 113 -->
<a id="28.2.29.2"></a>**2.**加卢斯也应被认为就曾孙作了同样考虑，使立遗嘱人可以写道：“如果我的孙子在我生前死亡，那么由他所生的曾孙……”等等。

<!-- source-p 114 -->
<a id="28.2.29.3"></a>**3.**如果儿子仍在世，但曾孙已经死亡且其妻怀有身孕，立遗嘱人也可以作成遗嘱写道：“如果我的儿子在我生前死亡，那么届时出生的曾孙……”

<!-- source-p 115 -->
<a id="28.2.29.4"></a>**4.**那么，如果儿子和孙子都在世，立遗嘱人能否写道：“若二人均在我生前死亡，那么届时出生的曾孙……”？同样应予认可，但必须是孙子先死亡、儿子后死亡，以免遗嘱因继承顺位变动而被撤销。

<!-- source-p 116 -->
<a id="28.2.29.5"></a>**5.**如果立遗嘱人只规定了儿子死亡这一情形，结果又如何？例如，儿子遭到放逐并被禁止使用水火呢？又例如，作为曾孙之父、且立遗嘱人曾指定该曾孙为继承人的孙子，已被解放出家父权力呢？这些情形以及其他所有会使自权继承人在祖父死后出生的情形，都不属于《维莱亚法》〔底本异写：*Vellaeam*〕所规范的范围。不过，根据《维莱亚法》〔底本异写：*Vellaeae*〕的宗旨，也应将这些情形一并认可；如此便可仿照儿子死亡的情形，承认其他情形。

<!-- source-p 117 -->
<a id="28.2.29.6"></a>**6.**如果某人的儿子处于敌人权力之下，而他立下遗嘱，又会怎样？为什么不规定：儿子在自敌人处返回之前死亡，无论是在父亲死亡之前还是之后；或者儿子甚至仍在世时，孙子在祖父死亡后出生，均不撤销遗嘱？因为这种情形不属于《维莱亚法》〔底本异写：*Vellaeam*〕所规范的范围。因此，较好的做法是，尤其在《维莱亚法》废除多种会撤销遗嘱的情形之后，为实现这种制度目的而作解释：立遗嘱人指定孙子，使其在自己死后出生并成为自权继承人，应视为有效；无论孙子因何种情形在立遗嘱人死后出生，只要他出生后成为自权继承人，就会因被略过而撤销遗嘱。甚至立遗嘱人若概括写道：“凡在我死后出生的子女”或“无论何人出生”，只要该子女出生时成为自权继承人，也应认为指定有效。

<!-- source-p 118 -->
<a id="28.2.29.7"></a>**7.**如果某人有儿子，并指定由该儿子所生的孙子为继承人，而儿媳怀有身孕时被敌人俘获，并在敌境生子；此人后来在其父亲和祖父死后返回。那么，这种情形应依《维莱亚法》处理，还是应与旧法相协调？无论依旧法还是依《维莱亚法》指定该继承人，他是否都不会撤销遗嘱？如果立遗嘱人在儿子已经死亡后指定曾孙为继承人，而曾孙在立遗嘱人死亡后返回，也应考察同一问题。但既然遗嘱不会被撤销，曾孙是依旧法还是依《维莱亚法》而不被排除，就没有区别。

<!-- source-p 119 -->
<a id="28.2.29.8"></a>**8.**有人或许会怀疑，在这些情形中，如果孙子在其父亲仍在世时、遗嘱作成后出生，之后孙子之子受孕，并且该曾孙又在其父亲仍在世时、祖父死亡后出生，是否不能指定曾孙为继承人，因为他的父亲并未被有效指定为继承人。对此完全不必担忧：此处出生的是自权继承人，而且是在立遗嘱人死后出生。

<!-- source-p 120 -->
<a id="28.2.29.9"></a>**9.**因此，如果后来出生的孙子之子是曾孙，即使其父亲仍在世，该曾孙也应获准继承；如同他是从其父亲所生，因而被收养为家子一样。

<!-- source-p 121 -->
<a id="28.2.29.10"></a>**10.**在上述所有情形中，应遵守如下规则：只有受家父权力支配的儿子，才必须被指定为部分遗产的继承人；在其死后再剥夺其继承人资格，是徒劳的。对于处于敌人权力之下、并在敌境死亡的儿子，这项要求并非必要；对于孙子和曾孙也确实如此。如果他们的子女被指定为继承人，我们绝不要求作出这种指定，因为这些子女可以被略过。

<!-- source-p 122 -->
<a id="28.2.29.11"></a>**11.**现在我们来讨论《维莱亚法》。该法希望我们生前出生的后代，与其他情形相同，不得撤销遗嘱。

<!-- source-p 123 -->
<a id="28.2.29.12"></a>**12.**第一条似乎涉及这样的人：其出生时本应成为自权继承人。〔底本文字疑误：*sui heredes futurus essententiarum et rogo*〕我请教：如果你有一个儿子，并仅指定尚未出生的孙子为继承人，儿子死亡后，该孙子又在你生前出生，结论如何？根据法律文字，应当说遗嘱不会被撤销。第一条所指出的，不仅是儿子不在世时出生的孙子；即使孙子在儿子尚在世时出生，也应如此。因为既然只要观察出生之时便已足够，为何还须顾及遗嘱作成之时？尽管法律条文的文字如下：“凡订立遗嘱者，其所有将成为自权继承人的男性后代……”等等。

<!-- source-p 124 -->
<a id="28.2.29.13"></a>**13.**即使后代在父母尚在世时出生，依照下一部分，他们递补到子女的位置时，也不应撤销遗嘱。〔底本文字疑误：*vovente parente vivo*〕应当如此解释：若你有儿子、孙子和曾孙，在儿子和孙子均死亡后，递补到自权继承人位置的曾孙，不会撤销遗嘱。措辞“如果某一自权继承人不再是自权继承人”，确实涵盖所有情形；我们此前说过，应依加卢斯·阿奎利乌斯的意见补足这些情形。并且，不仅在孙子先于其父死亡、曾孙递补且其祖父死亡后，不会撤销遗嘱；即使孙子在其父之后死亡，只要他已被指定为继承人或被剥夺继承人资格，遗嘱也不会被撤销。

<!-- source-p 125 -->
<a id="28.2.29.14"></a>**14.**应当考察，后文“如果某一自权继承人不再是自权继承人，其子女等递补到自权继承人的位置”这一部分，是否可以解释为：如果你有一名处于敌人权力之下的儿子，并指定其孙子为继承人，那么即使儿子在你死亡后、且尚未自敌境返回之前死亡，孙子递补继承也不会撤销遗嘱。法律并未增添任何文字以表明时间限制；尽管这种说法颇为大胆，仍可认为该儿子在父亲生前即已不再是自权继承人，即使他死于父亲之后，因为他既未归来，也不可能归来。

<!-- source-p 126 -->
<a id="28.2.29.15"></a>**15.**有一种情形颇难处理：某人有儿子，并指定尚未出生的孙子为继承人；孙子在其父仍在世时出生，而其父随后死亡。孙子出生时还不是自权继承人；而且，似乎只有已经出生、递补到他人位置的人，才能依据后文而不使遗嘱被撤销。归根结底，前一条虽允许指定尚未出生、但出生时将成为自权继承人的人；后一条却不允许指定此类人，而只是禁止他们因递补而撤销遗嘱。然而，遗嘱要有效，指定必须有效；尚未出生的人依何种法律又能被有效指定？尽管如此，尤利安似乎把法律的两条规定结合起来，认为此处也适用该法，使遗嘱不被撤销。

<!-- source-p 127 -->
<a id="28.2.29.16"></a>**16.**不过，既然尤利安的意见已获采纳，我们仍要考察：如果孙子在其父仍在世时出生，后来又被解放出家父权力，他能否自愿接受遗产？较可取的答案是可以，因为解放使他不能成为自权继承人。

<!-- source-p 129 -->

<!-- source-p 130 -->
在订立遗嘱所必需考虑的事项中，首要的法律规则是指定子女为继承人或剥夺其继承人资格，以免因略过这些人而使遗嘱被撤销。因为略过受家父权力支配的儿子，会使遗嘱无效。

<a id="28.2.32"></a>**28.2.32**

<!-- source-p 135 -->
**马尔基安：《规则集》第二卷。**

<!-- source-p 136 -->
如果某人剥夺已被解放出家父权力的儿子的继承人资格，却略过仍受其家父权力支配的另一名儿子，那么，前一名已获解放的儿子若请求取得违背遗嘱的遗产占有，便不会成功；但在无遗嘱继承中，已获解放的儿子与自权继承人都将继承。
