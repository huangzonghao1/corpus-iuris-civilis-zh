# D.28.8 论考虑期间（*De iure deliberandi*）

<!-- source-p 001 -->
<a id="8"></a><a id="28.8"></a>**28.8.0. 论考虑期间。**

<!-- source-p 002 -->
<a id="28.8.1"></a>**28.8.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第六十卷。**

<!-- source-p 004 -->
<a id="28.8.1.pr."></a>**序言。**如果某奴隶被指定为继承人，我们当然不是为该奴隶本人设定考虑期间，而是为其所有人设定，因为在裁判官法上，奴隶本人不作为权利主体处理。如果该奴隶属于数名所有人，也当然应为所有所有人设定期间。

<!-- source-p 005 -->
<a id="28.8.1.1"></a>**1.**裁判官说：“若有人请求给予考虑期间，我将予以准许。”

<!-- source-p 006 -->
<a id="28.8.1.2"></a>**2.**裁判官说“期间”而未指定日期，这无疑表明，指定何日届满，属于行使司法管辖权者的裁量权：

<!-- source-p 007 -->
<a id="28.8.2"></a>**28.8.2**

<!-- source-p 008 -->
**保罗：《告示评注》第五十七卷。**

<!-- source-p 009 -->
不得给予少于一百日的期间。

<!-- source-p 010 -->
<a id="28.8.3"></a>**28.8.3**

<!-- source-p 011 -->
**乌尔比安：《告示评注》第六十卷。**

<!-- source-p 012 -->
还应知道，考虑期间有时只给予一次，有时则给予数次；前提是向裁判官说明，最初提出请求时所定的期间并不足够：

<!-- source-p 013 -->
<a id="28.8.4"></a>**28.8.4**

<!-- source-p 014 -->
**乌尔比安：《告示评注》第六十一卷。**

<!-- source-p 015 -->
但只有存在重大事由时，才应准许这一请求。

<!-- source-p 016 -->
<a id="28.8.5"></a>**28.8.5**

<!-- source-p 017 -->
**乌尔比安：《告示评注》第七十卷。**

<!-- source-p 018 -->
<a id="28.8.5.pr."></a>**序言。**阿里斯托写道，裁判官不仅应当援助债权人，也应援助遗嘱指定的继承人，并让他们有机会查阅文书，使他们能够据此判断接受遗产是否有利。

<!-- source-p 019 -->
<a id="28.8.5.1"></a>**1.**如果遗产数额较大，继承人正在考虑是否接受，而遗产中又有会因时间经过而变坏的物品，那么，经向裁判官请求，正在考虑的继承人可以按公平价格出售这些物品，而不因此受不利影响。他也可以出售保管费用过高的物品，例如役畜或待售奴隶，以及其他因迟延而会变坏的物品；此外，他还应设法清偿那些附有罚则，或以贵重质物担保的债务。

<!-- source-p 020 -->
<a id="28.8.6"></a>**28.8.6**

<!-- source-p 021 -->
**盖尤斯：《行省告示评注》第二十三卷。**

<!-- source-p 022 -->
因此，如果遗产中有葡萄酒、橄榄油、谷物或现款，相关费用应从这些财物中支出；若无，则应向遗产债务人催收款项。如果没有债务人，或者债务人提出争议、要求交由法官裁判，就应出售多余的物品。

<!-- source-p 023 -->
<a id="28.8.7"></a>**28.8.7**

<!-- source-p 024 -->
**乌尔比安：《告示评注》第六十卷。**

<!-- source-p 025 -->
<a id="28.8.7.pr."></a>**序言。**裁判官说：“若有人代表未成年男孩或女孩请求考虑期间，以判断保留遗产是否对其有利，且已准许该请求；如果看来存在正当理由，我将准许遗产财产在此期间减少，除非经审理后依善良人的裁量决定禁止。〔原文此处以不定式结构 *bona interea deminui* 表达准许，译文据下文补出省略的谓语。〕”

<!-- source-p 026 -->
<a id="28.8.7.1"></a>**1.**只要有人代表未成年人请求考虑期间，裁判官暂时阻止遗产财产减少，确有其道理。

<!-- source-p 027 -->
<a id="28.8.7.2"></a>**2.**但我们应考察“我将禁止财产减少”究竟是什么意思。裁判官用这些措辞，不仅禁止让与，也不准许提起诉讼；因为禁止某人让与财产，却允许其提起诉讼，是不合情理的。拉贝奥也是这样写的。

<!-- source-p 028 -->
<a id="28.8.7.3"></a>**3.**审理案件时，所要判断的是是否存在正当理由，使裁判官可以准许处分财产。因此，为办理丧葬而减少财产，他会准许；对于不作处置便会构成宗教罪愆、必须加以赎罪的事项，也会准许。同样，为维持生活所需，他也会准许减少财产。但在情势紧迫时，他还应基于其他事由准许处分，例如修缮建筑物、避免田地荒芜；又如有一笔附有罚则的债务应予清偿，为避免质物被变卖，也应准许处分。基于其他正当事由向裁判官提出请求时，裁判官也会准许处分；因为未经其许可，不得减少遗产财产。

<!-- source-p 029 -->
<a id="28.8.8"></a>**28.8.8**

<!-- source-p 030 -->
**乌尔比安：《告示评注》第六十一卷。**

<!-- source-p 031 -->
如果某自家继承人在先前表示不承受遗产之后，又请求给予考虑期间，我们应考察是否应准许；较可取的意见是，只有存在具体事由时才应准许，且此时遗产财产尚未出售。

<!-- source-p 032 -->
<a id="28.8.9"></a>**28.8.9**

<!-- source-p 033 -->
**保罗：《告示评注》第五十八卷。**

<!-- source-p 034 -->
儿子在考虑是否接受遗产期间，应从遗产中获得生活供养。

<!-- source-p 035 -->
<a id="28.8.10"></a>**28.8.10**

<!-- source-p 036 -->
**马尔凯卢斯：《学说汇纂》第二十八卷。**

<!-- source-p 037 -->
马尔凯卢斯说，如果遗嘱指定了数个顺位的继承人，裁判官会在每一顺位分别适用其关于设定考虑期间的告示；也就是说，遗产一旦由第一顺位转移给下一顺位，就应尽快找到继承人，使其能够对被继承人的债权人作出答复。

<!-- source-p 038 -->
<a id="28.8.11"></a>**28.8.11**

<!-- source-p 039 -->
**雅沃勒努斯：《拉贝奥后论》第四卷。**

<!-- source-p 040 -->
某人有一名自由民身份的儿子，并指定他为继承人，随后写道：“如果我没有能够脱离父权而成为自权人的儿子，那么，奴隶达马即获自由。”该儿子是一名未成年的自由民。有人问，达马是否因此获得自由。特雷巴提乌斯否认，因为“儿子”一词也包含自由民之子；拉贝奥则持相反意见，因为在此处应当把“儿子”理解为自由出生的儿子。我赞同特雷巴提乌斯的意见，但前提是能够看出立遗嘱人所说的正是这个儿子。
