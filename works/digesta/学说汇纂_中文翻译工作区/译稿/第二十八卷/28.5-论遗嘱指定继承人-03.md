### <a id="28.5.45"></a>28.5.45（44）

### <a id="28.5.47"></a>28.5.47（46）

<!-- source-p 217 -->
阿非利卡努斯《疑问》第二卷

<!-- source-p 218 -->
某人想指定一名家子为继承人，但不愿该家子的父亲从该遗产中取得任何利益，便向儿子说明了自己的意愿。儿子担心父亲因此不满，请求立遗嘱人不要附加“若其已由父亲解放”这一条件而指定自己为继承人，并成功说服立遗嘱人改指定自己的朋友为继承人；于是遗嘱将一位立遗嘱人不认识的儿子的朋友指定为继承人，也没有要求该朋友作任何承诺。问题是：若该朋友不愿承受遗产，或虽已承受却不愿返还遗产，能否向他请求履行遗嘱信托，或对他提起其他诉讼？该请求权属于父亲还是儿子？答复是：即使显然遗嘱指定的继承人曾表示愿意守信，除非还能证明立遗嘱人本人也信赖了他的诚信，否则仍不能向他请求履行遗嘱信托。不过，若该朋友是在家子请求之下承诺承受遗产并将其返还给家父，可以合理地主张存在委任之诉。父亲不能有效提起该诉，因为依诚信原则，不应把立遗嘱人本不愿归于父亲的财产返还给他。儿子也不能提起通常的委任之诉，但可以提起衡平诉讼，正如家子为他人提供保证、成为家父后履行保证债务时所承认的做法。

<!-- source-p 219 -->
### <a id="28.5.48"></a>28.5.48（47）

<!-- source-p 220 -->
阿非利卡努斯《疑问》第四卷

<!-- source-p 221 -->
<a id="28.5.48.pr."></a>

**序言（pr.）** 若遗嘱写道：“提图斯，或者说塞尤斯，作我的继承人”，答复是只有塞尤斯成为继承人。若遗嘱写道：“提图斯作我的继承人；或者说塞尤斯作我的继承人”，结论也相同。

<!-- source-p 222 -->
<a id="28.5.48.1"></a>

**1.** 某人在遗嘱中如此指定继承人：“我的女儿提蒂娅作我的继承人；若我在生前或死后有任何子女出生，则凡出生的一个或多个男性子女，各以二分之一及四分之一份额；凡出生的一个或多个女性子女，以四分之一份额，作我的继承人。”后来有遗腹子出生，遂询问遗腹子应取得多少份额。答复是：遗产应分为七份，女儿取得四份，遗腹子取得三份；因为女儿取得了全部遗产（*as*），遗腹子则取得四分之三（*dodrans*），所以女儿应比遗腹子多得四分之一。若另有遗腹女出生，则女儿单独所得应与两名遗腹子女合计所得相等〔此处底本末尾文字疑误：*habiturus essententiarum*〕。因此，就本案而言，既然女儿取得全部遗产，遗腹子取得四分之三，遗产应分为二十一份：女儿取得十二份，儿子取得九份。

<!-- source-p 223 -->
<a id="28.5.48.2"></a>

**2.** 遗嘱写道：“卢基乌斯·提图斯以十二分之二、盖乌斯·阿提乌斯以十二分之一、梅维乌斯以十二分之一、塞尤斯以十二分之二作为份额，作我的继承人。”有人询问该如何处理。答复是，这一写法可以解释为卢基乌斯·提图斯取得十二分之二，而其余各人虽未指定份额，却从剩余的十二分之十中作为继承人；这十二分之十应如此分配：塞尤斯取得十二分之五，阿提乌斯与梅维乌斯合计取得另一个十二分之五。

<!-- source-p 224 -->
### <a id="28.5.49"></a>28.5.49（48）

<!-- source-p 225 -->
马尔基安《法学阶梯》第四卷

<!-- source-p 226 -->
<a id="28.5.49.pr."></a>

**序言（pr.）** 采用“提图斯应为我遗产的主人”这一表述，能够有效指定继承人。

<!-- source-p 227 -->
<a id="28.5.49.1"></a>

**1.** 下列继承人指定有效：“我的儿子虽然极其不孝、对我很不好，仍应为继承人。”因为这是无条件指定继承人，只是在其中附带了辱骂；这类继承人指定均为法律所承认。

<!-- source-p 228 -->
<a id="28.5.49.2"></a>

**2.** 有时，女主人即使同时授予自由，也不能有效指定自己的奴隶为继承人；神圣塞维鲁与安敦尼的敕令说明了这一点，其文如下：“被指控犯有通奸罪的奴隶，若其女主人也因同一罪名被起诉，则该女主人在判决作出前以遗嘱释放该奴隶，不符合法律。”因此，女主人将继承人身份授予同一奴隶，也不发生效力。

<!-- source-p 229 -->
<a id="28.5.49.3"></a>

**3.** 若对父亲、家父身份或其他类似身份关系的描述写错，但所指之人仍可确定，继承人指定有效。

<!-- source-p 230 -->
### <a id="28.5.50"></a>28.5.50（49）

<!-- source-p 231 -->
弗洛伦提努斯《法学阶梯》第十卷

<!-- source-p 232 -->
<a id="28.5.50.pr."></a>

**序言（pr.）** 若我命令他人的奴隶获得自由并成为继承人，而该奴隶后来成为我的奴隶，那么这两项安排均无效，因为向他人的奴隶授予自由不发生效力。

<!-- source-p 233 -->
<a id="28.5.50.1"></a>

**1.** 对外人继承人，应遵守以下规则：无论是其本人还是处于其权力之下的人被指定为继承人，都必须与立遗嘱人具有遗嘱能力关系（*testamenti factio*）。对此须考察两个时点：一是作成遗嘱之时，以确认继承人指定有效；二是立遗嘱人死亡之时，以使该指定发生效力。此外，无论继承人是无条件还是附条件被指定，在承受遗产时也必须与立遗嘱人具有遗嘱能力关系；因为继承人的法律资格尤其应在其取得遗产之时加以判断。在遗嘱作成与立遗嘱人死亡或继承人指定所附条件成就之间，继承人法律地位的改变不致损害其资格，因为如我所说，应考察三个时点。

<!-- source-p 234 -->
### <a id="28.5.51"></a>28.5.51（50）

<!-- source-p 235 -->
乌尔比安《规则》第六卷

<!-- source-p 236 -->
<a id="28.5.51.pr."></a>

**序言（pr.）** 我将自己的奴隶连同自由一并指定为继承人；若我生前把他卖给一个与我不具遗嘱能力关系的人，之后又将他买回，他仍可依我的遗嘱成为继承人。其间他曾属于该买受人的事实，并未使继承人指定失效，因为在作成遗嘱时和我死亡时，他确实都属于我。因此，若他仍留在买受人处，继承人指定便会失效；若他与买受人具有遗嘱能力关系，则他可依买受人的命令承受遗产，使买受人取得遗产。

<!-- source-p 237 -->
<a id="28.5.51.1"></a>

**1.** 若继承人指定附有一项要求其不作为、但不作为不可能实现的条件，依通说，该继承人仍将成为继承人，犹如其被无条件指定。

<!-- source-p 238 -->
<a id="28.5.51.2"></a>

**2.** 遗产通常分为十二盎司份额（*uncia*），十二份合称一整份（*as*）。从盎司份额到整份，各份额还有自己的名称，例如：六分之一份（*sextans*）、四分之一份（*quadrans*）、三分之一份（*triens*）、十二分之五份（*quincunx*）、半份（*semis*）、十二分之七份（*septunx*）、三分之二份（*bes*）、四分之三份（*dodrans*）、十二分之十份（*dextans*）、十二分之十一份（*deunx*）以及整份（*as*）。

<!-- source-p 239 -->
### <a id="28.5.52"></a>28.5.52（51）

<!-- source-p 240 -->
马尔基安《规则》第三卷

<!-- source-p 241 -->
<a id="28.5.52.pr."></a>

**序言（pr.）** 有些人认为下列继承人指定无效：“斯提库斯获得自由；若他获得自由，则成为继承人。”但神圣马尔库斯皇帝以敕答指出，这项指定有效，视同未附加“若他获得自由”这一条件。

<!-- source-p 242 -->
<a id="28.5.52.1"></a>

**1.** 若有人写道：“斯提库斯若在我死亡时属于我，即获得自由并成为继承人”，那么，斯提库斯若已被转让，便不能依买受人的命令承受遗产；即使没有明确写出这一条件，他也只有在仍属于立遗嘱人时才能获得自由并成为继承人。但是，若立遗嘱人生前释放了他，塞尔苏斯在《学说汇纂》第十五卷中写道，此人仍可成为继承人；因为显然立遗嘱人并未意图排除此种情形，遗嘱文字也并未与之完全冲突：他虽不再是立遗嘱人的奴隶，却仍是其释奴。

### <a id="28.5.53"></a>28.5.53（52）

<!-- source-p 244 -->
保罗《规则》第二卷

<!-- source-p 245 -->

### <a id="28.5.54"></a>28.5.54（53）

<!-- source-p 247 -->
马尔切鲁斯《关于解答的单篇论著》

<!-- source-p 248 -->
卢基乌斯·提图斯指定塞尤斯和塞姆普罗尼乌斯各以二分之一份额为继承人，剥夺其他人的继承权，并令二人互为替补继承人；随后又作出遗赠并授予自由，之后补写道：“科尔内利乌斯、萨卢斯提乌斯和瓦罗各以相等份额为继承人，并令三人互为替补继承人。”我询问，最初各获二分之一份额的前两人以及后来指定的三人各应取得多少。马尔切鲁斯答复：遗嘱人究竟是要将科尔内利乌斯、萨卢斯提乌斯和瓦罗指定为第一顺位、第二顺位还是第三顺位继承人，文字并不清楚；但依所述遗嘱文字，应认为另有一个整份遗产（*as*）分配给了他们。

### <a id="28.5.55"></a>28.5.55（54）

<!-- source-p 250 -->
涅拉提乌斯《书简集》第一卷

<!-- source-p 251 -->
父亲为未适婚年龄的儿子指定一名奴隶为替补继承人，并命令该奴隶获得自由。未适婚年龄的儿子后来将奴隶卖给提图斯；提图斯在先前已作成一份遗嘱后，又于第二份遗嘱中命令该奴隶获得自由并成为继承人。提图斯先前的遗嘱因此被撤销，因为该奴隶既可以获得自由，也可以成为继承人；只要后作遗嘱在某种情形下可能使其成为继承人，便足以撤销先前遗嘱。至于后作遗嘱中继承人指定的效力，情况如下：只要该奴隶仍可能依据对未适婚儿子的替补指定成为继承人，他便不能依提图斯的遗嘱取得自由和遗产；若该儿子已达到亲自管理自己事务的年龄，则奴隶将依提图斯的遗嘱成为自由人和继承人，犹如他未被指定为该儿子的替补继承人；若他已成为该儿子的继承人，更可取的意见是：只要他愿意，也可以成为提图斯的继承人。

<!-- source-p 252 -->
### <a id="28.5.56"></a>28.5.56（55）

<!-- source-p 253 -->
保罗《评〈埃利亚·森提亚法〉》第一卷

<!-- source-p 254 -->
若一名无清偿能力者先指定斯提库斯为继承人，再将一名依遗嘱信托负有释放义务的人指定为第二顺位继承人，并命令该人获得自由，涅拉提乌斯认为，第二顺位指定的继承人将成为继承人；因为这名奴隶并非为了欺诈债权人而被释放。

### <a id="28.5.57"></a>28.5.57（56）

<!-- source-p 256 -->

<!-- source-p 257 -->

<!-- source-p 258 -->
### <a id="28.5.58"></a>28.5.58（57）

<!-- source-p 259 -->
保罗《告示评注》第五十七卷

<!-- source-p 260 -->
若无清偿能力者指定奴隶连同自由一并成为继承人，并另指定一名自由人为替补继承人，应先由替补继承人承受遗产。因为依《埃利亚·森提亚法》，只有在该遗嘱下没有其他人能够成为继承人时，才保全为欺诈债权人而被指定为继承人的奴隶所获的自由。

### <a id="28.5.59"></a>28.5.59（58）

<!-- source-p 262 -->
保罗《评维泰利乌斯》第四卷

<!-- source-p 263 -->
<a id="28.5.59.pr."></a>

**序言（pr.）** 若所指之人就在场，立遗嘱人指着他写道“此人作我的继承人”，毫无疑问，这样指定继承人是有效的。

<!-- source-p 264 -->
<a id="28.5.59.1"></a>

**1.** 某人并非立遗嘱人的兄弟，但立遗嘱人像兄弟般爱他，则可在写明其姓名的同时，以“兄弟”这一称谓有效指定他为继承人。

### <a id="28.5.60"></a>28.5.60（59）

<!-- source-p 266 -->
塞尔苏斯《学说汇纂》第十六卷

<!-- source-p 267 -->
<a id="28.5.60.pr."></a>

**序言（pr.）** 一名自由人曾作为奴隶侍奉你，被指定为继承人后依你的命令承受遗产。特雷巴提乌斯认为，他因此成为继承人；拉贝奥则认为，若他是迫于必要而这样做，并非原本愿意受此约束，就不能成为继承人。

<!-- source-p 268 -->
<a id="28.5.60.1"></a>

**1.** 若有人这样指定继承人：“提图斯在盐场公课经营中与我合伙占有多少份额，就以该份额作我的继承人”，有人认为，若在列明全部遗产份额之后又加上这句话，且提图斯确为合伙人，则提图斯不能成为继承人；但若遗产有一部分未作分配，则他可就该空缺部分成为继承人。这种观点完全不妥且有缺陷：既已列明整份遗产，又有什么妨碍有效指定提图斯就其合伙份额——例如四分之一份额——成为继承人？

<!-- source-p 269 -->
<a id="28.5.60.2"></a>

**2.** 遗嘱写道：“提图斯作继承人；塞尤斯与梅维乌斯作继承人。”普罗库鲁斯的意见是正确的：遗产分为两个半份，其中一半共同分给二人。

<!-- source-p 270 -->
<a id="28.5.60.3"></a>

**3.** 若数名被指定者中，有一人并非与他人共同指定，却未能成为继承人，其份额便按遗嘱所定的继承份额比例归增于所有继承人；无论此人是第一顺位继承人，还是某人的替补继承人，均无不同。

<!-- source-p 271 -->
<a id="28.5.60.4"></a>

**4.** 若某人在遗嘱作成时是罗马公民，后来被禁止用水用火、遭放逐，只要他在立遗嘱人死亡前返回，便成为继承人；若其继承人指定附有条件，则须在条件成就时已经返回。遗赠和遗产占有也适用相同规则。

<!-- source-p 272 -->
<a id="28.5.60.5"></a>

**5.** 遗嘱写道：“提图斯取得二分之一份额；塞尤斯取得四分之一份额；若提图斯登上卡比托山，则再取得四分之一份额。”提图斯尚未登上卡比托山时，若他已以继承人身份处分遗产，便成为二分之一份额的继承人；若后来登上卡比托山，还可取得四分之一份额。由于他届时已经是继承人，无须再以继承人身份处分遗产。

<!-- source-p 273 -->
<a id="28.5.60.6"></a>

**6.** 遗嘱若写道：“提图斯以三分之一份额、梅维乌斯以三分之一份额作继承人；若在第三个朔日前有船从亚洲抵达，则提图斯再以剩余份额作继承人”，须考察提图斯是否立即取得二分之一份额。因为遗嘱指定了两名继承人，但提图斯可能取得二分之一，也可能取得三分之二；因此有六分之一份额处于待定状态。条件成就时，提图斯取得三分之二；条件未成就时，该六分之一份额归增于梅维乌斯。即使提图斯在条件成就前死亡，后来条件成就，该六分之一份额也不归增于提图斯的继承人，而是归增于梅维乌斯：当时尚不能确定这六分之一份额究竟给了提图斯还是梅维乌斯，提图斯便已死亡；不能认为该份额给了分配时已不在人世之人。

<!-- source-p 274 -->
<a id="28.5.60.7"></a>

**7.** 若阿提乌斯指定提图斯、梅维乌斯和塞尤斯各以相等份额为继承人，提图斯暂时独自承受遗产，随后又指定塞尤斯为自己的继承人，那么塞尤斯可以承受提图斯的遗产；对于阿提乌斯的遗产，他则可以选择承受或放弃。但在承受或放弃阿提乌斯的遗产之前，塞尤斯将按二分之一份额成为继承人。若塞尤斯承受阿提乌斯的遗产，提图斯便仅以三分之一份额成为继承人；通过提图斯的遗产，塞尤斯也仅取得三分之一份额，另一个三分之一份额则依据他本人的继承人指定取得。那么，若阿提乌斯指定提图斯和塞尤斯为继承人，提图斯承受遗产后，塞尤斯又成为提图斯的继承人，情况如何？塞尤斯能否放弃阿提乌斯的遗产，还是必然成为其全部遗产的继承人？由于除塞尤斯外没有指定其他继承人，而他本人已凭某一份额成为继承人，这种情形就如同仅通过提图斯指定了一名继承人。〔本段关于份额及承受顺序的关系较为复杂，照底本逐句译出。〕

<!-- source-p 275 -->
### <a id="28.5.61"></a>28.5.61（60）

<!-- source-p 276 -->
塞尔苏斯《学说汇纂》第二十九卷

<!-- source-p 277 -->
某个无清偿能力者先指定一名奴隶、再指定另一名奴隶为继承人。只有排在第一位被指定的奴隶取得遗产；因为《埃利亚·森提亚法》规定，若同一原因下有两名或更多人被指定为继承人，则以最先被指定者为继承人。

<!-- source-p 278 -->
### <a id="28.5.62"></a>28.5.62（61）

<!-- source-p 279 -->
莫德斯丁《解答》第八卷

<!-- source-p 280 -->
某人想在遗嘱中剥夺女儿的继承权，于是写道：“女儿，我剥夺你的继承权，是因为我希望你以嫁资为满足。”我询问，这样是否有效地剥夺了她的继承权。莫德斯丁答复：所述情形没有提出任何理由，足以否定立遗嘱人已按其意愿剥夺女儿继承权的效力。

<!-- source-p 281 -->
### <a id="28.5.63"></a>28.5.63（62）

<!-- source-p 282 -->
莫德斯丁《潘德克顿》第二卷

<!-- source-p 283 -->
<a id="28.5.63.pr."></a>

**序言（pr.）** 为使继承人在能够承受遗产时才成为继承人而作出指定，属于善意安排，例如：“卢基乌斯·提图斯在能够承受遗产时，作我的继承人。”遗赠也适用同一规则。

<!-- source-p 284 -->
<a id="28.5.63.1"></a>

**1.** 若无法确定究竟指定了谁为继承人，该继承人指定即无效；例如，立遗嘱人有数名同名朋友，却只用一个名字指示继承人。除非其他明确无疑的证据能够揭示立遗嘱人所指的是哪一个人。

<!-- source-p 285 -->
### <a id="28.5.64"></a>28.5.64（63）

<!-- source-p 286 -->
雅沃勒努斯《摘自卡西乌斯》第一卷

<!-- source-p 287 -->
未指定份额的继承人以共同方式还是分别方式指定，区别在于：若共同指定的一组中有人死亡，其份额只归增于同组的其他人；若继承人是分别指定的，其份额则归增于同一遗嘱中指定的所有继承人。

<!-- source-p 288 -->
### <a id="28.5.65"></a>28.5.65（64）

<!-- source-p 289 -->
雅沃勒努斯《书信》第七卷

<!-- source-p 290 -->
拉贝奥屡次写道，可以指定某一将在我死后出生之人的奴隶为继承人；他以明显的理由证明这一点：遗产中的奴隶在遗产尚未被承受前可以被指定为继承人，尽管在遗嘱作成时他尚不属于任何人。

<!-- source-p 291 -->
### <a id="28.5.66"></a>28.5.66（65）

<!-- source-p 292 -->
雅沃勒努斯《书信》第十二卷

<!-- source-p 293 -->
遗产在任何法律依据上都不属于斯塔提乌斯·普里穆斯，因为他并未被指定为继承人。他也不能因为有人向他作出遗赠，或立遗嘱人在遗嘱中将自己的释奴托付给他，就取得任何利益。因此，若该人未被释放，他仍是奴隶。

<!-- source-p 294 -->
### <a id="28.5.67"></a>28.5.67（66）

<!-- source-p 295 -->
庞波尼乌斯《评昆图斯·穆齐乌斯》第一卷

<!-- source-p 296 -->
若有人这样指定继承人：“提图斯作继承人；盖乌斯和梅维乌斯各以相等份额作继承人”，尽管连词“和”（*et*）具有连接作用，但其中一人死亡时，其份额并非仅归增于另一人，而应按各继承人的继承份额比例归增于所有共同继承人；因为这里的写法，与其说是要把他们合并为一个共同指定的组，不如说只是为了简便而将他们一并写出。
