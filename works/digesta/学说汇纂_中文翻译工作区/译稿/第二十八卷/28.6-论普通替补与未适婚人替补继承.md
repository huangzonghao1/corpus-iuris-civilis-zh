# <a id="6"></a><a id="28.6"></a>28.6 论普通替补与未适婚人替补继承（*De vulgari et pupillari substitutione*）

<!-- source-p 002 -->
### <a id="28.6.1"></a>28.6.1

<!-- source-p 003 -->
莫德斯丁《潘德克顿》第二卷

<!-- source-p 004 -->
<a id="28.6.1.pr."></a>

**序言（pr.）** 继承人分为被指定的继承人和替补继承人：被指定者处于第一顺位，替补者处于第二或第三顺位。

<!-- source-p 005 -->
<a id="28.6.1.1"></a>

**1.** 继承人替补可以是单重的，也可以是双重的。普通替补例如：“卢基乌斯·提图斯作继承人；若卢基乌斯·提图斯不作我的继承人，则令塞尤斯作我的继承人。”双重替补例如：“若提图斯不作继承人，或者虽作了继承人但在达到适婚年龄前死亡，则令盖乌斯·塞尤斯作我的继承人。”

<!-- source-p 006 -->
<a id="28.6.1.2"></a>

**2.** 父亲可以为子女指定替补继承人，无论子女已被指定为继承人还是已被剥夺继承权；也可以指定已被立遗嘱人指定为其继承人的人，或指定另一人作为替补继承人。

<!-- source-p 007 -->
<a id="28.6.1.3"></a>

**3.** 父亲只有在指定继承人为自己的继承人后，才能为子女指定替补继承人；因为未指定继承人时，遗嘱中所写的其他内容均不发生效力。

<!-- source-p 008 -->
### <a id="28.6.2"></a>28.6.2

<!-- source-p 009 -->
乌尔比安《评萨宾》第六卷

<!-- source-p 010 -->
<a id="28.6.2.pr."></a>

**序言（pr.）** 依习惯法，父亲可以为未达到适婚年龄的子女订立遗嘱，直到男孩年满十四岁、女孩年满十二岁。此规则应理解为仅适用于仍处于父亲权力之下的子女；对于已解放的子女，则不能这样做。不过，可以为遗腹子女作此指定。也可以为孙辈及更晚辈的直系后代作此指定，只要他们不会重新归入其父亲的权力之下。若他们的父亲先于他们，则只有在孙辈已被指定为继承人或被剥夺继承权时，才能为他们指定替补继承人；这样，他们在《维莱亚法》之后作为继承人递补时便不会撤销遗嘱。因为若作为基础的遗嘱被撤销，未适婚人替补遗嘱也随之失效。但是，若某人将一名外人指定为未适婚继承人，只要在其儿子在世时将此人收养为孙辈（收养或收为养子），也可以为他指定替补继承人。

<!-- source-p 011 -->
<a id="28.6.2.1"></a>

**1.** 凡为未适婚子女订立遗嘱者，也应为自己订立遗嘱；否则，除非其为军人，不能只为儿子订立遗嘱。为自己订立遗嘱是如此必要，以致若父亲的遗产尚未被承受，未适婚人替补遗嘱便会失效。不过，即使基础遗嘱未被执行、遗产改按无遗嘱继承方式占有，也应当认为仍须维护为未适婚子女指定的替补继承人。

<!-- source-p 012 -->
<a id="28.6.2.2"></a>

**2.** 有时，为使未适婚人替补遗嘱项下的遗嘱信托生效，甚至可以强制被指定的继承人承受遗产；例如未适婚子女已经死亡时即属此种情形。反之，若子女仍在世，尤利安认为，关切一个活人的遗产归属是不当的。

<!-- source-p 013 -->
<a id="28.6.2.3"></a>

**3.** 我还认为，若某人因承受遗产之事获得未满二十五岁者的回复原状救济，第二遗嘱书亦可因此发生效力，使裁判官得为替补继承人授予准诉权。

<!-- source-p 014 -->
<a id="28.6.2.4"></a>

**4.** 某人应先为自己指定继承人，再为儿子指定替补继承人，不得颠倒书写顺序。尤利安认为，应先为自己指定继承人，再为儿子指定继承人；若先为儿子、后为自己订立遗嘱，则遗嘱无效。我们的皇帝致不列颠尼亚行省总督维里乌斯·卢普斯的敕答确认了这一意见，而且理由充分：虽然涉及两项遗产，但遗嘱只有一份；因此，某人指定为自己必然继承人的人，也会成为其儿子的必然继承人；父亲也可以为未适婚儿子指定自己的遗腹子为替补继承人。

<!-- source-p 015 -->
<a id="28.6.2.5"></a>

**5.** 但若某人先写道：“若我的儿子在十四岁生日前死亡，令塞尤斯作继承人”，随后又写“儿子作继承人”，则替补指定仍然有效，尽管遗嘱书写顺序颠倒，先写了儿子的遗嘱。

<!-- source-p 016 -->
<a id="28.6.2.6"></a>

**6.** 若遗嘱写道：“若我的儿子不作我的继承人，令塞尤斯作继承人；儿子作继承人”，塞尤斯确是第二顺位继承人；若儿子未成为继承人，毫无疑问塞尤斯便成为他的继承人。但若儿子成为继承人后在达到适婚年龄前死亡，似乎也应准许塞尤斯继承；此时应看继承发生的先后次序，而非遗嘱书写顺序。

<!-- source-p 017 -->
<a id="28.6.2.7"></a>

**7.** 之所以规定父亲可以分别为每个子女指定替补继承人，是为了说明不应从未适婚儿子的遗嘱开始处理。

<!-- source-p 018 -->
### <a id="28.6.3"></a>28.6.3

<!-- source-p 019 -->
莫德斯丁《区别论》第一卷

<!-- source-p 020 -->
父亲为未达到适婚年龄的儿子指定替补继承人时，若写道：“凡作我的继承人者，也作我未适婚儿子的继承人”，则只有按此方式写明的人才能承受儿子的遗产。因此，若某人通过遗产中的奴隶取得遗产份额，但该奴隶后来脱离其权力，该人便不能依未适婚人替补而成为儿子的继承人。

<!-- source-p 021 -->
### <a id="28.6.4"></a>28.6.4

<!-- source-p 022 -->
莫德斯丁《关于法学发现（De heurematicis）的单篇论著》

<!-- source-p 023 -->
<a id="28.6.4.pr."></a>

**序言（pr.）** 根据神圣马尔库斯与维鲁斯皇帝的敕令，我们现行法是：父亲若在一种情形下为未适婚儿子指定替补继承人，该指定即视为同时适用于两种情形——儿子未成为继承人，或者儿子成为继承人后在未达到适婚年龄时死亡。

<!-- source-p 024 -->
<a id="28.6.4.1"></a>

**1.** 这项规则似乎也扩展至第三种替补继承。若父亲指定两个未适婚儿子为继承人，并令二人互为替补继承人，神圣庇护皇帝裁定，应视为已就两种情形作了相互替补指定。

<!-- source-p 025 -->
<a id="28.6.4.2"></a>

**2.** 但若父亲以“我令二人互为替补继承人”这一共同表述，使一名已达到适婚年龄的儿子与一名未适婚儿子互为替补，塞维鲁与安敦尼皇帝裁定，该替补仅适用于普通替补的情形。否则会出现不协调的结果：一人适用双重替补，另一人却仅适用普通替补。因此，此时父亲应分别为每个儿子指定替补继承人：若已达适婚年龄的儿子未成为继承人，则由未适婚的兄弟替补；若未适婚儿子成为继承人后在达到适婚年龄前死亡，则由已达适婚年龄的兄弟替补其共同继承人的份额。如此方可认为替补适用于两种情形。为避免争议，父亲也可以明确写明，在两种情形下均由兄弟替补未适婚儿子：“无论他未成为继承人，还是成为继承人后在达到适婚年龄之前死亡。”

<!-- source-p 026 -->
### <a id="28.6.5"></a>28.6.5

<!-- source-p 027 -->
盖尤斯《评〈尤利亚与帕皮亚法〉》第三卷

<!-- source-p 028 -->
若遗嘱中指定了数名继承人，并规定某人若未成为继承人，则凡成为立遗嘱人继承人的人也继承其未取得的份额，应认为每个人按其实际取得的继承份额比例，也有权取得未被承受的那一份；无论其取得较大份额是依据遗嘱中的继承人指定，还是依据某一法律主张了他人的另一份额，均不影响。

<!-- source-p 029 -->
### <a id="28.6.6"></a>28.6.6

<!-- source-p 030 -->
克莱门提乌斯《评〈尤利亚与帕皮亚法〉》第四卷

<!-- source-p 031 -->
若某人本不能从立遗嘱人的遗产中取得全部遗产，而立遗嘱人将其指定为未适婚儿子的替补继承人，则该人可因这一替补指定而取得全部遗产，仿佛该遗产是从未适婚儿子处取得的。但我们的尤利安似乎将此解释为：该人不得从原属立遗嘱人的财产中取得超过其依法可得的部分。反之，若未适婚子女后来另行取得财产，或该人是替补一名被剥夺继承权者，则不妨碍其取得该财产，因为这相当于从未适婚子女处取得。

<!-- source-p 032 -->
### <a id="28.6.7"></a>28.6.7

<!-- source-p 033 -->
帕比尼安《解答》第六卷

<!-- source-p 034 -->
依市民法措辞作出的替补指定，在子女年满十四岁后作出即属无效。但某人若不能作为替补继承人受理，也不得在任何时候被当作追加继承人；否则，若儿子在此期间未取得父亲遗嘱给予他的全部财产，便会违背父亲的意愿。〔此句结构及“追加继承人”的含义建议复核。〕

<!-- source-p 035 -->
### <a id="28.6.8"></a>28.6.8

<!-- source-p 036 -->
乌尔比安《评萨宾》第四卷

<!-- source-p 037 -->
<a id="28.6.8.pr."></a>

**序言（pr.）** 为未适婚子女指定替补继承人，通常可以无条件作出，也可以附条件作出。无条件指定例如：“若我的儿子在达到适婚年龄前死亡，令塞尤斯作继承人。”无论塞尤斯同时被指定为立遗嘱人的继承人并替补未适婚子女，还是仅被指定为替补继承人，这项指定都不附任何条件。若替补继承人是附条件被指定，即“若某人作我的继承人”，则只有在他依遗嘱指定本身成为继承人的情况下，才会因替补指定而成为继承人。下列替补方式也与此相同：“凡上述人员中作我的继承人者”；它也包含与前述相同的条件。

<!-- source-p 038 -->
<a id="28.6.8.1"></a>

**1.** “凡作我的继承人者，也作我未适婚儿子的继承人”这句话的意思是：不是凡成为父亲继承人的人都成为儿子的替补继承人，而只有依遗嘱成为父亲继承人的人才是替补继承人。因此，父亲若是通过儿子成为继承人，或主人若是通过奴隶成为继承人，均不得依此替补继承；继承人的继承人也不得依此继承，因为他们并非依据遗嘱而取得继承地位。替补继承人所取得的份额，也应与他们在家父遗产中所取得的份额相同。

<!-- source-p 039 -->
### <a id="28.6.9"></a>28.6.9

<!-- source-p 040 -->
拉贝奥《后论》第一卷（由雅沃勒努斯节编）

<!-- source-p 041 -->
若父亲为未适婚儿子指定与自己相同的继承人，并另外指定你为继承人，那么儿子的遗产中，你取得二分之一，其余父亲的继承人共同取得另一半；其中一半留给你，另一半则按这些人继承父亲遗产时各自所占份额，在父亲的继承人之间分配。

<!-- source-p 042 -->
### <a id="28.6.10"></a>28.6.10

<!-- source-p 043 -->
乌尔比安《评萨宾》第四卷

<!-- source-p 044 -->
<a id="28.6.10.pr."></a>

**序言（pr.）** 若有数人以“凡上述人员中作我继承人者”这种方式被指定为替补继承人，而其中有人在成为父亲的继承人后死亡，则只有仍在世者依替补指定成为继承人，并按他们被指定时各自的份额比例取得遗产；已死亡者所对应的指定不发生效力。

<!-- source-p 045 -->
<a id="28.6.10.1"></a>

**1.** 凡我可以指定为自己必然继承人的人，也可以指定为儿子的必然继承人，例如我的奴隶以及尚未出生的儿子的兄弟。因此，遗腹子将成为其兄弟的必然继承人。

<!-- source-p 046 -->
<a id="28.6.10.2"></a>

**2.** 某人被指定为未适婚儿子的替补继承人，而儿子被指定为父亲全部遗产的继承人；儿子后来成为父亲的继承人。替补继承人能否把两项遗产分开，只承受儿子的遗产而不承受父亲的遗产？不能；他必须同时承受两项遗产，或两项均不承受，因为两项遗产已经合并。

<!-- source-p 047 -->
<a id="28.6.10.3"></a>

**3.** 父亲若以某一份额指定我、另以某一份额指定儿子为继承人，而我放弃父亲的遗产，结果也相同：我也不能承受儿子的遗产。

<!-- source-p 048 -->
<a id="28.6.10.4"></a>

**4.** 某人被指定为全部遗产的继承人，并在儿子被剥夺继承权的情况下被指定为儿子的替补继承人；若他放弃父亲的遗产，且没有替补继承人，他便不能承受儿子的遗产。因为除非父亲的遗产已经被承受，儿子的遗嘱就不发生效力；仅仅是遗嘱以某种方式作成、使人可以据此承受遗产，并不足以使第二遗嘱书生效。

<!-- source-p 049 -->
<a id="28.6.10.5"></a>

**5.** 未适婚人替补继承人也取得未适婚子女后来获得的财产；因为立遗嘱人指定的是未适婚子女遗产的替补继承人，而非自己财产的替补继承人。即使子女已被剥夺继承权，父亲也可以为其指定替补继承人。除非你所说的是军人指定了替补继承人，并且其意图仅使替补继承人取得自己转给被指定继承人的那些财产。

<!-- source-p 050 -->
<a id="28.6.10.6"></a>

**6.** 未适婚子女被他人收为养子时，我们认为，养父指定的替补继承人不应取得该子女若未被收养本可拥有的财产，只能取得养父本人给予他的财产。或者也可以作如下区分：替补继承人不能取得养父依神圣庇护皇帝敕答无论如何都必须留给养子的四分之一份额，但可以取得超出该份额的部分。不过，斯凯沃拉在《疑问》第十卷中认为，甚至这一点也可由养父决定；此说有其道理。我甚至认为，养子若因养父的恩惠而取得任何财产，替补继承人也可以取得；例如养父的朋友或亲属留给养子的财产。

<!-- source-p 051 -->
<a id="28.6.10.7"></a>

**7.** 某人被指定为继承人，又被指定为自己的替补继承人，若没有继承原因的改变，不能因此取得任何利益；但这只适用于一个顺位。若存在两个顺位，替补指定则可能有效，正如尤利安在《学说汇纂》第三十卷中的意见。譬如，某人与共同继承人提图斯一同被指定为继承人，又这样指定自己的替补继承人：“若斯提库斯不成为继承人，令其获得自由并成为继承人”，此替补指定无效。若改写为：“若提图斯不成为继承人，则令斯提库斯获得自由并成为继承人，取得提图斯的份额”，这便构成两个顺位；因此，提图斯放弃继承后，斯提库斯将获得自由并成为继承人。

<!-- source-p 052 -->
### <a id="28.6.11"></a>28.6.11

<!-- source-p 053 -->
保罗《评萨宾》第一卷

<!-- source-p 054 -->
若被指定为继承人的人也被指定为儿子的替补继承人，那么，只要他在儿子死亡时有能力取得遗产，该替补指定便不会对他造成不利。反过来，即使他未在父亲的遗嘱中承受惩罚，也可能在儿子的遗嘱中承受惩罚。

<!-- source-p 055 -->
### <a id="28.6.12"></a>28.6.12

<!-- source-p 056 -->
帕比尼安《疑问》第三卷

<!-- source-p 057 -->
若某儿子先成为父亲的继承人，随后又依据第二遗嘱书成为兄弟的继承人，但他愿意拒绝父亲的遗产而保留兄弟的遗产，法院应听取他的请求。我认为，裁判官若准许他将兄弟的遗产与父亲的财产分开处理，更为公正。因为裁判官的职责在于使子女免受其未自愿承担的继承负担，而非违背其意愿将其排除于遗产之外；尤其是，即使没有第二遗嘱书，他本来也会依法取得兄弟的遗产。因此，只须履行第二遗嘱书中的遗赠；适用《法尔基第法》时，应以未适婚子女而非父亲的财产为计算基础。

<!-- source-p 058 -->
### <a id="28.6.13"></a>28.6.13

<!-- source-p 059 -->
庞波尼乌斯《评萨宾》第一卷

<!-- source-p 060 -->
为子女指定替补继承人时，替补顺位并不重要。

<!-- source-p 061 -->
### <a id="28.6.14"></a>28.6.14

<!-- source-p 062 -->
庞波尼乌斯《评萨宾》第二卷

<!-- source-p 063 -->
即使未适婚人替补指定了更长的期间，该替补仍于子女达到适婚年龄时终止。

<!-- source-p 064 -->
### <a id="28.6.15"></a>28.6.15

<!-- source-p 065 -->
帕比尼安《解答》第六卷

<!-- source-p 066 -->
一名百夫长直接为儿子指定替补继承人，规定若儿子在二十五岁之前、且未留下子女便死亡，由该人替补。儿子未满十四岁时，依普通法，替补继承人还可取得儿子的自有财产；超过该年龄后，依军人特权，替补继承人只能取得父亲的遗产以及遗产中所发现的孳息。

<!-- source-p 067 -->
### <a id="28.6.16"></a>28.6.16

<!-- source-p 068 -->
庞波尼乌斯《评萨宾》第三卷

<!-- source-p 069 -->
<a id="28.6.16.pr."></a>

**序言（pr.）** 若某人在自己的遗嘱中将某物遗赠给他人，后来又在儿子的替补遗嘱中命令该受遗赠人获得自由，该人便获得自由，仿佛遗赠已被撤销；因为遗赠也应以这些遗嘱中最后作成的文字为准，正如同一份遗嘱中的后写内容（或经确认的遗嘱及遗嘱附书中的后写内容）所适用的规则。

<!-- source-p 070 -->
<a id="28.6.16.1"></a>

**1.** 父亲完成自己的遗嘱后，后来另择时间，在有法定证人的情况下为儿子订立遗嘱，该遗嘱仍然有效，而父亲自己的遗嘱也继续有效。若父亲先为自己和儿子订立遗嘱，后来又只为自己订立遗嘱，则前两份遗嘱均被撤销。但若父亲在第二份遗嘱中规定：只有儿子先于自己死亡时，自己才指定某人为继承人，那么可以认为先前遗嘱未被撤销，因为第二份遗嘱中遗漏了儿子，因而并不有效。

<!-- source-p 071 -->
### <a id="28.6.17"></a>28.6.17

<!-- source-p 072 -->
庞波尼乌斯《评萨宾》第四卷

<!-- source-p 073 -->
也可以为子女指定一名替补继承人，即使该替补继承人是在其所替补者死亡后才出生，也不妨碍指定。

<!-- source-p 074 -->
### <a id="28.6.18"></a>28.6.18

<!-- source-p 075 -->
乌尔比安《评萨宾》第十六卷

<!-- source-p 076 -->
<a id="28.6.18.pr."></a>

**序言（pr.）** 若共同所有的奴隶连同自由一并被指定为未适婚子女的替补继承人，若该奴隶是由家父买回，他便成为未适婚子女的必然继承人；若是由未适婚子女买回，他则不成为必然继承人，而是自愿继承人，正如尤利安在《学说汇纂》第三十卷中所说。若既非家父也非未适婚子女买回该奴隶，衡平原则要求：奴隶向主人提出其份额的价款后，应允许他取得自由并承受遗产。

<!-- source-p 077 -->
<a id="28.6.18.1"></a>

**1.** 若奴隶已遗赠给提图斯，则可以像指定他为继承人那样，将他连同自由一并指定为未适婚子女的替补继承人；替补条件成就时，遗赠即归于失效。

<!-- source-p 078 -->
### <a id="28.6.19"></a>28.6.19

<!-- source-p 079 -->
尤利安《学说汇纂》第三十卷

<!-- source-p 080 -->
若奴隶是在受遗赠人死亡后才被指定为替补继承人，处理方式也相同。

<!-- source-p 081 -->
### <a id="28.6.20"></a>28.6.20

<!-- source-p 082 -->
乌尔比安《评萨宾》第十六卷

<!-- source-p 083 -->
<a id="28.6.20.pr."></a>

**序言（pr.）** 即使在裁判官法上，父亲和儿子的遗嘱也视为一份遗嘱。马尔切鲁斯在《学说汇纂》第九卷中写道，只要父亲的遗嘱书已加封即可，即使儿子的遗嘱书曾被拆封也不妨碍；父亲遗嘱书上的七名证人封印已经足够。

<!-- source-p 084 -->
<a id="28.6.20.1"></a>

**1.** 父亲可以以书面方式为自己订立遗嘱，以口头宣告方式为儿子订立遗嘱，或反过来为之；两份遗嘱均有效。

<!-- source-p 085 -->
### <a id="28.6.21"></a>28.6.21

<!-- source-p 086 -->
乌尔比安《告示评注》第四十一卷

<!-- source-p 087 -->
若某人这样指定替补继承人：“若我的儿子在十岁之前死亡，令塞尤斯作继承人”，而儿子在十岁之后、十四岁之前死亡，更可取的意见是，替补继承人不能请求遗产占有；因为替补指定并未适用于这种情形。

<!-- source-p 088 -->
### <a id="28.6.22"></a>28.6.22

<!-- source-p 089 -->
盖尤斯《评行省告示》第十五卷

<!-- source-p 090 -->
若某人请求取得违背父亲遗嘱书的遗产占有（*bonorum possessio contra tabulas*），而他又是未适婚兄弟的替补继承人，则其替补继承权将被排除。

<!-- source-p 091 -->
### <a id="28.6.23"></a>28.6.23

<!-- source-p 092 -->
帕比尼安《解答》第六卷

<!-- source-p 093 -->
某人指定数名继承人，并写道：“我令他们全体互为替补继承人。”其中有人已经承受遗产后，一人死亡；若另一名继承人放弃自己的份额，替补条件因而成就，则该死亡者的全部份额归于仍在世的继承人。因为每个人均应视为在所有情形下互为替补。若有人指定数名继承人为继承人，并写道“我令他们互为替补继承人”，则应视为只有实际成为继承人的人互为替补。

<!-- source-p 094 -->
### <a id="28.6.24"></a>28.6.24

<!-- source-p 095 -->
乌尔比安《论疑难》第四卷

<!-- source-p 096 -->
若数人被指定为不同份额的继承人，并且彼此互为替补，通常应认为他们在替补时取得与原指定相同的份额。例如，一人取得十二分之一，第二人取得十二分之八，第三人取得四分之一；若第三人放弃继承，则其四分之一份额应分为九份：原获十二分之八者取得其中八份，原获十二分之一者取得一份。除非立遗嘱人另有意图；除非遗嘱明确写出，否则很难认为其另有意图。

<!-- source-p 097 -->
### <a id="28.6.25"></a>28.6.25

<!-- source-p 098 -->
尤利安《学说汇纂》第二十四卷

<!-- source-p 099 -->
若父亲指定两名未适婚儿子互为替补继承人，并规定由提图斯替补最后死亡的儿子，应答称只有两名兄弟可以请求遗产占有。此项指定应理解为设立了两个顺位：首先是兄弟互为替补；只有在他们均不能继承时，才轮到提图斯。〔底本在“未适婚儿子”后重复出现 *impuberes*。〕

<!-- source-p 100 -->
### <a id="28.6.26"></a>28.6.26

<!-- source-p 101 -->
尤利安《学说汇纂》第二十九卷

<!-- source-p 102 -->
父亲指定未适婚儿子为继承人，并为他指定替补继承人：“若我死后有子女出生，则令其为继承人。”后来，遗腹子在其兄弟仍在世时出生，遗嘱即被撤销；但若遗腹子是在兄弟死亡后、父亲仍在世时出生，他便成为父亲唯一的继承人。

<!-- source-p 103 -->
### <a id="28.6.27"></a>28.6.27

<!-- source-p 104 -->
尤利安《学说汇纂》第三十卷

<!-- source-p 105 -->
若提图斯被指定为其共同继承人的替补继承人，之后塞姆普罗尼乌斯又被指定为提图斯的替补继承人，我认为，更妥当的意见是，塞姆普罗尼乌斯在两种情形下均为替补继承人。

<!-- source-p 106 -->
### <a id="28.6.28"></a>28.6.28

<!-- source-p 107 -->
尤利安《学说汇纂》第六十二卷

<!-- source-p 108 -->
《科尔内利亚法》确认那些死于敌人控制之下者所立的遗嘱；该法不仅适用于立遗嘱人的遗产，也适用于所有本可依据其遗嘱归于他人的遗产，若该人没有落入敌人控制之下，此类遗产本可归于他人。因而，若父亲死于敌人控制之下，在罗马境内留下未适婚儿子，而儿子在达到适婚年龄前死亡，则遗产归于替补继承人，犹如父亲未曾落入敌人控制之下。反之，若父亲死于罗马境内，而未适婚儿子在敌境，则若儿子是在父亲死亡后才落入敌人控制之下，可以恰当地说，其遗产依该法归于替补继承人；若儿子在父亲仍在世时便落入敌人控制之下，我认为《科尔内利亚法》不适用，因为该法不会使一个在罗马境内未留下任何财产的人因此拥有继承人。因此，即使已达到适婚年龄的儿子在父亲生前被俘，父亲后来死于罗马境内，而儿子死于敌人控制之下，父亲的遗产也应依《十二表法》归于最近的宗亲，而非依《科尔内利亚法》归于儿子。

<!-- source-p 109 -->
### <a id="28.6.29"></a>28.6.29

<!-- source-p 110 -->
斯凯沃拉《疑问》第十五卷

<!-- source-p 111 -->
若父亲先被敌人俘虏，随后儿子也被俘，二人均死于敌境，即使父亲先死，《科尔内利亚法》仍不适用于未适婚子女的替补继承；除非未适婚子女返回罗马境内后死亡。因为若父子二人都死于罗马境内，替补继承人本来也会取得遗产。

<!-- source-p 112 -->
### <a id="28.6.30"></a>28.6.30

<!-- source-p 113 -->
尤利安《学说汇纂》第七十八卷

<!-- source-p 114 -->
某人在遗嘱中指定普罗库鲁斯取得四分之一份额、奎厄图斯取得二分之一及四分之一份额为继承人；随后指定弗洛鲁斯替补奎厄图斯、索西娅替补普罗库鲁斯；又规定，若弗洛鲁斯与索西娅都未成为继承人，则在第三顺位将遗产二分之一及四分之一份额留给莱普提斯殖民地，并以四分之一份额指定数名继承人，从而分配的份额超过整份遗产。奎厄图斯承受了遗产，普罗库鲁斯和索西娅则在立遗嘱人仍在世时死亡。问题是：原给普罗库鲁斯的四分之一份额，归奎厄图斯还是归第三顺位的替补继承人？答复是：家父的意愿似乎是，只有在整份遗产均无人承受时，才由第三顺位所写明的继承人替补；分配给他们的份额超过十二盎司这一点，清楚地表明了这一意图。因此，所争议的遗产四分之一份额应归奎厄图斯。

<!-- source-p 115 -->
### <a id="28.6.31"></a>28.6.31

<!-- source-p 116 -->
尤利安《关于疑义的单篇论著》

<!-- source-p 117 -->
<a id="28.6.31.pr."></a>

**序言（pr.）** 父亲为儿子如此指定替补继承人：“凡上述人员中作我的继承人者，也作我儿子的继承人。”问题是，“凡作继承人者”指曾经在任何时候作过继承人的人，还是指儿子死亡时仍为继承人的人。法学家认为，应指曾经作过继承人的人；即使他在未适婚子女仍在世时已不再是继承人——例如有人提起了部分遗嘱违反义务之诉——仍认为他以后会依据替补指定成为继承人。

<!-- source-p 118 -->
<a id="28.6.31.1"></a>

**1.** 但下列情形不能作相同解释：某人有两个儿子，一个已达到适婚年龄的盖乌斯，一个尚未适婚的卢基乌斯，并这样为卢基乌斯指定替补继承人：“若我的未适婚儿子卢基乌斯死亡，且我的儿子盖乌斯不成为继承人，则令塞尤斯作继承人。”法学家对此的解释是，替补指定所附条件应以未适婚儿子的死亡时点为准。

<!-- source-p 119 -->
### <a id="28.6.32"></a>28.6.32

<!-- source-p 120 -->
尤利安《评乌尔塞乌斯·费罗克斯》第一卷

<!-- source-p 121 -->
某人以不同比例指定数名继承人，其中包括阿提乌斯；又规定，若阿提乌斯不承受遗产，则由其他人按其最初被指定时各自的份额替补。之后他又规定，若阿提乌斯不承受遗产，则将共同继承人提图斯加入替补继承人之列。问题是提图斯与其他人各应取得多少份额。答复是：提图斯取得平均份额，其他人按继承份额比例取得；例如，若有三人，提图斯取得阿提乌斯份额的四分之一，其余人则按最初指定时的继承份额比例取得阿提乌斯份额的其余部分。若除提图斯外，还另行加入其他继承人，则这些新增者取得等额份额；例如，若有三名共同继承人被指定为替补，又加入两名外人，则两名外人各取得阿提乌斯份额的五分之一，其余共同继承人则按其原有继承份额比例分配。

<!-- source-p 122 -->
### <a id="28.6.33"></a>28.6.33

<!-- source-p 123 -->
阿非利卡努斯《疑问》第二卷

<!-- source-p 124 -->
<a id="28.6.33.pr."></a>

**序言（pr.）** 母亲若订立遗嘱，规定其未适婚儿子在年满十四岁时成为继承人，并在未适婚人替补遗嘱中规定，若儿子不成为自己的继承人，则由他人替补，该替补指定有效。

<!-- source-p 125 -->
<a id="28.6.33.1"></a>

**1.** 若儿子及其遗腹子孙依盖卢斯·阿奎利乌斯的意见被指定为继承人，并且规定若孙辈不成为继承人则由提图斯替补，答复是：只要儿子成为继承人，提图斯即在任何情形下均被排除，即使孙辈未曾出生亦然。

<!-- source-p 126 -->
### <a id="28.6.34"></a>28.6.34

<!-- source-p 127 -->
阿非利卡努斯《疑问》第四卷

<!-- source-p 128 -->
<a id="28.6.34.pr."></a>

**序言（pr.）** 某人为两个未适婚子女指定替补继承人，规定替补者继承最后死亡者的遗产。若二人同时死亡，答复是替补者将成为二人的继承人；因为“最后”不仅指某人死在其他人之后，也包括其后已无人死亡的情形。相反，“最先”不仅指某人死在他人之前，也包括其前已无人死亡的情形。

<!-- source-p 129 -->
<a id="28.6.34.1"></a>

**1.** 某人指定未适婚儿子和提图斯为继承人；为提图斯指定梅维乌斯为替补继承人；为儿子则规定，凡上述人员中作自己继承人的人，也作儿子的替补继承人。提图斯放弃遗产，梅维乌斯承受遗产。儿子死亡后，尤利安认为，未适婚儿子的遗产似乎只应依替补指定归于同时承受了父亲遗产的人。

<!-- source-p 130 -->
<a id="28.6.34.2"></a>

**2.** 即使有人请求取得违背父亲遗嘱书的遗产占有，未适婚人替补指定仍然有效；替补指定中所作的遗赠应向所有受遗赠人履行。

<!-- source-p 131 -->
### <a id="28.6.35"></a>28.6.35

<!-- source-p 132 -->
阿非利卡努斯《疑问》第五卷

<!-- source-p 133 -->
即使未适婚子女请求取得违背父亲遗嘱书的遗产占有，仍应准许就遗赠向其替补继承人提起诉讼；并应据此增加遗赠额，但须扣除儿子本不应向外人承担的部分。替补继承人所负遗赠也应相应增加：如果遗产占有使更多财产归于儿子，替补继承人便应如同儿子本人一样，履行增加后的遗赠。因此，我认为，如果未适婚子女被指定为全部遗产的继承人，但因遗产占有而有一半遗产被他人取得，替补继承人应按遗赠比例获得减免；正如遗产占有增加的份额会增加遗赠，减少的份额也应减少遗赠。

<!-- source-p 134 -->
### <a id="28.6.36"></a>28.6.36

<!-- source-p 135 -->
马尔基安《法学阶梯》第四卷

<!-- source-p 136 -->
<a id="28.6.36.pr."></a>

**序言（pr.）** 某人可以在遗嘱中设置多个继承顺位，例如：“若某人不成为继承人，则令另一人为继承人”，并可依次增加多个顺位，以便在最后顺位指定必然继承人，例如奴隶。

<!-- source-p 137 -->
<a id="28.6.36.1"></a>

**1.** 可以为一人的位置指定数名替补继承人，也可以为数人指定一名替补；可以分别为每名继承人指定一名替补，也可以令被指定为继承人的人互为替补。

<!-- source-p 138 -->
### <a id="28.6.37"></a>28.6.37

<!-- source-p 139 -->
弗洛伦提努斯《法学阶梯》第十卷

<!-- source-p 140 -->
可以分别为每名子女指定替补继承人，也可以指定一人替补最后死亡的子女。若立遗嘱人不愿任何子女无遗嘱死亡，应分别为各子女指定替补；若立遗嘱人想在子女之间完整保留法定继承权，则应指定一人替补最后死亡的子女。

<!-- source-p 141 -->
### <a id="28.6.38"></a>28.6.38

<!-- source-p 142 -->
保罗《关于第二遗嘱书的单篇论著》

<!-- source-p 143 -->
<a id="28.6.38.pr."></a>

**序言（pr.）** 有多个子女的人，可以只为其中一些指定替补继承人；并非必须为所有子女指定，也可以一个都不指定。

<!-- source-p 144 -->
<a id="28.6.38.1"></a>

**1.** 因此，替补指定也可以只适用于较短的年龄期间，例如：“若我的儿子在十岁之前死亡，令提图斯作他的继承人。”

<!-- source-p 145 -->
<a id="28.6.38.2"></a>

**2.** 因而，若某人按不同年龄阶段指定不同的替补继承人，也应承认其效力，例如：“若他在十岁前死亡，令提图斯作继承人；若他在十岁后、十四岁前死亡，令梅维乌斯作继承人。”

<!-- source-p 146 -->
<a id="28.6.38.3"></a>

**3.** 若父亲指定某人为继承人，并要求他返还遗产，而该人受遗嘱信托请求的强制而承受了遗产，尽管该承受行为会使同一遗嘱中的其他处分——如遗赠和自由权授予——得到确认，昆图斯·塞尔维迪乌斯·斯凯沃拉仍认为，既然市民法上的遗嘱已失效，就不应使第二遗嘱书复活。多数人持相反意见，因为未适婚人替补遗嘱是先前遗嘱的一部分；我们现行法采用这一多数意见。

<!-- source-p 147 -->
### <a id="28.6.39"></a>28.6.39

<!-- source-p 148 -->
雅沃勒努斯《摘自拉贝奥〈后论〉》第一卷

<!-- source-p 149 -->
<a id="28.6.39.pr."></a>

**序言（pr.）** 某人有两个未适婚孙子，二人均由其儿子所生；其中一人处于自己的权力之下，另一人则不在其权力之下。他希望二人各以相等份额继承，并规定若其中一人在未达到适婚年龄时死亡，其份额转归另一人。依拉贝奥、奥菲利乌斯、卡斯切利乌斯和特雷巴提乌斯的意见，他只指定处于自己权力之下的孙子为继承人，并遗赠给另一孙子二分之一遗产，待其达到可以自行处理事务的年龄时取得；若处于自己权力之下的孙子在未适婚时死亡，则指定另一孙子为其替补继承人。

<!-- source-p 150 -->
<a id="28.6.39.1"></a>

**1.** 父亲可以针对不同情形，分别为未适婚儿子指定不同的继承人；例如，指定一人在自己没有儿子的情况下继承，另一人在有儿子且儿子未适婚时死亡的情况下继承。

<!-- source-p 151 -->
<a id="28.6.39.2"></a>

**2.** 某人指定四名继承人，并为除一人以外的所有继承人指定替补继承人。那名没有替补继承人的人，以及其他继承人中的一人，都在家父仍在世时死亡。奥菲利乌斯和卡斯切利乌斯答复说，没有另行指定替补继承人的那名继承人的份额，也归于已经指定的替补继承人；这一意见是正确的。

<!-- source-p 152 -->
### <a id="28.6.40"></a>28.6.40

<!-- source-p 153 -->
帕比尼安《疑问》第二十九卷

<!-- source-p 154 -->
经审理后被收为养子的未适婚人死亡。正如通过皇帝权威及担保，可为法定继承人提供保障一样，若自然父亲曾为未适婚子女指定替补继承人，也应给予替补继承人救济；因为即使是将来的法定继承人，也只能获得准诉权。

<!-- source-p 155 -->
### <a id="28.6.41"></a>28.6.41

<!-- source-p 156 -->
帕比尼安《解答》第六卷

<!-- source-p 157 -->
<a id="28.6.41.pr."></a>

**序言（pr.）** 某人被指定为共同继承人的替补继承人，但在承受遗产前、替补条件成就前便死亡。无论其替补继承人是在原替补指定之前还是之后被指定，两份遗产份额均归其替补继承人；原替补继承人是在被指定继承人之后还是之前死亡，也不影响这一结果。

<!-- source-p 158 -->
<a id="28.6.41.1"></a>

**1.** 遗嘱写道“我令他们互为替补继承人”时，未承受遗产者的份额应按书面指定继承人本人或他人所取得份额的比例，归于被指定的继承人。

<!-- source-p 159 -->
<a id="28.6.41.2"></a>

**2.** 父母为女儿或孙辈指定替补继承人时，若女儿或孙辈曾取代儿子的地位，或在遗嘱作成后开始取代儿子的地位，但在父母死亡时他们中有人已不属于该家族，未适婚人替补指定便失效。

<!-- source-p 160 -->
<a id="28.6.41.3"></a>

**3.** 若父亲要求被指定为继承人的儿子：在未适婚时死亡的，应将自己的遗产返还给提图斯；通说认为，应命儿子的法定继承人在保留《法尔基第法》所保障份额的前提下，将父亲的遗产返还给提图斯，视同未适婚儿子在死后以遗嘱信托方式作出该安排。当替补条件以请求式文字延伸至子女达到适婚年龄之后时，也应作相同处理。以上规则仅在父亲的遗嘱依法有效时适用；若遗嘱无效，父亲虽有意作成遗嘱的文字，除非明确表示其作为遗嘱附书，否则并不因此成为遗嘱附书。儿子自己的财产也不受该遗嘱信托约束。因此，若父亲剥夺儿子的继承权且未留给他任何财产，就不存在遗嘱信托；反之，若儿子取得了遗赠或遗嘱信托，他只须在所得范围内履行儿子所作的遗产信托，且不适用《法尔基第法》的扣减。

<!-- source-p 161 -->
<a id="28.6.41.4"></a>

**4.** 某人将不同份额分别留给数名共同继承人，并在全部继承人指定之后写道：“我令他们互为替补继承人。”这似乎是指第一顺位中共同指定的继承人互为替补；若他们不接受各自指定的份额，则其余所有共同继承人均获准承受遗产。

<!-- source-p 162 -->
<a id="28.6.41.5"></a>

**5.** 某人以一定份额指定父亲和儿子为继承人，并令二人互为替补；其余共同继承人获分配份额后，遗嘱人又在全部遗产份额安排完毕后写道：“我令这些人全体互为替补继承人。”此处须查明遗嘱人的意思：他提及“全体”时，是否将父子也纳入共同继承人的替补安排，还是仅将该文字用于其他所有人。由于父子之间已经有专门的替补指定，后者似乎更为可信。

<!-- source-p 163 -->
<a id="28.6.41.6"></a>

**6.** 某人既被指定为未适婚儿子的共同继承人，又被指定为该儿子的替补继承人时，应履行第二遗嘱书中的遗赠，仿佛他无条件取得了一部分遗产、附条件取得了另一部分遗产。对另一名替补继承人则不适用同一规则：他应依《法尔基第法》计算遗赠扣减，仿佛他在第一遗嘱书中被附条件指定为全部遗产的继承人，即使他作为儿子的共同继承人本可完整取得四分之一份额。因为第一遗嘱书将遗赠给提图斯的同一物品又在第二遗嘱书中遗赠给塞姆普罗尼乌斯时，塞姆普罗尼乌斯总会在某一时点与提图斯竞争取得该物。

<!-- source-p 164 -->
<a id="28.6.41.7"></a>

**7.** 父亲为最后死亡的未适婚女儿作成第二遗嘱书，并指定替补继承人；若未适婚女儿在其已达适婚年龄的姐妹仍在世时死亡，通说认为替补指定失效：就先死的女儿而言，她并非最后死亡；就另一名女儿而言，她已经达到适婚年龄。

<!-- source-p 165 -->
<a id="28.6.41.8"></a>

**8.** 下列文字作出的替补指定并无瑕疵：“我的儿子，若（这是我最不愿见到的事）在达到适婚年龄前死亡，则令提图斯作其继承人，取得其位置或份额。”这与遗嘱人在说明条件后命令继承人替补自己并无不同；因为某人若被指定继承特定物品，而遗嘱中没有其他共同继承人，他仍取得全部遗产。

<!-- source-p 166 -->
### <a id="28.6.42"></a>28.6.42

<!-- source-p 167 -->
帕比尼安《定义》第一卷

<!-- source-p 168 -->
某人留下两个未适婚儿子为继承人，并规定若二人都死亡，则由替补继承人继承。父亲死后，两个儿子同时死亡；替补继承人因此取得两项遗产。但若二人在不同时间死亡，替补继承人将在最后死亡的儿子遗产中取得先死兄弟的遗产。不过，计算《法尔基第法》份额时，不应计入先死儿子的遗产；替补继承人依据遗嘱请求的份额不得超过 *sescuncia*。替补继承人为先于其死亡、且无遗嘱死亡的儿子作出的遗赠，也归于失效。

<!-- source-p 169 -->
### <a id="28.6.43"></a>28.6.43

<!-- source-p 170 -->
保罗《疑问》第九卷

<!-- source-p 171 -->
<a id="28.6.43.pr."></a>

**序言（pr.）** 有人有一名已达适婚年龄但不能言语的儿子，他请求皇帝准许为儿子指定替补继承人，并指定提图斯为替补。父亲死后，该失语的儿子结婚并生有一子。我询问，遗嘱是否因此被撤销。答复是：皇帝恩典通常由皇帝本人解释；但考察皇帝的意旨，可以说他授予该恩典的范围，仅限于儿子持续处于同一健康状况的期间。正如依市民法，未适婚人遗嘱在子女达到适婚年龄时终止，皇帝也仿照该法，为因身体缺陷而不能立遗嘱的人作出安排。若父亲为患精神病的儿子指定替补继承人，我们也会说儿子恢复神智后，该遗嘱即不再有效，因为他此时已能为自己订立遗嘱。若仍认为皇帝恩典在此后继续有效，便会变得不公平：这会剥夺一个神志健全之人的立遗嘱能力。因此，即使儿子取得自权继承人，也应认为替补指定被撤销；因为无论儿子后来亲自指定另一人为继承人，还是依据法律取得自己的继承人，二者并无区别。父亲或皇帝不可能想到应剥夺后来出生之人的继承权。无论皇帝恩典对立遗嘱能力的影响适用于一人还是多人，均不影响这一结论。

<!-- source-p 172 -->
<a id="28.6.43.1"></a>

**1.** 我还询问，若替补指定如下：“若我的儿子在十岁前死亡，令提图斯作继承人；若他在十四岁前死亡，令梅维乌斯作继承人”，而儿子八岁时死亡，究竟只有提图斯，还是提图斯与梅维乌斯都依替补指定成为继承人？因为可以确定，儿子既在十岁前，也在十四岁前死亡。答复是：父亲可以在未适婚期间内自由为儿子指定替补继承人，但该期间以达到适婚年龄为终点。更妥当的解释是，两个年龄期间应分别适用各自的替补安排，除非立遗嘱人明确表示了相反意愿。

<!-- source-p 173 -->
<a id="28.6.43.2"></a>

**2.** 卢基乌斯·提图斯有处于其权力之下的儿子。他指定妻子为继承人，并将儿子指定为妻子的替补继承人。有人询问，妻子的继承人指定是否因儿子在该顺位未被剥夺继承权而无效。答复是：儿子被遗漏的那个顺位无效；因此，若儿子同时被指定为替补继承人，他们仍可依据遗嘱成为继承人。儿子并未使整份遗嘱无效，只使自始无效的那个顺位失效。正如已有答复所说，若第一顺位遗漏儿子、第二顺位剥夺其继承权，第二顺位仍有效。第二顺位继承人指定有效的理由，无论是因为儿子在该顺位被剥夺继承权，还是因为儿子本人被指定为替补继承人，均无不同。

<!-- source-p 174 -->
<a id="28.6.43.3"></a>

**3.** 尤利乌斯·隆吉努斯指定某些人作自己的继承人，并为儿子指定替补继承人，写道：“凡作我继承人者，也作我儿子的继承人。”其中一名被指定的继承人曾暗中允诺，将把自己取得的部分交给依法不能取得该部分的人。他获准依替补指定继承儿子的遗产。问题是，他应按遗嘱中指定给他的份额继承，还是按他实际取得的份额继承，从而在替补继承中增加其份额？答复是：为欺诈法律而作出允诺的人，一经承受遗产即成为继承人；即使遗嘱留给他的财产被剥夺，他也不会因此失去继承人身份。因此，他依据第二遗嘱书只能取得遗嘱指定给他的份额。其违反法律的行为已在财产被剥夺这一点上受到充分惩罚。即便他后来不再是继承人，我也会作相同回答；例如某人被指定为继承人，承受遗产后被降为奴隶，后来又获得自由。此人可以依遗嘱中为他保留的替补指定继承；虽然他已失去依据原指定取得的遗产，仍应通过替补继承取得他所失去的那一份额。

### <a id="28.6.44"></a>28.6.44

<!-- source-p 176 -->
保罗《疑问》第十卷

<!-- source-p 177 -->
梅基安努斯写道，未适婚人替补遗嘱不能使先前的主遗嘱得到部分或全部确认。

<!-- source-p 178 -->
### <a id="28.6.45"></a>28.6.45

<!-- source-p 179 -->
保罗《解答》第十二卷

<!-- source-p 180 -->
<a id="28.6.45.pr."></a>

**序言（pr.）** 卢基乌斯·提图斯指定其合法婚生儿子和另一名非婚生儿子为继承人，并令二人互为替补。合法婚生儿子提提安努斯在父亲死后仍未适婚时死亡；父亲留下他时他仅一岁，死亡时其母亲和非婚生兄弟仍在世，而该兄弟也是他的共同继承人。我询问，提提安努斯的遗产是否因替补继承而归于其非婚生兄弟提图斯，还是归于母亲。答复是：本案替补指定只适用于原指定继承人未能成为继承人的情形，并不适用于原继承人成为继承人后在未适婚时死亡的情形；因为对非婚生儿子而言，双重替补不能发生效力。因此，合法婚生儿子的遗产应按无遗嘱继承归于其母亲。

<!-- source-p 181 -->
<a id="28.6.45.1"></a>

**1.** 保罗答复：若所有被指定的继承人都互为替补，其中一人在其他继承人死亡后放弃自己的份额，则该份额依替补指定仅归于当时仍在世的那一人。

<!-- source-p 182 -->
### <a id="28.6.46"></a>28.6.46

<!-- source-p 183 -->
保罗《解答》第十三卷

<!-- source-p 184 -->
家父在第一遗嘱书中指定遗腹子为继承人；在第二遗嘱书中指定自己或儿子为继承人，并规定若儿子在达到适婚年龄前死亡，则由其兄弟盖乌斯·塞尤斯替补；随后又指定提图斯替补盖乌斯·塞尤斯；之后写道：“若我的兄弟盖乌斯·塞尤斯作为第一顺位替补继承人成为我的继承人，我便将遗嘱信托留给提图斯。”我询问：儿子成为父亲的继承人后在未适婚时死亡，其兄弟依替补指定成为继承人时，是否须履行该遗嘱信托？遗嘱信托所附条件是兄弟成为立遗嘱人的继承人。答复是：死者的兄弟既被指定为两种情形下的继承人或替补继承人，在未适婚儿子死亡后，应履行立遗嘱人所留的遗嘱信托。“若我的兄弟盖乌斯·塞尤斯成为我的继承人，我愿届时给付”这句话并不妨碍此结论，因为他确实也成为了立遗嘱人的继承人。

<!-- source-p 185 -->
### <a id="28.6.47"></a>28.6.47

<!-- source-p 186 -->
斯凯沃拉《解答》第二卷

<!-- source-p 187 -->
某人有一名未适婚儿子和一名未适婚女儿；他指定儿子为继承人，并剥夺女儿的继承权；若儿子在达到适婚年龄前死亡，则由女儿替补。对于女儿，父亲又规定，若她在结婚前死亡，则由自己的妻子和姐妹替补。我询问：若女儿先在未适婚时死亡，随后她的未适婚兄弟也死亡，儿子的遗产是否依据替补指定归于立遗嘱人的妻子和姐妹？答复是：依所述情形，不归于她们。

<!-- source-p 188 -->
### <a id="28.6.48"></a>28.6.48

<!-- source-p 189 -->
斯凯沃拉《关于公开讨论疑问的单篇论著》

<!-- source-p 190 -->
<a id="28.6.48.pr."></a>

**序言（pr.）** 我们共同所有一名奴隶；该奴隶被指定为继承人，若他不成为继承人，则由梅维乌斯替补。该奴隶依其中一名主人的命令承受遗产，未依另一名主人的命令承受。问题是，替补继承是否发生。更妥当的意见是，替补继承仍然发生。

<a id="28.6.48.1"></a>

**1.** 遗嘱写道：“提图斯作继承人。我将斯提库斯给并遗赠给梅维乌斯；斯提库斯作继承人。若斯提库斯不作继承人，则令斯提库斯获得自由并作继承人。”本案首先要判断，这是一个顺位还是两个顺位，以及替补时继承原因是否发生改变。关于多数情形，问题在于某人能否替补自己；答复是，继承原因改变时，可以指定自己为替补继承人。因此，若提图斯被指定为继承人，并且规定若他不成为继承人，仍由提图斯本人作继承人，该替补指定便毫无效力。但若某人附条件被指定为继承人，却无条件指定自己为替补继承人，继承原因即发生改变，因为原继承人指定所附条件可能不成就，而替补指定则另有意义；不过，若条件成就，两项指定便都是无条件的，替补指定因而无效。反之，若某人无条件被指定为继承人，随后又附条件指定自己为替补继承人，该条件替补也不发生效力，继承原因不视为已改变；因为即使条件成就，两项指定仍都是无条件继承人指定。依此即可说明本案：“提图斯作继承人。我将斯提库斯给并遗赠给梅维乌斯；斯提库斯作继承人。若斯提库斯不作继承人，则令斯提库斯获得自由并作继承人。”我们已知，在同一份遗嘱中，斯提库斯既被遗赠，又获授自由，授予自由的安排优先；自由授予优先时，遗赠便不应履行，他也不能依受遗赠人的命令承受遗产。因此，斯提库斯确实不成为继承人，后一句所授予的自由则对他发生效力；这看起来属于一个顺位。那么，若提图斯不承受遗产，结果如何？斯提库斯便因替补指定而获得自由并成为继承人。只要他尚未依受遗赠人的命令承受遗产，就不能认为他已因遗赠而成为受遗赠人的奴隶；因此可以确定，他并非继承人，于是依“若斯提库斯不作继承人，则令斯提库斯获得自由并作继承人”这句话，他将获得自由并成为继承人。尤利安在其著作中也赞同我们这一意见。

**2.** 若未适婚子女将指定给自己的替补奴隶转让给他人，而买受人又指定该奴隶获得自由并成为继承人，那么，该奴隶是否就成为未适婚子女全部遗产的替补继承人？若未适婚子女达到适婚年龄，该奴隶将依买受人的遗嘱成为必然继承人；若未适婚子女在达到适婚年龄前死亡，该奴隶则依据替补指定获得自由并成为继承人，对未适婚子女的父亲而言是必然继承人，对买受人而言则是自愿继承人。
