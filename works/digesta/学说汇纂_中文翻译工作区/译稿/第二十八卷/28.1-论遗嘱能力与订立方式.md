# D.28.1 论何人可以订立遗嘱及遗嘱如何订立（*Qui testamenta facere possunt et quemadmodum testamenta fiant*；底本题名作 *tesamenta*）

<!-- source-p 001 -->
<a id="1"></a><a id="28.1"></a>**28.1.0　论何人可以订立遗嘱及遗嘱如何订立**

<!-- source-p 002 -->
<a id="28.1.1"></a>**28.1.1**

<!-- source-p 003 -->
**莫德斯汀：《法学大全》第二卷。**

<!-- source-p 004 -->
遗嘱，是对我们意愿所作的合法确定，即确定某人希望其死后发生何事。

<!-- source-p 005 -->
<a id="28.1.2"></a>**28.1.2**

<!-- source-p 006 -->
**拉贝奥：《后论》第一卷，经雅沃勒努斯删节。**

<!-- source-p 007 -->
判断立遗嘱人是否具备能力，要求的是其订立遗嘱时心智健全，而非身体健康。

<!-- source-p 008 -->
<a id="28.1.3"></a>**28.1.3**

<!-- source-p 009 -->
**帕皮尼安：《疑问集》第十四卷。**

<!-- source-p 010 -->
遗嘱能力（*testamenti factio*）属于公法，而非私法。

<!-- source-p 011 -->
<a id="28.1.4"></a>**28.1.4**

<!-- source-p 012 -->
**盖尤斯：《法学阶梯》第二卷。**

<!-- source-p 013 -->
若要判断遗嘱是否有效，首先应考察立遗嘱人是否具有遗嘱能力；若其具有该能力，接着应查明其是否依市民法规则订立遗嘱。

<!-- source-p 014 -->
<a id="28.1.5"></a>**28.1.5**

<!-- source-p 015 -->
**乌尔比安：《萨宾评注》第六卷。**

<!-- source-p 016 -->
我们来考察男女分别从何年龄起可以订立遗嘱。较为正确的看法是：男子应已满十四岁，女子应已满十二岁。某人是否必须超过十四岁才能订立遗嘱，还是年满十四岁即已足够？例如，某人出生于一月一日，并在其十四岁生日当天订立遗嘱，该遗嘱是否有效？我说有效。我还认为，即使他在前一日的夜间第六时之后订立遗嘱，也有效；因为此时可视为他已经满十四岁，如马尔基安所认为的那样。

<!-- source-p 017 -->
<a id="28.1.6"></a>**28.1.6**

<!-- source-p 018 -->
**盖尤斯：《行省告示评注》第十七卷。**

<!-- source-p 019 -->
<a id="28.1.6.pr."></a>**序言。**处于父母权力之下的人无权订立遗嘱；即使父亲允许，也仍不能依法订立遗嘱。

<!-- source-p 020 -->
<a id="28.1.6.1"></a>**1.**聋哑人不得订立遗嘱。但若某人在订立遗嘱后，因疾病或其他原因成为哑者或聋者，其遗嘱仍然有效。

<!-- source-p 021 -->
<a id="28.1.7"></a>**28.1.7**

<!-- source-p 022 -->
**马克尔：《遗产税法评注》第一卷。**

<!-- source-p 023 -->
若聋哑人请求皇帝准许其订立遗嘱，并获准许，则该遗嘱有效。

<!-- source-p 024 -->
<a id="28.1.8"></a>**28.1.8**

<!-- source-p 025 -->
**盖尤斯：《行省告示评注》第十七卷。**

<!-- source-p 026 -->
<a id="28.1.8.pr."></a>**序言。**身处敌人控制之下的人在那里所订立的遗嘱无效，即使他后来返回亦然。

<!-- source-p 027 -->
<a id="28.1.8.1"></a>**1.**若某人被处以“水与火之禁”，其此前订立的遗嘱及此后订立的遗嘱均无效；其被定罪时所拥有的财产也将被没收；若这些财产看起来不具有收益性，则交付债权人。

<!-- source-p 028 -->
<a id="28.1.8.2"></a>**2.**被流放至岛上的人处于相同情形。

<!-- source-p 029 -->
<a id="28.1.8.3"></a>**3.**但被流放至岛上的人，以及被禁止进入意大利本土和其所属行省的人，仍保有订立遗嘱的权利。

<!-- source-p 030 -->
<a id="28.1.8.4"></a>**4.**被判处角斗、兽刑或矿山刑的人则丧失自由，其财产亦被没收；由此可见，他们丧失遗嘱能力。

<!-- source-p 031 -->
<a id="28.1.9"></a>**28.1.9**

<!-- source-p 032 -->
**乌尔比安：《告示评注》第四十五卷。**

<!-- source-p 033 -->
某人遭到控告后被拘禁，尚未定罪即死亡，其遗嘱有效。

<!-- source-p 034 -->
<a id="28.1.10"></a>**28.1.10**

<!-- source-p 035 -->
**保罗：《判决集》第三卷。**

<!-- source-p 036 -->
失去双手的人仍可订立遗嘱，尽管他无法书写。

<!-- source-p 037 -->
<a id="28.1.11"></a>**28.1.11**

<!-- source-p 038 -->
**乌尔比安：《萨宾评注》第十卷。**

<!-- source-p 039 -->
人质不得订立遗嘱，除非获准许。

<!-- source-p 040 -->
<a id="28.1.12"></a>**28.1.12**

<!-- source-p 041 -->
**尤利安：《学说汇纂》第四十二卷。**

<!-- source-p 042 -->
依科尔内利亚法，死于敌人控制之下者的遗嘱，视同立遗嘱人未曾落入敌人之手而予以确认；其遗产也以同样方式归属于相应继承人。因此，某人指定其奴隶为继承人后死于敌人控制之下，该奴隶即成为自由人及继承人，无论其本人愿意与否，尽管严格说来不宜将其称为当然继承人。因为，死于敌人控制之下者的儿子，即使不愿继承，也受遗产约束；虽然他在其父死亡时不处于父权之下，因而不能称为自家继承人。

<!-- source-p 043 -->
<a id="28.1.13"></a>**28.1.13**

<!-- source-p 044 -->
**马尔基安：《法学阶梯》第四卷。**

<!-- source-p 045 -->
<a id="28.1.13.pr."></a>**序言。**被强盗俘获的人，只要仍保有自由身份，就可以订立遗嘱。

<!-- source-p 046 -->
<a id="28.1.13.1"></a>**1.**在外国执行使节职务的人，也可以订立遗嘱。

<!-- source-p 047 -->
<a id="28.1.13.2"></a>**2.**某人因重罪被定罪后提出上诉，在上诉待决期间订立遗嘱，并于此后死亡，该遗嘱有效。

<!-- source-p 048 -->
<a id="28.1.14"></a>**28.1.14**

<!-- source-p 049 -->
**保罗：《规则集》第二卷。**

<!-- source-p 050 -->
由主人遗嘱释奴的人，若不知道主人已经死亡且其遗产已经被接受，便不得订立遗嘱，尽管此时他已成为家父且独立于他人权力之外；因为其身份尚不确定的人，不能在遗嘱中作出确定的处分。

<!-- source-p 051 -->
<a id="28.1.15"></a>**28.1.15**

<!-- source-p 052 -->
**乌尔比安：《告示评注》第十二卷。**

<!-- source-p 053 -->
神圣庇护皇帝敕答：对自身身份存疑或有所误认者，不得订立遗嘱。

<!-- source-p 054 -->
<a id="28.1.16"></a>**28.1.16**

<!-- source-p 055 -->
**庞波尼乌斯：《规则论》单卷本。**

<!-- source-p 056 -->
<a id="28.1.16.pr."></a>**序言。**家子、他人之奴隶、遗腹子以及聋者，均被认为具有遗嘱能力（*testamenti factio*）；尽管他们不能订立遗嘱，却能够依据遗嘱为自己或他人取得权利。

<!-- source-p 057 -->
<a id="28.1.16.1"></a>**1.**马尔凯鲁斯补充说：精神错乱者也具有遗嘱能力，尽管不能订立遗嘱；之所以具有遗嘱能力，是因为他可以为自己取得遗赠或信托遗赠。事实上，即便本人不知情，具备心智能力者也可以取得专属其本人的诉权。

<!-- source-p 058 -->
<a id="28.1.17"></a>**28.1.17**

<!-- source-p 059 -->
**保罗：《判决集》第三卷。**

<!-- source-p 060 -->
身体患病并因此丧失心智能力者，在该期间不能订立遗嘱。

<!-- source-p 061 -->
<a id="28.1.18"></a>**28.1.18**

<!-- source-p 062 -->
**乌尔比安：《萨宾评注》第一卷。**

<!-- source-p 063 -->
<a id="28.1.18.pr."></a>**序言。**依法被禁止处分财产的人不得订立遗嘱；若其订立，遗嘱依法当然无效。但在禁令作出之前已经订立的遗嘱仍然有效。因此，他也不得被选作遗嘱见证人，因为他不具有遗嘱能力。

<!-- source-p 064 -->
<a id="28.1.18.1"></a>**1.**若某人因作诽谤诗而被定罪，元老院决议明确规定其丧失作证资格；因此，他既不能订立遗嘱，也不得被选为遗嘱见证人。

<!-- source-p 065 -->
<a id="28.1.19"></a>**28.1.19**

<!-- source-p 066 -->
**莫德斯汀：《法学大全》第五卷。**

<!-- source-p 067 -->
家子、未成年人或他人之奴隶若制作并封缄遗嘱文书，不得依该文书授予遗产占有权（*bonorum possessio*）；即使家子后来成为自权人、未成年人后来达到青春期，或奴隶后来获释，结论亦同，因为他们订立遗嘱时均无遗嘱能力，故其所制作的文书并非有效遗嘱。

<!-- source-p 068 -->
<a id="28.1.20"></a>**28.1.20**

<!-- source-p 069 -->
**乌尔比安：《萨宾评注》第一卷。**

<!-- source-p 070 -->
<a id="28.1.20.pr."></a>**序言。**在同一份遗嘱中被指定为继承人的人，不得同时担任该遗嘱的见证人。对于受遗赠人及被指定为监护人的人，规则相反：只要没有其他妨碍事由，例如尚未成年，或处于立遗嘱人的父权之下，便可以担任见证人。

<!-- source-p 071 -->
<a id="28.1.20.1"></a>**1.**“父权之下”一词，不仅指处于父权之下的子女，也包括其从敌人手中赎回之人；尽管通常认为此人不是奴隶，而只是受某种拘束，直至偿还赎金为止。

<!-- source-p 072 -->
<a id="28.1.20.2"></a>**2.**反过来也可以问：能够就军中特有产订立遗嘱者，其父亲能否被其选为该遗嘱的见证人？马尔凯鲁斯在《学说汇纂》第十卷中写道，可以；因此，其兄弟也可以担任见证人。

<!-- source-p 073 -->
<a id="28.1.20.3"></a>**3.**我们关于禁止处于父权之下者作证的规定，应适用于一切作证情形，即适用于一切可能据以取得权利的法律行为。

<!-- source-p 074 -->
<a id="28.1.20.4"></a>**4.**精神错乱者也不得担任见证人，因为其心智不健全；但若其精神错乱有所间歇，则在间歇期间可以担任见证人。其在精神错乱前已经完成的遗嘱仍然有效，并可据该遗嘱取得遗产占有权。

<!-- source-p 075 -->
<a id="28.1.20.5"></a>**5.**我认为，因敲诈勒索罪被定罪者仍可担任遗嘱见证人，因为法律禁止其在审判中担任证人。

<!-- source-p 076 -->
<a id="28.1.20.6"></a>**6.**妇女不得在遗嘱中担任见证人；但妇女在其他情形下可以担任证人。《尤利娅通奸法》可作证据：该法禁止将因通奸被定罪的妇女传唤为证人，或允许其作证。

<!-- source-p 077 -->
<a id="28.1.20.7"></a>**7.**奴隶也理当不得被选作履行遗嘱程式的见证人，因为他完全不享有市民法上的权利共同体，甚至也不享有裁判官告示所赋予的权利。

<!-- source-p 078 -->
<a id="28.1.20.8"></a>**8.**古代法学家认为，为履行遗嘱程式而被选用的见证人，必须持续在场，直至最后的见证手续完成。

<!-- source-p 079 -->
<a id="28.1.20.9"></a>**9.**但我们不要求见证人理解遗嘱所用的语言。神圣马尔库斯曾就一名不懂拉丁语的见证人向狄狄乌斯·尤利安努斯作出敕答：只要某人能凭理解力领会自己所参与的事项，即已足够。

<!-- source-p 080 -->
<a id="28.1.20.10"></a>**10.**但若见证人是被强行留在现场、并非自愿到场，则其遗嘱见证不被认为有效。

<!-- source-p 081 -->
<a id="28.1.21"></a>**28.1.21**

<!-- source-p 082 -->
**乌尔比安：《萨宾评注》第二卷。**

<!-- source-p 083 -->
<a id="28.1.21.pr."></a>**序言。**继承人应以能够被听见的方式公开宣告。因此，立遗嘱人可以口头宣告继承人，也可以书写继承人；但若以口头方式宣告，必须公开进行。“公开”是什么意思？并非要在公共场所进行，而是须能被听见；也不是须让所有人听见，而是须让见证人听见。若见证人超过法定人数，只须法定人数的见证人听见即可。

<!-- source-p 084 -->
<a id="28.1.21.1"></a>**1.**若立遗嘱后决定变更任何内容，就必须重新履行全部手续。至于某人在遗嘱中以口头或书面方式作出含糊表述，能否在完成程式后再作说明，则有疑问。例如，他有数名奴隶都叫斯提库斯，却遗赠了斯提库斯而未说明指哪一人；他有许多名提图斯的朋友，却将遗赠给提图斯而未指明是哪一位；或者其姓名、前名或家族名写错，但对其本人并未认错——此后能否说明其原本所指为何？我认为可以，因为他并未作出新的处分，只是在说明先前已经作出的处分。若后来以口头或书面方式为遗赠补加说明，例如补充金额、未曾写明的受遗赠人姓名或钱币种类，是否妥当？我也认为可以补充钱币种类；即便未补充，也可以依据遗嘱附近的文字、家父的惯例或当地惯例，推断立遗嘱人留下的财物为何。

<!-- source-p 085 -->
<a id="28.1.21.2"></a>**2.**在必须请求见证人在场、遗嘱方能成立的情形中，若见证人原本是为其他事项而被请求到场，原则上认为其不适格。但应如此理解：即使他们最初是为另一事项而被召集，只要在作证前获知自己将作为遗嘱见证人，仍可以有效作证。

<!-- source-p 086 -->
<a id="28.1.21.3"></a>**3.**遗嘱见证应在一个连续行为中完成。所谓一个连续行为，是指不得在遗嘱过程中插入与遗嘱无关的其他行为；若所为之事与遗嘱有关，则不使遗嘱无效。

<!-- source-p 087 -->
<a id="28.1.22"></a>**28.1.22**

<!-- source-p 088 -->
**乌尔比安：《告示评注》第三十九卷。**

<!-- source-p 089 -->
<a id="28.1.22.pr."></a>**序言。**我与父亲以及其他曾处于同一父权之下的人，能否同时计入见证人数？

<!-- source-p 090 -->
<a id="28.1.22.1"></a>**1.**应以见证人签署遗嘱时的身份状况为准，而非以立遗嘱人死亡时为准。因此，若见证人在签署时具备担任见证人的资格，后来发生的任何身份变化都不影响遗嘱。

<!-- source-p 091 -->
<a id="28.1.22.2"></a>**2.**若我从立遗嘱人处取得戒指并以之封缄遗嘱，遗嘱仍然有效，如同我使用他人戒指封缄一般。

<!-- source-p 092 -->
<a id="28.1.22.3"></a>**3.**若封印被立遗嘱人本人扰乱，则不视为已完成封缄。

<!-- source-p 093 -->
<a id="28.1.22.4"></a>**4.**若一名见证人未写上自己的姓名，却已加盖印记，则视同其未被选作见证人；若其像许多人那样写上姓名却没有加盖印记，结论亦同。

<!-- source-p 094 -->
<a id="28.1.22.5"></a>**5.**封印是否必须仅用戒指压印，还是也可以用其他物品压印？人们使用的封印方式各不相同。较为可取的看法是，只有戒指可以用于封印，但该戒指须带有可识别的印记。

<!-- source-p 095 -->
<a id="28.1.22.6"></a>**6.**遗嘱可以在夜间封缄，这一点毫无疑问。

<!-- source-p 096 -->
<a id="28.1.22.7"></a>**7.**即使包裹遗嘱文书的亚麻布上留有印记，也应视为遗嘱文书已封缄。

<!-- source-p 097 -->
<a id="28.1.23"></a>**28.1.23**

<!-- source-p 098 -->
**乌尔比安：《论题集》第四卷。**

<!-- source-p 099 -->
若立遗嘱人拆开遗嘱的封印后，又由七名见证人重新封缄，该遗嘱不因此成为未完成；依市民法与裁判官法，该遗嘱均有效。

<!-- source-p 100 -->
<a id="28.1.24"></a>**28.1.24**

<!-- source-p 101 -->
**佛罗伦提努斯：《法学阶梯》第十卷。**

<!-- source-p 102 -->
一份遗嘱可以制作并封缄多份副本，有时这甚至是必要的，例如某人即将乘船，希望随身携带一份，同时留下另一份记载其处分意愿的遗嘱。

<!-- source-p 103 -->
<a id="28.1.25"></a>**28.1.25**

<!-- source-p 104 -->
**雅沃勒努斯：《拉贝奥后论》第五卷。**

<!-- source-p 105 -->
瓦鲁斯在《学说汇纂》第一卷中记载，塞尔维乌斯曾答复：若立遗嘱人已口头宣布第一顺位继承人，却在说出第二顺位继承人之前变成哑者，更准确地说，他只是开始订立遗嘱而尚未完成；因此，第一顺位继承人也不能依据该遗嘱继承。拉贝奥认为，只有在能够确定立遗嘱人原本意图宣布多名继承人的情况下，这一结论才正确；我认为塞尔维乌斯也不会有其他意思。

<!-- source-p 106 -->
<a id="28.1.26"></a>**28.1.26**

<!-- source-p 107 -->
**盖尤斯：《行省告示评注》第二十二卷。**

<!-- source-p 108 -->
法律命令某人丧失作证资格，意味着不得采纳其所作证言；此外，如有些人所认为的，也不得为其作证。

<!-- source-p 109 -->
<a id="28.1.27"></a>**28.1.27**

<!-- source-p 110 -->
**凯尔苏斯：《学说汇纂》第十五卷。**

<!-- source-p 111 -->

**保罗：《答复集》第十四卷。**

<a id="28.1.29.pr."></a>**序言。**若为订立遗嘱而准备的书面文书未依法完成遗嘱，则不得依据该文书中载有信托遗赠措辞的内容请求权利。

<!-- source-p 118 -->
<a id="28.1.29.1"></a>**1.**家父在文书中补写了如下文字：“我希望此项遗嘱意愿以任何方式均属有效。”由此可见，他希望自己所留下的一切处分无论如何均有效，即使其最终无遗嘱而死亡亦然。

> 底本原文（希腊文转写及拉丁释义）：tautyn tyn diavykyn boulomai einai kurian epi pasys ecousias. [拉丁释义：hanc voluntatem valere volo quocumque modo.]
