# D.28.5 论遗嘱指定继承人（*De heredibus instituendis*）——第一部分

<!-- source-p 001 -->
<a id="5"></a><a id="28.5"></a>**28.5.0. 论遗嘱指定继承人。**

<!-- source-p 002 -->
<a id="28.5.1"></a>**28.5.1**

<!-- source-p 003 -->
**乌尔比安：《评萨宾》第一卷。**

<!-- source-p 004 -->
<a id="28.5.1.pr."></a>**序言。**立遗嘱者通常应从指定继承人开始撰写遗嘱。不过，也可以先明确剥夺某人的继承权；神圣图拉真皇帝曾以敕答规定，即使在指定继承人之前，也可以明确剥夺儿子的继承权。

<!-- source-p 005 -->
<a id="28.5.1.1"></a>**1.**我们也将被指定为继承人的人称为“遗嘱指定继承人”，即使其姓名并未写入遗嘱，而只是以口头方式宣告指定。

<!-- source-p 006 -->
<a id="28.5.1.2"></a>**2.**聋哑人也可以被有效指定为继承人。

<!-- source-p 007 -->
<a id="28.5.1.3"></a>**3.**既不打算作出遗赠，也不打算剥夺任何人继承权的，可以用五个词订立遗嘱，例如说：“卢基乌斯·提图斯应为我的继承人。”这一表述适用于以口头方式而非书面方式订立遗嘱的人。他也可以用三个词订立遗嘱，说：“卢基乌斯应为继承人。”因为“我的”和“提图斯”二词都是多余的。

<!-- source-p 008 -->
<a id="28.5.1.4"></a>**4.**如果某人仅被指定为某一地产的继承人，即使删去关于该地产的表述，其继承人指定仍然有效。

<!-- source-p 009 -->
<a id="28.5.1.5"></a>**5.**如果遗嘱写道：“卢基乌斯，继承人”，即使没有补上“应为”二字，我们仍认为其口头宣告的内容多于书面记载；“卢基乌斯，应为”亦同；因此，即使只写“卢基乌斯”，结论也相同。马尔凯卢斯颇有道理地认为，这种解释如今未必仍能成立。神圣庇护皇帝曾处理这样的遗嘱：立遗嘱者在继承人之间分配份额，写道“某人取得全部份额，另一人也取得全部份额”，却没有加上“应为继承人”。皇帝敕答认定继承人指定有效，尤利安也持相同意见。

<!-- source-p 010 -->
<a id="28.5.1.6"></a>**6.**神圣庇护皇帝还曾以敕答认定，“那位女子应为我的妻子”这一表述虽未出现“继承人”一词，继承人指定仍然有效。

<!-- source-p 011 -->
<a id="28.5.1.7"></a>**7.**同一位尤利安认为，“某人应为继承人”这一表述无效，因为缺少了必要内容；不过，只要补足省略的“我命令”一词，该指定本身仍然有效。

<!-- source-p 012 -->
<a id="28.5.2"></a>**28.5.2**

<!-- source-p 013 -->
**乌尔比安：《评萨宾》第二卷。**

<!-- source-p 014 -->
<a id="28.5.2.pr."></a>**序言。**对于以“按我将写明的份额”之语指定的继承人，马尔凯卢斯认为，如果最终没有写明任何份额，他们就不是继承人；他将此情形视同遗嘱写道“如果我写明各人的份额”。但更妥当的解释是：如果死者的意思并未与此相反，两种指定都应理解为：“我写明份额的各人，若未写明，则平均分配”，仿佛遗嘱作了双重指定。塞尔苏斯在《学说汇纂》第十六卷中赞同这一观点。另一种情形则不同：遗嘱写道“提图斯曾写明我应取得的份额，塞乌斯应为继承人”。在这种情况下，如果提图斯没有将其写为继承人，塞乌斯也不因此成为继承人；这并非没有道理，因为该处被理解为含有一项条件。马尔凯卢斯却认为，这两种表述相似。

<!-- source-p 015 -->
<a id="28.5.2.1"></a>**1.**以下两种写法可能有所区别：“按我已经写明的份额”，与“按我将要写明的份额”。就第一种写法而言，可以认为，如果未写明任何份额，继承人指定便不成立。马尔凯卢斯对以下遗嘱也作了同样的解释：“凡在其母亲遗嘱中被列名者，均为继承人。”如果母亲未立遗嘱而死亡，则这些人并未被指定为继承人。

<!-- source-p 016 -->
<a id="28.5.3"></a>**28.5.3**

<!-- source-p 017 -->
**乌尔比安：《评萨宾》第三卷。**

<!-- source-p 018 -->
<a id="28.5.3.pr."></a>**序言。**他人的奴隶可以全部或按份额被指定为继承人，即使未同时给予其自由也可以。

<!-- source-p 019 -->
<a id="28.5.3.1"></a>**1.**如果我无条件将自己的奴隶指定为继承人，却附条件给予其自由，那么继承人指定将延至给予自由之时才发生效力。

<!-- source-p 020 -->
<a id="28.5.3.2"></a>**2.**如果某人如此写道：“若提图斯成为继承人，塞乌斯应为继承人；提图斯应为继承人”，那么在塞乌斯成为继承人之前，应等待提图斯接受继承，仿佛这是一项条件。尤利安和特尔图利安均持此见解。

<!-- source-p 021 -->
<a id="28.5.3.3"></a>**3.**如果某人依遗嘱信托，在满足条件后方可获得自由，那么继承人可以无条件指定其为继承人并给予自由，无须等待该条件成就。此人将同时取得自由与遗产继承权，并在此期间成为必然继承人。条件成就后，他转为自愿继承人；这并非使他不再是继承人，而只是改变其继承权的性质。

<!-- source-p 022 -->
<a id="28.5.3.4"></a>**4.**延迟开启遗嘱文书，并不改变必然继承人的地位；正如我们谈到对未达青春期者的替补继承人时通常所说：文献曾记载，如果已故未达青春期者的儿子将自己交由替补继承人收养，他仍会成为必然继承人。

<!-- source-p 023 -->
<a id="28.5.4"></a>**28.5.4**

<!-- source-p 024 -->
**乌尔比安：《评萨宾》第四卷。**

<!-- source-p 025 -->
<a id="28.5.4.pr."></a>**序言。**自家继承人也可以附条件指定为继承人，但儿子除外，因为不得在任何条件下指定儿子。对于由儿子本人决定是否实现的条件，儿子可以被附条件指定为继承人；这一点无人争议。但指定仅在其实现条件时才有效，还是即使儿子未实现条件便死亡也有效？尤利安认为，儿子若附此类条件被指定为继承人，即使未实现条件，也会因此被排除。因此，如果该遗嘱指定的儿子另有共同继承人，共同继承人无须等到儿子实现条件；因为如果儿子不实现条件便使父亲成为无遗嘱死亡者，共同继承人显然必须等待。此观点颇有道理：附加由儿子自行决定的条件，不应使父亲成为无遗嘱死亡者。

<!-- source-p 026 -->
<a id="28.5.4.1"></a>**1.**我认为可以一般性地规定：条件是否由当事人控制，属于事实问题。例如，“若他到达亚历山大里亚”这一条件，可能因冬季状况而不由其掌控；如果当事人住在距亚历山大里亚第一里程碑之处，该条件也可能由其掌控。又如，“若他给提图斯十个钱币”这一条件，如果提图斯正远行在外，也可能难以实现。因此，应回到一般规则判断。

<!-- source-p 027 -->
<a id="28.5.4.2"></a>**2.**如果儿子附其可自行决定的条件被指定为继承人，且其子（即立遗嘱人的孙子）或外人为替补继承人，那么我认为，儿子在世时，替补继承人不得取得继承人地位；儿子死后，替补继承人则可以取得。也无须由替补继承人再次剥夺儿子的继承权；即使作出这种剥夺，也属徒劳，因为那是在儿子死亡后才作出的，而我们曾表明，这样做在其他情形下无效。因此，我认为，如果儿子附其可自行决定的条件被指定为继承人，后续顺位的继承人无须再剥夺其继承权；否则，共同继承人也都需要如此处理。

<!-- source-p 028 -->
<a id="28.5.5"></a>**28.5.5**

<!-- source-p 029 -->
**马尔凯卢斯：《尤利安〈学说汇纂〉》第二十九卷札记。**

<!-- source-p 030 -->
如果儿子附有某项条件被指定为继承人，而到其生命最后时刻已确定该条件不可能成就，且他在条件尚未确定期间死亡，那么他将作为无遗嘱继承人继承其父亲的遗产，例如遗嘱写道：“若他到达亚历山大里亚，就成为继承人。”但是，如果条件即使到最后时刻仍有可能实现，例如“若他给提图斯十个钱币，就成为继承人”，我认为结论相反。

<!-- source-p 031 -->
<a id="28.5.6"></a>**28.5.6**

<!-- source-p 032 -->
**乌尔比安：《评萨宾》第四卷。**

<!-- source-p 033 -->
<a id="28.5.6.pr."></a>**序言。**但是，如果条件附有期限，例如“若他在三十日内登上卡庇托尔山”，也可以作出相同判断：儿子不实现条件时，可以排除儿子并准许替补继承人继承。这与尤利安及我的意见一致。

<!-- source-p 034 -->
<a id="28.5.6.1"></a>**1.**依《维莱亚法》指定为继承人的孙辈及其后代，不会使遗嘱失效；他们可以附任何条件被指定为继承人，即使该条件使其地位与儿子的条件相同，也可以如此。

<!-- source-p 035 -->
<a id="28.5.6.2"></a>**2.**我们通常认为，中间时期不产生不利影响。例如，一名罗马公民在立遗嘱人尚在世时被指定为继承人，后来一度成为外邦人，随后又恢复罗马公民身份；中间时期不产生不利影响。又如，他人的奴隶附条件被指定为继承人，之后被交付给遗产中的奴隶；后来该奴隶又被外人通过取得时效取得所有权，其继承人指定并未因此失效。

<!-- source-p 036 -->
<a id="28.5.6.3"></a>**3.**如果所有人将共有奴隶连同自由一并指定为继承人，随后又买回该奴隶，那么该奴隶将成为必然继承人。但是，如果该奴隶是未达青春期者的替补继承人，而该未达青春期者只买回了该奴隶的一部分份额，则该奴隶不会成为必然继承人，尤利安如此写道。

<!-- source-p 037 -->
<a id="28.5.6.4"></a>**4.**如果奴隶连同自由一起被指定为继承人，尤利安还讨论能否通过遗嘱附录剥夺其自由。他认为，如果该奴隶将成为必然继承人，这种剥夺便无效，以免他被视为从自己手中剥夺了自己的自由；因为作为继承人被指定的奴隶，是从自己那里取得自由的。这一观点有其道理：正如不能向自己作出遗赠，也不能从自己手中剥夺自由。

<!-- source-p 038 -->
<a id="28.5.7"></a>**28.5.7**

<!-- source-p 039 -->
**尤利安：《学说汇纂》第三十卷。**

<!-- source-p 040 -->
<a id="28.5.7.pr."></a>**序言。**如果共有奴隶附条件被指定为继承人，并在立遗嘱人仍生时获得自由，那么即使遗嘱所定条件尚未成就，他也可以接受继承。

<!-- source-p 041 -->
<a id="28.5.7.1"></a>**1.**无论立遗嘱人本人在其死亡后将该奴隶转让给他人，还是继承人在立遗嘱人死亡后将其转让，他均应依所有人的命令接受继承。

<!-- source-p 042 -->
<a id="28.5.8"></a>**28.5.8**

<!-- source-p 043 -->
**尤利安：《致乌尔塞乌斯·费罗克斯书》第二卷。**

<!-- source-p 044 -->
<a id="28.5.8.pr."></a>**序言。**两名共有奴隶的所有人订立遗嘱，命令该奴隶成为继承人并获得自由；此后二人同时被坍塌事故压死。多数法学家答复说，在这种情况下，该奴隶将同时成为二人遗产中的必然继承人；此说更为正确。

<!-- source-p 045 -->
<a id="28.5.8.1"></a>**1.**如果两名所有人都命令该共有奴隶附同一条件获得自由并成为继承人，而该条件成就，法律效果也相同。

<!-- source-p 046 -->
<a id="28.5.9"></a>**28.5.9**

<!-- source-p 047 -->
**乌尔比安：《评萨宾》第五卷。**

<!-- source-p 048 -->
<a id="28.5.9.pr."></a>**序言。**如果某人本想指定一人为继承人，却因认错身份而写下另一人的姓名，例如写“我的兄弟”或“我的保护人”，则认为书面列名者不是继承人，因为立遗嘱人并无指定他的意思；其本想指定者也不是继承人，因为姓名并未写入遗嘱。

<!-- source-p 049 -->
<a id="28.5.9.1"></a>**1.**如果有人误认遗赠标的，例如本想遗赠一只盘子，却遗赠了一件衣服，那么无论是他本人写下遗嘱，还是口授他人代写，均无须履行任何一项遗赠。

<!-- source-p 050 -->
<a id="28.5.9.2"></a>**2.**但是，如果并非标的物有误，而是份额有误，例如某人口授将某人指定为二分之一份额的继承人，遗嘱却写为四分之一份额，塞尔苏斯在《疑问集》第十二卷及《学说汇纂》第十一卷中说，可以主张其应取得二分之一份额，因为立遗嘱人口头宣告得多，书面记载得少。这一观点得到一般性敕答的支持。如果立遗嘱人本人少写了份额，而原意是写得更多，结论也相同。

<!-- source-p 051 -->
<a id="28.5.9.3"></a>**3.**如果遗嘱书记员，或者——虽较难证明——立遗嘱人本人写得比原意更多，例如本想写四分之一，却写成二分之一，普罗库鲁斯认为继承人只取得四分之一，因为四分之一包含在二分之一之中；塞尔苏斯也赞同这一观点。

<!-- source-p 052 -->
<a id="28.5.9.4"></a>**4.**如果某人以数字符号本想写一百，却写成二百，法律亦同；因为其中既写有其本意的数额，也写有额外增加的数额。这一观点并非毫无道理。

<!-- source-p 053 -->
<a id="28.5.9.5"></a>**5.**马尔凯卢斯也讨论了这样的情形：某人打算加入一项条件，却未将其写入遗嘱；他认为，此人不应被视为继承人。但是，如果立遗嘱人不想加入条件，却将条件写入，那么删除该条件后，此人仍将成为继承人；违背其意思写入的内容，不应视为口头宣告过。马尔凯卢斯和我都赞同这一观点。

<!-- source-p 054 -->
<a id="28.5.9.6"></a>**6.**他还讨论了遗嘱书记员违背立遗嘱人的意思删去或改变条件的情形：此人不成为继承人，而应视为未被指定。

<!-- source-p 055 -->
<a id="28.5.9.7"></a>**7.**如果某人原本只打算将第一人指定为二分之一份额的继承人，却写下第一人和第二人，那么只有第一人被视为指定继承人，并将作为二分之一份额的继承人取得遗产。

<!-- source-p 056 -->
<a id="28.5.9.8"></a>**8.**如果某人没有说出继承人的姓名，却以明确无疑的标记指明其身份，而该标记与姓名几乎没有区别，则继承人指定有效；但如果所用的只是通常出于侮辱而加上的称谓，则无效。

<!-- source-p 057 -->
<a id="28.5.9.9"></a>**9.**指定继承人时，必须明确指明其身份。

<!-- source-p 058 -->
<a id="28.5.9.10"></a>**10.**如果某人如此写道：“我的兄弟提图斯和梅维乌斯二人中，娶西娅为妻者取得四分之三份额；未娶者取得四分之一份额，并为继承人”，那么可以确定，继承人指定有效；但具体何人取得哪一份额，尚不确定。

<!-- source-p 059 -->
<a id="28.5.9.11"></a>**11.**以下指定也与之相似：“上述兄弟中，娶西娅为妻者，应为继承人。”不过，我认为这一指定也有效，因为可以将其理解为附条件指定。

<!-- source-p 060 -->
<a id="28.5.9.12"></a>**12.**继承人是法律上的继受人；如果指定了数名继承人，立遗嘱人就应当在他们之间分配继承份额；若未分配，则他们均为平均份额的继承人。

<!-- source-p 061 -->
<a id="28.5.9.13"></a>**13.**如果指定两名继承人，其中一人取得科尔涅利乌斯地产的三分之一份额，另一人取得该地产的三分之二份额，塞尔苏斯遵从萨宾极为简明的观点：删去地产份额的记载后，只要家父的意思并未明确相反，两人便视为未注明份额而被指定为继承人，并依此继承遗产。

<!-- source-p 062 -->
<a id="28.5.9.14"></a>**14.**如果某人如此写道：“斯提库斯获得自由后，应成为继承人”，拉贝奥、涅拉提乌斯和阿里斯托认为，删去中间的“后”字，就应同时给予其自由和继承权；我也认为这一观点正确。

<!-- source-p 063 -->
<a id="28.5.9.15"></a>**15.**如果某人先指定第一人取得三分之一份额，第二人取得三分之一份额，并规定若第二人不成为继承人，则指定第三人取得三分之二份额；第二人拒绝继承时，第三人取得三分之二份额，不仅依据替补指定，也依据其原本的继承人指定：三分之一依据替补指定取得，另三分之一依据原指定取得。

<!-- source-p 064 -->
<a id="28.5.9.16"></a>**16.**如果获释奴隶被连同自由一并指定为继承人，他被转让后，受让人可以命令他接受继承；但是，如果立遗嘱人买回了该奴隶，继承人指定仍然有效，该奴隶将成为必然继承人。

<!-- source-p 065 -->
<a id="28.5.9.17"></a>**17.**如果奴隶自某日起获得自由，却被无条件指定为继承人，随后又被转让或释放，我们应当考察继承人指定是否有效。如果该奴隶未被转让，可以主张继承人指定有效：自由取得之日届至时，因自由尚未取得而被推迟的继承权随即发生效力，该奴隶遂成为必然继承人。

<!-- source-p 066 -->
<a id="28.5.9.18"></a>**18.**但是，如果自由自某日起给予，继承则附条件给予，那么在该日期届至后条件成就时，该奴隶将同时成为自由人和继承人。

<!-- source-p 067 -->
<a id="28.5.9.19"></a>**19.**如果该奴隶被无条件指定为继承人，但自由自某日起给予，那么即使他后来被转让或释放，也应认为他能够成为继承人。

<!-- source-p 068 -->
<a id="28.5.9.20"></a>**20.**即使没有转让奴隶本人，而是转让了对该奴隶的用益权，继承人指定仍然有效；不过，其效力将推迟至用益权消灭之时。

<!-- source-p 069 -->
<a id="28.5.10"></a>**28.5.10**

<!-- source-p 070 -->
**保罗：《评萨宾》第一卷。**

<!-- source-p 071 -->
如果某人按不同地产的份额指定继承人，应视为其没有写明继承份额；因为不同地产的价值不容易据此计算出相应份额。因此，萨宾的观点更为简便：应将其视为既未提及地产，也未提及份额而指定继承人。

<!-- source-p 072 -->
<a id="28.5.11"></a>**28.5.11**

<!-- source-p 073 -->
**雅沃勒努斯：《书信集》第七卷。**

<!-- source-p 074 -->
某遗嘱写道：“阿提乌斯取得科尔涅利乌斯地产的继承人份额；两名提图斯取得那座公寓楼的继承人份额。”两名提图斯将取得二分之一，阿提乌斯也将取得二分之一；普罗库鲁斯持此意见。你怎么看？答复：普罗库鲁斯的意见正确。

<!-- source-p 075 -->
<a id="28.5.12"></a>**28.5.12**

<!-- source-p 076 -->
**保罗：《评萨宾》第二卷。**

<!-- source-p 077 -->
如果立遗嘱人先指定了不等的份额，随后又加上“我指定为不等份额继承人的各人，应平均继承”，那么应认为各人份额已被调平，但前提是这句话写在遗嘱完成之前。

<!-- source-p 078 -->
<a id="28.5.13"></a>**28.5.13**

<!-- source-p 079 -->
**乌尔比安：《评萨宾》第七卷。**

<!-- source-p 080 -->
<a id="28.5.13.pr."></a>**序言。**有时，“应平均继承”这一附加语可以表达立遗嘱人的意思。例如，遗嘱写道：“第一人和我兄弟的儿子应平均继承。”正如拉贝奥所写，这句话表明所有人均按个人份额被指定；如果删去该句，兄弟之子将取得二分之一，第一人也将取得二分之一。

<!-- source-p 081 -->
<a id="28.5.13.1"></a>**1.**家父可以将遗产分为其希望的任意份数；不过，通常以十二盎司为完整遗产单位，将遗产划分为十二份。

<!-- source-p 082 -->
<a id="28.5.13.2"></a>**2.**因此，如果分配份额不足，依法将恢复相应的份额。例如，若他指定两名继承人各取得四分之一，那么遗产的剩余部分依法补入，使两人视为各取得二分之一。

<!-- source-p 083 -->
<a id="28.5.13.3"></a>**3.**但是，如果一人被指定取得四分之一，另一人取得二分之一，补入的四分之一应依其继承份额比例由两人共同取得。

<!-- source-p 084 -->
<a id="28.5.13.4"></a>**4.**如果所分配份额超过十二盎司，则应同比例缩减。例如，遗嘱指定我取得十二盎司，你取得六盎司，那么我将取得遗产的三分之二，你取得三分之一。

<!-- source-p 085 -->
<a id="28.5.13.5"></a>**5.**如果立遗嘱人指定两人各取得全部遗产，又指定其他人各取得十二盎司，是否应平均分配？拉贝奥在《后论》第四卷中讨论了这一问题。他认为，前两人各取得二分之一，按十二盎司指定的其他人也各自分享另一个二分之一；我认为应当赞同这一意见。

<!-- source-p 086 -->
<a id="28.5.13.6"></a>**6.**在同一卷中，拉贝奥还说：如果立遗嘱人指定两人各取得全部遗产，另指定第三人取得二分之一加六分之一，那么应把一个完整遗产单位分为二十份；按二分之一加六分之一指定的第三人取得八份，前两人合计取得十二份。

<!-- source-p 087 -->
<a id="28.5.13.7"></a>**7.**同一卷中还记载：“提图斯取得三分之一”，随后在补足全部份额后又写“同一人取得六分之一”。特雷巴提乌斯说，应将遗产分为十四盎司。

<!-- source-p 088 -->
<a id="28.5.14"></a>**28.5.14**

<!-- source-p 089 -->
**雅沃勒努斯：《评卡西乌斯》第一卷。**

<!-- source-p 090 -->
如果某人如此指定继承人：“提图斯为第一份额继承人，塞乌斯为第二份额继承人，梅维乌斯为第三份额继承人，苏尔皮基乌斯为第四份额继承人”，那么被指定者将平均分配遗产。因为立遗嘱人使用序数，似乎只是为书写顺序编号，而非规定各人份额的数额。

<!-- source-p 091 -->
<a id="28.5.15"></a>**28.5.15**

<!-- source-p 092 -->
**乌尔比安：《评萨宾》第七卷。**

<!-- source-p 093 -->
<a id="28.5.15.pr."></a>**序言。**尤利安也在《学说汇纂》第三十卷中记载：如果某人如此指定继承人：“提图斯取得二分之一并为继承人；塞乌斯取得二分之一；我指定塞乌斯取得的那一份额由塞姆普罗尼乌斯继承”，那么可以疑问：立遗嘱人是想把遗产分成三个二分之一，还是想让塞乌斯与塞姆普罗尼乌斯共同取得一个二分之一？后一种意见更为正确，因此应视为共同指定。这样，提图斯取得二分之一，另两人各取得四分之一。

<!-- source-p 094 -->
<a id="28.5.15.1"></a>**1.**尤利安在同一卷中还写道：如果第一人、第二人各被指定为二分之一份额的继承人，而在第一人不成为继承人时，第三人被指定为四分之三份额的替补继承人，这属于事实问题。不过，较为妥当的说法是：如果第一人接受继承，前两人取得相等份额；如果第一人拒绝继承，则遗产分为十五份，第三人取得九份，第二人取得六份。

<!-- source-p 095 -->
<a id="28.5.16"></a>**28.5.16**

<!-- source-p 096 -->
**尤利安：《学说汇纂》第三十卷。**

<!-- source-p 097 -->
因此，第三人同时承担原指定继承人和替补继承人的身份：应视为原指定时取得三份，作为替补继承人时取得六份。
