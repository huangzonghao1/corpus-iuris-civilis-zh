## <a id="4.4"></a>4.4　论未满二十五岁者

### <a id="4.4.1"></a>4.4.1　乌尔比安《评告示》第十一卷

<a id="4.4.1.pr."></a>

**序言（pr.）** 裁判官依据自然衡平原则颁布本告示，并藉此承担起保护未成年人的职责。因为众所周知，这一年龄段的人判断脆弱而不稳，容易遭受许多欺诈，也暴露于许多人的算计之下；因此，裁判官在本告示中允诺向他们提供援助，使其免受欺诈。

<a id="4.4.1.1"></a>

**1.** 裁判官告示说：“据称与未满二十五岁者实施的行为，我将视具体情形予以审查。”

<a id="4.4.1.2"></a>

**2.** 显然，裁判官允诺援助未满二十五岁者；因为人们认为，过了这个年龄，成年人的成熟程度便已具备。

<a id="4.4.1.3"></a>

**3.** 因此，现今青年人在达到这一年龄之前，由保佐人协助管理事务；在此之前，不应将其财产事务的管理交由他们自行处理，即使他们能够妥善料理自己的事务亦然。

### <a id="4.4.2"></a>4.4.2　乌尔比安《评〈尤利娅法与帕皮娅法〉》第十九卷

他也不得仅因有子女，便提前从保佐人处取回自己的财产。神圣塞维鲁斯皇帝说，法律所规定的“每有一名子女即减免一年”，涉及担任公职的资格，并不涉及取回本人财产的管理权。

### <a id="4.4.3"></a>4.4.3　乌尔比安《评告示》第十一卷

<a id="4.4.3.pr."></a>

**序言（pr.）** 最后，神圣塞维鲁斯皇帝和我皇帝将这类执政官或行省长官所作的裁决解释为近于徇私；他们自己则极少以非常程序例外准许未成年人管理自己的事务；我们也遵行同一法律。

<a id="4.4.3.1"></a>

**1.** 如果某人与未成年人订立契约，而契约效力延续至该未成年人成年之时，我们应考察契约的开始还是结束？依既定规则，若其成年后认可了自己未成年时所为之事，恢复原状救济即不再适用。对此，塞尔苏斯在《书信集》第十一卷及《学说汇纂》第二卷中，曾就裁判官弗拉维乌斯·雷斯佩克图斯向其询问的一项事实作了恰当讨论：一名未满二十五岁者，当时或许年方二十四，曾对监护人的继承人提起监护诉讼。后来，审判尚未终结，此人已满二十五岁，而监护人的继承人却据称获判免责；于是有人请求恢复原状。塞尔苏斯因此建议雷斯佩克图斯，不应轻易准许这个曾经未成年的当事人恢复原状；但若能证明对方蓄意操纵，以便待此人成年后使其免责，则应准许救济。因为他说，此人似乎并非仅在审判最后一天受骗，而是整个安排从一开始便是为了等他成年后使对方免责。尽管如此，塞尔苏斯也承认，如果仅有较轻微的迹象，怀疑对方可能以欺诈方式行事，就不应准许恢复原状。

<a id="4.4.3.2"></a>

**2.** 我还记得曾发生过这样的情形：一名未满二十五岁者参与了父亲的遗产事务，成年后又从父亲的债务人处收取了某些款项；此后，他请求恢复原状，以便不承受父亲的遗产。有人反对说，他成年后已经认可了自己未成年时所为之事；但我们仍认为，应考察行为开始时的情形，并准许恢复原状。我认为，即使他接受的是他人的遗产，也应适用同一规则。

<a id="4.4.3.3"></a>

**3.** 还应考察：未满二十五岁者在其生日当天、但尚未到其出生时刻之前，是否仍应视为未成年人，以便其在受欺诈时得请求恢复原状？既然此时尚未满二十五岁，就应当逐时计算年龄。因此，即使其出生于闰年，塞尔苏斯也写道，无论出生于闰日的前一天还是后一天，都没有区别；这两日按一日计算，并将较后的那一日作为闰日插入日历。

<a id="4.4.3.4"></a>

**4.** 还须考察，救济应只给予家父，还是也给予家子。令人疑虑的是：如果认为家子就其特有产也应获得救济，那么这项救济便会经由家子使已成年的家父受益；而这绝非裁判官的本意，因为裁判官允诺援助的是未成年人，而不是成年人。我认为，主张未成年家子仅在涉及其自身利益的事由上可以请求恢复原状者，其见解最为正确，例如其本人负有债务时即属此类。

因此，若家子依父亲的命令负债，父亲当然可能被请求承担全部债务；至于家子本人，因其仍处于家父权下时也可能被诉，即使解放或被剥夺继承资格后，也可能在其有能力清偿的范围内被诉；而且，即便仍处于家父权下，也可能不顾父亲反对而因判决被诉追偿。故若家子本人被诉，就应请求救济。至于这一救济是否也惠及父亲，如同有时会惠及其保证人那样，则须讨论；我认为不会。因而，若家子被诉，他可以请求救济；若债权人起诉父亲，则不适用此项救济，但借贷情形除外：在借贷中，如果家子奉父亲之命借入金钱，他就不能获得救济。

同样，若家子未经父亲命令订约并受欺诈，而债权人仅以特有产之诉起诉父亲，家子不得请求恢复原状；若家子本人被诉，则可以请求恢复原状。我们并不因此认为家子享有特有产利益：特有产的利益主要属于父亲，而非家子，尽管在某些情形下特有产也与家子有关。例如，其父亲的财产因债务被国库查封时，依据克劳狄乌斯皇帝的敕令，家子的特有产应与其父亲的财产分离。

<a id="4.4.3.5"></a>

**5.** 因此，如果家女在嫁资事务上受了欺诈，例如她同意父亲就嫁资作出要式承诺，但底本紧接的 *non statim quam dedit* 句法关系未明；或同意由他人就嫁资作出要式承诺，我认为应准许她恢复原状，因为嫁资是家女自己的财产。〔原文含义未详：*non statim quam dedit*，具体指向和句法关系待核。〕

<a id="4.4.3.6"></a>

**6.** 如果未满二十五岁者将自己交由他人收养，并声称在收养过程中受了欺诈（例如，富有者被掠夺者收养），我认为，在其请求恢复原状时，应予受理。

<a id="4.4.3.7"></a>

**7.** 如果遗嘱为未成年家子留下遗赠或遗嘱信托，约定父亲死后给付，而他受到欺诈，例如同意父亲约定不请求该遗赠，则可以说应准许其恢复原状，因为他本人对该遗赠享有利益：父亲死后，该遗赠即归其享有。又如，遗嘱留给他的某项利益与其个人身份相连，例如军职权利，也应认为可以准许恢复原状；因为他有避免受欺诈的利益，该利益并非由父亲取得，而是由他本人享有。

<a id="4.4.3.8"></a>

**8.** 又如，某人被指定为继承人，但须在一百日内由父亲解放；他本应随即通知父亲，却在能够通知的情况下没有通知；如果父亲知情本会解放他，那么只要父亲现已准备将他解放，就应认为可以准许他恢复原状。

<a id="4.4.3.9"></a>

**9.** 庞波尼乌斯补充说：凡家子因特有产事由可以请求恢复原状的，父亲也可以在家子死亡后以其继承人身份，为家子请求审理。

<a id="4.4.3.10"></a>

**10.** 如果家子拥有军役特有产，毫无疑问，凡涉及军役特有产的事项，他都应获准恢复原状，犹如他在自己的财产中受了欺诈一样。

<a id="4.4.3.11"></a>

**11.** 未满二十五岁的奴隶在任何情况下都不得请求恢复原状，因为应考察的是主人的身份；主人应自行承担将事务委托给未成年人处理的后果。因此，即使主人通过未达适婚年龄的人订约，也应作同样处理，正如马尔切鲁斯在《学说汇纂》第二卷中所写。即使主人准许未成年奴隶自由管理特有产，已成年的主人也不得据此请求恢复原状。

### <a id="4.4.4"></a>4.4.4　阿非利卡努斯《问题集》第七卷

奴隶所实施的一切行为，均应视为在主人意愿下实施。若讨论店经理诉讼，或设定一名已满二十五岁者委托未成年人办理某项事务，而该未成年人在办理事务时受了欺诈，这一点便更为明显。

### <a id="4.4.5"></a>4.4.5　乌尔比安《评告示》第十一卷

但如果该奴隶享有依遗嘱信托即时获得自由的权利，而在自由权迟延实现期间受了欺诈，那么可以说裁判官应当向他提供救济。

### <a id="4.4.6"></a>4.4.6　乌尔比安《评告示》第十卷

未满二十五岁者可以通过恢复原状获得救济；不仅在其财产有所减少时如此，在其有理由避免诉讼及费用困扰时，也应如此。

### <a id="4.4.7"></a>4.4.7　乌尔比安《评告示》第十一卷

<a id="4.4.7.pr."></a>

**序言（pr.）** 裁判官说：“据称实施了行为。”所谓“实施行为”，应作广义理解，无论是订立契约，还是发生其他事项，均包括在内。

<a id="4.4.7.1"></a>

**1.** 因此，如果未成年人购买或出售某物、加入合伙，或借入金钱而受了欺诈，就应给予他救济。

<a id="4.4.7.2"></a>

**2.** 如果父亲的债务人或未成年人本人的债务人向他清偿金钱，而他将钱款丢失，也应认为可以向他提供救济，仿佛该行为系与他订立的交易。因此，未成年人起诉债务人时，应有保佐人在场，以便债务人向其清偿；否则，不得强令债务人付款。不过，正如庞波尼乌斯在《问题集》第二十八卷中所写，如今通常将金钱寄存于神庙，以免债务人继续负担利息，或未成年债权人丧失钱款；若有保佐人，也可将钱款付给保佐人。依皇帝敕令，债务人还可以要求未成年人请求指定保佐人。但如果裁判官裁定可在没有保佐人的情况下向未成年人付款，而债务人已经付款，他能否免于责任？对此可以有疑问。不过我认为，如果债务人以对方未成年为由提出抗辩，却仍被迫付款，就不应归咎于他；除非有人认为，他本应针对不当裁定提起上诉。但我认为，裁判官不会受理这个未成年人提出的恢复原状请求。

<a id="4.4.7.3"></a>

**3.** 不仅在上述情形下应给予救济，未成年人在提供担保等介入行为中受欺诈时，也应获得救济，例如他以保证人身份承担债务，或以自己的财物作保。庞波尼乌斯似乎赞同如下区分：究竟是为审查保证人资格而指定的仲裁人认可了该未成年人，还是其对方当事人认可了他？但我认为，只要其未满二十五岁且证明自己受了欺诈，就始终应给予救济。

<a id="4.4.7.4"></a>

**4.** 在诉讼中也应提供救济，无论未成年人作为原告还是被告时受了欺诈。

<a id="4.4.7.5"></a>

**5.** 如果未成年人接受了一项获利较少的遗产，也应给予救济，使其可以拒绝承受；因为他在此也受了欺诈。接受遗产占有或其他继承利益时亦同。不仅参与父亲遗产事务的家子如此，未满二十五岁的必然继承人也可同样请求恢复原状，例如被指定为继承人并获释的奴隶。因为若其已经参与遗产事务，应依年龄利益给予援助，使其本人的财产得以分离。当然，若其在接受遗产后获准恢复原状，对于遗产中已经归入其本人财产且未因其年龄未成熟而灭失的利益，仍须予以返还。

<a id="4.4.7.6"></a>

**6.** 如今已有确定规则：即使未成年人因行为获利，也应向其提供救济。

<a id="4.4.7.7"></a>

**7.** 庞波尼乌斯在《问题集》第二十八卷中还写道：未成年人即使没有任何人的欺诈而放弃遗赠，或在选择遗赠标的时受骗、选了较差之物，或承诺在两件物品中交付其一而最终交付较有价值的那件，也应给予救济；确应如此。

<a id="4.4.7.8"></a>

**8.** 既然说未成年人即使因获利也可获得救济，那么，如果其财产已经出售，而另有人愿出更高价，他是否也应为获利而恢复原状？裁判官每天都准许此类未成年人恢复原状，使竞价得以重新进行；对那些应为其保留的财物也作同样处理。但此事必须审慎办理，否则无人愿意购买未成年人或受监护人财产，即使这些财产是以诚信方式出售亦然。因此，对于易受意外事件影响的财产，除非能够证明存在舞弊行为，或监护人、保佐人明显偏袒，否则严格说来，不应向未成年人提供针对买受人的救济。

<a id="4.4.7.9"></a>

**9.** 获准恢复原状的人，如果重新参与遗产事务或接受先前已拒绝的遗产，之后仍可再次请求恢复原状，以便拒绝承受遗产；敕答及法律意见均已确认这一点。

<a id="4.4.7.10"></a>

**10.** 帕皮尼安在《答复集》第二卷中说：未成年人拒绝遗产时，替补指定的奴隶将成为必然继承人；即使该未成年人后来获准恢复原状，该奴隶仍保持自由。但如果未成年人先接受遗产，随后又获准不予承受，那么替补给该未成年人的、附有自由安排的奴隶，既不能成为继承人，也不能成为自由人。这一说法并非全然正确。因为如果遗产无力清偿债务，继承人拒绝承受时，神圣庇护皇帝及我皇帝都曾作出敕答：在这种情况下，替补指定的奴隶仍可成为必然继承人；对于外部继承人亦适用此规则。至于他说奴隶仍保持自由，其意是：未成年人后来获准拒绝遗产时，该奴隶不仅仍为自由人，也仍为继承人。因为未成年人此时并未成为继承人，而只是取得准诉权；毫无疑问，曾经成为继承人的奴隶仍将保持继承人身份。

<a id="4.4.7.11"></a>

**11.** 同样，未成年人如果未在期限内提起上诉，应给予救济，使其得以提起上诉；例如，设想其确有此请求。

<a id="4.4.7.12"></a>

**12.** 同样，未成年人在缺席判决中也应获得救济。缺席诉讼的恢复适用于所有年龄的人，只要其证明自己因正当理由缺席即可。

### <a id="4.4.8"></a>4.4.8　赫尔莫杰尼安《法学摘要》第一卷

即使未成年人因被视为抗辩不出庭而遭判决，也可以请求恢复原状救济。

### <a id="4.4.9"></a>4.4.9　乌尔比安《评告示》第十一卷

<a id="4.4.9.pr."></a>

**序言（pr.）** 如果未成年人的财物因执行判决而被扣押并出售，而后他又获准对总督或皇帝代理人的判决请求恢复原状，那么应否撤销已经进行的出售，尚须考察。不过，有一点确定：因执行判决而支付的钱款应返还给他。但对他本人而言，取回原物更为重要；我认为，若未成年人遭受重大损失，有时应准许其取回原物。

<a id="4.4.9.1"></a>

**1.** 在嫁资方面也应向妇女提供救济：若她受欺诈而给付的嫁资超出其财产承受能力，或相当于其全部财产，即属此类。

<a id="4.4.9.2"></a>

**2.** 现在须考察，未成年人受欺诈时，是否仅在契约中给予救济，还是在实施不法行为时也给予救济。例如，未成年人就寄托物、借用物或其他契约事项实施欺诈，而未因此获得任何利益，是否仍应获救济？通说认为，未成年人实施不法行为时不予救济；因此，这种情形也不提供救济。未成年人实施盗窃或不法损害时，同样不予救济。但若他可以承认造成损害，从而避免承担双倍责任，却选择否认，那么仅应准许其恢复原状，使其被视为已承认事实。因此，若他本可选择赔偿盗窃所致损害，而不必承担双倍或四倍责任，却没有这样做，也应给予救济。

<a id="4.4.9.3"></a>

**3.** 如果妇女因自身过错离婚后请求救济，或丈夫提出此种请求，我认为都不应准许恢复原状，因为这并非轻微的不法行为。未成年人实施通奸时，也不提供救济。

<a id="4.4.9.4"></a>

**4.** 帕皮尼安说，年龄已满二十岁但未满二十五岁者，若同意被卖为奴隶，也就是分得卖身所得价款，通常不得请求恢复原状。此规则确有道理，因为身份一经改变，该事项便无法恢复原状。

<a id="4.4.9.5"></a>

**5.** 如果称未成年人因税赋事项而落入罚没（*in commissum*），应准许恢复原状；但须理解为未成年人本人并未实施欺诈，否则恢复原状即不适用。〔此处“vectigalis ... in commissum”所指的具体税赋情形待核。〕

<a id="4.4.9.6"></a>

**6.** 对于涉及自由身份的争议，裁判官不可能依恢复原状向未成年人提供救济。〔原文含义未详：*adversus libertatem ... minori subveniri*；或指未成年人请求否定他人已经取得的自由身份，需据罗马法身份诉讼语境复核。〕

### <a id="4.4.10"></a>4.4.10　保罗《评告示》第十一卷

除非其已基于重大事由从皇帝处取得此项救济。

### <a id="4.4.11"></a>4.4.11　乌尔比安《评告示》第十一卷

<a id="4.4.11.pr."></a>

**序言（pr.）** 但可为此提起欺诈之诉或准诉权，以请求相当于未成年人若未被解放本可享有利益的赔偿；因此，他若未被解放时本可取得的任何利益，现在都应给付于他。又对于被解放的奴隶隐匿的主人财物，也可对其提起出示之诉、盗窃之诉及返还之诉，因为这些财物曾由该奴隶占有。不过，奴隶在仍处于奴隶身份时所实施的不法行为，主人在其获得自由后不得再对其提起诉讼；神圣塞维鲁斯皇帝的敕答也确认了这一点。

<a id="4.4.11.1"></a>

**1.** 如果年龄已满二十岁但未满二十五岁的未成年人，依约在出售后获得自由，那么是否应给予救济？我特意说“已满二十岁”，因为斯凯沃拉在《问题集》第十四卷中也写道，神圣马尔库斯皇帝致奥菲迪乌斯·维克托里努斯的敕令，应当不包括未满二十岁者。于是须考察，是否应向已满二十岁者提供救济：如果他在自由权尚未发生之前提出请求，应予受理；若在自由权发生之后才请求，则不应准许。又可追问，依约买入奴隶者若是未成年人，能否请求恢复原状。若自由权尚未发生，应认为可以给予救济；若自由权发生的期限已经届至，则成年出卖人的意愿即足以使该奴隶获得自由。

<a id="4.4.11.2"></a>

**2.** 曾有一项事实问题：一些青年聘请了一名名叫萨尔维安努斯的人担任保佐人。他履行保佐职责后，因皇帝恩准而取得罗马城市行政官职，并在青年们不在场时向裁判官请求解除其保佐职责。青年们遂向裁判官提出请求，要求针对萨尔维安努斯恢复原状，理由是其获准免责违反了敕令。因为通常只有因公务身在海外者，或在皇帝身边任职者，才可卸下已承受的监护职责；例如梅南德尔·阿里乌斯担任皇帝顾问时，曾获准免责。萨尔维安努斯却也获准免责，因此青年们主张自己受了欺诈，请求裁判官准许恢复原状。埃特里乌斯·塞维鲁斯对此有所疑虑，便将此事报告皇帝。塞维鲁斯皇帝就该询问向其继任者维尼狄乌斯·奎图斯作出敕答：裁判官无权处理此事，因为并不存在与未满二十五岁者订立的契约；皇帝应当介入，并使该保佐人重新承担其被裁判官错误解除的管理职责。

<a id="4.4.11.3"></a>

**3.** 须知，对未成年人并非一概给予救济；只有在查明案情后，且其主张自己确实受了欺诈时，才予救济。

<a id="4.4.11.4"></a>

**4.** 如果未成年人审慎管理自己的财产，只因并非轻率行为所致、而是命运造成的偶然损失，便请求恢复原状，也不应准许。因为恢复原状并非因损害结果本身而授予，而是针对轻率行事。庞波尼乌斯在《问题集》第二十八卷中也如此写道。因此，马尔切鲁斯在尤利安的著作中指出：未成年人为自己购买了一名必要的奴隶，而该奴隶随后死亡，不应准许其恢复原状；他购买必要之物时并未受欺诈，尽管奴隶终有一死。

<a id="4.4.11.5"></a>

**5.** 如果某人继承了一项原本富有的遗产，而遗产旋即遭受损失（例如地产因地陷而毁，公寓楼失火，奴隶逃走或死亡），尤利安在《学说汇纂》第四十六卷中似乎认为可以准许未成年人恢复原状。马尔切鲁斯则在尤利安的著作中指出，不应准许恢复原状：未成年人接受富有的遗产时，并非因年龄判断失误而受欺诈；命运造成的损失也可能降临于任何家父，即便其极为谨慎亦然。不过，如果未成年人接受的遗产中包含许多易灭失之物或城市地产，并负有沉重债务，而他未能预见奴隶可能死亡、地产可能倒塌，或未能及时出售那些容易遭受多种风险的财产，则这种情形可以构成准许其恢复原状的事由。

<a id="4.4.11.6"></a>

**6.** 又有问题：未成年人是否可以请求针对另一未成年人恢复原状？庞波尼乌斯简单地写道，不应准许恢复原状。但我认为，裁判官应查明谁受了欺诈。因此，如果双方都受了损失，例如一名未成年人借钱给另一名未成年人，而后者将钱挥霍或丢失，依庞波尼乌斯之见，收款一方的处境更为有利。

<a id="4.4.11.7"></a>

**7.** 但若未成年人同已成年的家子订约，则尤利安在《学说汇纂》第四卷、马尔切鲁斯在《学说汇纂》第二卷均写道，可以准许恢复原状，以便优先考虑年龄因素，而不适用元老院决议。

### <a id="4.4.12"></a>4.4.12　盖尤斯《评行省告示》第四卷

如果一名妇女为他人担保，而债权人是未成年人，则不得对该妇女给予诉权；她应像其他担保人一样，通过抗辩权被排除在诉讼之外，因为依一般法律，未成年人可恢复对原债务人的诉权。此规则以原债务人有清偿能力为前提；否则，该妇女不得援用元老院决议所规定的保护。

### <a id="4.4.13"></a>4.4.13　乌尔比安《评告示》第十一卷

<a id="4.4.13.pr."></a>

**序言（pr.）** 在审查案情时，须考察救济应仅给予未成年人，还是也应给予为其负有责任的人，例如保证人。因此，如果我明知你是未成年人且不信任你，而由你为其作保证，那么为了损害我的利益而救济保证人并不公平；相反，应拒绝未成年人提起委任之诉。总之，裁判官应权衡究竟应当帮助债权人还是保证人；因为受欺诈的未成年人对两者均不负责任。至于委托人，较容易得出不应给予救济的结论，因为他如同担保人，曾赞成并促使他人与未成年人订约。由此可进一步讨论，未成年人请求恢复原状时，应仅针对债权人，还是也应针对保证人。我认为，同时针对两者更为稳妥；应在查明案情后，并在对方当事人在场、或其无正当理由缺席的情况下，审酌是否恢复原状。

<a id="4.4.13.1"></a>

**1.** 有时也可给予未成年人对物恢复原状救济，即使其财物现由占有人持有，而未成年人与该占有人之间并未订约。例如，你从未成年人处买得某物，又将其转卖他人；未成年人有时可以请求针对占有人恢复原状，以免失去自己的物品或无法取回财物。裁判官可以通过审理案情，或撤销转让并授予对物诉权来提供救济。庞波尼乌斯在《问题集》第二十八卷中也写道，拉贝奥认为：如果未满二十五岁者出售并交付土地，而买受人又将土地转售，那么若后手买受人知道此前的交易情况，应准许未成年人针对其请求恢复原状；若后手买受人不知情，且第一手买受人有清偿能力，则不应准许；但若第一手买受人无清偿能力，那么即使后手买受人不知情且属善意买受人，让未成年人获得救济也更为公平。

### <a id="4.4.14"></a>4.4.14　保罗《评告示》第十一卷

但只要从未成年人处取得财物的人或其继承人有清偿能力，就不应对善意买受人另作新的裁定；庞波尼乌斯也如此写道。

### <a id="4.4.15"></a>4.4.15　盖尤斯《评行省告示》第四卷

但在准许恢复原状时，后手买受人可以向自己的出卖人追索；即使买卖关系经过数人转手，也适用同一法律。

### <a id="4.4.16"></a>4.4.16　乌尔比安《评告示》第十一卷

<a id="4.4.16.pr."></a>

**序言（pr.）** 在审查案情时，还应考察是否存在其他诉权，而无须恢复原状。如果未成年人已受一般救济及严格法保护，就不应再给予特别救济。例如，未成年人与未达适婚年龄的被监护人订约，而后者未经监护人授权；若前者并未因此获利，就属此类。

<a id="4.4.16.1"></a>

**1.** 拉贝奥曾报告说，未成年人受欺诈而订立合伙，或以赠与为目的订立契约时，合伙关系并不成立；即使当事人都是成年人，也仍然如此，因此无须裁判官介入。奥菲利乌斯也作了同样答复，因为未成年人已依严格法获得充分保护。

<a id="4.4.16.2"></a>

**2.** 庞波尼乌斯还在《问题集》第二十八卷中记载：有人作为继承人，受托将若干物品交给其兄弟之女，并约定若她无子女而死亡，就应将这些物品返还给继承人；她在该继承人死亡后，又向其继承人保证会返还。阿里斯托认为，她应获准恢复原状。庞波尼乌斯还补充说，即使她已成年，也可以就该保证提起不确定之债诉讼，因为她所受保护并非源于法律本身，而是通过该诉讼取得。

<a id="4.4.16.3"></a>

**3.** 一般而言，若契约无效，应认定裁判官不应介入。

<a id="4.4.16.4"></a>

**4.** 庞波尼乌斯还说，买卖双方在价格上相互占便宜，依通常交易规则本属许可。

<a id="4.4.16.5"></a>

**5.** 现在要考察哪些官员可以准许恢复原状。城市长官以及其他官员均可依其管辖权准许恢复原状；无论是其他事由，还是对其本人作出的判决，均可如此处理。

### <a id="4.4.17"></a>4.4.17　赫尔莫杰尼安《法学摘要》第一卷

禁卫军长官也可以针对自己作出的判决准许恢复原状，尽管不得对其提起上诉。两种救济的区别就在于：上诉包含对判决不公的申诉；恢复原状则包含请求宽宥自身错误，或主张对方当事人实施了欺诈。

### <a id="4.4.18"></a>4.4.18　乌尔比安《评告示》第十一卷

<a id="4.4.18.pr."></a>

**序言（pr.）** 下级官员不得针对上级官员的判决准许恢复原状。

<a id="4.4.18.1"></a>

**1.** 如果皇帝作出了判决，通常很少准许恢复原状，并将声称自己因年龄未成熟而受欺诈的人召入御前听审；例如，此人主张未陈述有利于自己的理由，或声称被律师出卖。神圣塞维鲁斯皇帝和皇帝安敦尼努斯并未受理格拉布里奥·阿基利乌斯提出的恢复原状请求；此人针对其兄弟请求救济时，御前听审已经结束，其请求显然只是托词。

<a id="4.4.18.2"></a>

**2.** 神圣塞维鲁斯皇帝和皇帝安敦尼努斯还准许佩尔肯尼乌斯·塞维鲁斯在御前听审，请求针对已经两度裁判的事项恢复原状。

<a id="4.4.18.3"></a>

**3.** 同一皇帝还向利基尼乌斯·弗龙托作出敕答：在代表皇帝审理上诉并作出判决之后，通常不得再由他人准许恢复原状，只有皇帝本人例外。

<a id="4.4.18.4"></a>

**4.** 如果受皇帝指派的法官已经审理案件，除指派该法官的皇帝本人外，任何人都不得准许恢复原状。

<a id="4.4.18.5"></a>

**5.** 恢复原状不仅给予未成年人，也给予未成年人的继承人或其他继受人，即使这些继受人本人已经成年。

### <a id="4.4.19"></a>4.4.19　乌尔比安《评告示》第十三卷

有时，依告示明文，我们会给予继受人超过一年的期限，例如继受人本人因年龄而可获援助时；因为其年满二十五岁后，将取得法定期限。继受人似乎是因自身受欺诈：虽然其本可在依被继承人身份确定的法定期限内请求恢复原状，却没有提出请求。当然，如果被继承人依可用期间计算的一年期限内只剩下很短的时间，那么该继承人年满二十五岁后请求恢复原状时，不应给予其全部法定期限，而只给予被继承人原先尚有的期限。

### <a id="4.4.20"></a>4.4.20　乌尔比安《评告示》第十一卷

<a id="4.4.20.pr."></a>

**序言（pr.）** 帕皮尼安在《答复集》第二卷中说，流放者返回后，不应仅因其曾经缺席而延长恢复原状的法定期限；因为他本可委托代理人向裁判官提出请求，或者在其所在之地向行省长官提出请求，却没有这样做。但帕皮尼安又说，此人因受刑罚而不值得宽宥，这一点并不妥当：犯罪与基于年龄给予的宽宥有什么关系呢？

<a id="4.4.20.1"></a>

**1.** 不过，如果某人年满二十五岁，在法定恢复原状期限内已经使诉讼正式受理，之后却又撤诉，那么诉讼正式受理对其请求恢复原状并无帮助；敕答已屡次确认这一点。

### <a id="4.4.21"></a>4.4.21　乌尔比安《评告示》第十卷

所谓撤诉，指的是放弃整个诉讼，而非仅仅延迟诉讼。

### <a id="4.4.22"></a>4.4.22　乌尔比安《评告示》第十一卷

未成年人请求针对其接受遗产恢复原状时，不必返还已经为遗赠支出的款项，也不必返还因其接受遗产而获得自由者的价额。反之，未成年人获准恢复原状、重新接受遗产时，先前依法律形式、由裁判官以命令指定的遗产管理人所实施的处分——为出售遗产财物而采取的行为——仍应视为有效；塞维鲁斯皇帝和安敦尼努斯皇帝曾向卡尔普尔尼乌斯·弗拉库斯作出敕答确认此点。

### <a id="4.4.23"></a>4.4.23　保罗《评告示》第十一卷

家子依父亲的委托管理事务时，不享有恢复原状的利益。即使是他人委托其办理事务，也不应给予救济，因为这样做实际上会使应承担损失的成年人获益。但如果未成年人因偶然情形将要遭受损失，例如其为所管理事务垫付的款项无法向本人追回，因为该本人无清偿能力，裁判官毫无疑问应予介入。若本人是未成年人、代理人则已成年，除非代理人系依本人委托行事且无法为其保全财产，否则不应轻易受理本人的请求。因此，如果未成年人以代理人身份受了欺诈，应将此归责于委托该代理人处理事务的本人；马尔切鲁斯也赞同这一点。

### <a id="4.4.24"></a>4.4.24　保罗《判例》第一卷

<a id="4.4.24.pr."></a>

**序言（pr.）** 如果未成年人自愿介入成年人的事务，应准许其恢复原状，以免成年人遭受损失。但如果未成年人拒绝这样做，之后又因无因管理之诉被起诉，则不得准许他针对该诉恢复原状；不过，应迫使他将恢复原状救济转让给成年人，使其为自身利益指定成年人为代理人，从而能够以这种方式弥补因未成年人而遭受的损失。

<a id="4.4.24.1"></a>

**1.** 与未成年人实施的行为并非一概应予撤销，而应使处理结果符合善与公平的要求，以免人们因担心与未成年人订约会遭受重大不便而无人愿意与其交易，从而在某种程度上将其排除于商业往来之外。因此，除非存在明显欺诈，或未成年人在该事项上行事极为疏忽，否则裁判官不应介入。

<a id="4.4.24.2"></a>

**2.** 我们的斯凯沃拉曾说，如果某人受年轻轻率影响而遗漏或拒绝遗产或遗产占有，而一切仍未改变，就应当无论如何受理其请求；但如果遗产已被出售、事务已处理完毕，而替代继承人经过辛劳后已准备好取得款项，此人此时才出现，就应将其驳回。基于这一事由，也更不应轻易准许未成年人的继承人恢复原状。

<a id="4.4.24.3"></a>

**3.** 如果奴隶或家子欺骗了未成年人，应命令家父或主人返还其所取得的利益；对其未取得的部分，则应从该奴隶或家子的特有产中赔偿。如果两者均不足以清偿，且奴隶存在欺诈行为，就应以鞭打惩罚奴隶，或将其交付受害人作诺克萨责任的替代承担。若实施欺诈的是家子，也应因其自身的欺诈而判令其承担责任。

<a id="4.4.24.4"></a>

**4.** 恢复原状应使每个人都取回其完整的权利。因此，未成年人在出售土地时受了欺诈并获准恢复原状，裁判官应命令买受人返还土地及孳息，并取回价款；但如果买受人交付价款时明知未成年人会将钱款耗尽，则不在此限。对于明知未成年人将耗尽钱款而向其放款，也适用同样做法；但买卖中的处理应更为谨慎，因为债务人清偿的是其本来必须偿还的债务，而放款则并非必须。即使契约的起因应予撤销，只要支付价款确属必要，也不应在所有情况下都让买受人承受损失。

<a id="4.4.24.5"></a>

**5.** 本告示并不产生独立的诉权或担保；这一切完全取决于裁判官对案情的审查。

### <a id="4.4.25"></a>4.4.25　盖尤斯《评行省告示》第四卷

<a id="4.4.25.pr."></a>

**序言（pr.）** 毫无疑问，如果未成年人基于民法不允许返还的事由支付了本不应支付之物，就应给予其准诉权，以请求返还；因为有正当理由时，成年人也通常可以请求返还。

<a id="4.4.25.1"></a>

**1.** 如果需要给予恢复原状救济的未成年人参与某项事务，应依其本人请求向其本人提供救济，或向获得特别授权、明确受托办理此事的代理人提供救济。仅提出一般性的处理全部事务授权者，不应予以受理。
