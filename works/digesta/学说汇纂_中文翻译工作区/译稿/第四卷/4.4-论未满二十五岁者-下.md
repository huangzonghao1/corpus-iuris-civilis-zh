### <a id="4.4.26"></a>4.4.26　保罗《评告示》第十一卷

<a id="4.4.26.pr."></a>

**序言（pr.）** 如果在请求恢复原状时，对代理人是否取得特别授权存有疑问，可以通过加入一项要式承诺来补救：由代理人承诺委托人将追认该事项。

<a id="4.4.26.1"></a>

**1.** 如果被指称利用了未成年人之人不在场，其诉讼代理人应提供判决履行担保（*satisdatio iudicatum solvi*）。

### <a id="4.4.27"></a>4.4.27　盖尤斯《评行省告示》第四卷

<a id="4.4.27.pr."></a>

**序言（pr.）** 父亲无论如何都应当为其子请求恢复原状，即使儿子不愿请求恢复原状亦然，因为父亲须承担风险；他对特有产债务负有责任。由此可见，其他亲属或姻亲的处境不同：除非他们是依青年本人的意愿提出请求，或者该青年的生活方式败坏到有理由禁止其管理财产，否则不应听取其请求。

<a id="4.4.27.1"></a>

**1.** 如果未成年人挥霍了自己借入的款项，总督应拒绝债权人对其提起诉讼。如果未成年人将钱借给了一个急需用钱的人，则不应再采取其他措施，只须命令该青年将其针对自己所借款项之债务人的诉权让与自己的债权人。如果未成年人用这笔钱以高于应有价格购买了地产，应当作如下调处：命令出卖人退还价款并收回地产，使债权人也能从该青年处收回自己的款项，而不使另一方遭受损失。由此也可知，如果青年用自己的钱以高于应有价格购买地产，应遵循何种规则。无论是此种情形还是前述情形，出卖人在退还价款后，还应返还其从该笔钱款中已收取或本可收取的利息，并取回那些使该青年得以增加财富的孳息。反过来说，如果青年以低于应有价格出售地产，应命令买受人连同孳息返还地产；而青年只须返还其因该笔价款而实际获益的部分。

<a id="4.4.27.2"></a>

**2.** 如果未满二十五岁者无正当理由使债务人获得正式免债，不仅应恢复对该债务人的诉权，也应恢复对保证人的诉权及针对质物的权利。如果有两名共同债务人，而他使其中一人获得正式免债，也应恢复对两人的诉权。

<a id="4.4.27.3"></a>

**3.** 由此可知，如果未成年人作出了对自己不利的债务更新，例如为更新债务而将债务关系从有清偿能力的债务人转给无清偿能力的债务人，就应使其恢复针对原债务人的诉权。

<a id="4.4.27.4"></a>

**4.** 对于那些不得以欺诈为由起诉之人，也应准许恢复原状；但特别法律明确排除的某些人除外。

### <a id="4.4.28"></a>4.4.28　塞尔苏斯《学说汇纂》第二卷

未满二十五岁者针对与其进行监护诉讼之人获准恢复原状，并不因此就应恢复监护人针对其提起的反向监护诉讼。

### <a id="4.4.29"></a>4.4.29　莫德斯蒂努斯《答复集》第二卷

<a id="4.4.29.pr."></a>

**序言（pr.）** 即使能够证明受监护人是在父亲及同一监护人担任授权人时受骗，也不妨碍后来为其指定的保佐人以受监护人本人名义请求恢复原状。

<a id="4.4.29.1"></a>

**1.** 一名女受监护人因保佐事务被判决后，想针对判决中的某一项请求恢复原状〔底本作 *adversus num caput sententiae*，此处疑有缺字〕；由于她似乎已在诉讼的其他事项上获得救济，一名当时已成年的原告、即当时接受该判决之人，主张应当重新审理整个案件。赫雷尼乌斯·莫德斯蒂努斯答复说：如果该女受监护人请求恢复原状所涉及的事项与其他事项并无关联，就没有理由听从原告要求撤销整项判决的请求。

<a id="4.4.29.2"></a>

**2.** 某人因年龄利益而就其父亲的遗产获准恢复原状，并在没有任何父亲的债权人在场、也没有被总督传唤到庭主张权利的情况下，拒绝承受遗产。有人询问，此项恢复原状是否妥当。赫雷尼乌斯·莫德斯蒂努斯答复说：既然所述情形是未传唤债权人便作出了恢复原状裁定，该裁定绝不因此对债权人产生不利影响。

### <a id="4.4.30"></a>4.4.30　帕皮尼安《问题集》第三卷

已解放的家子没有接受对抗遗嘱的遗产占有（*bonorum possessio contra tabulas*）；在恢复原状问题的审理已经开始后，他年满二十五岁，并请求取得父亲遗嘱所留遗赠。他应被视为放弃了该项诉讼，因为即使准予延长请求遗产占有的期限，他既已选择依死者遗嘱主张权利，也会被认为拒绝了裁判官所提供的救济。

### <a id="4.4.31"></a>4.4.31　帕皮尼安《答复集》第九卷

一名妇女在成为继承人后，因年龄而获准恢复原状，以便拒绝承受遗产。她依遗嘱信托正确地解放了遗产中的奴隶，这些奴隶应保有自由；他们不应被迫为维持自由而支付二十奥里，因为他们显然已依法取得自由。又如，若部分债权人在恢复原状前已从她处收回自己的款项，其他债权人不得以已收款者应与他们分配钱款为由向其提出请求。

### <a id="4.4.32"></a>4.4.32　保罗《问题集》第一卷

一名未满二十五岁者向总督申请后，凭其身体外观虚假证明自己已达到完全行为年龄。保佐人得知他仍未成年后，继续履行保佐职责。在证明其达到成年年龄之后、但其尚未满二十五岁之前，欠他的款项已支付给这名青年；他又不当挥霍了这些钱。我询问，应由谁承担风险？又如果保佐人也一直陷于同一错误，以为他已成年，因而停止管理，甚至交还了保佐事务，那么在其被认定成年后、二十五岁生日之前这段期间所发生的风险，是否应由保佐人承担？答复如下：已经清偿债务的人依法当然免责，不应再次被诉。显然，明知他仍未成年却继续履行职务的保佐人，不应任由他收取到期债款，并应因此承担诉讼责任。但如果保佐人也相信了总督的裁定，停止管理，或甚至已经交代账目，他们便与其他债务人相同，因此不应被诉。

### <a id="4.4.33"></a>4.4.33　瓦伦斯《遗嘱信托论》第六卷

尤利安答复说：如果未满二十五岁者受托解放自己的奴隶，而该奴隶的价值超过遗嘱留给他的遗赠，且他已经接受遗赠，那么只要他愿意返还遗赠，就不应强迫他给予该奴隶自由。正如成年人可以不接受遗赠，以免解放奴隶；同样，未成年人既愿意返还遗赠，就应免除其解放奴隶的义务。

### <a id="4.4.34"></a>4.4.34　保罗《判例集》第一卷

<a id="4.4.34.pr."></a>

**序言（pr.）** 未满二十五岁者向未成年家子出借款项时，应优先考虑耗用该款之人的利益；但如果在争讼程序确定时证明受款人仍因该款而受益，则不在此限。

<a id="4.4.34.1"></a>

**1.** 未成年人若已同意将争议交由裁判人裁断，并在监护人授权下订立了要式承诺，就该项义务请求恢复原状，依法有据。

### <a id="4.4.35"></a>4.4.35　赫莫杰尼安《法学摘要》第一卷

如果未成年人在为自己保留的买受机会中，被他人加价超过而未能购得标的，只要证明该物原本由自己买得对其有利，例如该物曾属于其祖先，就应听取其恢复原状请求；但他本人应将加价所得的增额交给出卖人。

### <a id="4.4.36"></a>4.4.36　保罗《判例集》第五卷

未满二十五岁者可以借助恢复原状救济，重新提出自己先前遗漏的主张。

### <a id="4.4.37"></a>4.4.37　特里丰尼努斯《论辩集》第三卷

<a id="4.4.37.pr."></a>

**序言（pr.）** 恢复原状救济并非为执行刑罚而设。因此，已经放弃的侮辱之诉不得重新提起。

<a id="4.4.37.1"></a>

**1.** 同样，丈夫依据其丈夫身份，可以在六十日内不受诬告之诉追究地控告妻子通奸；若该期限已经经过，则不准其恢复原状。若他现在想重新提出已放弃的指控，他所请求的除了对其不法行为给予宽宥——也就是请求宽免诬告责任——还能是什么？法律明确规定，裁判官不应援助不法行为或诬告者，因此不得恢复原状。对于不法行为，未满二十五岁者也不应获准恢复原状，尤其是在较严重的不法行为中；但有时，基于年龄的怜悯可以使法官减轻刑罚。现在转而考察惩治通奸的《尤利娅法》规定：如果未成年人承认自己犯有通奸罪，当然不得请求宽免通奸刑罚。我还要说，即使其实施了该法以通奸论处的其他行为，也不得宽免；例如，明知妻子已被判通奸罪仍与其结婚；或妻子被当场发现通奸却不与其离婚；或以妻子通奸牟利；或收取已查明的奸淫行为的报酬；或提供房屋供他人在其中奸淫或通奸。对于一面援引法律、一面违反法律命令之人，不得以年龄作为违反法律规定的抗辩。

### <a id="4.4.38"></a>4.4.38　保罗《裁决集》第一卷

<a id="4.4.38.pr."></a>

**序言（pr.）** 埃米利乌斯·拉里亚努斯依据解除条款向奥维尼乌斯购买了鲁提利亚地产，并支付了部分价款。约定：若自买卖之日起两个月内未支付其余价款的一半，买卖即视为未成立；再过两个月仍未支付余款的，亦同样视为买卖未成立。在最初两个月尚未届满时，拉里亚努斯死亡；未成年的鲁提利亚娜继承了他的地位，而她的监护人未能支付价款。出卖人多次通知监护人后，于一年后将同一地产出售给克劳狄乌斯·特勒马库斯。女受监护人请求恢复原状；她在裁判官和罗马城市长官处均败诉后提起上诉。我原以为判决妥当，因为订立契约的是她父亲，而非她本人。然而，皇帝对此案动了恻隐之心，因为解除买卖的期限落在女受监护人未成年期间，而且这一情况导致买卖条款未获履行。我曾说，更适宜基于下述理由准许她恢复原状：出卖人是在约定买卖解除之日过后才发出通知并请求支付价款，似乎已经放弃了自己所约定的解除条款。对我而言，解除期限后来届满并不构成阻碍；这与债权人在债务人死亡、清偿期限届满后出售质物的情形并无不同。由于皇帝不赞成解除买卖条款，遂宣告应准许恢复原状。还有一点也打动了皇帝：先前那些未曾请求恢复原状的监护人，已被认定为可疑监护人。

<a id="4.4.38.1"></a>

**1.** 所谓家子在解放后，仍不应就其处于家父权下时所遗漏之事请求救济，这一说法通常是正确的；但前提是，当时家子可以为其父取得权利。

### <a id="4.4.39"></a>4.4.39　斯凯沃拉《学说汇纂》第二卷

<a id="4.4.39.pr."></a>

**序言（pr.）** 未成年人在可用期间内向总督请求恢复原状，并证明了自己的年龄。总督作出有利于其年龄主张的裁定后，对方当事人为阻止总督继续审理而向皇帝上诉；总督遂将其余审理事项延期，等待上诉结果。有人询问：如果皇帝审结上诉并认定该上诉不当，而未成年人此时已超过相关年龄，他们能否继续完成其余程序，毕竟案件未能及时终结并非他们所致？我答复说：依照所述情形，应当按他们此刻仍处于未成年年龄范围内的情形进行审理。〔底文在 *essententiarum* 处讹误或中断；其后的文字无法确定。〕

<a id="4.4.39.1"></a>

**1.** 保佐人出售了一名未成年人的地产，卢基乌斯·提图斯买得该地产，持有约六年，并大幅改善了地产。我询问：既然保佐人适格，未成年人能否请求针对买受人提图斯恢复原状？我答复说：根据所述全部情形，几乎不应准许恢复原状；除非未成年人愿意向买受人偿付其证明自己善意支出的全部费用。尤其是，未成年人已经有适格保佐人，可以及时获得充分救济。

### <a id="4.4.40"></a>4.4.40　乌尔比安《意见集》第五卷

<a id="4.4.40.pr."></a>

**序言（pr.）** 一名未满二十五岁者获判应向其支付遗嘱信托利益后，出具了自己已收讫该款的凭证；债务人又向他作出债务凭证，仿佛这笔钱是借给他的。他可以请求恢复原状，因为他通过订立一项新契约，将自己依据判决取得的请求权变成了另一项请求权的起点。

<a id="4.4.40.1"></a>

**1.** 一名未满二十五岁者轻率地将其父亲的地产交付抵债，以清偿其父亲曾管理他人监护事务的账目所生债务。应通过恢复原状使事情回归公平状态；应计算经证明因监护关系而欠付的款项利息，并与已收取孳息的数额相抵。

### <a id="4.4.41"></a>4.4.41　尤利安《学说汇纂》第四十五卷

如果法官命令将一处地产返还给买卖中受欺诈的青年，并命其向买受人返还价款，而青年后来反悔、不愿利用这项恢复原状救济，那么，在买受人以判决为由请求价款时，青年可以援用有用抗辩。因为每个人都有权拒绝利用为自己设立的救济。即使裁判官使出卖人回到其自己造成的状态（而未成年人若未请求裁判官援助，出卖人本来也无法改变该状态），出卖人也不得因此抱怨。

### <a id="4.4.42"></a>4.4.42　乌尔比安《总督职务论》第二卷

行省长官即使面对其本人或前任作出的判决，也可以使未成年人恢复原状。成年人通过提起上诉所能获得的救济，未成年人则可依据年龄利益取得。

### <a id="4.4.43"></a>4.4.43　马尔切鲁斯《行省长官职务论》第一卷

对于自称已满二十五岁之人的年龄，应在审查案情后予以证明；因为这一证明会对同一青年请求恢复原状以及其他事项产生预断效力。

### <a id="4.4.44"></a>4.4.44　乌尔比安《意见集》第五卷

未满二十五岁者所为并非全部无效；只有在审查案情后查明存在下列情形之一，才可请求恢复原状：他们受他人欺诈，或因自身轻信而受骗；他们失去了原有财物；他们放弃了本可取得的利益；或者使自己承担了本不应承担的负担。

### <a id="4.4.45"></a>4.4.45　卡利斯特拉图斯《告示警示篇》第一卷

<a id="4.4.45.pr."></a>

**序言（pr.）** 拉贝奥写道，即使某人的财物在其出生前已被他人经时效取得而丧失，也应恢复其诉权。〔底文作 *prius quam "priusquam" nasceretur*，重复的 *priusquam* 及其标点性质不明，译文据上下文暂作通读。〕

<a id="4.4.45.1"></a>

**1.** 神圣提图斯·安东尼努斯皇帝曾作出敕答：如果有人称其对方当事人因监护人的欺诈而获判免责，并希望重新对其提起诉讼，他有权先起诉该监护人。

### <a id="4.4.46"></a>4.4.46　保罗《答复集》第二卷

自愿在诉讼中为未成年人辩护而被判决承担责任的人，可以依据该判决被诉；其所辩护之人的年龄不能使他获得恢复原状，因为他不得拒绝承认该判决的原因。因此可见，判决所针对的本人也不能仅因该判决而请求恢复原状救济。

### <a id="4.4.47"></a>4.4.47　斯凯沃拉《答复集》第一卷

<a id="4.4.47.pr."></a>

**序言（pr.）** 债权人催促之下，监护人善意出售了受监护人的财物；不过，母亲曾通知买受人。我询问：既然财物是因债权人催促而出售，且无正当理由可指责监护人行为不端，受监护人能否请求恢复原状？答复说：应查明案情后评断；即便恢复原状确属妥当，也不应仅因监护人没有过错而拒绝此项救济。

<a id="4.4.47.1"></a>

**1.** 一名青年人的保佐人出售了其本人及由其管理的青年人共同拥有的地产。我询问：如果青年人依裁判官的裁定获准恢复原状，是否仅在地产属于青年人共有份额的范围内撤销买卖？答复说：原则上仅在该份额范围内撤销；但如果买受人愿意解除整个契约，也可以解除，因为他原本不会只买其中一部分。我又询问：买受人应向受监护人塞尤斯和塞姆普罗尼乌斯索回价款及利息，还是应向保佐人的继承人索回？答复说：保佐人的继承人确实负有责任；但就属于塞尤斯和塞姆普罗尼乌斯的份额，应对他们分别给予诉权，前提是价款中相应份额确已由他们取得。

### <a id="4.4.48"></a>4.4.48　保罗《判例集》第一卷

<a id="4.4.48.pr."></a>

**序言（pr.）** 未成年人就其所提供的保证或所作的委任请求恢复原状，并不使主债务人免责。

<a id="4.4.48.1"></a>

**1.** 未成年人出售了一名女奴；如果买受人已将她解放，就不得仅因此请求恢复原状，但可以针对买受人提起诉讼，请求相当于其利益损失的赔偿。

<a id="4.4.48.2"></a>

**2.** 未满二十五岁的妇女若因嫁资协议使自身处境恶化，而且订立了一项成年后绝不会订立的协议，现又希望撤销该协议，应当听取她的请求。

### <a id="4.4.49"></a>4.4.49　乌尔比安《评告示》第三十五卷

如果受监护人或青年人的财物被出售，而法律并未禁止出售该物，则买卖有效；但是，如果受监护人或青年人遭受重大损失，即使没有串通，仍应通过恢复原状撤销该项出售。

### <a id="4.4.50"></a>4.4.50　庞波尼乌斯《书信集及异文集》第九卷

尤尼乌斯·狄俄梵图斯致其友庞波尼乌斯，问安。一名未满二十五岁者为一名受短期诉权拘束之人介入债务关系，意在更新债务；当时该诉权尚余十日有效期。此后，这名未成年人获准恢复原状。现在的问题是：恢复原状后债权人得以针对原债务人行使的诉权，有效期究竟只有十日，还是应当更长？我所了解到的是：恢复原状时应给予与原来剩余期间相同的时间。请你回信告知对此事的看法。庞波尼乌斯答复说：毫无疑问，我认为你对未成年人介入之短期诉权所作的判断较为正确；因此，原债务人所提供的质物仍继续负担担保责任。
