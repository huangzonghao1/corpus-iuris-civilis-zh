## <a id="4.6"></a>4.6　论年满二十五岁者得请求恢复原状的事由

### <a id="4.6.1"></a>4.6.1　乌尔比安《评告示》第十二卷

<a id="4.6.1.pr."></a>

**序言（pr.）** 无人会否认本告示的根据极为正当：对于某人在为公共事务效力期间或遭遇不幸时权利所受的损害，本告示予以矫正；并且也向其相对方提供救济，使已经发生的情形既不致损害该人，也不使其对方获利。

<a id="4.6.1.1"></a>

**1.** 告示的文字如下：“如果某人因受胁迫而缺席，或因公务缺席且并无欺诈，或处于镣铐拘束、奴隶身份或敌人权力之下，其财产中有任何部分受到损害；或者据称其某项诉讼的期限已经届满；又或者有人通过取得时效取得某物，或取回了其因未使用而丧失的物；或者某人因诉讼期限届满而免于诉讼，而其缺席时无人为其辩护，或其处于镣铐拘束之中；或者其本人不使他人得以对其起诉；或者法律不许强迫其到庭、且无人为其辩护；或者就该事项向官员提出了上诉；又或者据称某人在其本人无欺诈的情况下，因官员〔原文此处并列作 *pro magistratu* 与“*per magistratus*”，文字关系待核〕而丧失诉权：我将在首次有权就该事项提起诉讼之年内，对上述事项准许恢复原状；如果我认为另有正当事由，也将在法律、平民会议决议、元老院决议、告示及皇帝敕令所允许的范围内准许恢复原状。”

### <a id="4.6.2"></a>4.6.2　卡利斯特拉图斯《告示释义》第二卷

<a id="4.6.2.pr."></a>

**序言（pr.）** 本告示涉及其中所列人员的部分，如今较少适用；因为依据元老院决议和皇帝敕令，这类人员通常通过非常程序获得司法救济。

<a id="4.6.2.1"></a>

**1.** 首先，本章救济适用于因受胁迫而缺席者；但前提是他们并非因无谓的恐惧而受到惊吓、以致缺席。〔原文疑误：本段末作“afuissetentiarum”，疑为“afuisset”与“entiarum”粘连；粘连部分不译，待核。〕

### <a id="4.6.3"></a>4.6.3　乌尔比安《评告示》第十二卷

所谓因受胁迫而缺席，是指某人因有正当理由担心死亡或身体遭受酷刑，受到惊吓而离开；应根据其实际感受判断这一点。但仅仅因受到某种恐吓而害怕，并不足够；此事应由法官查明。

### <a id="4.6.4"></a>4.6.4　卡利斯特拉图斯《告示释义》第二卷

同样，因公务而缺席且无欺诈者，也属于救济对象。关于“欺诈”一语，我认为其意在排除这样的人：其本可返回却不返回，因此对其缺席期间针对他所实施的行为，不应给予救济。例如，有人为了攫取他人的重大利益，故意使自己以公务为由缺席，就应被排除于该项特权之外。〔原文疑误：底本作“afuissetentiarum dolum malum”，其中“afuissetentiarum”疑为粘连；本译仅据可辨部分处理，粘连部分不译。〕

### <a id="4.6.5"></a>4.6.5　乌尔比安《评告示》第十二卷

<a id="4.6.5.pr."></a>

**序言（pr.）** 即使某人是有意为之且并未因此获利，也包括在内；过早出发者亦然；因诉讼而开始以公务为由缺席者也同样如此。但“无欺诈”这一限定，针对的是因公务而缺席者，并不针对因受胁迫而缺席者，因为只要有欺诈介入，就不存在胁迫。

<a id="4.6.5.1"></a>

**1.** 但在罗马为公共事务效力的人，不属于因公务而缺席者。

### <a id="4.6.6"></a>4.6.6　保罗《评告示》第十二卷

例如，各类官员即属此列。

### <a id="4.6.7"></a>4.6.7　乌尔比安《评告示》第十二卷

不过，在罗马服役的军人，应视为因公务而缺席者。

### <a id="4.6.8"></a>4.6.8　保罗《提要》第三卷

依马尔库斯皇帝和康茂德皇帝的敕令，市镇派出的使节也获得救济。

### <a id="4.6.9"></a>4.6.9　卡利斯特拉图斯《告示释义》第二卷

亦救济曾处于镣铐拘束中的人。这不仅适用于受公共羁押者，也适用于遭盗匪、海盗或更强暴力压制而被镣铐拘束者。“镣铐”一语应作较广义理解：被囚禁在采石场监狱之类场所的人，也被认为属于受拘束者，因为受墙壁拘禁还是受脚镣约束，并无区别。不过，拉贝奥认为，“羁押”仅指公共羁押。

### <a id="4.6.10"></a>4.6.10　乌尔比安《评告示》第十二卷

同样处于这一情形的，还有被军人、驻勤人员或市镇机关人员扣留者，前提是他们能够证明自己当时无法处理自己的事务。我们所说的“镣铐拘束”，也包括虽被捆绑、但若在公共场所露面便会蒙受耻辱的人。

### <a id="4.6.11"></a>4.6.11　卡利斯特拉图斯《告示释义》第二卷

也救济曾处于奴隶身份的人，无论是自由人善意地作为奴隶服役，还是遭人扣留。

### <a id="4.6.12"></a>4.6.12　乌尔比安《评告示》第十二卷

对于正在就自身身份提起诉讼的人，自该诉讼开始之时起，本告示即不适用。因此，在此类诉讼尚未开始期间，此人仍被视为处于奴隶身份。

### <a id="4.6.13"></a>4.6.13　保罗《评告示》第十二卷

<a id="4.6.13.pr."></a>

**序言（pr.）** 拉贝奥正确指出，被指定为继承人的自由人，在其取得继承人身份之前，不属于本告示所称之人，因为他尚无财产，而法务裁判官所说的是自由人。

<a id="4.6.13.1"></a>

**1.** 不过，我认为，拥有军旅特有财产的家子也属于本告示的适用范围。

### <a id="4.6.14"></a>4.6.14　卡利斯特拉图斯《告示释义》第二卷

同样，也救济曾处于敌人权力之下的人，也就是被敌人俘获者。对于叛逃者，不应认为给予任何此类恩惠；他们已被否认复归权。不过，处于敌人权力之下的人仍可被本告示关于曾处于奴隶身份者的条款所涵盖。

### <a id="4.6.15"></a>4.6.15　乌尔比安《评告示》第十二卷

<a id="4.6.15.pr."></a>

**序言（pr.）** 被敌人俘获后依复归权返回者，以及在敌境中死亡者，均应获得救济，因为他们无法委任诉讼代理人。前文列举的其他人则可以通过诉讼代理人获得救济，但被扣留为奴隶者除外。我还认为，如果为被敌人俘获者的财产指定了管理人——这种情形颇为常见——也可以为该人利益请求救济。

<a id="4.6.15.1"></a>

**1.** 被敌人俘获者所获救济，不亚于出生在敌境、但享有复归权的人所获救济。

<a id="4.6.15.2"></a>

**2.** 如果有人因损害尚未发生的风险而被准许进入一名军人的房屋占有：若法务裁判官是在该军人在场时命令占有该房屋，则不予恢复原状；若该军人当时不在场，则应当给予救济。

<a id="4.6.15.3"></a>

**3.** 但法务裁判官仅笼统规定的“及其后”，应作如下理解：如果善意占有人的占有在当事人缺席前已经开始，而在其返回后才告完成，只有在其返回后不久即发生这种情形时，才可给予恢复原状的救济；并非无论何时都可以。这里所说的短暂期间，是指当事人正在安排住处、整理行装、寻找诉讼代理人之时。涅拉提乌斯记载，拖延请求恢复原状的人，不应获准提出该请求。

### <a id="4.6.16"></a>4.6.16　保罗《评告示》第十二卷

救济并非给予疏忽者，而是给予因客观情势所迫、受到阻碍者。所有这些均由法务裁判官酌情裁量：只有在当事人未因疏忽，而是因时间紧迫以致无法完成诉讼争点确定程序（*litis contestatio*）时，才准许恢复原状。

### <a id="4.6.17"></a>4.6.17　乌尔比安《评告示》第十二卷

<a id="4.6.17.pr."></a>

**序言（pr.）** 尤利安在《学说汇纂》第四卷中写道，应当救济军人，使其不仅可以向遗产占有人主张权利，也可以向从该占有人处购买遗产的人主张权利，从而得以请求返还遗产中的物；但以该军人已经承认并接受遗产为限。若其未承认并接受遗产，则可见此后已经发生取得时效完成的结果。

<a id="4.6.17.1"></a>

**1.** 如果遗嘱以如下方式为某人设立遗赠：“在他身处意大利的各年中，每年……”那么，应当恢复其原状，使其能够受领遗赠，视同其一直身处意大利。拉贝奥如此记载，尤利安《学说汇纂》第四卷及庞波尼乌斯《学说汇纂》第三十一卷亦赞同此说。此处并非在法务裁判官的救济本属必要时，诉权期间届满；问题在于遗赠受领条件是否成就。

### <a id="4.6.18"></a>4.6.18　保罗《评告示》第十二卷

应当知道，在这些情形中，我们给予年满二十五岁者恢复原状的救济，是为了追索物本身；如果他们所求的是利用他人的惩罚或损害获利，则不应给予此项救济。

### <a id="4.6.19"></a>4.6.19　帕比尼安《疑问集》第三卷

因此，如果买受人在通过取得时效取得该物之前被敌人俘获，则不认为其因复归权而恢复中断的占有；因为没有占有，取得时效便无从成立，而占有在很大程度上属于事实问题。复归权并不涵盖这种事实状态。

### <a id="4.6.20"></a>4.6.20　帕比尼安《疑问集》第十三卷

不应因此授予他准诉权，因为若从所有人处夺走连取得时效都未能使其丧失之物，极不公正；并且，未曾从他人处夺走的物，也不能认为已经丧失。

### <a id="4.6.21"></a>4.6.21　乌尔比安《评告示》第十二卷

<a id="4.6.21.pr."></a>

**序言（pr.）** 法务裁判官又说：“此外，如果某人通过取得时效取得某物，或者取回了因未使用而丧失之物，或者因诉权期间届满而免于应诉，而在此期间其缺席且无人为其辩护。”法务裁判官加入这一条款，是为了像救济前述人员、避免他们受损一样，也救济其相对方，避免前述人员反而因而获利。

<a id="4.6.21.1"></a>

**1.** 应当注意，法务裁判官在规定针对前述人员恢复原状时，表述得比规定给予他们本人救济时更为宽泛：此处并未列举特定的受救济对象，而是以一项条款概括所有缺席且无人为其辩护的人。

<a id="4.6.21.2"></a>

**2.** 如果缺席且无人辩护的人本人，或者其权力下之人，通过取得时效取得了某物，均可适用这一恢复原状；但前提是他们中无人为其辩护。若已有诉讼代理人，则既然已有可以起诉之人，就不应再使其受到干扰。反之，若没有辩护人，给予救济最为公平；尤其是对于无人辩护者，若其藏匿，法务裁判官依告示允诺准许债权人进入其财产占有，必要时甚至变卖其财产；若其并未藏匿，即使无人为其辩护，也仅准许进入其财产占有。

<a id="4.6.21.3"></a>

**3.** 某人并非仅因有人主动自称辩护人，就被视为已获辩护；只有在原告询问后，该辩护人确实不会拒绝辩护，才属于此种情形。只有在其不拒绝应诉，并提供履行判决的担保时，才构成充分辩护。

### <a id="4.6.22"></a>4.6.22　保罗《评告示》第十二卷

<a id="4.6.22.pr."></a>

**序言（pr.）** 因此，应当知道，本告示只有在已经询问其朋友是否愿意为其辩护，或者根本没有可以询问之人时，才适用。如果原告主动提出应诉要求，却没有任何人表示愿意辩护，就不能认为缺席者已经获得辩护；这一事实应以正式声明记载。

<a id="4.6.22.1"></a>

**1.** 因此，法务裁判官既不愿使他们遭受损害，也不允许他们因此获利。

<a id="4.6.22.2"></a>

**2.** 拉贝奥说，这一告示也适用于精神失常者、未成年人和市镇共同体。

### <a id="4.6.23"></a>4.6.23　乌尔比安《评告示》第十二卷

<a id="4.6.23.pr."></a>

**序言（pr.）** 法务裁判官说：“或者其处于镣铐拘束之中，或者不使他人得以对其提起诉讼。”将此类人列入条款是适当的，因为可能有人虽身在现场，却被置于镣铐拘束之下，无论是受公共羁押还是受私人拘禁。事实上，只要尚未处于奴隶身份，处于镣铐拘束中的人也能够通过取得时效取得某物，这一点是确定的。但如果处于镣铐拘束中的人已经获得辩护，则不适用恢复原状。〔原文疑误：本段“nam eteum”疑为“nam et eum”的词间粘连；此处依可辨句意翻译，待核。〕

<a id="4.6.23.1"></a>

**1.** 处于敌人控制下的人，既不能通过取得时效取得某物，也不能完成已经开始的占有；其身处敌境期间，情形皆是如此。此外，他即使依复归权返回，也不能恢复通过取得时效取得所有权的进程。

<a id="4.6.23.2"></a>

**2.** 帕比尼安说，如果某人因被俘而丧失土地的占有，或者丧失对用益权的准占有，也应给予其救济；并且，他认为，在此期间他人基于用益权所收取的孳息，也应返还给被俘者，此举合乎公平。

<a id="4.6.23.3"></a>

**3.** 当然，曾处于被俘者权力之下的人，可以就其特有财产中的物通过取得时效取得所有权。依本条款，对于仍在本地、即未被俘者，也应公平地给予救济：如果其未获辩护期间，有物被他人取得时效取得，即应如此。并且，如果针对被俘者的诉权期间届满，也应给予相对方救济，使其得以向被俘者主张权利。

<a id="4.6.23.4"></a>

**4.** 随后，法务裁判官补充说：“或者不使他人得以对其提起诉讼”，以便在其如此行事期间，如果取得时效已经完成，或发生前文所述任何一种情形，即准许恢复原状。这样规定是适当的，因为准许进入其财产占有并非总是足够；有时无法对藏匿者的财产准许进入占有，或者该人根本并未藏匿。举例说，当事人在请求法律协助期间诉权期间届满，或者因其他诉讼迟延而届满。〔原文含义未详：“in bonis latitantis mitti non possit aut non latitet”句后半与前半的逻辑关系不清；译文暂按两种情形并列处理，待核。〕
