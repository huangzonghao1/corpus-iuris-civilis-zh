### <a id="4.3"></a>4.3.0　论恶意欺诈（De dolo malo）

### <a id="4.3.1"></a>4.3.1　乌尔比安《评告示》第十一卷

<a id="4.3.1.pr."></a>

**序言（pr.）** 裁判官以本告示救济各种狡猾欺诈之人：这些人凭借某种诡计损害他人。如此便可避免他们因自己的恶意获利，也可避免他人因轻信而受损。

<a id="4.3.1.1"></a>

**1.** 告示的文字如下：“凡被称为因恶意欺诈而实施的行为，如对此等事项没有其他诉讼，且认为有正当理由，我将准许审判。”

<a id="4.3.1.2"></a>

**2.** 塞尔维乌斯将恶意欺诈界定为：为欺骗他人而采取某种计谋，表面上做一事，实际上却做另一事。拉贝奥则认为，即使没有伪装，也可以采取行动使某人遭受蒙骗；反过来，虽做一事而表面佯作另一事，也未必构成恶意欺诈，例如有人以此类掩饰维护自己或他人的利益。因此，拉贝奥本人将恶意欺诈界定为：为规避、欺骗或蒙骗他人而采用的一切狡黠、欺诈和计谋。拉贝奥的定义是正确的。

<a id="4.3.1.3"></a>

**3.** 裁判官没有只说“欺诈”，而是加上“恶意”二字，因为古人也称有“善意的欺诈”，并以此词指机敏，尤其是对敌人或强盗施用计谋时。

<a id="4.3.1.4"></a>

**4.** 裁判官说：“如果对此等事项没有其他诉讼。”裁判官仅在没有其他诉讼时才允诺此项诉讼，这是恰当的，因为如果当事人尚可通过民事诉讼或裁判官法诉讼起诉，就不应轻易准许这种可能导致名誉受损的诉讼。佩狄乌斯在《告示评注》第八卷中甚至写道，即使当事人可提起禁令之诉，或可援用抗辩保护自己，本告示也应停止适用。庞波尼乌斯在《学说汇纂》第二十八卷中也持此说，并补充：如果某人已由要式承诺获得保障，例如已就欺诈订立要式承诺，他便不得提起恶意欺诈之诉。

<a id="4.3.1.5"></a>

**5.** 庞波尼乌斯还说，即使不应准许对我们提起诉讼，例如某项要式承诺因恶意欺诈而如此卑劣，以致无人会依该承诺准许诉讼，也不必费力设法使我取得恶意欺诈之诉；毕竟无人会对我提起诉讼。

<a id="4.3.1.6"></a>

**6.** 庞波尼乌斯又记载，拉贝奥认为，即使某人可以获得恢复原状，也不应准许其提起本诉；如果其他诉讼因时效届满而终结，本诉也不应因此准许，因为当事人未及时起诉，责任应由其自负；但若有人也以恶意欺诈使期限届满，则属例外。

<a id="4.3.1.7"></a>

**7.** 某人原有民事诉讼或裁判官法诉讼，却将其转化为要式承诺，再以正式免债或其他方式消灭该诉讼的，不得提起恶意欺诈之诉，因为他原本有其他诉讼；但若其在丧失原诉讼时遭受了恶意欺诈，则属例外。

<a id="4.3.1.8"></a>

**8.** 不过，不仅在针对被请求承担恶意欺诈责任之人另有其他诉讼时，

### <a id="4.3.2"></a>4.3.2　保罗《评告示》第十一卷

或者该物可以由该人保全时，

### <a id="4.3.3"></a>4.3.3　乌尔比安《评告示》第十一卷

本告示不适用；而且，即使可以针对他人提起其他诉讼，

### <a id="4.3.4"></a>4.3.4　保罗《评告示》第十一卷

或者该物可以由他人为我保全时，也同样如此。

### <a id="4.3.5"></a>4.3.5　乌尔比安《评告示》第十一卷

因此，如果未成年人在其监护人配合串通的情况下受提提乌斯蒙骗，不应准许该未成年人对提提乌斯提起恶意欺诈之诉，因为他可以提起监护之诉，从而取得其所受损害的赔偿。不过，如果监护人无清偿能力，就应当说应准许其提起恶意欺诈之诉。

### <a id="4.3.6"></a>4.3.6　盖尤斯《评行省告示》第四卷

因为如果对方无清偿能力，以致诉讼落空，那么该人便可视为没有任何诉讼可用。

### <a id="4.3.7"></a>4.3.7　乌尔比安《评告示》第十一卷

<a id="4.3.7.pr."></a>

**序言（pr.）** 庞波尼乌斯巧妙地解释“如果没有其他诉讼”这几个字，认为其意是：相关人无法通过其他方式保全其利益。尤利安在《告示评注》第四卷所写的内容，似乎并不与此见解相悖：未满二十五岁者在奴隶的唆使下受骗，将该奴隶连同其特有产一并出卖，买受人又将其释放的，应准许对被释放者提起恶意欺诈之诉——对此可作如下理解：买受人并无欺诈，因而不能对其提起买卖之诉；或者，如果出卖人正是在决定出卖奴隶这一点上受骗，则买卖无效。这里提到未成年人，并不意味着可以恢复原状，因为不得对被释放者适用恢复原状。

<a id="4.3.7.1"></a>

**1.** 依此，如果可以通过惩罚性诉讼补偿其损失，就应当说恶意欺诈之诉不再适用。

<a id="4.3.7.2"></a>

**2.** 庞波尼乌斯还说，即使存在公益诉讼，恶意欺诈之诉也不再适用。

<a id="4.3.7.3"></a>

**3.** 不仅在没有其他诉讼时如此，即使是否存在其他诉讼尚有疑问，拉贝奥也认为应准许恶意欺诈之诉，并举例如下：某人因买卖或要式承诺而欠我一名奴隶，却给该奴隶服下毒药后才将其交付；或者某人欠我一块土地，交付时却在土地上设定役权、拆毁建筑物、砍伐或拔除树木。拉贝奥说，无论此人是否就欺诈作出担保，都应准许对其提起恶意欺诈之诉，因为若已作担保，是否可提起要式承诺之诉仍有疑问。不过，较妥当的意见是：如果已就欺诈作出担保，则因存在要式承诺之诉，恶意欺诈之诉不适用；如果未作担保，在买卖之诉的情形下，因存在买卖之诉，恶意欺诈之诉不适用；而在要式承诺之诉的情形下，则有必要准许恶意欺诈之诉。

<a id="4.3.7.4"></a>

**4.** 如果所有权人杀死一名由他人享有使用权的奴隶〔译疑：*servus usurarius* 指他人享有该奴隶的使用利益、但不享有所有权者；与用益权是否为同一制度待核〕，则《阿奎利亚法》之诉与出示之诉均可适用；如果所有权人在占有该奴隶时将其杀死，恶意欺诈之诉便不适用。

<a id="4.3.7.5"></a>

**5.** 又如，继承人在接受遗产之前杀死一名遗赠给他人的奴隶，由于该奴隶被杀时尚未成为受遗赠人的财产，因此不适用《阿奎利亚法》之诉；但无论继承人在何时杀死该奴隶，恶意欺诈之诉都不适用，因为受遗赠人可以提起遗嘱之诉。

<a id="4.3.7.6"></a>

**6.** 如果你的四足牲畜因他人的恶意欺诈而给我造成损害，可以追问我是否可以对该人提起恶意欺诈之诉。我赞同拉贝奥的意见：如果牲畜主人无清偿能力，就应准许恶意欺诈之诉；但如果已经发生诺克萨交付，我认为不得再准许此诉，即使损害超过交付所及亦然。

<a id="4.3.7.7"></a>

**7.** 拉贝奥还问：如果你解开我被镣铐锁住的奴隶，使其逃跑，是否应准许恶意欺诈之诉？昆图斯在拉贝奥的著作中作注说：如果你并非出于怜悯才如此行事，就应对你提起盗窃之诉；如果是出于怜悯，则应准许事实诉讼。

<a id="4.3.7.8"></a>

**8.** 奴隶为换取自由，在和解安排中将债务人交给主人，并约定在奴隶获释后将债务移转给自己〔译疑：本句各主体及债务移转安排压缩难明〕；但奴隶获释后，不允许将债务移转至自己名下。庞波尼乌斯写道，此时可提起恶意欺诈之诉。不过，如果债务未能移转是由于自由人保护人所致，他说应允许债务人援用抗辩，使自由人保护人不能起诉。我对此有所疑虑：既然存在其他诉讼，为何还准许恶意欺诈之诉？除非有人会说，由于债务人在自由人保护人起诉时可以援用抗辩将其排除，因此应视为并无可用的诉讼——既然该诉讼会被抗辩阻却——从而应裁定准许恶意欺诈之诉。然而，只有在自由人保护人不愿接受已获释的奴隶本人作为新债务承担人时，才会被排除。对新债务承担人而言，应当准许其对被释放者提起恶意欺诈之诉；或者，如果新债务承担人无清偿能力，则应准许主人提起该诉。

<a id="4.3.7.9"></a>

**9.** 如果代理人以恶意欺诈使我的对方当事人胜诉，从而使其获判无罪，可以追问我是否能对胜诉者提起恶意欺诈之诉。我认为，如果被告愿意在“曾有串通”的抗辩下移转诉讼，则不能提起该诉；否则，应准许恶意欺诈之诉，但须以不能对代理人起诉为前提，例如代理人无清偿能力。

<a id="4.3.7.10"></a>

**10.** 庞波尼乌斯还记载，凯基狄安努斯裁判官未准许对一名声称借款对象有偿付能力之人提起恶意欺诈之诉；这一做法是正确的，因为除非存在重大而明显的狡诈，不应准许恶意欺诈之诉。

### <a id="4.3.8"></a>4.3.8　盖尤斯《评行省告示》第四卷

但是，如果你明知此人财力日渐衰败，却为了自己的获利而向我声称他有偿付能力；既然你为了欺骗我而虚假称赞他，那么理应准许我对你提起恶意欺诈之诉。

### <a id="4.3.9"></a>4.3.9　乌尔比安《评告示》第十一卷

<a id="4.3.9.pr."></a>

**序言（pr.）** 如果有人声称遗产价值很小，并因此向继承人买下遗产，则不适用恶意欺诈之诉，因为买卖之诉已足以救济。

<a id="4.3.9.1"></a>

**1.** 但如果你劝我放弃遗产，谎称遗产资不抵债；或者劝我选择某一奴隶，谎称家中没有比他更好的奴隶，那么如果你是狡诈行事，我认为应准许恶意欺诈之诉。

<a id="4.3.9.2"></a>

**2.** 又如，为避免有人提起遗嘱违反义务之诉，遗嘱文书被长期隐匿，直到儿子死后才被出示，那么儿子的继承人可以依据《科尔内利亚法》以及恶意欺诈之诉，对隐匿文书之人提起诉讼。

<a id="4.3.9.3"></a>

**3.** 拉贝奥在《后论》第三十七卷中写道：如果提提乌斯主张你的橄榄油是他自己的，而你将油寄存于塞伊乌斯处，委托他出售并保管价款，直到你们之间判定该油归谁所有；提提乌斯却不愿接受诉讼，那么由于寄存条件尚未成就，你既不能对塞伊乌斯提起委任之诉，也不能提起保管争讼之诉，而应对提提乌斯提起恶意欺诈之诉。但庞波尼乌斯在《学说汇纂》第二十七卷中说，可以对保管人提起附特定事项说明的诉讼；或者，如果保管人无清偿能力，则可以对提提乌斯提起恶意欺诈之诉。这一区分似乎是正确的。

<a id="4.3.9.4"></a>

**4.** 又如，你通过法官将一名已被质押的奴隶交付给我作为诺克萨交付，而你因此获判免责；如果后来证实该奴隶曾被出质，你应承担恶意欺诈责任。

<a id="4.3.9.4a"></a>

**4a.** 此项恶意欺诈之诉属于诺克萨之诉。因此，拉贝奥在《外邦裁判官告示评注》第三十卷中也写道：以奴隶名义提起恶意欺诈之诉时，有时应以特有产为限，有时应作为诺克萨之诉提起。因为如果欺诈所涉及的事项原本适用特有产之诉，那么此处也应以特有产为限；如果原本适用诺克萨之诉，此处也应属于诺克萨之诉。

<a id="4.3.9.5"></a>

**5.** 裁判官恰当地规定应审查案件情况，因为不应随意准许此项诉讼。举例来说，首先，如果金额很小，

### <a id="4.3.10"></a>4.3.10　保罗《评告示》第十一卷

也就是不超过两个奥雷乌斯，

### <a id="4.3.11"></a>4.3.11　乌尔比安《评告示》第十一卷

<a id="4.3.11.pr."></a>

**序言（pr.）** 不应准许。

<a id="4.3.11.1"></a>

**1.** 对某些人也不应准许此诉，例如子女或被释自由人对其父母或自由人保护人提起此诉，因为该诉会使被告名誉受损。地位较低者对显贵者也不应提起此诉，例如平民对享有公认威望的前执政官提起此诉，或者放荡、挥霍或其他品行卑劣之人对生活品行较为端正者提起此诉。拉贝奥也持此见解。那么，应当如何处理？应当说，对这类人，应准许一种文字有所调整的事实诉讼，并提及善意，

### <a id="4.3.12"></a>4.3.12　保罗《评告示》第十一卷

以免其从自己的欺诈中获利。

### <a id="4.3.13"></a>4.3.13　乌尔比安《评告示》第十一卷

<a id="4.3.13.pr."></a>

**序言（pr.）** 不过，对于上述这些人的继承人，应当准许恶意欺诈之诉；此诉也可以针对继承人提起。

<a id="4.3.13.1"></a>

**1.** 拉贝奥说，是否准许对未成年人提起恶意欺诈之诉，也应根据案件情况审查；除非是以遗产继承关系为由起诉他。我认为，如果未成年人因自己的欺诈而被诉，且已接近成年，尤其是因此变得更为富有，也应对其提起诉讼。

### <a id="4.3.14"></a>4.3.14　保罗《评告示》第十一卷

例如，如果他设法使原告的代理人同意判他胜诉，或者谎称自己有监护人而取得钱财，或者实施其他类似行为——这些行为并不需要精心策划。

### <a id="4.3.15"></a>4.3.15　乌尔比安《评告示》第十一卷

<a id="4.3.15.pr."></a>

**序言（pr.）** 如果监护人因其欺诈而变得更为富有，我认为也应准许对监护人提起此诉，正如可以给予抗辩一样。

<a id="4.3.15.1"></a>

**1.** 是否可以对市镇共同体提起恶意欺诈之诉，尚有疑问。我认为，不能基于其自身的欺诈而准许此诉：市镇共同体本身能实施什么欺诈呢？不过，如果市镇共同体因其事务管理人的欺诈而取得某物，我认为应准许此诉。至于十人议事会成员的欺诈，则应对这些议事会成员本人提起恶意欺诈之诉。

<a id="4.3.15.2"></a>

**2.** 又如，如果因代理人的欺诈而有某物转归本人，就应以转归本人之利益为限，对本人准许恶意欺诈之诉；因为代理人无疑须对自己的欺诈负责。

<a id="4.3.15.3"></a>

**3.** 提起此项诉讼时，必须指明欺诈行为是谁实施的；而在胁迫之诉中则不必如此。

### <a id="4.3.16"></a>4.3.16　保罗《评告示》第十一卷

裁判官还要求诉状具体说明实施了何种恶意欺诈：原告必须知道自己在哪件事情上受了蒙骗，不能对如此严重的指控含糊其辞。

### <a id="4.3.17"></a>4.3.17　乌尔比安《评告示》第十一卷

<a id="4.3.17.pr."></a>

**序言（pr.）** 如果多人实施欺诈，而其中一人返还了财物，则所有人均免责；如果其中一人给付了该物的价值，我认为其余人也仍然免责。

<a id="4.3.17.1"></a>

**1.** 此项诉讼也可以对继承人及其他继受人提起，但仅限于转归他们的利益。

### <a id="4.3.18"></a>4.3.18　保罗《评告示》第十一卷

<a id="4.3.18.pr."></a>

**序言（pr.）** 在此项诉讼中，也可以由法官裁量命令恢复原状；若不恢复原状，随后便按该物的价值判处给付。恶意欺诈之诉和因胁迫而为之诉均未预先规定确定金额，是为了使被告在抗拒裁判时，可以按原告在诉讼中宣誓所报的金额判处给付；但在这两项诉讼中，法官均应依职权通过金额上限约束该项誓言。

<a id="4.3.18.1"></a>

**1.** 但并非在此诉讼中总是应交由法官裁量恢复原状。比如，如果显然无法恢复原状——例如因恶意欺诈而交付的奴隶已经死亡——那么是否应立即判令给付原告所关切的利益？

<a id="4.3.18.2"></a>

**2.** 如果所有权人烧毁了一栋房屋，而该房屋的用益权已被遗赠给他人，则不适用恶意欺诈之诉，因为由此会产生其他诉讼。

<a id="4.3.18.3"></a>

**3.** 关于明知而出借砝码、供卖方向买受人称量货物之人，特雷巴提乌斯准许提起恶意欺诈之诉。然而，如果他出借的是较重的砝码，则多交付的货物可以通过返还请求之诉追回；如果砝码较轻，则可以提起买卖之诉，请求交付其余货物。但若买卖约定按该等砝码交付货物，而该人出于欺骗目的声称砝码准确无误，则属例外〔译疑：该例外与前述替代诉讼的关系待核〕。

<a id="4.3.18.4"></a>

**4.** 如果某人的欺诈行为导致诉讼因法定期限届满而消灭，特雷巴提乌斯说，应准许恶意欺诈之诉；其目的不是由法官裁量恢复原状，而是使原告取得若非该欺诈本可获得的利益，以免行为人利用这种做法规避法律。

<a id="4.3.18.5"></a>

**5.** 如果他人杀死了你向我承诺交付的奴隶，多数学者正确地认为，应准许我对杀人者提起恶意欺诈之诉，因为你因此免除了对我的债务；因此，应否准你提起《阿奎利亚法》之诉。

### <a id="4.3.19"></a>4.3.19　帕皮尼安《疑问集》第三十七卷

如果保证人在迟延发生以前杀死了其所承诺交付的动物，涅拉提乌斯·普里斯库斯和尤利安答复说，应准许对保证人提起恶意欺诈之诉，因为主债务人免责后，保证人也随之免责。

### <a id="4.3.20"></a>4.3.20　保罗《评告示》第十一卷

<a id="4.3.20.pr."></a>

**序言（pr.）** 你的奴隶欠你钱，但无清偿能力；在你的劝说下，他向我借款并还给你。拉贝奥说，应准许我对你提起恶意欺诈之诉，因为不能提起特有产之诉——特有产中没有财物；也不能提起利益归入之诉，因为主人是以清偿债务为由收取款项。

<a id="4.3.20.1"></a>

**1.** 如果你说服我相信你与我所继承之人之间不存在合伙关系，因此我同意你在诉讼中获判免责，尤利安写道，应准许我对你提起恶意欺诈之诉。

### <a id="4.3.21"></a>4.3.21　乌尔比安《评告示》第十一卷

如果我要求你宣誓，你宣誓后获判免责，而后来又证实你作了伪证，拉贝奥说，应准许对你提起恶意欺诈之诉；但庞波尼乌斯认为，事情应视为已经因宣誓而了结。马尔凯鲁斯在《学说汇纂》第八卷中也赞同此说，因为应当尊重誓言。

### <a id="4.3.22"></a>4.3.22　保罗《评告示》第十一卷

因为伪证所受的处罚已经足够。

### <a id="4.3.23"></a>4.3.23　盖尤斯《评行省告示》第四卷

如果受遗赠人所得遗赠超出《法尔基第法》允许的限额，而继承人尚不知道遗产的实际状况，该受遗赠人自愿起誓或以其他欺诈方式说服继承人，称遗产足以充分支付全部遗赠，并因此取得了全部遗赠，则应准许恶意欺诈之诉。

### <a id="4.3.24"></a>4.3.24　乌尔比安《评告示》第十一卷

如果为主张自由者出庭陈述之人实施欺诈，致使未能在对方当事人到场时作出有利于自由的判决，我认为应立即准许对其提起恶意欺诈之诉，因为一旦已经作出有利于自由的判决，就不应将其撤销。

### <a id="4.3.25"></a>4.3.25　保罗《评告示》第十一卷

我向你请求给付金钱，并已就此进入诉讼；你却谎称已将该款付给我的奴隶或代理人，说服了我。你因此在我同意的情况下获判免责。我们就是否应准许我对你提起欺诈之诉进行讨论后，认为不应准许恶意欺诈之诉，因为我可以通过其他方式获得救济：我可以重新起诉；即使有人对我提出既判事项抗辩，我也可以依法援用再抗辩。

### <a id="4.3.26"></a>4.3.26　盖尤斯《评行省告示》第四卷

行省总督允诺，可在转归继承人的利益范围内对继承人提起此项诉讼；也就是说，以遗产因该事项而归继承人增值的范围为限。

### <a id="4.3.27"></a>4.3.27　保罗《评告示》第十一卷

或者，因继承人自己的恶意欺诈，财物才未能转归于其者，也应如此处理。

### <a id="4.3.28"></a>4.3.28　盖尤斯《评行省告示》第四卷

因此，如果金钱已通过正式免债行为免除，无论如何均可起诉你的继承人。但如果交付给你的是某物，则仅在你死亡时该物仍然存在的情况下，才能起诉你的继承人；否则不得起诉。不过，针对继承人的事实诉讼无论如何均可永久提起，因为继承人不应从他人的损失中获利。与此相应，对实施欺诈之人本人，也应永久准许事实诉讼，但仅以其因此增益的数额为限。

### <a id="4.3.29"></a>4.3.29　保罗《评告示》第十一卷

萨宾认为，起诉继承人是基于账目核算，而不是基于不法行为；因此，继承人不会因此蒙受名誉污损。正因如此，责任应当永久存续。

### <a id="4.3.30"></a>4.3.30　乌尔比安《评告示》第十一卷

对继承人无需审查案件情况。

### <a id="4.3.31"></a>4.3.31　普罗库鲁斯《书信集》第二卷

如果有人说服我家内之人〔译疑：*familia* 在此是否专指奴隶集体待核〕放弃占有，虽然占有本身并未丧失，但如果因此使我遭受损失，我可以对该人提起恶意欺诈之诉。

### <a id="4.3.32"></a>4.3.32　斯凯沃拉《学说汇纂》第二卷

一名儿子受托将以预先遗赠方式遗赠给他的奴隶释放，但须待某一日期届至，且在他向本人及作为共同继承人的兄弟交代账目之后方可为之。他却在期限届满和交账之前，以诉杖方式释放该奴隶，使其取得自由。有人问：他是否因遗嘱信托而对兄弟负有责任，应按各自份额向兄弟交代账目？我答复说，他既已使奴隶获得自由，便不因遗嘱信托而负有责任；但如果他是为了不向兄弟交账而故意提前释放奴隶，则可以对他提起恶意欺诈之诉。

### <a id="4.3.33"></a>4.3.33　乌尔比安《意见集》第四卷

占有人持有一件待售之物。对方当事人开始就该物的所有权提起诉讼；待其使一个原本有机会购买该物的买受人失去机会后，又撤回诉讼。判例认为，占有人可以就此提起事实诉讼，请求赔偿其全部损失。

### <a id="4.3.34"></a>4.3.34　乌尔比安《评萨宾》第四十二卷

如果你允许我从你的土地上采石、挖取白垩或沙土，而我为此支出了费用，你后来却不允许我将这些东西运走，那么除恶意欺诈之诉外，没有其他诉讼可以适用。

### <a id="4.3.35"></a>4.3.35　乌尔比安《评告示》第三十卷

如果有人在立遗嘱人死后，毁坏或以其他方式损毁寄存在自己处的遗嘱文书，那么遗嘱指定继承人可以对其提起恶意欺诈之诉。受遗赠人也应获准提起恶意欺诈之诉。

### <a id="4.3.36"></a>4.3.36　马尔基安《法则集》第二卷

两人共同实施恶意欺诈的，不得相互提起恶意欺诈之诉。

### <a id="4.3.37"></a>4.3.37　乌尔比安《评萨宾》第四十四卷

卖方为赞扬所售之物而说的话，应视为既未陈述，也未作出承诺。但如果卖方的话是为了欺骗买受人而说，则不得因此提起针对陈述或承诺的诉讼，而应提起恶意欺诈之诉。

### <a id="4.3.38"></a>4.3.38　乌尔比安《意见集》第五卷

某债务人使一封信看起来像是提提乌斯寄给自己债权人的，以便使自己免责。债权人受这封信欺骗，通过阿奎利亚式要式承诺和正式免债行为免除了债务人的债务。后来发现该信是伪造的或无效的；如果债权人已满二十五岁，就可以提起恶意欺诈之诉；如果尚未满二十五岁，则可以请求恢复原状。

### <a id="4.3.39"></a>4.3.39　盖尤斯《评行省告示》第二十七卷

如果你就一项自己并未占有的物出面与提提乌斯诉讼〔译疑：*te Titio optuleris* 指何种诉讼姿态未明〕，意在使他人时效取得该物，并且还提供判决清偿担保，那么即使你获判免责，仍须承担恶意欺诈责任。萨宾也持此见解。

### <a id="4.3.40"></a>4.3.40　富里乌斯《评告示》第一卷

有人欺骗他人，使其接受一项资不抵债的遗产〔译疑：*hereditas non idonea* 可指不适宜承受的遗产，暂按资不抵债理解〕，应承担恶意欺诈责任；但如果欺骗者本人就是债权人，而且是唯一的债权人，则属例外，因为对他援用恶意欺诈抗辩便已足够。
