# 第四卷

## 4.2　论因胁迫而实施的行为（Quod metus causa gestum erit）

<a id="2"></a><a id="4.2"></a>

### <a id="4.2.1"></a>4.2.1　乌尔比安《评告示》第十一卷

裁判官规定：“凡因胁迫而实施的行为，我均不予认可。”早先的告示表述为“凡因暴力或胁迫而为者”，因为其中提及暴力，是为说明违背行为人意愿而强加于人的强制；而恐惧，则是因即时或未来危险而产生的心神不安。后来删去“暴力”一词，是因为凡以强暴手段实施的行为，似乎也都是因恐惧而为。

### <a id="4.2.2"></a>4.2.2　保罗《格言集》第一卷

暴力，是较大力量的冲击，且无法抗拒。

### <a id="4.2.3"></a>4.2.3　乌尔比安《评告示》第十一卷

<a id="4.2.3.pr."></a>

**序言（pr.）** 因此，这一条款同时涵盖暴力与胁迫；任何人若因暴力而被迫实施某项行为，均可依本告示获得恢复原状。

<a id="4.2.3.1"></a>

**1.** 我们所说的暴力，是指强暴且违背善良风俗的行为，不包括官员依法正当地施加强制——也就是在法律许可的范围内，并依其所任官职的权限行事。然而，如果罗马官员或行省总督违法行事，庞波尼乌斯写道，本告示仍适用；例如，他说，若官员以死亡或鞭笞相威胁，从某人处勒取钱财，即属此种情形。

### <a id="4.2.4"></a>4.2.4　保罗《评告示》第十一卷

我认为，也应将害怕沦为奴隶及类似危险的恐惧纳入考虑。

### <a id="4.2.5"></a>4.2.5　乌尔比安《评告示》第十一卷

拉贝奥说，所谓恐惧，并非任何恐惧，而是对重大危险的恐惧。

### <a id="4.2.6"></a>4.2.6　盖尤斯《评行省告示》第四卷

我们应当认为，适用本告示的恐惧，不是胆怯之人的无端恐惧，而是有正当理由、足以使最坚定之人也感到畏惧的恐惧。

### <a id="4.2.7"></a>4.2.7　乌尔比安《评告示》第十一卷

<a id="4.2.7.pr."></a>

**序言（pr.）** 佩狄乌斯在《学说汇纂》第七卷中说，对陷入不名誉状态的恐惧不属于本告示所涵盖的恐惧；因担心遭受某种骚扰而产生的恐惧，也不得依本告示请求恢复原状。因此，如果胆怯之人无端害怕某件根本不会发生的事，就不能依本告示获得恢复原状，因为其行为既非因暴力而为，也非因胁迫而为。

<a id="4.2.7.1"></a>

**1.** 因此，如果有人因盗窃、通奸或其他恶行被当场发现，继而交付财物或承担债务，庞波尼乌斯在《学说汇纂》第二十八卷中正确地写道，此人可以适用本告示：因为他害怕死亡或被囚禁。诚然，并非所有通奸者或盗窃者都可被杀，除非其以武器自卫；但他们仍可能遭到违法杀害，因此这种恐惧有正当理由。又如，为免遭发现自己的人告发而处分财物，也应认为可依本告示获得救济，因为一旦被告发，他可能遭受我们刚才所说的那些后果。

### <a id="4.2.8"></a>4.2.8　保罗《评告示》第十一卷

<a id="4.2.8.pr."></a>

**序言（pr.）** 这些人确因收受与已查明的奸情有关的钱财而触犯《尤利娅法》。然而，裁判官仍应介入并命其返还：因为此种行为本身违背良俗；而且裁判官不考察给付者是否为通奸者，只考察受领者是否以死亡相威胁而取得财物。

<a id="4.2.8.1"></a>

**1.** 如果有人收钱，并威胁说除非我给钱，否则他就要毁掉证明我法律身份的文书，那么毫无疑问，他是在以极大的恐惧胁迫我；尤其是在我已被请求判为奴隶，而这些文书一旦毁失，我便无法被宣告为自由人的情况下。

<a id="4.2.8.2"></a>

**2.** 如果某人给付财物，是为了避免自己（无论男子或女子）遭受奸污，则本告示适用；对善良之人而言，这种恐惧应当大于死亡之恐惧。

<a id="4.2.8.3"></a>

**3.** 我们所说属于本告示范围的上述情形，无论某人是为自己还是为子女而感到恐惧，均无区别；由于亲子之情，父母对子女的恐惧往往更甚。
