### <a id="4.2.14"></a>4.2.14　乌尔比安《评告示》第十一卷

<a id="4.2.14.pr."></a>

**序言（pr.）** 同样，如果我本可凭一项对你永久有效的抗辩获得保护，却迫使你对我作出正式免债行为，那么本告示便不适用，因为你并未遭受任何损失。

<a id="4.2.14.1"></a>

**1.** 如果被告不予返还，裁判官承诺对其给予四倍额之诉：凡应返还的标的，均按四倍计算。裁判官对被告已相当宽厚，给了他返还的机会，使其可以借此避免刑罚。过了一年，裁判官承诺给予按单倍额计算的诉权，但并非一概准许，而须审查具体情由后决定。

<a id="4.2.14.2"></a>

**2.** 审查具体情由时，要考虑的是：如果不存在其他诉权，才给予此诉。确实，因胁迫所造成的侵害请求权经过一年（且该年按有效期间计算）即告消灭；因此，若要在一年届满后给予此诉，必须有充分理由。另一诉权例如可能存在于下列情形：遭受暴力之人死亡，其继承人享有遗产请求之诉，因为施暴者以占有人身份占有该物。为此，继承人不享有胁迫之诉；不过，若其能在一年期限内行使请求，继承人也可以提起四倍额之诉。之所以也把此诉权给予继受人，是因为此诉还具有对物追索的性质。

<a id="4.2.14.3"></a>

**3.** 在本诉中，不审查被诉之人还是他人造成了胁迫；只须证明有人对原告施加了胁迫或暴力，并且被诉之人虽未实施犯罪行为，却因此获利。既然恐惧本身会使人陷于不知情由的状态，便有理由不要求某人指明究竟是谁对他施加了胁迫或暴力。因此，原告只须证明：胁迫是其使某人作出要式免债行为、交付某物或实施其他行为的原因。任何人都不会认为，因他人行为而判令另一人承担四倍额是不公正的，因为该四倍额之诉并非一开始便按四倍额判处，只有在标的未获返还时才如此。

<a id="4.2.14.4"></a>

**4.** 本诉属于附裁判指令的诉讼，因此被告有权在受命裁判人作出裁判以前，依照我们上文所说返还标的；如果他不这样做，就应依法且理当地承受四倍额判决。

<a id="4.2.14.5"></a>

**5.** 然而，有时即使主张有人施加了胁迫，裁判人的裁量仍会使被告获判免责。试想：提图斯确实施加了胁迫，而我对此并不知情；标的却转到了我这里，并且该物已经不复存在，且并非因我的恶意欺诈所致——难道我不应由法官职权判予免责吗？〔原文含义未详：*et haec in rebus humanis non est sine dolo malo meo* 的否定结构及其与标的灭失原因的关系，仍需核定。〕又如，奴隶正在逃亡；同样，如果我依裁判人的指示作出保证，承诺该奴隶一旦进入我的权力控制之下便予以返还，我也应获判免责。因此，有些人认为，以善意从施暴者处购得该物者不负责任，受赠人或受遗赠者也不负责任。但是，维维安努斯认为这些人也应负责任，这一见解最为正确，以免我所遭受的胁迫反而成为使我陷入困境的陷阱。佩狄乌斯也在《学说汇纂》第八卷写道，法官就返还标的所作的裁量应当是：命令施暴者返还，即使标的已转至他人之手；并且也命令取得标的之人返还，即使胁迫是由他人施加的；因为不应使他人所承受的胁迫转而成为另一人的利益。

<a id="4.2.14.6"></a>

**6.** 拉贝奥说，如果某人因胁迫而被置于债务人地位，并提供一名自愿担任保证人的保证人，则本人和保证人都获免责；如果只有保证人因胁迫而加入，而主债务人本人并非如此，则仅保证人获免责。

<a id="4.2.14.7"></a>

**7.** 四倍计算的，是该物应有的价值，即连同孳息及一切相关利益计算。

<a id="4.2.14.8"></a>

**8.** 如果有人因受暴力而承诺到庭，后来又提供保证人，该承诺人也获免责。

<a id="4.2.14.9"></a>

**9.** 此外，如果有人以暴力迫使他人作出要式口约，却未对其作出正式免债，而后又被判承担四倍额，尤利安认为：此人日后依据该口约提起诉讼时，应允许其以回复抗辩（*replicatio*）应对对方提出的抗辩（*exceptio*）；因为在四倍额中，被告已经取得了单倍额部分。拉贝奥则说，即使已经提起四倍额之诉，仍应以抗辩排除施暴者。由于这种处理显得严苛，应作如下调和：既判令其承担三倍额，也无论如何都应强制其作出正式免债行为。

<a id="4.2.14.10"></a>

**10.** 既然我们说四倍额中包含单倍额，如果需要对此作出安排，应当这样处理：四倍额判决无论如何都应包括标的本身并命令返还；至于刑罚部分，则以三倍额为限。

<a id="4.2.14.11"></a>

**11.** 如果奴隶死亡并非因已被判决承担责任的施暴者之恶意欺诈或过失所致，怎么办？在这种情形下，如果奴隶是在执行判决之诉的期限内死亡，施暴者应免于承担该物价额部分的判决责任，因为他仍须为其不法行为承担三倍额的刑罚。至于据称正在逃亡的奴隶，应从被告处强制取得保证，要求他追寻该奴隶，并无论如何将其返还；与此同时，遭受暴力之人仍完整保有对物之诉、要求出示之诉，或任何其他可以使其取回该奴隶的诉权；这样，如果所有人以任何方式取回奴隶，以保证契约为由被诉之人便可援用抗辩而获保护。以上说的是判决作出之后的情形。如果奴隶在判决作出之前死亡，且其死亡并非出于施暴者的恶意欺诈或过失，被告仍应承担责任；这正是告示中“该物不能依法官裁量予以返还”这一用语所产生的效果。因此，如果奴隶正在逃亡，且并非因被诉之人的恶意欺诈或过失所致，法官应要求被告作出保证，承诺追寻并交还该奴隶。即使奴隶离开被告控制并非出于被告过失，只要若未施加胁迫该物本不会灭失，被告仍应负责；“以暴力剥夺占有”禁令程序（*interdictum unde vi*）及“因暴力或秘密侵占”禁令程序（*interdictum quod vi aut clam*）均遵循这一规则。因此，有时遭受暴力之人可以请求已死亡奴隶的价额——若未遭受暴力，他本会将该奴隶出售。

<a id="4.2.14.12"></a>

**12.** 施暴者虽从我处取得占有，却不是窃贼；不过，正如尤利安所认为的，以抢夺方式取得财物之人似乎是更为恶劣的窃贼。

<a id="4.2.14.13"></a>

**13.** 施加胁迫之人也受欺诈之诉追究，此点确定无疑；庞波尼乌斯亦持此说。两项诉权中的一项，会因另一项而消灭；只要提出针对具体事实的抗辩即可。

<a id="4.2.14.14"></a>

**14.** 尤利安说，只有利益损失额按四倍计算。因此，某人因遗嘱信托而负有四十的债务，却因受暴力而承诺给付三百并已实际支付的，他可以就二百六十请求四倍额；因为就这二百六十而言，他确实受到了暴力。

<a id="4.2.14.15"></a>

**15.** 依此，如果有数人施加胁迫，而其中一人被诉，若其在判决前自愿返还标的，则所有人均获免责；即使其未自愿返还，而是依判决返还了四倍额，较为正确的看法仍是：针对其他人的胁迫之诉也因此消灭。
