# 第四卷

## 4.6　论年满二十五岁者依哪些事由得以恢复原状（续）

### <a id="4.6.24"></a>4.6.24　保罗《评告示》第十二卷

本告示也适用于这样的人：他人已对其提起诉讼，而其以各种推诿、拖延或狡猾手段，使诉讼无法针对自己继续进行。

### <a id="4.6.25"></a>4.6.25　盖尤斯《评行省告示》第四卷

我们也认为，本告示以同样方式适用于这样的人：他并非出于使诉讼受阻的目的，而是因事务繁多、无暇应对，才使诉讼无法继续。

### <a id="4.6.26"></a>4.6.26　乌尔比安《评告示》第十二卷

<a id="4.6.26.pr."></a>

**序言（pr.）** 如果诉讼未能进行是因裁判官所致，也应准许恢复原状。

<a id="4.6.26.1"></a>

**1.** 庞波尼乌斯说，依一般条款，应准许针对被流放者的恢复原状救济；但不应也准许被流放者本人请求该救济，因为他本可留下诉讼代理人。不过，我认为，如有具体事由，也应救济其本人。

<a id="4.6.26.2"></a>

**2.** 裁判官说：“或者，法律不允许在未得其同意时将其传唤到法庭，而该人又未获辩护。”此条适用于依祖制不得在未构成不法的情况下将其传唤到法庭的人，例如执政官、裁判官以及其他持有统治权或其他权力者。但本告示不适用于裁判官禁止未经许可而传唤的人，因为裁判官本可准许传唤；例如释奴保护人和父母。

<a id="4.6.26.3"></a>

**3.** 裁判官接着加上“又未获辩护”一语；这适用于上述所有人，但不包括在缺席期间通过时效取得某物之人，因为前文已对这种情形作出充分规定。

<a id="4.6.26.4"></a>

**4.** 裁判官说：“或者，有人被称为因官职人员的行为、且非出于其自身恶意欺诈而丧失诉权。”此语何意？如果因法官一再延期，致使诉权消灭，就应恢复原状。拉贝奥还说，若当时没有官职人员可受理事务，也应恢复原状。所谓“因官职人员的行为”，应理解为官职人员未行使司法权；如果其审理案件后拒绝准许诉讼，则不适用恢复原状，塞尔维乌斯也持此见解。同样，如果官职人员出于偏袒或受贿而不行使司法权，也应视为其行为所致；本款适用。前文“或者不使对方有机会与其进行诉讼”一款也适用，因为诉讼当事人贿赂法官，正是为了不让对方对其提起诉讼。

<a id="4.6.26.5"></a>

**5.** “诉权被排除”应理解为当事人已不能再提起诉讼。

<a id="4.6.26.6"></a>

**6.** 裁判官又加上“非出于其自身恶意欺诈”一语，意思是，如果诉权消灭系由当事人自己的欺诈造成，就不应救济他；裁判官不帮助实施不法行为之人。因此，某人打算在下一任裁判官任内起诉，却因此虚耗了时间，就不应获得救济。又如，他不遵守裁判官的裁定，以致裁判官拒绝行使司法管辖权，拉贝奥记载说，此人不得恢复原状。若其因其他正当理由未获受理，亦同。

<a id="4.6.26.7"></a>

**7.** 如果因战事顺利等事由，或为尊崇元首而特别宣布休庭，官职人员因此未行使司法权，盖尤斯·卡西乌斯曾明文宣布将准许恢复原状，因为此事似乎是裁判官所致。相反，对于例行休庭日，不应计入期限，因为原告本可且应当预见这些日期，避免其间届至。此说较为妥当，塞尔苏斯在《学说汇纂》第二卷中也如此写道。但是，如果休庭日仅使期限暂时停止，则只应恢复这些休庭日，而不是恢复全部期限。尤利安在《学说汇纂》第四卷中也如此写道：时效取得应予撤销，并补回原告原本打算起诉、却因休庭而受阻的那些日期。

<a id="4.6.26.8"></a>

**8.** 如果某人因缺席只使另一人部分期间无法起诉，例如，我占有你的物品，在法定时效取得期限届满前仅差一日，随后又开始因公共事务而缺席，那么应对我恢复一日的期间。

<a id="4.6.26.9"></a>

**9.** 裁判官还说：“如果我认为存在其他正当理由，我将准许恢复原状。”告示必须纳入此条款，因为可能出现许多应给予恢复原状救济、却无法逐一列举的情形；因此，每当衡平要求恢复原状时，都应适用本条款。例如，某人代表共同体出使；即使其并非因公共事务而缺席，给予恢复原状仍最为公平。判例也一再确认应救济这类人，无论其是否留有代理人，均同。若某人为作证而从任一行省被召至罗马城或元首面前，我认为也应如此，因为敕答屡次确认应予救济。为接受审理或提起上诉而远行者，也同样获得救济。概而言之，每当某人因不得已而非自愿缺席，都应当救济他。

### <a id="4.6.27"></a>4.6.27　保罗《评告示》第十二卷

无论某人因此丧失了某物，还是未能取得某项利益，都应给予恢复原状；即使所失并非其财产中的某物，亦同。

### <a id="4.6.28"></a>4.6.28　乌尔比安《评告示》第十二卷

<a id="4.6.28.pr."></a>

**序言（pr.）** 如果某人因正当理由缺席，例如为求学而离开，且其代理人恰已死亡，裁判官也应斟酌是否救济他，以免其因极为正当的缺席事由反而受损。

<a id="4.6.28.1"></a>

**1.** 如果某人既未被拘禁，也未被关押，只是因提供保证而不得离开，结果因此受困，也应恢复原状，并准许对其提出相应的恢复原状请求。

<a id="4.6.28.2"></a>

**2.** 裁判官说：“凡法律、平民决议、元老院决议、告示及元首敕令所允许者。”此条款并非允诺：只要法律允许便恢复原状；其意是，法律未予禁止时，即可恢复原状。

<a id="4.6.28.3"></a>

**3.** 如果某人多次因公共事务而缺席，拉贝奥认为，应从其最后一次返还之日起计算恢复原状的期限。但如果历次缺席累计达到一年，而每次均不足一年，那么应当给予其一年恢复原状的期间，还是仅给予其最后一次缺席所占用的期间，仍须考察。我认为，应给予一年。

<a id="4.6.28.4"></a>

**4.** 如果你在某行省有住所，但当时人在罗马，我是否因此开始计算一年期限，仿佛我已有机会提起诉讼？拉贝奥说，期限不开始计算。我认为，若对方有权把我召回家乡，此说才是正确的；若对方无此权，则应视为我已有机会提起诉讼，因为我也可以在罗马使诉讼正式成立。

<a id="4.6.28.5"></a>

**5.** 因公共事务而缺席者，也可以仿照撤销诉讼提起抗辩；例如，对方在取得某物的占有后向其主张该物时，即可如此。

<a id="4.6.28.6"></a>

**6.** 对军人适用的撤销诉讼中，庞波尼乌斯说，最为公平的是：对方还应返还其在军人缺席且无人为其辩护期间取得的孳息。因此，这些孳息也应返还给军人；双方都将享有诉权，

### <a id="4.6.29"></a>4.6.29　阿非利卡努斯《疑问集》第七卷

显然，这是为了不使任何人因担任公职而蒙受损失或取得利益。

### <a id="4.6.30"></a>4.6.30　保罗《评告示》第十二卷

<a id="4.6.30.pr."></a>

**序言（pr.）** 如果正在通过时效取得物品的军人死亡，而其继承人完成了时效取得，那么其后取得的时效应予撤销，继承人承继时效取得的情形也应遵循同一规则；因为死者的占有仿佛作为附随部分一并移转给继承人，而且通常在遗产尚未被接受时，时效取得就已完成。

<a id="4.6.30.1"></a>

**1.** 如果因公共事务而缺席者通过时效取得某物，并在时效取得完成后将该物转让，就应恢复原状；即使其缺席与时效取得并无恶意欺诈，仍应阻止其从中获利。其他一切情形也应恢复原状，例如法院已对其作出判决的情形。

### <a id="4.6.31"></a>4.6.31　保罗《评告示》第五十三卷

如果某人因公共事务而缺席期间，他人通过时效取得了该人的物，而该人后来重新取得该物的占有，即使此后又丧失占有，也享有永久诉权，而非仅有定期诉权。

### <a id="4.6.32"></a>4.6.32　莫德斯丁《法则集》第九卷

离开罗马城的人，即使尚未离开所在行省，也被视为因公共事务而缺席；已经离开行省的人，则在返回罗马城以前均属此列。这一规则适用于行省总督及其副官、行省长官、奉命驻于行省的元首代理官，也适用于其姓名已登记于国库或元首簿册中的军事保民官、长官及使节随员。

### <a id="4.6.33"></a>4.6.33　莫德斯丁《疑难案例详析》

<a id="4.6.33.pr."></a>

**序言（pr.）** 国库代理人也属于依一般条款获得救济之人。

<a id="4.6.33.1"></a>

**1.** 为总督记录司法文书的速记员，显然不属于因公共事务而缺席者。

<a id="4.6.33.2"></a>

**2.** 军医也可以请求恢复原状救济，因为他们履行的职务有益于公共事务，不应因此遭受损害。

### <a id="4.6.34"></a>4.6.34　雅沃勒努斯《评卡西乌斯》第十五卷

<a id="4.6.34.pr."></a>

**序言（pr.）** 军人获准休假后身在家中，不视为因公共事务而缺席。

<a id="4.6.34.1"></a>

**1.** 为征收承包出去的公税而提供劳务者，不视为因公共事务而缺席。

### <a id="4.6.35"></a>4.6.35　保罗《评尤利娅法与帕庇娅法》第三卷

<a id="4.6.35.pr."></a>

**序言（pr.）** 奉命率领、护送士兵，或负责征募士兵的人，属于因公共事务而缺席。

<a id="4.6.35.1"></a>

**1.** 奉命向元首致贺之人，也属此列。

<a id="4.6.35.2"></a>

**2.** 元首代理官也属此列：不仅受命管理某一行省各项事务的代理官如此，受命管理部分事务的代理官亦然。因此，为不同事务分别任命的数名代理官，都被视为因公共事务而缺席。

<a id="4.6.35.3"></a>

**3.** 埃及长官也属于因公共事务而缺席者；因其他公共事务离开罗马城的人，也同样如此。

<a id="4.6.35.4"></a>

**4.** 神皇庇护亦对城市军团士兵作出同样的规定。

<a id="4.6.35.5"></a>

**5.** 有人询问，奉命制止恶人的人是否属于因公共事务而缺席者；通说认为，其确属因公共事务而缺席。

<a id="4.6.35.6"></a>

**6.** 又如，一名平民奉执政官之命参加军事远征，并在战阵中阵亡；应救济其继承人。

<a id="4.6.35.7"></a>

**7.** 为公共事务前往罗马的人，被视为因公共事务而缺席。即使其为公共事务离开本邦，且途中须经过本城，也仍属此列。

<a id="4.6.35.8"></a>

**8.** 同样，某人身在行省，自其离家出发之时起，或者在同一行省居住并开始处理公共事务之时起，均按缺席者对待。

<a id="4.6.35.9"></a>

**9.** 士兵前往军营及从军营返回期间，也属于因公共事务而缺席，因为应征入伍者必须前往军营并在退伍后返回。维维安努斯记载，普罗库鲁斯曾答复说：获准休假的士兵，在前往家中及返程期间属于因公共事务而缺席；但人在家中时则不属于此列。

### <a id="4.6.36"></a>4.6.36　乌尔比安《评尤利娅法与帕庇娅法》第六卷

只有那些并非为自身利益、而是因不得已而缺席的人，才被视为因公共事务而缺席。

### <a id="4.6.37"></a>4.6.37　保罗《评尤利娅法与帕庇娅法》第三卷

在本行省担任司法顾问、却超过元首敕令所准期限仍留任的人，不视为因公共事务而缺席。

### <a id="4.6.38"></a>4.6.38　乌尔比安《评尤利娅法与帕庇娅法》第六卷

<a id="4.6.38.pr."></a>

**序言（pr.）** 如果元首以特别恩惠准许某人在其本行省担任司法顾问，我认为该人属于因公共事务而缺席。若其未经许可便如此行事，则应认为：既然他实施了犯罪，便不得享有因公共事务而缺席者的特权。

<a id="4.6.38.1"></a>

**1.** 某人只有在担任某项职务期间，才被视为因公共事务而缺席；职务一旦结束，其因公共事务而缺席的状态即告终止。自其不再因公共事务而缺席之时起，应计算其返回罗马所需的期间；并应依法律给予返城者的期限，酌情给予其适当时间。因此，如果他为处理私事而绕道，毫无疑问，这段时间不得计入；计算其本可返回的期间后，应立即认定其不再因公共事务而缺席。当然，如果他因疾病而无法继续行程，则应予人道考虑；冬季、航行及其他偶然发生的情形，也通常作同样处理。

### <a id="4.6.39"></a>4.6.39　保罗《格言集》第一卷

某人原本将因公共事务而缺席，但若其留下了可为其辩护的代理人，却仍自愿请求恢复原状，则不应受理。

### <a id="4.6.40"></a>4.6.40　乌尔比安《意见集》第五卷

<a id="4.6.40.pr."></a>

**序言（pr.）** 如果针对军人的指控在其为公共事务服务期间提出，该指控并不因此消灭。

<a id="4.6.40.1"></a>

**1.** 如果能够证明：某人因受判处的刑罚而被送至岛上期间，他人从其未被剥夺的财产中取得某物并完成时效取得；而该人后来获得恢复原状，则应将该物返还给他。

### <a id="4.6.41"></a>4.6.41　尤利安《学说汇纂》第三十五卷

如果立遗嘱人为提提乌斯设立遗赠，条件是提提乌斯在立遗嘱人死亡时身在意大利；或者约定按年给付，以提提乌斯每年身在意大利为条件，而提提乌斯因公务缺席、因此被排除于遗赠之外并获救济，那么他仍须履行遗嘱中由其承担的遗嘱信托义务。马尔凯鲁斯注释说：军人仅因公务缺席而丧失遗产，若在不损害遗赠与遗嘱信托的前提下使其恢复该遗产，谁会对此存疑？

### <a id="4.6.42"></a>4.6.42　阿尔芬努斯《学说汇纂》第五卷

某人因处理私人事务而担任使节，不应称为因公共事务而缺席。

### <a id="4.6.43"></a>4.6.43　阿非利卡努斯《疑问集》第七卷

如果有人约定，只要他本人或要式承诺人身在意大利，便逐年给付；而任何一方开始因公共事务而缺席，裁判官就应准许一项准用之诉。若要式承诺写作“只要其在未来五年内身在罗马”，或写作“如果其不在罗马，你是否承诺给付一百？”，也应作同样处理。

### <a id="4.6.44"></a>4.6.44　保罗《评萨宾》第二卷

因公共事务而缺席者，就某项损害不得请求恢复原状，如果即使其未因公共事务而缺席，也同样会遭受该损害。

### <a id="4.6.45"></a>4.6.45　斯凯沃拉《法则集》第一卷

凡不能在没有危险的情况下脱离军旗的士兵，都被视为因公共事务而缺席。

### <a id="4.6.46"></a>4.6.46　马尔基安《法则集》第二卷

因公共事务而缺席者，即使相对方也同样因公共事务而缺席，只要其有正当理由主张自己遭受了损害，仍应获恢复原状。
