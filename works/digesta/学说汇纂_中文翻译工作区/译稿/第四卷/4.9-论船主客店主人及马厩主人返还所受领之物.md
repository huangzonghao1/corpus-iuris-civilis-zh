## <a id="9"></a><a id="4.9"></a>4.9　论船主、客店主人及马厩主人返还其所受领之物

*Nautae caupones stabularii ut recepta restituant*

### <a id="4.9.1"></a>4.9.1　乌尔比安《评告示》第十四卷

<a id="4.9.1.pr."></a>

**序言（pr.）** 法务裁判官说：“船主、客店主人和马厩主人，如果接受某人的物品并承诺妥善保管，却不予返还，我将给予针对他们的诉讼。”

<a id="4.9.1.1"></a>

**1.** 本告示极有用处，因为人们通常不得不信赖这些人，并将物品交由他们保管。不要因此认为这一规定对他们过于严厉：是否接纳某人，本由他们自行决定；若无此规定，他们便可能与盗贼勾结，侵害自己所接纳之人，而即使现在，他们也未停止此类欺诈。

<a id="4.9.1.2"></a>

**2.** 因此，需要考察哪些人应当承担责任。法务裁判官说的是“船员”。我们应将船舶经营人视为这里所说的“船员”；尽管凡为航行目的而在船上的人，通常都称为船员，法务裁判官在此仅指船舶经营人。正如庞波尼乌斯所说，经营人不应因桨手或副船员而承担责任，而应因其本人或船长而承担责任；不过，如果经营人本人命令将物品交给某一船员保管，则无疑应由其承担责任。

<a id="4.9.1.3"></a>

**3.** 船上还有一些人被安排负责船舶的保管，例如 *naufulakes*（船舶守卫）和 *diaetarii*（船上侍从）。因此，如果其中一人接收了物品，我认为应当给予针对船舶经营人的诉讼，因为安排他们担任此类职务的人，允许他人将物品交由他们保管；即使船主或船长本人实施了所谓 *xeirembolon* 的行为，亦是如此。〔原文含义未详：*xeirembolon* 为底本文字，具体所指待核。〕即使船主本人并未经营船舶，对于所受领的物品，他仍应承担责任。

<a id="4.9.1.4"></a>

**4.** 关于木筏经营人以及小船船主，告示没有规定；但拉贝奥记载，对他们也应作相同规定，我们现行法亦如此。

<a id="4.9.1.5"></a>

**5.** 客店主人和马厩主人同样包括实际经营客店或马厩者，以及他们的店铺经理。至于仅从事杂役的人，则不包括在内，例如门房、灶役及类似人员。

<a id="4.9.1.6"></a>

**6.** 法务裁判官说：“他们所承诺妥善保管的某人的物品”——这里指他们所受领的任何物品或货物。据维维安努斯记载，本告示也适用于附随于货物的物品，例如在船上使用的衣物以及其他日常用品。

<a id="4.9.1.7"></a>

**7.** 庞波尼乌斯还在《学说汇纂》第三十四卷中写道，所运入的是我们自己的物品还是他人的物品，并不重要，只要物品安全与我们有利害关系即可；因为他们应当向我们，而非物品所有人返还。因此，如果我因海事借贷而接受货物作为质物，只要船主先前已接收该货物，船主就应向我而非向债务人承担责任。

<a id="4.9.1.8"></a>

**8.** 他是否只有在物品已被运上船并交付给他时，才承诺妥善保管？还是说，即使物品没有交付，仅因已经运上船，也应视为已被接收？我认为，他应当对所有运上船的物品承担保管责任，并且不仅应对船员的行为负责，也应对旅客的行为负责；

### <a id="4.9.2"></a>4.9.2　盖尤斯《评行省告示》第五卷

客店主人对旅客的行为，也应同样负责。

### <a id="4.9.3"></a>4.9.3　乌尔比安《评告示》第十四卷

<a id="4.9.3.pr."></a>

**序言（pr.）** 庞波尼乌斯在《学说汇纂》第三十四卷中也这样论述旅客的行为。他还说，即使物品尚未被接收到船上，只是已经被接收后在岸上灭失，风险也由接收者承担。

<a id="4.9.3.1"></a>

**1.** 法务裁判官说：“如果他们不予返还，我将给予针对他们的诉讼。”本告示据此产生一项事实诉讼（*actio in factum*）。但是否有必要设立该诉讼，尚须考察，因为基于这一事由也可以提起市民法上的诉讼：如果收取了报酬，可以提起租赁之诉；如果整艘船均已出租，承租人也可以基于租赁之诉，就灭失的物品提起诉讼；如果船主受雇运送物品，则可以对其提起出租之诉；如果物品系无偿受领，庞波尼乌斯说，可以提起寄托之诉。因此，他不解为何在已有市民法诉讼时，还要创设裁判官法上的诉讼。除非如他所说，这是为了使人们知道，法务裁判官正致力于制止此类人的不诚实行为；并且，在租赁关系中承担过失责任，在寄托关系中仅承担欺诈责任，而依本告示，凡接收物品者均须承担责任，即使物品灭失或受损并非出于其过失也不例外，除非是因不可避免的灾祸所致。因此，拉贝奥写道，如果物品因海难或海盗暴力而灭失，给予被告抗辩并非不公。同样，如果马厩或客店发生不可抗力事件，也应如此处理。

<a id="4.9.3.2"></a>

**2.** 客店主人和马厩主人仅就其在经营业务过程中所接收的物品承担同样责任；若在经营业务之外接收物品，则不承担责任。

<a id="4.9.3.3"></a>

**3.** 如果家子或奴隶接收物品，且家父或主人表示同意，则应对家父或主人提起全额责任诉讼。同样，如果船舶经营人的奴隶窃取物品或造成损害，则不适用诺克萨诉讼，因为主人因接收物品而以本人名义被诉。若家子或奴隶未经家父或主人同意而经营，则可提起特有产之诉。

<a id="4.9.3.4"></a>

**4.** 庞波尼乌斯说，本诉旨在追索物本身，因此既可对继承人提起，也不受诉讼期间限制。

<a id="4.9.3.5"></a>

**5.** 最后还须考察：就同一物品，是否既可提起受领物品的裁判官法诉讼，也可提起盗窃之诉。庞波尼乌斯对此存疑；但较妥当的做法是，应由法官依职权裁量，或通过恶意抗辩，使原告满足于其中一项诉讼。

### <a id="4.9.4"></a>4.9.4　保罗《评告示》第十三卷

<a id="4.9.4.pr."></a>

**序言（pr.）** 如果物品灭失的风险由船员承担，船员本人也可以提起盗窃之诉；但若是船员自己窃取物品，随后又有人从该船员处窃取，或者物品虽由他人窃取、但该船员无力偿付，则不在此限。

<a id="4.9.4.1"></a>

**1.** 如果船员接收另一名船员的物品，马厩主人接收另一名马厩主人的物品，或者客店主人接收另一名客店主人的物品，也同样承担责任。

<a id="4.9.4.2"></a>

**2.** 维维安努斯说，本告示也适用于货物装载并安置在船上之后才被带上船的物品，即使这些物品不另行收取运费，例如衣物、日常食物；因为这些物品本身附随于其他物品的运输租赁。

### <a id="4.9.5"></a>4.9.5　盖尤斯《评行省告示》第五卷

<a id="4.9.5.pr."></a>

**序言（pr.）** 船主、客店主人和马厩主人收取报酬，并非为了保管：船主收取报酬是为了运送旅客，客店主人是为了允许旅客住在客店，马厩主人则是为了允许他人的牲畜在其马厩寄放；然而，他们仍须就保管承担责任。洗衣工和缝补工也是如此：他们收取报酬是为了其技艺，而非为了保管，但仍须因保管而依租赁关系承担责任。

<a id="4.9.5.1"></a>

**1.** 我们关于盗窃所说的一切，也应同样适用于损害；因为不应怀疑，凡承诺使物品安全者，应被视为不仅承诺使物品免遭盗窃，也承诺使其免受损害。

### <a id="4.9.6"></a>4.9.6　保罗《评告示》第二十二卷

<a id="4.9.6.pr."></a>

**序言（pr.）** 即使你免费乘船，或免费在客店住宿，只要你遭受了不法损害，也不会因此被拒绝获得基于事实的诉讼。

<a id="4.9.6.1"></a>

**1.** 如果你在船上或客店使用我的奴隶，而他对我造成损害或实施盗窃，尽管我本人可以提起盗窃之诉和不法损害之诉，但由于本诉是基于事实的诉讼，我也可以就我的奴隶对你提起本诉。奴隶由我与你共同所有时，亦作同样处理。不过，就你因该奴隶向我所作的给付，你还可以通过共同物分割之诉或合伙之诉向我主张；如果你租用了该奴隶的份额或全部，也可以基于租赁关系使我承担责任。

<a id="4.9.6.2"></a>

**2.** 但如果损害是由同一船舶或客店中的另一人造成，而法务裁判官通常会审查该人的行为，庞波尼乌斯认为，不应就该人的行为给予本项准诉权。

<a id="4.9.6.3"></a>

**3.** 客店主人依基于事实的诉讼，就以居住为目的而住在客店的人承担责任；但这不适用于临时投宿者，例如旅客。

<a id="4.9.6.4"></a>

**4.** 我们可以对船员提起盗窃之诉或不法损害之诉，以追究某一特定人的行为；但我们只能满足于其中一项诉讼。如果我们已经起诉船舶经营人，就应将我们对船员享有的诉权交给经营人，尽管经营人可以基于租赁之诉起诉船员。如果经营人已经在本诉中获判免责，之后再起诉船员时，将给予抗辩，以免同一人的同一行为被重复审理。反之，如果已经就某一人的行为提起诉讼，随后又提起基于事实的诉讼，也将给予抗辩。

### <a id="4.9.7"></a>4.9.7　乌尔比安《评告示》第十八卷

<a id="4.9.7.pr."></a>

**序言（pr.）** 船舶经营人应当对其所有船员的行为负责，无论船员是自由人还是奴隶；这并非没有道理，因为是经营人自行雇用他们，并由自己承担风险。但只有在损害发生于船上时，经营人才承担责任；如果损害发生在船外，即使是船员造成的，也不承担责任。同样，如果经营人事先声明每位旅客应自行保管其物品，并表示不对损害负责，而旅客同意了这一声明，则不得起诉经营人。

<a id="4.9.7.1"></a>

**1.** 这项基于事实的诉讼判处双倍责任。

<a id="4.9.7.2"></a>

**2.** 如果船员彼此造成损害，这与船舶经营人无关。但如果某人兼为船员和商人，文本接着说“应向其给付所欠之物”〔*debiti illi dari*；原句的句法和责任主体待核〕。如果某人属于俗称的 *nautepibatae*（海上强盗），经营人也须就其行为承担责任，因为此人同时也是船员。

<a id="4.9.7.3"></a>

**3.** 如果船员的奴隶造成损害，即使该奴隶本人不是船员，给予针对船舶经营人的准诉权也最为公平。

<a id="4.9.7.4"></a>

**4.** 依本诉，船舶经营人以本人名义承担责任，具体而言，是因为他自己的过失——他雇用了这类人；因此，即使他们后来死亡，他也不能免除责任。但就其自己的奴隶而言，他仅承担诺克萨责任。因为雇用他人的奴隶时，经营人应当查明他们是否忠实、是否品行端正；对于自己的奴隶，如果他不论其品行如何都将其雇来配备船舶，则值得宽宥。

<a id="4.9.7.5"></a>

**5.** 如果有数人共同经营一艘船，每个人都应按其经营份额被起诉。

<a id="4.9.7.6"></a>

**6.** 这些诉讼虽然属于裁判官法诉讼，但诉讼期间是永久的；不过，不得对继承人提起。因此，如果奴隶经营船舶后死亡，不得以特有产为限对主人提起诉讼，且一年内也不得提起此诉。但如果奴隶或家子经家父或主人同意而经营船舶、客店或马厩，我认为，家父或主人应承担全额责任，仿佛他们已就其中发生的一切事项承担了全部责任。
