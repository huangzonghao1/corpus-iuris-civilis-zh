<a id="8"></a>

### <a id="4.8"></a>4.8.0　论接受仲裁并应作出裁决者（De receptis: qui arbitrium receperint ut sententiam dicant）

### <a id="4.8.1"></a>4.8.1　保罗《评告示》第二卷

仲裁协议按照诉讼的模式订立，旨在终结争讼。

### <a id="4.8.2"></a>4.8.2　乌尔比安《评告示》第四卷

通常认为，基于仲裁协议并不产生抗辩，而是产生请求给付罚金的诉权。

### <a id="4.8.3"></a>4.8.3　乌尔比安《评告示》第十三卷

<a id="4.8.3.pr."></a>

**序言（pr.）** 拉贝奥说，如果双方订立仲裁协议，仲裁人作出裁决，使未满二十五岁者免于承担监护之诉的责任，裁判官不应认可该裁决；也不得基于此事请求给付罚金。

<a id="4.8.3.1"></a>

**1.** 裁判官固然不强迫任何人接受仲裁，因为接受仲裁一事自由且不受拘束，并不属于司法管辖权所必需；但某人一旦接受仲裁，裁判官便认为此事属于他应当关心并认真履行的职责。这不仅因为他应当致力于终结争讼，也因为选择他作为双方善良裁断者的人，不应受其欺骗。试想，案件已经审理过一次甚至两次，双方事务的内情和秘密已经披露之后，仲裁人却出于偏袒、受贿或其他原因而不愿作出裁决。谁能否认，裁判官最公允的做法就是介入，迫使仲裁人履行其所承担的职责？

<a id="4.8.3.2"></a>

**2.** 裁判官说道：“以金钱约定罚金而接受仲裁者。”

<a id="4.8.3.3"></a>

**3.** 现在讨论仲裁人的身份。无论仲裁人具有何种身份，裁判官都会迫使其履行所承担的职责，即使他是前执政官亦然；但若他担任某项官职或掌有权力，例如是执政官或裁判官，则可能例外，因为裁判官对此不具有统治权。

### <a id="4.8.4"></a>4.8.4　保罗《评告示》第十三卷

因为绝不能强迫具有较高或同等统治权的官员；他们是在就任前还是在任期间接受仲裁，并无区别。较低级别的官员则可以被强迫。

### <a id="4.8.5"></a>4.8.5　乌尔比安《评告示》第十三卷

但处于家父权下的儿子也会被强迫履行。

### <a id="4.8.6"></a>4.8.6　盖尤斯《评行省告示》第五卷

据说，处于家父权下的儿子甚至可以就其父亲的事务担任仲裁人；因为多数人也认为，他可以担任法官。

### <a id="4.8.7"></a>4.8.7　乌尔比安《评告示》第十三卷

<a id="4.8.7.pr."></a>

**序言（pr.）** 佩狄乌斯在《告示评注》第九卷、庞波尼乌斯在《告示评注》第三十三卷中写道，仲裁人是自由出生者还是被释自由人、品行端正者还是受不名誉处分者，并不重要。拉贝奥在《告示评注》第十一卷中写道，不得与奴隶订立仲裁协议；这才是正确的。

<a id="4.8.7.1"></a>

**1.** 因此，尤利安说，如果与提提乌斯及一名奴隶订立仲裁协议，不应强迫提提乌斯作出裁决，因为他是与另一人共同接受仲裁的。尤利安虽说奴隶的仲裁行为无效，但如果提提乌斯作出了裁决，又应如何处理？不会发生罚金责任，因为他并非按照其接受仲裁时约定的方式作出裁决。

### <a id="4.8.8"></a>4.8.8　保罗《评告示》第十三卷

但是，如果仲裁协议约定二人中任何一人的裁决均有效，就应当强迫提提乌斯作出裁决。

### <a id="4.8.9"></a>4.8.9　乌尔比安《评告示》第十三卷

<a id="4.8.9.pr."></a>

**序言（pr.）** 但是，如果与一名奴隶订立仲裁协议，而自由人作出了裁决，我认为：如果该自由人在获得自由后、经双方同意而作出裁决，该裁决有效。

<a id="4.8.9.1"></a>

**1.** 正如庞波尼乌斯在《告示评注》第三十三卷中所写，不得与未成年人、精神失常者、聋人或哑人订立仲裁协议。

<a id="4.8.9.2"></a>

**2.** 《尤利娅法》禁止法官就自己正在审理的事项接受仲裁，也禁止命令他人就涉及自己的事项订立仲裁协议；即使该法官作出了裁决，也不得请求给付罚金。

<a id="4.8.9.3"></a>

**3.** 还有其他一些人不受强迫作出裁决，例如仲裁人明显受贿或品行卑劣者。

<a id="4.8.9.4"></a>

**4.** 尤利安说，如果诉讼当事人诋毁仲裁人，裁判官不得一概免除仲裁人的职责，而应审查案件情况后再作决定。

<a id="4.8.9.5"></a>

**5.** 同样，如果当事人蔑视仲裁人的权威而转向法院，

### <a id="4.8.10"></a>4.8.10　保罗《评告示》第十三卷

或者转而选择另一仲裁人，也应作同样处理。

### <a id="4.8.11"></a>4.8.11　乌尔比安《评告示》第十三卷

<a id="4.8.11.pr."></a>

**序言（pr.）** 如果诉讼当事人曾离开某仲裁人，后来又回到同一仲裁人处，裁判官不应强迫该仲裁人为他们裁断，因为他们蔑视他而转向他人，已经如此侮辱了他。

<a id="4.8.11.1"></a>

**1.** 除非订立了仲裁协议，否则不得强迫仲裁人作出裁决。

<a id="4.8.11.2"></a>

**2.** 对于裁判官所说的“约定金钱”，应当理解为：并非只有双方都约定以金钱作为罚金才符合条件；如果约定在任何一方不遵守仲裁人裁决时，以其他物品代替罚金，也符合条件。庞波尼乌斯也这样写道。那么，如果双方约定将物品寄存于仲裁人处，由仲裁人交给胜诉方，或者约定任何一方不遵守裁决时就将该物交付出去，是否应强迫仲裁人作出裁决？我认为应当强迫。若为此目的存放于其处的是确定数额的金钱，亦同。相应地，如果一方承诺交付物品，另一方则向提出要式承诺者承诺给付金钱，仲裁协议也已完整成立，仲裁人应被强迫作出裁决。

<a id="4.8.11.3"></a>

**3.** 庞波尼乌斯写道，有时仅凭无形式的协议订立仲裁协议也完全有效。例如，双方都是债务人，并约定不遵守仲裁人裁决的一方，不得请求另一方给付其所欠之物。

<a id="4.8.11.4"></a>

**4.** 尤利安还写道，如果一方承诺支付罚金而另一方没有承诺，就不得强迫仲裁人作出裁决。他还说，如果双方约定的罚金附有条件，例如“如果船从亚洲归来，则给付若干千”，也不得强迫仲裁人作出裁决；须待条件成就后才能强迫，否则条件未成就时，裁决将无法发生效力。庞波尼乌斯在《告示评注》第三十三卷中也这样写道。

### <a id="4.8.12"></a>4.8.12　保罗《评告示》第十三卷

在这种情况下，裁判官的职责或许仅在于：如果可以延长仲裁协议的期限，就予以延长。

### <a id="4.8.13"></a>4.8.13　乌尔比安《评告示》第十三卷

<a id="4.8.13.pr."></a>

**序言（pr.）** 庞波尼乌斯说，如果一方已通过正式免债行为免除了仲裁协议所约定的罚金，就不应强迫仲裁人作出裁决。

<a id="4.8.13.1"></a>

**1.** 庞波尼乌斯还写道，如果仲裁协议仅涉及我自己的争议，而我又向你取得了罚金要式承诺，就应考察此种安排是否根本不构成仲裁协议。但我看不出他为何对此有所疑虑：如果是因为仲裁协议仅涉及一方的争议，那就没有道理，因为双方可以就一件事项订立仲裁协议；如果是因为仅有一方作出罚金要式承诺，那倒有理由。尽管如此，如果作出要式承诺的是原告，也可以说仲裁协议已经完整成立：被诉者可以援用类似协议抗辩获得保障；起诉者则在仲裁人裁决不被遵守时享有要式承诺之诉。但我认为这并不正确：仅有抗辩并不足以强迫仲裁人作出裁决。

<a id="4.8.13.2"></a>

**2.** 如佩狄乌斯在《告示评注》第九卷所说，承担法官职责并承诺以自己的裁决终结争议的人，才被视为接受了仲裁。他说，如果某人仅仅介入，试图看看当事人是否愿意通过他的建议或权威解决争端，则不视为接受仲裁。

<a id="4.8.13.3"></a>

**3.** 在法官不受强迫作出裁判的那些日子里，仲裁人也不受强迫作出裁决；但仲裁协议期限即将届满且无法延长的，不在此限。

<a id="4.8.13.4"></a>

**4.** 因此，如果裁判官催促仲裁人作出裁决，而仲裁人宣誓称自己尚未查明案情，那么最公平的做法是给他一些时间作出裁决。

### <a id="4.8.14"></a>4.8.14　庞波尼乌斯《答昆图斯·穆基乌斯》第十一卷

但如果订立仲裁协议时没有约定期限，仲裁人就必须在双方同意的情况下设定期限，并依此审理案件；如果他没有这样做，就应随时强迫其作出裁决。

### <a id="4.8.15"></a>4.8.15　乌尔比安《评告示》第十三卷

尽管裁判官严格宣告将强迫仲裁人作出裁决，但有时仍应考虑仲裁人的情况，并在审查案情后接受其免责理由。例如，诉讼当事人诋毁了仲裁人；仲裁人与当事人或其中一方存在生死仇敌关系；其后发生的年龄或健康状况使其无法承担该职责；他须处理自己的事务、急于出行或承担某项公共职务。拉贝奥也持此说：

### <a id="4.8.16"></a>4.8.16　保罗《评告示》第十三卷

<a id="4.8.16.pr."></a>

**序言（pr.）** 即使在接受仲裁后发生其他不便，也同样如此。但若是健康状况或类似事由，裁判官审查案情后必须延期。

<a id="4.8.16.1"></a>

**1.** 仲裁人因自己正在处理的公事或私事审判，应当从仲裁协议中获准免责，尤其是在仲裁协议期限无法延长时。如果期限可以延长，为何不在可以延长时强迫他办理延期？有时无需作任何区分，此种情形本身就会发生〔译疑：*quod sine ulla distinctione ipsius interdum futurum est* 的句法指向待核〕。然而，如果双方都希望他作出裁决，尽管没有约定可以延期，他是否仍须再次取得双方同意与自己订立仲裁协议，才可因自己正在审理案件而获准免责？这里讨论的是仲裁协议期限即将届满的情形。

### <a id="4.8.17"></a>4.8.17　乌尔比安《评告示》第十三卷

<a id="4.8.17.pr."></a>

**序言（pr.）** 又如，一方诉讼当事人将其财产让与债权人，尤利安在《学说汇纂》第四卷中写道，此时不应强迫仲裁人作出裁决，因为该方既不能起诉，也不能被起诉。

<a id="4.8.17.1"></a>

**1.** 拉贝奥写道，如果诉讼当事人过了很久才回到仲裁人处，不应强迫仲裁人作出裁决。

<a id="4.8.17.2"></a>

**2.** 又如，如果有数名仲裁人，不得只强迫其中一人作出裁决，而应强迫全体作出，或者一个也不强迫。

<a id="4.8.17.3"></a>

**3.** 因此，庞波尼乌斯在《告示评注》第三十三卷中提出：如果仲裁协议约定由裁断人提提乌斯认为妥当的事项，交由塞伊乌斯宣告，究竟应强迫谁？我认为，这种仲裁无效，因为仲裁人并没有自由作出裁决的权力。

<a id="4.8.17.4"></a>

**4.** 但如果仲裁协议约定由提提乌斯或塞伊乌斯裁断，庞波尼乌斯写道——我们也认为——仲裁协议有效；当事人同意由谁裁断，就应强迫谁作出裁决。

<a id="4.8.17.5"></a>

**5.** 如果约定由两名仲裁人裁断，意见不一致时再选第三人，我认为这种仲裁协议无效，因为双方在选择第三人时可能发生分歧。但如果约定由他们另行选定塞姆普罗尼乌斯作为第三人，仲裁协议便有效，因为他们不可能对选择该人发生分歧。

<a id="4.8.17.6"></a>

**6.** 但首先要考察，如果双方将争议交给两名仲裁人，裁判官是否应强迫他们作出裁决，因为人们天生容易意见不合，事情很可能因此无法了结。之所以允许由奇数名仲裁人裁断，并不是因为所有人容易达成一致，而是因为即使意见不一，也能产生多数意见，且应遵从多数意见。但惯例上也会将仲裁交给两人；若二人不能达成一致，裁判官就应强迫他们选定一名第三人，并服从此人的裁断。

<a id="4.8.17.7"></a>

**7.** 凯尔苏斯在《学说汇纂》第二卷中写道，如果将仲裁交给三人，两人的一致意见固然足够，但第三人必须在场；否则，即使两人意见一致，仲裁也无效，因为仲裁协议涉及多人，而第三人在场可能使他们转而采纳他的意见：

### <a id="4.8.18"></a>4.8.18　庞波尼乌斯《书信集与异读集》第十七卷

这就像指定三名法官时，第三人缺席而其余两人一致作出的判决无效一样；因为只有在显然三人都已作出裁判的情况下，才能确认多数人的判决有效。

### <a id="4.8.19"></a>4.8.19　保罗《评告示》第十三卷

<a id="4.8.19.pr."></a>

**序言（pr.）** 拉贝奥说，仲裁人应作出何种裁决，并不属于裁判官应当审查的事项，只要仲裁人作出了自己认为妥当的裁决即可。因此，尤利安在《学说汇纂》第四卷中写道，如果仲裁协议要求仲裁人作出特定内容的裁决，该仲裁便无效，也不得强迫仲裁人作出裁决。

<a id="4.8.19.1"></a>

**1.** 我们认为，仲裁人作出裁决，是指他意在通过其宣告使当事人结束全部争议。但如果交由仲裁人处理多项事项，除非他解决了所有争议，否则就不视为已经作出裁决，裁判官仍应强迫他作出裁决。

<a id="4.8.19.2"></a>

**2.** 由此还要考察仲裁人能否变更裁决。过去曾讨论：仲裁人先命令给付，后来又禁止给付，应遵从其命令还是其禁令？萨宾认为可以变更。卡西乌斯很好地为其老师的意见作了解释，说萨宾所指的并非终结仲裁的裁决，而是诉讼准备阶段的命令；例如，先命令当事人在月初到场，后来又命令他们在月中到场——仲裁人可以变更到场日期。至于仲裁人已经作出判决或宣告无罪，因而不再担任仲裁人的，便不得变更裁决，

### <a id="4.8.20"></a>4.8.20　盖尤斯《评行省告示》第五卷

因为仲裁人即使在作出裁决时犯了错误，也不能更正裁决。

### <a id="4.8.21"></a>4.8.21　乌尔比安《评告示》第十三卷

<a id="4.8.21.pr."></a>

**序言（pr.）** 但是，如果仲裁人受托处理数项彼此无关的争议，只对其中一项作出裁决，对其余争议尚未裁决，他是否就不再是仲裁人了？因此，我们应当考察，他能否变更已经作出的第一项争议裁决。这取决于双方是约定仲裁人须就所有事项一并作出裁决，还是分别作出裁决：如果约定一并裁决，他就可以变更，因为尚未作出完整裁决；但如果分别约定，就相当于存在数项仲裁协议，因此，就第一项争议而言，仲裁人已不再具有仲裁人身份。

<a id="4.8.21.1"></a>

**1.** 如果仲裁人裁定提提乌斯不欠塞伊乌斯任何款项，即使没有禁止塞伊乌斯提起请求，若他提出请求，仍被视为违反仲裁裁决。奥菲利乌斯和特雷巴提乌斯都作出了这样的答复。

<a id="4.8.21.2"></a>

**2.** 我认为，仲裁人可以规定给付期限；特雷巴提乌斯似乎也持此见解。

<a id="4.8.21.3"></a>

**3.** 庞波尼乌斯说，仲裁人作出不确定的裁决无效，例如：“把你所欠的数额还给他”；“应遵从你们的分割”；“按你向债权人清偿的份额收取”。

<a id="4.8.21.4"></a>

**4.** 又如，如果仲裁人禁止当事人请求给付仲裁协议所约定的罚金，我在庞波尼乌斯《告示评注》第三十三卷中读到，此种裁决无效；这有其道理，因为仲裁协议并未将罚金本身交由仲裁裁断。

<a id="4.8.21.5"></a>

**5.** 帕皮尼安在《问题集》第三卷中说，如果仲裁协议期限届满时，当事人延长了期限并再次约定由同一仲裁人裁断，但该仲裁人没有接受第二次仲裁，若他本人并无延误履职，则不应强迫其接受；如果是由于他的原因导致此事发生，最公平的做法是由裁判官强迫其接受后续仲裁。只有在先前的仲裁协议没有约定延长期限时，此问题才会出现；若协议有此约定而仲裁人已经延长期限，他仍是仲裁人。

<a id="4.8.21.6"></a>

**6.** 仲裁协议约定就“事项或争议”进行仲裁的，称为完整仲裁协议，因为它涵盖所有争议。但如果实际只就一件事发生争议，即使当事人订立了完整仲裁协议，其他事由所生的诉讼仍然保留；因为只有当事人约定提交仲裁的事项才属于仲裁范围。不过，如果有人准备就某一确定事项订立仲裁协议，最好在协议中仅列明该事项。

<a id="4.8.21.7"></a>

**7.** 如果仲裁人命令当事人做不正当之事，当事人不应服从。

<a id="4.8.21.8"></a>

**8.** 如果仲裁人在仲裁协议期限届满前受理案件，却命令当事人在期限届满后到场，不会发生罚金责任。

<a id="4.8.21.9"></a>

**9.** 如果诉讼当事人因患病、公共事务、担任公职或其他正当理由而无法到场，普罗库鲁斯和阿提利基努斯说，罚金责任仍会发生；但如果该当事人准备与同一仲裁人重新订立仲裁协议，就应拒绝罚金之诉，或准许其援用抗辩获得保护。只有在仲裁人准备再次接受仲裁时，这种说法才成立；因为尤利安在《学说汇纂》第四卷中正确地写道，不得强迫仲裁人违背本人意愿接受仲裁。即使如此，该当事人仍可免于罚金责任〔译疑：*ipse* 的指称及罚金责任归属待核〕。

<a id="4.8.21.10"></a>

**10.** 如果双方在罗马订立仲裁协议，仲裁人却命令他们到行省出席，是否可以不受罚金追究而不服从，尚有疑问。较妥当的意见是，尤利安在《学说汇纂》第四卷所说正确：应视为仲裁协议包含了当事人约定的地点。因此，如果仲裁人命令他们到别处出席，他们不服从也不会受到罚金追究。那么，如果看不出当事人约定了何处，应如何处理？较好的说法是，应以订立仲裁协议之地为准。但如果仲裁人命令当事人在靠近罗马的地方出席呢？佩加苏斯认为该命令有效。我认为，只有在仲裁人的声望足以使他通常可以在郊外处理事务，且当事人能够方便地前往该处时，此说才正确。

<a id="4.8.21.11"></a>

**11.** 但如果仲裁人命令当事人前往不体面的场所，例如维维安努斯所说的酒馆或妓院，当事人显然可以不受罚金追究而不服从。凯尔苏斯在《学说汇纂》第二卷中也赞同这一见解。他还巧妙地讨论了如下情形：某处是其中一名当事人不可能体面前往、另一名当事人却可以前往的场所；能够不失体面地前往之人没有到场，而前往会有失体面之人到场，那么是否发生仲裁协议的罚金责任，或者是否视为未履行出席义务？他正确地认为罚金不发生，因为仲裁人的命令对一方有效、对另一方无效，实属荒谬。

<a id="4.8.21.12"></a>

**12.** 还须考察，如果未按仲裁人命令给付，应在多长时间后发生要式承诺的罚金责任。如果没有规定期限，凯尔苏斯在《学说汇纂》第二卷中写道，应视为包含了一段合理的短暂期间；期间届满后，就可以立即请求给付罚金。但他说，即便当事人在罚金诉讼正式成立之前已经给付，也不得依据要式承诺起诉：

### <a id="4.8.22"></a>4.8.22　保罗《评告示》第十三卷

除非债权人有利益要求在当时给付。

### <a id="4.8.23"></a>4.8.23　乌尔比安《评告示》第十三卷

<a id="4.8.23.pr."></a>

**序言（pr.）** 凯尔苏斯说，如果仲裁人命令在九月初一之前给付，但届期未付，即使后来提出给付，已经发生的仲裁罚金责任也不会消灭，因为未在九月初一之前给付这一事实始终成立。但如果提出给付后对方接受了，就不能请求罚金；对方可以援用恶意抗辩将此请求排除。若仲裁人仅命令给付，而未规定期限，则另当别论。

<a id="4.8.23.1"></a>

**1.** 凯尔苏斯还说，如果仲裁人命令我向你给付，而你因病或其他正当理由不能受领，普罗库鲁斯认为不发生罚金责任；即使过了九月初一，你已准备好受领而我仍不支付，也不发生罚金责任。但凯尔苏斯本人正确地认为，仲裁人作出了两项命令：一项是给付金钱，另一项是在九月初一之前给付。因此，虽然未能在九月初一之前给付并非由我造成，不会因此产生罚金责任，但我仍会因未作给付而承担责任。

<a id="4.8.23.2"></a>

**2.** 凯尔苏斯还说，遵守裁决，是指当事人尽其所能服从仲裁人的裁决。

<a id="4.8.23.3"></a>

**3.** 同一凯尔苏斯说，如果仲裁人命令我在确定日期向你给付金钱，而你拒绝受领，可以依法律本身主张罚金责任并未发生。

### <a id="4.8.24"></a>4.8.24　保罗《评告示》第十三卷

但是，如果此后对方准备受领，而我不予给付，就不能免责；因为我先前并未给付。

### <a id="4.8.25"></a>4.8.25　乌尔比安《评告示》第十三卷

<a id="4.8.25.pr."></a>

**序言（pr.）** 拉贝奥说，如果仲裁协议约定仲裁人须在同一天就所有事项作出裁决，并可延长期限；但仲裁人只对部分事项作出裁决，对其余事项没有裁决便延长期限，那么延期有效，且当事人可以不受罚金追究而不服从其裁决。庞波尼乌斯赞同拉贝奥的意见，我也认为如此，因为仲裁人尚未履行其裁决职责。

<a id="4.8.25.1"></a>

**1.** “延长仲裁期限”这一条款只赋予仲裁人延长期限的权限，因此他不得缩减或变更最初仲裁协议的条件；所以，他还必须审理其余事项，并就全部事项作出一项裁决。

<a id="4.8.25.2"></a>

**2.** 如果最初的仲裁协议有保证人提供担保，拉贝奥说，延期后的协议也应由保证人担保。但庞波尼乌斯对此有所疑问：应由同一批保证人担保，还是也可以由其他同样适格的人担保？他说，如果原保证人不愿继续提供担保，又该如何？我认为，如果原保证人拒绝担保，就应另行提供资力不低于原保证人的人，

### <a id="4.8.26"></a>4.8.26　保罗《评告示》第十三卷

以免保证人日后拒绝承担责任，便使罚金责任发生；保证人死亡时也应如此处理。

### <a id="4.8.27"></a>4.8.27　乌尔比安《评告示》第十三卷

<a id="4.8.27.pr."></a>

**序言（pr.）** 仲裁人可以亲自、通过信使或通过书信延长仲裁期限。

<a id="4.8.27.1"></a>

**1.** 如果仲裁协议没有提及继承人或其他继受人，任何一方死亡都会使仲裁协议解除。我们不采纳拉贝奥的意见：他认为，如果仲裁人命令某人给付金钱，而此人在给付前死亡，即使其继承人准备提出给付，罚金责任仍然发生。

<a id="4.8.27.2"></a>

**2.** 仲裁人的裁决，无论公平与否，当事人都应遵守；订立仲裁协议者应自行承担后果。神皇庇护的敕答还补充说：“即使裁决较不合理，也应当心平气和地接受。”

<a id="4.8.27.3"></a>

**3.** 如果有数名仲裁人，而他们作出了不同裁决，当事人可以不遵守该裁决；但若多数仲裁人的意见一致，就应遵守多数意见，否则将发生罚金责任。尤利安因此讨论：三名仲裁人中，一人判给十五，一人判给十，第三人判给五，应遵从哪项裁决？尤利安写道，应给付五，因为三人都同意至少给付这一数额。

<a id="4.8.27.4"></a>

**4.** 如果诉讼当事人因其自身原因而未能到场参与仲裁，罚金责任就会发生。因此，除非仲裁协议特别约定一方或双方缺席时也可以作出裁决，否则不在当事人面前作出的裁决无效；但缺席者仍承担罚金责任，因为是他导致仲裁无法进行。

<a id="4.8.27.5"></a>

**5.** 仲裁人向有理解能力者宣告裁决，才视为在当事人面前作出；若当事人是精神失常者或痴呆者，就不视为当面宣告。对未成年人也不视为已当面宣告裁决，除非监护人在场。尤利安在《学说汇纂》第四卷中对上述各点均有论述。

<a id="4.8.27.6"></a>

**6.** 如果有人在场阻止仲裁人作出裁决，罚金责任就会发生。

<a id="4.8.27.7"></a>

**7.** 但如果仲裁协议没有约定罚金，而仅约定当事人应遵从裁决，则可以对违约者提起不确定给付之诉。

### <a id="4.8.28"></a>4.8.28　保罗《评告示》第十三卷

约定的金额是确定还是不确定，并不重要，例如约定“该物价值多少即给付多少”。

### <a id="4.8.29"></a>4.8.29　乌尔比安《评告示》第十三卷

如果当事人向仲裁人禁止请求给付之人提出请求，就构成违反仲裁裁决。那么，如果当事人转而向该人的保证人请求给付，是否会发生罚金责任？我认为会发生；萨宾也这样写道，因为他实质上是在向被告请求给付。〔译疑：底本此处作 *ty dunamei*，疑为希腊语“τῇ δυνάμει”，即“在效果上”。〕但如果我与保证人订立仲裁协议，而对债务人提出请求，除非保证人对此有利害关系，否则不发生罚金责任。

### <a id="4.8.30"></a>4.8.30　保罗《评告示》第十三卷

如果有人将已交付仲裁的事项诉诸法院，有些人说裁判官不应介入并强迫仲裁人作出裁决，因为此时罚金责任不可能发生，仲裁协议仿佛已经解除。但若采纳此说，后果将是：任何后悔订立仲裁协议的人，都可以由自己决定如何规避该协议。因此，当事人将事项交由法官依通常程序审理时，对该方应发生罚金责任。

### <a id="4.8.31"></a>4.8.31　乌尔比安《评告示》第十三卷

只有在要式承诺的受益人没有恶意欺诈时，才会发生要式承诺的罚金责任；订立要式承诺的条件正是任何人不得从自己的欺诈中获利。但如果仲裁协议还约定“若在此事中有任何欺诈”，就可以依据要式承诺之诉起诉实施欺诈者。因此，如果有人以金钱或拉拢手段贿赂仲裁人，或贿赂对方的律师，或贿赂受托处理己方案件的人，或者狡诈地蒙骗对方，凡是在该诉讼中以欺诈行事的，都可以依据要式承诺之诉起诉。由此，对方如果想提起恶意欺诈之诉，就不应准许，因为他已有要式承诺之诉。若仲裁协议没有写入此类条款，则可以适用恶意欺诈之诉或恶意欺诈抗辩。包含恶意欺诈条款的仲裁协议，才是完整的仲裁协议。

### <a id="4.8.32"></a>4.8.32　保罗《评告示》第十三卷

<a id="4.8.32.pr."></a>

**序言（pr.）** 在仲裁协议中，我们不区分所约定的罚金高于还是低于争议事项的价值。

<a id="4.8.32.1"></a>

**1.** 如果罚金责任已经发生，就不强迫仲裁人作出裁决。

<a id="4.8.32.2"></a>

**2.** 如果妇女以他人名义订立仲裁协议，由于禁止女性为他人承担债务，不视为约定了罚金。

<a id="4.8.32.3"></a>

**3.** 总而言之，无论是仲裁协议自始无效，还是协议虽有效但其罚金能否请求尚未确定，抑或仲裁协议后来因期限届满、死亡、正式免债、诉讼或协议而解除，使罚金责任消灭，裁判官都不应介入。

<a id="4.8.32.4"></a>

**4.** 如果仲裁人后来担任祭司，须考察是否仍应强迫其作出裁决。因为不仅应当顾及此人的尊荣，也应当顾及神的威严；祭司理应专心从事神圣礼仪。反之，如果他是在接受仲裁之后才担任祭司，就必须无论如何作出裁决。

<a id="4.8.32.5"></a>

**5.** 又如，如果相关事务已经和解，或者仲裁协议所涉之人已经死亡，也不应强迫仲裁人作出裁决；但在后一种情况下，如果任何诉讼当事人仍有利害关系，则属例外。

<a id="4.8.32.6"></a>

**6.** 尤利安不加区分地写道：如果当事人错误地将涉及可能导致名誉受损的犯罪、或已设立公诉程序的事项提交仲裁，例如通奸、杀人或类似事项，裁判官应禁止仲裁人作出裁决，也不得执行已经作出的裁决。

<a id="4.8.32.7"></a>

**7.** 关于自由身份的争议，即使订立了仲裁协议，也不得正确地强迫仲裁人作出裁决，因为自由受优待，此类案件应交由资历较高的法官审理。无论争议涉及自由出生身份、被释自由人身份，还是依据遗嘱信托主张应获自由，均应适用相同规则。公益诉讼亦同。

<a id="4.8.32.8"></a>

**8.** 如果奴隶订立了仲裁协议，不得强迫仲裁人作出裁决；即使他作出了裁决，也不得从奴隶的特有产中执行罚金。奥克塔维努斯持此意见。但如果自由人与奴隶订立仲裁协议，能否对自由人执行罚金？我们考察后认为，较妥当的做法是不予执行。

<a id="4.8.32.9"></a>

**9.** 又如，某人在罗马订立仲裁协议，后来作为使节来到罗马，仲裁人不应被强迫作出裁决；这与他在诉讼已经正式成立后，不应被强迫继续进行该诉讼相同。此前他是否已经担任使节，并无区别。但如果他是在担任使节期间订立仲裁协议，我认为应强迫仲裁人作出裁决，因为即使他自愿接受了诉讼，也会被强迫完成诉讼。不过，有些人对此仍有疑问，而这种疑问并不正确。尤其是在使节任期内就该任期内订立的事务作出仲裁协议时，更不应有疑问，因为就该事项提起诉讼，也会强迫他接受审理。第一种情形仍可进一步考察：如果某人在担任使节之前订立仲裁协议，而后在其本人担任使节时请求强迫仲裁人作出裁决，是否应予准许？按照前述理由，这似乎不公平，因为这将取决于他本人的意愿。但这种情形就像他决定是否提出诉讼请求一样，后者本来由他决定。我们应当将这种仲裁协议比照普通诉讼处理：除非他应诉，否则不得准许他请求仲裁人作出裁决。〔译疑：本段关于担任使节的时间、谁请求强制仲裁及其与普通诉讼的类比，句法关系较为压缩。〕

<a id="4.8.32.10"></a>

**10.** 如果有人对遗产提起争议，而他曾与死者订立仲裁协议，那么仲裁人作出裁决会对遗产继承产生先决影响；因此，仲裁人应暂时停止裁决。

<a id="4.8.32.11"></a>

**11.** 仲裁协议的期限可以延长；如果不是双方协议延长，而是必须由仲裁人命令延长，以免罚金责任发生，也可以延长。

<a id="4.8.32.12"></a>

**12.** 如果仲裁人躲藏起来，裁判官应当查找他；如果他长期不服从，就应对他科处罚金。

<a id="4.8.32.13"></a>

**13.** 如果仲裁协议交由多人裁断，并约定任何一人或其中一人作出的裁决均应遵守，那么即使其他人缺席，也应强迫在场者作出裁决。但如果约定所有人都必须作出裁决，或应遵守多数人的意见，就不应分别强迫每一个仲裁人，因为任何一人的单独意见都不足以使罚金责任发生。

<a id="4.8.32.14"></a>

**14.** 有一名仲裁人因其他事由而明显对当事人怀有敌意，当事人甚至正式告诫他不要作出裁决；然而他并未受到任何强迫，仍坚持作出裁决。神皇安敦宁在一名当事人提出申诉后批复说，该当事人可以援用恶意欺诈抗辩。后来，受理罚金请求的法官向皇帝请示，皇帝又作出敕答：即使不得上诉，也可以在请求罚金时援用恶意欺诈抗辩予以阻却。因此，该抗辩在一定程度上具有上诉的作用，因为当事人可以据此请求重新审查仲裁人的裁决。

<a id="4.8.32.15"></a>

**15.** 讨论仲裁人的职责时，应当知道，一切处理均须以仲裁协议本身为依据；仲裁人只能办理协议约定由其办理的事项。因此，仲裁人不得任意作出裁定，也不得就任意事项作出裁定；其权限仅及于仲裁协议所涉事项及约定的范围。

<a id="4.8.32.16"></a>

**16.** 关于仲裁人应作出何种裁决，已有讨论；虽然有些事项上意见不一，但并非任何内容都可以成为裁决。我认为，如果仲裁人命令当事人诉诸法官，或者另行订立仲裁协议，就不发生罚金责任。尤利安也说，如果仲裁人命令当事人转向另一仲裁人，当事人可以不受处罚地不服从，否则争议将永无终结。但如果仲裁人裁决土地应按照普布利乌斯·梅维乌斯的裁断交付，或应提供担保，当事人就应服从裁决。佩狄乌斯也赞同此说：仲裁人应以自己的裁决终结争议，以免仲裁一再延长，或有时转交给当事人的敌人；若只是延期或转交他人，争议就没有终结。如何提供担保、由哪些保证人担保，也属于裁决的一部分；仲裁人不得将此事项委托他人决定，除非仲裁协议约定由仲裁人决定应依谁的裁断提供担保。〔译疑：本段对“另行提交他人仲裁”与“按指定第三人的判断提供担保”作了区别，后半关于担保裁量的句法较难。〕

<a id="4.8.32.17"></a>

**17.** 又如，如果仲裁人命令当事人让另一人加入仲裁，而仲裁协议没有这样的约定，他就没有作出有效裁决，因为裁决必须针对提交仲裁的事项，而当事人并未就此约定仲裁。

<a id="4.8.32.18"></a>

**18.** 如果相互作出要式承诺的本人希望由各自代理人在仲裁人面前处理事务，仲裁人也可以命令本人亲自到场。

<a id="4.8.32.19"></a>

**19.** 如果仲裁协议提及继承人，仲裁人也可以命令继承人到场。

<a id="4.8.32.20"></a>

**20.** 仲裁人的职责还包括规定如何交付无负担的占有。是否也包括要求所有权人承诺追认？塞克斯图斯·佩狄乌斯认为，这没有道理，因为如果所有权人不予追认，罚金要式承诺就会发生效力。

<a id="4.8.32.21"></a>

**21.** 仲裁人不得处理仲裁协议范围以外的事项，因此必须约定可以延长仲裁期限；否则，当事人可以不受处罚地不服从仲裁人命令。

### <a id="4.8.33"></a>4.8.33　帕皮尼安《问题集》第一卷

双方选定的仲裁人如果有权延长仲裁期限，就可以延长期限；但当事人反对时，他不得将此事转交他人处理。〔译疑：*referre* 在此处是否指将事项转交他人或另作报告，待核。〕

### <a id="4.8.34"></a>4.8.34　保罗《评告示》第十三卷

<a id="4.8.34.pr."></a>

**序言（pr.）** 如果两人共同作为债权人或债务人，其中一人订立了仲裁协议，并被禁止请求给付或禁止对其请求给付，那么如果另一人提出请求或被他人请求，是否发生罚金责任？两名共同经营且姓名一并列入账簿的银行家，也适用同一规则。也许，只有在他们是合伙人时，我们才可以将这种情形与保证人相类比；否则，既不是你向我请求，也不是我请求，也不是以我的名义提出请求，即使请求确实是向你提出的。〔译疑：*duo rei* 及后半的共同债权、共同债务与合伙关系压缩难明。〕

<a id="4.8.34.1"></a>

**1.** 我认为，罚金责任一经发生，就更应当说仲裁协议已经解除，且不可能再次发生罚金责任；但如果双方约定每一事项或每次违约都可分别发生罚金责任，则属例外。

### <a id="4.8.35"></a>4.8.35　盖尤斯《评行省告示》第五卷

未成年人未经监护人同意而订立仲裁协议的，不得强迫仲裁人作出裁决，因为若裁决对未成年人不利，他不承担罚金责任；但如果他提供了保证人，则可以向保证人请求罚金。尤利安也持此见解。

### <a id="4.8.36"></a>4.8.36　乌尔比安《评告示》第七十七卷

如果裁判官在法定休庭日强迫仲裁人作出裁决，并有人请求仲裁协议的罚金，通常认为不得援用抗辩；但如果另有法律明确排除了作出裁决的那一法定休庭日，则属例外。

### <a id="4.8.37"></a>4.8.37　凯尔苏斯《学说汇纂》第二卷

即使仲裁人禁止一方当事人向另一方请求给付，如果继承人提出了请求，仍会发生罚金责任；当事人选择仲裁，是为了终结争讼，而不是拖延争讼。

### <a id="4.8.38"></a>4.8.38　莫德斯丁《法则集》第六卷

请求仲裁协议罚金时，应判令违反约定者承担责任；其对方当事人是否有利害关系要求遵守仲裁人裁决，并不重要。

### <a id="4.8.39"></a>4.8.39　雅沃勒努斯《评卡西乌斯》第十一卷

<a id="4.8.39.pr."></a>

**序言（pr.）** 并非所有不遵守仲裁人裁决的情形都会发生仲裁协议的罚金责任；只有裁决涉及给付金钱或提供劳务时，才会发生罚金责任。仲裁人也可以惩罚当事人的抗命，命令其向对方给付金钱；但没有按仲裁裁决出示证人姓名，不应归入此类情形。

<a id="4.8.39.1"></a>

**1.** 仲裁人有权延长仲裁期限且已命令延期时，一方当事人的迟延会使另一方得以请求罚金。

### <a id="4.8.40"></a>4.8.40　庞波尼乌斯《异读集》第十一卷

仲裁人命令当事人在一月初一到场，但在该日到来之前便已死亡；其中一名诉讼当事人没有到场。毫无疑问，罚金绝不发生。阿里斯托说，他听卡西乌斯说过：如果仲裁人本人没有到场，就不发生罚金；正如塞尔维乌斯所说，如果受要式承诺约束的一方阻止另一方受领，也不发生罚金。

### <a id="4.8.41"></a>4.8.41　卡利斯特拉图斯《警示告示》第一卷

《尤利娅法》规定不得强迫未满二十岁者担任法官，因此任何人都不得选任未满二十岁者为仲裁裁断人；其裁决绝不会使罚金责任发生。但许多人说，年满二十岁而未满二十五岁者，如果轻率地接受了仲裁职务，应基于此事获得救济。

### <a id="4.8.42"></a>4.8.42　帕皮尼安《答复集》第二卷

仲裁人命令在确定期限内返还奴隶；由于奴隶未获返还，仲裁人依仲裁协议的规定判令将罚金给付国库。国库并未因该裁决取得任何利益，但由于当事人未服从仲裁人所定期限，仍发生要式承诺约定的罚金责任。

### <a id="4.8.43"></a>4.8.43　斯凯沃拉《答复集》第一卷

卢基乌斯·提提乌斯与梅维乌斯·塞姆普罗尼乌斯就所有事项和争议订立仲裁协议；但卢基乌斯·提提乌斯因疏忽，没有将若干事项列入其请求，仲裁人也没有对这些事项作出裁决。有人问：是否还可以就遗漏的事项提出请求？我答复说，可以提出请求，且不发生仲裁协议的罚金责任。但如果他是恶意这样做，虽然仍可提出请求，却应承担罚金责任。

### <a id="4.8.44"></a>4.8.44　斯凯沃拉《学说汇纂》第二卷

卡斯特利安努斯与塞伊乌斯之间发生了边界争议，双方选定一名仲裁人，由其裁定争议事项。仲裁人在双方当事人到场时作出裁决并划定边界。有人问：如果卡斯特利安努斯一方不遵守仲裁裁决，是否发生仲裁协议的罚金责任？我答复说，既然仲裁人是在双方当事人均到场时作出裁决，而裁决未获遵守，罚金责任就已发生。

### <a id="4.8.45"></a>4.8.45　乌尔比安《评萨宾》第二十八卷

仲裁协议中针对特定人所作的安排，不得延及该人以外者。

### <a id="4.8.46"></a>4.8.46　保罗《评萨宾》第十二卷

仲裁人只能裁决订立仲裁协议之初当事人之间已经存在的事项、账目和争议，不能裁决此后才发生的事项。

### <a id="4.8.47"></a>4.8.47　尤利安《学说汇纂》第四卷

<a id="4.8.47.pr."></a>

**序言（pr.）** 如果仲裁协议约定仲裁人应当在双方当事人或其继承人到场时作出裁决，而一方当事人死亡并留下未成年人作为继承人，那么除非监护人同意参与，否则不视为已有效作出裁决。

### <a id="4.8.50"></a>4.8.50　阿尔费努斯《学说汇纂》第七卷

仲裁人受双方选定，但在仲裁协议约定的期限届满前无法作出裁决，于是命令延长仲裁期限；其中一名诉讼当事人没有服从。有人问，是否可以依据仲裁协议向其请求罚金？我答复说，不可以，因为双方并未授权仲裁人作出这种命令。

### <a id="4.8.51"></a>4.8.51　马尔基安《法则集》第二卷

如果某人就自己的事务被选为仲裁人，他不得作出裁决，因为那将使他命令自己作为一方当事人履行义务，或禁止自己提出请求；任何人都不能命令自己，也不能禁止自己。

### <a id="4.8.52"></a>4.8.52　马尔基安《法则集》第四卷

如果仲裁人命令某人依据仲裁协议给付金钱，而此人迟延给付，就应承担仲裁协议约定的罚金；但如果此后他实际给付了，就免于罚金责任。
