# 第四卷

## 4.1　论恢复原状救济（De in integrum restitutionibus）

<a id="1"></a><a id="4.1"></a>

### <a id="4.1.1"></a>4.1.1　乌尔比安《评告示》第十一卷

本题无需另行说明其重要性，因为题目本身已足以表明。裁判官在本题之下，于多种情形中向受损或受欺诈之人提供救济：无论其是因恐惧、诡计、年龄或缺席而陷入损害，均属此列。

### <a id="4.1.2"></a>4.1.2　保罗《格言集》第一卷

或者是由于身份变更，或者是由于正当错误。

### <a id="4.1.3"></a>4.1.3　莫德斯丁《学说汇纂》第八卷

裁判官承诺给予的一切恢复原状救济，均须在审查事由后作出；也就是说，裁判官要审查这些事由是否正当，并查明其所据以分别给予救济的情形是否真实。

### <a id="4.1.4"></a>4.1.4　卡利斯特拉图斯《告示警示篇》第一卷

我知道，有人遵循这样一种做法：如果请求恢复原状所涉事项或数额极小，而准许该请求将对较大的事项或数额造成先决影响，则不听取该请求人的主张。

### <a id="4.1.5"></a>4.1.5　保罗《评告示》第七卷

凡裁判官承诺给予恢复原状者，似乎无人会因其所涉事项而被排除在外。

### <a id="4.1.6"></a>4.1.6　乌尔比安《评告示》第十三卷

不仅未满二十五岁者的继承人可以获得恢复原状，因公共事务而缺席者的继承人，以及所有本人原本可以获得恢复原状之人的继承人，也都可以获得恢复原状；这一点已被屡次确认。因此，无论是继承人、获返还遗产之人，还是军人家子之继承人，均可获得恢复原状。由此，如果未成年人被降为奴隶或成为女奴，也应允许其主人在法定期限内请求恢复原状。又如，该未满二十五岁者在接受遗产时受到欺骗，尤利安在《学说汇纂》第十七卷中写道，其主人可以选择不承受该遗产；即使其年龄本身不提供保护，亦可如此。因为他们利用法律上的利益，并非为了取得遗产，而是为了报复。

### <a id="4.1.7"></a>4.1.7　马尔凯鲁斯《学说汇纂》第三卷

<a id="4.1.7.pr."></a>

**序言（pr.）** 神皇安敦尼努斯就如何救济因缺席而败诉之人，曾向裁判官马尔基乌斯·阿维图斯作出如下答复：“通常的正式程序固然不应轻易变更；然而，在明显的衡平要求救济之处，仍应予以救济。因此，如果某人经传唤而未应答，并因此按通常程序作出裁判，但你当时正坐于审判席上，他随即前来，那么可以认为，他并非因自身过错而缺席，而是未能充分听见传唤人的声音；故可以准许其恢复原状。”

<a id="4.1.7.1"></a>

**1.** 此类救济并不只限于上述情形：无过错而受欺骗之人，尤其是因对方欺诈而受骗者，也应获得救济。既然通常可以提起恶意欺诈之诉，那么，衡平原则要求如此时，善良的裁判官宁可恢复原诉讼，也不应设置使被告蒙受不名誉的诉讼；只有在已无其他救济途径时，才应采用后一诉讼。

### <a id="4.1.8"></a>4.1.8　马克尔《论上诉》第二卷

未满二十五岁者与因公共事务而缺席者之间，区别在于：未满二十五岁者即使已由其监护人或保佐人出庭为其辩护，仍可在对抗国家的一方获得恢复原状，但须经审查事由。至于因公共事务而缺席之人，以及处于同一情形的其他人，如果已由其代理人出庭为其辩护，通常仅在允许其提起上诉的范围内，通过恢复原状获得救济。
