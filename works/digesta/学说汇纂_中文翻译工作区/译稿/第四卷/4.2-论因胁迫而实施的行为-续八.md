### <a id="4.2.21"></a>4.2.21　保罗《评告示》第十一卷

<a id="4.2.21.pr."></a>

**序言（pr.）** 如果一名女释奴对其释奴保护人忘恩负义，且明知自己有此行为；当其自由身份受到威胁时，为避免被重新降为奴隶而向释奴保护人给付或承诺财物，则本告示不适用，因为这种恐惧是她自己招致的。

<a id="4.2.21.1"></a>

**1.** 凡因胁迫而实施的行为，裁判官在任何时候均不予认可。

<a id="4.2.21.2"></a>

**2.** 某人交付了自己并非所有的土地之占有时，所获金额应按占有本身的价值计算，而非按土地价值计算；他可请求该价值的四倍额或单倍额，并连同孳息一并请求。因为应按须恢复的内容、也就是实际缺失的部分进行估价；而实际缺失的是土地的单纯占有及其孳息。庞波尼乌斯也持此说。

<a id="4.2.21.3"></a>

**3.** 如果有人因胁迫而承诺提供嫁资，我认为并未产生债务，因为确实可以说，这样的嫁资承诺根本不成立。

<a id="4.2.21.4"></a>

**4.** 如果我因受胁迫而退出买卖或租赁，就应当考察：是否可视为没有发生任何行为，原有债务关系仍然存续；或者，这是否类似于正式免债行为。由于诚信契约债务一经放弃即告消灭，我们便无法再依据该债务主张；较妥当的看法是，此种情形类似正式免债行为，因此产生裁判官法上的诉讼。

<a id="4.2.21.5"></a>

**5.** 如果我因胁迫而接受遗产，我认为自己仍成为继承人；因为即使我在自由意志下不会接受，我仍是在受迫情况下表示了接受。但裁判官应使我恢复原状，以便我能够选择不承受该遗产。

<a id="4.2.21.6"></a>

**6.** 如果我因受胁迫而拒绝遗产，裁判官以两种方式救济我：或者给予我如同继承人一般的准诉权，或者给予我胁迫之诉；我选择哪一种途径，就应向我开放哪一种途径。

### <a id="4.2.22"></a>4.2.22　保罗《格言集》第一卷

有人将他人投入监狱以勒取财物的，因这一目的所实施的一切行为均不发生法律效力。

### <a id="4.2.23"></a>4.2.23　乌尔比安《意见集》第四卷

<a id="4.2.23.pr."></a>

**序言（pr.）** 如果某人在城内声称自己具有显赫身份，却被迫不公正地清偿并不负担的债务，这种说法并不可信，因为他本可援引公法，并向有权势者求助；后者必会阻止他遭受暴力。但是，若要推翻这种推定，他就必须提出极为明确的暴力证据。

<a id="4.2.23.1"></a>

**1.** 如果有权势的对方以正当恐惧相威胁，声称要将某人带去接受审理，令其如同囚犯一般前往；此人因而被迫出售其本有权保有的财物，则行省总督应使该财物恢复至合乎衡平的状态。

<a id="4.2.23.2"></a>

**2.** 如果放债人以不正当方式拘禁运动员，并禁止其参加比赛，进而迫使其就超过债务数额的款项提供担保；上述事实得到证明后，有管辖权的法官应裁定使该事项恢复至合乎衡平的状态。

<a id="4.2.23.3"></a>

**3.** 如果有人在行省总督的属员介入、但未经法官审理的情况下，因暴力而受迫，依对方指示向其交付本不欠对方之物，法官应命令由造成该财产损失之人返还以不正当方式强取之物。反之，如果某人依简单命令清偿了所欠债务，虽说此类征收本应循通常司法程序而不应以非常方式进行，但既然相关款项已用于清偿其债务，再将其追回便有失公平。
