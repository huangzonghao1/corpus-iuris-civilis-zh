## <a id="7"></a><a id="4.7"></a>4.7.0　论为改变诉讼而实施的财产转让（*De alienatione iudicii mutandi causa facta*）

### <a id="4.7.1"></a>4.7.1　盖尤斯《评行省告示》第四卷

<a id="4.7.1.pr."></a>

**序言（pr.）** 总督以各种方式确保任何人都不因他人的行为而使自身处境恶化。他认识到，在诉讼中，若另有一名对方当事人被置于我们面前，诉讼结果有时会对我们更加不利；因此，他也就此作了规定：如果有人通过转让财物，以另一人取代我们原来的对方当事人，并且故意如此行事以损害我们，那么我们可以对其提起事实之诉，要求其承担相当于“我们没有另一名对方当事人”这一利益的金额。

<a id="4.7.1.1"></a>

**1.** 因此，如果某人使来自另一行省的人，或者一名势力比我们更强的人，成为我们的对方当事人，他就应承担责任：

### <a id="4.7.2"></a>4.7.2　乌尔比安《评告示》第十三卷

或者，他以另一名将要骚扰对方当事人的人取而代之：

### <a id="4.7.3"></a>4.7.3　盖尤斯《评行省告示》第四卷

<a id="4.7.3.pr."></a>

**序言（pr.）** 因为即使我对来自另一行省的人提起诉讼，也必须在其所属行省起诉；而我们无法与势力比我们更强的人处于平等地位。

<a id="4.7.3.1"></a>

**1.** 又如，如果某人解放了我们原本请求返还之人，我们的处境也会恶化，因为裁判官偏袒自由。

<a id="4.7.3.2"></a>

**2.** 同样，如果你转让了你曾在其上施工的土地，而你因该施工原本须受“以暴力或秘密方式实施行为”禁令程序（*interdictum quod vi aut clam*）或“防止雨水妨害”之诉（*actio aquae pluviae arcendae*）追究，那么可以认定我们的处境已经恶化。因为若对你提起诉讼，你本应自费拆除该工程；但现在，我的诉权开始指向另一人，而非施工者，我便被迫自费拆除该工程，因为该占有人所持有的是他人施工的工程。你在这些诉讼中承担责任的范围，仅在于必须容许该工程被拆除。

<a id="4.7.3.3"></a>

**3.** 又如，我已向你通知不得继续施工，而你随后转让了该土地，买受人又继续施工；据说，此时可以依本诉追究你。因为我既不能依据新工程通知（*operis novi nuntiatio*）对你起诉——你并未实施任何施工，也不能对你转让土地之人起诉——因为没有向他作出通知。

<a id="4.7.3.4"></a>

**4.** 由此可见，总督承诺给予恢复原状救济，其效果是：原告可通过本诉，依裁判人职权取得相当于“没有另一名对方当事人”这一利益的金额。例如，因他人被置换为对方当事人而支出的费用，或因此遭受的其他不利，均可计入。

<a id="4.7.3.5"></a>

**5.** 那么，如果有权对其提起此类诉讼之人，愿意接受一项有用诉讼，仿佛其本人仍占有该物，又该如何处理？应当认为，依据本告示对其提起的诉讼应予拒绝。

### <a id="4.7.4"></a>4.7.4　乌尔比安《评告示》第三卷

<a id="4.7.4.pr."></a>

**序言（pr.）** 同样，如果财物已被受让人经时效取得，而不能向此人请求返还，本告示即适用。

<a id="4.7.4.1"></a>

**1.** 也可能出现这样的情形：某人确实并非出于恶意而停止占有，但其目的在于改变诉讼；类似情形还有许多。也可能有人出于恶意停止占有，却并非为了改变诉讼，因此不受本告示约束；因为仅仅放弃占有的人，并不属于转让财物。不过，裁判官并不谴责这样一种人的行为：此人认为，宁可放弃该物，也不愿因此反复诉讼（这是一种谨慎的考虑；厌恶诉讼之人作此考虑，不应受责难）；裁判官所谴责的仅是另一种人的行为：他仍想保有该物，却把诉讼转移给他人，以便让一个麻烦的对方当事人取代自己。

<a id="4.7.4.2"></a>

**2.** 佩狄乌斯在《评告示》第九卷中说，本告示不仅适用于所有权的转让，也适用于占有的转移；否则，他说，如果有人在对物之诉中退出占有，就不应因此承担责任。

<a id="4.7.4.3"></a>

**3.** 如果某人因疾病、年龄或必要事务而将诉讼转移给他人，不属于应受本告示追究的情形，因为本告示提及的是恶意。除此之外，还可以通过禁令程序并由诉讼代理人参加诉讼；通常，所有权基于正当事由转移给这些代理人。

<a id="4.7.4.4"></a>

**4.** 本告示也适用于地产上的权利，但以恶意转让为限。

<a id="4.7.4.5"></a>

**5.** 本诉仅限于请求利益损失额。因此，如果标的原本不属于原告，或者被转让之人并非因过失而死亡，诉讼即不再进行；但原告另有利益的除外。

<a id="4.7.4.6"></a>

**6.** 本诉并非罚金之诉，而是包含依裁判人裁量进行的对物追索，因此也应给予继承人；但在被告为继承人的情形，

### <a id="4.7.5"></a>4.7.5　保罗《评告示》第十一卷

或者被告为类似之人的情形，

### <a id="4.7.6"></a>4.7.6　乌尔比安《评告示》第十三卷

以及超过一年之后，均不再给予此诉。

### <a id="4.7.7"></a>4.7.7　盖尤斯《评行省告示》第四卷

因为此诉固然具有对物的追索性质，却似乎是基于不法行为而给予的。

### <a id="4.7.8"></a>4.7.8　保罗《评告示》第十二卷

<a id="4.7.8.pr."></a>

**序言（pr.）** 依本告示，也可以追究出示标的之人；如果其未依裁判人的裁量恢复原先的诉讼状态，就应承担责任。

<a id="4.7.8.1"></a>

**1.** 裁判官说：“凡为改变诉讼而实施的转让”；也就是说，是为将来的诉讼而实施的转让，而非针对已经开始的诉讼。

<a id="4.7.8.2"></a>

**2.** 出卖他人财物的人，也被视为实施了转让。

<a id="4.7.8.3"></a>

**3.** 如果某人通过指定继承人或作出遗赠而转让财物，本告示不适用。

<a id="4.7.8.4"></a>

**4.** 如果某人转让财物后又将其取回，就不受本告示追究。

<a id="4.7.8.5"></a>

**5.** 买受人向其出卖人返还标的物以解除买卖（*redhibitio*）的，不被视为为了改变诉讼而转让财物；

### <a id="4.7.9"></a>4.7.9　保罗《评市政营造官告示》第一卷

因为解除买卖返还会使一切回溯至先前状态；因此，行使该项返还的人不被视为为了改变诉讼而转让财物，除非其恰恰是为了这个目的才行使返还，而若非如此本不会返还。〔底文作 *redhibitio homine omnia retro aguntur*；其中 *homine* 疑为讹字，译文依句意按“解除买卖返还使法律关系回溯”处理。〕

### <a id="4.7.10"></a>4.7.10　乌尔比安《评告示》第十二卷

<a id="4.7.10.pr."></a>

**序言（pr.）** 如果我虽负有债务，却已经支付了你本可向我请求的款项，本告示也不适用。

<a id="4.7.10.1"></a>

**1.** 如果受监护人的监护人或精神失常者的宗亲转让财物，可以提起有用之诉，因为监护人或宗亲无法策划此种欺诈。

### <a id="4.7.11"></a>4.7.11　乌尔比安《意见集》第五卷

一名军人要求以自己名义就其声称受赠的占有物进行诉讼。对此答复说：如果该赠与是为了改变诉讼而作出的，就应由原所有人提起诉讼；这样才会被认为，他转给军人的是标的物本身，而非诉讼。

### <a id="4.7.12"></a>4.7.12　马尔西安《法学阶梯》第十四卷

如果某人为了规避共有物分割之诉而转让财物，依《利基尼娅法》，他不得再提起共有物分割之诉。例如，他这样做是为了让势力更强的买受人通过竞价以较低价格取得该物，继而由他自己再次取回。然而，转让共有份额之人若想提起共有物分割之诉，将不被受理；买受人若想提起该诉，则受本告示相应条款禁止，该条款规定不得为改变诉讼而实施任何转让。
