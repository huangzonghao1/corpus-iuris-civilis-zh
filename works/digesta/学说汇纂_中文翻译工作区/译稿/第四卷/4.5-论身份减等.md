# 第四卷

## 4.5　论身份减等者（De capite minutis）

<a id="5"></a><a id="4.5"></a>

### <a id="4.5.1"></a>4.5.1　盖尤斯《评行省告示》第四卷

身份减等（*capitis deminutio*）是身份的变更。

### <a id="4.5.2"></a>4.5.2　乌尔比安《评告示》第十二卷

<a id="4.5.2.pr."></a>

**序言（pr.）** 本告示适用于在保有市民身份的情况下发生的身份减等。至于因丧失市民身份或丧失自由身份而发生的身份减等，则本告示不适用，也不得直接向这些人提起诉讼；但可以对承受其财产之人提起诉讼。〔底本疑误：此处作 *sine amissione civitatis*（“未丧失市民身份”），与前句及下文区分身份减等类型的语义不合；正文依上下文译作“丧失市民身份”，疑底本此处 *sine* 应为 *sive*。〕

<a id="4.5.2.1"></a>

**1.** 裁判官说：“凡男女在与他人发生某项行为或订立某项契约之后，被称为已经身份减等者，我将准许对其提起诉讼，犹如该身份变更未曾发生。”

<a id="4.5.2.2"></a>

**2.** 身份减等者，对于身份减等发生以前既存事由所生的债务，仍负有自然债务；但就本告示的文义而言，若在身份减等之后与其订约，订约之人须自负其责。不过，有时在身份减等之后与其订约，仍应给予诉权；确实，若该人是经自权人收养而成为他权人，则不存在困难，因为他将像家子一样承担债务。

<a id="4.5.2.3"></a>

**3.** 任何人都不会因身份减等而摆脱其不法行为所生的责任。

<a id="4.5.2.4"></a>

**4.** 债权人收养自己的债务人后，该债务人一旦成为自权人，债权人不得恢复对其提起的诉讼。

<a id="4.5.2.5"></a>

**5.** 本诉权为永久诉权，既可针对继承人提起，也可由继承人提起。

### <a id="4.5.3"></a>4.5.3　保罗《评告示》第十一卷

<a id="4.5.3.pr."></a>

**序言（pr.）** 通说认为，随被自权人收养的父亲一同归入收养者家族的子女会发生身份减等，因为他们受他人权力支配，并且改变了家族身份。

<a id="4.5.3.1"></a>

**1.** 儿子及其他人被解放出家父权时，显然会发生身份减等，因为任何人要被解放出家父权，都必须先被置于一种拟制的奴隶身份；奴隶获释的情形则有所不同，因为奴隶身份不享有任何权利，因而也无从发生身份减等：

因为奴隶只有到此时才开始具有法律身份。

### <a id="4.5.5"></a>4.5.5　保罗《评告示》第十一卷

<a id="4.5.5.pr."></a>

**序言（pr.）** 丧失市民身份会导致身份减等，例如被处以水火禁断。

<a id="4.5.5.1"></a>

**1.** 背离其所属权力者会发生身份减等。所谓背离，是指脱离支配自己之人的权力，并投身敌人之列；此外，元老院宣布为敌人或经法律宣布为敌人者，也会发生身份减等，至少达到丧失市民身份的程度。

<a id="4.5.5.2"></a>

**2.** 现在应当考察，哪些权利会因身份减等而消灭。首先考察在保有市民身份的情况下发生的身份减等；可以确定，这种变更不影响公法上的权利，因为此人仍保有官职、元老身份或法官身份。

### <a id="4.5.6"></a>4.5.6　乌尔比安《评萨宾》第五十一卷

其他公职也不会因此终止。身份减等所剥夺的是个人及其家族的私权，而不是市民身份所包含的权利。

### <a id="4.5.7"></a>4.5.7　保罗《评告示》第十一卷

<a id="4.5.7.pr."></a>

**序言（pr.）** 身份减等也不使监护职务当然丧失，但因受他人权力支配者的身份而授予的监护职务除外。因此，依遗嘱、法律或元老院决议指定为监护人的人，仍继续担任监护人；但依据《十二表法》设立的法定监护会因此消灭，理由与此后法定继承也会消灭相同：这类监护与继承授予宗亲，而宗亲因家族身份变更便不再属于该家族。至于新法所设立的继承和监护，通常依自然亲属关系授予特定之人；例如，元老院决议将继承权授予母亲和儿女。

<a id="4.5.7.1"></a>

**1.** 侵害以及其他不法行为所生诉权的债务，随身份而存续。

<a id="4.5.7.2"></a>

**2.** 如果先丧失自由，继而发生身份减等，则不得针对该奴隶给予任何恢复原状救济，因为即使依裁判官的司法管辖权，奴隶也不承担可对其提起诉讼的债务。但是，正如尤利安所说，应当准许对其主人提起准用之诉；若主人不为全部债额提供诉讼上的抗辩，则应准许我对该奴隶曾经拥有的财产实施财产执行。

<a id="4.5.7.3"></a>

**3.** 同样，如果某人丧失市民身份，既丧失财产，又离开市民共同体而一无所有地流亡，则针对他给予恢复原状救济并无衡平可言。

### <a id="4.5.8"></a>4.5.8　盖尤斯《评行省告示》第四卷

可以清楚看出，那些被认为仍负有自然给付义务的债务，不会因身份减等而消灭，因为市民法秩序不能损害自然权利。因此，返还嫁资之诉是依善与公平的标准构成的，即使发生身份减等，该诉权仍继续存在，

### <a id="4.5.9"></a>4.5.9　保罗《评告示》第十一卷

以便该女子日后脱离家父权时仍可提起诉讼。

### <a id="4.5.10"></a>4.5.10　莫德斯丁《辨异论》第八卷

按年或按月给付的遗赠，以及居住权遗赠，虽会因受遗赠人死亡而消灭，但即使受遗赠人发生身份减等，该遗赠仍继续有效；这是因为此类遗赠更多取决于事实，而非法律身份。

### <a id="4.5.11"></a>4.5.11　保罗《评萨宾》第二卷

身份减等分为三类：最大、中等和最小。因为我们具有三种身份：自由身份、市民身份和家族身份。若三者——自由、市民及家族身份——全部丧失，即发生最大的身份减等；若丧失市民身份而保有自由身份，即发生中等身份减等；若自由与市民身份均保留、仅家族身份发生变更，则显然属于最小的身份减等。
