# D.41.2 论取得或丧失占有（*De adquirenda vel amittenda possessione*）

> **底本范围：**EPUB 全部段落元素的连续编号 source-p 283–543，共261段；本稿按源序保留题名、出处、分题、段落与锚点。

<!-- source-p 283 -->
<a id="41.2"></a>**41.2.0 论取得或丧失占有。**

<!-- source-p 284 -->
<a id="41.2.1"></a>**41.2.1**

<!-- source-p 285 -->
保罗《告示评注》第五十四卷。

<!-- source-p 286 -->
<a id="41.2.1.pr."></a>**序言。**如拉贝奥所说，占有（*possessio*）一词源于“住所”，意即“置于其上”；因为占有在自然意义上由实际处于该物上的人持有。希腊人称之为 *katoxyn*。

<!-- source-p 287 -->
<a id="41.2.1.1"></a>**1**　内尔瓦之子说，物的所有权始于自然占有；这一情形的痕迹仍见于通过陆地、海洋和天空捕获的物。此类物一经捕获，即归首先取得其占有者所有。同样，战争中俘获之物、海上新生的岛屿，以及在海岸发现的宝石、卵石和珍珠，也归首先取得其占有者所有。

<!-- source-p 288 -->
<a id="41.2.1.2"></a>**2**　我们可以亲自取得占有。

<!-- source-p 289 -->
<a id="41.2.1.3"></a>**3**　精神失常者，以及未经监护人授权的未成年人，不能开始占有，因为他们没有持有该物的意思，即使他们的身体实际接触该物也一样；这如同有人把某物放进睡着之人的手中。不过，未成年人经监护人授权后即可开始占有。奥菲利乌斯和内尔瓦之子则认为，未成年人即使未经监护人授权，也可以开始占有；因为这属于事实问题，而非法律问题。若未成年人已达到能够理解事物的年龄，可以采纳这一观点。

<!-- source-p 290 -->
<a id="41.2.1.4"></a>**4**　若丈夫为赠与妻子而将占有让与她，多数人认为妻子取得占有，因为事实上的事项不能被市民法否定。况且，既然丈夫一旦不愿占有便立即丧失占有，又何必说妻子没有取得占有呢？

<!-- source-p 291 -->
<a id="41.2.1.5"></a>**5**　我们也可以通过处于我们权力之下的奴隶或家子取得占有；对于他们以特有产持有的物，即使我们不知情也可以取得占有。萨宾、卡西乌斯和尤利安持此观点，因为我们允许他们拥有特有产，便可认为他们依我们的意思占有。因此，基于特有产，婴儿和精神失常者也能取得占有并取得时效；若遗产中的奴隶购买物品，继承人也能取得占有。

<!-- source-p 292 -->
<a id="41.2.1.6"></a>**6**　我们也可以通过自己善意占有的人取得占有，即使此人属于他人或是自由人。若我们恶意占有此人，我认为不能通过他为自己取得占有；但被他人占有时，他也不会为真正所有人或为自己取得占有。

<!-- source-p 293 -->
<a id="41.2.1.7"></a>**7**　我们可以像通过自己的奴隶一样，通过共有奴隶取得占有；若奴隶的意思是为一名共有人取得，则各共有人可以分别取得全部占有，其规则与取得所有权相同。

<!-- source-p 294 -->
<a id="41.2.1.8"></a>**8**　我们可以通过享有其用益权之人取得占有，正如其劳务通常会使我们取得财产一样。我们是否占有其本人并不重要；因为我们也不占有家子本人。

<!-- source-p 295 -->
<a id="41.2.1.9"></a>**9**　此外，我们意图借以取得占有的人，也必须具备理解占有的能力。

<!-- source-p 296 -->
<a id="41.2.1.10"></a>**10**　因此，若你派遣精神失常的奴隶去为你取得占有，不能认为你已取得占有。

<!-- source-p 297 -->
<a id="41.2.1.11"></a>**11**　但若你派遣未成年人去取得占有，你便开始取得占有；其规则如同未成年人取得占有一样，尤其是在经监护人授权的情况下。

<!-- source-p 298 -->
<a id="41.2.1.12"></a>**12**　毫无疑问，你可以通过女奴取得占有。

<!-- source-p 299 -->
<a id="41.2.1.13"></a>**13**　未成年人可以通过自己的奴隶取得占有，无论该奴隶已成年还是尚未成年；但未成年人须在监护人授权下命令奴隶进入占有。

<!-- source-p 300 -->
<a id="41.2.1.14"></a>**14**　内尔瓦之子说，我们不能通过逃亡奴隶取得任何占有。虽有人回答说，只要该奴隶尚未被他人占有，就仍应视为由我们占有，因而在此期间也可以取得时效；但出于实用考虑，法律接受了如下规则：只要无人取得该奴隶的占有，取得时效就可以完成。至于能否通过逃亡奴隶取得占有，卡西乌斯和尤利安认为可以，规则与通过我们在行省的奴隶取得占有相同。

<!-- source-p 301 -->
<a id="41.2.1.15"></a>**15**　尤利安说，我们不能通过已在事实上设质的奴隶取得占有；因为债务人仅为取得时效这一目的被认为占有该奴隶。债权人也不能通过该奴隶取得占有，因为他既不能依要式口约，也不能以其他方式通过该奴隶取得占有，尽管他确实占有该奴隶。

<!-- source-p 302 -->
<a id="41.2.1.16"></a>**16**　古代法学家认为，我们不能通过遗产中的奴隶取得该遗产的占有。由此引发争论：这一规则是否应进一步适用，即若数名奴隶被遗赠，能否通过其中一人取得其他奴隶的占有；若这些奴隶同时被买受或赠与，也存在同样的问题。但更正确的观点是，在这些情形下，我可以通过其中一人取得其余奴隶的占有。

<!-- source-p 303 -->
<a id="41.2.1.17"></a>**17**　若奴隶被遗赠给按份额指定的继承人，则该继承人基于遗赠取得的份额，可以取得遗产土地的占有。

<!-- source-p 304 -->
<a id="41.2.1.18"></a>**18**　若我命令共有奴隶接受遗产，也应作同样解释，因为我会基于自己的份额取得占有。

<!-- source-p 305 -->
<a id="41.2.1.19"></a>**19**　以上关于奴隶的论述，以奴隶本人愿意为我们取得占有为前提。若你命令自己的奴隶占有某物，而他进入占有时的意思是为提图斯而非为你取得占有，则你并未取得占有。

<!-- source-p 306 -->
<a id="41.2.1.20"></a>**20**　我们可以通过代理人、监护人或保佐人取得占有。但若他们以自己的名义取得占有，而非仅仅以提供劳务为目的，则不能为我们取得占有。否则，若我们说那些以我们的名义受领物品的人不能使我们取得占有，就会导致这样的结果：受领物的人因没有占有意思而不占有，交付物的人又因已放弃占有而不占有。

<!-- source-p 307 -->
<a id="41.2.1.21"></a>**21**　普里斯库斯说，若我命令出卖人在标的物就在现场时将其交付给我的代理人，应视为已向我交付；我命令债务人将钱交给他人时，亦同。取得占有并不必须以身体接触为必要条件；通过视见和意思也可以取得占有。柱子等因过于沉重而无法移动之物，便是此类情形的例子：若双方在标的物所在之处达成合意，就视为已交付。若酒窖钥匙已交给买受人，也应视为酒已交付。

<!-- source-p 308 -->
<a id="41.2.1.22"></a>**22**　市镇共同体不能自行取得占有，因为全体成员不可能共同表示同意。它们也不占有广场、会堂及类似场所，而是共同使用这些场所。但内尔瓦之子说，市镇共同体可以通过奴隶占有并取得时效取得其以特有产方式取得的物；有人则持相反观点，理由是市镇共同体并不占有这些奴隶。

<a id="41.2.3"></a>**41.2.3**

<!-- source-p 313 -->
保罗《告示评注》第五十四卷。

<!-- source-p 314 -->
<a id="41.2.3.pr."></a>**序言。**能够被占有的，只能是有体物。

<!-- source-p 315 -->
<a id="41.2.3.1"></a>**1**　我们通过身体和意思取得占有，不能仅凭意思，也不能仅凭身体。所谓必须通过身体和意思取得占有，并非要求想要占有土地的人绕行土地上的每一块土；只要进入该土地的任何一部分，并且在心里确实意图占有整块土地直至其界限，就已足够。

<!-- source-p 316 -->
<a id="41.2.3.2"></a>**2**　无人能够占有一项不确定的物，例如，你只是想占有提图斯所占有的任何东西。

<!-- source-p 317 -->
<a id="41.2.3.3"></a>**3**　内拉提乌斯和普罗库鲁斯认为，若没有先前的自然占有，不能仅凭意思取得占有。因此，若我知道自己的土地上放有宝藏，一旦我有了占有的意思，就立即取得该宝藏的占有，因为意思补足了自然占有所欠缺的部分。反之，布鲁图斯和马尼利乌斯认为，某人通过长期占有取得土地时，即使不知道土地中有宝藏，也一并取得宝藏；此说并不正确。因为不知道宝藏存在的人并不占有宝藏，尽管他占有土地。即使他知道宝藏存在，也不会因长期占有而取得宝藏，因为他知道宝藏属于他人。有些人认为萨宾的观点更为正确：知晓宝藏的人只有在宝藏被移出原处后才取得占有，因为此前宝藏不在其看管之下。我赞同这一观点。

<!-- source-p 318 -->
<a id="41.2.3.4"></a>**4**　依某些人的观点，我们可以基于多种原因占有同一物。例如，同一人既以买受人身份占有，也以己有之物的名义占有；若我继承了以买受人身份占有某物的人，我便既以买受人身份，也以继承人身份占有该物。正如所有权只能基于一种原因取得，占有并非只能基于一种原因取得。

<!-- source-p 319 -->
<a id="41.2.3.5"></a>**5**　相反，多人不能各自完整占有同一物。若我实际持有某物，便有悖自然地认为你也在持有它。然而，萨宾写道，基于使用借贷而交付的人仍占有该物，基于使用借贷而受领的人也占有该物。特雷巴提乌斯认可这一观点，认为一人可以合法占有，另一人非法占有，但两人不能同时合法占有，也不能同时非法占有。拉贝奥批评此说，因为就占有的本质而言，占有合法与否并不十分重要；这一意见较为正确。毕竟，同一占有不可能同时属于两人，正如你不可能站在我所站的位置上，或坐在我所坐的位置上。

<!-- source-p 320 -->
<a id="41.2.3.6"></a>**6**　丧失占有时，也应考察占有人的意思。因此，即使你身处土地上，但不愿再占有该地，也会立即丧失占有。由此可见，占有可以仅凭意思而丧失，尽管不能仅凭意思取得。

<!-- source-p 321 -->
<a id="41.2.3.7"></a>**7**　反之，即使你仅凭意思占有，而他人身处该土地上，你仍然占有该土地。

<!-- source-p 322 -->
<a id="41.2.3.8"></a>**8**　若有人告知房屋已被强盗占据，而所有人因恐惧不愿前往，应认为所有人已丧失占有。反之，若奴隶或佃户——即我借以实际占有土地的人——死亡或离开，我仍可凭意思保有占有。

<!-- source-p 323 -->
<a id="41.2.3.9"></a>**9**　若我将物交付给他人，也会丧失占有。因为确定的是，只要我们未自愿放弃占有，也未被暴力驱逐，就仍然占有。

<!-- source-p 324 -->
<a id="41.2.3.10"></a>**10**　若我占有的奴隶像斯巴达库斯那样自称自由人，并准备参加自由身份诉讼，就不能认为他仍由主人占有，因为他已准备与主人对抗。但只有在他已长期处于自由身份占有时，这一规则才适用。若他仍处于奴隶身份占有中便主张自由并请求审理自由身份诉讼，则在被判定为自由人之前，他仍属于我的占有人；我仍凭意思占有他。

<!-- source-p 325 -->
<a id="41.2.3.11"></a>**11**　我们凭意思占有冬季牧场和夏季牧场，尽管每年在特定时期会离开这些地方。

<!-- source-p 326 -->
<a id="41.2.3.12"></a>**12**　我们凭自己的意思、通过他人的身体占有物，如前所述通过佃户和奴隶占有一样。也不应使我们困惑：有些物品即使我们不知情也由我们占有，例如奴隶以特有产专门购得的物品；因为应认为我们通过这些奴隶，兼以意思和身体占有这些物品。

<!-- source-p 327 -->
<a id="41.2.3.13"></a>**13**　内尔瓦之子认为，除人以外的动产，只能在处于我们看管之下的范围内被占有；也就是说，只要我们愿意，便能够取得其自然占有。牲畜一旦走失，或器皿掉落后无法找到，我们便立即不再占有，即使无人占有该物亦然。若物品仍在我的看管范围内，只是暂时找不到，则不同；此时该物仍在现场，只是暂时停止了仔细搜寻。

<!-- source-p 328 -->
<a id="41.2.3.14"></a>**14**　同样，我们占有被圈养在兽苑中的野兽，以及被放入鱼池中的鱼。但我们不占有池塘中的鱼，也不占有在围起来的林地中游荡的野兽，因为这些动物仍处于自然自由状态。否则，若有人购买一片森林，便会认为他占有其中所有野兽；显然并非如此。

<!-- source-p 329 -->
<a id="41.2.3.15"></a>**15**　我们占有被圈养的鸟，或已被驯化并置于我们看管之下的鸟。

<!-- source-p 330 -->
<a id="41.2.3.16"></a>**16**　有些人正确地认为，从我们建筑物中飞出的鸽子，以及从我们的蜂箱中飞出、但依惯例会返回的蜜蜂，仍由我们占有。

<!-- source-p 331 -->
<a id="41.2.3.17"></a>**17**　拉贝奥和内尔瓦之子答复说，若河流或海洋淹没某处土地，我便不再占有该处。

<!-- source-p 332 -->
<a id="41.2.3.18"></a>**18**　若你为了实施盗窃而动用了寄存在你处的物品，我便丧失占有。但若你没有移动该物，只是打算日后否认受领，多数古代法学家以及萨宾、卡西乌斯都正确地答复说，我仍是占有人；因为未实施动用行为便不构成盗窃，也不能仅凭盗窃意思实施盗窃。

<!-- source-p 333 -->
<a id="41.2.3.19"></a>**19**　古代法学家还确立一项规则：任何人都不能自行改变其占有的原因。

<!-- source-p 334 -->
<a id="41.2.3.20"></a>**20**　但若曾将物品寄存或出借给我的人后来把该物卖给我或赠与我，我并非自行改变占有原因，因为此前我根本不占有该物。

<!-- source-p 335 -->
<a id="41.2.3.21"></a>**21**　占有的种类与取得非己有之物的原因一样多，例如，以买受人、受赠人、受遗赠人、受嫁资人、继承人的身份占有；以诺克萨交付方式取得；或以己有物的名义占有，例如我们从陆地或海洋、从敌人处取得的物，以及由我们亲自创制而使其成为自然界中之物的对象。总而言之，占有的种类只有一种，但具体形态无穷无尽。

<!-- source-p 336 -->
<a id="41.2.3.22"></a>**22**　也可以将占有分为两类：善意占有和非善意占有。

<!-- source-p 337 -->
<a id="41.2.3.23"></a>**23**　昆图斯·穆基乌斯将受治安官命令、为保全财产而取得的占有列为占有的一类，这种做法极不妥当。裁判官将债权人准入占有，以便保全财产；或者在邻人未就可能造成的损害提供担保时，将请求人准入占有；又或者准许某人以胎儿名义进入占有；在这些情形下，裁判官给予的不是占有，而是对财物的保管和监管。因此，若因邻人未就可能造成的损害提供担保，我们被准入占有，且这种状态持续很长时间，裁判官经审理案情后，也会允许我们取得占有，并通过长期占有取得所有权。

<a id="41.2.6.pr."></a>**序言。**我们称以秘密方式占有者，是指其秘密进入占有，且未告知他所预料会与自己发生争议、并因害怕对方争执而加以隐瞒。但若某人原本并非秘密取得占有，只是在已经占有后隐藏自己，则不属于秘密占有；因为应查明的是取得占有的起因，而非继续维持占有的方式。若经与物有关之人知情或同意，或通过其他善意方式取得占有，任何人都不能开始秘密占有。因此，庞波尼乌斯说：若某人担心日后发生争议，便趁其所惧怕之人不知情时偷偷进入占有，即属秘密取得占有。

<!-- source-p 372 -->

<!-- source-p 373 -->

<!-- source-p 374 -->

<!-- source-p 381 -->

雅沃勒努斯《拉贝奥遗著》第五卷。

<!-- source-p 535 -->
拉贝奥说，有些物可以仅凭意思取得占有。例如，我买下一堆木柴，出卖人命我派人看守；一旦我安排看守，就视为已经交付。出售葡萄酒时，若所有酒坛同时摆在一起，也适用同一规则。拉贝奥又说，应考虑这是否本身就是一种身体交付，因为无论我是命令将物交付给我，还是命令交付给任何看守者，都没有区别。我认为，问题在于：即使我本人没有亲手接触木柴或酒坛，是否仍应视为已经交付？我看不出二者有什么区别：无论我亲自看守整堆木柴，还是命令他人代我看守，在两种情形下，都应依某种意思表示来判断是否取得占有。〔底本文字 *simul essententiarum* 有粘连疑误。〕

<a id="41.2.52"></a>**41.2.52**

<!-- source-p 537 -->
维诺尼乌斯《禁令论》第一卷。

<!-- source-p 538 -->
<a id="41.2.52.pr."></a>**序言。**不应混淆占有与用益权各自的原因，正如不应混淆占有与所有权一样。若一人享有用益权，不应因此妨碍另一人占有；若一人占有，也不应因此剥夺另一人的用益权。

<!-- source-p 539 -->
<a id="41.2.52.1"></a>**1**　显然，若某人被禁止建造，也同时被禁止取得占有。

<!-- source-p 540 -->
<a id="41.2.52.2"></a>**2**　将某物置于他人占有之下的一种方式，是禁止对进入者施加暴力。因为裁判官立即命令对方让出，并使占有处于空置状态；这远超过单纯恢复占有。
