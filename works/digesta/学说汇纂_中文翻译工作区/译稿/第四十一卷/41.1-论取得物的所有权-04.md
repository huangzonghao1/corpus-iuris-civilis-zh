# D.41.1 论取得物的所有权（*De adquirendo rerum dominio*）—第四部分

<!-- source-p 201 -->
共有奴隶若以其中一名所有人的财物取得某物，该物仍归共有人共有；但在共有物分割之诉中，财物来源所有人可以优先取回该项金额，因为符合诚信原则的做法是，各人应优先取得奴隶以其财物所取得的利益。共有奴隶若从其他来源取得某物，该物则按所有权份额归所有共有人取得。

保罗《普劳提乌斯评注》第七卷。

<!-- source-p 210 -->
<a id="41.1.48.pr."></a>**序言**　善意买受人毫无疑问可以通过收取收益，暂时将他人之物的收益归自己所有；不仅是通过其勤勉和劳作取得的收益，所有收益均如此，因为就收益而言，他几乎处于所有人的地位。甚至在其实际收取收益之前，只要收益与土地分离，便立即归善意买受人所有。无论我善意购买的物能否通过长期占有取得时效，结论均相同；例如，该物属于未适婚人、系以暴力取得，或由行省总督违反勒索法而收受赠与后又转让给善意买受人。

<!-- source-p 211 -->
<a id="41.1.48.1"></a>**1**　反过来要问：若物品交付给我时，我认为出卖人是其所有人，后来却知道该物属于他人，而我仍继续完成长期占有取得时效，我是否会将收益归自己？庞波尼说，尽管我可能完成取得时效，却仍不能视为善意占有人，这一点值得注意。因为取得时效属于法律问题，而某人善意或恶意占有属于事实问题。继续经过长期期间并不与此矛盾；相反，即使占有物存在瑕疵而不能完成取得时效，占有人仍可将收益归自己。

<!-- source-p 212 -->
<a id="41.1.48.2"></a>**2**　羊所产的幼崽也是收益，因此归善意买受人所有，即使羊在怀孕时被出售或系被盗所得亦如此。即使羊在出售时乳房充盈，买受人取得其乳汁也毫无疑问；羊毛亦适用同样规则。

<!-- source-p 213 -->
<a id="41.1.49"></a>**41.1.49**

<!-- source-p 214 -->
保罗《普劳提乌斯评注》第九卷。

用益权人以自己的财物赠与某物，该物来自用益权人自己的财产；但若其意在使裸所有权人取得该物，则应认为裸所有权人取得该物。若第三人未加任何限定地向用益权人赠与某物，则仅由裸所有权人取得。对善意为我服役的自由人，也应作同样处理：若我赠与他某物，该物便归我所有。因此，庞波尼写道，即使我把他的劳务赠与他本人，他以自己的劳务所取得的任何物仍归我取得。

<a id="41.1.54"></a>**41.1.54**

<!-- source-p 230 -->
莫德斯蒂努斯《昆图斯·穆基乌斯评注》第三十一卷。

<!-- source-p 231 -->
<a id="41.1.54.pr."></a>**序言**　自由人善意地为我们服役，不能使我们取得遗产；但若他明知自己的身份，仍自愿接受遗产，便可为自己取得遗产。若他依我们的命令接受遗产，而他并无为自己取得遗产的意思，则遗产既不归他本人，也不归我们取得；若他有为自己取得遗产的意思，则遗产归其本人取得。

<!-- source-p 232 -->
<a id="41.1.54.1"></a>**1**　同样，善意为我们服役的自由人若向我们作出允诺，或者通过买卖、出租或承租与我们订约，便可依法律直接承担义务。

<!-- source-p 233 -->
<a id="41.1.54.2"></a>**2**　但若他造成损害，应承担非法损害责任；不过，对其造成损害的过失，应采用较严格的判断标准，不得低于对外人追究责任时的标准。

<!-- source-p 234 -->
<a id="41.1.54.3"></a>**3**　但若他依我们的命令处理我们的事务，或在我们不在场时如代理人般处理事务，则应当向他授予诉权。

<!-- source-p 235 -->
<a id="41.1.54.3a"></a>**3a**　以上规则不仅适用于我们购买的人，也适用于赠与给我们的人，或者因嫁资、遗赠或继承而开始归我们所有的人；无论我们认为他们是自己的奴隶、共有奴隶还是用益权奴隶，均适用同样规则。不过，若依实际身份，他们不可能为我们取得某物——例如其确为共有奴隶或用益权奴隶时——如今也仍不会为我们取得该物。

<!-- source-p 236 -->
<a id="41.1.54.4"></a>**4**　自由人、他人之奴隶或善意为我们服役之人未能为我们取得的财物，若其为自由人则由其本人取得；若其为他人之奴隶，则由其主人取得。唯一的例外是，自由人很难通过占有所取得时效，因为他本人正受他人占有，因而不被视为占有人。我们善意占有的他人奴隶也不能使其主人以特有产名义在不知情时取得时效，正如主人不能通过自己并未占有的逃亡奴隶取得时效。

<!-- source-p 237 -->
<a id="41.1.55"></a>**41.1.55**

<!-- source-p 238 -->
普罗库鲁斯《书信集》第二卷。

<!-- source-p 239 -->
你为狩猎设置的套索套住了一头野猪。野猪被困在套索中时，我把它取走。你认为我取走的是你的野猪吗？若你认为它原本属于你，那么，假使我将它解开并放归树林，它是否会因此不再属于你，还是仍归你所有？若它不再属于你，我又可以对你提起何种诉讼？我还要问，是否应当给予一项事实诉讼？答复说：应考察你将套索设置在公地还是私地；若设置在私地，该土地属于你还是他人；若属于他人，你是否得到土地所有人的许可。此外，还应考察野猪是否被套索缠住，以至于无法自行脱身，还是它再挣扎一段时间便可脱身。不过，基本原则是：若野猪已落入我的控制，它便归我所有。但若你将我的野猪——一头野生动物——放归其自然自由，从而使其不再属于我，我便应享有事实诉讼；有人将他人杯子从船上抛下时，也曾作出过类似答复。
