# D.41.1 论取得物的所有权（*De adquirendo rerum dominio*）—第五部分

<!-- source-p 241 -->
普罗库鲁斯《书信集》第八卷。

<!-- source-p 242 -->
<a id="41.1.56.pr."></a>**序言**　河中有一座岛屿形成在正对我土地的位置，其长度并未超出我土地的临河宽度；此后，岛屿逐渐扩大，延伸至上游邻人和下游邻人土地的临河界面。我想问：后来增加的部分，因附着于我的土地，是否归我所有；还是应按岛屿最初形成时若具有后来长度所适用的规则归属？普罗库鲁斯答复说：你所说的这条河，若享有冲积添附规则，且岛屿最初形成时比起河对岸土地更靠近你的土地，则整座岛屿归你所有；此后因冲积添附而增加的部分也归你所有，即使岛屿扩大到正对上下游邻人的土地，或甚至比你的土地更靠近河对岸土地，亦是如此。

<!-- source-p 243 -->
<a id="41.1.56.1"></a>**1**　我还要问：若岛屿最初形成时更靠近我的河岸，后来河流舍弃原有较宽河道，全部河水开始在我和岛屿之间流淌，难道不会仍认为岛屿归我所有，而且原河流留下的土地也归我吗？请把你的看法写信告知我。普罗库鲁斯答复说：若岛屿最初更靠近你的土地，而河流舍弃其与河对岸邻人土地之间原有的较宽河道，开始在岛屿与你的土地之间流淌，岛屿仍归你所有。但岛屿与邻人土地之间的河床应从中线划分：靠近你岛屿的一部分归你，靠近邻人土地的一部分归邻人。我知道，若岛屿另一侧的河床也干涸，岛屿便不再是岛屿；但为便于理解，我们仍将这块曾是岛屿的土地称为“岛屿”。

<a id="41.1.61"></a>**41.1.61**

<!-- source-p 257 -->
赫尔莫革尼安《法律摘要》第六卷。

<!-- source-p 258 -->
<a id="41.1.61.pr."></a>**序言**　遗产在许多法律关系中被视为所有人，因此遗产也会像所有人一样通过遗产中的奴隶取得财物。但若取得财物需要特定人的行为或劳务，遗产便不能通过奴隶取得该物。因此，虽然遗产中的奴隶可以被指定为继承人，但由于接受遗产需要有权命令接受的所有人作出意思表示，仍须等待继承人出现。

<!-- source-p 259 -->
<a id="41.1.61.1"></a>**1**　用益权不能脱离特定的人而设立，因此遗产不能通过奴隶取得用益权。

<a id="41.1.62"></a>**41.1.62**

有些物不能单独让与，却可通过概括承继转移给继承人，例如嫁资土地，以及某人无交易能力的物。即使此类物不能遗赠给他，只要他被指定为继承人，就会成为该物的所有人。

<!-- source-p 263 -->
<a id="41.1.63"></a>**41.1.63**

<!-- source-p 264 -->
特里福尼努斯《论答疑》第七卷。

<!-- source-p 265 -->
<a id="41.1.63.pr."></a>**序言**　若受他人权力支配之人发现宝藏，应根据财物归谁取得的规则处理：若他在他人土地上发现宝藏，应为自己取得其中一份；若他在父亲或主人身份之人的土地上发现，全部宝藏都归该人所有；若在他人土地上发现，他仅取得其中一份。

<!-- source-p 266 -->
<a id="41.1.63.1"></a>**1**　若共有奴隶在他人土地上发现宝藏，其份额究竟按共有人对奴隶的所有权份额确定，还是总是平均分配？这与遗产、遗赠或他人赠与并交付奴隶的财物相似，因为宝藏也被认为是命运赐予之物；因此，归发现者取得的份额，应由共有人依各自对该奴隶享有的所有权份额分配。

<!-- source-p 267 -->
<a id="41.1.63.2"></a>**2**　若共有奴隶在其中一名共有人自己的土地上发现宝藏，无疑，按土地所有权应归该土地所有人的那一部分宝藏，仅归该土地所有人所有。但另一名共有人是否可取得其余份额，仍须考察；这是否类似于奴隶依一名所有人的命令订立要式口约，或通过交付取得财物，且明确指定归该所有人所有？后一意见更为可取。

<!-- source-p 268 -->
<a id="41.1.63.3"></a>**3**　若一名由他人享有用益权的奴隶，在其所有人自己的土地上发现宝藏，全部宝藏是否归土地所有人？若在他人土地上发现，其一部分应归该土地所有人，还是归用益权人？应考察宝藏是否因奴隶的劳务而取得。假设奴隶正在挖土时发现宝藏，便可认为宝藏归用益权人；但若宝藏原先藏在隐蔽处，奴隶并未从事劳作，只是走过时发现，则宝藏应归奴隶的所有人。我认为，即使后一种情况下宝藏的一部分也不归用益权人；因为奴隶并非通过劳务寻找宝藏，他当时挖土也不是为了寻宝，而是在从事其他工作，偶然才有所得。因此，若奴隶在用益权人自己的土地上发现宝藏，我认为用益权人仅以土地所有人的身份取得其中一半，另一半归奴隶的裸所有权人。

<!-- source-p 269 -->
<a id="41.1.63.4"></a>**4**　若债权人发现宝藏，应视为其在他人土地上发现；因此，债权人应取得一部分，债务人取得另一部分。债权人收回借款时，不必返还依据发现者身份而非债权人身份保留的宝藏部分。既然如此，若债权人依元首授权开始以所有权人身份占有他人的土地，在法定清偿期限届满前，该土地仍处于质押状态；但期限届满后，若在债务人清偿前于该土地发现宝藏，债权人便取得全部宝藏。若债务人在法定期限内清偿，由于债权人应返还全部财物，而土地也可通过普通返还请求取回，债权人应返还宝藏，但仅返还其一半，因为发现者始终应保留一半。

<a id="41.1.65"></a>**41.1.65**

<!-- source-p 274 -->
拉贝奥《精义》第六卷，保罗节录。

<!-- source-p 275 -->
<a id="41.1.65.pr."></a>**序言**　拉贝奥说：“若我给你寄信，在信交付给你之前，该信不会成为你的。”保罗说：“恰恰相反。若你派自己的信使到我这里，我为了回复而给你写信，只要我已将信交给你的信使，该信便成为你的。若我寄给你的信仅与你的事务有关，规则亦同；例如，你请求我向某人推荐你，而我将推荐信寄给你。”

<!-- source-p 276 -->
<a id="41.1.65.1"></a>**1**　拉贝奥说：“若河中有一座岛屿完全属于你，则岛上没有任何东西属于公有。”保罗说：“不对。此类岛屿靠近河流的河岸部分，以及靠近海洋的海岸部分，属于公有；大陆土地也适用相同规则。”

<!-- source-p 277 -->
<a id="41.1.65.2"></a>**2**　拉贝奥说：“若公有河流中有一座岛屿形成在你土地附近，该岛屿归你所有。”保罗说：“这也未必正确：若岛屿并未与河床相连，而是由灌木或其他轻质材料支撑在河中，其底部没有接触河床，并且会随水移动，则它近乎是公有物，也是河流本身的一部分。”

<!-- source-p 278 -->
<a id="41.1.65.3"></a>**3**　保罗说：“若河中一座岛屿归你所有，随后又有另一座岛屿在该岛与对岸之间形成，则应从你原有的岛屿而非使该岛归你所有的土地起算距离。因为在判断后一座岛屿因靠近何处而归谁所有时，土地本身的性质有何关系？”

<!-- source-p 279 -->
<a id="41.1.65.4"></a>**4**　同卷中，拉贝奥说：“若自然形成或建造于公有土地上的物属于公有，那么，在公有河流中形成的岛屿也应属于公有。”
