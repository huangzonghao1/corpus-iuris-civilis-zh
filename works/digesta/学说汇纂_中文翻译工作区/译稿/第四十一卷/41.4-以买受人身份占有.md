<!-- source-p 759 -->
<a id="41.4"></a>**41.4.0**　以买受人身份占有。

<!-- source-p 760 -->
<a id="41.4.1"></a>**41.4.1**

<!-- source-p 761 -->
盖尤斯《行省告示评注》第六卷。

<!-- source-p 762 -->
占有人提出诉讼标的估价后，即开始以买受人身份占有。

<!-- source-p 763 -->
<a id="41.4.2"></a>**41.4.2**

<!-- source-p 764 -->
保罗《告示评注》第五十四卷。

<!-- source-p 765 -->
<a id="41.4.2.pr."></a>**序言**　以买受人身份占有者，必须确实买受了该物；仅仅认为自己是以买受人身份占有，并不足够，还必须存在买卖原因。不过，若我以为自己欠你某物，而你并不知情，我将该物交付给你，你可以因取得时效而取得它。那么，为什么我若以为自己已经将该物卖给你并向你交付，你却不能因取得时效而取得它？显然，这是因为在其他契约中，交付时点即已足够；例如，即使我明知要式承诺的标的是他人之物，只要在该物交付给我时，我以为它属于交付人，我仍可因取得时效而取得它。但在买卖中，还须考察订立买卖的时点。因此，买受人既须在善意下买受，也须在善意下取得占有。

<!-- source-p 766 -->
<a id="41.4.2.1"></a>**1**　占有原因与取得时效原因彼此有别。因为有人确实买受了某物，却出于恶意；例如，明知某物属于他人而仍予买受者，是以买受人身份占有该物，尽管不能因取得时效而取得它。

<!-- source-p 767 -->
<a id="41.4.2.2"></a>**2**　若买卖附有条件，在条件悬而未决期间，买受人不能因取得时效而取得该物。若买受人误以为尚未成就的条件已经成就，结论也相同；因为他与误以为自己已经买受该物的人相似。反之，若条件已经成就而他并不知情，依萨宾的意见——萨宾更着眼于实质而非主观认识——可以说他能够因取得时效而取得该物。不过二者仍有些不同：前一种情形中，他以为该物属于他人，也就是出卖人，因而具有买受人的意思；而条件尚未成就时，他几乎还不认为自己已经为自己买下该物。对此可以更清楚地提出问题：若死者已经买下某物，该物被交付给其继承人，而继承人不知道死者曾经买受，只以为该物是基于另一原因交付给自己，取得时效是否因此中断？

<!-- source-p 768 -->
<a id="41.4.2.3"></a>**3**　萨宾认为，若买卖约定：未在确定日期前支付价款，该物即视为未曾买卖，则买受人须在付清价款后才能因取得时效而取得该物。但我们应考察，这究竟是条件，还是约定；如果只是约定，与其说条件得到成就，不如说买卖关系因此解除。

<!-- source-p 769 -->
<a id="41.4.2.4"></a>**4**　若约定在一定期限内接受更优条件，也就是说，除非有人提出更优条件，尤利安认为买卖已经成立，孳息归买受人，取得时效也照常进行。另一些人认为，这种买卖附有条件；尤利安则说，它并非附条件成立，而是可以解除。后一意见是正确的。

<!-- source-p 770 -->
<a id="41.4.2.5"></a>**5**　若约定买受人可以在确定期限内因不满意而使买卖视为未曾成立，该买卖同样是无条件的。

<!-- source-p 771 -->
<a id="41.4.2.6"></a>**6**　我买下斯提库斯，却因不知情而收到达马作为交付物。普里斯库斯说，我不能因取得时效而取得达马，因为买下的物并未交付；未买下的物不能以买受人身份取得时效。不过，若买下土地而占有的界限超出买下的范围，则可通过长期占有取得全部土地，因为所占有的是一个整体，而非各个部分。

<!-- source-p 772 -->
<a id="41.4.2.7"></a>**7**　你买下了某人的财产，而该人曾受托保管一些奴隶。特雷巴提乌斯说，你不能因取得时效而取得这些奴隶，因为他们并未被买下。

<!-- source-p 773 -->
<a id="41.4.2.8"></a>**8**　监护人从未成年人的拍卖中买下他以为属于该未成年人的物。塞尔维乌斯说，监护人可以因取得时效而取得该物。之所以采纳这一意见，是因为若未成年人有更近的买受人，其处境并未因此变差；而且，若监护人以较低价格买下该物，他须在监护诉讼中承担责任，犹如他将该物以低价判卖给他人一样。据说神圣的图拉真也作过此项规定。

<!-- source-p 774 -->
<a id="41.4.2.9"></a>**9**　多数人认为，代理人依主人委托举行拍卖并在拍卖中买下物品，也可基于实用理由以买受人身份取得时效。出于同一实用理由，为不知情的主人管理事务而买下物品的，也可以作相同处理。

<!-- source-p 775 -->
<a id="41.4.2.10"></a>**10**　若你的奴隶以其特有产名义买下一物，并且知道该物属于他人，即使你不知道该物属于他人，你也不能因取得时效而取得它。

<!-- source-p 776 -->
<a id="41.4.2.11"></a>**11**　塞尔苏斯写道：若我的奴隶以特有产名义取得占有，即使我不知情，我也能因取得时效而取得该物；若并非以特有产名义，则只有我知情时才可以。若奴隶以有瑕疵的方式开始占有，占有对我而言也有瑕疵。

<!-- source-p 777 -->
<a id="41.4.2.12"></a>**12**　庞波尼乌斯也说，对于以主人名义占有的物，应考察主人的意思，而非奴隶的意思；若以特有产名义占有，则应考察奴隶的意思。若奴隶以恶意占有该物，而主人后来取得该物并改为以自己名义占有，例如收回奴隶的特有产，则应认为占有原因仍然相同，因此主人也不能因取得时效而取得该物。

<!-- source-p 778 -->
<a id="41.4.2.13"></a>**13**　若我的奴隶以特有产名义善意买下某物，塞尔苏斯说，即使我后来知道该物属于他人，取得时效仍会继续；因为占有开始时并无瑕疵。但若在奴隶买下该物时，我虽知情，奴隶本人仍出于善意，则我不能因取得时效而取得该物。

<!-- source-p 779 -->
<a id="41.4.2.14"></a>**14**　若我的奴隶以恶意买下某物，后来将该物交给我，作为约定释奴的条件，也不因此使我能够因取得时效而取得该物；塞尔苏斯仍认为，最初的占有原因持续存在。

<!-- source-p 780 -->
<a id="41.4.2.15"></a>**15**　若我未经监护人授权而从未成年人处买物，却以为该未成年人已经达到法定青春期，我们认为取得时效应当开始；在此，实情较主观认识更为重要。但若我知道对方是未成年人，却误以为未成年人可以未经监护人授权管理自己的财产，我就不能因取得时效而取得该物，因为对法律的错误不利于任何人。

<!-- source-p 781 -->
<a id="41.4.2.16"></a>**16**　若我从一个被我误认为神志健全的精神失常者处买物，出于实用理由，已经确定我可以因取得时效而取得该物，尽管买卖并未成立。因此，我既不产生追夺之诉，也不享有普布利基安对物之诉，亦不得并入前手的占有期间。

<!-- source-p 782 -->
<a id="41.4.2.17"></a>**17**　若你将自己正以买受人身份取得时效的物卖给我，而我知道该物属于他人，我不能因取得时效而取得该物。

<!-- source-p 783 -->
<a id="41.4.2.18"></a>**18**　即便死者的中间继承人未曾取得其占有，该死者的占有仍使更后顺位的继承人受益。

<!-- source-p 784 -->
<a id="41.4.2.19"></a>**19**　若死者善意买下某物，即使继承人知道该物属于他人，仍可因取得时效而取得该物。在遗产占有人、依《特雷贝利安元老院决议》获返还遗产的遗嘱信托受益人，以及其他裁判官法上的继受人中，也适用此规则。

<!-- source-p 785 -->
<a id="41.4.2.20"></a>**20**　出卖人的占有期间计入买受人的取得时效期间。

<!-- source-p 786 -->
<a id="41.4.2.21"></a>**21**　若我买下他人之物，在我通过取得时效取得该物期间，所有权人向我请求返还同一物，争讼程序并不中断我的取得时效。但若我宁愿支付诉讼标的估价，尤利安说，对支付估价者而言，占有原因即发生改变。所有权人将该物赠与从非所有权人处买下它的人，也应作相同处理。该意见是正确的。

<a id="41.4.4.pr."></a>**序言**　土地买受人知道其中一部分属于他人。有人答复说，他不能通过长期占有取得该土地中的任何部分。我认为，若买受人不知道土地中究竟哪一部分属于他人，这一答复是正确的；但若他知道属于他人的部分位于某一确定地段，我毫不怀疑，他可以通过长期占有取得其余部分。

<!-- source-p 793 -->
<a id="41.4.4.1"></a>**1**　若买受人购买整块土地时，知道其中有一部分按未分割状态属于他人，法律也相同：只有该部分不能因取得时效而取得；其余部分通过长期占有取得时效，不受影响。

<!-- source-p 797 -->
<a id="41.4.6"></a>**41.4.6**

<!-- source-p 798 -->
庞波尼乌斯《萨宾评注》第三十二卷。

<!-- source-p 799 -->
<a id="41.4.6.pr."></a>**序言**　某人以继承人或买受人身份取得时效期间，后来请求以可撤回占有方式继续占有的，就不能因取得时效而取得该物。因为两种情形并无差别：无论哪一种，想要以可撤回占有方式持有该物的人，都会停止以最初的占有原因占有。

<!-- source-p 800 -->
<a id="41.4.6.1"></a>**1**　若我买下十名奴隶，其中一些我认为属于他人，并且知道具体是哪些，我可以因取得时效而取得其余奴隶；但若我不知道哪些奴隶属于他人，则一个也不能因取得时效而取得。

<!-- source-p 801 -->
<a id="41.4.6.2"></a>**2**　在买受人死亡后，若补足取得时效所欠缺的期间，即使继承人尚未开始占有该奴隶，该奴隶仍会归其所有；但条件是无人占有过该奴隶。

<!-- source-p 802 -->
<a id="41.4.7"></a>**41.4.7**

<!-- source-p 803 -->
尤利安《学说汇纂》第四十四卷。

<!-- source-p 804 -->
<a id="41.4.7.pr."></a>**序言**　某人以买受人身份占有一块土地，但在完成长期占有之前便已死亡。留在该土地上的奴隶离开土地，意在放弃该土地。有人询问：即使奴隶离开，长期占有期间是否仍可为继承人继续计算？他答复说，即使奴隶已经离开，该期间仍为继承人继续计算。

<!-- source-p 805 -->
<a id="41.4.7.1"></a>**1**　若我以买受人身份通过长期占有取得科尔内利乌斯土地，并将邻地的一部分并入该土地，我究竟是以买受人身份在剩余期间内取得该部分，还是必须经过完整的法定期间？我答复说，附加于买下土地的部分具有自身独立的法律状态，因此也须分别取得对该部分的占有，并经过完整法定期间，才能以长期占有取得该部分。

<!-- source-p 806 -->
<a id="41.4.7.2"></a>**2**　我的奴隶委托提提乌斯为他买下一块土地；奴隶获释后，提提乌斯将该土地的占有交给他。有人询问，他能否通过长期占有取得该土地。他答复说：若我的奴隶曾委托提提乌斯买地，提提乌斯在奴隶获释后将土地交给他，无论提提乌斯以为特有产已经授予该奴隶，还是不知道特有产并未授予，该奴隶仍可通过长期占有取得土地。因为奴隶知道或应当知道特有产并未授予自己；就此而言，他与假称自己是债权人的人相似。但若提提乌斯知道该奴隶获释时并未取得特有产，就应认为他意在赠与，而非清偿一笔并不存在的债务。

<!-- source-p 807 -->
<a id="41.4.7.3"></a>**3**　若监护人偷走未成年人的物并将其出售，在该物返还到未成年人控制之下以前，不发生取得时效；因为监护人仅在管理监护事务时才就未成年人的财产处于所有权人的地位，而在掠夺未成年人财产时并非如此。

<!-- source-p 808 -->
<a id="41.4.7.4"></a>**4**　有人善意买下他人的土地，后来丧失占有；此后，他在知道土地属于他人时重新取得占有，就不能通过长期占有取得该土地，因为第二次占有的起始带有瑕疵。这与另一种情形不同：买受人在订立买卖时以为土地属于出卖人，但在交付时知道土地属于他人。因为一旦占有丧失，就必须考察重新取得占有时的起点。因此，若奴隶在买受人知道其属于他人时被返还，买受人不能因取得时效而取得该奴隶，即使在出卖之前，该奴隶曾处于可以被取得时效取得的状态。被人从土地上驱逐后，通过禁令恢复占有、且当时知道土地属于他人的，也适用相同规则。

<!-- source-p 809 -->
<a id="41.4.7.5"></a>**5**　若有人明知某人已被裁判官禁止以可疑继承人身份减损遗产，仍从该人处买物，就不能因取得时效而取得该物。

<!-- source-p 810 -->
<a id="41.4.7.6"></a>**6**　若你的代理人本可将一块土地以一百枚金币出售，却仅为使你受损而以三十枚金币卖出，而买受人对此不知情，毫无疑问，买受人可以通过长期占有取得该土地。即使某人明知土地属于他人，却将土地卖给不知情者，也不妨碍长期占有的进行。反之，若买受人与代理人串通并以贿赂使代理人低价出售，该买受人就不被视为善意买受人，不能通过长期占有取得土地；若他对所有权人请求返还的诉讼提出“该物经所有权人同意出售”的抗辩，则可对其提出有用的欺诈再抗辩。

<!-- source-p 811 -->
<a id="41.4.7.7"></a>**7**　即使被窃物由所有权人占有，只要所有权人不知道该物曾被盗，就不视为该物已回到所有权人的控制之下。因此，若我将从你处偷来的奴隶质押给你，而你不知道该奴隶是自己的；我在债务清偿后又将奴隶卖给提提乌斯，提提乌斯便不能因取得时效而取得该奴隶。

<!-- source-p 812 -->
<a id="41.4.7.8"></a>**8**　善意为我们服劳役的自由人，依与我们的奴隶相同的方式，可以凭借我们的财产为我们取得财物。因此，我们既可以通过其交付取得自己的物，也可以通过其介入而因取得时效取得自己的物；若以应归我们所有的特有产为基础订立买卖，即使我们不知情，也可以因取得时效而取得该物。

斯凯沃拉《答复集》第五卷。

<!-- source-p 830 -->
某人善意买下他人的土地，并在长期占有期间届满前开始建造房屋。土地所有权人在长期占有期间届满前通知他停止建造，他仍继续施工。我问：其长期占有是否因此中断，还是已开始的期间继续计算？他答复说，依所述事实，期间并未中断。

<a id="41.4.14"></a>**41.4.14**

<!-- source-p 832 -->
斯凯沃拉《学说汇纂》第二十五卷。

<!-- source-p 833 -->
一名无遗嘱死亡的姐妹，其遗产由两名兄弟继承，一人缺席，另一人在场。在场者也为缺席的兄弟处理事务；他以自己和兄弟的名义，将整块土地卖给善意买受人卢基乌斯·提提乌斯。有人询问：既然他知道土地的一部分属于缺席的兄弟，买受人是否通过长期占有取得了整块土地？他答复说，若买受人相信该土地是经其兄弟授权出售的，就已通过长期占有取得该土地。
