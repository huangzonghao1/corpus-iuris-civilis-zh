# D.41.1 论取得物的所有权（*De adquirendo rerum dominio*）—第三部分

<!-- source-p 131 -->
<a id="41.1.27.1"></a>**1**　若将多种材料一并加工制成某种药物，或煮制芳香材料制成香膏，任何先前的所有人都不能真正主张其中某一部分属于自己。因此，应认为该物归制作时所代表之人所有。

<!-- source-p 132 -->
<a id="41.1.27.2"></a>**2**　若两名所有人的物以焊料连接在一起，讨论应归谁所有时，卡西乌斯说，应依各部分的比例或各自的价额判断。但若任何一部分都不构成另一部分的附合物，我们还应考察，是否应认为整个物归双方共有，如同材料混合形成一团；或归焊接时所代表的一方所有。普罗库鲁斯和佩加苏斯则认为，各自的物仍归各自所有。

<a id="41.1.30.pr."></a>**序言**　因此，若岛屿因添附而与我的土地相连，而我将土地较下方的部分出售给一名买受人，且岛屿并不面向该部分，则该买受人不会取得岛屿的任何部分；理由与岛屿形成之初该买受人即便是该部分土地的所有人，也不会因此取得岛屿相同。

<!-- source-p 142 -->
<a id="41.1.30.1"></a>**1**　切尔苏斯之子说，若一棵树在紧邻我土地的河岸上生长，该树归我所有，因为土地本身属于私人所有，只是其使用被视为公用。因此，河床干涸后，该处土地归附近土地所有人所有，因为人民不再使用该地。

<!-- source-p 143 -->
<a id="41.1.30.2"></a>**2**　河中岛屿有三种形成方式：其一，河流环绕一块原本不是河床的土地；其二，河流使原属河床的一处土地干涸，并开始从其周围流淌；其三，河流逐渐冲刷河床，使河床上方的一处高地显露出来，并通过添附使之扩大。依后两种方式形成的私人岛屿，在其最初显现时，归土地距离该岛最近的所有人所有；因为河流的自然属性决定，其流向一旦改变，河床的性质也随之改变。无论所讨论的仅是河床本身改变，还是地表因沉积泥土而改变，都没有区别；两种情形属于同一类型。第一种情形则不改变所有权归属的根据。

<!-- source-p 144 -->
<a id="41.1.30.3"></a>**3**　冲积添附可以恢复被河流冲力全部带走的土地。因此，若一块位于公路与河流之间的土地被河水淹没，无论是逐渐被淹没，还是被河水一举带走后又随河流退去而恢复，均应归原所有人所有。因为河流履行监察官的职能，能够将土地从私有转为公有，又从公有转为私有。因此，正如这块土地在成为河床时曾是公有土地，如今也应恢复为原先所有人的私有土地。

<!-- source-p 145 -->
<a id="41.1.30.4"></a>**4**　若我将桩柱投入海中，并在其上建造房屋，该建筑物立即归我所有。同样，若我在海中建造岛屿，该岛屿立即归我所有，因为无主之物归先行占有者取得。

<a id="41.1.33.pr."></a>**序言**　马尔切鲁斯在《学说汇纂》第二十卷讨论了以下问题：军人的家子尚未接受遗产之前，遗产将财物遗赠给该家子的军役特有产奴隶，或者该奴隶订立要式口约时，究竟以谁的身份为依据，使该口约或遗赠发生效力。我认为，斯凯沃拉的看法更为正确，马尔切鲁斯本人也讨论过这一点：若遗产已被接受，则一切应按遗产中的奴隶处理；若遗产尚未被接受，则按父亲自己的奴隶处理。若向该奴隶遗赠用益权，有时被认为是遗赠给父亲，有时被认为是遗赠给继承人；但不能认为用益权从一人转移给另一人。

<!-- source-p 156 -->
<a id="41.1.33.1"></a>**1**　即使有人取走该物，也应依据同一区分处理：若遗产已被接受，由于盗窃不能针对遗产成立，便不产生盗窃之诉；若遗产尚未被接受，则应向父亲授予盗窃之诉。

<!-- source-p 157 -->
<a id="41.1.33.2"></a>**2**　尤利安认为，每当遗产中的奴隶订立要式口约或通过交付接受某物时，返还之诉也以死者的身份为依据取得效力；他认为这一意见有效，因为应考察立遗嘱人的身份。

<a id="41.1.37"></a>**41.1.37**

<!-- source-p 168 -->
尤利安《学说汇纂》第四十四卷。

<!-- source-p 169 -->
<a id="41.1.37.pr."></a>**序言**　以奴隶作质押时，债权人不能通过该奴隶取得占有；尽管奴隶处于债权人的占有之下，债权人仍不能通过该奴隶的要式口约、交付或其他任何方式取得财物。

<!-- source-p 170 -->
<a id="41.1.37.1"></a>**1**　共有奴隶的一名共有人若赠与该奴隶钱款，如何赠与由该共有人决定。若其仅意在将这笔钱从自己的账目中分离，并置于该奴隶的特有产中，则钱款仍归该共有人所有；但若他像通常赠与他人奴隶那样向共有奴隶赠与钱款，则该钱款成为共有人共有的财物，份额依各自在该奴隶中的所有权比例确定。

<!-- source-p 171 -->
<a id="41.1.37.2"></a>**2**　为讨论接下来的问题，先假定一名共有人向共有奴隶赠与钱款，并希望自己仍保有该钱款的所有权。若奴隶用这笔钱购买土地，该土地便按各共有人对奴隶享有的所有权份额归其共有；即使共有奴隶用盗窃所得的钱币购买土地，土地也同样按共有人份额归其共有。用益权奴隶以用益权人的财物取得财物时，用益权人取得而裸所有权人不取得；共有奴隶以其中一名所有人的财物取得财物时，则并非如此。至于奴隶从其他来源取得的财物，用益权人与共有奴隶所有人的地位不同：用益权奴隶不为用益权人取得，但共有奴隶会为其所有人取得。因而，若共有奴隶以用益权人的财物取得财物，该财物仅归用益权人；若共有奴隶以其中一名所有人的财物取得财物，则归两名所有人共有。

<!-- source-p 172 -->
<a id="41.1.37.3"></a>**3**　共有奴隶若在订立要式口约时明确指定一名共有人，就像通过交付受领物品时一样，仅为该共有人取得该物。

<!-- source-p 173 -->
<a id="41.1.37.4"></a>**4**　一人的奴隶若在交付受领物品时称其是为自己的主人和提提乌斯受领，则仅为自己的主人取得该物的一部分；对另一部分则不发生效力。

<!-- source-p 174 -->
<a id="41.1.37.5"></a>**5**　用益权奴隶若称自己通过交付为裸所有权人受领物品，而该物源自用益权人的财物，则应为裸所有权人取得全部；因为若该奴隶以用益权人的财物订立要式口约，也会为裸所有权人取得该物。

<!-- source-p 175 -->
<a id="41.1.37.6"></a>**6**　若你打算赠与我，我命令你将物交付给我与提提乌斯共有的奴隶，而该奴隶以使物归提提乌斯所有为目的受领，则交付不发生效力。正如你将物交付给我的代理人，使物归我所有，而代理人却以使物归自己所有为目的受领时，交付也不发生效力。若共有奴隶以使物归两名主人共有为目的受领，则就另一名共有人所享有的份额而言，交付不发生效力。

有人问：若自由人曾善意地为某人服役，该人死亡后由一名知道此人是自由人的继承人继承，那么继承人能否通过此人取得任何财物？阿非利卡努斯说，不能；继承人既然明知对方是自由人，就不能被视为善意占有人。正如有人将自己的土地遗赠出去，知道该土地已被遗赠的继承人，显然不能取得该土地的收益；若立遗嘱人曾基于善意买卖而占有他人土地，更应如此。对于奴隶的劳务和服侍，也应遵循同一理由：无论相关奴隶原本属于继承人本人或他人，是遗赠取得，还是依据遗嘱获释，只要继承人知晓其身份，就不应通过他们取得任何财物。一般说来，善意占有人若可将土地的收益消费归己，奴隶也会在同一情形下通过其劳务及其财物为此人取得利益。
