<a id="41.3.4"></a>**41.3.4**

<!-- source-p 555 -->
保罗《告示评注》第五十四卷。

<!-- source-p 556 -->
<a id="41.3.4.pr."></a>**序言**　接下来应论述取得时效。论述应依下列次序进行：考察谁可以取得时效、哪些物可以取得时效，以及须经过多长时间。

<!-- source-p 557 -->
<a id="41.3.4.1"></a>**1**　家父可以取得时效。家子也可以取得时效，尤其是军人对其在军营中取得之物可以取得时效。

<!-- source-p 558 -->
<a id="41.3.4.2"></a>**2**　未适婚人若在监护人认可下开始占有，可以取得时效。若其未获监护人认可而占有，但具有占有意思，我们会说他也能够取得时效。

<!-- source-p 559 -->
<a id="41.3.4.3"></a>**3**　疯癫者对其在疯癫前开始占有的物，可以取得时效。但此人只有基于能够产生取得时效的原因占有该物时，才可以取得时效。

<!-- source-p 560 -->
<a id="41.3.4.4"></a>**4**　奴隶不能以继承人身份占有。

<!-- source-p 561 -->
<a id="41.3.4.5"></a>**5**　女奴所生子女、牲畜所生幼畜以及果实，若并非属于死者所有，均可取得时效。

<!-- source-p 562 -->
<a id="41.3.4.6"></a>**6**　《阿提尼亚法》规定，被盗之物不得取得时效，除非该物返回被盗之人的控制之下。对此应作如下理解：该物必须返回所有人的控制之下，而不必返回被盗之人的控制之下。因此，若物从债权人或借用人处被盗，应返回所有人的控制之下。

<!-- source-p 563 -->
<a id="41.3.4.7"></a>**7**　拉贝奥也说，若我奴隶特有产中的物在我不知情时被盗，后来该奴隶又取得此物，看来该物已经返回我的控制之下。更妥当的说法是，即使我知情，该物也已返回我的控制之下；当然，仅仅是我不知情时该奴隶取回其失物，还不够。前提是我愿意让该物继续属于其特有产；若我不愿意，就必须要求我自己已取得对该物的控制能力。

<!-- source-p 564 -->
<a id="41.3.4.8"></a>**8**　因此，即使我的奴隶偷了我的物，随后又把它放回原处，也可以取得时效，因为该物似已返回我的控制之下；当然，这以我不知情为限。若我知情，则还须证明我知道该物已经返回我的控制之下。

<!-- source-p 565 -->
<a id="41.3.4.9"></a>**9**　庞波尼乌斯说，若我的奴隶以特有产名义持有他偷来的物，该物就不应被认为已返回我的控制之下；除非我们开始像被盗以前那样持有该物，或者在发现此事后，仍允许奴隶将其作为特有产持有。拉贝奥也持此见解。

<!-- source-p 566 -->
<a id="41.3.4.10"></a>**10**　若你为牟利而出售我寄存于你处的物，之后又因悔悟而买回，并使其保持原状；无论此事发生时我知情与否，依普罗库鲁斯的意见，该物均应视为已经返回我的控制之下；这一意见是正确的。

<!-- source-p 567 -->
<a id="41.3.4.11"></a>**11**　若未适婚人的物被盗，应当说，只要其监护人知道该物已返回未适婚人的家中，就足够了。若物属于疯癫者，则只要其保佐人知道即可。

<!-- source-p 568 -->
<a id="41.3.4.12"></a>**12**　只有在所有人依法取得该物的占有、使该物不可能再被取走，并且是将其作为自己的物来持有时，才应说该物返回所有人的控制之下。因此，若我不知情而买下被盗于我的物，该物不应被认为已返回我的控制之下。

<!-- source-p 569 -->
<a id="41.3.4.13"></a>**13**　但是，即使我请求返还被盗于我的物并取得诉讼估价金，虽未实际取得该物的占有，该物仍可以取得时效。

<!-- source-p 570 -->
<a id="41.3.4.14"></a>**14**　若该物经我同意交付给他人，也应作同样的说明。

<!-- source-p 571 -->
<a id="41.3.4.15"></a>**15**　继承人承受死者的法律地位；即使他在不知该女奴为被盗之物的情况下取得了她，而她在其处受孕并生子，他仍不能取得时效。

<!-- source-p 572 -->
<a id="41.3.4.16"></a>**16**　有人问：若我的奴隶把他偷来的女奴交给我，以换取我授予他自由，我能否对她在我处受孕所生的子女取得时效？萨宾和卡西乌斯认为不能，因为奴隶以有瑕疵的方式取得占有，会损害其主人；这一意见是正确的。

<!-- source-p 573 -->
<a id="41.3.4.17"></a>**17**　同样，若他人把被盗女奴交给我，以便我释放自己的奴隶，而该女奴在我处受孕并生子，我也不能取得时效。若有人把该女奴与我的物交换、用来清偿对我的债务，或赠与我，也应如此处理。

<!-- source-p 574 -->
<a id="41.3.4.18"></a>**18**　若买受人在女奴分娩前发现她属于他人，我们已说过，他不能取得时效；若他不知情，则可以。若他在取得时效期间开始后才知道她属于他人，就应考察取得时效开始时的情况，这与买受物的规则相同。

<!-- source-p 575 -->
<a id="41.3.4.19"></a>**19**　被盗绵羊的羊毛，若是在盗窃者处剪下，就不能取得时效；若是在善意买受人处剪下，则相反。因为羊毛属于孳息，不应通过取得时效取得，而是立即归买受人所有。若被盗羊羔已经被消耗，也应如此处理；此说是正确的。

<!-- source-p 576 -->
<a id="41.3.4.20"></a>**20**　若你用被盗羊毛制成衣服，较妥当的意见是应考察其物质本体，因此该衣服属于被盗之物。

<!-- source-p 577 -->
<a id="41.3.4.21"></a>**21**　若债务人偷走作为质押交付的物并将其出售，卡西乌斯写道，该物可以取得时效，因为该物似已进入作为出质人的所有人控制之下；尽管仍可对债务人提起盗窃诉讼。我认为这种说法更为正确。

<!-- source-p 578 -->
<a id="41.3.4.22"></a>**22**　若你以暴力把我从土地占有中驱逐，却没有取得该土地的占有，而提提乌斯进入了无人占有的土地，则该物可以经过长期占有而取得时效。虽然因我确实被暴力驱逐，可以适用《因暴力驱逐令》；但并不能说提提乌斯也是以暴力取得占有。

<!-- source-p 579 -->
<a id="41.3.4.23"></a>**23**　此外，即使你以恶意占有土地为由将我暴力驱逐，随后又出售该土地，也不能取得时效，因为该土地确是以暴力取得占有，尽管施暴者并非所有人。

<!-- source-p 580 -->
<a id="41.3.4.24"></a>**24**　对驱逐以继承人身份占有者的人，也应作同样的说明；即使他知道该物属于遗产，仍因以暴力占有而不能取得时效。

<!-- source-p 581 -->
<a id="41.3.4.25"></a>**25**　若土地所有人以暴力驱逐占有人，卡西乌斯说，该土地不应被认为已经返回所有人的控制之下，因为所有人将依据《因暴力驱逐令》返还占有。

<!-- source-p 582 -->
<a id="41.3.4.26"></a>**26**　若我有权经由你的土地通行，而你以暴力阻止我通行，我因长期不行使该权利，会丧失通行权；因为无体权利不能被认为可以占有，也不能说某人被逐出通行权——这只是法律上的权利。

<!-- source-p 583 -->
<a id="41.3.4.27"></a>**27**　同样，若你占有一块无人占有的土地，随后阻止所有人前来，也不应认为你是以暴力占有。

<!-- source-p 584 -->
<a id="41.3.4.28"></a>**28**　较为正确的意见是，役权可以因取得时效而消灭。因为《斯克里波尼亚法》废除了通过取得时效设立役权的规则，却没有废除通过消灭役权而使土地免受役权负担的取得时效。因此，若我负有一项役权，例如不得把建筑建得更高，而我在法定期间内一直把建筑建得更高，该役权就会消灭。

<a id="41.3.15.pr."></a>**序言**　若以买受人身份占有的人在取得时效完成前被敌人俘获，应考察取得时效能否对其继承人继续发生效力。取得时效毕竟会中断；若该人返还后也不能受益，继承人又怎能受益？但正确的说法是，他在生前已停止占有；因此，复归权也不能使他被视为已经取得时效。尤利安说，若处于敌人控制之下者的奴隶买下某物，取得时效的完成则处于待定状态：若主人返还，就视为已经取得时效；若他死在那里，则是否依《科尔内利亚法》将该物归其继承人，尚有疑问。马尔凯鲁斯认为，可以更充分地理解该法的拟制：依复归权返回的人，对于其奴隶所实施的行为，可以享有比其被俘时本人或通过奴隶占有的物更多的权利。因为，人们承认，在某些事项中，遗产可以代替人的身份。因此，继承人不能继续进行取得时效。

<!-- source-p 624 -->
<a id="41.3.15.1"></a>**1**　若我占有的奴隶逃跑，却表现得像自由人，应认为他仍由主人占有。但只有在以下情形才如此理解：如果他被抓获，并不准备为自己的自由身份提起诉讼。若他准备提起此种诉讼，就不应认为他由主人占有，因为他已准备以对方当事人的身份与主人争讼。

<!-- source-p 625 -->
<a id="41.3.15.2"></a>**2**　若某人善意占有一物，在取得时效完成前丧失占有，随后得知该物属于他人，又重新取得占有，他不能取得时效，因为第二次占有的起始带有瑕疵。

<!-- source-p 626 -->
<a id="41.3.15.3"></a>**3**　若依遗嘱或要式口约而应交付给我们的物被交付，应以交付时我们的认识为准；因为法律允许约定给付并非允诺人所有的物。

丈夫出售嫁资地产，无论买受人知道还是不知道该物属于嫁资，买卖均无效。若妻子此后在婚姻存续期间死亡，且全部嫁资归丈夫受益，适宜确认该买卖有效。规则相同于：某人出售被盗之物，后来成为该物所有人的继承人。

<a id="41.3.43"></a>**41.3.43**

<!-- source-p 730 -->
帕比尼安《疑问集》第二十二卷。

<!-- source-p 731 -->
<a id="41.3.43.pr."></a>**序言**　善意购买某物之人的继承人，若知道该物属于他人，就不能取得时效；但以该物的占有已经直接交付给继承人为限。继承人知情本身，不会妨碍取得时效期间的连续计算。

<!-- source-p 732 -->
<a id="41.3.43.1"></a>**1**　可以确定，父亲不能对儿子购买的物取得时效，无论父亲还是儿子知情，均是如此。

<!-- source-p 733 -->
<a id="41.3.44"></a>**41.3.44**

<!-- source-p 734 -->
帕比尼安《疑问集》第二十三卷。

<!-- source-p 735 -->
<a id="41.3.44.pr."></a>**序言**　我因正当的错误，认为提提乌斯是我的儿子并处于我的家父权之下，然而收养并未依法进行。我不认为他能通过我的财产为我取得任何东西。对于善意服役的自由人，法律认可另一种规则；但该规则之所以确立，是因为自由人长期、持续地与奴隶相似，公共利益要求加以规范——毕竟我们经常在不知情时买下自由人。收养或 *arrogatio* 家子的错误则没有那么容易、也没有那么常见。

<!-- source-p 736 -->
<a id="41.3.44.1"></a>**1**　可以确定，若你明知某物属于我，却将其出售给我，并在所有人追认之时才交付该物，应以交付时为准，该物就成为我的。

<!-- source-p 737 -->
<a id="41.3.44.2"></a>**2**　虽然取得时效通常考察占有开始的时间，而非合同订立的时间，但有时我们也考察更早的交付原因及其所具有的善意。例如，某人善意开始占有一名妇女，其所生子女即属此例；即使他在分娩前得知母亲属于他人，该子女仍可被取得时效取得。对依复归权归来的奴隶，也作同样处理。

<!-- source-p 738 -->
<a id="41.3.44.3"></a>**3**　法律允许在继承尚未被接受前经过的期间计入取得时效，无论是遗产奴隶购买某物，还是死者已经开始取得时效；但这些规则属于特别法上的例外。

<!-- source-p 739 -->
<a id="41.3.44.4"></a>**4**　家子购买他人之物，却不知道自己已经成为家父，开始占有交付给他的物。既然占有开始时他是善意的，为什么不能取得时效？尽管他错误地认为自己属于不能占有通过特有产取得之物的人，也应如此。若他有充分理由相信所购之物已因父亲的遗产而归自己所有，也应作同样的说明。

<!-- source-p 740 -->
<a id="41.3.44.5"></a>**5**　后来基于买受人身份或继承人身份取得时效，不会损害质权追索权。正如用益权不能因取得时效而取得，质权追索权也不会因对该物取得时效而消灭；质权追索权并非基于所有权的共同关系，而仅由约定设立。

<!-- source-p 741 -->
<a id="41.3.44.6"></a>**6**　若某人在开始取得时效后陷入疯癫，基于衡平考虑，允许其基于任何原因完成取得时效，以免精神疾病进一步使其财产遭受损失。

<!-- source-p 742 -->
<a id="41.3.44.7"></a>**7**　若所有人或家父身处敌人控制之下，其奴隶或家子购买物品，是否开始占有？若其以特有产为由取得占有，取得时效即开始；所有人被俘并不构成障碍，因为法律不要求主人在罗马境内知悉此事。若购买并非基于特有产，则不能取得时效，也不能认为依复归权取得了该物，因为要取得时效，先须占有。若家父死于敌境，由于被俘期间自其被俘之日起计算至死亡，可以说家子既为自己占有，也应视为已取得时效。

<!-- source-p 743 -->
<a id="41.3.45"></a>**41.3.45**

<!-- source-p 744 -->
帕比尼安《答复集》第十卷。

<!-- source-p 745 -->
<a id="41.3.45.pr."></a>**序言**　通常不准许通过长期占有的时效取得依万民法属于公有的场所。以下情形适用这一规则：有人在海岸建造房屋，房屋后来被彻底毁坏——例如被拆除或废弃——之后他人又在同一地点建造房屋，前者却提出授予占有人的抗辩；或者某人多年独自在公共河流的支汊捕鱼，便以同一权利阻止他人捕鱼。

<!-- source-p 746 -->
<a id="41.3.45.1"></a>**1**　所有人死亡后，遗产奴隶开始以特有产名义持有某物，取得时效的起算点应为继承被接受之时。因为，死者此前并未占有的物，又怎能被取得时效取得？
