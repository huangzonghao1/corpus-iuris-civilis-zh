# D.41.1 论取得物的所有权（*De adquirendo rerum dominio*）—第二部分

<!-- source-p 71 -->
未适婚人取得财产无须监护人授权；但其未经监护人在场并给予授权，不得让与任何物，甚至不得让与自然意义上的占有。萨宾学派持此意见，而且这一意见是正确的。

<a id="41.1.12"></a>**41.1.12**

<!-- source-p 73 -->
卡利斯特拉图斯《法学阶梯》第二卷。

<!-- source-p 74 -->
<a id="41.1.12.pr."></a>**序言**　湖泊和池塘虽有时涨水、有时干涸，却仍保持原有边界，因此不适用冲积添附规则。

<!-- source-p 75 -->
<a id="41.1.12.1"></a>**1**　若将我的青铜与你的白银熔合而制成某种新物，该物不会成为我们的共有物；因为青铜和白银属于不同材料，通常可以由工匠将其分离并还原为原来的材料。

<a id="41.1.13"></a>**41.1.13**

<!-- source-p 77 -->
涅拉提乌斯《法律格言》第六卷。

<!-- source-p 78 -->
<a id="41.1.13.pr."></a>**序言**　若代理人依我的委托为我购买某物，并以我的名义受领交付，即使我对此不知情，该物的所有权也归我取得。

<!-- source-p 79 -->
<a id="41.1.13.1"></a>**1**　监护人也可像代理人一样，以未适婚人的名义购买，从而使该未适婚人取得所有权，即使其对此并不知情。

<!-- source-p 80 -->
<a id="41.1.14"></a>**41.1.14**

<!-- source-p 81 -->
涅拉提乌斯《纸草札记》第五卷。

<!-- source-p 82 -->
<a id="41.1.14.pr."></a>**序言**　在海岸建造的建筑物归建造者所有。海岸虽属公有，却并非如人民财产那样属于人民所有；它与最初由自然产生、尚未归任何人所有的物相同。因此，海岸的法律地位与鱼类和野兽相同：鱼类和野兽一经捕获，毫无疑问便归控制它们之人所有。

<!-- source-p 83 -->
<a id="41.1.14.1"></a>**1**　还须考察：海岸上的建筑物被拆除后，该处地块处于何种地位？它是否仍归原建筑物所有人所有，还是回复原先状态，如同从未在该处建造过一样，再度成为公有？较妥当的看法是，只要该处恢复了原有海岸形态，就应认定它回复原有状态。

<a id="41.1.16"></a>**41.1.16**

<!-- source-p 88 -->
弗洛伦提努斯《法学阶梯》第六卷。

<!-- source-p 89 -->
在经界标划定的土地上，不适用冲积添附规则，这是确定的。神圣的庇护皇帝也曾作此规定。特雷巴提乌斯说，战胜敌人后依附有纳入本城邦条件而授予的土地，仍享有冲积添附权，因此并非经界标划定的土地；而以武力征服所得的土地则曾按界标划定，以便知悉分给各人的土地、已出售的土地以及作为公地保留的土地。

<!-- source-p 96 -->
<a id="41.1.19"></a>**41.1.19**

<!-- source-p 97 -->
庞波尼《萨宾评注》第三卷。

<!-- source-p 98 -->
阿里斯托毫无疑问地说：自由人善意地为我服役时，他以自己的劳务或我的财物所取得的物，归我所有；但他人赠与他的物，或他经无因管理所取得的物，则归其本人所有。经他取得的遗产或遗赠不归我所有，因为这既非源自我的财物，也非源自他的劳务；遗赠中不涉及任何劳务，遗产虽在某种程度上与其劳务有关，因为遗产须经他接受，但这方面瓦里乌斯·卢库卢斯也曾有过疑问。更为正确的意见是，这类遗产或遗赠不归我取得，即使遗嘱人希望其归我所有也是如此。不过，尽管我并未因此取得遗产，若遗嘱人的意思明确，仍应将遗产返还给我。特雷巴提乌斯认为，若自由人善意地为他人服役，并依其所服役之人的命令接受遗产，该自由人本人就成为继承人；其主观想法如何并不重要，重要的是其所实施的行为。拉贝奥则持相反意见：若他是出于不得已而如此行事，则另当别论；但若他也出于自己的意愿如此行事，则他本人就成为继承人。

<!-- source-p 99 -->
<a id="41.1.20"></a>**41.1.20**

<!-- source-p 100 -->
乌尔比安《萨宾评注》第二十九卷。

<!-- source-p 101 -->
<a id="41.1.20.pr."></a>**序言**　交付既不能也不应使受领人取得超过交付人所拥有的权利。因此，若有人拥有土地所有权，通过交付即可转移该所有权；若其并不拥有该所有权，交付便不能使受领人取得任何所有权。

<!-- source-p 102 -->
<a id="41.1.20.1"></a>**1**　所有权转移时，受让人取得的权利状态与交付人原有的状态相同：若土地为役地，所有权转移时役权一并转移；若土地为自由地，则仍为自由地。若被交付的土地负有役权，该役权也随土地一并转移。因此，若有人在交付时声称土地为自由地，而该地实际为役地，他不能消灭土地负担的役权；不过，他要对自己的陈述负责，并须履行其所承诺的事项。

<!-- source-p 103 -->
<a id="41.1.20.2"></a>**2**　若我和提提乌斯共同购买某物，而该物交付给提提乌斯，并且提提乌斯是作为我的代理人受领，我认为我也取得了所有权；因为已认可通过不受权力支配的自由人取得任何物的占有，也可通过此人取得所有权。

<!-- source-p 104 -->
<a id="41.1.21"></a>**41.1.21**

<!-- source-p 105 -->
庞波尼《萨宾评注》第十一卷。

<!-- source-p 106 -->
<a id="41.1.21.pr."></a>**序言**　若我的奴隶善意地为你服役，购买某物并受领交付，普罗库鲁斯认为，我不会因此取得该物，因为我并不占有该奴隶；你也不会取得，因为该物并非用你的财物购买。但若一名自由人善意地为你服役并购买某物，该物便归其本人所有。

<!-- source-p 107 -->
<a id="41.1.21.1"></a>**1**　若你占有我的物，而我愿意使该物归你所有，即使我并未占有该物，该物也会成为你的。

<!-- source-p 111 -->
<a id="41.1.23"></a>**41.1.23**

<!-- source-p 112 -->
乌尔比安《萨宾评注》第四十三卷。

<!-- source-p 113 -->
<a id="41.1.23.pr."></a>**序言**　某人若善意地为他人服役，无论其是他人之奴隶还是自由人，只要他以所服役之人的财物取得某物，该物便归其善意服役之人所有。若他以自己的劳务取得某物，也同样归其善意服役之人所有；因为劳务在某种意义上也属于其服役之人的财物，毕竟他依法有义务向善意服役之人提供劳务。

<!-- source-p 114 -->
<a id="41.1.23.1"></a>**1**　他仅在善意服役期间为该人取得财物。若他开始知道自己服役之人属于他人，或知道自己其实是自由人，我们就须考察此后取得的财物是否仍归该服役之人所有。问题在于，应看善意开始之时，还是应逐个时点考察；较妥当的是逐个时点考察。

<!-- source-p 115 -->
<a id="41.1.23.2"></a>**2**　一般而言，若某人不能以其善意服役之人的财物为该人取得某物，该物便由其本人取得；反之，若他不能以不属于该服役之人的财物为自己取得某物，该物便由其善意服役之人取得。

<!-- source-p 116 -->
<a id="41.1.23.3"></a>**3**　若某人善意地同时为两人服役，他可为二人取得财物，但分别以各自的财物取得。若财物源自其中一人的财物，则应考察：该财物是否应由服役之人按份取得，若此人是奴隶则其所有人也按份取得；若此人是自由人，则仍由其服役之人按份取得；还是应全部归财物来源一方所有。斯凯沃拉在《疑问集》第二卷也讨论了这一情形。他说，若他人的奴隶善意地同时为两人服役，并以其中一人的财物取得某物，依其理由应由该人单独取得全部。若该奴隶又在要式口约中指明其财物来源，他认为毫无疑问，应仅由该人取得全部；因为即使该奴隶是用某一共有人之财物订立要式口约，只要明确以该共有人之名订约，该共有人就取得全部。斯凯沃拉在后文还认可：即使该奴隶既未明确以我的名义，也未依我的命令订约，只要他在善意地为多人服役期间以我的财物订立口约，仍由我单独取得。因为已普遍承认：共有奴隶无法为所有共有人取得时，只能为其中可以取得者取得。我曾多次提到尤利安也作此论述，我们正是依此规则行事。

<a id="41.1.26.pr."></a>**序言**　但是，若你用我的木板造船，船便属于你，因为原有的柏木材料不复存在；正如羊毛制成衣物后，羊毛也不复存在，而形成了柏木制品或羊毛制品。普罗库鲁斯指出，我们适用塞尔维乌斯与拉贝奥所采纳的法律：对于具有特定性质的物，只要加入某物，该物便全部归原物所有人所有，例如雕像上的脚或手、酒杯的底座或把手、床的脚、船的木板、建筑物中的水泥；因为这些组成部分均属于其原先所属之物的所有人。

<!-- source-p 126 -->
<a id="41.1.26.1"></a>**1**　树木被连根拔起后移植到别处，在重新扎根之前仍属于原所有人；一旦扎根，就随土地归属；若之后再次被连根拔起，也不会返还给原所有人，因为可以相信，经由别处土地的滋养，它已成为另一棵树。

<!-- source-p 127 -->
<a id="41.1.26.2"></a>**2**　若你将我的羊毛染成紫色，拉贝奥说，该羊毛仍属于我，因为紫色羊毛与掉进泥土或污泥中、因而失去原有颜色的羊毛，并无区别。
