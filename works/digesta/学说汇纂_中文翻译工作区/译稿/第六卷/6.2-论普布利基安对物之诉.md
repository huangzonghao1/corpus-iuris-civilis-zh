<a id="2"></a>
# <a id="6.2"></a>6.2.0　论普布利基安对物之诉（*De publiciana in rem actione*）

### <a id="6.2.1"></a>6.2.1　乌尔比安《评告示》第十六卷

<a id="6.2.1.pr."></a>

**序言（pr.）** 裁判官告示称：“如果有人请求返还某物，而该物系基于正当原因由非所有权人交付给他且尚未因取得时效而取得，我将授予其诉权。”

<a id="6.2.1.1"></a>

**1.** 裁判官说“尚未因取得时效而取得”，确有道理：因为如果已经因取得时效取得，该人便有市民法上的诉讼，无须请求荣誉法上的诉讼。

<a id="6.2.1.2"></a>

**2.** 但是，为什么裁判官只提到交付和取得时效，而没有提到诸多可以取得所有权的法律原因呢？例如遗赠。

### <a id="6.2.2"></a>6.2.2　保罗《评告示》第十九卷

例如因死因赠与而取得的物：因为丧失占有后，普布利基安之诉即告适用；这是因为此类赠与是参照遗赠处理的。

### <a id="6.2.3"></a>6.2.3　乌尔比安《评告示》第十六卷

<a id="6.2.3.pr."></a>

**序言（pr.）** 此外还有许多其他情形。

<a id="6.2.3.1"></a>

**1.** 裁判官称：“依正当原因请求返还。”因此，凡具有交付之正当原因者，均可使用普布利基安之诉。该诉讼不仅适用于善意买受人，也适用于其他人；例如，某物以嫁资名义交付给某人而尚未因取得时效取得的情形。无论该物是否经估价后作为嫁资交付，其原因都是极为正当的。同样，如果某物是基于判决原因而交付的，亦属此类。

### <a id="6.2.4"></a>6.2.4　保罗《评告示》第十九卷

或者，基于清偿原因交付。

### <a id="6.2.5"></a>6.2.5　乌尔比安《评告示》第十六卷

或者，出于诺克萨交付（即交付致害奴隶以承担责任；*noxae deditio*）的原因；无论该原因真实与否，均是如此。

### <a id="6.2.6"></a>6.2.6　保罗《评告示》第十九卷

同样，如果某奴隶因致害之诉未获辩护，我依裁判官命令将其带走，后来又丧失了对他的占有，则我可以提起普布利基安之诉。

### <a id="6.2.7"></a>6.2.7　乌尔比安《评告示》第十六卷

<a id="6.2.7.pr."></a>

**序言（pr.）** 此外，如果某物已经经判决归属某人，亦适用普布利基安之诉。

<a id="6.2.7.1"></a>

**1.** 如果诉讼标的已经估价，其情形类似买卖。尤利安在《学说汇纂》第二十二卷中说，如果被告提出支付诉讼标的的估价金额，则适用普布利基安之诉。

<a id="6.2.7.2"></a>

**2.** 马尔凯卢斯在《学说汇纂》第十七卷中写道：某人不知道对方神志失常而从其处购买物品，可以因取得时效而取得该物。因此，他也可以提起普布利基安之诉。

<a id="6.2.7.3"></a>

**3.** 此外，如果某人基于无偿取得的原因取得某物，他也有普布利基安之诉，且可对赠与人提起；因为接受赠与的人是正当占有人和请求人。

<a id="6.2.7.4"></a>

**4.** 如果某人不知道出卖人未成年而向其购买，他可以提起普布利基安之诉。

<a id="6.2.7.5"></a>

**5.** 此外，如果发生了互易，亦适用同一诉讼。

<a id="6.2.7.6"></a>

**6.** 普布利基安之诉着眼于所有权，而非占有。

<a id="6.2.7.7"></a>

**7.** 如果我请求返还某物时，你要求我宣誓该物属于我，而我宣誓该物属于我，则我可以对你提起普布利基安之诉，但仅能对你提起；因为宣誓只应对要求宣誓的人发生不利后果。但是，如果向占有人提出宣誓要求，而占有人宣誓该物不属于请求人，他只能在请求人向其提起诉讼时援用抗辩，并不能因此取得诉权。

<a id="6.2.7.8"></a>

**8.** 在普布利基安之诉中，所有事项均与我们在所有物返还之诉中所说的相同。

<a id="6.2.7.9"></a>

**9.** 继承人和荣誉法上的继受人均可提起此诉。

<a id="6.2.7.10"></a>

**10.** 如果不是我本人购买，而是我的奴隶购买，我也可以提起普布利基安之诉。我的代理人、监护人、保佐人或其他管理我事务的人为我购买时，亦同。

<a id="6.2.7.11"></a>

**11.** 裁判官称：“善意买受人。”因此，并非任何买受行为都足以产生此效力，而须是善意的买受。由此，只要我是善意买受人，即使并非从所有权人处购买，也已足够，即便出卖人以欺诈手段出卖亦然；因为出卖人的欺诈不应损害我。

<a id="6.2.7.12"></a>

**12.** 在此诉讼中，如果我的继受人实施了欺诈，而我所继受之人是善意买受人，这不会对我不利；反之，如果我本人没有欺诈，而我所继受的买受人实施了欺诈，也不会对我有利。〔底本疑文：原文作 *si successor suum et dolo feci*，语法与上下文不合；此处依上下文暂译为“我的继受人实施了欺诈”，有待校勘。〕

<a id="6.2.7.13"></a>

**13.** 但是，如果是我的奴隶购买，应当考察他的欺诈，而非我的欺诈；反之亦然。

<a id="6.2.7.14"></a>

**14.** 普布利基安之诉所考察的是买受时点的情形。因此，庞波尼乌斯似乎认为，在此诉讼中，不应考虑买受之前或之后以恶意实施的行为。

<a id="6.2.7.15"></a>

**15.** 此外，善意只涉及买受人本人。

<a id="6.2.7.16"></a>

**16.** 要使普布利基安之诉得以适用，必须同时具备以下条件：某人善意购买该物，并且该物以买受为原因交付给他。否则，在交付之前，即使某人为善意买受人，也不得提起普布利基安之诉。

<a id="6.2.7.17"></a>

**17.** 尤利安在《学说汇纂》第七卷中写道，买受物的交付也必须是善意的。因此，如果某人明知占有属于他人而取得该占有，他便不得提起普布利基安之诉，因为他不能因取得时效而取得该物。不要以为我们的意思是，只要某人在交付开始时不知道该物属于他人，就足以使他能够提起普布利基安之诉；还必须要求其在该时点也是善意买受人。

### <a id="6.2.8"></a>6.2.8　盖尤斯《评行省告示》第七卷

关于价款是否已付，告示没有作出明文说明。因此可以推知，裁判官的意思似乎并非要求查明价款是否已经支付。

### <a id="6.2.9"></a>6.2.9　乌尔比安《评告示》第十六卷

<a id="6.2.9.pr."></a>

**序言（pr.）** 无论买受人本人还是买受人的继承人取得了该物的交付，均可提起普布利基安之诉。

<a id="6.2.9.1"></a>

**1.** 如果某人购买了寄存在自己处、借用给自己或质押给自己的物品，只要买受后该物仍留在其处，就应视为已经交付。

<a id="6.2.9.2"></a>

**2.** 如果交付先于买受发生，也应作相同解释。

<a id="6.2.9.3"></a>

**3.** 同样，如果我购买了一项遗产，并希望请求返还已经交付给我的遗产物品，涅拉提乌斯写道，我可以提起普布利基安之诉。

<a id="6.2.9.4"></a>

**4.** 如果某人分别将同一物出卖给两个善意买受人，我们应当考察谁更有理由使用普布利基安之诉：是先取得该物交付的人，还是仅仅购买该物的人。尤利安在《学说汇纂》第七卷中写道，如果他们是从同一个非所有权人处购买，则先取得该物交付的人地位较优；如果他们是从不同的非所有权人处购买，则占有人的地位优于请求返还的人。此说是正确的。

<a id="6.2.9.5"></a>

**5.** 对于不能因取得时效取得的物品，例如盗赃物或逃亡奴隶，不适用此诉。

<a id="6.2.9.6"></a>

**6.** 如果遗产中的奴隶在遗产被接受之前购买了某物，后来丧失了已经交付给他的占有，则继承人可以正当地提起普布利基安之诉，仿佛是继承人本人曾经占有该物一样。奴隶受某市镇共同体所有且该物交付给该奴隶时，该共同体也处于相同地位，

### <a id="6.2.10"></a>6.2.10　保罗《评告示》第十九卷

无论该奴隶是以特有财产名义购买，还是并非如此，均是如此。

### <a id="6.2.11"></a>6.2.11　乌尔比安《评告示》第十六卷

<a id="6.2.11.pr."></a>

**序言（pr.）** 如果我购买某物，而该物经我同意交付给他人，塞维鲁皇帝以敕答规定，应当给予该他人普布利基安之诉。

<a id="6.2.11.1"></a>

**1.** 如果诉讼涉及已经交付的用益权，应给予普布利基安之诉。城市土地役权经交付或容忍而设立的，也同样如此；例如，某人容许他人将水道引经自己的房屋。乡村土地役权亦同，因为在此情形下，交付和容忍也应受到保护，这一点是确定的。

<a id="6.2.11.2"></a>

**2.** 被盗女奴所生的子女，如果是在善意买受人处受胎，可以通过此诉请求返还，即使买受人本人并未占有该子女亦然。但是，窃贼的继承人没有此诉，因为他是死者瑕疵的继受人。

<a id="6.2.11.3"></a>

**3.** 然而，有时即使被盗女奴的母亲并未被出卖，而是被赠与了不知情的我，并在我处受胎、生产，我也可以对所生子女提起普布利基安之诉；尤利安如此说，但条件是我在提起诉讼时不知道该母奴是被盗的。

<a id="6.2.11.4"></a>

**4.** 同一尤利安概括地说：如果母奴并非被盗，我能够基于某种原因因取得时效取得该母奴，那么在我不知道母奴为被盗物的情况下，我也能够基于同一原因因取得时效取得其子女。因此，基于所有这些原因，我都可以提起普布利基安之诉。

<a id="6.2.11.5"></a>

**5.** 子女再生子女的情形亦同；如果胎儿尚未出生，而是在母亲死后剖开其腹部取出，也同样如此；庞波尼乌斯在《学说汇纂》第四十卷中也作如此记载。

<a id="6.2.11.6"></a>

**6.** 他还说，如果购买的房屋后来被拆毁，可以通过此类诉讼请求返还因添附于建筑物而归属的物品。

<a id="6.2.11.7"></a>

**7.** 然而，因冲积而附加于土地的部分与其所附着的土地成为一体。因此，如果土地本身不能通过普布利基安之诉请求返还，那么冲积形成的部分也不能请求返还；如果土地本身可以请求返还，则因冲积形成的部分也可以请求返还。庞波尼乌斯如此记载。

<a id="6.2.11.8"></a>

**8.** 他还补充说，如果请求返还购买的雕像上被切下的部分，也适用类似的诉讼。

<a id="6.2.11.9"></a>

**9.** 他还写道，如果我购买一处地块并在其上建造一幢公寓楼，我可以正当地使用普布利基安之诉。

<a id="6.2.11.10"></a>

**10.** 同样，他说，如果我购买了一幢公寓楼，而该楼后来移至一处地块，我也同样可以使用普布利基安之诉。〔疑义：底本 *ad aream ea pervenit* 的具体情形不明，暂依字面处理。〕

### <a id="6.2.12"></a>6.2.12　保罗《评告示》第十九卷

<a id="6.2.12.pr."></a>

**序言（pr.）** 未婚夫将一名奴隶赠与未婚妻，未婚妻又在取得时效完成之前将该奴隶作为嫁资收受。神化的安敦宁·庇护皇帝作出敕答：离婚后应返还该奴隶，因为未婚夫与未婚妻之间的赠与有效。因此，占有人可获得抗辩；如果其丧失占有，则可提起普布利基安之诉，而无论现由第三人还是赠与人占有该奴隶。

<a id="6.2.12.1"></a>

**1.** 依特雷贝利安元老院决议接受遗产返还的人，即使尚未取得占有，也可以提起普布利基安之诉。

<a id="6.2.12.2"></a>

**2.** 对于税租土地以及其他不能因取得时效取得的土地，如果该物是善意交付给我的，也适用普布利基安之诉。

<a id="6.2.12.3"></a>

**3.** 同样，如果我善意地从非所有权人处购买了一幢地上建筑（*superficiaria insula*），亦同。

<a id="6.2.12.4"></a>

**4.** 如果某物属于法律或皇帝敕令禁止转让的物品，则此种情形下不适用普布利基安之诉，因为在这些情形中，裁判官不会保护任何人，以免其行为违反法律。

<a id="6.2.12.5"></a>

**5.** 对于尚未满一岁的幼奴，我们也可以提起普布利基安之诉。

<a id="6.2.12.6"></a>

**6.** 如果某人只请求返还某物的一部分，他可以使用普布利基安之诉。

<a id="6.2.12.7"></a>

**7.** 即使某人仅在一瞬间占有过该物，也可以正当地提起此诉。

### <a id="6.2.13"></a>6.2.13　盖尤斯《评行省告示》第七卷

<a id="6.2.13.pr."></a>

**序言（pr.）** 凡是取得物品的正当原因，如果我们基于这些原因取得物品后又丧失了它们，就会为追索这些物品而给予我们此诉。

<a id="6.2.13.1"></a>

**1.** 有时，即使占有本身具有正当性，某些人也不得获得普布利基安之诉。例如，质权占有和依容许而占有都是正当占有，但通常不适用此类诉讼。其理由是，债权人以及依容许（*precarium*）请求占有的人，取得占有时都不认为自己是所有权人。

<a id="6.2.13.2"></a>

**2.** 从未成年人处购买的人，必须证明自己是在监护人同意且法律未禁止的情况下购买的。但是，如果其因受到欺骗而在假冒监护人同意的情况下购买，仍视为善意购买。

### <a id="6.2.14"></a>6.2.14　乌尔比安《评告示》第十六卷

帕比尼安在《疑问集》第六卷中写道：如果某人曾禁止或通知他人不要交付一件经其同意由代理人出卖的物品，而代理人仍然交付该物，裁判官将保护买受人，无论买受人占有该物还是请求返还该物。代理人因买受诉讼而向买受人承担的责任，可以通过反向委任诉讼向本人追偿。因为可能发生这种情形：委托出卖的人从买受人处取回该物；这是由于买受人因不知情而没有提出本应提出的抗辩，例如：“如果我的权利前手并非依你的意思出卖该物。”

### <a id="6.2.15"></a>6.2.15　庞波尼乌斯《评萨宾》第三卷

如果我的奴隶正在逃亡期间从非所有权人处购买某物，即使我并未通过该奴隶取得已经交付之物的占有，我也应当可以提起普布利基安之诉。

### <a id="6.2.16"></a>6.2.16　保罗《帕比尼安〈疑问集〉第十卷札记》

应当对普布利基安之诉提出正当所有权之抗辩（*exceptio iusti dominii*）。〔出处疑点：底本将出处记为 *Paulus notum ad Papiniani libro decimo quaestionum*；其中 *notum* 的形式与通常引文格式不合，译名暂按“保罗对帕比尼安《疑问集》第十卷的札记”处理。〕

### <a id="6.2.17"></a>6.2.17　涅拉提乌斯《札记》第三卷

普布利基安之诉的设立，并非为了从所有权人处夺走物品。其证明首先在于衡平，其次在于抗辩“如果该物并非占有人的”。设立此诉的目的，是使善意买受并基于该原因取得占有的人优先取得该物。
