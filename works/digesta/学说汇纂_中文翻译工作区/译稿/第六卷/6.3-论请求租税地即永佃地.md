## <a id="3"></a><a id="6.3"></a>6.3　论请求租税地（即永佃地）

*Si ager vectigalis, id est emphyteuticarius, petatur*

### <a id="6.3.1"></a>6.3.1　保罗《评告示》第二十一卷

<a id="6.3.1.pr."></a>

**序言（pr.）** 各自治市的土地，有些称为租税地，有些则不称为租税地。所谓租税地，是指永久出租的土地；依租约，只要承租人或继受其地位的人持续缴纳租税，该土地便不得收回。非租税地，则是按照我们通常将私人土地交付耕种的方式交付耕种的土地。

<a id="6.3.1.1"></a>

**1.** 凡向自治市永久承租土地以供收益者，虽未因此取得所有权，通说仍认为其享有对物诉权，可以对任何占有人提起诉讼，甚至可以对自治市本身提起诉讼。

### <a id="6.3.2"></a>6.3.2　乌尔比安《评萨宾》第十七卷

但须以他们缴纳租税为条件。

### <a id="6.3.3"></a>6.3.3　保罗《评告示》第二十一卷

同样，如果他们是定期承租，且租赁期限尚未届满，结论亦然。
