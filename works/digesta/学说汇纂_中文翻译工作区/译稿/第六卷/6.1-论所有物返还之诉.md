## <a id="1"></a><a id="6.1"></a>6.1　论所有物返还之诉

*De rei vindicatione*

### <a id="6.1.1"></a>6.1.1　乌尔比安《评告示》第十六卷

<a id="6.1.1.pr."></a>

**序言（pr.）** 在针对整体财产提起的诉讼之后，接续设有请求个别财物的诉讼。

<a id="6.1.1.1"></a>

**1.** 这种特别的对物之诉，适用于一切动产，无论是动物还是无生命物，也适用于附着于土地的物。

<a id="6.1.1.2"></a>

**2.** 但是，不能通过此诉请求返还属于我们权力之下的自由人，例如处于家父权下的子女。对此，应通过先决诉讼、禁令或裁判官的审理程序主张权利。庞波尼乌斯在《评告示》第三十七卷中也这样说。不过，他指出，如果请求时附加了相应事由，情况或许不同：例如，有人这样请求“自己的儿子”，或者称其“依罗马法处于自己权力之下”，那么在我看来，庞波尼乌斯也同意其诉讼提起得当；因为他说，附加该事由后，可以依据奎里蒂法请求返还。

<a id="6.1.1.3"></a>

**3.** 庞波尼乌斯在《讲读》第二十五卷中还写道，此诉不仅可用于请求返还个别财物，也可用于请求返还整个畜群。对畜群、马群以及其他成群饲养的动物，也应作相同处理。不过，只须证明畜群本身属于我们即可，即使每一头牲畜并非都属于我们；请求返还的是畜群，而不是其中各个动物个体。

### <a id="6.1.2"></a>6.1.2　保罗《评告示》第二十一卷

如果两人的牲畜头数相同，任何一方都不得请求返还整个畜群，也不得请求返还该畜群的一半。但是，如果一方拥有的头数较多，即使扣除属于他人的牲畜，仍足以构成一个畜群，那么返还时不包括他人的牲畜。

### <a id="6.1.3"></a>6.1.3　乌尔比安《评告示》第十六卷

<a id="6.1.3.pr."></a>

**序言（pr.）** 马尔凯卢斯在《学说汇纂》第四卷中写道：某人原有一个三百头牲畜的畜群，损失一百头后，又从牲畜所有人处，或从善意占有人处买入同样数目的他人牲畜。马尔凯卢斯说，这些牲畜当然也包括在畜群返还请求之内。即使仅剩下买入的牲畜，他仍可以请求返还畜群。

<a id="6.1.3.1"></a>

**1.** 船上的装备应逐件请求返还；小艇也应另行请求返还。

<a id="6.1.3.2"></a>

**2.** 庞波尼乌斯写道，如果同类物混合在一起，以致不能取出或分离，那么请求返还的不是全部，而是相应份额。例如，我的银与你的银熔成一块，我们便共有该银块；各人可以依其在银块中所占重量的比例请求返还，即使无法确定每人原有多少重量。

### <a id="6.1.4"></a>6.1.4　保罗《评告示》第二十一卷

在这种情形下，也可以提起共有物分割之诉；而故意使银混合之人，还要承担盗窃之诉和请求出示之诉的责任。在请求出示之诉中，应考虑价款；在所有物返还之诉或共有物分割之诉中，银较贵重的一方还应取得相应的额外部分。

### <a id="6.1.5"></a>6.1.5　乌尔比安《评告示》第十六卷

<a id="6.1.5.pr."></a>

**序言（pr.）** 庞波尼乌斯还写道，如果两人的谷物未经其同意而混合，各人均可提起对物之诉，请求返还谷堆中可以证明属于自己的份额；如果双方同意混合，则视为共有，应提起共有物分割之诉。

<a id="6.1.5.1"></a>

**1.** 庞波尼乌斯还写道，如果以我的蜂蜜和你的葡萄酒制成蜜酒，有些法学家认为该蜜酒也成为共有物。但我认为，更妥当的意见——庞波尼乌斯本人似乎也有所表示——是蜜酒归制作之人，因为它已不再保持原有的性质。不过，铅与银混合后仍可分离，因此既不成为共有物，也不能提起共有物分割之诉；既然可以分开，应提起对物之诉。若无法分离，例如铜与金混合，则应按份额请求返还。此处不能适用关于蜜酒的结论，因为两种材料虽已混合，却仍各自存在。

<a id="6.1.5.2"></a>

**2.** 庞波尼乌斯还写道，如果我的母马被你的公马配种，所生之物不属于你，而属于我。

<a id="6.1.5.3"></a>

**3.** 对于移植到他人土地上并已成活、扎根的树，瓦鲁斯和涅尔瓦准许提起准对物之诉；如果树尚未成活，它仍属于我。

<a id="6.1.5.4"></a>

**4.** 提起对物之诉时，如果双方对物本身没有争议，只是名称有误，仍应视为诉讼提起得当。

<a id="6.1.5.5"></a>

**5.** 如果有数名奴隶同名，例如有数名名叫埃罗斯的奴隶，而无法辨明诉讼所指的是哪一人，庞波尼乌斯说，不得作出任何判决。

### <a id="6.1.6"></a>6.1.6　保罗《评告示》第六卷

提起对物之诉时，必须指明所请求的物，并说明请求全部还是部分；如请求部分，还须指明具体份额。因为“物”这一称谓指具体种类，而非一般类别。奥克塔维努斯如此界定：未经加工的材料应按重量指明，带有标记的物应按数量指明，制成品则应指明其种类；以计量单位确定的物，也应说明计量单位。若请求返还衣物，或请求判令交付衣物，应当说明件数还是还须说明颜色？较妥当的意见是二者都应说明；不过，要求我们说明衣物是旧是新，未免不近人情。器皿也会产生困难：究竟只须说明是盘子，还是还须说明方形或圆形、素面或雕花？这些内容若要一并写入请求，也很难做到。因此，对请求事项不应作过分严格的限定。请求返还奴隶时，应说明其姓名；若有数名奴隶，还应说明是男童还是青年。如果不知道姓名，则应以特征说明，例如“属于某项遗产的那一人”或“某人所生的那一人”。请求返还土地者，也应说明土地名称及其所在地。

### <a id="6.1.7"></a>6.1.7　保罗《评告示》第十一卷

如果某人主动应对土地返还之诉并被判承担责任，原告仍可向占有人正确地请求返还；佩狄乌斯也这样说。

### <a id="6.1.8"></a>6.1.8　保罗《评告示》第十二卷

庞波尼乌斯在《评昆图斯·穆基乌斯》第三十六卷中赞同如下意见：如果我与你及卢基乌斯·提提乌斯共同占有一块土地，且我们各占相等份额，我不应分别向你们二人请求各四分之一，而应向并非所有人的提提乌斯请求整个二分之一。若你们按确定的区域分别占有该土地，则情况不同：毫无疑问，我应分别向你和提提乌斯请求相应的土地份额；因为各人既然占有确定的区域，其中就必然有一部分属于我。因此，你也应向提提乌斯请求四分之一。此一区分不适用于动产，也不适用于遗产请求之诉，因为这些财物从来不能以分割占有的方式占有。

### <a id="6.1.9"></a>6.1.9　乌尔比安《评告示》第十六卷

在此诉中，法官的职责是审查被告是否占有该物；其占有根据为何并不重要。因为我一旦证明该物属于我，占有人就必须返还，除非其提出某项抗辩。不过，佩伽苏斯等人认为，此诉仅适用于可提起“按现状占有”或“按最近一次占有”禁令的占有。因此，他们说，物品被寄托、借用或租赁给某人，或者某人为保全遗赠、基于嫁资或胎儿利益而占有，或未就可能造成的损害提供担保时，因这些人都不属于占有人，不能对他们提起所有物返还之诉。但我认为，凡实际持有该物且有能力返还之人，均可成为此诉的被告。

### <a id="6.1.10"></a>6.1.10　保罗《评告示》第二十一卷

请求返还动产时，如果该物不在诉讼地，应当在哪里返还？若被告是善意占有人，较妥当的办法是允许在物品所在地或诉讼地返还；但原告应承担因此发生的旅程或航运费用，膳食费用除外。

### <a id="6.1.11"></a>6.1.11　乌尔比安《评告示》第十六卷

除非原告选择由自己承担费用和风险，在审理案件的地点返还该物；在这种情况下，应就返还提供充分担保。

### <a id="6.1.12"></a>6.1.12　保罗《评告示》第二十一卷

如果占有人是恶意占有人，且在另一地点取得该物，也应作相同处理。但如果其在诉讼成立后将该物从原地取走并转移至他处，则应由其自费在取走该物之处返还。

### <a id="6.1.13"></a>6.1.13　乌尔比安《评告示》第十六卷

法官不仅应考虑是否返还原物；如果该物状况恶化，也应考虑其恶化程度。例如，设若被请求返还的奴隶变得衰弱，或者遭受殴打、受伤，法官应评估其状况恶化的程度。占有人也可能因而受到《阿奎利亚法》之诉的追究。于是有人问：法官是否只有在原告放弃《阿奎利亚法》之诉时，才能评定该项损害？拉贝奥认为，原告应承诺不再提起《阿奎利亚法》之诉；此说是正确的。

### <a id="6.1.14"></a>6.1.14　保罗《评告示》第二十一卷

如果原告宁愿提起《阿奎利亚法》之诉，占有人就应获判免责。因此，应将选择权交给原告，使其取得双倍赔偿，而非三倍赔偿。

### <a id="6.1.15"></a>6.1.15　乌尔比安《评告示》第十六卷

<a id="6.1.15.pr."></a>

**序言（pr.）** 同样，如果占有人交还的是遭受殴打之人，拉贝奥说，原告还可以提起侵害之诉。

<a id="6.1.15.1"></a>

**1.** 如果某人因不得已而出售该物，法官或许可以通过其职权给予救济：占有人只须返还价款。若其出售所取得的孳息是为了避免孳息腐坏，也同样只须返还价款。

<a id="6.1.15.2"></a>

**2.** 又如，请求返还的土地已分配给士兵，作为荣誉仅向占有人支付了少量款项，占有人是否也应返还该款？我认为应当返还。

<a id="6.1.15.3"></a>

**3.** 如果被请求返还的奴隶或其他动物并非因占有人的故意或过失而死亡，多数人认为无须支付价款。但更妥当的意见是：如果原告在迟延期间本可出售该物，就应向其支付价款；因为若占有人当时已返还该物，原告便会出售并取得价款。

### <a id="6.1.16"></a>6.1.16　保罗《评告示》第二十一卷

<a id="6.1.16.pr."></a>

**序言（pr.）** 即使被请求返还之人已经死亡，仍有必要作出判决，以处理孳息、子女以及关于追夺时返还的担保问题；因为占有人并非在诉讼成立后就必然对该人的死亡负责。

<a id="6.1.16.1"></a>

**1.** 请求返还的船只若在航行季节被送往海外，即使船只灭失，也不构成过失；除非占有人将船交给了不称职的船员。

### <a id="6.1.17"></a>6.1.17　乌尔比安《评告示》第十六卷

<a id="6.1.17.pr."></a>

**序言（pr.）** 尤利安在《学说汇纂》第六卷中写道：如果我从提提乌斯处买下原属梅维乌斯的奴隶；梅维乌斯向我请求返还该奴隶时，我又将其出售，而买受人杀死了该奴隶，那么我应向梅维乌斯返还价款，这样才公平。

<a id="6.1.17.1"></a>

**1.** 尤利安在同卷中还写道，如果占有人迟延返还奴隶，而该奴隶死亡，孳息应计算至判决之时。尤利安还说，不仅孳息，所有附随利益也应返还；因此，奴隶所生子女及其孳息也包括在内。附随利益的范围甚至如此广泛：尤利安在《学说汇纂》第七卷中写道，如果占有人通过该奴隶取得《阿奎利亚法》之诉，也应被命令返还该诉权。如果占有人以恶意欺诈停止占有，而他人不法杀害该奴隶，占有人就必须依原告的选择返还奴隶价款或相应诉权。占有人从其他占有人处取得的孳息，也应返还；因为他不得从已成为诉讼标的之奴隶身上获利。不过，对其曾被胜诉原告占有期间所生的孳息，不负返还义务。至于《阿奎利亚法》之诉权也应返还的说法，仅适用于占有人在诉讼成立后因时效取得该奴隶的情形，因为此时其取得完整权利。

### <a id="6.1.18"></a>6.1.18　盖尤斯《评行省告示》第七卷

如果占有人在诉讼成立后因时效取得奴隶，就应交付该奴隶，并就欺诈提供担保；因为存在这样的风险：占有人可能已将奴隶出质或释放为自由人。

### <a id="6.1.19"></a>6.1.19　乌尔比安《评告示》第十六卷

拉贝奥说，被告本人也应就“妥善履行这些事项”提供担保，例如其曾就土地可能发生的损害提供过担保。〔原文 *his rebus recte praestari* 的主语及其与后半句的关系不甚明确，暂按此义处理。〕

### <a id="6.1.20"></a>6.1.20　盖尤斯《评行省告示》第七卷

此外，占有人还应返还其在诉讼成立后通过该奴隶取得、且并非出于自身财产的利益；其中包括通过该奴隶取得的遗产和遗赠。返还奴隶本人并不足够，还须返还与该物相关的一切利益；也就是说，原告应取得其本可取得的一切，仿佛奴隶在诉讼成立时即已返还给他。因此，即使女奴所生子女是在占有人于诉讼成立后因时效取得其母亲之后才出生，该子女也应返还。在这种情况下，对子女和母亲均须交付，并就欺诈提供担保。

### <a id="6.1.21"></a>6.1.21　保罗《评告示》第二十一卷

如果奴隶从善意占有人处逃走，应查明其是否属于应当看管之人。如果其品行端正，看来无须看管，占有人应获判免责；但若其在此期间已因时效取得该奴隶，就应将相关诉权让与原告，并交付其占有期间的孳息。如果尚未因时效取得该奴隶，则应在不要求提供担保的情况下判占有人免责；占有人无须承诺继续追寻该奴隶。毕竟，即使奴隶在逃亡期间因时效被他人取得，原告又如何追索该物？庞波尼乌斯在《评告示》第三十九卷中写道，这样处理并非不公平。如果该奴隶本应受到看管，占有人也应就该奴隶承担判决责任；但若占有人尚未因时效取得奴隶，原告应受让其相关诉权。尤利安认为，在这些因奴隶逃亡而判占有人免责的情形中，虽然不必担保其会追寻奴隶，占有人仍应承诺：若日后取得该奴隶，将予返还。庞波尼乌斯在《杂论》第三十四卷中赞同此说；这一意见更为妥当。

### <a id="6.1.22"></a>6.1.22　乌尔比安《评告示》第十六卷

如果奴隶因占有人的欺诈而逃走，应将占有人视同仍在占有，并判其承担责任。

### <a id="6.1.23"></a>6.1.23　保罗《评告示》第二十一卷

<a id="6.1.23.pr."></a>

**序言（pr.）** 凡依万民法或市民法取得所有权之人，均可提起对物之诉。

<a id="6.1.23.1"></a>

**1.** 神圣之物和宗教之物，不能像属于我们所有的物那样，通过对物之诉请求返还。

<a id="6.1.23.2"></a>

**2.** 如果某人将他人的物附加于自己的物，使之成为该物的一部分，例如将他人的手臂或脚接到自己的雕像上，或将他人的把手接到自己的酒杯、底座接到自己的烛台、桌腿接到自己的桌子上，那么许多人正确地认为，整体物的所有人也成为附加部分的所有人，并可称整个雕像或酒杯为自己的物。

<a id="6.1.23.3"></a>

**3.** 写在我的纸上或画在我的画板上的内容，也立即成为我的；尽管有些人对绘画持相反意见，理由是绘画本身具有价值。但附加物必须归属于离开它便无法存在的主体物。

<a id="6.1.23.4"></a>

**4.** 因此，在上述所有情形中，我的物凭借其主要地位吸收他人的物并使之归我所有；如果我请求返还该物，就必须通过诈欺抗辩支付所附加之物的价款。

<a id="6.1.23.5"></a>

**5.** 同样，凡作为附属物而与他物结合或附加的物，在结合期间，所有人不得单独请求返还；但可以提起请求出示之诉，使其分离后再请求返还。不过，卡西乌斯关于焊接的论述除外。他说，如果他人的手臂通过同质金属焊接到我的雕像上，因较大部分的整体性，该手臂即被吸收；一旦归他人所有，即使日后从雕像上拆下，也不能恢复为原所有人所有。铅焊则不同，因为同质金属焊接会使材料融合，铅焊不会产生同样效果。因此，在既不能提起请求出示之诉、也不能提起对物之诉的所有这些情形中，有必要提起事实之诉。但由彼此分离的物体构成的集合物不同：各部分仍保有自身性质，例如各个人或各只羊。因此，即使你的公羊混入我的羊群，我仍可请求返还整个羊群；你也可以请求返还你的公羊。物体彼此附着时则不然：如果你把他人的手臂接到我的雕像上，不能说该手臂仍属于你，因为整个雕像作为一个整体而存在。

<a id="6.1.23.6"></a>

**6.** 他人的木料一旦接入房屋，就不得请求返还，这是《十二表法》的规定；除非针对明知木料属于他人仍将其接入房屋之人，否则也不得就此提起请求出示之诉。不过，依据《十二表法》可以提起古老的接合木料之诉，判处双倍。

<a id="6.1.23.7"></a>

**7.** 如果某人用他人的砖石在自己的土地上建造房屋，他可以请求返还房屋；房屋拆除后，砖石的原所有人仍可请求返还，即使房屋是在善意买受人占有、且时效取得期间经过之后才被拆除。因为砖石不能单独因时效而取得所有权；房屋虽因经过一段时间而归我们所有，亦然。

### <a id="6.1.24"></a>6.1.24　盖尤斯《评行省告示》第七卷

准备请求返还财物的人，应先查明能否通过某项禁令取得占有；因为自己先占有，再迫使对方承担请求返还的负担，远比在对方占有时提起诉讼有利。

### <a id="6.1.25"></a>6.1.25　乌尔比安《评告示》第七十卷

某人无正当理由主动为财物应诉，尽管他并未占有，也未以欺诈手段使自己不再占有；如果原告对此并不知情，马尔凯卢斯说，不应判其免责；此说正确。但这仅适用于诉讼成立之后。诉讼受理之前，某人否认占有而实际上也确未占有的，并未欺骗原告；其后来退出诉讼，也不视为曾主动应诉。

### <a id="6.1.26"></a>6.1.26　保罗《摘自普劳提乌斯》第二卷

因为，如果原告明知该情形，那么他并非受他人欺骗，而是受自己欺骗；因此，被告应获判免责。

### <a id="6.1.27"></a>6.1.27　保罗《评告示》第二十一卷

<a id="6.1.27.pr."></a>

**序言（pr.）** 如果我原本要向提提乌斯请求返还财物，却有他人声称自己占有该物，并因此主动应诉，而我又在诉讼过程中以作出证明的方式证实此事，那么无论如何都应判其承担责任。〔*in re agenda testatione* 的具体程序含义不明，暂依上下文译为“在诉讼过程中以作出证明的方式”。〕

<a id="6.1.27.1"></a>

**1.** 被告必须在诉讼成立时及作出判决时均为占有人。如果其在诉讼成立时占有该物，但至判决时并非因欺诈而失去占有，应判其免责。反之，如果其在诉讼成立时并未占有，但在判决时已经占有，则应采纳普罗库鲁斯的意见，判其承担责任；因此，自其开始占有之时起所生的孳息，也应由其承担。

<a id="6.1.27.2"></a>

**2.** 如果被请求返还的奴隶因占有人的欺诈而状况恶化，后来又并非因占有人的过错而因其他原因死亡，则不应就其状况恶化作出估价，因为该损害与原告无关。不过，这只是就对物之诉而言；《阿奎利亚法》之诉仍然存续。

<a id="6.1.27.3"></a>

**3.** 在诉讼成立之前以欺诈手段停止占有之人，也应承担对物之诉的责任；这可以从元老院决议中推知。该决议规定，正如前文所说，既往的欺诈也应纳入遗产请求之诉。既然遗产请求之诉本身也是对物之诉，既往欺诈可以纳入其中，那么在针对个别物的对物之诉中纳入既往欺诈，也并非不合理。

<a id="6.1.27.4"></a>

**4.** 如果家父或主人通过其子或奴隶占有该物，而后者在判决时并非因家父或主人的过错而不在场，则应给予期限，或要求其担保返还占有。

<a id="6.1.27.5"></a>

**5.** 如果占有人在诉讼成立前为被请求返还之物支出了费用，而原告仍坚持请求返还、却不偿付这些费用，应通过诈欺抗辩将这些费用纳入考虑。奴隶在占有人手中时，占有人若在诺克萨诉讼中为其辩护并因败诉而支付金钱，也应如此；又如，占有人因错误在原告的土地上建造了出租公寓，亦同。但如果原告愿意容许占有人拆除建筑物，则不在此限。关于赠与妻子的土地，审理嫁资案件的法官也曾裁定应作同样处理。不过，若占有人曾教育我的奴隶男孩，普罗库鲁斯认为不应作同样处理，因为我不应被剥夺自己的奴隶，也不能适用我们刚才对土地所说的救济。

### <a id="6.1.28"></a>6.1.28　盖尤斯《评行省告示》第七卷

例如，你教会了他绘画或抄写的技艺。据说，只有在下列情形下，法官才能依职权对相关利益作出估价：

### <a id="6.1.29"></a>6.1.29　庞波尼乌斯《评昆图斯·穆基乌斯》第二十一卷

除非你准备出售该人，并且因其技艺而能取得更高价款；

### <a id="6.1.30"></a>6.1.30　盖尤斯《评行省告示》第七卷

或者，原告先前已被通知应支付费用，但其置之不理，此时可以提出诈欺抗辩。

### <a id="6.1.31"></a>6.1.31　保罗《评告示》第二十一卷

讨论被请求返还的奴隶所生孳息时，不仅应考虑其是否已成年，因为未成年人也可能提供某些劳务。但原告若要求评定该奴隶凭借其技艺本可取得的孳息，则属不当；该技艺毕竟是其由占有人出资学习的。

### <a id="6.1.32"></a>6.1.32　莫德斯蒂努斯《论法律差异》第八卷

如果占有人使某人习得一项技艺，在该人年满二十五岁后，可以抵算所支出的费用。〔*post vicensimum quintum annum eius* 的具体时间关系不甚明确，暂依字面理解为“该人年满二十五岁后”。〕

### <a id="6.1.33"></a>6.1.33　保罗《评告示》第二十一卷

孳息不仅包括已经取得的，也包括本可正当地取得的。因此，如果被请求返还之物因占有人的故意或过失而灭失，庞波尼乌斯认为，特雷巴提乌斯主张的孳息应计算至判决之时，仿佛该物并未灭失；尤利安也赞同此说。依此，如果仅有裸所有权之人提起请求，而用益权在诉讼迟延期间消灭，则应从用益权回复于所有权之时起计算孳息。

### <a id="6.1.34"></a>6.1.34　尤利安《学说汇纂》第七卷

土地因冲积而增加部分时，也适用相同规则。

### <a id="6.1.35"></a>6.1.35　保罗《评告示》第二十一卷

<a id="6.1.35.pr."></a>

**序言（pr.）** 反之，如果原告在诉讼成立后遗赠了用益权，有些人正确地认为，自其脱离所有权之时起，不再计算孳息。

<a id="6.1.35.1"></a>

**1.** 如果我请求返还他人的土地，法官判决确认土地属于我，也应判占有人返还孳息；既然判决认定其对土地所有权的认识有误，也应同样认定其对孳息的认识有误。占有人败诉，孳息就不应成为其获利；否则，正如毛里基亚努斯所说，法官甚至不会命令其返还土地。若占有人立即返还占有，本来就不会取得这些孳息，他为何还能保有？

<a id="6.1.35.2"></a>

**2.** 原告无须就其已获得诉讼估价的物品，向占有人提供追夺担保；占有人应归咎于自己没有返还该物。

<a id="6.1.35.3"></a>

**3.** 毫无疑问，即使某些物不能在不毁损的情况下分割，也可以请求返还其中一部分。

### <a id="6.1.36"></a>6.1.36　盖尤斯《评行省告示》第七卷

<a id="6.1.36.pr."></a>

**序言（pr.）** 提起返还之诉的人，为免徒劳起诉，应先查明其所起诉之人是否为占有人，或是否以欺诈手段停止占有。

<a id="6.1.36.1"></a>

**1.** 被提起对物之诉的人，也因过失承担责任。占有人有过失的情形包括：将奴隶送往危险之地，致其死亡；准许被请求返还的奴隶进入竞技场，致其死亡；不看管被请求返还的逃亡奴隶，致其逃走；以及将被请求返还的船只在天气恶劣时派出航行，致其因海难灭失。

### <a id="6.1.37"></a>6.1.37　乌尔比安《评告示》第十七卷

尤利安在《学说汇纂》第八卷中写道：如果我在他人土地上建造房屋，虽是善意买受人，但建造时已知道土地属于他人，那么应考察诈欺抗辩是否对我毫无帮助；除非有人主张，因担忧可能发生的损害而设抗辩能够帮助我。不过，我认为该抗辩不能帮助此人；他既已确定土地属于他人，就不应在其上建造。但应准许其移走所建房屋，且不得使土地所有人因此遭受损失。〔*de damno sollicito* 所指不明，暂保留为“因担忧可能发生的损害”。〕

### <a id="6.1.38"></a>6.1.38　塞尔苏斯《学说汇纂》第三卷

你误以为土地属于自己而买下，在其上建造或种植，后来土地被他人追夺。公正的法官应根据当事人和具体情形分别处理。假设土地所有人自己也会作同样的建造或种植，则其应偿还费用，使其能够取回土地；偿还额以土地因此增值的数额为限。如果土地增值超过所支费用，则只偿还支出额。假设占有人贫困，若被迫返还土地，就不得不失去祖传家宅和墓地；那么，应允许其拆走能够拆走之物，但不得使土地状况比从未建造时更差。不过，如果土地所有人愿意支付占有人移走这些物品后所能得到的价值，就应允许土地所有人这样做。若你只是想刮掉所涂的灰泥或绘画，除了妨碍他人之外并无所得，就不应纵容这种恶意。再假设土地所有人取回土地后马上就要出售：如果他不支付前述应偿还的费用，则应在扣除该金额后判你承担责任。

### <a id="6.1.39"></a>6.1.39　乌尔比安《评告示》第十七卷

<a id="6.1.39.pr."></a>

**序言（pr.）** 承包人用自己的砖石建造房屋时，砖石立即归建造房屋所在土地的所有人所有。

<a id="6.1.39.1"></a>

**1.** 尤利安在《学说汇纂》第十二卷中正确地写道：一名妇女为他人提供担保而将土地设质，即使该土地已被债权人出售，她仍可提起对物之诉请求返还土地；

因为债权人似乎并未出售任何质押物。

### <a id="6.1.41"></a>6.1.41　乌尔比安《评告示》第十七卷

<a id="6.1.41.pr."></a>

**序言（pr.）** 如果买受人订约时约定，只要他人提出更优条件，买卖即告解除，那么在他人提出更优条件后，买受人便不得再提起对物之诉。如果土地是附有他人加价优先买受条件而暂归某人，且加价条件尚未成就，他可以提起对物之诉；条件成就后则不得起诉。

### <a id="6.1.42"></a>6.1.42　保罗《评告示》第二十六卷

如果已经提起对物之诉，即使占有人的继承人因并未占有而获判免责，但如果死者本人尚有债务责任，不论如何仍应将其计入判决责任。〔底本在 *si non ... absolvatur, tamen si quid ex ...* 处有带引号的断裂文字，句法疑有讹误；此处按上下文暂译。〕

### <a id="6.1.43"></a>6.1.43　保罗《评告示》第二十七卷

附属于墓地的物也具有宗教属性，因此，石块一经砌入墓中，即使后来被拆下，也不得再以对物之诉请求返还。不过，法院可以通过事实诉讼以非常程序救济请求人，强令实施拆除者返还石块。但如果他人未经所有人同意将其石块砌入墓中，并且在墓地尚未用于安葬之前就将其拆下，以便移至别处，所有人可以对石块提起对物之诉。若拆下石块是为了在别处重新使用，所有人同样可以请求返还。

### <a id="6.1.44"></a>6.1.44　盖尤斯《评行省告示》第二十九卷

尚未摘取的果实，视为土地的一部分。

### <a id="6.1.45"></a>6.1.45　乌尔比安《评告示》第六十八卷

如果奴隶是在提起诉讼后返还的，我认为，善意占有人只须就欺诈承担担保；其他人还须就其过失承担担保，其中包括诉讼成立后才成为善意占有人的人。

### <a id="6.1.46"></a>6.1.46　保罗《评萨宾》第二十卷

对于通过对物之诉请求返还的物，如果该物已按原告宣誓确定的诉讼估价作价，所有权即刻归占有人所有；因为我似乎已经以原告自行确定的价格与他达成和解并解决争议。

### <a id="6.1.47"></a>6.1.47　保罗《评普劳提乌斯》第十七卷

上述规则适用于标的物已在场的情形；如果标的物不在场，则须等到占有人依原告的意思取得该物的占有后，规则方适用。因此，由法官估定诉讼标的，附以原告作出担保为条件，并非不妥：原告须担保不会因其本人原因而未能交付该物的占有。

### <a id="6.1.48"></a>6.1.48　帕比尼安《法律意见》第二卷

善意占有人对后来证明属于他人的土地所支出的费用，既不得向赠与该土地的人请求，也不得向所有人请求；但其可以提出恶意欺诈抗辩，由法官依据衡平原则予以保留，条件是该费用超过诉讼成立前已收取的孳息。因为法院准许抵销后，如果费用余额使土地增值，所有人就必须返还超出部分。

<a id="6.1.50.1"></a>

### <a id="6.1.51"></a>6.1.51　庞波尼乌斯《评萨宾》第十六卷

如果已经提起对物之诉，并且针对占有人的继承人发出诉讼指令，继承人的过失和欺诈也应纳入该诉讼审理。

### <a id="6.1.52"></a>6.1.52　尤利安《学说汇纂》第五十五卷

如果土地占有人在诉讼成立前以欺诈方式不再占有土地，不得强令其继承人承担对物之诉；但应对他们准许事实诉讼，通过该诉迫使其返还因该事由而增加的财产。

### <a id="6.1.53"></a>6.1.53　庞波尼乌斯《评萨宾》第三十一卷

如果土地占有人曾耕种或播种该土地，后来土地被他人胜诉取回，他不得移走其所种植的作物。

### <a id="6.1.54"></a>6.1.54　乌尔比安《法律意见》第六卷

担任诉讼代理人与为自己的财物辩护，大不相同。因此，某人当时不知道某物属于自己，却协助他人请求返还该物；此后才知道该物属于自己，他并未因此丧失所有权。

### <a id="6.1.55"></a>6.1.55　尤利安《学说汇纂》第五十五卷

如果土地占有人在诉讼受理前死亡，留下两名继承人，而其中一人占有整块土地，原告又向其请求返还整块土地，那么毫无疑问，该继承人应对全部土地承担判决责任。

### <a id="6.1.56"></a>6.1.56　尤利安《学说汇纂》第七十八卷

对特有产的请求并不像对兽群的请求那样以整体为标的；被遗赠特有产的人，应当分别请求其中的各项财物。

### <a id="6.1.57"></a>6.1.57　阿尔芬《学说汇纂》第六卷

某人因土地被起诉，之后又有另一人以同一块土地为由起诉他。有人询问：如果他遵照其中一名法官的命令返还了土地，而另一名请求人后来又获得有利判决，如何避免其承担双重损失？我答复：先作出判决的法官应命令将土地返还给请求人，但应以占有人取得担保为条件；该担保应确保，若另一请求人后来胜诉，占有人可获赔偿。

### <a id="6.1.58"></a>6.1.58　保罗《阿尔芬〈学说汇纂〉摘要》第三卷

有人请求返还一名奴隶，同时又以同一名奴隶为由对占有人提起盗窃之诉。有人询问：如果占有人在两项诉讼中均被判败诉，应如何处理？我答复：如果占有人先在奴隶返还之诉中败诉，除非对方已就该奴隶所涉诉讼请求提供担保，否则法官不应强令其交付奴隶；该担保应确保，对方在该项事务中已经给付的款项得以妥善清偿。但如果先就盗窃之诉作出判决，占有人已将该奴隶以诺克萨方式交付，作为损害赔偿，之后又在请求返还奴隶之诉中判决原告胜诉，法官不应仅因占有人未交付奴隶而估定诉讼标的的价值，因为未能交付并非由其过失或欺诈造成。

### <a id="6.1.59"></a>6.1.59　尤利安《米尼基乌斯释义》第六卷

一名居住者在他人的建筑物上安装了窗户和门；一年后，建筑物所有人将其拆下。有人询问，安装者能否对这些物品提起对物之诉。我答复：可以。因为附属于他人建筑物的物品，只要仍与建筑物相连，就属于该建筑物；一经拆下，便立即恢复其原有状态。

### <a id="6.1.60"></a>6.1.60　庞波尼乌斯《评萨宾》第二十九卷

幼儿或精神失常者作为占有人而遗失或毁损物品的，不承担责任。

### <a id="6.1.61"></a>6.1.61　尤利安《米尼基乌斯释义》第六卷

有人问米尼基乌斯：如果某人用他人的材料修缮自己的船，这艘船是否仍是原来的船？他答复说：仍是原来的船。但如果该人在建造船只时使用他人的材料，尤利安注说，便不能作相同认定；因为整艘船的所有权取决于龙骨的归属。

### <a id="6.1.62"></a>6.1.62　帕比尼安《问题集》第六卷

<a id="6.1.62.pr."></a>

**序言（pr.）** 如果向恶意占有人请求返还船舶，也应估算其孳息，如同对租赁的商铺或场地一样。这与另一规则并不矛盾：继承人没有动用存放的钱款时，不必支付利息。因为即使运费与利息一样并非自然产生、而是依法取得，仍可请求运费；这是因为占有人不必向请求人承担船舶航行的风险，而借出的金钱则由出借人承担风险。

<a id="6.1.62.1"></a>

**1.** 一般而言，在需要估算孳息时，确定的标准并非恶意占有人是否实际享用了该物，而是如果请求人获准占有，他是否本可享用该物。尤利安也赞同这一意见。

### <a id="6.1.63"></a>6.1.63　帕比尼安《问题集》第十二卷

如果某人因过失而非欺诈丧失占有，既然他必须承受诉讼估价，法官就应听取其请求：如其希望，对方应将自己针对该物享有的诉权让与他。不过，如果裁判官日后会对任何其他占有人给予救济，他便不会因此遭受损失。即使是已经收取诉讼估价的人后来重新取得占有，也应获得救济；如果其希望返还自己承担判决风险而依据法官判决收取的钱款，不应轻易准许。

### <a id="6.1.64"></a>6.1.64　帕比尼安《问题集》第二十卷

提起对物之诉时，已经确定：即使针对不产生孳息、仅供使用的物，也应返还孳息。

### <a id="6.1.65"></a>6.1.65　帕比尼安《答复集》第二卷

<a id="6.1.65.pr."></a>

**序言（pr.）** 买受人向非所有人买入土地后，如果所有人提出恶意欺诈抗辩，只有在买受人能够收回为该土地设定质权者的债权人所受领的款项，以及期间利息的余额时，才会被迫向所有人返还土地；但前提是，诉讼成立前所收取的孳息少于该余额。按照土地费用的处理方式，仅以新生利息抵销孳息，才属公平。

<a id="6.1.65.1"></a>

### <a id="6.1.67"></a>6.1.67　谢沃拉《答复集》第一卷

有人从未成年被监护人的监护人处买下一栋房屋，并雇请工匠修缮；工匠发现了钱。有人询问，该钱应归谁所有。我答复：如果发现的不是埋藏的宝藏，而只是遗失的钱，或者钱的所有人因错误而未能取回，那么该钱仍属于原所有人。

### <a id="6.1.68"></a>6.1.68　乌尔比安《评告示》第五十一卷

某人受命返还财物，却不服从法官，声称自己无法返还：如果他实际上占有该物，法官可以命令以武力将占有移转给请求人，并仅就孳息及与该物有关的一切利益判令其承担责任。如果他确实无法返还，但其以欺诈方式造成无法返还的情形，则应按对方宣誓确定的金额判令其承担责任，不受任何估价上限限制。如果他确实无法返还，且并非以欺诈造成该结果，则判决金额不得超过该物的价值，也就是不得超过对方因此所受的损害。本项规则具有一般性，适用于一切情形：无论案件涉及禁令、对物之诉还是对人之诉，只要法官可以裁量命令返还，均适用该规则。

### <a id="6.1.69"></a>6.1.69　保罗《评萨宾》第十三卷

某人以欺诈方式使自己不再占有财物，也因此受到惩罚：原告无须向他作出担保，保证将把自己因该财物而享有的诉权移转给他。

### <a id="6.1.70"></a>6.1.70　庞波尼乌斯《评萨宾》第二十九卷

已确定不得向此人准许准用普布利基安之诉，以免任何人都能违背所有人的意愿，通过抢夺再以正当价格买下财物。

### <a id="6.1.71"></a>6.1.71　保罗《评萨宾》第十三卷

如果占有人确实存在欺诈，而原告却不愿宣誓，只希望被告按财物的价值承担判决责任，就应依原告的选择处理。

### <a id="6.1.72"></a>6.1.72　乌尔比安《评告示》第十六卷

如果你从提提乌斯处买下塞姆普罗尼乌斯的土地，付清价款并由提提乌斯交付土地；之后提提乌斯成为塞姆普罗尼乌斯的继承人，又将同一土地出售并交付给他人，那么由你取得优先地位更为公平。因为如果出卖人本人向你请求返还该物，你可以通过抗辩将其驳回。即使出卖人本人占有该物，而你向其请求返还，你也可以提出针对所有权抗辩的再抗辩。

<a id="6.1.76.pr."></a>

**序言（pr.）** 关于请求返还全部财物的规则，同样适用于请求返还其中一部分的情形；法官也有职责，按该部分的比例，命令返还必须与该部分一并返还的财物。

<a id="6.1.76.1"></a>

**1.** 如果存在正当事由，可以提起请求返还不确定份额的诉讼。例如，若遗嘱适用《法尔基第法》，由于必须从若干遗赠中扣除的份额尚不确定，受遗赠人在法官面前往往难以查明自己究竟应主张返还多少份额，因此可以认定存在正当理由，准许此项诉讼。其他财物亦作相同理解。

### <a id="6.1.77"></a>6.1.77　乌尔比安《评告示》第十七卷

一名妇女以书信将土地赠与丈夫，随后又从丈夫处租回该土地。可以主张，她有权提起对物之诉，因为她仿佛是通过自己——例如通过承租人——取得该物的占有。设定如下情形：赠与书信发出时，该妇女仍在该地上；仅此即足以构成交付占有，即使双方并未订立租赁合同。

### <a id="6.1.78"></a>6.1.78　拉贝奥《可信论》第四卷，保罗摘要

如果你占有他人的土地，却没有收取其孳息，就无须就该土地的孳息向他人给付。保罗注：恰恰应当追问，孳息是否因其以自己的名义收取而归其取得。所谓收取孳息，不仅指孳息已经完全采收，也包括已经开始采收、并与土地分离的情形；例如，橄榄或葡萄已经摘下，但尚未制成油或酒。此时应当立即视为其已经收取孳息。

### <a id="6.1.79"></a>6.1.79　拉贝奥《可信论》第六卷，保罗摘要

如果你向我请求返还一名奴隶，而该奴隶在诉讼成立后死亡，就应估算其生存期间的孳息。保罗注：只有在该奴隶此前未患上导致其劳务失去价值的疾病时，这一说法才正确；因为即使他仍活着，若患有这种疾病，也不应估算患病期间的孳息。

### <a id="6.1.80"></a>6.1.80　弗里乌斯《评告示》第一卷

不得强令某人应对对物之诉，因为任何人都可以声称自己并未占有该物。如果对方能够证明该物由被告占有，法官就可以命令将占有移转给原告，即使原告并未证明自己享有所有权。
