## 8.6.0　论地役权的消灭方式（*Quemadmodum servitutes amittuntur*）

### <a id="8.6.1"></a>8.6.1　盖尤斯《评行省告示》第七卷

如果同一人开始同时拥有供役地与需役地，地役权即因权利归于一人而消灭。

### <a id="8.6.2"></a>8.6.2　保罗《评告示》第二十一卷

如果某人享有步行通行权和驱赶通行权，却仅在法定期间内行使步行通行权，萨宾、卡西乌斯和奥克塔维努斯认为，驱赶通行权并未消灭，而仍然存续；因为享有驱赶通行权的人本来也可以单独步行通过。

### <a id="8.6.3"></a>8.6.3　盖尤斯《评行省告示》第七卷

通说认为，土地地役权不会因死亡或身份减等而消灭。

### <a id="8.6.4"></a>8.6.4　保罗《评告示》第二十七卷

通往坟墓的道路地役权，绝不会因不行使而消灭。

### <a id="8.6.5"></a>8.6.5　保罗《评告示》第六十六卷

地役权也可以由共有人、用益权人或善意占有人为我们保留：

### <a id="8.6.6"></a>8.6.6　塞尔苏斯《学说汇纂》第五卷

<a id="8.6.6.pr."></a>

**序言（pr.）** 因为只要有人以该土地的名义通行，就已足够。

<a id="8.6.6.1"></a>

**1.** 如果邻人的土地通过通道地役权对我们负责，且我曾经行使该权，而你在法定期间内停止行使，那么你是否已丧失自己的权利？反过来说，如果邻人对我们的土地享有通道地役权，并曾经由我所有的那一部分土地通行，却没有进入你所有的部分，那么邻人是否使你的部分土地免除了地役权？塞尔苏斯答复：如果共有人按界线分割了土地，就其所负地役权而言，应视同该地役权自始分别设定在两块土地上。各共有人分别通过行使而中断时效，也分别因不行使而丧失权利；此后，这两块土地的地役权不再相互牵连。供役地所有人并未因此受损；相反，其处境有所改善，因为其中一名共有人行使权利，只对自己的土地部分有利，而非使整块土地均受益。

<a id="8.6.6.1a"></a>

**1a.** 但是，如果被分割的是供役地，问题就稍有疑难。如果道路的位置固定且界限明确，而土地沿道路的长度方向分割，那么应遵循与设定地役权之初就存在两块供役地相同的规则。反之，如果土地是沿道路宽度方向分割的——无论两部分是否等分——则原来未分割时的地役权仍保持不变；只有整条道路才可以因行使而保留，或因不行使而消灭。即使出现仅使用经过其中一块土地的小路的情形，另一块土地也不会因此免除地役权，因为道路地役权是一项不可分割的权利。

<a id="8.6.6.1b"></a>

**1b.** 不过，只要有特别约定，仍可以使其中一块土地免除地役权。确实，如果地役权受益人买下了分割后的其中一块土地，另一块土地的地役权是否会因此继续存续？我不认为认定其继续存续会导致任何不合理结果，但前提是：起初本来可以将道路设定得比法律规定的宽度更窄，并且尚未解除地役权的另一块土地仍剩有足够空间供道路通过。如果剩余空间不足以容纳道路，则两块土地均免除地役权：一块是因为受益人买下了它，另一块则是因为无法在剩余土地上设置道路。

<a id="8.6.6.1c"></a>

**1c.** 另一方面，如果道路权设定为可以在土地的任何部分通行，且可以随时改变路线，而土地此后又被分割，那么应视同自始就对两块土地分别设定了两项地役权；如此，一项可以通过行使而保留，另一项则可以因不行使而消灭。

<a id="8.6.6.1d"></a>

**1d.** 我并非没有想到，一人的行为会改变另一人的权利；因为此前经由其中一部分土地通行更为便利，从而可在另一部分土地上保留同一权利。反过来说，地役权受益人也取得了一项好处：他可以同样经由两条道路通行，每条道路在直线段宽八尺、在转弯处宽十六尺。

### <a id="8.6.7"></a>8.6.7　保罗《评普劳提乌斯》第十三卷

如果引水权设定为仅可在夏季或某一个月引水，人们会问：如何因不行使而丧失该权利？因为在其不能使用的期间，并不存在连续的一段可供使用而未使用的时间。因此，如果某人隔年或隔月才有权引水，丧失权利所需的法定期间应加倍计算。道路权也适用相同规则。但如果某人隔日、整日或仅在夜间享有权利，则经过法律规定的期间，地役权即告消灭，因为这仍是一项连续存在的地役权。塞尔维乌斯写道，即使某人每天仅在隔小时或一小时内享有地役权，也会因不行使而丧失；因为其享有的权利是每日均可行使的。

### <a id="8.6.8"></a>8.6.8　保罗《评普劳提乌斯》第十五卷

<a id="8.6.8.pr."></a>

**序言（pr.）** 如果我有权将屋檐滴水引入你的院落，却允许你在该院落建造房屋，我便丧失引入滴水的权利。同样，如果你必须允许我经由你的土地通行，而我允许你在我有权通行的地点建造某物，我便丧失通行权。

<a id="8.6.8.1"></a>

**1.** 只要某人行使了通道的一部分，就视为其已通过行使保全了全部通道权。

### <a id="8.6.9"></a>8.6.9　雅沃伦《评普劳提乌斯》第三卷

如果水流进入引水渠道的一部分，即使尚未流至最远处，也视为该引水权的各个部分均已通过行使而保留。

### <a id="8.6.10"></a>8.6.10　保罗《评普劳提乌斯》第十五卷

<a id="8.6.10.pr."></a>

**序言（pr.）** 如果我与未成年人共同拥有一块土地，即使我们二人均未行使通行权，我仍因未成年人而保有道路权。

<a id="8.6.10.1"></a>

**1.** 如果享有夜间引水权的人在足以使地役权消灭的法定期间内，曾在白天引水，那么他因未行使而丧失了夜间地役权。某人若只在特定时段享有引水权，却在其余时段用水，也应作相同处理；对于其享有权利的任何一个时段，若均未行使，便会丧失相应权利。

### <a id="8.6.11"></a>8.6.11　马尔凯卢斯《学说汇纂》第四卷

<a id="8.6.11.pr."></a>

**序言（pr.）** 某人有权使用特定种类的车辆行使道路权或驱赶通行权，却改用另一种类的车辆。我们应当考察，他是否会因此丧失地役权；其情形是否不同于运输超过许可重量之人。后一种情形看起来更像是超出约定，而非实施了其他行为；正如使用较宽的道路，或驱赶超过许可数量的牲畜，或混入其他水源一样。因此，在上述所有情形中，地役权本身并不消灭，但受益人不得据此取得超出约定的权利。

<a id="8.6.11.1"></a>

**1.** 遗嘱命令继承人将附条件遗赠的土地交付受遗赠人；继承人先为该土地设定了地役权。如果遗赠条件成就，这些地役权将消灭。还应考察，已经取得的权利是否随土地归于受遗赠人；较妥当的意见是，地役权随土地一并归其取得。

### <a id="8.6.12"></a>8.6.12　塞尔苏斯《学说汇纂》第二十三卷

某人善意买下他人的土地，并行使该土地所享有的通道权；该通道权因此得以保留。即使他是基于容许占有，或在土地所有人被暴力驱逐后占有该土地，亦同。只要土地仍以其原有形态被占有，地役权便不会消灭；占有人是否依法占有并不重要。更有甚者，即使水自行经由水渠流过，也会保留引水权；萨宾也正确地赞同此说，涅拉提乌斯《札记》第四卷中亦有记载。

### <a id="8.6.13"></a>8.6.13　马尔凯卢斯《学说汇纂》第十七卷

某人出售了自己土地中邻人对之享有道路权的相邻部分，却未为受让人设定该地役权；如果他又在地役权因不行使而消灭的法定期间内重新取得该部分土地，就会重新享有邻人原先负有的地役权。

### <a id="8.6.14"></a>8.6.14　雅沃伦《卡西乌斯著作》第十卷

<a id="8.6.14.pr."></a>

**序言（pr.）** 如果道路权、步行通行权或驱赶通行权所经过的地点被洪水占据，而该地点在足以使地役权消灭的期间内又因冲积而恢复，地役权也恢复至原有状态。但如果该期间已经经过，致使地役权消灭，则必须重新设定该地役权。

<a id="8.6.14.1"></a>

**1.** 如果公共道路因洪水冲击或坍塌而毁坏，最近的邻人必须提供通道。

### <a id="8.6.15"></a>8.6.15　雅沃伦《书信集》第二卷

如果地役权原本须经数块土地行使，而我取得了中间的那块土地，我认为该地役权仍然存续；因为只有在地役权受益人无法行使该权时，地役权才会因权利归于一人而消灭。取得中间的土地后，仍可以经由最初和最末的土地通行。

### <a id="8.6.16"></a>8.6.16　普罗库鲁斯《书信集》第一卷

邻人土地上有泉水，多人依法习惯经由同一水渠引水，每人按自己的日期从水源处引水：最初大家共用同一水渠，随后各人依地势高低分别使用自己的水渠。其中一人未在足以使地役权消灭的法定期间内引水。我认为，他已经丧失引水权，其他人引水也不能替他保留该权，因为每个人的权利均属独立，不能由他人替其行使。但是，如果引水权是由数块土地共同享有，并经其中一块土地通行，那么其中一名共有人可以通过行使而为全体保留权利。同样，如果数名引水权人均享有经同一水渠引水的地役权，其中一人因不引水而丧失了引水权，其他使用该水渠的人并不会因此取得额外权利；相反，利益归于水渠经过其土地的所有人，因为其中一部分地役权已因一人不行使而消灭，该所有人得以享受该部分土地免于负担的状态。

### <a id="8.6.17"></a>8.6.17　庞波尼乌斯《杂论》第十一卷

拉贝奥说，如果享有取水权的人在足以使地役权消灭的期间内曾前往水源，却没有取水，他连通往水源的道路权也一并丧失。

### <a id="8.6.18"></a>8.6.18　保罗《评萨宾》第十五卷

<a id="8.6.18.pr."></a>

**序言（pr.）** 如果某人使用了与设定地役权时约定不同的水，地役权便会消灭。

<a id="8.6.18.1"></a>

**1.** 前手土地所有人未行使地役权的期间，应计入继受该土地之人的期间。

<a id="8.6.18.2"></a>

**2.** 如果你有权将梁木嵌入邻人的墙内，而邻人在足以使地役权消灭的法定期间内没有建造，致使你也无法嵌入梁木，你不会因此丧失地役权；因为邻人并未阻碍你的权利，不能认为其已因时效取得房屋免除该地役权的自由。

### <a id="8.6.19"></a>8.6.19　庞波尼乌斯《评萨宾》第三十二卷

<a id="8.6.19.pr."></a>

**序言（pr.）** 如果我出售土地的一部分时约定，我可以经由该部分向自己保留的土地引水，而在建造水渠之前，法定期间已经经过，我并未丧失任何权利，因为当时还不存在引水通道，我的权利仍完整存续。但如果我已经建成通道却未曾使用，就会丧失该权利。

<a id="8.6.19.1"></a>

**1.** 如果我遗赠给你经由我的土地通行的道路权，而我接受遗产后，你在足以使地役权消灭的法定期间内一直不知道该地役权已遗赠给你，你就会因不行使而丧失道路权。但是，如果在同一期间内、且在你得知受遗赠之前，你已出售自己的土地，那么只要买受人在剩余期间内行使了该道路权，该权利便归买受人；因为道路权既已开始属于买受人，你就不能再放弃遗赠，因为该土地已不再属于你。

### <a id="8.6.20"></a>8.6.20　谢沃拉《法学规则》第一卷

地役权可以通过行使而保留：受益人本人行使，或由占有其土地的人行使，或者由雇工、客人、医生、前来探望土地所有人的人、佃户或用益权人行使，均可保留地役权：

### <a id="8.6.21"></a>8.6.21　保罗《箴言集》第五卷

用益权人即使以自己的名义行使，也可以保留该地役权。

### <a id="8.6.22"></a>8.6.22　谢沃拉《法学规则》第一卷

最后，任何人只要曾将某条道路作为自己应享有的通道行使，

### <a id="8.6.23"></a>8.6.23　保罗《箴言集》第五卷

无论是通往我们的土地，还是从我们的土地通出，

### <a id="8.6.24"></a>8.6.24　谢沃拉《法学规则》第一卷

即使其为恶意占有人，地役权仍会保留。

### <a id="8.6.25"></a>8.6.25　保罗《箴言集》第五卷

只有相信自己是依据自身权利行使地役权的人，才被视为行使了该权。因此，如果某人把道路当作公共道路，或当作属于他人的地役权而加以使用，就不能有效地提起禁令之诉或诉讼。
