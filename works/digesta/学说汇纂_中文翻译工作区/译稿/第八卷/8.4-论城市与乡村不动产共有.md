## <a id="4"></a><a id="8.4"></a>8.4　论城市与乡村不动产的共同规则

*Communia praediorum tam urbanorum quam rusticorum*

### <a id="8.4.1"></a>8.4.1　乌尔比安《法学原理》第二卷

<a id="8.4.1.pr."></a>

**序言（pr.）** 我们把城市中的建筑物称为城市地产；不过，即使建筑物位于乡村庄园，也同样可以设立城市地产地役权。

<a id="8.4.1.1"></a>

**1.** 这些权利之所以称为地产地役权，是因为它们不能脱离地产而设立：只有拥有地产的人，才能取得城市地产或乡村地产的地役权；“也只有拥有地产的人，才能负担地役权”（*nec quisquam debere, nisi qui habet praedium*）。

### <a id="8.4.2"></a>8.4.2　乌尔比安《评告示》第十七卷

对于用水轮从河流中提水、汲水，或对蓄水池设定地役权，有些人曾怀疑这些是否属于地役权。不过，安敦尼皇帝致图利安努斯的敕复补充说：即使这种地役权在法律上并未有效设立，但如果某人依照该条件购得，或以其他合法方式取得了这项权利，就应保护已经占有该权利的人。

### <a id="8.4.3"></a>8.4.3　盖尤斯《评行省告示》第七卷

如果某人拥有两处地产，并在把一处地产交付给你时约定，该地产应为他保留的另一处地产提供便利；或者反过来约定，也应视为地役权已依法设立。

### <a id="8.4.4"></a>8.4.4　雅沃勒努斯《摘自卡西乌斯》第十卷

不能约定纪念碑只能建到某一特定高度，因为已不再属于人法支配范围之物，不能成为地役权的标的；同样，也不能设立这样一种地役权，即约定某一地点只能埋葬特定数量的人。

### <a id="8.4.5"></a>8.4.5　雅沃勒努斯《书信集》第二卷

我出售自己的土地时，能否设立这样一种地役权，使该土地既为我、也为邻人提供便利？同样，如果我出售共有土地，使其为我和共有人提供便利，能否做到？我答复说：无人能够为他人取得地役权。因此，附加邻人的利益应视为多余，全部地役权归取得该权利的人。至于出售共有土地并使其同时为我和共有人提供便利，我无法做到，因为不能由一名共有人为共有土地取得地役权。

### <a id="8.4.6"></a>8.4.6　乌尔比安《评萨宾》第二十八卷

<a id="8.4.6.pr."></a>

**序言（pr.）** 如果某人拥有两所房屋，并交付其中一所，他可以在交付时附加条件：未交付的房屋为已交付的房屋提供地役；也可以反过来，约定已交付的房屋为其保留的房屋提供地役。两所房屋是否相邻，并不重要。乡村地产也是如此：某人若拥有两处庄园，可以通过交付，使一处庄园为另一处庄园提供地役。不过，如果同时交付两所房屋，就不能使一所房屋成为另一所房屋的供役地，因为既不能在他人的房屋上取得地役权，也不能为其设定地役权。

<a id="8.4.6.1"></a>

**1.** 如果某人交付房屋的一部分或土地的一部分，就不能设定地役权，因为地役权不能按部分设定，也不能按部分取得。显然，如果他按界线划分土地，并将其中一部分作为独立地产交付，就可以为其中一处设定地役权，因为它不再是土地的一部分，而是独立的地产。房屋也可作同样解释：如果所有人用一面中墙把一幢房屋分成两幢，许多人都这样做，那么这里也应视为两所房屋。

<a id="8.4.6.2"></a>

**2.** 同样，如果两人共有两所房屋，我们同时交付房屋时，可以达到与我独自拥有两所房屋时相同的效果。即使我们分别交付，结果也相同；但须由最后一次交付使先前的交付也发生效力。

<a id="8.4.6.3"></a>

**3.** 不过，如果其中一所房屋为一人单独所有，另一所为共有，庞波尼乌斯在《评萨宾》第八卷中写道，我对这两所房屋都不能取得或设定地役权。

<a id="8.4.6.3a"></a>

**3a.** 如果有人在买卖时声明其所出售的房屋将成为供役地（*servas fore aedes quas vendidit*），他就没有义务以不负担地役权的状态交付房屋。因此，他可以使这些房屋为自己的房屋提供地役，也可以在交付前允许邻人取得地役权。显然，如果他说这些房屋应为提图斯的地产提供地役：若他已为提图斯设定地役权，义务即告履行；若他却为他人设定了地役权，就应依买卖之诉（*actio empti*）对买受人承担责任。这与马尔切鲁斯在《学说汇纂》第六卷中的论述并不冲突：如果有人在交付时说某地产为提图斯的地产提供地役，而该地产实际上并不负担此项地役；但卖方又负有向提图斯设定地役的义务，那么卖方能否提起出卖之诉（*actio venditi*），要求买受人容许在其所购地产上设定地役权？马尔切鲁斯更倾向于允许其起诉。他还说，即使卖方能够把地役权出售给提图斯，也同样应允许其起诉。只有在交付时明确作出该表示是为了取得地役权时，才适用上述规则。否则，正如他说的，如果卖方只是担心自己对提图斯负有地役权义务而作出保留，而并未承诺设定任何地役权，就不产生出卖之诉（*actio venditi*）。

### <a id="8.4.7"></a>8.4.7　保罗《评萨宾》第五卷

<a id="8.4.7.pr."></a>

**序言（pr.）** 拥有两所房屋的人交付其中一所时，必须明确说明所设定的地役权种类；否则，如果笼统地说该房屋应提供地役，或者因不清楚保留的是哪种地役权而使约定无效，或者就必须认为设定了所有种类的地役权。

<a id="8.4.7.1"></a>

**1.** 即使隔着他人的房屋，也可以设定地役权，例如允许或禁止加高房屋，或者设定通行权，但约定须待中间房屋后来也负担地役权时才生效。正如地役权可以在不同时间经由数人的地产设立一样。尽管也可以这样说：如果我有三处相连的地产，并将最外侧的一处交付给你，那么可以由你的地产或我自己的地产取得地役权；如果地役权设立在我保留的最外侧地产上，由于中间地产也是我的，地役权即可成立。但如果我随后又转让了取得地役权的地产或中间地产，该地役权就会中断，直至中间地产也被设定地役权为止。

### <a id="8.4.8"></a>8.4.8　庞波尼乌斯《评萨宾》第八卷

如果我拥有两幢公寓楼，并在同一时刻将它们分别交付给两人，应考察为其中一幢设定地役权是否有效，因为不能在他人的房屋上设定或取得地役权。但在交付完成之前，交付人仍是在自己的房屋上取得或设定地役权，因此该地役权有效。

### <a id="8.4.9"></a>8.4.9　庞波尼乌斯《评萨宾》第十卷

如果我继承了某人的遗产，而他的地产原来为我的地产提供地役；随后我又把该遗产卖给你，就应恢复地役权原来的状态，因为此处的目的，是把你视为仿佛已经成为该遗产的继承人。

### <a id="8.4.10"></a>8.4.10　乌尔比安《评萨宾》第十卷

卖方希望以地役权名义为自己保留的任何权利，都必须逐项明确保留。因为一般性的保留条款“凡原有地役权者，均仍照旧”（*quibus est servitus utique est*）适用于第三人，并不能帮助卖方保全自己的权利；他原本并无此种权利，因为无人对自己负有地役权。事实上，即使原先确有地役权，而供役物的所有权后来转归于我，也应据此认为地役权消灭。

### <a id="8.4.11"></a>8.4.11　庞波尼乌斯《评萨宾》第三十三卷

<a id="8.4.11.pr."></a>

**序言（pr.）** 为修缮之目的，地役权人有权进入并非供役地的地点；但只有在确有必要时才能进入，除非设定地役权时已明确规定进入路线。因此，土地所有人不得把水渠旁或水渠上方的地点（例如水渠在地下引水时）设为宗教用地，以免地役权消灭；这一点是正确的。你也可以降低或抬高自己依法有权引水经过的水渠，除非你已作出不得如此处理的保证。

<a id="8.4.11.1"></a>

**1.** 如果我有权通过你的土地附近的水渠引水，就默示伴随该权利而有以下权利：我可以修缮水渠；我和我的工匠可以从最近的路径前往修缮；土地所有人还应在水渠左右留出空间，使我能够前往水渠，并能把泥土、淤泥、石块、沙子和石灰堆放在那里。

### <a id="8.4.12"></a>8.4.12　保罗《评萨宾》第十五卷

一处地产为另一处地产提供地役时，即使地产被出售，地役权也随地产移转。房屋对地产、地产对房屋，也依照同一规则负担地役。

### <a id="8.4.13"></a>8.4.13　乌尔比安《意见集》第六卷

<a id="8.4.13.pr."></a>

**序言（pr.）** 格罗尼亚努斯地产（*fundus Geronianus*）的卖方，对其保留的波特里亚努斯地产（*fundus Botrianus*）规定了条件：不得在面向该地产的海域从事金枪鱼捕捞。虽然公海依其性质为所有人开放，不能通过私人约定对其设定地役权；但由于合同诚信要求遵守买卖中规定的条件，占有人或依法继受其权利的人，仍受买卖条款或要式口约的约束。

<a id="8.4.13.1"></a>

**1.** 如果可以确定你的土地上有采石场，未经你同意，任何人都不得以私人或公共名义采石，除非他有权这样做。不过，如果该采石场存在这样的惯例：任何人想从中采石，都必须先向所有人支付惯常补偿，那么可以依此办理。但采石仍须在补偿所有人之后进行，并且既不得妨碍对石料的必要使用，也不得依法剥夺所有人的利益。

### <a id="8.4.14"></a>8.4.14　尤利安《学说汇纂》第四十一卷

步行通行权可以这样设立：某人只能在白天步行通行。这种限制对于城市地产往往也是必要的。

### <a id="8.4.15"></a>8.4.15　保罗《阿尔芬努斯〈学说汇纂〉摘要》第一卷

确实，一个人把经过某一特定地点的步行通行权或驱畜通行权让与他人后，仍可以让与多人，使他们都经由同一地点步行或驱畜通行；正如某人使自己的房屋为邻人的房屋提供地役后，仍可以使该房屋为任意多个其他人的房屋提供地役。

### <a id="8.4.16"></a>8.4.16　盖尤斯《日常法学概要》（又称《金言集》）第二卷

立遗嘱人也可以在遗嘱中对继承人课以义务：不得加高自己的房屋，以免妨碍邻近房屋采光；或者应允许邻人把梁木插入自己的墙内，允许雨水流向邻人一侧；或者允许邻人穿过自己的土地通行、驾车通行，或从土地上引水。

### <a id="8.4.17"></a>8.4.17　帕皮尼安《疑问集》第七卷

如果邻人经你允许，以可随时撤回的方式在你的土地上筑墙，就不能提起“关于其以可撤回许可占有之物”的禁令（*quod precario habet*）；筑墙也不被视为已经完成了地役权的赠与；而且，主张自己有权违背你的意愿保有该建筑，也不会获得支持，因为建筑物随土地的法律状态而定，该主张因此不能成立。反之，如果一个对你负有地役权义务的人，经可随时撤回的许可在自己的土地上筑墙，土地取得无地役权状态（*libertas*）的时效就不会完成；你可以有效地对他提起“关于其以可撤回许可占有之物”的禁令（*quod precario habet*）。如果你是出于赠与目的允许他筑墙，你既不能再提起该禁令，地役权也因赠与而消灭。

### <a id="8.4.18"></a>8.4.18　保罗《实用手册》第一卷

已经确立：数名所有人即使不是同时让与，也可以设定或取得地役权；但最后一项行为必须确认先前的行为，使其效力如同所有人同时作出让与〔原文疑误：底本作 *cessissententiarum*，疑有词语粘连；此处依上下文暂译其可辨含义，原文仍待核〕。因此，如果最先让与的人已经死亡，或以其他方式、其他原因转让了自己的份额，而此后共有人才作出让与，就不发生效力：因为最后一人作出让与时，地役权并非溯及既往地取得；而是视为在最后一人作出让与之时，所有人都已作出让与。于是，这一行为仍处于待定状态，直至新的共有人作出让与。即使先由一名共有人向某人让与，而后另一名共有人发生上述情形，法律也相同。因此，反过来说，如果未作出让与的共有人发生上述任何一种情形，所有人就都必须重新作出让与。法律只给予他们一段可以共同作出让与、也可以分时作出让与的期间；所以任何一人都不能代替另一人让与。若一人让与地役权，另一人以遗嘱遗赠地役权，也应作相同解释。如果所有共有人都遗赠地役权，并且他们的遗产同时被承受，可以认为遗赠有效；如果遗产在不同时间被承受，遗赠的履行期就会无效地开始，因为法律并未承认死者的行为可以像生者的行为那样处于待定状态。
