## 8.5.0　论地役权之诉与否认之诉（*Si servitus vindicetur vel ad alium pertinere negetur*）

### <a id="8.5.1"></a>8.5.1

乌尔比安《评告示》第十四卷

关于农村土地役权或城市土地役权的诉权，属于拥有相关土地的人。坟墓并非我们的所有物；然而，我们可以就通往坟墓的道路提起确认之诉。

### <a id="8.5.2"></a>8.5.2

乌尔比安《评告示》第十七卷

<a id="8.5.2.pr."></a>

**序言（pr.）** 关于役权，我们可以仿照用益权提起物权之诉，包括确认之诉（*actio confessoria*）和否认之诉（*actio negatoria*）：主张自己享有役权的人提起确认之诉；所有权人否认役权存在时提起否认之诉。

<a id="8.5.2.1"></a>

**1.** 该确认物权之诉仅属于土地所有人。因为，只有对相邻土地享有所有权，并主张该土地应负担役权的人，才能请求确认役权。

<a id="8.5.2.2"></a>

**2.** 涅拉提乌斯正确地写道，如果遗赠了中间地块的用益权，通行权也随之而来——也就是说，应当经由土地中用益权设立人所指定的地点通行——但以行使用益权所必需的范围为限。须知，为使受益人行使用益权而提供的通行权，并非役权，因为役权不能仅对用益权人个人负担；但如果役权是对土地负担的，用益权人也可以行使该权利。

<a id="8.5.2.3"></a>

**3.** 庞波尼乌斯说，如果用益权人在本年度曾经通行，就可以使用关于通行的禁令救济（*interdictum de itinere*）。因为，一处讨论的是权利，即确认之诉；另一处讨论的是事实，即本项禁令中的实际通行情形。尤利安在《学说汇纂》第四十八卷中也这样写道。拉贝奥所写的内容支持尤利安的意见：即使用益权遗赠人曾经通行，也应向用益权人提供准禁令救济，正如继承人或买受人也可以适用这些禁令一样。

### <a id="8.5.3"></a>8.5.3

乌尔比安《评告示》第七十卷

如果有人买下土地的一部分，也应作同样处理。

### <a id="8.5.4"></a>8.5.4

乌尔比安《评告示》第十七卷

<a id="8.5.4.pr."></a>

**序言（pr.）** 地役权所涉的场所本身，并非役权所归属之人的所有物；此人享有的只是通行之权。

<a id="8.5.4.1"></a>

**1.** 享有步行通行权（*iter*）而不享有驱赶通行权（*actus*），或享有驱赶通行权而不享有步行通行权的人，应提起役权之诉。

<a id="8.5.4.2"></a>

**2.** 关于役权提起确认之诉时，也包括孳息。但我们应当考察，役权可能产生什么孳息。较为正确的看法是，只有起诉人因不被阻碍行使役权而享有的利益，才计作孳息。在否认之诉中，正如拉贝奥所说，孳息也应计入；其数额应按原告因对方不使用其土地上的道路而享有的利益计算。庞波尼乌斯也赞同此说。

<a id="8.5.4.3"></a>

**3.** 如果享有通行权的土地属于数人，每一人都可就全部权利提起诉讼；庞波尼乌斯在《学说汇纂》第四十一卷中也这样写道。不过，赔偿估价应计入提出诉讼者本人的利益，也就是说，计入实际起诉者的利益。因此，各人就役权本身均可提起诉讼，胜诉也会使其他人受益；但赔偿估价应以该起诉者的利益为限，尽管役权不能由一人单独取得。

<a id="8.5.4.4"></a>

**4.** 如果供役地属于两人，也可以分别对每一人提起诉讼。正如庞波尼乌斯在同卷中所写，无论谁为该诉讼作出应诉，均应恢复全部权利，因为此事不容分割。

<a id="8.5.4.5"></a>

**5.** 如果有人并不否认我享有步行通行权、驱赶通行权或道路通行权，却不允许我修缮、铺设道路，庞波尼乌斯在同卷中写道，我应提起确认之诉。又如，邻人有一棵树伸展过来，使道路或通道无法通行或难以使用，马尔凯卢斯在尤利安著作中也指出，应请求步行通行权或主张道路权。至于修缮道路，我们也可以使用关于修缮步行道和驱赶通道的禁令救济（*interdictum de itinere actuque reficiendo*）；但若有人要用石材铺路，除非协议对此有明确约定，否则不能如此要求。

<a id="8.5.4.6"></a>

**6.** 汲水权也是一种役权，因此我们也可以就此提起物权之诉。

<a id="8.5.4.7"></a>

**7.** 如果某建筑物所有人否认其建筑物对邻人负有役权，而该建筑物并非完全不负任何役权、只是对诉讼相对人不负役权，那么该所有人可以提起役权之诉。例如，我有房屋，毗邻塞伊乌斯家族的房屋和塞姆普罗尼乌斯家族的房屋；我对塞姆普罗尼乌斯家族负有役权。若塞伊乌斯家族的房屋所有人阻止我加高房屋，我可以对他提起物权之诉。虽然我的房屋负有役权，但并不对本案相对人负担役权；因此，我主张自己有权不顾相对人反对而加高房屋。就该相对人而言，我的房屋是自由的。

<a id="8.5.4.8"></a>

**8.** 如果某人完全无权加高房屋，可以适当地对其提起诉讼，主张他无权加高房屋。此种役权也可以对更远处房屋的所有人负担。

### <a id="8.5.5"></a>8.5.5

保罗《评告示》第二十一卷

因此，如果你的房屋位于我的房屋与提提乌斯的房屋之间，我可以为提提乌斯的房屋设立不得加高的役权，即使没有为你的房屋设立役权也可以；因为只要你不加高房屋，这项役权就仍有实际利益。

### <a id="8.5.6"></a>8.5.6

乌尔比安《评告示》第十七卷

<a id="8.5.6.pr."></a>

**序言（pr.）** 假如位于中间的邻人原本不负有役权，却把自己的建筑物加高，以致我若建筑便不再被视为妨碍你的采光，那么你主张我无权不顾你的反对而这样建筑，就不会胜诉。但如果邻人在法定期间内又拆除了建筑物，你的确认之诉权便会复生。

<a id="8.5.6.1"></a>

**1.** 须知，在这些役权关系中，也存在占有人与请求人的区分。譬如，如果我尚未在自己的土地上加高建筑物，我的对方就是占有人；既然没有任何新情况发生，他便是占有人，可以通过民事诉讼以及“以暴力或秘密方式实施之行为”禁令（*interdictum quod vi aut clam*）阻止我建筑。若他通过投掷石块妨碍我，也同样如此。但如果他容许我建筑，我便取得占有人地位。

<a id="8.5.6.2"></a>

**2.** 如果设立役权的目的是承受建筑物的重量，我们也可以提起诉讼，要求对方承重，并按照设立役权时约定的方式修缮建筑物。加卢斯认为，不能设立役权要求某人积极作为；只能要求其不得妨碍我作为。因为在所有役权中，修缮义务都属于主张自己享有役权的人，而非其财产供役的人。不过，在所述情形下，塞尔维乌斯的意见已经成为通说：可以主张自己有权要求对方修缮墙壁，以承受自己的建筑物重量。拉贝奥则写道，负担此种役权的不是某个人，而是物；因此，所有人可以抛弃该物。

<a id="8.5.6.3"></a>

**3.** 此项诉讼更接近物权之诉，而非对人之诉；它只属于建筑物所有人，并且只能针对建筑物所有人提起，正如其他役权的诉讼主张一样。

<a id="8.5.6.4"></a>

**4.** 如果建筑物有数名所有人，是否可以对全部权利提起诉讼，帕比尼安在《疑义》第三卷中作了讨论。他说，每一名所有人都可以就全部权利提起诉讼，如同其他役权一样，但用益权除外。不过，他说，如果这些建筑物为共有，且共同承受邻人的重量，则不能作同样答复。

<a id="8.5.6.5"></a>

**5.** 在此项诉讼中，修缮方式应依设立役权时约定的内容确定，例如约定用方石、砌块或其他特定方式修缮。

<a id="8.5.6.6"></a>

**6.** 此项诉讼也包括孳息，也就是如果邻人承受了其建筑物的重量，权利人本可获得的利益。

<a id="8.5.6.7"></a>

**7.** 墙壁可以修得比役权设立时约定的更好；若修得更差，则可以通过此项诉讼或新工程告知（*operis novi nuntiatio*）予以制止。

### <a id="8.5.7"></a>8.5.7

保罗《评告示》第二十一卷

这些诉讼的结果是，胜诉者可依职权要求法官判令对方履行原状给付，或提供担保。原状给付是指法官命令对方修复墙壁的缺陷，并使墙壁达到适用状态。担保则是指法官命令对方就修缮墙壁提供保证，并保证其本人及继承人不会阻止胜诉者加高建筑物，也不会使已经加高的建筑物被拆除。〔*sublatumque habere* 的法律效果表述较压缩，译文依上下文理解为保有所加高的建筑。〕若对方提供了担保，即判其免责。如果既不履行原状给付，也不提供担保，就应按原告对诉讼标的宣誓估价（*iusiurandum in litem*）确定的金额判令其赔偿。

### <a id="8.5.8"></a>8.5.8

乌尔比安《评告示》第十七卷

<a id="8.5.8.pr."></a>

**序言（pr.）** 正如修缮墙壁属于邻人，役权所归属的邻人之建筑物在墙壁修缮期间的支撑，也不应由下方邻人负责。如果上方邻人不愿支撑，就应拆下自己的建筑物，并在墙壁修复后重新建起。对此，如同其他役权，也可提起反向诉讼（*actio contraria*），即主张你无权强迫我这样做。

<a id="8.5.8.1"></a>

**1.** 如果有人向我让与这样一项役权，即允许我把梁插入他的墙壁，并在梁上建造例如一条有顶的步廊，还可以在该墙上立砌筑的柱子以支撑步廊屋顶，我可以对其提起相应诉讼。

<a id="8.5.8.2"></a>

**2.** 这两种诉讼的区别在于：前一种诉讼还可用于强令邻人修缮我的墙壁；本项诉讼则仅用于要求其承托梁木，而这种义务并不违背役权的种类和性质。

<a id="8.5.8.3"></a>

**3.** 如果需要确定谁处于占有人地位、谁处于请求人地位，应当知道：如果梁已经插入，主张自己享有役权的人处于占有人地位；如果尚未插入，则否认役权的人处于占有人地位。

<a id="8.5.8.4"></a>

**4.** 如果主张役权的人胜诉，不应把役权另行让与给他；无论判决正确——因为他本来就享有役权——还是判决错误，都是如此，因为判决不应创设役权，而只能确认已经存在的役权。当然，如果他在诉讼标的确定后，因建筑物所有人的恶意而未行使役权并因此丧失该权利，就应使其恢复该权利；建筑物所有人的情形也依此处理。

<a id="8.5.8.5"></a>

**5.** 阿里斯托答复塞雷利乌斯·维塔利斯说，他认为，除非设立了允许此种行为的役权，否则卡西亚里亚商铺排出的烟气不能合法地进入上层建筑。他还说，从上层建筑向下层排放水或其他物也不允许：任何人只能在自己的土地上行事，直到不把任何东西排入他人土地为止；烟气的排放与水的排放相同。因此，上层建筑所有人可以对下层所有人提起诉讼，主张后者无权如此行事。阿尔费努斯还写道，可以提起诉讼，主张某人无权在自己的土地上凿石，以致碎石落入我的土地。阿里斯托说，从明图尔奈人处租赁卡西亚里亚商铺的人，可以被上层邻人禁止排放烟气；但明图尔奈人应依租赁关系对其承担责任。他还说，可以对排放烟气的人提起诉讼，主张其无权排放。因此，反过来也可以提起诉讼，主张自己有权排放烟气；阿里斯托似乎也赞同这一点。如果有人被阻止以自己希望的方式使用自己的财产，也可以适用“依现状占有”禁令（*interdictum uti possidetis*）。

<a id="8.5.8.6"></a>

**6.** 庞波尼乌斯在《讲义》第四十一卷中对此存疑：某人能否提起诉讼，主张自己有权在自己的土地上排放并不浓重的烟气，例如炉灶产生的烟气？或者反过来，主张自己无权排放？他认为，更妥当的答案是不能提起此类诉讼；正如不能提起诉讼主张自己有权在自己的土地上生火、坐下或沐浴一样。

<a id="8.5.8.7"></a>

**7.** 同一作者又赞同相反的意见。他说，在浴场中，昆提拉曾设置一条烟道，将蒸汽导向乌尔苏斯·尤利乌斯的场所；当时认为，可以设立这类役权。〔底本此处人名及“浴场—烟道”的关系表述压缩，译文依字面处理。〕

### <a id="8.5.9"></a>8.5.9

保罗《评告示》第二十一卷

<a id="8.5.9.pr."></a>

**序言（pr.）** 如果你在我享有通行权的地方建筑，我可以主张自己有权通行、驱赶；如果我证明此权存在，就可以制止你的工程。尤利安还写道，如果邻人在自己的土地上建筑，致使我的屋檐雨水无法排入其处，我可以就自己的权利提起诉讼，也就是主张自己有权排放檐水，如同我们前面对道路权所说的那样。不过，如果对方尚未建筑，无论我享有用益权还是道路权，都可以主张自己有权通行、驱赶或行使用益权。如果土地所有人已经建筑，享有步行通行权和驱赶通行权的人仍可以主张自己的权利；但用益权人不能这样做，因为其用益权已经丧失。因此，尤利安说，在这种情况下应给予诈欺之诉。反过来，如果你在我应向你提供通行权的路线上建筑，我可以正当地主张你无权建筑或保有该建筑，正如你在我的空地上建筑时一样。

<a id="8.5.9.1"></a>

**1.** 使用较宽或较窄道路的人，仍保有其役权；同样，享有用水权的人即使改用混合了其他水源的水，也仍保有其权利。

### <a id="8.5.10"></a>8.5.10

乌尔比安《评告示》第五十三卷

<a id="8.5.10.pr."></a>

**序言（pr.）** 如果某人因长期使用和长期准占有而取得引水权，就无须证明该引水权通过何种法律原因设立，例如是否源自遗赠或其他方式；他享有准诉权，只须证明自己在若干年间以非暴力、非秘密、非容假方式持续行使该权利。

<a id="8.5.10.1"></a>

**1.** 提起此项诉讼时，被告不仅可以是水源所在土地的所有人或引水经过土地的所有人，也可以是任何妨碍引水的人；这与其他役权相同。总之，任何人妨碍引水，我都可以对其提起此项诉讼。

### <a id="8.5.11"></a>8.5.11

马尔凯卢斯《学说汇纂》第六卷

有人询问：共有土地的一名共有人能否不顾其他共有人的反对而合法建筑？也就是说，如果其他共有人阻止他，他能否对他们提起诉讼，主张自己有权建筑？反过来，其他共有人能否对他提起诉讼，主张自己有权禁止他建筑，或主张他无权建筑？如果建筑已经完成，其他共有人能否对他提起诉讼，主张他无权维持该建筑？对此，更适宜的说法是，共有人享有的是禁止他人建筑的权利，而非自行建筑的权利；因为如我所说，试图建筑的人若想像唯一所有人那样按自己的意愿使用共有权，某种程度上就是侵夺了他人的权利。

### <a id="8.5.12"></a>8.5.12

雅沃勒努斯《书信》第二卷

我提起诉讼，主张某人无权将梁插入我的墙壁。我问：是否也应要求其担保将来不再插入梁木？我答复：我认为，法官的职责包括要求其就将来的工程也提供担保。

### <a id="8.5.13"></a>8.5.13

普罗库鲁斯《书信》第五卷

我把输水管铺设在公共道路上，水由此输送；这些管道破裂后，水淹湿了你的墙壁。我认为，你可以正当地对我提起诉讼，主张我无权使水从我的管道流到你的墙上。

### <a id="8.5.14"></a>8.5.14

庞波尼乌斯《评萨比努斯》第三十三卷

<a id="8.5.14.pr."></a>

**序言（pr.）** 如果墙壁原本完全属于我，而我允许你把你先前已有的梁插入墙中，那么你若要插入新的梁，我可以制止；甚至我也可以对你提起诉讼，要求你移除新插入的梁。

<a id="8.5.14.1"></a>

**1.** 如果你施工导致共有墙壁倾斜到我的房屋一侧，我可以对你提起诉讼，主张你无权使该墙壁保持这种状态。

### <a id="8.5.15"></a>8.5.15

乌尔比安《意见集》第六卷

某人加高自己的房屋，从而遮挡一名未满二十五岁的未成年人或未适婚年龄者房屋的采光；该未适婚年龄者由此人担任监护人或保护人。尽管此人及其继承人还应就此承担诉讼责任——因为他依职务本应阻止他人实施的行为，自己却不应实施——但也应准许该未适婚年龄者或未成年人对该房屋的占有人提起诉讼，以便拆除违法建造的部分。

### <a id="8.5.16"></a>8.5.16

尤利安《学说汇纂》第七卷

如果我向你购买一项权利，允许雨水从我的房屋排入你的房屋；此后你明知此事，我依购买关系使雨水排入你的房屋，我问：我是否可以基于这一原因，通过某种诉讼或抗辩受到保护？我答复：我可以同时使用这两种救济。

### <a id="8.5.17"></a>8.5.17

阿尔费努斯《学说汇纂》第二卷

<a id="8.5.17.pr."></a>

**序言（pr.）** 如果两幢房屋之间有一堵墙向外鼓出，以致伸入邻人房屋半罗马尺或更多，就应提起诉讼，主张该墙无权违背自己的意愿如此突出并侵入自己的房屋。

<a id="8.5.17.1"></a>

**1.** 有人询问：盖乌斯·塞伊乌斯的房屋中有一处地方，为安尼乌斯的房屋提供役权；因此，塞伊乌斯无权在该处放置物品。塞伊乌斯却在那里种了一片树林，并放置了 *labra et tenes cucumellas* 等物。所有法学家都建议安尼乌斯对他提起诉讼，主张塞伊乌斯无权违背安尼乌斯的意愿在该处放置这些物品。〔底本人名及 *labra et tenes cucumellas* 一处文字疑有讹误，物名未能可靠判读，故保留拉丁原词。〕

<a id="8.5.17.2"></a>

**2.** 邻人在某人的墙边建了粪堆，导致墙壁受潮；有人询问如何强令邻人移走粪堆。我答复：如果粪堆建在公共场所，可以通过禁令强令移除；如果建在私人土地上，则应提起役权之诉。如果他已就尚未发生的损害提供要式口约担保，那么一旦因此遭受损害，也可以依据该担保获得救济。

### <a id="8.5.18"></a>8.5.18

尤利安《米尼基乌斯论著》第六卷

某人的家内人员（*familia*）阻止邻人引水，而此人拒不出面应诉，以致无法对其提起诉讼。原告询问应当如何处理。我答复：行政长官查明情况后，应命令原告占有对方财产；在此人向原告设立引水权，并赔偿原告因被禁止引水而在干旱中遭受的损失之前，不应解除对该财产的占有，例如草地或树木因此干枯所造成的损失。

### <a id="8.5.19"></a>8.5.19

马尔基安《规则》第五卷

如果某人就共有役权正确地主张该役权确实应当存在，却因自己的过失败诉，不应使其他人也因此受损。但如果他与对方串通而在诉讼中让步，塞尔苏斯写道，应向其他共有人给予诈欺之诉；他说，萨比努斯也赞同此意见。

### <a id="8.5.20"></a>8.5.20

斯凯沃拉《学说汇纂》第四卷

<a id="8.5.20.pr."></a>

**序言（pr.）** 遗嘱人在其遗赠的土地旁有相连的几间房屋。有人询问：如果这些房屋并未随遗赠的土地一并移转，而受遗赠人主张取得该土地，那么该土地是否对这些房屋负有某种役权？或者，如果受遗赠人请求以遗嘱信托方式取得该土地，继承人是否应保留某种役权，使这些房屋继续享有？答复：应当负有役权。

<a id="8.5.20.1"></a>

**1.** 数名市镇居民各自拥有不同土地，他们共同购买一片牧场，以便享有共同放牧权（*ius compascendi*）；其继承人也一直遵循这一做法。后来，其中一些享有该权利的人出售了各自的私人土地。我问：出售时，该放牧权是否也随土地转移，因为卖方有意一并让与该权利？答复：应依当事人之间的约定处理；如果当事人的意思并不明确，该权利也转移给买受人。我又问：如果这些私人土地中的一部分遗赠给某人，该部分土地是否也带有共同放牧权？答复：既然该权利也被视为遗赠土地的一项权利，它也应转移给受遗赠人。

### <a id="8.5.21"></a>8.5.21

拉贝奥《论可信命题》第一卷（保罗节编）

如果某处水源尚未显现，就不能为该水源设立通行权或引水权。保罗说：相反，我认为这句话不正确，因为可以让与一项权利，允许某人寻找水源，并在找到后引水。
