## 8.1.0　论役权（*De servitutibus*）

### <a id="8.1.1"></a>8.1.1

马尔基安《规则》第三卷

役权有属于人的，例如使用权和用益权；也有属于物的，例如农村土地役权和城市土地役权。

### <a id="8.1.2"></a>8.1.2

乌尔比安《评告示》第十七卷

共有房屋的共有人之一，不得单独为该房屋设立役权。

### <a id="8.1.3"></a>8.1.3

保罗《评告示》第二十一卷

土地役权有的以地面为对象，有的以地上建筑物为对象。

### <a id="8.1.4"></a>8.1.4

帕比尼安《疑义》第七卷

<a id="8.1.4.pr."></a>

**序言（pr.）** 役权依其本身法理，既不得自某一时点起设立，也不得仅在一定期间内设立；不得附条件设立，也不得附加某种确定条件设立（例如“只要我愿意”）。但是，如果加入了这类约定，对于违背约定而主张役权的人，可以提出协议抗辩或诈欺抗辩。卡西乌斯记载，萨比努斯也曾作出这样的答复；卡西乌斯本人亦赞同此说。

<a id="8.1.4.1"></a>

**1.** 役权可以附加行使方式的限制，这一点没有疑问；例如，规定可以或不可以使用何种车辆通行（比如仅可骑马），或者规定运输物的特定重量、驱赶某一特定畜群通过，或搬运木炭。

<a id="8.1.4.2"></a>

**2.** 依法设立的役权中，对日期或时段作出间隔安排，属于对行使方式的限制，而非对役权存续期间的限制。

### <a id="8.1.5"></a>8.1.5

盖尤斯《评行省告示》第七卷

<a id="8.1.5.pr."></a>

**序言（pr.）** 道路通行权（*via*）、步行通行权（*iter*）、驱赶通行权（*actus*）以及引水权（*ductus aquae*），其设立方式大体与我们前述用益权的设立方式相同。

<a id="8.1.5.1"></a>

**1.** 役权的行使可以按时间分隔；例如，有人可自第三时至第十时行使该权，或者隔日行使。

### <a id="8.1.6"></a>8.1.6

保罗《评告示》第二十一卷

役权可以针对土地的特定部分设立，也可以就该特定部分予以免除。

### <a id="8.1.7"></a>8.1.7

乌尔比安《评尤利亚法与帕皮亚法》第十三卷

排放污水的权利属于役权。

### <a id="8.1.8"></a>8.1.8

保罗《评普劳提乌斯》第十五卷

<a id="8.1.8.pr."></a>

**序言（pr.）** 不得设立役权，使我们可以摘取他人土地上的果实、在其土地上散步，或在那里用餐。

<a id="8.1.8.1"></a>

**1.** 如果你的土地为我的土地提供役权，那么无论后来是我成为你土地一部分的所有人，还是你成为我土地一部分的所有人，该役权都在各自仍分属不同所有人的部分上继续存在；尽管起初不能仅针对土地的一部分取得役权。

### <a id="8.1.9"></a>8.1.9

塞尔苏斯《学说汇纂》第五卷

如果有人以未作具体限定的方式，获让或受遗留一项经过他人土地的道路权，他原则上可以经由该土地的任何部分通行、驱赶，但须以合理方式行使；因为某些限制虽未写明，却默示地排除在约定之外。例如，不得让其穿过宅院本身或葡萄园中央；如果经由土地另一部分同样便利，且对供役地造成的损害较小，就应走该处。然而，通行路线一经首次确定，便应沿该路线通行、驱赶，不得再任意改变。萨比努斯也持此见，并以水渠为例：起初可以将水渠引往任何地方；一旦引成，便不得迁移。道路权亦应如此。

### <a id="8.1.10"></a>8.1.10

塞尔苏斯《学说汇纂》第十八卷

如果遗赠了一项步行通行权，而不施工就无法通行，普罗库鲁斯认为，可以通过开挖并修筑支撑结构来形成通道。

### <a id="8.1.11"></a>8.1.11

莫德斯蒂努斯《区别》第六卷

通常认为，役权不能按所有权份额取得。因此，如果某人拥有一块土地，先就道路权订立要式口约，之后又让与自己土地的一部分，就会使该要式口约失效，因为他使该口约落入一种役权无法开始发生效力的情形。道路权也不得按份遗赠或按份撤回；若如此遗赠或撤回，该遗赠或撤回均不发生效力。

### <a id="8.1.12"></a>8.1.12

雅沃勒努斯《书信》第四卷

我毫不怀疑，可以通过奴隶为市镇所有的土地合法取得役权。

### <a id="8.1.13"></a>8.1.13

庞波尼乌斯《评昆图斯·穆基乌斯》第十四卷

如果在划定一条极窄的路线后授予道路权，以致车辆和役畜都无法进入，那么所取得的应是步行通行权（*iter*），而不是道路通行权（*via*）或驱赶通行权（*actus*）。但如果役畜可以沿此路线驱赶、车辆却不能通行，则应认为取得的是驱赶通行权（*actus*）。

### <a id="8.1.14"></a>8.1.14

保罗《评萨比努斯》第十五卷

<a id="8.1.14.pr."></a>

**序言（pr.）** 农村土地役权即使附着于有体物，仍属无体物，因此不能通过长期占有取得。或者说，这是因为这类役权没有确定且持续不断的占有：没有人能够始终不间断地通行，以至于其占有似乎在任何时刻都未曾中断。城市土地役权亦同样处理。

<a id="8.1.14.1"></a>

**1.** 通往私人坟墓的道路役权仍属私法权利，因此可以向供役地所有人免除；即使坟墓已具有宗教物的性质，此项役权仍可取得。

<a id="8.1.14.2"></a>

**2.** 如果有公共场所或公共道路介于其间，可以设立汲水役权，却不能设立引水役权。不过，人们通常向皇帝请求许可，以便在不妨碍公共利益的情况下经由公共道路引水。神圣场所或宗教场所介于其间，也会阻止通行役权的设立，因为任何人都不能对这些场所享有役权。

### <a id="8.1.15"></a>8.1.15

庞波尼乌斯《评萨比努斯》第三十三卷

<a id="8.1.15.pr."></a>

**序言（pr.）** 如果既非人的役权，也非土地役权——因为邻人并无任何利益——那么有关约定便不发生效力，例如约定不得经过你的土地或不得在那里停留。因此，如果你允许我主张你无权使用、收益自己的土地，也毫无效果。与此不同，如果你允许我主张你无权在自己的土地上寻找水源，以免减少我的水量，则该约定有效。

<a id="8.1.15.1"></a>

**1.** 役权的性质并非要求某人积极作为，例如清除绿植、提供更宜人的景观，或在自己的土地上绘画；其性质在于要求某人容忍某事，或者不实施某行为。

### <a id="8.1.16"></a>8.1.16

尤利安《学说汇纂》第四十九卷

对于以土地作为质物的质权人，给予其关于役权的准诉权并无不公，正如可以给予其对该土地本身的准诉权一样。对于公税地（*fundus vectigalis*）权利人，也应适用同一规则。

### <a id="8.1.17"></a>8.1.17

庞波尼乌斯《规则单卷》

道路通行权、步行通行权、驱赶通行权和引水权均不可按部分转化为债务关系，因为这些权利的使用不可分。因此，如果要式口约债权人死亡并留下数名继承人，每一人都可以请求完整的道路权；如果要式口约债务人死亡并留下数名继承人，也可以向每一名继承人请求全部给付。

### <a id="8.1.18"></a>8.1.18

保罗对帕比尼安《疑义》第三十一卷的附记〔底本题署作 *Paulus notum ad Papiniani liber 31 quaestionum*，语形及格关系疑有讹误；译文据语境理解为“保罗对……的附记”。〕

在一切以底本文字 *actione confusae* 表述的役权中，据答复，若受遗赠人不允许这些役权重新设立，诈欺抗辩将对其发生效力。〔底本文字含义未详；另有转录作 *aditione confusae*。此处保留底本原文，不据推测改译。〕

### <a id="8.1.19"></a>8.1.19

拉贝奥《后论》第四卷（雅沃勒努斯节编）

我认为，即使役权对某人准备出售的土地并无用处，仍可以为该土地设立役权。例如，即使让某人引水并不合算，仍可设立该项役权；因为我们可能享有某些应由他人提供的权利，尽管这些权利对我们并无用处。

### <a id="8.1.20"></a>8.1.20

雅沃勒努斯《拉贝奥〈后论〉》第五卷

每当购买道路权或土地上的其他权利时，拉贝奥认为，应要求对方保证不会由其造成妨碍，使买受人无法行使该项权利，因为这类权利不存在不伴随实际行使的空洞交付。我认为，该项权利的实际使用应视为占有的交付；因此，也设有类似占有保护令的禁令救济。
