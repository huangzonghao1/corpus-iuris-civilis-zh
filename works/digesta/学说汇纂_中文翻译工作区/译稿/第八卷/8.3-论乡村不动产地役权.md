# 第八卷

<a id="8.3"></a>

## 8.3.0　论乡村不动产地役权（*De servitutibus praediorum rusticorum*）

### <a id="8.3.1"></a>8.3.1　乌尔比安《法学阶梯》第二卷

<a id="8.3.1.pr."></a>

**序言（pr.）** 乡村不动产地役权包括：步行通行权（*iter*）、驱赶牲畜通行权（*actus*）、道路通行权（*via*）和引水权（*aquae ductus*）。步行通行权，是人步行通行的权利，但不包括驱赶役畜的权利。驱赶牲畜通行权，是驱赶牲畜或车辆的权利；因此，享有步行通行权者并不享有驱赶牲畜通行权，享有驱赶牲畜通行权者则也享有步行通行权，即使没有牲畜也可以步行通过。道路通行权，是步行、驱赶牲畜及步行通行的权利；因为它包含步行通行权和驱赶牲畜通行权。引水权，是经他人土地引水的权利。〔原文疑误：底本作“*aquam dicendi*”；依上下文译为引水。〕

<a id="8.3.1.1"></a>

**1.** 乡村不动产地役权还包括汲水权、驱赶牲畜至水边饮水权、牧放权、烧制石灰权和采砂权。

<a id="8.3.1.2"></a>

**2.** 当然，通过交付并容忍地役权的行使，会产生裁判官的保护义务。

### <a id="8.3.2"></a>8.3.2　涅拉提乌斯《规则》第四卷

<a id="8.3.2.pr."></a>

**序言（pr.）** 乡村不动产地役权包括：允许增高建筑物并妨碍邻人的庄园房舍（*praetorium*）；允许使下水道穿过邻人的住宅或庄园房舍；以及允许建筑物伸出邻人土地上方。

<a id="8.3.2.1"></a>

**1.** 可以将经同一地点引水或汲水的权利授予数人；也可以规定各人在不同日期或时段引水或汲水。

<a id="8.3.2.2"></a>

**2.** 如果引水权或汲水权所涉水量充足，也可以授予数人，使其在相同日期或时段经同一地点引水或汲水。

### <a id="8.3.3"></a>8.3.3　乌尔比安《评告示》第十七卷

<a id="8.3.3.pr."></a>

**序言（pr.）** 同样，可以设定这样的地役权：允许用于耕作土地的牛在邻近土地上放牧。涅拉提乌斯在《札记》第二卷中写道，可以设定此种地役权。

<a id="8.3.3.1"></a>

**1.** 涅拉提乌斯还在同一卷中写道，可以设定这样的地役权：允许将收获物聚集并存放在邻人的庄园内，以及从邻人的土地上取得葡萄藤支柱。

<a id="8.3.3.2"></a>

**2.** 他在同一卷中说，如果邻人的采石场延伸至你的土地上方，你可以让与邻人以下权利：将土、碎石和石块抛置并存放在你的土地上；还可以让石块滚落到你的土地上、在那里存放，并从那里运走。

<a id="8.3.3.3"></a>

**3.** 享有汲水权的人，似乎也享有前往汲水地点的通行权。正如涅拉提乌斯在《札记》第三卷中所说，无论是同时让与汲水权与前往取水地点的权利，还是仅让与汲水权，前一种情形下权利人均享有两项权利；后一种情形下，通行权也包含在内。反过来，如果仅让与前往泉水处的通行权，汲水权也包含在内。这些规则适用于从私人泉源汲水。至于公有河流，涅拉提乌斯在同一卷中写道，应当让与通行权，而无须让与汲水权；如果某人仅让与汲水权，其让与不发生效力。

### <a id="8.3.4"></a>8.3.4　帕比尼安《答复集》第二卷

**正文** 如果土地的收益主要来自牲畜，那么为牲畜设定的牧放地役权以及驱赶牲畜至水边饮水的地役权，似乎更是附属于土地，而非归属于个人。但如果遗嘱人指明了他希望享有地役权的人，则不会为买受人或继承人提供同样的地役权。

### <a id="8.3.5"></a>8.3.5　乌尔比安《评告示》第十七卷

<a id="8.3.5.pr."></a>

**序言（pr.）** 因此，依其意见，也可以提起确认地役权之诉。

<a id="8.3.5.1"></a>

**1.** 涅拉提乌斯在《评普劳提乌斯》中说，汲水权、驱赶牲畜至水边饮水权、采白垩权和烧制石灰权，均不得设定在他人土地上，除非权利人拥有一处邻近土地。他还说，普罗库鲁斯和阿蒂利基努斯持此见解。但涅拉提乌斯本人认为，即使可以设定烧制石灰权和采白垩权地役权，其行使范围也不得超过该权利人自己的土地所需：

### <a id="8.3.6"></a>8.3.6　保罗《评普劳提乌斯》第十五卷

<a id="8.3.6.pr."></a>

**序言（pr.）** 例如，权利人拥有制陶作坊，用以制造运出该土地收获物所需的器皿（有些地方确有此种情形，例如制造运送葡萄酒的双耳瓶或储酒缸），或者制造瓦片、建造庄园所需的器具。但如果经营制陶作坊是为了出售器皿，所成立的便是用益权。

<a id="8.3.6.1"></a>

**1.** 此外，烧制石灰、采石以及为建造该土地上的建筑物而挖砂的权利，还有砍伐矮林以便为葡萄藤提供支柱的权利，与用益权相去甚远。那么，如果这些行为改善了不动产的状况，又当如何？毫无疑问，这属于地役权；麦基安也赞同此说。他甚至认为，可以设定这样的地役权：允许我在你的土地上建一间小屋；当然，前提是我享有牧放权或驱赶牲畜至水边饮水权，以便冬季来临时有地方躲避。

### <a id="8.3.7"></a>8.3.7　保罗《评告示》第二十一卷

<a id="8.3.7.pr."></a>

**序言（pr.）** 乘坐椅轿或卧轿的人，称为“步行通行”，而不是“驱赶通行”；仅享有步行通行权的人，不得牵引役畜。享有驱赶牲畜通行权的人，则可以驾车并驱赶牲畜。但是，步行通行权和驱赶牲畜通行权均不包括拖运石块或梁木的权利。有些人认为，即使竖直携带长矛也不被允许，因为这既非为步行或驱赶牲畜之目的，且可能因此损害收获物。享有道路通行权的人享有步行和驱赶牲畜的权利；多数人还认为，只要不损害收获物，也包括拖运物品及竖直携带长矛的权利。

<a id="8.3.7.1"></a>

**1.** 但在乡村不动产上，如果中间隔有一处不负担地役权的土地，地役权便不能通行。

### <a id="8.3.8"></a>8.3.8　盖尤斯《评行省告示》第七卷

**正文** 依《十二表法》，道路宽度在直行路段为八罗马尺，在弯曲处——即道路转弯之处——为十六罗马尺。

### <a id="8.3.9"></a>8.3.9　保罗《意见集》第一卷

**正文** 引水权或汲水权，除泉源或水源处外，不得设定；不过，如今通常可以从任何地点设定此种权利。

### <a id="8.3.10"></a>8.3.10　保罗《评告示》第四十九卷

**正文** 拉贝奥说，可以设定这样的地役权：允许寻找水源，并在找到之后引水。因为，既然可以在建筑物尚未建成时设定地役权，为何不能在尚未发现水源时设定同一地役权呢？而且，既然我们可以让与寻找水源的权利，也可以让与找到水源后引水的权利。

### <a id="8.3.11"></a>8.3.11　凯尔苏斯《学说汇纂》第二十七卷

**正文** 可以单独向我让与经由多人共有土地步行和驱赶牲畜通行的权利。因此，依严格法理，只有所有共有人均作出让与，该权利才归我所有；而且须待最后一项让与作出，先前各项让与才一并获得确认。不过，较为宽厚的解释是：即使最后一位共有人尚未让与，先前已作出让与的人也不得禁止我依已让与的权利通行。

### <a id="8.3.12"></a>8.3.12　莫德斯蒂努斯《法律区别》第九卷

**正文** 驱赶牲畜通行权与步行通行权有所区别：步行通行权允许人步行或骑马通过；驱赶牲畜通行权则还允许驱赶牛群并牵引车辆。

### <a id="8.3.13"></a>8.3.13　雅沃勒努斯《评卡西乌斯》第十卷

<a id="8.3.13.pr."></a>

**序言（pr.）** 可以为特定类别的土地取得地役权，例如为葡萄园取得地役权；因为该权利更多地附属于土地，而非地上物。因此，即使葡萄藤被移除，地役权仍然存续；但是，如果设定地役权时当事人另有约定，则有必要提出恶意抗辩。

<a id="8.3.13.1"></a>

**1.** 如果整片土地均负有步行通行权或驱赶牲畜通行权，土地所有人不得在该土地上实施任何妨碍地役权的行为；此时地役权的范围如此广泛，以致每一块土地均负有义务。遗赠步行通行权或驱赶牲畜通行权而未作任何具体界定的，也应如此处理。但如果权利范围已经确定，则地役权仅在首先确定的通道上成立，土地的其他部分均为自由。因而，在上述两种情形下，均应指定仲裁人，由其确定道路的位置。

<a id="8.3.13.2"></a>

**2.** 驱赶牲畜通行权和步行通行权的宽度，依前述内容确定；如果没有约定，则由仲裁人确定。道路通行权适用不同规则：如果没有约定宽度，则应当提供法定宽度。

<a id="8.3.13.3"></a>

**3.** 如果指明了地点但未约定宽度，权利人可以在该地点内任意通行。如果既未指明地点，也未约定宽度，则可以在整片土地上选择一条道路，但其宽度仅得为法律规定的宽度。对此如有疑问，应请求仲裁人处理。

### <a id="8.3.14"></a>8.3.14　庞波尼乌斯《评昆图斯·穆基乌斯》第三十二卷

**正文** 我已经向一人让与经由某一地点通行的权利，便不能再向另一人让与经由同一地点引水的权利；同样，如果我已经向一人授予引水权，也不能再向另一人出售或以其他方式让与经由同一地点的步行通行权。

### <a id="8.3.15"></a>8.3.15　庞波尼乌斯《评昆图斯·穆基乌斯》第三十一卷

**正文** 昆图斯·穆基乌斯写道，如果经由他人土地引水，无论是每日引水、夏季引水，还是间隔较长时间引水，权利人均可以在水流中放置自己的管道，无论是铅制、陶制或其他材质；只要不使水流对土地所有人更加不利，权利人还可以在水流中从事其所需的作业。

### <a id="8.3.16"></a>8.3.16　卡利斯特拉图斯《审判程序论》第三卷

**正文** 神化的庇护皇帝曾就捕鸟人一事作出如下答复：*ouk estin eulogon akontwn twn despotwn humas en allotriois xwriois iceuein*〔即：未经土地所有人同意，你们在他人土地上捕鸟并无正当理由。〕

### <a id="8.3.17"></a>8.3.17　帕皮里乌斯《敕令集》第一卷

**正文** 安敦宁与维鲁斯皇帝答复称：公有河流中的水，应按照各土地的占有面积分配，用于灌溉土地；除非有人证明自己依特别权利取得了更多的水。皇帝还答复称，只有在不损害他人权益的情况下，才允许引水。

### <a id="8.3.18"></a>8.3.18　乌尔比安《评萨宾》第十四卷

**正文** 即使一条道路地役权经由数处土地设定，它仍是一项地役权。于是有人提出疑问：如果我经由其中一处土地通行，而在另一处土地上，未在足以导致地役权消灭的期间内通行，我是否仍保有地役权？较妥当的看法是，要么地役权全部消灭，要么全部保留。因此，如果我在任何一处土地上均未行使权利，地役权全部消灭；如果我曾经由其中任一处土地通行，地役权便全部保留。

### <a id="8.3.19"></a>8.3.19　保罗《评萨宾》第六卷

**正文** 如果共有土地的一名共有人为共有土地约定取得步行通行权，该要式口约无效，因为不能仅向他一人授予此项权利。但是，如果全体共有人或共有奴隶作出要式口约，各共有人都可以请求将该权利授予自己，因为权利可以分别授予他们。这样也能避免步行通行权的要式口约人留下数名继承人后，导致该要式口约无效。

### <a id="8.3.20"></a>8.3.20　庞波尼乌斯《评萨宾》第三十三卷

<a id="8.3.20.pr."></a>

**序言（pr.）** 如果你在同一时间既授予我经由你的土地步行和驱赶牲畜通行的权利，又授予我使用、收益该土地的权利，之后我又同意你有权禁止我使用、收益该土地，那么你仍不得使用、收益该土地，除非我能够合法地经由该处步行和驱赶牲畜通行。同样，如果我依法可以经由你的土地引水，而未经我同意，你无权在该土地上建造建筑物；之后我同意你有权建造建筑物，你仍须为我保留该地役权，不得以妨碍我的引水为方式建造。关于这一切，其法律状态应当与当初仅作出一项让与时相同。

<a id="8.3.20.1"></a>

**1.** 地役权可能因自然原因而非人为行为损害供役地；例如，雨水使水流上涨，田地的水流入水道，或者后来在水道旁或水道之中发现泉源。

<a id="8.3.20.2"></a>

**2.** 如果泉源与塞亚努斯土地相邻，我依法经由塞亚努斯土地从该泉源引水，那么即使因我的行为使塞亚努斯土地发生变化，该地役权仍然存续。

<a id="8.3.20.3"></a>

**3.** 汲水权附属于不动产，而非个人。

### <a id="8.3.21"></a>8.3.21　保罗《评萨宾》第十五卷

**正文** 如果你授予我经由你的土地引水的权利，却没有指定引水路线，那么你的整片土地均负有地役权：

### <a id="8.3.22"></a>8.3.22　庞波尼乌斯《评萨宾》第三十三卷

**正文** 但是，在作出该项让与时，该土地上没有建筑物、树木或葡萄藤的地方，才仅以此名义负有地役权。

### <a id="8.3.23"></a>8.3.23　保罗《评萨宾》第十五卷

<a id="8.3.23.pr."></a>

**序言（pr.）** 道路通行权的宽度可以大于或小于八罗马尺，但仍须达到车辆能够通行的宽度；否则，所成立的只是步行通行权，而非道路通行权。

<a id="8.3.23.1"></a>

**1.** 如果你的土地上有一处常年湖泊，可以设定航行地役权，以便前往邻近土地。

<a id="8.3.23.2"></a>

**2.** 如果供役地或享有地役权的土地被收归公有，两种情况下地役权均继续存续；因为每处土地都是连同其原有状态一并收归公有的。

<a id="8.3.23.3"></a>

**3.** 任何附属于土地的地役权，均附属于该土地的全部部分。因此，即使土地被分割出售，地役权仍随各部分土地转移，各部分土地的所有人均可依法提起诉讼，主张自己享有通行权。但是，如果享有地役权的土地按不同区域分割给数名所有人，即使地役权附属于该土地的每一部分，不与供役地相邻的土地所有人仍须依法享有经由其他分割部分的通行权；或者，在相邻土地所有人允许的情况下，经由其土地通行。

### <a id="8.3.24"></a>8.3.24　庞波尼乌斯《评萨宾》第三十三卷

**正文** 拉贝奥写道，我可以将自己引水设施中的水借给任何邻人使用。普罗库鲁斯则认为，不得将水用于我自己土地上、不同于取得该地役权所为之部分的其他部分。普罗库鲁斯的见解较为正确。

### <a id="8.3.25"></a>8.3.25　庞波尼乌斯《评萨宾》第三十四卷

**正文** 如果我将自己土地中一处确定部分出售给你，即使引水权通常是为另一部分土地而行使，该引水权也随该部分土地归你享有。对此，不应考虑土地的肥沃程度或水的使用情况；不能仅由最肥沃、或最需要使用该水的那部分土地享有引水权，而应按照各自保留或转让的土地面积分配该水。

### <a id="8.3.26"></a>8.3.26　保罗《评告示》第四十七卷

**正文** 如果遗嘱仅笼统地遗赠经由某一土地的道路通行权、步行通行权、驱赶牲畜通行权或引水权，继承人可以选择在土地的哪一部分设定地役权，但不得因此使受遗赠人遭受损失。

### <a id="8.3.27"></a>8.3.27　尤利安《学说汇纂》第七卷

**正文** 如果塞姆普罗尼亚努斯土地为我与你共有的土地提供地役权，而我与你又共同买下塞姆普罗尼亚努斯土地，地役权便消灭，因为我们开始以相同的权利共同所有两处土地。但是，如果该地役权分别由我单独所有的土地和你单独所有的土地享有，地役权仍然存续，因为共有土地可以为个人单独所有的土地提供地役权。

### <a id="8.3.28"></a>8.3.28　尤利安《学说汇纂》第三十四卷

**正文** 如果遗赠了通往两人共有土地的道路，而双方未就道路位置达成一致，地役权既不取得，也不消灭。

### <a id="8.3.29"></a>8.3.29　保罗《阿尔芬〈学说汇纂〉摘要》第二卷

**正文** 某人曾拥有两处相邻土地，后来出售了较高处的土地。买卖契约规定，买受人可以打开水沟，将水引至较低处的土地。后来，如果买受人从另一处土地取得水并想将水引至较低处的土地，有人询问他是否有权这样做。我答复：较低处土地的邻人只须接纳买受人为排干其所购土地而引出的水。

### <a id="8.3.30"></a>8.3.30　保罗《阿尔芬〈学说汇纂〉摘要》第四卷

**正文** 某人拥有两处土地，在出售其中一处时，保留了土地中泉水以及泉水周围宽十尺的区域。有人询问，他保留的是该区域的所有权，还是经由该区域通行的权利。答复是：如果他作出的保留仅为“泉水周围宽十尺”，则看来出卖人仅保留了通行权。

### <a id="8.3.31"></a>8.3.31　尤利安《评米尼基乌斯》第二卷

**正文** 有三处彼此相连的土地，分别属于三名所有人。最低处土地的所有人曾取得一项引水地役权，可以从最高处土地引水至最低处土地，并经中间土地引水；中间土地的所有人对此表示同意。此后，同一人买下最高处土地，又出售了水流入其中的最低处土地。有人询问，最低处土地是否因而丧失引水权；因为两处土地成为同一人所有后，土地不能为自己提供地役权。尤利安否认最低处土地已丧失该地役权，因为输水经过的中间土地属于他人。正如要使水流至最低处土地，不能仅在最高处土地设定地役权而不同时经由中间土地引水；同样，除非在同一时间停止经由中间土地引水，或者三处土地同时归同一人所有，该地役权也不能消灭。〔原文疑误：底本在“*non potuissententiarum*”及末尾“*essententiarum*”处有词串讹连；此处依上下文译出，未将校改并入原文。〕

### <a id="8.3.32"></a>8.3.32　阿非利卡努斯《疑问集》第六卷

**正文** 一处土地由我与你共有。你将自己的份额交付给我，并通过你单独所有的邻近土地，为前往该共有土地设定道路。阿非利卡努斯说，以这种方式设定地役权是有效的；通常所谓地役权不能按份取得或设定的规则，在此情形并不适用。因为这里取得的不是按份地役权，取得该权利的时间应是该土地将成为我单独所有之时。

### <a id="8.3.33"></a>8.3.33　阿非利卡努斯《疑问集》第九卷

<a id="8.3.33.pr."></a>

**序言（pr.）** 我与你共有两处土地，名为提提亚努斯和塞亚努斯。分割共有财产时，我们约定提提亚努斯归我、塞亚努斯归你；我们相互交付各自的份额，并在交付时约定，双方可以经由对方土地引水。阿非利卡努斯说，地役权由此有效设定；尤其是在该协议之后又订立要式口约的情况下。

<a id="8.3.33.1"></a>

**1.** 如果已经以任何方式设定地役权，允许经由数人的土地引水，那么除非随后另有协议或要式口约对此作出约定，你既不能将从水沟汲水的权利授予其中任何一人，也不能授予其他邻人。通常只有在订立协议或要式口约的情况下，才可以作此授予；尽管任何土地都不能为其自身提供地役权，地役权的收益本身也不能成为另行设定的对象。

### <a id="8.3.34"></a>8.3.34　帕比尼安《疑问集》第七卷

<a id="8.3.34.pr."></a>

**序言（pr.）** 共有土地的一名共有人，单凭允许他人步行或驱赶牲畜通行，并不能有效设定该项权利。因此，如果彼此提供地役权的两处土地后来由同一组共有人共有，既然地役权可以按份保留，一方就不能免除另一方所享有的地役权。虽然每名共有人都是地役权的唯一权利人，但由于负担地役权的是土地而非个人，既不能按份取得土地免除地役权的自由，也不能按份免除地役权。

### <a id="8.3.36"></a>8.3.36　保罗《答复集》第二卷

**正文** 出卖人从两处土地中保留一处，并在该土地上设定引水地役权；买受土地的一方取得该地役权。该土地再次被出售时，已经取得的地役权随土地转移。至于约定罚金的要式口约是针对买受人个人作出的——即如果买受人无法享有该权利时适用——与此无关。

### <a id="8.3.38"></a>8.3.38　保罗《手册》第一卷

**正文** 如果有河流横亘其间，而河流可以涉水通过或架有桥梁，则可以设定道路通行权；如果靠渡船运送过河，则应作不同处理。以上规则以河流流经一人的土地为前提。否则，如果你的土地与我的土地相邻，其后是河流，再后是提提乌斯的土地，继而是我希望取得通行权的公用道路，我们应当考察：是否没有任何障碍妨碍你向我授予直至河流的道路通行权，再由提提乌斯授予直至公用道路的通行权？但如果隔河而与公用道路相接的那些土地也归你所有，我们还须考察法律是否相同。因为道路通常终止于城市、通往公用道路、通往可以乘渡船横渡的河流，或者通往同一所有人的另一处土地。如果确实如此，尽管同一所有人的土地之间隔有一条公有河流，地役权似乎并未因此中断。〔原文疑误：底本作“*interrrumpi*”，疑为“*interrumpi*”之讹。〕
