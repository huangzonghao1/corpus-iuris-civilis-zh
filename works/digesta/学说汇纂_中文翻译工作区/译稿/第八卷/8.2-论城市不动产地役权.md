## 8.2.0　论城市不动产地役权（*De servitutibus praediorum urbanorum*）

### <a id="8.2.1"></a>8.2.1　保罗《评告示》第二十一卷

<a id="8.2.1.pr."></a>

**序言（pr.）** 如果其间隔有公有土地或公用道路，并不妨碍设定步行通行权、赶牲畜通行权或增高建筑物的地役权；但这会妨碍设定将梁木嵌入邻人墙内、伸出建筑物、禁止建造，以及排水和屋檐滴水等地役权。因为位于该土地上方的天空必须保持自由。

<a id="8.2.1.1"></a>

**1.** 如果用益权属于你，而房屋所有权属于我，就邻人应当承受的负担而言，可以对我提起针对全部标的的诉讼，绝不能对你提起。

### <a id="8.2.2"></a>8.2.2　盖尤斯《评行省告示》第七卷

城市不动产地役权包括：允许增高建筑物，或禁止增高以免妨碍邻人的采光；允许将屋檐水引向邻人的屋顶或院落，或禁止引水；允许将梁木嵌入邻人的墙内；以及允许伸出阳台、屋檐等类似物。

### <a id="8.2.3"></a>8.2.3　乌尔比安《评萨宾》第十九卷

还有一种地役权，是不得妨碍眺望。

### <a id="8.2.4"></a>8.2.4　保罗《法学阶梯》第二卷

设定采光地役权，意味着取得邻人应当让我们的房屋采光这一权利；设定不得妨碍采光的地役权，则主要意味着取得如下权利：未经我们同意，邻人不得再行增高建筑物，以致减少我们房屋的采光。

### <a id="8.2.5"></a>8.2.5　乌尔比安《评告示》第十七卷

在地役权语境中，“违背意愿”应理解为未表示同意之人，而不是口头表示反对之人。因此，庞波尼乌斯在《评昆图斯·穆基乌斯》第四十卷中正确地说，幼儿和精神失常者也可以被称为“违背意愿”；因为这些词所指的是权利状态，而不是事实行为。

### <a id="8.2.6"></a>8.2.6　盖尤斯《评行省告示》第七卷

与乡村不动产地役权相同，这些权利也会因在一定期间内不行使而消灭。区别在于，它们并非只因不行使便一概消灭；还须邻人同时因时效取得免除地役权的自由。例如，你的房屋负有不得增高、不得妨碍我房屋采光的地役权；如果我在法定期间内封住或遮挡自家窗户，那么只有在你也于此期间内将自家房屋增高时，我才会丧失该权利；否则，如果你没有作出任何新的改变，我仍保有该地役权。同样，如果你的房屋负有容许嵌入梁木的地役权，而我将梁木取出，那么只有在你封堵梁木原先嵌入的洞口、并在法定期间内一直保持封堵时，我才会丧失该权利；否则，如果你没有作出任何新的改变，我的地役权仍完整存在。

### <a id="8.2.7"></a>8.2.7　庞波尼乌斯《评昆图斯·穆基乌斯》第二十六卷

据说，我可以通过在自己的建筑物上实施某种行为而取得免除地役权的自由；穆基乌斯说，如果我在同一地点种有一棵树，就不能取得这种自由。此说正确，因为树不像墙那样能以稳定的位置和状态保持不变，这是由于树会自然移动。

### <a id="8.2.8"></a>8.2.8　盖尤斯《评行省告示》第七卷

依自然关系属于邻人共有的墙，任何一方均无权拆除并重建；因为任何一方都不是该墙的唯一所有人。

### <a id="8.2.9"></a>8.2.9　乌尔比安《评告示》第五十三卷

如果某人增高建筑物，遮挡了邻人原本并不享有地役权的房屋采光，邻人对他不享有任何诉权。

### <a id="8.2.10"></a>8.2.10　马尔凯卢斯《学说汇纂》第四卷

高鲁斯致马尔凯卢斯：我有两处房屋，其中一处遗赠给你；继承人把另一处房屋增高，妨碍你的采光。你可以对他采取什么行动？你认为，继承人增高的是自己的房屋，还是遗产中的房屋，是否会影响判断？我还想问，继承人是否应当通过他人的房屋提供通往遗赠物的通道；正如遗赠某处土地的用益权，而该土地只能经过他人土地到达时，通常会提出的那个问题。马尔凯卢斯答复：某人拥有两处房屋而遗赠其中一处，毫无疑问，继承人可以增高另一处房屋，遮挡遗赠房屋的采光；如果一人受遗赠房屋所有权，另一人受遗赠另一处房屋的用益权，也应作相同处理。但通行权的情形并不总是相同，因为没有通道便无法享有用益权；即使采光被遮挡，仍然可以居住。至于遗赠某处土地的用益权，则必须同时提供通道；正如遗赠取水权时，也应提供前往取水地点的通路。不过，允许遮挡采光、使遗赠房屋变暗，并不意味着可以完全封住光线；仍须保留足以供居住者日常适度使用的光线。

### <a id="8.2.11"></a>8.2.11　乌尔比安《论执政官职务》第一卷

<a id="8.2.11.pr."></a>

**序言（pr.）** 凡欲妨碍邻人采光，或以其他方式损害其利益之人，应当知道，自己必须维持既有建筑物的形制和状态。

<a id="8.2.11.1"></a>

**1.** 如果你与邻人未能就拟建建筑物可以增高至何种程度达成一致，你可以请求指定仲裁人。

### <a id="8.2.12"></a>8.2.12　雅沃伦《卡西乌斯著作》第十卷

负有不得增高地役权的建筑物，可以在其限高之上种植树木；但如果地役权涉及眺望，且树木将妨碍眺望，则不得种植。

### <a id="8.2.13"></a>8.2.13　普罗库鲁斯《书信集》第二卷

<a id="8.2.13.pr."></a>

**序言（pr.）** 有个名叫希贝鲁斯的人，在我的粮仓后面拥有一幢公寓楼；他沿着共有墙建造了浴室。然而，不得将烟道管贴靠共有墙设置；正如不得以共有墙作支撑而建造自己的墙一样。对烟道管还应特别指出：火焰会经由烟道管灼烧墙体。因此，我希望你与希贝鲁斯交涉，劝其不要实施违法行为。普罗库鲁斯答复：我认为，希贝鲁斯对于自己沿共有墙设置烟道管、从而实施不被许可之事，并无疑问。

<a id="8.2.13.1"></a>

**1.** 依卡皮托的意见，可以在共有墙上抹灰；同样，我也可以在共有墙上绘制极其贵重的图画。不过，如果邻人拆毁该墙，双方依约定损害担保之诉处理时，估价不得超过普通灰泥的价值；抹灰层也应遵循同一规则。

### <a id="8.2.14"></a>8.2.14　帕皮里乌斯《敕令汇编》第一卷

安敦宁和塞维鲁皇帝答复称：对于不负有任何地役权的院落，所有人或经其同意的他人，可以在与邻近公寓楼之间留出法定间距后建造房屋。

### <a id="8.2.15"></a>8.2.15　乌尔比安《评萨宾》第二十九卷

不得妨碍采光的地役权与不得妨碍眺望的地役权，适用不同标准。就眺望而言，权利人享有更大的保护：不得妨碍其获得更宜人、开阔的眺望。就采光而言，要求只是不得使任何人的房屋采光变得更加昏暗。因此，只要他人负有地役权，任何妨碍采光的行为均可被禁止；如果该行为确实损害采光，还可以提出新工程异议。

### <a id="8.2.16"></a>8.2.16　保罗《阿尔芬〈学说汇纂〉摘要》第二卷

所谓采光，就是能够看见天空；采光与眺望有所不同：眺望也可以来自较低处，而采光不能来自较低处。

### <a id="8.2.17"></a>8.2.17　乌尔比安《评萨宾》第二十九卷

<a id="8.2.17.pr."></a>

**序言（pr.）** 如果某人种树是为了妨碍采光，也应当认定其行为违反所设地役权；因为树木同样会使天空变得不可见。不过，如果所种之物并不妨碍采光，而只是遮挡阳光，那么若该处本来就不适宜受阳光照射，可以认为其行为不违反地役权；但如果该处是日光浴室或露台，阳光为其所必需，则应当认定其树木造成阴影，违反了所设地役权。

<a id="8.2.17.1"></a>

**1.** 反过来说，如果某人拆除建筑物，或修剪树枝，使原先阴暗的地方开始充满阳光，并不构成违反地役权。因为其负担的是不得妨碍采光的义务；如今他没有妨碍采光，反而使光线超过通常程度。

<a id="8.2.17.2"></a>

**2.** 有时也可以说，拆除或降低建筑物之人妨碍了采光；例如，因光线反射〔希腊文 *κατὰ ἀντανάκλασιν*，即“经反射”〕或某种压迫作用，使光线反而射入这些房屋。

<a id="8.2.17.3"></a>

**3.** 地役权文书中的这项约定——“屋檐滴水应保持现状”——意味着将来相邻房屋负有承接滴水的义务；它并不意味着买受人也必须承接邻近建筑物的屋檐滴水。因此，出卖人保证的是自己的房屋负有承接滴水的地役权，而不负有使邻人承接其滴水的义务。

<a id="8.2.17.4"></a>

**4.** 关于屋檐滴水的上述规定，也适用于其他地役权；除非当事人另有明确的相反约定。

### <a id="8.2.18"></a>8.2.18　庞波尼乌斯《评萨宾》第十卷

如果用于引水的管道贴靠我的房屋设置并给我造成损害，我可以提起事实诉讼；我也可以要求你订立关于可能发生损害的要式口约。

### <a id="8.2.19"></a>8.2.19　保罗《评萨宾》第六卷

<a id="8.2.19.pr."></a>

**序言（pr.）** 普罗库鲁斯认为，贴靠共有墙设置、从水塔或天空取水的管道，不具有合法依据；但不得禁止邻人在共有墙旁设置浴室，即使墙体会受潮。这就像不得禁止其在自己的餐室或卧室洒水一样。不过，涅拉提乌斯认为，如果暖浴室的使用会使墙体持续受潮并损害邻人，就可以禁止这种使用。

<a id="8.2.19.1"></a>

**1.** 如果在共有墙旁以陶土构件建造拱顶，并使其即使拆掉该墙也能保持稳固，只要它不妨碍共有墙的修缮，便可合法保留。

<a id="8.2.19.2"></a>

**2.** 萨宾正确地写道，我可以在共有墙旁设置楼梯，因为楼梯可以移除。

### <a id="8.2.20"></a>8.2.20　保罗《评萨宾》第十五卷

<a id="8.2.20.pr."></a>

**序言（pr.）** 以建筑物表面为内容的地役权，通过占有而维持。例如，如果我将梁木从自己的房屋嵌入你的房屋，我便基于梁木这一事由，持续占有将其嵌入的状态。同样，如果我将阳台伸入你的房屋，或将屋檐水引向你的房屋，也是如此；因为我在使用你的财产，且由此形成了某种事实上的准占有。

<a id="8.2.20.1"></a>

**1.** 如果我的房屋高于你的院落，而你允许我经由你的院落出入我的房屋，且我不能从平地经你的院落进入房屋，那么我可以依法在靠近我家门口处修建台阶或斜坡，但拆除部分不得超过通行所必需的范围。

<a id="8.2.20.2"></a>

**2.** 如果原先有建筑物承接屋檐滴水，而该建筑物被拆除，为使之以相同形式和质量重建，衡平要求仍将其视为原有状态；否则，若作过于严格的解释，就会与下文所述规则不同：建筑物拆除后，用益权即告消灭，尽管院落是建筑物的一部分。

<a id="8.2.20.3"></a>

**3.** 如果设定了屋檐滴水地役权，供役院落的所有人不得在滴水开始落下之处建造建筑物。

<a id="8.2.20.4"></a>

**4.** 如果先前屋檐滴水是从瓦片流下，后来便不得改为从木板或其他材料处流下。

<a id="8.2.20.5"></a>

**5.** 无论以何种方式取得屋檐滴水地役权，均可将滴水口抬高；这样会减轻地役权负担，因为水从高处落下会更轻，有时还会被风吹散，根本落不到供役处。不得将滴水口降低，因为这样会加重地役权负担，也就是将滴水变成水流。可以将滴水向后引，因为这样一来，水会更多地落在我们自己的土地上；但不得向前延伸，以免滴水落在设定地役权时未指定的地点。我们可以使负担变轻，不得使之变重。总之，应当知道：可以改善邻人的处境，不得使之恶化，除非设定地役权时明确作了变更。

<a id="8.2.20.6"></a>

**6.** 在承接屋檐滴水的院落上建造房屋之人，可以将建筑物建至滴水落下之处；如果滴水落在建筑物上，也允许其在上方继续建造，但仍须使滴水得到妥善承接。

### <a id="8.2.21"></a>8.2.21　庞波尼乌斯《评萨宾》第三十三卷

如果你的房屋对我的建筑物负有两项地役权——不得增高，以及应承接我方建筑物的屋檐滴水——而我又允许你不受不得增高约定的限制、增高你的建筑物，那么就屋檐滴水而言，应作如下处理：如果你的建筑物增高后，我的滴水不能落在其上，你便不得据此增高；如果我的滴水并未因此受阻，你就可以增高。

### <a id="8.2.22"></a>8.2.22　尤利安《米尼基乌斯释义》第二卷

拥有建筑物的人可以对邻人设定地役权，要求其保证不仅不得妨碍现有窗户的采光，也不得妨碍日后设置的窗户采光。

### <a id="8.2.23"></a>8.2.23　庞波尼乌斯《评萨宾》第三十三卷

<a id="8.2.23.pr."></a>

**序言（pr.）** 如果约定设定的地役权是“现有采光应保持现状”，那么对未来设置的窗户似乎没有作出规定。如果约定的是“不得妨碍采光”，文义便有歧义：它是指不得妨碍现有窗户采光，还是也包括此后设置的窗户？较为宽厚的解释是，概括用语“采光”指一切采光，不论是现有的，还是在协议订立后才形成的。

<a id="8.2.23.1"></a>

**1.** 对尚未建成的未来建筑物，也可以设定或取得地役权。

### <a id="8.2.24"></a>8.2.24　保罗《评萨宾》第十五卷

依法享有较高建筑物的一方，有权在自己的建筑物上方无限增建；但不得使下方建筑物承受超过其应承受程度的地役权负担。

### <a id="8.2.25"></a>8.2.25　庞波尼乌斯《评萨宾》第三十三卷

<a id="8.2.25.pr."></a>

**序言（pr.）** 关于将梁木等物伸入他人建筑物的上述规定，适用于从一幢房屋的建筑物伸入另一幢房屋的建筑物；除此之外，任何人都不可能在他人建筑物上方拥有更高的建筑物。

<a id="8.2.25.1"></a>

**1.** 如果三幢房屋建在高低不平的地点，中间的房屋对上方房屋负有地役权，而下方房屋不负有任何地役权，并且下方房屋的所有人在其与中间房屋共有的墙上加高建筑物，萨宾说，他依法可以将该建筑物加高。

### <a id="8.2.26"></a>8.2.26　保罗《评萨宾》第十五卷

在共有物上，任何共有人均无权在另一共有人不同意时，以行使地役权的方式实施任何行为，也无权阻止另一共有人实施行为；因为自己的物不可能对自己负有地役权。因此，共有人之间常因争执甚多而诉至共有物分割之诉。通过该诉，共有人可以请求禁止某项工程，或请求拆除已完成的工程，但前提是拆除该工程有利于全体共有人。

### <a id="8.2.27"></a>8.2.27　庞波尼乌斯《评萨宾》第三十三卷

<a id="8.2.27.pr."></a>

**序言（pr.）** 如果你和我共有提提亚房屋，而有人将某物从这些共有房屋违法伸入我个人所有的其他房屋，我当然可以对你提起诉讼，或者拆除该物。反过来，如果某物从你个人所有的房屋伸出，违法进入我与你共有的房屋，也作相同处理；因为只有我可以对你提起诉讼。

<a id="8.2.27.1"></a>

**1.** 如果你想在共有院落上建造房屋，共有人有权禁止；即使邻人已经准许你建造，也不例外，因为你未经共有人同意，无权在共有物上建造。

### <a id="8.2.28"></a>8.2.28　保罗《评萨宾》第十五卷

如果在餐室或起居室的墙脚开孔是为了冲洗地面，通说认为，这既不构成水流地役权，也不能因时间经过而取得。只有在没有雨水从天空流入该处时，此说才正确；因为以人工方式形成的情形并非持续存在。反之，从天空落下的雨水，即使并非连续发生，也源于自然原因，因此视为持续发生。所有不动产地役权都必须具有持续存在的原因；因此，不得基于湖泊或池塘设定引水地役权。设定屋檐滴水地役权，也必须有自然且持续的原因。

### <a id="8.2.29"></a>8.2.29　庞波尼乌斯《评昆图斯·穆基乌斯》第三十二卷

因此，如果邻人因那个不能构成地役权的孔洞而遭受损害，应当认为，可以适用关于可能发生损害的要式口约。

### <a id="8.2.30"></a>8.2.30　保罗《评萨宾》第十五卷

<a id="8.2.30.pr."></a>

**序言（pr.）** 如果某人买下了负有地役权的房屋，并在交付时受领该房屋，地役权便因权利归于一人而消灭；如果他后来想要出售该房屋，就必须明确设定地役权；否则，房屋将以不负地役权的状态出售。

<a id="8.2.30.1"></a>

**1.** 如果我取得了某一不动产的一部分，而该不动产曾负有地役权，或我自己的不动产曾为其供役，通说认为，地役权不会因权利归于一人而消灭，因为地役权仍按份额存续。因此，如果我的不动产对你的不动产负有地役权，而你将自己不动产的一部分交付给我、我也将自己不动产的一部分交付给你，地役权仍将存续。在任一不动产上取得用益权，也不会中断地役权。

### <a id="8.2.31"></a>8.2.31　保罗《评告示》第四十八卷

如果遗嘱指定的继承人负有不得妨碍邻人采光并须维持地役权的义务，却拆除了建筑物，则应当准许受遗赠人提起准用之诉，以禁止继承人日后试图将建筑物增高至原有高度以上。

### <a id="8.2.32"></a>8.2.32　尤利安《学说汇纂》第七卷

<a id="8.2.32.pr."></a>

**序言（pr.）** 如果我的房屋对卢基乌斯·提提乌斯和普布利乌斯·梅维乌斯的房屋均负有不得增高的地役权，而我请求提提乌斯容许我增高建筑物，并在法定期间内一直保持增高后的状态，那么我便可以因时效取得对梅维乌斯的免役自由；因为我所负的不是对提提乌斯和梅维乌斯的一项地役权，而是两项地役权。其证明是：如果其中一人免除我所负的地役权，我只对该人免责，对另一人仍负有地役权。

<a id="8.2.32.1"></a>

**1.** 如果占有建筑物，可以因时效取得免除地役权的自由。因此，如果曾将建筑物增高之人在法定期间届满前停止占有该房屋，取得时效便中断。此后开始占有同一房屋之人，必须重新经过完整的法定期间，才能因时效取得免役自由。地役权的性质决定了它本身不能被占有；占有房屋的人才被视为占有该房屋所涉及的地役权。

### <a id="8.2.33"></a>8.2.33　保罗《阿尔芬〈学说汇纂〉摘要》第五卷

应由负担役权房屋的所有人修复承托邻近房屋重量的柱子，而不是由希望将负担加在该柱子上的人修复。因为建筑法令规定：“承托重量的墙应保持现状。”这句话显然是说，墙必须永远能够承托重量；并非说必须让同一面墙永远存在——这根本不可能做到——而是说，必须永远有同等性质的墙来承托重量。正如有人向他人承诺提供能够承受其负担的地役权，如果供役物灭失，就应当以其他物替代。

### <a id="8.2.34"></a>8.2.34　尤利安《米尼基乌斯释义》第二卷

拥有两处院落的人，可以通过交付其中一处，使该处成为另一处的供役地。

### <a id="8.2.35"></a>8.2.35　马尔基安《法学规则》第三卷

如果两处房屋的所有人曾表示，其出售的房屋将负有地役权，却在交付时未提及该地役权，他可以提起买卖之诉，或提起不确定给付之诉，请求设定该地役权。

### <a id="8.2.36"></a>8.2.36　帕比尼安《疑问集》第七卷

某人拥有两处共用一层屋顶的房屋，并将两处房屋分别遗赠给不同的人。我曾答复：较妥当的意见是，梁木可以由两人共有，但每人应享有屋顶结构中确定的部分；梁木应归属于各自房屋所有人所对应的部分，双方不得相互请求设定梁木嵌入地役权。两处房屋均为无条件遗赠，还是其中一处附条件遗赠，并不影响结论。

### <a id="8.2.37"></a>8.2.37　尤利安《学说汇纂》第七卷

如果两处房屋分别遗赠给两人，也应作相同处理。

### <a id="8.2.38"></a>8.2.38　保罗《疑问集》第二卷

如果我的房屋与你的房屋相距甚远，以致彼此不可见，或者中间有山丘遮挡视线，就不能设定地役权。

### <a id="8.2.39"></a>8.2.39　保罗《手册》第一卷

因为，任何人都不能在自己的建筑物上设定地役权；只有设定人和受益人都能看见相关建筑物，以致一方能够妨碍另一方时，才可以设定。

### <a id="8.2.40"></a>8.2.40　保罗《答复集》第三卷

我曾答复：未曾享有开窗采光权之人，在打开共有墙后开设窗户，并无法律依据。

### <a id="8.2.41"></a>8.2.41　谢沃拉《答复集》第一卷

<a id="8.2.41.pr."></a>

**序言（pr.）** 某人将其住宅及该住宅内的谷仓遗赠给奥林匹库斯，供其终身居住；同一住宅旁另有一座花园和一间楼上房屋，并未遗赠给奥林匹库斯。前往花园和楼上房屋，一直必须经过那座遗赠供其居住的住宅。有人询问，奥林匹库斯是否必须提供通道。我答复：双方之间虽不存在地役权，但继承人可以经过该住宅前往上述地点，只要不损害受遗赠人即可。

<a id="8.2.41.1"></a>

**1.** 卢基乌斯·提提乌斯拆开自家墙壁，在足以承接屋檐滴水并支承梁木突出部分的范围内，朝公共道路开设了一扇门。我询问：由于此举既未妨碍邻人普布利乌斯·梅维乌斯的采光，也未妨碍其通行，且屋檐滴水也未落入邻人的房屋，梅维乌斯是否享有禁止该行为的诉权？我答复：依所述事实，梅维乌斯不享有任何此类诉权。
