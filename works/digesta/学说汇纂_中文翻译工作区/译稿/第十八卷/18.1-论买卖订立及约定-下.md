## 18.1.0　论买卖的订立、买卖双方约定及不得出卖之物（*De contrahenda emptione et de pactis inter emptorem et venditorem compositis et quae res venire non possunt*）——下篇（D.18.1.41–81）

### 18.1.41

*尤利安《致乌尔塞乌斯·费罗克斯》第三卷*

<a id="18.1.41.pr."></a>

**序言（pr.）** 有人向一名将土地抵押给第三人的出卖人请求买入该土地，并要求出卖人在七月一日前解除抵押，双方约定该土地须在解除抵押后才归其买入。问题是，买受人能否提起买卖之诉，要求出卖人解除抵押？答复说，应考察买受人与出卖人之间的实际约定。如果双方约定出卖人无论如何都应在七月一日前解除土地抵押，买受人便可提起买卖之诉要求其解除；此时并不视为买卖附有停止条件。例如，买受人可以这样提出约定：“你在七月一日前解除抵押后，该土地即归我买入”（*erit mihi fundus emptus ita, ut eum intra kalendas Iulias liberes*），或“你在七月一日前从提图斯处赎回该土地后，该土地即归我买入”（*ita ut eum intra kalendas a Titio redimas*）。反之，如果买卖确实附有条件，就不能请求强制条件成就。

<a id="18.1.41.1"></a>

**1.** 你不知情且无意中把一张镀银桌子当作纯银桌卖给了不知情的我；买卖不成立，已经支付的价金可以请求返还。

### <a id="18.1.42"></a>18.1.42

*马尔西安《法学阶梯》第一卷*

主人不得亲自或通过代理人出售犯罪奴隶，让他们与野兽搏斗。神圣的马尔库斯和维鲁斯二皇帝也作出了这样的敕答。

### <a id="18.1.43"></a>18.1.43

*弗洛伦提努斯《法学阶梯》第八卷*

<a id="18.1.43.pr."></a>

**序言（pr.）** 买卖中为推销而作出的陈述，只要其内容显而易见，就不使出卖人承担责任；例如说奴隶相貌出众、房屋建造精良。但若出卖人说某人有学问或精通技艺，就应对此负责，因为他正是据此以较高价格出售。

<a id="18.1.43.1"></a>

**1.** 有些承诺也不使出卖人承担责任，前提是标的物的状况显而易见，买受人不可能不知情。例如，买受人买下一个双目被挖去的人，却又就其健康作出要式约定；应认为他所约定的是身体其他部分的健康，而非他明知有缺陷的部分。

<a id="18.1.43.2"></a>

**2.** 出卖人应保证自己没有欺诈。欺诈不仅包括为使人受骗而故意含糊其辞，也包括以诡计故意隐瞒事实。

### <a id="18.1.44"></a>18.1.44

*马尔西安《规则》第三卷*

如果有人以一个总价同时购买两名奴隶，而其中一人在买卖订立前已经死亡，那么即使对于仍然活着的那名奴隶，买卖也不成立。

### <a id="18.1.45"></a>18.1.45

*马尔西安《规则》第四卷*

拉贝奥在《后书》中写道，如果有人把翻新过的衣服当作新衣买下，特雷巴提乌斯认为，若买受人不知情，出卖人应赔偿其利益损失。庞波尼乌斯赞同这一观点，尤利安也持此说；尤利安认为，出卖人若不知情，应就标的物本身承担责任；若知情，还应赔偿由此造成的损失。正如有人不知情而把黄铜器当作黄金出售，也应按所出售的黄金承担责任。

### <a id="18.1.46"></a>18.1.46

*马尔西安《论告发人》单卷*

任何人均不得利用自己所任职务，亲自或通过他人购买任何物品；否则，不仅丧失该物，还要依塞维鲁和安敦尼二皇帝的敕令被请求支付该物价额的四倍。此规则也适用于皇帝的代理人；但如果某些人获得特别授权，则不在此限。

### <a id="18.1.47"></a>18.1.47

*乌尔比安《萨宾评注》第二十九卷*

如果某块土地享有引水权，该项引水权即使未被明言，也随土地转移给买受人；引水所经的管道也同样如此，

### <a id="18.1.48"></a>18.1.48

*保罗《萨宾评注》第五卷*

即使这些管道位于建筑之外，也一样。

### <a id="18.1.49"></a>18.1.49

*乌尔比安《萨宾评注》第二十九卷*

即使已经丧失的引水权不随土地转移，只要管道和水槽本身仍随土地一并转移，它们也应作为房屋的组成部分归于买受人。庞波尼乌斯在《萨宾评注》第十卷中也持此观点。

### <a id="18.1.50"></a>18.1.50

*乌尔比安《评告示》第十一卷*

拉贝奥写道，如果你把一座图书馆卖给我，约定以坎帕尼亚当地议事会把一处我可安置图书馆的场地卖给我为条件，而未能取得该场地是由于我自己的原因，那么毫无疑问，可以提起以限定词句提出之诉（*actio praescriptis verbis*）。我还认为，可以提起买卖之诉，因为条件未能成就应归因于买受人，故应视为条件已经成就。

### <a id="18.1.51"></a>18.1.51

*保罗《评告示》第二十一卷*

与所售土地相连的海岸不计入土地面积，因为它不属于任何人，而是依万民法向所有人开放；公共道路、宗教之地和神圣之地也不计入。因此，为使相关面积也计入土地的出售范围，通常会特别约定将道路、海岸及公共场所一并计入。

### <a id="18.1.52"></a>18.1.52

*保罗《评告示》第五十四卷*

元老院决议规定，任何人不得为了增加自身收益而拆毁房屋或别墅，也不得以经营交易为目的买卖此类房屋或别墅。对违反该决议之人设定了处罚：买受人须将其购买价金的双倍缴入国库；出卖人的买卖则归于无效。当然，如果你已向我支付价金，而你须向国库缴纳双倍价金，你可以向我请求返还，因为出卖人一方的买卖已被宣告无效。该元老院决议不仅适用于出售自己的别墅或房屋，也适用于出售他人的别墅或房屋。

### <a id="18.1.53"></a>18.1.53

*盖尤斯《告示汇编》第二十八卷*

要使标的物归买受人所有，价金是否已付并不重要；就价金提供保证人即可。关于保证人的规则，应作更广义理解：只要出卖人以任何方式就价金获得满足，例如有人承担债务或提供质押，就如同价金已经支付。

### <a id="18.1.54"></a>18.1.54

*保罗《库鲁尔市政官告示》第一卷*

善意出售的物，不应因微不足道的理由而被视为未曾买卖。

### <a id="18.1.55"></a>18.1.55

*保罗《库鲁尔市政官告示》第二卷*

徒具形式、没有真实内容的买卖，视为从未发生；因此，也不认为该物的所有权已经转移。

### <a id="18.1.56"></a>18.1.56

*保罗《评告示》第五十卷*

如果有人约定出售女奴时不得将她卖作娼妓，并约定违反时可以将她带走，即使该奴隶已经转手经过数名买受人，最初的出卖人仍有权将她带走。

### <a id="18.1.57"></a>18.1.57

*保罗《评普劳提乌斯》第五卷*

<a id="18.1.57.pr."></a>

**序言（pr.）** 我买下一所房屋，但我和出卖人都不知道该房屋已经被火烧毁。涅尔瓦、萨宾努斯和卡西乌斯说，买卖未成立；即使房屋地基尚存，已经支付的价金也可以请求返还。但如果房屋尚有部分留存，内拉提乌斯说，应考察房屋被火烧毁的部分有多少：如果被烧毁的是房屋的大部分，买受人无须完成买卖，也可以请求返还其已经支付的款项；如果被烧毁的部分为一半或少于一半，则应按善良之人的裁量评估价金，迫使买受人完成买卖，同时免除其支付因火灾而应从价金中扣减部分的义务。

<a id="18.1.57.1"></a>

**1.** 但如果出卖人知道房屋已经被烧毁，而买受人不知情，那么如果整所房屋在买卖前均已烧毁，买卖不成立；如果建筑仍有任何部分留存，买卖则有效，出卖人应向买受人返还其利益损失。

<a id="18.1.57.2"></a>

**2.** 反过来，如果买受人知道房屋已经烧毁，而出卖人不知情，也应作相同处理：买卖仍对出卖人有效；如果买受人尚未支付价金，就应向出卖人支付全部价金；如果已经支付，则不得请求返还。

<a id="18.1.57.3"></a>

**3.** 如果买受人和出卖人都知道房屋全部或部分已被烧毁，那么应认为双方并未达成任何交易，因为双方的欺诈相互抵销，而诚信诉讼不容许双方均以欺诈行事。

### <a id="18.1.58"></a>18.1.58

*帕比尼安《疑义集》第十卷*

如果树木被风刮倒或被火烧毁，而买受人是着眼于这些树木（例如橄榄园）才买下土地，那么应认为土地买卖并未成立，无论出卖人是否知情。至于买受人知情或不知情、或者双方均知情或不知情的情形，则适用前述有关房屋的规则。

### <a id="18.1.59"></a>18.1.59

*塞尔苏斯《学说汇纂》第八卷*

你出卖土地时，并未说它是“最佳且最大”（*ita ut optimus maximusque*）；因此，昆图斯·穆基乌斯的观点是正确的：出卖人应按土地的实际状况交付，而无须保证土地没有负担。城市地产也应作相同解释。

### <a id="18.1.60"></a>18.1.60

*马尔凯卢斯《学说汇纂》第六卷*

买卖条款约定买受人可取得六十只大缸；实际共有一百只。答复认为，应由出卖人选择交付其中哪些。

### <a id="18.1.61"></a>18.1.61

*马尔凯卢斯《学说汇纂》第二十卷*

我认为，可以附条件购买自己的物，因为可以期待该物届时不再属于自己。

### <a id="18.1.62"></a>18.1.62

*莫德斯蒂努斯《规则》第五卷*

<a id="18.1.62.pr."></a>

**序言（pr.）** 因职务在某行省任职或服役的人，不得购买该行省的不动产；但如果其父亲的土地由国库出售，则不在此限。

<a id="18.1.62.1"></a>

**1.** 如果有人不知情而把神圣之地、宗教之地或公物当作私有财产买下，尽管买卖不发生效力，他仍可对出卖人提起买卖之诉，请求赔偿其因受骗而遭受的利益损失。

<a id="18.1.62.2"></a>

**2.** 以整体或总批方式购买的物品，即使尚未逐一指定，只要出卖人没有欺诈，其风险也由买受人承担。

### <a id="18.1.63"></a>18.1.63

*雅沃勒努斯《卡西乌斯著作节本》第七卷*

<a id="18.1.63.pr."></a>

**序言（pr.）** 如果主人命令奴隶将某物卖给特定之人，而奴隶却卖给了其他人，买卖无效。自由人的情形也适用相同规则：若主人不愿某人买入该物，便不能在该人名下完成买卖。

<a id="18.1.63.1"></a>

**1.** 已经描述土地后，无须再列明其边界；如果仍列明边界，而出卖人恰好还拥有另一块相邻土地，就应当同时指明出卖人自己的土地。

### <a id="18.1.64"></a>18.1.64

*雅沃勒努斯《书信集》第二卷*

“该土地由我和提图斯买入。”我询问：买卖是按份有效、对全部有效，还是根本未成立？答复说，我认为提图斯只是多余地被提及，因此整个土地的买卖均归我。

### <a id="18.1.65"></a>18.1.65

*雅沃勒努斯《书信集》第十一卷*

我与你约定，你应按确定价金向我交付一定数量的瓦片；这属于买卖还是承揽？答复说，如果约定由我向你交付用我土地上的材料制成的瓦片，我认为这是买卖而非承揽。只有在材料仍保持原有状态时，才属于对某物的承揽；如果材料经过改变并转让，则应视为买卖，而非承揽。

### <a id="18.1.66"></a>18.1.66

*庞波尼乌斯《评昆图斯·穆基乌斯》第三十一卷*

<a id="18.1.66.pr."></a>

**序言（pr.）** 出卖土地时，即使没有明说，有些事项也应由出卖人负责，例如保证土地不被追夺或其用益权不被追夺；另一些事项则只有明示约定时才应负责，例如保证通行权、道路通行权、牲畜驱赶权或引水权。城市地产役权也适用相同规则。

<a id="18.1.66.1"></a>

**1.** 如果出卖的地产享有一项役权，出卖人没有提及，且明知该役权存在却故意隐瞒，买受人因不知情而在法定期间内未行使权利，从而丧失该役权，有些法学家正确地认为，出卖人因欺诈而须承担买卖之诉责任。

<a id="18.1.66.2"></a>

**2.** 昆图斯·穆基乌斯写道，有人在条款中写下“可移走、砍伐之物及其他不属于房屋或土地的物”，这是重复表述；因为所谓可移走、砍伐之物，就是既不属于房屋也不属于土地的物。

### <a id="18.1.67"></a>18.1.67

*庞波尼乌斯《评昆图斯·穆基乌斯》第三十九卷*

所谓让与，是指我们将某物的所有权连同其原有法律关系一并移转给他人；如果该物仍由我们所有，该法律关系本会继续存在。除非法律另有明确规定，整个市民法均适用这一规则。

### <a id="18.1.68"></a>18.1.68

*普罗库鲁斯《书信集》第六卷*

<a id="18.1.68.pr."></a>

**序言（pr.）** 如果你出售土地时约定，买受人可以取得你向承租人收取的租金，那么我认为，你在收取租金时不仅须遵守诚信，还须尽到注意义务；也就是说，你不仅不得欺诈，还不得有过失。

<a id="18.1.68.1"></a>

**1.** 人们通常会加上这样一句：“出卖人不得有欺诈”（*dolus malus a venditore aberit*）；即使未写入合同，出卖人也应当避免欺诈。

<a id="18.1.68.2"></a>

**2.** 如果由于出卖人的行为，买受人不能占有或将不能占有土地，就不能认为出卖人已避免欺诈。因此，可以提起买卖之诉；但该诉并非为了命令出卖人交付空置占有，因为出卖人可能因许多原因而无法交付，而是为了评估其已经实施或正在实施的任何欺诈行为。

### <a id="18.1.69"></a>18.1.69

*普罗库鲁斯《书信集》第十一卷*

鲁蒂利娅·波拉买下萨巴提努斯湖一角及其周围十罗马尺的土地。我询问：湖面后来扩大时，当初一并买入的十尺土地是否也会被湖水淹没，还是说鲁蒂利娅·波拉享有湖岸外侧最近的十尺土地？普罗库鲁斯答复：我认为，鲁蒂利娅·波拉买下的是湖泊当时的范围，以及当时湖岸周围的十尺土地；湖泊后来扩大，并不使她得以占有超出其买入范围的土地。

### <a id="18.1.70"></a>18.1.70

*利基尼《规则》第八卷*

多数法学家认为，如果双方均不知情，自由人也可以成为买卖标的。即使出卖人知道而买受人不知情，也适用相同规则；但如果买受人明知其为自由人仍予购买，买卖便不成立。

### <a id="18.1.71"></a>18.1.71

*帕皮里《敕令汇编》第一卷*

安敦尼和维鲁斯二位奥古斯都皇帝就此向塞克斯提乌斯·维鲁作出如下敕答：“*Quibus mensuris aut pretiis negotiatores vina compararent, in contrahentium potestate esse: neque enim quisquam cogitur vendere, si aut pretium aut mensura displiceat, praesertim si nihil contra consuetudinem regionis fiat*”（商人以何种计量方式或价格买卖葡萄酒，由缔约双方自行决定；没有人会被迫出售自己不满意其价金或计量方式的葡萄酒，尤其是在没有违反当地习惯的情况下）。

### <a id="18.1.72"></a>18.1.72

*帕比尼安《疑义集》第十卷*

<a id="18.1.72.pr."></a>

**序言（pr.）** 买卖成立后另行订立、减损买卖内容的协议，视为包含在合同之中；增加买卖内容的协议，我们则认为并未包含在合同之中。此规则适用于买卖的附随事项，例如约定不提供双倍价额追夺担保，或约定由保证人担保双倍赔偿。如果买受人提起诉讼时协议不能作为请求权依据，那么在出卖人起诉时，该协议仍可作为抗辩发生效力。价金后来增加或减少时能否作相同处理，确有疑问，因为价金构成买卖的本质。保罗补充说：如果双方在其他事项均保持不变的情况下再次约定增加或减少价金，应认为双方已解除先前合同，并另行成立新的买卖。

<a id="18.1.72.1"></a>

**1.** 帕比尼安说：如果买卖条款约定“若有任何神圣之物、宗教之物或公物，该物均不在出售之列”（*si quid sacri aut religiosi aut publici est, eius nihil venit*），但标的物并非供公众使用，而是属于国库财产，那么该物的买卖有效，出卖人也不能援用一项本来就不适用的抗辩。

### <a id="18.1.73"></a>18.1.73

*帕比尼安《答复集》第三卷*

<a id="18.1.73.pr."></a>

**序言（pr.）** 神圣建筑因地震而毁坏后，其建筑所在地并不因此成为俗地，故不得出售。

<a id="18.1.73.1"></a>

**1.** 墓园围墙以内留作园圃或其他耕作用途的未葬地，如果出卖人未明示保留，也归买受人所有。

### <a id="18.1.74"></a>18.1.74

*帕比尼安《定义集》第一卷*

交付钥匙后，如果钥匙是在仓库处交付的，应认为仓库内储存货物的占有也已交付。如此，买受人立即取得所有权和占有，即使尚未打开仓库也是如此；但如果货物并非出卖人所有，取得时效则从此时立即开始计算。

### <a id="18.1.75"></a>18.1.75

*赫莫革尼安《法学节要》第二卷*

出卖人出售土地时，若约定由其本人按确定租金继续承租该土地；或者约定买受人日后出售该土地时，不得卖给他人，而应转卖给出卖人；或约定类似事项，出卖人可以提起买卖之诉，请求履行双方的约定。

### <a id="18.1.76"></a>18.1.76

*保罗《答复集》第六卷*

<a id="18.1.76.pr."></a>

**序言（pr.）** 仓库中埋设的储酒大缸，如果买卖时未明示排除，应认为随仓库一并出售。

<a id="18.1.76.1"></a>

**1.** 继受买受人地位的人，可以援用其出卖人本可援用的相同抗辩；如果双方的占有期间合计达到敕令规定的期限，也可以援用长期占有时效抗辩。

### <a id="18.1.77"></a>18.1.77

*雅沃勒努斯《拉贝奥〈后书〉节本》第四卷*

出售土地时，合同写明土地上任何地点的采石场均予保留；多年后才在该土地上发现采石场。图贝罗答复说，这些采石场也属于出卖人。拉贝奥则认为，应查明双方的实际意思；如果无法确定，不应认为采石场已被保留。因为任何人既不会出售，也不会保留并不存在之物；所谓采石场，只能是已经显现且正在开采的地方。否则，若地下某处存在石料，整块土地都将被视为采石场。我赞同这一观点。

### <a id="18.1.78"></a>18.1.78

*拉贝奥《后书》第四卷（雅沃勒努斯节本）*

<a id="18.1.78.pr."></a>

**序言（pr.）** 合同约定引水管道也归买受人；问题是，供水管道引水的蓄水池是否也一并转让。答复说，显然当事人也意在转让蓄水池，尽管书面条款没有写明。

<a id="18.1.78.1"></a>

**1.** 你从某人处购买土地，后来又负责监护其儿子的事务，但你尚未取得空置占有。我说，你可以通过让受监护人及其家人离开土地，将占有交付给自己；待他们离开后，你再进入并取得占有。

<a id="18.1.78.2"></a>

**2.** 有人买入土地，约定支付价金后才向其交付占有；他留下两名继承人后死亡。如果其中一名继承人支付了全部价金，可以通过遗产分割之诉保留相应份额；如果他只支付部分价金，就不能基于买卖对出卖人起诉，因为依该合同成立的债务无法如此分割。

<a id="18.1.78.3"></a>

**3.** 你出售尚在生长中的谷物，并说如果发生暴力或风暴造成损失，你将承担责任；后来谷物被雪损坏。如果降雪强度异常，且超出当地气候常态，买受人可以对你提起买卖之诉。

### <a id="18.1.79"></a>18.1.79

*雅沃勒努斯《拉贝奥〈后书〉节本》第五卷*

你按如下条件出售土地的一半：买受人应以每年确定的租金承租你保留的另一半土地，期限十年。拉贝奥和特雷巴提乌斯否认可以提起买卖之诉，要求履行该约定。我则持相反意见，前提是你之所以以较低价格出售土地，正是为了取得这项承租安排；因为该土地依此条件出售时，这一安排本身便构成了土地的价金。我们也采用此规则。

### <a id="18.1.80"></a>18.1.80

*拉贝奥《后书》第五卷（雅沃勒努斯节本）*

<a id="18.1.80.pr."></a>

**序言（pr.）** 出售土地时约定排除人工播种之物，应认为所排除的并非永久种植的树木，而是每年播种、收取其果实的作物；否则就会认为葡萄藤和所有树木也都被排除在买卖之外。

<a id="18.1.80.1"></a>

**1.** 我说，可以买卖如下事项：“从我的房屋伸出、进入你房屋的部分，我可以照此保留”（*quae ex meis aedibus in tuas aedes proiecta sunt, ut ea mihi ita habere liceat*）。对此可以提起买卖之诉。

<a id="18.1.80.2"></a>

**2.** 有人出售一片五年期的可采伐树林；橡子落下后，问题是橡子归谁所有。我知道塞尔维乌斯曾答复说，首先应以双方的实际意思为准；如果意思不明，凡从未被砍伐的树木上落下的橡子，均属于出卖人；而在砍伐时仍留在树上的橡子，则属于买受人。

<a id="18.1.80.3"></a>

**3.** 如果出卖人意在使某物的所有权不转移给买受人，就不能认为其出售了该物；这种安排应属于租赁或其他类型的合同。

### <a id="18.1.81"></a>18.1.81

*谢沃拉《学说汇纂》第七卷*

<a id="18.1.81.pr."></a>

**序言（pr.）** 提提乌斯借入若干枚金币并约定支付利息，同时以土地设定质押或抵押，并提供卢基乌斯作为保证人；提提乌斯承诺在此后三年内解除卢基乌斯的保证责任。若至上述日期仍未解除，而保证人向债权人清偿债务，提提乌斯便命令将其抵押给债权人的土地视为已经出卖给保证人。我询问：既然提提乌斯未解除卢基乌斯的保证责任，卢基乌斯在向债权人清偿后，是否即已买入上述土地？答复说，如果双方约定并非使土地仅作为债务担保，而是使保证人取得土地所有权，则买卖附有条件，且债务关系已经成立。

<a id="18.1.81.1"></a>

**1.** 卢基乌斯·提提乌斯承诺以其土地每年向盖乌斯·塞乌斯的地产交付十万摩狄乌斯谷物。后来，卢基乌斯·提提乌斯出售该土地，并加上如下条款：“卢基乌斯·提提乌斯的这些地产，依今日所享有的权利和条件出售，并继续按该权利和条件保有”（*quo iure quaque condicione ea praedia Lucii Titii hodie sunt, ita veneunt itaque habebuntur*）。我询问，买受人是否对盖乌斯·塞乌斯负有交付谷物的义务？答复说，根据所陈述的情形，买受人不对盖乌斯·塞乌斯承担该项义务。
