## 18.6.0　论买卖标的物的风险与利益（*De periculo et commodo rei venditae*）

### <a id="18.6.1"></a>18.6.1　乌尔比安《评萨宾》第二十八卷

<a id="18.6.1.pr."></a>

**序言（pr.）** 如果已出售的葡萄酒变酸，或出现其他瑕疵，损失应由买受人承担；葡萄酒洒漏、容器破损或因其他原因受损时，也应如此。但是，如果出卖人约定由自己承担风险，则应在约定期间内承担；若未约定期间，则应承担至葡萄酒经品尝为止，因为葡萄酒似乎只有在经过品尝后才算完全售出。因此，双方要么约定由出卖人承担葡萄酒风险至某一期间，他就应承担至该期间；要么未作此约定，他就应承担至葡萄酒经品尝为止。但是，如果葡萄酒尚未品尝，买受人却已在容器或酒桶上作了标记，除非另有约定，我们仍应认为风险属于出卖人。

<a id="18.6.1.1"></a>

**1.** 出卖人还应负责保管至约定计量之日；葡萄酒尚未计量时，几乎可以说尚未出售。计量完成后，风险不再由出卖人承担；即使计量前，只要双方出售的不是按计量数量确定的酒，而是若干双耳酒罐或若干整桶酒，出卖人也免于承担风险。

<a id="18.6.1.2"></a>

**2.** 如果酒桶由买受人作了标记，特雷巴提乌斯说，应视为已经交付；拉贝奥则持相反意见，这也是正确的。作标记主要是为了防止酒桶被调换，而非为了表明已经交付。

<a id="18.6.1.3"></a>

**3.** 如果出卖人约定了计量期限，而买受人未在期限内计量，出卖人可以倒掉葡萄酒；但他不能立即倒掉，必须先以见证方式通知买受人：要么取走葡萄酒，要么知悉葡萄酒将被倒掉。尽管如此，如果出卖人本可倒掉却没有倒掉，反而值得称许；因此，他也可以请求酒桶租金，但只有在酒桶空置对他确有利益时才可以，例如他本可将酒桶租给他人，或不得不另行租用酒桶。更为妥当的做法是租用容器；或者，出卖人不返还葡萄酒，直到买受人偿付容器租金；又或者，他本着诚信出售葡萄酒，也就是说，在不使自己遭受不利的范围内尽力使买受人尽可能少受损失。

<a id="18.6.1.4"></a>

**4.** 如果你购买的是整桶葡萄酒，双方又未就交付作任何约定，应认为双方约定在新葡萄收获季需要使用酒桶之前将酒桶腾空。若届时尚未腾空，就应依古代法学家的做法，由出卖人用量筐计量后将酒倒出。古代法学家建议采用此种计量方法，是因为葡萄酒的数量若不明确，就无法知道买受人究竟损失了多少。

### <a id="18.6.2"></a>18.6.2　盖尤斯《日常法事录》第二卷

<a id="18.6.2.pr."></a>

**序言（pr.）** 上述规则适用于这样的出卖人：若非等到新的葡萄收获季，他并不需要这些酒桶。但如果出卖人是惯常买进并转售葡萄酒的商人，就应考察对出卖人而言何时取走葡萄酒最为方便。

<a id="18.6.2.1"></a>

**1.** 还须考察，在约定计量日之前，出卖人应承担何种保管责任：是应承担完整的保管责任并尽到注意义务，还是仅对故意负责？我认为，出卖人应尽到相应注意，使意外损失或重大暴力事件可以成为免责事由。

### <a id="18.6.3"></a>18.6.3　保罗《评萨宾》第五卷

出卖人应承担的保管责任，应如同借用物受领人所承担的责任，也就是尽到比其管理自己事务时更为严格的注意。

### <a id="18.6.4"></a>18.6.4　乌尔比安《评萨宾》第二十八卷

<a id="18.6.4.pr."></a>

**序言（pr.）** 如果某人出售葡萄酒，并约定应在一定期限内品尝；之后因出卖人的原因，葡萄酒未能在期限内品尝，那么出卖人仅须承担期限届满前葡萄酒变酸或发霉的风险，还是在期限届满后也应承担——例如，葡萄酒在品尝期限届满后变质，风险仍由出卖人承担？抑或买卖应当解除，仿佛双方出售的是附条件的物，也就是说，只有在期限届满前经过品尝，买卖才成立？这取决于双方的约定。但如果约定不明，我认为应认定买卖仍然存续，而出卖人即使在约定品尝期限之后，也仍应承担风险，因为未能品尝是由其自身造成的。

<a id="18.6.4.1"></a>

**1.** 如果葡萄酒是整批出售，出卖人只须承担保管责任。由此可见，如果双方出售时未约定品尝，出卖人既不对葡萄酒变酸也不对其发霉负责，一切风险均由买受人承担；不过，几乎没有人会在完全不品尝的情况下购买葡萄酒。因此，如果未为品尝约定期限，买受人可以随时品尝；在其品尝之前，葡萄酒变酸或发霉的风险仍由出卖人承担。约定品尝期限会使买受人的处境更为有利。

<a id="18.6.4.2"></a>

**2.** 整批出售葡萄酒时，出卖人的保管责任至买受人应取走葡萄酒之日终止。如果约定了取酒期限，应按该约定处理；若未约定期限，则须考察出卖人是否应承担无限期保管责任。根据前述规则，更可取的意见是，要么考察双方就期限达成的约定，要么由出卖人通知买受人取酒。无论如何，在酒桶因新一季葡萄收获而必须使用之前，葡萄酒应当被取走。

### <a id="18.6.5"></a>18.6.5　保罗《评萨宾》第五卷

如果由于买受人的原因，葡萄酒未能在约定日期取走，之后出卖人不再承担责任，但其故意侵占的部分除外。例如，如果买受人购买酒窖中葡萄酒的一百双耳酒罐，且葡萄酒须经计量，那么在计量完成前，全部风险均由出卖人承担，除非未能计量是买受人造成的。

### <a id="18.6.6"></a>18.6.6　庞波尼《评萨宾》第九卷

如果我购买葡萄酒，但明确排除变酸或发霉的葡萄酒；之后我又表示也愿意接受这些酒，普罗库鲁斯说，尽管排除这些酒是为了买受人的利益，变酸或发霉的葡萄酒仍不属于出售标的。买受人本来无须违背意愿接受这些葡萄酒，因此不允许出卖人或他人另行出售这些酒是不公平的。

### <a id="18.6.7"></a>18.6.7　保罗《评萨宾》第五卷

<a id="18.6.7.pr."></a>

**序言（pr.）** 如果土地出售后因冲积而增加面积，或者因冲刷而减少，其利益或不利益均由买受人承担。即使整块土地在出售后被河流淹没，风险也由买受人承担；因此，相应利益也应归其享有。

<a id="18.6.7.1"></a>

**1.** 被出售的部分应计入土地面积，除非双方另有约定。未出售的部分，只有在双方约定应计入面积时才应计入，例如公共道路、界线以及与该土地相接的树林。若双方对两者均未作约定，则不应计入。因此，通常会明确约定，土地上的树林和公共道路均应全部计入土地面积。

### <a id="18.6.8"></a>18.6.8　保罗《评告示》第三十三卷

<a id="18.6.8.pr."></a>

**序言（pr.）** 必须弄清买卖何时完成；只有这样，才能知道风险属于何人，因为买卖完成后，风险即归买受人。如果出售之物的种类、性质和数量均已确定，价款也已确定，并且买卖不附条件，那么买卖即告完成。如果财物附条件出售，条件不成就时买卖无效，如同要式口约无效一样；条件成就时，普罗库鲁斯和奥克塔维努斯说，风险属于买受人，庞波尼在《评萨宾》第九卷中也赞同这一意见。若条件尚未成就时买受人或出卖人死亡，但后来条件成就，众所周知，其继承人也受约束，仿佛买卖早已追溯至过去成立。如果条件尚未成就，财物就已交付，买受人不得以买受人身份取得时效。已经支付的价款应予返还，期间产生的孳息属于出卖人；因为如果财物在条件未成就期间灭失，附条件的要式口约和遗赠也会随之失效。不过，如果财物仍然存在，只是状况变坏，可以说损失应由买受人承担。

<a id="18.6.8.1"></a>

**1.** 如果双方约定：“该奴隶即为买受标的，无论那艘船是否从亚洲返回。”尤利安认为，买卖立即完成，因为可以确定买卖已经成立。

<a id="18.6.8.2"></a>

**2.** 如果你向我出售用益权，须区分你出售的是仅属于你的使用收益权，还是将你所有的实体物之用益权出售给我。前一种情形下，即使你立即死亡，你的继承人也无须向我给付；但如果你仍然在世，就应向我的继承人给付。后一种情形下，我的继承人无权请求给付，但你的继承人应当给付。

### <a id="18.6.9"></a>18.6.9　盖尤斯《评行省告示》第十卷

在查看土地后、买卖成立前，若树木被风吹倒，问题是这些树木是否也应交付给买受人。答复认为，无须交付，因为买受人并未购买这些树木；在买受人购买土地之前，树木已不再是土地的一部分。但是，如果买受人不知道树木已经倒下，而出卖人知道却未告知，只要树木属于出售标的，就应按买受人因此所受利益损失确定赔偿额。

### <a id="18.6.10"></a>18.6.10　乌尔比安《论争集》第八卷

如果双方在附条件买卖中约定标的物由买受人承担风险，我认为该约定有效。

### <a id="18.6.11"></a>18.6.11　斯凯沃拉《尤利安《学说汇纂》第七卷札记》

如果在土地计量之前，因水灾、地陷或其他意外导致部分土地灭失，买受人不得就该土地提起诉讼。

### <a id="18.6.12"></a>18.6.12　阿尔芬努斯《学说汇纂》第二卷

如果出售的公寓楼被烧毁，而火灾不可能在毫无过失的情况下发生，那么适用何种法律？答复说，火灾可以在家父毫无过失的情况下发生；即使火灾是奴隶疏忽所致，也不必然意味着主人有过失。因此，只要出卖人在看管公寓楼时尽到了正派、谨慎之人通常应尽的注意，若发生火灾，出卖人便不承担责任。

### <a id="18.6.13"></a>18.6.13　保罗《阿尔芬《学说汇纂》节要》第三卷

市政长官将置于公共道路上的已售床榻砍毁。如果床榻已经交付给买受人，或者未能交付是由买受人造成的，意见认为风险由买受人承担。

### <a id="18.6.14"></a>18.6.14　尤利安《致乌尔塞乌斯·费罗克斯》第三卷

如果市政长官的行为违法，买受人可以对其提起阿奎利亚法之诉；或者，买受人可以对出卖人提起买受之诉，要求出卖人将其对市政长官享有的诉权让与买受人。

### <a id="18.6.15"></a>18.6.15　保罗《阿尔芬《学说汇纂》节要》第三卷

<a id="18.6.15.pr."></a>

**序言（pr.）** 如果标的物既未交付，买受人也没有迟延受领，风险就由出卖人承担。

<a id="18.6.15.1"></a>

**1.** 如果购买的木料在交付后因盗窃而灭失，答复认为风险由买受人承担；若尚未交付，则由出卖人承担。买受人标记过的梁木，应视为已经交付。

### <a id="18.6.16"></a>18.6.16　盖尤斯《日常法事录》第二卷

如果出售的是储存在酒桶中的葡萄酒，而葡萄酒在买受人取走之前自然变质，若出卖人曾保证葡萄酒品质良好，就应对买受人承担责任；若出卖人未作任何保证，风险由买受人承担，因为他要么没有品尝，要么品尝后却错误地认可了品质。显然，如果出卖人明知葡萄酒品质不能维持至约定取酒之日，却未提醒买受人，就应按买受人若获提醒本可享有的利益承担责任。

### <a id="18.6.17"></a>18.6.17　雅沃勒努《卡西乌斯著作节要》第七卷

如果买受人购买奴隶后，请求出卖人将奴隶出租给自己，直至付清价款，那么买受人不能通过该奴隶取得任何利益，因为奴隶并未交付；出卖人通过租赁关系保留了奴隶的占有。若奴隶遭遇的风险并非由出卖人的欺诈造成，该奴隶的风险由买受人承担。

### <a id="18.6.18"></a>18.6.18　庞波尼《评昆图斯·穆基乌斯》第三十一卷

应当知道，一旦买受人开始迟延，出卖人此后仅对恶意欺诈负责，而不再对一般过失负责。如果出卖人与买受人双方都曾迟延，拉贝奥确实写道，迟延应使买受人而非出卖人受不利；但还须考察后发生的迟延是否对买受人造成损害。比如，我曾催告出卖人交付所购之物，他却没有交付；后来他提出交付，我却不接受。在这种情形下，迟延当然应由我承担不利后果。但如果迟延最初是由买受人造成，后来一切条件都已恢复正常，而出卖人本可履行却又迟延，公平起见，后一次迟延应使出卖人承担不利后果。

### <a id="18.6.19"></a>18.6.19　帕皮尼安《答复集》第三卷

<a id="18.6.19.pr."></a>

**序言（pr.）** 释奴死亡后，为其提供住所的义务随之终止；如果双方仅约定依已故者的意思，在价款之外为释奴提供住所，房屋买受人就不因此对出卖人承担责任，除非双方另有约定。

<a id="18.6.19.1"></a>

**1.** 在价款付清前，如果有人对所有权提出争议，买受人无须支付价款，除非出卖人为防止追夺提供了适格的保证人。

### <a id="18.6.20"></a>18.6.20　赫尔莫吉尼安《法学节要》第二卷

如果买受人迟延支付价款，他只须向出卖人支付利息，而不必赔偿出卖人若无迟延本可取得的一切收益；例如，出卖人若为商人，在收到价款后可能从货物经营中赚取比利息更高的利润。
