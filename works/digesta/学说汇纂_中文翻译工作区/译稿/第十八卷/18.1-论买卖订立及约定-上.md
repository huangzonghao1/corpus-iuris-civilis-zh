## 18.1.0　论买卖的订立、买卖双方约定及不得出卖之物（*De contrahenda emptione et de pactis inter emptorem et venditorem compositis et quae res venire non possunt*）——上篇

### <a id="18.1.1"></a>18.1.1

*保罗《评告示》第三十三卷*

<a id="18.1.1.pr."></a>

**序言（pr.）** 买卖起初源于交换。古时尚无货币，也不把商品与价金称为不同事物，而是人们依当时情形和需要，以有用之物交换无用之物，因为往往一方有余、另一方不足。由于人们并非总能或容易遇到你拥有我想要之物，而我又恰有你愿意接受之物的情形，遂选取一种材料，以其公开且恒定的价值评定，凭数量相等之法补救交换的困难。该材料经公共方式铸制后，其使用和所有权主要并非取决于质料本身，而取决于其数量；从此，同一物不再兼为商品与价金，其中一方称为价金。

<a id="18.1.1.1"></a>

**1.** 如今以物易物是否也可称为买卖，仍有疑问；例如，我交付一件长袍，以换取一件上衣。萨宾努斯和卡西乌斯认为这构成买卖；涅尔瓦和普罗库鲁斯则认为这是交换而非买卖。萨宾努斯援引荷马为证，称荷马记载希腊军队以铜、铁和奴隶换取葡萄酒，并有诗句如下：*enven ar' oinizonto karykomowntes Axaioi alloi men xalkw, alloi d' aivwni sidyrw, alloi de hrinois, alloi d' autysi boessi, alloi d' andrapodessin*〔即：蓄长发的阿开奥斯人正在换取葡萄酒，有人以铜，有人以闪亮的铁，有人以牛皮，有人以牛本身，有人以奴隶。〕但这些诗句似乎表明的是交换，而非买卖；正如另一诗句所示：*env' aute Glaukw Kronidys frenas eceleto Zeus, hos pros Tudeidyn Diomydea teuxe ameiben*〔即：克罗诺斯之子宙斯使格劳科斯心智迷乱，以致他与提丢斯之子狄俄墨得斯交换了武器。〕更能支持该观点的，或许是同一诗人另有一句：*priato kteatessin heoisin*〔即：他以自己的财物买下。〕然而，涅尔瓦和普罗库鲁斯的观点更为正确：正如出卖与买入有别，买受人与出卖人各不相同，价金与商品也各不相同；在交换中却无法区分谁是买受人、谁是出卖人。

<a id="18.1.1.2"></a>

**2.** 买卖属于万民法，因而以合意成立；当事人不在场时，也可以通过使者或书信订立。

### <a id="18.1.2"></a>18.1.2

*乌尔比安《萨宾评注》第一卷*

<a id="18.1.2.pr."></a>

**序言（pr.）** 父与子之间不得订立买卖，但对于军营特有财产，可以订立买卖。

<a id="18.1.2.1"></a>

**1.** 无价金即无买卖；但非价金的实际支付，而是合意，使未采用书面形式的买卖得以成立。

### <a id="18.1.3"></a>18.1.3

*乌尔比安《萨宾评注》第二十八卷*

如果约定买受人不满意时标的物即视为未曾买入，那么可以确定，该买卖并非附条件成立，而是买卖关系附解除条件。

### <a id="18.1.4"></a>18.1.4

*庞波尼乌斯《萨宾评注》第九卷*

如果买受人不知情而买入自由人、神圣之地或宗教之地（这些均不得为私有），也可认为买卖已经成立，

### <a id="18.1.5"></a>18.1.5

*保罗《萨宾评注》第五卷*

因为自由人与奴隶难以区分。

### <a id="18.1.6"></a>18.1.6

*庞波尼乌斯《萨宾评注》第九卷*

<a id="18.1.6.pr."></a>

**序言（pr.）** 但小塞尔苏斯说：明知对方是自由人，就不得购买；明知某项财物不得转让，也不得购买，例如神圣之地、宗教之地，或不属于交易范围的物，例如公物。公物并非归属于人民的财产，而是供公众使用之物，例如马尔斯广场。

<a id="18.1.6.1"></a>

**1.** 假如一块土地依约分期付款，在第一、第二或第三个年度的约定日付款；约定若买受人未于指定日期付款，土地即视为未曾买入；又约定，如在此期间买受人耕种土地并取得孳息，则土地视为未曾买入时，应返还该等孳息；还约定，若土地后来以较低价格出售给他人，买受人应向出卖人补足差价。那么，若买受人届期未付款，出卖人可以就此提起买卖之诉。我们不应对此感到困惑：虽说土地被视为未曾买入，却又认为可提起买卖之诉。因为在买卖关系中，应以当事人的实际约定为准，而非仅拘泥于所用言辞；既然约款如此表述，显然双方仅意在使出卖人不因买受人届期未付款而对其负有责任，并非意在使双方之间买卖关系所生的一切义务均告消灭。

<a id="18.1.6.2"></a>

**2.** 合同订立之初所约定的条件，之后可以通过另一项协议变更；同样，只要双方尚未履行各自应履行的事项，也可以解除整个买卖。

### <a id="18.1.7"></a>18.1.7

*乌尔比安《萨宾评注》第二十八卷*

<a id="18.1.7.pr."></a>

**序言（pr.）** 奴隶买卖约定“若其依主人裁量结算账目”（*si rationes domini computasset arbitrio*），属于附条件买卖；附条件买卖须待条件成就时才成立。但此处的买卖条件，究竟是依主人自己的裁量，还是依善良之人的裁量？若理解为依主人的裁量，则买卖并未成立，正如有人约定“若我愿意”（*si voluero*）才出卖，或对要约人作出“若我愿意，我将给付十”（*si voluero, decem dabo*）的承诺；因为不能把自己是否受约束交由义务人任意决定。因此，古人更倾向于认为，此处应由善良之人裁量，而非由主人裁量。于是，如果买受人本可取得账目却未取得，或者虽已取得却假称未取得，买卖条件即已成就，出卖人可对其提起买卖之诉。

<a id="18.1.7.1"></a>

**1.** 下列买卖有效：“按你购买该物的价格”（*quanti tu eum emisti*）买入，或者“按我钱箱中现有的钱数”（*quantum pretii in arca habeo*）买入。此种买卖的价金并非不确定；只是人们不知道当初买入的价格，而非该价格实际上不确定。

<a id="18.1.7.2"></a>

**2.** 如果有人约定：“该土地以一百的价格卖给我，另加我日后转卖该土地所得的超出部分”（*est mihi fundus emptus centum et quanto pluris eum vendidero*），买卖有效并立即成立；因为价金中的一百是确定的，只是在买受人以更高价格转卖土地时，价金才会增加。

### <a id="18.1.8"></a>18.1.8

*庞波尼乌斯《萨宾评注》第九卷*

<a id="18.1.8.pr."></a>

**序言（pr.）** 若无可供出卖的标的物，就不能成立买卖。尽管如此，未来的果实和子女仍可有效买卖；因此，一旦子女出生，即应认为买卖在交易订立之时已经成立。但如果出卖人故意阻止其出生或产生，买受人可以提起买卖之诉。

<a id="18.1.8.1"></a>

**1.** 有时，即便没有现存标的物，也可认为买卖成立，例如买受人以碰运气的方式购买。比如购买所捕获的鱼、鸟或抛掷物：即使最终一无所获，买卖仍已成立，因为买受的是机会。至于此种情形下以“抛掷物”名义捕获之物后来被他人追夺的，不因此发生买卖之诉上的责任，因为应认为这正是双方约定的内容。

### <a id="18.1.9"></a>18.1.9

*乌尔比安《萨宾评注》第二十八卷*

<a id="18.1.9.pr."></a>

**序言（pr.）** 显然，买卖必须有合意；如果当事人在是否买卖、价金或其他事项上意见不一致，买卖即未成立。因此，如果我以为自己买的是科尔内利亚努斯土地，而你以为卖给我的却是塞姆普罗尼亚努斯土地，由于我们对标的物意见不一致，买卖便不成立。如果我以为自己买的是斯提库斯，而你以为卖的是不在场的潘菲卢斯，也同样如此；既然当事人对标的物意见不一致，显然买卖即未成立。

<a id="18.1.9.1"></a>

**1.** 当然，如果我们只是在名称上意见不一致，而对标的物本身已有共识，那么毫无疑问，买卖仍然有效；只要标的物明确，名称错误并无影响。

<a id="18.1.9.2"></a>

**2.** 由此产生一个问题：如果对标的物本身并无误认，但对其材质发生错误，例如把醋当作葡萄酒出售、把铜当作黄金、把铅当作白银，或把其他类似白银之物当作白银，那么买卖是否成立？马尔凯卢斯在《学说汇纂》第六卷中写道，买卖成立，因为双方对标的物已有合意，尽管对材质发生错误。就葡萄酒而言，我同意这一观点：如果只是葡萄酒变酸，二者的本质几乎相同；但如果它并非由葡萄酒变酸，而是自始就是醋，例如调味酱所用的醋，那么便是以一物冒充另一物出售。至于其他情形，只要对材质发生错误，我认为买卖均不成立。

### <a id="18.1.10"></a>18.1.10

*保罗《萨宾评注》第五卷*

但如果确为黄金，只是品质低于买受人的预期，则情形不同：此时买卖仍然有效。

### <a id="18.1.11"></a>18.1.11

*乌尔比安《萨宾评注》第二十八卷*

<a id="18.1.11.pr."></a>

**序言（pr.）** 那么，如果买受人是盲人，或者对材质发生错误，或者欠缺辨别材质的能力，我们该如何解释？能否说他们对标的物本身已有合意？一个没有看见标的物的人又如何可能作出合意？

<a id="18.1.11.1"></a>

**1.** 但如果我以为自己买的是少女，而她实际上已经成年为妇女，买卖仍然有效，因为性别并未发生错误。反之，如果我出卖一名妇女，而你以为自己买的是男童，由于对性别发生错误，买卖均不成立。

### <a id="18.1.12"></a>18.1.12

*庞波尼乌斯《评昆图斯·穆基乌斯》第三十一卷*

在此类问题中，应考察缔约的买受人与出卖人本人，而非因该合同而取得诉权的人。因为如果我的奴隶，或处于我权力之下的儿子，在我在场时以自己的名义买入，就不应考察我的认识，而应考察实际缔约之人的认识。

### <a id="18.1.13"></a>18.1.13

*庞波尼乌斯《萨宾评注》第九卷*

但是，如果你把逃奴卖给我的奴隶，或卖给我所委托的人，而你知道其为逃奴、对方并不知情、我却知情，那么应认为你不因买卖而承担责任。

### <a id="18.1.14"></a>18.1.14

*乌尔比安《萨宾评注》第二十八卷*

那么，如果双方对材质和品质都发生错误，该如何处理？例如，我以为自己出卖的是黄金，你以为自己买的也是黄金，但标的物实际是铜。又如，数名共同继承人把一只据称为金制的小手镯（*viriola*）以高价卖给其中一名继承人，后来发现它大部分是铜制的。可以确定，买卖成立，因为其中确实含有一些黄金。如果某物只是镀金，即使我以为它是纯金，买卖仍然有效；但如果把铜当作黄金出售，买卖便不成立。

### <a id="18.1.15"></a>18.1.15

*保罗《萨宾评注》第五卷*

<a id="18.1.15.pr."></a>

**序言（pr.）** 即使双方对标的物已有合意，但该物在买卖之前已不复存在，买卖仍不成立。

<a id="18.1.15.1"></a>

**1.** 买受人的不知情对其有利，但不包括怠于注意之人的不知情。

<a id="18.1.15.2"></a>

**2.** 如果你把我的财物卖给我，而我对此并不知情，并依我的指示把它交给第三人，庞波尼乌斯认为我的所有权并未转移；因为我的意思并非使该物归我所有，而是仿佛使你的所有权转移给第三人。因此，即使你是要把我的财物赠给我，却依我的指示交给第三人，也应作相同处理。

### <a id="18.1.16"></a>18.1.16

*庞波尼乌斯《萨宾评注》第九卷*

<a id="18.1.16.pr."></a>

**序言（pr.）** 买卖自己的财物无效，无论买受人明知还是不知该物属于自己；但如果买受人不知情，其已支付的价金可以请求返还，因为双方之间并无债务关系。

<a id="18.1.16.1"></a>

**1.** 但如果买受人对该物仅享有用益权，并不妨碍买卖成立。

### <a id="18.1.17"></a>18.1.17

*保罗《评告示》第三十三卷*

不过，法官可依职权减少价金。

### <a id="18.1.18"></a>18.1.18

*庞波尼乌斯《萨宾评注》第九卷*

<a id="18.1.18.pr."></a>

**序言（pr.）** 但如果买受人与他人共有该物，就应认为：价金分割后，买卖按份额部分有效、部分无效。

<a id="18.1.18.1"></a>

**1.** 如果奴隶奉主人之命指示所售土地的界址，却因错误或欺诈而多指了土地，仍应以主人本意所指为准；阿尔芬努斯对于奴隶交付空置占有的情形，也作了相同论述。

### <a id="18.1.19"></a>18.1.19

*庞波尼乌斯《评昆图斯·穆基乌斯》第三十一卷*

我所出卖的物，只有在价金已付给我们、就价金提供了担保，或者我们无需任何担保而信任买受人时，才归受领人所有。

### <a id="18.1.20"></a>18.1.20

*庞波尼乌斯《萨宾评注》第九卷*

萨宾答复说，如果我们委托他人为我们制作某物，例如雕像、器皿或衣物，并约定我们只支付金钱，这应视为买卖；如果委托制作的人没有提供制作标的物所需的材料，就不能成立承揽。情形不同于我提供土地、由你在其上建造房屋，因为此时建筑材料源自我。

### <a id="18.1.21"></a>18.1.21

*保罗《萨宾评注》第五卷*

拉贝奥写道，协议含义不明的后果，应由提出该协议的出卖人承担，而非由买受人承担；因为在交易尚未确定之前，出卖人本可以把话说得更清楚。

### <a id="18.1.22"></a>18.1.22

*乌尔比安《萨宾评注》第二十八卷*

买卖条款“若其中有任何神圣或宗教之物，该物均不在出售之列”（*si quid sacri vel religiosi est, eius venit nihil*）并非多余，而是适用于少量土地。反之，如果整片土地都是宗教用地、神圣之地或公物，买卖便不成立，

### <a id="18.1.23"></a>18.1.23

*保罗《萨宾评注》第五卷*

（买受人可以就此请求返还其已支付的款项。）

### <a id="18.1.24"></a>18.1.24

*乌尔比安《萨宾评注》第二十八卷*

但对于少量土地，买受人可以提起买卖之诉，因为被出售的并非特定的神圣之地或宗教之地，而是该土地作为较大土地的附属部分一并出售。

### <a id="18.1.25"></a>18.1.25

*乌尔比安《萨宾评注》第三十四卷*

<a id="18.1.25.pr."></a>

**序言（pr.）** 如果买卖约定“此物或彼物”（*illa aut illa res*），由出卖人选择，则出卖人所选之物即为买卖标的。

<a id="18.1.25.1"></a>

**1.** 出卖人并无义务使土地归买受人所有；这不同于出卖人向要约人作出要式承诺、允诺交付土地的情形。

### <a id="18.1.26"></a>18.1.26

*庞波尼乌斯《萨宾评注》第十七卷*

如果我明知某人已被禁止管理其财产，或者其虽获准考虑是否接受遗产，但不得减损遗产财产，而仍向其购买某物，我就不会取得所有权。这与我明知向债务人购买财物会损害债权人利益的情形不同。

### <a id="18.1.27"></a>18.1.27

*保罗《萨宾评注》第八卷*

任何人从他人处购买某物，并相信该物属于出卖人，都是善意买受人；但未经监护人同意而从受监护的未成年人处购买，或者由买受人明知并非监护人的人假冒监护人同意而购买，则不属于善意买受人，萨宾努斯也作此论述。

### <a id="18.1.28"></a>18.1.28

*乌尔比安《萨宾评注》第四十一卷*

毫无疑问，任何人均可出卖他人之物；买卖仍然成立，但该物可能被从买受人处追夺。

### <a id="18.1.29"></a>18.1.29

*乌尔比安《萨宾评注》第四十三卷*

奴隶被出卖时，不包括其特有财产。因此，无论合同没有作出排除约定，还是明确约定不连同特有财产出售，都应视为该奴隶并非连同特有财产一并出售。由此，如果奴隶偷取了属于其特有财产的某物，可以请求返还，理由显然在于该物如同赃物；但须以该物已经到达买受人手中为限。

### <a id="18.1.30"></a>18.1.30

*乌尔比安《评告示》第三十二卷*

但我认为，仍可提起出示之诉，也可提起买卖之诉。

### <a id="18.1.31"></a>18.1.31

*庞波尼乌斯《萨宾评注》第二十二卷*

此后如有任何财物添入特有财产，也应返还给出卖人，例如奴隶生育的子女，以及从替代奴隶的劳务中取得之物。

### <a id="18.1.32"></a>18.1.32

*乌尔比安《萨宾评注》第四十四卷*

出卖钱商铺面或其他建于公有土地上的铺面之人，出卖的并非土地本身，而是相关权利；因为这些铺面属于公共财产，只是其使用权归私人享有。

### <a id="18.1.33"></a>18.1.33

*庞波尼乌斯《萨宾评注》第三十三卷*

如果买卖条款写道：“河流及屋檐滴水如今如何，此后仍应如何”，却未说明具体指哪些河流或滴水，首先应查明当事人的意思；如果仍无法确定，就应采对出卖人不利的解释，因为该表述含义不明。

### <a id="18.1.34"></a>18.1.34

*保罗《评告示》第三十三卷*

<a id="18.1.34.pr."></a>

**序言（pr.）** 如果土地买卖中约定附带一名名为斯提库斯的奴隶，却无法确定数名同名奴隶中究竟是哪一名，买受人和出卖人各自所指又不同，土地买卖仍然有效；但拉贝奥说，应交付出卖人所指的那名斯提库斯。附属物的价值大小并不重要，无论附属物的价值高于还是低于其所附随的主物均然；因为人们有时正是为了附属物而购买主物，例如为了大理石、雕像和绘画而购买房屋。

<a id="18.1.34.1"></a>

**1.** 凡人能够拥有、占有或请求返还的物，均可有效出卖；但依其性质、万民法或城市习惯而被排除于交易之外的物，不得出卖。

<a id="18.1.34.2"></a>

**2.** 明知是自由人，就不得购买。但下列买卖或要式允诺也不应获准：“等他成为奴隶时……”尽管我们认为未来之物可以买卖，也不得等待此类事情发生。

<a id="18.1.34.3"></a>

**3.** 如果买受人和出卖人都知道所售之物是赃物，双方均不因此产生债务关系。如果只有买受人知情，出卖人不承担义务；但出卖人也不能通过买卖之诉取得任何给付，除非买受人自愿履行约定。反之，如果出卖人知情而买受人不知情，双方之间均产生债务关系；庞波尼乌斯也如此论述。

<a id="18.1.34.4"></a>

**4.** 买卖自己的物，此时有效：双方自始即意在使买受人取得该物的占有，而出卖人或许曾经占有该物，且买受人在占有诉讼中将居于较优地位。

<a id="18.1.34.5"></a>

**5.** 品尝与计量的作用不同：品尝是为了允许买受人拒收；计量则不是为了确定所售之物是多是少，而是为了查明买入的数量。

<a id="18.1.34.6"></a>

**6.** 如果买卖约定“斯提库斯或潘菲卢斯归我买入”（*est mihi emptus Stichus aut Pamphilus*），由出卖人选择交付何人，正如要式允诺中所作的选择；但其中一人死亡，就必须交付另一人。因此，先死亡之人的风险由出卖人承担，后死亡之人的风险由买受人承担。即使二人同时死亡，也仍应支付价金，因为其中一人至少曾在买受人承担风险期间存活。如果由买受人选择要买何人，也应作相同处理，但前提是只把选择买入何人交由其裁量，而非把是否买入也交由其决定。

<a id="18.1.34.7"></a>

**7.** 监护人不得购买受监护人的财物；同一规则也应扩及类似人员，即财产管理人、代理人以及管理他人事务之人。

### <a id="18.1.35"></a>18.1.35

*盖尤斯《告示汇编》第十卷*

<a id="18.1.35.pr."></a>

**序言（pr.）** 买卖时通常交付的所谓定金，并非意味着没有定金合意就毫无效力，而是为了更明确地证明双方已就价金达成协议。

<a id="18.1.35.1"></a>

**1.** 有一点可以确定：如果出卖人对有意购买之人说：“你愿意给多少、认为多少公平、评估为多少，就按那个价格买下”（*Quanti velis, quanti aequum putaveris, quanti aestimaveris, habebis emptum*），交易尚未完成。

<a id="18.1.35.2"></a>

**2.** 有人认为，买卖有害的毒物并不产生买卖关系，因为对于可耻之事，合伙或委任也不发生效力。对于那些无论怎样掺入其他物质都不能为我们所用的毒物，这一观点确实可能正确；但对于那些与其他物质混合后便丧失其有害性质，进而可制成解毒剂及其他有益药物的物质，则可以有不同看法。

<a id="18.1.35.3"></a>

**3.** 如果有人委托一名即将出国的朋友寻找自己的逃奴，并在找到后将其出售，委托人本人并未违反元老院决议，因为他没有亲自出卖；其朋友也未违反，因为他出卖的是当场出现的奴隶。买受人购买当场出现的奴隶，也应认为是正当交易。

<a id="18.1.35.4"></a>

**4.** 如果出售的物因盗窃而灭失，首先应查明双方对该物的保管责任作了何种约定。若无法证明双方有所约定，就应要求出卖人尽到善良家父对待自己财物时所尽的注意。如果出卖人已尽此种注意而该物仍然灭失，他即应免责；但仍须向买受人交付对该物提起所有物返还之诉（*rei vindicatio*）及返还之诉（*condictio*）的诉权。因此，对于出卖他人之物的人，应另作考察：由于他不可能享有所有物返还之诉或返还之诉，仍应判令其承担责任；因为如果出卖的是自己的物，他本可将这些诉权移转给买受人。

<a id="18.1.35.5"></a>

**5.** 对于以重量、数量或计量确定的物，例如谷物、葡萄酒、橄榄油和白银，有时适用与其他物相同的规则：只要价金达成合意，买卖即视为完成；有时则即使价金已经议定，也须待标的物经过计量、称重或点数后，买卖才算完成。如果所有葡萄酒、橄榄油、谷物或白银无论数量多少均以一个总价出售，适用与其他物相同的规则。但如果约定葡萄酒按每安瓿（*amphora*）、橄榄油按每麦特雷忒（*metreta*）、谷物按每摩狄乌斯（*modius*）、白银按每磅分别计价，就会产生买卖何时完成的问题。以件数计价的物，也会产生同样问题。萨宾努斯和卡西乌斯认为，只有在物品已经点数、计量或称重后，买卖才告完成；因为买卖似乎是附有这样的条件：每安瓿、每麦特雷忒或每摩狄乌斯均按计量所得数量、每磅均按称重所得重量、每件均按点数所得数量确定价金。

<a id="18.1.35.6"></a>

**6.** 因此，如果出售的是一群牲畜，且以整群一个总价出售，那么一旦价金达成合意，买卖即告完成；如果每头牲畜分别定价，则适用刚才所述规则。

<a id="18.1.35.7"></a>

**7.** 如果从酒桶中出售一部分葡萄酒，例如一百麦特雷忒（*metretas*），那么在计量之前，全部风险仍由出卖人承担，这一观点最为正确，也似乎已成定论；无论一百麦特雷忒约定一个总价，还是逐单位计价，均不影响这一点。

<a id="18.1.35.8"></a>

**8.** 如果有人出售地产时隐瞒了相邻土地的界址，而买受人若知悉此事便不会购买，出卖人应承担责任。

### <a id="18.1.36"></a>18.1.36

*乌尔比安《评告示》第四十三卷*

如果有人出卖某物时虽标出价金，但无意请求支付，而是出于赠与目的，就不应认为其在出卖。

### <a id="18.1.37"></a>18.1.37

*乌尔比安《论辩》第三卷*

如果有人将依遗嘱继承的土地出售，并约定：“你按遗嘱人购买该土地时的价格（*tanti, quanti a testatore emptus est*）买下”，后来却发现该土地并非遗嘱人买入，而是受赠所得，那么应认为这项买卖仿佛未约定价金；因此，它类似于附条件买卖，而条件未成就时，该买卖无效。

### <a id="18.1.38"></a>18.1.38

*乌尔比安《论辩》第七卷*

如果有人为了赠与而以低价出售，买卖仍然有效。只有在整个买卖都是为了赠与而订立时，我们才说买卖整体无效；如果仅因赠与目的而以较低价格出售某物，毫无疑问，买卖仍然有效。此规则适用于其他人之间；但夫妻之间若为了赠与而以低价买卖，则不发生效力。

### <a id="18.1.39"></a>18.1.39

*尤利安《学说汇纂》第十五卷*

<a id="18.1.39.pr."></a>

**序言（pr.）** 如果债务人从债权人处赎回已出质之物，这相当于买受自己的物，因而不负买卖之诉上的责任；债权人的权利状态也不发生变化。

<a id="18.1.39.1"></a>

**1.** 有人出卖尚挂在树上的橄榄果实，并约定收取由此所产橄榄油十磅。可以推知，双方是根据实际产出的橄榄油定价，最多以十磅为限；因此，如果只收获了五磅，多数法学家认为，买受人只能请求交付已收获的五磅橄榄油。

### <a id="18.1.40"></a>18.1.40

*保罗《阿尔芬努斯〈学说汇纂〉节本》第四卷*

<a id="18.1.40.pr."></a>

**序言（pr.）** 某人出卖土地时，在合同条款中约定，买受人应于其后最近三十日内丈量土地并报告面积；如果其未在该期限前报告，出卖人即解除担保责任。买受人在丈量期限内报告土地面积比其原先认为的少，并就少出的部分收回了价款。后来，他又出售该土地，亲自为自己的买受人丈量时，发现土地面积远少于其原先所认为的面积，于是询问能否就进一步短少的面积向自己的出卖人请求返还。答复称，这取决于条款如何表述：如果约定买受人应在最近三十日内丈量土地并向出卖人报告面积少了多少，那么他在第三十日后才作出的报告对其毫无帮助；但如果约定买受人应在随后一段时间内丈量土地并报告面积，那么即使他已在三十日内报告土地面积不足，也仍可在多年后就进一步短少的面积请求返还。

<a id="18.1.40.1"></a>

**1.** 土地合同中说水也一并转让；问题是，是否还包括引水通道使用权。答复认为，应当如此，故出卖人也应交付引水通道使用权。

<a id="18.1.40.2"></a>

**2.** 出卖人出售土地时说共有十八犹格亩，并约定按实际丈量所得的每犹格亩支付确定价金；后来丈量出二十犹格亩。答复认为，应按二十犹格亩支付价金。

<a id="18.1.40.3"></a>

**3.** 土地出卖人保留了人工播种的谷物；但该土地上又从谷茬长出了庄稼。问题是，这是否包含在约定之内？答复认为，关键在于双方的实际意思；但依约定措辞，并不包括从谷茬长出的庄稼，正如麻袋搬运工的袋中掉落之物，或鸟从空中掉落之物所生之物，也不包括在内。

<a id="18.1.40.4"></a>

**4.** 有人出售土地时约定保留全部孳息。答复认为，可砍伐的芦苇和树林也属于孳息。

<a id="18.1.40.5"></a>

**5.** 出卖人说土地上的储酒大缸也一并转让。答复认为，耕种土地的奴隶以其特有财产购买的那些大缸，也应归买受人所有。

<a id="18.1.40.6"></a>

**6.** 用来汲水的水车与水桶一样，都是建筑物的组成部分。
