# D.18.4 论遗产或诉权的出卖

<!-- source-p 01; 原文导航锚点 4、题名锚点 18.4 -->
<a id="4"></a><a id="18.4"></a>**18.4.0. 论遗产或诉权的出卖（*De hereditate vel actione vendita*）**

<!-- source-p 02 -->
<a id="18.4.1"></a>**18.4.1**

<!-- source-p 03 -->
**庞波尼乌斯：《萨宾评注》第九卷。**

<!-- source-p 04 -->
如果出售的是一个尚在人世者的遗产，或一个根本不存在者的遗产，便没有发生任何交易，因为被出售之物并不存在。

<!-- source-p 05 -->
<a id="18.4.2"></a>**18.4.2**

<!-- source-p 06 -->
**乌尔比安：《萨宾评注》第四十九卷。**

<!-- source-p 07 -->
<a id="18.4.2.pr."></a>**序言。**遗产出卖人无须就遗产被追夺提供担保，因为买卖双方约定的是：买受人取得的权利既不多于、也不少于遗产继承人本可享有的权利；但出卖人显然必须就其自身行为提供担保。

<!-- source-p 08 -->
<a id="18.4.2.1"></a>**1.**遗产出卖时，应以何时的遗产数额为准：被继承人死亡时、继承人接受遗产时，还是遗产出售时？对此应当遵从当事人的约定；不过，通常看来，双方约定的是：截至出售时从遗产中取得的财物，均包含在出售范围内。

<!-- source-p 09 -->
<a id="18.4.2.2"></a>**2.**还可以提出这样的问题：如果出售遗嘱人遗产的人同时被指定为未达适婚年龄者的替代继承人，那么他从该未达适婚年龄者的遗产中取得的财物，是否也可依据买受之诉请求交付？较妥当的看法是不包括在内，因为这是另一份遗产；虽然只有一份遗嘱，遗产仍彼此不同。当然，如果双方约定将该未达适婚年龄者的遗产也纳入出售范围，就应认定该遗产亦已出售；尤其是在该遗产已经归属后才出售遗产的情形。

<!-- source-p 10 -->
<a id="18.4.2.3"></a>**3.**如何认定财物已经归于遗产出卖人名下？我认为，在出卖人尚未取得遗产中的实物之前，只能在其能够委托他人追索该物、并移转相关诉权的范围内，认定财物归其取得；但在他取得实物或收取债务后，应认为财物已更充分地归其取得。若出卖人在遗产出售前已收取遗产中某物的价款，显然该价款已经归其取得。还应注意，所谓归其取得，须是实际取得，而非仅在表面上取得。因此，某人以遗赠名义支付的财物，不视为归其取得；若遗产负有债务或其他遗产负担，也应认为相应财物并未归其取得。另一方面，衡平亦要求出卖人交付出售前已赠与之物的价款。

<!-- source-p 11 -->
<a id="18.4.2.4"></a>**4.**不仅遗产出卖人从遗产中取得的财物应交付买受人，其继承人从遗产中取得的财物也应交付买受人；不仅已经取得的财物如此，将来取得的财物亦应交付。

<!-- source-p 12 -->
<a id="18.4.2.5"></a>**5.**如果出卖人或其继承人以恶意行为致使财物未能归其取得，也必须向买受人负责。凡出卖人处分了某物、以受领免除使某债务人免责、恶意阻止遗产取得某项财产，或恶意阻止取得本可取得的占有，均视为其恶意阻止财物归其取得。即使并非恶意，而是出卖人有重大过失，也应承担责任；但因出卖人无恶意而灭失或减少的财物，不在赔偿之列。

<!-- source-p 13 -->
<a id="18.4.2.6"></a>**6.**有人问：遗产出卖人是否应就其处于家父权下的家子或其奴隶对被继承人所负的债务，向买受人承担责任？对此认为，只有在查明债务来自家子或奴隶的特有产，或用于家父本人事务的范围内，出卖人才应承担责任。

<!-- source-p 14 -->
<a id="18.4.2.7"></a>**7.**通常还会问：遗产出卖人因遗产而取得任何利益，是否应返还买受人？尤利安在《学说汇纂》第六卷讨论过这个问题。他说，继承人收取了本不应收取的款项（底本异文：*non debitum [debitur] exegerit*），可以保留；支付了本不应支付的款项，也不得请求买受人补偿。因为应当遵循的规则是：继承人既不向买受人交付其不应收取的款项，也不向买受人追偿其不应支付的款项。但如果继承人经判决而付款，只要能够证明其并非因自身欺诈而受判决，就足以将该支出列入遗产账目；即使判决认定的债权人事实上并非债权人，也不影响这一点。我赞同这一意见。

<!-- source-p 15 -->
<a id="18.4.2.8"></a>**8.**应当认为，出卖人不仅须向买受人移转遗产所生的诉权，也须移转继承人本人设定的债务关系。因此，如果继承人从遗产债务人处接受了保证人，就应向遗产买受人移转自己所享有的诉权；如果继承人更新了债务，或已将诉权提交诉讼审理，也应移转其因此取得的诉权。

<!-- source-p 16 -->
<a id="18.4.2.9"></a>**9.**正如遗产的一切收益归遗产买受人，损失也应由同一买受人承担。

<!-- source-p 17 -->
<a id="18.4.2.10"></a>**10.**例如，继承人出售遗产中的某物，并因此被判承担责任，他无权向遗产买受人起诉，因为他被判承担责任，并非由于其继承人身份，而是由于其出售了该物。但如果他将出售该物所得价款交给遗产买受人，则应考察他是否可以提起出卖之诉；我认为可以。

<!-- source-p 18 -->
<a id="18.4.2.11"></a>**11.**无论是遗产出卖人本人、其代理人，还是为其处理事务的其他人，只要有人为该遗产支出了款项，就可以提起出卖之诉；但前提是遗产出卖人确有财产损失。若出卖人没有任何损失，就不能认为其享有诉权。

<!-- source-p 19 -->
<a id="18.4.2.12"></a>**12.**尤利安记载：遗产出卖人保留了一名不带特有产的奴隶，后来因该奴隶的特有产及其用于家父事务的财物而被起诉。出卖人只能就其因该奴隶特有产中应由买受人承担的部分，或用于被继承人事务的部分所支付的款项，向买受人追偿；因为在这些情形中，他偿付的是买受人的债务。其余情形下，他是以自己的名义被判承担责任。

<!-- source-p 20 -->
<a id="18.4.2.13"></a>**13.**那么，如果遗产出卖人保留了一名带有特有产的奴隶，因特有产之诉而被起诉并付款，又应如何处理？马尔凯卢斯在《学说汇纂》第六卷中写道：如果双方约定特有产中剩余的财物归出卖人所有，他不得请求返还所付款项；但若双方作了相反约定，他可以正当地请求返还。如果双方没有明示约定，只是提到特有产，那么显然不产生出卖之诉。

<!-- source-p 21 -->
<a id="18.4.2.14"></a>**14.**如果遗产出卖人将一幢房屋保留给自己，而该房屋曾就可能发生的损害订立担保口约，则须考察双方约定的内容。如果出卖人保留房屋时也约定由自己承担该担保口约的责任，他便不能向买受人追偿；如果双方约定由买受人清偿这项债务，则该担保口约的负担应由买受人承担。若无法查明双方的约定，较可能的理解是：出售前已经发生的损害由买受人承担；此后发生的损害则由继承人承担。

<!-- source-p 22 -->
<a id="18.4.2.15"></a>**15.**提提乌斯将梅维乌斯的遗产出售给塞伊乌斯，后来提提乌斯成为塞伊乌斯的继承人，又将该遗产出售给阿提乌斯。是否可以依据先前的遗产买卖向阿提乌斯起诉？尤利安说：遗产出卖人本可向任何第三人的继承人请求的，均可向遗产买受人请求。确实，如果塞伊乌斯另有继承人，遗产出卖人因梅维乌斯遗产而承担的一切，都可以依据出卖之诉向该继承人追偿。同样，如果我向塞伊乌斯约定：若某奴隶被追夺，我将支付双倍价款；后来我成为塞伊乌斯的继承人，并将该遗产出售给提提乌斯，那么该奴隶被追夺时，我仍可向提提乌斯请求赔偿。

<!-- source-p 23 -->
<a id="18.4.2.16"></a>**16.**如果遗产出卖人以公共税赋名义支付了款项，应当认为买受人须予承受，因为这类费用也是遗产负担。若出卖人支付了任何赋税，也应作同样处理。

<!-- source-p 24 -->
<a id="18.4.2.17"></a>**17.**如果继承人在举行葬礼后才出售遗产，能否向买受人请求葬礼费用？拉贝奥认为，买受人应支付葬礼费用，因为这也是遗产支出。雅沃勒努认为这一意见正确，我也赞同。

<!-- source-p 25 -->
<a id="18.4.2.18"></a>**18.**某人继承了自己债务人的遗产后，因债权债务混同而不再是债权人。但如果他出售遗产，遗产买受人取代继承人的地位，公平地说，应对遗产出卖人承担责任：无论被继承人在死亡时所负的债务如何——即使出卖人接受遗产后，该债务因混同而消灭——还是尚待将来清偿的债务，或附条件且后来条件成就的债务，均应如此。不过，前提是继承人原本可以就该债务提起诉讼；若某项事由使对继承人的诉讼不能成立，也不得仅因此转而起诉买受人。

<!-- source-p 26 -->
<a id="18.4.2.19"></a>**19.**指定继承人接受遗产后丧失了地役权的，也可以依据出卖之诉向买受人起诉，请求将地役权恢复给自己。

<!-- source-p 27 -->
<a id="18.4.2.20"></a>**20.**即使遗产出卖人尚未实际履行，但只要其因遗产而负有任何名义下的债务，他仍可以向买受人提起诉讼。

出卖人经订立口约后追索到遗产中的某物，又将该物出售给他人。问题是，他应依据口约交付什么：因为口约不可能被触发两次，使其既须交付该物，又须交付价款。如果出卖人在出售该物之后才订立口约，我们认为口约所指的是价款；但如果先订立口约，之后才取得该物，他就应交付该物。那么，如果他出售的是一名奴隶，而该奴隶后来死亡，他是否应交付其价款？如果斯提库斯的承诺人将奴隶出售后，奴隶在没有迟延的情况下死亡，那么该承诺人本不应支付价款。但在遗产已经出售、继承人随后又出售遗产中的某物时，可以认为他是在处理买受人的事务，而不只是出售遗产中的单项财物。对于单项财物，却不能作同样认定：例如，我把同一奴隶卖给你，在尚未交付前又卖给他人并收取价款；奴隶死亡后，我们要考察我是否无需依据买卖关系对你承担责任，因为我交付并未迟延——出售奴隶所得价款并非来自该物本身，而是来自交易；这种情形可以视同我未曾另行出售给他人。毕竟，我对你负有交付该物的义务，而非交付一项诉权。但遗产出售时，似乎默示约定：继承人凡以继承人身份实施的行为，都应向买受人负责，如同是在处理买受人的事务。这正如土地出卖人基于诚信原则应交付孳息；即使其把土地当作他人之物而疏于管理，除非能够证明其有过失，否则也不能归责于他。如果出卖人向占有人请求返还已出售之物，并取得诉讼估价额，应当交付给买受人的是价款还是该物？当然应是该物；因为我有义务向买受人交付该物，而非诉权。如果我因暴力被逐出，或依据盗窃之诉取得双倍赔偿，这与买受人无关。另一方面，如果出卖人并无过失而不再占有该物，他应交付自己的诉权，而非该物；因此也应交付其取得的估价额。正如建筑物焚毁后，仍应交付其所在的土地。

你出售了科尔内利乌斯的遗产；随后，阿提乌斯——科尔内利乌斯曾以你为继承人而向他作出遗赠——在尚未从买受人处取得遗赠之前，使你成为继承人。我认为，你可以正当地依据出卖之诉请求买受人向你交付该遗赠，因为遗产售价之所以降低，正是由于买受人承担了支付该遗赠的义务。至于该笔款项原本应支付给使你成为继承人的阿提乌斯，还是应支付给遗赠受领人，并无区别。
