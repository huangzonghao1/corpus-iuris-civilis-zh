## 18.7.0　论奴隶输出；以及以奴隶应予释奴为条件出售，或以相反条件出售（*De servis exportandis: vel si ita mancipium venierit ut manumittatur vel contra*）

### <a id="18.7.1"></a>18.7.1　乌尔比安《评告示》第三十二卷

如果奴隶被出售时附有不得在某地停留的条件，出卖人处于可以免除该条件的地位，并可自行将奴隶留在罗马。帕比尼安在《答复》第三卷中也作了同样答复：他说，为保障主人的安全而设置该条件，是为了使其免于遭受危险。

### <a id="18.7.2"></a>18.7.2　马尔西安《论公法》第二卷

奴隶若以输出意大利为目的而出售，可以留在行省内，除非有特别禁令。

### <a id="18.7.3"></a>18.7.3　保罗《评告示》第五十卷

如果某人出售奴隶时约定，应在确定期限内将其释奴；若未在期限内释奴，只要出卖人仍坚持原有意愿，该奴隶即成为自由人；无须查明其继承人的意愿。

### <a id="18.7.4"></a>18.7.4　马尔凯卢斯《学说汇纂》第二十四卷

未满二十岁的人若为使你将奴隶释奴而将其出售并交付给你，该交付不发生效力；即使他有意等到自己满二十岁时再释奴，亦同。延后履行解放义务并无多大差别：法律所阻止的，毕竟是其近乎欠缺充分判断能力时所作的决定。

### <a id="18.7.5"></a>18.7.5　帕比尼安《问题集》第十卷

如果依出卖人的约定，某人不得进入任何城市的城界（*pomerium*），似乎也应认为其不得进入该城市。此规则固然有时是依据皇帝敕令作出的规定，但也有其自然的道理：不得使一个已被排除在较小范围之外的人，反而享有较大范围内的自由。〔此句中“较小／较大”的所指及规则适用范围，底本文义尚不完全明确。〕

### <a id="18.7.6"></a>18.7.6　帕比尼安《问题集》第二十七卷

<a id="18.7.6.pr."></a>

**序言（pr.）** 如果出卖人要求买受人作出约定，不得释奴，也不得使女奴卖淫；而女奴因某种违反该约定的行为，经裁判取得自由或被判定为自由人，出卖人又依据要式口约请求支付罚金，有些人认为买受人可以提出诈欺抗辩，萨宾努斯则认为不能提出。但依其理由，如果约定的是不得释奴，该口约在法律上就不发生效力：因为难以置信的是，双方所考虑的会是释奴行为本身，而不是这一恩惠所产生的结果。至于约定不得使其卖淫的情形，则没有理由认为罚金不应请求并执行；买受人既使女奴蒙受侮辱，也可能伤害出卖人的感情，甚至同时损害其体面。事实上，即使没有要式口约，若买受人作为或不作为违反买卖约款，通常也承认可以提起买卖之诉。

<a id="18.7.6.1"></a>

**1.** 我曾一度认为，只有出卖人因对奴隶施加惩罚而具有金钱上的利益，例如他曾向他人承诺支付罚金时，才可以提起买卖之诉；否则，一个正直的人不应认为，未能满足施虐者的心愿会使出卖人蒙受损失。但萨宾努斯的意见使我转而考虑相反结论。他认为可以有效提起诉讼，因为该奴隶看来是以较低价格出售的。

### <a id="18.7.7"></a>18.7.7　帕比尼安《问题集》第十卷

奴隶出售时附有不得留在意大利的条件；双方还约定，若违反该条件，买受人即使未作要式口约，也应支付罚金。出卖人很难仅以此为由，基于报复目的提起诉讼；但若出卖人因未遵守该条件而须向他人支付其所承诺的罚金，则可以提起有用之诉。因此，其诉讼请求只能达到其被迫向他人支付的数额；超出部分属于惩罚，而非对损失的追偿。反之，如果双方约定不得为了施加惩罚而将奴隶输出，出卖人也可以基于其个人感情正当地提起诉讼。这些看法并不相互矛盾，因为使一个人受益本身就是人的利益；至于未能施加惩罚所带来的愤懑，则只包含严酷之意。

### <a id="18.7.8"></a>18.7.8　帕比尼安《问题集》第二十七卷

有人出售自己的奴隶，并命令买受人在确定期限内将其释奴，后来却改变了主意，而买受人仍将奴隶释为自由人。问题是，出卖人对此是否享有任何诉权？我答复说，奴隶一经释奴，或者出卖人改变意愿，买卖之诉即告消灭。

### <a id="18.7.9"></a>18.7.9　保罗《问题集》第五卷

提图斯出售一名奴隶时约定：如果该奴隶留在罗马，出卖人可以对其实施拘束（*manus iniectio*）。买受人又以相同条件将其转卖给他人。该奴隶从第二买受人处逃走并留在罗马。我问：是否可以对其实施拘束；如可以，谁有权实施？我答复：对于逃亡奴隶，无疑应认为并未发生违反条件的行为，因为奴隶不能将自己从主人处带走，而逃亡中的人也不属于“留在”该处。若奴隶是在第二买受人的意愿下违反条件而留在罗马，则应优先保护最初设定该条件的人；后手出卖人重复载入同一条件，更是为了提醒买受人并使自己免受其约束，因此不能以任何方式排除其出卖人所设、且已发生适用情形的条件。即使后手出卖人承诺了罚金，也仍须负责，尽管他自己也曾取得买受人的要式口约；因为在罚金承诺的情形下存在两项诉权，而拘束奴隶的权利则针对奴隶本人行使。若最初的约定是女奴一旦卖淫即成为自由人，而后手约定允许实施拘束，则自由优先于拘束。显然，若最初约定允许实施拘束，而后手约定使其自由，更可取的意见是该奴隶应成为自由人；因为两项条件均是为该奴隶而附加，正如拘束奴隶一样，赋予自由也能排除对其的侵害。

### <a id="18.7.10"></a>18.7.10　谢沃拉《学说汇纂》第七卷

出售潘菲拉和斯提库斯时，出卖人在买卖中加入协议：这两名奴隶——出卖人已以降低价格的方式出售——除塞尤斯之外，不得服侍他人；塞尤斯死后，他们应处于自由状态。问题是，买受人与出卖人就此达成协议的奴隶，是否在买受人死亡后依法当然获得自由？答复说，根据神圣哈德良皇帝就此颁布的敕令，所询问的潘菲拉和斯提库斯若未经释奴，并非自由人。克劳狄乌斯按语：神圣马尔库斯皇帝规定，依出售时明示的自由条款，即使奴隶未被释奴，也将在六个月内成为自由人；尽管出卖人将自由的实现推迟至买受人死亡之时。〔底本末句作 *in semenstribus*；此处暂按“六个月内”译，词形及具体起算点仍须核校。〕
