<!-- source-p 0830 -->

<!-- source-p 0833 -->
要式免债行为也可以这样作成：“你将十视为已收讫吗？”对方回答：“我视为已收讫。”

<!-- source-p 0834 -->
<a id="46.4.8"></a>**46.4.8**

<!-- source-p 0835 -->
乌尔比安《萨宾评注》第48卷。

<!-- source-p 0836 -->
<a id="46.4.8.pr."></a>**序言**　有人问：无效的要式免债行为是否仍可能构成有效的协议？若双方的意思并未相反，也仍然构成协议。有人会说，双方可能没有合意吗？当然可能。假设一方明知要式免债行为无效，仍故意表示接受；谁会怀疑双方没有订立协议的合意，因此不成立协议？

<!-- source-p 0837 -->
<a id="46.4.8.1"></a>**1**　共有奴隶既可以向其中一名所有人提出要式口约，也可以请求其中一名所有人作成要式免债行为；该所有人可以因此对全部债务免责。奥克塔韦努斯持此见解。

<!-- source-p 0838 -->
<a id="46.4.8.2"></a>**2**　共有奴隶也可以从一名所有人处接受免债，以使另一名所有人免责；拉贝奥也赞同这一点。他在《可采规则集》中记载：若奴隶先向第一名所有人提出要式口约、再向第二名共同所有人提出，奴隶可以请求第二名所有人作成要式免债行为，从而使第一名所有人免责——第一名所有人原本正是由该奴隶使其负债的。这样，同一奴隶便可以设立并消灭债务。

<!-- source-p 0839 -->
<a id="46.4.8.3"></a>**3**　只有以言辞成立的债务才能以要式免债行为消灭；因为要式免债行为消灭的是言辞债务，而其自身也通过言辞作成。以言辞不能消灭并非以言辞成立的债务。

<!-- source-p 0840 -->
<a id="46.4.8.4"></a>**4**　家子作出允诺，并不会依市民法使父亲负债，而是使家子自己负债。因此，家子可以请求免债，以使自己免责，因为负债者是他；父亲请求免债则毫无效力，因为父亲本人并不负债，负债的是家子。奴隶也应适用同一规则：奴隶可以通过免债免责；若存在针对主人的裁判官法债务，也一并消灭。我们采用此规则，是因为要式免债行为属于万民法。因此，我认为也可以用希腊语作成免债，只要依照拉丁语形式进行：“*exeis labōn dynaria tosa; exō labōn*”，即“你已收讫这些钱币了吗？我已收讫”。

<!-- source-p 0841 -->
<a id="46.4.9"></a>**46.4.9**

<!-- source-p 0842 -->
保罗《萨宾评注》第12卷。

<!-- source-p 0843 -->
要式口约债务可以部分免除，不仅可以这样询问：“我向你允诺的十中，你收讫五了吗？”，也可以这样询问：“我向你允诺的一切，你是否免除其中一半？”

<!-- source-p 0844 -->
<a id="46.4.10"></a>**46.4.10**

<!-- source-p 0845 -->
庞波尼《萨宾评注》第26卷。

<!-- source-p 0846 -->
若要式口约的标的不是钱款，而是某一特定物，例如一名奴隶，也可以部分作成要式免债行为；同理，也可以只对其中一名继承人作成免债。

<!-- source-p 0847 -->
<a id="46.4.11"></a>**46.4.11**

<!-- source-p 0848 -->
保罗《萨宾评注》第12卷。

<!-- source-p 0849 -->
<a id="46.4.11.pr."></a>**序言**　使主人摆脱债务关系，是一种取得利益的方式。因此，用益权人之奴隶也可以通过请求用益权人作成免债，使后者免责，因为这似乎是为后者的利益取得权利。若我们仅享有使用权，也适用同一规则。对为我们善意服役的人，以及其他受我们权力支配的人，也应作同样处理。

<!-- source-p 0850 -->
<a id="46.4.11.1"></a>**1**　若我免除奴隶本人向我允诺的债务，我对主人享有的裁判官法诉权也将失去效力；这些诉权原本是基于特有产或利益归入而产生的。

<!-- source-p 0851 -->
<a id="46.4.11.2"></a>**2**　遗产中的奴隶若在继承人接受遗产前，请求免除被继承人所允诺的债务，我认为更妥当的看法是债务确已消灭，从而使遗产本身免责。

<!-- source-p 0852 -->
<a id="46.4.11.3"></a>**3**　若主人被敌人俘获，也应认为依归还原状原则确认了要式免债行为的效力；因为奴隶也可以向身处敌境的主人提出要式口约。

<!-- source-p 0853 -->
<a id="46.4.12"></a>**46.4.12**

<!-- source-p 0854 -->
庞波尼《萨宾评注》第26卷。

<!-- source-p 0855 -->
附期限或附条件的债务也可以通过要式免债行为消灭；但只有在条件成就或期限届至时，才能看出该行为已经发生效力。

<!-- source-p 0856 -->
<a id="46.4.13"></a>**46.4.13**

<!-- source-p 0857 -->
乌尔比安《萨宾评注》第50卷。

<!-- source-p 0858 -->
<a id="46.4.13.pr."></a>**序言**　较妥当的见解是：经自由人以宣誓方式承担的劳务债务，也可以通过要式免债行为消灭。

<!-- source-p 0859 -->
<a id="46.4.13.1"></a>**1**　若要式口约所包含的标的不能分割，要式免债行为部分作成便不发生效力，例如乡村或城市地役权便是如此。显然，若要式口约标的是用益权，例如提提乌斯土地的用益权，则可以部分免债，剩余部分土地的用益权仍然存在。但若有人允诺通行道路，而债权人仅免除步行权或驱赶牲畜通行权，要式免债行为便不发生效力；若仅免除驱赶牲畜通行权，也应作同样认定。反之，若步行权与驱赶牲畜通行权均已免除，则应认定允诺道路通行权的人已获免责。

<!-- source-p 0860 -->
<a id="46.4.13.2"></a>**2**　有一点是确定的：就土地用益权或道路通行权作出要式口约的人，若以免债方式免除该权利，免债并不生效。因为作出免债的人，必须就其所允诺的全部或一部分作出免债；而这些并非可分的部分，正如有人允诺一幢房屋，却只免除其中的水泥、窗户、墙壁或房间，并不构成有效免债。

<!-- source-p 0861 -->
<a id="46.4.13.3"></a>**3**　若有人曾允诺用益权，而后以免债方式免除“使用权”：倘若其意在免除作为独立使用权的使用，则不发生免责；倘若其意在免除用益权中的使用——因为使用权本可不伴随收益权而单独设立——则应认定要式免债行为有效。

<!-- source-p 0862 -->
<a id="46.4.13.4"></a>**4**　允诺交付一名奴隶的人，若以免债方式免除斯提库斯，尤利安在《学说汇纂》第54卷中写道：该免债行为产生了一定效力，并消灭了全部债务；因为债务人可以在债权人反对的情况下交付的标的，也可以通过债权人接受免债而使其免责。

<!-- source-p 0863 -->
<a id="46.4.13.5"></a>**5**　公认的是，允诺一块土地的人不能以免债方式免除关于恶意的条款；因为该条款并非债务的一部分，所负担的债务与免除的事项并不相同。

<!-- source-p 0864 -->
<a id="46.4.13.6"></a>**6**　若有人附条件允诺“斯提库斯或十”，而债权人以免债方式免除斯提库斯，随后在条件尚未成就时斯提库斯死亡，则十仍然处于债务关系之中，犹如从未作成要式免债行为。

<!-- source-p 0865 -->
<a id="46.4.13.7"></a>**7**　若保证人获得免债，而主债务人承担的是实物债务而非言词债务，主债务人是否也免责？我们采用的法律规则是：即使主债务人并未以言词方式负债，也仍可因对保证人作成免债而免责。

<!-- source-p 0866 -->
<a id="46.4.13.8"></a>**8**　若保证人已就附条件遗赠提供担保，而后获得免债，则遗赠所附条件成就时，该遗赠仍应给付。

<!-- source-p 0867 -->
<a id="46.4.13.9"></a>**9**　某人向保证人作如下要式口约：“你是否以你的信用担保我将贷与提提乌斯的一切款项？”在实际放贷之前，他便免除了该保证人的责任。主债务人并不因此免责；一旦向主债务人放款，他仍须承担责任。因为即便我们认为保证人须待款项贷与主债务人后才获免责，主债务人也不可能因早于其债务成立时作成的免债而获免责。

<!-- source-p 0868 -->
<a id="46.4.13.10"></a>**10**　监护人不能代被监护人免债；精神失常者的保佐人也不能；代理人同样不能作成免债。然而，这些人都可以（且有权）使债务更新，然后再作成免债。前述人等本身也不能直接接受免债，但在债务更新后，可以通过要式免债行为使债务人免责。我们通常也以此方法处理缺席者的债务：我们向某人作成要式口约，以更新缺席者所欠我们的债务，随后使我们所向其作成要式口约的人免责。如此一来，缺席者因债务更新而免责，在场者则因免债而免责。

<!-- source-p 0869 -->
<a id="46.4.13.11"></a>**11**　继承人可以接受免债并使他人免责；荣誉继受人亦同。

<!-- source-p 0870 -->
<a id="46.4.13.12"></a>**12**　在数名共同债务人中，若其中一人接受免债，则全部债务均告消灭。

<!-- source-p 0871 -->
<a id="46.4.14"></a>**46.4.14**

<!-- source-p 0872 -->
保罗《萨宾评注》第12卷。

<!-- source-p 0873 -->

<a id="46.4.15"></a>**46.4.15**

<!-- source-p 0875 -->
庞波尼《萨宾评注》第27卷。

<a id="46.4.16"></a>**46.4.16**

<a id="46.4.16.pr."></a>**序言**　若数名负债人中的一人获得免债，不仅该人本人免责，与其共同负有同一债务的人也一并免责。因为在两个或多个共同承担同一债务的人中，一人获得免债，其他人也会免责；这并非因为免债直接给予了他们，而是因为看起来，获得免债的人仿佛已经清偿了债务。

<!-- source-p 0880 -->
<a id="46.4.16.1"></a>**1**　若某人提供了判决债务保证人，且该保证人获得免债，已受判决约束的债务人也将免责。

<!-- source-p 0904 -->
<a id="5"></a><a id="46.5"></a>**46.5.0**　论裁判官法上的要式口约。

<!-- source-p 0905 -->
<a id="46.5.1"></a>**46.5.1**

<!-- source-p 0906 -->
乌尔比安《告示评注》第70卷。

<!-- source-p 0907 -->
<a id="46.5.1.pr."></a>**序言**　裁判官法上的要式口约似可分为三类：裁判上的、担保性的以及共同的。

<!-- source-p 0908 -->
<a id="46.5.1.1"></a>**1**　所谓裁判上的要式口约，是指因诉讼而作成者，例如为确保追认而作成的要式口约、判决债务担保，以及因新工程告示而作成的要式口约。

<!-- source-p 0909 -->
<a id="46.5.1.2"></a>**2**　担保性要式口约则具有诉权的功能，其目的在于产生新的诉权，例如有关遗赠、监护、确保追认以及防止损害的要式口约。

<!-- source-p 0910 -->
<a id="46.5.1.3"></a>**3**　共同要式口约，是为确保当事人到庭而作成的要式口约。

<!-- source-p 0911 -->
<a id="46.5.1.4"></a>**4**　还应知悉，所有要式口约依其性质均具有担保性；作成要式口约的目的，正是使某人因该要式口约而获得更周全、更可靠的保障。

<!-- source-p 0912 -->
<a id="46.5.1.5"></a>**5**　这些裁判官法上的要式口约，有些要求提供担保（*satisdatio*），有些只要求作出允诺（*repromissio*）。仅要求单纯允诺的情形极少；逐一列举后，即可看出其他要式口约要求的并非单纯允诺，而是担保。

<!-- source-p 0913 -->
<a id="46.5.1.6"></a>**6**　因此，因新工程告示而作成的要式口约，有时要求提供担保，有时只要求允诺。应依新工程告示所涉及的工程，判断是否须提供担保以及如何提供担保。对于在私人土地上建造的工程，应提供担保；对于在公共土地上建造的工程，则应作出允诺。但以自己名义提供保障的人只须允诺，以他人名义提供保障的人则须提供担保。

<!-- source-p 0914 -->
<a id="46.5.1.7"></a>**7**　同样，基于防止损害的事由，有时只须允诺，有时则须提供担保：若工程涉及公共河流中的事项，应提供担保；若涉及房屋，则只须允诺。

<!-- source-p 0915 -->
<a id="46.5.1.8"></a>**8**　关于双倍价额的要式口约，原则上只须允诺，除非当事人约定应提供担保。

<!-- source-p 0916 -->
<a id="46.5.1.9"></a>**9**　若发生争议，例如有人声称对方以诬告为由要求作成要式口约，裁判官本人应就此事作简要审查，并命令提供担保或拒绝该请求。

<!-- source-p 0917 -->
<a id="46.5.1.10"></a>**10**　若要式口约中有任何内容需要增补、删除或变更，也属于裁判官的管辖权。

<!-- source-p 0918 -->
<a id="46.5.2"></a>**46.5.2**

<!-- source-p 0919 -->
保罗《告示评注》第73卷。

<!-- source-p 0920 -->
<a id="46.5.2.pr."></a>**序言**　裁判官法上的要式口约，或包含返还标的物的义务，或包含不确定的金额。

<!-- source-p 0921 -->
<a id="46.5.2.1"></a>**1**　例如，因新工程告示而作成的要式口约，约定应恢复原状。因此，无论原告还是被告在留下数名继承人后死亡，只要其中一人胜诉或败诉，整个工程都必须恢复原状；因为只要尚有任何部分未恢复，就不能认为工程已经恢复原状。

<!-- source-p 0922 -->
<a id="46.5.2.2"></a>**2**　判决债务担保、确保权利人追认的要式口约、防止损害的要式口约及类似要式口约，包含不确定金额。有人认为，此类要式口约应按继承人人数分割，尽管也可以说，允诺人所承担的要式口约既由被继承人传下，便不应使各继承人处于不同地位。然而，基于相当有力的理由，反过来认为：若作成要式口约的权利人的一名继承人胜诉，则要式口约仅在该继承人的份额内发生效力；这是因为要式口约使用了“该事项价值若干”的措辞。尤利安写道，若允诺人的一名继承人占有全部标的物，则应判令其就全部标的承担责任。然而，他本人依该要式口约是否承担责任，或者保证人是否承担责任，乃至是否根本不承担责任，仍有疑问；尤利安说，应考虑要式口约是否根本未发生效力。但若占有人在争讼程序确定后死亡，即使某一继承人占有全部土地，也不得判令其承担超过其继承份额的责任。

<!-- source-p 0923 -->

乌尔比安《告示评注》第79卷。

概而言之，在所有裁判官法上的要式口约中，也应为代理人提供担保。

<a id="6"></a><a id="46.6"></a>**46.6.0**　确保未适婚人或青年的财产无损。

<!-- source-p 0952 -->
<a id="46.6.1"></a>**46.6.1**

<!-- source-p 0953 -->

<!-- source-p 0954 -->

<!-- source-p 0955 -->
<a id="46.6.2"></a>**46.6.2**

<!-- source-p 0956 -->

<!-- source-p 0957 -->

<!-- source-p 0958 -->
<a id="46.6.3"></a>**46.6.3**

<!-- source-p 0959 -->
乌尔比安《告示评注》第35卷。

<!-- source-p 0960 -->
（或者，裁判官应指定某人接受担保。）

<!-- source-p 0961 -->
<a id="46.6.4"></a>**46.6.4**

<!-- source-p 0962 -->
乌尔比安《告示评注》第79卷。

<!-- source-p 0963 -->
<a id="46.6.4.pr."></a>**序言**　这并不是说债务依法律本身即归于未适婚人（因为并非如此），而是要使未适婚人能够基于要式口约提起准诉讼。

<!-- source-p 0964 -->
<a id="46.6.4.1"></a>**1**　应以提供担保的方式，通过该要式口约保护未适婚人。

<!-- source-p 0965 -->
<a id="46.6.4.2"></a>**2**　应知悉，该要式口约既约束监护人，也约束曾经或正在以监护人身份处理事务的人，以及他们的保证人。

<!-- source-p 0966 -->
<a id="46.6.4.3"></a>**3**　但从未处理事务的人完全不承担责任；因为即使提起监护人诉讼，该人也不受其约束。不过，由于他自行承担风险而不履行职责，应通过准诉权起诉他。然而，既不能基于要式口约起诉他，他的保证人也不承担责任。因此，应强令其履行管理职责，以便他也能受该要式口约约束。

<!-- source-p 0967 -->
<a id="46.6.4.4"></a>**4**　通说认为，只有监护关系终止后，该要式口约才发生效力；保证人的履行期限也从此时开始计算。保佐人的情形则有所不同；曾经以监护人身份处理事务者，也应另作处理。因此，若某人曾任监护人，该等要式口约只有在监护终止后才生效；若某人曾以监护人身份处理事务，则应当认为，一旦未适婚人的某项财产开始不能保持完整，该要式口约即发生效力。

<!-- source-p 0968 -->
<a id="46.6.4.5"></a>**5**　若监护人被敌人俘获，该要式口约是否发生效力？我们应当考虑这一问题。尽管仍期待监护人归还，但监护关系已经终止；我认为可以提起诉讼。

<!-- source-p 0969 -->
<a id="46.6.4.6"></a>**6**　一般而言，应知悉：凡我们认为不能提起监护人诉讼的事由，同样应认为不能基于确保财产无损的要式口约提起诉讼。

<!-- source-p 0970 -->
<a id="46.6.4.7"></a>**7**　若被指定的保佐人并未履行保佐职责，应当认为该要式口约不发生效力；但此处应适用我们对监护人所说的规则，区别仅在于：保佐人的该项要式口约一旦有任何财产不再安全，便立即发生效力，保证人的履行期限亦随之起算；不过，期限将不断重新起算。

<!-- source-p 0971 -->
<a id="46.6.4.8"></a>**8**　该要式口约适用于所有因年龄尚幼而为适婚人或未适婚人指定的保佐人，也适用于为挥霍者、精神失常者或其他人（通常亦会为其指定保佐人）指定的保佐人。

<!-- source-p 0996 -->
<a id="7"></a><a id="46.7"></a>**46.7.0**　判决清偿担保。

<!-- source-p 0997 -->
<a id="46.7.1"></a>**46.7.1**

<!-- source-p 0998 -->
保罗《告示评注》第24卷。

<!-- source-p 0999 -->
判决作出后，判决清偿要式口约的履行期限即刻届至，但请求实际履行的时间，应推迟至给予主债务人的期限届满。

<!-- source-p 1000 -->
<a id="46.7.2"></a>**46.7.2**

<!-- source-p 1001 -->
保罗《告示评注》第71卷。

<!-- source-p 1002 -->
诉讼因当事人死亡而消灭时，标的事项亦不复存在；因此，公认保证人不因判决清偿要式口约而承担责任。

<!-- source-p 1003 -->
<a id="46.7.3"></a>**46.7.3**

<!-- source-p 1004 -->
乌尔比安《告示评注》第77卷。

<!-- source-p 1005 -->
<a id="46.7.3.pr."></a>**序言**　若某人在准备向一位法官起诉时作成判决清偿要式口约，却转而向另一位法官起诉，该要式口约不发生效力，因为保证人并未承诺承担这另一位法官所作判决的责任。

<!-- source-p 1006 -->
<a id="46.7.3.1"></a>**1**　代理人、监护人和保佐人都可以作成判决清偿要式口约。

<!-- source-p 1007 -->
<a id="46.7.3.2"></a>**2**　我们应将受有委任者视为代理人，无论其只接受了处理此事的委任，还是接受了管理全部财产的委任。若代理行为后来获得追认，该人也视为代理人。

<!-- source-p 1008 -->
<a id="46.7.3.3"></a>**3**　若子女或父母中的某人，或丈夫代表妻子出面，而他们无需出示委任，是否会使要式口约发生效力？较妥当的看法是：除非委任了他们，或追认其行为，否则要式口约不应生效。裁判官告示准许他们实施某些行为，并不会使他们成为代理人。因此，若由此类人出面，应重新提供担保。

<!-- source-p 1009 -->
<a id="46.7.3.4"></a>**4**　我们关于监护人所说的规则，也应作如下理解：若某人并非监护人，只是处理了监护事务，就不属于“监护人”这一称谓所涵盖的范围。

<!-- source-p 1010 -->
<a id="46.7.3.5"></a>**5**　若某人确实是监护人，但并非以监护人身份管理事务（无论是因为他对此并不知情，还是出于其他原因），则应认为要式口约不发生效力；因为裁判官告示只准许由父母、监护人多数或拥有相应管辖权者指定的监护人提起诉讼。

<!-- source-p 1011 -->
<a id="46.7.3.6"></a>**6**　我们所说的保佐人，包括男性或女性精神失常者、男性或女性未适婚人，以及其他人的保佐人，例如青年的保佐人；若其为其他任何人担任保佐人，我认为要式口约也会发生效力。

<!-- source-p 1012 -->
<a id="46.7.3.7"></a>**7**　若某人被指定为某地区、某行省或意大利事务的监护人，应当认为：只有在其就属于该管理职责范围的事由提起诉讼时，要式口约才发生效力。

<!-- source-p 1013 -->
<a id="46.7.3.8"></a>**8**　若被告在作成判决清偿允诺后变为精神失常，是否会因无人应诉而使要式口约发生效力？这一问题有待讨论。较妥当的看法是：若无人为其应诉，要式口约即发生效力。

<!-- source-p 1014 -->
<a id="46.7.3.9"></a>**9**　只要仍可能有人为其应诉，要式口约就不会因无人应诉而发生效力。

<!-- source-p 1015 -->

<!-- source-p 1018 -->

<a id="46.7.5.pr."></a>**序言**　即使已经接受诉讼的保证人被判承担责任，主债务人此后再承担应诉也无济于事；但若在判决作出后债务已经清偿，我们会准许请求返还已支付款项。

<!-- source-p 1022 -->
<a id="46.7.5.1"></a>**1**　若有数名保证人或继承人，其中一人不愿应诉，其他一人可以承担应诉。

<!-- source-p 1023 -->
<a id="46.7.5.2"></a>**2**　在此要式口约中，多个事由被合并为同一金额；因此，若要式口约因其中一项事由立即发生效力，就不能再因另一项事由再次发生效力。

<!-- source-p 1024 -->
<a id="46.7.5.3"></a>**3**　现在我们应考察，为使要式口约不发生效力，要求何种应诉，以及哪些人可以应诉。若告示列明的人之一接替应诉，显然应认为该事项已得到妥善应诉，要式口约不发生效力。若由告示所列范围以外的人出面应诉，只要该人愿意按照善良家父的判断妥善应诉，即提供担保，要式口约同样不发生效力；因为提供担保即表明其愿意应诉。反之，若其仅表示愿意出面而未提供担保，且未获准应诉，该要式口约便因无人应诉而发生效力。若有人准许此人应诉，无论其是否提供担保，均应认为要式口约任何部分都不发生效力，因为准许此种应诉者应自负其责。

<!-- source-p 1025 -->
<a id="46.7.5.4"></a>**4**　若已提供判决清偿担保的保证人出面应诉，通说认为，要式口约不会因判决事由而发生效力；其他事项也与由无关第三人出面应诉时相同。

<!-- source-p 1026 -->
<a id="46.7.5.5"></a>**5**　在此要式口约中，需要讨论的是：保证人若没有承担应诉，是否应依委任之诉承担责任。较妥当的意见是不承担责任：因为他们介入该事务，是为了保证一定金额，而他们接受的委任也只涉及此事，并不包括应诉。

<!-- source-p 1027 -->
<a id="46.7.5.6"></a>**6**　但若保证人也自行承担了应诉，他们能否提起委任之诉？若他们败诉，当然可以请求返还因判决事由而支付的款项，但不能请求诉讼费用。若他们胜诉，则可以请求诉讼费用，视同其遵循了委任，即使实际上并未依委任行事。

<!-- source-p 1028 -->
<a id="46.7.5.7"></a>**7**　但若有数名保证人愿意应诉，我们应考虑他们是否必须指定一名应诉代理人，还是只要每人就自己的份额应诉或指定一名代理人即可。较妥当的看法是：若原告要求他们指定一名代理人，而他们不予指定，则要式口约因无人应诉而发生效力。因为被告有数名继承人时，也必须指定一名代理人，以免多人分头应诉使原告遭受不便。原告的继承人则不同，他们没有义务通过一人进行诉讼。

<!-- source-p 1029 -->
<a id="46.7.5.8"></a>**8**　应知悉，只有在应当提起诉讼的地点应诉，才属于有效应诉。

<a id="46.7.13.pr."></a>**序言**　有人提出这样的问题：已作成判决清偿要式口约，某人却不为诉讼应诉，后来因未到庭而受缺席判决，是否会因判决事由使该条款发生效力？我当时认为，判决清偿要式口约以一个条款同时涵盖判决结果和无人应诉两种情形。因此，要式口约虽只有一个条款，却既适用于判决作出，也适用于未应诉；那么，若其中一种事由已使条款生效，是否还可因另一事由再次生效，确有讨论的必要。例如，有人作成如下允诺：“若船从亚洲归来，或若提提乌斯成为执政官”，公认无论船先归来，还是提提乌斯先成为执政官，要式口约都会发生效力；但若已经因先发生的事由而生效，即使另一条件随后成就，也不再因另一事由发生效力，因为要式口约所包含的是两个事由之一，而非两个事由均须发生。因此需要考察：无人应诉条款是在未应诉时即已生效，还是须等到依要式口约提起诉讼并进入诉讼系属后，才认为该条款已经生效？后一种意见较为可取。因此，在案件开始无人应诉时，保证人的履行期限似乎并不会立即届至。若必须应诉的诉讼后来因清偿、和解、要式免债行为或其他方式而终结，那么相应地，无人应诉条款也应认为失去效力。

<!-- source-p 1109 -->
<a id="46.8.8.2"></a>**2**　若某人因代理人而遭受自由身份诉讼，应要求代理人提供担保，以免此人因自己的身份而反复遭到起诉；若本人及其继受人不予追认，且代理人曾请求将该人判为奴隶，或该人曾以奴隶身份对代理人提起自由身份之诉，则在其自由身份确定后，应向其给付相当于该事项价值的金额。这包括其不再因自身身份遭受诉讼的利益，以及其为诉讼所支出的费用。但拉贝奥认为，应在担保中写明确定金额，因为自由身份的估值会无限扩张。自本人拒绝追认之时起，要式口约即视为发生效力；然而，在自由身份案件判决前不得基于该要式口约起诉，因为若判决认定其为奴隶，要式口约便失去意义；即便存在任何诉权，也应视为该诉权已由主人取得。

<!-- source-p 1156 -->
<a id="46.8.22.pr."></a>**序言**　若代理人在法院外收取了不应支付的款项，本人不予追认该清偿，却开始请求给付同一笔钱，则保证人须承担责任；若未作成该要式口约，债务人原可向代理人提起的返还之诉也随之消灭。每当款项支付给代理人而本人不追认该清偿，我认为其目的在于消灭返还之诉，使不当给付的付款人只能基于要式口约起诉代理人。除此之外，保证人还须赔偿本应在诉讼中支出的费用〔底本疑误：*fuissetentiarum*，此处疑有词间粘连或讹误，暂按上下文译〕。但若本人追认该行为，保证人即免责；付款人仍可通过返还之诉向本人请求返还同一笔钱。

<!-- source-p 1157 -->
<a id="46.8.22.1"></a>**1**　若代理人在法院外收取了本人应收的款项，法律规则相同；区别在于，若本人追认了该行为，便不得再请求返还该款项。

<!-- source-p 1158 -->
<a id="46.8.22.2"></a>**2**　若代理人经法院判决收取了不应支付的款项，可以说，无论本人是否追认，保证人都不承担责任：或者因为不存在可供本人追认的事项，或者因为追认与否并不影响要式口约权利人的利益。因此，受不利影响的是向代理人付款的人。不过，较妥当的看法是，若本人不予追认，保证人仍须承担责任。

<!-- source-p 1159 -->
<a id="46.8.22.3"></a>**3**　若代理人未经委任，经法院判决请求本人应收的款项，较妥当的看法是：若本人不予追认，保证人须就全部金额承担责任。

<!-- source-p 1160 -->
<a id="46.8.22.4"></a>**4**　若代理人依法提出请求，本人却不当行事，则代理人不应承担责任，以免本人从法官的不公中获益。法官不公绝不会使保证人承担责任。但较妥当的意见是，在此情形下，保证人仅须赔偿诉讼费用。

<!-- source-p 1161 -->
<a id="46.8.22.5"></a>**5**　马尔切鲁说，若本人未追认该行为，但在诉讼开始后丧失了标的物，追认要式口约所涵盖的仅为诉讼费用。

<!-- source-p 1162 -->
<a id="46.8.22.6"></a>**6**　尤利安说，若某人的遗产代理人在法院外收到了遗赠，除非继承人追认，否则要式口约会发生效力；当然，以该遗赠确属应付为限。此时，显然，追认要式口约权利人有利益要求继承人追认该清偿，以免同一遗赠被支付两次。

<!-- source-p 1163 -->
<a id="46.8.22.7"></a>**7**　若追认要式口约中只写明“卢基乌斯·提提乌斯是否将追认”，而当事人显然意在排除继承人及其他相关权利人的身份，则很难认为恶意条款会发生效力。但若遗漏这些人只是由于疏忽，则可以基于恶意条款提起诉讼。

<!-- source-p 1164 -->
<a id="46.8.22.8"></a>**8**　若代理人提起遗产诉讼，随后本人请求返还该遗产中的土地，追认要式口约即发生效力；因为若系真正代理人提起诉讼，既判事项抗辩就会阻止本人起诉。一般而言，若真正代理人提起诉讼会使本人的诉权依法律本身或因抗辩而失去效用，追认要式口约便会在此类情形下发生效力。

<!-- source-p 1165 -->
<a id="46.8.22.9"></a>**9**　父亲以自己名义就其子遭受殴打或击打而提起侵辱之诉时，应强令其在要式口约中也列入儿子的身份；特别是父亲可能在得知代理人已提起诉讼之前死亡，而侵辱之诉届时将归于儿子。

<!-- source-p 1166 -->
<a id="46.8.22.10"></a>**10**　若孙子遭受不法侵害，而祖父的代理人因此提起侵辱之诉，则要式口约中不仅须列入儿子的身份，也须列入孙子的身份。因为父亲和儿子都可能在得知代理人已提起诉讼之前死亡；若发生这种情形，孙子提起侵辱之诉时保证人却不承担责任，将显失公平。
