# D.46.3 论清偿与免责（*De solutionibus et liberationibus*）

<!-- source-p 0399 -->
<a id="3"></a><a id="46.3"></a>**46.3.0**　论清偿与免责。

<!-- source-p 0400 -->
<a id="46.3.1"></a>**46.3.1**

<!-- source-p 0401 -->
乌尔比安《萨宾评注》第四十三卷。

<!-- source-p 0402 -->
债务人基于数项不同原因而负有一笔债务，并予以清偿时，由付款人自行决定希望清偿哪一项债务；其所指定者即视为已经清偿，因为我们可以对所支付的款项作出明确指定。反之，若付款人没有说明款项用于清偿哪项债务，则由受领人决定将其记入哪一项债务，但须按其本人若处于债务人地位时会选择的方式指定：也就是选择一项没有争议的债务，或选择其曾为他人提供保证的债务，或选择尚未到期的债务。因为人们认为，债权人处理债务人事务，应如同处理自己的事务。因此，允许债权人指定款项清偿何项债务，但须如同处理自己的事务那样作出指定；而且必须在有关事项仍处于当前时指定，也就是款项一经清偿便立即指定：

<!-- source-p 0403 -->
<a id="46.3.2"></a>**46.3.2**

<!-- source-p 0404 -->
弗洛伦提努斯《法学阶梯》第八卷。

<!-- source-p 0405 -->
若债权人或债务人中的一方希望将款项用于另一项债务的清偿，就应在处理该债务时作出安排，使债权人仍可拒绝受领，或债务人仍可拒绝给付：

<!-- source-p 0406 -->
<a id="46.3.3"></a>**46.3.3**

<!-- source-p 0407 -->
乌尔比安《萨宾评注》第四十三卷。

<!-- source-p 0408 -->
<a id="46.3.3.pr."></a>**序言**　但此后便不再允许作出指定。由此可见，在未作指定的情况下，款项总是被视为记入较为沉重的债务；因为若处理自己的事务，债权人也会如此指定。

<!-- source-p 0409 -->
<a id="46.3.3.1"></a>**1**　若双方都没有作出指定，对于已经到期的债务，应视为清偿了到期日已经届至的那一项：

<!-- source-p 0410 -->
<a id="46.3.4"></a>**46.3.4**

<!-- source-p 0411 -->
庞波尼《论昆图斯·穆基乌斯》第十三卷。

<!-- source-p 0412 -->
清偿时，首先应归入以我自己名义所负的债务，而非我以保证人身份为他人担保的债务；应首先归入附有罚金的债务，而非不附罚金的债务；应首先归入提供了足额担保的债务，而非未提供足额担保的债务。

<!-- source-p 0413 -->
<a id="46.3.5"></a>**46.3.5**

<!-- source-p 0414 -->
乌尔比安《萨宾评注》第四十三卷。

<!-- source-p 0415 -->
<a id="46.3.5.pr."></a>**序言**　对于已经到期的数项债务，如果未加区分地支付一笔款项，通常认为该款项用于清偿较为沉重的债务；若没有哪项债务更为沉重，也就是各项债务情况相同，则用于清偿较早成立的债务。需要提供足额担保的债务，显然比单纯债务更为沉重。

<!-- source-p 0416 -->
<a id="46.3.5.1"></a>**1**　某人若提供了两名保证人，可以通过清偿使其中一名保证人免责。

<!-- source-p 0417 -->
<a id="46.3.5.2"></a>**2**　安敦尼皇帝与其已故父皇曾作复函：债权人出售质物并收回价款时，若既有已经到期的利息，也有尚未到期的利息，所支付的款项用于利息，应同时归入两类利息，即已到期与尚未到期的利息。例如，其中有些利息基于要式口约而负担，另一些则依约定仅成立自然债务。若已到期与未到期利息的总额不同，所付款项仍应平均用于两类利息，而非按比例分配，正如复函文字所显示的那样。但若利息根本不应支付，而某人只是一般性地支付了其从未以要式口约承诺的利息，安敦尼皇帝与其已故父皇复函称，该款应计入本金。该复函又补充说：“通常所确立的规则是，先将用于利息的款项记入利息；但这仅适用于债务人依法必须清偿的利息。正如依合意约定给付的利息不得请求返还一样，对于没有独立债权依据、且并未实际支付的利息，也不得仅凭受领人的意愿视为已经清偿。”

<!-- source-p 0418 -->
<a id="46.3.5.3"></a>**3**　马尔凯鲁斯在《学说汇纂》第二十卷中提出：若某人向债务人出具收据，称“收取本金及利息”，款项究竟应按比例分别冲抵本金与利息，还是应先冲抵利息，余额再冲抵本金？我毫不怀疑，这种“用于本金及利息”的收据，应先冲抵利息，其后如有剩余，再计入本金。

<!-- source-p 0419 -->
<a id="46.3.6"></a>**46.3.6**

<!-- source-p 0420 -->
保罗《论普劳提乌斯》第四卷。

<!-- source-p 0421 -->
判断时不应着眼于文书的行文顺序，而应依法律推断当事人意欲进行的事项。

<!-- source-p 0422 -->
<a id="46.3.7"></a>**46.3.7**

<!-- source-p 0423 -->
乌尔比安《萨宾评注》第四十三卷。

<!-- source-p 0424 -->
若某人既因导致名誉减损的诉因负债，也因非此类诉因负债，所付之款应视为用于清偿前一类债务。因此，若某人既因判决债务、又因非判决债务而负债，我认为所付款项应视为清偿判决债务，庞波尼也赞同此说。因此，若债务源自否认时会增加的债务，或源自罚金债务，应认为付款用于清偿附有罚金效果的那项债务。

<!-- source-p 0425 -->
<a id="46.3.8"></a>**46.3.8**

<!-- source-p 0426 -->
保罗《萨宾评注》第十卷。

<!-- source-p 0427 -->
庞波尼说，有一项记载颇为妥当：若各项债务在到期日和契约原因方面相同，则所付款项应视为按比例清偿全部债务。

<!-- source-p 0428 -->
<a id="46.3.9"></a>**46.3.9**

<!-- source-p 0429 -->
乌尔比安《萨宾评注》第二十四卷。

<!-- source-p 0430 -->
<a id="46.3.9.pr."></a>**序言**　我以要式口约约定款项可付给我或塞姆普罗尼乌斯的奴隶斯提库斯；即使塞姆普罗尼乌斯是该奴隶的主人，也不能向塞姆普罗尼乌斯本人清偿。

<!-- source-p 0431 -->
<a id="46.3.9.1"></a>**1**　欠十的人，清偿其中一部分后，就该部分免责，剩余五仍为债务。欠付斯提库斯的人，交付斯提库斯的一部分后，仍就其余部分负债。但若欠付的是一名奴隶，交付斯提库斯的一部分，仍不能免除给付一名奴隶的义务；因此，债权人仍可向其请求交付一名奴隶。不过，若债务人交付了斯提库斯的其余部分，或者债权人一方的代理人阻止其受领，则债务人免责。

<!-- source-p 0432 -->
<a id="46.3.10"></a>**46.3.10**

<!-- source-p 0433 -->
保罗《萨宾评注》第四卷。

<!-- source-p 0434 -->
我以“付给我或提提乌斯”为内容订立要式口约时，提提乌斯既不能请求给付，也不能使债务更新，亦不能作出免债承认；债务只能向他清偿。

<!-- source-p 0435 -->
<a id="46.3.11"></a>**46.3.11**

<!-- source-p 0436 -->
庞波尼《萨宾评注》第八卷。

<!-- source-p 0437 -->
若我以要式口约约定“给付我或未适婚人”，承诺人即使未经监护人授权而向未适婚人清偿，也可免除对我的债务。

<!-- source-p 0438 -->
<a id="46.3.12"></a>**46.3.12**

<!-- source-p 0439 -->
乌尔比安《萨宾评注》第三十卷。

<!-- source-p 0440 -->
<a id="46.3.12.pr."></a>**序言**　向真正的代理人清偿是有效的。所谓真正代理人，是指受特别委托者，或受托管理全部事务者。

<!-- source-p 0441 -->
<a id="46.3.12.1"></a>**1**　但有时向非代理人清偿也有效，例如某人的姓名已经列入要式口约：如有人约定“给付我或提提乌斯”。

<!-- source-p 0442 -->
<a id="46.3.12.2"></a>**2**　若某人曾委托我向提提乌斯付款，之后又禁止提提乌斯受领，而我不知该禁令仍向提提乌斯清偿，我便免责；但若我知道禁令，则不免责。

<!-- source-p 0443 -->
<a id="46.3.12.3"></a>**3**　若要式口约本身约定“给付我或提提乌斯”，则是另一种情形：即使提问人禁止我向提提乌斯清偿，我向提提乌斯付款仍可免责，因为该要式口约具有确定的约定内容，提问人不能单方面加以变更。

<!-- source-p 0444 -->
<a id="46.3.12.4"></a>**4**　即使我向不是真正代理人的人清偿，只要权利人追认该清偿，也会发生免责效果；因为追认等同于委托。

<!-- source-p 0445 -->
<a id="46.3.13"></a>**46.3.13**

<!-- source-p 0446 -->
尤利安《学说汇纂》第五十四卷。

<!-- source-p 0447 -->
权利人应当在得知此事后尽快追认。此处措辞为 *en platei*（底本释作 *id est: laxe*，“宽泛地”），并允许经过一定时间；这与讨论如何排除遗赠时的情形相同：应当承认有一段时间，既非最短也非最长，而是较适宜由理解把握、难以用言词精确表达的一段时间。

<!-- source-p 0448 -->
<a id="46.3.14"></a>**46.3.14**

<!-- source-p 0449 -->
乌尔比安《萨宾评注》第三十卷。

<!-- source-p 0450 -->
<a id="46.3.14.pr."></a>**序言**　若某人清偿时约定“若权利人不予追认，则可请求返还”，而权利人没有追认，付款人即可提起返还请求之诉。

<!-- source-p 0451 -->
<a id="46.3.14.1"></a>**1**　有几类监护人：有称为荣誉监护人的；有为提供情况而指定的；有被指定负责管理事务的。后一类可能由父亲指定一人管理，也可能由监护人们同意委托一人管理，或由裁判官作出此项安排。因此，向任何一名监护人清偿均属有效，即使是向荣誉监护人清偿亦然，因为风险也涉及他们；除非裁判官已禁止其管理事务，若已禁止，则向其清偿无效。明知有人请求将监护人认定为可疑而仍向其清偿的，也应作同样判断；因为在此期间，其管理权似乎已被暂时禁止。

<!-- source-p 0452 -->
<a id="46.3.14.2"></a>**2**　若向已被免职者清偿，等于向已经不再担任监护人的人清偿，因此付款人不免责。

<!-- source-p 0453 -->
<a id="46.3.14.3"></a>**3**　若向一名将由保佐人取代其地位的人清偿，例如被永久或暂时流放者，情况如何？我认为，若在保佐人尚未接任之前清偿，付款人应当免责。

<!-- source-p 0454 -->
<a id="46.3.14.4"></a>**4**　若向因公赴外地者清偿，清偿也有效；而且即使受领人缺席，只要尚未另行指定他人接替其职务，向其清偿亦有效。

<!-- source-p 0455 -->
<a id="46.3.14.5"></a>**5**　无论监护人是法定监护人、遗嘱指定监护人，还是经调查指定的监护人，向其中一人清偿均属有效。

<!-- source-p 0456 -->
<a id="46.3.14.6"></a>**6**　向为提供情况而指定的监护人清偿是否有效，尚须考察，因为指定此人是为了协助并指导共同监护人。但既然他也是监护人，除非已禁止向其清偿，我认为付款人即应免责。

<!-- source-p 0457 -->
<a id="46.3.14.7"></a>**7**　向精神失常者的保佐人清偿有效；向因年龄或其他正当原因而不能充分处理自己事务之人的保佐人清偿亦然。向未适婚人的保佐人清偿也显然有效。

<!-- source-p 0458 -->
<a id="46.3.14.8"></a>**8**　未适婚人未经监护人授权，显然无权清偿；但若他交付了钱币，钱币并不因此成为受领人的所有物，仍可通过所有物返还之诉请求返还。当然，若钱币已经被耗用，债务人即告免责。

<!-- source-p 0459 -->
<a id="46.3.15"></a>**46.3.15**

<!-- source-p 0460 -->
保罗《萨宾评注》第六卷。

<!-- source-p 0461 -->
未经监护人授权，不能向未适婚人清偿；未适婚人也不能委托他人受领，因为他无权处分任何财物。不过，若债务人已经向其付款且钱币仍然完整，未适婚人请求给付时，债务人可依据恶意抗辩使其请求被驳回。

<!-- source-p 0462 -->
<a id="46.3.16"></a>**46.3.16**

<!-- source-p 0463 -->
庞波尼《萨宾评注》第十五卷。

<!-- source-p 0464 -->
若债务人附条件地获得免债承认，条件成就后，应认为他自先前起便已免责。阿里斯托说，即使以实物清偿，也会出现同样结果。他曾写道：某人附条件承诺支付金钱，随后交付该款，并约定若条件成就则该款作为清偿；条件成就时，他即告免责，尽管该款此前已经成为受领人的财产。

<!-- source-p 0465 -->
<a id="46.3.17"></a>**46.3.17**

<!-- source-p 0466 -->
庞波尼《萨宾评注》第十九卷。

<!-- source-p 0467 -->
卡西乌斯说：我交给某人一笔钱，委托他替我清偿债权人；若他以自己名义付款，则我和他都不免责：我未能免责，是因为该款不是以我的名义支付；他未能免责，是因为他支付的是他人之钱。但他仍须依委托关系承担责任。反之，若债权人善意地耗用了该笔钱，以自己名义付款的人便免责；否则债权人就会不当获利。

<!-- source-p 0468 -->
<a id="46.3.18"></a>**46.3.18**

<!-- source-p 0469 -->
乌尔比安《萨宾评注》第四十一卷。

<!-- source-p 0470 -->
若有人在奴隶获释后，仍向曾被委派负责收取钱款的该奴隶付款：若债务源自主人的契约，只要付款人不知道该奴隶已获释，即足以使其免责；若债务源自特有产，即使付款人知道奴隶已获释，只要不知道其特有产已被撤回，也可免责。但在两种情形下，若获释奴隶意图侵吞该款，便构成对原主人的盗窃。又如，我曾委托自己的债务人向提提乌斯付款，之后禁止提提乌斯受领；债务人不知禁令，而提提乌斯假冒代理人受领款项，则债务人免责，提提乌斯则应承担盗窃之诉。

<!-- source-p 0471 -->
<a id="46.3.19"></a>**46.3.19**

<!-- source-p 0472 -->
庞波尼《萨宾评注》第二十一卷。

<!-- source-p 0473 -->
我的逃奴假装自由人，将从我处偷来的钱借给你。拉贝奥说，你因此对我负债；若你误以为他是自由人而向他清偿，你即免于对我负责。但若你依他的指示向他人清偿，或该人事后追认清偿，你便不免责，因为在前一种情形中，钱币会成为我的财产，并被视为已经向我清偿。因此，我的奴隶基于特有产出借金钱时，若他亲自收回借款，可以使债务人免责；若他委托他人受领或使债务更新，则不能产生同样效果。

<!-- source-p 0474 -->
<a id="46.3.20"></a>**46.3.20**

<!-- source-p 0475 -->
庞波尼《萨宾评注》第二十二卷。

<!-- source-p 0476 -->
若我以本应向你清偿、但已质押给他人的自己的物清偿，我并不免责，因为收受质押的人可以向你追回该物。

<!-- source-p 0477 -->
<a id="46.3.21"></a>**46.3.21**

<!-- source-p 0478 -->
保罗《萨宾评注》第十卷。

<!-- source-p 0479 -->
我先以要式口约向提提乌斯请求十，随后又向塞乌斯订立要式口约，约定他应给付提提乌斯未能偿还的差额；即使我已向提提乌斯请求十，塞乌斯也不会因此免责。因为提提乌斯可能虽被判决，却没有履行能力。反之，即使我先对塞乌斯起诉，提提乌斯也不会因此部分免责，因为尚不能确定塞乌斯是否负债；因此，若提提乌斯最终支付全部十，塞乌斯便显然并非债务人，因为使他负债的条件并未成就。

<!-- source-p 0480 -->
<a id="46.3.22"></a>**46.3.22**

<!-- source-p 0481 -->
乌尔比安《萨宾评注》第四十五卷。

<!-- source-p 0482 -->
家子未经父亲同意，不能免除父亲的债务人之债；他可以使父亲取得债权，却不能减损父亲的债权。

<!-- source-p 0483 -->
<a id="46.3.23"></a>**46.3.23**

<!-- source-p 0484 -->
庞波尼《萨宾评注》第二十四卷。

<!-- source-p 0485 -->
无论通过清偿，还是通过接受对我们有利的判决，我们都可能在不知情或不愿意的情况下免责。

<!-- source-p 0486 -->
<a id="46.3.24"></a>**46.3.24**

<!-- source-p 0487 -->
乌尔比安《萨宾评注》第四十七卷。

<!-- source-p 0488 -->
若保证人分别为两名债务人各保证十，他负担的保证责任总额为二十；无论其支付二十，还是分别清偿两笔十，均使两名债务人免责。若他只支付五，则应考察这五应从哪名债务人的债务中扣除：应依当事人所作的指定；若无法查明，则应看较早成立的债务。支付十五时亦同：若能查明所作指定，则十从一项债务中扣除，另五从另一项债务中扣除；若无法查明，则十从较早成立的契约债务中扣除，五从另一项债务中扣除。

<!-- source-p 0489 -->
<a id="46.3.25"></a>**46.3.25**

<!-- source-p 0490 -->
庞波尼《萨宾评注》第三十一卷。

<!-- source-p 0491 -->
被指定为部分继承人的人，若全额清偿了死者承诺的十，就其继承份额而言免责；就其余部分则可提起返还非债之诉。但若在其提起返还之诉之前，遗产的剩余部分又归属于他，我认为他也会就该部分负债；因此，他就非债款项提起返还请求时，应受恶意抗辩阻却。

<!-- source-p 0492 -->
<a id="46.3.26"></a>**46.3.26**

<!-- source-p 0493 -->
庞波尼《萨宾评注》第三十五卷。

<!-- source-p 0494 -->
若债权人出售设定质押的土地，并收回其应得的债额，债务人即免责。即使债权人将价款记入买受人名下，或向买受人订立要式口约，债务人也同样免责。但若债权人出售了作为质物的奴隶，只要该买卖仍可能被解除，债务人就不免责；正如任何质物被出售后，只要仍可能使该物恢复为未出售状态，债务人便尚未免责。

<a id="46.3.27"></a>**46.3.27**

<!-- source-p 0496 -->
乌尔比安《告示评注》第二十八卷。

<!-- source-p 0497 -->
即使是在要式口约之诉或遗嘱之诉中，若债务人交付了所负债的物，只要该物尚有某项法律权利未获满足，债权人仍可请求该物本身。例如，尽管土地已经交付给我，若仍有某项担保上的权利尚待履行，我仍可请求该土地。

<a id="46.3.29"></a>**46.3.29**

<!-- source-p 0502 -->
乌尔比安《告示评注》第三十八卷。

<!-- source-p 0503 -->
若向共同奴隶承诺交付斯提库斯和潘菲卢斯，不能向其一名主人交付斯提库斯、向另一名主人交付潘菲卢斯；而应向两名主人各交付两名奴隶的一半份额。若某人承诺交付两名斯提库斯或两名潘菲卢斯，或者承诺向两名共有人共有的奴隶交付十名奴隶，规则亦同。“十个人”一语如同“十第纳尔”一样具有歧义，因为两种标的都可以有两种方式理解为各半。但金钱、橄榄油、谷物以及类似按种类确定的物品，显然应按数量分割债务，因为这对承诺人与要式口约债权人都更为便利。

<a id="46.3.30"></a>**46.3.30**

<!-- source-p 0505 -->
乌尔比安《告示评注》第五十一卷。

<!-- source-p 0506 -->
若债务人提出支付债权人所请求的款项，而债权人拒绝受领，裁判官便不再给予债权人诉权。

<!-- source-p 0507 -->
<a id="46.3.31"></a>**46.3.31**

<!-- source-p 0508 -->
乌尔比安《论争议》第七卷。

<!-- source-p 0509 -->
不同工匠在才智、天赋、训练和技艺方面差异很大。因此，若某人承诺亲自建造船舶、修建公寓楼或开挖沟渠，且特别约定须以其自身劳务完成，即使保证人亲自建造或开挖，未经要式口约债权人同意，也不能使主债务人免责。因此，即使保证人另行作出“你不得妨碍我通行或驱赶牲畜吗？”这样的要式口约，保证人若加以阻碍，并不会因此触发该要式口约；但若他容忍通行或驱赶，也不会阻止该要式口约被触发。

<a id="46.3.32"></a>**46.3.32**

<!-- source-p 0511 -->
尤利安《学说汇纂》第十三卷。

<!-- source-p 0512 -->
若奴隶以特有产名义借出钱款，而债务人在不知道主人已经死亡的情况下、继承尚未接受前予以清偿，即可免责。奴隶获释后，债务人因不知道其特有产并未授予而向其付款，亦同。无论款项是在主人生前还是死后支付，都没有区别；因为这种情况下债务人也免责，正如债权人命令债务人向提提乌斯支付款项，即使债权人已经死亡，只要债务人不知道其死亡，向提提乌斯付款仍属有效。

<!-- source-p 0513 -->
<a id="46.3.33"></a>**46.3.33**

<!-- source-p 0514 -->
尤利安《学说汇纂》第五十二卷。

<!-- source-p 0515 -->
<a id="46.3.33.pr."></a>**序言**　某人以要式口约约定将土地交付给自己或提提乌斯；即使土地已交给提提乌斯，之后又被第三人追夺，仍可提起诉讼。这与约定交付一名奴隶，而承诺人将一名附条件释奴交给提提乌斯、该奴隶后来获得自由的情形相同。

<!-- source-p 0516 -->
<a id="46.3.33.1"></a>**1**　某人承诺交付斯提库斯或潘菲卢斯，若他曾使斯提库斯受伤，就不能以交付受伤的斯提库斯而免责；这与其单独承诺交付斯提库斯、却交付自己弄伤的斯提库斯无异。又如，某人承诺交付一名奴隶，却提出交付一名被自己弄伤的奴隶，也不免责。即使诉讼已经进入争点确定阶段，若被诉人提出交付自己弄伤的奴隶，也应判令其承担责任。若他交付的是被他人弄伤的奴隶，也应判令其承担责任，因为他本可交付另一名奴隶。

<!-- source-p 0517 -->
<a id="46.3.34"></a>**46.3.34**

<!-- source-p 0518 -->
尤利安《学说汇纂》第五十四卷。

<!-- source-p 0519 -->
<a id="46.3.34.pr."></a>**序言**　某人承诺将一名奴隶或十交付给你或提提乌斯；若他先向提提乌斯交付了该奴隶的一部分，随后又向你支付十，他可以向你请求返还奴隶的相应部分，视同他依你的意思向提提乌斯清偿了非债。提提乌斯死亡后，他再支付十的，也适用同一规则：他可以向你而非提提乌斯的继承人请求返还奴隶的相应部分。

<!-- source-p 0520 -->
<a id="46.3.34.1"></a>**1**　若两名共同要式口约债权人均约定交付一名奴隶，而承诺人分别向二人交付了不同奴隶的部分，毫无疑问承诺人并未免责。若向二人交付的是同一奴隶的不同份额，则发生免责，因为共同债务关系使得向两人清偿被视为向一人清偿。相反，若两名保证人承诺交付一名奴隶，分别交付不同奴隶的部分，均不免责；若交付的是同一奴隶的不同份额，则免责。

<!-- source-p 0521 -->
<a id="46.3.34.2"></a>**2**　我约定“给付我十，或给提提乌斯一名奴隶”；若奴隶已经交给提提乌斯，承诺人即免除对我的债务；但在交付奴隶之前，我可以请求十。

<!-- source-p 0522 -->
<a id="46.3.34.3"></a>**3**　若我委任提提乌斯管理我的全部事务，之后在债务人不知情时禁止他管理我的事务，债务人仍可向提提乌斯清偿并免责；因为委任某人管理全部事务的人，也被视为委托债务人向该代理人清偿。

<!-- source-p 0523 -->
<a id="46.3.34.4"></a>**4**　若没有任何委任，而债务人错误地以为自己是在我的意思下支付款项，他不会免责。因此，向主动插手他人事务、并自称为代理人的人清偿，也不能使付款人免责：

<!-- source-p 0524 -->
<a id="46.3.34.5"></a>**5**　逃奴假装自由人出售财物时，裁决认为，买受人向逃奴付款，并未免除其对主人的债务。

<!-- source-p 0525 -->
<a id="46.3.34.6"></a>**6**　女婿在女儿不知情时向岳父支付嫁资，并未因此免责；但除非女儿追认，他可以向岳父请求返还。女婿的情形大致类似于向缺席者的代理人付款，因为女儿在嫁资关系中是父亲的参与者，并仿佛是债务关系的共同一方。

<!-- source-p 0526 -->
<a id="46.3.34.7"></a>**7**　若我命令自己的债务人向提提乌斯付款，意在将钱赠与提提乌斯；即使提提乌斯受领时意在使钱币成为我的财产，债务人仍然免责。但若提提乌斯后来将同一笔钱交还给我，钱币便成为我的。

<!-- source-p 0527 -->
<a id="46.3.34.8"></a>**8**　某人曾指定自己从中接受保证的家子为继承人。有人问：若该家子奉父亲之命接受继承，父亲能否向保证人起诉？我曾说，凡作为担保提供者的人继承了接受担保者，保证人即被解除责任，因为不能在同一人之间就同一事项继续负债。〔原文疑误：底本句末作 *debere posseentiarum*，无法判读。〕

<!-- source-p 0528 -->
<a id="46.3.34.9"></a>**9**　若遗产的恶意占有人将其向遗产债务人收取的款项返还给请求遗产的人，遗产债务人即免责。

<!-- source-p 0529 -->
<a id="46.3.34.10"></a>**10**　若我约定交付十或一名奴隶，并接受提提乌斯和梅维乌斯两名保证人；提提乌斯支付五，在梅维乌斯也支付五之前，债务人不免责。若梅维乌斯交付了奴隶的一部分，两名保证人均仍负有责任。

<!-- source-p 0530 -->
<a id="46.3.34.11"></a>**11**　能够依永久抗辩保护自己的人，可以请求返还已经支付的款项，因此并未免责。所以，若两名共同要式口约债务人之一约定债权人不得向其请求，即使该人已经付款，另一人仍继续负债。

<!-- source-p 0531 -->
<a id="46.3.35"></a>**46.3.35**

<!-- source-p 0532 -->
阿尔芬努斯《论说集》第二卷（保罗节编）。

<!-- source-p 0533 -->
奴隶以其特有产所贷出或寄存的款项，无论该奴隶后来被出售还是获释，均可向其有效清偿；除非出现某种情形，足以表明清偿违背了该奴隶当时主人的意愿。若有人向奴隶借用主人所有的钱，而主人允许奴隶经管主人事务，规则亦同；因为与奴隶订约的人被视为经主人同意向奴隶受领钱款并向其清偿。

<!-- source-p 0534 -->
<a id="46.3.36"></a>**46.3.36**

<!-- source-p 0535 -->
尤利安《论乌尔塞乌斯·费罗克斯》第一卷。

<!-- source-p 0536 -->
我父亲在留下怀孕的妻子后去世；我基于继承原因请求并收取了全部欠父亲的款项。有人认为我并未取得不当利益：若最终没有孩子出生，我的请求便是正当的，因为在当时的事实状况下，我确实是唯一继承人。尤利安批注说：较妥当的看法是，在尚未确定不会有孩子出生之前，我已经丧失了自己本应继承的相应份额；若可能出生三人，则为四分之一；若可能出生五人，则为六分之一。因为亚里士多德也写道，最多可能生下五人，妇女子宫可以有五个容纳处；而且在罗马有一名来自埃及亚历山大的妇人曾一次生下五人，当时五人都健康存活；此事也有人向我证实在埃及发生过。

<!-- source-p 0537 -->
<a id="46.3.37"></a>**46.3.37**

<!-- source-p 0538 -->
尤利安《论乌尔塞乌斯·费罗克斯》第二卷。

<!-- source-p 0539 -->
数名保证人中的一人支付了自己的份额时，应视为其在替主债务人处理事务，因而效果如同主债务人自己支付了一名保证人的份额；不过，该款并不从主债务本金中扣除，而只是使以其名义付款的那名保证人免责。

<!-- source-p 0540 -->
<a id="46.3.38"></a>**46.3.38**

<!-- source-p 0541 -->
阿非利卡努斯《问题集》第七卷。

<!-- source-p 0542 -->
<a id="46.3.38.pr."></a>**序言**　某人约定将土地交付给自己或提提乌斯；较妥当的看法是，只有提提乌斯仍处于订立要式口约时的同一身份地位，向他付款才有效。反之，若他后来被收养、被流放、被剥夺水火，或成为奴隶，向他清偿便无效；应视为要式口约默示包含“以其仍处于同一身份地位为条件”。

<!-- source-p 0543 -->
<a id="46.3.38.1"></a>**1**　若我命令自己的债务人向提提乌斯付款，之后又禁止提提乌斯受领，而债务人不知禁令仍付款，尤利安认为，只有在提提乌斯受领时并非意图将钱据为己有的情况下，债务人才免责。否则，提提乌斯意图盗取钱币时，钱币仍属于债务人，债务人不能依法律本身免责；但若债务人愿意将其对提提乌斯享有的盗窃物返还请求权让与我，则应通过抗辩给予救济。丈夫意图向妻子赠与时，命令自己的债务人向妻子付款，也是同样的情形：由于钱币并未成为妻子所有，债务人并未免责；但若他让与自己对妻子的返还请求权，仍可依据抗辩对抗丈夫。就本例而言，离婚后我仍有权提起盗窃之诉，因为我有利益不使钱币被侵吞。

<!-- source-p 0544 -->
<a id="46.3.38.2"></a>**2**　有人基于特有产之诉起诉主人，主人被判承担责任并已清偿。裁决认为，为奴隶接受的保证人也因此免责；同一笔钱可以用于清偿数项不同原因的债务。例如，若有人为判决债务提供担保，债务人被判决后清偿，则不但判决之诉消灭，债务人与保证人也依据要式口约免责。更相似的是遗产占有人误以为自己是继承人而清偿的情形：真正继承人并不免责，因为该占有人以自己名义支付非债款项，因此有权请求返还。

<!-- source-p 0545 -->
<a id="46.3.38.3"></a>**3**　某人承诺交付一名奴隶，若他交付了附条件释奴，我认为不必等待条件成就；债权人可以起诉，付款人也享有返还请求之诉。若条件随后未成就，债务人即免责，如同有人在条件尚未成就时因错误而付款，且在其请求返还之前条件已成就。但绝不能说，若斯提库斯死亡导致条件不成就，债务人便免责；即使斯提库斯生存时条件未成就原本可以免责亦然，因为在这种情况下，债务人从未在任何时候使我取得对该奴隶完整的所有权。否则，就会近似于有人向我交付一名他人享有用益权的奴隶，而该奴隶在用益权存续期间死亡，便认为付款人免责；这一结论绝不可采，正如交付共有奴隶而该奴隶随后死亡亦然。

<!-- source-p 0546 -->
<a id="46.3.38.4"></a>**4**　若某人为一名因公离境后返回的人提供保证，而该人已通过诉讼抗辩免责；此后一年经过，保证人是否也免责？尤利安不赞同保证人免责；尤其是在此前无法对保证人提起诉讼时，应依告示恢复对保证人的诉权，正如保证人杀死了承诺交付的奴隶时恢复对其的诉权一样。

<!-- source-p 0547 -->
<a id="46.3.38.5"></a>**5**　某人曾为你向提提乌斯作保证，并以自己的财物为其债务设定质押；之后他又指定你为继承人。虽然你不因保证关系负债，该质物仍然维持担保。但若同一人改为提供另一名保证人，然后指定你为继承人，较妥当的看法是：被保证的主债务消灭后，提供保证的人也随之免责。

<!-- source-p 0548 -->
<a id="46.3.39"></a>**46.3.39**

<!-- source-p 0549 -->
阿非利卡努斯《问题集》第八卷。

<!-- source-p 0550 -->
若我准备向你支付一笔钱，经你指示，将其加印封缄后寄存在钱币兑换商处，等待核验，梅拉在《论说集》第十卷中写道，该款风险由你承担。此说正确，但关键是应考察，未能立即核验是否归因于你；若是，则应视为我已准备清偿而你因某种原因拒绝受领。不过，并非任何情况下风险都由你承担：如果我在不适当的时间或地点提出清偿，便不应如此。由此我认为，若买受人和出卖人因彼此不信任，分别将钱款和货物寄存于第三人处，钱款由买受人承担风险（尤其是由他选择寄存人时），货物也同样由买受人承担风险，因为买卖已经完成。

<a id="46.3.46"></a>**46.3.46**

<!-- source-p 0571 -->
马尔基安《规则集》第三卷。

<!-- source-p 0572 -->
<a id="46.3.46.pr."></a>**序言**　若某人经受领人同意，以一物代替另一物清偿，而该物后来被追夺，原有债务仍然存在。即使该物仅有一部分被追夺，原债务仍全额存续；因为如果债权人不能取得该物的全部权利，就不会接受该物作为完整清偿。

<!-- source-p 0573 -->
<a id="46.3.46.1"></a>**1**　若某人以两块土地作为债务的清偿，例如其中一块被追夺，原债务仍然完整存续。只有在受领人完整取得替代物的所有权时，以物代物清偿才发生免责效力。

<!-- source-p 0574 -->
<a id="46.3.46.2"></a>**2**　若某人以欺诈方式将一块估价过高的土地用于清偿，除非补足其不足部分，否则并不免责。

<a id="46.3.47.pr."></a>**序言**　对于未经监护人授权而向未适婚人清偿的情形，若争议在于未适婚人何时变得较为富有，应考察提起诉讼之时；若提出恶意抗辩会对其不利，也应考察诉讼时的情况。

<!-- source-p 0578 -->
<a id="46.3.47.1"></a>**1**　斯凯沃拉曾说，即使财物在争讼程序确定之前已经灭失，有时仍应视为未适婚人因而变得较为富有：例如，他用该款买了自己必需的物品，而本来就必须以自己的钱购买；因为正是由于他没有因此变得更穷，才应视为变得较为富有。斯凯沃拉还认为，若家子为必要事务借入金钱后又将其耗用，《马其顿元老院决议》便不适用。

我们认为，金钱若实际交给债权人，便已在自然法意义上清偿。若依债权人指示向他人付款，无论是向他的债权人、将来的债务人，还是他原本打算赠与的人付款，也应当发生清偿效果。债权人追认清偿的，结果相同。向监护人、保佐人、代理人、任何继受人或负责事务管理的奴隶付款，也使债务人受益。若对原以要式口约方式、或未经要式口约而以抵押承担责任的债务作出免债承认，单纯使用“清偿”一词并无效果；但只要提供足额担保即可。
