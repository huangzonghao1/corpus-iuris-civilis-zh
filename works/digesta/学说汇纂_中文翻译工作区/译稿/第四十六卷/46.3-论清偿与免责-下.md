<a id="46.3.58"></a>**46.3.58**

<!-- source-p 612 -->
<a id="46.3.58.pr."></a>**序言**　若有人本着善意，向主动处理他人事务的人付款，何时才免责？尤利安说，事务本人追认后，付款人才免责。他又问，在事务本人追认之前，能否基于该原因提起返还之诉。答复说，这取决于付款时的意思：究竟是希望债务人立即免责，还是希望等事务本人追认后再免责。若为前者，付款人可以立即向该代理人提起返还之诉；只有事务本人追认后，返还请求才消灭。若为后者，则只有在事务本人未予追认时，返还请求才产生。

<!-- source-p 613 -->
<a id="46.3.58.1"></a>**1**　若债权人尚不知其代理人已收到清偿，便将自己交由他人收养为子，若其父亲追认了该收款，清偿即为有效；若未追认，债务人可以请求返还。

<!-- source-p 614 -->
<a id="46.3.58.2"></a>**2**　若有两名共同要式口约债权人，债务人向不在场的一人的代理人付款，而该人尚未追认；其间债务人又向另一人清偿，则后一次清偿与前一次清偿均处于未定状态，因为无法确定收款人请求的是债务，还是本不应给付之物。

若我如此约定：“你允诺给付给我或提提乌斯吗？”，债务人若已向我允诺清偿，即使我可依据其承诺提起诉讼，他仍可向附加的提提乌斯清偿。若我向家子约定给付给我或提提乌斯，其父亲也可以将属于特有产的款项支付给提提乌斯，前提是父亲希望以自己名义而非以儿子名义清偿。因为向附加的人清偿，视为向我清偿。因此，若向附加的人清偿了本不应清偿之物，尤利安认为可以向要式口约债权人提起返还之诉；无论是我命令你向提提乌斯支付，还是要式口约自始如此订立，均无区别。

我以遗嘱命令我的事务管理人获得自由，并将特有产遗赠给他。他在我死后向债务人收取了金钱。问题是，我的继承人能否从其特有产中扣留所收款项。若他是在遗产已被承受后才收取金钱，毫无疑问，不得以特有产为由扣留该款，因为他既已成为自由人，债务人因清偿而免责后，他便开始对继承人负债。若事务管理人在遗产被承受前收到金钱，且债务人因该付款而免责，毫无疑问，应从其特有产中扣留该款，因为他开始对继承人负债，继承人可基于无因管理或委任之诉请求。若债务人并未免责，则产生如下问题：你作为我的事务管理人，从我的债务人处收款，而我没有追认；我此后若想基于无因管理之诉起诉你，只要你承诺使我不受损害，能否有效起诉？我认为不能，因为我未予追认，已经排除了无因管理之诉；因此，债务人仍是我的债务人。

<!-- source-p 644 -->
某奴隶受命向未成年人给付十，若该未成年人继承遗产，或者仅被指定为条件继承人，该奴隶便可获得自由。问题是，即使未成年人的监护人不在场，奴隶向未成年人给付后能否取得自由？你可能会联想到以行为作为条件的情形，例如“若其为未成年人服役”，即使监护人未介入也可以成就。你又问：若未成年人有保佐人，或者奴隶受命向精神障碍者给付，向保佐人给付能否使奴隶获得自由？设想某人将庄园遗赠给受遗赠人，条件是其向未成年人或精神障碍者给付。应当知道，在所有这些情形中，向监护人或保佐人付款才是有效清偿；向精神障碍者或未成年人本人付款则不当，以免给付因其无行为能力而落空。立遗嘱人并非意在使任何方式的给付都足以成就条件。

<a id="46.3.71"></a>**46.3.71**

<!-- source-p 652 -->
塞尔苏斯《学说汇纂》第27卷。

<!-- source-p 653 -->
<a id="46.3.71.pr."></a>**序言**　我约定给付十给我或提提乌斯，并已收到五，允诺人可以有效地将余款给付提提乌斯。

<!-- source-p 654 -->
<a id="46.3.71.1"></a>**1**　若保证人向债权人的代理人付款，债权人在保证人依法可以免责的期限之后才予追认，由于保证人付款时仍基于保证关系负有责任，他既不能请求返还，也不能因此而不再通过委任之诉向主债务人追偿；其追偿权与付款当时直接向债权人清偿相同。

<!-- source-p 655 -->
<a id="46.3.71.2"></a>**2**　同样，若债权人不知情时，已将其代理人收到的、由债务人的奴隶或家子支付的款项记为受领，后来得知实情并予追认，则付款得到确认，记为已受领的行为不发生效力。反之，若债权人未予追认，其记为已受领的行为即得到确认。

<!-- source-p 656 -->
<a id="46.3.71.3"></a>**3**　但若债权人不知付款已经发生而提起诉讼，且在诉讼审理期间追认该付款，应判被起诉者无罪；若未予追认，则应判其承担责任。

<!-- source-p 657 -->
<a id="46.3.72"></a>**46.3.72**

<!-- source-p 658 -->
马尔切鲁斯《学说汇纂》第20卷。

<!-- source-p 659 -->
<a id="46.3.72.pr."></a>**序言**　欠十的人若已向债权人提出给付，而债权人无正当理由拒绝受领，之后债务人又无过错地丢失该款，即使他先前曾受到催告却未付款，也可以恶意欺诈抗辩保护自己。因为若债权人愿意受领，债务人就不会因丢失金钱而承担责任，认定债权人迟延受领的款项视同已清偿，才是公平的。诚然，若嫁资中有一名奴隶，丈夫曾提出交付而奴隶随后死亡；或者丈夫提出交付金钱，妻子未受领而丈夫又丢失金钱，则依法律本身，丈夫即不再负债。

<!-- source-p 660 -->
<a id="46.3.72.1"></a>**1**　若你欠我斯提库斯，并且已在履行上迟延，之后又附条件允诺交付他；条件悬而未决期间，斯提库斯死亡。我们应考察，既然先前债务不能被更新，我能否请求给付奴隶，仿佛未曾另行订立要式口约。对此显然可以反驳：债务人向债权人作出附条件允诺，不应被认为已停止履行奴隶的清偿义务。因为正确的规则是，受催告后拒绝给付的人，后来提出给付时即可免于标的物灭失的风险。

<!-- source-p 661 -->
<a id="46.3.72.2"></a>**2**　若债权人在债务人不知情时，向另一人约定取得该奴隶，是否也应如此？此时同样应认为，债务人已免于风险；正如任何人代债务人提出该奴隶，而约定者拒绝受领时一样。

<!-- source-p 662 -->
<a id="46.3.72.3"></a>**3**　若有人在奴隶被窃后，附条件约定窃贼应给付或实施其所负担的一切，也已作出相同答复：若所有人拒绝受领窃贼提出的奴隶，窃贼也会因返还之诉而免责。但若要式口约是在奴隶恰好身处行省期间订立的——设想窃贼或允诺人尚未有机会找到该奴隶，奴隶便已死亡——则前述理由不适用；由于奴隶不在场，不能认为窃贼曾提出交付。

<!-- source-p 663 -->
<a id="46.3.72.4"></a>**4**　我约定给付奴隶斯提库斯或潘菲卢斯；当时潘菲卢斯属于我。即使他后来不再属于我，允诺人也不能通过给付潘菲卢斯免责，因为就潘菲卢斯而言，无论债务成立还是清偿都没有得到确认。不过，若有人约定给付一名奴隶，允诺人交付了约定者当时所有的奴隶之一，即可免责；事实上，他约定交付的本来就是非其所有之人中的一个。设想约定为“给付塞姆普罗尼乌斯留下的奴隶之一”，而塞姆普罗尼乌斯留下三名奴隶，其中一名属于约定者；若另外两名死亡，我们应考察是否仍有任何债务存续。较为可取的看法是，除非在另外两人死亡前，剩下的一名奴隶已不再属于约定者，否则要式口约即告失效。

<!-- source-p 664 -->
<a id="46.3.72.5"></a>**5**　有人欠付一名奴隶，却交付了斯提库斯；依遗嘱信托，斯提库斯应获自由。此人不应认为已经免责，因为他交付的少于一名仍受奴役的奴隶；正如交付一名尚未解除诺克萨责任的奴隶，也不能使债务人免责。那么，若交付的是一名以尸体埋葬为业或其他名声不佳的奴隶，是否也应作相同处理？确实不能否认这构成给付，而且该情形与前述不同，因为债权人取得了一名不能被他人夺走的奴隶。

<!-- source-p 665 -->
<a id="46.3.72.6"></a>**6**　允诺交付奴隶的人，须交付一名要式口约债权人如愿即可使其获得自由的人。

<!-- source-p 734 -->

<!-- source-p 735 -->
<a id="46.3.93.3"></a>**3**　若保证人指定主债务人为继承人，又应如何？依萨宾的见解，债务发生混同，尽管普罗库鲁斯持不同意见。

<a id="46.3.94"></a>**46.3.94**

<!-- source-p 737 -->
帕比尼安《疑问》第8卷。

<!-- source-p 738 -->
<a id="46.3.94.pr."></a>**序言**　若债权人收取债务人支付的他人所有的钱币，之后又在钱币仍完整的情况下继续请求债务人清偿，而不提出返还已收款项，即应被恶意欺诈抗辩排除。

<!-- source-p 739 -->
<a id="46.3.94.1"></a>**1**　反之，若我借出或清偿的是共有钱币，我的相应份额即刻产生诉权，债务也在相应份额内解除；无论认为每一枚钱币均为按份共有，还是认为金钱仅是一种数量而非具体物体，结论都相同。

<!-- source-p 740 -->
<a id="46.3.94.2"></a>**2**　若保证人以他人所有的钱币承担保证债务，待钱币被消耗后，可以提起委任之诉。因此，若他支付了自己所窃取的钱币，在承担盗窃之诉或返还之诉的责任后，可以提起委任之诉。

<!-- source-p 741 -->
<a id="46.3.94.3"></a>**3**　法比乌斯·雅努阿里乌斯致帕比尼安：提提乌斯因遗嘱信托而欠盖乌斯·塞尤斯一笔确定金额；基于另一原因，他也欠同一数额，但该另一项请求虽不能起诉，若付款后却不能请求返还。提提乌斯的奴隶代理人在主人不在场时支付了相当于其中一项债务的款项，并取得收据，载明所付款项已从全部债权中扣除。我问，该款应视为清偿哪一项债务。答复：若塞尤斯向提提乌斯出具凭证，表示款项已从全部债权中扣除，那么“债权”一词似乎仅指遗嘱信托项下的金钱，而不包括另一项没有请求权、但付款后又不得请求返还的金钱。若提提乌斯的奴隶代理人在主人不在场时付款，而付款被说成是清偿那项仅可通过抗辩保护、不能请求的债务，则连钱币所有权都不会转移。因为这不符合常理：主人会安排奴隶付款以清偿一项本不应清偿的债务；正如主人不会安排奴隶用特有产支付其非为特有产利益而承担的保证债务。

<!-- source-p 742 -->
<a id="46.3.95"></a>**46.3.95**

<!-- source-p 743 -->
帕比尼安《疑问》第28卷。

<!-- source-p 744 -->
<a id="46.3.95.pr."></a>**序言**　若我约定给付奴隶斯提库斯或潘菲卢斯，由我选择，而其中一人死亡，则只能请求仍然在世的那一人；但若债权人所选择的那名奴隶在死亡前已发生迟延，则应视同要式口约只将该已死亡之人纳入债务。

<!-- source-p 745 -->
<a id="46.3.95.1"></a>**1**　若选择权属于允诺人，其中一人死亡后，仍可请求另一名在世之人。反之，若因债务人的行为导致一名奴隶死亡，虽然当下只能请求仍可交付的人，但不能请求已死亡奴隶的估价——即使该奴隶价值低得多也一样，因为此项规定旨在惩罚允诺人——不过，若另一名奴隶随后也在债务人无过错的情况下死亡，就不能依要式口约起诉，因为该要式口约在他死亡时并未触发。当然，既然不应让不当行为不受惩罚，提出欺诈之诉也并非不合理。此种情况不同于保证人杀死允诺交付的奴隶，因为保证人仍须依要式口约之诉负责，正如主债务人没有继承人而死亡时，保证人仍负责任一样。

<!-- source-p 746 -->
<a id="46.3.95.2"></a>**2**　承受遗产有时依法使债务发生混同，例如债权人承受债务人的遗产，或者债务人承受债权人的遗产。有时，遗产承受相当于清偿：例如债权人未经监护人同意向未成年人出借钱币，后来成为其继承人；债权人不能仅在未成年人实际获益的范围内取回，而是从遗产中保有全部债权。有时，遗产承受会使原本无效的债务得到确认。例如，继承人依据《特雷贝利安元老院决议》返还遗产后，成为遗嘱信托受益人的继承人；或者曾为提提乌斯承担债务的妇女成为提提乌斯的继承人。此时，因依法负债之人所留下的遗产，民事债务开始成立，而债务人也不再享有原有的抗辩。对于以自己名义承担风险的妇女提供此类帮助，是不合宜的。

<!-- source-p 747 -->
<a id="46.3.95.3"></a>**3**　通常所说“保证人成为债务人的继承人后，即基于保证而免责”，仅在主债务人负有更完整的允诺义务时才正确。若主债务人只负有有限责任，保证人便会免责。反过来说，若主债务人享有个人抗辩，也不能因此认为保证人的债务不消灭。假设未满二十五岁的债务人因债权人欺诈而借入善意借贷，并丢失所收钱币；在恢复原状期限内死亡，且由保证人继承。很难说债权人仍可对保证人保有债务，理由是原本可保护未成年人的裁判官法救济仍应保留；主债务人的债务是主债务，保证人的债务则从属于主债务，后者并非在不考虑裁判官法的情况下成立。因此，作为该青年继承人的保证人，在规定期限内仍享有恢复原状的救济。

<!-- source-p 748 -->
<a id="46.3.95.4"></a>**4**　自然债务既可因支付金钱而消灭，也可依法律本身因正当协议或宣誓而消灭；因为此种债务仅由衡平关系维系，而协议的衡平效果能够解除该关系。因此，据说未成年人所提供的保证人可因上述原因免责。

<!-- source-p 749 -->
<a id="46.3.95.5"></a>**5**　有人问，能否约定“给我或我的儿子十”，或者“给我或我的父亲”。可以作如下区分：若由儿子提出要式口约，只有在债务不能由儿子取得时，才附加父亲的名字；反过来，若由父亲提出要式口约，则可以附加儿子的名字，因为父亲为儿子约定的事项，只要儿子不能为自己约定，就被视为父亲为自己约定。就本例而言，显然附加儿子之名仅是为了清偿，而非为了使其取得债权。

<!-- source-p 750 -->
<a id="46.3.95.6"></a>**6**　我约定将用益权给付给我或提提乌斯。即使提提乌斯发生人格减等，向提提乌斯清偿的可能性也不会消失，因为我们也可以这样约定：“若提提乌斯发生人格减等，则将用益权给付给我或提提乌斯。”

<!-- source-p 751 -->
<a id="46.3.95.7"></a>**7**　若附加的是精神障碍者或未成年人的名字，则在为成就条件而向监护人或保佐人付款也有效的情况下，可以向其监护人或保佐人付款。拉贝奥和佩伽苏斯认为，为实用起见，应采纳这一见解；若金钱用于未成年人或精神障碍者的利益，可以如此处理，如同主人命令奴隶向另一奴隶给付，以便由主人取得一样。除此之外，受命向奴隶给付的人，只有在依该奴隶意愿向主人付款时，才算成就条件。塞姆普罗尼乌斯约定将十给付给自己或梅维乌斯的奴隶斯提库斯，若债务人却向梅维乌斯主人清偿，也应如此处理。

<!-- source-p 752 -->
<a id="46.3.95.8"></a>**8**　若债权人占有一份本不属于自己的债务人遗产，而从中取得的财产价值足以使遗产占有人清偿债权人时使继承人免责，则不能说保证人因此免责；因为不能认为那位即将被遗产追夺的人是向自己清偿。

<!-- source-p 753 -->
<a id="46.3.95.9"></a>**9**　你以欺诈方式使自己不再占有从他人遗产中取得的财物。若占有人已交付该物或诉讼标的估价，这对你有利，因为请求人的利益已获满足；但若你在被起诉前，基于先前的欺诈已经给付，则该给付对占有人并无帮助。

<!-- source-p 754 -->
<a id="46.3.95.10"></a>**10**　若你受我委托，将钱借给提提乌斯，这一契约类似监护人与未成年人的债务人之间的关系。因此，即使委托人被起诉并被判决承担责任，尽管金钱已经清偿，仍有理由认为债务人并未免责；债权人还应将其对债务人的诉权让与委托人，以使委托人获得清偿。这是因为监护人与未成年人债务人之间并无可比性：监护人因未起诉未成年人的债务人而对未成年人负有责任；即使监护人已与该债务人进行诉讼，另一方也不会免责；即使监护人败诉并清偿，也不会使债务人获益。甚至通常认为，监护人可以通过反向监护诉讼，请求未成年人让与其针对债务人的诉权。

<!-- source-p 755 -->
<a id="46.3.95.11"></a>**11**　若债权人因自己的过错而丧失对债务人的请求权，那么委托人几乎不应通过委任之诉向其承担任何责任，因为正是债权人的过错使其无法将诉权让与委托人。

<!-- source-p 756 -->
<a id="46.3.95.12"></a>**12**　若买受人与出卖人约定在任何一方尚未作出给付之前解除买卖，基于该买卖接受的保证人也会因契约解除而免责。

<a id="46.3.96"></a>**46.3.96**

<!-- source-p 758 -->
帕比尼安《答问》第11卷。

<!-- source-p 759 -->
<a id="46.3.96.pr."></a>**序言**　未成年人的债务人依监护人指示，向监护人的债权人清偿金钱；若能证明此事并非与监护人恶意串通所为，债务人即获免责。若监护人的债权人参与了欺诈合谋，也可依欺诈禁令对其追责。

<!-- source-p 760 -->
<a id="46.3.96.1"></a>**1**　一名未成年女子成为某行政长官的继承人；该行政长官曾以欺诈方式为她指定监护人。其监护人与一名青年达成和解，但女子不愿追认该和解。尽管如此，监护人的金钱债务仍已解除；监护人对该青年既无直接诉权，也无准诉权，因为该青年已取回自己的财物。但若该青年愿意将金钱返还给女子的监护人，在撤销已经实施的行为后，他可以取得对该女子——即该行政长官继承人——的准诉权。

<!-- source-p 761 -->
<a id="46.3.96.2"></a>**2**　一名女子的兄弟作为继承人欠她一项遗赠。遗赠之争已经开始后，双方和解；女子同意不再请求遗赠，而仅接受债务人的债权名义。有人认为，尽管没有进行债务移转，债务人也没有免责，但债权风险仍由该女子承担。因此，若她违反约定再次请求遗赠，可以有效地对她提出协议抗辩。

<!-- source-p 762 -->
<a id="46.3.96.3"></a>**3**　若同一时间以两项契约为由设定质押，债权人应按各项契约债务的比例分配质押物价款；既然债务人已将质押物价款用于共同清偿，债权人无权选择将其记在哪一项债务上。若质押物是在不同时间为两项债务设定，则应先以质押物价款清偿较早的债务，再将剩余部分用于清偿后一债务。

<!-- source-p 763 -->
<a id="46.3.96.4"></a>**4**　遗嘱指定的继承人尚在考虑是否承受遗产时，因错误而向替代继承人支付了金钱；后来遗产归属于替代继承人后，返还请求即消失。因此，债务关系也随之消灭。

<a id="46.3.97"></a>**46.3.97**

<!-- source-p 765 -->
帕比尼安《定义》第2卷。

<!-- source-p 766 -->
若债务人基于数项债务原因付款，而未指明款项所对应的债务，应优先用于清偿涉及名誉减损的债务；其次是包含罚金的债务；第三是以抵押或质押设立的债务。依此顺序之后，自身债务优先于他人债务，例如保证债务。古人之所以如此规定，是因为可以合理推定：勤勉的债务人受到提醒后，会如此处理自己的事务。若以上情形均不存在，则先清偿订立时间较早的契约。若实际付款超过各项债务所需数额，先清偿优先顺序最高的契约；超过的部分则视为全部或部分用于减少下一顺位的债务。

<!-- source-p 767 -->
<a id="46.3.98"></a>**46.3.98**

<!-- source-p 768 -->
保罗《疑问》第15卷。

<!-- source-p 769 -->
<a id="46.3.98.pr."></a>**序言**　某人以自己的财产设定负担，之后又以其中一处占有物为女儿允诺嫁资，并已交付该物。若债权人追夺该物，应认为丈夫可以基于嫁资允诺之诉起诉；这与父亲为女儿给付作为嫁资的附条件获释奴隶或附条件遗赠物相同。因为此类清偿只有在条件结果确定后才能使债务人免责，也就是在可以确定该物最终归属时。

<!-- source-p 770 -->
<a id="46.3.98.1"></a>**1**　对于另一种情形，结论不同：获释奴死亡后，保护人依《法比亚法》取回财物。因为该诉讼是新的，不能撤销已经产生的免责。

<!-- source-p 771 -->
<a id="46.3.98.2"></a>**2**　受债权人欺诈的未满二十五岁者，其基于债务原因已经给付的标的被恢复原状，也属于这一类。

<!-- source-p 772 -->
<a id="46.3.98.3"></a>**3**　父亲清偿军营特有产债务时，应视同其交付的是他人之物；即使儿子先于他无遗嘱死亡，已清偿之物仍可能留在受领人处。只有儿子死亡时，才认为该物已被取得。究竟该物属于何人，应由事后发生的结果揭示；事后事实也可以说明此前的法律状态。

<!-- source-p 773 -->
<a id="46.3.98.4"></a>**4**　我无条件约定给付十给自己，或者在确定日期或附条件给付给提提乌斯；也可以有效地约定于一月给付我、二月给付提提乌斯。若约定于二月给付我、于一月给付提提乌斯，则可能产生疑问。不过，更正确的意见是该约定有效；因为对我的债务也附有期限，所以在二月之前也可以给付给我；因此，也可以给付给提提乌斯。

<!-- source-p 774 -->
<a id="46.3.98.5"></a>**5**　有人约定“给付给自己或提提乌斯”，并如此表述：“若你未给付提提乌斯，就给付给我”，则应认为他是附条件约定给付给自己。因此，若要式口约如此订立：“给付十给我，或给付五给提提乌斯”，而已向提提乌斯支付五，允诺人即对约定者免责。只有在明确意在将该事项作为类似罚则附加给约定者，即若未向提提乌斯清偿便须给付约定者时，才可作此处理。若仅仅约定“给付给自己或提提乌斯”，则提提乌斯仅是为了接受清偿而被附加；即使已向其给付五，剩余五仍是债务。反之，若我约定给付五给自己、十给提提乌斯，向提提乌斯支付五并不能使允诺人对我免责；而若他给付十，则我不得请求返还五，反而可通过委任之诉向其请求十。

<!-- source-p 775 -->
<a id="46.3.98.6"></a>**6**　我约定在罗马给付给我，或在以弗所给付给提提乌斯。我们应考察，若已在以弗所向提提乌斯付款，允诺人是否因此对我免责。依尤利安的见解，若两个给付地点分别约定，这就是不同事项。但若给付原因仍居于主导地位，债务人即获免责；因为即使我约定给付斯提库斯给我、给付潘菲卢斯给提提乌斯，后来向提提乌斯交付潘菲卢斯，也应免责。若我约定的纯粹是作为，例如在我的土地上或提提乌斯的土地上建造一座岛状建筑，是否应认为在提提乌斯土地上建造不能免责？毕竟无人认为，以一种行为履行另一种行为即可免责。但更正确的看法是，债务人因此免责，因为这并非以一种行为代替另一种行为，而是允诺人完成了其选择。

<!-- source-p 776 -->
<a id="46.3.98.7"></a>**7**　若用益权人的奴隶以用益权人的财产为基础，向所有权人或用益权人约定给付，则要式口约无效；但若是以所有权人的财产为基础，向所有权人本人或用益权人约定给付，则要式口约有效。在后一情形中，用益权人只能受领清偿，而不能取得债权。

<!-- source-p 777 -->
<a id="46.3.98.8"></a>**8**　我允诺交付一块属于他人的地基；该物所有人在地基上建造了一座岛状建筑。问题是，要式口约是否消灭。我答复：若我允诺交付他人所有的奴隶，而该奴隶被所有人释放，我即免责。塞尔苏斯所说的情形并未被接受：若该人依某项法律再次成为奴隶，债权人可以请求交付他。债务一经永久消灭，就不能恢复；即使他重新成为奴隶，也应视为另一个人。也不能以同样理由作如下类比：你允诺交付一艘船，所有人将其拆散，后又用同样木板重新拼装，你便仍负有责任。船仍是你曾允诺交付的那一艘，因此更应认为只是债务暂时停止，而非永久消灭。只有在拆船时意在将木板改作他用、之后又改变主意用同一批木板重新拼装的情况下，才与被释放的奴隶相似；因为后来拼装的船是另一艘，正如后来出现的是另一个人。地基与这些情形不同：建筑建成后，地基并未退出自然界；事实上仍可请求交付地基及其估价，因为地基是岛状建筑的组成部分，而且是其中最重要的部分，地上建筑随土地而归属。若允诺交付的奴隶被敌人俘获，结论则不同：在此期间，不能在期限到来前请求给付；但他若依返还权利回归，此时即可请求，因为债务只是暂时停止。地基则仍然存在，正如构成建筑的其他材料一样。最后，《十二表法》承认，嵌入房屋的木料仍可主张返还，但暂时禁止取回，并命令支付其价款。
