# D.29.7 论遗嘱附录（*De iure codicillorum*）

<!-- source-p 001 -->
<a id="7"></a><a id="29.7"></a>**29.7.0. 论遗嘱附录的法律。**

<!-- source-p 002 -->
<a id="29.7.1"></a>**29.7.1**

<!-- source-p 003 -->
**乌尔比安：《论疑义》第四卷。**

<!-- source-p 004 -->
人们屡次以敕答和决议规定：某人以为自己是在订立遗嘱，却不愿该文书作为遗嘱附录发生效力的，应视为也未订立遗嘱附录。因此，写在该遗嘱中的内容，尽管本可作为遗嘱附录发生效力，仍不得请求履行。

<!-- source-p 005 -->
<a id="29.7.2"></a>**29.7.2**

<!-- source-p 006 -->
**尤利安：《学说汇纂》第三十七卷。**

<!-- source-p 007 -->
<a id="29.7.2.pr."></a>**序言。**如果遗嘱附录以遗嘱信托的方式，向遗嘱订立后、遗嘱附录书写前出生的人给予某物，该给予有效。

<!-- source-p 008 -->
<a id="29.7.2.1"></a>**1.**但如果给予某人的某物，而此人在遗嘱订立后、遗嘱附录书写前已经死亡，则该给予视为未书写。

<!-- source-p 009 -->
<a id="29.7.2.2"></a>**2.**遗嘱附录适用一项特殊规则：其中所写的一切，均如同写在遗嘱中一样对待。因此，对于在遗嘱订立时属于立遗嘱人的奴隶、而在遗嘱附录订立时已不属于立遗嘱人的奴隶，不得以直接方式给予自由。反之，如果某奴隶在订立遗嘱时属于他人、而在遗嘱附录订立时已属于立遗嘱人，则视为立遗嘱人向他人的奴隶给予了自由。因此，尽管直接授予自由不能成立，仍应转而适用遗嘱信托方式授予自由。〔底本文字疑误：*essententiarum*；据句法暂按 *essent* 理解。〕

<!-- source-p 010 -->
<a id="29.7.2.3"></a>**3.**精神错乱者不被视为能够订立遗嘱附录，因为他也不被视为能够实施其他任何行为；在各方面、所有情形下，他均被视同不在场或处于沉睡状态。

<!-- source-p 011 -->
<a id="29.7.2.4"></a>**4.**遗嘱中无效给予的遗产，不能在遗嘱附录中作为遗产予以确认；但可以依据遗嘱信托请求该遗产，同时仍适用《法尔基迪亚法》。

<!-- source-p 012 -->
<a id="29.7.3"></a>**29.7.3**

<!-- source-p 013 -->
**尤利安：《学说汇纂》第三十九卷。**

<!-- source-p 014 -->
<a id="29.7.3.pr."></a>**序言。**某人没有遗嘱，却在遗嘱附录中以如下方式设立遗嘱信托：“凡将成为我的继承人或遗产占有人者，我均委托其诚信履行。”此类遗嘱信托应当履行。因为，一个享有遗嘱能力的家父在订立遗嘱附录时，应视同将一切法定继承或遗产占有本会归于其名下之人，均视为自己的继承人。

<!-- source-p 015 -->
<a id="29.7.3.1"></a>**1.**即使在遗嘱附录订立后，最近顺位的宗亲继承人或自权继承人才出生，也应履行遗嘱信托。因为此人也被视为已经被指定为继承人，因此不应将其视同使遗嘱附录失效的人。

<!-- source-p 016 -->
<a id="29.7.3.2"></a>**2.**即使订立了遗嘱，而遗嘱中未确认遗嘱附录，遗嘱附录仍从遗嘱取得效力。由此，如果无人依据遗嘱接受遗产，则此类遗嘱附录所设的遗嘱信托即不发生效力。

<!-- source-p 017 -->
<a id="29.7.4"></a>**29.7.4**

<!-- source-p 018 -->
**尤利安：《学说汇纂》第六十三卷。**

<!-- source-p 019 -->
已经决定：某人在订立遗嘱附录时有清偿能力，即可有效地给予自由，即使他在订立遗嘱时没有清偿能力。

<!-- source-p 020 -->
<a id="29.7.5"></a>**29.7.5**

<!-- source-p 021 -->
**帕比尼安：《答复集》第七卷。**

<!-- source-p 022 -->
在遗嘱文书之前订立的遗嘱附录，只有在其后订立的遗嘱或遗嘱附录中得到确认，或者其意愿以其他某种迹象得到保留时，才有效；但死者最后另作决定的事项，不予保留。

<!-- source-p 023 -->
<a id="29.7.6"></a>**29.7.6**

<!-- source-p 024 -->
**马尔基安：《法学阶梯》第七卷。**

<!-- source-p 025 -->
<a id="29.7.6.pr."></a>**序言。**神圣塞维鲁皇帝和安东尼努斯皇帝以敕答规定：母亲先以无条件方式指定其子女为继承人，随后又在遗嘱附录中附加解放条件，并未产生效力；因为她既不能在遗嘱附录中为已指定的继承人附加条件，也不能以直接方式指定替补继承人。

<!-- source-p 026 -->
<a id="29.7.6.1"></a>**1.**一人可以订立数份遗嘱附录；遗嘱附录无须由其本人亲笔书写，也无须由其本人签署。

<!-- source-p 027 -->
<a id="29.7.6.2"></a>**2.**即使家父在确认遗嘱附录时附加规定，只有经其亲笔签署并写有其亲笔签名的遗嘱附录才有效，他后来亲自订立的遗嘱附录仍然有效，即使该附录既未由其签署，也非其亲笔所写。因为后来的行为会减损先前行为的效力。

<!-- source-p 028 -->
<a id="29.7.6.3"></a>**3.**只有能够订立遗嘱的人，才可以订立遗嘱附录。

<!-- source-p 029 -->
<a id="29.7.6.4"></a>**4.**如果某人在遗嘱订立后、立遗嘱人死亡后，又在遗嘱附录中作出遗赠，即使该遗嘱附录已在遗嘱中得到确认，该遗赠仍视为未书写。

<!-- source-p 030 -->
<a id="29.7.7"></a>**29.7.7**

<!-- source-p 031 -->
**马尔基安：《规则集》第二卷。**

<!-- source-p 032 -->
<a id="29.7.7.pr."></a>**序言。**有些事项不属于遗嘱附录确认效力的范围。例如，某人在被俘前确认遗嘱附录，却在被俘期间书写遗嘱附录，这些遗嘱附录不发生效力。如果某人因任何原因丧失订立遗嘱的能力，亦同。

<!-- source-p 033 -->
<a id="29.7.7.1"></a>**1.**此外，对于属于事实而非法律的问题，遗嘱附录中的记载，不应一概视同写在确认遗嘱附录之处。例如，遗嘱附录中写道：“我所有的衣物”（*Vestem quae mea est*），应以订立遗嘱附录时的情形为准，而非以确认遗嘱附录时为准。同样，如果某人在遗嘱附录中向塞伊乌斯作出遗赠，写道：“如果提图斯尚在人世”（*si Titius vivus est*），或“如果他已满若干年”（*si tot annis est*），也应考察遗嘱附录订立时的情形，而非遗嘱订立时的情形。

<!-- source-p 034 -->
<a id="29.7.8"></a>**29.7.8**

<!-- source-p 035 -->
**保罗：《论遗嘱附录法》单卷。**

<!-- source-p 036 -->
<a id="29.7.8.pr."></a>**序言。**遗嘱附录有四种订立方式：确认其对将来发生效力；确认其对过去发生效力；在订立遗嘱后以遗嘱信托方式设立；或者在没有遗嘱的情况下订立。

<!-- source-p 037 -->
<a id="29.7.8.1"></a>**1.**无遗嘱继承人可以从遗嘱附录取得遗嘱信托，原因在于，人们认为家父自愿将法定继承份额留给了他们。

<!-- source-p 038 -->
<a id="29.7.8.2"></a>**2.**只有能够订立遗嘱的人，遗嘱附录才有效。但不能将此理解为：要求其在书写遗嘱附录的具体时刻也能够订立遗嘱。因为，如果他当时无法找到足够数量的证人，又该如何？应当要求的是，他享有遗嘱行为能力。

<!-- source-p 039 -->
<a id="29.7.8.3"></a>**3.**某人订立遗嘱后，在遗嘱中确认遗嘱附录；随后他使自己被收养（*adrogatio*），并在此期间订立遗嘱附录，之后被解放出家父权支配而死亡。问题是，是否应依遗嘱附录履行遗赠：遗嘱本身仍然有效，但他订立该遗嘱附录时并无遗嘱行为能力。这种情形不同于哑者适当确认遗嘱附录的情形：哑者虽不能订立遗嘱，但其先前订立的遗嘱仍保持原状；而此人的遗嘱已经被废除，他在某种意义上处分的是他人财产。不过，我们仍应说遗嘱附录有效；因为，即使遗腹子出生而使遗嘱失效，随后该遗腹子又死亡，遗嘱附录仍然有效。

<!-- source-p 040 -->
<a id="29.7.8.4"></a>**4.**军人在服役前订立了遗嘱，却在服役期间订立遗嘱附录，问题是该遗嘱附录能否依军人法有效：因为遗嘱依普通法有效，除非军人在服役期间签署该遗嘱或对其作了增补。可以确定的是，服役期间订立的遗嘱附录不应被视为归属于该遗嘱；但其依军人法有效。

<!-- source-p 041 -->
<a id="29.7.8.5"></a>**5.**如果某奴隶在遗嘱中取得遗赠，后又在遗嘱附录中获赐自由，我们应当说该遗赠有效，仿佛自始即已成立。

<!-- source-p 042 -->
<a id="29.7.8.6"></a>**6.**如果某人确认了特定种类的遗嘱附录，例如“我最后订立的遗嘱附录”，那么，只要仍可能订立其他遗嘱附录，其中所作的给予就不应立即视为成立。因此，如果后来另行订立了遗嘱附录，先前遗嘱附录中的遗赠即不发生效力。

<!-- source-p 043 -->
<a id="29.7.9"></a>**29.7.9**

<!-- source-p 044 -->
**马尔凯鲁斯：《学说汇纂》第九卷。**

<!-- source-p 045 -->
阿里斯托认为，如果订立遗嘱附录的人不知道自己是否为家父，该遗嘱附录无效。乌尔比安批注说：除非此人是退伍军人；在这种情况下，其遗嘱也有效。

<!-- source-p 046 -->
<a id="29.7.10"></a>**29.7.10**

<!-- source-p 047 -->
**帕比尼安：《疑义集》第十五卷。**

<!-- source-p 048 -->
一项传承下来的规则认为，遗嘱附录不能指定继承人，其理由在于：既然遗嘱附录的效力来自遗嘱，就不应使人认为，遗嘱本身——其效力源于继承人的指定——竟能由遗嘱附录予以确认。

<!-- source-p 055 -->
<a id="29.7.13"></a>**29.7.13**

<!-- source-p 056 -->
**帕比尼安：《疑义集》第十九卷。**

<!-- source-p 057 -->
<a id="29.7.13.pr."></a>**序言。**毫无疑问，不能说女儿也应被迫为奴隶授予自由，因为父亲未曾向她提出任何要求，而且她是依法以自己的权利成为继承人的。

<!-- source-p 058 -->
<a id="29.7.13.1"></a>**1.**通常会讨论这样一种情形：某人没有订立遗嘱，却在遗嘱附录中写道：“我希望提图斯成为继承人”（*Titium heredem esse volo*）。对此必须作重要区分：他究竟是想以这份意在具有遗嘱附录性质的书面文件，要求法定继承人以遗嘱信托方式交付遗产；还是以为自己正在订立遗嘱。若属后一情形，便不能向法定继承人请求任何给付。其意愿通常可从该书面文件中判明：例如，如果他向提图斯留下遗赠，并写明若提图斯未成为继承人，则由某人作为替补继承人，那么毫无疑问，应认定他意在订立的不是遗嘱附录，而是遗嘱。

<!-- source-p 059 -->
<a id="29.7.14"></a>**29.7.14**

<!-- source-p 060 -->
**斯凯沃拉：《疑义集》第八卷。**

<!-- source-p 061 -->
<a id="29.7.14.pr."></a>**序言。**有人记述——据我在维维安努斯处所读——萨比努斯、卡西乌斯与普罗库鲁斯曾就下列问题阐述争议：在被指定的继承人死亡后，才于遗嘱附录中增列或撤销的遗赠，是否应由替补继承人履行；也就是说，此时在遗嘱附录中作出的给予或撤销，是否与在遗嘱中作出时具有同等效力。据说萨比努斯和卡西乌斯作肯定答复，普罗库鲁斯则持异议。萨比努斯和卡西乌斯的推理，大概如他们自己所陈述的那样：遗嘱附录被视为遗嘱的一部分，并应遵循由遗嘱所确立的审查方式和法律规则。我则敢于说，普罗库鲁斯的见解最为正确。向遗嘱附录订立时已不在人世的人所作的遗赠，毫无效力，即使此人在遗嘱订立时尚在人世。受遗赠人必须存在，然后才能讨论给予是否成立；法律问题的考察，不应先于受益人的考察。因此，在本案中，继承人死亡后才在遗嘱附录中作出的遗赠或撤销，均毫无效力；因为作为遗嘱附录言辞所指向的继承人已不在人世，此时作出的给予或撤销也就无效。这适用于这样的情形：一名继承人被指定取得全部遗产，并另有替补继承人，而遗嘱附录由该被指定的继承人确认。

<!-- source-p 062 -->
<a id="29.7.14.1"></a>**1.**如果指定了两名继承人并为其指定替补继承人，其中一人死亡，那么遗赠似乎仍然有效。不过，关于共同继承人会有争议：如果遗赠的受益人写作“凡将成为我的继承人者”，共同继承人是否应负担全部遗赠？或者，由于存在一名替补继承人分得一份遗产，即使该替补继承人本人并不负担遗赠，是否仍应如此？对于明确写明姓名的受益人，也可以讨论同一问题。我认为共同继承人单独负担全部遗赠的看法更有说服力，因为与他共同成为继承人的替补继承人，在其被列为共同继承人时尚未出生于世。

<a id="29.7.16"></a>**29.7.16**

<!-- source-p 067 -->
**保罗：《疑义集》第二十一卷。**

<!-- source-p 068 -->
在无遗嘱情形下订立的遗嘱附录，其中所留下的给付，也应由后来出生并以无遗嘱继承人身份继承的人履行。无论何人以无遗嘱继承人身份继承，遗嘱附录均适用；因为这属于同一种情形，继承人是谁并不重要，只要其系无遗嘱继承即可。至于遗嘱附录涉及任何时候所订立的遗嘱，则应适用该遗嘱。更明确地说，家父无遗嘱死亡时，遗嘱附录无须另行确认，而是发挥遗嘱的作用；已经订立遗嘱的，遗嘱附录则遵循该遗嘱的法律规则。

**塞尔苏斯：《学说汇纂》第二十卷。**

<!-- source-p 074 -->
普洛提阿娜致其友塞尔苏斯，问候。卢基乌斯·提图斯曾以如下措辞作出规定：“如果我以遗嘱文书或其他方式留下任何与本遗嘱有关的内容，我希望其有效。”我想请教，在这份遗嘱之前书写的遗嘱附录，是否应予认可。尤文提乌斯·塞尔苏斯答普洛提阿娜，问候。这些话——“如果我留下任何与本遗嘱有关的内容，我希望其有效”——也包括在遗嘱之前书写的内容。

<!-- source-p 075 -->
<a id="29.7.19"></a>**29.7.19**

<!-- source-p 076 -->
**马尔凯鲁斯：《学说汇纂》第十四卷。**

<!-- source-p 077 -->
某人只有一个儿子，他写了遗嘱附录留给该儿子，随后未立遗嘱而死亡；该儿子与其后出生的继承人一同成为继承人。没有人会说，自权继承人的加入使遗嘱附录失效。因此，如果当时未曾预期会有遗腹子，该遗嘱附录就不会失效；其中所留下的给付，应由作为受遗嘱附录指定对象的儿子按二分之一份额履行，遗腹子则无须履行。又如某人留有遗嘱附录，写给其当时尚存的两个儿子，但他以为其中一人已经先死；同样可以说，受遗嘱附录指定的儿子应当像自己是父亲唯一继承人那样履行全部给付。其实，他只应履行相应份额；但是，对于不能按份额履行的事项，均无须履行，因为若非认为该儿子将是自己的唯一继承人，父亲本不会从该儿子处取走这些财物。

<!-- source-p 079 -->
**保罗：《尤利亚法与帕皮亚法评注》第五卷。**

<!-- source-p 080 -->
如果某人以口头方式公开指定继承人，而在遗嘱文书中列入遗赠，尤利安说：没有写明继承人的遗嘱文书，不应被视为遗嘱；与其说它是遗嘱，不如说它应被认为是遗嘱附录。我认为这种说法更为正确。
