# D.29.6 论禁止或强迫他人立遗嘱（*Si quis aliquem testari prohibuerit vel coegerit*）

<!-- source-p 001 -->
<a id="6"></a><a id="29.6"></a>**29.6.0. 论禁止或强迫他人立遗嘱。**

<!-- source-p 002 -->
<a id="29.6.1"></a>**29.6.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第四十八卷。**

<!-- source-p 004 -->
<a id="29.6.1.pr."></a>**序言。**某人为了谋求法定继承或遗嘱继承，在他人意欲订立或变更遗嘱时阻止其立遗嘱；神圣哈德良皇帝规定，应拒绝给予该人诉权；拒绝其诉权后，应由国库取得该遗产。

<!-- source-p 005 -->
<a id="29.6.1.1"></a>**1.**如果所有人以欺诈手段阻止变更遗嘱，而其奴隶原在遗嘱中被指定为继承人，那么即使该奴隶已获释并接受了遗产，也应拒绝给予该所有人诉权。若遗嘱中有财产给予其子女，也应作同样处理，即使这些子女不受其家父权支配。但如果遗嘱向该人留下遗赠，并要求他返还该遗赠，那么应当说，允许他取得该遗赠；因为他并非为自己保有该遗赠，而是要将其转给他人。

<!-- source-p 006 -->
<a id="29.6.1.2"></a>**2.**如果数人被指定为继承人，且他们全都以欺诈手段阻止变更遗嘱，那么应当说，应拒绝向所有人给予诉权，因为所有人均实施了欺诈。

<!-- source-p 007 -->
<a id="29.6.2"></a>**29.6.2**

<!-- source-p 008 -->
**保罗：《告示评注》第四十四卷。**

<!-- source-p 009 -->
<a id="29.6.2.pr."></a>**序言。**如果某人恶意使证人不能到场，从而使立遗嘱的机会落空，那么应拒绝向实施该恶意行为者给予诉权，无论其是法定继承人，还是在先前遗嘱中被指定为继承人。

<!-- source-p 010 -->
<a id="29.6.2.1"></a>**1.**兄弟一人的行为，不损害其兄弟。

<!-- source-p 011 -->
<a id="29.6.2.2"></a>**2.**如果某人因其欺诈行为而受托返还遗产，该遗产即成为附有其负担的失权遗产（*caduca*）；因此，国库取得《法尔基迪亚法》所规定的利益，而遗嘱信托受益人取得四分之三份额。

<!-- source-p 012 -->
<a id="29.6.3"></a>**29.6.3**

<!-- source-p 013 -->
**帕比尼安：《答复集》第十五卷。**

<!-- source-p 014 -->
我答复说：丈夫并未以暴力或欺诈方式阻止妻子在改变主意后订立遗嘱附录；他只是像通常那样，以夫妻间的言辞安抚了患病妻子所受的冒犯。因此，他不构成应受指控的行为；也不得剥夺他依遗嘱所获之物。
