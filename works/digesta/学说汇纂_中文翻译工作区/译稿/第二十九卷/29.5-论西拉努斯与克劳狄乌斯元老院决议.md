# D.29.5 论西拉努斯与克劳狄乌斯元老院决议：不得开启其遗嘱之人的遗嘱（*De senatus consulto Silaniano et Claudiano: quorum testamenta ne aperiantur*）

<!-- source-p 001 -->
<a id="5"></a><a id="29.5"></a>**29.5.0. 论西拉努斯与克劳狄乌斯元老院决议：不得开启其遗嘱之人的遗嘱。**

<!-- source-p 002 -->
<a id="29.5.1"></a>**29.5.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第五十卷。**

<!-- source-p 004 -->
<a id="29.5.1.pr."></a>**序言。**任何住宅若要安全，奴隶就必须被迫不惜自身性命，保护主人免受家内人员和外来者的侵害。为此，元老院制定了有关对被杀者家内奴隶进行公开调查的决议。

<!-- source-p 005 -->
<a id="29.5.1.1"></a>**1.**“主人”一词包括享有所有权的人，即使用益权属于他人。

<!-- source-p 006 -->
<a id="29.5.1.2"></a>**2.**善意占有奴隶的人不包括在“主人”一词之内；仅享有奴隶用益权的人也不包括在内。

<!-- source-p 007 -->
<a id="29.5.1.3"></a>**3.**就债务人被杀一事而言，已出质的奴隶在各方面均视同未曾出质。

<!-- source-p 008 -->
<a id="29.5.1.4"></a>**4.**“奴隶”一词也包括附条件遗赠的奴隶：在条件成就之前，他们属于继承人；条件成就使他们不再属于继承人，并不改变他们在此期间曾属于继承人的事实。附条件获释的奴隶也应如此处理。

<!-- source-p 009 -->
<a id="29.5.1.5"></a>**5.**但对于无条件享有遗嘱信托自由权的人，神圣皮乌斯曾向尤文提乌斯·萨比努斯作出敕答，指出不应急于对其施以刑讯。较可取的意见是，不应仅因他当时身处同一屋檐下便处罚他，除非他参与了犯罪。

<!-- source-p 010 -->
<a id="29.5.1.6"></a>**6.**“主人”一词也应包括仅享有部分所有权的人。

<!-- source-p 011 -->
<a id="29.5.1.7"></a>**7.**“主人”一词也包括家子及其他处于父权之下的子女；因为西拉努斯元老院决议不仅适用于家父，也适用于其子女。

<!-- source-p 012 -->
<a id="29.5.1.8"></a>**8.**那么，如果子女不处于父权之下，应如何处理？马尔凯卢斯在《学说汇纂》第十二卷对此有所疑问。我认为应作较宽泛的解释，使决议也适用于不处于父权之下的子女。

<!-- source-p 013 -->
<a id="29.5.1.9"></a>**9.**我们认为，某人被交付他人收养时，不适用该元老院决议；但被收养为子女的人，则适用该决议。

<!-- source-p 014 -->
<a id="29.5.1.10"></a>**10.**养育的孩子被杀时，也不适用该元老院决议。

<!-- source-p 015 -->
<a id="29.5.1.11"></a>**11.**母亲的儿子或女儿被杀时，不对母亲的奴隶进行调查。

<!-- source-p 016 -->
<a id="29.5.1.12"></a>**12.**斯凯沃拉精当地指出，如果父亲被敌人俘获，而儿子被杀，应对奴隶进行调查并施以刑罚；如果儿子在父亲死亡后、但在父亲的自家继承人成为继承人之前被杀，死后也应如此处理。

<!-- source-p 017 -->
<a id="29.5.1.13"></a>**13.**斯凯沃拉还指出，如果父亲指定儿子为继承人，而在遗产被接受之前儿子遭杀害，那么对已被无条件遗赠或已被给予自由的奴隶，应进行调查并施以刑罚。尽管若儿子仍在世并成为继承人，这些奴隶本不会属于他，但儿子一旦死亡，遗赠与自由权便告消灭，因此应认为该元老院决议适用。

<!-- source-p 018 -->
<a id="29.5.1.14"></a>**14.**如果父亲被杀，是否应对儿子的奴隶进行调查，例如儿子以军营特有产拥有奴隶？较可取的意见是，应对儿子的奴隶进行调查并施以刑罚，即使该儿子不处于父亲的父权之下。

<!-- source-p 019 -->
<a id="29.5.1.15"></a>**15.**如果丈夫或妻子被杀，也应调查他们的奴隶；尽管丈夫的奴隶并不严格属于妻子，妻子的奴隶也不严格属于丈夫，但由于家庭财产相互交融，且同处一宅，元老院决定，应如同对待自己所有的奴隶那样处理。

<!-- source-p 020 -->
<a id="29.5.1.16"></a>**16.**但元老院决定，妻子或丈夫被杀时，不应调查岳父或公公的奴隶。马尔凯卢斯在《学说汇纂》第十二卷则正确地说，对于岳父或公公的奴隶，应与丈夫的奴隶同样处理。

<!-- source-p 021 -->
<a id="29.5.1.17"></a>**17.**拉贝奥写道，“被杀者”包括遭暴力或殴打而死的人，例如被割喉、勒死、推下高处、用石块、棍棒或石头击打，或以其他武器杀死的人。

<!-- source-p 022 -->
<a id="29.5.1.18"></a>**18.**但如果某人被毒药杀死，或者以其他通常秘密杀人的方式被害，该元老院决议便不适用于追究其死亡。原因在于，奴隶之所以受罚，是因为他们未在有能力抵御暴力、援助主人时伸出援手；至于面对以毒药或其他秘密手段行事的埋伏者，他们又能做些什么呢？

<!-- source-p 023 -->
<a id="29.5.1.19"></a>**19.**当然，如果毒药是以暴力强行灌入，则适用该元老院决议。

<!-- source-p 024 -->
<a id="29.5.1.20"></a>**20.**因此，凡使用通常足以致死的暴力之处，都应认定该元老院决议适用。

<!-- source-p 025 -->
<a id="29.5.1.21"></a>**21.**那么，如果据称主人并非遭暴力，而是被毒药杀死，难道犯罪行为就不受惩罚吗？绝非如此。尽管西拉努斯元老院决议不适用，也不对同一屋檐下的人进行调查和处刑，但凡知情或参与犯罪的人，仍应受刑罚；遗产仍可在调查之前被接受，遗嘱文书也可在调查之前开启。

<!-- source-p 026 -->
<a id="29.5.1.22"></a>**22.**如果某人自杀，西拉努斯元老院决议固然不适用，但仍应追究其死亡：如果他当着奴隶的面自杀，而奴隶本可阻止他伤害自己，却未予阻止，就应处罚奴隶；若奴隶无力阻止，则应予以宽免。

<!-- source-p 027 -->
<a id="29.5.1.23"></a>**23.**如果某人并非因畏惧迫近的刑事指控，而是因厌倦生活或无法忍受痛苦而自杀，其遗嘱仍可开启并宣读；其死亡情形不妨碍此事。

<!-- source-p 028 -->
<a id="29.5.1.24"></a>**24.**还应知道，除非能够确认某人遭到杀害，否则不得对家内奴隶进行调查。因此，必须查明其死于犯罪行为，该元老院决议才适用。

<!-- source-p 029 -->
<a id="29.5.1.25"></a>**25.**这里所说的“调查”，不只指刑讯，也包括对死亡原因所作的一切查明和抗辩。

<!-- source-p 030 -->
<a id="29.5.1.26"></a>**26.**该元老院决议无论如何都会处罚曾在同一屋檐下的人；但对于不在同一屋檐下、而在同一地区的人，只有他们知情时才处罚。〔底本原文作 *conscii fuissententiarum*，疑有粘连或讹误。〕

<!-- source-p 031 -->
<a id="29.5.1.27"></a>**27.**我们来考察“同一屋檐下”应如何理解：是指同一组墙壁以内，还是也包括同一套房屋、同一房间、同一住宅、同一花园或整座庄园？塞克斯图斯说，人们曾多次这样裁判：凡在能够听到呼救声的地方的人，都应如同身处同一屋檐下而受罚；即使有些人声音较洪亮，有些人声音微弱，且并非所有人都能从四面八方听见呼救声。

<!-- source-p 032 -->
<a id="29.5.1.28"></a>**28.**神圣哈德良似乎也以如下措辞作出敕答：“奴隶每当能够援助主人时，不应把自己的安全置于主人的安全之上。那名与女主人同处一室的女奴，即使不能以身体相助，至少也能呼喊求救，让宅内的人或邻居听见；这从她说行凶者曾威胁，若她呼救便杀死她一事，显然可以看出。因此，她应受最严厉的刑罚；这样也可避免其他奴隶认为，主人遇险时人人都只应顾及自己。”

<!-- source-p 033 -->
<a id="29.5.1.29"></a>**29.**这份敕答包含许多内容：它不宽免与女主人同处一室的人，也不宽免因害怕死亡而未予援助的人；它还表明，奴隶至少也应以呼喊援助主人。

<!-- source-p 034 -->
<a id="29.5.1.30"></a>**30.**如果主人在庄园中被杀，而其地产范围极广，那么仅仅因为奴隶身处该地区，就对所有这些奴隶进行调查并处刑，未免过于不公。因此，只需调查那些与据称被杀的主人在一起，以及看起来有杀人嫌疑或知情的人。

<!-- source-p 035 -->
<a id="29.5.1.31"></a>**31.**如果主人在旅途中被杀，应当处罚那些在他被杀时与他同行的人，或者虽曾与他同行、后来却逃走的人。但如果主人被杀时没有任何人在他身边，这些元老院决议便不适用。

<!-- source-p 036 -->
<a id="29.5.1.32"></a>**32.**未达成年年龄的奴隶，以及尚未达到性成熟年龄的女奴，不属于同一情形；年龄可以构成宽免事由。

<!-- source-p 037 -->
<a id="29.5.1.33"></a>**33.**对未成年人，我们只是免除其刑罚，还是连调查也不进行？较可取的意见是，不应调查未成年人。其他案件中也通常遵循这一做法：未成年人不受刑讯，通常只以缰绳、藤条吓唬或鞭打。

<!-- source-p 038 -->
<a id="29.5.1.34"></a>**34.**未施恶意而提供援助的奴隶应获宽免。如果有人假装提供援助，或者只做做样子，这种伪装对他没有帮助。

<!-- source-p 039 -->
<a id="29.5.1.35"></a>**35.**不仅真正救下主人的人，也就是能够援助到使主人免于死亡的人，才算提供过援助；凡尽其所能采取行动的人，即使主人最终被杀，也同样算提供过援助。例如，有人呼喊召集他人前来援助，或吓退袭击者，或召集人群，或以身体挡在主人身前，或以其他身体行动提供援助。

<!-- source-p 040 -->
<a id="29.5.1.36"></a>**36.**但并非每个呼喊过的人都算提供援助。比如，他本可以亲手排除主人面临的危险，却选择徒劳呼喊；这种人当然应受惩罚。

<!-- source-p 041 -->
<a id="29.5.1.37"></a>**37.**如果奴隶在保护主人时受伤，应当宽免他们；但如果他们故意自伤以逃避惩罚，或者所受伤势实际上并不妨碍援助、若愿意仍本可以提供援助，就不应宽免。〔底本原文作 *si voluissententiarum*，疑有粘连或讹误。〕

<!-- source-p 042 -->
<a id="29.5.1.38"></a>**38.**如果主人虽受致命伤却活了下来，且没有指控任何奴隶，那么即使这些奴隶与他同处一屋檐下，也应宽免。

<!-- source-p 043 -->
<a id="29.5.2"></a>**29.5.2**

<!-- source-p 044 -->
**卡利斯特拉图斯：《司法审理论》第五卷。**

<!-- source-p 045 -->
神圣马尔库斯·科莫杜斯向皮索作出如下敕答：“亲爱的皮索，既然已经查明，尤利乌斯·多纳图斯在听闻强盗到来、逃离自己的庄园后受了伤，并且随后立下遗嘱，免除了其奴隶的责任，那么，无论是对奴隶的仁慈，还是继承人的顾虑，都不应使那些主人本人已经宣告无罪的人再被追究刑责。”

<!-- source-p 046 -->
<a id="29.5.3"></a>**29.5.3**

<!-- source-p 047 -->
**乌尔比安：《告示评注》第五十卷。**

<!-- source-p 048 -->
<a id="29.5.3.pr."></a>**序言。**如果某人身患重病，以致无法援助主人，应给予他宽免。

<!-- source-p 049 -->
<a id="29.5.3.1"></a>**1.**如果某人在临终时说自己是被奴隶以暴力杀害的，应当说不能仅凭主人临终时的话便相信他，除非能够对此加以证明。

<!-- source-p 050 -->
<a id="29.5.3.2"></a>**2.**如果丈夫在夜间于卧室内杀死与他同寝的妻子，或者妻子杀死丈夫，配偶的奴隶应免受元老院决议所定的刑罚。但如果他们听见了却没有援助，就应受惩罚；无论奴隶是妻子本人所有，还是丈夫所有，均同。

<!-- source-p 051 -->
<a id="29.5.3.3"></a>**3.**但如果丈夫当场发现妻子通奸而杀死她，由于法律宽恕丈夫，应当认为，不仅丈夫的奴隶，妻子的奴隶也应获释，只要他们没有阻止主人依法宣泄正当愤怒。

<!-- source-p 052 -->
<a id="29.5.3.4"></a>**4.**如果所有主人都遭到袭击，而奴隶只援助其中一人，他应否获宽免，还是因未援助所有主人而受罚？较可取的意见是，如果他本可援助所有人，即使已经援助其中一些人，也应受刑罚；但如果他无法同时援助所有人，则由于他曾援助其中一些人，应予宽免。若说一个奴隶无法同时援助两人，选择帮助其中一人反而构成犯罪，那就过于严苛了。

<!-- source-p 053 -->
<a id="29.5.3.5"></a>**5.**因此，如果女奴更援助了女主人的丈夫，而不是女主人，或者反过来援助了女主人而非其丈夫，也应宽免她。

<!-- source-p 054 -->
<a id="29.5.3.6"></a>**6.**如果主人或女主人被杀时，奴隶并无恶意地被关在某处，以致无法冲出救援，或无法抓住行凶者，应予宽免；至于是谁把他们关起来，并不重要。但如果他们故意把自己关起来，以免能够提供援助，则不在此列。被关押者也包括被捆绑的人，但前提是他们被捆得根本无法挣脱并提供援助。

<!-- source-p 055 -->
<a id="29.5.3.7"></a>**7.**年老体衰的人也应获宽免。

<!-- source-p 056 -->
<a id="29.5.3.8"></a>**8.**聋人也应列入无能力者，或者列入不在同一屋檐下的人；因为前者因距离听不到，聋人则因疾病听不到。

<!-- source-p 057 -->
<a id="29.5.3.9"></a>**9.**盲人也应获宽免。

<!-- source-p 058 -->
<a id="29.5.3.10"></a>**10.**哑人也应以同样方式获宽免，但仅限于援助只能通过声音提供的情形。

<!-- source-p 059 -->
<a id="29.5.3.11"></a>**11.**毫无疑问，精神失常者也应获宽免。

<!-- source-p 060 -->
<a id="29.5.3.12"></a>**12.**如果有人明知而故意接纳或藏匿该家内因犯罪而负有责任的任何奴隶或女奴，其地位与依《刺客法》对犯罪负有责任的人相同。

<!-- source-p 061 -->
<a id="29.5.3.13"></a>**13.**如果依据要式口约负有交付奴隶的义务，而该奴隶揭发主人被杀，并因此获准作为奖赏而自由，口约债权人不得提起要式口约之诉；即使该奴隶被处刑，也不会产生此项诉权。但如果该奴隶不在同一屋檐下，债权人仍可就该奴隶的估价提起有益的要式口约之诉。

<!-- source-p 062 -->
<a id="29.5.3.14"></a>**14.**究竟只有主动挺身指控的人才算揭发者，还是被告在自己受指控时将罪名转嫁给他人也算？较可取的意见是，只有主动挺身指控的人才应获得这项奖赏。

<!-- source-p 063 -->
<a id="29.5.3.15"></a>**15.**有些人原本无法获得自由，例如有人在出售奴隶时约定不得释放；但由于揭发之事关乎公共利益，他们也可以因此获得自由。

<!-- source-p 064 -->
<a id="29.5.3.16"></a>**16.**对依据遗嘱获得解放的奴隶，也应如同对其他奴隶一样施以刑罚。

<!-- source-p 065 -->
<a id="29.5.3.17"></a>**17.**如果奴隶在被杀者的遗嘱开启之前逃走，遗嘱开启后又发现他们被指定为自由人，则应如同对待奴隶一样对他们调查并施以刑罚。主人给予的宽免不应妨碍对主人被杀一事实施报复；而且，一个人享有的宽免越多，就越应因其犯罪而受到更重的处罚。

<!-- source-p 066 -->
<a id="29.5.3.18"></a>**18.**裁判官告示规定，在依元老院决议对家内奴隶完成调查并处罚罪犯之前，任何人不得明知而故意开启、宣读或抄录据称被杀之人遗留下的、与遗嘱事务有关的文书。

<!-- source-p 067 -->
<a id="29.5.3.19"></a>**19.**这里所说的“开启”，是指实际打开文书；无论文书是否加盖印封，还是仅仅以通常方式合拢，都在此列。

<!-- source-p 068 -->
<a id="29.5.3.20"></a>**20.**“禁止开启”应理解为，无论公开当众还是秘密开启，都在禁止之列；一切开启行为均被禁止。

<!-- source-p 069 -->
<a id="29.5.3.21"></a>**21.**如果某人不知道主人已被杀而开启遗嘱，不应受该告示约束。

<!-- source-p 070 -->
<a id="29.5.3.22"></a>**22.**即使他知道主人已被杀，但开启遗嘱并非出于故意，也同样不受约束；例如，他因缺乏经验或孤陋寡闻，不了解裁判官告示或元老院决议而开启遗嘱。

<!-- source-p 071 -->
<a id="29.5.3.23"></a>**23.**如果某人没有实际打开遗嘱文书，而只是割断了封缄的麻绳，应予宽免；因为没有打开遗嘱文书本身的人并无恶意。

<!-- source-p 072 -->
<a id="29.5.3.24"></a>**24.**如果开启的不是整份遗嘱，而只是其中一部分，应当说开启者违反了告示；因为开启全部还是部分并无区别。

<!-- source-p 073 -->
<a id="29.5.3.25"></a>**25.**如果某人开启了遗嘱补编，却没有开启遗嘱，也违反了告示；因为遗嘱补编同样涉及遗嘱事务。

<!-- source-p 074 -->
<a id="29.5.3.26"></a>**26.**无论被开启的文书依法有效与否，该告示均适用。

<!-- source-p 075 -->
<a id="29.5.3.27"></a>**27.**如果据称被杀的是未成年男孩或女孩，关于替代继承处分的文书也适用同样规则。

<!-- source-p 076 -->
<a id="29.5.3.28"></a>**28.**如果一人开启文书，另一人宣读，第三人抄录，那么实施各项行为的人都违反了告示。

<!-- source-p 077 -->
<a id="29.5.3.29"></a>**29.**该告示所涉继承不仅包括遗嘱继承，也包括无遗嘱继承。因此，在对家内奴隶进行调查之前，任何人不得接受遗产或请求遗产占有，以免继承人为自身利益而隐瞒家内犯罪。

<!-- source-p 078 -->
<a id="29.5.3.30"></a>**30.**斯凯沃拉精当地指出，如果某人在接受遗产之前死亡，要将有益诉权移转给其继承人，必须查明其未接受遗产正是因为害怕元老院决议和裁判官告示的规定。

<!-- source-p 079 -->
<a id="29.5.3.31"></a>**31.**如果有人被命令在死亡日起算所定期限内满足条件，却因不知情而未能满足；而其不知情是因为惧怕元老院决议、无法开启遗嘱文书所致，应给予救济，使其能够完成条件。

<!-- source-p 080 -->
<a id="29.5.3.32"></a>**32.**如果不接受遗产或不打开遗嘱文书还存在其他障碍，同时也存在元老院决议所致的障碍，那么元老院决议这一障碍并无助益，因为另有其他障碍。例如，被杀者的妻子怀孕，或者被认为怀孕，因此指定继承人无法接受遗产。

<!-- source-p 081 -->
<a id="29.5.4"></a>**29.5.4**

<!-- source-p 082 -->
**帕皮尼安：《答复集》第六卷。**

<!-- source-p 083 -->
某人指定遗腹子为继承人；如果遗腹子未出生，则由妻子按第二顺位继承。有人声称该人被家内奴隶杀害时，其妻已经死亡。该妇女的继承人请求依皇帝敕令取得诉权。我答复说，只有在能够确定该妇女并未怀孕、而她因元老院决议未能接受遗产时，才应听取他们的请求；否则，如果她是在怀孕时死亡，就不存在可以主张的侵害。

<!-- source-p 084 -->
<a id="29.5.5"></a>**29.5.5**

<!-- source-p 085 -->
**乌尔比安：《告示评注》第五十卷。**

<!-- source-p 086 -->
<a id="29.5.5.pr."></a>**序言。**我认为，必然继承人若介入遗产事务，也包括在告示之内。

<!-- source-p 087 -->
<a id="29.5.5.1"></a>**1.**裁判官也不允许请求遗产占有；我认为，该告示适用于所有种类的遗产占有。

<!-- source-p 088 -->
<a id="29.5.5.2"></a>**2.**只有在查明家父确遭杀害，且继承人在对家内奴隶进行调查并处罚罪犯之前已经接受遗产时，遗产才会被收归公产。

<!-- source-p 089 -->
<a id="29.5.5.3"></a>**3.**如果主人因疏忽或医生的阴谋而死亡，继承人仍可接受遗产，但应由继承人负责说明死亡原因。

<!-- source-p 090 -->
<a id="29.5.6"></a>**29.5.6**

<!-- source-p 091 -->
**保罗：《告示评注》第四十六卷。**

<!-- source-p 092 -->
<a id="29.5.6.pr."></a>**序言。**即使已经确定行凶者是谁，仍应进行调查，以查明是谁指使其犯罪；尤其应当首先对指使者进行调查，尽管其他人也会受到处罚。

<!-- source-p 093 -->
<a id="29.5.6.1"></a>**1.**虽然通常不得对奴隶施以刑讯以指控其主人，但即使奴隶指控的是继承人，也可以正当地进行调查；无论继承人是外人还是被继承人的自家继承人，均同。

<!-- source-p 094 -->
<a id="29.5.6.2"></a>**2.**如果共有人之一下落不明，应通过双方共有的奴隶查明其情况；因为此时对奴隶施刑，更多是为了保护或追究下落不明的主人，而非针对在场主人的本人。

<!-- source-p 095 -->
<a id="29.5.6.3"></a>**3.**如果有人企图杀害主人但未得逞，该元老院决议没有作出规定；因为主人可以自行惩罚自己的家内人员。

**保罗：《西拉努斯元老院决议论》单卷。**

<!-- source-p 100 -->
**保罗：《告示评注》第四十六卷。**

<!-- source-p 101 -->
<a id="29.5.8.pr."></a>**序言。**皮索元老院决议规定：如果出售的奴隶负有应受刑罚的责任，日后又对其执行刑罚，卖方应返还价款，以免元老院看起来损害买方利益。

<!-- source-p 102 -->
<a id="29.5.8.1"></a>**1.**如果家子军人就军营特有产立遗嘱后被杀，应当坚决主张：凡在家父的财产应归国库的情形下，该家子的军营特有产也应归国库，而不是归于那些在接受遗产等方面违法、又未为死者复仇的继承人。

<!-- source-p 103 -->
<a id="29.5.9"></a>**29.5.9**

<!-- source-p 104 -->
**盖尤斯：《行省告示评注》第十七卷。**

<!-- source-p 105 -->
如果死者的财产因其死亡未获复仇而被判归国库，可以对国库提起遗赠之诉；遗嘱所设的自由处分也有效，但仅限于该元老院决议所列的例外人员。

<!-- source-p 107 -->
**保罗：《西拉努斯元老院决议论》单卷。**

<a id="29.5.10.pr."></a>**序言。**如果被剥夺继承资格的儿子在父亲的遗产尚未被接受前遭到杀害，应根据事后结果判断：如果遗产已被接受，该儿子似乎应视为外人；但如果遗嘱被判无效，由于该儿子若仍在世本会成为财产所有人，一切都应视同他是主人。

<!-- source-p 109 -->
<a id="29.5.10.1"></a>**1.**神圣图拉真曾规定，应对死者生前已释放的自由民进行调查。

**特里丰尼努斯：《论辩集》第二卷。**

<!-- source-p 112 -->

<a id="29.5.13"></a>**29.5.13**

<!-- source-p 119 -->
<a id="29.5.14"></a>**29.5.14**

<!-- source-p 120 -->
**梅基安努斯：《公诉案件论》第十一卷。**

<!-- source-p 121 -->
西拉努斯元老院决议将未达成年年龄的奴隶排除在外。但行省长官特雷比乌斯·日耳曼努斯曾下令，即使奴隶未成年，也要对其施以刑罚；此举并非毫无道理：该男孩离成年已不远，主人被杀时他睡在主人脚边，事后却没有告发杀人一事。既然可以确定他当时无力援助，也可以确定他后来保持沉默。日耳曼努斯认为，元老院决议所宽免的未成年人，仅限于曾在同一屋檐下的人；至于作为帮手或共犯参与杀害主人、且虽未成年却已有能力理解行为的人，不应仅因其未成年而比其他犯罪案件获得更多宽免。

<!-- source-p 122 -->
<a id="29.5.15"></a>**29.5.15**

<!-- source-p 123 -->
**马尔西安：《告密者论》单卷。**

<!-- source-p 124 -->
<a id="29.5.15.pr."></a>**序言。**如果后顺位继承人替立遗嘱人报了杀人之仇，遗产是否应由前顺位继承人转归他？帕皮尼安说，不应如此；一人的刑罚不应成为另一人的奖赏。

<!-- source-p 125 -->
<a id="29.5.15.1"></a>**1.**某继承人被指定继承一部分遗产，也取得一项遗赠，但他没有追究死者被杀一事。神圣塞维鲁与安敦尼努斯以敕答确认，应同时剥夺其遗产份额和遗赠。

<!-- source-p 126 -->
<a id="29.5.15.2"></a>**2.**未追究死者被杀一事的继承人，无论依遗嘱还是依无遗嘱继承取得的财产，均应被剥夺；即使他们以保护人身份主张权利，似乎也应如此，尽管此时他们是基于自身权利取得财产。

<!-- source-p 127 -->
<a id="29.5.16"></a>**29.5.16**

**莫德斯汀：《规则集》第八卷。**

即使有人主张遗嘱违反义务，仍不禁止其对死者之死寻求追究；保罗也作了这样的答复。

继承人若正在查明毒杀一事，只要保全证据和线索，就不应被禁止处理遗产中亟须安排的事务。

<a id="29.5.21"></a>**29.5.21**

<!-- source-p 143 -->
**帕皮尼安：《答复集》第六卷。**

<!-- source-p 144 -->
<a id="29.5.21.pr."></a>**序言。**由于涉嫌毒杀而进行调查，并不延长请求遗产占有的期限；即使刑事指控尚未判定，仍可正当地请求遗产占有。主人被家内奴隶杀害时，元老院另有规定，显然是为了奴隶的利益：为了进行调查，必须暂不考虑他们可能取得的自由。

<!-- source-p 145 -->
<a id="29.5.21.1"></a>**1.**一名孙女请求取得祖母的遗产占有，明知祖母遭人杀害，却没有为她追究此事。裁定认为，在将财产返还国库时，不应扣除祖母依据另一份遗嘱欠该孙女的遗嘱信托；因为受到惩罚的是继承人的恶意。但如果该妇女只是因疏忽而丧失遗产利益，仍应保留遗嘱信托，因为其债权关系应恢复完整。

<!-- source-p 146 -->
<a id="29.5.21.2"></a>**2.**被告因行省长官不公而被宣告无罪。继承人已经认真履行应尽义务，即使没有提出上诉，也不应剥夺其遗产。

<a id="29.5.22"></a>**29.5.22**

<!-- source-p 148 -->
**保罗：《答复集》第十六卷。**

<!-- source-p 149 -->
盖乌斯·塞尤斯病势沉重时，抱怨自己正被其奴隶以毒药杀害，随即死亡。其妹妹卢基娅·提提娅继承了他的遗产，却没有追究其死因；十年后，她本人也死亡。此后有人告发盖乌斯·塞尤斯的财产。我问，提提娅死亡是否使该犯罪追诉消灭。保罗答复：本案所涉为财产请求，因此不能认为该请求已因忘恩继承人的死亡而消灭。

<!-- source-p 155 -->

<a id="29.5.25"></a>**29.5.25**

<!-- source-p 157 -->
**盖尤斯：《行省告示评注》第十七卷。**

<!-- source-p 158 -->
<a id="29.5.25.pr."></a>**序言。**《科尔内利亚法》规定了告发者的奖赏：告发者若搜寻并报告了该家内、在调查之前逃走的奴隶，每一名被其揭发定罪的奴隶，可从被杀者的财产中获得五枚金币；如果该数额无法从遗产中筹得，则由国库支付。这项奖赏并非给予所有曾在同一屋檐下或同一地点的奴隶，而只给予实施杀人行为的奴隶。

<!-- source-p 159 -->
<a id="29.5.25.1"></a>**1.**法律还规定，对于在调查前逃走、遗嘱开启后发现被指定为自由人的奴隶，应依《刺客法》审判；他们须在羁押状态下受审，定罪后应如同奴隶一样受罚。使其定罪的人，应从被定罪者的财产中获得十枚金币作为奖赏。

<!-- source-p 160 -->
<a id="29.5.25.2"></a>**2.**根据该告示，可以对被指称违反裁判官告示而开启遗嘱文书，或被指称实施其他相关行为的人提起诉讼；如前所述，告示规定了多种应受处罚的行为。显然，这是一种任何人均可提起的诉讼，罚金为从被定罪者财产中征收的一百枚金币。裁判官承诺，其中一半作为奖赏给予促成定罪的人，另一半则归入公库。

<!-- source-p 165 -->
**卡利斯特拉图斯：《国库法论》第一卷。**

<!-- source-p 166 -->
如果数名继承人中，有人未经同意或不知情，遗嘱仍被开启，那么没有过错的人不会丧失其继承份额。
