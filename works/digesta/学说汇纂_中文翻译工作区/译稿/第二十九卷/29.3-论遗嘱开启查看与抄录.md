# D.29.3 论遗嘱如何开启、查看及抄录（*Testamenta quemadmodum aperiantur inspiciantur et describantur*）

<!-- source-p 001 -->
<a id="3"></a><a id="29.3"></a>**29.3.0. 论遗嘱如何开启、查看及抄录。**

<!-- source-p 002 -->
<a id="29.3.1"></a>**29.3.1**

<!-- source-p 003 -->
**盖尤斯：《评行省告示》第十七卷。**

<!-- source-p 004 -->
<a id="29.3.1.pr."></a>**序言。**裁判官承诺，将准许任何希望查看或抄录遗嘱文书的人查看并抄录；显然，他既可以为自己，也可以为他人提出请求。

<!-- source-p 005 -->
<a id="29.3.1.1"></a>**1.**该告示的理由显而易见：对于遗嘱引起的争议，若不查看并知悉遗嘱文字，就既不能通过审判解决，也不能在法官面前查明真相。

<!-- source-p 006 -->
<a id="29.3.1.2"></a>**2.**若有人否认某印章是自己的，遗嘱文书仍应开启；但这会使文书受到怀疑。

<!-- source-p 007 -->
<a id="29.3.2"></a>**29.3.2**

<!-- source-p 008 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 009 -->
<a id="29.3.2.pr."></a>**序言。**遗嘱文书并非某一人的文件，也就是说，并非仅属于继承人的文件；凡其中记载有关事项的人，均与之有关。不如说，它是一份公共文件。

<!-- source-p 010 -->
<a id="29.3.2.1"></a>**1.**严格而言，只有依法完成的遗嘱才称为遗嘱；但我们也宽泛地把虚假、不合法、无效或被撤销的遗嘱称作遗嘱；同样，也常把未完成的遗嘱称作遗嘱。

<!-- source-p 011 -->
<a id="29.3.2.2"></a>**2.**凡是为遗嘱之事而作成的文书，不论写在何种材料上，只要载有最后意思，似乎都属于遗嘱事项；主要遗嘱文书和补充遗嘱文书均受该告示涵盖。

<!-- source-p 012 -->
<a id="29.3.2.3"></a>**3.**若请求出示数份遗嘱，应当准许请求人查阅全部遗嘱。

<!-- source-p 013 -->
<a id="29.3.2.4"></a>**4.**若无法确定请求查看、抄录遗嘱相关文书之人所指的人究竟仍在世还是已经死亡，应当认为裁判官须经审查案情作出决定；如果查明此人仍在世，就不应准许查看或抄录。

<!-- source-p 014 -->
<a id="29.3.2.4a"></a>**4a.**所谓查看遗嘱文书，是指查看其书写内容、印章以及请求人希望查看的其他文书事项。

<!-- source-p 015 -->
<a id="29.3.2.5"></a>**5.**查看遗嘱文书也包括阅读其内容。

<!-- source-p 016 -->
<a id="29.3.2.6"></a>**6.**裁判官不准许抄录或查看遗嘱文书上的日期和执政官姓名，以免发生伪造；因为查看本身也可能为制作伪件提供条件。

<!-- source-p 017 -->
<a id="29.3.2.7"></a>**7.**裁判官命令立即准许查看或抄录，还是应给请求人一段时间以便要求出示文书？较妥当的意见是，应依地点远近或路途长短给予相应时间。

<!-- source-p 018 -->
<a id="29.3.2.8"></a>**8.**若某人不否认遗嘱文书在自己手中，却不准许查看或抄录，应当强制其准许。若他否认文书由自己持有，则应依关于出示文书的禁令处理。

<!-- source-p 019 -->
<a id="29.3.3"></a>**29.3.3**

<!-- source-p 020 -->
**盖尤斯：《评行省告示》第十七卷。**

<!-- source-p 021 -->
遗嘱继承人也可以像对其他遗产物品一样，对遗嘱文书提起返还之诉；因此，也可以提起出示之诉。

<!-- source-p 022 -->
<a id="29.3.4"></a>**29.3.4**

<!-- source-p 023 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 024 -->
既然遗嘱文书从一开始就应当开启，裁判官的职责便是强令签署人会集，辨认各自的印章。

<!-- source-p 025 -->
<a id="29.3.5"></a>**29.3.5**

<!-- source-p 026 -->
**保罗：《评普劳提乌斯》第八卷。**

<!-- source-p 027 -->
即使有人否认自己曾签署遗嘱文书，结论也相同；因为让人们最后的意思得以实现，符合公共利益。

<!-- source-p 028 -->
<a id="29.3.6"></a>**29.3.6**

<!-- source-p 029 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 030 -->
但若大多数签署人已经到场，可以在他们参与下拆开遗嘱封印并宣读遗嘱。

<!-- source-p 031 -->
<a id="29.3.7"></a>**29.3.7**

<!-- source-p 032 -->
**盖尤斯：《评行省告示》第七卷。**

<!-- source-p 033 -->
若有签署人缺席，应将遗嘱文书送到他所在之处，以便他辨认自己的印章；为此召回他，负担过重。我们常常因此蒙受重大损失而被迫离开自己的事务；因履行自己的职责反而使任何人遭受损害，也是不公平的。缺席者是一人还是全体，均不影响这一点。即使全体签署人都缺席，而某种情形迫使遗嘱必须开启，行省总督也应设法使其在声誉卓著之人到场时开启；抄录并核验后，再由这些到场者重新封印，然后将文书送往签署人所在之处，以便他们查看自己的印章。

<!-- source-p 034 -->
<a id="29.3.8"></a>**29.3.8**

<!-- source-p 035 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 036 -->
关于未适婚人的遗嘱文书，即使没有在封面写明“不得开启”，但若立遗嘱人将其另行封印保存，裁判官未经查明案情，不得准许开启。

<!-- source-p 037 -->
<a id="29.3.9"></a>**29.3.9**

<!-- source-p 038 -->
**保罗：《评告示》第四十五卷。**

<!-- source-p 039 -->
若一名妇女以胎儿名义占有遗产，应当开启第二份遗嘱文书，以便查明受托管理事务的人是谁。

<!-- source-p 040 -->
<a id="29.3.10"></a>**29.3.10**

<!-- source-p 041 -->
**乌尔比安：《评尤利乌斯与帕皮乌斯法》第十三卷。**

<!-- source-p 042 -->
<a id="29.3.10.pr."></a>**序言。**若遗嘱写有两份副本，开启其中任一份，即视为遗嘱文书已经开启。

<!-- source-p 043 -->
<a id="29.3.10.1"></a>**1.**若遗嘱文书因其自身状态而已经开启，毫无疑问，应视为遗嘱已经开启；因为我们不必追问是谁开启的。

<!-- source-p 044 -->
<a id="29.3.10.2"></a>**2.**若遗嘱文书遗失或被焚毁，就应对受遗赠人给予救济；若文书被压下或隐藏，也是如此。

<!-- source-p 045 -->
<a id="29.3.11"></a>**29.3.11**

<!-- source-p 046 -->
**盖尤斯：《评尤利乌斯与帕皮乌斯法》第十一卷。**

<!-- source-p 047 -->
正如遗嘱附录被视为遗嘱的一部分，第二份遗嘱文书也应视为主要遗嘱文书的一部分。

<!-- source-p 048 -->
<a id="29.3.12"></a>**29.3.12**

<!-- source-p 049 -->
**乌尔比安：《评尤利乌斯与帕皮乌斯法》第十三卷。**

<!-- source-p 050 -->
若某人订立遗嘱并制作一份副本，仅开启副本并不意味着遗嘱本身已经开启；但若原件已经全部开启，则遗嘱即视为已经开启。
