# D.29.4 论舍弃遗嘱而按无遗嘱或其他依据占有遗产（*Si quis omissa causa testamenti ab intestato vel alio modo possideat hereditatem*）

<!-- source-p 001 -->
<a id="4"></a><a id="29.4"></a>**29.4.0. 论舍弃遗嘱而按无遗嘱或其他依据占有遗产。**

<!-- source-p 002 -->
<a id="29.4.1"></a>**29.4.1**

<!-- source-p 003 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 004 -->
<a id="29.4.1.pr."></a>**序言。**裁判官保护死者的意思，并制止某些人的狡诈：他们舍弃遗嘱继承这一依据，转而按无遗嘱继承的方式占有遗产或其中一部分，以此规避那些人——若非遗产由无遗嘱继承人占有，这些人本可依据死者的遗嘱取得利益。裁判官承诺对这类人提起诉讼。

<!-- source-p 005 -->
<a id="29.4.1.1"></a>**1.**某人能够亲自取得遗产，还是能够通过他人取得，并无区别。无论通过何种方式能够取得，只要他没有取得遗产，就处于适用裁判官告示的情形：

<!-- source-p 006 -->
<a id="29.4.1.2"></a>**2.**所谓舍弃遗嘱依据，是指某人本可以命令他人接受继承，却没有这样做。

<!-- source-p 007 -->
<a id="29.4.1.3"></a>**3.**那么，如果他的奴隶奉命接受继承，却不服从，如何处理？应当强令奴隶接受继承；因此，主人后来作为无遗嘱继承人取得遗产，就落入该告示的适用范围。

<!-- source-p 008 -->
<a id="29.4.1.4"></a>**4.**但若奴隶没有告知主人，而主人后来作为无遗嘱继承人占有遗产，则不应适用该告示，除非主人假称自己不知情。

<!-- source-p 009 -->
<a id="29.4.1.5"></a>**5.**如果某人既被指定为继承人，又被指定为替补继承人，却舍弃了原指定继承人的身份，是否适用该告示？我认为不适用，因为指定替补继承人的立遗嘱人已将这种选择权交给了他。

<!-- source-p 010 -->
<a id="29.4.1.6"></a>**6.**某人拒绝继承，也属于舍弃遗嘱依据。

<!-- source-p 011 -->
<a id="29.4.1.7"></a>**7.**处于家父权之下的人依遗嘱立即成为继承人；他们可以不介入遗产的事实，并不改变这一点。但如果他们后来介入遗产事务，就视为依遗嘱成为继承人；除非他们先依遗嘱放弃继承，却又以无遗嘱继承为由请求取得遗产占有。在这种情况下，他们就落入该告示的适用范围。

<!-- source-p 012 -->
<a id="29.4.1.8"></a>**8.**若某人被附条件指定为继承人，本可满足条件却没有满足，而条件是否成就又取决于该继承人自己的选择，之后此人却以无遗嘱继承为由占有遗产，就应受该告示约束；因为这类条件应视为无条件。

<!-- source-p 013 -->
<a id="29.4.1.9"></a>**9.**对于舍弃遗嘱依据而以无遗嘱继承为由占有遗产的人，我们不问其是否依合法继承权占有。无论依据何种法律理由占有遗产或其一部分，都可以依该告示对其提起诉讼；但若其基于其他原因占有，则不在此限。例如，某人虽放弃继承，却因遗嘱信托而受命占有遗产，以保全遗嘱信托财产；又如某人为了保全债权而取得占有。在这些情形下，他都不必因此对受遗赠人承担责任。由此可见，裁判官告示仅在下列情形适用：某人以法定继承人的身份占有遗产、作为无遗嘱继承人取得裁判官法上的遗产占有，或者作为仿佛无权占有者而占有遗产，虚构自己具有无遗嘱占有的依据。无论以何种方式取得遗产利益，他都应履行遗赠；但应提供担保，保证遗产被追夺时返还遗赠物。

<!-- source-p 014 -->
<a id="29.4.1.10"></a>**10.**即使某人没有占有遗产，但若其以诈欺故意阻止自己占有，也应如同已经接受继承一样承担责任。

<!-- source-p 015 -->
<a id="29.4.1.11"></a>**11.**某人以诈欺故意阻止自己占有遗产，是指他通过欺诈将占有转给他人，使受遗赠人及其他依遗嘱取得利益的人无法得到遗嘱留给他们的财产。

<!-- source-p 016 -->
<a id="29.4.1.12"></a>**12.**曾有人争论：只有以诈欺方式放弃自己曾经取得的占有，才算故意阻止占有；还是某人从一开始就以恶意不让自己取得占有，也同样属于这种情形？拉贝奥认为，从一开始就不取得占有的人，其过错不轻于后来停止占有的人；这一意见已获采纳。

<!-- source-p 017 -->
<a id="29.4.1.13"></a>**13.**若某人以欺诈方式放弃继承，以便遗产转归法定继承人，他仍须向受遗赠人承担责任。

<!-- source-p 018 -->
<a id="29.4.2"></a>**29.4.2**

<!-- source-p 019 -->
**乌尔比安：《评萨宾》第七卷。**

<!-- source-p 020 -->
<a id="29.4.2.pr."></a>**序言。**某人收取价款后放弃继承，虽不属于以继承人身份管理遗产，神圣哈德良皇帝仍以舍弃遗嘱依据、转按无遗嘱方式占有遗产者为例，敕令应准许对其提起诉讼。因此，他应对受遗赠人和遗嘱信托受益人承担责任。

<!-- source-p 021 -->
<a id="29.4.2.1"></a>**1.**应先向此人追偿，再向继承人追偿，还是颠倒顺序？我认为，先审查遗产占有人更为宽厚，尤其是当其无偿取得遗产时。

<!-- source-p 022 -->
<a id="29.4.3"></a>**29.4.3**

<!-- source-p 023 -->
**庞波尼乌斯：《评萨宾》第三卷。**

<!-- source-p 024 -->
若你收取替补继承人给付的钱财而放弃继承，且替补继承人接受了继承，是否应准许受遗赠人提起诉讼，尚可存疑。我认为，若你自己也放弃继承，而遗产依法转归你并由你占有，则可对你们二人提起诉讼；但若某人从你们二人处均受有遗赠，则只能选择向其中一人提起诉讼。

<!-- source-p 025 -->
<a id="29.4.4"></a>**29.4.4**

<!-- source-p 026 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 027 -->
<a id="29.4.4.pr."></a>**序言。**若某人没有收取钱财，只是单纯放弃遗嘱继承，以便让替补继承人或法定继承人取得遗产，是否不适用该告示？显然，死者的意思遭到规避，令人愤慨。因此，若能明确查明此举意在损害受遗赠人，即使没有收取钱财、只是给予对方过分的好处，也应认为可以对遗产占有人提起有用之诉。

<!-- source-p 028 -->
<a id="29.4.4.1"></a>**1.**凡某人意在使因其放弃继承而将取得遗产的人受益，而此人若未获此利益本不会放弃继承，尤其是其行为意在推翻遗嘱处分的，都应认为可以对遗产占有人提起诉讼。不过，如果放弃继承者收取钱财后拒绝继承，应当起诉放弃继承者；若其未收取钱财，而是无偿欺诈遗嘱受益人，则应以有用之诉起诉遗产占有人。

<!-- source-p 029 -->
<a id="29.4.4.2"></a>**2.**裁判官似乎是在谈论被指定的继承人，但这一规则也适用于其他人。例如，受遗赠人又被遗嘱信托要求给付财产给他人，却故意促成继承被放弃，那么也应起诉此人。

<!-- source-p 030 -->
<a id="29.4.4.3"></a>**3.**若某人出售了遗产，他仍应视为遗产占有人；不能说他以诈欺故意阻止自己占有遗产。

<!-- source-p 031 -->
<a id="29.4.5"></a>**29.4.5**

<!-- source-p 032 -->
**马尔凯卢斯：《学说汇纂》第十二卷。**

<!-- source-p 033 -->
释奴以不符合指定其为继承人之法定方式的方式指定其主人成为继承人，而主人又放弃继承的，应视为主人可以免责。即使释奴指定主人的奴隶为全部遗产的继承人，而该奴隶因任何原因未能奉主人之命接受继承，主人放弃遗嘱继承也不会因此承担责任。

<!-- source-p 034 -->
<a id="29.4.6"></a>**29.4.6**

<!-- source-p 035 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 036 -->
<a id="29.4.6.pr."></a>**序言。**既然某人若舍弃遗嘱继承依据、转而以无遗嘱继承方式占有遗产，就可能被起诉，那么，如果此人似乎是依照立遗嘱人的意思而放弃遗嘱继承，是否仍须履行遗赠？例如，立遗嘱人指定其兄弟为继承人，并另作遗嘱附录，请求其兄弟在依法取得继承时，向某些人履行遗嘱信托。若兄弟舍弃遗嘱继承、转而以无遗嘱继承方式占有遗产，应考察受遗赠人能否起诉他。尤利安在《学说汇纂》第三十一卷写道：应先强令他履行遗赠；履行遗赠后，若遗产中尚有四分之三余额，再强令他履行遗嘱信托；但若遗赠已经耗尽四分之三，就无需向遗嘱信托受益人给付，因为法定继承人应完整保有四分之一。尤利安据此设定顺序：先履行遗赠，再从剩余部分履行遗嘱信托，同时不得动用四分之一。我认为，对尤利安意见应作如下理解：若某人舍弃遗嘱继承、转而以无遗嘱方式占有遗产，则无论如何都应强令其履行遗赠；立遗嘱人既以遗嘱信托嘱托他，就不应准许他舍弃遗产。

<!-- source-p 037 -->
<a id="29.4.6.1"></a>**1.**但若立遗嘱人明确准许此人这样做，就应认为他不落入该告示的适用范围，因为他行使了立遗嘱人授予的选择权。若立遗嘱人没有特别准许其舍弃遗嘱继承，则应遵循尤利安所说明的顺序。

<!-- source-p 038 -->
<a id="29.4.6.2"></a>**2.**如果同一批人既依遗嘱取得遗赠，又以无遗嘱继承为由取得遗嘱信托，而此外还有其他遗嘱信托受益人，我们应否遵循尤利安所述顺序，还是应将所有遗嘱信托受益人视为平等而按比例分配？更妥当的做法是区分继承人是否落入该告示适用范围。若落入，则应优先满足依遗嘱取得利益的人；若未落入，因为立遗嘱人的意思是准许该继承人以无遗嘱方式继承，或者存在其他正当原因，依前述规则不构成违反告示的情形，则应将各项遗嘱信托视为同等而一并按比例分配。

<!-- source-p 039 -->
<a id="29.4.6.3"></a>**3.**裁判官并未简单承诺给予诉权，而是要查明案情后再决定。若他发现立遗嘱人本人促成此事，并准许此人以无遗嘱方式继承，或者存在其他正当的放弃原因，就不会给予受遗赠人针对该人的诉权。

<!-- source-p 040 -->
<a id="29.4.6.4"></a>**4.**同样，若他查明财产属于他人，只要没有串通的嫌疑足以使裁判官产生疑虑，就不会给予诉权。

<!-- source-p 041 -->
<a id="29.4.6.5"></a>**5.**若可能被追夺继承权的人曾占有遗产中的某项财产，后来并非出于诈欺而停止占有，更妥当的意见是，不再对其提起诉讼。

<!-- source-p 042 -->
<a id="29.4.6.6"></a>**6.**那么，应以何时为准来判断某人是否仍在占有遗产？应以争讼程序确定之时为准。

<!-- source-p 043 -->
<a id="29.4.6.7"></a>**7.**当然，若某人占有无人认领的遗产，且四年期间已经届满，仍可毫无疑问地依该告示这一部分对其提起诉讼，因为他既舍弃了遗嘱继承依据，又以无遗嘱方式占有遗产，尽管他已经因四年时效而受到保护。

<!-- source-p 044 -->
<a id="29.4.6.8"></a>**8.**如果释奴在应得份额内指定其主人为继承人，又在另一份额指定共同继承人，而主人因其应得份额已被耗尽而舍弃继承，共同继承人也放弃继承，随后主人以无遗嘱继承人身份占有全部法定遗产，塞尔苏斯在《学说汇纂》第十六卷说，应当准许对主人提起受遗赠人之诉，即原本可对提提乌斯提起的诉讼；主人已完整取得其应得份额，这一点便足以使其免责。但只有在共同继承人与主人串通时，才适用上述规则；否则，不应强令主人履行遗赠，因为法律并未禁止无欺诈地放弃继承。

<!-- source-p 045 -->
<a id="29.4.6.9"></a>**9.**更应认为，该告示也适用于违遗嘱的遗产占有。也就是说，若某人取得违遗嘱的遗产占有，本应向子女和父母履行遗赠；如果他放弃这种遗产占有，转而以无遗嘱方式占有遗产，就应强令他履行与取得违遗嘱遗产占有时相同的遗赠。

<!-- source-p 046 -->
<a id="29.4.6.10"></a>**10.**若遗嘱以条件“交付十枚钱币”授予自由，而奴隶舍弃了遗嘱继承依据，则只有满足该条件，他才能取得自由。

<!-- source-p 047 -->
<a id="29.4.7"></a>**29.4.7**

<!-- source-p 048 -->
**马尔凯卢斯：《学说汇纂》第十二卷。**

<!-- source-p 049 -->
某人指定提提乌斯和梅维乌斯为继承人，并遗赠给提提乌斯一百。二人都舍弃遗嘱继承，转而依法取得继承。提提乌斯无权正当地请求给付遗赠；若立遗嘱人将遗赠同时留给二人，亦同。

<!-- source-p 050 -->
<a id="29.4.8"></a>**29.4.8**

<!-- source-p 051 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 052 -->
若某人被附加交付十枚钱币或其他给付、作为之类的条件指定为继承人，却舍弃遗嘱继承依据，转而以无遗嘱方式占有遗产，应考察是否应给予其条件所指向之人救济。更妥当的意见是不予救济，因为此人并非受遗赠人。

<!-- source-p 053 -->
<a id="29.4.9"></a>**29.4.9**

<!-- source-p 054 -->
**保罗：《评告示》第四十五卷。**

<!-- source-p 055 -->
若此人仍有时间满足条件，则不受该告示这一部分的约束。

<!-- source-p 056 -->
<a id="29.4.10"></a>**29.4.10**

<!-- source-p 057 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 058 -->
<a id="29.4.10.pr."></a>**序言。**若舍弃遗嘱继承依据的人不是单独占有遗产，而是与他人共同占有，尤利安认为，应当正当地准许受遗赠人对他本人提起有用之诉，马尔凯卢斯也赞同这一点；毕竟，他不应只因被指定为继承人而受到不利，尤其是他也从这一身份获益。但若他收取钱财后才舍弃遗嘱继承，就应对全部债务承担责任。

<!-- source-p 059 -->
<a id="29.4.10.1"></a>**1.**若立遗嘱人向原指定继承人和替补继承人均留有遗赠，而二人都舍弃遗嘱继承、转而以无遗嘱方式占有遗产，神圣庇护皇帝曾以敕答指出，原指定继承人拒绝给付留给替补继承人的遗赠，并非不当或轻率。因为替补继承人接受继承时本可自由选择：既可以请求遗嘱信托，也可以取得全部财产。

<!-- source-p 060 -->
<a id="29.4.10.2"></a>**2.**若原指定继承人与替补继承人都舍弃遗嘱继承、转而以无遗嘱方式占有遗产，问题在于：是否应强令二人都履行遗赠；若是，各自只履行自己所留的遗赠，还是二人都应履行全部遗赠？我认为，应准许对每一人提起全部遗赠请求之诉；但尚须考察，每人仅对自己所留遗赠承担责任，还是也对另一继承人所留遗赠承担责任。再设一例：只有原指定继承人占有遗产，他是否只对自己所留遗赠承担责任，还是也要对替补继承人所留遗赠负责？只有在替补继承人欺诈，导致原指定继承人未付任何钱财便取得遗产时，才应认为后者也对替补继承人所留遗赠负责；若替补继承人收取了钱财，则应起诉替补继承人。同样，若只有替补继承人占有遗产：原指定继承人收取钱财后放弃继承的，应由原指定继承人对自己所留遗赠负责，替补继承人对自己所留遗赠负责；若没有收取钱财，则应对替补继承人提起诉讼。如今二人共同占有遗产，更妥当的意见是，各自只对自己所留的遗赠负责。

<!-- source-p 061 -->
<a id="29.4.11"></a>**29.4.11**

<!-- source-p 062 -->
**雅沃勒努斯：《书信》第七卷。**

<!-- source-p 063 -->
若同一物品既由原指定继承人遗赠给我，又由替补继承人遗赠给我，而二人都舍弃遗嘱继承、转而依法占有遗产，即使二人各自都须向我给付该物，我从一人处取得遗赠后，也不能再向另一人请求。因此，我可以选择起诉其中一人。

<!-- source-p 064 -->
<a id="29.4.12"></a>**29.4.12**

<!-- source-p 065 -->
**乌尔比安：《评告示》第五十卷。**

<!-- source-p 066 -->
<a id="29.4.12.pr."></a>**序言。**还曾有人询问，在这种情形下，遗嘱中授予的自由是否有效；无论是原指定继承人授予的自由，还是替补继承人授予的自由。较妥当的意见是，两者均有效，包括直接授予的自由和遗嘱信托式授予的自由。

<!-- source-p 067 -->
<a id="29.4.12.1"></a>**1.**已确定，对舍弃遗嘱继承、转而以无遗嘱方式占有遗产之人的继承人，可以提起遗赠之诉并请求其承担全部责任。因为该诉讼旨在追索财物，并非惩罚；因此，诉权不受时效限制。但若继承人是因死者的诈欺行为而被起诉，则仅能在其实际取得的范围内对其起诉。

<!-- source-p 068 -->
<a id="29.4.13"></a>**29.4.13**

<!-- source-p 069 -->
**盖尤斯：《评行省告示》第十七卷。**

<!-- source-p 070 -->
即使某人没有占有全部遗产或其被指定继承的那一份额，而只占有很小一部分，甚至只占有某一件遗产物，也受该告示约束。

<!-- source-p 071 -->
<a id="29.4.14"></a>**29.4.14**

<!-- source-p 072 -->
**盖尤斯：《论遗嘱与城市裁判官告示》第二卷。**

<!-- source-p 073 -->
不过，严格说来，单独一件物品并不构成遗产的一份额。

<!-- source-p 074 -->
<a id="29.4.15"></a>**29.4.15**

<!-- source-p 075 -->
**盖尤斯：《评行省告示》第十七卷。**

<!-- source-p 076 -->
这并不不公平，因为每个人都因自己的过错而承受这种不利。

<!-- source-p 077 -->
<a id="29.4.16"></a>**29.4.16**

<!-- source-p 078 -->
**盖尤斯：《论遗嘱与城市裁判官告示》第二卷。**

<!-- source-p 079 -->
既然可以向仅以继承名义占有某一遗产物的人请求返还遗产，就无须怀疑我们先前所说是正确的。

<!-- source-p 080 -->
<a id="29.4.17"></a>**29.4.17**

<!-- source-p 081 -->
**盖尤斯：《评行省告示》第十七卷。**

<!-- source-p 082 -->
若某人舍弃遗嘱继承依据，却根本没有占有遗产，则受遗赠人不能请求其履行遗赠。任何人都应有权放弃有利可图的遗产，即使这样会使遗赠和自由授予一并落空。不过，遗嘱信托继承另有保障：若被指定为继承人的人不愿接受继承，裁判官可以命令其接受继承并返还遗产。对于仅以遗嘱信托方式受领单件物品的人，并未给予同样的利益；受遗赠人也不享有这种利益。

<!-- source-p 083 -->
<a id="29.4.18"></a>**29.4.18**

<!-- source-p 084 -->
**盖尤斯：《论遗嘱与城市裁判官告示》第二卷。**

<!-- source-p 085 -->
<a id="29.4.18.pr."></a>**序言。**若两名继承人都舍弃遗嘱继承、转而以无遗嘱方式占有遗产，则二人均依裁判官法视为仿佛已经依遗嘱接受继承；因此，应按各自份额分别对其提起诉讼。

<!-- source-p 086 -->
<a id="29.4.18.1"></a>**1.**应当提醒，对依该告示这一部分而被准许提起遗赠之诉的人，应给予《法尔基第法》的利益。

<!-- source-p 087 -->
<a id="29.4.19"></a>**29.4.19**

<!-- source-p 088 -->
**盖尤斯：《评行省告示》第十七卷。**

<!-- source-p 089 -->
对被指定为全部遗产继承人的释奴主而言，若其以无遗嘱方式占有遗产，仍应保全他本可依遗嘱接受继承时取得的法定份额利益。

<!-- source-p 090 -->
<a id="29.4.20"></a>**29.4.20**

<!-- source-p 091 -->
**乌尔比安：《论争议》第四卷。**

<!-- source-p 092 -->
若同一物品分别由原指定继承人和替补继承人遗赠给不同的人，则只有从原指定继承人处取得该物品的人可以提起返还之诉；并非二人都可以起诉。

<!-- source-p 093 -->
<a id="29.4.21"></a>**29.4.21**

<!-- source-p 094 -->
**尤利安：《学说汇纂》第二十七卷。**

<!-- source-p 095 -->
若我的儿子被其母亲指定为继承人，而我因舍弃遗嘱继承而以儿子的名义请求取得遗产占有，则应准许对我提起遗赠之诉；其处理方式应与我本人被指定为继承人、却舍弃遗嘱继承而以无遗嘱方式取得遗产占有相同。

<!-- source-p 096 -->
<a id="29.4.22"></a>**29.4.22**

<!-- source-p 097 -->
**尤利安：《学说汇纂》第三十一卷。**

<!-- source-p 098 -->
<a id="29.4.22.pr."></a>**序言。**若遗嘱写道：“提提乌斯应为继承人；若提提乌斯成为继承人，梅维乌斯应为继承人”，而提提乌斯舍弃遗嘱继承、依法占有遗产，就不应准许梅维乌斯对其提起遗产请求之诉，以取得其未舍弃遗嘱继承时本可取得的份额。因为以无遗嘱方式占有遗产时，仍应考虑遗赠和自由授予，因为这些处分只能由继承人履行；但裁判官不应考虑以此种方式给予的遗产份额。立遗嘱人本可无条件给予该份额，却因自己的过错附加了条件。

<!-- source-p 099 -->
<a id="29.4.22.1"></a>**1.**因此，即使遗嘱写道：“提提乌斯应为继承人；凡上述之人中成为我继承人的，斯提库斯应为自由人和继承人”，而提提乌斯舍弃遗嘱继承、占有遗产，裁判官也不应保护斯提库斯取得自由，亦不应准许他提起遗产请求之诉。

<!-- source-p 100 -->
<a id="29.4.22.2"></a>**2.**若某人这样订立遗嘱：“提提乌斯应为继承人；若提提乌斯不成为继承人，梅维乌斯应为继承人；凡上述之人中成为我继承人的，若梅维乌斯不成为我的继承人，应给付他一百”，之后提提乌斯舍弃遗嘱继承、依法占有遗产，那么，是否应准许梅维乌斯提起遗赠之诉？梅维乌斯本可选择依替补指定接受继承，从而取得全部遗产。意见认为，应准许其提起诉讼，因为梅维乌斯可能有正当理由，不愿卷入遗产事务。

<!-- source-p 101 -->
<a id="29.4.23"></a>**29.4.23**

<!-- source-p 102 -->
**乌尔比安：《评告示》第四十六卷。**

<!-- source-p 103 -->
若仍处于父权之下的儿子和女儿被指定为继承人，而被遗漏的已解放兄弟本可取得违遗嘱的遗产占有，子女随后以无遗嘱继承为由取得遗产占有，则他们仍须履行全部遗赠；女儿无须将自己的嫁资交给兄弟，因为她似乎仍是作为遗嘱指定继承人取得遗产。

<!-- source-p 104 -->
<a id="29.4.24"></a>**29.4.24**

<!-- source-p 105 -->
**保罗：《评告示》第六十卷。**

<!-- source-p 106 -->
<a id="29.4.24.pr."></a>**序言。**若受监护未成年人因监护人的欺诈而舍弃遗嘱继承、依法占有遗产，应准许对该未成年人提起遗赠之诉，但责任仅限于其实际取得的遗产范围。因为他也可能与他人共同占有遗产。

<!-- source-p 107 -->
<a id="29.4.24.1"></a>**1.**多数人认为，对于已经达到适婚年龄的人，也应遵守同一规则：他按所占份额承担责任，尽管裁判官对其提起诉讼时，视同他已经接受继承。

<!-- source-p 108 -->
<a id="29.4.25"></a>**29.4.25**

<!-- source-p 109 -->
**塞尔苏斯：《学说汇纂》第十六卷。**

<!-- source-p 110 -->
某人指定自己的奴隶为替补继承人，并命令该奴隶接受继承。若他这样做是为了不履行遗赠，就应履行全部遗赠：既包括其作为继承人所负的遗赠，也包括其因舍弃遗嘱继承、通过替补而占有遗产所负的遗赠；但应保留《法尔基第法》所规定的份额。

<!-- source-p 111 -->
<a id="29.4.26"></a>**29.4.26**

<!-- source-p 112 -->
**帕比尼安：《疑问集》第十六卷。**

<!-- source-p 113 -->
<a id="29.4.26.pr."></a>**序言。**尤利安写道：父亲将女儿指定为自己的替补继承人，并命令她接受继承时，依该告示的宗旨，父亲应履行自己所留的遗赠。因为女儿是在特定情形下替补父亲，而非由父亲自行选择是否接受继承。不过，若遗赠总额超过遗产的四分之三，应先计算女儿所留的遗赠。父亲舍弃自己的身份地位而图取私利，选择让他人依据替补指定继承，并非没有欺诈。

<!-- source-p 114 -->
<a id="29.4.26.1"></a>**1.**最后，若女儿的父亲被指定为替补继承人并接受继承，尤利安认为他并无欺诈，因为任何人都不会认为父亲违背父母的愿望而指定女儿为替补继承人；此举只是将选择权留给她。

<!-- source-p 115 -->
<a id="29.4.27"></a>**29.4.27**

<!-- source-p 116 -->
**帕比尼安：《答复集》第六卷。**

<!-- source-p 117 -->
<a id="29.4.27.pr."></a>**序言。**母亲在第二份遗嘱文书中被指定为未适婚儿子的替补继承人；若她舍弃遗嘱继承、依法占有儿子的遗产，就落入该告示的适用范围。如果她既被指定为儿子的继承人，又被指定为替补继承人，规则亦同。

<!-- source-p 118 -->
<a id="29.4.27.1"></a>**1.**兄弟没有解放自己的儿子——该儿子在其兄弟的遗嘱中被指定为未适婚者的替补继承人——而是经由该儿子以无遗嘱方式开始占有遗产；就遗赠而言，不应认为该兄弟落入该告示的适用范围。

<!-- source-p 119 -->
<a id="29.4.27.2"></a>**2.**若某人未被遗嘱指定为继承人，却与遗嘱指定继承人串通，以欺诈方式独自占有法定继承遗产，应依裁判官告示的宗旨准许受遗赠人提起诉讼。

<!-- source-p 120 -->
<a id="29.4.28"></a>**29.4.28**

<!-- source-p 121 -->
**梅基安努斯：《遗嘱信托》第四卷。**

<!-- source-p 122 -->
<a id="29.4.28.pr."></a>**序言。**若某奴隶被指定为继承人，而其主人本人也受嘱托履行遗嘱信托；主人在命令奴隶接受继承前将其出售，就应履行遗嘱信托，因为他通过出售奴隶的价款，也取得了遗产的估值。

<!-- source-p 123 -->
<a id="29.4.28.1"></a>**1.**被指定为继承人并受嘱托返还遗产的人，若舍弃遗嘱继承、依法占有遗产，无疑应如同履行遗赠及其他遗嘱信托一样，被强令返还遗产；直接授予的自由及遗嘱信托式授予的自由也应履行。若受嘱托释放他人的奴隶，就必须买下这些奴隶。受领返还遗产的人应承担与返还人本应承担的相同扣减。

<!-- source-p 124 -->
<a id="29.4.29"></a>**29.4.29**

<!-- source-p 125 -->
**乌尔比安：《遗嘱信托》第五卷。**

<!-- source-p 126 -->
舍弃遗嘱继承、转而以无遗嘱方式占有遗产的人，应当使奴隶获得自由，以免他们因遗嘱指定继承人拒绝接受继承而受损；不过，这些获释者应当成为他的释奴。

<!-- source-p 127 -->
<a id="29.4.30"></a>**29.4.30**

<!-- source-p 128 -->
**赫尔莫格尼安努斯：《法学摘要》第三卷。**

<!-- source-p 129 -->
某人舍弃遗嘱继承后，若以买受人、嫁资受领人、受赠人或任何其他身份占有遗产——以继承人身份或占有人身份占有的除外——受遗赠人和遗嘱信托受益人不得对其提起诉讼。
