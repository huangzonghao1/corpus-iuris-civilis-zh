# D.29.1 论军人遗嘱（*De testamento militis*）

<!-- source-p 001 -->
<a id="1"></a><a id="29.1"></a>**29.1.0. 论军人遗嘱。**

<!-- source-p 002 -->
<a id="29.1.1"></a>**29.1.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第四十五卷。**

<!-- source-p 004 -->
<a id="29.1.1.pr."></a>**序言。**最初，神圣尤利乌斯·恺撒曾准许军人自由享有遗嘱能力，但这项准许是暂时的。此后，神圣提图斯首先再次准许，随后是多米提安；再后来，神圣涅尔瓦给予军人最为充分的宽免。图拉真沿袭此制，自此以后，皇帝诏令中开始列入如下条款：

诏令条款如下：“我得知，军人同袍所立遗嘱时常被提出；若依法律的严格要求和遵行规范加以审查，这些遗嘱可能引起争议。遵循我对最优秀、最忠诚同袍的诚挚情意，我认为应照顾他们的质朴，使他们无论以何种方式立遗嘱，其意愿均为有效。因此，他们可以按照自己愿意的方式立遗嘱，也可以按照自己能够做到的方式立遗嘱；只要立遗嘱人的单纯意愿足以分配其财产即可。”

<!-- source-p 005 -->
<a id="29.1.1.1"></a>**1.**“军人”（*miles*）一词，有人说源于“军旅”（*militia*），也就是他们代我们承受的艰苦；或源于人数众多；或源于他们通常所抵御的祸患；又或源于千人编制。后一说法取自希腊语 *tagma*：希腊人把一千人的队伍称为 *tagma*，仿佛其中每人都被称作千人之一；因此，他们把队伍首领称作 *chiliarchos*。而“军队”（*exercitus*）一词则源于操练（*exercitatio*）。

<!-- source-p 006 -->
<a id="29.1.2"></a>**29.1.2**

<!-- source-p 007 -->
**盖尤斯：《行省告示评注》第十九卷。**

<!-- source-p 008 -->
总督之所以将军人遗嘱另行规定，是因为他十分清楚，根据皇帝敕令，军人遗嘱适用独特而特殊的规则。

<!-- source-p 009 -->
<a id="29.1.3"></a>**29.1.3**

<!-- source-p 010 -->
**乌尔比安：《萨宾评注》第二卷。**

<!-- source-p 011 -->
如果一名军人原本打算依普通法立遗嘱，却在立遗嘱之前死亡，法律后果如何？庞波尼乌斯对此有所疑问。但为何不应承认军人的情形有所不同？意欲依普通法立遗嘱，并不意味着他立即放弃军人法上的利益；也不能认为任何人会选择某种立遗嘱方式来推翻自己的意思表示，更应认为他是为了应对偶发情况而希望两种方式都有效。许多平民在书写遗嘱时，常会附言表示该文书也愿作为遗嘱补编（*codicilli*）有效。无论对此如何解释，遗嘱若未完成，就不构成遗嘱补编；神圣马尔库斯也依照我们的意见作过敕答。

<!-- source-p 012 -->
<a id="29.1.4"></a>**29.1.4**

<!-- source-p 013 -->
**乌尔比安：《萨宾评注》第一卷。**

<!-- source-p 014 -->
通说认为，仍在军籍名册内、尚未因疾病退役的聋哑军人，可以依军人法立遗嘱。

<!-- source-p 015 -->
<a id="29.1.5"></a>**29.1.5**

<!-- source-p 016 -->
**乌尔比安：《萨宾评注》第四卷。**

<!-- source-p 017 -->
军人也可以为已经成为继承人的人指定替代继承人，但仅限于该人依其遗嘱所取得的财产。

<!-- source-p 018 -->
<a id="29.1.6"></a>**29.1.6**

<!-- source-p 019 -->
**乌尔比安：《萨宾评注》第五卷。**

<!-- source-p 020 -->
如果军人指定某人为一项特定不动产的继承人，人们认为，就其余财产而言，他应视为无遗嘱死亡；因为军人可以一部分依遗嘱、一部分依无遗嘱继承规则死亡。

<!-- source-p 021 -->
<a id="29.1.7"></a>**29.1.7**

<!-- source-p 022 -->
**乌尔比安：《萨宾评注》第九卷。**

<!-- source-p 023 -->
依军人法立遗嘱的人，即使不知道妻子已怀孕，或者妻子当时尚未怀孕，但若其意在排除后来为自己所生的任何子女，该遗嘱仍不因此失效。

<!-- source-p 024 -->
<a id="29.1.8"></a>**29.1.8**

<!-- source-p 025 -->
**马尔凯卢斯：《学说汇纂》第十卷。**

<!-- source-p 026 -->
如果他以收养（*adrogatio*）方式收养了一个儿子，或者孙子后来递补儿子的位置，情形也相同。

<!-- source-p 027 -->
<a id="29.1.9"></a>**29.1.9**

<!-- source-p 028 -->
**乌尔比安：《萨宾评注》第九卷。**

<!-- source-p 029 -->
<a id="29.1.9.pr."></a>**序言。**同样，如果儿子出生后，立遗嘱人仍在世时选择维持同一遗嘱，并依该遗嘱死亡，该遗嘱也应视为依军人法重新订立：

<!-- source-p 030 -->
<a id="29.1.9.1"></a>**1.**正如神圣皮乌斯在一项敕答中所说，有人尚为平民时立下遗嘱，随后开始服役；如果军人希望该遗嘱有效，它也会自此依军人法开始生效。

<!-- source-p 031 -->
<a id="29.1.10"></a>**29.1.10**

<!-- source-p 032 -->
**乌尔比安：《萨宾评注》第十一卷。**

<!-- source-p 033 -->
被敌人俘获的人，也不得依军人法立遗嘱。

<!-- source-p 034 -->
<a id="29.1.11"></a>**29.1.11**

<!-- source-p 035 -->
**乌尔比安：《告示评注》第四十五卷。**

<!-- source-p 036 -->
<a id="29.1.11.pr."></a>**序言。**因军中犯罪而被判处死刑的人，可以就其军营财产立遗嘱。但问题在于，他应依军人法还是普通法立遗嘱。较可取的意见是，应准许其依军人法立遗嘱：既然赋予他如同军人一般的立遗嘱权，随之就应认定其依军人法立遗嘱。只有在他未违反军誓忠诚义务时，才应如此理解。

<!-- source-p 037 -->
<a id="29.1.11.1"></a>**1.**如果一名军人不确定自己是否为自权人而立遗嘱，该遗嘱仍处于有效状态；因为即使他不确定父亲是否在世而立遗嘱，该遗嘱也有效。

<!-- source-p 038 -->
<a id="29.1.11.2"></a>**2.**如果家子军人不知道父亲已经死亡，却在服役期间就军营特有产立了遗嘱，那么其父的财产不因此归该军人遗嘱所指定的继承人；该遗嘱只处分军营特有产：

<!-- source-p 039 -->
<a id="29.1.12"></a>**29.1.12**

<!-- source-p 040 -->
**帕皮尼安：《答复集》第六卷。**

<!-- source-p 041 -->
军人只处分他们以书面列明的那些财物。

<!-- source-p 042 -->
<a id="29.1.13"></a>**29.1.13**

<!-- source-p 043 -->
**乌尔比安：《告示评注》第四十五卷。**

<!-- source-p 044 -->
<a id="29.1.13.pr."></a>**序言。**即使他曾考虑变更遗嘱，情形亦同；他这样做并非意在从书面指定的继承人处收回军营财产，而是想处分父系财产并另行指定继承人。

<!-- source-p 045 -->
<a id="29.1.13.1"></a>**1.**马尔凯卢斯在《学说汇纂》第十卷写道，如果他已作为退伍军人死亡，其全部财产，包括父系财产，均归军营财产的继承人；因为此时他已不能再就部分财产依遗嘱、就另一部分无遗嘱死亡。

<!-- source-p 046 -->
<a id="29.1.13.2"></a>**2.**军人可以指定被流放者以及几乎所有不具有遗嘱能力的人为继承人。但如果他指定刑罚奴隶为继承人，该指定无效；不过，如果该刑罚奴隶在军人死亡时已处于罗马公民共同体之中，该指定便开始有效，犹如继承权此时才授予他。一般而言，凡军人指定为继承人的人，只要在军人死亡时具备被军人指定为继承人的资格，该指定便开始发生效力。

<!-- source-p 047 -->
<a id="29.1.13.3"></a>**3.**如果军人把自己所有、但误以为是自由人的奴隶指定为继承人，却没有同时给予自由，那么该指定无效。

<!-- source-p 048 -->
<a id="29.1.13.4"></a>**4.**军人在遗嘱中给予奴隶自由，并通过遗嘱信托嘱托第一顺位继承人及第二顺位继承人将遗产交给同一奴隶；即使第一顺位继承人和替代继承人在接受遗产之前均已死亡，我们的皇帝与神圣塞维鲁仍以敕答确认，不应因此按无遗嘱继承处理。应当把该遗嘱视同直接同时给予该奴隶自由和遗产；不能否认立遗嘱人意在使这两项利益均归于他。

<!-- source-p 049 -->
<a id="29.1.14"></a>**29.1.14**

<!-- source-p 050 -->
**梅基安努斯：《遗嘱信托论》第四卷。**

<!-- source-p 051 -->
有人讨论，是否也应对平民遗嘱作出类似宽免。通说认为，不能不加区分地一概如此处理；如果有关继承人在立遗嘱人生前、且立遗嘱人知情时死亡，不应制定新的规则；但如果立遗嘱人对此不知情，或者继承人在其死后才死亡，则无论如何都应给予救济。

<!-- source-p 052 -->
<a id="29.1.15"></a>**29.1.15**

<!-- source-p 053 -->
**乌尔比安：《告示评注》第四十五卷。**

<!-- source-p 054 -->
<a id="29.1.15.pr."></a>**序言。**但是，军人即使意在欺诈债权人，也至多只能实施一项必要处分。

<!-- source-p 055 -->
<a id="29.1.15.1"></a>**1.**军人既可以仅凭其意思给予继承权，也可以仅凭其意思撤回继承权。因此，如果他涂销或撕毁遗嘱，该遗嘱即失去效力；但如果他涂销遗嘱后又希望其有效，则依其最后意思，遗嘱仍然有效。所以，如果军人划去遗嘱，随后又用自己的印戒在其上盖印，审理此事的人应查明他这样做的意图：如果证实他已悔改并改变主意，应视为遗嘱已经恢复；但如果他这样做只是为了使遗嘱所写内容无法辨认，则更应认定该遗嘱的处分无效。

<!-- source-p 056 -->
<a id="29.1.15.2"></a>**2.**神圣皮乌斯以敕答确认：军人在服役前订立的遗嘱，如果他在服役期间死亡，依军人法有效，除非军人后来表达了相反意思。

<!-- source-p 057 -->
<a id="29.1.15.3"></a>**3.**有人在军人遗嘱中把自己写作继承人，并不因此免受元老院决议所定的处罚。

<!-- source-p 058 -->
<a id="29.1.15.4"></a>**4.**军人可以指定某人为限期继承人，并指定另一人在该期限届满后继承；也可以附条件指定继承人，或者指定继承人须在条件成就后继承。

<!-- source-p 059 -->
<a id="29.1.15.5"></a>**5.**军人可以依军人法同时为自己和儿子立遗嘱；也可以仅为儿子立遗嘱，即使没有为自己立遗嘱。若父亲在服役期间或退役后一年内死亡，该遗嘱即有效。

<!-- source-p 060 -->
<a id="29.1.15.6"></a>**6.**帕皮尼安在《疑问集》第十四卷写道，即使是军人，也不得在告示规定的期限届满后承认其遗产占有；因为这一期限规定具有普遍效力。

<!-- source-p 061 -->
<a id="29.1.16"></a>**29.1.16**

<!-- source-p 062 -->
**保罗：《告示评注》第四十三卷。**

<!-- source-p 063 -->
如果军人遗赠嫁资土地，该遗赠因《尤利亚法》而无效。

<!-- source-p 064 -->
<a id="29.1.17"></a>**29.1.17**

<!-- source-p 065 -->
**盖尤斯：《行省告示评注》第十五卷。**

<!-- source-p 066 -->
<a id="29.1.17.pr."></a>**序言。**如果军人把不同类别的财物分别指定给不同继承人，例如指定一人继承城市不动产，另一人继承乡村不动产，第三人继承其余财物，该指定有效；其效力犹如未给继承人划定份额，并通过预取遗赠将全部财产分别分配给各人。

<!-- source-p 067 -->
<a id="29.1.17.1"></a>**1.**尤利安还说，如果某人指定一人继承军营财产，另一人继承其余财产，这应被理解为两个人分别继承两份遗产。因此，对军营中所负债务，只有被指定为军营财产继承人的人承担责任；对军营之外所负债务，也只有被指定为其余财产继承人的人承担责任。与此相应，军人无论基于何种原因享有债权，该债权均依法归属于这两名继承人中的相应一人。如果其中一类财产不足以清偿因该类财产而生的债务，且因此被指定继承该部分的人拒绝接受遗产，那么另一名已经接受遗产的继承人应被迫为全部遗产提供诉讼抗辩，或者向债权人清偿全部债务。

<!-- source-p 068 -->
<a id="29.1.17.2"></a>**2.**如果军人在同一遗嘱中先指定某人为继承人，随后又将其剥夺继承资格，应视为遗产已被撤回；因为在平民遗嘱中，仅凭剥夺继承资格并不能撤销继承人指定。

<!-- source-p 069 -->
<a id="29.1.17.3"></a>**3.**如果某家子军人从其军营特有产指定父亲为继承人，而父亲未依遗嘱承受该遗产却占有特有产中的财物，或者以恶意阻止自己占有该财物，可以对父亲提起遗赠之诉。

<!-- source-p 070 -->
<a id="29.1.17.4"></a>**4.**如果军人在服役期间立下遗嘱，退役后、且退役未满一年即死亡，并在此期间另立遗嘱补编，多数人的意见是，该遗嘱补编应适用市民法规则，因为它不是由军人在服役时订立的；遗嘱曾确认遗嘱补编一事与此无关。因此，遗嘱中所设遗赠不适用《法尔基迪亚法》，而遗嘱补编中所设遗赠则适用该法。

<!-- source-p 071 -->
<a id="29.1.18"></a>**29.1.18**

<!-- source-p 072 -->
**特里丰尼努斯：《论辩集》第十八卷。**

<!-- source-p 073 -->
<a id="29.1.18.pr."></a>**序言。**如果遗嘱和遗嘱补编中所设遗赠合计超过遗产的四分之三，问题在于，哪些遗赠应减少，以及减少多少。最妥当的处理方式是：先全额清偿军人在遗嘱中所设遗赠，再将剩余财产的四分之一留给继承人，四分之三用于满足遗嘱补编中的遗赠。

<!-- source-p 074 -->
<a id="29.1.18.1"></a>**1.**那么，如果遗嘱中所设遗赠已耗尽全部遗产，遗嘱补编受遗赠人是否一无所获？还是仍能取得某些财产？由于如果军人当时也在遗嘱中设立这些遗赠，一切遗赠便会合并计算，并按比例一同减少超出其遗产总额的部分，因此现在也应作同样处理。随后，在确定遗嘱补编中遗赠的数额时，应以假定所有遗赠均依同一规则负担而计算出的应付总额为基准，仅从遗嘱补编遗赠中扣除四分之一。

<!-- source-p 075 -->
<a id="29.1.18.2"></a>**2.**如果在将两类遗赠均按全额计算后，发现尚有财产留在继承人处，但不足以保留相当于遗嘱补编遗赠四分之一的份额，那么不足部分应仅从遗嘱补编受遗赠人所得中扣除。

<!-- source-p 076 -->
<a id="29.1.19"></a>**29.1.19**

<!-- source-p 077 -->
**乌尔比安：《论辩集》第四卷。**

<!-- source-p 078 -->
<a id="29.1.19.pr."></a>**序言。**有人问：如果一名军人已经立有遗嘱，后来又立了另一份遗嘱，并在其中写明把此事托付给继承人的诚信，使先前遗嘱继续有效，应如何处理？我曾说，军人可以立数份遗嘱；无论同时还是分别立下，只要他特别明确地表达了这一点，两份遗嘱均有效，后立遗嘱不会撤销先前遗嘱，因为军人也可以只就部分财产指定继承人，也就是说，一部分依遗嘱、一部分依无遗嘱继承规则死亡。甚至，如果他先前立有遗嘱补编，也可以在随后遗嘱中作出安排，把其中原本仅属遗嘱信托请求的继承人指定转为直接指定。基于这些理由，我曾在本案中认为，如果军人的意图是使先前所立遗嘱有效，那么他作出的安排就应当有效，因而可认定存在两份遗嘱。但本案中，他只是托付继承人的诚信，使先前遗嘱有效；这表明他并非希望先前遗嘱依法直接有效，而是希望通过遗嘱信托使其有效，也就是说，他把先前遗嘱转化为遗嘱信托安排和遗嘱补编。

<!-- source-p 079 -->
<a id="29.1.19.1"></a>**1.**问题在于，整份遗嘱是否都转化为遗嘱信托，也就是继承人指定是否同样转化；还是仅有遗赠、遗嘱信托和自由权处分转化。我认为，不仅除继承人指定以外的其余处分，连继承人指定本身也转化为遗嘱信托〔原文作 *et [es] ipsam institutionem*〕，除非能证明立遗嘱人另有书写。

<!-- source-p 080 -->
<a id="29.1.19.2"></a>**2.**如果军人指定一人为限期继承人，另指定一人在期限届满后继承，后位继承人是否应履行前位继承人留下的遗赠？我认为不应履行，除非能够证明军人另有意思。

<!-- source-p 081 -->
<a id="29.1.20"></a>**29.1.20**

<!-- source-p 082 -->
**尤利安：《学说汇纂》第二十七卷。**

<!-- source-p 083 -->
<a id="29.1.20.pr."></a>**序言。**如果一名军团护民官在其继任者进入营地后的规定期限内，仍留在营地时订立遗嘱补编，并在那里死亡，那么，因为其继任者入营后，他便不再被视为军人，其遗嘱补编应依罗马公民普通法判断。

<!-- source-p 084 -->
<a id="29.1.20.1"></a>**1.**如果某人在立遗嘱后才开始服役，他在服役前所立的遗嘱，在某些情况下也可视为服役期间所立；例如，他打开遗嘱板、读过遗嘱后，再用自己的印记重新封缄；此外，如果他在遗嘱中作了任何行间增补、删改、添加或修正，也属此例。但如果他没有改动遗嘱中的任何内容，该遗嘱便不适用军人特权。

<!-- source-p 085 -->
<a id="29.1.21"></a>**29.1.21**

<!-- source-p 086 -->
**阿非利卡努斯：《疑问集》第四卷。**

<!-- source-p 087 -->
规定服役期间所立遗嘱在退役后一年内仍然有效的规则，依其文字，我认为仅适用于通常会退役的军人。因此，总督、护民官以及其他在继任者到任后便停止服役的人，不享有这项特权。

<!-- source-p 088 -->
<a id="29.1.22"></a>**29.1.22**

<!-- source-p 089 -->
**马尔西安：《法学阶梯》第四卷。**

<!-- source-p 090 -->
家子军人发生身份减等，或者被父亲解放、交付他人收养后，其遗嘱仍有效，视同其基于新的意思重新立下遗嘱。

<!-- source-p 091 -->
<a id="29.1.23"></a>**29.1.23**

<!-- source-p 092 -->
**特尔图良：《军营特有产论》单卷。**

<!-- source-p 093 -->
家父军人仅就军营财产立下遗嘱后，如果将自己交付他人收养，该遗嘱仍有效；但如果他是在退役后才这样做，该遗嘱便无效。

<!-- source-p 094 -->
<a id="29.1.24"></a>**29.1.24**

<!-- source-p 095 -->
**弗洛伦提努斯：《法学阶梯》第十卷。**

<!-- source-p 096 -->
神圣图拉真就此事给斯塔提利乌斯·塞维鲁作出如下敕答：“给予军人的特权，是使他们以任何方式所立的遗嘱均有效。对此应作如下理解：首先必须能够确认确实立有遗嘱；遗嘱即使没有书面形式，非军人也可以订立。因此，如果你正在审理某军人遗产，而该军人曾召集众人，意在向他们表明自己的遗嘱意思，并且明确说明希望由谁继承、给予谁自由，那么可以认为他以这种方式口头立下了遗嘱，其意思应当有效。反之，如果他像人们在日常交谈中常做的那样，对某人说‘我让你做我的继承人’或‘我把财产留给你’，则不应将此视为遗嘱。没有人比享有这项特权的军人更应关切，不让这种先例得到承认；否则，某军人死后，很容易出现证人声称曾听他说要把财产留给某人，如此一来，真实的遗嘱意思便会被推翻。”

<!-- source-p 097 -->
<a id="29.1.25"></a>**29.1.25**

<!-- source-p 098 -->
**马尔凯卢斯：《答复集》单卷。**

<!-- source-p 099 -->
提提乌斯在成为军团护民官之前立下遗嘱，后来佩戴军人腰带入伍，并在仍服役时死亡。我问，这是否应视为军人遗嘱。马尔凯卢斯答复：如果不能证明他后来曾表示先前所立遗嘱仍应有效，那么该遗嘱应适用普通法。皇帝敕令确认的是军人所立的遗嘱，而非军人遗嘱以外的遗嘱。但只要他以某种方式表明希望先前所立遗嘱继续有效，就应解释为他重新立下了遗嘱。

<!-- source-p 100 -->
<a id="29.1.26"></a>**29.1.26**

<!-- source-p 101 -->
**马克尔：《军法论》第二卷。**

<!-- source-p 102 -->
因不名誉事由被退役者的遗嘱，立即丧失军人法上的效力；其他因荣誉退役或因健康事由退役者的遗嘱，则有一年有效期。军人家子获准就军营特有产立遗嘱的权利，不适用于因不名誉事由被退役者；这项权利是作为奖励授予表现合格者的。

<!-- source-p 103 -->
<a id="29.1.27"></a>**29.1.27**

<!-- source-p 104 -->
**帕皮尼安：《答复集》第六卷。**

<!-- source-p 105 -->
某百夫长在第二份遗嘱中指定尚未出生的子女为继承人，却没有指定替代继承人；他还表示，如果这些子女未出生，就恢复适用先前遗嘱。裁定认为，第二份遗嘱中的其他处分均无效，除非他回到先前意思后，逐项明确确认这些处分。

<!-- source-p 106 -->
<a id="29.1.28"></a>**29.1.28**

<!-- source-p 107 -->
**乌尔比安：《萨宾评注》第三十六卷。**

<!-- source-p 108 -->
家子军人死亡时指定未成年儿子为继承人，又为其指定替代继承人；该儿子仍处于祖父的父权之下，军人还为其指定了监护人。神圣两兄弟皇帝作出敕答：替代继承有效，但指定监护人无效。因为军人可以为自己的遗产指定任何替代继承人，却不能减损他人的权利。

<!-- source-p 109 -->
<a id="29.1.29"></a>**29.1.29**

<!-- source-p 110 -->
**马尔凯卢斯：《学说汇纂》第十卷。**

<!-- source-p 111 -->
<a id="29.1.29.pr."></a>**序言。**如果军人指定的继承人自愿接受遗产，并依军人嘱托返还全部遗产，诉权即依《特雷贝利安元老院决议》转移。

<!-- source-p 112 -->
<a id="29.1.29.1"></a>**1.**军人在遗嘱中给予自由，对依《埃利乌斯·森提乌斯法》或其他法律而不得获得自由的人不发生任何效力。

<!-- source-p 113 -->
<a id="29.1.29.2"></a>**2.**裁判官通过告示免除遗嘱指定的继承人和受遗赠人宣誓的规则，也适用于军人遗嘱，遗嘱信托亦同；如果所附条件有失体面，也适用同一规则。

<!-- source-p 114 -->
<a id="29.1.29.3"></a>**3.**如果父亲亲自实施其子解放行为，通说认为父亲可以就儿子遗嘱未处分的财产请求取得应得份额的遗产占有；但儿子在军营中取得、并对其享有自由遗嘱处分权的财产除外。

<!-- source-p 115 -->
<a id="29.1.30"></a>**29.1.30**

<!-- source-p 116 -->
**保罗：《疑问集》第七卷。**

<!-- source-p 117 -->
神圣皮乌斯·安敦尼努斯以敕答确认，不得就军人之子的军营特有产请求取得违反遗嘱的遗产占有。

<!-- source-p 118 -->
<a id="29.1.31"></a>**29.1.31**

<!-- source-p 119 -->
**马尔凯卢斯：《学说汇纂》第十三卷。**

<!-- source-p 120 -->
如果军人把奴隶遗赠给提提乌斯和塞尤斯两人，而提提乌斯在塞尤斯考虑期间将奴隶释放，随后塞尤斯又放弃遗赠，我认为该奴隶应当获得自由；因为即使继承人先暂时释放了遗赠给某人的奴隶，之后该受遗赠人再放弃遗赠，该奴隶也会成为自由人。

<!-- source-p 121 -->
<a id="29.1.32"></a>**29.1.32**

<!-- source-p 122 -->
**莫德斯汀：《规则集》第九卷。**

<!-- source-p 123 -->
如果按照军人的合理意思，其遗产无人接受，那么军营财产也不归继承人取得。

<!-- source-p 124 -->
<a id="29.1.33"></a>**29.1.33**

<!-- source-p 125 -->
**特尔图良：《军营特有产论》单卷。**

<!-- source-p 126 -->
<a id="29.1.33.pr."></a>**序言。**如果家子军人依军人方式立下遗嘱，父亲死亡后又有遗腹子出生，该遗嘱当然会被撤销。但如果他仍坚持原来的意思，希望该遗嘱继续有效，那么只要遗腹子出生时他仍在服役，该遗嘱就会有效，视同他此时重新立下了另一份遗嘱。

<!-- source-p 127 -->
<a id="29.1.33.1"></a>**1.**但如果家子军人立下遗嘱后，在其本人尚在世且其祖父也仍在世时，有遗腹子出生，该遗嘱不会被撤销。因为后来出生的孩子不会进入他的父权之下，所以不能认为他因此取得了一名自家继承人。对于祖父而言也是如此：孙子在其父仍在世时出生，不会立即成为祖父的自家继承人，因此祖父的遗嘱也不会被撤销；因为尽管孙子会立即进入祖父的父权之下，儿子仍排在孙子之前。

<!-- source-p 128 -->
<a id="29.1.33.2"></a>**2.**据此，如果家子军人立下遗嘱，因疏忽而未提及遗腹子——并非有意剥夺其继承资格——随后该遗腹子在祖父死后、其父仍在世时出生，该遗嘱无论如何都会被撤销。如果遗腹子是在其父已成为平民之后出生，已被撤销的遗嘱不会恢复效力；但如果他是在父亲仍服役时出生，遗嘱会先被撤销，之后若父亲希望确认该遗嘱，它就会恢复效力，视同此时重新立下。

<!-- source-p 129 -->
<a id="29.1.33.3"></a>**3.**如果遗腹子在祖父仍在世时出生，他不会立即撤销父亲的遗嘱；但若他在祖父死后、其父仍在世时存活下来，就会撤销该遗嘱，因为此时才有新的继承人加入。即便如此，他也绝不可能同时撤销祖父和父亲两人的遗嘱。

<!-- source-p 130 -->
<a id="29.1.34"></a>**29.1.34**

<!-- source-p 131 -->
**帕皮尼安：《疑问集》第十四卷。**

<!-- source-p 132 -->
<a id="29.1.34.pr."></a>**序言。**神圣哈德良以敕答确认：如果一名军人因无法忍受痛苦或厌倦生活而选择死亡，其遗嘱仍有效；若他未立遗嘱，其财产则可由法律所指定的人按无遗嘱继承规则请求取得。

<!-- source-p 133 -->
<a id="29.1.34.1"></a>**1.**某人在退役后一年内开始立遗嘱，却未能完成。可以认为，如果他服役期间所立遗嘱依军人法有效，那么该遗嘱可以被视为已经撤销；否则，如果该遗嘱依普通法有效，就不能认为它已依法撤销。

<!-- source-p 134 -->
<a id="29.1.34.2"></a>**2.**但对军人不适用同样的区分：无论他以何种方式立遗嘱，都会依其最后意思而撤销，因为军人的意思本身就是遗嘱。

<!-- source-p 135 -->
<a id="29.1.35"></a>**29.1.35**

<!-- source-p 136 -->
**帕皮尼安：《疑问集》第十九卷。**

<!-- source-p 137 -->
如果军人留下了一份未完成的遗嘱，后来提出的书面文书仍具有完整遗嘱的效力；因为军人遗嘱仅凭意思即告完成。一个人在不同日期多次书写遗嘱，通常应视为多次立下遗嘱。

<!-- source-p 138 -->
<a id="29.1.36"></a>**29.1.36**

<!-- source-p 139 -->
**帕皮尼安：《答复集》第六卷。**

<!-- source-p 140 -->
<a id="29.1.36.pr."></a>**序言。**军人在遗嘱补编中处分遗嘱所涉遗产时，也被认为依法给予了继承权。因此，如果他在遗嘱补编中给某人遗产的一半，遗嘱中被指定为全部继承人的人便取得另一半；遗嘱中所设遗赠则由遗产共同负担。

<!-- source-p 141 -->
<a id="29.1.36.1"></a>**1.**军人将军营财产和非军营财产分别指定给不同继承人，之后又为军营财产指定其他继承人。应视为先前遗嘱仅在后来处分所涉及的范围内被撤销；即使先前遗嘱只指定了一名继承人，也不改变这一结论。

<!-- source-p 142 -->
<a id="29.1.36.2"></a>**2.**一名军人在安排临终事务时，不知道妻子已经怀孕，因而未提及胎儿。父亲死后，女儿出生；由此可知遗嘱已被撤销，遗赠也不应给付。如果指定继承人在此期间已付出遗赠，则应为女儿提供有益诉权，以便她基于这一意外情形请求返还；而指定继承人既然是善意占有人，就不应对其已无法保存的财物承担责任。

<!-- source-p 143 -->
<a id="29.1.36.3"></a>**3.**一名退伍军人在临终时希望将自己服役期间依普通法所立的遗嘱视为无效，并选择无遗嘱继承。通说认为，继承人指定和替代继承仍维持原状；但请求遗赠的人可以依普通法受到恶意抗辩的阻却。该抗辩的效力应根据请求人的情况判断；此外，在双方权利相同的案件中，占有人地位较优。

<!-- source-p 144 -->
<a id="29.1.36.4"></a>**4.**一名军人先依普通法立遗嘱，后来又依军人法就全部财产立遗嘱，并在军人遗嘱的有效期届满后死亡。已经被撤销的先前遗嘱，不会因此恢复效力。

<!-- source-p 145 -->
<a id="29.1.37"></a>**29.1.37**

<!-- source-p 146 -->
**保罗：《疑问集》第七卷。**

<!-- source-p 147 -->
如果军人指定两名自由民为继承人，其中一人放弃继承，应视为死者就该部分无遗嘱死亡，因为军人可以仅就一部分财产立遗嘱。因此，保护人可以依无遗嘱继承规则请求遗产占有；除非能够证明死者的意思是，一人放弃时希望另一人取得全部遗产。

<!-- source-p 148 -->
<a id="29.1.38"></a>**29.1.38**

<!-- source-p 149 -->
**保罗：《疑问集》第八卷。**

<!-- source-p 150 -->
<a id="29.1.38.pr."></a>**序言。**所谓军人在退役后一年内死亡，其依军人法所立遗嘱仍有效，确实如此；即使继承人指定所附的条件在退役一年以后才成就，只要军人在一年内死亡，遗嘱仍有效。因此，如果他为儿子指定了替代继承人，儿子何时死亡并不重要；只要父亲在退役后一年内死亡即可。

<!-- source-p 151 -->
<a id="29.1.38.1"></a>**1.**某军人立下遗嘱，后来并非因不名誉事由退役，又在另一支部队重新服役。有人问，他在服役期间所立的遗嘱是否有效。我考虑的是，他依军人法还是普通法立遗嘱。如果依普通法立遗嘱，毫无疑问遗嘱有效。但如果他是以军人身份立遗嘱，我便开始考察他重新入伍的时间：是在离开军籍名册后一年内，还是一年以后？我查明，他是在一年内重新入伍。因此，如果该遗嘱当时仍依军人法有效，他是否也可以依同一军人法再次立遗嘱，以致即使在一年后死亡，该遗嘱仍有效？使我犹豫的是，后一次服役属于另一段军役；但较为宽厚的意见是，应将两段军役视为连续，从而承认遗嘱有效。我所说的不是军人希望遗嘱在再次入伍后仍有效的情形；在那种情形中，他是仿照先前为平民、后来开始服役的人，在后一次服役期间重新立下遗嘱。

<!-- source-p 152 -->
<a id="29.1.39"></a>**29.1.39**

<!-- source-p 153 -->
**保罗：《疑问集》第九卷。**

<!-- source-p 154 -->
如果家子军人被敌人俘获并在敌境死亡，我们应当说《科尔内利亚法》也适用于他的遗嘱。但如果其父先在罗马公民共同体内死亡，留下该军人之子所生的孙子，其父的遗嘱是否同样会被撤销？应当认为不会被撤销，因为从被俘之时起，该军人即被视为已经死亡。

<!-- source-p 155 -->
<a id="29.1.40"></a>**29.1.40**

<!-- source-p 156 -->
**保罗：《答复集》第十一卷。**

<!-- source-p 157 -->
<a id="29.1.40.pr."></a>**序言。**军人卢基乌斯·提提乌斯用速记符号口授遗嘱，令其书记员记录；但在将内容誊写成文字之前，他便死亡。我问，这种口授能否有效。答复是：允许军人以任何希望且能够做到的方式立遗嘱；但必须通过合法的证明方式，证明确实按照这种方式作出了遗嘱处分。

<!-- source-p 158 -->
<a id="29.1.40.1"></a>**1.**同一答复还指出：根据依军人法所立遗嘱，奴隶即使只是附条件取得遗赠，也可以主张获得自由。

<!-- source-p 159 -->
<a id="29.1.40.2"></a>**2.**同一答复还指出：军人卢基乌斯·提提乌斯立下如下遗嘱：“我的女奴潘菲拉应作为我的全部遗产继承人。”随后他又在另一条款中把同一潘菲拉遗赠给其军人同袍塞姆普罗尼乌斯，并托付塞姆普罗尼乌斯为她解放。我问，潘菲拉是否已成为继承人，并且如同直接获得自由一样成为自由人。答复是：应当认为，军人指定自己的女奴为继承人时，不知道这一指定也会使她取得自由；因此，他后来要求军人同袍释放她，是没有必要的。潘菲拉已经因先前书写而成为自由人和继承人；后来再将她作为遗赠处分，不会损害先前的意思，故该遗赠无效。

<!-- source-p 160 -->
<a id="29.1.41"></a>**29.1.41**

<!-- source-p 161 -->
**特里丰尼努斯：《论辩集》第十八卷。**

<!-- source-p 162 -->
<a id="29.1.41.pr."></a>**序言。**军人可以这样指定继承人：“提提乌斯在其有生之年为继承人；他死后，由塞普提基乌斯继承。”但如果他写道：“提提乌斯为继承人，期限为十年”，却没有指定替代继承人，那么十年后即适用无遗嘱继承规则。既然我们已经说过，军人可以自某一确定时间起或至某一确定时间止指定继承人，那么在指定继承人可以承受遗产的日期到来以前，遗产应依无遗嘱继承规则移转。军人依其特权可以处分遗产份额，也同样可以规定继承发生的时间；即使期间并不短，也适用该特权。

<!-- source-p 163 -->
<a id="29.1.41.1"></a>**1.**依神圣哈德良的敕答，如果某妇女可能受到不名誉关系的怀疑，她不得依据军人遗嘱取得任何财产。

<!-- source-p 164 -->
<a id="29.1.41.2"></a>**2.**军人不得为处于他人父权之下的人指定监护人。

<!-- source-p 165 -->
<a id="29.1.41.3"></a>**3.**有人问，如果军人剥夺儿子的继承资格，或者明知某人为自己的儿子却在遗嘱中不提及他，能否令替代继承人给该儿子遗赠。我认为不能，即使军人已为被剥夺继承资格的儿子留下丰厚遗赠，也不能如此处理。

<!-- source-p 166 -->
<a id="29.1.41.4"></a>**4.**军人也可以为已解放的儿子指定替代继承人；但这一权利仅适用于由军人本人移转给该儿子的财产，不适用于儿子已经拥有或后来取得的财产。因为即使军人为儿子指定了替代继承人，若儿子之后又从祖父处继承财产，也没人会认为这部分财产归替代继承人。

<!-- source-p 167 -->
<a id="29.1.41.5"></a>**5.**如果军人的遗产无人接受，他为未成年人指定的替代继承是否有效？应当作肯定回答，因为军人可以只为儿子立遗嘱，即使没有为自己立遗嘱。

<!-- source-p 168 -->
<a id="29.1.42"></a>**29.1.42**

<!-- source-p 169 -->
**乌尔比安：《告示评注》第四十五卷。**

<!-- source-p 170 -->
军人从被列入军籍名册之时起，才可以依军人法立遗嘱；此前不可以。因此，尚未列入军籍名册的人，即使已经被选为新兵并由公款资助前往军营，也还不是军人；因为他们必须先被列入军籍名册。

<a id="29.1.43"></a>**29.1.43**

<!-- source-p 172 -->
**帕皮尼安：《答复集》第六卷。**

<a id="29.1.44"></a>**29.1.44**

<!-- source-p 175 -->
**乌尔比安：《告示评注》第四十五卷。**

<!-- source-p 176 -->
皇帝敕答表明，凡因其身份等级而不得依军人法立遗嘱的人，如果身处敌境并在那里死亡，仍可按照自己希望且能够做到的方式立遗嘱；这包括行省总督，也包括其他不得依军人法立遗嘱的人。
