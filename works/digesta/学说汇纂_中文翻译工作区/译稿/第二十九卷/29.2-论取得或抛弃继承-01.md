# D.29.2 论取得或抛弃继承（*De adquirenda vel omittenda hereditate*）

<!-- source-p 001 -->
<a id="2"></a><a id="29.2"></a>**29.2.0. 论取得或抛弃继承。**

<!-- source-p 002 -->
<a id="29.2.1"></a>**29.2.1**

<!-- source-p 003 -->
**保罗：《萨宾评注》第二卷。**

<!-- source-p 004 -->
能够取得全部遗产的人，不得拆分遗产，仅接受其中一部分。

<!-- source-p 005 -->
<a id="29.2.2"></a>**29.2.2**

<!-- source-p 006 -->
**乌尔比安：《萨宾评注》第四卷。**

<!-- source-p 007 -->
即使某人在同一遗产的数个份额中被分别指定为继承人，他也不得拒绝其中某些份额、而接受另一些份额。

<!-- source-p 008 -->
<a id="29.2.3"></a>**29.2.3**

<!-- source-p 009 -->
**乌尔比安：《萨宾评注》第六卷。**

<!-- source-p 010 -->
只要先顺位的指定继承人仍可接受遗产，替补继承人就不能接受遗产。

<!-- source-p 011 -->
<a id="29.2.4"></a>**29.2.4**

<!-- source-p 012 -->
**乌尔比安：《萨宾评注》第三卷。**

<!-- source-p 013 -->
不能接受遗产的人，不被视为不愿接受遗产。

<!-- source-p 014 -->
<a id="29.2.5"></a>**29.2.5**

<!-- source-p 015 -->
**乌尔比安：《萨宾评注》第一卷。**

<!-- source-p 016 -->
<a id="29.2.5.pr."></a>**序言。**已经确定，天生不能说话者以及天生聋者，均能够以继承人身份行事并承担遗产债务。

<!-- source-p 017 -->
<a id="29.2.5.1"></a>**1.**已经确定，即使某人依法被禁止管理自己的财产，他被指定为继承人后仍能够接受遗产。

<!-- source-p 018 -->
<a id="29.2.6"></a>**29.2.6**

<!-- source-p 019 -->
**乌尔比安：《萨宾评注》第六卷。**

<!-- source-p 020 -->
<a id="29.2.6.pr."></a>**序言。**受他人家父权支配的人，不能违背其权力人的意愿，使该权力人承担继承债务；否则，父亲就会被迫承担他人的债务。

<!-- source-p 021 -->
<a id="29.2.6.1"></a>**1.**不过，对于遗产占有，人们认可：受权力支配者未经权力人同意而接受的遗产占有，可以被追认。

<!-- source-p 022 -->
<a id="29.2.6.2"></a>**2.**如果儿子依据《奥尔菲提安元老院决议》取得母亲遗产的法定继承权，也应采用同一规则。

<!-- source-p 023 -->
<a id="29.2.6.3"></a>**3.**即使儿子没有接受遗产，但父亲仍长期占有该遗产，也应认为父亲已接受遗产；神圣庇护皇帝及我主皇帝均以敕答如此规定。

<!-- source-p 024 -->
<a id="29.2.6.4"></a>**4.**如果某人以为自己仍是家子，奉父亲之命接受了遗产，那么已经确定，他既没有为自己，也没有为下令的父亲取得遗产。不过，若父亲命令某人接受遗产，而此人在父亲死后才接受，那么即使该人后来死亡，他仍会使自己负担遗产债务；正如尤利安在《学说汇纂》第三十一卷中所写，他更倾向于认可这样一项规则：某人若不确定自己是在父亲死亡后成为家子还是家父，仍可以接受遗产。

<!-- source-p 025 -->
<a id="29.2.6.5"></a>**5.**有时，家子无需正式接受遗产，即可为其权力人取得遗产。例如，立遗嘱人剥夺儿子的继承人资格，却指定孙子为继承人；此时孙子无需接受遗产，其父亲就会成为继承人，而且是当然继承人。

<!-- source-p 026 -->
<a id="29.2.6.6"></a>**6.**如果某人被指定为继承人，却被已遭剥夺继承人资格的儿子收养为家子，该人并不会因此成为当然继承人；应当命令他接受遗产，因为立遗嘱人死亡时，他并未处于儿子的权力之下。一个人不能通过另一人而成为当然继承人，除非后者本身也会成为当然继承人。

<!-- source-p 027 -->
<a id="29.2.6.7"></a>**7.**塞尔苏斯在《学说汇纂》第十五卷中写道：某人因言语威胁或其他恐惧而被迫、违背本意地接受遗产，若是自由人，并不因此成为继承人；若是奴隶，也不会使其主人因此成为继承人。

<!-- source-p 028 -->
<a id="29.2.7"></a>**29.2.7**

<!-- source-p 029 -->
**保罗：《萨宾评注》第一卷。**

<!-- source-p 030 -->
<a id="29.2.7.pr."></a>**序言。**如果某人指定一名家子为继承人，并写道：“如果提提乌斯——这名家子——不成为我的继承人，那么塞姆普罗尼乌斯即为继承人”，而该儿子奉父亲之命接受了遗产，替补继承人就被排除。

<!-- source-p 031 -->
<a id="29.2.7.1"></a>**1.**如果儿子尚未知道自己已成为父亲的当然继承人，就先行死亡，并留下自己的儿子作为当然继承人，应允许孙子拒绝祖父的遗产；因为如果其父仍在世，也应给予他同样的权利。

<!-- source-p 032 -->
<a id="29.2.7.2"></a>**2.**在任何继承情形中，凡成为某人的继承人，而该人又是提提乌斯的继承人者，也应视为提提乌斯的继承人；他不能拒绝提提乌斯的遗产。

<!-- source-p 033 -->
<a id="29.2.8"></a>**29.2.8**

<!-- source-p 034 -->
**乌尔比安：《萨宾评注》第七卷。**

<!-- source-p 035 -->
<a id="29.2.8.pr."></a>**序言。**依本城的惯例，男童和女童未经监护人授权，都不能使自己承担债务；而遗产会使我们承担债务——即使遗产不足清偿债务，这一点也再明显不过。这里所说的是不属于此类当然继承人的人所承受的遗产。

<!-- source-p 036 -->
<a id="29.2.8.1"></a>**1.**处于他人权力之下的未达法定成年年龄者，若奉权力人之命接受遗产，即使尚无理解能力，也会为权力人取得遗产。

<!-- source-p 037 -->
<a id="29.2.9"></a>**29.2.9**

<!-- source-p 038 -->
**保罗：《萨宾评注》第二卷。**

<!-- source-p 039 -->
即使男童尚未达到理解取得遗产原因的年龄，只要他能够说话，他仍可在监护人授权下取得遗产；尽管通常认为如此年幼的孩子并不具备理解能力，因为这个年龄既不能理解，也不能作出决定，正如精神失常者一样。之所以允许其如此，是出于对他们有利的考虑。

<!-- source-p 040 -->
<a id="29.2.10"></a>**29.2.10**

<!-- source-p 041 -->
**乌尔比安：《萨宾评注》第七卷。**

<!-- source-p 042 -->
如果某人被指定为全部遗产的继承人，却决定只取得遗产的一部分，应视为他已以继承人身份处理了全部遗产。

<!-- source-p 043 -->
<a id="29.2.11"></a>**29.2.11**

<!-- source-p 044 -->
**庞波尼乌斯：《萨宾评注》第三卷。**

<!-- source-p 045 -->
未达法定成年年龄的子女，无论如何都有权拒绝遗产；已达到法定成年年龄的子女，则只有在没有介入遗产事务时，才有此权利。

<!-- source-p 046 -->
<a id="29.2.12"></a>**29.2.12**

<!-- source-p 047 -->
**乌尔比安：《告示评注》第十一卷。**

<!-- source-p 048 -->
对于未介入父亲遗产的人，无论成年与否，都不必请求裁判官救济；只要其没有介入遗产事务即可。*semenstribus* 中曾就维比乌斯·索忒尔和维克托里努斯作出敕答：如果父亲已决定不接受祖父遗产，且未移走任何财物，也未以继承人身份处理遗产，未成年人无需就祖父生前所订合同请求恢复原状。〔*semenstribus* 的词义和指称待核〕

<!-- source-p 049 -->
<a id="29.2.13"></a>**29.2.13**

<!-- source-p 050 -->
**乌尔比安：《萨宾评注》第七卷。**
<!-- source-p 051 -->
<a id="29.2.13.pr."></a>**序言。**被指定为继承人或取得法定继承权的人，会因拒绝遗产而丧失继承权。只有在遗产已经可以接受时，这一规则才正确。反之，如果被指定的继承人在条件成就之前拒绝遗产，那么无论该条件为何，他的拒绝都不发生效力；即使条件是否成就取决于他的意愿，结论也相同。

<!-- source-p 052 -->
<a id="29.2.13.1"></a>**1.**如果某人不确定立遗嘱人是否仍然在世，他拒绝遗产并不发生效力。

<!-- source-p 053 -->
<a id="29.2.13.2"></a>**2.**替补继承人如果在指定继承人就遗产作出决定之前便拒绝遗产，其拒绝同样无效。

<!-- source-p 054 -->
<a id="29.2.13.3"></a>**3.**儿子未经父亲同意而拒绝遗产，不会损害父亲的权利；父亲未经儿子同意而拒绝，也不会损害儿子的权利。不过，父子双方都可以各自拒绝遗产。

<!-- source-p 055 -->
<a id="29.2.14"></a>**29.2.14**

<!-- source-p 056 -->
**保罗：《萨宾评注》第二卷。**

<!-- source-p 057 -->
如果子女取得的是法定继承，也应作同样处理。

<!-- source-p 058 -->
<a id="29.2.15"></a>**29.2.15**

<!-- source-p 059 -->
**乌尔比安：《萨宾评注》第七卷。**

<!-- source-p 060 -->
某人误以为自己是当然继承人，实际上却是自愿继承人，他不能拒绝遗产；因为对于能否拒绝遗产，主观认识比客观事实更有分量。

<!-- source-p 061 -->
<a id="29.2.16"></a>**29.2.16**

<!-- source-p 062 -->
**乌尔比安：《告示评注》第二十四卷。**

<!-- source-p 063 -->
反过来说，自以为是当然继承人的人，不能因此成为自愿继承人。

<!-- source-p 064 -->
<a id="29.2.17"></a>**29.2.17**

<!-- source-p 065 -->
**乌尔比安：《萨宾评注》第七卷。**

<!-- source-p 066 -->
<a id="29.2.17.pr."></a>**序言。**认为遗嘱无效或伪造的人，也不能拒绝遗产。但如果可以确定所谓“伪造”的遗嘱并非伪造，那么他既可以通过接受遗产而取得继承权，也会因拒绝遗产而丧失继承权。

<!-- source-p 067 -->
<a id="29.2.17.1"></a>**1.**某人既被指定为继承人，同时又是法定继承人；如果他以遗嘱继承人的身份拒绝遗产，并不会因此丧失法定继承权。但如果他以法定继承人的身份拒绝：若他知道自己已被指定为遗嘱继承人，应认为他同时拒绝了两种继承；若他并不知道，则该拒绝对两种继承都不发生不利效力：对遗嘱继承而言，他并未拒绝；对法定继承而言，遗产尚未归属于他。

<!-- source-p 068 -->
<a id="29.2.18"></a>**29.2.18**

<!-- source-p 069 -->
**保罗：《萨宾评注》第二卷。**

<!-- source-p 070 -->
有权取得遗产的人，也有权拒绝遗产。

<!-- source-p 071 -->
<a id="29.2.19"></a>**29.2.19**

<!-- source-p 072 -->
**保罗：《告示评注》第五十九卷。**

<!-- source-p 073 -->
希望接受遗产或请求遗产占有的人，必须确定立遗嘱人已经死亡。

<!-- source-p 074 -->
<a id="29.2.20"></a>**29.2.20**

<!-- source-p 075 -->
**乌尔比安：《告示评注》第六十一卷。**

<!-- source-p 076 -->
<a id="29.2.20.pr."></a>**序言。**某人仿佛继承人一样作出某项行为，就被视为以继承人身份行事。尤利安概括写道，只有仿佛继承人一样处理事务的人，才算以继承人身份行事；关键在于行为人的主观意图，而非行为本身，因为其意图必须是愿意成为继承人。反之，如果某人出于孝道或保管财产而行事，或者并非以继承人身份，而是基于其他权利、仿佛所有人一样行事，就显然不属于以继承人身份处理遗产。

<!-- source-p 077 -->
<a id="29.2.20.1"></a>**1.**因此，当然继承人子女常会声明，他们所作的行为并非出于继承人意图，而是出于孝道、保管财物或维护自身权益。例如，他们为父亲下葬，或为其履行丧葬仪式：如果是出于继承人意图，就属于以继承人身份行事；如果是出于孝道，则不属于此类行为。他们喂养遗产中的奴隶和牲畜，或将其出售：如果是以继承人身份行事，就属于以继承人身份处理遗产；如果不是，而是为了保管财物，或以为财物属于自己，或在考虑期间为保全遗产财物而采取措施——因为他也许不愿以继承人身份行事——那么显然不属于以继承人身份处理遗产。同样，如果某人出租农庄或房屋、修缮房屋，或做其他事情，并非出于以继承人身份处理事务的意图，而是为了替补继承人或可能的无遗嘱继承人着想，或者出售易于随时间毁损的财物，那么他也不属于以继承人身份处理遗产，因为他并非怀有该种意图。

<!-- source-p 078 -->
<a id="29.2.20.2"></a>**2.**如果某人仿佛继承人一样请求取得某项财物，但该财物并不转归外部继承人，我们应考察他是否已使自己承担遗产债务。例如，他向父母的被释奴隶请求提供劳务；外部继承人原本不能请求这些劳务，但此人却可以通过请求而取得。人们一致认为，他并未以继承人身份处理遗产，因为这些劳务的请求权也属于债权人，尤其是尚未履行的劳务。

<!-- source-p 079 -->
<a id="29.2.20.3"></a>**3.**但正如帕皮尼安所说，即使有人将死者安葬于家族墓地，也不应认为他因此须向父亲的债权人承担责任；这一意见较为宽厚，尽管尤利安写下了相反观点。

<!-- source-p 080 -->
<a id="29.2.20.4"></a>**4.**帕皮尼安写道：某儿子被指定为继承人，却拒绝接受父亲的遗产。通常有人认为，如果他从附条件解放的奴隶处收取钱款，就应对债权人承担责任，无论该钱款是否属于奴隶的特有财产；因为为满足解放条件而交付的钱，是依照死者的意愿取得的。尤利安认为，即使儿子没有拒绝遗产，结论也相同。不过，帕皮尼安说，只有儿子是唯一继承人时，才属于以继承人身份处理遗产；如果他有共同继承人，且共同继承人已经接受遗产，那么从附条件解放的奴隶处收取钱款的儿子，不必承担债权人的诉权。因为儿子拒绝遗产时，应依裁判官法取得与被解放出家父权力后拒绝遗产者相同的权利；在这种情况下，若曾命令附条件解放的奴隶将钱专门交给该儿子，只要他不把钱交给继承人，该奴隶就可以获得自由。因此，只有在某人取得某物，而若不具有继承人的名义和权利便无法取得时，才应说他以继承人身份处理了遗产。

<!-- source-p 081 -->
<a id="29.2.20.5"></a>**5.**如果儿子就毁坏墓地提起诉讼，即使该墓地属于遗产，也不应认为他已介入父亲的财产，因为他并未从父亲的财产中取得任何东西；这项诉讼包含的是惩罚和报复，而非追索财物。

<!-- source-p 082 -->
<a id="29.2.21"></a>**29.2.21**

<!-- source-p 083 -->
**乌尔比安：《萨宾评注》第七卷。**

<!-- source-p 084 -->
<a id="29.2.21.pr."></a>**序言。**外部继承人若像盗取或掠夺一样占有遗产财物，并不属于以继承人身份处理遗产；因为这种行为表明他具有相反的意图。

<!-- source-p 085 -->
<a id="29.2.21.1"></a>**1.**有时，单凭主观意图就会使某人受遗产约束；例如，他把一项并非遗产的财物当作继承人所有之物使用。

<!-- source-p 086 -->
<a id="29.2.21.2"></a>**2.**不过，只有在遗产已经归属于某人时，他才能通过以继承人身份处理遗产而取得遗产。我们已经说过，在某些情形中，即使拒绝遗产也不发生效力；同样应知，在这些情形中，即使以继承人身份处理遗产，也不发生任何效力。

<!-- source-p 087 -->
<a id="29.2.21.3"></a>**3.**如果某人不知道遗嘱指定给自己的份额，尤利安写道，这不会妨碍他以继承人身份处理遗产。卡西乌斯也赞同这一点：如果他知道自己被指定为附条件继承人，且其被指定为替补继承人所附的条件已经成就，也应如此。那么，如果他不知道替补条件已经成就呢？我认为他仍可接受遗产，正如他不知道共同继承人拒绝遗产、以致某一份额归属于自己的情形一样。

<!-- source-p 088 -->
<a id="29.2.22"></a>**29.2.22**

<!-- source-p 089 -->
**保罗：《萨宾评注》第二卷。**

<!-- source-p 090 -->
如果依法享有继承权的人误以为死者是自己的奴隶，并像取得其特有财产那样占有遗产，人们认为他不会因此承担继承债务。正如庞波尼乌斯所说，如果此人把自己已获自由的被释奴隶误认为仍是奴隶，并像庇护人一样占有其财产，也应作同样判断。某人要通过以继承人身份处理遗产而受其约束，必须知道遗产是基于何种原因归属于自己。例如，最近的宗亲继承人已在一份合法遗嘱中被指定为继承人；但在遗嘱尚未出示前，他以为家父无遗嘱死亡，即使他所做的一切都像所有人一样，也不会成为继承人。如果某人在一份不合法的遗嘱中被指定为继承人，遗嘱出示后他仍以为遗嘱合法，即使他所做的一切都像所有人一样管理财物，也不会因此取得遗产；法律规则亦同。

<!-- source-p 091 -->
<a id="29.2.23"></a>**29.2.23**

<!-- source-p 092 -->
**庞波尼乌斯：《萨宾评注》第三卷。**

<!-- source-p 093 -->
拒绝遗产或遗赠的人，必须确定自己享有何种权利。

<!-- source-p 094 -->
<a id="29.2.24"></a>**29.2.24**

<!-- source-p 095 -->
**乌尔比安：《萨宾评注》第七卷。**

<!-- source-p 096 -->
曾有人提出疑问：如果某人为了放弃遗产而收取一笔价金，是否会被视为以继承人身份处理了遗产？人们认可，此人因为不愿成为继承人而收取价金，并非以继承人身份处理遗产，但仍落入裁判官告示的适用范围。因此，无论价金是由替补继承人还是法定继承人支付，都应视为因死亡而取得的赠与。即使他没有实际收款，而只是有人向他承诺支付该款项，结论也相同；因为他通过订立要式口约，也取得了因死亡而作出的赠与。

<!-- source-p 097 -->
<a id="29.2.25"></a>**29.2.25**

<!-- source-p 098 -->
**乌尔比安：《萨宾评注》第八卷。**

<!-- source-p 099 -->
<a id="29.2.25.pr."></a>**序言。**如果他人的奴隶善意地为我服役，奉我的命令接受遗产，既不能使事务有所进展，也不能为我取得遗产；用益权人的奴隶也同样如此。

<!-- source-p 100 -->
<a id="29.2.25.1"></a>**1.**市镇、团体或市议会的奴隶被指定为继承人后，如果获得自由或被让与他人，就可以接受遗产。

<!-- source-p 101 -->
<a id="29.2.25.2"></a>**2.**如果奴隶属于国库，凯撒的财务官奉命令让他接受遗产，他就可以接受；敕答中经常如此规定。

<!-- source-p 102 -->
<a id="29.2.25.3"></a>**3.**如果某人沦为刑罚奴隶，即被判处角斗、斗兽或矿场劳役，而他被指定为继承人，那么这项指定视为未曾书写；神圣庇护皇帝曾以敕答作此规定。

<!-- source-p 103 -->
<a id="29.2.25.4"></a>**4.**权力人作出的命令，不同于监护人授权；监护人授权是在法律行为完成时作出的，而家父的命令必须先于行为作出。盖尤斯·卡西乌斯在《民法》第二卷中如此写道；他认为，命令可以经由传话人作出，也可以通过书信作出。

<!-- source-p 104 -->
<a id="29.2.25.5"></a>**5.**命令究竟可以概括为“凡有遗产归于你者”，还是必须针对特定遗产作出？盖尤斯·卡西乌斯认为，较可取的意见是，命令必须具体作出。

<!-- source-p 105 -->
<a id="29.2.25.6"></a>**6.**有人问：能否命令某人接受尚在人世之人的遗产？我认为不应允许此类命令。显然，如果传闻称卢基乌斯·提提乌斯已经死亡，权力人可以命令受权力支配者：若提提乌斯已在遗嘱中指定他，就接受遗产；或者，若遗嘱尚未启封，且不确定其儿子是否被指定为继承人，也可以如此命令。

<!-- source-p 106 -->
<a id="29.2.25.7"></a>**7.**如果权力人命令其子收集遗产财物，是否可视为命令其接受遗产？如果命令他请求遗产占有呢？或者命令他出售遗产财物呢？又或者，权力人认可了儿子请求遗产占有的行为，随后儿子又接受遗产，该如何处理？如果权力人命令儿子以继承人身份处理事务，而儿子接受了遗产，是否可视为奉命接受？对此可以存疑。不过，较为正确的意见是，上述所有情形均应认定为接受遗产的行为。

<!-- source-p 107 -->
<a id="29.2.25.8"></a>**8.**父亲给儿子写道：“儿子，我知道你会凭借自己的审慎，照料已归于你的卢基乌斯·提提乌斯的遗产。”我认为，这足以构成父亲的命令，儿子依命令接受了遗产。

<!-- source-p 108 -->
<a id="29.2.25.9"></a>**9.**如果父亲命令说：“如果接受遗产对你有利，就接受”，或者“如果你认为接受有利，就接受”，那么儿子就是奉命接受遗产。

<!-- source-p 109 -->
<a id="29.2.25.10"></a>**10.**如果父亲命令儿子“在提提乌斯面前”接受，或者“依卢基乌斯·提提乌斯的判断”接受，我认为该命令有效。

<!-- source-p 110 -->
<a id="29.2.25.11"></a>**11.**如果父亲命令儿子仿佛被指定为全部遗产的继承人一样接受，而后来发现他只被指定为部分遗产的继承人，我认为儿子并非依父亲命令而接受。如果父亲命令儿子按部分遗产继承人接受，而后来发现他被指定为全部遗产的继承人，儿子可以接受全部遗产。另一种情形是，父亲命令儿子仿佛无遗嘱继承人一样接受，而儿子却依遗嘱接受；我认为儿子并未因此作出有效行为。但如果父亲命令儿子依遗嘱接受，儿子也可以按无遗嘱继承接受，因为这不会使父亲的处境恶化。如果父亲命令儿子仿佛被指定的继承人一样接受，后来却发现儿子只是替补继承人，或者反之，也应作同样处理。

<!-- source-p 111 -->
<a id="29.2.25.12"></a>**12.**如果父亲命令儿子接受父亲的遗产，而儿子又被指定为未达法定成年年龄者的替补继承人，仅有该命令并不足够。

<!-- source-p 112 -->
<a id="29.2.25.13"></a>**13.**显然，如果父亲如此命令：“凡依卢基乌斯·提提乌斯遗嘱归于你的遗产”，就可以主张儿子是奉命接受遗产。

<!-- source-p 113 -->
<a id="29.2.25.14"></a>**14.**如果父亲命令儿子接受遗产后，在儿子接受之前又改变主意，那么儿子随后接受并不发生效力。

<!-- source-p 114 -->
<a id="29.2.25.15"></a>**15.**同样，如果儿子在接受遗产前将自己交由他人收养为家子，该遗产就不会归属他。

<!-- source-p 115 -->
<a id="29.2.26"></a>**29.2.26**

<!-- source-p 116 -->
**保罗：《萨宾评注》第二卷。**

<!-- source-p 117 -->
如果我与自己的奴隶或儿子一同被指定为继承人，而我命令儿子或奴隶接受遗产，庞波尼乌斯写道，我立即也会根据对我的指定成为继承人；马尔凯卢斯和尤利安也赞同此意见。

<!-- source-p 118 -->
<a id="29.2.27"></a>**29.2.27**

<!-- source-p 119 -->
**庞波尼乌斯：《萨宾评注》第三卷。**

<!-- source-p 120 -->
拉贝奥说，在其财产将被处理之人仍然在世时，没有人能够以继承人身份处理其财产。

<!-- source-p 121 -->
<a id="29.2.28"></a>**29.2.28**

<!-- source-p 122 -->
**乌尔比安：《萨宾评注》第八卷。**

<!-- source-p 123 -->
阿里斯托认为，应由裁判官允许正在考虑是否接受遗产的继承人，向保管死者账簿的人索取死者的账目。

<!-- source-p 124 -->
<a id="29.2.29"></a>**29.2.29**

<!-- source-p 125 -->
**庞波尼乌斯：《萨宾评注》第三卷。**

<!-- source-p 126 -->
某人被指定为继承人，而另一名与他一同被指定、且已接受遗产的继承人，禁止他查看死者的文书、信件和账目，使他无法据此判断是否应接受遗产；在这种情况下，该人不应被视为以继承人身份处理遗产。

<!-- source-p 127 -->
<a id="29.2.30"></a>**29.2.30**

<!-- source-p 128 -->
**乌尔比安：《萨宾评注》第八卷。**

<!-- source-p 129 -->
<a id="29.2.30.pr."></a>**序言。**某人因执行国事出使而身在外地，无法命令被指定为继承人的儿子在行省接受遗产。神圣庇护皇帝以敕答规定：儿子死亡后，应由执政官给予此人救济，因为他是为公共事务而离境。

<!-- source-p 130 -->
<a id="29.2.30.1"></a>**1.**所谓“只要女子怀孕或被认为怀孕，遗腹子女出生后的最近继承人就不能接受遗产；但如果他知道女子没有怀孕，就可以接受”，应理解为：女子腹中怀有将成为自权继承人的孩子。该规则不仅适用于有遗嘱继承，也适用于无遗嘱继承。此处所说的胎儿，也包括将成为法定继承人或同父兄弟的孩子；因为在死亡时，就阻止较远顺位继承人取得遗产、并在孩子出生时为其保留顺位而言，腹中胎儿被视为已经出生。裁判官最终也会依告示将胎儿置于遗产占有之中。

<!-- source-p 131 -->
<a id="29.2.30.2"></a>**2.**因此，无论我只是认为女子怀孕，还是她确实怀有将成为自权继承人的孩子，我都不能接受遗产，因为遗嘱可能被该孩子的出生撤销；但如果遗嘱中已指定胎儿为继承人，或剥夺其继承人资格，则不在此限。

<!-- source-p 132 -->
<a id="29.2.30.3"></a>**3.**所谓“女子被认为怀孕”，应理解为她声称自己怀孕。那么，如果她本人没有这样说，反而否认怀孕，而其他人说她怀孕呢？此时仍不能接受遗产；例如助产士声称她怀孕。那么，如果只有继承人本人认为她怀孕呢？如果他是基于合理理由而如此认为，就不能接受；如果他只是依据多数人的看法，则可以接受。

<!-- source-p 133 -->
<a id="29.2.30.4"></a>**4.**如果女子确实怀孕，但继承人误以为她没有怀孕而接受了遗产，随后女子又流产，该怎么办？毫无疑问，他的接受不发生效力。因此，只有在其推定与事实相符时，推定才对他有利。

<!-- source-p 134 -->
<a id="29.2.30.5"></a>**5.**如果自称怀孕的女子本人被指定为继承人，她通过接受遗产即可取得继承权；反之，如果她误以为自己怀孕，而实际上并未怀孕，就不能取得遗产。

<!-- source-p 135 -->
<a id="29.2.30.6"></a>**6.**可以确定，即使某女子自以为怀孕、实际却未怀孕，自权继承人仍是全部遗产的继承人。如果她腹中怀有一个孩子，他是否只取得遗产的一半？无论遗嘱中指定了遗腹子女为继承人，还是父亲无遗嘱死亡，问题都一样。特图利安在《疑义集》第四卷中记载塞克斯图斯·庞波尼乌斯的意见：他认为，就如同女子子宫空虚时，自权继承人取得全部遗产；女子仅怀有一个孩子，且按人类生育的自然过程不可能再孕育另一胎时——在受孕经过一定期间后确会如此——即使继承人对此并不知情，他也只取得一半遗产，而非如尤利安所认为的四分之一。

<!-- source-p 136 -->
<a id="29.2.30.7"></a>**7.**如果被指定为继承人的是家子或奴隶，关于怀孕的认识或判断，应以他们本人，还是以家父或主人为准？例如，父亲认为女子怀孕，而儿子确定她没有怀孕，并据此接受遗产，是否取得遗产？我认为取得；反过来则不取得。

<!-- source-p 137 -->
<a id="29.2.30.8"></a>**8.**如果我确定某份遗嘱并非伪造、无效或已被撤销，即使有人声称它是伪造、无效或已被撤销，我仍可接受遗产。

<!-- source-p 138 -->
<a id="29.2.31"></a>**29.2.31**

<!-- source-p 139 -->
**保罗：《萨宾评注》第二卷。**

<!-- source-p 140 -->
如果遗嘱指定某人和遗腹子女为共同继承人，且可以确定女子没有怀孕，那么遗腹子女所得的其余份额应归给另一名继承人，即使他对此并不知情。

<!-- source-p 141 -->
<a id="29.2.32"></a>**29.2.32**

<!-- source-p 142 -->
**乌尔比安：《萨宾评注》第八卷。**

<!-- source-p 143 -->
<a id="29.2.32.pr."></a>**序言。**被指定为继承人的人，如果以为立遗嘱人仍然在世，即使立遗嘱人实际上已死亡，也不能接受遗产。

<!-- source-p 144 -->
<a id="29.2.32.1"></a>**1.**如果某人知道自己被指定为继承人，却不知道该指定是无条件的还是附条件的，也不能接受遗产；即使他实际被无条件指定，或者虽附条件但已经满足条件，结论也相同。

<!-- source-p 145 -->
<a id="29.2.32.2"></a>**2.**如果某人不确定立遗嘱人的身份，是家父还是家子，也不能接受遗产；即使事实上立遗嘱人具有作成遗嘱的资格，结论亦然。

<!-- source-p 146 -->
<a id="29.2.33"></a>**29.2.33**

<!-- source-p 147 -->
**保罗：《普劳提乌斯评注》第十二卷。**

<!-- source-p 148 -->
如果某人不确定死者是在敌人权力之下死亡，还是作为罗马公民死亡，由于两种情形下他都有权接受遗产，且事实情况允许其接受遗产，就应当说他可以接受。

<!-- source-p 149 -->
<a id="29.2.34"></a>**29.2.34**

<!-- source-p 150 -->
**乌尔比安：《萨宾评注》第八卷。**

<!-- source-p 151 -->
<a id="29.2.34.pr."></a>**序言。**如果某人不确定自己的身份，是家子还是家父——如前所述，他仍可以取得遗产——那么，为什么他不确定自己的身份时可以接受遗产，而不确定立遗嘱人的身份时却不可以？理由在于：不确定立遗嘱人的身份，就会怀疑遗嘱是否有效；不确定自己的身份，则仍然确定遗嘱有效。

<!-- source-p 152 -->
<a id="29.2.34.1"></a>**1.**如果某人被无条件指定为继承人，却以为自己是附条件被指定，并在他误以为条件已经成就后接受遗产，他能否取得遗产？应当说他可以接受，尤其因为这种误解没有使他遭受不利，也没有带来风险。若某人被无条件指定为继承人，却以为自己是附条件被指定，而且所想象的条件已经成就，则更容易认可他取得遗产；因为这种误解丝毫没有使他处于不利地位。

<!-- source-p 153 -->
<a id="29.2.35"></a>**29.2.35**

<!-- source-p 154 -->
**乌尔比安：《萨宾评注》第九卷。**

<!-- source-p 155 -->
<a id="29.2.35.pr."></a>**序言。**某人被指定为部分遗产的继承人，之后又被指定为提提乌斯的替补继承人；在遗产尚未因替补继承而归属于他之前，他已以继承人身份处理遗产，那么，他也将依替补继承的原因成为继承人，因为即使他不愿意，该份额也会归并于他。如果家子或奴隶奉家父或主人之命接受遗产，后来又被解放或释放，并依替补继承而接受遗产，结论也相同：他们将成为继承人，因为替补继承是先前继承人指定的附随安排。

<!-- source-p 156 -->
<a id="29.2.35.1"></a>**1.**如果父亲因儿子所负条件而被排除，并命令儿子接受遗产，应当说父亲并未因此为自己取得相应份额。

<!-- source-p 157 -->
<a id="29.2.35.2"></a>**2.**但如果父亲有两个儿子，却只命令其中一人接受遗产，也应命令另一名儿子接受。

<!-- source-p 158 -->
<a id="29.2.36"></a>**29.2.36**

<!-- source-p 159 -->
**庞波尼乌斯：《萨宾评注》第三卷。**

<!-- source-p 160 -->
如果主人或父亲为自己所指定的份额接受了遗产，那么还必须作出命令，才能使儿子或奴隶接受共同继承人的份额。

<!-- source-p 161 -->
<a id="29.2.37"></a>**29.2.37**

<!-- source-p 162 -->
**庞波尼乌斯：《萨宾评注》第五卷。**

<!-- source-p 163 -->
继承人承受死者的一切法律地位，并非仅取得个别财物的所有权；因为以债权债务名义存在的权利，也会转归继承人。

<!-- source-p 164 -->
<a id="29.2.38"></a>**29.2.38**

<!-- source-p 165 -->
**乌尔比安：《告示评注》第四十三卷。**

<!-- source-p 166 -->
如果有两名当然继承人，其中一人拒绝遗产，另一人则在前者拒绝后介入遗产事务，应当说后一人不能拒绝承担全部遗产负担。因为他知道或应当知道，前一人拒绝后自己将承担遗产债务；他是在这种条件下接受遗产的。

<!-- source-p 167 -->
<a id="29.2.39"></a>**29.2.39**

<!-- source-p 168 -->
**乌尔比安：《告示评注》第四十六卷。**

<!-- source-p 169 -->
只要仍可依遗嘱接受遗产，该遗产就不会转而按无遗嘱继承归属。

<!-- source-p 170 -->
<a id="29.2.40"></a>**29.2.40**

<!-- source-p 171 -->
**乌尔比安：《论辩集》第四卷。**

<!-- source-p 172 -->
有人提出疑问：即使某人没有取得父亲遗产中的任何财物，但因父亲的意愿而取得某物或实施某行为，是否仍须向父亲的债权人承担责任？例如，他被指定为未达法定成年年龄者的替补继承人。对此情形，尤利安在《学说汇纂》第二十六卷中写道：如果他介入未成年人的遗产，就会落入裁判官告示的适用范围；因为反对父母安排的人，不应再从同一遗产中取得任何利益。但马尔凯卢斯精当地作了区分，指出被指定为父亲全部遗产的继承人，还是仅被指定为部分继承人，两者差异很大：如果仅被指定为部分继承人，他就可以在不担心父亲遗产继承的情况下，接受未成年人的遗产。

<!-- source-p 173 -->
<a id="29.2.41"></a>**29.2.41**

<!-- source-p 174 -->
**尤利安：《学说汇纂》第二十六卷。**

<!-- source-p 175 -->
儿子拒绝父亲的遗产后，如果介入其被剥夺继承人资格的兄弟之遗产，并以继承人身份处理该遗产，他可以依据替补继承取得该遗产。

<!-- source-p 176 -->
<a id="29.2.42"></a>**29.2.42**

<!-- source-p 177 -->
**乌尔比安：《论辩集》第四卷。**

<!-- source-p 178 -->
<a id="29.2.42.pr."></a>**序言。**尤利安在《学说汇纂》第二十六卷中写道：如果未成年人拒绝父亲的遗产，后来又有人成为他的继承人，那么除非该人是替补继承人，否则不得强令其对父亲的债权人承担责任。尤利安倾向于认为，替补继承人也应承担父亲的遗产负担。马尔凯卢斯正确地批评了这一意见，因为这损害未成年人的利益；未成年人至少可以有自己的继承人。若因父亲的债务负担而心生畏惧，人们甚至会更加不愿接受未成年人的遗产。否则，假如该人是兄弟，他可以不按遗嘱继承，而改按无遗嘱继承取得遗产，并且不承担责任；因为一个人若只是为了避免父亲的遗产负担牵连未成年人的遗产而保护自己，就不应被认为有意规避告示。不过，我认为，尤利安所说的“兄弟”，应理解为立遗嘱人的兄弟，而非未成年人的兄弟；否则，如果某人的兄弟被父亲指定为未成年人的替补继承人，他无疑会成为当然继承人。

<!-- source-p 179 -->
<a id="29.2.42.1"></a>**1.**如果儿子在父亲生前开始了合伙关系，并在父亲死后继续参与，尤利安正确地区分：他究竟是在完成父亲在世时已经开始的事务，还是另行开展新事务。尤利安写道，如果儿子在合伙关系中开始了新事务，就不应视为介入了父亲的遗产。

<!-- source-p 180 -->
<a id="29.2.42.2"></a>**2.**如果儿子释放了父亲的奴隶，毫无疑问，应视为他已介入父亲的遗产。

<!-- source-p 181 -->
<a id="29.2.42.3"></a>**3.**题设称：儿子曾用军营特有财产从父亲处购买奴隶；父亲请求儿子释放这些奴隶，并在遗嘱中指定他为继承人。问题是，如果儿子拒绝父亲的遗产，但仍释放了这些奴隶，是否应视为介入父亲的遗产？我们说，除非能够明确证明他是以继承人身份释放奴隶，否则不应以他已介入遗产为由指责他。

<!-- source-p 182 -->
<a id="29.2.43"></a>**29.2.43**

<!-- source-p 183 -->
**尤利安：《学说汇纂》第三十卷。**

<!-- source-p 184 -->
继承人不得通过遗产中的奴隶，为自己取得同一遗产的份额或属于该遗产的财物。

<!-- source-p 185 -->
<a id="29.2.44"></a>**29.2.44**

<!-- source-p 186 -->
**尤利安：《学说汇纂》第四十七卷。**

<!-- source-p 187 -->
如果未成年人继承其父亲的遗产后又拒绝该遗产，即使父亲的财产已经交由债权人处置，未成年人善意实施的行为仍应获得认可。因此，若有人在监护人授权下向未成年人购买土地，应予救济；未成年人是否有清偿能力，并不重要。

<!-- source-p 188 -->
<a id="29.2.45"></a>**29.2.45**

<!-- source-p 189 -->
**尤利安：《致乌尔塞乌斯·费罗克斯》第一卷。**

<!-- source-p 190 -->
<a id="29.2.45.pr."></a>**序言。**接受遗产不属于奴隶劳务的范围。

<!-- source-p 191 -->
<a id="29.2.45.1"></a>**1.**因此，如果嫁资中的奴隶接受了遗产，妻子可以通过嫁资之诉取回该遗产；尽管嫁资奴隶凭劳务取得的财物归丈夫所有。

<!-- source-p 192 -->
<a id="29.2.45.2"></a>**2.**在约定共同分享收益与利润的合伙关系中，合伙人通过自己的劳务取得的任何财物都应纳入共有；但每个人为自己取得继承。

<!-- source-p 193 -->
<a id="29.2.45.3"></a>**3.**此外，用益权人也不得命令用益权所及的奴隶接受遗产。

<!-- source-p 194 -->
<a id="29.2.45.4"></a>**4.**有些法学家答复说：如果一名自由人善意地为我服役，并因我的关系被指定为继承人，他可以奉我的命令接受遗产。这种说法可能正确；因为他不是通过自己的劳务为我取得财物，而是从我的财产中为我取得，正如他通过以我的财物订立要式口约或接受交付而为我取得财物一样。
