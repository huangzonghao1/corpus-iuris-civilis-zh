## 7.5.0　论通常因使用而消耗或减少之物的用益权（*De usu fructu earum rerum, quae usu consumuntur vel minuuntur*）

### <a id="7.5.1"></a>7.5.1　乌尔比安《评萨比努斯》第十八卷

元老院决议规定，只要可以确认某物属于某人的财产，就可以将该物的用益权遗赠给他人。该决议似乎由此创设了如下规则：因使用而消耗或减少的物，也可以遗赠其用益权。

### <a id="7.5.2"></a>7.5.2　盖尤斯《评行省告示》第七卷

<a id="7.5.2.pr."></a>

**序言（pr.）** 不过，对于以遗赠取得金钱用益权的人，应当要求其提供适当担保。

<a id="7.5.2.1"></a>

**1.** 该元老院决议并未使金钱用益权真正成为通常意义上的用益权——因为元老院的权威不能改变自然法理——而是通过引入救济，使之开始被视为准用益权。

### <a id="7.5.3"></a>7.5.3　乌尔比安《评萨比努斯》第十八卷

由此，任何物的用益权都可以遗赠。债权是否也可以遗赠用益权？涅尔瓦否认可以；但卡西乌斯和普罗库鲁斯认为可以，此说较为正确。不过，涅尔瓦本人也写道，用益权可以遗赠给债务人本人，并应免除其利息。

### <a id="7.5.4"></a>7.5.4　保罗《评涅拉提乌斯》第一卷

因此，也应要求该债务人提供担保。

### <a id="7.5.5"></a>7.5.5　乌尔比安《评萨比努斯》第十八卷

<a id="7.5.5.pr."></a>

**序言（pr.）** 该元老院决议不仅适用于遗赠其金钱或其他自有物用益权之人；即使这些物属于他人，也适用该决议。

<a id="7.5.5.1"></a>

**1.** 如果遗赠的是金钱或其他因使用而消耗的物之用益权，却未提供担保，那么用益权终止后，已交付的金钱或其他消耗物是否可以请求返还？如果有人在用益权仍存续时请求提供担保，可以说，未提供担保这一事实可通过不确定给付之诉（*condictio incerti*）请求救济。但如果用益权已经终止，萨比努斯认为，可以请求返还相应数额；塞尔苏斯在《学说汇纂》第十八卷中也赞同此说。我认为这一意见并非没有道理。

<a id="7.5.5.2"></a>

**2.** 关于金钱用益权及其他因使用而消耗之物的规则，也适用于使用权；因为尤利安和庞波尼乌斯在《论要式口约》第八卷中都写道，金钱的使用与其用益权所包含的内容相同。

### <a id="7.5.6"></a>7.5.6　尤利安《学说汇纂》第三十五卷

<a id="7.5.6.pr."></a>

**序言（pr.）** 如果一万钱遗赠给你，而同一笔一万钱的用益权遗赠给我，那么一万钱的所有权仍全部归你；但应向我支付五千钱，并由我提供担保，保证在我死亡或发生身份减等（*capitis deminutio*）时返还。又如，土地遗赠给你，而同一土地的用益权遗赠给我：你取得整块土地的所有权，其中一部分负有用益权，另一部分不负用益权；我应依善良公正之人的判断向你提供担保，而不是向继承人提供担保。

<a id="7.5.6.1"></a>

**1.** 如果同一笔一万钱的用益权遗赠给两人，每人各取得五千钱，并应彼此以及向继承人提供充分担保。

### <a id="7.5.7"></a>7.5.7　盖尤斯《评行省告示》第七卷

如果葡萄酒、橄榄油或谷物的用益权被遗赠，应将这些物的所有权转让给受遗赠人，并要求其提供担保：在其死亡或发生身份减等时，应返还质量相同的物；或者，对这些物作价后，以固定金额提供担保，后一种方式更为方便。其他以使用为内容的物，也应作相同理解。

### <a id="7.5.8"></a>7.5.8　帕比尼安《疑义》第十七卷

遗嘱指定三名继承人，将一万五千钱的用益权遗赠给提提乌斯，并命令其中两名继承人为受遗赠人提供充分担保。人们认为，担保本身的遗赠也有效，并不违反元老院决议，因为该决议并不禁止提供担保；而且，这里一项遗赠属于确定之物，另一项则属于不确定之物。因此，受遗赠人应以用益权为由，向已从共同继承人处取得担保的人请求相应金额；若其未提供充分担保，也可对其提起不确定给付之诉。至于已经提供担保、却因共同继承人迟延而未能从其处取得担保的人，在此期间既不因孳息而承担责任——元老院决议不允许如此——也不承担不确定给付之诉的责任，因为他已向共同继承人提供担保。我们还认为，应当强令受遗赠人作出允诺。用益权终止后，如果共同继承人因保证责任被起诉，他们不得提起委任之诉；因为他们并未接受委任，只是遵从遗嘱人的意思；况且，担保的遗赠最终使他们免责。对此，无须再长篇讨论：第二项遗赠，即担保的遗赠，应视为归属于金钱用益权的受遗赠人，而非继承人；遗嘱人意在保护的正是此人，并认为其利益在于无需自行承担风险即可取得保证人。〔本段关于“已提供担保者”“取得担保者”及担保遗赠的权利归属，原文关系较为压缩，译文依句法顺序处理。〕

### <a id="7.5.9"></a>7.5.9　保罗《评涅拉提乌斯》第一卷

关于返还金钱用益权的要式口约中，只列举了两种情形：死亡和身份减等，

### <a id="7.5.10"></a>7.5.10　乌尔比安《评告示》第七十九卷

<a id="7.5.10.pr."></a>

**序言（pr.）** 因为金钱的使用只能因这两种情形而终止。

<a id="7.5.10.1"></a>

**1.** 如果仅遗赠了金钱的使用，应认为这一用语在此也包含用益权，因此必须订立上述要式口约。有人认为，只有在金钱交付后才能订立该口约；但我认为，无论金钱在口约订立之前还是之后交付，该口约都有效。

### <a id="7.5.11"></a>7.5.11　乌尔比安《评萨比努斯》第十八卷

如果有人被遗赠羊毛、香料或芳香物的用益权，那么依法律似乎并未就这些物设立通常意义上的用益权；应适用关于这些物之担保的元老院决议。

### <a id="7.5.12"></a>7.5.12　马尔基安《法学阶梯》第七卷

金钱遗赠给提提乌斯，并规定受遗赠人死亡后应返还给梅维乌斯。尽管遗嘱还写明提提乌斯可以使用该金钱，塞维鲁和安敦尼皇帝仍在敕复中指出：遗嘱实际上将金钱所有权遗赠给了提提乌斯，只是提及“使用”，因为提提乌斯死亡后必须返还该金钱。
