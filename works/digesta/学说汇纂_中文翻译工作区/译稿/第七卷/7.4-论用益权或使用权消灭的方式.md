<a id="4"></a>
## <a id="7.4"></a>7.4.0　论用益权或使用权消灭的方式（*Quibus modis usus fructus vel usus amittitur*）

### <a id="7.4.1"></a>7.4.1　乌尔比安《评萨宾》第十七卷

<a id="7.4.1.pr."></a>

**序言（pr.）** 身份减等不仅会使用益权消灭，也会使有关用益权的诉权消灭。用益权究竟是依法设立，还是经裁判官保护而设立，并无区别。因此，通过交付设立的用益权，以及在税租土地或地上权（*superficies*）上非依法设立的用益权，也会因身份减等而消灭。〔术语疑点：此处 *superficies* 指地上权关系还是其地上建筑，底本未进一步说明。〕

<a id="7.4.1.1"></a>

**1.** 只有在用益权已经设立后，身份减等才会使其消灭；如果某人在接受遗产之前，或在遗赠权利确定时点（*dies cedens*）之前遭受身份减等，则用益权不会因此消灭，这一点是确定的。

<a id="7.4.1.2"></a>

**2.** 如果遗赠给你的是一处自某日起生效的土地，而你受嘱托将用益权返还给我，就应考察：如果我在你的遗赠所附期间内遭受身份减等，我的用益权是否仍然保全，仿佛身份减等发生在遗赠权利确定时点之前？对此可以作有利于我的解释。

<a id="7.4.1.3"></a>

**3.** 身份减等只会消灭已经设立的用益权，甚至可由此推知：如果用益权按年、月或日逐期遗赠，只会消灭已经开始的那一期。比如用益权按年遗赠的，只消灭该年度的用益权；按月遗赠的，只消灭该月的用益权；按日遗赠的，只消灭该日的用益权。

### <a id="7.4.2"></a>7.4.2　帕比尼安《疑问集》第十七卷

<a id="7.4.2.pr."></a>

**序言（pr.）** 如果用益权分别遗赠给两人，使其隔年享有，那么在连续各年中，所有权均处于裸所有权状态。反之，如果只指定一名受遗赠人，使其隔年享有用益权，那么在该受遗赠人无权享用的期间，完整所有权仍归继承人。如果前述两人中的一人死亡，完整所有权就会在各个期间交替归属；另一人不能因此取得任何增益，因为在对方不享有用益权的期间，每个人都曾完整享有自己相应期间的用益权。

<a id="7.4.2.1"></a>

**1.** 如果发生的不是死亡，而是身份减等，由于遗赠有数项，只会丧失其享有用益权的那一年度的收益。这一规则也应适用于逐年受领用益权的单一受遗赠人，使有关各期的记载具有再次取得相应用益权的效力。〔句义待核：*ut commemoratio temporum repetitionis potestatem habeat* 的具体含义不甚明确，暂依其与逐期遗赠及重新取得的语境翻译。〕

<a id="7.4.2.2"></a>

**2.** 如果用益权分别遗赠给数人，使其隔年享有，而他们同意在同一年享用，那么他们的请求会受到阻却，因为遗嘱人的意思显然不是让两人的权利发生重合。原因在于，以下两种情形大不相同：将用益权共同遗赠给两人，使其隔年享有（这种安排当然不能延续至第一年之后，正如将用益权以同样方式遗赠给一人也不能如此）；或者分别将用益权逐年交替遗赠给各人。如果他们要在同一年享有用益权，要么因各自的意思而相互阻却，要么在这种意思不构成障碍时，各该年度的用益权就会处于无人享有的状态。

### <a id="7.4.3"></a>7.4.3　乌尔比安《评萨宾》第十七卷

<a id="7.4.3.pr."></a>

**序言（pr.）** 正如用益权可以按年遗赠，因身份减等而消灭的用益权也可以再次遗赠，例如加上“每当其遭受身份减等时，我就将用益权遗赠给他”，或“每当用益权消灭时，我就将其遗赠给他”。如此一来，如果用益权因身份减等而消灭，应视为再次遗赠。由此产生的问题是：如果用益权遗赠给某人，直至其死亡为止，那么每当用益权消灭时，是否都应视为重新遗赠？麦基安也曾探讨此问题；我认为应视为重新遗赠。因此，如果用益权遗赠至某一期间，例如十年届满为止，也应作相同解释。

<a id="7.4.3.1"></a>

**1.** 对于因身份减等而丧失用益权后所作的重新遗赠，有人追问：它是否也保留了相应的增益权？例如，用益权遗赠给提提乌斯和梅维乌斯，并且立遗嘱人还规定，若提提乌斯遭受身份减等，就再次将用益权遗赠给他。于是产生问题：如果提提乌斯因重新遗赠而取得用益权，他与梅维乌斯之间的增益权是否仍然保留？帕比尼安在《疑问集》第十七卷中写道，增益权仍然保留，正如另有一人被指定为提提乌斯的用益权替补受遗赠人一样；因为虽然他们并非在措辞上相互结合，实质上却应视为结合在一起。

<a id="7.4.3.2"></a>

**2.** 同一帕比尼安还提出：用益权遗赠给提提乌斯和梅维乌斯后，如果重新遗赠时没有将全部用益权、而只将其中一部分遗赠给提提乌斯，他们是否应视为共同受遗赠人？他说，如果提提乌斯丧失用益权，全部份额都增益给另一人；如果丧失用益权的是梅维乌斯，则并非全部份额都增益给提提乌斯，而是一部分归提提乌斯，另一部分回复于所有权。此意见有其道理：不能说某人丧失并重新取得用益权的那个时点，他自己也从所丧失的用益权中获得了增益；因为我们认为，丧失用益权的人不能从其所丧失的部分取得任何增益。

<a id="7.4.3.3"></a>

**3.** 用益权因死亡而消灭也毫无疑问，因为享用权利随死亡而终止；其他附随于特定个人的权利亦同。

### <a id="7.4.4"></a>7.4.4　马尔西安《法学阶梯》第三卷

如果受遗赠人受嘱托将遗赠给他的用益权返还给他人，裁判官应当设法使该用益权在遗嘱信托受益人一方消灭，而尽量避免其在受遗赠人一方消灭。

### <a id="7.4.5"></a>7.4.5　乌尔比安《评萨宾》第十七卷

<a id="7.4.5.pr."></a>

**序言（pr.）** 用益权以任何方式消灭后，均可再次遗赠；但因死亡而消灭的除外，除非用益权是遗赠给继承人的。

<a id="7.4.5.1"></a>

**1.** 如果某人只转让了对一名奴隶所享有的用益权，而其用益权正是通过该奴隶取得的，那么毫无疑问，通过该奴隶取得的用益权仍然保留。

<a id="7.4.5.2"></a>

**2.** 通说认为，物的性质发生变更，用益权即告消灭。例如，我受遗赠一幢房屋的用益权，而房屋倒塌或被烧毁；在这种情况下，用益权无疑消灭。至于用益权是否及于房屋所在的地块，答案则十分确定：房屋烧毁后，对地块和砖石等建筑材料均不发生用益权。尤利安也持此见。

<a id="7.4.5.3"></a>

**3.** 如果遗赠的是某地块的用益权，而该地块上后来建起建筑物，物的性质即发生变化，用益权也就消灭。显然，如果这是所有权人所为，他将依遗嘱之诉或恶意欺诈之诉承担责任；

### <a id="7.4.6"></a>7.4.6　庞波尼乌斯《评萨宾》第五卷

（而且，用益权人也可以提起因暴力或秘密侵占而设的禁令程序〔*interdictum quod vi aut clam*〕。）

### <a id="7.4.7"></a>7.4.7　尤利安《学说汇纂》第三十五卷

除非在拆除建筑物后，地块的用益权已让与我；显然，须待用益权消灭所依据的期间届满。〔译者说明：原文为省略式，*cesserit* 的主语未明，此处依建筑物拆除后地块用益权转归的语境翻译。〕

### <a id="7.4.8"></a>7.4.8　乌尔比安《评萨宾》第十七卷

如果遗赠的是土地的用益权，而土地上的乡间别墅被毁，用益权并不消灭，因为别墅是土地的附属物；树木倒下时也不消灭。

### <a id="7.4.9"></a>7.4.9　保罗《评萨宾》第三卷

而且，我也可以使用和享用乡间别墅原先所在的那块土地。

### <a id="7.4.10"></a>7.4.10　乌尔比安《评萨宾》第十七卷

<a id="7.4.10.pr."></a>

**序言（pr.）** 但是，如果土地原本是乡间别墅的附属物，又该如何？我们应当考察，土地的用益权是否也会消灭。对此也应作同样回答：用益权并不消灭。

<a id="7.4.10.1"></a>

**1.** 不仅在房屋被夷为平地时用益权会消灭；即使遗嘱人拆除房屋后又重建了新房，用益权也会消灭。显然，如果只是分部分修缮，即使所有部分最终都是新建的，也应另作判断。

<a id="7.4.10.2"></a>

**2.** 如果遗赠的是田地或某处场所的用益权，而该地被水淹没，以致成为池塘或沼泽，用益权无疑消灭。

<a id="7.4.10.3"></a>

**3.** 但是，如果遗赠的是池塘的用益权，而池塘干涸至成为田地，则因物的性质改变，用益权消灭。

<a id="7.4.10.4"></a>

**4.** 不过，如果遗赠的是耕地的用益权，而土地上种植了葡萄，或反过来由葡萄园变为耕地，我认为用益权并不消灭。确实，如果遗赠的是森林的用益权，而森林被砍伐后在那里种上作物，用益权无疑消灭。

<a id="7.4.10.5"></a>

**5.** 如果遗赠的是料块的用益权，而料块被制成器皿，或反过来由器皿变成料块，卡西乌斯在乌尔塞乌斯的著作中写道，用益权消灭；我认为这一意见正确。

<a id="7.4.10.6"></a>

**6.** 装饰物被拆解或改造成其他形态，也会使用益权消灭。

<a id="7.4.10.7"></a>

**7.** 关于船舶的用益权，萨宾写道：如果船舶只是分部分修缮，用益权不消灭；如果船舶被拆解，即使只用原来的木板、未添加其他材料将其重建，用益权也已消灭。我认为后一意见更为妥当，因为即使房屋重建，用益权也会消灭。

<a id="7.4.10.8"></a>

**8.** 如果遗赠的是四马战车的使用权，其中一匹马死亡，是否导致用益权消灭？我认为，关键在于遗赠的是对马匹的用益权，还是对四马战车的用益权：如果是对马匹的用益权，剩余马匹仍可享有用益权；如果是对四马战车的用益权，用益权便不再保留，因为四马战车已经不复存在：

### <a id="7.4.11"></a>7.4.11　保罗《评萨宾》第三卷

除非在遗赠权利确定时点之前，已有另一匹马被替换进来。

### <a id="7.4.12"></a>7.4.12　乌尔比安《评萨宾》第十七卷

<a id="7.4.12.pr."></a>

**序言（pr.）** 如果某人受遗赠浴场的用益权，而立遗嘱人将浴场改作住所；或者受遗赠的是商铺的用益权，而立遗嘱人将其改成餐室，应当认为用益权已经消灭。

<a id="7.4.12.1"></a>

**1.** 同样，如果某演员奴隶的用益权被遗赠给某人，而该奴隶被调去从事另一种劳务，也应当认为用益权消灭。

### <a id="7.4.13"></a>7.4.13　保罗《评萨宾》第三卷

如果用益权人已经收割庄稼后死亡，拉贝奥说，留在收割处的秸秆归其继承人所有；仍附着于土地的谷穗则归土地所有人所有。收益是在谷穗被收割、干草被割下、葡萄被摘下或橄榄被摇落时取得的，尽管谷物尚未脱粒、橄榄油尚未榨成、葡萄尚未采收酿制。尤利安说，拉贝奥关于摇落橄榄的说法是正确的；但对于自行落下的橄榄，应另作处理：用益权人的收益须待其实际取得时才归其所有，而善意占有人的收益则自其与土地分离时即归其所有。

### <a id="7.4.14"></a>7.4.14　庞波尼乌斯《评萨宾》第五卷

除身份减等或死亡外，其他原因均可能导致用益权部分消灭。

### <a id="7.4.15"></a>7.4.15　乌尔比安《评萨宾》第十八卷

有时，所有权人会将奴隶释放为自由人；例如，用益权遗赠至奴隶获释时为止。在所有权人开始释奴时，用益权即告消灭。

### <a id="7.4.16"></a>7.4.16　乌尔比安《论辩集》第五卷

如果用益权附条件遗赠给我，而在条件尚未成就期间由继承人享有，继承人可以将用益权遗赠给他人。因此，如果我所受遗赠的条件成就，继承人另行遗赠的用益权就会终止。反之，如果我丧失了用益权，它也不会回复给继承人曾无条件遗赠用益权的受遗赠人，因为增益权不适用于不同遗嘱所设立的权利。

### <a id="7.4.17"></a>7.4.17　尤利安《学说汇纂》第三十五卷

如果土地的用益权无条件遗赠给你，而所有权附条件遗赠给提提乌斯，那么在条件尚未成就时，你取得了所有权；此后条件成就，提提乌斯将完整享有该土地的所有权。所有权虽是扣除用益权后遗赠的，也不影响这一结论：因为你取得所有权时，已经丧失了基于用益权遗赠而享有的一切权利。

### <a id="7.4.18"></a>7.4.18　庞波尼乌斯《评萨宾》第三卷

如果用益权在遗产被接受之前遗赠给遗产中的奴隶，较为妥当的意见是：遗产一经接受，该用益权就转归你，而非因所有权变更而消灭；因为在你成为继承人之前，遗赠权利确定时点尚未到来。

### <a id="7.4.19"></a>7.4.19　盖尤斯《评行省告示》第七卷

用益权，以及步行通行权（*iter*）或驱赶牲畜通行权（*actus*），均不因所有权变更而消灭。

### <a id="7.4.20"></a>7.4.20　保罗《评普劳提乌斯》第十五卷

享有用益权的人如果只使用该物，是因为他以为自己只有使用权，那么他是否仍保有用益权？如果他明知自己享有用益权，却只想使用该物，那么仍应认为他也在享受其收益。如果他并不知道自己享有用益权，我认为他会丧失收益权；因为他行使的不是自己实际享有的权利，而是自己以为享有的权利。

### <a id="7.4.21"></a>7.4.21　莫德斯蒂努斯《法律区别》第三卷

如果用益权遗赠给一座城市，而犁铧在其城址上犁过，城市便不复存在，如迦太基所遭遇的那样；因此，该城市如同死亡一般，不再享有用益权。

### <a id="7.4.22"></a>7.4.22　庞波尼乌斯《评昆图斯·穆基乌斯》第六卷

如果房屋使用权遗赠给一名妇女，而她出海远行，在足以因不使用而丧失使用权的期间内一直不在家，但其丈夫使用了这所房屋，则使用权仍然保留；这如同她将家内人留在家中而本人出外旅行一样。若丈夫将妻子留在家中，而房屋使用权是遗赠给丈夫本人的，更应如此认定。

### <a id="7.4.23"></a>7.4.23　庞波尼乌斯《评昆图斯·穆基乌斯》第二十六卷

如果我们的用益权所及土地被河水或海水淹没，用益权即告丧失，因为在这种情形下，土地所有权本身也会丧失；甚至不能通过捕鱼保留用益权。但是，正如水以同样的力量退去后，所有权会恢复，用益权也应恢复。

### <a id="7.4.24"></a>7.4.24　雅沃勒努斯《拉贝奥后编》（*ex posterioribus Labeonis*）第三卷

<a id="7.4.24.pr."></a>

**序言（pr.）** 我享有一处花园的用益权时，河水淹没了花园，后来又退去。拉贝奥认为，用益权也应恢复，因为该土地始终保持着相同的法律属性。我认为，若河水只是因泛滥而淹没花园，此说正确；如果河道改变后开始从那里流过，我认为用益权就会丧失，因为该地已成为公有河床，不能恢复到先前的状态。

<a id="7.4.24.1"></a>

**1.** 拉贝奥说，对于通行权和驱赶权，也应遵守相同的规则；我认为这些权利应与使用权及用益权作同样处理。

<a id="7.4.24.2"></a>

**2.** 拉贝奥说：即使从我的土地上移走了表层土，又在其上填入其他土壤，我的土地也不会因此不再属于我；这与给农田施肥并无不同。

### <a id="7.4.25"></a>7.4.25　庞波尼乌斯《异文集》（*Ex variis lectionibus*）第十一卷

通说认为，无论用益权针对某一特定部分，还是针对未分割的份额，均可能因不行使而消灭。

### <a id="7.4.26"></a>7.4.26　保罗《评涅拉提乌斯》第一卷

如果土地被敌人占领，或奴隶被俘后获释，用益权将依复归权（*postliminium*）恢复。

### <a id="7.4.27"></a>7.4.27　保罗《手册》第一卷

如果所有权人为承担致害责任而将一名他人享有用益权的奴隶交付给用益权人（*noxae deditio*），则该用益权因与所有权混同而消灭。〔句义待核：*liberabitur confusa servitute proprietatis comparatione* 涉及交付后所有权与用益权归并的法律效果，暂按“混同”理解。〕

### <a id="7.4.28"></a>7.4.28　保罗《评普劳提乌斯》第十三卷

如果用益权按隔年方式遗赠，就不能因不行使而使其消灭，因为这实际上包含数项遗赠。

### <a id="7.4.29"></a>7.4.29　乌尔比安《评萨宾》第十七卷

<a id="7.4.29.pr."></a>

**序言（pr.）** 庞波尼乌斯提出：如果所有权人向我承租一块土地，随后未扣除用益权就将该土地卖给塞伊乌斯，我能否通过买受人保有用益权？他说，即使所有权人向我支付租金，用益权仍会消灭，因为买受人享用该土地是以自己的名义，而不是以我的名义；不过，所有权人应依租赁之诉向我承担责任，赔偿此事使我遭受的利益损失。虽然，如果有人将自己从我处承租的用益权再出租给他人，用益权仍会保留；但如果所有权人以自己的名义将其出租，就应认为用益权消灭，因为承租人并非以我的名义享用该物。

<a id="7.4.29.1"></a>

**1.** 如果所有权人出卖了其从我处买得的用益权，我是否会丧失用益权？对此应当考察。我认为用益权会消灭，因为在这种情形下，土地买受人同样不是作为从我处买得用益权的人而享用该土地。

<a id="7.4.29.2"></a>

**2.** 同一庞波尼乌斯还提出：如果用益权遗赠给我，而我受嘱托将其返还给你，是否应认为我通过你享用用益权，从而用益权不会消灭？他说对此问题有所疑虑。不过，马尔凯卢斯所指出的意见更为妥当：此事不会损害遗嘱信托受益人，因为他将以自己的名义享有准用之诉。

### <a id="7.4.30"></a>7.4.30　盖尤斯《评行省告示》第七卷

死去牲畜的肉和皮并非孳息，因为牲畜死亡时，其用益权即告消灭。

### <a id="7.4.31"></a>7.4.31　庞波尼乌斯《评昆图斯·穆基乌斯》第四卷

遗赠的是畜群的用益权，而畜群数量减少到已不能称为畜群时，用益权即告消灭。
