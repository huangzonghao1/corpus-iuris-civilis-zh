## 7.3.0　论遗赠用益权起算日（*Quando dies usus fructus legati cedat*）

### <a id="7.3.1"></a>7.3.1　乌尔比安《评萨比努斯》第十七卷

<a id="7.3.1.pr."></a>

**序言（pr.）** 虽然用益权以享用为内容，也就是说，以享用人实施某种行为为内容，但遗赠权利确定的时点（*dies cedit*）仍只届至一次。这不同于按月、按日或按年逐期遗赠某物的情形：在那种情况下，遗赠权利分别于每一日、每一月或每一年届至。因此可以提出这样的问题：如果用益权按日或按年遗赠给某人，其权利确定时点是否一次届至？我认为并非一次全部届至，而是随着各期间届至，仿佛存在数项遗赠。马尔凯卢斯在《学说汇纂》第四卷中就隔日遗赠用益权的情形赞同此说。

<a id="7.3.1.1"></a>

**1.** 因此，即使遗赠的孳息无法每日取得，该遗赠也并非无效；遗赠的范围应是可以享用该孳息的那些日子。

<a id="7.3.1.2"></a>

**2.** 用益权以及使用权的权利确定时点，须待继承人接受遗产后才届至；因为只有在某人能够使用、享用时，用益权才告设立。因此，如果用益权遗赠给遗产中的奴隶，尤利安写道，虽然其他遗赠均归遗产取得，但就用益权而言，仍须等待所有人的身份确定，因为必须有一个能够使用、享用的人。

<a id="7.3.1.3"></a>

**3.** 同样，如果用益权附始期遗赠，在该始期届至之前，其权利确定时点尚未届至；可以肯定，用益权既可以附始期遗赠，也可以附终期遗赠。

<a id="7.3.1.4"></a>

**4.** 不仅在继承人接受遗产之前，用益权的权利确定时点尚未届至；关于用益权的诉权也尚未发生。用益权附始期遗赠的，也适用同一规则。最后，斯凯沃拉说，在用益权始期届至之前提起诉讼的人，其诉讼行为不产生任何效力；尽管通常而言，任何人在期限届至之前起诉，均属不当起诉。
