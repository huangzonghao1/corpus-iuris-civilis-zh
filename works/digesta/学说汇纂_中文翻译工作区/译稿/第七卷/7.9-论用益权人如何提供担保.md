# D.7.9　论用益权人如何提供担保（*Usufructuarius quemadmodum caveat*）

> 底本：*Digesta Iustiniani*，EPUB book-07.xhtml，source-p 658–713。

<!-- source-p 658 -->
<a id="9"></a><a id="7.9"></a>**7.9.0**　论用益权人如何提供担保。

<!-- source-p 659 -->
<a id="7.9.1"></a>**7.9.1**

<!-- source-p 660 -->
乌尔比安《告示评注》第七十九卷。

<!-- source-p 661 -->
<a id="7.9.1.pr."></a>**序言**　若某物的用益权已被遗赠，裁判官认为，要求受遗赠人就两方面提供担保最为公平：一是其将依善良人的判断行使用益权；二是当用益权不再归其享有时，将届时尚存之物返还。

<!-- source-p 662 -->
<a id="7.9.1.1"></a>**1**　无论标的是动产还是土地上的物，都应订立此项要式口约，

<!-- source-p 663 -->
<a id="7.9.1.2"></a>**2**　应当知道，此项担保也应适用于遗嘱信托。显然，若用益权是通过因死亡赠与设立的，也应仿照遗赠提供此项担保；若用益权是基于其他任何原因设立，也应作相同处理。

<!-- source-p 664 -->
<a id="7.9.1.3"></a>**3**　受担保人还应承诺，取得用益权时将依善良人的判断行事；也就是说，不会使用益权所涉物的状况恶化，并会像对待自己的物那样妥善处理其他事项。

<!-- source-p 665 -->
<a id="7.9.1.4"></a>**4**　继承人与受遗赠人最好在受遗赠人开始享有用益权时，把标的物的状况记录下来；这样便能据此判断受遗赠人是否使标的物恶化，以及恶化到何种程度。

<!-- source-p 666 -->
<a id="7.9.1.5"></a>**5**　认为以要式口约担保此事项是有用的：若某人未依善良人的判断行使用益权，要式口约即刻发生效力，无须等到其用益权被剥夺。

<!-- source-p 667 -->
<a id="7.9.1.6"></a>**6**　此项要式口约包含两个事由：一是某人未依善良人的判断行事；二是用益权终止时返还标的物。前一事由一旦发生，即刻触发担保责任，而且每次发生都会再次触发；后一事由则在用益权终止时触发。

<!-- source-p 668 -->
<a id="7.9.1.7"></a>**7**　但我们说要返还“届时尚存之物”，并非所有权人通过要式口约请求返还物本身（因为这似乎是无益地请求自己的物），而是请求返还届时尚存之物。有时，担保还会涉及所有权价值，例如用益权人本可中断他人对标的物的取得时效，却疏于处理。因为他承接了对该物的全部照管责任。

<!-- source-p 669 -->
<a id="7.9.2"></a>**7.9.2**

<!-- source-p 670 -->
保罗《告示评注》第七十五卷。

<!-- source-p 671 -->
用益权人应当承担保管责任。

<!-- source-p 672 -->
<a id="7.9.3"></a>**7.9.3**

<!-- source-p 673 -->
乌尔比安《告示评注》第七十九卷。

<!-- source-p 674 -->
<a id="7.9.3.pr."></a>**序言**　本项要式口约涵盖所有导致用益权丧失的情形。

<!-- source-p 675 -->
<a id="7.9.3.1"></a>**1**　所谓用益权“不再归其享有”，也包括用益权虽被遗赠、却从未开始归其享有的情形；即使它从未开始，也仍视为后来终止，担保照样触发。

<!-- source-p 676 -->
<a id="7.9.3.2"></a>**2**　若用益权被再次遗赠，那么每次用益权丧失时，除非担保已作了有利于受担保人的特别安排，此项要式口约都会触发；但届时需要提出抗辩。

<!-- source-p 677 -->
<a id="7.9.3.3"></a>**3**　若有人把用益权遗赠给你，并附条件把所有权遗赠给你——条件是“如果你生有子女”——那么用益权丧失时要式口约虽会触发，但可以提出抗辩。

<!-- source-p 678 -->
<a id="7.9.3.4"></a>**4**　若继承人出售所有权，之后用益权又丧失，我们应当考察是否可以提起要式口约之诉。较有力的意见是，要式口约依法律本身并未触发，因为标的物既不能返还给继承人或其继受人，也不再属于有权请求返还的人，即取得所有权的人。取得所有权的人应在取得之时另行要求提供担保；即使他没有这样做，也仍然可以提起对物之诉。

<!-- source-p 679 -->
<a id="7.9.4"></a>**7.9.4**

<!-- source-p 680 -->
维诺尼乌斯《要式口约论》第十二卷。

<!-- source-p 681 -->
若用益权人取得了所有权，用益权因权利混同而终止。但若他因要式口约而被起诉，应当认为：若“依善良人的判断行事”的约定涵盖这种情形，则诉讼依法律本身无效；否则，他应以基于事实的抗辩应诉。

<!-- source-p 682 -->
<a id="7.9.5"></a>**7.9.5**

<!-- source-p 683 -->
乌尔比安《告示评注》第七十九卷。

<!-- source-p 684 -->
<a id="7.9.5.pr."></a>**序言**　此项要式口约中包含“并且将不实施恶意”的承诺。既然恶意条款是以对物方式订立的，似乎也涵盖所有继承人以及自权收养人的恶意行为。

<!-- source-p 685 -->
<a id="7.9.5.1"></a>**1**　若遗赠的仅是使用权而不含收益权，裁判官命令提供担保时，应扣除收益这一项。这是合理的，因为此时应对单纯使用提供担保，而非对收益提供担保。

<!-- source-p 686 -->
<a id="7.9.5.2"></a>**2**　因此，即使收益权而非使用权被遗赠，此项要式口约也适用。

<!-- source-p 687 -->
<a id="7.9.5.3"></a>**3**　若遗赠的是居住权、人的劳务，或其他动物的劳务，此项要式口约也适用，尽管这些权利并非在所有方面都与用益权相同。

<a id="7.9.6"></a>**7.9.6**

<!-- source-p 689 -->
保罗《告示评注》第七十五卷。

同一规则也适用于土地的收益，例如遗赠了葡萄收成或谷物收成的情形。尽管这些收益是通过用益权取得的，但如果受遗赠人死亡，已经遗赠的收益仍归其继承人。

<a id="7.9.7"></a>**7.9.7**

<!-- source-p 693 -->
<a id="7.9.7.pr."></a>**序言**　若某物以用益权名义交付，却没有提供担保，普罗库鲁斯说，继承人可以请求返还该物；若对方提出“该物是以用益权名义交付”的抗辩，则应提出再抗辩。此说有其道理；而且也可以基于要式口约提起返还之诉。

<!-- source-p 694 -->
<a id="7.9.7.1"></a>**1**　若钱款的用益权被遗赠，要式口约中应明确列入以下两个情形：“你死亡或发生人格减等时，应当返还。”之所以只列这两种情形，是因为钱款的用益权只能在这两种情形下丧失。

<!-- source-p 695 -->
<a id="7.9.8"></a>**7.9.8**

<!-- source-p 696 -->
保罗《告示评注》第七十五卷。

<!-- source-p 697 -->
若用益权遗赠给你，而所有权遗赠给我，应由我要求提供担保。但若所有权附条件遗赠给我，有些法学家以及马尔基安努斯认为，应当同时向继承人和我提供担保；此说正确。同样，若所有权先遗赠给我，并规定用益权不再归我享有时应转归他人，那么依上文规则，也应向双方提供担保。若用益权以共同遗赠方式给两人，两人之间也应相互提供担保，并向继承人提供担保，以应对以下情形：“若用益权不归共同受遗赠人享有，应返还继承人。”

<!-- source-p 698 -->
<a id="7.9.9"></a>**7.9.9**

<!-- source-p 699 -->
乌尔比安《告示评注》第五十一卷。

<!-- source-p 700 -->
<a id="7.9.9.pr."></a>**序言**　若用益权遗赠给我，同时又被要求以遗嘱信托方式转交提图斯，应当考察由谁提供担保：是提图斯，还是我这个受遗赠人？或者是否应当说，继承人起诉我时，我还应当起诉遗嘱信托受益人？较便捷的处理方法是：若我仍有某种希望，即在你丧失用益权后，用益权可能回到我这个受遗赠人处，那么事情应当这样处理：你向我提供担保，我再向所有权人提供担保。若用益权遗赠给我是为了遗嘱信托受益人的利益，而用益权没有任何可能回到我处，那么应由遗嘱信托受益人直接向所有权人提供担保。

<!-- source-p 701 -->
<a id="7.9.9.1"></a>**1**　应当知道，无论某人依法律本身享有用益权，还是仅受裁判官保护而享有用益权，用益权人仍必须提供担保，或者承担相应诉讼。

<!-- source-p 702 -->
<a id="7.9.9.2"></a>**2**　不过，若所有权遗赠给某人并自某日起生效，而用益权则无条件遗赠，庞波尼乌斯说，应免除用益权人的担保义务，因为可以确定所有权最终会归其本人或其继承人。

<!-- source-p 703 -->
<a id="7.9.9.3"></a>**3**　庞波尼乌斯写道，若衣物的用益权被遗赠，尽管继承人已通过要式口约约定用益权终止时返还衣物，但允诺人若在没有恶意的情况下返还了因使用而磨损的衣物，仍不负责任。

<!-- source-p 704 -->
<a id="7.9.9.4"></a>**4**　若所有权属于数人，每一人只能就其自己的份额提出要式口约。
