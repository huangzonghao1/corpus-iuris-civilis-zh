## 7.2.0　论用益权的增益（*De usu fructu adcrescendo*）

### <a id="7.2.1"></a>7.2.1　乌尔比安《评萨比努斯》第十七卷

<a id="7.2.1.pr."></a>

**序言（pr.）** 每当用益权被遗赠时，只有在用益权系共同遗赠的情形下，各用益权人之间才有增益权；如果用益权分别遗赠给各人对物的份额，则毫无疑问不发生增益权。

<a id="7.2.1.1"></a>

**1.** 尤利安在《学说汇纂》第三十五卷中讨论：如果用益权遗赠给共有奴隶，且由两名所有人取得，那么一名所有人放弃或丧失用益权后，另一名是否取得全部用益权？尤利安认为，用益权归另一名所有人。尽管两名所有人取得用益权的份额并不相等，而是依其所有权份额确定，但增益是基于个人而非所有人身份加以考察，因此用益权归另一名所有人，而不归并于所有权。

<a id="7.2.1.2"></a>

**2.** 尤利安还说，如果用益权遗赠给共有奴隶，同时又分别遗赠给提提乌斯，那么共有者之一丧失用益权后，该份额不应归于提提乌斯，而应仅归于另一共有者，仿佛用益权只共同遗赠给共有者。此说正确：只要仍有一人行使用益权，就可以说用益权保持原有状态。两人共同受遗赠用益权、另有一人单独受遗赠的，也适用同一规则。

<a id="7.2.1.3"></a>

**3.** 有时，即使受遗赠人并非共同受遗赠，用益权仍会增益给另一人。例如，我和你分别受遗赠整块土地的用益权。正如塞尔苏斯在《学说汇纂》第十八卷、尤利安在第三十五卷所写，由于受遗赠相互竞合，我们取得相应份额；所有权也会发生同样情形：一人放弃后，另一人将取得整块土地。但用益权还有一点不同：即使一项用益权已经设立、后来又丧失，仍可发生增益权。因为普劳提乌斯著作中所引诸作者对此均有共识；正如塞尔苏斯和尤利安精辟地指出，用益权是每日持续设立并发生遗赠效力的，不像所有权只在请求返还的那个时点发生效力。因此，只要另一方不再有与其用益权相竞合之人，他便独自享有全部用益权；无论用益权系共同遗赠还是分别遗赠，均无区别。

<a id="7.2.1.4"></a>

**4.** 尤利安在《学说汇纂》第三十五卷中还写道：如果遗嘱指定两名继承人，并在扣除用益权后将所有权遗赠出去，继承人没有增益权；因为此时应视为用益权已经设立，而非因受遗赠相互竞合而分割：

### <a id="7.2.2"></a>7.2.2　阿非利卡努斯《疑义》第五卷

因此，用益权的一部分消灭后，将归还给同一受遗赠人兼所有权人。

### <a id="7.2.3"></a>7.2.3　乌尔比安《评萨比努斯》第十七卷

<a id="7.2.3.pr."></a>

**序言（pr.）** 涅拉提乌斯在《答复》第一卷中也认为，不发生增益权。塞尔苏斯所说的理由与此相符：只有在原本各自享有完整权利的两人之间，因权利相互竞合而发生份额分割时，才有增益权。

<a id="7.2.3.1"></a>

**1.** 因此，塞尔苏斯在《学说汇纂》第十八卷中写道：如果两名土地所有人扣除用益权后转让所有权，其中一人丧失用益权，用益权虽回复于所有权，却并非回复给整体所有权，而是各自归并于该所有人所转让的那部分；因为用益权应回复至其最初从中分离出来的部分。

<a id="7.2.3.2"></a>

**2.** 增益权不仅发生在用益权遗赠给两人的情形；如果一人受遗赠用益权、另一人受遗赠土地，也会发生增益权。用益权受遗赠人丧失用益权时，该份额更应基于增益权归另一人，而非回复于所有权。此规则并不新奇：即使用益权遗赠给两人，而其中一人的用益权归并于其所有权，增益权也不会因此消失；无论归并给谁，也不会使其丧失增益权；此人仍按归并前相同的方式丧失用益权。涅拉提乌斯和阿里斯托也持此意见，庞波尼乌斯赞同。

### <a id="7.2.4"></a>7.2.4　尤利安《学说汇纂》第三十五卷

如果土地所有权遗赠给你，而同一土地的用益权遗赠给我、梅维乌斯和你，那么我与梅维乌斯各享有三分之一的用益权，另一个三分之一则归并于你的所有权。无论我还是梅维乌斯发生身份减等（*capitis deminutio*），该三分之一都将在你与我们另一人之间分配；未发生身份减等的一方将享有二分之一的用益权，而你则取得所有权及其附随的二分之一用益权：

### <a id="7.2.5"></a>7.2.5　盖尤斯《评行省告示》第七卷

即使你在扣除用益权后转让所有权，尤利安仍认为用益权会发生增益；而且不应视为你因此新取得了用益权。

### <a id="7.2.6"></a>7.2.6　乌尔比安《评萨比努斯》第十七卷

<a id="7.2.6.pr."></a>

**序言（pr.）** 如果用益权归并于三名用益权人中的一人，也适用同一规则。

<a id="7.2.6.1"></a>

**1.** 如果所有权在扣除用益权后遗赠给一人，而用益权的一部分遗赠给我，则应考察我与继承人之间是否发生增益权。正确的意见是：无论谁丧失该份额，该份额均回复于所有权。

<a id="7.2.6.2"></a>

**2.** 如果土地的用益权无条件遗赠给我，而附条件遗赠给你，可以认为，在条件成就前，整块土地的用益权均归我享有；若我发生身份减等，就会丧失全部用益权。但如果条件成就，而我已发生身份减等，全部用益权便归你；反之，如果我的身份状态未变，用益权应由我们共同享有。

### <a id="7.2.7"></a>7.2.7　保罗《评萨比努斯》第三卷

如果某人将用益权遗赠给阿提乌斯及其继承人，阿提乌斯与继承人各享有二分之一。如果遗嘱写作“遗赠给阿提乌斯和塞伊乌斯，并与我的继承人共同享有”，则应分为三份：继承人取得一份，阿提乌斯和塞伊乌斯各取得一份。无论写作“遗赠给某某等人，并与梅维乌斯共同享有”，还是写作“遗赠给某某等人及梅维乌斯”，均无区别。

### <a id="7.2.8"></a>7.2.8　乌尔比安《评萨比努斯》第十七卷

如果用益权遗赠给一名妇女及其子女，子女丧失其用益权份额后，该妇女即享有该用益权；母亲死亡后，子女也仍基于增益权享有用益权。尤利安在《学说汇纂》第三十卷中说，即使遗嘱人只将子女指定为继承人，而未将他们称作受遗赠人，也应作相同理解；遗嘱人这样写，是要表明其更愿意让母亲与子女共同享有用益权。庞波尼乌斯还提出：如果子女与遗嘱外的其他人一同被指定为继承人，情况如何？他认为，子女应被视为用益权受遗赠人。反过来说，如果遗嘱人希望子女与母亲共同享有用益权，则应认为母亲是受遗赠人；在此情形中，法律效果的各方面也都与前述情形相同。

### <a id="7.2.9"></a>7.2.9　阿非利卡努斯《疑义》第五卷

如果土地所有权遗赠给两人，而用益权遗赠给一人，则用益权并非分为三份；两名所有权受遗赠人合计享有二分之一，用益权受遗赠人享有二分之一。反过来，如果用益权遗赠给两人，而土地遗赠给一人，也同样处理。

### <a id="7.2.10"></a>7.2.10　乌尔比安《评告示》第十七卷

有时，用益权的一部分会增益给原本并未享有该部分之人，而非归于所有权。例如，用益权遗赠给两人，其中一人在诉讼成立后丧失用益权，随后未参加该诉讼的共同受遗赠人也丧失用益权；此时，对主动应诉之人提起诉讼者，只能从占有人处取得前一人所丧失的二分之一。共同受遗赠人的份额增益给其本人，而不归于所有权人；因为用益权是基于受益人的个人身份而增益，即使该用益权已经丧失，也仍如此。〔本段第二位共同受遗赠人丧失用益权后，份额增益的具体程序关系较压缩，译文依后句处理。〕

### <a id="7.2.11"></a>7.2.11　帕比尼安《定义》第二卷

如果各继承人分别将同一物的用益权遗赠给各自的受遗赠人，这些用益权人应视为彼此分离；其情形不亚于同一物的用益权按相等份额遗赠给两人。因此，他们之间不发生增益权，

### <a id="7.2.12"></a>7.2.12　乌尔比安《评萨比努斯》第十七卷

因为各人是分别向不同继承人请求返还用益权的。
