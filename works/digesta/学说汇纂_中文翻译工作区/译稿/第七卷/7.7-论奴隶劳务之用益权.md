## <a id="7"></a><a id="7.7"></a>7.7　论奴隶劳务

*De operis servorum*

### <a id="7.7.1"></a>7.7.1　保罗《评告示》第二卷

劳务存在于具体行为之中；在应当提供劳务的日期到来之前，劳务尚未成为现实。这如同我们约定取得“阿瑞图萨所生之物”一样。

### <a id="7.7.2"></a>7.7.2　乌尔比安《评告示》第十七卷

奴隶劳务的遗赠，不因身份减等而消灭。

### <a id="7.7.3"></a>7.7.3　盖尤斯《评行省告示》第七卷

人的用益权包含其劳务，也包含因劳务取得的报酬。

### <a id="7.7.4"></a>7.7.4　盖尤斯《论自由权诉讼（针对城市告示）》第二卷（*De liberali contra edictum urbicum*）

人的收益在于其劳务；反过来说，劳务也是人的收益。正如其他物的收益应扣除必要费用后计算，奴隶劳务的收益也应如此计算。

### <a id="7.7.5"></a>7.7.5　特伦提乌斯·克莱孟斯《评尤利亚法与帕庇亚法》第十八卷

奴隶劳务被遗赠时，应视为同时授予了对该奴隶的使用权；我也这样理解，尤利安亦持此见。

### <a id="7.7.6"></a>7.7.6　乌尔比安《评告示》第五十五卷

<a id="7.7.6.pr."></a>

**序言（pr.）** 如果争议涉及技艺奴隶的劳务，应按照其技艺程度计价；普通劳役奴隶则按照其所提供的劳役计价。梅拉也如此写道。

<a id="7.7.6.1"></a>

**1.** 如果奴隶未满五岁、身体羸弱，或有其他情形致其不可能在主人处提供任何劳务，则不作任何估价。

<a id="7.7.6.2"></a>

**2.** 对于娱乐或感情方面的价值，也不予估价；例如，所有人喜爱该奴隶，或将他当作宠儿。

<a id="7.7.6.3"></a>

**3.** 其他情形则应在扣除必要费用后估价。
