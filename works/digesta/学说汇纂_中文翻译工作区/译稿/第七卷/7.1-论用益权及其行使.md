## <a id="7.1"></a>7.1　论用益权及其使用、收益方式

*De usu fructu et quemadmodum quis utatur fruatur*

### <a id="7.1.1"></a>7.1.1　保罗《评维特利乌斯》第三卷

用益权是指在不损害物之本质的前提下，使用他人之物并从中取得收益的权利。

### <a id="7.1.2"></a>7.1.2　凯尔苏斯《学说汇纂》第十八卷

用益权是存在于有体物上的一项权利；有体物灭失，用益权也必然随之消灭。

### <a id="7.1.3"></a>7.1.3　盖尤斯《日常法学概要》（又称《金言集》）第二卷

<a id="7.1.3.pr."></a>

**序言（pr.）** 任何土地均可通过遗赠设立用益权，例如命令继承人向某人授予用益权。所谓授予，是指允许受遗赠人进入土地，或容许其使用并收益。即使没有遗嘱，某人若想设立用益权，也可以通过协议和要式口约实现。

<a id="7.1.3.1"></a>

**1.** 用益权不仅可以设立于土地和房屋，也可以设立于奴隶、役畜及其他物上。

<a id="7.1.3.2"></a>

**2.** 为避免所有权因用益权始终存续而变得全无用处，通说认为，用益权应在若干特定情形下消灭并回复于所有权。

<a id="7.1.3.3"></a>

**3.** 用益权得以设立并消灭的方式，同样适用于单纯使用权的设立和消灭。

### <a id="7.1.4"></a>7.1.4　保罗《评告示》第二卷

在许多情形下，用益权是所有权的一部分；而且，用益权既可立即设立，也可自某一日期起设立。

### <a id="7.1.5"></a>7.1.5　帕比尼安《法律问题》第七卷

用益权自始可以按不可分份额或可分份额设立，也可以经过法定期间而以相同方式消灭；并且可依《法尔基第法》按同一比例减少。如果负有承诺义务的人死亡，用益权债务即按继承份额分割；如果用益权由共有土地负担，一名共有人提供担保并应诉的，返还应按该名应诉共有人的份额进行。

### <a id="7.1.6"></a>7.1.6　盖尤斯《评行省告示》第七卷

<a id="7.1.6.pr."></a>

**序言（pr.）** 用益权可以通过多种方式设立，例如以遗赠设立。也可以将扣除用益权后的所有权遗赠，使用益权留在继承人手中。

<a id="7.1.6.1"></a>

**1.** 用益权也可以在遗产分割诉讼或共有物分割诉讼中设立：法官可以将所有权判归一人，而将用益权判归另一人。

<a id="7.1.6.2"></a>

**2.** 我们取得用益权，不仅可以由自己取得，也可以通过受我们权力支配的人取得。

<a id="7.1.6.3"></a>

**3.** 将所有权扣除用益权后遗赠给被指定为继承人的我的奴隶，也不受禁止。

### <a id="7.1.7"></a>7.1.7　乌尔比安《评萨宾》第十七卷

<a id="7.1.7.pr."></a>

**序言（pr.）** 遗赠用益权时，该物的一切收益均归用益权人。遗赠的用益权可以针对不动产，也可以针对动产。

<a id="7.1.7.1"></a>

**1.** 如果遗赠的是土地，例如房屋的用益权，则一切收益均归用益权人，包括房屋、空地及其他属于房屋的部分所产生的收益。因此，通说也认为，可以为防范邻房可能造成的损害而准许用益权人占有邻房；若对方始终不提供担保，用益权人即可依所有权占有该房屋；用益权终止后，他也不会因此丧失任何权利。基于同一理由，拉贝奥写道：未经你同意，所有人不得加高房屋；正如遗赠空地的用益权后，也不得在该空地上建造房屋一样。我认为这一意见正确。

<a id="7.1.7.2"></a>

**2.** 既然该物的一切收益均归用益权人，凯尔苏斯在《学说汇纂》第十八卷中写道，可以通过仲裁程序强制其修缮房屋，但仅限于使房屋保持完好、屋顶不漏。如果房屋因年久失修而倒塌，则任何一方均不受强制修缮；但继承人修缮后，用益权人应获准使用。既然用益权人无须修缮年久倒塌之物，凯尔苏斯便讨论应如何理解保持房屋完好。他应承担适度的修缮费用，因为遗赠用益权时，他也须承担其他负担，例如土地税、贡赋、薪俸，或由该物提供的生活给养。马尔凯卢斯在《学说汇纂》第十三卷中也作此论述。

<a id="7.1.7.3"></a>

**3.** 卡西乌斯也在《市民法》第八卷中写道，可以通过仲裁程序强制用益权人修缮房屋，正如可以强制他扶植树木一样；阿里斯托也认定这确属正确。奈拉提乌斯则在《札记》第四卷中指出，不得禁止用益权人修缮房屋，因为也不得禁止他耕地或种植；他不仅可以实施必要的修缮，也可以为了美观而铺设墙面灰泥、地板及类似设施，但不得扩建，也不得拆除有益设施。

### <a id="7.1.8"></a>7.1.8　乌尔比安《评告示》第四十卷

即使他打算以更好的设施替代，也不得拆除；这一意见正确。

### <a id="7.1.9"></a>7.1.9　乌尔比安《评萨宾》第十七卷

<a id="7.1.9.pr."></a>

**序言（pr.）** 如果遗赠的是土地的用益权，那么土地上生长的一切，以及可以从土地取得的一切，均为用益权人的收益；但其使用和收益应符合善良家父的裁量。凯尔苏斯在《学说汇纂》第十八卷中写道，可以强制用益权人妥善耕种。

<a id="7.1.9.1"></a>

**1.** 如果土地上有蜜蜂，蜜蜂的用益权也归用益权人。

<a id="7.1.9.2"></a>

**2.** 如果土地上有采石场，而用益权人想开采石料，或者土地上有黏土矿或砂矿，萨宾认为，他可以像善良家父那样利用这些资源；我认为此意见正确。

<a id="7.1.9.3"></a>

**3.** 如果这些矿藏是在用益权遗赠之后才发现的，而遗赠对象是整片土地而非其中某部分，则这些矿藏也包含在遗赠之内。

<a id="7.1.9.4"></a>

**4.** 与此相关的是通常所说的土地增加物。通说认为，因冲积而增加的部分，其用益权也归用益权人。但是，如果河流中在土地旁形成一座岛屿，佩加苏斯写道，尽管该岛屿的所有权附加于土地所有权，其用益权仍不归用益权人；因为该岛屿仿佛是一块独立土地，其用益权并未授予你。此说不无道理：不易察觉的土地增加，会使用益权一并增加；但若增加部分明显独立，则不归用益权人。

<a id="7.1.9.5"></a>

**5.** 卡西乌斯在《市民法》第八卷中也说，捕鸟和狩猎所得归用益权人；捕鱼所得亦然。

<a id="7.1.9.6"></a>

**6.** 我认为，苗圃的收益也归用益权人；他可以出售苗木，也可以自行栽种。但为耕种土地而设置的苗圃，应由用益权人持续更新，视为土地的附属设施；用益权终止后，应将苗圃交还所有人。

<a id="7.1.9.7"></a>

**7.** 用益权人可以取得土地附属设施的收益，但不得出售其本身。假如遗赠的是土地的用益权，而家父过去惯常从某片土地上砍取木桩，用于其享有用益权的葡萄园，或者惯常使用柳木或芦苇，我认为，用益权人也可以如此使用，但不得出售这些材料；除非遗赠给他的是柳树林、供葡萄园搭架用的林地或芦苇荡的用益权，在此情形下，他也可以出售。特雷巴提乌斯写道，用益权人可以砍伐可周期采伐的树林和芦苇荡，正如家父过去所为，并且可以出售；即使家父过去并不出售而是自行使用，亦然。因为应当考察使用的方式，而非使用的具体类别。

### <a id="7.1.10"></a>7.1.10　庞波尼乌斯《评萨宾》第五卷

对于可周期采伐的树林，用益权人可以取用葡萄园支架和树枝；对于不可周期采伐的树林，他可以取材用于葡萄园，但不得使土地状况恶化。

### <a id="7.1.11"></a>7.1.11　保罗《阿尔费努斯〈学说汇纂〉摘要》第二卷

但如果是大树，则不得砍伐。

### <a id="7.1.12"></a>7.1.12　乌尔比安《评萨宾》第十七卷

<a id="7.1.12.pr."></a>

**序言（pr.）** 拉贝奥说，树木被连根拔起或被风吹倒时，用益权人可以将其用于自身需要及修缮宅院；如果另有木材可供使用，他不得将这些树木当作薪柴。我认为此说正确。否则，若整片土地都遭遇这种情形，用益权人便会把所有树木都取走。不过，他认为，用益权人可以砍伐木材，用于修缮宅院；正如拉贝奥所说，他也可以烧制石灰、挖取砂土，或取得其他建筑所需物。

<a id="7.1.12.1"></a>

**1.** 遗赠船舶用益权时，我认为用益权人可以驾船航行，即使有船舶失事的风险；因为船舶本来就是为航行而建造的。

<a id="7.1.12.2"></a>

**2.** 用益权人可以亲自使用该物，也可以允许他人使用、出租或出售用益权；因为出租者是在使用，出售者也同样是在使用。即使他将该物以可随时收回的方式交他人使用，或赠与他人，我也认为，他仍属于使用该物，因而保有用益权。卡西乌斯和佩加苏斯如此答复，庞波尼乌斯在《评萨宾》第五卷中也表示赞同。我出租用益权时当然保有用益权；即使他人替我处理事务并出租了用益权，尤利安在《学说汇纂》第三十五卷中也写道，我仍保有用益权。那么，如果我没有出租，而是有人在我不在场且不知情时替我处理事务并使用、收益该物，结果又如何？我仍保有用益权；庞波尼乌斯在《评萨宾》第五卷中也赞同此说，因为我因此取得了无因管理之诉权。

<a id="7.1.12.3"></a>

**3.** 庞波尼乌斯对下列情形有所疑问：如果一名我享有用益权的逃亡奴隶，就我的财产作出某种允诺，或者通过交付取得某物，我是否因而视为自己已经使用该物，从而保有用益权？较可取的意见是，我仍保有用益权。因为我们常常即使未实际使用在身边的奴隶，仍保有用益权；例如奴隶生病、年幼而无劳务能力，或因年老体衰而不能劳动时。即使我们耕种的土地十分贫瘠，不能产出任何收益，我们仍保有用益权。尤利安在《学说汇纂》第三十五卷中写道，即使逃亡奴隶没有作出任何允诺，用益权仍得保有；他说，正如所有人即使奴隶逃亡，仍保有对其占有，同理，用益权也仍得保有。

<a id="7.1.12.4"></a>

**4.** 他还讨论了另一问题：如果他人取得该奴隶的占有，用益权是否会像所有人失去占有那样一并消灭？他起初认为，可以说用益权会消灭；但即使如此，也应认为，在确定期间内，该奴隶为用益权人所作的允诺仍可归用益权人取得。由此可以推知，即使他人占有该奴隶，只要奴隶仍为我作出某种允诺，用益权或许并不消灭。奴隶由继承人占有、由购买遗产之人占有、由取得遗赠所有权之人占有，或由盗贼占有，均无区别。要保有用益权，只须有保有用益权的意思，且奴隶以用益权人的名义实施某种行为。此说有其道理。

<a id="7.1.12.5"></a>

**5.** 尤利安在《学说汇纂》第三十五卷中讨论：如果盗贼采摘或割下尚挂在树上的成熟果实，返还之诉应针对土地所有人还是用益权人？他认为，果实只有在由用益权人采收后才归其所有；即使由他人将果实与土地分离，向土地所有人提起返还之诉仍更为妥当。但用益权人可以提起盗窃之诉，因为他有利益，不愿果实被盗。马尔凯卢斯对此有所疑问：如果用益权人后来取得这些果实，它们或许会归其所有；如果确实如此，这是如何发生的？除非认为果实起初暂归所有人，后来被用益权人取得时才转归用益权人所有；这如同附条件遗赠的物，在条件成就之前属于继承人，条件成就后便转归受遗赠人。所有人确可提起返还之诉；但如果所有权处于未定状态——正如尤利安本人谈及被寄养的胎畜，以及用益权人通过交付取得奴隶之物、价款虽未支付但已提供担保的情形时所说——就应当认为返还之诉也处于待定状态，所有权亦未确定。

### <a id="7.1.13"></a>7.1.13　乌尔比安《评萨宾》第十八卷

<a id="7.1.13.pr."></a>

**序言（pr.）** 如果某物的用益权已经遗赠，所有人可以要求用益权人提供担保；此事应由法官依职权处理。因为用益权人应当使用并收益该物，所有权人也应对其所有权享有保障。尤利安在《学说汇纂》第三十八卷中证明，这一规则适用于一切用益权。如果用益权已经遗赠，在用益权人提供担保、承诺依善良家父的裁量使用并收益之前，不应先向其授予诉权；如果有数人遗赠了用益权，则应分别向每一人要求提供担保。

<a id="7.1.13.1"></a>

**1.** 因此，审理用益权纠纷时，法官不仅应判断已经发生的行为，也应裁量用益权人今后应如何使用和收益该物。

<a id="7.1.13.2"></a>

**2.** 对于过去造成的损害，用益权人也应依《阿奎利亚法》以及“以暴力或秘密方式实施”的禁令承担责任，正如尤利安所说。用益权人当然也受这些诉权以及盗窃之诉约束，正如任何人在他人之物上实施此类行为一样。有人问：既然已有《阿奎利亚法》之诉，裁判官为何还允诺给予此项诉权？答复是，在某些情形下，《阿奎利亚法》之诉不能适用，所以应指定法官，由其裁量用益权人是否妥善行使权利。例如，不翻耕土地、不在葡萄园补种葡萄藤，或放任水道损坏的人，并不受《阿奎利亚法》追诉。关于单纯使用权人，也应作相同解释。

<a id="7.1.13.3"></a>

**3.** 如果两名用益权人之间发生争议，尤利安在《学说汇纂》第三十八卷中写道，最公平的做法是准许他们提起类似共有物分割之诉，或者相互订立担保约定，确定各自如何享有收益。尤利安说，裁判官为何容许他们诉诸武力和争斗，而不运用自己的管辖权解决争议？凯尔苏斯在《学说汇纂》第二十卷中也赞同此说，我认为这是正确的。

<a id="7.1.13.4"></a>

**4.** 用益权人不得使所有权状况恶化，但可以使之改善。如果遗赠的是土地用益权，他不得砍伐结果实的树木，不得拆毁宅院，也不得实施任何损害所有权的行为。假如土地仅供游赏，具有绿地、散步场所和林荫步道，种植着不结果的树木，景致幽美；用益权人就不得将其毁掉，改作菜园或其他能够产生收益的用途。

<a id="7.1.13.5"></a>

**5.** 因此有人问，用益权人能否自行开设采石场、黏土矿或砂矿。我认为，如果他不会因此占用土地中不可或缺的部分，就可以自行开设。因此，他也可以探查石矿及类似矿藏的矿脉；所以，只要不妨碍农业生产，他可以开采金、银、硫磺、铜、铁及其他矿藏，也可以经营家父已经开设的矿场，或自行开设矿场。如果新开设的矿场收益高于原有葡萄园、灌木园或橄榄园，他或许甚至可以将这些园地毁掉，因为允许用益权人改善所有权状况。

<a id="7.1.13.6"></a>

**6.** 但是，如果用益权人开设的设施会破坏土地的空气环境，或者需要大量工匠、采集者，而所有人无力承担相关开支，就不能说用益权人是依善良家父的裁量行使权利。除收取收益所必需的建筑外，用益权人不得在土地上另行建造房屋。

<a id="7.1.13.7"></a>

**7.** 如果遗赠的是房屋用益权，内尔瓦之子说，用益权人可以开窗采光；也可以使用颜料、绘画、大理石、雕像及其他装饰房屋之物。但不得改造、合并或分隔房间，不得改变入口或后门，不得开辟隐蔽通道，不得改建中庭，也不得改变绿地的布局；他可以修缮和美化房屋，但不得改变其原有格局。内尔瓦还说，房屋用益权人不得加高房屋，即使不会遮挡光线也不行，因为这会损坏屋顶；拉贝奥认为，即使所有人也不得如此。内尔瓦还说，用益权人也不得堵塞窗户。

<a id="7.1.13.8"></a>

**8.** 如果遗赠的是房屋用益权，用益权人不得在其中开设旅店，也不得把房屋分隔成多个出租单间。虽然他可以出租，但应当像出租整栋住宅那样出租；不得在其中开设浴场。他说不得开设的“旅店”，应理解为通常所称的客舍或洗衣作坊。我认为，即使房屋中有浴室，原本供家主在住宅深处或雅致房间之间私人使用，用益权人也不得违背善良家父的裁量，将其出租供公众沐浴；这正如不得将住宅出租作牲畜驿站，也不得将原本供房屋主人停放牲畜和车辆的马厩改作磨坊一样。

### <a id="7.1.14"></a>7.1.14　保罗《评萨宾》第三卷

即使这样做所得收益少得多，亦然。

### <a id="7.1.15"></a>7.1.15　乌尔比安《评萨宾》第十八卷

<a id="7.1.15.pr."></a>

**序言（pr.）** 如果用益权人在土地上建造了什么，之后不得将其拆下或拆除；但拆下的材料可以请求返还。

<a id="7.1.15.1"></a>

**1.** 遗赠奴隶用益权时，用益权人不得滥用奴隶，而应依其身份和状况使用。例如，让书记奴隶去乡间搬运筐子和石灰，令演员担任浴场服务者，让乐师充任门房，或者令在体育场劳作的奴隶负责清理厕所，均可视为滥用所有权。

<a id="7.1.15.2"></a>

**2.** 用益权人应当按照奴隶的等级和身份，充分供给其饮食和衣物。

<a id="7.1.15.3"></a>

**3.** 拉贝奥概括说，对于一切动产，用益权人都应把握适当限度，不得因粗暴或残忍而损坏其物；否则，也可以依《阿奎利亚法》起诉他。

<a id="7.1.15.4"></a>

**4.** 如果遗赠的是衣物用益权，而非一定数量衣物的用益权，应当说，用益权人可以使用衣物，但不得耗尽其价值；他也不得出租，因为善良人不会如此使用衣物。

<a id="7.1.15.5"></a>

**5.** 因此，即使遗赠的是舞台服装、帷幕或其他舞台用品的用益权，用益权人也不得在舞台以外使用；至于能否出租，尚须考察。我认为可以出租；即使立遗嘱人过去只出借而不出租，用益权人仍可以出租舞台服装和丧服。

<a id="7.1.15.6"></a>

**6.** 所有权人不得阻止用益权人以不使物的状况恶化的方式使用该物。某些情形仍有疑问：如果所有人禁止用益权人使用，是否合法？例如遗赠土地用益权时，土地上有大酒桶；有人认为，即使酒桶埋在地下，也应禁止用益权人使用。对发酵缸、大桶、酒瓮和双耳罐，也有人持相同意见；如果遗赠房屋用益权，对玻璃窗亦然。但我认为，除非立遗嘱人有相反意思，土地或房屋的附属设施也包含在遗赠之内。

<a id="7.1.15.7"></a>

**7.** 所有权人不得在土地上设定地役权，也不得使地役权消灭。尤利安写道，即使违背用益权人的意愿，所有权人仍可为土地取得地役权。由此可知，用益权人不得为土地取得地役权，但可以保有地役权；如果因用益权人未行使而导致地役权消灭，他也须就此承担责任。即使得到用益权人的同意，所有权人也不得在土地上设定地役权，

### <a id="7.1.16"></a>7.1.16　保罗《评萨宾》第三卷

除非设定的地役权不会使用益权人的处境恶化，例如为邻人设立不得加高房屋的地役权。

### <a id="7.1.17"></a>7.1.17　乌尔比安《评萨宾》第十八卷

<a id="7.1.17.pr."></a>

**序言（pr.）** 经用益权人同意，可以将某处变为宗教场所；为尊重宗教，此说正确。但有时所有权人也可以单独将某处变为宗教场所：例如，所有人将遗嘱人安葬于该处，而在其他地方安葬并不合适。

<a id="7.1.17.1"></a>

**1.** 为避免所有权人使用益权人的处境恶化，常有人问：所有人能否惩戒奴隶？阿里斯托在卡西乌斯著作中指出，只要所有人并非出于恶意，就有权充分惩戒奴隶；而用益权人不得令奴隶从事与其技能相悖或不寻常的劳役，以致毁坏其技能，也不得用伤痕损害奴隶的身体。

<a id="7.1.17.2"></a>

**2.** 如果所有人并非出于恶意，也可以将奴隶交付受害人以代替赔偿，因为依法交付奴隶并不消灭用益权，正如设立用益权后发生的所有权取得时效也不消灭用益权。如果用益权人不向受领奴隶以代替赔偿的人提出诉讼估价，则应拒绝其追索用益权。

<a id="7.1.17.3"></a>

**3.** 如果有人杀死奴隶，我从不怀疑，应当类推《阿奎利亚法》给予用益权人一项准诉权。

### <a id="7.1.18"></a>7.1.18　保罗《评萨宾》第三卷

土地用益权遗赠后，已死去的树木应予补种；被移除的原有树木则归用益权人。

### <a id="7.1.19"></a>7.1.19　庞波尼乌斯《评萨宾》第五卷

<a id="7.1.19.pr."></a>

**序言（pr.）** 普罗库鲁斯认为，可以遗赠一座岛屿，并为其设定一项应向属于继承人的另一座岛屿承担的地役权，遗嘱可以这样写：“如果那个人向我的继承人承诺，不会由其加高该建筑，那么我将该建筑的用益权遗赠给他。”或者写道：“在那些房屋尚未加高至超过现有高度以前，我将其用益权遗赠给他。”

<a id="7.1.19.1"></a>

**1.** 如果所有人不移走被风吹倒的树木，致使用益权或通行变得不便，用益权人可以通过自己享有的诉权对所有人提起诉讼。

### <a id="7.1.20"></a>7.1.20　乌尔比安《评萨宾》第十八卷

如果有人这样遗赠：“我将科尔内利乌斯土地的年度收益赠与并遗赠给盖尤斯·梅维乌斯”，应将这句话理解为遗赠该土地的用益权。

### <a id="7.1.21"></a>7.1.21　乌尔比安《评萨宾》第十七卷

如果遗赠的是奴隶的用益权，该奴隶凭借自己的劳务或用益权人的财产所取得的一切，均归用益权人；无论是通过要式口约取得，还是通过交付而取得占有，均如此。如果该奴隶被指定为继承人或接受遗赠，拉贝奥则区分：应考察其被指定为继承人或接受遗赠，是为了谁的利益。

### <a id="7.1.22"></a>7.1.22　乌尔比安《评萨宾》第十八卷

如果有人向一名由他人享有用益权的奴隶赠与财物，也会产生应如何处理的问题。凡属此类情形，如果财物是考虑到用益权人才留给或赠与奴隶的，就由用益权人取得；如果是考虑到所有人，则由所有人取得；如果是为了奴隶本人，则由所有人取得。我们不区分受赠奴隶是从何处、因何缘由为赠与人所知。又如，享有用益权的奴隶为了满足某项条件而取得财物，如果可以确定该条件是考虑用益权人而附加的，就应当说由用益权人取得；因死亡而为的赠与，也应作相同处理。

### <a id="7.1.23"></a>7.1.23　乌尔比安《评萨宾》第十七卷

<a id="7.1.23.pr."></a>

**序言（pr.）** 正如奴隶通过要式口约为用益权人取得权利，尤利安在《学说汇纂》第三十卷中写道，奴隶也可以通过订立协议为用益权人取得抗辩权。如果奴隶请求债权人确认受领清偿，用益权人也会因此获得债务解除。

<a id="7.1.23.1"></a>

**1.** 既然我们说，奴隶凭借劳务取得的财物归用益权人，那么还应知道，用益权人可以强制奴隶提供劳务。萨宾答复说，用益权人也有权对奴隶作适度惩戒；卡西乌斯在《市民法》第八卷中写道，不得对奴隶施以酷刑或鞭打。

### <a id="7.1.24"></a>7.1.24　保罗《评萨宾》第十卷

某人原本打算赠与用益权人，却向一名由用益权人享有用益权的奴隶作出承诺，而该奴隶已为用益权人订立要式口约；该承诺应对用益权人发生效力，因为此类奴隶可以为用益权人订立口约，早已是惯例。

### <a id="7.1.25"></a>7.1.25　乌尔比安《评萨宾》第十八卷

<a id="7.1.25.pr."></a>

**序言（pr.）** 如果该奴隶为自己或为享有其用益权的人名下的斯提克斯订立要式口约，意在向用益权人赠与财物，那么应当说，只要向该奴隶给付，财物就归用益权人取得。

<a id="7.1.25.1"></a>

**1.** 有时，奴隶为谁取得财物尚未确定。例如，他购买一名奴隶并经交付取得其占有，价款尚未付清，只是为此提供了担保；此时该奴隶究竟归谁所有？尤利安在《学说汇纂》第三十五卷中写道，所有权尚处于未定状态，须待支付价款才能确定其归属；如果价款来自用益权人的财产，则该奴隶溯及既往地归用益权人所有。奴隶要支付价款而为要式口约时，亦同：应由付款确定要式口约利益归谁取得。因此，在价款付清之前，所有权处于未定状态。如果用益权消灭后才支付价款，又该如何？尤利安在《学说汇纂》第三十五卷中写道，仍须考察价款来源；马尔凯卢斯和毛里基亚努斯则认为，用益权消灭后，所有权已经归所有人取得。尤利安的意见更为妥当。如果价款由双方的财产共同支付，尤利安写道，双方按所支付价款的比例取得所有权。但如果奴隶同时以双方的财产付款，例如欠付一万的价款，却从每一方的财产中各付一万，奴隶究竟归谁取得？如果分次付款，应考察他先付的是哪一方的钱；其后支付的钱，要么由相应一方请求返还，要么在钱币已被花用时通过返还请求权追回。如果他从同一钱袋同时付款，收款人并未因此取得钱币所有权，所以似乎任何一方都尚未取得奴隶所有权；奴隶支付超过应付数额的价款，并不使收款人取得钱币所有权。

<a id="7.1.25.2"></a>

**2.** 如果该奴隶出租自己的劳务，并约定每年收取固定报酬，那么用益权存续期间各年的要式口约利益归用益权人取得；此后各年的要式口约利益则转归所有人，尽管通常要式口约一经为某人取得，除转归其继承人或收养人外，不会转归他人。因此，如果按年遗赠用益权，而该奴隶出租劳务并作出上述约定，当用益权因身份减等而消灭、随后又恢复时，要式口约的利益便随之转移；已经转归继承人的部分，也会回归用益权人。

<a id="7.1.25.3"></a>

**3.** 有人问，不能由用益权人取得的财物，是否会由所有人取得。尤利安在《学说汇纂》第三十五卷中写道，不能由用益权人取得的，便由所有人取得。因此，他写道：奴隶以所有人名义明确订立要式口约，或者依所有人的指示订立要式口约，即使该口约利益原本来自用益权人的财产，也由所有人取得。反之，如果奴隶订立要式口约的利益既非来自用益权人的财产，也非来自其自身劳务，则用益权人不能取得任何利益。

<a id="7.1.25.4"></a>

**4.** 如果享有用益权的奴隶订立要式口约，要求将用益权授予自己，或者未指明受益人，或者明确指定所有人为受益人，则由所有人取得；这与共有奴隶相同。共有奴隶为其中一名所有人订立要式口约时，如果标的是该所有人自己的物，他未取得任何利益，因为人对自己的物订立要式口约，不产生效果；如果是为另一名所有人订立要式口约，则由该所有人全部取得。

<a id="7.1.25.5"></a>

**5.** 尤利安在同一卷中还写道：用益权人雇用享有用益权的奴隶提供劳务，并不发生效力。因为他说，即使奴隶以我的财产为利益而向我本人订立要式口约，也不发生效力；正如善意为我服役的他人奴隶，不能因同样的行为使其真正所有人取得任何利益一样。同理，即使该奴隶以用益权人身份向我承租我的物，也不会使我负担义务。他概括说：奴隶为我向他人订立要式口约而使我取得的利益，若改为向我本人订立要式口约，便不发生效力；除非奴隶明确以其所有人的名义向我订立口约或向我承租。

<a id="7.1.25.6"></a>

**6.** 假设有两名用益权人，而奴隶以其中一人的财产订立了要式口约；问题是，该人会取得全部利益，还是仅按其用益权份额取得？谢沃拉在《法律问题》第二卷中也讨论过两个善意占有人的类似问题。他说，通说及其理由是：如果奴隶以一方的财产订立要式口约，则该方仅取得其份额，另一份额归所有人；如果奴隶明确指定某人为受益人，毫无疑问，所加列的那个人会取得全部利益。他又说，依该人的指示订立口约也相同，因为该指示视同在口约中列明其姓名。对于用益权人之间的关系也应如此处理：用益权人未取得全部利益的部分，应由所有权人取得，因为我们已经指出，用益权人可以从自己的财产中取得利益。

<a id="7.1.25.7"></a>

**7.** 我们说，奴隶可以从用益权人的财产或凭借自己的劳务取得利益；还须考察，这是否仅适用于因遗赠而设立用益权的情形，还是通过交付、要式口约或其他方式设立用益权时也适用。佩加苏斯的意见是正确的，尤利安在《学说汇纂》第十六卷中也赞同：上述利益可由任何用益权人取得。

### <a id="7.1.26"></a>7.1.26　保罗《评萨宾》第三卷

如果享有用益权的奴隶出租自己的劳务，而用益权在租期届满前消灭，剩余租期的收益归所有人。如果奴隶一开始就约定以劳务换取固定数额的价款，但其后因身份减等而丧失身份，亦同。

### <a id="7.1.27"></a>7.1.27　乌尔比安《评萨宾》第十八卷

<a id="7.1.27.pr."></a>

**序言（pr.）** 如果立遗嘱人留下了已经成熟但尚未采收的果实，而用益权开始之日这些果实仍挂在树上，用益权人便可取得；因为尚未采收的果实也归用益权人。

<a id="7.1.27.1"></a>

**1.** 如果所有人过去惯常将店铺用于储存自己的货物或从事商业经营，当然应允许用益权人将店铺出租，用于经营其他货物；但应注意，用益权人不得滥用用益权，也不得以侮辱、侵害的方式行使用益权。

<a id="7.1.27.2"></a>

**2.** 如果遗赠的是某奴隶的用益权，而立遗嘱人过去只是让该奴隶闲置服役，用益权人若教会其学科或技艺，就可以使用该奴隶的技艺或专长。

<a id="7.1.27.3"></a>

**3.** 如果有排水沟税，或须为穿过土地的水道设施缴费，应由用益权人承担；如果须缴纳道路维护摊款，我认为也应由用益权人承担。军队经过而征收的费用，也应从收益中支付。若须向自治市缴费，亦同；土地占有人通常会以较低价格将部分收益转让给自治市，也常须向国库缴纳摊款。这些负担均由用益权人承担。

<a id="7.1.27.4"></a>

**4.** 如果土地上设有地役权，用益权人必须承担；因此，如果地役权是通过要式口约承担的，我认为也应作相同处理。

<a id="7.1.27.5"></a>

**5.** 如果购买奴隶时约定了若干禁令，违反时须承担罚金；而该奴隶的用益权后来被遗赠，用益权人是否应遵守这些禁令？我认为应当遵守，否则便不是依善良家父的裁量使用并收益奴隶。

### <a id="7.1.28"></a>7.1.28　庞波尼乌斯《评萨宾》第五卷

可以遗赠旧金币或旧银币的用益权；这些钱币通常被当作宝石使用。

### <a id="7.1.29"></a>7.1.29　乌尔比安《评萨宾》第十八卷

凯尔苏斯在《学说汇纂》第三十二卷和尤利安在《学说汇纂》第六十一卷中写道，可以遗赠全部财产的用益权，但其价值不得超过遗产的四分之三；这一意见更为正确。

### <a id="7.1.30"></a>7.1.30　保罗《评萨宾》第三卷

如果某人有两栋房屋，而他遗赠了其中一栋房屋的用益权，马尔凯卢斯写道，继承人可以加高另一栋房屋并遮挡光线，因为即使房屋光线被遮挡，仍然可以居住。但对此应当有所限制：不得将房屋完全遮暗，而应保留足以供居住者使用的适度光线。

### <a id="7.1.31"></a>7.1.31　保罗《评萨宾》第十卷

也属于源自用益权人财产的利益的，还包括用益权人赠与或交给奴隶的财物，以及奴隶在管理用益权人事务时取得的收益。

### <a id="7.1.32"></a>7.1.32　庞波尼乌斯《评萨宾》第三十三卷

如果某人转让自己唯一的一栋房屋或唯一的一块土地，可以保留属于个人而非土地本身的权利，例如使用权或用益权。即使他保留放牧或居住的权利，该保留也有效，因为可以在多片林地放牧而取得收益。保留居住权，无论是有期限的，还是持续至保留者死亡为止，都应视为保留了使用权。

### <a id="7.1.33"></a>7.1.33　帕比尼安《法律问题》第十七卷

<a id="7.1.33.pr."></a>

**序言（pr.）** 如果将收益遗赠给提提乌斯，将所有权遗赠给梅维乌斯，而提提乌斯在立遗嘱人仍在世时死亡，遗嘱指定继承人就不会留下任何财产；奈拉提乌斯也作过同样的答复。

<a id="7.1.33.1"></a>

**1.** 通说认为，在某些情形下，用益权并不按份额发生效力。因此，如果有人请求取得土地的一部分或收益的一部分，判决其不负责任后，另一部分才归其取得并被请求返还，尤利安写道：就所有权诉讼而言，既判事项抗辩可以阻却后诉；就收益而言，该抗辩则不适用。因为土地的一部分如同冲积地归并于另一份额，而收益的用益权则归并于个人。

### <a id="7.1.34"></a>7.1.34　尤利安《学说汇纂》第三十五卷

<a id="7.1.34.pr."></a>

**序言（pr.）** 如果遗赠给两人用益权，并规定二人隔年使用、收益：如果遗嘱写的是“遗赠给提提乌斯和梅维乌斯”，可以认为用益权先遗赠给提提乌斯，之后才遗赠给梅维乌斯。如果两人同名，而遗嘱写道“我将用益权隔年遗赠给提提乌斯们”，那么除非二人就谁先使用达成一致，否则会彼此妨碍。如果提提乌斯在其应当收益的那一年取得所有权，那么该期间他不享有遗赠；用益权便隔年归梅维乌斯。如果提提乌斯转让了所有权，他仍享有用益权。因为，即使我受遗赠的用益权附有条件，而我在条件尚未成就时从继承人处取得所有权，之后又转让了所有权，条件成就时我仍可接受该遗赠。

<a id="7.1.34.1"></a>

**1.** 如果你将土地用益权遗赠给自己的承租人，他可以请求确认用益权，并依据租赁关系对你的继承人起诉；他可以请求免交租金，并取回自己为耕种土地所支出的费用。

<a id="7.1.34.2"></a>

**2.** 遗赠的是全部财产的用益权，还是个别物的用益权，我认为区别在于：如果房屋被烧毁，就不能请求个别房屋的用益权；但如果遗赠的是全部财产的用益权，则可以请求土地基地的用益权。因为立遗嘱人遗赠其全部财产的用益权，似乎不仅遗赠其中各个具体物的用益权，也遗赠全部财产总体的用益权；而土地基地也属于财产总体。

### <a id="7.1.35"></a>7.1.35　尤利安《评乌尔塞乌斯·费洛克斯》第一卷

<a id="7.1.35.pr."></a>

**序言（pr.）** 如果用益权已经遗赠，但遗嘱指定继承人为使受遗赠人迟延取得遗赠而延迟接受遗产，依萨宾意见，也应就此承担责任。

<a id="7.1.35.1"></a>

**1.** 有人将奴隶用益权遗赠给我；在我不再使用、收益该奴隶后，立遗嘱人命令释放奴隶；之后我从继承人处取得遗赠的估价款。萨宾答复说，该奴隶仍不会因此成为自由人；因为我被视为仍在使用、收益该奴隶，尽管我已经取得替代给付。不过，释放条件仍然不变：我死亡或发生身份减等时，奴隶即应成为自由人。

### <a id="7.1.36"></a>7.1.36　阿非利加努斯《法律问题》第五卷

<a id="7.1.36.pr."></a>

**序言（pr.）** 某人遗赠了一处土地基地的用益权，之后在其上建造房屋；房屋在其生前倒塌或被焚毁。他认为，基地的用益权仍然负有给付义务。反之，如果遗赠的是房屋的用益权，之后房屋才建在土地基地上，则不适用相同规则。杯子用益权的情形也相同：杯子熔化成金属块，又被制成杯子；尽管杯子的原有形状恢复，这些杯子仍不是原遗赠用益权的标的。

<a id="7.1.36.1"></a>

**1.** 我与提提乌斯约定，由他转让科尔内利乌斯土地的所有权，但扣除用益权；提提乌斯死亡后，有人询问其继承人应向我给付什么。答复是：要看扣除用益权时双方的意思。如果双方意在使任何人均享有用益权，继承人只须给付裸所有权；如果双方的意思只是让转让人自己享有用益权，则其继承人应向我给付完整所有权。在遗赠情形下，这一点更为明显：如果遗嘱指定继承人被遗赠裸所有权，而其在受遗赠人依据遗嘱起诉之前死亡，就更无疑问，其继承人应给付完整所有权。遗赠附有条件，而继承人在条件成就前死亡的，亦同。

<a id="7.1.36.2"></a>

**2.** 提提乌斯受遗赠奴隶的用益权；由于继承人迟延给付，用益权给付尚未完成时奴隶便死亡。他说，继承人只能按提提乌斯因迟延未发生而具有的利益承担责任；也就是说，应当自发生迟延之日起，计算至奴隶死亡之日的用益权价值。若提提乌斯本人死亡，也应同样自发生迟延之日起，计算至其死亡之日的用益权价值，并给付给其继承人。

### <a id="7.1.37"></a>7.1.37　阿非利加努斯《法律问题》第七卷

有人问：如果我约定由你在接下来的十年内授予我用益权，而你没有给付，致使五年过去，法律效果如何？如果我约定由你在接下来的十年内提供斯提克斯的劳务，五年也同样过去，结果又如何？答复是，对于因你迟延给付而经过的期间，可以正当地请求相应的用益权和劳务。

### <a id="7.1.38"></a>7.1.38　马尔西安《法学阶梯》第三卷

如果用益权人自己不使用，也没有他人以他的名义使用，例如买受人、承租人、受赠人或事务管理人均未使用，就不视为用益权人行使用益权。不过，如果我出售了用益权，即使买受人没有使用，我仍被视为保有用益权；

### <a id="7.1.39"></a>7.1.39　盖尤斯《评行省告示》第七卷

因为取得价金的人，被视为享有的利益并不低于亲自使用、收益原物的人。

### <a id="7.1.40"></a>7.1.40　马尔西安《法学阶梯》第三卷

但如果我将用益权赠与他人，只有在受赠人实际使用时，我才保有用益权。

### <a id="7.1.41"></a>7.1.41　马尔西安《法学阶梯》第七卷

<a id="7.1.41.pr."></a>

**序言（pr.）** 更妥当的意见是，雕像和肖像也可以遗赠用益权，因为只要将其放置在适当地点，也有一定用途。

<a id="7.1.41.1"></a>

**1.** 即使有些土地带来的收益少于投入，用益权仍然可以遗赠。

### <a id="7.1.42"></a>7.1.42　弗洛伦提努斯《法学阶梯》第十一卷

<a id="7.1.42.pr."></a>

**序言（pr.）** 如果同一物的使用权遗赠给一人，收益遗赠给另一人，用益权人取得使用权人使用后剩余的收益；使用权人仍保有为享用该物而使用它的权利。

<a id="7.1.42.1"></a>

**1.** 遗赠给你的是特定物的用益权，还是按估价确定的用益权，区别重大。如果遗赠的是特定物的用益权，则应先扣除另行遗赠给你的物，再由其余财产产生用益权；如果遗赠的是按估价确定的用益权，则另行遗赠给你的物也应计入估价。因为立遗嘱人反复遗赠同一物，并不会增加遗赠；但在遗赠特定物之外再遗赠其估价，则可以增加遗赠利益。

### <a id="7.1.43"></a>7.1.43　乌尔比安《规则》第七卷

也可以遗赠部分财产的用益权。如果没有特别说明其份额，则视为包含半数财产。

### <a id="7.1.44"></a>7.1.44　奈拉提乌斯《札记》第三卷

用益权人不得在原本未作抹灰的墙壁上加铺新的灰泥。因为，即使用益权人的行为会改善建筑物并使所有人受益，他也无权以自己的权利这样做；维护现有设施与新建设施并非一回事。

### <a id="7.1.45"></a>7.1.45　盖尤斯《评行省告示》第七卷

如同由用益权人承担其享有用益权的奴隶的食物费用一样，依自然法理，奴隶的医疗费用也应由用益权人承担。

### <a id="7.1.46"></a>7.1.46　保罗《评普劳提乌斯》第九卷

<a id="7.1.46.pr."></a>

**序言（pr.）** 如果立遗嘱人指定外人为继承人，遗漏了解放出家父权的儿子，并将扣除用益权后的所有权遗赠给其母亲；母亲请求取得对抗遗嘱的遗产占有后，基于亲情，应向母亲交付完整所有权。

<a id="7.1.46.1"></a>

**1.** 如果立遗嘱人命令继承人修缮一栋房屋，而该房屋的用益权已经遗赠，用益权人可以依据遗嘱提起诉讼，请求继承人修缮房屋。

### <a id="7.1.47"></a>7.1.47　庞波尼乌斯《评普劳提乌斯》第五卷

如果继承人没有修缮，致使用益权人无法享用该物，那么，即使用益权因其死亡而消灭，其继承人也可基于此事提起诉讼，请求赔偿继承人未履行义务而使用益权人所受的损失。

### <a id="7.1.48"></a>7.1.48　保罗《评普劳提乌斯》第九卷

<a id="7.1.48.pr."></a>

**序言（pr.）** 如果用益权人不在场，继承人以为其管理事务的方式修缮了房屋，那么继承人可以对用益权人提起无因管理之诉，即使继承人也是为了自己将来的利益而修缮。如果用益权人愿意放弃用益权，则不得强制其修缮；他因无因管理之诉而承担的责任也随之免除。

<a id="7.1.48.1"></a>

**1.** 可周期采伐的树林，即使在不适当的季节被砍伐，所得仍属于收益；正如未成熟的橄榄被采摘、未成熟的干草被收割，也属于收益。

### <a id="7.1.49"></a>7.1.49　庞波尼乌斯《评普劳提乌斯》第七卷

如果塞姆普罗尼乌斯和穆基乌斯作为继承人，将用益权遗赠给我和你，我可在塞姆普罗尼乌斯的份额中取得四分之一，并在穆基乌斯的份额中再取得四分之一；你也同样在他们各自的份额中取得四分之一。

### <a id="7.1.50"></a>7.1.50　保罗《评维特利乌斯》第三卷

提提乌斯将图斯库卢姆土地遗赠给梅维乌斯，并委托梅维乌斯向提提娅提供该土地二分之一份额的用益权。梅维乌斯修建了一座因年久失修而损坏的宅院；该宅院对于采收和保存收益确有必要。有人问，提提娅是否应按其用益权份额分担费用。谢沃拉答复：如果梅维乌斯在提供用益权之前已经有必要修建，那么只有在将相关费用纳入计算时，才应强制其返还费用。

### <a id="7.1.51"></a>7.1.51　莫德斯蒂努斯《法律区别》第九卷

将“某人在死亡时”才开始的用益权遗赠给提提乌斯，应视为无效；因为用益权在该人死亡时便开始脱离其本人而消灭。〔原文表述简略，具体所指尚待核。〕

### <a id="7.1.52"></a>7.1.52　莫德斯蒂努斯《规则》第九卷

遗赠用益权时，如果须缴纳该物的租税，毫无疑问应由用益权人缴纳；除非能够特别证明，立遗嘱人曾以遗嘱信托的方式明确表示，此项费用也应由继承人承担。

### <a id="7.1.53"></a>7.1.53　尤沃勒努斯《书信集》第二卷

如果遗赠了一栋公寓楼的用益权，只要该楼尚有任何一部分存续，用益权人便保有对整块土地的用益权。

### <a id="7.1.54"></a>7.1.54　尤沃勒努斯《书信集》第三卷

你作为继承人，附条件将一块土地的用益权遗赠给提提乌斯；之后，你扣除用益权，将土地出售并交付给我。我询问：如果条件未成就，或者条件成就而用益权随后消灭，该用益权归谁？答复是：我理解你问的是遗赠的用益权。因此，如果遗赠条件成就，毫无疑问，该用益权归受遗赠人；如果用益权因任何原因消灭，就回复于土地所有权。若条件未成就，用益权则归继承人；关于用益权消灭的一切规则，也都适用于继承人本人。至于这类买卖，应以买卖双方约定为准：如果能够确定，保留用益权是为了履行遗赠，即使条件未成就，出卖人也应将用益权返还给买受人。

### <a id="7.1.55"></a>7.1.55　庞波尼乌斯《评昆图斯·穆基乌斯》第二十六卷

如果只将使用权遗赠给婴儿，即使婴儿期间尚未实际使用，待其长大、超过婴儿年龄后，该使用权仍开始发生效力。

### <a id="7.1.56"></a>7.1.56　盖尤斯《评行省告示》第十七卷

有人问，是否应当准许自治市以用益权为由提起诉讼。人们担心用益权会永久存续，因为它不会因死亡消灭，也不容易因身份减等而消灭；如此一来，用益权始终不终止，所有权便会变得毫无用处。尽管如此，通说仍认为应当准许此项诉讼。因此，接着产生了疑问：应保护自治市享有用益权多久？通说认为应保护一百年，因为这是一位长寿者寿命的上限。

### <a id="7.1.57"></a>7.1.57　帕比尼安《答复集》第七卷

<a id="7.1.57.pr."></a>

**序言（pr.）** 所有人将一处土地遗赠给用益权人；该土地原本供用益权人行使用益权。受遗赠人占有该土地一段时间后，因立遗嘱人的儿子就遗嘱违反亲属义务之诉胜诉，被迫将土地返还给该儿子。此后才显明，用益权仍完整保留。

<a id="7.1.57.1"></a>

**1.** 如果立遗嘱人以遗嘱信托的方式，将土地收益留给释奴供养之用，释奴死亡后，相应份额的利益便归所有权人。

### <a id="7.1.58"></a>7.1.58　谢沃拉《答复集》第三卷

<a id="7.1.58.pr."></a>

**序言（pr.）** 用益权人于十二月死亡，而该土地所产的一切收益已于十月由承租人收取。有人询问：尽管用益权人在三月租金应缴付日之前死亡，承租人是否仍应向用益权人的继承人支付租金；或者是否应将租金在用益权人的继承人与取得所有权遗赠的公共机构之间分配？我答复：公共机构对承租人没有任何诉权；用益权人的继承人则应在约定日期，依所述情形收取全部租金。

<a id="7.1.58.1"></a>

**1.** “我将法拉里人土地上所产蔬菜和韭葱出售后所得的六分之一，赠与并遗赠给塞姆普罗尼乌斯。”有人问，这些话是否构成用益权遗赠。我答复：并未遗赠用益权，而是遗赠已经收取的收益中的一部分。

<a id="7.1.58.2"></a>

**2.** 又有人问，如果并非遗赠用益权，是否遗赠了每年收取收益的六分之一？我答复：除非继承人特别证明有相反意思，否则应视为遗赠了每年的六分之一。

### <a id="7.1.59"></a>7.1.59　保罗《格言集》第三卷

<a id="7.1.59.pr."></a>

**序言（pr.）** 树木因风暴而倒下，且并非用益权人的过错所致，不应要求用益权人补种。

<a id="7.1.59.1"></a>

**1.** 土地上生长或从土地取得的一切，均归用益权人；已经出租土地的租金也包括在内，但须特别将其纳入遗赠。依买卖的规则，如果未特别排除承租人，用益权人可以将承租人驱离。

<a id="7.1.59.2"></a>

**2.** 如果土地通常也以砍伐芦苇或木桩取得租税收入，那么砍伐所得也归用益权人。

### <a id="7.1.60"></a>7.1.60　保罗《格言集》第五卷

<a id="7.1.60.pr."></a>

**序言（pr.）** 任何土地的用益权人被禁止使用或遭到驱逐时，都可以提起诉讼，请求返还一并被占有的一切物品。即使其后因其他原因丧失用益权，仍可通过准诉权请求返还此前已经取得的收益。

<a id="7.1.60.1"></a>

**1.** 如果被请求用益权的土地并非由所有人占有，仍应准许提起诉讼。因此，如果两人之间存在土地所有权争议，用益权人仍应保持占有；占有人应向其提供担保，保证在受遗赠人证明其权利期间，不会阻止其使用并收益该土地。但如果用益权人本人也受到权利争议，在争议解决前，应暂缓其行使用益权；他应提供担保，承诺返还由这些收益取得之物；如果他不能提供充分担保，则应准许其亲自使用、收益该土地。

### <a id="7.1.61"></a>7.1.61　奈拉提乌斯《答复集》第二卷

用益权人不得在墙壁上设置新的水道。通说认为，用益权人不得完成尚未完工的建筑，即使不完成就无法以其他方式使用该土地；他甚至也不享有该建筑的用益权，除非设立或遗赠用益权时特别约定，他可以同时完成建筑并享有用益权。

### <a id="7.1.62"></a>7.1.62　特里波尼安《论辩集》第七卷

<a id="7.1.62.pr."></a>

**序言（pr.）** 通常认为，用益权人可以在其占有的林地或山地狩猎；他捕获的野猪或鹿并不归所有人所有，而是根据收益权或万民法归用益权人所有。

<a id="7.1.62.1"></a>

**1.** 如果设立用益权时，土地内圈养着围栏中的野兽，用益权人能否饲养它们，但不得将其杀死？或者，如果用益权人最初以自己的劳力将野兽圈养起来，或者之后野兽自行进入或掉入围栏，它们是否归用益权人所有？为避免逐一判断动物而因区分困难造成用益权人权利不确定，最方便的办法是：用益权终止时，每一类野兽都应将与用益权开始时相同数量的动物交还所有权人。

### <a id="7.1.63"></a>7.1.63　保罗《特别法单卷》

我们也可以将自己尚未享有的权利授予他人。例如，土地所有人虽不享有用益权，仍可设立并转让用益权。

### <a id="7.1.64"></a>7.1.64　乌尔比安《评告示》第五十一卷

如果用益权人愿意放弃用益权，在用益权人应承担修缮义务的情形下，不得强制其修缮房屋。即使针对他的诉讼已经受理，只要用益权人愿意放弃用益权，法官也应判决免除其责任。

### <a id="7.1.65"></a>7.1.65　庞波尼乌斯《评普劳提乌斯》第五卷

<a id="7.1.65.pr."></a>

**序言（pr.）** 用益权人应修缮因其本人或其家属行为而损坏的物；即使他愿意放弃用益权，也不得免除其责任。因为他应当像谨慎的家父修缮自己房屋那样，修缮该物。

<a id="7.1.65.1"></a>

**1.** 立遗嘱人因年久失修而留下状况恶化的物，其继承人并不比在立遗嘱人将所有权遗赠给他人时负有更重的修缮义务。

### <a id="7.1.66"></a>7.1.66　保罗《评告示》第四十七卷

用益权人不仅可能受到《阿奎利亚法》之诉的追究；如果他通过折磨奴隶使其状况恶化，也可能受到奴隶受损之诉及侮辱之诉的追究。

### <a id="7.1.67"></a>7.1.67　尤利安《评米尼基乌斯》第一卷

受遗赠用益权的人，即使继承人不同意，也可以将用益权出售给外人。

### <a id="7.1.68"></a>7.1.68　乌尔比安《评萨宾》第十七卷

<a id="7.1.68.pr."></a>

**序言（pr.）** 过去有人争论，奴隶所生子女是否归用益权人所有；但布鲁图斯的意见已经获采：用益权人无权取得奴隶所生子女，因为人不能成为另一人的收益。基于同一理由，用益权人对奴隶所生子女也不享有用益权。但如果遗赠中还包括该子女的用益权，他是否享有该项用益权？既然子女本身可以遗赠，其用益权也可以遗赠。

<a id="7.1.68.1"></a>

**1.** 但是，萨宾和卡西乌斯认为，牲畜所生幼畜归用益权人所有。

<a id="7.1.68.2"></a>

**2.** 如果遗赠的是畜群或牛群的用益权，用益权人应当以新生牲畜补充畜群，也就是替换已经死亡的牲畜。

### <a id="7.1.69"></a>7.1.69　庞波尼乌斯《评萨宾》第五卷

用益权人也可以用其他牲畜替换不能繁殖的牲畜；替换完成后，被替换的牲畜便归用益权人所有，以免此事使所有人获利。替换进去的牲畜立即归所有人所有；被替换出去的原有牲畜也依用益权的性质不再归所有人所有。否则，新生牲畜原本归用益权人所有，而他一旦用其替换原有牲畜，便会丧失新生牲畜的所有权。

### <a id="7.1.70"></a>7.1.70　乌尔比安《评萨宾》第十七卷

<a id="7.1.70.pr."></a>

**序言（pr.）** 如果用益权人不补充畜群或牛群，盖尤斯·卡西乌斯在《市民法》第十卷中写道，他应对所有人承担责任。

<a id="7.1.70.1"></a>

**1.** 在死亡牲畜被替换之前，其所生幼畜归谁所有？尤利安在《学说汇纂》第三十五卷中写道，幼畜的所有权处于未定状态：如果幼畜被用于补充畜群，就归所有人；如果没有用于补充，则归用益权人。此说正确。

<a id="7.1.70.2"></a>

**2.** 根据上述规则，如果幼畜死亡，风险由用益权人而非所有人承担；用益权人必须再用其他幼畜补充。因此，盖尤斯·卡西乌斯在《市民法》第八卷中写道，死亡幼畜的肉归用益权人。

<a id="7.1.70.3"></a>

**3.** 只有在遗赠畜群、牛群或马群——也就是整体牲畜群——的用益权时，才应当补充牲畜；如果遗赠的是个别牲畜的用益权，则无须补充。

<a id="7.1.70.4"></a>

**4.** 如果幼畜出生时没有可以替换的牲畜，而在其出生后才出现需要替换的情形，那么用益权人应以之后出生的幼畜，还是以已经出生的幼畜进行替换？我认为，更妥当的是：畜群完整时所生的幼畜归用益权人所有；但畜群后来发生的损失应由用益权人承担。

<a id="7.1.70.5"></a>

**5.** 替换是一种事实行为。尤利安对此作了准确说明：替换就是分配、分割，并进行某种划分；被用于替换的牲畜，其所有权归所有人。

### <a id="7.1.71"></a>7.1.71　马尔凯卢斯《学说汇纂》第十七卷

如果有人在他人享有用益权的土地基地上建造房屋，而在用益权届满前该房屋被拆除，古代法学家答复说，应恢复原来的用益权。

### <a id="7.1.72"></a>7.1.72　乌尔比安《评萨宾》第十七卷

如果所有人将裸所有权的用益权遗赠出去，麦基安在《遗嘱信托法律问题》第三卷中写道，该遗赠有效；如果用益权在立遗嘱人生前或继承人接受遗产前并入所有权，则归受遗赠人取得。麦基安还作了进一步解释：即使在继承人接受遗产后用益权才并入所有权，遗赠仍有效；受遗赠人的请求权也会到期，用益权仍归其取得。

### <a id="7.1.73"></a>7.1.73　庞波尼乌斯《评萨宾》第五卷

如果遗赠的是土地基地的用益权，我可以在其上建造小屋，以看守放在基地上的物品。

### <a id="7.1.74"></a>7.1.74　盖尤斯《评行省告示》第七卷

如果用益权遗赠给你的奴隶斯提克斯和我的奴隶潘菲卢斯，其效力等同于遗赠给我和你。因此，毫无疑问，用益权由我们平等享有。
