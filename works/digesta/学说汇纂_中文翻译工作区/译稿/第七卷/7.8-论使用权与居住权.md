## <a id="8"></a><a id="7.8"></a>7.8　论使用权与居住权

*De usu et habitatione*

### <a id="7.8.1"></a>7.8.1　盖尤斯《评行省告示》第七卷

<a id="7.8.1.pr."></a>

**序言（pr.）** 现在应当讨论使用权与居住权。

<a id="7.8.1.1"></a>

**1.** 也可以设立单纯的使用权，即不包括收益权的使用权；其设立方式与用益权相同。

### <a id="7.8.2"></a>7.8.2　乌尔比安《评萨宾》第十七卷

<a id="7.8.2.pr."></a>

**序言（pr.）** 被遗赠使用权的人可以使用该物，但不得享有其收益。对于各类情形，应分别考察。

<a id="7.8.2.1"></a>

**1.** 房屋的使用权遗赠给男子或女子时，如果遗赠给男子，他可以住在那里，不仅可以独自居住，也可以与自己的家属共同居住。男子能否与被释奴共同居住，曾有争议；塞尔苏斯写道可以，也可以接纳客人。他在《学说汇纂》第十八卷中如此写道，图贝罗也赞同这一意见。至于他能否接纳房客，我记得拉贝奥在《后书》中讨论过此事；拉贝奥说，自己住在房屋中的人可以接纳房客；同样也可以接纳客人和自己的被释奴。

### <a id="7.8.3"></a>7.8.3　保罗《评维泰利乌斯》第三卷

以及依附人（*clientes*）：

### <a id="7.8.4"></a>7.8.4　乌尔比安《评萨宾》第十七卷

<a id="7.8.4.pr."></a>

**序言（pr.）** 此外，即使是这些人，也不能不与他本人共同居住。普罗库鲁斯对“房客”一词作了批注：与他共同居住的人，不宜称为房客。依此，如果他本人也住在房屋中并收取租金，也不应因此受到非难。设想一个家境普通的人获遗赠一所十分宽敞的房屋的使用权，他满足于其中一小部分，难道不可以吗？他也可以与那些代替奴隶为他服劳务的人共同居住，即使这些人是自由人或他人的奴隶。

<a id="7.8.4.1"></a>

**1.** 如果使用权遗赠给女子，昆图斯·穆基乌斯最先承认，她可以与丈夫共同居住；否则，她想使用房屋时就不得不放弃婚姻。反过来说，妻子能否与丈夫共同居住，从来没有疑问。那么，如果使用权遗赠给寡妇，她在使用权设立后缔结婚姻，能否与丈夫共同居住？答案确实是可以；庞波尼乌斯在《评萨宾》第五卷、帕皮尼安在《疑问集》第十九卷都赞同这一意见：她后来再婚，也可以与丈夫共同居住。庞波尼乌斯还说，她也可以与公公共同居住。

### <a id="7.8.5"></a>7.8.5　保罗《评萨宾》第三卷

而且，公公也可以与儿媳共同居住，至少在丈夫也在场时如此。

### <a id="7.8.6"></a>7.8.6　乌尔比安《评萨宾》第十七卷

她不仅可以与丈夫共同居住，也可以与子女、被释奴及父母共同居住；阿里斯托在《评萨宾》中也作此说明。对此还应进一步认为，女子可以接纳与男子相同的那些人。

### <a id="7.8.7"></a>7.8.7　庞波尼乌斯《评萨宾》第五卷

女子只有在客人能够与享有使用权的女子合乎体面地共同居住时，才可以接纳该客人。

### <a id="7.8.8"></a>7.8.8　乌尔比安《评萨宾》第十七卷

<a id="7.8.8.pr."></a>

**序言（pr.）** 他们不得将房屋另行出租，不得在自己不居住时把居住权授予他人，也不得出卖使用权。

<a id="7.8.8.1"></a>

**1.** 如果房屋使用权遗赠给女子，附有“若她与丈夫离婚”的条件，应免除该条件，并允许她与丈夫共同居住；庞波尼乌斯在《评萨宾》第五卷中也赞同这一意见。

### <a id="7.8.9"></a>7.8.9　保罗《评萨宾》第三卷

如果其他物的使用权也被遗赠，应当认为，妻子可以与丈夫共同使用这些物品。

### <a id="7.8.10"></a>7.8.10　乌尔比安《评萨宾》第十七卷

<a id="7.8.10.pr."></a>

**序言（pr.）** 如果遗赠的是居住权，是否应将其视同使用权？这一问题尚待考察。就实际效果而言，遗赠使用权与居住权几乎相同，帕皮尼安在《疑问集》第十八卷中也赞同这一点。因此，居住权人不得赠与该权利，但可以接纳与使用权人相同的那些人。不过，居住权既不移转给其继承人，也不因不行使而消灭，亦不因人格减等而消灭。

<a id="7.8.10.1"></a>

**1.** 如果遗赠的是 *χρῆσις*（*xrysis*），应考察它是否属于使用权。帕皮尼安在《答复集》第七卷中说，它属于使用权，并未遗赠收益权。

<a id="7.8.10.2"></a>

**2.** 如果遗赠如此表述：“为居住之目的，某人享有该房屋的用益权”，应考察遗赠的究竟只是居住权，还是也包括用益权。普罗库鲁斯和涅拉提乌斯认为，只遗赠了居住权；这确是正确的。显然，如果立遗嘱人说“为居住之目的遗赠使用权”，我们就不会怀疑该遗赠有效。

<a id="7.8.10.3"></a>

**3.** 居住权究竟仅为一年，还是持续至居住权人终身，古人曾对此提出疑问。鲁提利乌斯说，居住权应持续至其有生之年；塞尔苏斯在《学说汇纂》第十八卷中也赞同这一意见。

<a id="7.8.10.4"></a>

**4.** 如果遗赠的是土地的使用权，其范围当然小于用益权，这一点无人怀疑。但其具体内容仍须考察。拉贝奥说，使用权人可以住在土地上，并可以禁止所有人到那里来；但不能禁止佃户，也不能禁止为耕种土地而在那里工作的家属。反之，如果所有人把城市家属派到那里，既然可以禁止所有人本人到场，基于同一理由，也可以禁止这些家属。拉贝奥还说，使用权人可以独自使用酒窖和油窖；未经其同意，所有人也不得使用。

### <a id="7.8.11"></a>7.8.11　盖尤斯《日常法学概要》（又称《金言集》）第二卷

使用权人可以在该土地上居住，但应以不妨碍土地所有人、也不妨碍从事农事劳作的人为限；他也不得将自己享有的权利出卖、出租或无偿授予他人。

### <a id="7.8.12"></a>7.8.12　乌尔比安《评萨宾》第十七卷

<a id="7.8.12.pr."></a>

**序言（pr.）** 如果遗赠给他的是宅院和庄园宅邸的使用权，他就应享有完整的使用权。更应认为，所有权人可以为收取收益而到场；在收获收益的期间，也应允许其住在那里。

<a id="7.8.12.1"></a>

**1.** 除居住权外，使用权人还享有散步和乘车出行的权利。萨宾和卡西乌斯认为，他可以使用日常所需的木柴、花园、果实、蔬菜、鲜花和水，但只能为使用而取用，不得以牟利为目的，也不得滥用。涅尔瓦持相同意见，并补充说，他还可以使用垫草和修枝；但不得使用树叶、橄榄油、谷物或其他收成。萨宾、卡西乌斯、拉贝奥和普罗库鲁斯进一步认为，对于土地上生长的物品，使用权人可以取用足以供自己及家人维持生活的数量，包括涅尔瓦不允许取用的那些物品。尤文提乌斯还认为，他可以与同席者和客人共同使用这些物品；我认为这一意见正确，因为应依受遗赠人的身份，对使用权人作较宽厚的对待。不过，我认为他只能在庄园宅邸中使用这些物品。至于果实、蔬菜、鲜花和木柴，尚须考察：他只能在原地使用，还是也可以运到城里？较好的解释是允许运到城里；如果土地上这些物品充足，运送它们并不构成沉重负担。

<a id="7.8.12.2"></a>

**2.** 如果遗赠给他的是牲畜的使用权，例如一群羊，拉贝奥说，他只能用羊群施肥，不得使用羊毛、羔羊或羊奶，因为这些属于收益。此外，我认为他也可以取用少量羊奶；毕竟，不应对死者的遗愿作过于严格的解释。

<a id="7.8.12.3"></a>

**3.** 如果遗赠的是牛群的使用权，他可以完整地使用牛群，包括耕地以及其他牛适用的用途。

<a id="7.8.12.4"></a>

**4.** 如果遗赠的是马群（*equitium*）的使用权，也应考察使用权人能否驯马，以及能否驾车时驾驭马匹。假如受遗赠人是战车驾手，而遗赠给他的是马匹的使用权，我认为他不得让这些马参加竞技会（*circenses*），因为那样做似乎是在出租马匹。但是，如果立遗嘱人知道他的职业和生活方式仍作此遗赠，就应认为立遗嘱人也考虑到了这种使用方式。

<a id="7.8.12.5"></a>

**5.** 如果遗赠给某人的是奴隶劳务的使用权，他可以让该奴隶为自己、子女和配偶服劳务；只要这些人一同使用该奴隶，就不视为把使用权授予了他人。不过，如果奴隶劳务的使用权遗赠给家子或奴隶，而该权利依法归属于父亲或主人，则后者只能要求该家子或奴隶本人使用该劳务，不能要求其权力支配下的其他人也使用。

<a id="7.8.12.6"></a>

**6.** 享有奴隶劳务使用权的人，不得出租该奴隶的劳务，也不得把使用权授予他人；拉贝奥持此意见。因为他本人应当使用奴隶的劳务，又怎能把劳务授予他人呢？不过，同一拉贝奥认为，如果使用权人租用了土地，可以让享有使用权的奴隶在那里劳作；因为使用其劳务时，究竟用于何事又有什么区别？因此，如果使用权人租下羊毛并须加工，就可以让享有使用权的女奴完成这项工作；同样，如果他承接了织制衣物、建造公寓楼或建造船舶的工作，也可以使用该奴隶的劳务完成这些工作。这并不违反萨宾的意见：女奴的使用权遗赠给某人后，不得把她派去从事纺织，也不得收取其劳务报酬，但可以合法地要求她为自己纺织羊毛。因为没有出租她的劳务，而只是完成自己承接的工作，所以这仍应视为为自己工作。奥克塔维努斯也赞同这一意见。

### <a id="7.8.13"></a>7.8.13　盖尤斯《评行省告示》第七卷

拉贝奥认为，也可以就奴隶或女奴本人的劳务向其本人收取报酬。

### <a id="7.8.14"></a>7.8.14　乌尔比安《评萨宾》第十七卷

<a id="7.8.14.pr."></a>

**序言（pr.）** 如果我通过享有使用权的奴隶订立要式口约，或由他受领交付，我是否取得权利？如果该行为使用的是我的财产，或者使用的是他的劳务，答案是否相同？如果使用的是他的劳务，行为就不生效，因为我们也不能出租他的劳务。但如果使用的是我的财产，我们认为，享有使用权的奴隶通过要式口约或受领交付而取得的财物归我所有；在这种情况下，我所利用的正是他的劳务。

<a id="7.8.14.1"></a>

**1.** 遗赠的是用益权还是收益权，二者并无区别：收益权中包含使用权，使用权中却不包含收益权。收益权不能脱离使用权而存在，使用权则可以不附收益权。由此，如果将收益部分在剔除使用权后遗赠给你，庞波尼乌斯在《评萨宾》第五卷中写道，该遗赠无效；如果在遗赠用益权之后又剥夺收益，他写道，应视为整个遗赠均被剥夺。但如果只遗赠收益而不包括使用权，则应视为设立了使用权；使用权本来也可以单独设立。反之，如果遗赠用益权后又剥夺使用权，阿里斯托写道，这不构成任何剥夺；这一意见较为宽厚。

<a id="7.8.14.2"></a>

**2.** 如果遗赠了使用权，又把收益权遗赠给同一人，庞波尼乌斯说，收益权会与使用权合并。他还说，如果使用权遗赠给你、收益权遗赠给我，我们二人都享有使用权，但只有我享有收益权。

<a id="7.8.14.3"></a>

**3.** 使用权可以归一人，收益权（不包括使用权）归另一人，所有权则归第三人。例如，某人拥有土地，将使用权遗赠给提图斯，其继承人随后又将收益权遗赠给你，或以其他方式设立该权利。

### <a id="7.8.15"></a>7.8.15　保罗《评萨宾》第三卷

<a id="7.8.15.pr."></a>

**序言（pr.）** 土地的使用权被遗赠时，使用权人可以从储藏室取用足够一年所需的物品，即使因此耗尽一处中等规模庄园的收益也无妨；因为他也可以如此使用房屋和奴隶，以致不留下任何收益给他人。

<a id="7.8.15.1"></a>

**1.** 土地使用权的受遗赠人不得禁止所有人为耕种土地而到那里活动，否则也就等于禁止所有人享有收益。同样，继承人也不得以任何方式妨碍受遗赠人依善良家父的标准行使其使用权。

### <a id="7.8.16"></a>7.8.16　庞波尼乌斯《评萨宾》第五卷

<a id="7.8.16.pr."></a>

**序言（pr.）** 如果土地的使用权连同其设备一并遗赠，属于土地设备的物品，其使用权也归受遗赠人；这如同这些物品的使用权被逐一明确遗赠给他一样。

<a id="7.8.16.1"></a>

**1.** 所有权人可以通过看守土地的人或公寓管理员看守土地或房屋，即使用益权人或使用权人不同意也可以；因为所有权人有维护地产边界的利益。无论用益权或使用权以何种方式设立，都应作此解释。

<a id="7.8.16.2"></a>

**2.** 对于我们仅享有使用权、并不享有收益权的奴隶，我们可以赠与他财物，也可以用自己的钱让他经商；他以这种方式取得的任何财物，都应归入我们的特有财产（*peculium*）。

### <a id="7.8.17"></a>7.8.17　阿非利卡努斯《疑问集》第五卷

房屋使用权遗赠给家子或奴隶，我认为该遗赠有效；对该权利的请求，也应以同时遗赠收益权时相同的方式进行。因此，无论家子或奴隶在场与否，父亲或主人都可以居住在这些房屋中。

### <a id="7.8.18"></a>7.8.18　保罗《评普劳提乌斯》第九卷

房屋的使用权在不包括收益权的情况下遗赠时，房屋的修缮维护费用应由继承人和使用权人共同承担。不过还须考察：如果继承人取得收益，是否应由其本人修缮；如果该物的性质使继承人不能取得收益，是否应强制受遗赠人修缮。这样的区分是有道理的。

### <a id="7.8.19"></a>7.8.19　保罗《评维泰利乌斯》第三卷

使用权不能按份遗赠，因为我们可以按份享有收益权，却不能按份享有使用权。

### <a id="7.8.20"></a>7.8.20　马尔切鲁斯《学说汇纂》第十三卷

奴隶的使用权遗赠给我，如果该奴隶担任店铺经理，而我在店铺中使用他的劳务，他所为的行为就为我取得权利；例如买卖货物时，他为我取得权利。如果他依我的指示通过交付受领物品，也同样如此。

### <a id="7.8.21"></a>7.8.21　莫德斯蒂努斯《规则集》第二卷

水的使用权具有人身专属性，因此不能移转给使用权人的继承人。

### <a id="7.8.22"></a>7.8.22　庞波尼乌斯《评昆图斯·穆基乌斯》第五卷

<a id="7.8.22.pr."></a>

**序言（pr.）** 神圣的哈德良皇帝曾裁定：如果遗赠给某些人的是森林使用权，也应视为遗赠了收益权；因为如果受遗赠人不能像用益权人那样砍伐并出售森林中的木材，他们就无法从该遗赠中获得任何利益。

<a id="7.8.22.1"></a>

**1.** 即使房屋使用权的受遗赠人能力有限，以致无法占用整幢房屋，他人仍不得使用空置部分，因为使用权人可以在不同时间使用整幢房屋；房屋所有人也会根据不同时期的需要使用其中某些部分，而不使用另一些部分。

<a id="7.8.22.2"></a>

**2.** 使用权遗赠后，如果受遗赠人行使的使用权超过应有范围，那么负责裁判其应如何使用该权利的法官应当如何处理？应命其不得以超出应有范围的方式行使使用权。

### <a id="7.8.23"></a>7.8.23　保罗《评涅拉提乌斯》第一卷

涅拉提乌斯说：使用权标的物的所有权人，绝不能改变该物的性质。保罗说：因为他不得使使用权人的地位恶化；即使把该物改成较好的状态，也会使使用权人的地位恶化。
