## 7.6.0　论请求用益权或否认其归属于他人（*Si usus fructus petetur vel ad alium pertinere negetur*）

### <a id="7.6.1"></a>7.6.1

乌尔比安《评萨比努斯》第十八卷

<a id="7.6.1.pr."></a>

**序言（pr.）** 如果某一用益权土地享有地役权，马尔凯卢斯在其第八卷中赞同尤利安所载拉贝奥和涅尔瓦的意见：他们认为，用益权人不能就该地役权本身提起确认之诉，但可以主张用益权；因此，邻地所有人若不允许其通行和驱赶牲畜，就应对他承担责任，犹如不允许其使用、收益一样。

<a id="7.6.1.1"></a>

**1.** 用益权遗赠需要有使权利得以行使的辅助条件；缺少这些条件，人便无法使用、收益。因此，遗赠用益权时，必须同时有通路随之而来。甚至，若有人遗赠某处的用益权，却附加条件说继承人无须提供通路，该附加条件也应视为无效。同样，遗赠用益权后又剥夺通行权的，该剥夺无效，因为通行权始终随用益权而来。

<a id="7.6.1.2"></a>

**2.** 但是，如果遗赠的用益权无法经由遗产中的土地通达，用益权人提起遗嘱之诉时，当然可以请求使该用益权连同通路一并提供给自己。

<a id="7.6.1.3"></a>

**3.** 遗赠用益权时，是否只应向用益权人提供通达之路（*aditus*）和步行通道（*iter*），还是也应提供道路（*via*），庞波尼乌斯在《评萨比努斯》第五卷中对此存疑；他的意见是正确的：凡行使用益权所需要的通行条件，均应提供给用益权人。

<a id="7.6.1.4"></a>

**4.** 继承人是否还应向用益权人提供其他便利和地役权，例如采光和用水？我认为，只应强令其提供那些缺少便绝对无法使用该物的便利；如果虽有不便仍能使用，就不应强令提供。

### <a id="7.6.2"></a>7.6.2

庞波尼乌斯《评萨比努斯》第五卷

如果某人依据遗嘱向继承人请求土地的用益权，而继承人曾砍伐树木、拆毁建筑，或以其他方式使该用益权状况恶化——例如设定地役权，或解除邻地所负担的地役权——那么法官应当审慎查明，在受理诉讼之前该土地处于何种状态，以确保用益权人的利益得到维护。

### <a id="7.6.3"></a>7.6.3

尤利安《学说汇纂》第七卷

某人基于遗嘱信托原因取得交付给他的用益权；如果他在一段时间内不再行使用该权利，而这段时间若其已依法取得该权利，足以使其丧失该权利，那么他不应享有请求恢复该用益权的诉权。因为，仅取得用益权占有而未取得所有权的人，反而享有更多权利，这显然荒谬。

### <a id="7.6.4"></a>7.6.4

尤利安《学说汇纂》第三十五卷

一块土地在扣除用益权后遗赠给提提乌斯；同一土地的用益权则附条件遗赠给塞姆普罗尼乌斯。我认为，在条件成就之前，用益权应随所有权归于提提乌斯。尽管通常认为，土地在扣除用益权后遗赠的，用益权归继承人保有；但家主在扣除用益权后将土地遗赠给一人、又将用益权附条件遗赠给另一人时，并非意在使用益权留归继承人。

### <a id="7.6.5"></a>7.6.5

乌尔比安《评告示》第十七卷

<a id="7.6.5.pr."></a>

**序言（pr.）** 只有享有用益权的人，才能主张自己享有使用、收益之权；土地所有人不能这样主张，因为享有所有权的人并无独立于所有权之外的使用、收益之权：自己的土地不能役属于自己。任何人都应依据自己的权利，而非他人的权利提起诉讼。虽然所有人可以对用益权人提起否认之诉，但他所主张的似乎仍是自己的权利，而非他人的权利：他否认用益权人未经自己同意有权使用、收益，或者主张自己有权禁止其使用、收益。若提起诉讼的人并非所有权人，即使用益权人也不享有使用权，前者仍会胜诉，因为依占有人地位优于他人的规则，占有人即使并无权利也居于优势。

<a id="7.6.5.1"></a>

**1.** 用益权人提起物权之诉，是只能对所有权人提起，还是也能对任何占有人提起？尤利安在《学说汇纂》第七卷中写道，该诉可对任何占有人提起。因为，即使地役权应由某一用益权土地享有，用益权人也应针对邻地所有人主张用益权，而非主张地役权本身。

<a id="7.6.5.2"></a>

**2.** 如果土地的一部分设有用益权，可以就此提起物权之诉；无论是有人主张自己享有该用益权，还是有人否认该用益权属于他人，均可如此。

<a id="7.6.5.3"></a>

**3.** 显而易见，在这些关于用益权提起的诉讼中，也包括对孳息的请求。

<a id="7.6.5.4"></a>

**4.** 如果在用益权诉讼的诉讼标的确定之后，用益权已经终止，此后是否不再负有给付孳息的义务？我认为，义务确实终止。因为，即使用益权人已经死亡，庞波尼乌斯在《评萨比努斯》第四十卷中也写道，应仅向其继承人授予请求此前孳息的诉权。

<a id="7.6.5.4a"></a>

**4a.** 用益权人胜诉后，应向其返还全部相关利益。因此，如果遗赠的是奴隶的用益权，占有人就应返还其从用益权人的财产或该奴隶的劳务中所取得的一切。〔“omnis causa”意为应恢复用益权人所涉的全部利益状态；此处依下句所举财产及劳务所得译出。〕

<a id="7.6.5.5"></a>

**5.** 如果由于期间经过，用益权已经消灭，而一人实际占有该物、另一人则出面参加诉讼，仅使该用益权重新设立即不足够；出面诉讼者还必须就用益权遭受追夺提供担保。因为，假如占有人已将奴隶或土地设质，而受质人依法禁止其使用，该怎么办？因此，必须取得相应担保。

<a id="7.6.5.6"></a>

**6.** 正如用益权人提起确认用益权之诉时应获给付孳息一样，所有权人提起否认之诉时也应如此；但在所有这些情形中，只有起诉者并非占有人时才请求孳息（因为占有人也可以提起这些诉讼）；若起诉者已经占有该物，就不能以孳息名义取得任何给付。那么，法官的职责是什么？就是确保用益权人能够安稳地行使用益权，并确保所有权人不受妨扰。

### 7.6.6

保罗《评告示》第二十一卷

被提起用益权之诉的人，如果其并无诈欺而停止占有，应判其免责；但如果其主动出面参加诉讼，并以占有人身份接受用益权之诉，则应判其承担责任。
