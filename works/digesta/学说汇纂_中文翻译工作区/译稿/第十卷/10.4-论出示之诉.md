## 10.4.0　论出示之诉（*Ad exhibendum*）

### <a id="10.4.1"></a>10.4.1　乌尔比安《评告示》第二十四卷

这项诉讼极为必要，在日常生活中经常使用，尤其是为返还原物之诉而设。

### <a id="10.4.2"></a>10.4.2　保罗《评告示》第二十一卷

所谓出示，就是使某物处于公开可供察看的状态，从而使起诉者能够检验该物。

### <a id="10.4.3"></a>10.4.3　乌尔比安《评告示》第二十四卷

<a id="10.4.3.pr."></a>

**序言（pr.）** 在本项诉讼中，原告应当知悉并陈述其所主张事项的事实根据。

<a id="10.4.3.1"></a>

**1.** 提起出示之诉的人，不一定声称自己是所有人，也无须证明自己是所有人，因为提起出示之诉的事由有很多。

<a id="10.4.3.2"></a>

**2.** 此外，本诉还应注意：被告拒不配合时，可以根据原告在诉讼中的估价宣誓判其承担责任，具体数额由法官核定。

<a id="10.4.3.3"></a>

**3.** 这是一项对人之诉，凡准备提起任何一种对物之诉的人均可提起，包括质权之诉、塞尔维安之诉或抵押之诉；后两者为债权人所享有。

<a id="10.4.3.4"></a>

**4.** 庞波尼乌斯说，准备请求用益权的人也可以提起出示之诉。

<a id="10.4.3.5"></a>

**5.** 如果某人希望就某物申请禁令，使该物得到出示，也应准许其请求。

<a id="10.4.3.6"></a>

**6.** 同样，如果我想依遗嘱选择一名奴隶或其他由我选择的物，显然我可以提起出示之诉，以便在该物出示后提起返还原物之诉。

<a id="10.4.3.7"></a>

**7.** 如果某人准备提起诺克萨之诉，他有必要提起出示之诉。因为，如果主人准备应诉，而原告却无法指明其所主张的奴隶——例如原告不认识该奴隶，或不知道其姓名——怎么办？难道不应公平地命令出示奴隶群体，以便原告辨认实施致害行为的奴隶吗？应根据具体情形，通过清点奴隶，指明原告所提诺克萨之诉针对的是哪一名奴隶。

<a id="10.4.3.8"></a>

**8.** 如果继承人以外之人请求出示遗嘱文书、遗嘱附录或其他与遗嘱有关的文件，应当说，不得提起本项诉讼；因为为此目的设有的禁令已足以救济。庞波尼乌斯亦作此说。

<a id="10.4.3.9"></a>

**9.** 应当知道，不仅前述之人可以提起出示之诉，凡对出示该物具有利害关系者也可以提起。因此，法官只须概括审查原告是否具有利害关系，而不必审查该物是否属于原告；随后应命令出示该物，或者认定原告没有利害关系而不予命令。

<a id="10.4.3.10"></a>

**10.** 尤利安还进一步指出，即使我尚不能提起返还原物之诉，只要出示该物与我有利害关系，我也可以暂时提起出示之诉。例如，遗嘱将某一名奴隶遗赠给我，但该奴隶须由提丢斯选择；我可以提起出示之诉，因为我有利害关系，须先让提丢斯作出选择，我随后才能提起返还原物之诉，尽管出示之后并非由我选择该奴隶。

<a id="10.4.3.11"></a>

**11.** 如果有人对我提起出示之诉，我不能仅以自己因该诉而负有返还义务、因而对此有利害关系为由，再提起出示之诉。但这还不够；否则，以诈欺方式使自己不再占有该物的人也能提起出示之诉，尽管他既不准备请求返还原物，也不准备申请禁令；窃贼或强盗也会如此，这显然不正确。因此，涅拉提乌斯作出精当界定：审理出示之诉的法官，应审查原告是否具有正当且合理的诉讼理由，足以说明其为何请求出示该物。

<a id="10.4.3.12"></a>

**12.** 庞波尼乌斯写道，数人可以分别就同一奴隶正当地提起出示之诉。例如，该奴隶属于第一人，第二人对其享有用益权，第三人主张自己占有该奴隶，第四人声称该奴隶已质押给自己。于是，所有人均可提起出示之诉，因为出示该奴隶与他们各自均有利害关系。

<a id="10.4.3.13"></a>

**13.** 庞波尼乌斯接着指出，依据本诉所授予的裁判授权，法官还应审查占有人提出的抗辩。如果某项抗辩显而易见，足以轻易驳回原告，就应判占有人胜诉；如果抗辩较为复杂，或需要深入审理，则应命令出示该物，并将该抗辩留待本案的正式诉讼处理。不过，对某些抗辩，审理出示之诉的法官无论如何都应亲自裁决，例如合意抗辩、诈欺抗辩、宣誓抗辩及既判事项抗辩。

<a id="10.4.3.14"></a>

**14.** 有时，基于衡平，即使不得提起出示之诉，也应给予事实之诉；尤利安讨论过这种情况。他说：“我妻子的奴隶抄录了我的账目，而这些账目由你占有；我请求你将其出示。”尤利安认为，如果账目写在我的纸上，可以提起本项诉讼，因为我也可以请求返还该纸；毕竟，纸是我的，写在上面的内容也归我。但是，如果纸不是我的，由于我不能请求返还该纸，也不能提起出示之诉；因此，应给予我一项事实之诉。

<a id="10.4.3.15"></a>

**15.** 应当知道，对本项诉讼而言，被告不仅包括依市民法占有该物的人，也包括事实上控制该物的人。因此，通常认为，收受质物的债权人也负有出示义务：

### <a id="10.4.4"></a>10.4.4　庞波尼乌斯《评萨宾》第六卷

此外，也可以对受寄人、借用人或承租人提起本诉。

### <a id="10.4.5"></a>10.4.5　乌尔比安《评告示》第二十四卷

<a id="10.4.5.pr."></a>

**序言（pr.）** 塞尔苏斯写道：如果某人承运货物以便运出，并将货物存放在仓库中，可以对承运人提起出示之诉；如果承运人死亡而有继承人，则应对继承人提起诉讼；如果没有继承人，则应对仓库保管人提起诉讼。因为，如果没有人占有货物，仓库保管人就应当算作占有人，或者至少是能够出示货物的人。塞尔苏斯还问：承运人是如何占有货物的？难道是因为他持有质物吗？这一情形表明，凡有能力出示该物之人，也可能负有出示义务。

<a id="10.4.5.1"></a>

**1.** 尤利安写道，为保管财物或遗赠而占有该物之人，负有出示之诉责任；以用益权人身份持有该物之人也同样如此，尽管其未必构成占有人。尤利安据此探讨这些人应当如何出示该物。他说，前一种人应使原告取得占有，而被告则以保管该物为由继续占有；用益权人则应使原告占有该物，而被告仍使用并收益该物。

<a id="10.4.5.2"></a>

**2.** 尤利安还写道，买受人未返还砍伐所得物时，负有出示之诉责任，责任数额依原告在诉讼中的宣誓估价确定；但买受人须仍占有该物，或以诈欺方式使自己不再占有。

<a id="10.4.5.3"></a>

**3.** 塞尔苏斯还写道，如果你把粪肥堆在我的场地上，我可以提起出示之诉，要求你将其清走，但你必须全部清除；否则不能认为已经履行。

<a id="10.4.5.4"></a>

**4.** 涅拉提乌斯写道，如果木筏被河水冲到他人土地上，可以对该土地所有人提起出示之诉。涅拉提乌斯还询问，该土地所有人是否只须就未来损害提供担保，还是也须就既往损害提供担保；他认为，既往损害也应提供担保。

<a id="10.4.5.5"></a>

**5.** 如果有物从废墟中坠落到你的场地或房屋内，即使你并未占有该物，也负有出示之诉责任。

<a id="10.4.5.6"></a>

**6.** 如果某人虽占有该物，却没有能力将其返还，例如奴隶正在逃亡，就不负出示之诉责任；但他仍须提供担保，承诺一旦取得对该奴隶的控制，便予以出示。如果奴隶并未逃亡，而是被允许在其所愿之处居住，或者被送往外地，或在主人的庄园中工作，也应作相同处理：此人仅须提供担保。

### <a id="10.4.6"></a>10.4.6　保罗《评萨宾》第十四卷

宝石嵌在他人的金器中，或印章嵌在烛台中，不能提起返还原物之诉；但可以提起出示之诉，要求将其取出。十二表法所称嵌接于建筑物的梁木则不同：既不得提起出示之诉，因为该法禁止拆除；依据同一法律，可以提起梁木嵌接之诉，请求双倍赔偿。

### <a id="10.4.7"></a>10.4.7　乌尔比安《评告示》第二十四卷

<a id="10.4.7.pr."></a>

**序言（pr.）** 有些人认为，在十二表法中，“梁木”一词应解释为包括一切建筑材料；这种理解是正确的。

<a id="10.4.7.1"></a>

**1.** 如果你把我的车轮装到你的车辆上，就负有出示之诉责任；庞波尼乌斯也是这样写的，即使你依市民法并不占有该车轮。

<a id="10.4.7.2"></a>

**2.** 如果你把我的木板接到橱柜或船上，把我的把手接到杯子上，把装饰浮雕嵌进酒杯，或将我的紫布织进衣服，或将我的雕像手臂接合到雕像上，也应作相同处理。

<a id="10.4.7.3"></a>

**3.** 市政共同体也可以被诉请出示，因为其具有返还能力；显然，它们也可以占有并取得时效。同样规则也适用于行会及其他法人团体。

<a id="10.4.7.4"></a>

**4.** 如果某人在争讼程序确定时并未占有该物，但此后在判决前开始占有，我们认为应判其承担责任，除非其出示并返还该物。

<a id="10.4.7.5"></a>

**5.** 如果某人在诉讼成立时占有该物，后来又在没有诈欺的情况下停止占有，应判其胜诉。庞波尼乌斯说，虽然可以责备他没有立即返还，而是任由对方与其成立诉讼关系，但仍应如此处理。

<a id="10.4.7.6"></a>

**6.** 庞波尼乌斯还写道，如果某人在争讼程序确定时占有该物，后来停止占有，之后又基于相同或不同原因重新开始占有，则除非出示该物，否则应判其承担责任。

<a id="10.4.7.7"></a>

**7.** 庞波尼乌斯在同处恰当地补充说，提起出示之诉的人，在两个时点都应有利害关系：既在诉讼成立时，也在作出判决时；拉贝奥亦持此说。

### <a id="10.4.8"></a>10.4.8　尤利安《学说汇纂》第九卷

如果某人既未占有该物，也未以诈欺方式使自己不再占有，而有人对其提起出示之诉；此人死亡后，其继承人占有该物，则继承人应被命令出示该物。因为，如果我请求返还一块土地或一个奴隶，而继承人基于同一原因开始占有，就应被命令返还。

### <a id="10.4.9"></a>10.4.9　乌尔比安《评告示》第二十四卷

<a id="10.4.9.pr."></a>

**序言（pr.）** 尤利安写道：如果某人杀死自己占有的奴隶，或将其占有移转给他人，或以其他方式毁损该物，使其无法继续存在，就因诈欺而使自己不再占有，故负出示之诉责任。因此，如果某人倾倒葡萄酒、橄榄油或其他物品，或将其打碎，也负有出示之诉责任。

<a id="10.4.9.1"></a>

**1.** 你树上的橡实掉到我的土地上，我放入牲畜将其吃掉：我可以提起何种诉讼？庞波尼乌斯写道，如果我故意放入牲畜让其吃掉橡实，可以提起出示之诉。即使橡实尚在，而你不许我拾取，我也负有出示之诉责任；正如有人不许我取走被冲到其土地上的木料一样。我们赞同庞波尼乌斯的意见，无论橡实仍在还是已经被吃掉，均同。若橡实尚在，并且我已提供损害担保，我还可以提起拾取橡实的禁令，使我每隔三日便可拾取一次。

<a id="10.4.9.2"></a>

**2.** 如果某人使该物转到他人手中，只要其行为出于诈欺，就应认为他以诈欺方式使自己不再占有。

<a id="10.4.9.3"></a>

**3.** 萨宾说，如果某人以较差的状态出示该物，也同样负有出示之诉责任。但只有在其以诈欺方式将该物转变为另一物体时，此说才当然正确，例如把杯子熔成金属块。尽管他出示了金属块，仍应承担出示之诉责任，因为物的形态改变，几乎等同于其实质被毁灭。

<a id="10.4.9.4"></a>

**4.** 马尔凯卢斯写道：你受遗赠十枚附条件给付的钱币，我则无条件取得十枚钱币的用益权；继承人在条件尚未成就时，未要求用益权人提供担保，便将十枚钱币交付给他。继承人应负出示之诉责任，仿佛其以诈欺方式使自己不再占有该款项。其诈欺在于：他没有要求用益权人提供担保，导致你的遗赠落空，使你再也不能请求返还这些钱币。但是，只有遗赠条件成就时，出示之诉才可提起。你本可以通过遗赠担保要式口约保护自己；如果已经如此保护，就不需要出示之诉。不过，如果继承人不知道你的遗赠，因而没有向用益权人要求充分担保，马尔凯卢斯说，出示之诉不适用，因为不存在诈欺；但他认为，仍应给予受遗赠人针对用益权人的事实之诉。

<a id="10.4.9.5"></a>

**5.** 就本项诉讼而言，出示是指：在诉讼成立时，使该物处于其原有状态，以便权利人能够取得该物，并行使其原拟提起的诉讼，且不因任何情形而损害该诉讼的主张；尽管本案请求的是出示，而非返还。

<a id="10.4.9.6"></a>

**6.** 因此，如果被告在争讼程序确定后才出示已经因时效取得的物，就不应认为其已履行出示义务，因为原告已丧失其原来的诉讼主张。因此，除非原告愿意在另定日期重新提出其主张，并依法律核算孳息，否则不应判被告胜诉。

<a id="10.4.9.7"></a>

**7.** 但是，由于本项诉讼旨在使原告恢复到其应有的处境，萨宾认为，还应返还奴隶妇女所生的子女，无论她在诉讼成立时已经怀孕，还是后来才怀孕；庞波尼乌斯也赞同此意见。

<a id="10.4.9.8"></a>

**8.** 此外，若因未出示或迟延出示而使原告丧失某种利益，法官应对此估价。因此，涅拉提乌斯说，应估算原告所受的利益损失，而非物本身的价值；这种利益有时低于物的价值。

### <a id="10.4.10"></a>10.4.10　保罗《评告示》第二十六卷

如果原告仅能在特定期限内选择某物，而审理被拖延至出示已无意义的时点，应保全原告的利益；但如果继承人并未导致诉讼成立时无法出示该物，就应判继承人胜诉。

### <a id="10.4.11"></a>10.4.11　乌尔比安《评告示》第二十四卷

<a id="10.4.11.pr."></a>

**序言（pr.）** 如果由于奴隶未被出示而使继承权丧失，法官应依其职权公平地估算该继承权损失。

<a id="10.4.11.1"></a>

**1.** 我们再来看应当在何处出示该物，以及由谁承担费用。拉贝奥说，应在诉讼成立时该物所在之处出示；由原告承担风险和费用，将该物运至诉讼进行之地。他还说，占有人应负责喂养、穿衣并照料奴隶。但是，我认为有时这些费用也应由原告承担，例如该奴隶原本通常靠自己的劳务或技艺维持生计，如今却被迫闲置。如果奴隶被寄存于官署，原告请求出示时也应承担其食物费用，除非占有人原本就负责供养该奴隶；如果占有人过去一直供养，既然仍继续供养，也可以不拒绝承担其食物费用。但是，如果被告故意将物品转移至偏僻之处，使原告出示该物更为不便，则被告有时必须自费并承担风险，在诉讼进行之地出示该物，以免其诡计使其获益。

<a id="10.4.11.2"></a>

**2.** 如果某人因多件物品被诉，并且在争讼程序确定时占有全部物品，即使后来在没有诈欺的情况下停止占有其中一些，也应判其承担责任，除非其出示自己仍能出示的物品。

### <a id="10.4.12"></a>10.4.12　保罗《评告示》第二十六卷

<a id="10.4.12.pr."></a>

**序言（pr.）** 如果某人想请求确认一个自由人的自由身份，可以提起本项诉讼，请求出示该人。

<a id="10.4.12.1"></a>

**1.** 如果家子有能力出示该物，也应依本诉承担责任。

<a id="10.4.12.2"></a>

**2.** 尤利安说，如果原告基于同一事由再次提起出示之诉，应以抗辩阻止。但是，如果出现新的事由，例如原告为提起返还原物之诉而请求出示，在争讼程序确定后又从他人处取得该物，就构成新的事由，因此该抗辩不妨碍他再次起诉。同样，如果有人为提起盗窃之诉而先行请求出示，之后又发生了一次盗窃，也可再次提起诉讼。最后，如果某人为行使遗嘱选择权而提起出示之诉，在争讼程序确定后又依另一份遗嘱取得选择权，也可以再次提起出示之诉。

<a id="10.4.12.3"></a>

**3.** 如果某人明知葡萄属于他人，仍将其酿成葡萄酒；或将他人的橄榄榨成橄榄油；或将他人的羊毛织成衣物，就这些原物及其加工所得物均负有出示之诉责任，因为由我们的物制成之物，原则上仍属于我们。

<a id="10.4.12.4"></a>

**4.** 如果奴隶在诉讼成立后死亡，即使占有人并无诈欺或过错，有时仍应判其承担相当于原告利益的损害额，即原告本可在诉讼成立时取得出示的利益；如果显然奴隶死于一种本不会发生的情形——假如当时已经出示该奴隶——就更应如此处理。

<a id="10.4.12.5"></a>

**5.** 如果基于正当理由不能立即出示该物，应依照法官命令提供担保，承诺在指定日期出示。

<a id="10.4.12.6"></a>

**6.** 继承人提起本诉，是以自己名义而非继承人身份提起；占有人之继承人也以自己名义承担责任。因此，无须再讨论本诉是否应由继承人提起或针对继承人提起。当然，如果被继承人实施诈欺，且遗产因此获益，例如取得该物的价款，则可以对继承人提起诉讼。

### <a id="10.4.13"></a>10.4.13　盖尤斯《裁判官告示中关于自由身份诉讼一题》

如果据称某人非法拘留了一名自由人，可以对被指拘留者申请命令其出示该人；因为在这种情形下，出示之诉似乎并无用处，本诉被认为仅适用于具有金钱利益之人。

### <a id="10.4.14"></a>10.4.14　庞波尼乌斯《评萨宾》第十四卷

如果丈夫明知妻子赠与自己的钱币尚未成为其所有，却将其用于购买物品，就以诈欺方式使自己不再占有该物，因此负有出示之诉责任。

### <a id="10.4.15"></a>10.4.15　庞波尼乌斯《评萨宾》第十八卷

我的宝藏在你的土地里，而你不许我挖掘。由于你并未移动宝藏，拉贝奥说，我不能就此正当地提起盗窃之诉或出示之诉，因为你既未占有宝藏，也未以诈欺方式使自己不再占有；毕竟，你可能不知道土地中有宝藏。然而，如果我宣誓自己并非出于恶意而提出请求，公平地说，应授予我禁令或诉讼，并命令你提供损害担保：如果我已依规提供因施工产生的损害担保，你就不得以暴力阻止我挖出、取走并运走宝藏。如果该宝藏本身也是被盗之物，还可以提起盗窃之诉。

### <a id="10.4.16"></a>10.4.16　保罗《评萨宾》第十卷

如果奴隶持有某物，主人应以本人名义承担出示之诉责任。但是，如果奴隶未经主人知情，以诈欺方式使该物不再由其持有，则可以奴隶名义提起诺克萨盗窃之诉或诺克萨诈欺之诉；不得另行设立准用的出示之诉。

### <a id="10.4.17"></a>10.4.17　乌尔比安《诸审判庭》第九卷

如果有人出示一名身体受损或残缺的奴隶，就出示之诉而言应判其胜诉；毕竟他已作出出示，而且这种出示并不妨碍原告提起本案的直接诉讼，原告仍可依据《阿奎利亚法》就该损害提起诉讼。

### <a id="10.4.18"></a>10.4.18　乌尔比安《意见集》第六卷

即使债务已经清偿、债务文书也已作废，且质物已经解除担保，债权人仍可提起诉讼，请求由债务人以外之人出示与该契约有关的文书。

### <a id="10.4.19"></a>10.4.19　保罗《阿尔芬《学说汇纂》节编》第四卷

凡对此具有利害关系的人，均可提起出示之诉。有人询问，这项诉讼能否使对方出示账簿，因为出示这些账簿对提问者极为重要。答复说，不应曲解市民法或拘泥字面，而应注意人们说话时的真实意图。否则，某一学科的爱好者也可以声称，出示某些书籍与自己有关，因为如果书籍出示并由其阅读，他就会变得更有学识、更优秀。

### <a id="10.4.20"></a>10.4.20　乌尔比安《法学规则》第二卷

为进行审讯，可以就奴隶实施的不法行为提起出示之诉，以追查知情共犯。
