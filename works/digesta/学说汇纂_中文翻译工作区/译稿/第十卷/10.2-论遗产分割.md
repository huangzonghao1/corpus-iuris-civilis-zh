# 第十卷

<a id="10.2"></a>

## 10.2.0　论遗产分割之诉（*Familiae erciscundae*）

### <a id="10.2.1"></a>10.2.1　盖尤斯《评行省告示》第七卷

<a id="10.2.1.pr."></a>

**序言（pr.）** 此项诉讼源自《十二表法》。共同继承人希望脱离共有关系，因此有必要设立某种诉讼，以便在他们之间分配遗产。

<a id="10.2.1.1"></a>

**1.** 即使某人并未占有自己的遗产份额，他仍依市民法当然享有此项诉讼。但是，如果占有人否认该人为共同继承人，可以通过以下抗辩排除其请求：“本案不得对遗产归属造成先决影响。”如果该人占有了该份额，即使他人否认其为继承人，这一抗辩也不会对他造成不利。因此，在这种情形下，审理本案的法官应当自行查明其是否为共同继承人；因为如果他不是共同继承人，就不应将任何财产判归他，也不应判令其对方当事人向他给付。

### <a id="10.2.2"></a>10.2.2　乌尔比安《评告示》第十九卷

<a id="10.2.2.pr."></a>

**序言（pr.）** 遗产分割之诉可以分割遗产，无论遗产是依据遗嘱还是无遗嘱继承规则承受，是依《十二表法》或其他法律承受，还是依元老院决议、皇帝敕令承受。一般而言，只有能够提起遗产请求之诉的人的遗产，才能通过此诉分割。

<a id="10.2.2.1"></a>

**1.** 如果依神化的庇护皇帝之敕令，有四分之一遗产份额归某一经 *adrogatio* 收养之人承受，由于此人既不成为继承人，也不取得遗产占有人的地位，就应当允许其提起必要的遗产分割准诉讼。

<a id="10.2.2.2"></a>

**2.** 军人家子的军营特有产也是如此。更有力的意见可以主张，依皇帝敕令，该财产已成为遗产，因此可以提起此项诉讼。

<a id="10.2.2.3"></a>

**3.** 在遗产分割之诉中，每一名继承人都兼具被告和原告的地位。

<a id="10.2.2.4"></a>

**4.** 毫无疑问，即使有数名继承人，也可以仅由其中部分继承人提起遗产分割之诉。

<a id="10.2.2.5"></a>

**5.** 虽然债权或债务（*nomina*）不纳入此项诉讼，但如果当事人已通过要式口约约定如何分割这些权利，并约定遵守该分割方案、彼此授予诉权并指定对方为自己事务的代理人，就应当遵循该分割方案。

### <a id="10.2.3"></a>10.2.3　盖尤斯《评行省告示》第七卷

**正文** 有时，法官应当将各项债权和债务分别全额分配给各继承人，因为分割后分别清偿或追收，常常会造成相当大的不便。但这种分配并不意味着某一继承人单独负担全部债务，或某一继承人单独享有全部债权；而是说，如果提起诉讼，该继承人可以部分以自己的名义、部分以代理人名义起诉；如果被提起诉讼，也可以部分以自己的名义、部分以代理人名义应诉。债权人仍可自行决定向各继承人中的任何一人提起诉讼；与此同时，各继承人也有权以自己的名义指定替代之人，由该人承受法官依职权转移给他的诉讼负担。

### <a id="10.2.4"></a>10.2.4　乌尔比安《评告示》第十九卷

<a id="10.2.4.pr."></a>

**序言（pr.）** 除债权或债务外，其他财产均纳入此项诉讼。如果某项债权被遗赠给一名继承人，该继承人可以通过遗产分割之诉取得该债权。

<a id="10.2.4.1"></a>

**1.** 有害药物和毒药虽纳入本案审理，但法官绝不应介入处置；法官应当履行善良无辜之人的职责。对于被禁读的书籍——例如魔法书或类似书籍——也应当如此处理；这些物品都应立即销毁。

<a id="10.2.4.2"></a>

**2.** 通过侵吞公款、亵渎圣物、暴力、劫掠或袭击所取得的财物，也不予分割。

<a id="10.2.4.3"></a>

**3.** 法官还应当命令遗嘱文书留存于继承份额较大的一方，或者存放在神庙中。拉贝奥也写道，遗产出售后，应当存放遗嘱文书的副本；继承人须提供副本，而原件则由其本人留存或存放在神庙中。

### <a id="10.2.5"></a>10.2.5　盖尤斯《评行省告示》第七卷

**正文** 如果遗产中有债务凭证，法官应当确保凭证由继承份额较大的人保管；其他继承人应制作经核对的副本，并提供担保，保证在实际需要时出示原件。如果继承人份额相等，且彼此无法就由谁保管达成一致，就应当抽签决定；也可以经一致同意或表决选出一名友人代为保管；或者将凭证存放在神庙中。

### <a id="10.2.6"></a>10.2.6　乌尔比安《评告示》第十九卷

**正文** 我与庞波尼乌斯都不赞成将遗产文书交由竞价最高者保管，即让竞价胜出之人取得遗产文书。

### <a id="10.2.7"></a>10.2.7　维诺尼乌斯《要式口约》第七卷

**正文** 如果一名继承人有一名附条件加入的共同继承人，或者有一名共同继承人被敌人俘获，而他声称自己是唯一继承人并提起诉讼胜诉；之后，共同继承人的条件成就，或者该共同继承人依复归权（*postliminium*）返回，那么胜诉的利益是否应与他分享？毫无疑问，胜诉人享有全额的既判事项之诉。应当给予共同继承人选择权：要么与其分享胜诉所得，要么允许其自行提起诉讼——该选择权应交给在另一继承人胜诉后才成为继承人、或才返回罗马公民共同体的人。同样的规则也适用于后来出生的遗腹子。不能因这些人保持沉默而归咎于他们，因为他们是在共同继承人胜诉之后才取得遗产继承权的。

### <a id="10.2.8"></a>10.2.8　乌尔比安《评告示》第十九卷

**正文** 庞波尼乌斯写道，如果账簿被预先遗赠给某一继承人，在共同继承人复制账簿之前，不得将其交付给该继承人。他还说，如果管理奴隶被遗赠，也须待其交代账目后方可交付。我们还须考虑，是否应要求其提供担保，保证在共同继承人请求账目或被遗赠的管理奴隶时，能够向其提供。因为管理奴隶往往需要原始账簿，以便查明后来出现、且关系到其职责的事项；因此，他有必要就此向共同继承人提供担保。

<a id="10.2.8.1"></a>

**1.** 庞波尼乌斯还说，从鸽舍放飞、平日会飞回来的鸽子，应纳入遗产分割之诉；只要它们仍保持飞回我们这里的习性，就仍然属于我们。因此，如果有人捕获这些鸽子，我们可以提起盗窃之诉。蜜蜂也应作相同处理，因为它们计入我们的财产。

<a id="10.2.8.2"></a>

**2.** 庞波尼乌斯还认为，如果我们的牲畜被野兽捕获，只要牲畜从野兽那里逃脱，仍应纳入遗产分割之诉。因为他认为，较妥当的看法是：被狼或其他野兽捕获的牲畜，只要尚未被其吞食，就不丧失我们的所有权。

### <a id="10.2.9"></a>10.2.9　保罗《评告示》第二十三卷

**正文** 继承人已经以取得时效取得的财物，如果这些财物原先是交付给被继承人的，也纳入此项诉讼；被继承人生前买入、后来交付给继承人的财物，也同样纳入：

### <a id="10.2.10"></a>10.2.10　乌尔比安《评告示》第十九卷

**正文** 此外，属于我们遗产的土地也纳入分割；缴纳地租的土地或地上权土地亦然。被继承人虽以善意占有、但实际上属于他人的财物，也同样纳入。

### <a id="10.2.11"></a>10.2.11　保罗《评告示》第二十三卷

**正文** 已出生的子嗣，包括在遗产承受后才出生者，也纳入分割。

### <a id="10.2.12"></a>10.2.12　乌尔比安《评告示》第十九卷

<a id="10.2.12.pr."></a>

**序言（pr.）** 萨宾写道，即使在争讼程序确定之后，财物仍可纳入遗产分割之诉，并可判归一方。

<a id="10.2.12.1"></a>

**1.** 如果遗产中的奴隶从第三人处取得某物，也适用相同规则。

<a id="10.2.12.2"></a>

**2.** 附条件遗赠的财物，在条件成就前属于继承人，因此纳入遗产分割之诉，也可以连同其附随条件一并判归一方：如果条件成就，该财物就从受判归之人处取回；如果条件未成就，财物便返还给原先留下该财物的继承人。同一规则也适用于附条件获释的奴隶：在条件成就前，他属于继承人；条件成就后，他便获得自由。

### <a id="10.2.13"></a>10.2.13　帕比尼安《疑问集》第七卷

**正文** 诉讼成立之后所禁止的，只是自愿处分；对于基于较早原因及既有权利来源而必须发生的处分，则不在禁止之列。

### <a id="10.2.14"></a>10.2.14　乌尔比安《评告示》第十九卷

<a id="10.2.14.pr."></a>

**序言（pr.）** 如果并非继承人的人，在争讼程序确定前已经开始取得时效，并在争讼程序确定后完成时效取得，该财物便不再纳入本案。

<a id="10.2.14.1"></a>

**1.** 用益权是否纳入本案，尚有疑问。例如，继承人遗赠一处土地时，扣除了用益权。

### <a id="10.2.15"></a>10.2.15　保罗《评告示》第二十三卷

**正文** 或者，用益权被遗赠给遗产中的奴隶；因为用益权不能脱离其所附着之人而存在，否则其本身也会消灭。

### <a id="10.2.16"></a>10.2.16　乌尔比安《评告示》第十九卷

**正文** 我认为，法官的职责包括：如果继承人希望结束对用益权的共有关系，就应当在他们提供担保后，按其请求办理。

<a id="10.2.16.1"></a>

**1.** 尤利安说，如果法官将土地判归一人、将该土地的用益权判归另一人，用益权便不成为共有。

<a id="10.2.16.2"></a>

**2.** 用益权可以判归自某一确定时间起享有、至某一确定时间止享有，也可以判归隔年享有。

<a id="10.2.16.3"></a>

**3.** 争讼程序确定后，河流冲积并附着于土地的部分，也纳入此项诉讼。

<a id="10.2.16.4"></a>

**4.** 庞波尼乌斯说，如果一名继承人以欺诈或过失损害用益权，该事项也应纳入本案。凡继承人就遗产所为的欺诈或过失行为，均纳入遗产分割之诉；但前提是其以继承人身份实施该行为。因此，如果一名继承人在遗嘱人尚在世时取走钱款，该钱款不纳入遗产分割之诉，因为当时他还不是继承人。尤利安写道，如果他以继承人身份实施行为，即使另有其他诉讼可以针对他提起，他仍须承担遗产分割之诉的责任。

<a id="10.2.16.5"></a>

**5.** 因此，庞波尼乌斯说，如果一名继承人涂抹或刮除遗产账簿，固然应依《阿奎利亚法》追究其毁损文书的责任；但也可以对其提起遗产分割之诉。

<a id="10.2.16.6"></a>

**6.** 如果遗产中的奴隶偷走某一继承人的个人财物，奥菲利乌斯认为，可以提起遗产分割之诉，而共有物分割之诉和盗窃之诉均不适用。因此，提起遗产分割之诉的人可以取得该奴隶的判归，或者要求按单倍诉讼估价给付。

### <a id="10.2.17"></a>10.2.17　盖尤斯《评行省告示》第七卷

**正文** 如果损害由一名继承人造成，在遗产分割之诉中以单倍额估价较为妥当。

### <a id="10.2.18"></a>10.2.18　乌尔比安《评告示》第十九卷

**正文** 尤利安接着说：如果遗嘱通过选择权将一名奴隶笼统地预先遗赠给数名继承人中的一人，其他继承人却主张斯提库斯涂抹或毁坏了遗产文书，并因此放弃让其选择奴隶；之后，该奴隶仍被选定并遭人主张所有权，那么，如果有人向这些继承人主张该奴隶，他们可以提出恶意抗辩，并就该奴隶进行审问。

<a id="10.2.18.1"></a>

**1.** 有人询问，继承人能否在遗产分割之诉中，就遗嘱人、遗嘱人之妻或其子女的死亡进行调查。庞波尼乌斯的意见完全正确：这些事项与遗产财物的分割无关。

<a id="10.2.18.2"></a>

**2.** 庞波尼乌斯还询问，如果遗嘱规定应将某奴隶出售并遣送出境，遗产分割之诉的法官是否有职责确保遗嘱人的意思不落空。遗嘱人命令建造纪念碑时，继承人也可以提起遗产分割之诉，请求完成建造。不过，庞波尼乌斯也考虑到，继承人因承受纪念碑相关权利而具有利害关系，或许可以提起言词前置之诉（*actio praescriptis verbis*），请求建造纪念碑。

<a id="10.2.18.3"></a>

**3.** 根据塞维鲁和安敦宁皇帝的敕答，某一继承人为遗产善意支出的费用，可以向共同继承人请求支付利息；利息自共同继承人迟延之日起计算。

<a id="10.2.18.4"></a>

**4.** 凯尔苏斯还精辟地补充说，即使共同继承人尚未清偿债务，另一继承人也可以提起遗产分割之诉，迫使该共同继承人清偿；否则，除非债权人获得全部清偿，否则他不会解除对该财物的担保。

<a id="10.2.18.5"></a>

**5.** 如果家子成为其父的部分继承人，而被特有产债权人起诉，并且愿意清偿全部债务，他可以通过恶意抗辩，要求债权人将诉权授予自己；他也可以对共同继承人提起遗产分割之诉。〔底本此处另有异文“*habet*”，现按正文译文处理。〕

<a id="10.2.18.6"></a>

**6.** 如果一名继承人向为保存遗赠而获准占有财产的人清偿了遗赠，帕比尼安认为——这也是正确的——该继承人可以对共同继承人提起遗产分割之诉。因为受遗赠人只有在全部遗赠均已清偿时，才会放弃其以质押方式取得的占有。

<a id="10.2.18.7"></a>

**7.** 如果有人替提提乌斯清偿债务，以免质押物被出售，涅拉提乌斯写道，此人可以提起遗产分割之诉。

### <a id="10.2.19"></a>10.2.19　盖尤斯《评行省告示》第七卷

**正文** 与此相应，法官也应妥善处理相反情形：一名继承人从遗产中取得的财物，或其承诺取得的利益，不应仅归该继承人获益。法官可以通过在继承人之间相互抵销来实现这一点，也可以要求他们提供担保，以便共同分享利益并分担不利。

### <a id="10.2.20"></a>10.2.20　乌尔比安《评告示》第十九卷

<a id="10.2.20.pr."></a>

**序言（pr.）** 如果已婚女儿本应将嫁资计入遗产，却因共同继承人的误解而承诺：她从丈夫处取回的嫁资将按各继承人的份额分配，帕比尼安写道，遗产分割之诉的仲裁人仍应判令她计入嫁资，即使她在婚姻存续期间死亡也是如此。因为他说，共同继承人的不熟悉法律程序，不能改变管辖规则。

<a id="10.2.20.1"></a>

**1.** 如果家子因父亲的命令而负债，应当允许他在遗产分割前优先扣除该债务；如果债务用于父亲的事务，也作相同处理；如果涉及特有产之诉，则应优先扣除特有产。我们的皇帝曾作出相同的敕答。

<a id="10.2.20.2"></a>

**2.** 此外，作为继承人的家子还应优先取回其妻的嫁资，这并非没有理由，因为婚姻负担由他承担。因此，他应先取回全部嫁资，并担保保护那些可能因要式口约而被起诉的共同继承人。如果嫁资由他人交付，而他人订立了要式口约，也适用相同规则。他应优先取回的不仅是其妻的嫁资，还包括其儿子的妻子的嫁资；因为这项婚姻负担也与他有关，他必须承担儿子和儿媳的负担。马尔凯卢斯写道，家子应当优先取回的不仅是交给父亲的嫁资，也包括交给家子的嫁资；但后者仅以特有产所能负担的范围为限，或者以嫁资用于父亲事务的范围为限。

<a id="10.2.20.3"></a>

**3.** 如果父亲没有书面文件，便在儿子之间分配财产，并依各人所占财产份额分配债务负担，帕比尼安说，这并非单纯赠与，而更像是以最后处分方式进行的分割。当然，他还说，如果债权人按各人继承份额起诉，而其中一人拒绝履行约定，只要所有财产均已分割，就可以将其视为已依确定约定进行交换，并对其提起言词前置之诉。

<a id="10.2.20.4"></a>

**4.** 除非经审查确认有充分理由，遗产分割之诉不得再次提起。如果有些财物仍未分割，可以就这些财物提起共有物分割之诉。

<a id="10.2.20.5"></a>

**5.** 帕比尼安说，如果某项遗产债务在遗赠安排之外被加诸一名继承人，审理遗产分割之诉的法官应命令该继承人承担此债务；但承担数额不得超过其继承份额的四分之三，使其保留不受损的四分之一。因此，他应担保其他共同继承人不受损失。

<a id="10.2.20.6"></a>

**6.** 帕比尼安还写道，如果家子在父亲同意下承担公职义务，并被指定为部分继承人，他也应先行扣除这项负担，因为这同样属于父亲的债务。但如果这些公职义务是在父亲死后才承担，父亲的继承人便不再对此负责。

<a id="10.2.20.7"></a>

**7.** 涅拉提乌斯曾作如下答复：某人有数名儿子，宣布其中一人将承担 *agwonovesian*〔主持竞赛庆典的职务〕，但该儿子尚未就任便去世，而所有儿子均被指定为继承人。有人询问，该儿子为此项事务支出的费用，能否在遗产分割之诉中取回；涅拉提乌斯答复说，他不能通过任何诉讼取回。这一意见确实不妥；因此，该费用应纳入遗产分割之诉。

<a id="10.2.20.8"></a>

**8.** 帕比尼安还写道，如果丈夫命令一名继承人承担以要式口约约定的嫁资清偿义务，而妻子同时向二人请求返还嫁资，那么，被命令承担该债务的人应保护其共同继承人。但是，妻子选择保留嫁资后，二人以嫁资名义保留的遗赠，不应成为免于债务的共同继承人的利益；应由承担债务的共同继承人依照法官职权取得该遗赠。此说正确，除非遗嘱人另有规定。

<a id="10.2.20.9"></a>

**9.** 帕比尼安还写道，如果遗嘱人为了使附条件获释的奴隶履行条件，将特有产交给共同继承人中的一人，该特有产不纳入此项诉讼，也不得由其他继承人分享：

### <a id="10.2.21"></a>10.2.21　保罗《评告示》第二十三卷

**正文** 共有物分割之诉也适用相同规则。

### <a id="10.2.22"></a>10.2.22　乌尔比安《评告示》第十九卷

<a id="10.2.22.pr."></a>

**序言（pr.）** 拉贝奥还写道，如果一名继承人挖出了遗嘱人留下的宝藏，即使他已与知情的外人分赃，也应在遗产分割之诉中承担责任。〔底本此处作“*unus heredum <heredem> thensaurum*”，有插入异文；按其上下文译出。〕

<a id="10.2.22.1"></a>

<a id="10.2.22.2"></a>

**2.** 毫无疑问，法官也可以按照区域划分土地，并依该划分作出判归。

<a id="10.2.22.3"></a>

**3.** 法官在作出判归时，也可以设定某种地役权，使其判归的一处土地为另一处土地提供地役权。但如果法官已将一处土地无条件判归一人，就不能再通过将另一处土地判归他人而追加设定地役权。

<a id="10.2.22.4"></a>

**4.** 遗产分割之诉由两部分构成：财物本身，以及须履行的给付；后者属于对人诉讼。

<a id="10.2.22.5"></a>

**5.** 帕比尼安批评马尔凯卢斯对敌人手中财物的看法。马尔凯卢斯认为，对于仍在敌人手中的财物，其给付请求不纳入遗产分割之诉。可是，既然该财物本身可以纳入，又有什么理由排除与该财物有关的给付请求呢？

### <a id="10.2.23"></a>10.2.23　保罗《评告示》第二十三卷

**正文** 这是因为有望依据复归权取回财物吗？当然应要求提供担保，因为财物可能无法返还；除非已经将归还结果的不确定性纳入估价。

### <a id="10.2.24"></a>10.2.24　乌尔比安《评告示》第十九卷

<a id="10.2.24.pr."></a>

**序言（pr.）** 即使某物已经不复存在于人世，与该物有关的给付请求仍纳入本案；我也赞同帕比尼安的意见。

<a id="10.2.24.1"></a>

**1.** 遗产分割之诉也适用于遗产占有人之间、依据特雷贝利安元老院决议接受返还遗产之人与其他名义继受人之间。

### <a id="10.2.25"></a>10.2.25　保罗《评告示》第二十三卷

<a id="10.2.25.pr."></a>

**序言（pr.）** 在敌人手中死亡之人的继承人，可以提起此项诉讼。

<a id="10.2.25.1"></a>

**1.** 如果一名军人指定一人继承军营特有产，另指定他人继承其他财产，则不适用遗产分割之诉；因为皇帝敕令已在二人之间分割其财产。正如在遗产中没有任何有体物、而只有债权债务时，遗产分割之诉也不适用。

<a id="10.2.25.2"></a>

**2.** 至于能否提起遗产分割之诉，是否占有遗产并不重要。

<a id="10.2.25.3"></a>

**3.** 如果同一当事人基于不同原因共同承受数项遗产，可以只提起一项遗产分割之诉。

<a id="10.2.25.4"></a>

**4.** 如果提提亚努斯遗产由我与你共有，而塞亚努斯遗产由我、你和提提乌斯三人共有，庞波尼乌斯写道，可以由三人共同提起一项诉讼。

<a id="10.2.25.5"></a>

**5.** 同样，如果我们共有数项遗产，也可以仅就其中一项提起遗产分割之诉。

<a id="10.2.25.6"></a>

**6.** 如果遗嘱人与外人共有某物，或者将其所有物的一部分遗赠给他人，或者继承人在遗产分割之诉成立前出卖了自己的份额，法官应命令将属于遗嘱人的那一份交付给某人。

<a id="10.2.25.7"></a>

**7.** 庞波尼乌斯否认，共同继承人以买受人或受赠人的身份占有的财物，可以纳入遗产分割之诉。

<a id="10.2.25.8"></a>

**8.** 庞波尼乌斯还写道：我与你共同继承提提乌斯的遗产。如果你向塞姆普罗尼乌斯请求一处土地的份额，主张整处土地都属于遗产，却被判败诉；此后我从塞姆普罗尼乌斯处买下同一份额，并由其交付给我；那么，当你提起遗产分割之诉时，该份额既不因我以继承人身份占有而纳入，也不因我以买受人身份占有而纳入。因为先前的法官已经认定该土地并非全部属于遗产，如何还能将其纳入遗产分割之诉呢？

<a id="10.2.25.9"></a>

**9.** 继承人各自享有全额诉权的要式口约是否纳入本案，尚有疑问。例如，死者曾通过要式口约取得道路通行权；依《十二表法》，该项要式口约不得分割，因为它不能被分割。但较妥当的意见是，该要式口约不纳入本案，而诉权仍由所有继承人各自全额享有；如果未提供道路，应按继承份额作出给付判决。

<a id="10.2.25.10"></a>

**10.** 相反，如果道路的承诺人死后留下数名继承人，债务既不分割，也毫无疑问仍然存续，因为即使不拥有土地，也可以承诺提供道路。因此，既然每名继承人均承担全部责任，法官应要求他们相互提供担保，使任何一人被起诉并支付诉讼估价后，都可以按份额向其他继承人追偿。

<a id="10.2.25.11"></a>

**11.** 遗嘱人遗赠道路通行权时，也应适用相同规则。

<a id="10.2.25.12"></a>

**12.** 遗嘱人若曾承诺“不得由其本人或其继承人妨碍他人步行或驱赶牲畜通行”，也应当保护共同继承人；因为只要其中一人加以禁止，要式口约的全部责任便会触发，不应让一名继承人的行为损害其他人。

<a id="10.2.25.13"></a>

**13.** 遗嘱人承诺支付金钱并约定罚金时，也适用相同规则。尽管依《十二表法》该债务可以分割，但支付自己的份额并无助于避免罚金。因此，如果金钱尚未支付且履行期限尚未届至，法官应要求担保：由于某一继承人的行为导致全部款项未能支付时，应保证其他继承人不受损害；或者保证向已支付全部款项的人偿付各自份额。即使一名继承人为避免罚金而支付了遗嘱人承诺的全部款项，也可以在遗产分割之诉中向共同继承人请求其各自份额。

<a id="10.2.25.14"></a>

**14.** 清偿质押债务时也应遵循同一规则：除非全部债务均已清偿，债权人依法可以出售质押物。

<a id="10.2.25.15"></a>

**15.** 如果一名继承人在诺克萨诉讼中为遗产中的奴隶进行辩护，并在确有必要时支付诉讼估价，他可以在本诉中按份额请求偿还。如果一名继承人为了避免某人被准许占有遗产以保全遗赠而提供担保，也适用相同规则。总之，对于无法按份完成的事项，如果一名继承人因必要而独自完成，就可以提起遗产分割之诉。

<a id="10.2.25.16"></a>

**16.** 共同继承人对遗产中的欺诈和过失均应承担责任，因为共同继承人之间并非基于契约关系，而是因继承而发生关系。但他不必尽到谨慎家父的注意义务；因为他是为自己的份额而管理事务，因此不能对其提起无因管理之诉。故他只须尽到处理自己事务时的注意义务。两人共同受遗赠时，也适用相同规则：使他们形成共同关系的不是合意，而是受遗赠的财物本身。

<a id="10.2.25.17"></a>

**17.** 如果遗赠的是一名尚未确定具体人选的奴隶，而受遗赠人在其后死亡，其一名继承人因拒绝同意而阻碍遗赠实现，那么该阻碍者应在本诉中向其他继承人赔偿其利益损失。反过来，如果数名继承人被笼统地遗赠一名奴隶，由他们自行选定，而其中一人拒绝同意交付对所有人均有利的奴隶，致使受遗赠人提起诉讼并获得较高额判决，也适用同一规则。

<a id="10.2.25.18"></a>

**18.** 如果一名继承人先于其他人承受遗产，却因不行使权利而放任遗产土地所享有的地役权消灭，他也应当因过失承担责任。

<a id="10.2.25.19"></a>

**19.** 如果家子为父亲进行辩护而被判败诉，并在父亲生前或死后履行判决，较为公平的意见是，他可以在遗产分割之诉中向共同继承人请求偿还。

<a id="10.2.25.20"></a>

**20.** 遗产分割之诉的法官不得留下任何未分割的财物。

<a id="10.2.25.21"></a>

**21.** 法官还应确保，为受判归财物之人提供追夺担保。

<a id="10.2.25.22"></a>

**22.** 如果遗嘱人并未将家中存放的金钱遗赠，而是通过预先取物遗赠金钱，究竟应由共同继承人支付全部金额，还是仅按继承份额支付——如同金钱属于遗产一样——尚有疑问。较妥当的意见是，应当支付的数额与在遗产中实际发现该笔金钱时相同。

### <a id="10.2.26"></a>10.2.26　盖尤斯《评行省告示》第七卷

**正文** 法官依职权可以命令出售一项或数项遗产财物，并将所得价款支付给受遗赠该款项之人。

### <a id="10.2.27"></a>10.2.27　保罗《评告示》第二十三卷

**正文** 此项诉讼中，必须对所有当事人分别作出判令或免责判决。因此，如果遗漏了对某一人的判令，对其他人所作的判决也无效；因为同一诉讼的既判事项不能部分有效、部分无效。

### <a id="10.2.28"></a>10.2.28　盖尤斯《评行省告示》第七卷

**正文** 如果遗嘱人通过预先取物的方式，将已交由债权人质押的财物遗赠给某人，法官应依职权命令从共有资金中清偿该质押债务，并将该财物判归受遗赠人。

### <a id="10.2.29"></a>10.2.29　保罗《评告示》第二十三卷

**正文** 如果被继承人的财物已设定质押，应认为该财物纳入遗产分割之诉。但在遗产分割之诉中，该财物判归谁，谁就应按份额向共同继承人承担责任；他无须向共同继承人担保，使其免受设定质押之人的追索。因为这相当于有人依据抵押诉讼或塞尔维安诉讼请求实现担保，并提出诉讼估价；而提出估价之人也应当以抗辩保护自己，免受所有人提起的返还原物之诉。反过来，如果质押物判归的继承人愿意支付全部债务，即使债务人不愿意，也应准许其如此办理。如果债权人买下另一份额，则不能作同样处理；因为判归是必须接受的，而购买是自愿的；除非有人指称债权人恶意抬高竞价。对此应予考虑，因为债权人的行为应被视为债务人通过代理人所为；而且，对于因必要而支出的费用，债权人还可以主动提起诉讼请求偿还。

### <a id="10.2.30"></a>10.2.30　莫德斯蒂努斯《答复集》第六卷

**正文** 我与一名未成年女继承人共有一处土地。土地上安葬着双方应当依宗教义务供奉的祖先；该未成年女继承人的父母也埋葬在那里。她的监护人想要出售土地，我不同意；我宁愿占有自己的份额，因为我无力买下整处土地，并希望按自己的意愿履行宗教义务。我询问：我请求指定共有物分割之诉的仲裁人来分割该土地，是否正当？还是也可以由遗产分割之诉指定的仲裁人履行相同职能，将该土地从其他遗产有体物中分离出来，按各自权利分配给我们？赫雷尼乌斯·莫德斯蒂努斯答复：没有任何理由妨碍受命审理遗产分割之诉的仲裁人，也对本案所涉土地的分割履行职务；但宗教场所不纳入诉讼，每名继承人均对其享有完整的权利。

### <a id="10.2.31"></a>10.2.31　帕比尼安《疑问集》第七卷

**正文** 如果一名继承人清偿了以奴隶作质押的债务，即使该奴隶后来死亡，仲裁人的职权仍继续存在；因为此前已经存在的共有关系足以支持此项诉讼，若该财物没有灭失，这种共有关系至今仍会持续。

### <a id="10.2.32"></a>10.2.32　帕比尼安《答复集》第二卷

**正文** 父亲在以其他给付替代分割、并已经授予诉权之后，仍未在儿子之间分割的财物，应按继承份额分别归各人所有；但前提是，父亲没有把其余未分割财物一概交给其中一人，或者这些财物并非随已交付的财物一并归其所有。

### <a id="10.2.33"></a>10.2.33　帕比尼安《答复集》第七卷

**正文** 如果家父通过向各继承人分别遗赠土地，意在让法官决定分割方式，那么，只有在共同继承人以互相交换的方式取得一份免受质押负担的份额时，才可以强迫其提供自己那一份。

### <a id="10.2.34"></a>10.2.34　帕比尼安《答复集》第八卷

**正文** 通说认为，分割遗产时为奴隶估价并记入各继承人份额，是为了分配财物，而非为了出售；因此，如果条件尚未成就时奴隶死亡，继承人和遗嘱信托受益人均承受该财物灭失的后果。

### <a id="10.2.35"></a>10.2.35　帕比尼安《答复集》第十二卷

**正文** 庞波尼乌斯·菲拉德尔福斯将自己对仍处于其权力之下的女儿所拥有的土地交付给她作嫁资，并命令将土地收益支付给女婿。后来有人询问：既然他已指定所有儿子为继承人，女儿能否优先保有这些土地？我答复：女儿有正当理由继续占有，因为父亲意在将所询问的土地作为嫁资；而且父亲死后婚姻仍然存续。女儿原本就自然占有这些土地，可以依她能够取得嫁资这一事实为其占有辩护。

### <a id="10.2.36"></a>10.2.36　保罗《疑问集》第二卷

**正文** 我以为你是我的共同继承人，虽然后来证明并非如此。我对你提起遗产分割之诉，法官相互作出财物判归和给付判决。真相查明后，请求返还之诉（*condictio*）是否相互适用，还是应提起所有物返还之诉（*rei vindicatio*）？真正的继承人与非继承人是否应作不同处理？我答复：如果某人是唯一继承人，却以为提提乌斯是其共同继承人，遂与他接受遗产分割之诉，并在作出给付判决后支付了金钱，由于他是依据判决而付款，便不得请求返还。你似乎是因为遗产分割之诉只有在共同继承人之间才能成立而有所疑虑；但即使该诉讼实际上并不成立，只要某人认为自己已被判令给付，就足以阻却其请求返还。如果双方都不是继承人，却以为自己是继承人而接受遗产分割之诉，那么二人中的任何一方都适用刚才所说的返还规则。当然，如果双方未经法官便自行分割财物，那么真实继承人可以提起请求返还之诉（*condictio*），追回分给他所误认为共同继承人的那部分财物；因为真实继承人误以为对方是共同继承人，不能认为双方已达成和解。

**正文** 提起遗产分割之诉的人，承认对方是自己的共同继承人。

### <a id="10.2.38"></a>10.2.38　保罗《答复集》第三卷

**正文** 卢基乌斯和提提亚是被父亲解放出父权的兄妹；成年后，他们各自获得监护人。监护人将共同财产的收益分别提供给二人。后来二人分割了全部财产。分割之后，提提亚指责兄长卢基乌斯取得的财产多于自己。事实上，卢基乌斯取得的并未超过其份额，甚至不足一半。我询问，提提亚能否对兄长提起诉讼？保罗答复：依所述情形，如果卢基乌斯从共有土地的收益中取得的数额未超过其继承份额，妹妹便不能对他提起诉讼。有人还说，依裁判官关于扶养给付的裁定，兄长取得的数额虽超过妹妹，但并未超过其继承份额的一半；保罗对此也作了同一答复。

### <a id="10.2.39"></a>10.2.39　斯凯沃拉《答复集》第一卷

<a id="10.2.39.1"></a>

**1.** 某人无遗嘱死亡，并在遗嘱附录中将其全部土地和财产分给子女，留给儿子的远多于女儿。有人询问，女儿是否须向兄长交出嫁资。我答复：依所述情形，如果遗嘱人没有留下任何未分割财物，较为妥当的说法是，依死者的意思，无须再计算嫁资的归并。

<a id="10.2.39.3"></a>

**3.** 如果儿子在父亲死后为公共事务所负债，而父亲并未在所有事务上与儿子共同经营，即使二人共同继承父亲遗产，儿子也不得要求兄长按继承份额承担该债务；即便父亲是代表另一名儿子担任本地公职时去世，也不例外。

<a id="10.2.39.4"></a>

**4.** 某人指定两个儿子为继承人，并将若干特定奴隶分别预先遗赠给他们；其中将斯蒂法努斯连同其特有产遗赠给一人。斯蒂法努斯在遗嘱人仍在世时被释放，之后遗嘱人才死亡。有人询问，在释放前斯蒂法努斯拥有的特有产，究竟归两个儿子共有，还是仅归获遗赠斯蒂法努斯及其特有产的儿子。我答复：依所述情形，该特有产应归两个儿子共有。

**5.** 父亲在儿子之间分割财产，并以遗嘱确认该分割，同时规定每名儿子各自承担现在或将来所负的债务。之后，一名儿子借款；父亲同意将分给该儿子的土地设定质押。父亲死后，该儿子继续占有这些土地并支付利息。我询问，如果债权人出售质押土地，该儿子能否在遗产分割之诉中请求共同继承人给付任何款项。我答复：依所述情形，共同继承人无须给付。

### <a id="10.2.44"></a>10.2.44　保罗《评萨宾》第六卷

<a id="10.2.44.pr."></a>

**序言（pr.）** 共同继承人之间也可以提起共有物分割之诉；届时只有他们共有的财物及由此产生的请求纳入本案，其他财物仍可通过遗产分割之诉处理。

<a id="10.2.44.1"></a>

**1.** 如果已经提起遗产分割之诉或共有物分割之诉，裁判官可以通过准许抗辩或诉讼来保护法官作出的财物判归。

<a id="10.2.44.2"></a>

**2.** 如果共同继承人在一名继承人不在场时出售财物，并以恶意欺诈使自己取得更多利益，就应当在遗产分割之诉或遗产请求之诉中向缺席继承人承担责任。

<a id="10.2.44.3"></a>

**3.** 尤利安说，继承人在承受遗产前从遗产土地取得的孳息，只有在其明知该土地属于遗产时，才须在遗产分割之诉中交付。

<a id="10.2.44.4"></a>

**4.** 提起遗产分割之诉、共有物分割之诉或界限确定之诉的人，既是原告，也是被告；因此，他们应当宣誓，自己并非出于诬告目的而提起诉讼，也非出于诬告目的而否认对方主张。

<a id="10.2.44.5"></a>

**5.** 共同继承人中的一人因自己的行为，依遗产中的要式口约承担给付的，不得向共同继承人请求偿还。例如，死者曾约定自己及其继承人不实施恶意欺诈，或不得由其本人或继承人妨碍他人通行。如果因一人的行为，使其他人也因遗产要式口约条件成就而开始承担责任，他们可以在遗产分割之诉中起诉导致该要式口约被违反的人。

<a id="10.2.44.6"></a>

**6.** 如果有人以要式口约约定提提乌斯及其继承人应予确认，而提提乌斯死后留下数名继承人，那么，只有未予确认的那名继承人承担责任；提起诉讼的也只是要式口约人的继承人中，受到请求的那一人。

<a id="10.2.44.7"></a>

**7.** 卡西乌斯说，如果遗嘱将用益权遗赠给妻子，直到嫁资得到清偿为止，那么通过遗产分割之诉的仲裁人，妻子既可以取回共同继承人代其支付的嫁资份额，也可以促使共同继承人履行清偿义务；此说正确。

<a id="10.2.44.8"></a>

**8.** 如果两名共同继承人被判令设置一座雕像，而其中一人不履行、另一人代为设置，尤利安说，准许提起遗产分割之诉并非不公；法官可以依善良人的判断，判令另一人偿还部分费用。

### <a id="10.2.46"></a>10.2.46　保罗《评萨宾》第七卷

**正文** 如果丈夫被父亲附条件指定为继承人，妻子请求返还嫁资的诉讼应暂缓。如果岳父去世后夫妻离婚，即使继承条件尚未成就，也应允许妻子优先取回嫁资；因为父亲死后，有些关系即使在儿子尚未成为继承人之前也随其延续，例如婚姻、子女和监护关系。因此，承担父亲死后婚姻负担的人也应当优先取回嫁资；我们的斯凯沃拉也持此见解。

### <a id="10.2.49"></a>10.2.49　乌尔比安《论辩集》第二卷

**正文** 一名按份继承人受裁判官命令安葬遗嘱人；他因此出售一名依遗嘱获释的奴隶，并承诺双倍担保，后来因该担保被诉而履行给付。有人询问，他能否在遗产分割之诉中请求补偿其依双倍担保所承担的损失。首先应考察，他是否应当提供双倍担保。我认为他不应当提供；只有自愿出售财物的人才被迫提供双倍担保。如果他是履行职务而出售财物，就不应受此约束；这与受裁判官委派、为执行判决而出售财物的人相同。履行职务之人和自愿出售之人之间存在重大区别。因此，在情况尚未确定时，他本不应订立双倍担保要式口约；裁判官应当裁定，如果出售的财物被追夺，买受人可以对继承人提起买卖之诉。但如果继承人误以为必须担保而提供了担保，且奴隶后来获得自由，那么该要式口约便会被触发。如果要式口约确已被触发，而直接的遗产分割之诉无法适用，就应当给予该继承人一项准诉权，使其可以对共同继承人请求补偿，避免其遭受损失。因为提起遗产分割之诉的人不仅必须是继承人，而且其起诉或应诉所依据的事项，必须是其成为继承人之后以继承人身份处理或实施的；否则，遗产分割之诉不适用。因此，如果有人在知道自己是继承人之前处理遗产事务，便不能提起遗产分割之诉，因为他并非以继承人的身份行事。所以，在承受遗产之前处理事务的人，例如安葬遗嘱人，不享有遗产分割之诉；但如果他在承受遗产后才这样做，就可以通过遗产分割之诉取回其支付的丧葬费用。

### <a id="10.2.51"></a>10.2.51　尤利安《学说汇纂》第八卷

<a id="10.2.51.pr."></a>

**序言（pr.）** 如果一处土地作为嫁资交给岳父，而岳父又指定儿子为部分继承人，遗产分割之诉的仲裁人应将该土地优先判归儿子，使其处于与嫁资被预先遗赠时相同的地位。因此，争讼程序确定后取得的孳息应归该儿子所有，但须扣除相关费用；争讼程序确定前取得的孳息，则由所有继承人平分。费用也应予以计算，因为不存在任何情形会妨碍这类扣除。

<a id="10.2.51.1"></a>

**1.** 如果我想向你请求遗产，而你对我提起遗产分割之诉，应根据我们各自的理由分别处理。如果我占有全部遗产，承认你是半数继承人，但希望脱离共有关系，就应准许我提起遗产分割之诉，因为否则我们无法分割遗产。同样，如果你有正当理由希望通过遗产请求之诉而不是遗产分割之诉解决争议，也应允许你请求遗产。因为有些事项可以纳入遗产请求之诉，却不纳入遗产分割之诉；例如，如果我欠遗产债务，你不能通过遗产分割之诉取得被继承人生前对我的债权，但可以通过遗产请求之诉取得。

### <a id="10.2.53"></a>10.2.53　乌尔比安《答复集》第二卷

**正文** 脱离父权的儿子借出一笔钱，并约定将钱交给父亲；只有在父亲可以就同额款项对儿子提起诉讼时，该款项才计入父亲的遗产。

### <a id="10.2.54"></a>10.2.54　涅拉提乌斯《札记》第三卷

**正文** 卢基乌斯·提提乌斯的遗产由我与你共有。我出卖了自己在其中一处土地上的份额，之后我们之间提起了遗产分割之诉。已经出卖的份额不纳入本案，因为它已因转让而脱离遗产；你的份额也不纳入，因为即使该份额仍依原有权利属于遗产，我出售自己份额的行为也使该土地脱离共有关系。至于是一个继承人出售了自己的份额，还是数名继承人出售了份额，并无区别；只要任何一名继承人出售的部分因此不再属于遗产即可。

### <a id="10.2.55"></a>10.2.55　乌尔比安《评告示》第二卷

**正文** 如果遗产分割之诉或共有物分割之诉的财物极难分割，以致几乎不可能分割，法官可以将全部给付责任集中于一人，并将所有财物判归该人。

### <a id="10.2.56"></a>10.2.56　保罗《评告示》第二十三卷

**正文** 不仅界限确定之诉，遗产分割之诉也包括此前期间取得的孳息。

### <a id="10.2.57"></a>10.2.57　帕比尼安《答复集》第二卷

**正文** 仲裁人受命后，兄弟们经合意分割共有遗产，是在履行亲属间应有的义务，不应允许撤销；即使仲裁人因争议终结而未作出裁决，也不例外，除非当事人因未成年而受到特别保护。
