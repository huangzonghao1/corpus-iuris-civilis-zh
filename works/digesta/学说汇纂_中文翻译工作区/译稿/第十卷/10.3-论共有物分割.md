## 10.3.0　论共有物分割（*Communi dividundo*）

### <a id="10.3.1"></a>10.3.1

保罗《评告示》第二十三卷

之所以必须设立共有物分割之诉，是因为合伙之诉主要涉及合伙人彼此之间的个人给付，而非共有物的分割。归根结底，如果不存在共有物，共有物分割之诉便不适用。

### <a id="10.3.2"></a>10.3.2

盖尤斯《评行省告示》第七卷

<a id="10.3.2.pr."></a>

**序言（pr.）** 数人之间的共有关系是否基于合伙，并无区别：两种情形都可以提起共有物分割之诉。基于合伙而共有，例如数人共同购买同一物；不基于合伙而共有，例如数人因遗嘱而共同受遗赠取得同一物。

<a id="10.3.2.1"></a>

**1.** 在三种双方当事人均可为原告或被告的诉讼中，即遗产分割之诉、共有物分割之诉和界限确定之诉，须判断谁应被视为原告，因为各方地位似乎相同；不过，较为可取的意见是，应将请求启动诉讼程序的人视为原告。

### <a id="10.3.3"></a>10.3.3

乌尔比安《评萨比努斯》第三十卷

<a id="10.3.3.pr."></a>

**序言（pr.）** 共有物分割之诉的审理范围，不超出共有物本身的分割；如果共有物遭受损害或被作了某种处置，或者某一共有人因共有物而有所损失或取得利益，也在审理范围之内。

<a id="10.3.3.1"></a>

**1.** 如果共有人之间未以诈欺方式订立任何约定，遗产分割之诉和共有物分割之诉的法官首先都应遵守该约定。

### <a id="10.3.4"></a>10.3.4

乌尔比安《评告示》第十九卷

<a id="10.3.4.pr."></a>

**序言（pr.）** 本诉讼分割的是我们享有所有权的有体物，而不是遗产本身。

<a id="10.3.4.1"></a>

**1.** 有人询问，能否就水井提起共有物分割之诉。梅拉说，只有井所在的土地为共有时，才可以提起。

<a id="10.3.4.2"></a>

**2.** 这是一项诚信诉讼；因此，即使有一项共有物未予分割，其他共有物的分割仍然有效。对仍未分割的共有物，还可以再次提起共有物分割之诉。

<a id="10.3.4.3"></a>

**3.** 共有物分割之诉不仅涉及共有物本身的分割，也涉及相互给付；因此，某人已经支出的费用，可以在本诉中请求偿还。但如果其起诉的不是共有人本人，而是该共有人之继承人，拉贝奥认为，死者支出的费用以及死者取得的孳息均应纳入审理。显然，在共有关系成立之前取得的孳息，或此前支出的费用，不纳入共有物分割之诉。

<a id="10.3.4.4"></a>

**4.** 因此，尤利安写道：如果我们因可能发生的损害而获准进入占有（*missio in possessionem damni infecti*），而在获准实际占有之前，我修缮了该建筑物，那么我不能通过共有物分割之诉请求偿还这笔费用。

### <a id="10.3.5"></a>10.3.5

尤利安《评乌尔塞乌斯·费罗克斯》第二卷

但如果该物无人辩护，因此行政长官命令我们占有该宅邸，并由此取得其所有权，普罗库鲁斯回答说，我可以通过共有物分割之诉收回所支费用中的相应份额。

### <a id="10.3.6"></a>10.3.6

乌尔比安《评告示》第十九卷

<a id="10.3.6.pr."></a>

**序言（pr.）** 如果某人误以为自己与提提乌斯共有一处土地，因而取得孳息或支出费用，而该土地实际上是与另一人共有，可以提起共有物分割准诉讼。

<a id="10.3.6.1"></a>

**1.** 因此，即使提提乌斯已经转让该土地，虽然共有关系已经终止，不能再提起通常的共有物分割之诉，仍可提起共有物分割准诉讼；共有关系终止时，针对相互给付的诉讼仍可适用。

<a id="10.3.6.2"></a>

**2.** 如果共有人通过出租共有土地或耕种共有土地而取得利益，应受共有物分割之诉拘束。如果他是以共有人的共同名义行事，就不应独自获利或承担损失；如果他并非以共同名义行事，而是意图独自获利，则损失更应由其本人承担。之所以可以通过共有物分割之诉处理，是因为他似乎无法便当地单独出租自己的份额。正如帕比尼安所写，只有在其处理事务确为妥善管理自己份额所必需时，才可以提起共有物分割之诉；否则，如果他本可以自行管理，就可以提起无因管理之诉，并受该诉讼拘束。

<a id="10.3.6.3"></a>

**3.** 如果在共有物分割之诉开始后支出费用，涅尔瓦正确地认为，这些费用也应纳入审理。

<a id="10.3.6.4"></a>

**4.** 萨比努斯和阿提利基努斯还认为，生育所得也应纳入分割。〔底本仅作 *partum*，未具体说明所指对象。〕

<a id="10.3.6.5"></a>

**5.** 他们还认为，添益和减损也应由本诉处理。

<a id="10.3.6.6"></a>

**6.** 如果有人将死者葬于共有土地，须考察该地是否因此成为宗教用地。确实，每个人都有权以完整权利将死者葬入墓地；但其中一人不能使原本为纯粹世俗用途的共有土地成为宗教用地。特雷巴提乌斯和拉贝奥虽认为该地并未因此成为宗教用地，仍认为可以提起事实之诉。

<a id="10.3.6.7"></a>

**7.** 如果你就房屋可能发生的损害提供了全部担保，拉贝奥说，你不能提起共有物分割之诉，因为你没有必要为全部损害提供担保；为自己的份额担保已经足够。此说正确。

<a id="10.3.6.8"></a>

**8.** 如果土地由我和你共有，但我将其设定质权，该土地仍属于共有物分割之诉的审理范围；即使土地被判归一方，债权人的质权仍然存续，因为即使只是将土地的一部分交给共有人，质权也不会受影响。尤利安说，仲裁人应按较低的价值评估该共有人份额，因为债权人可以依约定出卖该物。

<a id="10.3.6.9"></a>

**9.** 同一尤利安还写道：如果与我共有奴隶的人将其份额设质给我，之后又提起共有物分割之诉，应通过质权抗辩将其驳回；但如果我没有提出该抗辩，法官依职权应将奴隶整体判归债务人，并判其支付该份额的估价。因为质权仍完整存续。如果法官将奴隶判归我，则只应判我支付超过所担保债权额的质物价值，并命令我免除债务人所负债务。

<a id="10.3.6.10"></a>

**10.** 法官依职权也可以如此裁判：将土地所有权判归一方，将用益权判归另一方。

<a id="10.3.6.11"></a>

**11.** 其他事项与我们在遗产分割之诉中讨论的相同。

<a id="10.3.6.12"></a>

**12.** 乌尔塞乌斯说，如果邻人针对共有建筑物发出禁止施工的通知，而其中一名共有人因此被判承担责任，可以通过共有物分割之诉向另一共有人请求其应分担的部分。不过，尤利安正确地指出，只有该建筑物确实因此获得利益时，此说才成立。

### <a id="10.3.7"></a>10.3.7

乌尔比安《评告示》第二十卷

<a id="10.3.7.pr."></a>

**序言（pr.）** 共有物分割之诉也适用于缴纳地租的土地。该类土地能否按区域分割，尚待考察；不过，法官最好避免如此分割，否则地租的缴纳将陷于混乱。

<a id="10.3.7.1"></a>

**1.** 涅拉提乌斯写道，如果仲裁人将不属于缴纳地租土地的土地按区域分割并分别判归两人，可以视为在两个土地之间设立役权。

<a id="10.3.7.2"></a>

**2.** 享有普布利基安诉权的人，也可以提起共有物分割之诉。

<a id="10.3.7.3"></a>

**3.** 在某些情形下，所有物返还之诉不能提起；但只要占有具有正当原因，仍可以提起共有物分割准诉讼。例如，基于误付而取得该物的占有人，可以提起此诉。

<a id="10.3.7.4"></a>

**4.** 掠夺者之间不能提起本诉；基于容许占有（*precarium*）的占有人不能提起，即使是秘密占有人也不能，因为秘密占有并无正当性。容许占有虽有正当原因，却不具有足以支持本诉的效力。

<a id="10.3.7.5"></a>

**5.** 尤利安写道，如果一名占有人提起本诉，另一人却主张他是以暴力占有，就不应准许该诉；即使已经过了一年，也仍然如此，因为通说认为，对以暴力驱逐他人的人，即使一年之后仍可给予令状。尤利安说，如果对方主张提起诉讼者是基于容许占有，本诉也不适用，因为此时可以给予容许占有令状。如果对方主张提起诉讼者是秘密占有人，也应说本诉不适用；因为可以就秘密占有提起诉讼。

<a id="10.3.7.6"></a>

**6.** 如果有两名质权人，给予共有物分割准诉讼最为公平。

<a id="10.3.7.7"></a>

**7.** 如果两人对用益权发生争议，也应给予本诉。

<a id="10.3.7.8"></a>

**8.** 如果行政长官命令两人占有遗赠物，也应如此处理；这是为了保管而占有，具有正当原因。因此，如果有两名胎儿，结论也应相同；这很有道理。〔*duo ventres* 字面为“两腹／两孕体”，此处具体所指未详，暂按两名未出生者译。〕

<a id="10.3.7.9"></a>

**9.** 显然，如果某人已因可能发生的损害而被命令占有该物，就不适用此项共有物分割准诉讼，因为他可以提起所有物返还之诉。

<a id="10.3.7.10"></a>

**10.** 在共有用益权的分割诉讼中，法官应依职权作如下安排：可以准许双方按区域使用并享受收益；也可以将用益权出租给其中一人，或者出租给第三人，使双方毫无争议地收取租金。如果标的是动产，也可以要求双方约定并提供担保，轮流在不同期间使用并享受收益，即用益权在各人之间按约定期间交替行使。

<a id="10.3.7.11"></a>

**11.** 承租人和受寄存人均不能提起本诉，尽管他们在事实上占有该物。

<a id="10.3.7.12"></a>

**12.** 在数名质权人之间，应如此分割：对质物份额的估价不应按照其真实价值，而只应以该份额所担保的债务额为限；质物可以判归其中一名债权人，但不得剥夺债务人提出清偿债务并取回质物的权利。质权占有人对提起对物诉讼的原告提出质权估价给付，也适用同一规则。

<a id="10.3.7.13"></a>

**13.** 如果共有土地的债务人将其土地份额设定质权，而其债权人在竞价中胜出（该竞价可能由另一份额的所有人或另一债务人的债权人发起），债权人取得判归后，债务人若想在清偿自己所欠债务后取回其土地份额，较为妥当的意见是：除非其也愿意取回债权人通过判归取得的那一份额，否则不应准许。〔本句债权人与竞价者之间的关系表述紧缩，暂依上下文处理。〕又如，你已经出卖某物的一部分，在将该部分交付买受人之前，因共有物分割之诉被对方起诉，另一份额又判归给你，则相应地，应认为买受人若不愿接收全部标的，就不能提起买卖诉讼，因为该部分是由于出卖人的利益而归入标的整体的；甚至还可以依据出卖之诉起诉买受人，要求其接收全部标的。唯一需要考察的是，出卖人是否存在欺诈。如果出卖人已出卖一部分，并在竞价中落败而将其余部分让出，也同样应依买卖之诉返还价款。委任等其他同类诉讼也适用这些规则。

### <a id="10.3.8"></a>10.3.8

保罗《评告示》第二十三卷

<a id="10.3.8.pr."></a>

**序言（pr.）** 即使并非所有共有物共有人，而只是其中确定的数人希望分割，也可以在他们之间提起本诉。

<a id="10.3.8.1"></a>

**1.** 如果遗赠人和继承人之间是否适用《法尔基迪亚法》尚不确定，可以提起共有物分割之诉，也可以提起份额不确定的所有物返还之诉。如果遗赠的是特有产，也同样如此，因为特有产物在多大程度上减少了所有人享有的债权，尚不确定。

<a id="10.3.8.2"></a>

**2.** 如果某人使共有物状况恶化，也属于共有物分割之诉的范围，例如打伤共有奴隶、使其心智败坏，或者砍伐土地上的树木。

<a id="10.3.8.3"></a>

**3.** 如果某共有人因共有奴隶的诺克萨责任而支付了超过自己份额的金额，应先估算奴隶价值，再由该共有人据此取得相应的分担额。

<a id="10.3.8.4"></a>

**4.** 同样，如果某人因特有产被起诉并被判就全部债务负责，可以对共有人提起共有物分割之诉，以取得其应分担的特有产份额。

### <a id="10.3.9"></a>10.3.9

阿非利卡努斯《疑义》第七卷

但如果某共有人因共有奴隶的特有产而被判对全部债务负责，之后该共有人处的特有产物灭失，仍可以提起共有物分割准诉讼以取回相应份额；否则，如果全部损失都由接受诉讼者承担，就不公平，因为特有产物的风险应由两名所有人共同承担。又如，有人奉主人之命为奴隶进行辩护，其依诚信所支付的一切，即使特有产之后灭失，也应当获偿。以上规则以双方均无过错为前提；如果被提起特有产之诉的主人愿意将特有产物交给原告，法官应根据具体情况听取其意见，当然，以其并非出于诈欺或拖延为限。

### <a id="10.3.10"></a>10.3.10

保罗《评告示》第二十三卷

<a id="10.3.10.pr."></a>

**序言（pr.）** 同样，虽然《阿奎利亚法》之诉不能对继承人提起，但如果死者在共有物上实施了某种行为，并因此产生《阿奎利亚法》之诉，合伙人的继承人仍应在本诉中承担给付责任。

<a id="10.3.10.1"></a>

**1.** 如果我们共有的只是使用权，而该权利既不能转让也不能出租，我们应如何在共有物分割之诉中进行分割？对此，行政长官将予以介入并作出调整：例如，法官将使用权判归一方时，另一方收取金钱补偿，并不因此被视为未使用该物；享有使用权的一方也不应被视为获得更多利益，因为这是不得已的安排。

<a id="10.3.10.2"></a>

**2.** 在共有物分割之诉中，法官应按公平价格估价该物，并且还应就追夺提供担保。

### <a id="10.3.11"></a>10.3.11

盖尤斯《评行省告示》第七卷

总之，应当提醒：共有物灭失后，如果某人本应因共有关系而取得给付，并希望就此起诉，应给予共有物分割准诉讼。例如，原告曾为共有物支出费用，或者其共有人独自从该物取得某种利益，如奴隶劳务或租金；这些事项均在本诉中一并核算。

### <a id="10.3.12"></a>10.3.12

乌尔比安《评告示》第七十一卷

如果房屋为共有，或者墙体为共有，且需要修缮、拆除或在墙上施工，应提起共有物分割之诉；也可以提起 *uti possidetis* 占有令状之诉。

### <a id="10.3.13"></a>10.3.13

乌尔比安《评告示》第七十五卷

除非共有人明确共同约定排除某一共有物，不将其纳入分割，否则所有共有物均应纳入共有物分割之诉的审理。

### <a id="10.3.14"></a>10.3.14

保罗《评普劳提乌斯》第三卷

<a id="10.3.14.pr."></a>

**序言（pr.）** 明知自己有共有人而以共同名义进行或本应进行的事项，均属于本诉的审理范围。

<a id="10.3.14.1"></a>

**1.** 我误以为土地是自己的，而为该土地支出的费用——如果土地份额被请求返还，我本可以依据诈欺抗辩而保留该份额——是否也可以在他人对我提起的共有物分割之诉中，基于该诉讼本身的公平原则保留？应当对此加以考察。我更倾向于肯定，因为共有物分割之诉属于诚信诉讼；但这只适用于他人对我提起诉讼的情形。若我已转让自己的份额，就无从保留。至于从我处买受份额的人能否保留，则另当别论：如果有人向其请求返还份额，他本可就我支出的费用作出保留，如同我本人可以保留一样；较为正确的意见是，在这种情形下，费用也应准许保留。由此可知，即使共有关系仍然存续，也应允许我以支出费用为由对共有人提起共有物分割准诉讼。因为，这与我误以为某物归自己所有、却为他人的物或共有物支出费用不同：在后一情形中，我只是保留该物，因为我并无意使任何人对我负债。但如果我误以为提提乌斯的物属于梅维乌斯，或者误以为某物与他人共有而实际并非如此，我的目的就是使他人对我负债；正如我误以为他人的事务属于某人而为其管理时，可以对我所管理事务之人提起无因管理之诉，在此也应如此。因此，即使我已转让土地，既然我原本应取得诉权，也应将诉权给予我；正如尤利安所写，给予我无因管理之诉。

<a id="10.3.14.2"></a>

**2.** 如果共有人约定绝不分割，显然此种约定不具任何效力。但如果约定只在确定期间内不分割，而且该限制也有利于共有物的性质，则约定有效。

<a id="10.3.14.3"></a>

**3.** 如果共有人约定在一定期间内不分割合伙关系，并不妨碍受该约定拘束的人出售自己的份额。因此，买受人提起共有物分割之诉时，也会因同一抗辩而被驳回；该抗辩本可用于驳回其出卖人。

<a id="10.3.14.4"></a>

**4.** 如果共有人约定不请求分割自己的份额，该约定实际上消灭了合伙关系。

### <a id="10.3.15"></a>10.3.15

保罗《评普劳提乌斯》第五卷

如果某共有人因共有奴隶而被起诉并判败诉，可以在实际给付之前提起共有物分割之诉。又如，一人因诺克萨诉讼被起诉，另一人可以立即对其提起诉讼，请求将奴隶份额交给自己，并要求提供担保，以确保若对方未交付该份额，就应返还相应价值。

### <a id="10.3.16"></a>10.3.16

保罗《评普劳提乌斯》第六卷

共有人分割合伙关系时，对于附条件到期的债务，通常应相互提供担保。

### <a id="10.3.17"></a>10.3.17

莫德斯蒂努斯《规则集》第九卷

某人有共同继承人，如果他从债权人处买下被其立遗嘱人设定质权的土地，就不应被共同继承人通过共有物分割之诉起诉。

### <a id="10.3.18"></a>10.3.18

雅沃勒努斯《书信集》第二卷

仲裁人不得规定由遗产土地供非遗产土地役使，因为法官的权力不得超出提交审理的范围。

### <a id="10.3.19"></a>10.3.19

保罗《评萨比努斯》第六卷

<a id="10.3.19.pr."></a>

**序言（pr.）** 生长在土地界线上的树，以及横跨两块土地的石头，只要仍与土地相连，就分别属于其所处的两侧土地，不纳入共有物分割之诉。但石头被挖出，或者树木被连根拔起或砍倒后，就成为按份共有物，应纳入共有物分割之诉；因为原先分属确定部分的权利，又重新混合起来。因此，两名所有人的两块金属熔合后，整块金属即成为共有物，即使原先的某些部分仍可区分也是如此。树木或石头与土地分离，也会使所有权关系发生混合。

<a id="10.3.19.1"></a>

**1.** 对于两所房屋共有的门廊，未经任何一方同意，不应指定共有物分割之诉的仲裁人；因为被迫就门廊竞价的人，有时不得不为整所房屋出价，否则便没有其他通道可用。

<a id="10.3.19.2"></a>

**2.** 如果我和你对同一路段享有通行权，而且有人为此支出了费用，庞波尼乌斯认为，提起共有物分割之诉或合伙之诉似乎过于严苛：一项权利上的共有关系，如何能够单独理解呢？应当提起无因管理之诉。

<a id="10.3.19.3"></a>

**3.** 对于正在逃亡的奴隶，共有物分割之诉和遗产分割之诉的法官都应命令当事人竞价，再将奴隶判归竞价胜出者；否则就有违反元老院决议并招致《法比亚法》处罚的风险。

<a id="10.3.19.4"></a>

**4.** 拉贝奥说，水道权不纳入共有物分割之诉：它要么属于土地本身，因而不单独纳入审理；要么与土地分离，但已按数量或时间分开。不过，有些权利有时虽与土地分离，却既未按数量也未按时间分割，例如权利人留下了数名继承人。发生这种情形时，该项权利也应纳入遗产分割之诉的仲裁范围。庞波尼乌斯说，他不明白为何此类权利不能像纳入遗产分割之诉一样，纳入共有物分割之诉。因此，在这类情形中，水道权也应由共有物分割之诉的仲裁人处理，并按数量或时间加以分割。

### <a id="10.3.20"></a>10.3.20

庞波尼乌斯《评萨比努斯》第十三卷

如果与你共有土地的人未就不法行为应诉，因此法官依职权拆毁了宅邸或砍伐了树林，你可以通过共有物分割之诉请求赔偿损失；凡因共有人过错而灭失的财产，均属于本诉的审理范围。

### <a id="10.3.21"></a>10.3.21

乌尔比安《评萨比努斯》第三十卷

分割土地时，法官应遵循最有利于所有人的方案，或者当事人所希望采取的方案。

### <a id="10.3.22"></a>10.3.22

庞波尼乌斯《评萨比努斯》第三十三卷

如果我为自己和邻人的利益建造一堵墙，无论是希望向邻人请求分担一部分费用，还是出于赠与之意，该墙都会成为共有墙。

### <a id="10.3.23"></a>10.3.23

乌尔比安《评告示》第三十二卷

如果你与共有人约定轮流每年取得孳息，而共有人不允许你取得属于你那一年的孳息，应考察可以提起租赁之诉，还是共有物分割之诉。如果共有人约定轮流享用土地，却放牧牲畜，致使本应由另一共有人在下一年度取得的孳息遭到毁损，也有同样问题。我认为，更适用共有物分割之诉，而非租赁之诉，因为并无租金，不存在租赁；或者至少应给予一项给付内容不确定的市民法之诉。

### <a id="10.3.24"></a>10.3.24

尤利安《学说汇纂》第八卷

<a id="10.3.24.pr."></a>

**序言（pr.）** 共有奴隶即使利用其中一名共有人提供的财物取得某物，该物仍为共有；但提供财物的共有人可以通过共有物分割之诉请求分得相应款项，因为依诚信原则，每一共有人都应优先取得奴隶利用其财物所得的利益。

<a id="10.3.24.1"></a>

**1.** 当我想对你提起共有物分割之诉时，你为了改变诉讼关系而将自己的份额转让给提提乌斯；因此，你应对我承担行政长官诉权责任，因为你采取行动是为了使我不能对你提起共有物分割之诉。

### <a id="10.3.25"></a>10.3.25

尤利安《学说汇纂》第十二卷

如果斯提库斯是我和你共有的奴隶，并且有一个价值十奥雷的属奴潘菲卢斯，而我因特有产对斯提库斯提起诉讼并被判决，支付了十奥雷，那么即使潘菲卢斯后来死亡，你仍应通过共有物分割之诉或合伙之诉向我支付五千，因为我已替你清偿了这项债务。如果斯提库斯在潘菲卢斯死亡后又取得了另一名属奴，我更有权请求偿还。〔底本仅作 *quinque milia*“五千”，未标明货币单位。〕

### <a id="10.3.26"></a>10.3.26

阿尔费努斯《学说汇纂》第二卷

共有奴隶在其中一名共有人处从事工作时摔断了腿；有人询问另一名共有人可以对照管奴隶的人提起什么诉讼。我回答说，如果共有物遭受损失主要是由于该人的过错，而非偶然事件，可以通过共有物分割之诉的仲裁程序请求赔偿。

### <a id="10.3.27"></a>10.3.27

保罗《阿尔费努斯学说汇纂节录》第三卷

除为共有事务之目的外，共有人无权单独对共有奴隶施以刑讯。

### <a id="10.3.28"></a>10.3.28

帕比尼安《疑义》第七卷

萨比努斯说，在共有物上，任何共有人均无权违背另一共有人的意愿，依法实施任何行为。因此显然存在禁止权；在权利地位相同的情况下，禁止者的地位优先。不过，虽然共有人可以禁止另一共有人在共有物上施工，但如果他原本可以制止却未制止，就不能强迫对方拆除已完成的工程；因此，可以通过共有物分割之诉赔偿损失。如果他同意对方施工，就无权请求损害赔偿。若对方在共有人缺席时实施损害其利益的行为，则还应强令其拆除。

### <a id="10.3.29"></a>10.3.29

保罗《疑义》第二卷

<a id="10.3.29.pr."></a>

**序言（pr.）** 如果某人误以为自己与梅维乌斯共有一块土地，实际上该土地是与提提乌斯共有，而他为土地支出了费用，较为正确的意见是，他可以提起共有物分割之诉。也就是说，他知道该物共有，却不知道共有人是谁；他并非在处理他人的事务，而是在维护自己的财产利益。其诉权产生于费用所及之物，而非共有人本人。最后，我们说，未成年人也应在法官依职权作出的裁判下偿还费用。误以为自己是在为个人所有的土地支出费用，而土地实际上为共有，则属于不同情形：此人既不能提起共有物分割之诉，也不应获准提起准诉讼。因为，知道该物共有的人，是以使他人对自己负债为目的处理他人事务；其错误在于对共有人身份的认识。

<a id="10.3.29.1"></a>

**1.** 庞波尼乌斯写道，可以请求从任何一名共有人中选定法官；即使一名共有人是哑者，对其提起共有物分割之诉也完全适当。

### <a id="10.3.30"></a>10.3.30

斯凯沃拉《答复集》第一卷

无论双方均未占有土地，还是其中一名共有人未占有土地，提起共有物分割之诉均属适当。

### <a id="10.3.31"></a>10.3.31

保罗《答复集》第十五卷

父亲遗产中的两名奴隶，依行政长官命令为未成年人提供劳务而被保留；他们不应被视为已经分割，而应继续归全体共有人共有。
