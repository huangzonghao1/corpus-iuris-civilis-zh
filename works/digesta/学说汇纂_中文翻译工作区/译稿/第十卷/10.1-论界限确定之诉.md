# 第十卷

<a id="10.1"></a>

## 10.1.0　论界限确定之诉（*Finium regundorum*）

### <a id="10.1.1"></a>10.1.1　保罗《评告示》第二十三卷

**正文** 界限确定之诉属于对人之诉，尽管它具有物之返还诉（*rei vindicatio*）的功能。

### <a id="10.1.2"></a>10.1.2　乌尔比安《评告示》第十九卷

<a id="10.1.2.pr."></a>

**序言（pr.）** 此项诉讼适用于乡村不动产，即使其间有建筑物隔开也不例外；因为在界线上种树还是建造建筑物，并无太大区别。

<a id="10.1.2.1"></a>

**1.** 如果法官无法直接划定界限，可以通过裁判上的标的分配（*adiudicatio*）解决争议；而且，如果法官认为为消除旧有界限不明之状况，有必要将界线改经另一地带，也可以通过标的分配及给付判决（*condemnatio*）实现。

### <a id="10.1.3"></a>10.1.3　盖尤斯《评行省告示》第七卷

**正文** 在这种情况下，有必要将一方土地的一部分判归另一方；作为该部分土地的对价，受判归之人应被判令支付确定数额的金钱。

### <a id="10.1.4"></a>10.1.4　保罗《评告示》第二十三卷

<a id="10.1.4.pr."></a>

**序言（pr.）** 即使争议仅涉及一处地点，法官也可以通过标的分配将其划分给双方；分配范围应依其查明的双方各自所有权确定。

<a id="10.1.4.1"></a>

**1.** 在界限确定之诉中，也应计算当事人所涉的利益损失（*id quod interest*）。例如，若有人从显然属于邻人的地点取得某种利益，就此判令其承担责任并非不公。如果测量师仅由一方聘用，则未聘用测量师的一方应被判令分担部分报酬。

<a id="10.1.4.2"></a>

**2.** 诉讼成立之后，孳息也纳入本案审理，因为自此之后当事人须对过失和恶意欺诈负责。但是，判决前取得的孳息并非一概纳入本案：如果当事人善意取得，并已将孳息耗用，就应允许其保有所得；如果其恶意取得，则应当通过返还请求之诉予以追索。

<a id="10.1.4.3"></a>

**3.** 如果有人不遵从法官关于砍伐树木、拆除位于界线上的建筑物或拆除其一部分的命令，应判令其承担责任。

<a id="10.1.4.4"></a>

**4.** 如果有人主张界标被推倒或铲除，审理刑事案件的法官也可以审理界限争议。

<a id="10.1.4.5"></a>

**5.** 如果一处土地由两人共有，另一处土地由三人共有，即使争议地点一方有数名所有人，法官仍可将该地点判归其中一方；因为界限应视为判归土地，而非判归个人。此时将地点判归数人时，每人均取得其：

<a id="10.1.4.6"></a>

**6.** 在该土地上所占有的份额；以未分割方式共有土地的人之间，不相互判令承担责任，因为他们之间不被视为存在此项诉讼。

<a id="10.1.4.7"></a>

**7.** 如果我与你共有一处土地，而我单独拥有一处邻近土地，我们能否提起界限确定之诉？庞波尼乌斯写道，我们不能提起此诉，因为我与我的共有人在本诉中不能互为对方当事人，而被视为同一方。他还说，甚至不应授予准诉权，因为拥有自有土地的人可以出售其共有土地或自有土地，然后再提起诉讼。

<a id="10.1.4.8"></a>

**8.** 界限确定之诉不仅可以在两处土地之间提起，也可以在三处或更多土地之间提起；例如，数处土地彼此相邻，其中可能有三处或四处。

<a id="10.1.4.9"></a>

**9.** 界限确定之诉也可以在缴纳地租的土地（*agri vectigales*）之间提起；可以在相邻两地的用益权人之间提起，也可以在一方为邻地用益权人、另一方为该土地所有人的情形下提起；依质权占有土地之人之间，也可以提起此诉。

<a id="10.1.4.10"></a>

**10.** 此项诉讼适用于乡村不动产之间的界线；城市不动产之间则不适用，因为城市不动产通常称为邻接，而不称为相接，并且通常以共有墙分隔。因此，即使乡村建筑物彼此相连，也不能提起此项诉讼；但在城市中，花园之间可能留有足够宽的地带，以致仍可提起界限确定之诉。

<a id="10.1.4.11"></a>

**11.** 如果有河流或公用道路隔在其间，就不认为土地彼此相接，因此不能提起界限确定之诉：

### <a id="10.1.5"></a>10.1.5　保罗《评萨宾》第十五卷

**正文** 因为在此情形下，横亘于双方之间的是公用道路或河流，而非邻人的土地。

### <a id="10.1.6"></a>10.1.6　保罗《评告示》第二十三卷

**正文** 但是，如果有私人水沟隔在其间，可以提起界限确定之诉。

### <a id="10.1.7"></a>10.1.7　莫德斯蒂努斯《学说汇编》第十一卷

**正文** 对土地面积可以指定仲裁人。如果有人据称在某一区域占有较大面积，而其他人占有的面积较小，则前者应被强制为后者划定一块完整地块。对此已有敕答作出规定。

### <a id="10.1.8"></a>10.1.8　乌尔比安《意见集》第六卷

<a id="10.1.8.pr."></a>

**序言（pr.）** 如果河流泛滥使土地界限模糊混乱，因而使某些人有机会侵占其无权占有的地点，行省总督应命令他们不得占用他人土地，应将土地返还所有人，并由测量师查明和标示界标。

<a id="10.1.8.1"></a>

**1.** 审理界限争议之人的职务包括派遣测量师，并由其裁断界限本身的争议；如案情需要，为求公平，还应使争议地点呈现在其本人眼前进行勘察。

### <a id="10.1.9"></a>10.1.9　尤利安《学说汇纂》第八卷

**正文** 即使共有人已经提起共有物分割之诉，或者已经出卖土地，界限确定之诉仍然存续。

### <a id="10.1.10"></a>10.1.10　尤利安《学说汇纂》第五十一卷

**正文** 共有物分割之诉、遗产分割之诉和界限确定之诉具有这样的性质：在每一诉讼中，各当事人均兼具双重诉讼地位，既是提起诉讼之人，也是其对方当事人。

### <a id="10.1.11"></a>10.1.11　帕比尼安《答复集》第二卷

**正文** 在界限争议中，应当遵循旧有界标，以及诉讼开始前编制的土地登记册所具有的证明力；但如果能够证明，土地界限后来因继承关系变更或占有人的任意处置，随着土地增加或减少而有所变动，则不在此限。

### <a id="10.1.12"></a>10.1.12　保罗《答复集》第三卷

**正文** 就所有权争议而言，应当遵循曾同时拥有两处土地之人在出售其中一处时所指明的界限；不应遵循先前区分各个土地的界标，因为对相邻土地界限的指明可以在两处土地之间确立新的界限。

### <a id="10.1.13"></a>10.1.13　盖尤斯《评〈十二表法〉》第四卷

**正文** 应当知道，在界限确定之诉中，须遵守一项规则；该规则在某种程度上仿照据说由梭伦在雅典制定的法律。该法律内容如下：*ean tis ahimasian par' allotriw xwriw orugy, ^ orutty^ ton horon my parabainein: ean teixion, poda apoleipein: ean de oikyma, duo podas. ean de tafon y bovron orutty, hoson to bavos y, tosouton apoleipein: ean de frear, orguian. elaian de kai sukyn ennea podas apo tou allotriou futeuein ta de alla dendra pente podas*〔释文：如果有人在邻地旁修筑石篱，不得越过界限；如建墙，须留一足间距；如建房屋，须留两足。如挖墓穴〔原文随即订正：应为沟渠〕或坑，须留出与其深度相等的间距；如挖井，应留一寻。橄榄树和无花果树须种在距邻地九足之外，其他树木须距邻地五足。〕〔底本拉丁释义有疑误：作“*aedidicet*”，疑为“*aedificet*”；底本并将 *sepulchrum* 随即校为 *fossam*，译文依其校语处理。〕
