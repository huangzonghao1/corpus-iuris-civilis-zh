## 17.1.0　论委任之诉及其反诉（*Mandati vel contra*）

### <a id="17.1.1"></a>17.1.1　保罗《评告示》第三十二卷

<a id="17.1.1.pr."></a>

**序言（pr.）** 委任之债以缔约双方的合意为基础。

<a id="17.1.1.1"></a>

**1.** 因此，也可以通过使者或书信接受委任。

<a id="17.1.1.2"></a>

**2.** 同样，无论写下“我请求”“我愿意”“我委任”，还是使用其他任何措辞，均产生委任之诉。

<a id="17.1.1.3"></a>

**3.** 同样，委任可以约定在将来某一日期履行，也可以附条件订立。

<a id="17.1.1.4"></a>

**4.** 委任若非无偿即属无效，因为委任源自职责和友谊；有偿报酬与职责相悖。若约定金钱报酬，关系便更接近租赁。

### <a id="17.1.2"></a>17.1.2　盖尤斯《日常法律事务论》（又称《金言集》）第二卷

<a id="17.1.2.pr."></a>

**序言（pr.）** 委任可以基于下列利益关系在我们之间成立：你受托事务仅为我的利益、仅为他人利益、兼为我的利益和他人利益、兼为我的利益和你的利益，或兼为你的利益和他人利益。但如果委任仅为你的利益，就毫无必要；因此不产生任何债务关系。

<a id="17.1.2.1"></a>

**1.** 委任仅为我的利益，例如我委托你处理我的事务、为我购买土地，或为我作保证人。

<a id="17.1.2.2"></a>

**2.** 委任仅为他人利益，例如我委托你处理提提乌斯的事务、为他购买土地，或为他作保证人。

<a id="17.1.2.3"></a>

**3.** 委任兼为我和他人利益，例如我委托你处理我和提提乌斯的事务、为我和提提乌斯购买土地，或为我们二人作保证人。

<a id="17.1.2.4"></a>

**4.** 委任兼为你和我的利益，例如我委托你以利息为条件，向为我的利益借款的人提供借款。

<a id="17.1.2.5"></a>

**5.** 委任兼为你和他人利益，例如我委托你向提提乌斯提供有息借款；但若我委托你无息借款，委任便仅为他人利益。

<a id="17.1.2.6"></a>

**6.** 委任仅为你的利益，例如我委托你把自己的钱投入购买地产而不用于放贷，或反过来，委托你放贷而不投入购买地产。这类委任更像建议而非委任，因此不产生债务关系；因为无人因建议而承担责任。即使建议对接受建议者不利，结论也相同，因为每个人都可以自行判断该建议是否对自己有利。

### <a id="17.1.3"></a>17.1.3　保罗《评告示》第三十二卷

<a id="17.1.3.pr."></a>

**序言（pr.）** 此外，在委任关系中还涉及这样一点：委任人的处境有时不能因此改善，有时可以改善，但绝不会恶化。

<a id="17.1.3.1"></a>

**1.** 如果我委托你为我购买某物，却没有规定价款，而你已经买下，双方均可提起诉讼。

<a id="17.1.3.2"></a>

**2.** 但如果我规定了价款，而你以更高价格购买，有些人否认你可以提起委任之诉，即使你愿意放弃超出部分亦然；因为如果我不愿意，便不能对你起诉，而你却可以自行选择是否对我起诉，这显然不公平。

### <a id="17.1.4"></a>17.1.4　盖尤斯《日常法律事务论》（又称《金言集》）第二卷

但普罗库鲁斯正确地认为，你可以在已约定的价款范围内起诉；这一观点确实更为宽厚。

### <a id="17.1.5"></a>17.1.5　保罗《评告示》第三十二卷

<a id="17.1.5.pr."></a>

**序言（pr.）** 因此，必须谨慎遵守委任的界限：

<a id="17.1.5.1"></a>

**1.** 超越委任范围的人，视为另行处理了其他事项；如果其未履行所接受的委任，就应承担责任。

<a id="17.1.5.2"></a>

**2.** 因此，如果我委托你以一百购买塞伊乌斯之屋，而你却以更高价格购买了提提乌斯之屋，即使价款只有一百或更低，也不算履行了委任。

<a id="17.1.5.3"></a>

**3.** 同样，如果我委托你以一百出售我的土地，而你以九十出售；我随后请求返还土地，你不得援用抗辩，除非你把依我委任所欠缺的差额补给我，并在一切方面使我不受损失。

<a id="17.1.5.4"></a>

**4.** 如果主人命令奴隶以确定金额出售某物，而奴隶以较低价格出售，主人同样可以请求返还该物；除非得到充分赔偿，否则奴隶不得援用抗辩。

<a id="17.1.5.5"></a>

**5.** 如果我委托你以十购买斯提库斯，而你以较低价格买下，或以同样价格买下并为奴隶额外取得其他物品，那么委任人的处境可以改善；因为这两种情形下，你都没有超过约定价款，或者实际支出低于约定价款。

### <a id="17.1.6"></a>17.1.6　乌尔比安《评告示》第三十一卷

<a id="17.1.6.pr."></a>

**序言（pr.）** 如果约定给予酬谢，只是出于感谢之意，仍可提起委任之诉。

<a id="17.1.6.1"></a>

**1.** 如果某人受委托管理他人的事务，应以委任之诉起诉他，而不应正当地对他提起无因管理之诉；因为他承担责任，并非仅因其管理了事务，而是因为他接受了委任。因此，即使他实际上没有管理事务，也仍然承担责任。

<a id="17.1.6.2"></a>

**2.** 如果我容许某人为我作保证人或以其他方式为我介入，我就因委任承担责任；但若该人违背我的意愿而介入、意在赠与，或是作为无因管理人行事，则不产生委任之诉。

<a id="17.1.6.3"></a>

**3.** 对于不正当事项，不存在有效委任，因此不得提起委任之诉。

<a id="17.1.6.4"></a>

**4.** 如果你接受我的委任，办理一件并非为我利益的事，例如为塞伊乌斯介入或向提提乌斯放款，我仍可对你提起委任之诉，我也因此对你负有义务；塞尔苏斯在《学说汇纂》第七卷中如此写道。

<a id="17.1.6.5"></a>

**5.** 当然，如果我委托你办理一件对你有利的事，除非该事也对我有利，否则不产生委任之诉。或者，如果你若非受我委托便不会办理该事，即使该事并非为我的利益，也仍可提起委任之诉。

<a id="17.1.6.6"></a>

**6.** 尤利安在《学说汇纂》第十三卷中提出如下问题：如果主人命令自己的代理人取一定数额的钱，并由代理人承担风险放贷；代理人只须向主人支付固定利息，若能以更高利息放款，超出部分由代理人获利，这笔钱是否应视为借给代理人的款项？尤利安回答说，应当如此。当然，如果代理人受托管理主人的全部事务，他也因委任承担责任；正如债权人管理其债务人事务时，该债务人通常因委任承担责任一样。

<a id="17.1.6.7"></a>

**7.** 有一位名叫马里乌斯·保罗的人为达芙妮作保证，并约定因其保证取得报酬；他又以他人名义，约定根据诉讼结果向自己支付确定数额。后来，克劳狄乌斯·萨图尔尼努斯裁判官命令他交付更多收益，并禁止他收取辩护报酬。我起初认为，他曾保证判决债务的履行，仿佛成为诉讼承买人；他想通过对达芙妮提起委任之诉，追偿自己被判决支付的款项。但神圣的两位皇帝最为正确地作出敕答：由于他约定收取报酬后参与了这种诉讼买卖，因其狡诈，不享有任何诉权。马尔凯卢斯则这样论及收取钱款后作出承诺的人：如果双方约定他自行承担风险，他就没有诉权；如果并非如此约定，他更适宜享有准诉权。这个观点符合事务的实际需要。

### <a id="17.1.7"></a>17.1.7　帕皮尼安《答复录》第三卷

如果代理人被规定了薪俸，并在非常程序中请求给付，应考察主人是否意在酬谢代理人的劳务，因而应尊重双方约定；还是说，代理人违背善良风俗，以高额报酬承买诉讼结果。

### <a id="17.1.8"></a>17.1.8　乌尔比安《评告示》第三十一卷

<a id="17.1.8.pr."></a>

**序言（pr.）** 如果我指定某人为代理人，而他没有把案件文书交还给我，我可以基于何种诉讼起诉他？拉贝奥认为，应提起委任之诉；那些认为可以就此提起寄托之诉的观点并不可取，因为判断诉讼性质，应考察每种契约的成立起点和原因。

<a id="17.1.8.1"></a>

**1.** 如果对方因代理人与其串通而获判无责，该代理人也应因委任承担责任；但若代理人无力偿债，就应准许对因串通而获判无责的被告提起恶意之诉。

<a id="17.1.8.2"></a>

**2.** 此外，代理人显然还因委任之诉而有义务继续办理其所承接的诉讼。

<a id="17.1.8.3"></a>

**3.** 如果某人委托他人管理自己受托办理的另一人的事务，他可以提起委任之诉，因为他本人也负有责任——他之所以承担责任，是因为自己可以起诉。虽然通常认为代理人在争讼程序确定之前不能再指定代理人，但委任之诉仍然成立；他只是不能授权他人代为起诉。

<a id="17.1.8.4"></a>

**4.** 如果监护人委托共同监护人为被监护人购买奴隶，而对方没有购买，能否提起委任之诉？被委任者究竟仅受委任之诉追究，还是也受监护之诉追究？尤利安对此作了区分：他说，应考察监护人委托共同监护人购买的是哪一类奴隶。如果是多余或会造成负担的奴隶，被委任者仅因委任承担责任，不因监护关系承担责任；如果是必要的奴隶，他和其他监护人不仅受监护之诉追究，而且其他监护人也应负责，因为他们若不委托共同监护人，本应亲自为被监护人购买必要奴隶。因此，他们不能以已委托共同监护人为由免责，因为本来就应购买。尽管如此，他们仍可提起反向委任之诉，因为对方没有遵从委任。反过来，尤利安说，实际购买奴隶的监护人也可以对共同监护人提起反向委任之诉。

<a id="17.1.8.5"></a>

**5.** 某自由人善意地为他人服役时，委托提提乌斯将自己赎出，并交给提提乌斯一笔本应随自己而走、而不应留在善意买受人处的特有产钱款；提提乌斯付清价款后将他释放，后来该人被宣告为自由出生者。尤利安说，他可以对受托为其赎身的人提起委任之诉，但委任之诉仅包括要求对方将其对出卖人享有的诉权让与自己。尤利安还说，如果交付的是属于善意买受人特有产的款项，就不能向他让与任何诉权，因为他并无诉权：买受人是用自己的钱支付的。相反，他仍因买卖对买受人负有义务；但该诉讼也无实际意义，因为他通过此诉取得多少，就必须在买卖之诉中向买受人交付多少。

<a id="17.1.8.6"></a>

**6.** 只有在委任人有利益受损时，才产生委任之诉；如果没有利益受损，委任之诉便不成立，并且仅在受损范围内成立。例如，我委托你购买土地；如果买到土地对我有利，你就承担责任；如果我自己或他人已买下同一土地，且我并无其他利益，委任之诉便不成立。我委托你管理事务；如果没有发生任何损失，即使无人管理事务，也不产生诉讼；如果另有人已妥善办理，委任之诉同样不成立。其他类似情形也应适用相同规则。

<a id="17.1.8.7"></a>

**7.** 如果保证人不知道债务人已经清偿，或债务人已通过受领免除或协议解除，而仍以债务人财产清偿，就不因委任承担责任。

<a id="17.1.8.8"></a>

**8.** 这一规则也适用于保证人的诉权。神圣的两位皇帝在一项敕答中说明了这一点，敕答说：“致卡图卢斯·尤利安努斯。如果为你作保证的人明知而故意不行使上诉救济，导致其被判决承担超过债务实际数额的责任，你可以依据法官的衡平裁量，在他们提起委任之诉时为自己辩护。”因此，如果他们并不知情，其不知情可以免责；如果他们知情，就有义务提起上诉，否则其不作为即属欺诈。但如果他们因贫困而无法上诉，是否又应如此？他们的贫困足以使其免责。如果他们曾正式通知债务人，表示由债务人自行决定是否上诉，我认为其主张仍有根据。

<a id="17.1.8.9"></a>

**9.** 有能力返还却不予返还的人，视为实施欺诈：

<a id="17.1.8.10"></a>

**10.** 因此，如果我委托你购买一名奴隶，而你已经买下，就有义务返还给我。如果你因欺诈而疏于购买——例如收了钱却让别人去买——或有重大过失——例如出于偏袒而容许别人买下——也应承担责任。如果你买下的奴隶逃走，若因你的欺诈所致，你就应负责；若无欺诈也无过失，你只须保证该奴隶一旦回到你的权力之下，便将其返还给我。即使你愿意返还，也仍须实际交付。如果已就权利瑕疵提供担保，或你可以要求对方提供担保，我认为，只要你依据本诉将自己的诉权让与我，并使我成为为自身利益行事的代理人，就足够了；你不必交付超过自己能够追偿的数额。

### <a id="17.1.9"></a>17.1.9　保罗《评告示》第三十二卷

你还应就自己的行为提供担保。

### <a id="17.1.10"></a>17.1.10　乌尔比安《评告示》第三十一卷

<a id="17.1.10.pr."></a>

**序言（pr.）** 如果代理人替我购买土地，规则也相同：受托办理事务的人只须保证善意。

<a id="17.1.10.1"></a>

**1.** 如果代理人曾就奴隶的健康状况或其他瑕疵提供担保，或能够提供担保，规则亦同。如果他因过失而未设法取得担保，就应受判决承担责任。

<a id="17.1.10.2"></a>

**2.** 如果代理人从替我购买的土地取得了孳息，法官也应命其交付这些孳息。

<a id="17.1.10.3"></a>

**3.** 如果我的代理人持有我的钱款，迟延期间无疑应向我支付利息。如果他以我的钱款放贷并取得利息，我们也应当说，无论我是否委托，他都应交付自己取得的全部收益；这符合诚信原则，否则他会从他人财产中获利。如果他没有放贷，而是把钱用于自己事务，则应按各地通行的法定利率向他请求利息。最后，帕皮尼安说，即使代理人已收取利息，却将其用于自己事务，也应支付利息。

<a id="17.1.10.4"></a>

**4.** 如果某人委托提提乌斯向自己的代理人借款，帕皮尼安在《答复录》第三卷中写道，提提乌斯不能提起委任之诉，因为他因借款而负有债务。因此，如果利息未写入口约，他不能仿佛基于委任而请求利息。

<a id="17.1.10.5"></a>

**5.** 同一卷中，帕皮尼安还记载：如果有人因保证借款而受判决，而作出保证是因为主人曾委托代理人借款，应给予其准经理人之诉；因为在这种情形下，也可以认为主人已委任代理人接受借款。

<a id="17.1.10.6"></a>

**6.** 如果我委托你向提提乌斯作出口约，我可以依委任之诉请求你以受领免除的方式解除他的债务；如果我愿意，也可以请求你将债权让与我或我指定的其他人。帕皮尼安在同一卷中写道，如果母亲为女儿给付嫁资，并依女儿的委任立即或日后作出口约，母亲也因委任承担责任，尽管实际给付嫁资的是她本人。

<a id="17.1.10.7"></a>

**7.** 如果某人命令自己的代理人和奴隶所办理的一切事务，只有在塞姆普罗尼乌斯介入时才算经其认可；而钱款放贷时发生了不利结果，则没有欺诈的塞姆普罗尼乌斯不承担责任。事实上，那些并非以代理人身份介入，而只是出于友谊承诺提供意见、提醒代理人和管事人并加以指导的人，不因委任承担责任；如果其实施欺诈，也不是因委任，而更适宜提起恶意之诉。

<a id="17.1.10.8"></a>

**8.** 如果我委托代理人无息向提提乌斯提供我的钱款，而代理人却收取利息放款，我们要考察他是否也应向我返还利息。拉贝奥写道，他应当返还；即使我委托他无息放款，结论也一样。不过，拉贝奥说，如果他自行承担风险放款，就不产生请求利息的委任之诉。

<a id="17.1.10.9"></a>

**9.** 拉贝奥还说，委任之诉允许双方核算账目，这一观点正确。正如代理人须返还孳息，也应扣除其为取得孳息而支出的费用。如果代理人为前往地产而支出旅费，我认为也应核算这些费用；但如果他按薪俸受聘，且双方约定由其自行承担此类旅费，即从薪俸中支付，则不在此限。

<a id="17.1.10.10"></a>

**10.** 拉贝奥还说，如果代理人未经委任，为自己的享乐做了某事，只要不损害主人，就应允许他取走该物；除非主人愿意核算这项支出。

<a id="17.1.10.11"></a>

**11.** 保证人和受委任人即使未经过诉讼而清偿，也享有委任之诉。

<a id="17.1.10.12"></a>

**12.** 尤利安概括地说：如果保证人以自己的名义放弃了债务人本人不能援用的抗辩，若该抗辩不太光彩，他仍可提起委任之诉；但如果该抗辩是债务人本人可以援用的，且保证人明知而放弃，就不得提起委任之诉——前提是他有机会通知债务人并让其自行应诉，无论以本人名义还是以代理人名义应诉。

<a id="17.1.10.13"></a>

**13.** 如果债权人出于赠与目的，以受领免除方式免除保证人的债务，我认为，如果债权人意在酬谢保证人，保证人可以提起委任之诉。如果债权人是因临终赠与而免除其债务，或在遗嘱中遗赠该项免除，更应如此。

### <a id="17.1.11"></a>17.1.11　庞波尼《评普劳提乌斯》第三卷

如果我后来成为曾因保证之诉判我承担责任之人的继承人，我可以提起委任之诉。

### <a id="17.1.12"></a>17.1.12　乌尔比安《评告示》第三十一卷

<a id="17.1.12.pr."></a>

**序言（pr.）** 但如果债权人免除保证人的债务，并非意在酬谢保证人，而是出于赠与目的，保证人就不得提起委任之诉。

<a id="17.1.12.1"></a>

**1.** 马尔凯卢斯承认，如果某人打算赠与保证人，因而替他向债权人清偿，保证人可以提起委任之诉。

<a id="17.1.12.2"></a>

**2.** 当然，如果保证人是家子或奴隶，而我为了赠与他们替其清偿，马尔凯卢斯说，家父或主人不得提起委任之诉；因为我并非意在赠与家父。

<a id="17.1.12.3"></a>

**3.** 但马尔凯卢斯在同一处还说，如果奴隶作为保证人清偿，主人可以提起委任之诉。

<a id="17.1.12.4"></a>

**4.** 如果家子未经家父命令而作保证人，且特有产中没有财物，委任之诉便不成立；如果家父命令其作保证，或款项从特有产中支付，家父就更有理由提起委任之诉。

<a id="17.1.12.5"></a>

**5.** 如果我委托家子代我清偿，涅拉提乌斯说，无论是家父本人清偿，还是家子从特有产中清偿，家父都可以提起委任之诉；这有其道理，因为由谁清偿与我无关。

<a id="17.1.12.6"></a>

**6.** 如果我委托家子代我清偿，而他在脱离家父权后才清偿，可以确定，应准许家子提起事实之诉；家父在子脱离家父权后清偿，则可以提起无因管理之诉。

<a id="17.1.12.7"></a>

**7.** 接受委任的人，例如受托管理全部事务或某一项事务的代理人，可以提起反向委任之诉。

<a id="17.1.12.8"></a>

**8.** 帕皮尼安由此提出如下问题：一名保护人买下一处地产，已经支付三分之二价款，随后命令自己的被释奴接收该地产并支付余款；被释奴付清价款后，又同意将地产交还给作为出卖人的保护人。被释奴能否通过反向委任之诉请求返还三分之一价款？帕皮尼安说，如果被释奴起初接受的是委任而非赠与，就可以通过反向委任之诉请求返还扣除其期间取得的租金后的余额；如果保护人将地产赠与被释奴，则应认为被释奴后来也把地产赠与保护人。

<a id="17.1.12.9"></a>

**9.** 如果你委托我为你购买某物，而我用自己的钱支付价款，我可以提起委任之诉请求返还价款；如果我使用你的钱购买，但又为该买卖善意支出其他费用，也可以提起反向委任之诉。你若拒绝接受买下的物品，结论亦同；你委托其他事务而我为此支出费用时，也应如此。我不仅可以请求返还支出，也可以请求利息。利息并非只应从迟延时起算；法官还应估算相应利息。例如，有人向自己的债务人收款后用于清偿，而原本可以取得高额利息，就应公平地考虑这一点；或者他自己借款并支付了高额利息。即使他没有使债务人免于支付利息，而自己却承担了利息费用；或他虽使债务人免付较低利息，自己却借入高息款项以履行信用责任，我毫不怀疑，他都可以在委任之诉中请求利息。依既定规则，法官应按照公平和善良原则综合判断这一切。

<a id="17.1.12.10"></a>

**10.** 我给你钱，让你替我清偿债权人；你却没有清偿。你应向我支付利息，因为在这种情形下，债权人也会向我请求本金及利息。塞维鲁皇帝在致哈德里安努斯的敕答中如此说明。

<a id="17.1.12.11"></a>

**11.** 如果一个放荡的青年委托你为妓女作保证，而你明知情形仍接受委任，就不得提起委任之诉；这如同你明知对方要挥霍钱财，却仍借钱给他。但如果他进一步直接委托你借钱给妓女，委任之诉也不成立，因为这种委任违背诚信。

<a id="17.1.12.12"></a>

**12.** 有人给朋友写信说：“请你关照我的朋友塞克斯提利乌斯·克雷申斯。”他并不因委任承担责任，因为写信的目的更像是推荐此人，而不是委托事务。

<a id="17.1.12.13"></a>

**13.** 如果有人委托他人向家子放款，而家子并非违反元老院决议借款，但依具体原因，家父可能因特有产之诉、因财产受益之诉或基于命令之诉承担责任，这项委任就是允许的。我还要进一步说：如果我不确定家子是否违反元老院决议借款，并且通常不会向违反该决议借款的人放款；此时有人介入并表示家子并未违反决议，又说“由我承担风险放款”，那么我认为委任成立，该人应因委任承担责任。

<a id="17.1.12.14"></a>

**14.** 如果我已经放款，之后才委托债权人继续提供信用，帕皮尼安极为正确地说，这不构成委任。显然，如果我委托你等待一段时间、暂不催促债务人清偿，并表示由我承担风险，我认为债权债务关系的全部风险都应由委任人承担。

<a id="17.1.12.15"></a>

**15.** 同一位帕皮尼安说，如果监护人委托他人承接或确认自己所设立的债权，该监护人应因委任承担责任；当然，这是对自己的被监护人或其保佐人承担责任。

<a id="17.1.12.16"></a>

**16.** 如果我委托你追收一笔钱，之后改变主意，我本人或我的继承人能否提起委任之诉？马尔凯卢斯说，委任之诉不再成立，因为委任已随委任人意思终止而消灭。如果我委托你追收，后来又禁止你追收，而你已经收回款项，债务人即获免责。

<a id="17.1.12.17"></a>

**17.** 马尔凯卢斯还写道，如果某人委托他人在自己死后为自己建造纪念碑，其继承人可以提起委任之诉。我认为，接受委任的人如果用自己的钱建造，也可以提起委任之诉，除非委任明确要求其自费建造；因为他本可请求委任人提供建造所需款项，尤其是在他已经为建造购置某些材料时。

### <a id="17.1.13"></a>17.1.13　盖尤斯《评行省告示》第十卷

如果我委托你在我死后为我的继承人购买土地，规则也相同。

### <a id="17.1.14"></a>17.1.14　乌尔比安《评告示》第三十一卷

<a id="17.1.14.pr."></a>

**序言（pr.）** 保证人的继承人在清偿债务后可以提起委任之诉，这毫无疑问。但如果继承人出售遗产，而买受人清偿了债务，继承人是否可以提起委任之诉，则有疑问。尤利安在《学说汇纂》第十三卷中写道，继承人之所以享有委任之诉，是因为他因买卖之诉负有让与其诉权的义务；他之所以能提起买卖之诉，是因为自己可以让与这些诉权。

<a id="17.1.14.1"></a>

**1.** 如果保证人留下两名继承人，其中一人从共同继承人处买下遗产，之后向受约人清偿死者保证的全部债务，那么他可以依据口约或买卖契约使共同继承人对其负债。因此，他可以提起委任之诉。

### <a id="17.1.15"></a>17.1.15　保罗《评萨宾》第二卷

如果我委托你购买土地，之后又写信禁止你购买，而你在尚未知悉我的禁令之前已经买下土地，我仍应因委任对你承担责任；因为不能使接受委任的人遭受损失。

### <a id="17.1.16"></a>17.1.16　乌尔比安《评告示》第三十一卷

如果某人委托我在我自己的财产上做某事，而我已经做了，能否提起委任之诉？塞尔苏斯在《学说汇纂》第七卷中说，他曾就此作答：据说奥勒里乌斯·奎图斯曾委托自己的客人兼医生，在他位于拉文纳、每年都去休养的园林内，自费建造一个球场、暖浴室，以及若干适合其健康状况的设施。因此，应扣除建筑物增值的金额；超过增值的支出，他可以通过委任之诉请求返还。

### <a id="17.1.17"></a>17.1.17　保罗《评萨宾》第七卷

如果我委托你向提提乌斯追收十，而在款项尚未收回前我就对你提起委任之诉；若你在判决前已经收回款项，可以确定，法官应判你承担责任。

### <a id="17.1.18"></a>17.1.18　乌尔比安《评萨宾》第四十卷

允许他人委托向自己放款的人，应被视为自己也作出了委任。

### <a id="17.1.19"></a>17.1.19　乌尔比安《评萨宾》第四十三卷

如果我的奴隶委托他人买下自己、使自己获赎，庞波尼精辟地讨论了一个问题：买下该奴隶的人，能否反过来起诉出卖人，要求其收回奴隶，因为委任之诉可以由双方互相提起？庞波尼说，若因我的奴隶所为，迫使我收回原本打算永久转让的奴隶，极不公平。我的委任责任也不应比委托他人将奴隶卖给你的情形更重。

### <a id="17.1.20"></a>17.1.20　保罗《评萨宾》第十一卷

<a id="17.1.20.pr."></a>

**序言（pr.）** 接受委任的人不应因委任而留有任何财物；正如他若未能追收有息借款，也不应因此遭受损失。

<a id="17.1.20.1"></a>

**1.** 如果某人为缺席者作保证人，可以提起无因管理之诉；因为委任之诉不可能成立，委任并未先于保证发生。

### <a id="17.1.21"></a>17.1.21　乌尔比安《评萨宾》第四十七卷

如果我依据他人的委任为你作保证人，我不能对你提起委任之诉；正如有人根据他人的委任作出口约，也不能因此对你起诉。但如果我作保证并非只考虑其中一人的委任，而是同时考虑你和另一人的委任，就可以对你也提起委任之诉；正如两人共同委托我向你放款时，我可以要求两人都承担责任。

### <a id="17.1.22"></a>17.1.22　保罗《评告示》第三十二卷

<a id="17.1.22.pr."></a>

**序言（pr.）** 如果我委托你在将来某一日期为我作保证，而你却无期限地作了保证并已付款，较妥当的答复是：在该日期到来之前，你尚不能提起委任之诉。

<a id="17.1.22.1"></a>

**1.** 同样，如果我应在将来某一日期履行债务，而你根据我的委任在同一日期为我作保证，却在该日期之前已经付款，能否立即提起委任之诉，也曾引起讨论。有些人认为，委任之诉可以立即提起，但赔偿数额应减少，相当于我因在约定日期后才付款本可获得的利益。较好的观点是，在此期间连这部分金额也不能提起委任之诉，因为我仍享有不必提前清偿的利益。

<a id="17.1.22.2"></a>

**2.** 有时，某人是在处理自己的事务，却仍可以提起准委任之诉。例如，我的债务人将其自己的债务人交由我追索，并由他承担风险；又如，依保证人的请求，我对主债务人起诉。尽管我是在追索自己的债权，同时也在办理对方的事务。因此，我未能保全的差额，可以通过委任之诉请求。

<a id="17.1.22.3"></a>

**3.** 如果作为质物的财产正在出售，抵押人安排他人作为名义买受人，并委托其买下这些物品，应认为成立委任，尽管严格而言委任并未成立；因为人不可能购买自己所有的物品。

<a id="17.1.22.4"></a>

**4.** 尤利安写道，委任之债可以涉及接受委任者自身利益，这一点尤其可由下例证明：数名继承人出售遗产时，我委托其中一人购买遗产中的某物，即使就该部分而言他本人也是继承人，他仍因委任承担责任，也可以提起委任之诉。如果他因接受委任而没有把该物卖给第三人，依诚信原则，我应支付他原本可以出售该物的价款。反过来，如果买方本想购买自己需要的物品，却因曾指示继承人将物品卖给自己而未参与竞买，按照委任之诉赔偿其因未能买到该物所受的损失，最为公平。

<a id="17.1.22.5"></a>

**5.** 财产被没收的人可以委托他人购买该财产；如果买受人不履行承诺，可以提起准委任之诉。这项规则之所以被采纳，是因为财产被没收后取得的任何其他财产，都不会随之归入国库。

<a id="17.1.22.6"></a>

**6.** 如果有人接受委任，去掠夺神庙、伤害或杀害他人，就不能依据委任之诉取得任何利益，因为委任本身不正当。

<a id="17.1.22.7"></a>

**7.** 如果我给你一百，让你交给提提乌斯，而你没有交付，反而把钱花掉，普罗库鲁斯说，你既因委任也因盗窃承担责任；但如果我让你自行决定如何处分这笔钱，则只因委任承担责任。

<a id="17.1.22.8"></a>

**8.** 如果我委托你的奴隶代我偿还我欠你的债务，涅拉提乌斯写道：即使奴隶借了钱，并在你的账目中记作仿佛从我处收到了这笔款项，只要他借款时并非为了以我的名义付款，我既未获解除债务，你也不能对我提起委任之诉。相反，如果奴隶借款的目的就是代我付款，结论便完全相反。至于是另一名奴隶还是同一名奴隶以你的名义借款，用来替我偿债，并无区别。这一观点更为正确，因为债权人若收取的是他自己的钱，债务人并未因此获得解除。

<a id="17.1.22.9"></a>

**9.** 我的逃亡奴隶身处窃贼处时取得钱款，并用钱买了几名奴隶；提提乌斯从出卖人处受领交付了这些奴隶。梅拉说，如果我的奴隶曾委托提提乌斯通过交付方式受领奴隶，而且提提乌斯确实是应奴隶请求行事，我可以提起委任之诉，要求提提乌斯返还奴隶。若出卖人未经奴隶同意便将奴隶交付给提提乌斯，我则可以对出卖人提起买卖之诉，请求其向我交付奴隶；如果出卖人认为自己有义务交付，实际却不应交付，也可以对提提乌斯提起返还之诉。

<a id="17.1.22.10"></a>

**10.** 如果遗产管理人虽已出售财产，却没有向债权人付款，特雷巴提乌斯、奥菲利乌斯和拉贝奥答复说：对在场的债权人，可以提起委任之诉；缺席的债权人则享有无因管理之诉。但如果遗产管理人是受在场债权人委托而行事，缺席者就不能提起无因管理之诉，除非他们也曾委托管理人处理缺席债权人的事务。若在场的债权人认为自己就是全部债权人而作出委任，则应允许缺席债权人对这些委任人提起事实之诉。

<a id="17.1.22.11"></a>

**11.** 正如任何人都可以拒绝接受委任，接受之后就应当完成委任；除非其已声明辞任——但辞任必须为委任人保留完整权利，使其可以亲自或委托他人妥善完成同一事项——或者继续办理会使接受委任者遭受损失。如果有人受委托购买某物，却没有购买，也未声明不再购买；而未购买并非因他人过错，他就应因委任承担责任。正如梅拉也写道，他不应承担更多责任；即使他在已无法妥善购买时，出于欺诈才声明辞任，亦同。

### <a id="17.1.23"></a>17.1.23　赫莫革尼安《法学摘要》第二卷

当然，如果他以健康状况不佳或遭受致命仇敌迫害为由提出免责事由，〔下文续〕

### <a id="17.1.24"></a>17.1.24　保罗《箴言集》第二卷

或者因有关诉讼徒劳无益（*inanes rei actiones*）而提出免责事由，〔下文续〕

### <a id="17.1.25"></a>17.1.25　赫莫革尼安《法学摘要》第二卷

或者以其他正当理由提出免责事由，应当听取其陈述。

### <a id="17.1.26"></a>17.1.26　保罗《评告示》第三十二卷

<a id="17.1.26.pr."></a>

**序言（pr.）** 委任人死亡也是终止委任的原因之一，因为委任因委任人死亡而消灭。不过，如果受托人因不知情而履行了委任，仍可出于衡平目的给予诉权。尤利安也写道，委任人死亡会终止委任，但债务关系有时仍然存续。

<a id="17.1.26.1"></a>

**1.** 如果某人委托自己的债务人向提提乌斯付款，而债务人在不知委任人已死的情况下向提提乌斯付款，应当解除其债务。

<a id="17.1.26.2"></a>

**2.** 即使债务人已经被指定为债权人的债务人，只要债权人接受了这一债务人，就视为保证人的钱款已经付出；即使该债务人无清偿能力，也不影响此结论，因为债权人接受他人所指定的债务人，就等于取得了可靠债权。

<a id="17.1.26.3"></a>

**3.** 如果某人想赠与保证人，而自己的债务人恰好是保证人的债权人；他只要免除该债权人，保证人便可立即提起委任之诉，因为对保证人而言，赠与人向其债权人付款与免除该债权人，利益并无不同。

<a id="17.1.26.4"></a>

**4.** 此外，须知保证人依据委任之诉所能取得的数额，不得超过其实际支付的数额。

<a id="17.1.26.5"></a>

**5.** 依你的委任，我为十作了保证，并向债权人的代理人付款。如果对方确为债权人的代理人，我可以立即提起委任之诉；如果并非代理人，我可以向其请求返还。

<a id="17.1.26.6"></a>

**6.** 委任人不会因受托人没有发生的支出而承担责任。例如，受托人被强盗抢劫、因海难失去财物，或因自己或家人的疾病而支出费用，这些情形应归因于意外，而非委任。

<a id="17.1.26.7"></a>

**7.** 如果我委托你购买的奴隶偷了你的财物，涅拉提乌斯说，只要这件事并非因你的过错发生，你可以通过委任之诉请求将该奴隶交付，以承担诺克萨责任。如果我知道奴隶有这种品行，却没有预先告知你以便防范，则应赔偿你所受损害。

<a id="17.1.26.8"></a>

**8.** 一名工匠受朋友委托，以十买下一名奴隶，并教会其手艺；之后以二十卖出，却被迫在委任之诉中交付所得。后来他又因奴隶身体不健全而被买受人判令承担责任。梅拉说，除非奴隶是在买入后、且非因委任人的恶意而出现该瑕疵，否则委任人不应向工匠赔偿。但如果工匠是依委任人的命令教导奴隶，结论相反：工匠可以请求报酬和生活费用，除非受托时明确要求其无偿教导。

### <a id="17.1.27"></a>17.1.27　盖尤斯《评行省告示》第九卷

<a id="17.1.27.pr."></a>

**序言（pr.）** 如果某人写信委托他人免除自己的债务人，并承诺支付该债务人所欠的款项，就应因委任承担责任。

<a id="17.1.27.1"></a>

**1.** 如果我将奴隶交给你，并约定在我死后由你释放他，委任关系即告成立；我本人也可能因此取得诉权，例如我改变主意后希望取回奴隶。

<a id="17.1.27.2"></a>

**2.** 接受委任的人如果有能力履行，就不应放弃已承诺办理的事务；否则应按委任人所受损失承担责任。如果他发现自己无法履行，应在能够通知时尽早告知委任人，使委任人可以另请他人办理；若本可通知却没有通知，也应按委任人所受损失承担责任。若因某种原因无法通知，则不承担责任。

<a id="17.1.27.3"></a>

**3.** 如果接受委任的人在委任尚未完成时死亡，委任即告终止；因此，即使他的继承人完成了委任，也不能提起委任之诉。

<a id="17.1.27.4"></a>

**4.** 为履行委任而善意支出的费用，无论如何都应予以返还；委任人如果亲自处理事务本可少花费用，并不影响此结论。

<a id="17.1.27.5"></a>

**5.** 如果你依我的委任向提提乌斯放款，而后对我提起委任之诉，只有在你将自己对提提乌斯享有的诉权让与我之后，才能判我承担责任。但如果你已经对提提乌斯起诉，我并不因此免责；我仍须就你无法从提提乌斯处保全的数额承担责任。

### <a id="17.1.28"></a>17.1.28　乌尔比安《评告示》第十四卷

帕皮尼安在《疑义解答》第三卷中说，委任人代债务人付款，并不依法解除该债务人的责任，因为委任人是基于自己的委任、以自己的名义付款。因此，他认为委任人应取得对该债务人的诉权让与。

### <a id="17.1.29"></a>17.1.29　乌尔比安《论疑难》第七卷

<a id="17.1.29.pr."></a>

**序言（pr.）** 如果保证人被起诉时，不知道债权人根本没有向债务人交付钱款，却基于保证关系付款，他能否通过委任之诉追偿所付数额？如果他明知而故意不提出未交付款项或诈欺抗辩，就应视为有欺诈，因为极度疏忽几乎等同于欺诈；如果他不知情，就没有可归责于他的事由。同理，如果债务人本可援用其他抗辩，例如基于协议的抗辩，而保证人不知情、未提出抗辩，应当允许其提起委任之诉。作出承诺的债务人本来能够也应当通知保证人，以免保证人在不知情时清偿本不应清偿的债务。

<a id="17.1.29.1"></a>

**1.** 如果保证人不知道自己的保证无效，却仍然付款，他能否提起委任之诉，也不无讨论余地。如果他不知道的是事实，可以认可其不知情；如果不知道的是法律，则应作不同处理。

<a id="17.1.29.2"></a>

**2.** 如果债务人已经清偿，而保证人不知情又再次清偿，我认为保证人可以提起委任之诉。若保证人未能预见债务人已清偿，应当宽宥；债务人本应通知保证人已付款，以免债权人趁其不知情而欺骗他，并向他索取保证金额。

<a id="17.1.29.3"></a>

**3.** 如果保证人付款后没有通知债务人，而债务人随后又清偿了本不应清偿的款项，也应讨论同一问题。我认为，如果保证人有能力通知却没有通知，应驳回其所提委任之诉；付款后不告知债务人，近乎欺诈。债务人则应将非债清偿返还之诉让与保证人，以免债权人获得双重清偿。

<a id="17.1.29.4"></a>

**4.** 但有些抗辩即使保证人明知而不提出，也不构成欺诈。例如，保证人无论知情与否而未提出代理权抗辩，均属此类。因为这里考察的是诚信；诚信不要求争论法律细节，只要求判断债务是否存在。

<a id="17.1.29.5"></a>

**5.** 在前述所有情形中，如果债权人收取了未曾交付的款项，或对已经收取的款项再次请求清偿，都可以对其提起返还之诉；但如果款项是依判决支付，则不能请求返还，因为既判力排除了返还之诉。不过，债权人会因其狡诈而受到恶意欺诈罪的惩处。

<a id="17.1.29.6"></a>

**6.** 如果保证人仅因期间经过而获免责，却仍向债权人付款，可以正当地对债务人提起委任之诉。虽然保证人付款时已经免责，但他履行了诚信义务并使债务人获得解除；因此，如果他愿意为债务人对抗债权人，最公平的做法是允许其通过委任之诉追回所付款项。尤利安也持此见。

### <a id="17.1.30"></a>17.1.30　尤利安《学说汇纂》第十三卷

如果我把一名奴隶交给你，委托你释放他，之后我的代理人禁止你释放，你若仍然释放了奴隶，我能否对你提起委任之诉？我答复说，如果代理人有正当理由阻止释放这个专为获释而交给我的奴隶，例如后来发现奴隶伪造账目，或企图谋害前主人，而你没有遵从代理人的通知，我就可以起诉你。如果代理人并无正当理由禁止释放奴隶，即使你已经使奴隶获得自由，也不能对你提起委任之诉。
