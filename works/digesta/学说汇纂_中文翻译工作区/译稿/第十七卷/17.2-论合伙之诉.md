## 17.2.0　论合伙之诉（*Pro socio*）

### <a id="17.2.1"></a>17.2.1　保罗《评告示》第三十二卷

<a id="17.2.1.pr."></a>

**序言（pr.）** 合伙可以无限期成立，也就是存续至合伙人死亡；也可以约定存续一定期间、自某一时点起存续，或附条件成立。

<a id="17.2.1.1"></a>

**1.** 在全部财产合伙中，合伙人现有的一切财物立即成为共有财产，

### <a id="17.2.2"></a>17.2.2　盖尤斯《评行省告示》第十卷

因为即使没有特别交付，仍应认为默示地发生了交付。

### <a id="17.2.3"></a>17.2.3　保罗《评告示》第三十二卷

<a id="17.2.3.pr."></a>

**序言（pr.）** 但是，以债权形式存在的财产仍维持其原有状态；合伙人之间应相互提供相应诉权。

<a id="17.2.3.1"></a>

**1.** 明确约定成立全部财产合伙时，遗产、遗赠、受赠之物以及以任何方式取得的财产，也都归入共有财产。

<a id="17.2.3.2"></a>

**2.** 如果约定双方任何一方取得的合法继承财产均属共有，那么问题是：这里的“合法继承”是指依法定继承取得的继承财产，还是也包括依遗嘱取得的继承财产？较为可信的意见是，这仅涉及法定继承。

<a id="17.2.3.3"></a>

**3.** 如果合伙系以恶意或欺诈目的成立，则依市民法当然不发生效力；因为诚实信用与欺诈、恶意相互对立。

### <a id="17.2.4"></a>17.2.4　莫德斯汀《规则集》第三卷

<a id="17.2.4.pr."></a>

**序言（pr.）** 合伙可以通过行为、言词或使者传达的方式成立，这一点毫无疑问。

<a id="17.2.4.1"></a>

**1.** 合伙关系因退伙声明、死亡、人格减等或资不抵债而解散。

### <a id="17.2.5"></a>17.2.5　乌尔比安《评告示》第三十一卷

<a id="17.2.5.pr."></a>

**序言（pr.）** 合伙可以约定为全部财产合伙、某项营业合伙、公税承包合伙，或针对某一特定财物的合伙。

<a id="17.2.5.1"></a>

**1.** 即使合伙人资力并不相等，合伙仍可成立并有效，因为通常资力较弱的一方可以用劳务弥补其按财产比例所欠缺的部分。合伙不得以赠与为目的而正当地成立。

### <a id="17.2.6"></a>17.2.6　庞波尼《评萨宾》第九卷

如果你与我约定成立合伙，并约定合伙份额另行确定，就应依善良之人的裁量确定；依善良之人的裁量，合伙人未必应各占相等份额，例如一方将投入更多劳务、技能或金钱时。

### <a id="17.2.7"></a>17.2.7　乌尔比安《评萨宾》第三十卷

合伙也可以不作特别说明而成立；如果未作区分，应认为合伙涵盖一切由营利所得取得的财物，也就是买卖、出租和承租所产生的收益。

### <a id="17.2.8"></a>17.2.8　保罗《评萨宾》第六卷

因为所谓收益，是指由劳务所产生的收益。

### <a id="17.2.9"></a>17.2.9　乌尔比安《评萨宾》第三十卷

萨宾没有把继承、遗赠以及因死亡或非因死亡所作的赠与列入其中，或许是因为这些并非无由取得，而是因某种功绩而获得。

### <a id="17.2.10"></a>17.2.10　保罗《评萨宾》第六卷

这是因为，我们通常从父母或自由释奴处取得继承财产，仿佛这是我们应得的债务。

### <a id="17.2.11"></a>17.2.11　乌尔比安《评萨宾》第三十卷

昆图斯·穆基乌斯在论述继承、遗赠和赠与时也写道，规则正是如此。

### <a id="17.2.12"></a>17.2.12　保罗《评萨宾》第六卷

除非债务源自营利活动，否则也不应将其计入合伙账目。

### <a id="17.2.13"></a>17.2.13　保罗《评告示》第三十二卷

即使另有约定，合伙人分享收益和利润，该附加约定也确实仅涉及源于营利活动的利润。

### <a id="17.2.14"></a>17.2.14　乌尔比安《评萨宾》第三十卷

合伙人约定在一定期间内不得分割共有财物，并不表示他们约定不得退出合伙。但如果约定不得退出合伙，该约定是否有效？庞波尼精辟地写道，这种约定徒劳无益：即使没有该约定，若在不适当的时点声明退伙，也可以提起合伙之诉。然而，如果双方约定在一定期间内不得退出合伙，而一方在期限届满前声明退伙，该退伙仍可能有正当理由。合伙人如果因合伙成立所依据的某项条件未得到履行而声明退伙，也不承担责任；或者，若另一合伙人行事极为不公、造成重大损失，以致继续与其合伙并无益处，亦同。

### <a id="17.2.15"></a>17.2.15　庞波尼《评萨宾》第十三卷

又或者，合伙人无法享用其最初开展营业所依据的那项财物？

### <a id="17.2.16"></a>17.2.16　乌尔比安《评萨宾》第三十卷

<a id="17.2.16.pr."></a>

**序言（pr.）** 如果某合伙人因公事不得已而长期离开，并因此声明退出合伙，也应作相同处理。尽管有时可以反驳说，他本可委托他人管理合伙事务，或交由另一合伙人处理；但只有在另一合伙人非常可靠，或者即使通过他人管理、离开者也能方便地处理合伙事务时，才可以如此反驳。

<a id="17.2.16.1"></a>

**1.** 因此，约定除非有正当理由不得分割共有财产的人，也不得出售该财物，以免通过其他方式造成分割。不过，也可以说，出售本身并不受阻止；但如果买受人在卖方原本可以分割之前便分割财物，可以对买受人提出抗辩。

### <a id="17.2.17"></a>17.2.17　保罗《评萨宾》第六卷

<a id="17.2.17.pr."></a>

**序言（pr.）** 合伙人若违反约定处分财物，即构成违约，并可依合伙之诉或共有物分割之诉被追究责任。〔底本作 *accipit committit*，句法疑误；据文意译。〕

<a id="17.2.17.1"></a>

**1.** 如果合伙关系向不在场的合伙人作出退伙声明，那么在该合伙人知悉之前，作出声明者所取得的财物应归入共有；但由此产生的损失仅由声明退伙者承担。缺席者所取得的财物则仅归其本人；但由其造成的损失属于共同损失。

<a id="17.2.17.2"></a>

**2.** 成立合伙时，无须另行约定退伙声明的后果，因为依合伙法本身，不合时宜的退伙声明应纳入衡量。

### <a id="17.2.18"></a>17.2.18　庞波尼《评萨宾》第十三卷

如果奴隶订立了合伙，仅命令该奴隶退出合伙并不足够；还必须向其合伙人作出退伙声明。

### <a id="17.2.19"></a>17.2.19　乌尔比安《评萨宾》第三十卷

被接纳为合伙人的人，仅与接纳他的人构成合伙关系，这一点是正确的。合伙由合意成立，因此我不愿接纳为合伙人的人，不可能成为我的合伙人。那么，如果是我的合伙人接纳了他呢？他也仅与该合伙人构成合伙关系。

### <a id="17.2.20"></a>17.2.20　乌尔比安《评告示》第三十一卷

（因为我合伙人的合伙人，并非我的合伙人。）

### <a id="17.2.21"></a>17.2.21　乌尔比安《评萨宾》第三十卷

凡其因我们之间的合伙关系取得之物，他都应与接纳他入伙的人分享；我们则不与他分享。但他的行为应向合伙关系承担责任：也就是说，合伙人可以起诉他，并应将其所取得之物交给合伙财产。

### <a id="17.2.22"></a>17.2.22　盖尤斯《评行省告示》第十卷

反过来说，他也应像对待自己的行为一样，就合伙人的行为向其承担责任，因为他本人可以对这些合伙人提起诉讼。同样确定的是，在其他合伙人对接纳者提起诉讼之前，接纳者与被接纳者之间并无任何障碍，双方可以先行提起合伙之诉。

### <a id="17.2.23"></a>17.2.23　乌尔比安《评告示》第三十卷

<a id="17.2.23.pr."></a>

**序言（pr.）** 庞波尼对以下问题存疑：接纳他人入伙的人是否只须将其对被接纳者享有的诉权让与其他合伙人；若其无法履行，是否不再对合伙人负有其他责任；还是说，他必须使其他合伙人免受损失？我认为，他无论如何都应就自己单独接纳入伙之人的行为承担责任，因为很难否认，此人系因他的过失而被接纳。

<a id="17.2.23.1"></a>

**1.** 他还问：因接纳某人成为合伙人而取得的利益，是否应与因其过失造成的损失相抵？他认为应当抵销。这是不正确的。马尔切鲁斯在《学说汇纂》第六卷中也写道：如果某一合伙人的主人将其奴隶安排为合伙事务的管理人，而该奴隶管理不善，那么安排其任职的主人应向合伙承担责任；奴隶为合伙带来的利益，不得与损失相抵。马尔库斯皇帝也曾作出此项裁断；不能对合伙人说：“如果你请求赔偿损失，就放弃奴隶为合伙带来的利益。”

### <a id="17.2.24"></a>17.2.24　乌尔比安《评告示》第三十一卷

不过，如果两名合伙人都安排另一人的奴隶管理合伙事务，该奴隶的主人不因此承担全部责任，而仅在其特有产范围内承担责任；因为既然双方都安排了该奴隶，就应由双方共同承担风险。

### <a id="17.2.25"></a>17.2.25　保罗《评萨宾》第六卷

即使某项财物因合伙人的过失而灭失，也不会因此免除该合伙人所负担的风险；即便他在许多其他方面勤勉行事，曾使合伙财产增加，亦然。皇帝在一项上诉中也作出了这一裁断。

### <a id="17.2.26"></a>17.2.26　乌尔比安《评告示》第三十一卷

因此，如果合伙人处理合伙事务时有些方面疏忽、另一些方面却使合伙有所收益，就不得将收益与其过失相抵；马尔切鲁斯在《学说汇纂》第六卷中如此写道。

### <a id="17.2.27"></a>17.2.27　保罗《评萨宾》第六卷

合伙关系存续期间所负的一切债务，均应从共有财产中清偿，即使该债务是在合伙解散后才清偿，亦然。因此，即使某人作出附条件的允诺，而合伙解散后条件才成就，也应从共有财产中清偿。由此可见，如果合伙在条件成就前解散，就应相互提供担保。

### <a id="17.2.28"></a>17.2.28　保罗《评告示》第六十卷

如果我们是合伙人，而其中一人负有一笔约定于将来到期的债务，合伙关系又在到期前分割，那么该合伙人不得像债务已到期、可以立即请求清偿那样，先将该债务从份额中扣除；应先分割全部财产，并约定期限届至时使该合伙人获得保障。

### <a id="17.2.29"></a>17.2.29　乌尔比安《评萨宾》第三十卷

<a id="17.2.29.pr."></a>

**序言（pr.）** 如果没有约定合伙份额，应认为份额相等。如果约定一人占两份或三份，另一人占一份，该约定是否有效？意见认为有效，但须有一方为合伙投入了较多财物、劳务，或其他方面的贡献。

<a id="17.2.29.1"></a>

**1.** 卡西乌斯认为，合伙可以约定一方不承担任何损失，但双方共同分享收益；萨宾也认为，这只有在一方提供的劳务价值足以抵偿其本应承担的损失时才有效。因为合伙人的能力有时远胜其投入的金钱，例如只有一人出海或独自远行、承担风险时，情形便是如此。

<a id="17.2.29.2"></a>

**2.** 阿里斯托记载，卡西乌斯曾答复说，不能成立这样的合伙：一方只取得收益，另一方只承担损失；他惯称此种合伙为“狮子式合伙”。我们也赞同，不能成立一方取得收益、另一方毫无收益却承担损失的合伙；这种合伙极不公平，因为一方只承担损失而不分享收益。

### <a id="17.2.30"></a>17.2.30　保罗《评萨宾》第六卷

穆基乌斯在《民法》第十四卷中写道，不能约定合伙人承担不同份额的损失和收益。塞尔维乌斯在对穆基乌斯著作的批注中说，这种合伙既不能成立，也不应这样订立：只有扣除全部损失后才有收益；只有扣除全部收益后才有损失。但是，可以约定在扣除全部损失后，对剩余收益按不同份额分配；也可以约定在扣除全部收益后，对剩余损失按不同份额承担。

### <a id="17.2.31"></a>17.2.31　乌尔比安《评萨宾》第三十卷

只有存在合伙关系，才可提起合伙之诉；仅有共有财物并不足够，除非双方之间存在合伙关系。财物也可以在没有合伙关系的情况下由数人共有，例如，双方并非基于合伙意思而偶然成为共有人：如同一财物遗赠给两人、两人共同购买某物、两人共同取得遗产或赠与，或者两人分别购买各自的份额且无意成为合伙人。

### <a id="17.2.32"></a>17.2.32　乌尔比安《评告示》第二卷

如果双方经过商议而成立合伙，即可提起合伙之诉；如果没有经过商议，则仅因共同处理某项事务或共同经营某项交易而形成共有关系，

### <a id="17.2.33"></a>17.2.33　乌尔比安《评告示》第三十一卷

例如承包公共工程或共同购买财物时便是如此：不愿彼此发生争执的人，常通过使者共同购买某物，而这与合伙关系相去甚远。因此，未适婚的被监护人未经监护人许可而成立合伙时，不承担合伙之诉责任；但若双方共同处理事务，则仍应承担责任。

### <a id="17.2.34"></a>17.2.34　盖尤斯《评行省告示》第十卷

在上述情形下，如果一方为共有财物支出费用，或取得该物的孳息、租金，或使该物状况恶化，就不能提起合伙之诉；共同继承人之间应提起遗产分割之诉，其他共有人之间则应提起共有物分割之诉。依继承法成为财物共有人的，也可以提起共有物分割之诉。

### <a id="17.2.35"></a>17.2.35　乌尔比安《评萨宾》第三十卷

无人能够通过合伙约定使自己的继承人成为自己的合伙人；但是，针对已故合伙人的继承人可以提起诉讼，要求其遵守诚实信用。

### <a id="17.2.36"></a>17.2.36　保罗《评萨宾》第六卷

尽管继承人并非合伙人，但其仍应对其所承继之人的过失负责。

### <a id="17.2.37"></a>17.2.37　庞波尼《评萨宾》第十三卷

不过，如果继承已故合伙人的人决定就该遗产与其他人建立合伙关系，那么经新的合意，他们之后所进行的事务便可纳入合伙之诉处理。

### <a id="17.2.38"></a>17.2.38　保罗《评萨宾》第六卷

<a id="17.2.38.pr."></a>

**序言（pr.）** 合伙之诉的裁判人应预先要求提供担保，以处理合伙关系存续期间可能发生的损失或收益。萨宾认为，所有诚信诉讼均应如此，无论是概括性诉讼——如合伙之诉、无因管理之诉和监护之诉——还是特定诉讼——如委任之诉、借用物之诉和寄托之诉。

<a id="17.2.38.1"></a>

**1.** 如果我与你有合伙关系，且合伙财物由我们共有，那么我为这些财物支出的费用，以及你从这些财物取得的孳息，我可以依合伙之诉或共有物分割之诉请求给付。普罗库鲁斯说，其中一项诉讼会排除另一项。

### <a id="17.2.39"></a>17.2.39　庞波尼《评萨宾》第十三卷

如果有一块土地由我与你共有，而你在该土地上埋葬死者，我可以对你提起合伙之诉。

### <a id="17.2.40"></a>17.2.40　庞波尼《评萨宾》第十七卷

已故合伙人的继承人虽非合伙人，但已故者着手处理的事务仍应由继承人完成；对此，继承人也可能实施欺诈。

### <a id="17.2.41"></a>17.2.41　乌尔比安《评告示》第二十卷

如果某合伙人向另一合伙人约定罚金，且该罚金数额等于其因违约所受的利益损失，则不得再提起合伙之诉。

### <a id="17.2.42"></a>17.2.42　乌尔比安《评萨宾》第四十五卷

但是，如果他依允诺之诉已经取得该罚金，那么之后提起合伙之诉时，应将罚金计入本金，并相应减少其可获给付的数额。

### <a id="17.2.43"></a>17.2.43　乌尔比安《评告示》第二十八卷

即使已经提起共有物分割之诉，合伙之诉也不因此消灭，因为合伙之诉还涉及债权债务的核算，而且不允许裁判人将财物判归一方。不过，之后若提起合伙之诉，其可获给付的数额应扣除其在先前诉讼中已取得的部分。

### <a id="17.2.44"></a>17.2.44　乌尔比安《评告示》第三十一卷

如果我把珍珠交给你出售，并约定你若以十出售，就把十交给我；若以更高价格出售，超出部分归你所有，我认为：若双方是以成立合伙的意思订约，可以提起合伙之诉；否则，应提起特定言词诉讼。

### <a id="17.2.45"></a>17.2.45　乌尔比安《评萨宾》第三十卷

就共有物，若某合伙人以欺骗或恶意将其取走，或怀着隐匿共有物的意图加以占有，可以对该合伙人提起盗窃之诉；他也须依合伙之诉承担责任，两项诉讼彼此不排斥。所有诚信诉讼也都应作相同处理。

### <a id="17.2.46"></a>17.2.46　保罗《评萨宾》第六卷

对于承租土地者、处理他人事务者、执行我们委任者以及监护人，也适用同一规则。

### <a id="17.2.47"></a>17.2.47　乌尔比安《评萨宾》第三十卷

<a id="17.2.47.pr."></a>

**序言（pr.）** 但是，如果我因盗窃所生之诉而提起不当得利之诉，合伙之诉即不再适用，除非我依合伙关系享有的利益更大。

<a id="17.2.47.1"></a>

**1.** 如果一名合伙人损害共有财物，塞尔苏斯、尤利安和庞波尼都写道，他应依阿奎利亚法承担责任：

### <a id="17.2.48"></a>17.2.48　保罗《评萨宾》第六卷

但他仍须依合伙之诉承担责任，

### <a id="17.2.49"></a>17.2.49　乌尔比安《评告示》第三十一卷

前提是其行为损害了合伙关系；例如，他伤害或杀死合伙营业中的奴隶。

### <a id="17.2.50"></a>17.2.50　保罗《评萨宾》第六卷

但是，通过合伙之诉取得给付后，他就应以该诉讼的结果为满足，不得再依另一诉讼请求同一给付，因为两项诉讼都是为了回复财物，而盗窃之诉则仅在于处罚。

### <a id="17.2.51"></a>17.2.51　乌尔比安《评萨宾》第三十卷

<a id="17.2.51.pr."></a>

**序言（pr.）** 之所以特意加上“只有通过欺骗和恶意取走财物时才发生盗窃之诉”，是恰当的；因为若无恶意，便不承担盗窃责任。事实上，通常应相信，共有份额的所有人是依法行使自己的权利，而非意图盗窃。

<a id="17.2.51.1"></a>

**1.** 因此，我们还要考察他是否应依《法比亚法》承担责任。依其理由，他似乎不应承担；但若他实施拐带奴隶行为或将奴隶藏匿，则应依《法比亚法》承担责任。

### <a id="17.2.52"></a>17.2.52　乌尔比安《评告示》第三十一卷

<a id="17.2.52.pr."></a>

**序言（pr.）** 有一块待售土地毗邻两名邻人的地产，其中一人请求另一人买下该地，并约定与自己地产相邻的那部分归自己。后来，后者未告知邻人便自行买下了该地。问题是，邻人是否对他享有诉权。尤利安写道，这取决于具体事实：如果双方仅约定邻人买下卢基乌斯·提提乌斯的土地后与我分享，我对买下土地的邻人不享有任何诉权；但若双方约定共同经营该事务，我就应依合伙之诉承担责任：扣除你委托我取得的那部分后，我须将其余部分交付给你。

<a id="17.2.52.1"></a>

**1.** 善意原则适用于这项合伙之诉。

<a id="17.2.52.2"></a>

**2.** 问题在于，合伙人应对恶意负责，还是也应对过失负责。塞尔苏斯在《学说汇纂》第七卷中写道，合伙人之间应对恶意与过失负责。他说，如果一方在成立合伙时允诺提供技能或劳务——例如，双方约定共同放牧牲畜，或将土地交给园丁共同收取果实——当然也应对过失负责，因为劳务报酬正是以技能为掩饰。如果合伙人损害共有财物，更应认定其对过失负责。

<a id="17.2.52.3"></a>

**3.** 因意外而发生的损失，也就是不可避免的损失，合伙人无须承担。因此，若按估价交付的牲畜因劫掠或火灾而灭失，只要接受估价牲畜者没有故意或过失，这就是共同损失；但若牲畜被盗，则损失由该人自行承担，因为接受估价牲畜者本应负责保管。以上规则正确；只要交付牲畜是为了成立合伙、共同放牧，即使牲畜经过估价，也可以提起合伙之诉。

<a id="17.2.52.4"></a>

**4.** 有人共同经营羊毛布料买卖，其中一人外出采购货物时遭遇强盗，丢失了自己的钱财；其奴隶受伤，他自己的财物也被抢走。尤利安认为这是共同损失，因此另一合伙人应依合伙之诉承担其中一半损失，包括金钱以及其他财物；若非为共同名义采购货物，该合伙人本不会将这些财物随身带去。尤利安也极为正确地认为，为医治伤者所支出的费用，另一合伙人也应按份承担。同样，如果货物因海难而灭失——因为货物通常只能由船舶运送——双方都应承受损失。正如收益应为共同的，并非因合伙人过失造成的损失也应共同承担。

<a id="17.2.52.5"></a>

**5.** 两名银行家成立合伙，其中一人单独取得某项收益并从中获利；问题是，该收益是否应归入共有。塞维鲁皇帝就此向弗拉维乌斯·费利克斯作出如下复谕：“即使双方成立的是银行业合伙，任何合伙人若非因银行业务而取得某物，该物不属于共有，这一点已是确定的法律。”

<a id="17.2.52.6"></a>

**6.** 帕皮尼安在《答复集》第三卷中也说：兄弟们若保留父母留下的未分割遗产，是为了共同享有其收益并共同承担损失，那么他们从其他来源取得的财物并不因此归入共有。

<a id="17.2.52.7"></a>

**7.** 他还在《答复集》第三卷中说，曾就一项事实作出答复：弗拉维乌斯·维克托与贝利库斯·阿西亚努斯约定，以维克托的钱购买场地，由阿西亚努斯凭其劳务与技能建造纪念碑；纪念碑售出后，维克托取回本金及一定数额，余款由投入劳务的阿西亚努斯取得。对此可以提起合伙之诉。

<a id="17.2.52.8"></a>

**8.** 同一帕皮尼安在同卷还说，兄弟间若自愿成立合伙，并约定依合伙之诉将津贴及其他薪俸归入共有，那么即使已解放的儿子不必将这些财物交给仍受父权支配的兄弟，也应如此；因为即使他仍受父权支配，这些财物也本应由其特别享有。

<a id="17.2.52.9"></a>

**9.** 他还答复说，合伙不能延续至合伙人死亡之后。因此，任何人都不能以合伙约定限制其遗嘱处分自由，也不能约定使较远亲属优先于较近亲属。

<a id="17.2.52.10"></a>

**10.** 他答复说：某合伙人修复了一栋公寓楼中其他合伙人拖延修复的份额；尽管他可以在工程完工后四个月内请求返还本金及约定利息，并享有优先受偿权，或者此后取得该财物的所有权，他仍可依合伙之诉请求取得其所享有的利益。设想他更愿意取得其应得利益，而不愿取得公寓楼的所有权。已故马可皇帝的敕令将约定利息限定为四个月，正是因为四个月后便赋予其所有权。

<a id="17.2.52.11"></a>

**11.** 如果数人共同成立购买合伙，后来其中一人因另一合伙人的恶意或过失而未能买得该物，可以提起合伙之诉，这一点已确定。显然，若附有“在某日前出售”这样的条件，而该日期因合伙人无过失地届满，合伙之诉即不再适用。

<a id="17.2.52.12"></a>

**12.** 卡西乌斯写道，如果有人为修复共有水渠而支出费用，可以提起合伙之诉以请求偿还该费用。

<a id="17.2.52.13"></a>

**13.** 梅拉还写道：如果邻人各自让出半英尺土地，以便在那里共同建造一堵承受双方负荷的格栅墙，墙建成后其中一人却不许另一人将梁木嵌入墙中，可以提起合伙之诉。如果双方共同购买一块空地，以免遮挡各自的采光，而该地交给一方后，此人不履行对另一方的约定，也可以提起合伙之诉。

<a id="17.2.52.14"></a>

**14.** 同一当事人之间即使成立了数项合伙，一项合伙之诉也足以处理全部合伙关系，这一点已确定。

<a id="17.2.52.15"></a>

**15.** 如果合伙人为了合伙事务外出，例如采购货物，他只能将为该事务支出的费用计入合伙账目。因此，交通费、旅店及马厩费用，以及运输牲畜、车辆、本人行李或货物的费用，都可以适当计入。

<a id="17.2.52.16"></a>

**16.** 涅拉提乌斯说，全部财产合伙中的合伙人应将一切财物归入合伙。因此，无论他因自己遭受侵害而取得赔偿，或依《阿奎利亚法》取得赔偿——无论伤害的是他本人还是其子——他都应将其交入共有财产。

<a id="17.2.52.17"></a>

**17.** 同一作者还说，全部财产合伙中的合伙人无须将其通过违法事由取得的财物交入共有。

<a id="17.2.52.18"></a>

**18.** 古代法学家也从相反角度讨论：全部财产合伙中的合伙人若因侵害之诉被判承担责任并已给付，能否从共有财产中取得补偿。阿提利基努斯、萨宾和卡西乌斯答复说，如果他是因裁判不公而被判决，应可从共有财产中取得补偿；如果是因自己的不法行为，则应自行承担全部损失。这与奥菲狄乌斯所记载的塞尔维乌斯答复一致：若财产合伙中的一名合伙人未到庭而被判决，不得从共有财产中请求补偿；但若其到庭却遭受裁判官不公，则应由共有财产补偿。

### <a id="17.2.53"></a>17.2.53　乌尔比安《评萨宾》第三十卷

通过盗窃或其他不法行为取得之物，显然不应交入合伙，因为不法行为的共同参与是可耻且不正当的。不过，如果该物已交入共有，收益即成为共同收益。

### <a id="17.2.54"></a>17.2.54　庞波尼《评萨宾》第十三卷

合伙人因不法行为而交入合伙的财物，只有在其被判承担责任之后，才可以取回。

### <a id="17.2.55"></a>17.2.55　乌尔比安《评萨宾》第三十卷

因此，如果实施不法行为的合伙人因此受到起诉，他可以取回自己交入合伙的财物；取回时是否还须承担罚金，取决于具体情形：假如他是在另一合伙人不知情时，将该财物记入合伙账目，那么只须取回该财物；若另一合伙人知情，也应由其承担罚金，因为既然他分享了收益，公平起见也应分担损失。

### <a id="17.2.56"></a>17.2.56　保罗《评萨宾》第六卷

无论合伙关系存续期间还是解散之后，合伙人因盗窃而给付的罚金，都不影响上述规则。对于所有带有不名誉性质的诉讼也同样如此，例如侵害之诉、强夺财物之诉、奴隶被腐化之诉及类似诉讼；公诉程序所产生的一切金钱罚金亦同。

### <a id="17.2.57"></a>17.2.57　乌尔比安《评萨宾》第三十卷

庞波尼说，不应遗漏这一点：上述规则只有在合伙是为诚实、合法之事而成立时才适用。若合伙是为不法行为而成立，合伙关系当然无效。一般而言，为不正当之事成立的合伙均属无效。

### <a id="17.2.58"></a>17.2.58　乌尔比安《评告示》第三十一卷

<a id="17.2.58.pr."></a>

**序言（pr.）** 如果某人交入合伙的财物已经灭失，应考察其是否仍可提起合伙之诉。塞尔苏斯在《学说汇纂》第七卷、致科尔内利乌斯·费利克斯书中讨论了这一问题：你有三匹马，我有一匹，我们成立合伙，约定接受我的马后由你出售四马战车，并将价款的四分之一交给我。如果我的马在出售前死亡，塞尔苏斯认为，合伙关系不再存续，我也无权请求分得你其他马匹的价款；因为成立合伙的目的不是共同拥有四马战车，而是将其出售。反之，如果双方约定共同组成一辆四马战车并共有之，你享有四分之三，我享有四分之一，那么毫无疑问，我们仍是合伙人。

<a id="17.2.58.1"></a>

**1.** 塞尔苏斯还讨论：如果我们共同交付钱款以购买货物，而我的钱款灭失，损失应由谁承担？他说，如果钱款在交付之后灭失，且若非成立合伙便不会发生此事，则双方均承担损失；例如，钱款在运往外地采购货物途中灭失。但如果钱款在交付前、仅在你决定将其投入合伙之后便已灭失，他说，你不得因此请求任何给付，因为该钱款并非在合伙关系中灭失。

<a id="17.2.58.2"></a>

**2.** 家子成立合伙后被其父解放，尤利安讨论了原合伙是否继续，还是在解放后继续从事合伙事务时成立了另一个合伙。尤利安在《学说汇纂》第十四卷中写道，原合伙继续存续，因为这类契约应考察其成立之初；但应提起两项诉讼：一项针对父亲，另一项针对儿子。对父亲的诉讼仅涉及在解放前已届清偿期的债务；合伙在解放后继续存续期间的事务，父亲无须负责。对儿子的诉讼则涉及两个期间，也就是整个合伙关系；因为尤利安说，若儿子的合伙人在儿子解放后实施欺诈，诉讼应针对儿子而非其父。

<a id="17.2.58.3"></a>

**3.** 如果我的奴隶与提提乌斯成立合伙，之后该奴隶被出售却仍留在合伙关系中，可以说，奴隶被出售时，原合伙终止，并重新成立另一合伙。因此，我和买受人均可提起合伙之诉；对于出售前发生的事由，诉讼也可分别针对我和买受人；其余事由则只能针对买受人提起。

### <a id="17.2.59"></a>17.2.59　庞波尼《评萨宾》第十二卷

<a id="17.2.59.pr."></a>

**序言（pr.）** 合伙人死亡会使合伙关系消灭，因此我们甚至不能在合伙成立之初就约定其继承人继受合伙关系。庞波尼说，这适用于私人合伙；公税承包合伙则不同，即使某一成员死亡，合伙仍可继续，但只有在明确约定死者的份额归其继承人，且继承人也须投入相应份额时才是如此；这须依具体情形判断。因为，如果死亡者正是其劳务使合伙得以成立的人，或者没有他便无法管理合伙，那么又当如何？

<a id="17.2.59.1"></a>

**1.** 合伙人因赌博或通奸而遭受的损失，不应由共同财产承担；但若合伙人因我们的欺诈而遭受损失，则可向我们请求赔偿。

### <a id="17.2.60"></a>17.2.60　庞波尼《评萨宾》第十三卷

<a id="17.2.60.pr."></a>

**序言（pr.）** 拉贝奥说，如果合伙人迟延返还其从合伙收益中应得的部分，并且自己使用了该笔钱款，就应支付利息；但这并非作为利息，而是赔偿合伙人因其迟延所受的损失。反之，如果他没有使用该钱款，或者并未迟延，就不承担此项责任。同样，合伙人死亡后，不得因其继承人的行为作此种估价，因为合伙关系已因合伙人死亡而终止。

<a id="17.2.60.1"></a>

**1.** 一名合伙人为阻止共同所有、待售的奴隶逃跑而与之搏斗并受伤。拉贝奥说，他不能依合伙之诉请求偿还治疗自己的费用，因为该项支出并非“用于合伙事务”，尽管它是“因合伙关系而发生的”。这与以下情形相同：某人因合伙关系而不再指定我为继承人，或放弃遗赠，或更加疏于管理自己的财产；这些事由均不构成合伙事务支出。又如，即便某人因合伙关系而被指定为继承人，或获赠某物，该项收益也不应纳入共有财产。

### <a id="17.2.61"></a>17.2.61　乌尔比安《评告示》第三十一卷

不过，依尤利安的意见，他也可以取回为自己支付的医疗费用；这是正确的。

### <a id="17.2.62"></a>17.2.62　庞波尼《评萨宾》第十三卷

提提乌斯——我与之成立合伙的人——死亡后，我误以为提提乌斯的继承人是塞伊乌斯，便与塞伊乌斯共同出售财物；我和塞伊乌斯各自取走了售得价款的一部分。后来，真正继承提提乌斯遗产的你，能否通过合伙之诉向我请求我所取得的那部分价款？涅拉提乌斯和阿里斯托认为你无权请求，因为我仅取得了自己份额的价款；无论我是单独出售自己的份额，还是与声称其余份额属于自己的那个人共同出售，都没有区别。否则，如果两名合伙人出售一项财物，每个人都须依合伙之诉向另一人交付自己取得的那部分。你也无须将你可能通过遗产请求之诉从塞伊乌斯处取得的那部分交给我，因为塞伊乌斯所取得的是你份额的价款；既然我已经取得自己的份额，就不应再从该款中取得任何部分。

### <a id="17.2.63"></a>17.2.63　乌尔比安《评告示》第三十一卷

<a id="17.2.63.pr."></a>

**序言（pr.）** 萨宾的意见是正确的：即使当事人并非全部财产合伙人，而仅就一项特定财物成立合伙，被告仍应在其力所能及的范围内承担判决责任；如果其以恶意使自己无力履行，也应按其本可履行的范围承担责任。这一规则有充分的理由，因为合伙在某种程度上包含兄弟般的关系。

<a id="17.2.63.1"></a>

**1.** 还须考察，合伙人的保证人是否也应享有此项利益，还是说这仅是合伙人本人的特权。后一种意见似乎更正确。但如果保证人作为合伙人的诉讼代理人承担了诉讼，则也可以为自己主张该利益：尤利安在《学说汇纂》第十四卷中写道，合伙人的诉讼代理人应仅在合伙人力所能及的范围内被判决。他还说，保护人一方的诉讼代理人也应适用同一规则；所有其他仅在其力所能及范围内被起诉的人，也都应适用。

<a id="17.2.63.2"></a>

**2.** 如果合伙是在家父或主人命令下成立的，不应将此项抗辩给予该合伙人的父亲或主人；因为合伙人的继承人及其他继受人也不能享有此项利益。对于其他仅在其力所能及范围内被起诉之人的继承人或继受人，也不应给予同样利益。

<a id="17.2.63.3"></a>

**3.** 应如何衡量合伙人力所能及的范围？意见认为，不得扣除合伙人对外所负的债务。马尔切鲁斯在《学说汇纂》第七卷中也如此写道，但他补充说，若该债务源自合伙本身，则另当别论。

<a id="17.2.63.4"></a>

**4.** 还应考察，这项诉讼是否要求被告就其无力清偿的部分提供担保，也就是仅以允诺作出的担保；我认为应作肯定回答。

<a id="17.2.63.5"></a>

**5.** 如果共有三名合伙人，其中一人起诉一名合伙人并足额取得自己的份额，之后另一人起诉同一被告，却因被告无力足额给付而不能取得全部份额，那么未足额受偿者能否起诉已足额受偿者，要求双方分担、也就是均等分配各自所得？似乎不公平的是，同一合伙关系中一人取得较多、另一人取得较少。但更可取的意见是，他可以依合伙之诉请求补足，使双方份额相等；这一意见符合公平。

<a id="17.2.63.6"></a>

**6.** 衡量合伙人力所能及的范围，应以案件裁判时为准。

<a id="17.2.63.7"></a>

**7.** 如果某人以欺诈使自己无力履行，则其本可履行的数额也应视为其力所能及；因为允许任何人从自己的欺诈中获益并不公平。其他仅在其力所能及范围内被起诉的人，也应适用同一规则。但如果某人并非因欺诈，而是因自己的过失而丧失履行能力，则不应据此判令其承担责任。

<a id="17.2.63.8"></a>

**8.** 对合伙人的继承人也可以提起合伙之诉，尽管继承人并非合伙人；他毕竟是合伙利益的继受人。公税承包合伙及其他类似合伙也适用同一规则：除非继承人获准加入，否则继承人并非合伙人；但是，合伙的一切利益都归其享有，他也应承担相应损失，无论该损失发生在公税承包合伙人尚在世时还是其死亡之后。自愿成立的合伙则不适用同一规则。

<a id="17.2.63.9"></a>

**9.** 如果一名共有人的遗嘱将遗赠给共有奴隶，但未同时使其获得自由，该遗赠仅归该合伙人所有。问题在于，是否应依合伙之诉与已故合伙人的继承人共同分配。尤利安说，庞波尼曾转述萨宾的答复：不应共同分配；尤利安认为这一意见可以成立。因为该财物并非基于合伙而取得，而是基于其个人份额取得；任何人因其个人份额、而非因合伙取得的财物，都不应交入共有。

<a id="17.2.63.10"></a>

**10.** 合伙关系因主体、财物、意思或诉讼而解散。因此，无论是合伙人、合伙财物、合伙意思还是合伙诉讼关系消灭，均可认为合伙关系终止。合伙人因人格减等或死亡而不复存在；财物则因不再存续或法律性质发生变化而不复存在，因为已不存在的财物不可能再有合伙人，对已奉献于神或已收归公有的财物，也不可能再成立合伙。合伙意思消灭，则是因合伙人作出退伙声明。

### <a id="17.2.64"></a>17.2.64　卡利斯特拉《疑难集》第一卷

因此，如果合伙人各自开始单独从事事务，并分别为自己经营，合伙关系无疑即告解散。

### <a id="17.2.65"></a>17.2.65　保罗《评告示》第三十二卷

<a id="17.2.65.pr."></a>

**序言（pr.）** 合伙关系也会因诉讼而解散，即通过要式口约或诉讼使合伙关系的法律状态发生变化。普罗库鲁斯说，如果提起诉讼的目的就是解散合伙，那么仅因该诉讼已经提起，就应视为已声明退伙；无论成立的是全部财产合伙还是针对单一财物的合伙，都是如此。

<a id="17.2.65.1"></a>

**1.** 拉贝奥说，一名合伙人的财产被债权人拍卖，也会使合伙关系解散。

<a id="17.2.65.2"></a>

**2.** 拉贝奥说，如果成立合伙是为了购买或租赁某项特定财物，那么即使一名合伙人死亡，此后由此取得的一切收益或损失仍为共同的。

<a id="17.2.65.3"></a>

**3.** 我们说过，合伙关系因合伙人意见不合而解散；但只有所有合伙人都不同意继续合伙时，才是如此。那么，如果只有一人声明退伙呢？卡西乌斯写道，声明退伙者因此使其余合伙人免受合伙关系约束，却不能使自己免受他们的约束。若退伙声明出于恶意，例如我们成立全部财产合伙，之后某一合伙人因自己取得遗产便声明退伙，就应适用这一规则。因此，若该遗产带来损失，应由声明退伙者自行承担；若遗产带来利益，他则须依合伙之诉与他人分享。但若其在声明退伙后才取得某项财物，则无须分享，因为他在此事中并无欺诈。

<a id="17.2.65.4"></a>

**4.** 同样，如果我们成立合伙以购买某项财物，而你随后为了独自买下该物而退出合伙，就应按我所受的损失向我承担责任。但如果你是因为不再愿意购买而退出，即使我后来买下该物，你也不承担责任，因为此处并无欺诈；尤利安也赞同这一意见。

<a id="17.2.65.5"></a>

**5.** 拉贝奥在《后期著作》中写道，如果一名合伙人在其他合伙人有利益继续维持合伙关系时声明退伙，就应对其承担合伙之诉责任。例如，我们成立合伙购买奴隶后，你却在不宜出售奴隶之时向我声明退伙；既然你的行为使我的处境恶化，你就应依合伙之诉承担责任。普罗库鲁斯说，只有在解散合伙不符合合伙本身利益时，这一意见才正确；因为一贯考察的并非某一合伙人的个人利益，而是合伙关系的利益。若合伙成立时对此没有另行约定，应依此处理。

<a id="17.2.65.6"></a>

**6.** 同样，合伙人约定合伙存续一定期间，而一方在期限届满前声明退伙，并不能使自己免受另一方约束，只能使另一方免受对自己的约束。因此，此后若有收益，他不能分得份额；若有损失，他仍须分担，除非其退伙是出于某种不得已的情形。约定期限届满后，只要退伙并非出于恶意，合伙人即可自由退出。

<a id="17.2.65.7"></a>

**7.** 我们也可以通过他人声明退出合伙；因此，有人指出，代理人也可以代为声明退伙。但这一规则所指的，究竟是获准管理全部事务的代理人，还是仅获明确授权作出退伙声明的代理人？又或者两者都可以正当地声明退伙？后一意见更为正确，除非本人特别禁止代理人声明退伙。

<a id="17.2.65.8"></a>

**8.** 也有记载说，我的合伙人可以向我的代理人作出退伙声明。塞尔维乌斯在阿尔芬努斯的著作中如此说明：如果退伙声明已通知其代理人，是否认可该声明，由本人决定。因此，向其代理人送达退伙声明的一方似乎已退出合伙；至于向对方代理人作出声明的人是否也因此退出，则取决于其本人是否认可，正如前文所述，向合伙人本人声明退伙时也适用同一规则。

<a id="17.2.65.9"></a>

**9.** 即使数名合伙人一致成立合伙，一名合伙人死亡也会使合伙关系解散，除非成立合伙时另有约定。合伙人的继承人不继受合伙人地位；但是，此后从共同事务中取得的财物，以及因先前事务所生的欺诈或过失责任，继承人和遗产均须依具体情形向对方承担或请求。

<a id="17.2.65.10"></a>

**10.** 如果合伙是为处理某项特定事务而成立，该事务完成后，合伙关系即告终止。但如果一切事务均尚未完成，其中一名合伙人死亡，之后才发生双方成立合伙所针对的事项，就应适用与委任相同的区分：如果另一合伙人尚不知道对方死亡，合伙仍有效；如果已经知道，则合伙不再有效。

<a id="17.2.65.11"></a>

**11.** 合伙关系既不传给合伙人的继承人，也不传给收养合伙人的家父；否则，某人就可能违背意愿成为其不愿与之合伙之人的合伙人。但被收养者本人仍是合伙人；同样，家子即使被解放，也仍继续作为合伙人。

<a id="17.2.65.12"></a>

**12.** 我们说过，财产被收归公有也会使合伙关系解散。这似乎是指合伙人全部财产被没收；因为一旦他人取代其地位，就应将该合伙人视同死亡。

<a id="17.2.65.13"></a>

**13.** 合伙关系解散后，若某合伙人又为共同事务支出费用，不得依合伙之诉请求偿还，因为这已不能说是为合伙关系或共同利益而进行的事务。但该费用仍可在共有物分割之诉中予以核算；因为即使合伙关系解散，财物分割仍有必要。

<a id="17.2.65.14"></a>

**14.** 如果共有资金由某一合伙人保管，而另一合伙人有款项未能取得，应只起诉保管共有资金的人。扣除其所欠款项后，其余合伙人均可就各自应得数额提起诉讼。

<a id="17.2.65.15"></a>

**15.** 有时即使合伙关系仍在存续，也有必要提起合伙之诉。例如，成立公税承包合伙后，由于订立了各种契约，双方都不宜退出合伙；而且某一方取得的财物并未归入共有账目。

<a id="17.2.65.16"></a>

**16.** 如果一名合伙人是丈夫，而合伙关系在婚姻存续期间解散，丈夫应先行取回嫁资，因为嫁资应由承担婚姻负担的一方持有。如果合伙关系是在婚姻已经解除后才解散，则嫁资应在其应返还之日一并取回。

### <a id="17.2.66"></a>17.2.66　盖尤斯《评行省告示》第十卷

如果合伙关系分割时，嫁资处于显然无须返还、或仅须返还其中一部分的状态，裁判人就应在合伙人之间分配相应财物。

### <a id="17.2.67"></a>17.2.67　保罗《评告示》第三十二卷

<a id="17.2.67.pr."></a>

**序言（pr.）** 如果一名合伙人在其他合伙人同意后出售共有物，所得价款应予分配，同时应要求提供担保，确保该出售者不受损害；如果其已经遭受损失，则应予以补偿。但如果分配价款时没有提供担保，之后出售者已作出给付，而部分合伙人无力偿还，无法从他们处取得的部分是否应由其他合伙人承担？普罗库鲁斯认为，其他合伙人应承担无法向部分合伙人收回的数额；这一意见可以这样解释：合伙成立时，双方约定共同分享收益，也共同承担损失。

<a id="17.2.67.1"></a>

**1.** 如果并非全部财产合伙中的合伙人之一将共有资金贷出并取得利息，只有在其以合伙名义放贷时，才应分配利息。若以其本人名义放贷，由于本金风险由其承担，利息也应由其保留。

<a id="17.2.67.2"></a>

**2.** 如果一名合伙人为共同事务不得不以自己的钱款支出费用，可以通过合伙之诉请求偿还；如果他借入资金并支付了利息，也应取得该项利息。但即使他使用的是自己的资金，也不无理由地主张其应取得本可通过将该资金借给他人而获得的利息。

<a id="17.2.67.3"></a>

**3.** 只有在合伙人承认自己是合伙人的情况下，才可以判令其仅在力所能及的范围内承担责任。

### <a id="17.2.68"></a>17.2.68　盖尤斯《行省告示日常解释集》第十卷

<a id="17.2.68.pr."></a>

**序言（pr.）** 即使成立的是全部财产合伙，任何合伙人也不得处分超过其本人份额的财物。

<a id="17.2.68.1"></a>

**1.** 问题在于，只有为逃避将来的诉讼而挥霍自己财产的人，才应被视为使自己无力履行；还是说，未利用取得财物的机会也应如此认定？更可取的意见是，总督应针对挥霍自己财产的人作出判断。这一点可以从禁令中看出，其中规定：“你以欺诈行为使自己不再占有该物。”

### <a id="17.2.69"></a>17.2.69　乌尔比安《评告示》第三十二卷

如果数人成立购买合伙，并约定其中一人应向其他人提供集市日宴席，也就是宴饮，并使他们退出事务，而他没有向他们提供宴席，那么可以对他提起合伙之诉，也可以提起买卖之诉。

### <a id="17.2.70"></a>17.2.70　保罗《评告示》第三十三卷

合伙关系不可能约定永远存续。

### <a id="17.2.71"></a>17.2.71　保罗《阿尔芬《学说汇纂》节要》第三卷

<a id="17.2.71.pr."></a>

**序言（pr.）** 两人成立合伙，约定共同教授语法，并将由此取得的收益归为共有。他们将约定写入合伙协议，随后以如下言词相互订立要式口约：“上述事项应当如此给付、履行，并不得违反，对吗？若未按此给付、履行，则给付二万。”问题是，如果有人违反约定，是否可以提起合伙之诉。答复如下：如果他们就成立合伙所订的协议作了这样的要式口约——“你承诺将这些事项如此给付、履行吗？”——那么，若此举意在更新债务，就不得再提起合伙之诉，因为全部事务都应视为已纳入要式口约。但他们并未这样约定，而是约定“若未按此履行，则给付一万”，在我看来，这并不意味着合伙事务本身已纳入要式口约，而仅仅是约定了罚金；因为允诺人并非既承诺给付、履行该事项，又承诺未履行时承担罚金。因此，仍可提起合伙之诉。

<a id="17.2.71.1"></a>

**1.** 两名由同一保护人解放的释奴成立合伙，共同分享收益、营利和利润。后来，其中一人被保护人指定为继承人，另一人则获得遗赠。答复认为，两项财物都不应交入共有。

### <a id="17.2.72"></a>17.2.72　盖尤斯《日常法事录》或《黄金集》第二卷

合伙人也因过失而对另一合伙人承担责任，也就是说，因怠惰和疏忽而承担责任。但过失不应以最严格的注意标准衡量：只要他像通常管理自己的事务那样谨慎地处理共同事务，就已足够。因为选择了一名不够谨慎的合伙人，应当由选择者自行承担后果。

### <a id="17.2.73"></a>17.2.73　乌尔比安《答复集》第一卷

他答复马克西米努斯说，如果双方成立了全部财产合伙——也包括此后各自取得的财物——那么任何一方取得的继承财产也应归入共有。他还向马克西玛答复说，如果双方约定成立全部财产合伙，并约定一切支出及取得的财物均为共同收益、共同费用，那么为了其中一方的子女而支出的费用也应记入双方账目。

### <a id="17.2.74"></a>17.2.74　保罗《评告示》第六十二卷

某人即使成立了合伙，其购买的财物仍归其本人所有，而非当然成为共有；但他会被依合伙之诉强制将该物交入共有。

### <a id="17.2.75"></a>17.2.75　塞尔苏斯《学说汇纂》第十五卷

如果合伙是按提提乌斯所确定的份额成立，而提提乌斯在确定份额之前便已死亡，则合伙并未成立；因为双方所约定的正是只有按照提提乌斯的决定确定份额，合伙才成立。

### <a id="17.2.76"></a>17.2.76　普罗库鲁斯《书信集》第五卷

你与我成立合伙，条件是由我们共同的朋友涅尔瓦确定合伙份额。涅尔瓦决定你占三分之一，我占三分之二。你问：依合伙法，这一决定是否有效，还是我们仍应各占相等份额？我认为，你更应当问：我们是按他所确定的份额成为合伙人，还是按善良之人应当确定的份额成为合伙人。因为裁判人的裁量有两种：一种是无论公平与否，我们都必须服从其决定，例如依据仲裁协议交由仲裁人裁决；另一种则必须依善良之人的裁量作出，即使协议明确指定某人来决定也是如此。

### <a id="17.2.81"></a>17.2.81　帕皮尼安《疑难集》第九卷

一名合伙人为其女儿允诺给付嫁资，并在实际给付前死亡，遗产由女儿继承。后来，女儿向丈夫请求给付嫁资，丈夫经免除而解除该债务。问题是，如果提起合伙之诉，是否应先从共有财产中扣除嫁资数额——例如，合伙人曾约定由共有财产设立嫁资。我的意见是，这项约定并非不公平，尤其是在约定并非仅为另一合伙人的女儿设立嫁资时；如果这是双方共同的约定，那么即使只有一方有女儿，也不影响约定的效力。反之，如果父亲已经实际给付嫁资，而女儿在婚姻存续期间死亡后父亲取回该嫁资，依公平解释该约定，应将这笔钱返还合伙财产。如果婚姻因离婚而解除、但合伙仍继续存续，则嫁资由父亲为自己取回，也就是可以将其给付给另一任丈夫。若前任丈夫无力给付，合伙财产无须再次设立嫁资，除非双方对此有明示约定。不过，就本案而言，嫁资究竟已经给付还是仅作出允诺，显然有很大区别：如果女儿在父亲死亡后成为其继承人，并依自己的权利取回已给付的嫁资，那么该款无须交入合伙财产，因为即使由他人继承父亲遗产，该妇女也会取得该款；但如果她只是经丈夫免除而解除债务，则不得将未曾给付的款项计入合伙财产。

### <a id="17.2.82"></a>17.2.82　帕皮尼安《答复集》第三卷

合伙人不因另一合伙人的债务而依合伙关系承担责任，除非该债务所涉钱款已投入共同资金。

### <a id="17.2.83"></a>17.2.83　保罗《手册集》第一卷

一棵树生长在两块土地的边界上，一块石头也延伸至两块土地之中；当树被砍下或石头被取出后，它们是否仍应按其原先分别位于各自土地中的部分，归相应土地所有人所有？或者，是否应像两个所有人的金属块熔化后形成的整体归双方共有一样，树木一旦脱离土地、石头一旦取出并形成独立物质，就更应成为不可分割的共有物，而非如金属混合物那样？但依自然理由，双方在树木或石头中所享有的份额，仍应与其在土地中原有的份额相同。

### <a id="17.2.84"></a>17.2.84　拉贝奥《后期著作》第六卷（雅沃勒努节要）

如果某人命令他人与自己的家子或第三人订立合伙，那么应当直接对订立合伙时被视为合同主体的那个人提起诉讼。
