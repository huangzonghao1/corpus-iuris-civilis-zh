# 第十七卷

## 17.1　论委任之诉及其反诉（续）

### <a id="17.1.31"></a>17.1.31　尤利安《学说汇纂》第十四卷

如果我委托某人管理我的事务，而该人因某项请求曾须在一年内承担四倍责任，之后只承担单倍责任，即使我在一年后对他提起委任之诉，他仍应向我承担四倍责任；因为接受委任替他人管理事务的人，应按他人本人所负的责任承担义务。

### <a id="17.1.32"></a>17.1.32　尤利安《致乌尔塞乌斯·费罗克斯》第三卷

如果我只有在有人担保赔偿损失的条件下才会接受遗产，而双方也就此形成委任关系，我认为可以提起委任之诉。但如果有人委托他人不要拒绝自己所作的遗赠，情形则完全不同，因为取得遗赠绝不会使他遭受损失，而继承有时会造成损失。总而言之，凡是能够由保证人承担责任的契约，我认为也可能成立委任之债；因为有人在场接受询问并作保证，与其不在场却委托他人作保证，并无太大区别。此外，众所周知，有人会依债权人的委任而接受负债风险不明的遗产；毫无疑问，他们应受委任之诉追究。

### <a id="17.1.33"></a>17.1.33　尤利安《米尼基乌斯著作》第四卷

有人受请求作保证，如果其承担的金额少于所请求金额，仍应正当地承担责任；如果承担金额超过所请求的数额，尤利安更为正确地认为，应采纳多数人的答复：保证人仅在所受请求的数额范围内享有委任之诉，因为他只做了委任给他的事。请求保证的人显然只信赖其在被请求的金额范围内提供的信用。

### <a id="17.1.34"></a>17.1.34　阿非利卡努《疑义解答》第八卷

<a id="17.1.34.pr."></a>

**序言（pr.）** 某人为卢基乌斯·提提乌斯管理事务，从提提乌斯的债务人处收回钱款后，写信告知提提乌斯，自己因管理事务持有一定金额，并已将该款借给自己，承诺支付半利率（*usurae semisses*）的利息。问题是，能否基于该事由请求偿还借款，并请求利息？答复是，这笔钱并未成为借款；否则，只要通过单纯约定，就能把任何契约产生的钱款都转为借款。此情形与寄托给你的钱款约定改作借款不同，因为后一情形中，原属我的钱币变成了你的钱币。同样，如果我命令你从我的债务人处收取钱款并留作借款，也可以成立借款；这是基于宽厚而采纳的规则。另一个例证是：有人想借出钱款，却交付银器供人出售，即便如此，也不能正当地请求偿还借款；然而，出售银器所得的钱款仍由收受银器的人承担风险。因此，在本案中也应当说，代理人因委任之诉承担责任；尽管钱币成为其承担风险之物，他仍应支付双方约定的利息。

<a id="17.1.34.1"></a>

**1.** 你是遗产的部分继承人，我委托你按确定价款为我购买遗产中的土地；你已经买下。就其他共同继承人的份额而言，我们之间毫无疑问存在委任之诉；但就你自己的份额而言，究竟应提起买卖之诉还是委任之诉，则可以讨论。有人并非毫无理由地认为，该份额上的买卖是在条件成就时订立的。这一点尤其重要：如果买卖尚未完成我便死亡，而你明知我已死亡，却因我的委任而没有将土地卖给他人，我的继承人是否因此对你承担责任？反过来，如果你已将土地卖给他人，是否应对此向我的继承人负责？如果认为买卖附有条件，可以像其他条件在死后成就一样提起诉讼；如果应提起委任之诉（底本作 *sin (si) vero*，括号中形式照录），则应如同我委托你购买他人土地一样处理：我死亡后委任即已解除，你知道此事后，便不能再对我的继承人提起诉讼。不过，即使应提起委任之诉，也应承担与买卖之诉相同的责任。

### <a id="17.1.35"></a>17.1.35　涅拉提乌斯《札记》第五卷

如果我委托你为我购买一块土地，而该土地有一部分本来就属于你，委任可以有效成立；你买下其他份额后，还应将自己原有的份额一并交给我。但如果我委托你以确定价款购买，你无论以何种价款买下他人的份额，自己的份额价格也应相应调整，以免总价超过我委托你购买整块土地的金额。相反，如果我没有规定确定价款，而你按不同价格买下其他人的份额，那么你的份额也应按善良之人的裁量估价交付，

### <a id="17.1.36"></a>17.1.36　雅沃勒努《卡西乌斯著作》第七卷

<a id="17.1.36.pr."></a>

**序言（pr.）** 因此，应将各份额中较高和较低的金额合并计算，并据此向接受委任的人支付其所占份额的价款。多数人也赞同这一观点。

<a id="17.1.36.1"></a>

**1.** 如果我委托你按确定价款购买土地，而你妥善处理了其他份额的事务，并以较低价格买下这些份额，就应就你的份额向你支付相当于你实际利益的数额，但不得超过委任所定价款。如果与你共有土地的人因家庭财务困难或其他原因被迫以低价抛售，难道你也要承担同样的损失吗？但你也不应因此获利，因为委任必须无偿；不能因为你发现有买家比委任指定的人更积极，就允许你阻挠出售。

<a id="17.1.36.2"></a>

**2.** 如果我委托你购买分割出售的土地，并约定只有买下整块土地时我才受委任拘束，那么如果你无法买下整块土地，购买其中份额便是你自行处理事务；无论你是否原本拥有该土地的一部分，接受委任的人都可能要自担风险先行买下若干份额，若未买到全部，就不得不勉强留着这些份额。因为更妥当的看法是，接受这类委任的人应承受由此产生的不利；既然他自愿接受了委任，就应像购买整块土地一样，履行购买各个份额的职责。

<a id="17.1.36.3"></a>

**3.** 但如果我委托你为我购买土地，却没有附加“只有买下全部土地才受委任拘束”的条件，而你买下了其中一份或数份，即使未能买下其余份额，我们之间也毫无疑问彼此享有委任之诉。

### <a id="17.1.37"></a>17.1.37　阿非利卡努《疑义解答》第八卷

我为你作保证，承诺交付某一特定奴隶，并已履行。发生委任之诉时，应以奴隶交付时的估价为准，而不是起诉时的估价；因此，即使该奴隶后来死亡，准委任之诉仍然有效。口约之诉则不同：应考察起诉时的价值，除非未能按期交付是因承诺人阻挠，或债权人拒绝受领。因为任何一方都不得从自己造成的障碍中获利。

### <a id="17.1.38"></a>17.1.38　马尔凯卢斯《答复录》单卷

<a id="17.1.38.pr."></a>

**序言（pr.）** 卢基乌斯·提提乌斯允许其亲生儿子普布利乌斯·梅维乌斯，为儿子的债权人将共有房屋设定负担，但并非出于赠与。后来梅维乌斯死亡，留下未适婚年龄的女儿；其监护人对提提乌斯提起诉讼，提提乌斯也就双方相互主张的借款请求作出答辩。我询问：提提乌斯曾准许儿子设定负担的那部分房屋，是否应由法官裁量解除负担？马尔凯卢斯答复：是否应解除以及何时解除，应由法官根据债务人的情况、当事人之间的约定，以及被询问的财产被设定负担的时间加以判断：

<a id="17.1.38.1"></a>

**1.** 这属于须由法官处理的一类争议，与经常讨论的问题并无不同：保证人能否在清偿前提起诉讼，请求解除自己的责任？不过，也不应始终等到保证人付款或经诉讼判决承担责任后才允许其起诉；如果债务人长期不清偿，或显然正在耗散财产，尤其是保证人手头没有足够的钱款，无法先支付债权人再通过委任之诉起诉债务人，就更不应要求其继续等待。

### <a id="17.1.39"></a>17.1.39　涅拉提乌斯《札记》第七卷

阿里斯托和老塞尔苏斯都认为，可以约定将某物交付寄托或接受委任，并使该物的风险由接受寄托或委任的人承担；我也认为这是正确的。

### <a id="17.1.40"></a>17.1.40　保罗《评告示》第九卷

如果我在你在场且明确反对的情况下为你作保证，就既没有委任之诉，也没有无因管理之诉。有些人认为应给予准诉讼，但我不赞同；庞波尼似乎也持这一观点。

### <a id="17.1.41"></a>17.1.41　盖尤斯《评行省告示》第三卷

委任之诉可以仅由一方提起：如果接受委任的人超出了委任范围，他本人不能提起委任之诉，但委任人可以对他提起该诉。

### <a id="17.1.42"></a>17.1.42　乌尔比安《评告示》第十一卷

如果我委托你调查遗产的资力，而你误以为遗产价值较低，便从我处买下遗产，你应因委任对我承担责任。如果我委托你调查准备向其放款之人的资力，而你告知我此人有清偿能力，结论也相同。

### <a id="17.1.43"></a>17.1.43　乌尔比安《评告示》第二十三卷

某人接受委任，将钱款投资至约定日期；他完成委任后，应因委任之诉被起诉，并在给予延期的情况下让与相应诉权。

### <a id="17.1.44"></a>17.1.44　乌尔比安《评告示》第六十二卷

如果有人不愿追索自己本可追索的债权，或不愿支付自己已经追收的款项，即属欺诈。

### <a id="17.1.45"></a>17.1.45　保罗《评普劳提乌斯》第五卷

<a id="17.1.45.pr."></a>

**序言（pr.）** 如果你依我的委任购买土地，是否只有在你支付价款后才能对我提起委任之诉，还是在付款前也可以，以免你不得不变卖自己的财产？正确的观点是，委任之诉在此使我承担出卖人对你享有的债权关系；因为我也可以对你提起诉讼，要求你向我让与对出卖人享有的买卖之诉。

<a id="17.1.45.1"></a>

**1.** 如果你依我的委任出庭应诉，在诉讼尚未终结且没有正当理由时，你不应起诉我，要求将诉讼转到我名下；因为你还没有完成委任。

<a id="17.1.45.2"></a>

**2.** 同样，如果你在管理我的事务时，向我的某一名债权人作出承诺，在尚未清偿前，应当说你可以起诉我，要求我承接该债务；或者，如果债权人不愿变更债务人，我应向你提供担保，承诺为你辩护。

<a id="17.1.45.3"></a>

**3.** 如果我承诺确保你到庭，却没有将你带到庭上，在我承担赔偿之前，我可以提起委任之诉，要求你使我免责；我若成为代你承诺的债务人，亦同。

<a id="17.1.45.4"></a>

**4.** 如果我委托你向我的债权人清偿，而你代替我向其作出债务承诺并因此被判决承担责任，较为宽厚的观点是：在这种情形下，你也享有委任之诉。

<a id="17.1.45.5"></a>

**5.** 我们说，在付款前即可提起委任之诉的情形，受诉人承担的是履行义务，而不是给付义务。正如某人依委任取得诉权后，必须通过委任之诉行使该诉权；同样，因同一原因承担债务的人，也应享有委任之诉，以使自己获得免责。

<a id="17.1.45.6"></a>

**6.** 如果保证人因正当理由支出费用，导致其保证的数额增加，为其作保证的人应承担增加后的全部数额。

<a id="17.1.45.7"></a>

**7.** 你欠我的债务，我约定由你的债务人向我清偿，并由你承担风险。涅尔瓦和阿蒂利基努斯说，我可以对你提起委任之诉，追偿未能从该债务人处收取的差额。尽管该委任涉及你的事务，这样处理仍然正确：只有在债权人接受了你所指定的债务人时，指定该债务人的人才能免责；如果债权人仍是在你承担风险的情况下向其作出口约，你并未因此免责。

<a id="17.1.45.8"></a>

**8.** 如果我依保证人的委任对主债务人起诉，结论也一样；因为后续委任会使我就先前原因获得免责。

### <a id="17.1.46"></a>17.1.46　保罗《评告示》第七十四卷

如果某人替他人作出如下承诺：“如果你不交付斯提库斯，就支付十万”，而保证人以较低价格买下斯提库斯并交付，以免十万金币的口约责任发生，可以确定，他可以提起委任之诉。因此，委任通常应遵循这样的规则：委任内容确定时，不得偏离其约定方式；委任内容不确定或涉及多项事项时，即使受托人以与委任原定方式不同的履行方式解除委任，只要对委任人有利，仍可提起委任之诉。

### <a id="17.1.47"></a>17.1.47　庞波尼《评普劳提乌斯》第三卷

<a id="17.1.47.pr."></a>

**序言（pr.）** 尤利安说，如果某人的妻子答应以嫁资清偿她所欠保证人的保证债务，婚姻成立后，保证人便可以立即对债务人提起委任之诉；因为保证人承担婚姻负担，就应视为其钱款已经支出。

<a id="17.1.47.1"></a>

**1.** 如果为你保证交付奴隶的人，却向受约人交付了他人的奴隶，他本人和你都不因此免责，因此他不能对你提起委任之诉。但如果受约人通过取得时效取得该奴隶，尤利安说，应认为债务已获解除；因此，只有取得时效完成后，他才能对你提起委任之诉。

### <a id="17.1.48"></a>17.1.48　塞尔苏斯《学说汇纂》第七卷

<a id="17.1.48.pr."></a>

**序言（pr.）** 昆图斯·穆基乌斯·斯凯沃拉说：如果保证人就有息借款作了保证，而债务人在诉讼中本想抗辩该借款并非有息借款，保证人却替其支付利息，使债务人失去提出抗辩的机会，那么保证人不得向债务人请求该笔款项。但如果债务人曾通知保证人，要求他抗辩该债务并非有息，而保证人为了维护自己的声誉不愿提出抗辩，那么保证人可以向债务人请求其所支付的款项。斯凯沃拉的判断正确：在前一种情形中，保证人行事缺乏诚信，似乎凭借自己的权利剥夺债务人行使抗辩的机会；在后一种情形中，若保证人顾及廉耻而不提出抗辩，不应使其因此受损。

<a id="17.1.48.1"></a>

**1.** 如果我委托你通过借款办理我的事务，并要求由我承担债权风险、取得相应收益，我认为委任关系可以成立。

<a id="17.1.48.2"></a>

**2.** 但如果委托你办理自己的事务，由你自行决定向谁放款，利息归你，只有风险由我承担，这就超出了委任的范围；如同我委托你随意为我购买一处土地一样。

### <a id="17.1.49"></a>17.1.49　马尔凯卢斯《学说汇纂》第六卷

我从他人处善意买下并占有提提乌斯的奴隶。提提乌斯委托我出售该奴隶，却不知道奴隶属于自己；反过来，也可能是我依提提乌斯的委任出售该奴隶，而他因继承某人取得该奴隶，且该人曾买下此奴隶。问题涉及权利瑕疵担保和委任。我认为，提提乌斯即使仿佛以代理人身份出售，也仍对买受人承担责任；即使已经交付该物，也不得允许他请求返还。因此，提提乌斯不因委任承担责任；但如果他因此遭受损失——例如他原本不愿出售——则可以提起反向委任之诉。反过来，如果委任人想向提提乌斯请求返还该物，会被恶意抗辩阻却；并且他可基于继承权，对其被继承人的出卖人提起买卖之诉。

### <a id="17.1.50"></a>17.1.50　塞尔苏斯《学说汇纂》第三十八卷

<a id="17.1.50.pr."></a>

**序言（pr.）** 如果某人受托处理保证人的事务，并以使主债务人和保证人均获免责的方式向受约人付款，且其办理妥当，保证人就应对其承担无因管理之诉；保证人是否认可此事，并不重要。但保证人也可以在代理人尚未付款之前，只要已经认可其行为，就提起委任之诉。

<a id="17.1.50.1"></a>

**1.** 如果债务人应交付小麦，而保证人交付了非洲小麦；或者由于必须清偿，保证人支出的费用超过所交付物的价款；或者保证人交付了斯提库斯，而斯提库斯后来死亡、残疾或因品行恶劣而毫无价值，保证人都可以依据委任之诉请求补偿。

### <a id="17.1.51"></a>17.1.51　雅沃勒努《卡西乌斯著作》第九卷

保证人即使因错误而在期限届至前付款，也不能向受领人请求返还；在清偿期限到来之前，他也不能对债务人提起委任之诉。

### <a id="17.1.52"></a>17.1.52　雅沃勒努《书信集》第一卷

如果保证人未受品质约定限制而替他人保证交付小麦，我认为，他可以交付任何小麦使债务人免责；但保证人只能向债务人请求返还其所交付的、而该债务人原本可以用以对受约人免责的最低品质小麦。因此，如果债务人愿意交付自己原本可以用来向债权人免责的小麦，而保证人交付的是更好的小麦，我认为，保证人可以提起返还之诉请求返还较好的小麦；但债务人可以援用恶意抗辩阻却该请求。

### <a id="17.1.53"></a>17.1.53　帕皮尼安《疑义解答》第九卷

某人在另一人于场且未表示反对时，为第三人作保证，依委任之诉可以使委任的双方均承担责任；但如果他违背其中一人的意愿，或在其中一人不知情时，仅依另一人的委任作保证，就只能起诉作出委任的人，而不能起诉作出债务承诺的人。我不因保证人的钱款使主债务人免责而改变这一结论；某人依我的委任替他人付款时，也会产生同样效果。

### <a id="17.1.54"></a>17.1.54　帕皮尼安《疑义解答》第二十七卷

<a id="17.1.54.pr."></a>

**序言（pr.）** 如果奴隶委托外人买下自己，不构成有效委任。但如果委任是以释放奴隶为目的，而受托人没有释放，奴隶所有人仍可作为出卖人请求价款；并可依诚信原则的考虑提起委任之诉。可以设想奴隶是其亲生儿子或兄弟，因为较为明智的法学家认为，在诚信诉讼中应考虑亲情。如果买受人用自己的钱支付价款——否则他无法通过买卖之诉解除责任——人们通常会问，能否有效地提起特有产之诉。较正确、也更为妥当的观点是：裁判官并未考虑这类奴隶契约，因为奴隶会以不正当方式借此使自己脱离主人。

<a id="17.1.54.1"></a>

**1.** 如果自由人善意地为他人服役，并委托他人赎回自己，而买受人用自己的钱赎回，显然可以提起反向委任之诉；但应让与买受人对出卖人享有的诉权。可以设想买受人没有释放这名自由人。

### <a id="17.1.55"></a>17.1.55　帕皮尼安《答复录》第一卷

代理人没有取走封存的物品，而只是没有返还交付给他的物品，应受委任之诉追究，而不受盗窃之诉追究。

### <a id="17.1.56"></a>17.1.56　帕皮尼安《答复录》第三卷

<a id="17.1.56.pr."></a>

**序言（pr.）** 如果某人委托他人放款，债权人可以选择起诉该委任人，而不必先起诉主债务人或出售质物。如果以书面明确约定可以这样做，即使质物已经出售，债权人仍可向委任人追偿。因为为消除疑义而写入契约的条款，并不损害一般法律规则。

<a id="17.1.56.1"></a>

**1.** 保证人在法庭上提出款项，并因请求人未达成年而加以封存、存入公库后，可以立即提起委任之诉。

<a id="17.1.56.2"></a>

**2.** 即使主人离开行省五年后返回，随后又因公共事务出行，未核对账目便重新委托代理人办理事务，也仍应考察整个期间的诚信。既然代理人的职责包括将第一次无因管理中应交付的款项转入第二次账目，第二阶段的委任就应包括处理前一阶段尚未了结的诉讼。

<a id="17.1.56.3"></a>

**3.** 对于未确定承诺的薪俸，既不得通过非常程序正当地请求，也不得提起委任之诉要求对方为你确定薪俸。

<a id="17.1.56.4"></a>

**4.** 即使代理人未能完成事务，善意且必要支出的费用也必须依据委任之诉返还。

### <a id="17.1.57"></a>17.1.57　帕皮尼安《答复录》第十卷

出售奴隶的委任，在接受委任者死亡后即告终止，这一点已经确定。但其继承人因误解而出售奴隶，并非出于盗窃意图，而是为了完成死者所负责的事务；因此，已被买受人占有的奴隶应视为已由买受人通过取得时效取得。奴隶商从行省返回后，可以正当地提起普布利基安之诉；法院应在查明事实后给予真正所有权抗辩。选择信赖特定之人的人，不应因继承人的错误或无知而受损。

### <a id="17.1.58"></a>17.1.58　保罗《疑义解答》第四卷

<a id="17.1.58.pr."></a>

**序言（pr.）** 如果我先前曾受委任为提提乌斯辩护，而在不知道提提乌斯已经死亡的情况下继续辩护，我认为，可以对提提乌斯的继承人提起委任之诉，因为委任因委任人死亡而终止，但委任之诉本身并不因此消灭。如果我未受委任而承接辩护，就可以说我开始管理死者的事务；正如我若使他获得免责便可以提起无因管理之诉，继承人也可以因同一诉讼承担责任。

<a id="17.1.58.1"></a>

**1.** 卢基乌斯·提提乌斯为其债权人指定了一名委任人。债务人死亡后，在多数债权人同意的情况下，裁判官作出裁定，要求债权人只能从继承人处受领一定份额的清偿；但该委任人所代表的债权人当时不在场。我询问：如果委任人被起诉，他是否享有与债务人继承人相同的抗辩？答复是：如果他当时在场并且也同意裁判官的决定，就应认为双方基于正当原因订立了协议；该抗辩也应给予保证人和委任人。但既然你说明他当时不在场，剥夺他的选择权便不公平；他本可到场提出异议，也可以拒绝裁判官作出该裁定。这并非为继承人提供救济，而是为了委任人或保证人，因为他们通过委任之诉仍须承担同一份额。当然，如果债权人已从继承人处收取一部分，是否仍允许其就余额起诉保证人，曾有疑问；但债权人起诉继承人，似乎就应视为同意了裁定。

### <a id="17.1.59"></a>17.1.59　保罗《答复录》第四卷

<a id="17.1.59.pr."></a>

**序言（pr.）** 如果卡尔普尔尼乌斯依提提乌斯的委任，对提提乌斯所放出的款项作出口约，且并非出于赠与，提提乌斯的继承人可以通过委任之诉起诉卡尔普尔尼乌斯，要求其让与自己的诉权；如果卡尔普尔尼乌斯已经收回款项，结论也相同。

<a id="17.1.59.1"></a>

**1.** 保罗答复说，如果保证人从债权人处买下已依法设定质权的财物，而债务人的继承人对其提起委任之诉；在债务人提出全部应付款项后，应强制保证人连同孳息返还质物。保证人不应被视为普通第三人买受人，因为他在一切契约中都负有诚信义务。

<a id="17.1.59.2"></a>

**2.** 保罗答复说，即使卢基乌斯·提提乌斯在委任中写明自己将在某一日期前履行，该日期也不妨碍对方在该日期之后依据委任之诉起诉。

<a id="17.1.59.3"></a>

**3.** 保罗答复说，即使委任中没有约定，一名共同委任人也可以被选定承担全部责任；但判决若针对两人作出，就必须并且可以根据判决分别向二人追偿，各负一半。

<a id="17.1.59.4"></a>

**4.** 债权人出售了质物。我询问：如果买受人因权利瑕疵丧失占有，债权人能否向委任人追偿？债权人是以其自身权利出售还是依据一般法律承诺出售，是否有区别？保罗答复：如果债权人没有从质物价款中取得足额清偿，就不能认为委任人已获免责。由此答复可以看出，如果债权人不因权利瑕疵承担责任，出售质物就会使委任人获免责。

<a id="17.1.59.5"></a>

**5.** “某某致其姻亲布莱西乌斯·塞维鲁：我委托你以某某质物作担保，向我的姻亲布莱西乌斯·塞维鲁放款八十；对该款及后来产生的任何利息，我以本委任之由保证你的账目不受损失，直到布莱西乌斯·塞维鲁去世为止。”此后，委任人屡次被催告而不答复。我询问：债务人死亡后，委任人是否获免责？保罗答复：委任之债是持续存在的；尽管委任中似乎写明，要以委任之由保证账目不受损失，直至布莱西乌斯·塞维鲁去世。

<a id="17.1.59.6"></a>

**6.** 保罗答复说，如果委任中约定要求债务人提供适当担保，而债权人既未取得保证人也未取得质物，就不应认为已遵守委任条件。

### <a id="17.1.60"></a>17.1.60　斯凯沃拉《答复录》第一卷

<a id="17.1.60.pr."></a>

**序言（pr.）** 债权人起诉委任人，委任人受判决后提起上诉。问题是，在上诉尚未终结时，债权人能否起诉债务人？答复：可以。

<a id="17.1.60.1"></a>

**1.** 某人给即将娶妻的人写了如下书信：“提提乌斯致塞伊乌斯：问候。你知道塞姆普罗尼娅一直是我心中所系。因此，既然她将如我所愿嫁给你，我希望你确信，这桩婚姻与你的身份相称。尽管我知道少女的母亲提提娅会提供充分担保，承诺给付嫁资，但为了使你更加信任我家，我也毫不犹豫地以我的信用作保：因此，请你知道，凡是你基于此事向她约定的事项，我都以自己的信用保证你可以放心。”然而，提提娅既未委托提提乌斯，也未认可他的书信，却向塞伊乌斯承诺给付嫁资。我询问：如果提提乌斯的继承人基于委任而给付，能否以委任之诉起诉提提娅的继承人？答复：根据所述事实，不能。又问：是否至少可以提起无因管理之诉？答复：也不能依法以此名义起诉；因为提提乌斯显然不是以提提娅的名义，而是出于自己想提供帮助，才作出委任。又问：如果丈夫起诉委任人，能否以某项抗辩阻却？答复：没有提出任何可以阻却他的理由。

<a id="17.1.60.2"></a>

**2.** 某人委托两人共同管理事务。问题是，二人是否各自因委任之诉对全部债务承担责任？答复：可以对任何一人请求全部债务，但不得向两人合计请求超过债务总额。

<a id="17.1.60.3"></a>

**3.** 如果丈夫与岳父约定，或以默示方式达成共识，由丈夫承担供养妻子的责任，而父亲支付嫁资利息，则对未能证明已被耗用的款项，不得提起诉讼请求返还。但如果女儿的父亲证明自己曾委托他人供养女儿，就可以提起委任之诉。

<a id="17.1.60.4"></a>

**4.** 卢基乌斯·提提乌斯将自己事务的管理委托给兄弟之子，书信如下：

> *Seiw teknw xairein. egw men kata fusin einai nomizw to huper patros kai twn tou patros uhiwn pragmateuesvai dixa tou tina epitropikon aitein. ei de dei kai toioutou tinos, epitrepw soi peri pantwn twn emwn hws veleis pragmateuesvai, eite pwlein veleis eite hupotivesvai eite agorazein eite hotioun prattein, hws kuriw onti twn emwn: emou panta kuria ta hupo sou ginomena hygoumenou kai myden antilegontos soi pros mydemian pracin.*
>
> 〔底本附拉丁释义：*Seio filio salutem. Mihi quidem videtur naturae conveniens, ut patris necessariorumque patris filius curam gerat nec quisquam procurationem requirat. At si ea quoque quodammodo opus est, rerum mearum omnium procuratorem te facio, ut de iis constituas ut voles, sive vendere voles sive pignori rem obligare sive emere sive aliud quidvis facere, tamquam dominus rerum mearum, cum ego ratum habiturus sim quaecunque gesseris neque in ulla re tibi contra dicturus.*〕
>
> “致我的儿子塞伊乌斯：我认为，儿子为父亲及父亲的必要事务操劳，合乎自然，无须任何人另行请求其担任代理人。但如果确有此种需要，我委任你管理我的全部事务，按你的意愿处理：无论出售、设定质押、购买，还是采取任何其他行动，都如同你是我财产的主人。我将认可你所办理的一切，在任何事务上都不反对你。”

问题是：如果他并非出于管理事务的意图，而是出于欺诈而处分或委托他人处分财物，其行为是否有效？答复：被询问之人虽获得了全面授权，但其行事仍须符合诚信。同样，我询问：如果塞伊乌斯担任公职后成为债务人，卢基乌斯·提提乌斯能否因此被起诉，或其财产是否会因上述书信内容而被设定负担？答复：既不能起诉他，其财产也不受负担。

### <a id="17.1.61"></a>17.1.61　保罗《评涅拉提乌斯》第二卷

我曾委托家子追收一笔债务；他在脱离家父权后将其收回。我可以在一年内提起特有产准诉。保罗说：但也应对家子本人起诉。

### <a id="17.1.62"></a>17.1.62　斯凯沃拉《学说汇纂》第六卷

<a id="17.1.62.pr."></a>

**序言（pr.）** 已故女子的遗产在遗嘱指定的继承人、叔父梅维乌斯和姑母之间发生争议。梅维乌斯写信给姐妹们，表示无论遗产诉讼结果如何，凡他因此取得的财物都将由大家共有，但信后并未订立口约。问题是，梅维乌斯后来与遗嘱指定继承人和解，并依据和解取得若干地产及其他财物，姐妹们能否根据他的信件起诉他？答复：可以。

<a id="17.1.62.1"></a>

**1.** 我以如下措辞作出委任：“卢基乌斯·提提乌斯致我的盖乌斯：问候。我请求并委托你在塞姆普罗尼乌斯面前为普布利乌斯·梅维乌斯作保证；我以亲笔书信通知你，凡普布利乌斯未向你清偿的款项，我将立即偿还。”问题是，如果他没有作保证，而只是委托债权人作保证，并且所采取的行为超出了委任范围，能否提起委任之诉？答复：应承担责任。
