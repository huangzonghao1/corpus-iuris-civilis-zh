## 11.6.0　论测量员虚报测量结果（*Si mensor falsum modum dixerit*）

### <a id="11.6.1"></a>11.6.1　乌尔比安《评告示》第二十四卷

<a id="11.6.1.pr."></a>

**序言（pr.）** 裁判官针对土地测量员设立了一项事实诉讼。我们不应受测量员欺骗，因为我们有利害关系，不应在测量结果的报告上受骗；例如，当事人可能就界址发生争议，或者买受人、出卖人想知道出售土地的面积。因此，裁判官设立此项诉讼，是因为古人不认为此类人与委托人之间成立劳务租赁关系；他们认为，测量员提供劳务更像是作为恩惠而提供服务，支付给他的款项是酬谢，因此称为荣誉金（*honorarium*）。所以，如果依据劳务租赁之诉起诉，诉讼请求就不能成立。

<a id="11.6.1.1"></a>

**1.** 此项诉讼仅要求存在恶意欺诈。因为，测量员并不负有市民法上的债务，仅以恶意欺诈追究其责任，已被认为足以充分制裁他。因此，如果测量员业务不熟练，应由聘用他的人自负其责；即使测量员只是疏忽，也同样不承担责任。不过，重大过失显然等同于欺诈。即使测量员收取了报酬，根据告示的措辞，他也不对一切过失负责；裁判官当然知道测量员也会收取报酬提供服务。

<a id="11.6.1.2"></a>

**2.** 通过报告作出虚假陈述的人，应依此诉讼承担责任；而我们也应认为，通过他人作出报告的人同样属于作出报告。

### <a id="11.6.2"></a>11.6.2　保罗《评告示》第二十五卷

<a id="11.6.2.pr."></a>

**序言（pr.）** 也可以通过书信作出报告。

<a id="11.6.2.1"></a>

**1.** 如果我在你担任测量员时委托你测量一块土地，而你又把此事转托给提提乌斯，提提乌斯在此事上实施恶意欺诈，那么你应承担责任，因为你把事情托付给这样的人，本身就是出于恶意行事。

### <a id="11.6.3"></a>11.6.3　乌尔比安《评告示》第二十四卷

<a id="11.6.3.pr."></a>

**序言（pr.）** 如果我委托两人办理此事，而两人都实施欺诈，可以分别向每人请求全部赔偿；但其中一人被诉并已充分清偿后，对另一人的诉讼就应予拒绝。

<a id="11.6.3.1"></a>

**1.** 此项诉讼属于那些有利害关系、希望测量结果不被虚报的人，也就是买受人或因虚假报告而受损的出卖人。

<a id="11.6.3.2"></a>

**2.** 但庞波尼写道，如果买受人因虚假报告而多付价款给出卖人，由于买受人可以提起返还之诉追回多付部分，就不能再起诉测量员；买受人既然可以追回多付款，就没有损害。不过，如果出卖人没有清偿能力，测量员便应承担责任。

<a id="11.6.3.3"></a>

**3.** 同理，庞波尼认为，如果出卖人因测量员欺骗而交付了面积较大的土地，就不能对测量员提起诉讼，因为出卖人可以对买受人提起买卖之诉；除非该买受人也没有清偿能力。

<a id="11.6.3.4"></a>

**4.** 庞波尼还写道，如果测量员受聘参与诉讼，却在报告中欺骗我，并因此使我在诉讼中少获利益，他就应承担责任。显然，如果测量员是由法官聘用，并出于恶意作出不利于我的报告，庞波尼则疑问他是否应对我负责；他更倾向于承认应当负责。

<a id="11.6.3.5"></a>

**5.** 庞波尼写道，此项诉讼应授予原告的继承人及类似权利承受人；但他认为，不得针对被告的继承人及类似承受人提起此诉。

<a id="11.6.3.6"></a>

**6.** 庞波尼认为，就奴隶实施的行为而言，更宜给予加害奴隶之诉，而非特有财产之诉，尽管市民法上的特有财产之诉也可以提起。

### <a id="11.6.4"></a>11.6.4　保罗《评告示》第二十五卷

此项诉讼是永久性的，因为诉因并非始于欺骗行为，而是源自所承接的事务。

### <a id="11.6.5"></a>11.6.5　乌尔比安《评告示》第二十四卷

<a id="11.6.5.pr."></a>

**序言（pr.）** 如果测量员没有报告虚假面积，只是拖延报告，并因此使出卖人得以免责——该出卖人曾承诺在某个确定日期前标定面积——则本诉不适用。庞波尼还认为，不应给予准诉权。因而只能转而提起欺诈之诉。

<a id="11.6.5.1"></a>

**1.** 如果测量员报告了虚假面积，而买受人已对出卖人提起买卖之诉，他仍可以起诉测量员；但如果买受人并无损失，就不应判令测量员赔偿。如果买受人没有就所短缺的全部面积起诉出卖人，而只就其中较少部分起诉，庞波尼据此写道，买受人可以就剩余部分起诉测量员。

<a id="11.6.5.2"></a>

**2.** 裁判官扩大了此项诉讼的适用范围：如果有人被指称虚报其他事物的测量结果，也可以提起本诉。因此，无论是建筑物、谷物还是葡萄酒的测量结果有误，

### <a id="11.6.6"></a>11.6.6　保罗《评告示》第二十四卷

无论争议涉及道路的宽度、插入梁木权或向邻地突出建筑部分之地役权，还是测量场地、梁木或石块时有人作出虚假陈述，均包括在内。

### <a id="11.6.7"></a>11.6.7　乌尔比安《评告示》第二十四卷

<a id="11.6.7.pr."></a>

**序言（pr.）** 对任何其他事物作出虚假测量报告的，也应承担责任。

<a id="11.6.7.1"></a>

**1.** 即使机械测量员（*mensor machinarius*）实施欺骗，也应给予此项诉讼。

<a id="11.6.7.2"></a>

**2.** 此外，庞波尼还说，即使行为人并非测量员，但在测量结果上作了虚假陈述，也可以对其提起此项诉讼。

<a id="11.6.7.3"></a>

**3.** 依照这一先例，也应允许对作出欺骗的建筑师提起诉讼；因为神圣的塞维鲁皇帝曾裁定，可以对建筑师和承包人提起诉讼。

<a id="11.6.7.4"></a>

**4.** 我也认为，应允许对计算中作出错误的簿书员（*tabularius*）提起诉讼。
