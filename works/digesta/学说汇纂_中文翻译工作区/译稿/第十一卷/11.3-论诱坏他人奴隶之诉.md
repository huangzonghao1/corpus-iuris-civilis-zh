## 11.3.0　论诱坏他人奴隶之诉（*De servo corrupto*）

### <a id="11.3.1"></a>11.3.1　乌尔比安《评告示》第二十三卷

<a id="11.3.1.pr."></a>

**序言（pr.）** 裁判官说：“有人被指称以恶意收留他人的男奴或女奴，或者诱使其做某事，意在使该奴隶变坏的，我将对其授予一项诉讼，判其支付该事物价值的双倍。”（原文：*Qui servum servam alienum alienam recepisse persuasisseve quid ei dicetur dolo malo, quo eum eam deteriorem faceret, in eum quanti ea res erit in duplum iudicium dabo.*）

<a id="11.3.1.1"></a>

**1.** 善意买受奴隶的人不受此告示拘束，因为他自己也不能提起诱坏奴隶之诉；奴隶未被诱坏与他并无利害关系。况且，若承认他可以提起此诉，就会导致两人都能提起诱坏奴隶之诉，这显然荒谬。我们也认为，善意地有自由人服侍自己的人，不能提起此诉。

<a id="11.3.1.2"></a>

**2.** 裁判官所说的“收留”（*recepisse*），我们理解为将他人的奴隶接纳到自己处。严格而言，收留是指为奴隶提供藏匿之所，无论是在自己的田地，还是在他人的地方或建筑物内。

<a id="11.3.1.3"></a>

**3.** “劝诱”（*persuadere*）比迫使、强令某人服从更进一步。不过，劝诱属于中性的事物（底本作希腊语转写 *twn meswn estin*；即“处于中间状态”）：有人可以通过提出建议劝人为善，也可以劝人为恶。因此裁判官补充说，须以恶意意图使奴隶变坏。毕竟，只有劝奴隶做某种会使其变坏之事的人，才构成不法行为。因此，诱使奴隶去做或去想不正当之事的人，显然是本告示所针对的对象。

<a id="11.3.1.4"></a>

**4.** 只有在劝诱一个品行良好的奴隶犯罪时，劝诱者才承担责任吗？还是说，即使他劝奴隶做坏事，或者教他如何做坏事，也应承担责任？更可取的意见是，即使他教奴隶如何犯罪，也应承担责任。甚至，如果奴隶本来无论如何都会逃跑或盗窃，而此人却赞许了奴隶的计划，他仍应负责；不应通过赞许使恶行加重。因此，无论是使好奴隶变坏，还是使坏奴隶变得更坏，都应视为诱坏奴隶。

<a id="11.3.1.5"></a>

**5.** 劝奴隶实施侮辱、盗窃、逃跑，或诱使他人的奴隶；劝其侵扰自己的特有财产（*peculium*）；使其沉溺情欲、成为游荡者、醉心邪术、过度沉迷演出或参与煽动骚乱，也都属于使奴隶变坏。又如，有人以言语或金钱劝诱管事奴隶，毁坏或篡改主人的账簿，甚至扰乱交托给他的账目：

### <a id="11.3.2"></a>11.3.2　保罗《评告示》第十九卷

或者使奴隶变得放纵或桀骜不驯；又或者劝诱他遭受强暴。

### <a id="11.3.3"></a>11.3.3　乌尔比安《评告示》第二十三卷

<a id="11.3.3.pr."></a>

**序言（pr.）** 裁判官在条文中加入“恶意”一语，是为了谴责劝诱者的狡诈；反之，若有人并无恶意地使奴隶变坏，不受谴责；若只是为了嬉戏而为，也不承担责任。

<a id="11.3.3.1"></a>

**1.** 因此有人提出问题：若某人劝他人的奴隶爬上屋顶或下到井里，奴隶听从后爬上或下去，结果跌倒、摔断腿或其他部位，甚至死亡，劝诱者是否承担责任？若其并无恶意，则不承担责任；若有恶意，则应负责。

### <a id="11.3.4"></a>11.3.4　保罗《评告示》第十九卷

不过，更妥当的做法是依据《阿奎利亚法》的准诉权追究其责任。

### <a id="11.3.5"></a>11.3.5　乌尔比安《评告示》第二十三卷

<a id="11.3.5.pr."></a>

**序言（pr.）** “恶意”一词也适用于收留者；只有恶意收留的人才承担责任。反之，如果有人收留奴隶是为了替主人看管，或出于仁慈、怜悯，或基于其他受到认可且正当的理由，则不承担责任。

<a id="11.3.5.1"></a>

**1.** 如果有人以恶意劝诱一个奴隶做某事，而他以为此人是自由人，我认为应令其承担责任；因为明知对方是自由人仍加以诱坏，过错更重。因此，即使对方实际上是奴隶，他也应负责。

<a id="11.3.5.2"></a>

**2.** 即使被告承认事实，此项诉讼仍可判处双倍；而《阿奎利亚法》仅制裁否认责任的人。

<a id="11.3.5.3"></a>

**3.** 如果据称行为是由男奴或女奴实施，法院应准许附有交付加害奴隶（*noxae deditio*）的诉讼。

<a id="11.3.5.4"></a>

**4.** 此项诉讼针对的是奴隶遭诱坏或遭收留之时，而非起诉时。因此，即使奴隶后来死亡、被转让或获释，诉讼仍然可以提起；诉权一经发生，也不会因释放奴隶而消灭：

### <a id="11.3.6"></a>11.3.6　保罗《评告示》第十九卷

因为本案所估价的是过去的利益：

### <a id="11.3.7"></a>11.3.7　乌尔比安《评告示》第二十三卷

毕竟，品行不良的奴隶也可能后来获得自由；而后来发生的情况，有时也会为释放奴隶提供正当理由。

### <a id="11.3.8"></a>11.3.8　保罗《评告示》第十九卷

奴隶遭诱坏之人的继承人也享有此项诉权；无论该奴隶仍留在遗产中，还是已经离开遗产——例如被遗赠给他人——均是如此。

### <a id="11.3.9"></a>11.3.9　乌尔比安《评告示》第二十三卷

<a id="11.3.9.pr."></a>

**序言（pr.）** 如果有人诱坏了我与他共有的奴隶，尤利安在《学说汇纂》第九卷中讨论此人是否应依本诉承担责任，并认为他应对其合伙人负责。尤利安还说，如果双方是合伙人，也可以提起共有物分割之诉或合伙之诉。但尤利安为何使合伙人的处境比对外人提起诉讼更为不利？因为对外人，无论其收留还是诱坏奴隶，都可以提起诉讼；而对合伙人则不能择一提起，只能在其诱坏奴隶时起诉。或许尤利安认为合伙人之间不可能发生“收留”之事：毕竟无人收留自己的东西。不过，如果他以藏匿为目的收留奴隶，则可以主张其应承担责任。

<a id="11.3.9.1"></a>

**1.** 如果我对某奴隶享有用益权，而你享有其所有权，那么，如果是我使该奴隶变坏，你可以对我提起诉讼；如果是你所为，我可以提起准诉权之诉。此项诉讼涵盖各种诱坏行为；用益权人显然有利害关系，使其享有用益权的奴隶保持良好品行。如果另有人收留或诱坏该奴隶，用益权人也享有准诉权之诉。

<a id="11.3.9.2"></a>

**2.** 所授予的诉权，是请求判处该事物价值双倍的诉权。

<a id="11.3.9.3"></a>

**3.** 但有一个问题：估价是否只应考虑奴隶身体或精神所受的损害，也就是其价值因此降低了多少；还是也应考虑其他人的损失？内拉齐乌斯认为，诱坏者应按奴隶因遭受诱坏而贬值的数额被判处赔偿。〔底本疑词：此处作 *subpertus*，词义及文本形态待核；暂按“遭受诱坏”理解。〕

### <a id="11.3.10"></a>11.3.10　保罗《评告示》第十九卷

本诉的估价也包括奴隶带走的物品，因为全部损害均应加倍计算；这些物品是被带到被告那里、带到他人那里，还是已经被耗用，均无关紧要。与其追查物品最终落入谁手，不如令最初实施不法行为的人承担责任，这样更为公正。

### <a id="11.3.11"></a>11.3.11　乌尔比安《评告示》第二十三卷

<a id="11.3.11.pr."></a>

**序言（pr.）** 内拉齐乌斯说，后来发生的盗窃不计入估价。我认为这一意见正确，因为告示所用“该事物价值多少”一语，涵盖全部损失。

<a id="11.3.11.1"></a>

**1.** 我劝诱一名奴隶毁坏债务人的借据；显然，我应承担责任。但是，如果该奴隶后来因养成犯罪习惯，进而盗走、涂改或销毁账簿及其他类似文书，应当认为诱坏者不因这些行为而承担责任。

<a id="11.3.11.2"></a>

**2.** 虽然就被盗物品而言可以提起诱坏奴隶之诉，我们仍可提起盗窃之诉，因为物品显然是在劝诱者的帮助或教唆下被盗走的。仅提起其中一项诉讼并不足够，因为一项诉权不会减损另一项。尤利安对收留奴隶、将其藏匿并使其变坏之人，也作了同样论述：盗窃者与使奴隶变坏者实施的是不同的不法行为；此外，此人还须承担返还诉权（*condictio*）之责。即使原告已通过返还诉权取回奴隶、并通过盗窃之诉取得罚金，仍可通过诱坏奴隶之诉取得其利益损失，

### <a id="11.3.12"></a>11.3.12　保罗《评告示》第十九卷

因为即使物品已经返还，被告仍继续负有债务。

### <a id="11.3.13"></a>11.3.13　乌尔比安《评告示》第二十三卷

<a id="11.3.13.pr."></a>

**序言（pr.）** 此项诉讼是永久性的，而非限期提起；继承人及其他概括承受人均可提起。由于它具有罚则性质，不得针对被告的继承人提起。

<a id="11.3.13.1"></a>

**1.** 如果有人诱坏了遗产中的奴隶，也应依本诉承担责任；并且还可像掠夺人一样，通过遗产请求之诉追究其责任，

### <a id="11.3.14"></a>11.3.14　保罗《评告示》第十九卷

<a id="11.3.14.pr."></a>

**序言（pr.）** 也就是说，遗产请求之诉所计入的金额，以本诉所涉及的金额为限。

<a id="11.3.14.1"></a>

**1.** 如果被诱坏的是家父权下的儿子或女儿，本告示不适用，因为诱坏奴隶之诉是为属于我们财产的奴隶设立的。即便家庭尊严和名誉未受影响，主人仍可以证明自己因此变得贫困；但可提起准诉权之诉，由法官依其职权估价，因为我们的利益在于子女的心志不被败坏。

<a id="11.3.14.2"></a>

**2.** 如果我与你共有的奴隶诱坏了我自己的奴隶，萨宾认为不能对合伙人提起诉讼，正如我自己的奴隶诱坏了同属我的奴隶时一样。如果共有奴隶诱坏了外人的奴隶，则须考察应当同时对两名共有人起诉，还是像其他加害奴隶之诉那样分别对他们起诉。更可取的意见是，每人都应对全部债务承担责任；但其中一人清偿后，另一人即获免责。

<a id="11.3.14.3"></a>

**3.** 如果我对某人享有用益权，而此人诱坏了我的奴隶，我可以对其所有权人提起诉讼。

<a id="11.3.14.4"></a>

**4.** 债务人以质押物被诱坏为由享有此项诉权。

<a id="11.3.14.5"></a>

**5.** 本诉的双倍赔偿不超出诉讼标的本身；也就是说，只有所造成的损害额加倍。

<a id="11.3.14.6"></a>

**6.** 依此也可确认：如果你劝我的奴隶去偷提提乌斯的东西，你不仅须赔偿奴隶因此变坏所造成的损失，还须赔偿我应向提提乌斯承担的金额。

<a id="11.3.14.7"></a>

**7.** 同样，不仅在你教唆奴隶使我遭受损害时，你须向我负责；即使奴隶使第三人遭受损害，你也须就我依《阿奎利亚法》所负的责任向我负责。又如，我因将奴隶出租给他人，而该奴隶因你所为变坏，须依租赁之诉对承租人负责，那么你也须就此对我负责；其他类似情形亦同。

<a id="11.3.14.8"></a>

**8.** 本诉中的估价，应考察奴隶的效用价值；具体数额由法官依其职权确定：

<a id="11.3.14.9"></a>

**9.** 但有时奴隶反而变得毫无用处，以致主人不宜继续留用。那么，诱劝者是否应支付奴隶的价款，而主人则无偿取得奴隶？还是主人必须交还奴隶并取得其价款？更可取的意见是，应由主人选择：如果主人愿意保留奴隶，就取得相当于奴隶因变坏而遭受损害额的双倍赔偿；或者，如果能够交还奴隶，就在交还后取得其价款。如果无法交还，也应以同样方式取得价款，但须将关于该奴隶所有权的诉权让与诱劝者，并由诱劝者承担相关风险。关于交还奴隶的规则，仅适用于奴隶尚在人世时提起诉讼的情形。如果奴隶已被释放后才提起诉讼，又当如何？主人若辩称自己释放奴隶，是因为不愿再将其留在家中，从而既要取得价款又要保有自由人，恐怕不会轻易得到法官采纳。

### <a id="11.3.15"></a>11.3.15　盖尤斯《评行省告示》第六卷

即使有人劝奴隶蔑视主人，也会败坏奴隶的心志。

### <a id="11.3.16"></a>11.3.16　阿尔费努《学说汇纂》第二卷

主人释放了一名管理财务的奴隶；后来，他从该奴隶处收到账目，却发现账目对不上，遂查明该奴隶曾在某个女人那里花掉钱款。有人问：该奴隶既已成为自由人，主人能否对该女人提起诱坏奴隶之诉？我答复说可以；对于奴隶交给她的款项，还可以提起盗窃之诉。

### <a id="11.3.17"></a>11.3.17　马尔基安《格言集》第四卷

在婚姻关系存续期间，丈夫可以以诱坏奴隶为由对该妇女提起诉讼；但出于维护婚姻的考虑，判处单倍赔偿。
