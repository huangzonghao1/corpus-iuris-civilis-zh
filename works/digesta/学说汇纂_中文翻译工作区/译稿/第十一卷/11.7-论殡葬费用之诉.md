## 11.7.0　论宗教性场所、殡葬费用及准许举行葬礼（*De religiosis et sumptibus funerum et ut funus ducere liceat*）

### <a id="11.7.1"></a>11.7.1

乌尔比安《评告示》第十卷

因葬礼而支出费用的人，被视为与死者订立了契约，而非与继承人订立契约。

### <a id="11.7.2"></a>11.7.2

乌尔比安《评告示》第二十五卷

<a id="11.7.2.pr."></a>

**序言（pr.）** 阿里斯托认为，奴隶埋葬之处即成为宗教性场所。

<a id="11.7.2.1"></a>

**1.** 将死者埋入他人之地，或安排他人这样做的人，应承担事实之诉的责任。“他人之地”既指土地，也指建筑物。但是，此处的表述仅赋予所有权人诉权，不赋予善意占有人诉权：既然说“他人之地”，显然是指所有权人的土地，即该处土地的所有人。用益权人将死者埋入土地，也应对裸所有权人承担责任。共有人在另一共有人不知情时将死者埋入共有土地，是否承担责任，尚可讨论；但较为正确的意见是，可以对其提起遗产分割之诉或共有物分割之诉。

<a id="11.7.2.2"></a>

**2.** 行政长官规定：“据称，有人将死者或死者的遗骨埋入他人的纯粹场所，或埋入其无权埋葬的墓地。”实施此行为的人应承担事实之诉责任，并受金钱处罚。

<a id="11.7.2.3"></a>

**3.** 行政长官所指的是以埋葬为目的的埋入行为。

<a id="11.7.2.4"></a>

**4.** 所谓“纯粹场所”，是指既非神圣、非受保护，亦非宗教性场所，并且似乎不具有上述任何属性的场所。

<a id="11.7.2.5"></a>

**5.** 墓地，是指埋有人的尸体或遗骨之处。塞尔苏斯说，并非整个预定用于埋葬的场所都成为宗教性场所，而只是尸体实际埋葬之处。

<a id="11.7.2.6"></a>

**6.** 纪念性建筑物，是为保存记忆而建造之物。

<a id="11.7.2.7"></a>

**7.** 如果某人享有用益权，他不能使该场所成为宗教性场所。即使另一人享有所有权、另一人享有用益权，所有权人也不能使该场所成为宗教性场所；但如果埋葬的是遗赠用益权之人本人，且无法同样便利地将其埋入别处，则另当别论；尤利安即如此写道。其他情形下，未经用益权人同意，该场所不会成为宗教性场所；但如果用益权人同意，较妥当的意见是该场所可以成为宗教性场所。〔底本作“*Sed et si alius proprietatem. Alius usum fructum habuit*”，句法有疑，以上依上下文暂译。〕

<a id="11.7.2.8"></a>

**8.** 役权所及的场所，未经享有该役权之人的同意，任何人均不能使其成为宗教性场所。但如果役权可以同样便利地经由另一处场所行使，就不视为有人意图妨碍役权，因此该场所可以成为宗教性场所；这确有道理。

<a id="11.7.2.9"></a>

**9.** 将土地设定质权的人，如果把自己的死者埋入该土地，就会使该地成为宗教性场所；如果埋入的是其本人，结论也相同。但他不能允许他人在此埋葬。

### <a id="11.7.3"></a>11.7.3

保罗《评告示》第二十七卷

不过，较为有用的意见是，经所有共有人同意，场所可以成为宗教性场所；庞波尼乌斯也这样写道。

### <a id="11.7.4"></a>11.7.4

乌尔比安《评告示》第二十五卷

遗嘱指定的继承人在接受遗产之前，将已故家父埋入土地，也会使该地成为宗教性场所；但不应因此认为他已经以继承人身份处理遗产。设想他此时仍在考虑是否接受遗产即可。我还认为，即使埋葬死者的不是继承人，而是其他人——无论继承人尚未出现、缺席，还是担心自己的行为会被视为以继承人身份处理遗产——该地仍会成为宗教性场所。死者往往在继承人确定之前就已下葬。只有死者曾经拥有该处时，该地才成为宗教性场所；因为埋葬地点在自然意义上似乎属于死者，尤其是在死者被埋入其本人指定的地点时。即使继承人将死者埋入遗赠给他人的地点，只要无法同样便利地埋在别处，该地仍会因依遗嘱人的意思而埋葬死者成为宗教性场所。

### <a id="11.7.5"></a>11.7.5

盖尤斯《评行省告示》第十九卷

家族墓地，是指某人为自己及其家族设立的墓地；继承人墓地，则是某人为自己及其继承人设立的墓地。

### <a id="11.7.6"></a>11.7.6

乌尔比安《评告示》第二十五卷

<a id="11.7.6.pr."></a>

**序言（pr.）** 或者，是家父依继承权取得的场所。在这两类墓地中，无论何种继承人及其他继受人，即使仅以遗嘱或无遗嘱方式取得极小份额，均可在此安葬死者，即使其他人不同意。任何性别或辈分的子女，包括仍处于家父权之下的子女及已解放出家父权者，不论后来成为继承人还是放弃继承，也享有同样权利。被剥夺继承权的人，出于人道可以仅将自己埋葬于此；除非遗嘱人因正当的憎恶而特别禁止，否则不得将自己的后代以外之人埋入墓地。被释奴既不能在此安葬，也不能将他人埋入墓地，除非其成为释奴主的继承人，尽管有人曾在墓志上刻明“此墓为本人及其被释奴所建”。帕比尼安即如此答复，且此规则屡经确认。

<a id="11.7.6.1"></a>

**1.** 如果墓地仍是纯粹场所，任何人均可将其出售或赠与。如果建成的是衣冠冢，也应认为可以出售；因为神圣的皇帝兄弟曾以敕答确认，该处并非宗教性场所。

### <a id="11.7.7"></a>11.7.7

盖尤斯《评行省告示》第十九卷

<a id="11.7.7.pr."></a>

**序言（pr.）** 将死者埋入他人之地的人，应依事实之诉被责令移走其所埋之物，或者支付该地点的价款。此诉既可向继承人提起，也可由继承人提起，并且不受时效限制。

<a id="11.7.7.1"></a>

**1.** 如果有人将死者埋入他人的石棺，而该石棺尚未安葬死者，总督会针对其给予准事实之诉，因为严格说来，这不能称为将死者埋入他人的墓地或场所。

### <a id="11.7.8"></a>11.7.8

乌尔比安《评告示》第二十五卷

<a id="11.7.8.pr."></a>

**序言（pr.）** 有人将尸体或遗骨埋入某处后，该地点所有人能否未经祭司团裁定或元首命令便将其挖出或移走，尚有疑问。拉贝奥说，应等待祭司团许可或元首命令；否则，驱逐尸体的人将承担侵辱之诉责任。

<a id="11.7.8.1"></a>

**1.** 如果宗教性场所被当作纯粹场所出售，裁判官应向该事项的权利人给予事实之诉；该诉也可针对继承人提起，因为它包含了类似买卖之诉的内容。

<a id="11.7.8.2"></a>

**2.** 如果有人将死者埋入供公共用途的场所，且出于故意，裁判官应给予针对他的诉讼，并应通过非常程序予以适度处罚；如果并无故意，则应判其免责。

<a id="11.7.8.3"></a>

**3.** 在本诉中，“纯粹场所”一语也应扩展适用于建筑物。

<a id="11.7.8.4"></a>

**4.** 此诉不仅属于所有人，也属于对该地点享有用益权或某种役权的人，因为他们也享有禁止权。

<a id="11.7.8.5"></a>

**5.** 某人有权将死者埋入某处，却遭到禁止，可以提起事实之诉和令状之诉；即使受到禁止的是他的代理人而非本人，也可以如此，因为从法律意义上说，仍可视为本人受到禁止。

### <a id="11.7.9"></a>11.7.9

盖尤斯《评行省告示》第十九卷

被禁止埋葬死者或死者遗骨的人，可以立即提起令状之诉，以禁止对其施加暴力；也可以改在别处埋葬，之后再提起事实之诉。通过后者，原告可以取得相当于自己因未遭禁止而本可获得利益的金额。计算时应考虑购买地点的价款或租赁地点的租金，也应考虑原本属于自己的地点的价值——若非受到强迫，任何人都不会使该地点成为宗教性场所。因此，我不明白为何通说认为该诉既不能向继承人提起，也不能由继承人提起；显然，该诉涉及金钱数额的计算。无论如何，此诉在相关当事人之间始终可以提起。

### <a id="11.7.10"></a>11.7.10

乌尔比安《评告示》第二十五卷

土地出卖人如果保留墓地，以便自己及其后代在那里安葬，那么当他被禁止通行以埋葬死者时，可以提起诉讼。因为买卖双方也应被视为约定：出卖人有权为了埋葬而经过该土地。

### <a id="11.7.11"></a>11.7.11

保罗《评告示》第二十七卷

如果墓地地点出售时附有不得将依法有权埋葬之人埋入其中的条件，仅有此项协议并不足够，必须通过要式口约对此作出担保。

### <a id="11.7.12"></a>11.7.12

乌尔比安《评告示》第二十五卷

<a id="11.7.12.pr."></a>

**序言（pr.）** 如果某人拥有墓地，却没有通往墓地的道路，并且邻人禁止其通行，安东尼努斯皇帝与其父皇曾以敕答指出，通常可以请求并获准临时通行，以便在原本无权通行时，向拥有相邻土地的人请求通路。但这一敕答虽准许提出请求，并未因此创设市民法诉权；而应通过非常程序请求总督介入，后者此时应强制对方以公平价格提供通路，但法官还应考虑地点是否便利，以免邻人遭受重大损害。

<a id="11.7.12.1"></a>

**1.** 元老院决议规定，不得通过改变用途而玷污墓地，也就是说，不得使墓地改作其他用途。

<a id="11.7.12.2"></a>

**2.** 行政长官规定：“凡为葬礼而支出的费用，我将准许向该事项的责任人提起诉讼，请求偿还。”

<a id="11.7.12.3"></a>

**3.** 这一告示基于正当理由发布，使办理葬礼的人能够追偿其支出；这样，尸体就不会无人埋葬，也不会有人不得不自费为他人办理葬礼。

<a id="11.7.12.4"></a>

**4.** 办理葬礼的人，应是死者生前指定之人。如果该人没有办理葬礼，并无任何处罚，除非死者为此留给他某种利益；此时，如果他不遵从死者意愿，就不得取得该利益。如果死者没有就此作出安排，也未将此任务委托任何人，该事务就由遗嘱指定的继承人承担；如无遗嘱指定的继承人，则由法定继承人或血亲亲属依其继承顺序承担。

<a id="11.7.12.5"></a>

**5.** 葬礼费用应根据死者的财力和身份地位确定。

<a id="11.7.12.6"></a>

**6.** 总督或市政官员应确定葬礼所需费用。如果遗产中有现金，应从现金中支付；如果没有现金，应出售会随时间而灭失、继续保留反而加重遗产负担的物品；若仍不足，则应命令出售或质押金银，以筹措款项：

### <a id="11.7.13"></a>11.7.13

盖尤斯《评行省告示》第十九卷

或者，如果容易收取，也可以向债务人追收。

### <a id="11.7.14"></a>11.7.14

乌尔比安《评告示》第二十五卷

<a id="11.7.14.pr."></a>

**序言（pr.）** 如果有人阻挠买受人，致使所购财物不能交付给他，裁判官应当介入；凡有事妨碍已售财物交付给买受人，裁判官都应对此提供保护。

<a id="11.7.14.1"></a>

**1.** 如果死者是佃户或房客，而没有财物可以用来办理葬礼，庞波尼乌斯写道，应从其带入并置于租赁物中的财物中为其办理葬礼；如有余额，该余额应抵偿所欠租金。如果遗嘱人将遗赠物留给他人，而没有其他财物可以办理葬礼，也应动用遗赠物；宁可用死者自己的财物为其办理葬礼，也不要让他人取得遗赠。如果遗产后来被接受，也不得从买受人处取回该物，因为买受人是善意占有人；他经法官授权而购买，取得了所有权。但如果继承人能够使受遗赠人不受损失，就不应剥夺其遗赠；如果不能做到，宁可不让受遗赠人得利，也不要使买受人蒙受损失。

<a id="11.7.14.2"></a>

**2.** 如果遗嘱人委托某人办理自己的葬礼，而该人收取款项后却没有办理葬礼，梅拉写道，应给予针对他的恶意欺诈之诉；不过，我认为，裁判官还应通过非常程序强制其办理葬礼。

<a id="11.7.14.3"></a>

**3.** 只有为办理葬礼而支出、且属于葬礼不可或缺费用的支出，才视为葬礼费用；没有这项支出，葬礼便无法进行。例如，为将死者抬出而支出的费用就是如此。拉贝奥还写道，为埋葬死者而购买地点的费用也属于葬礼费用，因为必须准备安放尸体的地点。

<a id="11.7.14.4"></a>

**4.** 为将在外地死亡者的遗体运回而支出的费用，属于葬礼费用，即使死者尚未安葬亦然。为看护或安置尸体所支出的费用，以及购置大理石棺或衣物的费用，也同样属于葬礼费用。

<a id="11.7.14.5"></a>

**5.** 不应将装饰物或其他类似物品与尸体一同埋葬；这是一些较为朴素之人的做法。

<a id="11.7.14.6"></a>

**6.** 所谓殡葬费用之诉，源于公平与诚信；但其审理范围仅限于葬礼费用，不包括其他支出。公平的判断，应考虑死者的身份地位、具体事由、时机和诚信：既不得请求超过实际支出的数额，也不得在支出明显过度时照额全数计入。还应考虑为其办理葬礼之人的财力，以及无正当理由而超额耗费的支出本身。如果费用是依死者意愿支出的，又该如何处理？应知，即使死者有此意愿，只要费用超出合理范围，就不应遵从；支出仍应与死者的财力相称。

<a id="11.7.14.7"></a>

**7.** 有时，为葬礼支出费用的人不得请求偿还，因为他是出于孝敬之情而支出，并无意日后追回费用；我们的皇帝曾以敕答作此说明。因此，仲裁人应当衡量支出者当时的意图：他究竟是在管理死者或继承人的事务，还是出于人道，抑或是出于怜悯、虔敬或亲情。对怜悯的程度也可以作区分：为死者办理葬礼的人，或许只是出于怜悯与孝敬，使死者得以安葬、不至于暴尸，并非有意自行承担费用。如果法官认定情况确实如此，就不应仅据此判被诉者免责；毕竟，谁会毫无怜悯之心地埋葬他人的尸体呢？因此，支出者应事先声明自己是以何种意图办理葬礼，以免日后遭受争议。

<a id="11.7.14.8"></a>

**8.** 许多儿子在为父母办理葬礼时，或其他可能成为继承人的人，虽然仅凭这一行为既不能推定其已以继承人身份处理遗产，也不能推定其已接受继承，但他们仍会声明自己是出于孝敬而安葬死者，以免被认为已经干预遗产或以继承人身份处理遗产。若仅作这种概括声明，似乎只能使他们免受被视为干预遗产的指责，而不能确保费用得到偿还，因为他们声明是出于孝敬而为。因此，他们应作更充分的声明，以便也能追偿费用。

<a id="11.7.14.9"></a>

**9.** 或许有人会说，有时可以请求偿还部分费用：例如，支出者部分是在管理他人事务，部分是出于孝敬。此说更为正确。因此，对于并非出于赠与意思而支出的部分，可以请求偿还。

<a id="11.7.14.10"></a>

**10.** 负责依公平原则审理此案的法官，有时应完全不认可过少的支出；例如，为了羞辱富有的死者而只办了过于简陋的葬礼。以这种方式办理葬礼，似乎是在羞辱死者，法官不应考虑该项支出。

<a id="11.7.14.11"></a>

**11.** 如果某人以为自己是继承人而为家父办理葬礼，就不能提起殡葬费用之诉，因为他并非以管理他人事务的意思行事；特雷巴提乌斯和普罗库鲁斯均持此说。不过，我认为，具体情形适当时，也应给予其殡葬费用之诉。

<a id="11.7.14.12"></a>

**12.** 拉贝奥说，如果某人另有诉权可以请求偿还葬礼费用，就不能提起殡葬费用之诉。因此，如果他可以提起遗产分割之诉，就不应提起殡葬费用之诉；但如果他已经通过遗产分割之诉起诉，仍可以再行起诉。

<a id="11.7.14.13"></a>

**13.** 拉贝奥还说，如果你违背继承人的禁止而为遗嘱人办理葬礼，具体情形适当时，你仍享有殡葬费用之诉。因为，假设继承人禁止你为遗嘱人的儿子办理葬礼，又该如何？对此可以反驳说：“那么，你就是出于孝敬才办理葬礼的。”但假设我已经声明，我保留提起殡葬费用之诉的权利；毕竟，死者得到妥善安葬对其自身有利。再假设遗嘱人确曾委托我办理葬礼，继承人却加以禁止，而我仍然办理了；难道不应公平地允许我提起殡葬费用之诉吗？总的来说，我认为，公正的法官不应仅仅照搬无因管理之诉，而应更灵活地遵循公平原则；此诉的性质也允许法官这样做。

<a id="11.7.14.14"></a>

**14.** 神圣的马可皇帝曾以敕答指出，继承人禁止遗嘱人指定的人办理葬礼，做法不当；但法律并未对其规定处罚。

<a id="11.7.14.15"></a>

**15.** 受他人委托办理葬礼的人，没有殡葬费用之诉；享有该诉权的是委托办理葬礼的人，无论委托人已经向受托人付款，还是仍欠其费用。如果未成年人未经监护人同意而作出委托，应准许支出者对继承人提起准殡葬费用之诉；让继承人因此获利并不公平。如果未成年人未经监护人同意，委托他人办理与自己有关的葬礼，我认为，只要该未成年人后来成为死者的继承人，且遗产有清偿能力，就应准许对其提起诉讼。反之，如果有人奉继承人之命办理葬礼，拉贝奥写道，他不能提起殡葬费用之诉，因为他可以提起委任之诉。

<a id="11.7.14.16"></a>

**16.** 但如果某人是以管理继承人事务的意思办理葬礼，即使继承人不予追认，拉贝奥仍写道，该人可以提起殡葬费用之诉。

<a id="11.7.14.17"></a>

**17.** 此诉可向应当负责办理葬礼的人提起，例如继承人、遗产占有人以及其他继受人。

### <a id="11.7.15"></a>11.7.15

庞波尼乌斯《评萨比努斯》第五卷

依遗嘱以外的方式请求取得遗产占有的释奴主，也应承担葬礼费用。

### <a id="11.7.16"></a>11.7.16

乌尔比安《评告示》第二十五卷

裁判官可以对取得嫁资财物的人给予殡葬费用之诉。古人认为，这最为公平：妇女可以像从自己的财产一样，从嫁资中支付葬礼费用；因妇女死亡而取得嫁资的人，无论是其父亲还是丈夫，都应分担葬礼费用。

### <a id="11.7.17"></a>11.7.17

帕比尼安《答复集》第三卷

但如果父亲尚未取回嫁资，只应起诉丈夫；丈夫应将其所支付的款项计入与父亲之间的结算：

### <a id="11.7.18"></a>11.7.18

尤利安《学说汇纂》第十卷

因为，葬礼费用构成嫁资的债务：

### <a id="11.7.19"></a>11.7.19

乌尔比安《评萨比努斯》第十五卷

因此，嫁资也应承担这项债务。

### <a id="11.7.20"></a>11.7.20

乌尔比安《评告示》第二十五卷

<a id="11.7.20.pr."></a>

**序言（pr.）** 涅拉提乌斯询问：如果为妇女设定嫁资的人通过要式口约约定返还嫁资的三分之二、由丈夫保留三分之一，并另行约定丈夫无须分担葬礼费用，丈夫是否仍受殡葬费用之诉拘束？涅拉提乌斯说，如果要式口约的当事人本人为妇女办理葬礼，该约定适用，不能对其提起殡葬费用之诉；但如果由他人办理葬礼，则可以起诉丈夫，因为该约定不得违反公法。又如，有人以如下条件为妇女设定嫁资：妇女在婚姻存续期间死亡，或者婚姻以任何方式解除时，嫁资应返还给设定人；此时设定人是否无须分担葬礼费用？但既然妇女死亡后嫁资归其所有，仍可说他应当分担。

<a id="11.7.20.1"></a>

**1.** 如果丈夫取得嫁资，就应对其提起殡葬费用之诉，而不应起诉父亲。不过，我认为，如果嫁资极少，不足以支付葬礼费用，超出部分应允许对父亲提起诉讼。

<a id="11.7.20.2"></a>

**2.** 如果家母死亡，而其遗产没有清偿能力，就应仅从嫁资中为其办理葬礼。塞尔苏斯也这样写道。

### <a id="11.7.21"></a>11.7.21

保罗《评告示》第二十七卷

如果死者是家父权下之人，其父亲应依死者的身份地位和父亲的财力承担殡葬费用之诉的责任。

### <a id="11.7.22"></a>11.7.22

乌尔比安《评告示》第二十五卷

塞尔苏斯写道：妇女死亡时，应由丈夫保有的嫁资及妇女的其他财产按比例共同负担葬礼费用。

### <a id="11.7.23"></a>11.7.23

保罗《评告示》第二十七卷

例如，嫁资为一百，遗产为二百，则继承人承担三分之二，丈夫承担三分之一。

### <a id="11.7.24"></a>11.7.24

乌尔比安《评告示》第二十五卷

尤利安写道：不应扣除遗赠。

### <a id="11.7.25"></a>11.7.25

保罗《评告示》第二十七卷

也不应扣除获释奴隶的价额。

### <a id="11.7.26"></a>11.7.26

庞波尼乌斯《评萨比努斯》第十五卷

也不得先扣除债务。

### <a id="11.7.27"></a>11.7.27

乌尔比安《评告示》第二十五卷

<a id="11.7.27.pr."></a>

**序言（pr.）** 因此，丈夫和继承人都应按比例分担葬礼费用。

<a id="11.7.27.1"></a>

**1.** 如马尔凯卢斯所写，如果丈夫在婚姻存续期间已将嫁资偿付给妻子，就不应对其提起殡葬费用之诉。此说正确，但仅限于法律允许丈夫如此办理的情形。

<a id="11.7.27.2"></a>

**2.** 此外，我认为，丈夫仅在其有能力支付的范围内承担殡葬费用之诉责任；因为如果他被起诉并向妻子给付，他本来就会取得相应利益。

### <a id="11.7.28"></a>11.7.28

庞波尼乌斯《评萨比努斯》第十五卷

阿提利基努斯说，如果没有嫁资，就应由父亲承担全部费用；或者由该妇女的继承人承担，例如已脱离家父权的妇女之继承人。如果她既没有继承人，父亲也无力清偿，就应在丈夫有能力承担的范围内起诉丈夫，以免不公地让其前妻暴尸未葬。

### <a id="11.7.29"></a>11.7.29

盖尤斯《评行省告示》第十九卷

<a id="11.7.29.pr."></a>

**序言（pr.）** 如果妇女离婚后另嫁他人，并在此后死亡，福尔基尼乌斯认为，即使前夫取得嫁资利益，也不应由前夫承担葬礼费用。

<a id="11.7.29.1"></a>

**1.** 如果有人在嫁资返还给父亲之前，为处于家父权下的女儿办理葬礼，可以正当地起诉丈夫；嫁资一经返还，父亲便负有责任。无论如何，如果葬礼办理人已经起诉丈夫，丈夫就可以少向该妇女的父亲返还相应金额。

### <a id="11.7.30"></a>11.7.30

庞波尼乌斯《评萨比努斯》第十五卷

<a id="11.7.30.pr."></a>

**序言（pr.）** 反过来，如果父亲为女儿的葬礼支出费用，或者他人起诉父亲而父亲支付了葬礼费用，父亲可以通过嫁资之诉向丈夫追偿。

<a id="11.7.30.1"></a>

**1.** 但如果已脱离家父权的女儿在婚姻存续期间死亡，她的继承人或遗产占有人、父亲以及丈夫均应按比例分担：父亲按其取回的嫁资份额分担，丈夫按其取得利益的嫁资份额分担。

### <a id="11.7.31"></a>11.7.31

乌尔比安《评告示》第二十五卷

<a id="11.7.31.pr."></a>

**序言（pr.）** 如果家子是军人，并有军人特有产，我认为应先由其继承人承担责任，然后才由其父亲承担。

<a id="11.7.31.1"></a>

**1.** 为他人的奴隶或女奴办理葬礼的人，可以对其所有人提起殡葬费用之诉。

<a id="11.7.31.2"></a>

**2.** 此诉没有一年期限，而是永久有效；既可以由继承人及其他继受人提起，也可以针对继承人及其他继受人提起。

### <a id="11.7.32"></a>11.7.32

保罗《评告示》第二十七卷

<a id="11.7.32.pr."></a>

**序言（pr.）** 如果遗产占有人办理了葬礼，之后在遗产返还之诉中败诉，却未在返还时扣除自己支出的费用，应准许其提起准殡葬费用之诉。

<a id="11.7.32.1"></a>

**1.** 如果丈夫与妻子同时死亡，拉贝奥说，应按嫁资份额对丈夫的继承人给予此诉，因为该份额正是以嫁资名义归其取得。

### <a id="11.7.33"></a>11.7.33

乌尔比安《评告示》第六十八卷

如果某人曾经是继承人，之后因被认定为不配继承而被剥夺遗产，较为可取的意见是，墓地权利仍由其享有。

### <a id="11.7.34"></a>11.7.34

保罗《评告示》第六十四卷

如果某处场所以附条件的方式遗赠，在条件成就前，继承人将死者埋入其中，并不会使该处成为宗教性场所。

### <a id="11.7.35"></a>11.7.35

马尔凯卢斯《学说汇纂》第五卷

古人认为，绝不应哀悼那种意图毁灭祖国、杀害父母与子女的人；如果此人被其子或其父所杀，众人都认定杀害者不构成犯罪，甚至应予奖赏。

### <a id="11.7.36"></a>11.7.36

庞波尼乌斯《评昆图斯·穆基乌斯》第二十六卷

地点被敌人占领时，一切场所都不再具有宗教性或神圣性，正如自由人沦为奴隶一样。如果这些场所从灾祸中获释，就仿佛依据返还权恢复原状，回到其先前的状态。

### <a id="11.7.37"></a>11.7.37

马克尔《继承税法评注》第一卷

<a id="11.7.37.pr."></a>

**序言（pr.）** 葬礼费用包括为尸体而支出的一切，例如香料费用、死者安葬地点的价款、可能产生的地租税、石棺费用及运输费用。我认为，凡在安葬之前为尸体而耗费的款项，都属于葬礼费用。

<a id="11.7.37.1"></a>

**1.** 神圣的哈德良皇帝以敕答指出，墓地纪念物是指为保护安放尸体的地点而建造的设施。因此，如果遗嘱人命令建造大型建筑，例如围绕墓地的柱廊，这些费用便不属于葬礼费用。

### <a id="11.7.38"></a>11.7.38

乌尔比安《诸法庭事务》第九卷

为避免死者尸体或遗骨遭扣留、骚扰，或被阻止经由公路运送和安葬，行省总督负有职责采取措施。

### <a id="11.7.39"></a>11.7.39

马尔基安《法学阶梯》第三卷

神圣的皇帝兄弟在告示中提醒，不得惊扰已依正当方式埋葬、即已入土的尸体。即使尸体安放在小匣中，只要其意图是不再移往他处，也视为已经入土。但如有需要，应允许将该小匣移往更便利的地点，不应拒绝许可。

### <a id="11.7.40"></a>11.7.40

保罗《疑义》第三卷

如果某人将尸体安放于某处时，意图日后再将其移往别处，只是暂时寄放，而非意图在那里埋葬死者、仿佛为其安排永久安息之所，该地点仍是世俗场所。

### <a id="11.7.41"></a>11.7.41

卡利斯特拉图斯《法学阶梯》第二卷

如果死者被埋入的地点有数名所有人，埋葬外人时须经所有人同意；但其中任何一名所有人都可以将自己埋葬在那里，无须其他人同意，尤其是在没有其他可供埋葬的地点时。

### <a id="11.7.42"></a>11.7.42

弗洛伦蒂努斯《法学阶梯》第七卷

一般而言，纪念物是为后世保存记忆而建造的设施。如果尸体或遗骸埋入其中，它就成为墓地；如果没有埋入任何尸体或遗骸，它就是为纪念而建的纪念物，希腊人称之为 *kenotaphion*（衣冠冢）。

### <a id="11.7.43"></a>11.7.43

帕比尼安《疑义》第八卷

有些人虽然不能使场所成为宗教性场所，却可以有用地提起禁止埋葬死者的令状之诉。例如，土地所有人想将死者埋入一处用益权属于他人的土地：即使他埋葬死者，也不能使该地成为合法墓地；但如果他受到阻止，可以有用地提起涉及所有权的令状之诉。想要违背共有人意愿将死者埋入共有土地的共有人，也适用同一规则。考虑到公共利益——尸体不应无人埋葬——我们不会拘泥于严格的形式规则；在涉及宗教性质且有时难以确定的问题中，通常可以暂不适用该规则。因为，支持宗教的理由是最高的理由。

### <a id="11.7.44"></a>11.7.44

保罗《疑义》第三卷

如果尸体埋在不同地点，两处都不会成为宗教性场所，因为一次埋葬不能形成多个墓地。在我看来，尸体的主要部分埋葬之处才是宗教性场所，也就是埋有头颅之处；人的肖像由头颅构成，我们也由此被识别。获准将遗骸迁出后，原地点便不再具有宗教性。

### <a id="11.7.45"></a>11.7.45

梅基安《遗嘱信托》第八卷

葬礼费用始终应从遗产中扣除；当遗产没有清偿能力时，这项支出通常优先于所有债权。

### <a id="11.7.46"></a>11.7.46

斯凯沃拉《疑义》第二卷

<a id="11.7.46.pr."></a>

**序言（pr.）** 如果某人拥有数处地产，并将每一处地产的用益权分别遗赠，他的尸体可以埋入其中一处；由继承人选择埋葬地点，也可以出于恩惠作出安排。但应给予用益权人针对继承人的准诉讼，使其得以取回因继承人的选择而减少的用益权价值。

<a id="11.7.46.1"></a>

**1.** 如果妇女的继承人将死者埋入遗产土地，应按该地点的估价，向负有葬礼费用分担义务的丈夫请求给付。

<a id="11.7.46.2"></a>

**2.** 通说认为，如果遗赠给某人的衣物被用于葬礼，应给予该受遗赠人对继承人的准诉讼，并使其享有殡葬费用优先权。
