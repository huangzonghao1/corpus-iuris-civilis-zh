## 11.8.0　论安葬死者与建造墓冢（*De mortuo inferendo et sepulchro aedificando*）

### <a id="11.8.1"></a>11.8.1　乌尔比安《告示评注》第六十八卷

<a id="11.8.1.pr."></a>

**序言（pr.）** 裁判官说：“对于某人有权不顾你的反对而将死者运入的地点，无论何处，我禁止以暴力阻止其将死者运入该处并在那里安葬。”

<a id="11.8.1.1"></a>

**1.** 有权将死者运入安葬的人，不得被禁止这样做。所谓被禁止安葬，是指有人禁止其将死者运入某一地点，或者阻断其通行道路。

<a id="11.8.1.2"></a>

**2.** 土地所有权人可以援用这项关于安葬死者的禁令；该禁令也适用于普通土地（*locus purus*）。

<a id="11.8.1.3"></a>

**3.** 同样，如果我对某一土地享有通行地役权，而我希望将死者运入该土地，却有人禁止我通行，那么通说认为，我可以提起本项禁令，因为有人禁止我使用通行权，也就是禁止我将死者运入。若我享有的是其他地役权，也应当作相同判断。

<a id="11.8.1.4"></a>

**4.** 显然，这是一项禁止性禁令。

<a id="11.8.1.5"></a>

**5.** 裁判官说：“在某人有权不顾你的反对而将死者运入的地点，凡有人以暴力阻止其不带恶意地在该处建造墓冢，我禁止之。”

<a id="11.8.1.6"></a>

**6.** 设立这项禁令，是因为建造并装饰纪念碑关乎宗教利益。

<a id="11.8.1.7"></a>

**7.** 在某人有权使用的地点建造墓冢或纪念碑，任何人都不得加以禁止。

<a id="11.8.1.8"></a>

**8.** 禁止建造的人，还包括禁止运入建造所必需材料的人。因此，如果有人禁止为工程所需之人前来，本项禁令也适用；如果有人禁止固定施工机具〔译疑：*machinam alligare* 指将机具系固或架设于该处，具体器具不详〕，只要其禁止发生在负有地役权的地点，本项禁令同样适用。不过，如果你想在我的土地上放置机具，而我依法不允许你这样做，我便不受本项禁令约束。

<a id="11.8.1.9"></a>

**9.** 所谓建造，不仅指着手新建工程的人，也包括意图修缮的人。

<a id="11.8.1.10"></a>

**10.** 意图使墓冢坍塌的人，受本项禁令约束。

### <a id="11.8.2"></a>11.8.2　马尔凯卢斯《学说汇纂》第二十八卷

**正文** 王政时期的法律（*lex regia*）禁止将已经死亡的孕妇安葬，直至从她体内取出胎儿；违反此规定者，似乎连同孕妇一并断送了胎儿存活的希望。

### <a id="11.8.3"></a>11.8.3　庞波尼乌斯《评萨宾》第九卷

<a id="11.8.3.pr."></a>

**序言（pr.）** 如果有人在靠近你房屋之处建造墓冢，你可以提出新工程告知（*operis novi nuntiatio*）；但工程完成后，你将不享有任何诉权，只有在符合条件时可以提起因暴力或秘密施工之诉（*actio quod vi aut clam*）。

<a id="11.8.3.1"></a>

**1.** 如果死者被安葬于他人建筑物附近，且墓地与该建筑物之间的距离在法定限度以内，建筑物所有人此后不得禁止再将另一死者安葬于该处，或在那里建造纪念碑；但前提是，最初实施此事时，所有人对此知情。

### <a id="11.8.4"></a>11.8.4　乌尔比安《答复集》第二卷

**正文** 长期占有不能使本来依法不享有墓葬权的人取得该权利。

### <a id="11.8.5"></a>11.8.5　乌尔比安《意见集》第一卷

<a id="11.8.5.pr."></a>

**序言（pr.）** 如果人的遗骸已经安葬在一座据称尚未完工的墓冢中，并不妨碍将其完工。

<a id="11.8.5.1"></a>

**1.** 但是，如果该地点已经成为宗教场所（*locus religiosus*），祭司们应当查明：在不损及宗教属性的前提下，应当如何满足修复工程的愿望。
