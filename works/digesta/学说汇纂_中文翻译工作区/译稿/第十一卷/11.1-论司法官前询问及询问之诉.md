## 11.1.0　论司法官前的询问及询问之诉（*De interrogationibus in iure faciendis et interrogatoriis actionibus*）

### <a id="11.1.1"></a>11.1.1　卡利斯特拉图斯《告诫告示》第二卷

<a id="11.1.1.pr."></a>

**序言（pr.）** 每当有人对继承人提起诉讼，而原告不确定被告以何种份额继承时，都应在司法官前询问其继承份额；尤其是在针对被告提起对人之诉、原告请求特定数额的情形下，应当如此。因为原告若不知道被告继承死者遗产的份额，有时可能因请求过多而遭受损失。

<a id="11.1.1.1"></a>

**1.** 如今我们已不再使用询问之诉，因为无人被迫在审判前就自己的权利作出答复；因此，此类诉讼日益少见，现已废止。不过，在继承或其他诉讼中，当事人在法官面前明确作出的陈述，足以作为证明。

### <a id="11.1.2"></a>11.1.2　乌尔比安《评告示》第二十二卷

裁判官之所以颁布询问告示，是因为他知道，对继承人或遗产占有人提起诉讼的人，很难证明某人确为继承人或遗产占有人：

### <a id="11.1.3"></a>11.1.3　保罗《评告示》第十七卷

因为通常很难证明某人已经接受继承。

### <a id="11.1.4"></a>11.1.4　乌尔比安《评告示》第二十二卷

<a id="11.1.4.pr."></a>

**序言（pr.）** 裁判官想通过询问，使被诉者受其在诉讼中的答复约束：无论其承认还是说谎，都会使自己承担不利后果；同时，也可通过询问查明每人究竟以何种份额成为继承人。

<a id="11.1.4.1"></a>

**1.** 裁判官所说“在司法官前受询问并作出答复”，应理解为在罗马人民的行政长官、行省总督或其他法官面前作出的答复；因为所谓司法官前程序，是指为行使司法管辖或裁判职能而停留的场所，即使其在家中或旅途中履行该职能，也包括在内。

### <a id="11.1.5"></a>11.1.5　盖尤斯《评行省告示》第三卷

被询问者应当获得考虑时间，无论所问的是他是否为继承人、继承份额是多少，还是其是否对诺克萨之诉所针对之人行使权力。因为，如果其错误承认，便会遭受不利后果：

### <a id="11.1.6"></a>11.1.6　乌尔比安《评告示》第二十二卷

<a id="11.1.6.pr."></a>

**序言（pr.）** 既然死者有继承人符合其利益，生者也有权在其正当地考虑期间不被仓促迫答。

<a id="11.1.6.1"></a>

**1.** 有时，被询问是否为继承人之人无须回答，例如他正受到他人关于继承权的争议。神圣的哈德良皇帝曾作此规定，以免其否认自己是继承人而使自身遭受不利，或承认自己是继承人后，即使遗产被剥夺，仍受其答复拘束。

### <a id="11.1.7"></a>11.1.7　乌尔比安《评告示》第十八卷

如果某人在司法官前被问及致害的四足动物是否属于自己，并回答“属于”，就应承担责任。

### <a id="11.1.8"></a>11.1.8　保罗《评告示》第二十二卷

如果有人被问及造成损害的奴隶，并回答该奴隶属于自己，就应如同主人一样依《阿奎利亚法》承担责任；如果诉讼已针对作出该答复之人提起，真正的主人便因该项诉讼而免责。

### <a id="11.1.9"></a>11.1.9　乌尔比安《评告示》第二十二卷

<a id="11.1.9.pr."></a>

**序言（pr.）** 某人即使未经询问便回答说自己是继承人，也视同受询问后作出该答复。

<a id="11.1.9.1"></a>

**1.** 所谓受询问，不仅包括受裁判官询问，也包括受对方当事人询问。

<a id="11.1.9.2"></a>

**2.** 但是，如果被询问者是奴隶，询问无效；正如奴隶提出询问也不发生效力一样。

<a id="11.1.9.3"></a>

**3.** 不得强迫某人代他人回答自己是否为继承人；每个人都应在诉讼中、也就是在自己被诉时，就自身情况接受询问。

<a id="11.1.9.4"></a>

**4.** 塞尔苏斯在《学说汇纂》第五卷中写道：如果辩护人在诉讼中被问及其所辩护之人是否为继承人或继承份额多少，并作出虚假回答，辩护人本人应对对方承担责任，但不会因此对其所辩护之人产生任何不利影响。塞尔苏斯的意见无疑正确。还应考察，如果辩护人拒绝回答，是否就不算作辩护；依此应当说，他并未充分进行辩护。

<a id="11.1.9.5"></a>

**5.** 某人受询问后回答自己是继承人，却未说明继承份额，应认为其答复为继承全部遗产；除非问题明确问他是否继承一半，而他回答“我是继承人”，在这种情况下，我更倾向于认为他只是针对所问作出了答复。

<a id="11.1.9.6"></a>

**6.** 有人询问，是否可以强迫被询问者说明其继承是依据遗嘱，还是以本人名义取得遗产，抑或通过受其家父权支配之人或其所继承之人取得遗产。简言之，裁判官应依具体情形判断是否应令其说明继承所依据的法律关系；如果查明该事项具有重大意义，就应命其作出更完整的答复。这些规则不仅适用于民法继承人，也适用于裁判官法上的继受人。

<a id="11.1.9.7"></a>

**7.** 最后，尤利安写道，继承已返还给某人之时，该人也应在司法官前受询问，并回答继承是否已返还给自己。

<a id="11.1.9.8"></a>

**8.** 如果诉讼涉及特有产，不应要求父亲或主人回答其是否对家子或奴隶行使权力；因为此处只需查明特有产是否由被诉者占有。

### <a id="11.1.10"></a>11.1.10　保罗《评告示》第四十八卷

我们可以在司法官前询问某人是否拥有可能造成损害的房屋或土地，以及其享有的份额，以便在其否认土地属于自己且拒绝提供损害担保时，迫使其放弃该土地；或者，如果其决定抗辩，则将其按诈欺处理并迫使其交付土地。

### <a id="11.1.11"></a>11.1.11　乌尔比安《评告示》第二十二卷

<a id="11.1.11.pr."></a>

**序言（pr.）** 有时，被询问者也应当回答自己的年龄。

<a id="11.1.11.1"></a>

**1.** 如果某人并非继承人，却在受询问时回答自己是某一份额的继承人，就应按该份额的继承人起诉；因为其答复将对其自身发生拘束力。

<a id="11.1.11.2"></a>

**2.** 如果某人实际仅继承四分之一，或者根本不是继承人，却回答自己是全部遗产的继承人，就应按全部遗产起诉。

<a id="11.1.11.3"></a>

**3.** 如果某人实际继承一半，却声称自己只继承四分之一，就应承担说谎的处罚，即按全部遗产起诉；因为他不应谎称自己只继承较小份额。不过，有时确有正当理由使其相信自己仅继承较小份额。例如，他不知道自己的份额已经增加，或遗嘱指定的份额不确定。为什么此时仍要使其答复对自己不利呢？

<a id="11.1.11.4"></a>

**4.** 在裁判官面前保持沉默者，也处于应受全部责任追诉的地位，仿佛其已否认自己是继承人。完全不作答复之人属于藐视程序；其应受的藐视处罚，是按全部遗产承担责任，如同其作出否认，因为其似乎藐视了裁判官。

<a id="11.1.11.5"></a>

**5.** 裁判官所说“完全没有答复”，后来的法学家解释为：没有针对所问事项作出回答，也就是所谓 *pros epos*（逐项回答所问）。

<a id="11.1.11.6"></a>

**6.** 如果有人被问及是否继承全部遗产，却只回答自己是部分继承人；而其实际继承一半，则该答复不应使其受损。此意见合乎人情。

<a id="11.1.11.7"></a>

**7.** 对于受询问者而言，否认、沉默或含糊作答，以致询问者无法确定答案，并无区别。

<a id="11.1.11.8"></a>

**8.** 毫无疑问，应依具体情形救济作出答复之人。例如，某人被问及是否继承父亲遗产，回答“是”，后来出示遗嘱，发现他已被剥夺继承权；显然应当救济他。塞尔苏斯也这样写道，理由还在于后来出现的事项需要获得救济。比如，此后才出示此前被隐匿或藏起的遗嘱文书；为何要使其根据当时可见情形所作的答复对自己不利？如果某人回答自己是继承人，而后来认定遗嘱系伪造、违反亲属义务或无效，也应如此处理；他并非恶意作答，而是受遗嘱文书所误导。

<a id="11.1.11.9"></a>

**9.** 被询问后作出答复之人，仿佛是基于契约而承担责任；对方当事人可以因其答复起诉他。即使是裁判官进行询问，裁判官的权威本身也不产生该责任；使其承担责任的是其本人的答复或谎言。

<a id="11.1.11.10"></a>

**10.** 因正当错误而否认自己是继承人的，值得宽宥。

<a id="11.1.11.11"></a>

**11.** 如果某人作答时没有诈欺，但存在过失，也应认为只要其过失尚未接近诈欺，就应判其免责。

<a id="11.1.11.12"></a>

**12.** 塞尔苏斯写道，如果某人改变答复并未使原告遭受损害，就应允许其反悔；我认为此说极为正确，尤其是其后来得到更充分的信息，例如从文书或朋友来信中得知自己的法律权利后，便明白应当如何作答。

### <a id="11.1.12"></a>11.1.12　保罗《评告示》第十七卷

<a id="11.1.12.pr."></a>

**序言（pr.）** 如果家子已声明放弃父亲的遗产，却在司法官前受询问时回答自己是继承人，就应承担责任；因为作出该答复，似乎表明其以继承人身份处理了遗产。相反，如果已放弃继承的家子受询问时保持沉默，就应予以救济；因为裁判官不将放弃继承的家子视为继承人。

<a id="11.1.12.1"></a>

**1.** 对于因其本人答复而被起诉之人，也可以提出在诉讼中针对被告的抗辩，例如合意抗辩、既判事项抗辩及其他抗辩。

### <a id="11.1.13"></a>11.1.13　保罗《评普劳提乌斯》第二卷

<a id="11.1.13.pr."></a>

**序言（pr.）** 虚假答复之所以使答复者承担责任，是因为针对其所答复之人的诉讼也可能由此转而针对答复者；也就是说，如果对方是所有人，本可对其提起的诉讼，因我们自己的承认而转由我们承担。如果有人回答说，受其父权支配之人是自己的儿子，只有在该人的年龄确实可能使其成为自己的儿子时，答复者才承担责任，因为虚假答复应与自然关系相符。因此，以家父身份作答，不会仅因该答复而使答复者承担责任。

<a id="11.1.13.1"></a>

**1.** 如果某人回答说，一名家父身份者是自己的奴隶，就不应对其提起诺克萨之诉。即使一名自由人基于善意为我服役，也不能对我提起诺克萨之诉；如果已经提起诉讼，对实际实施侵害之人的直接诉权仍完整保留。

### <a id="11.1.14"></a>11.1.14　雅沃伦《卡西乌斯著作》第九卷

<a id="11.1.14.pr."></a>

**序言（pr.）** 如果以诺克萨之诉为由被诉之人，在诉讼进行期间被判定为自由人，被告应予免责。司法官前的询问不会产生任何作用，因为针对某人的诉讼义务可以转由他人承担：例如，某人承认他人的奴隶是自己的奴隶。但自由人并非针对他人提起诉讼的对象，因此，不能通过询问或承认将该责任转移给他人。于是，就自由人之事对承认者提起的诉讼便不成立。

<a id="11.1.14.1"></a>

**1.** 总之，只有当承认的事项在法律和自然关系上均可能成立时，承认才有效。

### <a id="11.1.15"></a>11.1.15　庞波尼乌斯《评萨宾》第十八卷

<a id="11.1.15.pr."></a>

**序言（pr.）** 在接受继承之前，如果我回答遗产中的奴隶属于我，就应承担责任，因为遗产被视为处于所有人地位。

<a id="11.1.15.1"></a>

**1.** 如果某人曾在司法官前承认某奴隶属于自己，而该奴隶后来死亡，答复者便不再承担责任；正如该奴隶原本确属其所有时，奴隶死亡后他也不再承担责任一样。

### <a id="11.1.16"></a>11.1.16　乌尔比安《评告示》第三十七卷

<a id="11.1.16.pr."></a>

**序言（pr.）** 如果某奴隶被敌人俘获，而有人在司法官前受询问时回答该奴隶处于自己的权力之下，尽管归还权可能使我们对此产生疑问，我仍认为不适用诺克萨之诉，因为该奴隶并不处于我们的控制之下。

<a id="11.1.16.1"></a>

**1.** 虽然通常认为，即使某人承认他人的奴隶是自己的奴隶，也应承担责任；但正确的意见是，只有能够取得该奴隶所有权的人才承担责任；如果其不能取得所有权，就不承担责任。

### <a id="11.1.17"></a>11.1.17　乌尔比安《评告示》第三十八卷

如果奴隶并非属于一人，而是属于数人，而他们全都或其中一些人谎称该奴隶不在其权力之下，或以诈欺方式使该奴隶脱离其权力，则每一人均应承担全部责任，正如其实际控制奴隶时所应承担的责任一样。但是，未以诈欺方式使奴隶脱离其权力、也未作出否认的人，不承担责任。

### <a id="11.1.18"></a>11.1.18　尤利安《致乌尔修斯·费罗克斯》第四卷

某人是二分之一份额的继承人；为替缺席的共同继承人辩护并免于提供担保，他回答说自己是唯一继承人，因而被判承担责任。原告无力清偿，遂询问：撤销此前判决后，是否应当对真正的继承人提起诉讼？普罗库鲁斯回答，可以在撤销原判后提起诉讼；此意见正确。

### <a id="11.1.19"></a>11.1.19　帕比尼安《疑问集》第八卷

如果家子在为父亲进行诉讼时受询问而保持沉默，则一切均应视同未曾询问。

### <a id="11.1.20"></a>11.1.20　保罗《疑问集》第二卷

<a id="11.1.20.pr."></a>

**序言（pr.）** 某人回答说他人的奴隶是自己的奴隶；如果他因此被提起诺克萨之诉，就使真正的主人免责。若有人承认自己杀死了他人所杀的奴隶，或回答自己是继承人，则不同：在这些情形中，实际实施行为的人或真正的继承人并不免责。这两种处理并不矛盾。前一情形中，责任是就奴隶本人而言由数人承担；如同共有奴隶的情形，对其中一人起诉，另一人也会获免责。但承认自己杀人或伤人者，是以本人名义承担责任；不能因为他人作出答复，就使实际实施侵害者免受惩罚。除非答复者以实施者或继承人的辩护人身份承担诉讼；在这种情况下，应给予事实抗辩以驳回原告，因为答复者可以通过无因管理之诉或委任之诉，向其所代理之人追偿自己已支付的金额。受继承人委托而回答自己是继承人，或为了替其辩护而作此答复的人，也应作同样处理。

<a id="11.1.20.1"></a>

**1.** 某人在司法官前被问及是否占有一块土地；我询问他是否必须回答，以及须说明自己占有该土地的份额。答复是：雅沃伦写道，土地占有人应被迫说明自己占有的份额；如果其声称只占有较小份额，原告就应被交付其未予辩护的另一部分土地的占有。

<a id="11.1.20.2"></a>

**2.** 如果我们请求提供损害担保，也应作同样处理。被询问者应说明该土地有多少份额属于自己，以便我们据此确定要式口约担保的范围。不提供反担保者所受的处罚，是原告取得占有；因此，查明其是否占有该土地具有意义。

### <a id="11.1.21"></a>11.1.21　乌尔比安《评告示》第二十二卷

凡法官认为衡平要求询问之处，无疑都应进行询问。

### <a id="11.1.22"></a>11.1.22　塞沃拉《学说汇纂》第四卷

皇帝代理官为追讨财政债务而进行询问时，一名既未取得遗产占有、也非继承人的儿子回答自己是继承人。有人问：他是否因此应对其他债权人承担询问之诉责任？答复是，未曾在司法官前询问过他的人，不得依据该答复对他提起诉讼。
