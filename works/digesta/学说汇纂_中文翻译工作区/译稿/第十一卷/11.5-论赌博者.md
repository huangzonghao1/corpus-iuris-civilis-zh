## 11.5.0　论赌博者（*De aleatoribus*）

### <a id="11.5.1"></a>11.5.1　乌尔比安《评告示》第二十三卷

<a id="11.5.1.pr."></a>

**序言（pr.）** 裁判官说：“如有人殴打被指称曾在其处举行掷骰赌博之人，或者使其遭受损害，或者在赌博期间有物因其故意行为而被取走，我将不提供诉讼。对于以赌博为目的而使用暴力的人，我将视具体情形予以惩处。”

<a id="11.5.1.1"></a>

**1.** 如果相互串通的赌徒彼此实施劫掠，不得拒绝给予强夺财物之诉。裁判官所禁止追诉的仅是开设赌局者，并非串通的赌徒，尽管他们看来也不值得获得救济。

<a id="11.5.1.2"></a>

**2.** 还须注意：开设赌局者即使在任何地点、任何时候遭到殴打或受有损害，也不得请求诉讼救济。但在其家中、赌博进行期间发生的盗窃，即使实施盗窃者并非赌徒，也不受处罚。可以确定，“家”应理解为居所与住所。

<a id="11.5.1.3"></a>

**3.** 至于裁判官称其不提供盗窃之诉，我们应考察这是否仅指刑罚性之诉，抑或也包括请求出示、提起所有物返还之诉或以 *condictio* 请求返还。庞波尼记载，所否认的仅是刑罚性之诉；我认为这一说法不正确，因为裁判官只是概括地说：“如有任何物被取走，我将不提供诉讼。”

<a id="11.5.1.4"></a>

**4.** 裁判官说：“对于以赌博为目的而使用暴力的人，我将视具体情形予以惩处。”这一款涉及对强迫他人赌博者的惩处：可以对其科处罚金，也可以将其押往公共采石场或公共监狱。

### <a id="11.5.2"></a>11.5.2　保罗《评告示》第十九卷

<a id="11.5.2.pr."></a>

**序言（pr.）** 有些人确实会强迫他人赌博：或从一开始便强迫，或在对方赌输后将其扣留。

<a id="11.5.2.1"></a>

**1.** 元老院决议禁止以金钱为赌注赌博，但下列竞赛除外：投掷长矛或标枪、赛跑、跳跃、摔跤或搏斗，凡以竞技技艺为目的者，均属例外。

### <a id="11.5.3"></a>11.5.3　马尔基安《规则集》第五卷

依《提提亚法》《普布利基亚法》和《科尔涅利亚法》，在上述竞赛中也可以订立赌约；但对其他不以竞技技艺为目的的活动，则不得如此。

### <a id="11.5.4"></a>11.5.4　保罗《评告示》第十九卷

<a id="11.5.4.pr."></a>

**序言（pr.）** 在宴席上，为供食用而摆出的东西，家内之人可以以之为赌注进行游戏。

<a id="11.5.4.1"></a>

**1.** 奴隶或家子赌输时，其家父或主人有权请求返还。又如奴隶赢得金钱，可以对主人提起特有产之诉，而非诺克萨之诉，因为该请求源于所从事的交易；但主人所须给付的，不得超过因该项事务而计入特有产的数额。

<a id="11.5.4.2"></a>

**2.** 依本告示，可以对父母与释奴保护人授予准用之诉，以请求返还赌博中输掉的财物。
