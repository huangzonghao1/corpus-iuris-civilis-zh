## 11.4.0　论逃亡者（*De fugitivis*）

### <a id="11.4.1"></a>11.4.1　乌尔比安《评告示》第一卷

<a id="11.4.1.pr."></a>

**序言（pr.）** 隐匿逃亡奴隶的人，就是窃贼。

<a id="11.4.1.1"></a>

**1.** 元老院决议规定，不得让逃亡奴隶进入庄园林地，也不得由土地占有人的管事或代理人加以庇护；违反者应受罚。但决议对过去的行为予以宽免：凡在二十日内将逃亡奴隶交还主人，或带到官员面前出示者，均可获宽免。此后，凡在规定期限内将自己在土地上发现的逃亡奴隶交给主人或官员，也依同一元老院决议免于处罚。

<a id="11.4.1.2"></a>

**2.** 该元老院决议还准许军人或平民进入元老、平民的地产搜查逃亡奴隶；《法比亚法》及莫德斯图斯任执政官时作出的元老院决议，也已就此作出规定。凡欲搜查逃亡奴隶之人，可获发致官员的公函；官员若收到公函后仍不协助搜查者，应罚款一百索利杜斯。阻止他人在自己地产内搜查的人，也适用同一处罚。神圣的马尔库斯皇帝与康茂德皇帝还颁布了一般性敕书，说明行省长官、其他官员及驻地军人均应协助主人搜查逃亡奴隶、将发现的奴隶交还主人；窝藏者如涉犯罪，也应受惩处。

<a id="11.4.1.3"></a>

**3.** 任何人抓获逃亡奴隶，都应将其带至公共机关。

<a id="11.4.1.4"></a>

**4.** 官员受到告诫，必须谨慎看守逃亡奴隶，以免其逃脱；此举确有正当理由。

<a id="11.4.1.5"></a>

**5.** “逃亡者”一词也包括流浪奴隶。拉贝奥在《评告示》第一卷中写道，逃亡女奴所生之人不包括在“逃亡者”这一称谓之内。

<a id="11.4.1.6"></a>

**6.** 所谓带至公共机关，是指将逃亡奴隶交给市政官员或公共机关的办事人员。

<a id="11.4.1.7"></a>

**7.** 为妥善看守逃亡奴隶，也可以将其捆缚。

<a id="11.4.1.8"></a>

**8.** 逃亡奴隶应一直被看守，直至将其带至夜巡长官或行省长官处。

<a id="11.4.1.8a"></a>

**8a.** 还应将逃亡奴隶的姓名、体貌标记及其所称主人报告给官员，以便更容易辨认和捕获；“标记”一词也包括疤痕。如果将这些信息写成文书，公开张贴或张贴在房屋中，也适用相同规则。

### <a id="11.4.2"></a>11.4.2　卡利斯特拉图斯《特别审理》第六卷

一般的逃亡奴隶应交还主人；但如果他们曾以自由人身份行事，通常会受到更严厉的惩处。

### <a id="11.4.3"></a>11.4.3　乌尔比安《论行省总督职务》第七卷

神圣的安敦尼·庇乌斯皇帝曾以敕答规定：想进入他人地产搜查逃亡奴隶的人，可以求助于行省长官，由其向搜查者发出公函；如情形确有必要，长官还可派遣随行公役，使其获准进入地产搜查。长官也应处罚不许搜查的人。神圣的马尔库斯皇帝在元老院宣读的演说中，也授权搜查逃亡奴隶之人进入皇帝、元老及平民的地产，并搜查可能藏匿奴隶之人的房间及踪迹。

### <a id="11.4.4"></a>11.4.4　保罗《箴言集》第一卷

港口守卫和驻地军人可以正当地将抓获的逃亡奴隶继续拘押。市政官员也可以正当地将抓获的逃亡奴隶移送至行省长官或行省总督的官署。

### <a id="11.4.5"></a>11.4.5　特里丰尼努斯《论辩集》第一卷

如果逃亡奴隶投身斗兽场，即使其冒着生命危险，也不能因此摆脱主人的权力。神圣的安敦尼·庇乌斯皇帝曾以敕答规定，无论其是在与野兽搏斗之前还是之后，都必须将其交还主人。因为有时奴隶侵吞钱财或实施其他更严重的犯罪，为逃避搜查或刑罚，宁愿投身斗兽场。因此，仍应将其交还主人。
