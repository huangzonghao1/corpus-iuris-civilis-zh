## <a id="2"></a><a id="9.2"></a>9.2　论阿奎利亚法

*Ad legem Aquiliam*

### <a id="9.2.1"></a>9.2.1　乌尔比安《评告示》第十八卷

<a id="9.2.1.pr."></a>

**序言（pr.）** 《阿奎利亚法》废止了此前所有涉及不法致损的法律，无论是《十二表法》中的规定，还是其他法律中的规定；这里没有必要逐一援引那些法律。

<a id="9.2.1.1"></a>

**1.** 《阿奎利亚法》是一项平民决议，因为平民保民官阿奎利乌斯曾将该法案提交平民表决。

### <a id="9.2.2"></a>9.2.2　盖尤斯《评行省告示》第七卷

<a id="9.2.2.pr."></a>

**序言（pr.）** 《阿奎利亚法》第一章规定：“凡不法杀死他人的男奴、女奴、四足牲畜或畜群中的牲畜者，应判令向所有人支付该物在该年中曾达到的最高价值之等额铜币。”（原文：*Ut qui servum servamve alienum alienamve quadrupedem vel pecudem iniuria occiderit, quanti id in eo anno plurimi fuit, tantum aes dare domino damnas esto*。）

<a id="9.2.2.1"></a>

**1.** 该法接着规定，对否认责任的人，应提起双倍之诉。

<a id="9.2.2.2"></a>

**2.** 由此可见，该法将列入牲畜类别并成群饲养的四足动物与我们的奴隶相提并论，例如绵羊、山羊、牛、马、骡和驴。猪是否包括在“牲畜”一词之内，尚有疑问；拉贝奥认为应当包括，确属正确。但狗不属于牲畜。更不用说野兽不在此列，例如熊、狮子和豹子。至于大象和骆驼，则兼具两种性质：它们既能像役畜一样劳作，天性又属野兽，因此应包括在第一章之内。

### <a id="9.2.3"></a>9.2.3　乌尔比安《评告示》第十八卷

如果男奴或女奴遭到不法杀害，《阿奎利亚法》即适用。法律特意加上“不法杀害”这一限定是有道理的；仅仅发生杀害并不足够，还必须是不法所为。

### <a id="9.2.4"></a>9.2.4　盖尤斯《评行省告示》第七卷

<a id="9.2.4.pr."></a>

**序言（pr.）** 因此，如果我杀死了一个正以强盗身份埋伏袭击我的你的奴隶，我就不负责任；因为自然理性允许人对抗危险而自卫。

<a id="9.2.4.1"></a>

**1.** 《十二表法》允许杀死夜间当场抓获的窃贼，但必须以呼喊将此事公之于众。对于白天当场抓获的窃贼，只有在他持械自卫时才允许杀死；即使如此，也同样必须呼喊示警。

### <a id="9.2.5"></a>9.2.5　乌尔比安《评告示》第十八卷

<a id="9.2.5.pr."></a>

**序言（pr.）** 如果有人杀死了任何持剑向自己攻击的人，也不视为不法杀人；如果有人因恐惧死亡而杀死窃贼，也无疑不受《阿奎利亚法》追究。但如果他本可将窃贼捕获，却宁愿杀死他，那么更应认为其行为不法；因此他还要依《科尔内利亚法》承担责任。

<a id="9.2.5.1"></a>

**1.** 此处的“不法”（*iniuria*）不能像“侵辱之诉”中的用法那样理解为某种侮辱，而应理解为行为不合法，即违反法律；换言之，是因过失而杀人。因此，有时《阿奎利亚法》之诉与侵辱之诉会同时发生，但须分别估价：一项针对损害，另一项针对侮辱。由此，此处的“不法”应理解为因过失造成的损害，即使行为人并无加害意图，也包括在内。

<a id="9.2.5.2"></a>

**2.** 因此，我们要问：如果精神失常者造成损害，是否可以提起《阿奎利亚法》之诉？佩加苏斯否认可以；他说，一个人既已失去理智，何来过失？这确是最正确的意见。因此，《阿奎利亚法》之诉不适用，正如四足动物造成损害或屋瓦坠落时该法不适用一样。婴儿造成损害，也应作同样解释。但如果是未达适婚年龄的未成年人造成损害，拉贝奥说，既然其须对盗窃承担责任，也应依《阿奎利亚法》承担责任。我认为这一意见正确，但以其已具备辨识不法行为的能力为限。

<a id="9.2.5.3"></a>

**3.** 如果教师在教学过程中伤害或杀死奴隶，是否应视为不法致损而依《阿奎利亚法》承担责任？尤利安写道，教师在教学时打伤学生致其失明，应依《阿奎利亚法》承担责任；那么，杀死学生更应作同样处理。尤利安举了这样一个例子：一名鞋匠教一名自由出身的家子制鞋，男孩没有把教师所示范的鞋样做好，鞋匠便用鞋楦打他的颈部，致使男孩眼部受伤。尤利安说，不能提起侵辱之诉，因为鞋匠并非出于侮辱目的打他，而是为了告诫和教导。至于能否提起雇佣之诉，他表示疑问，因为教师只获准给予轻微惩戒。不过，我毫不怀疑可以依《阿奎利亚法》起诉：

### <a id="9.2.6"></a>9.2.6　保罗《评告示》第二十二卷

因为教师过度严酷，应归责为过失。

### <a id="9.2.7"></a>9.2.7　乌尔比安《评告示》第十八卷

<a id="9.2.7.pr."></a>

**序言（pr.）** 他说，父亲可以通过该诉讼取得两项赔偿：其一，因儿子的眼睛受损而减少的劳务收入；其二，为治疗儿子所支出的费用。

<a id="9.2.7.1"></a>

**1.** “杀死”应作广义理解：无论用剑、棍棒或其他武器，还是用手（例如掐死对方）、用脚踢、用头撞，或以任何其他方式致人死亡，均属杀死。

<a id="9.2.7.2"></a>

**2.** 如果有人负重超过合理限度，放下重物时砸死奴隶，《阿奎利亚法》即适用，因为他本可以自行决定不负担如此重物。如果有人跌倒，身上的重物压死他人的奴隶，佩加苏斯说，只有在其负重超过合理限度，或在湿滑处行走时过于疏忽，才依《阿奎利亚法》承担责任。

<a id="9.2.7.3"></a>

**3.** 因此，如果某人因他人推搡而造成损害，普罗库鲁斯写道，推人的人不承担责任，因为不是他亲手杀死；被推的人也不承担责任，因为他并非不法造成损害。依此，应对推人者给予事实之诉。

<a id="9.2.7.4"></a>

**4.** 如果有人在摔跤、拳斗，或拳击手彼此练习时杀死对方，若是在公开比赛中杀人，《阿奎利亚法》不适用，因为造成损害显然是为了荣誉和勇武，而不是出于不法目的。不过，这一规则不适用于奴隶，因为通常参加比赛的是自由人；如果受伤的是家子，则适用该规则。显然，如果有人打伤正在退让的人，就适用《阿奎利亚法》；如果不是在比赛中杀死奴隶，也适用该法，除非此事是受主人指使而为；在这种情况下，《阿奎利亚法》不适用。

<a id="9.2.7.5"></a>

**5.** 如果有人轻轻打了一名患病的奴隶，而奴隶随后死亡，拉贝奥认为依《阿奎利亚法》追究是正确的，因为同一事物对不同的人可能有不同的致命性。

<a id="9.2.7.6"></a>

**6.** 塞尔苏斯说，亲手杀死与仅仅造成死亡原因，两者大不相同。仅仅造成死亡原因的人不依《阿奎利亚法》承担责任，而应受事实之诉追究。他举例说，给人毒药却称其为药物的人，只是造成死亡原因；把剑递给精神失常者的人也是如此。他们不依《阿奎利亚法》承担责任，而应受事实之诉追究。

<a id="9.2.7.7"></a>

**7.** 如果有人把人从桥上推下，塞尔苏斯说，无论此人因撞击当场死亡、随即溺水，还是因河水冲击而疲惫不支后死亡，推人者都依《阿奎利亚法》承担责任；这与有人用石头击中男孩的情形相同。

<a id="9.2.7.8"></a>

**8.** 普罗库鲁斯说，如果医生因缺乏专业能力而给奴隶动手术，可以提起雇佣之诉，也可以依《阿奎利亚法》起诉。

### <a id="9.2.8"></a>9.2.8　盖尤斯《评行省告示》第七卷

如果医生错误地使用药物，法律也作相同处理。即使医生手术时操作正确，但之后弃病人于不顾，也不能免除责任，而应视为有过失。如果赶骡人因缺乏经验未能控制骡群的冲势，以致骡子践踏他人，通常认为其应以过失承担责任。如果他因体弱而未能控制骡群冲势，也应如此处理。把体弱计为过失并非不公，因为任何人都不应从事自己已经知道或理应知道会因身体状况而给他人带来危险的工作。骑马者因缺乏经验或身体虚弱而无法控制所骑之马，也适用同一规则。

### <a id="9.2.9"></a>9.2.9　乌尔比安《评告示》第十八卷

<a id="9.2.9.pr."></a>

**序言（pr.）** 如果助产士给了药物，妇女因此死亡，拉贝奥作了区分：如果助产士亲手将药物置入妇人体内，就视为她杀死了妇女；如果她只是把药物交给妇女，让妇女自行使用，则应给予事实之诉。这一意见正确，因为助产士只是造成死亡原因，而非亲自杀人。

<a id="9.2.9.1"></a>

**1.** 如果有人以强迫或劝诱的方式，将药物灌入他人体内，无论经口服下还是经灌肠给药，或者用有害毒药涂抹他人，就应依《阿奎利亚法》承担责任，与亲自给妇人置入药物的助产士相同。

<a id="9.2.9.2"></a>

**2.** 涅拉提乌斯说，如果有人使他人饿死，应受事实之诉追究。

<a id="9.2.9.3"></a>

**3.** 如果你惊动我骑马的奴隶，使他驾马冲入河中并因此死亡，奥菲利乌斯写道，应给予事实之诉；这与我的奴隶被一人诱入埋伏、再由另一人杀死的情形相同。

<a id="9.2.9.4"></a>

**4.** 如果奴隶在众人投掷标枪的游戏中被杀，《阿奎利亚法》适用。但如果其他人在场地中投掷标枪时，奴隶不合时宜地经过该处，《阿奎利亚法》不适用，因为他本不应在此时穿过投掷标枪的场地。不过，若有人故意向他投掷，当然应依《阿奎利亚法》承担责任：

### <a id="9.2.10"></a>9.2.10　保罗《评告示》第二十二卷

因为有害的游戏同样构成过失。

### <a id="9.2.11"></a>9.2.11　乌尔比安《评告示》第十八卷

<a id="9.2.11.pr."></a>

**序言（pr.）** 梅拉还写道：有人打球时，一人用力击球，球飞进理发师的手里；理发师手中拿着剃刀，结果他照看的奴隶喉部被割断。对此，无论其中谁有过失，谁就依《阿奎利亚法》承担责任。普罗库鲁斯认为过失在理发师；如果他在惯常打球的地方或人流密集处理发，确有可归责之处。尽管也可以说，如果有人把自己交给一名在危险地点理发的理发师，那就只能怪他自己。

<a id="9.2.11.1"></a>

**1.** 如果一人控制住奴隶，另一人将其杀死，控制奴隶的人只是提供了死亡原因，应受事实之诉追究。

<a id="9.2.11.2"></a>

**2.** 如果数人殴打奴隶，我们要考察他们是否都应视为杀人者而承担责任。如果能够确定奴隶死于谁的击打，击打者就视为杀人者而承担责任；如果无法确定，尤利安说，所有人都应视为杀人者而承担责任。即使只起诉其中一人，其他人也不因此免责，因为依《阿奎利亚法》一人已经履行的责任不能免除他人的责任；该法具有惩罚性质。

<a id="9.2.11.3"></a>

**3.** 塞尔苏斯写道，如果一人造成致命伤，另一人随后使其断气，前者不作为杀人者承担责任，而作为伤人者承担责任，因为受害人是因另一处伤势死亡；后者则因杀人承担责任。马尔切鲁斯也持此见，这一意见更为可取。

<a id="9.2.11.4"></a>

**4.** 如果数人放下一根梁木并将人压死，古人同样认为所有人都依《阿奎利亚法》承担责任。

<a id="9.2.11.5"></a>

**5.** 对于激怒狗并使其咬人的人，即使他没有抓住狗，普罗库鲁斯答复说，也可以提起《阿奎利亚法》之诉。但尤利安说，只有抓住狗并使其咬人的人才依《阿奎利亚法》承担责任；如果没有抓住狗，就应提起事实之诉。

<a id="9.2.11.6"></a>

**6.** 《阿奎利亚法》之诉属于所有人，也就是主人。

<a id="9.2.11.7"></a>

**7.** 如果对一个我准备退货的奴隶造成了不法损害，尤利安说，《阿奎利亚法》之诉属于我；待我开始行使退货权时，就应把该诉权返还给你。

<a id="9.2.11.8"></a>

**8.** 如果奴隶基于善意为某人服役，是否由该人享有《阿奎利亚法》之诉？更适当的做法是给予事实之诉。

<a id="9.2.11.9"></a>

**9.** 尤利安说，借用衣物的人如果把衣物撕破，不能依《阿奎利亚法》起诉；该诉权属于所有人。

<a id="9.2.11.10"></a>

**10.** 尤利安讨论了用益权人或使用权人是否享有《阿奎利亚法》之诉；我认为，更妥当的是基于此事给予有益诉讼。

### <a id="9.2.12"></a>9.2.12　保罗《评萨宾》第十卷

如果所有权人伤害或杀死一名我享有用益权的奴隶，就应仿照《阿奎利亚法》之诉，给予我一项针对他的诉讼，其数额依我的用益权份额计算；即使在估价中还应计入我尚未享有用益权的那段年度期间，也应如此。

### <a id="9.2.13"></a>9.2.13　乌尔比安《评告示》第十八卷

<a id="9.2.13.pr."></a>

**序言（pr.）** 自由人以自己名义享有《阿奎利亚法》上的有益诉权，但不享有直接诉权，因为无人被视为自己身体各部分的所有人。对于逃奴，主人则享有诉权。

<a id="9.2.13.1"></a>

**1.** 尤利安写道，如果自由人基于善意为我服役，该自由人对我依《阿奎利亚法》承担责任。

<a id="9.2.13.2"></a>

**2.** 如果遗产中的奴隶被杀，由谁提起《阿奎利亚法》之诉？此时该奴隶尚无所有人。塞尔苏斯说，法律意在使所有人能够获得损害赔偿；因此，遗产本身应视为所有人。由此，在继承人接受遗产后，他可以提起诉讼。

<a id="9.2.13.3"></a>

**3.** 如果遗赠的奴隶是在继承人接受遗产后被杀，受遗赠人享有《阿奎利亚法》之诉，但以其在奴隶死亡前已接受遗赠为限。若其拒绝遗赠，尤利安说，应认为诉权属于继承人。

### <a id="9.2.14"></a>9.2.14　保罗《评告示》第二十二卷

不过，如果继承人本人杀死该奴隶，已经指出，应给予受遗赠人针对继承人的诉权。

### <a id="9.2.15"></a>9.2.15　乌尔比安《评告示》第十八卷

<a id="9.2.15.pr."></a>

**序言（pr.）** 由此可以进一步说：如果遗赠的奴隶在继承人接受遗产前被杀，通过继承取得的《阿奎利亚法》诉权仍留在继承人手中。如果奴隶在接受遗产前只是受伤，诉权虽仍属于遗产，但继承人应将其让与受遗赠人。

<a id="9.2.15.1"></a>

**1.** 尤利安说，如果奴隶受到致命伤，后来却因房屋倒塌、海难或其他撞击而提前死亡，就不能作为被杀害而起诉，只能作为被伤害而起诉；但如果奴隶因伤而死时已经获释或被转让，则可以作为被杀害而起诉。上述区别如此复杂，是因为只有在奴隶死亡后，才显明他在你伤害他时确由你杀死；而在前一种情形中，后来的事故使人无法确认他是否因此被杀。不过，如果你命令一名受致命伤的奴隶获得自由并成为继承人，而他随后死亡，他的继承人不能依《阿奎利亚法》起诉：

### <a id="9.2.16"></a>9.2.16　马尔恰努斯《规则集》第四卷

因为事情已经进入一种无法由此开始的情形。

### <a id="9.2.17"></a>9.2.17　乌尔比安《评告示》第十八卷

如果所有人杀死自己的奴隶，他应以事实之诉对善意占有人或质权受领人承担责任。

### <a id="9.2.18"></a>9.2.18　保罗《评萨宾》第十卷

如果质权受领人杀死或伤害了作为质物的奴隶，可以依《阿奎利亚法》之诉或质押之诉对其起诉；但原告必须择一行使，不得两诉并用。

### <a id="9.2.19"></a>9.2.19　乌尔比安《评告示》第十八卷

塞尔苏斯说，如果有人杀死共有奴隶，应依《阿奎利亚法》承担责任；伤害共有奴隶时也同样如此：

### <a id="9.2.20"></a>9.2.20　乌尔比安《评萨宾》第四十二卷

当然，按提起诉讼者作为所有人的份额计算。

### <a id="9.2.21"></a>9.2.21　乌尔比安《评告示》第十八卷

<a id="9.2.21.pr."></a>

**序言（pr.）** 法律规定：“该人在该年中曾达到的最高价值”（*Quanti is homo in eo anno plurimi fuisset*）。这一条款规定了所造成损害的估价方式。

<a id="9.2.21.1"></a>

**1.** 该年从被害人死亡之日起向前倒推计算。如果被害人受到致命伤，却在很长时间之后才死亡，依尤利安的意见，应从受伤之日起计算一年；尽管塞尔苏斯对此持相反意见。

<a id="9.2.21.2"></a>

**2.** 但我们究竟只估算被害人的身体在死亡时的价值，还是应估算被害人未被杀死对我们具有多少利益？我们采用的法律是，应按利害关系进行估价。

### <a id="9.2.22"></a>9.2.22　保罗《评告示》第二十二卷

<a id="9.2.22.pr."></a>

**序言（pr.）** 因此，如果你杀死了一个我曾承诺附违约罚则交付的奴隶，违约利益也应计入本诉的裁判。

<a id="9.2.22.1"></a>

**1.** 如果有人杀死一组彼此关联的人员或动物中的一个，例如喜剧演员团、合唱乐师团、双胞胎、四马战车中的一匹马，或一对骡子中的一头，也应将这种联系纳入估价。因为不仅要估算被杀死之物本身的价值，还应考虑其他物品因此贬值的程度。

### <a id="9.2.23"></a>9.2.23　乌尔比安《评告示》第十八卷

<a id="9.2.23.pr."></a>

**序言（pr.）** 因此，涅拉提乌斯写道，如果被指定为继承人的奴隶遭到杀害，遗产价值也应计入估价。

<a id="9.2.23.1"></a>

**1.** 尤利安说，如果被命令获释并成为继承人的奴隶遭到杀害，代位继承人或法定继承人都不能依据《阿奎利亚法》取得遗产价值，因为奴隶本人不可能享有这项诉权。这一意见正确。因此，原则上只估算奴隶的价格，因为看起来代位继承人所关心的只有这一点。但我认为，连奴隶的价格也不应估算，因为如果他成为继承人，他就已经是自由人。

<a id="9.2.23.2"></a>

**2.** 同一尤利安写道，如果我被附条件指定为继承人，条件是“若我释放斯提基乌斯”，而斯提基乌斯在立遗嘱人死后被杀，我在估价时也应取得遗产的价值；因为正是该奴隶被杀使条件不能成就。但如果他在立遗嘱人生前被杀，就不应估算遗产价值，因为应当向前追溯，考察他在该年中曾达到的最高价值。

<a id="9.2.23.3"></a>

**3.** 同一尤利安写道，被杀者的估价应追溯至其在该年中价值最高的时点。因此，即使一名身价很高的画师先被切断拇指，随后在该拇指被切断之日起一年内又被杀害，也可以依《阿奎利亚法》起诉；其价值应按他尚未因失去拇指而丧失技艺时的身价计算。

<a id="9.2.23.4"></a>

**4.** 如果一名奴隶曾在我的账目中实施重大欺诈，而我原本打算审讯他以查明参与欺诈的人，后来他被杀，拉贝奥认为，最正确的做法是按我查明该奴隶所实施欺诈的利益估价，而不是按该奴隶本身的价值估价。

<a id="9.2.23.5"></a>

**5.** 如果一名原本品行良好的奴隶在一年内改变品行后被杀，应按其改变品行之前的价值估价。

<a id="9.2.23.6"></a>

**6.** 总之，在奴隶被杀的那一年中，凡能使其价值提高的利益，都应计入估价。

<a id="9.2.23.7"></a>

**7.** 如果被杀的是尚未满一岁的婴儿，更可取的意见是，本诉足以救济；估价应追溯至该婴儿在一年期间实际存活的时点。

<a id="9.2.23.8"></a>

**8.** 已确认该诉权也给予继承人及其他继受人；但由于它具有惩罚性质，不得向继承人或其他继受人提起，除非该继承人因损害而获利。

<a id="9.2.23.9"></a>

**9.** 如果奴隶是被故意杀害，众所周知，主人也可以依《科尔内利亚法》起诉；即使他已经依《阿奎利亚法》起诉，也不应因此对《科尔内利亚法》之诉产生先决效力。

<a id="9.2.23.10"></a>

**10.** 对自认责任者提起本诉，判赔单倍；对否认责任者提起本诉，判赔双倍。

<a id="9.2.23.11"></a>

**11.** 如果某人错误地自认杀死了一个仍然活着的人，后来又准备证明此人尚在人世，尤利安写道，即使他已承认自己杀人，《阿奎利亚法》之诉仍不适用。自认的唯一作用，是免除原告证明被告实施了杀害的责任；但无论如何，必须确实有人被杀。

### <a id="9.2.24"></a>9.2.24　保罗《评告示》第二十二卷

对于伤人案件，这一点更加清楚：如果某人承认自己伤了人，而此人实际上并未受伤，我们要按何种伤势估价？或者应当以何时为估价基准？

### <a id="9.2.25"></a>9.2.25　乌尔比安《评告示》第十八卷

<a id="9.2.25.pr."></a>

**序言（pr.）** 因此，如果某人并未被杀，却已经死亡，那么更可取的意见是，即使被告自认，也不应令其对死者承担责任。

<a id="9.2.25.1"></a>

**1.** 如果诉讼代理人、监护人、保佐人或其他人承认自己伤害了不在场的人，应给予针对其本人的有益自认之诉。

<a id="9.2.25.2"></a>

**2.** 应当注意，在这种针对自认者提起的诉讼中，法官的职责不是裁判责任，而是估定损害赔偿；因为对于自认者，已经没有需要裁判的事项。

### <a id="9.2.26"></a>9.2.26　保罗《评告示》第二十二卷

设想被告承认自己杀了人，并准备支付估定的赔偿，而对方却把诉讼标的估得很高。

### <a id="9.2.27"></a>9.2.27　乌尔比安《评告示》第十八卷

<a id="9.2.27.pr."></a>

**序言（pr.）** 如果奴隶偷走他人的奴隶并将其杀死，尤利安和塞尔苏斯都写道，可以同时提起盗窃之诉和不法致损之诉。

<a id="9.2.27.1"></a>

**1.** 如果一名共有奴隶（也就是我和你共有的奴隶）杀死了我的奴隶，只要他是奉你的意愿行事，就可以依《阿奎利亚法》起诉你；乌尔塞尤斯说，普罗库鲁斯也持此意见。如果不是奉你的意愿行事，非难之诉就不适用；否则，该奴隶就会处于只能为你一人服役的地位。我认为这一解释正确。

<a id="9.2.27.2"></a>

**2.** 同样，如果由提图斯的奴隶杀死一名我和你共有的奴隶，塞尔苏斯写道，任何一名共有人提起诉讼，都应按其份额取得判定的赔偿；或者应将致害奴隶整体交付给原告作为非难赔偿，因为这一事项不能分割。

<a id="9.2.27.3"></a>

**3.** 奴隶杀人，主人应以该奴隶的名义承担责任；但奴隶基于善意为其服役的人不承担责任。至于逃亡中的奴隶，其主人是否应以该奴隶的名义依《阿奎利亚法》承担责任，尚有疑问。尤利安认为应承担责任；这确是最正确的意见，马尔切鲁斯也表示赞同。

<a id="9.2.27.4"></a>

**4.** 该法的第二章已经废止不用。

<a id="9.2.27.5"></a>

**5.** 同一《阿奎利亚法》第三章规定：“除人和被杀的牲畜外，任何人若不法烧毁、打碎或毁损他人的其他物品，应按该物在最近三十日内的价值，判令向所有人支付等额铜币。”（原文：*Ceterarum rerum praeter hominem et pecudem occisos si quis alteri damnum faxit, quod usserit fregerit ruperit iniuria, quanti ea res erit in diebus triginta proximis, tantum aes domino dare damnas esto*。）

<a id="9.2.27.6"></a>

**6.** 因此，如果有人没有杀死人或牲畜，而只是烧毁、打碎或毁损其物，毫无疑问应依该法的上述文字起诉。比如，你把火把伸向我的奴隶并将他烧伤，就应对我承担责任。

<a id="9.2.27.7"></a>

**7.** 同样，如果你烧毁我的果树林或庄园，我可以提起《阿奎利亚法》之诉。

<a id="9.2.27.8"></a>

**8.** 如果有人想烧毁我的公寓楼，火势也蔓延到邻人的公寓楼，他还应依《阿奎利亚法》对邻人承担责任；对于邻人房客被烧毁的财物，也同样应承担责任。

<a id="9.2.27.9"></a>

**9.** 如果佃户的炉工奴隶在炉边睡着，庄园因此被烧毁，涅拉提乌斯写道：如果佃户在挑选劳役人员时疏忽，就应依租赁之诉承担赔偿责任。反之，如果一人把柴火添进炉中，另一人疏忽看守，应由添火者承担责任吗？看守者并未亲手做任何事，正确添火的人也没有过错。那么应如何处理？我认为，应分别给予事实之诉，追究在炉边睡着的人和疏忽看守的人。没有人会说，睡着的人只是遭遇了人所难免的自然状况；他本应熄灭炉火，或采取措施围护炉火，以免火势蔓延。

<a id="9.2.27.10"></a>

**10.** 如果你在共用墙旁设有炉窑，是否应以不法致损承担责任？普罗库鲁斯说，不能起诉，因为对设有炉火的人也不能起诉。因此，我认为，如果共用墙已经被烧坏，较为公平的做法是给予事实之诉。如果你尚未对我造成损害，只是如此用火，以致我担心你会损害我，我认为要求你提供未来损害担保就足够了。

<a id="9.2.27.11"></a>

**11.** 普罗库鲁斯说，如果佃户的奴隶烧毁庄园，佃户应依租赁之诉或《阿奎利亚法》承担责任，并可以将奴隶交付作为非难赔偿；如果其中一项诉讼已经作出判决，就不得再提起另一项。不过，只有在佃户本人没有过失时才如此；如果他雇用了有害的奴隶，他就应因选用这类奴隶而承担不法致损责任。他还写道，对公寓楼房客的情形也应遵循同一规则。这一意见是有道理的。

<a id="9.2.27.12"></a>

**12.** 如果我的蜜蜂飞到你的蜂群中，而你把它们烧死，塞尔苏斯说，可以提起《阿奎利亚法》之诉。

<a id="9.2.27.13"></a>

**13.** 法律使用“撕裂”（*ruperit*）一词。几乎所有古代法学家都把它理解为“毁损”（*corruperit*）。

<a id="9.2.27.14"></a>

**14.** 因此，塞尔苏斯提出：如果你把黑麦草或燕麦撒在他人的庄稼里，意在污染庄稼，土地所有人不仅可以提起“以暴力或秘密方式侵害土地”的诉讼；如果土地已出租，佃户也可以起诉，而且还可以提起事实之诉。如果佃户已耕种该地，他就应作出担保，保证不再有人起诉，以免土地所有人继续受扰。因为有两种不同的损害：一种是直接毁损或改变物本身，以致适用《阿奎利亚法》；另一种是没有改变物本身，只是附加了其他物品，而分离这些物品会造成麻烦。

<a id="9.2.27.15"></a>

**15.** 塞尔苏斯说，如果有人污染葡萄酒、将其泼洒、使其变成醋，或以其他方式使其变质，可以依《阿奎利亚法》起诉；因为酒被泼洒或变成醋，也包括在“毁损”一词的含义之内。

<a id="9.2.27.16"></a>

**16.** 他并不否认，“毁损”一词也包括打碎和烧毁；这并非立法上的新做法：法律先逐项列举若干行为，再附加一个概括性用语，以涵盖这些特定情形。这一意见正确。

<a id="9.2.27.17"></a>

**17.** 对“撕裂”应作如下理解：无论是用棍棒、皮鞭或拳头殴打，还是用武器或其他物品伤害他人身体，或使其肿胀，都属于撕裂，但以造成不法损害为限。反之，如果奴隶的价值没有因此降低，也没有变得更差，《阿奎利亚法》就不适用；此时只能提起侵辱之诉。因为《阿奎利亚法》追究的是造成损害的撕裂行为。因此，即使奴隶的价格没有降低，但为恢复其健康而支出了费用，我认为这些费用构成损害；所以也可以依《阿奎利亚法》起诉。

<a id="9.2.27.18"></a>

**18.** 如果有人撕破或弄脏衣物，应依《阿奎利亚法》承担责任，视同其毁损了衣物。

<a id="9.2.27.19"></a>

**19.** 如果有人把我的黍米或谷物倒进河里，依《阿奎利亚法》起诉就足够了。

<a id="9.2.27.20"></a>

**20.** 同样，如果有人把沙子或其他东西混进我的谷物中，导致难以分离，就可以视同毁损而起诉。

<a id="9.2.27.21"></a>

**21.** 如果有人从我手中打落钱币，萨宾认为，若钱币就此灭失、未落入任何人手中，例如掉进河里、海里或下水道里，可以提起不法致损之诉；如果钱币落入他人手中，则应依其协助或策划盗窃提起诉讼，古人也赞同这一意见。他还说，也可以给予事实之诉。

<a id="9.2.27.22"></a>

**22.** 如果你用拳头打了妇女，或击打母马，致使其流产，布鲁图斯说，应依《阿奎利亚法》承担责任，视同造成身体撕裂。

<a id="9.2.27.23"></a>

**23.** 如果有人给骡子加负重超过合理限度，并因此使其身体某一部位受伤，也适用《阿奎利亚法》。

<a id="9.2.27.24"></a>

**24.** 维维安努斯写道，如果有人在运载待售货物的船上凿孔，可以依《阿奎利亚法》起诉，视同其毁损了船只。

<a id="9.2.27.25"></a>

**25.** 如果有人摘取尚未成熟的橄榄、割下未成熟的庄稼，或采摘未成熟的葡萄，就依《阿奎利亚法》承担责任；如果果实已经成熟，该法就不适用，因为这不构成不法损害，毕竟采收此类果实所需的费用也因此替你省下了。不过，如果有人在果实已经采收后将其截走，就应对盗窃承担责任。奥克塔维努斯补充说，葡萄也如此；但他说，如果有人把葡萄扔在地上，使其散落，就另当别论。

<a id="9.2.27.26"></a>

**26.** 他对可采伐林木也作相同论述：如果林木尚未成熟，行为人依《阿奎利亚法》承担责任；如果林木已经成熟而行为人将其截走，则应对盗窃以及盗伐树木承担责任。

<a id="9.2.27.27"></a>

**27.** 如果你收割成熟的柳树林，并且没有损伤树根，《阿奎利亚法》就不适用。

<a id="9.2.27.28"></a>

**28.** 维维安努斯写道，如果有人阉割男孩，使其身价反而提高，《阿奎利亚法》不适用；但可以提起侵辱之诉，或依市政官告示起诉，也可以请求四倍赔偿。

<a id="9.2.27.29"></a>

**29.** 如果你交付一只镂刻水晶杯供人加工，若工匠因缺乏经验将其打碎，应以不法致损承担责任；但如果他并非因技术不熟练而打碎杯子，而是杯子本身有缺陷裂纹，就可能获得免责。因此，交付这类材料时，工匠通常会约定自己不承担加工风险；有此约定，就排除了雇佣之诉和《阿奎利亚法》之诉。

<a id="9.2.27.30"></a>

**30.** 如果丈夫把拆下的珍珠交给妻子使用，而妻子未经丈夫同意或不知情，便在珍珠上穿孔，以便将它们穿在线上佩戴，那么无论夫妻后来离婚还是仍处于婚姻关系中，妻子都依《阿奎利亚法》承担责任。

<a id="9.2.27.31"></a>

**31.** 如果有人打破或撬坏我房屋的门，或者拆毁整幢房屋，就依《阿奎利亚法》承担责任。

<a id="9.2.27.32"></a>

**32.** 如果有人毁坏我的引水渠，即使被毁坏的是我所有的水泥构件，由于引水渠经过的土地并非我的土地，更可取的意见是应给予有益诉讼。

<a id="9.2.27.33"></a>

**33.** 如果石头从运货车上掉落并打碎或毁损了某物，较为可取的意见是：如果赶车人没有妥善装载石头，致使石头掉落，就应依《阿奎利亚法》承担责任。

<a id="9.2.27.34"></a>

**34.** 如果有人雇用一名奴隶驾驭骡子，并把骡子交给他照管；该奴隶用皮带把骡子拴在自己的拇指上，骡子突然挣脱，扯断奴隶的拇指并把他甩倒，梅拉写道：如果雇主雇用了不熟练的人来代替熟练的人，就可以对该奴隶的主人提起雇佣之诉，要求赔偿骡子受损或残废。但如果骡子是被击打或惊吓所扰乱，那么骡子的主人和奴隶的主人都可以依《阿奎利亚法》起诉惊扰骡子的人。我认为，即使在可以提起雇佣之诉的情形中，也可以提起《阿奎利亚法》之诉。

<a id="9.2.27.35"></a>

**35.** 同样，如果你雇用抹灰工修理一只装满葡萄酒的大缸，而他把缸凿穿，致使葡萄酒流出，拉贝奥写道，应提起事实之诉。

### <a id="9.2.28"></a>9.2.28　保罗《评萨宾》第十卷

<a id="9.2.28.pr."></a>

**序言（pr.）** 捕熊或捕鹿的人挖掘陷阱，如果他们把陷阱挖在道路上，有东西掉进去并因此受损，就依《阿奎利亚法》承担责任；如果他们把陷阱挖在通常设置陷阱的其他地点，就不承担责任。

<a id="9.2.28.1"></a>

**1.** 不过，是否给予这一诉讼，要视具体情形而定：如果没有人提醒他，他也不知道或无法预见危险，就不应承担责任。还有许多类似情形；只要请求人能够避开危险，其请求就会被驳回。

### <a id="9.2.29"></a>9.2.29　乌尔比安《评告示》第十八卷

<a id="9.2.29.pr."></a>

**序言（pr.）** 这就如同你在自己无权设置陷阱的地方放置套索，而邻人的牲畜落入其中。

<a id="9.2.29.1"></a>

**1.** 普罗库鲁斯写道，如果你砍掉我伸出并悬在你房屋上方、但我无权设置的挑檐，我可以对你提起不法致损之诉。因为你本应先起诉我，确认我无权设置挑檐；而你砍掉我的梁木，使我遭受损害，也并不公平。塞维鲁皇帝的敕复则规定了不同规则：如果水渠在没有地役权的情况下穿过某人的房屋，该人可以依法自行截断水渠。这是正确的，因为前者在自己的土地上设置了挑檐，后者却把水渠设在他人的土地上。

<a id="9.2.29.2"></a>

**2.** 如果你的船撞上我的小船并造成损害，曾有人询问我可以提起何种诉讼。普罗库鲁斯说，如果船员本可以避免事故，而事故又因他们的过失发生，就应依《阿奎利亚法》起诉船员。因为无论是把船驶向对方，还是用 *serraculum*（底本原词，所指器具未详）牵引船只，或以你自己的手直接造成损害，结果都一样：都是由你造成了损害。但如果事故是绳索断裂所致，或船只因无人操控而漂撞过来，就不能起诉船主。

<a id="9.2.29.3"></a>

**3.** 拉贝奥还写道，如果船只被风力吹动，撞上另一艘船的锚索，而船员为了脱困，除砍断锚索外别无他法，就不应给予诉讼。拉贝奥和普罗库鲁斯对渔网也作相同判断：船只撞入渔网时，如果船员有过失，就应依《阿奎利亚法》起诉。但因渔网受损而起诉时，不应把未能捕获的鱼计入估价，因为无法确定那些鱼原本是否能够捕获。对于猎人和捕鸟人，也应作同样解释。

<a id="9.2.29.4"></a>

**4.** 如果一艘船撞沉迎面驶来的另一艘船，阿尔芬努斯说，可以对舵手（*gubernator*）或领船者（*ductor*）提起不法致损之诉；但如果船只遭受的外力强大到无法控制，就不应给予针对船主的诉讼。反之，如果事故由船员的过失造成，我认为依《阿奎利亚法》起诉就足够了。

<a id="9.2.29.5"></a>

**5.** 如果有人割断系住船只的绳索，致使船只沉没，应给予事实之诉。

<a id="9.2.29.6"></a>

**6.** 依本章提起的诉讼，可以追究对所有非牲畜类动物造成的伤害，例如狗；野猪、狮子和其他野兽，以及鸟类，也同样如此。

<a id="9.2.29.7"></a>

**7.** 市政官员如果不法造成损害，也可以依《阿奎利亚法》承担责任。例如，有人扣押牲畜作为质物，却不准你给牲畜送食物，致使牲畜饿死，就应给予事实之诉。同样，如果市政官员以为自己依据法律扣押质物，实际上却无权这样做，并将已经磨损或毁坏的物品交还，据说《阿奎利亚法》适用；即使他确实依据法律扣押了质物，也应作同样解释。不过，如果市政官员在面对抵抗时采取了过度暴力，就不依《阿奎利亚法》承担责任；例如，他扣押一名奴隶作质物，而该奴隶随后自缢，就不产生任何诉讼。

<a id="9.2.29.8"></a>

**8.** 法律中的“该物在最近三十日内的价值”（*quanti in triginta diebus proximis fuit*），虽然没有“最高”（*plurimi*）一词，但众所周知，仍应按最高价值理解。

### <a id="9.2.30"></a>9.2.30　保罗《评告示》第二十二卷

<a id="9.2.30.pr."></a>

**序言（pr.）** 杀死当场抓获的他人奴隶通奸者，不依本法承担责任。

<a id="9.2.30.1"></a>

**1.** 作为质物交付的奴隶被杀，债务人享有诉权。是否也应给予债权人有益诉权，尚有疑问，因为债权人可能因债务人无偿债能力或债务人因时效而丧失诉权遭受损失。但若允许主人和债权人同时向行为人追责，似乎不公。除非认为债务人在此并未受不法侵害，因为赔偿可以抵偿债务，而且超过债务额的部分，他还可以从债权人处取得；或者从一开始就应只对超过债务额的部分给予债务人诉权。因此，在因债务人无偿债能力或其诉权因时效消灭而应给予债权人诉权的情形，债权人依《阿奎利亚法》只能在债务额范围内起诉，以使所得利益归于债务人；债务人本人则可以就超过债务额的部分提起《阿奎利亚法》之诉。

<a id="9.2.30.2"></a>

**2.** 如果有人消费了他人的葡萄酒或谷物，就不视为不法造成损害；因此，应给予有益诉讼。

<a id="9.2.30.3"></a>

**3.** 本章所产生的诉讼同样惩罚故意和过失。因此，如果有人为了烧除自家田里的麦茬或荆棘而点火，而火势蔓延开来，损害了他人的庄稼或葡萄园，就要考察损害是否因其缺乏经验或疏忽而发生。如果他选择在有风的日子点火，就应承担过失责任（因为提供发生损害的机会，也视为造成损害）；未能留意火势不再继续蔓延的人，也犯有同样过失。但如果他已采取一切应有措施，或火势因突发的强风而蔓延，就没有过失。

<a id="9.2.30.4"></a>

**4.** 如果奴隶所受的伤并非致命，但后来因疏忽而死亡，应提起伤害之诉，而非杀害之诉。

### <a id="9.2.31"></a>9.2.31　保罗《评萨宾》第十卷

如果修枝工从树上砍下一根树枝，或机械工人操作机器时杀死路人，只有在树枝或物件落入公共道路、而行为人又未出声警告以便他人避开时，才承担责任。但穆基乌斯还说，如果同样的事情发生在私人土地上，也可以因过失起诉。所谓过失，是指谨慎之人本可预见危险，却未采取预防措施；或者已经发出警告，但警告时危险已无法避免。依此理由，事情发生在公共道路还是私人道路并不十分重要，因为人们通常也会经过私人土地。如果那里根本没有道路，行为人只对故意承担责任：他不得向自己看见正在经过的人投掷物件。由于他无法预见是否有人会经过那里，就不应要求其承担过失责任。

### <a id="9.2.32"></a>9.2.32　盖尤斯《评行省告示》第七卷

<a id="9.2.32.pr."></a>

**序言（pr.）** 有人提出疑问：总督在处理家奴实施的盗窃时所遵循的规则——不逐一对每个奴隶提起惩罚之诉，只要求支付一名自由人实施该盗窃时应支付的数额——是否也应适用于不法致损之诉。更可取的意见是，应遵循同一规则，而且理由充分：盗窃之诉采取该规则，是为了避免主人因一次犯罪就失去整个家奴群体；同一理由也适用于不法致损之诉。因此，赔偿额也应依同一标准确定，尤其是在损害由过失而非故意造成、情节有时较轻的情况下。

<a id="9.2.32.1"></a>

**1.** 如果同一人先伤害同一名奴隶，后来又杀死他，就要分别对伤害和杀害承担责任，因为这是两项侵害。反之，如果某人在一次攻击中连续造成数处伤口并导致对方死亡，就只有一项杀害之诉。

### <a id="9.2.33"></a>9.2.33　保罗《评普劳提乌斯》第二卷

<a id="9.2.33.pr."></a>

**序言（pr.）** 如果你杀死了我的奴隶，我认为不应按我个人的感情估价；例如，若有人杀死你的亲生儿子，而你原本愿意出高价购买他，也不能据此估价，而应按他对所有人的通常价值计算。塞克斯图斯·佩迪乌斯也说，物品价格不依个人感情或个人用途确定，而应按一般标准计算。因此，拥有亲生儿子的人，不会仅仅因为若由他人所有时自己愿意高价买下他，就因此变得更富有；同样，拥有他人之子的父亲，也不因此拥有其父亲愿意支付的全部价款。因为《阿奎利亚法》使我们取得损害赔偿；我们所失去的，是原本可以取得的利益，或我们不得不支出的费用。

<a id="9.2.33.1"></a>

**1.** 对于《阿奎利亚法》不予追究的损害，应给予事实之诉。

### <a id="9.2.34"></a>9.2.34　马尔切鲁斯《学说汇纂》第二十一卷

### <a id="9.2.36"></a>9.2.36　马尔切鲁斯《学说汇纂》第二十一卷

<a id="9.2.36.pr."></a>

**序言（pr.）** 正如受遗赠人拒绝遗赠时，遗赠诉权归继承人所有，仿佛该物从未被遗赠一样；提图斯的诉权也应视为仿佛该奴隶只遗赠给了他一人。

<a id="9.2.36.1"></a>

**1.** 如果主人命令一名奴隶获释并成为继承人，而该奴隶此前已被提图斯致以致命伤，后来又由梅维乌斯成为继承人，梅维乌斯就不能对提图斯提起《阿奎利亚法》之诉。这符合萨宾的意见：如果死者本人不可能享有某项诉权，该诉权就不移转给继承人。否则会出现荒谬结果：继承人竟能就其所继承之人的被杀，取得该人的奴隶身价。但如果主人命令该奴隶只继承一部分遗产并同时获释，该奴隶死亡后，其共同继承人就可以依《阿奎利亚法》起诉。

### <a id="9.2.37"></a>9.2.37　雅沃勒努斯《摘自卡西乌斯》第十四卷

<a id="9.2.37.pr."></a>

**序言（pr.）** 自由人奉他人之命亲手实施不法侵害，如果发出命令的人有权命令他人，就应对命令者提起《阿奎利亚法》之诉；如果命令者无权发出该命令，就应对实际实施行为的人起诉。

<a id="9.2.37.1"></a>

**1.** 如果一头四足动物造成了致害行为，依非难之诉本可向其主人起诉，却被他人杀死，而原告转而依《阿奎利亚法》起诉，那么估价不应只按该动物本身的价值，而应考虑该动物所产生的法律责任。杀死该动物的人，应按原告的利害关系承担判决责任；也就是说，要看原告通过将该动物交付作为非难赔偿，而不是承担诉讼判赔，可以获得多少利益。

### <a id="9.2.38"></a>9.2.38　雅沃勒努斯《书信集》第九卷

在你以善意买下我的奴隶并由他为你服役期间，如果他被你的奴隶伤害，已经确立：我在任何情况下都可以依法对你提起《阿奎利亚法》之诉。

### <a id="9.2.39"></a>9.2.39　庞波尼乌斯《评昆图斯·穆基乌斯》第十七卷

<a id="9.2.39.pr."></a>

**序言（pr.）** 昆图斯·穆基乌斯写道：一匹母马在他人土地上吃草，主人将它赶走时，母马因怀孕而流产。有人询问，马主能否依《阿奎利亚法》起诉赶马人，因为赶逐时母马受到伤害。意见认为，如果赶马人打了母马，或故意过度驱赶，就可以起诉。

<a id="9.2.39.1"></a>

**1.** 庞波尼乌斯说：即使有人在自己的土地上发现了他人的牲畜，也必须像发现自己的牲畜那样将其赶走，因为如果因此遭受任何损害，他自有相应诉权。因此，在自己土地上发现他人牲畜的人，不得将牲畜关起来，也不得以不同于上文所说的方式驱赶它们，仿佛那是自己的牲畜；他应当无损地将牲畜赶走，或通知其主人前来领回。

### <a id="9.2.40"></a>9.2.40　保罗《评告示》第三卷

依《阿奎利亚法》起诉时，如果我称有人涂销了我的债务凭证，而凭证所载债务附有条件，我暂时还可以用证人证明该事实，但到了条件成就时，这些证人可能已经不在世；即使我只概述事实并使法官产生怀疑，我也应胜诉。不过，只有在债务条件成就时，才能执行判决；如果条件最终未成就，判决就不发生效力。

### <a id="9.2.41"></a>9.2.41　乌尔比安《评萨宾》第四十一卷

<a id="9.2.41.pr."></a>

**序言（pr.）** 如果有人涂销遗嘱，能否提起不法致损之诉？马尔切鲁斯在《学说汇纂》第五卷中对此表示疑问，并否认可以起诉。他说，损害应如何估价呢？我曾在他的意见旁批注：对立遗嘱人本人而言，这一观点确实正确，因为无法估算其利害关系；但对继承人或受遗赠人则不同，因为遗嘱对他们几乎就像债务凭证一样。马尔切鲁斯在同一处还写道，如果有人涂销了债务凭证，就可以提起《阿奎利亚法》之诉。此外，如果有人涂销了寄存于自己处的遗嘱文书，或当着许多人的面宣读遗嘱文书，而其目的是实施不法侵害、泄露遗嘱处置的秘密，那么提起事实之诉和侵辱之诉更为有利。

<a id="9.2.41.1"></a>

**1.** 庞波尼乌斯精辟地指出，有时某人涂销文书并不构成盗窃，而只构成不法致损；例如，他并非出于盗窃故意，而只是为了造成损害才涂销文书。此时不构成盗窃，因为盗窃不仅要求实施行为，还要求具备盗窃者的故意。

### <a id="9.2.42"></a>9.2.42　尤利安《学说汇纂》第四十八卷

如果有人涂销寄存于自己处的遗嘱文书或其他文书，使其无法阅读，就应依寄托之诉和出示之诉承担责任，因为他交还或出示的是已经毁损的物品。基于同一原因，也可以依《阿奎利亚法》起诉；涂改文书的人也应被正确地视为毁损了文书。

### <a id="9.2.43"></a>9.2.43　庞波尼乌斯《评萨宾》第十九卷

如果在继承人接受遗产之前，遗产中的财物遭到损害，而损害发生在被继承人死亡之后，继承人可以依《阿奎利亚法》起诉。因为该法所称“所有人”，并非必定是损害发生时的所有人。否则，这项诉权甚至不能从被继承人移转给继承人；同样，如果损害发生在某人被敌人俘虏期间，他获释返国后也无法起诉。这种解释还会使父母的遗腹子遭受重大损失；他们本应继承父母的遗产，却无法起诉。对于同一期间有人秘密砍伐树木的情形，也应作相同处理。我认为，如果有人以暴力或秘密方式实施行为，也可以适用同一规则：只要该行为人曾被禁止这样做，或者显然应当知道，继承人若知情就会禁止此事。

<a id="9.2.44.pr."></a>

### <a id="9.2.45"></a>9.2.45　保罗《评萨宾》第十卷

<a id="9.2.45.pr."></a>

**序言（pr.）** 此处应将“知情”理解为容忍：能够禁止却未加禁止的人，就应承担责任。

<a id="9.2.45.1"></a>

**1.** 即使受伤的奴隶已经痊愈，也可以依《阿奎利亚法》起诉。

**2.** 如果你以为我的奴隶是自由人，却将他杀死，仍依《阿奎利亚法》承担责任。

<a id="9.2.45.3"></a>

**3.** 两人跨越燃烧的麦秆时彼此撞上并摔倒，其中一人被火焰烧死；如果无法查明是谁把谁撞倒，就不能就此起诉〔底本原句在 *potest* 与 *agi* 之间留有空引号：*nihil eo nomine potest " " agi*；所缺诉名待核〕。

<a id="9.2.45.4"></a>

**4.** 如果有人在别无他法的情况下自卫并造成损害，就不承担责任；因为所有法律和一切权利都允许以暴力抵抗暴力。但如果我为了自卫向攻击者投掷石头，却没有打中他，而是打中路人，我就依《阿奎利亚法》承担责任。法律只允许打击正在施加暴力的人，而且还必须是为了保护自己，而非为了报复。

<a id="9.2.45.5"></a>

**5.** 如果有人拆除了足以支撑的墙体，应对该墙的所有人承担不法致损责任。

### <a id="9.2.46"></a>9.2.46　乌尔比安《评萨宾》第五十卷

如果已经就奴隶受伤依《阿奎利亚法》提起诉讼，而奴隶后来因该伤势死亡，仍然可以依《阿奎利亚法》就其死亡另行起诉。

### <a id="9.2.47"></a>9.2.47　尤利安《学说汇纂》第八十六卷

但是，如果第一次诉讼已经对伤害作出估价，而奴隶后来死亡，主人又开始就杀害提起诉讼，法院应准许被告提出恶意抗辩，并令原告通过两项诉讼取得的总额不得超过一开始就以奴隶被杀为由起诉时本应取得的数额。

### <a id="9.2.48"></a>9.2.48　保罗《评告示》第三十九卷

如果奴隶在继承人接受遗产前损害遗产中的财物，后来获得自由后又损害同一财物，他应依两项诉讼承担责任，因为这是两项不同的行为。

### <a id="9.2.49"></a>9.2.49　乌尔比安《论答疑》第九卷

<a id="9.2.49.pr."></a>

**序言（pr.）** 如果有人点烟驱走他人的蜜蜂，甚至将其杀死，更应视为其造成了死亡原因，而非亲自杀死蜜蜂；因此应给予事实之诉。

<a id="9.2.49.1"></a>

**1.** 《阿奎利亚法》追究不法造成的损害，应理解为：行为人在造成损害的同时，也带来了不法侵害；但如果是受到强大外力所迫而为，则属例外。塞尔苏斯以为阻止火灾而拆毁邻近房屋的人为例：他写道，《阿奎利亚法》之诉不适用，因为此人出于正当恐惧，担心火势蔓延到自己这里才拆毁邻屋。无论火势最终蔓延过来，还是在此前已被扑灭，他都认为《阿奎利亚法》之诉不适用。

### <a id="9.2.50"></a>9.2.50　乌尔比安《意见集》第六卷

某人未经房屋所有人同意拆毁他人的房屋，并在原址建造浴场；除依据自然法，地上建筑归土地所有人所有外，他还应因造成损害而承担诉讼责任。

### <a id="9.2.51"></a>9.2.51　尤利安《学说汇纂》第八十六卷

<a id="9.2.51.pr."></a>

**序言（pr.）** 一名奴隶受到一击，伤势严重到可以确定他会因此死亡；在此期间，他被指定为继承人，后来又被另一人击打后死亡。我询问，能否依《阿奎利亚法》分别以杀害为由起诉二人。答复如下：一般而言，人们把任何以某种方式造成死亡原因的人都称为杀人者；但在《阿奎利亚法》下，只有实际施加力量、亲手造成死亡原因的人，才被认为应承担责任。这里显然是从“击杀”一词（*caedere*）及“杀戮”（*caedes*）的词义引申而来。后来，人们认为，依《阿奎利亚法》承担责任的不仅包括造成伤势并使人立即死亡者，也包括造成某种伤势且可以确定受伤者会因此死亡的人。因此，如果一人给奴隶造成致命伤，另一人在一段时间后又击打他，使他比原本因第一处伤势死亡得更早，应当裁定二人都依《阿奎利亚法》承担责任。

<a id="9.2.51.1"></a>

**1.** 这也符合古人的权威意见：如果数人都以足以致命的方式伤害同一奴隶，而无法查明他死于谁的一击，古人就判定所有人都依《阿奎利亚法》承担责任。

<a id="9.2.51.2"></a>

**2.** 但对死者的估价，在二人身上并不相同。先行伤人的人，应按从受伤之日起向前倒推的一年中，该人曾达到的最高价值承担赔偿；后来伤人的人，则应按从死亡之日起向前倒推的一年中，该人可能达到的最高价值承担责任，遗产价值也计入其中。因此，对于同一奴隶被杀，一人承担较高估价，另一人承担较低估价，并不奇怪，因为二人被视为在不同原因和不同时间杀死了他。如果有人认为我们的裁定荒谬，他应当想到，更荒谬的结论是二人都不依《阿奎利亚法》承担责任，或者只由其中一人承担；因为不应让不法行为逍遥法外，而且也很难确定究竟应由谁承担责任。无数事例可以证明，民法为了公共利益而承认了许多与推理规则相悖的制度；我只举一例：数人出于盗窃目的共同搬运一根单独一人无法搬动的他人梁木，法律认为他们都应对盗窃承担责任，尽管按严格推理，可以说他们谁也不承担责任，因为没有任何一人单独搬走了梁木。

### <a id="9.2.52"></a>9.2.52　阿尔芬努斯《学说汇纂》第二卷

<a id="9.2.52.pr."></a>

**序言（pr.）** 如果奴隶因伤势死亡，而这并非由于医生缺乏经验或主人疏忽所致，就应正确地以不法杀害为由起诉。

<a id="9.2.52.1"></a>

**1.** 一名店主夜间把灯放在小路的一块石头上。一个路人经过时拿走了灯。店主追上他索要灯，并抓住逃跑者；逃跑者便用手中带有刺头的鞭子抽打店主，想让他放手。双方于是发生更激烈的争斗，店主挖出了拿灯者的一只眼。有人询问：由于店主先被鞭打，是否就不构成不法致损？我答复说，如果店主并非故意挖出对方的眼睛，就不视为不法致损；过失在于先用鞭子打人的一方。但如果店主此前没有被打，而是在他试图夺回灯时与对方争斗，那么过失就在店主一方。

<a id="9.2.52.2"></a>

**2.** 在卡比托利欧山坡上，两辆满载货物的车由骡子拉着行进。前车的赶车人扶住已经倾斜的前车，好让骡子容易拉动。随后，上方的车开始向后滑；当处在两辆车之间的赶车人离开后，后车被前车撞击并向后退，将一名男孩压死。男孩的主人询问应当起诉谁。我答复说，这要视具体情形而定：如果扶住上方车的赶车人自愿松手，导致骡子无法控制车子，车子又因负重而向后滑，就不能起诉骡子的主人；但可以依《阿奎利亚法》起诉扶车人，因为自愿松开自己扶住的物件，使之撞伤他人，与驱赶驴子后未能控制它，或从手中掷出武器或其他物品造成损害，并无不同。但如果骡子受到惊吓，赶车人担心自己被压伤而放开车子，就不能起诉这些人，而应起诉骡子的主人。如果骡子和赶车人都没有过错，而是骡子无法承受车载，或在奋力拉车时滑倒，导致车辆后退，且赶车人也无法挡住车载，那么无论是骡子的主人还是赶车人，都不承担责任。无论具体情形如何，后车骡子的主人肯定不能被起诉，因为这些骡子并非自愿后退，而是被撞后才向后退〔原文疑误：底本段末连写为 *retro redissententiarum*，疑有词语粘连；此处暂按可辨语义翻译，原文待核〕。

<a id="9.2.52.3"></a>

**3.** 有人出售牛，并约定交付买受人试用；后来他把牛交给买受人试用，买受人的奴隶在试牛时被另一头牛用角撞伤。有人询问卖方是否应赔偿买受人的损失。我答复说，如果买受人已经买下这些牛，卖方就不应赔偿；如果买受人尚未购买，那么若奴隶被牛撞伤是由于人的过失造成，卖方不应赔偿；若是由于牛本身的缺陷造成，则应赔偿。

<a id="9.2.52.4"></a>

**4.** 数人打球时，其中一人推倒了一名试图接球的小奴隶，奴隶摔倒并折断了腿。有人询问，奴隶的主人能否依《阿奎利亚法》起诉推倒他的人。我答复说不能，因为此事看起来更多是偶然发生，而非出于过失。

### <a id="9.2.53"></a>9.2.53　涅拉提乌斯《札记集》第一卷

你把他人的牛赶进狭窄处，结果牛被撞倒；可以依《阿奎利亚法》的规则对你给予事实之诉。

### <a id="9.2.54"></a>9.2.54　帕皮尼安《疑问集》第三十七卷

如果要式口约的债权人在债务人迟延履行前伤害了约定交付的动物，债务人享有《阿奎利亚法》之诉；债权人杀死该动物时也同样如此。但如果债权人在债务人迟延履行后才杀死动物，债务人当然因此免责，却不能在此情形下适当地依《阿奎利亚法》起诉；因为看来债权人伤害的是自己，而不是他人。

### <a id="9.2.55"></a>9.2.55　保罗《疑问集》第二十二卷

我向提图斯承诺交付斯提基乌斯或潘菲卢斯；斯提基乌斯当时价值一万，潘菲卢斯价值两万。债权人在债务人迟延履行前杀死了斯提基乌斯。有人询问应如何依《阿奎利亚法》起诉。我答复说，如果杀死的是价值较低的奴隶，就本案所讨论的问题而言，债权人并不不同于第三人。那么，究竟按斯提基乌斯被杀时的一万估价，还是按我必须交付的奴隶的价值估价，也就是按我的利害关系估价？如果潘菲卢斯也在债务人迟延履行前死亡，又该怎么说？债务人既已免责，斯提基乌斯的身价是否随之降低？只要斯提基乌斯被杀时或该年内曾有更高身价，就足够了。依此理由，即使斯提基乌斯在潘菲卢斯死亡后、但仍在一年内被杀，也应认为他当时价值更高。

### <a id="9.2.56"></a>9.2.56　保罗《判例集》第二卷

如果妻子损害了丈夫的财物，应依《阿奎利亚法》的规定对她起诉。

### <a id="9.2.57"></a>9.2.57　雅沃勒努斯《摘自拉贝奥后书》第六卷

我把一匹马借给你。你骑马时，还有几个人也在骑马；其中一人骑马冲撞你的马，把你撞下马，结果马腿折断。拉贝奥否认可以对你提起任何诉讼；但如果事故是该骑手的过失所致，就可以起诉骑手。当然，不能起诉那匹马的主人。我认为这是正确的。
