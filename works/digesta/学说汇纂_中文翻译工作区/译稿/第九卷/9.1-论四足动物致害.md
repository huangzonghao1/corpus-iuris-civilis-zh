# 第九卷

<a id="9.1"></a>

## 9.1.0　论四足动物致害之诉（*Si quadrupes pauperiem fecisse dicatur*）

### <a id="9.1.1"></a>9.1.1　乌尔比安《评告示》第十八卷

<a id="9.1.1.pr."></a>

**序言（pr.）** 如果有人主张四足动物造成了无不法行为人之过错的损害（*pauperies*），其诉权源自《十二表法》。该法规定，或者交付造成损害之物，即实施致害行为的动物；或者提出该项损害的估价。

<a id="9.1.1.1"></a>

**1.** 所谓 *noxia*，就是致害行为本身。

<a id="9.1.1.2"></a>

**2.** 这一诉讼适用于所有四足动物。

<a id="9.1.1.3"></a>

**3.** 裁判官说“造成了 *pauperies*”。所谓 *pauperies*，是指未实施不法行为的致害者所造成的损害；动物没有理性，因而不能说它实施了不法行为。

<a id="9.1.1.4"></a>

**4.** 因此，正如塞尔维乌斯所写，只有四足动物因凶性发作而造成损害时，才适用此项诉讼。例如，易踢人的马用后蹄踢人，习惯用角顶人的牛顶人，或者骡子因过于暴烈而伤人。如果损害是由于地势险恶、骡夫的过失，或者四足动物负载过重而将所载之物倾倒到某人身上造成的，则不适用此项诉讼，而应提起不法损害之诉。

<a id="9.1.1.5"></a>

**5.** 如果有人牵着狗，狗因凶猛挣脱控制并造成他人损害，那么，如果其他人本可以将狗控制得更牢，或者本不应牵狗经过该处，此项诉讼便不适用；控制狗的人应当承担责任。

<a id="9.1.1.6"></a>

**6.** 如果野兽是在他人驱使之下造成损害，此项诉讼也不适用。

<a id="9.1.1.7"></a>

**7.** 一般而言，凡动物受到刺激而作出违背其本性的行为，并因此造成 *pauperies*，均适用此项诉讼。因此，如果马因疼痛而受惊踢人，此项诉讼不适用；但殴打或刺伤马的人应承担事实诉讼责任，而非依《阿奎利亚法》承担责任，尤其因为造成损害的并非其自身身体。反之，如果有人抚摸马，或马受到抚触后踢伤某人，则可以提起此项诉讼。

<a id="9.1.1.8"></a>

**8.** 如果一头四足动物驱使另一头四足动物造成损害，应就实施驱使的动物提起诉讼。

<a id="9.1.1.9"></a>

**9.** 无论四足动物以自身身体造成 *pauperies*，还是通过其碰触的其他物品造成损害，均适用此项诉讼。例如，牛用牛车碾压某人，或者将其他物品撞落而造成损害。

<a id="9.1.1.10"></a>

**10.** 对野生动物而言，由于其具有天然的凶性，此项诉讼不适用。因此，如果一头熊逃脱后造成损害，不能起诉其原所有人；野兽逃脱后，原所有人便不再是其所有人。因此，如果我将它杀死，该野兽便归我所有。

<a id="9.1.1.11"></a>

**11.** 公羊或公牛相斗，其中一头杀死另一头时，昆图斯·穆基乌斯作了区分：如果死的是主动攻击的一方，诉讼不成立；如果死的是未曾挑衅的一方，则诉讼成立。因此，动物所有人应当赔偿损害，或者作诺克萨交付（*noxae deditio*）。

<a id="9.1.1.12"></a>

**12.** 由于即使对于四足动物，也适用诺克萨责任随致害者（此处为动物）转移（*noxa caput sequitur*）的规则，此项诉讼应当向动物现在的所有人提起，而非向动物致害时的所有人提起。

<a id="9.1.1.13"></a>

**13.** 当然，如果动物在争讼程序确定（*litis contestatio*）之前死亡，该诉权即告消灭。

<a id="9.1.1.14"></a>

**14.** 诺克萨交付，是指交付活着的动物。若动物由数人共有，则可以对每一共有人分别提起全额的诺克萨诉讼（*actio noxalis*），与对人的情形相同。

<a id="9.1.1.15"></a>

**15.** 有时，对所有人提起诉讼，并非仅要求其作诺克萨交付，而是要求其承担全部责任。例如，所有人在法庭前依法受询问、被问及四足动物是否属于自己时，回答说不属于自己；如果后来查明动物确属其所有，他将被判令承担全部责任。

<a id="9.1.1.16"></a>

**16.** 如果动物在争讼程序确定后被他人杀死，由于所有人享有《阿奎利亚法》之诉，应在审判中考虑该法之诉的估价，因为所有人已经丧失诺克萨交付的可能。因此，所有人应当按照本案所提出的诉讼估价赔偿；除非他愿意将针对杀害动物者的诉权授予原告行使。

<a id="9.1.1.17"></a>

**17.** 毫无疑问，此项诉讼可以由继承人及其他继受人提起；同样，也可以向继承人及其他人提起，但其依据并非继承关系，而是他们作为所有人的地位。

### <a id="9.1.2"></a>9.1.2　保罗《评告示》第二十二卷

<a id="9.1.2.pr."></a>

**序言（pr.）** 此项诉讼不仅归所有人享有，也归任何具有利害关系之人享有；例如，借用人以及漂洗工，因为他们会因自己所负的责任而遭受损失。

<a id="9.1.2.1"></a>

**1.** 如果某人为躲避他人（例如一名长官）而进入附近的店铺，并在那里被一条凶猛的狗咬伤，有些人认为，不能以该狗为由提起诉讼；但如果狗没有被拴住，则应作相反处理。

### <a id="9.1.3"></a>9.1.3　盖尤斯《评行省告示》第七卷

**正文** 依此法，如今无疑也可以就自由人提起诉讼；例如，四足动物使家父或家子受伤。此时不考虑毁容，因为自由人的身体不能以金钱估价；而应计算为治疗所支出的费用、丧失的劳动，以及因伤致残而将会丧失的劳动。

### <a id="9.1.4"></a>9.1.4　保罗《评告示》第二十二卷

**正文** 即使造成 *pauperies* 的不是四足动物，而是其他动物，也可以提起此项准诉讼（*actio utilis*）。

### <a id="9.1.5"></a>9.1.5　阿尔芬《学说汇纂》第二卷

**正文** 一名马夫把马牵进客店时，马嗅了嗅一头骡子；骡子随即向后踢，踢断了马夫的腿。有人询问，能否因为骡子造成了 *pauperies* 而向骡子的所有人提起诉讼。我答复：可以。
