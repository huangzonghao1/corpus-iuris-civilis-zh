## 9.4.0　论诺克萨诉讼（*De noxalibus actionibus*）

### <a id="9.4.1"></a>9.4.1

盖尤斯《评行省告示》第二卷

诺克萨诉讼，是指针对我们提起、其依据并非契约，而是奴隶的诺克萨行为及不法行为的诉讼。这类诉讼的效力在于：如果我们被判败诉，可以交付实施不法行为的奴隶本人，从而免于支付诉讼标的估价。

### <a id="9.4.2"></a>9.4.2

乌尔比安《评告示》第十八卷

<a id="9.4.2.pr."></a>

**序言（pr.）** 如果奴隶在主人知情的情况下杀人，主人即负全部责任，因为这被视为主人本人杀了人；如果主人不知情，则适用诺克萨责任。毕竟，主人不应仅因奴隶的不法行为而承担超过交付该奴隶以免除责任的义务。

<a id="9.4.2.1"></a>

**1.** 未予制止的人，无论后来仍是主人还是已不再是主人，均受此项诉讼拘束。只要其在未予制止时是主人，即已足够。因此，塞尔苏斯认为，即使奴隶后来全部或部分被转让，或被解放，诺克萨责任也不随奴隶本人而转移；因为奴隶服从主人的命令，并未自行实施不法行为。如果主人确曾下令，这一说法当然可以成立；但如果他只是没有制止，又如何为奴隶的行为开脱？不过，塞尔苏斯区分《阿奎利亚法》与《十二表法》：依古法，如果奴隶在主人知情时实施盗窃或其他诺克萨行为，诉讼以奴隶名义提起，主人不以自己的名义承担责任；但依《阿奎利亚法》，他说，应以主人自己的名义追究责任，而非以奴隶名义。塞尔苏斯分别解释两法的理由：《十二表法》仿佛意在规定奴隶在此类事项上不得服从主人；《阿奎利亚法》则仿佛宽恕服从主人的奴隶，因为奴隶若不服从，便可能遭到处死。但是，如果采纳尤利安在《学说汇纂》第八十六卷所写的意见，即“奴隶若实施盗窃或造成诺克萨损害”（*si servus furtum faxit noxiamve nocuit*），这一规则也适用于后来的法律，那么仍可就奴隶名义对主人提起诺克萨诉讼。这样，《阿奎利亚法》下对主人提起的诉讼便不会使奴隶免责，而是使主人承担责任。我们赞同尤利安的意见；此说有其道理，且马尔凯卢斯在尤利安著作中也予以认可。〔*noxam caput non sequi* 字面为“诺克萨责任不随行为人”，此处与奴隶服从主人命令、本人未独立实施不法行为相连；暂按责任不随奴隶转移理解。〕

### <a id="9.4.3"></a>9.4.3

乌尔比安《评告示》第三卷

在所有以主人知情为要件的诺克萨诉讼中，所谓“知情”，应理解为：主人能够制止，却没有制止。因为，作为奴隶不法行为的教唆者，与容忍奴隶实施不法行为，是两回事。

### <a id="9.4.4"></a>9.4.4

保罗《评告示》第三卷

<a id="9.4.4.pr."></a>

**序言（pr.）** 在奴隶的不法行为中，如何认定主人知情？是否须知情并参与谋划？还是说，只要看见即可，即便其无力制止？例如，奴隶在主人知情时主张自己享有自由，或者蔑视主人而行事，又该如何处理？再如，奴隶在河对岸实施诺克萨行为，主人虽看见却不赞同，情况又如何？因此，更恰当的说法是，应以有能力制止之人的知情为准；整个告示中出现“知情”一词时，都应如此理解。

<a id="9.4.4.1"></a>

**1.** 如果他人的奴隶在我知情时实施不法行为，而我后来买下了该奴隶，应对我提起诺克萨诉讼；因为行为发生时我并非主人，不能认为这是在主人知情的情况下实施的。

<a id="9.4.4.2"></a>

**2.** 如果主人因知情而承担责任，是否也应以奴隶名义提起诉讼？应予考察；除非行政长官只是想向主人追究一项处罚。如此一来，奴隶的故意不法行为岂非不受处罚？这并不公平。相反，主人在两种诉讼方式下都受拘束；但原告选择并取得一种处罚后，另一种处罚即不得再行追究。

<a id="9.4.4.3"></a>

**3.** 如果原告未请求交付致害奴隶，而是仿佛主人知情那样提起诉讼，但主人实际上并不知情，那么主人获判免责、诉讼终结后，原告不能再以诺克萨交付为由提起诉讼；他会因既判事项抗辩而被驳回，因为该事项已提交前诉并经终局处理。不过，在前诉尚在进行时，如果原告后悔主张主人知情，可以转而按照诺克萨事由起诉。反过来，如果原告已对知情的主人提起诺克萨诉讼，就不得再撤去诺克萨交付要求、另行对主人提起诉讼；但在同一诉讼中，若原告愿意主张主人知情，不得禁止其如此主张。

### <a id="9.4.5"></a>9.4.5

乌尔比安《评告示》第三卷

<a id="9.4.5.pr."></a>

**序言（pr.）** 如果数人共有的奴隶在所有主人均不知情时实施不法行为，可以对任何一名主人提起诺克萨诉讼；但如果所有主人均知情，则可对其中任何一人追究全部责任，不允许其交付致害奴隶，正如数名行为人共同实施不法行为的情形；而且，即使已对其中一人起诉，也不会使另一人免责。如果一人知情、另一人不知情，则对知情者提起不允许诺克萨交付的诉讼，对不知情者则提起诺克萨诉讼。

<a id="9.4.5.1"></a>

**1.** 这两种诉讼的区别不仅在于知情的主人承担全部责任；还在于，即使知情的主人转让了奴隶、解放了奴隶，或奴隶死亡，主人仍然承担责任。但如果主人本人死亡，其继承人不承担责任。

### <a id="9.4.6"></a>9.4.6

乌尔比安《评告示》第十八卷

即使奴隶本人已经被解放，也仍受责任拘束。

### <a id="9.4.7"></a>9.4.7

乌尔比安《评告示》第三卷

<a id="9.4.7.pr."></a>

**序言（pr.）** 只有奴隶处于我占有或控制之下时，才可对我提起诺克萨诉讼。只要奴隶现在处于我控制之下，即使实施不法行为时并非如此，我仍承担责任；如果致害奴隶仍然存活，我的继承人也承担责任。

<a id="9.4.7.1"></a>

**1.** 庞波尼乌斯说，如果买受人因奴隶的诺克萨行为被起诉，就不能再起诉明知该行为的出卖人。

### <a id="9.4.8"></a>9.4.8

乌尔比安《评告示》第三十七卷

如果共有奴隶实施盗窃，可以对任何一名共有人提起诺克萨诉讼并追究全部责任；我们适用这一规则。被诉者只有将奴隶完整地交付以免除责任，才能避免支付诉讼标的估价；若其只愿交付一部分，不应接受。如果因其他共有人不愿交付，某一共有人被判承担全部责任，他可以对其他共有人提起共有物分割之诉或遗产分割之诉。在诺克萨诉讼开始之前，他当然可以让与自己在奴隶中的份额，从而获得保障，避免不得不应诉。尽管有人可能会说，这样会导致其丧失诉权，因为他一旦成为按份所有人，就不能对共有人提起诺克萨诉讼。或许，他也不能就共有关系形成之前发生的不法行为提起共有物分割之诉；若果真如此，他显然会遭受不公。但更好的意见是，应当允许他提起共有物分割之诉。

### <a id="9.4.9"></a>9.4.9

保罗《评告示》第三十九卷

如果共同家奴或共有奴隶实施盗窃，其中一名主人知情，那么知情者应代表所有主人承担责任；对其提起诉讼，也使另一主人免责，而且他不得向共有人请求任何分担，因为他是因自己的行为而受处罚。反之，如果不知情的主人支付了双倍金额，可以向共有人请求分担其中的单倍金额。

### <a id="9.4.10"></a>9.4.10

保罗《评告示》第二十二卷

此外，如果某共有人使共有奴隶的状况恶化，也可以对其提起诉讼，如同对任何使共有物状况恶化的人一样。若诺克萨交付后双方已无其他共有物，则可以提起合伙之诉；若双方并非合伙关系，则可提起事实之诉。

### <a id="9.4.11"></a>9.4.11

乌尔比安《评告示》第七卷

善意占有奴隶的人，应以该奴隶名义承担盗窃之诉责任；所有权人不承担责任。但通过诺克萨交付，并不会使奴隶成为原告所有。此后，若所有权人开始对该奴隶主张所有权，被告可以通过诈欺抗辩将其驳回，或者由法官依职权确保被告不受损害。

### <a id="9.4.12"></a>9.4.12

保罗《评告示》第六卷

如果善意占有人释放了自己善意占有的奴隶，意图使他人无法基于诺克萨事由对自己提起诉讼，那么他应承担针对控制奴隶者或以诈欺方式使自己不再控制奴隶者所设的诉讼责任，因为就此而言，仍视为其继续占有该奴隶。

### <a id="9.4.13"></a>9.4.13

盖尤斯《评行省告示》第十三卷

诺克萨诉讼不仅可以针对善意占有人提起，也可以针对恶意占有人提起。若善意占有人须面对诉讼，而掠夺者反能安然无恙，这显然荒谬。

### <a id="9.4.14"></a>9.4.14

乌尔比安《评告示》第十八卷

<a id="9.4.14.pr."></a>

**序言（pr.）** 如果数人因同一奴隶的诺克萨行为起诉某人，或者一人基于该奴隶实施的数项不法行为起诉某人，被告既然无法将奴隶交付给所有人，就无须向无法交付奴隶的人提出支付诉讼标的估价。那么，如果有数名原告，如何处理？如果其中一人先取得奴隶，是否应由其单独受领，以使其处于较优地位？还是应当把奴隶交付给所有人，或提供担保以确保其他原告获得救济？较为正确的看法是，先取得奴隶者处于较优地位。因此，奴隶应交付给先取得判决的人，而不是先提起诉讼的人；后来胜诉者则应因既判事项而被拒绝诉权。

<a id="9.4.14.1"></a>

**1.** 如果奴隶属于附条件解放者，而交付前条件已经成就；或者在交付前已经依遗嘱信托实现自由；或者遗赠所附条件成就、所有权已经转移，法官应依其裁量判被告免责。法官依职权还应要求其向受领奴隶的人提供担保，以应对因其自身行为而发生的追夺。

### <a id="9.4.15"></a>9.4.15

盖尤斯《评行省告示》第六卷

行政长官应裁定将诉讼转移至附条件解放的奴隶本人。如果在裁判时其附条件自由仍处于待定状态，萨比努斯和卡西乌斯认为，继承人可以通过交付奴隶而免责，因为他已让与自己全部权利；此说正确。

### <a id="9.4.16"></a>9.4.16

尤利安《学说汇纂》第二十二卷

如果继承人以诈欺方式使附条件解放的奴隶不再处于自己控制之下，并因此在未请求诺克萨交付的情况下接受诉讼，那么即使该奴隶所附的自由条件已经成就，继承人仍应被判承担责任，如同奴隶已经死亡一样。

### <a id="9.4.17"></a>9.4.17

保罗《评告示》第二十二卷

<a id="9.4.17.pr."></a>

**序言（pr.）** 如果奴隶有两名主人，一人知情而另一人不知情，奴隶实施了不法行为；若原告先起诉不知情的主人，而该主人已交付奴隶以免除责任，让另一主人也因此免责是不公平的，因为所交付的只是价值最低之人的责任替代物。因此，也可以起诉另一主人；如果损害赔偿额超过已交付奴隶的价值，原告可在扣除该奴隶价值后取得剩余部分。两名主人之间则应通过共有物分割之诉进行结算：如果知情的主人已经付款，不应由其承担全部份额，而只承担相当于奴隶价值的份额；另一人若支付了款项，也应按其份额计算。命令奴隶实施不法行为的人却向共有人请求分担，是不公平的，因为他遭受的损害源自自己的不法行为。

<a id="9.4.17.1"></a>

**1.** 如果数人想以同一奴隶为名对我提起诺克萨诉讼，或者一人以同一奴隶为名提起多项诉讼，而该奴隶的用益权属于你、所有权属于我，那么我交付奴隶时，法官的职责包括使原告也取得对该奴隶的用益权。不过，我作为所有权人可以请求行政长官命令你按照用益权估价向诉讼标的估价中作出分担；若较为适当，也可命令你让与用益权。如果我作为所有权人不愿为该奴隶应诉，就应准许你为其辩护；即使你败诉并交付奴隶，你也应获得针对我的保护。〔末句底本作 *et adversus me tueris*，语义及形态不稳，暂依上下文译出。〕

### <a id="9.4.18"></a>9.4.18

庞波尼乌斯《评萨比努斯》第十八卷

对奴隶享有用益权的人，可以像其他人一样对所有权人提起盗窃之诉；但不能对该奴隶本人提起，即便该奴隶为其提供劳务亦然。因此，所有权人被判决后，将奴隶交付给用益权人即可免责。〔底本作 *liberatur*，并列异文 *liberabitur*。〕

### <a id="9.4.19"></a>9.4.19

保罗《评告示》第二十二卷

<a id="9.4.19.pr."></a>

**序言（pr.）** 如果提提乌斯的奴隶对我和你共有的财产造成损害，我们起诉时，应适用《阿奎利亚法》下的诺克萨诉讼，避免奴隶被判对每一名原告分别承担全部交付责任。也可以认为，这是一项损害和一项债务：要么向我们两人支付金钱，要么由法官依职权同时向我们两人交付奴隶以免除责任。但即使奴隶被完整交付给我们中的一人，且主人因此对我们双方均获免责，也可以说，受领奴隶的人应通过共有物分割之诉对另一人承担责任，将以诺克萨方式交付给自己的奴隶与另一人共有，因为共同事务已有利益归于共有人。

<a id="9.4.19.1"></a>

**1.** 如果奴隶的所有权属于一人、用益权属于另一人，而所有权人出租了该奴隶的劳务，那么依契约文字，应判其以诺克萨方式交付奴隶。

<a id="9.4.19.2"></a>

**2.** 如果你的奴隶经营船舶，而其属奴（*vicarius*）同时也是该船水手，并在该船上造成损害，对你提起诉讼时，应如同该经营者是自由人、该属奴是其奴隶一样处理；你应因你奴隶的特有产而被判交付该属奴以免除责任。不过，如果属奴是奉你奴隶之命，或在你奴隶知情且容任的情况下造成损害，则应以你奴隶名义提起诺克萨诉讼。如果他命令水手实施行为，也应作同样处理。

### <a id="9.4.20"></a>9.4.20

盖尤斯《评行省告示》第七卷

如果原告在不同时间基于奴隶的数项不同诺克萨行为提起诉讼，而其因其中一项行为取得奴隶所有权，就不能再针对曾经是该奴隶所有权人的人提起其他诉讼，因为诺克萨诉讼随行为人本人而转移。但如果主人选择在第一项诉讼中支付诉讼标的估价，那么无论同一原告还是另一原告基于其他不法行为起诉，他仍然承担责任。

### <a id="9.4.21"></a>9.4.21

乌尔比安《评告示》第二十三卷

<a id="9.4.21.pr."></a>

**序言（pr.）** 每当主人因诺克萨事由被起诉而不愿接受诉讼时，案件应如此处理：他必须交付被起诉的奴隶以免除责任；如果不这样做，就必须接受诉讼，但只有在奴隶仍处于其控制之下，或他以诈欺方式使自己不再控制奴隶时，才可判他承担责任。

<a id="9.4.21.1"></a>

**1.** 通说认为，可以为因其而提起诺克萨诉讼的人辩护，即使其本人缺席；但仅限于奴隶为自己所有的情形。如果奴隶属于他人，或者无法确定奴隶究竟属于自己还是他人，则奴隶应当到场。我认为，这应理解为：如果确定该人是以善意身份服役，即使缺席也可以为其辩护。

<a id="9.4.21.2"></a>

**2.** 行政长官告示规定：“如果被称为控制奴隶的人否认该奴隶处于其控制之下，我将依原告的选择，命令其宣誓该奴隶不在其控制之下且并非其以诈欺方式使奴隶脱离控制；或者，我将准许不附诺克萨交付的诉讼。”

<a id="9.4.21.3"></a>

**3.** “处于控制之下”应理解为有能力并能够将奴隶交出；否则，如果奴隶正在逃亡或身处外地，就不视为处于其控制之下。

<a id="9.4.21.4"></a>

**4.** 如果被告拒绝宣誓，其地位就如同既不为缺席者辩护、也不将其交出的人；此类人会被视为抗命者而判承担责任。

<a id="9.4.21.5"></a>

**5.** 若监护人或保佐人在场，他们应宣誓奴隶不在主人的控制之下；若由代理人出庭，则必须由主人本人宣誓。〔底本作 *extent*，疑为 *exstent*，依“在场”义译。〕

<a id="9.4.21.6"></a>

**6.** 如果原告要求宣誓而被告已经宣誓，原告后来又想提起诺克萨诉讼，应考察是否应向被告提供宣誓抗辩。萨比努斯认为不应提供，因为当时宣誓针对的是另一事项，即奴隶当时不在其控制之下；而现在奴隶已被发现处于其控制之下，可以就奴隶的行为起诉。涅拉提乌斯也说，宣誓之后，原告仍可撤去诺克萨交付要求而提起诉讼，只要其主张奴隶是在宣誓之后才进入被告控制之下。

### <a id="9.4.22"></a>9.4.22

保罗《评告示》第十八卷

<a id="9.4.22.pr."></a>

**序言（pr.）** 如果奴隶被寄存或借用，可以对主人提起诺克萨诉讼；因为该奴隶仍被视为在为主人服役，就本告示而言，也处于主人的控制之下，尤其是主人能够将奴隶要回时。

<a id="9.4.22.1"></a>

**1.** 以质权取得奴隶的人，或请求并获准暂时占有奴隶的人，不承担诺克萨诉讼责任。虽然他们的占有具有正当性，但并非以所有权人的身份占有。不过，如果主人有能力将奴隶要回，也可以认为奴隶仍处于主人的控制之下。

<a id="9.4.22.2"></a>

**2.** 所谓有能力要回奴隶，是指有足够金钱使自己解除相应负担；因为不应强迫他出售自己的财产，以便支付金钱并取回奴隶。

<a id="9.4.22.3"></a>

**3.** 主人承认奴隶处于自己控制之下的，应当将奴隶交出，或者为缺席的奴隶辩护；否则就要受处罚，如同奴隶在场却不交付以免除责任一样。

<a id="9.4.22.4"></a>

**4.** 如果主人否认奴隶处于自己控制之下，行政长官允许原告选择：是要求主人宣誓，还是在不附诺克萨交付的情况下提起诉讼。若原告证明奴隶处于被告控制之下，或被告以诈欺方式使自己不再控制奴隶，即可胜诉；未能证明奴隶处于对方控制之下的，就丧失其诉讼请求。

### <a id="9.4.23"></a>9.4.23

盖尤斯《评行省告示》第六卷

如果对方后来开始控制该奴隶，就应基于新的占有追究其责任，不得向其提供抗辩。

### <a id="9.4.24"></a>9.4.24

保罗《评告示》第十八卷

应当考察：如果某人以诈欺方式使自己不再控制奴隶，因而诺克萨诉讼无法进行，例如他命令自己的奴隶逃跑，是否只能对该人提起诺克萨诉讼；还是说，在仍可对他人起诉时——例如奴隶被转让或解放——也可以起诉他人。较为正确的看法是可以；在这种情况下，原告可以选择对谁起诉。不过，尤利安说，对于解放奴隶的人，如果被解放者愿意为自己辩护，应给予该解放者抗辩。拉贝奥也持此说。

### <a id="9.4.25"></a>9.4.25

盖尤斯《评行省告示》第六卷

如果奴隶的新主人愿意接受诉讼，也应作同样处理。

### <a id="9.4.26"></a>9.4.26

保罗《评告示》第十八卷

<a id="9.4.26.pr."></a>

**序言（pr.）** 原告作出选择，会使另一人免责。行政长官设立此项规则，是为了不让原告受挫，而不是让其获得额外利益。因此，后续被诉者可以提出抗辩，将原告驳回。

<a id="9.4.26.1"></a>

**1.** 由此可知，如果数人均以诈欺方式使自己不再控制奴隶，原告应当选择起诉其中何人。

<a id="9.4.26.2"></a>

**2.** 同样，如果数名主人中有人以诈欺方式停止占有其份额，原告可以选择：是直接起诉仍在占有奴隶的人，还是通过行政长官设立的诉讼起诉停止占有的人。

<a id="9.4.26.3"></a>

**3.** 如果有人在法庭上声称他人的奴隶是自己的，而另一人支付了相应款项，则前者免责。

<a id="9.4.26.4"></a>

**4.** 如果你以诈欺方式停止占有的奴隶，在你因本项诉讼被起诉之前已经死亡，你就免责，因为本项诉讼取代了直接诉讼。若你在接受诉讼时迟延，则应作不同处理。

<a id="9.4.26.5"></a>

**5.** 对于死者所作的虚假陈述，不得向其继承人或由继承人提起诉讼；也不得在任何时候就此起诉死者本人。为缺席奴隶辩护的人，应能够避免本告示规定的处罚，也就是避免在不能诺克萨交付的情况下被起诉。因此，如果你曾否认奴隶处于你的控制之下，之后仍可承认；但如果针对你的诉讼已经确定诉讼标的，就不得再听取这一承认，正如拉贝奥所说。奥克塔维努斯认为，即使诉讼标的已经确定，也应基于具体情形给予救济，尤其是在你的年龄足以应予宽宥时。〔本段关于“死者的陈述”及其继承人是否承担诉讼责任，底本文义较压缩，译文依上下文处理。〕

<a id="9.4.26.6"></a>

**6.** 如果主人缺席时奴隶被带走，或者主人虽在场但处于可获恢复原状救济的情形，应准许以带走奴隶之人的名义进行辩护；因为原告请求将奴隶交出以便辩护时，行政长官应予准许。如果在场的主人不愿辩护，也应允许用益权人或质权人如此处理，以免他人的诈欺或怠惰损害他们。同样规则也适用于共有奴隶：一名在场共有人拒绝辩护时，应准许另一人辩护。但在这些情形中，也应救济原告，因为通说认为，一旦通过所有权取得奴隶，诉权即告消灭；奴隶依行政长官命令被带走后，便成为带走者财产的一部分。

### <a id="9.4.27"></a>9.4.27

盖尤斯《评行省告示》第六卷

<a id="9.4.27.pr."></a>

**序言（pr.）** 如果诺克萨诉讼涉及以质权负担的奴隶，或用益权属于他人的奴隶，应当注意：如果债权人或用益权人在场却不愿进行辩护，总督将介入，并拒绝其行使质权或用益权的诉讼。在这种情况下，可以说质权依法即告解除，因为其追索权既被拒绝，就不存在可追索的质权。用益权则不同；即使其追索权被拒绝，用益权仍依法存续，直至因在法定期间内不行使而消灭。

<a id="9.4.27.1"></a>

**1.** 从我们关于以质权负担的他人奴隶、附条件解放的奴隶以及用益权属于他人的奴隶所说的内容可见：某人即使因诺克萨诉讼而承担责任，并在法庭上声称他人的奴隶是自己的，也不能仅凭诺克萨交付而当然免责，因为他并非所有人，不能将所有权转移给原告。不过，如果主人后来主张取回依此原因交付的奴隶，却不愿支付诉讼标的估价，可以通过诈欺抗辩将其驳回。

### <a id="9.4.28"></a>9.4.28

阿非利卡努斯《疑义》第六卷

一般而言，如果我以诺克萨诉讼起诉你，而该奴隶虽属他人、却以正当的服役关系为你服役，你将其交付给我，那么，无论主人在我占有时向我主张奴隶所有权，还是主人自己占有该奴隶，我都可获得救济。若主人在我占有时主张所有权，除非他支付诉讼标的估价，否则我可以通过诈欺抗辩将其驳回；若主人自己占有奴隶，则应给予我普布利基安诉权。若所有权人提出“如果他是该物所有人”的抗辩，我可以提出诈欺的准反诉。依此，我甚至可以通过时效取得该奴隶，尽管我明知其属于他人。否则，善意占有人将遭受极不公平的对待：尽管法律直接允许对其提起诺克萨诉讼，却又强迫其支付诉讼标的估价。即使主人不进行辩护，奴隶是依行政长官命令被我带走，结论也相同，因为在这种情况下我同样具有正当的占有原因。

### <a id="9.4.29"></a>9.4.29

盖尤斯《评行省告示》第六卷

不仅不控制奴隶的人可以拒绝接受诺克萨诉讼；即使控制奴隶的人，只要让该人无人辩护，也可以避免诉讼。不过，此人必须将自己的权利转移给原告，如同其已经被判败诉一样。

### <a id="9.4.30"></a>9.4.30

盖尤斯《城市裁判官关于未发生损害的告示》

在诺克萨诉讼中，善意缺席者的权利不会因此受损；他们返回后，应依诚信和公平原则给予辩护机会，无论其是所有人，还是对该奴隶享有某种权利，例如债权人或用益权人。

### <a id="9.4.31"></a>9.4.31

保罗《评普劳提乌斯》第七卷

行政长官说，如果家奴实施盗窃，将以这样的方式给予诉讼：原告取得的金额，应与自由人实施盗窃时相同。问题在于，这句话是指金钱给付，还是也包括诺克萨交付；例如，是否应将交付致害奴隶所得价款计入双倍金额，并禁止其后续诉讼？萨比努斯和卡西乌斯认为，交付致害奴隶所得价款也应计入；庞波尼乌斯赞同此说，这也是正确的。即使奴隶因无人辩护而被带走，其估价也应计入。尤利安认为，不仅应考虑双倍赔偿，还应考虑返还之诉。判断奴隶是否属于同一家奴群，应以盗窃发生时为准；如果当时分别属于数名主人，后来才归于同一所有人，则不适用该告示。

### <a id="9.4.32"></a>9.4.32

卡利斯特拉图斯《告示解说》第二卷

如果有人处于他人权力之下，并被指称实施了诺克萨行为，而无人为其辩护，就会被带走；如果主人在场，则应交付此人，并就诈欺提供允诺担保。

### <a id="9.4.33"></a>9.4.33

庞波尼乌斯《评萨比努斯》第十四卷

在诺克萨诉讼中，没有人会被强迫违背意愿为他人辩护；如果不为奴隶辩护，就应丧失该奴隶。如果处于他人权力之下的是自由人，则应无条件准许其本人为自己辩护：

### <a id="9.4.34"></a>9.4.34

尤利安《评乌尔塞乌斯·费罗克斯》第四卷

因为，每当无人基于不法行为为家子辩护时，就应对家子本人给予诉讼。

### <a id="9.4.35"></a>9.4.35

乌尔比安《评萨比努斯》第四十一卷

如果家子被判败诉，就应履行判决；因为判决对其具有拘束力。甚至还应说，在家子被判败诉之后，也只能在特有产范围内对父亲提起诉讼。

### <a id="9.4.36"></a>9.4.36

乌尔比安《评告示》第三十七卷

如果有人从债务人处买下已设质、后又被债务人偷回的奴隶，他取得奴隶所有权后，应以该奴隶名义承担盗窃诉讼责任；债权人可以通过塞尔维安诉权将奴隶取回，并不妨碍对买受人起诉。即使某人从未满二十五岁的人处买下奴隶，或明知而参与损害债权人的交易，也适用同一规则；因为即使这些人的所有权可能被剥夺，在此期间仍可对其提起诉讼。

### <a id="9.4.37"></a>9.4.37

特里丰尼努斯《争论集》第十五卷

如果他人的奴隶曾对我实施盗窃，后来该奴隶成为我的所有物，那么在盗窃诉讼尚未提交审理之前，我享有的盗窃之诉即告消灭；即使后来我又出售了在诉讼标的确定前买下的奴隶，该盗窃之诉也不会恢复。但如果我是在诉讼标的确定后才买下该奴隶，出卖人应被判承担责任，

### <a id="9.4.38"></a>9.4.38

乌尔比安《评告示》第三十七卷

<a id="9.4.38.pr."></a>

**序言（pr.）** ……如同出卖给他人一样。因为出卖给谁并不重要，无论是出卖给对方当事人还是他人；出卖人是因自己的过错而承担诉讼标的估价，因为他通过出卖奴隶使自己丧失了诺克萨交付的可能。

<a id="9.4.38.1"></a>

**1.** 尤利安在《学说汇纂》第二十二卷中写道，如果我把曾对你实施盗窃的奴隶视为弃置物，我就免责，因为该奴隶立即不再属于我；对于无主人的人，不存在盗窃之诉。

<a id="9.4.38.2"></a>

**2.** 如果我的奴隶窃取你的物品并将其出售，而你又从他手中拿走其持有的售款，就会出现双方互相提起盗窃之诉的情形：你可以以奴隶的诺克萨行为为由对我提起盗窃之诉，我则可以就金钱对你提起盗窃之诉。

<a id="9.4.38.3"></a>

**3.** 如果我把钱交给债权人的奴隶，让其转交给主人，而该奴隶截留了收到的钱，也同样可以提起盗窃之诉。

### <a id="9.4.39"></a>9.4.39

尤利安《学说汇纂》第九卷

<a id="9.4.39.pr."></a>

**序言（pr.）** 如果共有奴隶实施盗窃，所有主人都以诈欺方式使奴隶不再处于自己控制之下，行政长官就应遵循市民法诉权，并依此事由向原告所选择的人给予告示诉权。行政长官给予原告的救济不应超过这一范围：如果奴隶被交出，原告本可通过诺克萨诉讼起诉该人；现在则允许其撤去诺克萨交付要求而起诉。

<a id="9.4.39.1"></a>

**1.** 如果有人承认他人的奴隶是自己的，尽管他因此受诺克萨诉讼拘束，经审查案情后仍应提供担保；但以奴隶为名被起诉的人，不应被要求提供担保，因为他并未主动提出为他人的奴隶辩护。

<a id="9.4.39.2"></a>

**2.** 如果有人指称主人以诈欺方式使奴隶不再处于其控制之下，而主人主张另有人已经为该奴隶提供担保并进行辩护，就可以适用诈欺抗辩。

<a id="9.4.39.3"></a>

**3.** 如果诉讼标的确定后，奴隶出现在主人身边，而由于无人辩护已经被带走，主人可以提出诈欺抗辩并获判免责。

<a id="9.4.39.4"></a>

**4.** 如果奴隶在诉讼标的确定前死亡，主人完全不承担本项诉讼责任。

### <a id="9.4.40"></a>9.4.40

尤利安《学说汇纂》第二十二卷

如果遗赠的奴隶在遗产被接受前，窃取了将来继承人的财物，该继承人可以对接受遗赠的受遗赠人提起盗窃之诉。但如果同一奴隶窃取的是遗产财物，则不发生盗窃之诉，因为这类物不构成盗窃；不过，可以提起出示之诉。

### <a id="9.4.41"></a>9.4.41

尤利安《评乌尔塞乌斯·费罗克斯》第二卷

共有奴隶对其中一名主人造成不法损害时，不适用《阿奎利亚法》之诉；因为如果该奴隶对外人造成损害，可以依据《阿奎利亚法》对其中一名主人追究全部责任。同样，共有奴隶实施盗窃时，不能对另一名主人提起盗窃之诉，但可以提起共有物分割之诉。

### <a id="9.4.42"></a>9.4.42

乌尔比安《评告示》第三十七卷

<a id="9.4.42.pr."></a>

**序言（pr.）** 如果因某人而提起诺克萨诉讼，而此人主张自己享有自由，应暂停该诉讼，直至其身份得到裁判。如果判定其为奴隶，就继续进行诺克萨诉讼；如果判定其为自由人，该诉讼便失去意义。

<a id="9.4.42.1"></a>

**1.** 如果有人不知道奴隶已经死亡，却因该奴隶接受了诺克萨诉讼，应判其免责，因为“应当交付该奴隶”这一前提已不再成立。〔底本在 *desit* 后并列异文 *desiit*；译文依后者理解。〕

<a id="9.4.42.2"></a>

**2.** 这些诉讼是永久性的，只要我们仍有能力交付奴隶，就可以提起；不仅我们可以提起，我们的继承人也可以提起。诉讼也可以针对继承人，但不是以继承人身份追究，而是基于所有权。因此，即使主张奴隶已经转归他人，也可以基于所有权对新主人提起诺克萨诉讼。

### <a id="9.4.43"></a>9.4.43

庞波尼乌斯《书信》第八卷

对于其诺克萨责任随本人而转移的奴隶，应当在被指称实施不法行为的地点进行辩护。因此，主人必须在据称实施暴力的地点将奴隶交出；若不为其辩护，就可能丧失对这些奴隶的所有权。
