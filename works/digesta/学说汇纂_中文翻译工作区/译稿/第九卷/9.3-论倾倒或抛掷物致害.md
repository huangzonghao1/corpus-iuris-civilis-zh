## 9.3.0　论倾倒或抛掷物致害（*De his, qui effuderint vel deiecerint*）

### <a id="9.3.1"></a>9.3.1　乌尔比安《评告示》第二十三卷

<a id="9.3.1.pr."></a>

**序言（pr.）** 裁判官就倾倒或抛掷物者规定如下：“凡有物被抛下或倾倒至众人通常通行或停留之处，我将针对居住在该处之人，依因此造成或发生的损害，授予双倍赔偿之诉。如果据称自由人因该物击中而死亡，我将授予请求五十奥雷乌斯的诉讼。如果其生还而据称受到伤害，我将授予诉讼，请求法官认为被告为此应承担的公平数额。如果据称奴隶未经主人知情而实施上述行为，我将在诉讼中增加：或者交付奴隶以承担诺克萨责任。”

<a id="9.3.1.1"></a>

**1.** 无人否认，裁判官颁布此告示极有裨益：使人们能够无所畏惧、无危险地在道路上通行，确有公共利益。

<a id="9.3.1.2"></a>

**2.** 该处是公共场所还是私人场所，本不应有什么关系，只要众人通常经由那里通行即可；因为告示旨在保护通行者，而非专门保护公共道路。凡众人通常通行之处，都应享有同等的安全保障。反之，如果某条道路过去并无众人通行，倾倒或抛掷发生时那里仍是僻静之处，只是后来才开始有人通行，就不应适用本告示。

<a id="9.3.1.3"></a>

**3.** 悬挂之物脱落，较宜视为被抛下；悬置之物坠落，也最好按被抛下处理。因此，即使悬挂之物自行倾泻、无人实施倾倒，也应认为本告示适用。

<a id="9.3.1.4"></a>

**4.** 此项事实之诉针对倾倒或抛掷发生时居住于该处之人，而不针对房屋所有人；因为过错在居住者。授予双倍之诉时，并不另要求证明过错，也不以被告否认责任为条件；尽管提起不法损害之诉须具备二者。

<a id="9.3.1.5"></a>

**5.** 但是，自由人死亡时，不按双倍计算损害额，因为自由人的身体不能估价；而是判处被告支付五十奥雷乌斯。

<a id="9.3.1.6"></a>

**6.** “如果其生还而据称受到伤害”一语，并不适用于对自由人财物造成的损害，例如其衣物或其他物品被撕破、损坏；该语仅指对其身体所造成的伤害。

<a id="9.3.1.7"></a>

**7.** 家子租住公寓，而有物从该处抛下或倾倒时，不得以特有产之诉向其父请求，因为此事并非源于契约。因此，此项诉讼应针对家子本人。

<a id="9.3.1.8"></a>

**8.** 奴隶是居住者时，是否应给予诺克萨之诉，因为本案并非源自奴隶所处理的事务？还是应给予特有产之诉，因为本案并非源自奴隶的不法行为？毕竟，不能妥当地说奴隶实施了侵害，因为奴隶并未造成损害。但我认为，不应使奴隶不受惩处；应由法官依特别程序予以矫正。

<a id="9.3.1.9"></a>

**9.** 所谓居住，包括居住在自己的房屋、租赁的房屋或无偿提供的房屋中。客人显然不承担责任，因为他并非居住在那里，只是暂时作客；但提供住宿的人承担责任。居住者与客人之间的区别，正如有住所者与旅行者之间的区别。

<a id="9.3.1.10"></a>

**10.** 如果数人居住在同一间公寓，而物是从那里抛下的，本项诉讼可以针对其中任何一人：

### <a id="9.3.2"></a>9.3.2　盖尤斯《评行省告示》第六卷

由于确实无法查明究竟是谁抛下或倾倒了该物，

### <a id="9.3.3"></a>9.3.3　乌尔比安《评告示》第二十三卷

而且每一人均应承担全部责任；但是，如果已经对其中一人提起诉讼，其余人即获免责。

### <a id="9.3.4"></a>9.3.4　保罗《评告示》第十九卷

应以实际受偿之时，而非诉讼成立之时为准；其余人应通过合伙之诉或衡平诉讼，向已清偿者分担损害份额。

### <a id="9.3.5"></a>9.3.5　乌尔比安《评告示》第二十三卷

<a id="9.3.5.pr."></a>

**序言（pr.）** 但是，如果数人分别居住在同一公寓的不同部分，诉讼只针对居住在发生倾倒之部分的人。

<a id="9.3.5.1"></a>

**1.** 如果某人为自己的或其妻子的被释奴与门客无偿提供住所，特雷巴提乌斯说，应以提供住所者本人为其行为负责；此说正确。如果某人向朋友分配若干小客房，也应作相同处理。若经营公寓出租者自己占有其中大部分，则仅由其一人承担责任；但若其只保留一小处住所，而将其余部分出租给多人，则这些人均作为居住在发生抛掷或倾倒的公寓中之人而承担责任。

<a id="9.3.5.2"></a>

**2.** 有时，为避免使原告遭受不利，裁判官应基于衡平，优先针对发生抛掷之房间或外室的居住者授予诉讼，即使同一公寓中有数名居住者亦然；如果物是从公寓中央部分抛下的，更妥当的意见是由所有居住者承担责任。

<a id="9.3.5.3"></a>

**3.** 如果仓库保管人抛下或倾倒某物，或店铺承租人，或仅为在该处工作或授课而租用场所之人如此行事，即可提起事实之诉；即使是其中的工匠或学徒抛下、倾倒物品，也同样适用。

<a id="9.3.5.4"></a>

**4.** 某人因本案已依《阿奎利亚法》之诉被判承担责任时，拉贝奥说，应准许其针对从客房或公寓中抛下物品的人提起此项事实之诉；此说正确。当然，如果该居住者将住所出租给抛掷者，也可以提起租赁之诉。

<a id="9.3.5.5"></a>

**5.** 关于倾倒或抛掷物的此项诉讼不受期间限制，并可由继承人提起，但不得针对继承人提起。若据称自由人因该物死亡，则此项诉讼仅能在一年内提起；不得针对继承人提起，也不得由继承人及类似身份者提起，因为它是刑罚性且属于公众之诉。但我们应知，在多人请求提起该诉讼时，原则上应优先授予与此事有利害关系的人，或与死者有姻亲、血亲关系的人。如果自由人只是受伤，则受伤者本人享有不受期间限制的诉权；其他人若要起诉，则须在一年内提起。该诉权并非依据继承法由继承人取得，因为针对自由人身体所给付的损害赔偿，不应作为继承权利传给继受人；这并非金钱损害，而是基于善与衡平产生的请求。

<a id="9.3.5.6"></a>

**6.** 裁判官规定：“任何人不得在檐廊或屋檐突出部分上方、即众人通常通行或停留之处，放置任何物品，以免该物坠落而可能伤人。违反者，我将授予请求十枚索利杜斯的事实之诉。如果据称奴隶未经主人知情而实施该行为，我将命令交付奴隶以承担诺克萨责任。”（底本文字在 *qua* 后另以引号标出 *quo*。）

<a id="9.3.5.7"></a>

**7.** 此告示是前一告示的补充部分。裁判官有必要进一步考虑此类情形，以便房屋这些部位危险放置的物品不致伤人。

<a id="9.3.5.8"></a>

**8.** 裁判官说：“任何人不得在檐廊或屋檐突出部分上方……” “任何人不得”一语涵盖所有人，无论是承租人还是房屋所有人，无论是否居住其中，只要他们在这些地方放置了某物。

<a id="9.3.5.9"></a>

**9.** “在众人通常通行或停留之处上方放置某物。”我们应理解，这包括放置在住宅、公寓、仓库或其他建筑物中、且位于该处上方的物品。

<a id="9.3.5.10"></a>

**10.** 即使某人并非亲自放置，而是容许他人放置，也应认为其持有放置之物。因此，如果奴隶放置了某物，而主人容许该物留在那里，主人应以本人名义承担责任，而非承担诺克萨之诉责任。

<a id="9.3.5.11"></a>

**11.** 裁判官说：“其坠落可能伤人之物。”由此可见，裁判官所考虑的并非所有放置之物，而仅是以可能伤人的方式放置之物，并意在防止其造成伤害。是否实际造成伤害并不重要，只要存在造成伤害的可能性，就适用告示。放置该物者均受制裁，无论该物是否实际造成损害。

<a id="9.3.5.12"></a>

**12.** 如果放置之物坠落并造成损害，诉讼应针对放置该物的人，而非居住者；似乎本项诉讼不足以救济此情形，因为除非放置者是房屋所有人或居住者，否则不应认为其持有该放置之物。例如，画师在画廊中陈列盾牌或画板，物品坠落并损害行人财物时，塞尔维乌斯答复说，应类比本诉讼而授予一项诉讼；显然本项诉讼并不适用，因为画板既非放置在檐廊，也非置于屋檐突出部分上方。若有陶罐悬挂在网袋中，后来坠落并造成损害，也应遵循同一答复，因为无论市民法诉讼还是裁判官法诉讼均无法适用。

<a id="9.3.5.13"></a>

**13.** 此项诉讼属于公众之诉，继承人及类似身份者也可以提起；但不得针对继承人提起，因为它具有刑罚性质。

### <a id="9.3.6"></a>9.3.6　保罗《评告示》第十九卷

<a id="9.3.6.pr."></a>

**序言（pr.）** 此告示不仅适用于城市与村镇，也适用于众人通常通行的道路。

<a id="9.3.6.1"></a>

**1.** 拉贝奥说，此告示适用于白天发生的抛掷行为，而不适用于夜间；但有些地方夜间也有人通行。

<a id="9.3.6.2"></a>

**2.** 居住者应对自己及其所属之人的过错负责。

<a id="9.3.6.3"></a>

**3.** 如果物品是从船上抛下的，应对船舶管理人授予准用之诉。

### <a id="9.3.7"></a>9.3.7　盖尤斯《评行省告示》第六卷

当抛下或倾倒之物损伤自由人的身体时，法官应计算支付给医生的费用及治疗所支出的其他费用；此外，还应计算其因受伤而丧失或将丧失的劳务报酬。至于疤痕或毁容，不作估价，因为自由人的身体不能估价。
