# D.48.7–D.48.13　私人暴力、杀人及公共犯罪

> 底本：*Digesta Iustiniani*，EPUB `book-48.xhtml`，source-p 546–937。

## D.48.7　论《尤利亚私人暴力法》

<!-- source-p 0546 -->
<a id="7"></a><a id="48.7"></a>**48.7.0**　论《尤利亚私人暴力法》。

<!-- source-p 0547 -->
<a id="48.7.1"></a>**48.7.1**

<!-- source-p 0548 -->
马尔基安《法学阶梯》第十四卷。

<!-- source-p 0549 -->
<a id="48.7.1.pr."></a>**序言**　依《尤利亚法》，因私暴力被判罪者，其财产的三分之一应予没收；并规定其不得担任元老、不得担任城邦议员或任何荣誉职位，不得列入这些等级，也不得担任法官。显然，根据元老院决议，他将如同遭受不名誉判决者一样，被剥夺一切荣誉身份。

<!-- source-p 0550 -->
<a id="48.7.1.1"></a>**1**　依同一刑罚处罚者，还包括被判处《尤利亚私人暴力法》刑罚的人；某人若出于恶意从海难船只上抢夺财物，也适用该法。

<!-- source-p 0551 -->
<a id="48.7.1.2"></a>**2**　皇帝敕令还规定，对那些从海难船只上掠夺财物的人，应依非常程序予以处罚。神圣的庇护皇帝曾以复函指出，不得对水手施加任何暴力；若有人施暴，应从严惩处。

<!-- source-p 0552 -->
<a id="48.7.2"></a>**48.7.2**

<!-- source-p 0553 -->
斯凯沃拉《规则集》第四卷。

<!-- source-p 0554 -->
凡召集人群实施暴力，以致有人遭受鞭打或殴打、但无人被杀的，均受本法追究。

<!-- source-p 0555 -->
<a id="48.7.3"></a>**48.7.3**

<!-- source-p 0556 -->
马克尔《公诉法》第一卷。

<!-- source-p 0557 -->
<a id="48.7.3.pr."></a>**序言**　召集自由人或奴隶、自己的人或他人的人来实施暴力，并无区别。

<!-- source-p 0558 -->
<a id="48.7.3.1"></a>**1**　同样，受召集前来的人也依同一法律承担责任。

<!-- source-p 0559 -->
<a id="48.7.3.2"></a>**2**　即使无人被召集、无人被殴打，但有人以暴力从他人财产中取走某物，实施该行为的人仍受本法追究。

<!-- source-p 0560 -->
<a id="48.7.4"></a>**48.7.4**

<!-- source-p 0561 -->
保罗《告示评注》第五十五卷。

<!-- source-p 0562 -->
<a id="48.7.4.pr."></a>**序言**　据称，若有人为阻止某人被押送至法庭而聚集人群并煽动围堵，即构成《尤利亚私人暴力法》之罪。

<!-- source-p 0563 -->
<a id="48.7.4.1"></a>**1**　如果有人对他人的奴隶进行审讯，拉贝奥说，应较为克制地适用裁判官关于侵害的告示。

<!-- source-p 0564 -->
<a id="48.7.5"></a>**48.7.5**

<!-- source-p 0565 -->
乌尔比安《告示评注》第六十九卷。

<!-- source-p 0566 -->
若有人召集一群未持武器的人，将另一人驱逐出其土地，可以对其提出私暴力罪指控。

<!-- source-p 0567 -->
<a id="48.7.6"></a>**48.7.6**

<!-- source-p 0568 -->
莫德斯丁《规则集》第八卷。

<!-- source-p 0569 -->
依《沃卢西亚努斯元老院决议》，那些恶意加入他人诉讼，并约定分享判决后为自己取得的财物的人，依《尤利亚私人暴力法》承担责任。

<!-- source-p 0570 -->
<a id="48.7.7"></a>**48.7.7**

<!-- source-p 0571 -->
卡利斯特拉图斯《审判论》第五卷。

<!-- source-p 0572 -->
债权人若对自己的债务人提起诉讼，应通过法官请求返还其认为应得之物；否则，若未经任何人许可而进入债务人的财产，神圣的马可皇帝曾裁定，他们将丧失债权。裁定原文如下：“最佳做法是：如果你认为自己享有请求权，就应通过诉讼主张；在此期间，他应继续占有该物，而你是请求人。”马尔基安辩称：“我并未使用任何暴力。”皇帝答道：“你认为只有使人受伤才算暴力吗？凡有人不经法官而自行请求其认为应得之物，也属于暴力。我认为，你的谦恭、尊严和虔敬均不容许你实施任何不合法之事。因此，凡经证明有人未经债务人亲手交付、又未经过任何司法程序，便轻率地占有债务人的任何财物并自称对该物享有权利，此人将丧失其债权。”

<!-- source-p 0573 -->
<a id="48.7.8"></a>**48.7.8**

<!-- source-p 0574 -->
莫德斯丁《刑罚论》第二卷。

<!-- source-p 0575 -->
债权人若未经法官授权而占有债务人的财物，应依本法承担责任、被处以其财产三分之一的罚金，并被判处不名誉。

## D.48.8　论《科尔内利亚杀人及投毒法》

<!-- source-p 0576 -->
<a id="8"></a><a id="48.8"></a>**48.8.0**　论《科尔内利亚杀人及投毒法》。

<!-- source-p 0577 -->
<a id="48.8.1"></a>**48.8.1**

<!-- source-p 0578 -->
马尔基安《法学阶梯》第十四卷。

<!-- source-p 0579 -->
<a id="48.8.1.pr."></a>**序言**　依《科尔内利亚杀人及投毒法》，杀害他人者、出于恶意纵火者、携带武器以杀人或秘密实施盗窃者，均承担责任。身为官员或主持公审者，若帮助他人作虚假陈述，致使无辜者遭到起诉或定罪，也承担责任。

<!-- source-p 0580 -->
<a id="48.8.1.1"></a>**1**　此外，为杀人而制造或给予毒物者，为使某人在公审中被判处死刑而故意作伪证者，以及作为官员或审讯法官、为使某人依公诉法被追责而收受钱财者，也承担责任。

<!-- source-p 0581 -->
<a id="48.8.1.2"></a>**2**　杀人者均受处罚，不因被杀者的身份地位而有区别。

<!-- source-p 0582 -->
<a id="48.8.1.3"></a>**3**　神圣的哈德良曾以复函指出，某人虽杀了人，但若其并无杀人故意，可以宣告无罪；某人虽未杀人，但为杀人而伤害他人的，应作为杀人犯定罪。此事应根据具体情节判断：若其拔剑并以剑击人，毫无疑问，他是出于杀人故意实施该行为；但若其在争斗中用钉状铁器（*clavi*）或锅具（*cuccuma*）击人，即使所用者为铁器，也并非出于杀人故意。争斗中主要因偶然而非出于意愿杀人的，应减轻其刑罚。

<!-- source-p 0583 -->
<a id="48.8.1.4"></a>**4**　神圣的哈德良还曾以复函指出，杀死以暴力对自己或自己家属实施强奸的人，应予释放。

<!-- source-p 0584 -->
<a id="48.8.1.5"></a>**5**　神圣的庇护皇帝还写道，杀死当场捉获的通奸妻子的丈夫应受较轻刑罚：身份低微者应被永久放逐，担任较高职位者则应限期迁居。

<!-- source-p 0585 -->
<a id="48.8.2"></a>**48.8.2**

<!-- source-p 0586 -->
乌尔比安《论通奸》第一卷。

<!-- source-p 0587 -->
父亲不得未经审讯便杀死儿子，而应向城市长官或行省总督控告他。

<!-- source-p 0588 -->
<a id="48.8.3"></a>**48.8.3**

<!-- source-p 0589 -->
马尔基安《法学阶梯》第十四卷。

<!-- source-p 0590 -->
<a id="48.8.3.pr."></a>**序言**　《科尔内利亚杀人及投毒法》第五章规定，为杀人而制造、出售或持有毒物的人应受惩处。

<!-- source-p 0591 -->
<a id="48.8.3.1"></a>**1**　在公共场所出售有害药物，或为杀人而持有此类药物的人，也受同一法律的刑罚。

<!-- source-p 0592 -->
<a id="48.8.3.2"></a>**2**　该法加上“有害毒物”一语，表明有些毒物并非有害。因此，“毒物”是一个中性名称，既包括为治病而配制的，也包括为杀人而配制的，还包括所谓媚药；但该法只关注为杀人目的而持有的毒物。元老院决议还规定，对一名妇女予以迁居处罚：她虽无恶意，却以恶劣示范的方式给人服用助孕药物，致使服药者死亡。

<!-- source-p 0593 -->
<a id="48.8.3.3"></a>**3**　另一项元老院决议规定，药剂商若轻率地将毒芹、蝾螈、乌头、松毛虫（*pituocampas*）、牛虻虫（*bubrostim*）、曼陀罗等交给他人，或为净化之目的交付斑蝥，应受本法处罚。

<!-- source-p 0594 -->
<a id="48.8.3.4"></a>**4**　此外，某人的家奴在其知情下为取得或恢复占有而持械，煽动叛乱者，掩盖海难者，作虚假陈述或安排虚假陈述以陷害无辜者，以及为淫欲或牟利而阉割他人者，依元老院决议受《科尔内利亚法》处罚。

<!-- source-p 0595 -->
<a id="48.8.3.5"></a>**5**　《科尔内利亚杀人及投毒法》的刑罚是流放至岛屿并没收全部财产。不过，现今通常处以死刑，除非行为人出身较高，以致应按该法规定的刑罚处罚：身份低微者通常被投入野兽，身份较高者则被流放至岛屿。

<!-- source-p 0596 -->
<a id="48.8.3.6"></a>**6**　逃亡至敌方的人，无论在何处被发现，均可被当作敌人杀死。

<!-- source-p 0597 -->
<a id="48.8.4"></a>**48.8.4**

<!-- source-p 0598 -->
乌尔比安《论总督职责》第七卷。

<!-- source-p 0599 -->
<a id="48.8.4.pr."></a>**序言**　身任官职者若实施法律所不允许的、涉及杀害他人的行为，应依《科尔内利亚杀人法》承担责任。

<!-- source-p 0600 -->
<a id="48.8.4.1"></a>**1**　某人因放纵行事造成他人死亡，神圣的哈德良认可了贝蒂卡行省总督伊格纳提乌斯·陶鲁斯的处理：对该人处以五年迁居处罚。

<!-- source-p 0601 -->
<a id="48.8.4.2"></a>**2**　同一位神圣的哈德良曾作如下复函：“确已规定，不得制造阉人；被控犯有此罪者，应依《科尔内利亚法》处罚，其财产也理应归入我的国库。实施阉割的奴隶也应受最严厉的刑罚。被控犯有此罪者若未到庭，也应缺席判决，按《科尔内利亚法》追究。显然，若遭受此种侵害的人亲自提出申诉，行省总督应当听取那些丧失男性生殖能力者的申诉；因为任何人都不得阉割自由人或奴隶，无论其同意与否，也不得让他人自愿阉割自己。若有人违反我的敕令，实施切除的医生应处死刑；自愿接受切除的人也应处以同样刑罚。”

<!-- source-p 0602 -->
<a id="48.8.5"></a>**48.8.5**

<!-- source-p 0603 -->
保罗《论总督职责》第二卷。

<!-- source-p 0604 -->
依神圣的哈德良致尼尼乌斯·哈斯塔的敕令，实施 *thlibias*（挤压式阉割）的人，与实施阉割者承担相同责任。

<!-- source-p 0605 -->
<a id="48.8.6"></a>**48.8.6**

<!-- source-p 0606 -->
维诺尼乌斯《论总督职责》第一卷。

<!-- source-p 0607 -->
依涅拉提乌斯·普里斯库斯与安尼乌斯·维鲁斯任执政官时作出的元老院决议，交付自己的奴隶供人阉割者，应被处以其财产二分之一的罚金。

<!-- source-p 0608 -->
<a id="48.8.7"></a>**48.8.7**

<!-- source-p 0609 -->
保罗《公诉法》单行卷。

<!-- source-p 0610 -->
在《科尔内利亚法》中，故意可以视同行为本身；该法并不将重大过失视为故意。因此，若有人从高处跳下，落在另一个人身上并将其压死；或者修枝人从树上砍下树枝时没有事先喊告，致使经过者被砸死，这些情形均不属于该法的惩罚范围。

<!-- source-p 0611 -->
<a id="48.8.8"></a>**48.8.8**

<!-- source-p 0612 -->
乌尔比安《告示评注》第三十三卷。

<!-- source-p 0613 -->
若查明某妇女对自己的身体内部施加暴力以促使胎儿流产，行省总督应将她放逐。

<!-- source-p 0614 -->
<a id="48.8.9"></a>**48.8.9**

<!-- source-p 0615 -->
乌尔比安《告示评注》第三十七卷。

<!-- source-p 0616 -->
若有人杀死夜间窃贼，只有在不危及自身安全便无法饶其性命时，才可免受处罚。

<!-- source-p 0617 -->
<a id="48.8.10"></a>**48.8.10**

<!-- source-p 0618 -->
乌尔比安《告示评注》第十八卷。

<!-- source-p 0619 -->
若有人出于恶意烧毁我的公寓楼（*insula*），应作为纵火犯处以死刑。

<!-- source-p 0620 -->
<a id="48.8.11"></a>**48.8.11**

<!-- source-p 0621 -->
莫德斯丁《规则集》第六卷。

<!-- source-p 0622 -->
<a id="48.8.11.pr."></a>**序言**　神圣的庇护皇帝曾以复函仅准许犹太人割除自己儿子的包皮；其他宗教信仰者若这样做，应处以阉割者所受的刑罚。

<!-- source-p 0623 -->
<a id="48.8.11.1"></a>**1**　未经法官裁定而将奴隶交付野兽的人，不仅出售奴隶者承担责任，买受者也承担责任。

<!-- source-p 0624 -->
<a id="48.8.11.2"></a>**2**　《佩特罗尼乌斯法》及有关该法的元老院决议颁布后，主人已无权自行决定将奴隶交给野兽搏斗。不过，若主人将奴隶交给法官，且其申诉理由正当，奴隶仍应被交付受罚。

<!-- source-p 0625 -->
<a id="48.8.12"></a>**48.8.12**

<!-- source-p 0626 -->
莫德斯丁《规则集》第八卷。

<!-- source-p 0627 -->
婴儿或精神错乱者杀人，不受《科尔内利亚法》追究：前者受其无犯罪意图所保护，后者则因命运不幸而获免责。

<!-- source-p 0628 -->
<a id="48.8.13"></a>**48.8.13**

<!-- source-p 0629 -->
莫德斯丁《法学汇编》第十二卷。

<!-- source-p 0630 -->
元老院决议规定，实施或持有邪恶祭仪者应依该法受罚。

<!-- source-p 0631 -->
<a id="48.8.14"></a>**48.8.14**

<!-- source-p 0632 -->
卡利斯特拉图斯《审判论》第六卷。

<!-- source-p 0633 -->
神圣的哈德良曾作如下复函：“犯罪时应考察行为意图，而非结果。”

<!-- source-p 0634 -->
<a id="48.8.15"></a>**48.8.15**

<!-- source-p 0635 -->
乌尔比安《尤利亚与帕比亚法评注》第八卷。

<!-- source-p 0636 -->
某人杀人，还是造成他人死亡的原因，并无区别。

<!-- source-p 0637 -->
<a id="48.8.16"></a>**48.8.16**

<!-- source-p 0638 -->
莫德斯丁《刑罚论》第三卷。

<!-- source-p 0639 -->
自愿或出于恶意实施杀戮的人，若担任某种高级职位，通常被流放至岛屿；若属于次一等级，则处死刑。对城邦议员更容易适用此规定，但必须事先征求皇帝意见并获得其命令；除非只有如此才能平息骚乱。

<!-- source-p 0640 -->
<a id="48.8.17"></a>**48.8.17**

<!-- source-p 0641 -->
保罗《判例集》第五卷。

<!-- source-p 0642 -->
若有人在争斗中遭到击打后死亡，应考察聚集者中每个人所施加的击打。

## D.48.9　论《庞培弑亲法》

<!-- source-p 0643 -->
<a id="9"></a><a id="48.9"></a>**48.9.0**　论《庞培弑亲法》。

<!-- source-p 0644 -->
<a id="48.9.1"></a>**48.9.1**

<!-- source-p 0645 -->
马尔基安《法学阶梯》第十四卷。

<!-- source-p 0646 -->
《庞培弑亲法》规定，杀害或出于恶意使他人杀害其父、母、祖父、祖母、兄弟、姐妹、堂表兄弟姐妹、伯叔、舅父、姑母、表亲、妻子、丈夫、女婿、岳母、继父、继子女、保护人或女保护人的，适用《科尔内利亚杀人法》的刑罚。杀害儿子或女儿的母亲也受该法处罚；杀害孙辈的祖父亦然。此外，为交给父亲服用而购买毒药的人，即使最终未能交付，也承担责任。

<!-- source-p 0647 -->
<a id="48.9.2"></a>**48.9.2**

<!-- source-p 0648 -->
斯凯沃拉《规则集》第四卷。

<!-- source-p 0649 -->
仅仅知情却未告知父亲的兄弟，被处以迁居处罚；医生则被处以刑罚。

<!-- source-p 0650 -->
<a id="48.9.3"></a>**48.9.3**

<!-- source-p 0651 -->
马尔基安《法学阶梯》第十四卷。

<!-- source-p 0652 -->
但应知，《庞培法》虽将表亲包括在内，却未同样涵盖与其亲等相同或更近的人。该法虽遗漏继母和未婚妻，但依其立法意旨也应包括她们。

<!-- source-p 0653 -->
<a id="48.9.4"></a>**48.9.4**

<!-- source-p 0654 -->
马尔基安《公诉法》第一卷。

<!-- source-p 0655 -->
未婚夫或未婚妻的父母，包含在“岳父母”这一称谓之内；同样，未婚夫或未婚妻也包含在“子女”及“女婿或儿媳”的称谓之内。

<!-- source-p 0656 -->
<a id="48.9.5"></a>**48.9.5**

<!-- source-p 0657 -->
马尔基安《法学阶梯》第十四卷。

## D.48.10　论《科尔内利亚伪造法》与《利波尼安元老院决议》

<!-- source-p 0676 -->
<a id="10"></a><a id="48.10"></a>**48.10.0**　论《科尔内利亚伪造法》与《利波尼安元老院决议》。

<!-- source-p 0677 -->
<a id="48.10.1"></a>**48.10.1**

<!-- source-p 0678 -->
马尔基安《法学阶梯》第十四卷。

<!-- source-p 0679 -->
<a id="48.10.1.pr."></a>**序言**　依《科尔内利亚法》，恶意召集他人制作虚假见证文书或审查虚假证词者，应受处罚。

<!-- source-p 0680 -->
<a id="48.10.1.1"></a>**1**　此外，为准备辩护或提供证词而收受钱财，或约定收受钱财，或者结成团伙以使无辜者承担责任的，依元老院决议予以惩处。

<!-- source-p 0681 -->
<a id="48.10.1.2"></a>**2**　若有人为撤回或放弃证词、作证或不作证而收受钱财，也应受《科尔内利亚法》的刑罚。贿赂法官或安排他人贿赂法官的，也一样。

<!-- source-p 0682 -->
<a id="48.10.1.3"></a>**3**　法官若无视元首敕令，也应受罚。

<!-- source-p 0683 -->
<a id="48.10.1.4"></a>**4**　在账目、簿册、蜡板或其他载体中，未经核验便伪造内容或移走某物的人，应按照伪造者处罚。神圣的塞维鲁也曾依《科尔内利亚伪造法》判处埃及总督；该总督在任职期间伪造了自己的文书。

<!-- source-p 0684 -->
<a id="48.10.1.5"></a>**5**　打开仍在世之人遗嘱的人，应受《科尔内利亚法》的刑罚。

<!-- source-p 0685 -->
<a id="48.10.1.6"></a>**6**　若有人声称自己交由他人保管的文书被该人泄露给自己的对手，可以控告该人犯伪造罪。

<!-- source-p 0686 -->
<a id="48.10.1.7"></a>**7**　元老院决议也适用于军人遗嘱：擅自在遗嘱中为自己记载遗赠或遗嘱信托者，依《科尔内利亚法》承担责任。

<!-- source-p 0687 -->
<a id="48.10.1.8"></a>**8**　遗嘱由儿子、奴隶或外人书写，三者有所区别。若是外人书写，只有在立遗嘱人特别签署“我口授并确认了其所写内容”时，才免受处罚且可以取得遗赠；若是儿子或奴隶书写，立遗嘱人的概括性签署即足以使其免罚并取得遗赠。

<!-- source-p 0688 -->
<a id="48.10.1.9"></a>**9**　神圣的塞维鲁与安敦尼二帝还规定，监护人、保佐人，以及卸任后尚未交清监护或保佐账目的人，不得与国库订立契约；若有人违反此法而欺骗国库，应按伪造罪处罚。

<!-- source-p 0689 -->
<a id="48.10.1.10"></a>**10**　二帝的复函指出，这一规定不适用于在接受监护职责之前已经进行上述行为的人；这不是承认其抗辩，而是排除欺诈情形。

<!-- source-p 0690 -->
<a id="48.10.1.11"></a>**11**　二帝还曾以复函指出，尚未交清监护或保佐账目的人，只有在受其监护的人仍然在世时，才不得与国库订立契约；若受监护人已经死亡，即使尚未向其继承人交账，该监护人仍可依法与国库订约。

<!-- source-p 0691 -->
<a id="48.10.1.12"></a>**12**　监护人或保佐人若以继承人身份继受其与国库之间的契约，即使尚未交账，我认为也不适用该刑罚，即使受监护人仍然在世亦然。

<!-- source-p 0692 -->
<a id="48.10.1.13"></a>**13**　伪造罪或准伪造罪的刑罚是流放至岛屿并没收全部财产；奴隶若实施其中任何行为，应处最严厉的刑罚。

保罗《疑问集》第二十二卷。

<!-- source-p 0740 -->
<a id="48.10.14.pr."></a>**序言**　某位已脱离父权的儿子替父亲书写遗嘱，并依父亲命令，将遗赠记载给提提乌斯与自己共有的奴隶。有人问此问题应如何处理。答复说：你把几个问题合在了一起。就元老院决议而言，该决议禁止为自己或处于自己权力下的人记载遗赠；已脱离父权的儿子即使依父亲命令书写，也仍受同一刑罚。不过，处于父权之下的人若能证明遗嘱人签署确认了其命令，则可像奴隶一样免责；我确实发现元老院曾如此裁定。

<!-- source-p 0741 -->
<a id="48.10.14.1"></a>**1**　接下来的问题是：既然非法写入的内容视为未写，写给遗嘱书写人与他人共有奴隶的遗赠，究竟应全部视为未写，还是仅就书写人所占份额视为未写、而由共有者取得全部遗赠？我发现马尔凯卢斯在尤利安著作中对此作过批注。尤利安曾说，若某人为自己和提提乌斯，或为自己与共同奴隶写入遗赠，因该内容视为未写，最容易的问题是：提提乌斯或共有者可取得多少？马尔凯卢斯接着问：如果奴隶的姓名被当作伪造而删去，共有者又如何取得遗赠？当前问题也应遵循这一意见。

<!-- source-p 0742 -->
<a id="48.10.14.2"></a>**2**　丈夫解放了一名嫁资奴隶，并在该奴隶的遗嘱中为自己记载遗赠。有人问妻子依据《尤利亚法》可以取得何种救济。我答复说，应认定保护人也触犯了神圣的克劳狄乌斯敕令；已脱离父权的儿子也适用此规则，尽管他们可能作为被遗漏者请求遗产占有。若保护人未从被释奴的遗产中取得任何财物，就不对妻子承担责任。是否因为法律还规定“或以欺诈方式阻止该财物归其所有”，便可令其承担责任？但他并未欺诈妻子，因为他并非针对她而安排此事。是否因为他将把所得返还他人，我们就不应否认妻子诉权？然而，若某人依立遗嘱人命令为自己记载遗赠，即便立遗嘱人同样命其将遗赠返还他人，元老院仍命其放弃遗赠，并令遗赠留在继承人处，同时负担遗嘱信托义务。

<!-- source-p 0743 -->
<a id="48.10.15"></a>**48.10.15**

<!-- source-p 0744 -->
卡利斯特拉图斯《疑问集》第一卷。

<!-- source-p 0745 -->
<a id="48.10.15.pr."></a>**序言**　神圣的克劳狄乌斯曾以敕令规定，在《科尔内利亚法》中增添一项规则：若有人替他人书写遗嘱或附录，却亲笔为自己写入遗赠，应如同触犯《科尔内利亚法》一样承担责任；不得宽恕那些声称不知该敕令严厉规定的人。所谓为自己书写遗赠，不仅指亲笔写入，也包括立遗嘱人口授遗赠、由该人通过自己的奴隶或处于其权力下的儿子取得遗赠。

<!-- source-p 0746 -->
<a id="48.10.15.1"></a>**1**　元首敕令规定，若立遗嘱人特别签署确认自己曾口授命某人的奴隶将遗赠给予其主人，该遗赠有效；但立遗嘱人的概括签署不能对抗元老院决议的效力，因此遗赠仍应视为未写入。即使奴隶亲笔为自己记载遗赠，也可以获准宽免。我认为，较稳妥的做法是请求皇帝宽免，并由受遗赠人放弃所留遗赠。

<!-- source-p 0747 -->
<a id="48.10.15.2"></a>**2**　元老院还裁定，奴隶若依主人命令在遗嘱或附录中亲笔为自己写入自由条款，不因此获得自由；但其自由应以遗嘱信托方式给予，前提是立遗嘱人在奴隶写入后亲笔签署该遗嘱或附录。

<!-- source-p 0748 -->
<a id="48.10.15.3"></a>**3**　该元老院决议原本只涉及遗嘱信托方式给予自由的情形，神圣的庇护皇帝却以复函指出，应当遵循该决议的意旨而非其字面：奴隶服从主人，是出于权力关系带来的必然；若主人签署确认自己口授并认可该内容，奴隶应因此免责，因为该内容应视为主人亲笔所写，且系依其意愿写成。不过，庇护皇帝说：“这一规则不得扩及立遗嘱人对其不享有任何权利的自由人；但仍须考察，对于实施未获准许之事的人，服从命令的必要性是否同样构成正当免责理由。”

<!-- source-p 0749 -->
<a id="48.10.15.4"></a>**4**　若母亲通过其奴隶书写、且系儿子口授为自己记载遗赠，也应准许其依《科尔内利亚法》获得宽免。

<!-- source-p 0750 -->
<a id="48.10.15.5"></a>**5**　元老院还裁定，女儿若因不知法律，经母亲口授而为自己写入遗赠，也应适用同一规则。

<!-- source-p 0751 -->
<a id="48.10.15.6"></a>**6**　若有人指定两名继承人，并附加条件：其中一人无子女而死时，遗产返还给仍在世且有子女的另一人；若二人均无子女而死，遗产则由遗嘱书写人取得（该部分为另一人手书），则应免除遗嘱书写人依《科尔内利亚法》所受的刑罚。较宽厚的做法是，也让其依同一方式取得上述遗赠。

<!-- source-p 0755 -->

<!-- source-p 0756 -->

<!-- source-p 0776 -->
<a id="48.10.22.pr."></a>**序言**　不应认为未适婚人受本敕令约束，因为其很难承担伪造罪责任；未适婚年龄的人不具备恶意故意。

<!-- source-p 0777 -->
<a id="48.10.22.1"></a>**1**　父亲若在被敌人俘获的儿子的遗嘱中为其记载遗赠，应认为儿子归来后父亲才受元老院决议的刑罚；若儿子在敌方死亡，则父亲无罪。

<!-- source-p 0778 -->
<a id="48.10.22.2"></a>**2**　父亲也可以为已经脱离父权的儿子记载遗赠；为被收养的儿子记载亦然。

<!-- source-p 0779 -->
<a id="48.10.22.3"></a>**3**　父亲若为一名奴隶记载遗赠，而自己曾拖延履行该奴隶的遗嘱信托解放义务，应认为不受元老院决议约束；因为公认，此类奴隶所取得的一切，在其获释时均应返还给他。

<!-- source-p 0780 -->
<a id="48.10.22.4"></a>**4**　若有人为一名善意服役的奴隶记载遗赠，虽然这在主观上有害于书写人，因为他为自己认为属于自己的奴隶写入遗赠；但善意占有人并不取得遗赠或继承，因此应认为书写人免受刑罚。

<!-- source-p 0781 -->
<a id="48.10.22.5"></a>**5**　主人为自己的奴隶记载遗赠，并规定其在获得自由时才能取得该遗赠的，应认为主人可依元老院决议免责，因为他绝无可能因此使自己受益。对后来脱离父权的儿子，也可作同样判断。

<!-- source-p 0782 -->
<a id="48.10.22.6"></a>**6**　某人确认了在遗嘱之前订立、且为其记载遗赠的附录，也应受元老院决议约束；尤利安也如此写道。

<!-- source-p 0783 -->
<a id="48.10.22.7"></a>**7**　亲手撤销某项遗赠的人，也应受罚，视同其为自己取得了某物。例如，某人受遗赠一名奴隶并已将其解放，随后亲笔剥夺其自由；若系依立遗嘱人意愿剥夺，则受罚；若立遗嘱人不知情，奴隶的自由仍有效。又如，某人受命返还为自己记载的遗赠，却亲手撤销了该遗嘱信托，也同样受罚。

<!-- source-p 0784 -->
<a id="48.10.22.8"></a>**8**　某人亲笔为自己写入被释奴的指定，不落入元老院决议的字面范围，但受其立法意旨约束。

<!-- source-p 0785 -->
<a id="48.10.22.9"></a>**9**　奴隶若在他人遗嘱中为自己写入遗嘱信托方式给予的自由条款，按文字并未被该决议涵盖。但对此可能有疑问：如前所述，元老院仅在主人签署确认时，才免除奴隶在主人遗嘱中为自己写入遗嘱信托自由条款的刑罚。实际上，更应认定此奴隶违反了元老院决议，甚至比为自己记载遗赠的人更甚；因为自由无论如何都归奴隶本人，而遗赠却可能归主人取得。

<!-- source-p 0786 -->
<a id="48.10.22.10"></a>**10**　遗嘱书写人若为自己的奴隶指定遗嘱信托方式的自由，似乎应不受刑罚，因为他并无任何个人利益；但若其如此记载，是为了使奴隶以高价从自己处赎买自由，则属例外。

<!-- source-p 0787 -->
<a id="48.10.22.11"></a>**11**　遗嘱将土地遗赠给提提乌斯，书写人却亲笔加上“应向我支付钱款”的条件，也落入元老院决议的范围。

<!-- source-p 0788 -->
<a id="48.10.22.12"></a>**12**　某人依父亲意愿自愿将自己剥夺继承权，或撤销为自己记载的遗赠，不受元老院决议文字或意旨的约束。

<a id="48.11.6"></a>**48.11.6**

<!-- source-p 0844 -->
维努莱乌斯·萨图尔尼努斯《公诉法》第三卷。

<!-- source-p 0845 -->
<a id="48.11.6.pr."></a>**序言**　为告发或不告发证词而收受钱财的人，也受同一法律追究。

<!-- source-p 0846 -->
<a id="48.11.6.1"></a>**1**　依该法被定罪的人，不得在公诉案件中作证，也不得担任法官或行使诉讼陈述权。

<!-- source-p 0847 -->
<a id="48.11.6.2"></a>**2**　《尤利亚追索非法所得法》还规定，任何人不得为征募或派遣士兵而收受铜钱，也不得为在元老院或公共议事会发表意见、或为提出或不提出控告而收受钱财；城市官员应避免一切卑劣牟利，每年收受的礼品或酬谢不得超过一百奥里。

<!-- source-p 0848 -->
<a id="48.11.7"></a>**48.11.7**

<!-- source-p 0849 -->
马克尔《公诉法》第一卷。

<!-- source-p 0850 -->
<a id="48.11.7.pr."></a>**序言**　《尤利亚追索非法所得法》规定，任何人不得为指定、更换法官或仲裁人，或命令其作出裁判而收受钱财；也不得为不指定、不更换或不命令其作出裁判而收受钱财；不得为将某人投入公牢、捆绑或命令捆绑、或从羁押中释放而收受钱财；不得为判处或宣告某人无罪而收受钱财；也不得为评定争议标的价值，或作出或不作出涉及死刑或金钱的裁判而收受任何财物。

<!-- source-p 0851 -->
<a id="48.11.7.1"></a>**1**　由此可见，该法虽然允许对列明的例外对象无限额收受钱财，但对于本款列举的其他人，任何人均不得收受任何金额。

<!-- source-p 0852 -->
<a id="48.11.7.2"></a>**2**　该法还规定，公共工程尚未依法律完成、验收并交付之前，不得将其记作已完成；公共粮食的发放、供应或征收，以及公共建筑修缮，也不得在依法完成、核验并交付之前记账。

<!-- source-p 0853 -->
<a id="48.11.7.3"></a>**3**　如今，依追索非法所得法，通常以非常程序处罚，且多处以放逐或更严厉的刑罚，视其行为而定。若其为杀人而收受钱财，或虽未收钱，却一时激愤杀死无辜者或不应受罚者，又当如何？此类人应处死刑，至少也应被流放至岛屿；许多人已受到这种处罚。

<!-- source-p 0854 -->
<a id="48.11.8"></a>**48.11.8**

<!-- source-p 0855 -->
保罗《告示评注》第五十四卷。

<!-- source-p 0856 -->
<a id="48.11.8.pr."></a>**序言**　行省总督或裁判官违反追索非法所得法而收受的赠与，不能通过时效取得所有权。

<!-- source-p 0857 -->
<a id="48.11.8.1"></a>**1**　同一法律也使为此目的而以高价或低价进行的买卖或租赁无效，并阻止取得时效；直到该物返还给交付该物的人或其继承人时，取得时效方可开始。

<!-- source-p 0858 -->
<a id="48.11.9"></a>**48.11.9**

<!-- source-p 0859 -->
帕皮尼安《答复集》第十五卷。

<!-- source-p 0860 -->
官员接受钱财后放弃受托的公共职务者，应以追索非法所得罪起诉。

## D.48.12　论《尤利亚粮食供应法》

<!-- source-p 0861 -->
<a id="12"></a><a id="48.12"></a>**48.12.0**　论《尤利亚粮食供应法》。

<!-- source-p 0862 -->
<a id="48.12.1"></a>**48.12.1**

<!-- source-p 0863 -->
马尔基安《法学阶梯》第二卷。

<!-- source-p 0864 -->
若奴隶声称主人侵害了公共粮食供应，可以在奴隶与主人之间成立诉讼关系。

乌尔比安《论总督职责》第九卷。

<!-- source-p 0867 -->
<a id="48.12.2.pr."></a>**序言**　依《尤利亚粮食供应法》，任何人若采取损害粮食供应的行为，或结成团体使粮价上涨，应受处罚。

<!-- source-p 0868 -->
<a id="48.12.2.1"></a>**1**　同一法律还规定，任何人不得扣留船舶或水手，也不得出于恶意使其遭到扣留。

<!-- source-p 0869 -->
<a id="48.12.2.2"></a>**2**　该法规定处以二十奥里罚金。

<!-- source-p 0870 -->
<a id="48.12.3"></a>**48.12.3**

帕皮里乌斯《皇帝敕令论》第一卷。

<a id="48.12.3.pr."></a>**序言**　皇帝安敦尼与维鲁斯曾以如下措辞作出复函：“要求城邦议员以低于粮食市价的价格向本城公民出售粮食，极不公平。”

<!-- source-p 0873 -->
<a id="48.12.3.1"></a>**1**　他们还指出，城邦议员团体无权自行规定所发现粮食的价格。他们另以如下措辞复函：“虽然妇女通常不从事此类告发，但既然你承诺将揭示与粮食供应利益有关之事，你可以告知粮食供应长官。”

## D.48.13　论《尤利亚侵吞公款法》、渎神罪与公款余额

<!-- source-p 0874 -->
<a id="13"></a><a id="48.13"></a>**48.13.0**　论《尤利亚侵吞公款法》、渎神罪及公款余额。

<!-- source-p 0875 -->
<a id="48.13.1"></a>**48.13.1**

<!-- source-p 0876 -->
乌尔比安《萨宾评注》第四十四卷。

<!-- source-p 0877 -->
《尤利亚侵吞公款法》规定，任何人不得取走、截留或据为己有神圣、宗教或公共钱款，也不得使他人实施这些行为，除非法律明确准许；任何人也不得向公共金、银、铜中掺入或混入其他物质，或明知而出于恶意使他人如此行事，以致其品质变坏。

<!-- source-p 0878 -->
<a id="48.13.2"></a>**48.13.2**

<!-- source-p 0879 -->
保罗《萨宾评注》第十一卷。

<!-- source-p 0880 -->
依《尤利亚公款余额法》，受托将公共钱款用于某项用途，却予以扣留且未用于该用途的人，承担责任。

<!-- source-p 0881 -->
<a id="48.13.3"></a>**48.13.3**

<!-- source-p 0882 -->
乌尔比安《论通奸》第一卷。

<!-- source-p 0883 -->
侵吞公款罪的刑罚包括禁止水火之用；如今该刑罚已由流放至岛屿取代。被判处这种刑罚的人，既丧失其此前的一切权利，也丧失财产。

<!-- source-p 0884 -->
<a id="48.13.4"></a>**48.13.4**

<!-- source-p 0885 -->
马尔基安《法学阶梯》第十四卷。

<!-- source-p 0886 -->
<a id="48.13.4.pr."></a>**序言**　依《尤利亚侵吞公款法》，取走或截留神圣或宗教钱款的人承担责任。

<!-- source-p 0887 -->
<a id="48.13.4.1"></a>**1**　若有人取走献给不朽之神的财物，也受侵吞公款罪的刑罚。

<!-- source-p 0888 -->
<a id="48.13.4.2"></a>**2**　皇帝训令规定了渎神罪的处理：行省总督应追查渎神者、强盗和掠卖人口者，并依各人罪行惩处。皇帝敕令也规定，渎神者应依非常程序受适当刑罚。

<!-- source-p 0889 -->
<a id="48.13.5"></a>**48.13.5 (4,3)**

<!-- source-p 0890 -->
马尔基安《法学阶梯》第十四卷。

<!-- source-p 0891 -->
<a id="48.13.5.pr."></a>**序言**　若有人因租赁、买卖、赡养事务、收取钱款或其他原因而持有未清缴的公共钱款，应依《尤利亚公款余额法》承担责任。

<!-- source-p 0892 -->
<a id="48.13.5.1"></a>**1**　（旧版第4款）某人接受公共钱款用于某项用途，却予以扣留且未支出的，也依该法承担责任。

<!-- source-p 0893 -->
<a id="48.13.5.2"></a>**2**　（旧版第5款）依该法被定罪的人，被判处的金额比其所欠款项多出三分之一。

<!-- source-p 0894 -->
<a id="48.13.5.3"></a>**3**　（旧版第6款）发现宝藏的地点不会因此成为宗教场所；即使宝藏是在墓中发现，也不会仅因墓地而被视为宗教场所。法律禁止埋葬的东西，不能因此成为宗教物；钱财不能被埋葬，这一点元首训令也有规定。

<!-- source-p 0895 -->
<a id="48.13.5.4"></a>**4**　（旧版第7款）若有人窃取城邦财物，神圣的图拉真与哈德良二帝的皇帝敕令规定，此行为也构成侵吞公款罪；我们现今仍适用该规则。

<!-- source-p 0896 -->
<a id="48.13.6"></a>**48.13.6 (5)**

<!-- source-p 0897 -->
马尔基安《规则集》第五卷。

<!-- source-p 0898 -->
神圣的塞维鲁与安敦尼曾以复函答复卡西乌斯·费斯图斯：私人财物若寄存于神庙后被盗，应提起盗窃之诉，而非渎神罪之诉。

<!-- source-p 0899 -->
<a id="48.13.7"></a>**48.13.7 (6)**

<!-- source-p 0900 -->
乌尔比安《论总督职责》第七卷。

<!-- source-p 0901 -->
总督应根据行为人的身份、案件性质、行为时间、年龄和性别，较严厉或较宽缓地确定渎神罪刑罚。我知道，许多渎神者被判处投入野兽，也有人被活活烧死，还有人被吊在叉形木架上。但对那些聚众破开神庙并于夜间盗走神明供物的人，刑罚应酌情控制在投入野兽这一程度。另一方面，若有人白天从神庙只拿走少量物品，应处以矿场劳役；若出身较高，则应流放至岛屿。

<!-- source-p 0902 -->
<a id="48.13.8"></a>**48.13.8 (6,1)**

<!-- source-p 0903 -->
乌尔比安《论总督职责》第七卷。

<!-- source-p 0904 -->
<a id="48.13.8.pr."></a>**序言**　在公共铸币厂工作的人员若从外部使用公共模具为自己铸造钱币，或偷走已经铸好的钱币，不视为铸造伪币，而是盗窃公共铸币，属于侵吞公款罪。

<!-- source-p 0905 -->
<a id="48.13.8.1"></a>**1**　（旧版第2款）若有人从皇帝所有的矿场偷取金或银，依神圣的庇护皇帝敕令，应根据其身份地位处以流放或矿场劳役。为窃贼提供衣襟以藏赃的人，视同因现行盗窃罪被定罪，并被判处不名誉。非法持有从矿场盗来的金子并将其熔化的人，应被判处四倍额。

<!-- source-p 0906 -->
<a id="48.13.9"></a>**48.13.9 (7)**

<!-- source-p 0907 -->
维努莱乌斯·萨图尔尼努斯《公诉法》第二卷。

<!-- source-p 0908 -->
侵吞公款罪若发生在五年以前，不应再予指控。

<!-- source-p 0909 -->
<a id="48.13.10"></a>**48.13.10 (8)**

<!-- source-p 0910 -->
维努莱乌斯·萨图尔尼努斯《公诉法》第三卷。

<!-- source-p 0911 -->
<a id="48.13.10.pr."></a>**序言**　有人揭下刻有法律文本、土地界图或其他内容的铜牌，或对其作出任何改动，应依《尤利亚侵吞公款法》承担责任。

<!-- source-p 0912 -->
<a id="48.13.10.1"></a>**1**　有人删除或增添公共簿册中的任何内容，也受同一法律追究。

<!-- source-p 0913 -->
<a id="48.13.11"></a>**48.13.11 (9)**

<!-- source-p 0914 -->
保罗《公诉法》单行卷。

<!-- source-p 0915 -->
<a id="48.13.11.pr."></a>**序言**　渎神者应处死刑。

<!-- source-p 0916 -->
<a id="48.13.11.1"></a>**1**　所谓渎神者，是指掠夺公共祭仪物品的人。若有人触碰私人祭祀物品或无人看守的小神龛，所受处罚应重于窃贼、轻于渎神者。因此，哪些物属于神圣物品、哪些行为构成渎神罪，均应仔细判断。

<!-- source-p 0917 -->
<a id="48.13.11.2"></a>**2**　拉贝奥在《后编》第三十八卷中将侵吞公款定义为：并非由负有该财物风险的人所实施的公共或神圣钱款盗窃。因此，神庙看守人对交付给自己的物品不构成侵吞公款罪。

<!-- source-p 0918 -->
<a id="48.13.11.3"></a>**3**　拉贝奥还在同卷下文写道，不仅公共钱款，私人钱款也可能构成侵吞公款罪：例如某人假称自己是国库债权人，从国库收取其声称国库应向其支付的钱款，尽管他取走的是私人钱款。

<!-- source-p 0919 -->
<a id="48.13.11.4"></a>**4**　受托转运钱款的人，或其他为钱款承担风险的人，不构成侵吞公款罪。

<!-- source-p 0920 -->
<a id="48.13.11.5"></a>**5**　元老院规定，未经负责该事务者许可而准许他人查阅或抄录公共簿册的人，依侵吞公款法承担责任。

<!-- source-p 0921 -->
<a id="48.13.11.6"></a>**6**　拉贝奥在《后编》第三十八卷写道，将公共钱款留作某种用途却未支出的人，依该法承担责任。某人离开行省时，将其持有的钱款申报为应交国库却予以扣留，对其不适用公款余额之诉；因为作为私人，他欠国库此款，因此应列为债务人。行使该项权力的人应向其追缴，即可扣押其质物、拘禁其本人或处以罚金。但《尤利亚公款余额法》又规定，超过一年后，该款也作为公款余额处理。

<!-- source-p 0922 -->
<a id="48.13.12"></a>**48.13.12 (10)**

<!-- source-p 0923 -->
马尔基安《公诉法》第一卷。

<!-- source-p 0924 -->
<a id="48.13.12.pr."></a>**序言**　有人在公共簿册中记载的金额低于物品实际出售或出租的金额，或实施类似行为，应依本法承担责任。

<!-- source-p 0925 -->
<a id="48.13.12.1"></a>**1**　神圣的塞维鲁与安敦尼曾将一名显贵青年流放至岛屿。该人把一个箱子放进神庙，并将一人藏在箱内；待神庙关闭后，藏匿者从箱中出来，从神庙窃取许多物品，再返回箱中。该青年因此被查明并定罪。

<!-- source-p 0926 -->
<a id="48.13.13"></a>**48.13.13 (11)**

<!-- source-p 0927 -->
乌尔比安《告示评注》第六十八卷。

<!-- source-p 0928 -->
凿穿墙壁或从墙内取走任何物品的人，应承担侵吞公款之诉的责任。

<!-- source-p 0929 -->
<a id="48.13.14"></a>**48.13.14 (12)**

<!-- source-p 0930 -->
马尔凯卢斯《法学汇编》第二十五卷。

<!-- source-p 0931 -->
若我向某人请求偿还钱款，而该人既欠我也欠国库钱款，并不构成侵吞公款；因为从债务人处取走钱款，并未截留国库的钱，毕竟此人仍同样欠国库钱款。

<!-- source-p 0932 -->
<a id="48.13.15"></a>**48.13.15 (13)**

<!-- source-p 0933 -->
莫德斯丁《刑罚论》第二卷。

<!-- source-p 0934 -->
从敌人处窃取战利品的人，应依侵吞公款法承担责任，并被判处四倍额。

<!-- source-p 0935 -->
<a id="48.13.16"></a>**48.13.16 (14)**

<!-- source-p 0936 -->
帕皮尼安《疑问集》第三十六卷。

<!-- source-p 0937 -->
侵吞公款、公款余额及追索非法所得的公诉案件，也可针对继承人提起，并非没有理由，因为这些案件的核心审理对象是被取走的钱款。
