# D.48.14–D.48.24　刑事犯罪与刑罚（续）

## D.48.14　论《尤利亚反贿选法》（*De lege Iulia ambitus*）

<!-- source-p 0938 -->
<a id="14"></a><a id="48.14"></a>**48.14.0**　论《尤利亚反贿选法》。

<!-- source-p 0939 -->
<a id="48.14.1"></a>**48.14.1**

<!-- source-p 0940 -->
莫德斯汀《刑罚》第2卷。

<!-- source-p 0941 -->
<a id="48.14.1.pr."></a>**序言**　该法如今在罗马城已不再适用，因为官员的任命属于皇帝的职责，而非取决于民众的拥护。

<!-- source-p 0942 -->
<a id="48.14.1.1"></a>**1**　若有人在市镇中违反该法竞选官职或祭司职位，根据元老院决议，应处以一百奥里金币罚款，并被列为不名誉者。

<!-- source-p 0943 -->
<a id="48.14.1.2"></a>**2**　若依据该法被判有罪者揭发另一人，则应准许其恢复原状，但不得返还其已缴纳的金钱。

<!-- source-p 0944 -->
<a id="48.14.1.3"></a>**3**　同样，设立新税赋的人也应依元老院决议受此刑罚。

<!-- source-p 0945 -->
<a id="48.14.1.4"></a>**4**　若被告或控告人进入法官住宅，便违反《尤利亚司法法》中关于反贿选的规定；也就是说，应命其向国库缴纳一百奥里金币。

## D.48.15　论《法比亚拐掠人身法》（*De lege Fabia de plagiariis*）

<!-- source-p 0946 -->
<a id="15"></a><a id="48.15"></a>**48.15.0**　论《法比亚拐掠人身法》。

<!-- source-p 0947 -->
<a id="48.15.1"></a>**48.15.1**

<!-- source-p 0948 -->
乌尔比安《规则》第1卷。

<!-- source-p 0949 -->
若买受人明知所购之人为自由人仍予购买，便依《法比亚拐掠人身法》对其构成可处死刑的犯罪；若出卖人明知该人为自由人仍予出售，出卖人也同样有罪。

<!-- source-p 0950 -->
<a id="48.15.2"></a>**48.15.2**

<!-- source-p 0951 -->
乌尔比安《总督职务》第9卷。

<!-- source-p 0952 -->
<a id="48.15.2.pr."></a>**序言**　应知悉，《法比亚法》不适用于因奴隶不在身边而将其出售的人；奴隶不在身边，与奴隶逃亡，是两回事。

<!-- source-p 0953 -->
<a id="48.15.2.1"></a>**1**　同样，该法不适用于委托他人追捕并出售逃奴的人；因为他并未出售奴隶的逃亡状态。

<!-- source-p 0954 -->
<a id="48.15.2.2"></a>**2**　还应指出，若有人委托提提乌斯抓捕逃奴，并约定提提乌斯一旦抓获便可将其买下，则元老院决议不适用。

<!-- source-p 0955 -->
<a id="48.15.2.3"></a>**3**　该元老院决议也涵盖出售自己逃亡奴隶的主人。

<!-- source-p 0956 -->
<a id="48.15.3"></a>**48.15.3**

<!-- source-p 0957 -->
马尔基安《公诉》第1卷。

<!-- source-p 0958 -->
<a id="48.15.3.pr."></a>**序言**　善意占有人不因隐匿他人奴隶而受《法比亚法》追究；所谓善意占有人，是指不知道该奴隶属于他人，或基于主人的同意而认为自己有权如此行事的人。该法本身也规定了善意占有人的情形，因为法条附加“明知且出于恶意欺诈”这一条件。神圣的塞维鲁与安敦尼皇帝也屡次裁定，不得依据该法追究善意占有人的责任。

<!-- source-p 0959 -->
<a id="48.15.3.1"></a>**1**　还应指出，如同《阿奎利亚法》的规则，若某人因之而有人违反《法比亚法》的人已经死亡，仍可提起控告并适用《法比亚法》的刑罚；神圣的塞维鲁与安敦尼皇帝曾以敕答确认这一点。

<!-- source-p 0960 -->
<a id="48.15.4"></a>**48.15.4**

<!-- source-p 0961 -->
盖尤斯《行省告示评注》第22卷。

<!-- source-p 0962 -->
凡明知自由人身份，却将其赠与或作为嫁资交付的人，均受《法比亚法》追究；同样，明知而以任何此类方式取得自由人的人，也应与出卖人和买受人承担相同责任。若双方以物易物，也适用同一规则。

<!-- source-p 0963 -->
<a id="48.15.5"></a>**48.15.5**

<!-- source-p 0964 -->
莫德斯汀《答复》第17卷。

<!-- source-p 0965 -->
答复指出，若能证明某人收留并藏匿他人的逃奴，他不能仅以自己提出了所有权争议为由逃避刑事指控。

<!-- source-p 0966 -->
<a id="48.15.6"></a>**48.15.6**

<!-- source-p 0967 -->
卡利斯特拉《裁判》第6卷。

<!-- source-p 0968 -->
<a id="48.15.6.pr."></a>**序言**　神圣的哈德良皇帝以如下敕答指出：仅因盗窃罪而被控截留他人奴隶的人，并不立即构成拐掠人身罪：“有人引诱或截留他人奴隶，是否构成对其所指控的拐掠人身罪，仍有疑问。因此，不应就此事咨询我，而应由法官查明案件事实后，遵循其认为最真实的情况。当然，应当知道，某人可能因截留他人奴隶而构成盗窃罪，但不能因此立即认定其为拐掠人身者。”

<!-- source-p 0969 -->
<a id="48.15.6.1"></a>**1**　同一皇帝还就此事作出如下敕答：“若某处只发现一名或两名逃奴，他们以劳务换取食物，尤其是若此前也曾在他人处工作，则不能依法称此处收留者为藏匿逃奴的人。”

<!-- source-p 0970 -->
<a id="48.15.6.2"></a>**2**　《法比亚法》规定：自由人若明知而出于恶意欺诈，违背自由出生者或释奴的意愿将其藏匿、拘禁或买下，或参与此类行为；或者劝说他人的奴隶或女奴逃离主人，或违背主人意愿、在主人不知情时藏匿、拘禁或买下该奴隶，或参与此类行为，均受该法刑罚处罚。

<!-- source-p 0971 -->
<a id="48.15.7"></a>**48.15.7**

<!-- source-p 0972 -->
赫莫革尼安《法学摘要》第5卷。

<!-- source-p 0973 -->
《法比亚法》规定的金钱刑罚如今已不再适用；发现此类犯罪后，应依行为严重程度处罚，且通常会判处矿场劳役。

## D.48.16　论《图尔皮利安元老院决议》及刑事指控撤回（*Ad senatus consultum Turpillianum et de abolitionibus criminum*）

<!-- source-p 0974 -->
<a id="16"></a><a id="48.16"></a>**48.16.0**　论《图尔皮利安元老院决议》及刑事指控撤回。

<!-- source-p 0975 -->
<a id="48.16.1"></a>**48.16.1**

<!-- source-p 0976 -->
马尔基安《〈图尔皮利安元老院决议〉单篇》。

<!-- source-p 0977 -->
<a id="48.16.1.pr."></a>**序言**　控告人的轻率行为可分为三种，并分别受到三类处罚：他们可能诬告、串通妨碍追诉，或无正当程序地撤回控告。

<!-- source-p 0978 -->
<a id="48.16.1.1"></a>**1**　诬告，是指提出虚假的犯罪指控；串通妨碍追诉，是指隐瞒真实犯罪；无正当程序地撤回控告，则是完全放弃控告。

<!-- source-p 0979 -->
<a id="48.16.1.2"></a>**2**　《雷米亚法》规定了对诬告者的刑罚。

<!-- source-p 0980 -->
<a id="48.16.1.3"></a>**3**　但控告人未能证明其主张，并不意味着其立即构成诬告；是否构成诬告，应由审理者裁量。被告获判无罪后，审理者应开始调查控告人的意图：他是出于何种心态提起控告。若发现其只是合理地判断错误，应判其无罪；若明确发现其诬告，则应对其处以法定刑罚。

<!-- source-p 0981 -->
<a id="48.16.1.4"></a>**4**　上述两种裁判结果都应在判决用语中清楚表明。若法官说“你未能证明指控”，就是宽宥控告人；若说“你实施了诬告”，便是判其有罪。即使判决中未进一步说明刑罚，法律仍会对其适用刑罚。正如帕皮尼安答复所言，事实问题由法官裁量，但刑罚的追诉并不交由法官自行决定，而应依法律权威执行。

<!-- source-p 0982 -->
<a id="48.16.1.5"></a>**5**　若法官这样宣告：“卢基乌斯·提提乌斯似乎轻率地提起控告”，这是否意味着其已被判为诬告者？这一问题可能出现。帕皮尼安说，轻率可能仅反映判断失误；未经审慎考虑的冲动并不等于诬告，因此此人不应受任何刑罚。

<!-- source-p 0983 -->
<a id="48.16.1.6"></a>**6**　我们已经说明，所谓串通妨碍追诉者，是指与被告串通、敷衍履行控告职责的人；其故意隐瞒自己的证据，却接受被告虚假的辩解。

<!-- source-p 0984 -->
<a id="48.16.1.7"></a>**7**　若有人未经准许撤回控告，应受处罚。

<!-- source-p 0985 -->
<a id="48.16.1.8"></a>**8**　通常应向总督私下请求准许撤回控告，也可以在审判席前提出，但不得在非正式场合提出；总督本人在场时，不得将此项审查委托给他人。

<!-- source-p 0986 -->
<a id="48.16.1.9"></a>**9**　若同一人对同一被告提出多项犯罪指控，应逐项请求准许撤回；否则，将依其实施的行为，按元老院决议承担相应刑罚。

<!-- source-p 0987 -->
<a id="48.16.1.10"></a>**10**　若控告人原本可被诉讼时效或身份抗辩排除，例如男性在通奸行为发生后连续五年届满、女性在离婚后有效期间六个月届满，才提起通奸控告，那么他此后撤回控告，是否应依本元老院决议受罚？对此确有疑问。有人认为，若时间经过或行为人身份缺陷足以完全排除控告，几乎任何案件都无法继续；此类规则为被告免除了恐惧和风险。相反的理由是，无论如何，一旦控告已经提出，就应由审理者依其权威准许撤回，而不能任由控告人自行决定；轻率提出如此恶劣控告者，更应受到谴责。因此，较妥当的意见是，我们讨论的此人也应落入本元老院决议范围。然而，帕皮尼安答复说，女性若因不追究自身或家人的侵害，而不获准提出伪造文书之控告，其后来撤回控告并不受《图尔皮利安元老院决议》处罚。那么，他对其他情形是否也会作同样答复？因性别、身份不名誉或期间届满而不得提出控告，彼此有何区别？而且更应排除的是，那名女性的控告可能因其自身所受侵害而产生效力，但其他人的控告则仅有言词形式。另一方面，他在别处又写道，同一人不得同时控告通奸的男女二人；但若其同时告发二人，必须对二人都请求准许撤回，以免落入该元老院决议范围。既然如此，控告因前述原因不成立，与因同时控告多人而无效，又有什么区别？或者说，控告人本来具有完整的控告权，仅因多人关系而被排除；与某些人根本不具备控告权，是否确有区别？因此，较妥当的结论是，除女性与未成年人外，其他人若不请求准许撤回，均应落入本元老院决议范围。

<!-- source-p 0988 -->
<a id="48.16.1.11"></a>**11**　对可疑监护人的控告只能在审判席前审查，且只有总督可以就此作出判决；但撤回此类控告的人不受该元老院决议约束。

<!-- source-p 0989 -->
<a id="48.16.1.12"></a>**12**　若有人声称另一人已落入《图尔皮利安元老院决议》的适用范围，应由总督审查此事；不过，不得依据该元老院决议处罚撤回控告者。仅仅声称某人落入该决议范围的人，并不因此成为控告人。

<!-- source-p 0990 -->
<a id="48.16.1.13"></a>**13**　指使或唆使他人控告的人，也落入该元老院决议范围；委托他人提出死刑指控，并提供证据、陈述控告理由的人，同样如此。这是合理的：此人不信任自己所提出的指控，便试图将诬告或撤回控告的风险转嫁给他人，因此理应受诬告者及撤回控告者的刑罚处罚；但若受唆使的控告人证明了他受命提出的犯罪指控，则不在此限。无论是亲自委托他人控告，还是通过第三人委托，均不影响结论。帕皮尼安答复说，应依元老院决议的本旨而非字面处罚实际委托者。受唆使的控告人也同样受该决议处罚，即仅因其接受他人所委托的控告事务而受罚。

<!-- source-p 0991 -->
<a id="48.16.1.14"></a>**14**　被告已被判有罪并提起上诉，随后控告人撤回控告；该控告人是否落入本元老院决议范围？他似乎确已落入，因为上诉救济会使原有罪判决失效。

<!-- source-p 0992 -->
<a id="48.16.2"></a>**48.16.2**

<!-- source-p 0993 -->
保罗《各法律刑罚单篇》。

<!-- source-p 0994 -->
撤回控告的人不得再继续诉讼或再次提出控告。

<!-- source-p 0995 -->
<a id="48.16.3"></a>**48.16.3**

<!-- source-p 0996 -->
保罗《判例》第1卷。

<!-- source-p 0997 -->
无论在私诉还是非常程序追诉的犯罪中，所有诬告者都应依其行为严重程度受非常程序处罚。

<!-- source-p 0998 -->
<a id="48.16.4"></a>**48.16.4**

<!-- source-p 0999 -->
帕皮尼安《答复》第15卷。

<!-- source-p 1000 -->
<a id="48.16.4.pr."></a>**序言**　某女性以伪造文书罪控告他人，所主张的是针对自己所受的侵害；在提出正式告发后，她又撤回控告。帕皮尼安认为，她似乎不受《图尔皮利安元老院决议》追究。

<!-- source-p 1001 -->
<a id="48.16.4.1"></a>**1**　经准许撤回控告后，同一人不得再对同一人重新提出同一犯罪指控。

<!-- source-p 1002 -->
<a id="48.16.5"></a>**48.16.5**

<!-- source-p 1003 -->
保罗《答复》第2卷。

<!-- source-p 1004 -->
有人以呈交皇帝的请愿书威胁称，若对方不履行要求，他就会提出伪造文书指控；若此人最终没有提出指控，是否受《图尔皮利安元老院决议》约束？保罗答复说，依该决议的文字，所询问的这个人不在其适用范围内。

<!-- source-p 1005 -->
<a id="48.16.6"></a>**48.16.6**

<!-- source-p 1006 -->
保罗《判例》第1卷。

<!-- source-p 1007 -->
<a id="48.16.6.pr."></a>**序言**　若控告人与对方就其提出的犯罪指控达成和解，便视为其撤回了控告。

<!-- source-p 1008 -->
<a id="48.16.6.1"></a>**1**　放弃控告意图的人，也视为撤回控告；也就是说，他已放弃控告的愿望和意图。

<!-- source-p 1009 -->
<a id="48.16.6.2"></a>**2**　若控告人在总督规定的期限内未能完成对被告的追诉，应视为其已撤回控告。

<!-- source-p 1010 -->
<a id="48.16.6.3"></a>**3**　通过公开告示报告线索的告发人，应被命令出庭支持其告示所提出的指控。

<!-- source-p 1011 -->
<a id="48.16.6.4"></a>**4**　若有人被指称为了诬告而收集、撰写或在法庭上提交文书、证言或其他材料，应以诬告罪处罚。

<!-- source-p 1012 -->
<a id="48.16.7"></a>**48.16.7**

<!-- source-p 1013 -->
乌尔比安《论争》第8卷。

<!-- source-p 1014 -->
<a id="48.16.7.pr."></a>**序言**　若有人希望在公诉案件经公共撤销程序撤销后重新提出指控，应依其原先提出控告时适用的法律行事；不得对其提出在被告获准撤销控告之前尚未提出的期间抗辩。神圣的哈德良皇帝曾以敕答确认此规则。

<!-- source-p 1015 -->
<a id="48.16.7.1"></a>**1**　若有人提出欺诈罪或侵吞遗产罪的指控后又撤回，不受《图尔皮利安元老院决议》的刑罚；盗窃或侵辱之诉也一样。但法官仍可依其职权追究其过错。

<!-- source-p 1016 -->
<a id="48.16.8"></a>**48.16.8**

<!-- source-p 1017 -->
帕皮尼安《通奸案》第2卷。

<!-- source-p 1018 -->
公共撤销程序可以因纪念日或公共庆典而作出。

<!-- source-p 1019 -->
<a id="48.16.9"></a>**48.16.9**

<!-- source-p 1020 -->
马凯尔《公诉》第2卷。

<!-- source-p 1021 -->
也可以因军事行动顺利而作出。

<!-- source-p 1022 -->
<a id="48.16.10"></a>**48.16.10**

<!-- source-p 1023 -->
帕皮尼安《通奸案》第2卷。

<!-- source-p 1024 -->
<a id="48.16.10.pr."></a>**序言**　也可以应控告人个人请求而准许撤销。第三种情形则是依法撤销，即控告人死亡或因正当事由无法提出控告。

<!-- source-p 1025 -->
<a id="48.16.10.1"></a>**1**　若公共撤销程序已经作出，不得再通过重审婚姻关系问题恢复该案。

<!-- source-p 1026 -->
<a id="48.16.10.2"></a>**2**　神圣的图拉真皇帝解释，重新提出控告的三十日属于有效期间，自节庆结束之日起计算。元老院还规定，该期间仅在控告人能够重新提出控告的日子内计算。而且，只有控告人本人也能够出庭时，重新控告的期间才开始计算。

<!-- source-p 1027 -->
<a id="48.16.11"></a>**48.16.11**

<!-- source-p 1028 -->
帕皮尼安《通奸案单篇》。

<!-- source-p 1029 -->
有人询问，因控告期间届满而被排除起诉的人，是否落入《图尔皮利安元老院决议》的范围。帕皮尼安答复说，不应怀疑：因期间抗辩而不能继续通奸案件的人，不会因诬告受到处罚。

<!-- source-p 1030 -->
<a id="48.16.12"></a>**48.16.12**

<!-- source-p 1031 -->
乌尔比安《通奸案》第2卷。

<!-- source-p 1032 -->
若元老院因公共庆典、皇室尊荣或其他理由，按惯例准许公共撤销，而控告人未在规定期限内重新提出控告，应认为《图尔皮利安元老院决议》不再适用。因为控告人未重新控告已获豁免的被告，并不视为撤回控告；该被告因公共撤销程序而获豁免。

<!-- source-p 1033 -->
<a id="48.16.13"></a>**48.16.13**

<!-- source-p 1034 -->
保罗《通奸案》第3卷。

<!-- source-p 1035 -->
<a id="48.16.13.pr."></a>**序言**　所谓撤回控告，是指彻底放弃追诉意图的人，而不是仅仅推迟控告的人。

<!-- source-p 1036 -->
<a id="48.16.13.1"></a>**1**　但若有人经皇帝许可撤回控告，则不受处罚。

<!-- source-p 1037 -->
<a id="48.16.14"></a>**48.16.14**

<!-- source-p 1038 -->
乌尔比安《总督职务》第7卷。

<!-- source-p 1039 -->
神圣的哈德良皇帝写信给克里特行省总督萨尔维乌斯·卡鲁斯：若监护人为了未适婚人的利益提起控告，而该未适婚人随后死亡，不应强令监护人继续完成控告。

<!-- source-p 1040 -->
<a id="48.16.15"></a>**48.16.15**

<!-- source-p 1041 -->
马凯尔《公诉》第2卷。

<!-- source-p 1042 -->
<a id="48.16.15.pr."></a>**序言**　下列人应落入《图尔皮利安元老院决议》的范围：指使他人控告者；受指使提出控告却未完成追诉者；以及未获准撤销便以其他方式撤回控告者。此外，曾为控告或达成任何协议而签署书面文件的人，也在其列。这里的“未完成追诉”应理解为适用于前述所有人。〔底本疑误：*pactionemve aliquam interposuissententiarum*，*interposuissent* 与后续词语粘连。〕

<!-- source-p 1043 -->
<a id="48.16.15.1"></a>**1**　有人询问，该元老院决议是否适用于现今以非常程序审理公诉案件的人。我们如今依皇帝敕令采用的规则是：该决议适用，但应按各案件分别判处相应刑罚。

<!-- source-p 1044 -->
<a id="48.16.15.2"></a>**2**　皇帝敕令规定，法律不允许以诬告罪追究的人，若撤回控告，不受该元老院决议刑罚。

<!-- source-p 1045 -->
<a id="48.16.15.3"></a>**3**　若控告人因被告死亡而撤回控告，不受该元老院决议追究，因为被告死亡会使诉讼消灭；除非犯罪属于可以对继承人继续追诉的类型，例如叛逆罪。追索非法所得罪也一样，因为该诉讼不会因被告死亡而消灭。

<!-- source-p 1046 -->
<a id="48.16.15.4"></a>**4**　但若控告人先撤回控告，而被告随后死亡，控告人的犯罪并不因此减轻。塞维鲁与安敦尼皇帝裁定，已经撤回控告的人即使后来准备再次控告，也不得受理。

<!-- source-p 1047 -->
<a id="48.16.15.5"></a>**5**　若控告人已经正式登记控告，但在争讼程序确定前，由于总督事务繁忙或民事职务所需而一年或两年不能继续追诉，不落入该元老院决议范围。

<!-- source-p 1048 -->
<a id="48.16.15.6"></a>**6**　即使控告人此前已提出控告，若在被告重新被控告之前又作出另一项撤销，则三十日期限应从第二次撤销起算，而非从第一次撤销起算。

<!-- source-p 1049 -->
<a id="48.16.16"></a>**48.16.16**

<!-- source-p 1050 -->
保罗《通奸案单篇》。

<!-- source-p 1051 -->
图密善皇帝曾以敕答规定，有关节庆期间及撤销控告的规则不适用于被控告后被命令拘禁的奴隶，否则诉讼就无法终结。

<!-- source-p 1052 -->
<a id="48.16.17"></a>**48.16.17**

<!-- source-p 1053 -->
莫德斯汀《答复》第17卷。

<!-- source-p 1054 -->
卢基乌斯·提提乌斯控告塞尤斯伪造文书；在他尚未继续追诉之前，皇帝普遍赦免了此类犯罪。我问，若他之后没有再次正式控告塞尤斯，是否落入《图尔皮利安元老院决议》范围？赫雷尼乌斯·莫德斯汀答复说，公开给予的犯罪赦免并不适用于此类犯罪。

<!-- source-p 1055 -->
<a id="48.16.18"></a>**48.16.18**

<!-- source-p 1056 -->
帕皮里乌《敕令》第1卷。

<!-- source-p 1057 -->
<a id="48.16.18.pr."></a>**序言**　安敦尼与维鲁斯皇帝答复尤利乌斯·维鲁斯：若诉讼据称已经拖延很久，未经对方同意，不得接受撤销控告。

<!-- source-p 1058 -->
<a id="48.16.18.1"></a>**1**　皇帝还答复说，除非能明确证明对方同意，否则不得准许撤销控告。

<!-- source-p 1059 -->
<a id="48.16.18.2"></a>**2**　皇帝又答复说，若有人在死刑案件中声称其请求撤销控告只是为了金钱事项，仍应恢复审理；若他不能证明其所主张的情况，就不得使其逍遥法外。

## D.48.17　论追查被列名者及缺席判罪（*De requirendis vel absentibus damnandis*）

<!-- source-p 1060 -->
<a id="17"></a><a id="48.17"></a>**48.17.0**　论追查被列名者及缺席判罪。

<!-- source-p 1061 -->
<a id="48.17.1"></a>**48.17.1**

<!-- source-p 1062 -->
马尔基安《公诉案件》第2卷。

<!-- source-p 1063 -->
<a id="48.17.1.pr."></a>**序言**　神圣塞维鲁与安敦尼皇帝曾以敕答规定，不得惩罚缺席者。我们现行法也遵循此规则，不使缺席者被判罪；正义的考量不允许任何人在未获听审的情况下被判罪。

<!-- source-p 1064 -->
<a id="48.17.1.1"></a>**1**　若某人可能受到较重刑罚，例如被送入矿场劳役或受类似刑罚，乃至死刑，在这种情形下，不得对缺席者科刑；应将其列为须追查者，使其有机会到庭。

<!-- source-p 1065 -->
<a id="48.17.1.2"></a>**2**　行省总督对被列为须追查者，应当这样处理：以告示命令其到庭，使其得知自己已被列名；还应向其居住地的行政官员发函，使这些官员能够告知他已被列为须追查者。

<!-- source-p 1066 -->
<a id="48.17.1.3"></a>**3**　为其自我辩明而计算的一年期间，自此开始。

<!-- source-p 1067 -->
<a id="48.17.1.4"></a>**4**　帕皮尼安在《答复》第16卷中也写道：若被列为须追查者的人在一年内向行省总督申诉并提供担保，则不适用有关将其财产归入国库的敕令。若其在一年内死亡，刑事案件即告消灭，其财产转归继承人。

<!-- source-p 1068 -->
<a id="48.17.2"></a>**48.17.2**

<!-- source-p 1069 -->
马凯尔《公诉案件》第2卷。

<!-- source-p 1070 -->
<a id="48.17.2.pr."></a>**序言**　对于被列为须追查者，其财产可被占有的期间为一年。

<!-- source-p 1071 -->
<a id="48.17.2.1"></a>**1**　然而，若国库二十年间未占有其财产，之后无论由被告本人还是其继承人，均可援引时效抗辩排除国库的请求：

<!-- source-p 1072 -->
<a id="48.17.3"></a>**48.17.3**

<!-- source-p 1073 -->
马尔基安《公诉案件》第2卷。

<!-- source-p 1074 -->
凡属国库管辖的案件，若无其他特定时效，神圣皇帝们均规定，经过二十年不行使权利，即可援引时效抗辩。

<!-- source-p 1075 -->
<a id="48.17.4"></a>**48.17.4**

<!-- source-p 1076 -->
马凯尔《公诉案件》第2卷。

<!-- source-p 1077 -->
<a id="48.17.4.pr."></a>**序言**　一年期间应自该项列名通过告示或致行政官员的函件公之于众时起算。

<!-- source-p 1078 -->
<a id="48.17.4.1"></a>**1**　因此，国库的二十年期间也自列名公之于众时起算。

<!-- source-p 1079 -->
<a id="48.17.4.2"></a>**2**　总之，应知，被列为须追查者不得以任何期间经过为由，排除对案件实体的审理。

<!-- source-p 1080 -->
<a id="48.17.5"></a>**48.17.5**

<!-- source-p 1081 -->
莫德斯廷《学说汇纂》第12卷。

<!-- source-p 1082 -->
<a id="48.17.5.pr."></a>**序言**　敕令规定，对被列为须追查者的财产，应在一年内加封；若其返回并证明自己无罪，应完整保有其财产。若其既未答复，也无人为其辩护，一年后其财产即被征归国库。

<!-- source-p 1083 -->
<a id="48.17.5.1"></a>**1**　神圣塞维鲁与安敦尼皇帝规定，在这一年期间内，如有动产，为避免因迟延而毁损或以其他方式灭失，应予出售，其价款应存入保管账户。

<!-- source-p 1084 -->
<a id="48.17.5.2"></a>**2**　神圣图拉真皇帝还以敕答确认，孳息也属于动产。

<!-- source-p 1085 -->
<a id="48.17.5.3"></a>**3**　应设法确保其债务人暂不向逃亡者清偿，以免因此资助其逃亡。

## D.48.18　论刑讯（*De quaestionibus*）

<!-- source-p 1086 -->
<a id="18"></a><a id="48.18"></a>**48.18.0**　论刑讯。

<!-- source-p 1087 -->
<a id="48.18.1"></a>**48.18.1**

<!-- source-p 1088 -->
乌尔比安《总督职务》第8卷。

<!-- source-p 1089 -->
<a id="48.18.1.pr."></a>**序言**　在查明犯罪时，通常会采用刑讯。但何时以及在何种范围内可以如此，应予考察。神圣奥古斯都已规定，不得一开始便施以刑讯，也不得过分相信刑讯所得；神圣哈德良致森尼乌斯·萨比努斯的书信中亦载有此意。

<!-- source-p 1090 -->
<a id="48.18.1.1"></a>**1**　该敕答的措辞如下：“只有在被告已受到怀疑，且其他证据已使其罪责达到几乎只差奴隶供述即可证明的程度时，方应对奴隶施以刑讯。”

<!-- source-p 1091 -->
<a id="48.18.1.2"></a>**2**　神圣哈德良皇帝还以敕答答复克劳狄乌斯·夸尔提努斯；敕答明确指出，应从最可疑者开始，并从法官认为最容易获知真相的人开始。

<!-- source-p 1092 -->
<a id="48.18.1.3"></a>**3**　神圣皇帝兄弟致卢基乌斯·提贝里安努斯的敕答表明：控告人从自己家中带来的奴隶，不得对其施刑；也不应轻信所谓被替换的女儿——据称其父母都很疼爱她。

<!-- source-p 1093 -->
<a id="48.18.1.4"></a>**4**　神圣皇帝兄弟还答复科尔内利乌斯·普罗库鲁斯说，不能仅凭对一个奴隶的刑讯结果便确定案件事实，而应根据各种证据审查案件。

<!-- source-p 1094 -->
<a id="48.18.1.5"></a>**5**　神圣安敦尼皇帝与神圣哈德良皇帝答复森尼乌斯·萨比努斯说，若据称奴隶与主人共同运走金银，不得就主人一事讯问奴隶；即使奴隶自行说出某些内容，也不得因此使主人受不利影响。

<!-- source-p 1095 -->
<a id="48.18.1.6"></a>**6**　神圣皇帝兄弟答复莱利亚努斯·隆基努斯说，不得就遗产物品对遗产奴隶施刑，即使继承人似乎曾通过虚假的买卖取得该奴隶的所有权，因而使人对此产生怀疑。

<!-- source-p 1096 -->
<a id="48.18.1.7"></a>**7**　敕答屡次确认，可以对市镇团体的奴隶施刑以牵连该市镇的公民，因为该奴隶并非属于这些公民个人，而是属于公共团体。其他团体的奴隶也应作同样处理；其并非属于多个成员，而是属于团体本身。

<!-- source-p 1097 -->
<a id="48.18.1.8"></a>**8**　若某奴隶以善意为我服役，即使我并不拥有其所有权，也可以说不得为牵连我而对他施刑。善意为人服役的自由人亦同。

<!-- source-p 1098 -->
<a id="48.18.1.9"></a>**9**　又已确立，不得对释奴施刑以牵连其原主。

<!-- source-p 1099 -->
<a id="48.18.1.10"></a>**10**　我国皇帝与其神圣父皇还曾敕答说，不得对兄弟施刑以牵连另一兄弟；理由是，对于任何人均无义务违背本人意愿作证，也不得对其施刑以取得这种证言。

<!-- source-p 1100 -->
<a id="48.18.1.11"></a>**11**　神圣图拉真皇帝答复塞尔尼乌斯·夸尔图斯说，可以对丈夫的奴隶施刑以牵连其妻。

<!-- source-p 1101 -->
<a id="48.18.1.12"></a>**12**　他又答复穆米乌斯·洛利安努斯说，被判罪者的奴隶因已不再属于该人，可以被刑讯以牵连该被判罪者。

<!-- source-p 1102 -->
<a id="48.18.1.13"></a>**13**　若某奴隶被特意解放，以使其不受刑讯，只要不是为牵连其原主人而施刑，仍可对其施刑；神圣庇护皇帝曾以敕答如此规定。

<!-- source-p 1103 -->
<a id="48.18.1.14"></a>**14**　神圣皇帝兄弟还敕答说，在调查开始时属于他人的奴隶，即使后来成为被告，也可以为牵连其本人而受刑讯。

<!-- source-p 1104 -->
<a id="48.18.1.15"></a>**15**　若有人被指称其购买奴隶并无法律效力，则在确认该买卖无效之前，不得对奴隶施刑；我国皇帝与其神圣父皇曾以敕答作此规定。

<!-- source-p 1105 -->
<a id="48.18.1.16"></a>**16**　塞维鲁皇帝还以如下措辞答复斯皮基乌斯·安提戈努斯：“不得对奴隶施刑以牵连其主人；即使已施刑，作出裁判的人也不应以此作为判断依据。更不得采纳奴隶针对主人的告发。”

<!-- source-p 1106 -->
<a id="48.18.1.17"></a>**17**　神圣塞维鲁皇帝敕答说，若没有任何证据足以使审理者确信，不得将被告的供认视为已经查实的犯罪事实。

<!-- source-p 1107 -->
<a id="48.18.1.18"></a>**18**　有人准备缴纳奴隶的价金，以便对该奴隶施刑并使其牵连主人；我国皇帝与其神圣父皇不准许这样做。

<!-- source-p 1108 -->
<a id="48.18.1.19"></a>**19**　若奴隶被当作犯罪参与者而受刑，并在法官面前供认了有关主人的事项，神圣图拉真皇帝敕答说，法官应依案件具体情况作出裁判。该敕答表明，奴隶的供述可能使主人承担不利后果；但后来的敕令显示，法律制度已背离这一敕答。

<!-- source-p 1109 -->
<a id="48.18.1.20"></a>**20**　在税赋案件中，众所周知，税赋乃国家的命脉；而奴隶若明知欺诈仍参与，可能被判死刑。这种危险也会使其陈述更为可信。

<!-- source-p 1110 -->
<a id="48.18.1.21"></a>**21**　准备施刑的人，不应具体询问“卢基乌斯·提提乌斯是否犯了杀人罪”，而应一般地询问“是谁犯了此罪”；前者更像是在提示答案，而非查问事实。神圣图拉真皇帝曾以敕答如此规定。

<!-- source-p 1111 -->
<a id="48.18.1.22"></a>**22**　神圣哈德良皇帝以如下措辞答复卡尔普尔尼乌斯·凯莱里安努斯：“可以询问庞培·瓦伦斯的奴隶是否参与此事。若在刑讯时他说出更多内容，这可成为针对被告的证据；这不构成提问者的过错。”

<!-- source-p 1112 -->
<a id="48.18.1.23"></a>**23**　敕令表明，不应总是相信刑讯所得，但也不能一概不信；因为刑讯脆弱而危险，可能使真相受到误导。有些人忍耐力强或坚忍，轻视刑讯，以致无论如何都无法从他们口中逼出真情；另一些人则极不耐受，宁愿说任何谎话也不愿忍受刑讯。因此，他们甚至会以不同方式供认，不仅控告自己，还会牵连他人。

<!-- source-p 1113 -->
<a id="48.18.1.24"></a>**24**　此外，不应相信仇敌对他人所作的刑讯证言，因为他们容易说谎；但也不得以存在仇怨为借口，一概否定刑讯所得的可信性。

<!-- source-p 1114 -->
<a id="48.18.1.25"></a>**25**　应在查明案件情况后，决定是否采信刑讯所得。

<!-- source-p 1115 -->
<a id="48.18.1.26"></a>**26**　若有人交出了强盗，一些敕答规定，不应相信这些人针对交出他们者所作的陈述；另一些内容更为周全的敕答则规定，不应像通常对待其他人那样，严格地排除其陈述，而应在查明案件情况后判断是否应予采信。许多人担心自己被捕后会供出同伙，便先行告发他们，以求自己免受处罚；因为通常不会轻易相信那些告发出卖自己之人的人。但也不得仅因他们作出此种告发便一概给予免罚，更不得接受他们声称自己之所以受到牵连，只是因为他们交出了同伙的说法；这种说法本身足以成为其说谎或诬告的有力证据。

<!-- source-p 1116 -->
<a id="48.18.1.27"></a>**27**　若有人主动承认犯罪，也不应总是相信他；因为有时人会出于恐惧或其他原因自我归罪。神圣皇帝兄弟致沃科尼乌斯·萨克萨的书信中记载：应释放一名自认犯罪的人，若其被判罪后又查明无罪。书信内容如下：“亲爱的萨克萨，你以审慎且极具人道的理由，判定奴隶普里米提乌斯有罪；他因害怕回到主人身边，涉嫌虚构自己犯下杀人罪。你又坚持此项虚假指控，意在查明其同谋；他也谎称自己有同谋，以便促使其作出更为确定的自我供认。你的审慎安排并未白费，因为刑讯已证明那些人并非其同谋，而他所说的自身犯罪也纯属编造。因此，你可以给予他宽赦，并命令通过你的职员将其出售，同时附加条件：此人不得再回到其主人的权力之下。我们确信，其主人收到价金后，乐于摆脱这样一个奴隶。”这封书信表明，若奴隶被判罪后又获返还，其仍归判罪前的所有人所有。但行省总督无法返还自己判罪者，因为他同样无权撤销自己作出的金钱判决。那么应当如何处理？若后来查明原先看似有罪者实属无辜，总督应就此事向皇帝报告。

## D.48.19　论刑罚（*De poenis*）

<!-- source-p 1207 -->
<a id="19"></a><a id="48.19"></a>**48.19.0**　论刑罚。

<!-- source-p 1208 -->
<a id="48.19.1"></a>**48.19.1**

<!-- source-p 1209 -->
乌尔比安《论题》第8卷。

<!-- source-p 1210 -->
<a id="48.19.1.pr."></a>**序言**　每当审理犯罪时，已确立的规则是：应使被告承受其犯罪时本应承受的刑罚，而非裁判作出时其身份状况所允许的刑罚。

<!-- source-p 1211 -->
<a id="48.19.1.1"></a>**1**　因此，奴隶若犯下犯罪，后来据称获得自由，应承受其犯罪时若被判刑本应承受的刑罚。

<!-- source-p 1212 -->
<a id="48.19.1.2"></a>**2**　反之，若其身份后来变得更差，也应承受其身份仍处于原先状况时本应承受的刑罚。

<!-- source-p 1213 -->
<a id="48.19.1.3"></a>**3**　一般而言，对于公诉罪或私人犯罪的法律，以及由长官或总督依非常程序审理的案件，均已确立如下规则：对于因贫困而逃避金钱刑罚的人，应施以非常强制措施。

<!-- source-p 1214 -->
<a id="48.19.2"></a>**48.19.2**

<!-- source-p 1215 -->
乌尔比安《告示》第48卷。

<!-- source-p 1216 -->
<a id="48.19.2.pr."></a>**序言**　所谓被判处死刑罪者，是指被判罪后将受到死亡、丧失公民身份或奴役后果的人。

<!-- source-p 1217 -->
<a id="48.19.2.1"></a>**1**　显然，自流放至岛上取代禁止水火以来，只有皇帝决定将某人流放至岛上后，此人才丧失公民身份；毫无疑问，总督无权作出此种流放。但罗马城长官有权作出流放判决，因此，在该长官宣判后，被判者即视为已丧失公民身份。

<!-- source-p 1218 -->
<a id="48.19.2.2"></a>**2**　所谓被判罪者，是指未提起上诉的人；若其提起上诉，则尚不视为已被判罪。若某人被无权判处死刑的长官判罪，情况亦同；只有在判决生效时，该人才算被判罪。

<!-- source-p 1219 -->
<a id="48.19.3"></a>**48.19.3**

<!-- source-p 1220 -->
乌尔比安《萨宾评注》第14卷。

<!-- source-p 1221 -->
被判处死刑的孕妇，其刑罚应延至分娩之后。我还知道，在她怀孕期间，通常也不会对她施以刑讯。

<!-- source-p 1222 -->
<a id="48.19.4"></a>**48.19.4**

<a id="48.19.5.pr."></a>**序言**　神圣图拉真皇帝曾敕答尤利乌斯·弗龙托努斯说，不得在刑事案件中对缺席者判罪；他也曾敕答阿西狄乌斯·塞维鲁说，不得仅凭怀疑判罪，因为宁可让有罪者未受惩罚，也不可判无辜者有罪。然而，对不服从传唤或总督告示的顽抗者，可以依私人诉讼的惯例在其缺席时作出判决。有人或许会主张这些规则并不矛盾。应如何理解？较妥当的规则是：对于缺席者，可以科处金钱刑罚或影响其名誉的刑罚；若其经多次通知仍顽抗不至，也可判处流放。但若本应施加更重刑罚，例如矿场劳役或死刑，则不得对缺席者科处。

<!-- source-p 1228 -->
<a id="48.19.5.1"></a>**1**　若控告人缺席，有时可以对其处以比《图尔皮利安元老院决议》规定更重的刑罚。

<!-- source-p 1229 -->
<a id="48.19.5.2"></a>**2**　对于较重的犯罪，还应考察行为是故意实施，还是偶然发生。事实上，在所有犯罪中，这一区分都应当影响刑罚，使刑罚或者正当适用，或者有所减轻。

<a id="48.19.6.pr."></a>**序言**　有人为避免受刑，声称自己有事关皇帝安危的事项要向皇帝报告；应否将其转送皇帝，值得考虑。有些总督十分胆怯，即使已对其宣判，也会让其承受刑罚而不听取任何陈述；另一些总督则根本不允许此类主张；还有一些既非总是转送，也非从不转送，而是先查明其意欲向皇帝报告何事，以及其声称何事关乎皇帝安危，再决定是否让其受刑。这似乎是折中的做法。不过依我之见，既然某人已被判罪，无论其提出何种主张，都不应再听取其陈述。谁会怀疑有人只是为逃避刑罚才诉诸此法？况且，那些长期不作声、如今才声称有事关皇帝安危事项要报告的人，更应受到惩罚；如此重大之事，本不应被他们隐瞒这么久。

<!-- source-p 1234 -->
<a id="48.19.6.2"></a>**2**　现在应列举总督可以施加的各类刑罚。有些刑罚剥夺生命，有些施加奴役，有些剥夺公民身份，有些构成流放，有些则包括身体强制：

（例如，杖击、警告；鞭笞、惩戒；拘束、殴打。）

<a id="48.19.8.pr."></a>**序言**　其他刑罚包括：罚款并使其蒙受不名誉，剥夺某种身份地位，或禁止实施某种行为。

<!-- source-p 1241 -->
<a id="48.19.8.1"></a>**1**　剥夺生命，例如判处某人以剑处死。但应以剑行刑，不得使用斧、投射武器、棍棒、绞索或其他方式。因此，总督无权准许受刑者自行选择死亡方式；更不能准许其服毒自尽。不过，神圣皇帝兄弟曾以敕答准许某人自行选择死亡方式。

<!-- source-p 1242 -->
<a id="48.19.8.2"></a>**2**　敌人及叛逃者则应受活活焚烧之刑。

<!-- source-p 1243 -->
<a id="48.19.8.3"></a>**3**　不得判处任何人被打死、被棍棒打死或死于刑讯之刑，尽管许多人在受刑讯时往往会死去。

<!-- source-p 1244 -->
<a id="48.19.8.4"></a>**4**　有些刑罚剥夺自由，例如判处某人进入矿场或从事矿场劳役。矿场数量众多，有些行省设有矿场，有些则没有；没有矿场的行省会将受刑者送往设有矿场的行省。

<!-- source-p 1245 -->
<a id="48.19.8.5"></a>**5**　神圣塞维鲁皇帝致法比乌斯·基洛的书信明确指出，罗马城长官特别享有判处矿场劳役的权力。

<!-- source-p 1246 -->
<a id="48.19.8.6"></a>**6**　被判进入矿场者与被判从事矿场劳役者之间，区别仅在于拘束程度：前者受较重的锁链束缚，后者则较轻；此外，逃离矿场劳役者会被送入矿场，而从矿场逃脱者则受更严厉的拘束。

<!-- source-p 1247 -->
<a id="48.19.8.7"></a>**7**　被判公共工程劳役而逃亡者，通常会被加判其剩余刑期的两倍；应加倍计算其逃亡时尚未服完的刑期，不应将其被捕后在监狱中的时间也计入加倍期间。若其被判十年，刑罚应改为终身，或转为矿场劳役。若某人一开始便逃亡，且原判十年，则应考虑是加倍刑期，还是改为终身或矿场劳役；较可取的做法是改为矿场劳役或终身刑。一般而言，若刑期加倍后将超过十年，就不应仅以加长刑期处理。

<!-- source-p 1248 -->
<a id="48.19.8.8"></a>**8**　妇女通常被判终身或定期在矿工中服役，也可能被判在盐场服役。若判处终身，应视为受刑奴隶；若判处定期，则保留公民身份。

<!-- source-p 1249 -->
<a id="48.19.8.9"></a>**9**　总督通常判处被告羁押于监狱或拘束于锁链，但不应如此判处；这些刑罚已被禁止。监狱应当用于拘禁人，而非惩罚人。

<!-- source-p 1250 -->
<a id="48.19.8.10"></a>**10**　有些人被判在石灰窑或硫磺窑服役；但这些刑罚更接近矿场刑罚。

<!-- source-p 1251 -->
<a id="48.19.8.11"></a>**11**　对于被判进入斗兽场与野兽搏斗者，应考察其是否成为受刑奴隶；年轻人通常受此刑罚。那么，这些人究竟成为受刑奴隶，还是保留自由？较可取的意见是，他们也成为受刑奴隶。其与其他人不同之处在于，他们被训练成猎手、舞蹈表演者，或训练为表演其他娱乐性动作的人。

<!-- source-p 1252 -->
<a id="48.19.8.12"></a>**12**　毫无疑问，奴隶通常被交付矿场、矿场劳役或斗兽场；一旦被交付，即成为受刑奴隶，不再归属于判罪前的主人。曾有一名奴隶被判入矿场，后因皇帝恩典获释；安敦尼皇帝非常正确地敕答说，该奴隶一旦成为受刑奴隶，便已不再属于主人，因此之后不得将其交还给主人控制。

<!-- source-p 1253 -->
<a id="48.19.8.13"></a>**13**　但奴隶无论被判终身拘束还是定期拘束，仍归属于其被判罪前的主人。

<a id="48.19.9.pr."></a>**序言**　总督也惯常禁止某人从事讼务代理。有时永久禁止，有时限期禁止，期限可按年计算，或者仅在其治理该行省期间有效。

<!-- source-p 1257 -->
<a id="48.19.9.1"></a>**1**　也可以命令某人不得为特定的人提供讼务代理。

<!-- source-p 1258 -->
<a id="48.19.9.2"></a>**2**　也可以禁止某人在总督法庭担任代理人，但并不因此禁止其在使节或财务官面前代理诉讼。

<!-- source-p 1259 -->
<a id="48.19.9.3"></a>**3**　但若某人已被禁止在使节面前代理诉讼，我认为依此也应推知，他不得在总督面前代理诉讼。

<!-- source-p 1260 -->
<a id="48.19.9.4"></a>**4**　有时，禁止的不是讼务代理，而是进入法庭。禁止进入法庭比禁止担任诉讼代理更重，因为这会完全禁止其参与法庭事务。此类禁令通常针对法律学者、讼务代理人、公证人或法律顾问作出。

<!-- source-p 1261 -->
<a id="48.19.9.5"></a>**5**　有时还会禁止某人制作任何文书、起草请愿书或签署证言记录。

<!-- source-p 1262 -->
<a id="48.19.9.6"></a>**6**　有时还会禁止某人在公共文书存放处，例如档案馆或文书库所在地点就座。

<!-- source-p 1263 -->
<a id="48.19.9.7"></a>**7**　有时会禁止某人整理、书写或签署遗嘱。

<!-- source-p 1264 -->
<a id="48.19.9.8"></a>**8**　还有一种刑罚是禁止某人参与公共事务；此人仍可参与私人事务，但被排除于公共事务之外。通常对被判不得参与公共事务的人，会作出这种禁令。

<!-- source-p 1265 -->
<a id="48.19.9.9"></a>**9**　还有其他刑罚，例如命令某人停止经商，或禁止其承包公共出租项目，例如公共税赋的征收。

<!-- source-p 1266 -->
<a id="48.19.9.10"></a>**10**　通常会禁止某人从事某种或某些商业活动。但是否可以判令某人必须经商，值得考察。若作一般考察，这些刑罚并不合乎公民法原则：强迫他人实施其无法实施之事。但若针对特定情形考察，强迫某人经商可能存在正当理由；若确有正当理由，则应遵循该判决。

<!-- source-p 1267 -->
<a id="48.19.9.11"></a>**11**　以上是通常施加的刑罚。应知刑罚之间存在区别，并非所有人都可以受同一种刑罚。首先，市镇议员不得被判入矿场、从事矿场劳役、受刑架之刑或活活焚烧。若有人被判受此类刑罚，应予释放；但作出判决的法官无权自行采取此措施，而应向皇帝报告，由皇帝决定变更或免除刑罚。

<!-- source-p 1268 -->
<a id="48.19.9.12"></a>**12**　市镇议员的父母和子女也适用同一规则。

<!-- source-p 1269 -->
<a id="48.19.9.13"></a>**13**　这里所说的子女，不仅是儿子，而是所有子女。

<!-- source-p 1270 -->
<a id="48.19.9.14"></a>**14**　应当考虑，只有在担任市镇议员之后出生的子女才不受这些刑罚，还是所有子女都不受这些刑罚，即使他们出生于平民家庭？我认为，这一规则应使所有子女受益。

<!-- source-p 1271 -->
<a id="48.19.9.15"></a>**15**　但若父亲已不再是市镇议员，须作区分：若子女出生时父亲仍为市镇议员，该子女应受益而不受刑罚；若父亲成为平民后才有该子女，则该子女应像平民所生子女一样受罚。

<!-- source-p 1272 -->
<a id="48.19.9.16"></a>**16**　神圣庇护皇帝曾敕答萨尔维乌斯·马尔基安努斯，附条件获得自由的奴隶应被视为自由人而受刑罚。

<a id="48.19.16.pr."></a>**序言**　受处罚的行为包括作为，例如盗窃和杀人；言辞，例如侮辱和不忠实的讼务代理；书写，例如伪造文书和诽谤性文书；以及谋划，例如阴谋、知悉强盗活动，以及以劝诱方式帮助他人犯罪，后者也等同于犯罪。

<!-- source-p 1299 -->
<a id="48.19.16.1"></a>**1**　上述四类事项应从七个方面考察：原因、行为人、地点、时间、性质、数量及结果。

<!-- source-p 1300 -->
<a id="48.19.16.2"></a>**2**　其一为原因。例如，教师或父母为了管教而施以殴打，不受处罚，因为此举并非为了侵害；但若外人出于愤怒殴打某人，则应处罚。

<!-- source-p 1301 -->
<a id="48.19.16.3"></a>**3**　行为人应从两个方面考察：实施行为者与遭受行为者。同一种犯罪，奴隶与自由人所受刑罚不同；对主人或父母实施行为者，与对外人实施者不同；针对官员者与针对私人者也不同。考察这一点时，也应考虑年龄。

<!-- source-p 1302 -->
<a id="48.19.16.4"></a>**4**　地点会使同一行为成为盗窃或亵渎神物，也会使其应处死刑或较轻刑罚。

<!-- source-p 1304 -->
<a id="48.19.16.6"></a>**6**　性质，是指行为较为严重或较为轻微。例如，通常会区分现行盗窃与非现行盗窃、斗殴与拦路抢劫、掠夺与盗窃、猥亵与暴力。希腊最著名的演说家德摩斯梯尼曾这样说：

**希腊文原文（拉丁字母转写）**：*ou gar hy plygy parestyse tyn hubrin, all' hy atimia: oude to tuptesvai tois eleuverois esti deinon, kaiper on deinon, alla to eph' hubrei. polla gar poiyseien ho tuptwn, w andres avynaioi, hwn ho pavwn enia oud' an apaggeilai dunaito heterw, tw sxymati, tw blemmati, ty fwny, hotan hws hubrizwn, hotan hws exvros huparxwn, hotan kondulois, hotan epi korrys. tauta kinei, tauta ecistysin anvrwpous ahutwn ayveis ontas tou propylakizesvai.*

**校勘者所附拉丁释义**：*Neque enim plaga iniuriam [immo iram] movit, sed contumelia: neque tam verberari ingenuis intolerabile, quamquam non tolerandum, quam verberari iniuria. Multa enim, Athenienses, facere potest is qui verberat, quorum quaedam qui es subit alii ne demonstrare quidem potest, gestu adspectu voce, cum facit iniuria, cum inimicitia motus, cum pugnis ferit, eum in os. Haec exacerbant, haec faciunt, ut sui compotes amplius non sint homines non adsueti opprobriis.*

**译文**：使人愤怒的并非殴打本身，而是侮辱；对自由人而言，受到殴打固然难以忍受，然而更不可忍受的是受到侮辱性殴打。雅典人啊，殴打者可以做出许多事情，其中一些甚至无法向旁人说明：他的姿态、目光、声音；他以侮辱之意行事，因敌意而动手，用拳头打脸。这些举动会激怒人，使不习惯受辱者失去自制。

<!-- source-p 1306 -->
<a id="48.19.16.7"></a>**7**　数量可区分盗窃者与盗牲者：偷走一头猪的人按盗窃者处罚，偷走一群牲畜的人则按盗牲者处罚。

<!-- source-p 1307 -->
<a id="48.19.16.8"></a>**8**　还应考察行为结果；这一点即使最宽仁者也会考虑。尽管如此，法律对携带武器意图杀人的人与实际杀人的人，仍处以同等刑罚。因此，希腊人允许以自愿流放赎偿意外事故，正如最杰出的诗人所写：

<!-- source-p 1309 -->

**译文**：当我尚年幼时，墨诺伊提俄斯因一次惨痛的杀人事件，从奥普斯把我带到你们家中；那一天，我因掷骰争执，懵懂之中并非故意地杀死了安菲达曼提俄斯的儿子。

<a id="48.19.28.pr."></a>**序言**　死刑大致分为以下等级：最高刑罚似乎是判处绞刑；其次是活活焚烧。尽管后者理应也被称为最高刑罚，但因这种刑罚出现较晚，故被列于绞刑之后。再其次是斩首；接近死刑的是矿场拘禁；其后是流放至岛上。

<!-- source-p 1352 -->
<a id="48.19.28.1"></a>**1**　其他刑罚影响名誉，而非危及生命，例如限期或终身限居、流放至岛上、交付公共工程劳役，或处以杖击。

<!-- source-p 1353 -->
<a id="48.19.28.2"></a>**2**　并非所有人都会受杖击，只有自由人中的地位较低者才会受此刑；地位较高者不受杖击，此点已在皇帝敕答中明确规定。

<!-- source-p 1354 -->
<a id="48.19.28.3"></a>**3**　有些自称“青年”的人，在某些骚乱的城市里迎合民众，以呼喊助势。若他们未另有违法行为，且此前未受总督警告，则可在受杖击后释放，或被禁止观看公共演出。但若他们受此矫正后仍有类似行为，应处流放；有时甚至应处死刑，尤其是他们屡次煽动骚乱、行为扰乱秩序，曾多次被捕并受到宽缓处理，却仍固执地坚持同一鲁莽行为时。

<!-- source-p 1358 -->
<a id="48.19.28.7"></a>**7**　禁止以侵害他人为目的逃往皇帝雕像或肖像处避难。法律平等保障所有人的安全，因此，逃往皇帝雕像或肖像处是为了侵害他人，而非自我保护，理应禁止；但若有人被拘禁或羁押，并遭有权势者压迫而逃往此类庇护处，则应宽宥。为防止人们逃往雕像或肖像处，元老院曾作出决议；神圣庇护皇帝亦以敕答规定，若有人举起凯撒肖像意图使他人受憎恶，应将其关入公牢。

<!-- source-p 1362 -->
<a id="48.19.28.11"></a>**11**　奴隶若阴谋危害主人生命，通常应被焚烧；有时，地位低下的自由平民也受此刑。

<!-- source-p 1363 -->
<a id="48.19.28.12"></a>**12**　出于仇怨或劫掠目的，在城镇内纵火者应处死刑，通常被活活焚烧。若仅烧毁茅屋或乡间别墅，刑罚可以轻一些。对于本可避免、却因起火地的占有人疏忽而发生并损害邻人的意外火灾，应以民事方式处理，也就是由遭受损失者请求赔偿；或者仅施以较轻惩罚。

<a id="48.19.38.pr."></a>**序言**　若有人盗窃皇帝的矿场财物或神圣铸币厂财物，应处矿场刑罚及流放。

<!-- source-p 1400 -->
<a id="48.19.38.1"></a>**1**　叛逃至敌方者或泄露我方计划者，应被活活焚烧或钉在刑架上。

<!-- source-p 1401 -->
<a id="48.19.38.2"></a>**2**　煽动民众叛乱和骚乱者，应依其身份地位处以刑架之刑、投喂野兽或流放至岛上。

<!-- source-p 1402 -->
<a id="48.19.38.3"></a>**3**　奸污尚未达到婚龄的处女者，地位较低者应被判入矿场；地位较高者应被流放至岛上或驱逐出境。

<!-- source-p 1403 -->
<a id="48.19.38.4"></a>**4**　不能证明自己是以自有金钱赎回的人，不得请求自由；应将其交还同一主人并附加锁链刑罚，或者依主人选择判入矿场。

<!-- source-p 1404 -->
<a id="48.19.38.5"></a>**5**　给予堕胎药或媚药者，即使并无欺诈故意，也因其行为会造成恶劣示范而应受罚：地位较低者判入矿场，地位较高者没收部分财产后流放至岛上。若因此导致妇女或男子死亡，则应处以最高刑罚。

<!-- source-p 1405 -->
<a id="48.19.38.6"></a>**6**　依法完全无效的遗嘱，可以不受处罚地隐匿；因为任何人都不能据此提出请求，遗嘱也无法成立。

<!-- source-p 1406 -->
<a id="48.19.38.7"></a>**7**　遗嘱人在生前开启、宣读或拆封遗嘱者，应依《科尔内利亚法》承担刑罚；地位较低者通常被判入矿场，地位较高者则被流放至岛上。

<!-- source-p 1407 -->
<a id="48.19.38.8"></a>**8**　若有人证明，对方代理人泄露了其诉讼文书，则该代理人若地位较低，应被判入矿场；若地位较高，则应没收其一半财产并终身流放。

<!-- source-p 1408 -->
<a id="48.19.38.9"></a>**9**　有人将寄存于自己处的他人文书，在另一方缺席时返还，或泄露给对方的，应依其身份状况判入矿场或流放至岛上。

<!-- source-p 1409 -->
<a id="48.19.38.10"></a>**10**　简易法官若被指称受贿，通常会被总督或市镇议会免职，也可能被驱逐出境或限期流放。

<!-- source-p 1410 -->
<a id="48.19.38.11"></a>**11**　士兵若持配发的剑从监狱逃脱，应处死刑；与其一同逃走的被押送者一同逃脱者，也受同一刑罚。

<!-- source-p 1411 -->
<a id="48.19.38.12"></a>**12**　士兵若自伤但未完成自杀，除非其行为出于无法忍受疼痛、疾病、丧亲之痛或其他原因，否则应处死刑；在其他情况下，应使其蒙受不名誉后被遣送。

## D.48.20　论被判刑者的财产（*De bonis damnatorum*）

<!-- source-p 1428 -->
<a id="20"></a><a id="48.20"></a>**48.20.0**　论被判刑者的财产。

<!-- source-p 1429 -->
<a id="48.20.1"></a>**48.20.1**

<!-- source-p 1430 -->
卡利斯特拉图《国库与人民法》第1卷。

<!-- source-p 1431 -->
<a id="48.20.1.pr."></a>**序言**　若判决剥夺某人的生命、公民身份，或使其陷于奴隶身份，其财产便因该判决归公。

<!-- source-p 1432 -->
<a id="48.20.1.1"></a>**1**　即使子女在定罪前已受孕、定罪后才出生，也有权从被判刑的父亲财产中取得份额。

<!-- source-p 1433 -->
<a id="48.20.1.2"></a>**2**　但只有在合法婚姻中出生的子女，才可取得该份额。

<!-- source-p 1434 -->
<a id="48.20.1.3"></a>**3**　若某人仅有一半财产被没收，其子女不取得份额；神圣皇帝兄弟也曾以敕答作此规定。

<!-- source-p 1435 -->
<a id="48.20.2"></a>**48.20.2**

<!-- source-p 1436 -->
卡利斯特拉图《审判程序》第6卷。

<!-- source-p 1437 -->
不得仅因某人被押入监狱便剥夺其财产，而应待其被定罪后方可如此处理；神圣哈德良皇帝曾以敕答作此规定。

<!-- source-p 1438 -->
<a id="48.20.3"></a>**48.20.3**

<!-- source-p 1439 -->
乌尔比安《告示》第33卷。

<!-- source-p 1440 -->
以下五部法律规定，对被判罪的妇女没收嫁资：关于叛逆罪、公共暴力、弑亲、投毒及刺杀者的法律。

<!-- source-p 1441 -->
<a id="48.20.4"></a>**48.20.4**

<!-- source-p 1442 -->
帕皮尼安《通奸法》第2卷。

<!-- source-p 1443 -->
无论如何，丈夫对国库仍保有完整的诉权。

<!-- source-p 1444 -->
<a id="48.20.5"></a>**48.20.5**

<!-- source-p 1445 -->
乌尔比安《告示》第33卷。

<!-- source-p 1446 -->
<a id="48.20.5.pr."></a>**序言**　但若妇女依据其他法律被判处死刑，而该法并未规定没收嫁资，由于她先成为受刑奴隶，嫁资应归丈夫受益；她应被视同已经死亡。

<!-- source-p 1447 -->
<a id="48.20.5.1"></a>**1**　若家父权下的女儿被流放，马尔凯卢斯认为——这也是正确意见——流放本身并不当然解除婚姻。因为妇女仍是自由人，因此并无妨碍丈夫保有丈夫身份、妇女保有妻子身份的理由。若妇女有意离开丈夫，马尔凯卢斯说，父亲此时可以就嫁资提起诉讼。但若妇女是自权人，且在婚姻仍存续期间被流放，嫁资应继续留在丈夫处；其后若婚姻解除，妇女即可提起诉讼，此项诉权是基于衡平考虑而于今日创设的。

<!-- source-p 1448 -->
<a id="48.20.6"></a>**48.20.6**

<!-- source-p 1449 -->
乌尔比安《总督职务》第10卷。

<!-- source-p 1450 -->
神圣哈德良皇帝以如下措辞答复阿奎利乌斯·布拉杜阿：“何谓 *pannicularia*（衣物及随身小物），从其名称本身即可看出。无人可以妥当地说，被判罪者的财产属于所谓衣物及随身小物；若其身上系有腰带，也不应立即由任何人据为己有。该词所指的是其身着的衣服，或其放在衣袋里、随时可用于维持生计的少量钱币，或轻便的戒指，即价值不超过五奥里金币之物。反之，若被判罪者手指上戴有红玉髓戒指或其他贵重宝石，或衣内藏有大额债权文书，则无论如何都不得以衣物及随身小物为由保留。”衣物及随身小物，是指某人被收押时随身带入的物品；名称本身亦表明，这是被带去受刑时穿着的衣物。侦察官不得擅自据为己有，助理官也不得索取这些物品。被判刑时没收的物品，不应由总督挪为私用，也不得允许助理官或书记官擅用其钱款；这些钱款应留作总督依职权通常支出的用途，例如以此为某些职员支付文书费用，或向表现英勇的士兵赠与钱财；也可用于馈赠来访的蛮族使者或因其他事务前来者。总督有时还将汇集的钱款送入国库，但这未免过于勤勉；只要不将其用于私人用途，而是用于公务，便已足够。

<!-- source-p 1451 -->
<a id="48.20.7"></a>**48.20.7**

<!-- source-p 1452 -->
保罗《论准予被判刑者子女取得份额》单卷。

<!-- source-p 1453 -->
<a id="48.20.7.pr."></a>**序言**　自然理性仿佛一项不成文法律，使父母的遗产归属于子女，仿佛将其召为依法应继承的继承人；因此，在市民法中也称他们为“己有继承人”。父母只有基于值得重视的理由，才能以遗嘱排除他们的继承权。既然判决因父母受到刑罚而没收财产，极为公平的做法是仍考虑子女的利益，以免毫无过错的子女因他人的行为而承受更重刑罚，有时甚至陷入极端贫困。法律对此作了适度规定：依法本可通过继承取得全部遗产的人，应获准从中取得相应份额。

<!-- source-p 1454 -->
<a id="48.20.7.1"></a>**1**　若对被释奴判处刑罚，不得剥夺其释奴保护人原本可以取得的部分，即假设被判者以自然死亡而非受刑身故时，释奴保护人本可从其遗产中取得的份额。剩余部分若不属于解放该奴隶的主人，应归国库。

<!-- source-p 1455 -->
<a id="48.20.7.2"></a>**2**　被判刑者的养子女，若收养并非为欺诈目的，与亲生子女一样，也应公平地获准取得份额。即使收养发生时被判者尚未陷于刑事被告状态，只是因知悉自身处境、预料财产将丧失并担心即将遭控告，而在绝望中收养子女以使其分得财产，也应视为具有欺诈目的。

<!-- source-p 1456 -->
<a id="48.20.7.3"></a>**3**　有些先例表明，若被判刑者有多个子女，可以将其全部财产都交给这些子女。神圣哈德良皇帝也曾作出如下敕答：“阿尔比努斯子女的人数使我倾向于给予其有利的处理；与其增加钱财，我更愿意通过增加人民来扩充帝国。因此，我愿将其父亲的财产交给他们；即使他们取得全部财产，也会使这些财产拥有多个所有人。”

<!-- source-p 1457 -->
<a id="48.20.7.4"></a>**4**　子女的份额不因被判刑者以可耻手段取得的财产而增加。例如，若他安排杀害亲属，继而接受该亲属的遗产或取得其遗产占有，神圣庇护皇帝曾以敕答作此规定。该皇帝也据此确立：若家父权下的女儿被证明以毒药杀害指定她为继承人的人，即使她依其父亲——亦即对其行使家父权者——的命令接受了遗产，该遗产仍应归国库。

<!-- source-p 1458 -->
<a id="48.20.7.5"></a>**5**　被判刑者财产已被没收后所取得的财产，若其仅被限居，归其遗嘱指定的继承人或无遗嘱继承人所有；因为被限居至岛上的人保有作成遗嘱的资格及其他权利。若其被驱逐出境，则因其丧失公民身份而不能有继承人，此后取得的财产也由国库取得。

<!-- source-p 1459 -->
<a id="48.20.8"></a>**48.20.8**

<!-- source-p 1460 -->
马凯尔《公诉案件》第……卷。

<!-- source-p 1461 -->
<a id="48.20.8.pr."></a>**序言**　若父亲的释奴财产被没收，释奴保护人的子女仍完整保有释奴保护权。若该释奴保护人的儿子仍在，则国库不得取得属于该保护人儿子的份额。

<!-- source-p 1462 -->
<a id="48.20.8.1"></a>**1**　若释奴的子女排除了释奴保护人之子，则较妥当的意见是国库无权取得该份额，因为排除释奴保护人之子的是释奴子女，而释奴保护人之子本人则排除国库。

<!-- source-p 1463 -->
<a id="48.20.8.2"></a>**2**　即使释奴保护人的儿子没有请求遗产占有，他显然仍会在其应得份额范围内排除国库对父亲原有释奴财产的请求。

<!-- source-p 1464 -->
<a id="48.20.8.3"></a>**3**　可以通过特别判决没收被限居者的财产；但除非皇帝下令，不得剥夺其对释奴的权利。

<!-- source-p 1465 -->
<a id="48.20.8.4"></a>**4**　若父亲被判罪，而他曾为女儿提供嫁资，国库对该嫁资无权主张；即使女儿后来在婚姻存续期间死亡，亦同。

<!-- source-p 1466 -->
<a id="48.20.9"></a>**48.20.9**

<!-- source-p 1467 -->
卡利斯特拉图《……卷》。

<!-- source-p 1468 -->

<!-- source-p 1469 -->
<a id="48.20.10"></a>**48.20.10**

<!-- source-p 1470 -->
马凯尔《公诉案件》第……卷。

<!-- source-p 1471 -->
<a id="48.20.10.pr."></a>**序言**　即使父亲在为女儿允诺嫁资后被判罪，女婿仍可向国库请求从其财产中支付该嫁资。

<!-- source-p 1472 -->
<a id="48.20.10.1"></a>**1**　若女儿的父亲在婚姻解除后被判罪，且女儿此前已同意请求返还嫁资，则国库可以向丈夫请求该嫁资；若父亲在女儿同意之前便被判罪，则由女儿本人请求返还。

<!-- source-p 1473 -->
<a id="48.20.11"></a>**48.20.11**

<!-- source-p 1474 -->
马尔基安《公诉案件》第……卷。

<!-- source-p 1475 -->
<a id="48.20.11.pr."></a>**序言**　被判罪者若提起上诉，并在上诉待决期间死亡，其财产不得没收；其遗嘱仍然有效。即使上诉未被受理，亦同。

<!-- source-p 1476 -->
<a id="48.20.11.1"></a>**1**　被控犯下叛逆罪以外犯罪的人，可以管理财产、出借钱款，并在债务人善意向其清偿时收取其债权；但其为诈害国库而处分的财产，在其被判刑后应予追回。

## D.48.21　论在判决前自杀或贿赂控告人者的财产（*De bonis eorum, qui ante sententiam vel mortem sibi consciverunt vel accusatorem corruperunt*）

<!-- source-p 1477 -->
<a id="21"></a><a id="48.21"></a>**48.21.0**　论在判决前自杀或贿赂控告人者的财产。

<!-- source-p 1478 -->
<a id="48.21.1"></a>**48.21.1**

<!-- source-p 1479 -->
乌尔比安《论题》第8卷。

<!-- source-p 1480 -->
皇帝们已裁定，在死罪案件中，贿赂对方者不因此受不利处理；但仅限于法定刑包含死刑的案件。皇帝认为，应宽恕以任何方式救回自己性命的人。

<!-- source-p 1481 -->
<a id="48.21.2"></a>**48.21.2**

<!-- source-p 1482 -->
马凯尔《公诉案件》第2卷。

<!-- source-p 1483 -->
<a id="48.21.2.pr."></a>**序言**　“塞维鲁与安敦尼皇帝致尤利乌斯·尤利安努斯：那些被强盗指认为同伙、随后贿赂控告人并死亡的人，既已被视为承认犯罪，便合理地不再由其继承人继续辩护。”

<!-- source-p 1484 -->
<a id="48.21.2.1"></a>**1**　若某人因其案件已呈报皇帝，例如其为市镇议员，或应被流放至岛上，在皇帝答复之前便死亡，可以讨论他是否算在判决前死亡。关于被送往罗马的人尚未判决便死亡一事，有元老院决议可作参照；其措辞如下：“在罗马尚未对某人审理并宣判之前，不得认为他在本年度内已被判罪；在罗马尚未对死者宣判之前，也未没收任何死者的财产；其继承人应占有这些财产。”〔底本疑误：*decessissententiarum* 一词疑为相邻文字粘连，须对照校勘本核实。〕

<!-- source-p 1485 -->
<a id="48.21.3"></a>**48.21.3**

<!-- source-p 1486 -->
马尔基安《告发人论》单卷。

<!-- source-p 1487 -->
<a id="48.21.3.pr."></a>**序言**　被正式控告者，或犯罪时被当场发现者，若因担心迫近的刑事指控而自杀，便没有继承人。然而，帕皮尼安在《学说汇纂》第16卷《答复》中写道：未被正式控告犯罪的人若自杀，其财产不得归国库；因为法律认为，应使犯罪行为本身承担责任，而非仅因被告的内心恐惧便如同已承认犯罪一样处罚。因此，只有被正式控告或犯罪时被当场发现者自杀，其财产才应被没收。

<!-- source-p 1488 -->
<a id="48.21.3.1"></a>**1**　正如神圣庇护皇帝曾敕答，只有在自陷刑事被告状态而自杀者所涉犯罪，若其被判罪本应处死刑或流放时，其财产才应归国库。

<!-- source-p 1489 -->
<a id="48.21.3.2"></a>**2**　他还敕答说，若有人仅被控轻微盗窃，即使其上吊结束生命，也不应视为处于必须剥夺继承人财产的情形；如果查明其确实施盗窃，也不会因此剥夺其本人财产。

<!-- source-p 1490 -->
<a id="48.21.3.3"></a>**3**　因此，只有在自杀者所涉犯罪一经证明即可使其丧失全部财产时，才应认定其财产归国库。

<!-- source-p 1491 -->
<a id="48.21.3.4"></a>**4**　神圣安敦尼皇帝曾敕答：若有人因厌倦生活、无法忍受某种痛苦或其他原因而结束生命，其仍可有继承人。

<!-- source-p 1492 -->
<a id="48.21.3.5"></a>**5**　神圣哈德良皇帝曾敕答：某父亲自杀，据称是因为杀害了自己的儿子；更可能的是，他因丧子悲痛而自杀，因此其财产不得没收。

<!-- source-p 1493 -->
<a id="48.21.3.6"></a>**6**　自杀是否导致财产没收，应根据自杀原因加以区分。同样，在判断某人自伤却未遂是否应受罚、是否应视同对自己作出判决时，也应作此区分。若非因厌倦生活或无法忍受某种痛苦而自杀未遂，无论如何都应受罚；若其无故自伤，理应受罚，因为不顾惜自己的人更不会顾惜他人。

<!-- source-p 1494 -->
<a id="48.21.3.7"></a>**7**　皇帝敕令规定：若某些人在案件结果未明时仍被羁押或由担保人担保，期间死亡，其财产不得没收。

<!-- source-p 1495 -->
<a id="48.21.3.8"></a>**8**　若有人在无正当原因的情况下自杀并在刑事被告状态中死亡，还应考察：若继承人愿意承接案件并证明死者无罪，是否应听取其辩护，且在犯罪尚未证明前不将财产交归国库，还是无论如何均应没收？神圣庇护皇帝曾敕答莫德斯图斯·陶里努斯：若继承人愿意提出辩护，在犯罪获得证明之前，不应没收财产。

<a id="48.22.6.pr."></a>**序言**　流放至岛上也是一种刑罚；此种刑罚会剥夺罗马公民身份。

<!-- source-p 1515 -->
<a id="48.22.6.1"></a>**1**　行省总督无权将人驱逐至岛上，但罗马城长官有此权；神圣塞维鲁皇帝致罗马城长官法比乌斯·基洛的书信明确说明了这一点。因此，行省总督若认为某人应被驱逐至岛上，应先作此记录，并将其姓名呈报皇帝，由皇帝决定是否准其驱逐；随后，总督应提交附有完整意见的报告，由皇帝判断是否采纳总督意见并驱逐此人。在等待皇帝答复期间，总督应命令此人羁押于监狱。

<!-- source-p 1516 -->
<a id="48.22.6.2"></a>**2**　神圣皇帝兄弟敕答，市镇议员若犯下死罪，可以被驱逐至岛上或限居。最终，他们曾命令将普里斯库斯驱逐至岛上；此人因杀人和纵火，在刑讯之前便亲自供认。

<!-- source-p 1517 -->
<a id="48.22.7"></a>**48.22.7**

<!-- source-p 1518 -->
乌尔比安《总督职务》第10卷。

<!-- source-p 1519 -->
<a id="48.22.7.pr."></a>**序言**　被限居者有两类：一类被限居在岛上；另一类仅被禁止进入某些行省，并未指定某一岛屿。

<!-- source-p 1520 -->
<a id="48.22.7.1"></a>**1**　行省总督可以将人限居于岛上，但有条件：若其管辖范围内有岛屿，即属于其所治理行省的岛屿，可以具体指定该岛并将人限居在那里；若其管辖范围内没有岛屿，则应宣告将此人限居于某岛，并向皇帝报告，由皇帝指定岛屿。总督不得判某人限居在其所辖行省之外的岛上。在皇帝指定岛屿之前，应将被限居者交由士兵看管。

<!-- source-p 1521 -->
<a id="48.22.7.2"></a>**2**　驱逐出境与限居之间的区别在于，限居可以定期，也可以终身。

<!-- source-p 1522 -->
<a id="48.22.7.3"></a>**3**　无论某人被定期还是终身限居，均保有罗马公民身份及作成遗嘱的资格。

<!-- source-p 1523 -->
<a id="48.22.7.4"></a>**4**　某些敕答明确指出，不应剥夺被定期限居者的全部或部分财产；那些曾剥夺定期限居者部分财产或全部财产的判决受到了批评，但这些判决仍不因此失效。

<!-- source-p 1524 -->
<a id="48.22.7.5"></a>**5**　在埃及行省，将人限居于绿洲，也是一种类似于限居岛上的流放方式。

<!-- source-p 1525 -->
<a id="48.22.7.6"></a>**6**　正如任何人不得将他人限居于其管辖范围之外的岛屿，也不得将其限居于自己管辖范围之外的行省；例如，叙利亚总督不得将人限居于马其顿。

<!-- source-p 1526 -->
<a id="48.22.7.7"></a>**7**　但总督可以将人逐出自己所辖行省。

<!-- source-p 1527 -->
<a id="48.22.7.8"></a>**8**　总督也可以命某人只在行省特定部分居留，例如不得进入某一城市，或不得离开某一区域。

<!-- source-p 1528 -->
<a id="48.22.7.9"></a>**9**　我知道，总督通常也会将人限居于行省较为荒僻的地区。

<!-- source-p 1529 -->
<a id="48.22.7.10"></a>**10**　某人只能被禁止进入其所治理的行省，不得由其禁止进入其他行省；神圣皇帝兄弟曾以敕答作此规定。因此，若某人被禁止进入其居住的行省，仍可能住在其出生地。然而，我国皇帝与其神圣父皇已对此作出处理。他们敕答西班牙行省总督梅基乌斯·普罗布斯说，治理某行省的总督，也可禁止某人进入其出生地所在行省，而该人居住在另一行省。若某人在并非其居住地的行省实施犯罪，使其受该敕答授权约束，也属公平。

<!-- source-p 1530 -->
<a id="48.22.7.11"></a>**11**　有人曾怀疑：若总督治理某人居住的行省，他是否可以禁止此人进入其出生地所在行省，而不禁止其进入自己治理的行省？就像有些人禁止他人进入意大利，却不禁止其进入故乡。或者，是否应推知总督连自己治理的行省也一并禁止进入？后一意见较可取。

<!-- source-p 1531 -->
<a id="48.22.7.12"></a>**12**　反之，治理某人出生地所在行省的总督，并未因此取得禁止该人进入其居住地所在行省的权力。

<!-- source-p 1532 -->
<a id="48.22.7.13"></a>**13**　若接受如下意见：某人在另一行省犯罪，可以由治理该行省的总督限居，那么此人除意大利外，可能必须避开三个行省：犯罪地行省、居住地行省及出生地行省。若因其本人身份或父母、释奴保护人的身份而被视为来自多个行省，也可推知他被禁止进入多个行省。

<!-- source-p 1533 -->
<a id="48.22.7.14"></a>**14**　某些总督获特别授权，可以禁止他人进入多个行省，例如叙利亚和达契亚的总督。

<!-- source-p 1534 -->
<a id="48.22.7.15"></a>**15**　已经确定，某人若被禁止进入其故乡，也必须避开罗马城；反之，若某人仅被禁止进入罗马城，并不视为同时被禁止进入其故乡。许多敕令都作了此项规定。

<!-- source-p 1535 -->
<a id="48.22.7.16"></a>**16**　若某人被禁止进入的不是其故乡，而是某个其他城市，应考察是否也应视为禁止其进入故乡及罗马城；较可取的意见是应当如此。

<!-- source-p 1536 -->
<a id="48.22.7.17"></a>**17**　总督可以且通常会为被限居者确定离境期限；判决中惯常写道：“我将某人限居于某行省及若干岛屿，他应于某日之前离开。”

<!-- source-p 1537 -->
<a id="48.22.7.18"></a>**18**　神圣皇帝兄弟曾敕答，被限居者可以向皇帝提交请愿书。

<!-- source-p 1538 -->
<a id="48.22.7.19"></a>**19**　判决有时还会禁止某人在故乡领土或城墙范围内停留，也会禁止其离开故乡，或命其留居于某些村庄。

<!-- source-p 1539 -->
<a id="48.22.7.20"></a>**20**　有时会以判决禁止市镇议员担任议员职务，期限可以是暂时或永久。

<!-- source-p 1540 -->
<a id="48.22.7.21"></a>**21**　也可以判令某人不得取得官职；但此种处罚不使其丧失市镇议员身份，因为一个人可以仍是市镇议员，却不得担任官职。正如某人可以是元老院成员，却不再谋求担任官职。

<!-- source-p 1541 -->
<a id="48.22.7.22"></a>**22**　也可以禁止某人担任某一项官职。但若其被禁止担任某项官职，不仅不得谋求该职，也不得谋求高于该职的官职；因惩罚而被禁止担任低级官职的人，竟谋求高级官职，实在荒谬。反之，被禁止担任高级官职者，并不因此不得谋求低级官职。若某人因刑罚而被禁止承担公共义务，该判决则无效，因为刑罚不应给予其豁免。因此，若以刑罚禁止某人担任官职，而这些官职又附有繁重的混合义务，则可以说，名誉上的禁令不能使其免除此等负担：

<!-- source-p 1542 -->
<a id="48.22.8"></a>**48.22.8**

<!-- source-p 1543 -->
马尔基安《公诉案件》第2卷。

<!-- source-p 1564 -->
<a id="48.22.14.2"></a>**2**　皇帝、元老院、长官及行省总督均可判处限居，但执政官无此权。

<!-- source-p 1565 -->
<a id="48.22.14.3"></a>**3**　丧失公民身份但仍有财产的人，债权人可以对其提起具有类似效力的诉讼。

<a id="48.22.15.pr."></a>**序言**　被驱逐出境者丧失公民身份，但保有自由；其不享有市民法上的权利，却适用万民法。因此，其可以买卖、出租、承租、交换、放贷及实施其他类似行为。故其被定罪后取得的财产，也能有效设定债务。当被驱逐出境者死亡后，国库继受其财产，但在此之前与其善意订约的债权人，优先于国库受偿。至于被定罪时已经存在的财产，被驱逐出境者不得处分。

<a id="48.22.18.pr."></a>**序言**　被限居者不得留在罗马，即使判决未明确载明此项禁令，因为罗马是共同的故乡；其也不得停留在皇帝居住或经过的城市，因为只有获准进入罗马的人，才获准觐见作为祖国之父的皇帝。

<!-- source-p 1581 -->
<a id="48.22.18.1"></a>**1**　若对自由人作出一种判决，将其财产没收，例如流放至岛上的判决，则他们自该判决作出时起即丧失先前身份，并立即承受判决所科的刑罚；除非涉及皇帝尊严的事项需要加重刑罚。

## D.48.23　论承受判决并获恢复者（*De sententiam passis et restitutis*）

<!-- source-p 1582 -->
<a id="23"></a><a id="48.23"></a>**48.23.0**　论承受判决并获恢复者。

<!-- source-p 1583 -->
<a id="48.23.1"></a>**48.23.1**

<!-- source-p 1584 -->
乌尔比安《告示》第38卷。

<!-- source-p 1585 -->
<a id="48.23.1.pr."></a>**序言**　被驱逐出境后又获恢复者，可以作为其原释奴的释奴保护人参与继承。

<!-- source-p 1586 -->
<a id="48.23.1.1"></a>**1**　但若某人被判入矿场后又获恢复，其成为受刑奴隶的状态是否会连同其恢复后的释奴保护权一并消灭？较可取的意见是，受刑奴隶身份不消灭释奴保护权。

<!-- source-p 1587 -->
<a id="48.23.2"></a>**48.23.2**

<!-- source-p 1588 -->
乌尔比安《意见》第5卷。

<!-- source-p 1589 -->
被驱逐出境者若经皇帝宽赦而恢复身份，但并未恢复其全部财产，则债权人或公权机关均不得向其请求清偿。不过，若皇帝曾允许其取回财产，而他宁愿放弃财产，则不得借此免除其在判决前所负的责任。

<!-- source-p 1590 -->
<a id="48.23.3"></a>**48.23.3**

<!-- source-p 1591 -->
帕皮尼安《答复》第16卷。

<!-- source-p 1592 -->
被驱逐至岛上的人的财产，即使刑罚已被赦免，仍由国库保有；已知其先前债权人不得对曾为其债务人的人提起诉讼。若此人恢复财产并恢复身份地位，则无需授予必要的类似效力诉权，因为直接诉权也已适用。

<!-- source-p 1593 -->
<a id="48.23.4"></a>**48.23.4**

<!-- source-p 1594 -->
保罗《疑问》第17卷。

<!-- source-p 1595 -->
一名被判入矿场的妇女生下了她先前怀上的孩子，之后获皇帝恢复身份。较为人道的说法是，应认为她也恢复了亲属关系方面的权利。

## D.48.24　论受刑者的尸体（*De cadaveribus punitorum*）

<!-- source-p 1596 -->
<a id="24"></a><a id="48.24"></a>**48.24.0**　论受刑者的尸体。

<!-- source-p 1597 -->
<a id="48.24.1"></a>**48.24.1**

<!-- source-p 1598 -->
乌尔比安《总督职务》第9卷。

<!-- source-p 1599 -->
不得拒绝将被判死刑者的尸体交给其亲属；神圣奥古斯都在《自述》第10卷中记载自己也遵行此规则。但如今，被处决者的尸体只有在有人请求且获准时才予安葬；有时不予许可，尤其是因叛逆罪被判刑者。被判处焚烧者的尸体也可以请求领回，以便收集其骨骸和骨灰后加以安葬。

<!-- source-p 1600 -->
<a id="48.24.2"></a>**48.24.2**

<!-- source-p 1601 -->
马尔基安《公诉案件》第2卷。

<!-- source-p 1602 -->
若某人被驱逐至岛上或被限居，刑罚在其死后仍然存续；未经皇帝咨询，不得将其尸体迁往别处安葬。塞维鲁与安敦尼皇帝曾屡次以敕答作此规定，也曾应许多人的请求，特别准许这样做。

<!-- source-p 1603 -->
<a id="48.24.3"></a>**48.24.3**

<!-- source-p 1604 -->
保罗《判例集》第1卷。

<!-- source-p 1605 -->
被处决者的尸体，应交给任何提出请求的人安葬。
