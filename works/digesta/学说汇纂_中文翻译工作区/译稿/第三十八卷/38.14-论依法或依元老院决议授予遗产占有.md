# D.38.14 论依法或依元老院决议授予遗产占有（*Ut ex legibus senatusve consultis bonorum possessio detur*）

<!-- source-p 814 -->
<a id="14"></a><a id="38.14"></a>**38.14.0 论依法或依元老院决议授予遗产占有**（*Ut ex legibus senatusve consultis bonorum possessio detur*）。

<!-- source-p 815 -->
<a id="38.14.1"></a>**38.14.1**

<!-- source-p 816 -->
乌尔比安《告示评注》第四十九卷。

<!-- source-p 817 -->
<a id="38.14.1.pr."></a>**序言**　裁判官说：“*Uti me quaque lege senatus consulto bonorum possessionem dare oportebit, ita dabo*”（凡我依任何法律或元老院决议应当授予遗产占有的，我都将予以授予）。

<!-- source-p 818 -->
<a id="38.14.1.1"></a>**1**　某人依据告示其他部分已经取得遗产占有，并不妨碍其依据本部分取得遗产占有。

<!-- source-p 819 -->
<a id="38.14.1.2"></a>**2**　某人若依据《十二表法》取得继承权，并非请求本部分规定的遗产占有，而是依据告示中“*tum quem ei heredem esse oportet*”（因此，谁应当成为他的继承人）这一部分请求；因为除非法律特别授予遗产占有，否则本部分并不适用。
