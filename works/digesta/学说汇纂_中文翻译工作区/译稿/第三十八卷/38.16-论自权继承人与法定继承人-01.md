<a id="16"></a><a id="38.16"></a>**38.16.0 论自权继承人与法定继承人**（*De suis et legitimis heredibus*）。

<!-- source-p 847 -->
<a id="38.16.1"></a>**38.16.1**

<!-- source-p 848 -->
乌尔比安《萨宾评注》第十二卷。

<!-- source-p 849 -->
<a id="38.16.1.pr."></a>**序言。**严格而言，只有本可立遗嘱却未立遗嘱的人，才称为无遗嘱死亡。某人虽立有遗嘱，但其遗产未被接受，或者遗嘱被撤销或无效，也可以不无道理地说他无遗嘱死亡。确实，不能立遗嘱的人严格说来并非无遗嘱死亡，例如未达适龄者、精神失常者，或被禁止管理财产者；不过，我们也应将这些人按无遗嘱死亡者处理。被敌人俘获的人亦如此：依《科尔内利亚法》，继承权归属于在其于罗马共同体内死亡时本可取得继承权的人；因为其遗产也被认为仍然存在。

<!-- source-p 850 -->
<a id="38.16.1.1"></a>**1.**可以提出这样的问题：若子女是由一名因遗嘱信托式释奴而获释迟延的女子所生，该子女是否为其父亲的自权继承人？既然马可皇帝、维鲁斯皇帝及我们的安东尼努斯·奥古斯都在敕答中认为，此类子女出生时为自由民，为什么不彻底将该女子视同已获释，使其丈夫所生之子成为自权继承人？由奴隶所生之人可以是自由民，这并不奇怪；因为敕答也曾认定，由被俘女子所生者为自由民。因此，我敢于说，即使该子女的父亲与母亲一样，因遗嘱信托式释奴而迟延获释，且父亲本人也曾遭遇这种迟延，该子女仍应仿照与被俘父母一同归返者，成为父亲的自权继承人。于是，若其父亲后来在迟延后才获释，就会重新取得对该子女的家父权；若父亲在此之前已经死亡，则应认定该子女为其自权继承人。

<!-- source-p 851 -->
<a id="38.16.1.2"></a>**2.**这里的自权继承人，包括儿子、女儿，无论是自然子女还是收养子女。

<!-- source-p 852 -->
<a id="38.16.1.3"></a>**3.**有时，即使是自权继承人，也会因国库优先而被排除；例如，父亲死后被判犯有叛国罪时，甚至可能导致其子不得享有墓葬权。〔底本本句疑有缺漏或讹误。〕

<!-- source-p 853 -->
<a id="38.16.1.4"></a>**4.**若儿子不再是自权继承人，所有由他所生且处于家父权之下的孙子女，均代位取得其原有份额；这符合自然衡平。儿子因大身份减等或小身份减等而脱离家父权，就不再是自权继承人。但若儿子被敌人俘获，只要他仍活着，孙子女就不得代位继承。因此，即使他获赎，也须等到赎金付清后孙子女才能代位；若他在此期间死亡，而法律又认为他恢复身份后才死亡，孙子女仍会被他排除。

<!-- source-p 854 -->
<a id="38.16.1.5"></a>**5.**有时，父亲并非不再处于家父权之下，而是从未开始处于该权力之下。例如，我的儿子在我父亲仍在世时被敌人俘获，随后我父亲成为家父并死亡；此时孙子女将代位于其父亲。

<!-- source-p 855 -->
<a id="38.16.1.6"></a>**6.**孙女与孙子一样，也会代位于其父母。

<!-- source-p 856 -->
<a id="38.16.1.7"></a>**7.**有时，某人的父亲既未停止处于家父权之下，也从未开始处于该权力之下，我们仍说其子女可以代位继承。例如，我自权人收养某人时，他的儿子已被敌人俘获，而孙子留在罗马共同体内；收养的儿子死亡后，被俘的儿子也在敌境死亡，那么这个曾孙就是我的自权继承人。

<!-- source-p 857 -->
<a id="38.16.1.8"></a>**8.**须知，有时孙子及更后代即使其父母先于他们在立遗嘱人死亡时死亡，仍可成为自权继承人，尽管自权继承人之间不存在代位继承。情形如下：家父立遗嘱后死亡，遗嘱排除了儿子的继承权；在遗嘱指定的继承人尚在考虑是否接受遗产时，该儿子死亡；之后，遗嘱指定的继承人放弃遗产。正如马尔凯鲁斯在《告示评注》第十卷所写，孙子可以成为自权继承人，因为遗产从未归属于其父亲。若儿子被指定为全部遗产的继承人，附有由其本人决定是否成就的条件，或者孙子被指定为全部遗产的继承人但未成就所附条件而死亡，也应作同样判断：只要在立遗嘱人死亡时，他们仍然活着或至少已经受孕，自权继承人即可代位；尤利安和马尔凯鲁斯也持此见解。

<!-- source-p 858 -->
<a id="38.16.1.9"></a>**9.**自权继承人之后，立即召集同父血亲继承人。

<!-- source-p 859 -->
<a id="38.16.1.10"></a>**10.**卡西乌斯将同父血亲界定为彼此有血缘联系的人。正确而言，即使他们未能成为父亲的自权继承人，例如被遗嘱排除继承者，彼此仍为同父血亲；若其父被流放，亦然，尽管他们未成为父亲的自权继承人。那些从未处于家父权之下的人也彼此为同父血亲，例如父亲被俘后或死亡后出生的人。

<!-- source-p 860 -->
<a id="38.16.1.11"></a>**11.**不仅自然子女，收养子女也与属于同一家属共同体的人，以及在父亲死亡前已受孕或死亡后出生的人，享有同父血亲关系。

<!-- source-p 861 -->
<a id="38.16.2"></a>**38.16.2**

<!-- source-p 862 -->
乌尔比安《萨宾评注》第十三卷。

<!-- source-p 863 -->
<a id="38.16.2.pr."></a>**序言。**没有同父血亲时，依法理应准许宗亲继承，因为宗亲是在同父血亲之后才被准许继承。若存在同父血亲，即使他们没有接受遗产，继承也不会转由法定继承人取得。但只有在不再期待会有同父血亲出现时，才应如此理解；若仍可能有同父血亲出生，或从敌境归返，宗亲就会被阻却。

<!-- source-p 864 -->
<a id="38.16.2.1"></a>**1.**宗亲是沿男性系谱出自同一祖先的亲属。因为在自权继承人和同父血亲之后，我的同父血亲之子与我彼此最为亲近；父亲的兄弟，即叔父，也属此类；此后如有其他由同一男性系谱产生的亲属，依次递推，不限世代。

<!-- source-p 865 -->
<a id="38.16.2.2"></a>**2.**法定继承权归于最近的宗亲，也就是无人先于其取得继承顺位的人；若数人处于同一亲等，则由他们共同取得，按人头平均分配。例如，我有两名兄弟或两名叔父，其中一人留下一个儿子，另一人留下两个儿子；我的遗产将分为三份。

<!-- source-p 866 -->
<a id="38.16.2.3"></a>**3.**宗亲是因出生还是因收养而取得身份，并不重要；被收养者与其父亲相同的人成为宗亲，并可取得这些人的法定继承权，反之亦然。

<!-- source-p 867 -->
<a id="38.16.2.4"></a>**4.**法定继承只归于最近的宗亲。最近者是一人、两人、多人，无论他们先于其他亲属还是只有他们处于该亲等，都不重要；因为最近者就是无人先于其取得顺位者，最远者就是无人后于其取得顺位者。有时，唯一应召的人同时也是第一顺位和最后顺位。

<!-- source-p 868 -->
<a id="38.16.2.5"></a>**5.**有时也会准许较远亲等的宗亲继承。例如，有人立遗嘱时有一名叔父及叔父之子；遗嘱指定的继承人尚在考虑是否接受遗产时，叔父死亡，随后遗嘱指定的继承人放弃继承；此时叔父之子将获准继承。因此，他也可以请求遗产占有。

<!-- source-p 869 -->
<a id="38.16.2.6"></a>**6.**我们所说的最近亲属，不是家父死亡时最近的亲属，而是在确定其无遗嘱死亡时最近的亲属。据此，若原先先于他的人是自权继承人或同父血亲，但在遗嘱继承被放弃时均已死亡，我们就以放弃继承时处于第一顺位的人为最近亲属。

<!-- source-p 870 -->
<a id="38.16.2.7"></a>**7.**因此，很值得探讨的是：放弃继承后，我们是否仍授予代位继承。设遗嘱指定继承人受托返还遗产，却放弃继承；神圣的庇护皇帝曾敕答，即使遗嘱指定继承人本可被迫接受继承并返还遗产，也属此种情形。假设该人又活了一百日，而期间最近的亲属死亡，随后受托返还遗产的人也死亡；那么，应准许较远的继承人继承，但其须承担遗嘱信托义务。

<!-- source-p 871 -->
<a id="38.16.3"></a>**38.16.3**

<!-- source-p 872 -->
乌尔比安《萨宾评注》第十四卷。

<!-- source-p 873 -->
<a id="38.16.3.pr."></a>**序言。**被释奴无遗嘱死亡时，继承首先归于其自权继承人；若没有自权继承人，则归于释奴保护人。

<!-- source-p 874 -->
<a id="38.16.3.1"></a>**1.**这里的被释奴，是指某人使其脱离奴隶身份并取得罗马公民身份的人，无论是自愿还是因受遗嘱信托委托而不得不将其释放；因为委托释放者也获准取得该被释奴的法定继承。

<!-- source-p 875 -->
<a id="38.16.3.2"></a>**2.**若有人解放一名嫁资奴隶，他就被视为释奴保护人，并获准取得该被释奴的法定继承。

<!-- source-p 876 -->
<a id="38.16.3.3"></a>**3.**若我依约定买入某人，条件是我应将其解放，即使他依据神圣的马可皇帝敕令取得自由，仍依该敕令明文成为我的被释奴，其法定继承也归于我。

<!-- source-p 877 -->
<a id="38.16.3.4"></a>**4.**若某奴隶揭发其主人的谋杀，并依元老院决议获得自由，又当如何？若裁判官指定他是谁的被释奴，毫无疑问，他就是该人的被释奴，法定继承也归于该人。若裁判官未作指定，他虽成为罗马公民，却成为最近曾拥有他的人的被释奴；该人即可取得其法定继承，除非某种情形下因其不适格而应拒绝授予继承。

<!-- source-p 878 -->
<a id="38.16.3.5"></a>**5.**若有人迫使女被释奴宣誓“不得非法结婚”，他不应因此触犯《埃利乌斯·森提乌斯法》。但若他要求她“在特定期限内不得结婚”“不得嫁给释奴保护人未同意的任何人”“只能嫁给共同获释的被释奴”或“只能嫁给释奴保护人的亲属”，则应当说，他触犯了《埃利乌斯·森提乌斯法》，并不得取得该女被释奴的法定继承。

<!-- source-p 879 -->
<a id="38.16.3.6"></a>**6.**若市镇共同体解放一名奴隶，该共同体即可取得其无遗嘱死亡的男被释奴或女被释奴的法定继承。

<!-- source-p 880 -->
<a id="38.16.3.7"></a>**7.**军人解放其特有产中的奴隶后，该奴隶即成为其被释奴；军人也获准取得该被释奴的法定继承。

<!-- source-p 881 -->
<a id="38.16.3.8"></a>**8.**皇帝获准取得其被释奴的财产，这一点再明显不过。

<!-- source-p 882 -->
<a id="38.16.3.9"></a>**9.**依《十二表法》，胎儿若出生，也获准取得法定继承。胎儿会延缓其后位宗亲的继承；若其出生，就优先于他们。因此，胎儿也会为同一亲等的人形成一份份额。例如，已有一名兄弟和一个胎儿，或者已有一名叔父之子出生，另有一名叔父之子仍在母腹中。

<!-- source-p 883 -->
<a id="38.16.3.10"></a>**10.**曾有人讨论胎儿应形成多少份额，因为同一母腹可能生出数名子女。裁定认为，若事实已能确定自称怀孕的女子并未怀孕，已出生的继承人就取得全部遗产；因为即使当事人不知道自己是继承人，也可以成为继承人。因此，若此人在此期间死亡，全部遗产都会传给他的继承人。

<!-- source-p 884 -->
<a id="38.16.3.11"></a>**11.**父亲死亡十个月后才出生的人，不得取得法定继承。

<!-- source-p 885 -->
<a id="38.16.3.12"></a>**12.**关于在第一百八十二日出生的人，希波克拉底曾作论述，神圣的庇护皇帝也曾向祭司团作出敕答，认为其出生时间适当；而且不应认为他是在奴隶身份期间受孕，因为其母亲在第一百八十二日前已经获释。
