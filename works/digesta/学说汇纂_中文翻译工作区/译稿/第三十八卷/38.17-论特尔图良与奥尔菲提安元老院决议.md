# D.38.17 论《特尔图良与奥尔菲提安元老院决议》（*Ad senatus consultum Tertullianum et Orphitianum*）

<!-- source-p 926 -->
<a id="17"></a><a id="38.17"></a>**38.17.0 论《特尔图良与奥尔菲提安元老院决议》**（*Ad senatus consultum Tertullianum et Orphitianum*）。

<!-- source-p 927 -->
<a id="38.17.1"></a>**38.17.1**

<!-- source-p 928 -->
乌尔比安《评萨宾》第十二卷。

<!-- source-p 929 -->
<a id="38.17.1.pr."></a>**序言**　无论母亲是自由出生者还是自由释奴，其子女均可依据《奥尔菲提安元老院决议》继承她的遗产。

<!-- source-p 930 -->
<a id="38.17.1.1"></a>**1**　若母亲的身份尚有疑问——例如不能确定她是自权家母（*mater familias*）还是处于父权之下的家女（*filia familias*），因为她的父亲已被敌人俘虏——一旦确定她是自权家母，其子女便可获准继承。由此可以讨论：身份尚未确定期间（*status pendet*），裁判官是否应救济子女，以免他们在此期间死亡后，无法将继承权传给自己的继承人。较妥当的意见是应给予救济；许多类似情形也采此意见。

<!-- source-p 931 -->
<a id="38.17.1.2"></a>**2**　非婚生子女也可以请求继承母亲的法定遗产。

<!-- source-p 932 -->
<a id="38.17.1.3"></a>**3**　有时，即使在奴隶身份中受孕的子女，也应准许继承母亲的法定遗产；例如母亲因遗嘱信托获释而迟延，子女在迟延期间出生。若子女在母亲获释后出生，即使其受孕时母亲仍是奴隶，也应准许其继承母亲的法定遗产。若子女由被俘的母亲在敌境受孕，之后随母亲一同归来，根据我们的皇帝及其神圣父亲对奥维尼乌斯·特尔图卢斯所作敕答，也可以依本元老院决议准许其继承，视同非婚生子女。

<!-- source-p 933 -->
<a id="38.17.1.4"></a>**4**　若儿子在母亲死亡时是罗马公民，却在接受继承之前被降为奴隶身份，则不得向其转归法定继承；即使他之后恢复自由，也仍不得继承，但若其成为刑罚奴隶后经皇帝恩准恢复自由，则属例外。

<!-- source-p 934 -->
<a id="38.17.1.5"></a>**5**　若剖腹取出的儿子出生，更妥当的意见是也准许他取得法定继承；因为他本可依遗嘱书板取得继承，也可无遗嘱地依据“最近亲属”或“法定继承人”顺位请求遗产占有。以胎儿名义占有遗产可以适用于告示的所有部分，这也足以证明这一点。

<!-- source-p 935 -->
<a id="38.17.1.6"></a>**6**　曾受雇与野兽搏斗的人，或被判处死罪且未获复权的人，原本不得依据《奥尔菲提安元老院决议》继承母亲的遗产；但依人道解释，现已认为应准许其继承。若该子女处于上述某种身份者的权力之下，也应作同样处理，准许其依据《奥尔菲提安元老院决议》继承。

<!-- source-p 936 -->
<a id="38.17.1.7"></a>**7**　若母亲立遗嘱时有多个儿子，却仅将其中一人附条件指定为继承人；在条件尚未成就时，该儿子请求遗产占有，之后条件又未成就，则不应因此剥夺其他儿子取得法定继承的权利。帕皮尼安在《问题集》第十六卷中也如此写道。

<!-- source-p 937 -->
<a id="38.17.1.8"></a>**8**　身份得以保留的身份减等，不损害子女取得法定继承的权利。只有依据《十二表法》转归的旧有继承，才因身份减等而消灭；新近依据法律或元老院决议转归的继承，不因身份减等而消灭。因此，若某人在继承开始前发生身份减等，仍可取得法定继承，除非发生重大身份减等而丧失公民身份，例如被流放。

<!-- source-p 938 -->
<a id="38.17.1.9"></a>**9**　“*Si nemo filiorum eorumve, quibus simul legitima hereditas defertur, volet ad se eam hereditatem pertinere, ius antiquum esto*”（若其子女或同时取得法定继承的其他人中，无人愿意使该继承归于自己，则应适用旧法。）这句话的意思是，只要有一名儿子愿意取得法定继承，旧法就不适用。因此，若两名儿子中一人接受继承，另一人拒绝继承，拒绝者的份额便归并给前者。若一人为儿子、另一人为释奴保护人，儿子拒绝继承时，继承即转归释奴保护人。

<!-- source-p 939 -->
<a id="38.17.1.10"></a>**10**　若有人已经接受母亲的遗产，之后经恢复原状而退出继承，旧法是否可以适用？条文措辞允许适用：“愿意使该继承归于自己”，条文如此说；此人如今已不愿意，尽管他曾经愿意。我认为，可以适用旧法。

<!-- source-p 940 -->
<a id="38.17.1.11"></a>**11**　继承应转归当时被认定为法定继承人的人，还是转归儿子取得继承时的法定继承人？例如，假设死者有一名旁系血亲及其儿子；死者的儿子尚在考虑是否接受继承时，该旁系血亲死亡，随后儿子拒绝母亲遗产。该旁系血亲的儿子是否可以获准继承？尤利安正确认为，在《特尔图良元老院决议》范围内，继承可以转归作为后继宗亲的人。

<!-- source-p 941 -->
<a id="38.17.1.12"></a>**12**　元老院决议所说“*quae iudicata transacta finitave sunt, rata maneant*”（已经裁判、和解或终结的事项，均应维持效力），应作如下理解：“已经裁判”是指由享有裁判权的人作出的裁判；“已经和解”是指以诚信达成、因而有效的和解；“已经终结”则指经同意或长期沉默而平息的事项。

<!-- source-p 942 -->
<a id="38.17.2"></a>**38.17.2**

<!-- source-p 943 -->
乌尔比安《评萨宾》第十三卷。

<!-- source-p 944 -->
<a id="38.17.2.pr."></a>**序言**　母亲无论是自由出生者还是自由释奴，均可享有《特尔图良元老院决议》所规定的利益。

<!-- source-p 945 -->
<a id="38.17.2.1"></a>**1**　这里所说的儿子或女儿，包括婚生子女和非婚生子女。尤利安在《学说汇纂》第五十九卷中也如此论述非婚生子女。

<!-- source-p 946 -->
<a id="38.17.2.2"></a>**2**　但是，若儿子或女儿已经成为自由释奴，母亲便不得主张其法定继承，因为她已不再是此类子女的母亲。尤利安也如此写道，我们的皇帝亦已作出裁定。

<!-- source-p 947 -->
<a id="38.17.2.3"></a>**3**　若儿子在母亲仍为奴隶时受孕，而母亲获释后才生下他，母亲可以继承其法定遗产。若母亲在怀孕时是刑罚奴隶，恢复自由后才生下儿子，亦同；自由女子受孕后被降为刑罚奴隶，之后恢复自由并生下儿子的，结论也相同；自由女子受孕后被降为奴隶身份，后来获释才生下儿子的，亦应准许母亲继承其法定遗产。母亲在怀孕期间获释，也应认为对此有利。母亲还可以继承在奴隶身份中出生的子女的法定遗产；例如，她在遗嘱信托式释奴迟延期间生下子女，或在敌境受孕并随子女一同归来，或赎身后才生下子女。

<!-- source-p 948 -->
<a id="38.17.2.4"></a>**4**　若母亲是名声不佳的女子，也准许她继承子女的法定遗产。

<!-- source-p 949 -->
<a id="38.17.2.5"></a>**5**　父亲为未适婚子女订立后续遗嘱时，只有在替补继承人拒绝接受该子女遗产后，才能确定该子女无遗嘱死亡。因此，若该未适婚子女曾被自权人收养，也应说母亲可以取得其遗产，犹如该子女无遗嘱死亡。

<!-- source-p 950 -->
<a id="38.17.2.6"></a>**6**　死者的自权子女，无论男性或女性、自然子女或收养子女，都会排除其母亲；但遗产占有人即使不是自权子女，也可以排除母亲，而且只有自然子女才如此。收养子女在解放出家父权后，只有其源自自然子女时才可获准；例如，自然孙子被祖父收养，即使后来解放出家父权，只要他取得遗产占有，仍会排除母亲。

<!-- source-p 951 -->
<a id="38.17.2.7"></a>**7**　若儿子仍在敌人手中，或有望出生，母亲的权利便处于待定状态，直至儿子返回或出生。

<!-- source-p 952 -->
<a id="38.17.2.8"></a>**8**　若存在自权继承人，但遗产实际上并未归他们所有——例如他们放弃了遗产——应考察母亲能否取得遗产。阿非利卡努斯和普布利基乌斯试图论证：只要自权继承人放弃遗产，母亲便可继承；只有当他们实际取得财物时，他们才会排除母亲，不能仅凭“自权继承人”这一空名损害母亲。此说较为公平。

<!-- source-p 953 -->
<a id="38.17.2.9"></a>**9**　若某人死亡时留下女儿——该女儿已依法交由他人收养——并留下母亲，神圣庇护皇帝裁定，《特尔图良元老院决议》不再适用；母亲与女儿应同时依“最近亲属”顺位取得遗产占有。但尤利安曾写道，若女儿放弃请求遗产占有，母亲不得依元老院决议取得遗产；此说并不正确，因为母亲可以继受女儿的权利。因此，只要女儿仍可请求遗产占有，母亲就不得取得遗产占有，因为预计女儿将以法定继承人身份继承。

<!-- source-p 954 -->
<a id="38.17.2.10"></a>**10**　若已解放出家父权的儿子取得遗产占有后，经恢复原状而退出遗产，则《特尔图良元老院决议》确实可以适用；但若他再次介入遗产事务，母亲也应再次退出。

<!-- source-p 955 -->
<a id="38.17.2.11"></a>**11**　若某子女尚在胎中时已被置于遗产占有，之后出生，却在取得遗产占有之前死亡，应考察其是否会像遗产占有人那样排除母亲。我认为，若该子女并未成为父亲的自权继承人，就不会排除母亲；因为仅被置于占有状态还不够，必须出生后也取得遗产占有。若因某人精神错乱而依裁定请求遗产占有，他在恢复理智并请求遗产占有之前死亡，也不会排除母亲。

<!-- source-p 956 -->
<a id="38.17.2.12"></a>**12**　若有人在身份争议期间仅取得卡尔博尼亚遗产占有，问题是这是否妨碍母亲取得遗产占有。对此确有争议；但由于卡尔博尼亚遗产占有有期限，应说期限届满后便不再妨碍母亲；或者，若未适婚者死亡，母亲也可获准取得遗产占有。

<!-- source-p 957 -->
<a id="38.17.2.13"></a>**13**　但若由监护人为婴儿请求遗产占有，即使婴儿立即死亡，也应说该请求会妨碍母亲。因为这种情形不同于授予精神错乱者的遗产占有。

<!-- source-p 958 -->
<a id="38.17.2.14"></a>**14**　只有在儿子接受法定继承时，母亲才不能享有《特尔图良元老院决议》的利益；反之，若儿子放弃法定继承，母亲便可依据该决议继承。但若法定继承人并非仅此一名儿子，而是还有其他人与他共同继承，母亲不得依据该决议取得他们的份额。

<!-- source-p 959 -->
<a id="38.17.2.15"></a>**15**　就儿子或女儿的遗产而言，父亲无论作为继承人还是遗产占有人，都会排除母亲。但在《特尔图良元老院决议》下，祖父或曾祖父均不排除母亲，即使他们订立了信托安排亦如此。不过，只有自然父亲会排除母亲，养父不会；较妥当的意见是，父亲一旦不再具有父亲身份，便会被母亲排除。他也不得请求违遗嘱的遗产占有，因为他已不再是父亲。

<!-- source-p 960 -->
<a id="38.17.2.16"></a>**16**　自然父亲无论依据何种理由取得遗产占有——无论是法定遗产占有还是违遗嘱遗产占有——都会排除母亲。

<!-- source-p 961 -->
<a id="38.17.2.17"></a>**17**　若死者有宗亲，而其自然父亲处于收养家族之中，同时也有母亲，则应准许母亲继承，因为该父亲已被宗亲排除。

<!-- source-p 962 -->
<a id="38.17.2.18"></a>**18**　若死者有同父母的姐妹，同时有母亲以及被收养或已解放出家父权的父亲，若该姐妹愿意接受继承，应依元老院决议准许母亲与姐妹一同继承，并排除父亲。若姐妹拒绝继承，则因父亲存在，母亲不得依元老院决议继承。通常母亲无须等待同父母的姐妹是否接受继承，但此处应当等待，因为该姐妹可以排除父亲。因此，姐妹拒绝遗产占有时，母亲将与父亲同以血亲身份取得遗产占有；但在此情形下母亲也须等待，只有父亲请求后，她才能取得遗产占有，因为父亲放弃时，她可以依据元老院决议继承。

<!-- source-p 963 -->
<a id="38.17.2.19"></a>**19**　若母亲本人同时也是同父母的姐妹，例如母亲的父亲收养了其女儿所生的外孙；此外还有自然父亲，则母亲若以同父母姐妹身份继承，会排除父亲。若她放弃同父母姐妹身份的权利，或因身份减等而丧失该身份，则因自然父亲存在，她不得依据元老院决议继承；但若父亲放弃，她又可以依据该决议继承。

<!-- source-p 964 -->
<a id="38.17.2.20"></a>**20**　若母亲没有依据《特尔图良元老院决议》接受儿子或女儿的继承，则在遗产占有方面应维持旧法；因为母亲放弃元老院决议赋予的优先权时，旧法便继而适用。

<!-- source-p 965 -->
<a id="38.17.2.21"></a>**21**　若母亲拒绝遗产占有，却仍在考虑是否接受继承，应说宗亲尚不能继承，因为母亲尚未真正拒绝接受继承。

<!-- source-p 966 -->
<a id="38.17.2.22"></a>**22**　我们既已说，母亲不接受继承时应适用旧法，还须考察遗产应转归何人：是母亲拒绝时最近的亲属，还是确定死者无遗嘱死亡时最近的亲属？例如，死者无遗嘱死亡时有伯父及伯父之子；母亲拒绝继承时，遗产尚未转归伯父。若伯父在母亲考虑期间死亡，应准许伯父之子继承。

<!-- source-p 967 -->
<a id="38.17.2.23"></a>**23**　若母亲没有为子女请求适任的监护人，或先前的监护人获准辞任或被拒绝后，未立即提出其他人选，她便无权主张继承其无遗嘱死亡子女的财产。她若根本没有请求，就会受到该规定制裁；因为条文说“或未请求”。那么，应向谁请求？皇帝敕令虽然提到裁判官，但我认为这一规定也适用于行省；即使母亲未向市镇官员请求，也同样适用，因为市镇官员也负有指定监护人的义务。

<!-- source-p 968 -->
<a id="38.17.2.24"></a>**24**　那么，若母亲已经请求监护人，只是后来受到被释奴或亲属提醒，是否也会落入元老院决议的制裁？我认为，若她是受迫才提出请求，就会落入制裁；若她本就准备请求，只是恰好受到提醒，则不会。

<!-- source-p 969 -->
<a id="38.17.2.25"></a>**25**　若父亲曾禁止为子女请求监护人，因为他希望由母亲管理子女财产，又应如何处理？若母亲既未请求监护人，也未依法管理监护事务，她仍会受该规定制裁。

<!-- source-p 970 -->
<a id="38.17.2.26"></a>**26**　若母亲没有为完全贫困的子女请求监护人，应宽宥她。

<!-- source-p 971 -->
<a id="38.17.2.27"></a>**27**　但若母亲不在时，被释奴或其他人抢先请求了监护人，应说不应排除母亲；除非此事发生在她企图欺诈规避义务时。

<!-- source-p 972 -->
<a id="38.17.2.28"></a>**28**　若母亲没有为儿子请求监护人而受处罚，女儿的情形也相同。孙辈呢？若不为孙辈请求监护人，也同样受罚。

<!-- source-p 973 -->
<a id="38.17.2.29"></a>**29**　若母亲没有请求为子女指定保佐人呢？敕答的文字对此有所遗漏；但应说，若未为未适婚子女请求保佐人，适用同一规则；若子女已经达到适婚年龄，则不应适用该规则。

<!-- source-p 974 -->
<a id="38.17.2.30"></a>**30**　若母亲怀孕时没有请求为遗产指定保佐人，我认为她会落入该规定的制裁。若她有一名未适婚的儿子被敌人俘虏，也应作同样处理。

<!-- source-p 975 -->
<a id="38.17.2.31"></a>**31**　若母亲没有为精神错乱的子女请求指定监护人或保佐人，较妥当的意见是她也会落入该规定的制裁。

<!-- source-p 976 -->
<a id="38.17.2.32"></a>**32**　母亲不仅因未请求监护人而受制裁，也会因敷衍请求而受制裁，敕答对此已有说明。例如，她请求指定享有特权的人，或请求指定已经承担三项监护事务的人；但须以她故意如此行事为限。

<!-- source-p 977 -->
<a id="38.17.2.33"></a>**33**　若母亲请求指定此类人员，而他们仍然接受监护事务，或因其他原因被留任，又该如何？母亲可以得到宽宥。

<!-- source-p 978 -->
<a id="38.17.2.34"></a>**34**　若母亲请求指定不适任的人，即不适合担任监护人的人，因为她知道裁判官不会任命他们；但裁判官应母亲请求仍任命了他们，又该如何？此时固然是裁判官的过失，但我们也会惩罚母亲的谋划。

<!-- source-p 979 -->
<a id="38.17.2.35"></a>**35**　因此，若这些人获准辞任或遭拒绝，母亲应立即请求指定其他人。

<!-- source-p 980 -->
<a id="38.17.2.36"></a>**36**　所以，无论母亲未请求指定监护人，还是未请求指定适任者，均会受罚；即使裁判官因错误而任命了不太适任的人，也不例外。

<!-- source-p 981 -->
<a id="38.17.2.37"></a>**37**　请求指定适任者时，是否应考察其财力，还是还要考察其品行，也可能存有疑问。我认为，若母亲请求的人财力充足，就容易宽宥她。

<!-- source-p 982 -->
<a id="38.17.2.38"></a>**38**　若先前的监护人获准辞任或遭拒绝后，母亲未立即提出其他人选，也会受罚。

<!-- source-p 983 -->
<a id="38.17.2.39"></a>**39**　若并非所有监护人都获准辞任或被拒绝，又该如何？应考察母亲是否应因未请求替代被免除者的其他人选而受责；我认为她应受责。

<!-- source-p 984 -->
<a id="38.17.2.40"></a>**40**　若其中有些人死亡呢？我认为，即使条文有所遗漏，元老院决议的宗旨仍适用。

<!-- source-p 985 -->
<a id="38.17.2.41"></a>**41**　我们所说的“被拒绝者”，究竟仅指裁判官未予任命的人，还是也包括因被怀疑不适任而被免除，或因疏忽、懈怠而被拒绝的人？后者也可以适当地称为被拒绝者。若他们躲藏不出，又该如何？问题会很繁复：因为也不应责怪母亲为何没有请求将其列为可疑监护人。否则，即使他们躲藏，母亲也可以依据告示请求裁判官命令他们到庭；若他们不到庭，裁判官就可将其作为可疑者免除。〔底本句末作 *si deessententiarum*，文字疑有残缺或拼接。〕

<!-- source-p 986 -->
<a id="38.17.2.42"></a>**42**　若母亲没有强迫他们承担监护事务，又该如何？既然我们要求母亲尽到全部职责，这件事也应由她照管，以免这些人在遗产继承中妨碍她。

<!-- source-p 987 -->
<a id="38.17.2.43"></a>**43**　“立即”应理解为“最早可能之时”，也就是裁判官有空处理此事并正在开庭之时；除非母亲因病或其他重大原因受阻，以致连委托他人为子女请求监护人也做不到。但无论如何，不得超过一年。若子女死亡抢在母亲之前，不得归责于母亲。

<!-- source-p 988 -->
<a id="38.17.2.44"></a>**44**　可以进一步讨论：若给未成年人留下大额遗赠，条件是“若其没有监护人”，母亲为了不使条件落空而未请求监护人，元老院决议是否不适用？我认为，若遗赠利益大于损失，决议便不适用。特尔图良也在市镇官员问题上讨论了这一点；他认为可以对这些官员提起诉讼，但仅以损失超过遗赠数额的部分为限。也有人可能认为，此条件损害公共利益，应像许多其他情形一样予以免除；或者从文字上苛责母亲，称她未请求指定保佐人。但若条件写得更为完整，难道不应宽宥母亲吗？是否还要责怪她没有请求皇帝免除该条件？我认为，不应归责于她。

<!-- source-p 989 -->
<a id="38.17.2.45"></a>**45**　即使母亲没有为无清偿能力的子女请求监护人，我也认为应宽宥她；因为她是为了避免子女在无人辩护的情况下受到更多侵扰。

<!-- source-p 990 -->
<a id="38.17.2.46"></a>**46**　若有人指定共同子女的母亲为继承人，并请求她免除担保，在子女达到适婚年龄后将遗产返还给子女；母亲却没有为子女请求监护人，则应说该敕令不适用，因为她遵从了父亲的意思，而且子女一无所有，无须指定监护人。若未免除担保，结论则相反，因为正因如此，子女应有监护人。但若母亲怠于请求后，未适婚子女被他人自权人收养并在未适婚时死亡，则应说母亲不得对收养者提起要式允诺之诉。

<!-- source-p 991 -->
<a id="38.17.2.47"></a>**47**　母亲被禁止主张自己的权利时，我们究竟应准许其他人继承，视同母亲不存在；还是仍称母亲为继承人，只是拒绝给予她诉权？我们发现，我们的皇帝安敦宁·奥古斯都与其神圣父亲曾于普劳提阿努斯第二次任执政官之年四月伊得斯前一日，向马米亚·马克西米娜作出敕答：母亲被排除后，应准许那些在母亲不存在时本可继承的人取得遗产。因此，宗亲及其他继承顺位者均可继承；若无人继承，财产便成为无主财产。
