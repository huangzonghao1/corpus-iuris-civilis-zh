# D.38.5 论为诈害释奴保护人而实施的行为（*Si quid in fraudem patroni factum sit*）

<!-- source-p 516 -->
<a id="5"></a><a id="38.5"></a>**38.5.0 论为诈害释奴保护人而实施的行为**（*Si quid in fraudem patroni factum sit*）。

<!-- source-p 517 -->
<a id="38.5.1"></a>**38.5.1**

<!-- source-p 518 -->
乌尔比安《告示评注》第四十四卷。

<!-- source-p 519 -->
<a id="38.5.1.pr."></a>**序言**　若有人声称，被释奴实施了恶意诈害行为——无论该被释奴立有遗嘱而死亡，还是无遗嘱死亡——以致本应归属于有权请求违遗嘱遗产占有之人的遗产，不足法定应得份额，裁判官即应进行审理，并设法不使该行为损害这些人的利益。

<!-- source-p 520 -->
<a id="38.5.1.1"></a>**1**　若财产系出于恶意诈害而被转让，我们不问该转让是否因死亡而作出；无论如何，均应予以撤销。若转让并非出于恶意诈害，而是基于其他原因，则原告必须证明该转让系因死亡而作出。因为，若主张转让系因死亡而作出，我们无须再问其是否出于恶意诈害；证明其系因死亡而作出即已足够。这并非没有道理：因死亡而作出的赠与与遗赠相当；正如在遗赠中我们不问是否出于恶意诈害，在因死亡而作出的赠与中也不应如此追问。

<!-- source-p 521 -->
<a id="38.5.1.2"></a>**2**　因死亡而赠与儿子的财物，不予撤销。因为立遗嘱人本可自由决定向儿子遗赠多少；因此，他通过赠与而非遗赠财物，并不因此被视为诈害释奴保护人。

<!-- source-p 522 -->
<a id="38.5.1.3"></a>**3**　凡以诈害释奴保护人为目的而实施的行为，均应撤销。

<!-- source-p 523 -->
<a id="38.5.1.4"></a>**4**　我们所说的恶意，应当是转让人本人的恶意，而非受让人的恶意。因此，即使受让人并不知道存在诈害或欺诈，也应失去因诈害释奴保护人而转让给他的财物；即便他误以为转让人是自由出生者，并不知道其为被释奴，也同样如此。

<!-- source-p 524 -->
<a id="38.5.1.5"></a>**5**　对于放弃请求违遗嘱遗产占有的共同释奴保护人，若赠与物没有超过释奴保护人应得份额，*Faviana* 之诉不适用。因此，若该共同释奴保护人是因死亡而受赠，便应向另一共同释奴保护人分出相应份额，如同作为受遗赠人的释奴保护人所应做的一样。

<!-- source-p 525 -->
<a id="38.5.1.6"></a>**6**　现在应当考察，*Faviana* 之诉所针对的，是否仅限于被释奴从其财产中处分出去的东西，还是也包括他未曾取得的东西。尤利安在《学说汇纂》第二十六卷说，若被释奴为了诈害释奴保护人而未接受遗产或放弃遗赠，*Faviana* 之诉即不适用；我认为这确是正确的。尽管遗赠在未被拒绝前，追溯而言算是我们的；但既然遗赠被拒绝，就显然从未归我们所有。对于被释奴未接受的其他赠与，也应同样认定 *Faviana* 之诉不适用。释奴保护人只需确保被释奴没有诈害性地处分自己的财产，而无须确保他取得本可取得的财产。因此，若被释奴为了不使遗赠所附条件成就而采取行动，或者其因附条件订立要式口约后，宁愿使条件不成就，也应说 *Faviana* 之诉不适用。

<!-- source-p 526 -->
<a id="38.5.1.7"></a>**7**　若被释奴故意希望在诉讼中败诉，如何处理？若他故意败诉，或在法务官面前承认诉请，则应说 *Faviana* 之诉适用；若他只是提起诉讼却不愿胜诉，则此处仍有疑问。我认为，他已使自己的财产减少；他因诉讼而减少了财产，正如他放任诉权期间届满一样。

<!-- source-p 527 -->
<a id="38.5.1.8"></a>**8**　但若被释奴本可提起不孝遗嘱之诉，或其他诉讼——例如侵辱之诉或类似诉讼——却没有提起，释奴保护人不得仅因此提起 *Faviana* 之诉。

<!-- source-p 528 -->
<a id="38.5.1.9"></a>**9**　但若被释奴为诈害释奴保护人而达成和解，释奴保护人可以提起 *Faviana* 之诉。

<!-- source-p 529 -->
<a id="38.5.1.10"></a>**10**　若被释奴为女儿置办嫁资，仅凭置办嫁资这一事实，并不视为诈害释奴保护人，因为父亲对子女的慈爱不应受到责难。

<!-- source-p 530 -->
<a id="38.5.1.11"></a>**11**　若被释奴为诈害释奴保护人而向数人赠与财物，或因死亡而向数人赠与财物，释奴保护人应依其应得份额，平等地对所有受赠人提起 *Faviana* 或 *Calvisiana* 之诉。

<!-- source-p 531 -->
<a id="38.5.1.12"></a>**12**　若有人为诈害释奴保护人而出售、出租或交换财物，我们应当考察法官应如何裁量。对于已经出售的财物，应给予买受人选择：是愿意以公平价格保留所购之物，还是愿意退出交易并收回价款。我们不应一概撤销买卖，仿佛被释奴没有出售权；也不应使买受人蒙受价款损失，尤其是因为此处争论的不是买受人的恶意，而是被释奴的恶意。

<!-- source-p 532 -->
<a id="38.5.1.13"></a>**13**　但若被释奴为诈害释奴保护人而买入财物，也应作类似处理：若买价过高，应在价格上给予释奴保护人救济。不过，退出买卖的选择权并不交给释奴保护人，而应交给出卖人，由出卖人决定是减免一部分价款，还是在收回价款后取回所售之物。交换、出租与租赁，也同样依此处理。

<!-- source-p 533 -->
<a id="38.5.1.14"></a>**14**　但若被释奴以诚信且并非出于任何偏袒而出售财物，随后却把收到的价款赠与他人，则应考察 *Faviana* 之诉究竟应针对买受人，还是针对受赠价款之人。庞波尼在《学说汇纂》第八十三卷正确地写道，不应追究买受人；因为对释奴保护人的诈害发生在价款上。因此，应以 *Faviana* 之诉起诉受赠价款之人。

<!-- source-p 534 -->
<a id="38.5.1.15"></a>**15**　另外还应考察一种情形：释奴保护人声称财物虽以公平价格售出，但因自己在意该地产的便利、邻近、气候，或曾在那里长大、父母安葬在那里，地产本不应出售，出售本身即构成诈害；他希望撤销出售，是否应获准？任何情况下均不应听从这种主张；因为这里所说的诈害，是指金钱上的损失。

<!-- source-p 535 -->
<a id="38.5.1.16"></a>**16**　但若财物以低价售出，且价款又赠与他人，则低价买受人与受赠钱款之人均应依 *Faviana* 之诉被追究。不过，若买受人愿意返还财物，只有在取回其所支付价款时才须返还。若买受人依被释奴的安排向其赠与价款之人付款，又应如何？较妥当的看法是，即使价款已到达一名无力清偿之人手中，买受人仍应当可以取回价款。因为，即使被释奴将已收取的价款挥霍掉，我们也会说，若付款人愿意退出买卖，仍应允许其取回价款。

<!-- source-p 536 -->
<a id="38.5.1.17"></a>**17**　若被释奴为诈害释奴保护人而借入金钱，是否适用 *Faviana* 之诉？我们来考察这一问题。这种情形有什么救济？他借入了钱；若他将借来的钱赠与他人，释奴保护人可以起诉被释奴赠与钱款之人；但若被释奴收取钱款后将其挥霍，出借人不应因此遭受损失，也不应因其曾出借钱款而受到责难。

<!-- source-p 537 -->
<a id="38.5.1.18"></a>**18**　当然，若被释奴并未实际取得钱款，只是向贷款人作出正式允诺，则可以提起 *Faviana* 之诉。

<!-- source-p 538 -->
<a id="38.5.1.19"></a>**19**　若被释奴为诈害释奴保护人而为我作保证，或以自己的财物为他人设质，是否适用 *Faviana* 之诉？我们还应当考察，是否不应以损害我的利益为代价来帮助释奴保护人。因为，若被释奴为一个无力清偿的人代为介入，并非赠与了我任何东西；我们也正是依此法律处理。因此，债权人不应成为 *Faviana* 之诉的被告。债务人则可能成为被告，但对其也可以提起委任之诉。当然，若委任之诉不能成立——因为被释奴系出于赠与目的而代为介入——则可以提起 *Faviana* 之诉。

<!-- source-p 539 -->
<a id="38.5.1.20"></a>**20**　同样，若被释奴为他人担任委任人，也应适用相同规则。

<!-- source-p 540 -->
<a id="38.5.1.21"></a>**21**　虽然 *Faviana* 之诉仅就一部分财产发生效力，但对于不能分割的权利，该诉可以就全部权利提起，例如地役权。

<!-- source-p 541 -->
<a id="38.5.1.22"></a>**22**　若被释奴为诈害释奴保护人而向我的奴隶或家子给付财物，是否可以对我提起 *Faviana* 之诉？我们来考察这一问题。我认为，对我这个主人或父亲提起诉讼即可；法官可以裁量判令我承担相当于已归入本人财产的利益，以及奴隶或家子的特有产范围内的金额。

<!-- source-p 542 -->
<a id="38.5.1.23"></a>**23**　若家子是经父亲命令与被释奴订立契约，父亲当然应承担责任。

<!-- source-p 543 -->
<a id="38.5.1.24"></a>**24**　若被释奴为诈害释奴保护人而与奴隶订立契约，而该奴隶后来被解放，是否应依 *Faviana* 之诉追究该奴隶？既然我们已经说过，只考察被释奴的恶意，而不考察与其订约之人的恶意，那么这个后来获释的人可能不受 *Fabiana* 之诉追究。

<!-- source-p 544 -->
<a id="38.5.1.25"></a>**25**　此外还可以追问：若奴隶后来获释、死亡或被转让，是否必须在一年内提起诉讼？庞波尼说，应当提起。

<!-- source-p 545 -->
<a id="38.5.1.26"></a>**26**　此诉是对人之诉，而非对物之诉；可以针对继承人及其他继受人提起，也可以由释奴保护人的继承人及其他继受人提起。它不是遗产继承而来的诉权，即并非源自被释奴的遗产，而是释奴保护人自己的诉权。

<!-- source-p 546 -->
<a id="38.5.1.27"></a>**27**　若被释奴为诈害释奴保护人而赠与财物，随后释奴保护人死亡，而被释奴仍在世；释奴保护人的儿子取得针对该被释奴的违遗嘱遗产占有后，能否提起 *Fabiana* 之诉，追回已转让的财物？正确的看法是可以；庞波尼在《学说汇纂》第八十三卷、帕比尼安在《疑义集》第十四卷也赞同此说。只要行为损害了释奴保护关系，即已足够；因为我们所说的诈害，是诈害该关系，而非特定个人。

<!-- source-p 547 -->
<a id="38.5.1.28"></a>**28**　在该诉讼中，也包括争讼程序确定后取得的孳息。

<a id="38.5.3.pr."></a>**序言**　若释奴保护人被指定为继承人，并在不知被释奴曾为诈害自己而转让某些财物的情况下，按其应得份额接受了遗产，应当考察是否应救济其不知情，以免他受到被释奴欺诈的损害。帕比尼安在《疑义集》第十四卷答复说，已转让的财物仍维持现状；因此，释奴保护人应归咎于自己，因为他本可以针对已转让或因死亡而赠与的财物，请求违遗嘱遗产占有，却没有这样做。

<!-- source-p 554 -->
<a id="38.5.3.1"></a>**1**　此诉不受时效限制，因为它包含对物的追索。

<!-- source-p 555 -->
<a id="38.5.3.2"></a>**2**　若释奴保护人被指定为遗产的唯一继承人，并希望提起 *Faviana* 之诉，裁判官应准许其起诉；因为他并非自愿接受遗产，而是由于无法请求违遗嘱遗产占有才接受遗产。

<!-- source-p 556 -->
<a id="38.5.3.3"></a>**3**　若被释奴无遗嘱死亡，释奴保护人通过接受其遗产，可以依 *Calvisiana* 之诉追回那些因恶意诈害而被转让的财物；这些转让旨在阻止被释奴遗产中依法应得的份额依遗嘱归属于释奴保护人或其子女。无论释奴保护人是否请求无遗嘱遗产占有，均作此处理。

<!-- source-p 557 -->
<a id="38.5.3.4"></a>**4**　若有数名女释奴保护人或释奴保护人，每人只能依 *Calvisiana* 之诉追回其个人应得份额。

<!-- source-p 558 -->
<a id="38.5.3.5"></a>**5**　若被释奴无遗嘱死亡，留给释奴保护人的财产达到其应得份额或超过该份额，但仍转让了某些财物，帕比尼安在《疑义集》第十四卷写道，不应追回任何财物。因为，既然被释奴本可通过遗嘱将财物留给任何人，只要他将应得份额留给释奴保护人，此外再行赠与就不构成诈害。

被释奴为了诈害释奴保护人，想把一块土地交给塞乌斯；塞乌斯却委托提丢斯收受该土地，于是塞乌斯与提丢斯之间成立委任关系。我问：被释奴死亡后，释奴保护人只能起诉作出委托的塞乌斯，还是可以起诉持有土地的提丢斯，抑或可以选择起诉其中任何一人？答复说：诉讼应针对意图受赠之人提起，但以该物已到达其手中为条件；凡依其意思实施的全部事务，均应纳入对其判决的责任范围。不能认为该人必须交付由他人占有之物，因为他可以通过委任之诉取得该物，从而要么亲自返还给释奴保护人，要么迫使与其订立委任关系的人返还。若介入交易之人没有实施欺诈，又该如何？我们毫不怀疑，无论如何都不能起诉该人。因为，不能认为有人实施了欺诈，仅仅是因为他把信用借给朋友，而不是为自己从被释奴的诈害行为中取得财物。

<!-- source-p 589 -->
保罗《朱利亚—帕皮亚法评注》第十卷。

<!-- source-p 590 -->
神圣皮乌斯皇帝关于收养未适婚年龄者的敕令规定：被收养者有权取得收养人死亡时财产的四分之一；皇帝还命令，将被收养者为养父取得的财产返还给他。若经审查具体情况后，被收养者获准解放出父权，则其四分之一份额即告丧失。因此，若有财物为诈害被收养者而被转让，应仿照 *Calvisiana* 或 *Faviana* 之诉予以追回。
