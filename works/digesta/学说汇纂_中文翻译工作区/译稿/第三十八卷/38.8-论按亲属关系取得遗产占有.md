<!-- source-p 655 -->
<a id="8"></a><a id="38.8"></a>**38.8.0 论按亲属关系取得遗产占有**（*Unde cognati*）。

<!-- source-p 656 -->
<a id="38.8.1"></a>**38.8.1**

<!-- source-p 657 -->
乌尔比安《告示评注》第四十六卷。

<!-- source-p 658 -->
<a id="38.8.1.pr."></a>**序言。**这种遗产占有纯粹源于裁判官的恩准，并无市民法上的根据。因为裁判官邀请那些依市民法不能取得继承资格的人请求遗产占有，也就是邀请血亲亲属。

<!-- source-p 659 -->
<a id="38.8.1.1"></a>**1.**所谓血亲亲属，是指仿佛由同一来源出生的人；或者，正如拉贝奥所说，是仿佛具有共同出生起源的人。

<!-- source-p 660 -->
<a id="38.8.1.2"></a>**2.**本告示适用于非奴隶身份所生的血亲关系；因为奴隶之间通常很难说存在血亲关系。

<!-- source-p 661 -->
<a id="38.8.1.3"></a>**3.**本告示这一部分所授予的遗产占有，涵盖血亲亲属的六个亲等；此外还包括第七亲等中的两类人，即 *sobrinus* 与 *sobrina* 所生的男性与女性。

<!-- source-p 662 -->
<a id="38.8.1.4"></a>**4.**收养也能产生血亲关系。因为，收养子女在哪些人之间成为宗亲，也会在哪些人之间成为血亲亲属。凡涉及血亲亲属之处，我们都应作此理解，即也包括因收养而成为血亲亲属的人。因此，被送养之人既在自然父亲的家族中保留血亲关系所生的权利，也在收养家族中取得相应权利；不过，他只在收养家族中与因其收养而成为宗亲的人建立血亲关系，而在自然家族中则保留与所有人的血亲关系。

<!-- source-p 663 -->
<a id="38.8.1.5"></a>**5.**即使只有一人，也可以称为最近亲属，尽管严格来说，“最近”通常是相对于数人而言。

<!-- source-p 664 -->
<a id="38.8.1.6"></a>**6.**认定最近亲属，应以遗产占有被授予之时为准。

<!-- source-p 665 -->
<a id="38.8.1.7"></a>**7.**因此，若遗嘱指定继承人尚在考虑是否接受继承，而最近的血亲亲属在此期间死亡，就应准许下一顺位的人作为最近亲属取得遗产占有；也就是说，准许当时被认定处于最近亲属顺位的人取得。

<!-- source-p 666 -->
<a id="38.8.1.8"></a>**8.**若预计会有一名更近亲等的亲属出生，应当认为此情形足以阻止其后顺位者取得遗产占有。但若该胎儿最终未能出生，则应准许原先看来排在胎儿之后最近的亲属取得遗产占有。不过，只有在所称胎儿于被请求遗产占有之人尚在世时已经受孕，才适用此规则；若胎儿是在其死亡后受孕，既不妨碍他人取得遗产占有，其本人也不得取得，因为被继承人尚在世时，该胎儿尚未成为有生命的存在（*animax*）。

<!-- source-p 667 -->
<a id="38.8.1.9"></a>**9.**若一名孕妇死亡，剖开子宫后取出胎儿，则该胎儿可以依据“最近血亲亲属顺位”取得其母亲的遗产占有。但《奥尔菲提安元老院决议》之后，该胎儿也可以依据“法定继承人顺位”请求遗产占有，因为在其母亲死亡时，他尚在母腹之中。

<!-- source-p 668 -->
<a id="38.8.1.10"></a>**10.**血亲亲属依亲等顺序逐级取得遗产占有；因此，处于第一亲等的人应一同取得。

<!-- source-p 669 -->
<a id="38.8.1.11"></a>**11.**若在被请求遗产占有之人死亡时，有亲属身处敌方，应当说该亲属可以请求遗产占有。

<!-- source-p 670 -->
<a id="38.8.2"></a>**38.8.2**

<!-- source-p 671 -->
盖尤斯《行省告示评注》第十六卷。

<!-- source-p 672 -->
行省总督基于自然公平，在本告示这一部分承诺向所有因血缘关系而应被召集继承的人授予遗产占有，即使市民法不承认其继承资格。因此，非婚生子女与其母亲，以及这些子女彼此之间，均可依据本告示请求遗产占有，因为他们互为血亲；甚至，若一名孕妇女奴被解放后生下子女，出生子女与其母亲、母亲与子女，以及这些出生子女彼此之间，也都是血亲亲属。

<!-- source-p 673 -->
<a id="38.8.3"></a>**38.8.3**

<!-- source-p 674 -->
尤利安《学说汇纂》第二十七卷。

<!-- source-p 675 -->
因身份减等而消灭的，是通过收养取得的血亲关系。因此，若某人的养兄弟死亡后的一百日内，另一养兄弟发生人格减等，他便不能以最近亲属为由取得该兄弟的遗产占有。显然，裁判官不仅考察死亡时的情形，也考察请求遗产占有时的情形。

<!-- source-p 676 -->
<a id="38.8.4"></a>**38.8.4**

<!-- source-p 677 -->
乌尔比安《规则集》第六卷。

<!-- source-p 678 -->
若一名非婚生子无遗嘱死亡，其遗产依同血亲关系或宗亲关系均不归任何人，因为同血亲关系与宗亲关系的权利均源自父亲。但其母亲或同母兄弟，可以基于最近亲属关系，依告示请求该人的遗产占有。

<!-- source-p 679 -->
<a id="38.8.5"></a>**38.8.5**

<!-- source-p 680 -->
庞波尼《萨宾评注》第四卷。

<!-- source-p 681 -->
发生身份减等而丧失法定继承资格的人，不得依据法定继承人之权利取得遗产占有，因为他们与子女的情形不同；但他们仍可依血亲亲属的亲等顺序再次被召集。

<!-- source-p 682 -->
<a id="38.8.6"></a>**38.8.6**

<!-- source-p 683 -->
乌尔比安《告示评注》第四十五卷。

<!-- source-p 684 -->
血亲亲属彼此提起控告，不妨碍其继承；即使他们曾控告自己的血亲亲属，也不影响继承资格。

<!-- source-p 685 -->
<a id="38.8.7"></a>**38.8.7**

<!-- source-p 686 -->
莫德斯蒂努《规则集》第六卷。

<!-- source-p 687 -->
某人无论因何种原因沦为奴隶，即使后来获得解放，也不能恢复其血亲关系。

<!-- source-p 688 -->
<a id="38.8.8"></a>**38.8.8**

<!-- source-p 689 -->
莫德斯蒂努《答复集》第十四卷。

<!-- source-p 690 -->
莫德斯蒂努答复说，孙辈被认为是非婚生子女，并不妨碍他们在无遗嘱继承中取得外祖母的遗产。

<!-- source-p 691 -->
<a id="38.8.9"></a>**38.8.9**

<!-- source-p 692 -->
帕比尼安《答复集》第六卷。

<!-- source-p 693 -->
<a id="38.8.9.pr."></a>**序言。**第八亲等的宗亲，即使没有实际成为继承人，也可依据法定继承人的权利取得遗产占有；但最近的血亲亲属即使已经成为继承人，也不得因此取得遗产占有。

<!-- source-p 694 -->
<a id="38.8.9.1"></a>**1.**某人的兄弟之子被指定为部分继承人；他声称自己的叔父耳聋，因此不能订立遗嘱，并以最近血亲亲属的身份取得遗产占有。裁定认为，相关期间应从死亡之日起计算，因为难以相信与死者血缘如此亲近的人，竟不知道死者的健康状况。

<!-- source-p 695 -->
<a id="38.8.10"></a>**38.8.10**

<!-- source-p 696 -->
斯凯沃拉《答复集》第二卷。

<!-- source-p 697 -->
提丢娅无遗嘱死亡，留下同父异母的姐妹塞普提基娅，以及由另一丈夫所怀孕的母亲。我问：若母亲仍在怀孕时放弃继承，后来生下塞姆普罗尼娅，那么塞姆普罗尼娅能否取得提丢娅遗产的遗产占有？答复说：若母亲已被排除于继承之外，那么如题设所言后来出生的女儿可以取得。
