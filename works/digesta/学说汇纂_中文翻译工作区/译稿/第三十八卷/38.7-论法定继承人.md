# D.38.7 论法定继承人（*Unde legitimi*）

<!-- source-p 631 -->
<a id="7"></a><a id="38.7"></a>**38.7.0 论法定继承人**（*Unde legitimi*）。

<!-- source-p 632 -->
<a id="38.7.1"></a>**38.7.1**

<!-- source-p 633 -->
尤利安《学说汇纂》第二十七卷。

<!-- source-p 634 -->
告示中的“那么，谁就应当成为其继承人”这几个词，应理解为连续适用，并含有一定时间间隔（底本作 *paratatikws*）；它们并非指向立遗嘱人死亡之时，而是指请求遗产占有之时。因此，法定继承人若发生身份减等，显然会被排除在此种遗产占有之外。

<!-- source-p 635 -->
<a id="38.7.2"></a>**38.7.2**

<!-- source-p 636 -->
乌尔比安《告示评注》第四十六卷。

<!-- source-p 637 -->
<a id="38.7.2.pr."></a>**序言。**若自权继承人放弃无遗嘱遗产占有，我们仍应当说，他们会妨碍法定继承人取得继承权，也就是妨碍那些本可取得法定继承的继承人。这是因为，自权继承人放弃以子女身份取得的遗产占有后，便开始仿佛以法定继承人身份取得该遗产占有。

<!-- source-p 638 -->
<a id="38.7.2.1"></a>**1.**此种遗产占有不仅授予男性，也授予女性；不仅授予自由出生者，也授予被释奴。因此，它可由多人共同享有。女性也可能有同父血亲（*consanguinei*）或宗亲（*adgnati*）；被释奴也可能有男性或女性释奴保护人。

<!-- source-p 639 -->
<a id="38.7.2.2"></a>**2.**不仅男性能够取得此种遗产占有，女性也同样能够取得。

<!-- source-p 640 -->
<a id="38.7.2.3"></a>**3.**若某人死亡，但尚不确定他当时是家父还是家子——例如其父被敌人俘获但仍活着，或者其身份因其他原因尚未确定——较妥当的意见是，暂不得请求其遗产占有，因为尚不能确定他是否无遗嘱死亡；此时也不确定他是否具有立遗嘱的能力。因此，应等到其身份明确后，才请求遗产占有；所等的不是确定其无遗嘱死亡，而是确定其为家父。

<!-- source-p 641 -->
<a id="38.7.2.4"></a>**4.**此种遗产占有召集所有可能依无遗嘱方式成为继承人的人，无论其继承权源自《十二表法》，还是源自其他法律或元老院决议。最后，依《特尔图良元老院决议》取得继承权的母亲，以及依《奥尔菲提安元老院决议》获准法定继承的人，也可以请求此种遗产占有。

<!-- source-p 642 -->
<a id="38.7.3"></a>**38.7.3**

<!-- source-p 643 -->
保罗《告示评注》第四十三卷。

<!-- source-p 644 -->
一般而言，只要法律或元老院决议授予继承权，却未同时授予遗产占有，就应依据本告示条款请求遗产占有；若法律或元老院决议同时命令授予遗产占有，则应依据有关法律的告示条款请求；不过，也可以依据本条款请求。

<!-- source-p 645 -->
<a id="38.7.4"></a>**38.7.4**

<!-- source-p 646 -->
尤利安《学说汇纂》第二十七卷。

<!-- source-p 647 -->
两兄弟中一人依法立遗嘱后死亡；在遗嘱指定的继承人尚在考虑是否接受继承期间，另一兄弟也无遗嘱死亡，而遗嘱指定的继承人放弃了遗产。此时，叔父将取得法定继承。因为告示所称“那么，谁就应当成为继承人”，是指最早能够请求无遗嘱遗产占有的时点。

<!-- source-p 648 -->
<a id="38.7.5"></a>**38.7.5**

<!-- source-p 649 -->
莫德斯汀《学说汇纂》第三卷。

<!-- source-p 650 -->
<a id="38.7.5.pr."></a>**序言。**宗亲与血亲的区别在于：宗亲必然也属于血亲，而血亲未必是宗亲。例如，父亲的兄弟即叔父，既是宗亲，也是血亲；母亲的兄弟即舅父，则是血亲，却不是宗亲。

<!-- source-p 651 -->
<a id="38.7.5.1"></a>**1.**只要尚有可能出现该死者的自权继承人，同父血亲（*consanguinei*）便无权取得遗产。例如，死者的妻子仍怀有遗腹子，或者死者的儿子仍在敌人手中。

<!-- source-p 652 -->
<a id="38.7.6"></a>**38.7.6**

<!-- source-p 653 -->
赫尔莫革尼安《法律概要》第三卷。

<!-- source-p 654 -->
父亲死亡后、或者父亲被俘或遭流放后出生的人，以及父亲被俘或遭流放时已处于其家父权之下的人，彼此之间享有同父血亲关系；即使他们没有成为父亲的继承人，亦同，正如遭遗嘱排除继承者一样。
