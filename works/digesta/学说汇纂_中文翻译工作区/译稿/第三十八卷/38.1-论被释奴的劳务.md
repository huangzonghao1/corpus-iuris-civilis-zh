<!-- source-p 8 -->
<a id="38.1.2.1"></a>**1.**因此，裁判官首先承诺，将对自由释奴（男、女）给予劳务诉讼救济。

<a id="38.1.3.pr."></a>**序言**　虽已约定劳务，但在该日尚未结束前，不得请求该日的劳务。

<!-- source-p 12 -->
<a id="38.1.3.1"></a>**1.**劳务也不得按小时拆分履行，因为它属于按日履行的义务。因此，自由释奴即使只在上午提供了六小时劳务，也不能据此免除该日的义务。

某人由两人共同释奴，并向二人都承诺提供劳务；二人中一人死亡后，便不再有理由允许其儿子请求劳务，即使另一位释奴保护人仍然在世。此事与继承或遗产占有毫无共同之处：请求自由释奴提供劳务，正如请求偿还出借的钱款。阿里斯托如此记载；我认为他的意见正确，因为即使请求过去已经到期的劳务，也可以对非直系继承人给予诉权，且不必担心遭遇抗辩。因此，另一位释奴保护人仍在世时，也可以给予该诉权。

<a id="38.1.7"></a>**38.1.7**

<!-- source-p 23 -->

<!-- source-p 24 -->
<a id="38.1.7.pr."></a>**序言**　要通过宣誓成立债务，宣誓者必须是自由释奴，且须因取得自由而宣誓。

<!-- source-p 25 -->
<a id="38.1.7.1"></a>**1.**有人将财产遗赠给自己的自由释奴；若该自由释奴曾向释奴保护人的儿子宣誓，承诺提供十日劳务，他是否因宣誓而负有义务？塞尔苏斯·尤文提乌斯说，他受誓言约束；至于自由释奴因何种原因就劳务宣誓，并不重要。我也赞同塞尔苏斯。

<!-- source-p 26 -->
<a id="38.1.7.2"></a>**2.**他必须在获释之后宣誓，才受其约束；无论立即宣誓还是经过一段时间后宣誓，均受约束。

<!-- source-p 27 -->
<a id="38.1.7.3"></a>**3.**他应宣誓将提供劳务、赠与或其他恩惠；所承诺的劳务可以是任何种类，但必须是以适当且合法的方式课加的劳务。

<!-- source-p 28 -->
<a id="38.1.7.4"></a>**4.**神圣的哈德良皇帝曾作出敕答：对于因遗嘱信托而获释的人，此后不得再追索劳务。

<!-- source-p 29 -->
<a id="38.1.7.5"></a>**5.**对未适婚者，也可以在其成年后提起劳务诉讼；有时甚至可在其未适婚期间提起，因为他也能提供劳务，例如他是抄写员、传名官、计算员、演员或其他娱乐技艺的从业者。

<!-- source-p 30 -->
<a id="38.1.7.6"></a>**6.**若释奴保护人的子女被指定继承遗产时份额不相等，他们应按二分之一份额还是按各自的继承份额享有劳务请求权？我认为，较为正确的是子女应平均享有该请求权。

<!-- source-p 31 -->
<a id="38.1.7.7"></a>**7.**子女仍处于家父权之下还是已经解放出家父权，并不重要。

<!-- source-p 32 -->
<a id="38.1.7.8"></a>**8.**但是，若释奴保护人将其已交付他人收养的子女指定为继承人，较妥当的意见是，仍应向该子女提供劳务。

<!-- source-p 33 -->
<a id="38.1.7.9"></a>**9.**女释奴保护人的子女也不会因此被排除在劳务请求之外。

<!-- source-p 37 -->
<a id="38.1.8.1"></a>**1.**任何人都可以为宣誓承诺提供劳务的自由释奴作保证人，这一意见已获认可。

<!-- source-p 40 -->
<a id="38.1.9.pr."></a>**序言**　劳务并非现实世界中的物。

<!-- source-p 41 -->
<a id="38.1.9.1"></a>**1.**未来的事务性劳务只能向释奴保护人承担，不能向其他人承担，因为这类劳务的特性取决于提供劳务者本人以及接受劳务者本人。手艺劳务或其他同类劳务则不同：任何人都可以向任何人提供。确实，若自由释奴从事某项手艺，经释奴保护人命令，也可以向他人提供此类劳务。

<a id="38.1.13.pr."></a>**序言**　若某人依买卖条件被买下并应获释，后来依据神圣的马尔库斯皇帝的敕令获得自由，则对其课加的劳务不发生效力。

<!-- source-p 55 -->
<a id="38.1.13.1"></a>**1.**若某人依据神圣的马尔库斯皇帝关于保全释奴自由的敕令而受让财产，也不得向相关自由释奴请求劳务；无论是依据直接方式获释者，还是依据遗嘱信托获释者，均不得请求。即使依据遗嘱信托获释者成为该受让人的自由释奴，结论也相同；因为这类人并非像我们不受任何强制而自愿释奴时那样，成为自己的自由释奴。

<!-- source-p 56 -->
<a id="38.1.13.2"></a>**2.**只有劳务期限经过后，才可提起劳务诉讼。期限只有在劳务开始计入到期日后才会经过；而劳务开始计入到期日，是从劳务被要求提供时起。

<a id="38.1.13.4"></a>**4.**若释奴保护人是未适婚者，即使女自由释奴依其意愿结婚，若监护人未授权该意愿，也不视为该婚姻已经得到其有效同意。

<!-- source-p 59 -->
<a id="38.1.13.5"></a>**5.**释奴保护人事后追认女自由释奴的婚姻，也会使其丧失劳务请求权。

<a id="38.1.22.pr."></a>**序言**　释奴保护人约定由自由释奴提供劳务时，只有在他已经请求提供而自由释奴未予提供时，约定才发生违约效果。无论是否加上“在我请求时”这句话，结论都相同；因为劳务与其他事项不同。提供劳务不过是履行一项义务，认为该义务应在接受劳务者所希望的日期以外履行，是荒谬的。

<!-- source-p 90 -->
<a id="38.1.22.1"></a>**1.**自由释奴承诺向释奴保护人提供劳务，却未加上“并向其子女提供”，只有在这些子女成为父亲的继承人时，才可由他们请求劳务。尤利安认为，子女成为其父亲的继承人，只有在并非经由他人继承时，才有利于他们请求劳务。因此，若某人将已被父亲排除继承的解放出家父权之子的一名奴隶指定为继承人，而该儿子经由该奴隶成为继承人，就应驳回其劳务请求；正如在释奴保护人未课加劳务，或将其已经课加的劳务重新买回时，也应驳回请求一样。

<!-- source-p 91 -->
<a id="38.1.22.2"></a>**2.**对于所有劳务，尤其应确保留给自由释奴必要的时间照料身体。

<!-- source-p 95 -->
<a id="38.1.23.1"></a>**1.**若数名释奴保护人故意分别前往不同地区，同时要求自由释奴提供劳务，可以说劳务到期日已经开始计算，但自由释奴不负义务，因为未能提供劳务并非由他造成，而是释奴保护人造成的；自由释奴患病而被要求提供劳务时，也是如此。若释奴保护人分居不同城市，各自留在自己的城市，他们就必须就接受自由释奴提供的劳务达成一致。否则情形便过于严苛：自由释奴本可通过工作十日解除全部义务，但若释奴保护人同时要求提供劳务、又不能就接受劳务达成一致，却仍迫使他向其中一人支付五日劳务的估价。

<a id="38.1.25.1"></a>**1.**例如，若某人有一名哑剧演员或首席哑剧演员身份的自由释奴，而其财产仅属中等，以至于只有将该人的劳务出租，才能利用这些劳务，那么应认为他是在请求提供劳务，而不是收取租金。

<!-- source-p 103 -->
<a id="38.1.25.2"></a>**2.**同样，医生往往把从事同一技艺的奴隶释放为自由人；他们只能通过出租其劳务，才能持续利用这些劳务。其他手艺人也可以如此处理。

<!-- source-p 104 -->
<a id="38.1.25.3"></a>**3.**但是，若有人能够自行利用其自由释奴的劳务，却宁愿出租并取得价款，则应认为他是在收取其自由释奴劳务的租金。

<!-- source-p 105 -->
<a id="38.1.25.4"></a>**4.**有时，释奴保护人是应自由释奴本人的请求而出租劳务；在这种情况下，应认为他取得的更像是劳务价款，而非租金。

<!-- source-p 106 -->
<a id="38.1.26"></a>**38.1.26**

<!-- source-p 107 -->
阿尔费努斯·维鲁斯《学说汇纂》第七卷。

<!-- source-p 108 -->
<a id="38.1.26.pr."></a>**序言**　一名自由释奴医生认为，若其自由释奴不再行医，会有更多人向他本人求医；因此，他要求这些自由释奴跟随自己，不得另行执业。这种要求是否合法？答复说，合法，但前提是他要求的是无偿劳务；也就是说，应允许这些自由释奴在午间休息，并顾及自己的健康和体面。

<!-- source-p 109 -->
<a id="38.1.26.1"></a>**1.**我还询问，若这些自由释奴不愿提供此类劳务，应按多少金额估价。答复说，应按释奴保护人能够从他们的劳务取得多少收益估价，而非按禁止他们行医给他们造成不便的程度估价。

<!-- source-p 110 -->
<a id="38.1.27"></a>**38.1.27**

<!-- source-p 111 -->
尤利安《米尼基乌斯评注》第一卷。

<!-- source-p 112 -->
自由释奴若从事哑剧演员技艺，确实不仅应向释奴保护人本人无偿提供劳务，也应在释奴保护人朋友的演出中无偿提供劳务。同样，从事医疗的自由释奴，释奴保护人若愿意，也确实可以要求他免费为自己的朋友治病。毕竟，释奴保护人不必为了利用其自由释奴的劳务而总是举办演出，或总是生病。

<!-- source-p 122 -->
<a id="38.1.30.1"></a>**1.**对于经释奴保护人同意而结婚的女自由释奴，仍可就其结婚前已经到期的劳务提起诉讼。

<!-- source-p 141 -->
<a id="38.1.37"></a>**38.1.37**

<!-- source-p 142 -->
保罗《尤利亚—帕皮亚法评注》第二卷。

<!-- source-p 143 -->
<a id="38.1.37.pr."></a>**序言**　“若一名自由释奴有两名或更多由其亲生的子女处于自己的权力之下，但不包括从事舞台表演者或出租自身劳务与野兽搏斗者，则对于他曾宣誓、承诺或以其他方式承担义务的事项，任何人均不得要求他向释奴保护人、女释奴保护人或其子女提供、履行或给付劳务、赠与、其他恩惠或任何其他东西。”

<!-- source-p 144 -->
<a id="38.1.37.1"></a>**1.**即使他并未在同一时间有两名子女处于自己权力之下，只要有一名年满五岁的子女处于其权力之下，也可以免除劳务义务。

<!-- source-p 145 -->
<a id="38.1.37.1a"></a>**1a.**尤利安说，先前已经死亡的子女，也可以使自由释奴免于后来所课加的劳务。

<!-- source-p 146 -->
<a id="38.1.37.2"></a>**2.**若自由释奴在失去一名子女后承担劳务义务，之后又有另一名子女出生，庞波尼乌斯说，前一名已死亡的子女更应与后来出生的子女一并计算，使自由释奴获得免责。

<!-- source-p 147 -->
<a id="38.1.37.3"></a>**3.**无论自由释奴是向释奴保护人本人承诺，还是向处于释奴保护人权力之下的人承诺，结论均无区别。

<!-- source-p 148 -->
<a id="38.1.37.4"></a>**4.**但是，若释奴保护人将自由释奴指定给自己的债权人，结论就不同；这种指定具有清偿的效力。不过，若自由释奴先向释奴保护人承诺，之后又被指定给他人，则可以说他能够依据本法免责；因为即使他现在不再欠释奴保护人，他确曾向其承担替代给付义务。反之，若释奴保护人一开始就指定他向他人承诺，则自由释奴不能免责。

<!-- source-p 149 -->
<a id="38.1.37.5"></a>**5.**免责不仅适用于将来的劳务，也适用于过去的劳务。

<!-- source-p 150 -->
<a id="38.1.37.6"></a>**6.**尤利安还认为，即使已经请求劳务，只要自由释奴有了子女，也应免除其义务。但是，若他已经因劳务被判决承担责任，则不能免责，因为此时他已开始负有金钱债务。

<!-- source-p 151 -->
<a id="38.1.37.7"></a>**7.**自由释奴的遗腹子女不能使其父亲的继承人免责，因为免责必须由自由释奴本人取得；任何人都不可能在死后才被视为免责。不过，依法出生的子女可以使其免责。

<!-- source-p 152 -->
<a id="38.1.37.8"></a>**8.**即使法律规定的免责仅涉及自由释奴本人，依该法的解释，保证人也会一并免责；但若自由释奴提供了债务承担人（*expromissor*），则本条对其不发生作用。

<!-- source-p 153 -->
<a id="38.1.38"></a>**38.1.38**

<!-- source-p 154 -->
卡利斯特拉图斯《告示通知评注》第三卷。

<!-- source-p 155 -->
<a id="38.1.38.pr."></a>**序言**　只有能够在不失体面且不危及生命的情况下提供的劳务，才被认为可以课加。例如，女妓获释后，即使仍以身体营利，也无须向释奴保护人提供同类劳务；竞技场斗士获释后，也无须提供这类劳务，因为这些劳务无法在不危及生命的情况下履行。

<!-- source-p 156 -->
<a id="38.1.38.1"></a>**1.**但是，若自由释奴从事某项技艺，即使他是在获释之后才学会的，也应向释奴保护人提供该项技艺的劳务。若他不再从事该技艺，则应提供不损害其身份尊严的劳务，例如陪伴释奴保护人、随其出行至外地或为其处理事务。

<!-- source-p 157 -->
<a id="38.1.39"></a>**38.1.39**

<!-- source-p 158 -->
保罗《普劳提乌斯评注》第七卷。

<!-- source-p 159 -->
<a id="38.1.39.pr."></a>**序言**　若释奴保护人如此订立口约：“若你不提供十日劳务，你承诺支付二十钱币吗？”应当考察：是否既不得请求二十钱币——因为其承诺是为了加重自由释奴的负担——也不得请求未曾承诺的劳务？抑或应认定仅承诺了劳务，以免释奴保护人的请求完全被排除？裁判官也采纳后一意见，即只认定承诺了劳务。

<!-- source-p 160 -->
<a id="38.1.39.1"></a>**1.**接下来的问题是，自由释奴是否应获准请求判决金额不得超过二十；因为释奴保护人似乎以此金额评估劳务，所以判决金额不应超过二十。但不应宽待自由释奴，让其提出这种主张并不公平，因为他不能一方面承认义务的一部分有效，另一方面又抱怨另一部分不公平。
