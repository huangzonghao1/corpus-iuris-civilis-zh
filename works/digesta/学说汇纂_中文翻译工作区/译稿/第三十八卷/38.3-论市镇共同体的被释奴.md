# D.38.3 论市镇共同体的被释奴（*De libertis universitatium*）

<!-- source-p 449 -->
<a id="3"></a><a id="38.3"></a>**38.3.0 论市镇共同体的被释奴**（*De libertis universitatium*）。

<!-- source-p 450 -->
<a id="38.3.1"></a>**38.3.1**

<!-- source-p 451 -->
乌尔比安《告示评注》第四十九卷。

<!-- source-p 452 -->
<a id="38.3.1.pr."></a>**序言**　市镇共同体对被释奴与女被释奴的遗产，享有完整权利；也就是说，享有释奴保护人所享有的权利。

<!-- source-p 453 -->
<a id="38.3.1.1"></a>**1**　市镇共同体能否亲自请求遗产占有，尚有疑问。问题在于，它们不能自行表示同意；不过，可以由他人代为请求遗产占有，从而由共同体本身取得该权利。既然元老院曾裁定，可以依《特雷贝利安元老院决议》将遗产返还给它们；又曾依据另一项元老院决议，允许它们在被释奴指定为继承人时取得遗产，那么也应当说，它们可以请求遗产占有。

<!-- source-p 454 -->
<a id="38.3.1.2"></a>**2**　市镇共同体请求遗产占有的期间，应自其能够就是否请求作出决定之时起算。帕比尼安也作此答复。
