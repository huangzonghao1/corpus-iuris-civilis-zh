# D.38.2 论被释奴的财产（*De bonis libertorum*）

<!-- source-p 200 -->
<a id="2"></a><a id="38.2"></a>**38.2.0 论被释奴的财产**（*De bonis libertorum*）。

<!-- source-p 201 -->
<a id="38.2.1"></a>**38.2.1**

<!-- source-p 202 -->
乌尔比安《告示评注》第四十二卷。

<!-- source-p 203 -->
<a id="38.2.1.pr."></a>**序言**　裁判官颁布本告示，旨在调节被释奴应给予释奴保护人的敬意。正如塞尔维乌斯所记，从前，释奴保护人惯于向被释奴索取极为苛刻的事项，以报偿施加于被释奴身上的重大恩惠——使他们脱离奴隶身份，成为罗马公民。

<!-- source-p 204 -->
<a id="38.2.1.1"></a>**1**　最初，鲁提利乌斯裁判官宣布，除劳务诉权和合伙诉权外，他不再向释奴保护人提供其他诉权；也就是说，双方曾约定：若被释奴不向其履行敬顺义务（*obsequium*），释奴保护人便可以加入合伙。

<!-- source-p 205 -->
<a id="38.2.1.2"></a>**2**　后来的裁判官承诺授予遗产的确定份额的遗产占有。显然，合伙关系的观念促使人们在死后给付相同份额：被释奴生前通常以合伙名义给付什么，死后也应给付什么。

<!-- source-p 206 -->
<a id="38.2.2"></a>**38.2.2**

<!-- source-p 207 -->
庞波尼乌斯《评萨宾》第四卷。

<!-- source-p 208 -->
<a id="38.2.2.pr."></a>**序言**　若释奴保护人因被被释奴遗嘱遗漏，原本可以请求违遗嘱的遗产占有，却在请求前死亡，或请求遗产占有的期限已经届满，则其子女或另一释奴保护人的子女，可以依告示的相应部分请求；该部分规定，在先顺位者未请求，或甚至表示该权利与自己无关时，后顺位者可以请求。〔底本末尾文字疑误，作 *atque si priores ex eo numero non essententiarum*；此处暂按“如同在先顺位者不属于该等人”理解。〕

<!-- source-p 209 -->
<a id="38.2.2.1"></a>**1**　但是，如果释奴保护人在被释奴生前被指定为继承人，却先于被释奴死亡，并留下子女，那么问题在于，这些子女能否请求违遗嘱的遗产占有。最终采取的意见是，应考察遗产占有发生的时点，即死亡时释奴保护人是否仍在世；若其仍在世，则其子女不得依告示第一部分请求遗产占有。

<!-- source-p 210 -->
<a id="38.2.2.2"></a>**2**　若一名解放出家父权的儿子留下仍处于祖父权力之下的孙子，则应将无遗嘱死亡的被释奴遗产一半的遗产占有授予该儿子；尽管依市民法，法定继承应归孙子，因为若该被释奴立有遗嘱，儿子反而会取得其应得份额的遗产占有，而非孙子。

<!-- source-p 211 -->
<a id="38.2.3"></a>**38.2.3**

<!-- source-p 212 -->
乌尔比安《告示评注》第四十一卷。

<!-- source-p 213 -->
<a id="38.2.3.pr."></a>**序言**　即使被释奴从皇帝处取得佩戴金戒指的权利（*ius anulorum*），释奴保护人仍可依其遗嘱请求遗产占有；许多敕答都确认了这一点。因为此人活着时如同自由出生者，死亡时却如同被释奴。

<!-- source-p 214 -->
<a id="38.2.3.1"></a>**1**　当然，若其被恢复为自由出生者身份（*natalibus redditus*），则不再发生违遗嘱的遗产占有。

<!-- source-p 215 -->
<a id="38.2.3.2"></a>**2**　若其从皇帝处取得自由立遗嘱权，结论亦同。

<!-- source-p 216 -->
<a id="38.2.3.3"></a>**3**　但是，若有人依约购买奴隶，条件是将其释奴，则属于告示本部分的适用范围。

<!-- source-p 217 -->
<a id="38.2.3.4"></a>**4**　若有人收取钱款以释奴，则其不享有违遗嘱的遗产占有。

<!-- source-p 218 -->
<a id="38.2.3.5"></a>**5**　释奴保护人若要取得违遗嘱的遗产占有，必须有人接受继承，或有人请求遗产占有；继承人中只要一人接受继承或请求遗产占有，即已足够。

<!-- source-p 219 -->
<a id="38.2.3.6"></a>**6**　释奴保护人绝不得就被释奴在军营中取得的财产请求遗产占有。

<!-- source-p 220 -->
<a id="38.2.3.7"></a>**7**　若被流放的释奴保护人获准复归，他可以请求被释奴遗产的违遗嘱遗产占有。被流放后获准复归的被释奴，亦应作同样处理。

<!-- source-p 221 -->
<a id="38.2.3.8"></a>**8**　若家子从军营特有产中释奴，依神圣哈德良皇帝的敕令，其释奴保护人得以释奴保护人身份请求违遗嘱的遗产占有。

<!-- source-p 222 -->
<a id="38.2.3.9"></a>**9**　若被指定归属于某一儿子的被释奴遭该儿子提起身份之诉，该儿子便不得请求违遗嘱的遗产占有；这也不妨碍其兄弟请求。兄弟可以请求违遗嘱的遗产占有，犹如他们是另一名儿子的孙辈；因为被指定归属于其中一名儿子的被释奴，并不因此不再是另一名儿子的被释奴。还应进一步说，即使一名兄弟放弃遗产占有，未被指定为该被释奴释奴保护人的另一名兄弟，也可以承继请求并取得违遗嘱的遗产占有。

<!-- source-p 223 -->
<a id="38.2.3.10"></a>**10**　每当释奴保护人未被指定为继承人，或所得份额未达到其应得份额时，便可以请求违遗嘱的遗产占有。

<!-- source-p 224 -->
<a id="38.2.3.11"></a>**11**　若释奴保护人被附条件指定为继承人，且该条件在立遗嘱人仍在世时成就，他便不得取得违遗嘱的遗产占有。

<!-- source-p 225 -->
<a id="38.2.3.12"></a>**12**　那么，若条件在立遗嘱人死亡时仍悬而未决，却在遗产占有授予释奴保护人之前、也就是有人接受继承之前成就，应如何处理？较妥当的看法是，应以接受继承的时点为准；我们现行的法律正是如此。

<!-- source-p 226 -->
<a id="38.2.3.13"></a>**13**　不过，若条件被设定为过去已经发生或现在正在发生，就不视为附条件指定继承人：条件若已成就，则指定是无条件的；若未成就，则此人根本未被指定为继承人。

<!-- source-p 227 -->
<a id="38.2.3.14"></a>**14**　若被释奴如此指定释奴保护人为继承人：“若我的儿子先于我死亡，则释奴保护人应为继承人”，则该遗嘱并无不妥；因为儿子若死亡，条件成就时，释奴保护人便可以取得遗产占有。

<!-- source-p 228 -->
<a id="38.2.3.15"></a>**15**　若以遗赠方式给予释奴保护人其应得份额，即使未将其指定为继承人，也足以满足其权利。

<!-- source-p 229 -->
<a id="38.2.3.16"></a>**16**　若其被指定的份额少于应得份额，而其余部分通过遗赠或遗嘱信托补足，也应认为其权利已获满足。

<!-- source-p 230 -->
<a id="38.2.3.17"></a>**17**　也可以通过因死亡而生效的赠与补足释奴保护人应得的份额，因为此类赠与发挥遗赠的作用。

<!-- source-p 231 -->
<a id="38.2.3.18"></a>**18**　若被释奴并非因死亡而向释奴保护人赠与财物，但赠与是为了满足其应得份额，结论也相同：这些财物要么视同因死亡而生效的赠与予以计入，要么视同被释奴已经认可其应得份额，从而排除释奴保护人请求违遗嘱遗产占有。

<!-- source-p 232 -->
<a id="38.2.3.19"></a>**19**　若为使释奴保护人履行某项条件而向其给付财物，只要该财物来自被释奴的财产，就应计入其应得份额。

<!-- source-p 233 -->
<a id="38.2.3.20"></a>**20**　我们将被释奴死亡时所拥有财产的应得份额授予释奴保护人，因为应以死亡时为准。若被释奴以恶意使自己不再拥有某物，裁判官也希望将该物视为仍属于其财产。

<!-- source-p 234 -->
<a id="38.2.4"></a>**38.2.4**

<!-- source-p 235 -->
保罗《告示评注》第四十二卷。

<!-- source-p 236 -->
<a id="38.2.4.pr."></a>**序言**　若奴隶揭发其主人的谋杀，裁判官通常裁定使其成为自由人；据确认，他是仿照元老院决议而取得自由，并不成为任何人的释奴。

<!-- source-p 237 -->
<a id="38.2.4.1"></a>**1**　若被释奴遭敌人俘虏并死于敌境，尽管“被释奴”这一称谓不再适用于他，但由于科尔内利亚法将其遗嘱视同他在罗马公民共同体中死亡时所立，释奴保护人也应取得遗产占有。

<!-- source-p 238 -->
<a id="38.2.4.2"></a>**2**　若释奴保护人被流放，其子可以就被释奴的财产取得遗产占有；释奴保护人被视为已死亡，不妨碍其子取得遗产占有。若释奴保护人被敌人俘虏，情形则不同：由于存在其复归原状的希望，他会妨碍自己的子女取得遗产占有。

<!-- source-p 239 -->
<a id="38.2.4.3"></a>**3**　若被释奴指定外人为继承人，并嘱托其将遗产返还给儿子；而根据特雷贝利乌斯元老院决议，遗产返还后儿子被视为继承人，则应排除释奴保护人。

<!-- source-p 240 -->
<a id="38.2.5"></a>**38.2.5**

<!-- source-p 241 -->
盖尤斯《行省告示评注》第十五卷。

<!-- source-p 242 -->
<a id="38.2.5.pr."></a>**序言**　被释奴既有释奴保护人，也有释奴保护人的子女。若其将释奴保护人指定为继承人，份额达到应得份额，就应将释奴保护人的子女替补指定为同一份额的继承人；这样，即使释奴保护人在被释奴生前死亡，也可认为其子女的权利已获满足。

<!-- source-p 243 -->
<a id="38.2.5.1"></a>**1**　若被释奴的释奴保护人有一名已解放出家父权的儿子，以及一名仍留在祖父家族中的孙子，则被释奴只须满足该儿子的权利，而无须满足孙子的权利；即使二人都被召入继承其尊亲属的财产，也不影响这一点。

<!-- source-p 244 -->
<a id="38.2.6"></a>**38.2.6**

<!-- source-p 245 -->
乌尔比安《告示评注》第四十三卷。

<!-- source-p 246 -->
<a id="38.2.6.pr."></a>**序言**　即使被释奴的子女仅被指定为很小的份额继承人，释奴保护人也不得请求违遗嘱的遗产占有。马尔切卢斯在《学说汇纂》第九卷中也写道：只要被释奴的儿子被指定为任何份额的继承人，即使份额极小，也足以排除释奴保护人。

<!-- source-p 247 -->
<a id="38.2.6.1"></a>**1**　某被释奴指定释奴保护人的女儿为继承人，但遗嘱被宣告为伪造；该女儿提起上诉后，在上诉尚未审结时死亡。神圣马可·奥理略皇帝救济了她的继承人，使他们取得她若仍在世本可取得的财产。

<!-- source-p 248 -->
<a id="38.2.6.2"></a>**2**　若被释奴的儿子被指定为继承人，却放弃继承，即使他在名义上仍是继承人，释奴保护人也可以请求遗产占有。

<!-- source-p 249 -->
<a id="38.2.6.3"></a>**3**　若某人通过恢复原状而退出其已介入的父亲遗产，或退出其已接受的遗产，也可以准许释奴保护人请求遗产占有。

<!-- source-p 250 -->
<a id="38.2.6.4"></a>**4**　若释奴保护人及其子女依已故被释奴的意思接受继承，或选择请求遗赠或遗嘱信托，则不得请求违遗嘱的遗产占有。

<!-- source-p 251 -->
<a id="38.2.7"></a>**38.2.7**

<!-- source-p 252 -->
盖尤斯《行省告示评注》第十五卷。

<!-- source-p 253 -->
若允许同一人一方面认可死者的判断，另一方面又推翻该判断，似乎荒谬。

<!-- source-p 254 -->
<a id="38.2.8"></a>**38.2.8**

<!-- source-p 255 -->
乌尔比安《告示评注》第四十三卷。

<!-- source-p 256 -->
<a id="38.2.8.pr."></a>**序言**　若其请求实际上未发生效力，我认为这并不妨碍对其予以救济。甚至，若他以已被指定为应得份额继承人的身份接受继承，之后却发现自己取得的份额少于预期，准许他请求救济也极为公平。若他起初接受遗嘱安排并要求继承人向其给付遗赠，后来又改变主意，我认为也可以给予救济。

<!-- source-p 257 -->
<a id="38.2.8.1"></a>**1**　若释奴保护人认可遗赠给他的遗赠，而该遗赠后来被追夺，他有权取得法定救济，因为他并未得到自己原以为会取得的东西。即使遗赠并未全部被追夺，而只是所得少于原先预期，也应给予救济。

<!-- source-p 258 -->
<a id="38.2.8.2"></a>**2**　若释奴保护人认可留给其奴隶或儿子的遗赠，应视同他认可留给自己的遗赠；因此，他会被排除在违遗嘱的遗产占有之外。

<!-- source-p 259 -->
<a id="38.2.8.3"></a>**3**　若他认可因死亡而生效的赠与，也应说他会被排除在违遗嘱的遗产占有之外，但须以他在被释奴死亡后才予认可为限。反之，若被释奴生前赠与、释奴保护人也已接受，则他不会仅因此被排除；因为他可以主张自己原本希望被释奴在遗嘱中也对他表示感激。遗产占有人应允许他放弃该赠与，或按比例将其抵充应得份额。

<!-- source-p 260 -->
<a id="38.2.8.4"></a>**4**　因此，若被释奴死后为使释奴保护人履行某一条件而向其给付财物，也应说释奴保护人会被排除在违遗嘱的遗产占有之外，仿佛他已经认可死者的遗嘱安排。

<!-- source-p 261 -->
<a id="38.2.8.5"></a>**5**　若释奴保护人未满二十五岁便认可被释奴的遗嘱安排，我们认为应使其恢复原状，以便他能够请求违遗嘱的遗产占有。

<!-- source-p 265 -->
<a id="38.2.10"></a>**38.2.10**

<!-- source-p 266 -->
乌尔比安《告示评注》第四十四卷。

<!-- source-p 267 -->
<a id="38.2.10.pr."></a>**序言**　若释奴保护人中有人未获满足，而被释奴的财产却使另一人得以取得超过其份额的财产，则未获满足者可以提起诉讼，请求以遗产指定给外部继承人的部分，以及给付释奴保护人超过其应得份额的部分，补足其份额。释奴保护人不止一人时，也适用同一规则。

<!-- source-p 268 -->
<a id="38.2.10.1"></a>**1**　尤利安说：某人若被祖父剥夺继承权，应被排除于该祖父被释奴的财产之外，但不排除于其父亲被释奴的财产之外。若此人被父亲剥夺继承权、却未被祖父剥夺，则不仅应排除于父亲被释奴的财产之外，也应排除于祖父被释奴的财产之外，因为他是经由父亲取得祖父被释奴的权利。反之，若其父亲被祖父剥夺继承权，而此人本人未被剥夺，则该孙子可以请求祖父被释奴的违遗嘱遗产占有。尤利安还说：若父亲剥夺了我的继承权，祖父以及更早一代的祖父先后死亡，我应被排除于二人各自的被释奴财产之外；但若父亲先死亡、祖父后死亡，则应认为父亲对我作出的剥夺继承权，不妨碍我就祖父的被释奴财产请求权利。

<!-- source-p 269 -->
<a id="38.2.11"></a>**38.2.11**

<!-- source-p 270 -->
尤利安《学说汇纂》第二十六卷。

<!-- source-p 271 -->
若我的父亲被其父亲剥夺继承权，而我既未被父亲也未被祖父剥夺继承权，则父亲死亡后，我对祖父和父亲的被释奴均享有权利。父亲仍在世时，只要我仍处于其权力之下，就不得请求祖父被释奴的违遗嘱遗产占有；若我已解放出家父权，则不会因此被排除。

<!-- source-p 272 -->
<a id="38.2.12"></a>**38.2.12**

<!-- source-p 273 -->
乌尔比安《告示评注》第四十四卷。

<!-- source-p 274 -->
<a id="38.2.12.pr."></a>**序言**　若释奴保护人在依军法订立的遗嘱中，以沉默方式剥夺其儿子的继承权，该剥夺应对儿子发生不利效力；因为儿子确实被剥夺了继承权。

<!-- source-p 275 -->
<a id="38.2.12.1"></a>**1**　若某人将一名被释奴指定归属于自己的儿子，并在遗嘱中剥夺该儿子的继承权，则该儿子仍可请求被释奴财产的遗产占有。

<!-- source-p 276 -->
<a id="38.2.12.2"></a>**2**　若某人被剥夺继承权并非出于其尊亲属的恶意，而是基于其他原因，该剥夺不对其发生不利效力。例如，可设其因精神错乱而被剥夺继承权；或者因为尚未达到适婚年龄，虽被指定为继承人，却被要求将继承到的遗产返还。

<!-- source-p 277 -->
<a id="38.2.12.3"></a>**3**　若某人被剥夺继承权，但裁判错误地宣告其并未被剥夺，则不应将其排除；因为应尊重已经作出的裁判。

<!-- source-p 278 -->
<a id="38.2.12.4"></a>**4**　若释奴保护人的儿子提起遗嘱不孝之诉，部分胜诉、部分败诉，我们应考察剥夺继承权是否对其不利。我认为应当不利，因为剥夺其继承权的遗嘱仍然有效。

<!-- source-p 279 -->
<a id="38.2.12.5"></a>**5**　若遗嘱既未有人接受继承，也未有人请求遗产占有，则对释奴保护人子女的剥夺继承权不发生不利效力；否则，遗嘱在其他方面虽不生效，却唯独使剥夺继承权发生效力，未免荒谬。

<!-- source-p 280 -->
<a id="38.2.12.6"></a>**6**　若释奴保护人的儿子在遗嘱第一顺位被指定为继承人，第二顺位则被剥夺继承权，该剥夺对他不发生不利效力；因为依父亲的意思，他要么已经成为继承人，要么本可成为继承人。父亲既已将儿子列为自己遗产的第一顺位继承人，就不应认为他认为儿子不配取得被释奴的财产。即使儿子在第一顺位被剥夺继承权、却在同一遗嘱中被指定为替补继承人，也不应认为他被排除于被释奴的财产之外。因此，凡在遗嘱第一顺位、其后顺位或其他顺位被指定为继承人的人，即使在同一遗嘱中也被剥夺继承权，仍不得被排除于被释奴的财产之外。

<!-- source-p 281 -->
<a id="38.2.12.7"></a>**7**　若释奴保护人的已解放出家父权的儿子拒绝接受继承，或仍处于父权下的儿子拒绝保留继承，即使如此，该儿子仍可取得被释奴的遗产占有。

<!-- source-p 287 -->
<a id="38.2.14.pr."></a>**序言**　释奴保护人的儿子年满二十五岁后，若曾以重罪起诉被释奴，或请求将其置于奴隶身份，则应被排除于违遗嘱的遗产占有之外。

<!-- source-p 288 -->
<a id="38.2.14.1"></a>**1**　若起诉人尚未成年，则应认为不排除其请求，无论由其本人起诉，还是由其监护人或保佐人起诉。

<!-- source-p 289 -->
<a id="38.2.14.2"></a>**2**　若其未成年时提起起诉，成年后才收到判决，应宽厚处理，认为不应排除他，因为起诉始于其未成年时。我们不能责怪他为何未撤回起诉，或未请求撤销程序：若作前者，可能会违反图尔皮利安努斯法；若作后者，通常也不容易获得准许。确实，若法院已正式准许撤销，他成年后又重新起诉，则应将其排除；因为成年后，他本可无须顾虑地放弃已撤销的起诉。

<!-- source-p 290 -->
<a id="38.2.14.3"></a>**3**　只有在某程序中提出指控，且该程序的刑罚是死刑、体罚，或与流放相当并导致丧失公民身份的放逐，才视为以重罪起诉。

<!-- source-p 291 -->
<a id="38.2.14.4"></a>**4**　若某人以并非死罪的罪名起诉被释奴，但审判者决定加重刑罚，这不会损害释奴保护人的儿子；因为审判者的无知或严苛，不应损害只提出较轻罪名的释奴保护人之子。

<!-- source-p 292 -->
<a id="38.2.14.5"></a>**5**　若他并未起诉，却在针对被释奴的重罪程序中作证，或唆使他人起诉，我认为应将其排除于违遗嘱的遗产占有之外。

<!-- source-p 293 -->
<a id="38.2.14.6"></a>**6**　若被释奴以叛国罪起诉释奴保护人的儿子，而该儿子请求以诬告罪对被释奴处以死刑，不应依本告示将其排除。我认为，若被释奴先起诉他，而他反过来指控被释奴，结论也相同；若他受到挑衅后意图报复，应予宽宥。

<!-- source-p 294 -->
<a id="38.2.14.7"></a>**7**　若释奴保护人的儿子有必要为父亲之死追责——例如因此起诉父亲的被释奴医生、侍寝室的奴仆或其他曾在父亲身边的人——是否也应给予救济？我认为，若出于亲情并因父亲财产面临危险，他不得已提起起诉，即使起诉带有诬告性质，也应给予救济。

<!-- source-p 295 -->
<a id="38.2.14.8"></a>**8**　只有提出罪名并使案件审理持续至判决，才称得上起诉；若在此之前停止，就不算起诉，我们也依此规则行事。但若因提起上诉而停止，应宽厚地认为他没有使起诉进行到底。因此，若被释奴在上诉期间死亡，释奴保护人的儿子可以取得遗产占有，因为被释奴因死亡而未能等到判决。

<!-- source-p 296 -->
<a id="38.2.14.9"></a>**9**　若释奴保护人的儿子为起诉被释奴的人提供法律协助，不应将其排除；律师并不因此成为起诉人。

<!-- source-p 297 -->
<a id="38.2.14.10"></a>**10**　若父亲在遗嘱中规定应起诉其被释奴，例如该人曾企图给自己下毒或对自己做了其他事情，则更妥当的意见是，应宽宥并非出于自愿而起诉的子女。

<!-- source-p 298 -->
<a id="38.2.14.11"></a>**11**　若释奴保护人的儿子起诉被释奴并证明其罪行，之后该被释奴又获准恢复原状，则不应将该儿子排除；因为他所提出的指控已经得到证明。

<a id="38.2.16.pr."></a>**序言**　被视为请求将他人置于奴隶身份的，并非这样的人：对方仍处于奴隶占有状态并请求确认自由，他只是对此提出抗辩。只有从自由身份出发请求将他人置于奴隶身份的人，才属于此列。

<!-- source-p 305 -->
<a id="38.2.16.1"></a>**1**　若有人并非主张他人全部属于自己，而只主张部分所有权、用益权，或其他只有在该人是奴隶时才可能享有的权利，是否也应将其视为请求将对方置于奴隶身份而予以排除？较妥当的意见是应予排除。

<!-- source-p 306 -->
<a id="38.2.16.2"></a>**2**　若某人曾请求将被释奴置于奴隶身份并胜诉，后来得知真相后又容许其保持自由身份，不应因此对其不利；尤其是他有正当理由发生误解时。

<!-- source-p 307 -->
<a id="38.2.16.3"></a>**3**　在诉讼标的确定之前放弃请求将他人置于奴隶身份的人，不视为曾提出此项请求。即使在诉讼标的确定之后才放弃，也应说这不应对其不利，因为诉讼并未持续至判决。

<!-- source-p 308 -->
<a id="38.2.16.4"></a>**4**　若释奴保护人的儿子被剥夺继承权，或曾请求将父亲的被释奴置于奴隶身份，或曾以重罪起诉该被释奴，这些行为不损害不再处于其父权下的子女；神圣的昆提利兄弟曾就此作出敕答。

<!-- source-p 309 -->
<a id="38.2.16.5"></a>**5**　若释奴保护人已取得被释奴遗产的违遗嘱遗产占有，就应被排除于被释奴遗嘱所设的一切权利之外；不仅在他本人被指定为继承人时如此，即使他被指定为未适婚儿子的替补继承人，也同样如此。尤利安还写道：释奴保护人在请求遗产占有后，若接受了被释奴未适婚儿子的遗产，应拒绝给予他诉权。

<!-- source-p 310 -->
<a id="38.2.16.6"></a>**6**　若以遗嘱附录留给释奴保护人某物，或向其作出因死亡而生效的赠与，也应同样拒绝其请求这些财物。

<!-- source-p 311 -->
<a id="38.2.16.7"></a>**7**　不过，有时即使释奴保护人已经请求遗产占有，仍可准许其请求遗赠；例如他并未从遗赠中获得任何利益，因为他受托将遗赠返还给他人。

<!-- source-p 312 -->
<a id="38.2.16.8"></a>**8**　此外，裁判官说不予支持的，不仅是明确直接给予释奴保护人的财物；即使财物经由他人最终归其所有，只要预计他会保有而不予返还，也应如此处理，例如通过受其控制的人转给他。

<!-- source-p 313 -->
<a id="38.2.16.9"></a>**9**　若被释奴释放了释奴保护人的奴隶，并预先将该奴隶的价款遗赠给释奴保护人，则应准许释奴保护人请求该遗赠。

<!-- source-p 314 -->
<a id="38.2.16.10"></a>**10**　释奴保护人请求违遗嘱遗产占有后，被指定为其替补继承人的人，不得取得原本授予该释奴保护人份额的诉权。

<!-- source-p 315 -->
<a id="38.2.16.11"></a>**11**　若释奴保护人被指定为替补继承人，却先于立遗嘱人死亡；其儿子请求违遗嘱的遗产占有时，众所周知，他取得的不仅是替补继承人的份额，也会按比例从所有继承人处取得一部分。

<!-- source-p 329 -->
<a id="38.2.20.1"></a>**1**　若遗赠给提提乌斯，并嘱托其将遗赠返还给释奴保护人；若遗嘱指定继承人已经满足释奴保护人的应得份额，则应拒绝提提乌斯提起遗赠诉讼。

<!-- source-p 330 -->
<a id="38.2.20.2"></a>**2**　被释奴将释奴保护人与外部人共同指定为遗产一半的继承人。释奴保护人被指定取得的四分之一，应全部计入其本人份额；至于其余应得份额，则应按比例从所有继承人处扣除。

<!-- source-p 331 -->
<a id="38.2.20.3"></a>**3**　若遗赠共同给予释奴保护人与提提乌斯，也应适用同一规则：释奴保护人取得的遗赠部分计入其应得份额；其余部分则按比例仅从提提乌斯处扣除。

<!-- source-p 332 -->
<a id="38.2.20.4"></a>**4**　若被释奴将解放出家父权的儿子附条件指定为继承人，条件未成就时由替补继承人接受遗产，我询问：裁判官应否准许释奴保护人向替补继承人请求其应得份额，还是应准许已解放出家父权的儿子向替补继承人请求全部遗产？我答复说：父亲将儿子列为第一顺位的附条件继承人时，若儿子所附条件未成就，继承权转由第二顺位取得；或者儿子在条件仍悬而未决时死亡，释奴保护人即可向替补继承人请求其应得份额的遗产占有。若儿子未及时请求遗产占有而丧失权利，或明确放弃，结论亦同。反之，若条件未成就时继承权归于儿子，裁判官应优先保护已解放出家父权的儿子，使其得以对抗替补继承人。我认为，儿子附条件被指定为继承人时，有些情形必须明确剥夺其在替补顺位的继承权，有些情形则无此必要。若条件取决于儿子自己的意愿，例如“待其立遗嘱时”，我认为即使未明确写明条件，儿子也会使替补继承人取得继承资格。若条件不取决于儿子自己的意愿，例如“若提提乌斯成为执政官”，则除非遗嘱明确剥夺儿子的替补顺位继承权，否则不准许替补继承人取得继承。

<!-- source-p 333 -->
<a id="38.2.20.5"></a>**5**　若被释奴指定已解放出家父权的儿子为继承人，并嘱托其将全部遗产返还给塞姆普罗尼乌斯；儿子称遗产负担过重，经裁判官命令接受继承后，将遗产返还给塞姆普罗尼乌斯，则不应不公平地拒绝释奴保护人取得应得份额的遗产占有；这应视同塞姆普罗尼乌斯而非儿子成为被释奴的继承人。

<!-- source-p 334 -->
<a id="38.2.20.6"></a>**6**　同样，若儿子放弃被释奴父亲的遗产，而其共同继承人承担全部遗产负担，则应授予释奴保护人遗产占有。这两种情形中，被剥夺份额的都是外部人，而不是儿子。

<a id="38.2.42"></a>**38.2.42**

<!-- source-p 405 -->
帕皮尼安《问题集》第十三卷。

<!-- source-p 406 -->
<a id="38.2.42.pr."></a>**序言**　某儿子继承父亲的遗产后，以自权人收养（*adrogatio*）方式收养了被剥夺继承权的兄弟，并在死亡时指定该兄弟为继承人。该兄弟不得请求其自然父亲被释奴的遗产占有：既然此类收养会损害未被剥夺继承权之人，也应损害被剥夺继承权之人；因为法律或告示施加的惩罚，不应通过收养的救济手段而消除。保罗批注说：若某人依据其所丧失权利以外的其他权利取得地位，则他不会因丧失的权利受损，反而因现有权利受益。因此曾说，释奴保护人或女性释奴保护人的儿子，即使其作为释奴保护人曾有过错，只要其是以女性释奴保护人之子的身份取得权利，这项过错就不应对其不利。帕皮尼安。

<!-- source-p 407 -->
<a id="38.2.42.1"></a>**1**　提提乌斯被被释奴指定为军营特有产的继承人，其他人则被指定为其余财产的继承人；提提乌斯接受了继承。我们较倾向于认为，释奴保护人尚不能请求违遗嘱的遗产占有。由此产生的问题是：若取得其余财产的人放弃继承，其份额是否像他们接受同一遗产的份额一样归并给提提乌斯？我认为，更妥当的意见是，其余财产应依无遗嘱继承规则转归他人。因此，提提乌斯作为继承人，不能使解放者请求遗产占有；因为提提乌斯没有被剥夺任何财产，而且其余财产尚不属于遗嘱所涉财产。

<!-- source-p 408 -->
<a id="38.2.42.2"></a>**2**　若被释奴的未适婚儿子被称为“冒认子女”（*subiectus*），并依第一顺位取得遗产占有，有人问，死者的释奴保护人能否取得遗产占有。毫无疑问，后顺位的人在此期间不得请求；因为既已有前一顺位的遗产占有，后顺位人便不能取得。若裁判认定该子女确属被顶替者，则此前授予的遗产占有不视为有效。释奴保护人若正处于争议之中，结论也相同；当然，涉及释奴保护人的争议也应延期处理。

<!-- source-p 409 -->
<a id="38.2.42.3"></a>**3**　若他人在行省宣称被释奴的遗嘱伪造，案件因上诉而拖延期间，释奴保护人的女儿——被释奴曾指定她为继承人——死亡，神圣马可皇帝便为该女子的儿子保留了该份财产；若她仍在世，该份财产依无遗嘱继承规则本可归她。

<!-- source-p 415 -->
<a id="38.2.44.pr."></a>**序言**　若你将释奴保护人指定为应得份额继承人，并无条件请求其交付一块土地，同时又附条件遗赠相当价值的财物给他，则该遗嘱信托受条件拘束。不过，此处仍有问题：释奴保护人会因遗嘱信托而被要求提供担保。但应当说，应由遗嘱信托受领人向释奴保护人提供担保；这样，释奴保护人的权利才不会在各方面都受到削减。〔本句担保关系的句法及其与附条件遗赠的对应关系待核。〕

<!-- source-p 416 -->
<a id="38.2.44.1"></a>**1**　释奴保护人被指定为继承人，并被遗赠一名奴隶以补足其应得份额；即使该奴隶在遗嘱书板尚未开启时死亡，释奴保护人也不得请求违遗嘱的遗产占有。

<!-- source-p 417 -->
<a id="38.2.44.2"></a>**2**　若被释奴依其死亡时所拥有的财产，在遗产或遗赠中给付释奴保护人应得份额；而奴隶在被释奴死亡后自敌境返回，使其财产增加，释奴保护人不得因此主张：若自己被指定为应得份额继承人，其所得本可更多。河流冲积使财产增加时，亦同；因为释奴保护人已从被释奴死亡时所拥有的财产中得到满足。若共同受遗赠人放弃继承，原留给被释奴的遗赠份额又归于被释奴，结论也相同。

<!-- source-p 425 -->
保罗《答复集》第十一卷。

<!-- source-p 426 -->
<a id="38.2.47.pr."></a>**序言**　保罗答复说：若孙子被剥夺继承权并非意在责难，而是基于其他考虑，则该剥夺不应妨碍其请求祖父被释奴的违遗嘱遗产占有。

<!-- source-p 427 -->
<a id="38.2.47.1"></a>**1**　有人询问：释奴保护人之女提提亚声称，其父提提乌斯在死前曾写信给她，补充说自己遭受其被释奴的恶行攻击；她遵从这些书信，在父亲死后起诉了被释奴。她能否以此作为理由，避免被排除？保罗答复说：依父亲意思起诉的人不应被排除于违遗嘱的遗产占有之外，因为她执行的不是自己的判断，而是他人的判断。

<!-- source-p 428 -->
<a id="38.2.47.2"></a>**2**　释奴保护人的儿子曾向被释奴发出如下书信：“塞姆普罗尼乌斯致其被释奴佐伊卢斯：问候。鉴于你的功绩，以及你一向对我所表现的忠诚，我准许你享有自由立遗嘱权。”有人询问，释奴保护人的儿子是否因此无须获得任何遗赠。保罗答复说，本案被释奴不应视为已经取得自由立遗嘱权。

<!-- source-p 429 -->
<a id="38.2.47.3"></a>**3**　保罗答复说：若祖父死亡后才受孕的孙子，在被释奴仍在世时出生，也可以请求祖父被释奴的违遗嘱遗产占有，并取得祖父的法定继承。尤利安的答复仅涉及请求祖父的法定继承，以及请求祖父遗产占有的问题。

<!-- source-p 430 -->
<a id="38.2.47.4"></a>**4**　保罗答复说：尽管军人父亲遗漏的儿子视为被剥夺继承权，但父亲的沉默不应对他们造成如此严重的后果，以致他们也被排除于祖父被释奴的财产之外。父系被释奴的财产也应作同样处理。

<!-- source-p 438 -->
特里丰尼努斯《论辩集》第十七卷。

<!-- source-p 439 -->
<a id="38.2.50.pr."></a>**序言**　释奴保护人被指定为低于其应得份额的继承人后，亲自接受继承，或命令被指定为继承人的奴隶接受继承并保留遗产，二者并无区别；无论哪种情形，他都会被排除于违遗嘱的遗产占有之外。

<!-- source-p 440 -->
<a id="38.2.50.1"></a>**1**　但若释奴保护人在命令奴隶接受被释奴的遗产之前，已将该奴隶出售或释放，使新获自由者或买受人成为继承人，则告示的文字并不禁止释奴保护人请求违遗嘱的遗产占有。

<!-- source-p 441 -->
<a id="38.2.50.2"></a>**2**　不过，若他企图欺骗告示，想在收取较高价款后，或通过秘密约定，同时取得遗嘱指定继承人依遗嘱取得利益及违遗嘱遗产占有，裁判官是否应拒绝向其提供占有诉权？更容易怀疑的是：虽由被指定为继承人的儿子（哪怕已解放出家父权）接受被释奴的遗产，实际取得利益的却是释奴保护人本人；因为我们总依自己的意愿，让所拥有的一切归于子女。

<!-- source-p 442 -->
<a id="38.2.50.3"></a>**3**　不过，若被释奴遗嘱书板仍封闭，释奴保护人尚不知道遗嘱意思，却对上述被指定或替补继承人中的某人实施了前述行为，则不应怀疑其存在欺诈；他可以依自己的权利请求违遗嘱的遗产占有。

<!-- source-p 443 -->
<a id="38.2.50.4"></a>**4**　若被释奴将释奴保护人指定为应得份额继承人，并请求其返还遗产；释奴保护人却称遗产负担过重，在被迫接受继承后，尽管原本可以保留遗产，却将其返还，则他不得请求违遗嘱的遗产占有；因为他既认可了被释奴的遗嘱意思，又轻视并仿佛否定了该遗产占有。

<!-- source-p 444 -->
<a id="38.2.50.5"></a>**5**　与此大不相同的是释奴保护人的儿子：被释奴将其收养，并在没有其他释奴保护人家族成员的情况下，将其指定为较小份额的继承人。尽管依严格法律，他作为家子是必然继承人；但若他并未以父亲继承人的身份介入遗产事务，而是放弃继承，则仍应以释奴保护人之子的身份准许其请求违遗嘱的遗产占有。

<!-- source-p 445 -->
<a id="38.2.50.6"></a>**6**　若被释奴免除了释奴保护人所欠的确定金额，而释奴保护人以此对抗请求债务给付的继承人，凭借恶意抗辩或债务免除（*acceptilatio*）而因遗赠免除债务，则应说他不得请求违遗嘱的遗产占有。
