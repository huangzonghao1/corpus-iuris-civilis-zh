# D.38.4 论将被释奴指定给子女（*De adsignandis libertis*）

<!-- source-p 455 -->
<a id="4"></a><a id="38.4"></a>**38.4.0 论将被释奴指定给子女**（*De adsignandis libertis*）。

<!-- source-p 456 -->
<a id="38.4.1"></a>**38.4.1**

<!-- source-p 457 -->
乌尔比安《萨宾评注》第十四卷。

<!-- source-p 458 -->
<a id="38.4.1.pr."></a>**序言**　克劳狄乌斯在位期间，韦勒乌斯·鲁福斯与奥斯托里乌斯·斯卡普拉任执政官时，元老院就指定被释奴作出了如下决议：“凡在合法婚姻中有两个或更多子女、且这些子女处于其权力之下的人，若曾就自己的某一被释奴或女被释奴声明，希望该被释奴或女被释奴归属于自己的哪一名子女，则无论该人是生前还是依遗嘱解放该被释奴或女被释奴，只要解放者日后永久脱离市民共同体，该名子女即为唯一的释奴保护人或女释奴保护人，犹如该被释奴或女被释奴是由该子女解放的一样。无论如何，若其子女中有人不再身处共同体且没有任何子女，则对解放该被释奴或女被释奴之人的其他子女，应保留一切权利，犹如其父母从未就该被释奴或女被释奴作过指定一样。”

<!-- source-p 459 -->
<a id="38.4.1.1"></a>**1**　元老院决议虽以单数措辞写成，但可以确定，既可将一名被释奴指定给数名子女，也可将数名被释奴或女被释奴指定给子女。

<!-- source-p 460 -->
<a id="38.4.1.2"></a>**2**　身在敌方的被释奴，也可以被指定。

<!-- source-p 461 -->
<a id="38.4.1.3"></a>**3**　指定可以用任何措辞作出，也可以用点头表示；既可以载于遗嘱或遗嘱附录，也可以在生前作出。

<!-- source-p 462 -->
<a id="38.4.1.4"></a>**4**　指定人也可以仅凭未以任何特定形式表达的意思，撤销该指定。

<!-- source-p 463 -->
<a id="38.4.1.5"></a>**5**　即使某人将被释奴指定给了一个被剥夺继承权的儿子，该指定仍然有效；就释奴保护人权利而言，剥夺继承权并不妨碍该儿子。

<!-- source-p 464 -->
<a id="38.4.1.6"></a>**6**　但若儿子是在指定之后才被剥夺继承权，剥夺继承权并非总会使指定失效；只有在作出剥夺时具有撤销指定的意思，才会如此。

<!-- source-p 465 -->
<a id="38.4.1.7"></a>**7**　若被指定之人拒绝接受，我认为——马尔切卢斯也有此说——可以准许其兄弟参加继承。

<!-- source-p 466 -->
<a id="38.4.1.8"></a>**8**　若一名释奴保护人有一个儿子，另一名有两个儿子，而被释奴被指定给后者的其中一个儿子，则应考察该被释奴的遗产应分为几份：是分为三份，使被指定之人取得两份，也就是自己的份额和兄弟的份额；还是均分，因为指定排除了另一人？尤利安在《学说汇纂》第七十五卷写道，更妥当的看法是，排除其兄弟的被指定之人取得三分之二。这一看法是正确的，只要其兄弟仍在世，或者本可被准许参加法定继承；但若其兄弟发生人格减等，则两人应取得相等份额。

<!-- source-p 467 -->
<a id="38.4.2"></a>**38.4.2**

<!-- source-p 468 -->
庞波尼《元老院决议》第四卷。

<!-- source-p 469 -->
若我指定之人死亡，留下儿子、兄弟以及另一释奴保护人的儿子，则该孙子应取得二分之一；如果我没有指定该被释奴，他将取得与我仍在世的儿子本应取得的份额相同的份额。

<!-- source-p 470 -->
<a id="38.4.3"></a>**38.4.3**

<!-- source-p 471 -->
乌尔比安《萨宾评注》第十四卷。

<!-- source-p 472 -->
<a id="38.4.3.pr."></a>**序言**　若某人有儿子和孙子，却将被释奴指定给孙子，也应作相同解释：该孙子应被准许参加法定继承，尽管他是另一名释奴保护人的儿子；这是因为其叔父尚在世才会发生这种情形。若没有该叔父，这项指定就不能使他减损另一名释奴保护人之子的权利。

<!-- source-p 473 -->
<a id="38.4.3.1"></a>**1**　可以确定，也能将被释奴指定给孙子；而且，被指定的孙子应优先于指定人自己的儿子。

<!-- source-p 474 -->
<a id="38.4.3.2"></a>**2**　由此还可以追问：若某人有一个儿子，并有该儿子所生的孙子，能否将他们视为自己权力下的两名子女，从而适用元老院决议？既然我们认可，也可以将被释奴指定给日后会重新回归其权力之下的人，为何不允许这种情形适用该决议？毕竟，我们不能否认这两人都处于其权力之下。

<!-- source-p 475 -->
<a id="38.4.3.3"></a>**3**　还可以讨论，处于其权力之下的这名孙子能否被准许参加法定继承。既然有许多情形允许处于权力之下的人拥有被释奴，为什么不也准许父亲通过他取得法定继承的利益？庞波尼对此也持正确意见。家子也可以拥有被释奴，例如有人解放了家子所有的军旅奴隶。

<!-- source-p 476 -->
<a id="38.4.3.4"></a>**4**　我认为，被释奴指定给某人的已解放儿子，也能享有元老院决议所赋予的利益；但这并不是说他们因此被准许参加法定继承，而是说，他们可以取得自己有权取得的其他利益。

<!-- source-p 477 -->
<a id="38.4.3.5"></a>**5**　依此而言，若被释奴无遗嘱死亡，由于这些人不能参加法定继承，就应当考察：仍留在家族中的指定人之子是否应获准参加继承？我认为，已解放的子女应由裁判官优先准许参加。

<!-- source-p 478 -->
<a id="38.4.3.6"></a>**6**　这里所说的被指定之人的子女，不仅包括儿子，也包括孙子、孙女以及其后的直系卑亲属。

<!-- source-p 479 -->
<a id="38.4.3.7"></a>**7**　若某人将被释奴指定给两名子女，其中一人永久脱离市民共同体且没有子女，另一人则仍然在世，

<!-- source-p 480 -->
<a id="38.4.4"></a>**38.4.4**

<!-- source-p 481 -->
庞波尼《元老院决议》第四卷。

<!-- source-p 482 -->
或者，其中一人尚在世时不愿使被释奴的遗产归于自己，

<!-- source-p 483 -->
<a id="38.4.5"></a>**38.4.5**

<!-- source-p 484 -->
乌尔比安《萨宾评注》第十四卷。

<!-- source-p 485 -->
<a id="38.4.5.pr."></a>**序言**　那么，该人离开共同体或拒绝接受后，其份额究竟应回归家族，还是应归并给指定关系仍然存续的另一人？尤利安在《学说汇纂》第七十五卷写道，指定仅对后一人发生效力，应当只准许该人参加继承；这是正确的。

<!-- source-p 486 -->
<a id="38.4.5.1"></a>**1**　若该人死亡时并非没有子女，是否应准许这些子女与仍在世的另一名被指定人一同参加继承？他认为，在该人仍在世时，仍只准许其本人参加；但该人死亡后，另一人的子女可以继承，而不应使被释奴重新归入家族。

<!-- source-p 487 -->
<a id="38.4.5.2"></a>**2**　但若这两人中一人留下儿子，另一人留下孙子，是否应准许他们一同参加法定继承？我认为，应在他们之间确定继承顺序。

<!-- source-p 488 -->
<a id="38.4.6"></a>**38.4.6**

<!-- source-p 489 -->
马尔基安《法学阶梯》第七卷。

<!-- source-p 490 -->
若某奴隶被命令于特定条件成就时获得自由，并遗赠给儿子，后来立遗嘱人在生前将其解放，则该被释奴归属于该儿子，犹如已被指定给他一样。无论遗嘱是否明文写明，或者能否确定立遗嘱人并非将他作为奴隶遗赠，而是作为被释奴指定给儿子，均作此处理。

<!-- source-p 491 -->
<a id="38.4.7"></a>**38.4.7**

<!-- source-p 492 -->
斯凯沃拉《规则集》第二卷。

<!-- source-p 493 -->
指定被释奴，既可以无条件作出，也可以附条件作出；可以通过书信、书面声明或手书文书作出。因为指定被释奴既不作为遗赠受领，也不作为遗嘱信托受领；因此，也不能以遗嘱信托为其附加负担。

<!-- source-p 494 -->
<a id="38.4.8"></a>**38.4.8**

<!-- source-p 495 -->
莫德斯蒂努《疑义集》第七卷。

<!-- source-p 496 -->
释奴保护人的子女虽在多数情形下也被视为享有释奴者的权利，但他们不能将父亲的被释奴指定给自己的子女，即使该被释奴是父亲指定给他们的。尤利安与马尔切卢斯均赞同此说。

<!-- source-p 497 -->
<a id="38.4.9"></a>**38.4.9**

<!-- source-p 498 -->
莫德斯蒂努《大全》第九卷。

<!-- source-p 499 -->
通常会有疑问：释奴保护人能否将被释奴指定给处于其权力之下的儿子，也能否指定给已解放的儿子，只要他还有至少另外两名子女处于其权力之下？较妥当的看法是可以。

<!-- source-p 500 -->
<a id="38.4.10"></a>**38.4.10**

<!-- source-p 501 -->
克莱门提乌《朱利亚—帕皮亚法评注》第十二卷。

<!-- source-p 502 -->
<a id="38.4.10.pr."></a>**序言**　若被释奴附条件或自某日起被指定给某人，在条件成就或该日到来之前，一切均应依照尚未作出指定的情形处理。因此，若被释奴在此期间死亡，其遗产及遗产占有应归属于所有子女。

<!-- source-p 503 -->
<a id="38.4.10.1"></a>**1**　若被释奴无条件指定给一人，却附条件指定给另一人，应当说，在条件尚未成就期间，只有被无条件指定之人享有释奴保护人权利。

<!-- source-p 504 -->
<a id="38.4.11"></a>**38.4.11**

<!-- source-p 505 -->
帕比尼安《答复集》第十四卷。

<!-- source-p 506 -->
关于生活给养而交由子女照管的被释奴，我答复说，这不应视为已将他们指定给子女。因为释奴保护人这样安排，是为了照料被释奴，使他们更容易实现其意愿所带来的利益；共同法上的权利仍予保留。

<!-- source-p 507 -->
<a id="38.4.12"></a>**38.4.12**

<!-- source-p 508 -->
庞波尼《书信集》第十二卷。

<!-- source-p 509 -->
若两名释奴保护人中的一人将被释奴指定给自己的儿子，并不妨碍另一名释奴保护人享有其完整权利。

<!-- source-p 510 -->
<a id="38.4.13"></a>**38.4.13**

<!-- source-p 511 -->
庞波尼《元老院决议》第四卷。

<!-- source-p 512 -->
<a id="38.4.13.pr."></a>**序言**　某人可以在遗嘱中既解放一名奴隶，又将该被释奴指定给某人。

<!-- source-p 513 -->
<a id="38.4.13.1"></a>**1**　元老院决议说的是处于权力之下的子女；因此，该决议没有规定遗腹子女的情形。不过，我认为遗腹子女也包括在内。

<!-- source-p 514 -->
<a id="38.4.13.2"></a>**2**　元老院决议所谓“其子女中有人不再身处共同体”，指永久脱离市民共同体之人，并不包括被敌人俘虏、但仍可能返回的人。

<!-- source-p 515 -->
<a id="38.4.13.3"></a>**3**　也可以指定自某个确定日期起发生效力；但指定有效至某一确定日期，通常难以成立，因为元老院决议本身已为此类事务设定了界限。
