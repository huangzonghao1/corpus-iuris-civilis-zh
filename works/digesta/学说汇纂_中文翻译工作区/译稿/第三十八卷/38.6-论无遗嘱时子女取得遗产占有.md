<a id="6"></a><a id="38.6"></a>**38.6.0 论无遗嘱书板时子女从何取得遗产**（*Si tabulae testamenti nullae extabunt, unde liberi*）。

<!-- source-p 592 -->
<a id="38.6.1"></a>**38.6.1**

<!-- source-p 593 -->
乌尔比安《告示评注》第四十四卷。

<!-- source-p 594 -->
<a id="38.6.1.pr."></a>**序言。**裁判官谈过已立遗嘱者的遗产占有后，便转而讨论无遗嘱者，并遵循《十二表法》所采用的顺序；因为通常应当先讨论立遗嘱者的继承，再讨论无遗嘱继承。

<!-- source-p 595 -->
<a id="38.6.1.1"></a>**1.**裁判官将无遗嘱继承分为数个部分，设立不同顺位：第一顺位为子女，第二顺位为法定继承人，第三顺位为血亲继承人，之后为丈夫与妻子。

<!-- source-p 596 -->
<a id="38.6.1.2"></a>**2.**只有在既未承认依遗嘱书板取得的遗产占有，也未承认违遗嘱的遗产占有时，才可依无遗嘱方式取得遗产占有。

<!-- source-p 597 -->
<a id="38.6.1.3"></a>**3.**显然，即使请求遗嘱继承遗产占有的期间已经开始，但遗产占有后来被放弃，也应当说此时开始准许依无遗嘱方式取得遗产占有。因为放弃遗产占有的人在放弃后不得再请求取得该遗产占有；因此，逻辑上应当允许自此请求无遗嘱遗产占有。

<!-- source-p 598 -->
<a id="38.6.1.4"></a>**4.**即使已经依卡尔波尼安告示授予遗产占有，也更应当认为仍可依无遗嘱方式请求遗产占有。正如我们在适当之处所说明的，依卡尔波尼安告示取得的遗产占有并不妨碍依告示规定的其他方式取得遗产占有。

<!-- source-p 599 -->
<a id="38.6.1.5"></a>**5.**裁判官以子女作为无遗嘱继承的起始顺位是正确的：正如裁判官将遗产首先依违遗嘱方式给予他们，也应在无遗嘱继承中召集他们。

<!-- source-p 600 -->
<a id="38.6.1.6"></a>**6.**这里的“子女”，应当理解为我们先前说过可获准取得违遗嘱遗产占有者，包括自然子女与收养子女。不过，收养子女仅在仍处于家父权之下时才被准许；如果已经取得自权人身份，则不获召集取得遗产占有，因为解放出家父权后，收养关系所生的权利即告消灭。

<!-- source-p 601 -->
<a id="38.6.1.7"></a>**7.**某人解放其子出家父权后，又将该子收养为孙子，并将他再次解放；当时此人另有一个由该子所生的孙子。马尔凯鲁斯曾就此询问：收养关系被解除，是否妨碍该孙子取得遗产占有？但是，既然孙子通常可以与已被解放出家父权的父亲共同取得遗产占有，谁会说，即使这个孙子曾被收养、仿佛成为该人的儿子，也仍会妨碍其亲生儿子呢？他在家父权下仅是收养子，而非自然子。

<!-- source-p 602 -->
<a id="38.6.1.8"></a>**8.**若遗嘱指定的继承人不愿接受继承——无论是因为遗嘱书板已被割裂、划销，还是立遗嘱人以其他方式改变意思并希望无遗嘱死亡——应当说，已取得遗产占有的人将依无遗嘱继承规则取得遗产。

<!-- source-p 603 -->
<a id="38.6.1.9"></a>**9.**如果已被解放出家父权的儿子遭遗嘱排除继承，而仍处于家父权下的人却被遗嘱遗漏，那么已解放的儿子请求以子女身份依无遗嘱方式取得遗产占有时，裁判官应当保护他，使其取得至多一半份额，犹如其父未留下任何遗嘱书板。

<!-- source-p 604 -->
<a id="38.6.2"></a>**38.6.2**

<!-- source-p 605 -->
尤利安《学说汇纂》第二十七卷。

<!-- source-p 606 -->
已被解放出家父权而遭遗嘱遗漏的儿子，若未请求违遗嘱遗产占有，且遗嘱指定继承人已经接受继承，那么他因自身过失丧失父亲的遗产。尽管他没有请求依遗嘱书板取得遗产占有，裁判官也不会保护他，使其得以子女身份请求无遗嘱遗产占有。被遗嘱遗漏的释奴保护人也是如此：若他不请求违遗嘱遗产占有，裁判官通常不会依据召集法定继承人的告示条款，使其得以对抗遗嘱指定继承人。

<!-- source-p 607 -->
<a id="38.6.3"></a>**38.6.3**

<!-- source-p 608 -->
乌尔比安《萨宾评注》第八卷。

<!-- source-p 609 -->
若能够确定不存在由七名证人加盖印记的遗嘱书板，即可依无遗嘱方式请求遗产占有。

<!-- source-p 610 -->
<a id="38.6.4"></a>**38.6.4**

<!-- source-p 611 -->
保罗《萨宾评注》第二卷。

<!-- source-p 612 -->
子女即使发生身份减等，也依裁判官告示获准取得其父母的遗产占有，收养子女除外；因为收养子女被解放出家父权后，也会丧失子女身份。但自然子女若先被解放出家父权，又被收养，并再次被解放，则仍享有自然子女的权利。

<!-- source-p 613 -->
<a id="38.6.5"></a>**38.6.5**

<!-- source-p 614 -->
庞波尼乌斯《萨宾评注》第四卷。

<!-- source-p 615 -->
<a id="38.6.5.pr."></a>**序言。**若裁判官承诺给予遗产占有的人之一，在被讨论其遗产的家父死亡时并未处于该家父权力之下，则应将本可由他取得的份额授予他及其当时处于同一家属共同体中的子女；条件是继承权依各自身份归属于他们，且他们未被遗嘱逐名排除。其份额按以下方式分配：若他仍处于家父权之下，本可取得该份额，则现由他取得其中一半，其余由其子女取得；并且只有这些子女须将自己的财产归并。

<!-- source-p 616 -->
<a id="38.6.5.1"></a>**1.**若父亲解放其子及由该子所生的孙子出家父权，则只有该子可取得遗产占有，尽管裁判官告示规定身份减等本身不构成障碍。事实上，即使从未处于家父权之下、也从未具有自权继承人地位的人，也会被召集取得其父母的遗产占有。例如，已被解放的儿子若将自己的儿子留在祖父权力之下，则留在该权力之下的人可取得其已解放父亲的遗产占有；若该父亲在解放后又生育子女，则该子女可取得祖父的遗产占有，其父亲的存在不构成障碍。

<!-- source-p 617 -->
<a id="38.6.5.2"></a>**2.**若已被解放的儿子未请求遗产占有，则孙辈的权利仍完整，仿佛该儿子并不存在。因此，该儿子在请求遗产占有后本可取得的份额，应由其子女单独取得，而不与其他人共同增益。

<!-- source-p 618 -->
<a id="38.6.6"></a>**38.6.6**

<!-- source-p 619 -->
乌尔比安《告示评注》第三十九卷。

<!-- source-p 620 -->
若父亲解放其子出家父权，却将孙子留在自己权力之下，随后该子死亡，那么无论依衡平理由还是依规定应向子女授予遗产占有的告示宗旨，都应考虑该已故之子，并准许依无遗嘱方式取得其父亲遗产的遗产占有。不过，祖父会因该孙子而取得这一遗产占有利益，因此应被迫将该孙子的财产归并给其姊妹；该姊妹已作为必然继承人取得其父亲的遗产。除非祖父根本不愿从孙子取得任何利益，并且准备解除孙子的家父权，使全部遗产占有利益归于已被解放的儿子。姊妹作为父亲的继承人，也不得正当地抱怨自己因此失去财产归并的利益，因为祖父日后无遗嘱死亡时，她仍可与其兄弟一同继承祖父的财产。

<!-- source-p 621 -->
<a id="38.6.7"></a>**38.6.7**

<!-- source-p 622 -->
帕比尼安《疑难集》第二十九卷。

<!-- source-p 623 -->
<a id="38.6.7.pr."></a>**序言。**遗嘱指定的继承人尚在考虑是否接受继承时，被遗嘱排除的儿子死亡；随后，遗嘱指定的继承人放弃了遗产。该儿子所生的孙子将成为祖父的自权继承人；其父亲不应被视为曾阻碍他，因为法定继承是在父亲死亡后才开始。也不能说，该孙子虽为继承人却不是自权继承人，理由是他从未处于最近的继承顺位；毕竟他本人也处于家父权之下，而且其父亲并未在本次继承中先于他取得继承地位。否则，若他不是自权继承人，他又依据何种法律成为继承人？他显然不是旁系血亲。再者，即使孙子未被遗嘱排除，在儿子死亡后，遗嘱指定的继承人仍可接受遗嘱继承。因此，既然儿子依无遗嘱继承规则并未构成障碍，就应认为他依遗嘱继承规则构成了障碍。

<!-- source-p 624 -->
<a id="38.6.7.1"></a>**1.**父母继承子女遗产，并不像子女继承父母遗产那样当然。父母之所以获准继承子女遗产，是基于怜悯；子女继承父母遗产则出于自然，也与父母共同的意愿相符。

<!-- source-p 625 -->
<a id="38.6.8"></a>**38.6.8**

<!-- source-p 626 -->
帕比尼安《答复集》第六卷。

<!-- source-p 627 -->
家子经父亲同意，以最近旁系血亲的身份接受遗产占有。尽管遗嘱所附条件规定：若他继续处于父亲权力之下，便不得继承遗产，他仍可有效接受该遗产占有，且不落入告示规定的范围；因为他并非依据遗嘱书板接受占有，从遗嘱书板不能取得遗产；该条件也不由儿子掌控，而且几乎不可能强迫父亲解放儿子出家父权。

<!-- source-p 628 -->
<a id="38.6.9"></a>**38.6.9**

<!-- source-p 629 -->
保罗《答复集》第十一卷。

<!-- source-p 630 -->
已被解放出家父权的儿子请求取得其父亲的遗产占有后，若其身份随后发生变化，不妨碍他保有已经取得的财产；但若他在请求遗产占有前已经改变身份，则不得请求取得遗产占有。
