<!-- source-p 698 -->
<a id="9"></a><a id="38.9"></a>**38.9.0 论继承顺位告示**（*De successorio edicto*）。

<!-- source-p 699 -->
<a id="38.9.1"></a>**38.9.1**

<!-- source-p 700 -->
乌尔比安《告示评注》第四十九卷。

<!-- source-p 701 -->
<a id="38.9.1.pr."></a>**序言。**设立继承顺位告示，是为了不让遗产长期处于无人承受的状态，也不让债权人遭受过长的拖延。因此，裁判官认为合乎公共利益，便为获准取得遗产占有的人规定期间，并使后顺位者可以依次承接。这样，债权人就能尽早知道应当向谁主张债权，还是遗产已作为无主财产归入国库，抑或应继续依遗产占有程序处理，仿佛死者没有继承人一样。

<!-- source-p 702 -->
<a id="38.9.1.1"></a>**1.**任何人都可以放弃自己的遗产占有，但不得放弃他人的遗产占有。

<!-- source-p 703 -->
<a id="38.9.1.2"></a>**2.**因此，未经我的意思表示，我的代理人不得放弃我的遗产占有。

<!-- source-p 704 -->
<a id="38.9.1.3"></a>**3.**若遗产占有是通过奴隶授予的，主人可以放弃该遗产占有。

<!-- source-p 705 -->
<a id="38.9.1.4"></a>**4.**我们来考察未适婚年龄者的监护人能否代其放弃遗产占有。较妥当的看法是监护人不能放弃；但未适婚年龄者可以在监护人同意下放弃。

<!-- source-p 706 -->
<a id="38.9.1.5"></a>**5.**精神失常者的保佐人绝不能放弃遗产占有，因为遗产占有尚未授予该精神失常者。

<!-- source-p 707 -->
<a id="38.9.1.6"></a>**6.**任何人一旦不愿请求遗产占有，便丧失该权利，即使其请求期间尚未届满也是如此。因为他既已表示不愿取得，遗产占有便开始归于他人，或转归国库。

<!-- source-p 708 -->
<a id="38.9.1.7"></a>**7.**我们来考察，经裁定授予的遗产占有是否可以放弃。其请求期间确实可以按日计算；但较正确的说法是，遗产占有尚未授予之前，不能放弃，只有在作出裁定后才算授予。反过来说，一旦已经裁定授予，放弃便太迟了，因为已经取得的权利不能再行放弃。

<!-- source-p 709 -->
<a id="38.9.1.8"></a>**8.**若前顺位之人在一百日期间届满前死亡，可以立即准许下一顺位者取得遗产占有。

<!-- source-p 710 -->
<a id="38.9.1.9"></a>**9.**我们所说“可以在一百日内请求遗产占有”，应理解为第100日当天也可以请求遗产占有；正如“在月朔期内”也包括月朔当天。说“在一百日之内”也是同样道理。

<!-- source-p 711 -->
<a id="38.9.1.10"></a>**10.**凡依告示可以取得遗产占有之人，若其中有人不愿遗产占有授予自己，或未在规定期间内接受，那么其他人便取得遗产占有，仿佛前一顺位之人从未存在一样。

<!-- source-p 712 -->
<a id="38.9.1.11"></a>**11.**但应当考察，被排除之人是否也能在其他顺位中获准参加。比如儿子仍处于家父权之下，最初依子女顺位获准遗产占有；但他因期间届满或放弃而被排除，遗产占有遂授予其他人。该儿子能否依继承顺位告示重新取得遗产占有，也就是由自己继承自己？较妥当的看法是应当准许他这样做，使他可以依据法定继承人顺位请求遗产占有，并在法定继承人之后，按照自己的顺位，依据最近血亲亲属顺位取得遗产占有。我们采用的规则是应准许他参加；因此，他可以依后续顺位继承自己。同样的说法也适用于依遗嘱书板取得的遗产占有：若本可依据遗嘱书板请求遗产占有、并可无遗嘱继承之人未提出该项请求，也可以依后续顺位由自己继承自己。

<!-- source-p 713 -->
<a id="38.9.1.12"></a>**12.**为尊重血亲关系，给予父母与子女较长的请求遗产占有期间；他们几乎是在取得自己的财产，因此不应受到过于紧迫的限制。故而，法律规定应给予他们一年期间，既不催促他们请求遗产占有，也不让遗产长期无人承受。当然，有时债权人催促时，应当在法庭上询问他们是否接受遗产占有，使债权人知道该如何处理；若他们表示仍在考虑，则不得催促他们作出决定。

<!-- source-p 714 -->
<a id="38.9.1.13"></a>**13.**若某人被父亲指定为尚未适婚年龄之子女的替补继承人，他请求遗产占有的期间不是一年，而是一百日。

<!-- source-p 715 -->
<a id="38.9.1.14"></a>**14.**父母与子女不只是在以自己的名义请求遗产占有时享有较长期限；即使其子女或父母中的一人所拥有的奴隶被指定为继承人，也适用一年期间。因为享有该项利益的身份人，才是应当提出请求的人。

<!-- source-p 716 -->
<a id="38.9.1.15"></a>**15.**此外，若父亲希望取得其已解放出家父权之子的违遗嘱遗产占有，应当确认他享有一年的请求期间。

<!-- source-p 717 -->
<a id="38.9.1.16"></a>**16.**尤利安概括指出，在一切情形下，父母与子女均有权在一年内请求遗产占有。

<!-- source-p 718 -->
<a id="38.9.2"></a>**38.9.2**

<!-- source-p 719 -->
帕比尼安《答复集》第六卷。

<!-- source-p 720 -->
较低亲等的血亲亲属没有继承顺位告示所规定的利益，因为较高顺位之人已经依其所属顺位取得遗产占有。即使该较高顺位亲属因年龄方面的救济而获准拒绝承受遗产，也不影响这一结论。因此，裁定将无人承受的财产归入国库是正确的。
