<a id="10"></a><a id="38.10"></a>**38.10.0　论亲等、姻亲及其称谓**（*De gradibus et adfinibus et nominibus eorum*）。

<!-- source-p 722 -->
<a id="38.10.1"></a>**38.10.1**

<!-- source-p 723 -->
盖尤斯《行省告示评注》第八卷。

<!-- source-p 724 -->
<a id="38.10.1.pr."></a>**序言**　亲属亲等分为上行直系、下行直系和横向旁系。上行直系包括父母，下行直系包括子女；横向或旁系包括兄弟姐妹及其子女。

<!-- source-p 725 -->
<a id="38.10.1.1"></a>**1.**上行和下行直系亲等均从第一亲等开始；横向或旁系亲等则没有第一亲等，因此从第二亲等开始。所以，在第一亲等中，上行直系和下行直系亲属可以同时出现，旁系亲属则绝无可能处于该亲等。但在第二、第三以及其后的亲等中，旁系亲属也可能与上行直系亲属同时出现。

<!-- source-p 726 -->
<a id="38.10.1.2"></a>**2.**但是，应当提醒：在处理继承或遗产占有问题时，亲等相同之人并非总会同时取得权利。

<!-- source-p 727 -->
<a id="38.10.1.3"></a>**3.**第一亲等：上行为父亲、母亲；下行为儿子、女儿。

<!-- source-p 728 -->
<a id="38.10.1.4"></a>**4.**第二亲等：上行为祖父、祖母；下行为孙子、孙女；旁系为兄弟、姐妹。

<!-- source-p 729 -->
<a id="38.10.1.5"></a>**5.**第三亲等：上行为曾祖父、曾祖母；下行为曾孙、曾孙女；旁系为兄弟姐妹的儿子、女儿，即侄子、侄女或外甥、外甥女；相应地，还有伯父、叔父、姑母、舅父、姨母。

<!-- source-p 730 -->
<a id="38.10.1.6"></a>**6.**第四亲等：上行为高祖父、 高祖母；下行为玄孙、玄孙女；旁系为兄弟姐妹的孙子、孙女。相应地，有伯祖父、叔祖父、姑祖母（即祖父的兄弟姐妹），舅祖父、姨祖母（即祖母的兄弟姐妹）；还有堂兄弟、堂姐妹（即由两名兄弟所生之人），姨表兄弟、姨表姐妹（即由两名姐妹所生之人，仿佛称为“共同姐妹所生者”），以及姑表兄弟、姑表姐妹（即由兄弟与姐妹所生之人）。但通常人们以“表兄弟姐妹”这一通称称呼上述所有人。

<!-- source-p 731 -->
<a id="38.10.1.7"></a>**7.**第五亲等：上行为五世祖父、五世祖母；下行为来孙、来孙女。旁系为兄弟姐妹的曾孙、曾孙女。相应地，有高祖父的兄弟姐妹（即高祖父的兄弟、姐妹；高祖母的兄弟、姐妹），以及兄弟姐妹的堂兄弟姐妹、表兄弟姐妹、姑表兄弟姐妹之子女；还有比表亲更近一等的亲属，即伯祖父、叔祖父、姑祖母、舅祖父或姨祖母的儿子、女儿：

<!-- source-p 732 -->
<a id="38.10.2"></a>**38.10.2**

<!-- source-p 733 -->
乌尔比安《告示评注》第四十六卷。

<!-- source-p 734 -->
上文所称的，是被考察亲属之父亲的表兄弟姐妹，亦即其父系堂兄弟姐妹。

<!-- source-p 735 -->
<a id="38.10.3"></a>**38.10.3**

<!-- source-p 736 -->
盖尤斯《行省告示评注》第八卷。

<!-- source-p 737 -->
<a id="38.10.3.pr."></a>**序言**　横向亲等的第六亲等包括：上行为六世祖父、六世祖母；下行为再来孙、再来孙女。旁系为兄弟姐妹的玄孙、玄孙女。相应地，有曾祖父的兄弟姐妹（即高祖父的兄弟姐妹）、高祖母的兄弟姐妹；伯祖父、叔祖父、舅祖父、姨祖母的孙子、孙女；堂兄弟姐妹、表兄弟姐妹、姑表兄弟姐妹的孙子、孙女；以及高祖父兄弟姐妹的儿子、女儿。由堂兄弟姐妹、表兄弟姐妹或姑表兄弟姐妹各支系所生之人，也属于此列；这些人严格说来称为远亲表亲（*sobrini*）。

<!-- source-p 738 -->
<a id="38.10.3.1"></a>**1.**由上文所述各类人员，可以充分看出第七亲等可能包括多少人。

<!-- source-p 739 -->
<a id="38.10.3.2"></a>**2.**还须提醒：父母和子女两类人员的数量始终按两倍计算。祖父、祖母既包括父系，也包括母系；孙子、孙女也既包括儿子所生者，也包括女儿所生者。此后各亲等的上行和下行亲属，均依此方法计算。

<!-- source-p 740 -->
<a id="38.10.4"></a>**38.10.4**

<!-- source-p 741 -->
莫德斯蒂努斯《学说汇纂》第十二卷。

<!-- source-p 742 -->
<a id="38.10.4.pr."></a>**序言**　就我们的法律而言，若讨论自然亲属关系，一个人通常不会超出第七亲等；因为自然状况几乎不允许亲属关系延续到更远的亲等。

<!-- source-p 743 -->
<a id="38.10.4.1"></a>**1.**人们认为，亲属（*cognati*）之所以得名，是因为他们仿佛共同出生，或由同一人产生并繁衍而来。

<!-- source-p 744 -->
<a id="38.10.4.2"></a>**2.**罗马人所说的亲属关系分为两类：有些依据市民法成立，有些依据自然关系成立；有时两者并存，亲属关系便同时由自然法和市民法联结。自然亲属关系可以单独存在而不伴随市民法上的亲属关系，它通过女性一系传递，通常也包括由女性所生的子女。市民法上的亲属关系本身也称为合法亲属关系，可以通过收养而单独成立，并不以自然血缘关系为前提。通过合法婚姻联结的亲属关系，则同时依据两者成立。自然关系本身称为亲属关系（*cognatio*）；市民法上的关系虽然也充分称为亲属关系，但严格说来称为宗亲关系（*adgnatio*），也就是经由男性一系成立的关系。

<!-- source-p 745 -->
<a id="38.10.4.3"></a>**3.**由于某些法律关系也涉及姻亲，在此简要讨论姻亲并非不合适。姻亲是丈夫和妻子的亲属。之所以如此称呼，是因为原本彼此不同的两支亲属关系经由婚姻联结，使一支亲属关系与另一支的边缘相接；婚姻正是姻亲关系得以结合的原因。

<!-- source-p 746 -->
<a id="38.10.4.4"></a>**4.**这些姻亲称谓如下：*socer*（岳父／公公）、*socrus*（岳母／婆婆）、*gener*（女婿）、*nurus*（儿媳）、*noverca*（继母）、*vitricus*（继父）、*privignus*（继子）和 *privigna*（继女）。

<!-- source-p 747 -->
<a id="38.10.4.5"></a>**5.**姻亲关系没有亲等。

<!-- source-p 748 -->
<a id="38.10.4.6"></a>**6.**丈夫的父亲以及妻子的父亲都称为 *socer*，其母亲称为 *socrus*。希腊人分别称丈夫的父亲为 *hekuros*、母亲为 *hekura*，妻子的父亲为 *penveros*、母亲为 *penvera*。儿子的妻子称为 *nurus*，女儿的丈夫称为 *gener*。妻子对丈夫与另一妻子所生的子女而言称为 *noverca*；母亲后来与另一男子所生子女的继父称为 *vitricus*。双方各自与他人所生的子女，互称 *privigni*、*privignae*，即继子女。也可以这样界定：妻子的父亲是我的 *socer*，我是他的 *gener*；妻子的祖父称为我的 *socer magnus*，我是他的 *progener*。反过来，我的父亲是妻子的 *socer*，妻子是他的 *nurus*；我的祖父是妻子的 *socer magnus*，妻子是他的 *pronurus*。妻子的祖母是我的 *prosocrus*，我是她的 *progener*；反过来，我的母亲是妻子的 *socrus*，妻子是她的 *nurus*；我的祖母是妻子的 *socrus magna*，妻子是她的 *pronurus*。妻子与另一男子所生的儿子是我的 *privignus*，我是他的 *vitricus*；反过来，我与另一妻子所生的子女称我妻子为 *noverca*，这些子女则是她的 *privigni*。丈夫的兄弟称为 *levir*，希腊语称 *dayr*；荷马诗中也有记载，海伦对赫克托耳这样说：*daer emeio kunos kakomyxanou okruoessys*〔底本拉丁释义：*levir meus canis noxae et horrendae*，意为“我的丈夫之兄，像恶毒可怖的狗”〕。丈夫的姐妹称为 *glos*，希腊语称 *galws*。两兄弟的妻子互称 *ianitrices*，希腊语称 *einateres*。荷马在一行诗中也表达了同一意思：*ye tines galown y einaterwn eupeplwn*〔底本拉丁释义：*an aliquo ad domus glorum ianitricumque stolarum*；该释义的句法和所指不详〕。

<!-- source-p 749 -->
<a id="38.10.4.7"></a>**7.**由于上述姻亲彼此被视为父母或子女，法律禁止他们相互结婚。

<!-- source-p 750 -->
<a id="38.10.4.8"></a>**8.**应知，若没有不受禁止的婚姻，便既不能成立亲属关系，也不能成立姻亲关系；姻亲关系正是由此类婚姻联结而成。

<!-- source-p 751 -->
<a id="38.10.4.9"></a>**9.**自由释奴之间也可以成立姻亲关系。

<!-- source-p 752 -->
<a id="38.10.4.10"></a>**10.**被交付收养或被解放出家父权的人，保留此前具有的各种亲属和姻亲关系，但丧失宗亲关系的权利。不过，在其因收养进入的家族中，除养父以及与其成立宗亲关系的人外，无人是他的亲属；在该家族中，也完全没有人是他的姻亲。

<!-- source-p 753 -->
<a id="38.10.4.11"></a>**11.**被剥夺水火权，或以其他方式遭受身份减等，以致丧失自由和公民身份的人，会丧失其此前拥有的一切亲属和姻亲关系。

<a id="38.10.10"></a>**38.10.10**

<!-- source-p 771 -->
保罗《论亲等、姻亲及其称谓》单卷。

<!-- source-p 772 -->
<a id="38.10.10.pr."></a>**序言**　法学家必须了解亲属亲等和姻亲关系，因为依法律，继承和监护通常归于最近的宗亲；裁判官也依告示将遗产占有给予最近的亲属。此外，依公审法，我们不得被迫对姻亲或亲属作证。

<!-- source-p 773 -->
<a id="38.10.10.1"></a>**1.**“亲属”（*cognati*）一词似乎源自希腊语；希腊人称我们所说的亲属为 *suggeneis*。

<!-- source-p 774 -->
<a id="38.10.10.2"></a>**2.**《十二表法》称为宗亲的人，也属于亲属；但这里的宗亲是经由父亲、来自同一家庭的人。经由女性联结的人，则只称为亲属。

<!-- source-p 775 -->
<a id="38.10.10.3"></a>**3.**宗亲中最近的那些人称为自权继承人（*sui*）。

<!-- source-p 776 -->
<a id="38.10.10.4"></a>**4.**宗亲与亲属之间的关系，如同属与种：宗亲必定也是亲属，但亲属未必是宗亲。前者是市民法上的称谓，后者是自然法上的称谓。

<!-- source-p 777 -->
<a id="38.10.10.5"></a>**5.**我们也将“亲属”这些称谓用于奴隶；因此，也称奴隶的父母、子女和兄弟姐妹。但奴隶之间的亲属关系不属于法律所调整的亲属关系。

<!-- source-p 778 -->
<a id="38.10.10.6"></a>**6.**亲属关系也可以仅经由女性一系产生。只与同一母亲所生的人也是兄弟；若他们有同一父亲、但母亲不同，也属于宗亲。

<!-- source-p 779 -->
<a id="38.10.10.7"></a>**7.**罗马人对上行尊亲属的称谓，至六世祖父（*tritavus*）为止均有专名；再往上没有专名的，统称为远祖（*maiores*）。下行卑亲属则至再来孙（*trinepos*）为止有专名；再往后者称为更远后代（*posteriores*）。

<!-- source-p 780 -->
<a id="38.10.10.8"></a>**8.**亲属也可以是旁系，例如兄弟姐妹及其后代，以及伯叔父、姑母、舅父和姨母。

<!-- source-p 781 -->
<a id="38.10.10.9"></a>**9.**每当需要确定某人属于第几亲等时，应从被考察其亲属关系的人开始。若该人属于上行或下行直系，沿着向上或向下的直系容易确定亲等，只须逐级计算紧邻的亲属：与我第一亲等亲属处于第一亲等者，对我而言就是第二亲等；此后每增加一代，亲等数也相应增加。旁系亲等也用同一方法计算。因此，兄弟属于第二亲等，因为联结双方的父亲或母亲先计为第一亲等。

<!-- source-p 782 -->
<a id="38.10.10.10"></a>**10.**“亲等”一词源自阶梯或倾斜地势的相似性；我们沿着阶梯从一级走到相邻一级，也就是从最近者走向仿佛由其所生者。

<!-- source-p 783 -->
<a id="38.10.10.11"></a>**11.**现在逐一计算各亲等。

<!-- source-p 784 -->
<a id="38.10.10.12"></a>**12.**亲属第一亲等：上行有父亲、母亲两人；下行有儿子、女儿两人，但实际人数可以更多。

<!-- source-p 785 -->
<a id="38.10.10.13"></a>**13.**第二亲等包括以下十二人：祖父，即父亲和母亲的父亲；祖母同样既包括父系祖母，也包括母系祖母。兄弟也有数种情形：可以只同母、只同父，或父母相同。父母相同者并不因此增加总人数，因为他们与只同父者在这里的计算没有差别；不同之处仅在于，父母相同的兄弟同时拥有父系和母系亲属。因此，父母不同的人之间可能出现这种情形：某人是我兄弟的兄弟，却不是我的亲属。假设我有一名只与我同父的兄弟，而他另有一名只与他同母的兄弟；后两人彼此是兄弟，但其中一人不是我的亲属。姐妹也与兄弟同样计算。孙子也按两种情形计算：由儿子或女儿所生；孙女亦同。

<!-- source-p 786 -->
<a id="38.10.10.14"></a>**14.**第三亲等包括三十二人。曾祖父（*proavus*）按四种关系计算：可以是父系祖父或母系祖父的父亲，也可以是父系祖母或母系祖母的父亲。曾祖母（*proavia*）也包括四人：可以是父系祖父、父系祖母、母系祖父或母系祖母的母亲。伯父或叔父（*patruus*）是父亲的兄弟，也应按两种关系计算，即同父或同母的兄弟。我的父系祖母若嫁给你父亲并生下你，或者你的父系祖母若嫁给我父亲并生下我，我便是你的伯父或叔父，你也同样是我的伯父或叔父。若两名女子分别嫁给对方的儿子，也会出现这种关系：她们所生的男孩互为伯父或叔父，女孩互为姑母；男孩对于女孩也互为伯父或叔父，女孩对于男孩也互为姑母。若一名男子娶了另一名女子的女儿，而该女子又嫁给此男子的儿子，则男子一方所生子女与女子一方所生子女之间，也会形成兄弟之子女称对方为伯叔父母、伯叔父母称对方为侄甥的关系。舅父（*avunculus*）是母亲的兄弟；前述关于伯叔父的关系，在此也同样适用。若两名男子分别娶了对方的女儿，则他们所生的男孩互为舅父，女孩互为姨母；男孩对于女孩也互为舅父，女孩对于男孩也互为姨母。姑母（*amita*）是父亲的姐妹，关系如上所述。姨母（*matertera*）是母亲的姐妹，计算方式也相同。须注意，父母的兄弟姐妹分别有伯叔父、姑母、舅父、姨母等专名；但兄弟姐妹的子女没有专门的亲属称谓，而是通过“兄弟姐妹的子女”来表明，这一点从下文还会看出。曾孙和曾孙女也按四种关系计算：可以由儿子的儿子、女儿的儿子、儿子的女儿或女儿的女儿所生。

**18.**第七亲等包括以下一千零二十四人。六世祖父、六世祖母的父亲和母亲包括一百二十八人：六世祖父的父亲与其本人数量相同，母亲亦然，合计六十四人；六世祖母的父亲和母亲也同样合计六十四人。五世祖父、五世祖母的兄弟姐妹，是六世祖父的儿子、女儿，也就是高祖父或高祖母的伯叔父、舅父、姑母、姨母；曾祖父或曾祖母的 *patruus magnus*、*avunculus magnus*、*amita magna*、*matertera magna*；祖父或祖母的 *propatruus*、*proavunculus*、*proamita*、*promatertera*；以及父亲或母亲的 *abpatruus*、*abavunculus*、*abamita*、*abmatertera*。六世祖父的兄弟包括三十二人：五世祖父所包括的十六人之外，因兄弟有两种亲缘关系，还要再加十六人；其兄弟须分别从父系和母系计算，各十六人。六世祖父的姐妹同样三十二人，合计六十四人；六世祖母的兄弟、姐妹也各按同样方式计算，合计亦六十四人。*patruus maximus* 的儿子或女儿，是六世祖父经由儿子所生的孙子、孙女，也是高祖父的兄弟之子或女儿。*amita maxima* 的儿子或女儿，是六世祖父经由女儿所生的孙子、孙女，也是高祖父的姐妹之子或女儿。*avunculus maximus* 的儿子或女儿，是六世祖母经由儿子所生的孙子、孙女，也是高祖母的兄弟之子或女儿。*matertera maxima* 的儿子或女儿，是六世祖母经由女儿所生的孙子、孙女，也是高祖母的姐妹之子或女儿。从 *patruus maximus* 的儿子开始列举的这些人，对被考察亲属关系之人的曾祖父、曾祖母而言，都是表兄弟姐妹；对其祖父、祖母而言，则是较近一等的远亲表亲。每一种称谓各包括十六人：既然 *patruus maximus* 包括十六人，其儿子和女儿也各按同样方式、各包括十六人。以上从 *patruus maximus* 的儿子开始列举的八类亲属，合计一百二十八人。*patruus maior* 的孙子包括十六人，因为他们是高祖父或高祖母的曾孙；高祖父按八种关系计算，其孙子按两种关系计算，便得上述人数。*patruus maior* 的孙女亦然。*avunculus maior* 的孙子、孙女合计三十二人；*amita maior* 的孙子、孙女亦按同样方法计算；*matertera maior* 的孙子、孙女也同样。上述各类相加，共一百二十八人。对于这些人，被考察亲属关系之人的祖父或祖母是较近一等的远亲表亲，其父亲或母亲是远亲表亲；被考察者本人则是由远亲表亲所生。特雷巴提乌斯说，他应以其父母的“近称亲属”称谓来界定；他解释该称谓的理由是，亲属关系的最后各等均由远亲表亲组成，因此“远亲表亲之子”可以恰当地称作“近称亲属”。由他本人来看，这些人的子女也称为“近称亲属之子”；所以，远亲表亲所生者彼此以“近称”相称，因为他们没有其他专名可用来互称。*patruus magnus*、*avunculus magnus*、*amita magna*、*matertera magna* 的曾孙、曾孙女合计一百二十八人；每一称谓各包括十六人。举例来说，*patruus magnus* 按四种关系理解，而其每一关系下的曾孙、曾孙女再按四种关系计算，合计三十二人；四类称谓各得三十二人，合计即为前述总数。上述亲属的父亲、母亲是被考察者的远亲表亲；被考察者本人则是由这些远亲表亲所生。*patruus*、*avunculus*、*amita*、*matertera* 的再来孙、再来孙女各包括十六人。以 *patruus* 的再来孙为例：*patruus* 按两种关系计算，曾孙按四种关系计算，曾孙女也按四种关系计算，继而计算他们的子女，合为十六人；其女系后代同理，其余称谓亦同。所有这些类别合计一百二十八人。他们是被考察者表兄弟姐妹的孙子、孙女；他们本人则是被考察者的 *patruus maximus*、*avunculus maximus*、*amita maxima*、*matertera maxima* 的儿子、女儿，也是其曾祖父、曾祖母的表兄弟姐妹。兄弟姐妹的再来孙、再来孙女包括一百二十八人。更高一代的 *trinepos* 的儿子、女儿以及 *trineptis* 的儿子、女儿也合计一百二十八人：如前所述，*trinepos* 和 *trineptis* 共包括六十四人；其儿子、女儿各依同一计算方法，人数相同。
