# D.38.15 论遗产占有的顺序（*Quis ordo in possessionibus servetur*）

<!-- source-p 820 -->
<a id="15"></a><a id="38.15"></a>**38.15.0 论遗产占有的顺序**（*Quis ordo in possessionibus servetur*）。

<!-- source-p 821 -->
<a id="38.15.1"></a>**38.15.1**

<!-- source-p 822 -->
莫德斯汀《潘德克顿》第六卷。

<!-- source-p 823 -->
<a id="38.15.1.pr."></a>**序言**　无遗嘱继承的顺位如下：第一顺位为自权继承人（*sui heredes*），第二顺位为法定继承人（*legitimi*），第三顺位为最近的旁系亲属（*proximi cognati*），之后为夫与妻（*vir et uxor*）。

<!-- source-p 824 -->
<a id="38.15.1.1"></a>**1**　无论遗嘱书板不存在，还是虽有遗嘱书板却无人依遗嘱或违遗嘱取得遗产占有，均应授予无遗嘱遗产占有。

<!-- source-p 825 -->
<a id="38.15.1.2"></a>**2**　父亲无遗嘱死亡时，遗产占有授予其子女；不仅授予直到父亲死亡时仍处于其权力之下的子女，也授予已解放出家父权的子女。

<!-- source-p 826 -->
<a id="38.15.2"></a>**38.15.2**

<!-- source-p 827 -->
乌尔比安《告示评注》第四十九卷。

<!-- source-p 828 -->
<a id="38.15.2.pr."></a>**序言**　请求遗产占有的期间是有效期间（*tempus utile*）；所谓有效期间，是指其中每一天都须为有效日（*dies utilis*），也就是说，每一天当事人都知道且能够请求遗产占有。反之，若某日当事人不知情或不能请求遗产占有，毫无疑问，该日不计入其期间。某人可能起初知道并能够请求遗产占有，后来却变得不知情或不能请求；例如，起初他得知死者无遗嘱死亡，后来听到更可靠的消息，因而开始怀疑死者是否立过遗嘱或是否仍在世，因为之后有这样的传言流传。反过来，起初不知情的人，后来也可能开始知情。

<!-- source-p 829 -->
<a id="38.15.2.1"></a>**1**　显然，遗产占有的期间按有效日计算；但若遗产占有可以直接申请，则不按裁判官开庭的次数计算。若遗产占有需要在裁判庭审理案情，或需要裁判官作出裁定，则应计算裁判官开庭的日子，以及裁判官本可授予遗产占有却并非因其自身原因未能授予的日子。

<!-- source-p 830 -->
<a id="38.15.2.2"></a>**2**　对于须经裁判庭授予的遗产占有，有人问：若裁判官确实在裁判庭开庭，却没有受理请求，遗产占有的期间是否仍继续计算？可以说，期间不应届满；因为长官可能正忙于其他事务，例如军务、看守或审理案件。

<!-- source-p 831 -->
<a id="38.15.2.3"></a>**3**　若行省总督在邻近城市，则应将路程所需时间计入有效期间，按二万步（*viginti milia passuum*）计算；我们不应等待行省总督亲自来到请求遗产占有的人所在之处。

<!-- source-p 832 -->
<a id="38.15.2.4"></a>**4**　若孕妇已被准许以胎儿名义占有遗产，则对后顺位请求人而言，遗产占有期间不开始计算，这一点毫无疑问；不仅在一百日以内如此，只要胎儿仍可能出生，就一直如此。即使胎儿已经出生，也应知道遗产占有须先授予该子女。

<!-- source-p 833 -->
<a id="38.15.2.5"></a>**5**　庞波尼乌斯说，应以当事人所能达到的实际知情程度为准，而非以法学家所能达到的知识为准；也就是说，应以其本人或通过他人所能获知的情况为准，例如咨询较有学识的人。谨慎的家父应当进行这样的咨询。

<!-- source-p 834 -->
<a id="38.15.3"></a>**38.15.3**

<!-- source-p 835 -->
保罗《告示评注》第四十四卷。

<!-- source-p 836 -->
父亲知悉遗产占有期间的开始，不得对不知情的儿子造成不利。

<!-- source-p 837 -->
<a id="38.15.4"></a>**38.15.4**

<!-- source-p 838 -->
尤利安《学说汇纂》第二十八卷。

<!-- source-p 839 -->
<a id="38.15.4.pr."></a>**序言**　若你被指定为共同继承人的替补继承人，并取得了遗产占有；之后你的共同继承人决定不再请求遗产占有，则应认为全部遗产占有都授予了你。你的共同继承人此后不得再请求遗产占有。

<!-- source-p 840 -->
<a id="38.15.4.1"></a>**1**　儿子无论以儿子身份、还是以家族旁系亲属或血亲身份被列入遗产占有顺位，都享有一年期间。父亲若曾释放儿子出家父权，即使其以解放者身份取得遗产占有，也同样享有一年期间。

<!-- source-p 841 -->
<a id="38.15.5"></a>**38.15.5**

<!-- source-p 842 -->
马尔切卢斯《学说汇纂》第九卷。

<!-- source-p 843 -->
<a id="38.15.5.pr."></a>**序言**　若遗产占有授予家子，则在他无法通知父亲、使父亲得以命令其接受遗产占有或认可其接受行为的那些日子里，期间不开始计算。假设他在遗产占有授予后的第一天就接受了，但无法通知父亲使其认可，那么一百日的期间并不开始计算；只有从他能够通知父亲之时起，期间才开始计算。一百日届满后，父亲再作认可便徒劳无益。

<!-- source-p 844 -->
<a id="38.15.5.1"></a>**1**　可以问：若儿子本可请求遗产占有，但父亲外出且无法通知，或父亲精神错乱，而儿子却疏于请求，之后是否不得再请求？然而，未请求遗产占有为何会对他不利呢？即使他已经请求，在父亲认可之前，他仍不会取得遗产占有。

<!-- source-p 845 -->
<a id="38.15.5.2"></a>**2**　若他人的奴隶被指定为继承人，之后该奴隶被出售，问题是，请求遗产占有的期间是否应计入后来所有人的期间。意见认为，应将原所有人所剩的期间计入后来所有人的期间。
