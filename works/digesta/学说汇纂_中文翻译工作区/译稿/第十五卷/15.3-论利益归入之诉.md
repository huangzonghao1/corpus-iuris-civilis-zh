## 15.3.0　论利益归入之诉（*De in rem verso*）

### <a id="15.3.1"></a>15.3.1　乌尔比安《评告示》第二十九卷

<a id="15.3.1.pr."></a>

**序言（pr.）** 如果处于他人权力之下的人没有特有产，或者虽有特有产却不足以清偿全部债务，只要其所取得之物已转用于权力支配者的事务，支配他们的人就不在全部债务范围内承担责任；因为在这种情况下，应视为交易实际上是与支配者本人订立的。

<a id="15.3.1.1"></a>

**1.** 利益归入之诉并非徒然规定，仿佛特有产之诉已经足够。拉贝奥的说法完全正确：利益确已转入，却仍可能不能提起特有产之诉。比如，主人并无恶意地收回了特有产；或者，奴隶死亡使特有产消灭，而特有产之诉的一年可用期间也已届满。因为利益归入之诉是永久性的；无论主人是否无恶意地收回了特有产，或特有产之诉是否因一年期间届满而终结，均可提起。

<a id="15.3.1.2"></a>

**2.** 同样，如果有数人提起特有产之诉，应使其对利益归入之诉原告有利：只要其款项转用于主人事务，他就应享有更充分的诉权。当然，如果已有他人先行起诉并提起特有产之诉，利益归入之诉是否因此消灭，尚须考察。庞波尼乌斯记载，尤利安认为，特有产之诉会使利益归入之诉消灭，因为原本转用于主人事务并代奴隶支付的款项，已经转入特有产；这就如同主人直接向奴隶支付了一样。但仅当主人依特有产之诉，已经就奴隶转用于其事务的款项作出给付时，才是如此；否则，利益归入之诉仍然存在。

### <a id="15.3.2"></a>15.3.2　雅沃勒努《卡西乌斯著作》第十二卷

一个人收取钱款后便释放了奴隶，不能对其提起利益归入之诉，因为他仅因给予自由，并未因这些钱款而增加财产。

### <a id="15.3.3"></a>15.3.3　乌尔比安《评告示》第二十九卷

<a id="15.3.3.pr."></a>

**序言（pr.）** 如果奴隶把我借给他的款项交给主人，以换取释放，那么该款项虽不计入特有产，但若奴隶所交付之物的价值超过其身价，就应视为利益已转入主人事务。

<a id="15.3.3.1"></a>

**1.** 下列情形均应视为利益归入：奴隶将自己取得的同一财物转用于主人事务，例如取得小麦后，将小麦本身作为食物供主人家属食用；或者奴隶将从债权人处借得的钱款用于偿还主人的债权人。即使奴隶清偿时发生错误，把并非债权人的人误认为债权人，庞波尼乌斯在《评告示》第六十一卷中也说，仍应视为利益已转入；但仅以主人能够请求返还非债清偿之款项的范围为限。又如，奴隶为管理或处理主人的事务而行事，例如借钱购买谷物供主人家属食用，或购买衣物供其穿用；或者奴隶最初为自己的特有产借款，后来又将款项转用于主人事务。我们采用的法律规则是：即使奴隶先将钱款转入特有产，之后才转用于主人事务，仍可提起利益归入之诉。

<a id="15.3.3.2"></a>

**2.** 一般而言，凡代理人可以提起委任之诉，或事务管理人可以提起无因管理之诉的情形，均可提起利益归入之诉；也就是奴隶消耗某物，使主人的财产状况有所改善或至少没有变差的情形。

<a id="15.3.3.3"></a>

**3.** 因此，如果奴隶借款供自己依主人通常的做法维持生活和购置衣物，也就是不超过主人惯常供给他的数额，拉贝奥写道，应视为利益已转入主人事务。同一规则也适用于家子。

<a id="15.3.3.4"></a>

**4.** 但是，如果奴隶借款装饰主人的住宅，例如做灰泥装饰及添置其他物品，而这些主要是为了享受而非实用，就不应视为利益归入；因为除非主人曾作出委任或表示意愿，代理人也不会将这些费用计入账目。主人也不应因其自己本不会做的事情而承受债务。那么应如何处理？主人应容许债权人取走这些物品，但不得损坏房屋；这样也可避免迫使主人出售房屋，仅为支付因装饰而增加的价值。

<a id="15.3.3.5"></a>

**5.** 拉贝奥还说，如果奴隶向我借款后又把钱借给他人，主人应因其取得了该项债权而依利益归入之诉承担责任。庞波尼乌斯仅在奴隶并未将该债权作为特有产债权，而是仿佛作为主人的账项取得时，才赞同这一意见。主人承担责任的范围仅到此为止：如果主人认为保有对债务人的债权对自己并无益处，就应将该债权让与债权人，并指定债权人为代理人。

<a id="15.3.3.6"></a>

**6.** 拉贝奥还认为，奴隶借款后，在主人同意下为其购置香水等奢侈享用之物，或供给其他享乐用品、甚至不正当开支，也属于利益归入主人事务。因为我们考察的并不是所消费之物是否给主人带来善益，而是该消费是否用于主人的事务。

<a id="15.3.3.7"></a>

**7.** 因此，奴隶为供养主人家属而购买谷物，并将其存入主人的谷仓，即使谷物后来灭失、变质或被焚毁，也应正确地认为利益已经转入。

<a id="15.3.3.8"></a>

**8.** 同样，如果奴隶为主人买下一名必需的奴隶，而该奴隶后来死亡；或者奴隶加固了一栋出租公寓楼，而楼宇后来倒塌，我认为都可提起利益归入之诉。

<a id="15.3.3.9"></a>

**9.** 但是，如果奴隶声称借款是要转用于主人事务，实际上却没有这样做，并因此欺骗了债权人，就不应视为利益归入，主人也不承担责任；否则，债权人的轻信会损害主人，奴隶的狡诈也会使主人受累。不过，如果该奴隶一向会把所借款项转用于主人事务，又该如何？即便如此，如果奴隶借款时另有打算，或虽以该目的借款、后来却改作他用，我仍认为不能使主人受损。因此，债权人应当谨慎查明款项将转用于何处。

<a id="15.3.3.10"></a>

**10.** 如果奴隶借款购买衣物，而钱款遗失，谁可以提起利益归入之诉：债权人还是卖方？我认为，如果价款已经支付，即使衣物后来灭失，债权人也可提起利益归入之诉。如果价款尚未支付，但借款是为了购买衣物，钱款虽已遗失，衣物却已经分给主人家属，那么债权人当然可以提起利益归入之诉。卖方是否也可以提起，因为其货物已进入主人的事务？依此理由，主人应承担责任；于是主人因同一原因而对两人负有责任。因此，如果钱款和衣物都已灭失，应当说主人对双方均承担责任，因为双方都曾意图使利益归入主人事务。

### <a id="15.3.4"></a>15.3.4　盖尤斯《评行省告示》第九卷

但应当说，先行起诉者的地位应较有利；因为让主人因利益归入之诉而对双方都被判承担责任，是不公平的。

### <a id="15.3.5"></a>15.3.5　乌尔比安《评告示》第二十九卷

<a id="15.3.5.pr."></a>

**序言（pr.）** 如果奴隶把并非主人所必需的物品买作仿佛是主人必需之物，例如买入奴隶，庞波尼乌斯写道，应仅在该奴隶的实际价值范围内视为利益归入；如果奴隶买入的确为必需之物，主人则应就其成交价全额承担责任。

<a id="15.3.5.1"></a>

**1.** 他还说，无论主人是否追认奴隶的交易，均可提起利益归入之诉。

<a id="15.3.5.2"></a>

**2.** 如果奴隶为主人购置物品：若依主人的意思购置，可以提起基于命令之诉（*actio quod iussu*）；若并非依其意思购置，但主人已追认，或该物事实上为主人所必需或有益，则可提起利益归入之诉；若以上情形均不成立，则可提起特有产之诉。

<a id="15.3.5.3"></a>

**3.** 我们认为，不仅债权人直接交给主人、因而转用于主人事务的钱款属于利益归入；先前已经进入特有产的钱款也可能属于利益归入。但只有在奴隶处理主人事务时，以特有产中的钱款使主人变得更富有，才是如此。反之，如果主人收回奴隶的特有产，或连同特有产一起出售奴隶，或出售属于奴隶特有产的物品并收取价款，就不应视为利益归入。

### <a id="15.3.6"></a>15.3.6　特里丰尼努《论争议》第一卷

否则，在主人出售特有产中的物品之前，就已经可以对其提起利益归入之诉，因为奴隶仅仅持有特有产，便会使主人变得更富有；而这显然是错误的。

### <a id="15.3.7"></a>15.3.7　乌尔比安《评告示》第二十九卷

<a id="15.3.7.pr."></a>

**序言（pr.）** 因此，即使奴隶把特有产中的物品赠与主人，利益归入之诉也不再适用；这一点正确无疑。

<a id="15.3.7.1"></a>

**1.** 当然，如果奴隶借款后，以赠与的意思把钱款交给主人，并不想使主人在特有产关系中成为债务人，仍可提起利益归入之诉。〔底本作 *accepit*，并列异读 *acceperit*。〕

<a id="15.3.7.2"></a>

**2.** 梅拉所写的下述意见并不正确：如果你把银料交给我的奴隶，让他用其中任意银料为你制成杯子；杯子制成后，奴隶随即死亡，你便可对我提起利益归入之诉，因为我可以对杯子提起所有物返还之诉。

<a id="15.3.7.3"></a>

**3.** 拉贝奥所写的下述意见则是正确的：如果奴隶购买香料和香水，用于为其主人举行的葬礼，应视为利益已转入主人事务。

<a id="15.3.7.4"></a>

**4.** 拉贝奥还说，如果我从你的奴隶处购买本来属于你的遗产，并向债权人支付钱款，随后你又把该遗产取回，我可依买卖之诉取得相应救济；因为应视为利益已转入你的事务。又如，我从奴隶处买下遗产，意在抵销奴隶本人欠我的债务，尽管我没有实际支付价款，仍可依买卖之诉取得已经归于主人的利益。但我认为，除非奴隶行事时意在使利益归入主人事务，否则买受人不能提起利益归入之诉。

<a id="15.3.7.5"></a>

**5.** 如果家子借款为自己的女儿提供嫁资，应视为利益归入父亲事务，但以祖父本来会为孙女提供的数额为限。我认为，只有在家子意在替父亲处理事务时作出给付，这一意见才是正确的。

### <a id="15.3.8"></a>15.3.8　保罗《评告示》第三十卷

庞波尼乌斯说，无论家子是以自己女儿、姐妹，还是以另一名儿子所生的孙女之名提供嫁资，均无区别。因此，如果奴隶借款后以主人的女儿之名提供嫁资，也应作同样处理。

### <a id="15.3.9"></a>15.3.9　雅沃勒努《卡西乌斯著作》第十二卷

但如果父亲本来不会提供嫁资，就不应视为利益已转入父亲事务。

### <a id="15.3.10"></a>15.3.10　乌尔比安《评告示》第二十九卷

<a id="15.3.10.pr."></a>

**序言（pr.）** 如果家子为父亲作保证人，并向债权人清偿，就应视为利益已转入父亲事务，因为他使父亲免于债务。

<a id="15.3.10.1"></a>

**1.** 与此相似的是，帕皮尼安在《疑义集》第九卷中写道：如果家子以父亲的诉讼代理人身份承受诉讼，并因此被判败诉，父亲应依利益归入之诉承担责任；因为家子承受诉讼，使父亲免于承担诉讼责任。

<a id="15.3.10.2"></a>

**2.** 帕皮尼安还讨论了这样的情形：我就父亲本应给付之物向家子订立要式口约，继而起诉家子；此时也应有利益归入之诉。但如果家子承担债务是为了赠与父亲，则不在此限。

<a id="15.3.10.3"></a>

**3.** 因此还可以说，如果家子以父亲的诉讼代理人身份承受特有产之诉，父亲应在特有产数额范围内依利益归入之诉承担责任。该意见的实际益处在于：即使特有产之诉已经终结，仍可改依利益归入之诉起诉。我认为，即使尚未作出判决，只要诉讼已以父亲名义承受，父亲就应依利益归入之诉承担责任。

<a id="15.3.10.4"></a>

**4.** 利益归入应按实际转入的数额认定；因此，如果仅有部分利益归入，诉权也仅及于该部分。

<a id="15.3.10.5"></a>

**5.** 主人承担责任的范围究竟仅限于本金，还是也包括利息？如果主人曾允诺支付利息，马尔切鲁斯在《学说汇纂》第五卷中写道，主人应当给付利息；如果未曾允诺，则不负利息，因为利息未被纳入要式口约。当然，如果债权人是考虑到主人而交付钱款，并非奴隶在替主人处理事务，而是债权人本人在处理主人的事务，则可依无因管理之诉一并请求利息。

<a id="15.3.10.6"></a>

**6.** 我们对利益归入的理解是，利益须持续存在；因此，只有主人尚未向奴隶或家子清偿时，利益归入之诉才成立。但是，如果主人为了损害债权人而向奴隶或家子清偿，也就是明知对方将挥霍财产仍向其清偿，那么即使已经清偿，利益归入也确实会消失；但基于公平，应当允许对父亲或主人提起恶意之诉。特有产债务人若以欺诈方式向奴隶偿还其所欠债务，也不能因此免责。

<a id="15.3.10.7"></a>

**7.** 如果奴隶是主人的债务人，而他向他人借款后将钱款付给主人，就其欠主人的数额而言，利益并未转入；超过该数额的部分则属于利益归入。因此，如果奴隶欠主人三十，却借四十偿还主人的债权人，或用以供养主人家属，应当说可就十提起利益归入之诉；如果奴隶所欠与借款相等，则不应视为有利益归入。正如庞波尼乌斯所写，这一规则是为了防止主人获利。因此，无论奴隶在利益归入时已经是主人的债务人，还是之后才成为主人的债务人，均应认为利益归入已经消失；奴隶向主人清偿时亦同。庞波尼乌斯还进一步说，如果主人后来赠与奴隶的数额恰与奴隶为主人所清偿的债权数额相同：若主人是为了酬谢奴隶而赠与，就不应视为利益归入；若是基于其他原因赠与，利益归入仍然持续存在。

<a id="15.3.10.8"></a>

**8.** 他还讨论：如果奴隶已将十转用于主人事务，之后又向主人借得同额款项，而且另有十的特有产，利益归入是否因此消失？或者，因为存在可从中扣除债务的特有产（底本作 *trahatur*，并注异读 *detrahatur*），是否不应排除利益归入之诉？还是应从两项财产中按比例扣除？我认为，一旦奴隶成为主人的债务人，利益归入之诉即告消灭。

<a id="15.3.10.9"></a>

**9.** 他还讨论：如果奴隶已将利益转用于你的事务，因而成为你的债务人，随后又成为你的债权人，所享债权数额恰等于他欠你的数额，那么利益归入之诉是否恢复，还是事后发生的情形不能使该诉权复活？后一说是正确的。

<a id="15.3.10.10"></a>

**10.** 他还讨论，家子能否因事后发生的情形而使利益归入父亲事务，例如父亲和家子共同负有债务，家子以自己的名义借款后清偿该债务；或你依父亲的命令向家子提供借款，家子随后偿还你。我认为，如果钱款曾经到达父亲手中，就应视为利益已转入；如果钱款并未到达父亲手中，而家子是在处理自己的事务，就不应提起利益归入之诉。

### <a id="15.3.11"></a>15.3.11　保罗《评告示》第三十卷

如果奴隶借款的目的只是清偿自己的债权人，即使主人因此依特有产之诉免责，也不应视为利益归入。

### <a id="15.3.12"></a>15.3.12　盖尤斯《评行省告示》第九卷

如果奴隶或家子为父亲或主人买下一块土地，应视为利益已经转入；但若土地价值低于买价，利益归入的数额仅按土地实际价值计算；若土地价值高于买价，则不得视为转入的利益超过买价。

### <a id="15.3.13"></a>15.3.13　乌尔比安《评告示》第二十九卷

如果利益归入数名共有人中的一人事务，问题在于，是否仅能起诉利益归入其事务的那一人，还是也能起诉其共有人。尤利安写道，只能起诉利益归入其事务的人；这与只有该人作出授权时的处理相同。我认为这一意见正确。

### <a id="15.3.14"></a>15.3.14　尤利安《学说汇纂》第十一卷

马尔切鲁斯附注说，有时，即使利益归入的是另一名共有人的事务，也可以依利益归入之诉起诉该共有人；被诉的共有人可向另一共有人请求返还其被判承担的数额。譬如，如果另一名共有人已从奴隶处收回特有产，该如何处理？保罗说：因此，这一问题只有在不能提起特有产之诉时才会出现。

### <a id="15.3.15"></a>15.3.15　乌尔比安《论争议》第二卷

如果家子约定清偿父亲所欠的债务，应考察是否应准许提起利益归入之诉。但他并未使父亲免于债务：作出约定的人固然使自己负债，却没有使父亲免责。当然，如果家子在作出约定后实际清偿，尽管表面上看似是在清偿自己的债务，也应当恰当地说，利益已转入父亲事务。

### <a id="15.3.16"></a>15.3.16　阿尔费努《学说汇纂》第二卷

有人把一块土地租给自己的奴隶耕种，并交给他几头牛。由于这些牛不适用，主人命令把牛卖掉，再用收回的钱另买几头。奴隶卖掉牛，另行买入新牛，却没有向卖方支付价款，后来破产。出售新牛的人向主人请求支付价款，依据是特有产之诉，或因利益已转入主人事务而请求给付；其理由是，债权人请求付款所涉的牛当时在主人手中。〔底本此处作 *essententiarum respondit*，疑为 *essent. Alfenus respondit* 连写讹误。〕答复认为，除扣除奴隶欠主人的债务后仍有剩余外，不应认为特有产中有任何财产。至于这些牛，虽应视为利益已转入主人事务，但主人仅须支付相当于原先几头牛售价的数额；如果后来买入的牛价款更高，主人应就超过原售价的部分被判承担责任。

### <a id="15.3.17"></a>15.3.17　阿非利加努《疑义集》第八卷

<a id="15.3.17.pr."></a>

**序言（pr.）** 奴隶为主人事务借款，却无过失地遗失了钱款。阿非利加努认为，仍可对主人提起利益归入之诉。因为如果我的代理人借款是为了用于我的事务，却无过失地遗失了钱款，他仍可就此正当地提起委任之诉或无因管理之诉。

<a id="15.3.17.1"></a>

**1.** 我曾与奴隶潘菲鲁斯的奴隶副手斯提库斯订立契约：特有产之诉和利益归入之诉的适用范围，应包括转入你本人事务或转入潘菲鲁斯特有产的部分；即使起诉时斯提库斯已经死亡或被转让，也应如此。如果我在潘菲鲁斯死亡后起诉，较妥当的意见是，尽管斯提库斯仍然在世，但就转入潘菲鲁斯特有产的部分，诉讼只能在潘菲鲁斯死亡后一年内提起。因为在这种情况下，我可以说是在就潘菲鲁斯的特有产起诉，正如我曾依其命令提供借款时起诉一样。斯提库斯仍然在世这一点不应使我们改变看法，因为有关财产只有在潘菲鲁斯的特有产仍然存在时，才可能属于斯提库斯的特有产。基于同一理由，我们应当说：就转入潘菲鲁斯特有产的部分给付时，应先扣除潘菲鲁斯欠你的债务；而转入你本人事务的部分，即使不扣除潘菲鲁斯欠你的债务，也应予以给付。

### <a id="15.3.18"></a>15.3.18　内拉提《论法律解释》第七卷

即使你曾为我的奴隶提供保证，而该项交易原本是为了使利益归入我的事务——例如奴隶购买谷物供家属食用，你为谷物卖方提供保证——更妥当的意见仍是，你就此应提起特有产之诉，而不是利益归入之诉；因为每项交易中，只应有一人享有利益归入之诉，即那个将实际转入主人事务的物品贷出的人。

### <a id="15.3.19"></a>15.3.19　保罗《疑义集》第四卷

家子买了一件托加袍。之后家子死亡，父亲不知情，误以为该袍是自己的，便在儿子的葬礼上将其作为祭献之物。内拉提在《答复集》中说，应视为利益已转入父亲事务。但在特有产之诉中，如果该物已不复存在，只有在被起诉者有恶意时，才应以某种方式估价。然而，如果父亲本应为儿子购买托加袍，利益归入父亲事务的时间并非他后来将袍用于葬礼之时，而是购买之时（因为儿子的丧葬费用是父亲的债务，不是儿子的债务；内拉提认为父亲依利益归入之诉承担责任，也正表明此处所涉事务，即儿子的埋葬与葬礼，是父亲的债务，而不是儿子的）。因此，即使该物已不复存在，父亲仍成为特有产债务人，故仍可依特有产之诉起诉；而该诉也涵盖已经转入的利益。不过，只有在儿子死亡一年期满后，才有必要作此补充。

### <a id="15.3.20"></a>15.3.20　斯凯沃拉《答复集》第一卷

<a id="15.3.20.pr."></a>

**序言（pr.）** 父亲为女儿承诺提供嫁资，并约定由自己供养女儿。父亲未履行供养义务，女儿便向丈夫借款，后在婚姻存续期间死亡。我答复：如果借来的钱用于她赖以维持自身生活或供养父亲奴隶的必要开支，应准许提起准利益归入之诉。

<a id="15.3.20.1"></a>

**1.** 一名奴隶向一名未适婚人的奴隶放贷；该未适婚人因公事不在，监护人在借据上签署，使要式口约的债务转由监护人本人承担。问题是，是否可对未适婚人提起诉讼。我答复：如果钱款是为未适婚人利益而提供，并已转用于其事务；监护人又为确认其奴隶的行为而作出允诺，仍可说对未适婚人享有利益归入之诉。

### <a id="15.3.21"></a>15.3.21　斯凯沃拉《学说汇纂》第五卷

一名家女嫁人时，父亲承诺提供嫁资；各方约定，由父亲供养她，或由她自行供养。丈夫借给她钱款，因为他有正当理由相信，她的父亲会按原先计划给予女儿相应的生活费。她把这些钱用于自己的必要开支，并供养随她一同生活的奴隶；此外，因为家庭财产事务曾交由她处理，她还将丈夫所给钱款中的一部分用于相同用途。之后，女儿在父亲付清生活费之前死亡；父亲拒绝承担这些费用，丈夫则留置该女子的财产。我询问，能否对父亲提起利益归入之诉。答复是：如果借来的钱用于她赖以维持自身生活或供养父亲奴隶的必要开支，应准许提起准利益归入之诉。
