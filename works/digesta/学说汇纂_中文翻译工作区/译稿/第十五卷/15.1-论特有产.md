## 15.1.0　论特有产（*De peculio*）

### <a id="15.1.1"></a>15.1.1　乌尔比安《评告示》第二十九卷

<a id="15.1.1.pr."></a>

**序言（pr.）** 裁判官认为，通常应先说明那些受他人权力支配者所订立、并产生对全部债务承担责任之诉的契约，随后才论及本节这种仅在特有产范围内提起的诉讼。

<a id="15.1.1.1"></a>

**1.** 本告示由三种诉讼构成：特有产之诉、利益归入之诉，以及基于命令之诉，均由此产生。

<a id="15.1.1.2"></a>

**2.** 告示的用语如下：“凡与处于他人权力之下的人进行交易者……”

<a id="15.1.1.3"></a>

**3.** 这里说的是男性而非女性；不过，依据本告示，也可以就处于他人权力之下的女性提起诉讼。

<a id="15.1.1.4"></a>

**4.** 如果与未适婚年龄的家子或奴隶订立契约，只有在其特有产因而增加时，才可以对家父或主人提起特有产之诉。

<a id="15.1.1.5"></a>

**5.** “权力”一词应同时适用于家子和奴隶。

<a id="15.1.1.6"></a>

**6.** 所应考察的不是对奴隶享有所有权，而是有权支配他们的能力。我们不仅会因自己的奴隶而被起诉，也会因共有奴隶而被起诉；对于善意为我们服役的人亦然，无论其是自由人还是他人的奴隶。

### <a id="15.1.2"></a>15.1.2　庞波尼《评萨宾》第五卷

凡奴隶通常可据以为用益权人或使用权人取得财产的原因，仅可对享有该奴隶用益权或使用权的人提起特有产之诉及其他裁判官法上的诉讼；其他原因所生的请求，则应对裸所有权人提起。

### <a id="15.1.3"></a>15.1.3　乌尔比安《评告示》第二十九卷

<a id="15.1.3.pr."></a>

**序言（pr.）** 虽然裁判官承诺，在与处于他人权力之下的人进行交易时给予诉权，但须知，即使该人不受任何人的权力支配，也可以提起特有产之诉。例如，在遗产奴隶继承尚未接受之前与其订约的情形，即属此例。

<a id="15.1.3.1"></a>

**1.** 因此，拉贝奥写道：即使奴隶被指定为第二顺位或第三顺位的替补继承人，并且在第一顺位继承人考虑是否接受遗产期间，有人与该奴隶订约；后来第一顺位继承人放弃遗产，而该奴隶遂成为自由人并取得继承人身份，也可以对他提起特有产之诉及利益归入之诉。

<a id="15.1.3.2"></a>

**2.** 奴隶属于男性还是女性，并无多大关系；女性也可以因其奴隶而被提起特有产之诉。

<a id="15.1.3.3"></a>

**3.** 佩迪乌斯还说，未适婚年龄的奴隶所有人也会因特有产之诉而承担责任；因为交易并非与未适婚年龄的所有人本人订立，故无需考虑监护人的同意。他还补充说，未适婚年龄的被监护人不能为奴隶设立特有产，即使取得监护人同意亦然。

<a id="15.1.3.4"></a>

**4.** 我们也认为，可以对精神失常者的保佐人提起特有产之诉；因为精神失常者的奴隶也可以拥有特有产。并非只有在明确准许其拥有时才有特有产；只要未被禁止拥有即可。

<a id="15.1.3.5"></a>

**5.** 如果家子或奴隶为他人作保证人、以其他方式介入，或出具委任，便会产生是否可以提起特有产之诉的问题。就奴隶而言，较妥当的观点是应考察其作保证或出具委任的原因；塞尔苏斯在《学说汇纂》第六卷中也就作为保证人的奴隶赞同这一看法。因此，如果奴隶是作为代为介入者行事，而非为特有产事务行事，主人就不因特有产之诉承担责任。

<a id="15.1.3.6"></a>

**6.** 尤利安在《学说汇纂》第十二卷中也写道：如果奴隶委托他人向“我的债权人”付款，应考察其委托的原因。如果他是为自己的债权人安排付款，主人应因特有产之诉承担责任；如果他是以代为介入者的身份行事，主人则不因此承担特有产责任。

<a id="15.1.3.7"></a>

**7.** 与此相一致，尤利安还写道：如果我从自己的家子处取得一名保证人，无论我从保证人处取得什么，都应按照特有产责任规则，在委任之诉中承担责任，而非利益归入之诉承担责任。奴隶作保证人的情形也应如此；如果第三人为我的债务人家子代为付款，亦同。如果我的家子并非债务人，保证人可以援用诈欺抗辩；若已付款，尤利安说，他可以提起返还之诉。

<a id="15.1.3.8"></a>

**8.** 奴隶假扮自由人而约定交付仲裁时，能否因仲裁协议的违约金提起特有产之诉，仿佛这是基于交易而产生的诉讼——如航海借贷的情形——是有疑问的。但涅尔瓦之子和我都认为，因奴隶订立仲裁协议，不应给予特有产之诉；因为即使奴隶经判决败诉，也不能对其本人提起诉讼。

<a id="15.1.3.9"></a>

**9.** 但如果家子作了保证人或以代为介入者的身份行事，是否使家父因特有产之诉承担责任，仍有疑问。萨宾和卡西乌斯的观点是正确的：家父始终因特有产之诉承担责任；这一点使家子与奴隶不同。

<a id="15.1.3.10"></a>

**10.** 因此，家父也会因仲裁协议承担责任。帕皮尼安在《疑义解答》第九卷中也如此写道，并说家子订立仲裁协议的原因并不重要：无论该原因是否属于可以对家父提起特有产之诉的原因，家父都因口约之诉而被起诉。

<a id="15.1.3.11"></a>

**11.** 他还写道，家父也因针对家子的判决而受特有产之诉拘束；马尔凯卢斯亦持此见，即使原始请求本身并不能使家父受到特有产之诉拘束，结论仍然如此。正如家子以口约订立契约，判决也会与家子形成债务关系。因此，应考察判决本身仿佛产生的债务，而不是原诉的起因。因此，即使家子以准被告身份受判决，马尔凯卢斯认为结论也相同。

<a id="15.1.3.12"></a>

**12.** 可以确定，基于盗窃原因，可以对家子提起返还之诉。至于能否对家父或主人提起特有产之诉，则有疑问；较妥当的见解是，在主人因盗窃而变得富有的范围内，可以提起特有产之诉。拉贝奥也赞同这一点，因为主人因奴隶盗窃而获利却不受惩罚，是极不公平的。就家女而言，因取走财物之诉也可以其名义提起特有产之诉，但仅限于财物实际到达家父手中的范围。

<a id="15.1.3.13"></a>

**13.** 如果担任市政官的家子未能要求提供担保，以确保被监护人的财产得到妥善保全，帕皮尼安在《疑义解答》第九卷中说，可以提起特有产之诉。我认为，家子是否经家父同意而成为市政官，并不改变结论，因为家父对公共财产的妥善保全负有责任。

### <a id="15.1.4"></a>15.1.4　庞波尼《评萨宾》第七卷

<a id="15.1.4.pr."></a>

**序言（pr.）** 特有产并非奴隶脱离主人而另行记账的财产，而是主人亲自从自己的账目中划分出来、与奴隶的账目相区别的财产。既然主人可以全部剥夺、增加或减少奴隶的特有产，就应考察主人为设立奴隶特有产而做了什么，而非奴隶自己做了什么。

<a id="15.1.4.1"></a>

**1.** 我认为，只有在主人意图免除奴隶债务时，上述原则才是正确的：即使主人只是以单方意思免除奴隶所欠之债，奴隶也不再是债务人。相反，如果主人仅在账簿上作出记载，使自己看似成为奴隶的债务人，而事实上并不负债，我认为结论相反：增加特有产应看实际情况，而非文字记载。

<a id="15.1.4.2"></a>

**2.** 由此可见，构成特有产的不是奴隶在主人不知情时所拥有之物，而是主人愿意让其拥有之物；否则，奴隶从主人处偷来的东西也会成为特有产，这显然不对。

<a id="15.1.4.3"></a>

**3.** 但是，主人不知情而奴隶特有产开始减少的情形经常发生，例如奴隶使主人受损或实施盗窃。

<a id="15.1.4.4"></a>

**4.** 如果你在我的奴隶帮助下从我这里实施盗窃，应从特有产中扣除相应数额，以减少我就被窃物所能取得的赔偿。

<a id="15.1.4.5"></a>

**5.** 即使奴隶的特有产被主人的债务耗尽，其中的财物仍保有特有产的性质。主人若免除奴隶所欠之债，或他人以奴隶名义向主人清偿，特有产便得到补充，无需主人重新授予。

<a id="15.1.4.6"></a>

**6.** 奴隶副手的特有产不仅包括主人交给他的财物，也包括他从设有该副手特有产的奴隶处另行取得并独立记账的财物。

### <a id="15.1.5"></a>15.1.5　乌尔比安《评告示》第二十九卷

<a id="15.1.5.pr."></a>

**序言（pr.）** 因寄托而起诉时，家父或主人仅在特有产范围内受诉；如果我因他们的恶意而受损，也同样如此。

<a id="15.1.5.1"></a>

**1.** 如果某物以可随时收回的方式交给家子或奴隶，家父或主人也仅在特有产范围内承担责任。

<a id="15.1.5.2"></a>

**2.** 如果家子提出宣誓，并且对方已宣誓，可以像发生契约一样提起特有产之诉。但奴隶的情形不同：

<a id="15.1.5.3"></a>

**3.** “特有产”一词，据说源于“小额钱财”或“小规模财产”。

<a id="15.1.5.4"></a>

**4.** 至于图贝罗对特有产的定义，塞尔苏斯在《学说汇纂》第六卷中记载如下：奴隶经主人许可而持有、与主人账目分开的财产，并应扣除奴隶所欠主人的债务。

### <a id="15.1.6"></a>15.1.6　塞尔苏斯《学说汇纂》第六卷

拉贝奥说，图贝罗所提出的特有产定义不适用于奴隶副手的特有产；这一说法不正确。主人为奴隶设立特有产时，应认为也为其副手设立了特有产。

### <a id="15.1.7"></a>15.1.7　乌尔比安《评告示》第二十九卷

<a id="15.1.7.pr."></a>

**序言（pr.）** 塞尔苏斯本人也赞同图贝罗的这一观点。

<a id="15.1.7.1"></a>

**1.** 他补充说，未适婚年龄的被监护人或精神失常者不能为奴隶设立特有产；但如果特有产此前已经设立——即在精神失常发生之前，或由被监护人的父亲设立——便不会仅因这些原因而被剥夺。这个观点是正确的，也与马尔凯卢斯在尤利安著作中所作的批注相符：“可能出现这样的情形：奴隶对其中一名共同所有人有特有产，而对另一名没有；例如其中一名所有人精神失常或尚未适婚年龄，如果像有些人所认为的那样，奴隶只有在主人准许时才能拥有特有产。”但我认为，主人无需明确准许奴隶拥有特有产；只要不予剥夺，奴隶即可保有特有产。特有产的自由管理权则是另一回事，必须特别授予。

<a id="15.1.7.2"></a>

**2.** 但主人无须知道每一件具体财物，只需概括知悉（底本作 *paxumeresteron*，并释为“更概括地说”〔*magis in universum*〕）；庞波尼也倾向于这一观点。

<a id="15.1.7.3"></a>

**3.** 佩迪乌斯在《评告示》第十五卷中写道，未适婚年龄的家子和奴隶都可以拥有特有产；他解释说，这完全取决于主人的设立。因此，奴隶或家子后来开始精神失常，也仍保有其特有产。

<a id="15.1.7.4"></a>

**4.** 特有产可以包括一切动产和不动产；奴隶也可以在其特有产中拥有奴隶副手及副手的特有产。此外，还可以包括对债务人的债权。

<a id="15.1.7.5"></a>

**5.** 如果奴隶因盗窃之诉或其他诉讼享有债权，该债权也计入特有产。拉贝奥说，继承和遗赠也包括在内。

<a id="15.1.7.6"></a>

**6.** 如果主人因奴隶将财物用于主人的账目而仍愿意对奴隶负债，或者主人已向奴隶的债务人提起诉讼，那么主人所欠奴隶的债务也属于奴隶特有产。由此，如果主人因购买奴隶发生权利瑕疵而取得双倍赔偿，该款项应归入奴隶特有产；除非主人无意将其纳入奴隶的特有产。

<a id="15.1.7.7"></a>

**7.** 如果奴隶的同伴欠他财物，该债权也属于其特有产，但以该同伴拥有特有产为限，并依其特有产的实际状况而定。

### <a id="15.1.8"></a>15.1.8　保罗《评萨宾》第四卷

主人仅有意将自己的财物作为特有产，并不会立即使其成为特有产；只有主人已经交付该物，或该物虽仍在主人手中但被视同已经交付，才算设立特有产，因为财物必须通过现实交付而转移。反过来说，主人一旦不再愿意将其作为特有产，该财物便不再属于奴隶的特有产。

### <a id="15.1.9"></a>15.1.9　乌尔比安《评告示》第二十九卷

<a id="15.1.9.pr."></a>

**序言（pr.）** 如果主人使奴隶遭受损害，该损害不计入特有产；主人从奴隶处盗取财物，也同样如此。

<a id="15.1.9.1"></a>

**1.** 但如果造成损害或实施盗窃的是同伴奴隶，该事项应计入特有产；庞波尼在《评萨宾》第十一卷中也如此写道。涅拉提乌斯在《答复录》第二卷中还写道，主人从盗取特有产财物的人那里已经取得或可以取得的任何利益，均应计入奴隶的特有产。

<a id="15.1.9.2"></a>

**2.** 计算特有产时，应扣除奴隶所欠主人的债务，因为应认为主人已经抢先对奴隶起诉。

<a id="15.1.9.3"></a>

**3.** 塞尔维乌斯为此定义补充说，还应扣除奴隶所欠处于主人权力之下之人的债务，因为无人否认，这些债务也等同于欠主人。

<a id="15.1.9.4"></a>

**4.** 此外，还应扣除奴隶所欠下列人员的债务：由主人或家父监护或保佐的人，以及主人或家父代为管理事务之人的债务；但主人或家父不得有诈欺。若他们以诈欺方式取走或减少特有产，仍应承担责任。既然认为主人总是已经抢先起诉，那么为什么不能说，主人也就这些债务起诉了自己——因为他可能就此承担监护之诉、无因管理之诉或准诉讼？正如佩迪乌斯精辟指出的，之所以从特有产中扣除奴隶所欠主人或家父的债务，是因为不大可能认为主人会准许奴隶把欠自己的款项留在特有产中。既然在其他原因下，我们说事务管理人或监护人已经向自己追偿了本应追偿的款项，为什么在特有产的情形下不也如此处理？因此，当有人试图提起特有产之诉时，应当抗辩说该人已仿佛向自己清偿。

<a id="15.1.9.5"></a>

**5.** 如果奴隶的债权人成为其主人的继承人，在该继承人因特有产之诉被起诉时，也应扣除奴隶所欠他的债务；无论奴隶是否已经获释，结论相同。如果奴隶被无条件遗赠，亦应如此。继承人可以扣除自己享有的债权，仿佛他已抢先向自己起诉；即使在奴隶获释或无条件遗赠后，他从未在任何时点取得其所有权，也不影响此结论。尤利安在《学说汇纂》第十二卷中也如此写道。尤利安在同一处还明确指出，如果奴隶被附条件释放，继承人扣除债权就更无疑问，因为此时他已成为奴隶的主人。尤利安还为其观点提出另一理由：如果我成为某人的继承人，而此人在奴隶或家子死亡后一年内本可因特有产之诉被起诉，那么毫无疑问，我也会扣除他所欠我的债务。〔原文句法似有脱漏，关系从句结构未完；译文据上下文处理。〕

<a id="15.1.9.6"></a>

**6.** 无论奴隶是基于契约还是基于账目结余而欠主人债务，主人都可以扣除。即使债务源于不法行为，例如奴隶实施盗窃，也同样可以扣除。但问题在于，应扣除盗窃行为的估价——即主人实际遭受的损失——还是应扣除若由他人奴隶实施盗窃时所适用的数额，即包括盗窃罚金在内的金额？较妥当的观点是，仅扣除盗窃行为本身的估价。

<a id="15.1.9.7"></a>

**7.** 如果奴隶伤害了自己，不应将该损害从特有产中扣除；奴隶自杀或自我坠落致死时，亦同。奴隶在自然意义上也可能残害自己的身体。但如果主人为奴隶自行造成的伤害进行治疗，我认为奴隶因此应就费用对主人负债；这与奴隶生病时主人为其治疗不同，因为在后一种情形中，主人所处理的仍是自己的财产事务。

<a id="15.1.9.8"></a>

**8.** 如果主人因奴隶而负债或代其付款，也应从特有产中扣除。例如，有人依主人命令向奴隶提供借款时，尤利安在《学说汇纂》第十二卷中写道，该款应予扣除。但我认为，只有在所借款项未用于主人或家父的事务时才如此；否则，主人应以双方债权相互抵销。尤利安在《学说汇纂》第十二卷中还写道，如果主人为奴隶作保证，也应扣除。马尔凯卢斯就这两种情形都说，如果主人尚未因此实际受损，较好的做法是让债权人向主人提供担保，承诺如主人日后因该事由被起诉并付款，债权人即予偿还；而不是一开始就扣除，以便债权人取得期间利息。如果主人因特有产之诉被起诉并受判决，在后续的特有产诉讼中应予扣除；因为家父或主人已经因判决而承担债务。即使主人未受判决，只是代奴隶向债权人付款，也应扣除该款。

### <a id="15.1.10"></a>15.1.10　盖尤斯《评行省告示》第九卷

如果先前的特有产之诉仍悬而未决，后来另一起诉讼先行作出判决，那么在后一判决中绝不能考虑前一诉讼。因为在特有产之诉中，先取得判决者处于较有利地位；所谓先取得，不是指先完成诉讼系属，而是指先得到法官的判决。

### <a id="15.1.11"></a>15.1.11　乌尔比安《评告示》第二十九卷

<a id="15.1.11.pr."></a>

**序言（pr.）** 如果主人在诺克萨诉讼中被起诉后，提出支付诉讼标的估价，应从特有产中扣除该款；如果主人将奴隶交付以承担诺克萨责任，则不作扣除。

<a id="15.1.11.1"></a>

**1.** 如果主人承诺代奴隶付款，也应扣除相应款项；奴隶代债务人向主人作出承诺时，亦同。奴隶若以获得自由为对价而向主人作出承诺，也应视为因此成为主人的债务人；但只有在奴隶获释后提起诉讼时才如此。

<a id="15.1.11.2"></a>

**2.** 如果奴隶从主人的债务人处收取款项，他是否因此成为主人的债务人，是有疑问的。尤利安在《学说汇纂》第十二卷中说，除非主人认可该收款，否则主人不得扣除；家子的情形也应作相同处理。我认为尤利安的观点正确：计算特有产中的扣除时，应考虑自然债务。奴隶或家子因收取本不应收取的款项而免于负担债务，在自然意义上是公平的。

<a id="15.1.11.3"></a>

**3.** 问题是：主人在一次被起诉时已经扣除的数额，若后来再次被起诉，是否可以再从特有产中扣除，还是说既已扣除一次，就应视为已经向主人清偿？涅拉提乌斯、涅尔瓦和尤利安在《学说汇纂》第十二卷中均认为：如果主人已将该款从特有产中取走，就不得再次扣除；如果他让特有产维持原状，则仍可扣除。

<a id="15.1.11.4"></a>

**4.** 尤利安还写道：如果奴隶在特有产中有一名价值五的副手，而奴隶也欠主人五，主人便以该副手抵扣债务；此后副手死亡，奴隶又以同样的价钱买入另一名副手，则奴隶仍然是主人的债务人，仿佛原副手是在仍属于主人时死亡。除非主人先从奴隶处取走该副手并以此向自己清偿，然后副手才死亡。

<a id="15.1.11.5"></a>

**5.** 尤利安还正确地说，如果副手价值十，主人因特有产之诉被起诉，并代奴隶支付五——因为奴隶欠他五——此后副手死亡，另一债权人提起特有产之诉请求十，主人可以扣除五，因为主人已因先前代付而使奴隶对自己负债。除非主人从奴隶处取走副手，作为向自己清偿。

<a id="15.1.11.6"></a>

**6.** 我们说应扣除被起诉者本人享有的债权，这是以该债权不能通过其他途径实现为前提。

<a id="15.1.11.7"></a>

**7.** 尤利安写道，出售奴隶并连同特有产一并出售的卖方，若被提起特有产之诉，不得扣除奴隶所欠自己的债务。卖方本可以在出售时从特有产账目中扣除该款，现在则可以提起返还之诉，主张该款为非债清偿，因为奴隶所欠主人的款项不属于特有产。他还说，卖方也可以提起买卖之诉。只有在出售时特有产足以使主人得到清偿时，这一观点才成立；如果债务条件在出售后才成就，而主人出售时并未扣除该债务，则应作相反处理。

<a id="15.1.11.8"></a>

**8.** 尤利安还写道：如果某人买下其本人原可提起特有产之诉的奴隶，能否扣除奴隶所欠自己的债务，因为他可以对卖方提起特有产之诉？他的回答正确：可以。任何人都可以选择对买方或卖方起诉；因此，该买方可以选择以扣除债务代替提起诉讼。我看不出其他债权人有何可抱怨之处，因为如果他们认为特有产中尚有财物，可以自行对卖方起诉。

<a id="15.1.11.9"></a>

**9.** 不仅应扣除欠被起诉者本人的债务，也应扣除欠其合伙人的债务；尤利安在《学说汇纂》第十二卷中也如此写道。理由是：既然两人中的任何一人都可以就全部债务被起诉，同样也应允许其扣除欠另一人的债务。这一观点已获采纳：

### <a id="15.1.12"></a>15.1.12　尤利安《学说汇纂》第十二卷

因为在这种情形下，即使特有产并不由其持有，也可以对其提起诉讼。

### <a id="15.1.13"></a>15.1.13　乌尔比安《评告示》第二十九卷

但这一规则不适用于买方和卖方、用益权人和裸所有权人，以及其他并非合伙人的人；也不适用于所有人和善意买受人。尤利安在《学说汇纂》第十二卷中写道，这些人任何一方都不得扣除对方所欠自己的债务。

### <a id="15.1.14"></a>15.1.14　尤利安《学说汇纂》第十二卷

<a id="15.1.14.pr."></a>

**序言（pr.）** 同样，如果遗嘱规定奴隶于遗嘱生效当日获释，应对所有继承人提起特有产之诉；每一名继承人所能扣除的，不得超过奴隶欠其本人的债务。

<a id="15.1.14.1"></a>

**1.** 同样，如果奴隶在主人生前死亡，而主人随后于一年内留下数名继承人，特有产之诉和扣除债务的权利均应按继承份额分割。

### <a id="15.1.15"></a>15.1.15　乌尔比安《评告示》第二十九卷

如果有两名善意占有人，也应认为任何一人均不得扣除超过奴隶所欠自己的债务。两名用益权人的情形亦同，因为他们彼此之间并无合伙关系。有时，对合伙人也应作相同处理，例如他们各自分别持有特有产，以致任何一人都不会因另一人的特有产而被起诉。相反，如果特有产是共有的，他们就可能各自因全部债务被起诉，也可以扣除奴隶对双方所负的债务。

### <a id="15.1.16"></a>15.1.16　尤利安《学说汇纂》第十二卷

在何种情形下，共有奴隶的特有产只归属于其中一名所有人？首先，如果某人出售奴隶的一半份额，却未将特有产授予买方；其次，如果某人把钱款或其他物品交给共有奴隶，意在保留这些财物的所有权，只允许奴隶管理。马尔凯卢斯批注说，还有一种情形：一名所有人剥夺了特有产；或者虽然主人将特有产完全授予奴隶，但授予的只是债权。

### <a id="15.1.17"></a>15.1.17　乌尔比安《评告示》第二十九卷

如果我的普通奴隶拥有奴隶副手，我能否将副手欠我的债务从该普通奴隶的特有产中扣除？首先要问的是，副手的特有产是否应计入普通奴隶的特有产。普罗库鲁斯和阿蒂利基努斯认为，正如副手本身属于普通奴隶的特有产，副手的特有产也属于其中。副手欠我的债务，也就是普通奴隶欠我的债务，应从副手的特有产中扣除；副手本人所欠我的债务，则仅从其自己的特有产中扣除。如果副手欠的不是我而是普通奴隶，应当作为欠同伴奴隶的债务，从副手的特有产中扣除。但普通奴隶欠副手的债务，不应从普通奴隶的特有产中扣除，因为副手的特有产本已包含在普通奴隶的特有产中；塞尔维乌斯也作此答复。不过，在我看来，副手的特有产应相应增加，仿佛主人欠奴隶债务一样。

### <a id="15.1.18"></a>15.1.18　保罗《疑义解答》第四卷

由此可知，如果斯提库斯的特有产遗赠给了他，而他依据遗嘱提起诉讼，只有在副手拥有自己的特有产时，才必须从遗产中留出副手所欠遗嘱人的款项。

### <a id="15.1.19"></a>15.1.19　乌尔比安《评告示》第二十九卷

<a id="15.1.19.pr."></a>

**序言（pr.）** 由此产生一个问题：如果已就普通奴隶提起特有产之诉，能否也就其副手的特有产起诉？我认为不能。但如果已就副手的特有产提起诉讼，也可以就普通奴隶的特有产起诉。

<a id="15.1.19.1"></a>

**1.** 我可能同时涉及两种不同归属的特有产。例如，奴隶属于嫁资财产，他可能有一部分特有产归我，另一部分归妻子；凡因丈夫财产或奴隶劳务所得，均归丈夫。因此，庞波尼写道，如果该奴隶因丈夫一方被指定为继承人，或从丈夫处取得遗赠，丈夫无需返还该财产。如果有人依据与我有关的契约起诉我，我能否从中扣除奴隶所欠我的全部债务——无论债务属于我还是属于妻子？还是应把两种原因分别视为两个特有产，并根据所主张债务的原因加以区分？也就是说，如果诉讼涉及归妻子所有的特有产，我只能扣除源于该特有产的债务；如果涉及归我所有的特有产，则只能扣除与我有关的债务。用益权人的情形更能说明这一问题：他是否仅因与其有关的契约才在特有产范围内受诉，还是因奴隶的一切契约均受诉？马尔凯卢斯写道，用益权人对奴隶的一切契约均承担责任，因为订约人把奴隶的全部特有产都视为其财产。不过，他明确认为，应先对与该事由有关的人提起诉讼；只有在不能足额受偿的范围内，才可起诉未从中获益的人。这一观点更为可取，帕皮尼安也赞同。两名善意买受人的情形也应如此。至于丈夫，较好的说法是，他仅在特有产范围内承担责任。如果丈夫曾为此类奴隶支付款项，能否在妻子提起嫁资之诉时扣除？他说，如果向债权人支付的款项涉及两种特有产，应按比例分别扣减；由此可知，如果契约只涉及其中一种特有产，则仅从该项特有产中扣除；但若契约涉及由丈夫持有的特有产，则不得从妻子的特有产中扣除。

<a id="15.1.19.2"></a>

**2.** 有时，用益权人也可以对所有人提起特有产之诉，例如奴隶在用益权人处拥有特有产，而在所有人处没有特有产或特有产较少。反过来的情形亦然。尽管如此，如果涉及两名所有人，彼此之间仍可提起合伙之诉或共有物分割之诉：

### <a id="15.1.20"></a>15.1.20　保罗《评告示》第三十卷

因为合伙人之间不得彼此提起特有产之诉。

### <a id="15.1.21"></a>15.1.21　乌尔比安《评告示》第二十九卷

<a id="15.1.21.pr."></a>

**序言（pr.）** 裁判官也有充分理由将主人以恶意造成特有产减少的数额计入特有产。所谓恶意，是指主人剥夺了奴隶的特有产；梅拉还写道，如果主人放任奴隶耗尽特有产，以致损害债权人，也构成恶意。如果主人猜测他人将对自己提起诉讼，便把特有产转移到别处，也不能免于恶意责任。但如果主人是向另一名债权人清偿，我毫不怀疑他不承担责任，因为他是在向债权人付款，而且债权人本可以留意并采取措施实现自己的权利。

<a id="15.1.21.1"></a>

**1.** 如果监护人、精神失常者的保佐人或代理人实施欺诈，能否就特有产起诉被监护人、精神失常者或所有人，仍须考察。我认为，如果监护人有清偿能力，被监护人应就监护人的欺诈承担责任，尤其是在被监护人实际取得利益时；庞波尼在《书信集》第八卷中也如此写道。保佐人和代理人的情形也应如此。

<a id="15.1.21.2"></a>

**2.** 买方不因卖方的欺诈而承担责任；继承人或其他继受人也不承担责任，但以实际到达其手中的利益为限。无论欺诈发生在接受诉讼之后还是之前，均由法官在其职权范围内予以考虑。

<a id="15.1.21.3"></a>

**3.** 如果主人或家父拒绝应诉特有产之诉，不应听从其拒绝，而应强令其承受另一项人身诉讼。

### <a id="15.1.22"></a>15.1.22　庞波尼《评萨宾》第七卷

如果主人曾以特有产房屋的名义承诺提供损害尚未发生的担保，就应将该担保计入；因此，提起特有产之诉的人应向主人提供担保。

### <a id="15.1.23"></a>15.1.23　庞波尼《评萨宾》第九卷

就特有产房屋名义作出的损害尚未发生担保，应为全部责任提供担保；这与主人因副手承担全部诺克萨诉讼责任相同，因为如果房屋未获防护，原告可以将其带走或占有，作为质物。

### <a id="15.1.24"></a>15.1.24　乌尔比安《评萨宾》第二十六卷

精神失常者的保佐人可以准许或拒绝精神失常者的奴隶或家子管理特有产。

### <a id="15.1.25"></a>15.1.25　庞波尼《评萨宾》第二十三卷

如果主人把衣服交给奴隶，意在让奴隶永久穿用，并将衣服交由其保管以供自己穿用，不让他人使用，该衣服便开始成为特有产。但如果主人交给奴隶的衣服并非供其经常穿用，而仅供特定场合、特定时间使用，例如跟随主人外出或在主人用餐时侍奉所穿，那么该衣服就不属于特有产。

### <a id="15.1.26"></a>15.1.26　保罗《评告示》第三十卷

如果主人因欺诈而被提起特有产之诉，并已就该事由承担责任，就无需再为其他原告就同一事由承担责任。如果奴隶所欠主人之债等于主人以欺诈方式减少的特有产，主人也不应被判决承担责任。由此可知，即使奴隶已获释或被转让，主人仍应在一年内因该欺诈承担责任。

### <a id="15.1.27"></a>15.1.27　盖尤斯《评行省告示》第九卷

<a id="15.1.27.pr."></a>

**序言（pr.）** 对女奴和家女也可以提起特有产之诉；尤其是她们从事缝纫、织布或其他普通手艺时，可以因其提起该诉。尤利安说，也可以就她们提起寄托之诉和借用之诉；如果她们在家父或主人知情的情况下以特有产中的货物经营，还可以提起分配之诉。如果交易是依家父或主人的命令订立，且利益用于其财产，则更毫无疑问可以提起相应诉讼。

<a id="15.1.27.1"></a>

**1.** 可以确定，如果奴隶的主人在遗产被接受之前取走、耗用或毁损遗产中的财物，而他人以该奴隶的名义对其提起特有产之诉，作为继承人的主人也应扣除该等财物。

<a id="15.1.27.2"></a>

**2.** 如果奴隶被转让，尽管裁判官承诺在一年内对转让人提起特有产之诉，但仍可对新主人提起诉讼。新主人是否另行取得特有产，还是在买入奴隶时一并取得该特有产，或通过赠与取得后再授予奴隶，并无区别。

<a id="15.1.27.3"></a>

**3.** 尤利安赞同另一项已获采纳的规则：应始终允许债权人分别对每一名主人按份起诉，或选择其中一人请求其承担全部债务。

<a id="15.1.27.4"></a>

**4.** 但尤利安认为，不应允许出售奴隶的人就出售前提供的借款，对买方提起特有产之诉。

<a id="15.1.27.5"></a>

**5.** 如果我曾向他人所有的奴隶提供借款，后来买下该奴隶，再将其转让，尤利安同样认为，不应允许我对买方提起该诉。

<a id="15.1.27.6"></a>

**6.** 尤利安认为，对转让人提起诉讼的期限仅为赎回奴隶后一年，且只涉及我在该奴隶仍属于他人时向其提供的借款；同时，应扣除该奴隶在我处拥有的特有产。

<a id="15.1.27.7"></a>

**7.** 尤利安认为，既然我不能因自己在出售奴隶前提供给该奴隶的借款而对买方提起诉讼，如果是我的奴隶向我的另一名奴隶提供借款，而受借款的奴隶后来被转让，我也不得对买方起诉。

<a id="15.1.27.8"></a>

**8.** 如果某人同共有奴隶订约，应允许其选择对任何一名所有人提起诉讼，并请求其承担全部债务。与一人订约，却被迫面对多名对手，是不公平的。计算时，不应只考虑被起诉的所有人处由该奴隶持有的特有产，也应考虑其在另一所有人处持有的特有产。被判决承担责任的所有人不会因此遭受损失，因为他可以另行提起合伙之诉或共有物分割之诉，向其合伙人追回超出自己份额的付款。尤利安说，只有在另一所有人处也有特有产时，才能如此处理；因为在这种情形下，每一所有人都有清偿债务的能力，也就可以免除合伙人的债务。如果另一所有人处没有特有产，则应作相反处理，因为不能认为其因此免除了任何债务。

### <a id="15.1.28"></a>15.1.28　尤利安《学说汇纂》第十二卷

因此，如果另一合伙人既未成为继承人，也未取得遗产占有，被起诉的人只应在其所持有的特有产范围内，并在其可从遗产中取得的数额范围内承担责任。

### <a id="15.1.29"></a>15.1.29　盖尤斯《评行省告示》第九卷

<a id="15.1.29.pr."></a>

**序言（pr.）** 如果某人以遗嘱命令奴隶获释，却留下曾与该奴隶订约的继承人，这些共同继承人可以彼此提起特有产之诉，因为其中任何一人都可能因自己持有的特有产而受诉，即使另有人已经提起该诉亦然。

<a id="15.1.29.1"></a>

**1.** 即使主人曾禁止他人与奴隶订约，也仍可对主人提起特有产之诉。

### <a id="15.1.30"></a>15.1.30　乌尔比安《评告示》第二十九卷

<a id="15.1.30.pr."></a>

**序言（pr.）** 有人问：提起诉讼时特有产中即使没有任何财物，只要在判决时有财物，特有产之诉是否仍然有效？普罗库鲁斯和佩加苏斯认为，仍应承担责任，因为原告可以正当地提出诉请，即使当时特有产中并无财物。展示之诉和利益归入之诉也适用同一规则；我们也赞同这一观点。

<a id="15.1.30.1"></a>

**1.** 如果对家父或主人之一的部分继承人提起诉讼，判决仅以被起诉继承人所持有的特有产为限；利益归入之诉也仅按其份额承担责任，但利益实际用于该继承人自身财产的除外。起诉该继承人时，不应把他视为众合伙人之一，而只能按其份额起诉。

<a id="15.1.30.2"></a>

**2.** 但如果奴隶本人被指定为部分继承人，也同样应对其提起诉讼。

<a id="15.1.30.3"></a>

**3.** 如果被指定为部分继承人的是家子，尽管仅继承部分遗产，仍须对全部债务承担责任。但如果他愿意按比例买下共同继承人的债权，应当听取其请求：如果相关利益用于家父的财产，家子为什么不能从共同继承人处取得属于家父财产的部分？如果特有产充足，结论也相同。

<a id="15.1.30.4"></a>

**4.** 已经提起一次特有产之诉的人，如果特有产后来增加，可以就债务余额再次起诉。

<a id="15.1.30.5"></a>

**5.** 如果债权人因一年期间的抗辩而无法对卖方起诉，应给予其对买方的救济；但如果其因其他抗辩而败诉，则只应在扣除本可向卖方取得的数额后，就余额对买方提供救济。

<a id="15.1.30.6"></a>

**6.** 提出恶意抗辩时，也应考虑时间经过。或许过了期间后，裁判官将不允许再提出恶意抗辩，因为恶意之诉本身也不得在法定期间届满后提起。

<a id="15.1.30.7"></a>

**7.** 对继承人提出恶意条款时，责任应以实际到达其手中的利益为限，不得超过该数额。

### <a id="15.1.31"></a>15.1.31　保罗《评告示》第三十卷

但如果继承人本人实施了欺诈，就应对全部债务承担责任。

### <a id="15.1.32"></a>15.1.32　乌尔比安《论疑难》第二卷

<a id="15.1.32.pr."></a>

**序言（pr.）** 如果某人因奴隶获释、被遗嘱命令成为自由人、被转让或死亡，而在一年内本可被起诉，那么，对其两名或多名继承人中的一人提起诉讼后，所有继承人均获免责；即使该继承人仅就自己所持有的特有产范围受判决，亦然。尤利安如此写道。利益归入之诉也适用同一规则。如果有数名用益权人或善意占有人，对其中一人起诉也会使其他人免责，即使该人仅因自己持有的特有产而受判决。尽管法律上会产生这一结果，衡平仍要求对那些借法律规则而获免责的人提起诉讼，使他们因实际取得利益而非仅因诉请提出而获免责；因为与奴隶订约的人，是把该奴隶无论在何处持有的全部特有产都视为其整体财产。

<a id="15.1.32.1"></a>

**1.** 在本诉中，即使前一诉讼获恢复（底本作 *restauretur praecedens*，具体程序含义未详），仍应考虑特有产的增加和减少。因此，无论现时特有产中已无财物，还是后来有所增加，都应考察特有产的当前状况。因此，就卖方和买方而言，较妥当的看法是，我们可以向买方追偿特有产后来增加的部分，而不应倒推视为同一诉讼，并把对买方的起诉时间追溯到卖方被起诉之时。

<a id="15.1.32.2"></a>

**2.** 如果奴隶的卖方连同特有产一起出售奴隶，并已交付该特有产，即使在一年内也不得因特有产之诉起诉卖方；正如涅拉提乌斯所写，奴隶的价金并非特有产。

### <a id="15.1.33"></a>15.1.33　雅沃勒努《卡西乌斯著作》第十二卷

但如果某人出售奴隶，并约定把特有产的价金收归自己，则应认为特有产由收到该价金的人持有，

### <a id="15.1.34"></a>15.1.34　庞波尼《杂录》第十二卷

而不是由持有特有产财物的人持有。

### <a id="15.1.35"></a>15.1.35　雅沃勒努《卡西乌斯著作》第十二卷

但如果继承人受命在收取一定款项后交付特有产，就不应认为特有产由继承人持有。

### <a id="15.1.36"></a>15.1.36　乌尔比安《论疑难》第二卷

在诚信诉讼中，家父或主人究竟仅在特有产范围内还是对全部债务承担责任，是有疑问的。例如，在嫁资之诉中，如果嫁资交给家子，是否只能就家父所持有的特有产起诉家父？我认为，针对家父不仅可以提起特有产之诉；如果女性因家父的恶意而受损或受欺诈，也可以提起诉讼。家父既有财物却不愿返还时，对其判处该物的价值才是公平的。庞波尼写道，对奴隶设定质权时明文规定的规则，也应适用于其他诚信诉讼。对奴隶设定质权时，不仅可以提起特有产之诉和利益归入之诉，还可以附加如下请求：“以及原告因主人恶意而受损或受欺诈的任何数额。”主人有能力返还却不愿返还，即属恶意。

### <a id="15.1.37"></a>15.1.37　尤利安《学说汇纂》第十二卷

<a id="15.1.37.pr."></a>

**序言（pr.）** 如果你儿子的债权人指定你为继承人，而你又出售其遗产，根据约款中“因遗产而到达你手中的款项”这一部分，你将因特有产之诉承担责任。

<a id="15.1.37.1"></a>

**1.** 如果你准许自己的奴隶用八奥雷金币购买一名副手，而他以十枚金币买下，却告诉你只花了八枚；你又准许他用你的钱支付这八枚金币，而他实际支付了十枚，那么你只能就两枚金币主张返还；而且卖方仅能在奴隶特有产范围内取得该两枚金币。

<a id="15.1.37.2"></a>

**2.** 我与提提乌斯共有一名奴隶，后来我将其卖给塞姆普罗尼乌斯。有人问：若对提提乌斯或塞姆普罗尼乌斯提起特有产之诉，是否应考虑仍在我处的特有产？我回答说，如果对塞姆普罗尼乌斯起诉，绝不应考虑仍在我处的特有产，因为他没有任何诉权可以向我追回应付款项。如果在奴隶转让一年后对提提乌斯起诉，也同样不应计算我处的特有产，因为届时已不能对我提起特有产之诉。但如果在一年内起诉，也应考虑该特有产，因为既然奴隶转让后允许债权人同时对卖方和买方起诉，结论即应如此。

<a id="15.1.37.3"></a>

**3.** 如果债权人已对享有奴隶用益权的人提起特有产之诉，却未能足额受偿，那么允许其从全部特有产中继续取得清偿并不不公平，无论特有产由用益权人还是裸所有权人持有。奴隶是向用益权人租赁自己的劳务，还是从其处取得借款，并无区别。因此，应允许债权人对裸所有权人提起诉讼，但须扣除奴隶作为特有产留在用益权人处的财物。

### <a id="15.1.38"></a>15.1.38　阿非利卡努《疑义解答》第八卷

<a id="15.1.38.pr."></a>

**序言（pr.）** 我将十枚金币寄托给家子，并提起寄托之诉，要求在特有产范围内承担责任。即使家子不欠家父任何债务，并持有这十枚金币，如果除此以外没有特有产，阿非利卡努仍认为不应判家父承担责任，因为这笔钱仍属于我，并非特有产。他说，任何其他人提起特有产之诉时，也毫无疑问不应将这笔钱计入。因此，我应提起展示之诉，并在该钱款展示后提起返还之诉。

<a id="15.1.38.1"></a>

**1.** 如果一名即将与家子结婚的女子约定以嫁资名义给付一定金额，离婚后对家父提起嫁资之诉，她是否应因全部约定而免责，还是应先扣除家子所欠家父的债务？答复是，她应因全部约定而免责；因为即使有人依据该约定对她提起诉讼，她也可以援用恶意抗辩。

<a id="15.1.38.2"></a>

**2.** 斯提库斯的特有产中有一名价值十的潘菲卢斯，而潘菲卢斯欠主人五。如果有人就斯提库斯提起特有产之诉，应计算潘菲卢斯的全部价值，不扣除其所欠主人的五，因为不能认为某人属于自己的特有产。在这种情形下，主人将承受损失，正如他把财物借给任何一名没有特有产的奴隶一样。若将特有产遗赠给斯提库斯，这一点就更清楚：斯提库斯依据遗嘱提起诉讼时，不应被迫扣除其副手所欠的债务；除非只能从斯提库斯自己的特有产中扣除。否则，若副手欠主人同等数额，斯提库斯便会被认为毫无特有产，这显然荒谬。

<a id="15.1.38.3"></a>

**3.** 我将钱借给曾由我卖给你的奴隶。问题是，我对你提起特有产之诉时，是否应扣除仍留在我处的该项特有产？这显然不正确；无论我是在出售后一年内还是一年后起诉，结论都相同，因为当时与该奴隶订约的其他人也不能对我起诉。反过来，以前曾与该奴隶订约的人对我起诉时，我也不会扣除该奴隶后来开始欠我的债务。由此可见，我仍持有的特有产，不应成为奴隶后来订立交易的责任负担。

### <a id="15.1.39"></a>15.1.39　弗洛伦提努《法学阶梯》第十一卷

特有产还包括奴隶凭借节俭所积累的财物、以劳务取得的报酬，或从任何人处接受的赠与；只要主人愿意让奴隶把这些财物作为自己的财产持有即可。

### <a id="15.1.40"></a>15.1.40　马尔基安《规则》第五卷

<a id="15.1.40.pr."></a>

**序言（pr.）** 特有产会产生、增长、减少并消灭，因此帕皮里乌斯·弗龙托颇为精妙地说，特有产就像一个人。

<a id="15.1.40.1"></a>

**1.** 特有产如何产生，曾引起讨论。古代法学家作如下区分：奴隶取得主人并无义务提供的财物，该财物属于特有产；如果是衣服或类似必需品，而主人有义务提供给奴隶，则不属于特有产。因此，特有产由此产生；财物增加时便增长；奴隶副手死亡或财物灭失时便减少；一旦被剥夺，特有产即告消灭。

### <a id="15.1.41"></a>15.1.41　乌尔比安《评萨宾》第四十三卷

奴隶不能负担债务，也不能成为他人债权的债务人；我们使用这些说法时，描述的是事实，而非民法上的债务关系。因此，奴隶享有的债权，应由主人向第三人主张；奴隶本人所负债务，则可对主人提起特有产之诉；如果奴隶将所得用于主人财产，也可以对主人提起利益归入之诉。

### <a id="15.1.42"></a>15.1.42　乌尔比安《评告示》第十二卷

有人正确地认为，可以对收养者提起特有产之诉；尽管萨宾和卡西乌斯认为，对收养前发生的事项不应给予特有产之诉。

### <a id="15.1.43"></a>15.1.43　保罗《评告示》第三十卷

如果我对你提起特有产之诉后、判决作出前，你出售了奴隶，拉贝奥说，你还应就奴隶在买方处取得的特有产承担责任，不应给予你救济；因为这是你的过错，你出售了奴隶。

### <a id="15.1.44"></a>15.1.44　乌尔比安《评告示》第六十三卷

如果某人与家子订约，就有两个债务人：家子对全部债务承担责任，家父则仅在特有产范围内承担责任。

### <a id="15.1.45"></a>15.1.45　保罗《评告示》第六十一卷

因此，即使家父剥夺了家子的特有产，债权人仍可对家子起诉。

### <a id="15.1.46"></a>15.1.46　保罗《评告示》第六十卷

准许他人管理特有产的人，应被认为概括地准许了他若逐项说明也会准许的事务。

### <a id="15.1.47"></a>15.1.47　保罗《评普劳提乌斯》第四卷

<a id="15.1.47.pr."></a>

**序言（pr.）** 如果有人在店铺张贴告示：“我禁止与我的奴隶雅努阿里乌斯进行交易”，可以确定，主人仅因此免于经理人之诉，而不免于特有产之诉。

<a id="15.1.47.1"></a>

**1.** 萨宾答复说，只有在奴隶作保证是为了主人的事务或特有产事务时，才可以对主人提起特有产之诉。

<a id="15.1.47.2"></a>

**2.** 如果已经提起特有产之诉，即使判决时特有产少于债务，也不应要求提供担保，以保证将来特有产增加时支付；但在合伙之诉中适用这一规则，因为合伙人对全部债务负责。

<a id="15.1.47.3"></a>

**3.** 如果奴隶的债权人已从买方处取得部分清偿，普罗库鲁斯说，他可以就余额对卖方提起准诉讼。但诉讼关系尚未确定时，不得允许原告分割诉讼，同时对买方和卖方起诉。只需准许原告在撤销先前诉讼后，对另一方提起诉讼；如果原告选择的被告不能使其足额受偿，便可如此处理。现行法即采用这一规则。

<a id="15.1.47.4"></a>

**4.** 不仅任何债权人都可以因出售前发生的交易对卖方起诉，买方本人也可以；尤利安持相同观点。买方也可以在他人起诉时主张扣除，但仍须计算自己所持有的特有产。

<a id="15.1.47.5"></a>

**5.** 如果奴隶在扣除特有产后被出售，卖方可以援用该扣除；如果奴隶在出售后开始欠卖方债务，该债务不会减少特有产，因为奴隶此时并不欠其主人。

<a id="15.1.47.6"></a>

**6.** 我们对买方和卖方所说的规则，也适用于通过其他方式变更所有权的情形，例如遗赠或以嫁资给付；因为奴隶的特有产被视为自由人的财产，无论其位于何处。

### <a id="15.1.48"></a>15.1.48　保罗《评普劳提乌斯》第十七卷

<a id="15.1.48.pr."></a>

**序言（pr.）** 特有产的自由管理权不会继续适用于逃亡的奴隶、被窃取的奴隶，或其生死不明的人。

<a id="15.1.48.1"></a>

**1.** 获准管理特有产的人，可以指定自己的债务人代为履行。

### <a id="15.1.49"></a>15.1.49　庞波尼《评昆图斯·穆基乌斯》第四卷

<a id="15.1.49.pr."></a>

**序言（pr.）** 特有产不仅包括主人授予奴隶的财物，也包括奴隶在主人不知情时取得、但如果主人知情也会允许其作为特有产持有的财物。

<a id="15.1.49.1"></a>

**1.** 如果我的奴隶在我不知情的情况下管理我的事务，他应被视为欠我相应债务，数额与自由人替我管理事务时其所负的责任相同。

<a id="15.1.49.2"></a>

**2.** 判断奴隶是否为主人的债务人，或主人是否为奴隶的债务人，应依民法上的原因计算。因此，即使主人在账目中记载自己欠奴隶债务，但事实上既未借款，也不存在任何先前的债务原因，仅有账目记载并不能使其成为债务人。

### <a id="15.1.50"></a>15.1.50　帕皮尼安《疑义解答》第九卷

<a id="15.1.50.pr."></a>

**序言（pr.）** 在特有产中毫无财物时，家父躲藏起来。我不能为保全财产而取得其遗产占有，以便对他提起特有产之诉，因为如果他接受诉讼，本应获判无责；因此，他躲藏并非为了欺诈债权人。可能后来仍会作出有罪判决，与此无关：即使债务尚未到期或附有条件，也不认为债务人是为欺诈而躲藏，尽管法官可能错误地判其承担责任。尤利安认为，在特有产中没有财物时提供的保证人仍应承担责任，因为只要担保约定如此，保证人也可以担保将来可能发生的诉讼。

<a id="15.1.50.1"></a>

**1.** 如果一名有权因特有产之诉起诉家父的债权人指定家父为继承人，由于计算法尔基迪亚份额时应考察死亡时的状况，因此应考察该时点的特有产。

<a id="15.1.50.2"></a>

**2.** 即使主人已经因特有产之诉被起诉，也可以接受他人为奴隶提供保证。因此，正如诉讼文书制作后奴隶付款，不能像诉讼文书尚未制作时那样请求返还；同理，此时接受保证人也有效，因为自然债务并未转化为诉讼债务；奴隶本人似乎也能够承担自然债务。

<a id="15.1.50.3"></a>

**3.** 他人的奴隶善意地为我服役时，从提提乌斯处借得钱款交给我，以使我释放他；我遂释放了他。债权人询问应对谁提起特有产之诉。我答复说，尽管通常由债权人选择被告，但在此情形下应起诉奴隶的主人；主人可以对我提起展示之诉，要求我展示为其取得、且未被用于据称为奴隶身份所作安排的那笔钱款。不应采纳这样的区分：若我未释放奴隶，钱款属于主人；既然释放已发生，钱款便被视为因我的财产事项而取得。因为该钱款更应被视为因与我有关的事务而交付给我，而不是从我的财产中取得。

### <a id="15.1.51"></a>15.1.51　斯凯沃拉《疑义解答》第二卷

奴隶对第三人享有债权时，主人被提起特有产之诉，并非在任何情形下都应按该债权金额受判决，因为请求债权所需费用以及执行结果都可能不确定，还应考虑判决后的时间经过，以及是否需要变卖财产。因此，如果主人愿意让与相应诉权，就应判其无责。有人说，对一名合伙人起诉时应计算全部特有产，因为原告可以对合伙人提起诉讼；但如果被告愿意提供诉权，结论也一样。在所有因持有诉权而被认为承担责任的人当中，授权原告行使诉权都属于适当履行。

### <a id="15.1.52"></a>15.1.52　保罗《疑义解答》第四卷

<a id="15.1.52.pr."></a>

**序言（pr.）** 有如下事实问题：某人一直以自由人身份管理监护事务，后来被判定为奴隶。若被监护人起诉其主人，能否从特有产中扣除主人所享有的债权？有敕答规定，被监护人的请求优先于该奴隶其他债权人的请求。如果可以扣除，那么债务是在该人仍以自由人身份行事时，还是之后产生，是否有区别？未适婚年龄者能否提起特有产之诉？我的答复是：家父或主人以家子或奴隶身份被提起特有产之诉时，不享有优先于其他人的特权。其他债权人的优先权则应予考虑：例如，家子是否取得嫁资或管理了监护事务？因此，对作为准监护人行事的奴隶也作出该敕答是正确的；又因为先行占有者通常处于较有利地位，其他债权人的诉权将被阻却。显然，如果奴隶以被监护人的财产登记债权，或将钱款存入钱箱，被监护人可以提起钱款返还之诉；如果奴隶已花用钱款，也可以对债务人提起准诉讼，因为该监护人无权处分这些钱款；任何监护人均应适用这一规则。我认为，奴隶何时开始欠主人债务并不重要，无论当时奴隶仍处于自由人身份，还是之后才欠债，均同。因为即使我借钱给提提乌斯的奴隶，后来成为他的主人，在有人对我提起特有产之诉时，我也可以扣除此前所借款项。问题究竟在哪里？既然不能提起特有产之诉，就应准许对主人提起准监护之诉；如此一来，该人原本视为自己财产的财物，应被视为特有产。

<a id="15.1.52.1"></a>

**1.** 如果嫁资交给家子，或者家子管理了监护事务，在特有产之诉中应考虑优先权；可以暂缓其他债权人的诉讼，或要求提供担保：若无优先权的债权人先行起诉，而后来有优先权的债权人对家父提起诉讼，先前债权人应返还已经取得的财物。

### <a id="15.1.53"></a>15.1.53　保罗《疑义解答》第十一卷

如果斯提库斯获释时，其特有产未被剥夺，应认为主人已将其授予斯提库斯；但斯提库斯只有在债务人向其让与诉权后，才能对债务人提起诉讼。

### <a id="15.1.54"></a>15.1.54　斯凯沃拉《答复录》第一卷

某人将若干农庄作为附属完整的地产遗赠给一名家子继承人，其中包括奴隶；这些奴隶曾欠主人债务。问题是，其他继承人能否对该继承人提起特有产之诉？答复：不能。

### <a id="15.1.55"></a>15.1.55　涅拉提乌斯《答复录》第一卷

我正在对其提起特有产之诉的人，被你以暴力带走。应考察你以暴力将其带走时，特有产中包含哪些财物。

### <a id="15.1.56"></a>15.1.56　保罗《评涅拉提乌斯》第二卷

我的奴隶代我的债务人向我作出承诺，该承诺应从特有产中扣除，但原债务人仍负有债务。不过，我们还要考虑，是否应认为代为承诺的债务人之债权由此成为特有产。保罗说：如果有人在特有产之诉中希望扣除该债权，那么该债权当然就成为特有产。

### <a id="15.1.57"></a>15.1.57　特里丰尼努《论疑难》第八卷

<a id="15.1.57.pr."></a>

**序言（pr.）** 如果仅以特有产为由提起诉讼的家子或奴隶，在诉讼终结前死亡，应考察其死亡时所拥有的特有产。

<a id="15.1.57.1"></a>

**1.** 尤利安写道，如果某人以遗嘱命令奴隶获释，并将特有产遗赠给该奴隶，应认为所遗赠的是奴隶取得自由时的特有产。因此，在遗产被接受之前以任何方式取得的特有产增益，均归获释者所有。

<a id="15.1.57.2"></a>

**2.** 但如果某人将奴隶的特有产遗赠给第三人，则应根据立遗嘱人的意思判断。较可信的观点是，遗赠的是死亡时属于特有产的财物，并包括遗产被接受前由特有产财物所产生的增益，例如女奴所生子女和牲畜所产幼畜；但赠与奴隶的财物，以及奴隶以自身劳务取得的财物，不属于遗赠对象。

### <a id="15.1.58"></a>15.1.58　斯凯沃拉《学说汇纂》第五卷

某人将若干农庄作为附属完整的地产遗赠给一名继承人，包括奴隶及其他财物，并将其中一切一并遗赠；这些奴隶因多种原因以及依据账簿往来均欠主人债务。问题是，其他继承人能否就奴隶所欠的钱款，对该继承人提起特有产之诉？答复：不能。
