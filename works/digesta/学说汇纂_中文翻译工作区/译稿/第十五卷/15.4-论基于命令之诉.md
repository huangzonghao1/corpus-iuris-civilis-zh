## 15.4.0　论基于命令之诉（*Quod iussu*）

### <a id="15.4.1"></a>15.4.1

**乌尔比安《评告示》第二十九卷**

<a id="15.4.1.pr."></a>

**序言（pr.）** 基于主人的命令而提起诉讼，依法应授予针对主人的全部责任之诉；因为在某种意义上，命令者本人就是订约的一方。

<a id="15.4.1.1"></a>

**1.** 所谓命令，无论是以见证方式作出、通过书信作出、口头作出或经由使者传达，无论是针对一项特定交易作出，还是概括作出，均应如此理解。因此，如果主人曾这样声明：“你愿意与我的奴隶斯蒂库斯办理什么交易，就办理什么，一切风险由我承担”，那么除非某项特定法律禁止相关事项，应视为主人已就一切事项作出命令。

<a id="15.4.1.2"></a>

**2.** 但是，我要问：在他人尚未据此提供信用之前，能否撤回这一命令？我认为可以，正如某人作出委任后，在合同订立之前因意思改变而撤回委任，并已通知我一样。

<a id="15.4.1.3"></a>

**3.** 此外，如果家父或主人作出委任，也应视为已经作出命令。

<a id="15.4.1.4"></a>

**4.** 主人在奴隶出具的书面债务凭证（*chirographum*）上签名，也应基于命令之诉承担责任。

<a id="15.4.1.5"></a>

**5.** 那么，如果某人为奴隶作保证人，又该如何？马尔凯鲁斯说，此人不基于命令之诉承担责任，因为他是以外人身份介入。他这样说，并不是因为此人依保证原因承担责任，而是因为作出命令与作保证是两回事。事实上，他还写道，即使保证行为无效，此人仍不因仿佛作出命令而承担责任。此说较为可取。

<a id="15.4.1.6"></a>

**6.** 如果某人追认其奴隶或家子所实施的行为，就应可对其提起基于命令之诉。

<a id="15.4.1.7"></a>

**7.** 如果未成年人主人作出命令，他当然不承担责任；但若其是在监护人同意下作出命令，则属例外。

<a id="15.4.1.8"></a>

**8.** 如果与奴隶订立交易，是依用益权人的命令；或者由善意占有该奴隶、并以为其为自己奴隶之人作出命令，马尔凯鲁斯认为，应对这些人授予基于命令之诉；我也赞同这一意见。

<a id="15.4.1.9"></a>

**9.** 如果与奴隶订立交易，是由青年人、精神失常者或浪费人的保佐人作出命令，拉贝奥认为，应对该奴隶所属之人授予基于命令之诉；由真正的代理人作出命令时，也应如此。但是，如果该代理人并非真正的代理人，拉贝奥说，诉讼反而应对其本人提起。

### <a id="15.4.2"></a>15.4.2

**保罗《评告示》第三十卷**

<a id="15.4.2.pr."></a>

**序言（pr.）** 如果依监护人的命令，向未成年人的奴隶提供了借款，我认为，只要该借款是为未成年人的利益而提供，就应对未成年人授予“因监护人命令而提起的诉讼”（*actio quod iussit tutor*）。

<a id="15.4.2.1"></a>

**1.** 如果向女奴提供借款，是依其主人的命令；或者向女儿提供借款，是依其父亲的命令，就应对这些命令者授予基于命令之诉。

<a id="15.4.2.2"></a>

**2.** 如果依我的命令与他人的奴隶订立了合同，而我后来又买下该奴隶，我不基于命令之诉承担责任；否则，一项自始无效的诉权就会因后来发生的事情而得到补正。

### <a id="15.4.3"></a>15.4.3

**乌尔比安《答复》第二卷**

主人命令他人以半利率向自己的奴隶贷出款项，其责任以命令范围为限；奴隶未经主人同意而设定负担的那些土地，不发生质押的效力。

### <a id="15.4.4"></a>15.4.4

**乌尔比安《评告示》第十卷**

如果依受命管理城市事务之人的命令，与该城市的奴隶订立了交易，庞波尼乌斯写道，可以对该受命管理者提起基于命令之诉。

### <a id="15.4.5"></a>15.4.5

**保罗《评普劳提乌斯著作》第四卷**

<a id="15.4.5.pr."></a>

**序言（pr.）** 如果主人或家父打算接受借款，并命令将款项交付给奴隶或家子，那么毫无疑问，可以直接对主人或家父本人提起返还之诉；而且在这种情形下，不适用基于命令之诉。

<a id="15.4.5.1"></a>

**1.** 如果奴隶的共有人中只有一人命令与该奴隶订立合同，仅该共有人承担责任；但如果两名共有人都作出命令，可以向其中任何一人请求全部给付，因为他们的情形类似于两名共同委任人。
