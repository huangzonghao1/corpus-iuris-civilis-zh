## 15.2.0　论特有产之诉何时适用一年期间（*Quando de peculio actio annalis est*）

### <a id="15.2.1"></a>15.2.1　乌尔比安《评告示》第二十九卷

<a id="15.2.1.pr."></a>

**序言（pr.）** 裁判官说：“对于曾受他人权力支配之人，在其死亡后，或者在其被解放出家父权、被释奴或被转让后，我仅就特有产，以及掌权人以恶意欺诈致使特有产减少的部分，自首次能够就该事提起诉讼之日起一年内，授予诉讼。”

<a id="15.2.1.1"></a>

**1.** 奴隶或家子仍受他人权力支配期间，特有产之诉不受期间限制；但其死亡，或者被解放出家父权、被释奴或被转让后，该诉即开始受期间限制，也就是仅有一年。

<a id="15.2.1.2"></a>

**2.** 这一年应按有效期间计算。因此，如果债务附有条件，尤利安写道，应从条件成就、得以请求给付时起算，而不是从被解放出家父权之日起算。

<a id="15.2.1.3"></a>

**3.** 裁判官在此情形下使诉讼受期间限制，理由充分：因为奴隶死亡或被转让后，特有产即告消灭，因此将责任延续一年已经足够。

<a id="15.2.1.4"></a>

**4.** 转让和释奴适用于奴隶，而不适用于家子；死亡则既适用于奴隶，也适用于家子；解放出家父权只适用于家子。即使家子未经过解放程序，而是以其他方式不再受他人权力支配，该诉也仅有一年期间。此外，如果家子因父亲死亡或被流放而取得自权人身份，父亲的继承人或国库应在一年内承担特有产之诉的责任。

<a id="15.2.1.5"></a>

**5.** 所谓转让，在此当然包括出售奴隶；出售人仍须在一年内承担特有产之诉的责任：

<a id="15.2.1.6"></a>

**6.** 同样，如果主人将奴隶赠与他人、与他人交换，或将其作为嫁资交付，也适用相同规则：

<a id="15.2.1.7"></a>

**7.** 将奴隶遗赠而未连同其特有产一并遗赠时，遗赠人的继承人也处于相同地位。如果奴隶连同特有产一并被遗赠，或者遗嘱命令释放该奴隶，就曾引发疑问。我认为，更妥当的意见是，不应对被释奴或获遗赠特有产的人提起特有产之诉。那么，继承人是否承担责任？凯基利乌斯说应当承担，因为特有产原在其手中，是他将其交给受遗赠人后才使自己脱离责任。佩加苏斯则说，继承人应要求获遗赠特有产之人提供担保，因为债权人会向该人主张权利。因此，如果继承人未取得担保便交付特有产，就可以对其提起诉讼。

<a id="15.2.1.8"></a>

**8.** 如果奴隶及其特有产已作为预遗赠留给继承人，而该继承人又受嘱托返还遗产，那么有人对其提起特有产之诉时，依马尔凯鲁斯讨论此事所得出的结论，继承人不得援用《特雷贝利安元老院决议》抗辩。斯凯沃拉说，受领返还遗产之人不承担责任，因为他既没有特有产，也未以欺诈方式使特有产减少。

<a id="15.2.1.9"></a>

**9.** 庞波尼在《评昆图斯·穆基乌斯》第六十一卷中写道，用益权消灭后一年内，也应准许对用益权人提起诉讼。

<a id="15.2.1.10"></a>

**10.** 拉贝奥曾讨论这样一种情形：儿子尚在世时，你误以为他已经死亡，遂提起一年期间内的诉讼；后来因一年已经经过，你被抗辩驳回。查明误认后，是否应允许你再次起诉？他说应予准许，但仅可提起特有产之诉，不可再提起利益归入之诉；因为前一诉讼中提起利益归入之诉是正当的，而一年的抗辩仅适用于特有产之诉，并不适用于利益归入之诉。

### <a id="15.2.2"></a>15.2.2　保罗《评告示》第三十卷

<a id="15.2.2.pr."></a>

**序言（pr.）** 家子死亡后一年内，可以对其父亲提起诉讼；而家子在世时，对其父亲本可提起不受期间限制的诉讼。因此，如果特有产之诉源于解除买卖（*redhibitio*），则家子死亡后仅可在六个月内提起；所有其他有期间限制的诉讼也应作相同处理。

<a id="15.2.2.1"></a>

**1.** 如果获贷金钱的奴隶落入敌方之手，只要其仍可能依复归权（*postliminium*）返回，针对主人的特有产之诉就不应因一年期满而终结。

### <a id="15.2.3"></a>15.2.3　庞波尼《评昆图斯·穆基乌斯》第四卷

即使奴隶已不复存在，且裁判官仅在一年内准许提起特有产之诉，有时仍须运用特有产的定义。此时仍应像特有产尚存一样，计算其增加和减少；尽管奴隶死亡或被释奴后，特有产已不复存在，仍应将其可能取得的利益计入，例如特有产孳息、牲畜所产幼畜或女奴所生子女；也应扣除其减少部分，例如动物死亡或因其他原因灭失。
