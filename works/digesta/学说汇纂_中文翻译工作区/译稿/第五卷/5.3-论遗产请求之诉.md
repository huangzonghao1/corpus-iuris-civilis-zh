## <a id="3"></a><a id="5.3"></a>5.3.0　论遗产请求之诉（*De hereditatis petitione*）

### <a id="5.3.1"></a>5.3.1　盖尤斯《评行省告示》第六卷

遗产依据旧法或新法归属于我们。依旧法，遗产可依据《十二表法》取得，也可依据依法订立的遗嘱取得。

### <a id="5.3.2"></a>5.3.2　乌尔比安《评告示》第十五卷

（无论我们是以自己的名义、亲自，还是通过他人成为继承人，

### <a id="5.3.3"></a>5.3.3　盖尤斯《评行省告示》第六卷

例如，如果我们命令一名处于我们权力之下、且已被指定为继承人的人接受遗产；又如，我们成为提提乌斯的继承人，而提提乌斯又是塞伊乌斯的继承人：正如我们可以主张提提乌斯的遗产属于我们一样，也可以主张塞伊乌斯的遗产属于我们。）或者通过无遗嘱继承（例如，因为我们是死者的自权继承人（*sui heredes*）或宗亲，或者因为我们释放了死者，或我们的父母曾释放死者）。新法下，凡依元老院决议或皇帝敕令而被召继承遗产者，均成为继承人。

### <a id="5.3.4"></a>5.3.4　保罗《评告示》第一卷

如果我对仅占有一项财物之人提起遗产请求之诉，而当时争议也仅涉及该项财物，那么该人后来开始占有的其他遗产财物，也应当返还。

### <a id="5.3.5"></a>5.3.5　乌尔比安《评告示》第十四卷

<a id="5.3.5.pr."></a>

**序言（pr.）** 神圣的庇护皇帝曾作出敕复：对有争议的遗产之占有人，在诉讼开始之前，应禁止其处分遗产中的任何财物；除非其愿意就全部遗产或其中各项财物的返还提供充分担保。至于案情经审查后，即使所提供的不是这种担保，而是通常的担保，裁判官也曾宣布：在诉讼开始之后仍可准许减少遗产，以免一概禁止减少遗产反而妨碍其他利益。例如，丧葬所需之物可以处分，因为裁判官准许为葬礼而减少遗产。同样，如果不在期限内清偿债务，质物将被出售，也可处分相关财物。家庭维持生计所需的费用，也可成为减少遗产的理由。对于会随时间而毁损的财物，裁判官也应准许出售。

<a id="5.3.5.1"></a>

**1.** 神圣的哈德良皇帝曾向特雷比乌斯·塞尔吉安努斯作出敕复：应令埃利乌斯·阿西亚提库斯就向其请求的遗产提供充分担保，并由此提出伪造指控。〔*et sic falsum dicat* 的主语及其所指程序不明。〕这是因为遗产请求之诉应予暂缓，直到伪造之诉审理完毕。

<a id="5.3.5.2"></a>

**2.** 关于遗产请求之诉的这些判决具有这样的效力：不得作出任何会对该诉讼产生先决影响的行为。

### <a id="5.3.6"></a>5.3.6　乌尔比安《评告示》第七十五卷

如果有人主张遗嘱是伪造的，而又依据该遗嘱请求遗赠，要么应在提供担保后给付遗赠，要么应查明该遗赠是否确实应当给付，即使遗嘱被指为伪造也如此。但是，如果伪造之诉已经开始审理，就不得向提起伪造指控之人给付遗赠。

### <a id="5.3.7"></a>5.3.7　乌尔比安《评告示》第十四卷

<a id="5.3.7.pr."></a>

**序言（pr.）** 如果有人主张自己依据遗嘱取得自由，法官就不应对自由身份作出判决，以免对审理遗嘱效力的案件产生先决影响；元老院曾如此决议。神圣的图拉真皇帝也曾作出敕复：关于自由身份的诉讼应予延期，直至关于遗嘱违背义务之诉提起或终结。

<a id="5.3.7.1"></a>

**1.** 只有在关于遗嘱违背义务之诉已经正式受理的情况下，关于自由身份的诉讼才应暂缓；若该诉尚未正式受理，则无须等待关于自由身份的诉讼。神圣的庇护皇帝也曾作出这样的敕复。曾有一名利基尼亚努斯就自己的身份受到质疑；为了不让其身份过早得到裁定，他不愿进入关于自由身份的诉讼，而声称自己将提起关于遗嘱违背义务之诉并请求遗产，因为他主张依据遗嘱取得自由和遗产。神圣的庇护皇帝说，如果利基尼亚努斯确实占有遗产，就更应当听取他的主张，因为他将就遗产提起诉讼；而是否提起关于遗嘱违背义务之诉，本由自称为所有权人的人决定。然而，在本案中，利基尼亚努斯本人并未提起关于遗嘱违背义务之诉，不应以该诉为借口，使奴役状态延续五年。当然，皇帝准许法官作初步审查，判断其是否确实善意请求审理遗嘱；如果法官认定是善意请求，就应设定一个较短期限；如果期限内仍未正式受理该诉，便应命令审理自由身份案件的法官履行其职责。

<a id="5.3.7.2"></a>

**2.** 神圣的庇护皇帝曾作出敕复：如果某人虽同时面临自由身份与遗产的争议，却并非主张依据遗嘱获得自由，而是主张由其他途径获得自由，或者是在遗嘱人仍在世时已被释奴，那么即使预计会提起遗嘱诉讼，也不应妨碍自由身份案件的审理。皇帝在敕复中还补充说，应当预先告知审理自由身份案件的法官，不得接受任何以遗嘱为依据、支持其自由身份的材料。

### <a id="5.3.8"></a>5.3.8　保罗《评告示》第十六卷

不知道遗嘱效力如何、但曾遵从死者遗愿之人，不因此被禁止主张法定继承权。

### <a id="5.3.9"></a>5.3.9　乌尔比安《评告示》第十五卷

一般而言，只有以继承人身份或以占有人身份占有遗产的人，或者占有遗产财物的人，才受遗产请求之诉追究。

### <a id="5.3.10"></a>5.3.10　盖尤斯《评行省告示》第六卷

<a id="5.3.10.pr."></a>

**序言（pr.）** 即使所占份额极小，

<a id="5.3.10.1"></a>

**1.** 因此，无论是继承全部遗产还是部分遗产之人，虽主张遗产全部或相应份额属于自己，但依裁判人职权，实际返还给他的，仅限于对方所占有的部分：如果他是全部遗产的继承人，就返还全部；如果他仅为部分继承人，就按其继承份额返还。

### <a id="5.3.11"></a>5.3.11　乌尔比安《评告示》第十五卷

<a id="5.3.11.pr."></a>

**序言（pr.）** 以继承人身份占有遗产的，是认为自己为继承人之人。但明知自己并非继承人者，是否也属于以继承人身份占有，尚有疑问。阿里安努斯在《禁令程序》第二卷中认为，此人也应承担责任；普罗库鲁斯写道，我们所适用的正是这一规则。此外，遗产占有人（*bonorum possessor*）似乎也属于以继承人身份占有。

<a id="5.3.11.1"></a>

**1.** 至于以占有人身份占有的，则是掠夺者；

### <a id="5.3.12"></a>5.3.12　乌尔比安《评告示》第六十七卷

如果有人被问及为何占有某物，他会回答“因为我占有”，而不会主张自己是继承人，甚至不会以谎言作此主张。

### <a id="5.3.13"></a>5.3.13　乌尔比安《评告示》第十五卷

<a id="5.3.13.pr."></a>

**序言（pr.）** 而且，他不能提出任何占有根据；因此，窃贼和强盗均受遗产请求之诉追究。

<a id="5.3.13.1"></a>

**1.** 以各种占有名义占有遗产之人，在此诉中都被视为以占有人身份占有，仿佛这些占有名义均附着于其占有。最后，即使其以买受为由占有，亦然：例如，我明知是从精神失常者处购买，仍以占有人身份占有。同样，以赠与为由占有时，也会涉及某人是否以占有人身份占有的问题，例如妻子或丈夫；我们赞同尤利安的意见，即此人以占有人身份占有，因此受遗产请求之诉追究。以嫁资为由占有的名义，也包括以占有人身份占有的情形；例如，我明知妻子尚未满十二岁，仍接受她作为嫁资交付的财物。此外，如果我明知遗赠所依据的事由虚假，却仍接受遗赠给付，我当然也将以占有人身份占有。

<a id="5.3.13.2"></a>

**2.** 返还遗产之人不得再因遗产请求之诉承担责任，除非其曾有欺诈行为，即明知其情仍返还遗产。遗产请求之诉也涵盖先前的欺诈；此时，行为人被视为因欺诈而停止占有。

<a id="5.3.13.3"></a>

**3.** 涅拉提乌斯在《札记》第六卷中写道，即使继承人不知道死者曾以继承人或占有人身份占有遗产，仍可向该继承人请求遗产。他在第七卷中也说，即使继承人以为某些财物属于归其继承的遗产，亦同。

<a id="5.3.13.4"></a>

**4.** 如果某人买下了整份遗产，是否应当对其授予遗产请求之诉的准诉，以免其因逐项诉讼而受到纠缠？出卖人当然要承担责任；但假设出卖人不复存在，或者仅以很低的价格出卖遗产，且其本人是善意占有人，是否应将救济扩及买受人？盖尤斯·卡西乌斯认为，应当授予准诉。

<a id="5.3.13.5"></a>

**5.** 如果继承人受命以低价出售遗产，并将其卖给提提乌斯，结论亦应相同。帕比尼安认为，应当准许对遗嘱信托受领人提起诉讼，因为对仅持有极少价款的继承人提起遗产请求之诉并不适当。

<a id="5.3.13.6"></a>

**6.** 如果某人受嘱在保留一定金额后返还遗产，结论也相同。但如果其受嘱先收取一定金额再返还遗产，帕比尼安认为，不应对继承人提起遗产请求之诉，因为其为履行附条件的安排而收取的款项，并非以继承人身份占有。萨宾努斯对准释奴持相反意见；后说更可取，因为该笔钱属于遗产。

<a id="5.3.13.7"></a>

**7.** 对于仅保留遗产孳息之人，也应作相同处理：此人同样受遗产请求之诉追究。

<a id="5.3.13.8"></a>

**8.** 如果某人明知遗产属于他人仍予购买，他是以占有人身份占有；因此有人认为，可以对其提起遗产请求之诉。我认为此说不正确：支付了价款的人并非掠夺者。不过，作为整体遗产的买受人，他仍应受遗产请求之诉的准诉追究。

<a id="5.3.13.9"></a>

**9.** 同样，如果某人从国库购买了一份被视为无人承受的遗产，对其授予准诉是最为公平的。

<a id="5.3.13.10"></a>

**10.** 马尔凯鲁斯《学说汇纂》第四卷记载：如果一名妇女将遗产作为嫁资交付，丈夫虽以嫁资为由占有该遗产，仍应受遗产请求之诉的准诉追究；马尔凯鲁斯还写道，该妇女本人也受直接诉追究，尤其是在婚姻已经解除的情况下。

<a id="5.3.13.11"></a>

**11.** 可以确定，继承人即使就死者曾以买受为由占有的财物，也受遗产请求之诉追究，仿佛其本人以继承人身份占有；至于死者曾以继承人或占有人身份占有的财物，继承人当然也要承担责任。

<a id="5.3.13.12"></a>

**12.** 如果某人以缺席者的名义占有遗产，而缺席者是否会追认尚不确定，我认为应当以缺席者的名义请求遗产，绝不能对占有人本人提起诉讼；因为以他人利益为着眼点而占有者，不被视为以继承人或占有人身份占有。除非有人主张：缺席者未予追认时，该代理人便如同掠夺者；在这种情况下，才可以对其本人提起诉讼。

<a id="5.3.13.13"></a>

**13.** 遗产不仅可以向占有遗产实体财物之人请求；即使某人什么也不占有，也可能成为请求对象。应当考察：如果未占有财物之人主动表示愿意应对遗产请求之诉，他是否承担责任。塞尔苏斯《学说汇纂》第四卷写道，此人因欺诈而承担责任；因为主动让自己成为该诉的对象，就是欺诈。马尔凯鲁斯在尤利安著作中概括赞同这一意见：任何主动接受遗产请求之诉的人，均应视为占有人并承担责任。

<a id="5.3.13.14"></a>

**14.** 同样，如果某人以欺诈方式使自己不再占有遗产，也受遗产请求之诉追究。但如果我因恶意欺诈而丧失占有后，另一人取得占有并愿意应对该诉，马尔凯鲁斯《学说汇纂》第四卷讨论了：对已停止占有之人的诉讼估价是否会因此落空。他认为，除非请求人仍有利益，否则该估价更可能落空；他说，如果现占有人愿意返还财物，那么估价无疑会落空。但是，如果先起诉的是以欺诈方式停止占有之人，该诉并不会使现占有人免责。

<a id="5.3.13.15"></a>

**15.** 此外，还可以向遗产债务人请求遗产，因为遗产债务人是权利的占有人；可以向权利占有人请求遗产，这一点已经确定。

### <a id="5.3.14"></a>5.3.14　保罗《评告示》第二十卷

债务究竟源于不法行为还是契约，并无区别。遗产债务人还包括向遗产中的奴隶作出允诺之人，以及在遗产被接受之前造成损害之人。

### <a id="5.3.15"></a>5.3.15　盖尤斯《评行省告示》第六卷

或者盗取了某项遗产财物。

### <a id="5.3.16"></a>5.3.16　乌尔比安《评告示》第十五卷

<a id="5.3.16.pr."></a>

**序言（pr.）** 如果遗产债务人的债务尚未到期，或者附有条件，而遗产请求之诉是针对该债务人提起的，就不应判令其承担责任。依奥克塔维努斯的意见，应当考察判决作出时的情况，确定期限是否已经届至；波庞波尼乌斯著作中也有记载。附条件的要式口约亦应作相同处理。如果期限尚未届至或条件尚未成就，法官应依其职权命其提供担保，保证在期限届至或条件成就时返还该债务。

<a id="5.3.16.1"></a>

**1.** 占有遗产财物价款之人，以及已从遗产债务人处收取款项之人，也受遗产请求之诉追究。

<a id="5.3.16.2"></a>

**2.** 因此，尤利安在《学说汇纂》第六卷中说，对已经请求遗产并取得诉讼估价款之人，仍可以提起遗产请求之诉。

<a id="5.3.16.3"></a>

**3.** 遗产不仅可以向死者的债务人请求，也可以向遗产债务人请求。最后，塞尔苏斯和尤利安都认为，可以向管理遗产事务之人请求遗产；但若其管理的是继承人的事务，则绝不能如此，因为不能向继承人的债务人请求遗产。

<a id="5.3.16.4"></a>

**4.** 尤利安写道，如果以继承人身份占有遗产之人被人以暴力驱逐，可以将其视为权利占有人而向其请求遗产，因为他享有“因暴力驱逐”禁令（*interdictum unde vi*），并且败诉后应当让出财物。驱逐他的人也受遗产请求之诉追究，因为其以占有人身份占有遗产财物。

<a id="5.3.16.5"></a>

**5.** 尤利安还说，无论出卖人出售财物时是否占有该物，也无论其已经收到价款还是仍可请求价款，都受遗产请求之诉追究；此人也应当转让其享有的诉权。

<a id="5.3.16.6"></a>

**6.** 尤利安写道，解放自由人以欺诈方式转让财物后，其保护人不得向受让人提起遗产请求之诉，因为该受让人应依《卡尔维西亚法》之诉对保护人承担责任；此人是保护人的债务人，而非遗产债务人。因此，也不得向因死亡原因受赠之人请求遗产。

<a id="5.3.16.7"></a>

**7.** 尤利安写道，如果某人基于遗嘱信托返还遗产或交付个别财物，可以向其请求遗产，因为其享有返还该等给付物的准契约返还请求权，因而相当于权利占有人。

<a id="5.3.16.8"></a>

**8.** 同样，如果某人基于遗嘱信托交付出售遗产财物所得的价款，也可以向其请求遗产，因为其可以请求返还该款。在这些情形下，他只须交付自己享有的诉权，因为相关财物仍然存在，请求人也可以通过对物之诉取回这些财物。

### <a id="5.3.17"></a>5.3.17　盖尤斯《评行省告示》第六卷

如果遗产占有人因依据遗嘱而自认为继承人，遂以自己的财产支付遗赠，而后来有人依无遗嘱继承取得该遗产，虽然占有人未能通过“遗产被追夺时返还遗赠”的要式口约保护自己，看起来是其自身的损失，但考虑到其可能在争议尚未发生时就已支付遗赠，因而未作担保，仍认为在遗产被追夺时应准许其请求返还。然而，在未提供担保的情况下仍准许返还，存在一种风险：受领遗赠之人无清偿能力，从而无法追回。因此，依照元老院决议的宗旨，应当给予其救济：占有人可以从遗产财物中扣留相应部分以满足自己，但须将其诉权让与请求人，由请求人自行承担风险提起这些诉讼。

### <a id="5.3.18"></a>5.3.18　乌尔比安《评告示》第十五卷

<a id="5.3.18.pr."></a>

**序言（pr.）** 还应当考察：如果遗产占有人通过银行家出售财物，并将所得钱款存于银行家处而遭受损失，是否受遗产请求之诉追究；因为他既不再占有钱款，也无法收回。拉贝奥认为此人应当承担责任，因为他自行承担风险，却不慎将钱款交由银行家保管。奥克塔维努斯则认为，他只须交付自己享有的诉权；因此，他应当仅就这些诉权受遗产请求之诉追究。我认为，对于恶意占有人，应采拉贝奥之见；至于善意占有人，则似应采奥克塔维努斯之见。

<a id="5.3.18.1"></a>

**1.** 如果有人在遗产请求之诉对其提起时，既未占有遗产财物，也未占有遗产权利，但之后取得了某物，是否应认为其受遗产请求之诉追究？塞尔苏斯《学说汇纂》第四卷正确地写道，应当判令此人承担责任，尽管他起初什么也没有占有。

<a id="5.3.18.2"></a>

**2.** 现在应当考察哪些事项属于遗产请求之诉的范围。人们认为，所有遗产财物都纳入此诉，无论是权利还是有体物，

### <a id="5.3.19"></a>5.3.19　保罗《评告示》第二十卷

<a id="5.3.19.pr."></a>

**序言（pr.）** 不仅遗产中的有体物属于此诉范围，不属于遗产、但其风险由继承人承担的物品也包括在内，例如死者所质押、借用或寄存的物品。对于质押物，另有特别的请求之诉，但仍可纳入遗产请求之诉；《普布利基亚法》之诉所及物品亦同。尽管对借用或寄存物通常很难提起诉讼，既然这些物品的风险由我们承担，令其返还仍属公平。

<a id="5.3.19.1"></a>

**1.** 如果继承人以买受人身份完成了取得时效，该物就不纳入遗产请求之诉；因为继承人，也就是请求人，可以对其提起对物之诉，占有人也没有任何抗辩可以援用。

<a id="5.3.19.2"></a>

**2.** 有些物品虽可由占有人主张留置，却不可由其提出请求，这些物品也属于遗产请求之诉的范围。例如，死者曾宣誓称请求人之物并非其所有，随后即已去世；这些物品也应当返还。甚至占有人因自身过失而使其灭失，也要就此承担责任。对掠夺者亦同，尽管他不因过失而承担责任；因为他也不应留置这些物品。

<a id="5.3.19.3"></a>

**3.** 我所知，地役权不属于遗产返还范围，因为对地役权无法像对有体物和孳息那样予以返还；但是，如果占有人不允许他人通行或驱赶牲畜，就应当通过专门之诉追究其责任。

### <a id="5.3.20"></a>5.3.20　乌尔比安《评告示》第十五卷

<a id="5.3.20.pr."></a>

**序言（pr.）** 同样，为遗产目的而购置的财物也属于遗产，例如奴隶、牲畜以及其他为遗产所必需而购置的物品。如果以遗产的钱款购置，当然属于遗产；如果并非以遗产的钱款购置，则应另行考察。我认为，如果购置对遗产有重大利益，这些物品也属于遗产，但继承人应返还其价款。

<a id="5.3.20.1"></a>

**1.** 但并非所有以遗产钱款购置的财物都纳入遗产请求之诉。最后，尤利安在《学说汇纂》第六卷中写道：占有人以遗产的钱款购买奴隶后，有人向其请求遗产；只有在购置该奴隶符合遗产利益时，该奴隶才纳入遗产请求之诉；如果占有人是为自己购置，则纳入此诉的只是价款。

<a id="5.3.20.2"></a>

**2.** 同样，如果有人出售了遗产中的土地，若其出售并无正当理由，土地本身及其孳息均纳入遗产请求之诉；但若其出售土地是为了清偿遗产债务，则纳入此诉的仅为价款。

<a id="5.3.20.3"></a>

**3.** 纳入遗产请求之诉的，不仅是死者死亡时已有的财物，之后增加到遗产中的财物也包括在内；因为遗产会增加，也会减少。接受遗产后增加的财物，如果来自遗产本身，我认为应归入遗产；如果来自外部，则不归入遗产，而归入占有人个人。所有孳息都会增加遗产，无论是在接受遗产之前还是之后取得。女奴所生子女当然也会增加遗产。

<a id="5.3.20.4"></a>

**4.** 我们已经说过，所有遗产诉权都纳入遗产请求之诉。于是产生疑问：这些诉权是否依其本来性质纳入，还是以其他方式纳入？例如，有一种诉权会因否认而增加数额；该诉是按其增加后的数额纳入，还是只按原数额纳入，例如《阿奎利亚法》之诉？尤利安在《学说汇纂》第六卷中写道，只须给付单倍额。

<a id="5.3.20.5"></a>

**5.** 尤利安还正确地说，如果遗产占有人在死者生前已因奴隶致害而被判承担责任，就不能在遗产请求之诉中通过交付致害奴隶而免除责任；因为只有在被判履行之前，才可以交付致害奴隶免除责任；诉讼正式受理之后，便不能再以交付致害奴隶免责。遗产请求之诉既已正式受理，便不得再如此免责。

<a id="5.3.20.6"></a>

**6.** 此外，我们还发现，关于遗产请求之诉、处分遗产财物、先前的欺诈以及孳息，已有许多讨论。既然元老院决议已经为此制定了规则，最好引述决议原文并逐句解释。原文如下：“三月十五日前一日，执政官昆图斯·尤利乌斯·巴尔布斯与普布利乌斯·尤文提乌斯·塞尔苏斯·提图斯·奥菲迪乌斯·奥埃努斯·塞维里亚努斯，就皇帝凯撒·哈德良·奥古斯都、最高统治者——他是皇帝图拉真·帕提库斯之子、神圣的涅尔瓦之孙——在最近一次三月诺纳节前第五日提出并写入呈文、说明其认为应如何处理的事项，发表如下意见；对此事项，他们决议如下：

<a id="5.3.20.6a"></a>

**6a.** “如果在国库请求取得农夫遗产中的失权份额之前，自以为是继承人的人已经出售了遗产，决议认为，出售遗产财物所得价款不应计收利息；类似案件也应遵照此规则处理。”

<a id="5.3.20.6b"></a>

**6b.** “同样决议：如果有人被请求返还遗产，且判决对其不利，即使遗产财物在请求遗产之前已经灭失或价值减少，他也应返还自己从出售这些遗产财物中取得的价款。”

<a id="5.3.20.6c"></a>

**6c.** “同样，那些明知财物不属于自己仍侵占的人，即使在诉讼正式受理之前已使自己不再占有，也应当如同仍在占有一样被判承担责任；但有正当理由认为财物属于自己的人，仅在其因此变得较为富有的范围内承担责任。”

<a id="5.3.20.6d"></a>

**6d.** “国库请求取得遗产的时间，应认定为某人首次知道国库向其请求该遗产之时；也就是说，首次向其送达通知，或者通过书信或告示传唤其到庭之时。以上为决议内容。”

因此，我们应当对元老院决议中的每一句话作出与之相应的解释。

<a id="5.3.20.7"></a>

**7.** 元老院说：“在国库请求取得失权份额之前。”当时确有国库请求取得失权份额的情形；但即使是请求取得全部遗产，该元老院决议也适用。即使国库请求取得无人承受的财产，或者基于任何其他原因取得了财产，该决议也适用：

<a id="5.3.20.8"></a>

**8.** 如果遗产是由市镇请求取得，也同样适用。

<a id="5.3.20.9"></a>

**9.** 毫无疑问，该元老院决议也适用于私人之间的遗产请求，尽管决议原本是针对公共案件作出的。

<a id="5.3.20.10"></a>

**10.** 我们适用该元老院决议的，不仅限于遗产，也包括军营特有财产或其他财产整体。

<a id="5.3.20.11"></a>

**11.** “请求取得遗产”之语，指某人知道遗产正被向其请求之时；从此时起，他便成为恶意占有人。“也就是说，首次送达通知之时。”那么，如果某人明知遗产正被请求，却无人向其送达通知，他是否应当就出售所得钱款支付利息？我认为仍应支付，因为他已经成为恶意占有人。再设想通知虽已送达，但本人并不知情，因为通知并非送达给他，而是送达给他的代理人：元老院要求向本人送达通知，因此这不会对其不利；除非代理人已经告知他。但如果代理人本来能够告知而没有告知，就不在此限。元老院并未要求说明由谁送达通知；因此，无论何人送达，均会产生不利后果。

<a id="5.3.20.12"></a>

**12.** 以上规则针对善意占有人，因为元老院说的是“自以为是继承人的人”。但是，如果某人明知遗产不属于自己仍予出售，纳入遗产请求之诉的当然不是价款，而是财物本身及其孳息。皇帝塞维鲁似乎在致凯勒尔的书信中，也对恶意占有人作了同样规定；然而，元老院决议所谈的是自以为是继承人的人。除非我们将其理解为涉及那些出售有利于遗产的财物——这些财物与其说为遗产带来收益，不如说增加了遗产负担。这样，请求人便可以自行选择对恶意占有人采用何种计算方式：请求返还财物本身及孳息，还是请求价款及争议发生后的利息。

<a id="5.3.20.13"></a>

**13.** 元老院决议虽然谈及自认为是继承人的人，但自认为是遗产占有人、正当的概括继受人，或认为遗产已返还给自己的人，也处于相同地位。

<a id="5.3.20.14"></a>

**14.** 帕比尼安在《问题集》第三卷中说，如果遗产占有人没有动用遗产中发现的钱款，就绝不能以利息为由对其提起诉讼。

<a id="5.3.20.15"></a>

**15.** 元老院说“出售财物所得价款”。“所得”应作如下理解：不仅指已经实际收取的价款，也包括虽未收取但本可以收取的价款。

<a id="5.3.20.16"></a>

**16.** 如果在遗产被请求之后才出售财物，该财物本身及其孳息均纳入此诉。但若所出售的财物本来不生孳息，或者会随时间毁损，而其售价又是合理的，请求人或许可以选择请求给付价款及利息。

<a id="5.3.20.17"></a>

**17.** 元老院说：“如果有人被请求返还遗产，且判决对其不利，则应返还其出售遗产财物所取得的价款，即使这些财物在遗产被请求之前已经灭失或价值减少。”善意占有人出售遗产财物后，无论是否实际收取价款，因为他享有请求价款的诉权，就应当给付该价款；但如果他仍享有该诉权，交付诉权即已足够。

<a id="5.3.20.18"></a>

**18.** 但是，如果占有人出售财物后，因买受人追夺而返还了所收取的价款，就不认为该价款曾归其取得。尽管有人可能认为，价款自始就不应纳入此诉，因为被出售的财物并非遗产财物；然而，元老院决议虽提到出售遗产中的财物，而非“遗产财物”，但仍不应命其返还，因为其手中已无任何所得。尤利安在《学说汇纂》第六卷中也写道，某人收取了本不应收取之款，不必返还；其支付了本不应支付之款，也不应在结算时计入。

<a id="5.3.20.19"></a>

**19.** 如果买卖被解除并返还标的物，该物当然仍属于遗产；已退还的价款则不纳入此诉。

<a id="5.3.20.20"></a>

**20.** 此外，如果遗产占有人因出售财物而对买受人负有债务，就应当以担保为其提供保障。

<a id="5.3.20.21"></a>

**21.** 即使财物已经灭失或价值减少，占有人仍应返还价款。但这是否仅适用于善意占有人，还是恶意占有人也适用？如果买受人仍占有财物，且财物既未灭失也未贬值，恶意占有人当然应当返还财物；如果无论如何都无法从买受人处取回财物，则应当给付依诉讼估价宣誓确定的金额。但如果财物已经灭失或价值减少，则应当给付其实际价款，因为如果请求人取得该物，也会将其出售，从而不会失去该物的真实价款。”

### <a id="5.3.21"></a>5.3.21　盖尤斯《评行省告示》第六卷

被视为灭失的，是已不复存在于自然界中的物；被视为减少的，则是因他人取得时效而脱离遗产的物。

### <a id="5.3.22"></a>5.3.22　保罗《评告示》第二十卷

如果善意占有人既持有原物，也持有价款——例如，他又买回了同一物——那么，如果他愿意返还原物而不返还价款，是否应当听从他？对于侵夺者，我们认为选择权应归原告。至于此处，是否应当听从占有人——即使原物已经变差，他仍愿意交付原物——而不听从要求价款的原告，因为这种要求似乎有失得体；还是应当考虑到占有人因遗产财产而增加了财富，故须返还超过原物价值的价款，尚待斟酌。哈德良神皇的敕答也这样说：“元老们，请审察：是否更为公平的是，占有人不得从中获利，而应返还其因他人之物所取得的价款？因为可以认为，所售遗产之物的价款已经取代该遗产之物，并且在某种意义上也成为遗产的一部分。”因此，占有人应当向原告返还原物，并返还因出售该物而取得的利益。

### <a id="5.3.23"></a>5.3.23　乌尔比安《评告示》第十五卷

<a id="5.3.23.pr."></a>

**序言（pr.）** 尚须考察，善意占有人是否必须返还全部价款，还是仅在其因此增加财富时才须返还。例如，设想他收取价款后将其丢失、花尽或赠与他人。“归于其手”一语确有歧义：它究竟仅指最初取得的款项，还是也包括目前仍然保有的款项？我认为，即使元老院决议的这一措辞有歧义，也应遵循其后续条款；只有在占有人因此增加财富时，才适用该决议。

<a id="5.3.23.1"></a>

**1.** 因此，如果占有人除价款外，还因迟延支付价款而收取了罚金，可以说，由于其整体上增加了财富，该罚金也应纳入返还范围，尽管元老院决议只提到价款。

### <a id="5.3.24"></a>5.3.24　保罗《评告示》第二十卷

但是，如果占有人是被暴力逐出的，他不应返还因原告无法取得该罚金而发生的罚金。同样，对方曾承诺：若其不到庭，便向占有人给付罚金；此项罚金也不应返还。〔译疑：本段 *poena ex eo commissam, quod eam actor habere non potest* 的责任主体与罚金归属关系较压缩，暂依字面处理。〕

### <a id="5.3.25"></a>5.3.25　乌尔比安《评告示》第十五卷

<a id="5.3.25.pr."></a>

**序言（pr.）** 如果占有人依据解除约款（*lex commissoria*）出售了物，也应作同样处理：他须交付因该约款而取得的利益。

<a id="5.3.25.1"></a>

**1.** 同样，如果他出售某物后用所得价款购买了另一物，遗产请求之诉所涉及的是价款，而非他已纳入自己财产中的另一物。但是，如果另一物的价值低于购买价款，那么他只在该物现有价值的范围内被视为增加了财富；正如他若已将价款花尽，就不被视为整体上增加了财富一样。

<a id="5.3.25.2"></a>

**2.** 元老院说：“侵占了明知不属于自己的财产之人，即使在诉讼成立前已采取措施使自己不再占有，也应如同仍在占有一样被判处。”这应理解为，遗产请求之诉也包括既往的欺诈，以及过失。因此，遗产请求之诉可以针对未向他人收取债款的人提起；也可以针对因时效届满而使自己免责的人提起；但前提是他本来能够收取该款。〔译疑：*ab alio non exegit vel a semet ipso, si tempore esset liberatus* 的关系较简略，译文依前后语义处理。〕

<a id="5.3.25.3"></a>

**3.** 元老院所说的“侵占财产之人”，指侵夺者，也就是明知遗产不属于自己，仍在没有任何占有权源的情况下侵占遗产的人。

<a id="5.3.25.4"></a>

**4.** 元老院还说，占有人应交付的不是其实际收取的孳息，而是其本应收取的孳息。

<a id="5.3.25.5"></a>

**5.** 元老院所说的是从一开始就怀有侵夺之意、进而占有遗产之人。如果某人起初具有正当的取得占有原因，后来才明知遗产与己无关，并开始像侵夺者那样行事，元老院决议似乎并未涉及此人。不过，我认为元老院决议的意旨也应适用于他；毕竟，一个人究竟从一开始就在遗产事务中欺诈行事，还是后来才开始如此，差别不大。

<a id="5.3.25.6"></a>

**6.** “明知财产不属于自己”究竟只指明知事实的人，还是也包括在法律上发生错误的人？例如，有人以为遗嘱依法成立，实际却无效；或者，在有另一顺位更优的近亲属时，他误以为遗产应归自己。我认为，只要没有欺诈，即使在法律上发生错误，也不应将此人视为侵夺者。

<a id="5.3.25.7"></a>

**7.** 元老院说“在诉讼成立前已采取措施”，之所以加上此语，是因为诉讼成立后，所有占有人都开始成为恶意占有人；实际上，争议一经提出，情形即是如此。尽管元老院决议提到诉讼成立，但争议发生后，所有占有人的地位也相同，并都按侵夺者对待。如今我们也依此法办理：受到催告的人，从此知道自己占有的物不属于自己。侵夺者即使在诉讼成立前，也要就其既往欺诈承担责任。

<a id="5.3.25.8"></a>

**8.** 元老院说：“应如同仍在占有一样判处。”这是有道理的：以欺诈手段使自己不再占有的人，应如同占有人一样被判处。无论他以欺诈手段停止占有，还是以欺诈手段拒绝接受占有，均属此列。无论物由他人占有，还是已全然不存在，该条款都适用。因此，如果另有占有人，遗产请求之诉可以同时针对二人提起；如果占有曾经辗转多人，所有这些人都承担责任。

<a id="5.3.25.9"></a>

**9.** 孳息应由现占有人单独交付，还是也应由以欺诈手段使自己不再占有的人交付？应当说，依照元老院决议，二人都承担责任。

<a id="5.3.25.10"></a>

**10.** 元老院决议的这些文字也允许对非占有人进行诉讼估价宣誓：因为对于以欺诈手段使自己不再占有的人，以及仍在占有的人，都可以就诉讼标的宣誓估价。

<a id="5.3.25.11"></a>

**11.** 元老院为善意占有人作了安排，使他们不至于承担全部损失，而只在其增加财富的范围内承担责任。因此，他们从遗产中支出的费用，以及在以为自己是在使用自己的财产时挥霍或丢失的东西，均无须返还。即使他们赠与了财物，也不视为因此增加财富，尽管受赠人基于自然义务负有回报他们的责任。但是，如果他们收到了回赠物（*antidwra*），应当说，他们在所收回赠物的范围内增加了财富；这可以视为一种交换。〔译注：底本以拉丁字母转写希腊语 *antidwra*。〕

<a id="5.3.25.12"></a>

**12.** 如果某人因期待遗产将归自己而更加奢侈地使用自己的财产，马尔切卢斯在《学说汇纂》第五卷中认为：只要他没有动用遗产，就不得从遗产中扣除任何款项。

<a id="5.3.25.13"></a>

**13.** 如果他借入金钱，情形也相同；这仿佛是他因自以为富有而使自己受了欺骗。

<a id="5.3.25.14"></a>

**14.** 不过，如果他将遗产中的物作为质物，还须考察遗产是否因此也算被动用；这一点难以确定，因为他本人因此负有债务。

<a id="5.3.25.15"></a>

**15.** 对于未因此增加财富的人，责任限制得如此严格：例如，有人以为自己是唯一继承人，在没有恶意欺诈的情况下花掉遗产的一半，马尔切卢斯在《学说汇纂》第四卷中讨论他是否不承担责任，因为他支出的财产并非属于自己，而是属于共同继承人。即使不是继承人的人将自己持有的一切都花尽，也毫无疑问不承担责任，因为他并未增加财富。对于本案，提出了三种看法：第一种认为他不承担责任；另一种认为他应返还全部剩余财产，仿佛他花掉的是自己的那一份；第三种认为所花掉的部分应由双方共同承担。他说，无论如何都应返还一些财产，但尚不确定应返还全部还是一部分。我仍认为，不必返还全部剩余财产，而只须返还其中的一半。〔译疑：本段列举三种意见处的句法压缩，三种处理方案的主语及相互关系待校。〕

<a id="5.3.25.16"></a>

**16.** 有人从遗产中支出了费用，这些费用应全部从遗产中扣除，还是应按其个人财产与遗产的比例分担？例如，他把遗产中的储藏物消耗殆尽，这项开支应全部归入遗产，还是有一部分也应由其个人财产承担？应以他在遗产交付给他之前通常会自行支出的数额，作为判断其增加财富的范围。因此，如果他因期待遗产而更奢侈地支出，就不应视为增加财富；对于他通常会有的固定支出，则应视为增加财富，因为即使他没有继承遗产，也会为日常生活支出一些费用。马尔库斯神皇在皮托多鲁斯一案中也作出裁断：皮托多鲁斯受托返还其从遗产中剩余的财产；被出售的财物并非为减少遗嘱信托而出售，其价款也未并入皮托多鲁斯的个人财产，因此该支出应同时从皮托多鲁斯自己的财产和遗产中扣除，而不能只从遗产中扣除。现在也应考察，依照马尔库斯神皇敕答，通常支出应从遗产还是仅从个人财产中扣除。较妥当的意见是：即使他没有成为继承人也会支出的费用，应从其个人财产中扣除。

<a id="5.3.25.17"></a>

**17.** 同样，如果善意占有人出售了某物，却未因价款而增加财富，那么，只要该物尚未被他人取得时效，原告能否向买受人请求返还该物？即使原告提出返还请求，买受人能否援用“原告与出卖人之间的判决不得损害遗产”的抗辩予以拒绝？因为该物价款似乎并未纳入遗产请求之诉，尽管买受人败诉后将转而向出卖人追偿。我认为，除非买受人可以向善意占有人追偿，否则可以请求返还该物。

<a id="5.3.25.17a"></a>

**17a.** 但是，如果出卖人愿意为遗产请求之诉应诉，并使自己如同占有人一样受诉，情形如何？此时，应从买受人的地位适用该抗辩。若该物是以低价售出，而原告已经取得了任何数额的价款，就更应当说可以依据该抗辩排除原告的请求。尤利安在《学说汇纂》第四卷中写道：如果占有人将从债务人处收取的债款支付给遗产请求人，债务人即获解除；无论收取债款的是善意占有人还是侵夺者，均依法律本身使债务人免责。

<a id="5.3.25.18"></a>

**18.** 遗产请求之诉虽为对物之诉，但其中也包含若干人身给付，例如从债务人处收取的款项以及价款。

<a id="5.3.25.19"></a>

**19.** 应当认为，为遗产请求之诉而制定的这项元老院决议，也适用于遗产分割之诉；否则便会出现荒谬结果：可以请求返还的物，却不能进行分割。

<a id="5.3.25.20"></a>

**20.** 群畜和牲畜所生的幼畜会增加遗产。

### <a id="5.3.26"></a>5.3.26　保罗《评告示》第二十卷

如果先有羊羔出生，随后又由这些羊羔生出其他羊羔，那么后者也应作为遗产的增益一并返还。

### <a id="5.3.27"></a>5.3.27　乌尔比安《评告示》第十五卷

<a id="5.3.27.pr."></a>

**序言（pr.）** 女奴所生的子女，以及这些子女再生的子女，虽不被视为孳息——因为购置女奴通常并非为了使其生育——但仍会增加遗产。既然这一切都成为遗产财产，毫无疑问，占有人若仍占有这些财产，或者在遗产请求提出后以欺诈手段使自己不再占有，均应返还。

<a id="5.3.27.1"></a>

**1.** 城市地产出租所收取的租金也应纳入返还范围，即使租金来自妓院亦然；因为许多体面之人的地产上也经营着妓院。

### <a id="5.3.28"></a>5.3.28　保罗《评告示》第二十卷

应当说，元老院决议之后，无论善意占有人还是侵夺者，均不得保有任何利益。

### <a id="5.3.29"></a>5.3.29　乌尔比安《评告示》第十五卷

佃户交付的租金显然相当于孳息。奴隶提供的劳务也属于同一情形；船舶与役畜的运费亦然。

### <a id="5.3.30"></a>5.3.30　保罗《评告示》第二十卷

尤利安写道，原告应当选择：是仅请求本金，还是连同利息一并请求，并承担债权无法收回的风险。然而，若依此办理，就不会遵循元老院的意旨，即善意占有人仅在其增加财富的范围内承担责任：如果原告选择金钱，而这些款项无法收回，又当如何？因此，应当说，善意占有人仅须作如下给付：或者返还本金及其利息——但以他也收取了利息为限；或者将全部债权及其请求权一并让与原告，使其自行承担仍有款项未获清偿的风险。

### <a id="5.3.31"></a>5.3.31　乌尔比安《评告示》第十五卷

<a id="5.3.31.pr."></a>

**序言（pr.）** 如果占有人向债权人支付了款项，应当允许他扣除该款，尽管依法律本身并未使遗产请求人免责；因为某人以自己的名义、而非以债务人的名义付款，并不能使债务人免责。因此，尤利安在《学说汇纂》第六卷中写道，占有人只有在提供担保、保证遗产请求人将获抗辩时，才能扣除该款。善意占有人是否也必须提供此种担保，尚须考察，因为他支付该款并未因此增加财富；除非他有返还请求权，从而因能够请求返还而被视为增加了财富。例如，他以为自己是继承人，便以自己的名义支付了款项。我认为，尤利安所说需要提供担保的仅是侵夺者，而非善意占有人；但善意占有人仍应让与相应的返还请求权。此外，如果遗产请求人被债权人起诉，他也应当援用抗辩。

<a id="5.3.31.1"></a>

**1.** 如果侵夺者本人享有一项债权，就不得扣除该债权；尤其是该债务仅基于自然法义务时更是如此。但是，如果该债务因罚金或其他原因而清偿，对遗产请求人有利，又当如何？可以说，遗产请求人本人应当已经清偿，或者本来就应当清偿。

<a id="5.3.31.2"></a>

**2.** 至于正当占有人，无疑应当扣除应向其清偿的债务。

<a id="5.3.31.3"></a>

**3.** 正如占有人可以扣除其已支出的费用，如果他本应支出却未支出，也应就自己的过失作出说明；善意占有人除外。因为在遗产请求提出之前，他既然把财产当作自己的，就如同疏忽了自己的财产，不受任何追责；但此后他本人也成为侵夺者。

<a id="5.3.31.4"></a>

**4.** 侵夺者不应因允许债务人免责、任其财产减少且未起诉他们而受责难，因为他本来没有对他们提起诉讼的权利。

<a id="5.3.31.5"></a>

**5.** 占有人收到他人清偿的款项后是否应当返还？应当说，无论他是善意占有人与否，均应返还。卡西乌斯和尤利安在《学说汇纂》第六卷中写道：如果他已返还，债务人即依法律本身免责。

### <a id="5.3.32"></a>5.3.32　保罗《评告示》第二十卷

通过奴隶取得的财物应当返还给继承人；这一规则适用于被释奴的遗产，以及提起遗嘱不当之诉的情形，因为在此期间，这些财物原属继承人的财产：

### <a id="5.3.33"></a>5.3.33　乌尔比安《评告示》第十五卷

<a id="5.3.33.pr."></a>

**序言（pr.）** 但奴隶若是依据遗嘱指定继承人的财产订立要式口约，则不在此限。

<a id="5.3.33.1"></a>

**1.** 尤利安写道：如果占有人出售了奴隶，若该奴隶并非遗产所必需，在遗产请求之诉中就应交付其价款；因为如果他没有出售，也应就该奴隶承担责任。若该奴隶为遗产所必需，且仍然活着，就应交付奴隶本人；若已死亡，或许连价款也无须交付。但是，尤利安写道，审理案件的法官不会允许占有人从价款中获利；这种意见较为妥当。

### <a id="5.3.34"></a>5.3.34　保罗《评告示》第二十卷

<a id="5.3.34.pr."></a>

**序言（pr.）** 我认为，可以向军人的家子请求返还依遗嘱归于我们的遗产。〔译疑：*filii familias militis* 的属格关系及遗产请求的相对人尚待结合上下文核定。〕

<a id="5.3.34.1"></a>

**1.** 如果奴隶或家子持有遗产中的财物，只要父亲或主人有能力返还，就可以向其请求返还遗产。确实，如果奴隶的特有产中有出售遗产财物所得的价款，尤利安也认为，可以将主人视为法律上的占有人，向其提起遗产请求之诉。

### <a id="5.3.35"></a>5.3.35　盖尤斯《评行省告示》第六卷

尤利安还说，即使奴隶尚未收到出售财物的价款，也可以将主人视为法律上的占有人，向其请求返还遗产；因为奴隶享有一项能够取得该款的诉权，而且该诉权即使在主人不知情时也归主人取得。

### <a id="5.3.36"></a>5.3.36　保罗《评告示》第二十卷

<a id="5.3.36.pr."></a>

**序言（pr.）** 如果遗产请求之诉是向持有价款的主人或父亲提起，那么在家子或奴隶死亡、奴隶获释或家子被解放后，是否须在一年内提起诉讼？主人或父亲能否扣除他人欠自己的债务？尤利安认为，较妥当的意见——普罗库鲁斯也这样答复——是诉权永久存续，不应扣除该债务，因为这里提起的并非特有产之诉，而是遗产请求之诉。若价款由奴隶或家子持有，这些说法是正确的。但如果遗产请求之所以向主人提起，是因为奴隶是债务人，就应当如同提起特有产之诉一样处理。毛里基亚努斯说，即使奴隶或家子已将从价款中取得的金钱花掉，也应作同样处理；不过，其他特有产仍可用于清偿。

<a id="5.3.36.1"></a>

**1.** 毫无疑问，也可以向家子请求返还遗产，因为他有能力返还，如同在请求出示之诉中一样。尤其是，某人原为家父并占有遗产，后来又使自己被他人收养为家子时，更可以向该家子请求返还遗产。

<a id="5.3.36.2"></a>

**2.** 如果占有人杀死了遗产中的奴隶，遗产请求之诉也应包括此项损害。但庞波尼乌斯说，原告应当选择：是请求判令占有人提供担保，保证不再依据《阿奎利亚法》起诉；还是不请求法官对该事项估价，从而保留完整的《阿奎利亚法》诉权。只有在继承人承受遗产之前奴隶已被杀死时，才有这种选择；如果奴隶是在此后被杀，相关诉权便成为原告自己的诉权，不纳入遗产请求之诉。

<a id="5.3.36.3"></a>

**3.** 如果侵夺者以欺诈手段不再占有某物，而该物以即使占有状态未变也会发生的方式灭失，那么，按照元老院决议的文字，侵夺者的处境反而优于善意占有人：因为侵夺者只要以欺诈手段停止占有，就应如同仍在占有一样被判处，决议并未补充规定物灭失时如何处理。但无疑，侵夺者不应比善意占有人处境更好。因此，如果该物以高于其价值的价格出售，原告应有权选择请求价款；否则侵夺者便会获利。

<a id="5.3.36.4"></a>

**4.** 善意占有人应在何时被视为增加了财富，尚有争议；但较妥当的意见是，应以作出判决之时为准。

<a id="5.3.36.5"></a>

**5.** 孳息的计算应扣除为取得、收取和保存孳息而支出的费用。自然理性不仅要求善意占有人如此处理，也要求侵夺者如此处理，萨宾亦持此说。

### <a id="5.3.37"></a>5.3.37　乌尔比安《评告示》第十五卷

如果善意占有人确已支出费用，却没有取得任何孳息，那么，将这些费用也纳入考量是最公平的。

### <a id="5.3.38"></a>5.3.38　保罗《评告示》第二十卷

对于其他必要费用和有益费用，可以作出区分：善意占有人可以扣除这些费用；侵夺者则应自责，因为他明知是在他人之物上支出费用。不过，较为宽厚的意见是，即使对侵夺者，也应考虑此类费用——原告不应因他人的损失获利——而且这本就属于法官职权范围，无须另行援用恶意欺诈抗辩。区别在于：善意占有人无论其支出所针对的物是否仍然存在，均可扣除费用，如同监护人或保佐人能够请求偿还费用；侵夺者则只有在该物因此改善时，才可扣除费用。

### <a id="5.3.39"></a>5.3.39　盖尤斯《评行省告示》第六卷

<a id="5.3.39.pr."></a>

**序言（pr.）** 必要或有益的费用，例如为修缮建筑物而支出的费用、在新植园地支出的费用，或者为奴隶支付诉讼估价的费用——因为这样做比交出奴隶本人更为有利——均属此类。显然，还有许多其他同类费用。〔译注：*novelleta* 暂译“新植园地”，词义指栽植幼树或葡萄藤的园地。〕

<a id="5.3.39.1"></a>

**1.** 不过，还须考察：如果我们是善意占有人，针对绘画、大理石制品及其他奢侈物品所支出的费用，是否也同样可以援用恶意欺诈抗辩。对于侵夺者，可以正当地说，他本不应在他人之物上支出不必要的费用；但应允许他取走那些可以拆除、且拆除不会损害物本身的物品。

### <a id="5.3.40"></a>5.3.40　保罗《评告示》第二十卷

<a id="5.3.40.pr."></a>

**序言（pr.）** 哈德良神皇敕答中还有这样一项规定：诉讼成立后，应向原告给付其在请求之时若遗产已返还便会取得的利益。有时，这一规定过于严苛。例如，若在诉讼成立后，奴隶、役畜或牲畜灭失，是否应当依敕答的文字判令占有人承担责任？因为若遗产在原告请求时即获返还，原告本可将这些财物出售。普罗库鲁斯认为，对个别诉讼应作此处理；卡西乌斯则持相反意见。普罗库鲁斯的意见适用于侵夺者，卡西乌斯的意见适用于善意占有人。占有人不应对物的自然灭失承担责任，也不应因担心承担这种风险，就轻率地放弃为自己的权利辩护。〔译疑：*specialibus petitionibus* 暂译“个别诉讼”，具体所指待核。〕

<a id="5.3.40.1"></a>

**1.** 侵夺者取得的孳息不归其所有，而是增加遗产；因此，他也应交付这些孳息所产生的孳息。善意占有人则仅须在返还遗产时交付使其增加财富的孳息，作为遗产的增益。

<a id="5.3.40.2"></a>

**2.** 占有人取得的诉权，在遗产被判归他人后也应返还；例如，占有人曾取得“因暴力驱逐”之禁令，或曾取得“基于暂时许可占有”之禁令。反过来说，如果占有人曾就损害发生前的危险提供担保，也应向占有人提供担保。

<a id="5.3.40.3"></a>

**3.** 法官的职权也包括处理奴隶责任诉讼：如果占有人愿意以交出奴隶的方式承担诺克萨责任，而该奴隶曾损害遗产财物或实施盗窃，就应判占有人免责；“以暴力或秘密方式实施行为”的禁令案件也采取同样处理。

### <a id="5.3.41"></a>5.3.41　盖尤斯《评行省告示》第六卷

<a id="5.3.41.pr."></a>

**序言（pr.）** 如果在遗产占有人被起诉时，他占有的财物较少，后来又取得其他财物的占有，那么无论他是在诉讼受理之前还是之后取得这些财物的占有，败诉后都应当将它们一并返还。如果他提供的保证人不足以担保诉讼标的，行省总督应命令他提供适当担保。反之，如果他后来占有的财物少于起初所占有的，只要这种情况并非因其欺诈所致，就其已停止占有的财物部分，应判其免责。

<a id="5.3.41.1"></a>

**1.** 尤利安说，死者曾接受质押的那些财物所生的孳息，也应计入。

### <a id="5.3.42"></a>5.3.42　乌尔比安《评告示》第六十七卷

如果遗产债务人拒绝清偿，并非因为他声称自己是继承人，而是因为他否认或怀疑遗产是否归请求遗产之人所有，那么他不受遗产请求之诉追究。

### <a id="5.3.43"></a>5.3.43　保罗《评普劳提乌斯》第二卷

在我从你处接受遗赠之后，我请求遗产。阿提利基努斯说，有些法学家认为，只有我返还遗赠，才应准许我对你提起遗产请求之诉。不过，我们还应考虑：遗产请求人是否只须在获得担保之后才返还遗赠；该担保应保证，若关于遗产的裁判对其不利，他能取回遗赠。因为在这种情形下，遗产占有人保留其已给付的遗赠并不公平；尤其是请求人并非恶意滥诉，而是因错误而请求遗产。莱利乌斯也赞同这一意见。不过，安敦尼皇帝曾作出敕复：对于依据遗嘱取得遗赠后又请求遗产之人，应在审查案情后拒绝其遗产请求；也就是说，只有在其明显恶意滥诉时才予拒绝。

### <a id="5.3.44"></a>5.3.44　雅沃雷努斯《摘自普劳提乌斯》第一卷

如果依据遗嘱取得遗赠之人请求遗产，而无论基于何种原因，该遗赠尚未返还，那么法官应依其职权处理：从应返还给胜诉人的遗产中扣除其已取得的遗赠。

### <a id="5.3.45"></a>5.3.45　塞尔苏斯《学说汇纂》第四卷

某人并未占有财物，却主动参加诉讼的，应判其承担责任；除非他能以明确无疑的证据证明，原告自诉讼开始时就知道他并未占有。因为如此一来，原告并未受其欺骗。凡依欺诈条款而使自己成为遗产请求之诉被告者，亦承担责任；具体应按原告因未受欺骗本可获得的利益确定诉讼估价。

### <a id="5.3.46"></a>5.3.46　莫德斯蒂努斯《论法律差异》第六卷

以默示信托方式约定将遗产返还给无受领资格之人的，应视同掠夺者。

### <a id="5.3.47"></a>5.3.47　莫德斯蒂努斯《答复》第八卷

卢基乌斯·提提乌斯在指控其亲属的遗嘱为伪造时未能胜诉。我问：他是否仍可就该遗嘱未依法作成且未依法署名提起诉讼？答：他在伪造指控中未能胜诉，并不因此被排除在主张该遗嘱未依法作成之外。

### <a id="5.3.48"></a>5.3.48　雅沃雷努斯《摘自卡西乌斯》第三卷

在遗产的诉讼估价中，应计入已售遗产的价款；如果遗产是为经营交易而出售的，还应计入遗产价值超过该价款的部分。若遗产是基于遗嘱信托而交付，则除此之外，仅应计入其善意取得的部分。

### <a id="5.3.49"></a>5.3.49　帕比尼安《疑义》第三卷

如果遗产的善意占有人愿意与遗产债务人或侵占遗产财物之人进行诉讼，应准许其这样做；尤其是在诉讼延误可能导致诉权消灭的危险存在时。遗产请求人则可以不受抗辩之虞而提起对物之诉。因为，占有人若怠于行事怎么办？若他知道自己不享有任何权利，又该如何？

### <a id="5.3.50"></a>5.3.50　帕比尼安《疑义》第六卷

<a id="5.3.50.pr."></a>

**序言（pr.）** 即使没有任何有体物，遗产在法律观念上仍然存在。

<a id="5.3.50.1"></a>

**1.** 如果善意占有人为履行死者所设条件而为其建造纪念墓，可以认为，死者的意愿在此也应得到遵从；但建造墓葬的费用不得超过合理数额，也不得超过遗嘱人所指示的数额。被剥夺遗产之人可以基于诈欺抗辩保留相关费用，也可以提起事务管理之诉请求返还，仿佛其管理了遗产事务。尽管依严格法，继承人并不因任何诉权而负有建造墓葬的义务，但仍可由皇帝或祭司长的权威促使其遵从死者最后意愿。

### <a id="5.3.51"></a>5.3.51　帕比尼安《答复》第二卷

<a id="5.3.51.pr."></a>

**序言（pr.）** 精神失常者的继承人应向其替补继承人或后顺位的旁系血亲交付中间期间的孳息；这些孳息显然使精神失常者因监护人的管理而增加了财产。应扣除为同一财产所支出的必要及有益费用。为精神失常者本人所支出的必要费用，也应扣除；但如果精神失常者另有足以维持生活的财产，则不在此限。

<a id="5.3.51.1"></a>

**1.** 对于请求遗产之后取得的孳息，不应支付利息；在遗产诉讼提起之前取得、并使遗产增加的孳息，情形则不同。

### <a id="5.3.52"></a>5.3.52　赫尔莫革尼安《法律摘要》第二卷

如果占有人从遗产中获得不正当收益，也必须返还，以免对法律作正当解释反而使占有人从不正当收益中获利。

### <a id="5.3.53"></a>5.3.53　保罗《评萨比努斯》第十卷

占有人为清偿遗产债务而处分财产固然属必要；如果其为遗产财物支出了必要费用，或者迟延将导致财物灭失或恶化，处分也属必要。

### <a id="5.3.54"></a>5.3.54　尤利安《学说汇纂》第六卷

<a id="5.3.54.pr."></a>

**序言（pr.）** 对于从国库购买遗产份额或整份遗产之人，准许其提起一项诉讼以追索遗产的全部财物，并非不公平；正如依据特雷贝利安元老院决议取得返还遗产之人，也获准提起遗产请求之诉。

<a id="5.3.54.1"></a>

**1.** 毫无疑问，债务人的继承人可以提起遗产请求之诉，以取得死者曾设定质押的财物。

<a id="5.3.54.2"></a>

**2.** 如果占有人的疏忽使城市或乡村地产状况恶化，例如葡萄园、果园或菜园的耕作方式偏离死者家父通常采用的方式，那么占有人应承担这些财物因状况恶化而产生的诉讼估价责任。

### <a id="5.3.55"></a>5.3.55　尤利安《学说汇纂》第六十卷

遗产被追夺后，遗产的善意占有人应将其依据《阿奎利亚法》所取得的赔偿加倍返还，而非仅返还单倍；因为他不应从其因遗产而取得之物中获利。

### <a id="5.3.56"></a>5.3.56　阿非利卡努斯《疑义》第四卷

遗产请求之诉提起后，占有人取得的孳息无论如何均应返还，即使请求人本不会取得这些孳息，也应如此。

### <a id="5.3.57"></a>5.3.57　涅拉提乌斯《札记》第七卷

同一人就同一遗产对两人分别应诉，而其中一案已经作出有利于一方的裁判时，通常会产生这样的疑问：是否应当要求其向该胜诉人返还遗产，其方式如同他未曾在针对另一人的诉讼中应诉一样？也就是说，如果后来又对另一人作出有利裁判，那么对其提起诉讼之人是否应获判免责，因为该人既不再占有遗产，也没有以恶意欺诈停止占有；他只是因先前败诉判决而已返还遗产。另一种看法是：既然也可能对另一人作出有利裁判，就只有在该人获得担保——使其在针对另一人的诉讼中受到保障——之后，才应令其返还遗产。但较妥当的做法是由法官依职权命胜诉人提供担保或保证，以救济败诉者；因为后来才开始执行裁判的人，在针对先前胜诉者时，仍保有其财物。

### <a id="5.3.58"></a>5.3.58　斯凯沃拉《学说汇纂》第三卷

一名由父亲解放为自权人的儿子，依其母亲遗嘱所设条件接受遗产。父亲在解放儿子之前曾占有该遗产，并取得孳息；父亲还从遗产中支出费用以维护儿子的荣誉。〔*cum esset senator* 的主语不明，可能指父亲或儿子担任元老。〕问题是：父亲愿意在扣除其为儿子支出的费用后返还遗产，儿子仍坚持请求遗产的，是否可以基于恶意诈欺抗辩而驳回其请求？答：即使不提出该抗辩，法官依职权也足以妥善处理。
