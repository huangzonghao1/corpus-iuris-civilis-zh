# D.5.3.21–40　《论遗产请求》分段译稿

> 底本：Mommsen–Krueger 拉丁文本，`source_html/d-05.htm`。本稿仅含 D.5.3.21–40。

### <a id="5.3.21"></a>5.3.21　盖尤斯《评行省告示》第六卷

被视为灭失的，是已不复存在于自然界中的物；被视为减少的，则是因他人取得时效而脱离遗产的物。

### <a id="5.3.22"></a>5.3.22　保罗《评告示》第二十卷

如果善意占有人既持有原物，也持有价款——例如，他又买回了同一物——那么，如果他愿意返还原物而不返还价款，是否应当听从他？对于侵夺者，我们认为选择权应归原告。至于此处，是否应当听从占有人——即使原物已经变差，他仍愿意交付原物——而不听从要求价款的原告，因为这种要求似乎有失得体；还是应当考虑到占有人因遗产财产而增加了财富，故须返还超过原物价值的价款，尚待斟酌。哈德良神皇的敕答也这样说：“元老们，请审察：是否更为公平的是，占有人不得从中获利，而应返还其因他人之物所取得的价款？因为可以认为，所售遗产之物的价款已经取代该遗产之物，并且在某种意义上也成为遗产的一部分。”因此，占有人应当向原告返还原物，并返还因出售该物而取得的利益。

### <a id="5.3.23"></a>5.3.23　乌尔比安《评告示》第十五卷

<a id="5.3.23.pr."></a>

**序言（pr.）** 尚须考察，善意占有人是否必须返还全部价款，还是仅在其因此增加财富时才须返还。例如，设想他收取价款后将其丢失、花尽或赠与他人。“归于其手”一语确有歧义：它究竟仅指最初取得的款项，还是也包括目前仍然保有的款项？我认为，即使元老院决议的这一措辞有歧义，也应遵循其后续条款；只有在占有人因此增加财富时，才适用该决议。

<a id="5.3.23.1"></a>

**1.** 因此，如果占有人除价款外，还因迟延支付价款而收取了罚金，可以说，由于其整体上增加了财富，该罚金也应纳入返还范围，尽管元老院决议只提到价款。

### <a id="5.3.24"></a>5.3.24　保罗《评告示》第二十卷

但是，如果占有人是被暴力逐出的，他不应返还因原告无法取得该罚金而发生的罚金。同样，对方曾承诺：若其不到庭，便向占有人给付罚金；此项罚金也不应返还。〔译疑：本段 *poena ex eo commissam, quod eam actor habere non potest* 的责任主体与罚金归属关系较压缩，暂依字面处理。〕

### <a id="5.3.25"></a>5.3.25　乌尔比安《评告示》第十五卷

<a id="5.3.25.pr."></a>

**序言（pr.）** 如果占有人依据解除约款（*lex commissoria*）出售了物，也应作同样处理：他须交付因该约款而取得的利益。

<a id="5.3.25.1"></a>

**1.** 同样，如果他出售某物后用所得价款购买了另一物，遗产请求之诉所涉及的是价款，而非他已纳入自己财产中的另一物。但是，如果另一物的价值低于购买价款，那么他只在该物现有价值的范围内被视为增加了财富；正如他若已将价款花尽，就不被视为整体上增加了财富一样。

<a id="5.3.25.2"></a>

**2.** 元老院说：“侵占了明知不属于自己的财产之人，即使在争讼程序确定前已采取措施使自己不再占有，也应如同仍在占有一样被判处。”这应理解为，遗产请求之诉也包括既往的欺诈，以及过失。因此，遗产请求之诉可以针对未向他人收取债款的人提起；也可以针对因时效届满而使自己免责的人提起；但前提是他本来能够收取该款。〔译疑：*ab alio non exegit vel a semet ipso, si tempore esset liberatus* 的关系较简略，译文依前后语义处理。〕

<a id="5.3.25.3"></a>

**3.** 元老院所说的“侵占财产之人”，指侵夺者，也就是明知遗产不属于自己，仍在没有任何占有权源的情况下侵占遗产的人。

<a id="5.3.25.4"></a>

**4.** 元老院还说，占有人应交付的不是其实际收取的孳息，而是其本应收取的孳息。

<a id="5.3.25.5"></a>

**5.** 元老院所说的是从一开始就怀有侵夺之意、进而占有遗产之人。如果某人起初具有正当的取得占有原因，后来才明知遗产与己无关，并开始像侵夺者那样行事，元老院决议似乎并未涉及此人。不过，我认为元老院决议的意旨也应适用于他；毕竟，一个人究竟从一开始就在遗产事务中欺诈行事，还是后来才开始如此，差别不大。

<a id="5.3.25.6"></a>

**6.** “明知财产不属于自己”究竟只指明知事实的人，还是也包括在法律上发生错误的人？例如，有人以为遗嘱依法成立，实际却无效；或者，在有另一顺位更优的近亲属时，他误以为遗产应归自己。我认为，只要没有欺诈，即使在法律上发生错误，也不应将此人视为侵夺者。

<a id="5.3.25.7"></a>

**7.** 元老院说“在争讼程序确定前已采取措施”，之所以加上此语，是因为争讼程序确定后，所有占有人都开始成为恶意占有人；实际上，争议一经提出，情形即是如此。尽管元老院决议提到争讼程序确定，但争议发生后，所有占有人的地位也相同，并都按侵夺者对待。如今我们也依此法办理：受到催告的人，从此知道自己占有的物不属于自己。侵夺者即使在争讼程序确定前，也要就其既往欺诈承担责任。

<a id="5.3.25.8"></a>

**8.** 元老院说：“应如同仍在占有一样判处。”这是有道理的：以欺诈手段使自己不再占有的人，应如同占有人一样被判处。无论他以欺诈手段停止占有，还是以欺诈手段拒绝接受占有，均属此列。无论物由他人占有，还是已全然不存在，该条款都适用。因此，如果另有占有人，遗产请求之诉可以同时针对二人提起；如果占有曾经辗转多人，所有这些人都承担责任。

<a id="5.3.25.9"></a>

**9.** 孳息应由现占有人单独交付，还是也应由以欺诈手段使自己不再占有的人交付？应当说，依照元老院决议，二人都承担责任。

<a id="5.3.25.10"></a>

**10.** 元老院决议的这些文字也允许对非占有人进行诉讼估价宣誓：因为对于以欺诈手段使自己不再占有的人，以及仍在占有的人，都可以就诉讼标的宣誓估价。

<a id="5.3.25.11"></a>

**11.** 元老院为善意占有人作了安排，使他们不至于承担全部损失，而只在其增加财富的范围内承担责任。因此，他们从遗产中支出的费用，以及在以为自己是在使用自己的财产时挥霍或丢失的东西，均无须返还。即使他们赠与了财物，也不视为因此增加财富，尽管受赠人基于自然义务负有回报他们的责任。但是，如果他们收到了回赠物（*antidwra*），应当说，他们在所收回赠物的范围内增加了财富；这可以视为一种交换。〔译注：底本以拉丁字母转写希腊语 *antidwra*。〕

<a id="5.3.25.12"></a>

**12.** 如果某人因期待遗产将归自己而更加奢侈地使用自己的财产，马尔切卢斯在《学说汇纂》第五卷中认为：只要他没有动用遗产，就不得从遗产中扣除任何款项。

<a id="5.3.25.13"></a>

**13.** 如果他借入金钱，情形也相同；这仿佛是他因自以为富有而使自己受了欺骗。

<a id="5.3.25.14"></a>

**14.** 不过，如果他将遗产中的物作为质物，还须考察遗产是否因此也算被动用；这一点难以确定，因为他本人因此负有债务。

<a id="5.3.25.15"></a>

**15.** 对于未因此增加财富的人，责任限制得如此严格：例如，有人以为自己是唯一继承人，在没有恶意欺诈的情况下花掉遗产的一半，马尔切卢斯在《学说汇纂》第四卷中讨论他是否不承担责任，因为他支出的财产并非属于自己，而是属于共同继承人。即使不是继承人的人将自己持有的一切都花尽，也毫无疑问不承担责任，因为他并未增加财富。对于本案，提出了三种看法：第一种认为他不承担责任；另一种认为他应返还全部剩余财产，仿佛他花掉的是自己的那一份；第三种认为所花掉的部分应由双方共同承担。他说，无论如何都应返还一些财产，但尚不确定应返还全部还是一部分。我仍认为，不必返还全部剩余财产，而只须返还其中的一半。〔译疑：本段列举三种意见处的句法压缩，三种处理方案的主语及相互关系待校。〕

<a id="5.3.25.16"></a>

**16.** 有人从遗产中支出了费用，这些费用应全部从遗产中扣除，还是应按其个人财产与遗产的比例分担？例如，他把遗产中的储藏物消耗殆尽，这项开支应全部归入遗产，还是有一部分也应由其个人财产承担？应以他在遗产交付给他之前通常会自行支出的数额，作为判断其增加财富的范围。因此，如果他因期待遗产而更奢侈地支出，就不应视为增加财富；对于他通常会有的固定支出，则应视为增加财富，因为即使他没有继承遗产，也会为日常生活支出一些费用。马尔库斯神皇在皮托多鲁斯一案中也作出裁断：皮托多鲁斯受托返还其从遗产中剩余的财产；被出售的财物并非为减少遗嘱信托而出售，其价款也未并入皮托多鲁斯的个人财产，因此该支出应同时从皮托多鲁斯自己的财产和遗产中扣除，而不能只从遗产中扣除。现在也应考察，依照马尔库斯神皇敕答，通常支出应从遗产还是仅从个人财产中扣除。较妥当的意见是：即使他没有成为继承人也会支出的费用，应从其个人财产中扣除。

<a id="5.3.25.17"></a>

**17.** 同样，如果善意占有人出售了某物，却未因价款而增加财富，那么，只要该物尚未被他人取得时效，原告能否向买受人请求返还该物？即使原告提出返还请求，买受人能否援用“原告与出卖人之间的判决不得损害遗产”的抗辩予以拒绝？因为该物价款似乎并未纳入遗产请求之诉，尽管买受人败诉后将转而向出卖人追偿。我认为，除非买受人可以向善意占有人追偿，否则可以请求返还该物。

<a id="5.3.25.17a"></a>

**17a.** 但是，如果出卖人愿意为遗产请求之诉应诉，并使自己如同占有人一样受诉，情形如何？此时，应从买受人的地位适用该抗辩。若该物是以低价售出，而原告已经取得了任何数额的价款，就更应当说可以依据该抗辩排除原告的请求。尤利安在《学说汇纂》第四卷中写道：如果占有人将从债务人处收取的债款支付给遗产请求人，债务人即获解除；无论收取债款的是善意占有人还是侵夺者，均依法律本身使债务人免责。

<a id="5.3.25.18"></a>

**18.** 遗产请求之诉虽为对物之诉，但其中也包含若干人身给付，例如从债务人处收取的款项以及价款。

<a id="5.3.25.19"></a>

**19.** 应当认为，为遗产请求之诉而制定的这项元老院决议，也适用于遗产分割之诉；否则便会出现荒谬结果：可以请求返还的物，却不能进行分割。

<a id="5.3.25.20"></a>

**20.** 群畜和牲畜所生的幼畜会增加遗产。

### <a id="5.3.26"></a>5.3.26　保罗《评告示》第二十卷

如果先有羊羔出生，随后又由这些羊羔生出其他羊羔，那么后者也应作为遗产的增益一并返还。

### <a id="5.3.27"></a>5.3.27　乌尔比安《评告示》第十五卷

<a id="5.3.27.pr."></a>

**序言（pr.）** 女奴所生的子女，以及这些子女再生的子女，虽不被视为孳息——因为购置女奴通常并非为了使其生育——但仍会增加遗产。既然这一切都成为遗产财产，毫无疑问，占有人若仍占有这些财产，或者在遗产请求提出后以欺诈手段使自己不再占有，均应返还。

<a id="5.3.27.1"></a>

**1.** 城市地产出租所收取的租金也应纳入返还范围，即使租金来自妓院亦然；因为许多体面之人的地产上也经营着妓院。

### <a id="5.3.28"></a>5.3.28　保罗《评告示》第二十卷

应当说，元老院决议之后，无论善意占有人还是侵夺者，均不得保有任何利益。

### <a id="5.3.29"></a>5.3.29　乌尔比安《评告示》第十五卷

佃户交付的租金显然相当于孳息。奴隶提供的劳务也属于同一情形；船舶与役畜的运费亦然。

### <a id="5.3.30"></a>5.3.30　保罗《评告示》第二十卷

尤利安写道，原告应当选择：是仅请求本金，还是连同利息一并请求，并承担债权无法收回的风险。然而，若依此办理，就不会遵循元老院的意旨，即善意占有人仅在其增加财富的范围内承担责任：如果原告选择金钱，而这些款项无法收回，又当如何？因此，应当说，善意占有人仅须作如下给付：或者返还本金及其利息——但以他也收取了利息为限；或者将全部债权及其请求权一并让与原告，使其自行承担仍有款项未获清偿的风险。

### <a id="5.3.31"></a>5.3.31　乌尔比安《评告示》第十五卷

<a id="5.3.31.pr."></a>

**序言（pr.）** 如果占有人向债权人支付了款项，应当允许他扣除该款，尽管依法律本身并未使遗产请求人免责；因为某人以自己的名义、而非以债务人的名义付款，并不能使债务人免责。因此，尤利安在《学说汇纂》第六卷中写道，占有人只有在提供担保、保证遗产请求人将获抗辩时，才能扣除该款。善意占有人是否也必须提供此种担保，尚须考察，因为他支付该款并未因此增加财富；除非他有返还请求权，从而因能够请求返还而被视为增加了财富。例如，他以为自己是继承人，便以自己的名义支付了款项。我认为，尤利安所说需要提供担保的仅是侵夺者，而非善意占有人；但善意占有人仍应让与相应的返还请求权。此外，如果遗产请求人被债权人起诉，他也应当援用抗辩。

<a id="5.3.31.1"></a>

**1.** 如果侵夺者本人享有一项债权，就不得扣除该债权；尤其是该债务仅基于自然法义务时更是如此。但是，如果该债务因罚金或其他原因而清偿，对遗产请求人有利，又当如何？可以说，遗产请求人本人应当已经清偿，或者本来就应当清偿。

<a id="5.3.31.2"></a>

**2.** 至于正当占有人，无疑应当扣除应向其清偿的债务。

<a id="5.3.31.3"></a>

**3.** 正如占有人可以扣除其已支出的费用，如果他本应支出却未支出，也应就自己的过失作出说明；善意占有人除外。因为在遗产请求提出之前，他既然把财产当作自己的，就如同疏忽了自己的财产，不受任何追责；但此后他本人也成为侵夺者。

<a id="5.3.31.4"></a>

**4.** 侵夺者不应因允许债务人免责、任其财产减少且未起诉他们而受责难，因为他本来没有对他们提起诉讼的权利。

<a id="5.3.31.5"></a>

**5.** 占有人收到他人清偿的款项后是否应当返还？应当说，无论他是善意占有人与否，均应返还。卡西乌斯和尤利安在《学说汇纂》第六卷中写道：如果他已返还，债务人即依法律本身免责。

### <a id="5.3.33"></a>5.3.33　乌尔比安《评告示》第十五卷

<a id="5.3.33.pr."></a>

**序言（pr.）** 但奴隶若是依据遗嘱指定继承人的财产订立要式口约，则不在此限。

<a id="5.3.33.1"></a>

**1.** 尤利安写道：如果占有人出售了奴隶，若该奴隶并非遗产所必需，在遗产请求之诉中就应交付其价款；因为如果他没有出售，也应就该奴隶承担责任。若该奴隶为遗产所必需，且仍然活着，就应交付奴隶本人；若已死亡，或许连价款也无须交付。但是，尤利安写道，审理案件的法官不会允许占有人从价款中获利；这种意见较为妥当。

### <a id="5.3.34"></a>5.3.34　保罗《评告示》第二十卷

<a id="5.3.34.pr."></a>

**序言（pr.）** 我认为，可以向军人的家子请求返还依遗嘱归于我们的遗产。〔译疑：*filii familias militis* 的属格关系及遗产请求的相对人尚待结合上下文核定。〕

<a id="5.3.34.1"></a>

**1.** 如果奴隶或家子持有遗产中的财物，只要父亲或主人有能力返还，就可以向其请求返还遗产。确实，如果奴隶的特有产中有出售遗产财物所得的价款，尤利安也认为，可以将主人视为法律上的占有人，向其提起遗产请求之诉。

### <a id="5.3.35"></a>5.3.35　盖尤斯《评行省告示》第六卷

尤利安还说，即使奴隶尚未收到出售财物的价款，也可以将主人视为法律上的占有人，向其请求返还遗产；因为奴隶享有一项能够取得该款的诉权，而且该诉权即使在主人不知情时也归主人取得。

### <a id="5.3.36"></a>5.3.36　保罗《评告示》第二十卷

<a id="5.3.36.pr."></a>

**序言（pr.）** 如果遗产请求之诉是向持有价款的主人或父亲提起，那么在家子或奴隶死亡、奴隶获释或家子被解放后，是否须在一年内提起诉讼？主人或父亲能否扣除他人欠自己的债务？尤利安认为，较妥当的意见——普罗库鲁斯也这样答复——是诉权永久存续，不应扣除该债务，因为这里提起的并非特有产之诉，而是遗产请求之诉。若价款由奴隶或家子持有，这些说法是正确的。但如果遗产请求之所以向主人提起，是因为奴隶是债务人，就应当如同提起特有产之诉一样处理。毛里基亚努斯说，即使奴隶或家子已将从价款中取得的金钱花掉，也应作同样处理；不过，其他特有产仍可用于清偿。

<a id="5.3.36.1"></a>

**1.** 毫无疑问，也可以向家子请求返还遗产，因为他有能力返还，如同在请求出示之诉中一样。尤其是，某人原为家父并占有遗产，后来又使自己被他人收养为家子时，更可以向该家子请求返还遗产。

<a id="5.3.36.2"></a>

**2.** 如果占有人杀死了遗产中的奴隶，遗产请求之诉也应包括此项损害。但庞波尼乌斯说，原告应当选择：是请求判令占有人提供担保，保证不再依据《阿奎利亚法》起诉；还是不请求法官对该事项估价，从而保留完整的《阿奎利亚法》诉权。只有在继承人承受遗产之前奴隶已被杀死时，才有这种选择；如果奴隶是在此后被杀，相关诉权便成为原告自己的诉权，不纳入遗产请求之诉。

<a id="5.3.36.3"></a>

**3.** 如果侵夺者以欺诈手段不再占有某物，而该物以即使占有状态未变也会发生的方式灭失，那么，按照元老院决议的文字，侵夺者的处境反而优于善意占有人：因为侵夺者只要以欺诈手段停止占有，就应如同仍在占有一样被判处，决议并未补充规定物灭失时如何处理。但无疑，侵夺者不应比善意占有人处境更好。因此，如果该物以高于其价值的价格出售，原告应有权选择请求价款；否则侵夺者便会获利。

<a id="5.3.36.4"></a>

**4.** 善意占有人应在何时被视为增加了财富，尚有争议；但较妥当的意见是，应以作出判决之时为准。

<a id="5.3.36.5"></a>

**5.** 孳息的计算应扣除为取得、收取和保存孳息而支出的费用。自然理性不仅要求善意占有人如此处理，也要求侵夺者如此处理，萨宾亦持此说。

### <a id="5.3.37"></a>5.3.37　乌尔比安《评告示》第十五卷

如果善意占有人确已支出费用，却没有取得任何孳息，那么，将这些费用也纳入考量是最公平的。

### <a id="5.3.38"></a>5.3.38　保罗《评告示》第二十卷

对于其他必要费用和有益费用，可以作出区分：善意占有人可以扣除这些费用；侵夺者则应自责，因为他明知是在他人之物上支出费用。不过，较为宽厚的意见是，即使对侵夺者，也应考虑此类费用——原告不应因他人的损失获利——而且这本就属于法官职权范围，无须另行援用恶意欺诈抗辩。区别在于：善意占有人无论其支出所针对的物是否仍然存在，均可扣除费用，如同监护人或保佐人能够请求偿还费用；侵夺者则只有在该物因此改善时，才可扣除费用。

### <a id="5.3.39"></a>5.3.39　盖尤斯《评行省告示》第六卷

<a id="5.3.39.pr."></a>

**序言（pr.）** 必要或有益的费用，例如为修缮建筑物而支出的费用、在新植园地支出的费用，或者为奴隶支付诉讼估价的费用——因为这样做比交出奴隶本人更为有利——均属此类。显然，还有许多其他同类费用。〔译注：*novelleta* 暂译“新植园地”，词义指栽植幼树或葡萄藤的园地。〕

<a id="5.3.39.1"></a>

**1.** 不过，还须考察：如果我们是善意占有人，针对绘画、大理石制品及其他奢侈物品所支出的费用，是否也同样可以援用恶意欺诈抗辩。对于侵夺者，可以正当地说，他本不应在他人之物上支出不必要的费用；但应允许他取走那些可以拆除、且拆除不会损害物本身的物品。

### <a id="5.3.40"></a>5.3.40　保罗《评告示》第二十卷

<a id="5.3.40.pr."></a>

**序言（pr.）** 哈德良神皇敕答中还有这样一项规定：争讼程序确定后，应向原告给付其在请求之时若遗产已返还便会取得的利益。有时，这一规定过于严苛。例如，若在争讼程序确定后，奴隶、役畜或牲畜灭失，是否应当依敕答的文字判令占有人承担责任？因为若遗产在原告请求时即获返还，原告本可将这些财物出售。普罗库鲁斯认为，对个别诉讼应作此处理；卡西乌斯则持相反意见。普罗库鲁斯的意见适用于侵夺者，卡西乌斯的意见适用于善意占有人。占有人不应对物的自然灭失承担责任，也不应因担心承担这种风险，就轻率地放弃为自己的权利辩护。〔译疑：*specialibus petitionibus* 暂译“个别诉讼”，具体所指待核。〕

<a id="5.3.40.1"></a>

**1.** 侵夺者取得的孳息不归其所有，而是增加遗产；因此，他也应交付这些孳息所产生的孳息。善意占有人则仅须在返还遗产时交付使其增加财富的孳息，作为遗产的增益。

<a id="5.3.40.2"></a>

**2.** 占有人取得的诉权，在遗产被判归他人后也应返还；例如，占有人曾取得 *interdictum unde vi*（“因暴力驱逐”禁令），或因以暂时许可方式交付财物而取得相应禁令。〔译疑：*aut quod precario concessit* 省略所指的禁令，暂依 *interdictum quod precario* 理解。〕反过来说，如果占有人曾就损害发生前的危险提供担保，也应向占有人提供担保。

<a id="5.3.40.3"></a>

**3.** 法官的职权也包括处理奴隶责任诉讼：如果占有人愿意以交出奴隶的方式承担诺克萨责任，而该奴隶曾损害遗产财物或实施盗窃，就应判占有人免责；“以暴力或秘密方式实施行为”的禁令案件也采取同样处理。
