## <a id="1"></a><a id="5.1"></a>5.1　论诉讼应在何处提起及何地应诉

*De iudiciis: ubi quisque agere vel conveniri debeat*

### <a id="5.1.1"></a>5.1.1　乌尔比安《评告示》第二卷

如果有人自愿服从某人的管辖并表示同意，那么，对于同意接受管辖的当事人，无论是主持法庭还是享有其他管辖权的任何法官，均有管辖权。

### <a id="5.1.2"></a>5.1.2　乌尔比安《评告示》第三卷

<a id="5.1.2.pr."></a>

**序言（pr.）** 明知自己不受某人的管辖，却仍同意接受其管辖者，视为已经同意。反之，如果当事人误以为某人享有管辖权，则该人并不因此取得管辖权：正如尤利安在《学说汇纂》第一卷中所写，当事人的错误不构成同意。又或者，当事人误将他人当作法务裁判官，此种错误同样不能产生管辖权。又或者，诉讼一方虽曾表示反对，却因法务裁判官的权力而被迫接受管辖，则并不存在有效管辖权。

<a id="5.1.2.1"></a>

**1.** 当事人之间的同意是否已经足够，还是还须法务裁判官本人同意？《尤利娅审判法》规定“除非私人当事人之间达成协议”，因此私人当事人之间的同意已经足够。由此，如果私人当事人同意，而法务裁判官并不知道他们已同意、仍以为自己享有管辖权，是否符合该法，尚须考察；我认为，可以主张此时仍属其管辖。

<a id="5.1.2.2"></a>

**2.** 如果某法官仅在一定期间内获任命，而所有诉讼当事人均同意延长其任期，除非皇帝以特别命令禁止延长，法官得以延长原先应当审结案件的期限。

<a id="5.1.2.3"></a>

**3.** 对于使节，就其在出使前订立的契约；以及因作证而被召来者、被召来担任法官者，或被派往行省者，均赋予其回返本土的权利。对于自行提起上诉的人，也不得强令其在为办理上诉而停留于罗马或其他上诉地点期间，对其他人针对其提出的诉讼应诉。因为塞尔苏斯说，此人也应享有回返本土的权利，毕竟他是为其他事由而来；塞尔苏斯的这一意见既有道理，也合乎情理。神圣的安敦尼·庇护皇帝曾复函普洛提乌斯·凯尔西安努斯：某人既因皇帝传召而来到罗马、为的是交代一项监护事务，就不应被强迫就另一项自己并未因之受召的监护事务接受诉讼。皇帝又曾复函克劳狄乌斯·弗拉维安努斯：一名未满二十五岁的男子，就自己针对阿西尼安努斯请求恢复原状一事而言，因阿西尼安努斯是为另一事务而来，不应在罗马受审。

<a id="5.1.2.4"></a>

**4.** 上述所有人，如果并非在被起诉地订立契约，均有权请求回返本土。反之，若在该地订立契约，则无此权利。但使节除外：即使他们在当地订立契约，只要是在出使前订立，且他们仍因出使而停留于罗马期间，就不应被迫在罗马应诉。尤利安有此记载，神圣的庇护皇帝也曾作出同样复函。不过，庇护皇帝还曾复函说，使节完成出使后若仍停留于当地，则可以对其提起诉讼。

<a id="5.1.2.5"></a>

**5.** 如果当事人在其所属行省之外订立契约，即使不在意大利，是否可以在罗马对其起诉，仍有疑问。马尔凯鲁斯认为，他们只有在本城，或至少在本行省内订立契约时，才享有请求回返本土的特权；此说正确。但如果他们自己提起诉讼，就必须应对所有针对他们的诉讼；不过，若他们是在追究对自己实施的侵辱、盗窃，或当下遭受的损害，则不在此限。否则，正如尤利安精辟指出的那样，他们要么会被人肆意侮辱、损害而无法追究，要么任何人都可以在他们寻求救济时反过来起诉他们，使其受该人的管辖。

<a id="5.1.2.6"></a>

**6.** 如果有疑问，不知某人是否属于可以请求回返本土的情形，应由法务裁判官查明事实后作出判断。如果确认其确有此权利，他就应承诺届时出庭，并由法务裁判官确定其承诺到庭的日期。至于仅作承诺是否足够，还是应提供正式担保，马尔凯鲁斯对此存疑；我认为只需作出承诺，梅拉也持此说。否则，当事人将被迫接受诉讼，而非设法找到为其提供正式担保的人。

<a id="5.1.2.7"></a>

**7.** 在所有延后发出传唤通知的情形中，都应确保债权人不会因此遭受期间性的损失。

<a id="5.1.2.8"></a>

**8.** 只有依法承担公共审判职能的人，才有权判处罚金；其他人均无此权利，除非特别授权其如此行事。

### <a id="5.1.3"></a>5.1.3　乌尔比安《评告示》第四卷

某人虽在场，但并未被强迫接受审判的，不应被视为为了逃避诉讼而藏匿。

### <a id="5.1.4"></a>5.1.4　盖尤斯《评行省告示》第一卷

除非涉及军役特有财产，否则我与处于我权力之下的人之间不能发生诉讼。

### <a id="5.1.5"></a>5.1.5　乌尔比安《评告示》第五卷

如果某人因另一人的管辖权而被传唤至法务裁判官处，他就应当前往；庞波尼乌斯和温狄乌斯也如此记载。判断案件是否属于自己的管辖，是法务裁判官的职责；被传唤者则不应藐视法务裁判官的权威。使节以及其他享有请求回返本土权利的人也属于此种情形：他们被传唤到法庭时，应当到场主张自己的特权。

### <a id="5.1.6"></a>5.1.6　乌尔比安《评告示》第六卷

盲人可以履行法官职务。

### <a id="5.1.7"></a>5.1.7　乌尔比安《评告示》第七卷

如果某人在被传唤到庭之后才成为军人，或转而属于另一审判管辖区，则其无权请求移送至另一法院，因为该案已经先行确定管辖。

### <a id="5.1.8"></a>5.1.8　盖尤斯《评行省告示》第二卷

如果某人在出使期间，为出使之前所负债务订立了契约，不得强迫其在订约地接受诉讼。

### <a id="5.1.9"></a>5.1.9　乌尔比安《评告示》第九卷

各岛屿既属于意大利的一部分，也属于各自所属行省的一部分。

### <a id="5.1.10"></a>5.1.10　乌尔比安《评告示》第十卷

并非仅仅延迟诉讼的人就被视为撤诉；只有彻底放弃诉讼的人才是如此。因为所谓撤诉，是指放弃一项原本以诬告为目的而提起的事务。当然，如果某人查明事实真相后放弃自己的主张，是因为不愿继续进行不正当诉讼，而该诉讼原本也并非为诬告而提起，那么他不应被视为撤诉。

### <a id="5.1.11"></a>5.1.11　乌尔比安《评告示》第十二卷

如果我收养了此前已与我确定诉讼关系的人——无论是他先对我提起诉讼，还是我先对他提起诉讼——马尔凯鲁斯在《学说汇纂》第三卷中写道，该诉讼即告消灭，因为从一开始，诉讼关系就在我们之间无法成立。

### <a id="5.1.12"></a>5.1.12　保罗《评告示》第十七卷

<a id="5.1.12.pr."></a>

**序言（pr.）** 如果法务裁判官禁止若干人中的一人担任法官，就视为将此事交由其余人处理。

<a id="5.1.12.1"></a>

**1.** 法律、皇帝敕令或元老院决议授予任命法官权力的人，可以任命法官。法律授予此权，例如授予行省总督此权。受托行使管辖权的人也可以任命法官，例如行省总督的使节。另有一些人依据惯例、因其统治权而获此权限，例如罗马城长官以及罗马的其他高级官员。

<a id="5.1.12.2"></a>

**2.** 但并非所有有权任命法官的人，都可以任命任何人担任法官。有些人依法不得担任法官，有些人因自然状况，有些人因惯例。因自然状况不得担任法官的，包括聋人、哑人、持续精神失常者和未达青春期者，因为他们欠缺诉讼判断能力。因法律而不得担任法官的，是被逐出元老院者。按照惯例，妇女和奴隶不得担任法官；这并非因为他们没有判断能力，而是因为惯例不允许他们履行市民职务。

<a id="5.1.12.3"></a>

**3.** 能够担任法官的人，无论处于他人权力之下还是享有自己的法律地位，均无区别。

### <a id="5.1.13"></a>5.1.13　盖尤斯《评行省告示》第七卷

在遗产分割之诉、共有物分割之诉和界址确定之诉这三类诉讼中，需要确定谁应视为原告，因为各方的地位似乎相同。但较为可取的意见是，应将首先请求法院审理的人视为原告。

### <a id="5.1.14"></a>5.1.14　乌尔比安《论争议问题》第二卷

如果双方都请求法院审理，通常以抽签决定由谁作为原告。

### <a id="5.1.15"></a>5.1.15　乌尔比安《评告示》第二十一卷

<a id="5.1.15.pr."></a>

**序言（pr.）** 如果家子担任法官并使诉讼成为自己的责任，他应在宣判时依其特有产承担相应数额的责任。

<a id="5.1.15.1"></a>

**1.** 法官在恶意违反法律的情况下作出判决时，才被视为使诉讼成为自己的责任；所谓恶意，是指显然因偏袒、仇怨或贪赃而作出判决。在此情形下，应强制其承担诉讼标的的真实价值。

### <a id="5.1.16"></a>5.1.16　乌尔比安《评告示》第五卷

尤利安认为，可以对使诉讼成为自己责任的法官之继承人提起诉讼；但这一意见并不正确，且已受到许多人的批评。

### <a id="5.1.17"></a>5.1.17　乌尔比安《评告示》第二十二卷

尤利安说，如果诉讼一方使法官成为自己的唯一继承人或共同继承人，就必须另行选任法官，因为让任何人审理与自己有关的案件都是不公正的。

### <a id="5.1.18"></a>5.1.18　乌尔比安《评告示》第二十三卷

<a id="5.1.18.pr."></a>

**序言（pr.）** 如果法官因时间过长而无法履行职务，法务裁判官命令更换该法官；例如，某项事务使法官无法审理案件，包括疾病、不得不出行，或其家庭事务面临危险。

<a id="5.1.18.1"></a>

**1.** 如果家子因某种不法行为希望提起诉讼，而该行为本应使家父享有诉权，只有在无人能以家父名义提起诉讼时，才允许家子起诉。尤利安也赞同：如果家子因出使或求学而离家，并遭受盗窃或不法损害，可以准许其提起准诉讼，以免在等待一名不会前来的家父时，不法行为逍遥法外；或者家父尚未到达，实施不法行为的人就已逃逸。因此，我一向认为，如果诉因并非源于不法行为，而是源于契约，家子也应当能够提起准诉讼，例如请求返还寄托物、提起委任之诉，或追讨其贷出的钱款；这可能发生在家父身处行省，而家子本人因求学或其他正当事由留在罗马的情形。否则，如果我们不授予他诉权，他就可能在罗马任由欺诈侵害而无法救济，因拿不到家父为其生活费用所寄的钱款而陷入贫困。试想，若家子是元老而家父身处行省，难道其身份不会使授予诉权更有益吗？

### <a id="5.1.19"></a>5.1.19　乌尔比安《评告示》第六十卷

<a id="5.1.19.pr."></a>

**序言（pr.）** 继承人缺席时，应在被继承人本应应诉之地为其辩护；若继承人在该地被找到，也可以在那里起诉他。他不得以自身享有的任何特权为由请求免除。

<a id="5.1.19.1"></a>

**1.** 如果某人在特定地点管理监护、照管、事务、银行业务，或其他足以产生债务的事务，即使他在该地没有住所，也必须在那里应诉；如果他既不在当地应诉，也没有当地住所，就应容许债权人占有其财产。

<a id="5.1.19.2"></a>

**2.** 因此，如果某人在特定地点出售、寄存或购入货物，除非双方另行约定其应在其他地点应诉，否则应认为他须在那里应诉。难道我们要说，某人作为外地旅客向商人购货，或向明知将立即离开当地的人售货时，不应在当地占有其财产，而应依其住所处理吗？但如果某人从在特定地点租用店铺或作坊的人那里购买物品，则他应当在那里应诉，这样处理更为合理。因为若有人只是路过便立即离开，就如同从旅客、渡海者或沿岸航行者处购买物品一样；要求一个人在每个航行或旅行经过的地点应诉，过于严苛。但如果某人在一地停留，即使不构成法律意义上的住所，只要他租用了店面、货廊、仓库、储藏室或作坊，并在那里出售物品、经营事务，就应在该地应诉。

<a id="5.1.19.3"></a>

**3.** 拉贝奥讨论过这样一种情形：一名外省人派奴隶经理到罗马出售货物。与该奴隶订立契约，应视同与主人订立契约；因此，主人应当在罗马应诉。

<a id="5.1.19.4"></a>

**4.** 应当知道，如果某人负有在意大利清偿债务的义务，但住所位于某一行省，则可以在意大利或该行省对其起诉。尤利安和许多人都持此见解。

### <a id="5.1.20"></a>5.1.20　保罗《评告示》第五十八卷

应当认为，所有债务关系都属于契约关系；因此，无论某人在何处负有债务，都应视为在该地订立了契约，即使该债务并非源于借贷。


### <a id="5.1.21"></a>5.1.21　乌尔比安《评告示》第七十卷

如果我打算向自己的债务人提出诉讼请求，应当认为：若其承认负有债务，并表示愿意清偿，就应听取其意见，并给予适当期限，同时要求其提供适当担保，以偿还债款。短暂迟延不会造成重大损害。此处所谓短暂期间，应理解为判决作出后给予被告的履行期间。

### <a id="5.1.22"></a>5.1.22　保罗《评普劳提乌斯》第三卷

未被迫在某地应诉之人，如果本人在该地提起诉讼，就必须应对他人对其提起的诉讼，并被移送至同一法官处审理。

### <a id="5.1.23"></a>5.1.23　保罗《评普劳提乌斯》第七卷

诉讼正式受理后才发生的事项，不能视为已经纳入该诉讼；因此必须另行催告。

### <a id="5.1.24"></a>5.1.24　保罗《评普劳提乌斯》第十七卷

<a id="5.1.24.pr."></a>

**序言（pr.）** 对皇帝召至罗马之人，只有在其于此期间订立合同的情况下，才可在罗马对其提起诉讼。

<a id="5.1.24.1"></a>

**1.** 使节因其在使节任期内实施的不法行为而被迫在罗马应诉，无论该行为是其本人所为，还是其奴隶所为。

<a id="5.1.24.2"></a>

**2.** 但是，如果有人针对使节提起对物之诉，是否应予准许？毕竟，这种诉讼以现时占有为依据。卡西乌斯答复说，应作如下处理：如果取回该奴隶会使使节失去其劳务，就不应准许该诉；如果在其众多奴隶中仅就一人提起诉讼，则不应禁止。尤利安主张不作区分，一律拒绝该诉；此说有理，因为不准提起该诉，正是为了不使使节被召离其所承担的使节职务。〔*si subducatur ministerium ei* 的具体指涉不明，此处依上下文理解为取回奴隶会使使节失去其劳务。〕

### <a id="5.1.25"></a>5.1.25　尤利安《学说汇纂》第一卷

如果某人在使节任期内购买了奴隶或其他财物，或者基于其他事由开始占有某物，就其所占有的财物而被要求应诉，并非不公；否则，就会使使节得以借此种名义将他人财物带回家中。

### <a id="5.1.26"></a>5.1.26　保罗《评普劳提乌斯》第十七卷

至于已经接受遗产之人，卡西乌斯写道：即使他是在罗马接受遗产，也不得对其提起诉讼，以免妨碍使节职务；此说正确。对遗赠受领人也不准提起诉讼；但未提供充分担保的，应将遗赠受领人置于遗产财物的占有之中；遗产债权人亦同。

### <a id="5.1.27"></a>5.1.27　尤利安《学说汇纂》第一卷

有什么妨碍使节履行公共职务，同时让一名管理人为了保管遗产而占有遗产财物呢？

### <a id="5.1.28"></a>5.1.28　保罗《评普劳提乌斯》第十七卷

<a id="5.1.28.pr."></a>

**序言（pr.）** 同样，如果依《特雷贝利亚努姆元老院决议》将遗产返还给某人，就不得对其提起诉讼，无论继承人是自愿还是被迫接受该遗产。因为更为妥当的做法是，虽然将遗产返还给该人，却仍将其视同由继承人本人接受了遗产。

<a id="5.1.28.1"></a>

**1.** 相反，如果使节在使节任期内接受遗产并将其返还，就可以对遗嘱信托受领人提起诉讼；遗嘱信托受领人不得援引使节个人享有的《特雷贝利亚努姆元老院决议》抗辩，因为这项利益仅属于使节本人。

<a id="5.1.28.2"></a>

**2.** 对于使节不被强制接受诉讼的那些情形，也不得强制其宣誓称自己无须给付；因为此项宣誓具有替代争讼程序确定的效力。

<a id="5.1.28.3"></a>

**3.** 就房屋而言，使节应当就可能发生的损害提供担保，或者允许邻人取得占有。

<a id="5.1.28.4"></a>

**4.** 此外，如果诉权即将届满，裁判官经审查案情后，应准许对其提起诉讼，以便正式确定争点，并使案件随后移送至行省。

<a id="5.1.28.5"></a>

**5.** 如果家父死亡时留下一个儿子和一名怀孕的妻子，即使后来又有一个儿子出生，先前的儿子也不得向债务人请求债权的一半，因为当时可能有多名子女出生；尽管依自然规律，实际出生人数终会确定。萨宾努斯和卡西乌斯则认为，应请求四分之一，因为当时不能确定是否会出生三名子女；不应考察自然规律——事物发生后，一切当然都已确定——而应考虑我们自身的无知。

### <a id="5.1.29"></a>5.1.29　保罗《评普劳提乌斯》第八卷

先行提出诉请者，即为诉讼中的原告。

### <a id="5.1.30"></a>5.1.30　马尔凯鲁斯《学说汇纂》第一卷

诉讼一经在某地受理，就应当也在那里终结。

### <a id="5.1.31"></a>5.1.31　塞尔苏斯《学说汇纂》第二十七卷

如果原告留下数名继承人，而其中一人提起诉讼，就不能认为前一诉讼已经将整个争议标的纳入审理；因为未经共同继承人同意，任何人都不能将他人的诉权带入诉讼。

### <a id="5.1.32"></a>5.1.32　乌尔比安《论执政官职务》第一卷

如果一名法官原已获准一定期限，后来去世并由另一人接任，我们应当认为，已向接任者重新给予了同样长的期限，即使官员在任命继任者时没有明确说明这一点；但该期限不得超过法律规定的期间。

### <a id="5.1.33"></a>5.1.33　莫德斯蒂努斯《规则集》第三卷

请求在同一法官面前向其告知诉讼类型之人，不视为已经同意由该法官审理。

### <a id="5.1.34"></a>5.1.34　雅沃列努斯《摘自卡西乌斯》第十五卷

如果曾在罗马接受诉讼之人去世，其继承人即使住所位于海外，也仍应在罗马应诉，因为他承继了留下遗产之人的诉讼地位。

### <a id="5.1.35"></a>5.1.35　雅沃列努斯《书信集》第十卷

保证人的债务可以处于待定状态，也可以约定在将来发生；但诉讼不能处于待定状态，也不能涉及日后才会成为债务的事项。我认为，没人会怀疑：可以在主债务产生之前接受保证；但在尚无任何债务应付之前，不可能受理诉讼。

### <a id="5.1.36"></a>5.1.36　卡利斯特拉图《审判论》第一卷

<a id="5.1.36.pr."></a>

**序言（pr.）** 有时，基于正当事由并涉及特定人员的审理应当暂缓；例如，据称诉讼文书掌握在因公务而缺席之人手中。神圣的皇帝兄弟曾就此作出如下敕复。出于人道，应当因意外事件准许延期；例如，作为当事人的父亲失去儿子或女儿、妻子失去丈夫，或者儿子失去父亲；在类似情形下，审理也应当在一定程度上暂缓。

<a id="5.1.36.1"></a>

**1.** 如果一名元老在行省自愿为他人事务提供服务，尤利安答复说，他不得拒绝无因管理之诉，而应承受该诉，因为他是自愿为自己承担了这一义务。

### <a id="5.1.37"></a>5.1.37　卡利斯特拉图《审判论》第五卷

如果争议涉及暴力与占有，应当先审理暴力问题，再审理物的所有权问题。神圣的哈德良皇帝曾以希腊文向塞萨利人议会作出敕复；底本载其称谓为 *tw koinw twn Thessalwnon*，并释作“塞萨利人议会”。

### <a id="5.1.38"></a>5.1.38　利基尼乌斯《规则集》第四卷

遗赠物如果通过对人之诉请求给付，应当在该物所在地给付；但如果继承人出于恶意将其移走，则应在请求给付之地给付。此外，以重量、数量或度量确定的物品，也应当在请求给付之地给付；但遗嘱另有指定的除外，例如“从那座谷仓中取一百摩迪乌斯”或“从那只酒缸中取葡萄酒坛”。如果通过对物之诉请求遗赠物，也应当在该物所在地提起诉讼。如果该物是动产，可以对继承人提起出示之诉，要求其出示该物；如此，遗赠受领人方可对该物提起对物之诉。

### <a id="5.1.39"></a>5.1.39　帕比尼安《问题集》第三卷

<a id="5.1.39.pr."></a>

**序言（pr.）** 即使被指定为法官的是精神失常者，也不因此使诉讼无效，尽管他今日不能裁判；等到其恢复神志后，他所作出的判决仍应有效。因为指定法官时，并不要求法官在场或知情。

<a id="5.1.39.1"></a>

**1.** 因使节事务来到罗马之人，可以基于任何事由为他人提供保证；但如果合同是在意大利订立的，就不能援用其特权。

### <a id="5.1.40"></a>5.1.40　帕比尼安《问题集》第四卷

<a id="5.1.40.pr."></a>

**序言（pr.）** 并非一切交由法官裁量之事，都受法律强制规范。

<a id="5.1.40.1"></a>

**1.** 法官如果在裁判时故意违背法律的要求而有所遗漏，即属违法。

### <a id="5.1.41"></a>5.1.41　帕比尼安《疑问集》第十一卷

在所有诚实信用诉讼中，即使履行金钱给付的期限尚未届至，只要有人为请求对方提供担保而起诉，法院基于正当理由即可判令提供担保。

### <a id="5.1.42"></a>5.1.42　帕比尼安《疑问集》第二十四卷

妻子若在罗马投宿于一名使节处，裁定认为，丈夫应当在罗马就嫁资问题应诉。

### <a id="5.1.43"></a>5.1.43　帕比尼安《疑问集》第二十七卷

如果某人以要式口约约定在特定期限内于卡普阿建造一栋公寓楼，期限届满后，他显然可以在任何地点就其利益损失提起诉讼。

### <a id="5.1.44"></a>5.1.44　帕比尼安《答复集》第二卷

<a id="5.1.44.pr."></a>

**序言（pr.）** 在针对所有监护人提起诉讼之后，其中若有监护人因公务离开，并不妨碍法官履行职务，因为可以区分并审查在场者与无人辩护者各自应承担的事务。

<a id="5.1.44.1"></a>

**1.** 后来，如果出现一名奴隶，而先前已有诉讼代理人代表该奴隶提起诉讼，就应判令债务人免责；这并不妨碍奴隶主人日后以本人名义提起诉讼。

### <a id="5.1.45"></a>5.1.45　帕比尼安《答复集》第三卷

<a id="5.1.45.pr."></a>

**序言（pr.）** 应当在订立银行交易之地起诉银行家；除非有正当理由，例如需要从行省调取账簿，否则不应准许延期。监护之诉也适用同一规则。

<a id="5.1.45.1"></a>

**1.** 如果监护人因一名女孩的事务在行省被判承担责任，该女孩的照管人应当在罗马履行判决；女孩的母亲曾在罗马借入款项，而女孩后来成为母亲的继承人。

### <a id="5.1.46"></a>5.1.46　保罗《疑问集》第二卷

法官受任后，即使后来开始精神失常，仍保有该职务，因为他起初是依法任命的；但严重疾病可以免除其履行审判职责的义务。因此，应当更换该法官。

### <a id="5.1.47"></a>5.1.47　卡利斯特拉图斯《疑问集》第一卷

应当注意，不要任命一方当事人点名请求的法官；神圣的哈德良皇帝曾复函指出，这会形成不公正的先例。只有皇帝特别许可，并以维护被点名法官的体面为考虑时，才可例外。

### <a id="5.1.48"></a>5.1.48　保罗《答复集》第二卷

哈德良皇帝敕书的一部分。底本以拉丁字母转写希腊文如下：

> *tous arxontas en hw arxousin eniautw myte eisienai dikyn idian myte diwkontwn myte feugontwn, myte peri hwn epitropoi y kouratores eien krinetwsan. Epeidan de ecyky hy arxy, kai autois pros tous feugontas kai tois feugousi pros autous eisagwgimous einai tas dikas.*

其意为：“官员在其任期内，不得提起或应诉于涉及本人的案件，也不得审理涉及其担任监护人或照管人的人的案件。任期届满后，他们可以起诉被告，被告也可以起诉他们。”〔原文疑点：底本将希腊语转写为拉丁字母，拼写形式未作校订；译文依底本所附释义翻译。〕

### <a id="5.1.49"></a>5.1.49　保罗《答复集》第三卷

<a id="5.1.49.pr."></a>

**序言（pr.）** 买受人通知出卖人，请其就标的物被第三人追夺一事为买受人提供辩护；出卖人声称自己享有在其本籍法官处应诉的特权。问题是：他能否将买受人与原告已经开始的诉讼，从该法官处移送至自己的法官处？保罗答复说，出卖人通常应当跟随买受人的法官。

<a id="5.1.49.1"></a>

**1.** 总督任命的法官通常会在其继任者任期内继续任职，并被要求作出判决；这些判决也应得到遵行。斯凯沃拉对此作了相同答复。

### <a id="5.1.50"></a>5.1.50　乌尔比安《论遗嘱信托》第六卷

<a id="5.1.50.pr."></a>

**序言（pr.）** 如果有人请求他人履行遗嘱信托，而对方称遗产的主要部分位于别处，就不得强迫其履行。许多皇帝敕令规定，应在遗产主要部分所在地请求履行遗嘱信托；除非能够证明立遗嘱人希望在提出请求之地履行该遗嘱信托。

<a id="5.1.50.1"></a>

**1.** 人们还讨论过债务问题：如果请求履行遗嘱信托的行省中，遗产债务更多，是否应以主要遗产实际位于别处为由提出抗辩？对此也认为，债务的名称并不影响判断，因为债务并不属于某一地点，而是涉及全部财产；债务显然会减少整个遗产，而非某一地点的财产。不过，如果遗产被指定用于某些特定负担，例如家父命令在罗马支付的扶养费、税款或其他不可免除的负担，能否提出该项抗辩？我认为，此时更妥当的意见是允许提出。

<a id="5.1.50.2"></a>

**2.** 另有皇帝复函规定，应在继承人住所地请求履行遗嘱信托。某人一旦开始清偿遗嘱信托，就不得再援用这一抗辩，

### <a id="5.1.51"></a>5.1.51　马尔基安《法学阶梯》第八卷

尽管继承已经归属于一名住所位于行省的人。神圣的塞维鲁和安敦尼皇帝还曾复函：如果遗嘱信托受益人同意在另一地点受领，就必须依照其同意，在该地点履行。

### <a id="5.1.52"></a>5.1.52　乌尔比安《论遗嘱信托》第六卷

<a id="5.1.52.pr."></a>

**序言（pr.）** 如果某人已经接受遗嘱信托之诉，并以其他抗辩应诉而未提出这一抗辩，之后即使尚未作出判决，也不得再回头援用这一抗辩。

<a id="5.1.52.1"></a>

**1.** 如果立遗嘱人希望为自己的获释奴隶购买粮食配给凭券，即使遗产主要部分在行省，也应认定遗嘱信托必须在罗马履行；因为从遗赠的类别可以看出，这正是立遗嘱人的意思。

<a id="5.1.52.2"></a>

**2.** 同样，假设遗嘱为若干显贵留下若干磅银或金，而罗马的遗产足以履行这类遗嘱信托：即使全部遗产的主要部分位于行省，也应认为须在罗马履行。立遗嘱人既希望对受遗赠人表达敬意，却仅留下如此少量的遗嘱信托，就不太可能还希望在行省履行。

<a id="5.1.52.3"></a>

**3.** 如果遗嘱信托所留之物就在当地，就应当认定，不得以遗产主要部分位于别处为由提出抗辩，以阻止请求履行者。

<a id="5.1.52.4"></a>

**4.** 但如果请求的并非当地履行遗嘱信托，而是为该遗嘱信托提供担保，是否适用这一抗辩，尚须考察。我认为不适用；恰恰相反，即使当地没有任何财产，也应命令其提供正式担保。因为他有什么可担忧的呢？如果他不提供担保，对方就会为保全遗嘱信托而被准许进入财产占有。

### <a id="5.1.53"></a>5.1.53　赫尔莫格尼安《法学纲要》第一卷

只有在少数特定事由下，才允许奴隶对主人提起诉讼：例如，奴隶声称主人隐匿了遗嘱文书，而遗嘱中为奴隶指定了自由。对于导致罗马人民粮食供应紧张、人口登记方面的犯罪以及伪造货币犯罪，也允许奴隶揭发有罪的主人。此外，奴隶可以请求主人履行遗嘱信托所指定的自由；如果奴隶声称自己已用自有钱款赎身，而主人违反约定未予释放，也可如此请求。另有奴隶被命令在结清账目后获得自由；他可以正当地请求指定仲裁人，审查主人所掌握的账目。如果有人允诺以自己的钱款赎买某奴隶，并在收到款项后释放他，但此人拒绝接受已提出的款项，则法律也赋予奴隶揭露该契约违信行为的权能。

### <a id="5.1.54"></a>5.1.54　保罗《法学格言》第一卷

较小案件不应对较大的审理产生先决影响；较大的争议会将较小案件纳入其中。

### <a id="5.1.55"></a>5.1.55　保罗《论辅佐官职务》单卷

前任官员发布的告示，应计入三项告示的总数。当然，即使前任官员已经发布完规定数量的告示，继任者通常仍会发布一项告示。

### <a id="5.1.56"></a>5.1.56　乌尔比安《评萨宾》第三十卷

确实，通常只有真正的诉讼代理人才能将案件提交法院；不过，即使某人并非诉讼代理人，却已经确定诉讼关系，后来本人又予以追认，也应视为该案件自始已被合法提交法院。

### <a id="5.1.57"></a>5.1.57　乌尔比安《评萨宾》第四十一卷

无论基于契约还是不法行为，都可以对家子提起诉讼；但如果家子在确定诉讼关系后死亡，诉讼即转而针对家父，但责任仅以特有产及归入家父利益的财产为限。当然，如果家子以某人的诉讼代理人身份接受诉讼，家子死亡后，可以基于和解或判决向其所代理的人提出请求。〔原文含义待核：*transactio vel iudicati datur* 所指的具体程序效果不够明确。〕

### <a id="5.1.58"></a>5.1.58　保罗《评萨宾》第十三卷

如果曾命令法官审判的人禁止其继续审判，诉讼即告终止；如果在同一管辖范围内享有更高统治权的人禁止其审判，也是如此；如果法官本人后来开始享有与任命他审判之人同等的统治权，诉讼同样终止。

### <a id="5.1.59"></a>5.1.59　乌尔比安《评萨宾》第五十一卷

如果任命法官的命令没有指定审判地点，就应认为命令法官在通常审判之地审理案件，同时不得给诉讼当事人造成不便。

### <a id="5.1.60"></a>5.1.60　保罗《评萨宾》第十四卷

法官死亡后，接替他的法官应依前任法官本应作出的方式裁判。

### <a id="5.1.61"></a>5.1.61　乌尔比安《评告示》第二十六卷

<a id="5.1.61.pr."></a>

**序言（pr.）** 我们通常说，诉讼所审理的是当事人之间已经约定的事项。但是，凯尔苏斯说，若从被告的立场衡量，便有危险，因为被告总会声称双方并未达成约定，以免被判处败诉。那么，应当怎样说才更妥当？诉讼所审理的，是当事人约定提交审理的事项；但当事人明确约定不提交审理的事项，则不属于审理范围。

<a id="5.1.61.1"></a>

**1.** 负责审理盗匪犯罪的官员（*latrunculator*），不得审理金钱案件。

### <a id="5.1.62"></a>5.1.62　乌尔比安《评告示》第三十九卷

当事人之间的诉讼，只有一方为请求人、另一方为占有人时，才能进行裁判；因为必须有人承担请求人的举证责任，也必须有人享有占有人的地位。

### <a id="5.1.63"></a>5.1.63　乌尔比安《评告示》第四十九卷

妥为应诉，是亲自或通过他人接受诉讼程序，并提供担保；未履行判决所确定给付的人，也不视为已经妥为应诉。

### <a id="5.1.64"></a>5.1.64　乌尔比安《论争议问题》第一卷

<a id="5.1.64.pr."></a>

**序言（pr.）** 欺诈所涉金额并非由法官依利害关系所受损失来估定，而是依当事人在诉讼中宣誓确定的金额来估定。因此，即使被告是强盗，也无疑可以因此对其提起寄托之诉和使用借贷之诉。

<a id="5.1.64.1"></a>

**1.** 如果某人在准备提起的一宗诉讼中接受了判决履行担保，随后却在另一宗诉讼中起诉，该要式承诺不发生责任，因为该担保被视为针对另一事项作出。

在绝断告示中，发布告示的人会警告说，即使对方缺席，他也将审理案件并作出裁判。

### <a id="5.1.73"></a>5.1.73　乌尔比安《论一切审判庭》第四卷

<a id="5.1.73.pr."></a>

**序言（pr.）** 申请并获得绝断告示后，待告示所定之日到来时，应传唤缺席者。无论其是否应答，均应审理案件并作出裁判；裁判并非必定有利于到场者，有时缺席者若主张有理，也会胜诉。

<a id="5.1.73.1"></a>

**1.** 如果申请绝断告示的人在审理之日缺席，而被申请该告示针对的人到场，就应撤销绝断告示；既不审理案件，也不得仅因一方到场而作出有利于该方的裁判。

<a id="5.1.73.2"></a>

**2.** 告示撤销后，我们还须考察被告能否再次被传唤，还是诉讼仍然存续、仅告示的效力消失。较妥当的意见是，仅告示的效力消失，双方仍可重新进行诉讼。〔译疑：*instantia edicti* 暂按“告示的效力”理解，具体程序含义待核。〕

<a id="5.1.73.3"></a>

**3.** 应当知道，缺席者因绝断告示而被判处败诉后提起上诉，如果他是因抗命而缺席，就不应受理；如果并非如此，则应受理。

### <a id="5.1.74"></a>5.1.74　尤利安《学说汇纂》第五卷

<a id="5.1.74.pr."></a>

**序言（pr.）** 法官既已审理某事项，也必须就该事项作出裁判。

<a id="5.1.74.1"></a>

**1.** 法官虽仅受命裁判一定金额以内的事项，但如果当事人之间达成合意，他也可以裁判金额更高的事项。

<a id="5.1.74.2"></a>

**2.** 我本想为一名缺席者进行抗辩，却在其已经死亡后接受了诉讼程序，随后被判令给付并已履行。有人询问：继承人是否因此免责？我对继承人可以提起何种诉讼？我答复说：债务人已经死亡后，其抗辩人所接受的诉讼程序无效，因此继承人不免责。代理人若基于判决而履行给付，虽不得请求返还，但可以对继承人提起无因管理之诉；如果继承人被原告起诉，他当然可以援用恶意欺诈抗辩保护自己。

### <a id="5.1.75"></a>5.1.75　尤利安《学说汇纂》第三十六卷

如果裁判官命令被请求偿还债务的人到场，并在告示程序全部完成后宣告该缺席者负有债务，那么审理判决之诉的法官通常不应重新审查裁判官的裁判；否则，这类告示和裁判官的命令就会沦为儿戏。马尔切卢斯补充说：如果能够明确证明，被告明知所陈述之事虚假，却仍以欺诈方式作出陈述，并因此取得裁判官的裁判，我认为法官应受理被告的申诉。保罗补充说：如果被告因疾病或奉公事之命而无法到场，我认为在这种情况下，应当驳回针对他的判决之诉，或者裁判官不应执行该判决。

### <a id="5.1.76"></a>5.1.76　阿尔费努斯《学说汇纂》第六卷

有人提出这样一个问题：为同一事项指定的数名法官中，有些人在听审案件后获准辞任，另一些人被选来接替他们；于是有人询问，个别法官的更换是否使原来的事项变成另一事项，或使原来的诉讼变成另一诉讼。我答复说，即使只更换一名或两名法官，甚至全部法官都更换，仍然是原来的事项，诉讼也仍是先前的同一诉讼。并非只有在这种情况下，尽管组成部分更换，仍被认为是同一事物；许多其他事物也一样。例如，一支军团中许多人死去、又由他人补入，仍被视为同一支军团；如今的人也被认为是百年前的同一群人，尽管当时的人如今无一在世；一艘船即使屡次修缮，以至没有一块木板仍是原来的，也仍被认为是同一艘船。若有人认为组成部分一经更换，便成为另一事物，那么依照他的推论，我们也不再是去年那个我们自己，因为正如哲学家所说，构成我们的最微小粒子每日从身体中离去，又有其他粒子从外部进入，取代它们。因此，只要某一事物的外观保持相同，也应认为它仍是同一事物。
