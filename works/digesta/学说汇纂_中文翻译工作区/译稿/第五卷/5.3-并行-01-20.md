## <a id="3"></a><a id="5.3"></a>5.3.0　论遗产请求之诉（*De hereditatis petitione*）

### <a id="5.3.1"></a>5.3.1　盖尤斯《评行省告示》第六卷

遗产依据旧法或新法归属于我们。依旧法，遗产可依据《十二表法》取得，也可依据依法订立的遗嘱取得。

### <a id="5.3.2"></a>5.3.2　乌尔比安《评告示》第十五卷

（无论我们是以自己的名义、亲自，还是通过他人成为继承人，

### <a id="5.3.3"></a>5.3.3　盖尤斯《评行省告示》第六卷

例如，如果我们命令一名处于我们权力之下、且已被指定为继承人的人接受遗产；又如，我们成为提提乌斯的继承人，而提提乌斯又是塞伊乌斯的继承人：正如我们可以主张提提乌斯的遗产属于我们一样，也可以主张塞伊乌斯的遗产属于我们。）或者通过无遗嘱继承（例如，因为我们是死者的自权继承人（*sui heredes*）或宗亲，或者因为我们释放了死者，或我们的父母曾释放死者）。新法下，凡依元老院决议或皇帝敕令而被召继承遗产者，均成为继承人。

### <a id="5.3.4"></a>5.3.4　保罗《评告示》第一卷

如果我对仅占有一项财物之人提起遗产请求之诉，而当时争议也仅涉及该项财物，那么该人后来开始占有的其他遗产财物，也应当返还。

### <a id="5.3.5"></a>5.3.5　乌尔比安《评告示》第十四卷

<a id="5.3.5.pr."></a>

**序言（pr.）** 神圣的庇护皇帝曾作出敕复：对有争议的遗产之占有人，在诉讼开始之前，应禁止其处分遗产中的任何财物；除非其愿意就全部遗产或其中各项财物的返还提供充分担保。至于案情经审查后，即使所提供的不是这种担保，而是通常的担保，裁判官也曾宣布：在诉讼开始之后仍可准许减少遗产，以免一概禁止减少遗产反而妨碍其他利益。例如，丧葬所需之物可以处分，因为裁判官准许为葬礼而减少遗产。同样，如果不在期限内清偿债务，质物将被出售，也可处分相关财物。家庭维持生计所需的费用，也可成为减少遗产的理由。对于会随时间而毁损的财物，裁判官也应准许出售。

<a id="5.3.5.1"></a>

**1.** 神圣的哈德良皇帝曾向特雷比乌斯·塞尔吉安努斯作出敕复：应令埃利乌斯·阿西亚提库斯就向其请求的遗产提供充分担保，并由此提出伪造指控。〔*et sic falsum dicat* 的主语及其所指程序不明。〕这是因为遗产请求之诉应予暂缓，直到伪造之诉审理完毕。

<a id="5.3.5.2"></a>

**2.** 关于遗产请求之诉的这些判决具有这样的效力：不得作出任何会对该诉讼产生先决影响的行为。

### <a id="5.3.6"></a>5.3.6　乌尔比安《评告示》第七十五卷

如果有人主张遗嘱是伪造的，而又依据该遗嘱请求遗赠，要么应在提供担保后给付遗赠，要么应查明该遗赠是否确实应当给付，即使遗嘱被指为伪造也如此。但是，如果伪造之诉已经开始审理，就不得向提起伪造指控之人给付遗赠。

### <a id="5.3.7"></a>5.3.7　乌尔比安《评告示》第十四卷

<a id="5.3.7.pr."></a>

**序言（pr.）** 如果有人主张自己依据遗嘱取得自由，法官就不应对自由身份作出判决，以免对审理遗嘱效力的案件产生先决影响；元老院曾如此决议。神圣的图拉真皇帝也曾作出敕复：关于自由身份的诉讼应予延期，直至关于遗嘱违背义务之诉提起或终结。

<a id="5.3.7.1"></a>

**1.** 只有在关于遗嘱违背义务之诉已经正式受理的情况下，关于自由身份的诉讼才应暂缓；若该诉尚未正式受理，则无须等待关于自由身份的诉讼。神圣的庇护皇帝也曾作出这样的敕复。曾有一名利基尼亚努斯就自己的身份受到质疑；为了不让其身份过早得到裁定，他不愿进入关于自由身份的诉讼，而声称自己将提起关于遗嘱违背义务之诉并请求遗产，因为他主张依据遗嘱取得自由和遗产。神圣的庇护皇帝说，如果利基尼亚努斯确实占有遗产，就更应当听取他的主张，因为他将就遗产提起诉讼；而是否提起关于遗嘱违背义务之诉，本由自称为所有权人的人决定。然而，在本案中，利基尼亚努斯本人并未提起关于遗嘱违背义务之诉，不应以该诉为借口，使奴役状态延续五年。当然，皇帝准许法官作初步审查，判断其是否确实善意请求审理遗嘱；如果法官认定是善意请求，就应设定一个较短期限；如果期限内仍未正式受理该诉，便应命令审理自由身份案件的法官履行其职责。

<a id="5.3.7.2"></a>

**2.** 神圣的庇护皇帝曾作出敕复：如果某人虽同时面临自由身份与遗产的争议，却并非主张依据遗嘱获得自由，而是主张由其他途径获得自由，或者是在遗嘱人仍在世时已被释奴，那么即使预计会提起遗嘱诉讼，也不应妨碍自由身份案件的审理。皇帝在敕复中还补充说，应当预先告知审理自由身份案件的法官，不得接受任何以遗嘱为依据、支持其自由身份的材料。

### <a id="5.3.8"></a>5.3.8　保罗《评告示》第十六卷

不知道遗嘱效力如何、但曾遵从死者遗愿之人，不因此被禁止主张法定继承权。

### <a id="5.3.9"></a>5.3.9　乌尔比安《评告示》第十五卷

一般而言，只有以继承人身份或以占有人身份占有遗产的人，或者占有遗产财物的人，才受遗产请求之诉追究。

### <a id="5.3.10"></a>5.3.10　盖尤斯《评行省告示》第六卷

<a id="5.3.10.pr."></a>

**序言（pr.）** 即使所占份额极小，

<a id="5.3.10.1"></a>

**1.** 因此，无论是继承全部遗产还是部分遗产之人，虽主张遗产全部或相应份额属于自己，但依裁判人职权，实际返还给他的，仅限于对方所占有的部分：如果他是全部遗产的继承人，就返还全部；如果他仅为部分继承人，就按其继承份额返还。

### <a id="5.3.11"></a>5.3.11　乌尔比安《评告示》第十五卷

<a id="5.3.11.pr."></a>

**序言（pr.）** 以继承人身份占有遗产的，是认为自己为继承人之人。但明知自己并非继承人者，是否也属于以继承人身份占有，尚有疑问。阿里安努斯在《禁令程序》第二卷中认为，此人也应承担责任；普罗库鲁斯写道，我们所适用的正是这一规则。此外，遗产占有人（*bonorum possessor*）似乎也属于以继承人身份占有。

<a id="5.3.11.1"></a>

**1.** 至于以占有人身份占有的，则是掠夺者；

### <a id="5.3.12"></a>5.3.12　乌尔比安《评告示》第六十七卷

如果有人被问及为何占有某物，他会回答“因为我占有”，而不会主张自己是继承人，甚至不会以谎言作此主张。

### <a id="5.3.13"></a>5.3.13　乌尔比安《评告示》第十五卷

<a id="5.3.13.pr."></a>

**序言（pr.）** 而且，他不能提出任何占有根据；因此，窃贼和强盗均受遗产请求之诉追究。

<a id="5.3.13.1"></a>

**1.** 以各种占有名义占有遗产之人，在此诉中都被视为以占有人身份占有，仿佛这些占有名义均附着于其占有。最后，即使其以买受为由占有，亦然：例如，我明知是从精神失常者处购买，仍以占有人身份占有。同样，以赠与为由占有时，也会涉及某人是否以占有人身份占有的问题，例如妻子或丈夫；我们赞同尤利安的意见，即此人以占有人身份占有，因此受遗产请求之诉追究。以嫁资为由占有的名义，也包括以占有人身份占有的情形；例如，我明知妻子尚未满十二岁，仍接受她作为嫁资交付的财物。此外，如果我明知遗赠所依据的事由虚假，却仍接受遗赠给付，我当然也将以占有人身份占有。

<a id="5.3.13.2"></a>

**2.** 返还遗产之人不得再因遗产请求之诉承担责任，除非其曾有欺诈行为，即明知其情仍返还遗产。遗产请求之诉也涵盖先前的欺诈；此时，行为人被视为因欺诈而停止占有。

<a id="5.3.13.3"></a>

**3.** 涅拉提乌斯在《札记》第六卷中写道，即使继承人不知道死者曾以继承人或占有人身份占有遗产，仍可向该继承人请求遗产。他在第七卷中也说，即使继承人以为某些财物属于归其继承的遗产，亦同。

<a id="5.3.13.4"></a>

**4.** 如果某人买下了整份遗产，是否应当对其授予遗产请求之诉的准诉，以免其因逐项诉讼而受到纠缠？出卖人当然要承担责任；但假设出卖人不复存在，或者仅以很低的价格出卖遗产，且其本人是善意占有人，是否应将救济扩及买受人？盖尤斯·卡西乌斯认为，应当授予准诉。

<a id="5.3.13.5"></a>

**5.** 如果继承人受命以低价出售遗产，并将其卖给提提乌斯，结论亦应相同。帕比尼安认为，应当准许对遗嘱信托受领人提起诉讼，因为对仅持有极少价款的继承人提起遗产请求之诉并不适当。

<a id="5.3.13.6"></a>

**6.** 如果某人受嘱在保留一定金额后返还遗产，结论也相同。但如果其受嘱先收取一定金额再返还遗产，帕比尼安认为，不应对继承人提起遗产请求之诉，因为其为履行附条件的安排而收取的款项，并非以继承人身份占有。萨宾努斯对准释奴持相反意见；后说更可取，因为该笔钱属于遗产。

<a id="5.3.13.7"></a>

**7.** 对于仅保留遗产孳息之人，也应作相同处理：此人同样受遗产请求之诉追究。

<a id="5.3.13.8"></a>

**8.** 如果某人明知遗产属于他人仍予购买，他是以占有人身份占有；因此有人认为，可以对其提起遗产请求之诉。我认为此说不正确：支付了价款的人并非掠夺者。不过，作为整体遗产的买受人，他仍应受遗产请求之诉的准诉追究。

<a id="5.3.13.9"></a>

**9.** 同样，如果某人从国库购买了一份被视为无人承受的遗产，对其授予准诉是最为公平的。

<a id="5.3.13.10"></a>

**10.** 马尔凯鲁斯《学说汇纂》第四卷记载：如果一名妇女将遗产作为嫁资交付，丈夫虽以嫁资为由占有该遗产，仍应受遗产请求之诉的准诉追究；马尔凯鲁斯还写道，该妇女本人也受直接诉追究，尤其是在婚姻已经解除的情况下。

<a id="5.3.13.11"></a>

**11.** 可以确定，继承人即使就死者曾以买受为由占有的财物，也受遗产请求之诉追究，仿佛其本人以继承人身份占有；至于死者曾以继承人或占有人身份占有的财物，继承人当然也要承担责任。

<a id="5.3.13.12"></a>

**12.** 如果某人以缺席者的名义占有遗产，而缺席者是否会追认尚不确定，我认为应当以缺席者的名义请求遗产，绝不能对占有人本人提起诉讼；因为以他人利益为着眼点而占有者，不被视为以继承人或占有人身份占有。除非有人主张：缺席者未予追认时，该代理人便如同掠夺者；在这种情况下，才可以对其本人提起诉讼。

<a id="5.3.13.13"></a>

**13.** 遗产不仅可以向占有遗产实体财物之人请求；即使某人什么也不占有，也可能成为请求对象。应当考察：如果未占有财物之人主动表示愿意应对遗产请求之诉，他是否承担责任。塞尔苏斯《学说汇纂》第四卷写道，此人因欺诈而承担责任；因为主动让自己成为该诉的对象，就是欺诈。马尔凯鲁斯在尤利安著作中概括赞同这一意见：任何主动接受遗产请求之诉的人，均应视为占有人并承担责任。

<a id="5.3.13.14"></a>

**14.** 同样，如果某人以欺诈方式使自己不再占有遗产，也受遗产请求之诉追究。但如果我因恶意欺诈而丧失占有后，另一人取得占有并愿意应对该诉，马尔凯鲁斯《学说汇纂》第四卷讨论了：对已停止占有之人的诉讼估价是否会因此落空。他认为，除非请求人仍有利益，否则该估价更可能落空；他说，如果现占有人愿意返还财物，那么估价无疑会落空。但是，如果先起诉的是以欺诈方式停止占有之人，该诉并不会使现占有人免责。

<a id="5.3.13.15"></a>

**15.** 此外，还可以向遗产债务人请求遗产，因为遗产债务人是权利的占有人；可以向权利占有人请求遗产，这一点已经确定。

### <a id="5.3.14"></a>5.3.14　保罗《评告示》第二十卷

债务究竟源于不法行为还是契约，并无区别。遗产债务人还包括向遗产中的奴隶作出允诺之人，以及在遗产被接受之前造成损害之人。

### <a id="5.3.15"></a>5.3.15　盖尤斯《评行省告示》第六卷

或者盗取了某项遗产财物。

### <a id="5.3.16"></a>5.3.16　乌尔比安《评告示》第十五卷

<a id="5.3.16.pr."></a>

**序言（pr.）** 如果遗产债务人的债务尚未到期，或者附有条件，而遗产请求之诉是针对该债务人提起的，就不应判令其承担责任。依奥克塔维努斯的意见，应当考察判决作出时的情况，确定期限是否已经届至；波庞波尼乌斯著作中也有记载。附条件的要式口约亦应作相同处理。如果期限尚未届至或条件尚未成就，法官应依其职权命其提供担保，保证在期限届至或条件成就时返还该债务。

<a id="5.3.16.1"></a>

**1.** 占有遗产财物价款之人，以及已从遗产债务人处收取款项之人，也受遗产请求之诉追究。

<a id="5.3.16.2"></a>

**2.** 因此，尤利安在《学说汇纂》第六卷中说，对已经请求遗产并取得诉讼估价款之人，仍可以提起遗产请求之诉。

<a id="5.3.16.3"></a>

**3.** 遗产不仅可以向死者的债务人请求，也可以向遗产债务人请求。最后，塞尔苏斯和尤利安都认为，可以向管理遗产事务之人请求遗产；但若其管理的是继承人的事务，则绝不能如此，因为不能向继承人的债务人请求遗产。

<a id="5.3.16.4"></a>

**4.** 尤利安写道，如果以继承人身份占有遗产之人被人以暴力驱逐，可以将其视为权利占有人而向其请求遗产，因为他享有“因暴力驱逐”禁令（*interdictum unde vi*），并且败诉后应当让出财物。驱逐他的人也受遗产请求之诉追究，因为其以占有人身份占有遗产财物。

<a id="5.3.16.5"></a>

**5.** 尤利安还说，无论出卖人出售财物时是否占有该物，也无论其已经收到价款还是仍可请求价款，都受遗产请求之诉追究；此人也应当转让其享有的诉权。

<a id="5.3.16.6"></a>

**6.** 尤利安写道，解放自由人以欺诈方式转让财物后，其保护人不得向受让人提起遗产请求之诉，因为该受让人应依《卡尔维西亚法》之诉对保护人承担责任；此人是保护人的债务人，而非遗产债务人。因此，也不得向因死亡原因受赠之人请求遗产。

<a id="5.3.16.7"></a>

**7.** 尤利安写道，如果某人基于遗嘱信托返还遗产或交付个别财物，可以向其请求遗产，因为其享有返还该等给付物的准契约返还请求权，因而相当于权利占有人。

<a id="5.3.16.8"></a>

**8.** 同样，如果某人基于遗嘱信托交付出售遗产财物所得的价款，也可以向其请求遗产，因为其可以请求返还该款。在这些情形下，他只须交付自己享有的诉权，因为相关财物仍然存在，请求人也可以通过对物之诉取回这些财物。

### <a id="5.3.17"></a>5.3.17　盖尤斯《评行省告示》第六卷

如果遗产占有人因依据遗嘱而自认为继承人，遂以自己的财产支付遗赠，而后来有人依无遗嘱继承取得该遗产，虽然占有人未能通过“遗产被追夺时返还遗赠”的要式口约保护自己，看起来是其自身的损失，但考虑到其可能在争议尚未发生时就已支付遗赠，因而未作担保，仍认为在遗产被追夺时应准许其请求返还。然而，在未提供担保的情况下仍准许返还，存在一种风险：受领遗赠之人无清偿能力，从而无法追回。因此，依照元老院决议的宗旨，应当给予其救济：占有人可以从遗产财物中扣留相应部分以满足自己，但须将其诉权让与请求人，由请求人自行承担风险提起这些诉讼。

### <a id="5.3.18"></a>5.3.18　乌尔比安《评告示》第十五卷

<a id="5.3.18.pr."></a>

**序言（pr.）** 还应当考察：如果遗产占有人通过银行家出售财物，并将所得钱款存于银行家处而遭受损失，是否受遗产请求之诉追究；因为他既不再占有钱款，也无法收回。拉贝奥认为此人应当承担责任，因为他自行承担风险，却不慎将钱款交由银行家保管。奥克塔维努斯则认为，他只须交付自己享有的诉权；因此，他应当仅就这些诉权受遗产请求之诉追究。我认为，对于恶意占有人，应采拉贝奥之见；至于善意占有人，则似应采奥克塔维努斯之见。

<a id="5.3.18.1"></a>

**1.** 如果有人在遗产请求之诉对其提起时，既未占有遗产财物，也未占有遗产权利，但之后取得了某物，是否应认为其受遗产请求之诉追究？塞尔苏斯《学说汇纂》第四卷正确地写道，应当判令此人承担责任，尽管他起初什么也没有占有。

<a id="5.3.18.2"></a>

**2.** 现在应当考察哪些事项属于遗产请求之诉的范围。人们认为，所有遗产财物都纳入此诉，无论是权利还是有体物，

### <a id="5.3.19"></a>5.3.19　保罗《评告示》第二十卷

<a id="5.3.19.pr."></a>

**序言（pr.）** 不仅遗产中的有体物属于此诉范围，不属于遗产、但其风险由继承人承担的物品也包括在内，例如死者所质押、借用或寄存的物品。对于质押物，另有特别的请求之诉，但仍可纳入遗产请求之诉；《普布利基亚法》之诉所及物品亦同。尽管对借用或寄存物通常很难提起诉讼，既然这些物品的风险由我们承担，令其返还仍属公平。

<a id="5.3.19.1"></a>

**1.** 如果继承人以买受人身份完成了取得时效，该物就不纳入遗产请求之诉；因为继承人，也就是请求人，可以对其提起对物之诉，占有人也没有任何抗辩可以援用。

<a id="5.3.19.2"></a>

**2.** 有些物品虽可由占有人主张留置，却不可由其提出请求，这些物品也属于遗产请求之诉的范围。例如，死者曾宣誓称请求人之物并非其所有，随后即已去世；这些物品也应当返还。甚至占有人因自身过失而使其灭失，也要就此承担责任。对掠夺者亦同，尽管他不因过失而承担责任；因为他也不应留置这些物品。

<a id="5.3.19.3"></a>

**3.** 我所知，地役权不属于遗产返还范围，因为对地役权无法像对有体物和孳息那样予以返还；但是，如果占有人不允许他人通行或驱赶牲畜，就应当通过专门之诉追究其责任。

### <a id="5.3.20"></a>5.3.20　乌尔比安《评告示》第十五卷

<a id="5.3.20.pr."></a>

**序言（pr.）** 同样，为遗产目的而购置的财物也属于遗产，例如奴隶、牲畜以及其他为遗产所必需而购置的物品。如果以遗产的钱款购置，当然属于遗产；如果并非以遗产的钱款购置，则应另行考察。我认为，如果购置对遗产有重大利益，这些物品也属于遗产，但继承人应返还其价款。

<a id="5.3.20.1"></a>

**1.** 但并非所有以遗产钱款购置的财物都纳入遗产请求之诉。最后，尤利安在《学说汇纂》第六卷中写道：占有人以遗产的钱款购买奴隶后，有人向其请求遗产；只有在购置该奴隶符合遗产利益时，该奴隶才纳入遗产请求之诉；如果占有人是为自己购置，则纳入此诉的只是价款。

<a id="5.3.20.2"></a>

**2.** 同样，如果有人出售了遗产中的土地，若其出售并无正当理由，土地本身及其孳息均纳入遗产请求之诉；但若其出售土地是为了清偿遗产债务，则纳入此诉的仅为价款。

<a id="5.3.20.3"></a>

**3.** 纳入遗产请求之诉的，不仅是死者死亡时已有的财物，之后增加到遗产中的财物也包括在内；因为遗产会增加，也会减少。接受遗产后增加的财物，如果来自遗产本身，我认为应归入遗产；如果来自外部，则不归入遗产，而归入占有人个人。所有孳息都会增加遗产，无论是在接受遗产之前还是之后取得。女奴所生子女当然也会增加遗产。

<a id="5.3.20.4"></a>

**4.** 我们已经说过，所有遗产诉权都纳入遗产请求之诉。于是产生疑问：这些诉权是否依其本来性质纳入，还是以其他方式纳入？例如，有一种诉权会因否认而增加数额；该诉是按其增加后的数额纳入，还是只按原数额纳入，例如《阿奎利亚法》之诉？尤利安在《学说汇纂》第六卷中写道，只须给付单倍额。

<a id="5.3.20.5"></a>

**5.** 尤利安还正确地说，如果遗产占有人在死者生前已因奴隶致害而被判承担责任，就不能在遗产请求之诉中通过交付致害奴隶而免除责任；因为只有在被判履行之前，才可以交付致害奴隶免除责任；诉讼正式受理之后，便不能再以交付致害奴隶免责。遗产请求之诉既已正式受理，便不得再如此免责。

<a id="5.3.20.6"></a>

**6.** 此外，我们还发现，关于遗产请求之诉、处分遗产财物、先前的欺诈以及孳息，已有许多讨论。既然元老院决议已经为此制定了规则，最好引述决议原文并逐句解释。原文如下：“三月十五日前一日，执政官昆图斯·尤利乌斯·巴尔布斯与普布利乌斯·尤文提乌斯·塞尔苏斯·提图斯·奥菲迪乌斯·奥埃努斯·塞维里亚努斯，就皇帝凯撒·哈德良·奥古斯都、最高统治者——他是皇帝图拉真·帕提库斯之子、神圣的涅尔瓦之孙——在最近一次三月诺纳节前第五日提出并写入呈文、说明其认为应如何处理的事项，发表如下意见；对此事项，他们决议如下：

<a id="5.3.20.6a"></a>

**6a.** “如果在国库请求取得农夫遗产中的失权份额之前，自以为是继承人的人已经出售了遗产，决议认为，出售遗产财物所得价款不应计收利息；类似案件也应遵照此规则处理。”

<a id="5.3.20.6b"></a>

**6b.** “同样决议：如果有人被请求返还遗产，且判决对其不利，即使遗产财物在请求遗产之前已经灭失或价值减少，他也应返还自己从出售这些遗产财物中取得的价款。”

<a id="5.3.20.6c"></a>

**6c.** “同样，那些明知财物不属于自己仍侵占的人，即使在争讼程序确定之前已使自己不再占有，也应当如同仍在占有一样被判承担责任；但有正当理由认为财物属于自己的人，仅在其因此变得较为富有的范围内承担责任。”

<a id="5.3.20.6d"></a>

**6d.** “国库请求取得遗产的时间，应认定为某人首次知道国库向其请求该遗产之时；也就是说，首次向其送达通知，或者通过书信或告示传唤其到庭之时。以上为决议内容。”

因此，我们应当对元老院决议中的每一句话作出与之相应的解释。

<a id="5.3.20.7"></a>

**7.** 元老院说：“在国库请求取得失权份额之前。”当时确有国库请求取得失权份额的情形；但即使是请求取得全部遗产，该元老院决议也适用。即使国库请求取得无人承受的财产，或者基于任何其他原因取得了财产，该决议也适用：

<a id="5.3.20.8"></a>

**8.** 如果遗产是由市镇请求取得，也同样适用。

<a id="5.3.20.9"></a>

**9.** 毫无疑问，该元老院决议也适用于私人之间的遗产请求，尽管决议原本是针对公共案件作出的。

<a id="5.3.20.10"></a>

**10.** 我们适用该元老院决议的，不仅限于遗产，也包括军营特有财产或其他财产整体。

<a id="5.3.20.11"></a>

**11.** “请求取得遗产”之语，指某人知道遗产正被向其请求之时；从此时起，他便成为恶意占有人。“也就是说，首次送达通知之时。”那么，如果某人明知遗产正被请求，却无人向其送达通知，他是否应当就出售所得钱款支付利息？我认为仍应支付，因为他已经成为恶意占有人。再设想通知虽已送达，但本人并不知情，因为通知并非送达给他，而是送达给他的代理人：元老院要求向本人送达通知，因此这不会对其不利；除非代理人已经告知他。但如果代理人本来能够告知而没有告知，就不在此限。元老院并未要求说明由谁送达通知；因此，无论何人送达，均会产生不利后果。

<a id="5.3.20.12"></a>

**12.** 以上规则针对善意占有人，因为元老院说的是“自以为是继承人的人”。但是，如果某人明知遗产不属于自己仍予出售，纳入遗产请求之诉的当然不是价款，而是财物本身及其孳息。皇帝塞维鲁似乎在致凯勒尔的书信中，也对恶意占有人作了同样规定；然而，元老院决议所谈的是自以为是继承人的人。除非我们将其理解为涉及那些出售有利于遗产的财物——这些财物与其说为遗产带来收益，不如说增加了遗产负担。这样，请求人便可以自行选择对恶意占有人采用何种计算方式：请求返还财物本身及孳息，还是请求价款及争议发生后的利息。

<a id="5.3.20.13"></a>

**13.** 元老院决议虽然谈及自认为是继承人的人，但自认为是遗产占有人、正当的概括继受人，或认为遗产已返还给自己的人，也处于相同地位。

<a id="5.3.20.14"></a>

**14.** 帕比尼安在《问题集》第三卷中说，如果遗产占有人没有动用遗产中发现的钱款，就绝不能以利息为由对其提起诉讼。

<a id="5.3.20.15"></a>

**15.** 元老院说“出售财物所得价款”。“所得”应作如下理解：不仅指已经实际收取的价款，也包括虽未收取但本可以收取的价款。

<a id="5.3.20.16"></a>

**16.** 如果在遗产被请求之后才出售财物，该财物本身及其孳息均纳入此诉。但若所出售的财物本来不生孳息，或者会随时间毁损，而其售价又是合理的，请求人或许可以选择请求给付价款及利息。

<a id="5.3.20.17"></a>

**17.** 元老院说：“如果有人被请求返还遗产，且判决对其不利，则应返还其出售遗产财物所取得的价款，即使这些财物在遗产被请求之前已经灭失或价值减少。”善意占有人出售遗产财物后，无论是否实际收取价款，因为他享有请求价款的诉权，就应当给付该价款；但如果他仍享有该诉权，交付诉权即已足够。

<a id="5.3.20.17a"></a>

**17a.**

<a id="5.3.20.18"></a>

**18.** 但是，如果占有人出售财物后，因买受人追夺而返还了所收取的价款，就不认为该价款曾归其取得。尽管有人可能认为，价款自始就不应纳入此诉，因为被出售的财物并非遗产财物；然而，元老院决议虽提到出售遗产中的财物，而非“遗产财物”，但仍不应命其返还，因为其手中已无任何所得。尤利安在《学说汇纂》第六卷中也写道，某人收取了本不应收取之款，不必返还；其支付了本不应支付之款，也不应在结算时计入。

<a id="5.3.20.19"></a>

**19.** 如果买卖被解除并返还标的物，该物当然仍属于遗产；已退还的价款则不纳入此诉。

<a id="5.3.20.20"></a>

**20.** 此外，如果遗产占有人因出售财物而对买受人负有债务，就应当以担保为其提供保障。

<a id="5.3.20.21"></a>

**21.** 即使财物已经灭失或价值减少，占有人仍应返还价款。但这是否仅适用于善意占有人，还是恶意占有人也适用？如果买受人仍占有财物，且财物既未灭失也未贬值，恶意占有人当然应当返还财物；如果无论如何都无法从买受人处取回财物，则应当给付依诉讼估价宣誓确定的金额。但如果财物已经灭失或价值减少，则应当给付其实际价款，因为如果请求人取得该物，也会将其出售，从而不会失去该物的真实价款。”
