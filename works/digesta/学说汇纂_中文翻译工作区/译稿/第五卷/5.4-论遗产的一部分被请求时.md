## <a id="4"></a><a id="5.4"></a>5.4　论遗产的一部分被请求时

*Si pars hereditatis petatur*

### <a id="5.4.1"></a>5.4.1　乌尔比安《评告示》第五卷

<a id="5.4.1.pr."></a>

**序言（pr.）** 法务裁判官已经为主张遗产仅归自己一人所有者规定了诉讼；与之相应，也有必要为请求遗产一部分者规定诉讼。

<a id="5.4.1.1"></a>

**1.** 请求遗产或遗产一部分的人，其请求范围不是按占有人实际占有的财物确定，而是依请求人自己的权利确定。因此，如果他是取得全部遗产的继承人，即使你只占有一件物品，他也可以请求整个遗产；如果他是部分继承人，则可请求其应有部分，即使你占有整个遗产。

<a id="5.4.1.2"></a>

**2.** 不仅如此，如果有两人占有遗产，也有两人各自主张遗产中的份额，他们不能满足于各自分别向一人请求，例如第一人向第一位占有人请求、第二人向第二位占有人请求；而应由二人共同向第一位占有人请求，也共同向第二位占有人请求。因为二人并非分别占有第一位或第二位占有人的份额，而是各自以继承人身份占有二人的遗产份额。如果占有人与请求人都占有遗产，且各自声称遗产的一半归自己所有，他们就应彼此请求，以取得各项遗产物的份额；或者，如果他们之间并不对遗产归属发生争议，就应提起遗产分割之诉。

<a id="5.4.1.3"></a>

**3.** 如果我主张自己是部分继承人，而我的共同继承人与一名外人共同占有遗产；由于该共同继承人所占有的份额并未超过其应有份额，那么我应仅向外人请求遗产，还是也应向共同继承人请求？对此存在疑问。据说佩加苏斯认为，我只应向外人请求，由外人返还其所占有的一切；或许这也应由法官依职权作出处理。另一方面，按事理，我应向二人请求遗产，也就是向我的共同继承人请求；而该共同继承人也应当向外部占有人提起诉讼。不过，佩加苏斯的意见更为有用。

<a id="5.4.1.4"></a>

**4.** 同样，如果我主张自己是二分之一继承人，却只占有遗产的三分之一，之后希望追索剩余的六分之一，应当如何起诉？拉贝奥写道，我无论如何都应分别向每一人请求二分之一；如此，我便可以从每一人处各取得六分之一，从而拥有三分之二。我认为这是正确的；但我自己也须从所占有的三分之一中返还六分之一。因此，如果我所请求遗产的人是我的共同继承人，法官应依职权准许双方就我所占有的份额相互抵销。

<a id="5.4.1.5"></a>

**5.** 有时，若存在适当事由，法务裁判官会允许请求份额尚未确定的遗产。例如，某人的兄弟之子尚在世，而已故兄弟的妻子们均怀有身孕：该兄弟之子可请求遗产的份额尚不确定，因为尚不知已故兄弟的妻子们将生下多少子女。因此，准许他请求一项未确定份额的遗产，是最为公平的。由此可以毫不冒进地说，凡某人有正当理由不确定自己应请求遗产的何种份额，就应准许其请求一项未确定份额的遗产。

### <a id="5.4.2"></a>5.4.2　盖尤斯《评行省告示》第六卷

如果有数人共同享有同一遗产，其中一些人已经接受继承，另一些人仍在考虑是否接受，那么已接受继承者请求遗产时，不得请求超过其他人也都接受继承时自己所能取得的份额；其他人尚未接受继承，对他们并无帮助。只有在其他人最终不接受继承的情况下，已接受继承者才可以请求其份额，但以该份额本应归其所有为限。

### <a id="5.4.3"></a>5.4.3　保罗《评普劳提乌斯》第十七卷

古人对尚未出生的自由人作了如下保护：在其出生之前，为其完整保留一切权利。这一点在继承法中尤为明显：如果胎儿所属的宗亲等级尚不确定，就不允许位于该等级之后的其他宗亲继承，因为尚不确定胎儿能否出生。但如果其他人和胎儿处于同一宗亲等级，法学家便会考察应为胎儿保留何种份额，因为他们不知道胎儿可能有多少。事实上，关于此事的传闻纷繁而不可思议，其中不少已近于神话。据说某贵妇曾一次生下四个女儿；也有可信作者记载，一名伯罗奔尼撒妇女五次生下四胞胎，还有许多埃及妇女一胎生下七个孩子。我们还见过三胞胎，即身着元老服饰的贺拉提三兄弟。〔原文疑点：*tregeminos senatores cinctos vidimus Horatios* 的词序及“身着元老服饰”的关系待核。〕拉埃利乌斯还记载，他曾在宫廷见到一名从亚历山大里亚带来、供哈德良皇帝观看的自由妇女，她身边有五个孩子；据他说，其中四个是她同一次分娩所生，第五个则在四十天后出生。那么，法学家的处理方式是什么呢？他们极为审慎地采取折中方案，只考虑并非极其罕见、确有可能发生的情形：既然可能一次生下三胞胎，就给存活的儿子分配四分之一。底本接着引泰奥弗拉斯托斯的话：*to gar hapac y dis, ut ait Theophrastus, parabainousin ohi nomovetai*（“因为……，正如泰奥弗拉斯托斯所说，立法者……”）。〔原文疑点：此希腊语以拉丁字母转写，拼写和句法未明；括号内仅依上下文提示句意，确切译义待核。〕因此，即使妇人将只生一个孩子，该孩子暂时也不是继承二分之一，而是继承四分之一。

### <a id="5.4.4"></a>5.4.4　乌尔比安《评告示》第十五卷

如果实际出生的人数少于预期，剩余份额应按比例增加给该继承人；如果出生人数超过三个，则应从他据以成为继承人的那一份额中相应扣减。

### <a id="5.4.5"></a>5.4.5　保罗《评普劳提乌斯》第十七卷

<a id="5.4.5.pr."></a>

**序言（pr.）** 应当知道，如果妇人实际上并未怀孕，却被误认为怀孕，那么儿子暂时应视为全部遗产的继承人，即使他不知道自己是全部遗产的继承人也是如此。

<a id="5.4.5.1"></a>

**1.** 对于外人继承人也同样如此：如果他被指定继承某一确定份额，剩余部分则由遗腹子继承。如果遗嘱作如下指定：“凡我所生的子女，以及卢基乌斯·提提乌斯，均按人数相等的份额继承”，卢基乌斯·提提乌斯就会犹豫自己是否可以接受继承，因为他不知道自己在遗嘱中所占的份额。不过，较为有用的做法是，允许不知道自己份额的人接受继承，只要他并未忽略其他必须知道的事项。

### <a id="5.4.6"></a>5.4.6　乌尔比安《意见集》第六卷

<a id="5.4.6.pr."></a>

**序言（pr.）** 已经决定，某女子与四名兄弟共同继承母亲的财产。该女子取得五分之一份额，应从原属四兄弟的份额中按比例扣出；因此，四兄弟各自仅须从原先被认为归其所有的四分之一份额中，向她分出五分之一。

<a id="5.4.6.1"></a>

**1.** 为承担整个遗产的负担而合理支出的费用，应由凭借释奴人保护人（*patronus*）权利追回遗产份额的人按比例分担。

### <a id="5.4.7"></a>5.4.7　尤利安《学说汇纂》第八卷

我们不能通过遗产请求之诉取得在遗产分割之诉中可以取得的结果，即脱离共有关系；因为法官的职权仅及于命令将遗产中未分割的份额返还给我。

### <a id="5.4.8"></a>5.4.8　尤利安《学说汇纂》第四十八卷

应当允许遗产占有人对遗产的一部分进行抗辩，而就另一部分放弃争议；法律并不禁止某人占有整个遗产，同时知道其中一半归自己所有，并且不对另一半提出争议。

### <a id="5.4.9"></a>5.4.9　保罗《阿尔芬努斯〈学说汇纂〉提要》第三卷

某人立遗嘱指定数人为继承人，其中一人在亚细亚。他的诉讼代理人出售遗产物，并取走了该人应得份额的价款。后来发现，那名身在亚细亚的人此前已经死亡，并在遗嘱中指定其诉讼代理人继承二分之一，另一人继承另一半。问题是，应如何请求返还遗产中的价款？答复是：由于该价款来自遗产，并且是通过出售遗产物而到达诉讼代理人手中，应向曾任其诉讼代理人的人请求整个遗产；同时，也应向其共同继承人请求遗产的一半。如此，无论全部价款仍由该代理人持有、请求人得以通过法官从他那里全部追回，还是他已将一半价款交给自己的共同继承人，均可得到处理：前一种情形下由该代理人返还全部；后一种情形下，则判令代理人承担二分之一，其共同继承人承担另二分之一。

### <a id="5.4.10"></a>5.4.10　帕比尼安《疑问集》第六卷

如果一名被指定为部分继承人的男子之子，不知道其父在立遗嘱人尚在世时已经死亡，却将父亲视为缺席者而以其名义管理遗产的一部分，并在出售遗产物后收取价款，就不能向该子请求遗产，因为他既不是以继承人身份，也不是以占有人身份占有这些价款，而是作为儿子处理父亲的事务。其他共同继承人——死者的份额归他们所有——可以提起无因管理之诉。无需担忧该子还会因处理继承事务而对其父的继承人承担责任，哪怕他可能已被父亲剥夺继承权，因为他所管理的并非父亲遗产中的事务。即使无因管理之诉应由以其名义受领财物的人提起，仍应将以他人名义（*alieno nomine*）受领的财物返还给其名义所指之人，方为公平。〔原文疑点：底本在此处以引号分隔 *est*、*perceptum*、*alieno*、*nomine*，其句法关系待核。〕不过，在本案中，这既不是其父的事务——因为父亲已不在人世——也不是父亲的继承事务，因为相关财产属于另一遗产。如果该子后来成为其父的继承人，并主张其父是在成为继承人之后才死亡，就会产生另一个问题：他是否应被视为自行改变了其占有根据？然而，既然管理遗产事务的人已因此成为债务人，之后又对继承权提出争议，就应像以权利占有人身份起诉那样处理；对这个儿子也应作相同答复。〔原文疑点：本段关于 *pro herede*、*pro possessore* 及 *ut iuris possessor* 的占有依据区分复杂，末句的诉讼身份待核。〕
