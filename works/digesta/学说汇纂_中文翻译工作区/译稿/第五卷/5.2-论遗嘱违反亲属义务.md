<a id="2"></a><a id="5.2"></a>5.2　论违反亲属义务的遗嘱

*De inofficioso testamento*

### <a id="5.2.1"></a>5.2.1　乌尔比安《评告示》第十四卷

应知，提起遗嘱违反亲属义务之诉的情形很多。因为父母和子女均可就遗嘱是否违反亲属义务提出争议。至于血亲关系中远于兄弟姐妹的旁系亲属，最好不要徒然耗费诉讼费用；他们本来就没有胜诉的希望。

### <a id="5.2.2"></a>5.2.2　马尔西安《法学阶梯》第四卷

提起遗嘱违反亲属义务之诉时，所采用的理由是立遗嘱人仿佛心智不健全，因而不能妥善安排遗嘱。这里这样说，并不是指他确实患有精神病或神志错乱，而是说，他虽依法有效地订立了遗嘱，却未履行亲属间的伦理义务；因为如果他确实患有精神病或神志错乱，遗嘱就不成立。

### <a id="5.2.3"></a>5.2.3　马尔凯卢斯《学说汇纂》第三卷

主张遗嘱违反亲属义务，就是提出理由说明某人本不应被剥夺继承权或被遗漏；这种情形通常发生于父母受到不实挑拨，因而剥夺子女的继承权或将其遗漏。

### <a id="5.2.4"></a>5.2.4　盖尤斯《格利提亚法单卷释义》

不应认可父母在遗嘱中对自己的子女施加不公；这种事通常是他们恶意针对自己的血亲作出决定，受到继母的甜言蜜语或挑唆所蒙蔽。

### <a id="5.2.5"></a>5.2.5　马尔凯卢斯《学说汇纂》第三卷

即使并非出自男性一系的亲属，也有权提起此诉；他们也可以就母亲的遗嘱起诉，而且通常能够胜诉。我前面说过，“遗嘱违反亲属义务”这一用语的含义，是表明起诉人并无过错，本不应被不公正地遗漏，甚至不应被剥夺继承权。诉讼在法官面前便借此理由提出，使立遗嘱人看起来仿佛在不公正安排遗嘱时心智不健全。

### <a id="5.2.6"></a>5.2.6　乌尔比安《评告示》第十四卷

<a id="5.2.6.pr."></a>

**序言（pr.）** 胎儿出生后，可以对这样的人所立的遗嘱主张违反亲属义务：如果其在该人死亡时已在母腹中，本可成为该人的自家继承人或法定继承人。胎儿也可以对其亲属所立的遗嘱提出此项主张，因为若依法定继承，其本可取得该亲属遗产的占有。对此，难道要归咎于这些人没有无遗嘱而死吗？但无人能在法官面前取得这种主张，因为这并不妨碍立遗嘱能力的行使。当然，可以归咎于立遗嘱人没有指定该胎儿为继承人：若已将其指定为继承人，便可依据有关将胎儿置于占有中的告示条款，使其取得遗产占有；同样，胎儿出生后也可依遗嘱取得遗产占有。我认为，母亲立遗嘱后经剖腹取出的胎儿，也可以同样提起此诉。

<a id="5.2.6.1"></a>

**1.** 如果不属于无遗嘱继承人的人提起遗嘱违反亲属义务之诉（因为无人会阻止其起诉），并且偶然胜诉，该胜诉不应使其本人受益，而应使有权无遗嘱继承的人受益；因为该判决使家父的遗产按无遗嘱继承处理。

<a id="5.2.6.2"></a>

**2.** 有人已经提起遗嘱违反亲属义务之诉，却在诉讼中死亡；该项诉权是否移转给其继承人？帕皮尼安答复说，依若干敕答所示，如果其在承认遗产占有后死亡，该项起诉权可以继承。即使尚未请求遗产占有，但争议已经开始或诉讼已经准备妥当；或者其在着手提起该诉时死亡，我认为起诉权也移转给其继承人。

### <a id="5.2.7"></a>5.2.7　保罗《七人审判庭单卷释义》

让我们考察，何种情形下可以认为某人已为诉讼作好准备，从而能够移转该项诉权。假设某人能够自行决定是否提起诉讼，既无须取得遗产占有，也无须接受遗产：如果他只是威胁要提起指控，或者已进行至发出通知，乃至递交诉状的阶段，就可以将该项指控移转给自己的继承人。神圣的庇护皇帝曾就递交诉状和发出通知作出敕答。那么，如果某人无法自行决定是否起诉，能否将诉权移转给继承人？如果他已实施前述事项，我认为应当认定其已为诉讼作好准备。

### <a id="5.2.8"></a>5.2.8　乌尔比安《评告示》第十四卷

<a id="5.2.8.pr."></a>

**序言（pr.）** 帕皮尼安在《法律问题》第五卷中正确指出，父亲不得违背儿子的意思，以儿子的名义提起遗嘱违反亲属义务之诉，因为受到侵害的是儿子本人。他接着写道：儿子在为安排诉讼而取得遗产占有后死亡的，此项诉讼即告终结；该诉讼并非授予父亲，而是以儿子的名义提起。

<a id="5.2.8.1"></a>

**1.** 如果某人在遗嘱违反亲属义务之诉已经进入程序后放弃诉讼，之后不再受理其起诉。

<a id="5.2.8.2"></a>

**2.** 如果皇帝被指定为继承人，遗嘱仍可被主张违反亲属义务；敕答对此已屡次确认。

<a id="5.2.8.3"></a>

**3.** 帕皮尼安在《法律意见》第二卷中说，可以针对一位退役军人家父所立的遗嘱提起遗嘱违反亲属义务之诉，即使他仅有在军营中取得的财产。

<a id="5.2.8.4"></a>

**4.** 某人在服役期间订立遗嘱，并于退役后一年内死亡；由于该遗嘱依军人法在此期限内仍然有效，我不确定此时是否不得提起遗嘱违反亲属义务之诉。也可以认为，此项诉讼应当排除。

<a id="5.2.8.5"></a>

**5.** 未达青春期儿子的母亲不得主张儿子的遗嘱违反亲属义务，因为该遗嘱是由父亲为儿子订立的；帕比尼安也如此答复。父亲的兄弟亦不得起诉，因为该遗嘱是为儿子所作。因此，如果父亲没有提起此诉，未达青春期者的兄弟也不得起诉。但如果父亲已就此胜诉，该胜诉对此处讨论的遗嘱安排仍不发生效力；除非遗嘱仅就父亲的部分被撤销，此时为未达青春期子女设立的替补继承指定仍然有效。

<a id="5.2.8.6"></a>

**6.** 如果某人以临终赠与方式，将儿子在其无遗嘱死亡时本可取得财产的四分之一赠与儿子，我认为他可以放心订立遗嘱。

<a id="5.2.8.7"></a>

**7.** 如果某人为未达青春期的儿子设立替补继承人，并制作第二套遗嘱文书，不得仅因此就允许该儿子提起遗嘱违反亲属义务之诉。

<a id="5.2.8.8"></a>

**8.** 既然应得份额的四分之一足以排除该项诉讼，就须考察没有提起诉讼的被剥夺继承权者是否也应计入应得份额。例如，若有两名儿子均被剥夺继承权，答案当然是肯定的，帕皮尼安也这样答复。因此，即使我主张遗嘱违反亲属义务，也只能请求一半遗产，而不能请求全部遗产。由两名儿子所生的孙辈亦同：一支有三人，另一支只有一人；独自一支的孙辈以一盎司半的份额即可排除该诉，三人中的任一人则以半盎司即可排除该诉。

<a id="5.2.8.9"></a>

**9.** 计算应得的四分之一时，应先扣除债务和丧葬费用；至于释奴是否也应从中扣除，尚须考察。是否应当扣除呢？例如，某人被指定为全部遗产的继承人，因其享有《法尔基第法》所保障的四分之一份额，故不得主张遗嘱违反亲属义务；然而，《法尔基第法》并不减少遗嘱所赋予的自由。因此，可以认为，计算应得四分之一时应先扣除释奴。既然认为释奴会减少该份额，那么，某人全部财产只有奴隶时，只要将奴隶释为自由人，便可排除遗嘱违反亲属义务之诉。不过，如果儿子不受家父权支配且被父亲指定为继承人，他或许可以正当地不接受遗产，将该诉移转给替补继承人后再提起；或者不受告示所定惩罚而依无遗嘱继承取得遗产。

<a id="5.2.8.10"></a>

**10.** 如果立遗嘱人要求继承人以某项条件为儿子或其他有权提起该诉的人给付，而该人明知此事仍予接受，就应考察他是否因此不得再提起遗嘱违反亲属义务之诉，因为他已经认可了立遗嘱人的安排。受遗赠人或附条件释奴作出给付时，情形亦同。尤其是在立遗嘱人要求继承人给付时，可以认为该人不得起诉；但如果给付者是受遗赠人，受遗赠人的给付是否会消灭已经产生的诉权，尚有疑问。为何对继承人就能径直如此认定？因为在接受遗产之前，该诉权尚未产生。我认为此事应依实际情形判断：如果在提起诉讼之前，已经有人将遗嘱所留之物交付给该人，那么既然该给付符合立遗嘱人的意思，就应认为其请求已经获得满足。

<a id="5.2.8.11"></a>

**11.** 因此，如果某人被指定为遗产二分之一的继承人，而依其遗产应得份额本应取得六分之一，并且受托在一定期间届满后返还遗产，那么可以正当地说，他不应提起诉讼，因为他能够取得应得份额及其孳息。孳息通常计入《法尔基第法》所保障的份额，这一点并非不为人知。同样，如果某人自始被指定为遗产二分之一的继承人，并受托在十年后返还遗产，他也没有可供主张之处，因为在此期间，他可以轻易要求取得其应得份额及其孳息。

<a id="5.2.8.12"></a>

**12.** 如果某人同时主张遗嘱无效、因后事发生而失效以及违反亲属义务，应让其选择先提起哪一项诉讼。

<a id="5.2.8.13"></a>

**13.** 如果被剥夺继承权的儿子占有遗产，遗嘱指定的继承人可以请求返还遗产；儿子则可以提出遗嘱违反亲属义务之诉作为抗辩，犹如他不占有遗产、而是请求取得遗产一样。

<a id="5.2.8.14"></a>

**14.** 还须记住：有人恶意主张遗嘱违反亲属义务而未能胜诉的，将丧失遗嘱所给予他的利益；该利益将作为对不配受领者的剥夺而归入国库。但只有恶意坚持诉讼直至法官作出判决的人，才会被剥夺遗嘱所给予的利益；如果他在判决前放弃诉讼或死亡，则不予剥夺。因此，如果法院在其缺席时作出有利于到庭一方的判决，也可以认为应保留其已经取得的利益。某人仅应丧失对其本人有利益的部分；如果他受托将该利益返还给他人，就不应使其受此不利。帕皮尼安在《法律意见》第二卷中对此有妥当说明：如果某人被指定为继承人，并受托返还遗产，却未能在遗嘱违反亲属义务之诉中胜诉，他仅丧失依《法尔基第法》本可保留的部分。

<a id="5.2.8.15"></a>

**15.** 如果一名未达青春期的被收养人属于即使未经收养或解放出家父权也可主张遗嘱违反亲属义务的人，我认为应排除其起诉，因为依神圣的庇护皇帝敕令，他享有四分之一份额。如果他已经起诉但未能胜诉，是否会丧失该四分之一份额？我认为，要么不应准许其提起此诉；要么即使准许其起诉，虽未胜诉，也应将该四分之一份额作为债权准许给他。

<a id="5.2.8.16"></a>

**16.** 如果法官审理遗嘱违反亲属义务之诉后判决遗嘱不成立，且无人上诉，该遗嘱即依法被撤销。依判决确定的继承人为自家继承人；若其据此主张，则为遗产占有人。释奴安排依法不生效；遗赠不再负有给付义务，但已经给付的，可以由给付人或胜诉者通过准诉权请求返还。通常，如果给付发生在争议开始之前，由胜诉者请求返还；神圣的哈德良皇帝和神圣的庇护皇帝均曾作出此类敕答。

<a id="5.2.8.17"></a>

**17.** 当然，如果有重大且正当的理由，在五年届满后才开始主张遗嘱违反亲属义务，不得撤销已经成立或已经履行的释奴安排；但每名释奴均应向胜诉者给付二十金币。

### <a id="5.2.9"></a>5.2.9　莫德斯蒂努斯《遗嘱违反亲属义务之诉单卷释义》

如果在五年内提起诉讼，释奴安排便不生效。不过，保罗说，遗嘱信托所附的释奴安排仍应履行；在此情形下，每名释奴也应给付二十金币。

### <a id="5.2.10"></a>5.2.10　马尔凯卢斯《学说汇纂》第三卷

<a id="5.2.10.pr."></a>

**序言（pr.）** 如果审理遗嘱是否违反亲属义务的法官中，一部分判决遗嘱不成立，另一部分则判决遗嘱有效——这种情形有时会发生——较为妥当的做法是采纳支持遗嘱有效的那部分法官的意见；但若明显可见法官不公正地判决遗嘱指定的继承人胜诉，则不在此限。

<a id="5.2.10.1"></a>

**1.** 众所周知，已经受领遗赠的人，不得正当地主张遗嘱违反亲属义务；但如果他已将所受领之物全部交给他人，则不在此限。

### <a id="5.2.11"></a>5.2.11　莫德斯蒂努斯《答复集》第三卷

我答复说：即使遗嘱违反亲属义务之诉已经胜诉，也不能因此撤销据称立遗嘱人生前已完成的赠与，亦不得请求返还作为嫁资给付之物的一部分。

### <a id="5.2.12"></a>5.2.12　莫德斯蒂努斯《诉讼抗辩单卷释义》

<a id="5.2.12.pr."></a>

**序言（pr.）** 被剥夺继承权的儿子，无论承认遗嘱为其本人所留的遗赠，还是已经取得留给其儿子或奴隶的遗赠，均会受到抗辩而不得起诉。甚至，如果他在命令遗嘱指定的奴隶接受遗产之前就将其释为自由人，使该奴隶可以自行决定是否接受遗产，而他又是出于欺诈目的这样做，也将被排除于诉讼之外。

<a id="5.2.12.1"></a>

**1.** 如果被剥夺继承权的人开始向附条件释奴请求给付金钱，应视为其已经认可父母的遗嘱安排。

<a id="5.2.12.2"></a>

**2.** 如果儿子起诉请求取回被撤销的遗赠，却因此被排除于诉讼之外，之后再提起遗嘱违反亲属义务之诉，不应以抗辩驳回。虽然他曾经起诉，仿佛认可了遗嘱，但仍有可归因于立遗嘱人过错之处，因此不应将他排除。

<a id="5.2.12.3"></a>

**3.** 立遗嘱人的儿子曾与提提乌斯就同一笔金钱负有债务；提提乌斯依遗嘱受领免债遗赠后，该儿子因提提乌斯的正式免债而免于诉讼。此情形不应使该儿子被排除于遗嘱违反亲属义务之诉。

### <a id="5.2.13"></a>5.2.13　谢沃拉《答复集》第三卷

提提娅指定女儿为继承人，并将遗赠留给儿子；她在同一份遗嘱中还作出如下安排：“我命令以上各项给付和作为，均由任何将以无遗嘱继承或遗产占有人身份继承我的人履行；我还将此后命令给付或履行的一切，委托其诚信予以给付或履行。”有人询问：如果姐妹在百人审判庭胜诉，是否仍应依据上述条款履行遗嘱信托？我答复说：如果问题在于，能否委托那些某人认为将以无遗嘱继承人或遗产占有人身份继承自己的人履行信托，我答复说可以。保罗注：但他也认为，以无遗嘱继承方式设定的遗嘱信托并无给付义务，因为这仿佛是由心智不健全者设定的。

### <a id="5.2.14"></a>5.2.14　帕比尼安《法律问题》第五卷

父亲解放了儿子出家父权，却将孙子留在自己权力之下；该已被解放的儿子后来生了儿子，之后在两个儿子均被剥夺继承权、父亲又被遗漏的情形下死亡。在有关遗嘱违反亲属义务之诉的争议中，儿子们的诉讼尚在先行审理。如果判决不利于儿子们，父亲便可提起此诉，并继续主张自己的权利。

### <a id="5.2.15"></a>5.2.15　帕比尼安《法律问题》第十四卷

<a id="5.2.15.pr."></a>

**序言（pr.）** 父母并不因其对儿子的期望以及对儿子的天然慈爱而当然享有儿子的遗产；然而，若生死次序颠倒，父母理应像子女一样，受到合乎亲属伦理的遗产留置。

<a id="5.2.15.1"></a>

**1.** 某人为遗嘱违反亲属义务之诉作好准备后改变主意，并在放弃诉讼后死亡，其继承人不得提起该项诉讼；仅仅开始诉讼还不够，除非其坚持进行。

<a id="5.2.15.2"></a>

**2.** 儿子针对两名继承人提起遗嘱违反亲属义务之诉，却分别获得不同判决：他胜诉于其中一人，败诉于另一人。此后，他可以按份额起诉债务人，也可以按份额被债权人起诉；他可以请求返还遗产中的具体物，并请求分割遗产。因为家产分割之诉确实适用：我们认为他已经按份额成为法定继承人。因此，遗产的一部分仍依遗嘱继承；认为遗产在一部分上属于无遗嘱继承，并非不合理。

### <a id="5.2.16"></a>5.2.16　帕比尼安《法律意见》第二卷

<a id="5.2.16.pr."></a>

**序言（pr.）** 儿子已经就母亲遗嘱违反亲属义务一事起诉其兄弟，并请求取得一部分遗产且胜诉；女儿既未起诉，也未胜诉，因此在依法定继承时不得与其兄弟共同继承。

<a id="5.2.16.1"></a>

**1.** 父亲依据解放权，以遗嘱外继承人的身份取得儿子的遗产占有并已取得遗产占有人地位。此后，死者的女儿——她本人也被父亲剥夺继承权——正当地提起遗嘱违反亲属义务之诉并胜诉。父亲取得的遗产占有随即失效：此前诉讼审理的是父亲的权利，而非遗嘱效力。因此，必须将全部遗产及其孳息返还给女儿。

### <a id="5.2.17"></a>5.2.17　保罗《法律问题》第二卷

<a id="5.2.17.pr."></a>

**序言（pr.）** 某人若并非以放弃为意而未参加遗嘱违反亲属义务之诉，就不应被计入其他拟提起同一诉讼者的应得份额。比如，一名被剥夺继承权的子女就父亲的遗嘱提起诉讼；因为遗嘱一旦撤销，另一子女也会被召来无遗嘱继承，所以该起诉人原本不应请求全部遗产。但如果他胜诉，就可以依据既判力主张权利，仿佛百人审判庭在使遗产成为无遗嘱继承时，认定现今世上只有他这一名儿子。

<a id="5.2.17.1"></a>

**1.** 遗嘱被判定违反亲属义务时，不认为死者具有订立遗嘱的能力。但如果因遗嘱指定的继承人未作答辩，法院在其缺席时判决到庭一方胜诉，则不能作相同认定；在此情形下，不能认为判决创设了实体权利。因此，释奴安排仍然有效，遗赠也仍可请求给付。

### <a id="5.2.18"></a>5.2.18　保罗《遗嘱违反亲属义务之诉单卷》

关于此事，神皇二帝的一项敕令也采纳了这种区分。

### <a id="5.2.19"></a>5.2.19　保罗《法律问题》第二卷

一位母亲临终时，在遗嘱中指定一名外人为四分之三份额的继承人，指定一名女儿继承四分之一份额，而遗漏了另一名女儿。被遗漏的女儿提起遗嘱违反亲属义务之诉并胜诉。有人询问，应如何救济遗嘱中被指定的女儿。我答复：被遗漏的女儿应主张其母亲无遗嘱死亡时本可取得的份额。因此可以说，若被遗漏的女儿以无遗嘱继承为由请求全部遗产并胜诉，她可能独自取得全部继承，正如另一女儿未主张法定继承时的情形。但是，不应允许她以遗嘱违反亲属义务为由对其姐妹起诉。还应当指出，接受遗嘱继承的女儿不同于被遗漏者。因此，她应向外人请求二分之一遗产，并主张整个二分之一均应从外人处取回，仿佛这全部二分之一都归她所有。依此，遗嘱并非整体失效，而只是在一部分上按无遗嘱继承处理，尽管立遗嘱人的最后意愿被视同心智失常者所作而予以否定。另一方面，如果有人认为被遗漏的女儿胜诉后遗嘱整体失效，那么也应当说，遗嘱中被指定的女儿仍可按无遗嘱继承接受遗产；因为她依据遗嘱继承而接受遗产——她认为遗嘱有效——并不被视为放弃法定继承；何况她并不知道该法定继承已归属于自己。即使那些知道自己权利的人，选择其认为自己可以主张的权利，也不会因此丧失其他权利。释奴主即属此例：他因错误认识而接受死者的遗嘱安排，也不被视为放弃对抗遗嘱的遗产占有。由此可见，被遗漏者不应请求整个遗产，因为遗嘱被撤销后，被指定继承人仍保有接受遗产的权利。

### <a id="5.2.20"></a>5.2.20　谢沃拉《法律问题》第二卷

想要提起遗嘱违反亲属义务之诉的人，即使其子身份遭到否认，也不应取得卡波尼安遗产占有。（只有在某人确为儿子的情况下本可成为继承人或遗产占有人时，才应给予这种遗产占有，使其暂时得以占有并获得扶养，且不因诉讼而遭受先决裁判的不利影响；但提起遗嘱违反亲属义务之诉的人，不应提起其他诉讼，也不应行使遗产请求之诉以外的任何诉权，底本此处作 *nec ali)*，疑有缺文，未予补足。）以免其处境反而优于对方承认其子身份时的情形。

### <a id="5.2.21"></a>5.2.21　保罗《答复集》第三卷

<a id="5.2.21.pr."></a>

**序言（pr.）** 如果某人提起遗嘱违反亲属义务之诉，却因遗嘱指定继承人的欺诈，误以为该继承人已受秘密委托将遗产三分之一返还给自己，而放弃该项诉讼，则不应视为其放弃了遗嘱违反亲属义务之诉；因此，不妨碍他重新提起已经开始的诉讼。

<a id="5.2.21.1"></a>

**1.** 又有人询问：在遗嘱违反亲属义务之诉提起之前，继承人请求返还自己已经支付的款项，是否应予受理？答复是：明知并无义务而仍支付遗嘱信托给付的人，不得基于该项给付请求返还。

<a id="5.2.21.2"></a>

**2.** 他还答复说：如果通过遗嘱违反亲属义务之诉，遗嘱指定继承人的继承权被撤销，就应当一如遗产尚未被接受那样处理全部事项。因此，胜诉者仍可向遗嘱指定继承人主张全部债权；遗嘱指定继承人也可主张债务抵销。

### <a id="5.2.22"></a>5.2.22　特里波尼安《论辩集》第十七卷

<a id="5.2.22.pr."></a>

**序言（pr.）** 儿子不因其父亲接受了母亲遗嘱所给的遗赠或接受了遗产而丧失控告母亲遗嘱违反亲属义务的权利，即便父亲仍对其行使家父权。我还说，父亲也不因儿子的权利而不得提起此项诉讼，因为受到损害的是儿子。

<a id="5.2.22.1"></a>

**1.** 又有人问：如果儿子提起诉讼未能胜诉，父亲所得之物是否应归入国库？这是因为儿子是为他人谋取胜诉利益，而本案并非审查父亲的身份或履职，完全取决于儿子本人提起诉讼的根据。应当倾向于认为，如果判决依照遗嘱作出，父亲不应丧失遗嘱给予他的利益。

<a id="5.2.22.2"></a>

**2.** 如果立遗嘱人把遗赠留给我，而其儿子在提起遗嘱违反亲属义务之诉后死亡，并指定我为继承人；我继续处理遗产争议而败诉，那么我不会因此丧失遗嘱留给我的利益；尤其是在死者已经开始提起诉讼的情况下。

<a id="5.2.22.3"></a>

**3.** 同样，如果我收养了这样一个人：他已就立遗嘱人留给我遗赠的那份遗嘱提起遗嘱违反亲属义务之诉；我以儿子的名义继续诉讼，却未能胜诉，那么我不应丧失遗赠。因为我并非不配受领，以致国库可以从我这里取走遗嘱留给我的利益；我提起诉讼并非以自己的名义，而是基于继承而取得的权利。

### <a id="5.2.23"></a>5.2.23　保罗《遗嘱违反亲属义务之诉单卷》

<a id="5.2.23.pr."></a>

**序言（pr.）** 假设一个被解放出家父权的儿子遭到遗漏，而留在家父权下的孙子被指定为继承人：该儿子可以针对自己的儿子、即立遗嘱人的孙子，请求对抗遗嘱的遗产占有；但不得提起遗嘱违反亲属义务之诉。如果被解放出家父权的儿子被剥夺继承权，则可以提起此诉；如此，他便与自己的儿子一同取得遗产。

<a id="5.2.23.1"></a>

**1.** 如果被剥夺继承权的人明知遗嘱指定继承人为继承人，仍从其处买下遗产或个别物件，或者租用田地或实施其他类似行为，或者向继承人清偿其原本欠立遗嘱人的债务，就被视为承认死者的遗嘱安排，并因此不得再提起遗嘱违反亲属义务之诉。

<a id="5.2.23.2"></a>

**2.** 如果有两名被剥夺继承权的儿子，二人都提起遗嘱违反亲属义务之诉，其中一人后来决定不再起诉，其份额便增归另一人。如果一人因时效届满而被排除，亦同。

### <a id="5.2.24"></a>5.2.24　乌尔比安《评萨宾》第四十八卷

关于遗嘱违反亲属义务之诉，常常会出现同一案件作出不同判决的情形。例如，兄弟之一提起诉讼，而遗嘱指定的继承人各自所据的继承权不同，该如何处理？如果确属如此，就应视为立遗嘱人部分依遗嘱、部分依无遗嘱继承而死亡。

### <a id="5.2.25"></a>5.2.25　乌尔比安《论辩集》第二卷

<a id="5.2.25.pr."></a>

**序言（pr.）** 如果赠与并非因死亡而作，而是生前赠与，但意在计入四分之一份额，可以说：如果受赠人通过赠与已经取得四分之一份额，便不得提起遗嘱违反亲属义务之诉；如果所得不足，则应依善良人士的裁量补足差额；或者至少应将所赠之物计入该份额。

<a id="5.2.25.1"></a>

**1.** 如果某人本来不得提起遗嘱违反亲属义务之诉，却获准起诉，并试图仅撤销遗嘱的一部分，且选择其中一名继承人作为被告提起此诉，那么应当认为该诉有效提起，因为遗嘱在部分范围内仍然有效，而排在此人之前的其他权利人已经被排除。

### <a id="5.2.26"></a>5.2.26　乌尔比安《论辩集》第八卷

某人以“释放斯提克斯”为条件被指定为继承人，并已释放该奴隶；此后遗嘱又被判定为违反亲属义务或不合法。公平起见，应予救济，使该人得从被释放者处取得奴隶的价额，以免其白白失去奴隶。

### <a id="5.2.27"></a>5.2.27　乌尔比安《意见集》第六卷

<a id="5.2.27.pr."></a>

**序言（pr.）** 提起遗嘱违反亲属义务之诉后，双方以协议解决争议；但继承人不履行协议。对此，通说认为遗嘱违反亲属义务之诉仍完整保留。

<a id="5.2.27.1"></a>

**1.** 有人主张自己是某人的儿子，而该人在遗嘱中否认其子身份，却仍将其剥夺继承权；此人仍可就该遗嘱提起遗嘱违反亲属义务之诉。

<a id="5.2.27.2"></a>

**2.** 士兵也不得就另一名士兵的遗嘱提起遗嘱违反亲属义务之诉。

<a id="5.2.27.3"></a>

**3.** 某孙子针对其叔父或其他遗嘱指定继承人，就遗嘱违反亲属义务之诉主张其份额并胜诉，但遗嘱指定继承人提起上诉。通说认为，在诉讼终结前，应考虑该未成年孙子的贫困状况，按照其通过该诉所主张的份额，裁定给予其生活供养；其对方有义务持续供养，直至诉讼终结。

<a id="5.2.27.4"></a>

**4.** 母亲误以为一名儿子已经死亡，因而指定另一人为继承人；对此母亲的遗嘱，可以提起遗嘱违反亲属义务之诉。

### <a id="5.2.28"></a>5.2.28　保罗《七人审判庭单卷释义》

一位母亲误闻其士兵儿子已经死亡，遂在遗嘱中指定其他人为继承人。神皇哈德良裁定，遗产应归该儿子，但仍须履行释奴安排和遗赠。此处特别记载了关于释奴和遗赠的补充规定：因为一旦遗嘱被指为违反亲属义务，该遗嘱的任何内容均不生效。

### <a id="5.2.29"></a>5.2.29　乌尔比安《意见集》第五卷

<a id="5.2.29.pr."></a>

**序言（pr.）** 如果遗嘱指定的继承人与提起遗嘱违反亲属义务之诉的人之间，疑有受遗赠人参与串通，已经确立：受遗赠人也可参加诉讼并维护死者的意愿；如果判决否定遗嘱，他们也可以提起上诉。

<a id="5.2.29.1"></a>

**1.** 非婚生子女也可以就其母亲的遗嘱提起遗嘱违反亲属义务之诉。

<a id="5.2.29.2"></a>

**2.** 即使遗嘱违反亲属义务之诉已经通过和解解决，遗嘱仍保持效力。因此，遗嘱中所作的释奴安排和遗赠，在《法尔基第法》许可的限度内，仍然有效。

<a id="5.2.29.3"></a>

**3.** 女性未经皇帝命令不得收养儿子；因此，某人误以为某女性是自己的养母，也不得就该女性的遗嘱提起遗嘱违反亲属义务之诉。

<a id="5.2.29.4"></a>

**4.** 应当在遗嘱指定继承人住所所在的行省，就遗嘱违反亲属义务提起诉讼。

### <a id="5.2.30"></a>5.2.30　马尔西安《法学阶梯》第四卷

<a id="5.2.30.pr."></a>

**序言（pr.）** 对于被交付他人收养之子的遗嘱，其生父可以正当地提起遗嘱违反亲属义务之诉。

<a id="5.2.30.1"></a>

**1.** 神皇塞维鲁和安东尼敕答说，监护人可以代表未成年人提起遗嘱违反亲属义务之诉或关于伪造遗嘱的诉讼，而不致危及遗嘱给予该未成年人的利益。

### <a id="5.2.31"></a>5.2.31　保罗《七人审判庭单卷释义》

<a id="5.2.31.pr."></a>

**序言（pr.）** 如果有权提起控告的人不愿或不能起诉，是否应由其后的权利人起诉，尚须考察。通说认为可以如此，以便依次递补。

<a id="5.2.31.1"></a>

**1.** 就子女或父母提起遗嘱违反亲属义务之诉而言，遗嘱指定的继承人是子女、外人还是自治市，并无区别。

<a id="5.2.31.2"></a>

**2.** 如果我成为某遗嘱指定继承人的继承人，而我想指控该份遗嘱违反亲属义务，这不会对我不利；尤其是在我并未占有该份额，或是依自己的权利占有时。

<a id="5.2.31.3"></a>

**3.** 如果立遗嘱人把某物遗赠给我，而他人依据该遗嘱取得了该物，则应作不同处理：如果我承认并接受该遗赠，就会被排除在控告之外。

<a id="5.2.31.4"></a>

**4.** 如果我曾以其他方式认可立遗嘱人的意愿，又该如何？例如，我曾在遗嘱中写明，父亲死后我会表示同意。此时我应被排除在控告之外。

### <a id="5.2.32"></a>5.2.32　保罗《遗嘱违反亲属义务之诉单卷》

<a id="5.2.32.pr."></a>

**序言（pr.）** 如果被剥夺继承权的人为请求遗赠的受遗赠人提供诉讼协助，或担任其代理人，就应被排除在控告之外；因为无论死者的安排如何，认可了其遗嘱决定的人，都被视为承认该决定。

<a id="5.2.32.1"></a>

**1.** 如果被剥夺继承权的人成为受遗赠人的继承人，并请求交付遗赠，我们要考察是否应将他排除在此项控告之外：可以确定的是，他认可了死者的安排；另一方面，确实没有依据遗嘱直接留给他的利益。尽管如此，他最好还是不请求该项遗赠。
