# <a id="6"></a><a id="5.6"></a>5.6.0　论遗嘱信托遗产请求之诉（*De fideicommissaria hereditatis petitione*）

### <a id="5.6.1"></a>5.6.1　乌尔比安《评告示》第十六卷

接下来出现的是为遗产已经返还之人设置的诉讼。凡依元老院决议接受返还遗产的人，均可提起遗嘱信托遗产请求之诉；依该决议，诉权随之移转。〔校勘疑点：底本在 *susceperit* 后引出 *“suscepit”*；疑为异文或校勘标记，正文按“接受”处理。〕

### <a id="5.6.2"></a>5.6.2　保罗《评告示》第二十卷

该诉讼适用的规则，与民法上的遗产请求之诉相同。

### <a id="5.6.3"></a>5.6.3　乌尔比安《评告示》第十六卷

<a id="5.6.3.pr."></a>

**序言（pr.）** 无论某人受嘱托将遗产返还给我，还是返还给后来由我继承的那个人，均无区别。此外，即使我是被指定取得遗嘱信托遗产之人的遗产占有人（*bonorum possessor*），或者是该人的其他继受人，也可以通过此诉提起请求。

<a id="5.6.3.1"></a>

**1.** 应当知道，此诉不得对已经返还遗产的人提起。

<a id="5.6.3.2"></a>

**2.** 此外，赋予我的，是本来可由继承人行使以及可针对继承人行使的那些诉权。
