# D.42.1 论既判力、裁判效力与中间裁定（*De re iudicata et de effectu sententiarum et de interlocutionibus*）—第二部分

<!-- source-p 61 -->
<a id="42.1.15.2"></a>**2**　因此，在出售依法扣押的质物时，首先命令扣押动产和牲畜，继而将其出售。若所得价款足够，事情便告解决；若仍不足，也命令扣押并出售不动产。若没有动产，则从不动产质物开始；所以裁判官通常会作出附条件的中间裁定：如果没有动产，也可扣押不动产。不得一开始便从不动产质物着手。若不动产质物仍不足，或根本没有此类质物，最终还会及于各种权利。因此，行省总督以这种方式执行既判。

<!-- source-p 62 -->
<a id="42.1.15.3"></a>**3**　若被扣押的质物找不到买受人，有敕答称，我国皇帝与其神圣的父皇裁定，应将该物判归债权人所有，但其价值不得超过所欠债额。若债权人宁愿将质物作为债额受领并持有，敕答又称，他不得再请求超过该物价值的债额；因为债权人既满足于持有质物，就仿佛已通过协议处分了债权。他不得一方面将质物保留至确定数额，另一方面又请求余额。

<!-- source-p 63 -->
<a id="42.1.15.4"></a>**4**　若对依质权扣押的财物发生权属争议，我国皇帝已规定，执行既判的人应当审理其所有权；若查明财物属于被判决者，便应执行既判。但须知，他们只能作概略审查；其裁定不得对债务人产生先决效力。例如，他们若认为该物应予释放，因为它属于提出争议者而非以其名义扣押该物之人，便不得据此妨碍债务人日后另行主张权利；同样，即使该物已返还给争议者，若其后依通常程序有人向其请求返还，也不能仅凭该裁定便认定他当然胜诉。由此可见，在各方权利均不受影响的前提下，既判仅在扣押方面发生作用。但若争议仅涉及某一质物，而另有无争议的财物，则应释放该质物，改为扣押其他财物。

<!-- source-p 64 -->
<a id="42.1.15.5"></a>**5**　若被扣押之物本身已为他人设定质权，应考虑能否在保留先前债权人权利的同时出售该物，并将余额用于清偿判决债务。尽管债权人并无义务出售其接受质押的财物，但在执行判决时应遵循以下做法：若被扣押的财物有买受人，且买受人愿意在先前债权人获得清偿后支付余额，也应允许出售该物。如此并未使该债权人的地位恶化；在其受偿之前，其质权并不解除。

<!-- source-p 65 -->
<a id="42.1.15.6"></a>**6**　若质物判归买受人后，有人就该物向买受人提出争议，应考虑是否由执行判决的同一法官审理。既然买卖已经完成，标的物风险由买受人承担，我认为不应再由该法官审理。尤其是买受人已经被引入占有之后，这些法官的职权岂不就此终止？若财物判归既判债权人本人，也应作同样处理。

<!-- source-p 66 -->
<a id="42.1.15.7"></a>**7**　若法官执行判决、将质物判归买受人后，买受人不支付价款，应考虑负责执行判决的同一法官能否对买受人采取强制措施。我认为他们不应继续介入，否则事情会无休止地扩大。我们该怎么说呢？他们要先判令买受人承担责任，再对其执行判决，还是径直将其视同已受判决？若买受人否认曾经购买，或主张已经付款，又该怎么办？因此，较妥当的做法是不让这些法官介入；况且，要求清偿判决债务的人对买受人也没有诉权。这并不会使债权人遭受不公，因为依法扣押并出售的质物应以即时支付价款的方式出售，不得约定日后付款。若这些法官确实介入，其权限也仅限于重新扣押并出售已经判归买受人的该物，仿佛该物尚未解除质押。

<!-- source-p 67 -->
<a id="42.1.15.8"></a>**8**　若没有其他可供扣押的财物，法官执行判决时也可以依质权扣押债权。我国皇帝曾敕答，债权也可以依质权扣押。

<!-- source-p 68 -->
<a id="42.1.15.9"></a>**9**　但我们要考察，是否只能扣押债务人承认的债权，还是连其否认的债权也可以扣押。较妥当的意见是，仅扣押债务人承认的债权；若债权遭到否认，最公平的做法是放弃扣押该债权。有人或许会仿照有体质物的先例，主张法官可以进一步审理该债权是否存在，正如他们审理财物所有权一样；但敕答对此持相反意见。

<!-- source-p 69 -->
<a id="42.1.15.10"></a>**10**　那么，法官应亲自向债务人请求该债权并收取所欠款项，再将其用于清偿判决债务，还是应像出售有体质物那样出售该债权？应当采取对执行判决更为便利的做法。

<!-- source-p 70 -->
<a id="42.1.15.11"></a>**11**　若款项存放在银行家处，也同样可以扣押。此外，若款项虽存放在他人处，但已指定交给被判决者，也通常可依质权扣押，并用于清偿判决债务。

<!-- source-p 71 -->
<a id="42.1.15.12"></a>**12**　此外，通常也会扣押以被判决者名义寄托的款项，或其存放在钱箱中的款项，以便清偿判决债务。更进一步，若为购买庄园而将未成年人财产中的款项存入钱箱，即使未获裁判官许可，执行判决者通常也可扣押该款项，并将其用于清偿判决债务。
