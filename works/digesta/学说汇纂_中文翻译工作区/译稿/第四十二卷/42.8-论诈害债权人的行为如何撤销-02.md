# D.42.8 论诈害债权人的行为如何撤销（*Quae in fraudem creditorum facta sunt ut restituantur*）·下

> 底本：*Digesta Iustiniani*，EPUB `book-42.xhtml`，source-p 658–721。

<!-- source-p 658 -->
<a id="42.8.10.16"></a>**16**　若我追上了逃跑中的债务人——他是我的债务人，也欠着其他数名债权人的债务，且随身携带钱款——并取走了足以清偿我债权的款项，尤利安认为，这种行为是在债权人将其财产置于占有之前还是之后发生，二者大有区别：若发生在此前，事实诉权不适用；若发生在此后，则适用该诉权。

<!-- source-p 659 -->
<a id="42.8.10.17"></a>**17**　若依神圣马尔库斯的敕令，为保全奴隶自由而将财产判归某人，该诉权便不适用；因为受领人以继承人身份承继，其父家长所实施的行为均属有效。

<!-- source-p 660 -->
<a id="42.8.10.18"></a>**18**　该事实诉权的一年期间，自财产变卖之日起计算。

<!-- source-p 661 -->
<a id="42.8.10.19"></a>**19**　依此诉权返还财产时，应连同该财产的法律状态一并恢复。

<!-- source-p 662 -->
<a id="42.8.10.20"></a>**20**　应返还孳息，不仅包括已经收取的孳息，也包括欺诈者本可以收取的孳息；但须扣除所支出的费用。依裁判官的裁量，在必要费用得到偿还之前，不得强令其返还该物；若其依保证人或债权人的意思支出了其他费用，也应作同样处理。

<!-- source-p 663 -->
<a id="42.8.10.21"></a>**21**　我认为，奴隶女所生子女也应纳入该诉权的范围。

<!-- source-p 664 -->
<a id="42.8.10.22"></a>**22**　此外还应一般性地知道，依此诉权应恢复原状，无论涉及物还是债务关系，均应一概恢复，犹如从未发生免除债务之事。因此，若债务未被免除，当事人本可在中间期间取得的利益，也应予以给付；但若利息未被纳入要式口约，则不应给付。若该契约属于即使未以要式口约约定也可能产生利息的类型，则另当别论。

<!-- source-p 665 -->
<a id="42.8.10.23"></a>**23**　若债务附有条件，应连同该条件一并恢复；若债务定有到期日，则应连同该到期日一并恢复。但若债务有固定的终止期限，可以说，要求恢复的期间不得超过该债务剩余的期限，而不必一概限于诉权的一年期间。

<!-- source-p 666 -->
<a id="42.8.10.24"></a>**24**　一年期满后，该诉权仍可对被诉之人行使，但仅限于实际到达其手中的利益。法务官认为，让因欺诈获利的人保有利益是不公平的；因此认为应从其手中追回该利益。无论受领人本人是欺诈者还是其他任何人，只要利益到达其手中，或因其恶意行为而未能到达其手中，均可在该利益范围内对其提起诉讼。

<!-- source-p 667 -->
<a id="42.8.10.25"></a>**25**　该诉权可由继承人及其他继受人行使；也可对继承人及类似身份的人提起。

<a id="42.8.17.pr."></a>**序言**　所有为诈害债权人而被免除债务的债务人，均应依此诉权恢复至原有债务关系。

<!-- source-p 689 -->
<a id="42.8.17.1"></a>**1**　卢基乌斯·提提乌斯有债权人，却将全部财产交给自己的释奴，而这些释奴也是他的自然子女。答复如下：即使案情未说明他具有诈害意图，但凡知道自己有债权人而仍处分全部财产的人，均应视为具有诈害债权人的意图。因此，即使其子女不知道父亲有此意图，也应依该诉权承担责任。

<!-- source-p 690 -->
<a id="42.8.17.2"></a>**2**　若丈夫意图诈害债权人，在婚姻解除后，提前将嫁资返还给妻子，而依约本应在指定日期才返还，则妻子仅在债权人因嫁资被提前返还而受影响的范围内承担责任；因为法务官也认为，诈害可以发生在时间安排上。

<a id="42.8.23"></a>**42.8.23**

首顺位的遗嘱继承人发现，死者的财产至多只够偿还四分之一的债务。为维护死者的名誉，经债权人同意并获行省总督授权，他们依皇帝敕令并附加如下条件接受继承：仅向债权人清偿一定比例。有人问，遗嘱中获释的奴隶能否取得自由及生活供养。答复说，若授予自由并非为诈害债权人，则该自由应当有效；但若遗产无清偿能力，则遗赠不应给付。

<!-- source-p 709 -->
<a id="42.8.24"></a>**42.8.24**

<!-- source-p 710 -->
斯凯沃拉《公开讨论问题集》单卷。

<!-- source-p 711 -->
未适婚人继承了父亲的遗产，并向一名债权人清偿；随后他拒绝接受父亲的遗产，而父亲的财产被变卖。有人问，是否应追回该债权人所收取的款项，以免其处境优于其他债权人。是否应区分其受领款项是出于赠与还是基于正当清偿？若系监护人出于偏袒而支付，则应追回，使该债权人仅能取得其他债权人本可按比例分得的数额。反之，若该债权人依法请求清偿，而其他债权人怠于请求，期间财物又因自然损耗、动产被转移或不动产价值受损而贬损，则不得以任何方式追回该债权人所收款项，因为其他债权人应自行承担怠于行事的后果。那么，若在债务人的财产即将被变卖时，他向我支付了款项，我是否应依此诉权返还？是否还应区分：是他主动向我提出付款，还是我违背其意愿强行向他索取？若是违背其意愿强行索取，则应追回；若并非如此，则不应追回。但我已经勤勉行事，使自己的处境更好；市民法是为勤勉之人制定的。因此，我所收取的款项不予追回。

<!-- source-p 712 -->
<a id="42.8.25"></a>**42.8.25**

<!-- source-p 713 -->
维努莱乌斯·萨图尔尼努《令状论》第六卷。

<!-- source-p 714 -->
<a id="42.8.25.pr."></a>**序言**　若欺诈者明知情而以要式免除方式免除其保证人的债务，且主债务人也知情，则二人均承担责任；若主债务人不知情，则仅知情者承担责任。但若获免除债务的保证人无清偿能力，还须考察是否应对主债务人提起诉讼，即使主债务人不知情也是如此，因为他是通过赠与取得利益。反之，若明知情而免除的是主债务人的债务，则保证人若也知情，仍应承担责任；若其不知情，是否也应对其提起诉讼？毕竟，他所受的与其说是损失，不如说是获利。至于有两名主债务人的情形，二人的处境相同。

<!-- source-p 715 -->
<a id="42.8.25.1"></a>**1**　若欺诈者岳父明知情而将嫁资交给女婿，女婿应依此诉权承担责任；但若女婿返还嫁资，他便不再保有该嫁资。拉贝奥说，女儿已被解放出父权并离婚后，女婿无须向她返还任何款项，因为该诉权旨在返还财物，而非施加刑罚；因此，被告通常只要返还财物即可免责。但若债权人尚未对女婿提起诉讼，女婿已在嫁资之诉中被判向女儿返还嫁资，则拉贝奥说，他仍应依此诉权承担责任，且不得向女儿追偿。若他未经法院裁判而返还，则是否享有返还请求权，尚须考察。若女婿不知情而女儿知情，则女儿承担责任；若二人均知情，则二人均承担责任。若二人均不知情，有些人认为仍应对女儿授予诉权，因为可以认为她如同受赠一样取得了利益；或者至少应要求她作出担保，承诺返还所取得的利益。但不应对不知情的丈夫授予诉权，正如不应对从欺诈者处收取应得款项的债权人授予诉权一样；毕竟，若妻子没有嫁资，他原本不会娶她。

<!-- source-p 716 -->
<a id="42.8.25.2"></a>**2**　同样，若第三人以处于家父权下的女儿为名，为诈害债权人而给付嫁资，则丈夫知情时应承担责任；女儿也同样承担责任；若父亲知情，他也应承担责任，并须保证：若嫁资到达自己手中，就予以返还。

<!-- source-p 717 -->
<a id="42.8.25.3"></a>**3**　若代理人不告知本人，且明知本人之债务人意图诈害债权人，却命奴隶从该债务人处受领财物，则应由代理人本人依此诉权承担责任，而非由本人承担。

<!-- source-p 718 -->
<a id="42.8.25.4"></a>**4**　应返还的不仅是被处分的物本身，也包括在处分时附着于土地的孳息，因为这些孳息当时属于欺诈者的财产；还包括诉讼开始后收取的孳息。但中间期间收取的孳息不属于返还范围。同样，受欺诈处分的女奴在中间期间所生子女不应返还，因为该子女当时并不属于欺诈者的财产。

<!-- source-p 719 -->
<a id="42.8.25.5"></a>**5**　普罗库鲁斯说，若妇女在财产被处分后才怀孕，并在诉讼开始前分娩，毫无疑问，所生子女不应返还；但若她在财产被处分时已经怀孕，则可以认为该子女也应返还。

<!-- source-p 720 -->
<a id="42.8.25.6"></a>**6**　拉贝奥说，他不完全明白法务官所说的“附着于土地的孳息”，究竟仅指已经成熟的孳息，还是也包括尚未成熟的孳息。不过，即使法务官所指仅为已经成熟的孳息，也不应因此另行返还占有。因为土地被处分时，土地及其孳息构成一个整体，也就是土地本身；各种形式的土地处分均随土地而及于其孳息。有人在冬季持有一处价值一百的土地，临近收获或葡萄采收时能以十出售其孳息，并不因此应被认为拥有两项财产，即价值一百的土地和价值十的孳息；应认为其只有一项财产，即价值一百的土地。正如可以将房屋用地与房屋分别出售的人，也仍被视为持有一项财产。

<!-- source-p 721 -->
<a id="42.8.25.7"></a>**7**　即使欺诈者本人，也可以成为该诉权的被告，尽管梅拉不认为该诉权可以对欺诈者提起，因为财产变卖后，不应再依据此前处理的事务对其提起诉讼；而对财产已被剥夺的人提起诉讼是不公平的。〔底本疑误：此处拉丁文作 *bona ablata essententiarum*。〕不过，若欺诈者将某些财物挥霍掉，且无任何方式可以追回，即使如此仍可对其提起诉讼；此时法务官对已失去全部财产之人，似乎并非着眼于诉讼可带来的利益，而是着眼于惩罚。

> 译注：P721 的 *bona ablata essententiarum* 疑为粘连或讹误，正文暂依句意译作“财产已被剥夺”，未据此猜补原文。
