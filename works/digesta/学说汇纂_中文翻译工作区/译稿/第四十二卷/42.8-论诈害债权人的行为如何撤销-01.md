# D.42.8 论诈害债权人的行为如何撤销（*Quae in fraudem creditorum facta sunt ut restituantur*）·上

> 底本：*Digesta Iustiniani*，EPUB `book-42.xhtml`，source-p 594–657。

<!-- source-p 594 -->
<a id="8"></a><a id="42.8"></a>**42.8.0**　论诈害债权人的行为如何撤销。

<!-- source-p 595 -->
<a id="42.8.1"></a>**42.8.1**

<!-- source-p 596 -->
乌尔比安《告示评注》第六十六卷。

<!-- source-p 597 -->
<a id="42.8.1.pr."></a>**序言**　法务官说：“对于为诈害债权人而实施、且相对人并非不知该欺诈的行为，我将在自可以提起诉讼之日起一年内，向财产管理人或依法应获准就此事提起诉讼之人授予诉权；对于实施欺诈者本人，我也将适用同一规则。”

<!-- source-p 598 -->
<a id="42.8.1.1"></a>**1**　法务官确有必要发布这项敕令，以便保护债权人，使一切为诈害债权人而处分的财产均得以追回。

<!-- source-p 599 -->
<a id="42.8.1.2"></a>**2**　法务官说：“凡以诈害为目的而实施的行为。”这些用语概括广泛，涵盖一切为诈害债权人而实施的处分或任何契约行为。因此，凡为欺诈目的所为，无论属于何种行为，均可依这些用语撤销，因为其涵盖范围甚广。无论是处分财产，还是通过要式免除或协议免除某人的债务，

<!-- source-p 600 -->
<a id="42.8.2"></a>**42.8.2**

<!-- source-p 601 -->
乌尔比安《告示评注》第七十三卷。

<!-- source-p 602 -->
同样的规则也应适用：若其解除质押，或为诈害债权人而使他人取得优先地位。

<!-- source-p 603 -->
<a id="42.8.3"></a>**42.8.3**

<!-- source-p 604 -->
乌尔比安《告示评注》第六十六卷。

<!-- source-p 605 -->
<a id="42.8.3.pr."></a>**序言**　若某人给予他人抗辩，或者为诈害债权人而使自己承担义务、支付款项，或实施任何其他诈害债权人的行为，显然均适用该敕令。

<!-- source-p 606 -->
<a id="42.8.3.1"></a>**1**　我们理解的“为诈害而实施的行为”，不只包括当事人订立契约的行为；例如，某人故意不出庭、任由诉讼因未继续进行而消灭，或者不向债务人请求给付以致时效届满，或者丧失用益权或地役权，也包括在内。

<!-- source-p 607 -->
<a id="42.8.3.2"></a>**2**　凡有人为使自己不再拥有原有财产而采取行为，也属于该敕令的适用范围。

<!-- source-p 608 -->
<a id="42.8.4"></a>**42.8.4**

<!-- source-p 609 -->
保罗《告示评注》第六十八卷。

<!-- source-p 610 -->
即使某人没有做其本应做的事，也应理解为实施了诈害行为；例如，他不行使地役权：

<!-- source-p 611 -->
<a id="42.8.5"></a>**42.8.5**

<!-- source-p 612 -->
盖尤斯《行省告示评注》第二十六卷。

<!-- source-p 613 -->
又如，某人将自己的物作为遗弃物处理，以便他人取得该物为自己所有。

<!-- source-p 614 -->
<a id="42.8.6"></a>**42.8.6**

<!-- source-p 615 -->
乌尔比安《告示评注》第六十六卷。

<!-- source-p 616 -->
<a id="42.8.6.pr."></a>**序言**　某人本可取得某物，却不采取行动使自己取得该物，这不属于该敕令的适用范围；该敕令针对的是减少自己财产的人，而非仅仅不使自己变得更加富有的人。

<!-- source-p 617 -->
<a id="42.8.6.1"></a>**1**　因此，若某人不履行条件是为了避免要式口约发生效力，他的情形就不属于该敕令的适用范围。

<!-- source-p 618 -->
<a id="42.8.6.2"></a>**2**　同理，拒绝接受法定继承或遗嘱继承的人，也不属于该敕令的适用情形：他只是不愿取得财产，并未减少自己的既有财产。

<!-- source-p 619 -->
<a id="42.8.6.3"></a>**3**　同样，若某人解放其子，使儿子可以自行决定是否接受继承，该敕令也不适用。

<!-- source-p 620 -->
<a id="42.8.6.4"></a>**4**　同样可以认定，拒绝接受遗赠者不适用该敕令；尤利安也如此记载。

<!-- source-p 621 -->
<a id="42.8.6.5"></a>**5**　若某人出售其奴隶，而该奴隶已被指定为继承人，以便奴隶依买受人的命令接受继承：如果买卖本身并无欺诈，只是接受继承涉及欺诈，敕令便不适用，因为此人原本也可以拒绝接受继承。但若奴隶的处分本身构成欺诈，则应予撤销，正如为诈害债权人而释奴时应予撤销一样。

<!-- source-p 622 -->
<a id="42.8.6.6"></a>**6**　拉贝奥记载，收取自己应得之物的人似乎并未实施欺诈，也就是说，收取自己应得债权的人不构成欺诈。毕竟，若总督违其意愿强令某人清偿，而该人仍可不受制裁地拒绝清偿，那是不公平的。因为整部敕令针对的是法务官不介入的契约，例如质押与买卖。

<!-- source-p 623 -->
<a id="42.8.6.7"></a>**7**　应知，尤利安记载且我们也依此法律处理：债权人在债务人的财产尚未被债权人占有之前，收取其到期债权的给付，即使明知债务人无清偿能力，也不受该敕令约束；这是他自己勤勉行事的结果。但若债权人在债务人的财产已被占有后才收取债权给付，则应被要求按比例参与，并与其他债权人平等受偿。因为在全体债权人地位已经平等之后，他不应抢在其他债权人之前受偿。

<!-- source-p 624 -->
<a id="42.8.6.8"></a>**8**　该敕令制裁的是明知某行为意在诈害债权人，仍接受该项诈害行为的人。因此，若某行为虽为诈害债权人而实施，但受领者并不知情，敕令的文字似乎不适用。

<!-- source-p 625 -->
<a id="42.8.6.9"></a>**9**　此外还应知道，某人与欺诈者订约或接受其承诺时，若其他债权人同意此事，便不视为诈害债权人；毕竟，对知情并同意的人，不可能构成欺诈。

<!-- source-p 626 -->
<a id="42.8.6.10"></a>**10**　若未适婚人实施诈害债权人的行为，拉贝奥说，只要债权人确受损害，无论如何都应撤销该行为；未适婚人因年龄而无知，不应成为欺骗债权人的手段，也不应使其本人获利。我们也依此法律处理。

<!-- source-p 627 -->
<a id="42.8.6.11"></a>**11**　同理，若某人接受赠与，也无须考察受赠人是否知道赠与是为诈害债权人而作；只须考察债权人是否因此受损。受赠人并未遭受不法损害，因为只是剥夺了其所得利益，并未加诸损失。不过，对不知情而从无清偿能力者处受赠的人，只能在其因而变得较为富有的范围内授予诉权，超出该范围则不应授予。

<!-- source-p 628 -->
<a id="42.8.6.12"></a>**12**　同理，若奴隶明知债务人无清偿能力而接受其财物、但主人并不知情，是否应由主人承担责任，也值得讨论。拉贝奥说，主人仅在以下范围内承担责任：返还实际到达其手中的财物，或者仅在特有产范围内被判承担责任，或者就其事务因而受益的部分承担责任。对处于家父权下的儿子，也应作同样处理。但若主人知情，则应以主人本人名义对其提起诉讼。

<!-- source-p 629 -->
<a id="42.8.6.13"></a>**13**　又如，必然继承人已经履行遗赠，之后其财产被变卖；普罗库鲁斯说，即使受遗赠人不知情，也应给予准诉权。对此毫无疑问。

<!-- source-p 630 -->
<a id="42.8.6.14"></a>**14**　该诉讼的一年期间，自财产变卖之日起计算；此为可用期间。

<!-- source-p 631 -->
<a id="42.8.7"></a>**42.8.7**

<!-- source-p 632 -->
保罗《告示评注》第六十二卷。

<!-- source-p 633 -->
若债务人为诈害债权人，以低价将农庄卖给明知情的买受人；此后，有权请求撤销该处分的人请求返还农庄。有人问，是否应返还价款。普罗库鲁斯认为，无论如何都必须返还农庄，即使价款尚未支付也是如此。敕答亦依普罗库鲁斯的意见作出。

<!-- source-p 634 -->
<a id="42.8.8"></a>**42.8.8**

<!-- source-p 635 -->
维努莱乌斯·萨图尔尼努《令状论》第六卷。

<!-- source-p 636 -->
据此可以推知，买受人甚至无权请求返还部分价款。不过，也可以说，应由仲裁人根据具体情况审查：若已支付的钱款仍在债务人的财产中，就命令返还，因为这样便不会有人遭受损害。

<!-- source-p 637 -->
<a id="42.8.9"></a>**42.8.9**

<!-- source-p 638 -->
保罗《告示评注》第六十二卷。

<!-- source-p 639 -->
某人明知债务人的财产已被债权人占有，仍向该债务人购买财物，之后又将其出售给善意买受人。有人问，能否对第二买受人提起诉讼。萨宾的意见更为正确：善意买受人不承担责任，因为欺诈只应损害实施欺诈的人。正如我们所说，某人若不知情地直接从债务人处购买，也不承担责任；至于先前明知情而买入、再转卖给善意买受人的人，则应在其所收取的价款全额范围内承担责任。

<!-- source-p 640 -->
<a id="42.8.10"></a>**42.8.10**

<!-- source-p 641 -->
乌尔比安《告示评注》第七十三卷。

<!-- source-p 642 -->
<a id="42.8.10.pr."></a>**序言**　法务官说：“卢基乌斯·提提乌斯意图诈害债权人而实施行为、且你明知其意图的，你应将这些行为所涉及的财产返还给本案中的债权人；但以这些债权人依我发布的告示就本案应享有诉权为限，并且从他们可以就本案提起诉讼时起不得超过一年。某些情况下，经审查具体情形，即使你并不知情，我也将准许事实诉权。”

<!-- source-p 643 -->
<a id="42.8.10.1"></a>**1**　只有诈害债权人的行为已经产生实际结果时，才撤销该行为；也就是说，为了诈害而实施行为的那些债权人，已经使债务人的财产被变卖。反之，若债务人已清偿其原本意图诈害的债权人，随后又出现其他债权人：如果他只是清偿前一批债权人，之后才负担对其他人的债务，则不予撤销；但如果他使用那些本不意图诈害之人的钱款，清偿了原本意图诈害的债权人，马尔凯鲁斯说，应予撤销。塞维鲁与安敦尼皇帝的敕答也依此区分作出；我们亦依此法律处理。

<!-- source-p 644 -->
<a id="42.8.10.2"></a>**2**　法务官所说的“你明知”，我们理解为“你是共谋者并参与了欺诈”；若我只是知道某人有债权人，并不足以据此断定应以事实诉权追究我的责任；只有我参与欺诈时，才是如此。

<!-- source-p 645 -->
<a id="42.8.10.3"></a>**3**　若某人虽未参与欺诈，但债务人出售财产时，债权人曾当着证人面警告他不要购买，而他仍然购买，是否应以事实诉权追究？较妥当的意见是应当追究；毕竟，受到正式警告仍坚持购买者，并非没有欺诈。

<!-- source-p 646 -->
<a id="42.8.10.4"></a>**4**　另有一种情形：某人知道他人有债权人，但只是与其普通订约，并无参与欺诈之意；这种人似乎不应依此诉权承担责任。

<!-- source-p 647 -->
<a id="42.8.10.5"></a>**5**　法务官说“你明知”，指的是将以此诉权被诉之人。那么，若监护人知情而未适婚人不知情，监护人的知情是否会对诉权产生不利影响？对精神失常者或未成年人之保佐人，也有同样问题。我认为，监护人或保佐人的知情，仅在有财物到达他们手中的范围内，才对其所监护或保佐之人产生不利影响。

<!-- source-p 648 -->
<a id="42.8.10.6"></a>**6**　此外还应讨论：所谓为诈害债权人而处分的财产可以追回，是否要求债权人仍为同一批人。即使原受诈害债权人中只有一人仍在，或者起初有多个债权人、其他人均获清偿而仅此一人留下，也应认定该诉权仍然适用。

<!-- source-p 649 -->
<a id="42.8.10.7"></a>**7**　只要行为人知道有一名债权人将受诈害，即使不知道其他债权人，也足以适用该诉权。

<!-- source-p 650 -->
<a id="42.8.10.8"></a>**8**　那么，若行为人知道的那名债权人已经获得清偿，诉权是否就不再适用，因为其余债权人并未受诈害？我认为应采此说。但若有人说：“我愿意向我所知的那名债权人清偿其债权”，不得准许他借此规避该诉权。

<!-- source-p 651 -->
<a id="42.8.10.9"></a>**9**　若欺诈者有继承人，而继承人的财产被变卖，所涉并非本案针对的那一份财产，因此该诉权不适用。

<!-- source-p 652 -->
<a id="42.8.10.10"></a>**10**　若儿子本可拒绝接受继承，却为诈害债权人而实施行为，后来又获准恢复原状、退出其所介入的继承；或者某人自愿接受继承，之后因未适婚年龄或其他正当事由获准恢复原状，也应认为债权人享有准诉权。对必然继承人也一样。拉贝奥写道，应作如下区分：若债权人立即变卖财产，或者必然继承人在债权人缺席或同意的情况下介入继承，则应撤销双方的欺诈行为，即遗嘱人和必然继承人的行为。反之，若债权人容许必然继承人介入，并仿佛将其视为债务人，或者因利息的吸引或其他理由而信赖他，则不应撤销遗嘱人所作的处分。

<!-- source-p 653 -->
<a id="42.8.10.11"></a>**11**　若未适婚人继承父亲遗产，在获准将父亲遗产与本人财产分离后，父亲或未适婚人、监护人、保佐人的诈害行为均应予撤销。

<!-- source-p 654 -->
<a id="42.8.10.12"></a>**12**　若债务原定于将来某日到期，而欺诈者当场提前清偿，则就其因提前清偿而取得的时间利益，应认为适用事实诉权；因为法务官也认为，诈害可以发生在时间安排上。

<!-- source-p 655 -->
<a id="42.8.10.13"></a>**13**　若债务虽未清偿，但债权人就旧债接受了质押，也适用该诉权；这一点已多次得到确立。

<!-- source-p 656 -->
<a id="42.8.10.14"></a>**14**　若妻子与人合谋诈害债权人，并以设立嫁资为名，通过要式免除使其丈夫亦即债务人免除债务，则适用该诉权；债务人所欠的全部款项均可依此诉权请求清偿，妻子也不得提起嫁资之诉。毕竟，不得为诈害债权人而设立嫁资。这一点极为确定，且已多次确立。该诉权的结果是，先前以要式免除方式消灭的要式口约应恢复原状并重新成立。

<!-- source-p 657 -->
<a id="42.8.10.15"></a>**15**　依此诉权，也可以请求返还用益权以及类似的要式口约，例如：“你承诺每年给付十个钱币吗？”
