<a id="42.5.6.pr."></a>**序言**　若让未成年人保留父母的遗产并不有利，裁判官就准许出售死者的财产，以便将剩余财产返还给未成年人。

<!-- source-p 396 -->
<a id="42.5.6.1"></a>**1**　若未成年人在表示不承受遗产之前已经实施某些行为，应予维持，尤其是其行为出于善意时。

<!-- source-p 397 -->
<a id="42.5.6.2"></a>**2**　那么，若未成年人向某些债权人清偿后，财产又被出售，应如何处理？若问题在于能否请求返还，应依具体事由裁断。尤利安说，这样可以避免他人的疏忽或贪婪损害行事勤勉之人。可是，若保佐人在双方债权人均提出请求时，偏袒其中一方并向其付款，那么公平的做法是：要么先向该人追索与我应得份额相同的部分，要么将你已收取之款分给我；尤利安也这样说。显然，他说的是以父亲遗产中的财产付款的情形。那么，若未成年人以其他来源的财产付款，是否应返还给他？又应由债权人返还，还是从遗产中返还？我们的斯凯沃拉说，若遗产中尚有财产，应参照事务管理人的情形，将全部款项从遗产中扣除；若遗产中已无财产，则允许未成年人以不当清偿为由向债权人请求返还，并无不公。

<a id="42.5.8.pr."></a>**序言**　出售财产时，用益权也包括在内，因为“所有权人”这一称谓也涵盖用益权人。

<!-- source-p 404 -->
<a id="42.5.8.1"></a>**1**　若可以从债务人的土地收取孳息，已获准占有该土地的债权人应当出售或出租该孳息；但仅限于债务人此前尚未出售或出租孳息的情形。若债务人已经出售或出租，裁判官应维持其所作的买卖或租赁，即使价格较低也如此；除非该交易是为了诈害债权人。若属诈害，裁判官便可授权债权人重新出租或出售。

<!-- source-p 405 -->
<a id="42.5.8.2"></a>**2**　其他财物的孳息也应作相同处理：凡可出租的，就应出租，例如奴隶、役畜及其他可出租财物所产生的收益。

<!-- source-p 406 -->
<a id="42.5.8.3"></a>**3**　裁判官没有规定租赁期限，因此租赁多长时间似乎由债权人自由决定；是否出售或出租，也由他们酌定，但不得有恶意欺诈。他们不因过失而承担责任。〔末句所指责任范围待核。〕

<!-- source-p 407 -->
<a id="42.5.8.4"></a>**4**　若只有一人占有财产，租赁事务很简单；但若有多人占有，就会产生应由谁出租或出售的问题。若他们达成一致，处理最为简便：可以共同出租，也可以将事务交给其中一人办理。若不能达成一致，则应由裁判官查明情况后，选定负责出租或出售的人。

<a id="42.5.9"></a>**42.5.9**

<!-- source-p 409 -->

<!-- source-p 410 -->
<a id="42.5.9.pr."></a>**序言**　裁判官说道：“若有人在占有财产期间，未将其因该占有而收取的孳息返还给有权取得之人；或者未补偿其无恶意欺诈而支出的费用；或者据称因其恶意欺诈使占有财产的状况恶化，我将就此授予事实诉权。”

<!-- source-p 411 -->
<a id="42.5.9.1"></a>**1**　裁判官所说的孳息，也应理解为债务人财产所产生或带来的一切其他利益。确实应当如此：例如，若他因和解协议或其他原因获得罚金，该罚金也必须交付。

<!-- source-p 412 -->
<a id="42.5.9.2"></a>**2**　裁判官所说“未补偿其无恶意欺诈而以费用名义支出的款项”，是指债权人自己支出费用时，只要并无恶意欺诈，就应予补偿。因此，只要其支出时没有恶意欺诈，即已足够，即使该项支出对债务人的财物并无益处也一样。

<!-- source-p 413 -->
<a id="42.5.9.3"></a>**3**　“有权取得该物之人”一语，也包括为变卖财产而指定的管理人；若发生债务人财产免于出售的情形，债务人本人也包括在内。因此，该债权人可针对上述人员提起诉讼，请求返还其为收取孳息、供养和照料家内奴隶、支撑或修缮土地上的建筑、就尚未发生的损害提供承诺，或在奴隶受到诺克萨之诉时为其辩护而支出的费用；但若交出奴隶比留置更为有利，就不在此限。若交出更为有利，结论应是债权人不得请求返还该项费用。

<!-- source-p 414 -->
<a id="42.5.9.4"></a>**4**　还应概括地说：凡其为该物支出的费用，只要支出时没有恶意欺诈，均可请求返还。他不能提起事务管理之诉；这与共有人修缮共有建筑物的情形相似，因为在此情形中，债权人似乎也是在处理共有事务，而非他人事务。

<!-- source-p 415 -->
<a id="42.5.9.5"></a>**5**　此外还有一个问题：若土地因债权人没有恶意欺诈而恶化，土地上的权利丧失、建筑物被拆除或烧毁，或者家内奴隶和牲畜未得到照料，或财产占有在无恶意欺诈的情况下交给他人，债权人是否应承担责任？显然，他不应承担责任，因为他没有恶意欺诈；因此，其地位优于质权债权人，后者不仅对恶意欺诈负责，也对过失负责。财产管理人的情形相同，因为他也像债权人一样承担责任。

<!-- source-p 416 -->
<a id="42.5.9.6"></a>**6**　若有人既未出租土地孳息，也未将其出售，裁判官也对其授予事实诉权；判决金额为因其未出售或出租而少收的部分。反之，若其所收取的金额与出租或出售孳息本可取得的金额相同，就不应归责于他。他仅在自己或受其指令之人占有财产期间负责，直至占有终止为止。债权人没有进入占有，不应归责于他；他离开占有也不应归责于他，因为债权人是自愿处理自己的事务，而非他人的事务。判决估价则依起诉人所受的利益损失确定。

<!-- source-p 417 -->
<a id="42.5.9.7"></a>**7**　这些诉权不受特定期间限制，并且既可由继承人提起，也可对继承人及其他继受人提起。

<!-- source-p 418 -->
<a id="42.5.9.8"></a>**8**　若有人因被准入占有者的恶意欺诈而使财产状况恶化，可对该人提起欺诈之诉。该诉权一年后不得提起，也不得对其继承人或其他继受人提起，因为它源于不法行为，并以惩罚为目的。

<a id="42.5.12.pr."></a>**序言**　某一债权人请求获准占有债务人的财产时，问题在于：只有提出请求的债权人可以占有，还是说，一人提出请求且裁判官准许后，所有债权人都可以参与？较妥当的意见是，裁判官一经准许，就应视为不仅是准许提出请求的个人占有，而是为债权人整体及财产本身准许占有；拉贝奥也这样认为。不能说获准占有的自由人是为他人取得财物，因为裁判官所准许的人也没有为自己取得任何财物，他只是依既定程序行事；因此，该准许也使其他债权人受益。显然，若提出请求的人并非债权人，就绝不能说某一债权人因此可以占有，因为这种请求并未产生任何效果。这与获准占有的债权人后来收回自己的债权不同：在后一情形，其他债权人仍可继续进行财产出售程序。

<!-- source-p 472 -->
<a id="42.5.24.2"></a>**2**　银行家财产出售时，已有各项优先权后，应优先考虑那些基于对银行业的信任而将款项存入银行的人。但若存款人收取了银行家的利息，就不与其他债权人区别对待；这是合理的，因为借贷与寄存是不同的。不过，若钱币仍然存在，我认为寄存人可以通过所有物返还请求取回这些钱；提出该请求的人应优先于享有优先权的债权人。

<a id="42.5.24.3"></a>**3**　其资金流入享有优先权的债权人者，其债权应优先受偿。我们应如何理解“资金流入”？是指资金直接从普通债权人处转给优先债权人，还是也包括资金先付给债务人，再由债务人转付给优先债权人的情形？若两次给付之间并未经过一段时间，宽厚地认为后一情形也包括在内，是可以的。

雅沃勒努斯《书信集》第一卷。

<!-- source-p 485 -->
家父为未达法定青春期的儿子指定替补继承人，条件是儿子在达到青春期前死亡。儿子拒绝承受父亲遗产，因此父亲的财产被出售；后来有一项遗产归儿子取得，儿子接受该遗产后死亡。我询问：裁判官既然不会仅因儿子后来取得遗产，就准许父亲的债权人对该儿子提起诉讼，那么债权人能否对替补继承人提起诉讼？替补继承人并未从父亲的遗产中取得任何财产——这些财产本应供已获准占有的债权人受偿；债权人对未成年人的财产也没有权利，而且无论未成年人是否接受后来取得的遗产，债权人的利益都不应受影响，因为替补继承人若不接受该继承，这些财产便不属于父亲的债权人可据以受偿的财产。最使我犹疑的是，你的老师们认为这只有一份遗嘱。他答复说：裁判官给予拒绝承受父亲遗产的儿子的保护，是为了避免在父亲财产被出售时对儿子提起诉讼；即使儿子后来取得遗产，也不得将这项保护撤回而使父亲的债权人受益。对作为继承人的替补儿子，则不应适用相同规则，因为法律顾及儿子的名誉，使出售的宁可为父亲的财产，而非儿子的财产。因此，父亲的债权人不得就儿子后来取得的财产提起诉讼，因为这些财产是从外部取得的，并非由父亲转给他。然而，若替补继承人接受了儿子的遗产，且未成年人已将自己并入父亲的遗产，那么父亲和儿子的遗产便合为一体；对于属于父亲或儿子的全部债务，继承人即使不愿意也须承担责任。正如继承人无权免除这一债务，若不为其应诉，其本人财产就可能被出售一样，他也无权将父亲与儿子的债务分开；在这种情形下，应当准许债权人对他提起诉讼。反之，若替补继承人未接受儿子的遗产，父亲的债权人不得就未成年人留下的财产提起诉讼；因为不得仅因父亲的债务而出售未成年人的财产，而未成年人取得的财产也不属于父亲的财产。

<a id="42.5.31.pr."></a>**序言**　若债权人认为继承人状况可疑，可以要求其提供担保，以确保偿还债务。裁判官应就此查明情况；除非查明有理由保护提出该请求的债权人，否则不得立即强令继承人提供担保。

<!-- source-p 495 -->
<a id="42.5.31.1"></a>**1**　判断继承人是否状况可疑，与判断监护人是否状况可疑的方式不同：监护人之所以可疑，是因为其在未成年人财产事务中有欺诈、狡猾的行为，而继承人是否可疑，则仅取决于其财产状况。

<!-- source-p 496 -->
<a id="42.5.31.2"></a>**2**　不过，若继承人刚刚接受遗产，应听取主张其状况可疑之人的意见；但若他们已容许继承人持有遗产一段时间，却不能指控其有任何欺诈行为，就不应在很久以后再迫使继承人承担这一义务。

<!-- source-p 497 -->
<a id="42.5.31.3"></a>**3**　若被裁判官命令提供担保的可疑继承人不遵守命令，裁判官就应依告示准许债权人占有并出售遗产。

<!-- source-p 498 -->

<a id="42.5.31.5"></a>**5**　若债权人甚至不能证明他陷于贫困，就应对他承担侮辱之诉的责任。
