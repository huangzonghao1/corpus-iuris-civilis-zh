# D.42.7 论指定财产管理人（*De curatore bonis dando*）

> 底本：*Digesta Iustiniani*，EPUB `book-42.xhtml`，source-p 571–593。

<!-- source-p 571 -->
<a id="7"></a><a id="42.7"></a>**42.7.0**　论指定财产管理人。

<!-- source-p 572 -->
<a id="42.7.1"></a>**42.7.1**

<!-- source-p 573 -->
保罗《告示评注》第五十七卷。

<!-- source-p 574 -->
<a id="42.7.1.pr."></a>**序言**　若某人被指定为附条件继承人，只要可能，就应迫使其履行该条件；如果他表示即便条件成就也不愿接受继承，则应变卖死者的财产。

<!-- source-p 575 -->
<a id="42.7.1.1"></a>**1**　若他无力做到，则应为遗产指定财产管理人，或者变卖遗产。

<!-- source-p 576 -->
<a id="42.7.1.2"></a>**2**　但若债务沉重且会因罚金而增加，则应由财产管理人清偿债务；胎儿名义的遗产占有，或未适婚继承人没有监护人时，通常也会作出同样的裁定。

<!-- source-p 577 -->
<a id="42.7.2"></a>**42.7.2**

<!-- source-p 578 -->
乌尔比安《告示评注》第六十五卷。

<!-- source-p 579 -->
<a id="42.7.2.pr."></a>**序言**　关于指定财产管理人，我们适用这样的规则：应向法务官提出申请，由法务官依债权人多数的同意指定一名或数名管理人；如果待变卖的财产位于行省，则由行省总督指定。

<!-- source-p 580 -->
<a id="42.7.2.1"></a>**1**　由以这种方式任命的一人或数人所实施、办理和管理的一切事项，均应有效；他们可以享有准诉权，也可以成为准诉权的被告。若管理人派人提起诉讼或进行辩护，该人得依法行事。无需要求该受派者以财产将被变卖之人的名义提供担保，无论是追认担保还是判决履行担保；但应以派遣他的管理人本人的名义提供担保。

<!-- source-p 581 -->
<a id="42.7.2.2"></a>**2**　若指定了数名管理人，塞尔苏斯说，他们每个人都可以就全部债务提起诉讼，也都可能就全部债务被诉，而非仅按份额承担责任。但若各管理人按地区分别受任，例如一人管理意大利事务，另一人在行省任职，我认为他们应各自守其负责的地区。

<!-- source-p 582 -->
<a id="42.7.2.3"></a>**3**　有人问，能否违背某人意愿而指定其为管理人。卡西乌斯写道，不得强迫任何人违背其意愿担任财产管理人；这一意见更为正确。因此，应当寻找自愿担任者；但若确有重大必要，且皇帝裁量决定如此办理，也可以违背其意愿任命管理人。

<!-- source-p 583 -->
<a id="42.7.2.4"></a>**4**　被指定为管理人的人并非必须是债权人；非债权人也可以担任。

<!-- source-p 584 -->
<a id="42.7.2.5"></a>**5**　若有三名管理人，其中一人未经手任何事务，是否也应对这个未曾经手者给予诉权？卡西乌斯认为，不应对原告设置任何限制，原告可以选择起诉自己希望起诉的人。我认为卡西乌斯的意见更为正确：应考察的是实际收取的财产总额，而非其中有多少落到某一名管理人手中；我们也依此处理，除非该人系违背其意愿被任命。若属这种情形，应认为不得对其提起诉讼。

<!-- source-p 585 -->
<a id="42.7.3"></a>**42.7.3**

<!-- source-p 586 -->
塞尔苏斯《学说汇纂》第二十四卷。

<!-- source-p 587 -->
若同一财产有数名管理人，原告可以自行选择其中任何一人，并对其请求全部给付；正如他们每个人都可以就全部请求提起诉讼一样。

<!-- source-p 588 -->
<a id="42.7.4"></a>**42.7.4**

<!-- source-p 589 -->
帕皮里乌斯《敕令论》第一卷。

<!-- source-p 590 -->
皇帝安敦尼与维鲁斯奥古斯都曾以敕答规定：依元老院决议由管理人变卖财产后，实施欺诈者不得就此前所处理的事务享有任何诉权。

<!-- source-p 591 -->
<a id="42.7.5"></a>**42.7.5**

<!-- source-p 592 -->
尤利安《学说汇纂》第四十七卷。

<!-- source-p 593 -->
若债务人已作财产让与，债权人私下商议并共同选出一人，由其变卖财产，再将所得款项按份额分配给债权人；此后又出现另一人，自称也是债权人，那么此人虽不得对管理人提起诉讼，却可以与管理人一同变卖债务人的财产；管理人和该债权人从财产变卖中取得的款项，应按比例分配给全体债权人。
