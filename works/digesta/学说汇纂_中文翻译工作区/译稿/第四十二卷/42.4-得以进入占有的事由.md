# D.42.4 得以进入占有的事由（*Quibus ex causis in possessionem eatur*）

> 底本：*Digesta Iustiniani*，EPUB `book-42.xhtml`，source-p 297–376。

<!-- source-p 297 -->
<a id="4"></a><a id="42.4"></a>**42.4.0 得以进入占有的事由**（*Quibus ex causis in possessionem eatur*）。

<!-- source-p 298 -->
<a id="42.4.1"></a>**42.4.1**

<!-- source-p 299 -->
乌尔比安《告示评注》第十二卷。

<!-- source-p 300 -->
通常有三种准许进入占有的事由：为保全财产、为保障遗赠履行，以及以腹中胎儿名义。若未就尚未发生但有发生危险的损害提供担保，以此为由准入占有时，并非针对全部财产，而仅针对可能遭受损害的特定物。

<!-- source-p 301 -->
<a id="42.4.2"></a>**42.4.2**

<!-- source-p 302 -->
乌尔比安《告示评注》第五卷。

<!-- source-p 303 -->
<a id="42.4.2.pr."></a>**序言**　裁判官称：“对于为保证按时出庭而提供保证人的人，若其既不使自己可以被找到，也无人为其辩护，我将命令进入其财产占有。”

<!-- source-p 304 -->
<a id="42.4.2.1"></a>**1**　故意使对方无法找到自己的人，没有使自己可以被找到；因此，裁判官命令占有躲藏者的财产。

<!-- source-p 305 -->
<a id="42.4.2.2"></a>**2**　若他并未躲藏，只是身处外地且无人为其辩护，又当如何？这难道不应被视为未使自己可以被找到吗？

<!-- source-p 306 -->
<a id="42.4.2.3"></a>**3**　所谓获得辩护，是指其缺席不会使对方当事人的案件在任何方面处于更不利的地位。

<!-- source-p 307 -->
<a id="42.4.2.4"></a>**4**　“获得辩护”一词以 *paratatikws*（持续体）形式书写，因此，若辩护没有持续，仅仅曾经提供过辩护并不足够；但若现在才提出辩护，也不会因此受到不利影响。

<!-- source-p 308 -->
<a id="42.4.3"></a>**42.4.3**

<!-- source-p 309 -->
乌尔比安《告示评注》第五十九卷。

<!-- source-p 310 -->
<a id="42.4.3.pr."></a>**序言**　尤利安曾讨论：未适婚人的父亲与提提乌斯共有一物，未适婚人在共有物分割之诉中无人辩护，而且不存在可因父亲身份而对其作出判决的财产；此时应出售父亲的财产，还是仅为保全该物而准许进入占有？尤利安说，若父亲曾收取孳息或使该物价值降低，可以出售其财产；若不存在足以出售父亲财产的理由，则应准许占有未适婚人的财产。马尔凯鲁斯指出，要求一个未与未适婚人订立合同的人等到其达到青春期，极不公平。这一意见有其道理。因此，既然合同义务源自父亲，就不应等待未适婚人达到青春期。

<!-- source-p 311 -->
<a id="42.4.3.1"></a>**1**　若与未适婚人的奴隶订立合同，也可以说是与未适婚人订立合同；因为可对其提起特有产诉权。因此，应当认可：凡可对未适婚人提起诉讼的事由，均适用同一规则。若该奴隶将所得用于主人事务，或依主人命令行事，又或者可以对其提起经理人诉讼，则更容易证明这一点。

<!-- source-p 312 -->
<a id="42.4.3.2"></a>**2**　我认为，若与其监护人订立合同，且基于该原因可对未适婚人提起诉讼，也更应适用该告示，视同与未适婚人本人订立了合同。

<!-- source-p 313 -->
<a id="42.4.3.3"></a>**3**　若未适婚人成为某人的继承人，并因此负有遗赠债务，应考察该告示是否适用。较妥当的意见是，如马尔凯鲁斯所写，也可以准许占有未适婚人的财产，并由遗产债权人选择何者为宜；因为未适婚人在接受继承时，似乎也订立了合同。

<!-- source-p 314 -->
<a id="42.4.4"></a>**42.4.4**

<!-- source-p 315 -->
保罗《告示评注》第五十八卷。

<!-- source-p 316 -->
若某人介入遗产事务，也应认为他已经订立合同。

<!-- source-p 317 -->
<a id="42.4.5"></a>**42.4.5**

<!-- source-p 318 -->
乌尔比安《告示评注》第五十九卷。

<!-- source-p 319 -->
<a id="42.4.5.pr."></a>**序言**　无论未适婚人是否有监护人或保佐人，凡无人为其辩护的情形，均适用以上规则。若有人愿意为其辩护，则不再为保全财产而准许进入占有。

<!-- source-p 320 -->
<a id="42.4.5.1"></a>**1**　必须查明确无任何人为未适婚人辩护，并使裁判官确信这一点，之后才能准许占有其财产。为此，应传唤未适婚人的监护人到裁判官面前，询问是否愿意辩护。若没有监护人，则应询问亲属、姻亲以及其他可能基于亲属关系、情谊或其他理由愿意为未适婚人辩护之人；若有合适的自由释奴，也应传唤并询问其是否愿意辩护。若这些人拒绝辩护，或者不作拒绝、只是沉默，裁判官便准许占有，并持续至有人愿意辩护为止；一旦有人开始为该未适婚男童或女童辩护，占有人就应退出。疯癫者也适用同一规则。

<!-- source-p 321 -->
<a id="42.4.5.2"></a>**2**　裁判官称：“若该男童已脱离监护，或该女童已达到婚龄，并且获得了适当辩护，我将命令占有人退出占有。”

<!-- source-p 322 -->
<a id="42.4.5.3"></a>**3**　何谓适当辩护？是只要使自己可以被找到并表示愿意应诉，还是无论如何均须提供担保？该告示不仅适用于当事人本人愿意辩护的情形，而是针对财产的救济；“获得适当辩护”是指本人或任何他人为其辩护。但若由他人辩护，就必须提供担保；若当事人本人辩护，我认为无须提供担保。因此，一旦有人提出辩护，占有人即可依据所发布的令状被驱逐。

<!-- source-p 323 -->
<a id="42.4.6"></a>**42.4.6**

<!-- source-p 324 -->
保罗《告示评注》第五十七卷。

<!-- source-p 325 -->
<a id="42.4.6.pr."></a>**序言**　即使债务仅在某项条件成就后才应支付，债权人通常也可以被准许进入占有。

<!-- source-p 326 -->
<a id="42.4.6.1"></a>**1**　告示称：“债权人已占有某人财产的，该人的财产也可以出售；未适婚人以及因公事正当离境且无恶意欺诈者除外。”我们据此理解，若某人因恶意欺诈而离境，其财产可以出售。

<!-- source-p 327 -->
<a id="42.4.6.2"></a>**2**　若某人被敌人俘获，应准许其债权人进入占有；但不得立即出售其财产，而应在此期间为财产指定管理人。

<!-- source-p 328 -->
<a id="42.4.7"></a>**42.4.7**

<!-- source-p 329 -->
乌尔比安《告示评注》第五十九卷。

<!-- source-p 330 -->
<a id="42.4.7.pr."></a>**序言**　富尔基尼乌斯认为，为保全财产而被准许进入占有的债权人，不应以该财产供养自己。

<!-- source-p 331 -->
<a id="42.4.7.1"></a>**1**　裁判官称：“若某人为了诈害债权人而躲藏，且未依善良之人的判断获得辩护，我将命令占有并出售其财产。”

<!-- source-p 332 -->
<a id="42.4.7.2"></a>**2**　该告示适用时，仅仅躲藏并不足够，还必须是为了诈害债权人而躲藏。反之，虽有诈害债权人的行为但未躲藏，也不足以准许占有并出售财产；必须是为了诈害债权人而躲藏。这是最常见的准许占有事由，因为实践中经常占有躲藏者的财产。

<!-- source-p 333 -->
<a id="42.4.7.3"></a>**3**　若有人把某人的财产当作躲藏者的财产而加以占有并出售，但该人实际上并未躲藏，那么应当说随后进行的财产出售毫无效力。

<!-- source-p 334 -->
<a id="42.4.7.4"></a>**4**　现在来考察何谓躲藏。躲藏并非如西塞罗所定义的那样，是可耻地隐藏自己；一个人可能出于并不可耻的原因躲藏，例如害怕暴君的残暴、敌人的暴力或国内叛乱。

<!-- source-p 335 -->
<a id="42.4.7.5"></a>**5**　若某人为诈害而躲藏，却并非为了诈害债权人，即使这种躲藏实际上使债权人受损，也不能因此准许占有其财产；因为他并非怀着诈害债权人的意思而躲藏。应查明躲藏者的主观意图，即他是为了诈害债权人而躲藏，还是出于其他原因。

<!-- source-p 336 -->
<a id="42.4.7.6"></a>**6**　若他有两个或多个躲藏原因，其中包括诈害债权人，出售财产是否仍有效？我认为应当认可：若有多个躲藏原因，而其中包括诈害债权人的原因，就会对其不利，财产也可以据此出售。

<!-- source-p 337 -->
<a id="42.4.7.7"></a>**7**　若某人有意躲避一些人，却不躲避另一些人，应如何处理？庞波尼乌斯极为正确地写道，无须证明其对所有人都躲藏；只须证明他有意躲避并欺骗某一特定之人即可。于是，是否所有人都可因他躲藏而出售其财产——也就是说，即使他没有躲避某些人也可以，因为他确实在躲藏——还是只有被他躲避之人可以？他的确属于躲藏，并且为了诈害而躲藏，即使他没有躲避我也是如此；但庞波尼乌斯认为，应考察他是否躲避我，只有被躲避之人可以请求出售其财产。

<!-- source-p 338 -->
<a id="42.4.7.8"></a>**8**　躲藏是指在一段时间内持续隐匿，正如反复实施某事称为经常实施。

<!-- source-p 339 -->
<a id="42.4.7.9"></a>**9**　躲藏需要隐藏者具有相应的主观意图。因此，有人正确地说，疯癫者的财产不能据此出售，因为疯癫者并非自主控制自己，不能说他在隐藏自己。

<!-- source-p 340 -->
<a id="42.4.7.10"></a>**10**　当然，若疯癫者无人辩护，应为其指定保佐人，或者明确准许占有其财产。拉贝奥写道，若找不到疯癫者的保佐人或辩护人，或者指定的保佐人不为其辩护，就应将其撤换，并由裁判官从债权人中指定一名保佐人，使出售疯癫者财产的范围不超过必要限度。拉贝奥说，应参照准许以腹中胎儿名义进入占有时通常保全的财产。

<!-- source-p 341 -->
<a id="42.4.7.11"></a>**11**　当然，有时经审查案情后应出售其财产：若债务紧迫，迟延将损害债权人，就应出售，但须将剩余财产交给疯癫者；因为其身份与状况与未适婚人相差不远。这一做法确有道理。

<!-- source-p 342 -->
<a id="42.4.7.12"></a>**12**　挥霍者以及其他由保佐人协助的人，也应作同样处理；毕竟，不能严格地说他们在躲藏。

<!-- source-p 343 -->
<a id="42.4.7.13"></a>**13**　应当知道，一个人可以身处同一城市却仍在躲藏，也可以身处另一城市而并未躲藏。若某人在另一城市，公开露面并应诉，是否仍算躲藏？我们如今适用的规则是：无论其在本地还是在外地，只要他躲避债权人与其相遇，就视为躲藏。古代法学家甚至答复说，某人在同一广场出庭，却躲在柱子或摊位附近，也应视为躲藏；并且一个人可能躲避某人，却不躲避另一人。但可以确定，只有被其躲避之人能够出售其财产。

<!-- source-p 344 -->
<a id="42.4.7.14"></a>**14**　若期限债务人或附条件债务人正在躲藏，在期限届至或条件成就以前，不能出售其财产。毕竟，某人不是债务人，与虽为债务人但尚不能被起诉，有什么区别？若某人根本不是债务人，结论也相同。对于虽有诉权、但该诉权会被抗辩排除的人，也应如此处理。

<!-- source-p 345 -->
<a id="42.4.7.15"></a>**15**　若可以基于家子或奴隶的特有产对某人提起诉讼，而此人躲藏，我们适用的规则是，可以占有并出售他的财产，即使其特有产中当时没有任何财物；因为特有产可能存在，而且我们考察判决时它是否存在，也考察诉讼所及的范围，即使当时特有产中没有财物，诉权仍可能成立。

<!-- source-p 346 -->
<a id="42.4.7.16"></a>**16**　现在考察，若某人躲避针对他的对物诉讼，是否可以占有并出售其财产。涅拉提乌斯的意见现存于文献中：他认为应出售其财产。哈德良皇帝的敕答也载有这一规则，我们如今仍适用。

<!-- source-p 347 -->
<a id="42.4.7.17"></a>**17**　塞尔苏斯曾答复塞克斯图斯：若我想请求返还的土地由提提乌斯占有，而他缺席且无人辩护，我认为更妥当的做法是准许我进入该土地的占有，而非占有提提乌斯的财产。应注意，塞尔苏斯讨论的不是躲藏者，而是缺席者。

<!-- source-p 348 -->
<a id="42.4.7.18"></a>**18**　塞尔苏斯还认为，若我想请求遗产的人正在躲藏，最妥当的做法是准许我进入其以继承人或占有人身份持有的遗产物之占有；但若他以欺诈方式使自己无法占有遗产，就应占有并出售其财产。

<!-- source-p 349 -->
<a id="42.4.7.19"></a>**19**　神圣的皮乌斯皇帝也曾就一名遗产占有人不使自己可以被找到的案件作出敕答：应使对方进入遗产物的占有。敕答还命令准许进入遗产物占有的人收取孳息；遗产占有人的严重抗命应使该请求人获益。
