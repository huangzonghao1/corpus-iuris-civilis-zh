# D.42.6 论财产分离（*De separationibus*）

> 底本：*Digesta Iustiniani*，EPUB `book-42.xhtml`，source-p 527–570。

<!-- source-p 527 -->
<a id="6"></a><a id="42.6"></a>**42.6.0 论财产分离**（*De separationibus*）。

<!-- source-p 528 -->
<a id="42.6.1"></a>**42.6.1**

<!-- source-p 529 -->
乌尔比安《告示评注》第六十四卷。

<!-- source-p 530 -->
<a id="42.6.1.pr."></a>**序言**　应当知道，财产分离通常由裁判官以裁令准许。

<!-- source-p 531 -->
<a id="42.6.1.1"></a>**1**　债权人通常基于下列理由请求财产分离：例如，某人以塞尤斯为债务人；塞尤斯死亡，提提乌斯成为其继承人，而提提乌斯无清偿能力并面临财产出售。塞尤斯的债权人主张塞尤斯的财产应足以清偿他们，提提乌斯的债权人则应满足于提提乌斯自己的财产，因此应仿佛存在两次分别的财产出售。因为，塞尤斯可能原本有清偿能力，足以向债权人清偿——即使不能全部清偿，也能清偿一部分；但若接纳提提乌斯的债权人并将其与塞尤斯的债权人混在一起，塞尤斯的债权人就会少得偿还，因为提提乌斯无清偿能力，或者因为债权人数量增加而所得减少。因此，塞尤斯的债权人请求财产分离，完全公平，应准许他们向裁判官请求分别确定各类债权人可获清偿的数额。

<!-- source-p 532 -->
<a id="42.6.1.2"></a>**2**　反之，提提乌斯的债权人不能请求财产分离。因为，一个人可以通过增加债务人的债权人，使另一人的处境恶化。但如果我的债务人成为继承人，其接受继承并不会使我的处境恶化，因为我可以请求财产分离；他接受无清偿能力之人的继承，却增加了自己的债权人所承担的负担，因此其债权人也不能请求财产分离。

<!-- source-p 533 -->
<a id="42.6.1.3"></a>**3**　还应知道，即使继承人以质权或抵押权为由主张某物已负担担保，只要该物属于遗产，依法请求财产分离的抵押债权人仍优先于该继承人。塞维鲁和安东尼努斯皇帝曾作敕答，确认这一点。

<!-- source-p 534 -->
<a id="42.6.1.4"></a>**4**　也可以对国库和城市共同体请求财产分离。

<!-- source-p 535 -->
<a id="42.6.1.5"></a>**5**　有人问，继承人若为诈害自己的债权人而接受继承，其本人的债权人有时能否请求财产分离。文献中没有提供任何救济；他们应当自责与这种人订立合同。除非认为裁判官可以在非常程序中救济他们，以对抗实施此种欺诈诡计的人；但这种救济并不轻易准许。

<!-- source-p 536 -->
<a id="42.6.1.6"></a>**6**　若有人声称继承可能有害而接受继承，之后又被迫返还遗产，却已没有可供返还之人；这种情形可能在若干案件中发生。若该人本人请求救济，使其免受遗产债权人的追索，我们应予救济。神圣的皮乌斯皇帝也曾作敕答，规定应如同继承从未被接受一样出售立遗嘱人的财产。我认为，若此类继承人的债权人提出同样请求，尽管继承人本人未作请求，也应给予相同救济，仿佛准许了某种财产分离。

<!-- source-p 537 -->
<a id="42.6.1.7"></a>**7**　再考察以下情形：某人作为未适婚人继承其父，随后在青春期前死亡，替补继承人的财产即将出售；接受未适婚人遗产的人，其父亲的债权人能否请求财产分离？我认为可以。更进一步，我认为，未适婚人的债权人也可以请求将其财产与继承人债权人的财产分离。

<!-- source-p 538 -->
<a id="42.6.1.8"></a>**8**　依此考察：第一顺位继承人指定第二顺位继承人，第二顺位继承人又指定第三顺位继承人，而第三顺位继承人的财产即将出售，哪些债权人可以请求财产分离？我认为，若第一顺位继承人的债权人请求，应当准许他们针对第二顺位和第三顺位继承人的债权人请求分离；若第二顺位继承人的债权人请求，他们当然可以针对第三顺位继承人的债权人请求分离，却不能针对第一顺位继承人的债权人请求分离。总之，第一顺位继承人的债权人可以针对所有后续顺位的债权人请求财产分离；第二顺位继承人的债权人不能针对第一顺位的债权人，但可以针对第三顺位的债权人请求分离。

<!-- source-p 539 -->
<a id="42.6.1.9"></a>**9**　若家子拥有军役特有财产，其财产即将出售，应否在军役债权人与其他债权人之间进行财产分离？两类债权人可以同时参与；但若某些债权人在该家子服军役前已与其订立合同，他们或许应当与其他人分离。我认为应当认可这一点。因此，若出售军役特有财产，先前的债权人不能与军役债权人一同参与。又，若某项债务使财产归于家父所有，债权人也可能被驳回，不得侵扰军役特有财产，因为他可以转而向家父提起诉讼。

<!-- source-p 540 -->
<a id="42.6.1.10"></a>**10**　应当知道，只有未以更新债务为目的与继承人订立要式口约的债权人，才能请求财产分离。若他们以更新债务的意思与继承人订约，就已经丧失财产分离的利益，因为他们选择了继承人的债务关系，不能再与继承人分离。若他们有意选择继承人并向其收取利息，也应作同样处理。

<!-- source-p 541 -->
<a id="42.6.1.11"></a>**11**　还应考察，若债权人已从继承人处取得担保，能否请求财产分离。我认为不能，因为他们已经选择继承人为债务人。也许有人会问：若取得的担保并不充分，如何处理？他们应自责为何接受了不充分的保证人。

<!-- source-p 542 -->
<a id="42.6.1.12"></a>**12**　此外，应当知道，遗产财产一旦与继承人自己的财产混合，就不能再请求财产分离；财产已经混同并合为一体，就不能准许分离。那么，若仍有土地、奴隶、牲畜或其他可以分离的财产呢？此时当然可以请求分离，不应允许继承人以财产已经合并为由抗辩；土地不可能被并入其他财产，除非各项占有已经如此结合、混合，以致无法分离。当然，这种情形极少发生。

<!-- source-p 543 -->
<a id="42.6.1.13"></a>**13**　所谓不得在经过很长时间后请求财产分离，应理解为继承被接受五年之后不得再请求分离。

<!-- source-p 544 -->
<a id="42.6.1.14"></a>**14**　是否准许上述任何一种财产分离，应由裁判官或行省总督审查，且只有将准许分离的人有权审理。

<!-- source-p 545 -->
<a id="42.6.1.15"></a>**15**　若有人从继承人处取得质物，不应准许其财产分离，因为这视同他选择了继承人；不应容许这样的人以任何方式选择继承人后，又请求与其分离。

<!-- source-p 546 -->
<a id="42.6.1.16"></a>**16**　有人问，若债权人有数人，其中一些选择了继承人，另一些没有；未选择继承人的债权人请求并获得财产分离后，能否将已经选择继承人的债权人一并纳入？我认为这对后者毫无帮助，因为他们应与继承人的其他债权人一同计算。

<!-- source-p 547 -->
<a id="42.6.1.17"></a>**17**　还应知道，通常认为，若立遗嘱人的财产有剩余，继承人的债权人可以用该剩余清偿自己的债权；但立遗嘱人的债权人不能从继承人的财产中受偿。理由是，请求分离的人应自责自己轻率：继承人的财产原本足以清偿债务，他们却宁愿将死者的财产与继承人的财产分离；继承人的债权人则不能因此受责。若死者的债权人请求也从继承人的财产中受偿，不应听从，因为他们自己请求的分离已经使其与这些财产分开。可是，若死者的债权人轻率请求了财产分离，他们可以请求宽宥，但必须提出极为正当的理由，证明自己确实不知情。

<!-- source-p 548 -->
<a id="42.6.1.18"></a>**18**　还应知道，以遗嘱指定为必然继承人并同时获释的奴隶，也可以请求财产分离；也就是说，若他未动用保护人的财产，其后来取得的任何财产均应与之分离。若立遗嘱人欠该奴隶财物，也应如此处理。

继承人出售遗产后，若不存在任何欺诈嫌疑，再请求财产分离就徒劳无益；因为继承人在此期间善意实施的行为通常应予维持。

<!-- source-p 552 -->
<a id="42.6.3"></a>**42.6.3**

<!-- source-p 553 -->
帕比尼安《疑问集》第二十七卷。

<!-- source-p 554 -->
<a id="42.6.3.pr."></a>**序言**　债务人成为其保证人的继承人，随后继承人的财产被出售。尽管保证债务已经消灭，但若保证人所担保的债权人请求，仍应准许财产分离；无论该债权人是唯一的遗产债权人，还是遗产债权人之一，均是如此。法律之所以基于主债务较大而排除保证债务，不应损害已谨慎保障自身利益的债权人。

<!-- source-p 555 -->
<a id="42.6.3.1"></a>**1**　那么，若分离保证人的财产后，债权人仍不能从遗产中获得全部清偿，他应与继承人的其他债权人按份额受偿，还是必须满足于他选择分离的财产？然而，若保证人的债务人未接受保证人的遗产、保证人的财产又已出售，债权人本可以就未受偿部分加入债务人的债权人之列；因此，法律理由不允许在本案中排除他。

<!-- source-p 556 -->
<a id="42.6.3.2"></a>**2**　对于其他请求财产分离的债权人，较妥当的意见是：若无法从遗产中获得全部清偿，只有在继承人自己的债权人已经受偿后，他们才能从继承人的财产中取得任何利益。毫无疑问，遗产债权人已受偿后，应如此对待继承人的债权人。

<!-- source-p 557 -->
<a id="42.6.4"></a>**42.6.4**

帕比尼安《答复集》第十二卷。

<!-- source-p 559 -->
<a id="42.6.4.pr."></a>**序言**　债务须待期限届至或条件成就后才履行的债权人，由于尚不能请求付款，也同样可以获得财产分离；因为他们也会受到共同担保的保护。

<!-- source-p 560 -->
<a id="42.6.4.1"></a>**1**　受遗赠人只能就从财产中保全下来的部分取得质权。

<!-- source-p 561 -->
<a id="42.6.5"></a>**42.6.5**

<!-- source-p 562 -->
保罗《疑问集》第十三卷。

<!-- source-p 563 -->
若遗产债权人请求并获得财产分离，而遗产后来证明不足清偿，继承人自身却有清偿能力，他们不得再转而请求继承人本人清偿，而必须受其最初请求的拘束。但若准许分离后继承人又取得财产，若该财产来自遗产，就应允许请求分离的遗产债权人就新增部分受偿；若他们已获清偿，剩余部分应分配给继承人自己的债权人。若继承人基于其他原因取得财产，则遗产债权人不得参与。有人认为，若继承人自己的债权人已获全部清偿，剩余部分应分给遗产债权人；我不这样认为：他们既然请求了财产分离，就已脱离继承人本人而转向死者的财产，仿佛只出售了死者的财产，不能取得该财产后来增加的部分。即使遗产债权人因请求财产分离而受误导，所得少于继承人自己的债权人，也应作同样的说明。继承人自己的债权人则可以对其本人的财产以及其本人主张权利，而继承人在生前仍可继续取得财产。

尤利安《学说汇纂》第四十六卷。

<!-- source-p 566 -->
<a id="42.6.6.pr."></a>**序言**　每当继承人无清偿能力时，不仅立遗嘱人的债权人，而且受遗赠人也都应公平地请求遗产与继承人财产分离；待债权人获得全部清偿后，再为受遗赠人保全全部遗赠或其中一部分。

<!-- source-p 567 -->
<a id="42.6.6.1"></a>**1**　若被指定为继承人的女释奴请求依据遗嘱书板取得某位无清偿能力者的遗产占有，有人问，是否应将她的财产与遗产债权人的财产分离。答复说：救济释奴保护人并无不公，使其免于承担女释奴请求依遗嘱书板取得遗产占有而带来的债务负担。
