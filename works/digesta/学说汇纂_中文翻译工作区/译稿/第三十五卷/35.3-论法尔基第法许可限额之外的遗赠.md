# D.35.3《论被称为超过法尔基第法许可限额而作出的遗赠》

<!-- source-p 825 -->
<a id="3"></a><a id="35.3"></a>**35.3.0 论被称为超过法尔基第法许可限额而作出的遗赠**（*Si cui plus, quam per legem Falcidiam licuerit, legatum esse dicetur*）

<!-- source-p 826 -->
<a id="35.3.1"></a>**35.3.1**

<!-- source-p 827 -->
**乌尔比安：《告示评注》第七十九卷。**

<!-- source-p 828 -->
<a id="35.3.1.pr."></a>**序言。**如果有人所得遗赠超过法律所许可的限额，且确有正当理由怀疑法尔基第法是否适用，裁判官便救济继承人，命受遗赠人提供担保：倘若查明其以遗赠名义取得的财物超过法尔基第法所许可的数额，他应给付相当于该超额的金钱，并保证自己不实施恶意行为。

<!-- source-p 829 -->
<a id="35.3.1.1"></a>**1.**此事无论发生于遗嘱的第一组遗嘱书板、遗腹继承人遗嘱书板，还是两者之中，均无区别。即使存在两份遗嘱，法尔基第法也只适用一次，这一点已经确定；因此，应合并计算遗赠，既包括遗嘱人本人所作的遗赠，也包括由未适婚年龄者的替补继承人所作的遗赠。

<!-- source-p 830 -->
<a id="35.3.1.2"></a>**2.**如果未以未适婚年龄者本人名义订立该项要式口约，未适婚年龄者的继承人可对监护人提起监护诉讼。不过，正如庞波尼乌斯所说，也可以将要式口约订立给未适婚年龄者本人及其继承人；在订立给未适婚年龄者本人的情形下，法尔基第法得于其生前开始适用。他对监护诉讼也作了同样的论述。

<!-- source-p 831 -->
<a id="35.3.1.3"></a>**3.**马尔凯卢斯举例说：某人拥有四百财产，指定未适婚年龄的儿子为继承人，并指定提提乌斯和塞尤斯为替补继承人；立遗嘱人没有命未适婚年龄者作出任何遗赠，却命提提乌斯遗赠三百。究竟应给付二百，还是一百五十？他说，三百无论如何都不应由提提乌斯给付。我认为，较为妥当的是，不得强迫他支出超过其份额的财产，当然也不得少于其份额。依此结果，不能只向他一人订立该项要式口约；在查明具体情形后，应向所有继承人订立。

<!-- source-p 832 -->
<a id="35.3.1.4"></a>**4.**遗赠的数额以及债务负担，都会影响法尔基第法的适用。如果债务明显或数额确定，计算便很容易；但若债务尚不确定——例如债务是否成立仍取决于条件，或者债权人已经进行诉讼程序而诉讼尚未终结——那么由于债务数额未定，受遗赠人应得多少便会引起疑问。

<!-- source-p 833 -->
<a id="35.3.1.5"></a>**5.**不过，如今在遗嘱信托方面也有类似的处理。

<!-- source-p 834 -->
<a id="35.3.1.6"></a>**6.**当法尔基第法被认为适用时，通常会指定一名仲裁人，以计算遗产的数额，即使仅有一人追索数额不大的遗嘱信托；这项计算不得对其他未被提交仲裁人处理的人产生预决效力。不过，继承人通常也会通知其他遗嘱信托受益人前来仲裁，并在那里主张自己的权利；通常还会通知债权人，以便他们证明债务。对受遗赠人以及遗嘱信托受益人而言，仍有一项处理办法：如果继承人愿意全额给付遗嘱所留之物，并希望通过订立该项要式口约为自己提供保障，应当准许。

<!-- source-p 835 -->
<a id="35.3.1.7"></a>**7.**如果有些遗赠于现在即可请求给付，另一些则附有条件，那么应就附条件的遗赠订立这项要式口约；但现在即可请求给付的遗赠应全额清偿。尤利安写道，如果遗赠既有无条件的，也有附条件的，并且法尔基第法要到条件成就时才适用，那么无条件遗赠的请求诉权只有在继承人已获得如下担保时方可授予：“凡你取得超过法尔基第法所许可数额的部分，均应返还。”

<!-- source-p 836 -->
<a id="35.3.1.8"></a>**8.**同一尤利安还写道：某人被附条件遗赠四分之一，被无条件遗赠四分之三，他应提供如下担保：“凡你取得超过法尔基第法所许可数额的部分，均应返还。”

<!-- source-p 837 -->
<a id="35.3.1.9"></a>**9.**之所以适用这项要式口约，是因为尽管已经给付之物可以请求返还，但受领给付者可能无力清偿，从而导致已给付之物无法追回。

<!-- source-p 838 -->
<a id="35.3.1.10"></a>**10.**也可以认为，因死亡而为的赠与同样应订立这项要式口约。

<!-- source-p 839 -->
<a id="35.3.1.11"></a>**11.**要式口约中的“你以遗赠名义取得的超过法尔基第法所许可的部分”，不仅包括取得超过法尔基第法许可数额、因而应返还其中一部分并保留另一部分的人，也包括应将全部所得返还的人。应当知道，法尔基第法有时仅撤回已给付之物的一部分，有时则全部撤回。因为计算法尔基第法份额时须考虑债务负担；债务出现或债务所附条件成就后，经常会发生遗赠全部被耗尽的情形。此外，解放自由人的条件有时一经成就，也会导致遗赠完全不应给付；毕竟，只有先考虑解放自由人的负担并扣除其价额，才计算遗赠数额。

<!-- source-p 840 -->
<a id="35.3.1.12"></a>**12.**有些遗嘱不适用法尔基第法，但仍须遵守如下规则：即使继承人不能保留四分之一，遗赠也只在遗产财力所能负担的范围内给付；并且必须先扣除债务，以及在遗嘱中直接获释或以遗嘱信托方式获释者的价额。

<!-- source-p 841 -->
<a id="35.3.1.13"></a>**13.**如果受遗赠人负有设立遗嘱信托的义务，他也应提供担保。

<!-- source-p 842 -->
<a id="35.3.1.14"></a>**14.**订立这项要式口约时，有时不仅要考虑法尔基第法，还须考虑其他法律。例如，受庇护人被指定为全部遗产的继承人，无条件受遗赠五分之一，另有某项附条件给付超过其依法应得份额；在这种情形下，应考虑召唤受庇护人继承的那部法律，而非法尔基第法。

<!-- source-p 843 -->
<a id="35.3.1.15"></a>**15.**如果遗赠之物在受遗赠人处灭失，应认为可以通过抗辩救济作出承诺的人，

<!-- source-p 844 -->
<a id="35.3.2"></a>**35.3.2**

<!-- source-p 845 -->
**保罗：《告示评注》第七十五卷。**

<!-- source-p 846 -->
即使他承诺给付该物的价额，

<!-- source-p 847 -->
<a id="35.3.3"></a>**35.3.3**

<!-- source-p 848 -->
**乌尔比安：《告示评注》第七十九卷。**

<!-- source-p 849 -->
<a id="35.3.3.pr."></a>**序言。**但如果该人自身有恶意行为，则应依该要式口约中所含的恶意条款承担责任，并且可以通过反抗辩排除对方的抗辩。

<!-- source-p 850 -->
<a id="35.3.3.1"></a>**1.**为遵守法尔基第法而订立的这项担保，应由保证人提供担保。

<!-- source-p 851 -->
<a id="35.3.3.2"></a>**2.**如果遗赠的金钱约定在若干个未来日期给付，而法尔基第法确定适用，佩狄乌斯说，应进行计算，而无须订立要式口约：评估以未来日期给付的遗赠价值，并据该评估认定遗赠数额；随后依该数额，在所有遗赠中立即计算法尔基第法份额。

<!-- source-p 852 -->
<a id="35.3.3.3"></a>**3.**凡在给付日期到来之前已经显然应适用法尔基第法的，均应在该时点进行计算。如果条件尚未成就，我们就应等待条件成就；如果只是给付日期尚未来临，则应考虑这段间隔时间并作价值评估，据此讨论法尔基第法，并认定该要式口约已经触发。

<!-- source-p 853 -->
<a id="35.3.3.4"></a>**4.**尽管所有受遗赠人和遗嘱信托受益人都必须依此要式口约提供担保，神君兄弟皇帝仍以敕答准许对某些人免除担保，例如只获少量生活费的人。他们曾就庞培娅·福斯蒂娜的案件作出如下敕答：“你所称其由你的庇护人庞培娅·克里斯皮安娜在遗嘱中按年留给你的十枚金币，与留给被释奴的生活费和衣物费并非同一情形；对于后者，我们曾认为应免除提供担保的负担。”

<!-- source-p 854 -->
<a id="35.3.3.5"></a>**5.**还应知道，国库不接受这项担保，但可以像已经提供担保那样对其提起诉讼。神君庇护曾以敕答指出，其他人无论地位高低，即使已经取得遗赠，也必须被迫提供担保。由此敕答还可得知，他甚至要求在遗赠已经给付之后再订立要式口约。

<!-- source-p 855 -->
<a id="35.3.3.6"></a>**6.**受遗赠人已经就遗赠返还取得担保；该担保由一名已遭遇或预料将遭遇遗产争议的继承人提供。后来遗产被他人胜诉取回，但这是由于给付遗赠者的过失或恶意所致。在这种情况下，依善良之人裁量原则——该原则包含于此项要式口约之中——应认定要式口约并未触发。

<!-- source-p 856 -->
<a id="35.3.3.7"></a>**7.**同样，如果给付遗赠者基于其他原因自行取回了遗产，例如后来发现自己在后一份遗嘱中被指定为继承人，而该受遗赠人并未在后一份遗嘱中取得遗赠，那么应认为要式口约已经触发，因为此处适用善良之人裁量原则。

<!-- source-p 857 -->
<a id="35.3.3.8"></a>**8.**一般而言，凡已为自己作此担保的人给付了遗产、一定数额或其他利益，只要提供担保者本身没有过失，就应认定该要式口约在此情形下触发。

<!-- source-p 858 -->
<a id="35.3.3.9"></a>**9.**有人问，要式口约是否会多次触发。通说认为，如果遗产分批被取回，该要式口约也可以多次触发。

<!-- source-p 859 -->
<a id="35.3.3.10"></a>**10.**如果在订立这项要式口约之前遗赠已经给付，能否提起返还诉，以要求订立该项担保？问题在于：因错误而遗漏或给付之物可以请求返还，因此这里也可认为，由于遗漏担保而给付过多。庞波尼乌斯认为，可以为促使订立担保而提起返还诉；我认为，出于实用上的考虑，应当采纳庞波尼乌斯的意见。

<!-- source-p 860 -->
<a id="35.3.4"></a>**35.3.4**

<!-- source-p 861 -->
**保罗：《告示评注》第七十五卷。**

<!-- source-p 862 -->
<a id="35.3.4.pr."></a>**序言。**只有在存在正当理由时，才适用这项担保。因为在诉讼争议尚未发生时一概要求担保并不公平，对方可能只是提出无根据的威胁。因此，裁判官将此事交由自己审查。

<!-- source-p 863 -->
<a id="35.3.4.1"></a>**1.**如果两人都依据遗嘱主张自己对遗产享有完整权利——例如他们姓名相同——那么无论对占有人还是对请求人，债权人和受遗赠人都可以提起诉讼。

<!-- source-p 864 -->
<a id="35.3.4.2"></a>**2.**如果某人以自己的金钱清偿债务，或交付自己的物品，这项担保当然必要。但如果他以遗产的金钱清偿债务，或交付遗产物品，有些人认为无须担保，因为他败诉时既未占有，也未以恶意阻止自己占有，因而不能就此被追究责任。上述规则适用于诉讼争议发生之前的给付；若在争议发生后给付，则应以过失为由承担责任。

<!-- source-p 865 -->
<a id="35.3.4.3"></a>**3.**如果两人之间争议的是一项债权，向外转让遗产债权的人或许无须提供担保，因为无论如何其中一人都会获得清偿；这就像清偿遗产债务一样。但是，如果请求人以自己的金钱清偿，或交付自己的物品，他便没有可供保留的财产，因此必须取得担保。

<!-- source-p 866 -->
<a id="35.3.5"></a>**35.3.5**

<!-- source-p 867 -->
**马尔凯卢斯：《学说汇纂》第二十一卷。**

<!-- source-p 868 -->
我们来考察：对于负有基于遗嘱信托将遗赠返还给他人义务的人，约定“你取得超过法尔基第法所许可部分的，应予给付”是否足以为对方提供保障。只要声明并未将任何遗产交托给他设立遗嘱信托，便足以应对。也就是说，他应向受遗赠人提供担保；接受遗嘱信托的人也应提供担保，除非受遗赠人更愿意省去迂回程序，改由继承人提供担保。此外，如果允许受遗赠人按比例从遗嘱信托中保留一部分——通常这样做是公平的——他还应进一步提供担保，即使其从遗赠中保留的数额已足以履行遗嘱信托。

<!-- source-p 869 -->
<a id="35.3.6"></a>**35.3.6**

<!-- source-p 870 -->
**卡利斯特拉图斯：《审判论》第四卷。**

<!-- source-p 871 -->
受遗赠人或遗嘱信托受益人往往难以提供担保，结果可能因此被排除在依据遗嘱请求慷慨给付之外；那么，是否应免除他们提供担保的负担？神君康茂德的敕答似乎支持这一意见，敕答如下：“有权审理此事的人在接到申请后，若查明向你要求担保是为了阻止你请求遗嘱信托给付，就会设法免除你提供担保的负担。”

<!-- source-p 873 -->
**保罗：《尤利亚法与帕皮亚法评注》第七卷。**

<!-- source-p 874 -->

<!-- source-p 876 -->
**梅基安努斯：《遗嘱信托论》第十卷。**

<!-- source-p 878 -->
<a id="35.3.9"></a>**35.3.9**

<!-- source-p 879 -->
**梅基安努斯：《遗嘱信托论》第十二卷。**

<!-- source-p 880 -->
如果争议的不是所有权，而是用益权——因为某物的所有权可以遗赠给提提乌斯，而该物的用益权遗赠给他人——那么就返还该物提供担保时，担保对象应是提提乌斯，而非继承人。有时，即使是继承人遗赠用益权，也应向提提乌斯提供担保；例如，遗嘱先扣除用益权而将所有权遗赠给提提乌斯，又将用益权遗赠给塞尤斯。因为在这种情形下，向继承人提供担保有何意义？用益权消灭所产生的利益并不归继承人享有。但是，如果用益权遗赠给塞尤斯，而所有权遗赠给提提乌斯，并且约定用益权不再归塞尤斯时，提提乌斯即取得所有权，那么用益权人应向继承人提供担保，继承人则应向提提乌斯提供担保；因为用益权中断时，所有权是否会归于提提乌斯尚不确定。
