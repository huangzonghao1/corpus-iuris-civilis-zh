# D.35.2　论《法尔基第法》（*Ad legem Falcidiam*）

> **底本范围：**依 d-35.htm source-p 423–824 翻译，完整覆盖 D.35.2 至 D.35.3 之前；逐段保留底本顺序、锚点及出处。

<!-- source-p 423 -->
<a id="2"></a><a id="35.2"></a>**35.2.0　论《法尔基第法》**（*Ad legem Falcidiam*）。

<!-- source-p 424 -->
<a id="35.2.1"></a>**35.2.1**

<!-- source-p 425 -->
保罗《法尔基第法专论》。

<!-- source-p 426 -->
<a id="35.2.1.pr."></a>**序言**　《法尔基第法》经制定，其第一章以如下文字赋予立遗嘱人自由遗赠的权能，但遗赠总额不得超过遗产的四分之三。底本原文：“*Qui cives Romani sunt, qui eorum post hanc legem rogatam testamentum facere volet, ut eam pecuniam easque res quibusque dare legare volet, ius potestasque esto, ut hac lege sequenti licebit.*”译文：“凡罗马公民，以及本法请求通过后希望订立遗嘱的罗马公民，均有权力和能力将其希望给与或遗赠的金钱及物品给与或遗赠他人，但须遵守下述本法规定。”该法第二章以如下文字规定遗赠限额。底本原文：“*Quicumque civis Romanus post hanc legem rogatam testamentum faciet, is quantam cuique civi Romano pecuniam iure publico dare legare volet, ius potestasque esto, dum ita detur legatum, ne minus quam partem quartam hereditatis eo testamento heredes capiant, eis, quibus quid ita datum legatumve erit, eam pecuniam sine fraude sua capere liceto isque heres, qui eam pecuniam dare iussus damnatus erit, eam pecuniam debeto dare, quam damnatus est.*”译文：“任何罗马公民在本法请求通过后订立遗嘱，均有权力和能力依公法将其希望给与或遗赠的金钱给与或遗赠任何罗马公民；但遗嘱中须给继承人留下不少于遗产四分之一的部分。以此方式获赠或受遗赠者，得无诈地取得该金钱；被命令或判令给付该金钱的继承人，应给付其被判令给付的金额。”〔“请求通过”对应 *rogata*。〕

<!-- source-p 427 -->
<a id="35.2.1.1"></a>**1.**《法尔基第法》似乎也适用于在敌人控制下死亡的人，这是基于科尔内利亚法：该法使他们的遗嘱如同其在罗马公民共同体内死亡时一样有效。由于这一法律拟制，《法尔基第法》以及其他一切适用于遗嘱的法律亦随之适用，但仍以相关规定确有适用余地为限。

<!-- source-p 428 -->
<a id="35.2.1.2"></a>**2.**《法尔基第法》不适用于放弃依遗嘱继承这一原因、而占有遗产的人；不过，裁判官告示赋予了相当于该法的权能。

<!-- source-p 429 -->
<a id="35.2.1.3"></a>**3.**若宣誓条件被免除，情形亦同。

<!-- source-p 430 -->
<a id="35.2.1.4"></a>**4.**此外，立遗嘱人将遗赠给自己的奴隶并同时给予自由时，因遗赠要等到该奴隶成为自由人时才发生效力；若遗赠给处于敌人控制下的人，或尚未出生的人，本法也适用。

<!-- source-p 431 -->
<a id="35.2.1.5"></a>**5.**遗赠给市镇共同体的事项，以及遗赠给神祇的事项，也适用《法尔基第法》。

<!-- source-p 432 -->
<a id="35.2.1.6"></a>**6.**本法不仅适用于遗嘱人遗赠自己的财物，也适用于遗赠他人财物。

<!-- source-p 433 -->
<a id="35.2.1.7"></a>**7.**凡从死者遗产中支出的，均纳入本法计算；无论其为特定或不特定的有体物、按重量／数量／度量确定的物，还是用益权等权利，或债权。

<!-- source-p 434 -->
<a id="35.2.1.8"></a>**8.**若遗嘱如此规定：“我的继承人应给塞尤斯食品；若未给，则给十”，有人认为，无论如何都只是遗赠十；食品则是因死亡而取得之物，继承人不得将其计入《法尔基第法》的计算。我所了解的意见则是：若继承人立即给付食品，即可视为履行了遗赠，并可计入《法尔基第法》；所谓“立即”，应理解为在一段合理时间内。若继承人拖延后才给付食品，则不能视为受遗赠，也不得计入《法尔基第法》；因为此时遗赠已经转化为应给付十。若遗嘱自始如此规定：“若未给付食品，则给十”，结论也相同；因为此处食品并未被遗赠，若给付食品，属于因遗赠条件未成就而因死亡取得之物。

<!-- source-p 435 -->
<a id="35.2.1.9"></a>**9.**若遗赠的是用益权（用益权可以分割，不同于其他不可分割的役权），古代法学家认为应对整个用益权估价，据此确定遗赠的价值。阿里斯托则不同于古代法学家的意见：他说，可以像对有体物那样，从用益权中保留四分之一；尤利安认为此说正确。但若遗赠的是奴隶劳务，由于该遗赠中既不是使用权，也不是用益权，便有必要遵循古代法学家的意见，以确定遗赠价值；因为凡属事实上可分割的项目，均须扣除其一部分，而劳务并不能理解为可分割的份额。并且，即使在用益权情形下，若问题涉及受遗赠人取得多少，或为其他遗赠（乃至用益权本身）估价以判断遗赠是否超过四分之三，也必须回到古代法学家的意见。

<!-- source-p 436 -->
<a id="35.2.1.10"></a>**10.**若立遗嘱人将债务人所欠债务遗赠给债权人，该遗赠要么无益、因为没有任何利益；要么因立即受偿等利益而有效。在后一情形，《法尔基第法》也适用于该项利益。

<!-- source-p 437 -->
<a id="35.2.1.11"></a>**11.**若受遗赠人已取得占有，且因其系在继承人错误的意思下取得占有，继承人不能将该物取回，则可给予继承人诉权，使其请求返还超过遗产四分之三部分的价值。

<!-- source-p 438 -->
<a id="35.2.1.12"></a>**12.**有时必须先向受遗赠人给付全部遗赠，并订立返还超额部分的要式口约：“凡其取得超过《法尔基第法》所允许者，均应返还。”例如，未适婚人所作遗赠尚未超过该法限额，但若其在达到适婚年龄前死亡，可能还会发现其他遗赠，合并计算后超过遗产四分之三。若主要遗嘱中有若干附条件遗赠，是否应履行尚不确定，也同样如此。因此，若继承人准备不经诉讼即给付，可通过订立该口约保护自己。

<!-- source-p 439 -->
<a id="35.2.1.13"></a>**13.**因共同继承人的替补继承而归于共同继承人的份额，有利于受遗赠人；因为该共同继承人类似于一部分无条件、一部分附条件被指定为继承人的人。但若该共同继承人放弃继承，则其遗嘱中所作遗赠不会增加；前提是遗赠是特别指定给该人的，而非规定“凡成为我继承人的人”。

<!-- source-p 440 -->
<a id="35.2.1.14"></a>**14.**若我共同继承人的份额已被遗赠耗尽，而我的份额仍完整，我又主张取得该份额，卡西乌斯认为应合并计算两份；普罗库卢斯则持相反意见。尤利安在此情形赞同普罗库卢斯，我认为这一意见更可取。不过，也有记载称，神圣的安敦尼皇帝裁定，在《法尔基第法》的计算中应将两份合并。

<!-- source-p 441 -->
<a id="35.2.1.15"></a>**15.**若我在接受继承后收养了我的共同继承人，则毫无疑问，各份额应分别计算，犹如我继承了共同继承人的遗产。

<!-- source-p 442 -->
<a id="35.2.1.16"></a>**16.**若遗赠给提图斯的是逐年给付的遗赠，由于还有许多其他遗赠及附条件遗赠，应适用告示所规定的担保：“凡超额取得者，均应返还。”

<!-- source-p 443 -->
<a id="35.2.1.17"></a>**17.**有人认为，依其性质归属于遗产、但不得请求且一旦清偿又不得请求返还的债务，不应计入遗产。但尤利安认为，这类债务是否增加财产，应视实际结果而定；既然它也是依继承权取得的，亦应纳入遗产返还的范围。

<!-- source-p 444 -->
<a id="35.2.1.18"></a>**18.**若债务人成为债权人的继承人，虽因债权债务混同而免除债务，他仍被视为取得了较丰厚的遗产；因此，应将其所欠债务计入，即便该债务因接受继承而混同消灭。

<!-- source-p 445 -->
<a id="35.2.1.19"></a>**19.**问题在于，为建造纪念碑所支出的费用是否应扣除。萨宾努斯认为，若建造纪念碑确属必要，应予扣除。马尔凯鲁斯被问及：葬礼及纪念碑费用是否应依遗嘱人命令的数额作为债务扣除。他答复说，只能扣除为葬礼实际支出的费用。建造纪念碑的支出理由不同，因为纪念碑建造不像葬礼及埋葬那样具有必要性。因此，遗赠给某人用于建造纪念碑的钱款，仍受《法尔基第法》限制。

<a id="35.2.3.pr."></a>**序言**　若被指定的继承人出售了一项资不抵债的遗产，很难令人信服该遗产原本并非资不抵债，因为毕竟有人愿意购买；但按照真正的理由，受遗赠人仍无权取得任何给付，因为继承人取得利益，更多是来自买受人的愚蠢，而非死者的遗产。反过来说，若继承人以低价出售遗产财物，这也不应损害受遗赠人。因此，若继承人妥善管理财物，获利应归继承人。

<!-- source-p 452 -->
<a id="35.2.3.1"></a>**1.**若资不抵债的遗嘱人作出遗赠，而继承人与债权人达成和解，无须清偿全部债务，并因此得以保留部分财物，受遗赠人仍无权取得任何给付；因为继承人保留的钱并非来自遗产，而是来自和解。

<!-- source-p 453 -->
<a id="35.2.3.2"></a>**2.**若遗赠给国家或市镇共同体的是逐年给付的遗赠，而问题涉及《法尔基第法》，马尔凯鲁斯认为，应将遗赠视为仅有足够本金产生相当于所遗赠年金三分之一利息的金额。

帕比尼安《疑问集》第二十九卷。

<!-- source-p 478 -->
<a id="35.2.11.pr."></a>**序言**　就《法尔基第法》的计算而言，继承人在任何时候所作的保留，均计入其应保留的四分之一。

<!-- source-p 479 -->
<a id="35.2.11.1"></a>**1.**若奴隶被附条件给予自由，但在条件成就前死亡，若该条件后来终究成就，则不能认为继承人有所损失；若条件未成就，结论相反。但应依该附条件自由的奴隶死亡时的价值计算。

<!-- source-p 480 -->
<a id="35.2.11.2"></a>**2.**马尔库斯·安敦尼努斯皇帝裁定：其部分财产被剥夺的继承人，承担遗赠的责任不得超过其实际保留的财产份额。

<!-- source-p 481 -->
<a id="35.2.11.3"></a>**3.**某人被剥夺一半财产后遭放逐；他提起上诉，并在其后订立遗嘱而死亡。其死后，上诉被判为不合法。问题在于，是否应将被剥夺的一半作为债务扣除，仅把剩余部分视为其遗产；或者是否有必要给予继承人救济。看来应给予救济，因为当事人争讼及求取胜诉的意思，足以支持这一意见。

<!-- source-p 482 -->
<a id="35.2.11.4"></a>**4.**若经遗嘱解放的奴隶在继承人接受继承前死亡，通常应视为继承人丧失了该奴隶；但该奴隶若仍活着，本来又不会被估价，其价值如何计算？对于主人死亡时已患重病、确定无法存活的奴隶，虽然后来才死亡，也曾答复说应视为遗产损失。主人被家奴杀害时，同一屋檐下的家奴亦作相同处理。

<!-- source-p 483 -->
<a id="35.2.11.5"></a>**5.**通常所谓“父亲与儿子的遗嘱书中仅保留一个法尔基第法规定的四分之一”，其效力应予考察。尽管替补继承人取得了儿子所遗留的财产，并在儿子成为继承人时承受其债务，但对于第二遗嘱书中所作的遗赠，仍应合并计算。由此可能出现替补继承人一无所留，或者其所得远超父亲遗产四分之一的情形。那么，若未适婚人的遗产不足以清偿遗赠，而父亲的遗产本足以清偿，应如何处理？替补继承人应以自己的财产（即其四分之一）给付，因为父亲是从自己的财产中作出遗赠。并不妨碍这一结论的是：任何遗嘱均不得要求给付超过遗产总额的财物；因为在此法律关系中，第二遗嘱书的遗赠被视为第一遗嘱书中附条件作出的遗赠。

<!-- source-p 484 -->
<a id="35.2.11.6"></a>**6.**若某人为其儿子指定两名替补继承人，并使其中一人的份额负担遗赠，通常会讨论该替补继承人能否以自己的身份主张《法尔基第法》；而未适婚人本人或其一名替补继承人本来可能无权主张该法。有人很容易依照前述关于遗产计算的意见认为，本案不适用《法尔基第法》，另一名替补继承人也不应承担超过其份额的给付义务。但更妥当的意见相反：应给该替补继承人留下四分之一，如同他继承了父亲一样。正如父亲的财产状况及遗赠的合并计算由此获得其形式和基础，多名替补继承人也应撇开未适婚人这一中间层，按其指定继承人的地位理解。然而，对未负担遗赠的另一名替补继承人又应如何处理？假如未适婚人尚未清偿其所作遗赠，而所有遗赠合计超过四分之三，该替补继承人是否也能主张《法尔基第法》？但他本来就有四分之一，指定继承人的身份比较又不允许得出相同结论。若否认其权利，回答显然又与通常认可的意见不同。因此，结果会有所区别：以本人名义负担遗赠者，如同指定继承人一样，可以要求保留四分之一；另一名未负担遗赠者则如同替补继承人，尽管其份额有所增加，也不会因计算合并而被要求全额给付。由此还可得出：若未适婚人就《法尔基第法》订立了担保口约，两名替补继承人都可依各自本可保留的数额主张该口约。

<!-- source-p 485 -->
<a id="35.2.11.7"></a>**7.**有人问：若某人给未适婚人指定了一名共同继承人，《法尔基第法》应如何计算？通常所说遗赠计算应分开进行，是否正确？我曾答复，就父亲对儿子及替补继承人所作遗赠而言，不能分开计算，因为应合并计算，并相互分担遗赠负担。但由外部指定继承人作出的遗赠，不应与其他遗赠混合。因此，替补继承人应就未适婚人所获份额保留四分之一，即使其以指定继承人身份对自己的份额也享有四分之一。若某人是以多个份额被指定为继承人，则情况不同：此时各项遗赠的计算应当合并，正如其一次被指定为多个份额的继承人一样；其继承人身份是无条件的，还是分别附有不同条件，并无区别。

<!-- source-p 486 -->
<a id="35.2.11.8"></a>**8.**若某人给被排除继承权的儿子指定替补继承人，并在第二遗嘱书中由该替补继承人作出遗赠，则计算必然合并；尤利安认为替补继承人作出的遗赠有效，正是因为他也成为父亲的继承人。

<!-- source-p 533 -->
<a id="35.2.22.pr."></a>**序言**　涅塞尼乌斯·阿波利纳里斯致尤利乌斯·保罗：“阁下，发生了如下情形：提提娅将三个女儿按相等份额指定为继承人，并分别向她们互相作出遗赠；但她对其中一人作出遗赠时，规定该遗赠给共同继承人及外部受遗赠人，且适用《法尔基第法》。我询问：该女儿能否对其从共同继承人处所得的遗赠主张《法尔基第法》？若不能，是否应以恶意抗辩阻却？对外部受遗赠人应如何计算法尔基第法保留额？”答复如下：受遗赠人从共同继承人处取得遗赠，通常不会使其免受《法尔基第法》的扣减；但若负有给付遗赠义务的人自己也依据同一遗嘱向该受遗赠人请求给付，则不应允许其对该人援用《法尔基第法》，因为依遗嘱人的意思，他所将取得的利益应补足其希望扣除的部分。当然，对其他受遗赠人而言，他不应把向共同继承人给付的全部金额计入，而应仅计入在未从该人处取得任何利益时他本应给付的金额。

<!-- source-p 534 -->
<a id="35.2.22.1"></a>**1.**若奴隶被指定为继承人，而主人接受遗嘱信托、奴隶接受遗赠，应先计算遗赠，再从剩余财产中计算遗嘱信托。主人承担责任，仅以其所得为限；其所得是扣除遗赠后的剩余部分。当然，《法尔基第法》仍适用。

<!-- source-p 535 -->
<a id="35.2.22.2"></a>**2.**若主人放弃接受继承，并命令为自己指定的奴隶接受继承，则应先给付主人自己所作的遗赠；之后才计算奴隶所作的遗赠，但须以《法尔基第法》允许为限。

<!-- source-p 536 -->
<a id="35.2.22.3"></a>**3.**若遗赠给债务人的是免除债务，即使债务人无清偿能力，也应计入全部遗赠，尽管该债权仅在实际发生时才增加遗产。因而，若适用《法尔基第法》，该债务人所获免除债务应视为其受遗赠的金额；其他遗赠也会因此扣减，而这项遗赠本身亦会因其他遗赠而扣减；因为债务人被免除债务，也被视为取得了利益。

<!-- source-p 565 -->
<a id="35.2.30.pr."></a>**序言**　就《法尔基第法》的计算而言，奴隶或其他动物死亡、盗窃、抢劫、火灾、坍塌、海难、敌人、海盗或强盗的暴力，以及债务人资力恶化等损失，概而言之，任何损害，只要并非受遗赠人过错所致，均由继承人承担。与此相应，孳息、女奴所生子女、奴隶所取得的财产（例如要式口约、财物交付，以及遗赠、继承或其他赠与），还有役权消灭而使土地增值，以及取得的诉权（例如盗窃、非法损害等诉权），均归继承人获益；这些事项均不纳入《法尔基第法》的计算。

<!-- source-p 566 -->
<a id="35.2.30.1"></a>**1.**若受命以特定价格出售或购买土地或其他物品，在《法尔基第法》计算中应确定遗赠金额，则应计入该物品实际价值与遗嘱人命令接受或支付的价款之间的差额。不过，就计算扣除遗赠后的份额而言，应再扣除超过其价值的部分；因为该价款并非为受遗赠人自己的利益而取得，扣除该部分后，剩余价款才构成遗赠。

<!-- source-p 567 -->
<a id="35.2.30.2"></a>**2.**必须谨慎理解“遗嘱人死亡后发生的损失仅由继承人承担”这一说法，不得将其一概、毫无区别地适用。即使不考虑《法尔基第法》，本来适用的法律规则，在该法所设定的部分也应同样适用。之所以不扣除后来发生的损失，是为了避免因遗赠或遗嘱信托的份额已被划出而使其承担损失。

<!-- source-p 568 -->
<a id="35.2.30.3"></a>**3.**但上述规则确实只适用于以重量、数量或度量确定的物品；即使后来发生损失，也不得从依死亡时财产估价确定的份额中扣除任何金额。

<!-- source-p 569 -->
<a id="35.2.30.4"></a>**4.**对于特定物品，以及按特定方式表述的物品，例如“某箱内的钱”“某些酒瓮中的酒”“我存放在那些仓库中的一定重量的白银”，若在继承人无过错的情况下灭失或品质变坏，则毫无疑问，要么无须给付，要么仅应依遗嘱人死亡时遗产估价所确定的法尔基第法保留额，给付尚存物品及其当时状态所对应的部分。

<!-- source-p 570 -->
<a id="35.2.30.5"></a>**5.**遗赠不特定物品时，则应作区分。若立遗嘱人从自己的财物中遗赠不特定物品，例如“由其选择的白银”，而立遗嘱人所有的白银均在继承人无过错时灭失，则无须给付任何物品。反之，若无条件遗赠一定重量的白银，即使立遗嘱人的全部白银均已灭失，适用《法尔基第法》时仍应按立遗嘱人死亡时遗产中该类财物的数量计算其份额；后来发生的损失不影响该数额。

<!-- source-p 571 -->
<a id="35.2.30.6"></a>**6.**但已经灭失的物品，任何部分都不应给付，连估价金额也不应给付；这与遗嘱逐项列明并遗赠的所有物品均已灭失时相同。〔底本末尾有疑似讹误。〕

<!-- source-p 572 -->
<a id="35.2.30.7"></a>**7.**虽说为履行条件而给继承人的财物，在《法尔基第法》计算中不计入其四分之一，但若继承人被要求将财物返还遗嘱信托受益人时，并非以“履行条件”的名义收取某笔款项，塞尔苏斯及我们的尤利安认为该款仍应计入；这与继承人受命出售这些物品时相同，因为他被要求交付该款，并非为了履行条件，而是作为某种价款。在此还进一步讨论：遗嘱信托受益人是否也可被迫交付该款并接受遗产，仿佛遗嘱信托也对他设立一样。但这种推论并不可信，因为这种安排看起来更可能是为了受益人本人的利益，而非对其不利。

<!-- source-p 573 -->
<a id="35.2.30.8"></a>**8.**适用《法尔基第法》时，继承人遗赠或以遗嘱信托留给自己本人或其奴隶的财物，不纳入合并计算。定期给付的财物则不同：若给予自由人的日期已经到来，该财物即应给付，也应纳入合并计算。若某人无效地向自己的奴隶作遗赠或遗嘱信托，却未同时给予自由，该等财物也不纳入本法的计算。

<!-- source-p 574 -->
<a id="35.2.30.9"></a>**9.**显然不能通过遗嘱信托留给他人的财物，不纳入《法尔基第法》计算。

<a id="35.2.32.pr."></a>**序言**　刑罚性诉权，无论属于市民法还是裁判官法，除公益诉权外，均应计入原告的财产，不因被告死亡时诉权可能消灭而例外。反过来，被告死亡时，这些诉权不减少其遗产。若原告已死亡，侮辱诉权也不得计入原告财产，因为该诉权随本人死亡而消灭；用益权以及仅在某人存活期间逐日、逐月或逐年应付的给付也同样如此。只有转移给继承人的债务，才会减少被告的遗产。即使被告在世时其财产似乎较少，也不构成矛盾：若有人约定在债权人死亡时才开始欠债，该人的财产仍会增加；反之，若债务人约定在其死亡时才开始负债，其死亡时遗产就会减少。

<a id="35.2.73.1"></a>**1.**关于死亡时条件尚未确定的事项，存在很大争议：即附条件债务是否应计入债权人的财产，并从债务人的财产中扣除。我们适用的规则是：债权人财产中应计入该项债权期待可能出售的价值；债务人财产则相应扣除该价值。也可通过担保解决，使两种结果之一确定；或者按债务已无条件到期处理，或者视为完全不存在债务；之后由继承人与受遗赠人相互担保，若条件成就，继承人应返还其少付的金额；若条件未成就，受遗赠人应返还其多取得的金额。

<a id="35.2.87.1"></a>**1.**又，某人有两处土地，价值共一百；他指定我与提图斯为继承人，命令我以五十将科尔内利亚努斯土地卖给提图斯，又命令提图斯以五十将塞伊阿努斯土地卖给我。我不明白《法尔基第法》如何适用，因为我们各自基于继承权取得一处土地的一半，而该半份即遗产份额的一半。毕竟，被命令出售科尔内利亚努斯土地的人，依据继承权享有塞伊阿努斯土地的一部分；被命令出售塞伊阿努斯土地的人，也依据继承权保有科尔内利亚努斯土地的一部分。

<!-- source-p 785 -->
<a id="35.2.87.2"></a>**2.**若某人指定一人为继承人，并请求其死后返还一百，则在《法尔基第法》计算中，应扣除一百；因为若由其他任何人继承，这一百都会作为债务列入遗产。

<!-- source-p 786 -->
<a id="35.2.87.3"></a>**3.**若你与提图斯最初各按四分之一被指定为继承人，之后你又附条件被指定为二分之一继承人，并设有遗赠及自由解放，则在条件未定期间，自由解放即已生效，全部遗赠均应履行；因为无论条件成就、由你继承时，两者均有效，还是条件不成就、由你与提图斯继承，结论相同。若你问《法尔基第法》应如何适用，我们会答复：条件成就时，你的四分之一与二分之一应合并，因此对你无条件继承时向受遗赠人作出的遗赠，应按合并后的四分之三计算。

<!-- source-p 787 -->
<a id="35.2.87.4"></a>**4.**某人将其未适婚儿子与提图斯按相等份额指定为继承人，把全部二分之一遗赠给儿子，未向提图斯遗赠，并指定提图斯为儿子的替补继承人。问题是，提图斯依指定接受继承，儿子未适婚而死亡后，提图斯又依替补继承成为继承人时，应以遗赠名义给付多少。较可取的意见是，提图斯应全额履行遗赠；因为两份二分之一合并后，《法尔基第法》应以整个十二份为基础计算，因此遗赠可全额履行。但仅在儿子先于父亲死亡时，这一结论才正确。若儿子先继承父亲，替补继承人所负的遗赠义务不得超过未适婚人原先承担的数额；因为该义务并非由他以本人名义承担，而是源自已故未适婚人；未适婚人只须履行其二分之一中的四分之三。

<!-- source-p 788 -->
<a id="35.2.87.5"></a>**5.**若外部继承人所占二分之一全部被遗赠耗尽，而他又因替补继承未适婚人（未适婚人未作任何遗赠）而成为继承人，则可以认为遗赠增加；应如同其被指定为任何共同继承人的替补继承人，并因该共同继承人放弃继承而取得全部遗产一样处理；因为替补继承人始终应按父亲死亡时遗产数额计算《法尔基第法》。

<!-- source-p 789 -->
<a id="35.2.87.6"></a>**6.**父亲指定两名未适婚子女为继承人，并互相指定为替补继承人；之后遗产依替补继承归于其中一人，且需要计算《法尔基第法》时，也应作同样处理。

<!-- source-p 790 -->
<a id="35.2.87.7"></a>**7.**某人有两名未适婚儿子，指定一人为继承人，排除另一人；随后指定被排除者为继承人的替补继承人，之后又为被排除者指定麦维乌斯为替补继承人，并由其作出遗赠。被排除的儿子继承其未适婚兄弟后，也未适婚而死亡。既然依父亲遗嘱，父亲财产经由继承原因及替补继承归于麦维乌斯，可以认为，麦维乌斯应履行被排除儿子所作的遗赠，并以父亲死亡时遗留的财产为基础适用《法尔基第法》。这与父亲向被排除的儿子作出遗赠、替补继承人却不因此承担遗赠义务的情形不同；后者取得的不是父亲遗产份额，而是遗赠。有人会问：若被排除的儿子不是依替补继承而是依法或通过中间人继承其兄弟，随后又未适婚而死亡，替补继承人是否也应履行遗赠？绝非如此。被排除儿子依替补继承成为兄弟的继承人，与以其他方式继承兄弟并不相同；这还体现在前一种情形中，父亲可以由其作出遗赠，后一种则不能。因此，为符合逻辑，遗嘱人对替补继承人的法律地位，不应享有超过其对被替补者原本拥有的权利。

<!-- source-p 791 -->
<a id="35.2.87.8"></a>**8.**若某人与未适婚人共同继承，已按其份额并考虑《法尔基第法》履行遗赠；未适婚人死亡后，该共同继承人又依替补继承成为继承人，且未适婚人的二分之一已被遗赠耗尽，则应重新计算《法尔基第法》，将其本人及未适婚人所作遗赠合并，并使四分之一遗产留在其手中。虽然他成为未适婚人的继承人，但就《法尔基第法》而言，仍按其继承父亲遗产的情形计算。并且，只有在遗赠总额超过四分之三时，才增加其本人原先所作遗赠的负担；这与某人按份额被指定为继承人，并被指定为共同继承人的替补继承人，在共同继承人考虑后已按《法尔基第法》清偿遗赠，之后又依替补继承取得另一份遗产的情形相同。

<a id="35.2.88"></a>**35.2.88**

阿非利卡努斯《疑问集》第五卷。

<!-- source-p 794 -->
<a id="35.2.88.pr."></a>**序言**　某人遗产有四百，遗赠三百；之后又附条件遗赠一处价值一百的土地给你，条件是其遗嘱不适用《法尔基第法》。问题是法律如何规定。我说，这是一项“twn aporwn”（疑难之题）；辩证法学家称之为“tou qeudomenou”（说谎者）。〔底本以拉丁字母转写希腊文。〕因为无论我们认定哪一种结论为真，都会发现它是假的：若认定你的遗赠有效，《法尔基第法》便适用，条件不成就，你就无法取得土地；反之，若因条件不成就而认为遗赠无效，《法尔基第法》便不适用；若《法尔基第法》不适用，则条件成就，你就能取得土地。由于立遗嘱人显然不希望你的遗赠导致其他遗赠被扣减，更适当的处理是认定你的遗赠条件未成就。

<!-- source-p 795 -->
<a id="35.2.88.1"></a>**1.**若遗赠二百给其他人，同时也以同一条件遗赠二百给你，又该如何？认定你的遗赠条件成就或不成就，从而使你取得全部或一无所得，均不公平且违背立遗嘱人的意思；若只履行部分遗赠，也不合逻辑，因为整个遗赠的条件只能成就或不成就。因此，应通过恶意抗辩调整整个关系。

<!-- source-p 796 -->
<a id="35.2.88.2"></a>**2.**若有人希望取得类似结果，可以如此立遗嘱。底本原文：“*Si quo amplius legavi vel legavero, quam per legem Falcidiam licebit, tum quantum ad supplendum quadrantem deduci oportet, ex eo legato quod Titio dedi heres meus damnas esto dare.*”译文：“若我所遗赠或将遗赠的数额超过《法尔基第法》允许的限额，则我的继承人应从我给提图斯的遗赠中，给付补足四分之一所需扣除的金额。”

<!-- source-p 797 -->
<a id="35.2.88.3"></a>**3.**某人遗产有二百，立即遗赠一百给我，又附条件遗赠一百给你；一段时间后条件成就，但你所得金额的收益使你最多只能取得二十五。应如此计算继承人的法尔基第法保留额：你应将二十五计入合并计算；还应计入继承人期间取得的五十金额孳息，例如五。于是合计须计入三十。有人认为，我与您应各计入十五，但此说并不正确；虽然我们取得了相同的名义金额，显然我的遗赠收益更高。因此，你的遗赠中应扣除继承人从其孳息所取得的金额。依此，本案应按七份计算：我应计入四份，你计入三份，因为我的遗赠比你的多出四分之一。
