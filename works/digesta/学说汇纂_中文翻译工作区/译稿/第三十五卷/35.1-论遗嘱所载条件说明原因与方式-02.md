# D.35.1 论遗嘱所载条件、说明、原因与方式（*De condicionibus et demonstrationibus et causis et modis eorum, quae in testamento scribuntur*，第二段）

<!-- source-p 141 -->
拉贝奥后期著作评注第一卷，雅沃勒努斯。

<!-- source-p 142 -->
<a id="35.1.39.pr."></a>**35.1.39 序言**　我们认为，若条件针对某一类人而非特定且明确的人，该条件便关涉整个遗嘱，并适用于所有被指定的继承人；若条件是为特定的人设置，则应将其仅归于这些人被指定继承的那一顺位。

<!-- source-p 143 -->
<a id="35.1.39.1"></a>**1**　遗嘱如此写道：“应在广场上做某事”，却未注明是在哪一广场。拉贝奥说，若不能查明死者的意思，就应在立遗嘱人有住所的那个市镇的广场上实施。我也赞同这一见解。

<!-- source-p 144 -->
<a id="35.1.40"></a>**35.1.40**

<!-- source-p 145 -->
拉贝奥后期著作评注第二卷，雅沃勒努斯。

<!-- source-p 146 -->
<a id="35.1.40.pr."></a>**序言**　在你想前往履行条件的那些日子里，邻人阻止你走公共道路，而阻碍并非出于你的原因，且你也不能通过提起诉讼以恶意诉讼为由排除该阻碍的，所耗这些日子不计入条件期限。

<!-- source-p 147 -->
<a id="35.1.40.1"></a>**1**　有人如此遗赠：“若普布利乌斯·科尔内利乌斯将我为塞伊乌斯庄园支出的费用交给我的继承人，我的继承人届时应将塞伊乌斯庄园交给普布利乌斯·科尔内利乌斯。”卡斯凯利乌斯认为，庄园价款也应给付；奥菲利乌斯则认为，“费用”一词并不指价款，而只指购买庄园后为其支出的费用。辛纳也写道，计算费用时不应扣除收益；我认为这后一见解更为正确。

<!-- source-p 148 -->
<a id="35.1.40.2"></a>**2**　有人将一百遗赠给提图斯，随后又在遗嘱下文命令：“凡我遗赠给各人的钱款，我的继承人应在我母亲去世时给付。”家父去世时，提图斯仍在世；家母尚在世时，提图斯便去世了。奥菲利乌斯答称，家母去世后，应将遗赠给付提图斯的继承人，因为遗赠并非附条件，而是先作了无条件遗赠，只是另附给付日期。拉贝奥说，我们应当看看这是否错误：因为以下两种写法并无区别：“凡我遗赠给各人的钱款，我的继承人应在我母亲去世时给付”，或者“除非我母亲去世，否则不得给付”；在两种情形中，遗赠都是附条件作出，或者说其撤回也附有条件。我赞同拉贝奥的答复。

<!-- source-p 149 -->
<a id="35.1.40.3"></a>**3**　主人将五枚金币遗赠给奴隶，并写道：“我的继承人应给我的奴隶斯提库斯五枚金币，即我在账簿上所欠的款项；我已命令在遗嘱中释放他。”纳穆萨·塞尔维乌斯写道，他曾答称并未遗赠任何物给奴隶，因为主人不可能对奴隶负有债务。我认为，应依立遗嘱人的意思考察自然债务，而非市民法上的债务；我们也遵循这一法律规则。〔底本此处有残缺字样“eius []”，所指不明。〕

<!-- source-p 150 -->
<a id="35.1.40.4"></a>**4**　某人并无任何嫁资庄园，却如此遗赠：“我的继承人应将科尔内利乌斯庄园交给她；她曾把该庄园作为嫁资给我。”拉贝奥、奥菲利乌斯和特雷巴提乌斯答称，该庄园仍属有效遗赠，因为科尔内利乌斯庄园确实存在；错误的说明并不使遗赠无效。

<!-- source-p 151 -->
<a id="35.1.40.5"></a>**5**　小特尔穆斯在遗嘱中写道，他希望由他人裁量为自己建造墓冢，随后又遗赠：“我的继承人应给卢基乌斯·普布利乌斯·科尔内利乌斯诸人一千，用于建造我的墓冢。”特雷巴提乌斯答称，应将此视同遗赠附有如下条件：他们须提供担保，保证以该笔钱按上述方式建造墓冢。拉贝奥赞同特雷巴提乌斯的见解，因为立遗嘱人的意思是让这笔钱用于建造墓冢；我和普罗库鲁斯也赞同此说。〔底本作 *ex ea pecunia*；异文标记“[ea]”所涉读法保留待核。〕

<a id="35.1.43"></a>**35.1.43**

<!-- source-p 159 -->
保罗《普劳提乌斯评注》第八卷。

<!-- source-p 160 -->
<a id="35.1.43.pr."></a>**序言**　普劳提乌斯记载：一名作为自由人的立遗嘱人嘱托继承人，在继承人收取十之后，将全部遗产转售给该自由人。后来，死者的庇护人请求取得违背遗嘱的遗产占有，并取走了依法应得的遗产份额。普罗库鲁斯和卡西乌斯说，遗嘱信托受益人应按比例请求返还已支付的款项。保罗说：我们遵循这一法律规则。正如继承人履行遗嘱信托和遗赠后，经裁判官之助即可免除义务，他本人也应能取回相应份额。

<!-- source-p 161 -->
<a id="35.1.43.1"></a>**1**　若情形不同，即法尔奇狄亚法介入并减少遗赠，则不应请求返还任何款项，因为条件已被完整履行。

<!-- source-p 162 -->
<a id="35.1.43.2"></a>**2**　同样，若受遗赠人不能完整取得遗嘱留给他的遗产份额，给付义务也应分割。较为妥当的看法是：他应履行其中一部分，而从他处取走超出法律许可数额的人，应履行另一部分。

<!-- source-p 163 -->
<a id="35.1.43.3"></a>**3**　涅拉提乌斯《答复集》第一卷写道：若有两名指定继承人，其中一人受嘱托将遗产返还给你，而你须给付提图斯一笔确定数额；继承人在返还时又享有法尔奇狄亚法的利益，那么你向提图斯给付的数额相应减少多少，才不失公平。

<!-- source-p 164 -->
<a id="35.1.44"></a>**35.1.44**

<!-- source-p 165 -->
保罗《普劳提乌斯评注》第九卷。

<!-- source-p 166 -->
<a id="35.1.44.pr."></a>**序言**　受命向继承人给付的人，在另有他人的奴隶被指定为继承人时，应向该奴隶给付，而非向其主人给付。因为，即使另有继承人被指定，而给付义务人受命向提图斯的奴隶给付，款项也应给奴隶本人；事实行为的效果不会移转给主人。正如我约定向我本人或提图斯的奴隶给付时，既可向我给付，也可向其奴隶给付，而不必向提图斯给付。以上见解均属正确。

<!-- source-p 167 -->
<a id="35.1.44.1"></a>**1**　但是，若受命向继承人给付，我们应考察是否应向主人给付；由此推论，此处也应向奴隶给付。

<!-- source-p 168 -->
<a id="35.1.44.2"></a>**2**　当然，附条件获释的奴隶（*statuliber*）必须向主人给付，这一点毫无疑问。

<!-- source-p 169 -->
<a id="35.1.44.3"></a>**3**　反之，若应向主人给付，却向其奴隶给付，条件并未履行，除非主人表示同意。因为在这种情形下，未经我知悉或同意，任何人都不能履行条件。

<!-- source-p 170 -->
<a id="35.1.44.4"></a>**4**　依特雷贝利亚努姆元老院决议返还遗产时，应向继承人给付，方能履行条件；该项给付不应再依遗嘱信托的事由予以返还。

<!-- source-p 171 -->
<a id="35.1.44.5"></a>**5**　但是，若某人以可疑遗产为由接受继承后又返还遗产，曾有人疑问是否应从他处取走某物。此处也应从宽处理，不应从其处取走任何东西。

<!-- source-p 172 -->
<a id="35.1.44.6"></a>**6**　若我被指定为继承人，而有人对我取得继承权提出争议；受遗赠人承诺，若遗产被追夺便返还遗赠，那么受遗赠人也应获得担保，确保其已给付之物可获返还。〔本句担保的提供人与受保护人关系，底本文字省略，依句法暂译。〕

<!-- source-p 173 -->
<a id="35.1.44.7"></a>**7**　但是，若你受命给我十，并据元老院决议接受遗产，我不会基于遗嘱信托事由将这十返还给你。

<!-- source-p 174 -->
<a id="35.1.44.8"></a>**8**　若遗赠给两名奴隶中的一人，并附有给付条件，有人说条件不能分开履行，而必须一次给付全部款项；但我持相反意见。

<!-- source-p 175 -->
<a id="35.1.44.9"></a>**9**　若遗赠物的一部分已因取得时效而归属他人，我不确定是否必须完整履行条件。可以说，依立遗嘱人的意思，履行其中相应部分即可。

<!-- source-p 176 -->
<a id="35.1.44.10"></a>**10**　普劳提乌斯说：“我将庄园遗赠给一名继承人，条件是他向继承人们给付一百。他应扣除自己所占的遗产份额，并按其他继承人的份额向他们给付余款。可是，若某人被指定为部分继承人，条件是向共同继承人给付十，他只有在向共同继承人给付全部十之后才成为继承人；因为只有给付全部款项，他才会被接纳为继承人。曾有一名奴隶在遗嘱中被释放，并被指定为部分继承人，条件也是向继承人给付十；对此，意见一致认为，他只有在向共同继承人给付全部十后，才会成为自由人和继承人。”保罗说：我们遵循这一法律规则。

<a id="35.1.71.pr."></a>**序言**　遗赠给提图斯一百，条件是他购买一座庄园。塞克斯图斯·凯基利乌斯认为，不应强迫提图斯提供担保，因为遗赠的利益只归于他本人。但是，若立遗嘱人意在照顾不够勤勉的儿子、兄弟或受养人，则应认为继承人也有利害关系；因此必须提供担保，保证购买庄园并且此后不将其转让。

<!-- source-p 267 -->
<a id="35.1.71.1"></a>**1**　遗赠给提图斯一百，条件是他与寡居的梅维娅结婚。条件不得免除，因此担保也不得免除。这一见解并不因如下情形而受影响：若某人承诺，倘若不与梅维娅结婚便给付钱款，裁判官会拒绝给予诉权。因为，因惧怕处罚而被剥夺选择婚姻的自由，与通过遗嘱以特定条件受到诱引，是两回事。

<!-- source-p 268 -->
<a id="35.1.71.2"></a>**2**　遗赠给提图斯一百，条件是他不得离开我的墓冢，或在该市镇设立住所。可以说，不应要求提供担保，因为该担保会侵害其自由权。但对于死者的自由人，我们适用不同的法律规则。

<!-- source-p 269 -->
<a id="35.1.71.3"></a>**3**　“我的继承人应以我女儿塞娅的嫁资名义，给我的女婿提图斯一百。”遗赠的利益固然归于开始取得嫁资的塞娅；然而，既然看来不仅照顾了该女子，也照顾了获得钱款遗赠的提图斯，那么提图斯本人应被视为受遗赠人，并应请求遗赠。离婚后，若继承人将钱款交给女婿，同样可以免除义务，因为该给付已转作嫁资。婚姻关系存续期间，即使妻子反对，向提图斯给付仍属有效；因为开始拥有嫁资也符合该女子的利益。有人若认为妻子本人也有请求权，而她请求钱款却不愿将其作为嫁资，则毫无疑问，继承人可以提出恶意抗辩。婚姻缔结前，若提图斯或该女子死亡，遗赠仍由继承人保有。若提图斯不愿娶她，就该女子而言，遗赠的事由可视为已经满足；但提图斯请求遗赠时，将受到恶意抗辩的阻却。萨宾则认为，该女子结婚后，提图斯无需提供担保即可请求遗赠，因为钱款将成为嫁资；但是，婚前遗赠是无条件的，可以请求给付，因此必须提供担保，保证将钱款返还给该女子。若丈夫因自己的过错使婚姻未能成立，并且无清偿能力，是否应为无过错的妻子提供救济，使她可以向继承人请求原定作为嫁资的钱款？但由于夫妻双方均有遗赠请求权，若钱款尚未付给丈夫，该女子仍保有诉权。

<a id="35.1.72"></a>**35.1.72**

<!-- source-p 271 -->
帕比尼安《疑问集》第十八卷。

<!-- source-p 272 -->
<a id="35.1.72.pr."></a>**序言**　遗赠给提提娅的条件是“若她不离开子女”。有人认为，她无法妥善提供担保，因为即使子女死亡，遗赠条件也可能成就。但这一见解未被采纳：不应以如此不祥、要求不提供担保的解释，违背母亲的意愿。

<!-- source-p 273 -->
<a id="35.1.72.1"></a>**1**　庇护人将一笔确定数额遗赠给自由人，条件是自由人不离开其子女。皇帝准许提供类似穆基乌斯担保的担保；因为要求与庇护人子女关系密切的自由人等待他们死亡，既危险又令人悲伤。

<!-- source-p 274 -->
<a id="35.1.72.2"></a>**2**　提图斯被指定为继承人，立遗嘱人嘱托他在自己死后返还遗产，条件是无人请求遗嘱信托担保。若在立遗嘱人设立该遗嘱信托之前，担保已经被免除，则不能援用穆基乌斯担保的范例；因为在受领遗嘱信托的人仍在世时，条件便可能成就。

<!-- source-p 275 -->
<a id="35.1.72.3"></a>**3**　那么，若遗嘱如此写道：“我请求你在死后返还遗产，但不得请求提供遗嘱信托担保，也不得要求核算账目”，又应如何处理？毫无疑问，这些措辞似乎附加了不要求提供担保的条件；至于不要求核算账目，则应理解为仅免除过失责任，而非故意责任。对此，曾就一名事务管理人作出答复：该人依遗嘱免除了交账义务。

<!-- source-p 276 -->
<a id="35.1.72.4"></a>**4**　“若提图斯裁量塞娅结婚，我的继承人应将庄园给她。”应答称，即使提图斯尚在世，而她未遵从提图斯的裁量便结婚，她仍可取得遗赠；这似乎是该法律规则的含义，即不得对婚姻施加任何阻碍。但若提图斯在立遗嘱人之前死亡，尽管条件未能成就，仍应给予该女子救济，因为即使条件悬而未决，对她也不会有任何利益。

<!-- source-p 277 -->
<a id="35.1.72.5"></a>**5**　“我将庄园遗赠给梅维娅，若她未结婚，则在她死亡时给付。”可以说，若她结婚，她即可立即取得遗赠。若遗赠另附有一个确定日期或另一个不确定日期，则不能作相同认定。

<!-- source-p 278 -->
<a id="35.1.72.6"></a>**6**　更为正确的见解是，错误的原因说明不损害遗赠，因为遗赠与其原因并无内在联系；但是，若能证明立遗嘱人若非如此便不会遗赠，通常可以提出恶意抗辩。

<!-- source-p 279 -->
<a id="35.1.72.7"></a>**7**　卡西乌斯和凯利乌斯·萨宾认为，错误条件属于不可能条件，例如：“若潘菲卢斯偿还我欠提图斯的债务，他即为自由人”，但实际上我并不欠提图斯任何债务。若立遗嘱人在遗嘱作成后偿还了该笔钱，则应认为条件未能成就。

<!-- source-p 280 -->
<a id="35.1.72.8"></a>**8**　萨宾答称，错误的遗赠说明不能成立遗赠。例如，某人并未将任何财产遗赠给提图斯，却如此写道：“在我遗赠给提图斯的一百中，我的继承人应给塞伊乌斯五十。”他依据死者的意思得出这一结论：立遗嘱人如此书写，并非意在遗赠，而是意在减少其误以为已作出的遗赠。但即使遗赠说明有误，塞伊乌斯所能取得的，也不会超过说明正确时本可取得的数额。
