<!-- source-p 294 -->
帕皮尼安《答复集》第七卷。

<!-- source-p 295 -->
<a id="35.1.77.pr."></a>**序言。**祖母以孙子被解放出父权为条件，指定他取得部分遗产继承权；后来又在遗嘱附录中写道：“除已指定孙子为继承人之外，我另将那座庄园遗赠给他。”应认为，遗赠中重复包含了解放出父权这一条件，即使祖母像其指定继承人时那样，并未在遗赠中设立替补继承人。神圣的庇乌斯皇帝也曾以敕答规定：如果奴隶被无条件命令释放，却仅在成为继承人时附条件；并且若未成为继承人，仍命令向其给付遗赠，则在遗赠中应视为再次附加了自由条件。

<!-- source-p 296 -->
<a id="35.1.77.1"></a>**1.**如果另一个条件会使遗赠之诉延后，便无需提供穆基乌斯担保。

<!-- source-p 297 -->
<a id="35.1.77.2"></a>**2.**“若该妇女不结婚，我的继承人应给提提乌斯一百。”提提乌斯受托将这笔钱返还给该妇女。如果该妇女在遗赠权利开始发生之日已经结婚，她可以请求履行遗嘱信托；但若不考虑此项遗嘱信托，受遗赠人便不能享有穆基乌斯担保所具有的保护。

<!-- source-p 298 -->
<a id="35.1.77.3"></a>**3.**父亲剥夺女儿继承权，并为她指定监护人；如果女儿未成年时其母亲先于女儿去世，父亲命令监护人开始管理事务。同时，他嘱托妻子在临终时将一千返还给他们共同的女儿。监护人的指定不应视为附条件；如果女儿期间另有财产，也不因此妨碍监护人管理该财产；但母亲的遗嘱信托担保已获免除。任何能够表明立遗嘱人意思的方式，均可免除遗赠或遗嘱信托的担保。因此，即使遗赠或遗嘱信托附有“不必提供担保”的条件，该安排也不会因此成为附条件遗赠或信托：如果有人要求担保，而担保义务并未随之发生，该条件也不会落空；因为在法律承认担保可以免除后，现行公法并不允许强迫不愿提供担保的人担保。

<!-- source-p 303 -->
<a id="35.1.79"></a>**35.1.79**

<!-- source-p 304 -->
帕皮尼安《法则集》第一卷。

<!-- source-p 305 -->
<a id="35.1.79.pr."></a>**序言。**“我的继承人应在提提乌斯死亡时给他一百。”这是无条件遗赠，因为该遗赠只是被延后，而非附有条件；死亡这一事件必然发生〔底本异文：*existere*〕。

<!-- source-p 306 -->
<a id="35.1.79.1"></a>**1.**“我的继承人应在自己死亡时给提提乌斯一百。”这是附条件遗赠；虽然继承人一定会死亡，但不能确定其死亡时受遗赠人是否仍在世。遗赠权利开始发生的日期尚未到来，也不能确定遗赠最终会归于该受遗赠人。

<!-- source-p 307 -->
<a id="35.1.79.2"></a>**2.**受遗赠人提供穆基乌斯担保后取得遗赠；如果他违反担保，因要式允诺责任已经发生，除须向继承人返还遗赠外，还须返还孳息。受遗赠人自始就有义务就此提供担保。

<!-- source-p 308 -->
<a id="35.1.79.3"></a>**3.**虽然不能有效地把用益权遗赠至受遗赠人死亡之时，但如果遗赠用益权附有“不实施某行为”的条件，穆基乌斯担保救济也适用于此种用益权遗赠。

<!-- source-p 309 -->
<a id="35.1.79.4"></a>**4.**以阻挠婚姻为目的、规避法律所作的安排不发生效力。例如：“若其父权下的女儿不结婚，我的继承人应给提提乌斯之父一百”；或者：“若某家子的父亲不结婚，我的继承人应给该家子一百。”

<a id="35.1.81"></a>**35.1.81**

<!-- source-p 314 -->
保罗《疑难集》第二十一卷。

<!-- source-p 315 -->
<a id="35.1.81.pr."></a>**序言。**朱利乌斯·保罗致宁菲狄乌斯：你问，若遗嘱如此规定：“若斯提库斯交出账目，他与其同居女伴即获得自由，继承人应给他们十”，在斯提库斯尚未交账便死亡时——无论他已经生育子女，还是仍有余额未清——该妇女是否获得自由；遗赠是否也应作相同处理。奴隶若依交账条件获释，该交账条件应理解为：如果他尚有余额，就应基于对其事务处理的信义将余额返还。若并无余额，他即无条件获得自由；若他在继承人接受遗产后才死亡，则由于自由已发生效力，遗赠也随之归于他和该妇女。反之，如果他在仍有余额时死亡，则其同居女伴似乎也附同一条件获得自由；条件未成就，她的自由也就不能生效。不过，也可以作出一种并非不合理的解释：斯提库斯是附条件获释，而其同居女伴是无条件获释；将他们并列，是为了表明二人之间的关系，而非使该妇女的自由也附加同一条件。

<!-- source-p 316 -->
<a id="35.1.81.1"></a>**1.**只有在本应因条件成就而负有债务之人阻碍条件成就时，才视为条件已经成就。

<a id="35.1.82"></a>**35.1.82**

<!-- source-p 318 -->
卡利斯特拉图斯《疑难集》第二卷。

<!-- source-p 319 -->
如果奴隶被命令“在交出账目时”获得自由，而继承人又被命令给他一座庄园，我们须考察：该条件只附加于自由，还是也附加于遗赠。若仅认为该条件附加于自由，则无需进一步讨论：遗赠本身为无条件遗赠，因此会无效。若像有些人正确主张的那样，该条件也包含在遗赠中，则自由与遗赠的权利开始发生之日可以同时到来。于是，“若他交出账目”这句话究竟包含什么？有人说其意为“若他返还余额”，仿佛“若返还余额”与“若交出账目”是同一条件。但我们既不认为该条件纯粹取决于给付，也不认为其纯粹取决于行为；它是两者混合构成的条件。因为奴隶若只把余额放在钱袋中提出交付，并不当然就获得自由：立遗嘱人的意思并非如此，而是要求他像奴隶通常交账那样履行义务，也就是先提交账目供人查阅，再予核算，以便查明记入的扣除项目是否正当、收入是否记载正确。事情因此始于行为，最终则落实到钱款。该文字还要求继承人了解账目内容，使其知道每笔账目记载了什么。立遗嘱人生前会亲自做的事，应理解为命令继承人照办；而他不会仅在奴隶提交余额时便为其签署账目，而是会阅读、审核并核对。因此，遗嘱以“若他交出账目”为条件释放奴隶时，含义不只是奴隶向继承人出示其经手事务的全部凭证和文书，也包括他须清偿尚欠余额。

<a id="35.1.86.pr."></a>**序言。**我们的尤利安认为：若奴隶被命令给付十后获得自由，而他在主人生前即获释放，那么与自由一并遗赠给他的财物，只有在他满足自由所附条件后才能取得；若他被出卖，规则亦同。但只有在遗赠原则上可以与自由同时取得、即使遗赠本身并未附条件时，才适用此规则；例如，遗赠被延至自由发生之时给付。

<!-- source-p 332 -->
<a id="35.1.86.1"></a>**1.**如果自由附有条件，而遗赠则自始即可取得，问题就在于该遗赠是否成立。此处不适用卡托规则，因为即使立遗嘱人立即死亡，遗赠也未必全然无效：条件仍可能在继承人接受遗产之前成就，奴隶获释后即可取得遗赠。除非有必然继承人；在这种情形下，遗赠依法律本身当然无效，因为受遗赠人取得自由时仍处于附条件状态。

附加于未来事项的条件有三种性质：有些涉及立遗嘱人生前的期间；有些涉及其死后发生的事项；还有些则可能在其生前或死后成就。相关期间可以是确定的，也可以是不确定的。上述情形不仅适用于遗嘱信托，也常见于继承指定和遗赠。例如，“给提提娅，若她嫁给我”，显然只能在立遗嘱人生前成就；“若她参加我的葬礼”，则只能在立遗嘱人死后成就；“若她嫁给我的儿子”，则无论立遗嘱人生前或死后，都可能成就。上述第一项和第三项条件均没有确定期限：条件在她结婚时即成就；第二项条件则附有确定期限。

<a id="35.1.92"></a>**35.1.92**

<!-- source-p 349 -->
乌尔比安《遗嘱信托论》第五卷。

<!-- source-p 350 -->
如果某人获得遗赠，并受托解放自己的子女，能否强制其解放子女？我记得自己曾说，他们会丧失请求遗嘱信托的权利；因为裁判官并不像保护奴隶那样，以遗嘱信托保护他们获得自由。我还记得，帕皮尼安在《答复集》第九卷中也写道，不得强迫某人解放自己的子女。然而我认为，若某人明知遗赠是为了使其解放子女而仍予接受，特别程序应裁定强迫其解放子女；否则便会挫败立遗嘱人的意愿。此事应视为遗赠附有解放子女条件，或者受遗赠人因承诺解放子女而取得遗赠。神圣的塞维鲁皇帝曾以敕答确认这一点：某妇人指定自己的孙子为继承人，也指定自己的儿子与孙子共同继承，并令他们彼此为替补继承人；她请求儿子解放其子女，却未请求其向子女返还遗产。根据神圣塞维鲁皇帝的权威，该儿子被强制解放子女并向他们返还遗产。敕答还补充：如果他迟延履行，就应支付迟延利息；因为迟延解放子女者，视为同时迟延履行遗嘱信托返还。
