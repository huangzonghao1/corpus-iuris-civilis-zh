<!-- source-p 352 -->
帕皮尼安《答复集》第八卷。

<!-- source-p 353 -->
母亲在未附任何条件的情况下，使儿子与自己的女儿们共同成为继承人，并请求儿子解放其女儿们，以便她们从裁判官处取得财产管理人。人们认为，儿子受托的意思是：使女儿们成为自权人后，允许她们继承祖母的遗产；至于儿子是否依据替补继承规则取得了女儿们的份额，则与此无关。

<!-- source-p 354 -->
<a id="35.1.94"></a>**35.1.94**

<!-- source-p 355 -->
赫莫革尼安《法律摘要》第一卷。

<!-- source-p 356 -->
<a id="35.1.94.pr."></a>**序言。**以如下方式授予自由：“如果他向提提乌斯”（此人并非继承人）“给付十”，这里指明了一个确定的人，因此条件只能由向此人给付而成就。当然，如果条件期限届至时，附条件获释的奴隶持有条件所涉及的钱款，依既定法律，即使他不给任何人钱，也能取得自由。受遗赠人的情形则不同：如果提提乌斯在受遗赠人给付钱款之前死亡，条件便因受遗赠人本人而落空。

<!-- source-p 357 -->
<a id="35.1.94.1"></a>**1.**根据“如果他向继承人”或“如果他向继承人提提乌斯给付十，便获得自由”这样的文字，给付对象不仅可以是继承人，也可以是继承人的继承人；附条件获释的奴隶向继承人的继承人给付，也能取得自由。但如果没有人承受继承人的遗产，依既定法律，即使不给任何人钱，他也会取得自由。

附条件遗留的遗赠转给他人时，只要该条件并非与受遗赠人本人身份相连，就应视为连同同一条件一并转移。

<a id="35.1.96"></a>**35.1.96**

<!-- source-p 362 -->
保罗《尼拉提乌斯评注》第一卷。

<!-- source-p 363 -->
<a id="35.1.96.pr."></a>**序言。**奴隶的用益权遗赠给提提乌斯，并规定：如果用益权不再归属于提提乌斯，该奴隶即获自由。提提乌斯在立遗嘱人尚在世时死亡。该自由安排无效，因为条件尚未开始发生。保罗说：因此，即使提提乌斯仍在世但不能取得用益权，结论也相同；尚未开始的事项，不能说已经终止。

<!-- source-p 364 -->
<a id="35.1.96.1"></a>**1.**奴隶的用益权遗赠给一名妇女，期限为她守寡期间；并命令同一奴隶在她结婚时获得自由。妇女若结婚，该奴隶即获自由，因为自由优先于遗赠。

<a id="35.1.101"></a>**35.1.101**

<!-- source-p 378 -->
帕皮尼安《答复集》第八卷。

<!-- source-p 379 -->
<a id="35.1.101.pr."></a>**序言。**父亲在遗嘱中指定其女塞维里安娜·普罗库拉嫁给姻亲埃利乌斯·菲利普；又以她嫁给埃利乌斯·菲利普为条件，将一处庄园以遗嘱信托方式留给女儿；如果她不嫁，则希望将同一庄园交给菲利普。该女孩尚未达到适婚年龄便去世了。我答复说，解释遗嘱条件时，应重视遗嘱人的意思而非文字；因此，对埃利乌斯·菲利普所设遗嘱信托，应理解为以已故立遗嘱人的女儿普罗库拉不愿嫁给他为条件。既然她在达到适婚年龄之前便去世，就不能认为条件已经成就。

<!-- source-p 380 -->
<a id="35.1.101.1"></a>**1.**遗嘱信托如此设立：“我希望你在无子女而死时返还遗产。”依立遗嘱人的意思，只要受托人留下一个子女，条件即告落空。

<!-- source-p 381 -->
<a id="35.1.101.2"></a>**2.**遗嘱中所写的条件，应依立遗嘱人的意思解释。因此，遗嘱指定的监护人因未成年男孩后来长大，采取行动使自己被任命为财产管理人；遗嘱信托条件写作“如果他们担任监护职务直至男孩十八岁”，不能因此认为该条件落空。

<!-- source-p 382 -->
<a id="35.1.101.3"></a>**3.**婆母以如下条件向儿媳设立遗嘱信托：“如果她继续与我儿子保持婚姻关系。”婆母去世后，双方在丈夫无过错的情况下离婚。我答复说，条件已经落空。遗嘱信托的履行期限要到妻子或丈夫开始死亡时才届至；因此，穆基乌斯担保也不适用，因为丈夫死亡时条件仍可能成就。

<!-- source-p 383 -->
<a id="35.1.101.4"></a>**4.**遗嘱人以“只要他管理 patron 女儿的事务”为条件，按月、按年向其自由人设立遗嘱信托。即使女儿禁止其管理自己的财产，仍有义务给付；但若女儿改变主意，该条件便恢复适用，因为相关给付有多期。

<a id="35.1.107"></a>**35.1.107**

有时，附条件作出的遗赠应视为无条件遗赠，例如：遗赠所附条件与另一继承人被指定为继承人时所附条件相同，或者遗赠附有“若其接受遗产”这一条件。反过来，有时无条件作出的遗赠也看似附有条件，例如遗赠在某一条件下被撤回，因为这应理解为在相反条件下作出遗赠。

<a id="35.1.111"></a>**35.1.111**

<!-- source-p 412 -->

<!-- source-p 413 -->
某奴隶被命令在交代账目这一条件下获得自由。他必须证明自己经手的一切均可置信：既未侵吞所收取的任何物品，也未在账目中记载实际上并未支付的支出；而且，账目连续记载后显示仍由他持有的余额，他也必须予以清偿。只有这样履行使其获得自由的条件，他才能取得自由。至于他本人所订立合同的债务人，并非一概须由他证明这些人在其主人死亡之日具有清偿能力；他只须证明，在向这些人提供信用之时，他们的状况足以使一个谨慎的家父愿意向其放贷。

<a id="35.1.112"></a>**35.1.112**

<!-- source-p 415 -->
庞波尼乌斯《书信集》第十二卷。

<!-- source-p 416 -->
<a id="35.1.112.pr."></a>**序言。**诸如“如果他们建造墓冢”这样的条件，向数人一并设定时，只有对所有人同时成就，条件才能成立。

<!-- source-p 417 -->
<a id="35.1.112.1"></a>**1.**又如：“若提提乌斯向辛福洛与雅努阿里乌斯给付一百，我将庄园遗赠给他。”辛福洛死亡后，遗赠是否失效？我认为，也应将此解释为：提提乌斯须在他们各自仍在世时给付。不过，依宽厚解释，如果辛福洛并非在提提乌斯迟延之后才死亡，那么提提乌斯向雅努阿里乌斯给付一半款项，作为受遗赠人也应取得庄园的一半。

<!-- source-p 418 -->
<a id="35.1.112.2"></a>**2.**又有人问：土地遗赠给数人，条件是他们交付确定数额的钱，用于丧葬以及将遗体运往另一地区的费用。〔底本此处连写为 *dedissententiarum*，文字有讹疑。〕如果不是两人都给付，任何一人都不得取得遗赠，因为条件不能由一人单独履行。但我们通常作较宽厚的解释：若土地遗赠给两人，条件是他们给付十，其中一人给付时，也应由其取得遗赠土地的一半。

<!-- source-p 419 -->
<a id="35.1.112.3"></a>**3.**普里斯库斯答复说，附条件获释的奴隶不必一定在家父去世之地、自己被遗留之地或自己所选择之地交代账目；他应当前往必须向其交代账目的人那里，尤其是在该人因公事离开的情况下。确切地说，每次均应结合相关人物与地点分别判断。
