# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.41"></a>3.3.41　保罗《评告示》第九卷

经审查具体情由后，有时允许妇女代父母起诉；例如父母因疾病或年老受阻，且没有其他人可以代为起诉时。

### <a id="3.3.42"></a>3.3.42　保罗《评告示》第八卷

<a id="3.3.42.pr."></a>**序言。** 虽然不得在公益诉讼中指定代理人，但已有规则认为，若有人因禁止通行而遭受私人损害，并就公共道路事项提起诉讼，则其可以像在私人诉讼中那样指定代理人。更进一步，对违反墓地规定之诉而言，与该事项有利害关系的人也可以指定代理人。

<a id="3.3.42.1"></a>**1.** 依《科尔内利亚侵辱法》提起侵辱之诉，可以指定代理人；因为尽管该诉讼是为公共利益而进行，它仍属于私人诉讼。

<a id="3.3.42.2"></a>**2.** 本人与代理人之间通常存在的关系，会产生委任之诉。但有时并未成立委任之诉所依据的法律关系。例如，我们指定代理人使其为自身利益行事，并以该身份承诺提供判决清偿担保；若我们依此承诺支付了款项，提起的就不是委任之诉，而是：如果我们出售的是遗产，则提起买卖之诉；或者依其原先存在的法律关系提起诉讼，例如保证人指定主债务人为代理人的情形。

<a id="3.3.42.3"></a>**3.** 依特雷贝利亚努斯元老院决议受返还遗产者，依法可以指定继承人为代理人。

<a id="3.3.42.4"></a>**4.** 对质物享有权利的债权人，也可以适当地指定质物所有人为代理人，以提起塞尔维亚诉讼。

<a id="3.3.42.5"></a>**5.** 如果向共同债权人之一作出定期给付承诺，而该债权人又就约定款项指定另一人为代理人，我们不否认其可以这样做。共同承担要式承诺债务的两人之一，也可以指定另一人为代理人代为辩护。

<a id="3.3.42.6"></a>**6.** 若有数名继承人，且提起遗产分割之诉或共有物分割之诉，不得允许他们指定同一代理人，因为在裁定财产归属及判令给付时，案件无法妥善解决。但如果一名共同继承人有数名继承人，则当然可以允许他们指定同一代理人。

<a id="3.3.42.7"></a>**7.** 被告在争讼程序确定后藏匿不出时，只有在以下情形下，才视为其保证人已经代为辩护：保证人中有一人承担全部辩护责任；或者全体保证人共同辩护；或者其中一些保证人共同指定一名代理人，由该代理人承受诉讼。
