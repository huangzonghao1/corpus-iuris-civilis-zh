# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.61"></a>3.3.61　保罗《评普劳提乌斯》第三卷

普劳提乌斯说，代理人受判决后，不得再向其提起诉讼；但代理人是为自身利益受任，或者明知未提供担保仍主动承担诉讼的，除外。大家一致认为，辩护人虽已提供担保但仍以自身名义承担诉讼的，也适用同一规则。

### <a id="3.3.62"></a>3.3.62　庞波尼乌斯《评普劳提乌斯》第二卷

为请求遗赠而受任的代理人，若以令状请求继承人出示遗嘱文书，继承人不得以代理人身份抗辩，称该代理人并未获委任处理此事。

### <a id="3.3.63"></a>3.3.63　莫德斯汀《辨异集》第六卷

受委托管理全部财产的代理人，未经委托人特别授权，不得处分委托人的动产、不动产或奴隶；但果实及其他容易腐坏的物品除外。

### <a id="3.3.64"></a>3.3.64　莫德斯汀《规则集》第三卷

某人曾由他人出任辩护人；若在诉讼正式受理前，他本人到场并请求以本人名义接受诉讼，经审查具体情由后，应当听取其请求。

### <a id="3.3.65"></a>3.3.65　莫德斯汀《论法学发现》单卷

如果委托人希望免除不在场代理人提供担保的义务，应向对方寄送亲笔书信，说明指定了谁担任其代理人以及代理事项为何，并声明自己将追认与该代理人进行的一切行为。此种情形下，若对方认可其书信，代理人即视为委托人在场而参加诉讼。因此，即使委托人后来改变主意、不再愿意让此人担任代理人，代理人此前以代理人身份进行的诉讼仍应视为已获追认。

### <a id="3.3.66"></a>3.3.66　帕皮尼安《问题集》第九卷

某人作出要式承诺，约定给付斯提库斯或达马之一，具体由承诺人择定；若该人追认提提乌斯以代理人名义就其中一人提出的请求，则视为该事项已经进入诉讼程序，并使该项要式承诺消灭。

### <a id="3.3.67"></a>3.3.67　帕皮尼安《答复集》第二卷

代理人就其出售的土地不被追夺而承担担保责任后，即使停止管理委托人的事务，也不得请求裁判官免除其义务；代理人既已代委托人承担债务约束，就不能徒然拒绝该项负担。

### <a id="3.3.68"></a>3.3.68　帕皮尼安《答复集》第三卷

代理人在不违背委任的情况下，就委托人事务作出要式承诺后，委托人不得违背代理人的意愿请求该项给付。
