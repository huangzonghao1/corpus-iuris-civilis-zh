# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.8"></a>3.3.8　乌尔比安《评告示》第八卷

<a id="3.3.8.pr."></a>**序言。** 受家父权支配的家子，如果本人享有某项诉权，也可以指定代理人代为起诉；这不仅适用于拥有军役特有产的家子，也适用于任何家子。例如，家子遭受侵辱，可以为提起侵辱之诉指定代理人；假如父亲不在场，且父亲的代理人不愿起诉，家子本人依法可以指定代理人。此外，尤利安还记载：如果家子因仍处于同一父权之下的儿子而遭受侵辱，而祖父不在场，父亲可以指定代理人，为缺席的孙子追究其所受侵辱。家子也可以指定代理人代为应诉。家女同样可以为提起侵辱之诉指定代理人。至于家女与父亲共同指定代理人追索嫁资一事，瓦莱里乌斯·塞维鲁写道，此举多余，因为只要父亲依家女的意愿指定代理人即可。不过，我认为，若父亲不在场或品行可疑——在这些情形下，家女通常有权自行提起嫁资之诉——家女可以指定代理人。家子本人也可以被指定为代理人，代为起诉或应诉。

<a id="3.3.8.1"></a>**1.** 通常不得指定不愿担任代理人的人。所谓“不愿”，不仅指明确表示反对的人，也包括无法证明其已经同意的人。

<a id="3.3.8.2"></a>**2.** 退伍军人可以担任代理人；现役军人则不得被指定为代理人，即使对方愿意也不例外。但如果在争讼程序确定时，因某种原因未提出这一障碍，则属例外。为自身利益受任的代理人，以及代表其所属编制单位全体追究或承接共同事务的人，也不在此限；此类代理人依法获准担任代理人。
