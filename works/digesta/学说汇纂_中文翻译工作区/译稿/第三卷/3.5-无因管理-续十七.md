# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.34"></a>3.5.34　斯凯沃拉《疑问集》第一卷

<a id="3.5.34.pr."></a>**序言（pr.）** 离婚后，丈夫管理妻子的事务；嫁资不仅可以通过嫁资之诉予以追回，也可以通过无因管理之诉予以追回。但这以丈夫管理事务期间有能力返还嫁资为前提；否则，不能因他没有向自己追讨而归责于他。即使他后来丧失了全部财产，无因管理之诉仍可完整提起；不过，如果丈夫被依嫁资之诉起诉，则应判其免责。对此仍须设定一定限度：即使丈夫后来失去财产，也只在他当时有能力支付的范围内，才可提出请求。丈夫没有立即变卖自己的财物以换取现金，并不表示他立刻违反了职责；必须经过一段时间，足以显示他曾拖延不履行。若他尚未履行职责，财产便在此期间灭失，则他不依无因管理之诉承担责任，犹如他从未有能力履行一样。反之，如果丈夫目前仍有能力支付，也可以提起无因管理之诉，因为存在他可能丧失清偿能力的风险。

<a id="3.5.34.1"></a>**1.** 我们认为，管理债务人事务的人，如果该债务人仍欠其款项，且没有其他财物可用于清偿，就不负有返还质物的责任。

<a id="3.5.34.2"></a>**2.** 解除买卖之诉不属于无因管理之诉的范围；因此，经过六个月后，该解除买卖之诉即告消灭。例如，管理人在买受人的财物中没有找到该奴隶；或者虽已找到该奴隶，却没有找到或收回以添附名义增加的财物、该奴隶状况恶化所导致的价值差额，或经由该奴隶取得但并非以买受人财物取得的财物；并且，在其所管理的买受人事务中，也没有可供其当下取回的财物。

<a id="3.5.34.3"></a>**3.** 但是，如果某人因其他永久性债务而负有债务，且其本人富有，那么，不应因其未清偿而归责于他；尤其是在利息方面也没有引起争议时。作为债务人的监护人则属不同情形，因为在该情形下，先前债务是否清偿，会影响其是否依监护之诉承担责任。
