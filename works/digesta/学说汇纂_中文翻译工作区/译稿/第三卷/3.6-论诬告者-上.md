# 第三卷

## <a id="3.6"></a>3.6　论诬告者

### <a id="3.6.1"></a>3.6.1　乌尔比安《评告示》第十卷

<a id="3.6.1.pr."></a>**序言（pr.）** 对于被指称为收受钱财、以恶意诉讼为目的而提起或不提起某项诉讼的人，收款后一年内可提起事实诉讼，请求四倍于其所收款项；一年后，则可提起单倍额的事实诉讼。

<a id="3.6.1.1"></a>**1.** 庞波尼乌斯写道，这项诉讼不仅适用于财产案件，也适用于公诉案件；尤其是，根据《勒索公款法》，凡以恶意方式收受钱财，以便提起或不提起某项诉讼者，亦须承担责任。

<a id="3.6.1.2"></a>**2.** 收受钱财的人，无论是在诉讼受理之前还是之后收受，均须承担责任。

<a id="3.6.1.3"></a>**3.** 我们的皇帝曾致函卡西乌斯·萨比努斯作出敕令，禁止在公诉、私诉或财政诉讼中向法官或对方给付钱财，并命令该诉讼因此失效。问题是：如果对方收款并非出于恶意诉讼，而是为了和解，该敕令是否不适用？我认为，应与本项事实诉讼同样，不予适用；因为被禁止的不是和解，而是卑劣的敲诈勒索。

<a id="3.6.1.4"></a>**4.** 所谓收受钱财，即使实际收受的是其他物品，也属于收受钱财。

### <a id="3.6.2"></a>3.6.2　保罗《评告示》第十卷

即使有人因而免除了债务，也可视为其已取得利益；无偿取得资金使用权，或以低于合理价值出租、出售物品，也同样如此。至于他是亲自收受钱财、指示他人代为收受，还是以自己名义追认他人所收款项，并无区别。

### <a id="3.6.3"></a>3.6.3　乌尔比安《评告示》第十卷

<a id="3.6.3.pr."></a>**序言（pr.）** 总而言之，只要有人因此取得任何利益，无论利益来自对方还是任何其他人，均作相同处理。

<a id="3.6.3.1"></a>**1.** 如果有人收钱以便提起诉讼，那么无论他后来是否提起诉讼，均须承担责任；如果有人收钱以便不提起诉讼，即使他后来仍然提起，也须承担责任。

<a id="3.6.3.2"></a>**2.** 依本告示，即使是以不正当方式达成和解的人，也须承担责任；所谓“以不正当方式达成和解”，就是以卑劣手段订立协议。

<a id="3.6.3.3"></a>**3.** 应当注意，支付钱财以使他人对自己提起诉讼的人，不能自行请求返还，因为其行为本身不正当；但应将请求权授予因而遭受恶意诉讼之人。由此，如果某人既从你处收钱以便对我提起诉讼，又从我处收钱以便不对我提起诉讼，那么，他须依两项诉讼对我承担责任。

### <a id="3.6.4"></a>3.6.4　盖尤斯《评行省告示》第四卷

这项诉讼不由继承人享有，因为继承人能够请求返还死者所支付的钱款，这已足够。
