# 第三卷

## 3.2　论被标记为不名誉者（续）

### 3.2.2　乌尔比安《评告示》第六卷（续）

<a id="3.2.2.3"></a>**3.** 因《朱利亚通奸法》被判罪的军人，属于不名誉者；其判决本身即使其因不名誉事由解除军人誓约。

<a id="3.2.2.4"></a>**4.** 因不名誉事由退伍的人，不得居住在罗马城，也不得居住在皇帝所在的任何其他地方。

<a id="3.2.2.5"></a>**5.** 裁判官说：“登台者，属于不名誉者。”依拉贝奥的定义，所谓舞台，是为了举行竞技，在任何地点搭设的场所；无论该地点在公共场所、私人场所还是街巷，只要有人在那里站立、移动并将自己展示给观众观看，即属舞台；但该地点必须允许公众为观看表演而自由进入。佩加苏斯与内尔瓦之子答复说，为谋利而参加竞赛的人，以及所有为获取奖赏而登台表演的人，均属于不名誉者。

### <a id="3.2.3"></a>3.2.3　盖尤斯《评行省告示》第一卷

某人虽出租自己的劳务，意图以舞台表演者身份登台，却最终没有登台的，不会因此被标记为不名誉者；因为此事尚未恶劣到连其意图也应受惩罚的程度。

### <a id="3.2.4"></a>3.2.4　乌尔比安《评告示》第六卷

<a id="3.2.4.pr."></a>**序言。** 萨宾努斯与卡西乌斯答复说，运动员所从事的并非舞台表演职业；他们这样做是为了展示勇武。通常的见解也大体如此。将竞技庆典中的合唱、音乐或其他表演人员（*thymelici*）、在竞技场或体育场竞技的运动员（*xystici*）、战车御者、向赛马洒水的人，以及为神圣竞技活动服务的其他辅助人员，一概不视为不名誉者，也被认为是适当的。

<a id="3.2.4.1"></a>**1.** 塞尔苏斯认为，负责安排或主持竞技的人——希腊人称之为 *brabeutae*——并不从事舞台表演职业，因为他们从事的是辅助事务，而非舞台表演职业。况且，如今元首授予这一职位，实为不小的恩遇。

<a id="3.2.4.2"></a>**2.** 裁判官说：“从事拉皮条者。”凡以营利为目的持有奴隶、使其卖淫的人，即属从事拉皮条；在自由人身上经营此种营利活动者，也处于同一情形。无论此人以此为主要生意，还是将其附加于其他营业——例如，客栈经营者或马厩经营者雇有此类奴隶供人役使，又使其借服务之机营利；或者浴场经营者像某些行省的做法那样，雇用这类奴隶在浴场看管衣物，同时在其经营场所从事此类活动——均应承担拉皮条行为的处罚。

<a id="3.2.4.3"></a>**3.** 庞波尼乌斯还说，某人在仍为奴隶时曾将属于其特有财产的奴隶用于卖淫的，即使后来获得自由，仍应被标记为不名誉者。

<a id="3.2.4.4"></a>**4.** 诬告者只有在因诬告而被判罪时，才会被标记为不名誉者；仅仅实施了诬告还不够。串通妨碍追诉者亦同。所谓串通妨碍追诉者，近似于反复变换立场的人：他背弃己方诉讼，转而帮助对方。拉贝奥说，这一名称源自“交替争辩”；因为实施此行为的人站在双方一边，甚至站在对方一边。

<a id="3.2.4.5"></a>**5.** 同样，凡以本人名义因盗窃、暴力劫夺财物、侵辱或恶意欺诈而被判罪，或者与对方和解者，也属于不名誉者，

### <a id="3.2.5"></a>3.2.5　保罗《评告示》第五卷

因为与对方和解者，被视为承认了犯罪。
