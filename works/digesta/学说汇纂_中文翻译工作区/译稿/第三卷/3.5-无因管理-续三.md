# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.5"></a>3.5.5　乌尔比安《评告示》第十卷

<a id="3.5.5.pr."></a>**序言（pr.）** 同样，如果我误以为你已委托我，却仍管理了事务，在委任之诉不适用时，也会产生无因管理之诉。即使我误以为你已委任我，而替你提供保证，也适用同一规则。

<a id="3.5.5.1"></a>**1.** 如果我误以为事务属于提提乌斯，实际上却属于塞姆普罗尼乌斯，并管理了这些事务，则只有塞姆普罗尼乌斯对我负无因管理之诉的责任。

<a id="3.5.5.2"></a>**2.** 尤利安在《学说汇纂》第三卷中写道：如果我管理了你所监护的未成年人的事务，并非受你委任，而是为了避免你承担监护之诉的责任，那么你应依无因管理之诉对我负责；该未成年人本人也可能承担责任，但仅限于其因此而增加的财产利益。

<a id="3.5.5.3"></a>**3.** 同样，如果我出于为你办事的考虑，将借款交给你的代理人，以便他清偿你的债权人或解除你的质押，我可以对你提起无因管理之诉，但不能对与我订立借贷关系的代理人提起诉讼。如果我还从你的代理人处取得要式承诺，可以认为我对你仍保有无因管理之诉，因为我只是额外加入了该项要式承诺。

<a id="3.5.5.4"></a>**4.** 如果某人收受金钱或其他物品，受托将其交付给我，那么他管理了我的事务，我可以对其提起无因管理之诉。
