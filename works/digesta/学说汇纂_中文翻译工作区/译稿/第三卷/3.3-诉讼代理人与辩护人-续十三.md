# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.46"></a>3.3.46　盖尤斯《评行省告示》第三卷

<a id="3.3.46.pr."></a>**序言。** 某人以本人名义接受了诉讼，后来希望指定代理人、由原告将诉讼移转给该代理人的，应予准许；但须依通常方式提供判决清偿担保。

<a id="3.3.46.1"></a>**1.** 为他人辩护、但并非以该他人名义提起诉讼的人，可以自由选择只就某一事项提供辩护。

<a id="3.3.46.2"></a>**2.** 为他人辩护的人必须提供担保；因为未经担保，任何人都不得视为有能力为他人诉讼提供充分辩护。

<a id="3.3.46.3"></a>**3.** 有人问：辩护人已经接受诉讼，而原告后来获准恢复原状时，是否应强制辩护人接受恢复原状后的诉讼？较可取的意见是，应当强制。

<a id="3.3.46.4"></a>**4.** 代理人依诚信原则管理其他事务，也应以同样方式处理诉讼事务。因此，他在诉讼中取得的一切，无论是直接取得诉讼标的，还是因该诉讼附带取得其他利益，都应通过委任之诉返还。即使他因错误或法官不公而取得了本不应取得之物，也必须返还。

<a id="3.3.46.5"></a>**5.** 反过来，代理人因判决而支付的款项，应通过反向委任之诉请求返还；但其因自身不法行为而支付的罚金，不得请求返还。

<a id="3.3.46.6"></a>**6.** 无论是原告一方还是被告一方的代理人，凡其基于诚信而支出的诉讼费用，均应予返还；衡平原则要求如此。

<a id="3.3.46.7"></a>**7.** 若有两人受委任管理事务，其中一人又是委托人的债务人，另一人能否对其提起诉讼？当然可以；被起诉之人也担任代理人，并不使起诉者失去代理人身份。

### <a id="3.3.47"></a>3.3.47　尤利安《评乌尔塞乌斯·费罗克斯》第四卷

某人指定两名代理人管理其全部事务，若未明确指示其中一人向另一人追索款项，就不得认为他曾委任任何一人向另一人追债。

### <a id="3.3.48"></a>3.3.48　盖尤斯《评行省告示》第三卷

因此，只有在特别作出此项委任时，被告才能提出抗辩说：“委托人并未授权我向债务人追讨。”原告则应以再抗辩回应：“或者，委托人已授权我向你追讨。”

### <a id="3.3.49"></a>3.3.49　保罗《评告示》第五十四卷

不得因代理人的行为而使不知情委托人的法律地位恶化。

### <a id="3.3.50"></a>3.3.50　盖尤斯《评行省告示》第二十二卷

无论你的代理人以何种方式使我免责，该免责都应对你有利。
