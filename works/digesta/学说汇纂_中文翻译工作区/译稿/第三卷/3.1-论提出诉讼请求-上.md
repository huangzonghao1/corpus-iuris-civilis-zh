# 第三卷

## <a id="3.1"></a>3.1　论提出诉讼请求

### <a id="3.1.1"></a>3.1.1　乌尔比安《评告示》第六卷

<a id="3.1.1.pr."></a>**序言。** 裁判官提出本题，一方面是为了使自己的职责得到妥当履行，另一方面是为了维护其尊严与体面，避免任何人不加甄别地在其面前提出请求。

<a id="3.1.1.1"></a>**1.** 因此，他设定了三类人：有些人完全不得提出请求；有些人只准为自己提出请求；另一些人则可以为自己以及特定的人提出请求。

<a id="3.1.1.2"></a>**2.** 所谓提出请求，是指在司法程序中，向主持司法管辖权的人陈述自己或朋友的请求；也包括反对他人的请求。

<a id="3.1.1.3"></a>**3.** 裁判官首先规定了完全不得提出请求的人。在这项告示中，他以年龄或身体状况作为免责事由。就年龄而言，裁判官禁止未满十七岁的人提出请求，因为他认为这个年龄足以在公众场合出面活动。也有人记载，内尔瓦之子年长几岁时，已经公开回答法律问题。就身体状况而言，裁判官禁止完全听不见的人在其面前提出请求；因为不得允许无法听见裁判官命令的人提出请求，这对其本人也会造成危险：他若没有听见裁判官的命令，就可能被视为不服从命令，并以藐视诉讼命令者的身份受罚。

<a id="3.1.1.4"></a>**4.** 裁判官规定：“如果他们没有诉讼辩护人，我将为他们指定。”裁判官通常不仅向上述人员提供这种照顾，也向其他因特定事由——例如对方施加势力或令其心生畏惧——而找不到保护人或辩护人的人提供帮助。

<a id="3.1.1.5"></a>**5.** 告示接着规定了不得为他人提出请求的第二类人员。裁判官在此告示中将性别和身体状况列为例外事由，也将若干因不名誉行为而受污名者列入禁止范围。就性别而言，裁判官禁止妇女为他人提出请求。禁止的理由是：妇女不应违背与其性别相称的贞洁规范，介入他人的诉讼事务，也不应从事属于男性的职务。此项规则起源于卡尔法尼娅——一个极其恶劣的妇女；她无耻地提出请求并扰乱裁判官，因而促使裁判官制定了该告示。

就身体状况而言，裁判官拒绝双目失明者为他人提出请求，因为此人不能看见并尊重官职人员的标志。拉贝奥还记载，盲人普布利乌斯——阿斯普雷纳斯·诺尼乌斯之父——曾想提出请求，却被布鲁图斯转开座椅而拒绝。尽管盲人不得为他人提出请求，他仍保有元老身份，也可以担任裁判者。那么，他是否也可以担任官职？此事尚待考察。确有盲人担任官职的先例：例如阿庇乌斯·克劳狄乌斯·凯库斯参与公共议事，并曾在元老院就皮洛士的俘虏提出极为严厉的意见。但是，较妥当的说法是：已经开始担任的官职可以继续履行，但应完全禁止其谋求新的官职；许多实例都支持这一看法。〔译注：底本在 *melius* 后附有引号括出的“milius”，疑为误植。〕


<a id="3.1.1.6"></a>**6.** 裁判官还禁止下列人为他人提出请求：其本人曾遭受被视为女性化的性行为者。但是，如果某人是被强盗或敌人以暴力侵害，不应因此受到污名，庞波尼乌斯也如此认为。被判处死刑者，也不得为他人提出请求。此外，依元老院决议，因诬告公共刑事案件而被定罪者，即使在基层裁判官面前，也不得为他人提出请求。凡出租自己的劳务、以便与野兽搏斗者，也在禁止之列。这里所谓野兽，应以其凶猛程度判断，而非仅看动物种类；例如，如果是狮子但性情温顺，或者是其他有牙齿但已驯服的动物呢？因此，只要某人出租了自己的劳务，无论他是否实际搏斗，均会受污名；反之，如果他没有出租劳务，即使实际搏斗，也不承担此项责任。因为受处罚的不是与野兽搏斗的人，而是为此出租劳务的人。古人说，为展示勇气而无偿这样做的人不受处罚；但如果他在竞技场中允许自己因而获得荣誉，我认为他就不能逃避污名。如果某人出租自己的劳务，在竞技场之外捕猎野兽，或者搏斗会危害该地区的野兽，则不受污名。因此，对那些并非为了展示勇气而与野兽搏斗的人，裁判官允许他们为自己提出请求，但禁止他们为他人提出请求。不过，若此类人员担任监护或保佐职务，允许其为受其监护或保佐的人提出请求，最为公平。凡被发现违反上述规定者，不仅不得再为他人提出请求，还应依裁判者的估定，受非常程序的金钱处罚。

<a id="3.1.1.7"></a>**7.** 如本题开头所述，裁判官将不得提出请求者分为三类；这里所说的是第三类。对于此类人员，裁判官并未完全剥夺其提出请求的资格，而只是禁止其为所有人提出请求；这是因为他们的过错似乎轻于前两类中被列举的人。
