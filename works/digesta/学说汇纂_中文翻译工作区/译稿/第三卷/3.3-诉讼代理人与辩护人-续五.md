# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.28"></a>3.3.28　乌尔比安《论争议》第一卷

如果我的代理人接受了判决清偿担保，我可以取得基于要式承诺的准诉权，正如我也获准提起判决之诉一样。即使我的代理人未经我同意，仍依据该担保提起诉讼，我本人仍会取得基于要式承诺的诉权。因此，我的代理人依据要式承诺起诉时，应以抗辩阻却；正如他若提起判决之诉，但并非为自身利益受任，且未获授权处理该事项，也应以抗辩阻却。反之，如果我的代理人为判决清偿提供了担保，则不得依据要式承诺对我提起诉讼。我的诉讼辩护人提供担保时亦同，因为也不得对我本人提起判决之诉。

### <a id="3.3.29"></a>3.3.29　乌尔比安《评告示》第九卷

如果原告宁愿起诉委托人，而不愿起诉为自身利益受任的代理人，应当说原告有此权利。

### <a id="3.3.30"></a>3.3.30　保罗《判例集》第一卷

原告的代理人若并非为自身利益受任，可以因其在诉讼中支出的费用，请求从判决所确定的给付中获得清偿，前提是诉讼委托人无清偿能力。

### <a id="3.3.31"></a>3.3.31　乌尔比安《评告示》第九卷

<a id="3.3.31.pr."></a>**序言。** 某人以诉讼代理人的身份被判罪后，成为诉讼委托人的继承人时，不得正当地拒绝履行判决之诉所请求的义务；但以其继承全部遗产为限。若其仅为部分继承人，却清偿了全部债务：如果他受委任承担该项清偿，可以依据委任之诉向共同继承人追偿；如果未获委任，则可以提起无因管理之诉。即使他并非继承人，只是代为清偿，也适用同一规则。

<a id="3.3.31.1"></a>**1.** 不禁止为同一诉讼中的数人指定多名代理人。

<a id="3.3.31.2"></a>**2.** 尤利安说，某人先后在不同时间指定了两名代理人的，后来指定代理人，应视为已经排除先前指定的代理人。

### <a id="3.3.32"></a>3.3.32　保罗《评告示》第八卷

若同时为多人指定数名代理人，并使每人均有权请求全部给付，则先行起诉者处于较有利地位；后来的代理人不得就先前代理人已经请求的部分再行起诉。
