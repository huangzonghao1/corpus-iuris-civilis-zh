# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（终）

### <a id="3.3.69"></a>3.3.69　保罗《答复集》第三卷

保罗答复说，即使某人已经为接受诉讼而指定代理人，也不妨碍其本人亲自处理自己的案件。

### <a id="3.3.70"></a>3.3.70　塞克斯图斯·凯基利乌斯·斯凯沃拉《答复集》第一卷

父亲为自己的未成年儿子指定债权人塞姆普罗尼乌斯担任监护人。塞姆普罗尼乌斯管理完监护事务后，指定自己的兄弟为继承人；其兄弟也已去世，并以遗嘱信托方式将对债务人的债权遗留给提提乌斯，继承人又将相关诉权委任给提提乌斯。我询问：既然监护之诉和借款债权之诉都源自塞姆普罗尼乌斯的遗产，是否只有在提提乌斯为委任其诉权的继承人辩护时，才应向其授予受委任的诉权？答复：他应当为继承人辩护。

### <a id="3.3.71"></a>3.3.71　保罗《判例集》第一卷

不在场的被告可以通过代理人说明其缺席理由。

### <a id="3.3.72"></a>3.3.72　保罗《手册集》第一卷

我们并非总是通过代理人取得诉权；有时只是保全诉权。例如，在法定期间内向被告起诉；又如阻止新工程施工，使我们得以援用《暴力或秘密实施》令状。因为在后一情形中，代理人也只是为我们保全既有权利。

### <a id="3.3.73"></a>3.3.73　保罗《论司法顾问职务》单卷

如果被告愿在诉讼正式受理前支付款项，而代理人正在起诉，应当如何处理？强迫被告接受诉讼并不公平。因此，如果委托人在场而代理人没有提出付款，被告是否会因此显得可疑？如果他当时没有支付能力，又应如何处理：是否仍应强制其接受诉讼？如果该诉讼还会导致不名誉污名呢？可以确定的是，在诉讼正式受理前，行省总督应命令将款项存入神庙；处理未成年人款项时也采用这一做法。诉讼正式受理后，这些问题均应由法官依职权处理。

### <a id="3.3.74"></a>3.3.74　乌尔比安《意见集》第四卷

城市的代理人也不得通过诉讼代理人处理公共事务。

### <a id="3.3.75"></a>3.3.75　尤利安《学说汇纂》第三卷

某人代不在场的买受人——该买受人同时占有土地——进行辩护，并以买受人名义接受诉讼；随后，他要求土地出卖人代为辩护。出卖人要求对方提供担保，保证买受人将追认相关行为。我认为，代理人应向出卖人提供追认担保；因为如果他将土地返还给原告，买受人仍可请求返还该物，出卖人也就可能再次被迫为其辩护。

### <a id="3.3.76"></a>3.3.76　尤利安《评米尼基乌斯》第五卷

提提乌斯代不在场的被告进行辩护并提供担保；在其接受诉讼之前，被告已陷入无清偿能力。于是，辩护人拒绝该诉讼由自己承受。我询问：是否应当允许其这样做？尤利安答复：辩护人既已提供担保，就应视同委托人。如果裁判官不强制其接受诉讼，也无法给他多少救济，因为原告可以转而向其保证人追偿，而保证人无论履行了什么，都将向该辩护人追偿。

### <a id="3.3.77"></a>3.3.77　保罗《评告示》第五十七卷

凡由他人代为辩护者，均应依善良人的判断获得辩护。

### <a id="3.3.78"></a>3.3.78　阿非利卡努斯《问题集》第六卷

<a id="3.3.78.pr."></a>**序言。** 因此，若有人以拖延原告的方式，使争议无法得到最终解决，就不得认为他已依善良人的判断履行了辩护义务。

<a id="3.3.78.1"></a>**1.** 代理人受委任请求两项标的，却只请求其中一项的，不会因此被抗辩排除；他仍可将该项标的提交诉讼审理。
