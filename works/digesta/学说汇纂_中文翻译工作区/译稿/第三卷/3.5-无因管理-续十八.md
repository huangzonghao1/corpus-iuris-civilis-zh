# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.35"></a>3.5.35　保罗《疑问集》第四卷

如果一名自由人基于善意在我这里服役，借入款项并将其用于我的事务，那么，我应依何种诉讼返还其用于我们事务的款项，尚须考察；因为他处理这项事务，并非像朋友那样，而是像奴隶主的事务管理人那样。但应准许无因管理之诉；如果我已经向其债权人清偿，该诉权即告消灭。

### <a id="3.5.36"></a>3.5.36　保罗《判决集》第一卷

<a id="3.5.36.pr."></a>**序言（pr.）** 通常应在争讼程序确定时考察：未获监护人授权而有人管理某受监护未成年人的事务，该未成年人是否因此变得更加富有，以致其可因该事项而被起诉。

<a id="3.5.36.1"></a>**1.** 如果有人管理他人的资金事务，就必须支付利息，并承担其本人所订立债权的风险；但若债务人因意外事故丧失了资力，以致在该诉讼成立时已无清偿能力，则属例外〔原文疑误〕。

<a id="3.5.36.2"></a>**2.** 如果父亲管理了赠与已脱离其家父权之子的财物，应依无因管理之诉对儿子承担责任。

### <a id="3.5.37"></a>3.5.37　特里丰尼努斯《论争集》第二卷

一名不负利息债务的人管理了其债权人的事务。问题是，他是否应依无因管理之诉，就该笔债务支付利息？我认为，如果他本应向自己追讨，就应当支付利息；但如果在其管理事务期间，债务尚未到期，则不应支付利息。到期日经过后，如果他没有将自己所欠的款项记入其所管理的债权人账目，那么，依诚信诉讼，他理应支付利息。但应支付何种利息？是债权人通常向其他人收取的利率，还是最高利率？因为如果有人擅自将其管理或监护之人的钱款挪作己用，或者市镇官员将公款用于私用，就须支付最高利率；神圣皇帝们已对此作出规定。不过，此人与上述情形不同：他并非从管理事务中取出钱款，而是在开始管理事务之前从朋友处借款。前述人负有无偿、完整且不谋取任何利益的诚信义务；他们看似滥用权限，因而被施以最高利率，作为某种惩罚。此人则有正当理由向他人借款；他应因未清偿而承担利息责任，而非因将管理事务中的钱款据为己有而受罚。至于债务是现在才发生，还是此前已存在，区别重大：其结果足以使原本不生利息的债务开始生息。

### <a id="3.5.38"></a>3.5.38　盖尤斯《论口头债务》第三卷

任何人替他人清偿债务，即使该人不知情或不愿意，也能使其获得免责；但他人对某人享有的债权，未经该债权人同意，不能由另一人依法强行收取。自然法理与市民法理共同认可：我们可以改善他人的处境，即使该人不知情或不愿意；却不能使其处境恶化。
