# 第三卷

## 3.6　论诬告者（续）

### <a id="3.6.5"></a>3.6.5　乌尔比安《评告示》第十卷

<a id="3.6.5.pr."></a>**序言（pr.）** 对继承人提起该诉时，仅限于其实际取得的利益。因为已有规定：尽管犯罪本身因行为人死亡而消灭，卑劣所得仍可向其继承人追索。例如，为伪造文书或为使法官作出偏袒性判决而支付的钱财，以及通过其他犯罪所得的一切利益，均可向继承人追索。

<a id="3.6.5.1"></a>**1.** 除本项诉讼外，如果只有收款人一方行为不正当，也可以提起返还之诉；如果付款人一方也有不正当行为，占有人的法律地位则较优。问题是：若已提起返还之诉，本项诉讼是否因此排除，还是应当将本项诉讼定为三倍额？又或者，如同对窃贼那样，既准许四倍额诉讼，也准许返还之诉？我认为，两种诉讼中择一提起即已足够。若可以提起返还之诉，则一年后无须再准许事实诉讼。

### <a id="3.6.6"></a>3.6.6　盖尤斯《评行省告示》第四卷

对于支付钱财、以避免他人对自己起诉之人，一年期间自其付款之日起计算，但须以当时他有机会提起诉讼为前提。至于另一人支付钱财、以便对其提起诉讼的人，一年究竟自付款之日还是自其知悉付款之日起计算，存在疑问；因为不知情者似乎没有机会起诉。较妥当的见解是，自其知悉付款之日起计算一年。

### <a id="3.6.7"></a>3.6.7　保罗《评告示》第十卷

<a id="3.6.7.pr."></a>**序言（pr.）** 如果某人从他人处收钱，以便不对我提起诉讼，而该钱是依我的委任支付的，或者由我的事务总代理人支付，或者由原本打算管理我事务之人支付且我已予追认，那么，应视为该钱由我支付。反之，如果他人未经我的委任，虽出于怜悯而支付钱财以使诉讼不发生，而我又未追认，那么，付款人本人可以请求返还，我也可以提起四倍额诉讼。

<a id="3.6.7.1"></a>**1.** 如果有人收钱，以便对家子提起诉讼，也应准许对其家父提起诉讼〔底本在 *et* 处加引号，疑为校勘标记〕。同样，如果家子收钱以便提起或不提起诉讼，则应对该家子本人准许诉讼；如果他人未经我的委任，向该家子付款以使诉讼不发生，那么，付款人也可以请求返还，而我可以提起四倍额诉讼。

<a id="3.6.7.2"></a>**2.** 如果税务承包人扣留奴隶，并收受了本不应支付的钱款，他本人也须依本告示这一部分所规定的事实诉讼承担责任。

### <a id="3.6.8"></a>3.6.8　乌尔比安《意见集》第四卷

如果有人以某种罪名为借口，从无辜者处收取钱财，而该罪名并未得到证明，且对该事享有审判权的人获悉此情，那么，他应依有关收钱以提起或不提起诉讼者的告示，命令返还非法勒取的钱财，并按行为人的不法程度对其施加处罚。

### <a id="3.6.9"></a>3.6.9　帕比尼安《论通奸罪》第二卷

如果有人控告一名奴隶并请求对其施以拷问，则应对该奴隶进行拷问；该奴隶被判无罪后，控告人应被判向奴隶主人支付双倍价款。但除价额赔偿外，还须另行审查控告人是否构成诬告。因为诬告罪与因拷问奴隶而给其主人造成的损害，是彼此独立的。
