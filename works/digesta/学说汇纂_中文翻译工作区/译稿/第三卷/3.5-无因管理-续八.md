# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.9"></a>3.5.9　乌尔比安《评告示》第十卷

<a id="3.5.9.pr."></a>**序言（pr.）** 那么，我是否也有权请求偿还自己所支出的费用？我认为有此诉权，除非双方曾特别约定，彼此均不得对对方提起诉讼。

<a id="3.5.9.1"></a>**1.** 提起无因管理之诉的人，并非只有在其所管理的事务已经产生结果时才能使用该诉；只要其管理有利，即使事务未能产生结果，也已足够。因此，如果他修缮一栋公寓楼，或照料一名患病的奴隶，即使公寓楼后来被烧毁，或奴隶后来死亡，他仍可提起无因管理之诉；拉贝奥也赞同这一点。不过，如塞尔苏斯所述，普罗库鲁斯在评注中指出，并非任何情形都应准许该诉。假如他修缮的那栋公寓楼，房主认为其不值得这笔费用而已弃置，或者房主认为并无修缮必要，又该如何？依拉贝奥的意见，这会使房主承担负担；然而，任何人都可以因尚未发生的损害风险而放弃某物。塞尔苏斯巧妙地驳斥了这一意见：他说，只有有利地管理事务的人才享有无因管理之诉；承担一项不必要的事务，或着手处理将给家父造成负担的事务，并非有利地管理事务。与此相近，尤利安写道，修缮公寓楼或照料患病奴隶的人，如果这样做确属有利，即使未能达到预期结果，也享有无因管理之诉。我则要问：如果他自以为这样做有利，但实际上对家父并无益处，怎么办？我认为，此人不享有无因管理之诉；因为我们虽不考察最终结果，但该事务在开始处理时就必须确属有利。
