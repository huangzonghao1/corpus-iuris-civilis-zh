# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.31"></a>3.5.31　帕比尼安《答复集》第三卷

<a id="3.5.31.pr."></a>**序言（pr.）** 一名保证人因缺乏经验而犯错，除为其本人所涉合同提供担保外，也为另一项与其本人无关的合同接受了质物或抵押，并向债权人清偿了两笔款项；他原以为，将这些土地合并处理便可保障自己免受损失。基于这些事实，对他提起委任之诉不会成功，他本人向债务人起诉也不会成功；双方均须依无因管理之诉解决争议。在该诉中，只须评估是否存在过失，无须评估意外事件，因为该保证人不应被视为掠夺者。债权人也不因这一行为而须在返还质物的诉讼中返还其所受领之物，因为他似乎已转让了自己的权利。

<a id="3.5.31.1"></a>**1.** 女儿不知情时，母亲从女儿的未婚夫处收受了赠与女儿的物品。由于委任之诉和寄托之诉均不适用，此事应依无因管理之诉处理。

### <a id="3.5.32"></a>3.5.32　莫德斯蒂努斯《答复集》第十卷

已故丈夫的继承人，不应以妻子在婚姻期间曾占有丈夫的财物为由，指控她侵吞遗产。因此，如果她确实管理过丈夫的事务，继承人更妥当的做法是对她提起出示之诉及无因管理之诉。

### <a id="3.5.33"></a>3.5.33　保罗《疑问集》第一卷

涅森尼乌斯·阿波利纳里斯致朱利乌斯·保罗：祖母管理了其孙子的事务。两人均死亡后，孙子的继承人依无因管理之诉起诉祖母的继承人；祖母的继承人则主张，应将她曾为孙子提供的扶养费用计入账目。有人答辩说，祖母是出于亲情而用自己的财产提供扶养，因为她既未请求裁定扶养费用，该费用也未曾经裁判确定〔原文疑误〕。此外，已有规则认为，如果母亲提供了扶养，她不得请求返还自己因亲情而以个人财产支付的费用。相反意见则认为，只有在能够证明母亲确实以个人财产提供扶养时，才能适用该规则；而本案中，祖母管理着孙子的事务，很可能是用孙子本人的财产供养他。双方还讨论了这些费用是否应视为由两份财产共同支出。我问，哪一种处理更为公允？我答复说，这一争议取决于具体事实；而且，我认为，关于母亲的规则不应始终一概适用。倘若母亲曾明确表示，她供养儿子正是为了日后起诉儿子本人或其监护人，又该如何？再设想其父在外地去世，母亲返乡途中供养了儿子及其家内人员：在这种情形下，神圣庇护皇帝安敦尼已规定，可以对该受监护的未成年人本人提起无因管理之诉。因此，鉴于此事取决于事实，我更倾向于认为，如果祖母或其继承人希望将扶养费用列入账目，应允许其陈述；尤其是如能证明祖母曾将这些费用记入支出账目。至于认为这些费用由两份财产共同支出，我认为绝不可采。
