# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.20"></a>3.5.20　保罗《评告示》第九卷

<a id="3.5.20.pr."></a>**序言（pr.）** 塞尔维乌斯也曾作出答复，阿尔芬努斯在《学说汇纂》第三十九卷中记载如下：三人被卢西塔尼人俘获，其中一人以为三人带回赎金为条件获释；约定如果他没有返回，另外两人须替他支付赎金。此人后来不愿返回，因此另外两人也替第三人支付了赎金。塞尔维乌斯答复说，裁判官准许他们对该人提起诉讼是公平的。

<a id="3.5.20.1"></a>**1.** 管理遗产事务的人，在某种程度上使遗产对自己负有义务，也使自己对遗产负有义务。因此，后来是否由受监护的未成年人取得继承人身份，并无区别；该债务与遗产的其他负担一并转移给他。

<a id="3.5.20.2"></a>**2.** 如果我在提提乌斯生前开始管理其事务，他死后我不应中断管理。不过，我没有必要开始新的事务；但有必要完成并保全原有事务。合伙人之一死亡时也会发生这种情形：为处理完先前事务而实施的行为，不论在何时完成，均不重要；重要的是这些行为何时开始。

<a id="3.5.20.3"></a>**3.** 卢基乌斯·提提乌斯依你的委任管理我的事务；他管理不当的部分，使你须依无因管理之诉对我承担责任。你的责任不仅在于向我提供你对他的诉权，也在于你选择他时不够谨慎，因此，他因过失造成的任何损失，你都须向我赔偿。

### <a id="3.5.21"></a>3.5.21　盖尤斯《评行省告示》第三卷

无论管理的是遗产事务还是他人的事务，只要管理人确有必要购买某物，即使该物后来灭失，他仍可依无因管理之诉请求偿还所支出的费用。例如，为家内事务购置谷物或葡萄酒，后来因某种意外而毁于火灾或房屋倒塌。然而，只有在火灾或倒塌并非管理人过错所致时，才能如此主张；因为如果他本人须对火灾或倒塌承担责任，却仍请求偿还这些因此毁损之物的费用，那就是不合理的。
