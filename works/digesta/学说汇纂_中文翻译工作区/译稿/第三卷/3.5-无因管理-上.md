# 第三卷

## <a id="3.5"></a>3.5　论管理他人事务（无因管理）

### <a id="3.5.1"></a>3.5.1　乌尔比安《评告示》第十卷

本告示十分必要，因为它关系到缺席者的重大利益：以免他们无人辩护，因而遭受财物被他人占有或出售、质物被变卖、对方提起罚则之诉，或者遭受不公而失去自己的财物。

### <a id="3.5.2"></a>3.5.2　盖尤斯《评行省告示》第三卷

某人管理了不在场者的事务，即使不在场者对此并不知情，只要管理人为了有利于该人而支出费用，或者为该人的事务而使自己对第三人承担义务，就可以基于此提起诉讼。因此，在这种情形下，会相互产生诉权，这种诉讼称为无因管理之诉。确实，管理人若有不当管理之处，或从所管理的事务中保留了某物，对其进行核算并判令其承担责任，是公平的；反过来说，如果他有利地管理了事务，就应当向其偿付因此已经支出或将要支出的费用。

### <a id="3.5.3"></a>3.5.3　乌尔比安《评告示》第十卷

<a id="3.5.3.pr."></a>**序言（pr.）** 裁判官说：“如果有人管理他人的事务，或者有人管理某人在其死亡时所留下的事务，我将就此授予诉权。”

<a id="3.5.3.1"></a>**1.** “如果有人”一语，应理解为“无论男女”；因为毫无疑问，妇女也可以提起无因管理之诉，也可以成为该诉的被告。

<a id="3.5.3.2"></a>**2.** “事务”一语，应理解为一项或多项事务。

<a id="3.5.3.3"></a>**3.** 裁判官说“他人”；此处“他人”包括男性和女性。
