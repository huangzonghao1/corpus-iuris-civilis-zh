# 第三卷

## 3.2　论被标记为不名誉者（续）

### <a id="3.2.8"></a>3.2.8　乌尔比安《评告示》第六卷

裁判官说：“女婿死亡后”，并恰当地补充：“明知其已死亡”，以免因不知情而受罚。但是，既然服丧期间连续计算，即使不知情，该期间也应自丈夫死亡之日起计算，这样规定是恰当的。因此，若她在法定期间届满后才得知丈夫死亡，拉贝奥说，她应在得知当日穿上丧服，随即又将丧服脱下。

### <a id="3.2.9"></a>3.2.9　保罗《评告示》第五卷

<a id="3.2.9.pr."></a>**序言。** 妻子并不被强制要求为丈夫服丧。

<a id="3.2.9.1"></a>**1.** 未婚妻没有服丧期间。

### <a id="3.2.10"></a>3.2.10　保罗《评告示》第八卷

<a id="3.2.10.pr."></a>**序言。** 通常可以请求元首准许妇女在法定期间内结婚。

<a id="3.2.10.1"></a>**1.** 妇女在为丈夫服丧期间曾经订婚，不妨碍她在该期间内结婚。

### <a id="3.2.11"></a>3.2.11　乌尔比安《评告示》第六卷

<a id="3.2.11.pr."></a>**序言。** 为子女或父母服丧，并不构成结婚的障碍。

<a id="3.2.11.1"></a>**1.** 即使丈夫属于依祖先惯例不应为之服丧的人，妻子仍不得在法定期间内另行嫁人。因为裁判官所指的是为丈夫服丧的期间；丈夫通常须受服丧，是因为需要避免血统关系发生混淆。

<a id="3.2.11.2"></a>**2.** 庞波尼乌斯认为，妇女在法定期间内分娩的，可以立即结婚；我认为这一看法正确。

<a id="3.2.11.3"></a>**3.** 如内拉提乌斯所说，敌人、因叛国罪被判刑者，以及上吊自尽者，通常不受服丧；但因良心有愧而非厌倦生活自尽的人除外。因此，若妇女在其丈夫以此类方式死亡后另行嫁人，就会被标记为不名誉者。

<a id="3.2.11.4"></a>**4.** 裁判官还说：“与该女子结婚的人”，但仅限于明知情形者；因为对事实的无知可以免责，对法律的无知则不可以。经其权力支配者命令而结婚的人可以免责；而允许他结婚的权力支配者本人则会被标记为不名誉者。这两项规则都很恰当：服从命令者应获宽宥，允许其结婚者则应受不名誉污名。
