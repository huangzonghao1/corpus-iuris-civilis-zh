# 第三卷

## 3.1　论提出诉讼请求（续）

### 3.1.1　乌尔比安《评告示》第六卷（续）

<a id="3.1.1.8"></a>**8.** 裁判官规定：“凡依据法律、平民会决议、元老院决议、告示或元首命令而被禁止提出请求的人，除非是为特定的人提出请求，否则不得在我主持的司法程序中为他人提出请求。”此项告示也包括所有依裁判官告示被标记为不名誉者；这些人均只能为自己及特定的人提出请求。

<a id="3.1.1.9"></a>**9.** 裁判官接着补充：“除非上述人员已经获准恢复原状。”应当这样理解“上述人员之一”：如果此人属于第三项告示所列、仅可为特定的人提出请求者；如果属于前两类人员，则很难获准恢复原状。

<a id="3.1.1.10"></a>**10.** 裁判官所说的恢复原状，是指哪一种？是元首或元老院所给予的恢复原状吗？庞波尼乌斯提出这一问题，并认为裁判官所指的是元首或元老院准许的恢复原状。裁判官本人是否也可以准许恢复原状，也有疑问。我认为，裁判官此类裁定不应被遵循，除非其是依职权行使司法管辖权而给予救济，例如关于年龄的情形，以及我们将在“论恢复原状”标题下讨论的其他情形。支持这一观点的是：如果某人因不名誉判决而被定罪，后来又通过恢复原状被宣告无罪，庞波尼乌斯认为，该人应免除不名誉污名。

<a id="3.1.1.11"></a>**11.** 裁判官接着规定：“可以为他人提出请求，但下列情形除外：不得为自己的父母、保护人、女保护人，以及保护人或女保护人的子女和父母以外的人提出请求。”关于这些人，我们已在“论传唤到庭”标题下作了较详尽的说明。裁判官还补充：“也可以为自己的子女、兄弟或姐妹、妻子、岳父或岳母、女婿或儿媳、继父或继母、继子或继女、受监护的男孩或女孩、精神失常的男子或女子提出请求——”

### <a id="3.1.2"></a>3.1.2　盖尤斯《评行省告示》第一卷

“以及心智愚钝的男子或女子。”这些人也应设立保佐人。

### <a id="3.1.3"></a>3.1.3　乌尔比安《评告示》第六卷

<a id="3.1.3.pr."></a>**序言。** “即由父母指定的人，或由多数监护人意见指定的人，或由对此事项享有司法管辖权的人指定其为监护人或保佐人。”

<a id="3.1.3.1"></a>**1.** 此处所说的姻亲，应是现存的姻亲关系，而非曾经存在的姻亲关系。

<a id="3.1.3.2"></a>**2.** 庞波尼乌斯还说，“儿媳”和“女婿”这些称谓也包括岳父、岳母以及更远的姻亲；在这些更远的亲属称谓前，通常会加上表示“前一代”的前缀 *pro-*。

<a id="3.1.3.3"></a>**3.** 乌尔比安说，关于保佐人，裁判官本应补充：哑者以及其他通常须设保佐人的人，也包括在内，即聋者、挥霍者和未成年人。

### <a id="3.1.4"></a>3.1.4　保罗《评告示》第五卷

同样，裁判官通常因身体虚弱而为之指定保佐人的人，也包括在内。

### <a id="3.1.5"></a>3.1.5　乌尔比安《评告示》第九卷

以及因长期疾病而无法处理自己事务的人。

### <a id="3.1.6"></a>3.1.6　乌尔比安《评告示》第六卷

我认为，凡并非自愿、而是必须履行职务的人，即使属于通常只能为自己提出请求的人，也可以提出请求而不违反告示。如果某人被禁止提供诉讼辩护；而这项禁止是在他自己任职期间、于其主持的法庭中作出的——这种情形并不少见——我认为，此人之后可以在其继任者主持的法庭中出庭。

### <a id="3.1.7"></a>3.1.7　盖尤斯《评行省告示》第三卷

裁判官禁止某人在自己面前提出请求的，即使对方允许其提出请求，也仍然绝对禁止。

### <a id="3.1.8"></a>3.1.8　帕皮尼安《问题集》第二卷

安东尼努斯皇帝曾答复：某人被禁止提供诉讼辩护五年，五年期满后，不得禁止他为任何人提出请求。神圣哈德良皇帝也曾答复：被允许结束流放而返回的人可以提出请求。不得区分其被判处停止陈述或流放所依据的罪名，以免期限已经确定的刑罚违反判决效力而被延长。

### <a id="3.1.9"></a>3.1.9　帕皮尼安《答复集》第一卷

某人因某项事由被禁止为他人提出请求，但该事由并不导致不名誉污名，因此也未剥夺其为任何人提出请求的资格。在作出该判决的行省总督所辖行省内，他不得为他人提出请求；在另一行省内则不受此限，即使两地所涉罪名相同，也不例外。

### <a id="3.1.10"></a>3.1.10　保罗《规则集》单卷

代表国库处理诉讼事务的人，仍可在针对国库的案件中为自己、自己的子女或父母，或者为自己担任监护人的未成年人提出请求。市镇议员也不得在针对本市镇的案件中提出请求，但上述人员除外。

### <a id="3.1.11"></a>3.1.11　特里丰尼努斯《论争议》第五卷

<a id="3.1.11.pr."></a>**序言。** 我们的元首曾答复：监护人可以在诉讼中协助被监护人，即使他此前曾在针对被监护人父亲的案件中担任辩护人。元首还准许监护人代表被监护人处理针对国库的案件，即使他此前曾在针对被监护人父亲的案件中担任国库辩护人。
