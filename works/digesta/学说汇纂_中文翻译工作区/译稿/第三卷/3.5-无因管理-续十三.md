# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.22"></a>3.5.22　保罗《评告示》第二十卷

有人管理他人事务时，若收取了并不应付的款项，就必须返还；但如果他支付了原本不应支付的款项，更妥当的看法是，应由他自行承担这一后果。

### <a id="3.5.23"></a>3.5.23　保罗《评告示》第二十四卷

如果我交给你的代理人一笔钱，意在使该笔钱归债权人所有，债权人并不因代理人收取钱款而取得其所有权。但债权人仍可通过追认使该笔钱成为自己的钱，即使我不同意也一样；因为代理人收款时只是在处理债权人的事务。因此，债权人追认后，我即获免责。

### <a id="3.5.24"></a>3.5.24　保罗《评告示》第二十七卷

如果有人管理他人事务时支出超过适当数额，他能够请求偿还的，仅限于本应由本人承担的部分。

### <a id="3.5.25"></a>3.5.25　莫德斯蒂努斯《答复集》第一卷

某城市被遗嘱信托指定为遗产受领人，遗产应移交该城市。市政官员指定提提乌斯、塞尤斯和盖乌斯为该遗产的适当管理人。其后，这些管理人彼此划分遗产的管理工作，并在未经市政官员授权、亦未获其同意的情况下进行管理。过了一段时间，法庭裁定，原先指定将遗产移交城市的遗嘱无效；于是，塞姆普罗尼乌斯作为死者的法定继承人，在无遗嘱继承下取得了遗产。但上述管理人之一在无清偿能力的状态下死亡，且没有继承人。我问：如果塞姆普罗尼乌斯起诉这些遗产管理人，该由谁承担已故管理人无清偿能力所造成的风险？赫雷尼乌斯·莫德斯蒂努斯答复说：对于某一管理人单独处理的事项，如无法依无因管理之诉向该人追偿，其损失应由取得法定继承权的人承担。
