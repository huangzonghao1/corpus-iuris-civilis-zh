# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### 3.5.3　乌尔比安《评告示》第十卷（续）

<a id="3.5.3.7"></a>**7.** 既然此项诉讼源于事务管理，它既可以由继承人提起，也可以针对继承人提起。

<a id="3.5.3.8"></a>**8.** 如果裁判官指定的事务执行人在管理我的事务时对我实施欺诈，我可以对其提起诉讼。

<a id="3.5.3.9"></a>**9.** 拉贝奥记载，有时无因管理之诉仅涉及欺诈责任。例如，你出于情义，为避免我的财产被处分而主动管理我的事务，那么只让你对欺诈承担责任，最为公平；这一意见是衡平的。

<a id="3.5.3.10"></a>**10.** 该项诉讼不仅约束自愿介入他人事务、并在没有任何迫切需要时进行管理的人，也约束因某种迫切需要或认为存在迫切需要而进行管理的人。

<a id="3.5.3.11"></a>**11.** 马尔凯鲁斯在《学说汇纂》第二卷中讨论：如果我原本打算管理提提乌斯的事务，而你又委托我这样做，我是否可以同时使用两种诉讼？我认为，两种诉讼均可适用。马尔凯鲁斯还记载，若我接受保证人的保证以便管理事务，也可以对双方提起诉讼。

### <a id="3.5.4"></a>3.5.4　乌尔比安《评萨宾努斯》第四十五卷

但我们来看看，保证人在此是否享有某种诉权。确实，保证人可以提起无因管理之诉，除非其提供保证是出于赠与之意。
