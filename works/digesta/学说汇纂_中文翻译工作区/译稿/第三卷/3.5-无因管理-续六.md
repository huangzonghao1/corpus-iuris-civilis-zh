# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### 3.5.5　乌尔比安《评告示》第十卷（续）

<a id="3.5.5.11"></a>**11.** 庇狄乌斯《答复集》第七卷提出这样的问题：如果我在庭外通知提提乌斯，称他是你的债务人，提提乌斯因此向我付款，实际上他却并非你的债务人；后来你得知此事并予以追认，我能否依无因管理之诉起诉你？他说，此事可能存在疑问，因为提提乌斯并非你的债务人，所以并未管理你的事务。但他又说，追认使该事项成为你的事务；正如付款人可以向追认此事的人提起返还之诉，提提乌斯在追认后也应当能够对我提起诉讼。如此，追认便使原本不属于你的事务成为你的事务，尽管该事务最初是为了你而处理的。

<a id="3.5.5.12"></a>**12.** 他还说，如果我误以为你是提提乌斯的继承人，而实际上塞尤斯才是继承人，我像上述情形一样向提提乌斯的债务人追债并收取款项，随后你予以追认，那么我可以对你提起无因管理之诉，你也可以对我提起相互的无因管理之诉。虽然我处理的本是他人的事务，但追认使该事务成为你的事务；因此，视同处理了你的事务，并可以向你请求遗产。

<a id="3.5.5.13"></a>**13.** 那么，庇狄乌斯接着问：如果我误以为你是继承人，便修缮属于遗产的房屋，而你予以追认，我能否对你提起诉讼？他说，不能；因为我的行为使另一人获益，实际上处理的是另一人的事务。该行为本身既然使他人取得利益，就不能将其视为你的事务。

<a id="3.5.5.14"></a>**14.** 我们还应考察事务管理人的情形：如果他管理了某些事务，却没有管理另一些事务，但由于他已经介入，其他人便没有处理这些事务；而谨慎之人——这是我们对事务管理人的要求——本来也会处理那些未管理的事务，那么是否应认为他也须对未处理的事务承担无因管理之诉责任？我认为较妥当的看法是应当如此。至少，如果他本应向自己追讨债务却没有追讨，毫无疑问应将此归责于他。虽然不能因为他没有向其他债务人起诉而归责于他——因为他没有诉权，无法通过诉讼向他们追讨——但他没有向自己追讨，则应归责于他。即使该债务原本不计利息，也因此开始计息；神圣庇护皇帝曾就此向弗拉维乌斯·隆吉努斯作出敕答：“除非他已经免除了该债务的利息。”
