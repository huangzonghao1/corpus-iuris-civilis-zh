# 第三卷

## 3.2　论被标记为不名誉者（续）

### <a id="3.2.12"></a>3.2.12　保罗《评告示》第五卷

依父亲命令而结婚者，即使其后脱离父权仍保留该女子为妻，也不被标记为不名誉者。

### <a id="3.2.13"></a>3.2.13　乌尔比安《评告示》第六卷

<a id="3.2.13.pr."></a>**序言。** 那么，如果某人起初并未允许其权力下之人结婚，而是在婚后予以追认呢？例如，他起初不知道该女子属于此类，后来才知道。此人不会被标记为不名誉者，因为裁判官关注的是婚姻缔结之时。

<a id="3.2.13.1"></a>**1.** 某人以他人名义安排两次订婚的，不会被标记为不名誉者，除非他是以自己权力支配下的男子或女子的名义安排；当然，允许儿子或女儿安排订婚的人，在某种意义上也被视为亲自安排了订婚。

<a id="3.2.13.2"></a>**2.** 裁判官所说“在同一时期”，并非指两次订婚必须在同一时刻开始，而是指两次订婚的期间相互重叠。

<a id="3.2.13.3"></a>**3.** 同样，若一人与一名女子订婚，却与另一名女子结婚，也依该告示的规定受罚。

<a id="3.2.13.4"></a>**4.** 由于受到标记的是行为本身，即使某人与一名依法不能或不应娶为妻的女子缔结婚姻或订婚，也会被标记为不名誉者。

<a id="3.2.13.5"></a>**5.** 依当事人约定提交仲裁而作出的裁决，不会导致不名誉污名，因为仲裁裁决并不在各方面都等同于判决。

<a id="3.2.13.6"></a>**6.** 就不名誉污名而言，须区分裁判者是否在审理案情后作出裁断，还是仅在庭外附带说了某些话；后一种情形不会施加不名誉污名。

<a id="3.2.13.7"></a>**7.** 超出法律规定而施加较重刑罚的，仍保全其名誉地位；对此已有规定和法律解答。例如，某人依法本应被处以部分财产罚，行省总督却将其放逐；应当认为，较重的判决已就其名誉地位作了处置，因此他不属于不名誉者。但是，如果法官在非现行盗窃案件中判处四倍赔偿，虽然被告因此承受了加重的刑罚——因为非现行盗窃原本应以双倍额起诉——这并未保全其名誉地位；不过，若法官加重的是非金钱刑罚，则似乎可以认为其名誉地位已经通过该刑罚得到处置。

<a id="3.2.13.8"></a>**8.** 因诈欺罪（*stellionatus*）被判罪者，即使该罪并非通过公审程序审理，也会承受不名誉污名。
