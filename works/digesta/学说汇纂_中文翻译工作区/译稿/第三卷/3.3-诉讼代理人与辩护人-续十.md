# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.40"></a>3.3.40　乌尔比安《评告示》第九卷

<a id="3.3.40.pr."></a>**序言。** 庞波尼乌斯记载，并非所有诉讼都可以委任代理人。例如，为使据称受不在场者家父权支配的子女被带回而请求发布令状，原则上不得由代理人提出；尤利安认为，只有经审查具体情由后才可例外，即已明确委任此事，且父亲因疾病或其他正当理由而受阻时。

<a id="3.3.40.1"></a>**1.** 代理人为可能发生的损害或遗赠请求担保的，也应提供追认担保。

<a id="3.3.40.2"></a>**2.** 某人以诉讼辩护人的身份在对物之诉中被起诉的，除通常的判决清偿担保外，也应提供追认担保。因为，倘若本案判决认定该物属于我，先前由他辩护的委托人回来后仍要求追索该土地，那么此人岂不是未追认已经作出的判决？毕竟，如果是真正的诉讼代理人，或者委托人本人在场亲自进行诉讼而败诉，随后再向我请求返还该土地，就会因既判力抗辩而被驳回。尤利安在《学说汇纂》第五十卷中也如此写道：因为判决认定该物属于我，也就同时判定该物不属于他。

<a id="3.3.40.3"></a>**3.** 代理人须在争讼程序确定前提供追认担保；诉讼一经正式受理，就不得再强迫其提供该项担保。

<a id="3.3.40.4"></a>**4.** 对于无需委任书的那些人，如果显然其行为违背了所代表之人的意愿，就应当拒绝其代理。因此，我们不要求他们证明本人已同意或作出委任，只要求不得证明本人曾表示反对；即使他们愿意提供追认担保，也不改变这一点。
