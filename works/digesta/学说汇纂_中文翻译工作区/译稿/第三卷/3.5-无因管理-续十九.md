# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.39"></a>3.5.39　保罗《评萨比努斯》第十卷

如果我与你共有一所房屋，并就你所占份额向邻人提供了关于尚未发生之损害的担保，应当认定：我可依无因管理之诉请求返还所支付的款项，而非通过共有物分割之诉请求返还。因为我可以只为保护自己的份额提供担保，而不必迫使合伙人也为其份额提供担保。

### <a id="3.5.40"></a>3.5.40　保罗《评告示》第三十卷

有人在我不知情或不在场时，为我的奴隶辩护诺克萨诉讼，则其可以对我提起无因管理之诉，请求全部金额，而非仅以特有产为限。

### <a id="3.5.41"></a>3.5.41　保罗《评告示》第三十二卷

如果你应我的奴隶之请求接手管理我的事务，而你只是因我的奴隶提醒你才这样做，那么我们之间产生无因管理之诉。但如果你是把该奴隶的请求当作其对你的委任，则答复认为，你可以依特有产之诉及利益归入之诉提出请求。

### <a id="3.5.42"></a>3.5.42　拉贝奥《后期著作》第六卷（雅沃勒努斯编摘要）

如果你替某人清偿款项，而此人并未委任你，那么，由于该清偿使债务人免受债权人追索，你享有无因管理之诉；除非债务人有不应支付该笔款项的利益。

### <a id="3.5.43"></a>3.5.43　乌尔比安《论争集》第六卷

某人出于对父亲的友情，为受监护的未成年人请求指定监护人，或请求宣告其监护人为可疑监护人；依神圣塞维鲁皇帝的敕令，该人对这些未成年人或监护人均不享有诉权。
