# 第三卷

## 3.2　论被标记为不名誉者（续）

### <a id="3.2.6"></a>3.2.6　乌尔比安《评告示》第六卷

<a id="3.2.6.pr."></a>**序言。** 告示所说的“盗窃”，包括现行盗窃和非现行盗窃。

<a id="3.2.6.1"></a>**1.** 某人因盗窃或其他导致不名誉的诉讼被判罪后提起上诉的，在上诉案件审理期间，尚不视为不名誉者。若所有上诉期限均已届满，则其不名誉身份溯及既往发生。不过，如果其上诉被认定为不正当，我认为他从此时起被标记为不名誉者，而不溯及既往。

<a id="3.2.6.2"></a>**2.** 某人以他人名义被判罪的，不承受不名誉污名。因此，我的诉讼代理人、诉讼辩护人、监护人、保佐人或继承人因盗窃或其他类似事由被判罪，不会因此被标记为不名誉者；如果案件从一开始就是通过诉讼代理人进行的，我本人也不会因此受污名。

<a id="3.2.6.3"></a>**3.** 告示说：“或者与对方和解者。”这里的和解，应理解为当事人就某一金额达成的和解。否则，即使某人只是恳求对方不要起诉而如愿，也会被标记为不名誉者，且全无宽宥余地；这显然有失人道。

<a id="3.2.6.4"></a>**4.** 依裁判官命令、支付价金后与对方和解的人，不会被标记为不名誉者。

<a id="3.2.6.4a"></a>**4a.** 若某人经对方请求而宣誓，称自己并未实施不法行为，也不会被标记为不名誉者；因为他在某种意义上已通过宣誓证明自己的清白。

<a id="3.2.6.5"></a>**5.** 告示所说的“因委任之诉被判罪者”，并非仅指接受委任的人，也包括未能履行对方赖以行事之信赖的人。例如，我为你作保证人并已代为清偿；若我以委任之诉起诉你并获判胜诉，就会使你成为不名誉者。

<a id="3.2.6.6"></a>**6.** 必须补充一点：有时继承人也会以本人名义被判罪，因此成为不名誉者；例如，他在寄托或委任关系中处理不当。但是，继承人不能在监护之诉或合伙之诉中以本人名义被判罪，因为继承人并不承受死者的监护人身份或合伙人身份，只承受死者的债务。

<a id="3.2.6.7"></a>**7.** 在反诉中被判罪的人，不会成为不名誉者；这并非没有道理。因为反诉所涉及的不是背信，而是账目计算，而此类事项通常正是通过诉讼解决的。

### <a id="3.2.7"></a>3.2.7　保罗《评告示》第五卷

在源于契约的诉讼中，即使此类诉讼会导致不名誉污名、被判罪者也会被标记为不名誉者，与对方和解的人却不会因此受污名；这是合理的，因为此类和解的可责程度，不及前述各类情形。
