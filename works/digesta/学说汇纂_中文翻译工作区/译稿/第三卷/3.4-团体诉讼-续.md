# 第三卷

## 3.4　论以任何团体名义或针对任何团体提起的诉讼（续）

### <a id="3.4.3"></a>3.4.3　乌尔比安《评告示》第九卷

除法律授权者外，任何人不得以城市或议员团名义提起诉讼；法律未作规定时，也须经议员团授权，并有其三分之二成员或超过三分之二成员出席。

### <a id="3.4.4"></a>3.4.4　保罗《评告示》第九卷

确切地说，议员团三分之二成员须出席；议员团所指定的人也可以计入出席人数。

### <a id="3.4.5"></a>3.4.5　乌尔比安《评告示》第八卷

庞波尼乌斯说，应当注意：父亲的表决可以计入儿子名下，儿子的表决也可以计入父亲名下，

### <a id="3.4.6"></a>3.4.6　保罗《评告示》第九卷

<a id="3.4.6.pr."></a>**序言。** 对于处于同一家父权下的人，也适用同一规则；因为此人是以议员身份投票，而不是以家庭成员身份投票。竞选官职时也应遵守这一规则，除非市镇法律或长期惯例禁止。

<a id="3.4.6.1"></a>**1.** 如果议员团决议由双官之一选定的人提起诉讼，该人即视为议员团所选，因此可以起诉；由议员团亲自选定，还是由议员团委托其办理事务的人选定，差别不大。但如果议员团决议称，无论将来发生何种争议，均由提提乌斯负责起诉，则该决议依法无效；因为对于尚未发生争议的事项，不得认为议员团已通过决议授予诉讼追索权。不过，如今此类事务通常按照当地惯例由团体代理人办理。

<a id="3.4.6.2"></a>**2.** 如果一名代表人被指定后，议员团又通过决议禁止其行事，该代表人是否会受到抗辩？我认为，应当这样理解：只有在授权仍持续有效的范围内，才视为准许其行事。

<a id="3.4.6.3"></a>**3.** 团体代表人提起诉讼时，也被要求为团体辩护，但不被要求提供追认担保。不过，如果代表人是否经决议授权存在疑问，我认为也应提供追认担保。因此，此类代表人履行的是代理人的职能；除非其系为自身利益受任，否则告示不授予其判决之诉。他也可以接受定期给付承诺。更换代表人的理由与更换诉讼代理人的理由相同。家子也可以被指定为团体代表人。

### <a id="3.4.7"></a>3.4.7　乌尔比安《评告示》第十卷

<a id="3.4.7.pr."></a>**序言。** 正如裁判官准许以市镇名义提起诉讼，他也认为发布针对市镇的告示是最为公允的。此外，对受委派办理公共事务而支出费用的人，我认为也应准许其向市镇提起诉讼。

<a id="3.4.7.1"></a>**1.** 若有债务应向团体清偿，该债务并非应向其个别成员清偿；团体所负债务，也不由各成员分别承担。

<a id="3.4.7.2"></a>**2.** 对议员团或其他团体而言，成员是否全体留任、部分留任或全体更换，并不重要。但若团体最终只剩一人，较可采的意见是，该人可以起诉，也可以被起诉；因为全体成员的权利都归于一人，而团体之名仍然存在。

### <a id="3.4.8"></a>3.4.8　雅沃勒努斯《评卡西乌斯》第十五卷

如果市镇未由管理其事务的人代为辩护，且没有可供请求人取得占有的市镇共同财产，就应允许请求人通过对市镇债务人提起诉讼而获得清偿。

### <a id="3.4.9"></a>3.4.9　庞波尼乌斯《评萨宾努斯》第十三卷

如果你与市镇共同继承一项遗产，你们之间可以提起遗产分割之诉。对于界址确定之诉和阻止雨水流入之诉，也应作同样处理。

### <a id="3.4.10"></a>3.4.10　保罗《手册集》第一卷

也可以指定团体代表人负责新工程告知程序，并负责订立相关要式承诺，例如遗赠担保、未发生损害担保或判决清偿担保。尽管担保最好由市镇的奴隶提供，但即使担保是向团体代表人提供，也应授予市镇事务管理人一项准诉权。
