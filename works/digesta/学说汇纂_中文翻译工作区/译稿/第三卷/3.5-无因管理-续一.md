# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### 3.5.3　乌尔比安《评告示》第十卷（续）

<a id="3.5.3.4"></a>**4.** 受监护的未成年人若管理了他人事务，根据神圣庇护皇帝的敕答，也可以对其提起诉讼，但仅限于其因此而增加的财产利益；反过来，他若提起诉讼，也应承担对方就其所管理事务提出的抵销请求。

<a id="3.5.3.5"></a>**5.** 如果我管理了精神失常者的事务，我可以对其提起无因管理之诉。拉贝奥说，也应准许精神失常者的监护人对该男子或女子提起此项诉讼。

<a id="3.5.3.6"></a>**6.** “或者有人管理某人在其死亡时所遗留的事务”一语，指的是某人在他人死亡后管理其事务的情形。告示有必要作出规定，因为此时既不可能说管理人处理了已故立遗嘱人的事务，也不能说他处理了尚未接受遗产的继承人的事务。但是，如果死亡后有新的财产增加，例如子女出生、牲畜产仔或收获果实，或者奴隶取得了某项财产，尽管这些情形不在该措辞的字面范围内，仍应视为包括在内。
