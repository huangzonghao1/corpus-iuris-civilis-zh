# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.10"></a>3.5.10　庞波尼乌斯《评昆图斯·穆基乌斯》第二十一卷

如果你在事务本人不在场且不知情时管理其事务，就应对过失和欺诈承担责任。普罗库鲁斯认为，有时你甚至还应对意外损失承担责任；例如，你以其名义经营一项他平日并不从事的新事务，如购入新奴隶供出售，或开展某种营业。若因此发生损失，应由你承担；但所获利益归不在场的事务本人。若某些事项获利、另一些事项受损，则事务本人应以所得利益抵销损失。

### <a id="3.5.11"></a>3.5.11　乌尔比安《评告示》第十卷

<a id="3.5.11.pr."></a>**序言（pr.）** 对于在敌方被俘期间死亡、且其事务曾由他人管理之人的承受人，应准许提起这一诉讼。

<a id="3.5.11.1"></a>**1.** 如果我管理的是一名家子的事务，而其军人家父已经死亡并立有遗嘱，也应同样准许该诉。

<a id="3.5.11.2"></a>**2.** 正如管理生者事务时，只要管理有利即已足够；管理死者遗产亦同，即使最终结果有所不同，也不妨碍此点。

### <a id="3.5.12"></a>3.5.12　保罗《评告示》第九卷

我的债务人曾欠我五十；他去世后，我承担了该遗产的管理，并支出十。随后，我将出售遗产物所得的一百存入钱箱；这些钱并非因我的过失而灭失。问题是，日后出现继承人时，我能否向其请求偿还五十的借款债权，或请求偿还我所支出的十？尤利安写道，关键在于考察我是否有正当理由将这一百存放起来：如果我本应向自己以及其他遗产债权人清偿，那么这一百灭失的风险应由我承担；我不仅要对其中六十负责，还要对其余四十负责。不过，我仍可保留自己支出的十；也就是说，只须返还九十。反之，如果我有正当理由将这一百完整保管起来，例如为避免遗产土地被没收入公库、海上借贷的罚金增加，或因仲裁约定而触发罚则，那么，我不仅可以向继承人请求偿还为管理遗产事务而支出的十，也可以请求偿还其所欠我的五十。
