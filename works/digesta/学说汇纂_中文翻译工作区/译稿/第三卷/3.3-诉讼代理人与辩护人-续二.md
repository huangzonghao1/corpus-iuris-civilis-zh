# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### 3.3.8　乌尔比安《评告示》第八卷（续）

<a id="3.3.8.3"></a>**3.** 裁判官说：“对于受委任接受诉讼、且委托人已同意并为其提供判决清偿担保的代理人，我将强制其接受诉讼。”不过，遇有特定情由时，不应强制代理人接受诉讼。例如，代理人与委托人之间发生了不共戴天的仇怨；尤利安认为，应拒绝对该代理人提起诉讼。又如，代理人的身份地位有所变化，或者他将因公务而离开：

### <a id="3.3.9"></a>3.3.9　盖尤斯《评行省告示》第三卷

又如，他以健康状况或必须出行作为理由：

### <a id="3.3.10"></a>3.3.10　乌尔比安《评告示》第八卷

又如，他须处理继承事务，或存在其他正当理由。此外，即使委托人在场，只要委托人本人可以被强制接受诉讼，也不应强制代理人接受诉讼：

### <a id="3.3.11"></a>3.3.11　保罗《评告示》第八卷

但以委托人确实能够被强制为限。

### <a id="3.3.12"></a>3.3.12　盖尤斯《评行省告示》第三卷

不过，也有人认为，在某些情形下仍应强制代理人接受诉讼。例如，委托人不在场，而原告主张若因时间经过而拖延，争议标的将会灭失。

### <a id="3.3.13"></a>3.3.13　乌尔比安《评告示》第八卷

但是，这些情形既不应一概准许，也不应一概严格拒绝；裁判官应审查具体情由后酌情裁定。

### <a id="3.3.14"></a>3.3.14　保罗《评告示》第八卷

代理人受任后，若代理人与委托人之间发生不共戴天的仇怨，不应强制代理人接受诉讼；也不应使关于未予辩护的担保条款发生效力，因为此时出现了新的事由。
