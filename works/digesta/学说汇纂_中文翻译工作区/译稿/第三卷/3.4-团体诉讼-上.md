# 第三卷

## <a id="3.4"></a>3.4　论以任何团体名义或针对任何团体提起的诉讼

### <a id="3.4.1"></a>3.4.1　盖尤斯《评行省告示》第三卷

<a id="3.4.1.pr."></a>**序言。** 并非任何人都可以随意设立合伙、社团或此类团体；因为法律、元老院决议和元首敕令都对这类事项加以限制。只有极少数情形获准设立此类团体。例如，承包公税者的合伙人获准组成团体，经营金矿、银矿和盐场者也获准如此。在罗马，还有若干特定社团，其团体地位经元老院决议和元首敕令确认，例如面包师和其他若干行业团体，以及船主团体；此类团体在行省也有设立。

<a id="3.4.1.1"></a>**1.** 凡获准以社团、合伙或其他此类团体名义成立团体者，均可仿照国家共同体的模式，拥有共同财产、共同资金以及代表人或团体代理人；共同事务应由该代表人或代理人代表团体处理和进行，犹如国家共同体中的事务一般。

<a id="3.4.1.2"></a>**2.** 如果没有人替团体辩护，团体的共同财产即可依程序被置于占有之下；若经通知后，团体仍不采取行动为自身辩护，总督说，他将下令出售该共同财产。即使在名义上设有代表人或团体代理人，只要该人不在场、因病受阻或不适于处理诉讼事务，我们也应认为该团体实际上没有代表人或代理人。

<a id="3.4.1.3"></a>**3.** 如果团体以外的人愿意为该团体辩护，总督允许其这样做；这与私人诉讼中的辩护规则相同，因为这样会改善团体的处境。

### <a id="3.4.2"></a>3.4.2　乌尔比安《评告示》第八卷

如果市镇成员或某一团体指定代表人提起诉讼，不得将其视为由众多人分别指定；因为此人是代表国家共同体或团体介入诉讼，而非代表各个成员。
