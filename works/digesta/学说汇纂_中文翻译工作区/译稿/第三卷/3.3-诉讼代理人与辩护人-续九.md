# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### 3.3.39　乌尔比安《评告示》第九卷（续）

<a id="3.3.39.4"></a>**4.** 父亲以儿子名义提起侵辱之诉的，无须提供追认担保，因为此处存在两项诉权：一项属于父亲，另一项属于儿子。

<a id="3.3.39.5"></a>**5.** 如果代理人使某人陷入身份争议，无论对方主张该人原为奴隶、现为自由人，还是该人本人主张自己原为自由人、现为奴隶，都应提供担保，保证委托人将追认其行为。告示也是这样规定的：在身份争议的两方中，均将各方视同原告。

<a id="3.3.39.6"></a>**6.** 还有一种情形，代理人就同一诉讼既须提供追认担保，也须提供判决清偿担保。例如，有人请求恢复原状，主张未成年人在买卖中受到欺诈；另一方由代理人出庭。该代理人应提供追认担保，以防委托人返回后提出请求；还应提供判决清偿担保，以便在恢复原状程序中如有应付给该未成年人的款项，能够予以给付。庞波尼乌斯在《评告示》第二十五卷中如此记载。

<a id="3.3.39.7"></a>**7.** 他还说，若有人申请以监护人品行可疑为由对其进行审查，监护人的辩护人也应提供追认担保，以防监护人回来后要求撤销已经进行的程序。但通常不易允许通过代理人提出此种对监护人不利的指控，因为该程序关系到其名誉；除非能够证明监护人已明确委任代理人提出指控，或者即使监护人不在场，裁判官也会因其无人辩护而进行审查。
