# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.33"></a>3.3.33　乌尔比安《评告示》第九卷

<a id="3.3.33.pr."></a>**序言。** 也有人说，奴隶和家子可以有代理人。就家子而言，此说确实正确；对于奴隶，我们仍存疑问。我们承认，可以有人处理奴隶特有产方面的事务，并在这种情况下充当其代理人，拉贝奥也持此见解；但我们不允许以奴隶名义提起诉讼。

<a id="3.3.33.1"></a>**1.** 对自己的身份提起诉讼的人，我们毫不怀疑其可以有代理人；代理人不仅可以管理其事务，也可以代为处理其本人享有或针对其提起的诉讼，无论争议涉及自由人身份还是奴隶身份。反过来，为与其对立的一方指定代理人，也显然可以。

<a id="3.3.33.2"></a>**2.** 让不在场的人由任何人代为辩护，符合公共利益；即使在涉及死刑的诉讼中，也允许为其辩护。因此，凡不在场者可能被判罪的案件，公平且通常的做法都是听取任何代表其陈述并为其开脱的人；这也可由我们的皇帝所作敕答得到印证。

<a id="3.3.33.3"></a>**3.** 裁判官规定：“凡有人请求为他人名义授予诉权，该他人应依善良人的判断获得辩护；并且，代理人应依善良人的判断提供担保，保证其所代表之人将追认其行为。”

<a id="3.3.33.4"></a>**4.** 裁判官认为公平的是：以某人名义担任代理人而起诉的人，也应承担为其辩护的责任。

<a id="3.3.33.5"></a>**5.** 若有人以自身利益为由介入、担任代理人，仍应认为其有义务为对方辩护；但如果他是不得已才担任代理人，则属例外。

### <a id="3.3.34"></a>3.3.34　盖尤斯《评行省告示》第三卷

某人以自身利益为由、以代理人名义起诉，例如遗产买受人；他是否也必须反过来为出卖人辩护？通说认为，如果该交易系善意进行，且并非为了欺诈那些可能反向提起诉讼的人，就不应要求他反过来为出卖人辩护。
