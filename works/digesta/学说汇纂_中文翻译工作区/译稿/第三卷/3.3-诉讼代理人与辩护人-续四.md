## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.25"></a>3.3.25　乌尔比安《评告示》第九卷

上述各项规则不仅适用于被告一方，也适用于原告一方。如果对方或代理人本人主张委托人在说谎，相关问题应由裁判官裁断。不得容许代理人自行声称自己获得了代理权；仅凭这一行为，他就显得可疑，因为他强行提供服务，违背了本人的意愿。除非他更愿意澄清所受的侮辱，而非继续履行代理职责。只有在他表示愿意退出代理、但此举不会损害其名誉的范围内，才应听取其意见；否则，若他是在为自己洗清名誉，应当允许他这样做。显然，如果他主张自己是为自身利益而被指定为代理人，并且证明了这一点，就不应剥夺其自行进行诉讼的权利。同样，如果代理人主张行使留置权，也不应轻易将诉讼从他手中转移，

### <a id="3.3.27"></a>3.3.27　乌尔比安《评告示》第九卷

<a id="3.3.27.pr."></a>**序言。** 审查具体情由时，还应考虑：只有在有人准备将全部诉讼都从代理人处移转时，才允许将诉讼移转。否则，若当事人想移转部分诉讼，却要保留其余部分，代理人有理由拒绝这种反复无常的做法。但上述规则以代理人系依委托人委任而行事为前提。若代理人并未获得委任，既未将任何事项提交诉讼审理，你也未予追认，那么未经你同意而进行的事项对你不发生不利效力，因此无需将这些诉讼移转给你，以免你因他人的行为而承担负担。是否更换代理人，应由裁判官审查裁断。

<a id="3.3.27.1"></a>**1.** 若原告一方达成诉讼和解，我们认为，被告所作的判决清偿担保即告触发；内拉提乌斯与尤利安也赞同此说，现行法亦如此，但须以委托人已经接受担保为前提。即使担保是由代理人接受，随后诉讼又移转给委托人，更妥当的看法仍是担保被触发，且基于该担保的诉权从代理人移转给委托人。若诉讼从委托人或一名代理人移转给另一名代理人，马尔凯鲁斯也毫不怀疑担保将被触发。这些看法是正确的。即使担保是针对代理人而被触发，也应向委托人授予基于要式承诺的准诉权，而原有的直接诉权则应完全消灭。
