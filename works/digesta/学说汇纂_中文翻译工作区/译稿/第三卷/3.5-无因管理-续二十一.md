# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.46"></a>3.5.46　保罗《判决集》第一卷

<a id="3.5.46.pr."></a>**序言（pr.）** 无因管理之诉应授予有利益通过该诉讼主张权利之人。

<a id="3.5.46.1"></a>**1.** 无论某人提起或被提起直接之诉还是准诉讼，都没有区别；因为在不采用程式诉讼的特别审判程序中，这种细分并无必要，尤其是两种诉讼具有相同的效力和效果。

### <a id="3.5.47"></a>3.5.47　帕比尼安《疑问集》第三卷

即使姐妹不知情，若其兄弟在管理她的事务时从丈夫处取得了嫁资的要式承诺，丈夫也可以依法依无因管理之诉起诉该兄弟，以使自己获得免责。

### <a id="3.5.48"></a>3.5.48　阿非利加努斯《疑问集》第八卷

如果买受人转售某物，而该物是我作为卖方出售的奴隶从我处窃取的，且后来该物已不复存在，那么，应准许我就其价款提起无因管理之诉。这与下列情形相同：你误以为某事务属于自己而加以管理，实际上该事务属于我。反过来说，如果你误以为属于我的遗产其实属于你，便用自己的财物向受遗赠人履行遗赠，而我因该项履行而免责，那么，你也可以对我提起无因管理之诉。
