# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.35"></a>3.3.35　乌尔比安《评告示》第九卷

<a id="3.3.35.pr."></a>**序言。** 有些人即使没有委任，也可以起诉；他们也应当承担辩护责任。例如，子女即使仍受家父权支配，父母、兄弟姐妹、姻亲以及被释奴，也都包括在内。

<a id="3.3.35.1"></a>**1.** 主人可以通过代理人指控被释奴忘恩负义；被释奴也可以通过代理人答辩。

<a id="3.3.35.2"></a>**2.** 不仅在他人请求授予诉权时，在请求作出先决裁断或发布令状时亦然；若有人请求就遗赠或可能发生的损害提供担保，也应在有管辖权的法庭、同一行省内为不在场者辩护。反之，若要强迫某人从罗马前往另一行省，或从某行省前往另一行省为人辩护，则过于严苛。

<a id="3.3.35.3"></a>**3.** 所谓辩护，是指为委托人做其本人在诉讼中会做的事，并提供适当担保。除提供担保这一点外，不应使代理人的处境比委托人更为不利。除担保事项外，代理人接受诉讼，即视为已经履行辩护义务。因此，尤利安曾讨论：是否应强制代理人接受诉讼，还是只需使关于未予辩护的担保条款发生效力即可。尤利安在《学说汇纂》第三卷中写道，应强制代理人接受诉讼；但若经审查具体情由后，他拒绝代理诉讼，或因正当理由被撤换，则属例外。代理人若允许他人取得占有，也视为履行了辩护义务，例如有人请求就可能发生的损害或遗赠提供担保时，

### <a id="3.3.36"></a>3.3.36　保罗《评告示》第八卷

又如在新工程告知程序中。代理人若允许奴隶因诺克萨责任而被带走，也视为履行辩护义务；但在上述所有情形中，他都应提供担保，保证委托人将追认其行为。

### <a id="3.3.37"></a>3.3.37　乌尔比安《评告示》第九卷

<a id="3.3.37.pr."></a>**序言。** 代理人应代为辩护的诉讼包括所有诉讼，甚至包括依法不对继承人提起的诉讼。

<a id="3.3.37.1"></a>**1.** 因此，有人问：如果对方提起多项诉讼，而有数名辩护人分别愿意接受其中一项，是否可以认为该人已获适当辩护？尤利安说可以；庞波尼乌斯记载，我们也依此规则行事。

### <a id="3.3.38"></a>3.3.38　乌尔比安《评告示》第四十卷

但不能走到这一步：例如，对方请求一万，而有两名辩护人各自准备只为其中五千提供辩护，此种安排不应获准。
