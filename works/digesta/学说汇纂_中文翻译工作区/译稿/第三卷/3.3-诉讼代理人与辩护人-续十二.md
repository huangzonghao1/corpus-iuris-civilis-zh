# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.43"></a>3.3.43　保罗《评告示》第九卷

<a id="3.3.43.pr."></a>**序言。** 哑者和聋者，只要能够通过某种可行方式作出委任，就不被禁止指定代理人；或许他们自己也可以被指定为代理人，但仅限于管理事务，而非代为起诉。

<a id="3.3.43.1"></a>**1.** 判断某人是否可以委任代理人时，应审查其是否未被禁止指定代理人，因为本告示属于禁止性告示。

<a id="3.3.43.2"></a>**2.** 在公益诉讼中，某人虽以公众一员的身份起诉，但不应被强制作为代理人为他人提供辩护。

<a id="3.3.43.3"></a>**3.** 某人为在场之人申请指定保佐人的，只有在成年人同意时才会受理；若申请对象不在场，申请人必须提供担保，保证该人将追认其行为。

<a id="3.3.43.4"></a>**4.** 代理人不履行辩护义务的处罚是：驳回其诉权。

<a id="3.3.43.5"></a>**5.** 代理人提起诉讼时，若不在场者的奴隶在场，阿提利基努斯说，应由该奴隶提供担保，而非代理人。

<a id="3.3.43.6"></a>**6.** 某人原本不必为不在场者辩护，但若其为了代不在场者辩护而提供了判决清偿担保，就应强制代理人接受诉讼，以免已收受担保的一方受骗；因为原本不必辩护的人，提供担保后即会被强制辩护。拉贝奥认为应审查具体情由后酌情处理：如果时间拖延会使原告受损，就应强制代理人接受诉讼；但若姻亲关系已经解除、双方发生仇怨，或不在场者的财产已开始由他人占有，

### <a id="3.3.45"></a>3.3.45　保罗《评告示》第九卷

<a id="3.3.45.pr."></a>**序言。** 则不得强制代理人接受诉讼。不过，萨宾努斯认为，裁判官无权强迫某人为他人辩护；原告只能依据未予辩护的要式承诺提起诉讼。但是，如果代理人有正当理由拒绝接受诉讼，保证人就不承担责任，因为任何善良人都不会认为应强迫提出正当理由的人为他人辩护。如果代理人未提供正式担保，而对方只是信赖其作出的非正式承诺，也应作同样处理。

<a id="3.3.45.1"></a>**1.** 某人虽为公共利益行事，同时也维护私人利益的，经审查具体情由后，可以指定代理人；此后他人再行起诉的，将被抗辩驳回。

<a id="3.3.45.2"></a>**2.** 若对代理人发出了新工程告知，而代理人援引“不得以暴力阻挠其施工”的令状，尤利安说，他应承担辩护人的职责，无须提供委托人将追认其行为的担保。即使他已经提供担保，尤利安也说，我仍看不出在何种情况下该担保会被触发。
