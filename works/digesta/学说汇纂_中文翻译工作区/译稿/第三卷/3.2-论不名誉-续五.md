# 第三卷

## 3.2　论被标记为不名誉者（续）

### <a id="3.2.14"></a>3.2.14　保罗《评告示》第五卷

奴隶的主人曾以该奴隶为名提起诺克萨诉讼，后来又将同一奴隶释放并立为继承人；若此人在同一诉讼中被判罪，不会因此成为不名誉者，因为他并非以本人名义被判罪；毕竟，诉讼最初并未对他本人提起。

### <a id="3.2.15"></a>3.2.15　乌尔比安《评告示》第八卷

妇女以腹中胎儿名义，凭借诬诈被准许占有遗产，并声称自己已经怀孕的，会被标记为不名誉者，

### <a id="3.2.16"></a>3.2.16　保罗《评告示》第八卷

——但她其实并未怀孕，或者胎儿是与他人所受孕的。

### <a id="3.2.17"></a>3.2.17　乌尔比安《评告示》第八卷

因为欺骗裁判官的人理应受到惩戒。不过，只有在她属于自权人时这样做，才会被标记为不名誉者。

### <a id="3.2.18"></a>3.2.18　盖尤斯《评行省告示》第三卷

因错误认识而受骗的妇女，不得视为以诬诈方式取得占有。

### <a id="3.2.19"></a>3.2.19　乌尔比安《评告示》第八卷

只有经裁断认定她是以诬诈为目的而获准占有的妇女，才会被标记为不名誉者。对父亲也应适用同一规则：若其出于诬诈目的，允许自己权力下的女儿以腹中胎儿名义取得占有，也应如此处理。

### <a id="3.2.20"></a>3.2.20　帕皮尼安《答复集》第一卷

行省总督在判决中说：“你似乎以狡猾的设计成为控告的煽动者。”这句话施加的更像是羞辱，而非不名誉污名；因为劝促他人提出控告的人，并非以委托人身份行事。
