# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### 3.5.5　乌尔比安《评告示》第十卷（续）

<a id="3.5.5.8"></a>**8.** 如果我管理了你儿子或奴隶的事务，应当考察我能否对你提起无因管理之诉。依我之见，应采纳拉贝奥所作、庞波尼乌斯在《评告示》第二十六卷中赞同的区分：如果我是为了你而管理其特有产事务，你应对我负责；但如果我是出于与你儿子或奴隶的情谊，或是为了他们本人的利益而管理事务，则对父亲或主人只应准许我在特有产范围内提起诉讼。即使我误以为他们是自权人，也适用同一规则。又如，我为你儿子购买了一个并非必需的奴隶，而你予以追认，庞波尼乌斯也写道，追认并不产生效力。他还补充认为，即使特有产中没有财物——例如对父亲或主人所负债务已超过特有产价值——也应允许对父亲提起诉讼，但仅限于父亲因我的管理而增加的财产利益。

<a id="3.5.5.9"></a>**9.** 如果我管理了一个自由人的事务，而此人基于善意为你服役：若我误以为他是你的奴隶而进行管理，庞波尼乌斯写道，对于应归属于你的特有产，我可以对你提起无因管理之诉；对于应归属于该自由人本人的财物，则应对其本人起诉。但如果我知道他是自由人，对于归属于他的财物，我可以对他起诉；对于归属于你的财物，我可以对你起诉。

<a id="3.5.5.10"></a>**10.** 如果我误以为提提乌斯的奴隶属于他本人，实际上该奴隶属于塞姆普罗尼乌斯，却给付金钱以避免该奴隶被杀，如庞波尼乌斯所说，我可以对塞姆普罗尼乌斯提起无因管理之诉。
