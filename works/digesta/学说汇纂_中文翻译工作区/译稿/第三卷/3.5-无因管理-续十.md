# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.13"></a>3.5.13　乌尔比安《评告示》第十卷

如果主张某家子曾管理事务，那么，也应准许对其家父提起诉讼；无论该家子有特有产，还是其管理所得已用于家父的事务，均应如此。女奴管理事务的情形，也同样处理。

### <a id="3.5.14"></a>3.5.14　保罗《评告示》第九卷

庞波尼乌斯在《学说汇纂》第二十六卷中说，管理事务时，应考察每一阶段开始时当事人的身份状况。他举例说：如果我开始管理一名未成年人的事务，而在管理期间他已达到法定成年年龄，怎么办？又如我开始管理奴隶或家子的事务，而在此期间该人获释为自由人或成为自权人，怎么办？我也认为这一看法更为妥当；但如果我起初是以处理一项事务为目的而介入，后来在对方已成年、获释或成为家父之后，又以新的意思开始处理另一事项，则属例外。因为在这种情形下，可以视为管理了数项事务；应当根据各人的身份状况确定适用的诉讼，并调整判决责任。

### <a id="3.5.15"></a>3.5.15　保罗《评普劳提乌斯》第七卷

即使有人管理我的事务，通常也不因此成为多项事务，而是构成一个整体的法律关系；除非他从一开始只为办理一项事务而介入，并打算办妥后即退出。在这种情形下，如果他后来基于新的意思又开始处理其他事项，那就是另一个法律关系。

### <a id="3.5.16"></a>3.5.16　乌尔比安《评告示》第三十五卷

一个人在奴隶身份期间所实施的行为，获释后不必就此向他人交代。但如果两者相互关联，以致无法将其在奴隶身份期间处理的事务与获释后处理的事务分别核算，那么，可以确定的是，在委任之诉或无因管理之诉中，也会一并审理其奴隶身份期间所处理的事项。举例说：他在奴隶身份期间购入一块土地，并在其上建造公寓楼；该楼后来倒塌；获释后，他又出租土地。在无因管理之诉中，只审理出租土地这一事项，因为对于其较早时期的管理，诉讼中至多只能审理为核算其自由身份期间所管理事务所不可缺少的部分。

### <a id="3.5.17"></a>3.5.17　保罗《评告示》第九卷

普罗库鲁斯和佩加苏斯认为，在奴隶身份期间开始管理事务的人，也必须遵守诚信。因此，如果由他人管理其事务时本可保全某项利益，那么，未曾向自己追偿的人就应在无因管理之诉中承担相应责任；但以其特有产中有可通过留置而保全该利益的财物为限。涅拉提乌斯也持同样意见。
