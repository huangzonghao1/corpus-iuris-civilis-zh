# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.7"></a>3.5.7　乌尔比安《评告示》第十卷

<a id="3.5.7.pr."></a>**序言（pr.）** 如果事务管理人属于无需以委任为前提者，那么，在债务人提出追认担保后，他仍未起诉债务人，这一点可以归责于他；但以他能够轻易提供担保为限。至少，就人身债权而言，这一点毫无疑问。因此，即使债务人所负债务的原因因确定期限届满而终止，且债务人因期限届满而免责，事务管理人仍须依无因管理之诉承担责任。马尔凯鲁斯写道，对于继承人本不承担责任的那种情形，也应作同样解释。

<a id="3.5.7.1"></a>**1.** 又如，我在管理你的事务或市镇事务时，以不正当方式起诉请求取得你或市镇的土地，并因此获得超过应得数额的孳息，那么，即使我原本无权提出该诉讼，也应将这些孳息交还给你或市镇。

<a id="3.5.7.2"></a>**2.** 如果法官以任何方式没有考虑抵销，可以提起反向之诉；但如果抵销请求经审查后已被驳回，更妥当的见解是，不得再以仿佛该事项已经判决为由提起反向之诉，因为应当提出既判力抗辩。

<a id="3.5.7.3"></a>**3.** 尤利安在《学说汇纂》第三卷中讨论：两个合伙人中，一人禁止我管理事务，另一人没有禁止；我能否对未禁止者提起无因管理之诉？他对此有所疑虑，因为如果准许对其起诉，就势必要使禁止者也受到影响；但若因另一人的行为而使未禁止者免责，也是不公平的。况且，如果其中一名合伙人禁止我向另一名合伙人出借款项，我仍会使实际借款的合伙人承担债务。我认为，应当依尤利安的意见，认定针对未禁止者的无因管理之诉仍然存在；但禁止管理的合伙人不得因此遭受任何损害，无论损害是通过其合伙人造成，还是由其本人造成。

### <a id="3.5.8"></a>3.5.8　斯凯沃拉《疑问集》第一卷

庞波尼乌斯写道，如果我认可了你所管理的事务，即使你管理得很差，你仍不因无因管理之诉而对我承担责任。因此，应当考察：在我是否追认尚有疑问时，无因管理之诉是否取决于此？因为该诉一旦发生，怎能仅凭单方意愿将其消灭？不过，庞波尼乌斯认为，上述说法成立的条件是你没有欺诈。斯凯沃拉则说：不；即使我认可了该事务，无因管理之诉仍然存在。所谓你不对我承担责任，是因为我不能否认自己已经认可的事项。正如有利管理的事务必须由法官视为已经获准，一切经本人认可的事项也应如此。否则，如果我一经认可便不再有无因管理之诉，那么，假如他向我的债务人收取了款项，而我又认可了此事，我该如何收回款项？如果他已经将物品出售，又该怎么办？最后，如果他本人支出了费用，又该如何取回？毕竟双方之间并无委任关系。因此，即使在追认之后，无因管理之诉仍然存在。
