# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.18"></a>3.5.18　保罗《评涅拉提乌斯》第二卷

<a id="3.5.18.pr."></a>**序言（pr.）** 然而，即使他在特有产中一无所有，他仍属自然债务人；若后来取得财物，只要他继续处理同一事务，就应当在后来向自己清偿。这如同某人原先负有一项受期限限制的诉讼责任，即使期限届满，仍可被强制依无因管理之诉履行该责任。

<a id="3.5.18.1"></a>**1.** 我们的斯凯沃拉说，他认为萨比努斯所说“应当从起初核算”应理解为：须查明其最初成为自由人时还剩下什么；而不是将其奴隶身份期间的欺诈或过失重新纳入其责任。因此，如果查明他在奴隶身份期间以不当方式花用了特有产中的钱，他便可免责。

<a id="3.5.18.2"></a>**2.** 如果我命令一名自由人做某事，而此人基于善意一直在我这里服役，拉贝奥说，我与其间不成立委任之诉，因为他并非出于自由意志履行我交办的事项，而是仿佛受奴隶身份的强制。因此，应有无因管理之诉；因为他具有管理我事务的意思，而且他属于我能够使其承担债务责任之人。

<a id="3.5.18.3"></a>**3.** 我不在场时，你管理我的事务；你不知情而买下了属于我的物，并通过时效取得了该物。你不因此依无因管理之诉负有向我返还该物的责任。但如果你在通过时效取得该物之前得知它属于我，就应安排一人以我的名义向你主张该物，使该物归还给我，同时使你能够援用关于追夺担保的要式承诺。你这样安排并不构成欺诈；你之所以应当这样做，正是为了避免依无因管理之诉对我承担责任。

<a id="3.5.18.4"></a>**4.** 依无因管理之诉，我们不仅应交付从他人资金取得的本金及利息，也应交付本来能够取得的利息。反之，对于我为管理他人事务而投入的自有资金，我已支付的利息或本来能够取得的利息，也可依无因管理之诉请求偿还。

<a id="3.5.18.5"></a>**5.** 提提乌斯被敌人俘获期间，我管理了他的事务；后来他返回。即使我管理事务时这些事务尚无事务本人，我仍享有无因管理之诉。

### <a id="3.5.19"></a>3.5.19　乌尔比安《评告示》第十卷

但如果某人在敌方被俘期间死亡，那么，其承受人既可以提起无因管理的直接之诉，也可以提起反向之诉；针对其承受人，亦同样可以提起这两种诉讼。
