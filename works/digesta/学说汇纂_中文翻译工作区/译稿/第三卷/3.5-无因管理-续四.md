# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### 3.5.5　乌尔比安《评告示》第十卷（续）

<a id="3.5.5.5"></a>**5.** 如果某人管理我的事务并非出于为我办事，而是为了自己的利益，拉贝奥写道，他管理的更像是自己的事务，而非我的事务——因为以掠夺为目的介入的人，谋求的是自己的利益，而非我的便利。尽管如此，他仍应承担无因管理之诉的责任。不过，如果他在处理我的财物时有所支出，则其对我享有诉权的范围，不是其本人所受损失的数额——因为他不当地介入了我的事务——而仅限于我因此增加的财产利益。

<a id="3.5.5.6"></a>**6.** 如果某人只是处理自己的事务，却把自己的财产当作我的财产来管理，那么双方均不产生诉权，因为诚信原则不允许这样做。但如果他将自己的事务和我的事务都作为我的事务来管理，则他应就我的事务承担责任。拉贝奥说，同样，如果我委托某人管理属于我和你共有的事务，而他明知该事务也属于你，却一并管理了你的部分，那么他应依无因管理之诉对你负责。

<a id="3.5.5.7"></a>**7.** 如果某人将我的事务作为我的奴隶所管理的事务来处理，但实际上他是我的被释奴或自由出生者，则可以提起无因管理之诉。
