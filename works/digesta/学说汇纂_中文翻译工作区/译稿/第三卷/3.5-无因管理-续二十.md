# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.44"></a>3.5.44　乌尔比安《意见集》第四卷

<a id="3.5.44.pr."></a>**序言（pr.）** 为他人事务作出的有利支出，可以依无因管理之诉请求偿还；其中也包括为按等级晋升、适当取得公职荣誉而支出的费用。

<a id="3.5.44.1"></a>**1.** 依遗嘱无条件取得自由的自由释奴，不必就其主人生前管理的事务交代账目。

<a id="3.5.44.2"></a>**2.** 提提乌斯认为，其姐妹依遗嘱成为死者继承人，遂替遗产债权人支付款项。虽然他是怀着管理姐妹事务的意思这样做，但就事实而言，在遗嘱被撤销后，他管理的是死者之子的事务；若无该遗嘱，这些儿子本会作为自权继承人继承父亲。鉴于不应使他遭受损失，准许他依无因管理之诉请求偿还。

### <a id="3.5.45"></a>3.5.45　阿非利加努斯《疑问集》第七卷

<a id="3.5.45.pr."></a>**序言（pr.）** 你委托我儿子替你购买一块土地；我得知此事后，亲自替你买下该土地。我认为，关键在于我购买时的意思：如果我购买是因为我知道该土地对你有必要，而且你确实想要买下它，那么我们之间应成立无因管理之诉；这与双方之间根本没有委任，或者你委任提提乌斯购买、而我因能更便利地办妥此事便亲自购买，情形相同。反之，如果我购买是为了避免我儿子依委任之诉承担责任，那么，更妥当的看法是，我可以代其依委任之诉向你请求；而你可以对我提起特有产之诉。因为，假如提提乌斯接受了这项委任，而我为了使他不因此承担责任而亲自购买，我可以依无因管理之诉起诉提提乌斯；提提乌斯可以依委任之诉起诉你；你也可以依委任之诉起诉他。如果你委托我儿子为你提供保证，而我代替他作了保证，亦同。

<a id="3.5.45.1"></a>**1.** 如果有人主张，你曾委托提提乌斯为你提供保证，而提提乌斯因某种原因无法提供保证，我为免除其责任而代为提供保证，那么，我享有无因管理之诉。
