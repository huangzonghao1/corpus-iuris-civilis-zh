# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.30"></a>3.5.30　帕比尼安《答复集》第二卷

<a id="3.5.30.pr."></a>**序言（pr.）** 某人委托一名自由释奴或朋友借入一笔款项；债权人依其书信与该人订约，并由一名保证人介入。即使该笔钱并未用于委托人的事务，仍应准许债权人或保证人对委托人提起无因管理之诉；此规则以店铺经理诉讼为参照。

<a id="3.5.30.1"></a>**1.** 我在管理塞姆普罗尼乌斯事务时，不知情地也处理了提提乌斯的事务；因此，我也须就这部分事务向塞姆普罗尼乌斯负责。但法官依其职权必须要求为我提供针对提提乌斯的赔偿担保；提提乌斯可对我提起诉讼。监护人的情形也适用同一规则。

<a id="3.5.30.2"></a>**2.** 某人的诉讼已经提请法院审理，被告却弃诉；其朋友主动代为陈述，并向法官说明被告未到庭的理由。若法院作出对未到庭者不利的判决，而该朋友本人没有提起上诉，他似乎不构成过失。乌尔比安注称：这是正确的，因为被判败诉的是怠于出庭者。不过，如果朋友代未到庭者辩护，却由朋友本人败诉并拟依无因管理之诉请求偿还，那么，如果他本可上诉而没有上诉，该遗漏可以归责于他。

<a id="3.5.30.3"></a>**3.** 管理他人事务的人，须就扣除必要费用后剩余的款项支付利息。

<a id="3.5.30.4"></a>**4.** 遗嘱人希望自由释奴取得一笔确定数额的钱，用于建造纪念墓碑的费用。若实际支出超过该数额，便不得依无因管理之诉或遗嘱信托请求继承人支付超出部分，因为遗嘱人的意思已限定支出上限。

<a id="3.5.30.5"></a>**5.** 如果监护人的继承人是一名未成年家子，他不对其父亲作为监护人管理女受监护人财产的事项承担责任；应当以监护人本人的名义对其提起无因管理之诉。

<a id="3.5.30.6"></a>**6.** 母亲依父亲的意思并出于亲情管理儿子的事务，但她无权自行承担风险，为诉讼之目的指定代理人；因为她既不能适当地以儿子的名义起诉，也不能处分儿子的财产，更不能通过受领款项使该未成年人的债务人免责。

<a id="3.5.30.7"></a>**7.** 一人辩护涉及共有水权的诉讼，判决作出后土地一方胜诉；但在该共同诉讼中支付了必要且合理费用的人，享有无因管理之诉。
