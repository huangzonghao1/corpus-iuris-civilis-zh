# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.15"></a>3.3.15　乌尔比安《评告示》第八卷

<a id="3.3.15.pr."></a>**序言。** 委托人在争讼程序确定前死亡，而其已为代理人提供判决清偿担保的，应强制代理人接受诉讼；但以委托人是在代理人知情且代理人未表示反对的情况下作出该安排为限。若情形并非如此，却使不知情的代理人承担责任，实在有违公平；不过，关于未予辩护的担保条款仍会发生效力。

<a id="3.3.15.1"></a>**1.** 为提起共有物分割之诉而指定的代理人，应视为同时受托起诉和应诉；为此应分别提供两项担保。

### <a id="3.3.16"></a>3.3.16　保罗《评告示》第八卷

诉讼正式受理前，当事人可以自由更换代理人，也可以由本人亲自接受诉讼。

### <a id="3.3.17"></a>3.3.17　乌尔比安《评告示》第九卷

<a id="3.3.17.pr."></a>**序言。** 诉讼正式受理后，作为被告而指定了代理人的人，经审查具体情由后，可以更换代理人；只要代理人尚在世且仍在本城，也可以将诉讼转由本人承受。

<a id="3.3.17.1"></a>**1.** 不仅指定代理人的本人可以这样做，其继承人及其他概括继受人也可以。

<a id="3.3.17.2"></a>**2.** 审查具体情由时，除前文所述可不强迫代理人接受诉讼的事由外，还应考虑年龄。
