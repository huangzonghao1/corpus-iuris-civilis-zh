# 第三卷

## 3.2　论被标记为不名誉者（终）

### <a id="3.2.21"></a>3.2.21　保罗《答复集》第二卷

卢基乌斯·提提乌斯以盖乌斯·塞尤斯对自己实施侵辱为由提出控告，并就此向禁卫军长官提交证言。禁卫军长官不采信该证言，裁定卢基乌斯·提提乌斯并未遭盖乌斯·塞尤斯侵辱。我询问：证言未被采信的证人，是否会因作伪证而被视为不名誉者？保罗答复：没有任何已述事实足以说明这些人应被视为不名誉者；毕竟，不应因针对他人所作的判决而使第三人承受不利，无论该判决正确与否。

### <a id="3.2.22"></a>3.2.22　马尔凯鲁斯《公审程序论》第二卷

遭受杖责本身不会导致不名誉污名；真正导致污名的是其所以受到杖责的原因——但前提是该原因属于会使被判罪者承受不名誉污名的事由。其他种类的刑罚也适用同一规则。

### <a id="3.2.23"></a>3.2.23　乌尔比安《评告示》第八卷

父母、男女子女，以及其他宗亲或血亲，应依亲情和本人意愿，按照各自所愿的方式服丧。未为这些亲属服丧的人，不会被标记为不名誉者。

### <a id="3.2.24"></a>3.2.24　乌尔比安《评告示》第六卷

塞维鲁皇帝以敕答确认：妇女在奴隶身份期间以卖淫所得的收入，并不损害其名誉。

### <a id="3.2.25"></a>3.2.25　帕皮尼安《问题集》第二卷

<a id="3.2.25.pr."></a>**序言。** 已决定，即使儿子被遗嘱排除继承，也应为纪念其父而服丧。对于母亲也适用同一法律规则，即使其遗产不归儿子继承亦然。

<a id="3.2.25.1"></a>**1.** 某人在战争中阵亡的，即使其遗体未被发现，也应为之服丧。
