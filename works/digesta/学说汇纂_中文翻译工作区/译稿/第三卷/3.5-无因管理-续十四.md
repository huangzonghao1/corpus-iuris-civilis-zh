# 第三卷

## 3.5　论管理他人事务（无因管理）（续）

### <a id="3.5.26"></a>3.5.26　莫德斯蒂努斯《答复集》第二卷

<a id="3.5.26.pr."></a>**序言（pr.）** 两名兄弟中，一人已达到成年年龄，另一人尚未成年；他们共同拥有乡村地产。年长的兄弟在共有的山林地产上、祖居所在之处建造了宏大的建筑。后来，他与兄弟分割该山林地产时，弟弟已经达到法定成年年龄；年长者以自己改善了共有财产为由，要求弟弟偿还其支出。赫雷尼乌斯·莫德斯蒂努斯答复说：对于并非出于任何迫切需要、仅为享乐而作的支出，提问之人不享有诉权。

<a id="3.5.26.1"></a>**1.** 我曾答复说：如果提提乌斯出于亲情抚养了其姐妹的女儿，他不得以此为由对她提起诉讼。

### <a id="3.5.27"></a>3.5.27　雅沃勒努斯《卡西乌斯论》第八卷

如果某人依提提乌斯的委任管理塞尤斯的事务，那么，此人依委任之诉对提提乌斯承担责任；诉讼标的应按塞尤斯与提提乌斯各自的利益确定。提提乌斯的利益，则是他须向塞尤斯承担的数额；他对塞尤斯所负的责任，可能基于委任，也可能基于无因管理。提提乌斯可以对受其委托管理他人事务之人提起诉讼，而且即使他本人尚未向事务本人支付任何款项，也可提起；因为他已经因该责任而遭受损失。

### <a id="3.5.28"></a>3.5.28　卡利斯特拉图斯《告示警示篇》第三卷

父亲在遗嘱中为未出生的遗腹子指定监护人；该监护人在遗腹子出生前暂时管理了监护事务，而遗腹子最终没有出生。此时，应对该人提起无因管理之诉，而非监护之诉。若遗腹子出生，则应提起监护之诉；该诉应涵盖两个期间：婴儿出生之前其所管理的期间，以及婴儿出生之后其所管理的期间。

### <a id="3.5.29"></a>3.5.29　尤利安《学说汇纂》第三卷

本案所询问的事实是：某市依议员团决议指定一人为采购黑麦的管理人，又为其指定一名副管理人；该副管理人将其他谷物掺入黑麦，致使黑麦受损，而为公共用途购买黑麦的价款因此由管理人承担。管理人可以提起何种诉讼以弥补因此遭受的损失？瓦莱里乌斯·塞维鲁答复说，应准许监护人对共同监护人提起无因管理之诉。他还答复说，同样的诉权也应准许一名官员针对另一名官员行使，但以其不知悉欺诈为限。依此，对副管理人也应作相同处理。
