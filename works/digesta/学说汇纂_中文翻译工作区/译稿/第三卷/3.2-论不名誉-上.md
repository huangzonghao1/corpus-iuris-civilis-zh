# 第三卷

## <a id="3.2"></a>3.2　论被标记为不名誉者

### <a id="3.2.1"></a>3.2.1　尤利安《评告示》第一卷

裁判官的告示规定：“下列人员被标记为不名誉者：因不名誉事由而被皇帝或有权对此作出决定的人从军队中革退者；为从事舞台表演或朗诵职业而登台者；从事拉皮条者；在公审程序中被判定实施诬告或串通妨碍追诉行为者；以本人名义因盗窃、暴力劫夺财物、侵辱、恶意欺诈或欺骗而被判罪，或者与对方和解者；以本人名义在合伙、监护、委任或寄托之诉中被判罪，且该判决并非基于反诉者；女婿死亡后，明知其已死亡，却在通常为亡夫服丧的期间尚未届满、且其女儿尚未为丈夫服丧期满时，将自己权力下的女儿嫁出者；明知某女子受他人家父权支配，未经其权力支配者许可而与之结婚者；允许自己权力下之人与上述女子结婚者；以及未经自己权力支配者许可，以本人名义，或以自己权力下男子、女子的名义，在同一时期安排两次订婚或两桩婚姻者。”

### <a id="3.2.2"></a>3.2.2　乌尔比安《评告示》第六卷

<a id="3.2.2.pr."></a>**序言。** 裁判官所说“凡从军队中被革退者”，应理解为被革退的普通士兵，或直至百夫长、步兵大队长、骑兵队长、军团长，以及步兵大队或军团的护民官为止的任何军人。庞波尼乌斯还说，即使统率军队者佩有执政官等级的标志，只要是被皇帝以不名誉为由革退，也会受到这一污名。因此，统帅在统率军队期间被革退，也会被标记为不名誉者；皇帝革退军人并明确补充说是因不名誉而革退时，依裁判官告示将其标记为不名誉者，毫无疑问。不过，若皇帝并未表示不满，只是为他任命了继任者，则不在此限。

<a id="3.2.2.1"></a>**1.** 这里所说的军队，并非仅指一个步兵大队或一个骑兵队，而是指众多军人组成的部队。我们称受皇帝委任、统率一个或数个军团及其辅助部队的人为军队统帅。不过，在此也应将从某一支军人队伍中被革退者，视同从军队中被革退者。

<a id="3.2.2.2"></a>**2.** 告示之所以加上“因不名誉而被革退”，是因为革退有多种类型：一种是荣誉退伍，即军人服满兵役后退伍，或者皇帝提前恩准其退伍；一种是因健康状况而免除军役负担的病退；还有一种是不名誉退伍。只有在作出革退决定的人明确说明其系因不名誉而革退时，才构成不名誉退伍；因为他必须始终说明军人退伍的原因。但是，即使没有补充说明革退是因不名誉，若将其除籍——也就是剥去其军人标志——也会使其成为不名誉者。此外还有第四种退伍：有人为逃避公共负担而入伍；此种退伍不损害其名誉，这一点在皇帝敕答中已被屡次确认。
