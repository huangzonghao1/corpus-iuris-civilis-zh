# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.51"></a>3.3.51　乌尔比安《评告示》第六十卷

<a id="3.3.51.pr."></a>**序言。** 未满二十五岁的人若担任辩护人，在依法可以请求恢复原状的情形下，不属于适格辩护人；因为该未成年人本人及其保证人也可以获得恢复原状救济。

<a id="3.3.51.1"></a>**1.** 既然辩护人须承担与被告相同的地位，丈夫的辩护人就不得被判令承担超过丈夫本人可能承担的责任。

<a id="3.3.51.2"></a>**2.** 接受辩护的人，即使极为富有，

### <a id="3.3.52"></a>3.3.52　保罗《评告示》第五十七卷

即使具有执政官等级，

### <a id="3.3.53"></a>3.3.53　乌尔比安《评告示》第六十卷

若不准备提供担保，也不视为已经履行辩护义务。

### <a id="3.3.54"></a>3.3.54　保罗《评告示》第五十卷

<a id="3.3.54.pr."></a>**序言。** 妇女、军人、因公务而将离开的人、身患长期疾病的人、即将担任官职的人，以及不得被强制违背其意愿接受诉讼的人，都不属于适格辩护人。

<a id="3.3.54.1"></a>**1.** 在某地管理过监护事务的监护人，也必须在同一地点获得辩护。

### <a id="3.3.55"></a>3.3.55　乌尔比安《评告示》第六十五卷

代理人若为自身利益而受任，委托人不得在提起诉讼或受领款项方面优先于该代理人；因为代理人以本人名义享有准诉权，依法提起这些诉讼并无不当。

### <a id="3.3.56"></a>3.3.56　乌尔比安《评告示》第六十六卷

受委任请求返还动产的代理人，可以适当地提起出示之诉。

### <a id="3.3.57"></a>3.3.57　乌尔比安《评告示》第七十四卷

<a id="3.3.57.pr."></a>**序言。** 某人指定代理人立即起诉的，应理解为也允许代理人日后继续进行该诉讼。

<a id="3.3.57.1"></a>**1.** 某人若已放弃提出代理人身份抗辩，就不能事后反悔再提出该项抗辩。

### <a id="3.3.58"></a>3.3.58　保罗《评告示》第七十一卷

受委托自由管理事务的代理人，可以收取债款、更新债务，或者以其他给付替代原给付。

### <a id="3.3.59"></a>3.3.59　保罗《评普劳提乌斯》第十卷

也应认为，委任还包括替委托人向债权人清偿。

### <a id="3.3.60"></a>3.3.60　保罗《答复集》第四卷

以概括委任并不包括为解决争议而达成和解。因此，如果委托人事后未追认该和解，就不得据此抗辩，阻止委托人行使其诉权。
