# 第三卷

## <a id="3.3"></a>3.3　论诉讼代理人与诉讼辩护人

### <a id="3.3.1"></a>3.3.1　乌尔比安《评告示》第九卷

<a id="3.3.1.pr."></a>**序言。** 代理人，是指依本人委任管理他人事务的人。

<a id="3.3.1.1"></a>**1.** 代理人可以受委任管理全部事务，也可以仅管理某一事务；委任可以当面作出，也可以通过使者或书信作出。尽管庞波尼乌斯在《评告示》第二十四卷中记载，有些人认为，接受单一事务委任者并非代理人；正如仅受托传递物品、书信或口信的人，也不严格称为代理人。但更为妥当的意见是，受委任处理单一事务的人也属于代理人。

<a id="3.3.1.2"></a>**2.** 代理制度极为必要，使得那些不愿或不能亲自处理自己事务的人，可以通过他人提起诉讼或应诉。
