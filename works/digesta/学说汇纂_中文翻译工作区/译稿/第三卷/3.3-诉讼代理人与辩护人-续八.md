# 第三卷

## 3.3　论诉讼代理人与诉讼辩护人（续）

### <a id="3.3.39"></a>3.3.39　乌尔比安《评告示》第九卷

<a id="3.3.39.pr."></a>**序言。** 代理人不仅应在诉讼、令状程序和要式承诺关系中为委托人辩护，在司法询问中也应如此；当其在法庭上受询问时，应就委托人本人须回答的所有事由作出答复。因此，若被询问委托人是否为继承人，代理人应当回答；无论他作出回答还是保持沉默，均应承担责任。

<a id="3.3.39.1"></a>**1.** 凡以他人名义提起任何诉讼的人，都应提供担保，保证与该事项有关之人将追认其行为。但有时，代理人虽以本人名义起诉，仍须提供追认担保；庞波尼乌斯在《评告示》第二十四卷中如此记载。例如，原告向代理人提出宣誓问题，代理人宣誓称应当向不在场的委托人交付某物；由于该代理人因自己的宣誓而以本人名义提起此诉——毕竟此诉并非委托人可以提起——他仍须提供追认担保。若代理人获得了定期给付的约定，并据此起诉，毫无疑问也应提供追认担保；庞波尼乌斯亦如此记载。

<a id="3.3.39.2"></a>**2.** 尤利安讨论：应提供担保保证仅由委托人追认，还是其他债权人也追认？他认为，只须就委托人追认提供担保；“与该事项有关之人”一语并不包括债权人，因为委托人本人也不负有此项担保义务。

<a id="3.3.39.3"></a>**3.** 父亲为追索嫁资而起诉的，应提供担保保证女儿将予追认；马尔凯鲁斯还记载，父亲也应为她辩护。
