<a id="34.3.7.5"></a>**5.**因此，尤利安提出：如果免债遗赠是由未成年人替补继承人留下，而未成年人随后收取了债务，遗赠是否消灭。既然确定，替补继承人所作遗赠中的未成年人承继了附条件受遗赠人的地位，那么，如果未成年人向债务人收取了债务，替补继承人就应依遗嘱之诉承担责任。

<!-- source-p 322 -->
<a id="34.3.7.6"></a>**6.**即使未成年人没有收取债务，只是已经提起诉讼，结论也相同：替补继承人负有义务，须放弃该诉讼请求。

<!-- source-p 323 -->
<a id="34.3.7.7"></a>**7.**同样，如果免债附有条件遗赠给债务人，而条件尚未成就时已经提起诉讼，甚至已经收取债务，那么即使后来留下免债遗赠，依据遗嘱提起的诉讼仍然存在。

<!-- source-p 326 -->
<a id="34.3.8.pr."></a>**序言。**我们不仅可以遗赠免除自己债务人的债务，也可以遗赠免除继承人或任何其他人的债务人的债务。

<!-- source-p 327 -->
<a id="34.3.8.1"></a>**1.**可以命令继承人在某一确定期间内不得向债务人请求；毫无疑问，在该期间内也不得免除该债务。如果债务人在此期间死亡，也不得在该期间内向其继承人请求。

<!-- source-p 328 -->
<a id="34.3.8.2"></a>**2.**须考察：在继承人被禁止请求的期间内，他能否请求利息或违约罚金。普里斯库斯和涅拉提乌斯认为，如果继承人提出请求，即违反遗嘱；这一意见是正确的。

<!-- source-p 329 -->
<a id="34.3.8.3"></a>**3.**如果遗赠写道：“我的继承人不得仅向卢基乌斯·提提乌斯请求”，而在卢基乌斯·提提乌斯在世时，继承人并未因试图向其追债而违反遗嘱，那么该遗赠不转归卢基乌斯·提提乌斯的继承人。凡遗赠所包含的事项与受领人身份不可分，例如人役地役权，不转归其继承人；若该事项并非与其身份不可分，则转归其继承人。

<!-- source-p 330 -->
<a id="34.3.8.4"></a>**4.**如果免债的文字是针对某项财产或债务关系作出的，其效果相当于禁止继承人向该债务人及其继承人请求；因此，补充提及债务人的继承人并无效力，正如若未包括债务人本人，该补充本来也不会发生效力。

<!-- source-p 331 -->
<a id="34.3.8.5"></a>**5.**某人被命令交出账目；如果他不提交账目，只交付余额，不应视为已经履行。

<!-- source-p 332 -->
<a id="34.3.8.6"></a>**6.**如果继承人被禁止起诉管理过死者事务的人，那么，若该管理人因欺诈或舞弊行为而负有债务，该债务似乎并未被预先遗赠；立遗嘱人看来也正是此意。因此，若继承人提起无因管理之诉，该管理人作为代理人依据遗嘱提起不确定之诉时，可以援用诈欺抗辩而被排除。

<!-- source-p 333 -->
<a id="34.3.8.7"></a>**7.**如果我曾向某人寄存财物、借用财物给他或将财物出质给他，或者某人因盗窃之债负有向我给付的义务，也都可以有效地将免债遗赠给该人。

如果债务人命令自己的继承人免除保证人的债务，是否应当使保证人免责？答称：应当。又有人问：既然继承人可因委任之诉被起诉，此遗赠是否无效，正如债务人将遗赠给自己的债权人的遗赠无效一样。答〔底本校勘记补作 *respondi*〕称：债务人遗赠给其债权人的情形，只有在债权人依据遗嘱而非原有债务起诉并无任何利益时，遗赠才无效。例如，提提乌斯委托梅维乌斯代其允诺给付金钱，之后又命令允诺受领人免除梅维乌斯；显然，对允诺人而言，免于要式允诺之债比先履行该债务、再提起委任之诉更有利。
