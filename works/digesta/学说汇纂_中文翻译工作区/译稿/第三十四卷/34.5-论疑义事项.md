<a id="34.5.7.pr."></a>**序言。**问题在于：遗腹子是否只有出生后才构成一个份额，还是即使没有出生也构成份额。我认为，较妥当的解释是：如果遗腹子没有出生，他完全不构成份额，全部遗产归你，犹如从一开始就将全部遗产留给你；如果遗腹子出生，你们便各自取得遗嘱留给自己的份额。例如，出生一人，你取得二分之一；出生两人，你取得三分之一；出生三人——因为也可能生下三胞胎——你取得四分之一。在我们这个时代，一名亚历山大的妇女塞拉皮娅曾被带到神圣哈德良皇帝面前，她一胎生下五名子女。不过，超过三名婴儿同胎出生通常被视为怪异之事。

<!-- source-p 573 -->
<a id="34.5.7.1"></a>**1.**某人指定数名继承人，并托付其中一人的诚信，令其在自己死亡时，将自己所得的遗产份额返还给一名由其自行选择的共同继承人。这项遗嘱信托确属有效；因为受托人无权自行决定是否返还，只能决定返还给谁。二者有重大区别：立遗嘱人若使其意欲课以义务之人可以自行决定是否给付，便是把给付本身置于该人的意愿之下；若先令其负有给付义务，再仅准其自由决定分配给谁，则不同。

<!-- source-p 574 -->
<a id="34.5.7.2"></a>**2.**有人问：如果共同继承人被指定的份额并不相等，受托人应将自己的份额平均返还给各人，还是依他们各自的继承份额返还。通说认为：如果立遗嘱人命令受托人在他人给付一定款项时返还该份额，而且命令他人平均给付，那么遗嘱信托也应平均返还；如果立遗嘱人表明该款项应按不等份额分配，且这些份额与继承份额相符，那么遗嘱信托也应依继承份额返还。

**特里福尼努斯：《论辩集》第二十一卷。**

<!-- source-p 580 -->
<a id="34.5.9.pr."></a>**序言。**某人有两个未适婚的儿子，并为最后死亡的儿子指定提提乌斯为替补继承人。两个未适婚儿子在船难中同时死亡。有人问，替补继承是否发生，遗产又归谁。我答复说：如果二人先后死亡，先死亡者死后，兄弟作为无遗嘱继承人继承其遗产；后死亡者死后，替补继承人继承。不过，在后一继承中，替补继承人也会取得先死亡儿子的遗产。至于本案，两人同时遇难，既然没有兄弟在另一人死后存活，是否应视为二人都是最后死亡者？还是应认为二人都不符合条件，因为判断谁是最后死亡者，要以另一人先死亡为前提？较应采纳前一种意见，即替补继承人为二人各自的继承人。即使某人只有一个儿子，为其指定在儿子最后死亡时承继的替补继承人，也不应认为该替补指定无效；而且，最近的宗亲即使是唯一一人、没有其他人在其之前，也仍可称为最近宗亲。本案亦然：由于两人均无另一人存活，二人既是最后死亡者，也是最先死亡者。〔*frater necessarius* 的句法关系及其与替补继承的关系仍需核对。〕

<!-- source-p 581 -->
<a id="34.5.9.1"></a>**1.**父亲与儿子在战争中同时死亡。母亲主张儿子较父亲后死，因而请求取得儿子的财产；父亲的宗亲则主张儿子先于父亲死亡。神圣哈德良皇帝认为，父亲先死亡。

<!-- source-p 582 -->

<!-- source-p 584 -->
<a id="34.5.9.4"></a>**4.**如果卢基乌斯·提提乌斯与其已达适婚年龄的儿子同时死亡，而该儿子是遗嘱中唯一指定的继承人，应推定儿子比父亲存活得更久，并依遗嘱成为继承人；儿子的遗产继而归其继承人，除非有相反证据。如果与父亲同时死亡的是未适婚的儿子，则应推定父亲存活得更久，除非同样证明相反事实。

<a id="34.5.10.pr."></a>**序言。**如果遗赠给我的亲属中最先登上卡比托利欧山的人，而据称两人同时到达，又无法查明谁先到，遗赠是否因此不能成立？如果遗赠给建造墓碑的人，而有多人建造呢？如果遗赠给年龄最大的人，而有两人年龄相同呢？如果遗赠给我的朋友塞姆普罗尼乌斯，而有两人与我情谊相同呢？又如，遗赠给两个同名之人，例如两个塞姆普罗尼乌斯，之后遗嘱人又撤销了给塞姆普罗尼乌斯的遗赠，却无法查明撤销的是给谁的遗赠：是对两人的遗赠均因受领对象不明而失效，还是撤销均不生效？多个同名奴隶中，若遗嘱仅向其中一人或若干人遗赠自由，也会有同样问题。较妥当的意见是：在上述所有情形中，遗赠及自由遗赠均不能确定受益人而不能成立；但撤销遗赠则对两人均有效。

<!-- source-p 588 -->
<a id="34.5.10.1"></a>**1.**如果女奴获准在“首先生下男孩时”取得自由，而她一胎生下一男一女：若能确定先出生者是谁，就不应对她是否获得自由产生疑问，女儿的身份也不应存疑；因为如果女儿是后出生的，她便是自由出生者。反之，如果出生先后无法确定，甚至无法通过司法审查查明，在疑义事项中应当采纳更为人道的意见，推定男孩先出生，从而使女奴本人取得自由，她的女儿也取得自由出生身份。〔底本此处作 *non debet*，并以尖括号校改为 *decet*；译文据校改读法处理。〕

<!-- source-p 596 -->
**尤利安：《论措辞歧义》独卷。**

<!-- source-p 597 -->
<a id="34.5.13.pr."></a>**序言。**如果有人寄存了二百，却遗嘱写道：“我将三百连同寄存在塞尤斯处的二百一并遗赠给塞尤斯”，便会产生歧义：两个金额各自都有明确指称，但以这样的措辞连接起来，就有了歧义。然而，应认为应给付的不是三百，而是五百，因为两个金额相加。

<!-- source-p 598 -->
<a id="34.5.13.1"></a>**1.**如果有人遗嘱写道：“继承人应将塞尤斯土地连同梅维乌斯的奴隶狄奥给阿提乌斯”，人们会怀疑：土地是否也遗赠给狄奥，还是仅将狄奥连同土地一起遗赠给阿提乌斯。较妥当的解释是，土地和奴隶狄奥都已遗赠，尤其是遗嘱人没有正当理由只遗赠狄奥的情况下。

<!-- source-p 599 -->
<a id="34.5.13.2"></a>**2.**如果我们如此订立要式口约：“如果你不交付奴隶或土地，你承诺给付一百吗？”为避免触发要式口约，奴隶和土地两者都必须交付；无论只交付其中一项，还是两项均未交付，要式口约都会生效。我们对下列约定也显然应作相同解释：具体列出数项必须履行的事项后，又约定“其中有任何一项未履行时”，例如：“你承诺将斯提库斯、达玛和厄洛忒斯带到吗？如果其中任何一人没有到场，是否给付十？”必须将所有人带到，才能履行要式口约。更明确地说，假设要式口约如此订立：“如果你不带到斯提库斯、达玛和厄洛忒斯，是否给付十？”毫无疑问，同样必须将所有人带到。

<!-- source-p 600 -->
<a id="34.5.13.3"></a>**3.**要式口约可以如此表述：“如果那件事或这件事没有完成”，也可以如此表述：“为了完成而列举的事项中，有任何一项没有完成”。二者的区别在于：前一种表述中，即使其中一项已完成，确实可以说“那件事或这件事已完成”，但不能因此说“那件事或这件事没有完成”；一项已完成而另一项未完成时，这两种说法可以同时为真，尽管彼此相反。因为其含义不是从整体而是从其中一项得出，只要其中有一项为真，整个陈述便为真。反过来，包含相互矛盾内容的两个陈述也可能同时为假。例如，若子女中有些在成年后死亡，有些在未成年时死亡，那么“所有子女都未成年时死亡”和“所有子女都成年后死亡”便都为假。这是因为其含义取自整体，其中只要有一部分为假，整个陈述便为假。因此，应注意所问的究竟是什么。如果要式口约写作“如果那件事或这件事没有完成”，应判断其是否意指两件事均未完成；该写法的效果是两件事都没有完成。另一种写法的效果则是两件事都必须完成：在前一种情形中，即使有一项未完成，只要另一项已完成，也不因此触发；在后一种情形中，即使有一项已完成，只要另一项未完成，仍会触发。〔本段区分两种否定结构，译文依上下文按条件范围解释，建议复核。〕

<!-- source-p 601 -->
<a id="34.5.13.4"></a>**4.**因此，如果有人这样问：“你做了被指控的那些事中的任何一件吗？”答话者否认，并说：“被指控的这些事，我一件也没做”，也就是“这些事我都没做”。

<!-- source-p 602 -->
<a id="34.5.13.5"></a>**5.**如果有人在要式口约中列入数项事项，而只要求其中一项完成，就应如此表述：“你承诺完成那件事或这件事吗？如果这些事都没有完成，你给付这么多吗？”

<!-- source-p 603 -->
<a id="34.5.13.6"></a>**6.**此外，如果家父在遗嘱中如此写道：“若我有儿子或女儿出生，就让其为我的继承人；若我有儿子或女儿而其不是我的继承人，就让塞尤斯为继承人”，那么，若他意在仅在儿子和女儿均非继承人时才让外人继承，该文字并未充分表明其意思；应当写成：“若我没有儿子或女儿成为继承人。”不过，在某些情况下，前一种写法可能是必要的：例如遗嘱人已有儿子和女儿，并希望二人均成为继承人，但若其中一人成为继承人，也让外人参与继承；若二人均未成为继承人，则以外人作为替补继承人。尽管如此，较自然的解释仍是：无论遗嘱人有儿子还是女儿出生，外人都不应成为继承人，除非遗嘱人明确作出相反表示。

**马尔西安：《规则集》第三卷。**

<!-- source-p 619 -->
<a id="34.5.18.pr."></a>**序言。**还有一种情形：未适婚人和被指定为其替补继承人的必然继承人兄弟同时死亡；问题是，该兄弟是否继承未适婚人的遗产，还是相反？又如，两名必然继承人互相指定对方为替补继承人，二人同时死亡，是否应认为彼此已成为继承人？或者二人受托将遗产互相返还。在这些情形中，如果二人同时死亡且无法查明谁先断气，就不应认为其中一人比另一人存活得更久。

<!-- source-p 620 -->
<a id="34.5.18.1"></a>**1.**关于法尔基丢法也是如此：如果家主与奴隶同时死亡，在计算法定份额时，不将这些奴隶视为其死亡时仍在其财产中的奴隶。

<!-- source-p 621 -->
<a id="34.5.19"></a>**34.5.19**

<!-- source-p 622 -->
**乌尔比安：《萨比努斯评注》第二十五卷。**

<!-- source-p 623 -->
<a id="34.5.19.pr."></a>**序言。**如果遗赠给亲属，而这些人后来不再是亲属、但仍保有公民身份，仍应认为遗赠须予给付；因为他们在遗嘱订立时是亲属。当然，如果某人在遗嘱订立时不是亲属，却在遗嘱人死亡时因收养而成为亲属，那么他更容易取得遗赠。

<!-- source-p 624 -->
<a id="34.5.19.1"></a>**1.**如果有人将遗赠给“亲属”，与遗赠给“各亲属”含义相同。

<!-- source-p 625 -->
<a id="34.5.20"></a>**34.5.20**

<!-- source-p 626 -->
**保罗：《普劳提乌斯评注》第十二卷。**

<!-- source-p 627 -->
如果神圣马尔库斯皇帝在位期间，元老院曾准许社团接受遗赠，那么遗赠给依法可以组成社团的团体时，毫无疑问遗赠应予给付。若遗赠给依法不得组成社团的团体，则遗赠无效，除非是分别遗赠给各个人；因为这些人取得遗赠并非以社团名义，而是作为特定的个人。

<!-- source-p 628 -->
<a id="34.5.21"></a>**34.5.21**

<!-- source-p 629 -->
**保罗：《普劳提乌斯评注》第十四卷。**

<!-- source-p 630 -->
<a id="34.5.21.pr."></a>**序言。**措辞存在歧义时，应以当事人实际达成的意思为准；例如，我在要式口约中约定给付奴隶斯提库斯，但有多个同名的斯提库斯；或者约定交付“一名奴隶”；又或者约定在迦太基交付物品，而迦太基有两座。

<!-- source-p 631 -->
<a id="34.5.21.1"></a>**1.**对依诚信订立的交易遇有疑义时，应始终采取使该交易处于最稳妥地位的解释，除非书面内容明确违反法律。

<!-- source-p 632 -->
<a id="34.5.22"></a>**34.5.22**

<!-- source-p 633 -->
**雅沃勒努斯：《卡西乌斯著作摘编》第五卷。**

<!-- source-p 634 -->
母亲与已达适婚年龄的儿子在海难中死亡。如果无法查明谁先死亡，较为人道的做法是推定儿子存活得更久。

<!-- source-p 635 -->
<a id="34.5.23"></a>**34.5.23**

<!-- source-p 636 -->
**盖尤斯：《尤利亚法与帕皮亚法评注》第五卷。**

<!-- source-p 637 -->
如果妇女与未适婚的儿子在海难中死亡，应推定儿子先死亡。

<!-- source-p 638 -->
<a id="34.5.24"></a>**34.5.24**

<!-- source-p 639 -->
**马尔凯卢斯：《学说汇纂》第十一卷。**

<!-- source-p 640 -->
遗嘱措辞含糊，甚至书写有误时，应从宽解释，并采信可信的遗嘱人原意。

<!-- source-p 641 -->
<a id="34.5.25"></a>**34.5.25**

<!-- source-p 642 -->
**塞尔苏斯：《学说汇纂》第二十二卷。**

<!-- source-p 643 -->
“我曾对继承人说，我希望谁获得自由，谁就应当自由。我曾对继承人说，应当给付何人，继承人就应当给付何人。”如果通过某些证据可以确定遗嘱人所指为何人，就应实现遗嘱人的意思。

<!-- source-p 644 -->
<a id="34.5.26"></a>**34.5.26**

<!-- source-p 645 -->
**塞尔苏斯：《学说汇纂》第二十六卷。**

<!-- source-p 646 -->
如果争议在于要式口约的实际约定为何，措辞歧义应作不利于要式口约债权人的解释。

<!-- source-p 647 -->
<a id="34.5.27"></a>**34.5.27**

<!-- source-p 648 -->
**莫德斯蒂努斯：《规则集》第一卷。**

<!-- source-p 649 -->
如果某人希望在数名奴隶中释放一人，却无法查明遗嘱人意在释放谁，则无人有权依遗嘱信托取得自由。

<!-- source-p 650 -->
<a id="34.5.28"></a>**34.5.28**

<!-- source-p 651 -->
**雅沃勒努斯：《拉贝奥后编》第三卷。**

<!-- source-p 652 -->
某人有名叫弗拉库斯的洗衣奴隶，以及名叫菲洛尼库斯的面包师奴隶，却将“面包师弗拉库斯”遗赠给妻子。问题是，遗赠了哪一名奴隶，还是两人都应给付。通说认为，首先应将遗嘱人意在遗赠的那名奴隶视为遗赠对象。如果无法查明，则应先考察主人是否熟悉奴隶的姓名；如果熟悉，应给付遗嘱中写明姓名的奴隶，即使奴隶的职业写错亦然。反之，如果主人并不熟悉奴隶的姓名，则应认为遗赠的是面包师，仿佛遗嘱未附加奴隶姓名。

<!-- source-p 653 -->
<a id="34.5.29"></a>**34.5.29**

<!-- source-p 654 -->
**谢沃拉：《学说汇纂》第十八卷。**

<!-- source-p 655 -->
某人在遗嘱中释放了数名奴隶，其中包括萨比娜和基普罗革尼娅；他希望每名奴隶年满三十岁并获得自由时，给付一定金额。他在相连的条款中又写道：“我希望在萨比娜和基普罗革尼娅达到规定年龄时，分别给她们十；此外，在她们有生之年，每年以扶养费名义分别给她们十。”有人问，扶养费遗赠是给所有被释放的奴隶，还是只给萨比娜和基普罗革尼娅。答复说，根据所述情况，应认为扶养费遗赠给了所有被释放的奴隶。
