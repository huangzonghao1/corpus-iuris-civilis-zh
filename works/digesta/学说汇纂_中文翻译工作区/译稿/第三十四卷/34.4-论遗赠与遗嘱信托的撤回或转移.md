# D.34.4 论遗赠或遗嘱信托的撤回与转移（*De adimendis vel transferendis legatis vel fideicommissis*）

<!-- source-p 425 -->
<a id="4"></a><a id="34.4"></a>**34.4.0 论遗赠或遗嘱信托的撤回与转移**（*De adimendis vel transferendis legatis vel fideicommissis*）。

<!-- source-p 426 -->
<a id="34.4.1"></a>**34.4.1**

<!-- source-p 427 -->
保罗《萨宾评注》第三卷。

<!-- source-p 428 -->
若在遗赠役道（*actus*）时撤回步行通行权（*iter*），该撤回不发生效力，因为役道不可能在没有步行通行权的情况下行使。

<!-- source-p 429 -->
<a id="34.4.2"></a>**34.4.2**

<!-- source-p 430 -->
庞波尼乌斯《萨宾评注》第五卷。

<!-- source-p 431 -->
<a id="34.4.2.pr."></a>**序言**　遗赠了一处庄园后，可以如此撤回其中一部分：“除用益权外，我不将该庄园交付或遗赠给他”，从而使遗赠中保留用益权。

<!-- source-p 432 -->
<a id="34.4.2.1"></a>**1**　也可以撤回果实部分，从而仍遗赠所有权。

<!-- source-p 433 -->
<a id="34.4.2.2"></a>**2**　同样，也可以撤回已遗赠庄园的一部分。

<!-- source-p 434 -->
<a id="34.4.3"></a>**34.4.3**

<!-- source-p 435 -->
乌尔比安《萨宾评注》第二十四卷。

<!-- source-p 436 -->
<a id="34.4.3.pr."></a>**序言**　若某人如此遗赠：“我将庄园交付并遗赠给提图斯；若提图斯去世，我的继承人应将其交给塞尤斯”，则应认为遗赠已有效转移。若受遗赠人已经去世，立遗嘱人又以同样方式转移该物，则该物应交给塞姆普罗尼乌斯。

<!-- source-p 437 -->
<a id="34.4.3.1"></a>**1**　若某人如此遗赠给提图斯：“交付给提图斯；若提图斯在受领前去世，则交付给塞姆普罗尼乌斯”，依严格解释，继承人似乎对两人均负义务，即对塞姆普罗尼乌斯及提图斯的继承人都负义务。但若提图斯未能及时受领是继承人造成的，遗赠请求权便移转给提图斯的继承人，塞姆普罗尼乌斯的请求应予驳回；反之，若不存在迟延，则遗赠归塞姆普罗尼乌斯，而非提图斯的继承人。若提图斯在遗赠请求权到期前去世，则遗赠仅应给付塞姆普罗尼乌斯。

<!-- source-p 438 -->
<a id="34.4.3.2"></a>**2**　同样，若遗嘱信托将遗产交给一名男童，并规定若他在遗产返还前去世，则遗产留给其母亲，也应依上述规则处理：男童若在遗赠请求权到期前去世，遗产应给付其母亲；若他在此后去世，遗嘱信托则移转给未成年人的继承人，因为实际发生了迟延。

<!-- source-p 439 -->
<a id="34.4.3.3"></a>**3**　若某人如此遗赠：“我的继承人应将某物交给提图斯；若未交付，则交给塞姆普罗尼乌斯”，只有在提图斯一方的给付期限未届至时，塞姆普罗尼乌斯才有权取得。

<!-- source-p 440 -->
<a id="34.4.3.4"></a>**4**　若某人如此遗赠：“我的继承人应将庄园交给提图斯；若提图斯让与该庄园，我的继承人应将同一庄园交给塞尤斯”，则继承人负有义务。因为若提图斯让与庄园，并非立遗嘱人要求提图斯履行遗嘱信托，而是立遗嘱人另行将该庄园遗赠给塞尤斯。因此，继承人应要求提图斯提供担保，承诺不让与庄园，以免遭受诈欺抗辩。

<!-- source-p 441 -->
<a id="34.4.3.5"></a>**5**　若遗嘱人撤回的数额超过其原先遗赠的数额，撤回仍然有效；例如遗赠二十，却撤回四十。

<!-- source-p 442 -->
<a id="34.4.3.6"></a>**6**　若立遗嘱人遗赠一处地点的用益权，却撤回通行权，该撤回无效，也不损害遗赠；正如某人遗赠庄园所有权，却不能因撤回通行权而减少遗赠。

<!-- source-p 443 -->
<a id="34.4.3.7"></a>**7**　若立遗嘱人分别向两名提图斯遗赠，并撤回其中一人的遗赠，但无法查明撤回针对何人，则遗赠应付给二人双方。与之相反，若是给予而无法查明给了谁，我们会说双方均未获遗赠。

<!-- source-p 444 -->
<a id="34.4.3.8"></a>**8**　若立遗嘱人无条件将庄园遗赠给提图斯，又附条件将同一庄园遗赠给他，随后如此撤回：“我的继承人不得将我附条件遗赠给提图斯的庄园交付给他”，则提图斯不再能基于任何一项遗赠取得该庄园，除非立遗嘱人特别说明仍愿其无条件取得。

<!-- source-p 445 -->
<a id="34.4.3.9"></a>**9**　应考察遗赠、继承或附条件释奴所附的条件能否撤回。尤利安写道，若从附条件释奴的条件中删去条件，并不因此立即使其自由。帕皮尼安在《疑义》第十七卷中也一般性地写道，条件不能撤回；他说，条件并非“给与”，而是“附加”于处分之上；附加的内容不能撤回，只有给与的内容才能撤回。但较好的做法是重视意思而非文字：条件既可附加，也可撤回。

<!-- source-p 446 -->
<a id="34.4.3.10"></a>**10**　某人在遗嘱中遗赠一百给提图斯，随后又在遗嘱附录中写道：“我的继承人仅给提图斯五十，不得多给。”受遗赠人只能请求五十。

<!-- source-p 447 -->
<a id="34.4.3.11"></a>**11**　不仅遗赠可以撤回，遗嘱信托也可以撤回，而且只要意思表示即可。因此有人问：若立遗嘱人与受益人之间发生敌对，遗嘱信托是否仍应履行。若双方发生生死攸关或极其严重的敌对，应视为遗赠已被撤回；若只是轻微不快，遗嘱信托仍然有效。基于同样理由，若提出诈欺抗辩，我们也会对遗赠作同样处理。

<!-- source-p 448 -->
<a id="34.4.4"></a>**34.4.4**

<!-- source-p 449 -->
乌尔比安《萨宾评注》第三十三卷。

<!-- source-p 450 -->
若双方后来恢复友谊，且立遗嘱人对先前的冒犯感到后悔，则先前留下的遗赠或遗嘱信托即恢复效力；因为死者的意思在其生命终结之前始终可以变更。

<!-- source-p 451 -->
<a id="34.4.5"></a>**34.4.5**

<!-- source-p 452 -->
盖尤斯《城市告示评注》第二卷。

<!-- source-p 453 -->
正如遗赠可以撤回，也可以转移给他人，例如：“我遗赠给提图斯的物品，现交付并遗赠给塞尤斯。”这种做法包含了对提图斯所受遗赠的默示撤回。

<!-- source-p 454 -->
<a id="34.4.6"></a>**34.4.6**

<!-- source-p 455 -->
保罗《尤利乌斯与帕皮乌斯法评注》第五卷。

<!-- source-p 456 -->
<a id="34.4.6.pr."></a>**序言**　遗赠的转移有四种方式：从一人转给另一人；从原受命给付者转移，改由他人给付；以一物替代另一物，例如以十枚金币替代一处庄园；或者将原来无条件给付之物转为附条件给付。

<!-- source-p 457 -->
<a id="34.4.6.1"></a>**1**　若我将先前命提图斯给付之物改为命梅维乌斯给付，尽管同一物通常可能由两名债务人承担给付义务，但较正确的看法是，在这种情形下，先前的遗赠已被撤回。因为我说“塞尤斯应给付提图斯曾被命令给付之物”，似乎就是说“不要由提图斯给付”。

<!-- source-p 458 -->
<a id="34.4.6.2"></a>**2**　同样，若以十枚金币替代一处庄园遗赠，有人认为先前遗赠并未撤回；但较正确的看法是，先前遗赠已被撤回，因为应遵从立遗嘱人最后的意思。

<!-- source-p 459 -->
<a id="34.4.7"></a>**34.4.7**

<!-- source-p 460 -->
乌尔比安《萨宾评注》第二十四卷。

<!-- source-p 461 -->
若将原先无条件给付的遗赠附条件转给他人，则不能认为已完全撤回原遗赠；只有在后来遗赠的条件成就时，才发生撤回。反之，若立遗嘱人的意思是无论如何都要撤回先前遗赠，则应认为该遗赠已被撤回。

<!-- source-p 462 -->
<a id="34.4.8"></a>**34.4.8**

<!-- source-p 463 -->
尤利安《学说汇纂》第三十二卷。

<!-- source-p 464 -->
因此，若立遗嘱人生前，接受转移遗赠之人已经死亡，遗赠也不会因此归还给原受遗赠人。

<!-- source-p 465 -->
<a id="34.4.9"></a>**34.4.9**

<!-- source-p 466 -->
乌尔比安《讨论》第五卷。

<!-- source-p 467 -->
若某人将原先无条件遗赠的一百加上条件，再遗赠给同一人：若他意在使后一笔成为另一笔款项，则原无条件遗赠的一百应立即给付，附条件遗赠的另一百则在条件成就时给付。若他改变意思，将同一笔款项改为附条件遗赠，则应认为原先的无条件给付已变为附条件给付。因此，若他在同一遗嘱中先写下一百，后来又遗赠五十：若后一笔五十另有所指，则应给付一百五十；若他只愿给付五十，则仅应给付五十。遗嘱附录中作出同样处分时，亦同。

<!-- source-p 468 -->
<a id="34.4.10"></a>**34.4.10**

<!-- source-p 469 -->
尤利安《学说汇纂》第三十七卷。

<!-- source-p 470 -->
<a id="34.4.10.pr."></a>**序言**　若某项无条件遗赠被附条件撤回，而提图斯在条件尚未成就时去世，即使条件后来未成就，该遗赠也不归提图斯的继承人；因为附条件撤回遗赠，等同于在相反条件下作出遗赠。

<!-- source-p 471 -->
<a id="34.4.10.1"></a>**1**　遗嘱如此规定：“我的继承人应给提图斯十枚金币；若未给提图斯，则将同样十枚金币给塞姆普罗尼乌斯。”若提图斯在遗赠请求权到期前去世，塞姆普罗尼乌斯可以有效请求该遗赠，因为应认为遗赠已转移给他。

<!-- source-p 472 -->
<a id="34.4.11"></a>**34.4.11**

<!-- source-p 473 -->
尤利安《学说汇纂》第五十四卷。

<!-- source-p 474 -->
若某人遗赠一名奴隶，却撤回了斯提库斯，则并未消灭遗赠，只是缩小了遗赠范围，

乌尔比安《萨宾评注》第五十卷。

<!-- source-p 477 -->

<a id="34.4.13"></a>**34.4.13**

<!-- source-p 479 -->
马尔基安《法学阶梯》第六卷。

<!-- source-p 480 -->
神圣塞维鲁和安敦尼两位皇帝曾以敕答规定：若立遗嘱人在最后的书面文件中，无论出于何种缘由，补充说某自由人是极其恶劣之人，则先前文件中留给该自由人的遗赠应视为已经撤回。

<!-- source-p 481 -->
<a id="34.4.14"></a>**34.4.14**

<!-- source-p 482 -->
弗洛伦提努斯《法学阶梯》第一卷。

<!-- source-p 483 -->
<a id="34.4.14.pr."></a>**序言**　以无效方式作出的遗赠，不会因撤回而变为有效。例如，某人指定奴隶的主人为继承人，却无条件将遗赠给奴隶，后来又附条件撤回该遗赠：若无条件遗赠附条件撤回，应理解为该遗赠是在相反条件下作出的，因此反而变得有效。撤回的作用在于减少而非增加遗赠应给付的内容。

<!-- source-p 484 -->
<a id="34.4.14.1"></a>**1**　凡给付遗赠无效的原因，也会使撤回失去效力；例如，部分撤回一条通道，或只在部分范围内禁止某人成为自由人。

<a id="34.4.18"></a>**34.4.18**

<!-- source-p 495 -->
莫德斯汀《区别论》第八卷。

<!-- source-p 496 -->
若立遗嘱人生前将遗赠之物赠与他人，该遗赠在任何情况下均告消灭。我们不区分其赠与究竟是出于家计所需，还是仅出于自愿；不能认为若因需要而赠与，遗赠仍应给付，若出于自愿则不应给付。因为这种区分不适用于赠与人的慷慨行为：人在迫于需要时并非出于慷慨。

<a id="34.4.23"></a>**34.4.23**

<!-- source-p 510 -->
帕皮尼安《答复》第七卷。

<!-- source-p 511 -->
父亲在女儿之间分配财产时，曾希望其中一名女儿按首席百人队长的收益取得三百金币；此后，他用该收益款购置了财产。尽管如此，兄弟及共同继承人仍应向姐妹履行遗嘱信托，因为投入遗产本金的财物不应被视为已经耗尽。若父亲在女儿之间分割遗产时，意在让尚未分割的财物仍归所有共同继承人共有，则应将用收益购得的财产予以分割，使女儿按其继承份额取得超过价款的部分；因为若以钱款留在遗产中，也会出现同样结果。

<!-- source-p 512 -->
<a id="34.4.24"></a>**34.4.24**

<!-- source-p 513 -->
帕皮尼安《答复》第八卷。

<!-- source-p 514 -->
<a id="34.4.24.pr."></a>**序言**　附条件遗赠转移给另一人时，若该条件并非专属于原受遗赠人，则应认为转移时仍附有同一条件。例如，若立遗嘱人向妻子作出附条件遗赠，并以子女不再在场为条件，则后来转移该遗赠时，不应认为必须重复写明该条件，因为该条件与妻子本人相关。

<!-- source-p 515 -->
<a id="34.4.24.1"></a>**1**　父亲将设施齐备的花园遗赠给女儿；此后，他将花园中的若干奴隶赠给妻子。无论他是否确认了该赠与，后来作出的意思表示均优先于给女儿的遗赠；即使赠与无效，也应认为父亲减少了给女儿的遗赠。

<a id="34.4.26"></a>**34.4.26**

<!-- source-p 520 -->
保罗《疑义》第九卷。

<!-- source-p 521 -->
<a id="34.4.26.pr."></a>**序言**　若奴隶连同自由一并被遗赠，后来奴隶被让与时又撤回其自由，尽管对他人所有的奴隶撤回自由本身无效，遗赠仍不会移转给买受人。这是合理的：撤回之所以有效，是因为该奴隶可能被买回；正如自由的授予，在授予对象于立遗嘱时属于立遗嘱人、之后又被让与，并通过遗嘱附录获释的情形下，也可以发生效力。

<!-- source-p 522 -->
<a id="34.4.26.1"></a>**1**　那么，若某人命令一个奴隶获自由，自己生前又将其释放，随后却在遗嘱附录中撤回其自由，应如何处理？应考察他是否因无效的自由撤回而丧失遗赠。有人持肯定看法；但多余的书面处分不会损害遗赠。

<!-- source-p 523 -->
<a id="34.4.27"></a>**34.4.27**

<!-- source-p 524 -->
保罗《疑义》第二十一卷。

<!-- source-p 525 -->
<a id="34.4.27.pr."></a>**序言**　某人遗赠了一名奴隶，并另遗赠某物给该奴隶。若奴隶被让与后，立遗嘱人撤回遗赠给他的物品，该撤回有效，因为若奴隶被买回，遗赠仍可能实现。

<!-- source-p 526 -->
<a id="34.4.27.1"></a>**1**　若某人遗赠一名奴隶，并在生前将其释放，之后又撤回该遗赠，则撤回毫无效力；因此，该奴隶仍能取得遗赠给自己的物品。即使他后来又沦为奴隶，该遗赠也不会恢复，因为他被视为一个新人。

<a id="34.4.30"></a>**34.4.30**

<!-- source-p 534 -->
斯凯沃拉《学说汇纂》第二十卷。

<!-- source-p 535 -->
<a id="34.4.30.pr."></a>**序言**　某人向其受抚养女留下多项遗赠；他撤回其中一些，又要求其继承人履行其余部分，其中包括以下文字所示的二十金磅：“此外，我交付并遗赠二十金磅，并愿予给付。”他接着写道：“阿提乌斯，我将此事托付给你的信用：请你本着亲情，尤其照料并保护你的姐妹塞姆普罗尼娅；若你认为她已回归良好的生活方式，则在你去世时将二十金磅交还给她。但在此期间，你应向她提供收益，也就是半率利息。”此后，他在遗嘱附录中将同一二十金磅转给受遗赠人梅维乌斯，并以如下文字托付给他：“我在遗嘱中留给受抚养女塞姆普罗尼娅的二十金磅，愿交给梅维乌斯，但须作出担保，使他在塞姆普罗尼娅有生之年，从该款中每月给付她五德纳里，并每年给付一百二十五德纳里作为衣物费；此事托付给你们的信用。我相信，梅维乌斯，你会本着亲情，请求你的继承人使我对受抚养女的意愿继续实现。”问题是，梅维乌斯是否应如阿提乌斯继承人先前受托的那样，在自己去世后将二十金磅交还给塞姆普罗尼娅。答称，依所陈述的情形，梅维乌斯无须给付二十金磅本金；但遗赠给受抚养女的其他给付，在她有生之年应由梅维乌斯及其继承人履行。

<!-- source-p 536 -->
<a id="34.4.30.1"></a>**1**　提提娅在遗嘱中指定其自由女塞娅——亦即其乳姊妹——为十二分之一份额的继承人；她以遗嘱信托方式将若干地产遗赠给自己的自由人潘菲卢斯，其中包括所谓“靠近科洛努斯的地产联合体”（*sugktysin*）。此后，她又通过书信赠与其他物品，并就塞娅与潘菲卢斯写道：“提提娅致我的继承人，安好。我愿下列事项确定有效：此前我以潘菲卢斯名义所作的一切；若我的乳姊妹塞娅未能按我指定给她的份额成为我的继承人，我愿将靠近科洛努斯的地产联合体交给她。”〔底本希腊文转写为 *Titia tois klyronomois mou xairein. Boulomai bebaia einai ta hypotetagmena, hosa efvasa eis to onoma to pamfilou pepoiykenai. ean Seia hy suntrofos mou klyronomos my genytai, ec ohu gegrafa autyn merous, boulomai auty dovynai tyn sugktysin tyn peri Kolwnyn*；底本并列拉丁文译释：*Titia heredibus meis salutem. Infra scripta rata esse volo, quaecumque ante in nomen Pamphili feci, quod si Seia collactanea mea heres mihi non fiet ex ea parte qua eam scripsi, volo dari eam massam quae est circa Colonem.*〕问题是，若自由女塞娅放弃遗嘱指定给她的继承份额，转而根据遗嘱附录请求遗嘱信托，即靠近科洛努斯的地产联合体；而潘菲卢斯也基于遗嘱信托请求返还同一地产，他是否应被诈欺抗辩驳回。答称：应认为有关该地产的遗嘱信托——即靠近科洛努斯的 *sugktysin*——已转给自由女塞娅。

<!-- source-p 537 -->
<a id="34.4.30.2"></a>**2**　某人请求继承人：若自己在外省去世，应给付卢基乌斯·提图斯六十枚金币，由其负责将遗体运回故乡；并补充道：“我愿将该款项的剩余部分交给他。”同日，他又在遗嘱附录中如此写给继承人：“我请求你们，无论我在外省还是途中遭遇不测，都照料我的遗体，将其运回坎帕尼亚，安葬于我儿子的墓中。”问题是，剩余的六十金币是否已被他默示地从卢基乌斯·提图斯处撤回。答称：应视为已经撤回。

<!-- source-p 538 -->
<a id="34.4.30.3"></a>**3**　某人在遗嘱中按不同份额指定女儿为继承人，并在同一遗嘱中几乎分配了全部财产，随后又补充如下文字：“至于我其余的一切财产，以及继承债务，都只归我的两个女儿普里玛和塞昆达，或她们中尚存的一人。”〔底本希腊文转写为 *Ta de loipa panta twn huparxontwn mou, homoiws kai ta tys klyronomias bary estai monwn twn duo mou vugaterwn primys kai sekoundys y tys ec autwn periousys*；底本并列拉丁译文：*quaecumque reliqua sunt ex bonis meis itemque onera hereditaria pertineant ad solas duas filias meas Primam et Secundam superstitemve earum*。〕此后，他在遗嘱附录中对同一批女儿的财产作了完全不同的分配，但有些财物未明确遗赠给任何人。问题是，第一和第二女儿能否依据遗嘱文字，请求取得父亲在最后一次分配中未明确遗赠给任何人的财物，使其仅归她们所有。答称：不能认为立遗嘱人已完全放弃先前意思；应认为仅变更了其后来重新处分的财物。

<!-- source-p 539 -->
<a id="34.4.30.4"></a>**4**　遗嘱公布并开启后，普里斯基利安努斯仍然在世；其母亲曾就他的遗赠及遗产份额以书信规定：“我得知我的儿子普里斯基利安努斯病危，故认为最公正、最合乎亲情的做法是，将我在遗嘱中留给他的遗产份额，以相等份额遗赠给我的兄弟马里亚努斯和我的丈夫伊阿努阿里乌斯；若我还另有遗赠给他的物品，若他遭遇不测，我也愿交付给他们。”此后，普里斯基利安努斯因同一疾病去世。问题是，他所受遗赠是否也基于遗嘱信托转给伊阿努阿里乌斯和马里亚努斯。答称：可以认为，若他因该疾病去世，则其遗赠也已全部转给所问及的二人。

<!-- source-p 540 -->
<a id="34.4.31"></a>**34.4.31**

<!-- source-p 541 -->
斯凯沃拉《学说汇纂》第十四卷。

<!-- source-p 542 -->
<a id="34.4.31.pr."></a>**序言**　某人指定其子为部分继承人，并将两处庄园连同奴隶及全部用具遗赠给他；又向妻子作出多项遗赠，并将奴隶斯提库斯和达马遗赠给妻子。但他发现预先遗赠给儿子的其中一处庄园缺少庄园管理人，便派斯提库斯前往，令其负责农务及庄园账目。问题是，斯提库斯究竟归妻子还是归儿子。答称：既然立遗嘱人记得自己在遗嘱中的安排，斯提库斯就应作为管理人归属于他被调往的那些地产；妻子不得基于遗嘱信托请求斯提库斯。

<!-- source-p 543 -->
<a id="34.4.31.1"></a>**1**　某人指定其母为部分继承人，并将四处地产遗赠给她，托付她从中返还两处给岳父；此后，他在遗嘱附录中撤回了对岳父所设的遗嘱信托。问题是，这两处地产是否仍基于预先遗赠归母亲所有。答称：没有任何已陈述的事实表明这些地产归母亲。

<!-- source-p 544 -->
<a id="34.4.31.2"></a>**2**　塞娅遗赠五磅黄金。提图斯控告她，称她曾命令杀害自己的父亲。控告提出后，塞娅订立遗嘱附录，却没有撤回给继子提图斯的遗赠；她在控告终结前去世。案件审理后，判决认定提图斯之父并非因塞娅的罪行而死亡。我问：既然她在遗嘱附录中没有撤回原遗嘱给提图斯的遗赠，塞娅的继承人是否仍应向提图斯给付。答称：依所述情形，不应给付。

<!-- source-p 545 -->
<a id="34.4.31.3"></a>**3**　某人将特有产遗赠给处于其权力下的女儿；立遗嘱后，他又向女儿的债务人追收钱款，并将其记入自己的账目。我问，女儿能否就此向父亲的继承人起诉。答称：若她能证明父亲这样做并非出于撤回遗赠的意思，即可起诉。
