# D.34.8–D.34.9　论视为未书写的事项及因不适格而被剥夺的遗产

> **底本范围：**依 d-34.htm source-p 681–808 翻译，完整覆盖 D.34.8 与 D.34.9 两个标题；按源段落保留编号、出处和锚点。

<!-- source-p 681 -->
<a id="8"></a><a id="34.8"></a>**34.8.0　论视为未书写的事项。**

<!-- source-p 682 -->
<a id="34.8.1"></a>**34.8.1**

<!-- source-p 683 -->
尤利安《学说汇纂》第七十八卷

<!-- source-p 684 -->
若有人在遗嘱中将继承权或遗赠指定给自己，问题在于，该继承权或遗赠是否应视为未曾写入。若这种继承人指定还设有替补继承人，又当如何？答复说，你向我咨询的那部分遗产应归替补继承人。因为元老院在针对将继承权或遗赠写给自己的人制定科尔内利亚法的处罚时，似乎以同样方式否定了这类条款，正如以下条款也被否定一样：“提图斯在其遗嘱书中将我指定为继承人的部分，应由我继承。”这类条款应视同从未写入遗嘱。〔底本疑误：原文末尾连写“testamento non fuissententiarum”，句意据上下文译出。〕

<!-- source-p 685 -->
<a id="34.8.2"></a>**34.8.2**

<!-- source-p 686 -->
阿尔芬努斯《学说汇纂》第五卷

<!-- source-p 687 -->
遗嘱中虽有书写、但无法理解其含义的内容，应视同未曾书写；其余内容则独立有效。

<!-- source-p 688 -->
<a id="34.8.3"></a>**34.8.3**

<!-- source-p 689 -->
马尔基安《法学阶梯》第十一卷

<!-- source-p 690 -->
<a id="34.8.3.pr."></a>**序言。**若某人被判处矿山劳役，而遗嘱留给他的财物并非用于供养，则该遗赠视为未曾书写，也不归国库；因为他是刑罚的奴隶，而非皇帝的奴隶。神圣的安敦尼·庇乌斯也曾以敕答作此确认。

<!-- source-p 691 -->
<a id="34.8.3.1"></a>**1.**即使继承人在遗嘱订立后才被判处矿山劳役，国库也不取得遗嘱留给他的财物。

<!-- source-p 692 -->
<a id="34.8.3.2"></a>**2.**又，若遗赠给他人所有的奴隶，而立遗嘱人后来买下该奴隶，遗赠即告消灭；因为财物后来处于一种原本不可能开始发生遗赠的状态时，应视为未曾写入遗嘱。

<!-- source-p 693 -->
<a id="34.8.4"></a>**34.8.4**

<!-- source-p 694 -->
乌尔比安《评尤利亚法与帕皮亚法》第十三卷

<!-- source-p 695 -->
<a id="34.8.4.pr."></a>**序言。**若在某人被指定为受遗赠人时，该人尚未存在于世，则该遗赠应视为未曾写入。

<!-- source-p 696 -->
<a id="34.8.4.1"></a>
**1.**又，若订立遗嘱时某人处于敌人控制之下，且此后未能从敌人处返回，则该遗赠应视为未曾写入。尤利安也如此写道。

<!-- source-p 697 -->
<a id="34.8.5"></a>**34.8.5**

<!-- source-p 698 -->
保罗《疑问集》第十二卷

<!-- source-p 699 -->
若某人将遗赠写给自己，但立遗嘱人命令他将该物交还他人，则该遗赠仍由继承人持有，并负有遗嘱信托的负担，尽管该遗赠本身视为未曾写入。军人遗嘱亦同。

<!-- source-p 700 -->
<a id="9"></a><a id="34.9"></a>**34.9.0　论从不适格人处剥夺遗产。**

<!-- source-p 701 -->
<a id="34.9.1"></a>**34.9.1**

<!-- source-p 702 -->
马尔基安《法学阶梯》第六卷

<!-- source-p 703 -->
神圣的塞维鲁和安东尼努斯皇帝以敕答规定，被释自由人若在其主保人死后，将主保人告发为从事非法商品交易的人，则应视为不适格，并丧失遗嘱中留给他的遗赠或遗嘱信托，即便他因此获得了赏金。

<!-- source-p 704 -->
<a id="34.9.2"></a>**34.9.2**

<!-- source-p 705 -->
马尔基安《法学阶梯》第十一卷

<!-- source-p 706 -->
<a id="34.9.2.pr."></a>**序言。**若已脱离父权的儿子因父亲在遗嘱中遗漏自己，而请求取得对抗遗嘱的遗产占有（bonorum possessio contra tabulas），并依据对未适婚人设立的替补继承而接受继承，则全部遗产应予剥夺并归入国库。

<!-- source-p 707 -->
<a id="34.9.2.1"></a>
**1.**又，若某人违反行政命令，与其任职省份的妇女结婚，则塞维鲁和安东尼努斯皇帝以敕答规定，他不得保留依据妻子遗嘱取得的财产；这与监护人违反最高等级元老院的决议，将未适婚人女被监护人娶入自己家中相同。因此，在这两种情形下，即使此人被指定为全部遗产的继承人并已接受继承，国库仍可取得遗产；因为该继承是从不适格人处剥夺的。

<!-- source-p 708 -->
<a id="34.9.2.2"></a>
**2.**反过来说，若某妇女被省任职者或监护人非法娶为妻，较妥当的意见是，她仍可依据遗嘱取得财产，不应以不适格为由将她排除。

<!-- source-p 709 -->
<a id="34.9.2.3"></a>
**3.**若有人在某亲属不知情时，擅自赠与他人该亲属的全部或部分财产，也应作相同处理；该人应被视为不适格，财产应予剥夺。

<!-- source-p 710 -->
<a id="34.9.3"></a>**34.9.3**

<!-- source-p 711 -->
马尔基安《规则集》第五卷

<!-- source-p 712 -->
庇乌斯皇帝判定某人为不适格；马尔切卢斯在《学说汇纂》第十二卷也作此记载：若已有明确证据证明某人以自己的疏忽和过失，导致指定其为继承人的妇女死亡，则该人不适格。

<!-- source-p 713 -->
<a id="34.9.4"></a>**34.9.4**

<!-- source-p 714 -->
乌尔比安《评告示论》第十四卷

<!-- source-p 715 -->
帕皮尼安在《疑问集》第五卷说，若某人以伪造遗嘱为由控告一名被指定的继承人，则共同继承人留给他的遗赠不得被剥夺；该控告人并未对这位共同继承人提起争议。

<!-- source-p 716 -->
<a id="34.9.5"></a>**34.9.5**

<!-- source-p 717 -->
保罗《国库法论》第一卷

<!-- source-p 718 -->
<a id="34.9.5.pr."></a>**序言。**接受遗赠后，不仅可以主张遗嘱系伪造，也可以主张遗嘱并非依法订立；但不允许主张遗嘱违反亲属义务。

<!-- source-p 719 -->
<a id="34.9.5.1"></a>
**1.**主张遗嘱未依法订立但未能胜诉的人，不会因此被剥夺其已经取得的利益。因此，接受遗赠后又主张遗嘱系伪造的人，应丧失已经取得的财物。至于接受遗赠后主张遗嘱并非依法订立的人，神圣的庇乌斯皇帝曾如此作出敕答：“索弗隆的亲属虽已从遗嘱指定的继承人处接受遗赠，但若该继承人被认定不具备取得继承权的资格，且依无遗嘱继承规则，遗产依法应归这些亲属，他们即可依据法律本身请求继承遗产。是否应禁止其请求，应由法官根据每个人的身份、状况、年龄及案件具体情形决定。”

<!-- source-p 720 -->
<a id="34.9.5.2"></a>
**2.**有人认为，被指定为监护人后以理由请求免除监护职责的人，应丧失其依遗嘱取得的利益；若他已经取得利益，则不得再请求免除。我认为，仅取得遗赠、之后又被未适婚人之母请求担任监护人的人，情形不同；因为他没有做出违背死者意思的事。但被拒绝给予监护人的遗赠，不应转归国库，而应留给其利益遭到弃置的子女。

<!-- source-p 721 -->
<a id="34.9.5.3"></a>
**3.**若家父或主人控告遗嘱系伪造，即使其子或奴隶获有遗赠，只要该财物利益将归其子或奴隶，家父或主人也不得就该遗赠提起诉讼；若遗赠仅与其子或奴隶的人身有关，则应作不同处理。

<!-- source-p 722 -->
<a id="34.9.5.4"></a>
**4.**若某人取得遗赠，却被请求释放自己的奴隶；或者奴隶本人同时取得了这两项利益，则不应因主人的行为而损害奴隶。国库应买下该奴隶并使其获得自由，但前提是主人愿意出售；由于主人蔑视死者的意思，仍不得强迫其出售奴隶。

<!-- source-p 723 -->
<a id="34.9.5.5"></a>
**5.**若处于父权之下的家子控告遗嘱系伪造，应考察是否也应拒绝其父亲提起诉讼。我认为，若家子违背父亲意愿提出控告，就不应拒绝其父亲的诉讼请求。

<!-- source-p 724 -->
<a id="34.9.5.6"></a>
**6.**若我受托将遗赠交还给某人，而该人主张遗嘱系伪造，我就应将该遗赠交还国库。

<!-- source-p 725 -->
<a id="34.9.5.7"></a>
**7.**若控告遗嘱系伪造的人后来成为受遗赠人的继承人，或成为遗嘱指定继承人的继承人，应认为此事对他不生不利。

<!-- source-p 726 -->
<a id="34.9.5.8"></a>**8.**主张遗嘱违反亲属义务的人，情形也相同。

<!-- source-p 727 -->
<a id="34.9.5.9"></a>**9.**控告人的年龄可获宽宥；若监护人或保佐人意图主张遗嘱系伪造或违反亲属义务，尤其应当如此。塞维鲁和安东尼努斯皇帝也以敕答作此确认。

<!-- source-p 728 -->
<a id="34.9.5.10"></a>**10.**以证言协助控告人提出主张的人，不得提起诉讼。神圣的塞维鲁皇帝曾作出此项裁定。

<!-- source-p 729 -->
<a id="34.9.5.11"></a>**11.**有人正确地认为，对协助控告人或为其提供保证的人，也应拒绝其诉讼请求。

<!-- source-p 730 -->
<a id="34.9.5.12"></a>**12.**有人还认为，若省长曾宣告遗嘱系伪造，而在上诉后遗嘱指定的继承人胜诉，则该省长也属不适格。

<!-- source-p 731 -->
<a id="34.9.5.13"></a>**13.**国库律师奉职务之命执行告发人的主张，其职务必要性在所有情形下均足以为其开脱。

<!-- source-p 732 -->
<a id="34.9.5.14"></a>**14.**控告主要遗嘱系伪造的人，也应被排除于第二份遗嘱之外；即使针对的是为第一份遗嘱作成、但未获确认的遗嘱附录，也应如此。若他控告的是第二份遗嘱或遗嘱附录，则不应作同样处理，因为在后一情形下，他似乎并未同时否定两份遗嘱。

<!-- source-p 733 -->
<a id="34.9.5.15"></a>**15.**应考察，是否应剥夺以证言试图推翻遗嘱的奴隶所获自由。此人当然不配取得遗嘱信托；至于自由，神圣的庇乌斯皇帝裁定，也应将其剥夺。

<!-- source-p 734 -->
<a id="34.9.5.16"></a>**16.**被指定为监护人的人，不能以自己曾主张遗嘱系伪造为由请求免除监护职责；但应将其排除于遗赠之外。

<!-- source-p 735 -->
<a id="34.9.5.17"></a>**17.**从立遗嘱人处接受死因赠与的人，在此问题上与受遗赠人不同。

<!-- source-p 736 -->
<a id="34.9.5.18"></a>**18.**若某人受命将所获财物交还给受遗赠人或待解放奴隶，则其情形不同；此人应以不适格为由被排除。

<!-- source-p 737 -->
<a id="34.9.5.19"></a>**19.**庇乌斯皇帝和马尔库斯皇帝认为，也应剥夺遗嘱指定继承人依据法尔基迪亚法所享有的四分之一扣减利益。

<!-- source-p 738 -->
<a id="34.9.5.20"></a>**20.**所有以不适格为由遭排除的人，也应被剥夺依神圣图拉真皇帝敕令授予告发人的赏金。

<!-- source-p 739 -->
<a id="34.9.6"></a>**34.9.6**

<!-- source-p 740 -->
马尔切卢斯《学说汇纂》第二十二卷

<!-- source-p 741 -->
皇帝以敕答规定，继承人不得保留其取走财物价值的四分之一。因此，若立遗嘱人拥有四百，并将全部四百遗赠；继承人却私自取走一百，那么，他只能从剩余的三百中扣留四分之一，即七十五，并应向受遗赠人交付二百二十五。至于他私取的一百，其中七十五应交付受遗赠人，剩余二十五则归国库。

<!-- source-p 742 -->
<a id="34.9.7"></a>**34.9.7**

<!-- source-p 743 -->
莫德斯提努斯《区分论》第六卷

<!-- source-p 744 -->
控告提图斯遗嘱系伪造但未能胜诉的人，不应被禁止成为提图斯继承人的继承人，因为他并非直接继承提图斯的遗产。

<!-- source-p 745 -->
<a id="34.9.8"></a>**34.9.8**

<!-- source-p 746 -->
莫德斯提努斯《规则集》第九卷

<!-- source-p 747 -->
若某人被判定为不适格继承人并因此被剥夺遗产，不应恢复已因继承人身份混同而消灭的诉权。

<!-- source-p 748 -->
<a id="34.9.9"></a>**34.9.9**

<!-- source-p 749 -->
乌尔比安《评尤利亚法与帕皮亚法》第十四卷

<!-- source-p 750 -->
<a id="34.9.9.pr."></a>**序言。**若受遗赠人与立遗嘱人之间发生了生死之仇，以致有理由相信立遗嘱人不愿向遗嘱中指定的人给付遗赠或遗嘱信托，则较妥当的意见是，该人不得请求交付遗赠。

<!-- source-p 751 -->
<a id="34.9.9.1"></a>
**1.**若该人曾公开、明确地辱骂立遗嘱人，并对其恶语相向，也应作相同处理。但若其法律身份本身引发争议，则应拒绝其请求遗嘱给付的诉讼；在这种情形下，相关财物应立即归入国库。

<!-- source-p 752 -->
<a id="34.9.10"></a>**34.9.10**

<!-- source-p 753 -->
盖尤斯《评尤利亚法与帕皮亚法》第十五卷

<!-- source-p 754 -->
<a id="34.9.10.pr."></a>**序言。**若某人以默示承诺的方式规避法律，答应将遗赠的财物或其他财物返还给依法不得依据遗嘱取得财物的人，无论他因此出具书面凭据，还是仅以口头承诺作出保证，均属规避法律。

<!-- source-p 755 -->
<a id="34.9.10.1"></a>
**1.**若某人受托将财物返还给原本有资格接受遗赠的人，但该人在立遗嘱人死亡时已依法不得取得该财物，我毫不怀疑，尽管遗嘱信托不能履行，财物仍应留在受托返还之人处；因为看不出他参与了任何规避法律的行为。但若他预先承诺，即使受益人日后开始依法不得取得财物，仍会将财物返还给他，则属例外。

<!-- source-p 756 -->
<a id="34.9.10.2"></a>
**2.**正确的说法是，若父亲为处于自己权力之下的儿子设立默示信托，不应因此损害儿子；因为儿子有义务服从父亲。

<!-- source-p 757 -->
<a id="34.9.11"></a>**34.9.11**

<!-- source-p 758 -->
帕皮尼安《疑问集》第十五卷

<!-- source-p 759 -->
若继承人以规避法律的方式接受默示遗嘱信托，则对其实施规避的那部分财产，不得适用法尔基迪亚法扣减；元老院也曾作出此项决定。但若遗嘱指定给他的份额大于其规避法律的份额，则就法尔基迪亚法而言，他可以从超出部分中保留四分之一。

<!-- source-p 760 -->
<a id="34.9.12"></a>**34.9.12**

<!-- source-p 761 -->
帕皮尼安《疑问集》第十六卷

<!-- source-p 762 -->
某人指定了依法不得成为继承人的人为继承人。尽管继承人指定无效，且此前的遗嘱并未因此失效，元老院早已规定，这些未能承接立遗嘱人最后意思的继承人仍应以不适格为由被剥夺继承权。神圣的马尔库斯皇帝曾就一人作出裁判：立遗嘱人完成遗嘱后，又将其姓名补入其中。皇帝将此事交由国库长官处理；但立遗嘱人留给该人的遗赠仍然有效。至于特别先行取得的财物，应依立遗嘱人的意思判断；除非明显可见立遗嘱人另有意思，否则不得拒绝向其交付遗赠。

<!-- source-p 763 -->
<a id="34.9.13"></a>**34.9.13**

<!-- source-p 764 -->
帕皮尼安《疑问集》第三十二卷

<!-- source-p 765 -->
克劳狄乌斯·塞琉库斯致其友帕皮尼安，敬祝安好。梅维乌斯因与塞姆普罗尼娅通奸而被定罪，但他与未被定罪的塞姆普罗尼娅结婚。梅维乌斯临终时指定她为继承人。我询问，这是否构成有效婚姻，该妇女是否应准许继承遗产。答复说，该婚姻不成立，该妇女也不得取得继承利益；遗嘱留给她的财产应归国库。反过来，若该妇女指定该男子为继承人，也应以他不适格为由剥夺其遗产。

<!-- source-p 766 -->
<a id="34.9.14"></a>**34.9.14**

<!-- source-p 767 -->
帕皮尼安《疑问集》第三十三卷

<!-- source-p 768 -->
我最近曾答复你：与一名军人通奸并与其同居的妇女，即使该军人退役后一年内死亡，也不得依据军人遗嘱继承；留给她的财产应归国库。

<!-- source-p 769 -->
<a id="34.9.15"></a>**34.9.15**

<!-- source-p 770 -->
帕皮尼安《答复集》第六卷

<!-- source-p 771 -->
若继承人主张遗嘱附录系伪造而未能胜诉，不应剥夺其继承权；但若他依据该遗嘱附录从共同继承人处取得了任何财物，则应拒绝其就该财物提起诉讼。因此，若立遗嘱人通过遗嘱附录在继承人之间分割遗产，继承人仍保有不能通过遗赠设立的继承份额；但若其所失份额的数额足以使其经公平抵销而放弃法尔基迪亚法的利益，则不得再享有该法的扣减利益。

<!-- source-p 772 -->
<a id="34.9.16"></a>**34.9.16**

<!-- source-p 773 -->
帕皮尼安《答复集》第八卷

<!-- source-p 774 -->
<a id="34.9.16.pr."></a>**序言。**父亲在第二份遗嘱中将其未适婚的儿子指定为继承人，并将其兄弟的儿子列为共同继承人和替补继承人。男孩死后，作为替补继承人的叔伯子女起诉其母亲，指控她假称生下该男孩，以便取得其叔父的法定遗产。我答复说，他们败诉后，应从其依据替补继承取得的遗产份额中被剥夺；因为他们并未依据遗嘱取得对自己有利的裁判。

<!-- source-p 775 -->
<a id="34.9.16.1"></a>
**1.**既已认定，妇女允许自己成为主保人的妾，并不构成通奸；因此，立遗嘱人若有妾，其遗嘱留给妾的财物不得拒绝交付。我们最优秀、最伟大的皇帝曾在著名人士科凯乌斯·卡西安努斯的遗嘱案中作出此项裁判：卡西安努斯以充分礼遇爱慕出身自由的鲁菲娜。后来查明，他在遗嘱中称为养女、并与孙女一同指定为共同继承人的鲁菲娜之女，实际上是非婚生女。

<!-- source-p 776 -->
<a id="34.9.16.2"></a>
**2.**家父改变意思并划销遗嘱，撤回了对某继承人的指定，因此该份额被判归国库。马尔库斯皇帝认为，这不应损害依遗嘱接受财物的受遗赠人；国库应承继该遗产，并承担其上的负担。

<!-- source-p 777 -->
<a id="34.9.17"></a>**34.9.17**

<!-- source-p 778 -->
帕皮尼安《答复集》第十三卷

<!-- source-p 779 -->
我认为，若继承人明知死者遭受侵害却未予伸张，应被命令返还全部孳息；他不能正当地请求恢复因继承人身份混同而消灭的诉权。若他因事实上的错误而受骗，则在争议尚未提出前，享有善意占有人的抗辩，但须先结算孳息；此后他请求恢复因身份混同而消灭的诉权，也不属不当。

<!-- source-p 780 -->
<a id="34.9.18"></a>**34.9.18**

<!-- source-p 781 -->
帕皮尼安《答复集》第十五卷

<!-- source-p 782 -->
<a id="34.9.18.pr."></a>**序言。**我答复说，因规避法律而接受默示遗嘱信托的人，即使在诉讼开始前已取得孳息，也应被命令返还；因为他并非善意占有人，正如被国库主张权利的遗产中的财物一样。关于默示遗嘱信托的争议提起后，我答复说，应返还此前取得的孳息价额及利息；但只须返还实际收取价款的孳息。若孳息已被本人使用，返还其价额即已足够。不过，塞维鲁皇帝宽厚地裁定，对默示遗留给他人的财物，无论孳息何时取得，均只须返还孳息，不必支付利息。我们现行适用这一规则。

<!-- source-p 783 -->
<a id="34.9.18.1"></a>
**1.**若依据默示遗嘱信托将全部财产返还国库，继承人原则上不承担遗产债务；未对死者死亡加以辩护的情形亦同。但若因接受继承而发生诉权或役权混同，使其丧失某项权利，则不得请求恢复原状予以救济。

<!-- source-p 784 -->
<a id="34.9.18.2"></a>
**2.**某人被指定为部分继承人，并接受了庄园遗赠；同时，他还受托以默示遗嘱信托的方式，将财物交给依法不得接受遗产的人。尽管该庄园遗赠并未计入其继承份额，因此他是以继承人身份占有该部分，我仍答复说，应将整座庄园留给他；法律根据与占有方式的差异，不应导致立遗嘱人意思被分割。

<!-- source-p 785 -->
<a id="34.9.19"></a>**34.9.19**

<!-- source-p 786 -->
保罗《答复集》第十六卷

<!-- source-p 787 -->
答复说，若立遗嘱人因改变意思、打算另立遗嘱，却受到遗嘱指定继承人的阻挠，因而遗产被从这些继承人处剥夺，则应认为立遗嘱人已撤回先前遗嘱的全部意思。

<!-- source-p 788 -->
<a id="34.9.20"></a>**34.9.20**

<!-- source-p 789 -->
赫尔莫革尼安《法学摘要》第三卷

<!-- source-p 790 -->
若丈夫未能为妻子的死亡进行辩护，其嫁资应以不适格为由从他处剥夺。

<!-- source-p 791 -->
<a id="34.9.21"></a>**34.9.21**

<!-- source-p 792 -->
保罗《箴言集》第五卷

<!-- source-p 793 -->
若被释自由人死时情况可疑，而其继承人未能为其死亡进行辩护，这些继承人所取得的份额也应归国库。所有继承人及处于继承人地位的人，都有义务尽力维护死者的权益。

<!-- source-p 794 -->
<a id="34.9.22"></a>**34.9.22**

<!-- source-p 795 -->
特里福尼努斯《论辩集》第五卷

<!-- source-p 796 -->
若监护人代表未适婚人主张遗嘱系伪造或违反亲属义务，但未能胜诉，有充分理由认为，不应因此剥夺监护人本人所受的遗赠。若监护人代表其未适婚人被监护人的父亲控告被释自由人犯有死罪，也不应因此拒绝其请求违反遗嘱的遗产占有；因为其履行职责的必要性及监护人的诚信应予认可。若监护人并非出于个人怨怼，而是在未适婚人的母亲或其父亲的被释自由人坚持要求下提出控告，任何法官都不应将其指为恶意诉讼人。又，若监护人代表未适婚人控告某人，但因未适婚人在诉讼期间达到适婚年龄而未能继续追诉，不应认为监护人因此违反图尔皮利安元老院决议。虽然若干法律关系可能集中于同一人，其权利仍须分别判断：监护人身份与受遗赠人身份各不相同。监护人既非以本人名义，而是代表未适婚人提出控告，就不应承受个人刑罚。最后，若未适婚人在该遗嘱中获有遗赠，除非皇帝予以保全，该遗赠仍会失效；由此可见，监护人是控告者，同时也是未适婚人的辩护人和近似保护人。萨宾在《评维泰利乌斯论》中也作相同记载。

<!-- source-p 797 -->
<a id="34.9.23"></a>**34.9.23**

<!-- source-p 798 -->
盖尤斯《默示遗嘱信托论》单行本

<!-- source-p 799 -->
若任何遗嘱中的继承人受默示委托，应将其依据法尔基迪亚法所保留的四分之一返还给依法不得接受遗赠的人，同样适用元老院决议；因为这种遗嘱信托与某人受托返还其从遗产中取得的财物，并无多大区别。
