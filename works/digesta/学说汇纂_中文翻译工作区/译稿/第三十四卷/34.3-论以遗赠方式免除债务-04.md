如果继承人受托免除其债务人的债务，似乎仅指债务关系中仍然存在的部分。因此，如果在遗嘱书启封之前已经清偿某笔款项，该款不属于遗嘱信托事项。但是，如果在遗嘱启封后、继承人接受继承之前，有人明知死者的意思仍收取了款项，则近于欺诈，因而可以请求返还。

我将他人欠我的款项遗赠给提提乌斯；遗嘱中可以注明或不注明确定数额或特定物。反过来也是如此，即我将自己所欠的款项遗赠给他人时，也应作同样区分，例如：“给提提乌斯我所欠他的款项”，或“给提提乌斯一百，即我所欠他的款项”。我问：所有这些情形是否都须审查债务是否实际存在？我还请求你更全面地论述相关问题，因为这些情形十分常见。答称：如果债权人意在免除提提乌斯所欠的债务，无论是命令继承人免除债务，还是禁止继承人追索，均无区别；两种方式都使债务人免责，而且两种情形下债务人均可主动起诉请求免债。如果还提到一百枚金币或欠下的某座庄园，若确能证明债务存在，就应免除债务；若并无债务，则可以认为，附加的只是错误的说明，而所写明的财物仍可请求取得。但只有在遗赠写道“给他一百枚我所欠的金币”或“我的继承人不得向他请求我所欠的奴隶斯提库斯”时，才可以如此解释。如果写道：“我的继承人应给提提乌斯一百枚他所欠我的金币”，也可以尝试主张，即使说明错误仍可请求所写明的财物；但我绝不赞同这一意见，因为立遗嘱人认为，“给付”一词是指清偿债务。反之，如果债务人将遗赠给自己的债权人，而未写明数额，我看不出该遗赠有什么效用；即使他说明了自己承认所欠的款项，除非属于能够增加债务利益的情形，也没有实际效用。不过，如果债务人遗赠了一百枚他自称所欠的金币：若债务确实存在，该遗赠无效；若并非债务人，则通说认为遗赠有效。因为确定数额的金钱，类似于附有错误说明而遗赠奴隶斯提库斯；神圣的庇乌斯皇帝也曾以敕答确认，将确定款项作为已收取嫁资遗赠时，适用此规则。

某位监护人在遗嘱中指定其他人为继承人，并希望将三分之一财产给其所监护的未成年人；条件是该未成年人不得因监护事务而与继承人发生争议，而应就此免除继承人的全部责任。未成年人优先取得了遗赠，但其后仍请求返还监护人因出售财产或其他原因从监护事务中取得的一切。我问：遗嘱文字是否排除该未成年人提出这些请求。答称：如果未成年人在履行条件之前已取得遗嘱信托，随后又请求其依条件不得请求的事项，则继承人可以提出诈欺抗辩；但如果未成年人愿意返还其依据遗嘱信托取得之物，则不在此限。应基于其年龄给予这一宽宥。

我们来考察：如果某人被遗赠免除一项针对其特有产的诉权，而通常应在遗赠权利开始发生之日审查其特有产；若该日特有产中没有任何财物，他是否仍视为受遗赠人？然而，此人当时尚不是债务人；除非因未来可能取得特有产而有此期待，否则遗赠利益不会归于他。是否因此应认为其受遗赠人地位尚未确定，如同另有原因使遗赠能否实现存疑一样？

<!-- source-p 396 -->
<a id="34.3.28.pr."></a>**序言。**奥雷利乌斯·辛福鲁斯曾为某人的监护人提供保证；他临终时以如下文字向那些未成年人遗赠：“阿雷利乌斯·拉提努斯和阿雷利乌斯·费利克斯各五枚金币，分别在他们年满十四岁时给付；在此之前，我愿每月向他们各给付六第纳里乌斯作为生活给养，每年各给付二十五第纳里乌斯作为衣物费用。你们应满足于这项遗赠，因为你们的监护事务已使我的财产遭受相当损失。我请求你们，我的继承人，不要依据监护账目向他们索取任何款项，也不要扣留他们的这项遗赠。”问题是：如果辛福鲁斯的继承人因保证责任给付了款项，能否向他所保证之人的儿子（未成年人的继承人）请求返还。答称：依遗嘱文字，继承人所受托的仅是不向阿雷利乌斯兄弟索取其依据辛福鲁斯所管理的监护账目所欠的款项。

<!-- source-p 397 -->
<a id="34.3.28.1"></a>**1.**某人在遗嘱中留下了对债务人的免债遗赠；此后，他解开封绳并查阅该遗嘱，又另立遗嘱，并在其中以如下文字重申该遗赠：“凡我在那份已启封的遗嘱中所作的遗赠，我都愿其有效，并确认其中写下的一切。”问题是：接受后立遗嘱项下的继承后，先前遗嘱中获遗赠免债的债务人，能否连同先前遗嘱订立后新增的债务一并免责；如果继承人向他们追债，他们能否提出诈欺抗辩。答称：不能免除新增债务。

<!-- source-p 398 -->
<a id="34.3.28.2"></a>**2.**提提乌斯如此遗赠给自己的债务人塞伊乌斯：“给并遗赠塞伊乌斯十第纳里乌斯；此外，我将他所欠我的全部本金和利息一并赠给他。”他还概括地命令继承人并托付其信义，要求其给付并返还遗赠给每个人的一切。此后，塞伊乌斯又向提提乌斯借了一笔钱。我问：这笔在遗嘱订立后交付给塞伊乌斯的钱，是否也应视为已被遗赠。答称：既然文字指向过去期间，就不应认为后来的债务也在遗赠之内。

<!-- source-p 399 -->
<a id="34.3.28.3"></a>**3.**提提乌斯立遗嘱指定其子为继承人，并就曾担任其监护人的父亲如此写道：“我愿免除父亲塞伊乌斯的监护诉讼责任。”我问：应如何理解这段文字？例如，父亲是否应向立遗嘱人的儿子及继承人——也就是自己的孙辈——返还其出售财物或收取债权后用于自身之款项，或者以自己名义出借的款项。答称：应由有管辖权之人加以评定。基于自然亲情，推定父亲可使用一切财物；除非其继承人能够证明立遗嘱人另有意思。

<!-- source-p 400 -->
<a id="34.3.28.4"></a>**4.**梅维娅在遗嘱中如此规定，希望免除其一名继承人的监护诉讼责任：“我不愿请求朱利乌斯·保罗返还他与安提斯提乌斯·西塞罗共同管理监护事务所负的账目，并愿就此使他彻底免责。”我问：如果监护事务中的款项仍留在该继承人处，能否向其请求。答称：所陈述的情形并未表明，留在监护人处、属于未成年女继承人的款项也被遗赠给了监护人。

<!-- source-p 401 -->
<a id="34.3.28.5"></a>**5.**某人在遗嘱中如此写道：“我愿免除我的姻亲提提乌斯所欠我的任何债务；此外再给他十。”他又在遗嘱附录中写道：“此外，我愿我的继承人在我姻亲及债务人提提乌斯生前，免除他所欠钱款的利息；但如果他认为依我的意思仍可继续请求，我愿我的继承人在提提乌斯生前，就其所欠本金向其支付利息。”问题是：既然立遗嘱人意在增加而非减少利益，继承人是否负有遗嘱信托义务，必须免除提提乌斯的全部债务。答称：依所述情形，先前作出的遗赠似乎已被减少。

<!-- source-p 402 -->
<a id="34.3.28.6"></a>**6.**遗嘱作如下遗赠：“我愿免除塞伊乌斯所欠我的一切债务，以及我为他承担保证责任所负的债务。”我问：遗赠是否仅包括立遗嘱时所欠之债，还是其后就该款项所产生的利息也包括在内。答称：应认为立遗嘱人意在通过遗嘱信托免除该项债务的全部责任。

<!-- source-p 403 -->
<a id="34.3.28.7"></a>**7.**某人在遗嘱中释放奴隶斯提库斯，并将一座配置齐备的庄园及其他财物遗赠给他，还补充道：“我不要求他交账，因为账簿在他手中。”问题是：斯提库斯是否仍须返还其管理事务所欠的余额。答称：斯提库斯对此不负责任。克劳狄乌斯补充说：没有人会在获得自由后，因其奴隶身份期间所为之事继续承担责任；而咨询所涉原本是债务责任。因此，若余额已随特有产遗赠给他，可以保留该余额，或从特有产中扣除。

<!-- source-p 404 -->
<a id="34.3.28.8"></a>**8.**“我寄存在阿普罗尼安努斯处的一百，愿其继续留在他那里，直至我的儿子年满二十岁；我不准收取该款的利息。”问题是：阿普罗尼安努斯能否依据遗嘱信托请求，在立遗嘱人所定期限届满前不得向他追索该款。答称：依所述情形，可以请求如此处理。

<!-- source-p 405 -->
<a id="34.3.28.9"></a>**9.**某人指定女儿为继承人，并以如下文字将其信义托付于她们：“不得向盖乌斯·塞伊乌斯索取其经手办理我事务所涉账目；无论这些事务是在其钱柜之内还是之外办理，均自我死亡之日起免除他的责任。”问题是：既然此人在我死亡前经手管理全部账目，包括经由钱柜办理及其他方式办理的账目，他是否仍有义务向继承人交账。答称：依所述情形，免债遗赠确已设立；至于应在何种范围内履行，应由法官根据争议的性质加以评定。

<!-- source-p 406 -->
<a id="34.3.28.10"></a>**10.**某人指定曾管理其监护事务的监护人、自己的兄弟及其他人为继承人，并将他们为自己和兄弟所支出的费用十遗赠给监护人。问题是：此项遗嘱信托对监护人是否有效。答称：如果遗赠的是他人所欠之物，则不得再请求该物。

<!-- source-p 407 -->
<a id="34.3.28.11"></a>**11.**同一人又问：如果遗嘱信托对监护人无效，对其兄弟是否有效，因为该兄弟也从监护人管理的监护事务中获益。答称：对兄弟而言，遗赠有效，因为他自己的债务因此得以免除。

<!-- source-p 408 -->
<a id="34.3.28.12"></a>**12.**同一人又问：如果监护人接受遗嘱信托，却只愿遵循遗嘱中的某些文字，而拒绝遵循另一些文字，理由是遗嘱信托所包括的费用数额小于其实际支出，他是否应获支持。答称：遗嘱文字不妨碍监护人请求其能够证明应由他人偿还的全部款项。

<!-- source-p 409 -->
<a id="34.3.28.13"></a>**13.**某人如此遗赠：“我命令我的继承人向妻子塞姆普罗尼娅返还五十，即我以逐笔出具的债务凭证形式借入并用于事务的款项。”问题是：若他确实是妻子的债务人，遗嘱信托是否成立。答称：如果该款项本来就是债务，则不成立遗嘱信托。

<!-- source-p 410 -->
<a id="34.3.28.14"></a>**14.**同一人又问：如果妻子曾以债务为由向法官请求该款，却败诉，是否仍可依据遗嘱信托请求。答称：依所述情形，可以依据遗嘱信托请求已查明并非基于其他原因所欠的款项。

如果某人有两名共同承担要式允诺之债的债务人，并命令继承人使二人均免责，而其中一人依法不能受领遗赠，且两人并非合伙人，则应将该不能受领者应得的利益转让给依法有权享有该利益之人。此人请求后，便可使双方均获益：他取得该利益，另一名有受领资格的债务人也因此免责。但如果二人是合伙人，则因为其中一人有受领资格，另一人也会随之取得利益；通过对前者作清偿确认，后者亦相应免责。即使遗嘱仅命令免除有受领资格者的债务，也会产生同样结果。

请求人或占有人命令自己的继承人不得提起百人团法庭诉讼。问题是，此遗赠有何效力。有人认为，只有在立遗嘱人的对方诉讼理由不成立、继承人提起诉讼本应败诉时，遗赠才有效；在这种情况下，继承人不仅须向受遗赠人给付诉讼所带来的利益，还须承担诉讼费用。若立遗嘱人的理由充分，则该遗赠似乎不产生效力，包括不产生支付费用的效力；尽管有人持相反意见。

斯凯沃拉《答复集》第三卷。

<!-- source-p 419 -->
<a id="34.3.31.pr."></a>**序言。**债权人如此遗赠给债务人：“我愿我的继承人向盖乌斯·塞伊乌斯给付他以其庄园作质押而欠我的一切。”我问：如果立遗嘱人生前已从塞伊乌斯处收取某笔款项，是否仍可依据遗赠请求该款。答称：依所述情形，不可以。同一问题再次提出时又说：立遗嘱人在作出遗赠的遗嘱附录订立之前，已经收取几乎全部本金和利息，因此仅剩少量本息尚欠。鉴于遗嘱使用“他欠我的一切”这一过去时文字，是否可以请求返还已收款项。答称：前一问题已依所述情形作出正确答复；后一问题则应由法官结合时间加以评定，查明立遗嘱人是否忘记款项已经清偿，或款项是否在其不知情时支付，抑或其明知款项已付，仍意在给付曾经欠下的数额，而非免除债务。

<!-- source-p 420 -->
<a id="34.3.31.1"></a>**1.**某人还如此遗赠给其自由释奴：“凡他在我生前经手办理的事务，我不准继承人向他索取账目。”问题是：该自由释奴是否仍须向继承人交出记载账目的文书，以及按收支所列的余额。答称：继承人可以请求返还问题所涉财物；但如果其曾将款项贷与仍在遗产中的共同奴隶，且该款已用于主人的事务，则该款已不再属于尚欠余额。

<!-- source-p 421 -->
<a id="34.3.31.2"></a>**2.**提提娅曾有两名监护人，并作如下安排：“我不愿请求卢基乌斯·提提乌斯交出他与普布利乌斯·梅维乌斯共同管理我监护事务的账目。”问题是：如果仍有监护财产留在该监护人处，是否可以请求返还。答称：所述情形并未表明，仍留在监护人处、属于未成年女被监护人的款项也被遗赠给了监护人。

<!-- source-p 422 -->
<a id="34.3.31.3"></a>**3.**又问：共同监护人是否也因此获免责。答称：共同监护人并未获免责。

<!-- source-p 423 -->
<a id="34.3.31.4"></a>**4.**“此外，我还遗赠给对我恩德深厚的盖乌斯·塞伊乌斯，并愿无论我或其继承人均不得向他请求我以债务凭证或账目所记载而由他所欠的任何款项，或他向我借入的任何款项，或我为他承担保证责任所负的任何债务。”我问：遗赠是否仅包括立遗嘱时所欠的债务，还是后来就该数额产生的利息也属于遗赠范围。答称：依所述情形，应认为立遗嘱人意在通过遗嘱信托免除塞伊乌斯该项债务的全部责任。

<!-- source-p 424 -->
<a id="34.3.31.5"></a>**5.**又问：如果此后通过债务更新扩大了所欠数额，先前合同所欠款项是否仍属于遗赠范围；债务更新后，塞伊乌斯是否会作为新债务人，就扩大的数额被起诉。答称：应认为遗赠仅包括当时所欠的款项，但前提是立遗嘱人仍维持其当时的意思。
