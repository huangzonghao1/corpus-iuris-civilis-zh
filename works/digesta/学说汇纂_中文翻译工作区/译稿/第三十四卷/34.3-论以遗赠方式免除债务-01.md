# D.34.3《论以遗赠方式免除债务》

> **底本范围：**依 d-34.htm source-p 283–350 翻译；本标题分为两段译稿，保留原段落编号、标题和底本锚点。

<!-- source-p 283 -->
<a id="3"></a><a id="34.3"></a>**34.3.0　论以遗赠方式免除债务。**

<!-- source-p 284 -->
<a id="34.3.1"></a>**34.3.1**

<!-- source-p 285 -->
乌尔比安《萨比努斯评注》第二十一卷。

<!-- source-p 286 -->
<a id="34.3.1.pr."></a>**序言。**可以将债务人所负的债务遗赠给该债务人，即使受遗赠人本来就是其债权人。

<!-- source-p 287 -->
<a id="34.3.1.1"></a>**1.**尤利安写道：如果债权人将已出质之物遗赠给债务人，该遗赠有效；债务人有权在清偿债务之前请求取回质物。尤利安这样说，仿佛债务人不应因此获利；但是，如果立遗嘱人另有意思，也可参照赎回质物的情形达到这一结果。

<!-- source-p 288 -->
<a id="34.3.2"></a>**34.3.2**

<!-- source-p 289 -->
庞波尼乌斯《萨比努斯评注》第六卷。

<!-- source-p 290 -->
<a id="34.3.2.pr."></a>**序言。**继承人虽被命令不得向保证人请求给付，仍可向主债务人请求；但如果继承人被禁止向主债务人请求，而他却向保证人请求，主债务人是否应依遗嘱承担责任，塞尔苏斯认为应当承担。

<!-- source-p 291 -->
<a id="34.3.2.1"></a>**1.**塞尔苏斯同样说，毫无疑问：既然继承人被禁止向债务人请求，即使是继承人的继承人，也不得向该债务人请求。

<!-- source-p 292 -->
<a id="34.3.3"></a>**34.3.3**

<!-- source-p 293 -->
乌尔比安《萨比努斯评注》第二十三卷。

<!-- source-p 294 -->
<a id="34.3.3.pr."></a>**序言。**现在已经确定，可以将免除债务遗赠给债务人。

<!-- source-p 295 -->
<a id="34.3.3.1"></a>**1.**如果某人在临终时将债务凭证交给自己的债务人，我认为该债务人可以提出抗辩，仿佛以这种交付方式设立了遗嘱信托。

<!-- source-p 296 -->
<a id="34.3.3.2"></a>**2.**尤利安在《学说汇纂》第四十卷中还写道：某人临终时将塞伊乌斯的债务凭证交给提提乌斯，令其在自己死后交给塞伊乌斯；若自己康复，则应归还给自己。其后，提提乌斯在赠与人死亡后将凭证交给塞伊乌斯，而赠与人的继承人请求清偿债务。对此，塞伊乌斯享有诈欺抗辩。

<!-- source-p 297 -->
<a id="34.3.3.3"></a>**3.**现在我们来考察这种遗赠的效力。如果我独自是债务人，且遗赠给我免债，那么无论我被起诉与否，都可以主张免债：若被起诉，我可以援用抗辩；若未被起诉，我可以提起诉讼，通过清偿确认方式（*acceptilatio*）使自己免责。如果我与他人共同负债，例如我们二人共同承担要式允诺之债，而立遗嘱人只想使我受益，那么我提起诉讼时所能取得的，不是以清偿确认方式免债——否则我的共同债务人也会违背立遗嘱人的意思而获释——而是通过协议免债。但如果我们是合伙人呢？我们应否通过清偿确认方式免债？否则，债权人向我的共同债务人请求时，我也会受到牵连。尤利安在《学说汇纂》第三十二卷中写道：若我们并非合伙人，我应通过协议免债；若我们是合伙人，则应通过清偿确认方式免债。

<!-- source-p 298 -->
<a id="34.3.3.4"></a>**4.**接下来要问：即使遗嘱中没有写明其姓名，那位合伙人是否也视为受遗赠人？虽然只要我们是合伙人，遗嘱所带来的利益便会及于双方。正确的意见是：不仅遗嘱中列名之人应视为受遗赠人，即使未被列名，只要遗嘱人在设立免债时也考虑到该人，该人同样应视为受遗赠人。

<!-- source-p 299 -->
<a id="34.3.3.5"></a>**5.**在这种情形下，双方均视为受遗赠人。例如，我所欠提提乌斯的债务若遗赠给他，且是为了使我获释，没有人会否认我也是受遗赠人，尤利安在同卷中也这样写道。马尔凯鲁斯补充说：即使我有清偿能力，遗赠仍同时属于我和我的债权人，因为债权人有利害关系保有两个债务人。

<!-- source-p 300 -->
<a id="34.3.4"></a>**34.3.4**

<!-- source-p 301 -->
庞波尼乌斯《普劳提乌斯评注》第七卷。

<!-- source-p 302 -->
那么，债权人何以能够依据遗嘱提起诉讼呢？只有在债权人承诺：若债务人提出请求，他将为债务人提供辩护，继承人才应被判令履行。反之，如果债务人起诉，继承人只须为其提供对抗债权人的辩护，无须作其他给付。

<!-- source-p 303 -->
<a id="34.3.5"></a>**34.3.5**

<!-- source-p 304 -->
乌尔比安《萨比努斯评注》第二十三卷。

<!-- source-p 305 -->
<a id="34.3.5.pr."></a>**序言。**如果某人既有主债务人又有保证人，并将免除主债务人的债务遗赠给该主债务人，尤利安在同书中写道，应通过清偿确认方式使主债务人免责；否则，若转而起诉保证人，就会以另一法律理由向主债务人追偿。不过，如果保证人是出于赠与目的而介入，且无权向主债务人追偿，情况又如何？或者，如果款项已转到保证人手中，而保证人又以自己的名义提供了主债务人，并亲自充任保证人呢？在这些情形下，应通过协议使主债务人免责。我们通常会说，应将主债务人可主张的协议抗辩授予保证人；但由于遗赠人的意思与订立协议之人的意思不同，我们不能如此处理。

<!-- source-p 306 -->
<a id="34.3.5.1"></a>**1.**如果将免债遗赠给保证人，毫无疑问，正如尤利安所写，应通过协议使保证人免责。但我认为，在某些情形下也应以清偿确认方式使其免责，例如他实际上同时就是主债务人，或是该项债务中的共同债务人。

<!-- source-p 307 -->
<a id="34.3.5.2"></a>**2.**尤利安在同书中写道：如果家子是债务人，而其父亲获遗赠免债，应通过协议使父亲免责，以免家子也随之免责。他说，遗赠开始生效之日，家父特有产中是否有财物并不重要；父亲因此项遗赠取得了保障。他尤其指出，在审理诉讼之日应考察特有产。尤利安将这种父亲的情形与丈夫相类比：妻子在离婚后将嫁资债务的免除遗赠给丈夫。尤利安认为，即便遗赠开始生效之日丈夫无清偿能力，他仍是受遗赠人；并认为两人都不得请求返还已经支付的款项。但马尔凯鲁斯的意见更为正确：父亲可以请求返还，因为他付款时尚不是债务人；丈夫则不可以，因为他清偿了自己的债务。即使有人认为父亲也是债务人，他仍处于附条件债务人的地位，而附条件债务人清偿后可以请求返还，这一点并无疑问。

<!-- source-p 308 -->
<a id="34.3.5.3"></a>**3.**如果继承人被命令免除家子的债务，尤利安没有说明应以清偿确认还是协议使家子免责；但他似乎认为应以清偿确认方式免债，而这也会使父亲受益。除非能够明确证明立遗嘱人另有意思，否则应遵此意见。所谓另有意思，是指立遗嘱人意在不使家子受到追索，而非不使父亲受到追索；在这种情况下，不得通过清偿确认使家子免责，而应以协议免债。

<!-- source-p 309 -->
<a id="34.3.5.4"></a>**4.**尤利安还写道：如果父亲为家子充任保证人，而免债遗赠给了父亲，应将其视为保证人而非父亲，通过协议使其免责；因此，仍可就特有产向其起诉。尤利安认为，只有在立遗嘱人仅意在使父亲以保证人身份免责时，才适用此规则；否则，如果立遗嘱人也意在使其以父亲身份免责，则应使其就特有产责任一并免责。

<!-- source-p 310 -->
<a id="34.3.6"></a>**34.3.6**

<!-- source-p 311 -->
雅沃勒努斯《书信集》第六卷。

<!-- source-p 312 -->
<a id="34.3.6.pr."></a>**序言。**家子被解放出父权后，父亲只能在其须就特有产或用于家父事务的财产承担给付责任的范围内依据遗嘱起诉。因为只有在父亲具有利害关系的范围内，该遗赠才归父亲。

<!-- source-p 313 -->
<a id="34.3.6.1"></a>**1.**可以进一步问：父亲能否依据遗嘱起诉，以使家子也免于诉讼。有些人认为诉权应扩展至此，因为如果父亲在解放家子后仍允许其保有特有产，父亲显然有利害关系。我持相反意见：我认为，依据这类遗嘱文字，父亲无权请求更多；他只能不再给付原本须向继承人给付的部分。

<!-- source-p 314 -->
<a id="34.3.7"></a>**34.3.7**

<!-- source-p 315 -->
乌尔比安《萨比努斯评注》第二十三卷。

<!-- source-p 316 -->
<a id="34.3.7.pr."></a>**序言。**不仅可以免除全部债务，也可以免除其中一部分，或免除债务关系的一部分；尤利安在《学说汇纂》第三十三卷中讨论过这一点。

<!-- source-p 317 -->
<a id="34.3.7.1"></a>**1.**某人以要式允诺约定给付斯提库斯或十，并命令继承人不得向其请求斯提库斯。此项遗赠显然有效，但其内容为何，我们还须考察。尤利安写道：应认为，遗嘱之诉的效果是通过清偿确认使债务人免责；如此一来，债务人当然也就十的债务一并免责。因为清偿确认等同于清偿：如同债务人给付斯提库斯时会获释一样，通过对斯提库斯作清偿确认，他也会获释。

<!-- source-p 318 -->
<a id="34.3.7.2"></a>**2.**如果继承人被命令免除债务人的二十，而债务人实际只欠十，尤利安同样在《学说汇纂》第三十三卷中写道，仍应使其免除十；因为即使对他作了二十的清偿确认，他也只就十的债务免责。

<!-- source-p 319 -->
<a id="34.3.7.3"></a>**3.**如果指定了两名继承人，而立遗嘱人命令其中一人向债权人清偿，该遗赠仍有效；共同继承人可以依据遗嘱起诉，要求向债权人清偿。

<!-- source-p 320 -->
<a id="34.3.7.4"></a>**4.**只有在立遗嘱人生前未从债务人处收取债务的情况下，遗赠给债务人的免债才发生效力；如果已经收取，遗赠即告消灭。
