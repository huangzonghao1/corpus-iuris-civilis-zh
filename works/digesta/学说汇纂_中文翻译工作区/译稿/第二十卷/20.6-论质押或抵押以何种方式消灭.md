# D.20.6 论质押或抵押以何种方式消灭

<!-- source-p 001; 原文导航锚点 6、题名锚点 20.6 -->
<a id="6"></a><a id="20.6"></a>**20.6.0. 论质押或抵押以何种方式消灭（*Quibus modis pignus vel hypotheca solvitur*）**

<!-- source-p 002 -->
<a id="20.6.1"></a>**20.6.1**

<!-- source-p 003 -->
**帕比尼安：《答复录》第十一卷。**

<!-- source-p 004 -->
<a id="20.6.1.pr."></a>**序言。**某债务人不在时，其朋友为其处理事务，并以自己的钱款赎回质物，而非购买债权；这应视为质物原有的权利状态已恢复给所有人。因此，处理事务的朋友不能正当地请求给予自己准用的塞尔维亚诉讼；不过，若他占有该物，则可凭恶意抗辩获得保护。

<!-- source-p 005 -->
<a id="20.6.1.1"></a>**1.**出卖人收取部分价款后，将已售不动产设定为质物；此后，他以书信将剩余价款赠与买受人。出卖人死亡后，该赠与因若干原因被认定无效。财政库继受出卖人的地位后，若依据质权请求该不动产，显然不能成立：最初赠与时解除质押的约定已经作出。法律虽使金钱赠与无效，但该规则不适用于解除质押。

<!-- source-p 006 -->
<a id="20.6.1.2"></a>**2.**缺席者的诉讼辩护人提供了判决清偿担保；后来诉讼转而针对本人提起时，辩护人提供的、用于担保判决债务的保证人不再承担责任，他们提供的质物也不再受约束。

<!-- source-p 007 -->
<a id="20.6.2"></a>**20.6.2**

<!-- source-p 008 -->
**盖尤斯：《行省告示评注》第九卷。**

<!-- source-p 009 -->
如果债权人依据塞尔维亚诉讼向占有人请求质物，而占有人提出按诉讼估价支付该物的价额，之后债务人又向占有人主张该物，那么，只有债务人先向占有人提出清偿债务，才允许其这样做。

<!-- source-p 010 -->
<a id="20.6.3"></a>**20.6.3**

<!-- source-p 011 -->
**乌尔比安：《论疑难问题》第八卷。**

<!-- source-p 012 -->
如果某物以这样的条件出售：在某一确定日期前若有人提出更优条件，买卖即不维持；该物已经交付，而买受人在有人提出更优条件之前又将其设定为质物，那么，马尔凯鲁斯在《学说汇纂》第五卷中说，一旦有人提出更优条件，质押即告消灭。不过，如果该物的出售条件是买受人未表示不满则买卖维持，他认为质押并不因此消灭。

<!-- source-p 013 -->
<a id="20.6.4"></a>**20.6.4**

<!-- source-p 014 -->
**乌尔比安：《告示评注》第七十三卷。**

<!-- source-p 015 -->
<a id="20.6.4.pr."></a>**序言。**如果债务人的财物已设定质押，而债务人将自己购买的奴隶退还出卖人，塞尔维亚诉讼是否因此不再适用？较妥当的看法是，该诉讼并不因此失去适用，除非此事是在债权人同意下办理的。

<!-- source-p 016 -->
<a id="20.6.4.1"></a>**1.**如果债权人同意出售质物，或者同意债务人将该物互易、赠与或作为嫁资给付，应认为质押已经解除；但若债权人同意出售或作其他处分时保留了自己的质押权，则不在此限，因为许多人同意处分时会保留质押权。反之，如果债权人亲自出售该物，但其出售的意思是除非债务得到清偿，否则不放弃质押，那么应认为抗辩不妨碍他。即使债权人未曾允许出售质物，但事后追认了该买卖，也应作同样处理。

<!-- source-p 017 -->
<a id="20.6.4.2"></a>**2.**有一问题值得细究：如果特定设定担保之物的出售无效，债权人曾表示同意这一事实是否应对其不利？例如，是否有某项法律原因阻止了出售？应当认为，质押仍然有效。

<!-- source-p 018 -->
<a id="20.6.5"></a>**20.6.5**

<!-- source-p 019 -->
**马尔基安：《抵押公式专论》单卷。**

<!-- source-p 020 -->
<a id="20.6.5.pr."></a>**序言。**债权人放弃抵押，或者约定不再请求给付金钱时，抵押也会消灭；除非有人认为，双方约定的只是不得向债务人本人请求给付，而不涉及抵押物。若作出约定时抵押物可能由他人占有，又该如何处理？不过，既然约定产生永久抗辩，也可以在此情形下作同样解释，即债权人放弃抵押。

<!-- source-p 021 -->
<a id="20.6.5.1"></a>**1.**如果债权人约定一年内不请求给付金钱，应理解为他也就抵押作出了同样的约定。

<!-- source-p 022 -->
<a id="20.6.5.2"></a>**2.**如果双方约定以提供保证人代替抵押，并且保证人已经提供，就应认为债权人已获满足，抵押因此解除。债权人出售债权并取得价款则属另一回事：在这种情况下，所有债务关系均保持完整，因为所收取的是价款，而非清偿。

<!-- source-p 023 -->
<a id="20.6.5.3"></a>**3.**如果债权人就抵押物提出宣誓，而对方宣誓该物并未设定担保，也应认为债权人已获满足。

<!-- source-p 024 -->
<a id="20.6.6"></a>**20.6.6**

<!-- source-p 025 -->
**乌尔比安：《告示评注》第七十三卷。**

<!-- source-p 026 -->
<a id="20.6.6.pr."></a>**序言。**质押会因债务得到清偿或因其他方式使债权人获得满足而解除。如果质押设有期限，该期限届满时也应作同样解释；质押义务因任何其他原因终止时亦然。

<!-- source-p 027 -->
<a id="20.6.6.1"></a>**1.**准备清偿债务的人，应认为已经解除质押；但准备提供其他满足而非清偿的人，情形则不同。因此，债权人若接受其他满足，该行为对其有利；因为债权人既已接受其替代清偿，就应自行承担后果。反之，债权人不接受其他满足而要求清偿，并无可责之处。

<!-- source-p 028 -->
<a id="20.6.6.2"></a>**2.**不过，在提供担保时，我们不采纳阿提利基努斯的意见；他认为，若债权人就一笔确定金额获得了担保，就应放弃质物。

<!-- source-p 029 -->
<a id="20.6.7"></a>**20.6.7**

<!-- source-p 030 -->
**盖尤斯：《抵押公式专论》单卷。**

<!-- source-p 031 -->
**序言。**如果债权人同意出售，抵押即告解除；但未成年人所作的同意，只有在监护人在场并给予同意时，或者监护人本人同意时，方可视为有效；当然，法官须认定此事给未成年人带来某种利益，或者已使其获得充分满足。

<!-- source-p 032 -->
<a id="20.6.7.1"></a>**1.**我们还要考察：全体财产代理人或管理奴隶的同意是否有效；该奴隶不仅可以受领清偿，而且是为此事务而受任的。应当认为，这些人的同意无效，除非他们获得了特别授权。

<!-- source-p 033 -->
<a id="20.6.7.2"></a>**2.**如果与债务人的代理人约定该物不再受担保约束，应认为债务人可以通过恶意抗辩获益；但如果是与其奴隶作出该约定，债务人就应依据约定抗辩本身获益。

<!-- source-p 034 -->
<a id="20.6.7.3"></a>**3.**如果双方约定让与共有物中未分割的一份，而出售的又是特定物，可以认为，自始就应就剩余部分提起诉讼，且不存在抗辩阻却该诉讼。

<!-- source-p 035 -->
<a id="20.6.7.4"></a>**4.**应当注意：如果某人将共有物中未分割的一份设定抵押，后来与共有人分割该物，债权人并不当然只对分配给出质人的那一份享有担保；双方各自的份额仍应按未分割共有的状态，各有一半继续受担保约束。

<!-- source-p 036 -->
<a id="20.6.8"></a>**20.6.8**

<!-- source-p 037 -->
**马尔基安：《抵押公式专论》单卷。**

<!-- source-p 038 -->
<a id="20.6.8.pr."></a>**序言。**正如有体物灭失时其上的质押或抵押消灭，用益权消灭时，其上的质押或抵押也随之消灭。

<!-- source-p 039 -->
<a id="20.6.8.1"></a>**1.**债权人可以约定某物不再作为质物或抵押物；因此，如果债权人与继承人作出这种约定，该约定也使依《特雷贝利安元老院决议》向其返还遗产的人受益。

<!-- source-p 040 -->
<a id="20.6.8.2"></a>**2.**如果债务人的代理人是为自身利益行事的代理人，我认为毫无疑问，其所作约定会损害债权人。同样，如果债权人一方的代理人成为为自身利益行事的代理人，他会因作出约定而使抵押之诉对自己失去效用；在这种程度上，我认为也可以正确地说，这一抗辩在此情形下会损害诉讼当事人本人。

<!-- source-p 041 -->
<a id="20.6.8.3"></a>**3.**如果约定共有物中未分割的一半不作为质物，那么，不论向何种占有人请求该农庄的任何部分，都不能正当地请求其中的一半。

<!-- source-p 042 -->
<a id="20.6.8.4"></a>**4.**如果数人将共有物中的未分割份额设为抵押，债权人又与其中一人约定该物不再作为抵押，之后却向此人请求该物，即使与债权人订立约定的人占有整座农庄，也应认为该约定仅涉及未分割的一份，不能据此阻却债权人对整座农庄提出请求。

<!-- source-p 043 -->
<a id="20.6.8.5"></a>**5.**我们还要考察：家子或奴隶能否约定解除以特有产受领的质押；他们对该特有产享有自由管理权。既然他们不能赠与，是否也不能约定该物不再作为质物？应当认为他们可以作此约定，尤其是在因该约定而收取价款时；这就如同他们出售质物一样。

<!-- source-p 044 -->
<a id="20.6.8.6"></a>**6.**如果农庄经债权人同意而转让，且出售确已完成，债权人仍要求将该农庄归于自己，实属无理；但如果买卖并未完成，仅有债权人曾同意出售这一点，还不足以排除其请求。

<!-- source-p 045 -->
<a id="20.6.8.7"></a>**7.**如果债务人仍占有该农庄，那么去考察经债权人许可出售特定设定抵押的农庄是否多此一举？不过，也可能发生这样的情形：债务人经债权人许可出售后，又善意地从买受人或其继受人处买回该物；或者债务人自己成为买受人的继承人。可是，由于价款尚未支付，债务人将该物重新取得时便会产生恶意的嫌疑，债权人因此可以提出恶意复抗辩。

<!-- source-p 046 -->
<a id="20.6.8.8"></a>**8.**我们还要考察：债务人提提乌斯经债权人同意，将该物出售给梅维乌斯，或者出售给梅维乌斯所向其购买之人；此后梅维乌斯成为提提乌斯的继承人，债权人再向梅维乌斯请求该物，法律上应如何处理？债权人不应从并非依据继承、而是以其他方式取得该物的人手中夺走该物。然而，也可以这样说：如果提提乌斯的欺诈在此事中起了作用，致使债权人不能从占有人处取得金钱，那么让其受骗显然极不公允。

<!-- source-p 047 -->
<a id="20.6.8.9"></a>**9.**如果梅维乌斯又将该农庄设定抵押给他人，而该后来的债权人尚未获偿，那么，重新允许其提出“若该物并非经债权人同意出售”（*si non voluntate creditoris venit*）的抗辩，就显得公平。尽管未清偿债务的债务人有恶意介入，接受该物作为质物的第二债权人仍处于较优地位。

<!-- source-p 048 -->
<a id="20.6.8.10"></a>**10.**不过，如果债务人向债权人请求准许其出售质物，以便更充分地清偿债务，那么较为稳妥的做法是：在作出准许前，先要求将要购买该物的人提供担保，保证将出售所得价款在债务额范围内支付给债权人。

<!-- source-p 049 -->
<a id="20.6.8.11"></a>**11.**“出售”一词应作广义理解，因此，即使债权人允许以遗赠方式处分该物，其许可也应有效；但是，如果遗赠被拒绝，质押即恢复。

<!-- source-p 050 -->
<a id="20.6.8.12"></a>**12.**如果债务人出售该物却未交付，债权人是否仍不受阻却，因为该物依然属于债务人的财产？还是说，由于债务人须承担买受之诉的责任，质押因此消灭？后一种看法更为可取。但如果出卖人没有取得价款，买受人也不准备支付，又该如何？也可以作同样的回答。

<!-- source-p 051 -->
<a id="20.6.8.13"></a>**13.**如果债权人允许出售，债务人却将该物赠与他人，债权人能否以抗辩排除该人？这或许主要是事实问题：债务人是否正是为了收取价款、以便也处理好自己的事务才要出售该物？若属此情形，债权人的同意不应使其受不利影响。但如果债务人将该物作为嫁资给付，在此情形下，由于婚姻负担，应当正当地视为出售。反过来说，如果债权人允许赠与，而债务人却出售该物，债权人将被排除；除非有人认为，债权人之所以允许赠与，是因为他与受赠人有交情。

<!-- source-p 052 -->
<a id="20.6.8.14"></a>**14.**如果债权人准许以十出售，而债务人只以五出售，应认为债权人不会因此被排除；反过来，如果债务人以高于债权人所准许的价额出售，则无须怀疑该出售有效。

<!-- source-p 053 -->
<a id="20.6.8.15"></a>**15.**如果债权人知道债务人出售该物，不能因此认为债权人已经同意；他之所以容许该物被出售，是因为知道自己的质权无论如何都会继续存在。但是，如果债权人在买卖文书上签字，通常应认为他已同意，除非明显看出他受了欺骗；即使没有书面文书，债权人同意时也应遵循同一规则。

<!-- source-p 054 -->
<a id="20.6.8.16"></a>**16.**如果债务人获准出售，而其继承人出售了该物，债权人当时如何理解，可能属于事实问题。不过，应当认为该物已经有效出售；法官不采纳这类过分细密的推论。〔译注：底本作 *suptilitates*，疑为 *subtilitates* 的拼写讹误；此处依文义译为“过分细密的推论”。〕

<!-- source-p 055 -->
<a id="20.6.8.17"></a>**17.**如果债务人在获准出售后不再占有该物，而新的占有人出售了该物，质押是否仍然存续，如同债权人仅允许特定的人出售？这后一种看法更可取。因为如果债权人允许的是新占有人出售，而不是其受领抵押的债务人出售，应当认为该抗辩会对债权人发生效力。

<!-- source-p 056 -->
<a id="20.6.8.18"></a>**18.**如果债权人同意债务人在一年或两年内出售，债务人在该期限届满后出售，并不能使债权人丧失质权。

<!-- source-p 057 -->
<a id="20.6.8.19"></a>**19.**如果债权人依据抵押之诉向占有人起诉并取得诉讼估价款，之后又向债务人请求清偿债务，我认为债务人可以提出恶意抗辩予以阻却。

<!-- source-p 058 -->
<a id="20.6.9"></a>**20.6.9**

<!-- source-p 059 -->
**莫德斯蒂努斯：《答复录》第四卷。**

<!-- source-p 060 -->
<a id="20.6.9.pr."></a>**序言。**提提乌斯先将一座农庄设定质押给塞姆普罗尼乌斯，随后又将同一农庄设定质押给盖乌斯·塞伊乌斯；之后，提提乌斯又将此前分别完整设定给这两人的同一农庄出售给他们，出售的为全部份额（*in assem*）。我询问：买卖成立后，质权是否消灭，以致二人只保有基于买卖取得的权利？莫德斯蒂努斯答复说，所有权依买卖取得而归于所询问的这两人；既然可以认定二人彼此同意买卖，就不能互相提起质物之诉。〔译注：*in assem* 的确切份额含义依底文暂作“全部份额”处理。〕

<!-- source-p 061 -->
<a id="20.6.9.1"></a>**1.**提提乌斯以农庄作质，从塞伊乌斯处取得借款。当时，该农庄此前已向公法人设定担保；第二债权人替其偿还了这笔公债。但梅维乌斯出现并主张，该农庄在先已向他设定担保。可是，证据显示，梅维乌斯曾参与并签署塞伊乌斯与公法人订立的担保文书；塞伊乌斯在文书中保证该农庄未向任何其他人设定担保。我询问：梅维乌斯是否可以提起某种对物诉讼？莫德斯蒂努斯答复说，对于自己曾表示同意的质押，所询问之人绝不能再予保有。

<!-- source-p 062 -->
<a id="20.6.10"></a>**20.6.10**

<!-- source-p 063 -->
**保罗：《疑问集》第三卷。**

<!-- source-p 064 -->
<a id="20.6.10.pr."></a>**序言。**债务人经债权人同意出售质物，此后债务人与买受人又约定解除买卖，债权人的质权仍然保留。因为债务人和债权人都恢复了原有的权利状态；债权人并非在任何情况下都放弃质物，只有在买受人仍保有该物、没有将其返还出卖人时，才是如此。因此，即使买卖诉讼已经开始，出卖人最终获判无责，或者因未交付而被判赔偿利益损失，也应认为债权人的质权仍然保留；即使该买卖未经债权人同意，这些情形也可能发生。

<!-- source-p 065 -->
<a id="20.6.10.1"></a>**1.**如果债权人出售了质物，而买卖随后解除，或者奴隶被退还，所有权即回复于债务人。凡被允许出售他人之物的人，均适用同一规则：他们虽能将所有权移转给买受人，却不会因此从买受人处重新取得所有权；买卖解除后，该物只是恢复到先前的法律状态。
