# D.20.1 论质押与抵押及其成立方式和相关约定

<!-- source-p 001 -->
<a id="1"></a><a id="20.1"></a>**20.1.0　论质押与抵押及其成立方式和相关约定（*De pignoribus et hypothecis et qualiter ea contrahantur et de pactis eorum*）**

<!-- source-p 002 -->
<a id="20.1.1"></a>**20.1.1**

<!-- source-p 003 -->
**帕比尼安《答复》第十一卷**

<!-- source-p 004 -->
<a id="20.1.1.pr."></a>**序言（pr.）** 约定以某人现有或日后取得的全部财产设定质押，属于受承认的约定。如果约定仅针对他人之物，而该物并非欠债人所有；此后欠债人取得该物所有权时，若债权人明知该物属于他人，债权人较难取得准用诉权，但占有人较容易保留该物。

<!-- source-p 005 -->
<a id="20.1.1.1"></a>**1.** 奴隶被交付作质后，若未就该奴隶的特有产另作特别约定，债权人便不能出售该奴隶的特有产；无论该奴隶何时从主人处取得特有产，均不影响这一点。

<!-- source-p 006 -->
<a id="20.1.1.2"></a>**2.** 土地设质时，双方明确约定孳息也作为质物。善意买受人已消费这些孳息的，不得依准用塞尔维亚诉讼被迫返还。因为既已认定，质押关系不因取得时效而消灭：质押问题与所有权主张相分离。孳息则不同，因为孳息从未属于欠债人。

<!-- source-p 007 -->
<a id="20.1.1.3"></a>**3.** 双方约定，如果到期日未支付利息，抵押物孳息应抵偿利息，并以法定利率为限。虽然最初以要式口约约定的利率较低，但该约定仍然有效；因为如果到期时连较低利率的利息也未支付，债权人本可有效地通过要式口约请求法定的较高利率。

<!-- source-p 008 -->
<a id="20.1.1.4"></a>**4.** 妻子将一处地产赠与丈夫，丈夫又将该地产设质。离婚后，妻子取回该地产的占有，并以此为丈夫的债务设质。妻子有效设质的金额，仅限于她本应向丈夫偿付的金额；也就是说，只有丈夫对地产的支出超过其从地产取得的孳息时，妻子才负有相应债务。因为就该金额而言，妻子是在处理自己的事务，而非承接他人的事务。

<!-- source-p 009 -->
<a id="20.1.2"></a>**20.1.2**

<!-- source-p 010 -->
**帕比尼安《答复》第三卷**

<!-- source-p 011 -->
保证人接受了质物或抵押，并据此支付款项；如果他提起委任之诉，或被他人提起委任之诉，应依债权人的标准衡量其过失。但不得依交付质物所生的诉讼对他提起诉讼。

<!-- source-p 012 -->
<a id="20.1.3"></a>**20.1.3**

<!-- source-p 013 -->
**帕比尼安《问题集》第二十卷**

<!-- source-p 014 -->
<a id="20.1.3.pr."></a>**序言（pr.）** 如果欠债人请求返还其物，却因未能证明该物属于自己而败诉，债权人仍应享有塞尔维亚诉讼，前提是债权人证明：订立质押约定时，该物属于欠债人的财产。即使欠债人在请求返还遗产的诉讼中败诉，塞尔维亚诉讼的法官也应审查质押关系，而不受遗产诉讼中既有判决的拘束。不过，在遗赠和自由释放的情形中，规则有所不同：如果判决支持主张法定继承权的人，就依该判决处理。但债权人不能在各方面都与受遗赠人等同，因为遗赠只有在遗嘱被认定有效时才能成立；而质物可能已经有效设定，只是债权人的诉讼未能妥善提起。

<!-- source-p 015 -->
<a id="20.1.3.1"></a>**1.** 某人在一项诉讼中不公正地败诉，之后将其曾请求返还的物设质。债权人所能取得的权利不得超过出质人本人的权利。因此，债权人将受到既判事项抗辩的阻却；即使胜诉者本人无法就该物提起独立诉讼，也不影响这一点。应考察的不是胜诉者本人没有什么权利，而是欠债人对所设质之物曾享有什么权利。

<!-- source-p 016 -->
<a id="20.1.4"></a>**20.1.4**

<!-- source-p 017 -->
**盖尤斯《论抵押程式》单篇**

<!-- source-p 018 -->
抵押因当事人达成约定而成立：某人约定以其财物为某项债务承担抵押责任。至于采用何种措辞，并不重要；合意成立的债务关系也是如此。因此，即使没有书面文件，只要双方约定设定抵押且能够证明，约定涉及的财物就受抵押约束。书面文件的作用，是使已经达成的约定更容易证明；但即使没有书面文件，只要有证据，约定仍然有效。婚姻亦然，即使没有以书面方式制作证明文件，婚姻仍可成立。

<!-- source-p 019 -->
<a id="20.1.5"></a>**20.1.5**

<!-- source-p 020 -->
**马尔西安《论抵押程式》单篇**

<!-- source-p 021 -->
<a id="20.1.5.pr."></a>**序言（pr.）** 应当知道，任何债务都可以用财物设定抵押担保，无论是借款、嫁资、买卖、租赁或委任所生的债务；无论债务是即时到期、约定将来到期，还是附有条件；无论债务已在当前合同中成立，还是先于该合同成立。也可以为将来发生的债务设定抵押；既可以为全部债务，也可以只为其中一部分设定抵押；既可以担保民法债务或裁判官法债务，也可以仅担保自然债务。但对于附条件的债务，只有条件成就后，抵押才发生效力。

<!-- source-p 022 -->
<a id="20.1.5.1"></a>**1.** 质押与抵押之间，仅名称不同。

<!-- source-p 023 -->
<a id="20.1.5.2"></a>**2.** 某人既可以为自己的债务设定抵押，也可以为他人的债务设定抵押。

<!-- source-p 024 -->
<a id="20.1.6"></a>**20.1.6**

<!-- source-p 025 -->
**乌尔比安《评告示》第七十三卷**

<!-- source-p 026 -->
如果约定以某人现有或将来取得的一般财产设定担保，不包括那些显然不可能是其特别意图设定担保的财物。例如，应将家具、衣物以及其日常使用的奴隶留给债务人，因为可以确定，他本不会将这些财物设质。对其极为必要的家内服务人员，或与其具有特殊感情联系的人员，也应如此处理。

<!-- source-p 027 -->
<a id="20.1.7"></a>**20.1.7**

<!-- source-p 028 -->
**保罗《评告示》第六十八卷**

<!-- source-p 029 -->
或者，对日常使用的物品，不得提起塞尔维亚诉讼。

<!-- source-p 030 -->
<a id="20.1.8"></a>**20.1.8**

<!-- source-p 031 -->
**乌尔比安《评告示》第七十三卷**

<!-- source-p 032 -->
因此， 姘居伴侣、非婚生子女、收养照料的儿童，以及其他此类家内服务人员，均不包括在一般财产担保之内。

<!-- source-p 033 -->
<a id="20.1.9"></a>**20.1.9**

<!-- source-p 034 -->
**盖尤斯《评行省告示》第九卷**

<!-- source-p 035 -->
**序言（pr.）** 对于某人在达成约定时已经拥有的财物，也应适用同一规则。

<!-- source-p 036 -->
<a id="20.1.9.1"></a>**1.** 可以作为买卖标的的物，也可以设定质押。

<!-- source-p 037 -->
<a id="20.1.10"></a>**20.1.10**

<!-- source-p 038 -->
**乌尔比安《评告示》第七十三卷**

<!-- source-p 039 -->
如果欠债人同时将自己的财物为两名债权人设质，并约定每名债权人均可就全部财物实现担保，那么在对抗第三人时，每名债权人都可以分别提起全部塞尔维亚诉讼。但两名债权人彼此发生争议时，占有人的地位较优；占有人可以提出以下抗辩：“双方并未约定同一物也为我设质。”如果双方约定财物按份设质，则各人均可提起准用诉讼，无论对方当事人还是第三人均可起诉；通过该诉讼，各自可以取得该物一半的占有。

<!-- source-p 040 -->
<a id="20.1.11"></a>**20.1.11**

<!-- source-p 041 -->
**马尔西安《论抵押程式》单篇**

<!-- source-p 042 -->
**序言（pr.）** 依法管理市镇共同体财产的人，如果为市镇借入款项，可以用该财产设定担保。

<!-- source-p 043 -->
<a id="20.1.11.1"></a>**1.** 如果当事人约定以孳息抵息（底本转写作 *antixrysis*，通称 *antichresis*），并让债权人进入土地或房屋，债权人便以质物占有的方式保有占有，直至债务人偿还款项；债权人可以出租该不动产，或者自行使用、居住，以孳息抵偿利息。因此，如果债权人丧失占有，通常可以提起事实之诉。

<!-- source-p 044 -->
<a id="20.1.11.2"></a>**2.** 用益权能否设质或抵押，曾有疑问；无论由所有权人还是仅享有用益权的人达成约定，问题均是如此。帕比尼安在《答复》第十一卷中写道，即使所有权人起诉债权人，主张“未经我同意，你无权使用和收益”，也应保护债权人；裁判官将给予如下抗辩：“如果债权人与用益权人约定以用益权设质。”既然裁判官会保护用益权买受人，为何不保护债权人？同理，债务人也会受到这一抗辩的阻却。

<!-- source-p 045 -->
<a id="20.1.11.3"></a>**3.** 城市土地役权不得设质；因此，当事人也不能约定以城市土地役权设定抵押。

<!-- source-p 046 -->
<a id="20.1.12"></a>**20.1.12**

<!-- source-p 047 -->
**保罗《评告示》第六十八卷**

<!-- source-p 048 -->
庞波尼说，还应考察通行权、道路权、赶牲畜通行权和引水权能否依质押约定设定担保。双方可以约定，在债务尚未清偿期间，债权人享有这些役权（当然以债权人拥有相邻土地为前提）；如果债务未在确定期限内清偿，债权人可以将这些役权出售给邻人。基于交易双方的利益，应承认此种意见。

<!-- source-p 049 -->
<a id="20.1.13"></a>**20.1.13**

<!-- source-p 050 -->
**马尔西安《论抵押程式》单篇**

<!-- source-p 051 -->
<a id="20.1.13.pr."></a>**序言（pr.）** 整群牲畜设质后，此后出生的牲畜也受担保；即使原有牲畜逐渐死亡、整群牲畜已全部更新，新牲畜仍受质押担保。

<!-- source-p 052 -->
<a id="20.1.13.1"></a>**1.** 以条件获得自由的奴隶也可以设定抵押，但条件成就时抵押即告消灭。

<!-- source-p 053 -->
<a id="20.1.13.2"></a>**2.** 既然允许将质物再次设质，只要两笔债务均未清偿，该物就受第二位债权人的质押担保；第二位债权人既可提出抗辩，也可提起准用诉讼。如果所有权人清偿了债务，质押即告消灭。不过，尚有疑问：第二位债权人能否就已经清偿的款项取得准用诉讼？例如，若交付作为质物的是一项债权，情况又如何？庞波尼在《评告示》第七卷中的意见正确：如果质物是欠债人对他人享有的金钱债权，在收取该款项后，债权人应将其与自己所欠金额抵销；如果欠债人所欠的是一件特定物，并已将其交付清偿，该物就转而作为第二位债权人的质物。

<!-- source-p 054 -->
<a id="20.1.13.3"></a>**3.** 对于地上权，债权人也可以对任何占有人合法行使权利；无论双方仅达成抵押约定，还是曾交付占有而后又丧失占有，均同。

<!-- source-p 055 -->
<a id="20.1.13.4"></a>**4.** 即使债权人已对债务人提起对人之诉并取得判决，抵押仍然有效，因为抵押之诉有其自身的条件；只有债务已清偿或债权人已获满足，抵押才消灭。在对防御人提起对人之诉时，即使对方提供担保并被判决承担责任，抵押仍继续有效。更不用说，无论对人之诉是针对主债务人、保证人，还是二者分别按份提起，即使他们都已被判决承担责任，抵押仍然有效；债权人仅因取得判决之诉，并不因此视为已获清偿。

<!-- source-p 056 -->
<a id="20.1.13.5"></a>**5.** 如果抵押是为附条件的债务设定的，在条件成就之前不得正当地提起诉讼，因为此时尚无债务；条件成就后，债权人便可以再次起诉。但如果债务已经到期，抵押本身却附有条件，而债权人在条件成就前提起抵押之诉，虽然债务尚未清偿属实，但让抵押因此消灭并不公平。因此，法官应要求提供担保：“如果条件成就而债务仍未清偿，并且抵押物尚存，就应恢复抵押。”

<!-- source-p 057 -->
<a id="20.1.13.6"></a>**6.** 如果抵押也担保利息，利息同样应予清偿；罚金亦同。

<!-- source-p 058 -->
<a id="20.1.14"></a>**20.1.14**

<!-- source-p 059 -->
**乌尔比安《评告示》第七十三卷**

<!-- source-p 060 -->
<a id="20.1.14.pr."></a>**序言（pr.）** 有人问，租金尚未到期时，是否也应允许债权人在此期间对质物提起诉讼。我认为，应当准许其追及质物，因为这关系到我的利益；塞尔苏斯也这样写道。

<!-- source-p 061 -->
<a id="20.1.14.1"></a>**1.** 凡仅成立自然债务的情形，质押关系仍继续存在，这一点已获确认。

<!-- source-p 062 -->
<a id="20.1.15"></a>**20.1.15**

<!-- source-p 063 -->
**盖尤斯《论抵押程式》单篇**

<!-- source-p 064 -->
**序言（pr.）** 尚不存在但将来会存在的物，也可以设定抵押，例如未收获的孳息、女奴所生子女、牲畜后代以及其他将来产生的物，均可受抵押担保。无论是土地所有人就用益权或将产生之物作出约定，还是用益权人作出约定，均应适用此规则；尤利安也是这样写的。

<!-- source-p 065 -->
<a id="20.1.15.1"></a>**1.** 有人说，债权人必须证明双方订立约定时该物属于债务人的财产；这一要求仅适用于双方针对特定物订立的约定，不适用于常见的概括性条款，即在特定财物设定抵押之外，约定债务人现有及日后取得的其他财产也一并担保，效力如同这些财物均已特别设质。

<!-- source-p 066 -->
<a id="20.1.15.2"></a>**2.** 已将自己的财物设质的人，又将其交由第二位债权人设质。为避免多重设质通常带来的风险，当事人往往声明该物除卢基乌斯·提提乌斯外未再设质，使该物仅在超过第一笔债务的范围内受担保；或者约定第一笔债务清偿后，整件财物均受担保。应考察：只有明确作出这类约定时，第二项担保才具此效果，还是只要约定超出第一笔债务的部分受抵押即可？第一位债权人获得清偿后，整件财物是否就包含在抵押约定之内，抑或仍只限于一部分？更可取的仍是我们先前所说的意见。〔本段末尾对第二顺位抵押范围的结论较为压缩，暂按仅就超过第一笔债务的部分设质处理。〕

<!-- source-p 067 -->
<a id="20.1.16"></a>**20.1.16**

<!-- source-p 068 -->
**马尔西安《论抵押程式》单篇**

<!-- source-p 069 -->
<a id="20.1.16.pr."></a>**序言（pr.）** 土地设定抵押后，若因冲积而扩大，扩大的部分也一并受抵押约束。

<!-- source-p 070 -->
<a id="20.1.16.1"></a>**1.** 未经所有人知情而将其财物设定抵押，此后所有人追认的，应认为其追认意在追溯至订立约定之时。但通常只有有权设定质押的人，其追认意愿才应获承认。

<!-- source-p 071 -->
<a id="20.1.16.2"></a>**2.** 设定抵押的物之后发生变更，抵押之诉仍然适用。例如，房屋设定抵押后被改建成花园；又如，双方约定以某一空地抵押，之后在其上建造房屋；或者以某块土地设质，随后在其上种植葡萄藤。

<!-- source-p 072 -->
<a id="20.1.16.3"></a>**3.** 在质物返还诉讼中，应查明被告是否占有诉讼所涉之物。如果被告并未占有，且并非因欺诈而停止占有，就应判其胜诉。若被告占有，只要支付债务或返还该物，也应判其胜诉；两者均不履行，则应判其承担责任。如果被告愿意返还但无法返还，例如该物不在当地而远在行省，可以通过担保处理：若被告承诺返还，即可获判免责。反之，如果被告因欺诈而停止占有，且虽竭尽全力仍无法返还原物，则应按原告就诉讼标的宣誓的金额判赔，这与其他对物之诉相同。因为如果判赔仅限于债务数额，对物之诉就没有意义；原告通过对人之诉也能取得同样结果。

<!-- source-p 073 -->
<a id="20.1.16.4"></a>**4.** 有时法官还应就孳息作出裁量，自诉讼开始之时起，将孳息一并计入判决。因为质押土地的价值可能低于债务额。对于此前产生的孳息，除非孳息仍然存在且质物价值不足以清偿债务，法官不能作出判决。

<!-- source-p 074 -->
<a id="20.1.16.5"></a>**5.** 债权人凭判决取得抵押物后，应如何持有该物，尚有疑问；因为他不能主张取得该物所有权。但他仍可提起抵押之诉。如果占有人提出既判事项抗辩，债权人可以答辩：“如果并未作出对我有利的判决。”

<!-- source-p 075 -->
<a id="20.1.16.6"></a>**6.** 如果欠债人因未返还质物而被判承担的金额，高于本金和利息的合计额，那么他只支付实际所欠金额时，抵押是否解除？就法律严格解释及判决效力而言，我不赞同；因为案件似乎一经判决，债务即转化为判决所确定的金额。但较为宽厚的意见是，欠债人只要支付实际所欠的金额，就应允许其解除抵押，不必支付更多。〔底本作 *suptilitatem*，此处依义理解为 *subtilitatem*。〕

<!-- source-p 076 -->
<a id="20.1.16.7"></a>**7.** 他人之物可以附条件地有效设定抵押，条件是该物后来归债务人所有。

<!-- source-p 077 -->
<a id="20.1.16.8"></a>**8.** 两人同时约定以同一物设定抵押时，各债权人究竟按各自债务的金额，还是各占一半享有抵押权，尚有疑问。更可取的意见是，抵押物应按各自债务数额担保。若二人都对占有人提起诉讼，各自可以请求其份额，还是可以像抵押物对双方均承担全部责任一样请求全部？如果抵押物在同一天分别交付给二人设质，应认定双方均可请求全部；如果并非如此，则各人只能请求自己的份额。

<!-- source-p 078 -->
<a id="20.1.16.9"></a>**9.** 当事人可以这样设定质押或抵押：如果款项未在确定期限内清偿，债权人便可按届时评定的公平价格，以买受人的身份占有该物。这种情形在某种程度上相当于附条件买卖。神圣塞维鲁皇帝和安东尼努斯皇帝也曾作出同样的敕答。

<!-- source-p 092 -->
**乌尔比安《评告示》第七十三卷**

<!-- source-p 093 -->
<a id="20.1.21.pr."></a>**序言（pr.）** 如果我的佃农与我的代理人约定设定质押，而我追认了该约定或曾授权代理人作出约定，就应视为我与佃农之间已经达成约定。

<!-- source-p 094 -->
<a id="20.1.21.1"></a>**1.** 欠债人善意地从非所有人处买得一名奴隶，并将其设质后仍占有该奴隶，债权人可以提起塞尔维亚诉讼。债权人对其起诉时，欠债人虽可提出诈欺抗辩，但债权人可以通过诈欺答辩排除该抗辩。尤利安也这样说，而且理由充分。

<!-- source-p 095 -->
<a id="20.1.21.2"></a>**2.** 质物偶然取得的任何利益或遭受的任何不利益，均归欠债人承担。

<!-- source-p 096 -->
<a id="20.1.21.3"></a>**3.** 质物未获返还时，应根据被告占有人评定诉讼标的；但针对欠债人和其他任何占有人，评定方式不同。对欠债人起诉，判赔不得超过其所欠债务，因为债权人并无超过该数额的利益；对其他占有人起诉，判赔则可以超过债务额。债权人取得超过债务的部分后，应依质权之诉将超额部分返还给欠债人。

<a id="20.1.26"></a>**20.1.26**

<!-- source-p 111 -->
**莫德斯蒂努《答复》第四卷**

<!-- source-p 112 -->
<a id="20.1.26.pr."></a>**序言（pr.）** 保证人请求权力机关准许其在清偿前先行占有质物，仿佛将替债权人履行债务；但他并未履行。现在，债务人的继承人已准备向债权人清偿。我问：是否应强制保证人返还质物？莫德斯蒂努答复：应当强制其返还。

<!-- source-p 113 -->
<a id="20.1.26.1"></a>**1.** 父亲劝说已脱离父权的儿子塞尤斯：既然他要从债权人塞普提基乌斯处借款，而父亲因故不能书写，就由儿子亲手写下借据，并在借据中提到以属于儿子的房屋设质。问题是，塞尤斯既已声明不接受父亲的遗产，是否仍可依法将该房屋作为自己的其他财产占有？仅因他依父亲指示亲笔写下借据，是否应认为他已同意设质，尽管他并未通过加盖印记或另行书写向父亲表示同意？莫德斯蒂努答复：塞尤斯既亲手写明以自己的房屋设质，显然已同意设定该项担保。

<!-- source-p 114 -->
<a id="20.1.26.2"></a>**2.** 卢基乌斯·提提乌斯将地产及其中的奴隶设定抵押。其继承人分割地产后，原有奴隶死亡，继承人又以其他奴隶替代。债权人后来将地产连同奴隶一并出售。问题是，买受人能否对如今位于地产中的奴隶主张所有权？莫德斯蒂努答复：如果这些奴隶本身并未设质，也不是由已设质的女奴所生，就没有对债权人承担担保责任。

<!-- source-p 115 -->
<a id="20.1.27"></a>**20.1.27**

<!-- source-p 116 -->
**马尔凯卢斯《学说汇纂》第五卷**

<!-- source-p 117 -->
有人将奴隶设质，债权人仅因极轻微的过错便将奴隶捆绑，随后又将其释放；由于债务未获清偿，债权人以低价出售奴隶。问题是，债权人的债权诉讼不足以追偿其损失，是否应当给予其对欠债人的其他诉权？如果债权人杀死奴隶或使其失明，又应如何处理？如果杀死奴隶，应给予展示之诉；如果使其失明，则应给予损害不法之诉，赔偿因其致残或捆绑而使质物追索落空所造成的损失。即使假设债权人因某种原因在债权诉讼中败诉，已无该项诉权，我认为这仍是值得裁判官审查并给予救济的情形。乌尔比安注：如果债权人为了损害出质人而捆绑奴隶，就应承担责任；如果奴隶确实应受惩戒，则不承担责任。

<a id="20.1.28"></a>**20.1.28**

<!-- source-p 119 -->
**保罗《问题集》第三卷**

<!-- source-p 120 -->
家子获得附条件遗赠后，父亲从继承人处接受了该家子自己的财物作为质物。父亲死亡或家子脱离父权后，遗赠条件成就，遗赠便应交付给家子。此时，父亲不能对质物主张所有权；家子也不能主张质物，因为他到此时才取得诉权，不能追溯至此前期间对质物享有任何权利；保证人的情形也是如此。

<!-- source-p 121 -->
<a id="20.1.29"></a>**20.1.29**

<!-- source-p 122 -->
**保罗《答复》第五卷**

<!-- source-p 123 -->
<a id="20.1.29.pr."></a>**序言（pr.）** 保罗答复说，概括约定足以使质物承担担保责任；但属于被继承人的财产中原本不包括、而由继承人后来基于其他原因取得的财物，遗嘱人的债权人不得主张。

<!-- source-p 124 -->
<a id="20.1.29.1"></a>**1.** 奴隶被设质后，由这些奴隶所生的奴隶也应依同一规则处理。不过，我们所说后出生的奴隶也受担保，无论双方是否特别约定，均以所有权归于设质人或其继承人为前提；如果奴隶在另一所有人处生育，其子女就不受担保。

<!-- source-p 125 -->
<a id="20.1.29.2"></a>**2.** 房屋设质后被烧毁，卢基乌斯·提提乌斯买下该地基并在其上重建房屋。问题是，质押权是否继续存在？保罗答复：质物追索权继续存在，因此地上建筑似乎随土地而受抵押权拘束。不过，善意占有人不应被迫将建筑物返还债权人，除非债权人偿还其建造支出，且偿还额以该物因此增加的价值为限。

<!-- source-p 126 -->
<a id="20.1.29.3"></a>**3.** 如果奴隶在主人知情并同意的情况下约定以主人的全部财产设质，那么作出担保的奴隶本人也应依质押规则承担责任。

<a id="20.1.31"></a>**20.1.31**

<!-- source-p 131 -->
**谢沃拉《答复》第一卷**

<!-- source-p 132 -->
<a id="20.1.31.pr."></a>**序言（pr.）** 某项公田租赁法规定，超过确定期限仍未缴纳地租，该土地即应归还土地所有人。之后，占有人将该土地设质。问题是，该土地是否有效设质？答复说：如果有款项交付，就成立质押。

<!-- source-p 133 -->
<a id="20.1.31.1"></a>**1.** 又有人问：如果债务人和债权人均未缴纳地租，因此法院依该法判决土地归土地所有人，土地所有人的权利是否优先？答复说，如果如题述所言，土地所有人因未缴纳地租而依法行使其权利，质押权也随之消灭。

<!-- source-p 134 -->
<a id="20.1.32"></a>**20.1.32**

<!-- source-p 135 -->
**谢沃拉《答复》第五卷**

<!-- source-p 136 -->
欠债人约定，凡搬入、运入、输入土地，以及在土地上出生或备置的任何财物，均作为质物。土地的一部分没有佃户，欠债人将该部分交给自己的事务管理人耕种，并指定了耕作所需的奴隶。问题是，管事斯提库斯、其他派往耕作的奴隶以及斯提库斯的副手奴隶是否也受质押约束？答复认为，只有主人带到土地上且意在让其永久留在那里、而非暂时借用的奴隶，才受担保。〔底本末尾作 *obligatos essententiarum respondit*，疑有词语粘连；依上下文暂按“答复认为……受担保”处理。〕

<a id="20.1.33"></a>**20.1.33**

<!-- source-p 138 -->
**特里丰尼努《论争议问题》第八卷**

<!-- source-p 139 -->
某人承诺向你或提图斯付款；如果款项已经付给提图斯，付款人不得请求返还，但可以在清偿前取回交给提图斯的质物。〔本段 *solutum quidem Titio* 与 *ante solutionem* 的关系较为压缩，暂按“付款不能追回、质物可提前取回”直译。〕

<!-- source-p 140 -->
<a id="20.1.34"></a>**20.1.34**

<!-- source-p 141 -->
**谢沃拉《学说汇纂》第二十七卷**

<!-- source-p 142 -->
<a id="20.1.34.pr."></a>**序言（pr.）** 欠债人将商店交给债权人作质。问题是，这一行为是否不发生效力，还是“商店”一词也使店内货物受到担保？如果欠债人逐渐出售这些货物、另行购置其他货物并搬入商店，之后死亡，债权人能否以抵押之诉请求返还死亡时店内的一切财物，尽管货物种类已经改变、又有其他物品搬入？答复说：欠债人死亡时在商店中发现的财物，视为已经设质。

<!-- source-p 143 -->
<a id="20.1.34.1"></a>**1.** 他又问，若曾发出如下书信：“*Daneisamenos para sou dynaria pentakosia parekalesa se my bebaiwtyn all' hupovykyn par' emou labein: oidas gar akribws, hoti kai hy taberna kai ohi douloi mou oudeni katexontai y soi kai hws eusxymoni anvrwpw episteusas*。”〔拉丁释义为：我向你借了五百第纳里乌斯，请你接受我交付的质物，而非我的保证；你确切知道，我的商店和奴隶除向你设定担保外，未向任何人设质；你是基于对正直之人的信赖而借款给我。〕问题是，质押是否已经成立，还是因为信中没有日期和执政官纪年而不发生效力？答复说，既然看来双方已就质押达成合意，就不能仅因未注明日期和执政官、也未在书板上加盖印记，便认定质押义务未成立。

<!-- source-p 144 -->
<a id="20.1.34.2"></a>**2.** 债权人与欠债人约定，以欠债人现有或将来取得的全部财产设质。问题是，欠债人后来从他人处借入钱款，该钱款成为其财产后，是否也开始受抵押担保？答复说：是。
