# D.26.7 论曾经或未曾管理事务的监护人与保佐人的管理及责任，以及对一人或多人提起诉讼（*De administratione et periculo tutorum et curatorum qui gesserint vel non et de agentibus vel conveniendis uno vel pluribus*）

<!-- source-p 001 -->
<a id="7"></a><a id="26.7"></a>**26.7.0. 论曾经或未曾管理事务的监护人与保佐人的管理及责任，以及对一人或多人提起诉讼。**

<!-- source-p 002 -->
<a id="26.7.1"></a>**26.7.1**

<!-- source-p 003 -->
**乌尔比安：《告示评注》第三十五卷。**

<!-- source-p 004 -->
<a id="26.7.1.pr."></a>**序言。**通常可以通过非常程序，强令监护人承担并管理监护事务。

<!-- source-p 005 -->
<a id="26.7.1.1"></a>**1.**监护人一旦知悉自己已被指定为监护人，若仍不履职，便须自担风险。这是神圣的马尔库斯皇帝所确立的规则：凡知道自己已被指定为监护人，却未在规定期限内提出其所拥有的免责理由，仍不履职者，应自担风险。

<!-- source-p 006 -->
<a id="26.7.1.2"></a>**2.**对于充分进行诉讼防御而言，无论由监护人本人应诉，还是未成年人在监护人同意下应诉，都已足够；不应像对通常的诉讼代理人那样，强令监护人提供担保。因此，监护人可以选择自行应诉，或使未成年人出庭、由监护人表示同意后进行诉讼。不过，对于不能说话的人或缺席者，监护人应亲自应诉；对于已满七岁且在场的未成年人，监护人则应作出同意。

<!-- source-p 007 -->
<a id="26.7.1.3"></a>**3.**对于已达青春期但未满二十五岁者的诉讼，原告可以选择传唤本人到庭，由其在保佐人同意下应诉；也可以起诉保佐人，由保佐人本人应诉。如果该青年缺席，则无论如何都应起诉其保佐人。

<!-- source-p 008 -->
<a id="26.7.1.4"></a>**4.**监护人或保佐人均不应被禁止以本人名义传唤未成年人或青年人的债务人到庭，以维护其职责所要求的利益；如果未成年人或青年人自行采取此种诉讼行动，也不应禁止监护人或保佐人表示同意。

<!-- source-p 009 -->
<a id="26.7.2"></a>**26.7.2**

<!-- source-p 010 -->
**乌尔比安：《告示评注》第九卷。**

<!-- source-p 011 -->
<a id="26.7.2.pr."></a>**序言。**如果监护人使未成年人被判承担责任，或者监护人本人被判承担责任，判决之诉原则上应给予未成年人并向未成年人提起；尤其是在监护人并未主动出庭应诉，而是因未成年人缺席或尚属婴儿、无法授权监护人接受诉讼，才由监护人应诉时。神圣的皮乌斯皇帝曾以敕答确认此规则，此后又在多份敕答中说明：监护人被判承担责任后，除非未成年人放弃有关权利，否则判决之诉始终应向未成年人提起；若未成年人放弃，则既不得向监护人，也不得向未成年人提起。敕答还多次规定，不得扣押监护人的质物。

<!-- source-p 012 -->
<a id="26.7.2.1"></a>**1.**此外，马尔凯卢斯在《学说汇纂》第二十一卷中写道：即使监护人提供了担保，而未成年人随后放弃有关权利，也应使监护人的保证人获得保护；如果未成年人没有放弃，则既应保护未成年人，也应保护其保证人，尤其是在监护人是为缺席的未成年人或婴儿提供担保时。

<!-- source-p 013 -->
<a id="26.7.3"></a>**26.7.3**

<!-- source-p 014 -->
**乌尔比安：《告示评注》第三十五卷。**

<!-- source-p 015 -->
<a id="26.7.3.pr."></a>**序言。**如果指定了数名保佐人，庞波尼乌斯在《告示评注》第六十八卷中写道，即使仅由其中一人实施管理行为，该行为也应视为有效。对于精神失常者的保佐人也是如此：为免妨碍精神失常者的利益，裁判官会指定其中一人负责管理；该人未以诈欺方式实施的行为，均予承认。

<!-- source-p 016 -->
<a id="26.7.3.1"></a>**1.**如果受父权支配的父亲在遗嘱中指定由哪名监护人管理监护事务，裁判官认为应由该人管理；尊重父母的意愿是合理的，因为父亲无疑是为儿子妥善作了安排。对于父亲在遗嘱中指定、后由裁判官确认的监护人，裁判官也采取同样做法：如果父亲表明希望由某人管理监护事务，就由该人单独管理。

<!-- source-p 017 -->
<a id="26.7.3.2"></a>**2.**因此，其余监护人不负责管理事务；我们通常称他们为荣誉监护人。任何人都不应认为他们完全不承担风险：应先穷尽实际管理者的财产，再向这些荣誉监护人起诉，这一点是确定的。因为他们被指定为管理行为的监督者和守护者；如果他们看到实际管理者行为不当，却未将其控告为可疑监护人，日后就会被追问为何如此。因此，他们应当持续要求实际管理者提交账目，谨慎监督其行为；如果有款项可以存放，还应确保将其存放，以便购买土地。认为荣誉监护人绝不承担责任的人，不过是自我宽慰；如上所述，他们确实可能承担责任。

<!-- source-p 018 -->
<a id="26.7.3.3"></a>**3.**虽然裁判官表示，应优先将监护事务交给遗嘱人指定的人，但有时也会偏离该指定。例如，父亲作出指定时判断不周，可能当时未满二十五岁；或者指定时此监护人看似品行端正、可靠，后来却开始行为不端，而遗嘱人对此并不知情；又或者父亲是考虑到该人的财产状况才将事务交给他，而该人后来失去了这些财产。

<!-- source-p 019 -->
<a id="26.7.3.4"></a>**4.**即使父亲只指定了一名监护人，有时也会另行指定保佐人。我们的皇帝曾与其父共同作出敕答：有人指定自己的两名自由人为监护人，一人管理意大利事务，另一人管理非洲事务；应为他们另行指定保佐人，而不遵从父亲的安排。

<!-- source-p 020 -->
<a id="26.7.3.5"></a>**5.**关于监护人的规则，也应适用于父亲在遗嘱中指定、交由裁判官确认的保佐人。

<!-- source-p 021 -->
<a id="26.7.3.6"></a>**6.**由此可见，裁判官关心的是避免由多人共同管理监护事务。即使父亲没有指定应由谁管理，裁判官仍设法使事务由一人管理；毕竟，由一名监护人行使诉权和应诉都较为容易。

<!-- source-p 022 -->
<a id="26.7.3.7"></a>**7.**为免监护事务分散给多人，如果遗嘱人没有选定监护人，或者被选定的人不愿管理，就由获得多数监护人推举者负责。裁判官应命令召集他们；如果他们不出席，或在被命令出席后仍未能作出决定，裁判官就应查明情况后自行决定由谁管理监护事务。

<!-- source-p 023 -->
<a id="26.7.3.8"></a>**8.**当然，如果监护人不赞同裁判官的安排，而是都想亲自管理，理由是他们不信任被选定者，也不愿仅仅承担他人行为所带来的风险，那么应当说，裁判官应允许他们全体共同管理。

<!-- source-p 024 -->
<a id="26.7.3.9"></a>**9.**同样，如果监护人希望彼此分配监护事务，也应听取他们的意见，将管理事务分配给各人。

可以按份额或按地区分配；如果已如此分配，每人均可依据抗辩，阻止他人就自己未负责管理的份额或地区对其提起诉讼。

<!-- source-p 028 -->
<a id="26.7.5"></a>**26.7.5**

<!-- source-p 029 -->
**乌尔比安：《告示评注》第三十五卷。**

<!-- source-p 030 -->
<a id="26.7.5.pr."></a>**序言。**只有在款项能够积聚——也就是能够汇集到足以购买土地的数额——时，才有必要存放款项。如果监护财产经证明数额很少，即使将零散款项凑在一起也不足以为未成年人购买土地，就无须存放。因此，我们要考察监护财产达到多少时才须存放。既然存放款项的目的，是为未成年人购置土地，显然不应适用于极小的数额；由于每个案件均须具体审查，不能一概规定统一数额。但即使数额较少，如果监护人看起来可疑，也不应剥夺要求其存放款项的权利。

<!-- source-p 031 -->
<a id="26.7.5.1"></a>**1.**监护人只要处理过任何一项未成年人事务，即使所涉金额很少，也视为已经履行管理；那些通常负责强令怠于履职者开始管理的人，其介入理由便不复存在。

<!-- source-p 032 -->
<a id="26.7.5.2"></a>**2.**但如果监护人曾经管理事务，此后才停止履职，则可以请求将其认定为可疑监护人。

<!-- source-p 033 -->
<a id="26.7.5.3"></a>**3.**如果有人将监护事务委托他人管理，而受托人确已管理，就可以提起监护诉讼；因为通过他人进行管理的人，视为本人已经管理。如果受托人并未开始管理，则可以对委托人提起有用之诉。

<!-- source-p 034 -->
<a id="26.7.5.4"></a>**4.**父亲的债务人若管理其儿子的监护事务，也应在监护诉讼中承担责任，包括其原本欠父亲的债务。

<!-- source-p 035 -->
<a id="26.7.5.5"></a>**5.**如果监护人没有提醒已经达到青春期的未成年人请求指定保佐人——神圣的敕令要求曾管理监护事务的人履行这项义务——他是否应在监护诉讼中承担责任？我认为，监护诉讼足以处理此事，因为这与监护职责相连，尽管诉讼是在未成年人达到青春期之后提起。

<!-- source-p 036 -->
<a id="26.7.5.6"></a>**6.**如果年满二十五岁后仍未交付账目，且仍未交付与相关事务有关的文书，保佐人应本着诚信和体面，运用自己的判断完成已经开始的诉讼。因此，如果他们没有完成已确定应做的事项，我更倾向于认为，即使相关事务已经处理完毕，只要尚未就此结账，仍可提起事务管理之诉。

<!-- source-p 037 -->
<a id="26.7.5.7"></a>**7.**尤利安在《学说汇纂》第二十一卷中提出如下情形：某人临终时为儿子指定了监护人，并附加“我希望他们免于查账”的条款。尤利安说，监护人若未在管理中秉持诚信，就应被判令承担责任，尽管遗嘱写明他们无须交账。尤利安还说，他们也不得以遗嘱信托为由取得任何利益；此意见正确。因为任何人不得通过这种担保免除公法义务，也不得改变自古确立的制度。不过，监护人因监护事务遭受的任何损失，都可以通过遗赠或遗嘱信托予以补偿。

<!-- source-p 038 -->
<a id="26.7.5.8"></a>**8.**帕皮尼安在《答复集》第五卷中如此写道：父亲命令监护人在母亲的建议下管理儿子的事务，并据此免除监护人的责任。即使如此，监护人的职责仍完整存在；正派人应采纳母亲有益的建议。监护人的免责、父亲的意愿或母亲的介入，均不减损监护人的职责。

<!-- source-p 039 -->
<a id="26.7.5.9"></a>**9.**监护人甚至可以不遵守父亲的指示：如果父亲曾规定不得出售其财产、奴隶、衣物、房屋或其他承担风险的财物，监护人仍可不顾该项父亲意愿。

<!-- source-p 040 -->
<a id="26.7.5.10"></a>**10.**监护人一旦获知自己是监护人，就应知道监护事务的风险由自己承担。无论以何种方式获知都已足够，并不一定要通过正式通知传唤他；毫无疑问，即使没有正式告知，只要他从任何途径得知此事，就应由他承担风险。

监护人是否已经知悉，应由未成年人承担证明责任。

<a id="26.7.7"></a>**26.7.7**

<!-- source-p 045 -->
**乌尔比安：《告示评注》第三十五卷。**

<!-- source-p 046 -->
<a id="26.7.7.pr."></a>**序言。**监护人若未制作财产清册（通常称为盘点清册），应视为出于诈欺，除非能够提出某项必要且极正当的理由，说明为何未制作。因此，监护人若以诈欺方式未制作清册，就应对未成年人所受利益损失承担责任；该损失依诉讼中的宣誓确定。故在制作清册之前，监护人不得处理任何事务，除非该事务不能稍作延迟。

<!-- source-p 047 -->
<a id="26.7.7.1"></a>**1.**如果监护人未及时变卖那些会随时间损耗的财物，就须自担风险：他本应立即履行职责。如果他是在等候共同监护人，而其他人拖延或也想请求免责，是否可以宽恕他？不应轻易宽恕；他应履行自己的职责，既不可仓促，也不可无故拖延。

<!-- source-p 048 -->
<a id="26.7.7.2"></a>**2.**如果监护人以不正当手段或徇私方式购置不适宜的土地，就可以对其提起监护诉讼。若其既未行贿也未徇私，只是选中了条件不佳的土地，又如何处理？有人正确地说，在此问题上，监护人仅应对重大过失负责。

<!-- source-p 049 -->
<a id="26.7.7.3"></a>**3.**如果监护人在款项存放后怠于为未成年人购置土地，就应开始向其请求利息。尽管裁判官应强令监护人购置土地，但若其仍怠于办理，也应因拖延而被处以利息；除非未能购置并非由其所致。

<!-- source-p 050 -->
<a id="26.7.7.4"></a>**4.**监护人将款项挪作己用的，应支付法定利息，但只有在明确证明其确将款项挪作己用时才如此。未放贷或未存放款项的人，并不必然就是将款项挪作己用；神圣的塞维鲁皇帝也曾作此裁定。因此，必须证明该款项已被挪作己用。

<!-- source-p 051 -->
<a id="26.7.7.5"></a>**5.**如果监护人原本是未成年人的父亲的债务人，却没有向自己偿还债务，我们不认为他因此已将款项挪作己用；但他应支付自己曾向父亲承诺的利息。

<!-- source-p 052 -->
<a id="26.7.7.6"></a>**6.**如果监护人以自己的名义将未成年人的款项贷出，只有在未成年人愿意承担其他债权凭据所涉风险时，监护人才被要求交付自己收到的利息。

<!-- source-p 053 -->
<a id="26.7.7.7"></a>**7.**如果应为购置土地而存放款项，并且已经存放，就不计利息；如果没有存放，则若裁判官未曾命令存放，应支付未成年人通常享有的利息；若已命令而监护人未遵守，则须考察利息数额。裁判官通常会警告监护人：若未存放款项，或者存放有所迟延，就应支付法定利息。因此，如果裁判官曾作出此种警告，日后审理案件的法官应遵循裁判官的裁定。

<!-- source-p 054 -->
<a id="26.7.7.8"></a>**8.**裁判官对于声称自己没有任何款项可用于供养未成年人的监护人，也通常采取同样做法：一旦查明确有款项在其手中，就应按极高利率支付利息。显然，法官应当追究此事，并可同时附加其他处罚。

<!-- source-p 055 -->
<a id="26.7.7.9"></a>**9.**至于其余未成年人款项，应支付未成年人适用的利息。

<!-- source-p 056 -->
<a id="26.7.7.10"></a>**10.**何谓未成年人适用的利息，尚须说明。显然，其规则如下：监护人将款项挪作己用的，应支付该款项的法定利息。如果监护人否认持有该款，而裁判官作出对其不利的裁定，也应支付法定利息；如果其拖延存放，且裁判官责令其支付法定利息，也应如此。如果监护人否认自己持有某笔款项，迫使未成年人为满足自身需要而不得不以法定利率借款，他也应支付相应的法定利息。如果监护人向债务人收取了法定利息，也应按法定利率支付。除此之外的情形，则依行省惯例支付利息，例如五分利、三分利，或当地通行的其他较低利率。

<!-- source-p 057 -->
<a id="26.7.7.11"></a>**11.**监护人所欠利息并非立即请求，而是应给予两个月期限，以便其收取和安排款项；监护诉讼通常遵循此规则。但对于将未成年人或青年的钱款挪作己用的人，不应给予这一宽限期。

<!-- source-p 058 -->
<a id="26.7.7.12"></a>**12.**如果监护人或保佐人收取了利息，却将其留作己用，就应当承认其也须支付该利息所生的利息；毕竟，将未成年人的本金还是利息挪作己用，并无实质差别。

<!-- source-p 059 -->
<a id="26.7.7.13"></a>**13.**保存在钱箱中的款项，如果保佐人的继承人尚未请求另行指定保佐人以接替死者，就应由这些继承人持续支付利息。

<!-- source-p 060 -->
<a id="26.7.7.14"></a>**14.**如果一名监护人因共同监护人而被判承担责任，是否也应判令其支付利息？对此存在疑问。多份敕答以及帕皮尼安《疑问集》第十二卷都认为，如果他未及时将共同监护人控告为可疑监护人，也应判令他支付利息；而且他仅须支付自己管理监护事务时本来也须支付的那种利息。

<!-- source-p 061 -->
<a id="26.7.7.15"></a>**15.**应知，监护人的职责即使终止，仍须支付利息，直至其交还监护事务之日。

<!-- source-p 062 -->
<a id="26.7.8"></a>**26.7.8**

<!-- source-p 063 -->
**乌尔比安：《告示评注》第二十三卷。**

<!-- source-p 064 -->
如果由曾受监护的人提起监护诉讼，有时应等到借款期限届满后再行审理，例如监护人以未成年人名义出借款项，而收款期限尚未届至。就借款而言，只有监护人有权且有义务放贷时，才适用这一规则；如果他本不应放贷，则无须等待期限届满。

<!-- source-p 065 -->
<a id="26.7.9"></a>**26.7.9**

<!-- source-p 066 -->
**乌尔比安：《告示评注》第三十六卷。**

<!-- source-p 067 -->
<a id="26.7.9.pr."></a>**序言。**监护人将未成年人的款项放贷时，应按如下顺序订立要式承诺：应由未成年人本人或未成年人的奴隶作出要式承诺。如果未成年人尚未达到可以作出要式承诺的年龄，也没有奴隶，那么应由监护人本人或受其权力支配的人作出要式承诺；在这种情形下，尤利安多次写道，应给予未成年人一项有用之诉。毫无疑问，即使未成年人缺席，监护人也应以自己名义作出要式承诺。

<!-- source-p 068 -->
<a id="26.7.9.1"></a>**1.**如果家父为某人提供保证后，又将该人指定为其儿子的监护人，监护职责要求监护人在债务清偿期限届满时替债务人向债权人付款。因此，如果监护人怠于履行，而未成年人取得自主管理财产的资格后，因保证关系代为付款，他不仅可以提起委任之诉，也可以提起监护诉讼；因为应归责于监护人的是，他为何没有代为付款。如果该债务人负有附期限的债务，有些人认为，如果期限在监护职责终止后才届至，就不属于监护诉讼的审理范围；如果期限在监护关系存续期间届至，则无论如何都应纳入监护诉讼。我认为，无论上述何种情形，只有在监护人的财力开始恶化时才适用；反之，如果监护人仍有充分清偿能力，就不属于监护诉讼的审理范围。任何人都不应认为这种处理毫无实际效果：因为如果认定该事由属于监护诉讼范围，就会适用优先受偿权；如果曾就财产妥善保全提供担保，保证人也须承担责任。

<!-- source-p 069 -->
<a id="26.7.9.2"></a>**2.**同样，如果监护人负有一项附期限的债务，应允许提起监护诉讼，以使该债务成为无期限限制的请求权。

<!-- source-p 070 -->
<a id="26.7.9.3"></a>**3.**一般而言，监护人本应向他人履行、以保障其未成年人利益的义务，也应向未成年人履行；甚至可能还应承担更多责任，因为未成年人无法在没有诉权的情况下向他人追责，但可以向监护人本人追责。

<!-- source-p 071 -->
<a id="26.7.9.4"></a>**4.**但是，如果监护人欠未成年人的父亲一笔利率高于未成年人通常适用利率的债务，应考察是否应将此事归责于监护人。如果他已经偿还，就不应归责于他；因为他本可偿还，从而避免承担高额利息。如果他没有偿还，就应被要求承担自己本应向父亲支付的利息。

<!-- source-p 072 -->
<a id="26.7.9.5"></a>**5.**监护人可以清偿自己所欠的债务，也可以收取别人欠自己的债务；如果他是未成年人父亲的债权人，也可如此。只要有款项可供偿还，他就可以向自己清偿；如果父亲欠他的利息较高，未成年人就会因该利息而获得减免，因为监护人本可以免除自己的债务，正如他本可以且应当向其他债权人清偿一样。

<!-- source-p 073 -->
<a id="26.7.9.6"></a>**6.**监护人被起诉时，并非必须经法官判决后才付款；因此，如果未成年人的诉讼理由不成立，监护人应当向自己说明实情。神圣的安敦尼皇帝与其父也曾禁止向未成年人追偿不必要诉讼所产生的律师报酬：如果真正的债权人已起诉监护人，而监护人又提起了不必要的诉讼，便不得将相关律师报酬计入未成年人的账目。但这并不妨碍监护人承认善意债权。

<!-- source-p 074 -->
<a id="26.7.9.7"></a>**7.**如马尔凯卢斯在《学说汇纂》第八卷中所写，监护人不仅可以向自己清偿，也可以将交由自己保管的款项记作自己向未成年人借入的款项；他还可以通过将借款记入自己名下，使自己负有借款债务。

<!-- source-p 075 -->
<a id="26.7.9.8"></a>**8.**有人被指定为补充监护人，例如负责后来增加的财产，如后来取得的母系遗产或其他增加财产；可以确定，此人通常不管理原有财产。但是，如果他没有请求将先前的监护人认定为可疑监护人，或没有要求其提供担保，就应受到惩罚。

<!-- source-p 076 -->
<a id="26.7.9.9"></a>**9.**反之，如果某人被笼统地指定为未成年人的监护人或保佐人，后来又有财产增加，他也应对此承担风险，尽管有时会专门为增加的财产另行指定保佐人。这并不意味着新增财产不属于原监护人的管理范围，因为一切有利于未成年人的事务都应由先前监护人负责。因此，如果另行指定了监护人，其风险与原监护人共同承担；如果没有另行指定，先前指定的人就有义务管理新增财产。

<!-- source-p 077 -->
<a id="26.7.10"></a>**26.7.10**

<!-- source-p 078 -->
**乌尔比安：《告示评注》第四十九卷。**

<!-- source-p 079 -->
一般而言，只要监护人没有以未成年人名义完成任何一项适任家父都会完成的事务，就不能认为他已妥善履职。因此，无论他拒绝清偿债务、拒绝应诉，还是拒绝作出要式承诺，都不能说他已尽到职责。

<!-- source-p 080 -->
<a id="26.7.11"></a>**26.7.11**

<!-- source-p 081 -->
**乌尔比安：《告示评注》第三十三卷。**

<!-- source-p 082 -->
未成年人由奴隶担任监护人时，神圣的皮乌斯皇帝曾以敕答规定：如果奴隶使用未成年人的款项购买财物，其所有人不得主张抵销优先权。对保佐人也应遵循此规则。

<!-- source-p 083 -->
<a id="26.7.12"></a>**26.7.12**

<!-- source-p 084 -->
**保罗：《告示评注》第三十八卷。**

<!-- source-p 085 -->
<a id="26.7.12.pr."></a>**序言。**如果有数人共同管理监护事务，不得以未成年人名义向其中任何一人提起针对共同监护人的诉讼。

<!-- source-p 086 -->
<a id="26.7.12.1"></a>**1.**依据图拉真和哈德良的敕答，监护人善意实施的行为均应维持效力。因此，未成年人不得追回监护人依法出售的财物；如果无人购买，监护管理便无法得到遵守，这对未成年人也无益。监护人是否具有清偿能力并无区别：善意实施的行为应予维持；若属恶意，转让则不发生效力。

<!-- source-p 087 -->
<a id="26.7.12.2"></a>**2.**若仅为维护未成年人的声誉，就允许监护人从其财产中支出连自己都不会以最体面的方式支出的款项，实在过分。

<!-- source-p 088 -->
<a id="26.7.12.3"></a>**3.**监护人受托照管的不仅是未成年人的财产，也包括其品行。首先，监护人应按照财产能力和出身地位，支付教师薪酬，而非只支付最低数额；应为奴隶和自由人提供生活资料，有时若有利于未成年人，也应供养外人；还应依惯例向父母及亲属赠送礼物。但不得为同父异母或异父同母的姐妹给付嫁资，即使她除此之外无法结婚也不例外；因为这固然是体面的行为，却仍属赠与，应由未成年人自行决定。

<!-- source-p 089 -->
<a id="26.7.12.4"></a>**4.**如果监护人本可放贷未成年人的款项，但找不到适当的借款人，该款项闲置不应归责于未成年人。

<!-- source-p 090 -->
<a id="26.7.13"></a>**26.7.13**

<!-- source-p 091 -->
**盖尤斯：《行省告示评注》第十二卷。**

<!-- source-p 092 -->
<a id="26.7.13.pr."></a>**序言。**监护人应按照未成年人的地位和财产能力，确定围绕其生活的奴隶人数。

<!-- source-p 093 -->
<a id="26.7.13.1"></a>**1.**监护人若辩称未成年人的款项之所以闲置，是因为找不到适任债务人，但有人证明他在同一时期妥善安排了自己的款项，就不应采信该辩解。

<!-- source-p 094 -->
<a id="26.7.13.2"></a>**2.**支付遗赠和遗嘱信托时，监护人应查明受领人确实享有该权利；也不应向未成年人的母亲或姐妹赠送婚礼礼物。但是，如果未成年人的母亲或姐妹无法供养自己，监护人偶尔为她们提供生活必需品，则应认可此项支出；因为用于生活供养的支出，与作为礼物或遗赠名义的支出并非同一性质。

<!-- source-p 095 -->
<a id="26.7.14"></a>**26.7.14**

<!-- source-p 096 -->
**保罗：《简要论》第八卷。**

<!-- source-p 097 -->
共同监护人的行为也会归责于其同僚，前提是后者本可且应当请求将共同监护人认定为可疑监护人；有时，如果他本应要求其提供担保，也会归责于他。但如果共同监护人突然丧失清偿能力，就不能归责于其同僚。

<!-- source-p 098 -->
<a id="26.7.15"></a>**26.7.15**

<!-- source-p 099 -->
**保罗：《意见集》第二卷。**

<!-- source-p 100 -->
如果监护人没有起诉其接手时发现的债务人，导致这些债务人后来丧失清偿能力；或者在最初六个月内没有安排未成年人的款项，那么应向该监护人请求未收回的本金，以及未放贷款项所生的利息。

<!-- source-p 101 -->
<a id="26.7.16"></a>**26.7.16**

<!-- source-p 102 -->
**保罗：《萨宾评注》第六卷。**

<!-- source-p 103 -->
在监护诉讼中，若要确定未成年人应承认监护人设立的哪些债权凭据，马尔凯卢斯认为：如果监护人将未成年人的款项出借，并以自己名义订立要式承诺，可以说，完整有效的债权凭据归未成年人享有；已经无法实现或订立不当的债权，则由监护人承担。不过，我认为更正确的做法是，监护人可以把选择交给青年人：对于监护人在设立这些债权时所作的一切，青年人可以选择全部承认，或者全部拒绝；其效果犹如监护人为自己处理事务一样。若监护人以未成年人名义放贷，也同样处理。

<!-- source-p 104 -->
<a id="26.7.17"></a>**26.7.17**

<!-- source-p 105 -->
**庞波尼乌斯：《萨宾评注》第十七卷。**

<!-- source-p 106 -->
凡受有权命令者指令而管理监护事务的人，如果未履行职责，应自受命之日起负责使未成年人免受损失，而不是从其正式成为监护人之日起算。

<!-- source-p 107 -->
<a id="26.7.18"></a>**26.7.18**

<!-- source-p 108 -->
**尤利安：《学说汇纂》第二十一卷。**

<!-- source-p 109 -->
<a id="26.7.18.pr."></a>**序言。**只要监护人曾管理未成年人的事务，即使他从未在任何事项上给予未成年人监护人同意，也毫无疑问应受监护诉讼追究。因为未成年人的财产完全可能如此安排，以至于无须办理任何必须由监护人表示同意的事务。

<!-- source-p 110 -->
<a id="26.7.18.1"></a>**1.**如果两名监护人中一人已经被起诉，另一人并不因此免责。

<!-- source-p 111 -->
<a id="26.7.19"></a>**26.7.19**

<!-- source-p 112 -->
**乌尔比安：《答复集》第一卷。**

<!-- source-p 113 -->
不应强令一名共同保佐人向另一名共同保佐人交代自己的管理行为；但是，如果他不与对方共同管理，或者未能诚信履职，可以请求将其认定为可疑保佐人。

<!-- source-p 114 -->
<a id="26.7.20"></a>**26.7.20**

<!-- source-p 115 -->
**乌尔比安：《总督职务论》第五卷。**

<!-- source-p 116 -->
如果监护人或保佐人的上诉被裁定为无正当理由，或者其免责请求未获准，他应自本应开始管理事务之日起承担责任。

<!-- source-p 117 -->
<a id="26.7.21"></a>**26.7.21**

<!-- source-p 118 -->
**马尔凯卢斯：《答复集》单卷本。**

<!-- source-p 119 -->
卢基乌斯·提提乌斯在遗嘱中指定家子盖乌斯·塞尤斯为自己儿子的监护人。盖乌斯·塞尤斯在其父亲知情并同意的情况下管理监护事务。我询问：盖乌斯·塞尤斯死亡后，是否可以向其父亲提起监护诉讼，以及责任范围如何？马尔凯卢斯答复：根据所述事实，可以依特有财产之诉以及特有财产投入所得之诉追究父亲责任。仅凭父亲知情并同意，并不足以使其承担全部责任；除非共同监护人或其他人曾试图将该家子认定为可疑监护人，而父亲介入阻止此事，并仿佛自行承担了相关风险。

<!-- source-p 120 -->
<a id="26.7.22"></a>**26.7.22**

<!-- source-p 121 -->
**保罗：《告示评注》第三卷。**

<!-- source-p 122 -->
为未成年人的利益，监护人可以更新债务，也可以将争议提交法院；但监护人所作的赠与不得损害未成年人的利益。

<!-- source-p 123 -->
<a id="26.7.23"></a>**26.7.23**

<!-- source-p 124 -->
**乌尔比安：《告示评注》第九卷。**

<!-- source-p 125 -->
通常，监护人以未成年人名义提起诉讼时，无须担保未成年人将追认该行为。但是，如果不确定他是否为监护人、监护人身份是否仍持续，或管理事务是否曾交由他处理，那么为免对方受骗，应要求其提供适当担保。尤利安写道，对保佐人也应如此。

<!-- source-p 126 -->
<a id="26.7.24"></a>**26.7.24**

<!-- source-p 127 -->
**保罗：《告示评注》第九卷。**

<!-- source-p 128 -->
<a id="26.7.24.pr."></a>**序言。**每当事务繁杂，或监护人的地位、年龄、健康状况要求如此，通常由裁判官作出裁定，指定一名事务代理人，其行为风险由监护人承担。如果未成年人尚不会说话，无法指定诉讼代理人，或者本人缺席，则必须指定事务代理人。

<!-- source-p 129 -->
<a id="26.7.24.1"></a>**1.**如果父母、共同监护人或官员允许两人共同管理监护事务，应从宽解释为也允许其中一人单独起诉，因为两人不可能同时实施同一诉讼行为。

<!-- source-p 130 -->
<a id="26.7.25"></a>**26.7.25**

<!-- source-p 131 -->
**乌尔比安：《告示评注》第十三卷。**

<!-- source-p 132 -->
如果未成年人在监护人和保佐人协助下提起诉讼，随后又因保佐人有过失、未能使监护人被判承担责任而起诉保佐人，并获得判决，赔偿其作为未成年人本应取得的利益，那么是否还可针对监护人请求恢复原状？帕皮尼安在《答复集》第二卷中说，仍可请求恢复原状。因此，如果保佐人尚未履行判决，就可以提起上诉，并通过诈欺抗辩取得针对监护人的诉权让与。但是，如果保佐人已经履行判决，这会使监护人受益吗？会，因为未成年人并未遭受任何损失；他所关心的倒更像是获利，而非填补损害。不过，如果保佐人准备将相关诉权让与未成年人，则另当别论。

<!-- source-p 133 -->
<a id="26.7.26"></a>**26.7.26**

<!-- source-p 134 -->
**保罗：《告示评注》第二十四卷。**

<!-- source-p 135 -->
即使保佐人或临时监护人仍在管理事务，也可以对其提起诉讼。

<!-- source-p 136 -->
<a id="26.7.27"></a>**26.7.27**

<!-- source-p 137 -->
**保罗：《普劳提乌斯评注》第七卷。**

<!-- source-p 138 -->
担任监护人并管理事务的人，就照管未成年人而言，应视同财产所有人。

<!-- source-p 139 -->
<a id="26.7.28"></a>**26.7.28**

<!-- source-p 140 -->
**马尔凯卢斯：《学说汇纂》第八卷。**

<!-- source-p 141 -->
<a id="26.7.28.pr."></a>**序言。**监护人代表未成年人被正式传唤到庭时，已提供通常要求的担保。如果在诉讼延宕期间，未成年人达到青春期，就不得强令监护人接受该诉讼。

<!-- source-p 142 -->
<a id="26.7.28.1"></a>**1.**未成年人达到青春期后，监护人不再管理其事务的，自监护人提出交付款项之时起，无须支付利息。依我之见，如果未能返还监护事务并非监护人的过错，则更不应强令其支付利息。乌尔比安注：仅提出交付还不够；还必须将款项加封后存放在安全地点。

<!-- source-p 143 -->
<a id="26.7.29"></a>**26.7.29**

<!-- source-p 144 -->
**马尔凯卢斯：《学说汇纂》第八卷。**

<!-- source-p 145 -->
尤其不应向监护人的继承人请求利息；毕竟，某人可能在二十年甚至更久之后才想到请求返还监护事务，却还要追索利息，这是极不公平的。

<!-- source-p 146 -->
<a id="26.7.30"></a>**26.7.30**

<!-- source-p 147 -->
**马尔凯卢斯：《学说汇纂》第二十一卷。**

<!-- source-p 148 -->
监护人的首要职责，是不使未成年人处于无人保护的状态。

<!-- source-p 149 -->
<a id="26.7.31"></a>**26.7.31**

<!-- source-p 150 -->
**莫德斯蒂努斯：《免责事由论》第一卷。**

<!-- source-p 151 -->
神圣的塞维鲁与安敦尼皇帝致塞尔吉乌斯·尤利安努斯：“数名监护人各自管理监护事务时，有时须就全部责任承担连带责任；此规则仅适用于未成年人尚未达到青春期的期间，不适用于其达到青春期后管理的事务。”

<!-- source-p 152 -->
<a id="26.7.32"></a>**26.7.32**

<!-- source-p 153 -->
**莫德斯蒂努斯：《答复集》第六卷。**

<!-- source-p 154 -->
<a id="26.7.32.pr."></a>**序言。**监护人无继承人而死亡。有人询问：如果未成年人的保佐人未能从监护人的保证人处取得财产清册或其他文书，能否依据要式承诺，按照未成年人所受利益损失的数额起诉同一保证人？莫德斯蒂努斯答复：监护人可以被请求承担多少责任，保证人也可以被请求承担同样的责任。

<!-- source-p 155 -->
<a id="26.7.32.1"></a>**1.**莫德斯蒂努斯答复：如果因未能找到已缴纳赋税的凭证而发生损失，而事实表明监护人并无过错，那么该损失绝不应由监护人承担。

<!-- source-p 156 -->
<a id="26.7.32.2"></a>**2.**莫德斯蒂努斯答复：监护人应就未成年人所能善意取得的土地收益向其交账。

<!-- source-p 157 -->
<a id="26.7.32.3"></a>**3.**他还答复：如果监护人从奴隶处取得的收益少于土地上本可善意取得的数额，那么在监护人对未成年人负有债务的范围内，应将该奴隶特有财产中本可保全的部分计入监护人的利益；但前提是，监护人将事务交给该奴隶管理时，并未预见其将遭受损失。

<!-- source-p 158 -->
<a id="26.7.32.4"></a>**4.**青年人在保佐人协助下将土地出售给提提乌斯。此后，因发现诈欺而获准恢复原状，并被命令恢复占有。有人询问：既然该青年并未因这项买卖而获益，也没有证据证明任何利益用于其本人事务，是否无须向买受人返还价款？莫德斯蒂努斯答复：如果土地价款没有使该青年的财产受益，而且作出恢复原状裁定的法官也未就价款作出任何裁断，买受人请求青年返还土地价款，是徒劳的。

<!-- source-p 159 -->
<a id="26.7.32.5"></a>**5.**他还答复：不得令青年承担买受人出于享乐目的所作的支出；不过，如果这些建筑部分可以拆除，而不使建筑物无法恢复到出售前的外观，则应允许买受人拆除。

<!-- source-p 160 -->
<a id="26.7.32.6"></a>**6.**卢基乌斯·提提乌斯是其姐妹的共同继承人和保佐人。他所在城市的惯例是，由土地所有人而非承租人承担粮食供应及临时摊派的负担。他遵循一贯的惯例，为共同且未分割的遗产缴纳了粮食供应费用。有人询问：在提交账目时，能否反对保佐人，理由是他不应替姐妹的份额支出这些费用？莫德斯蒂努斯答复：在该成年女子自己的财务管理中，如果她本人也必须支付这些费用，那么就本案所问的情形，可在账目中向她计入该等费用。

<!-- source-p 161 -->
<a id="26.7.32.7"></a>**7.**两名监护人出售未成年人财物后，彼此分割了款项；分割后，在监护关系存续期间，其中一人被流放。有人询问：指定诉讼代理人后，另一名共同监护人能否向被流放者请求其所分得的未成年人款项？莫德斯蒂努斯答复：如果问题是被流放的共同监护人能否被另一名共同监护人提起监护诉讼，我不能答复说可以。

<!-- source-p 162 -->
<a id="26.7.33"></a>**26.7.33**

<!-- source-p 163 -->
**卡利斯特拉图斯：《审理程序论》第四卷。**

<!-- source-p 164 -->
<a id="26.7.33.pr."></a>**序言。**对于监护人和保佐人管理未成年人财产，应要求其尽到与善良家父管理自己事务时同等的注意。

<!-- source-p 165 -->
<a id="26.7.33.1"></a>**1.**一旦指定保佐人，监护人的职责即告终止；因此，已经开始的所有事务均转由保佐人诚信处理。神圣的马尔库斯皇帝与其子康茂德也曾以敕答作出同样规定。

<!-- source-p 166 -->
<a id="26.7.33.2"></a>**2.**未成年人的继承人对监护人也享有同样的选择权，可以选择自己希望采取的立场；元首敕令已说明，原受监护者本人也享有这一权利。

<!-- source-p 167 -->
<a id="26.7.33.3"></a>**3.**通常只核算为监护事务善意支出的费用，而不核算监护人自身的支出；但任命监护人的人若已为监护人规定确定的报酬，则不在此限。

他答复说，为协助法官谨慎审理并维护未成年人的利益，也可以询问未成年人的奴隶。

<!-- source-p 174 -->
<a id="26.7.36"></a>**26.7.36**

<!-- source-p 175 -->
**帕皮尼安：《疑问集》第三卷。**

<!-- source-p 176 -->
监护事务虽已在监护人之间分配，但基于衡平而产生的纯粹抵销权，不因起诉的监护人负有职责或具有特定身份而被延后适用。监护事务的分配属于司法管辖权，而非实体法；它限制各人的管理范围，只在监护人彼此之间发生效力，不应妨碍愿意起诉未成年人的人提起诉讼。

<!-- source-p 177 -->
<a id="26.7.37"></a>**26.7.37**

<!-- source-p 178 -->
**帕皮尼安：《疑问集》第十一卷。**

<!-- source-p 179 -->
<a id="26.7.37.pr."></a>**序言。**萨宾和卡西乌斯认为，监护人每管理一项事务，就会因该项事务并在相应期间内分别负担债务，仿佛其责任各有不同原因。

<!-- source-p 180 -->
<a id="26.7.37.1"></a>**1.**据此，奴隶担任店铺经理或受命负责收取债务，获释后仍继续同一事务的，即使他在奴隶身份存续期间不能负担债务，仍可因过去期间提起事务管理之诉；但仅限于与此后管理事务具有连续关系的事项。基于同一理由，人们认为，监护诉讼也涵盖未成年人达到青春期后管理的事项，只要后来的管理与此前的管理相衔接，且并未分离成独立的事务。

<!-- source-p 181 -->
<a id="26.7.37.2"></a>**2.**由此引出一个通常就家子讨论的问题：某家子依遗嘱被指定为监护人，在管理监护事务后脱离父权，却继续担任同一职务。依萨宾和卡西乌斯的意见，他在脱离父权后管理事务所生的责任应由其本人承担全部；对于此前期间的责任，无论其特有财产是否被父亲收回，他均仅在其履行能力范围内负责。如果未成年人选择就先前期间向父亲提起特有财产之诉——可提起该诉讼的一年期间自监护诉讼可以提起时起算——为免父亲以涵盖全部期间的事由提出抗辩，儿子作为家子管理监护事务的期间也应计入。

<!-- source-p 182 -->
<a id="26.7.38"></a>**26.7.38**

<!-- source-p 183 -->
**帕皮尼安：《疑问集》第十二卷。**

<!-- source-p 184 -->
<a id="26.7.38.pr."></a>**序言。**如果数名监护人均未管理事务，且人人都有清偿能力，由于无法确定各自的管理份额，是否应允许原告选择起诉其中一人，还是应当像同一笔债务的债务人那样，共同分担风险？后一种处理更符合道理。

<!-- source-p 185 -->
<a id="26.7.38.1"></a>**1.**如果其中有人没有清偿能力，其余人无疑应承担更重责任；这并非不公，因为每个人的抗命行为都使未成年人遭受全部损失。

<!-- source-p 186 -->
<a id="26.7.38.2"></a>**2.**由此应进一步询问：未成年人是否应向唯一被起诉的人提供对其他人的诉权，当然仅按相应份额提供？但是，既然每个人都因自身不服从命令而受罚，又怎能理直气壮地提出这种要求？

<!-- source-p 187 -->
<a id="26.7.39"></a>**26.7.39**

<!-- source-p 188 -->
**帕皮尼安：《答复集》第五卷。**

<!-- source-p 189 -->
<a id="26.7.39.pr."></a>**序言。**监护关系终止后，监护人因误解职责而继续管理财产；对于青年达到青春期后仍属适任的父亲债权凭据，既然监护人当时无法行使诉权，就不得强令其承担该等债权的风险。

<!-- source-p 190 -->
<a id="26.7.39.1"></a>**1.**父亲在遗嘱中为未成年人指定了一名保佐人，该人因误解而介入管理事务。此后，裁判官另行指定其他监护人；如果该人之后未曾管理任何事务，就不应对未来期间的风险承担责任。

<!-- source-p 191 -->
<a id="26.7.39.2"></a>**2.**某人并未依法被指定为未成年人的监护人，却依父亲意愿介入其事务。发现错误后，他较为审慎的做法是请求裁判官指定一名监护人，以免他若中途放弃已经开始的事务，被判因诈欺或过失承担责任。若某人自愿管理他人事务，则不适用同一规则；即使仅就一项具体事务，友人的帮助也已足够维护财产所有人的利益。

<!-- source-p 192 -->
<a id="26.7.39.3"></a>**3.**一名被指定为继承人的人没有指定替补继承人，在接受其应返还给未成年人的遗产之前便已死亡。遗产位于意大利，而被指定的继承人在行省死亡；我认为，如果负责行省财产的监护人明知遗嘱安排的原因，却放弃维护未成年人的利益，就应以过失为由判令其承担责任。因为，即使在行省通过遗嘱信托返还遗产能够解决法律关系问题，财产管理事务仍应由在意大利接受监护职责的人负责。〔底本文字末尾“suscepissententiarum”疑为误连，依可辨句义处理。〕

<!-- source-p 193 -->
<a id="26.7.39.4"></a>**4.**如果监护人使未成年人放弃父亲的遗产，不应拒绝与该监护人订约的债权人对其提起诉讼，即使监护人曾将款项用于未成年人的事务。

<!-- source-p 194 -->
<a id="26.7.39.5"></a>**5.**青年的数名保佐人彼此提供担保，以分担共同风险，并为此交付质物；职责终止且他们均有清偿能力后，该担保被认定无效，质押关系也已解除。

<!-- source-p 195 -->
<a id="26.7.39.6"></a>**6.**某人被指定为监护人后，就该指定本身提出上诉；其继承人在后来败诉后，应对先前期间的风险承担责任，因为拒绝服从法律所设监护职责，并非轻微过失。

<!-- source-p 196 -->
<a id="26.7.39.7"></a>**7.**负责行省财产的监护人在罗马为未成年人办理上诉事务时，应促使意大利财产的保佐人履行其职责；否则，如果前者先返回行省，法官也可适当地追究他们在该部分事务中的诈欺或过失责任。

<!-- source-p 197 -->
<a id="26.7.39.8"></a>**8.**某叔父在遗嘱中被指定为其兄弟之子的监护人，并以意大利为住所；他接手了意大利和行省财产的管理，将在罗马出售财物所得款项转运至行省，并将款项转入未成年人的账簿。后来在罗马另行指定替代监护人；该替代监护人无须接管不属于其监护范围的款项。

<!-- source-p 198 -->
<a id="26.7.39.9"></a>**9.**有人依遗嘱被无效地指定为保佐人或监护人，且未获裁判官裁定确认，却仍管理事务。由于他们在没有法律授权的情况下自愿承担职责，应相互承担风险；本来适任的人应当请求裁判官以裁定指定保佐人或监护人。

<!-- source-p 199 -->
<a id="26.7.39.10"></a>**10.**适任的监护人死亡后，其风险不会相互转归其继承人；因为监护职责仍在履行期间时，并不存在这种风险转移。

<!-- source-p 200 -->
<a id="26.7.39.11"></a>**11.**对于不愿管理监护事务的人，依有用之诉的规则，应在其他已履职监护人之后对其提起监护诉讼。但是，如果未成年人事务所生利益并未归于那些介入管理的人，而是因大家共同疏忽而灭失，则不依替补顺位，而应由所有人平均承担风险。

<!-- source-p 201 -->
<a id="26.7.39.12"></a>**12.**监护人开始了未成年人达到青春期之前的上诉诉讼，未成年人达到青春期后，因执政官熟悉案情而奉其命令继续诉讼；如果他们无法执行判决，就不因过失风险承担责任。

<!-- source-p 202 -->
<a id="26.7.39.13"></a>**13.**对于无法获得恢复原状救济的人，可以通过协议免除对监护人过失的追究；此举不视为赠与，而视为和解。

<!-- source-p 203 -->
<a id="26.7.39.14"></a>**14.**如果因监护人的过失风险而将父亲按较高利率放贷形成的债权凭据记入账目，未成年女孩就须承认该账簿债权；但她在监护期间已经收取的利息，无须抵销，应予保留。

<!-- source-p 204 -->
<a id="26.7.39.15"></a>**15.**青年人起诉监护人后，未能从他们处获得全部赔偿，仍保有对保佐人的完整诉权；保佐人曾因疏忽，未将监护事务接管过来。监护诉讼并未消耗针对保佐人的请求权，因为该项请求涉及另一项职责。

<!-- source-p 205 -->
<a id="26.7.39.16"></a>**16.**监护人不愿以未成年人名义起诉适任的监护人继承人时，应代替造成损害者承担责任；该损害本可通过及时将不适任的监护人控告为可疑监护人而避免。

<!-- source-p 206 -->
<a id="26.7.39.17"></a>**17.**不得仅因同一人同时承担其兄弟和未成年共同继承人的监护职责，就延后监护诉讼。

<!-- source-p 207 -->
<a id="26.7.39.18"></a>**18.**青年开始自行管理财产后，释放了原先担任代理人的奴隶；该奴隶的特有财产中，由青年保留或本可保留的财物，应由法官在向保佐人提交的账目中记为已收取。

<!-- source-p 208 -->
<a id="26.7.40"></a>**26.7.40**

<!-- source-p 209 -->
**帕皮尼安：《答复集》第六卷。**

<!-- source-p 210 -->
一名百夫长为其未成年儿子指定了保佐人。若未取得裁判官裁定确认，而该保佐人也未管理任何事务，就不应因违抗或疏忽而令其承担责任。军人的特权不应扩大到损害他人；对于军人最后意愿方面的无知，也不应在军人财产以外的事务中获得免责。父亲为儿子安排监护事务，是基于父权，而非军功赏赐。

<a id="26.7.41"></a>**26.7.41**

<!-- source-p 212 -->
**帕皮尼安：《答复集》第七卷。**

<!-- source-p 213 -->
某人有数名监护人，其中一人已无清偿能力，却阻止他人就其管理行为要求交账。由于遗嘱并未免除他对自己从监护中取得的利益或以诈欺方式所订契约的责任，因此，未将其控告为可疑监护人的共同监护人，应因自身过失而被正当地起诉。遗嘱中虽免除作为受遗赠人的监护人的责任，但该免责并不涵盖其过失。

<a id="26.7.42"></a>**26.7.42**

<!-- source-p 215 -->
**帕皮尼安：《定义集》第一卷。**

<!-- source-p 216 -->
法官从数名监护人中判令一人承担全部责任。若诉讼代理人因自身利益而被判承担责任，就不享有未成年人的优先权；未成年人的继承人也不享有该项优先权。因为优先救济针对的是具有特别应受保护身份的人，而非诉讼本身。

<a id="26.7.43"></a>**26.7.43**

<!-- source-p 218 -->
**保罗：《疑问集》第七卷。**

<!-- source-p 219 -->
<a id="26.7.43.pr."></a>**序言。**未成年人死亡后，如果债权凭据已无清偿能力，监护人即免于承担风险。

<!-- source-p 220 -->
<a id="26.7.43.1"></a>**1.**某人担任其兄弟之女的保佐人，允诺以嫁资名义向她的丈夫给付四百。后来出现债务，嫁资允诺额超过其财产能力。有人询问是否应予救济，因为文书中写着：“其叔父兼保佐人向要式承诺受领人作出允诺。”引起疑问的是：他允诺的并非自己财产，而是相信未成年人的财产足以负担该数额。此外还可讨论：如果保佐人明知财产不足仍作出允诺，他是否应被视为赠与，或者因其有诈欺而不得获得救济。我的答复是：保佐人超出职责范围，自愿使自己承担义务，我认为裁判官不应救济他；这与他向女子的债权人允诺代为给付并无不同。但是，如果本案的保佐人允诺嫁资并非出于赠与之意，而是为了处理事务，那么女子仍负有债务；甚至可以说，即使婚姻仍存续，她也负有该债务，因为该嫁资应计入财产合并；至少在离婚后，无论嫁资是否已经收取、该项债权是否仍然存在，女子都负有债务，因为她可以使这笔债务记为已受清偿。如果女子无力偿还保佐人超出其财产能力所允诺给付的嫁资，保佐人对超出部分可通过抗辩获得免责；女子则应向丈夫提供担保：若她在婚姻关系存续期间日后变得富有，就将嫁资余额留给丈夫。

<a id="26.7.44"></a>**26.7.44**

<!-- source-p 222 -->
**保罗：《疑问集》第十三卷。**

<!-- source-p 223 -->
<a id="26.7.44.pr."></a>**序言。**如果某人从前任保佐人或监护人处接手债权凭据，或承认这些债权凭据，就将相应风险转由自己承担。

<!-- source-p 224 -->
<a id="26.7.44.1"></a>**1.**但是，如果未成年人达到青春期后，接受监护人所提交的账目，并依账目承认其结余债务，即使监护人的财产被变卖，他仍不丧失自己的优先权；裁判官应为其保留该项优先权。

<a id="26.7.45"></a>**26.7.45**

<!-- source-p 226 -->
**保罗：《疑问集》第十四卷。**

<!-- source-p 227 -->
如果未成年人达到青春期后免除了两名监护人中的一人，他就不应不当地以该人的名义再向另一人追索。同一规则也适用于两名共同任职的行政官，其中一人已经获公共权力免除责任。不过，这里讨论行政官时，假定两人始终都是同一债务的共同债务人；实际上并非如此。如果两人都具有清偿能力，就不存在选择起诉其中一人的问题。已获免除的人也不同于毫无财产的人，而如同已经履行了义务的人，因为他可以据此对请求人提出抗辩。

<a id="26.7.46"></a>**26.7.46**

<!-- source-p 229 -->
**保罗：《答复集》第九卷。**

<!-- source-p 230 -->
<a id="26.7.46.pr."></a>**序言。**保佐人卢基乌斯·提提乌斯在管理盖乌斯·塞尤斯事务期间，将科尔内利乌斯土地出租给塞姆普罗尼乌斯；塞姆普罗尼乌斯拖欠了后续租金。未成年人达到适当年龄后，指定曾经的承租人塞姆普罗尼乌斯为自己的代理人。有人询问：青年是否因代理人所作的行为而被视为承认全部债务，并据此免除了自己的保佐人？保罗答复：不能仅因青年愿意任命耕种其土地的人为代理人，就认为他承认了租赁所欠的债务。

<!-- source-p 231 -->
<a id="26.7.46.1"></a>**1.**塞姆普罗尼乌斯曾因允诺而成为其本邦的债务人。依总督命令，公共权力占有其财产；公共机关的行政官员指定三名财产管理人，希腊人称其为 *epimelētai*。此后，三人未经公共权力同意便在彼此之间分配了塞姆普罗尼乌斯财产的管理事务。其中一人因拖欠款项，在实际管理期间丧失了清偿能力。后来，已经放弃继承的未成年人作为塞姆普罗尼乌斯的继承人，获皇帝准许取回父亲的财产。有人询问：既然行政官员委托他们履行的是不可分割的管理职责，是否应以其余管理人的财产保障未成年人的利益？保罗答复：如果裁定未成年人可以对财产管理人提起诉讼，那么应就无清偿能力者所负责的份额起诉行政官员；因为监护人与管理公共事务的人，其责任依据并不相同。

<!-- source-p 232 -->
<a id="26.7.46.2"></a>**2.**监护人即使以自己名义放贷未成年人的款项，也不应视为违反禁止将未成年人款项挪作己用的敕令。

<!-- source-p 233 -->
<a id="26.7.46.3"></a>**3.**有人询问：监护人使用未成年人款项，在监护关系终止后，是否仍应支付利息，直至诉讼系属成立之日？保罗答复：管理职责终止后，应依监护诉讼中计算利息的规则计算。

<!-- source-p 234 -->
<a id="26.7.46.4"></a>**4.**保罗答复：对于监护人职责终止后，在无必要的情况下由其自愿管理的事务，曾就财产妥善保全提供担保的保证人不承担责任。

<!-- source-p 235 -->
<a id="26.7.46.5"></a>**5.**监护人在监护诉讼中提交了账簿，并依该账簿被判承担责任且已付款。此后，未成年人向父亲的债务人追债，而这些债务人的债权并未列入账簿；债务人拿出了监护人出具的收据。有人询问：未成年人对监护人还是对债务人享有诉权？保罗答复：如果债务人在监护人管理监护事务期间已向其清偿，就依法免于向未成年人再次清偿；但如果未成年人已经起诉监护人，他仍可基于此事提起监护诉讼，并可通过诈欺再抗辩，排除既判事项抗辩。

<!-- source-p 236 -->
<a id="26.7.46.6"></a>**6.**遗嘱指定了两名未成年人的监护人，其中一人死亡。应母亲请求，省总督命令行政官员另行指定监护人；行政官员要求新监护人提供财产妥善保全的担保。后来，遗嘱指定的监护人又控告新指定者为可疑监护人。有人询问遗嘱指定的监护人应在多大范围内承担责任。保罗答复：遗嘱指定的监护人应仅就其实际管理的份额承担责任。对于另一共同监护人的份额，应先起诉为该人承担义务的保证人，或起诉指定该人的行政官员；只有未成年人仍无法获得全部赔偿时，才应进一步考察共同监护人是否本应将此人控告为可疑监护人，尤其是据说他确实提出过此项控告。通常，若行政官员指定了数名监护人，未成年人须先穷尽对所有监护人的请求，才可转而起诉行政官员。但本案据称只有一名监护人是由行政官员指定的，因此不应要求先起诉遗嘱指定的共同监护人，因为此人既曾控告新监护人为可疑监护人，又是遗嘱指定的；两人应视同各自被指定管理一半监护事务。〔底本文字末尾“essententiarum”疑为误连，已依可辨句义处理。〕

<!-- source-p 237 -->
<a id="26.7.46.7"></a>**7.**监护人可以向未成年人的债务人收款，使债务人依法免责；但无权赠与债务、或为减少债务而与债务人和解。因此，债务人若少付给监护人款项，未成年人仍可向其追索余额。

<a id="26.7.47"></a>**26.7.47**

<!-- source-p 239 -->
**斯凯沃拉：《答复集》第二卷。**

<!-- source-p 240 -->
<a id="26.7.47.pr."></a>**序言。**某人指定提提乌斯和梅维乌斯为监护人，并作出如下担保：〔原希腊文拉丁转写：*boulomai kai parakalw pantas ginesvai meta tys maibiou tou adelfou mou gnwmys, kai dixa autou to ginomenon akuron estw.*〕〔底本随附拉丁释义：*volo et rogo, ut omnia fiant ex fratris mei Maevii sententia, et quidquid sine eo fiet, ratum ne sit.*〕“我希望并请求，所有事务均依我兄弟梅维乌斯的意见办理；未经他参与所作的一切均无效。”提提乌斯独自向债务人收款。有人询问债务人是否已经免责。我答复：如果管理事务也交由梅维乌斯负责，则债务人不应被视为已妥善清偿。

<!-- source-p 241 -->
<a id="26.7.47.1"></a>**1.**“我儿子每日所需的金额，由玛丽娜和雅努阿里娅估定。”有人询问监护人是否应满足于两名女子的决定。我答复：支出应依善良家父的裁量确定。

<!-- source-p 242 -->
<a id="26.7.47.2"></a>**2.**受命管理意大利事务的监护人在罗马发现了行省债务人的债权文书，文书规定在罗马或其他指定地点清偿。有人询问：既然债务人和他们的土地都不在意大利，这些债权的收取是否属于意大利事务监护人的职责？我答复：如果债务基于行省交易，就不属于其管理范围；但他们仍有职责查阅相关文书，以免文书不为负责管理该交易的人所知。

<!-- source-p 243 -->
<a id="26.7.47.3"></a>**3.**某母亲在遗嘱中指定了一人为监护人，此人误以为自己是监护人，便出售未成年人的母系和父系财产，后在无清偿能力的情况下死亡。有人询问未成年人能否请求返还财物。我答复：如果财物仍然存在，未成年人可以请求返还。

<!-- source-p 244 -->
<a id="26.7.47.4"></a>**4.**一名军团长官在遗嘱中规定：“是否将这笔款项的十二分之一作为利息收取，由我儿子的监护人自行决定，但不得使钱币分散。”有人询问：如果监护人放贷，应在监护诉讼中支付十二分之一的利息，还是支付其订约约定的利息？我答复：如果监护人依死者意愿选择收取利息，却未以未成年人名义放贷，就应支付遗嘱人所希望的数额。

<!-- source-p 245 -->
<a id="26.7.47.5"></a>**5.**卢基乌斯·提提乌斯向监护人借款，并以继承所得财物向其设定质押。三年后，那些已达到青春期的被监护人所继承的死者财产被国库没收，因为继承人未追究其死亡之事。有人询问未成年人能否拒绝承认该债权凭据。我答复：根据所述事实，该债权凭据所涉风险不应由监护人承担。

<!-- source-p 246 -->
<a id="26.7.47.6"></a>**6.**两名兄弟共同拥有财产并经营生意，其中一人死亡，留下儿子为继承人。叔父担任监护人，卖掉共同经营的全部商品后再自行买下，并以自己的名义继续经营。有人询问他应支付经营利润还是资金利息。我答复：根据所述事实，应向未成年人支付利息，而非经营利润。

<!-- source-p 247 -->
<a id="26.7.47.7"></a>**7.**负责意大利财产的监护人被一名行省债权人起诉后，已向其清偿；未成年人在该行省持有财物。有人询问这笔支出能否在监护诉讼中计入。我答复：没有理由认为不能计入。

<!-- source-p 259 -->
如果有两名或更多监护人共同管理监护事务，每名监护人均可使针对保证人的要式承诺以全部责任为限发生效力。但是，如果监护事务按地区分配——这种情况很常见，例如一人管理城市事务，另一人管理外地事务——那么应根据相关事务所属财产，判断针对保证人的要式承诺是否发生效力。因为，虽然人人都是监护人并共同承担监护职责，但如果有人就其负责地区以外的事务起诉，或被传唤应诉，则要式承诺不发生效力，犹如该事务根本未交由他管理。就相关争议而言，若该项管理权被全部否定，与之仅就该事项被否定，效果相同。

**保罗：《裁判集》第二卷。**

<!-- source-p 265 -->
埃米利乌斯·德克斯特任行政官期间曾指定监护人，却疏于要求其提供担保。后来，部分监护人获准免责，后任行政官又指定德克斯特担任监护人。德克斯特因此以双重理由被起诉并被要求承担全部责任：一是他曾任行政官并指定监护人，二是他未要求监护人提供担保。另一意见则认为，虽然未曾要求提供担保，但截至监护关系终止之日，监护人仍有清偿能力；保佐人的怠职不应损害监护人。裁判结论是：如果监护人一直有清偿能力至监护关系终止，即使未曾取得担保，风险也由保佐人承担；如果届时监护人已无清偿能力，则由监护人和行政官承担。也就是说，只有在监护关系终止时才发现监护人已不适任，未将其控告为可疑监护人或未要求其提供担保的人，才承担风险。

<!-- source-p 267 -->
**特里福尼努斯：《论争论》第二卷。**

<!-- source-p 268 -->
我认为，不应令某人承担最高利率，因为他从共同监护人处借用了未成年人的款项，并提供担保、允诺支付一定利息；其他债务人向未成年人支付的也正是这一利率。因为此人并未暗中挪用款项，也未把它当作自己的钱任意使用；如果共同监护人不按这一利率借给他，他本可从别处借款。公开地以外人身份成为未成年人的债务人，与在监护管理中借未成年人之名、暗中用其钱款资助自己，二者区别甚大。

<!-- source-p 269 -->
<a id="26.7.55"></a>**26.7.55**

<!-- source-p 270 -->
**特里福尼努斯：《论争论》第十四卷。**

<!-- source-p 271 -->
<a id="26.7.55.pr."></a>**序言。**为一名未成年人指定了三名监护人：一人实际管理监护事务但无清偿能力；第二人委托提提乌斯管理，而提提乌斯确曾处理某些事务；第三人完全没有管理。有人询问他们各自应在多大范围内承担责任。监护人就管理事务共同承担风险，并且人人都负全部责任。当然，如果未成年人的现金已经在他们之间分配，每个人承担的责任不得超过自己实际取得的数额。

<!-- source-p 272 -->
<a id="26.7.55.1"></a>**1.**但是，如果监护人自己盗窃未成年人的财物，应考察他们是否各自依《十二表法》规定的双倍返还之诉承担全部责任；即使一人已经给付双倍，其他人是否仍然承担责任？其他数人盗窃同一财物时，不会仅因其中一人已被追偿，就使其余人免受处罚。但监护人既已承担管理职责，其取走财物与其说是违背所有人的意愿，不如说是背信弃义。因此，没人会说一名监护人既须在该诉中给付双倍，又须通过类似返还之诉交还原物或其估价。

<!-- source-p 273 -->
<a id="26.7.55.2"></a>**2.**因此，不仅将监护事务委托他人管理的人视为已管理事务；即使他从共同监护人处取得财产妥善保全的担保，并允许共同监护人管理全部监护事务，也应作相同认定。他不得援引要求先起诉实际管理者的敕令为自己辩护。

<!-- source-p 274 -->
<a id="26.7.55.3"></a>**3.**同样，对于无人管理的事务，风险并非仅由曾处理部分事务的人承担，而是由所有监护人共同承担。但不得仅因其他未管理事务的风险就只向此人追偿；除非那些事务是完成其已开始事务所必需，或彼此关联而不应分割。

<!-- source-p 275 -->
<a id="26.7.55.4"></a>**4.**关于共同监护人是否已丧失清偿能力，或者是否应承担责任的问题，应考察其具体含义：只要自其被指定之时起财产未有减少、资产状况保持不变，是否就已足够？还是即使没有发生明显的财产减少，共同监护人仍应调查对方的财务状况？对此还应依个人品行及立遗嘱后至父亲死亡期间的长短分别判断。显然，不应允许明显挥霍无度、或财产已遭变卖的人管理共同监护事务，即使其通过隐瞒使作出裁定的裁判官受骗指定了他。父亲可能不知道遗嘱作出后发生的情况；或者虽已打算更改遗嘱，却未能实行。

<!-- source-p 276 -->
<a id="26.7.56"></a>**26.7.56**

<!-- source-p 277 -->
**斯凯沃拉：《学说汇纂》第四卷。**

<!-- source-p 278 -->
监护人出售了未成年人的财物和牲畜，但有些牲畜因买受人未付款而由监护人留在自己手中；监护人却已在未成年人的账目中将价款记作收讫。牲畜中又有一些繁殖了后代。监护人死亡后，其继承人继续管理同一监护事务，并占有这些牲畜多年。有人询问：当受监护者年满二十四岁时，是否可以依法请求返还牲畜？答复说，根据所述事实，未成年人无权请求返还这些牲畜。

<a id="26.7.57"></a>**26.7.57**

<!-- source-p 280 -->
**斯凯沃拉：《学说汇纂》第十卷。**

<!-- source-p 281 -->
<a id="26.7.57.pr."></a>**序言。**债务人的债权文书被火灾烧毁。监护人本可依据财产清册起诉债务人，要求清偿款项或更新债务；他们此前曾对其他债务人采取同样行动，却对未成年人的债务人未作处理。有人询问：如果未成年人因监护人怠于处理而遭受损失，能否在监护诉讼中获偿？答复说：如果证明监护人是出于诈欺或过失而疏于处理，就应由他们赔偿。

<!-- source-p 282 -->
<a id="26.7.57.1"></a>**1.**某人依总督判决被剥夺财产并流放，但经皇帝许可，其上诉获受理，而原先作出判决的人并未受理上诉。未成年人在监护人参与下向此人购买土地；上诉被判无正当理由后，土地被收回。有人询问未成年人能否在监护诉讼中向监护人请求土地价款。答复说：如果监护人明知卖方处于受先前判决约束的状态，仍向其购买，就应在监护诉讼中承担责任。

<!-- source-p 283 -->
<a id="26.7.58"></a>**26.7.58**

<!-- source-p 284 -->
**斯凯沃拉：《学说汇纂》第十一卷。**

<!-- source-p 285 -->
<a id="26.7.58.pr."></a>**序言。**某人通过帕姆菲鲁斯和狄菲鲁斯经营生意；他们起初是奴隶，后来获得自由。他在遗嘱中指定两人为监护人，并规定继续按照自己在世时的方式经营。两人不仅在保护人的儿子尚未成年时管理监护事务，也在其达到青春期后继续管理。狄菲鲁斯提交账目时计入了经营增长所得；帕姆菲鲁斯却认为，账目不应计入生意增长的收益，而应依监护诉讼的通常做法，只计算利息。有人询问：帕姆菲鲁斯是否也应像狄菲鲁斯那样，依死者意愿提交账目？答复说：应当如此。克劳狄乌斯·特里福尼努斯补充说：因为他不应从监护事务中获利。

<!-- source-p 286 -->
<a id="26.7.58.1"></a>**1.**两名监护人中的一人死亡时，未成年人仍未达到青春期。存续的监护人以未成年人名义提起诉讼，收回了原本在已故监护人处的监护财产及其利息。有人询问：未成年人达到青春期后提起监护诉讼，利息应仅以原本归于已故共同监护人的份额为基数，还是也包括本金所生利息；这些利息在未成年人死亡后与本金一同转交或本应转交给存续监护人？答复说：如果监护人将该款项挪作己用，就应对全部款项支付利息；如果款项仍留在未成年人的账目中，则应支付其善意取得或本可取得的款项；若本可放贷却怠于放贷，也应负责。因为债务人连同本金支付的利息，对收款人而言全部都发挥本金的作用，或应当发挥本金的作用。

<!-- source-p 287 -->
<a id="26.7.58.2"></a>**2.**遗嘱指定的监护人认为遗嘱已被撤销，因而停止管理监护事务；总督随后为未成年人另行指定一名监护人。但后来命令遗嘱指定的监护人与总督所指定、已经开始管理事务的人共同履职。有人询问：遗嘱指定的监护人应自遗嘱公开之日起，还是自接获共同管理命令之日起，对此前管理期间的风险承担责任？答复说：所问的这些人不对此前期间的风险承担责任。

<!-- source-p 288 -->
<a id="26.7.58.3"></a>**3.**遗嘱指定未成年人为继承人，却剥夺女儿的继承权，并遗赠给她二千金币；同一批监护人也被指定为两人的监护人。有人询问：自监护人本可将这二千金币从遗产中取出并用于放贷、却未如此办理之日起，是否应在监护诉讼中判令他们向该未成年女孩支付利息？答复说：应当判令支付。

<!-- source-p 289 -->
<a id="26.7.58.4"></a>**4.**有人询问：监护人应付的未成年人款项利息转交保佐人后，是否应计入本金，使保佐人开始对全部金额支付利息？答复说：转交给保佐人的全部款项均适用同一规则，因为此后全部金额都构成本金。

<a id="26.7.59"></a>**26.7.59**

<!-- source-p 291 -->
**斯凯沃拉：《学说汇纂》第二十六卷。**

<!-- source-p 292 -->
父亲的遗产负债沉重，情形似乎已至应使未成年女儿放弃父系遗产的程度。一名监护人与多数债权人达成和解，使他们满足于按一定比例受偿并收取相应款项。女儿达到适婚年龄后，其保佐人也与多数债权人达成和解。有人询问：如果一名监护人本身是女儿父亲的债权人，并已从女儿财产中收取全额本金和利息，女儿的保佐人能否要求他像其他债权人一样，只接受按比例分配的款项？答复说：如果该监护人要求其他人按比例受偿，他自己也必须满足于相同的比例。

<!-- source-p 295 -->
如果监护人的继承人继续完成监护人已经开始的事务，也应就此承担监护诉讼责任。

<!-- source-p 296 -->
<a id="26.7.61"></a>**26.7.61**

<!-- source-p 297 -->
**庞波尼乌斯：《书信集》第二十卷。**

<!-- source-p 298 -->
阿里斯托曾如此写道：如果未成年人因监护人的过错而丧失对遗产财物的占有，在遗产请求诉讼中毫无疑问应计入该财物的估价，但前提是已为未成年人就遗产提供担保。若监护人具有清偿能力，足以支付未成年人因诉讼估价而承担的金额，就视为已经提供担保。如果监护人无清偿能力，则应考察损失究竟应由未成年人还是请求人承担；应将其视同财物因偶然事件灭失，类似未成年人本人无过错地使遗产中的财物减少、损坏或灭失。对于占有遗产的精神失常者，也可以提出同样的问题：如果因其精神失常而使某物不复存在，应如何处理？你怎么看？庞波尼乌斯说：我认为他的意见是正确的。但如果监护人无清偿能力，你为何犹豫损失应由谁承担？因为还可以更妥当地说，只须将未成年人对监护人享有的诉权交付给遗产出卖人。正如继承人或遗产占有人若无过错——例如被暴力逐出遗产土地，或遗产奴隶在占有人无过错的情况下被他人伤害——只须交付其因此享有的诉权，不应承担更多责任。同样，如果精神失常者的保佐人因过失或诈欺使财物灭失，也应如此；就如监护人或保佐人曾作出要式承诺，或出售遗产财物的情形。我认为，因某人精神失常而发生的后果应予免除责任；正如无任何人的行为而因偶然事件发生时一样。
