# D.26.4 论法定监护人（*De legitimis tutoribus*）

<!-- source-p 001 -->
<a id="4"></a><a id="26.4"></a>**26.4.0. 论法定监护人。**

<!-- source-p 002 -->
<a id="26.4.1"></a>**26.4.1**

<!-- source-p 003 -->
**乌尔比安：《萨宾评注》第十四卷。**

<!-- source-p 004 -->
<a id="26.4.1.pr."></a>**序言。**《十二表法》将法定监护授予父系宗亲、同父血亲以及保护人，也就是有资格取得法定继承的人。这项安排极有远见：期望取得继承的人，同时负责照管财产，以免财产被挥霍。

<!-- source-p 005 -->
<a id="26.4.1.1"></a>**1.**有时，继承权归一人，而监护权归另一人。例如，未成年人有同父血亲的女性亲属：继承权归该女亲属，监护权则归男性父系宗亲。获释奴隶的情形也一样：如果既有女性保护人，又有保护人的儿子，那么监护权归保护人的儿子，继承权则归女性保护人。保护人有女儿和孙子的情形，也同样处理。

<!-- source-p 006 -->
<a id="26.4.1.2"></a>**2.**如果兄弟被敌人俘虏，监护权不会移交给较低顺位的父系宗亲；同样，如果保护人被敌人俘虏，监护权也不会移交给保护人的儿子。但在此期间，应由裁判官指定监护人。

<!-- source-p 007 -->
<a id="26.4.1.3"></a>**3.**有时，虽无继承权仍会取得监护权；有时，则有继承权而无监护权。例如，有人受托释放自己的奴隶，却藏匿起来不履行义务：神圣的庇护者皮乌斯曾以敕答告知奥勒利乌斯·巴苏斯，此人不享有保护人权利，并作如下说明：“对于那些企图破坏遗嘱信托所设的自由，却不愿其受益人成为自由人的人，应以这种方式惩罚：不得使其取得保护人权利。”如果获释奴隶被指定归女儿所有，情形也相同：如马尔凯卢斯所指出，监护权仍由兄弟享有，而法定继承权归姐妹。

<!-- source-p 008 -->
<a id="26.4.2"></a>**26.4.2**

<!-- source-p 009 -->
**乌尔比安：《萨宾评注》第三十七卷。**

<!-- source-p 010 -->
毫无疑问，未成年人发生人格减等，即使其公民身份仍然保留，也会丧失法定监护权。

<!-- source-p 011 -->
<a id="26.4.3"></a>**26.4.3**

<!-- source-p 012 -->
**乌尔比安：《萨宾评注》第三十八卷。**

<!-- source-p 013 -->
<a id="26.4.3.pr."></a>**序言。**《十二表法》所规定、授予保护人的法定监护权，并非该法明确、逐名授予，而是由该法赋予保护人的法定继承权推导而来。

<!-- source-p 014 -->
<a id="26.4.3.1"></a>**1.**因此，依《十二表法》，释放奴隶的人就是监护人，无论他是自愿释放，还是因遗嘱信托的原因而被迫释放。

<!-- source-p 015 -->
<a id="26.4.3.2"></a>**2.**同样，如果某人依买卖约定应予释放，而后依据神圣的马尔库斯皇帝向奥菲迪乌斯·维克托里努斯发布的敕令获得自由，那么也应说该人是监护人。

<!-- source-p 016 -->
<a id="26.4.3.3"></a>**3.**当然，如果奴隶是依据鲁布里安元老院决议获得自由，受托释放他的人便不享有监护权；该奴隶成为奥尔库斯自由人后，将归属于遗嘱人的家族。在这种情形下，监护权开始归属于保护人的子女，而不再归属于保护人本人。遗嘱释放的奥尔库斯自由人均适用此规则。

<!-- source-p 017 -->
<a id="26.4.3.4"></a>**4.**如果有两人或多人共同释放奴隶，他们都是监护人；但如果共同释放者中有女性，应说只有男性是监护人。

<!-- source-p 018 -->
<a id="26.4.3.5"></a>**5.**如果一名保护人死亡，监护权仍由其他保护人享有，即使死者留下了儿子。保护人若被敌人俘虏，暂时也只有其他共同保护人担任监护人。同样，如果一名保护人沦为奴隶，显然其他保护人仍是监护人。

<!-- source-p 019 -->
<a id="26.4.3.6"></a>**6.**但是，如果所有保护人均已死亡，监护权才开始归属于他们的子女。

<!-- source-p 020 -->
<a id="26.4.3.7"></a>**7.**因此，如果一名保护人留下儿子，另一名保护人留下孙子，监护权究竟只归儿子，还是也归孙子——毕竟孙子在其父的家族中也居于最近顺位？这应从法定继承权看出：法定继承权只归儿子。因此，监护权也只传给儿子；儿子之后，才传给孙子。

<!-- source-p 021 -->
<a id="26.4.3.8"></a>**8.**可以进一步询问：如果保护人的儿子被免职或获准免责，监护权是否转归孙子？马尔凯卢斯认为不得发生替代继任，并写道：他们退出监护，是为了由他人接替，而不是为了开启继承顺位。

<!-- source-p 022 -->
<a id="26.4.3.9"></a>**9.**法定监护中的继任，不仅因死亡而发生，也因人格减等而发生。因此，如果顺位在先者发生人格减等，其后顺位者即继任监护事务。

<!-- source-p 023 -->
<a id="26.4.3.10"></a>**10.**如果父亲将受其父权支配的未成年儿子、女儿、孙子、孙女或更远一代的未成年人解放，使其脱离父权，该父亲即代行法定监护人的职能：

<!-- source-p 024 -->
<a id="26.4.4"></a>**26.4.4**

<!-- source-p 025 -->
**莫德斯蒂努斯：《差异论》第四卷。**

<!-- source-p 026 -->
父亲死亡后，如果其子女已达到完全年龄，他们就成为兄弟或姐妹的信托监护人。

<!-- source-p 027 -->
<a id="26.4.5"></a>**26.4.5**

<!-- source-p 028 -->
**乌尔比安：《告示评注》第三十五卷。**

<!-- source-p 029 -->
<a id="26.4.5.pr."></a>**序言。**没有人指定法定监护人；是《十二表法》使其成为监护人。

<!-- source-p 030 -->
<a id="26.4.5.1"></a>**1.**当然可以确定，即使这些法定监护人也可能被要求提供担保；多数人甚至认为，应当要求保护人、保护人的儿子及其其他子女提供财产妥善保全的担保。不过，较好的做法是由裁判官查明情况后决定，是否要求保护人及其子女提供担保。如果其品行端正，就免除担保义务；若未成年人财产数额尤其有限，也更应免除。反之，如果保护人品行平庸或不佳，就应要求提供担保。因此，应根据监护事务的规模、当事人的品行或其他具体情况，决定是否要求担保。

<!-- source-p 031 -->
<a id="26.4.5.2"></a>**2.**对于法定监护人以及由官员指定的监护人，曾有人询问是否可以裁定由其中一人单独管理监护事务。拉贝奥说，即使只裁定一人管理，也完全妥当，因为其他人可能缺席或精神失常。为求实际效用，应采纳这一意见，由一人获准管理监护事务。

<!-- source-p 032 -->
<a id="26.4.5.3"></a>**3.**那么，他们能否依据前述规则相互提出异议？较为可取的意见是，如果无人提供担保，或者担保已经终止——有时并未要求他们提供担保，有时原有担保已不再有效，或者市政官员无力或不愿要求其所指定的监护人提供担保——即使在这些未获担保的情形下，也应允许提出异议。〔*provocatio* 的具体程序含义待核。〕

<!-- source-p 033 -->
<a id="26.4.5.4"></a>**4.**那么，对保护人是否也应作同样处理，尤其是在不要求担保时？我认为，除非有重大理由，不应允许保护人提出异议，以免削弱其取得继承的期待；因为如果监护事务没有交给保护人管理，而共同保护人独自管理未成年人财产不善，保护人可能因此遭受损失。

<!-- source-p 034 -->
<a id="26.4.5.5"></a>**5.**如果法定监护人发生人格减等，应当说他不再是监护人；监护关系终止后，即可提起监护诉讼。

<!-- source-p 035 -->
<a id="26.4.6"></a>**26.4.6**

<!-- source-p 036 -->
**保罗：《告示评注》第三十八卷。**

<!-- source-p 037 -->
父亲未立遗嘱死亡时，监护权归父系宗亲。所谓未立遗嘱，不仅指未制作遗嘱的人，也包括在遗嘱中未为子女指定监护人的人；就监护事项而言，此人仍视为未立遗嘱。同样，如果遗嘱指定的监护人在儿子尚未成年时死亡，其监护权即回归父系宗亲。

<!-- source-p 038 -->
<a id="26.4.7"></a>**26.4.7**

<!-- source-p 039 -->
**盖尤斯：《法学阶梯》第一卷。**

<!-- source-p 040 -->
父系宗亲是指通过男性亲属而形成亲属关系的人，即属于父系亲属，例如同父兄弟、兄弟的儿子或孙子，以及叔父、叔父的儿子或孙子。

<!-- source-p 041 -->
<a id="26.4.8"></a>**26.4.8**

<!-- source-p 042 -->
**保罗：《告示评注》第三十八卷。**

<!-- source-p 043 -->
如果我留下未成年的儿子、兄弟以及另一儿子所生的孙子，只要他们均已达到完全年龄，就应确认兄弟和孙子都是监护人，因为他们处于同一亲等。

<!-- source-p 044 -->
<a id="26.4.9"></a>**26.4.9**

<!-- source-p 045 -->
**盖尤斯：《行省告示评注》第十二卷。**

<!-- source-p 046 -->
如果有数名父系宗亲，最近顺位者取得监护权；如果数人处于同一亲等，则他们全都取得监护权。

<!-- source-p 047 -->
<a id="26.4.10"></a>**26.4.10**

<!-- source-p 048 -->
**赫莫革尼安努斯：《法学撮要》第二卷。**

<!-- source-p 049 -->
<a id="26.4.10.pr."></a>**序言。**即使有亲等较近的女性亲属，也不妨碍男性父系宗亲担任未成年男性父系宗亲的监护人。因此，即使某人的兄弟之子有同父姐妹，其叔父仍是法定监护人；同样，姑母也不妨碍叔祖父担任监护人，姨母也不妨碍兄弟之子担任监护人。

<!-- source-p 050 -->
<a id="26.4.10.1"></a>**1.**聋者和哑者均不能担任法定监护人，因为无论通过遗嘱还是以其他方式，都不能有效地指定他们为监护人。

<!-- source-p 051 -->
<a id="26.4.11"></a>**26.4.11**

<!-- source-p 052 -->
**保罗：《普劳提乌斯评注》第十六卷。**

<!-- source-p 053 -->
听力较弱者则可以担任监护人。
