<!-- 源段落 731 -->
# <a id="8"></a><a id="26.8"></a>26.8.0 论监护人和保佐人的认可与同意

<!-- 源段落 732 -->
### <a id="26.8.1"></a>26.8.1

<!-- 源段落 733 -->
乌尔比安《评萨宾》第一卷

<!-- 源段落 734 -->
<a id="26.8.1.pr."></a>

**序言（pr.）** 尽管市民法的一般规则是不允许监护人就自身利益作出认可，但监护人可以认可未适婚人接受其本人债务人的遗产；尽管如此，该监护人会因此成为该债务人的债权人。认可的首要目的在于使未适婚人成为继承人；由此产生的后果是，他须承担该债务。可是，监护人不得以认可人的身份从未适婚人处取得对自己的要式口约。曾有监护人认可其受监护的女孩向监护人自己的奴隶作出要式口约并承诺履行，神圣安敦尼努斯·庇护皇帝以敕答指出，依法律该女孩不承担责任；但在其因而变得较为富有的范围内，应给予诉权。若监护人认可将某物交付给自己的儿子，则该认可无效，因为该物显然是凭借监护人自己的认可而归其本人取得。

<!-- 源段落 735 -->
<a id="26.8.1.1"></a>

**1.** 若监护人遭强力扣留而非自愿在场，所为行为无效。仅有其身体在场，并不足以构成认可；例如，他因睡眠或癫痫发作而未作表示。

<!-- 源段落 736 -->
### <a id="26.8.2"></a>26.8.2

<!-- 源段落 737 -->
乌尔比安《评萨宾》第二十四卷

<!-- 源段落 738 -->
无论监护人的认可未曾介入，还是其认可被不当援用，法律效果并无差别。

<!-- 源段落 739 -->
### <a id="26.8.3"></a>26.8.3

<!-- 源段落 740 -->
保罗《评萨宾》第八卷

<!-- 源段落 741 -->
即使无人询问监护人，而监护人仍作出认可，只要他表示赞同所进行的行为，其认可便有效；这正是作出认可的含义。

<!-- 源段落 742 -->
### <a id="26.8.4"></a>26.8.4

<!-- 源段落 743 -->
庞波尼乌斯《评萨宾》第十七卷

<!-- 源段落 744 -->
尽管在指定了数名监护人的情况下，一名监护人的认可已经足够；但若作出认可的监护人并未获准管理监护事务，裁判官就不应承认该认可有效。因此，我认为奥菲利乌斯的意见更为正确：若我明知另有监护人正在管理监护事务，却在一名未负责管理的监护人认可下向未适婚人购买财物，我便不能取得所有权。同样，若作出认可的监护人已被免除监护职责，我也不能取得所有权；这种认可不应被承认为有效。

<!-- 源段落 745 -->
### <a id="26.8.5"></a>26.8.5

<!-- 源段落 746 -->
乌尔比安《评萨宾》第四十卷

<!-- 源段落 747 -->
<a id="26.8.5.pr."></a>

**序言（pr.）** 未适婚人不得在其监护人认可之下对该监护人负担债务。若有数名监护人，且其中一人的认可即已足够，则应当说，另一名监护人认可时，未适婚人可以对该另一名监护人负担债务：无论是该监护人向未适婚人出借金钱，还是未适婚人向该监护人作出要式口约，均是如此。但即使该监护人是唯一的监护人，若他向未适婚人出借金钱，或未适婚人向他作出要式口约，未适婚人仍不因此对监护人负担法律上的债务。不过，未适婚人仍会在事实上负担自然债务，范围以其因此受益为限；因为神圣庇护皇帝曾以敕答规定，不仅监护人，任何人均可在未适婚人受益的范围内对其提起诉讼。

<!-- 源段落 748 -->
<a id="26.8.5.1"></a>

**1.** 未适婚人未经监护人认可而出售财物，不因此负担债务；购买财物亦同，但以其受益为限的责任除外。

<!-- 源段落 749 -->
<a id="26.8.5.2"></a>

**2.** 监护人本人不得兼任买受人或出卖人。不过，若其另有共同监护人，且该共同监护人的认可已经足够，则监护人当然可以购买。但若买卖系出于恶意，则买卖不发生效力，因此也不能据此取得时效完成的所有权。若未适婚人在达到适婚年龄后追认该买卖，合同即有效。

<!-- 源段落 750 -->
<a id="26.8.5.3"></a>

**3.** 若监护人借由他人购买未适婚人的财物，该买卖亦不发生效力，因为他显然并非善意行事。神圣塞维鲁与安敦尼努斯皇帝曾以敕答作此规定。

<!-- 源段落 751 -->
<a id="26.8.5.4"></a>

**4.** 当然，若监护人本人公开购买，只是没有恶意而单纯借用他人名义——正如身份显贵者通常不愿自己的姓名记载于文书之中——买卖仍然有效；但若他是蓄意如此，则与借由他人购买无异。

<!-- 源段落 752 -->
<a id="26.8.5.5"></a>

**5.** 即使由未适婚人的债权人出售其财物，监护人同样可以善意购买。

<!-- 源段落 753 -->
<a id="26.8.5.6"></a>

**6.** 若监护人的儿子或其他受其权力支配的人购买财物，法律效果与监护人本人购买相同。

<!-- 源段落 754 -->
### <a id="26.8.6"></a>26.8.6

<!-- 源段落 755 -->
庞波尼乌斯《评萨宾》第十七卷

<!-- 源段落 756 -->
未获准管理监护事务的监护人，可以作为外人从未适婚人处购买财物；此种购买应予认可。

<!-- 源段落 757 -->
### <a id="26.8.7"></a>26.8.7

<!-- 源段落 758 -->
乌尔比安《评萨宾》第四十卷

<!-- 源段落 759 -->
<a id="26.8.7.pr."></a>

**序言（pr.）** 我们所说监护人不得就自身利益作出认可，仅在通过监护人本人或受其支配的人为其取得要式口约时才属实。除此以外，如前所述，监护人作出认可，并不妨碍他通过由此产生的后果为自己处理事务。

<!-- 源段落 760 -->
<a id="26.8.7.1"></a>

**1.** 若有两名共同债权人，其中一人经我认可而向未适婚人作出要式口约，另一人则经另一名监护人认可而作出要式口约，应当认为该口约有效；但以一名监护人的认可已经足够为前提。若一名监护人的认可尚不足够，则该口约应属无效。

<!-- 源段落 761 -->
<a id="26.8.7.2"></a>

**2.** 若父亲和处于其家父权之下的儿子均为监护人，而父亲在儿子认可下作出要式口约，该口约不发生效力，因为儿子不能就其父亲自身利益作出认可。

<!-- 源段落 762 -->
### <a id="26.8.8"></a>26.8.8

<!-- 源段落 763 -->
乌尔比安《评萨宾》第四十八卷

<!-- 源段落 764 -->
即使与未适婚人订立的是附条件合同，监护人也应无条件地作出认可。认可不得附条件，而应以纯粹、无条件的方式作出，从而使附条件合同获得确认。

<!-- 源段落 765 -->
### <a id="26.8.9"></a>26.8.9

<!-- 源段落 766 -->
盖尤斯《评行省告示》第十二卷

<!-- 源段落 767 -->
<a id="26.8.9.pr."></a>

**序言（pr.）** 未适婚人未经监护人认可，不得因任何合同而负担债务；但其可以未经监护人认可，通过作出要式口约或接受交付而为自己取得权利。可是，他不能通过出借金钱使他人对自己负担债务，因为未经监护人认可，他不得处分任何财物。

<!-- 源段落 768 -->
<a id="26.8.9.1"></a>

**1.** 既然未适婚人未经监护人认可不得处分任何财物，就可以看出，他未经监护人认可也不得使奴隶获得自由。此外，即使经监护人认可而使奴隶获得自由，也必须依《埃利娅·森提亚法》在审查委员会前证明其事由。

<!-- 源段落 769 -->
<a id="26.8.9.2"></a>

**2.** 未适婚人未经监护人认可而履行任何债务，均不发生效力，因为他不能转移所有权；不过，若债权人善意地花用了未适婚人支付的金钱，未适婚人即获解除债务。

<!-- 源段落 770 -->
<a id="26.8.9.3"></a>

**3.** 未适婚人未经监护人认可不得接受遗产，即使接受遗产纯属获利且不会遭受任何损失，亦是如此。

<!-- 源段落 771 -->
<a id="26.8.9.4"></a>

**4.** 未适婚人未经监护人认可，也不得依据特雷贝利安元老院决议接受遗产。

<!-- 源段落 772 -->
<a id="26.8.9.5"></a>

**5.** 监护人必须在法律行为进行当时亲自作出认可；事后作出认可或通过书信作出认可，均不发生效力。

<!-- 源段落 773 -->
<a id="26.8.9.6"></a>

**6.** 即使与未适婚人订约的人没有亲耳听到监护人作出认可，只要该认可有书面证明，法律行为仍可有效进行。例如，我以书信方式向不在场的未适婚人出售或出租某物，而其监护人以书面认可同意该行为。

<!-- 源段落 774 -->
### <a id="26.8.10"></a>26.8.10

<!-- 源段落 775 -->
保罗《评告示》第二十四卷

<!-- 源段落 776 -->
因疾病、缺席或其他正当事由而无法作出认可的监护人，不承担责任。

<!-- 源段落 777 -->
### <a id="26.8.11"></a>26.8.11

<!-- 源段落 778 -->
盖尤斯《评行省告示》第十五卷

<!-- 源段落 779 -->
若遗产占有权归未适婚人或精神错乱者所有，为便于处理事务，法院认为，在承认或放弃遗产占有时，应考虑其监护人或保佐人的意思。若监护人或保佐人作出任何有损未适婚人或精神错乱者利益的行为，应依监护或保佐之诉承担责任。

<!-- 源段落 780 -->
### <a id="26.8.12"></a>26.8.12

<!-- 源段落 781 -->
尤利安《学说汇纂》第二十一卷

<!-- 源段落 782 -->
若你与提提乌斯共同所有的奴隶，经你认可，从你所监护的女孩处受领某物的交付，该物将全部归提提乌斯所有。马尔凯卢斯注：凡某物不能归全体所有人共同取得的，古代法学家认可，应由能够取得该物的人单独取得。

<!-- 源段落 783 -->
### <a id="26.8.13"></a>26.8.13

<!-- 源段落 784 -->
尤利安《学说汇纂》第二十一卷

<!-- 源段落 785 -->
未适婚人经监护人认可，即使保持沉默，也会负担债务。例如，他们借入金钱时，即使没有说任何话，只要监护人作出认可，他们便受其约束。因此，若向这些人支付了本不应支付的金钱，即使他们保持沉默，只要监护人作出认可，便足以使其负返还之诉责任。

<!-- 源段落 786 -->
### <a id="26.8.14"></a>26.8.14

<!-- 源段落 787 -->
尤利安《学说汇纂》第三十一卷

<!-- 源段落 788 -->
监护人是在订立法律行为时缺席，还是虽在场却不知道所订法律行为的性质，两者并无多大差别。

<!-- 源段落 789 -->
### <a id="26.8.15"></a>26.8.15

<!-- 源段落 790 -->
马尔基安《规则》第二卷

<!-- 源段落 791 -->
同一监护人可以为接受人和给付人双方的诉讼行为作出认可。但这是否仅指他分别作出两次认可，还是一次认可也足够，只要其意思是使认可适用于双方？庞波尼乌斯对此有所疑问；不过，一次认可即已足够的意见得到了有力支持。

<!-- 源段落 792 -->
### <a id="26.8.16"></a>26.8.16

<!-- 源段落 793 -->
保罗《论埃利娅·森提亚法判例》第一卷

<!-- 源段落 794 -->
即使监护人已经失明，仍然可以作出认可。

<!-- 源段落 795 -->
### <a id="26.8.17"></a>26.8.17

<!-- 源段落 796 -->
保罗《评告示》第六卷

<!-- 源段落 797 -->
若监护人不愿为未适婚人作出认可，裁判官不应强迫他这样做。首先，即使作出认可对未适婚人并无益处，强迫监护人认可也不公平；其次，即使这样做对未适婚人有益，他仍可通过监护之诉请求赔偿因此遭受的损失。

<!-- 源段落 798 -->
### <a id="26.8.18"></a>26.8.18

<!-- 源段落 799 -->
保罗《评普劳提乌斯》第一卷

<!-- 源段落 800 -->
经监护人认可，未适婚人可以将自己的债务人指定为对提提乌斯负债的人。但若监护人本人欠未适婚人的债务，则不得在监护人自己的认可下将其指定为受让债务人，也不得以该监护人为被告而指定代理人；否则，监护人将凭借自己的认可而获得债务解除。

<!-- 源段落 801 -->
### <a id="26.8.19"></a>26.8.19

<!-- 源段落 802 -->
保罗《答复集》第九卷

<!-- 源段落 803 -->
可以为未适婚人指定保佐人；但是，对于法律要求遵循正式程序的事项，仍须由监护人作出认可，方能处理。

<!-- 源段落 804 -->
### <a id="26.8.20"></a>26.8.20

<!-- 源段落 805 -->
斯凯沃拉《学说汇纂》第十卷

<!-- 源段落 806 -->
数名未适婚人之间分割父亲遗产时，监护人在场，但未在分割文书上签字。有人询问：是否仍应遵守该分割？答复是：若监护人已经作出认可，则不能仅因他未在文书上签字而不遵守该分割。

<!-- 源段落 807 -->
### <a id="26.8.21"></a>26.8.21

<!-- 源段落 808 -->
斯凯沃拉《学说汇纂》第二十六卷

<!-- 源段落 809 -->
监护人为未适婚人进行辩护后，未适婚人因其父亲订立的合同而被判承担责任；随后为该未适婚人指定了一名保佐人。保佐人与债权人在凯撒的代理官面前进行如下陈述。凯撒代理官普里斯库斯说：“执行已经裁定的事项。”保佐人诺维利乌斯说：“我代表未适婚人声明不承受遗产。”凯撒代理官普里斯库斯说：“你已经得到答复；你知道应当怎么做。”有人询问，是否可根据这些陈述认定该青年已不承受其父亲的遗产。答复是：所述情形表明，他已声明不承受遗产。〔本段末附底本题号：26.8.22〕

<!-- 源段落 810 -->
拉贝奥《论实用判例》第五卷

<!-- 源段落 811 -->
若未适婚人必须提起某项诉讼才能使其监护人免责，就不得在监护人本人认可的情况下提起该诉讼。
<!-- 源段落 812 -->
# <a id="9"></a><a id="26.9"></a>26.9.0 论未成年人何时得因监护人或保佐人的行为提起诉讼或被诉

<!-- 源段落 813 -->
### <a id="26.9.1"></a>26.9.1

<!-- 源段落 814 -->
庞波尼乌斯《评萨宾》第二十九卷

<!-- 源段落 815 -->
阿里斯托认为，因监护人的欺诈或过失，应判令作为占有人的未适婚人承担责任。但我不认为应按照原告在诉讼标的上的宣誓估值判赔。尽管如此，仅在未适婚人能够从监护人处保全该物的情况下，才应如此处理。

<!-- 源段落 816 -->
### <a id="26.9.2"></a>26.9.2

<!-- 源段落 817 -->
乌尔比安《意见集》第一卷

<!-- 源段落 818 -->
若监护人或保佐人以其所管理事务之人的金钱向他人出借，并由自己作出要式口约，或者以自己的名义购买土地，则应向出资人给予准诉权，使其得请求返还该物或追回借出的钱款。

<!-- 源段落 819 -->
### <a id="26.9.3"></a>26.9.3

<!-- 源段落 820 -->
帕皮尼安《疑义集》第二十卷

<!-- 源段落 821 -->
监护人的欺诈不应使未成年人受损，也不应使其获益。通常所说“监护人的欺诈不损害未适婚人”，只有在未适婚人未因该欺诈而变得较为富有时，才是正确的。因此，萨宾正确地认为，若监护人因不公正分配而使未适婚人的账目受益，就应基于监护人的欺诈对未适婚人提起分配之诉。寄托之诉也应如此；在遗产请求之诉中亦然，但须证明因监护人的欺诈而未能取得的财物，确已记入未适婚人的账目。

<!-- 源段落 822 -->
### <a id="26.9.4"></a>26.9.4

<!-- 源段落 823 -->
乌尔比安《评告示》第六十四卷

<!-- 源段落 824 -->
若监护人在监护事务之外另行实施欺诈，该行为不应使未适婚人受损。

<!-- 源段落 825 -->
### <a id="26.9.5"></a>26.9.5

<!-- 源段落 826 -->
帕皮尼安《答复集》第五卷

<!-- 源段落 827 -->
<a id="26.9.5.pr."></a>

**序言（pr.）** 精神错乱者死亡后，不得对曾管理其事务的保佐人提起基于判决的诉讼；对监护人亦同。前提是：须能确定，在其职务结束后，并未经同意另行完成债务更新，将原债务转移至保佐人或监护人名下。

<!-- 源段落 828 -->
<a id="26.9.5.1"></a>

**1.** 未适婚人的父亲被判承担一笔款项后，监护人曾保证代为支付；监护职责终止后，该监护人得适当地拒绝此项诉讼。对于另一种情形，法律意见并非如此：监护人以自己的名义借入款项，并为未适婚人履行判决义务；但若债权人订约时的目的正是使该款项转用于履行判决，则另当别论。

<!-- 源段落 829 -->
### <a id="26.9.6"></a>26.9.6

<!-- 源段落 830 -->
帕皮尼安《法律定义集》第二卷

<!-- 源段落 831 -->
监护人经裁判官裁定后放弃了诉讼请求。若法院依其主张作出判决，基于该判决的诉权即转归未适婚人；这与监护人胜诉的情形并无不同。

<!-- 源段落 832 -->
### <a id="26.9.7"></a>26.9.7

<!-- 源段落 833 -->
斯凯沃拉《疑义集》第十三卷

<!-- 源段落 834 -->
对于曾为婴儿辩护的监护人，应予救济，使基于判决的诉权得以针对未适婚人提起。〔底本题号接续附于本段：26.9.8〕

斯凯沃拉《答复集》第五卷

一名既是未适婚人的监护人又是其共同继承人的人，因遗嘱信托请求而被起诉时，曾为全部债务提供担保。有人询问：是否可以对现已成年的未适婚人按其应负份额给予准诉权？答复：应当给予〔底本异文：danda／dandam〕。

# <a id="10"></a><a id="26.10"></a>26.10.0 论有嫌疑的监护人和保佐人

<!-- 源段落 838 -->
### <a id="26.10.1"></a>26.10.1

<!-- 源段落 839 -->
乌尔比安《评告示》第三十五卷

<!-- 源段落 840 -->
<a id="26.10.1.pr."></a>

**序言（pr.）** 本告示条款既常被援用，又极为必要：人们每天都会请求认定监护人有嫌疑。

<!-- 源段落 841 -->
<a id="26.10.1.1"></a>

**1.** 首先，我们要讨论“有嫌疑”的指控从何而来，以及可以向何人提出申请，请求认定某监护人或保佐人有嫌疑；其次，讨论哪些人可以被免职、由谁提出申请以及基于何种事由免职；最后，讨论对有嫌疑者的处罚。

<!-- 源段落 842 -->
<a id="26.10.1.2"></a>

**2.** 应当知道，对监护人提出有嫌疑的指控源自《十二表法》。

<!-- 源段落 843 -->
<a id="26.10.1.3"></a>

**3.** 在罗马，认定并免除有嫌疑监护人的权力授予裁判官；在各行省，则授予该省的省长官。

<!-- 源段落 844 -->
<a id="26.10.1.4"></a>

**4.** 能否向前总督的副官提出申请，认定监护人有嫌疑，曾有疑问。但安敦尼努斯皇帝与神圣塞维鲁皇帝曾以敕答复非洲前总督布拉杜阿·毛里库斯，认为可以这样做，因为一旦司法管辖权委托给副官，审判职务的全部权限便转移给他。因此，若裁判官委托司法管辖权，也应以同样方式认定：可以向受委托者提出申请，认定监护人有嫌疑。既然这份敕答针对行省情形作出，顺理成章也应认为，裁判官将司法管辖权委托给某人后，该人亦可审理有关监护人有嫌疑的案件。

<!-- 源段落 845 -->
<a id="26.10.1.5"></a>

**5.** 我们已经说明哪些人可以审理有嫌疑监护人的案件；现在来看哪些人可以被认定有嫌疑。所有监护人均可被控告，无论是遗嘱指定的监护人，还是其他种类的监护人。因此，即使是法定监护人，也可以被控告。若其为庇护人呢？仍应作同样判断，但须记得应当宽待庇护人。

<!-- 源段落 846 -->
<a id="26.10.1.6"></a>

**6.** 接下来应当讨论谁可以请求认定监护人有嫌疑。应当知道，这近似于一种公共诉权，也就是说，任何人都可以提出。

<!-- 源段落 847 -->
<a id="26.10.1.7"></a>

**7.** 不仅如此，妇女也获准提出申请，但仅限于因亲属间的亲爱之情而参与此事者，例如母亲。乳母和祖母也可以提出。姐妹亦可；关于姐妹，尚有神圣塞维鲁皇帝的敕答。若有其他妇女，裁判官确认她并非因抛弃女性应有的矜持而行事，而是出于亲爱之情，无法容忍未适婚人受到侵害的，也应准许她提出控告。

<!-- 源段落 848 -->
<a id="26.10.1.8"></a>

**8.** 若某平民因在履行监护职责时实施极其严重的行为而被控告，应将其移送城市长官，予以严厉处罚。

<!-- 源段落 849 -->
### <a id="26.10.2"></a>26.10.2

<!-- 源段落 850 -->
乌尔比安《论各类审判机关》第一卷

<!-- 源段落 851 -->
释奴人若被证明以欺诈方式管理其庇护人子女的监护事务，也应移送城市长官予以处罚。

<!-- 源段落 852 -->
### <a id="26.10.3"></a>26.10.3

<!-- 源段落 853 -->
乌尔比安《评告示》第三十五卷

<!-- 源段落 854 -->
<a id="26.10.3.pr."></a>

**序言（pr.）** 监护人也可以使其共同监护人被认定有嫌疑，无论该监护人本人仍在任，还是其已不再担任监护人而共同监护人仍在任；神圣塞维鲁皇帝曾以敕答作此规定。此外，神圣庇护皇帝在致凯基利乌斯·佩提努斯的敕答中指出，已被免职的监护人也可以使自己的共同监护人被认定有嫌疑。

<!-- 源段落 855 -->
<a id="26.10.3.1"></a>

**1.** 未适婚人的释奴若指控其监护人或保佐人在管理庇护人或庇护人子女的财产时行为不当，便是出于善意行事。但若他们想在监护职责中指控自己的庇护人有嫌疑，最好不准许释奴提出控告，以免审理过程中出现更严重的问题；其他任何人都可以提出控告。

<!-- 源段落 856 -->
<a id="26.10.3.2"></a>

**2.** 不仅青少年的保佐人，而且精神错乱者或挥霍者的保佐人，也可以作为有嫌疑者予以免职。

<!-- 源段落 857 -->
<a id="26.10.3.3"></a>

**3.** 管理胎儿或其财产的人，也不能免于被提出此项指控。

<!-- 源段落 858 -->
<a id="26.10.3.4"></a>

**4.** 还应考察，是否可以不经控告而免除有嫌疑者。较妥当的意见是：若裁判官根据极为明确的事实证据确信某人有嫌疑，就应将其免职；此规则应从有利于未适婚人的角度理解。

<!-- 源段落 859 -->
<a id="26.10.3.5"></a>

**5.** 现在来看，基于哪些事由可以免除有嫌疑的监护人。应当知道，若监护人在履行监护职责时实施欺诈，例如侵吞财产、行为卑劣、对未适婚人造成损害，或在任监护人时从未适婚人的财产中侵占任何物品，即可请求认定其有嫌疑。若他是在担任监护人之前实施该行为——即使行为涉及未适婚人的财产或监护事务——也不能请求认定其为有嫌疑的监护人，因为该违法行为先于监护职责发生。因此，若他侵吞了未适婚人的财产，但行为发生在其担任监护人之前，应以侵吞遗产罪控告；若不符合该罪，则应以盗窃罪控告。

<!-- 源段落 860 -->
<a id="26.10.3.6"></a>

**6.** 可以询问：若某人曾是未适婚人的监护人，后来又被确认为青少年的保佐人，是否可以因监护职责中的不法行为而请求认定其有嫌疑？既然共同保佐人可以对其提起监护之诉，顺理成章便应认为，不再适用有嫌疑指控，因为在其卸任并由他人接任后，仍可提起监护之诉。

<!-- 源段落 861 -->
<a id="26.10.3.7"></a>

**7.** 若某人曾停止担任监护人，之后又重新担任，也应提出同一问题。例如，他仅在一段时间内或某项条件存续期间受指定，之后又因遗嘱条件成就或裁判官再次指定而重新担任。能否请求认定其有嫌疑？由于这是两段监护职责，若有人可以对其提起监护之诉，极为公平的结论便是，不再适用有嫌疑指控。

<!-- 源段落 862 -->
<a id="26.10.3.8"></a>

**8.** 若该人是唯一的监护人，是否会因为监护之诉不再适用，而应将其免除管理职责，理由是他在另一段监护职责中表现不当，故在当前管理中也有嫌疑？同样的结论也可适用于监护职责结束后被单独确认为保佐人的人。

<!-- 源段落 863 -->
<a id="26.10.3.9"></a>

**9.** 若某人受指定时附有如下条件：“只要他在意大利境内，就担任监护人”，或者“只要他尚未前往海外，就担任监护人”，能否基于其离开海外之前履行监护职责的行为请求认定其有嫌疑？较妥当的意见是，可以提出申请；此处应视为一段监护职责，只是履行期间有所间断。

<!-- 源段落 864 -->
<a id="26.10.3.10"></a>

**10.** 若某人因公务而将暂时离开，并请求另行指定一人代替自己担任监护人，他返回后是否可以基于此前的管理行为被请求认定有嫌疑？由于可以基于其先前的管理行为对其提起准诉，故不再适用该项申请。

<!-- 源段落 865 -->
<a id="26.10.3.11"></a>

**11.** 若一名负责管理胎儿及其财产的保佐人曾欺诈行事，之后又被指定为监护人，能否因其在保佐期间实施的欺诈而请求认定其有嫌疑，尚有疑问。若他有共同监护人，则不得提出此项申请，因为可以对其提起诉讼；若没有共同监护人，则可以将其免职。

<!-- 源段落 866 -->
<a id="26.10.3.12"></a>

**12.** 若监护人是未适婚人或其父母的仇敌，或者存在其他足以促使裁判官认为其不应履行监护职责的正当理由，裁判官就应将其排除。

<!-- 源段落 867 -->
<a id="26.10.3.13"></a>

**13.** 塞维鲁和安敦尼努斯皇帝曾以敕答回复埃皮库鲁斯：监护人在未经裁定的情况下处分法律禁止处分的财物，其行为固然不发生效力；但若他们是以欺诈方式为之，就应将其免职。

<!-- 源段落 868 -->
<a id="26.10.3.14"></a>

**14.** 监护人若不出面为未适婚人提供生活供给，即有嫌疑，可以将其免职。

<!-- 源段落 869 -->
<a id="26.10.3.15"></a>

**15.** 但若他并未躲藏，而是在场主张自己无力支付任何款项，因为其一贫如洗；而未适婚人聘请律师后证明他在说谎，则应将其移送城市长官。无论某人为使调查受到操纵而得以被指定为监护人，还是虽经善意调查获任监护人，却像强盗一样侵占他人财产，两者并无差别。因此，此人不应仅以“有嫌疑”为由免职，而应移送处罚；处罚应与那些通过贿赂裁判官的属员而谋得监护职责的人所受处罚相同。

<!-- 源段落 870 -->
<a id="26.10.3.16"></a>

**16.** 有些人顽固拒绝为购买土地交付金钱，且在出现购买机会之前也拒绝寄存该款；法律命令将其拘禁于公共监狱，并另将其视为有嫌疑者。但应当知道，并非所有人都应受此严厉处置，尤其是地位低下者才如此；至于具有一定身份地位的人，我认为不应将其拘禁于公共监狱。

<!-- 源段落 871 -->
<a id="26.10.3.17"></a>

**17.** 监护人若因轻率或欺诈而使未适婚人未能接受遗产，可以请求认定其有嫌疑。

<!-- 源段落 872 -->
<a id="26.10.3.18"></a>

**18.** 若某人因怠惰、粗疏、无能、轻信或不适任而被免职，其卸任监护或保佐职责时名誉仍保持完整。若某人并未因欺诈而被免职，只是另有人被指定与其共同履职，他也不因此蒙受污名，因为法院并未命令其卸任。

<!-- 源段落 873 -->
### <a id="26.10.4"></a>26.10.4

<!-- 源段落 874 -->
乌尔比安《论各类审判机关》第一卷

<!-- 源段落 875 -->
<a id="26.10.4.pr."></a>

**序言（pr.）** 正是这些事由，使某人可以在不损害名誉的情况下卸任监护或保佐职责。

<!-- 源段落 876 -->
<a id="26.10.4.1"></a>

**1.** 因此，裁定中应说明免职事由，以便明确其名誉状况。

<!-- 源段落 877 -->
<a id="26.10.4.2"></a>

**2.** 若裁判官未在其裁定中说明免职事由，该怎么办？帕皮尼安说，应当注明此人名誉完整；此说正确。

<!-- 源段落 878 -->
<a id="26.10.4.3"></a>

**3.** 若裁判官并未以判决免除监护人，而只是禁止其履行监护职责，则应认为该人也因此不再是监护人。

<!-- 源段落 879 -->
<a id="26.10.4.4"></a>

**4.** 未曾履行监护职责的人，不得被申请认定为有嫌疑；但若其因怠惰、疏忽或欺诈而有过错，则可以将其免职。

<!-- 源段落 880 -->
### <a id="26.10.5"></a>26.10.5

<!-- 源段落 881 -->
乌尔比安《论争议问题》第三卷

<!-- 源段落 882 -->
即使监护人已经提供担保，或此刻提出愿意提供担保，仍可以请求认定其有嫌疑。对未适婚人而言，确保财产安全比仅持有一份担保文书更有利；共同监护人也不应仅以未适婚人已经获得担保为由，而不请求认定其共同监护人有嫌疑，

<!-- 源段落 883 -->
### <a id="26.10.6"></a>26.10.6

<!-- 源段落 884 -->
卡利斯特拉图斯《论审判程序》第四卷

<!-- 源段落 885 -->
因为提供担保并不会改变监护人的恶意，只会让他有更长时间侵害家庭财产。

<!-- 源段落 886 -->
### <a id="26.10.7"></a>26.10.7

<!-- 源段落 887 -->
乌尔比安《论各类审判机关》第一卷

<!-- 源段落 888 -->
<a id="26.10.7.pr."></a>

**序言（pr.）** 不允许未适婚人申请认定监护人有嫌疑；但若青少年愿意，可以允许其申请认定自己的保佐人有嫌疑，只要其是在近亲属建议下这样做。

<!-- 源段落 889 -->
<a id="26.10.7.1"></a>

**1.** 若未实施欺诈，而只是严重疏忽，因为这种疏忽几乎等同于欺诈，就应将该人作为有嫌疑者免职。

<!-- 源段落 890 -->
<a id="26.10.7.2"></a>

**2.** 此外，我国皇帝和神圣塞维鲁皇帝致阿特里乌斯·克洛尼乌斯的敕书还规定了若干情形：对于那些为避免裁定支付生活供给而持续拒不到场的人，应命令其不得支配自身财产〔ut suis rebus careant，具体法律效果未详〕；为保全财产，应使未适婚人取得对该有嫌疑者财产的占有；凡因迟延可能贬损的财物，则应指定保佐人后予以变卖。

<!-- 源段落 891 -->
<a id="26.10.7.3"></a>

**3.** 同样，若被指定的监护人不出庭，通常会以告示传唤；最终，若其仍不露面，便可仅因其不出面而将其作为有嫌疑者免职。但这种做法应极少采用，且须经过审慎调查。

<!-- 源段落 892 -->
### <a id="26.10.8"></a>26.10.8

<!-- 源段落 893 -->
乌尔比安《评告示》第六十一卷

<!-- 源段落 894 -->
我们认为，有嫌疑的监护人是指其品行足以令人怀疑的人。监护人即使贫穷，只要忠诚且勤勉，就不应仅以有嫌疑为由将其免职。

<!-- 源段落 895 -->
### <a id="26.10.9"></a>26.10.9

<!-- 源段落 896 -->
莫德斯蒂努《论法学发现》（De heurematicis）单卷

<!-- 源段落 897 -->
若监护人与未适婚人具有亲属或姻亲关系，或者庇护人正在管理其释奴子女的监护事务，而他们中有人似乎应被免职，最妥当的做法是为其增设一名保佐人，而不是使其因诚信和名誉受损而被免职。

<!-- 源段落 898 -->
### <a id="26.10.10"></a>26.10.10

<!-- 源段落 899 -->

<!-- 源段落 900 -->
监护人依裁判官裁定作为有嫌疑者被免职后，无须再担心未来的责任风险。若将其免除监护或保佐职责，却仍不能使其今后获得安全保障，显然有失公平。

### <a id="26.10.11"></a>26.10.11

<!-- 源段落 902 -->
帕皮尼安《答复集》第五卷

<!-- 源段落 903 -->
监护职责终止后，对有嫌疑监护人的审理程序即告结束，即使该程序早已开始亦然。

<!-- 源段落 904 -->
### <a id="26.10.12"></a>26.10.12

<!-- 源段落 905 -->
阿奎拉《答复集》

<!-- 源段落 906 -->
没有任何理由表明，保佐人可以在审理监护人有嫌疑的程序中提出抗辩，以阻止裁判官听取未适婚人的奴隶揭发欺诈的陈述并据此开展调查。
