# D.26.1 论监护（*De tutelis*）

<!-- source-p 001 -->
<a id="1"></a><a id="26.1"></a>**26.1.0. 论监护。**

<!-- source-p 002 -->
<a id="26.1.1"></a>**26.1.1**

<!-- source-p 003 -->
**保罗：《告示评注》第三十八卷。**

<!-- source-p 004 -->
<a id="26.1.1.pr."></a>**序言。**依塞尔维乌斯的定义，监护是市民法授予并许可的一种权力与权限，施用于自由人身，以保护因年龄尚幼而不能自行维护自身的人。

<!-- source-p 005 -->
<a id="26.1.1.1"></a>**1.**监护人就是拥有上述权力与权限的人；其名称也由此而来。因此，*tutores* 一词犹如 *tuitores*，意为保护者、捍卫者，正如 *aeditui* 指守护神庙的人。

<!-- source-p 006 -->
<a id="26.1.1.2"></a>**2.**不能指定哑者为监护人，因为他无法作出监护人的同意。

<!-- source-p 007 -->
<a id="26.1.1.3"></a>**3.**多数法学家以及庞波尼乌斯在《告示评注》第六十九卷中都认为，不能指定聋者为监护人，因为监护人不仅应能说话，也应能听见。

<!-- source-p 008 -->
<a id="26.1.2"></a>**26.1.2**

<!-- source-p 009 -->
**庞波尼乌斯：《萨宾评注》第三卷。**

<!-- source-p 010 -->
不应要求未成年人为自己请求监护人，也不应要求他前往自己的监护人处。

<!-- source-p 011 -->
<a id="26.1.3"></a>**26.1.3**

<!-- source-p 012 -->
**乌尔比安：《萨宾评注》第三十七卷。**

<!-- source-p 013 -->
<a id="26.1.3.pr."></a>**序言。**已有监护人的未成年人，无论男孩还是女孩，若开始精神失常，仍处于监护关系之中。这是昆图斯·穆基乌斯的意见，尤利安也予以赞同。我们遵循的规则是：如果其年龄仍需要监护，监护关系就继续存在。因此，已有监护人的未成年人，不会因精神失常而转入保佐；原本没有监护人而后来精神失常的，也仍可取得监护人，因为《十二表法》被如此解释：该法的规定不适用于未成年人。

<!-- source-p 014 -->
<a id="26.1.3.1"></a>**1.**我们既然不允许未成年人的近亲属担任其保佐人，因此我认为，即使未满二十五岁的人精神失常，也应为其指定保佐人，但指定理由不是其精神失常，而是其尚属青年。对此我们会作如下界定：对于因年龄而须受保佐或监护的人，无须像对待精神失常者那样为其另行请求保佐人。皇帝安敦尼也曾作出同样的敕答，因为此时应暂且优先照顾其年龄，而非精神失常。

<!-- source-p 015 -->
<a id="26.1.3.2"></a>**2.**如果未成年人想要与其法定监护人诉讼，或者监护人想要与未成年人诉讼，并为该诉讼请求指定保佐人，那么该保佐人应由当事人本人请求，还是也可由对方请求？应知，无论未成年人作为原告还是被告，均可为此指定保佐人；但仅在应由其受领保佐人者本人提出请求时，方可指定。卡西乌斯在《告示评注》第六卷中写道，任何人都不得在其缺席时被指定这样的保佐人，也不得为任何缺席者指定保佐人；受领人须本人在场并提出请求，因此不能为婴儿指定。卡西乌斯还说，如果未成年人不愿请求指定此种保佐人，以致诉讼无法对其提起，裁判官本应强令其请求指定。

<!-- source-p 016 -->
<a id="26.1.3.3"></a>**3.**庞波尼乌斯在《萨宾评注》第十六卷中写道，可以在任何地点、任何时间指定此种保佐人。

<!-- source-p 017 -->
<a id="26.1.3.4"></a>**4.**如果未成年人请求指定此种保佐人，却未说明指定用于何事，那么该保佐人是否应视为对所有争议事项均已指定？塞尔苏斯说，塞尔维乌斯认为应视为对所有事项均已指定。

<!-- source-p 018 -->
<a id="26.1.4"></a>**26.1.4**

<!-- source-p 019 -->
**保罗：《萨宾评注》第八卷。**

<!-- source-p 020 -->
<a id="26.1.4.pr."></a>**序言。**所谓未明确限定事项而指定的保佐人，视为对整个诉讼均已指定，或许是针对这样的情况：未成年人和监护人之间提起遗产分割之诉、共有物分割之诉或界限确定之诉；此时即使未明确限定事项，保佐人不仅代表未成年人作为原告起诉，也代表未成年人应诉。

<!-- source-p 021 -->
<a id="26.1.4.1"></a>**1.**可以请求指定数名保佐人代替数名监护人，也可以指定一名代替数名，或指定一名代替一名；可以只为一个诉讼，也可以为数个诉讼请求指定保佐人。

<!-- source-p 022 -->
<a id="26.1.5"></a>**26.1.5**

<!-- source-p 023 -->
**庞波尼乌斯：《萨宾评注》第十七卷。**

<!-- source-p 024 -->
<a id="26.1.5.pr."></a>**序言。**既已为某项诉讼请求指定这样的保佐人，在其继续担任保佐人期间，不得为同一诉讼另行请求指定一名保佐人。

<!-- source-p 025 -->
<a id="26.1.5.1"></a>**1.**例如，如果提提乌斯被请求指定为对塞尤斯的诉讼保佐人，同一提提乌斯仍可被指定为对另一监护人的保佐人，从而同一人基于不同原因担任两名未成年人的保佐人。如果在不同时间为不同诉讼请求指定同一人，即使对方是同一监护人，也会出现同样情形。

<!-- source-p 026 -->
<a id="26.1.6"></a>**26.1.6**

<!-- source-p 027 -->
**乌尔比安：《萨宾评注》第三十八卷。**

<!-- source-p 028 -->
<a id="26.1.6.pr."></a>**序言。**可以为未成年的哑者或聋者指定监护人，这一点是正确的；但能否对他们作出监护人同意，尚有疑问。如果可以对不说话的人作出同意，那么对哑者也可以。尤利安在《学说汇纂》第二十一卷中所写的意见更为正确：即使当事人不说话，监护人也可以作出同意。

<!-- source-p 029 -->
<a id="26.1.6.1"></a>**1.**人们认为，行省总督不得附条件指定监护人；即使已经作出这种指定，也不发生效力。庞波尼乌斯也持此说。不过，行省总督所作的如下补充：“如果他提供担保，我便指定他为监护人”，并非使指定附有条件，而只是提醒：只有提供担保后，监护事务才交由其负责；也就是说，只有在其承诺妥善保全财产后，才允许其管理。

<!-- source-p 030 -->
<a id="26.1.6.2"></a>**2.**指定监护人既非统治权的行使，也非司法权的行使；只有法律、元老院决议或皇帝明确授予该项权力的人，才有权指定监护人。

<!-- source-p 031 -->
<a id="26.1.6.3"></a>**3.**可以为未成年的聋者指定监护人。

<!-- source-p 032 -->
<a id="26.1.6.4"></a>**4.**父亲尚在敌人控制之下的人，显然不能被指定监护人；但如果已经作出指定，该指定是否处于待定状态，尚可讨论。我认为该指定不发生效力：因为父亲返回后，未成年人即重新受其父权支配，仿佛父亲从未被敌人俘虏。相反，应为财产指定保佐人，以免财产在此期间遭受损失。

<!-- source-p 033 -->
<a id="26.1.7"></a>**26.1.7**

<!-- source-p 034 -->
**乌尔比安：《论争论》第二卷。**

<!-- source-p 035 -->
如果家子被裁判官指定为监护人，而父亲承认了监护事务，则父亲应承担全部责任；如果父亲未予承认，则仅以家子的特有财产为限承担责任。无论父亲亲自管理监护事务、同意家子管理，还是以其他方式参与监护事务，均视为已承认。有人曾写信给自己的儿子，要求他认真管理监护事务，并说：“你知道，风险关系到我们。”我认为，这种情形也应视为父亲已经承认；当然，如果父亲只是提醒儿子，则不视为承认。

<!-- source-p 036 -->
<a id="26.1.8"></a>**26.1.8**

<!-- source-p 037 -->
**乌尔比安：《意见集》第一卷。**

<!-- source-p 038 -->
保护人担任其自由人的监护人，也应恪尽诚信；如果其自由人虽为未成年人，却进行损害债权人的行为，公法允许撤销此类行为。

<!-- source-p 039 -->
<a id="26.1.9"></a>**26.1.9**

<!-- source-p 040 -->
**马尔基安努斯：《法学阶梯》第三卷。**

<!-- source-p 041 -->
对以下人员应采取非常程序予以惩处：经证实有人付钱以取得监护人身份；或收受报酬后出面促成指定不适任的监护人；或在列报未成年人财产时故意少报财产数额；或以明显诈欺方式出售未成年人的财物。

<!-- source-p 042 -->
<a id="26.1.10"></a>**26.1.10**

<!-- source-p 043 -->
**乌尔比安：《告示评注》第二卷。**

<!-- source-p 044 -->
即使不是该市的市民，也可以被指定为监护人，只要其被指定为该市未成年人的监护人即可。

<!-- source-p 045 -->
<a id="26.1.11"></a>**26.1.11**

<!-- source-p 046 -->
**保罗：《维泰利乌斯评注》第三卷。**

<!-- source-p 047 -->
如果精神失常者被指定为监护人，可以将该指定理解为：待其神志恢复时方生效。

<!-- source-p 048 -->
<a id="26.1.12"></a>**26.1.12**

<!-- source-p 049 -->
**保罗：《答复集》第十卷。**

<!-- source-p 050 -->
有人询问：为代替因公务而缺席者指定的监护人，是否会在该缺席者死亡后继续担任监护人，还是应另行请求指定监护人？保罗答复：为代替缺席者而指定的人，只要缺席者尚未返回，就在同一身份下继续担任监护人，直至未成年人达到适婚年龄为止。〔底本文字异常：“essententiarum”疑为相邻文字误连；本译文依句法作审慎断读。〕

<!-- source-p 051 -->
<a id="26.1.13"></a>**26.1.13**

<!-- source-p 052 -->
**庞波尼乌斯：《手册》第二卷。**

<!-- source-p 053 -->
<a id="26.1.13.pr."></a>**序言。**有时，即使未成年人已有监护人，仍会因监护人患病或年老而为其指定保佐人；此人更应被理解为财产管理人，而非通常意义上的保佐人。

<!-- source-p 054 -->
<a id="26.1.13.1"></a>**1.**另有监护辅助人，裁判官通常允许监护人指定此人，因为监护人无法胜任监护事务的管理；但监护人须自担风险指定该辅助人。

<!-- source-p 055 -->
<a id="26.1.14"></a>**26.1.14**

<!-- source-p 056 -->
**乌尔比安：《萨宾评注》第三十七卷。**

<!-- source-p 057 -->
<a id="26.1.14.pr."></a>**序言。**未成年人在未达青春期时经收养（*adrogatio*）归入他人父权，或未成年人遭流放，其监护人即不再担任监护人。

<!-- source-p 058 -->
<a id="26.1.14.1"></a>**1.**同样，如果未成年人沦为奴隶，监护关系当然终止。

<!-- source-p 059 -->
<a id="26.1.14.2"></a>**2.**监护人也会因其他原因而不再担任监护人，例如未成年人或监护人被敌人俘虏。

<!-- source-p 060 -->
<a id="26.1.14.3"></a>**3.**如果监护人仅在一定期限内被指定，期限届满后即不再担任监护人。

<!-- source-p 061 -->
<a id="26.1.14.4"></a>**4.**此外，如果某人因可疑而被免去监护人职务，他也就不再是监护人。

<!-- source-p 062 -->
<a id="26.1.14.5"></a>**5.**同样，如果某人附条件被指定为监护人，条件成就时，其监护人身份即告终止。

<!-- source-p 063 -->
<a id="26.1.15"></a>**26.1.15**

<!-- source-p 064 -->
**乌尔比安：《萨宾评注》第三十八卷。**

<!-- source-p 065 -->
如果某监护人并未被敌人俘虏，而是作为使节被派往敌方，或者受到敌方接纳，或投奔敌方，由于他并未因此成为奴隶，仍然保有监护人身份；但在此期间，总督应另行指定一名监护人。

<!-- source-p 066 -->
<a id="26.1.16"></a>**26.1.16**

<!-- source-p 067 -->
**盖尤斯：《行省告示评注》第十二卷。**

<!-- source-p 068 -->
<a id="26.1.16.pr."></a>**序言。**监护通常是男子承担的职务。

<!-- source-p 069 -->
<a id="26.1.16.1"></a>**1.**还应知，监护关系不会依继承权转移给他人；但法定监护关系会传给达到完全年龄的男性子女，其他监护关系则不会传给他们。

<!-- source-p 070 -->
<a id="26.1.17"></a>**26.1.17**

<!-- source-p 071 -->
**保罗：《萨宾评注》第八卷。**

<!-- source-p 072 -->
已经制定了若干元老院决议，以便为精神失常、哑或聋的监护人另行指定监护人。

<!-- source-p 073 -->
<a id="26.1.18"></a>**26.1.18**

<!-- source-p 074 -->
**涅拉提乌斯：《规则集》第三卷。**

<!-- source-p 075 -->
不得指定妇女为监护人，因为此职务属于男子；但妇女若特别向皇帝请求担任其儿子的监护人，则属例外。
