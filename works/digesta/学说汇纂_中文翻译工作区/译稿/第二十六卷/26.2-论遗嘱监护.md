# D.26.2 论遗嘱监护

<!-- source-p 001 -->
<a id="2"></a><a id="26.2"></a>**26.2.0. 论遗嘱监护（*De testamentaria tutela*）**

<!-- source-p 002 -->
<a id="26.2.1"></a>**26.2.1**

<!-- source-p 003 -->
**盖尤斯《行省告示评注》第十二卷。**

<!-- source-p 004 -->
<a id="26.2.1.pr."></a>**序言。**《十二表法》允许父母通过遗嘱，为处于自己家父权之下的子女指定监护人，不论子女为男性还是女性。

<!-- source-p 005 -->
<a id="26.2.1.1"></a>**1.**我们还应当知道，父母也可以通过遗嘱为遗腹子女、遗腹孙辈或其他遗腹后代指定监护人，但前提是：若这些子女在父母生前出生，就会处于父母家父权之下，并且不会使遗嘱失效。

<!-- source-p 006 -->
<a id="26.2.1.2"></a>**2.**还应当知道，某人若同时对儿子及处于其家父权之下的孙子行使家父权，并为孙子指定监护人，只有在孙子于该人死亡后不会重新归入其父亲的家父权之下时，才应认为该指定有效。若儿子在遗嘱人尚在世时已经脱离其家父权，就会发生这种情形。

<!-- source-p 007 -->
<a id="26.2.2"></a>**26.2.2**

<!-- source-p 008 -->
**乌尔比安《萨宾评注》第二卷。**

<!-- source-p 009 -->
神圣皇帝兄弟曾以复函指出，军人不得为将重新归入他人家父权之下的子女指定监护人。

<!-- source-p 010 -->
<a id="26.2.3"></a>**26.2.3**

<!-- source-p 011 -->
**乌尔比安《告示评注》第三十五卷。**

<!-- source-p 012 -->
<a id="26.2.3.pr."></a>**序言。**所谓遗嘱指定的监护人，也包括在遗嘱所确认的附录遗嘱中指定的人。

<!-- source-p 013 -->
<a id="26.2.3.1"></a>**1.**不过，只有依法指定的人，才应被视为遗嘱指定的监护人。

<!-- source-p 014 -->
<a id="26.2.4"></a>**26.2.4**

<!-- source-p 015 -->
**莫德斯蒂努斯《辨异论》第七卷。**

<!-- source-p 016 -->
父亲可以为被指定为继承人的儿子或被剥夺继承权的儿子指定监护人；母亲则只能为被指定为继承人的儿子指定监护人，似乎是为财产而非为人指定监护人。但对母亲遗嘱所指定的监护人，应进行调查；父亲所指定的监护人，即使指定不完全符合法律，仍无须调查便可获得确认，除非指定时据以作出的判断依据后来发生变化，例如原是朋友的人变成仇敌，或者原先富裕的人变得贫困。

<!-- source-p 017 -->
<a id="26.2.5"></a>**26.2.5**

<!-- source-p 018 -->
**乌尔比安《萨宾评注》第十五卷。**

<!-- source-p 019 -->
某人为其女儿或儿子指定监护人，也应认为包括遗腹女儿在内，因为“女儿”一词也涵盖遗腹女儿。

<!-- source-p 020 -->
<a id="26.2.6"></a>**26.2.6**

<!-- source-p 021 -->
**乌尔比安《萨宾评注》第三十九卷。**

<!-- source-p 022 -->
若有孙辈，应当考察“儿女”一词是否也包括他们。我更倾向于认为，若遗嘱人说的是“子女”，就应认为也为孙辈指定了监护人；若说的是“儿子”，则不包括孙子，因为儿子与孙子的称谓不同。当然，若遗嘱人是为遗腹后代指定监护人，则既包括遗腹儿子，也包括其他遗腹后代。

<!-- source-p 023 -->
<a id="26.2.7"></a>**26.2.7**

<!-- source-p 024 -->
**保罗《萨宾评注》第三卷。**

<!-- source-p 025 -->
监护人并非由继承人指定，而是直接由遗嘱人指定；只要有人取得继承人身份，指定便立即发生效力。继承人本人也可以被指定为监护人；即使是在继承人死亡之后指定监护人，也仍属有效。

<!-- source-p 026 -->
<a id="26.2.8"></a>**26.2.8**

<!-- source-p 027 -->
**乌尔比安《萨宾评注》第二十四卷。**

<!-- source-p 028 -->
<a id="26.2.8.pr."></a>**序言。**遗嘱人可以通过遗嘱或附录遗嘱，禁止已经指定的人成为监护人。

<!-- source-p 029 -->
<a id="26.2.8.1"></a>**1.**但若监护人是在附条件的情况下指定，条件未成就时，该人就不是监护人。

<!-- source-p 030 -->
<a id="26.2.8.2"></a>**2.**指定监护人时，可以规定其自某一确定时间起任职，或任职至某一确定时间；也可以附条件指定，或规定其任职至某一条件成就为止。

<!-- source-p 031 -->
<a id="26.2.8.3"></a>**3.**指定监护人时，应考察最轻微的条件，还是像遗赠一样考察最后写下的条件？例如：“提图斯在能够任职时担任监护人”；又如：“提图斯在船只从亚洲抵达时担任监护人。”尤利安在《学说汇纂》第二十卷中正确地写道，应以最后写下的条款为准。

<!-- source-p 032 -->
<a id="26.2.9"></a>**26.2.9**

<!-- source-p 033 -->
**庞波尼乌斯《评昆图斯·穆基乌斯》第三卷。**

<!-- source-p 034 -->
若无人接受遗产，遗嘱中所写的这些安排均不发生效力；但若数名继承人中有一人接受遗产，监护指定便立即有效，无须等待所有人都接受遗产。

<!-- source-p 035 -->
<a id="26.2.10"></a>**26.2.10**

<!-- source-p 036 -->
**乌尔比安《萨宾评注》第三十六卷。**

<!-- source-p 037 -->
<a id="26.2.10.pr."></a>**序言。**如果遗产尚未被接受，而遗嘱指定的监护人又是以该遗产获接受为前提，则更妥当的看法是，可以另行指定一名监护人，因为原监护人尚未成为监护人，也没有预期其将成为监护人。

<!-- source-p 038 -->
<a id="26.2.10.1"></a>**1.**在遗嘱监护中，我们遵循最后作出的指定；若监护人被多次指定，应以最后一份遗嘱文书为准。

<!-- source-p 039 -->
<a id="26.2.10.2"></a>**2.**某人有一名儿子及该儿子的儿子；若他为孙子指定监护人，就会产生疑问：在某种情形下，该指定是否无效？例如，儿子在父亲生前死亡，孙子在祖父仍在世时继承其父亲的身份。更有力的见解是，依《尤尼亚·维莱亚法》，监护指定也应得到确认；庞波尼乌斯在《萨宾评注》第十六卷中同样写道，该监护指定有效。遗嘱既已获得确认，其中所载的监护人指定也应随之有效；也就是说，孙子已被指定为继承人，或者已被明确剥夺继承权。

<!-- source-p 040 -->
<a id="26.2.10.3"></a>**3.**若遗嘱指定一名精神失常者为监护人，普罗库鲁斯认为，若指定条件是该人恢复神智后担任监护人，则该指定有效；若无条件指定，则无效。但庞波尼乌斯提出的见解更为妥当：该人应被视为已有效指定，只是在恢复神智后才开始担任监护人。

<!-- source-p 041 -->
<a id="26.2.10.4"></a>**4.**他人的奴隶可以按如下方式被指定为监护人：“若其成为自由人，就担任监护人。”甚至在无条件指定的情形下，也应认为包含“在其成为自由人时”这一条件。对于他人的奴隶，也可以基于此事主张遗嘱信托解放：遗嘱人指定的是自己的奴隶还是他人的奴隶，有何区别？既然被指定为监护人的人获得自由，是出于对被监护人的利益及公共利益的考虑，就可以为该奴隶主张遗嘱信托解放；但若遗嘱人的意思明显与此相反，则不在此限。

<!-- source-p 042 -->
<a id="26.2.11"></a>**26.2.11**

<!-- source-p 043 -->
**乌尔比安《萨宾评注》第三十七卷。**

<!-- source-p 044 -->
<a id="26.2.11.pr."></a>**序言。**若遗嘱人附条件或自某一日期起指定监护人，在此期间应另行指定监护人，即使被监护人已有法定监护人也如此。因为只要仍期待遗嘱监护开始，法定监护便暂不适用。

<!-- source-p 045 -->
<a id="26.2.11.1"></a>**1.**若监护已经转由遗嘱监护人承担，而该遗嘱监护人后来获得免责，我们仍认为应另行指定监护人，而非使监护关系重新回到法定监护人。

<!-- source-p 046 -->
<a id="26.2.11.2"></a>**2.**监护人被撤换时也适用相同规则：撤换该监护人正是为了另行指定他人。

<!-- source-p 047 -->
<a id="26.2.11.3"></a>**3.**但若遗嘱指定的监护人死亡，监护关系便回归法定监护，因为此时该元老院决议不再适用。

<!-- source-p 048 -->
<a id="26.2.11.4"></a>**4.**当然，若有两名或两名以上遗嘱指定的监护人，其中一人死亡或离开本城，可以另行指定一人填补空缺；否则，若没有任何遗嘱监护人尚在世或留在本城，就由法定监护接续。

<!-- source-p 049 -->
<a id="26.2.12"></a>**26.2.12**

<!-- source-p 050 -->
**乌尔比安《萨宾评注》第三十八卷。**

<!-- source-p 051 -->
遗嘱不得为其他事项或事务指定监护人，即使将有关事项分别列出，也不可以。

<!-- source-p 052 -->
<a id="26.2.13"></a>**26.2.13**

<!-- source-p 053 -->
**庞波尼乌斯《萨宾评注》第十七卷。**

<!-- source-p 054 -->
即使作出这种指定，整个指定也不发生效力，

<!-- source-p 055 -->
<a id="26.2.14"></a>**26.2.14**

<!-- source-p 056 -->
**马尔基安《制度论》第二卷。**

<!-- source-p 057 -->
因为监护人是为人指定的，而不是为物或某种事务指定的。

<!-- source-p 058 -->
<a id="26.2.15"></a>**26.2.15**

<!-- source-p 059 -->
**乌尔比安《萨宾评注》第三十八卷。**

<!-- source-p 060 -->
不过，若监护人是为非洲或叙利亚的事务而指定，该指定有效；我们适用的正是这一规则。

<!-- source-p 061 -->
<a id="26.2.16"></a>**26.2.16**

<!-- source-p 062 -->
**乌尔比安《萨宾评注》第三十九卷。**

<!-- source-p 063 -->
<a id="26.2.16.pr."></a>**序言。**若有人写道“我为我的子女指定监护人”，应认为其既为儿子也为女儿指定了监护人，因为“儿子”一词涵盖女儿。

<!-- source-p 064 -->
<a id="26.2.16.1"></a>**1.**若有人为其儿子指定监护人，而他有数名儿子，该指定是否应认为适用于所有儿子？对此，庞波尼乌斯有所疑问；但更妥当的看法是，应认为其为所有儿子都指定了监护人。

<!-- source-p 065 -->
<a id="26.2.16.2"></a>**2.**若有人为其子女，或为其儿子指定监护人，而其部分子女被敌人俘获，除非能够明确证明遗嘱人另有意思，否则应认为指定也适用于他们。

<!-- source-p 066 -->
<a id="26.2.16.3"></a>**3.**若某人不知道自己有一名名为提图斯的儿子，却为其子女指定监护人，应认为他只为自己知道并处于家父权之下的子女指定了监护人，还是也包括那个他不知道存在的儿子？更妥当的看法是，不应认为他为这个儿子指定了监护人。尽管“子女”一词从字面上可以包括他，但遗嘱人并未想到此人，因此应认为该指定对他不发生效力。

<!-- source-p 067 -->
<a id="26.2.16.4"></a>**4.**因此，若遗嘱人确信尚存的儿子已经死亡，也应作相同处理；因为他不可能为一个自己以为已经死亡的人指定监护人。

<!-- source-p 068 -->
<a id="26.2.16.5"></a>**5.**若遗嘱人为遗腹子女指定监护人，而这些子女在遗嘱人仍在世时出生，该指定是否有效？更妥当的看法是，即使子女在遗嘱人仍在世时出生，该指定也有效。

<!-- source-p 069 -->
<a id="26.2.17"></a>**26.2.17**

<!-- source-p 070 -->
**乌尔比安《告示评注》第三十五卷。**

<!-- source-p 071 -->
<a id="26.2.17.pr."></a>**序言。**毫无疑问，遗嘱指定的监护人不应被强制提供财产安全担保。但若有人主动提出担保，以便独自管理监护事务，则应听取其意见，正如告示所规定的。不过，裁判官正确地也向其他监护人提供同一选择：若他们也愿意担保，就不应仅因另一人提出担保而被排除；当然，所有人均已提供担保的，应由所有人共同管理事务。如此一来，宁愿取得充分担保而不愿亲自管理事务的人，也可确保其利益。

<!-- source-p 072 -->
<a id="26.2.17.1"></a>**1.**并非任何提供担保的人都当然应优先。若此人品行可疑或声名不佳，即使提供担保，也不应将监护事务交给他；又或者，他在监护事务中已经实施过许多不当行为，难道不应将其排除或撤换，而不让他独自管理吗？不提供担保的监护人也不得轻率排除，因为许多监护人已被证明品行良好、适任且诚实，即使不提供担保，也不应将其拒之门外；事实上，甚至不应命令他们提供担保。

<!-- source-p 073 -->
<a id="26.2.17.2"></a>**2.**因此，须进行双重调查：一方面调查提出担保者本人，查明其身份和品行；另一方面调查其他共同监护人的情况，判断他们是否具有足够的声誉和诚信，以至于不应承受提供担保这种侮辱。

<!-- source-p 074 -->
<a id="26.2.18"></a>**26.2.18**

<!-- source-p 075 -->
**卡利斯特拉图斯《告示释义》第三卷。**

<!-- source-p 076 -->
若有数名监护人都愿意提供担保，就应优先选择更为适任者，并对监护人本人及其保证人进行比较。

<!-- source-p 077 -->
<a id="26.2.19"></a>**26.2.19**

<!-- source-p 078 -->
**乌尔比安《告示评注》第三十五卷。**

<!-- source-p 079 -->
<a id="26.2.19.pr."></a>**序言。**若没有任何监护人主动提出提供担保，却有一名并非监护人的人要求：要么监护人提供担保，要么在他们不提供担保时将监护事务交给他管理，因为他愿意提供担保，那么不应受理其请求。监护事务既不应交给外人，也不得违反法律而强迫遗嘱指定的监护人提供担保。

<!-- source-p 080 -->
<a id="26.2.19.1"></a>**1.**这项关于担保的告示适用于遗嘱监护人。但马尔凯卢斯说，通过调查程序指定的监护人也适用该告示；两位神圣皇帝的敕答也表明了这一点。因此，这些监护人也受同一条款约束：若监护人中的多数作出决定，就由多数选定的人管理事务，尽管告示的文字仅指遗嘱监护人。

<!-- source-p 081 -->
<a id="26.2.19.2"></a>**2.**遗嘱为遗腹子指定的监护人，在遗腹子出生前尚不是监护人。不过，被监护人的替补继承人仍可对其提起无因管理之诉。若孩子出生后，该监护人在尚未管理任何事务之前即被撤换，也应依同一诉讼承担责任。当然，若他在孩子出生后已经管理事务，则对其此前所管理的事务，也应在监护之诉中承担责任；该诉讼将涵盖其全部管理行为。

<!-- source-p 082 -->
<a id="26.2.20"></a>**26.2.20**

<!-- source-p 083 -->
**保罗《告示评注》第三十八卷。**

<!-- source-p 084 -->
<a id="26.2.20.pr."></a>**序言。**不得指定身份不确定的人为监护人。

<!-- source-p 085 -->
<a id="26.2.20.1"></a>**1.**遗嘱人可以指定任何人为监护人，无论其为裁判官还是执政官；《十二表法》确认了这一点。

<!-- source-p 086 -->
<a id="26.2.21"></a>**26.2.21**

<!-- source-p 087 -->
**保罗《简要论集》第八卷。**

<!-- source-p 088 -->
遗嘱可以指定具有遗嘱能力的人担任监护人。

<!-- source-p 089 -->
<a id="26.2.22"></a>**26.2.22**

<!-- source-p 090 -->
**乌尔比安《告示评注》第四十五卷。**

<!-- source-p 091 -->
若某人将一名奴隶指定为其儿子的监护人，却误以为该奴隶是自由人，则该人既不会因此成为自由人，也不会成为监护人。

<!-- source-p 092 -->
<a id="26.2.23"></a>**26.2.23**

<!-- source-p 093 -->
**阿非利卡努斯《问题集》第八卷。**

<!-- source-p 094 -->
<a id="26.2.23.pr."></a>**序言。**以下述方式指定监护人并不有效：“提图斯担任我某一儿子或另一儿子的监护人，由他选择其中一人。”因为如果提图斯不愿意选择为哪一个儿子担任监护人，我们该如何处理？

<!-- source-p 095 -->
<a id="26.2.23.1"></a>**1.**但可以这样有效指定监护人：“若提图斯愿意，就由他担任我儿子的监护人。”

<!-- source-p 096 -->
<a id="26.2.24"></a>**26.2.24**

<!-- source-p 097 -->
**雅沃列努斯《卡西乌斯著作节本》第五卷。**

<!-- source-p 098 -->
若有数名监护人，就无须为诉讼之目的请求裁判官另行指定保佐人，因为可以在另一名监护人的同意下提起诉讼。

<!-- source-p 099 -->
<a id="26.2.25"></a>**26.2.25**

<!-- source-p 100 -->
**莫德斯蒂努斯《法学汇编》第四卷。**

<!-- source-p 101 -->
一人被指定为两名未成年被监护人的监护人，即使他因两人的事务彼此分离而可对其中一人申请免除，也仍然是另一人的监护人。

<!-- source-p 102 -->
<a id="26.2.26"></a>**26.2.26**

<!-- source-p 103 -->
**帕比尼安《答复集》第四卷。**

<!-- source-p 104 -->
<a id="26.2.26.pr."></a>**序言。**依我国法律，父亲不得在遗嘱中将共同子女的监护事务委托给母亲；即使行省总督因不熟悉法律而遵循父亲的意思作出裁定，其继任者也不应继续遵循该裁定，因为我国法律不承认这种做法。

<!-- source-p 105 -->
<a id="26.2.26.1"></a>**1.**父亲希望某人以荣誉身份担任监护人，但又要求其向其他受托管理事务的监护人收取账目；在这种情形下，不应认为该人是仅为荣誉而指定的监护人。

<!-- source-p 106 -->
<a id="26.2.26.2"></a>**2.**为处理被剥夺继承权之子提起的遗嘱违反亲属义务之诉，父亲已为其指定监护人；裁判官应确认该监护人。判决结果将表明，该监护人究竟是依据父亲的遗嘱，还是依据裁判官的裁定取得监护人身份。

<!-- source-p 107 -->
<a id="26.2.27"></a>**26.2.27**

<!-- source-p 108 -->
**特里丰尼努斯《论辩集》第十四卷。**

<!-- source-p 109 -->
<a id="26.2.27.pr."></a>**序言。**若有人代表未成年被监护人主张其父亲无遗嘱死亡，或代表该被监护人主张遗嘱系伪造，也适用相同规则。即使被监护人的叔父作为法定监护人出现，也不得再为已有监护人的人指定监护人。更为妥当的是，由裁判官指定遗嘱中所载之人为监护人，使其能够在不预断任何诉讼争议的情况下，以合法监护人的身份为未成年人参与该诉讼。

<!-- source-p 110 -->
<a id="26.2.27.1"></a>**1.**但如果被监护人所称的法定监护人——其叔父——指控该被监护人是被冒充的儿子，并主张自己有权继承法定遗产，尤利安答复说，应另行请求指定监护人。

<!-- source-p 111 -->
<a id="26.2.28"></a>**26.2.28**

<!-- source-p 112 -->
**帕比尼安《答复集》第四卷。**

<!-- source-p 113 -->
<a id="26.2.28.pr."></a>**序言。**某人依法可以申请免除遗嘱指定的监护职责，却拒绝承担该职责；若遗嘱留给其子女的遗赠并非出于对子女本人的感情，而是为了向其父亲表示敬意，也应剥夺其子女取得这些遗赠的资格。

<!-- source-p 114 -->
<a id="26.2.28.1"></a>**1.**通过遗嘱信托获释的人，不能在遗嘱中被有效指定为监护人。因此，待其获得自由后，应依遗嘱人的意思召其担任监护人。

<!-- source-p 115 -->
<a id="26.2.28.2"></a>**2.**保护人不得有效地为未成年自由释奴指定监护人；但若调查所得与保护人的意思相符，裁判官将遵循其意愿。

<!-- source-p 116 -->
<a id="26.2.29"></a>**26.2.29**

<!-- source-p 117 -->
**帕比尼安《答复集》第十五卷。**

<!-- source-p 118 -->
依《利博尼亚元老院决议》的意见，凡在遗嘱中将自己写作未成年人的监护人者，不得成为监护人。但若父亲亲笔写明的意思明确无疑，我答复说，即使另有监护人，也应指定该人为保佐人；并且不应准许他援引公法上的免除理由，因为他似乎已经作出承诺，也不应以其品行可疑为由将其撤换。

<!-- source-p 119 -->
<a id="26.2.30"></a>**26.2.30**

<!-- source-p 120 -->
**保罗《问题集》第六卷。**

<!-- source-p 121 -->
有两名提图斯，一人为父、一人为子。遗嘱指定名为提图斯的人担任监护人，却未显示遗嘱人指的是哪一位。我问，应适用何种法律。答复说：应认为遗嘱人指定的是其想要指定的人；若无法确定，欠缺的不是法律规则，而是证明。因此，两人都不是监护人。

<!-- source-p 122 -->
<a id="26.2.31"></a>**26.2.31**

<!-- source-p 123 -->
**斯凯沃拉《问题集》第四卷。**

<!-- source-p 124 -->
若父亲为被剥夺继承权的女儿指定监护人，而其遗嘱因遗腹子出生而被认为失效，最妥当的做法是为该女儿请求继承无遗嘱遗产时，仍指定同一批监护人。

<!-- source-p 125 -->
<a id="26.2.32"></a>**26.2.32**

<!-- source-p 126 -->
**保罗《答复集》第九卷。**

<!-- source-p 127 -->
<a id="26.2.32.pr."></a>**序言。**我问，能否在遗嘱中指定与遗嘱人属于同一城市的公民担任监护人？保罗答复说，可以。

<!-- source-p 128 -->
<a id="26.2.32.1"></a>**1.**保罗还答复说，因熟悉事务而被指定为监护人的人，在监护事务管理及相应责任方面，与同一遗嘱指定的其他监护人一样，均可以被诉。

<!-- source-p 129 -->
<a id="26.2.32.2"></a>**2.**卢基乌斯·提图斯指定自己的儿子为未成年继承人，并以如下措辞为他们指定监护人：“我的儿子们应由盖乌斯·梅维乌斯和卢基乌斯·埃罗斯担任监护人。”他没有给予埃罗斯自由；而埃罗斯尚未满二十五岁。我问，埃罗斯能否主张自由。保罗答复说，既然通行见解认为，主人指定奴隶担任监护人时，该奴隶也应视为因此获得自由，那么，本案中的埃罗斯也应处于同一地位：遗产一经接受，他就成为自由人；但监护职责这一负担，要到其达到法定年龄后才加于其身。

<!-- source-p 130 -->
<a id="26.2.33"></a>**26.2.33**

<!-- source-p 131 -->
**雅沃列努斯《拉贝奥后论节本》第八卷。**

<!-- source-p 132 -->
遗嘱人如此指定监护人：“我指定卢基乌斯·提图斯为监护人。若他不在世，则指定盖乌斯·普劳提乌斯为监护人。”提图斯当时尚在人世，并已履行监护职责，后来才死亡。特雷巴提乌斯认为，监护职责不转由普劳提乌斯承担；拉贝奥持相反意见，普罗库鲁斯也赞同拉贝奥。我赞同特雷巴提乌斯的意见，因为这些措辞指的是遗嘱所涉的死亡时点。

<!-- source-p 133 -->
<a id="26.2.34"></a>**26.2.34**

<!-- source-p 134 -->
**斯凯沃拉《学说汇纂》第十卷。**

<!-- source-p 135 -->
遗嘱人曾表示要通过附录遗嘱另行指定监护人，因为他发现遗嘱中指定的部分监护人已经死亡，或可能申请免除。问题是，其他仍在世且未获免除的人是否仍继续担任监护人？答复说，没有提出任何理由表明他们不应继续担任监护人。
