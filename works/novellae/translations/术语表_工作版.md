# 《查士丁尼新律及相关文献》罗马法术语表（工作版）

此表用于新律、敕令、附录及《尤利安新律拉丁摘要》译稿的统一校订，须结合语境判断；不要机械替换不同法律关系中的同形词。原文拉丁／希腊术语应在首次出现、存在歧义或涉及罗马法专门制度时保留括注。

| 原文术语 | 暂定译法 | 使用说明 |
|---|---|---|
| heres | 继承人 | 区分遗产本身 hereditas 与继承人资格。 |
| hereditas | 遗产／继承 | 按指向财产整体或继承关系择译。 |
| legatum | 遗赠 | 不与遗嘱继承混同。 |
| legatarius | 受遗赠人 | 与继承人、信托遗赠受益人区分。 |
| fideicommissum | 信托遗赠 | 罗马法制度名；依具体文本说明其请求、给付或遗嘱安排。 |
| fideicommissarius | 信托遗赠受益人 | 全书统一采用；若原文明示概括性信托遗赠，则译作“概括信托遗赠受益人”。 |
| fideicommissarius generalis | 概括信托遗赠受益人 | 与特定信托遗赠受益人区分。 |
| ab intestato | 无遗嘱继承／无遗嘱继承人 | 根据修饰继承、继承人或召集顺位的语法关系调整。 |
| exheredatus | 被剥夺继承权者 | 与单纯未列入遗嘱者区分。 |
| Falcidia / lex Falcidia | 法尔基第法／法尔基第法上的四分之一 | 首次出现说明其限制遗赠、保障继承人保留份额的作用；不要只译作普通“法定份额”。 |
| dos | 嫁资 | 涉及婚姻财产时保持与 donatio propter nuptias 区分。 |
| donatio propter nuptias | 婚前赠与 | 依篇章语境确认时间与制度含义，不与嫁资合并。 |
| praefectus praetorio | 近卫大区长官 | 如上下文需要，可首次括注拉丁官职名；避免与 praefectus urbi 混淆。 |
| praefectus urbi | 城市长官 | 指罗马／君士坦丁堡城市长官时按文本注明。 |
| provincia | 行省 | 不笼统译为“省份”。 |
| sacra iussio | 神圣敕令 | 保留其皇帝命令程式含义，不泛译为普通命令。 |
| constitutio | 宪令／皇帝敕令 | 根据作品标题、发布形式和语境择一，保持篇内统一。 |
| praefatio | 序言 | 作为新律结构标题时保留 Praefatio 对照。 |
| caput | 章 | 罗马法文本篇章层级；可保留 Caput I 等原标记。 |
| epilogus | 结语 | 作为文本结构标题，保留 Epilogus 对照。 |
| fideiussor | 保证人 | 如特指罗马法保证关系，首次保留拉丁术语。 |
| sportulae | 礼金／规费 | 依文本中的职务授予或行政收费语境确定，不直译成现代诉讼费。 |

如发现本表与特定篇章的制度含义不合，应在该篇译者注中说明，并把校订建议记回本表；不以术语统一为由抹平原文差异。
