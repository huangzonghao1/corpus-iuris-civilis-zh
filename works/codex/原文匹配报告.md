# 拉丁引文与网页锚点匹配报告

核验日期：2026-09-27（Asia/Shanghai）

## 范围与方法

核对对象为 16 个核心 HTML 页面中的法条锚点及其译稿 Markdown 引文。运行命令：

```text
python3 audit_translation_sources.py
```

脚本按网页锚点抽取源文，读取译稿中标记为拉丁原文的段落，统一处理空白和约定的 Markdown 标记后逐项比较。原始来源字节、编码和摘要另见 `source_manifest.json`。

## 解释与限制

本报告证明的是机器抽取后拉丁引文与本地网页转录的文本匹配；不证明网页转录等同于 Krueger 印本，也不评价中文译文的语义或法律解释。若网页源文存在疑似讹字、缺文、重复或未锚定段落，依问题表保留并另作记录，不据此静默订正文句。

CJ1 1.17.2 中另有网页显示为 12(13) 的未锚定段落，问题表将其单独登记；该项不属于 4,667 个命名锚点计数。
