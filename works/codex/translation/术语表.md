# 术语表

本表汇集本书拉丁法学术语的暂定译名及适用说明。不同语境下可能需要细分；首次出现处保留拉丁术语或于条文后说明。

| 拉丁术语 | 统一译名 | 语境说明 |
| --- | --- | --- |
| Codex Iustinianus | 《查士丁尼法典》 | 全书书名；拉丁题名首次并列保留。 |
| Corpus Iuris Civilis | 《民法大全》 | 丛书名；首次并列保留拉丁题名。 |
| liber | 卷 | 全书层级；必要时保留 Liber I 等原编号。 |
| titulus | 题 | 卷内层级；题名保留原编号。 |
| constitutio | 敕令 | 皇帝立法文本的泛称；依具体文本功能细分。 |
| imperator | 皇帝 | 罗马皇帝；不与现代国家元首制度作等同。 |
| restitutio in integrum | 恢复原状救济 | 古典法上的衡平救济；首次可并列拉丁术语，避免等同于现代民法上的一般恢复原状。 |
| minor; minor annis viginti quinque | 未成年人；未满二十五岁者 | 罗马法年龄语境通常指未满二十五岁者，依条文条件译出。 |
| actio | 诉权；诉讼 | 依语境区分诉讼形式、程序权利与起诉行为；重要专名保留拉丁语。 |
| exceptio | 抗辩 | 罗马程序法上的抗辩；与现代实体法抗辩不当然等同。 |
| rescriptum | 皇帝复文 | 皇帝对请示或呈请所作的答复文本。 |
| iusiurandum; sacramentum | 宣誓；誓言 | 依语法作动词或名词处理；不得与现代证据法规则等同。 |
| tutor; tutela | 监护人；监护 | 罗马法上的监护关系，依语境区分人和制度。 |
| fideicommissum | 信托遗赠 | 罗马法遗嘱处分方式；避免直接套用普通法信托。 |
| dilatio | 期限展延 | 诉讼中的期限延长或延期；依据上下文选用。 |
| feriae | 休庭日；法定休假日 | 司法审理停歇日；依语境说明其是否属于法定节日。 |
| suffragium | 助力；请托性支持 | 为实现请求而提供的支持或援助，不译为选举投票。 |
| commonitorium | 推荐状；告知文书 | 依语境可指载有支持或通知内容的书面文书。 |
| procurator | 代理人 | 罗马法代理制度术语；依文书或诉讼语境细分。 |
| praeses provinciae | 行省长官 | 行省治理及司法职务；不等同于现代行政职务。 |
| fiscus | 国库 | 罗马帝国皇帝财政机关或国库，依条文语境确定。 |
| bonae fidei contractus | 善意契约 | 罗马法契约类别术语；解释其诉讼与诚信义务语境。 |
| arbiter; compromissum | 仲裁人；仲裁协议 | 罗马法仲裁程序；依原文分别译出仲裁人和提交仲裁的合意。 |
| usucapio | 取得时效 | 罗马法通过持续占有取得所有权的制度。 |
| commodatum | 使用借贷 | 无偿交付物品供他人使用并负返还义务的契约类型。 |
| pignus; hypotheca | 质押；抵押 | 依物的交付与否和文本语境区分罗马法担保形态。 |
| actio pigneraticia | 质权诉权 | 基于质权关系请求返还质押物或追究相关责任的诉权。 |
| chirographum | 亲笔文书 | 私人亲笔书写的文书；与法院或官方文书区分。 |
| apocha; antapocha | 收据；反向收据 | 收款凭证及其由受领人交付的对应凭证；保留拉丁术语以避免现代票据化。 |
| arrha | 订金 | 为买卖承诺而交付的款项；依条文处理双倍返还或丧失。 |
| actio institoria | 经理人诉权 | 针对被委任经营业务之人所订合同的罗马法诉权。 |
| actio exercitoria | 船舶经营诉权 | 针对船舶经营业务中相关合同的罗马法诉权。 |
| peculium | 特有财产 | 奴隶或家子管理的特定财产集合；不直接等同现代独立财产。 |
| dispensator | 财务管理人 | 管理款项、账簿或支付事务的人员；依上下文细化。 |
| fructus | 孳息 | 物所产生的收益；区分已经取得与应当取得者。 |
| actio de peculio | 特有财产之诉 | 以奴隶或家子特有财产为责任限额的诉权。 |
| actio de in rem verso | 利益归入之诉 | 以证明所得利益归入主人或家父事务为前提的诉权。 |
| actio quod iussu | 依命令之诉 | 依据主人或家父授权订立交易而发生的诉权。 |
| actio furti | 盗窃之诉 | 罗马法上针对盗窃行为的诉权。 |
| filius familias | 家子 | 处于家父权下的儿子；并非仅指未成年子女。 |
| stipulatio | 要式口约 | 以特定问答形式成立的口头债务约定。 |
| colonus | 佃户 | 与土地经营、租佃身份相关；依具体法律地位译出。 |
| conductor | 承租人 | 依租赁关系受领物或承接业务之人；语境可能涉及地产承租。 |
| actor; procurator | 事务代理人；诉讼代理人 | 在监护诉讼中，actor指为被监护人事务受任处理事务者，procurator指诉讼代理人；其他语境仍依具体职能区分。 |
| actio tutelae; negotiorum gestorum actio | 监护诉讼；事务管理之诉 | 罗马法上相应的责任诉讼，依当事人关系与案件语境使用。 |
| mandatum; actio mandati | 委任；委任之诉 | 委任关系及据此发生的诉讼救济；与代理权限和费用责任相连。 |
| actio empti; actio venditi | 买受之诉；出卖之诉 | 分别对应买卖中买受人及出卖人的诉权，依请求主体区分。 |
| actio pro socio | 合伙之诉 | 合伙人之间用于结算、履行合伙义务及分配收益的诉权。 |
| emptio venditio | 买卖 | 罗马法上的买卖合同关系；依条文判断成立、交付与风险承担。 |
| evictio | 追夺 | 买受人因第三人权利而失去买卖标的物的情形及相关保障。 |
| capitatio praedii | 地产人头税 | 地产所负担的税额，依当地税制语境解释。 |
| publicae pensitationes | 公共赋税 | 由占有人或土地相关主体承担的公共缴纳义务。 |
| arrha sponsalicia; arrhae sponsaliciae | 订婚定金 | 罗马法婚约中的特定给付及返还、罚则；不径直等同现代合同法定金。 |
| sponsalia | 婚约；订婚关系 | 罗马法上的婚姻预约关系；与婚姻本身相区分。 |
| dos | 嫁资 | 为婚姻提供的财产；与婚前赠与相区别。 |
| donatio ante nuptias | 婚前赠与 | 罗马法婚前赠与制度；与嫁资相区别。 |
| actio rei uxoriae | 嫁资返还之诉 | 历史诉权名称；在查士丁尼敕令中并入要式口约之诉。 |
| actio ex stipulatu | 要式口约之诉 | 依据要式口约请求履行的罗马法诉权；依具体敕令确定其特别性质。 |
| curator; cura | 管理人；管理 | 未成年人或其他需保护者的财产管理关系；与tutor/tutela区分。 |
| venia aetatis | 提前成年许可 | 准许未达通常年龄者提前取得完全行为能力的许可。 |
| defensor civitatis | 城市护民官 | 晚期罗马城市中的职官；依具体敕令说明权限，不套用现代监察制度。 |
| dos adventicia | 外来嫁资 | 按旧法分类，非由妻方父亲或其他父系尊亲属提供的嫁资，通常包括女子本人或其他外人提供者；依具体条文确认来源主体。 |
| dos profecticia | 父系嫁资 | 按旧法分类，由妻方父系尊亲属（通常为女方父亲）为其提供的嫁资；依具体条文确认来源主体。 |
| retentio; retentiones | 保留扣除规则 | 嫁资返还诉讼中为特定事由扣留、抵扣嫁资的规则。 |
| lex Falcidia | 法尔基迪亚法 | 限制遗赠总额并保障法定四分之一份额的罗马法。 |
| parapherna | 副财产 | 嫁资以外由妻子保有的财产；避免误作另一份嫁资。 |
| exceptio non numeratae pecuniae | 未交付款项抗辩 | 针对虽有债务文书记载但金钱并未实际交付的抗辩。 |
| alimenta; alimentum | 生活供养；扶养 | 依具体关系指对子女、父母或配偶的扶养费用，不直接等同现代法上的单一扶养制度。 |
| concubina; concubinatus | 妾；非婚同居关系 | 罗马法承认的非婚伴侣关系；依条文语境描述，避免与合法婚姻混同。 |
| actio communi dividundo | 共有物分割之诉 | 请求分割共有物的诉权。 |
| actio utilis | 准诉权 | 由裁判官扩展或类推给予的救济；依原有诉权作必要调整。 |
| actio in factum | 事实之诉 | 针对具体事实情形授予的诉权；不与严格法诉权混同。 |
| actio iudicati | 判决执行之诉 | 依据已作出的判决请求履行或执行的诉权。 |
| actio protutelae | 临时监护之诉 | 针对未经正式任命但实际管理未成年人事务者的责任诉权。 |
| satisdatio; cautio rem pupilli salvam fore | 担保；确保未成年人财产安全的担保 | 依监护人、管理人及相关程序语境说明担保对象。 |
| agnatus; agnatio | 父系亲属；父系亲属关系 | 依罗马法父系亲属关系界定；与自然血缘亲属的范围不完全相同。 |
| cognatus; cognatio | 血亲；血亲关系 | 基于自然血缘形成的亲属关系；与父系法律亲属关系区分。 |
| patruus; avunculus | 父系伯叔；母舅 | patruus为父亲的兄弟，avunculus为母亲的兄弟。 |
| vectigal | 税收；税收承包权 | 依语境指公税、公共收入或承包征收相关事务。 |
| tutor testamentarius; tutor legitimus | 遗嘱指定监护人；法定监护人 | 依监护人指定来源区分；另有经裁判官指定的类型。 |
| fideiussor; fideiussio | 保证人；保证 | 罗马法债务担保关系；区分主债务人与保证人。 |
| stipulatio rem salvam fore | 确保财产安全的要式口约 | 监护事务中确保未成年人财产得到保全的特别担保约款。 |
| usurae legitimae | 法定利息 | 依法律规定的利率或标准计算的利息。 |
| lata culpa; latae culpae | 重大过失 | 罗马法过失等级术语；按具体条文确定其责任范围。 |
| actio contraria; contrarium iudicium | 反向诉权；反向之诉 | 在监护诉讼及相应反请求语境中，依原文的诉讼形式选译。 |
| confusio | 债权债务混同 | 同一人兼具债权人与债务人身份而使债务在相应范围消灭。 |
| litis contestatio | 争点确定 | 罗马诉讼程序阶段术语；不等同现代法庭审理中的单一庭审行为。 |
| adrogatio | 自权人收养 | 收养自权人并使其进入收养人的家父权之下的制度。 |
| longi temporis praescriptio | 长期时效抗辩 | 罗马法长期占有或经过一定期间所生的抗辩；具体期间和效力依文本确定。 |
| pubertas | 法定成年年龄；青春期 | 涉及监护终止时指达到罗马法上的pubertas年龄；依语境避免误作现代成年年龄。 |
| suspectus tutor | 可疑监护人 | 经请求主管机关审查、可能被撤换的监护人。 |
| servus fugitivus; fugitivus | 逃亡奴隶；逃亡者 | 罗马法奴隶身份与逃亡相关规则；依语境区分身份与一般逃亡者。 |
| mancipium | 奴隶 | 依罗马法身份语境译出；不在译文中将奴隶身份现代化。 |
| libertus; libertinus | 释奴；自由释奴 | 已获释的原奴隶；依条文区分释放方式和身份。 |
| manumissio; manumittere | 释奴；释放奴隶 | 奴隶获得自由的制度行为或释放行为。 |
| actio servi corrupti | 诱使奴隶败坏之诉 | 针对诱使、败坏他人奴隶者的罗马法惩罚性诉权。 |
| condictio | 返还请求诉权 | 特定债法请求形式；依债的来源和条文语境具体表述。 |
| vindicatio | 返还所有物之诉 | 所有权人请求返还其物的对物诉权。 |
| furtum manifestum; furtum nec manifestum | 显明盗窃；非显明盗窃 | 罗马法盗窃分类，决定相应惩罚幅度；不按现代犯罪现行犯规则简单等同。 |
| plagium | 拐卖奴隶；诱拐人口 | 罗马法上非法诱拐、买卖奴隶或自由人的行为；依具体对象译出。 |
| operae libertorum; operae | 释奴劳务义务；劳务 | 释奴可能对原主人负担的特定劳务；与一般劳动合同区分。 |
| res furtiva | 赃物；被盗物 | 盗窃所得之物；涉及取得时效限制时保留罗马法语境。 |
| heres; hereditas | 继承人；遗产 | 罗马法继承制度概念；依语境区分继承人身份、继承权和遗产。 |
| institutio heredis; heredem instituere | 继承人指定；指定继承人 | 遗嘱中设定继承人的处分；与遗赠、信托遗赠区分。 |
| substitutio; substitutus | 替补继承指定；替补继承人 | 遗嘱中在前位继承人不能或不愿继承时设定的后位安排。 |
| substitutio pupillaris | 未成年继承人替补指定 | 为受监护未成年人设置的特别继承替补制度。 |
| exheredatio; exheredare | 剥夺继承资格；剥夺继承资格 | 依遗嘱明示排除法定继承人；译文按罗马法制度说明。 |
| postumus; postuma | 遗腹子；遗腹女 | 立遗嘱时尚未出生而后来出生的子女；依性别和上下文处理。 |
| bonorum possessio | 遗产占有权；裁判官遗产承受 | 由裁判官法赋予的遗产承受地位；与市民法上的继承区分。 |
| ex asse; ex certa parte | 全部遗产；确定份额 | ex asse为全部遗产份额，ex certa parte为指定的确定份额。 |
| adire hereditatem; aditio hereditatis | 接受遗产；遗产承受 | 继承人作出承受遗产的行为；与单纯被指定为继承人区分。 |
| legitimam portionem; legitima portio | 法定份额 | 法律保障的最低遗产份额；依具体时期和文本确定数额。 |
| delatio hereditatis; hereditas delata | 遗产开放继承；继承的开放 | 表示继承已向特定继承人开放或转归；与其后实际接受遗产相区分。 |
| pro herede gerere | 以继承人身份处理遗产 | 对遗产实施足以表明接受继承的管理或处分行为；依具体条文辨别其效果。 |
| sui heredes; heres suus | 自权继承人 | 家父死亡时处于其家父权之下、依法直接取得继承地位者；依条文范围处理。 |
| beneficium deliberandi; ius deliberandi | 考虑期限利益；考虑是否接受遗产的权利 | 继承人获得一定期间决定接受或放弃继承的制度利益；依敕令变化说明其期间及效果。 |
| cretio | 正式接受继承声明 | 古法接受继承时的正式声明手续；查士丁尼法典相关规定明确废止。 |
| uncia; uncia hereditatis | 十二分之一份额 | 遗产份额的计量单位；十二份构成全部遗产。 |
| consanguineus; consanguinitas | 同父血亲；同父血亲关系 | 罗马法继承语境常指同父兄弟姐妹之间的关系；按条文与一般血亲或父系亲属概念区分。 |
| ususfructus | 用益权 | 对他人财产享有使用及取得收益的权利；与财产所有权区分。 |
| bona materna; bona materni generis | 母系财产；母系来源财产 | 母亲或母系亲属来源的财产；依法律规定，所有权与家父的用益权可能分离。 |
| praemium emancipationis | 解放奖励 | 父亲依特定法律安排解放处于家父权下子女时可取得的财产利益；份额依条文确定。 |
| manumissio vindicta | 以权杖仪式释奴 | 罗马市民法上的正式释奴方式；不应误作现代诉讼程序，依制度语境说明。 |
| manumissio apud consilium | 在评议会前释奴 | 奴隶在皇帝评议会或有权官员前经审理取得自由；与权杖仪式释奴区分。 |
| libertas directa; manumissio directa | 直接授予的自由；直接释奴 | 遗嘱人以直接处分方式授予奴隶自由；与信托释奴区分。 |
| libertas fideicommissaria; manumissio fideicommissaria | 信托方式授予的自由；信托释奴 | 立遗嘱人请求继承人或受遗赠人履行释奴；不得直接套用现代信托制度。 |
| statuliber; statuliberi | 附条件获释奴隶 | 自由已被安排但须待条件成就；条件成就前仍处于奴隶身份。 |
| lex Aelia Sentia | 《埃利亚—森提亚法》 | 罗马释奴法之一，对未成年人释奴、诈害债权人等设有限制。 |
| lex Fufia Caninia | 《富菲亚—卡尼尼亚法》 | 限制遗嘱释奴数量的罗马法；查士丁尼《法典》7.3.1废止该法。 |
| ingenuus; ingenua | 自由出生者 | 自出生即为自由人者；与经释奴取得自由的 libertinus 区分。 |
